# L1 Sentence value

**Applies when:** always.
**Requires:** where the sentence can carry it, it says what it does for the reader.
**Evidence:** the benefit in a few words, or "none" plus why the fact is needed.

- Goal first; the benefit before the bare fact, in the sentence's structure (goal clause, subject,
  verb), never in an added sentence or an adjective. An opt-in states its advantage.
- A cross-reference states the fact its target holds, with the link on those words. A trailing
  "See [X]" only when the sentence can't state that fact; link text that only gestures at the target
  ("covers the details") fails.
