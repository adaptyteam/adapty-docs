# Frame check

**Applies when:** always.
**Requires:** once per article, a frame; for every sentence, a one-line check that it still belongs.
**Evidence:** the frame (written once): the article's promise (title, description), its reader, and
each section's promise in one line. Per sentence: the section promise and article promise it serves,
and the `act` question or user request it answers (`reader-questions.md`, when the session has one).
None: cut the sentence; its fact stays in `facts.md`.

- If a sentence may not belong in its section or article, load `L3` and `L4` and run them.
