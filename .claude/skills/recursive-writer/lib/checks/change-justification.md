# Change justification

**Applies when:** a change to existing or approved text.
**Flags:** --change
**Requires:** existing text changes only to fix a reader problem: wrong, misleading, unclear, fails a
check, or conflicts with the edit being made. Style preference alone isn't one. Existing text means
text already in the file before this task, or approved or written by the user. Your own draft isn't
existing text.
**Evidence:** the reader problem, in one line. None: leave the text alone.

- A style-only check-10 hit (a lone "lets you", an avoidable gerund) in a sentence you aren't
  otherwise changing isn't a reader problem: fix it only in sentences you write or already change, and
  don't list it under "Also noticed".
- Inherited text: find out why it's there before cutting; if it still has a purpose, rework it.
- The user's manual edits and dictated text never change unless they ask. Exception: a fact in dictated
  text contradicts the source. Propose their structure with the fact corrected, show the evidence;
  never correct it silently.
