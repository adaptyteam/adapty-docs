# Product terms

**Applies when:** always.
Current names win; a date marks when a term changed, where known. Check the frontend for UI labels.

- **Flows**: the entity. The tool is the **Flow & Paywall Builder** (capital B, ampersand): the full
  name on first mention and wherever it doesn't hurt readability; later mentions can say "the
  builder" or "the flow builder". In text that covers both builder generations, "our builder". Never
  "flow" for a sequence of steps.
- **Old Paywall Builder**: the deprecated builder. Keep "old Paywall Builder" wherever it's used; don't
  change it to "legacy builder". For its paywalls: "paywalls from the old Paywall Builder" or "legacy
  builder paywall", never "legacy Paywall Builder paywall".
- **Custom paywall** (2026-09-30): a paywall the app renders itself from SDK product data; remote
  config is optional. Not "headless". "Manually implemented paywall" in intros where remote config
  isn't the subject. Keep "custom paywall" where it already exists.
- Flows come before paywalls in every enumeration.
- A placement **serves** one content type (a flow, a paywall, or an onboarding); it doesn't include,
  contain, or have it. Each type has its own remote config. "Paywall" has three senses (the SDK
  paywall object, a paywall from the old Paywall Builder, a paywall screen in a flow): name the one
  you mean.
- **Purchases**: a flow displays products and triggers a purchase, a button or a **Purchase** action
  starts it, and the store completes it. Nothing in a flow buys, sells, or purchases, and nothing
  sells "on" or "from" a screen.
- **Access levels**, never "entitlements".
- **Profiles**, not "user accounts" or "users", where anonymous profiles count.
- **Field** only for something on screen; SDK and API members are **properties** or **parameters**.
- **Google Analytics** and **Firebase**; never "GA4" or "Firebase Analytics".
- **Products panel**: "the products you added to the screen", never "products on the screen".
- **Add element** panel: "Open the **Add element** panel." (no route; it has several entry points).
- 12-month commitment: **upfront plan** and **commitment plan**, never "monthly plan".
- Adapty Mail terms that shadow core Adapty terms get a qualifier: Adapty Mail's **Profiles** vs
  Adapty profiles; Adapty Mail flows vs flows.
- SDK versions: no "current", "legacy", "deprecated", "new", or "modern" labels; name the version.
