# Shell preamble

Paste this at the top of every subagent prompt: rw-draft's `briefs/fit-pass.md` and
`briefs/review-round.md`, rw-plan's `briefs/structure-pass.md`, and the pass-1 briefs in rw-research,
rw-questions, and rw-ripple.

Read-only: never edit, commit, push, or switch branches; write only your output files. Shell: zsh. Quote
separators ('-----'): zsh treats a bare `=word` specially. Write files with Python or `>|`: noclobber
refuses `>` onto an existing file.
