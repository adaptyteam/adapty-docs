To update your app from Adapty Android SDK 4.1, 4.2, or 4.3 to 4.4, set the `adapty-bom` version to `4.4.0`, and replace the fallback file in the same build. SDK versions 4.1–4.3 reject the new file. If your Java code calls `AdaptyFlowView.showFlow`, add an argument to each call. An app on 4.0 needs the [v4.1 changes](migration-to-android-sdk-41) first.

:::warning
The fallback file format changed in 4.4, and the compiler can't detect an outdated file. Without a [new fallback file](#replace-the-fallback-file), every placement loses its fallback.
:::

## Replace the fallback file

To download the [fallback file](fallback-flows) again, in **[Placements](https://app.adapty.io/placements)**, click **Fallbacks** > **Download Android Fallback**. In the **Adapty SDK v4.4.0 and higher** row, click **Download**. Bundle the file in your app.

The downloaded file is named `android_4_4_0_fallback.json`. Give it the name of the file that your app loads, or update the name in the call that loads it:

- **`FileLocation.fromAsset`**: The file name, such as `android_fallback.json`.
- **`FileLocation.fromResId`**: The resource name, such as `android_fallback` in `R.raw.android_fallback`.

With an outdated file, `Adapty.setFallback` passes an `AdaptyError` to its callback, with the message "The fallback file version is not correct. Download a new one from the Adapty Dashboard." To verify the new file, run the app, and make sure that this callback receives no error. The callback is optional. Without it, set the [`Adapty.logLevel`](sdk-installation-android#logging) property to `AdaptyLogLevel.ERROR` or a more detailed level. Then make sure that Logcat doesn't show this error.

## Add an argument to showFlow calls in Java

In 4.4, `AdaptyFlowView.showFlow` has a new last parameter, `customElementsResolver`. Java code must pass every parameter of `showFlow`, so a call with eight arguments doesn't compile. Pass `null` as the last argument:

```diff showLineNumbers
  flowView.showFlow(flowConfiguration, products, eventListener, insets,
-         customAssets, tagResolver, timerResolver, observerModeHandler);
+         customAssets, tagResolver, timerResolver, observerModeHandler, null);
```

Kotlin calls to `showFlow` and all calls to `AdaptyUI.getFlowView` compile without changes.
