Copy a flow to change an existing flow design. Archive the flows you've stopped using.

<ZoomImage id="flow-copy-archive.webp" width="700px" alt="Flows list with the context menu open, showing Metrics, Edit, Copy, and Archive" />

## Copy a flow

1. Open the **Flows** page.
2. Open the context menu <Inline id="context.svg" alt="Context menu" /> next to the flow and select **Copy**. You can't copy an Archived flow.
3. The Flow Builder opens the copy as a new **Draft** with the name of the original plus a `_copy` suffix.

   The copy contains everything stored in the flow itself:

    - **Screens and elements**: Every screen, with its layout, elements, and interactions.
    - **Assigned products**: The connections between your product cards and your store products.
    - **Design**: Saved color and text styles, backgrounds, and dark mode values.
    - **Variables**: [Custom, element, and product variables](onboarding-variables).
    - **Localizations**: Every locale, with its translated text and media.
    - **Remote config**: Every locale's [JSON payload](customize-flow-with-remote-config).

   Anything stored outside the flow stays behind:

    - **Placements**: The copy belongs to no [placement](placements).
    - **A/B tests**: The copy joins no [A/B test](ab-tests).
    - **Metrics**: The copy starts with an empty [analytics history](flow-metrics).

4. Optional: [rename the flow](paywall-builder-templates#create-flow). Adapty allows duplicate flow names — a unique name helps to avoid confusion.
5. Save [or publish](builder-save-publish) your copy. A copy is always a **Draft** until published.
6. Add the copy to a [placement](placements) to show it to users.

To copy a single screen instead of the whole flow, see [Copy screens between flows](paywall-layout-and-products#copy-screens-between-flows).

### When to copy a flow

- **Serve a different audience**: One [placement](placements) can show a different flow to each [audience](add-audience-paywall-ab-test). Copy the flow once per audience, then tailor each copy. Adapty shows the first match in [priority order](change-audience-priority).
- **Keep metrics separate**: Adapty reports [flow metrics](flow-metrics) per flow. Republish an edited flow and its numbers cover both designs. A copy starts with an empty analytics history, so each design reports separately.
- **Create an A/B test variant**: Copy the flow, change one thing, and add both to the [A/B test](ab-tests). Everything else stays identical, so the result reflects only that change.
- **Avoid breaking older app versions**: [Custom fonts](using-custom-fonts-in-flow-builder) ship with your app, not with the flow. Swap the font in a copy, then serve that copy only for app versions that include it.
- **Branch for a different market or campaign**: Copy the flow, swap the products and images, and publish the copy for a different audience.

## Archive a flow

In the [**Flows**](https://app.adapty.io/flows) list, select **Archive** from the flow's context menu <Inline id="context.svg" alt="Context menu" />.

You can't archive a flow that an [A/B test](ab-tests) still uses. Adapty names the blocking tests in the error message. Archive those tests first.

Archiving a flow doesn't remove its metrics. You can't edit an archived flow.
