A custom tag is a [custom variable](onboarding-variables#custom-variables) with a value from your app. After you select **Value comes from outside the app** in a variable's settings, your app can set its value through the Adapty SDK. For example, a text element contains "Coins:" and a custom tag. If your app passes 120 for the tag, users see "Coins: 120".

Use custom tags to show:

- **Who the user is**: A username in a greeting, such as "Welcome back, DragonSlayer42!"
- **What the user has**: The number of days in a streak, or a player's level.
- **What your app calculates**: A discount for a larger pack, or a [BMI](ios-flow-custom-tags#example-show-a-bmi-from-onboarding-answers) based on the user's answers in an earlier flow.

## Values and fallbacks

Your app identifies each value by the name of its custom tag. The value is always a string. Adapty doesn't format or translate the string, so your app must make each value human-readable before it appears in the flow. For example, pass "1,250", not "1250.0".

## 1. Create a custom tag \{#create-a-custom-tag\}

1. Open the <Inline id="variables.svg" alt="Variables" /> Variables panel in the flow builder.
2. Add a new variable — click <Inline id="plus.svg" alt="Plus" />.
3. Configure the variable **Name**. Your app's code must reference it exactly, including letter case.
   - **Characters**: Use Latin letters (A–Z and a–z), digits, `_`, and `-`. To put the tag in a group, start its name with the group and a dot, such as `user.streak`.
   - **Reserved names**: In any letter case, don't use a reserved name, such as `PRICE`, `TITLE`, `VALUE`, or one that starts with `TIMER_`.
   - **Uniqueness**: Use a name that's unique within the flow.
4. (Optional) To distinguish between different variables, fill in the **Description** field. When you hover over the variable's name in the builder, you'll see the description.
5. In the **Initial value** field, enter the fallback that users see when your app passes no value:
   - **A word that fits every user**: For the `username` tag in a greeting, enter `friend`. Unauthenticated users will see "Welcome back, friend!". Note that the initial value cannot be localized.
   - **A dash for a balance or a count**: To avoid displaying an incorrect balance value for unauthenticated users, enter a dash (`—`).

6. (**String** variables only) Select the **Value comes from outside the app** checkbox. This action is irreversible and locks in the **Value Type**.
7. Click **Create variable**.

<ZoomImage id="flow-custom-tag-create.webp" width="500px" alt="Create variable form with a name, a description, the String value type, and an initial value" />

Variables are flow-specific. To use a custom tag in another flow, create one there with the same name.

### Replace a variable with a custom tag

You can only select the **Value comes from outside the app** checkbox when you create a variable. To show your app's value in place of a regular custom variable, such as one from a [converted paywall](convert-paywall-to-flow), replace the variable with a custom tag:

1. Delete the variable and all its references in the flow.
2. [Create a custom tag](#create-a-custom-tag) with the same name.
3. [Insert the custom tag](#add-a-custom-tag-to-a-text-element) into each text element that used the variable.

## 2. Add a custom tag to a text element \{#add-a-custom-tag-to-a-text-element\}

Select the text element. In the **Content** section, click <Inline id="variables.svg" alt="Variables" /> **Add variable**, and select the tag on the **Custom** tab.

<ZoomImage id="flow-custom-tag-full-name.webp" width="500px" alt="Custom tab of the Add variable dropdown with the streak tag in the user group" />

You can insert custom tags into every branch of [conditional text](onboarding-text#add-conditional-text), but you can't select them in its **if** conditions.

## Limitations

- **Text elements only**: You can only insert custom tags into text elements. You can't insert them into the following:
  - **Set variable** actions
  - **Show alert** actions
  - **Open URL** actions
  - Input placeholders
- **No conditions on custom tags**: You can't select a custom tag in a condition or in conditional visibility. To decide which sentence, elements, and screens users see based on a value from your app:
  - **Sentence**: Build the sentence in your app's code, and pass it as the tag's value. For example, for a `coins_message` tag, pass "You have 120 coins" to players with coins, and "Get your first coins" to the rest.
  - **Elements and screens**: [Set the value as a custom attribute](setting-user-attributes). Then show a separate flow to an [audience](audience) built from that attribute.
- **No SDK method to update the values in an open flow**: To show a result based on what users enter in a flow, pass the result to the next flow, as in the [BMI example](ios-flow-custom-tags#example-show-a-bmi-from-onboarding-answers).
