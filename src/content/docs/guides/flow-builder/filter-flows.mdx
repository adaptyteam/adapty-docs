The [**Flows**](https://app.adapty.io/flows) page lists every flow in your app with its [status](#filter-by-status) and main [metrics](flow-metrics). Click a flow to open its full [metrics](flow-metrics), or, if you hold the **Developer** role — the [Flow Builder](adapty-flow-builder).

<ZoomImage id="flow-list.webp" width="700px" alt="Flows page with the search box, the All states filter, sortable Flow name and Status columns, and an open context menu" />

## Search by name

**Search by flow name** matches any part of a flow name. It doesn't search placements, products, or screen content.

## Filter by status

Open the **All states** filter above the list, select one or more statuses, and click **Apply**.

- **Draft**: Never published — users don't see it.
- **Publishing**: Adapty is publishing the flow right now.
- **Published**: The latest saved version is live, no unpublished edits exist.
- **Failed**: The last publishing attempt failed.
- **Dirty**: Published earlier. Contains saved edits that haven't gone live yet.
- **Archived**: Out of use, and not editable. See [Archive flows](archive-flows).

[Save & publish flows](builder-save-publish#flow-status) describes how a flow moves between these statuses.

<ZoomImage id="flows-filter-by-state.webp" width="300px" alt="All states filter open, with a checkbox for each flow status and an Apply button" />

## Filter by placement

Open the **All placements** filter above the list, select one or more [placements](placements), and click **Apply**. This filter appears when you have at least one flow assigned to a placement.

<ZoomImage id="flows-filter-by-placement.webp" width="300px" alt="All placements filter open, listing two placements with checkboxes and an Apply button" />

## Sort

You can sort by **Flow name** or **Status**. The metric columns aren't sortable. By default, published flows come first and archived flows last.

## Flow actions

Open the context menu <Inline id="context.svg" alt="Context menu" /> in a flow's row.

| Action | What it does |
| :----- | :----------- |
| **Metrics** | Opens the flow's [metrics](flow-metrics). |
| **Edit** | Opens the flow in the [Flow Builder](adapty-flow-builder). |
| **Copy** | [Copies the flow](copy-flows) as a new Draft. |
| **Archive** | [Archives the flow](archive-flows). |

The menu for an archived flow shows **Metrics** only.
