Follow this recipe to display the user's progress as a Lottie animation — for example, a ring that fills up to indicate their daily streak. We will use a [custom element](flow-custom-elements) to render a native view with a Lottie player.

<DocVideo id="custom-element-lottie-demo.mp4" width="300px" alt="The finished flow: the user taps See my streak, and on the next screen, the ring fills up to 4 of 7 days." />

## Before you start

- Update your app to Adapty iOS SDK 4.4 or later. Earlier versions do not support custom elements — they will always render [fallback content](flow-custom-elements#set-fallback-content).
- Set up your app to [fetch](get-pb-paywalls) and [display](ios-present-paywalls) flows.
- Add Lottie to your app with Swift Package Manager, from `https://github.com/airbnb/lottie-spm.git`.
- Prepare a Lottie animation in `.json` format, or download the sample [`streak_ring.json`](https://raw.githubusercontent.com/adaptyteam/adapty-docs/refs/heads/main/Downloads/streak_ring.json). The app plays the animation from the start and stops it in proportion to the progress, such as halfway through for 50%. To show the exact progress, the animation needs:
  - No progress on its first frame, and full progress on its last frame.
  - A steady speed, with no easing. If the animation starts slowly and then speeds up, it shows less than half of the progress halfway through.

## 1. Add the custom element to the screen

In the Flow & Paywall Builder, [add a custom element](flow-custom-elements#add-and-configure) to a flow screen, and set it up for the animation:

- **Type**: `lottie_animation`.
- **ID**: `streak_ring`. In this recipe, the ID is also the name of the animation file.
- **Height**: **Fixed**. The animation scales to fit the custom element.

Inside the custom element, add an [**Image**](custom-media#image) with a still picture of the ring. Users see it as the [fallback](flow-custom-elements#set-fallback-content) when their version of your app doesn't play the animation.

## 2. Add the animation file to your app

In Xcode, add the animation file to your app target. The file name without `.json` must match the ID of the custom element, such as `streak_ring.json` for `streak_ring`.

## 3. Match the animation to the custom element

Write a [resolver](ios-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views) that returns a `LottieView` for the `lottie_animation` Type and the `streak_ring` ID. Store the progress in a property of the resolver, from 0 for an empty ring to 1 for a full one:

<Tabs groupId="current-os" queryString>
<TabItem value="ios" label="iOS" default>

```swift showLineNumbers title="Swift"
import AdaptyUIBuilder
import Lottie
import SwiftUI

struct StreakResolver: AdaptyUICustomElementsResolver {
    let streakProgress: AnimationProgressTime // from 0 to 1

    func view(
        forType type: String,
        id: String,
        context: AdaptyUICustomElementContext
    ) -> AnyView? {
        guard type == "lottie_animation", id == "streak_ring",
              let animation = LottieAnimation.named(id) else {
            return nil // another custom element, or no file: show the fallback
        }
        return AnyView(
            LottieView(animation: animation)
                .resizable()
                .playing(.fromProgress(0, toProgress: streakProgress, loopMode: .playOnce))
        )
    }
}
```

</TabItem>
</Tabs>

`.playing(.fromProgress(0, toProgress: streakProgress, loopMode: .playOnce))` fills the ring once, from empty up to `streakProgress`. If the app bundle has no file for the ID, the resolver returns `nil`, and users see the fallback.

## 4. Display the animation in the custom element

Attach the resolver to the flow when you fetch its configuration. Create the resolver with the progress at that moment, such as the current streak out of a goal of 7 days:

<Tabs groupId="current-os" queryString>
<TabItem value="ios" label="iOS" default>

```swift showLineNumbers title="Swift"
// currentStreak comes from your app; 7 days fill the ring
let streakProgress = min(AnimationProgressTime(currentStreak) / 7, 1)

do {
    let flowConfiguration = try await AdaptyUI.getFlowConfiguration(
        forFlow: flow,
        customElementsResolver: StreakResolver(streakProgress: streakProgress)
    )
    // present the flow
} catch {
    // handle the error
}
```

</TabItem>
</Tabs>

If your app also sets an [app-wide resolver](ios-flow-custom-elements#display-the-same-views-to-all-users), this resolver replaces it in this flow. To keep the app-wide views for other custom elements in the flow, [call the app-wide resolver](ios-flow-custom-elements#display-user-specific-data-such-as-a-daily-streak) for their Types and IDs.

## 5. Test on a device

The builder canvas shows the fallback, never the animation. To see the animation:

1. [Publish the flow](builder-save-publish). To see the latest published version instead of a cached one, register the device as a [test device](test-devices).
2. Run a build of your app that includes the resolver. Open the screen at a few progress values, such as 0, 0.5, and 1, and verify that the ring fills up to each value.
3. To see the fallback, remove the animation file from the build, and open the screen again.

To find out why the fallback appears instead of the animation, follow the instructions in the [Test on a device](ios-flow-custom-elements#test-on-a-device) section of the iOS guide.
