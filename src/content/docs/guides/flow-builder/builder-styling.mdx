The **Design** tab in the right panel controls each element's visual appearance. The available properties depend on the element type, but most elements share common styling options.

:::link
For sizing, spacing, and positioning, see [Layout and positioning](manage-paywall-ui-elements).
:::

## Visibility

<ZoomImage id="flow-builder/visibility.webp" width="300px" float="right" alt="Visibility toggle" />

The **Visibility** toggle determines whether the element appears on screen.

* <Inline id="eye.svg" alt="Show" /> **Show** (default): The element is visible when the screen opens.
* <Inline id="visibility-conditional.svg" alt="Conditional" /> **Conditional**: The element is visible only when specific conditions are met. See [Conditional visibility](onboarding-element-visibility) for more information.
* <Inline id="visibility-hide.svg" alt="Hide" /> **Hide**: The element is hidden until a [**Show element** action](flow-show-hide-animations#show-or-hide-an-element) reveals it. Use this to temporarily remove an element from the flow without deleting it.

## Fill

<ZoomImage id="single-layer-color-fill.webp" width="300px" float="right" alt="Screen settings with one solid color layer in the Fill section, and the color picker on the Custom tab" />

The **Fill** section sets the background of an element. To fill the entire screen, set the [screen background](paywall-head-picture) instead.

A fill consists of one or more layers. Each layer has one of the following types:

- **Solid color** <Inline id="fill-solid.svg" alt="Solid color" />: Use the color picker or enter a hex value. Adjust the **opacity** to make the background semi-transparent.
- **Gradient** <Inline id="fill-gradient.svg" alt="Gradient" />: Two or more color stops. Drag the stops to adjust the transition, and set the angle with the **Direction** slider. To change a stop, edit its row under **Stops**. To add a stop, click the gradient bar or <Inline id="plus.svg" alt="Add gradient stop" /> next to **Stops**. The slider in the layer row changes the opacity of all stops at once.
- **Image** <Inline id="fill-image.svg" alt="Image" /> or **Video** <Inline id="fill-video.svg" alt="Video" />: An [image or video](custom-media) as the background.

<ZoomImage id="gradient-picker.webp" width="300px" alt="The gradient picker with three stops, the Direction slider, and the Stops list" />

To manage the layers:

- To add a layer, click <Inline id="plus.svg" alt="Plus" /> next to **Fill**.
- To change the type of a layer, click its swatch and select a type.
- To change the order of the layers, drag their rows.
- To remove a layer, click <Inline id="close.svg" alt="Close" /> in its row.

The top layer covers the ones below it, so a semi-transparent layer above an image [tints it](paywall-head-picture#tint-a-background). Input fields and date/time pickers only show the bottom layer.

To reuse a layer in other elements or give it a dark version, [save it as a color style](builder-reusable-styles#create-a-color-style). To reuse an image together with its tint, [create a single, multi-layer style](builder-reusable-styles#multi-layer-styles).

## Border

<ZoomImage id="flow-builder/border.webp" width="300px" float="right" alt="Border settings" />

Borders are off by default. Click the <Inline id="plus.svg" alt="Plus" /> next to **Border** in the right panel to add one. To remove a border, click the <Inline id="close.svg" alt="Close" /> next to the **Border** heading.

When a border is present, configure:

- **Color**: Use the color picker or enter a hex value. To apply a [color style](builder-reusable-styles#color-styles) instead, select it from the **Styles** tab. A border ignores the [image and video layers](builder-reusable-styles#multi-layer-styles) of a style.
- **Width**: The border thickness in pixels.

:::tip
To give a border a gradient, apply a [color style](builder-reusable-styles#color-styles) with a gradient layer to its **Color**.
:::

## Corners

<ZoomImage id="flow-builder/corners.webp" width="300px" float="right" alt="Corners settings" />

The **Corners** section controls the border radius (rounded corners).

* **Radius slider**: Set the same radius for all four corners
* **Per-corner toggle** <Inline id="per-corner.svg" alt="Per Corner" />: Enable to set a different radius for each individual corner

## Effects

<ZoomImage id="flow-builder/effects.webp" width="300px" float="right" alt="Effects settings" />

Click the plus button <Inline id="plus.svg" alt="Plus" /> next to **Effects** to add one or more visual effects:

* **Drop shadow**: A shadow behind the element
* **Inner shadow**: A shadow inside the element's boundaries
* **Layer blur**: Blurs the element and its children

You can stack multiple effects on the same element. Toggle its visibility <Inline id="eye.svg" alt="Show" /> to temporarily disable an effect.

## Animation

:::tip
When users move between screens, the flow can display [transition animations](flow-screen-transitions).

To make an element fade, rise, or pop as it appears or disappears, [select an animation in a **Show element** or **Hide element** action](flow-show-hide-animations#animate-an-element-as-it-appears-or-disappears).
:::

<ZoomImage id="flow-builder/animation.webp" width="300px" float="right" alt="Animation settings for a Pulse animation: Type, Scale amount, Duration, Delay between loops, Show after delay, and Easing" />

Click the <Inline id="plus.svg" alt="Plus" /> button next to **Animation** to add an animated effect. The builder adds a **Pulse** animation, which rhythmically scales the element up and down to draw attention. To use a different effect, choose it in **Type**.

<ZoomImage id="flow-builder/animation-types.webp" width="300px" alt="Type dropdown open in the Animation settings, listing None, Pulse, Radial fill waves, Radial outline waves, Glow, Shake, Wiggle, Bounce, and Breathe" />

### Animation types

Each type has its own settings. The [timing settings](#timing-settings) are the same for every type.

| Type | What it does | Settings |
|------|--------------|----------|
| Pulse | The element scales up and back down. | **Scale amount** (%): how much the element grows. |
| Radial fill waves | A filled copy of the element's shape grows out from behind it and fades. | **Scale amount** (%): how much each wave grows relative to the element.<br/>**Wave size** (px): how far each wave reaches past the element's edge.<br/>**Wave color**.<br/>**Button pulse**: also scales the element with every wave, by **Pulse amount** (%). |
| Radial outline waves | Same as **Radial fill waves**, but each wave is an outline. | Same as **Radial fill waves**. |
| Glow | A soft halo swells around the element and fades. | **Glow size** (px): how far the halo reaches at its brightest.<br/>**Glow color**. |
| Shake | The element moves left and right. | **Distance** (px): how far the element moves to each side. |
| Wiggle | The element tilts left and right. | **Angle** (°): how far the element tilts to each side. |
| Bounce | The element hops up and comes back down. | **Height** (px): how high the element hops. |
| Breathe | The element fades and comes back. | **Fade amount** (%): how much the element fades at its faintest. |
| Color shift | The element's fill turns into another color and back. | **Shift color**. |
| Border flash | A border lights up on the element's edge and fades. While it plays, it replaces the element's own border. | **Flash width** (px): how wide the border is at its brightest. It grows inward from the edge.<br/>**Flash color**. |
| Shimmer | A light band sweeps across the element's fill. | **Shimmer width** (%): how wide the band is, as a share of the element.<br/>**Shimmer angle** (°): the direction of the sweep, read like a gradient's angle. 90° goes left to right.<br/>**Shimmer color**. |

Some types depend on the element's layout or fill. The builder shows a note in the **Animation** settings when the element doesn't meet these conditions, and the flow publishes without the animation:

- **Radial fill waves** and **Radial outline waves**: The element needs a fixed width and height and no margin.
- **Color shift**: The element needs a solid color fill or no fill.
- **Shimmer**: The element needs a solid color fill.

### Timing settings

| Parameter | Description |
|-----------|-------------|
| Duration (ms) | Length of a single animation cycle |
| Delay between loops (ms) | Pause between repetitions |
| Show after delay (ms) | Pause before the first cycle |
| Easing | How the animation speeds up and slows down: **Linear**, **Ease In**, **Ease Out**, **Ease In Out**, **Elastic** (overshoots and settles), or **Bounce** (lands with a few bounces). A new Pulse uses a preset curve, shown as **Custom**. |

<ZoomImage id="flow-builder/animation-demo.webp" width="600px" alt="Pulse animation in action" />

### Preview the animation

The builder shows static screens by default — animations stay still until you turn them on. Two ways:

- Click the **Toggle animations** <Inline id="fill-video.svg" alt="Toggle animations" /> button above the device preview. It turns the screen's animations on or off — once on, they run continuously until you click again. The button only appears when the active screen contains at least one animation.
- Open the screen's [context menu](paywall-layout-and-products#screen-actions) (the three-dot icon next to the screen layer) and choose **Play Animation**.

## Typography properties (text elements)

<ZoomImage id="flow-builder/typography.webp" width="300px" float="right" alt="Typography settings" />

Text elements display a **Typography** section with the following controls:

### Font

:::link
See also: [Custom fonts](using-custom-fonts-in-flow-builder)
:::

Click the font dropdown <Inline id="font-select.svg" alt="Font select" /> to open the font picker. It has two tabs:

* **Styles**: Lists your project's saved [text styles](builder-reusable-styles#text-styles). Select a style to apply its full typography settings at once.
* **Fonts**: Lists all available font families. Search or scroll to find the one you need. Built-in fonts can **render differently across devices** — for consistent rendering, upload a [custom font](using-custom-fonts-in-flow-builder).

To save the current typography settings as a new [text style](builder-reusable-styles#text-styles), click <Inline id="plus.svg" alt="Create text style" /> next to the tabs. The element then uses the new style.

### Size and weight

:::warning
**Bold** and **Italic** have no effect on a [custom font](using-custom-fonts-in-flow-builder) unless its family includes a bold or italic face. [Upload the correct face](using-custom-fonts-in-flow-builder#manage-a-custom-font) yourself.
:::

* **Weight**: Select a font weight from the dropdown
* **Size**: Select a size from the dropdown or type a custom value

:::note
Text size renders differently per platform: Android scales flow text with the system font size setting, while iOS renders the exact size you set. Test your layout on Android with an increased system font size — text that fits on iOS can wrap or overflow there.
:::

### Color

Click the color swatch, and enter a hex value or use the palette. To apply a [color style](builder-reusable-styles#color-styles) instead, select it from the **Styles** tab. Text only shows the [solid color layers](builder-reusable-styles#multi-layer-styles) of a style.

### Alignment

Two groups of alignment controls:

* **Horizontal**: Left <Inline id="align-left.svg" alt="Align left" />, Center <Inline id="align-center.svg" alt="Align center" />, or Right <Inline id="align-right.svg" alt="Align right" />
* **Vertical**: Top <Inline id="align-top.svg" alt="Align top" />, Middle <Inline id="align-middle.svg" alt="Align middle" />, or Bottom <Inline id="align-bottom.svg" alt="Align bottom" />

### Decoration

* **None** <Inline id="border-none.svg" alt="None" />: No decoration (default)
* **Underline** <Inline id="underline.svg" alt="Underline" />: Adds an underline to the text
* **Strikethrough** <Inline id="strikethrough.svg" alt="Strikethrough" />: Adds a strikethrough line

### Limit lines and auto shrink

To keep text from breaking the layout, turn on **Limit lines** and set **Max Lines**. Text past that number of lines is cut off with an ellipsis (…).

To fit long text instead of cutting it off, turn on **Auto shrink**. The text gets smaller until it fits its line limit or its fixed height, in every locale. Use it where a translation runs longer than the original, such as a product card title or a button label.

<ZoomImage id="flow-builder/text-auto-shrink.webp" width="700px" alt="Flow & Paywall Builder in German: the yearly product card title fits on one line beside the discount badge, with Limit lines on, Max Lines set to 1, and Auto shrink on in the Typography section" />

- **Auto shrink** is available when **Limit lines** is on, or when the text has a **Fixed** height and a **Fixed size** layout.
- Text shrinks to no less than 10% of its font size. Text that still doesn't fit is cut off.
- The font size you set doesn't change. The preview shows the size the text has on a device.

:::tip
Small text is hard to read. Shorten a translation that is much longer than the original, and leave **Auto shrink** for the rest.
:::

:::note
When you select a text element, an **inline toolbar** also appears above it on the canvas. This toolbar offers quick access to font, weight, size, and alignment without scrolling through the right panel.
:::

## State-specific settings (interactive elements)

<ZoomImage id="flow-builder/states.webp" width="300px" alt="State selection" float="right" />

Interactive elements support multiple visual states. When you select such an element, a **States** section appears in the right panel. Switch between states to configure different visual properties for each.

Each state can override any visual property — fill, border, typography color, opacity, and more.

### Selectable states

:::link
Main article: [Selectable elements](flow-selectable-elements)
:::

Elements that belong to a selectable group (quiz options, products, tabs, toggles and checkboxes) offer two states by default:

* **Default**: The element's normal appearance
* **Selected**: The appearance when the user has selected this option. Override properties like fill, border color, and text color to highlight the active choice

To style a selectable element when it's not interactive, add a third state manually. Open **States settings** <Inline id="settings.svg" alt="Settings" /> and add a **Disabled state**.

The **Disabled** state is condition-driven. Select it and click **Set conditions** <Inline id="visibility-conditional.svg" alt="set conditions" /> to define when the element becomes disabled at runtime, for example when a required field is empty.

### Input states

Input fields offer additional states:

* **Default**: Normal, unfocused appearance
* **Active**: The field is focused and ready for input
* **Invalid**: The entered value fails validation
* **Disabled**: The field is not interactive

<ZoomImage id="flow-builder/state-demo.webp" width="600px" alt="Switching states and applying visual overrides" />

### Other state-bearing elements

A few elements expose state-specific styling outside the standard **Default / Selected / Disabled** pattern:

- **[Progress indicator steps](builder-loaders-and-progress-bars#step-states)** — three states per step: **Completed**, **Current**, and **Upcoming**.
- **[Carousel dots](builder-containers#dots)** — two color variants: **Color** for inactive dots and **Active Color** for the dot of the current slide.
