The Adapty plugin for Figma turns frames from your design file into a flow. Select frames in Figma, send them to Adapty, and the import creates a draft flow you edit in the flow builder like any other.

An import gives you a starting point, not a finished flow. Layout, text, and images come across; fonts and interactions need your attention afterwards.

:::note
The Figma plugin is in early access. It's not available in the Figma Community plugin repository. You need to download it manually, and [reinstall updates by hand](#update-the-plugin).
:::

## How the import works

The plugin reads the frames you select and uploads them to Adapty, which converts them into the screens of a new draft flow. The plugin never changes your Figma file — it reads your frames and leaves them as they are. Screen layout, text, images, icons, and colors come across, along with the structure of each screen.

### Import limitations

An import reproduces the look of your design, not its behavior. Expect to fix these in the builder:

- **Fonts**: Imported text keeps its size, weight, and color, but can arrive with no typeface assigned — the font control reads **Select font** until you choose one. A custom font reaches users' devices only when its file ships in your app bundle, which is developer work. See [Custom fonts](using-custom-fonts-in-flow-builder).
- **Products and purchases**: Pricing cards import as ordinary frames, so the flow starts with no products at all. Add a Product Card element and assign your products to it. See [Set up purchases](paywall-product-block).
- **Navigation and actions**: An imported screen has nothing wired, even when the Figma prototype links every frame. Set up [navigation](onboarding-navigation-branching) and [actions](onboarding-actions) yourself.
- **Interactive elements**: A countdown, quiz, or similar element imports as plain text or an image. Rebuild it with the matching element, such as a [countdown timer](flow-timer) or a [quiz](onboarding-quizzes).
- **Backgrounds**: A background image can import as an ordinary image element that covers the rest of the screen. Move it behind your content, or set it as the screen's [background](paywall-head-picture).
- **Visual detail**: Gradients, shadows, and text that mixes several styles in one block often need manual adjustment.

Adapty may narrow these gaps in future releases.

One export includes at most **50 screens** and **20 MB** of design data. Image resolution drives that size most, so a large export gets smaller when you set **Image resolution** to 1×.

Each export produces a single flow. To import the same design a second time, export it from Figma again.

An import link stays valid for one hour after the export. Finish the import in one sitting, or export the design again.

## Before you start

To import a design, you need:

- **The Figma desktop app**: Custom Figma plugins only work in the desktop app, not in a browser.
- **Edit access to a design file**: The plugin can't run on a file you can only view. Your own drafts work well. FigJam boards and Figma Slides aren't supported.
- **An app in Adapty** with flow editing privileges: The import creates the flow inside one of your apps. Make sure you can edit the flows inside the target Adapty app.

## 1. Install the plugin

To install the plugin:

1. Download [the plugin archive](PLUGIN_DOWNLOAD_URL) and unzip it.
2. Move the unzipped folder somewhere permanent, such as **Documents**. Figma reads the plugin from this folder on every run. The plugin stops working if the folder moves or is deleted.
3. In Figma, go to **Plugins** > **Development** > **Import plugin from manifest**.
4. Select `manifest.json` inside the unzipped folder.

The plugin now appears under **Plugins** > **Development** >  **Import to Adapty**, and stays there until you remove it.

### Update the plugin

To move to a new version:

1. Under **Plugins** > **Development**, remove **Import to Adapty**.
2. Replace the old folder with the newly unzipped download.
3. Import the new `manifest.json` the same way you did at install.

Figma reads the plugin code from your folder on every run, but caches `manifest.json` from the moment you import it. A new download on its own can therefore leave the plugin on its old settings.

## 2. Send your design to Adapty

To send screens to Adapty:

1. In Figma, select the frames to import. Select several at once to send a whole sequence of screens.
2. Go to **Plugins** > **Development** > **Import to Adapty**.
3. Review the selection the plugin lists, then click **Export to Adapty**.
4. Click **Open in Adapty**.

<ZoomImage id="launch-figma-export.webp" width="700px" alt="Figma's Plugins menu open on Development with Import to Adapty highlighted, and a section selected on the canvas" />

The plugin names your selection and counts the screens it will send, so you can confirm the count before you export.

<ZoomImage id="figma-export-wizard.webp" width="700px" alt="The Import to Adapty panel showing the selected Mindfulness section and an Export 7 screens to Adapty button" />

Once the upload finishes, the plugin shows a **Done** screen. **Open in Adapty** opens the import in your browser. **Copy link** puts the same link on your clipboard, which helps when you use Adapty in another browser or profile.

### How frames become screens

What you select decides how many screens you get:

- **Several frames**: Each frame becomes its own screen.
- **A section**: Each frame inside the section becomes a screen.
- **A single frame**: The whole frame becomes one screen, even when it contains other frames. To import those inner frames as separate screens instead, turn on **Split into separate screens**.

Screens follow their position on the Figma canvas, not the order you clicked them. Select individual frames or a section rather than a whole page. Otherwise you import every other frame on that page too.

### Export settings

To change what the export includes, click **Customize export**:

- **Export images**: Includes image and photo assets. On by default.
- **Image resolution**: Exports images at 1×, 2×, or 3×. Higher resolution increases the sharpness and file size. 2× by default.
- **Split into separate screens**: Imports each frame inside your selection as its own screen. Off by default.

<ZoomImage id="figma-export-settings.webp" width="400px" alt="The Export settings panel with the Export images toggle on, Image resolution set to 2x, and Split into separate screens off" />

## 3. Finish the import in Adapty

**Open in Adapty** opens a browser tab in your Adapty dashboard. Conversion itself runs on Adapty's servers — the tab shows progress and creates the flow at the end.

1. Select the app this flow belongs to. Conversion starts as soon as you choose.
2. Keep the tab open until the import finishes. If you close it early, open the same link again to resume.

<ZoomImage id="figma-import-select-app.webp" width="600px" alt="The Figma import page in Adapty asking which app the flow will be imported to, with a list of apps to choose from" />

Adapty then converts the design and reports how far along it is.

<ZoomImage id="figma-import-progress.webp" width="600px" alt="The Figma import page showing the Importing your design message and a progress bar" />

The finished flow opens in the flow builder as a draft, named after the Figma file it came from. Adapty tells you when parts of the design need a second look.

## Troubleshooting

### Export errors

| Message | What to do |
|---|---|
| Too many screens to export | Split your selection into smaller batches of 50 screens or fewer. |
| Export data is too large | Lower **Image resolution**, or reduce the number of layers in your screens. |
| This frame is too large to export | Export a smaller section of the design. |
| Upload didn't complete | Your design changed while it uploaded. Export it again. |
| This import link has expired | An import link is valid for one hour. Export the design again from Figma. |
| This design was already imported | That export already produced a flow. Export the design again from Figma. |

### After an import

| What you see | Cause and fix |
|---|---|
| A screen looks washed out, as though a haze covers it | A background image was imported as an ordinary element on top of your content. Move it behind the rest of the screen. |
| The **Products** panel reports no products in the flow | Pricing cards import as ordinary frames. Add a Product Card element and assign your products to it. |
| A countdown shows a fixed time and never counts down | The countdown imported as text. Replace it with a [countdown timer](flow-timer). |
| The font control reads **Select font** | The import left this text without a typeface. Pick one from the dropdown, or [upload a font file](using-custom-fonts-in-flow-builder). |

## Next steps

The imported flow is a draft, unavailable to users. Improve the flow in the builder and follow the steps below to ship it:

1. [Save and publish the flow](builder-save-publish).
2. [Preview the flow on a real device](paywall-device-compatibility-preview).
3. Create a [flow placement](create-placement) and add the flow to it.
4. Fetch that placement in your app with Adapty SDK v4.0 or later. Earlier SDK versions can't render flows.
