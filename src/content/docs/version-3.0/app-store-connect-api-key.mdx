Adapty uses the App Store Connect API key to work with your products in App Store Connect:

- [Create products](create-product#create-product-and-push-to-store) and subscription groups.
- Find your existing products by ID when you add a product in Adapty.
- Show the App Store status of each product in Adapty.
- Import prices daily, and export the price changes you make in Adapty.
- Suggest products for Switch Plan in [Retention Messaging](retention-messaging-setup).

Adapty only changes App Store Connect when you act in Adapty, such as when you create a product or change prices. To show statuses and import prices, it only reads from App Store Connect.

Generate the key on the **Team Keys** tab in App Store Connect, then connect it in **App settings** in Adapty. If the key stops working or needs a change, [replace it](#replace-the-key).

The App Store Connect API key is different from the [In-App Purchase key](generate-in-app-purchase-key), though App Store Connect labels the IDs of both keys **Issuer ID** and **Key ID**.

To enter all the credentials in **App settings** > **iOS SDK** at once, follow [Configure App Store integration](app-store-connection-configuration).

## Replace the key

If the key stops working or needs a different **Access** setting, connect a new key in Adapty before you revoke the old one.

Without a working key, Adapty can't:

- Create products.
- Find your existing products by ID.
- Sync product status and prices.

A key that stops working still shows as connected in Adapty. The signs are [products with no App Store status and an empty **App Store Product ID** dropdown](troubleshoot-app-store-integration#products-dont-appear-or-show-no-app-store-status).

Adapty doesn't show the Key ID of a connected key. If you don't know which key Adapty uses, replace it with a new key.

When your app moves to another Apple developer account, [connect a team key from the new owner](transfer-apps#app-store-ios-transfer).

To replace the key:

1. [Generate a new team key](#generate-a-team-key-in-app-store-connect).
2. In Adapty, go to [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). In the **App Store Connect API key** section, click **Edit**. [Enter the values of the new key](#connect-the-key-in-adapty), and click **Save changes**.
3. One team key serves every app of your App Store Connect team. If other apps of your team use Adapty, connect the new key for them too. Replace the old key on any of your servers that use it.
4. A revoked key stops working in every app that uses it, and you can't restore it. If you know which key the new one replaces, go to App Store Connect and revoke that key.
