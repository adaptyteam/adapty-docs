Adapty uses the In-App Purchase key to validate purchases in your app and to sign [promotional offers](offers). Generate the key in App Store Connect, then enter it in two sections of **App settings** in Adapty. If the key stops working or needs a change, [replace it](#replace-the-key).

The In-App Purchase key is different from the [App Store Connect API key](app-store-connect-api-key), though App Store Connect labels the IDs of both keys **Issuer ID** and **Key ID**.

To enter all the credentials in **App settings** > **iOS SDK** at once, follow [Configure App Store integration](app-store-connection-configuration).

## Replace the key

If the key stops working or needs a change, save a new key in Adapty before you revoke the old one.

When the key stops working:

- Purchases in your app unlock no access, and the app receives no error.
- Users can't redeem promotional offers.
- [Refund Saver](refund-saver) can't answer consumption requests.
- Adapty shows no warning, and the status in the **App Store server notifications** section stays **Active**.

When your app moves to another Apple developer account, [replace the key with one from the team of the new owner](transfer-apps#app-store-ios-transfer).

To replace the key:

1. In Adapty, go to [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). To identify the key that Adapty uses now, in the **In-app purchase API (StoreKit 2)** section, note the value in the **Key ID** field.
2. [Generate a new key](#generate-the-key-in-app-store-connect).
3. [Add the new key to Adapty](#add-the-key-to-adapty) in the **In-app purchase API (StoreKit 2)** and **App Store promotional offers** sections, and click **Save**.
4. One key serves every app of your App Store Connect team. If other Adapty apps use the Key ID from step 1, add the new key to them too. Replace the old key on any of your servers that use it.
5. A revoked key stops working in every app that uses it, and you can't restore it. In App Store Connect, revoke the old key: the active key with the Key ID from step 1.

Users who bought while Adapty had no working key get access when they [restore purchases](troubleshoot-app-store-integration#a-purchase-succeeds-but-the-customer-loses-access).
