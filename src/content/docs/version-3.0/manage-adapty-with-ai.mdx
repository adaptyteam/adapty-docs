Adapty works with AI coding tools and agents. Use them to integrate the SDK, ask about your analytics, or look up Adapty docs without leaving your editor. This page lists what's available and who each tool is for.

## Connect an AI assistant to your Adapty account

The [Adapty MCP server](adapty-mcp) connects the Claude app, Claude Code, Codex, or another MCP client to your Adapty account. Your assistant can then read analytics, set up products and placements, publish flows, and run A/B tests from a chat, signed in as you. No API key is needed, and there is nothing to install.

## Integrate the Adapty SDK with AI

Two ways to add the Adapty SDK to your app with an AI coding tool. Both work with Cursor, Claude, and other AI assistants.

### Skill-based integration

The Adapty SDK integration skill runs the whole integration from your AI coding tool in one command. Use it when you want a guided, automated setup.

Choose your platform: [iOS](adapty-sdk-integration-skill) · [Android](adapty-sdk-integration-skill-android) · [React Native](adapty-sdk-integration-skill-react-native) · [Flutter](adapty-sdk-integration-skill-flutter) · [Unity](adapty-sdk-integration-skill-unity) · [Kotlin Multiplatform](adapty-sdk-integration-skill-kmp) · [Capacitor](adapty-sdk-integration-skill-capacitor)

### Step-by-step integration

Walk your AI tool through the integration stage by stage, feeding it the right docs in order. Use it when you want to review each step as you go.

## Migrate from RevenueCat with AI

Your coding agent moves your RevenueCat catalog and paywall designs to a new Adapty app with the Adapty CLI, then replaces the RevenueCat SDK in your app code with the IDs that catalog got in Adapty. See [Migration from RevenueCat](migration-from-revenuecat).

## Build and edit flows with an AI coding tool

The [flow-generator skill](flow-generator-skill) edits your Adapty flows from the terminal — add a locale, rewrite copy, add or remove screens, wire branching, or author a paywall from a description. It previews and validates every change locally, then saves a draft for you to publish.

Before you publish, the [flow-audit skill](flow-audit-skill) reads the same flow and checks whether it's ready for production — triggers, store compliance, products, and localization — and ends in a pass/fail verdict.

If your app already runs on paywalls, the [migrate-placements skill](migrate-placements-skill) moves it over: it inventories your paywall placements, groups them by the paywall each one serves, and creates a flow placement for each one alongside the original.

## Manage Adapty from the command line

The [Adapty Developer CLI](developer-cli-quickstart) lets you manage your Adapty entities — apps, access levels, products, paywalls, flows, and placements — from the terminal, without opening the dashboard. Because it's a command-line tool, your AI coding agent can run it directly.

## Find what to test next

The [growth-advisor skill](export-analytics-with-ai) reads your subscription numbers through the Adapty CLI analytics commands, finds where your app loses revenue, and suggests hypotheses to A/B test, grouped by placement. It also answers plain-language questions about your metrics — revenue, retention, LTV, and more. No API key required.

## Run Adapty Mail from a chat

Adapty Mail has its own [MCP server](mail-mcp). Connect it to Claude, ChatGPT, Claude Code, Codex, Cursor, or another MCP client, and your assistant can generate and translate campaigns, launch flows, set up a sending domain, and read campaign analytics, signed in as you. No API key is needed. In a coding agent, add the [Adapty Mail skill](mail-skill): it connects the server, asks before anything that emails real people, and traces why someone didn't get an email.

## Run A/B tests

The [ab-tests skill](ab-tests-skill) creates, starts, stops, and replaces paywall and flow A/B tests from your AI coding tool. Before each step that can't be undone, it shows you who sees what and waits for your yes.

## Give your AI tool the Adapty docs

### Plain-text docs

Every Adapty doc is available as Markdown — add `.md` to the page URL, or click **Copy for LLM** under the title. For broader context, give your tool the [`llms.txt`](https://adapty.io/docs/llms.txt) index or a platform-specific subset such as [`ios-llms.txt`](https://adapty.io/docs/ios-llms.txt).

### Context7

[Context7](https://context7.com/adaptyteam/adapty-docs) is an MCP server that serves Adapty docs to your AI tool, but it indexes only code snippets — not the full prose. Use it for quick code examples; for complete guidance, give your tool the plain-text docs above. Context7 works with Cursor, Claude Code, Windsurf, and other MCP-compatible tools. It serves docs only; to work with your account data, use the [Adapty MCP server](adapty-mcp).
