The Adapty plugin teaches your AI tool to work with Adapty. Install it in claude.ai, Claude Code, Codex, Cursor, or another AI tool, then ask in plain language: integrate the SDK, build a paywall, find out why revenue dropped, or start an A/B test. The plugin is the only part you set up. It connects your tool to your Adapty account and signs it in.

## What the plugin adds

An AI tool can reach your Adapty account through the [Adapty MCP server](adapty-mcp) or the [Adapty CLI](developer-cli-quickstart). That access lets it read and change your data. The plugin gives it the knowledge to do that correctly:

- **Flow config rules**: A flow is a large JSON config with rules that exist only in the plugin. With them, your tool builds screens from a description or a screenshot, and validates and previews every change before it saves the flow. Without them, your tool can't build a working flow.
- **Tested methods**: The plugin knows which reports answer a question, how to read them, and how your numbers compare with the market. It turns them into hypotheses to A/B test, ranked by the revenue at stake.
- **Current Adapty APIs**: When it integrates the SDK, the plugin reads the current Adapty docs at each stage, so your tool writes code for the SDK version you install, not for one it remembers from its training data.
- **Confirmation before changes that reach your users**: Before it starts an A/B test, changes a placement, or emails real people, the plugin shows you what will change and waits for your yes.
- **Connection**: The plugin detects whether your tool has the MCP server, the CLI, or both, chooses the one that suits each task, and signs in with your Adapty account.

## Install the plugin

<Tabs groupId="ai-tool">
<TabItem value="claude-ai" label="claude.ai" default>

You install the plugin in Claude's settings, with no command line. The steps are the same in Claude desktop.

1. In Claude, open **Settings** → **Plugins**.
2. Click **Add** → **Add marketplace**.
3. Select **Add from a repository**.
4. In the **URL** field, enter `adaptyteam/adapty-skills` and select the repository. To get new skills and fixes as they ship, keep **Sync automatically** on.
5. Click **Sync**.

<ZoomImage id="adapty-skills-claude-add-marketplace.png" width="584px" alt="Add marketplace dialog in Claude with adaptyteam/adapty-skills in the URL field and Sync automatically turned on" />

Claude opens the **Discover** tab with the plugins from the Adapty marketplace. To install the plugin, in the **Adapty** row, click **Add**.

<ZoomImage id="adapty-skills-claude-discover.png" width="600px" alt="Discover tab in Claude listing the Adapty, Apple ads, and Apple ads benchmarks plugins, each with an Add button" />

The plugin runs its scripts in Claude's sandbox. To let it, in **Settings** → **Capabilities**, turn on **Code execution and file creation**.

To give Claude access to your Adapty account, add the Adapty MCP server as a connector and sign in, as [Connect your assistant](adapty-mcp#connect-your-assistant) describes.

<TabItem value="coding-agent" label="Coding agent">

The plugin works in any coding agent that supports skills: Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI, and others.

To install the plugin, in your terminal, run:

```bash
npx adapty skills install
```

Restart your agent to load the plugin. For other installation methods, see the [plugin README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Claude Code doesn't update the plugin on its own. To get new skills as they ship, in Claude Code, run `/plugin`, open **Marketplaces**, select `adapty`, and choose **Enable auto-update**.

In Claude Code and Codex, the plugin also adds the Adapty MCP server, so you only sign in, as [Connect your assistant](adapty-mcp#connect-your-assistant) describes.

## What you can do

You don't need to name a skill. Ask the way you'd brief a colleague, and the plugin chooses the workflow.

### Integrate the SDK

```
Integrate Adapty into my app
```

The plugin sets up the dashboard, installs the SDK, adds a paywall, and verifies each stage before it moves on. It detects your platform. See the guide for [iOS](adapty-sdk-integration-skill), [Android](adapty-sdk-integration-skill-android), [React Native](adapty-sdk-integration-skill-react-native), [Flutter](adapty-sdk-integration-skill-flutter), [Unity](adapty-sdk-integration-skill-unity), [Kotlin Multiplatform](adapty-sdk-integration-skill-kmp), or [Capacitor](adapty-sdk-integration-skill-capacitor).

### Build and change flows

```
Add a German locale to my onboarding flow
```

The plugin [builds and edits flows](flow-generator-skill): it adds locales, rewrites copy, adds or removes screens, wires quiz branching, and builds a paywall from a description. Before you publish, it [audits the flow](flow-audit-skill) for triggers, store compliance, products, and localization. If your app still runs on paywalls, it [moves your placements to flows](migrate-placements-skill).

### Find what to test next

```
Audit my app. What should I test next to grow revenue?
```

The plugin [reads your analytics, prices, and past A/B tests](export-analytics-with-ai), scores each part of your business against the market, and returns hypotheses ranked by the revenue at stake. It also answers plain questions about your numbers, such as why renewals dropped last month.

### Run A/B tests

```
Start a 50/50 test of my two onboarding paywalls
```

The plugin [creates, starts, stops, and replaces A/B tests](ab-tests-skill) for paywalls and flows.

### Analyze your ad campaigns

```
Which campaigns should I scale, and which should I cut?
```

The plugin [reads your Adapty Attribution data](developer-cli-attribution-skill): ROAS, payback, cost per trial, and refunds by channel, campaign, and country.

### Run Adapty Mail

```
Why didn't this user get the welcome email?
```

The plugin [connects the Adapty Mail MCP server](mail-skill), launches email flows, and traces why an email didn't send. It asks before anything that emails real people.

### Migrate from RevenueCat

Your coding agent moves your RevenueCat catalog and paywall designs to a new Adapty app, then replaces the RevenueCat SDK in your app code with the IDs that catalog got in Adapty. See [Migration from RevenueCat](migration-from-revenuecat).

:::tip
Apple Ads campaigns have a plugin of their own. See [Manage Apple Ads with an AI coding tool](developer-cli-ads-manager-skill).
:::

## How the plugin reaches your account

The plugin works through two connections. You set up the one your tool needs, and the plugin chooses between them when both are there:

- **[Adapty MCP server](adapty-mcp)**: The connection for claude.ai and Claude desktop, and for coding agents that support MCP. You sign in with your Adapty account in the browser. No API key is needed.
- **[Adapty CLI](developer-cli-quickstart)**: The connection for coding agents that run terminal commands. The flow and analytics workflows use it in coding agents, because the CLI hands them files directly. You can also run the CLI yourself or from your own scripts.

## Give your AI tool the Adapty docs

### Plain-text docs

Every Adapty doc is available as Markdown — add `.md` to the page URL, or click **Copy for LLM** under the title. For broader context, give your tool the [`llms.txt`](https://adapty.io/docs/llms.txt) index or a platform-specific subset such as [`ios-llms.txt`](https://adapty.io/docs/ios-llms.txt).

### Context7

[Context7](https://context7.com/adaptyteam/adapty-docs) is an MCP server that serves Adapty docs to your AI tool, but it indexes only code snippets — not the full prose. Use it for quick code examples; for complete guidance, give your tool the [plain-text docs](#plain-text-docs). Context7 serves docs only; to work with your account, [install the Adapty plugin](#install-the-plugin).
