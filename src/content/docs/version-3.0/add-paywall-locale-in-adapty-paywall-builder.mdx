You can localize your flow to serve international users locale-specific content in a language they understand. You can translate or customize the following:

- Every string in the flow, including each branch of [conditional text](#conditional-text).
- The [URL of each **Open URL** action](#action-urls).
- Images and videos, with a [separate file per locale](#images-and-videos).

The <Inline id="localizations.svg" alt="Localizations" /> **Localizations** panel lists all the strings and action URLs in one table. Each locale is a column, and each string is a row. From there, you can translate the cells by hand, with Adapty's built-in AI, or by exporting them for a third-party translator. Images and videos aren't in the table: you localize them in the property panel.

<ZoomImage id="locales-table.webp" width="700px" alt="Localizations panel with the locale tabs, the filters, and the localization table" />

To show a locale to users, your app [has to pass the locale code](localizations-and-locale-codes) in the [flow view configuration request](get-pb-paywalls#fetch-the-view-configuration). Values without a translation fall back to the content specified for the default locale (English unless you [set another locale as default](#set-the-default-locale)).

:::tip
Finish setting up your flow in the default locale before adding other languages.
:::

## What you can localize

### Text content

The **Localizations** panel has a row for every string in the flow, including:

- The content of each text element, such as a button label.
- The **Placeholder** of each input field.
- The title and message of each **Show alert** action.

### Variables

What a [variable](onboarding-variables) shows in other locales depends on where its value comes from:

- **Product variables**: The store returns their values already localized. A string that only contains a product variable, such as a price, needs no translation.
- **Custom and element variables**: Their values cannot be localized. For example, `selectedOptionTitle` shows the selected option's **Element Title** exactly as you entered it. Use static or conditional text instead.

### Conditional text

Text elements can display [different content](onboarding-text#add-conditional-text) based on the conditions that you set. You can localize each branch of conditional text, but not the conditions themselves.

:::warning
Conditional logic cannot differ between the locales. If you compare a variable to a string, the string cannot be locale-specific.
:::

### Action URLs

An **Open URL** action can open a different URL in each locale, for example, a help page in the user's language. In a locale without its own URL, the action opens the default locale's URL. On the device, the SDK picks the URL by the app's current language, not by the locale code your app passes to it.

### Images and videos

Image and Video elements can show a [different file in each locale](#localize-images-and-videos). In a locale without its own file, the element shows the default locale's file. The **Localizations** panel doesn't list images and videos. You can't localize icons or [screen and container backgrounds](custom-media#limitations).

## Manage localizations and translations

### Add and set up a locale

1. Open the <Inline id="localizations.svg" alt="Localizations" /> Localizations panel on the left. Click **Add locale**.
2. In the **Select languages** field, select one or more languages.
3. (Optional) To translate your flow into the new locales right away, select **Translate content from default locale using AI**.
4. Click **Add locales**.

<ZoomImage id="new-locale-flow.webp" width="500px" alt="Add locales dialog" />

Each locale corresponds to a column in the localization table. The rows are the strings and [action URLs](#action-urls) in the flow, including each branch of [conditional text](#conditional-text). The table groups them into a section for each screen.

<ZoomImage id="locales-sidebar.webp" width="250px" float="right" alt="Locale tabs in the Localizations panel sidebar, with a pin on the default locale and a percentage on each other locale" />

The panel's sidebar shows your progress in each locale, as the percentage of translated cells. The section header of each screen shows that screen's progress across all locales. The panel counts a cell as translated as soon as it has a value, even when that value is a copy of the default locale's text.

A row with a missing translation displays the **Missing** badge. Each empty cell shows the default locale's text dimmed.

### Set the default locale

The pin icon <Inline id="pin.svg" alt="Pin" /> marks the default locale. It holds your source content, and serves as fallback for any missing translations. Every flow starts with English as its default and only locale.

Before you change the default locale, fill its replacement with translations. If a locale is incomplete when it becomes the default, Adapty populates it with content from the previous default locale. The fields no longer report translations as **Missing**.

To change the default locale, in the column header of the target locale, open **Locale actions** and select **Set as default**.

<ZoomImage id="flow-builder-set-default-locale.webp" width="500px" alt="Locale actions menu of a locale column, with Set as default highlighted" />

### Delete a locale

To delete a locale, open **Locale actions** in its column header and select **Delete locale**. Adapty removes all locale-specific content, including images and videos. To restore the locale, undo the deletion. To delete the default locale, first [make another locale the default](#set-the-default-locale).

### Table actions

You can change many cells in one operation, and a single undo reverts all of them.

#### Filter rows

Set the filters in the panel's sidebar to limit the rows that the table shows:

- **Screens** — Limit the screen selection {/*, and hides reusable components*/}.
- **Status** > **Missing only** — Hide rows that have a translation in every locale.

Bulk actions only affect visible rows. When you turn the filter on, you limit the surface area for bulk actions. To translate or reset a whole locale or the whole flow, turn off the filters first.

#### Manage a locale

Open the column context menu <Inline id="collapse-layer.svg" alt="Locale actions" /> to bulk-manage a single locale:

- **Set as default**: Makes the locale the [default locale](#set-the-default-locale).
- **Import** and **Export**: Import or export the locale's [translation file](#localize-content-externally).
- **AI Translate locale**: Translate the locale's entire column from the default locale [with AI](#translate-strings-with-ai).
- **AI Translate missing only**: Translate the locale's empty cells [with AI](#translate-strings-with-ai).
- **Reset to default (…)**: Removes every translation of the locale.
- **Delete locale**: [Deletes the locale and its content](#delete-a-locale).

<ZoomImage id="flow-builder-set-default-locale.webp" width="500px" alt="Locale actions menu of a locale column" />

#### Manage a row

Open the row context menu <Inline id="context.svg" alt="Row context menu" /> to bulk-manage a single string, with all its locales:

- **AI Translate missing only**: Translate the row's empty cells [with AI](#translate-strings-with-ai).
- **AI Translate row**: Translate the entire row from the default locale [with AI](#translate-strings-with-ai).
- **Reset to default**: Removes every translation in the row.

<ZoomImage id="locales-row-menu.webp" width="600px" alt="Row context menu with AI Translate missing only, AI Translate row, and Reset to default" />

#### Cell actions

Open the cell context menu <Inline id="context.svg" alt="Cell context menu" /> to manage a single cell value:

- **Add variable**: Inserts a [variable](onboarding-variables) into the cell.
- **Copy** and **Paste here**: Copy the cell's value, with its formatting and variables, and paste it into another cell.
- **AI Translate**: Translates the cell [with AI](#translate-strings-with-ai).
- **Push value to all locales**: Copies the cell's text into every other locale except the default, so the row counts as translated. For text that stays the same in every language, such as a brand name or a string that only contains a [product variable](#variables), you can fill the whole row in one step. To update the copies after you edit the cell, push the value again.
- **Clear translation**: Empties the cell, so users in its locale see the default locale's text.

<ZoomImage id="locales-cell-menu.webp" width="400px" alt="Cell toolbar and its context menu, with Add variable, Copy, Paste here, AI Translate, Push value to all locales, and Clear translation" />

## Localize content in the builder

To translate strings and set action URLs, open the **Localizations** panel. You can [translate them manually](#translate-strings-manually), [with AI](#translate-strings-with-ai), or [export the localization file](#localize-content-externally) for use with a third-party translator.

To localize images and videos, [edit the target element's properties](#localize-images-and-videos).

### Translate strings manually

The table in the **Localizations** panel includes every string in the flow:

- Static text (a row per element)
- Conditional text (a row per branch)
- **Open URL** action targets (a row per URL)

To translate a string, click a cell and enter the translation. To insert a [variable](onboarding-variables), click **&#123; &#125;** in the cell. To find a string's row, [select its element](builder-ui#preview-area-center) in the preview.

Each conditional text element is a separate group of rows. Click the arrow <Inline id="expand-layer.svg" alt="Expand" /> to expand the group and view all condition branches.

<ZoomImage id="locales-conditional-text.webp" width="700px" alt="Conditional text expanded in the Localizations panel, with a row for each branch and its translations" />

### Translate strings with AI

AI translates strings from the default locale into the other locales. It doesn't translate [action URLs](#action-urls).

Open **AI Translate** in the panel header and select one of the following:

- **Translate missing only**: Translates the empty cells and keeps the existing translations.
- **Translate all**: Translates every cell and replaces the existing translations, including the ones you edited by hand.

<ZoomImage id="locales-ai-translate.webp" width="700px" alt="AI Translate menu in the Localizations panel header, with Translate missing only and Translate all" />

You can only translate the rows that the [filters](#filter-rows) show. To translate only some rows or locales, select their checkboxes first.

If an AI translation changes a variable or the text formatting, Adapty discards that translation and keeps the cell's previous value.

### Set locale-specific action URLs

Each **Open URL** action has its own row. To set a different [URL](#action-urls) for a specific locale, change the cell value in that locale's column. To see which element a URL belongs to, click its row: the builder selects that element in the preview.

### Localize images and videos

To show a different image or video in a locale, upload a separate file for that locale:

1. If the **Localizations** panel is open, close it.
2. Change the current locale in the [bottom toolbar](builder-ui#view-controls-bottom-toolbar).
3. Select the image or video element. Upload the localized file.
4. When you're done, set **Locale** back to the default. While another locale is active, your edits in the property panel only apply to that locale.

<ZoomImage id="image-localization-demo.webp" width="500px" alt="Canvas image changing as the active locale changes" />

## Localize content externally

You can [export the localization file](#export-the-localization-file) to feed your entire flow's text content to a third-party translation tool. After the service completes the translation, [import](#import-the-file-with-a-translation) the file back.

### Export the localization file

Click **Import / Export** in the table header to export the entire flow with all its locales. Click **Export** in the [column context menu](#manage-a-locale) to export  an individual locale alongside the source locale.

<ZoomImage id="import-export.webp" width="700px" alt="Import / Export menu in the Localizations panel header" />

### Import / Export file format

The localization file is a `.tsv` (tab-separated) file in UTF-8, with one row per string or action URL. An exported file covers the whole flow, whatever filters you set in the panel. To import a file, keep its format unchanged. The columns are:

| Column | Description |
|--------|-------------|
| `id` | The row's identifier. Adapty matches rows by it on import, so keep it unchanged. Adapty ignores rows with an `id` that isn't in the flow. |
| `Screen` | The screen{/* or reusable component*/} the string belongs to. Adapty ignores this column on import. |
| `[locale]` | One column per locale, named by its code (e.g., `en`, `fr`). Adapty ignores columns for locales that aren't in the flow. |

Example:

```
id	Screen	en	fr	es
lc_1	Welcome	Turn words into art	Transformez les mots en art
lc_2	Welcome	Start your <b>free trial</b>	Commencez votre <b>essai gratuit</b>
lc_3	Quiz	What will you create?
```

In the exported file:

- Formatting appears as HTML tags, such as `<b>`, and variables as `{{name}}`. Keep them intact: Adapty restores them on import.
- Each branch of [conditional text](#conditional-text) has its own row, without its condition.
- Images and videos aren't included: you [localize them in the builder](#localize-images-and-videos).

To translate strings that you add after the export, export the file again.

Adapty can't import a file in the old format, with `Screen`, `Element`, and `Property` columns. To reuse its translations, export the flow again and copy them into the new file.

### Import the file with a translation

:::warning
If a cell in the file is empty, Adapty removes that cell's translation on import, except in the default locale's column. To keep a locale's translations, leave its cells as exported, or delete its column from the file. If an import clears translations you wanted to keep, undo the import: the whole import is one undo step.
:::

To import the whole flow, click **Import / Export** in the table header and select **Import**. To import one locale, select **Import** in its [column context menu](#manage-a-locale). Then, select the translated file.

Strings without a row in the file keep their current values. A whole-flow import updates the default locale's text wherever the file changes it. A one-locale import only changes the locale you import. To import a new language, [add its locale](#add-and-set-up-a-locale) first.

## Preview different locales

The text in the preview area always shows the active locale. If you edit text content in the property panel, these edits only apply to that locale. Switch back to the default locale to edit the source content.

- To switch the active locale, select it from the **Locale** dropdown in the [bottom toolbar](builder-ui#view-controls-bottom-toolbar), or click its tab in the **Localizations** panel.
- To switch the active screen from the **Localizations** panel, click **View screen** <Inline id="eye.svg" alt="View screen" /> in its section header.
- To spread the localization table across the entire screen, click **Hide preview**.

<ZoomImage id="preview-locales.webp" width="500px" alt="Locale preview in Flow & Paywall Builder" />

To find copies of the default locale's text without previewing every screen, run the [flow-audit skill](flow-audit-skill).
