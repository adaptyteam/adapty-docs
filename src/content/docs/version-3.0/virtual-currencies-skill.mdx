[Virtual currencies](virtual-currencies) credit coins to your users when they buy a product or renew a subscription. The virtual-currencies skill manages them from your AI tool. Your agent lists your currencies, shows how many coins each product credits, creates a currency, and adds, changes, or removes the products that credit it. It also reads the coin transactions and the balances of a user, so it can tell you why that user has a balance. It works through the [`adapty virtual-currencies` CLI commands](developer-cli-virtual-currencies) or the [Adapty MCP server](adapty-mcp).

:::note
A change of a mapping changes how many coins your users get, from the next purchase. Before the skill creates a currency or changes its mappings, it shows you each product that changes, with its coins before and after. It runs the change only after your yes.
:::

## What you can ask

Ask the way you'd brief a colleague. You don't need to name the skill:

```
Which virtual currencies does my app have?

How many gems does the Starter pack give?

Give the Starter pack 50 gems.

Create a currency "Gems" and give 100 gems for each Gem pack purchase.

Stop giving gems for the Weekly subscription.

Why does user 4512 have 40 coins?
```

## Before you start

- **Products in Adapty**: A mapping links a currency to a [product](create-product) in Adapty.
- **An AI tool connected to your Adapty account**: The skill works through the [Adapty MCP server](adapty-mcp) or the [Adapty CLI](developer-cli). In Claude Code and Codex, the plugin adds the MCP server, so you only sign in. The skill checks which of the two your AI tool has and uses it. With both, it uses the MCP server. With neither, the skill asks which one to set up.

## What the skill asks before each change

The skill reads the currency right before each change, and shows you what changes. Only your answer to the skill's question counts. A general "go ahead" before the skill shows the change doesn't. If you say no, the skill changes nothing.

| Change | What the skill tells you |
|---|---|
| Create a currency | The code, the name, and the products that credit it. You can't delete a currency or change its code, and an app can have up to 20 currencies. |
| Add or change mappings | Each product that changes: new, or its coins before and after, for each purchase or each subscription period. The other mappings stay as they are. |
| Remove a mapping | The product. Its purchases stop giving coins of this currency, and no transaction records the purchases that give none. |
| Change the name or the description | The name or the description before and after. The rest stays as it is. |

If someone changes the currency in the dashboard between the skill's read and its write, Adapty refuses the write and nothing changes. The skill then reads the currency again, shows you the change again, and waits for a new yes.

If Adapty doesn't answer a change, the skill doesn't send it again at once. It reads the currency first and tells you what was saved. For a part of the change that is still missing, it shows you a new question and waits for a new yes.

## How the skill explains a balance

Ask why a user has a balance, and the skill reads the user's coin transactions and balances, by the profile ID or by your own user ID. It tells you which purchases, spends, and grants gave the balance, and which coins expire and when. The [user's profile](virtual-currency-balance) in the dashboard shows the same data.

For totals and trends across all users, the skill uses the virtual currency charts of Adapty analytics, not a sum of transactions. A chart leaves out each user with a sandbox transaction, so a sum of transactions can differ from a chart.

## Limits

- **No deletion of a currency**: You can't delete a currency or change its code, in the skill or in the dashboard.
- **No balance changes**: The skill doesn't credit or debit a balance. To do it, use the [dashboard](virtual-currency-balance#adjust-a-balance-manually) or the server-side API.
- **No unattended changes**: In a scheduled run or a script, with no one to answer, the skill only reads. For a change, it reports what the change does and the command for you to run.

To run the commands yourself, without the skill, see [Manage virtual currencies from the CLI](developer-cli-virtual-currencies).
