The Flow & Paywall Builder includes three media element types under the **Media** category: Image, Video, and Icon.

:::tip
To make an image or video cover the entire screen — including the areas behind the notch and the home indicator — position it as fixed with all offsets at 0 and select **Ignore safe area**. See [Layout and positioning](manage-paywall-ui-elements#ignore-safe-area).
:::

## Image

Upload a `.JPG`, `.PNG`, or `.WEBP` file up to 20 MB.

Animated GIFs and WEBPs aren't supported. To add motion, use a [Video](#video) element instead.

An Image element can have a different image for each locale. To show a different image in dark mode, [add a dark file](paywall-dark-mode#show-a-different-image-or-video-in-dark-mode) to the element.

:::tip
To place your content over a full-screen image, [build a hero image](paywall-head-picture#use-a-background-as-a-hero-image) from a screen background and a sliding sheet.
:::

- **Content mode** — controls how the image fills its container when you set its height. See [Image sizing](#image-sizing).
- **Use custom media ID** — see [Custom media ID](#custom-media-id) below.

### Image sizing

An image has its own proportions, and the box you give it may not match them. Set the width first, then decide the height:

- **Auto height**. The image keeps its shape: the height follows from the width you set. **Content mode** turns off, because there is nothing to crop.
- **Fixed or Fill height**. The box gets proportions of its own, and **Content mode** resolves the mismatch:
  - **Fit**. Scales the whole image inside the box and leaves empty space.
  - **Fill**. Crops whatever overflows. Default.

To keep an image uncropped at every screen width, use **Fill** width with **Auto** height. With a fixed height, the crop at the top and bottom changes from one screen size to the next.

## Video

Upload an `.MP4` or `.WEBM` file up to 50 MB and no longer than 30 seconds. The minimum video resolution is 640x640 pixels.

- **Aspect** — controls how the video fills its container when you set its height. See [Video sizing](#video-sizing).
- **Loop** — replay the video continuously. On by default.
- **Use custom media ID** — see [Custom media ID](#custom-media-id) below.

Videos do not play in the editor preview — the canvas shows a still frame. On the device at runtime, the video plays muted by default. With Loop on, it repeats indefinitely.

A Video element can have a different video for each locale. To show a different video in dark mode, [add a dark file](paywall-dark-mode#show-a-different-image-or-video-in-dark-mode) to the element.

### Video sizing

A video has its own proportions, and the box you give it may not match them. The height decides what happens:

- **Hug height**. The height follows the video's own proportions.
- **Fixed or Fill height**. The **Aspect** property resolves the mismatch:
  - **Fit**. Scales the whole video inside the box and leaves empty space.
  - **Fill**. Crops whatever overflows. Default.

When Adapty can't read a video's proportions on upload, it warns you: "Could not determine video dimensions. Set a fixed height to ensure the video displays correctly." Give the video a fixed height, or make sure a container that holds it has one. Otherwise its height may collapse to 0.

### Trigger an action when the video ends

:::link
Main article: [Actions](onboarding-actions)
:::

The Video element supports an **On playback finished** trigger that fires when the video reaches the end. Set it up in the **Interactions** panel to navigate to another screen, reveal a CTA, or run any other action.

## Icon

<ZoomImage id="builder-icon-selection.webp" width="300px" float="right" alt="Icon picker with the Tabler Icons library" />

Pick from the bundled [Tabler Icons](https://tabler.io/icons) library, with thousands of icons in two visual styles:

- **Stroke** — outline only.
- **Filled** — solid fill.

Search the picker by keyword to find an icon. Set the icon's color in the **Color** picker — pick a saved [color style](builder-reusable-styles#color-styles) or set a custom color. You can only apply a single layer style with a solid color.

## Localize media

:::link
Main article: [Add a locale](add-paywall-locale-in-adapty-paywall-builder)
:::

The following elements and layers can hold a different file per locale:

- Image and Video elements.
- Image and video layers in a [fill](builder-styling#fill), such as a screen background.
- Image and video layers of a [color style](builder-reusable-styles#color-styles), in each light or dark version separately.

To upload a localized file:

1. If the **Localizations** panel is open, close it to show the property panel.
2. In the [bottom toolbar](builder-ui#view-controls-bottom-toolbar), set **Locale** to the target locale.
3. Select the element, or click an empty area of the preview for a screen background.
4. In the property panel, upload the localized file.
5. Set **Locale** back to the default locale, so that later edits apply to the default locale again.

For a color style, [replace the image or video in the style](builder-reusable-styles#images-and-videos) while the target locale is active.

In a locale without its own file, users see the file of the default locale. For a color style, each version falls back to the default locale separately. You can also upload a file for each locale in the [**Localizations** panel](add-paywall-locale-in-adapty-paywall-builder#localize-images-and-videos).

### Limitations

You can't localize icons or custom media IDs. To localize an image or video that has a custom media ID, use the ID to [substitute a localized file at runtime](#custom-media-id).

## Custom media ID

:::important
You can set a custom media ID for an image or video in a [fill](builder-styling#fill), such as a [screen background](paywall-head-picture).
:::

Tag an image or video element with a custom media ID to swap it at runtime from your app code. Use this for [personalized visuals](get-pb-paywalls#customize-assets) — for example, showing the user's selected avatar.

The media you upload in the Flow & Paywall Builder serves as the fallback. If your code doesn't provide media for the ID at runtime, the fallback renders instead.

A custom media ID can only swap a file for another of the same type — an image for an image, a video for a video. If the types don't match, the fallback renders.

To enable a custom media ID on an Image or Video element:

1. Select the **Use custom media ID** checkbox under the upload area.
2. Enter a media ID.
3. Upload a fallback image or video.

In your app code, fetch media by its ID — see [Customize assets](get-pb-paywalls#customize-assets) for the SDK API.

:::tip
To make the first screen of a flow render instantly, tag its heavy images and videos with custom media IDs and have your developers bundle those files with the app. See [Show first-screen media from the app bundle](ios-optimize-paywall-fetching#show-first-screen-media-from-the-app-bundle).
:::
