If your backend must keep its URL in App Store Connect, pass the App Store server notifications from your backend to Adapty unchanged. If your backend doesn't need its URL in App Store Connect, [set up forwarding to your backend in Adapty](enable-app-store-server-notifications#raw-events-forwarding) instead. That route needs no code.

Adapty handles the notifications from your backend as if Apple sent them directly. With [Refund Saver](refund-saver), Adapty still answers the refund requests among them.

If your backend receives real-time developer notifications from Google Play through its own Pub/Sub topic, it needs no code to pass them to Adapty. [Add a push subscription for Adapty to that topic](enable-real-time-developer-notifications-rtdn#send-notifications-to-two-adapty-apps).

To pass App Store server notifications to Adapty:

1. In Adapty, open the app you're connecting: each Adapty app has its own notification URL. Go to [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). In the **App Store server notifications** section, copy the URL from the **URL for App Store server notifications** field.
2. In your backend, post each notification from Apple to the URL you copied. In each request:

   - Keep the body from Apple unchanged: `{"signedPayload": "…"}`.
   - Set the `Content-Type: application/json` header.
   - Don't add an `Authorization` header.

   If Adapty also forwards notifications to your backend, don't post those back to Adapty.

```python showLineNumbers
import requests

url = "https://api.adapty.io/api/v1/sdk/apple/webhook/123a258e62fad41bfa734f4b0dbcad45/" # don't forget to replace this URL

  'Content-Type': 'application/json'
}
```

<TabItem value="go" label="Go" default>

  ```go showLineNumbers
package main

import (
	"fmt"
	"strings"
	"net/http"
)

func main() {
	url := "https://api.adapty.io/api/v1/sdk/apple/webhook/123a258e62fad41bfa734f4b0dbcad45/" // Replace this with the actual URL

	payload := strings.NewReader(`{"signedPayload":"eyJhbGciOiJFUzI1NiIs..."}`) // Apple's request body, unchanged

	method := "POST"

	client := &http.Client{}
	req, err := http.NewRequest(method, url, payload)
	if err != nil {
		fmt.Println("Error creating request:", err)
		return
	}
	req.Header.Add("Content-Type", "application/json")

	res, err := client.Do(req)
	if err != nil {
		fmt.Println("Error sending request:", err)
		return
	}
	defer res.Body.Close()
}
  ```

A `200` response doesn't confirm that Adapty could use the notification. Adapty answers before it decodes the signed payload. To confirm that notifications reach Adapty, make a [sandbox purchase](test-purchases-in-sandbox). Then make sure that [the notifications status](enable-app-store-server-notifications#check-that-notifications-reach-adapty) in the **App Store server notifications** section reads **Active**.
