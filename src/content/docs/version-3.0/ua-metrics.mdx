This is an overview of the metrics available in Adapty Attribution analytics. Use it to understand what each metric measures and how Adapty calculates it. For the subscription analytics generated by Adapty Core, use the [metric comparison table](metric-comparison-table).

:::note
Web purchases have no app install event. Adapty cohorts them by the date of the first trial start or purchase.
:::

## Standard metrics

| **Metric**                        | Description                                                                                                                                                                                                                                                                                                                                                                                                                                     | <InlineTooltip tooltip="Cohort support">A cohort period limits a metric to a number of days after the install, such as 7 days for D7 ROAS.</InlineTooltip> |
|-----------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---:|
| **Spend**                         | The sum of the cost of each customer tap on your ad.                                                                                                                                                                                                                                                                                                                                                                                            | No     |
| **Impressions**                   | The number of times your ad was displayed within the selected date range.                                                                                                                                                                                                                                                                                                                                                                           | No     |
| **Clicks**                        | The number of times users clicked on your ad within the selected date range. Excludes clicks on [custom tracking links](ua-tracking-links).                                                                                                                                                                                                                                                                                                                                                                       | No     |
| **Clicks (attributed)** | The number of ad clicks that Adapty counted through its tracking links. Includes clicks on [custom tracking links](ua-tracking-links). | No |
| **CPI**                           | **CPI (Cost per Install)** is the amount you pay for each install. <br/>**Formula**: `Spend / Installs`                                                                                                                                                                                                                                                                                                                                         | No     |
| **CPC**                           | **CPC (Cost per Click**) is the amount you pay for each click on your ad. <br/>**Formula**: `Spend / Clicks`                                                                                                                                                                                                                                                                                                                                    | No     |
| **CPM**                           | **CPM (Cost per Mille)** is the amount you pay per one thousand ad impressions. <br/>**Formula**: `Spend / (Impressions / 1000)`                                                                                                                                                                                                                                                                                                                | No     |
| **ICR**                           | **ICR (Install Conversion Rate)** is the percentage of ad clicks that resulted in installs. <br/>**Formula**: `(Installs / Clicks) × 100%`                                                                                                                                                                                                                                                                                                      | No     |
| **ICR (attributed)** | The percentage of **Clicks (attributed)** that resulted in installs. <br/>**Formula**: `(Installs / Clicks (attributed)) × 100%` | No |
| **IPM**                           | **IPM (Installs per Mille)** represents the number of installs per one thousand ad impressions. <br/>**Formula**: `(Installs / Impressions) × 1000`                                                                                                                                                                                                                                                                                             | No     |
| **CTR**                           | **CTR (Click-Through Rate)** is the percentage of impressions that resulted in clicks. <br/>**Formula**: `(Clicks / Impressions) × 100%`                                                                                                                                                                                                                                                                                                        | No     |
| **Inline link clicks**            | The number of times users clicked inline links in your ad creatives or app page.                                                                                                                                                                                                                                                                                                                                                                | No     |
| **Avg cost per inline link click** | The average amount you pay per inline link click. <br/>**Formula**: `Spend / Inline link clicks`                                                                                                                                                                                                                                                                                                                                                | No     |
| **Inline link click through rate**         | The percentage of impressions that resulted in inline link clicks. <br/>**Formula**: `(Inline link clicks / Impressions) × 100%`                                                                                                                                                                                                                                                                                                                | No     |
| **Installs**                      | The total number of times users installed your app within the selected date range. Each reinstall counts as a new install, with its own attribution.                                                                                                                                                                                                                                                                                                                                           | No     |
| **Payers** | The number of paid subscriptions that users started, directly or after a trial. <br/>**Formula**: `Subscriptions started + Trial converted` | Yes |
| **Total revenue**                 | The total amount of money generated so far from purchases by users who installed within the selected date range. To switch between gross revenue and proceeds, use the revenue dropdown in [Adapty Attribution analytics](ua-analytics#gross-revenue-or-proceeds).                                                                                                                                                                                                                                                                  | No     |
| **Revenue** | The revenue from the users who installed within the selected date range, in the cohort period after the install, such as 7 days for **D7 Revenue**. Without a cohort period, use **Total revenue**. | Cohorts only |
| **ROAS**                          | **ROAS (Return on Ad Spend)** is the revenue from your ads divided by ad spend, expressed as a percentage. <br/> **Formula**: `(Total revenue / Spend) × 100% if Spend > 0, otherwise 0%`                                                                                                                                                                                                                                                            | Yes    |
| **AdProfit** | The revenue minus the ad spend. <br/>**Formula**: `Total revenue − Spend` | Yes |
| **ARPU** | **ARPU (Average Revenue per User)** is the average revenue per install. <br/>**Formula**: `Total revenue / Installs` | Yes |
| **ARPPU** | **ARPPU (Average Revenue per Paying User)** is the average revenue per user who paid. <br/>**Formula**: `Total revenue / Paying users`. `Paying users` is the number of users who paid, while **Payers** is the number of paid subscriptions. | No |
| **ARPAS** | **ARPAS (Average Revenue per Active Subscriber)** is the average revenue per subscription or trial started. <br/>**Formula**: `Total revenue / (Subscriptions started + Trial started)` | Yes |
| **ARPT** | **ARPT (Average Revenue per Trial)** is the average revenue per trial started. <br/>**Formula**: `Total revenue / Trial started` | Yes |
| **Cost per trial**                | The average amount you pay per trial started. <br/>**Formula**: `Spend / Trial started`                                                                                                                                                                                                                                                                                                                                                   | No     |
| **Cost per subscription**         | The average amount you pay per subscription started. <br/>**Formula**: `Spend / Subscriptions started`                                                                                                                                                                                                                                                                                                                           | No     |

## Event metrics

Event metrics count the subscription and purchase events of the users who installed within the selected date range. Each event has two metrics:

- **Count**: The number of times the event happened.
- **Rate**: The count as a percentage of installs. **Formula**: `(Count / Installs) × 100%`

You can add all event metrics with or without a cohort period.

| Event | Count metric | Rate metric |
|---|---|---|
| Users started a paid subscription without a trial. | **Subscriptions started** | **Rate subscription started** |
| Subscriptions renewed. | **Subscription renewed** | **Rate subscription renewed** |
| Users turned off the auto-renewal of a subscription. | **Subscription renewal cancelled** | **Rate subscription renewal cancelle** |
| Users turned the auto-renewal of a subscription back on. | **Subscription renewal reactivated** | **Rate subscription renewal reactivated** |
| Subscriptions ended without a renewal. | **Subscription expired** | **Rate subscription expired** |
| Users paused a subscription on Android. | **Subscription paused** | **Rate subscription paused** |
| The app's backend [deferred the payment](https://adapty.io/glossary/subscription-purchase-deferral/) of a Google Play subscription. | **Subscription deferred count** | **Rate subscription deferred** |
| The store refunded a subscription purchase. | **Subscription refunded** | **Rate subscription refunded** |
| Users disputed a subscription payment with their bank. | **Subscription chargeback** | **Rate subscription chargeback** |
| The bank returned a disputed subscription payment to you. | **Subscription chargeback reversed** | **Rate subscription chargeback reversed** |
| Users started a free trial. | **Trial started** | **Rate trial started** |
| Trials converted into paid subscriptions. | **Trial converted** | **Rate trial converted** |
| Users turned off the auto-renewal during a trial. | **Trial renewal cancelled** | **Rate trial renewal cancelled** |
| Users turned the auto-renewal back on during a trial. | **Trial renewal reactivated** | **Rate trial renewal reactivated** |
| Trials ended and didn't convert into paid subscriptions. | **Trial expired** | **Rate trial expired** |
| The store couldn't charge a user, for example, because of insufficient funds. | **Billing issue detected** | **Rate billing issue detected** |
| Subscriptions entered a grace period because of a billing issue. | **Entered grace period** | **Rate entered grace period** |
| Users made a one-time purchase. | **Non-subscription purchase** | **Rate non-subscription purchase** |
| The store refunded a one-time purchase. | **Non-subscription purchase refunded** | **Rate non-subscription purchase refunded** |
| Users disputed a one-time purchase payment with their bank. | **Non-subscription purchase chargeback** | **Rate non-subscription purchase chargeback** |
| The bank returned a disputed one-time purchase payment to you. | **Non-subscription purchase chargeback reversed** | **Rate non-subscription purchase chargeback reversed** |

## Predicted metrics

Predicted metrics project a cohort's future performance from the app's own historical data, so they cover organic installs too. They are available at multiple cohort periods, including D30, D60, D90, D180, and D360, plus custom periods you can add in days. For how these values are calculated, see [Predicted metrics in Adapty Attribution](ua-predicted-metrics).

| **Metric**    | Description                                                                                                                                                                                | <InlineTooltip tooltip="Cohort support">A cohort period limits a metric to a number of days after the install, such as 7 days for D7 ROAS.</InlineTooltip> |
|---------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---:|
| **pRevenue**  | Predicted total revenue a cohort is expected to generate by the target horizon. Modeled from the app's historical cohort retention.                                                        | Cohorts only |
| **pROAS**     | Predicted return on ad spend over the same horizon. **Formula**: `(pRevenue / Spend) × 100%`. Adapty doesn't calculate it for rows without spend, such as **Organic**.                     | Cohorts only |
| **pAdProfit** | Predicted revenue net of ad spend over the horizon. **Formula**: `pRevenue − Spend`                                                                                                        | Cohorts only |
| **pARPU**     | Predicted average revenue per install over the horizon (predicted LTV). **Formula**: `pRevenue / Installs`                                                                                 | Cohorts only |
| **pARPPU**    | Predicted average revenue per paying user over the horizon. **Formula**: `pRevenue / paying users at d{N}`, where `d{N}` matches the selected horizon.                                     | Cohorts only |
