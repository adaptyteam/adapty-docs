Adapty reads your products, validates purchases, and receives subscription events through the following Google APIs:

- Google Play Android Developer API
- Google Play Developer Reporting API
- Cloud Pub/Sub API

## Before you start

Check that you have the [access privileges and Google Cloud project the Google Play integration needs](initial-android#before-you-start). You can't complete the steps below without them.

## Enable the APIs

1. Open the [Google Cloud Console](https://console.cloud.google.com/).

2. Select the project you will use for the integration.

3. Open the [**Google Play Android Developer API**](https://console.cloud.google.com/apis/library/androidpublisher.googleapis.com) page.

4. Click **Enable** and wait for the status to read **Enabled**. If the button says **Manage** instead, the API is already on and there's nothing to do.

   <ZoomImage id="gp-api-library-enable.webp" width="700px" alt="An API page in the Google Cloud API library, with the Enable button" />

5. Open the [**Google Play Developer Reporting API**](https://console.cloud.google.com/apis/library/playdeveloperreporting.googleapis.com) page.

6. Click **Enable** and wait for the status to read **Enabled**.

7. Open the [**Cloud Pub/Sub API**](https://console.cloud.google.com/apis/library/pubsub.googleapis.com) page.

8. Click **Enable** and wait for the status to read **Enabled**.

To confirm, open the [**APIs & Services**](https://console.cloud.google.com/apis/dashboard) page in Google Cloud Console. The table at the bottom lists every API enabled in the project, and all three should appear:

- Google Play Android Developer API
- Google Play Developer Reporting API
- Cloud Pub/Sub API

<ZoomImage id="gp-apis-enabled-list.webp" width="700px" alt="Enabled APIs and services table listing all three required APIs" />
