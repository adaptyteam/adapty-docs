Ask an AI coding agent about your Adapty analytics in plain language — revenue, conversions, retention, LTV — and let it pull the numbers for you. The agent runs the [Adapty CLI analytics commands](developer-cli-analytics) in your terminal and reads the results.

## What you can ask about

The CLI returns the same numbers that the Adapty Analytics dashboard shows. Each kind of question maps to one command:

| Question about | What it covers | Command |
| --- | --- | --- |
| Revenue, MRR, ARR, ARPU, and other charts | A metric over time, grouped by a dimension the chart supports, such as country | `adapty analytics chart` |
| Conversion rates | How many users move from one step to the next, such as trial to paid | `adapty analytics conversion` |
| Funnel | Where users drop off between install and renewals | `adapty analytics funnel` |
| Retention | How many subscribers stay after each period | `adapty analytics retention` |
| Lifetime value (LTV) | Revenue per paying user after each renewal or day | `adapty analytics ltv` |
| Install cohorts | Revenue, subscribers, and predictions for users who installed in the same period | `adapty analytics cohort` |

Every command is read-only. The agent can't change anything in your Adapty account through them.

## Before you start

You need three things:

- **An Adapty account with data**: The CLI returns the same numbers as your dashboard, so your app must already collect analytics.
- **The Adapty CLI, version 0.10.0 or later, logged in**: To install the CLI and log in, run these commands. The login opens a browser tab where you confirm the code from the terminal.

  ```bash
  npm install -g adapty
  ```

  ```bash
  adapty auth login
  ```

  One login reads every app your Adapty user can access, so you need no API key.

- **An AI tool that can run terminal commands**: For example, Claude Code, Cursor, Codex, or Gemini CLI. Plain chat tools like claude.ai or ChatGPT can't run the CLI.

## Give your agent the commands

The [CLI analytics reference](https://adapty.io/docs/developer-cli-analytics.md) describes every command, its flags, and how to read the results. Once your agent has read it, it builds correct commands without you writing any.

Give your agent the reference by URL: if your agent can fetch URLs, give it `https://adapty.io/docs/developer-cli-analytics.md` and ask it to read the page.

The agent doesn't need to know your chart names in advance. It finds them with `adapty analytics catalog --app <app-id>`, which lists every chart, conversion, grouping, and filter your app supports.

## Ask about your data

With the reference loaded and the CLI logged in, name the app, the metric, the period, and what you want to decide.

Example prompts:

```
For my app "Sleep Tracker", what was MRR at the end of each month this year,
and how does it compare to the same months last year?

Show the trial-to-paid conversion rate for the last 90 days, by product.
Which product converts worst?

Which 10 countries brought the most revenue in Q3? Use revenue after the
store's commission.

How does retention compare between iOS and Android for subscribers who started
in the last 6 months?

Compare LTV after 30 and 90 days for users who installed in July and in August,
and save it as a CSV file.
```

The agent finds the app's UUID with `adapty apps list`, picks the command, and returns the data. It reads results as JSON (`--json`). Ask for CSV when you want a spreadsheet-ready file — the agent adds `--csv` to the command.

## Set up once for repeated use

To avoid repeating setup every session, save the reference where your agent can reuse it:

- **Save the reference link**: Add `https://adapty.io/docs/developer-cli-analytics.md` to your agent's rules or memory file (for example, a `CLAUDE.md` or Cursor rules file) so it loads every session.
- **Name your app**: Add your app's name or UUID to the same file, so you don't have to name it in every prompt.
- **Save reusable prompts or create a custom skill**: Keep your common questions as saved prompts, or wrap them in a custom skill or slash command so your agent runs a report on demand.

## Limits

Keep these constraints in mind:

- **Rate limit**: Each analytics command allows 2 requests per second per app. The CLI doesn't retry, so a command sent too fast fails with exit code 4. Tell your agent to run commands one after another and to wait `retry_after_seconds` before it runs a failed one again.
- **One app per command**: Each command reads one app. To compare apps, the agent runs one command per app.
- **Not added to Attribution**: For ad spend, installs, and ROAS by campaign, use the [Attribution commands](developer-cli-attribution). Don't add their numbers to the analytics numbers, because Adapty calculates them differently.

To pull analytics from a server or a scheduled job, where no one can log in through a browser, use the [Export Analytics API](export-analytics-api) with a secret API key instead.
