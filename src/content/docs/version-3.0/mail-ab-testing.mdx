An A/B test in Adapty Mail compares two or more full email campaigns against each other. Each variation is a complete, independent campaign. When a user matches the test's segment in a [flow](mail-flows), Adapty Mail routes them to one of the variations using the configured weights and tracks delivery, engagement, and revenue per variation.

:::tip
An AI assistant connected to the [Adapty Mail MCP server](mail-mcp) can create a test, launch it on a flow, read the funnel per variation, and finish it with the winner. It asks for your go before launching or finishing.
:::

## What a variation is

Each variation is a full campaign. Variations can differ in copy, hero images, tone, sequence length, or delay timing between emails. Each variation has its own [translations](mail-localization). For a fair comparison, localize every variation into the same languages.

Variations can't differ in who receives them, or when. One segment covers the whole test. Every campaign in it shares one [purpose](mail-create-campaign) — the lifecycle moment it addresses, named the same way as the [purpose of a flow](mail-flows#purposes). That's what decides which flow the test can run in.

You write each campaign separately, then add them as variations.

## Create an A/B test

1. Create the campaigns first in **Campaigns**. Each variation needs its own campaign, and they all need the same purpose.
2. In Adapty Mail, go to **A/B Tests** and click **Create**.
3. Add each campaign as a variation and set its weight. Weights must total **100%**.
4. Assign a segment to control which users the test applies to.
5. Save.

The test is saved as a **draft** and doesn't send anything yet. To go live, launch it.

## Launch the test

A test runs on the flow of its own purpose and segment. You can launch it from the **A/B Tests** page or from a flow.

### From the A/B Tests page

1. In Adapty Mail, go to **A/B Tests**.
2. Open the row menu of the draft test and select **Launch**. Or open the test and click **Launch**.
3. Read the **Launch A/B test** dialog, then click **Launch**.

<ZoomImage id="mail-ab-testing-launch.webp" width="400px" alt="The Launch A/B test dialog, saying that a flow for the Never purchased purpose and the Trial users segment will be created" />

The dialog tells you what happens to the flow:

- **The flow exists and sends a campaign**: The test replaces the campaign.
- **There is no flow for the purpose and segment**: Adapty Mail creates one, after the other flows of the purpose.
- **The flow runs another A/B test**: You can't launch the test. Finish the other test first.

### From a flow

1. In Adapty Mail, go to **Flows**. [Create a flow](mail-create-flow#create-a-flow), or open the flow of the test's segment and purpose.
2. Set **Content type** to **A/B Test** and select the draft test.
3. Click **Create** or **Save**.

The test's state moves from **draft** to **live**, and incoming users who match the segment start being routed to variations. Emails start going out at once.

## How routing works

When a user hits the flow's trigger and matches the A/B test's segment, Adapty Mail picks a variation using **weighted random** selection — each variation's weight determines its share of the draw. Routing is not deterministic per user.

## Read results

On the **Flows** page, the row of a flow with a live test adds up the numbers of all its variations.

To compare the variations, open the row menu of the test on the **A/B Tests** page, or of its flow on the **Flows** page, and select **View in analytics**. The Analytics page opens with one group for each variation, for the period that the test ran.

On the **A/B Tests** page, each test is one row. The row adds up the numbers of all its variations since the test started:

- **Sent**: Emails that Adapty Mail sent.
- **Rates**: The first three rates of your project, in the order of the rate list. To change them, see [Change the rates](mail-analytics#change-the-rates).
- **Revenue**: Attributed revenue.

<ZoomImage id="mail-ab-tests-list.webp" width="700px" alt="A/B Tests page with one row per test: Sent, the Open rate, Click rate, and Conversion rate columns, and Revenue" />

[Campaign analytics](mail-analytics) covers what each metric counts and how revenue is attributed.

## Finish the test

1. In Adapty Mail, go to **Flows**, open the row menu of the flow that runs the test, and select **Finish A/B test**. You can also click **Finish A/B test** on the flow's page, or **Finish** on the **A/B Tests** page.
2. In the **Finish A/B test** dialog, select the **Winner**: the campaign that goes on sending on this flow. To stop sending to the segment, select **No winner, remove the flow** instead.
3. Click **Finish**.

<ZoomImage id="mail-ab-testing-finish.webp" width="400px" alt="The Finish A/B test dialog with a campaign selected in the Winner dropdown" />

:::note
Users who are already mid-sequence in any variation — winning or losing — keep receiving their scheduled emails. They aren't switched to the winner.
:::

## Lifecycle

An A/B test moves through four states:

- **Draft**: Created, not yet launched.
- **Live**: Launched on a flow; routing incoming users.
- **Finished**: Stopped with **Finish A/B test**, or its flow was deleted.
- **Archived**: Soft-deleted from the list.
