An A/B test in Adapty Mail compares two or more full email campaigns against each other. Each variation is a complete, independent campaign. When a user enters a [flow](mail-flows) that runs the test, Adapty Mail routes them to one of the variations using the configured weights and tracks delivery, engagement, and revenue per variation.

:::tip
An AI assistant connected to the [Adapty Mail MCP server](mail-mcp) can create a test, launch it on a flow, read the funnel per variation, and finish it with the winner. It asks for your approval before it launches or finishes the test.
:::

## What a variation is

Each variation is a full campaign. Variations can differ in copy, hero images, tone, sequence length, or delay timing between emails. Each variation has its own [translations](mail-localization). For a fair comparison, localize every variation into the same languages.

Variations can't differ in who receives them, or in what starts their sequence. One segment covers the whole test. Every campaign in it shares one [purpose](mail-purposes) — the situation its emails are written for, named the same way as the [purpose of a flow](mail-flows#purposes). The purpose decides which flows the test can run on.

You write each campaign separately, then add them as variations.

## Create an A/B test

1. Create the campaigns first in **Campaigns**. Each variation needs its own campaign, and they all need the same purpose.
2. In Adapty Mail, go to **A/B Tests** and click **Create**.
3. Add each campaign as a variation and set its weight. Weights must total **100%**.
4. Assign a segment. When you launch the test from the **A/B Tests** page, it runs on the flow of this segment and purpose.
5. Click **Create**.

The test is saved as a **draft** and doesn't send anything yet. To go live, launch it.

## Launch the test

A test runs on one flow of its purpose. Launched from the **A/B Tests** page, it runs on the flow of its own segment, and Adapty Mail creates that flow if there's none. Picked on a flow, it runs on that flow's segment instead, whatever segment you saved in the test.

Whichever way you launch it, the test goes from **draft** to **live**. From then on, users who enter the flow are routed to variations. The first email follows after its [**Delay**](mail-flows#email-delivery-timing).

### From the A/B Tests page

1. In Adapty Mail, go to **A/B Tests**.
2. Open the row menu of the draft test and select **Launch**. Or open the test, save any changes, and click **Launch**.
3. Read the **Launch A/B test** dialog, then click **Launch**.

<ZoomImage id="mail-ab-testing-launch.webp" width="400px" alt="The Launch A/B test dialog, saying that a flow for the Never purchased purpose and the test's segment will be created" />

The dialog tells you what happens to the flow:

- **The flow exists and sends a campaign**: The test replaces the campaign.
- **There is no flow for the purpose and segment**: Adapty Mail creates one, after the other flows of the purpose. If a flow before it has a broader segment, [move the new flow up](mail-create-flow#change-the-order-of-flows), or the test gets no users.
- **The flow runs another A/B test**: You can't launch the test. Finish the other test first.

### From a flow

1. In Adapty Mail, go to **Flows**. [Create a flow](mail-create-flow#create-a-flow) of the test's purpose, or open one.
2. Set **Content type** to **A/B Test**. In the **A/B Test** field, select the draft test. The list offers every draft test of the purpose.
3. Click **Create** for a new flow, or **Save** for an existing one.

:::note
The test runs on this flow's segment, whatever segment you saved in it. To run it on its own segment, launch it from the **A/B Tests** page.
:::

## How routing works

When a user enters the flow that runs the test, Adapty Mail picks a variation using **weighted random** selection — each variation's weight determines its share of the draw. Routing is not deterministic per user.

## Read results

To pick a winner, compare the variations in Analytics. On the **A/B Tests** page, open the test's row menu and select **View in analytics**. The flow's row menu on the **Flows** page has the same **View in analytics** option. The Analytics page opens with one group for each variation, for the period that the test ran. Give users in every variation time to receive the whole sequence before you decide.

The **Flows** and **A/B Tests** pages show the test's totals, not who is ahead. On the **Flows** page, the row of the flow adds up **Sent** and the rates of all variations. On the **A/B Tests** page, each test has one row, which adds up all its variations since the test started:

- **Sent**: Emails that Adapty Mail sent.
- **Rates**: The first three rates of your project, in the order of the rate list. To change them, see [Change the rates](mail-analytics#change-the-rates).
- **Revenue**: Attributed revenue.

<ZoomImage id="mail-ab-tests-list.webp" width="700px" alt="A/B Tests page with one row per test: Sent, the Open rate, Click rate, and Conversion rate columns, and Revenue" />

[Campaign analytics](mail-analytics) covers what each metric counts and how revenue is attributed.

## Finish the test

:::warning
In the **Finish A/B test** dialog, **Winner** starts at **No winner, remove the flow**. If you leave it there, Adapty Mail deletes the flow. The flows after it move up, and new users of the segment enter the next flow that has them in its segment, if any.
:::

1. In Adapty Mail, go to **Flows**. Open the row menu of the flow that runs the test and select **Finish A/B test**.

   You can also start from these places:
   - **The flow's edit page**: Click **Finish A/B test**.
   - **The A/B Tests page**: In the test's row menu, select **Finish**. A live test's own page also has **Finish**.

2. In the **Finish A/B test** dialog, in **Winner**, select the campaign that the flow sends after the test. The flow keeps its place in the order.
3. Click **Finish**.

<ZoomImage id="mail-ab-testing-finish.webp" width="400px" alt="The Finish A/B test dialog with a campaign selected in the Winner dropdown" />

:::note
Users who are already mid-sequence in any variation — winning or losing — keep receiving their scheduled emails. They aren't switched to the winner.
:::

## Lifecycle

An A/B test moves through four states:

- **Draft**: Created, not launched.
- **Live**: Launched on a flow and routing incoming users.
- **Finished**: Stopped from the **Finish A/B test** dialog, or by deleting its flow.
- **Archived**: Deleted with **Delete** in the row menu of a draft or finished test. A live test can't be deleted. Finish it first.
