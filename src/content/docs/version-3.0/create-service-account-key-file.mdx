The key file is the service account's credential. Adapty uses it to sign in as that account and call Google's APIs on your behalf.

## Before you start

- **Previous step**: [Grant permissions to the service account](grant-permissions-to-service-account)
- **Why**: The service account needs Play Console access to be useful.

## Generate the key file

1. Open [**IAM & Admin** > **Service accounts**](https://console.cloud.google.com/iam-admin/serviceaccounts) in Google Cloud Console, and make sure you're in the right project.

2. Click the service account you created.

3. Open the **Keys** tab, then click **Add key** > **Create new key**.

   <ZoomImage id="gp-keys-add-key.webp" width="700px" alt="Keys tab of a service account in Google Cloud Console, with the Add key menu open" />

4. Leave **Key type** set to **JSON** and click **Create**. The file downloads to your computer.

   <ZoomImage id="gp-create-json-key.webp" width="700px" alt="Create private key dialog with JSON selected as the key type" />

Store the file somewhere safe. Google won't let you download it again, and anyone who has it can act as the service account.

## Activate the account immediately

A new service account takes about 24 hours to activate, and until it does, Adapty can't read your products. To skip the wait, in [Google Play Console](https://play.google.com/console/) go to **Monetize with Play** > **Products** > **Subscriptions**, then edit and save the description of any product. You can revert the edit straight away.

<ZoomImage id="gp-edit-product-description.webp" width="700px" alt="Subscription details page in Google Play Console with the Description field" />
