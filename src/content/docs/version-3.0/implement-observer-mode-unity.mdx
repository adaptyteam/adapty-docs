If you already have your own purchase infrastructure and aren't ready to fully switch to Adapty, you can explore [Observer mode](observer-vs-full-mode). In its basic form, Observer Mode offers advanced analytics and seamless integration with attribution and analytics systems.

If this meets your needs, you only need to:
1. Turn it on when configuring the Adapty SDK by setting the `observerMode` parameter to `true`. Follow the setup instructions for [Unity](sdk-installation-unity#activate-adapty-module-of-adapty-sdk).
2. [Report transactions](report-transactions-observer-mode-unity) from your existing purchase infrastructure to Adapty.

:::tip
In SDK v4, you can also present Adapty-rendered flows and paywalls in Observer mode: implement `IAdaptyUIObserverModeResolver` and register it with `SetObserverModeResolver` to perform the purchase or restore with your own code when a user taps the corresponding button. See [Present flows in Observer mode](unity-present-flows-in-observer-mode).
:::

### Observer mode setup

Turn on the Observer mode if you handle purchases and subscription status yourself and use Adapty for sending subscription events and analytics.

:::important
When running in Observer mode, Adapty SDK won't close any transactions, so make sure you're handling it.
:::

:::note
In SDK 4.1, listener interfaces follow the C# I-prefix convention — implement `IAdaptyEventListener` instead of `AdaptyEventListener` — and the interface requires one more method, `OnReceivePromotedPurchase`. See the [migration guide](migration-to-unity-sdk-v4).
:::

```csharp showLineNumbers title="C#"
using UnityEngine;
using AdaptySDK;

public class AdaptyListener : MonoBehaviour, AdaptyEventListener {
    void Start() {
        DontDestroyOnLoad(this.gameObject);
        Adapty.SetEventListener(this);

        var builder = new AdaptyConfiguration.Builder("YOUR_PUBLIC_SDK_KEY")
            .SetObserverMode(true); // Enable observer mode

        Adapty.Activate(builder.Build(), (error) => {
            if (error != null) {
                // handle the error
                return;
            }
        });
    }

    public void OnLoadLatestProfile(AdaptyProfile profile) { }
    public void OnInstallationDetailsSuccess(AdaptyInstallationDetails details) { }
    public void OnInstallationDetailsFail(AdaptyError error) { }
}
```

Parameters:

| Parameter    | Description                                                                                         |
|--------------|-----------------------------------------------------------------------------------------------------|
| observerMode | A boolean value that controls [Observer mode](observer-vs-full-mode). The default value is `false`. |

## Using Adapty flows & paywalls in Observer Mode \{#using-adapty-paywalls-in-observer-mode\}

If you also want to use Adapty's flows, paywalls, and A/B testing features, you can — but it requires some extra setup in Observer mode. Here's what you'll need to do in addition to the steps above:

1. Display [remote config paywalls](present-remote-config-paywalls-unity) as usual. For flows & paywalls built in the Flow & Paywall Builder, see [Present flows in Observer mode](unity-present-flows-in-observer-mode).
2. [Associate flows & paywalls](report-transactions-observer-mode-unity) with purchase transactions.
