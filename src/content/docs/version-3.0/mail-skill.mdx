The adapty-mail skill runs your Adapty Mail project from your AI coding tool. It works through the [Adapty Mail MCP server](mail-mcp), signed in as you. It launches flows, translates campaigns, walks a sending domain through DNS and verification, reads campaign and A/B test results, and finds out why a person didn't get an email.

The MCP server alone gives your agent the tools. The skill adds what an agent gets wrong without it:

- **Connecting the server**: It verifies whether the server is connected and signed in. If it isn't, it gives you the setup step for your client.
- **Mail or the rest of Adapty**: Flows, segments, and profiles mean different things in Adapty Mail and in Adapty's in-app paywalls. The skill settles which one you mean before it changes anything.
- **What only the dashboard does**: It tells you when a request needs your company address, the web checkout, or data sending turned on, and links the page that covers it.
- **The work after launch**: Results, A/B tests, deliverability, and tracing a missing email.

:::note
Nothing reaches real people without your yes. Saving a flow starts sending, and the segment list it saves replaces the whole flow, so the skill first shows the flow as it will be: every segment, every campaign, and anything removed. Deletes, unsubscribes, and A/B test launches and finishes wait for your yes too.
:::

## Install the skill

The adapty-mail skill is part of the [`adapty-skills` plugin](https://github.com/adaptyteam/adapty-skills).

<AdaptySkillsInstall />

The skill needs the Adapty Mail MCP server. If your agent doesn't have it yet, ask it to connect Adapty Mail. The skill gives you the command for your client, and you approve the connection in the Adapty Mail dashboard. The steps for every client are in [Manage Adapty Mail with AI assistants](mail-mcp#connect-your-assistant).

## How it works

1. **Connect.** The skill verifies that the MCP server answers and that you're signed in.
2. **Orient.** It finds your project and reads what is already set up: brand, company address, sending domain, campaigns, flows, and when data last arrived. It reuses what exists.
3. **Plan.** It names anything only you can do in the dashboard before it starts.
4. **Act.** It works through the server's tools and shows you each result. Anything that emails real people or can't be undone waits for your yes.

## Why an email didn't send

When you ask about one person, the skill reads the profile and the profile's journey, then goes through these reasons in order and stops at the first one that explains it:

1. The profile is suppressed: unsubscribed, bounced, complained, or failed address verification. See [Unsubscribe and suppression](mail-suppression).
2. The person is already in another marketing flow.
3. The person bought, so the sequence ended as designed.
4. Sending limits held the email during domain warm-up.
5. The trigger never fired. Either no purchase events reach Adapty Mail, or the profile arrived before setup was finished.
6. No segment in the flow matched the person.
7. Double opt-in is on and the person hasn't confirmed the address.
8. The email is still scheduled for the sending window in the person's time zone.
