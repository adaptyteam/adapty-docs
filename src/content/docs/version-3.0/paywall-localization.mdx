title: "Localization"
description: "Translate a flow's screens and its remote config values for every market you sell in."
metadataTitle: "Localization | Flows | Adapty Docs"
---

Add locales to a flow so each user reads their own language. You localize in two places:

1. [In the builder](add-paywall-locale-in-adapty-paywall-builder): translate the text and swap the media on every screen.
2. [In the remote config](add-flow-remote-config-locale): translate the values your app reads at runtime.

To control which translation the SDK shows, pass a locale when your app loads the view configuration. See [Localizations and locale codes](localizations-and-locale-codes).
