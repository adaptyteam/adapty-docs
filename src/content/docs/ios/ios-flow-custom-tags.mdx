A [custom tag](flow-custom-tags) is a kind of custom variable. After you select **Value comes from outside the app** in a variable's settings, your app can set its value through the Adapty SDK. For example, a text element contains "Coins:" and a custom tag. If your app passes 120 for the tag, users see "Coins: 120".

## Pass custom tag values

Pass your app's values to the `tagResolver` parameter of `getFlowConfiguration`, as a `[String: String]` dictionary:

- Each key is the full name of a custom tag, such as `user.streak`.
- Each value is the string that users see in place of the tag.
- Each value must be human-readable, such as "1,250", not "1250.0". Adapty doesn't format or translate it.

```swift showLineNumbers title="Swift"
let customTags = [
    "username": "DragonSlayer42",
    "coins": "1,250",
]

do {
    let flowConfiguration = try await AdaptyUI.getFlowConfiguration(
        forFlow: flow,
        tagResolver: customTags
    )
    // present the flow
} catch {
    // handle the error
}
```

The SwiftUI [`.flow` modifier and `AdaptyFlowView`](ios-present-paywalls#present-flows-and-paywalls-in-swiftui) and the UIKit [flow controller](ios-present-paywalls#present-flows-and-paywalls-in-uikit) have no parameter for custom tag values. They display the values from the flow configuration you give them.

### Pass the BMI to the paywall

Collect the weight and the height from the onboarding flow's `flow_user_input` events, as in [Process data from flows](ios-flow-input). When the user closes the onboarding flow, calculate the BMI. Then fetch the paywall's flow configuration, and pass the BMI for the `bmi` custom tag.

The following code is for UIKit. It implements the `AdaptyFlowControllerDelegate` methods on one view controller, which is the delegate of both the onboarding flow's controller and the paywall's controller.

```swift showLineNumbers title="Swift"
private var bodyAnswers: [String: String] = [:]

func flowController(
    _ controller: AdaptyFlowController,
    didReceiveAnalyticEvent name: String,
    params: [String: any Sendable]
) {
    guard name == "flow_user_input",
          let elementId = params["element_id"] as? String,
          let value = params["value"] as? String
    else { return }

    bodyAnswers[elementId] = value
}

func flowControllerDidDisappear(_ controller: AdaptyFlowController) {
    // Number inputs send their values as strings.
    guard let weight = bodyAnswers["weight"].flatMap({ Double($0) }),
          let height = bodyAnswers["height"].flatMap({ Double($0) }),
          height > 0
    else { return }

    // This delegate receives events from both flows. Clear the answers,
    // so that the paywall doesn't open again when the user closes it.
    bodyAnswers.removeAll()

    let heightInMeters = height / 100
    let bmi = weight / (heightInMeters * heightInMeters)

    Task {
        await showBMIPaywall(bmi: bmi.formatted(.number.precision(.fractionLength(1))))
    }
}

func showBMIPaywall(bmi: String) async {
    do {
        let flow = try await Adapty.getFlow(placementId: "bmi_paywall")
        let flowConfiguration = try await AdaptyUI.getFlowConfiguration(
            forFlow: flow,
            tagResolver: ["bmi": bmi]
        )
        let flowController = try AdaptyUI.flowController(
            with: flowConfiguration,
            delegate: self
        )
        present(flowController, animated: true)
    } catch {
        // handle the error
    }
}
```

`formatted` uses the decimal separator of the user's locale: "22.7" in English, "22,7" in German.

In SwiftUI, use the closures of the onboarding flow's `.flow` modifier instead of the delegate methods:

- `didReceiveAnalyticEvent`: Collect the answers.
- `didDisappear`: Calculate the BMI. Then fetch the paywall's flow configuration, and pass the BMI for the `bmi` custom tag. Present that configuration with a second `.flow` modifier.
