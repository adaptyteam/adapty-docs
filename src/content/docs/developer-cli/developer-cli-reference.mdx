The Adapty CLI groups its commands by topic, such as `products` or `placements`. Each topic has its own page with its commands, arguments, flags, and accepted values. This page lists the topics, the flags that every command accepts, and the command that installs the Adapty skills.

| Topic | Commands | What they do |
|---|---|---|
| [Apps and access levels](developer-cli-apps) | `apps`, `access-levels` | Create and configure apps and the subscription tiers your app checks |
| [Products and offers](developer-cli-products) | `products`, `product-offers` | Set up products, map them to App Store and Google Play product IDs, and link store offers to them |
| [Paywalls](developer-cli-paywalls) | `paywalls` | Create paywalls and assign products to them |
| [Flows](developer-cli-flows) | `flows` | Create flows, write and validate their builder configs, publish them, and read their metrics |
| [Placements and segments](developer-cli-placements) | `placements`, `segments` | Configure placements, their audiences, and the segments the audiences target. Read the metrics of flow placements |
| [Analytics](developer-cli-analytics) | `analytics` | Read charts, conversions, the funnel, retention, LTV, and cohorts |
| [A/B tests](developer-cli-ab-tests) | `ab-tests` | Create, start, stop, replace, and archive paywall and flow A/B tests |
| [Attribution](developer-cli-attribution) | `attribution` | Read spend, installs, revenue, and ROAS by channel and campaign |
| [Ads Manager](developer-cli-ads-manager-reference) | `asa` | Run Apple Ads campaigns, keywords, and automation rules |
| [Migrations](developer-cli-migrations) | `migrations` | Move a RevenueCat project to Adapty |
| [Authentication](developer-cli-authentication) | `auth` | Log in, check, and revoke your CLI session |

## Global flags

These flags are available on all commands.

| Flag | Description |
|---|---|
| `--json` | Output as JSON instead of formatted text |
| `--help` | Show command help |

All `list` commands except `adapty product-offers list` also accept pagination flags:

| Flag | Default | Description |
|---|---|---|
| `--page` | `1` | Page number |
| `--page-size` | `20` | Items per page (max: 100) |

## Skills

### adapty skills install

Install the Adapty skills into the coding agents on this machine.

```bash
adapty skills install
```

| Flag | Required | Description |
|---|---|---|
| `--agent` | No | Agent to install into: `claude-code`, `codex`, or `gemini-cli`. Repeat the flag for several agents. |
| `-y`, `--yes` | No | Install into every agent found without asking. Required when the CLI finds several agents and can't ask, for example with `--json`. |

The CLI looks for Claude Code, Codex, and Gemini CLI on `PATH`. If it finds none, it asks whether to run `npx skills@1.7.0 add adaptyteam/adapty-skills --all --global`, which covers other agents. Restart the agent to load the skills.

Claude Code doesn't update the plugin on its own. To get new skills as they ship, in Claude Code, run `/plugin`, open **Marketplaces**, select `adapty`, and choose **Enable auto-update**. To turn it on without the menu, add `"autoUpdate": true` to the `adapty` entry in `~/.claude/settings.json`:

```json title="~/.claude/settings.json"
{
  "extraKnownMarketplaces": {
    "adapty": {
      "source": { "source": "github", "repo": "adaptyteam/adapty-skills" },
      "autoUpdate": true
    }
  }
}
```

Skills installed through the skills CLI update with `npx skills update`. For Codex, see the [plugin README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#codex).
