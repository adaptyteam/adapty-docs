The **Adapty Developer CLI** is a command-line tool for managing your Adapty account without opening the Dashboard. It provides the main configuration capabilities, accessible from your terminal or automated environments.

<AIPromo id="adapty-mcp" title="Work from a chat instead of a terminal." cta="Connect the Adapty MCP server">
The Adapty MCP server gives the Claude app, Claude Code, Codex, and other MCP clients access to the same account. You sign in once in the browser, and there is nothing to install.
</AIPromo>

**What you can do with the CLI:**

- Create and configure iOS and Android apps in your Adapty account
- Define access levels — the subscription tiers your app checks at runtime
- Set up products and map them to App Store and Google Play store IDs
- Link store offers, Google Play free trials included, to products — see [Product offers](developer-cli-products#product-offers) in the command reference
- Create paywalls and assign products to them
- Create flows, write their builder configs, and publish them — see [Flows](developer-cli-flows) in the command reference
- Configure placements to fetch paywalls or flows via the SDK
- Read your app's analytics — revenue, MRR, conversions, the funnel, retention, LTV, and cohorts — through [Analytics](developer-cli-analytics)
- Create, start, stop, and replace paywall and flow A/B tests through [A/B tests](developer-cli-ab-tests)
- Run Apple Ads campaigns, keywords, and automation rules through [Ads Manager](developer-cli-ads-manager)
- Read Adapty Attribution reports — spend, installs, revenue, and ROAS by channel and campaign — through [Attribution](developer-cli-attribution)
- Migrate a RevenueCat project — its catalog, paywall designs, app code, and transaction history — see [Migration from RevenueCat](migration-from-revenuecat)
- Install the Adapty skills into your coding agents with `adapty skills install` — see [Skills](developer-cli-reference#skills) in the command reference
