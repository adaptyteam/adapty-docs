<Callout type="warning">

The `getFlowForDefaultAudience` method has two drawbacks:

- **Same flow for all app versions**: Older app versions may load a flow they can't display. If the flow uses a feature of a later Adapty SDK, [branch it by SDK version](flow-sdk-version-branching).
- **No targeting**: Every user sees the flow for the **All Users** audience, so you can't target by country, attribution, or custom attributes.

To avoid both, use [`getFlow`](#fetch-flowpaywall) instead.

</Callout>
