In the Flow & Paywall Builder, create the top-up flow. Add the flow to a [placement](placements) with the ID `out_of_diamonds`. When the balance is too low for a spend, the code in step 4 opens the flow from this placement.

To show a different top-up flow depending on the balance, add an [audience](audience) with a [segment by virtual currency balance](segments#virtual-currency-balance) to the `out_of_diamonds` placement. For example, show a separate flow to users with 0 diamonds. Adapty reads the balance each time your app code fetches the flow, so a spend or a purchase can change the flow that the user sees next.

To show the diamond balance in this flow too, [add a custom element](flow-custom-elements#add-and-configure) with the same Type and ID as in the out-of-energy flow: `currency_balance` and `diamonds`. Inside the custom element, add the diamond **Icon** as the fallback. Players see the same balance view in both flows, and you don't need to add code for it.
