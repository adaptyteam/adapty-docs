You need:

- **Adapty SDK v4 or later**: Versions before v4 don't display flows.
- **A flow with a custom tag in a text element**: [Create a custom tag](flow-custom-tags#create-a-custom-tag) in the builder, and [insert it into a text element](flow-custom-tags#add-a-custom-tag-to-a-text-element).
- **The full name of each custom tag**: For example, if the `user` group contains a `streak` tag, the tag's full name is `user.streak`.
