Users see a custom tag's **Initial value** as a fallback in the following cases:

- Your app passes no value for the tag.
- The user hasn't updated your app to a version that passes the value.
- The name in your app's code doesn't match the tag's full name, including letter case.
- Another custom tag in the same text element has no value. Then every custom tag in that text element shows its Initial value.

To show nothing in place of a tag, pass an empty string. Adapty treats an empty string as a value, so the fallback doesn't appear.
