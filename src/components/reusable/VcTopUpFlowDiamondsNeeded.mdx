To tell players how many more diamonds they need, use a [custom tag](flow-custom-tags): a placeholder that you insert into a text element. The code in step 3 passes the number to the tag once, when it opens the flow. The words around the number stay in the builder, where you can edit and translate them.

1. [Create a custom tag](flow-custom-tags#create-a-custom-tag) named `diamonds_needed`, and enter a dash (`—`) in its **Initial value** field. If your app code passes no number for the tag, players see the dash.
2. Add a text element with the words "You need more diamonds". After "need", [insert the `diamonds_needed` custom tag](flow-custom-tags#add-a-custom-tag-to-a-text-element).
