In the [event history](virtual-currency-balance#review-balance-changes-in-the-event-history) of the player, verify the following entries:

- **Virtual currency credited**: For each purchase or renewal that adds diamonds.
- **Virtual currency debited**: For each spend that goes through, with the `energy_refill` or `unlimited_energy` label.
- **Virtual currency expired**: For subscription diamonds that expire unspent.
