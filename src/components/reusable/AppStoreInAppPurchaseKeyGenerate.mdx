1. In App Store Connect, go to [**Users and Access** > **Integrations** > **In-App Purchase**](https://appstoreconnect.apple.com/access/integrations/api/subs).

   One key serves every app of your App Store Connect team. To reuse an active key from this page, you need its file. If you have it, skip steps 2-4. Active keys keep working when you generate a new one.

2. To generate a key, you need the Account Holder or Admin role in App Store Connect. Without either role, ask someone who has one to generate a key and send you the file with its Issuer ID and Key ID.

   If the page already lists active keys, click **+**. Otherwise, click **Generate In-App Purchase Key**.

   <ZoomImage id="asc-in-app-purchase-keys-add.webp" width="700px" alt="In-App Purchase keys page in App Store Connect, with the button that adds a key" />

3. Enter a name for the key, and click **Generate**. The key appears in the **Active** list.

   <ZoomImage id="asc-in-app-purchase-key-name.webp" width="700px" alt="Generate In-App Purchase Key dialog with a name for the key and the Generate button" />

4. You can only download each key once. Next to the new key, click **Download In-App Purchase Key**.

   <ZoomImage id="asc-in-app-purchase-key-download-link.webp" width="700px" alt="Active list of In-App Purchase keys, with the download link next to a new key" />

   Then, in the dialog, click **Download**. Keep the file secure: you upload it to each Adapty app that uses the key.

   <ZoomImage id="asc-in-app-purchase-key-download-dialog.webp" width="700px" alt="Download dialog for an In-App Purchase key" />
