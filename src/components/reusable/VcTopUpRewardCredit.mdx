To confirm the reward, use the server-side verification of your ad network: a request from your app code can't prove that the player watched the ad. When the confirmation reaches your backend, your backend adds the diamonds with [Create virtual currency transaction](api-adapty/operations/createVirtualCurrencyTransaction). Set the following values in the request:

- **`amount`**: A positive number, such as 5.
- **`operation`**: [`reward`](virtual-currencies#operation).
- **`feature`**: A label such as `rewarded_ad`.
- **`Idempotency-Key`**: A UUID v4 for each confirmed reward. To add the reward once, reuse the key for each retry of the request.
- **`reference_id`**: The reward ID from your ad network, to trace the transaction to the ad.

When your app code requests the balance after the ad, return the new balance, as for a spend.
