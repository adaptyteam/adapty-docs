In the Flow & Paywall Builder, create the out-of-energy flow. Add the flow to a [placement](placements) with the ID `out_of_energy`. When a player runs out of energy, the code in step 2 opens the flow from this placement.

To give players a way to close the flow without a spend, add a [**Close** button](basic-paywall-screen#3-add-the-close-button).
