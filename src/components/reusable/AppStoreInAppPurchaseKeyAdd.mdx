1. To find the **Issuer ID** and the **Key ID** of your key, in App Store Connect, go to [**Users and Access** > **Integrations** > **In-App Purchase**](https://appstoreconnect.apple.com/access/integrations/api/subs). If someone else generated the key and sent you its Issuer ID, Key ID, and file, skip this step.

   <ZoomImage id="asc-in-app-purchase-keys-ids.webp" width="700px" alt="Issuer ID and the Key ID of an In-App Purchase key in App Store Connect" />

2. In Adapty, go to [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). In the **In-app purchase API (StoreKit 2)** section, fill in the fields:
   - **Issuer ID**: Copy it from the **In-App Purchase** page in App Store Connect.
   - **Key ID**: Copy it from the **Active** list on the **In-App Purchase** page, next to the key you downloaded.
   - **Private key (.p8 file)**: Upload the file you downloaded.

   <ZoomImage id="app-settings-in-app-purchase-api.webp" width="700px" alt="Issuer ID, Key ID, and Private key (.p8 file) fields in the In-app purchase API (StoreKit 2) section in Adapty" />

3. Adapty signs [promotional offers](offers) with the In-App Purchase key. In the **App Store promotional offers** section, enter the key again:
   - **Subscription key ID**: The Key ID from step 2.
   - **Subscription key (.p8 file)**: The file from step 2.

   <ZoomImage id="app-settings-promotional-offers.webp" width="700px" alt="Subscription key ID and Subscription key (.p8 file) fields in the App Store promotional offers section" />

   A different key saves without an error, but users then can't receive promotional offers.

4. Click **Save**. Adapty verifies the key in the **In-app purchase API (StoreKit 2)** section with Apple before it saves the page. If Apple rejects the key, the page shows "The provided field values are incorrect": [review the values](troubleshoot-app-store-integration#the-provided-field-values-are-incorrect-when-saving-credentials).
