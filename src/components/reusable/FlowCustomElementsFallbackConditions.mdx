To show users the [fallback content](flow-custom-elements#set-fallback-content) instead of an empty custom element, return no view in the following situations:

- Nothing to visualize — the necessary animation file or data file is missing.
- Nothing to process — the user skipped a quiz question, and the data is incomplete.
- Access prohibited — a denied permission prevents the view from accessing a resource.

For example, the [resolver](#write-a-resolver-to-match-custom-elements-and-views) returns no view when the animation file is missing.
