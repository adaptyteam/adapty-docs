import ZoomImage from '../ZoomImage.astro';

1. In Adapty, open the app you're connecting: each Adapty app has its own notification URL. Go to [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). In the **App Store server notifications** section, copy the URL from the **URL for App Store server notifications** field.

   <ZoomImage id="app-settings-notifications-url.webp" width="700px" alt="URL for App Store server notifications in the App Store server notifications section in Adapty" />

2. In [App Store Connect](https://appstoreconnect.apple.com/apps), open the **App Information** page of your app.
3. In the **App Store Server Notifications** section, find **Production Server URL**. If a URL is already there, click **Edit**. Otherwise, click **Set Up URL**.

   <ZoomImage id="asc-server-notifications-set-up-url.webp" width="700px" alt="App Store Server Notifications section on the App Information page in App Store Connect" />

4. Paste the URL from Adapty, and click **Save**.

   <ZoomImage id="asc-server-url-set-up-dialog.webp" width="700px" alt="Production Server URL dialog in App Store Connect with the URL from Adapty" />

5. To have the notifications from your sandbox tests reach Adapty, repeat steps 3 and 4 for **Sandbox Server URL**.
