To install the plugin, in your terminal, run:

```bash
npx adapty skills install
```

Restart your agent to load the skills. For other installation methods, see the [plugin README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Claude Code doesn't update the plugin on its own. To get new skills as they ship, in Claude Code, run `/plugin`, open **Marketplaces**, select `adapty`, and choose **Enable auto-update**. For the update command in other agents, see the [plugin README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).
