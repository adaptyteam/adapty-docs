If you already installed the Adapty plugin, you have this skill. If your agent doesn't list it, update the plugin with the command for your agent in the [plugin README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

To install the plugin in a coding agent, in your terminal, run:

```bash
npx adapty skills install
```

Restart your agent to load the plugin. To install the plugin in claude.ai or Claude desktop, see [Install the plugin](manage-adapty-with-ai#install-the-plugin). For other installation methods, see the [plugin README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Claude Code doesn't update the plugin on its own. To get new skills as they ship, in Claude Code, run `/plugin`, open **Marketplaces**, select `adapty`, and choose **Enable auto-update**. For the update command in other agents, see the [plugin README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).
