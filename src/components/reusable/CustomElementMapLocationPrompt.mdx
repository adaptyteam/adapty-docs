To tell users why your app needs their location, ask for location access on a screen before the map:

1. In the Flow & Paywall Builder, add a screen before the screen with the map. On it, add a text that explains the request, such as "Find fitness centers near you," and a **Continue** button.
2. [Add an **On Tap** trigger](onboarding-actions#set-up-interactions) with the **Request permission** action to the **Continue** button.
3. From the **Permission** dropdown, select **Location while using the app**.

The default **After response** action is **Navigate Next**, so whether users grant location access or decline it, they go to the screen with the map. Users without location access see the fallback there. To skip the screen with the map for users who decline, add the **Navigate to Screen** action to **When denied**, and select the screen after the map.

To design the screen with the request, see [Add the request to a screen](flow-permissions#add-the-request-to-a-screen).
