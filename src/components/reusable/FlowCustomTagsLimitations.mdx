- **Text elements only**: You can only insert custom tags into text elements. You can't insert them into the following:
  - **Set variable** actions
  - **Show alert** actions
  - **Open URL** actions
  - Input placeholders
- **No conditions on custom tags**: You can't select a custom tag in a condition or in conditional visibility. To decide which sentence, elements, and screens users see based on a value from your app:
  - **Sentence**: Build the sentence in your app's code, and pass it as the tag's value. For example, for a `coins_message` tag, pass "You have 120 coins" to players with coins, and "Get your first coins" to the rest.
  - **Elements and screens**: Set the value as a custom attribute. Then show a separate flow to an [audience](audience) built from that attribute.
- **No SDK method to update the values in an open flow**: To show a result based on what users enter in a flow, pass the result to the next flow, as in the [BMI example](#example-show-a-bmi-from-onboarding-answers).
