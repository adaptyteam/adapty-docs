To show your app's values in a flow, set up custom tags in the builder:

1. [Create a custom tag](flow-custom-tags#create-a-custom-tag) for each value that your app passes.

   <ZoomImage id="flow-custom-tag-create.webp" width="500px" alt="Create variable form with a name, a description, the String value type, and an initial value" />

2. [Insert each tag into a text element](flow-custom-tags#add-a-custom-tag-to-a-text-element).
3. Note each tag's full name, including its group. Your app's code passes each value under this name. For example, if the `user` group contains a `streak` tag, the tag's full name is `user.streak`.

   <ZoomImage id="flow-custom-tag-full-name.webp" width="500px" alt="Custom tab of the Add variable dropdown with the streak tag in the user group" />
