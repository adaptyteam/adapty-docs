`access_level_updated` is a **webhook-only event**. Adapty never sends it to this integration. But Adapty records an outcome for every enabled integration, and an unsupported event counts as a failure. You'll see that line for every integration except the webhook. Adapty creates the event only when the webhook integration is enabled with **Access level updated** turned on. Ignore the line. Your integration is fine. To use this event, configure the [webhook integration](webhook).
