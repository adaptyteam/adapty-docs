The `adapty-integration` skill automates Adapty integration end to end: dashboard setup, SDK install, paywall, and per-stage verification. It detects your platform automatically and fetches the relevant Adapty docs at each stage. It works in any coding agent that supports skills: Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI, and others.

The skill is part of the [`adapty-skills` plugin](https://github.com/adaptyteam/adapty-skills). To install the plugin, in your terminal, run:

```bash
npx adapty skills install
```

Restart your agent to load the skills. For other installation methods, see the [plugin README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

To start the integration, in your agent, ask:

```
Integrate Adapty into my app
```

The skill asks a few setup questions, then walks through dashboard setup, SDK install, paywall, and verification.
