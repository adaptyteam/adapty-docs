The [adapty-integration skill](https://github.com/adaptyteam/adapty-skills) automates Adapty integration end to end: dashboard setup, SDK install, paywall, and per-stage verification. It detects your platform automatically and fetches the relevant Adapty docs at each stage. It works in any coding agent that supports skills: Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI, and others.

To install the skill, in your terminal, run:

```bash
npx adapty skills install
```

This installs `adapty-integration` along with the rest of the Adapty skills. Restart your agent to load them. For other installation methods, see the [plugin README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

To start the integration, in your agent, ask:

```
Integrate Adapty into my app
```

The skill asks a few setup questions, then walks through dashboard setup, SDK install, paywall, and verification.
