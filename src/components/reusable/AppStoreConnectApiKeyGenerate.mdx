1. In App Store Connect, go to [**Users and Access** > **Integrations** > **App Store Connect API**](https://appstoreconnect.apple.com/access/integrations/api), and open the **Team Keys** tab. Adapty needs a team key: individual keys have no Issuer ID.

   One team key serves every app of your App Store Connect team. If an active key on this tab has **Admin** access and you have its file, reuse it and skip steps 2-4.

   If your team doesn't have App Store Connect API access yet, the Account Holder [requests it](https://developer.apple.com/help/app-store-connect/get-started/app-store-connect-api). Apple reviews each request.

2. To generate a key, you need the Account Holder or Admin role in App Store Connect. Without either role, ask someone who has one to generate a key with **Admin** access and send you the file with its Issuer ID and Key ID.

   If the tab already lists active keys, click **+**. Otherwise, click **Generate API Key**.

   <ZoomImage id="asc-team-keys-add.webp" width="700px" alt="Team Keys tab of the App Store Connect API page in App Store Connect" />

3. Enter a name for the key, and set **Access** to **Admin**. **Access** determines what Adapty can do with the key, whatever your own role is. You can't change **Access** after you generate the key. Click **Generate**.

   <ZoomImage id="asc-team-key-generate-dialog.webp" width="700px" alt="Dialog for a new team key, with a name and the Access dropdown" />

4. You can only download each key once. Next to the new key, click **Download**. Keep the file secure: you upload it to each Adapty app that uses the key.

   <ZoomImage id="asc-team-key-download.webp" width="700px" alt="Active list of team keys, with the Download link next to a new key" />
