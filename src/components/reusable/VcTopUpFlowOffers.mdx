1. Add a [**Products** element](paywall-product-block#add-a-product-group) with the diamond packs. To start the purchase of a pack when a player taps its card, attach the [**Purchase** action to each card](paywall-product-block#trigger-purchase-from-a-product-card).
2. To offer the subscription on the same screen as the packs, add a [purchase button](paywall-product-block#add-a-purchase-button). In the **Purchase** action of the button, select the subscription from the **Product** dropdown. In the button text, insert the [`prod_price` and `prod_billing_period`](onboarding-variables#product-variables) variables of the subscription.
3. In a text element of each card, type how many diamonds the player receives, such as "500 diamonds". Add a text element for the subscription, and type how many diamonds the player receives for each billing period, such as "300 diamonds every month". Keep each number equal to the **Credit amount** or **Credit per cycle** of the product: no [product variable](onboarding-variables#product-variables) holds this number. If the name of each pack in the app store already includes the number, such as "500 Diamonds", insert the `prod_title` variable instead.
4. To give players a way to close the flow without a purchase, add a [**Close** button](basic-paywall-screen#3-add-the-close-button). Add the [footer links](basic-paywall-screen#9-add-footer-links): app stores require the Terms of Use and Privacy Policy links wherever players can buy a subscription.
