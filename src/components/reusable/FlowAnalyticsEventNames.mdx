The flow sends the following analytics events to your app:

| Event | The flow sends the event when |
|:--|:--|
| `flow_screen_showed` | The user opens a screen of the flow |
| `flow_user_input` | The user changes the value of an input or a selectable group |
| `flow_permission_requested` | The flow sends a permission request to your app |
| `flow_permission_answered` | Your app passes the result of a permission request to the flow |
| `flow_permission_unanswered` | Your app passes no result to the flow within 60 seconds after a permission request |
