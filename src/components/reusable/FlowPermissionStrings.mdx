Pass the string that matches the result:

- **With a granted result**: `granted`. Use `limited` if the user granted part of the access, such as a selection of photos. Use `provisional` for provisional authorization on iOS, such as quiet notifications or provisional Always location access.
- **With a not-granted result**: `denied`. Use `restricted` if a device policy, such as parental controls, blocks the permission. Use `permanently_denied` if the system no longer shows the dialog to the user.
- **For a permission your app doesn't request**: `unsupported`, with a not-granted result and no dialog.
- **When the user made no choice**: No string. For example, the user closed the dialog, or the OS reported no decision before the timeout in your code. The flow then runs the **After response** actions.

Pass the strings in lowercase, exactly as written. For a not-granted result with any other string, such as `Denied` or an error message, the flow runs the **After response** actions.
