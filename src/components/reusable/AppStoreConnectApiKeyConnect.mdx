1. To find the **Issuer ID** and the **Key ID** of your team key, in App Store Connect, go to [**Users and Access** > **Integrations** > **App Store Connect API**](https://appstoreconnect.apple.com/access/integrations/api), and open the **Team Keys** tab. If someone else generated the key and sent you its Issuer ID, Key ID, and file, skip this step.

   <ZoomImage id="asc-team-keys-ids.webp" width="700px" alt="Issuer ID and the Key ID of a team key on the Team Keys tab in App Store Connect" />

2. In Adapty, go to [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). In the **App Store Connect API key** section, click **Connect API Key**.

   <ZoomImage id="app-settings-connect-api-key.webp" width="700px" alt="App Store Connect API key section in Adapty, with the Connect API Key button" />

3. Fill in the fields:
   - **Issuer ID**: Copy it from the **Team Keys** tab in App Store Connect.
   - **Key ID**: Copy it from the **Active** list on the **Team Keys** tab, next to the key you downloaded.
   - **Private key (.p8 file)**: Upload the file you downloaded for the team key.

   <ZoomImage id="app-settings-api-key-dialog.webp" width="700px" alt="Issuer ID, Key ID, and Private key (.p8 file) fields in the window for the App Store Connect API key" />

4. You can replace a connected key later, but you can't remove it. Make sure the key comes from the App Store Connect team that owns this app, and click **Connect**. From then on, you select each **App Store Product ID** from your products in App Store Connect, rather than type it.

   Adapty doesn't verify the key with Apple when you connect it. A wrong key fails with no message about the key: products show no App Store status, and the **App Store Product ID** dropdown stays empty. To fix a wrong key, [replace it](app-store-connect-api-key#replace-the-key).
