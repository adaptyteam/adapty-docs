To show the diamond balance, use a [custom element](flow-custom-elements): an element where users see a native view from your app code. When your app code changes the balance while the flow is open, such as after a spend, users see the new balance.

1. [Add a custom element](flow-custom-elements#add-and-configure) to the screen, and enter its **Type** and **ID**:
   - **Type**: `currency_balance`.
   - **ID**: `diamonds`.

   The code in [step 2](#create-the-balance-view) matches the balance view to the custom element by this Type and ID.

   <ZoomImage id="vc-top-up-custom-element.webp" width="700px" alt="Custom element settings in the Flow & Paywall Builder, with currency_balance in the Type field, diamonds in the ID field, and an Icon inside the Diamond balance layer" />

2. Inside the custom element, add a diamond [**Icon**](custom-media#icon). In app versions without the balance view, users see the icon as the [fallback](flow-custom-elements#set-fallback-content).
