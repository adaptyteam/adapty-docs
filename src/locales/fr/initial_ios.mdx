Connectez votre application App Store à Adapty pour qu'il puisse valider les achats, recevoir les événements d'abonnement et lire vos produits depuis le store.

Chaque store est connecté séparément, et Adapty ne valide les achats que pour les stores que vous avez connectés. Si votre application est aussi disponible sur Google Play, [connectez-le également](initial-android) — les deux sont indépendants, et l'un n'accélère pas l'autre.

La configuration s'étend sur App Store Connect et l'Adapty Dashboard, et prend environ 30 minutes. L'onboarding intégré dans l'Adapty Dashboard couvre les mêmes étapes si vous préférez rester dans une seule fenêtre.

## Guide pour l'intégration initiale \{#guide-for-the-initial-integration\}

- [ ] Une fois votre compte Adapty créé et le nom et la catégorie de votre application mobile renseignés, nous configurons l'application pour vous sur notre plateforme Adapty.
- [ ] [Générer une clé d'achat intégré](generate-in-app-purchase-key) dans l'App Store Connect
- [ ] [Configurer l'intégration App Store](app-store-connection-configuration) dans l'Adapty Dashboard et l'App Store Connect
- [ ] Si votre application propose des essais ou d'autres offres promotionnelles, [configurez les offres promotionnelles App Store](app-store-connection-configuration#step-4-for-trials-and-special-offers--set-up-promotional-offers) dans l'Adapty Dashboard.
- [ ] [Activer les notifications serveur App Store](enable-app-store-server-notifications) dans l'App Store Connect
- [ ] Installez les SDK Adapty pour les frameworks que vous utilisez :
  - [ ] [Installer le SDK Adapty pour iOS natif](sdk-installation-ios)
  - [ ] [Installer le SDK Adapty pour React Native](sdk-installation-reactnative)
  - [ ] [Installer le SDK Adapty pour Flutter](sdk-installation-flutter)
  - [ ] [Installer le SDK Adapty pour Unity](sdk-installation-unity)
  - [ ] [Installer le SDK Adapty pour Kotlin Multiplatform](sdk-installation-kotlin-multiplatform)
- [ ] Compilez votre application et exécutez-la en mode sandbox.

Une fois l'intégration initiale terminée, vous pouvez [commencer à utiliser les fonctionnalités d'Adapty](product).

Gardez à l'esprit que pour que les paywalls et les produits s'affichent dans votre application mobile et que les analyses fonctionnent, vous devez apporter des modifications au code de votre application. Plus précisément, vous devez au minimum [afficher les paywalls](ios-quickstart-paywalls) et, si vous utilisez des paywalls non créés avec le Paywall Builder, [gérer le processus d'achat](making-purchases) dans votre application.

:::danger
Consultez la checklist de publication avant de publier votre application

Avant de publier votre application, assurez-vous de bien consulter la [Liste de contrôle de publication](release-checklist). Cela vous permettra de vérifier que toutes les étapes nécessaires ont été effectuées avant la mise en ligne de votre app avec le SDK Adapty.
:::
