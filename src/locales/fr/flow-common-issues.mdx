Cet article répertorie les problèmes les plus fréquemment rencontrés lors de la création d'un flow dans le [Flow Builder](adapty-flow-builder), avec leur cause et leur solution.

## Un flow ne peut pas être prévisualisé ou publié \{#a-flow-wont-preview-or-publish\}

<ZoomImage id="flow-publish-error.webp" width="300px" alt="Message d'erreur de publication dans l'interface web du Flow Builder lorsqu'un flow contient des actions incomplètes" float="right" />

Vous ne pouvez pas publier ni prévisualiser votre flow si l'un des problèmes suivants est présent.

- Une interaction avec une configuration incomplète. Cas fréquents :
    - Une action **Open URL** sans URL cible.
    - Une action **Navigate to screen** sans destination — se produit aussi lorsque l'écran de destination est supprimé après la configuration de l'action.
    - Une **action conditionnelle** sans opérateur ni valeur.
    - Une action **Set variable** sans assignation de variable/valeur.
    - Une action **Purchase** sans produit (store intégré) ou sans URL de Web Paywall (paiement web).
    - Une action **Custom** sans identifiant d'action (Action ID).
    - Une action **Show alert** avec un Titre ou un Message vide.
    - Une action **Show** ou **Hide** sans élément sélectionné.
    - Une action **Select product** sans produit cible — se produit aussi lorsque l'élément produit cible est supprimé, déplacé hors de son groupe de produits, ou laissé sur un autre écran.
    - Une action **Select product** enregistrée dans un composant réutilisable, ou ciblant un identifiant d'élément présent sur plusieurs écrans.
- Un **écran sans éléments**.
- Un élément produit **sans produit associé** — peut survenir si vous supprimez le produit référencé.
- Un JSON de **Remote Config** invalide bloque l'ensemble du processus de livraison — il est même impossible d'enregistrer le brouillon.

Pour détecter ces problèmes avant publication, [prévisualisez le flow dans l'application Adapty](paywall-device-compatibility-preview). Si le flow ne se charge pas, le message d'erreur vous donnera plus de détails.

## L'action Set variable ne change pas le produit sélectionné \{#a-set-variable-action-doesnt-change-the-selected-product\}

Le produit sélectionné n'est pas une variable que vous pouvez affecter, donc **Set variable** ne peut pas modifier la sélection. Utilisez l'action [**Select product**](onboarding-actions#select-product) à la place.

## Une image ou une vidéo ne se charge pas \{#an-image-or-video-wont-upload\}

Un fichier qui dépasse les limites de médias du Flow Builder ne sera pas chargé. Vérifiez le fichier par rapport aux exigences pour les [Images](custom-media#image) et les [Vidéos](custom-media#video) :

| Élément | Formats | Taille maximale | Autres limites |
| :--- | :--- | :--- | :--- |
| Image | `.JPG`, `.PNG`, `.WEBP` | 20 Mo | — |
| Vidéo | `.MP4`, `.WEBM` | 50 Mo | 30 secondes maximum ; 640×640 pixels minimum |

Ces formats ne sont pas pris en charge :

- **GIF animés et WEBP animés** : pour ajouter du mouvement, utilisez un élément Vidéo à la place.
- **SVG** : exportez le fichier en PNG ou WEBP. Pour les icônes, vous n'avez rien à uploader — l'élément Icône puise dans la bibliothèque [Tabler Icons](custom-media#icon) intégrée.
