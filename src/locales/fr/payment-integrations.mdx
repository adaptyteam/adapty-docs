Adapty prend en charge l'intégration avec des systèmes de paiement web pour vous aider à gérer les abonnements et les achats depuis votre application mobile et votre site web en un seul endroit. Cela vous permet de :

- Collectez les données d'abonnement provenant des achats intégrés et des achats sur votre site web dans un seul système
- Accordez l'accès aux fonctionnalités payantes de votre application mobile aux utilisateurs ayant acheté sur votre site web
- Consultez les analyses et les données d'abonnement de tous vos canaux de vente dans un seul tableau de bord

Intégrations disponibles :

- [Stripe](stripe)
- [Paddle](paddle)
- [FunnelFox](funnelfox)
