Adapty utilise la clé API App Store Connect pour gérer vos produits dans App Store Connect :

- [Créer des produits](create-product#create-product-and-push-to-store) et des groupes d'abonnements.
- Retrouver vos produits existants par ID lorsque vous ajoutez un produit dans Adapty.
- Afficher le statut App Store de chaque produit dans Adapty.
- Importer les prix quotidiennement et exporter les modifications de prix que vous effectuez dans Adapty.
- Suggérer des produits pour Switch Plan dans [Retention Messaging](retention-messaging-setup).

Adapty ne modifie App Store Connect que lorsque vous agissez dans Adapty, par exemple lors de la création d'un produit ou de la modification des prix. Pour afficher les statuts et importer les prix, il lit uniquement depuis App Store Connect.

Générez la clé dans l'onglet **Team Keys** d'App Store Connect, puis connectez-la dans **App settings** d'Adapty. Si la clé ne fonctionne plus ou doit être remplacée, [remplacez-la](#replace-the-key).

La clé API App Store Connect est différente de la [clé d'achat intégré](generate-in-app-purchase-key), même si App Store Connect utilise les libellés **Issuer ID** et **Key ID** pour les deux.

Pour saisir toutes les informations d'identification dans **App settings** > **iOS SDK** en une seule fois, suivez le guide [Configurer l'intégration App Store](app-store-connection-configuration).

## Remplacer la clé \{#replace-the-key\}

Si la clé ne fonctionne plus ou nécessite un paramètre **Access** différent, connectez une nouvelle clé dans Adapty avant de révoquer l'ancienne.

Sans clé fonctionnelle, Adapty ne peut pas :

- Créer des produits.
- Retrouver vos produits existants par ID.
- Synchroniser le statut et les prix des produits.

Une clé qui ne fonctionne plus apparaît toujours comme connectée dans Adapty. Les signes révélateurs sont [des produits sans statut App Store et un menu déroulant **App Store Product ID** vide](troubleshoot-app-store-integration#products-dont-appear-or-show-no-app-store-status).

Adapty n'affiche pas l'identifiant Key ID d'une clé connectée. Si vous ne savez pas quelle clé Adapty utilise, remplacez-la par une nouvelle clé.

Lorsque votre application passe sur un autre compte développeur Apple, [connectez une clé d'équipe du nouveau propriétaire](transfer-apps#app-store-ios-transfer).

Pour remplacer la clé :

1. [Générez une nouvelle clé d'équipe](#generate-a-team-key-in-app-store-connect).
2. Dans Adapty, allez dans [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). Dans la section **App Store Connect API key**, cliquez sur **Edit**. [Saisissez les valeurs de la nouvelle clé](#connect-the-key-in-adapty), puis cliquez sur **Save changes**.
3. Une clé d'équipe s'applique à toutes les applications de votre équipe App Store Connect. Si d'autres applications de votre équipe utilisent Adapty, connectez-y également la nouvelle clé. Remplacez l'ancienne clé sur tous vos serveurs qui l'utilisent.
4. Une clé révoquée cesse de fonctionner dans toutes les applications qui l'utilisent, et il est impossible de la restaurer. Si vous savez quelle clé la nouvelle remplace, rendez-vous dans App Store Connect et révoquez cette ancienne clé.
