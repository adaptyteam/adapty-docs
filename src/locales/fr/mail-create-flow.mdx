Dans Adapty Mail, un **flow** envoie une campagne ou un test A/B à un **segment** de vos utilisateurs. La **finalité** du flow correspond à l'étape du cycle de vie client qu'il couvre, comme un abonnement expiré ou un paiement échoué. Une finalité peut comporter plusieurs flows, un par segment, classés par ordre de priorité. La finalité définit également le **déclencheur** du flow : ce qui le démarre pour un utilisateur.

Ce guide explique comment créer, réordonner, modifier et supprimer des flows. Consultez [Flows](mail-flows) pour une vue d'ensemble des finalités, segments et priorités.

:::tip
Un assistant IA connecté au [serveur MCP Adapty Mail](mail-mcp) peut créer et réorganiser des flows pour vous. La création d'un flow déclenche l'envoi, alors lisez le plan de l'assistant avant de l'approuver. Le [skill Adapty Mail](mail-skill) affiche chaque modification avant de l'enregistrer.
:::

## Créer un flow \{#create-a-flow\}

:::important
Un flow n'a pas de brouillon. Il commence à envoyer dès que vous cliquez sur **Create**, à chaque utilisateur de son segment qui déclenche le trigger. Vérifiez la campagne au préalable et [testez le flow](mail-testing) avec un utilisateur de test.
:::

1. Dans Adapty Mail, accédez à **Flows**. Ouvrez l'onglet **Marketing** pour un flow marketing, ou l'onglet **Transactional** pour les messages de service.

   Pour l'objectif **Double opt-in**, activez plutôt le [double opt-in](mail-double-opt-in). Le paramètre crée le flow, et le désactiver supprime tous les flows Double opt-in, y compris ceux que vous avez créés ici.

2. Cliquez sur **Create**.
3. Dans la boîte de dialogue **New marketing flow** ou **New transactional flow**, sélectionnez l'objectif du flow, puis cliquez sur **Continue**. L'objectif détermine ce qui déclenche le flow et quelles campagnes il peut envoyer.

   <ZoomImage id="mail-flow-purpose-picker.webp" width="400px" alt="La boîte de dialogue New marketing flow avec les cinq objectifs marketing et Never purchased sélectionné" />

4. Sur la page **New Flow**, renseignez les champs :
   - **Segment** : Choisissez un segment, ou **All Users** pour toucher tout le monde. Un segment qui possède déjà un flow pour cet objectif affiche **(has a flow already)** et ne peut pas être sélectionné. Pour modifier ce que reçoit ce segment, [modifiez ce que son flow envoie](#change-what-a-flow-sends). Pour créer un nouveau segment, cliquez sur **Create segment** en bas de la liste. Lorsque vous créez un segment, une campagne ou un test A/B depuis ces listes, Adapty Mail conserve ce que vous avez saisi sur cette page et vous y ramène.
   - **Content type** : **Campaign** pour envoyer une campagne à tous les membres du segment, ou **A/B Test** pour répartir le segment entre les campagnes d'un test. Voir [Tests A/B](mail-ab-testing).
   - **Campaign** ou **A/B Test** : Sélectionnez ce que le flow envoie. La liste propose uniquement les campagnes correspondant à cet [objectif de campagne](mail-create-campaign), ou les tests A/B en brouillon avec cet objectif. Un test sélectionné s'exécute sur le segment de ce flow. Pour en créer un nouveau, cliquez sur **Create campaign** ou **Create A/B test** en bas de la liste.

   <ZoomImage id="mail-flow-create.webp" width="600px" alt="La page Nouveau Flow avec le but Jamais acheté, le segment Utilisateurs UE et une campagne sélectionnée" />

5. Cliquez sur **Create**.

Le flow est actif dès sa création. Les utilisateurs qui déclenchent l'événement et appartiennent au segment commencent à recevoir la campagne. Le premier e-mail arrive après son [**Delay**](mail-flows#email-delivery-timing).

Si le flow envoie un test A/B, celui-ci est activé à la création du flow.

Un nouveau flow est placé après les autres flows numérotés ayant le même objectif. Si un flow situé avant lui cible un segment plus large, ce flow capte tous les utilisateurs que le nouveau aurait dû recevoir, et le nouveau flow n'envoie rien. Pour corriger cela, [déplacez le nouveau flow vers le haut](#change-the-order-of-flows).

## Modifier l'ordre des flows \{#change-the-order-of-flows\}

Lorsqu'un objectif comporte plusieurs flows, Adapty Mail les évalue dans l'ordre de priorité et démarre le premier flow dont le segment correspond à l'utilisateur. La colonne **Priority** de la page **Flows** affiche cet ordre.

Pour modifier l'ordre :

1. Sur la page **Flows**, ouvrez l'onglet des flows, puis cliquez sur **Change order**. Le bouton est actif lorsqu'un objectif de cet onglet possède au moins deux flows en plus de son flow **All Users**.
2. Dans le menu déroulant **Purpose**, sélectionnez l'objectif.
3. Faites glisser les flows dans l'ordre souhaité.
4. Cliquez sur **Save**. Le bouton devient actif dès que vous avez déplacé un flow.

<ZoomImage id="mail-flow-change-order.webp" width="400px" alt="La boîte de dialogue Changer l'ordre pour le type Jamais acheté, avec deux flows numérotés et le flow Tous les utilisateurs en dernier" />

Dans la colonne **Priority**, un flow avec **All Users** affiche **Last**. Il reste toujours en dernier, car tous les utilisateurs appartiennent à son segment.

## Modifier ce qu'un flow envoie \{#change-what-a-flow-sends\}

1. Sur la page **Flows**, trouvez le flow. Dans sa ligne, cliquez sur le nom de la campagne ou du test dans la colonne **Content**, ou ouvrez le menu de la ligne et sélectionnez **Edit flow**.

   <ZoomImage id="mail-flow-row-menu.webp" width="700px" alt="The Flows page with the row menu of a flow open: Edit flow, View in analytics, Finish A/B test, and Delete" />

2. Modifiez le **Content type** et la **Campaign** ou l'**A/B Test**.
3. Cliquez sur **Save**. **Save** apparaît dès que le contenu diffère de ce que le flow envoie actuellement.

Les utilisateurs qui déclenchent le flow après l'enregistrement reçoivent la nouvelle campagne ou le nouveau test A/B. Les utilisateurs déjà engagés dans la séquence précédente continuent de recevoir ses e-mails. Les chiffres dans la ligne du flow repartent de zéro avec le nouveau contenu. Pour consulter les chiffres antérieurs, utilisez [Analytics](mail-analytics).

Tant qu'un flow exécute un test A/B en cours, son contenu est verrouillé et **Save** n'apparaît pas. Pour envoyer autre chose, [terminez le test](mail-ab-testing#finish-the-test) d'abord.

## Envoyer un flow vers un autre segment \{#send-a-flow-to-another-segment\}

Vous ne pouvez pas modifier la cible ou le segment d'un flow. Pour l'envoyer vers un autre segment, remplacez le flow :

1. [Créez un flow](#create-a-flow) avec le nouveau segment.
2. [Déplacez-le](#change-the-order-of-flows) juste avant l'ancien flow.
3. [Supprimez](#delete-a-flow) l'ancien flow.

Dans cet ordre, aucun utilisateur ne bascule vers un autre flow entre les deux. Si l'ancien flow exécute un test A/B en cours, sa suppression met fin au test.

## Supprimer un flow \{#delete-a-flow\}

1. Sur la page **Flows**, ouvrez le menu de ligne du flow et sélectionnez **Delete**.
2. Dans la boîte de dialogue **Delete flow**, cliquez sur **Delete**.

Quand vous supprimez un flow :

- **Utilisateurs qui déclenchent l'événement plus tard** : Ils entrent dans le flow suivant correspondant à leur segment, par exemple **All Users**, ou aucun s'ils n'appartiennent à aucun segment.
- **Priorité** : Les flows suivants remontent d'une place.
- **Utilisateurs déjà dans le flow** : Ils continuent de recevoir les e-mails programmés restants.
- **Un test A/B en cours** : Si le flow en exécute un, Adapty Mail le termine.
