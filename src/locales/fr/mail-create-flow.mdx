Dans Adapty Mail, un **flow** achemine les utilisateurs vers des campagnes lorsqu'un déclencheur se déclenche. Il est actif dès qu'il possède une ligne — il n'y a pas d'étape de lancement. Vous le configurez comme une liste de lignes priorisées dans une vue de déclencheur fixe, où chaque ligne indique un segment et la campagne qu'il reçoit. Ce guide explique comment ajouter, réorganiser, modifier et supprimer ces lignes. Pour les concepts sous-jacents aux déclencheurs, aux priorités et aux types de contenu, consultez [Flows](mail-flows).

## Ajouter une ligne \{#add-a-row\}

1. Dans Adapty Mail, accédez à **Flows** et ouvrez le déclencheur à configurer.
2. Cliquez sur **Create** pour ouvrir la boîte de dialogue.

   <ZoomImage id="create-flow-mail.webp" width="500px" alt="Boîte de dialogue de création de flow avec les champs Segment, Content type et Campaign" />

3. Dans la boîte de dialogue :
   - **Segment** : Sélectionnez un segment, ou **All Users** pour cibler tous les utilisateurs.
   - **Content type** : **Campaign** pour une seule campagne, ou **A/B Test** pour en comparer plusieurs — voir [test A/B](mail-ab-testing).
   - **Campaign** : Sélectionnez la campagne à envoyer.
   <ZoomImage id="mail-flow-details.webp" width="500px" alt="Flow details view with a prioritized list of segment-to-campaign rows" />

4. Cliquez sur **Save**.

La ligne est active immédiatement. Les utilisateurs qui déclenchent l'événement et correspondent au segment commencent à recevoir la campagne à partir de ce moment.

## Réorganiser les lignes \{#reorder-rows\}

Faites glisser la poignée à gauche d'une ligne pour modifier sa priorité. Adapty Mail attribue automatiquement `priority: 1, 2, 3…` selon l'ordre enregistré.

Une ligne **All Users** doit rester en dernière position — la déplacer au-dessus d'une autre ligne est bloqué à l'enregistrement.

## Modifier une ligne \{#edit-a-row\}

Cliquez sur **Change content** pour une ligne afin de rouvrir la boîte de dialogue avec ses valeurs actuelles pré-remplies. Vous pouvez modifier le segment, le type de contenu et la campagne, puis cliquer sur **Save** pour appliquer.

Une ligne utilisant un test A/B ne peut être modifiée que lorsque le test est à l'état **draft**. Une fois le test lancé, son contenu est verrouillé jusqu'à ce que vous le terminiez.

## Supprimer une ligne \{#delete-a-row\}

Ouvrez le menu d'actions de la ligne et cliquez sur **Delete**. Aucune confirmation n'est demandée — la ligne est supprimée immédiatement.

- **Lignes de campagne** : peuvent être supprimées à tout moment.
- **Lignes avec un test A/B actif** : impossible à supprimer. Terminez d'abord le test via **Finish A/B test**, puis supprimez la ligne.

:::note
Supprimer une ligne empêche les nouveaux utilisateurs d'entrer dans la séquence. Les utilisateurs déjà en cours de séquence peuvent continuer à recevoir leurs e-mails planifiés — il n'y a pas d'annulation automatique.
:::
