## Configuration \{#configuration\}

### Android

1. Ajoutez le fichier de configuration de secours à votre application. Choisissez l'un des répertoires suivants :
   * **android/app/src/main/assets/**
   * **android/app/src/main/res/raw/**

      Remarque : Le dossier `res/raw` suit une convention de nommage particulière (commence par une lettre, pas de majuscules, pas de caractères spéciaux à l'exception du trait de soulignement, et pas d'espaces dans les noms).

2. Mettez à jour la propriété `android` de la constante `FileLocation` :
   * Si le fichier se trouve dans le répertoire `assets`, indiquez le chemin du fichier relatif à ce répertoire.
   * Si le fichier se trouve dans le répertoire `res/raw`, indiquez le nom du fichier sans l'extension.

### iOS

1. Ajoutez le fichier JSON de secours à votre bundle de projet : ouvrez le menu **File** dans XCode et sélectionnez l'option **Add Files to "YourProjectName"**.
2. Passez le nom de votre fichier de configuration à la propriété `ios` de la constante `FileLocation`.

## Exemple \{#example\}

```typescript showLineNumbers
//after v3.8
const fileLocation = {
  ios: {
    fileName: 'ios_fallback.json'
  },
  android: {
    //if the file is located in 'android/app/src/main/assets/'
    relativeAssetPath: 'android_fallback.json'
  }
}
await adapty.setFallback(fileLocation);
```
