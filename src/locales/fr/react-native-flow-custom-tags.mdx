Un [tag personnalisé](flow-custom-tags) est une variable personnalisée dont la valeur provient de votre application. Après avoir sélectionné **Value comes from outside the app** dans les paramètres d'une variable, votre application peut définir sa valeur via le SDK Adapty. Par exemple, un élément texte contient « Coins : » et un tag personnalisé. Si votre application passe « 120 » pour ce tag, les utilisateurs voient « Coins : 120 ».

## Passer des valeurs de balises personnalisées \{#pass-custom-tag-values\}

Passez les valeurs de votre application dans le champ `customTags` des paramètres de la vue, sous forme d'objet. Avec le composant `AdaptyFlowView`, les paramètres correspondent à sa prop `params`. Avec `createFlowView`, il s'agit de son deuxième argument.

- Chaque clé est le nom complet d'une balise personnalisée, par exemple `user.streak`.
- Chaque valeur est la chaîne que les utilisateurs voient à la place de la balise.
- Chaque valeur doit être lisible par un humain, par exemple "1 250" et non "1250.0". Adapty ne la formate pas et ne la traduit pas.

`createFlowView` lit les valeurs une seule fois, lors de la création de la vue, elles ne changent donc pas pendant que le flow est ouvert. Si les `params` d'un `AdaptyFlowView` monté changent, le composant recrée la vue du flow, et le flow recommence depuis son premier écran. Gardez les `params` identiques pendant que le flow est ouvert.

```typescript showLineNumbers title="React Native (TSX)"

const flowParams = {
  customTags: {
    'username': 'DragonSlayer42',
    'coins': '1,250',
  },

function MyFlow({ flow }: { flow: AdaptyFlow }) {
  return <AdaptyFlowView flow={flow} params={flowParams} style={{ flex: 1 }} />;
}
```

### Transmettre l'IMC au paywall \{#pass-the-bmi-to-the-paywall\}

Récupérez le poids et la taille depuis les événements `flow_user_input` du flow d'onboarding, comme indiqué dans [Traiter les données des flows](react-native-flow-input). Pour savoir que l'utilisateur a atteint le dernier écran, attendez un événement `flow_screen_showed` avec `is_last_screen` défini à `true`, comme indiqué dans [Suivre les vues d'écran des flows](react-native-flow-screen-views). Lorsque l'utilisateur ferme le flow d'onboarding après cet écran, calculez l'IMC. Ensuite, créez la vue du paywall et transmettez l'IMC pour le tag personnalisé `bmi`.

Enregistrez les gestionnaires suivants sur `onboardingView`, la vue que `createFlowView` renvoie pour le flow d'onboarding. Le composant `AdaptyFlowView` ne dispose pas de gestionnaire `onDisappeared`, donc cet exemple ne fonctionne pas avec lui.

```javascript showLineNumbers title="React Native"

const bodyAnswers = {};
let reachedLastScreen = false;

const unsubscribe = onboardingView.setEventHandlers({
  onAnalytics(name, params) {
    if (name === 'flow_screen_showed' && params.is_last_screen) {
      reachedLastScreen = true;
    }
    if (name === 'flow_user_input' && typeof params.value === 'string') {
      bodyAnswers[params.element_id] = params.value;
    }
    return false; // keep the flow open
  },
  onDisappeared() {
    // Number inputs send their values as strings.
    const weight = Number(bodyAnswers.weight);
    const height = Number(bodyAnswers.height);
    const finished = reachedLastScreen;
    delete bodyAnswers.weight;
    delete bodyAnswers.height;
    reachedLastScreen = false;

    if (finished && weight > 0 && height > 0) {
      const heightInMeters = height / 100;
      const bmi = weight / (heightInMeters * heightInMeters);
      showBmiPaywall(bmi.toLocaleString(undefined, { maximumFractionDigits: 1 }));
    }
    return false;
  },
});

async function showBmiPaywall(bmi) {
  try {
    const flow = await adapty.getFlow('bmi_paywall');
    const view = await createFlowView(flow, { customTags: { 'bmi': bmi } });
    await view.present();
  } catch (error) {
    // handle the error
  }
}
```

`toLocaleString` utilise le séparateur décimal de la locale de l'utilisateur : « 22.7 » en anglais, « 22,7 » en allemand.

### Enregistrer l'IMC dans le profil de l'utilisateur \{#save-the-bmi-to-the-users-profile\}

Pour afficher différents flows aux utilisateurs selon leur IMC, enregistrez-le en tant qu'[attribut personnalisé](react-native-setting-user-attributes#custom-user-attributes) de leur profil. Dans l'Adapty Dashboard, [créez un attribut personnalisé de type **Number**](segments#custom-attributes) avec la clé `bmi`. Affichez ensuite chaque flow à une [audience](audience) définie à partir de cet attribut.

Appelez la méthode `updateProfile` dans `onDisappeared`, juste après la ligne qui calcule `bmi`. Passez ce nombre, et non la chaîne formatée, afin qu'un segment puisse comparer le BMI à un seuil. `onDisappeared` ne peut pas être `async`, gérez donc le résultat avec `.catch` plutôt qu'avec `await` :

```javascript showLineNumbers title="React Native"
adapty
  .updateProfile({ codableCustomAttributes: { bmi } })
  .catch((error) => {
    // handle the error
  });
```
