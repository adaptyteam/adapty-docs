Adapty lit vos produits, valide les achats et reçoit les événements d'abonnement via les API Google suivantes :

- Google Play Android Developer API
- Google Play Developer Reporting API
- Cloud Pub/Sub API

## Avant de commencer \{#before-you-start\}

Vérifiez que vous disposez des [droits d'accès et du projet Google Cloud requis par l'intégration Google Play](initial-android#before-you-start). Sans ceux-ci, vous ne pourrez pas effectuer les étapes ci-dessous.

## Activer les API \{#enable-the-apis\}

1. Ouvrez la [Google Cloud Console](https://console.cloud.google.com/).

2. Sélectionnez le projet que vous utiliserez pour l'intégration.

3. Ouvrez la page [**Google Play Android Developer API**](https://console.cloud.google.com/apis/library/androidpublisher.googleapis.com).

4. Cliquez sur **Enable** et attendez que le statut affiche **Enabled**. Si le bouton indique **Manage** à la place, l'API est déjà activée et il n'y a rien à faire.

   <ZoomImage id="gp-api-library-enable.webp" width="700px" alt="Une page d'API dans la bibliothèque d'API Google Cloud, avec le bouton Enable" />

5. Ouvrez la page [**Google Play Developer Reporting API**](https://console.cloud.google.com/apis/library/playdeveloperreporting.googleapis.com).

6. Cliquez sur **Enable** et attendez que le statut affiche **Enabled**.

7. Ouvrez la page [**Cloud Pub/Sub API**](https://console.cloud.google.com/apis/library/pubsub.googleapis.com).

8. Cliquez sur **Enable** et attendez que le statut affiche **Enabled**.

Pour vérifier, ouvrez la page [**APIs & Services**](https://console.cloud.google.com/apis/dashboard) dans Google Cloud Console. Le tableau en bas liste toutes les API activées dans le projet, et les trois doivent y apparaître :

- Google Play Android Developer API
- Google Play Developer Reporting API
- Cloud Pub/Sub API

<ZoomImage id="gp-apis-enabled-list.webp" width="700px" alt="Tableau des API et services activés répertoriant les trois API requises" />
