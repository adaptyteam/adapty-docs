description: "Pour les applications iOS, découvrez ce que contient chaque section de l'onglet iOS SDK dans les paramètres de l'application et comment les configurer."
metadataTitle: "Configuration des paramètres iOS dans Adapty | Documentation Adapty"
---

L'onglet [**iOS SDK**](https://app.adapty.io/settings/ios-sdk) dans **App settings** contient les identifiants App Store de votre application. Pour les renseigner tous, suivez le guide [Configurer l'intégration App Store](app-store-connection-configuration).

<ZoomImage id="app-settings-ios-sdk.webp" width="700px" alt="Onglet iOS SDK dans App settings" />

| Section | Ce qu'elle contient et pourquoi Adapty en a besoin | Où la configurer |
|---|---|---|
| **SDK status** | Indique si le SDK Adapty est installé dans votre application | [Installation du SDK Adapty](installation-of-adapty-sdks) |
| **Bundle ID** | Le Bundle ID de votre application, pour traiter les achats | [Saisir le Bundle ID et l'Apple App ID](app-store-connection-configuration#enter-the-bundle-id-and-apple-app-id) |
| **In-app purchase API (StoreKit 2)** | La clé In-App Purchase, pour valider les achats | [Ajouter la clé In-App Purchase à Adapty](generate-in-app-purchase-key) |
| **App Store Connect shared secret** | Le secret partagé spécifique à l'application, pour valider les reçus d'achat et créer des produits dans App Store Connect | [Saisir le secret partagé spécifique à l'application](app-store-connection-configuration#enter-the-app-specific-shared-secret) |
| **App Store server notifications** | L'URL qui reçoit les événements d'abonnement d'Apple, et une URL optionnelle de votre serveur vers laquelle Adapty les transfère | [Activer les notifications serveur App Store](enable-app-store-server-notifications) |
| **Apple Retention Messaging API** | L'URL que vous soumettez à Apple lorsque vous demandez l'accès à l'API Retention Messaging | [Configurer le Retention Messaging](retention-messaging-setup) |
| **App Store promotional offers** | L'ID et le fichier de la clé In-App Purchase, pour signer les offres promotionnelles | [Ajouter la clé In-App Purchase à Adapty](generate-in-app-purchase-key) |
| **App Store Connect API key** | Une clé de l'onglet **Team Keys** dans App Store Connect, pour créer des produits et synchroniser leur statut et leurs prix | [Ajouter la clé API App Store Connect à Adapty](app-store-connect-api-key) |
| **Apple App ID** | L'Apple ID de votre application, pour trouver et créer des produits dans App Store Connect, entre autres usages | [Saisir le Bundle ID et l'Apple App ID](app-store-connection-configuration#enter-the-bundle-id-and-apple-app-id) |
