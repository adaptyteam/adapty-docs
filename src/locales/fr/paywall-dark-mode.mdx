Quand l'appareil de l'utilisateur est en mode sombre, votre flow peut adapter ses couleurs et ses arrière-plans en conséquence — afficher un dégradé plus sombre ou une image adaptée au thème. Pour configurer cela, vous utilisez des [styles](builder-reusable-styles#color-styles) avec une version distincte pour chaque thème — clair et sombre.

Chaque version est un remplissage : une couleur unie, un dégradé, une image ou une vidéo. Un seul remplissage peut combiner plusieurs éléments : une couche de couleur semi-transparente peut teinter l'image en dessous. Si les deux thèmes sont identiques, les deux versions peuvent l'être aussi.

Il vous suffit d'appliquer le style à un élément, et le flow utilise automatiquement la bonne version selon le mode de l'appareil.

<ZoomImage id="builder-dark-mode-demo.webp" width="600px" alt="Un écran prévisualisé en mode clair et sombre côte à côte" />

## Ajouter un thème sombre \{#add-a-dark-theme\}

Par défaut, un nouveau flow utilise un thème clair. Pour ajouter un thème sombre :

1. Ouvrez le panneau **Styles** <Inline id="styles.svg" alt="Styles" /> et sélectionnez l'onglet **Colors**.
2. Cliquez sur l'icône <Inline id="settings.svg" alt="Color theme actions" /> pour ouvrir le menu de gestion des thèmes.
3. Sélectionnez **Add dark theme**. La variante sombre est ajoutée à chaque style de couleur, avec deux valeurs identiques. Vous pouvez maintenant [configurer le thème sombre](#configure-the-dark-theme).

<ZoomImage id="add-dark-theme.webp" width="500px" alt="L'onglet Couleurs du panneau Styles avec le menu de thème ouvert, révélant l'option de menu Ajouter un thème sombre" />

## Configurer le thème sombre \{#configure-the-dark-theme\}

Après avoir ajouté le thème sombre, chaque entrée de la liste Color Style dispose de deux paramètres spécifiques au thème : **Light** et **Dark**.

Pour modifier un style :

1. Ouvrez le panneau **Styles** <Inline id="styles.svg" alt="Styles" />
2. Sélectionnez l'onglet **Colors**.
3. Cliquez sur une entrée de style. Si le style nécessaire n'existe pas encore, [créez-en un nouveau](builder-reusable-styles#create-a-color-style).
4. La valeur Light et la valeur Dark sont listées l'une après l'autre. Chaque valeur peut contenir plusieurs [couches](builder-reusable-styles#multi-layer-styles). Cliquez sur l'échantillon pour définir la couche selon son type de remplissage :
    - [Couleur unie](builder-reusable-styles#solid-colors)
    - [Dégradé](builder-reusable-styles#gradients)
    - [Image ou vidéo](builder-reusable-styles#images-and-videos)
5. Cliquez sur **Save**.

<ZoomImage id="edit-style-image.webp" width="600px" alt="Le formulaire Modifier le style avec une image différente dans les sections Light et Dark, ainsi que le sélecteur d'image de l'image Dark" />

Les valeurs Light et Dark peuvent utiliser [différents types de remplissage](#mix-and-match-fill-types).

### Combiner différents types de remplissage \{#mix-and-match-fill-types\}

Vous pouvez combiner librement les types de remplissage entre les deux versions d'un style :

- **Couleurs unies, dégradés et images** : Dans n'importe quelle combinaison. Par exemple, un arrière-plan peut être une couleur unie en mode clair et une image en mode sombre.
- **Vidéos** : Si la version claire inclut une vidéo, la version sombre doit également inclure une vidéo — et vice versa. Les deux vidéos peuvent être différentes.

## Appliquer le thème à un élément \{#apply-the-theme-to-an-element\}

Si la propriété d'un élément n'utilise pas de style de couleur, le thème sombre ne s'y applique pas. Les éléments Image et Vidéo n'ont pas de style de couleur : pour changer leur fichier en mode sombre, [ajoutez un fichier sombre](#show-a-different-image-or-video-in-dark-mode).

Pour qu'un élément suive le thème, cliquez sur la pastille de sa couche de remplissage, de sa couleur de texte, de sa couleur de bordure ou de sa couleur d'icône. Remplacez la valeur statique par le style en cliquant sur l'onglet **Styles** et en sélectionnant l'entrée de style. Si aucun style ne correspond à la valeur dont vous avez besoin, [enregistrez la valeur actuelle en tant que style](builder-reusable-styles#create-a-color-style).

L'arrière-plan d'un écran suit le thème de la même façon : appliquez le style à sa couche de remplissage dans [**Screen settings**](paywall-layout-and-products#screen-background). Pour les étapes, consultez [Afficher un arrière-plan différent en mode sombre](paywall-head-picture#show-a-different-background-in-dark-mode).

Pour [appliquer un style](builder-reusable-styles#apply-a-color-style) à de nombreux éléments d'un écran, demandez à l'[éditeur IA](flow-ai-editor), par exemple : `Apply the Card background style to all cards`.

## Prévisualiser le flow en mode sombre \{#preview-the-flow-in-dark-mode\}

Cliquez sur les icônes de thème sous le canvas pour basculer entre <Inline id="dark-mode.svg" alt="Dark theme" /> **Dark mode** et <Inline id="light-mode.svg" alt="Light theme" /> **Light mode**.

Ces icônes n'apparaissent que si le flow possède un thème sombre, ou un élément Image ou Vidéo avec un fichier sombre.

<ZoomImage id="dark-mode-preview.webp" width="500px" />

## Afficher une image ou vidéo différente en mode sombre \{#show-a-different-image-or-video-in-dark-mode\}

Un élément Image ou Vidéo affiche son fichier dans les deux modes jusqu'à ce que vous ajoutiez un fichier pour le mode sombre. Pour afficher un fichier différent en mode sombre :

1. Sélectionnez l'élément Image ou Vidéo.
2. Dans la section **Image** ou **Video** du panneau de propriétés, sélectionnez l'onglet <Inline id="dark-mode.svg" alt="Moon" /> **Dark**. Le canevas bascule vers l'aperçu en mode sombre.
3. Importez le fichier pour le mode sombre.

<ZoomImage id="image-dark-file.webp" width="320px" alt="The Image section of an Image element with the Dark tab selected and a dark-mode image uploaded" />

Pour modifier à nouveau le fichier en mode clair, sélectionnez l'onglet <Inline id="light-mode.svg" alt="Sun" /> **Light**.

## Définir le thème de la barre d'état \{#set-the-status-bar-theme\}

Les icônes d'heure et de batterie dans la barre d'état peuvent entrer en conflit avec les couleurs de votre flow dans l'un des modes. Pour garder les icônes lisibles, définissez le **Status bar theme** dans [**Screen settings**](paywall-layout-and-products#screen-settings) lorsque le commutateur **Status bar** est activé :

- <Inline id="light-mode.svg" alt="Sun" /> : Icônes blanches, pour un fond sombre dans les deux modes.
- <Inline id="dark-mode.svg" alt="Moon" /> : Icônes noires, pour un fond clair dans les deux modes.
- <Inline id="portrait.svg" alt="Phone" /> : Icônes qui suivent le paramètre de l'appareil, pour un fond clair dans un mode et sombre dans l'autre.

<ZoomImage id="status-bar-theme.webp" width="500px" />

## Supprimer un thème \{#delete-a-theme\}

1. Ouvrez le panneau **Styles** <Inline id="styles.svg" alt="Styles" /> et sélectionnez l'onglet **Colors**.
2. Cliquez sur l'icône de paramètres <Inline id="settings.svg" alt="Color theme actions" /> pour ouvrir le menu de gestion des thèmes.
3. Sélectionnez un élément du menu :
    - **Delete Dark theme** : conserve la version claire de chaque style de couleur pour les deux modes.
    - **Delete Light theme** : conserve la version sombre de chaque style de couleur pour les deux modes.
