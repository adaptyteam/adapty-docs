Le serveur MCP d'Adapty connecte un assistant IA à votre compte Adapty. Posez des questions sur les revenus et les conversions, configurez des produits et des placements, publiez des flows ou lancez un test A/B depuis un chat, en langage naturel. L'assistant se connecte avec votre compte Adapty dans le navigateur et obtient vos permissions. Aucune clé API n'est nécessaire.

| | |
|---|---|
| Server URL | `https://mcp.adapty.io/mcp` |
| Protocol | MCP over Streamable HTTP, OAuth 2.1 sign-in in the browser |
| Works with | claude.ai, Claude desktop, Claude Code, Codex, and other MCP clients that support OAuth sign-in |

:::important
Le serveur MCP donne à votre assistant l'accès à votre compte Adapty. Pour lui transmettre le savoir-faire — les règles de configuration des flows, les méthodes éprouvées pour vos analytics, et une confirmation avant chaque étape qui touche vos utilisateurs — installez d'abord le [plugin Adapty](manage-adapty-with-ai#install-the-plugin). Dans Claude Code et Codex, le plugin ajoute ce serveur automatiquement, vous n'avez donc qu'à [vous connecter](#connect-your-assistant).
:::

## Ce que l'assistant peut faire \{#what-the-assistant-can-do\}

Les outils du serveur suivent l'Adapty Dashboard et le [CLI Développeur Adapty](developer-cli). L'assistant choisit les outils adaptés à votre demande ; vous n'avez pas à les nommer.

| Domaine | Ce que l'assistant peut faire | Exemple de question |
|---|---|---|
| Applications et niveaux d'accès | Lister, créer et mettre à jour des applications et des niveaux d'accès | « Crée un niveau d'accès `premium` dans Fitness Pro. » |
| Produits et offres | Créer des produits avec leurs identifiants store et lier des offres store à ces produits | « Lesquels de mes produits n'ont pas d'identifiant Google Play ? » |
| Paywalls | Créer et mettre à jour des paywalls, et trouver les placements qui les affichent | « Quels placements affichent le paywall Annual sale ? » |
| Flows | Créer des flows, lire et écrire leurs configurations builder, valider, prévisualiser, publier et lire les métriques de flow | « Publie le flow Onboarding v2 et dis-moi quels placements l'affichent. » |
| Placements et audiences | Créer des placements, gérer qui voit quoi, et lire les métriques des placements de flow | « Qui voit quoi sur le placement `onboarding` ? » |
| Segments | Lire les segments et leurs filtres | « Liste mes segments et les filtres appliqués à chacun. » |
| Tests A/B | Créer, démarrer, arrêter, remplacer et archiver des tests A/B de paywalls et de flows | « Lance le test en brouillon Weekly vs annual pour les utilisateurs en Allemagne. » |
| Analytics | Lire les revenus, le MRR, les conversions, le funnel, la rétention, la LTV et les cohortes d'installation | « Compare le taux de conversion essai-vers-payant par pays pour le mois dernier. » |
| Migration depuis RevenueCat | Créer et exécuter une migration du catalogue RevenueCat vers une nouvelle application Adapty | « Transfère mon projet RevenueCat vers une nouvelle application Adapty. » |

Adapty Mail possède son propre serveur MCP. Pour connecter un assistant à votre projet Adapty Mail, consultez [Gérer Adapty Mail avec des assistants IA](mail-mcp).

## Choisir entre le serveur MCP et la CLI \{#choose-the-mcp-server-or-the-cli\}

Le serveur MCP et l'[Adapty Developer CLI](developer-cli) accèdent au même compte Adapty. Si aucun n'est configuré, le plugin Adapty vous demande lequel installer et vous guide pas à pas. Si les deux sont disponibles, il choisit l'un ou l'autre selon la tâche :

| | Serveur MCP Adapty | CLI Adapty |
|---|---|---|
| Fonctionne dans | Tout client MCP, y compris claude.ai et Claude desktop | Les agents qui exécutent des commandes terminal, et vos propres scripts |
| Connexion | Une fois par client, dans le navigateur | `adapty auth login`, une fois par machine |
| Idéal pour | Questions et modifications depuis un chat | Modifier les configs de flow, modifications en masse, et scripts |
| Installation | Rien à installer | `npm install -g adapty` |

Dans claude.ai et Claude desktop, le serveur MCP nécessite moins de configuration que le CLI : le CLI doit être installé et autorisé dans chaque conversation, comme le décrit [Configurer le CLI Adapty dans l'application Claude](developer-cli-cowork).

<Details summary="Quels skills utilisent le serveur MCP et lesquels utilisent le CLI">

Avant sa première étape, chaque skill détecte si votre assistant dispose du serveur MCP, du CLI, ou des deux. Avec l'un d'eux, le skill l'utilise. Avec les deux, le skill utilise celui qui convient le mieux à son travail :

- **Serveur MCP** : Lancer des tests A/B, intégrer le SDK, et tester des achats.
- **Adapty CLI** : Créer et auditer des flows, identifier ce qu'il faut tester ensuite, déplacer des placements vers des flows, et créer des segments. Ces skills exécutent leurs propres scripts et fichiers, et la CLI leur transmet directement les fichiers.

</Details>

## Avant de commencer \{#before-you-start\}

- **Compte Adapty** : L'assistant agit au sein des entreprises et applications accessibles depuis votre compte Adapty, avec vos permissions.
- **Client MCP avec OAuth** : Votre client prend en charge les serveurs MCP distants qui s'authentifient via OAuth.

:::warning
L'assistant agit avec vos droits, et ses modifications sont réelles. Un test A/B démarré ou un placement modifié touche vos utilisateurs. Avant que l'assistant démarre ou arrête un test A/B, ou modifie qui voit quoi sur un placement, le serveur lui demande de décrire l'effet exact et d'attendre votre confirmation. Lisez le plan avant de l'approuver.
:::

## Connectez votre assistant \{#connect-your-assistant\}

<Tabs groupId="mcp-client" queryString>
<TabItem value="claude-app" label="claude.ai" default>

claude.ai et Claude desktop ajoutent des serveurs MCP distants en tant que connecteurs personnalisés.

1. Pour ajouter le serveur, ouvrez **Settings → Connectors** et cliquez sur **Add custom connector**.
2. Saisissez un nom, par exemple `Adapty`, et l'URL `https://mcp.adapty.io/mcp`.
3. Conservez les paramètres d'authentification par défaut et cliquez sur **Add**.
4. Connectez-vous à Adapty dans l'onglet du navigateur qui s'ouvre. Voir [Se connecter](#sign-in).

Les administrateurs de l'espace de travail peuvent ajouter le connecteur une seule fois pour toute l'organisation. Chaque membre se connecte ensuite avec son propre compte Adapty la première fois qu'il l'utilise.

</TabItem>
<TabItem value="claude-code" label="Claude Code">

Si vous avez installé le plugin Adapty, Claude Code répertorie déjà le serveur sous `plugin:adapty-skills:adapty`, avec le statut **Needs authentication**. Pour vous connecter, exécutez `/mcp` dans Claude Code, sélectionnez `plugin:adapty-skills:adapty`, puis choisissez **Authenticate**.

Sans le plugin, ajoutez d'abord le serveur :

```bash
claude mcp add --transport http --scope user adapty https://mcp.adapty.io/mcp
```

Ensuite, lancez `/mcp` dans Claude Code, sélectionnez `adapty` et choisissez **Authenticate**. Si les outils Adapty n'apparaissent pas dans la session en cours, démarrez une nouvelle session.

</TabItem>
<TabItem value="codex" label="Codex">

Si vous avez installé le plugin Adapty, le plugin ajoute le serveur et Codex vous demande de vous connecter lors de la connexion.

Sans le plugin, ajoutez le serveur et connectez-vous :

```bash
codex mcp add adapty --url https://mcp.adapty.io/mcp
codex mcp login adapty
```

La commande de connexion ouvre votre navigateur. Pour configurer le serveur manuellement, ajoutez-le dans `~/.codex/config.toml`, puis lancez la commande de connexion :

```toml
[mcp_servers.adapty]
url = "https://mcp.adapty.io/mcp"
```

Démarrez une nouvelle session `codex` pour charger les outils Adapty.

</TabItem>
<TabItem value="other" label="Autres clients">

Ajoutez `https://mcp.adapty.io/mcp` en tant que serveur MCP distant dans les paramètres de votre client ou dans son fichier de configuration MCP. Le client ouvre votre navigateur pour la connexion lors de la première connexion.

Le serveur identifie chaque client par son Client ID Metadata Document, la méthode d'enregistrement client de la spécification MCP actuelle. Un client qui ne prend pas en charge cette méthode ne peut pas finaliser la connexion. Dans ce cas, utilisez le [CLI développeur Adapty](developer-cli-quickstart) depuis un agent terminal à la place.

</TabItem>
</Tabs>

## Se connecter \{#sign-in\}

Chaque client aboutit au même endroit : la page de connexion Adapty dans votre navigateur.

1. Connectez-vous avec votre compte Adapty, si ce n'est pas déjà fait.
2. Autorisez le client à accéder à votre compte Adapty.

Le client peut alors lire et modifier les données des entreprises accessibles depuis votre compte, et il reste connecté jusqu'à ce que vous le déconnectiez. N'approuvez que les connexions que vous avez initiées vous-même.

Pour vérifier la connexion, demandez à l'assistant à quel compte Adapty il est connecté. La réponse doit mentionner votre nom et les entreprises accessibles depuis votre compte.

## Commencer à travailler \{#start-working\}

Demandez à l'assistant quelles applications il peut voir, puis nommez l'application sur laquelle travailler. Quelques requêtes à essayer :

```text
List my Adapty apps and their placements.
How did revenue and new subscriptions change last month compared with the month before?
Which products in Fitness Pro have no App Store product ID?
Show who sees what on the onboarding placement, including any A/B test.
Create a draft A/B test on main_paywall: the current paywall against Annual sale, 50/50.
```

Le assistant demande une confirmation avant les étapes qui modifient ce que les utilisateurs voient. Une demande qui ne fait que lire des données s'exécute sans questions.

Après une tâche de plusieurs étapes, le assistant peut envoyer à l'équipe Adapty une courte note sur le déroulement de la tâche. La note ne contient aucune donnée personnelle des utilisateurs de votre application.

## Déconnexion \{#disconnect\}

Pour vous déconnecter, supprimez le serveur dans le client :

- **claude.ai** : Dans **Settings → Connectors**, supprimez le connecteur Adapty.
- **Claude Code** : Exécutez `claude mcp remove adapty`. Si le serveur provient du plugin Adapty, désactivez-le plutôt dans `/mcp`.
- **Codex** : Supprimez le serveur `adapty` de `~/.codex/config.toml`.

Pour vous reconnecter, ajoutez à nouveau le serveur et connectez-vous.

## Dépannage \{#troubleshooting\}

| Problème | Solution |
|---|---|
| Claude Code affiche le serveur comme **Needs authentication** | Le client a ajouté le serveur mais ne s'est pas connecté. Exécutez `/mcp`, sélectionnez le serveur Adapty et choisissez **Authenticate**. |
| Le client ne liste aucun outil Adapty | Terminez la connexion, puis démarrez une nouvelle session. Certains clients ne chargent les outils qu'au début d'une session. |
| L'assistant ne trouve pas une application | L'application appartient à une entreprise à laquelle votre compte Adapty n'a pas accès. Demandez l'accès à un propriétaire de l'entreprise. |
| Le client ne peut pas terminer la connexion | Le client ne prend pas en charge la méthode de connexion utilisée par le serveur. Connectez-vous depuis claude.ai, Claude Code ou Codex, ou utilisez le [CLI développeur Adapty](developer-cli-quickstart). |
