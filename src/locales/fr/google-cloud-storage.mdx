Activez l'intégration Google Cloud Storage pour stocker en toute sécurité les [événements d'abonnement](events) et les [données de visites des paywalls](paywall-metrics) dans un emplacement central : votre bucket Google Cloud Storage.

Chaque jour à 4h UTC, Adapty téléverse des fichiers .csv avec les données de la veille dans vos buckets. Vous pouvez choisir de recevoir les données d'**événements**, les données de **visites de paywall**, ou **les deux**. Vous pouvez également exporter ces données [manuellement](#manual-data-export) à tout moment, pour n'importe quelle période.

Pour configurer l'intégration, [générez une clé d'accès au bucket](#create-google-cloud-storage-credentials) dans votre console Google Cloud, puis [ajoutez-la à vos paramètres Adapty](#set-up-google-cloud-storage-integration).

## Calendrier et durée des téléversements \{#upload-schedule-and-duration\}

Adapty téléverse les données vers Google Cloud Storage toutes les 24 heures, à 04:00 UTC.

Les fichiers contiennent les données des événements créés au cours de la journée calendaire précédente (UTC). Le fichier téléversé le 8 mars contiendra tous les événements créés le 7 mars, de 00:00:00 à 23:59:59 UTC.

Le processus peut prendre plusieurs heures, selon le nombre total de fichiers dans la file d'attente ainsi que le volume de données que vous avez demandées. Si Adapty inclut des données historiques dans votre premier téléversement, celui-ci prendra plus de temps que les téléversements quotidiens suivants.

## Configurer l'intégration Google Cloud Storage \{#set-up-google-cloud-storage-integration\}

Vous devez disposer d'une clé de compte de service Google Cloud valide avec un accès en **écriture**. Pour la générer, suivez les étapes de la section [créer des identifiants](#create-google-cloud-storage-credentials).

:::warning
Vous pouvez utiliser différents buckets avec des identifiants différents pour les événements et les visites de paywall. Cependant, si **l'un ou l'autre** ensemble d'identifiants est invalide, [**les deux envois échoueront**](#troubleshooting).
:::

Accédez à [**Integrations** -> **Google Cloud Storage**](https://app.adapty.io/integrations/google-cloud-storage) et ouvrez l'onglet souhaité (**Events** ou **Paywall visits**). Activez l'intégration.

Importez le fichier contenant votre **clé de compte de service Google Cloud**. Indiquez le **bucket** et le **dossier** cibles. Enregistrez vos modifications.

## Créer des identifiants Google Cloud Storage \{#create-google-cloud-storage-credentials\}

Ce guide vous aidera à créer les identifiants nécessaires dans votre Console Google Cloud Platform.

Pour qu'Adapty puisse téléverser des rapports de données brutes dans votre bucket désigné, la clé du compte de service est requise, ainsi que l'accès en écriture au bucket correspondant. En fournissant la clé du compte de service et en accordant l'accès en écriture au bucket, vous permettez à Adapty de transférer de manière sécurisée et efficace les rapports de données brutes depuis sa plateforme vers votre environnement de stockage.

:::warning
Veuillez noter que nous prenons uniquement en charge l'autorisation par clé HMAC de compte de service. Il est donc essentiel de vous assurer que votre clé HMAC de compte de service dispose des rôles « Storage Object Viewer », « Storage Legacy Bucket Writer » et « Storage Object Creator » pour permettre un accès correct à Google Cloud Storage.
:::

1. Pour commencer, rendez-vous dans la section [IAM](https://console.cloud.google.com/projectselector2/iam-admin/serviceaccounts) de votre compte Google Cloud et sélectionnez le projet concerné ou créez-en un nouveau.

<ZoomImage id="30a81ef-CleanShot_2023-03-17_at_15.22.142x.webp" width="700px" />


1. Ensuite, créez un nouveau compte de service pour Adapty en cliquant sur le bouton **+ CREATE SERVICE ACCOUNT**.

    <ZoomImage id="98f8ebf-CleanShot_2023-03-17_at_15.40.062x.webp" width="700px" />

2. Remplissez les champs de la première étape — les accès seront configurés plus tard. Pour en savoir plus sur cette page, consultez la documentation [ici](https://docs.cloud.google.com/iam/docs/service-accounts-create).

    <ZoomImage id="2190c50-CleanShot_2023-03-17_at_15.48.552x.webp" width="700px" />

3. Pour créer et télécharger une [clé JSON privée](https://docs.cloud.google.com/iam/docs/keys-create-delete), accédez à la section KEYS et cliquez sur le bouton « ADD KEY ».

    <ZoomImage id="8a45468-CleanShot_2023-03-17_at_15.58.092x.webp" width="700px" />

4. Dans la section DETAILS, repérez la valeur Email associée au compte de service que vous venez de créer et copiez-la. Vous en aurez besoin dans les étapes suivantes pour autoriser le compte et lui permettre d'écrire dans le bucket.

    <ZoomImage id="6ccd0f0-CleanShot_2023-03-17_at_16.03.162x.webp" width="700px" />
    

5. Pour continuer, rendez-vous sur la page [Buckets](https://console.cloud.google.com/storage/browser) de Google Cloud Storage et sélectionnez un bucket existant ou créez-en un nouveau pour stocker les rapports Event ou Visits Data provenant d'Adapty. Accédez ensuite à la section PERMISSIONS et sélectionnez l'option [GRANT ACCESS](https://docs.cloud.google.com/identity/docs/how-to?hl=en).

    <ZoomImage id="3cdd937-CleanShot_2023-03-17_at_16.14.232x.webp" width="700px" />

6. Dans la section PERMISSIONS, saisissez l'e-mail du compte de service obtenu à la cinquième étape mentionnée précédemment, puis choisissez le rôle Storage Object Creator. Enfin, cliquez sur SAVE pour appliquer les modifications.


    <ZoomImage id="62801f4-CleanShot_2023-03-17_at_16.17.312x.webp" width="700px" />

    N'oubliez pas de noter le nom du bucket pour une utilisation ultérieure.

## Exportation manuelle des données \{#manual-data-export\}

En plus de l'exportation automatique des données d'événements vers Google Cloud Storage, Adapty propose également une fonctionnalité d'exportation manuelle de fichiers. Cette fonctionnalité vous permet de sélectionner un intervalle de temps spécifique pour les données d'événements et de les exporter manuellement vers votre bucket GCS. Vous gardez ainsi un meilleur contrôle sur les données exportées et sur le moment où vous les exportez.

La plage de dates spécifiée sera utilisée pour exporter les événements créés depuis la date A à 00:00:00 UTC jusqu'à la date B à 23:59:59 UTC.

<ZoomImage id="e347308-CleanShot_2023-03-17_at_17.39.452x.webp" width="700px" />

## Structure des données \{#data-structure\}

Adapty utilise des fichiers `.csv` pour exporter les données dans un format tabulaire.

:::warning
Le contenu des événements peut évoluer au fil du temps, avec de nouvelles données introduites par nos soins ou par les tiers avec lesquels nous travaillons. Assurez-vous que le code qui traite ces données est suffisamment robuste et s'appuie sur des champs spécifiques, et non sur la structure dans son ensemble.
:::

## Dépannage \{#troubleshooting\}

Adapty vérifie la validité de vos clés d'accès **avant** de lancer l'upload. Si même une seule de vos clés Google Cloud Storage est invalide, Adapty **annule l'upload** et renvoie une erreur.

Pour garantir des uploads sans interruption, remplacez vos clés avant leur expiration. Si vous mettez à jour la clé pour les **événements**, n'oubliez pas de mettre à jour la clé pour les **visites de paywall**, et vice versa.
