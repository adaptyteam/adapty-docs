L'intégration de l'attribution Adapty avec TikTok for Business vous permet de suivre et d'optimiser les performances de vos campagnes sur TikTok.

:::tip
Consultez notre [guide de configuration des publicités dans TikTok for Business](tiktok-create-campaign).
:::

## Étape 1. Connecter votre compte TikTok \{#step-1-connect-your-tiktok-account\}

1. Accédez à **Integrations > TikTok Ads** depuis la barre latérale gauche et cliquez sur **Continue with TikTok**.

<ZoomImage id="ua-connect-tiktok.webp" width="700px" />

2. Connectez-vous avec votre compte TikTok et cliquez sur **Continue**.

3. Vérifiez les autorisations demandées et cliquez sur **Save**.

<ZoomImage id="ua-tiktok-sign.webp" width="500px" />

Ensuite, tous vos comptes publicitaires seront ajoutés à Adapty Attribution. Vous pouvez alors passer à l'ajout de campagnes.

## Étape 2. Ajouter des campagnes \{#step-2-add-campaigns\}

Pour ajouter une campagne TikTok for Business à Adapty Attribution et suivre les performances de vos publicités TikTok dans Adapty :

1. Passez sur l'onglet **Web Campaigns** et cliquez sur **Create configuration**.

<ZoomImage id="ua-new-campaign-tiktok.webp" width="500px" />

2. Dans l'onglet **General**, développez la section **iOS** et/ou **Android** et collez les URLs de l'application App Store et/ou Google Play.

<ZoomImage id="ua-url.webp" width="900px" />

3. Copiez la valeur du champ **Click link**. Ensuite, dans TikTok Ads Manager, lors de la création de votre publicité, collez cette valeur dans le champ **Tracking URL** dans la section **Advanced Settings**. Cela permettra à Adapty de relier les installations et les achats aux publicités sur TikTok.

<ZoomImage id="ua-lnk.webp" width="900px" />

4. (Facultatif) Pour renvoyer les événements de conversion vers TikTok, vous pouvez également associer vos pixels TikTok à des campagnes dans Adapty Attribution. Pour ce faire, sélectionnez l'un de vos pixels existants dans le menu déroulant **Pixel**. Après avoir sélectionné un pixel, vous pouvez cliquer sur **Send test event** pour vérifier la connexion.

Si vous acquérez des utilisateurs via un funnel web, l'onglet **General** comprend également une section **Web funnel** avec le snippet de pixel et les paramètres d'URL publicitaires. Pour le configurer, consultez [Configurer le pixel web Adapty](ua-web-pixel).

## Étape 3. Mapper les événements \{#step-3-map-events\}

Pour renvoyer des événements de conversion à TikTok afin d'optimiser vos campagnes, vous devez configurer le mappage des événements dans la section **Events names**. Cela permet à Adapty d'envoyer automatiquement les événements d'abonnement à votre pixel TikTok lorsque les utilisateurs effectuent des actions dans votre application.

Dans la section **Events names**, activez les événements que vous souhaitez suivre dans TikTok Ads Manager. Pour chaque événement activé, sélectionnez l'événement TikTok correspondant dans la liste déroulante ou définissez-en un personnalisé. Par défaut, Adapty associe les événements Adapty aux événements standard de TikTok.

Cliquez sur **Save** pour appliquer votre configuration de mappage d'événements.

<ZoomImage id="ua-meta-events.webp" width="900px" />

## Configuration supplémentaire \{#additional-configuration\}

### Paramètres supplémentaires \{#additional-parameters\}

Le champ **Additional parameter** vous permet d'ajouter des données personnalisées pour une analyse en dehors d'Adapty. C'est utile lorsque vous avez besoin de transmettre des données spécifiques de campagne ou d'utilisateur à des outils d'analyse externes ou à des partenaires d'attribution.

Dans le champ **Additional parameter**, saisissez les données personnalisées que vous souhaitez inclure dans votre suivi d'attribution. Le paramètre supplémentaire sera inclus dans toutes les données d'attribution envoyées à TikTok et peut être utilisé pour une analyse et une optimisation avancées des campagnes.

Par exemple, si vous exécutez plusieurs variations de la même campagne, vous pouvez ajouter `variant=A` ou `variant=B` pour distinguer les différentes approches créatives.

:::important
Les paramètres supplémentaires modifient le **Click link** que vous collez dans TikTok Ads Manager. Si vous avez déjà copié ce lien et ajouté un paramètre personnalisé ensuite, assurez-vous de copier-coller le lien mis à jour qui contient ce paramètre.
:::

### Paramètres \{#settings\}

L'onglet **Settings** contrôle la façon dont Adapty associe les actions des utilisateurs à vos campagnes TikTok Ads. Ces paramètres définissent les fenêtres temporelles pour la correspondance d'attribution déterministe et probabiliste.

Pour les configurer, rendez-vous dans l'onglet **Settings** de la configuration de votre campagne. Vous y trouverez deux paramètres principaux à ajuster :

- **Fenêtre de correspondance déterministe** : utilise des identifiants d'appareil exacts (comme l'IDFA sur iOS ou l'Advertising ID sur Android) pour associer les utilisateurs aux campagnes avec une grande précision. Réglez-la sur 168 heures (7 jours) pour une précision d'attribution maximale — c'est la valeur par défaut et recommandée. Lorsqu'un utilisateur clique sur votre publicité TikTok et installe votre application dans cette fenêtre, Adapty peut attribuer définitivement l'installation à ce clic précis grâce aux identifiants d'appareil.

- **Probabilistic matching window** : Cette option utilise la modélisation statistique et le device fingerprinting pour associer les utilisateurs quand le matching déterministe n'est pas possible. Réglez-la sur 6 heures pour la plupart des campagnes — c'est la valeur par défaut et elle convient à la majorité des cas d'usage. Pour les campagnes à fort volume de clics, vous pouvez la réduire à 1-2 heures. Pour les utilisateurs qui ne peuvent pas être associés de façon déterministe (en raison des paramètres de confidentialité ou d'autres facteurs), Adapty utilise le matching probabiliste dans cette fenêtre plus courte.

Cliquez sur **Save** pour appliquer vos paramètres.

<ZoomImage id="ua-meta-attribution-settings.webp" width="900px" />

### Remplacement du revenu \{#revenue-override\}

Si vous suivez les événements d'essai et souhaitez que TikTok leur attribue un revenu, utilisez la section **Revenue override**. Elle apparaît lorsque l'événement **Trial started** est activé. Le remplacement s'applique uniquement à **Trial started** — **Trial converted** et **Subscription started** transmettent toujours leur revenu réel.

Pour chaque cible d'événement d'essai, définissez le pourcentage du prix de l'abonnement à déclarer comme revenu. Par exemple, à 30 %, Adapty envoie 30 % du prix de l'abonnement comme valeur de conversion pour les événements d'essai.

Pour ajouter un remplacement :

1. Activez **Trial started** dans la section **Events names**.
2. Dans **Revenue override**, cliquez sur **Add override**.
3. Sélectionnez l'événement cible et entrez un pourcentage de revenu (0–100).
4. Cliquez sur **Save**.

<ZoomImage id="revenue-override.webp" width="500px" />

### Essai qualifié \{#qualified-trial\}

Un essai est qualifié une fois qu'il survit un certain nombre d'heures sans être annulé. Utilisez la section **Qualified trial** pour retenir les événements d'essai jusqu'à ce qu'ils soient qualifiés, afin que TikTok ne reçoive que les essais que les utilisateurs ont conservés.

Pour chaque cible d'événement d'essai, définissez le nombre d'heures à attendre. Adapty compte les heures à partir du début de l'essai et envoie l'événement une fois le délai écoulé. Si l'utilisateur désactive le renouvellement automatique avant la fin du délai, Adapty n'envoie jamais l'événement. Si l'utilisateur réactive le renouvellement automatique avant la fin du délai, Adapty envoie l'événement comme prévu.

Pour maintenir un événement d'essai en attente jusqu'à ce qu'il soit qualifié :

1. Activez **Trial started** dans la section **Events names**.
2. Dans **Qualified trial**, cliquez sur **Add event**.
3. Sélectionnez l'événement cible et entrez le nombre d'heures d'attente, de 1 à 24.
4. Cliquez sur **Save**.

<ZoomImage id="qualified-trial.webp" width="700px" alt="Qualified trial section with a target event held for two hours in a campaign configuration" />

Adapty envoie l'événement qualifié avec l'heure de début d'essai d'origine, de sorte que TikTok le rapporte au jour où l'essai a commencé.

:::important
Adapty associe les essais qualifiés à leur transaction App Store ou Google Play, donc ce délai s'applique uniquement aux essais intégrés à l'application. Les événements d'essai issus d'achats web, comme [FunnelFox](ua-funnelfox), sont envoyés immédiatement.
:::

### Envoyer tous les événements \{#send-all-events\}

Par défaut, Adapty n'envoie des événements à votre pixel que pour les utilisateurs attribués à une campagne TikTok. Activez **Send all events** pour transmettre également les événements des utilisateurs organiques et non attribués au pixel.

Lorsque cette option est activée, chaque événement d'installation et de transaction est envoyé au pixel, quelle que soit l'attribution de campagne. Utilisez-la pour fournir à TikTok des données de conversion plus larges pour la modélisation d'audience et l'optimisation des campagnes.

Pour activer cette option, dans les paramètres de campagne, sélectionnez **Send all events (forward organic/non-attributed events to this pixel)** et cliquez sur **Save**.
