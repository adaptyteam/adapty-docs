L'intégration de l'attribution Adapty avec TikTok for Business vous permet de suivre et d'optimiser les performances de vos campagnes sur TikTok.

:::tip
Consultez notre [guide de configuration des publicités dans TikTok for Business](tiktok-create-campaign).
:::

## Étape 1. Connecter votre compte TikTok \{#step-1-connect-your-tiktok-account\}

1. Accédez à **Integrations > TikTok Ads** depuis la barre latérale gauche et cliquez sur **Continue with TikTok**.

<ZoomImage id="ua-connect-tiktok.webp" width="700px" />

2. Connectez-vous avec votre compte TikTok et cliquez sur **Continue**.

3. Vérifiez les autorisations demandées et cliquez sur **Save**.

<ZoomImage id="ua-tiktok-sign.webp" width="500px" />

Ensuite, tous vos comptes publicitaires seront ajoutés à Adapty Attribution. Vous pouvez alors passer à l'ajout de campagnes.

## Étape 2. Ajouter des campagnes \{#step-2-add-campaigns\}

Une seule campagne peut couvrir l'App Store, le Google Play et votre funnel web en même temps. Deux éléments assurent la connexion :

- **Lien de suivi** : À intégrer dans votre annonce. Quand un utilisateur appuie sur l'annonce, Adapty enregistre le clic, redirige l'utilisateur vers la destination, puis attribue l'installation et les achats à cette annonce. Chaque destination possède son propre lien.
- **Pixel** : Sélectionné dans la campagne, parmi les pixels de votre compte TikTok. Renvoie ces conversions à TikTok afin que TikTok puisse optimiser la campagne sur la base d'achats réels. Un seul pixel peut couvrir les trois destinations, ou chaque destination peut avoir le sien.

Pour ajouter une campagne TikTok for Business à Adapty Attribution et suivre les performances de vos annonces TikTok dans Adapty :

1. Accédez à l'onglet **Web Campaigns** et cliquez sur **Create configuration**.

   <ZoomImage id="ua-new-campaign-tiktok.webp" width="500px" />

2. Dans l'onglet **General**, développez la section **iOS** et/ou **Android** et collez les URLs de l'application App Store et/ou Google Play.

   <ZoomImage id="ua-url.webp" width="900px" />

3. Copiez la valeur du champ **Click link**. Ensuite, dans TikTok Ads Manager, lors de la création de votre annonce, collez cette valeur dans le champ **Tracking URL** sous la section **Advanced Settings**. Cela permettra à Adapty de relier les installations et les achats aux annonces dans TikTok.

<ZoomImage id="ua-lnk.webp" width="900px" />

4. (Facultatif) Pour renvoyer les événements de conversion vers TikTok, vous pouvez également associer vos pixels TikTok à des campagnes dans Adapty Attribution. Pour ce faire, sélectionnez l'un de vos pixels existants dans le menu déroulant **Pixel**. Une fois un pixel sélectionné, vous pouvez cliquer sur **Send test event** pour vérifier la connexion.

La section **Web funnel** fonctionne de la même façon. Les achats effectués dans un web funnel se déroulent en dehors de votre application, donc TikTok n'en est informé que via le pixel que vous sélectionnez ici. Cette section vous fournit également le snippet pour [installer le pixel sur votre funnel](ua-web-pixel) et les paramètres pour [tagger vos URLs publicitaires](ua-tag-ad-urls).

Un pixel différent par destination permet de distinguer les achats iOS, Android et web pour l'optimisation et les rapports ; le même pixel partout les regroupe. La liste **Web Campaigns** affiche ce choix pour chaque configuration, sous **Pixel (iOS)**, **Pixel (Android)** et **Pixel (Web)**, avec le nom et l'identifiant du pixel. Une section sans pixel affiche un tiret, et un pixel sélectionné dans les trois sections apparaît trois fois.

## Étape 3. Mapper les événements \{#step-3-map-events\}

Pour renvoyer des événements de conversion à TikTok et optimiser vos campagnes, vous devez configurer le mapping des événements dans la section **Events names**. Cela permet à Adapty d'envoyer automatiquement des événements d'abonnement lorsque les utilisateurs effectuent des actions dans votre application.

Dans la section **Events names**, activez les événements que vous souhaitez suivre dans TikTok Ads Manager. Pour chaque événement activé, sélectionnez l'événement TikTok correspondant dans le menu déroulant ou définissez-en un personnalisé. Par défaut, Adapty associe les événements Adapty aux événements standard de TikTok.

Cliquez sur **Save** pour appliquer votre configuration de mapping des événements.

## Configuration supplémentaire \{#additional-configuration\}

### Paramètres supplémentaires \{#additional-parameters\}

Le champ **Additional parameter** vous permet d'ajouter des données personnalisées pour une analyse en dehors d'Adapty. C'est utile lorsque vous avez besoin de transmettre des données spécifiques de campagne ou d'utilisateur à des outils d'analyse externes ou à des partenaires d'attribution.

Dans le champ **Additional parameter**, saisissez les données personnalisées que vous souhaitez inclure dans votre suivi d'attribution. Le paramètre supplémentaire sera inclus dans toutes les données d'attribution envoyées à TikTok et peut être utilisé pour une analyse et une optimisation avancées des campagnes.

Par exemple, si vous exécutez plusieurs variations de la même campagne, vous pouvez ajouter `variant=A` ou `variant=B` pour distinguer les différentes approches créatives.

:::important
Les paramètres supplémentaires modifient le **Click link** que vous collez dans TikTok Ads Manager. Si vous avez déjà copié ce lien et ajouté un paramètre personnalisé ensuite, assurez-vous de copier-coller le lien mis à jour qui contient ce paramètre.
:::

### Paramètres \{#settings\}

L'onglet **Settings** contrôle la façon dont Adapty associe les actions des utilisateurs à vos campagnes TikTok Ads. Ces paramètres définissent les fenêtres temporelles pour la correspondance d'attribution déterministe et probabiliste.

Pour les configurer, rendez-vous dans l'onglet **Settings** de la configuration de votre campagne. Vous y trouverez deux paramètres principaux à ajuster :

- **Fenêtre de correspondance déterministe** : utilise des identifiants d'appareil exacts (comme l'IDFA sur iOS ou l'Advertising ID sur Android) pour associer les utilisateurs aux campagnes avec une grande précision. Réglez-la sur 168 heures (7 jours) pour une précision d'attribution maximale — c'est la valeur par défaut et recommandée. Lorsqu'un utilisateur clique sur votre publicité TikTok et installe votre application dans cette fenêtre, Adapty peut attribuer définitivement l'installation à ce clic précis grâce aux identifiants d'appareil.

- **Probabilistic matching window** : Cette option utilise la modélisation statistique et le device fingerprinting pour associer les utilisateurs quand le matching déterministe n'est pas possible. Réglez-la sur 6 heures pour la plupart des campagnes — c'est la valeur par défaut et elle convient à la majorité des cas d'usage. Pour les campagnes à fort volume de clics, vous pouvez la réduire à 1-2 heures. Pour les utilisateurs qui ne peuvent pas être associés de façon déterministe (en raison des paramètres de confidentialité ou d'autres facteurs), Adapty utilise le matching probabiliste dans cette fenêtre plus courte.

Cliquez sur **Save** pour appliquer vos paramètres.

<ZoomImage id="ua-meta-attribution-settings.webp" width="900px" />

### Remplacement du revenu \{#revenue-override\}

Si vous suivez les événements d'essai et souhaitez que TikTok leur attribue un revenu, utilisez la section **Revenue override**. Elle apparaît lorsque l'événement **Trial started** est activé. Le remplacement s'applique uniquement à **Trial started** — **Trial converted** et **Subscription started** transmettent toujours leur revenu réel.

Pour chaque cible d'événement d'essai, définissez le pourcentage du prix de l'abonnement à déclarer comme revenu. Par exemple, à 30 %, Adapty envoie 30 % du prix de l'abonnement comme valeur de conversion pour les événements d'essai.

Pour ajouter un remplacement :

1. Activez **Trial started** dans la section **Events names**.
2. Dans **Revenue override**, cliquez sur **Add override**.
3. Sélectionnez l'événement cible et entrez un pourcentage de revenu (0–100).
4. Cliquez sur **Save**.

<ZoomImage id="revenue-override.webp" width="500px" />

### Essai qualifié

:::warning
Adapty Attribution retarde l'événement d'essai jusqu'à 24 heures et ne l'envoie que si l'utilisateur n'a pas annulé. Si un MMP transfère également `trial_started` ou [`trial_active`](events#synthetic-events), TikTok reçoit le même essai plusieurs fois.
:::

Un essai est qualifié lorsqu'il survit un certain nombre d'heures sans être annulé. Utilisez la section **Qualified trial** pour retenir les événements d'essai jusqu'à leur qualification, afin que TikTok ne reçoive que les essais conservés par les utilisateurs.

Pour chaque cible d'événement d'essai, indiquez le nombre d'heures d'attente. Adapty compte les heures à partir du début de l'essai et envoie l'événement une fois le délai écoulé. Si l'utilisateur désactive le renouvellement automatique avant la fin du délai, Adapty n'envoie jamais l'événement. Si l'utilisateur réactive le renouvellement automatique avant la fin du délai, Adapty envoie l'événement comme prévu.

Pour retenir un événement d'essai jusqu'à ce qu'il soit qualifié :

1. Activez **Trial started** dans la section **Events names**.
2. Dans **Qualified trial**, cliquez sur **Add event**.
3. Sélectionnez l'événement cible et saisissez le nombre d'heures d'attente, de 1 à 24.
4. Cliquez sur **Save**.

<ZoomImage id="qualified-trial.webp" width="700px" alt="Section d'essai qualifié avec un événement cible retenu pendant deux heures dans une configuration de campagne" />

Adapty envoie l'événement qualifié avec l'heure de début d'essai d'origine, afin que TikTok le signale au jour où l'essai a commencé.

:::important
Adapty associe les essais qualifiés à leur transaction App Store ou Google Play, donc le délai s'applique uniquement aux essais intégrés. Les événements d'essai provenant d'achats web, comme [FunnelFox](ua-funnelfox), sont envoyés immédiatement.
:::

**Revenue override** et **Qualified trial** fonctionnent indépendamment, et vous pouvez appliquer les deux au même événement de trial. Revenue override modifie la valeur que TikTok reçoit ; Qualified trial modifie le moment où TikTok la reçoit. Avec les deux actifs, Adapty retient l'événement jusqu'à ce que le trial soit qualifié, puis l'envoie avec le revenu remplacé. Aucune des deux options n'est recommandée par rapport à l'autre — testez ce qui fonctionne pour vos campagnes.

### Envoyer tous les événements \{#send-all-events\}

Par défaut, Adapty ne remonte que les événements des utilisateurs provenant de l'une de vos campagnes TikTok. L'option **Send all events** remonte chaque installation et transaction, y compris celles des utilisateurs organiques ou non attribués.

Nous ne le recommandons pas, sauf si vos campagnes envoient trop peu de conversions à TikTok pour être optimisées, car mélanger des événements organiques et non attribués avec vos événements de campagne réduit la précision de l'optimisation TikTok.

Si vous décidez de l'activer, dans les paramètres de la campagne, sélectionnez **Send all events (forward organic/non-attributed events to this pixel)** et cliquez sur **Save**.
