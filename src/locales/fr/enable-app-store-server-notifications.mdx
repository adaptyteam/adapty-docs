La configuration des notifications serveur de l'App Store est essentielle pour garantir la précision des données : elle vous permet de recevoir instantanément les mises à jour de l'App Store, notamment les informations sur les remboursements et autres événements.

:::important
Adapty iOS SDK 2.10.0 ou version ultérieure est requis pour la prise en charge complète des notifications serveur App Store V2.
:::

1. Copiez l'**URL for App Store server notification** dans l'Adapty Dashboard.

2. Ouvrez [App Store Connect](https://appstoreconnect.apple.com/apps). Sélectionnez votre application et accédez à la section **General** → **App Information**, sous-section **App Store Server Notifications**.
3. Collez l'**URL for App Store server notification** copiée dans les champs **Production Server URL** et **Sandbox Server URL**.

:::warning
Renseignez les deux champs URL. Sans le **Production Server URL**, Adapty n'est pas informé des renouvellements, expirations et remboursements qui se produisent en dehors de l'application. Si des notifications de production ont été manquantes pendant une période, contactez [support@adapty.io](mailto:support@adapty.io) : Adapty peut restaurer l'historique manquant depuis Apple à l'aide d'une liste de valeurs `apple_original_transaction_id`, sans créer de doublons.
:::

Après avoir enregistré les URLs, le statut des notifications dans l'Adapty Dashboard ne change que lorsqu'Apple envoie la première vraie notification — c'est-à-dire lors du premier événement d'abonnement, comme un achat ou un renouvellement. La notification test d'Apple ne le modifie pas. Un statut « en attente » juste après la configuration ne signifie pas que la connexion est interrompue.

## Transfert brut des événements \{#raw-events-forwarding\}

Parfois, vous souhaitez quand même recevoir les événements S2S bruts d'Apple. Pour continuer à les recevoir tout en utilisant Adapty, ajoutez simplement votre endpoint dans le champ **URL for forwarding raw Apple events**, et nous transmettrons les événements bruts tels quels depuis Apple.

:::warning
Si les notifications cessent de parvenir à Adapty, les nouvelles transactions, renouvellements et remboursements n'apparaissent plus. Adapty ne le signale pas — consultez [Si les mises à jour cessent d'arriver](store-sync#if-updates-stop-arriving).
:::
