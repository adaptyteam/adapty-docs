Si votre paywall actuel a été créé dans le Paywall Builder legacy, vous pouvez le convertir en flow. En un seul clic, l'action **Move to new builder** recrée votre paywall sous forme de draft flow modifiable.

La conversion copie :

- **Mise en page et design** : les écrans, éléments et styles du paywall d'origine.
- **Texte** : tous les contenus, dans chaque langue que vous avez ajoutée.
- **Produits** : chaque produit, avec les prix et remises sous forme de variables plutôt que de valeurs codées en dur.

Le paywall d'origine reste actif et inchangé, vous pouvez donc personnaliser et tester le flow avant de basculer.

:::warning
Certaines fonctionnalités du Paywall Builder legacy n'ont pas d'équivalent dans les flows, donc un paywall converti peut ne pas correspondre exactement à l'original. Le panneau [Import review](#import-review) vous guide à travers chaque différence et comment la corriger.
:::

## Convertir votre paywall \{#convert-your-paywall\}

Pour convertir un paywall en flow, ouvrez la page de présentation du paywall et cliquez sur **Move to new builder**. Ce bouton n'apparaît que pour les paywalls créés avec le Paywall Builder hérité.

<ZoomImage id="move-to-new-builder.webp" width="700px" alt="Move to new builder button in the paywall action row" />

Adapty ouvre le brouillon du flow dans l'éditeur, où vous pouvez le modifier avant de le publier. Si certains éléments n'ont pas été repris à l'identique, le builder lance une [révision d'import](#import-review).

<ZoomImage id="paywall-imported-toast.webp" width="500px" alt="Toast de confirmation d'importation du paywall dans l'éditeur de flow après la conversion" />

## Vérification de l'import \{#import-review\}

Le panneau **Import review** liste tout ce que la conversion n'a pas pu reproduire, et propose une correction pour chaque écart.

<ZoomImage id="import-review.webp" width="500px" alt="Panneau Import review listant ce que la conversion n'a pas pu reproduire exactement, avec une case à cocher pour chaque élément" />

Parcourez le panneau, puis [prévisualisez le flow sur un vrai appareil](migrate-to-flows#preview-on-device) avant de publier.

## Servir votre flow \{#serve-your-flow\}

:::link
Article principal : [Migrer vers les flows](migrate-to-flows)
:::

Un flow converti commence sous forme de brouillon. Pour le servir à vos utilisateurs, vous devez :

1. [Publier le flow](builder-save-publish)
2. Ajouter le flow à un nouveau placement dédié aux flows
3. Invoquer le placement du flow dans votre application avec le SDK Adapty v4.X
