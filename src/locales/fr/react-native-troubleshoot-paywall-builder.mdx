Ce guide vous aide à résoudre les problèmes courants lors de l'utilisation de paywalls conçus dans le Paywall Builder d'Adapty avec le SDK React Native. Pour les problèmes liés aux flows, consultez [Problèmes courants](flow-common-issues).

## L'obtention d'une configuration de paywall échoue \{#getting-a-paywall-configuration-fails\}

**Problème** : La récupération de la configuration de vue pour un flow ou un paywall échoue.

**Cause** : Le paywall n'est pas activé pour l'affichage sur l'appareil dans le Paywall Builder.

**Solution** : Activez le bouton **Show on device** dans le Paywall Builder.

## Le nombre de vues du paywall est trop élevé \{#the-paywall-view-number-is-too-big\}

**Problème** : Le nombre de vues du paywall affiche le double de la valeur attendue.

**Raison** : Vous appelez peut-être `logShowFlow` (React Native SDK v4+) / `logShowPaywall` dans votre code, ce qui duplique le compteur de vues pour un paywall créé avec l'ancien Paywall Builder. Adapty suit ces vues automatiquement, vous n'avez donc pas besoin de cette méthode.

**Solution** : Vérifiez que vous n'appelez pas `logShowFlow` (React Native SDK v4+) / `logShowPaywall` dans votre code pour un paywall créé avec l'ancien Paywall Builder.

## Autres problèmes \{#other-issues\}

**Problème** : Vous rencontrez d'autres problèmes liés au Paywall Builder qui ne sont pas couverts ci-dessus.

**Solution** : Migrez le SDK vers la dernière version à l'aide des [guides de migration](react-native-sdk-migration-guides) si nécessaire. De nombreux problèmes sont résolus dans les versions plus récentes du SDK.
