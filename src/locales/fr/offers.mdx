Les offres disponibles sur l'App Store et le Google Play Store sont des promotions spéciales, des essais gratuits ou des remises sur les abonnements. Elles permettent d'attirer de nouveaux utilisateurs, de réengager les abonnés inactifs et d'augmenter les conversions.

Les offres s'appliquent uniquement aux abonnements. Les produits avec une durée **Lifetime**, **Non-Subscriptions** ou **Consumables** ne peuvent pas comporter d'offre dans aucun des stores, et Adapty masque les champs d'offre pour ces produits. Pour appliquer une réduction à un achat unique, [créez un second produit au prix réduit et ciblez-le avec des audiences](create-offer#how-adapty-works-with-offers).

## Activer les offres dans votre application \{#enable-offers-in-your-app\}

Pour traiter les offres, Adapty nécessite la configuration suivante :

1. Créez des offres dans le store :
   - [App Store](app-store-offers)
   - [Google Play](google-play-offers)
2. Pour l'App Store : [importez votre clé d'achat intégré depuis App Store Connect dans Adapty](app-store-connection-configuration#step-4-for-trials-and-special-offers--set-up-promotional-offers).
3. [Ajoutez les offres dans Adapty et affichez-les dans un flow ou un paywall](create-offer).

:::note
Les offres de lancement sur iOS sont appliquées automatiquement si l'utilisateur est éligible. Ne les ajoutez pas dans Adapty.
:::

Une exception à l'étape 1 : Adapty crée une offre de lancement gratuite dans l'App Store pour vous, mais uniquement lorsque vous [envoyez un nouveau produit vers les stores](create-product#create-product-and-push-to-store). Une offre de lancement que vous configurez vous-même fonctionne normalement, mais [n'apparaît jamais dans Adapty](store-sync).
