L'intégration d'Adapty Attribution avec un stockage compatible S3 personnalisé vous permet de stocker les données de campagne d'acquisition utilisateur en toute sécurité dans votre propre solution de stockage compatible S3. Adapty Attribution enregistre des fichiers .csv dans votre bucket S3 personnalisé. Chaque ligne correspond à une installation d'application, avec ses identifiants d'appareil et ses données d'attribution, comme le canal et la campagne. Les fichiers ne contiennent aucune donnée de dépenses publicitaires, de revenus ou d'achats.

Pour configurer cette intégration, vous devrez suivre quelques étapes simples dans la console de votre stockage compatible S3 et dans le tableau de bord Adapty Attribution.

:::note
Adapty Attribution exporte un ensemble de fichiers par jour calendaire. Le planificateur d'export s'exécute trois fois par jour — à **02:00**, **04:00** et **06:00 UTC**. Chaque exécution crée le job d'export du jour précédent s'il n'existe pas encore, ou le relance en cas d'échec d'une exécution antérieure. Vos données sont donc généralement disponibles après l'exécution de 02:00 ; les exécutions suivantes servent à récupérer d'éventuelles erreurs plutôt qu'à ajouter des données.

Chaque export couvre les installations enregistrées par l'attribution Adapty lors du jour calendaire précédent en UTC. Par exemple, l'export du 8 mars contient les installations enregistrées le 7 mars, de 00:00:00 à 23:59:59 UTC.

Chaque fichier reflète l'attribution au moment de l'export. Pendant jusqu'à 30 jours après une installation, l'attribution Adapty peut encore rattacher l'installation à un autre canal ou une autre campagne. Pour actualiser des fichiers plus anciens avec l'attribution actuelle, [lancez un export manuel](#manual-data-export) pour les dates concernées.
:::

:::warning
L'export planifié ne fonctionne que pour les entreprises disposant d'un abonnement payant ou en période d'essai. Si votre entreprise n'est dans aucun de ces cas, le planificateur ignore l'export et n'écrit aucun fichier, même si l'intégration reste activée dans le tableau de bord. Si votre bucket est vide et que la configuration semble correcte, vérifiez d'abord le statut de votre abonnement.
:::

## Configurer l'intégration Custom S3 \{#set-up-custom-s3-integration\}

Pour commencer à recevoir des données, configurez l'intégration dans Adapty Attribution :

1. Allez dans [**Integrations** -> **Custom S3**](https://app.adapty.io/ua/integrations/custom-s3)
2. Activez le bouton **Export install events to custom S3**.
3. Renseignez les champs obligatoires pour établir une connexion entre votre stockage S3 personnalisé et les profils Adapty Attribution.

| Champ                                   | Description                                                                                                                                                                                                                        |
|:----------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Access Key ID**                       | Un identifiant unique utilisé pour authentifier l'accès d'un utilisateur ou d'une application à votre service de stockage compatible S3. Vous trouverez cet identifiant dans la console de votre fournisseur de stockage.                                                            |
| **Secret Access Key**                   | Une clé privée utilisée conjointement avec l'Access Key ID pour authentifier l'accès d'un utilisateur ou d'une application à votre service de stockage compatible S3. Vous trouverez cette clé dans la console de votre fournisseur de stockage.                           |
| **S3 Bucket Name**                      | Un nom globalement unique qui identifie un bucket S3 spécifique dans votre environnement de stockage. Les buckets S3 sont un service de stockage simple permettant aux utilisateurs de stocker et de récupérer des objets de données, tels que des fichiers et des images, dans le cloud. |
| **Region** (Optionnel)                   | Obtenez votre région depuis la Management Console.                                                                                                                                                                                                                                   |
| **Folder Inside the Bucket** (Optionnel) | Le nom du dossier que vous souhaitez créer dans le bucket S3 sélectionné. Notez que S3 simule les dossiers à l'aide de préfixes de clés d'objet, qui correspondent en réalité à des noms de dossiers.                                                   |
| **Custom Endpoint URL**                 | L'URL du point de terminaison de votre service de stockage compatible S3. Elle doit être fournie par votre fournisseur de stockage (par ex., MinIO, DigitalOcean Spaces, Wasabi, etc.).                                                                        |

:::note
Vous pouvez également spécifier des répertoires imbriqués dans le champ du nom du bucket S3, par exemple `adapty-ua-events/com.sample-app`
:::

## Export manuel des données \{#manual-data-export\}

Pour exporter des données sur des dates antérieures, dans la section **Manual file export**, sélectionnez une plage de dates et cliquez sur **Export to S3**. Si votre bucket contient déjà des fichiers pour ces dates, Adapty Attribution les remplace.

## Structure du tableau \{#table-structure\}

Chaque fichier contient une ligne par installation enregistrée par l'attribution Adapty au cours d'une journée UTC, avec les données de l'appareil et l'attribution. Les fichiers ne contiennent aucune donnée de dépenses publicitaires, de revenus ou d'achats.

:::warning
Notez que cette structure peut évoluer au fil du temps — avec de nouvelles données introduites par nous ou par les tiers avec lesquels nous travaillons. Assurez-vous que le code qui traite ces fichiers est suffisamment robuste et repose sur des champs spécifiques, et non sur la structure dans son ensemble.
:::

Les fichiers contiennent les colonnes suivantes :

| Colonne                  | Description                               |
|--------------------------|-------------------------------------------|
| `adapty_profile_id`      | Identifiant de profil Adapty unique       |
| `install_id`             | Identifiant d'installation unique         |
| `created_at`             | Horodatage de création de l'enregistrement (ISO 8601) |
| `installed_at`           | Horodatage d'installation de l'app (ISO 8601) |
| `store`                  | Store applicatif (`ios`, `android`)       |
| `country`                | Code pays de l'utilisateur (ISO 3166-1 alpha-2) |
| `ip_address`             | Adresse IP du client                      |
| `idfa`                   | Identifiant publicitaire iOS (IDFA)       |
| `idfv`                   | Identifiant vendeur iOS (IDFV)            |
| `gaid`                   | Google Advertising ID (Android)           |
| `android_id`             | Identifiant d'appareil Android            |
| `app_set_id`             | Android App Set ID                        |
| `bundle_id`              | Identifiant de bundle de l'app (ex. `com.example.app`) |
| `device_brand`           | Marque de l'appareil (ex. `Apple`, `Samsung`) |
| `device_model`           | Modèle de l'appareil (ex. `iPhone15,2`)   |
| `os_version`             | Version principale du système d'exploitation |
| `app_version`            | Version de l'app rapportée par le SDK Adapty |
| `sdk_version`            | Version du SDK Adapty                     |
| `channel`                | Canal d'attribution                       |
| `campaign_id`            | Identifiant de campagne                   |
| `campaign_name`          | Nom de la campagne                        |
| `adset_id`               | Identifiant du groupe d'annonces          |
| `adset_name`             | Nom du groupe d'annonces                  |
| `ad_id`                  | Identifiant de l'annonce                  |
| `ad_name`                | Nom de l'annonce                          |
| `keyword_id`             | Identifiant du mot-clé                    |
| `keyword_name`           | Nom du mot-clé                            |
| `asa_org_id`             | Identifiant d'organisation Apple Search Ads |
| `asa_keyword_match_type` | Type de correspondance de mot-clé ASA (`Exact`, `Broad`) |
| `asa_attribution`        | Données d'attribution ASA (chaîne JSON)   |
| `asa_conversion_type`    | Type de conversion ASA                    |
| `asa_country_or_region`  | Pays ou région ASA                        |
| `asa_creative_set_name`  | Nom du jeu créatif ASA                    |
| `fbclid`                 | Facebook Click ID                         |
| `ttclid`                 | TikTok Click ID                           |
| `utm_source`             | Paramètre UTM source                      |
| `utm_medium`             | Paramètre UTM medium                      |
| `utm_campaign`           | Paramètre UTM campaign                    |
| `utm_term`               | Paramètre UTM term                        |
| `utm_content`            | Paramètre UTM content                     |
| `click_time`             | Horodatage du clic attribué, en secondes Unix. Vide si aucun clic n'est attribué à l'installation. |
| `asa_click_time`         | Horodatage du tap Apple Search Ads avant l'installation, en secondes Unix, arrondi à la minute. Vide si Apple Search Ads ne signale aucun tap pour cette installation. Contrairement à `click_time`, cette colonne contient une valeur même si l'attribution Adapty crédite l'installation à un autre canal. |
