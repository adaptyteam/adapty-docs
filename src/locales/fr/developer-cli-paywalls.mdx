Ces commandes CLI Adapty gèrent les [paywalls](paywalls) et les produits vendus par chaque paywall.

## adapty paywalls list \{#adapty-paywalls-list\}

Liste tous les [paywalls](paywalls) d'une application.

```bash
adapty paywalls list --app <app-id>
```

| Flag | Requis | Description |
|---|---|---|
| `--app` | Oui | ID de l'application (UUID) |

Accepte les [flags de pagination](developer-cli-reference#global-flags).

## adapty paywalls get

Obtenez les détails d'un [paywall](paywalls) spécifique.

```bash
adapty paywalls get --app <app-id> <paywall-id>
```

| Argument | Description |
|---|---|
| `paywall-id` | ID du paywall (UUID) |

| Flag | Requis | Description |
|---|---|---|
| `--app` | Oui | ID de l'application (UUID) |

## adapty paywalls create

Créer un nouveau [paywall](paywalls).

```bash
adapty paywalls create --app <app-id> --title "Default Paywall" --product-id <product-id>
```

| Flag | Requis | Description |
|---|---|---|
| `--app` | Oui | ID de l'app (UUID) |
| `--title` | Oui | Titre du paywall |
| `--product-id` | Oui | ID du [produit](product) (UUID). Répéter pour plusieurs produits : `--product-id <id1> --product-id <id2>` |

## adapty paywalls update

Remplace tous les champs d'un [paywall](paywalls) existant.

:::important
Une fois un paywall lié à un placement, ses produits ne peuvent plus être modifiés. Pour utiliser des produits différents dans un paywall actif, créez un nouveau paywall et mettez à jour le placement pour qu'il pointe vers celui-ci.
:::

```bash
adapty paywalls update --app <app-id> <paywall-id> --title "Default Paywall" --product-id <product-id>
```

Cette commande remplace tous les champs du paywall, y compris la liste complète des produits.

| Argument | Description |
|---|---|
| `paywall-id` | ID du paywall (UUID) |

| Flag | Obligatoire | Description |
|---|---|---|
| `--app` | Oui | ID de l'application (UUID) |
| `--title` | Oui | Titre du paywall |
| `--product-id` | Oui | ID du [produit](product) (UUID). Répéter pour plusieurs produits : `--product-id <id1> --product-id <id2>` |

## adapty paywalls placements

Listez tous les [placements](placements) qui utilisent actuellement un [paywall](paywalls) donné.

```bash
adapty paywalls placements --app <app-id> <paywall-id>
```

| Argument | Description |
|---|---|
| `paywall-id` | ID du paywall (UUID) |

| Flag | Requis | Description |
|---|---|---|
| `--app` | Oui | ID de l'application (UUID) |

Utilisez cette commande avant de remplacer un paywall pour voir quels placements seraient affectés.

Les éléments de cette liste ne comportent pas de champ `is_active`. Pour lire l'état d'activation d'un placement, utilisez [`placements list`](developer-cli-placements#adapty-placements-list) ou [`placements get`](developer-cli-placements#adapty-placements-get).
