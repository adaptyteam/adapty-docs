Adapty génère automatiquement des fichiers de configuration JSON pour vos [paywalls de secours](/fallback-paywalls), un par plateforme. Ces fichiers contiennent également les données de secours pour vos onboardings.

Si un placement comporte plusieurs paywalls ou onboardings, la version de secours inclura la variante ayant le poids le plus élevé ou l'audience la plus large. Adapty met à jour ces fichiers chaque fois que vous modifiez vos paywalls ou onboardings.

Suivez les étapes ci-dessous pour télécharger vos configurations de secours :

1. Ouvrez la page **[Placements](https://app.adapty.io/placements)**.
2. Cliquez sur le bouton **Fallbacks**.
3. Sélectionnez votre plateforme cible (*iOS* ou *Android*) dans le menu déroulant.
4. Sélectionnez votre version du SDK pour lancer le téléchargement.
