Adapty génère automatiquement des fichiers de configuration JSON pour vos [paywalls de secours](/fallback-paywalls), un par plateforme. Ces fichiers contiennent également les données de secours pour vos onboardings.

Si un placement possède plusieurs [audiences](audience), le fichier de secours utilise uniquement l'audience **All users**. Si cette audience exécute un test A/B, le fichier contient chaque variante du test, et le SDK répartit les utilisateurs entre elles selon leur poids. Les [tests A/B interplacements](ab-test-types) ne sont jamais inclus dans le fichier. Adapty met à jour ces fichiers à chaque fois que vous modifiez vos paywalls ou vos onboardings.

Suivez les étapes ci-dessous pour télécharger vos configurations de secours :

1. Ouvrez la page **[Placements](https://app.adapty.io/placements)**.
2. Cliquez sur le bouton **Fallbacks**.
3. Sélectionnez votre plateforme cible (*iOS* ou *Android*) dans le menu déroulant.
4. Sélectionnez la version du SDK pour lancer le téléchargement.

:::tip
Pour télécharger le fichier depuis le terminal, utilisez le [Developer CLI](developer-cli). Indiquez la version du SDK Adapty utilisée par votre application :

```bash
adapty fallbacks get --app <app-id> --platform ios --sdk-version <sdk-version> --output ios_fallback.json
```

Exécutez-la une fois par store, avec `--platform ios` ou `--platform android`. Consultez [`adapty fallbacks get`](developer-cli-fallbacks) pour les options disponibles.
:::
