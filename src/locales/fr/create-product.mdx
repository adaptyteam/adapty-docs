La façon dont vous créez des produits dans Adapty dépend de si vous les avez déjà dans les stores :
- **[Si les produits n'existent pas encore dans l'App Store et/ou Google Play, créez-les dans Adapty et publiez-les directement dans les stores.](#create-product-and-push-to-store)**
- **[Si les produits existent déjà dans l'App Store et/ou Google Play, créez-les dans Adapty et connectez les produits existants du store.](#create-product-and-connect-existing-store-products)**

Pour permettre aux utilisateurs de l'App Store de payer un abonnement annuel en 12 mensualités, créez d'abord un produit **Annual**. Ensuite, ouvrez-le pour le modifier et [ajoutez un plan d'engagement de 12 mois](set-up-12-month-commitment#2-adapty-configuration).

Le prix saisi ici ne peut pas être modifié après la création, et une modification de prix dans la console du store [n'est pas répercutée dans Adapty](store-sync#product-and-price-discrepancies).

:::tip
Vous pouvez également créer des produits de manière programmatique à l'aide du [Developer CLI](developer-cli-products#adapty-products-create).
:::

## Créer un produit et le pousser vers le store \{#create-product-and-push-to-store\}

:::warning
Avant de commencer, assurez-vous d'avoir configuré l'intégration avec les stores dont vous avez besoin :
- [App Store](initial_ios)
- [Google Play](initial-android)

Assurez-vous que votre intégration App Store inclut la [clé API App Store Connect](app-store-connect-api-key).
:::

:::important
Adapty active le [Partage familial](apple-family-sharing) pour chaque abonnement ou produit non consommable que vous envoyez à App Store Connect. Une fois le Partage familial activé, vous ne pouvez pas le désactiver. Pour proposer un produit sans Partage familial, créez-le dans App Store Connect et [connectez-le](#create-product-and-connect-existing-store-products).
:::

<YouTube id="qUpC2XG-r5E" />

Pour ajouter un nouveau produit à votre application :

1. Accédez à **[Products](https://app.adapty.io/products)** depuis le menu principal d'Adapty.

<ZoomImage id="products-tab.webp" width="700px" />

2. Cliquez sur **Create product** dans le coin supérieur droit. Adapty prend en charge tous les types de produits : abonnements, non-consommables \(y compris à vie\), et consommables.

3. Sélectionnez **Create a new product and push to stores**.

<ZoomImage id="push-to-stores.webp" width="400px" />

4. Saisissez les informations suivantes :
    - **Product name** : entrez le nom du produit tel qu'il apparaîtra dans Adapty Dashboard. Ce nom est avant tout pour votre usage personnel, choisissez donc celui qui vous convient le mieux dans Adapty Dashboard.
    - **Access Level** : sélectionnez le [niveau d'accès](access-level) auquel appartient le produit. Le niveau d'accès détermine les fonctionnalités débloquées après l'achat du produit. Cette liste ne contient que les niveaux d'accès déjà créés. Le niveau d'accès `premium` est créé par défaut dans Adapty, mais vous pouvez également [en ajouter d'autres](access-level).
    - **Subscription duration** : sélectionnez la durée de l'abonnement dans la liste. Cette valeur ne peut pas être modifiée après la création du produit.
        - **Weekly/Monthly/2 Months/3 Months/6 Months/Annual** : la durée de l'abonnement. Adapty ne pousse pas les [plans d'engagement de 12 mois](app-store-12-month-commitment) vers App Store Connect. Pour en proposer un, créez l'abonnement dans App Store Connect et [connectez-le](#create-product-and-connect-existing-store-products).
        - **Lifetime** : utilisez la période à vie pour les produits qui débloquent définitivement les fonctionnalités premium de l'application.
        - **Non-Subscriptions** : pour les produits à achat unique sans durée. Un achat non-abonnement n'accorde pas de niveau d'accès — il apparaît dans le tableau `nonSubscriptions` du profil utilisateur, et c'est votre application qui décide de ce qu'il débloque.
        - **Consumables** : les consommables peuvent être achetés plusieurs fois et utilisés au cours de la vie de l'application. Par exemple : la monnaie dans le jeu ou les extras. Un achat consommable n'accorde pas non plus de niveau d'accès. Pour accorder un niveau d'accès via un achat unique, utilisez **Lifetime**.
    - **Price (USD)** : le prix du produit en USD. Ce prix servira de base pour calculer et définir automatiquement les prix dans tous les pays. Vous pourrez [personnaliser le prix pour différents pays et régions](edit-product#set-country-specific-prices) ultérieurement.
<ZoomImage id="create-product-push.webp" width="400px" />

5. Cliquez sur **Save & Continue**.
6. Configurez les informations du produit pour l'App Store si vous prévoyez d'y publier :
   - **Product ID** : Créez un identifiant unique et permanent pour le produit.
   - **Product group** : Sélectionnez un groupe de produits existant que vous avez créé dans App Store Connect, ou cliquez sur **Create new Product Group** et définissez son nom. Une fois qu'Adapty l'a créé, vous pouvez le sélectionner dans la liste déroulante.
   - **Screenshot** : Téléchargez une capture d'écran de l'achat intégré montrant clairement l'article ou le service proposé. Cette capture d'écran est utilisée uniquement pour la révision App Store et n'est pas affichée sur l'App Store. Consultez les exigences de taille et de format [ici](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/).

<ZoomImage id="push-app-store.webp" width="400px" />

7. Cliquez sur **Push data to App Store**.

:::warning
S'il s'agit de votre premier produit pour cette application, vous devez le soumettre manuellement à l'examen dans App Store Connect. Cela ne sera plus nécessaire par la suite. Une fois l'examen terminé, le statut du produit dans Adapty se mettra à jour automatiquement.
:::

8. Configurez les informations produit pour Google Play si vous prévoyez d'y publier :
   - **Base Product ID** : Créez un identifiant unique et permanent pour le produit.
   - **Subscription** : Sélectionnez un groupe d'abonnements existant créé dans la Google Play Console ou cliquez sur **Create new Product Group** et définissez son nom et son identifiant. Une fois qu'Adapty l'a créé, vous pouvez le sélectionner dans la liste déroulante.
   :::note
   Le délai de grâce et la période de blocage du compte seront automatiquement définis selon les valeurs par défaut du Play Store. Vous pourrez les modifier ultérieurement dans la Google Play Console.
   :::

<ZoomImage id="push-google-play.webp" width="400px" />

9. Cliquez sur **Push data to Play Store**.
10. Pour iOS, configurez l'offre de lancement (essai gratuit) en sélectionnant sa **Free duration** dans le menu déroulant. Pour cette configuration initiale, vous pouvez ajouter un essai gratuit de lancement. Une fois le produit principal approuvé par les stores, vous pouvez [ajouter d'autres offres](offers) (par ex., promotionnelles, de reconquête) en liant leurs identifiants existants depuis votre console store.

<ZoomImage id="intro.webp" width="400px" />

:::important
Les offres de lancement ne se synchronisent pas automatiquement avec Google Play. Contrairement à l'App Store, Google Play ne dispose pas de type distinct « offre de lancement » — les essais gratuits et les offres à prix réduit sont tous configurés comme des **offres** sur un plan de base. [Créez l'offre dans Google Play Console et associez-la à votre produit Adapty](google-play-offers).
:::

11. Pour finir, cliquez sur **Save** pour confirmer la création du produit.

## Créer un produit et connecter des produits de store existants \{#create-product-and-connect-existing-store-products\}

:::warning
Avant de commencer, assurez-vous d'avoir :
- Configuré l'intégration avec les stores dont vous avez besoin :
  - [App Store](initial_ios)
  - [Google Play](initial-android)
- Créé des produits dans les stores dont vous avez besoin :
  - [App Store](app-store-products)
  - [Google Play](android-products)

**Si vous n'avez encore aucun produit créé**, suivez plutôt le guide [Envoyer vers les stores](#create-product-and-push-to-store) pour les créer simultanément dans Adapty et dans les stores.
:::

<YouTube id="nlkdKCF0SwY" />

Pour ajouter un nouveau produit à votre application :

1. Accédez à **[Products](https://app.adapty.io/products)** depuis le menu principal d'Adapty.

<ZoomImage id="products-tab.png" width="700px" />

2. Cliquez sur **Create product** en haut à droite. Adapty prend en charge tous les types de produits : abonnements, achats non consommables \(y compris à vie\) et consommables.

3. Sélectionnez **Connect an existing store product**.

<ZoomImage id="existing-product.webp" width="400px" />

4. Renseignez les informations suivantes :

    - **Product name** : saisissez le nom du produit tel qu'il apparaîtra dans Adapty Dashboard. Ce nom est avant tout pour votre usage personnel, choisissez donc celui qui vous convient le mieux dans l'Adapty Dashboard.

    - **Access Level ID** : Sélectionnez le [niveau d'accès](access-level) auquel appartient le produit. Le niveau d'accès détermine les fonctionnalités débloquées après l'achat du produit. Cette liste contient uniquement les niveaux d'accès déjà créés. Le niveau d'accès `premium` est créé par défaut dans Adapty, mais vous pouvez également [en ajouter d'autres](access-level).

   - **Durée de l'abonnement** : sélectionnez la durée de l'abonnement dans la liste. Vous ne pouvez pas la modifier après la création du produit.
      - **Hebdomadaire/Mensuel/2 mois/3 mois/6 mois/Annuel** : la durée de l'abonnement. Pour ajouter un [plan d'engagement de 12 mois](set-up-12-month-commitment), sélectionnez **Annual** et configurez les versements une fois le produit créé.
      - **Lifetime** : utilisez une durée à vie pour les produits qui débloquent les fonctionnalités premium de l'application définitivement.
      - **Non-Subscriptions** : pour les produits à achat unique sans durée. Un achat non-abonnement n'accorde pas de niveau d'accès — il apparaît dans le tableau `nonSubscriptions` du profil utilisateur, et c'est votre application qui décide ce qui est débloqué.
      - **Consumables** : les articles consommables peuvent être achetés plusieurs fois et utilisés au cours de la vie de l'application. Par exemple, la monnaie ou les extras en jeu. Un achat consommable n'accorde pas non plus de niveau d'accès. Pour accorder un niveau d'accès à partir d'un achat unique, utilisez **Lifetime**.
   - **Price (USD)** : le prix du produit en USD. Si votre produit est déjà dans le store, cette valeur n'affectera pas son prix réel dans le store ; vous pouvez sélectionner n'importe quelle valeur dans la liste. Vous pourrez ensuite [personnaliser les prix pour différentes régions](edit-product#set-country-specific-prices) directement depuis l'Adapty Dashboard.

<ZoomImage id="product-info.webp" width="400px" />

5. Cliquez sur **Continue**.

6. Configurez les informations du produit pour chaque store :

   - **App Store :**
        - **App Store Product ID :** Cet identifiant unique permet d'accéder à votre produit sur les appareils. Sélectionnez-le dans la liste. S'il n'y figure pas, [vérifiez le produit dans le store, la clé API App Store Connect et l'Apple App ID](troubleshoot-app-store-integration#products-dont-appear-or-show-no-app-store-status).
   - **Play Store :**
        - **Google Play Product ID :** Il s'agit de l'identifiant du produit dans le Play Store. Sélectionnez-le dans la liste. S'il n'apparaît pas, vérifiez sa configuration dans la Google Play Console et assurez-vous qu'il est correct et associé à cette application.
        - **Base Plan ID :** Cet identifiant définit le plan de base du produit dans le Play Store. Lorsque vous ajoutez l'identifiant d'un abonnement sur le Play Store, vous devez fournir un Base Plan ID. Un plan de base définit les caractéristiques essentielles d'un abonnement : la période de facturation, le type de renouvellement (automatique ou prépayé) et le prix associé. Notez que dans Adapty, chaque combinaison d'un même abonnement avec des plans de base différents est considérée comme un produit distinct.
        - **Legacy fallback product** : Un produit de secours utilisé exclusivement pour les applications utilisant d'anciennes versions du SDK Adapty (versions 2.5 et antérieures). En marquant un produit comme rétrocompatible dans la Google Play Console, Adapty peut déterminer s'il peut être acheté par d'anciennes versions du SDK. Pour ce champ, indiquez la valeur au format suivant : `<subscription_id>:<base_plan_id>`.
   - **Stripe** :
        - **Stripe Product ID** : Il s'agit d'un identifiant unique pour un produit dans Stripe.
        - **Stripe Price ID** : Dans Stripe, les objets de prix comprennent bien plus que le montant ; ils couvrent également le comportement fiscal, les paliers de volume et les intervalles d'abonnement. Un même produit pouvant avoir plusieurs prix, indiquez l'identifiant de prix correct lors de la création d'un produit dans Adapty.
   - **Paddle** :
       - **Paddle Product ID** : Il s'agit d'un identifiant unique pour un produit dans Paddle.
       - **Paddle Price ID** : Dans Paddle, les objets de prix comprennent bien plus que le montant ; ils couvrent également le comportement fiscal, les paliers de volume et les intervalles d'abonnement. Un même produit pouvant avoir plusieurs prix, indiquez l'identifiant de prix correct lors de la création d'un produit dans Adapty.

:::warning
Chaque ID de produit doit correspondre exactement à celui du store. Une incohérence ne génère pas d'erreur : l'achat est effectué, mais le client ne reçoit aucun niveau d'accès.
:::

7. **Optionnel :** Vous pouvez ajouter des produits depuis n'importe quel store personnalisé en cliquant sur **Add custom store**. Dans la fenêtre **Manage custom store info**, vous pouvez sélectionner un store personnalisé existant ou en ajouter un nouveau et y associer un produit. Gardez à l'esprit qu'Adapty ne suit que les transactions provenant de l'App Store, de Google Play et de Stripe. Pour les stores personnalisés, vous devrez soumettre les transactions via la méthode Set transaction de l'API server-side d'Adapty.

8. Cliquez sur **Save product** pour finaliser la création du produit. La synchronisation du statut des produits peut prendre jusqu'à cinq minutes ; attendez qu'ils se mettent à jour dans le tableau.

9. Vous pouvez [créer des offres](create-offer) pour le produit si nécessaire. Pour ajouter des offres, cliquez sur **Yes, add offers**. Sinon, cliquez sur **No, thanks**.

:::note
Les offres de lancement sont créées dans Adapty uniquement lors de l'envoi d'un produit au store. Lors d'une importation ou pour des produits précédemment créés, les offres de lancement ne sont pas synchronisées et ne s'affichent pas dans Adapty, mais fonctionneront correctement dans l'application.
:::

## Étapes suivantes \{#next-steps\}

Félicitations ! Vous avez ajouté vos produits à Adapty. Et maintenant ?

- Si vous n'avez pas encore configuré d'offres de lancement/promotionnelles, vous pouvez [le faire](offers) maintenant.
- Si vous ne souhaitez pas le faire ou l'avez déjà fait, passez à la [configuration des paywalls](quickstart-paywalls) pour activer les achats intégrés.
- Si vous souhaitez apporter des ajustements aux produits du store (par exemple, définir des prix régionaux ou configurer le délai de grâce), faites-le dans App Store Connect ou Google Play Console.
- Découvrez comment [modifier vos produits](edit-product) ultérieurement.
