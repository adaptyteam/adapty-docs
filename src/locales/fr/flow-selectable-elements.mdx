Les éléments sélectionnables sont des éléments de flow que les utilisateurs peuvent appuyer pour sélectionner ou désélectionner. Leur état peut piloter la navigation, la visibilité et d'autres logiques dans le flow. Voici ce que vous pouvez faire :

- [Utiliser les éléments sélectionnables par défaut](#default-selectable-elements) — les options de quiz, produits, onglets et boutons d'essai sont sélectionnables par défaut
- [Rendre n'importe quel élément sélectionnable](#make-an-element-selectable) — transformez n'importe quel élément en élément sélectionnable et assignez-le à un groupe
- [Créer et gérer des groupes](#create-a-group) — organisez les éléments sélectionnables en groupes à choix unique, à choix multiple ou à bascule
- [Utiliser l'état sélectionné dans les conditions](#use-selectable-state-in-conditions) — référencez les valeurs de groupe dans les conditions sur n'importe quel écran du flow

## Éléments sélectionnables par défaut \{#default-selectable-elements\}

Certains types d'éléments sont sélectionnables par défaut — ils appartiennent déjà à des groupes créés automatiquement et ne nécessitent aucune configuration supplémentaire :

- **Options de quiz** : chaque réponse de quiz est un élément sélectionnable au sein du groupe de quiz. Voir [Quiz](onboarding-quizzes).
- **Produits** : les cartes produit dans un groupe de produits. Voir [Bloc produit](paywall-product-block).
- **Onglets** : les éléments d'onglet au sein d'un groupe d'onglets. Voir [Onglets](builder-tabs).
- **Bascules d'essai** : un conteneur qui appartient à un groupe et prend un état sélectionné. Voir [Bascules](builder-toggles).

## Rendre un élément sélectionnable \{#make-an-element-selectable\}

<YouTube id="btpZPOm9VRY" />

Dans certains cas, vous pouvez vouloir rendre des éléments supplémentaires sélectionnables. Par exemple, vous pouvez ajouter une case à cocher **Don't ask me again** qui fonctionne comme un élément au sein d'un groupe de quiz.

Pour rendre un élément sélectionnable :

1. Sélectionnez l'élément sur l'écran ou dans le panneau **Layers**.
2. À droite, basculez vers le panneau **Interactions**.
3. Sélectionnez **Turn into selectable element**.

<ZoomImage id="turn-into-selectable-element.webp" width="300px" alt="Option Turn into selectable element dans le panneau Interactions" />

4. Dans le menu déroulant **Group**, sélectionnez un groupe existant ou [créez-en un nouveau](#create-a-group).
5. Définissez l'**Element ID** — un identifiant unique pour cet élément au sein du groupe.
6. Si vous souhaitez que cet élément soit sélectionné par défaut, cochez la case **Set as default in group**.

<ZoomImage id="turn-into-selectable-element-settings.webp" width="300px" alt="Paramètres de l'élément sélectionnable avec le menu déroulant Group, l'Element ID et la case Set as default" />

## Créer un groupe \{#create-a-group\}

Les groupes organisent les éléments sélectionnables sur un écran et définissent le mode de sélection — un seul choix, plusieurs choix ou bascule.

Pour créer un groupe :

1. Sélectionnez un élément et [rendez-le sélectionnable](#make-an-element-selectable).
2. Dans le menu déroulant **Group**, sélectionnez **Create group**.

<ZoomImage id="create-group.webp" width="300px" alt="Option Create group dans le menu déroulant Group" />

3. Saisissez un **Group name**.
4. Sélectionnez le [type de groupe](#group-types).

Le groupe est maintenant disponible dans le menu déroulant **Group** pour les autres éléments sélectionnables du même écran.

<ZoomImage id="create-group-settings.webp" width="300px" alt="Paramètres de création de groupe avec le nom du groupe et le sélecteur de type de groupe" />

## Types de groupe \{#group-types\}

:::important
La plupart des [préréglages de quiz](onboarding-quizzes) sont en mode **multi-choix** par défaut. Modifiez le [type de groupe](#manage-groups) pour n'autoriser qu'une seule réponse.
:::

- **Choix unique** : Un seul élément du groupe peut être sélectionné à la fois. La sélection d'un nouvel élément désélectionne le précédent.
- **Multi-choix** : Plusieurs éléments peuvent être sélectionnés simultanément.
- **Bascule** : Chaque élément bascule entre sélectionné et désélectionné à chaque appui, indépendamment des autres éléments.

## Gérer les groupes \{#manage-groups\}

Pour afficher et modifier les groupes, ouvrez le panneau **Screen settings** et recherchez la section **Selectable groups**. Elle liste tous les groupes présents sur l'écran actuel.

Cliquez sur un ID de groupe pour :

- Modifier l'ID du groupe
- Modifier le [type de groupe](#group-types)
- Voir comment les éléments du groupe sont référencés dans les conditions

<ZoomImage id="edit-group.webp" width="500px" alt="Modifier un groupe sélectionnable dans le panneau Screen settings" />

## Utiliser l'état sélectionnable dans les conditions \{#use-selectable-state-in-conditions\}

Vous pouvez référencer l'état sélectionné d'un groupe dans des conditions sur n'importe quel écran du flow — pas uniquement l'écran où le groupe est défini. Par exemple : `IF quiz.photo is selected, THEN navigate to the Photo screen`.

:::important
Tous les éléments d'un groupe doivent se trouver sur le même écran. Vous ne pouvez pas ajouter des éléments provenant d'écrans différents à un même groupe. En revanche, vous pouvez référencer les valeurs d'un groupe dans des conditions sur n'importe quel écran du flow.
:::

Utilisez l'état sélectionnable avec :

- **[Actions conditionnelles](onboarding-actions#conditional-actions)** : Redirigez les utilisateurs vers différents écrans ou déclenchez différentes actions selon les éléments sélectionnés.
- **[Navigation dynamique](onboarding-navigation-branching)** : Faites bifurquer le flow selon les réponses à un quiz, l'état de bascules ou d'autres sélections.
- **[Visibilité conditionnelle](onboarding-element-visibility)** : Affichez ou masquez des éléments selon ce que les utilisateurs ont sélectionné sur les écrans précédents.

Pour les groupes de produits, vous pouvez également définir la sélection au lieu de simplement la lire. Une action [Sélectionner un produit](onboarding-actions#select-product) déplace la sélection vers un élément de produit spécifique dans un groupe sur le même écran.
