Dans ce guide étape par étape, vous allez apprendre à créer et configurer des publicités pour votre app sur Meta, afin de les optimiser et de suivre facilement leurs performances.

## Comment les publicités sont structurées dans Meta \{#how-ads-in-meta-are-structured\}

Lorsque vous faites de la publicité sur Meta Ads, vous devez configurer trois niveaux hiérarchiques :

- **Campagne** : Les campagnes définissent vos objectifs publicitaires.
- **Ensemble de publicités** : Les ensembles de publicités précisent votre audience cible et vos placements, c'est-à-dire où et à qui vos publicités seront diffusées. Chaque campagne peut contenir plusieurs ensembles de publicités.
- **Publicités** : Les publicités sont les créatifs que les utilisateurs voient et avec lesquels ils interagissent. Chaque ensemble de publicités peut contenir plusieurs publicités ; il est toutefois recommandé de ne pas dépasser cinq publicités par ensemble pour des performances optimales.

## Étape 1. Créer un compte Meta Ads Manager \{#step-1-create-meta-ads-manager-account\}

Pour commencer avec Meta Ads, vous devez avoir une page Facebook Business, car vous ne pouvez pas diffuser des publicités depuis votre page personnelle.

Vous devez donc lier votre page Business à votre portfolio Meta Ads Business :

1. Rendez-vous sur [business.facebook.com](https://business.facebook.com/). Si vous n'avez pas encore de page Business dans votre portfolio, vous devez en ajouter une. Cliquez sur **Go to settings**.
   <ZoomImage id="meta-ads-settings.webp" />

2. Accédez à **Account > Pages** dans la barre latérale gauche. Cliquez sur **Add** et sélectionnez **Add an existing Facebook page** ou **Create a new Facebook page**. Consultez le [guide sur la création d'une page professionnelle](https://www.facebook.com/business/help/473994396650734) si vous n'en avez pas encore.

   <ZoomImage id="add-page-meta.png" />

3. Vous pouvez également associer votre compte Instagram depuis la page **Account > Instagram accounts** dans les paramètres.

Une fois votre page professionnelle connectée, vous pouvez passer à la suite.

## Étape 2. Ajouter le pixel Meta \{#step-2-add-meta-pixel\}

Vous aurez besoin d'un pixel Meta pour relier les données de votre campagne aux revenus et obtenir de meilleurs résultats.

Avant de connecter des données et de créer un pixel, vous aurez besoin de :
- Une page business – ajoutez-la à votre portfolio business dans [**Settings > Accounts > Pages**](https://business.facebook.com/latest/settings/pages)
- Un compte Business Manager – vous devez avoir le contrôle total sur le portfolio business
- Un email professionnel – défini dans [**Settings > Business info**](https://business.facebook.com/latest/settings/business_info)
- Un compte publicitaire – ajoutez-le à votre portfolio business dans [**Settings > Accounts > Ad accounts**](https://business.facebook.com/latest/settings/ad_accounts)

Lorsque vous êtes prêt, créez un pixel :
1. Accédez à [**Events Manager**](https://www.facebook.com/events_manager2). Cliquez sur **Connect data**.
   <ZoomImage id="connect-data.webp" />
2. Sélectionnez **Web** comme type de source de données.
   <ZoomImage id="new-data-source.webp" />
3. Donnez un nom à votre jeu de données et cliquez sur **Create**.
   <ZoomImage id="new-dataset.webp" />
4. Pour l'[Attribution Adapty](adapty-user-acquisition), vous n'aurez pas besoin de finaliser l'installation complète du pixel. Ainsi, lorsqu'on vous demande de configurer l'intégration, vous pouvez simplement cliquer sur **x** dans la fenêtre de configuration, et votre pixel apparaîtra tout de même dans la liste après avoir actualisé la page.
   <ZoomImage id="close-pixel.webp" />
5. Une fois que votre jeu de données apparaît dans la liste, vous pouvez procéder à la création d'une campagne.

## Étape 3. Créer une campagne \{#step-3-create-campaign\}

Pour créer une campagne dans Meta Ads Manager :

1. Rendez-vous sur [Meta Ads Manager](https://adsmanager.facebook.com/adsmanager/manage). Dans l'onglet **Campaign**, cliquez sur **Create**.

   <ZoomImage id="meta-new-campaign.webp" />

2. Sélectionnez **Sales** comme objectif de campagne et cliquez sur **Continue**.
   
   <ZoomImage id="meta-objective.webp" />

3. Nommez votre campagne dans la section **Campaign name**.
4. Dans la section **Budget**, sous **Budget strategy**, choisissez comment vous souhaitez contrôler le budget :
   - **Campaign budget** : L'option la plus simple si vous n'êtes pas sûr des opportunités qui fonctionneront le mieux. Si vous la sélectionnez, Meta Ads détectera automatiquement les meilleures performances pour allouer davantage de budget aux ensembles de publicités les plus performants.
   
Ensuite, choisissez si vous souhaitez un budget **Daily** ou **Lifetime** et saisissez la limite dans votre devise. Le budget **Daily** vous offre plus de flexibilité pendant votre phase d'apprentissage : vous pouvez commencer avec de petits montants et les ajuster progressivement. Vous pouvez également sélectionner **Schedule budget increase** et définir des règles pour augmenter automatiquement le budget d'un montant fixe ou d'un pourcentage.
     <ZoomImage id="daily-budget.webp" />
   - **Ad set budget** : Sélectionnez cette option si vous souhaitez définir manuellement quelles audiences recevront plus ou moins de budget. Si vous n'êtes pas tout à fait sûr, vous pouvez sélectionner **Share some of your budget with other ad sets** pour permettre à Meta d'ajuster automatiquement les budgets des ensembles de publicités jusqu'à 20 % si cela améliore les performances.
     <ZoomImage id="ad-set-budget.webp" />
5. Dans **Campaign bid strategy**, sélectionnez l'option la mieux adaptée à vos objectifs :
   - **Highest volume (default)** : l'option la plus simple pour démarrer. En la choisissant, vous laissez Meta optimiser le coût par clic pour obtenir les meilleurs résultats avec votre budget.
   - **Cost per result goal** : visez un certain coût par résultat si vous connaissez vos repères de référence.
   - **Bid cap** : définissez le coût maximum que vous êtes prêt à enchérir.
   <ZoomImage id="campaign-bid.webp" />
6. Adapty vous permet de réaliser des [tests A/B](ab-tests) complets. Vous pouvez également activer des tests A/B dans Meta Ads si nécessaire. Pour en savoir plus sur les tests A/B dans Meta Ads Manager, consultez [cette page](https://www.facebook.com/business/help/1159714227408868).
7. Il est maintenant temps d'ajouter le premier ensemble de publicités à votre campagne. Cliquez sur **Next** pour continuer.

## Étape 4. Créer un ensemble de publicités \{#step-4-create-ad-set\}

Pour créer un ensemble de publicités :
1. Donnez un nom à votre ensemble de publicités dans le champ **Ad set name**.
2. Dans le menu déroulant **Conversion location**, sélectionnez **Website**.
   <ZoomImage id="conversion-location.webp" />
3. Dans le champ **Performance goal**, sélectionnez **Maximize number of landing page views** si vous disposez d'une page de destination, ou **Maximize number of link clicks** si vous utilisez un lien intelligent redirigeant les utilisateurs directement vers le store.

   <ZoomImage id="performance-goal.webp" />

4. Dans le champ **Dataset**, sélectionnez le dataset que vous avez créé à l'[Étape 2](#step-2-add-meta-pixel).
5. Sélectionnez un **Conversion event**. Dans notre cas, ce sera probablement **Purchase** ou **Start trial**. Ne vous inquiétez pas si vous voyez un avertissement indiquant que votre dataset ne contient pas encore d'événements — cela signifie simplement que votre dataset est nouveau.
   <ZoomImage id="conversion-event.webp" />

6. Si vous avez sélectionné **Ad set budget** lors de la configuration de la campagne, choisissez si vous souhaitez un budget **Daily** ou **Lifetime** et saisissez la limite dans votre devise. Le budget **Daily** vous offre plus de flexibilité pendant la phase d'apprentissage : vous pouvez commencer avec des montants modestes et les ajuster progressivement au fil du temps.
   
   Définissez la date de début et, le cas échéant, la date de fin de l'ensemble d'annonces. Par exemple, si vous souhaitez faire la promotion d'une offre promotionnelle dans votre application, il est essentiel que la plage de dates de l'ensemble d'annonces corresponde à la durée de l'offre.

   <ZoomImage id="ad-set-money.webp" />

7. Dans la section **Audience controls**, configurez les paramètres d'audience :
    - **Location** : les zones géographiques peuvent être aussi larges ou précises que nécessaire. Vous pouvez restreindre les **Locations** dans l'ensemble de publicités pour tenir compte des spécificités régionales de vos annonces.
    - **Minimum age** : sélectionnez l'âge minimum des utilisateurs qui verront votre publicité. Pour certaines annonces, cela peut être une obligation légale. Il n'est pas possible de sélectionner un âge minimum inférieur à 18 ans à l'échelle mondiale, ou à 20 ans en Thaïlande.
    - **Language** : renseignez **Language** uniquement si la langue choisie n'est pas la plus courante dans les pays sélectionnés. Par exemple, vous n'aurez pas besoin de sélectionner **English** aux États-Unis, mais si vous ciblez des hispanophones qui y vivent, vous pourrez sélectionner **Spanish**.

<ZoomImage id="meta-audience.webp" width="500px" />

8. Par défaut, Meta trouve automatiquement des groupes de personnes susceptibles d'être intéressées par votre annonce. Cependant, si vous ajoutez une suggestion d'audience, vous pouvez orienter Meta vers les personnes que vous pensez les plus réceptives. Dans la section **Advantage+ audience**, vous pouvez ajuster :
    - **Age** : Définissez une tranche d'âge spécifique pour mieux cibler différents groupes démographiques.
    - **Gender** : Montrez votre annonce à tous les utilisateurs ou ciblez-les par genre.
    - **Detailed targeting** : Ce paramètre vous offre le contrôle le plus précis sur l'audience de votre annonce et/ou application. Vous pouvez y former des groupes basés sur des **Demographics**, des **Interests** ou des **Behaviors**. Selon ce que fait votre application, vous pouvez par exemple cibler des professions spécifiques, des fans de groupes de musique particuliers, des parents de nouveau-nés ou des personnes ayant tendance à beaucoup acheter en ligne.
    :::note
    Les paramètres **Detailed targeting** s'appliquent avec l'opérateur **Or**. Si vous souhaitez appliquer des conditions avec l'opérateur **And**, cliquez sur **Define further** et sélectionnez de nouvelles conditions.
    :::
    <ZoomImage id="advantage-audience.webp" />
9. Dans la section **Placements**, vous pouvez choisir où votre annonce apparaîtra. Par défaut, le paramètre **Advantage+** est sélectionné, ce qui permet à Meta de répartir le budget de votre ensemble d'annonces sur plusieurs placements en fonction de là où ils sont susceptibles d'obtenir les meilleurs résultats. Nous vous recommandons d'utiliser cette option si vous ne savez pas où diffuser votre annonce. Si vous souhaitez sélectionner des placements spécifiques manuellement, choisissez **Manual placements** et personnalisez-les. En savoir plus [ici](https://www.facebook.com/business/help/965529646866485).

<ZoomImage id="meta-placements.webp" width="500px" />
10. **Recommandé** : Le ciblage par appareil vous aide à optimiser vos dépenses. Dans la section **Placements**, cliquez sur **Show more settings**. Dans la sous-section **Devices and operating system**, sélectionnez les appareils, systèmes d'exploitation et versions d'OS à inclure dans votre audience. Vos annonces ne seront ainsi diffusées qu'aux utilisateurs pertinents. Par exemple, les utilisateurs sur ordinateur ne verront pas votre annonce, et ceux dont la version d'OS n'est pas prise en charge par votre application seront exclus.
    <ZoomImage id="meta-devices.webp" width="500px" />
11. Lorsque vous êtes prêt, cliquez sur **Next** pour continuer.

## Étape 5. Créer des publicités \{#step-5-create-ads\}

Pour créer une publicité dans Meta Ads Manager :

1. Donnez un nom à votre annonce dans le champ **Ad name**.
2. Dans la section **Identity**, sélectionnez la page Facebook qui sera utilisée pour publier les annonces. Si vous avez un compte Instagram dédié à votre application et que vous l'avez connecté dans Meta Business Suite à l'[Étape 1](#step-1-create-meta-ads-manager-account), sélectionnez-le dans le menu déroulant **Instagram account**. Sinon, sélectionnez **Use Facebook page** pour que les annonces Instagram soient publiées via la page Facebook.
   <ZoomImage id="meta-identity.webp" width="500px" />
3. Dans **Ad setup**, choisissez la façon dont vous souhaitez publier votre annonce. Pour la promotion d'applications, nous recommandons de sélectionner **Create ad**, afin que votre publication redirige les utilisateurs vers votre application plutôt que vers la page Facebook. Dans le champ **Format**, sélectionnez une option selon le nombre de créatifs dont vous disposez et la façon dont vous souhaitez les afficher.
   <ZoomImage id="meta-ad-setup.webp" width="500px" />
4. Dans la section **Destination**, conservez **Website** comme **Main destination**. Dans le champ **Website URL**, collez `https://api-ua.adapty.io/api/v1/attribution/click`. Dans [Adapty Attribution](adapty-user-acquisition), [créez une campagne web](ua-facebook) et collez le contenu du **Click link** après `https://api-ua.adapty.io/api/v1/attribution/click` dans le champ **URL parameters** de la section **Tracking**.
   <ZoomImage id="meta-destination.webp" width="700px" />
5. Dans la section **Ad creative**, cliquez sur **Set up creative** et sélectionnez **Image ad** ou **Video ad**. Une nouvelle fenêtre s'ouvre pour vous permettre d'importer des fichiers médias, de les recadrer et d'ajouter des textes.
   <ZoomImage id="meta-creative.webp" width="500px" />
6. Si vous souhaitez traduire automatiquement les textes de votre annonce, dans la section **Languages**, cliquez sur **Add languages**. Ajoutez ensuite une langue principale — elle récupérera automatiquement les textes de votre créatif. Ajoutez ensuite les langues de traduction pour la traduction automatique.
   <ZoomImage id="meta-languages.webp" width="500px" />
7. Lorsque vous êtes prêt, cliquez sur **Publish** pour lancer votre annonce.
