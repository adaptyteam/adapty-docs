:::important
Avant de commencer, assurez-vous d'avoir la version requise du SDK Adapty installée :
- **Paywall Builder ou paywalls personnalisés** : 3.6.1 ou ultérieur (iOS), 3.15 ou ultérieur (Android et cross-platform)
- **Flow Builder** : 4.0 ou ultérieur (toutes les plateformes)
:::

Avec Adapty, vous pouvez créer un paywall ou un [flow](adapty-paywall-builder) avec un bouton qui redirige vos utilisateurs vers leur navigateur pour effectuer un paiement. Ensuite, lorsqu'ils reviennent dans votre app après un achat réussi, l'abonnement s'active.
Cela vous permet de contourner les frais du store tout en suivant les paiements des utilisateurs.

<ZoomImage id="web_paywall.gif" width="700px" alt="Démo du paywall web" />

:::tip
L'App Store n'autorise les options de paiement externe qu'aux États-Unis et au Japon.

Pour utiliser un paywall exclusivement sur ces marchés, dupliquez votre paywall actuel et configurez un paywall web. Vous aurez ainsi deux paywalls presque identiques en service : un pour les États-Unis et le Japon, et un autre pour tout le monde.
:::

## Fonctionnement \{#how-it-works\}

Un paywall web est une URL unique générée pour chacun de vos paywalls intégrés. Elle s'ouvre dans le navigateur pour le paiement et fonctionne avec différents fournisseurs de paiement (Stripe, Paddle et autres), prenant en charge aussi bien une simple page avec un bouton Apple Pay que des flows plus complexes avec des offres supplémentaires.

<ZoomImage id="web-paywall-promo.png" width="700px" alt="Aperçu du paywall web" />

Les paywalls web fonctionnent de la façon suivante :
1. **Configurez l'apparence et le comportement de la page du paywall web** dans l'éditeur de paywall web.
2. **Associez le paywall web** dans les paramètres du paywall.
3. Dans le paywall de votre app, **ajoutez un bouton** qui redirige les utilisateurs vers le navigateur.
4. Lorsque les utilisateurs appuient sur le bouton, le SDK Adapty **génère une URL unique**.
5. Les utilisateurs **accèdent à la page du paywall web** et **paient** leur abonnement via un mode de paiement externe.
6. Lorsqu'ils reviennent dans l'app, le SDK Adapty **interroge les mises à jour du profil** pour confirmer que l'abonnement est activé.
7. Adapty enregistre l'achat et surveille l'abonnement pour détecter les changements de statut, comme les renouvellements ou les annulations.

## Étape 1. Créer un paywall web \{#step-1-create-a-web-paywall\}

1. Choisissez un paywall avec lequel travailler :
   - Pour activer les paiements externes sur un paywall existant, [dupliquez-le](duplicate-paywalls). Cela vous permet d'afficher le paywall web à votre segment cible et l'original à tous les autres.
   - Pour repartir de zéro, [créez](create-paywall) un nouveau paywall.
2. Sur la page Paywall, passez à l'onglet **Web paywall** et cliquez sur **Create web paywall**. Vous serez redirigé vers une nouvelle page.   
<ZoomImage id="web-paywall-1.png" width="700px" alt="Onglet Web paywall dans les paramètres du paywall" />
3. Configurez le paywall web et connectez un mode de paiement.
:::tip
Pour obtenir de l'aide sur la configuration de l'éditeur externe et la connexion d'un fournisseur de paiement, consultez le [guide de démarrage rapide](web-paywall-configuration).
:::
4. Retournez à la page **Web paywall** et collez le lien du paywall.
:::important
Lorsque vous déployez votre paywall en production, assurez-vous d'utiliser le lien correct généré après la publication de votre paywall web. Le format du lien est `paywalls-....fnlfx.com`.
:::
5. Cliquez sur **Save**.
<ZoomImage id="web-paywall-4.png" width="700px" alt="Collage du lien du paywall web et enregistrement" />

## Étape 2. Déclencher le paywall \{#step-2-trigger-the-paywall\}

Pour utiliser votre paywall web, vous devez le déclencher, et la façon de procéder dépend de votre configuration :

- Si vous utilisez le Flow Builder, il vous suffit d'[ajouter un nouveau bouton](#step-2a-add-a-web-purchase-button) qui utilisera le lien que vous avez fourni pour suivre les achats et renvoyer les données à Adapty.
- Si vous utilisez le SDK, vous devez configurer la méthode [`openWebPaywall`](#step-2b-set-up-the-sdk-method) pour gérer les paywalls web.

### Étape 2a. Ajouter un bouton d'achat web \{#step-2a-add-a-web-purchase-button\}

Si vous utilisez le **Flow Builder**, vous devez ajouter un bouton de paywall web. Ce bouton utilisera le lien que vous avez fourni pour suivre les achats et renvoyer les données à Adapty.

1. Ouvrez le flow et ajoutez un bouton.
   
   Si vous utilisez un modèle ou un paywall existant, ajoutez un bouton de paywall web à côté du bouton d'achat existant. Vous pouvez le configurer de la même façon.

2. Dans le panneau **Interactions** à droite, cliquez sur **Add trigger**. Ensuite, assignez l'action **Purchase** à ce déclencheur.
   <ZoomImage id="on-tap-purchase.webp" width="500px" />
3. Dans les paramètres de l'action, passez à l'onglet **Web payment**. Là, sélectionnez un produit et — optionnellement — une offre à associer au bouton d'achat web.

4. Collez le lien du paywall web dans le champ **Web paywall URL**.

5. Par défaut, les paywalls web s'ouvrent dans un navigateur intégré à l'app pour que les utilisateurs n'aient pas à la quitter. Si vous souhaitez les ouvrir dans un navigateur externe, sélectionnez **Open in external browser**.

<ZoomImage id="web-payment-action.webp" width="500px" />

## Étape 3. Configurer un placement \{#step-3-set-up-a-placement\}

Étant donné que l'App Store n'autorise les options de paiement externe qu'aux États-Unis et au Japon, créez un segment d'utilisateurs distinct pour les utilisateurs iOS de ces marchés et configurez un placement pour cibler différents paywalls selon les segments. Pour les utilisateurs Android, aucune restriction géographique ne s'applique — créez un segment Android distinct sans filtre par pays.

1. [Créez un nouveau segment](segments) avec les attributs suivants :
   - **Country from store account** : United States, Japan
   - **Platform** : iOS and iPadOS
   - **App version** : La dernière version utilisant le SDK Adapty.
<ZoomImage id="web-paywall-6.png" width="700px" alt="Attributs du segment pour le ciblage du paywall web" />
2. [Créez](create-placement) un placement ou [modifiez](edit-placement) un placement existant. [Ajoutez une nouvelle audience](add-audience-paywall-ab-test) avec le paywall web et le segment créé.
<ZoomImage id="web-paywall-7.png" width="700px" alt="Placement avec l'audience du paywall web" />
