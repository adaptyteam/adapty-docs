Adapty Attribution vous aide à connecter les dépenses publicitaires aux revenus d'abonnement dans vos campagnes web-to-app, vous offrant une vue complète de l'économie de votre application en un seul endroit.

Pour consulter vos données de revenus dans Adapty Attribution, vous devez d'abord activer l'intégration dans l'Adapty Dashboard. Vous n'avez pas besoin de fournir de clés API, tokens ou identifiants. Il vous suffit de mettre à jour et de configurer le SDK.

:::important
L'attribution Adapty est disponible avec :
- iOS, Android et Flutter SDK version 3.9.1 ou supérieure.
- React Native et Capacitor SDK version 3.10.0 ou supérieure.
- Unity SDK version 3.12.0 ou supérieure.
- Kotlin Multiplatform SDK version 3.15.0 ou supérieure.

À partir de la version 4.1 du SDK, l'attribution Adapty est désactivée par défaut dans le SDK. [Activez-la dans le code de votre application](#step-1-enable-adapty-attribution-in-the-sdk).
:::

## Avant de commencer \{#before-you-start\}

Pour relier vos données de revenus aux performances de vos campagnes, laissez Adapty suivre vos achats :

- Si vous **avez déjà des achats intégrés implémentés avec Adapty**, vous n'avez rien d'autre à faire à cette étape.
- Si vous **n'avez pas encore d'achats intégrés implémentés et souhaitez utiliser Adapty**, suivez les étapes du [guide de démarrage rapide](quickstart) pour déléguer la gestion des achats à Adapty.
- Si vous **avez déjà des achats intégrés implémentés sans Adapty** et ne prévoyez pas de migrer vers Adapty, [installez le SDK Adapty pour votre plateforme en mode observateur](implement-observer-mode). À cette étape, vous devez simplement ajouter le SDK à votre projet, l'activer avec le mode observateur activé, et signaler les transactions :

Cette configuration active l'attribution web-vers-app :
- Quand des utilisateurs installent votre application, le SDK Adapty récupère les détails de l'installation à partir des paramètres du lien, ce qui permet à Adapty Attribution d'obtenir les informations de campagne.
- Le SDK Adapty connaît tous les événements liés aux revenus au sein de l'application et peut les attribuer aux campagnes web.

## Étape 1. Activer l'attribution Adapty dans le SDK \{#step-1-enable-adapty-attribution-in-the-sdk\}

À partir de la version 4.1 du SDK Adapty, l'attribution Adapty est désactivée par défaut. Pour permettre au SDK d'enregistrer les installations et de transmettre les détails d'installation à votre application, activez-la lors de l'initialisation du SDK :

<Tabs groupId="current-os" queryString>
<TabItem value="swift" label="Swift" default>

```swift showLineNumbers
let configurationBuilder = AdaptyConfiguration
    .builder(withAPIKey: "YOUR_PUBLIC_SDK_KEY")
    .with(adaptyAttributionEnabled: true)
```

</TabItem>
<TabItem value="kotlin" label="Kotlin">

```kotlin showLineNumbers
val config = AdaptyConfig.Builder("YOUR_PUBLIC_SDK_KEY")
    .withAdaptyAttributionEnabled(true)
    .build()

Adapty.activate(applicationContext, config)
```

</TabItem>
<TabItem value="java" label="Java">

```java showLineNumbers
AdaptyConfig config = new AdaptyConfig.Builder("YOUR_PUBLIC_SDK_KEY")
    .withAdaptyAttributionEnabled(true)
    .build();

Adapty.activate(getApplicationContext(), config);
```

</TabItem>
</Tabs>

Dans les versions du SDK inférieures à 4.1, Adapty Attribution est activé automatiquement — aucune modification du code n'est nécessaire.

## Étape 2. Ouvrez Adapty Attribution

:::important
Si **Attribution** n'apparaît pas lorsque vous cliquez sur le logo Adapty, effacez les cookies et les données du site adapty.io dans les paramètres de votre navigateur, puis rechargez la page.
:::

Cliquez sur le logo Adapty dans l'en-tête et choisissez **Attribution**.

<ZoomImage id="product-switcher.webp" width="500px" alt="Adapty product switcher" />

Les événements d'abonnement commencent automatiquement à affluer dans Adapty Attribution. Les données de campagne apparaissent après avoir connecté une source de données à l'étape 3.

Pour suspendre la diffusion des événements, ouvrez **Integrations > Adapty** dans l'Adapty Dashboard et désactivez le bouton.

### Événements pris en charge \{#supported-events\}

Par défaut, Adapty envoie trois groupes d'événements à Adapty Attribution :

- Essais
- Abonnements
- Problèmes

Consultez la [liste complète des événements pris en charge](events).

<ZoomImage id="events-ua.png" width="700px" alt="Événements envoyés à Adapty Attribution" />

## Étape 3. Connectez votre plateforme publicitaire et ajoutez des liens de suivi \{#step-3-connect-your-ad-platform-and-add-tracking-links\}

Adapty utilise des liens de suivi pour associer les installations d'applications aux données de campagne.
Vous devez utiliser un lien de suivi comme URL de destination dans chaque campagne publicitaire que vous souhaitez mesurer dans Adapty Attribution.

Si vous diffusez des publicités sur plusieurs plateformes, configurez des liens de suivi pour chaque plateforme séparément.

Adapty fonctionne avec les plateformes publicitaires de deux manières :

- **Intégrations natives (Meta Ads, TikTok Ads).** Adapty se connecte directement à la plateforme publicitaire. Les liens de suivi sont générés automatiquement, et les paramètres de campagne sont remplis dynamiquement selon l'endroit où le lien est utilisé. Vous pouvez utiliser le même lien dans différentes campagnes, ensembles de publicités ou créatifs, et Adapty recevra automatiquement les données de campagne et les dépenses publicitaires correctes.

- **Liens de tracking uniquement (toutes les autres plateformes publicitaires).** Adapty ne se connecte pas à la plateforme publicitaire. Les liens de tracking sont créés manuellement et tous les paramètres de campagne doivent être définis explicitement lors de la création du lien. Les données de dépenses publicitaires ne sont pas disponibles pour ces plateformes.

<Tabs>
<TabItem value="meta" label="Meta Ads" default>
Pour créer un lien de tracking pour Meta Ads :
1. Rendez-vous dans [Integrations > Meta](https://app.adapty.io/ua/integrations/facebook/accounts) dans l'Adapty Attribution Dashboard et cliquez sur **Continue with Facebook**.

<ZoomImage id="ua-connect-meta.webp" width="700px" />
2. Connectez-vous avec votre compte Facebook et cliquez sur **Continue**.

<ZoomImage id="ua-fb-sign.webp" width="500px" />

3. Vérifiez les permissions demandées et cliquez sur **Save**.
4. Passez à l'onglet **Web campaigns** et cliquez sur **Create campaign**. Sélectionnez l'application et cliquez sur **Save**.

<ZoomImage id="ua-new-campaign.webp" width="500px" />

5. Dans l'onglet **General**, développez la section **iOS** et/ou **Android** et collez les URL de l'application App Store et/ou Google Play. Ensuite, cliquez sur **Save**.

<ZoomImage id="ua-url.webp" width="900px" />

6. Copiez la valeur du champ **Click link** pour **un seul lien** ou pour un lien spécifique à une plateforme. Ensuite, dans Meta Ads Manager, ouvrez votre annonce et collez ce lien comme URL de destination.

:::important
Dans le champ **Website URL**, collez `https://api-ua.adapty.io/api/v1/attribution/click`. Collez le reste du lien dans le champ **URL parameters** de la section **Tracking**. Cela aidera votre annonce Meta à être approuvée. Consultez les [recommandations sur la configuration de vos annonces dans Meta Ads Manager](meta-create-campaign).
:::

7. Désormais, lorsque vous lancez votre publicité dans Meta Ads, ses données seront disponibles pour analyse dans le tableau de bord Adapty Attribution.
</TabItem>
<TabItem value="tiktok" label="TikTok for Business">
Pour créer un lien de suivi pour TikTok for Business :
1. Rendez-vous dans [Integrations > TikTok Ads](https://app.adapty.io/ua/integrations/tiktok/accounts) dans l'Adapty Attribution Dashboard et cliquez sur **Continue with TikTok**.
   <ZoomImage id="ua-connect-tiktok.webp" width="700px" />
2. Connectez-vous avec votre compte TikTok et cliquez sur **Continue**.

3. Vérifiez les autorisations demandées et cliquez sur **Save**.

<ZoomImage id="ua-tiktok-sign.webp" width="500px" />
4. Passez à l'onglet **Web campaigns** et cliquez sur **Create campaign**. Sélectionnez l'application et cliquez sur **Save**.

    <ZoomImage id="ua-new-campaign-tiktok.webp" width="500px" />

5. Dans l'onglet **General**, développez la section **iOS** et/ou **Android** et collez les URL de l'application App Store et/ou Google Play. Puis cliquez sur **Save**.

    <ZoomImage id="ua-url.webp" width="900px" />

6. Copiez la valeur du champ **Click link** pour **un lien** ou pour un lien spécifique à une plateforme. Ensuite, dans TikTok Ads Manager, lors de la création de votre annonce, collez cette valeur dans le champ **Tracking URL** sous la section **Advanced Settings**. Cela permettra à Adapty de relier les installations et les achats aux annonces dans TikTok. Consultez le [guide de configuration de votre campagne dans TikTok Ads](tiktok-create-campaign).

    <ZoomImage id="ua-lnk.webp" width="900px" />
7. Désormais, lorsque vous lancez votre annonce dans TikTok for Business, ses données seront disponibles pour analyse dans le tableau de bord Attribution d'Adapty.

</TabItem>
<TabItem value="others" label="Autres plateformes publicitaires">
Pour créer un lien de suivi pour d'autres plateformes publicitaires :

1. Dans le tableau de bord Adapty Attribution, accédez à **Tracking links** depuis le menu latéral. Cliquez ensuite sur **Create link**.

    <ZoomImage id="new-tracking-link.webp" width="700px" />

2. Sélectionnez votre application dans la liste et cliquez sur **Next**.

    <ZoomImage id="ua-choose-app.webp" width="700px" />

3. Renseignez les paramètres du lien pour le faire correspondre à la campagne et à la publicité que vous souhaitez suivre.
4. Par défaut, vous créez un One Link. Il détecte automatiquement la plateforme de l'utilisateur et le redirige vers l'App Store ou Google Play après avoir enregistré le clic.

    Si vous préférez utiliser des URL de redirection distinctes pour chaque plateforme, décochez la case **One Link** et renseignez manuellement les liens de store propres à chaque plateforme.

    <ZoomImage id="one-link.webp" width="700px" />

5. Cliquez sur **Create**.
6. Ouvrez la page de votre lien de suivi et copiez le **Click link** depuis l'une des sections :
    - **One link** – utilisez ce lien pour suivre les clics et rediriger automatiquement les utilisateurs vers le bon store.
    - **iOS link** ou **Android link** — versions spécifiques à chaque plateforme, si vous souhaitez des liens séparés pour chaque store.
7. Accédez à votre plateforme publicitaire et collez le lien dans votre annonce en tant qu'URL de destination.

</TabItem>
</Tabs>

## Étape 4. Lancez votre campagne web-to-app et consultez les résultats \{#step-4-launch-your-web-to-app-campaign-and-view-results\}

Une fois votre campagne en ligne et les utilisateurs qui commencent à installer votre application, Adapty attribue les installations et les revenus à vos campagnes.

Dans le [tableau de bord d'analytics d'attribution Adapty](ua-analytics), vous verrez des métriques au niveau de la campagne, telles que :
- Installations et conversions
- Revenus des abonnements et des achats
- Répartition des performances par plateforme publicitaire, campagne, ensemble d'annonces et créatif

Les métriques apparaissent dès que les événements d'installation et de revenus sont reçus depuis votre application. Les données de dépenses publicitaires sont disponibles pour les plateformes disposant d'intégrations natives.
