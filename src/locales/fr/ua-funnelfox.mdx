[FunnelFox](https://funnelfox.com) est une plateforme de funnel web2app qui vous permet d'acquérir et de facturer des utilisateurs en dehors de l'App Store, en contournant ses frais et autres restrictions.

Configurez cette intégration pour envoyer les données d'achat FunnelFox à Adapty. Adapty met ensuite en regard vos revenus web et vos dépenses publicitaires, afin que vous puissiez voir ce que chaque campagne, ensemble de publicités et publicité a rapporté.

## Comment ça fonctionne \{#how-it-works\}

Lorsqu'un utilisateur finalise un achat dans votre funnel FunnelFox, FunnelFox envoie l'événement de transaction à Adapty Attribution. Adapty utilise le **Project ID** pour identifier à quelle application appartient la transaction. L'événement est ensuite stocké et apparaît dans vos analyses Adapty Attribution.

Une fois l'intégration active, chaque transaction dans Adapty comprend :

- **Événement du cycle de vie de l'abonnement** : démarré, renouvelé, annulé, essai converti, remboursé, et plus encore
- **Canal d'attribution** : Facebook, TikTok, Google, ou organique. Adapty le détermine à partir du click ID, que les réseaux publicitaires ajoutent automatiquement — vous n'avez rien à configurer.
- **Données d'attribution** : identifiants de campagne, d'ensemble de publicités et de publicité ; paramètres UTM ; click IDs de plateforme (fbclid, ttclid, gclid). La campagne, l'ensemble de publicités et la publicité ne sont disponibles que si vos annonces contiennent les [paramètres de suivi](#step-3-tag-your-ad-urls) d'Adapty.
- **Données de funnel et d'expérience** : nom du funnel FunnelFox et nom de l'expérience, pour comparer les variantes de tests A/B
- **Date de cohorte** : la date du premier démarrage d'essai ou achat. Les achats web n'ayant pas d'événement d'installation d'application, Adapty les regroupe en cohortes selon cette date.

## Configurer l'intégration \{#configure-integration\}

:::note
Vous n'avez pas besoin du [pixel web Adapty](ua-web-pixel) sur un funnel FunnelFox — FunnelFox signale les achats à Adapty directement.
:::

### Étape 1. Obtenez votre Project ID dans FunnelFox \{#step-1-get-your-project-id-in-funnelfox\}

1. Dans votre tableau de bord FunnelFox, cliquez sur **Settings** dans la barre latérale gauche.
2. Dans la section **Project info**, copiez la valeur **ID**.

<ZoomImage id="ff-project-id.webp" width="500px" />

### Étape 2. Ajouter le projet dans Adapty Attribution

1. Dans Adapty Attribution, accédez à [**Integrations > FunnelFox**](https://app.adapty.io/ua/integrations/funnelfox).
2. Collez l'ID de projet que vous avez copié depuis FunnelFox.
3. Cliquez sur **Save**.

Pour connecter des projets FunnelFox supplémentaires, cliquez sur **Add project** et répétez cette étape pour chacun d'eux.

<ZoomImage id="ua-funnelfox.webp" width="500px" />

### Étape 3. Taguez vos URLs publicitaires \{#step-3-tag-your-ad-urls\}

FunnelFox ne peut transmettre que les données de campagne qui parviennent à l'URL de votre page de destination, et il lit cette URL à l'arrivée du visiteur — pas lors du paiement. Ajoutez les paramètres de suivi d'Adapty à vos publicités, comme décrit dans [Taguez vos URLs publicitaires pour les web funnels](ua-tag-ad-urls).

### Étape 4. Activer l'attribution de campagne dans FunnelFox \{#step-4-turn-on-campaign-attribution-in-funnelfox\}

:::note
Ce paramètre est désactivé par défaut, et FunnelFox ne comble pas les données manquantes : les transactions effectuées avant son activation ne seront jamais transmises à Adapty.
:::

1. Dans FunnelFox, accédez à [**Integrations > Adapty**](https://app.funnelfox.com/integrations/adapty).
2. Activez **Campaign attribution**.

Activez cette option pour chaque projet FunnelFox que vous avez connecté.

Votre projet FunnelFox doit appartenir à une organisation, et vos comptes publicitaires doivent être connectés dans Adapty.

Pour les événements que FunnelFox envoie via ce canal, consultez [l'intégration Adapty](https://funnelfox.com/docs/integrations/subscription-management/adapty#campaign-attribution) dans la documentation FunnelFox.
