Adapty fonctionne avec les outils de codage IA et les agents. Utilisez-les pour intégrer le SDK, poser des questions sur vos analyses ou consulter la documentation Adapty sans quitter votre éditeur. Cette page liste ce qui est disponible et à qui chaque outil s'adresse.

## Intégrer le SDK Adapty avec l'IA \{#integrate-the-adapty-sdk-with-ai\}

Deux façons d'ajouter le SDK Adapty à votre application avec un outil de codage IA. Les deux fonctionnent avec Cursor, Claude et d'autres assistants IA.

### Intégration guidée par skill \{#skill-based-integration\}

Le skill d'intégration du SDK Adapty effectue toute l'intégration depuis votre outil de codage IA en une seule commande. Utilisez-la pour un démarrage guidé et automatisé.

Choisissez votre plateforme : [iOS](adapty-sdk-integration-skill) · [Android](adapty-sdk-integration-skill-android) · [React Native](adapty-sdk-integration-skill-react-native) · [Flutter](adapty-sdk-integration-skill-flutter) · [Unity](adapty-sdk-integration-skill-unity) · [Kotlin Multiplatform](adapty-sdk-integration-skill-kmp) · [Capacitor](adapty-sdk-integration-skill-capacitor)

### Intégration étape par étape \{#step-by-step-integration\}

Guidez votre outil IA à travers l'intégration étape par étape, en lui fournissant la bonne documentation dans le bon ordre. Utilisez cette approche si vous souhaitez valider chaque étape au fur et à mesure.

Choisissez votre plateforme : [iOS](adapty-cursor) · [Android](adapty-cursor-android) · [React Native](adapty-cursor-react-native) · [Flutter](adapty-cursor-flutter) · [Unity](adapty-cursor-unity) · [Kotlin Multiplatform](adapty-cursor-kmp) · [Capacitor](adapty-cursor-capacitor)

## Migrer depuis RevenueCat avec l'IA \{#migrate-from-revenuecat-with-ai\}

Votre agent de code transfère votre catalogue RevenueCat et vos designs de paywall vers une nouvelle application Adapty avec la CLI Adapty, puis remplace le SDK RevenueCat dans le code de votre application par les identifiants obtenus dans Adapty. Voir [Migration depuis RevenueCat](migration-from-revenuecat).

## Créer et modifier des flows avec un outil de codage IA \{#build-and-edit-flows-with-an-ai-coding-tool\}

Le [skill flow-generator](flow-generator-skill) modifie vos flows Adapty depuis le terminal — ajoutez une locale, réécrivez les textes, ajoutez ou supprimez des écrans, configurez des branchements, ou créez un paywall à partir d'une description. Il prévisualise et valide chaque modification en local, puis enregistre un brouillon pour que vous puissiez le publier.

Avant de publier, le [skill flow-audit](flow-audit-skill) lit le même flow et vérifie s'il est prêt pour la production — déclencheurs, conformité au store, produits et localisation — et rend un verdict de succès ou d'échec.

Si votre application utilise déjà des paywalls, le [skill de migration des placements](migrate-placements-skill) s'en charge : il inventorie vos placements de paywalls, les regroupe par paywall associé et crée un placement de flow pour chacun d'eux, en parallèle des placements existants.

## Gérer Adapty depuis la ligne de commande \{#manage-adapty-from-the-command-line\}

L'[interface en ligne de commande Adapty](developer-cli-quickstart) vous permet de gérer vos entités Adapty — applications, niveaux d'accès, produits, paywalls, flows et placements — depuis le terminal, sans ouvrir le tableau de bord. Comme il s'agit d'un outil en ligne de commande, votre agent de codage IA peut l'exécuter directement.

## Trouvez quoi tester ensuite \{#find-what-to-test-next\}

Le [skill growth-advisor](export-analytics-with-ai) lit vos chiffres d'abonnement via les commandes analytiques de l'Adapty CLI, identifie où votre app perd des revenus et suggère des hypothèses à tester en A/B, regroupées par placement. Il répond aussi à vos questions en langage naturel sur vos métriques — revenus, rétention, LTV, et plus encore. Aucun serveur MCP ni clé API requis.

## Exécuter Adapty Mail depuis un chat \{#run-adapty-mail-from-a-chat\}

Adapty Mail dispose de son propre [serveur MCP](mail-mcp). Connectez-le à Claude, ChatGPT, Claude Code, Codex, Cursor ou un autre client MCP, et votre assistant peut générer et traduire des campagnes, lancer des flows, configurer un domaine d'envoi et consulter les analyses de campagnes, connecté en tant que vous. Aucune clé API n'est nécessaire. Dans un agent de code, ajoutez le [skill Adapty Mail](mail-skill) : il connecte le serveur, demande confirmation avant toute action impliquant l'envoi d'e-mails à de vraies personnes, et explique pourquoi quelqu'un n'a pas reçu un e-mail.

## Exécuter des tests A/B \{#run-ab-tests\}

Le [skill ab-tests](ab-tests-skill) crée, démarre, arrête et remplace des tests A/B de paywall et de flow depuis votre outil de développement IA. Avant chaque étape irréversible, il vous montre qui voit quoi et attend votre confirmation.

## Donnez à votre outil IA les docs Adapty \{#give-your-ai-tool-the-adapty-docs\}

### Docs en texte brut

Chaque doc Adapty est disponible en Markdown — ajoutez `.md` à l'URL de la page, ou cliquez sur **Copy for LLM** sous le titre. Pour plus de contexte, donnez à votre outil l'index [`llms.txt`](https://adapty.io/docs/fr/llms.txt) ou un sous-ensemble spécifique à une plateforme comme [`ios-llms.txt`](https://adapty.io/docs/fr/ios-llms.txt).

### Context7

[Context7](https://context7.com/adaptyteam/adapty-docs) est un serveur MCP qui fournit la documentation Adapty à votre outil d'IA, mais il n'indexe que les extraits de code — pas la prose complète. Utilisez-le pour des exemples de code rapides ; pour des conseils complets, fournissez à votre outil la documentation en texte brut ci-dessus. Context7 fonctionne avec Cursor, Claude Code, Windsurf et d'autres outils compatibles MCP.
