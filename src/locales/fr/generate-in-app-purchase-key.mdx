Adapty utilise la clé d'achat intégré pour valider les achats dans votre application et pour signer les [offres promotionnelles](offers). Générez la clé dans App Store Connect, puis saisissez-la dans deux sections des **App settings** d'Adapty. Si la clé cesse de fonctionner ou doit être remplacée, [remplacez-la](#replace-the-key).

La clé d'achat intégré est différente de la [clé API App Store Connect](app-store-connect-api-key), bien qu'App Store Connect désigne les identifiants des deux clés sous les mêmes noms **Issuer ID** et **Key ID**.

Pour saisir toutes les informations d'identification dans **App settings** > **iOS SDK** en une seule fois, suivez [Configurer l'intégration App Store](app-store-connection-configuration).

## Remplacer la clé \{#replace-the-key\}

Si la clé cesse de fonctionner ou doit être modifiée, enregistrez une nouvelle clé dans Adapty avant de révoquer l'ancienne.

Quand la clé cesse de fonctionner :

- Les achats dans votre application ne débloquent aucun accès, et l'application ne reçoit aucune erreur.
- Les utilisateurs ne peuvent pas utiliser les offres promotionnelles.
- [Refund Saver](refund-saver) ne peut pas répondre aux demandes de consommation.
- Adapty n'affiche aucun avertissement, et le statut dans la section **App Store server notifications** reste **Active**.

Lorsque votre application passe à un autre compte développeur Apple, [remplacez la clé par celle de l'équipe du nouveau propriétaire](transfer-apps#app-store-ios-transfer).

Pour remplacer la clé :

1. Dans Adapty, accédez à [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). Pour identifier la clé qu'Adapty utilise actuellement, dans la section **In-app purchase API (StoreKit 2)**, notez la valeur du champ **Key ID**.
2. [Générez une nouvelle clé](#generate-the-key-in-app-store-connect).
3. [Ajoutez la nouvelle clé dans Adapty](#add-the-key-to-adapty) dans les sections **In-app purchase API (StoreKit 2)** et **App Store promotional offers**, puis cliquez sur **Save**.
4. Une seule clé couvre toutes les apps de votre équipe App Store Connect. Si d'autres apps Adapty utilisent le Key ID de l'étape 1, ajoutez-leur également la nouvelle clé. Remplacez l'ancienne clé sur tous vos serveurs qui l'utilisent.
5. Une clé révoquée cesse de fonctionner dans toutes les apps qui l'utilisent, et il est impossible de la restaurer. Dans App Store Connect, révoquez l'ancienne clé : la clé active portant le Key ID de l'étape 1.

Les utilisateurs qui ont acheté alors qu'Adapty n'avait pas de clé valide obtiennent l'accès lorsqu'ils [restaurent leurs achats](troubleshoot-app-store-integration#a-purchase-succeeds-but-the-customer-loses-access).
