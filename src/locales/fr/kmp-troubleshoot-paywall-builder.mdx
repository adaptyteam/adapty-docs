Ce guide vous aide à résoudre les problèmes courants lors de l'utilisation des paywalls conçus dans le Adapty Paywall Builder avec le SDK Kotlin Multiplatform. Pour les problèmes liés aux flows, consultez [Problèmes courants](flow-common-issues).

## La récupération de la configuration du paywall échoue \{#getting-a-paywall-configuration-fails\}

**Problème** : La méthode `createFlowView` ne parvient pas à créer une vue, ou le flow ne dispose pas de configuration de vue.

**Raison** : Le paywall n'est pas activé pour l'affichage sur l'appareil dans le Paywall Builder.

**Solution** : Activez le bouton **Show on device** dans le Paywall Builder. Vous pouvez également lire la propriété `hasViewConfiguration` sur l'objet `AdaptyFlow` pour vérifier si une configuration de vue est disponible.

## Le nombre de vues de la paywall est trop élevé \{#the-paywall-view-number-is-too-big\}

**Problème** : Le nombre de vues de la paywall affiche le double de la valeur attendue.

**Cause** : Vous appelez peut-être `logShowFlow` (SDK v4+) / `logShowPaywall` dans votre code, ce qui duplique le compteur de vues pour une paywall créée avec l'ancien Paywall Builder. Adapty suit ces vues automatiquement, donc vous n'avez pas besoin de cette méthode.

**Solution** : Assurez-vous de ne pas appeler `logShowFlow` (SDK v4+) / `logShowPaywall` dans votre code pour une paywall créée avec l'ancien Paywall Builder.
