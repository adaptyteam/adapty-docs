## Autorisation \{#authorization\}

Vous devez authentifier vos requêtes API avec votre clé API secrète en tant qu'en-tête d'autorisation. Vous pouvez la trouver dans les [App Settings](https://app.adapty.io/settings/general). Le format est `Api-Key {YOUR_SECRET_API_KEY}`, par exemple : `Api-Key secret_live_...`.

:::important
Les clés API sont spécifiques à chaque application. Si vous avez plusieurs applications, veillez à utiliser des clés différentes pour chacune d'elles.
:::

## Format des requêtes \{#request-format\}

**En-têtes**

Les requêtes vers l'API côté serveur nécessitent des en-têtes spécifiques et un corps JSON. Utilisez les informations ci-dessous pour structurer vos requêtes :

| En-tête      | Description                                                  |
| ------------ | ------------------------------------------------------------ |
| Content-Type | (Requis) Définir sur `application/json` pour que l'API traite la requête. |
| Adapty-Tz    | (Facultatif) Définir le fuseau horaire pour déterminer comment les données sont regroupées et affichées. Utiliser le [format de la base de données de fuseaux horaires IANA](https://en.wikipedia.org/wiki/List_of_tz_database_time_zones) (par exemple, `Europe/Berlin`). |

## Corps \{#body\}

L'API attend un corps au format JSON avec les données nécessaires à la requête.

## Limites de débit \{#rate-limits\}

Le maximum est de 2 requêtes par seconde par clé API. Si cette limite est dépassée, une erreur `429 Too Many Requests` est renvoyée.

## Rotation des clés API \{#rotate-api-keys\}

Si vous devez faire pivoter des clés API secrètes :

1. Dans **Settings → General**, cliquez sur **Generate new key**, puis cliquez sur l'icône de corbeille à côté de l'ancienne clé.
2. Mettez à jour la clé utilisée dans votre application.
