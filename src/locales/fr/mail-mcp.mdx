Adapty Mail exécute un serveur MCP, ce qui permet à un assistant IA de travailler dans votre projet comme vous le faites dans le tableau de bord : générer et localiser des campagnes, lancer des flows, configurer un domaine d'envoi, rechercher des profils et consulter les analyses. L'assistant se connecte avec votre propre compte Adapty Mail et obtient vos permissions dès que vous approuvez la connexion dans le tableau de bord. Aucune clé API n'est nécessaire.

| | |
|---|---|
| Server URL | `https://api-mail.adapty.io/mcp` |
| Protocol | MCP over Streamable HTTP, OAuth 2.1 sign-in |
| Works with | Claude (web and desktop), ChatGPT, Claude Code, Codex CLI, GitHub Copilot CLI, Gemini CLI, Cursor, Windsurf, and any client that supports remote MCP servers with OAuth |

:::tip
Pour de meilleurs résultats dans un agent de code, ajoutez également le [skill Adapty Mail](mail-skill). Il se connecte au serveur à votre place, demande confirmation avant toute action qui envoie des e-mails à de vraies personnes, et couvre le travail après le lancement : résultats, tests A/B et raisons pour lesquelles quelqu'un n'a pas reçu un e-mail.
:::

## Ce que l'assistant peut faire \{#what-the-assistant-can-do\}

Les outils du serveur reflètent le tableau de bord :

| Domaine | Exemples |
|---|---|
| Orientation | Retrouver vos entreprises et projets, identifier les étapes de configuration manquantes |
| Marque | Créer la marque à partir d'une fiche store, la réviser et la modifier |
| Domaines d'envoi | Ajouter un domaine, récupérer ses enregistrements DNS, vérifier la validation, consulter l'état du domaine |
| Destinations | Créer et mettre à jour les pages vers lesquelles pointent vos e-mails |
| Campagnes | Générer une campagne à partir d'un brief, modifier des e-mails, les traduire, envoyer un e-mail de test |
| Flows et segments | Créer des segments et lancer ou modifier des flows |
| Tests A/B | Créer, lancer et terminer des tests |
| Profils | Rechercher un profil et son parcours, désabonner un profil |
| Analytics | Métriques de campagne dans le temps, ventilations, entonnoirs de tests A/B |
| Paramètres | Nom d'expéditeur, adresse de réponse, double opt-in, téléchargements d'images |

Trois workflows guidés sont disponibles sous forme de prompts dans les clients qui les prennent en charge. Dans Claude Code, ils apparaissent comme des commandes slash, par exemple `/mcp__adaptymail__campaign_to_flow` :

- **campaign_to_flow** : Générer une campagne à partir d'un brief, choisir une destination et un segment, puis lancer le flow.
- **campaign_localization** : Traduire une campagne enregistrée dans d'autres langues.
- **domain_onboarding** : Ajouter un domaine d'envoi, publier ses enregistrements DNS et le vérifier.

Certaines étapes de configuration se font uniquement depuis le tableau de bord : votre [adresse d'entreprise](mail-get-started#5-add-your-company-address), le [paiement web](mail-checkout), et [l'activation de l'envoi des données](mail-entry-points).

## Avant de commencer

- **Appartenance au projet** : Votre compte Adapty Mail est membre du projet sur lequel vous souhaitez travailler. L'assistant ne voit que les entreprises et les projets auxquels votre compte a accès.
- **Support client** : Votre client prend en charge les serveurs MCP distants avec OAuth.

:::warning
L'assistant dispose des mêmes droits que vous, et tout ce qu'il fait est réel : enregistrer un flow commence à envoyer des e-mails à de vraies personnes. Le serveur identifie ses outils destructifs, et les assistants que nous avons testés demandent une confirmation avant de les exécuter. Lisez le plan de l'assistant avant de l'approuver.
:::

## Connectez votre assistant \{#connect-your-assistant\}

### Claude (claude.ai et Claude desktop)

1. Pour ajouter le serveur, ouvrez **Settings → Connectors** et cliquez sur **Add custom connector**.
2. Saisissez un nom, par exemple `Adapty Mail`, et l'URL `https://api-mail.adapty.io/mcp`.
3. Laissez **Authentication** sur **Sign in now** et le client OAuth sur la valeur détectée par défaut, puis cliquez sur **Add**.
4. Dans l'onglet Adapty Mail qui s'ouvre, connectez-vous si nécessaire, puis cliquez sur **Approve**.

Les administrateurs de l'espace de travail peuvent ajouter le connecteur une seule fois pour toute l'organisation. Chaque membre se connecte ensuite avec son propre compte Adapty Mail la première fois qu'il l'utilise.

### ChatGPT

ChatGPT ajoute des serveurs MCP personnalisés depuis la page des connecteurs dans **Settings**. Le mode développeur doit être activé pour votre espace de travail.

1. Pour ajouter le serveur, cliquez sur **Create**.
2. Saisissez un nom, par exemple `Adapty Mail`, et l'URL du serveur `https://api-mail.adapty.io/mcp`. Laissez **Authentication** sur **OAuth**.
3. Développez **Advanced OAuth settings**. Sous **Client registration**, définissez **Registration method** sur **Dynamic Client Registration (DCR)**.
4. Acceptez l'avertissement concernant le serveur MCP personnalisé et cliquez sur **Create**.
5. Lorsque ChatGPT vous le demande, connectez le serveur. Dans l'onglet Adapty Mail qui s'ouvre, connectez-vous si nécessaire, puis cliquez sur **Approve**.

:::important
L'étape 3 est obligatoire. Avec la méthode d'inscription par défaut de ChatGPT, la connexion échoue avec une erreur `invalid_request` indiquant que l'ID client est introuvable.
:::

### Claude Code

```bash
claude mcp add --transport http --scope user adaptymail https://api-mail.adapty.io/mcp
```

Pour vous connecter, exécutez `/mcp` dans Claude Code, sélectionnez `adaptymail`, puis choisissez **Authenticate**. Connectez-vous ensuite au tableau de bord Adapty Mail dans votre navigateur et cliquez sur **Approve**.

### Codex CLI

```bash
codex mcp add adaptymail --url https://api-mail.adapty.io/mcp
codex mcp login adaptymail
```

La commande de connexion ouvre votre navigateur, où vous approuvez la connexion. Pour configurer le serveur manuellement, ajoutez-le dans `~/.codex/config.toml`, puis exécutez la commande de connexion :

```toml
[mcp_servers.adaptymail]
url = "https://api-mail.adapty.io/mcp"
```

### GitHub Copilot CLI

```bash
copilot mcp add --transport http adaptymail https://api-mail.adapty.io/mcp
```

La première fois que le serveur se connecte, votre navigateur s'ouvre pour la connexion.

### Gemini CLI

```bash
gemini mcp add --transport http --scope user adaptymail https://api-mail.adapty.io/mcp
```

Démarrez une nouvelle session, puis exécutez `/mcp auth adaptymail` et approuvez la connexion dans votre navigateur.

### Cursor, Windsurf et autres clients

Ajoutez le serveur dans le fichier de configuration MCP du client, par exemple `~/.cursor/mcp.json` :

```json
{
  "mcpServers": {
    "adaptymail": {
      "url": "https://api-mail.adapty.io/mcp"
    }
  }
}
```

Le client ouvre votre navigateur pour vous connecter lors de la première connexion. Les clients qui ne prennent pas en charge OAuth pour les serveurs distants ne peuvent pas se connecter à Adapty Mail.

## Approuver la connexion \{#approve-the-connection\}

Chaque client se termine sur le même écran dans le tableau de bord Adapty Mail. Il indique l'application qui demande l'accès et l'adresse à laquelle elle reçoit cet accès. Pour les outils de bureau, cette adresse se trouve sur votre propre ordinateur (`localhost`), donc n'approuvez que la connexion que vous avez vous-même initiée. Pour terminer, cliquez sur **Approve**.

La demande de connexion expire après 10 minutes. Si l'écran affiche **This request has expired**, recommencez depuis le client.

## Commencer à travailler \{#start-working\}

Demandez à l'assistant de lister vos projets, puis nommez celui sur lequel vous souhaitez travailler. Quelques exemples de requêtes :

- « Montre-moi le statut d'onboarding de mon projet et dis-moi ce qui manque. »
- « Génère une campagne de reconquête pour les utilisateurs dont l'essai a expiré, en anglais, et montre-moi le premier e-mail. »
- « Traduis la campagne Trial expired en allemand et en français. »
- « Ajoute `mail.example.com` comme domaine d'envoi et donne-moi les enregistrements DNS. »
- « Compare les taux d'ouverture et de clic de mes campagnes en ligne sur les 30 derniers jours. »

## Déconnexion \{#disconnect\}

Pour vous déconnecter, supprimez le connecteur dans les paramètres du client. Dans Claude, rendez-vous dans **Settings → Connectors** ; dans ChatGPT, sur la page du connecteur ; dans Claude Code, exécutez `claude mcp remove adaptymail`.

Le token d'accès du client expire en moins d'une heure. Le token de rafraîchissement est révoqué lors de la déconnexion du client ; un token inutilisé expire au bout de 90 jours. Pour vous reconnecter, ajoutez à nouveau le serveur et approuvez la connexion.

## Résolution des problèmes \{#troubleshooting\}

| Problème | Solution |
|---|---|
| ChatGPT échoue avec `invalid_request` et "Client ID ... not found" | Dans les paramètres du connecteur, définissez **Registration method** sur **Dynamic Client Registration (DCR)**. Voir [ChatGPT](#chatgpt). |
| Le tableau de bord indique que la demande de connexion a expiré | Relancez la connexion depuis le client et approuvez-la dans les 10 minutes. |
| L'assistant indique que le projet est introuvable | Votre compte n'est pas membre de ce projet. Demandez l'accès à un propriétaire de l'entreprise. |
| L'assistant a été déconnecté | L'accès expire après une longue période d'inactivité ou après une déconnexion. Reconnectez-vous depuis le client. |
| Le client n'affiche aucun outil | Le client s'est connecté sans authentification. Effectuez l'étape de connexion, par exemple `/mcp` dans Claude Code. |
