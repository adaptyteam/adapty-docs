Si votre backend doit conserver son URL dans App Store Connect, transmettez les notifications de serveur App Store de votre backend vers Adapty sans modification. Si votre backend n'a pas besoin de son URL dans App Store Connect, [configurez le transfert vers votre backend dans Adapty](enable-app-store-server-notifications#raw-events-forwarding) à la place. Cette approche ne nécessite aucun code.

Adapty traite les notifications de votre backend comme si Apple les avait envoyées directement. Avec [Refund Saver](refund-saver), Adapty répond toujours aux demandes de remboursement qui s'y trouvent.

Si votre backend reçoit des notifications en temps réel de Google Play via son propre sujet Pub/Sub, aucun code n'est nécessaire pour les transmettre à Adapty. [Ajoutez un abonnement push pour Adapty à ce sujet](enable-real-time-developer-notifications-rtdn#send-notifications-to-two-adapty-apps).

Pour transmettre les notifications du serveur App Store à Adapty :

1. Dans Adapty, ouvrez l'application à connecter : chaque application Adapty possède sa propre URL de notification. Accédez à [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). Dans la section **App Store server notifications**, copiez l'URL depuis le champ **URL for App Store server notifications**.
2. Dans votre backend, transmettez chaque notification d'Apple à l'URL copiée. Dans chaque requête :

   - Conservez le corps reçu d'Apple sans modification : `{"signedPayload": "…"}`.
   - Définissez l'en-tête `Content-Type: application/json`.
   - N'ajoutez pas d'en-tête `Authorization`.

   Si Adapty transfère également des notifications vers votre backend, ne les renvoyez pas à Adapty.

package main

	"fmt"
	"strings"
	"net/http"
)

func main() {
	url := "https://api.adapty.io/api/v1/sdk/apple/webhook/123a258e62fad41bfa734f4b0dbcad45/" // Replace this with the actual URL

	payload := strings.NewReader(`{"signedPayload":"eyJhbGciOiJFUzI1NiIs..."}`) // Apple's request body, unchanged

	method := "POST"

	client := &http.Client{}
	req, err := http.NewRequest(method, url, payload)
	if err != nil {
		fmt.Println("Error creating request:", err)
		return
	}
	req.Header.Add("Content-Type", "application/json")

	res, err := client.Do(req)
	if err != nil {
		fmt.Println("Error sending request:", err)
		return
	}
	defer res.Body.Close()
}

Une réponse `200` ne confirme pas qu'Adapty a pu utiliser la notification. Adapty répond avant de décoder le payload signé. Pour vérifier que les notifications parviennent à Adapty, effectuez un [achat sandbox](test-purchases-in-sandbox). Vérifiez ensuite que [le statut des notifications](enable-app-store-server-notifications#check-that-notifications-reach-adapty) dans la section **App Store server notifications** indique **Active**.
