La page Change History suit les modifications apportées à votre configuration Apple Ads. Chaque compte (groupe de campagnes) possède son propre historique. Vous pouvez sélectionner le groupe de campagnes actif depuis le menu déroulant.

L'historique couvre les 6 derniers mois jusqu'à aujourd'hui, quelle que soit la date de connexion du compte ou les outils utilisés pour le gérer. Il répertorie les modifications apportées aux entités suivantes :

- Campagnes
- Groupes d'annonces
- Mots-clés
- Mots-clés négatifs
- Annonces

Développez une entrée de la liste pour découvrir [en quoi consistait la modification et qui l'a autorisée](#entry-details).

:::tip
Pour consulter l'historique des modifications depuis le terminal ou avec un agent IA, utilisez les [commandes `change-history` de l'Adapty CLI](developer-cli-ads-manager-reference#change-history).
:::

## Recherche, filtres et contrôles \{#search-filters-and-controls\}

Vous pouvez affiner la liste des modifications avec les filtres suivants :

| Contrôle | Limite la liste à | Par défaut |
|---|---|---|
| Menu déroulant de plage de dates | Une période | Le mois dernier |
| Menu déroulant du type d'objet | **Campaigns**, **Ad groups**, **Keywords**, **Negative keywords** ou **Ads** | Toutes les entités |
| Boutons de type de modification | Modifications **Created**, **Updated** ou **Removed** | Toutes les modifications |
| Champ de recherche | Un seul mot-clé, campagne ou groupe d'annonces (nom exact ou ID, sensible à la casse) | Vide |

## Détails d'une entrée \{#entry-details\}

Les modifications sont regroupées par date, en commençant par la plus récente.

Chaque entrée indique l'objet concerné et son emplacement, par exemple un mot-clé et son groupe d'annonces. Une action groupée apparaît comme une seule entrée, par exemple « 8 mots-clés mis à jour dans 2 groupes d'annonces ».

Cliquez sur l'entrée pour afficher :

- Ce qui a changé, selon le type de modification :
  - **Updated** : Chaque paramètre modifié, avant et après
  - **Created** et **Removed** : Tous les paramètres de l'objet ajouté ou supprimé
- L'identifiant Apple de la personne ayant effectué la modification (Apple ne partage pas les noms d'utilisateur)
- La source de la modification :
  - **Apple Ads UI** : Le tableau de bord Apple Ads
  - **API** : Tous les autres outils, y compris Adapty Ads Manager
  - **APPLE_SUPPORT** : Le support Apple

## Découvrez les corrélations entre les performances de campagne et les changements de paramètres \{#discover-correlations-between-campaign-performance-and-setting-changes\}

Pour identifier les changements susceptibles d'expliquer une hausse ou une baisse d'une métrique :

### Campagnes \{#campaigns\}

1. Ouvrez le graphique de métriques détaillé pour une **Campaign** spécifique
2. Repérez la date que vous souhaitez examiner
3. Cliquez sur le badge au-dessus de cette date.
    - Si le badge n'est pas présent, personne n'a modifié la campagne ou ses groupes d'annonces ce jour-là.
    - Si le badge est présent, un clic affiche l'historique des modifications pour la date indiquée.

<ZoomImage id="change-history-chart-marker.webp" width="700px" alt="Graphique de métriques de campagne avec les modifications effectuées en un jour" />

### Mots-clés et groupes d'annonces \{#keywords-and-ad-groups\}

Ouvrez le graphique de métriques correspondant et repérez la date que vous souhaitez examiner. Ensuite, cherchez les modifications effectuées ce jour-là dans l'onglet **Change history**.

:::tip
Chaque campagne, groupe d'annonces et mot-clé possède son propre historique. L'historique d'un groupe d'annonces n'inclut pas les modifications apportées à sa campagne ou à ses mots-clés. Pour voir toutes les modifications, supprimez les filtres.
:::

## Annuler une modification \{#revert-a-change\}

Vous ne pouvez pas annuler une modification en un seul clic.

1. Inspectez les détails du changement que vous souhaitez annuler
2. Notez la propriété concernée et sa valeur précédente
3. Suivez les instructions spécifiques à l'objet pour définir une nouvelle valeur :
    - **Campaigns** : [Modifier les campagnes](ads-manager-create-campaign#edit-campaigns) et [Lancer et mettre en pause les campagnes](ads-manager-create-campaign#launch--pause-campaigns)
    - **Ad groups** : [Modifier les groupes d'annonces](ads-manager-create-ad-group#edit-ad-groups) et [Lancer et mettre en pause les groupes d'annonces](ads-manager-create-ad-group#launch--pause-ad-groups)
    - **Keywords** : [Modifier les mots-clés](ads-manager-manage-keywords#edit-keywords)
    - **Ads** : [Modifier les annonces](ads-manager-manage-ads#edit-ads) et [Lancer et mettre en pause les annonces](ads-manager-manage-ads#launch--pause-ads)

## Limites de l'attribution \{#attribution-limitations\}

- Apple ne fait pas de distinction entre les différents outils qui utilisent son API. De ce fait, chaque modification effectuée via un outil tiers est marquée **API** sur la page Change History. Il est impossible de différencier une modification faite dans Adapty Ads Manager d'une modification faite par un autre outil.
- Apple ne communique pas les noms d'utilisateurs internes des outils tiers, y compris Adapty Ads Manager. Si une modification provient d'Ads Manager, vous pouvez l'attribuer à un utilisateur ou à une règle d'automatisation spécifique depuis l'[**Bid History**](ads-manager-manage-keywords#bid-history).
