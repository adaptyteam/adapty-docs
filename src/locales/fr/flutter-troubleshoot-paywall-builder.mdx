Ce guide vous aide à résoudre les problèmes courants lors de l'utilisation de paywalls conçus dans le Paywall Builder d'Adapty dans le SDK Flutter. Pour les problèmes liés aux flows, consultez [Problèmes courants](flow-common-issues).

## La récupération de la configuration du paywall échoue \{#getting-a-paywall-configuration-fails\}

**Problème** : La méthode `createPaywallView` n'arrive pas à récupérer la configuration du paywall.

**Cause** : Le paywall n'est pas activé pour l'affichage sur l'appareil dans le Paywall Builder.

**Solution** : Activez le bouton **Show on device** dans le Paywall Builder.

## Le nombre de vues de la paywall est trop élevé \{#the-paywall-view-number-is-too-big\}

**Problème** : Le nombre de vues de la paywall affiche le double du nombre attendu.

**Raison** : Vous appelez peut-être `logShowFlow` (Flutter SDK v4+) / `logShowPaywall` dans votre code, ce qui duplique le nombre de vues d'une paywall créée dans l'ancien Paywall Builder. Adapty enregistre ces vues automatiquement, vous n'avez donc pas besoin de cette méthode.

**Solution** : Assurez-vous de ne pas appeler `logShowFlow` (Flutter SDK v4+) / `logShowPaywall` dans votre code pour une paywall créée dans l'ancien Paywall Builder.

## Autres problèmes \{#other-issues\}

**Problème** : Vous rencontrez d'autres problèmes liés au Paywall Builder qui ne sont pas couverts ci-dessus.

**Solution** : Migrez le SDK vers la dernière version à l'aide des [guides de migration](flutter-sdk-migration-guides) si nécessaire. De nombreux problèmes sont résolus dans les versions plus récentes du SDK.
