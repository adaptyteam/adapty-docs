Utilisez cette intégration si vous faites de la publicité pour une application Android, une application iOS ou un funnel web avec Google Ads. Lorsque vous connectez Google Ads à Adapty Attribution :

- Google enchérit pour les utilisateurs susceptibles de commencer un essai ou de souscrire un abonnement. Adapty envoie ces essais et achats à Google.
- Adapty Attribution affiche les revenus et le ROAS de chaque campagne, avec les dépenses qu'Adapty récupère depuis Google Ads.

## Avant de commencer \{#before-you-begin\}

Assurez-vous que :

- Vous disposez d'un compte Google Ads dans le bon mode :
  - ✅ **Mode Expert** : Vous pouvez créer tous les [types de campagnes pris en charge par Adapty Attribution](#supported-campaign-types).
  - ❌ **Mode Simplifié** : Ne fonctionne qu'avec les campagnes intelligentes, incompatibles avec Adapty Attribution. Un nouveau compte démarre en mode Simplifié si vous créez une campagne intelligente à l'inscription. Passez en mode Expert depuis le menu **Tools** (cette action est irréversible).
- Votre compte Google Ads dispose d'un moyen de paiement.
- Le SDK dans votre application a [Adapty Attribution activé](user-acquisition#step-1-enable-adapty-attribution-in-the-sdk).

## Configurer l'intégration \{#set-up-the-integration\}

1. Dans Adapty Attribution, [connectez votre compte Google](ua-google-ads-settings#connect-your-google-account).
2. Pour créer une configuration dans Adapty Attribution et paramétrer vos campagnes dans Google Ads, suivez le guide correspondant à ce que vous promouvez :
   - Pour une application Android : [Campagnes App Android](google-ads-app-campaigns).
   - Pour une application iOS ou un entonnoir web : [Campagnes Search et Performance Max](google-ads-search-pmax-campaigns).

Vous créez une configuration distincte dans chaque guide, et une même application peut avoir les deux configurations.

:::important
Vous n'avez pas besoin de configurer SKAdNetwork (SKAN), le framework Apple qui rapporte les installations publicitaires sans identifier les utilisateurs. L'attribution Adapty ne l'utilise pas. Si vous utilisez SKAN à d'autres fins, conservez vos paramètres SKAN : ils n'affectent pas l'attribution Adapty.
:::

## Types de campagnes \{#campaign-types\}

### Types de campagnes pris en charge \{#supported-campaign-types\}

| Type de campagne | Où les annonces sont diffusées | Onglet dans Adapty Attribution | Listes de stores compatibles | Compatible avec les funnels web |
|---|---|---|---|---|
| Campagnes applicatives pour les installations (UAC) | Google Search, Google Play, YouTube et le Réseau Display | **App Campaigns** | Google Play | ❌ |
| Search | Résultats Google Search, pour les mots-clés que vous ajoutez | **Other Campaigns** | App Store, Google Play | ✅ |
| Performance Max | Tous les canaux Google depuis une seule campagne : Search, YouTube, Display, Discover, Gmail et Maps | **Other Campaigns** | ❌ | ✅ |
| Demand Gen | YouTube in-feed et Shorts, Discover et Gmail, sous forme d'annonces image et vidéo | **Other Campaigns** | App Store, Google Play | ✅ |
| Display | Annonces bannières sur les sites et applications du Réseau Display Google | **Other Campaigns** | App Store, Google Play | ✅ |
| Video | Annonces vidéo sur YouTube | **Other Campaigns** | App Store, Google Play | ✅ |

### Types de campagnes incompatibles \{#incompatible-campaign-types\}

- **Campagnes de réengagement** : campagnes d'application du sous-type « App engagement ». Elles diffusent des annonces auprès des personnes qui ont déjà votre application. Adapty n'envoie à Google que les événements des nouvelles installations.
- **Campagnes de pré-inscription** : campagnes d'application du sous-type « App pre-registration », pour les applications qui ne sont pas encore disponibles sur Google Play.
- **Campagnes intelligentes** : le seul type de campagne que les comptes Google Ads en mode simplifié peuvent créer.
- **Campagnes Shopping** : campagnes qui présentent des produits issus d'un flux Google Merchant Center. Chaque annonce renvoie vers la page d'un produit sur votre site web, et non vers un store. Google n'autorise pas les annonces Shopping pour les abonnements avec paiements récurrents.

## Comment ça fonctionne \{#how-it-works\}

Le mécanisme d'attribution varie selon le type de campagne :

- **Campagnes applicatives pour les installations (UAC)** :
  - Adapty envoie chaque nouvelle installation à Google.
  - Google vérifie si l'utilisateur a cliqué ou interagi d'une autre façon avec une annonce d'une campagne applicative avant l'installation.
  - Le cas échéant, Google renvoie la campagne, le groupe d'annonces et l'annonce à Adapty.
- **Tous les autres types de campagnes** :
  - Google Ads envoie chaque clic sur une annonce à Adapty.
  - Adapty associe les installations et les achats web à ces clics.

Si l'utilisateur a cliqué sur des publicités provenant de plusieurs campagnes avant l'installation, Adapty attribue l'installation au [dernier clic](adapty-user-acquisition#channels).

### Campagnes App (Android) \{#app-campaigns-android\}

Adapty se connecte à Google Ads en tant que fournisseur tiers d'analyse d'applications. Vous liez Adapty Attribution à votre application dans Google Ads via un App Link ID. Ces campagnes ne nécessitent pas de modèle de suivi.

1. Un utilisateur installe votre application depuis une annonce de campagne App et l'ouvre pour la première fois.
2. Adapty envoie l'installation à Google via le lien ID.
3. Google associe l'installation à l'annonce de campagne App et renvoie la campagne, le groupe d'annonces et l'annonce à Adapty.
4. Adapty envoie les essais et achats de l'utilisateur à Google via le même lien ID.

### Autres campagnes (iOS et Android) \{#other-campaigns-ios-and-android\}

Vous ajoutez le modèle de suivi depuis Adapty Attribution à la campagne dans Google Ads. Un modèle de suivi est un lien que Google Ads charge en arrière-plan chaque fois que quelqu'un clique sur votre annonce.

1. Un utilisateur clique sur la publicité, et Google ajoute un identifiant de clic. Pour les utilisateurs iOS qui n'autorisent pas le suivi, Google utilise un identifiant de clic respectueux de la vie privée, `gbraid` ou `wbraid`, au lieu de `gclid`.
2. Google Ads envoie l'utilisateur vers le store ou votre tunnel web. En parallèle, Google Ads charge le modèle de suivi en arrière-plan. Par ce biais, Google Ads transmet l'identifiant de clic et les détails de la campagne à Adapty.
3. Adapty associe l'installation ou l'achat web à ce clic :
   - **Installations iOS** : Adapty utilise une correspondance probabiliste pour sélectionner le clic qui a le plus probablement conduit à l'installation.
   - **Installations Android** : Adapty utilise une correspondance par identifiant de clic. Si Google Play ne transmet aucun identifiant de clic à votre application, Adapty utilise une correspondance probabiliste.
   - **Achats web** : Adapty lit les détails du clic que votre tunnel web transmet lors du paiement.
4. Adapty envoie les conversions vers le compte Google Ads que vous sélectionnez, associées par identifiant de clic.

#### Comment Adapty associe les installations et les achats aux campagnes \{#how-adapty-matches-installs-and-purchases-to-campaigns\}

Adapty associe chaque achat intégré à la campagne de son installation. Pour associer une installation à un clic, Adapty utilise l'une des deux méthodes suivantes :

| Méthode | Comment Adapty attribue l'installation | Délai maximum entre le clic et l'installation |
|---|---|---|
| Correspondance par ID de clic | Au clic dont l'ID est transmis à votre application par Google Play | 168 heures (7 jours) par défaut, jusqu'à 720 heures |
| Correspondance probabiliste | Au clic récent le plus probable provenant de la même plage d'adresses IP et du même système d'exploitation | 6 heures par défaut, jusqu'à 24 heures |

Pour une correspondance probabiliste, Adapty sélectionne le clic qui obtient le meilleur score selon le temps écoulé depuis le clic, la langue de l'appareil et le pays. Adapty n'utilise pas l'identifiant publicitaire (IDFA), donc la correspondance probabiliste couvre les utilisateurs iOS qui n'autorisent pas le suivi.

Adapty ne peut pas faire correspondre une installation de manière probabiliste si l'appareil change de réseau entre le clic et l'installation, par exemple en passant du Wi-Fi au réseau cellulaire. Sur les réseaux partagés par de nombreux appareils, comme les réseaux des opérateurs mobiles, Adapty fait correspondre moins d'installations de manière probabiliste. L'attribution Adapty affiche alors une installation non attribuée sans détails de campagne : sous le canal **Google Play** si elle possède un identifiant de clic, et sous **Organic** si ce n'est pas le cas.

#### Modifier les limites de temps pour la correspondance \{#change-the-time-limits-for-matching\}

Les limites de temps ne s'appliquent pas aux campagnes App, car c'est Google qui détermine quelles installations en proviennent.

1. Dans l'en-tête d'Adapty Attribution, sélectionnez l'application à promouvoir.
2. Allez dans **Integrations** > **Google Ads**. Dans l'onglet **Other Campaigns**, ouvrez la configuration depuis laquelle vous avez copié le modèle de suivi.
3. Sélectionnez l'onglet **Settings**.
4. Dans la section **New user attribution**, saisissez chaque limite en heures :
   - **Deterministic Matching Window** : Pour une correspondance par ID de clic.
   - **Probabilistic Matching Window** : Pour une correspondance probabiliste. Si vous définissez plus de 6 heures, les clics survenus plus de 6 heures avant l'installation doivent également correspondre au modèle d'appareil et à la version du système d'exploitation de l'installation.

   Gardez les interrupteurs des deux champs activés : sans correspondance probabiliste, Adapty ne peut pas associer les installations iOS.

## Gardez vos données Google Ads précises dans l'attribution Adapty \{#keep-google-ads-data-accurate-in-adapty-attribution\}

Pour ventiler les données Google Ads dans [les analyses d'attribution Adapty](ua-analytics), sélectionnez l'une des options suivantes dans **Group by** :

| Regrouper par | Ce que c'est dans Google Ads | Dépenses rapportées pour | Répartition par pays |
|---|---|---|---|
| **Campaign** | Un ensemble de groupes d'annonces partageant un budget, une stratégie d'enchères et un ciblage uniques | Tous les types de campagnes | Exacte, telle que Google la rapporte |
| **Adset** | Un groupe d'annonces : un ensemble d'annonces au sein d'une campagne. Dans une campagne Search, un groupe d'annonces contient également des mots-clés. Les campagnes Performance Max utilisent des groupes de ressources à la place | Tous les types de campagnes sauf Performance Max | Exacte, telle que Google la rapporte |
| **Ad** | Le texte, l'image ou la vidéo que voient les utilisateurs | Tous les types de campagnes sauf Performance Max | Estimée : Google ne rapporte pas les annonces par pays, donc Adapty répartit les chiffres de chaque annonce entre les pays de la même façon que les chiffres de son groupe d'annonces se répartissent |
| **Keyword** | Un mot ou une expression que vous ajoutez à un groupe d'annonces d'une campagne Search. Google affiche les annonces du groupe d'annonces dans les recherches correspondant au mot-clé | Campagnes Search uniquement | Non disponible |

Adapty importe également les comptages de conversions, les estimations d'enchères par mot-clé et les statuts de campagne directement depuis Google. Pour les afficher dans le tableau d'analyse, sélectionnez le [preset Google Ads](ua-analytics#google-ads-preset). Pour la description de chaque colonne, consultez les [métriques Google Ads](ua-metrics#google-ads-metrics).

Pour que les données restent précises et lisibles :

- **Promouvez une seule application par campagne** : Adapty ajoute la totalité des dépenses d'une campagne à chaque application qu'elle promeut. Pour une campagne menant à un funnel web, il s'agit de l'application depuis laquelle vous avez copié le modèle de suivi.
- **Collez le modèle de suivi dans toutes vos campagnes** : Il est obligatoire pour chaque campagne non-UAC. Si vous l'omettez, Adapty Attribution affiche les installations, mais pas les détails de la campagne : les installations Android sous le canal **Google Play**, et les installations iOS sous **Organic**. Adapty Attribution peut toujours afficher les dépenses de la campagne, mais pas ses revenus, ce qui fait paraître son ROAS faible.
- **Supprimez les autres modèles de suivi de vos campagnes** : Google Ads n'envoie pas à Adapty les clics sur un groupe d'annonces, une annonce ou un mot-clé disposant de [son propre modèle de suivi](google-ads-search-pmax-campaigns#add-the-tracking-template-to-an-existing-campaign).
- **Anticipez les variations des dépenses récentes** : Google continue d'ajuster les dépenses, les impressions et les clics pour les jours récents. Toutes les 4 heures, Adapty actualise ces chiffres pour les 3 derniers jours, y compris aujourd'hui.
- **Anticipez des fuseaux horaires différents pour les dépenses et les revenus quotidiens** : Adapty Attribution affiche les dépenses Google Ads par jour dans le fuseau horaire de votre compte Google Ads. Les installations et les revenus sont affichés par jour en UTC. Si les deux fuseaux horaires diffèrent, les dépenses quotidiennes et les revenus quotidiens couvrent des heures différentes. Pour afficher les installations et les revenus dans un autre fuseau horaire, contactez le [support Adapty](mailto:support@adapty.io).
- **Utilisez Adapty Attribution pour les revenus et le ROAS** : Les valeurs de conversion dans Google Ads ne correspondent pas à vos revenus réels :
  - Les remboursements ne réduisent pas les valeurs de conversion : les campagnes App reçoivent des événements de remboursement sans valeur, et Adapty n'envoie pas d'événements de remboursement aux autres campagnes.
  - Dans les autres campagnes, Google ne comptabilise que les événements survenus dans les 30 jours suivant le clic sur l'annonce : Adapty crée ses actions de conversion avec cette fenêtre de conversion après clic. Pour comptabiliser les événements jusqu'à 90 jours après le clic, augmentez la fenêtre dans les paramètres de chaque action de conversion dans Google Ads.
  - Dans les campagnes App, Adapty n'envoie à Google que les événements survenus au cours des 90 derniers jours. Adapty envoie la plupart des événements peu après qu'ils se produisent, donc la limite n'affecte pas les renouvellements longtemps après l'installation.
