Transférez votre application à un autre propriétaire lors d'une acquisition, d'une vente ou d'une réorganisation de votre structure juridique. Après le transfert, le nouveau propriétaire [vérifie que les achats débloquent l'accès](#verify-transfer-completed-successfully).

## Transférer la propriété d'une application \{#transfer-app-ownership\}

:::note
Ne supprimez pas et ne recréez pas de produits pendant le processus de transfert. Ne modifiez pas les identifiants de produit avant d'avoir vérifié que le transfert s'est bien déroulé.
:::

Suivez les étapes correspondant à chaque compte qui change :

- Le compte développeur Apple : [Transfert App Store (iOS)](#app-store-ios-transfer)
- Le compte développeur Google Play : [Transfert Google Play (Android)](#google-play-android-transfer)
- Uniquement le compte Adapty : [Transfert Adapty uniquement](#adapty-only-transfer)

### Transfert App Store (iOS) \{#app-store-ios-transfer\}

Si l'application est transférée vers un autre compte développeur Apple, le nouveau propriétaire remplace trois identifiants dans Adapty par les siens :

- La clé d'achat intégré
- La clé API App Store Connect (une clé d'équipe)
- Le secret partagé propre à l'application

L'application conserve son Bundle ID et son URL de notification dans Adapty.

Le transfert se déroule en deux phases : [avant qu'Apple le finalise](#before-apple-completes-the-transfer) et [après qu'Apple le finalise](#after-apple-completes-the-transfer).

#### Avant qu'Apple finalise le transfert \{#before-apple-completes-the-transfer\}

1. **Nouveau propriétaire :** Si vous n'avez pas de compte Adapty, créez-en un sur [app.adapty.io](https://app.adapty.io).
2. **Ancien propriétaire :** Lancez le transfert de l'application dans App Store Connect en suivant le [guide de transfert](https://developer.apple.com/help/app-store-connect/transfer-an-app/overview-of-app-transfer) d'Apple.
3. **Ancien propriétaire :** Envoyez un e-mail à [support@adapty.io](mailto:support@adapty.io) pour transférer l'application dans Adapty. Indiquez le nom de l'application et l'adresse e-mail du compte Adapty de l'étape 1. Le nouveau propriétaire pourra ensuite saisir ses propres identifiants pour l'application dans Adapty.
4. **Nouveau propriétaire :** Vous aurez besoin d'une clé d'achat intégré et d'une clé d'équipe avec accès **Admin** depuis votre équipe App Store Connect. Si vous disposez du fichier d'une clé active existante, utilisez-la. Sinon, générez la [clé d'achat intégré](generate-in-app-purchase-key#generate-the-key-in-app-store-connect) ou la [clé d'équipe](app-store-connect-api-key#generate-a-team-key-in-app-store-connect) dans App Store Connect.
5. **Nouveau propriétaire :** Acceptez le transfert dans App Store Connect. Apple le finalise sous deux jours ouvrables, puis notifie les deux titulaires de compte.

#### Après que Apple finalise le transfert \{#after-apple-completes-the-transfer\}

:::warning
Enregistrez la nouvelle clé d'achat intégré dans Adapty dès qu'Apple finalise le transfert. La clé de l'ancien propriétaire cesse de fonctionner pour l'application après le transfert. Tant qu'Adapty ne dispose pas d'une clé valide, les nouveaux achats ne débloquent aucun niveau d'accès et l'application ne reçoit aucune erreur. Les utilisateurs qui achètent pendant cette période obtiennent l'accès lorsqu'ils [restaurent leurs achats](troubleshoot-app-store-integration#a-purchase-succeeds-but-the-customer-loses-access).
:::

1. **Nouveau propriétaire :** Accédez à [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk) dans Adapty. Saisissez la nouvelle clé d'achat intégré dans les sections **In-app purchase API (StoreKit 2)** et **App Store promotional offers**, puis cliquez sur **Save**.
2. **Nouveau propriétaire :** Connectez la clé d'équipe pour qu'Adapty maintienne vos produits synchronisés avec App Store Connect. Si la section **App Store Connect API key** contient déjà une clé, cliquez sur **Edit**. Sinon, cliquez sur **Connect API Key**. Puis saisissez la clé d'équipe.
3. **Nouveau propriétaire :** Dans App Store Connect, ouvrez la page **App Information** de l'application. Vérifiez que l'[**Production Server URL** et la **Sandbox Server URL**](enable-app-store-server-notifications#enter-the-notification-url-in-app-store-connect) correspondent bien à l'**URL for App Store server notifications** dans Adapty.
4. **Nouveau propriétaire :** Une fois [les nouvelles clés opérationnelles](app-store-connection-configuration#check-each-credential), [régénérez le secret partagé spécifique à l'application](app-store-connection-configuration#enter-the-app-specific-shared-secret) afin que la copie de l'ancien propriétaire cesse de fonctionner. Collez immédiatement le nouveau secret dans Adapty, puis cliquez sur **Save**.

### Transfert Google Play (Android) \{#google-play-android-transfer\}

Si l'application est transférée vers un autre compte développeur Google Play, le nouveau propriétaire remplace tous les identifiants Google Play dans Adapty par les siens.

1. **Nouveau propriétaire :** Si vous n'avez pas de compte Adapty, créez-en un sur [app.adapty.io](https://app.adapty.io).
2. **Les deux propriétaires :** Assurez-vous que les deux comptes Google Play Developer sont entièrement enregistrés.
3. **Ancien propriétaire :** Soumettez une demande de transfert via la Google Play Console ou le support Google Play Developer. Google peut demander des documents supplémentaires tels que des numéros DUNS, des contrats ou des justificatifs de vente.
4. **Nouveau propriétaire :** Examinez et approuvez la demande de transfert.
5. **Google :** L'équipe du support Google traite le transfert, généralement en quelques jours ouvrables, mais le délai peut être plus long selon la vérification du compte, la complexité des abonnements et la configuration des paiements.
6. **Ancien propriétaire :** Une fois le transfert effectué par Google, envoyez un e-mail à [support@adapty.io](mailto:support@adapty.io) pour transférer l'application dans Adapty. Indiquez le nom de l'application et l'adresse e-mail du nouveau propriétaire.
7. **Nouveau propriétaire :** Après avoir reçu l'application dans Adapty, suivez le [guide d'intégration Google Play](initial-android) pour générer et configurer toutes les informations d'identification sous votre compte.

Le transfert inclut les utilisateurs, les abonnements, les statistiques, les avis et la fiche du store. La continuité de facturation est maintenue pour les abonnés existants, mais les paiements sont basculés vers le compte marchand du nouveau propriétaire uniquement après la finalisation du transfert. Les rapports de paiement et les commandes antérieurs au transfert restent dans le compte d'origine. Suivez le [guide de transfert](https://support.google.com/googleplay/android-developer/answer/6230247) de Google pour connaître les conditions détaillées.

### Transfert dans Adapty uniquement \{#adapty-only-transfer\}

Si l'application ne fait que changer de compte Adapty, elle conserve tous ses identifiants et URLs de notification. Les stores et le code de l'application n'ont pas besoin d'être modifiés.

1. **Nouveau propriétaire :** Si vous n'avez pas de compte Adapty, créez-en un sur [app.adapty.io](https://app.adapty.io).
2. **Ancien propriétaire :** Envoyez un e-mail à [support@adapty.io](mailto:support@adapty.io) pour transférer l'application dans Adapty. Indiquez le nom de l'application et l'adresse e-mail du nouveau propriétaire.

## Vérifier que le transfert s'est bien déroulé \{#verify-transfer-completed-successfully\}

Après le transfert, le nouveau propriétaire vérifie l'application :

1. **Vérifier l'accès au tableau de bord** : Le nouveau propriétaire doit voir l'application dans son Adapty Dashboard.
2. **Tester la connexion SDK** : Lancez votre application et vérifiez que le SDK Adapty s'initialise sans erreurs.
3. **Tester un achat** : Effectuez un [achat de test](validate-test-purchases) et vérifiez qu'il déverrouille l'accès.
4. **Vérifier les identifiants** : Pour l'App Store, [vérifiez que chaque identifiant fonctionne](app-store-connection-configuration#check-each-credential). Pour Google Play, vérifiez que le nouveau compte de service se connecte correctement dans Adapty.
5. **Vérifier les renouvellements** : Dans les jours suivant le transfert, les renouvellements des abonnés existants doivent apparaître dans le [**Event feed**](event-feed).
