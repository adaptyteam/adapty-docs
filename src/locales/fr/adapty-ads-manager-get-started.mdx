[Adapty Ads Manager](adapty-ads-manager) est votre plateforme d'optimisation et d'analyse pour Apple Ads.

Dans ce guide, vous apprendrez à démarrer avec Adapty Ads Manager en deux étapes :

1. Installez le SDK Adapty et laissez-le suivre vos données d'achat.
2. Connectez Adapty Ads Manager à votre compte Apple Ads pour importer vos données historiques et commencer à suivre les mises à jour en temps réel.

:::note
Adapty Ads Manager n'utilise pas l'[intégration Apple Ads](apple-search-ads) disponible dans **App settings**.

Pour utiliser Adapty Ads Manager, il vous suffit de compléter la configuration décrite dans ce guide.
:::

## 1. Installer le SDK Adapty \{#1-install-the-adapty-sdk\}

:::important
Adapty Ads Manager est un **produit autonome**. Vous pouvez l'utiliser même si vos paywalls, abonnements ou analyses ne sont pas gérés par Adapty — migrer l'intégralité de votre stack vers Adapty n'est pas nécessaire.

Pour obtenir des données de revenus précises, la configuration minimale consiste à installer le SDK Adapty en mode observateur et à activer les notifications serveur App Store dans Adapty.
:::

Pour connecter vos données de revenus aux performances de vos campagnes, laissez Adapty suivre vos achats :

1. La première étape dépend de si vous avez déjà des achats intégrés implémentés :
   - Si vous **avez déjà des achats intégrés implémentés avec Adapty**, vous n'avez rien d'autre à faire à ce stade.
   - Si vous **avez déjà des achats intégrés implémentés sans Adapty** et ne prévoyez pas de migrer vers Adapty, installez le SDK Adapty pour votre plateforme en mode observateur. À ce stade, vous devez uniquement ajouter le SDK à votre projet, l'activer avec le mode observateur activé, et signaler les transactions :
     - [iOS](implement-observer-mode)
     - [Android](implement-observer-mode-android)
     - [React Native](implement-observer-mode-react-native)
     - [Flutter](implement-observer-mode-flutter)
     - [Unity](implement-observer-mode-unity)
     - [Kotlin Multiplatform](implement-observer-mode-kmp)
     - [Capacitor](implement-observer-mode-capacitor)
   - Si vous **n'avez pas encore d'achats intégrés implémentés et souhaitez utiliser Adapty**, suivez les étapes du [guide de démarrage rapide](quickstart) pour déléguer la gestion des achats à Adapty.
2. Pour recevoir les mises à jour liées aux revenus directement depuis l'App Store, [activez les notifications serveur de l'App Store dans Adapty](enable-app-store-server-notifications).

## 2. Connecter Apple Ads \{#2-connect-apple-ads\}

:::important
Vous devez avoir le rôle **Account Admin** dans Apple Ads pour connecter Apple Ads à Adapty.
:::

Vous devez maintenant connecter votre compte Adapty Ads Manager à votre compte Apple Ads :

1. Cliquez sur le logo Adapty dans l'en-tête et choisissez **Search Ads**.

<ZoomImage id="product-switcher.webp" width="500px" alt="Adapty product switcher" />

2. Cliquez sur **Continue with Apple**.

<ZoomImage id="continue-with-apple.webp" width="700px" />

3. Connectez-vous à votre compte Apple.
4. Sélectionnez le niveau d'accès que vous souhaitez accorder à Adapty Ads Manager :
- **Read and Write** : fournit l'accès à tous les groupes de campagnes.
- **Limited access** : choisissez des groupes de campagnes spécifiques et attribuez le rôle **Read & Write** pour accorder l'accès uniquement à ces groupes.

<ZoomImage id="apple-ads-access.webp" width="700px" />

5. Cliquez sur **Grant access**.

<ZoomImage id="grant-access.webp" width="300px" />

Après cela, Adapty commencera à synchroniser vos données historiques depuis Apple Ads. Vous pouvez déjà commencer à explorer Adapty Ads Manager, mais l'importation de toutes les données historiques prendra un certain temps.
