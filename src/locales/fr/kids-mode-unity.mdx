Si votre application Unity est destinée aux enfants, vous devez respecter les politiques d'[Apple](https://developer.apple.com/kids/) et de [Google](https://support.google.com/googleplay/android-developer/answer/9893335). Si vous utilisez le SDK Adapty, quelques étapes simples vous permettront de le configurer pour satisfaire ces politiques et passer les examens des stores.

## Qu'est-ce qui est requis ? \{#whats-required\}

Vous devez configurer le SDK Adapty pour désactiver la collecte de :

- [IDFA (Identifier for Advertisers)](https://en.wikipedia.org/wiki/Identifier_for_Advertisers) (iOS)
- [Android Advertising ID (AAID/GAID)](https://support.google.com/googleplay/android-developer/answer/6048248) (Android)
- [Adresse IP](https://www.ftc.gov/system/files/ftc_gov/pdf/p235402_coppa_application.pdf)

De plus, nous recommandons d'utiliser l'identifiant utilisateur client avec précaution. Un identifiant au format `<Prénom.NomDeFamille>` sera incontestablement considéré comme une collecte de données personnelles, tout comme l'utilisation d'un e-mail. Pour le Mode Enfants, la bonne pratique consiste à utiliser des identifiants aléatoires ou anonymisés (par exemple, des identifiants hachés ou des UUID générés par l'appareil) pour assurer la conformité.

## Activation du Mode Enfants \{#enabling-kids-mode\}

### Modifications dans l'Adapty Dashboard \{#updates-in-the-adapty-dashboard\}

Dans l'Adapty Dashboard, vous devez désactiver la collecte des adresses IP. Pour ce faire, accédez aux [App settings](https://app.adapty.io/settings/general) et cliquez sur **Disable IP address collection** sous **Collect users' IP address**.

### Modifications dans le code de votre application mobile \{#updates-in-your-mobile-app-code\}
