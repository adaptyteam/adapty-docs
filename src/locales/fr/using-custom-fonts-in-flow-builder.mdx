Lorsque vous créez des flows, vous pouvez utiliser une police personnalisée pour correspondre au reste de votre application. Voici comment ajouter des polices personnalisées et les utiliser dans vos flows.

Tous les flows d'une même application partagent les polices que vous importez, y compris les flows que vous [copiez](copy-flows). Les autres applications de votre compte Adapty ont chacune besoin de leur propre import.

:::tip
[Configurez les polices](onboarding-text) dans le panneau **Styles** avant de commencer à concevoir le flow. Ainsi, toutes les modifications que vous apportez s'appliqueront globalement.
:::

## Polices intégrées \{#built-in-fonts\}

Lorsque vous créez un flow dans le Builder, Adapty utilise par défaut la police système. Il s'agit généralement de SF Pro sur iOS et de Roboto sur Android, bien que cela puisse varier selon l'appareil. Vous pouvez également choisir parmi des polices courantes comme Arial, Times New Roman, Courier New, Georgia et Helvetica. Chacune de ces polices propose quelques options de style.

Ces polices ne sont pas fournies dans le SDK et ne servent qu'à des fins de prévisualisation. Nous ne pouvons pas garantir qu'elles fonctionneront parfaitement sur tous les appareils. Cependant, d'après nos tests, ces polices sont généralement reconnues par la plupart des appareils sans aucune intervention de votre part. Vous pouvez également [consulter les polices disponibles par défaut sur iOS](https://developer.apple.com/fonts/system-fonts/).

## Ajouter une police personnalisée \{#add-a-custom-font\}

:::warning
Le fichier que vous téléchargez est **uniquement destiné à la prévisualisation dans l'éditeur** — Adapty ne le distribue pas sur les appareils des utilisateurs. Pour afficher la police sur l'appareil, [incluez le fichier dans le bundle de votre application](#add-the-font-files-to-your-apps-bundle). Sans cela, le SDK utilisera SF Pro (iOS) ou Roboto (Android) au moment de l'exécution.
:::

Si vous souhaitez utiliser des polices autres que celle du système, vous pouvez ajouter une police personnalisée.

Pour ajouter une police personnalisée :

0. Si la police est variable, divisez-la en fichiers à style unique avec des noms uniques. Les contrôles de graisse, gras et italique ne s'appliquent pas aux polices personnalisées. Adapty n'enregistre qu'un seul style par fichier de police personnalisé. Pour [mettre le texte en forme](onboarding-text), passez à la variation de police appropriée.

1. Choisissez **Upload new font** dans n'importe quel menu déroulant de police.

<ZoomImage id="upload-new-font.webp" width="300px" alt="Add custom font" />

2. Dans la fenêtre **Add custom font**, remplissez les champs suivants :

:::warning
Le **nom de la police dans le Builder**, le **nom de la police iOS** et le **nom de la police Android** doivent chacun être uniques parmi tous les fichiers de polices personnalisées de l'application.
:::

- **Font name in Builder** : Saisissez un nom d'affichage pour la police. Ce nom apparaîtra dans les menus déroulants de polices dans le Builder.
   - **iOS font name** : Saisissez le nom PostScript de la police. Vous pouvez le trouver dans Font Book → PostScript name, ou via l'[API `UIFont`](https://developer.apple.com/documentation/uikit/uifont).
   - **Android font name** : Saisissez le nom de fichier depuis `res/font/`. Utilisez uniquement des lettres minuscules, des chiffres et des underscores.
   - **Font file** : Glissez-déposez le fichier de police ou cliquez sur **Select files**. Formats pris en charge : `.ttf`, `.otf`, `.woff`, `.woff2`.

3. Cliquez sur **Save font**.

<ZoomImage id="add-custom-font-window.webp" width="300px" alt="Fenêtre d'ajout de police personnalisée" />

En téléchargeant le fichier de police sur Adapty, vous confirmez que vous disposez des droits nécessaires pour l'utiliser dans votre application.

### Supprimer une police personnalisée \{#delete-a-custom-font\}

Supprimer une police personnalisée depuis le tableau de bord remplace silencieusement toutes les références à cette police par la police système, dans tous les flows en brouillon et publiés. Aucun avertissement n'est affiché et cette action est irréversible. Avant de supprimer, vérifiez qu'aucun flow en production n'utilise cette police.

## Polices personnalisées dans les templates de flow \{#custom-fonts-in-flow-templates\}

La [bibliothèque de templates de flow](paywall-builder-templates) inclut des templates avec des polices personnalisées. Survolez la puce **Custom font** sur la carte d'un template pour voir les polices qu'il utilise.

Adapty ne fournit pas ces polices. Vous devez les obtenir vous-même, en faisant correspondre les noms de polices affichés dans la puce. Certaines polices peuvent nécessiter une licence commerciale.

Une fois que vous avez les fichiers de polices, suivez les étapes de configuration ci-dessous.

## Ajoutez les fichiers de police au bundle de votre application \{#add-the-font-files-to-your-apps-bundle\}

Si vous utilisez déjà une police personnalisée ailleurs dans votre application, il vous suffit d'ajouter vos polices de paywall de la même manière. Sinon, assurez-vous d'inclure le fichier de police dans le projet et le bundle de votre application. Consultez la procédure ci-dessous :

- Sur iOS : [Dans la documentation officielle d'Apple](https://developer.apple.com/documentation/uikit/adding-a-custom-font-to-your-app)
- Sur Android : [Dans la documentation officielle d'Android](https://developer.android.com/develop/ui/views/text-and-emoji/fonts-in-xml)
