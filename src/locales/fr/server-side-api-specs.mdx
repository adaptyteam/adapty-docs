L'API côté serveur d'Adapty vous permet d'accéder et de gérer vos données d'abonnement par programmation, facilitant l'intégration avec vos services et infrastructures existants. Que vous synchronisiez des données entre plateformes, accordiez des niveaux d'accès ou validiez des achats dans Stripe, cette API fournit les outils nécessaires pour maintenir vos systèmes à jour et vos utilisateurs engagés.

## Collection et environnement Postman \{#postman-collection-and-environment\}

Pour simplifier l'utilisation de notre API côté serveur, nous avons préparé une collection Postman et un fichier d'environnement que vous pouvez télécharger et importer dans Postman.

- **Request Collection** : Inclut toutes les requêtes disponibles dans l'API Adapty côté serveur. Notez qu'elle utilise des variables que vous pouvez définir dans l'environnement.
- **Environment** : Contient une liste de variables où vous pouvez définir des valeurs une seule fois. Nous avons préparé un environnement unifié pour l'API côté serveur, l'API web et l'API d'export des analyses, pour vous faciliter la tâche. Une fois cet environnement activé, Postman substitue automatiquement les valeurs des variables définies dans vos requêtes.

:::tip

[Télécharger la collection et l'environnement](https://raw.githubusercontent.com/adaptyteam/adapty-docs/refs/heads/main/Downloads/Adapty_server_side_API_postman_collection.zip)

:::

Pour savoir comment importer une collection et un environnement dans Postman, consultez la [documentation Postman](https://learning.postman.com/docs/getting-started/importing-and-exporting/importing-data/).

### Variables utilisées \{#variables-used\}

Nous avons créé un environnement unifié pour l'API côté serveur, l'API web et l'API d'export des données analytics, afin de simplifier votre workflow. Voici les variables propres à l'API côté serveur :

| Variable                | Description                                                  | Exemple de valeur                                           |
| ----------------------- | ------------------------------------------------------------ | ------------------------------------------------------- |
| secret_api_key          | Disponible dans le champ **Secret key** de vos [**App settings**](https://app.adapty.io/settings/general). | `secret_live_Pj1P1xzM.2CvSvE1IalQRFjsWy6csBVNpH33atnod` |
| adapty-customer-user-id | L'identifiant utilisateur de votre système. Dans l'Adapty Dashboard, il se trouve dans le champ **Customer user ID** du profil. | `john.doe@example.com`                                  |
| adapty-profile-id       | L'identifiant utilisateur attribué par Adapty. Dans l'Adapty Dashboard, il se trouve dans le champ **Adapty ID** du profil. | `3286abd3-48b0-4e9c-a5f6-ac0a006333a6`                  |
| Adapty-platform         | La plateforme utilisée par l'utilisateur pour votre application. Valeurs possibles : `iOS`, `macOS`, `iPadOS`, `visionOS`, `Android`, `web`. | `iOS`                                                   |
| stripe_token            | Token d'un objet Stripe représentant un achat unique, tel qu'un abonnement (`sub_XXX`) ou un Payment Intent (`pi_XXX`). | `sub_1JY8xLLy6P12345a`                                  |
