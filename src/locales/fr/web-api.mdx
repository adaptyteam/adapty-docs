La Web API est une extension de l'API côté serveur conçue pour être utilisée avec des applications web. Elle vous permet de récupérer le bon paywall à partir de l'ID de placement associé et d'enregistrer les vues de paywall pour un suivi précis des conversions. Cela vous permet d'exploiter les tests A/B et la personnalisation des paywalls disponibles dans Adapty, ainsi que de suivre les paywalls les plus performants.

## Cas d'usage : Enregistrer une transaction depuis votre application web et la lier au paywall utilisé \{#use-case-record-a-transaction-from-your-web-app-and-link-it-to-the-used-paywall\}

Disons que vous vendez des produits dans votre application web. Vous devez afficher un paywall à vos utilisateurs, les laisser acheter un produit, puis ajouter les détails de la transaction à Adapty. Il est essentiel de lier ces transactions aux paywalls spécifiques par lesquels l'utilisateur a effectué l'achat, afin que vos analyses reflètent des données précises. Tout cela peut être facilement accompli grâce à l'API Adapty.

### Prérequis

1. [Créez les produits](create-product) que vous utiliserez dans le paywall depuis l'Adapty Dashboard.
2. [Créez le paywall](create-paywall) dans l'Adapty Dashboard. [Utilisez Remote Config](customize-paywall-with-remote-config) pour concevoir votre paywall web.
3. [Configurez un placement](create-placement) et associez-y le paywall dans l'Adapty Dashboard.

### Étapes avec l'API Adapty \{#steps-with-adapty-api\}

1. **Créer un profil utilisateur :** Adapty a besoin d'un profil avant de demander un paywall afin de personnaliser le résultat pour l'utilisateur concerné. Utilisez la requête [Create profile](api-adapty/operations/createProfile) pour créer un profil utilisateur.
2. **Récupérer et afficher le paywall :** Lorsque l'utilisateur atteint le placement dans votre application web où le paywall doit être affiché, utilisez la requête [Get paywall](api-web/operations/getPaywall) pour récupérer le paywall via l'[identifiant de placement](placements). Vous obtiendrez ainsi un paywall correspondant à l'[audience](audience) de votre utilisateur. Affichez le paywall avec votre code, en utilisant les produits retournés et (optionnellement) le [Remote Config](customize-paywall-with-remote-config) de ce paywall.
3. **Enregistrer la vue du paywall :** Utilisez [Record paywall view](api-web/operations/recordPaywallView) pour journaliser la vue du paywall dans Adapty et garantir que vos analytics reflètent précisément l'événement. Cela est indispensable pour suivre correctement les conversions.
4. **Enregistrer l'achat :** Si l'utilisateur finalise un achat, envoyez les détails de la transaction à Adapty via l'API Adapty. Incluez le **variation ID** dans cette requête pour associer la transaction au paywall affiché. Pour plus d'informations, consultez notre page sur l'[association des paywalls aux transactions dans les applications mobiles](report-transactions-observer-mode) — la même approche s'applique aux applications web.
5. **Ajouter des données d'attribution marketing (si applicable) :** Si vous disposez de données d'attribution marketing (par exemple, des détails sur une campagne ou une publicité), utilisez [Add attribution](api-web/operations/addAttribution) pour les intégrer au profil utilisateur, afin d'enrichir les analytics et d'en apprendre davantage sur les performances de vos publicités dans Adapty.
