Adapty Ads Manager fournit des métriques complètes pour mesurer les performances des campagnes et le comportement des utilisateurs.

:::tip
Les noms de métriques présentés sur cette page sont également acceptés par le CLI Adapty, qui les retourne au format JSON pour n'importe quel niveau du compte — consultez [Commandes Ads Manager](developer-cli-ads-manager-reference#metrics).
:::

## Performance \{#performance\}

| Métrique | Description |
|--------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Spend | La somme du coût de chaque clic d'un client sur votre publicité. |
| Impressions | Le nombre de fois où votre publicité sponsorisée est apparue dans les résultats de recherche de l'App Store au cours de la période de rapport. |
| CPM | Le montant moyen que vous payez pour mille impressions publicitaires. CPM moy. = Spend / (Impressions / 1000) Remarque : pour les campagnes App Store Search Results avec le modèle de tarification CPT, affiche le CPM effectif. |
| Taps | Le nombre de fois où la publicité a été tappée par des utilisateurs au cours de la période de rapport. |
| CPT | Le montant moyen que vous payez par clic sur votre publicité. CPT moy. = Spend / Taps |
| TTR | Le nombre de fois où votre publicité a été tappée par des clients, divisé par le nombre total d'impressions reçues. TTR = Taps / Impressions × 100 % |
| Downloads (Total) | Le nombre total de nouveaux téléchargements et de re-téléchargements via clic ou vue depuis une publicité au cours de la période de rapport. |
| Downloads (View-Through) | Le nombre de téléchargements et de re-téléchargements d'utilisateurs ayant vu votre publicité dans une fenêtre de 24 heures sans avoir cliqué dessus. |
| Downloads (Tap-Through) | Le nombre total de nouveaux téléchargements et de re-téléchargements d'utilisateurs ayant cliqué sur votre publicité dans une fenêtre de 30 jours. |
| Avg CPA (Total) | Le coût moyen par acquisition (CPA) total correspond aux dépenses totales de la campagne divisées par le nombre total de téléchargements résultant d'une vue ou d'un clic sur votre publicité au cours de la période de rapport. |
| Avg CPA (Tap-Through) | Le coût moyen par acquisition (CPA) via clic correspond aux dépenses totales de la campagne divisées par le nombre de téléchargements via clic au cours de la période de rapport. |
| Download Rate (Total) | Le total des téléchargements résultant d'une vue ou d'un clic sur votre publicité divisé par le nombre total de clics au cours de la période de rapport. Formule : (Total Downloads / Taps) × 100 % si Taps > 0, sinon 0 % |
| Download Rate (Tap-Through) | Le total des téléchargements résultant de clics sur votre publicité divisé par le nombre total de clics au cours de la période de rapport. Formule : (Tap-Through Downloads / Taps) × 100 % si Taps > 0, sinon 0 % |
| DPM (Total) | Downloads per Mille (DPM) est le nombre de téléchargements pour mille impressions. Formule : (Total Downloads / Impressions) × 1000 si Impressions > 0, sinon 0 |

## Conversions \{#conversions\}

:::note
Les métriques Revenus, ARPU, ARPPU, ARPAS, ROAS et ROI sont également disponibles en tant que métriques de cohorte pour l'analyse temporelle des groupes d'utilisateurs.
:::

| Métrique | Description |
|--------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Conversions | Conversions est le nombre total d'événements de conversion sur la période de reporting. Formule : Essais démarrés + Abonnements démarrés + Achats uniques |
| Conversion CR | Conversion CR (Taux de conversion) est le pourcentage de téléchargements totaux ayant abouti à une conversion. Formule : (Conversions / Total des téléchargements) × 100% si Total des téléchargements > 0, sinon 0% |
| Coût par conversion | Le coût par conversion est votre dépense totale divisée par le nombre de conversions. Formule : Dépenses / Conversions si Conversions > 0, sinon 0 |
| Revenus | Revenus est le montant total d'argent généré par les achats, renouvellements ou autres conversions monétisées dans votre application sur une période sélectionnée (avant commission du store). |
| ROAS | ROAS (Retour sur les dépenses publicitaires) est le revenu généré par vos annonces divisé par les dépenses publicitaires, exprimé en pourcentage. Formule : (Revenus / Dépenses) × 100% si Dépenses > 0, sinon 0% |
| ROI | ROI (Retour sur investissement) mesure le bénéfice net par rapport aux dépenses. Formule : ((Revenus − Dépenses) / Dépenses) × 100% si Dépenses > 0, sinon 0% |
| ARPU | ARPU (Revenu moyen par utilisateur) est le revenu moyen par utilisateur. Il est calculé comme le revenu total divisé par le nombre d'utilisateurs uniques. 60 000 $ de revenus / 5 000 utilisateurs = 12 $ d'ARPU. Il est utile de comparer cette valeur au coût par installation (CPI) pour évaluer l'efficacité de vos campagnes marketing. |
| ARPPU | ARPPU (Revenu moyen par utilisateur payant) est le revenu moyen par utilisateur payant. Il est calculé comme le revenu total divisé par le nombre d'utilisateurs payants uniques. 60 000 $ de revenus / 1 000 utilisateurs payants = 60 $ d'ARPPU. Il vous aide à comprendre combien d'argent génère en moyenne un client payant. |
| ARPAS | ARPAS est le revenu moyen par abonné actif. Il est calculé comme le revenu total / le nombre d'abonnés actifs. Par abonnés, nous entendons ceux qui ont activé une période d'essai ou un abonnement. 60 000 $ de revenus / 1 500 abonnés = 40 $ d'ARPAS. |
| Installations | Installations est le nombre total d'utilisateurs ayant installé l'application pour la première fois, ainsi que toutes les réinstallations par des utilisateurs existants. Cela inclut les installations multiples d'un même utilisateur sur différents appareils. Veuillez noter que les téléchargements incomplets ou les installations annulées avant leur achèvement ne sont pas comptabilisés dans le nombre d'installations. |
| Installs CR | Installs CR (Taux de conversion) est le pourcentage d'utilisateurs parmi les téléchargements totaux ayant installé l'application. Formule : (Installations / Total des téléchargements) × 100% si Total des téléchargements > 0, sinon 0% |
| CPI | CPI (Coût par installation) est le coût par installation capturé par Adapty. Formule : Dépenses / Installations si Installations > 0, sinon 0 |
| Essais | Essais est le nombre de nouveaux abonnements d'essai initiés pendant la période de reporting. |
| Trial CR | Trial CR (Taux de conversion) est le pourcentage de téléchargements totaux ayant démarré un essai. Formule : (Essais / Total des téléchargements) × 100% si Total des téléchargements > 0, sinon 0% |
| Coût par essai | Le coût par essai est votre dépense totale divisée par le nombre de nouveaux démarrages d'essai. Formule : Dépenses / Essais si Essais > 0, sinon 0 |
| Essais convertis | Essais convertis est le nombre d'abonnements d'essai ayant été convertis avec succès en abonnements payants pendant la période de reporting. |
| Trial converted CR | Trial converted CR (Taux de conversion) est le pourcentage d'abonnements d'essai convertis en abonnements payants. Formule : (Essais convertis / Essais) × 100% si Essais > 0, sinon 0% |
| Coût par essai converti | Le coût par essai converti est votre dépense totale divisée par le nombre d'essais convertis sur la même période. Formule : Dépenses / Essais convertis si Essais convertis > 0, sinon 0 |
| Abonnements | Abonnements est le nombre total de nouvelles souscriptions (hors essai) pendant la période de reporting. |
| Subscription CR | Subscription CR (Taux de conversion) est le pourcentage de téléchargements totaux ayant souscrit un abonnement payant (sans période d'essai gratuite). Formule : (Abonnements / Total des téléchargements) × 100% si Total des téléchargements > 0, sinon 0% |
| Coût par abonnement | Le coût par abonnement est votre dépense totale divisée par le nombre de nouveaux abonnements démarrés. Formule : Dépenses / Abonnements si Abonnements > 0, sinon 0 |
| Achats uniques démarrés | Achats uniques démarrés est le nombre total d'achats intégrés uniques qui ne sont pas basés sur un abonnement. |
| Non-subscription CR | Non-subscription CR (Taux de conversion) est le pourcentage de téléchargements totaux ayant effectué un achat unique dans votre application. Formule : (Achats uniques démarrés / Total des téléchargements) × 100% si Total des téléchargements > 0, sinon 0% |
| Coût par achat unique | Le coût par achat unique est votre dépense totale divisée par le nombre d'achats uniques. Formule : Dépenses / Achats uniques démarrés si Achats uniques démarrés > 0, sinon 0 |

## Téléchargements avancés \{#advanced-downloads\}

| Métrique | Description |
|--------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Nouveaux téléchargements (Total) | Le nombre total de nouveaux téléchargements par clic et par vue au cours de la période de reporting. |
| Nouveaux téléchargements (Par vue) | Nouveaux téléchargements de la part d'utilisateurs qui ont vu votre publicité sans cliquer dessus et qui n'avaient pas téléchargé votre application auparavant, comptabilisés dans une fenêtre de 24 heures. |
| Nouveaux téléchargements (Par clic) | Nouveaux téléchargements de la part d'utilisateurs qui ont cliqué sur votre publicité et qui n'avaient pas téléchargé votre application auparavant. Comptabilisés dans une fenêtre d'attribution de 30 jours. |
| Part des nouveaux téléchargements (Par clic) | Indique le pourcentage de téléchargements totaux par clic qui sont des nouveaux téléchargements (de la part d'utilisateurs ayant cliqué sur votre publicité dans une fenêtre d'attribution de 30 jours). |
| Retéléchargements (Total) | Le nombre total de retéléchargements par clic et par vue au cours de la période de reporting. |
| Retéléchargements (Par vue) | Retéléchargements de la part d'utilisateurs qui ont vu votre publicité sans cliquer dessus dans une fenêtre de 24 heures. Comptabilisés lorsqu'un utilisateur télécharge votre application, la supprime, puis la retélécharge sur le même appareil ou un autre après avoir vu une publicité. |
| Retéléchargements (Par clic) | Retéléchargements de la part d'utilisateurs qui ont cliqué sur votre publicité dans une fenêtre d'attribution de 30 jours. Comptabilisés lorsqu'un utilisateur télécharge votre application, la supprime, puis la retélécharge sur le même appareil ou un autre après avoir cliqué sur une publicité. |
| Part des retéléchargements (Par clic) | Indique le pourcentage de téléchargements totaux par clic qui sont des retéléchargements. |

## Aperçus \{#insights\}

| Métrique | Description                                                                                                                              |
|--------|------------------------------------------------------------------------------------------------------------------------------------------|
| Impression Share | L'Impression Share est le pourcentage d'impressions reçues par votre annonce par rapport au total des impressions pour le même terme de recherche.           |
| Rank | Le Rank (actuel) est la position actuelle de votre application en termes d'Impression Share pour le terme de recherche sélectionné dans un pays ou une région spécifique. |
| Search Popularity | La Search Popularity (actuelle) est la popularité des termes de recherche selon le pays ou la région. Le classement va de 1 à 5, 5 correspondant au volume de recherche le plus élevé.              |
