Vous pouvez contrôler l'affichage d'un élément en lui ajoutant une condition. Un élément conditionnel n'est visible que pour les utilisateurs qui remplissent les critères spécifiés.

:::important
Si vous affichez ou masquez un élément à l'aide de l'action **Show element** ou **Hide element** [action](onboarding-actions), cette action remplace la condition de **Visibility** définie sur cet élément. Ce remplacement reste actif jusqu'à ce qu'une variable ou un état d'élément dans la condition soit mis à jour.

Sur un élément ayant une condition de **Visibility**, ces actions modifient l'élément immédiatement, [sans animation ni délai](flow-show-hide-animations#when-animation-and-delay-dont-apply).

Utilisez les conditions de **Visibility** pour les éléments qui doivent apparaître ou se masquer en fonction d'un critère, comme une réponse à un quiz. Utilisez les actions lorsque la visibilité doit changer à un moment précis, par exemple [lorsque l'écran s'ouvre ou que l'utilisateur appuie sur un élément](flow-show-hide-animations#show-or-hide-an-element).
:::

Pour ajouter une condition à un élément :

1. Sélectionnez l'élément dans le canevas ou le panneau des calques.
2. Dans la section **Visibility** du panneau de droite, sélectionnez **Conditional**.

<ZoomImage id="flow-conditional-visibility.webp" width="500px" alt="Paramètres de visibilité conditionnelle" />

3. Configurez la condition en choisissant un type de propriété parmi les trois onglets :
   - **Custom** : Variables que vous créez et gérez ; leurs valeurs peuvent être mises à jour via les interactions utilisateur. Consultez [Variables](onboarding-variables) pour plus de détails.
   - **Products** : Propriétés des produits dans votre flow, comme le prix ou le nom.
   - **Elements** : États des autres éléments dans le flow, comme l'activation d'un bouton d'essai.
4. Saisissez la **Value** à faire correspondre.
5. Cliquez sur l'opérateur pour le modifier si nécessaire.
6. (Facultatif) Cliquez sur **Add condition** pour ajouter d'autres conditions. Utilisez le sélecteur pour exiger que toutes les conditions soient remplies, ou n'importe laquelle d'entre elles.
