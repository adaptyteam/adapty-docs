Vous pouvez contrôler l'affichage d'un élément en lui ajoutant une condition. Un élément conditionnel n'est visible que pour les utilisateurs qui remplissent les critères spécifiés.

Une condition peut également évaluer l'[état d'un autre élément](element-states-in-conditions). Par exemple, vous pouvez afficher un indice uniquement si un bouton est **Disabled**.

:::important
Si vous affichez ou masquez un élément à l'aide de l'action **Show element** ou **Hide element** [action](onboarding-actions), cette action remplace la condition de **Visibility** définie sur cet élément. Ce remplacement reste actif jusqu'à ce qu'une variable ou un état d'élément dans la condition soit mis à jour.

Sur un élément ayant une condition de **Visibility**, ces actions modifient l'élément immédiatement, [sans animation ni délai](flow-show-hide-animations#when-animation-and-delay-dont-apply).

Utilisez les conditions de **Visibility** pour les éléments qui doivent apparaître ou se masquer en fonction d'un critère, comme une réponse à un quiz. Utilisez les actions lorsque la visibilité doit changer à un moment précis, par exemple [lorsque l'écran s'ouvre ou que l'utilisateur appuie sur un élément](flow-show-hide-animations#show-or-hide-an-element).
:::

Pour ajouter une condition à un élément :

1. Sélectionnez l'élément dans le canevas ou le panneau des calques.
2. Dans la section **Visibility** du panneau de droite, sélectionnez **Conditional**.

<ZoomImage id="flow-conditional-visibility.webp" width="500px" alt="Paramètres de visibilité conditionnelle" />

3. Pour définir la condition, sélectionnez un type de propriété dans l'un des onglets suivants :
   - **Custom** : Variables que vous créez et gérez ; leurs valeurs peuvent être mises à jour via les interactions utilisateur. Consultez [Variables](onboarding-variables) pour plus de détails.
   - **Product** : Propriétés des produits dans votre flow, comme le prix ou le nom.
   - **Elements** : Variables d'autres éléments, comme la réponse à un quiz ou l'état d'un bouton bascule.
   - **States** : L'[état d'un autre élément](element-states-in-conditions) à l'écran, par exemple un bouton **Disabled**.
   - **System** : La plateforme de l'appareil de l'utilisateur, `system.platform`. Consultez [Afficher un élément sur une seule plateforme](#show-an-element-on-one-platform-only).
4. Saisissez la **Value** à faire correspondre.
5. Cliquez sur l'opérateur pour le modifier si nécessaire.
6. (Facultatif) Cliquez sur **Add condition** pour ajouter d'autres conditions. Utilisez le sélecteur pour exiger que toutes les conditions soient remplies, ou au moins l'une d'elles.

## Afficher un élément sur une seule plateforme \{#show-an-element-on-one-platform-only\}

Pour conserver un seul flow pour iOS et Android, affichez les éléments spécifiques à chaque plateforme uniquement sur celle-ci. Par exemple, affichez « Gérez votre abonnement dans les paramètres de l'App Store » sur iOS, et « Gérez votre abonnement dans Google Play » sur Android.

1. Sélectionnez l'élément, puis dans la section **Visibility**, choisissez **Conditional**.
2. Cliquez sur le champ **Variable**, ouvrez l'onglet **System** et sélectionnez `system.platform`.
3. Dans le menu déroulant des valeurs, sélectionnez **iOS** ou **Android**. Avec `=`, l'élément s'affiche uniquement sur cette plateforme. Avec `!=`, il s'affiche uniquement sur l'autre plateforme.

<ZoomImage id="flow-condition-system-platform.webp" width="500px" alt="Show element if editor with the System tab open and system.platform selected" />

Le SDK Adapty transmet automatiquement la plateforme, votre application n'a donc pas besoin de la fournir. Les appareils Android, y compris les appareils Huawei, correspondent à **Android**.

Le canvas affiche l'élément si la condition correspond à la plateforme de l'[appareil de prévisualisation](paywall-device-compatibility-preview#preview-in-the-adapty-dashboard). Pour prévisualiser l'autre plateforme, sélectionnez un appareil de cette plateforme dans les contrôles de prévisualisation.

Pour afficher un écran entier sur une seule plateforme, utilisez une [action conditionnelle](onboarding-actions#show-a-screen-on-one-platform-only).
