Définissez un arrière-plan sur n'importe quel écran via le panneau **Fill** dans [**Screen settings**](paywall-layout-and-products#screen-settings). Choisissez parmi quatre types d'arrière-plan : couleur unie, dégradé, image ou vidéo.

## Image \{#image\}

<ZoomImage id="flow-builder-bg-img.webp" width="300px" alt="Image d'arrière-plan dans le Flow Builder" float="right"/>

Importez un fichier `.JPG`, `.PNG`, `.GIF` ou `.WEBP` de 20 Mo maximum. L'image est mise à l'échelle pour couvrir tout l'arrière-plan.

:::note
Les images et vidéos en arrière-plan remplissent l'intégralité de la fenêtre d'affichage, y compris les zones derrière l'encoche et les barres système — même quand **Safe area** est activé. Gardez le contenu important loin des bords pour éviter tout rognage.
:::

Pour remplacer l'image d'arrière-plan à l'exécution depuis le code de votre application, activez un [identifiant de média personnalisé](custom-media#custom-media-id).

## Vidéo \{#video\}

<ZoomImage id="flow-builder-bg-vid.webp" width="300px" alt="Vidéo d'arrière-plan dans le Flow Builder" float="right"/>

Importez un fichier `.MP4` ou `.WEBM` de 50 Mo maximum. L'aperçu affiche une image fixe, mais la vidéo est lue sur l'appareil à l'exécution.

Activez **Loop** pour rejouer la vidéo en boucle.

Pour remplacer la vidéo d'arrière-plan à l'exécution, activez un [identifiant de média personnalisé](custom-media#custom-media-id).

## Couleur unie \{#solid-color\}

<ZoomImage id="flow-builder-bg-solid.webp" width="300px" alt="Arrière-plan uni dans le Flow Builder" float="right"/>

Saisissez une valeur hexadécimale et définissez l'opacité de 0 à 100 %. Choisissez un [style de couleur](builder-styling) enregistré depuis les nuanciers pour appliquer votre couleur de marque — l'arrière-plan suit automatiquement vos thèmes clair et sombre.

## Dégradé \{#gradient\}

<ZoomImage id="flow-builder-bg-gradient.webp" width="300px" alt="Arrière-plan dégradé dans le Flow Builder" float="right"/>

Créez un dégradé linéaire multi-paliers :

- **Direction** — faites pivoter le dégradé de 0 à 360°.
- **Stops** — faites glisser le long de la barre pour repositionner. Cliquez sur un palier pour modifier sa valeur hexadécimale et son opacité.
