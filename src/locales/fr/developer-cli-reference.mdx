L'Adapty CLI regroupe ses commandes par thème, comme `products` ou `placements`. Chaque thème dispose de sa propre page avec ses commandes, arguments, options et valeurs acceptées. Cette page liste les thèmes, les options acceptées par toutes les commandes, ainsi que la commande d'installation des skills Adapty.

| Sujet | Commandes | Ce qu'elles font |
|---|---|---|
| [Applications et niveaux d'accès](developer-cli-apps) | `apps`, `access-levels` | Créer et configurer des applications ainsi que les niveaux d'abonnement vérifiés par votre app |
| [Produits et offres](developer-cli-products) | `products`, `product-offers` | Configurer des produits, les associer aux identifiants produit App Store et Google Play, et leur lier des offres store |
| [Paywalls](developer-cli-paywalls) | `paywalls` | Créer des paywalls et leur assigner des produits |
| [Flows](developer-cli-flows) | `flows` | Créer des flows, rédiger et valider leurs configurations builder, les publier et consulter leurs métriques |
| [Placements et segments](developer-cli-placements) | `placements`, `segments` | Configurer les placements, leurs audiences et les segments ciblés par ces audiences. Consulter les métriques des placements de flows |
| [Analytics](developer-cli-analytics) | `analytics` | Consulter les graphiques, conversions, entonnoir, rétention, LTV et cohortes |
| [Tests A/B](developer-cli-ab-tests) | `ab-tests` | Créer, démarrer, arrêter, remplacer et archiver des tests A/B de paywalls et de flows |
| [Attribution](developer-cli-attribution) | `attribution` | Consulter les dépenses, installations, revenus et ROAS par canal et campagne |
| [Ads Manager](developer-cli-ads-manager-reference) | `asa` | Gérer les campagnes Apple Ads, les mots-clés et les règles d'automatisation |
| [Migrations](developer-cli-migrations) | `migrations` | Migrer un projet RevenueCat vers Adapty |
| [Authentification](developer-cli-authentication) | `auth` | Se connecter, vérifier et révoquer votre session CLI |

## Drapeaux globaux \{#global-flags\}

Ces drapeaux sont disponibles sur toutes les commandes.

| Drapeau | Description |
|---|---|
| `--json` | Afficher en JSON au lieu du texte formaté |
| `--help` | Afficher l'aide de la commande |

Toutes les commandes `list` sauf `adapty product-offers list` acceptent également des drapeaux de pagination :

| Drapeau | Défaut | Description |
|---|---|---|
| `--page` | `1` | Numéro de page |
| `--page-size` | `20` | Éléments par page (max : 100) |

## Skills \{#skills\}

### adapty skills install

Installe les skills Adapty dans les agents de code sur cette machine.

```bash
adapty skills install
```

| Flag | Required | Description |
|---|---|---|
| `--agent` | No | Agent to install into: `claude-code`, `codex`, or `gemini-cli`. Repeat the flag for several agents. |
| `-y`, `--yes` | No | Install into every agent found without asking. Required when the CLI finds several agents and can't ask, for example with `--json`. |

Le CLI recherche Claude Code, Codex et Gemini CLI dans `PATH`. S'il n'en trouve aucun, il demande s'il faut exécuter `npx skills@1.7.0 add adaptyteam/adapty-skills --all --global`, qui couvre les autres agents. Redémarrez l'agent pour charger les skills.

Claude Code ne met pas le plugin à jour automatiquement. Pour obtenir les nouvelles skills au fur et à mesure de leur publication, dans Claude Code, exécutez `/plugin`, ouvrez **Marketplaces**, sélectionnez `adapty`, puis choisissez **Enable auto-update**. Pour l'activer sans passer par le menu, ajoutez `"autoUpdate": true` à l'entrée `adapty` dans `~/.claude/settings.json` :

```json title="~/.claude/settings.json"
{
  "extraKnownMarketplaces": {
    "adapty": {
      "source": { "source": "github", "repo": "adaptyteam/adapty-skills" },
      "autoUpdate": true
    }
  }
}
```

Les skills installés via le CLI skills se mettent à jour avec `npx skills update`. Pour Codex, consultez le [README du plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#codex).
