Le [CLI développeur Adapty](developer-cli) fonctionne dans l'application Claude, ce qui vous permet de gérer votre compte Adapty depuis une conversation plutôt qu'un terminal. Claude exécute les commandes dans un sandbox qui n'accède qu'aux domaines autorisés, donc le CLI nécessite une configuration unique dans Claude avant de pouvoir se connecter à votre compte.

:::note
Claude Cowork et chat ne font désormais [plus qu'un](https://claude.com/resources/articles/cowork-is-now-claude) : tout ce que vous faisiez dans Cowork, vous pouvez maintenant le faire dans n'importe quelle conversation. La fusion est déployée progressivement selon les plans. Si votre plan dispose encore d'un Cowork séparé, suivez les mêmes étapes et démarrez chaque tâche dans Cowork.
:::

**Ce dont vous avez besoin :**

- L'application Claude
- Un compte Adapty
- Pour les espaces de travail Claude d'entreprise, l'aide de votre administrateur d'espace de travail — voir [Autoriser les domaines Adapty](#allow-the-adapty-domains)

## Ajouter le plugin Adapty \{#add-the-adapty-plugin\}

Le plugin Adapty regroupe les instructions que Claude suit pour installer, authentifier et piloter le CLI, y compris la [skill Apple Ads](developer-cli-ads-manager-skill) pour les tâches dans Ads Manager.

Pour ajouter le plugin :

1. Dans Claude, ouvrez **Settings** → **Plugins**.
2. Cliquez sur **Add** → **Add marketplace**.
3. Sélectionnez **Add from a repository**.
4. Dans le champ **URL**, collez `https://github.com/adaptyteam/apple-ads-cli`.
5. Cliquez sur **Sync**.

<ZoomImage id="cowork-marketplace-url.png" width="700px" alt="Boîte de dialogue d'ajout de marketplace dans Claude avec l'URL du dépôt Adapty et le bouton Sync" />

Les plugins Adapty apparaissent sous **Personal** dans le répertoire des plugins.

## Autoriser les domaines Adapty \{#allow-the-adapty-domains\}

Tant que vous n'autorisez pas Adapty dans la liste des domaines autorisés du sandbox, le CLI ne peut pas se connecter ni lire votre compte.

Autorisez `adapty.io` et `*.adapty.io`. Un joker ne couvre pas le domaine racine dans la plupart des implémentations de listes blanches. Le CLI lui-même atteint `api.adapty.io`, et un agent qui consulte la documentation Adapty pendant son travail atteint le domaine racine.

Claude applique ces paramètres au démarrage d'une conversation. Si vous modifiez le mode d'accès ou ajoutez un domaine en cours de conversation, cette conversation conserve les paramètres avec lesquels elle a démarré — commencez une nouvelle conversation.

### Comptes personnels \{#personal-accounts\}

Vous configurez vous-même la liste d'autorisation :

1. Dans Claude, ouvrez **Settings** → **Capabilities**.
2. Activez **Code execution and file creation**. Le bloc **Allow network egress** reste masqué jusqu'à ce que vous le fassiez.
3. Activez **Allow network egress**.
4. Dans **Domain allowlist**, sélectionnez **Package managers only**.
5. Sous **Additional allowed domains**, ajoutez `adapty.io`, puis ajoutez `*.adapty.io`.

<ZoomImage id="cowork-domain-allowlist.png" width="700px" alt="Paramètres Allow network egress dans Claude, avec adapty.io et *.adapty.io dans la liste des domaines autorisés supplémentaires" />

L'autre mode d'accès, **All domains**, permet au sandbox d'accéder à n'importe quel site. Avec cette option, vous n'avez pas besoin d'ajouter les domaines Adapty.

### Espaces de travail d'entreprise \{#corporate-workspaces\}

Un administrateur contrôle la liste d'autorisations. Demandez-lui d'ajouter les deux domaines pour l'espace de travail.

## Installer et autoriser le CLI \{#install-and-authorize-the-cli\}

Chaque conversation commence sur une machine vierge : ni CLI, ni token, ni configuration ne sont conservés d'une conversation à l'autre. Les étapes d'installation et de connexion se répètent donc au début de chaque conversation.

Pour installer et autoriser le CLI :

1. Démarrez une nouvelle conversation dans Claude.
2. Demandez à Claude d'installer le CLI Adapty — par exemple, « Install the Adapty CLI ». Claude peut demander l'autorisation d'ouvrir des liens d'installation — acceptez.

   <ZoomImage id="cowork-cli-installed.png" width="700px" alt="A Claude chat where Claude confirms the Adapty CLI is installed" />

3. Une fois l'installation terminée, Claude propose de se connecter à Adapty — acceptez, et il publie un lien d'autorisation avec un code d'appareil. Le code expire dans environ 15 minutes.

   <ZoomImage id="cowork-auth-link.png" width="700px" alt="A Claude chat where Claude posts the Adapty authorization link and device code" />

4. Ouvrez le lien. La page d'autorisation de l'Adapty CLI s'ouvre dans votre navigateur.
5. Vérifiez que le code affiché sur la page correspond au code que Claude vous a donné, puis cliquez sur **Authorize**. Si les codes ne correspondent pas, cliquez sur **Deny** et demandez à Claude un nouveau lien.

   <ZoomImage id="cowork-authorize-page.png" width="700px" alt="La page d'autorisation Adapty CLI dans un navigateur affichant le code d'appareil et le bouton Authorize" />

6. De retour dans le chat, dites à Claude que vous avez autorisé — par exemple, « done ». Claude vérifie la connexion et affiche les détails de votre compte.

Le CLI est prêt. Pour configurer votre app, vos produits et vos paywalls depuis le chat, suivez le [guide de démarrage rapide](developer-cli-quickstart).

## Résolution des problèmes \{#troubleshooting\}

| Problème | Comment le résoudre |
|---------|---------------|
| Les skills n'apparaissent pas après avoir cliqué sur **Sync** | Vérifiez que l'URL du dépôt est `https://github.com/adaptyteam/apple-ads-cli`, puis cliquez à nouveau sur **Sync**. |
| Erreurs réseau pendant l'installation ou l'autorisation | Ajoutez `adapty.io` et `*.adapty.io` à la [liste des domaines autorisés](#allow-the-adapty-domains). Les paramètres s'appliquent au démarrage d'une conversation, donc démarrez une nouvelle conversation après les avoir ajoutés. |
| Le lien d'autorisation ne s'ouvre pas ou est refusé | Le code expire au bout d'environ 15 minutes. Demandez à Claude de générer un nouveau lien. |
| Le code dans le navigateur ne correspond pas au code dans le chat | Ne cliquez pas sur **Authorize**. Demandez à Claude un nouveau lien et recommencez depuis le début. |
