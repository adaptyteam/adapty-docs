Pour vous aider à démarrer avec le SDK Adapty, nous avons préparé des exemples d'applications qui montrent comment intégrer et utiliser ses fonctionnalités principales. Ces applications proposent des implémentations prêtes à l'emploi de paywalls, d'achats et de suivi analytique.

## Pourquoi utiliser les exemples d'applications ? \{#why-use-sample-apps\}

- **Intégration rapide :** Découvrez comment le SDK Adapty fonctionne dans une vraie application.
- **Bonnes pratiques :** Suivez les modèles d'implémentation recommandés.
- **Débogage et tests :** Utilisez les exemples d'applications pour résoudre des problèmes et expérimenter avant d'intégrer Adapty dans votre propre projet.
