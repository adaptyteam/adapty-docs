Pour vous aider à démarrer avec le SDK Adapty, nous avons préparé des exemples d'applications qui montrent comment intégrer et utiliser ses fonctionnalités principales. Ces applications proposent des implémentations prêtes à l'emploi de paywalls, d'achats et de suivi analytique.

## Pourquoi utiliser les exemples d'applications ? \{#why-use-sample-apps\}

- **Intégration rapide :** Découvrez comment le SDK Adapty fonctionne dans une vraie application.
- **Bonnes pratiques :** Suivez les modèles d'implémentation recommandés.
- **Débogage et tests :** Utilisez les exemples d'applications pour résoudre des problèmes et expérimenter avant d'intégrer Adapty dans votre propre projet.

## Applications d'exemple disponibles \{#available-sample-apps\}

- [iOS (Swift)](https://github.com/adaptyteam/AdaptySDK-iOS/tree/master/Examples)
- [Android (Kotlin)](https://github.com/adaptyteam/AdaptySDK-Android/tree/master/app)
- [React Native (exemple basique)](https://github.com/adaptyteam/AdaptySDK-React-Native/tree/master/examples/BasicExample) — une configuration minimale qui illustre les fonctionnalités essentielles du SDK.
- [React Native (Expo Go et Expo Web)](https://github.com/adaptyteam/AdaptySDK-React-Native/tree/master/examples/ExpoGoWebMock) — le plus rapide à tester : il tourne dans un navigateur avec des données fictives, sans clé API Adapty. Couvre à la fois un paywall personnalisé et le Flow & Paywall Builder.
- [React Native (Focus Journal, une app Expo)](https://github.com/adaptyteam/AdaptySDK-React-Native/tree/master/examples/FocusJournalExpo) — une application avec des fonctionnalités premium derrière un paywall Flow & Paywall Builder. Accompagnée d'un [guide vidéo](https://www.youtube.com/watch?v=TtCJswpt2ms).
- [React Native (Adapty DevTools)](https://github.com/adaptyteam/AdaptySDK-React-Native/tree/master/examples/AdaptyDevtools) — un outil de développement et de signalement de bugs pour les cas plus complexes. La même application est aussi disponible [avec Swift Package Manager à la place de CocoaPods](https://github.com/adaptyteam/AdaptySDK-React-Native/tree/master/examples/AdaptyDevtoolsSpm).
- [Flutter (Dart)](https://github.com/adaptyteam/AdaptySDK-Flutter/tree/master/example)
- [Unity (C#)](https://github.com/adaptyteam/AdaptySDK-Unity/tree/main/Assets)
- [Kotlin Multiplatform](https://github.com/adaptyteam/AdaptySDK-KMP/tree/main/example)
- [Capacitor (React)](https://github.com/adaptyteam/AdaptySDK-Capacitor/tree/master/examples/basic-react-example)
- [Capacitor (Vue.js)](https://github.com/adaptyteam/AdaptySDK-Capacitor/tree/master/examples/basic-vue-example)
- [Capacitor (Angular)](https://github.com/adaptyteam/AdaptySDK-Capacitor/tree/master/examples/basic-angular-example)
- [Capacitor (Outils de développement avancés)](https://github.com/adaptyteam/AdaptySDK-Capacitor/tree/master/examples/adapty-devtools)
