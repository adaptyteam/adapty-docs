## Autorisation \{#authorization\}

Les requêtes API doivent être authentifiées avec votre clé API publique dans le header **Authorization** sous la forme `Api-Key {your_public_api_key}`, par exemple `Api-Key public_live_...`. Retrouvez cette clé dans [Adapty Dashboard -> **App Settings** -> **General** tab -> **API keys** section](https://app.adapty.io/settings/general).

:::important
Les clés API sont propres à chaque application. Si vous avez plusieurs applications, veillez à utiliser des clés différentes pour chacune d'elles.
:::

## Format des requêtes \{#request-format\}

- **En-tête Content-Type** :
  Définissez l'en-tête **Content-Type** sur `application/json` pour que l'API traite votre requête.
- **Corps** :
  L'API s'attend à ce que la requête utilise le corps au format JSON.
