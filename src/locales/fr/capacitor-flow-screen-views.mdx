Chaque fois qu'un utilisateur ouvre un écran dans un [flow](adapty-flow-builder), le SDK envoie un événement `flow_screen_showed` à votre application. Transmettez-le à Amplitude, Mixpanel ou tout autre outil d'analyse produit que vous utilisez, afin d'analyser les écrans de flow avec le reste des événements de votre application.

:::tip
Pour voir jusqu'où les utilisateurs avancent dans un flow, aucun code n'est nécessaire — les [métriques de flow](flow-metrics) affichent déjà les vues, les complétions et les abandons par écran dans l'Adapty Dashboard. Utilisez ce guide si vous avez besoin des mêmes données dans votre propre outil d'analyse, combinées avec des événements qu'Adapty ne connaît pas.
:::

## Avant de commencer \{#before-you-start\}

Vous avez besoin de :

- **Adapty Capacitor SDK v4 ou version ultérieure** : le callback d'analytique de flow n'existe pas dans les versions antérieures.
- **Une version de flow publiée après le déploiement de cette fonctionnalité** : Adapty génère les événements d'écran lors de la publication d'un flow. Un flow publié avant cette date ne remonte aucun événement. Si aucun événement n'arrive dans votre application, publiez une nouvelle version du flow et réessayez.

## Ce que vous recevez \{#what-you-receive\}

<FlowScreenShowedParams />

Les vues d'écran parviennent au même callback d'analyse que tous les autres événements de flow. Consultez [Gérer les événements flow & paywall](capacitor-handling-events) pour savoir où l'enregistrer.

## Transférez chaque vue d'écran vers vos analytics \{#forward-every-screen-view-to-your-analytics\}

Vérifiez le nom de l'événement avant de lire quoi que ce soit d'autre, car un flow signale d'autres événements via le même callback.

```typescript showLineNumbers title="Capacitor"
view.setEventHandlers({
  onAnalytics(name, params) {
    if (name === 'flow_screen_showed') {
      const screenId = params.instanceId;
      const screenOrder = params.screen_order;

      // Send screenId and screenOrder to your analytics provider here.
    }
    return false; // keep the flow open
  },
});
```

## Exécuter du code quand un utilisateur atteint la fin \{#run-code-when-a-user-reaches-the-end\}

`is_last_screen` vaut `true` sur un écran que le flow ne peut pas dépasser. Utilisez-le pour déverrouiller du contenu, marquer l'onboarding comme terminé ou envoyer un événement de complétion personnalisé, sans ajouter d'action de bouton dans le builder.

```typescript showLineNumbers title="Capacitor"
view.setEventHandlers({
  onAnalytics(name, params) {
    if (name === 'flow_screen_showed' && params.is_last_screen) {
      // The user reached the end of the flow.
    }
    return false; // keep the flow open
  },
});
```

Atteindre le dernier écran n'est pas la même chose que fermer le flow. Un utilisateur peut voir l'écran final et fermer le flow sans agir dessus, et un flow avec embranchements peut se terminer sur plusieurs écrans différents. Pour savoir que le flow lui-même a disparu, utilisez plutôt `onDisappeared`.
