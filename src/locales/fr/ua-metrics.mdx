Voici un aperçu des métriques disponibles dans les analyses Adapty Attribution. Utilisez-le pour comprendre ce que chaque métrique mesure et comment Adapty la calcule. Pour les analyses d'abonnement générées par Adapty Core, consultez le [tableau de comparaison des métriques](metric-comparison-table).

:::note
Les achats web n'ont pas d'événement d'installation d'application. Adapty les regroupe en cohortes selon la date du premier démarrage d'essai ou du premier achat.
:::

## Métriques standard \{#standard-metrics\}

| **Métrique**                        | Description                                                                                                                                                                                                                                                                                                                                                                                                                                     | <InlineTooltip tooltip="Support des cohortes">Une période de cohorte limite une métrique à un nombre de jours après l'installation, par exemple 7 jours pour le ROAS J7.</InlineTooltip> |
|-----------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---:|
| **Spend**                         | La somme du coût de chaque clic d'un utilisateur sur votre publicité.                                                                                                                                                                                                                                                                                                                                                                            | Non     |
| **Impressions**                   | Le nombre de fois où votre publicité a été affichée dans la plage de dates sélectionnée.                                                                                                                                                                                                                                                                                                                                                                           | Non     |
| **Clicks**                        | Le nombre de fois où des utilisateurs ont cliqué sur votre publicité dans la plage de dates sélectionnée. Exclut les clics sur les [liens de suivi personnalisés](ua-tracking-links).                                                                                                                                                                                                                                                                                                                                                                       | Non     |
| **Clicks (attributed)** | Le nombre de clics sur votre publicité qu'Adapty a comptabilisés via ses liens de suivi. Inclut les clics sur les [liens de suivi personnalisés](ua-tracking-links). | Non |
| **CPI**                           | **CPI (Coût par Installation)** est le montant que vous payez pour chaque installation. <br/>**Formule** : `Spend / Installs`                                                                                                                                                                                                                                                                                                                                         | Non     |
| **CPC**                           | **CPC (Coût par Clic)** est le montant que vous payez pour chaque clic sur votre publicité. <br/>**Formule** : `Spend / Clicks`                                                                                                                                                                                                                                                                                                                    | Non     |
| **CPM**                           | **CPM (Coût pour Mille)** est le montant que vous payez pour mille impressions publicitaires. <br/>**Formule** : `Spend / (Impressions / 1000)`                                                                                                                                                                                                                                                                                                                | Non     |
| **ICR**                           | **ICR (Taux de Conversion par Installation)** est le pourcentage de clics sur une publicité ayant abouti à des installations. <br/>**Formule** : `(Installs / Clicks) × 100%`                                                                                                                                                                                                                                                                                                                      | Non     |
| **ICR (attributed)** | Le pourcentage de **Clicks (attributed)** ayant abouti à des installations. <br/>**Formule** : `(Installs / Clicks (attributed)) × 100%` | Non |
| **IPM**                           | **IPM (Installations pour Mille)** représente le nombre d'installations pour mille impressions publicitaires. <br/>**Formule** : `(Installs / Impressions) × 1000`                                                                                                                                                                                                                                                                             | Non     |
| **CTR**                           | **CTR (Taux de Clic)** est le pourcentage d'impressions ayant abouti à des clics. <br/>**Formule** : `(Clicks / Impressions) × 100%`                                                                                                                                                                                                                                                                                                                        | Non     |
| **Inline link clicks**            | Le nombre de fois où des utilisateurs ont cliqué sur des liens intégrés dans vos créations publicitaires ou votre page d'application.                                                                                                                                                                                                                                                                                                                                                                | Non     |
| **Avg cost per inline link click** | Le montant moyen que vous payez par clic sur un lien intégré. <br/>**Formule** : `Spend / Inline link clicks`                                                                                                                                                                                                                                                                                                                                                | Non     |
| **Inline link click through rate**         | Le pourcentage d'impressions ayant abouti à des clics sur des liens intégrés. <br/>**Formule** : `(Inline link clicks / Impressions) × 100%`                                                                                                                                                                                                                                                                                                                | Non     |
| **Installs**                      | Le nombre total de fois où des utilisateurs ont installé votre application dans la plage de dates sélectionnée. Chaque réinstallation compte comme une nouvelle installation, avec sa propre attribution.                                                                                                                                                                                                                                                                                                                                           | Non     |
| **Payers** | Le nombre d'abonnements payants démarrés par des utilisateurs, directement ou après une période d'essai. <br/>**Formule** : `Subscriptions started + Trial converted` | Oui |
| **Total revenue**                 | Le montant total généré jusqu'à présent par les achats des utilisateurs installés dans la plage de dates sélectionnée. Pour basculer entre les revenus bruts et les revenus nets, utilisez le menu déroulant des revenus dans [Adapty Attribution analytics](ua-analytics#gross-revenue-or-proceeds).                                                                                                                                                                                                                                                                  | Non     |
| **Revenue** | Les revenus générés par les utilisateurs installés dans la plage de dates sélectionnée, durant la période de cohorte suivant l'installation, par exemple 7 jours pour **D7 Revenue**. Sans période de cohorte, utilisez **Total revenue**. | Cohortes uniquement |
| **ROAS**                          | **ROAS (Retour sur les Dépenses Publicitaires)** est le revenu généré par vos publicités divisé par les dépenses publicitaires, exprimé en pourcentage. <br/> **Formule** : `(Total revenue / Spend) × 100% si Spend > 0, sinon 0%`                                                                                                                                                                                                                                            | Oui    |
| **AdProfit** | Le revenu diminué des dépenses publicitaires. <br/>**Formule** : `Total revenue − Spend` | Oui |
| **ARPU** | **ARPU (Revenu Moyen par Utilisateur)** est le revenu moyen par installation. <br/>**Formule** : `Total revenue / Installs` | Oui |
| **ARPPU** | **ARPPU (Revenu Moyen par Utilisateur Payant)** est le revenu moyen par utilisateur ayant payé. <br/>**Formule** : `Total revenue / Paying users`. `Paying users` est le nombre d'utilisateurs ayant payé, tandis que **Payers** est le nombre d'abonnements payants. | Non |
| **ARPAS** | **ARPAS (Revenu Moyen par Abonné Actif)** est le revenu moyen par abonnement ou essai démarré. <br/>**Formule** : `Total revenue / (Subscriptions started + Trial started)` | Oui |
| **ARPT** | **ARPT (Revenu Moyen par Essai)** est le revenu moyen par essai démarré. <br/>**Formule** : `Total revenue / Trial started` | Oui |
| **Cost per trial**                | Le montant moyen que vous payez par essai démarré. <br/>**Formule** : `Spend / Trial started`                                                                                                                                                                                                                                                                                                                                                   | Non     |
| **Cost per subscription**         | Le montant moyen que vous payez par abonnement démarré. <br/>**Formule** : `Spend / Subscriptions started`                                                                                                                                                                                                                                                                                                                           | Non     |

## Métriques d'événement \{#event-metrics\}

Les métriques d'événement comptabilisent les événements d'abonnement et d'achat des utilisateurs qui ont installé l'application dans la plage de dates sélectionnée. Chaque événement dispose de deux métriques :

- **Count** : Le nombre de fois que l'événement s'est produit.
- **Rate** : Le nombre exprimé en pourcentage des installations. **Formule** : `(Count / Installs) × 100%`

Vous pouvez ajouter toutes les métriques d'événement avec ou sans période de cohorte.

| Événement | Métrique de comptage | Métrique de taux |
|---|---|---|
| Des utilisateurs ont démarré un abonnement payant sans période d'essai. | **Subscriptions started** | **Rate subscription started** |
| Des abonnements ont été renouvelés. | **Subscription renewed** | **Rate subscription renewed** |
| Des utilisateurs ont désactivé le renouvellement automatique d'un abonnement. | **Subscription renewal cancelled** | **Rate subscription renewal cancelle** |
| Des utilisateurs ont réactivé le renouvellement automatique d'un abonnement. | **Subscription renewal reactivated** | **Rate subscription renewal reactivated** |
| Des abonnements ont pris fin sans renouvellement. | **Subscription expired** | **Rate subscription expired** |
| Des utilisateurs ont mis un abonnement en pause sur Android. | **Subscription paused** | **Rate subscription paused** |
| Le backend de l'application a [différé le paiement](https://adapty.io/glossary/subscription-purchase-deferral/) d'un abonnement Google Play. | **Subscription deferred count** | **Rate subscription deferred** |
| Le store a remboursé un achat d'abonnement. | **Subscription refunded** | **Rate subscription refunded** |
| Des utilisateurs ont contesté un paiement d'abonnement auprès de leur banque. | **Subscription chargeback** | **Rate subscription chargeback** |
| La banque vous a restitué un paiement d'abonnement contesté. | **Subscription chargeback reversed** | **Rate subscription chargeback reversed** |
| Des utilisateurs ont démarré un essai gratuit. | **Trial started** | **Rate trial started** |
| Des essais ont été convertis en abonnements payants. | **Trial converted** | **Rate trial converted** |
| Des utilisateurs ont désactivé le renouvellement automatique pendant un essai. | **Trial renewal cancelled** | **Rate trial renewal cancelled** |
| Des utilisateurs ont réactivé le renouvellement automatique pendant un essai. | **Trial renewal reactivated** | **Rate trial renewal reactivated** |
| Des essais ont pris fin sans conversion en abonnement payant. | **Trial expired** | **Rate trial expired** |
| Le store n'a pas pu débiter un utilisateur, par exemple en raison de fonds insuffisants. | **Billing issue detected** | **Rate billing issue detected** |
| Des abonnements sont entrés en délai de grâce en raison d'un problème de paiement. | **Entered grace period** | **Rate entered grace period** |
| Des utilisateurs ont effectué un achat unique. | **Non-subscription purchase** | **Rate non-subscription purchase** |
| Le store a remboursé un achat unique. | **Non-subscription purchase refunded** | **Rate non-subscription purchase refunded** |
| Des utilisateurs ont contesté le paiement d'un achat unique auprès de leur banque. | **Non-subscription purchase chargeback** | **Rate non-subscription purchase chargeback** |
| La banque vous a restitué un paiement d'achat unique contesté. | **Non-subscription purchase chargeback reversed** | **Rate non-subscription purchase chargeback reversed** |

## Métriques Google Ads \{#google-ads-metrics\}

Google Ads rapporte ces métriques directement, elles ne sont donc disponibles que sur les lignes Google Ads. Les lignes des autres réseaux affichent « — ». Pour ajouter la plupart de ces colonnes au tableau en une seule étape, sélectionnez le [préréglage Google Ads](ua-analytics#google-ads-preset).

| **Métrique** | Description | Cohorte |
|---|---|---|
| **Conversions (Network)** | Les conversions que Google Ads comptabilise pour les actions de conversion dans votre compte Google Ads, par date de clic. Ce sont les chiffres de Google, pas les essais ou achats d'Adapty, donc les deux ne correspondent pas. | Non |
| **All Conv. (Network)** | Toutes les conversions que Google Ads comptabilise, par date de clic. Google Ads affiche ce chiffre dans sa colonne **All conv.**. | Non |
| **Cost per Conversion (Network)** | La dépense moyenne par conversion reportée par Google Ads. Seule la dépense des lignes qui reportent des conversions est prise en compte. <br/>**Formule** : `Spend / Conversions (Network)` | Non |
| **First Page Bid Est.** | L'estimation de Google concernant l'enchère nécessaire pour afficher votre annonce sur la première page des résultats de recherche. | Non |
| **First Position Bid Est.** | L'estimation de Google concernant l'enchère nécessaire pour afficher votre annonce en première position sur la première page des résultats de recherche. | Non |
| **Status** | Le statut Google Ads de la campagne, du groupe d'annonces, de l'annonce ou du mot-clé de la ligne : **Enabled**, **Paused** ou **Removed**. | Non |

### Conversions \{#conversions\}

Adapty actualise les conversions de chaque journée pendant 3 jours, puis les conserve telles quelles. Google Ads continue d'ajouter des conversions tardives aux dates de clic passées, ce qui peut entraîner un nombre de conversions inférieur dans Adapty par rapport à Google Ads pour les jours plus anciens. Adapty n'importe pas les conversions pour les jours antérieurs au début de leur collecte, ces jours affichent donc « — ».

### Estimations des enchères \{#bid-estimates\}

Les deux colonnes d'estimation des enchères n'apparaissent dans le tableau que lorsque vous regroupez par mot-clé. Pour chaque mot-clé, Adapty affiche l'estimation de Google pour le dernier jour avec du trafic dans la plage de dates sélectionnée.

Google ne fournit pas d'estimations d'enchères pour les mots-clés Display et App. Il n'en fournit pas non plus pour les mots-clés Search dans les campagnes avec enchères automatiques, telles que **Maximize clicks**, **Maximize conversions** ou **Target CPA**. Ces mots-clés affichent « — ».

### Statut \{#status\}

Adapty met à jour les statuts une fois par jour. Un statut s'affiche dans une ligne lorsque deux conditions sont réunies :

- Le tableau est regroupé par campagne, ensemble d'annonces, annonce ou mot-clé.
- La ligne présente des dépenses Google Ads dans la plage de dates sélectionnée.

Si plusieurs campagnes Google Ads portent le même nom, la ligne affiche **Enabled** si l'une d'elles est active. Sinon, elle affiche **Paused** si l'une d'elles est en pause, et **Removed** si toutes sont supprimées.

## Métriques prédites \{#predicted-metrics\}

Les métriques prédites projettent les performances futures d'une cohorte à partir des données historiques de l'application, et couvrent donc aussi les installations organiques. Elles sont disponibles pour plusieurs périodes de cohorte, notamment D30, D60, D90, D180 et D360, ainsi que des périodes personnalisées que vous pouvez ajouter en jours. Pour en savoir plus sur le calcul de ces valeurs, consultez [Métriques prédites dans Adapty Attribution](ua-predicted-metrics).

| **Métrique**  | Description                                                                                                                                                                                | <InlineTooltip tooltip="Support des cohortes">Une période de cohorte limite une métrique à un nombre de jours après l'installation, par exemple 7 jours pour le ROAS D7.</InlineTooltip> |
|---------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---:|
| **pRevenue**  | Revenu total prédit qu'une cohorte devrait générer d'ici l'horizon cible. Modélisé à partir de la rétention historique des cohortes de l'application.                                      | Cohortes uniquement |
| **pROAS**     | Retour sur les dépenses publicitaires prédit sur le même horizon. **Formule** : `(pRevenue / Spend) × 100%`. Adapty ne le calcule pas pour les lignes sans dépenses, comme **Organic**.    | Cohortes uniquement |
| **pAdProfit** | Revenu prédit net des dépenses publicitaires sur l'horizon. **Formule** : `pRevenue − Spend`                                                                                               | Cohortes uniquement |
| **pARPU**     | Revenu moyen prédit par installation sur l'horizon (LTV prédit). **Formule** : `pRevenue / Installs`                                                                                       | Cohortes uniquement |
| **pARPPU**    | Revenu moyen prédit par utilisateur payant sur l'horizon. **Formule** : `pRevenue / paying users at d{N}`, où `d{N}` correspond à l'horizon sélectionné.                                   | Cohortes uniquement |
