Un test A/B dans Adapty Mail compare deux campagnes e-mail complètes ou plus l'une contre l'autre. Chaque variante est une campagne indépendante et autonome. Lorsqu'un utilisateur correspond au segment du test dans un [flow](mail-flows), Adapty Mail le dirige vers l'une des variantes selon les poids configurés, et suit la distribution, l'engagement et les revenus par variante.

## Ce qu'est une variante \{#what-a-variation-is\}

Chaque variante est une campagne complète. Les variantes peuvent différer par le texte, les images principales, le ton, la longueur de la séquence ou les délais entre les e-mails. Ce qu'elles ont en commun, c'est l'[objectif](mail-create-campaign) — un test compare des éléments similaires, donc chaque campagne qu'il contient est rédigée pour le même moment du cycle de vie client. Le test A/B lui-même n'expose pas ces paramètres directement ; vous créez les campagnes séparément et vous les ajoutez comme variantes.

## Créer un test A/B \{#create-an-ab-test\}

1. Créez d'abord les campagnes dans **Campaigns**. Chaque variante nécessite sa propre campagne, et elles doivent toutes avoir le même objectif.
2. Dans Adapty Mail, accédez à **A/B Tests** et cliquez sur **Create**.
3. Ajoutez chaque campagne en tant que variante et définissez son poids. Le total des poids doit être égal à **100 %**.
4. Assignez un segment pour déterminer à quels utilisateurs le test s'applique.
5. Enregistrez.

Le test est sauvegardé en tant que **draft** et n'envoie rien pour le moment. Pour le mettre en ligne, il doit être associé à un flow.

## Lancement depuis un flow \{#launch-from-a-flow\}

Les tests A/B ne peuvent pas être lancés depuis la page A/B Tests — le lancement et la fin se font tous deux depuis une ligne de flow.

1. Dans Adapty Mail, accédez à **Flows** et ouvrez le déclencheur depuis lequel vous souhaitez exécuter le test.
2. Cliquez sur **Create** sur une nouvelle ligne. Dans la boîte de dialogue, définissez **Content type** sur **A/B Test**, sélectionnez le test que vous avez enregistré, puis cliquez sur **Save**.
3. Sur la ligne, cliquez sur **Launch A/B test**.

L'état du test passe de **draft** à **live** et les utilisateurs entrants qui correspondent au segment commencent à être routés vers les variantes. Consultez [Créer un flow](mail-create-flow) pour en savoir plus sur les lignes de flow.

## Comment fonctionne le routage \{#how-routing-works\}

Lorsqu'un utilisateur déclenche le flow et correspond au segment du test A/B, Adapty Mail sélectionne une variante par tirage **aléatoire pondéré** — le poids de chaque variante détermine sa part du tirage. Le routage n'est pas déterministe par utilisateur.

## Lire les résultats \{#read-results\}

Sur la page des tests A/B, chaque variante affiche ses compteurs bruts et les taux calculés :

- **Delivery** : Sends, Deliveries, Bounces.
- **Engagement** : Opens, Clicks, Unsubs.
- **Revenue** : Purchases, Revenue.

Consultez [Analytique des campagnes](mail-analytics) pour savoir ce que chaque métrique comptabilise et comment le chiffre d'affaires est attribué.

## Terminer le test \{#finish-the-test\}

Comme pour le lancement, la clôture s'effectue depuis la ligne du flow, et non depuis la page A/B Tests.

1. Ouvrez la ligne du flow où le test est en cours.
2. Cliquez sur **Finish A/B test**.
3. Dans la boîte de dialogue **Finish A/B test**, sélectionnez la campagne gagnante dans le menu déroulant **Replace with campaign** — ou laissez-le vide pour supprimer entièrement le segment du flow.
4. Confirmez.

:::note
Les utilisateurs déjà en cours de séquence dans n'importe quelle variante — gagnante ou perdante — continuent de recevoir leurs e-mails planifiés. Ils ne sont pas basculés vers la variante gagnante.
:::

## Cycle de vie \{#lifecycle\}

Un test A/B passe par quatre états :

- **Brouillon** : Créé, pas encore associé à une ligne de flow active.
- **En cours** : Associé et lancé ; dirige les nouveaux utilisateurs.
- **Terminé** : Arrêté via **Finish A/B test**.
- **Archivé** : Supprimé de manière logicielle de la liste.
