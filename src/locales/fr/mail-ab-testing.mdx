Un test A/B dans Adapty Mail compare deux campagnes e-mail complètes ou plus. Chaque variante est une campagne indépendante à part entière. Lorsqu'un utilisateur correspond au segment du test dans un [flow](mail-flows), Adapty Mail l'oriente vers l'une des variantes selon les poids configurés, et suit les livraisons, l'engagement et le chiffre d'affaires par variante.

:::tip
Un assistant IA connecté au [serveur MCP Adapty Mail](mail-mcp) peut créer un test, le lancer sur un flow, lire le funnel par variante et le terminer en désignant le gagnant. Il vous demande confirmation avant de lancer ou de terminer.
:::

## Ce qu'est une variante \{#what-a-variation-is\}

Chaque variante est une campagne complète. Les variantes peuvent différer par le texte, les images principales, le ton, la longueur de la séquence ou les délais entre les e-mails. Chaque variante a ses propres [traductions](mail-localization). Pour une comparaison équitable, localisez chaque variante dans les mêmes langues.

Les variantes ne peuvent pas différer selon les destinataires ou le moment d'envoi. Un seul segment couvre l'intégralité du test. Chaque campagne qu'il contient partage un même [objectif](mail-create-campaign) — le moment du cycle de vie auquel elle répond, nommé de la même façon qu'un flow nomme son [déclencheur](mail-flows#triggers). C'est ce qui détermine dans quel flow le test peut s'exécuter.

Vous rédigez chaque campagne séparément, puis vous les ajoutez en tant que variantes.

## Créer un test A/B \{#create-an-ab-test\}

1. Créez d'abord les campagnes dans **Campaigns**. Chaque variante nécessite sa propre campagne, et elles doivent toutes avoir le même objectif.
2. Dans Adapty Mail, accédez à **A/B Tests** et cliquez sur **Create**.
3. Ajoutez chaque campagne en tant que variante et définissez son poids. Le total des poids doit être égal à **100 %**.
4. Assignez un segment pour déterminer à quels utilisateurs le test s'applique.
5. Enregistrez.

Le test est sauvegardé en tant que **draft** et n'envoie rien pour le moment. Pour le mettre en ligne, il doit être associé à un flow.

## Lancer depuis un flow \{#launch-from-a-flow\}

Vous lancez et terminez un test A/B depuis le flow, et non depuis la page **A/B Tests**.

1. Dans Adapty Mail, accédez à **Flows** et ouvrez le déclencheur qui doit lancer le test.
2. Cliquez sur **Create** dans une nouvelle ligne. Dans la boîte de dialogue, définissez **Content type** sur **A/B Test**, sélectionnez le test enregistré et cliquez sur **Save**.
3. Sur la ligne, cliquez sur **Launch A/B test**.

L'état du test passe de **draft** à **live** et les utilisateurs entrants qui correspondent au segment commencent à être dirigés vers les variantes. [Gérer les segments dans un flow](mail-create-flow) couvre tout ce que vous pouvez faire à cet endroit.

## Comment fonctionne le routage \{#how-routing-works\}

Lorsqu'un utilisateur déclenche le flow et correspond au segment du test A/B, Adapty Mail sélectionne une variante par tirage **aléatoire pondéré** — le poids de chaque variante détermine sa part du tirage. Le routage n'est pas déterministe par utilisateur.

## Lire les résultats \{#read-results\}

Pour comparer les variantes d'un test en cours, ouvrez son déclencheur sur la page **Flows**. Sous le test, chaque variante dispose d'une ligne avec ses propres compteurs : Sends, Deliveries, Bounces, Opens, Clicks, Unsubs, Purchases et Revenue. Les taux fixes, comme **Del Rate** et **Click/Del**, suivent les compteurs.

<ZoomImage id="mail-ab-testing-comparison.webp" width="500px" alt="Un test A/B en cours sur la page Flows, avec une ligne de compteurs pour chaque variante" />

Pour comparer les variantes sur un graphique, rendez-vous sur la page **A/B Tests**, ouvrez le menu de la ligne du test et sélectionnez **View in analytics**. La page Analytics s'ouvre avec un groupe par variante, pour la période couverte par le test.

Sur la page **A/B Tests**, chaque test correspond à une ligne. La ligne cumule les chiffres de toutes ses variantes depuis le début du test :

- **Sent** : les e-mails envoyés par Adapty Mail.
- **Rates** : les trois premiers taux de votre projet, dans l'ordre de la liste des taux. Pour les modifier, consultez [Modifier les taux](mail-analytics#change-the-rates).
- **Revenue** : le chiffre d'affaires attribué.

<ZoomImage id="mail-ab-tests-list.webp" width="700px" alt="Page des tests A/B avec une ligne par test : colonnes Sent, Open rate, Click rate, Conversion rate et Revenue" />

[L'analyse des campagnes](mail-analytics) explique ce que compte chaque métrique et comment le chiffre d'affaires est attribué.

## Terminer le test \{#finish-the-test\}

1. Ouvrez le déclencheur qui démarre le test.
2. Cliquez sur **Finish A/B test**.
3. Dans la boîte de dialogue **Finish A/B test**, sélectionnez la campagne gagnante dans le menu déroulant **Replace with campaign** — ou laissez-le vide pour retirer entièrement le segment du flow.
4. Confirmez.

:::note
Les utilisateurs déjà en cours de séquence dans l'une ou l'autre variante — gagnante ou perdante — continuent de recevoir leurs e-mails planifiés. Ils ne sont pas basculés vers la variante gagnante.
:::

## Cycle de vie \{#lifecycle\}

Un test A/B passe par quatre états :

- **Draft** : Créé, pas encore ajouté à un flow.
- **Live** : Associé et lancé ; il route les utilisateurs entrants.
- **Finished** : Arrêté via **Finish A/B test**.
- **Archived** : Supprimé (de façon réversible) de la liste.
