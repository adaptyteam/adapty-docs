Un test A/B dans Adapty Mail compare deux campagnes e-mail complètes ou plus. Chaque variante est une campagne indépendante à part entière. Lorsqu'un utilisateur correspond au segment du test dans un [flow](mail-flows), Adapty Mail l'oriente vers l'une des variantes selon les poids configurés, et suit les livraisons, l'engagement et le chiffre d'affaires par variante.

:::tip
Un assistant IA connecté au [serveur MCP Adapty Mail](mail-mcp) peut créer un test, le lancer sur un flow, lire le funnel par variante et le terminer en désignant le gagnant. Il vous demande confirmation avant de lancer ou de terminer.
:::

## Ce qu'est une variante \{#what-a-variation-is\}

Chaque variante est une campagne complète. Les variantes peuvent différer par le texte, les images principales, le ton, la longueur de la séquence ou les délais entre les e-mails. Chaque variante a ses propres [traductions](mail-localization). Pour une comparaison équitable, localisez chaque variante dans les mêmes langues.

Les variantes ne peuvent pas différer selon qui les reçoit, ni quand. Un seul segment couvre l'ensemble du test. Chaque campagne qu'il contient partage un seul [objectif](mail-create-campaign) — le moment du cycle de vie qu'elle adresse, nommé de la même façon que [l'objectif d'un flow](mail-flows#purposes). L'objectif détermine sur quels flows le test peut s'exécuter.

Vous rédigez chaque campagne séparément, puis vous les ajoutez comme variantes.

## Créer un test A/B \{#create-an-ab-test\}

1. Créez d'abord les campagnes dans **Campaigns**. Chaque variante nécessite sa propre campagne, et elles doivent toutes avoir le même objectif.
2. Dans Adapty Mail, accédez à **A/B Tests** et cliquez sur **Create**.
3. Ajoutez chaque campagne comme variante et définissez son poids. Les poids doivent totaliser **100%**.
4. Assignez un segment. Lorsque vous lancez le test depuis la page **A/B Tests**, il s'exécute sur le flow de ce segment et de cet objectif.
5. Cliquez sur **Create**.

Le test est enregistré en tant que **brouillon** et n'envoie rien pour le moment. Pour le mettre en ligne, lancez-le.

## Lancer le test \{#launch-the-test\}

Un test s'exécute sur un flow selon son objet. Lancé depuis la page **A/B Tests**, il s'exécute sur le flow de son propre segment, et Adapty Mail crée ce flow s'il n'en existe aucun. Lancé depuis un flow, il s'exécute sur le segment de ce flow, quel que soit le segment enregistré dans le test.

Quelle que soit la façon dont vous le lancez, le test passe de l'état **brouillon** à **actif**. Dès lors, les utilisateurs qui déclenchent le trigger et appartiennent au segment sont dirigés vers les variantes. Le premier e-mail est envoyé après le [**Délai**](mail-flows#email-delivery-timing) défini.

### Depuis la page des tests A/B \{#from-the-ab-tests-page\}

1. Dans Adapty Mail, accédez à **A/B Tests**.
2. Ouvrez le menu contextuel du test en brouillon et sélectionnez **Launch**. Ou ouvrez le test, enregistrez vos modifications, puis cliquez sur **Launch**.
3. Lisez la boîte de dialogue **Launch A/B test**, puis cliquez sur **Launch**.

<ZoomImage id="mail-ab-testing-launch.webp" width="400px" alt="La boîte de dialogue Launch A/B test, indiquant qu'un flow pour l'objectif Never purchased et le segment du test sera créé" />

La boîte de dialogue vous indique ce qui va se passer avec le flow :

- **Le flow existe et envoie une campagne** : Le test remplace la campagne.
- **Il n'existe pas de flow pour l'objectif et le segment** : Adapty Mail en crée un, après les autres flows de l'objectif. Si un flow précédent a un segment plus large, [déplacez le nouveau flow vers le haut](mail-create-flow#change-the-order-of-flows), sinon le test ne recevra aucun utilisateur.
- **Le flow exécute un autre test A/B** : Vous ne pouvez pas lancer le test. Terminez d'abord l'autre test.

### À partir d'un flow \{#from-a-flow\}

1. Dans Adapty Mail, accédez à **Flows**. [Créez un flow](mail-create-flow#create-a-flow) correspondant à l'objectif du test, ou ouvrez-en un existant.
2. Définissez **Content type** sur **A/B Test**. Dans le champ **A/B Test**, sélectionnez le test en brouillon. La liste affiche tous les tests en brouillon correspondant à cet objectif.
3. Cliquez sur **Create** pour un nouveau flow, ou sur **Save** pour un flow existant.

:::note
Le test s'exécute sur le segment de ce flow, quel que soit le segment que vous y avez enregistré. Pour l'exécuter sur son propre segment, lancez-le depuis la page **A/B Tests**.
:::

## Fonctionnement du routage \{#how-routing-works\}

Lorsqu'un utilisateur déclenche le flow et appartient au segment du flow, Adapty Mail sélectionne une variante par **tirage aléatoire pondéré** — le poids de chaque variante détermine sa part du tirage. Le routage n'est pas déterministe par utilisateur.

## Lire les résultats \{#read-results\}

Pour désigner un gagnant, comparez les variantes dans Analytics. Sur la page **A/B Tests**, ouvrez le menu de ligne du test et sélectionnez **View in analytics**. Le menu de ligne du flow sur la page **Flows** propose la même option **View in analytics**. La page Analytics s'ouvre avec un groupe par variante, pour la période pendant laquelle le test a été actif. Laissez aux utilisateurs de chaque variante le temps de recevoir l'intégralité de la séquence avant de prendre votre décision.

Les pages **Flows** et **A/B Tests** affichent les totaux du test, et non qui est en tête. Sur la page **Flows**, la ligne du flow cumule les **Sent** et les taux de toutes les variantes. Sur la page **A/B Tests**, chaque test occupe une ligne, qui cumule toutes ses variantes depuis le début du test :

- **Sent** : E-mails envoyés par Adapty Mail.
- **Rates** : Les trois premiers taux de votre projet, dans l'ordre de la liste des taux. Pour les modifier, consultez [Modifier les taux](mail-analytics#change-the-rates).
- **Revenue** : Revenus attribués.

<ZoomImage id="mail-ab-tests-list.webp" width="700px" alt="Page des tests A/B avec une ligne par test : colonnes Sent, Open rate, Click rate, Conversion rate et Revenue" />

[L'analyse des campagnes](mail-analytics) explique ce que compte chaque métrique et comment le chiffre d'affaires est attribué.

## Terminer le test \{#finish-the-test\}

:::warning
Dans la boîte de dialogue **Finish A/B test**, **Winner** commence sur **No winner, remove the flow**. Si vous laissez cette option, Adapty Mail supprime le flow. Les flows suivants remontent d'un rang, et les nouveaux utilisateurs du segment rejoignent le flow suivant du même objectif correspondant à leur segment, s'il en existe un.
:::

1. Dans Adapty Mail, accédez à **Flows**. Ouvrez le menu de la ligne du flow qui exécute le test et sélectionnez **Finish A/B test**.

   Vous pouvez également partir de ces emplacements :
   - **La page d'édition du flow** : Cliquez sur **Finish A/B test**.
   - **La page A/B Tests** : Dans le menu de la ligne du test, sélectionnez **Finish**. La propre page d'un test en cours dispose également de **Finish**.

2. Dans la boîte de dialogue **Finish A/B test**, dans **Winner**, sélectionnez la campagne que le flow envoie après le test. Le flow conserve sa place dans l'ordre.
3. Cliquez sur **Finish**.

<ZoomImage id="mail-ab-testing-finish.webp" width="400px" alt="La boîte de dialogue Finish A/B test avec une campagne sélectionnée dans la liste déroulante Winner" />

:::note
Les utilisateurs déjà en cours de séquence dans une variante — gagnante ou perdante — continuent de recevoir leurs e-mails programmés. Ils ne sont pas basculés vers la variante gagnante.
:::

## Cycle de vie \{#lifecycle\}

Un test A/B passe par quatre états :

- **Brouillon** : Créé, mais pas encore lancé.
- **En cours** : Lancé sur un flow et en train de router les nouveaux utilisateurs.
- **Terminé** : Arrêté depuis la boîte de dialogue **Finish A/B test**, ou en supprimant son flow.
- **Archivé** : Supprimé via **Delete** dans le menu de la ligne d'un test en brouillon ou terminé. Un test en cours ne peut pas être supprimé. Terminez-le d'abord.
