Pour activer les achats intégrés, vous devez comprendre trois concepts clés :

- [**Produits**](product) – tout ce que les utilisateurs peuvent acheter (abonnements, consommables, accès à vie)
- [**Flows & paywalls**](adapty-flow-builder) – les écrans qui présentent les produits aux utilisateurs, créés dans le Flow & Paywall Builder sans code. Le SDK les récupère via `getFlow`. Si vous préférez construire l'interface dans votre propre code, consultez [Implémenter des paywalls personnalisés](android-quickstart-manual).
- [**Placements**](placements) – où et quand vous affichez les flows & paywalls dans votre app (par exemple `main`, `onboarding`, `settings`). Vous les associez à des placements dans le tableau de bord, puis vous les demandez par ID de placement dans votre code. Cela facilite les tests A/B et l'affichage de différents contenus selon les utilisateurs.

Adapty vous propose trois façons d'activer les achats dans votre application. Sélectionnez-en une selon les besoins de votre application :

| Implémentation | Complexité | Quand l'utiliser |
|---|---|---|
| Adapty Flow & Paywall Builder | ✅ Facile | Vous [créez un flow complet prêt à l'achat ou un paywall dans le builder no-code](quickstart-paywalls). Adapty le rend automatiquement et gère toute la logique d'achat complexe, la validation des reçus et la gestion des abonnements en coulisses. |
| Paywalls personnalisés | 🟡 Moyen | Vous implémentez l'interface de votre paywall dans le code de votre application, mais récupérez quand même l'objet flow depuis Adapty pour conserver de la flexibilité dans vos offres de produits. Consultez le [guide](android-quickstart-manual). |
| Mode observateur | 🔴 Difficile | Vous disposez déjà de votre propre infrastructure de gestion des achats et souhaitez continuer à l'utiliser. Notez que le mode observateur a ses limites dans Adapty. Consultez l'[article](observer-vs-full-mode). |

:::important
**Les étapes ci-dessous montrent comment intégrer un flow ou un paywall créé dans l'Adapty Flow & Paywall Builder.**

Si vous préférez construire l'interface du paywall vous-même, consultez [Implémenter des paywalls personnalisés](android-quickstart-manual).
:::

Pour afficher un flow ou un paywall créé dans l'Adapty Flow & Paywall Builder, vous n'avez besoin que de :

1. **Obtenez le flow ou le paywall** : Récupérez-le depuis Adapty.
2. **Affichez-le et Adapty gère les achats pour vous** : Intégrez la vue dans votre application.
3. **Gérez les actions des boutons** : Associez les interactions utilisateur aux réponses de votre application. Par exemple, ouvrez des liens ou fermez le paywall lorsque les utilisateurs cliquent sur des boutons.

## Avant de commencer \{#before-you-start\}

Avant de commencer, effectuez les étapes suivantes :

1. [Connectez votre application à Google Play](initial-android) dans l'Adapty Dashboard.
2. [Créez vos produits](create-product) dans Adapty.
3. [Créez un flow ou un paywall](paywall-builder-templates) et [ajoutez-y des produits](paywall-product-block).
4. [Créez un placement et ajoutez-y votre flow ou paywall](create-placement).
5. [Installez et activez le SDK Adapty](sdk-installation-android) dans le code de votre application. Ce guide utilise les API du SDK Adapty Android v4.

:::tip
La manière la plus rapide d'effectuer ces étapes est de suivre le [guide de démarrage rapide](quickstart) ou de créer des flows et des placements à l'aide du [CLI développeur](developer-cli-quickstart).
:::

## 1. Récupérer le flow ou le paywall \{#1-get-the-flow-or-paywall\}

Vos flows et paywalls sont associés à des placements configurés dans le tableau de bord. Les placements vous permettent d'afficher différents flows ou paywalls selon les audiences ou de lancer des [tests A/B](ab-tests).

Pour récupérer un flow ou un paywall créé dans l'Adapty Flow & Paywall Builder, vous devez :

1. Récupérer l'objet `flow` par l'ID du [placement](placements) en utilisant la méthode `getFlow` et vérifier s'il possède une configuration de vue.

2. Obtenez la configuration de vue à l'aide de la méthode `getFlowConfiguration`. La configuration de vue contient les éléments d'interface et le style nécessaires à son affichage.

:::important
Pour obtenir la configuration de vue, [publiez le flow ou le paywall](builder-save-publish). Un flow ou un paywall avec des modifications non publiées a le statut **Dirty**, et son placement continue de servir la dernière version publiée.
:::

<Tabs groupId="current-os" queryString>

<TabItem value="kotlin" label="Kotlin" default>

```kotlin showLineNumbers
Adapty.getFlow("YOUR_PLACEMENT_ID") { result ->
    if (result is AdaptyResult.Success) {
        val flow = result.value
        
        if (!flow.hasViewConfiguration) {
            return@getFlow
        }
        
        AdaptyUI.getFlowConfiguration(flow) { configResult ->
            if (configResult is AdaptyResult.Success) {
                val flowConfiguration = configResult.value
            }
        }
    }
}
```
</TabItem>

                    ((AdaptyResult.Success<AdaptyUI.FlowConfiguration>) configResult).getValue();
                // use loaded configuration
            }
        });
    }
});

## 2. Afficher le flow ou le paywall \{#2-display-the-flow-or-paywall\}

## 3. Gérer les actions des boutons \{#handle-button-actions\}

Lorsque les utilisateurs cliquent sur des boutons dans le flow ou le paywall, le SDK Android gère automatiquement les achats, la restauration, la fermeture de l'écran et l'ouverture des liens.

Cependant, d'autres boutons ont des identifiants personnalisés ou prédéfinis et nécessitent une gestion des actions dans votre code. Vous pouvez également souhaiter remplacer leur comportement par défaut.

Par exemple, voici le comportement par défaut du bouton de fermeture. Vous n'avez pas besoin de l'ajouter dans le code, mais vous pouvez voir ici comment procéder si nécessaire.

:::tip
Consultez nos guides sur la gestion des [actions](android-handle-paywall-actions) et des [événements](android-handling-events) liés aux boutons.
:::

<Tabs groupId="current-os" queryString>

<TabItem value="kotlin" label="Kotlin" default>

```kotlin showLineNumbers title="Kotlin"
override fun onActionPerformed(action: AdaptyUI.Action, context: Context) {
    when (action) {
        AdaptyUI.Action.Close -> (context as? Activity)?.onBackPressed() // default behavior
    }
}
```
</TabItem>
<TabItem value="java" label="Java" default>

```java showLineNumbers
@Override
public void onActionPerformed(@NonNull AdaptyUI.Action action, @NonNull Context context) {
    if (action instanceof AdaptyUI.Action.Close) {
        if (context instanceof Activity) {
            ((Activity) context).onBackPressed();
        }
    }
}
```
</TabItem>

## Exemple complet \{#full-example\}

Voici comment intégrer toutes ces étapes dans votre application.

<Tabs groupId="current-os" queryString>

<TabItem value="kotlin" label="Kotlin" default>

```kotlin showLineNumbers title="Kotlin"
class MainActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)

        Adapty.getFlow("YOUR_PLACEMENT_ID") { flowResult ->
            if (flowResult is AdaptyResult.Success) {
                val flow = flowResult.value

                if (!flow.hasViewConfiguration) {
                    // Use custom logic
                    return@getFlow
                }

                AdaptyUI.getFlowConfiguration(flow) { configResult ->
                    if (configResult is AdaptyResult.Success) {
                        val flowConfiguration = configResult.value

                        val flowView = AdaptyUI.getFlowView(
                            this,
                            flowConfiguration,
                            null, // products = null means auto-fetch
                            object : AdaptyFlowDefaultEventListener() {
                                override fun onActionPerformed(action: AdaptyUI.Action, context: Context) {
                                    when (action) {
                                        is AdaptyUI.Action.Close -> {
                                            (context as? Activity)?.onBackPressed()
                                        }
                                    }
                                }
                            }
                        )

                        setContentView(flowView)
                    }
                }
            }
        }
    }
}

```
