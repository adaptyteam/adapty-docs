Si vous **développez votre première application iOS**, vous devez configurer votre compte Apple Developer et App Store Connect avant d'intégrer Adapty.

:::note
Si vous avez déjà un compte Apple Developer et une application enregistrée dans App Store Connect, vous pouvez ignorer ce guide et passer directement à [Intégration initiale avec l'App Store](initial_ios).
:::

## Étape 1. S'inscrire au programme Apple Developer \{#step-1-enroll-in-apple-developer-program\}

Pour distribuer des apps sur l'App Store et vendre des achats intégrés, vous devez rejoindre le [programme Apple Developer](https://developer.apple.com/programs/).

### Choisissez votre type d'inscription \{#choose-enrollment-type\}

Apple propose deux types d'inscription :

|                                      | Individuel          | Organisation                        |
|--------------------------------------|---------------------|-------------------------------------|
| **Pour qui**                         | Développeurs solo   | Entreprises, équipes, associations  |
| **Numéro D-U-N-S requis**            | Non                 | Oui                                 |
| **Applications publiées sous**       | Votre nom personnel | Le nom de votre organisation        |
| **Gestion des membres de l'équipe**  | Non disponible      | Disponible                          |

:::tip
Si vous vous inscrivez en tant qu'organisation, vous avez besoin d'un **numéro D-U-N-S** — un identifiant d'entreprise unique à neuf chiffres fourni par Dun & Bradstreet. Vous pouvez [vérifier si votre organisation en possède déjà un](https://developer.apple.com/enroll/duns-lookup/) ou en demander un nouveau — le lien se trouve en bas de la page de recherche. L'obtention d'un numéro D-U-N-S peut prendre jusqu'à 5 jours ouvrables.
:::

### S'inscrire \{#enroll\}

1. Rendez-vous sur la [page d'inscription au programme Apple Developer](https://developer.apple.com/programs/enroll/).
2. Connectez-vous avec votre identifiant Apple. Si vous n'en avez pas, créez-en un d'abord.
3. Suivez les étapes correspondant à votre type d'inscription (particulier ou organisation).
4. Payez les frais annuels.

Une fois qu'Apple a traité votre inscription, vous accédez à [App Store Connect](https://appstoreconnect.apple.com). L'inscription prend généralement jusqu'à 48 heures. Pour les organisations, cela peut prendre plus longtemps si une vérification D-U-N-S est requise.

## Étape 2. Configurer votre app dans App Store Connect \{#step-2-set-up-your-app-in-app-store-connect\}

Avant de pouvoir vendre des achats intégrés, effectuez la configuration initiale dans App Store Connect. Cela inclut la signature des contrats, l'ajout des informations de paiement et l'enregistrement de votre app.

### Signez le contrat pour les applications payantes \{#sign-the-paid-applications-agreement\}

Apple exige que vous signiez le contrat pour les applications payantes (Paid Applications Agreement) avant de pouvoir vendre sur l'App Store. Cela s'applique aussi bien aux applications payantes qu'aux achats intégrés dans les applications gratuites.

1. Accédez à la page **Business** dans [App Store Connect](https://appstoreconnect.apple.com/business).
2. Trouvez l'accord **Paid Apps** et cliquez sur **Review and Agree**.
3. Complétez les informations requises :
   - **Banking information** : Ajoutez un compte bancaire sur lequel Apple enverra vos revenus.
   - **Tax information** : Remplissez les formulaires fiscaux pour les pays où vous souhaitez vendre.
   - **Contact information** : Fournissez vos coordonnées.

:::important
Vous devez compléter les trois sections (bancaire, fiscale, coordonnées) pour que le contrat devienne actif. Tant que le contrat n'est pas actif, vous ne pouvez pas vendre d'achats intégrés.
:::

### Créer un Bundle ID \{#create-a-bundle-id\}

Un Bundle ID identifie votre application de manière unique dans l'écosystème Apple. Vous en avez besoin pour enregistrer votre application dans App Store Connect et pour configurer l'intégration Adapty.

1. Ouvrez le [portail développeur Apple](https://developer.apple.com/account).
2. Allez dans **Certificates, Identifiers & Profiles** → **Identifiers**.
3. Cliquez sur **+** pour enregistrer un nouvel identifiant.
4. Sélectionnez **App IDs** et cliquez sur **Continue**.
5. Sélectionnez **App** comme type et cliquez sur **Continue**.
6. Remplissez les champs :
   - **Description** : un nom pour identifier cet Bundle ID (par exemple, « My Subscription App »).
   - **Bundle ID** : choisissez **Explicit** et entrez un identifiant unique au format domaine inversé (par exemple, `com.yourcompany.yourapp`).
7. Dans la section **Capabilities**, faites défiler vers le bas et cochez **In-App Purchase**.
8. Cliquez sur **Continue**, puis sur **Register**.

### Enregistrez votre application dans App Store Connect

1. Accédez à la page **Apps** dans [App Store Connect](https://appstoreconnect.apple.com/apps).
2. Cliquez sur **+** → **New App**.
3. Remplissez les champs obligatoires :
   - **Platforms** : Sélectionnez **iOS**.
   - **Name** : Le nom de votre application tel qu'il apparaîtra sur l'App Store.
   - **Primary language** : La langue par défaut pour les métadonnées de votre application.
   - **Bundle ID** : Sélectionnez le Bundle ID créé à l'étape précédente.
   - **SKU** : Un identifiant unique pour votre application (non visible par les utilisateurs). Par exemple, `my_subscription_app_2025`.
4. Cliquez sur **Create**.

Votre application est maintenant enregistrée dans App Store Connect et prête pour l'intégration Adapty.
