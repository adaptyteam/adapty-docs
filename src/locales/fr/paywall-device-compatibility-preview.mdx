Vous avez deux façons de prévisualiser votre flow sur différents types d'écrans :
- **Prévisualisation sur des appareils** : Vérifiez l'apparence de votre flow sur de vrais appareils à n'importe quelle étape du développement.
- **Prévisualisation dans l'Adapty Dashboard** : Prévisualisez votre flow pendant sa conception.

## Prévisualisation sur des appareils \{#preview-on-devices\}

Pour prévisualiser votre flow sur un vrai appareil :

1. [Téléchargez l'application Adapty depuis l'App Store](https://apps.apple.com/us/app/adapty/id6739359219).
2. Dans le flow builder, cliquez sur **Test on device**.

<ZoomImage id="flow-test-on-device.webp" width="700px" alt="Bouton Test on device dans le flow builder" />

3. Sélectionnez la locale du flow.
4. Scannez le QR code avec l'appareil photo ou ouvrez le lien. Votre flow s'ouvre dans l'application mobile Adapty.

:::note
En mode test, Adapty ne peut pas accéder à vos produits dans les stores, donc les prix affichés dans le flow ne sont pas réels.
:::

<ZoomImage id="flow-test-on-device-qr.webp" width="400px" alt="Sélecteur de locale et QR code dans la boîte de dialogue Test on device" />

## Prévisualisation dans l'Adapty Dashboard \{#preview-in-the-adapty-dashboard\}

:::tip
Pour vous assurer que votre flow est prêt à être publié, [prévisualisez-le sur un vrai appareil](#preview-on-devices) et confirmez qu'il s'affiche sans erreurs.
:::

Vous pouvez prévisualiser votre flow sur différents types d'écrans grâce à la zone de prévisualisation du flow builder. Cela vous permet de vous assurer que votre flow s'affiche parfaitement sur différents appareils et tailles d'écran.

Les contrôles de prévisualisation situés sous la zone de prévisualisation vous permettent de :
- Sélectionner l'appareil sur lequel prévisualiser votre flow.
- Basculer entre les modes de prévisualisation horizontal et vertical.
- Basculer entre les modes clair et sombre.
- Basculer entre les locales.

:::tip
- Prévisualisez toujours les différentes locales, car les langues peuvent avoir des longueurs de mots différentes et la mise en page de l'écran peut varier en conséquence.
- Pour prévisualiser des variables personnalisées, définissez des valeurs initiales pour celles-ci. Par exemple, si vous ajoutez une variable `name`, vous pouvez définir la valeur initiale à `Jane Doe` pour la prévisualiser.
:::
