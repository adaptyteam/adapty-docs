Vous disposez de deux façons de prévisualiser votre flow sur différents types d'écrans :
- **Prévisualisation sur les appareils** : vérifiez l'apparence de votre flow sur de vrais appareils à n'importe quelle étape du développement.
- **Prévisualisation dans l'Adapty Dashboard** : prévisualisez votre flow pendant sa conception.

## Aperçu sur les appareils \{#preview-on-devices\}

Pour prévisualiser votre flow sur un vrai appareil :

1. Téléchargez l'application mobile Adapty pour [iOS](https://apps.apple.com/us/app/adapty/id6739359219) ou [Android](https://play.google.com/store/apps/details?id=io.adapty.dashboard).
2. Dans le flow builder, cliquez sur **Test on device**.

<ZoomImage id="flow-test-on-device.webp" width="700px" alt="Bouton Test on device dans le flow builder" />

3. Sélectionnez la langue du flow.
4. Scannez le QR code avec l'appareil photo ou ouvrez le lien. Votre flow s'ouvrira dans l'application mobile Adapty.

:::note
En mode test, Adapty ne peut pas accéder à vos produits dans les stores, donc les prix affichés dans le flow ne sont pas réels.
:::

<ZoomImage id="flow-test-on-device-qr.webp" width="400px" alt="Sélecteur de langue et code QR dans la boîte de dialogue Tester sur l'appareil" />

### Dépannage \{#troubleshooting\}

Si le flow ne s'ouvre pas dans l'aperçu, la cause habituelle est une action incomplète, un écran vide ou un produit non associé. Consultez [Problèmes courants](flow-common-issues#a-flow-wont-preview-or-publish) pour la liste complète.

## Aperçu dans l'Adapty Dashboard \{#preview-in-the-adapty-dashboard\}

:::tip
Pour vous assurer que votre flow est prêt à publier, [prévisualisez-le sur un vrai appareil](#preview-on-devices) et vérifiez qu'il s'affiche sans erreurs.
:::

Vous pouvez prévisualiser votre flow sur différents types d'écrans depuis la zone d'aperçu dans le flow builder. Cela vous permet de vous assurer que votre flow s'affiche correctement sur tous les appareils et toutes les tailles d'écran.

Grâce aux contrôles d'aperçu situés sous la prévisualisation, vous pouvez :
- Sélectionner l'appareil sur lequel prévisualiser votre flow.
- Basculer entre les modes d'aperçu horizontal et vertical.
- Basculer entre les modes clair et sombre.
- Changer de locale.

:::tip
- Prévisualisez toujours différentes locales, car les langues peuvent avoir des longueurs de mots différentes et la mise en page peut s'en trouver modifiée.
- Pour prévisualiser les variables personnalisées, définissez des valeurs initiales. Par exemple, si vous ajoutez une variable `name`, vous pouvez lui attribuer la valeur initiale `Jane Doe` pour la prévisualiser.
:::

### Aperçu des produits et offres \{#preview-products-and-offers\}

L'aperçu lit les [variables de produit](onboarding-variables#product-variables) depuis votre catalogue Adapty, ce qui ne couvre qu'une partie de ce qu'un appareil peut résoudre :

- `prod_title` affiche le titre du produit tel qu'il est stocké dans Adapty. `prod_price` et les variables `prod_price_per_*` affichent le prix stocké dans Adapty, en dollars américains — les utilisateurs voient à la place le prix localisé du store.
- `offer_price`, `offer_billing_period` et `offer_full_duration` restent non résolues, donc l'aperçu affiche le nom de la variable entre accolades — par exemple, `{{products.selectedProduct.offer_price}}`. Ces valeurs parviennent au flow lorsque le SDK l'affiche dans votre application.
- `is_free_trial`, `is_pay_up_front` et `is_pay_as_you_go` suivent l'offre sélectionnée sur la fiche produit. Sans offre, les trois valent `false`. Avec une offre, l'aperçu la traite comme un paiement à l'utilisation.

Les conditions portant sur le type d'offre basculent donc dans l'aperçu, mais seule la branche « pay-as-you-go » s'affiche par défaut. Pour voir les autres branches, simulez le mode de paiement :

1. Sur le canvas, sélectionnez la carte produit qui contient l'offre.
2. Dans le panneau de droite, sous **Product**, ouvrez le menu déroulant de l'offre.
3. Sous **Preview as**, sélectionnez **Free trial**, **Pay up front** ou **Pay as you go**.

Chaque condition portant sur ces trois variables est restituée dans le mode sélectionné pour cette carte. **Preview as** s'applique à une carte produit à la fois, ne modifie rien dans le flow que vous publiez, et se réinitialise lorsque vous changez l'offre de la carte.
