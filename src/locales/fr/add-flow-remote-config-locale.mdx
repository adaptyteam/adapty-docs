Un Remote Config de flow peut contenir un payload JSON distinct pour chaque locale. À l'exécution, le SDK retourne le payload correspondant à la locale de l'utilisateur, ce qui vous permet de servir des textes traduits, des images différentes ou d'autres valeurs spécifiques à la locale sans publier une nouvelle version de l'application.

## Ajouter une locale \{#add-a-locale\}

Pour ajouter une locale à un Remote Config de flow :

1. Ouvrez le flow dans le Flow & Paywall Builder.
2. Cliquez sur l'icône Remote Config au-dessus de l'aperçu de l'écran.
3. Cliquez sur **Add locale** au-dessus de l'éditeur.
4. Remplissez le formulaire :
   - **Code** : Le code de locale, par exemple `en`, `fr` ou `de`.
   - **Name** : Le nom d'affichage, par exemple English ou French.

   Adapty ajoute une nouvelle colonne à l'éditeur JSON pour la locale.

## Modifier les valeurs par langue \{#edit-values-per-locale\}

Chaque colonne de langue accepte ses propres données au format JSON. Utilisez les mêmes clés dans toutes les colonnes et traduisez les valeurs pour chaque langue.

Par exemple, la colonne anglaise :

```json showLineNumbers
{
    "title": "Try for free!",
    "cta": "Continue",
    "trial_days": 7
}
```

Et la colonne espagnole :

```json showLineNumbers
{
    "title": "¡Prueba gratis!",
    "cta": "Continuar",
    "trial_days": 7
}
```

Les colonnes sont indépendantes — modifier l'une n'affecte pas les autres.

## Lire la locale correspondante dans votre application \{#read-the-matching-locale-in-your-app\}

Le SDK expose une entrée `AdaptyRemoteConfig` par locale dans `AdaptyFlow.remoteConfigs`. Sélectionnez l'entrée dont la `locale` correspond à votre utilisateur, puis lisez son `dictionary` ou son `jsonString` pour utiliser les valeurs au moment de l'exécution.

## Sauvegarder ou déplacer des locales \{#back-up-or-move-locales\}

Utilisez le menu **Import/Export** situé au-dessus de l'éditeur pour sauvegarder votre Remote Config ou le copier entre différents flows. Le fichier JSON exporté contient les données de chaque locale en une seule fois. Consultez [Personnaliser un flow avec le Remote Config](customize-flow-with-remote-config) pour le format du fichier.
