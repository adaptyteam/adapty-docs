Ce guide vous aide à résoudre les problèmes courants lors de l'utilisation de paywalls conçus dans l'Adapty Paywall Builder dans le SDK iOS. Pour les problèmes liés aux flows, consultez [Problèmes courants](flow-common-issues).

## La récupération d'une configuration de paywall échoue \{#getting-a-paywall-configuration-fails\}

**Problème** : La méthode `getPaywallConfiguration` ne parvient pas à récupérer la configuration du paywall.

**Cause** : Le paywall n'est pas activé pour l'affichage sur l'appareil dans le Paywall Builder.

**Solution** : Activez le bouton **Show on device** dans le Paywall Builder.

## Le nombre de vues du paywall est trop élevé \{#the-paywall-view-number-is-too-big\}

**Problème** : Le nombre de vues du paywall affiche le double du chiffre attendu.

**Raison** : Vous appelez peut-être `logShowFlow` (iOS SDK v4+) / `logShowPaywall` dans votre code, ce qui duplique le comptage des vues pour un paywall créé dans l'ancien Paywall Builder. Adapty suit ces vues automatiquement, donc cette méthode n'est pas nécessaire.

**Solution** : Vérifiez que vous n'appelez pas `logShowFlow` (iOS SDK v4+) / `logShowPaywall` dans votre code pour un paywall créé dans l'ancien Paywall Builder.

## Autres problèmes \{#other-issues\}

**Problème** : Vous rencontrez d'autres problèmes liés au Paywall Builder qui ne sont pas abordés ci-dessus.

**Solution** : Migrez le SDK vers la dernière version à l'aide des [guides de migration](ios-sdk-migration-guides) si nécessaire. De nombreux problèmes sont résolus dans les versions plus récentes du SDK.
