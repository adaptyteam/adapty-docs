[Retention Messaging](https://developer.apple.com/documentation/retentionmessaging) est une fonctionnalité Apple qui affiche un message personnalisé aux abonnés sur l'écran iOS **Cancel Subscription**, juste avant qu'ils confirment leur annulation. Utilisez-la pour réduire le churn en leur donnant une raison — ou une offre — de rester.

Adapty se connecte à l'API Retention Messaging d'Apple, afin qu'Apple demande le bon message en temps réel dès qu'un abonné appuie sur **Cancel Subscription**. Adapty gère cet endpoint pour vous : vous rédigez, localisez et testez vos messages dans l'Adapty Dashboard, et Adapty répond automatiquement à Apple. Aucun backend à construire, aucune mise à jour de l'app nécessaire.

Il existe deux types de messages. Un message *par défaut* est un texte simple qui sert de solution de repli lorsqu'un message promo ne peut pas être affiché. Un message *promo* ajoute une incitation concrète : une remise, un essai gratuit ou un passage à un plan mieux adapté. Apple affiche à chaque abonné le message qui correspond à son produit et à sa langue.

## Démarrage rapide \{#quickstart\}

Avant de commencer, vous aurez besoin de :

- Une [clé API App Store Connect](app-store-connection-configuration) dans Adapty.
- [L'approbation d'Apple pour votre application](retention-messaging-setup#request-access-from-apple). L'examen par Apple peut prendre jusqu'à un mois, alors soumettez la demande tôt.
- Au moins un [produit](create-product) que vos messages doivent couvrir.

Ensuite :

1. [Connectez Adapty à l'API Retention Messaging en mode sandbox](retention-messaging-setup).
2. Achetez votre produit à la durée la plus longue avec un compte sandbox ou via TestFlight, et maintenez l'abonnement actif.
3. [Passez le test de performance d'Apple](retention-messaging-setup#pass-the-performance-test). Cela peut prendre jusqu'à une heure.
4. Passez en mode production.
5. [Créez vos messages de production](retention-messaging-create) — d'abord les messages par défaut, puis les messages promo — et soumettez chacun à l'examen d'Apple.
6. [Suivez les performances de chaque message](retention-messaging-analytics) une fois qu'Apple l'a approuvé.

## Messages de rétention dans App Store Connect \{#app-store-connect-retention-messages\}

Vous pouvez également [créer des messages de rétention dans App Store Connect](https://developer.apple.com/help/app-store-connect/manage-subscriptions/configure-retention-messages/), sans l'API Retention Messaging. Ces deux options diffèrent :

| | App Store Connect | Adapty |
| --- | --- | --- |
| **Accès** | Ouvert à tous les développeurs. | Nécessite [l'approbation d'Apple pour votre app](retention-messaging-setup#request-access-from-apple). |
| **Choix du message** | Un seul message actif par abonnement. | Pour chaque annulation, Adapty renvoie un message correspondant au produit et à la langue de l'abonné. |
| **Analytics dans Adapty** | Aucun. | [Analytics par message](retention-messaging-analytics). |

Vous pouvez utiliser les deux en même temps. Lorsqu'un abonné appuie sur **Cancel Subscription**, Apple interroge d'abord Adapty. Adapty renvoie un message promotionnel actif pour le produit s'il en existe un, sinon un message Default actif. Si Adapty ne renvoie aucun message ou ne répond pas à temps, Apple affiche à la place votre message App Store Connect. Un message App Store Connect constitue donc un utile fallback pendant que vous attendez l'approbation d'Apple, ou pour les produits qui n'ont aucun message actif dans Adapty.

Les messages que vous créez dans App Store Connect n'apparaissent pas sur la page **Retention Messaging** d'Adapty, et les analyses qui s'y trouvent comptabilisent uniquement les messages qu'Adapty renvoie à Apple. Lorsqu'un abonné accepte une offre provenant d'un message App Store Connect, il reste sur le même abonnement, vous n'avez donc pas besoin d'ajouter un nouveau produit dans Adapty.
