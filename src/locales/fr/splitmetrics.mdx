Grâce à l'intégration [SplitMetrics Acquire](https://splitmetrics.com/acquire/), vous pouvez voir exactement combien rapportent vos Apple Search Ads en termes d'abonnements. Et vous pouvez suivre vos utilisateurs pendant des mois pour connaître le retour sur investissement de vos publicités dans le temps.

De plus, Adapty envoie des [événements d'abonnement](events) à SplitMetrics Acquire afin que vous puissiez y créer des tableaux de bord personnalisés et des automatisations basés sur l'attribution Apple Search Ads.
Cela n'ajoute aucune donnée d'attribution dans Adapty, car nous disposons déjà de tout ce dont nous avons besoin directement depuis ASA.

Nous recommandons d'utiliser les noms d'événements par défaut fournis par Adapty. Vous pouvez toutefois les modifier selon vos besoins. Adapty enverra les événements d'abonnement à SplitMetrics Acquire via une intégration serveur à serveur, vous permettant de consulter tous les événements d'abonnement dans votre tableau de bord SplitMetrics.

## Configuration du SDK \{#sdk-configuration\}

Vous n'avez rien à configurer côté SDK, mais nous recommandons d'envoyer le `customerUserId` à Adapty pour une meilleure précision.

:::warning
Assurez-vous d'avoir configuré [Apple Search Ads](apple-search-ads) dans Adapty et d'avoir [importé vos identifiants](https://app.adapty.io/settings/apple-search-ads) — sans cela, SplitMetrics Acquire ne fonctionnera pas.
:::

## Résolution des problèmes \{#troubleshooting\}

### Les événements n'arrivent pas à SplitMetrics Acquire \{#events-dont-reach-splitmetrics-acquire\}

Si l'intégration avec SplitMetrics Acquire ne fonctionne pas malgré une configuration correcte :

- Assurez-vous d'avoir activé le bouton **Receive Apple Search Ads attribution in Adapty** dans [App Settings -> Apple Search Ads tab](https://app.adapty.io/settings/apple-search-ads), d'avoir configuré [Apple Search Ads](apple-search-ads) dans Adapty, et d'avoir [importé vos identifiants](https://app.adapty.io/settings/apple-search-ads) — sans cela, SplitMetrics ne fonctionnera pas.
- Assurez-vous que les profils disposent d'une attribution ASA non organique. Seuls les profils avec une attribution ASA détaillée et non organique transmettront leurs événements à Adapty.

## Structure des événements SplitMetrics Acquire \{#splitmetrics-acquire-event-structure\}

Adapty envoie les événements à SplitMetrics Acquire via une requête GET avec des paramètres de requête. Chaque événement est structuré comme suit :

```json
{
  "source": "Apple Search Ads",
  "app_id": "123456789",
  "name": "subscription_renewed",
  "type": "subscription_renewed",
  "revenue": 9.99,
  "currency": "USD",
  "tap_time": "2024-03-01 12:00:00",
  "open_time": "2024-03-01 12:05:00",
  "event_time": "2024-03-02 12:00:00",
  "adaccount_id": "123456",
  "campaign_id": "123456789",
  "adgroup_id": "123456789",
  "keyword_id": "123456789",
  "creative_set_id": "123456789",
  "Ad_id": "123456789",
  "country_or_region": "US",
  "conversion_type": "Download",
  "user_id": "user_12345",
  "att_status": "3",
  "device_type": "iphone",
  "app_version": "1.2.3",
  "sdk_version": "2.10.0",
  "ios_version": "17.2",
  "event_value": "{\"vendor_product_id\":\"yearly.premium.6999\",\"original_transaction_id\":\"GPA.3383...\"}",
  "event_id": "123e4567-e89b-12d3-a456-426614174000"
}
```

Where:

| Paramètre           | Type   | Description                                                                                                             |
|:--------------------|:-------|:------------------------------------------------------------------------------------------------------------------------|
| `source`            | String | Toujours "Apple Search Ads".                                                                                            |
| `app_id`            | String | Apple App ID.                                                                                                           |
| `name`              | String | Nom de l'événement (mappé depuis l'événement Adapty).                                                                   |
| `type`              | String | Type d'événement (identique à `name`).                                                                                  |
| `revenue`           | Float  | Montant des revenus.                                                                                                    |
| `currency`          | String | Code de la devise.                                                                                                      |
| `tap_time`          | String | Date et heure du clic sur l'annonce.                                                                                    |
| `open_time`         | String | Date et heure de l'ouverture de l'application (installation).                                                           |
| `event_time`        | String | Date et heure de l'événement.                                                                                           |
| `adaccount_id`      | String | ID d'organisation ASA.                                                                                                  |
| `campaign_id`       | String | ID de campagne ASA.                                                                                                     |
| `adgroup_id`        | String | ID de groupe d'annonces ASA.                                                                                            |
| `keyword_id`        | String | ID de mot-clé ASA.                                                                                                      |
| `creative_set_id`   | String | ID de jeu de créatifs ASA.                                                                                              |
| `Ad_id`             | String | ID d'annonce ASA.                                                                                                       |
| `country_or_region` | String | Pays ou région du store.                                                                                                 |
| `conversion_type`   | String | Type de conversion (ex. : "Download").                                                                                  |
| `user_id`           | String | Customer User ID ou Adapty Profile ID.                                                                                  |
| `att_status`        | String | Statut d'autorisation de suivi (0-3).                                                                                   |
| `device_type`       | String | Type d'appareil (ex. : "iphone", "ipad").                                                                               |
| `app_version`       | String | Version de l'application.                                                                                               |
| `sdk_version`       | String | Version du SDK Adapty.                                                                                                  |
| `ios_version`       | String | Version d'iOS.                                                                                                          |
| `event_value`       | String | Chaîne JSON contenant tous les [détails de l'événement](webhook-event-types-and-fields#for-most-event-types) disponibles. |
| `event_id`          | String | ID d'événement unique (UUID).                                                                                           |
