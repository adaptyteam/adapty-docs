Adapty peut échanger des informations avec des services tiers pour attribuer les événements d'abonnement à des campagnes marketing spécifiques. Cet échange vous permet de :

* Découvrir quelles stratégies marketing génèrent le plus de revenus
* Filtrer les [graphiques d'abonnement](charts) Adapty par attribution
* Utiliser les fonctionnalités d'un service tiers pour analyser les données d'abonnement Adapty

Vous pouvez le configurer de deux façons :

* [L'attribution intégrée](#integrated-attribution) nécessite une configuration minimale et permet à Adapty d'échanger des données avec 9 plateformes populaires.
* [L'attribution manuelle](#manual-attribution) vous oblige à récupérer vous-même les données d'attribution depuis les API de services tiers avant de les envoyer à Adapty.

:::tip
Activez [Adapty Attribution](user-acquisition) pour avoir une vue complète de l'économie de votre application.

Adapty Attribution est un tableau de bord web facile à configurer qui consolide les données de différentes sources pour identifier les stratégies d'acquisition d'utilisateurs les plus efficaces.
:::

:::warning
Gardez vos données propres : évitez la duplication d'événements et les conflits d'attribution. Suivez les conseils de la section **[Prévenir les problèmes de données](#prevent-data-issues)** pour vous assurer qu'une nouvelle source de données ne pollue pas vos analytics.
:::

## Attribution intégrée \{#integrated-attribution\}

Adapty propose une intégration d'attribution clé en main avec 9 services populaires. Ces plateformes peuvent recevoir automatiquement les [données d'abonnement](events) depuis Adapty, traiter chaque achat et renvoyer une attribution appropriée.

Chaque plateforme a son propre fonctionnement, mais les étapes restent simples :

1. **Configurez le partage automatique des données.** Autorisez Adapty à communiquer avec la plateforme de votre choix.
2. **Intégrez le SDK Adapty.** Certaines plateformes nécessitent du code supplémentaire pour transmettre les données d'attribution.
3. **Désactivez les autres services de partage d'événements et sources d'attribution** pour éviter la [duplication d'événements](#avoid-event-duplication) et les [conflits de données](#select-a-single-attribution-source).

Consultez le guide spécifique à votre plateforme pour une présentation détaillée de l'intégration :

- [Adjust](adjust)
- [Airbridge](airbridge)
- [Apple Search Ads](apple-search-ads)
- [AppsFlyer](appsflyer)
- [Asapty](asapty)
- [Branch](branch)
- [Facebook Ads](facebook-ads)
- [Singular](singular)
- [Tenjin](tenjin)

:::note
Si vous souhaitez qu'Adapty élargisse cette liste, [créez une demande de fonctionnalité](https://adapty.featurebase.app/en?b=6979f233ebd3cffd4f425ba0) et faites part de votre intérêt pour un service particulier.
:::

## Attribution manuelle \{#manual-attribution\}

Si Adapty ne propose pas d'[attribution intégrée](#integrated-attribution) avec votre service, vous devez écrire votre propre code pour échanger des données avec la source d'attribution.

1. **Récupérez les données depuis le service d'attribution**. Utilisez l'API du service pour demander les données d'attribution.
2. **Créez un dictionnaire avec les données d'attribution reçues.**

    Le dictionnaire peut contenir les clés suivantes :

    - `status` (`organic`, `non-organic`, ou `unknown`)
    - `channel`
    - `campaign`
    - `ad_group`
    - `ad_set`
    - `creative`

:::important
    * Toutes les clés sont optionnelles.
    * Adapty ignore les clés qui ne figurent pas dans la liste.
    * La valeur de chaque clé peut comporter jusqu'à 50 caractères.
    :::

    **Exemple** :

    ```swift showLineNumbers title="Swift"
    let attribution = [
        "status": "non_organic",
        "channel": "Google Ads",
        "campaign": "Christmas Sale",
        "ad_group": "ad group 1",
        "ad_set": "ad set 1",
        "creative": "creative id 1"
    ]
    ```

3. **Définir les données d'attribution** :

Transmettez le dictionnaire d'attribution à la méthode `updateExternalAttribution` (nommée `updateAttribution` avant la version 4.1 du SDK). Une fois qu'Adapty a enregistré la valeur d'attribution, vous ne pouvez plus la remplacer :

   ```swift showLineNumbers title="Swift"
   Adapty.updateExternalAttribution(attribution, provider: .custom) { error in
       if error == nil {
           // attribution data accepted for processing
       }
   }
   ```

:::info
`appliedExternalAttributionProviders` ne rapporte que l'attribution provenant d'Apple Ads. L'attribution des autres fournisseurs est visible sur les profils utilisateurs et disponible dans les filtres de segments, mais pas encore ici.
:::

**Paramètres :**

- `attribution` (obligatoire) : dictionnaire contenant les données d'attribution.
- `provider` (obligatoire ; nommé `source` avant la version 4.1 du SDK) : fournisseur d'attribution. Utilisez `.custom` (SDK 4.1 et versions ultérieures) si votre fournisseur d'attribution ne prend pas en charge l'[attribution intégrée](#integrated-attribution). Dans les versions antérieures, passez la chaîne `"custom"`.

4. **Désactivez les autres services de partage d'événements et les sources d'attribution** pour éviter la [duplication d'événements](#avoid-event-duplication) et les [conflits de données](#select-a-single-attribution-source).

## Prévenir les problèmes de données \{#prevent-data-issues\}

### Sélectionner une seule source d'attribution \{#select-a-single-attribution-source\}

N'activez pas l'intégration d'attribution avec plusieurs plateformes en même temps. Adapty ne peut accepter qu'une seule source d'attribution à la fois, et une fois qu'une valeur d'attribution est enregistrée, elle ne peut pas être écrasée.

Si vous activez plusieurs sources d'attribution, Adapty sélectionnera la source contenant le plus de données — pas nécessairement les meilleures.

Par exemple, l'[attribution Apple Search Ads](apple-search-ads) non organique sera toujours prioritaire sur iOS. Pour désactiver l'attribution Apple Search Ads, ouvrez l'onglet [**App Settings** -> **Apple Search Ads**](https://app.adapty.io/settings/apple-search-ads) et désactivez le commutateur **Receive Apple Search Ads attribution**.

### Éviter la duplication des événements \{#avoid-event-duplication\}

Si vous utilisez Adapty pour partager des données d'abonnement en temps réel avec vos services d'attribution, **vous devez désactiver** les autres services qui remplissent le même rôle. Si vous avez connecté votre compte Facebook à AppsFlyer, Adjust ou Branch, ceux-ci transmettront automatiquement vos événements à ces services, sauf si vous désactivez cette option.

Les événements dupliqués peuvent fausser vos analyses et rendre l'interprétation des données difficile. Une fois le partage d'événements Adapty configuré, désactivez **les fonctionnalités de transfert d'événements** des services tiers.
