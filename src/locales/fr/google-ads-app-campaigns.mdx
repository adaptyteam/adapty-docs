Utilisez ce guide pour la configuration Google Ads suivante :

- **Ce que vous annoncez** : Une application Android sur Google Play.
- **Type de campagne** : Campagnes App pour les installations (UAC). Elles diffusent vos annonces dans Google Search, Google Play, YouTube et d'autres applications et sites web. Chaque annonce renvoie vers la page Google Play de votre application.

Dans Adapty Attribution, les campagnes App pour les installations (UAC) ne fonctionnent que pour les applications Android. Pour faire la publicité d'une application iOS ou d'un funnel web, utilisez les [campagnes Search et Performance Max](google-ads-search-pmax-campaigns).

## Comment ça fonctionne \{#how-it-works\}

Lorsque vous connectez vos campagnes App à Adapty Attribution :

- Google reçoit les événements d'essai et d'achat provenant d'Adapty.
- Grâce aux informations d'Adapty, Google mise sur les personnes susceptibles de démarrer un essai ou de souscrire un abonnement, et pas seulement d'installer votre application.
- Adapty Attribution affiche le chiffre d'affaires et le ROAS de chaque campagne, groupe d'annonces et annonce, avec les dépenses qu'Adapty récupère depuis Google Ads.

Dans ce guide, vous créez un App Link ID dans Google Ads et l'ajoutez à l'attribution Adapty. Via ce lien, Adapty envoie chaque nouvelle installation à Google. Si l'utilisateur provient d'une publicité de campagne App, Google renvoie [la campagne, le groupe d'annonces et l'annonce](ua-google-ads#app-campaigns-android) à Adapty.

## Avant de commencer \{#before-you-begin\}

Assurez-vous que :

- Votre application est sur Google Play, publiée en production ou en test ouvert sans limite de testeurs.
- Le SDK Adapty de votre application a [l'attribution Adapty activée](user-acquisition#step-1-enable-adapty-attribution-in-the-sdk).
- Vous avez un compte Google Ads en [mode Expert](ua-google-ads#before-you-begin), pour pouvoir créer des campagnes App.
- Votre compte Google Ads dispose d'un moyen de paiement.
- Votre compte Google, par exemple vous@nomapp.com, a le [niveau d'accès **Admin**](ua-google-ads-settings#set-account-permissions) dans votre compte Google Ads. Ce niveau d'accès est nécessaire pour créer l'App Link ID.
- Votre compte Google est [connecté à l'attribution Adapty](ua-google-ads-settings#connect-your-google-account).

## Configurer l'App Link ID et la campagne

Via votre compte Google connecté, Adapty actualise les dépenses de vos campagnes toutes les 4 heures. Les campagnes applicatives nécessitent également un lien vers l'application elle-même, appelé App Link ID. Par ce lien, Adapty envoie à Google les installations, essais et achats de votre application. Vous n'avez pas besoin d'un nouveau lien pour chaque campagne.

Si vous gérez déjà des campagnes applicatives pour votre application, choisissez laquelle utiliser avec Adapty Attribution. Sinon, créez une nouvelle campagne afin de tirer pleinement parti des fonctionnalités d'Adapty Attribution.

| Campagne | Installations et revenus dans Adapty Attribution | Google optimise pour les essais ou les achats | Étapes à suivre |
|---|---|---|---|
| Une campagne existante | ✅ sans installations passées | ❌ | [Étapes 1–3](#create-the-configuration-in-adapty-attribution) |
| Une nouvelle campagne (recommandée) | ✅ | ✅ | Toutes les étapes de ce guide |

### 1. Créer la configuration dans Adapty Attribution \{#create-the-configuration-in-adapty-attribution\}

1. Basculez vers l'application que vous souhaitez promouvoir.
2. Accédez à **Integrations** > **Google Ads**. Dans l'onglet **App Campaigns**, cliquez sur **Create configuration**.

    <ZoomImage id="google-ads-create-ad-campaign.webp" width="700px" alt="Onglet App Campaigns de l'intégration Google Ads dans Adapty Attribution avec le bouton Create configuration" />

3. Copiez la valeur du **Provider ID**. Vous en aurez besoin pour créer l'App Link ID dans Google Ads.

### 2. Créer l'identifiant de lien d'application dans Google Ads \{#create-the-app-link-id-in-google-ads\}

1. Cliquez sur l'icône **Tools** et sélectionnez **Data manager**.
2. Cliquez sur **+ Connect Product**, sélectionnez **Third-party app analytics**, puis cliquez sur **Continue**.
3. Cliquez sur **Create link ID**.
4. Dans la liste des fournisseurs, sélectionnez **Other provider** et collez le **Provider ID** copié depuis Adapty Attribution.
5. Sélectionnez **Android** comme plateforme et recherchez votre application dans le champ **Look up your app**.
6. Cliquez sur **Create link ID** et copiez l'identifiant de lien généré.

:::note
Google Ads affiche l'ID de lien comme **Non vérifié** jusqu'à ce qu'il reçoive le premier événement d'Adapty.
:::

### 3. Ajouter l'ID du lien à Adapty Attribution \{#add-the-link-id-to-adapty-attribution\}

1. Retournez à la configuration que vous avez créée à l'[étape 1](#create-the-configuration-in-adapty-attribution). Collez l'ID du lien dans le champ **Android App Link ID**. Vous ne pouvez utiliser chaque ID de lien que dans une seule configuration.

    <ZoomImage id="app-link-id.webp" width="700px" alt="Champ Android App Link ID dans une configuration App campaigns, avec le Provider ID au-dessus" />

2. [Sélectionnez les événements qu'Adapty envoie à Google](ua-google-ads-settings#map-events). Pour signaler les revenus à Google pour les essais démarrés, configurez le [Revenue override](ua-google-ads-settings#revenue-override). Pour n'envoyer à Google que les essais que les utilisateurs conservent, configurez le [Qualified trial](ua-google-ads-settings#qualified-trial).
3. Cliquez sur **Save**.

### 4. Envoyer des événements de test \{#send-test-events\}

La première fois que Google Ads reçoit un événement, Google crée une action de conversion qui comptabilise cet événement. Pour que les actions de conversion soient prêtes avant de créer votre campagne, envoyez un événement de test pour chaque événement à optimiser :

1. Dans la configuration, cliquez sur **Send test event**.
2. Pour l'événement à optimiser, sélectionnez ou saisissez son nom d'événement Google, par exemple `in_app_purchase`. Cliquez ensuite sur **Send**. Adapty affiche le résultat dans une notification.
3. Si l'action de conversion pour l'événement n'apparaît pas dans Google Ads après un test réussi, importez l'événement en tant qu'action de conversion. Google décrit les étapes dans [Measure app conversions with third-party app analytics](https://support.google.com/google-ads/answer/7382633).

<ZoomImage id="google-ads-test-event.webp" width="700px" alt="Send test event dialog in an App campaigns configuration, with in_app_purchase as the event name" />

Pour que Google Ads accepte les premières installations de la campagne, publiez-la après qu'un événement test ait réussi. Un nouvel identifiant de lien met environ 24 heures à s'activer dans Google Ads, ce qui peut entraîner l'échec des événements test entre-temps. En cas d'échec, suivez [Échec de l'événement test pour un nouvel identifiant de lien](#test-event-fails-for-a-new-link-id).

### 5. Optimiser votre campagne pour les essais ou les achats \{#optimize-your-campaign-for-trials-or-purchases\}

Par défaut, Google comptabilise les événements provenant d'Adapty dans les rapports, mais ne les utilise pas pour optimiser les enchères. Pour modifier ce comportement pour l'événement à optimiser, éditez l'action de conversion correspondante :

1. Dans Google Ads, rendez-vous dans **Goals** > **Conversions** > **All conversions**.
2. Cliquez sur l'action de conversion à optimiser.
3. Sélectionnez l'onglet **Settings**.
4. Cliquez sur le paramètre **Action optimization**. Sélectionnez **Primary action used for bidding optimization**, puis cliquez sur **Save**.

### 6. Créer et publier une nouvelle campagne App \{#create-the-app-campaign\}

Créez une nouvelle campagne App, même si vous avez déjà des campagnes App actives pour votre application. Google déconseille de modifier l'événement à optimiser dans une campagne App en cours d'exécution.

1. Dans Google Ads, ouvrez le menu **Campaigns** et sélectionnez **Campaigns**. Cliquez sur le bouton plus et sélectionnez **New campaign**.
2. Sélectionnez **App promotion** comme objectif, et **App installs** comme sous-type de campagne.
3. Sélectionnez **Android** comme plateforme. Ensuite, trouvez votre application par son nom, son nom de package ou son éditeur.
4. Saisissez un nom de campagne et cliquez sur **Continue**. Sélectionnez ensuite les zones géographiques à cibler.
5. Sélectionnez les langues de vos annonces. Google ne les traduit pas.
6. Sur la page **Budget and bidding**, sélectionnez **In-app actions** dans le menu déroulant **What do you want to focus on?**.
7. Sous **Which actions are most important to you?**, sélectionnez l'action de conversion que vous avez modifiée à l'[étape 5](#optimize-your-campaign-for-trials-or-purchases). Google recommande une action par campagne.
8. Saisissez le coût cible par action. Si vous gérez déjà des campagnes, basez-vous sur le **Cost per trial** ou le **Cost per subscription** qu'[Adapty Attribution analytics](ua-analytics) affiche pour ces campagnes.
9. Définissez le budget quotidien à au moins 10 fois le coût cible par action, comme le recommande Google.
10. Ajoutez vos ressources publicitaires : quelques titres, descriptions, images et vidéos. Google assemble les annonces à partir de ces éléments.
11. Cliquez sur **Publish campaign**.

## Après la publication \{#after-you-publish\}

- **Attendez la vérification de l'annonce** : Google vérifie chaque annonce avant sa diffusion. Pendant la vérification, l'annonce a le statut **Under review**. La plupart des vérifications se terminent en un jour ouvrable. Une fois l'annonce validée, son statut passe à **Eligible** et la diffusion commence.
- **Évitez les modifications importantes pendant la phase d'apprentissage de Google** : L'algorithme d'enchères de Google a généralement besoin de 1 à 2 semaines pour apprendre quels clics génèrent les conversions qu'Adapty lui envoie. Si vous modifiez la campagne pendant cette période, vous risquez de perturber l'apprentissage. Ne changez pas l'événement à optimiser. N'ajustez le budget ou le coût cible par action que de 20 % maximum à la fois.
- **Consultez les installations, les revenus et le ROAS dans Adapty Attribution** : Ouvrez [l'analytics Adapty Attribution](ua-analytics). Adapty actualise les dépenses, les impressions et les clics depuis Google Ads toutes les 4 heures.

## Dépannage \{#troubleshooting\}

### L'événement de test échoue pour un nouvel identifiant de lien \{#test-event-fails-for-a-new-link-id\}

Un nouvel identifiant de lien met environ 24 heures à s'activer dans Google Ads. Pendant ce temps, Google Ads rejette les événements provenant d'Adapty, ce qui fait échouer l'événement de test même si la configuration est correcte.

Attendez 24 heures et renvoyez l'événement de test. Ne remplacez pas l'identifiant de lien entre-temps : un nouvel identifiant de lien nécessite encore 24 heures pour s'activer.

Si l'événement de test échoue toujours après 24 heures, vérifiez le champ **Android App Link ID** dans la configuration. Il doit contenir l'identifiant de lien issu de **Data manager**, et non un autre identifiant Google Ads.

Une fois qu'un événement de test a réussi pour chaque événement à optimiser, passez à [Optimiser votre campagne pour les essais ou les achats](#optimize-your-campaign-for-trials-or-purchases).

### Google Ads n'affiche aucune conversion provenant d'Adapty \{#google-ads-shows-no-conversions-from-adapty\}

Pour voir les conversions qu'Adapty envoie à Google, dans Google Ads, accédez à **Goals** > **Conversions** > **All conversions**. Si l'événement à optimiser n'affiche aucune conversion, vérifiez que :

- Un [événement de test a réussi](#send-test-events) pour cet événement.
- Google [optimise les enchères pour l'événement](#optimize-your-campaign-for-trials-or-purchases).
- Vous avez sélectionné l'action de conversion dans votre campagne App, sous **Which actions are most important to you?**.

### Les campagnes applicatives affichent moins d'installations en provenance de l'EEE et du Royaume-Uni \{#app-campaigns-show-fewer-installs-from-the-eea-and-the-uk\}

Pour protéger la vie privée des utilisateurs de l'Espace économique européen et du Royaume-Uni, Adapty marque les événements qu'il envoie à Google comme non consentis pour les annonces. Par conséquent, Google peut attribuer moins d'installations à vos campagnes applicatives. Votre configuration fonctionne comme prévu.
