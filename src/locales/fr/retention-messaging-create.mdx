Les messages de rétention vous permettent de toucher les abonnés sur le point de se désabonner pendant le processus d'annulation. Lorsqu'un client accède à l'écran iOS Annuler l'abonnement, Apple lui affiche le message correspondant à son produit et à sa langue.

Il existe deux types de messages de fidélisation :

- **Default** : Un message de fidélisation simple avec un titre, un corps de texte, une image optionnelle et jusqu'à cinq points. Utilisé comme solution de secours lorsqu'un message promo n'est pas disponible.
- **Promo** : Un message de fidélisation qui propose aux abonnés une offre spéciale ou un forfait différent. Vous ne pouvez créer des messages promo que pour les produits auxquels un message Default est déjà assigné.

## Avant de commencer \{#before-you-begin\}

- Créez au moins un [produit](create-product) que le message doit couvrir.
- [Testez la messagerie de rétention](retention-messaging-setup) en mode sandbox.

## Créer un message \{#create-a-message\}

Ouvrez la page Retention Messaging dans l'Adapty Dashboard. Cliquez sur **Create Default** pour un message par défaut, ou sur **Create Message** pour un message promo.

<ZoomImage id="retention-select-default-or-promo.webp" width="700px" alt="The Create Default and Create Message buttons in the Retention Messaging page header" />

Sélectionnez l'environnement — un message sandbox pour les tests, ou un message de production pour les vrais utilisateurs. L'option de production reste désactivée tant que vous n'avez pas [configuré l'URL de production](retention-messaging-setup#switch-to-production) et réussi le test de performance en sandbox.

<ZoomImage id="retention-new-message.webp" width="700px" alt="Écran de démarrage d'un nouveau message avec les options Créer un message sandbox et Créer un message de production" />

### Général \{#general\}

Nommez le message et ajoutez les produits dont l'annulation déclenchera le message.

La liste des produits grise les produits que vous ne pouvez pas ajouter, avec la raison indiquée à côté de chacun : **used** signifie qu'un autre message du même type couvre déjà ce produit, et **no default message** signifie que le produit a besoin d'un message par défaut avant de pouvoir en recevoir un promotionnel.

Le sandbox et la production utilisent des messages distincts : un message Default en sandbox ne couvre pas le produit en production. Avant de créer un message promo en production, créez d'abord un message Default en production pour le même produit. Inutile d'attendre la validation d'Apple : dès que vous soumettez le message Default, vous pouvez ajouter son produit à un message promo.

<ZoomImage id="retention-message-step-1-general.webp" width="700px" alt="Default message General step with the Name field and Products section" />

Pour un message **promo**, associez une incitation à chaque produit ajouté. Un produit reçoit une incitation, et **Next** reste désactivé tant que chaque produit n'en a pas une :

- **Link Promo Offer** : une offre promotionnelle que vous avez [préalablement configurée pour le produit](app-store-offers). La liste n'affiche que les offres promotionnelles, donc les offres de reconquête et les offres de lancement n'y figurent pas. Si la liste est vide, [créez une offre promotionnelle dans App Store Connect](app-store-offers#promotional-offers) et [ajoutez-la au produit dans Adapty](create-offer).

    <ZoomImage id="retention-messaging-promo.webp" width="500px" alt="Promo message General step with the Associated offers list open for a product" />

- **Link Plan Switch** : Un autre produit du groupe d'abonnements du produit que vous ajoutez. Si la liste de plans est vide, ajoutez les autres produits du groupe dans Adapty et vérifiez que chaque produit du groupe [affiche un statut App Store](troubleshoot-app-store-integration#products-dont-appear-or-show-no-app-store-status).

    <ZoomImage id="retention-messaging-switch-plan.webp" width="500px" alt="Message promotionnel à l'étape Général avec la liste des plans associés ouverte pour un produit" />

### Contenu \{#content\}

Rédigez le message en anglais. Un aperçu à droite affiche le message sur l'écran d'annulation d'abonnement au fur et à mesure que vous tapez.

Le message **Default** peut inclure une image. Ajoutez un **Alt text** pour décrire l'image aux lecteurs d'écran. L'alt text n'est pas localisé : Apple reçoit l'alt text en anglais pour toutes les langues.

Par défaut, le titre et le corps du texte apparaissent sous l'image. Pour afficher le titre au-dessus de l'image, sélectionnez **Above the image** dans **Title position**. Le corps du texte reste toujours sous l'image.

<ZoomImage id="retention-message-step-2-content.webp" width="700px" alt="Étape de contenu avec une image téléchargée, position du titre définie sur Au-dessus de l'image, et aperçu sur téléphone montrant le titre au-dessus de l'image" />

:::important
Choisissez la position du titre au moment de la création du message. Vous ne pourrez plus la modifier ensuite — pour utiliser une position différente, créez un nouveau message. Si vous créez un message sans image et en ajoutez une plus tard, le titre restera en dessous de l'image.
:::

Un message **Default** peut également lister jusqu'à cinq points sous le corps, avec ou sans image. Pour en ajouter un, sous **Bullet points**, cliquez sur **+ Add Bullet Point**, puis remplissez ses champs :

- **Icon** : Obligatoire pour chaque point. Importez un PNG de exactement 1024 × 1024 px, sans transparence. Apple examine chaque icône séparément.
- **Text** : Jusqu'à 66 caractères.
- **Alt text** : Une description de l'icône pour les lecteurs d'écran. Si vous laissez ce champ vide, Adapty envoie une description par défaut à Apple. Comme le texte alternatif de l'image, il n'est pas localisé.

<ZoomImage id="retention-message-bullet-points.webp" width="600px" alt="Étape de contenu avec une carte « Point 1 » remplie, et un aperçu sur téléphone listant trois points avec des icônes sous le corps du message" />

Les messages promotionnels ne peuvent pas contenir de points de liste.

### Localisation \{#localization\}

L'anglais est la langue source. Ajoutez les autres langues utilisées par vos abonnés, puis traduisez le contenu.

1. Cliquez sur **Add Locale** et choisissez les paramètres régionaux à prendre en charge.
2. Cliquez sur **AI Translate All Cells** pour traduire automatiquement le [contenu](#content). La traduction remplace les textes du titre, du corps et des points de liste dans chaque paramètre régional ajouté, y compris vos modifications manuelles — traduisez donc en premier et modifiez ensuite.
3. Cliquez sur n'importe quelle cellule pour modifier une traduction.

Chaque locale doit respecter les mêmes limites que la version anglaise : 66 caractères pour le titre, 144 pour le corps et 66 pour chaque point. Une traduction trop longue bloque **Submit To Review** tant que vous ne la raccourcissez pas. Un point vide dans une locale avec du texte bloque aussi la soumission. Les icônes sont identiques dans toutes les locales : seul le texte des points est traduit.

Survolez une locale pour en avoir un aperçu sur l'écran Annuler l'abonnement.

Adapty utilise la version `en-US` si Apple n'a pas encore approuvé une traduction pour la locale cible.

<ZoomImage id="retention-message-step-3-localization.webp" width="700px" alt="Étape de localisation avec le tableau de paramètres régionaux et le bouton AI Translate All Cells" />

## Soumettre pour révision \{#submit-for-review\}

Lorsque le message est prêt, cliquez sur **Submit To Review**. Adapty téléverse le message et les icônes de ses points de liste vers Apple dans chaque langue qui contient du texte, et Apple commence à l'examiner. Adapty ignore les langues dont toutes les cellules sont vides. Suivez l'[état](#message-states) de votre soumission sur la page Retention Messaging.

Adapty enregistre le message uniquement au moment de la soumission.

## États des messages \{#message-states\}

Après avoir soumis le message, Apple examine chaque langue séparément. Le message est mis en ligne uniquement après qu'Apple a approuvé toutes les langues, y compris l'anglais. Un message par défaut nécessite également qu'Apple l'accepte comme message par défaut pour chaque produit ajouté. En attendant, le message reste **In review**, même si certaines langues affichent déjà **Live**. Pour les langues qu'Apple n'a pas encore approuvées, Adapty [revient à `en-US`](#localization). La colonne **State** sur la page Retention Messaging vous permet de suivre la progression du message :

| État | Ce que ça signifie |
| --- | --- |
| **In review** | Apple n'a pas encore reçu le message, n'a pas approuvé toutes ses locales, ou n'a pas accepté de message par défaut pour tous ses produits. |
| **Live** | Apple a approuvé le message, et Adapty le diffuse aux abonnés qui annulent. |
| **Rejected** | Apple a refusé la soumission dans au moins une locale — essayez de soumettre une version alternative. |
| **Inactive** | Vous avez [désactivé](#deactivate-and-reactivate) le message. Vous pouvez maintenant en créer un nouveau pour les mêmes produits. |

Pour voir quelles langues Apple n'a pas encore approuvées, ouvrez le message et accédez à l'étape **Localization**. Chaque langue ajoutée affiche son propre statut **Live**, **In review** ou **Rejected**. La ligne anglaise n'affiche aucun statut, mais Apple doit également l'approuver. Si toutes les langues ajoutées affichent **Live** et que le message reste **In review**, contactez le support en indiquant le nom du message.

Vous pouvez modifier n'importe quel message à tout moment — y compris les messages en cours de diffusion auprès de vos clients. Si vous modifiez un message **Live**, ou si vous y ajoutez une nouvelle locale, le message perd immédiatement son statut live et redevient un message **In review**.

Si vous modifiez le titre ou le corps en anglais d'un message existant, le bouton de l'étape **Content** se transforme en **Update Locales**. Cliquez dessus pour ouvrir l'étape **Localization**, mettez à jour les traductions, puis cliquez sur **Submit To Review**.

## Désactiver et réactiver \{#deactivate-and-reactivate\}

Pour retirer un message d'Apple sans le supprimer d'Adapty, ouvrez le menu dans la ligne du message et cliquez sur **Deactivate**.

Pour le remettre en ligne, cliquez sur **Activate**. La réactivation ne passe pas par la revue d'Apple, et le message peut prendre quelques minutes à atteindre tous les abonnés.

Un produit peut avoir au maximum un message par défaut et un message promo. Si un autre message du même type a revendiqué le produit pendant que celui-ci était inactif, la réactivation échoue.
