Les messages de rétention vous permettent de toucher les abonnés sur le point de se désabonner pendant le processus d'annulation. Lorsqu'un client accède à l'écran iOS Annuler l'abonnement, Apple lui affiche le message correspondant à son produit et à sa langue.

Il existe deux types de messages de rétention :

- **Default** : Un message de reconquête simple avec un titre, un corps de texte et une image facultative. Utilisé comme solution de secours lorsqu'aucun message promo n'est disponible.
- **Promo** : Un message de reconquête qui propose aux abonnés une offre spéciale ou un plan différent. Vous ne pouvez créer des messages promo que pour des produits auxquels un message Default est déjà assigné.

## Avant de commencer \{#before-you-begin\}

- Créez au moins un [produit](create-product) que le message doit couvrir.
- [Testez la messagerie de rétention](retention-messaging-setup) en mode sandbox.

## Créer un message \{#create-a-message\}

Ouvrez la page Retention Messaging dans l'Adapty Dashboard. Cliquez sur **Create Default** pour un message par défaut, ou sur **Create Message** pour un message promo.

<ZoomImage id="retention-select-default-or-promo.webp" width="700px" alt="The Create Default and Create Message buttons in the Retention Messaging page header" />

Sélectionnez l'environnement — un message sandbox pour les tests, ou un message de production pour les vrais utilisateurs. L'option de production reste désactivée tant que vous n'avez pas [configuré l'URL de production](retention-messaging-setup#switch-to-production) et réussi le test de performance en sandbox.

<ZoomImage id="retention-new-message.webp" width="700px" alt="Écran de démarrage d'un nouveau message avec les options Créer un message sandbox et Créer un message de production" />

### Général \{#general\}

Nommez le message et ajoutez les produits dont l'annulation déclenchera le message.

La liste des produits grise ceux que vous ne pouvez pas ajouter, avec la raison indiquée à côté : **used** signifie qu'un autre message du même type couvre déjà ce produit, et **no default message** signifie que le produit doit avoir un message par défaut avant de pouvoir recevoir un message promotionnel.

<ZoomImage id="retention-message-step-1-general.webp" width="700px" alt="Étape Général du message par défaut avec le champ Nom et la section Produits" />

Pour un message **promo**, associez une incitation à chaque produit ajouté. Un produit reçoit une incitation, et **Next** reste désactivé tant que chaque produit n'en a pas une :

- **Link Promo Offer** : une offre promotionnelle que vous avez [préalablement configurée pour le produit](app-store-offers).

    <ZoomImage id="retention-messaging-promo.webp" width="500px" alt="Étape General d'un message promo avec la liste des offres associées ouverte pour un produit" />

- **Link Plan Switch** : un produit différent de votre catalogue. Si la liste des plans est vide, vérifiez que vous avez ajouté une [clé API App Store Connect](app-store-connection-configuration) : Adapty en a besoin pour récupérer les plans.

    <ZoomImage id="retention-messaging-switch-plan.webp" width="500px" alt="Étape Générale du message promotionnel avec la liste des plans associés ouverte pour un produit" />

### Contenu \{#content\}

Rédigez le message en anglais. Un aperçu à droite affiche le message sur l'écran d'annulation d'abonnement au fur et à mesure que vous tapez.

Le message **Default** peut inclure une image. Ajoutez un **Alt text** pour décrire l'image aux lecteurs d'écran. L'alt text n'est pas localisé : Apple reçoit l'alt text en anglais pour toutes les langues.

Par défaut, le titre et le corps du texte apparaissent sous l'image. Pour afficher le titre au-dessus de l'image, sélectionnez **Above the image** dans **Title position**. Le corps du texte reste toujours sous l'image.

<ZoomImage id="retention-message-step-2-content.webp" width="700px" alt="Étape de contenu avec une image téléchargée, position du titre définie sur Au-dessus de l'image, et aperçu sur téléphone montrant le titre au-dessus de l'image" />

:::important
Choisissez la position du titre au moment de la création du message. Vous ne pourrez plus la modifier ensuite — pour utiliser une position différente, créez un nouveau message. Si vous créez un message sans image et en ajoutez une plus tard, le titre restera en dessous de l'image.
:::

### Localisation \{#localization\}

L'anglais est la langue source. Ajoutez les autres langues utilisées par vos abonnés, puis traduisez le contenu.

1. Cliquez sur **Add Locale** et choisissez les locales à prendre en charge.
2. Cliquez sur **AI Translate All Cells** pour traduire automatiquement le [contenu](#content). La traduction remplace le titre et le corps dans chaque locale ajoutée, y compris vos modifications manuelles — traduisez donc en premier, puis effectuez vos modifications.
3. Cliquez sur n'importe quelle cellule pour modifier une traduction.

Chaque locale doit respecter les mêmes limites que la source en anglais : 66 caractères pour le titre, 144 pour le corps. Une traduction trop longue bloque **Submit To Review** jusqu'à ce que vous la raccourcissiez.

Survolez une locale pour la prévisualiser sur l'écran d'annulation d'abonnement.

Adapty utilise la version `en-US` si Apple n'a pas encore approuvé de traduction pour la locale cible.

<ZoomImage id="retention-message-step-3-localization.webp" width="700px" alt="Localization step with the locale table and the AI Translate All Cells button" />

## Soumettre pour examen \{#submit-for-review\}

Lorsque le message est prêt, cliquez sur **Submit To Review**. Adapty envoie le message à Apple dans toutes les locales ayant un titre ou un corps, et Apple commence l'examen. Adapty ignore les locales dont les deux champs sont vides. Suivez l'[état](#message-states) de votre soumission sur la page Retention Messaging.

Adapty n'enregistre le message qu'au moment de la soumission.

## États des messages \{#message-states\}

Après envoi du message, Apple examine chaque locale séparément. Le message est mis en ligne dès qu'Apple approuve au moins une locale. Pour les locales qu'Apple n'a pas encore approuvées, Adapty [revient à `en-US`](#localization). La colonne **State** de la page Retention Messaging vous permet de suivre la progression du message :

| État | Ce que cela signifie |
| --- | --- |
| **In review** | Apple n'a pas encore reçu le message, ou n'a approuvé aucun de ses paramètres régionaux. |
| **Live** | Apple a approuvé le message, et Adapty le présente aux abonnés qui souhaitent se désabonner. |
| **Rejected** | Apple a rejeté la soumission dans au moins un paramètre régional — essayez de soumettre une version alternative. |
| **Inactive** | Vous avez [désactivé](#deactivate-and-reactivate) le message. Vous pouvez maintenant en créer un nouveau pour les mêmes produits. |

Pour voir quelles locales Apple n'a pas encore approuvées, ouvrez le message et accédez à l'étape **Localization**. Chaque locale ajoutée affiche son propre statut : **Live**, **In review** ou **Rejected**.

Vous pouvez modifier n'importe quel message à tout moment — y compris les messages actuellement diffusés à vos clients. Si vous modifiez un message **Live** ou ajoutez une nouvelle locale, le message perd immédiatement son statut actif et repasse à l'état **In review**.

Si vous modifiez le titre ou le corps d'un message existant en anglais, le bouton de l'étape **Content** devient **Update Locales**. Cliquez dessus pour ouvrir l'étape **Localization**, mettez à jour les traductions, puis cliquez sur **Submit To Review**.

## Désactiver et réactiver \{#deactivate-and-reactivate\}

Pour retirer un message d'Apple sans le supprimer d'Adapty, ouvrez le menu dans la ligne du message et cliquez sur **Deactivate**.

Pour le remettre en ligne, cliquez sur **Activate**. La réactivation ne passe pas par la revue d'Apple, et le message peut prendre quelques minutes à atteindre tous les abonnés.

Un produit peut avoir au maximum un message par défaut et un message promo. Si un autre message du même type a revendiqué le produit pendant que celui-ci était inactif, la réactivation échoue.
