Une formule est une [variable personnalisée](onboarding-variables#custom-variables) dont la valeur est calculée : un nombre ou une date. Une formule peut lire les réponses des utilisateurs dans le flow, d'autres variables personnalisées, les prix des produits de votre catalogue Adapty, et le jour actuel. Grâce aux formules dans le Flow & Paywall Builder, un flow peut afficher des valeurs calculées sans code dans votre app :

- **Un résultat issu des réponses** : la somme des scores d'un quiz, un IMC calculé à partir du poids et de la taille, ou une taille en pieds et en pouces.
- **Un prix** : le prix du produit sélectionné après une remise de 20 %, ou l'économie réalisée avec l'abonnement annuel par rapport à l'abonnement hebdomadaire.
- **Une date** : la date de fin d'un essai gratuit.
- **Une durée** : la durée d'un essai gratuit en jours, ou l'âge d'un utilisateur calculé à partir de sa date de naissance.

Le flow calcule le résultat d'une formule directement sur l'appareil. Quand une valeur lue par la formule change, le flow met à jour le résultat automatiquement. Vous pouvez afficher ce résultat dans un élément texte ou l'utiliser dans des conditions.

## Créer une formule \{#create-a-formula\}

1. Ouvrez le panneau <Inline id="variables.svg" alt="Variables" /> Variables dans le flow builder.
2. Ajoutez une nouvelle variable — cliquez sur <Inline id="plus.svg" alt="Plus" />.
3. Saisissez le **Name** de la variable, par exemple `bmi`. Les autres formules utilisent ce nom pour lire le résultat.
4. Dans le menu déroulant **Value Type**, sélectionnez **Formula**.
5. Dans le champ **Expression**, entrez la formule, par exemple `round({{weight}} * 10000 / ({{height}} * {{height}}), 1)`, où `weight` et `height` sont des variables de type Number. Pour les règles, consultez [Écrire une formule](#write-a-formula).
6. Cliquez sur **Create variable**.

<ZoomImage id="flow-formula-create.webp" width="300px" alt="La boîte de dialogue Créer une variable avec le type Formula, une formule IMC dans le champ Expression, le type de sortie Number, et un aperçu de 22,9" />

Lorsque vous quittez le champ **Expression**, le builder valide la formule. Si la formule contient une erreur, le texte de l'erreur s'affiche sous le champ. Tant que l'erreur est visible, le bouton **Create variable**, ou **Save** pour une variable existante, est désactivé. Dès que vous modifiez l'expression, l'erreur disparaît et le bouton redevient disponible.

Sous le champ, le builder affiche :

- **Type de résultat** : **Number** ou **Date**, le type du résultat. Le builder le détermine à partir de la formule : le résultat est une Date quand la formule est une [fonction de date](#date-functions) qui retourne une date, comme `addDays`, ou une valeur Date seule, comme `{{trial_start}}`. Toute autre formule donne un Number, y compris une formule qui calcule la durée entre deux dates, comme `daysBetween`.
- **Format de date** : Uniquement pour une formule de type Date. Définit comment les éléments texte affichent le résultat. Voir [Afficher une date dans un élément texte](#show-a-date-in-a-text-element).
- **Aperçu** : Le résultat, calculé à partir des valeurs initiales et des prix des produits. Voir [Prévisualiser une formule dans le builder](#preview-a-formula-in-the-builder).

Une formule dépend toujours d'autres valeurs, elle n'a donc pas de **Initial value**. Pour la même raison, votre application ne peut pas définir une formule.

### Insérer des références et des fonctions \{#insert-references-and-functions\}

Si vous ne connaissez pas le nom exact d'une variable, tapez `{{` dans le champ **Expression**. Une liste de variables s'affiche. Saisissez une partie du nom pour filtrer la liste, puis sélectionnez une variable pour insérer sa référence. La liste s'affiche également lorsque vous tapez un nom de fonction. Lorsque vous tapez un espace après une valeur numérique, comme `{{weight}}` ou `5`, la liste propose les opérateurs `+`, `-`, `*` et `/`. Pour fermer la liste, appuyez sur Échap.

La liste affiche uniquement les variables et fonctions utilisables à la position du curseur. Par exemple, dans le premier argument de `addDays`, la liste propose des valeurs de type Date, `today()`, et les fonctions qui retournent une date. Dans le deuxième argument de `round`, la liste ne propose rien, car le nombre de décimales est un nombre que vous saisissez directement.

Le champ **Expression** affiche chaque référence sous forme de puce avec le nom de la variable, par exemple **weight** pour une variable personnalisée ou **Weekly · prod_price** pour le prix d'un produit. Une puce est une unité indivisible : Retour arrière ou Suppr supprime toute la référence, et les touches fléchées déplacent le curseur au-delà de la puce.

Pour parcourir toutes les variables que la formule peut lire, ou consulter la description d'une fonction, utilisez les deux boutons de la ligne **Output type**. Chaque bouton insère du texte à l'emplacement du curseur dans le champ **Expression** :

- <Inline id="variables.svg" alt="Insert variable" /> **Insert variable** : Ouvre une liste avec quatre onglets. Sélectionnez une valeur pour insérer sa référence, ou une fonction pour insérer son nom et une parenthèse ouvrante :
  - **Functions** : Les fonctions des formules.
  - **Elements** : Les réponses dans les champs et les sélecteurs, comme `weight.value`.
  - **Products** : Les prix du produit sélectionné dans chaque groupe de produits, puis les produits de votre catalogue Adapty. Voir [Lire le prix de n'importe quel produit](#read-the-price-of-any-product).
  - **Custom** : Les variables personnalisées de type Nombre, Date et Formule.
- <Inline id="function.svg" alt="Insert function" /> **Insert function** : Liste les fonctions, chacune accompagnée d'une description et d'un exemple. Pour trouver une fonction, tapez son nom dans le champ de recherche. Sélectionnez une fonction pour insérer son nom et une parenthèse ouvrante, par exemple `addDays(`. Saisissez ensuite les arguments et la parenthèse fermante.

La liste **Insert variable** n'affiche pas les variables de type String, Boolean ou Array, ni la formule que vous modifiez.

## Écrire une formule \{#write-a-formula\}

Une formule combine des nombres, des références à des valeurs, des opérateurs et des fonctions. Les noms de fonctions et de variables sont sensibles à la casse : `Round(2.5)` est une erreur.

### Références \{#references\}

Mettez chaque référence entre doubles accolades :

| Référence | Ce que la formule lit | Exemple |
| :--- | :--- | :--- |
| `{{<variable name>}}` | Une variable personnalisée de type Nombre, Date ou Formule | `{{discount}}` |
| `{{<Element ID>.value}}` | La réponse dans un [champ Texte ou Nombre](builder-inputs-and-forms), un [sélecteur de nombre](builder-number-picker), ou un champ Date ou Date & Heure | `{{weight.value}}` |
| `{{<Group ID>.selectedProduct.prod_price}}` | Le prix du produit sélectionné par l'utilisateur dans un groupe de produits, sous forme de nombre | `{{products.selectedProduct.prod_price}}` |
| `{{<Group ID>.selectedProduct.prod_price_per_week}}` | Le prix du produit sélectionné pour une semaine. Aussi `prod_price_per_day`, `prod_price_per_month` et `prod_price_per_year`. Un produit qui n'est pas un abonnement ne retourne aucune valeur. Voir [Prix par période](#per-period-prices). | `{{products.selectedProduct.prod_price_per_month}}` |
| `{{<Group ID>.selectedProduct.offer_price}}` | Le prix de l'offre du produit sélectionné, sous forme de nombre | `{{products.selectedProduct.offer_price}}` |
| `{{<Group ID>.selectedProduct}}` | Le produit sélectionné, uniquement comme second argument de `addOfferDuration` | `{{products.selectedProduct}}` |
| `{{<Adapty product ID>.prod_price}}` | Le prix d'un produit de votre catalogue Adapty, sous forme de nombre. Ainsi que les prix par période du produit, comme `prod_price_per_week`. Voir [Lire le prix de n'importe quel produit](#read-the-price-of-any-product). | `{{<annual product ID>.prod_price}}`, affiché sous la forme **Annual · prod_price** |

Une formule lit une réponse saisie sous forme de nombre lorsque la réponse est composée de chiffres, avec un éventuel signe moins devant et une éventuelle partie décimale après un point ou une virgule. La formule ignore les espaces au début et à la fin. Par exemple, `12`, `-5`, `1.5` et `1,5` sont des nombres. Toute autre réponse, comme `abc`, `1,5,0` ou `1e3`, donne à la formule [aucune valeur](#formulas-without-a-value). Dans un champ de saisie Nombre qu'une formule lit, les utilisateurs ne peuvent entrer qu'un nombre. Avec les formats **Decimal (Point)** et **Decimal (Comma)**, les utilisateurs peuvent saisir un point ou une virgule décimale, ce qui permet d'utiliser la touche décimale de n'importe quel clavier.

Un champ de saisie Date ou Date & Time renvoie le jour du calendrier sélectionné par l'utilisateur.

Une formule peut lire une autre formule, mais les références ne peuvent pas former de boucle. Si la formule A lit la formule B, la formule B ne peut pas lire la formule A en retour. Une boucle plus longue est également une erreur : par exemple, si A lit B, B lit C, et C lit A. Une formule ne peut pas se référencer elle-même. Lorsque vous renommez une variable, un **Element ID** ou un **Group ID**, la formule affiche le nouveau nom et lit la même valeur. Lorsque vous supprimez une variable qu'une formule lit, le champ **Expression** affiche à la place une puce **deleted variable**, et une erreur apparaît sous le champ.

Un nom qui correspond à deux valeurs est une erreur. Par exemple, si une variable personnalisée est nommée `age.value` et qu'un champ a l'Element ID `age`, `{{age.value}}` correspond aux deux. Renommez la variable personnalisée.

### Nombres et opérateurs \{#numbers-and-operators\}

- **Nombres** : Utilisez toujours un point décimal, par exemple `0.8`. Dans une fonction, une virgule sépare les arguments : `round(2,5)` correspond à `round(2, 5)`, ce qui donne 2 et non 2,5. En dehors d'une fonction, une virgule dans un nombre est une erreur. Un signe moins devant un nombre ou une référence le rend négatif, par exemple `-3`.
- **Opérateurs** : `+`, `-`, `*` et `/`. Le flow calcule `*` et `/` avant `+` et `-`, et les opérateurs de même niveau de gauche à droite. Utilisez des parenthèses pour modifier l'ordre : `({{a}} + {{b}}) / 2`.

## Formules numériques \{#number-formulas\}

Une formule numérique retourne un nombre.

### Fonctions numériques \{#number-functions\}

| Fonction | Résultat | Exemple |
| :--- | :--- | :--- |
| `round(n)` | `n` arrondi à l'entier le plus proche. Une valeur exactement à mi-chemin s'arrondit en s'éloignant de zéro. | `round(2.5)` = 3, `round(-2.5)` = -3 |
| `round(n, digits)` | `n` arrondi à `digits` décimales. `digits` est un entier de 0 à 6 que vous saisissez directement dans la formule, pas une référence ni un calcul. | `round(23.12, 1)` = 23.1, `round(1.005, 2)` = 1.01 |
| `floor(n)` | Le plus grand entier qui n'est pas supérieur à `n` | `floor(2.7)` = 2, `floor(-2.5)` = -3 |
| `mod(a, b)` | Le reste de la division de `a` par `b`, avec le signe de `b`, comme la fonction MOD des tableurs | `mod(7, 3)` = 1, `mod(-7, 3)` = 2, `mod(5.5, 2)` = 1.5 |

Un résultat nul de `round`, `floor` et `mod` est toujours 0, jamais -0.

### Afficher un nombre dans un élément texte \{#show-a-number-in-a-text-element\}

Pour afficher une formule ou une variable de type Date, [insérez la variable](onboarding-variables#use-variables-in-text) dans un élément texte depuis l'onglet **Custom** du sélecteur de variables. Les dates et les nombres avec `round` au niveau supérieur s'affichent dans la langue de l'appareil, et non dans la langue du flow.

L'apparence d'une formule Nombre dépend de la fonction au niveau supérieur de la formule :

- **`round` au niveau supérieur** : Le nombre affiche exactement le nombre de décimales défini par `round`. Il utilise le séparateur décimal de la langue de l'appareil, sans séparateurs de milliers ni symbole de devise. Par exemple, `round(23.12, 1)` affiche « 23.1 » en anglais et « 23,1 » en russe, et `round(15.04, 1)` affiche « 15.0 » en anglais.
- **Toute autre formule** : Le nombre apparaît sous sa forme brute, avec un point décimal quelle que soit la langue et jusqu'à 15 chiffres significatifs. Par exemple, `9.99 * 0.8` affiche « 7.992 », et `1 - 1 / 3` affiche « 0.666666666666667 ». Pour définir le nombre de décimales, placez `round` au niveau supérieur de la formule, par exemple `round(1 - 1 / 3, 2)`.

Une variable Nombre et une formule avec `floor` ou `mod` au niveau supérieur apparaissent également sous forme ordinaire.

### Comparer des nombres dans les conditions \{#compare-numbers-in-conditions\}

Vous pouvez sélectionner une formule ou une variable Date dans une condition, comme une règle de [visibilité conditionnelle](onboarding-element-visibility) ou une action conditionnelle :

- **Formules numériques** : Utilisez les mêmes opérateurs que pour une variable de type Nombre : **Equals**, **Does not equal**, **Greater than**, **Less than**, **Is empty** et **Is not empty**. Comparez la formule avec un nombre ou avec une autre valeur de type Nombre, par exemple `bmi` **Greater than** `25`. Les opérateurs ne comprennent pas « supérieur ou égal » ni « inférieur ou égal ». Pour cibler un nombre entier de 10 ou plus, comme un score à un quiz, utilisez `score` **Greater than** `9`.

## Prix des produits \{#product-prices\}

Une formule peut lire les prix des produits depuis deux sources :

- **Le produit sélectionné d'un groupe de produits** : le prix change quand l'utilisateur sélectionne un autre produit dans le groupe, par exemple `{{products.selectedProduct.prod_price}}`.
- **Un produit de votre catalogue Adapty** : le prix d'un seul produit, même un produit que l'écran n'affiche pas. Utilisez-le pour comparer des offres, par exemple les économies réalisées avec l'abonnement annuel par rapport à l'abonnement hebdomadaire.

Sur l'appareil, le flow utilise le prix du store dans la devise de l'utilisateur. Dès que les prix des produits sont chargés, le flow recalcule la formule.

### Lire le prix d'un produit \{#read-the-price-of-any-product\}

1. Dans le champ **Expression**, placez le curseur à l'endroit où le prix doit apparaître.
2. Cliquez sur <Inline id="variables.svg" alt="Insert variable" /> **Insert variable**, et ouvrez l'onglet **Products**.
3. Pointez sur le produit et sélectionnez le prix : `prod_price`, ou un [prix par période](#per-period-prices), comme `prod_price_per_week`.

L'onglet **Products** répertorie les produits en deux groupes :

- **This flow** : les produits présents sur les écrans du flow.
- **Other** : le reste de votre catalogue Adapty.

Pour différencier les produits, comparez le niveau d'accès et le prix en USD de chaque produit dans la liste. La durée d'abonnement d'un produit n'est pas affichée dans la liste. Lorsque deux produits ont le même titre, la liste et l'infobulle de la puce affichent également l'identifiant du produit dans le store.

Une formule peut afficher un prix à l'écran uniquement si le produit figure dans la [liste de produits de l'écran](paywall-product-block). Lorsque vous insérez la formule dans un élément texte ou que vous l'utilisez dans une condition, le builder ajoute le produit à cette liste, sans offre ni plan de facturation. Il en fait de même lorsque la formule lit le prix via une autre formule. Pour un composant réutilisable, le builder ajoute le produit à chaque écran qui affiche le composant. Si l'écran ne contient le produit qu'avec une offre ou un plan de facturation, le builder ajoute une seconde entrée sans ces éléments.

L'entrée ajoutée s'affiche dans le panneau **Products**, dans les analyses, et dans les produits que reçoit le code de votre application, comme n'importe quel autre produit de l'écran. L'écran ne le sélectionne pas, et un appui sur le texte ne déclenche pas l'achat.

Une fois l'entrée ajoutée par le builder, vous la gérez dans le panneau **Products**, comme n'importe quel autre produit de l'écran :

- **Vous supprimez le prix de la formule, ou la formule de l'écran** : l'entrée reste. Si rien d'autre sur l'écran n'utilise le produit, supprimez l'entrée. Une entrée conservée bloque la publication après avoir supprimé le produit de votre catalogue Adapty.
- **Vous supprimez l'entrée alors que l'écran utilise encore la formule** : le builder ne rajoute pas l'entrée automatiquement, et l'écran affiche le problème **This product is off this screen**. Pour corriger ce problème, rajoutez le produit dans le panneau **Products**.

Lorsque vous supprimez un produit de votre catalogue Adapty, le champ **Expression** affiche son prix sous forme de puce **Missing product**, et une erreur apparaît sous le champ. Remplacez ce prix par celui d'un autre produit. La suppression ne modifie pas les versions publiées du flow.

Si vous créez un flow avec [Adapty CLI](developer-cli-flows) ou l'API, ajoutez le produit, sans offre ni plan de facturation, à chaque écran qui utilise la formule, comme le fait le builder. Dans l'expression, utilisez l'ID de produit Adapty que retourne [`adapty products list`](developer-cli-products). La publication échoue avec l'erreur `formula_undeclared_product` uniquement lorsqu'un élément de texte ou une condition utilise la formule et qu'aucun écran du flow ne contient le produit sans offre ni plan de facturation.

### Prix par période \{#per-period-prices\}

Un prix par période est le prix d'un produit d'abonnement pour un jour, une semaine, un mois ou une année. Une formule peut lire ces prix pour un produit du catalogue et pour le produit sélectionné d'un groupe de produits :

| Prix | Exemple pour un produit mensuel au prix de 9,99 |
| :--- | :--- |
| `prod_price_per_day` | 9,99 / 30 = 0,333 |
| `prod_price_per_week` | 9,99 × 7 / 30 = 2,331 |
| `prod_price_per_month` | 9,99 |
| `prod_price_per_year` | 9,99 × 12 = 119,88 |

Le flow divise le prix par le nombre de jours, semaines, mois ou années compris dans la durée d'abonnement du produit. Un mois correspond à 30 jours, soit 30/7 semaines. Une année correspond à 365 jours, 52 semaines ou 12 mois. Les [variables de prix des éléments de texte](onboarding-variables#product-variables) utilisent la même conversion. Par exemple, un produit annuel au prix de 120 donne 10 pour `prod_price_per_month` et 120 / 52 pour `prod_price_per_week`.

La formule conserve tous les décimales d'un prix par période. Pour afficher le prix avec deux décimales, placez `round` au niveau supérieur de la formule. Quand un utilisateur sélectionne un produit annuel au prix de 120, `round({{products.selectedProduct.prod_price_per_week}}, 2)` affiche « 2.31 ».

Un produit qui n'est pas un abonnement, comme un produit à vie ou un produit consommable, donne aux prix par période [aucune valeur](#formulas-without-a-value).

## Formules de date \{#date-formulas\}

Une formule de date renvoie une date. Pour utiliser un jour fixe dans une formule, comme une date de début d'essai, stockez-le dans une variable de type Date.

### Créer une variable Date \{#create-a-date-variable\}

1. Ouvrez le panneau <Inline id="variables.svg" alt="Variables" /> Variables et cliquez sur <Inline id="plus.svg" alt="Plus" />.
2. Saisissez le **Name** de la variable, par exemple `trial_start`.
3. Dans le menu déroulant **Value Type**, sélectionnez **Date**.
4. (Facultatif) Dans le champ **Initial value**, entrez une date au format `DD.MM.YYYY`, par exemple `17.11.2026`, ou cliquez sur le champ et choisissez le jour dans le calendrier, puis cliquez sur **Apply**. Le builder n'accepte pas une date inexistante, comme `31.02.2027`. Sans valeur initiale, la variable n'a aucune valeur tant qu'une action [**Set variable**](onboarding-actions) ne la définit pas.
5. (Facultatif) Dans le menu déroulant **Date format**, sélectionnez la façon dont les éléments de texte affichent la date. Voir [Afficher une date dans un élément de texte](#show-a-date-in-a-text-element).
6. Cliquez sur **Create variable**.

<ZoomImage id="flow-date-variable-create.webp" width="300px" alt="The Create variable dialog with the Date type and the Initial value 17.11.2026" />

Une variable Date contient un jour sans heure ni fuseau horaire.

Pour modifier une variable Date quand les utilisateurs appuient sur un élément, ajoutez une action [**Set variable**](onboarding-actions), sélectionnez la variable Date et saisissez la nouvelle date au format `DD.MM.YYYY` ou choisissez-la dans le calendrier. Une action **Set variable** ne peut pas modifier une formule, car une formule dépend toujours d'autres valeurs.

### Fonctions de date \{#date-functions\}

| Fonction | Résultat | Exemple |
| :--- | :--- | :--- |
| `today()` | Le jour actuel sur l'appareil | `today()` |
| `addDays(date, n)` | `date` plus `n` jours | `addDays(today(), 7)` |
| `addWeeks(date, n)` | `date` plus `n` semaines | `addWeeks({{trial_start}}, 2)` |
| `addMonths(date, n)` | `date` plus `n` mois | `addMonths({{trial_start}}, 1)` |
| `addYears(date, n)` | `date` plus `n` années | `addYears({{birth_date.value}}, 18)` |
| `addOfferDuration(date, product)` | `date` plus la durée de l'offre du produit | `addOfferDuration(today(), {{products.selectedProduct}})` |
| `daysBetween(start, end)` | Le nombre de jours calendaires entre `start` et `end`, en tant que Nombre | `daysBetween(today(), {{trial_end}})` |
| `weeksBetween(start, end)` | Le nombre de semaines complètes entre `start` et `end`, en tant que Nombre | `weeksBetween({{trial_start}}, today())` |
| `monthsBetween(start, end)` | Le nombre de mois complets entre `start` et `end`, en tant que Nombre | `monthsBetween({{trial_start}}, today())` |
| `yearsBetween(start, end)` | Le nombre d'années complètes entre `start` et `end`, en tant que Nombre | `yearsBetween({{birth_date.value}}, today())` |

La date functions follow these rules:

- **`today()`** : Donne le début du jour actuel dans le fuseau horaire de l'appareil. Le flow lit le jour à l'ouverture, donc la valeur ne change pas à minuit pendant que le flow est ouvert.
- **`n` négatif ou fractionnaire** : Un `n` négatif recule la date. Le flow supprime la partie fractionnaire de `n` : `addWeeks(date, 1.5)` ajoute 1 semaine, et `addDays(date, -1.9)` recule la date d'1 jour.
- **Mois courts** : Lorsque le mois cible ne contient pas le jour voulu, le résultat est le dernier jour de ce mois. Par exemple, le 31 janvier 2027 plus 1 mois donne le 28 février 2027, et le 29 février 2028 plus 1 an donne le 28 février 2029.
- **`addOfferDuration`** : Ajoute chaque phase de l'offre du produit que le SDK Adapty transmet au flow, dans l'ordre. Pour chaque phase, la fonction ajoute la période de la phase multipliée par son nombre de périodes en une seule étape : un essai gratuit de 7 jours débutant le 10 novembre 2026 se termine le 17 novembre 2026. Si le produit n'a pas d'offre, ou si une phase de l'offre a une période inconnue, le résultat n'a aucune valeur.
- **Durée entre deux dates** : `daysBetween`, `weeksBetween`, `monthsBetween` et `yearsBetween` ne comptent que les unités entières et ignorent le reste :
  - `weeksBetween` divise le nombre de jours par 7 : 13 jours équivaut à 1 semaine.
  - `monthsBetween` et `yearsBetween` comptent les mois et années calendaires complets. Par exemple, du 15 janvier 2027 au 14 mars 2027, cela fait 1 mois, et jusqu'au 15 mars 2027, cela fait 2 mois. Lorsque le mois de `end` est trop court pour le jour de `start`, le dernier jour de ce mois complète le mois : du 31 janvier 2027 au 28 février 2027, cela fait 1 mois.
  - Lorsque `end` est antérieur à `start`, le résultat est négatif : c'est le résultat des deux dates dans l'ordre inverse, avec un signe moins. Par exemple, `daysBetween` du 1er décembre 2026 au 24 novembre 2026 donne -7, et `weeksBetween` donne -1 pour un `end` 10 jours avant `start`.

Dans une formule, une Date ne peut être que le premier argument d'une fonction qui ajoute du temps à une date, ou l'argument d'une fonction qui calcule le temps entre deux dates. Utiliser une Date dans un calcul, comme `{{trial_start}} + 1`, est une erreur. Un Nombre ne peut pas être un argument là où une fonction attend une date. Une variable de type Chaîne, Booléen ou Tableau ne peut pas faire partie d'une formule.

### Afficher une date dans un élément texte \{#show-a-date-in-a-text-element\}

Pour afficher une formule ou une variable Date, [insérez la variable](onboarding-variables#use-variables-in-text) dans un élément texte depuis l'onglet **Custom** du sélecteur de variables. Les dates et les nombres avec `round` au niveau supérieur s'affichent dans la langue de l'appareil, et non dans la langue du flow.

Une variable Date et une formule Date disposent d'un **Date format** dans les paramètres de la variable. Chaque élément texte qui affiche la variable utilise ce format, et si vous le modifiez, tous ces éléments texte sont mis à jour. Une nouvelle variable utilise le format **Medium**.

Pour utiliser un autre format dans un élément de texte, dans le champ **Content**, cliquez sur la variable et sélectionnez un format. Pour revenir au format de la variable, sélectionnez **Variable default**. Les formats disponibles sont :

| Format de date | Exemple en anglais |
| :--- | :--- |
| **Short** | 11/17/26 |
| **Medium** | Nov 17, 2026 |
| **Long** | November 17, 2026 |
| **Month D** | November 17 |
| **Mon D** | Nov 17 |

**Short**, **Medium** et **Long** suivent l'ordre de date de la langue de l'appareil. **Month D** et **Mon D** affichent le mois avant le jour dans toutes les langues, comme « ноября 17 » en russe.

### Comparer des dates dans les conditions \{#compare-dates-in-conditions\}

Vous pouvez sélectionner une formule ou une variable de type Date dans une condition, comme une règle de [visibilité conditionnelle](onboarding-element-visibility) ou une action conditionnelle :

- **Variables de type Date et formules de type Date** : utilisez **Equals**, **Does not equal**, **Earlier than**, **Later than**, **Is empty** ou **Is not empty**. Comparez la date avec une autre date, ou avec une date que vous saisissez au format `DD.MM.YYYY` ou sélectionnez dans le calendrier. **Is empty** est vrai tant que la date n'a pas de valeur, par exemple une variable de type Date sans valeur initiale avant qu'une action **Set variable** ne la définisse.

Une comparaison de dates porte sur des jours calendaires, pas sur des heures. Par exemple, une date choisie par un utilisateur à 21h00 le 17 novembre 2026 est égale à `17.11.2026`. Vous ne pouvez pas comparer une date avec un nombre.

## Formules sans valeur \{#formulas-without-a-value\}

Une formule n'a pas de valeur lorsque l'une de ses valeurs n'est pas disponible sur l'appareil :

- Une réponse est vide ou n'est pas un nombre.
- Les prix des produits n'ont pas été chargés, ou le store n'a pas renvoyé un produit lu par la formule. Pour fournir une valeur à la formule sur iOS et Android, configurez le produit dans App Store Connect et dans Google Play Console.
- Le produit n'est pas un abonnement, et la formule lit un [prix par période](#per-period-prices).
- Le produit sélectionné n'a pas d'offre, et la formule lit `offer_price` ou appelle `addOfferDuration`.
- La formule divise par zéro, comme dans `{{a}} / 0` ou `mod({{a}}, 0)`.
- Une variable Date lue par la formule n'a pas de valeur.

Une formule qui lit une formule sans valeur n'a elle-même aucune valeur. Sans valeur, une formule se comporte ainsi :

- **Éléments texte** : La formule n'affiche rien.
- **Conditions** : **Is empty** est vrai. **Equals**, **Does not equal**, ainsi que toutes les comparaisons de la formule sont fausses.

Le flow met à jour le résultat d'une formule dès qu'une valeur lue par cette formule change : quand les utilisateurs saisissent une réponse, qu'une action **Set variable** modifie une variable, ou que les prix des produits se chargent. Si les utilisateurs reviennent en arrière et effacent une réponse, la formule n'a aucune valeur sur l'écran suivant. Tant que le flow n'a pas modifié une variable personnalisée, la formule lit la valeur initiale de cette variable.

## Prévisualiser une formule dans le builder \{#preview-a-formula-in-the-builder\}

Le builder calcule le résultat d'une formule à partir des valeurs initiales des variables personnalisées et des prix en USD des produits de votre catalogue Adapty. La **Preview** sous le champ **Expression** affiche **No value** lorsque la formule contient l'un des éléments suivants :

- Une réponse que les utilisateurs saisissent ou sélectionnent
- `offer_price`
- L'offre de `addOfferDuration`
- Une variable sans valeur, comme une variable Date sans valeur initiale
- Le prix d'un produit de votre catalogue Adapty sans prix en USD, ou avec un prix en USD de 0
- Le prix par période d'un produit qui n'est pas un abonnement, comme un produit à vie

Dans ces cas, un élément texte sur le canevas affiche le nom de la variable entre accolades, comme `{{trial_end}}`. Pour voir les valeurs des réponses, [prévisualisez le flow dans l'application mobile Adapty](paywall-device-compatibility-preview). Les valeurs d'offre nécessitent une version de votre application avec de vrais produits.

Sur le canevas, les dates et les nombres avec `round` au niveau supérieur s'affichent dans la langue que vous sélectionnez pour la prévisualisation.

## Exemples \{#examples\}

### Afficher la somme des réponses \{#show-a-sum-of-answers\}

Sur un écran, ajoutez trois champs Number avec les IDs d'élément `a1`, `a2` et `a3`. Créez une formule `sum` :

```
{{a1.value}} + {{a2.value}} + {{a3.value}}
```

Sur l'écran suivant, insérez `sum` dans un élément texte. Si les utilisateurs saisissent 2, 3 et 4, le texte affiche « 9 ». S'ils reviennent en arrière et remplacent 4 par 5, le texte affiche « 10 ».

### Afficher un IMC et un label "High" \{#show-a-bmi-and-a-high-label\}

Ajoutez un champ de saisie numérique avec l'ID d'élément `weight` pour le poids en kilogrammes, et un autre avec l'ID d'élément `height` pour la taille en centimètres. Créez une formule `bmi` :

```
round({{weight.value}} * 10000 / ({{height.value}} * {{height.value}}), 1)
```

Insérez `bmi` dans un élément texte. Pour un IMC de 23,12, les utilisateurs voient « 23.1 » avec un appareil en anglais, et « 23,1 » avec un appareil en russe. Pour afficher l'étiquette « High » uniquement pour un IMC supérieur à 25, ajoutez un élément texte avec le mot « High », et attribuez-lui une règle de [visibilité conditionnelle](onboarding-element-visibility) : `bmi` **Greater than** `25`.

### Afficher un prix réduit \{#show-a-discounted-price\}

Créez une formule `discounted` qui applique une réduction de 20 % sur le prix du produit sélectionné :

```
{{products.selectedProduct.prod_price}} * 0.8
```

Créez ensuite une formule `shown` qui arrondit le résultat à deux décimales :

```
round({{discounted}}, 2)
```

Insérez `shown` dans un élément texte. Pour un produit au prix de 9,99, le texte affiche « 7,99 ». Quand les utilisateurs sélectionnent un produit au prix de 100, le texte affiche « 80,00 ». Le nombre n'inclut pas le symbole de devise. Si le prix du produit sélectionné n'a pas pu être chargé, le texte est vide.

### Afficher les économies réalisées avec le plan annuel \{#show-the-savings-of-the-annual-plan\}

Pour montrer combien les utilisateurs économisent avec un plan annuel par rapport à 52 semaines d'un plan hebdomadaire, créez une formule `saving` qui lit les prix des deux produits. Le produit hebdomadaire n'a pas besoin d'apparaître sur un écran du flow. Dans cet exemple, le produit annuel coûte 120 et le produit hebdomadaire coûte 5 :

1. Dans le champ **Expression**, cliquez sur <Inline id="variables.svg" alt="Insert variable" /> **Insert variable**. Dans l'onglet **Products**, pointez sur le produit hebdomadaire et sélectionnez `prod_price`.
2. Tapez `* 52 -`.
3. Insérez de la même façon `prod_price` du produit annuel.

Le champ **Expression** affiche **Weekly · prod_price** `* 52 -` **Annual · prod_price**, et l'**Preview** indique 140. Le builder enregistre l'expression avec les ID de produit Adapty :

```
{{<weekly product ID>.prod_price}} * 52 - {{<annual product ID>.prod_price}}
```

Pour afficher les économies en pourcentage, créez une formule `saving_percent`. Insérez les deux prix depuis l'onglet **Products**, de la même façon que pour `saving`. Le builder enregistre l'expression ainsi :

```
round((1 - {{<annual product ID>.prod_price}} / ({{<weekly product ID>.prod_price}} * 52)) * 100)
```

Pour ces prix, `saving_percent` est 54. Insérez `saving` ou `saving_percent` dans un élément texte de l'écran du paywall. Le builder ajoute le produit hebdomadaire à la fin de la liste des produits de l'écran. Sur l'appareil, la formule utilise les prix du store dans la devise de l'utilisateur. Le bouton d'achat de l'écran déclenche l'achat du produit annuel.

### Afficher la fin d'un essai et une date de rappel \{#show-the-end-of-a-trial-and-a-reminder-date\}

Créez une formule `trial_end` :

```
addOfferDuration(today(), {{products.selectedProduct}})
```

Ensuite, créez une formule `reminder` pour trois jours avant la fin de l'essai :

```
addDays({{trial_end}}, -3)
```

Pour un produit avec un essai gratuit de 7 jours, le 10 novembre 2026, `trial_end` correspond au 17 novembre 2026 et `reminder` au 14 novembre 2026. Avec le format de date **Medium**, le texte affiche « Nov 17, 2026 ». Avec **Month D**, il affiche « November 17 ».

### Afficher la durée d'un essai \{#show-the-length-of-a-trial\}

Utilisez la formule `trial_end` de [Afficher la fin d'un essai et une date de rappel](#show-the-end-of-a-trial-and-a-reminder-date), et créez une formule `trial_days` :

```
daysBetween(today(), {{trial_end}})
```

Dans un élément de texte, saisissez « Free for », insérez `trial_days`, puis saisissez « days ». Pour un produit avec un essai gratuit de 7 jours, le texte affichera « Free for 7 days ». Lorsque le produit sélectionné ne comporte pas d'offre, `trial_end` n'a pas de valeur. Pour n'afficher le texte que pour un produit avec une offre, donnez à l'élément de texte une règle de [visibilité conditionnelle](onboarding-element-visibility) : `trial_end` **Is not empty**.

### Afficher l'âge d'un utilisateur \{#show-the-age-of-a-user\}

Ajoutez un champ Date avec l'ID d'élément `birth_date`, et créez une formule `age` :

```
yearsBetween({{birth_date.value}}, today())
```

Pour les utilisateurs nés le 25 novembre 2000, `age` vaut 25 le 24 novembre 2026, et 26 le 25 novembre 2026. Tant que le champ est vide, `age` n'a pas de valeur.

### Afficher une taille en pieds et en pouces \{#show-a-height-in-feet-and-inches\}

Ajoutez un champ de saisie numérique avec l'ID d'élément `height` pour la taille en centimètres. Créez trois formules :

- `total` : `round({{height.value}} / 2.54)`, la taille en pouces entiers.
- `feet` : `floor({{total}} / 12)`.
- `inches` : `mod({{total}}, 12)`.

Dans un élément texte, insérez `feet`, tapez « ft », insérez `inches`, puis tapez « in ». Pour 180 cm, le texte affiche « 5 ft 11 in ». Pour 140 cm, il affiche « 4 ft 7 in ».

## Résolution des problèmes \{#troubleshooting\}

Lorsque vous quittez le champ **Expression**, le builder affiche la première erreur de la formule sous le champ. Quelques exemples :

| Texte d'erreur | Cause et solution |
| :--- | :--- |
| `addDays() needs a date and a number` | Une fonction reçoit un mauvais nombre d'arguments ou un argument du mauvais type. Utilisez les arguments des tableaux [Fonctions numériques](#number-functions) ou [Fonctions de date](#date-functions). |
| `Unknown function "flor". Use one of: …` | Le nom de la fonction est mal orthographié ou sa casse est incorrecte. Utilisez une fonction de la liste indiquée dans l'erreur. Pour lire une variable, placez son nom dans `{{ }}`. |
| `Use a dot in a decimal number, like 1.5` | Un nombre hors d'une fonction contient une virgule. Remplacez la virgule par un point décimal. À l'intérieur d'une fonction, le builder interprète la virgule comme séparateur entre les arguments ; utilisez donc un point décimal à la place. |
| `{{…}} is not a variable, an answer or a product field of this flow` | Aucune variable, aucun ID d'élément ou groupe de produits ne porte ce nom. Corrigez le nom ou créez la variable. |
| `{{…}}: the product … is not in the product catalog of the app` | Vous avez supprimé le produit de votre catalogue Adapty. La puce affiche **Missing product**. Remplacez le prix par celui d'un autre produit. |
| `Offers, billing plans and fields other than prod_price, … of a catalog product are not supported yet` | La formule lit une offre, un plan de facturation ou un autre champ d'un produit de votre catalogue Adapty. Insérez le prix depuis l'onglet **Products** de **Insert variable**. |
| `This variable no longer exists. Pick another one.` | Vous avez supprimé une variable que la formule utilise. Le champ **Expression** l'affiche sous forme de puce **deleted variable**. Remplacez-la par une autre référence. |
| `{{…}} is the name of a variable and of an element answer: rename the variable` | Le nom correspond à deux valeurs. Renommez la variable personnalisée. |
| `{{…}} uses this formula: formulas cannot use each other in a loop` | Les références entre formules forment un cycle : par exemple, la formule A lit la formule B, et la formule B lit la formule A. Supprimez l'une des références. |

<ZoomImage id="flow-formula-error.webp" width="300px" alt="Une erreur de fonction inconnue sous le champ Expression, avec la liste des fonctions disponibles" />

Une formule contenant une erreur bloque la publication. La boîte de dialogue **Can't publish yet** liste chaque formule en erreur sous **Variables**. Pour les erreurs pouvant apparaître lors de la publication, consultez [Problèmes courants](flow-common-issues#a-flow-wont-preview-or-publish).

## Limitations \{#limitations\}

- **Nombres et dates uniquement** : une formule ne renvoie qu'un nombre ou une date. Pour afficher du texte qui dépend du résultat, ajoutez du [texte conditionnel](onboarding-text#add-conditional-text) à un élément texte. Par exemple, pour afficher « Élevé » pour un IMC supérieur à 25, définissez la condition **if** sur `bmi` **Greater than** `25`, et saisissez « Élevé » sous **then**.
- **Produits du catalogue** : une formule ne lit que le prix et les prix par période d'un produit de votre catalogue Adapty, sans offre ni plan de facturation. Pour utiliser un prix d'offre, lisez `offer_price` du produit sélectionné dans un groupe de produits.
- **Produit sélectionné** : une formule qui lit le produit sélectionné n'a aucune valeur tant que l'utilisateur n'a pas choisi un produit. Pour afficher le résultat dès l'ouverture de l'écran, sélectionnez **Set as default** sur l'une des cartes produit.
- **Offres sur iOS et Android** : sur iOS, le SDK Adapty transmet une seule offre au flow. Parmi les offres disponibles pour l'utilisateur, une offre de reconquête est prioritaire, suivie d'une offre promotionnelle, puis d'une offre de lancement. Sur Android, le SDK Adapty ne transmet que la première phase de l'offre de lancement. Pour un essai gratuit suivi d'un prix réduit, `addOfferDuration` sur Android n'ajoute que l'essai.
