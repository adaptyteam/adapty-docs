:::tip
Vous pouvez obtenir un plan de test A/B concret sans faire la recherche vous-même. Demandez à votre agent IA avec le [skill growth-advisor](export-analytics-with-ai) : il évalue vos chiffres par rapport au marché, propose des hypothèses et configure leurs tests A/B. Les hypothèses que vous conservez apparaissent sur la page [AI Growth Advisor](autopilot).
:::

Boostez les revenus de votre application en lançant des tests A/B dans Adapty. Comparez différents flows, paywalls et onboardings pour trouver ce qui convertit le mieux — sans modifier le code. Par exemple, vous pouvez tester :

- Les prix des abonnements
- Le design, les textes et la mise en page des paywalls
- Les périodes d'essai et les durées d'abonnement
- Les designs d'onboarding

## Prérequis \{#prerequisites\}

Avant de configurer un test A/B, vous devez disposer de :

- **Placements** : Un ou plusieurs [placements](placements) où un flow, un paywall ou un onboarding est affiché.
- **Pour les flows** : Au moins deux [flows](adapty-flow-builder).
- **Pour les paywalls** : Au moins deux [paywalls](paywalls).
- **Pour les onboardings** : Au moins deux [onboardings](onboardings).

:::warning
Si vous n'utilisez pas le [Adapty Flow & Paywall Builder](adapty-flow-builder) ou l'[ancien Adapty Paywall Builder](adapty-paywall-builder), [envoyez les vues de paywall à Adapty](present-remote-config-paywalls#track-paywall-view-events) avec `.logShowFlow()` (iOS SDK v4+) / `.logShowPaywall()`. Sans cette méthode, Adapty ne peut pas calculer les vues du paywall dans le test, et les statistiques de conversion seront inexactes.
:::

## Types de tests A/B \{#ab-test-types\}

Adapty prend en charge deux types de tests A/B principaux :

- **Regular** : S'exécute sur un seul placement de flow/paywall/onboarding.
- **Crossplacement** : S'exécute sur plusieurs placements de flow ou de paywall, en affichant la même variante à un utilisateur partout.

Pour une comparaison complète des types, des cas d'usage et des règles de priorité, consultez [Types de tests A/B](ab-test-types).
