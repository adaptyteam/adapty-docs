:::tip
Vous pouvez obtenir un plan de test A/B actionnable sans faire de recherche vous-même. [AI Growth Advisor](autopilot) analyse votre paywall, compare vos concurrents et génère des suggestions à partir de données anonymisées issues de 20 000 applications d'abonnement suivies par Adapty.
:::

Boostez les revenus de votre application en lançant des tests A/B dans Adapty. Comparez différents flows, paywalls et onboardings pour découvrir ce qui convertit le mieux — sans modifier votre code. Par exemple, vous pouvez tester :

- Les prix des abonnements
- Le design, le texte et la mise en page des paywalls
- Les périodes d'essai et les durées d'abonnement
- Les designs d'onboarding

## Prérequis \{#prerequisites\}

Avant de configurer un test A/B, vous devez disposer de :

- **Placements** : Un ou plusieurs [placements](placements) où un flow, un paywall ou un onboarding est affiché.
- **Pour les flows** : Au moins deux [flows](adapty-flow-builder).
- **Pour les paywalls** : Au moins deux [paywalls](paywalls).
- **Pour les onboardings** : Au moins deux [onboardings](onboardings).

:::warning
Si vous n'utilisez pas le [Adapty Flow & Paywall Builder](adapty-flow-builder) ou l'[ancien Adapty Paywall Builder](adapty-paywall-builder), [envoyez les vues de paywall à Adapty](present-remote-config-paywalls#track-paywall-view-events) avec `.logShowFlow()` (iOS SDK v4+) / `.logShowPaywall()`. Sans cette méthode, Adapty ne peut pas calculer les vues du paywall dans le test, et les statistiques de conversion seront inexactes.
:::

## Types de tests A/B \{#ab-test-types\}

Adapty propose deux types principaux de tests A/B :

- **Classique** : s'exécute sur un seul placement de flow/paywall/onboarding.
- **Crossplacement** : s'étend sur plusieurs placements de paywall, en affichant la même variante à un utilisateur partout. Disponible uniquement pour les paywalls pour l'instant.

Pour une comparaison complète des types, des cas d'utilisation et des règles de priorité, consultez [Types de tests A/B](ab-test-types).
