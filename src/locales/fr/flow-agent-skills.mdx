Les compétences d'agent permettent à votre outil de codage IA de travailler sur les flows depuis le terminal, via l'[Adapty CLI](developer-cli-quickstart) plutôt que via l'éditeur visuel. Vous décrivez ce que vous voulez en langage naturel ; l'outil lit votre compte, effectue le travail et vous montre le résultat avant que quoi que ce soit ne soit enregistré.

Trois compétences, chacune avec un rôle distinct : une pour créer et modifier des flows, une pour vérifier qu'un flow est prêt à être publié, et une pour migrer une application qui utilise encore des paywalls vers des placements de type flow. Les trois font partie du même plugin, donc une seule installation suffit pour toutes les obtenir.

<CustomDocCardList />

Utilisez **flow-generator** quand vous savez ce que vous voulez modifier — une nouvelle locale, des textes réécrits, un écran ajouté ou supprimé, une branche recâblée. Il modifie la config et enregistre un brouillon pour votre validation ; il ne publie jamais.

Utilisez **flow-audit** quand vous voulez savoir si un flow est prêt. Il analyse le flow et votre catalogue de produits, signale ce qui poserait problème pour un vrai utilisateur, et transmet les corrections à flow-generator.

Utilisez **migrate-placements** quand votre application fonctionne encore avec des paywalls. Il ne touche pas au contenu des flows — il lit vos placements de paywalls et crée un placement de flow pour chacun, puis vous fournit les ID de placements et l'appel SDK à modifier.

Aucun de ces outils ne remplace l'[AI Editor](flow-ai-editor), qui fonctionne directement dans le Flow & Paywall Builder. Les compétences de l'agent s'exécutent dans votre terminal, dans la même session que le code de votre application.
