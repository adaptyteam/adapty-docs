Les skills d'agent permettent à votre outil IA de travailler sur des flows via le [CLI Adapty](developer-cli-quickstart) ou le [serveur MCP Adapty](adapty-mcp), plutôt que via l'éditeur visuel. Vous décrivez ce que vous voulez en langage naturel ; l'outil lit votre compte, fait le travail et vous montre le résultat avant que quoi que ce soit ne soit enregistré.

Trois skills, et ils se partagent le travail : l'un crée et modifie des flows, l'autre vérifie qu'un flow est prêt à être publié, et le dernier migre une app qui utilise encore des paywalls vers des placements de flows. Les trois sont inclus dans le [plugin Adapty](manage-adapty-with-ai), donc une seule installation suffit pour tout avoir.

<CustomDocCardList />

Utilisez **flow-generator** quand vous savez ce que vous voulez changer — une nouvelle locale, des textes réécrits, un écran ajouté ou supprimé, une branche recâblée. Il modifie la configuration et enregistre un brouillon pour votre validation ; il ne publie jamais.

Utilisez **flow-audit** pour vérifier si un flow est terminé. Il lit le flow et votre catalogue de produits, signale ce qui ne fonctionnerait pas pour un vrai utilisateur, et transmet les corrections à flow-generator.

Utilisez **migrate-placements** si votre application utilise encore des paywalls. Il ne touche pas au contenu du flow — il lit vos placements de paywalls, crée un placement de flow pour chacun, puis vous transmet les IDs de placement et l'appel SDK à modifier.

Aucun de ces éléments ne remplace l'[Éditeur IA](flow-ai-editor), qui fonctionne directement dans le Flow & Paywall Builder. Les skills d'agent s'exécutent dans votre propre outil IA : un agent de codage, dans la même session que le code de votre application, ou claude.ai.
