Les skills d'agent permettent à votre outil IA de travailler sur des flows via le [CLI Adapty](developer-cli-quickstart) ou le [serveur MCP Adapty](adapty-mcp), plutôt que via l'éditeur visuel. Vous décrivez ce que vous voulez en langage naturel ; l'outil lit votre compte, fait le travail et vous montre le résultat avant que quoi que ce soit ne soit enregistré.

Quatre skills, et chacun a son rôle : l'un crée et modifie les flows, l'autre vérifie qu'un flow peut être publié en toute sécurité, le troisième s'assure que les stores l'accepteront, et le dernier migre une application qui utilise encore des paywalls vers des placements de flows. Les quatre sont inclus dans le [plugin Adapty](manage-adapty-with-ai), une seule installation suffit pour tous les avoir.

Utilisez **flow-generator** quand vous savez ce que vous voulez modifier — une nouvelle locale, des textes réécrits, un écran ajouté ou supprimé, une branche recâblée. Il modifie la configuration et enregistre un brouillon pour votre validation ; il ne publie jamais rien.

Utilisez **flow-audit** pour vérifier si un flow est prêt. Il lit le flow et votre catalogue de produits, signale ce qui ne fonctionnerait pas pour un vrai utilisateur, et transmet les corrections à flow-generator.

Utilisez **[paywall-compliance](paywall-compliance-skill)** avant de soumettre votre app à la revue de l'App Store ou Google Play. Il vérifie un flow, des captures d'écran ou le code de votre app par rapport aux règles du store et aux lois de protection des consommateurs sur les abonnements, et intègre les motifs de rejet récemment signalés par les développeurs.

Utilisez **migrate-placements** quand votre application utilise encore des paywalls. Ce skill ne touche pas au contenu des flows — il lit vos placements de paywalls, crée un placement de flow pour chacun, puis vous fournit les IDs de placement et l'appel SDK à modifier.

Aucun de ces skills ne remplace l'[Éditeur IA](flow-ai-editor), qui fonctionne directement dans le Flow & Paywall Builder. Les skills d'agent s'exécutent dans votre propre outil IA : un agent de code, dans la même session que le code de votre application, ou sur claude.ai.
