Les compétences d'agent permettent à votre propre outil de codage IA de travailler sur des flows depuis le terminal, via l'[Adapty CLI](developer-cli-quickstart) plutôt qu'avec l'éditeur visuel. Vous décrivez ce que vous souhaitez en langage naturel ; l'outil lit la configuration du builder du flow, effectue le travail et vous montre le résultat avant que quoi que ce soit ne soit sauvegardé.

Deux compétences, qui fonctionnent en binôme : l'une crée et modifie des flows, l'autre vérifie si un flow est prêt à être publié. Les deux sont incluses dans le même plugin, donc une seule installation vous donne accès aux deux.

<CustomDocCardList />

Utilisez **flow-generator** lorsque vous savez ce que vous souhaitez modifier — une nouvelle locale, un texte réécrit, un écran ajouté ou supprimé, une branche reconfigurée. Il modifie la config et enregistre un brouillon pour votre validation ; il ne publie jamais.

Utilisez **flow-audit** lorsque vous voulez savoir si un flow est terminé. Il lit le flow et votre catalogue de produits, signale ce qui poserait problème pour un vrai utilisateur, et transmet les corrections à flow-generator.

Aucune de ces deux compétences ne remplace l'[AI Editor](flow-ai-editor), qui fonctionne directement dans le Flow Builder. Les compétences de l'agent s'exécutent dans votre terminal, dans la même session que le code de votre application.
