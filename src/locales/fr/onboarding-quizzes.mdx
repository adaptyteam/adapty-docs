Utilisez les quiz pour proposer aux utilisateurs des choix prédéfinis. Contrairement aux champs de saisie, les quiz ne comportent pas de champs texte — les utilisateurs sélectionnent parmi les options que vous définissez. Servez-vous-en pour recueillir des préférences, segmenter les utilisateurs ou faire bifurquer le flow en fonction de leurs réponses.

### Ajouter un quiz \{#add-a-quiz\}

<ZoomImage id="quiz.webp" width="400px" float="left" alt="Add input" />

1. Cliquez sur **+** en haut à gauche.
2. Sélectionnez **Quiz**.
3. Choisissez le type de quiz :
   - **Options avec icône/image/emoji :** une liste verticale d'options sélectionnables, chacune avec une icône, une image ou un emoji accompagné d'un libellé texte.
   - **Grille avec icône/image/emoji :** une grille d'options sélectionnables, chacune avec une icône, une image ou un emoji.
   - **Note :** une échelle permettant aux utilisateurs d'exprimer une évaluation — numérique ou sous forme d'étoiles.

### Configurer la navigation conditionnelle \{#set-up-conditional-navigation\}

Pour rediriger les utilisateurs différemment selon leur sélection, définissez une action conditionnelle sur le **bouton de navigation**, et non sur l'option du quiz :

1. Sélectionnez le bouton de navigation.
2. Dans le panneau **Interactions**, ajoutez un déclencheur **On Tap** avec une action **Conditional**.
3. Dans la boîte de dialogue **Edit Action**, construisez la ligne **if** :
   - À gauche, cliquez sur `{}` et sélectionnez **Elements → Screen → `<quizElementId>.selectedOptionId`** pour référencer la sélection de l'utilisateur.
   - Laissez l'opérateur sur `=`.
   - À droite, saisissez l'elementId à faire correspondre — par exemple, `rock`.
4. Sous **then**, définissez l'action **Navigate to** et choisissez l'écran de destination.
5. Sous **else**, définissez une destination **Navigate to** de secours, ou cliquez sur **+ Add else/if** pour ajouter d'autres conditions pour d'autres options.

### Changer le type de quiz \{#change-quiz-type\}

Par défaut, un quiz est en **choix multiple** — les utilisateurs peuvent sélectionner plusieurs options à la fois. Passez en **choix unique** si vous souhaitez que les utilisateurs n'en choisissent qu'une seule.

1. Sélectionnez l'écran contenant le quiz.
2. Dans **Screen settings**, faites défiler jusqu'à **Selectable groups** et cliquez sur votre quiz.
3. Dans la boîte de dialogue **Edit group**, ouvrez **Group type** et choisissez :
   - **Single choice** — une seule option peut être sélectionnée à la fois.
   - **Multi choice** — les utilisateurs peuvent sélectionner plusieurs options.
4. Cliquez sur **Save**.
