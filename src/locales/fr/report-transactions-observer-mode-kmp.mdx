<SDKv4>

En mode Observer, le SDK Adapty ne peut pas suivre automatiquement les achats effectués via votre système d'achat existant. Vous devez lui signaler les transactions depuis votre store. Il est crucial de configurer cela **avant** de publier votre application pour éviter les erreurs dans les analyses.

Utilisez `reportTransaction` pour signaler explicitement chaque transaction afin qu'Adapty puisse la reconnaître.

:::warning
**Ne négligez pas le signalement des transactions !**
Si vous n'appelez pas `reportTransaction`, Adapty ne reconnaîtra pas la transaction, elle n'apparaîtra pas dans les analyses et ne sera pas envoyée aux intégrations.
:::

Si vous utilisez des flows et des paywalls Adapty, incluez le `variationId` lors du signalement d'une transaction. Cela associe l'achat au flow ou au paywall qui l'a déclenché, garantissant ainsi une analyse précise.

```kotlin showLineNumbers

Adapty.reportTransaction(
    transactionId = "your_transaction_id",
    variationId = product.paywallVariationId // the AdaptyPaywallProduct the user bought
).onSuccess {
    // Transaction reported successfully
}.onError { error ->
    // handle the error
}
```

Paramètres :

| Paramètre       | Présence | Description                                                                                                                                                                                  |
| --------------- | -------- |----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| transactionId   | requis | <ul><li> Pour iOS : Identifiant de la transaction.</li><li> Pour Android : Identifiant de type chaîne (`purchase.getOrderId`) de l'achat, où l'achat est une instance de la classe [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) de la bibliothèque de facturation.</li></ul>                                                       |
| variationId     | optionnel | L'identifiant de type chaîne de la variante. Passez le `paywallVariationId` du `AdaptyPaywallProduct` acheté par l'utilisateur. C'est la même valeur que le `variationId` du [AdaptyFlowPaywall](https://kmp.adapty.io/adapty/com.adapty.kmp.models/-adapty-flow-paywall/) qui contient ce produit. |

</SDKv4>

Paramètres :

| Paramètre       | Présence | Description                                                                                                                                                                                  |
