Pour mettre à jour votre application depuis le SDK iOS Adapty 4.3 vers la version 4.4, appliquez chacune des modifications décrites dans ce guide. Si votre application utilise la version 4.1 ou 4.2, vous devez d'abord appliquer les [modifications de la v4.3](migration-to-ios-sdk-43), et si elle est en version 4.0, appliquez les [modifications de la v4.1](migration-to-ios-sdk-41) avant cela. Pour passer ensuite à la version 4.5, suivez le guide [Migrer vers la v4.5](migration-to-ios-sdk-45).

:::warning
Le format du fichier de secours a changé dans la version 4.4, et le compilateur ne peut pas détecter un fichier obsolète. Sans un [nouveau fichier de secours](#fallback-files), chaque placement perdra son paywall de secours.
:::

## Référence rapide \{#quick-reference\}

| Avant | Après |
|---|---|
| `case let .custom(id)` | `case let .custom(id, _)` |
| `AdaptyUICustomAsset` | `AdaptyUIAsset` ; `AdaptyCustomAsset` reste inchangé |
| `.color(.uiColor(x))` et `.color(.swiftUIColor(c))` | `.color(Color(uiColor: x))` et `.color(c)` |
| `AdaptyUICustomFontAsset(font:defaultColor:defaultLetterSpacing:defaultLineHeight:)` | `AdaptyUIFontAsset(font:color:letterSpacing:lineHeight:)` |
| Pas d'assets de données | `AdaptyUIAsset` inclut `.data` pour les assets de données |
| `AdaptyProduct.localizedBillingPeriod` | `subscriptionPricingTerms?.localizedBillingPeriod` |
| Fichier de secours téléchargé pour 4.1–4.3 | Nouveau format de fichier de secours ; téléchargez à nouveau le fichier |

## AdaptyUI.Action.custom contient deux valeurs \{#custom-actions\}

Lorsqu'un utilisateur appuie sur un bouton avec une action personnalisée, votre application reçoit `AdaptyUI.Action.custom`. Depuis la version 4.4, elle contient une deuxième valeur, `arguments`, après l'ID de l'action. Dans le closure `didPerformAction` et la méthode delegate `flowController(_:didPerform:)`, ajoutez `_` pour cette deuxième valeur :

```diff showLineNumbers
  switch action {
- case let .custom(id):
+ case let .custom(id, _):
      if id == "openNewPaywall" {
          // Display another flow or paywall
      }
  default:
      break
  }
```

Code that compares `id` to a string stops compiling until you add `_`. Other code still builds, with the warning "enum case 'custom' has 2 associated values; matching them as a tuple is deprecated". In that code, `id` contains both values, not the action ID alone. Add `_` wherever Xcode shows this warning.

## Ressources personnalisées \{#custom-assets\}

Dans la version 4.4, `AdaptyUICustomAsset` est renommé en `AdaptyUIAsset`. L'ancien nom déclenche un avertissement de dépréciation.

Les ressources de couleur, de police et de données changent de trois façons :

- **Ressources de couleur** : `.color` prend une `Color` SwiftUI. `AdaptyUICustomColorAsset` est supprimé. Enveloppez une `UIColor` dans `Color(uiColor:)` et passez directement une `Color` SwiftUI :

  ```diff showLineNumbers
  - "brand_color": .color(.uiColor(brandColor)),
  + "brand_color": .color(Color(uiColor: brandColor)),
  ```

- **Ressources de police** : `AdaptyUIFontAsset` prend `color:`, `letterSpacing:` et `lineHeight:` au lieu de `defaultColor:`, `defaultLetterSpacing:` et `defaultLineHeight:`. Le paramètre `color:` accepte une `Color` SwiftUI :

  ```diff showLineNumbers
  - "title_font": .font(AdaptyUICustomFontAsset(font: titleFont, defaultColor: .uiColor(.white), defaultLineHeight: 24)),
  + "title_font": .font(AdaptyUIFontAsset(font: titleFont, color: .white, lineHeight: 24)),
  ```

- **Ressources de données** : `AdaptyUIAsset` inclut un nouveau type de ressource, `.data`. Une instruction `switch` qui liste chaque type de ressource sans branche `default` cesse de compiler. Seuls les [éléments personnalisés](ios-flow-custom-elements) lisent les ressources de données, donc la nouvelle branche peut être vide : `case .data: break`.

## AdaptyProduct.localizedBillingPeriod est déprécié \{#localizedbillingperiod-is-deprecated\}

`AdaptyProduct` a une propriété [`subscriptionPricingTerms`](fetch-paywalls-and-products) qui décrit chaque paiement pour le produit : son prix et la fréquence à laquelle l'utilisateur paie. Dans la version 4.4, `localizedBillingPeriod`, le texte indiquant la fréquence de paiement de l'utilisateur, est déplacé de `AdaptyProduct` vers `subscriptionPricingTerms`. `AdaptyProduct.localizedBillingPeriod` fonctionne toujours, avec un avertissement de dépréciation : il renvoie `subscriptionPricingTerms?.localizedBillingPeriod`. Pour supprimer cet avertissement, lisez la propriété depuis les termes de tarification :

```diff showLineNumbers
- let period = product.localizedBillingPeriod
+ let period = product.subscriptionPricingTerms?.localizedBillingPeriod
```

## Fichiers de secours \{#fallback-files\}

Le format du [fichier de secours](fallback-flows) a changé dans le SDK 4.4. Téléchargez à nouveau le fichier depuis **[Placements](https://app.adapty.io/placements)** > **Fallbacks**, sélectionnez **Adapty SDK v4.4.0 and higher**, et intégrez-le dans votre application.

Le fichier téléchargé s'appelle `ios_4_4_0_fallback.json`. Donnez-lui le nom que votre application passe à `Bundle.main.url(forResource:withExtension:)`, ou mettez à jour ce nom dans cet appel.

:::warning
Un fichier de secours obsolète ne génère aucune erreur de compilation. Chaque placement perd silencieusement son paywall de secours. Le log du SDK affiche alors « The fallback paywalls version is not correct. Download a new one from the Adapty Dashboard. »
:::
