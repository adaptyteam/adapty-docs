Le CLI nécessite une authentification pour appeler l'API Adapty.

Une seule connexion couvre l'ensemble du CLI. Les [commandes de l'Ads Manager](developer-cli-ads-manager) font appel à un service différent, mais elles utilisent le même token stocké — il n'y a pas de deuxième étape de connexion.

## Se connecter \{#log-in\}

Pour vous connecter :

1. Dans votre terminal, exécutez :
   ```bash
   adapty auth login
   ```
2. La CLI affiche un code de vérification au format `XXXX-XXXX` et ouvre l'Adapty Dashboard dans votre navigateur.
3. Sur la page d'autorisation, vérifiez que le code correspond à celui affiché dans votre terminal.
4. Cliquez sur **Authorize**. Le navigateur affiche « CLI authorized! You can close this tab. »
5. De retour dans le terminal, la CLI confirme que vous êtes authentifié.

Si le code expire avant que vous n'ayez autorisé, ou si vous cliquez sur **Deny**, relancez la commande suivante pour redémarrer le flow :

```bash
adapty auth login
```

## Gérer l'authentification \{#manage-authentication\}

### Vérifier le statut d'authentification \{#check-authentication-status\}

Pour consulter votre état d'authentification actuel, exécutez :

```bash
adapty auth status
```

Lorsque vous êtes authentifié, la sortie affiche votre e-mail, un préfixe de token masqué et le chemin vers le fichier de configuration local :

```
Email: you@example.com
Token: abcd1234****
Config: ~/.config/adapty/config.json
```

Lorsque vous n'êtes pas authentifié :

```
Not authenticated. Run `adapty auth login`.
```

### Vérifiez votre token \{#verify-your-token\}

Pour confirmer que votre token est valide et consulter les détails de votre compte, exécutez :

```bash
adapty auth whoami
```

Contrairement à `adapty auth status`, cette commande envoie une requête au serveur pour vérifier le token.

### Se déconnecter \{#log-out\}

Pour effacer vos identifiants stockés localement, exécutez :

```bash
adapty auth logout
```

Cette commande supprime `~/.config/adapty/config.json`. Le token reste valide côté serveur jusqu'à son expiration — si vous souhaitez l'invalider immédiatement, utilisez plutôt `adapty auth revoke`.

### Révoquer votre token \{#revoke-your-token\}

Pour invalider le token côté serveur et le supprimer localement, exécutez :

```bash
adapty auth revoke
```

Utilisez cette commande pour invalider complètement un token — par exemple, si vos identifiants ont pu être compromis. Après révocation, lancez `adapty auth login` pour vous authentifier à nouveau.

## Erreurs de token \{#token-errors\}

Si un token est révoqué ou devient invalide, les commandes CLI retournent une erreur 401. Pour vous authentifier à nouveau, exécutez :

```bash
adapty auth login
```
