Exporter vos données analytiques en CSV vous offre la flexibilité d'explorer plus en détail les métriques de performance de votre application, de personnaliser des rapports et d'analyser les tendances dans le temps. Avec l'API Adapty, vous pouvez facilement extraire des analyses détaillées au format CSV, ce qui facilite le suivi, le partage et l'affinement de vos données selon vos besoins.

## Collection et environnement Postman \{#postman-collection-and-environment\}

Pour simplifier l'utilisation de notre API d'export de données analytiques, nous avons préparé une collection Postman et un fichier d'environnement que vous pouvez télécharger et importer dans Postman.

- **Collection de requêtes** : Inclut toutes les requêtes disponibles dans l'API d'export analytics d'Adapty. Elle utilise des variables que vous pouvez définir dans l'environnement.
- **Environnement** : Contient une liste de variables où vous pouvez définir des valeurs une seule fois. Nous avons préparé un environnement unifié pour l'API côté serveur, l'API web et l'API d'export analytics pour vous simplifier la tâche. Une fois cet environnement activé, Postman substitue automatiquement les valeurs des variables définies dans vos requêtes.

:::tip

[Télécharger la collection et l'environnement](https://raw.githubusercontent.com/adaptyteam/adapty-docs/refs/heads/main/Downloads/Adapty_export_analytics_API_postman_collection.zip)

:::

Pour savoir comment importer une collection et un environnement dans Postman, consultez la [documentation Postman](https://learning.postman.com/docs/getting-started/importing-and-exporting/importing-data/).
