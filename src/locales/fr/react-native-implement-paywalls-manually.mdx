## Accepter les achats \{#accept-purchases\}

Si vous travaillez avec des paywalls que vous avez implémentés vous-même, vous pouvez déléguer la gestion des achats à Adapty en utilisant la méthode `makePurchase`. Ainsi, nous gérerons tous les scénarios utilisateur, et vous n'aurez qu'à traiter les résultats des achats.

:::important
`makePurchase` fonctionne avec les produits créés dans Adapty Dashboard. Assurez-vous de configurer les produits et les moyens de les récupérer dans le tableau de bord en suivant le [guide de démarrage rapide](quickstart).
:::

## Mode observateur \{#observer-mode\}

Si vous souhaitez implémenter votre propre logique de gestion des achats de A à Z, mais souhaitez tout de même bénéficier des analyses avancées d'Adapty, vous pouvez utiliser le mode observateur.

:::important
Consultez les limitations du mode observateur [ici](observer-vs-full-mode).
