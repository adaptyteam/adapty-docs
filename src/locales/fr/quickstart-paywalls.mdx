:::info
Pour suivre ce guide, assurez-vous d'avoir effectué l'[intégration du store](integrate-payments) et créé au moins un produit comme décrit dans le [guide précédent sur l'ajout de produits](quickstart-products).
:::

Maintenant que vous avez des produits, vous devez les présenter à vos utilisateurs. Adapty vous propose deux options :

- **Flow & Paywall Builder (recommandé)** : éditeur visuel sans code pour tout le parcours d'achat. Le SDK Adapty affiche le résultat nativement, sans aucun code UI à écrire.
- **Paywall personnalisé** : vous créez un paywall personnalisé, y associez des produits et gérez vous-même l'affichage dans le code de l'application.

Les deux options aboutissent au même endroit : vous associez ce que vous avez créé à un [placement](placements). C'est le placement que votre application appelle à l'exécution pour récupérer le bon contenu pour le bon utilisateur.

:::important
Les flows nécessitent le SDK Adapty v4.0 ou une version ultérieure.
:::

Un flow est composé d'un ou plusieurs écrans avec des produits intégrés directement. Vous le concevez dans le [Flow & Paywall Builder](adapty-flow-builder) — sans code.

Le SDK Adapty affiche les flows nativement sur chaque plateforme. Votre app appelle `getFlow`, et le SDK présente les écrans, gère les achats et remonte les événements. Pas de code d'interface séparé, pas de paywall à maintenir en parallèle.

## 1. Créer le flow \{#1-build-the-flow\}

1. Rendez-vous dans [**Flows & Paywalls**](https://app.adapty.io/flows) depuis le menu principal d'Adapty et ouvrez l'onglet **Flow & Paywall builder**.
2. Cliquez sur **Create flow** et concevez votre flow.

Apprenez-en plus sur le [Adapty Flow & Paywall Builder](adapty-flow-builder).

:::tip
Pour créer le flow depuis votre outil de codage IA, installez le [plugin `adapty-skills`](flow-generator-skill#install-the-skill). Son skill flow-generator crée un flow à partir d'une description textuelle ou d'une capture d'écran et l'enregistre en tant que brouillon. Avant de publier, son [skill flow-audit](flow-audit-skill) vérifie que le flow est prêt pour la production.
:::

Une fois votre flow enregistré et publié, passez à son intégration dans un placement.

:::warning
N'oubliez pas de publier le flow ! Si vous ne le publiez pas, vous ne pouvez pas l'ajouter à un placement.
:::

### 2. Ajouter le flow à un placement \{#2-add-the-flow-to-a-placement\}

Créez un <InlineTooltip tooltip="placement">Un placement est un point précis de votre application où vous affichez un flow, un paywall, un onboarding ou un test A/B. Les placements vous permettent de cibler des [audiences](audience) spécifiques avec votre contenu. En savoir plus sur les [placements](placements).</InlineTooltip> pour que votre application puisse demander le flow au moment de l'exécution.

Commençons par le plus essentiel — le placement d'onboarding. Ensuite, vous pourrez ajouter d'autres [placements pertinents](choose-meaningful-placements) tout au long du parcours utilisateur.

1. Accédez à [**Placements**](https://app.adapty.io/placements) dans le menu principal d'Adapty et passez à l'onglet **Flows**.
2. Cliquez sur **Create placement**.
3. Saisissez un **Placement name** (par exemple, `main` ou `onboarding`). Il s'agit d'un identifiant interne dans l'Adapty Dashboard.
4. Saisissez un **Placement ID**. Vous utiliserez cet identifiant dans le SDK Adapty pour charger le flow du placement.
5. Cliquez sur **Run flow** et choisissez le flow que vous venez de créer.
6. Cliquez sur **Save & publish**.

Dans le code de votre application, vous n'intégrez en dur que les identifiants de placement. Tout le reste — quel flow s'exécute, quels produits il propose, comment il s'affiche — est configuré dans l'Adapty Dashboard et peut être modifié à tout moment sans mise à jour de l'application.

:::tip
Adapty vous permet de montrer différents flows à différents groupes d'utilisateurs et d'analyser leurs performances. En savoir plus sur les [audiences](audience) et les [tests A/B](ab-tests).
:::

Un paywall personnalisé est un conteneur configuré à distance pour un ou plusieurs produits. Adapty fournit la liste de produits et un payload JSON optionnel en [Remote Config](customize-paywall-with-remote-config) — votre code applicatif les lit et construit l'interface.

:::tip

### 1. Créer un paywall personnalisé \{#1-create-a-custom-paywall\}

1. Accédez à [**Flows & Paywalls**](https://app.adapty.io/paywalls) dans le menu principal d'Adapty et ouvrez l'onglet **Custom Paywalls**.
2. Cliquez sur **Create custom paywall**.
3. Saisissez un **Paywall name**. Il s'agit d'un identifiant interne dans l'Adapty Dashboard.
4. Cliquez sur **Add product** et sélectionnez les produits à afficher sur le paywall.
5. (Optionnel) Ouvrez l'onglet **Remote config** et ajoutez la payload JSON dont votre application a besoin (titres, textes, indicateurs de fonctionnalités). Consultez [Personnaliser un paywall avec le Remote Config](customize-paywall-with-remote-config) pour plus de détails.
6. Cliquez sur **Create as a draft**, puis publiez quand vous êtes prêt.
