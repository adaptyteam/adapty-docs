:::info
Pour suivre ce guide, assurez-vous d'avoir complété l'[intégration au store](integrate-payments) et d'avoir créé au moins un produit comme décrit dans le [guide précédent sur l'ajout de produits](quickstart-products).
:::

Maintenant que vous avez des produits, il vous faut un moyen de les présenter à vos utilisateurs. Adapty vous propose trois options :

- **Flow Builder (recommandé)** : Éditeur visuel no-code pour l'intégralité du parcours d'achat. Le SDK Adapty affiche le résultat nativement, sans aucun code d'interface à écrire.
- **Paywall manuel** : Vous créez un paywall, y associez des produits et gérez vous-même l'affichage dans le code de l'application.
- **Adapty Paywall Builder (Legacy)** : Éditeur de paywall no-code.

Les deux options aboutissent au même résultat : vous associez ce que vous avez créé à un [placement](placements). C'est le placement que votre application appelle à l'exécution pour récupérer le bon contenu pour le bon utilisateur.

:::important
Les flows nécessitent le SDK Adapty v4.0 ou version ultérieure.
:::

Un flow est un ou plusieurs écrans avec des produits intégrés directement. Vous le concevez dans le [Flow Builder](adapty-flow-builder) — aucun code requis.

Le SDK Adapty affiche les flows nativement sur chaque plateforme. Votre app appelle `getFlow`, et le SDK présente les écrans, gère les achats et remonte les événements. Ni code UI supplémentaire, ni paywall à maintenir en parallèle.

## 1. Créer le flow \{#1-build-the-flow\}

1. Accédez à [**Flows**](https://app.adapty.io/flows) dans le menu principal d'Adapty.
2. Cliquez sur **Create flow** et concevez votre flow.

En savoir plus sur le [Adapty Flow Builder](adapty-flow-builder).

### 2. Ajouter le flow à un placement \{#2-add-the-flow-to-a-placement\}

Créez un <InlineTooltip tooltip="placement">Un placement est un point précis de votre application où vous affichez un flow, un paywall, un onboarding ou un test A/B. Les placements vous permettent de cibler des [audiences](audience) spécifiques avec votre contenu. En savoir plus sur les [placements](placements).</InlineTooltip> pour que votre application puisse demander le flow au moment de l'exécution.

Commençons par le plus essentiel — le placement d'onboarding. Ensuite, vous pourrez ajouter d'autres [placements pertinents](choose-meaningful-placements) tout au long du parcours utilisateur.

1. Accédez à [**Placements**](https://app.adapty.io/placements) dans le menu principal d'Adapty et passez à l'onglet **Flows**.
2. Cliquez sur **Create placement**.
3. Saisissez un **Placement name** (par exemple, `main` ou `onboarding`). Il s'agit d'un identifiant interne dans l'Adapty Dashboard.
4. Saisissez un **Placement ID**. Vous utiliserez cet identifiant dans le SDK Adapty pour charger le flow du placement.
5. Cliquez sur **Run flow** et choisissez le flow que vous venez de créer.
6. Cliquez sur **Save & publish**.

Dans le code de votre application, vous codez en dur uniquement les identifiants de placement. Tout le reste — quel flow s'exécute, quels produits il vend, à quoi il ressemble — est configuré dans l'Adapty Dashboard et peut être modifié à tout moment sans mise à jour de l'application.

:::tip
Adapty vous permet de montrer différents flows à différents groupes d'utilisateurs et d'analyser les performances. En savoir plus sur les [audiences](audience) et les [tests A/B](ab-tests).
:::

Un paywall est un conteneur configuré à distance pour un ou plusieurs produits. Adapty fournit la liste de produits et un payload JSON [Remote Config](customize-paywall-with-remote-config) optionnel — votre code d'application les lit et construit l'interface.

:::tip
Vous configurez Adapty par programmation ? Vous pouvez effectuer cette étape avec la [Developer CLI](developer-cli-quickstart).
:::

### 1. Créer un paywall \{#1-create-a-paywall\}

1. Accédez à [**Paywalls**](https://app.adapty.io/paywalls) dans le menu principal d'Adapty.
2. Cliquez sur **Create paywall**.
3. Saisissez un **Paywall name**. Il s'agit d'un identifiant interne dans l'Adapty Dashboard.
4. Cliquez sur **Add product** et sélectionnez les produits à afficher sur le paywall.
5. (Facultatif) Ouvrez l'onglet **Remote config** et ajoutez la payload JSON dont votre application a besoin (titres, textes, feature flags). Consultez [Concevoir un paywall avec Remote Config](customize-paywall-with-remote-config) pour plus de détails.
6. Cliquez sur **Create as a draft**, puis publiez quand vous êtes prêt.
