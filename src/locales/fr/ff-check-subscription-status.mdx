---

Pour déterminer si un utilisateur a accès à un contenu payant spécifique, vous devez vérifier son niveau d'accès. Cela implique de s'assurer qu'il possède au moins un niveau d'accès et que ce niveau est bien celui requis.

Vous pouvez le faire en vérifiant le profil utilisateur, qui contient tous les niveaux d'accès disponibles.

Maintenant, permettons aux utilisateurs d'acheter votre produit :

1. Double-cliquez sur le bouton qui doit afficher le contenu payant et ouvrez la section **Actions** dans le panneau de droite si elle n'est pas déjà ouverte.

2. Ouvrez l'**Action Flow Editor**.

3. Dans la fenêtre **Select Action Trigger**, choisissez **On Tap**.

4. Dans la fenêtre **No Actions Created**, cliquez sur le bouton **Add Conditional Action**.

5. Cliquez sur **UNSET** pour définir les arguments d'action et choisissez la variable `currentProfile`. C'est la variable Adapty qui contient les données du profil de l'utilisateur actuel.

6. Remplissez les champs comme suit :
- **Available Options** : Data Structure Field
- **Select Field** : accessLevels
- **Available Options** : Filter List Items
- **Filter Conditions** :
  1. Sélectionnez **Conditions -> Single Condition** et cliquez sur **UNSET**.
  2. Dans le champ **First value**, sélectionnez **Item in list** comme **Source** et remplissez les champs comme suit :
     - **Available Options** : Data Structure Field
     - **Select Field** : accessLevelIdentifier
  3. Définissez l'opérateur de filtre sur **Equal to**.
  4. Cliquez sur **UNSET** à côté de **Second value** et dans le champ **Value**, entrez l'ID de votre niveau d'accès ; dans notre exemple, nous utilisons `premium`.

  5. Cliquez sur **Confirm** et continuez à remplir les autres champs ci-dessous.
- **Available Options** : Item at Index
- **List Index Options** : First
- **Available Options** : Data Structure Field
- **Select Field** : accessLevel
- **Available Options** : Data Structure Field
- **Select Field** : isActive

7. Cliquez sur **Confirm**.

Maintenant, ajoutez les actions qui définissent ce qui se passe ensuite — si l'utilisateur dispose ou non du bon abonnement. Redirigez-le vers la page réservée aux abonnés premium ou ouvrez la page du paywall pour qu'il puisse acheter l'accès.
