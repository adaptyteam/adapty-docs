L'intégration initiale n'est nécessaire que pour [l'App Store](initial_ios), [Google Play](initial-android), [Stripe](stripe) et [Paddle](paddle), car Adapty vérifie vos applications, produits et offres auprès de ces stores.

Adapty ne valide pas les données auprès d'autres stores et ne traite pas les achats effectués via ceux-ci. Vous pouvez néanmoins marquer les produits vendus par d'autres stores pour qu'Adapty accorde l'accès au contenu payant après un achat réussi, reflète les transactions dans vos analyses et les partage via des intégrations.

:::important

Assurez-vous que votre backend traite l'achat et envoie la transaction à Adapty via l'[API serveur d'Adapty](getting-started-with-server-side-api). Adapty n'accordera l'accès, ne déclenchera un événement de transaction, ne l'enverra aux intégrations et ne le reflétera dans les analyses qu'après réception de la transaction.

:::

Pour marquer un produit comme vendu via un store applicatif personnalisé, sélectionnez le store lors de la création du produit. Si le store dont vous avez besoin n'est pas répertorié, voici comment en créer un :

1. Sur la page **Products**, ouvrez le produit que vous souhaitez vendre via un store applicatif personnalisé.

2. Choisissez le store par lequel vous souhaitez vendre. S'il n'est pas dans la liste, cliquez sur le bouton **Create Custom Store**.

   <Zoom>
     <img src="/assets/shared/img/create_custom-appstore.webp"
     style={{

3. Saisissez le **Title** et le **Store ID** du store.
4. Cliquez sur le bouton **Create store**.

Si votre backend est correctement configuré, Adapty recevra les transactions de produits depuis ce store personnalisé, les reflétera dans les analyses, le [**Event Feed**](event-feed) et les [intégrations](https://app.adapty.io/integrations), et accordera les accès en conséquence.

## Tirez le meilleur parti de vos données de store personnalisé \{#get-more-from-your-custom-store-data\}

:::important
Pour que vos événements de store personnalisé fonctionnent avec les intégrations, vos utilisateurs doivent s'être connectés à l'application avec leur compte App Store/Google Play au moins une fois.
:::

Une fois votre intégration de store personnalisé configurée, Adapty est prêt à vous fournir des insights immédiatement. Pour exploiter au maximum vos données, vous pouvez configurer des intégrations Adapty supplémentaires afin de transférer les événements de store personnalisé — en regroupant toutes vos analyses d'abonnements dans un seul Adapty Dashboard.

Intégrations que vous pouvez utiliser pour transmettre et analyser vos événements de store personnalisés :
- [AppsFlyer](appsflyer)
- [Webhook](webhook)
- [Posthog](posthog)
