Si vous avez besoin de **déverrouiller manuellement des fonctionnalités premium** pour des utilisateurs ou groupes d'utilisateurs spécifiques, vous pouvez le faire via l'API Adapty. C'est utile pour les campagnes promotionnelles, l'accès investisseur ou les cas particuliers de support client.

Dans ce guide, vous apprendrez à identifier les utilisateurs et à leur accorder des niveaux d'accès par programmation.

#### Exemples d'utilisation \{#sample-use-cases\}

- **Codes promo** : Lorsqu'un utilisateur saisit un code promo valide dans votre application, accordez-lui automatiquement accès aux fonctionnalités premium.

- **Accès investisseurs/bêta-testeurs** : Offrez un accès premium aux investisseurs ou aux bêta-testeurs en vérifiant leurs attributs personnalisés.

:::note
**Codes promo Google Play** : Un achat effectué en utilisant un code promo Google Play peut arriver sans `orderId`. La validation des achats uniques (hors abonnement) d'Adapty nécessite un `orderId`, donc ces remboursements ne sont ni validés ni accordés automatiquement. Accordez l'accès manuellement en suivant les étapes ci-dessous — l'API côté serveur ne dépend pas d'un `orderId`.
:::

## Étape 1. Identifier les utilisateurs \{#step-1-identify-users\}

Adapty utilise `customer_user_id` pour identifier les utilisateurs sur toutes les plateformes et tous les appareils. C'est essentiel pour garantir que les utilisateurs conservent leur accès après avoir réinstallé l'application ou changé d'appareil.

Vous devez créer cet identifiant une seule fois. Lorsque des utilisateurs s'inscrivent pour la première fois depuis l'application, vous pouvez transmettre leur `customer_user_id` lors de l'activation du SDK, ou utiliser la méthode `identify` si le SDK a été activé avant l'inscription.

:::important
Si vous identifiez les nouveaux utilisateurs après l'activation du SDK, le SDK créera d'abord un profil anonyme (il ne peut pas fonctionner sans). Lorsque vous appelez `identify` avec un customer user ID, un nouveau profil sera créé.

Ce comportement est normal et n'affectera pas la précision des analyses. En savoir plus [ici](ios-quickstart-identify).
:::

## Étape 2. Accorder un niveau d'accès via l'API \{#step-2-grant-access-level-via-api\}

Une fois qu'un utilisateur est identifié avec un `customer_user_id`, vous pouvez lui accorder des niveaux d'accès via l'API côté serveur. Cet appel API accordera le niveau d'accès à l'utilisateur, lui permettant d'accéder aux fonctionnalités payantes sans avoir réellement effectué d'achat.

Consultez la référence complète de la méthode [ici](api-adapty/operations/grantAccessLevel).

:::tip
Vous pouvez contrôler l'accès des utilisateurs en ajoutant un attribut personnalisé (par exemple, Beta tester ou Investor) dans l'Adapty Dashboard.
Au lancement de votre application, [vérifiez cet attribut dans le profil de l'utilisateur](subscription-status) pour accorder l'accès automatiquement.
Pour mettre à jour l'accès, modifiez simplement l'attribut dans le tableau de bord.
:::

```bash
curl --request POST \
  --url https://api.adapty.io/api/v2/server-side-api/purchase/profile/grant/access-level/ \
  --header 'Accept: application/json' \
  --header 'Authorization: Api-Key YOUR_SECRET_API_KEY' \
  --header 'Content-Type: application/json' \
  --header 'adapty-customer-user-id: CUSTOMER_USER_ID' \
  --data '{
  "access_level_id": "YOUR_ACCESS_LEVEL"
}'
```

## Étape 3. Vérifier l'accès dans l'application \{#step-3-verify-access-in-the-app\}

Après avoir accordé l'accès via l'API, le profil de l'utilisateur sera automatiquement mis à jour. Récupérez son profil pour vérifier son statut d'abonnement et débloquer les fonctionnalités premium.
