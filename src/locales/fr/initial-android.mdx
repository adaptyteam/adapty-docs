Connectez votre compte Google Play à Adapty afin que nos serveurs puissent lire vos produits du Play Store, valider vos achats et recevoir les événements d'abonnement Android.

:::important
Chaque store est connecté séparément, et ces connexions sont indépendantes. Si votre application est aussi disponible sur l'App Store, [configurez l'intégration App Store Connect](initial_ios).
:::

La configuration prend environ une heure. L'onboarding intégré dans l'Adapty Dashboard couvre les mêmes étapes si vous préférez rester dans une seule fenêtre.

## Avant de commencer \{#before-you-start\}

Contrairement à Apple, Google divise son écosystème développeur entre deux produits distincts — Google Play Console et Google Cloud Console — et cette configuration concerne les deux.

### Ce que cela implique \{#whats-involved\}

- **Compte de service** : Un compte Google pour les machines plutôt que pour les personnes. Vous devez créer un nouveau compte de service pour accorder à Adapty l'accès à vos consoles Google Cloud et Google Play.
- **Google Cloud Console** : La plateforme d'infrastructure polyvalente de Google. Le Play Store ne dispose pas de ses propres identifiants API, vous les créez donc ici. Utilisez la Cloud Console pour activer les API Développeur, créer le compte de service et lui accorder une partie des autorisations nécessaires. Adapty en a besoin pour recevoir les renouvellements, les annulations et les remboursements. Le fichier de clé du compte de service, qui permet à Adapty de s'authentifier auprès de Google, peut être téléchargé depuis cet endroit.
- **Google Play Console** : L'endroit où vous publiez votre application et vendez des abonnements. Utilisez la Play Console pour accorder au compte de service le reste des autorisations nécessaires. Adapty en a besoin pour lire vos produits et valider les achats. C'est également ici que vous activez les notifications développeur en temps réel (RTDN) pour établir une ligne de communication entre le Play Store et Adapty.

### Privilèges d'accès requis \{#required-access-privileges\}

| Console | Ce dont vous avez besoin |
| --- | --- |
| Google Cloud Console | **Project Creator** (`roles/resourcemanager.projectCreator`) pour créer un projet, si vous n'en avez pas. **Service Account Creator** (`roles/iam.serviceAccountCreator`) pour créer le compte de service, et **Project IAM Admin** (`roles/resourcemanager.projectIamAdmin`) pour lui attribuer des permissions sur le projet. Les **Owners** peuvent faire les trois par défaut. |
| Google Play Console | **Admin (all permissions)**, ce qui inclut le droit d'inviter des utilisateurs — vous avez besoin de cette permission pour inviter le compte de service. |

Google accorde le rôle **Project Creator** à tous les membres d'une nouvelle organisation par défaut, vous l'avez donc probablement déjà. Une organisation d'entreprise verrouillée peut vous l'avoir retiré.

### Ressources nécessaires \{#required-resources\}

**Un projet Google Cloud.** [Créez-en un](https://console.cloud.google.com/projectcreate) si vous n'en avez pas, ou réutilisez un projet existant. Vous vous en servez pour activer les API Developer et créer le compte de service pour Adapty.

Un projet est indépendant de votre application Play Console. Un seul projet peut gérer les communications de plusieurs applications. Chaque application dispose de son propre topic — une file de communication — au sein du projet.

Lorsque vous connectez les services Google à Adapty, vous devez **utiliser le même projet** du début à la fin. Préférez un projet appartenant à votre équipe plutôt qu'un projet personnel — la clé et le topic y résident aussi longtemps que l'application existe.

## Liste de contrôle pour l'intégration initiale \{#checklist-for-the-initial-integration\}

1. [Activez les API développeur](enabling-of-devepoler-api) dans Google Cloud Console.
2. [Créez un compte de service](create-service-account) dans Google Cloud Console.
3. [Accordez les autorisations nécessaires au compte de service](grant-permissions-to-service-account) dans Google Play Console.
4. [Générez le fichier de clé du compte de service](create-service-account-key-file) dans Google Cloud Console.
5. [Importez le fichier de clé et le nom du package dans Adapty](google-play-store-connection-configuration) depuis l'Adapty Dashboard. Un nouveau compte de service nécessite au moins 24 heures pour être activé, et Adapty ne peut pas lire vos produits avant cela — pour éviter cette attente, [modifiez et enregistrez la description d'un produit](create-service-account-key-file#activate-the-account-immediately) dans Google Play Console.
6. [Activez les notifications en temps réel pour les développeurs (RTDN)](enable-real-time-developer-notifications-rtdn) dans Google Play Console, en utilisant le nom de topic généré par Adapty.
7. [Installez le SDK Adapty](installation-of-adapty-sdks) pour chaque framework utilisé par votre application :
   - [Android](sdk-installation-android)
   - [React Native](sdk-installation-reactnative)
   - [Flutter](sdk-installation-flutter)
   - [Kotlin Multiplatform](sdk-installation-kotlin-multiplatform)
   - [Unity](sdk-installation-unity)
   - [Capacitor](sdk-installation-capacitor)
8. [Testez vos achats intégrés](testing-on-android) sur un vrai appareil avant de publier.

## Prochaines étapes \{#next-steps\}

Une fois l'intégration en place, vous pouvez [commencer à utiliser les fonctionnalités d'Adapty](product).

L'affichage des paywalls nécessite du code dans l'application en plus de l'intégration : au minimum, [affichez les paywalls](android-quickstart-paywalls) et [gérez le processus d'achat](android-making-purchases) si vous affichez les paywalls vous-même.

:::tip
Avant de publier votre application, consultez la [liste de contrôle de publication](release-checklist).
:::
