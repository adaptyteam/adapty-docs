Si vous implémentez vous-même votre écran d'achat, vous devez créer un **paywall** dans Adapty. Il définit quels produits vous vendez, dans quel ordre et avec quelles offres promotionnelles. Les flows fonctionnent différemment : les produits y sont attachés directement. Un paywall que vous implémentez vous-même est aussi appelé **paywall personnalisé**.

Une fois créé, assignez le paywall à un [placement](placements) — le point de votre application où vous insérez du contenu provenant d'Adapty.

:::tip
Vous pouvez également créer des paywalls par programmation à l'aide du [Developer CLI](developer-cli-reference#adapty-paywalls-create).
:::

## Créer un paywall \{#create-paywall\}

Pour créer un nouveau paywall dans l'Adapty Dashboard :

1. Rendez-vous dans [**Paywalls**](https://app.adapty.io/paywalls) dans le menu principal d'Adapty. Cette page affiche une vue d'ensemble de tous vos paywalls et leurs métriques.
2. Cliquez sur **Create paywall**.
3. Sur la page **Paywalls / New paywall**, saisissez un **Paywall name** pour identifier ce paywall dans l'Adapty Dashboard.
4. Cliquez sur **Add product**.
5. Sélectionnez les produits à afficher à vos utilisateurs.

:::note
- L'ordre des produits dans cette liste sera conservé dans le SDK, arrangez donc les produits dans l'ordre souhaité.  
- Une fois qu'un paywall est affiché en production, vous ne pourrez plus modifier les produits qu'il contient, car cela pourrait affecter les métriques du paywall.
:::

6. Si vous proposez des essais gratuits ou d'autres offres pour vos produits, ajoutez-les ici, sinon elles ne seront pas disponibles. Choisissez une offre que vous avez [créée précédemment](create-offer) pour ce produit dans la liste **Offer**. La liste n'est disponible que pour les produits qui ont des offres.
7. Cliquez sur **Create as a draft** pour confirmer la création du paywall.

Votre paywall est maintenant créé !
