Si vous implémentez vous-même votre écran d'achat, vous devez créer un **custom paywall** dans Adapty. Il définit quels produits vous vendez, dans quel ordre, et avec quelles offres promotionnelles. Les flows fonctionnent différemment : les produits sont attachés directement au flow.

Une fois créé, assignez le custom paywall à un [placement](placements) — le point dans votre application où vous insérez du contenu depuis Adapty.

:::tip
Vous pouvez également créer des custom paywalls par programmation à l'aide du [Developer CLI](developer-cli-reference#adapty-paywalls-create).
:::

## Créer un paywall personnalisé \{#create-custom-paywall\}

Pour créer un paywall personnalisé dans l'Adapty Dashboard :

1. Accédez à [**Flows & Paywalls**](https://app.adapty.io/paywalls) dans le menu principal d'Adapty et ouvrez l'onglet **Custom Paywalls**.
2. Cliquez sur **Create custom paywall**.
3. Sur la page **Custom Paywalls / New paywall**, saisissez un **Paywall name** pour identifier ce paywall dans l'Adapty Dashboard.
4. Cliquez sur **Add product**.
5. Sélectionnez les produits à afficher à vos utilisateurs.

:::note
- L'ordre des produits dans cette liste sera conservé dans le SDK, donc arrangez les produits dans l'ordre souhaité.  
- Une fois qu'un paywall est affiché en production, vous ne pourrez plus modifier les produits qui y sont associés, car cela pourrait affecter les métriques du paywall.
:::

6. Si vous proposez des essais gratuits ou d'autres offres pour vos produits, ajoutez-les ici, sinon ils ne seront pas disponibles. Choisissez une offre que vous avez [créée précédemment](create-offer) pour ce produit dans la liste **Offer**. La liste n'est disponible que pour les produits qui ont des offres.
7. Cliquez sur **Create as a draft** pour confirmer la création du paywall.

Votre paywall personnalisé est maintenant créé !

1. Ajoutez-le à un [placement](placements) — l'identifiant du placement est le seul identifiant Adapty que vous codez en dur dans votre application.
