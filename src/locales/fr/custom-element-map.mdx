Suivez ce guide pour intégrer une carte interactive dans un flow. La carte affiche vos lieux, comme des salles de sport partenaires, dans un rayon de 2 km autour de l'utilisateur. Votre app affiche la carte en tant que vue native dans un [élément personnalisé](flow-custom-elements), avec MapKit. Votre app demande l'accès à la localisation sur l'écran du flow.

## Avant de commencer \{#before-you-start\}

- Mettez à jour votre app vers Adapty iOS SDK 4.4 ou version ultérieure. Les versions antérieures du SDK affichent le [contenu de secours](flow-custom-elements#set-fallback-content) pour chaque élément personnalisé.
- Configurez votre app pour [récupérer](get-pb-paywalls) et [afficher](ios-present-paywalls) les flows.
- Pour demander l'accès à la localisation, ajoutez la clé `NSLocationWhenInUseUsageDescription` au fichier `Info.plist` de votre app. Définissez sa valeur avec le texte de la demande, par exemple « Trouvez des centres de fitness près de chez vous. »

## 2. Créer la vue de la carte \{#2-create-the-map-view\}

Créez un type pour vos lieux et un modèle pour l'accès à la localisation :

```swift showLineNumbers title="Swift"

// A place of your app, such as a partner fitness center
struct Place: Identifiable {
    let id = UUID()
    let name: String
    let coordinate: CLLocationCoordinate2D
}

// One location manager for the resolver and the map view
@MainActor
final class LocationAccess: NSObject, ObservableObject, CLLocationManagerDelegate {
    @Published private(set) var status: CLAuthorizationStatus = .notDetermined
    var isMapOnScreen = false
    private let manager = CLLocationManager()

    var isDenied: Bool { status == .denied || status == .restricted }

    override init() {
        super.init()
        manager.delegate = self
        status = manager.authorizationStatus
    }

    // Shows the prompt only if the user hasn't answered it yet
    func requestAccess() {
        manager.requestWhenInUseAuthorization()
    }

    nonisolated func locationManagerDidChangeAuthorization(_ manager: CLLocationManager) {
        let status = manager.authorizationStatus
        Task { @MainActor in self.status = status }
    }
}
```

Créez une vue avec une carte. La vue demande l'accès à la localisation et affiche un marqueur pour chacun de vos lieux situés à moins de 2 km de l'utilisateur :

```swift showLineNumbers title="Swift"

@available(iOS 17.0, *)
struct NearbyFitnessCentersMap: View {
    @ObservedObject var access: LocationAccess
    let places: [Place]
    @State private var position: MapCameraPosition = .userLocation(fallback: .automatic)
    @State private var nearbyPlaces: [Place] = []

    var body: some View {
        ZStack {
            if access.isDenied {
                ContentUnavailableView(
                    "Location access is off",
                    systemImage: "location.slash",
                    description: Text("To see fitness centers near you, allow location access in Settings.")
                )
            } else {
                Map(position: $position) {
                    UserAnnotation()
                    ForEach(nearbyPlaces) { place in
                        Marker(place.name, systemImage: "dumbbell.fill", coordinate: place.coordinate)
                            .tint(.teal)
                    }
                }
                .task {
                    access.requestAccess()
                    do {
                        for try await update in CLLocationUpdate.liveUpdates() {
                            guard let location = update.location else { continue }
                            nearbyPlaces = places.filter { place in
                                let placeLocation = CLLocation(
                                    latitude: place.coordinate.latitude,
                                    longitude: place.coordinate.longitude
                                )
                                return location.distance(from: placeLocation) <= 2_000 // meters
                            }
                            withAnimation {
                                position = .automatic // zoom to fit the user and the places
                            }
                            break
                        }
                    } catch {
                        // the map still shows the location of the user
                    }
                }
            }
        }
        // Tells the resolver that the map is on the screen
        .onAppear { access.isMapOnScreen = true }
        .onDisappear { access.isMapOnScreen = false }
    }
}
```

La vue cartographique nécessite iOS 17 ou une version ultérieure. Sur iOS 16, les utilisateurs voient le paywall de secours.

Si l'utilisateur refuse l'accès à la localisation sur l'écran, la vue remplace la carte par un message expliquant comment autoriser l'accès dans les Réglages.

## 3. Associer la map à l'élément personnalisé \{#3-match-the-map-to-the-custom-element\}

Dans votre [resolver global](ios-flow-custom-elements#set-an-app-wide-resolver), ajoutez des propriétés pour le modèle `LocationAccess` et vos lieux. Renvoyez ensuite la vue map pour le Type `map` et l'ID `fitness_centers`. Les lignes surlignées indiquent ce qu'il faut ajouter ou modifier. Si votre app ne possède pas encore de [resolver](ios-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views) global, copiez l'intégralité du code :

```swift showLineNumbers title="Swift" {5-6,14-21}

struct CustomElementsResolver: AdaptyUICustomElementsResolver {
    let locationAccess = LocationAccess()
    let places: [Place] // your app's places, such as partner fitness centers

    func view(
        forType type: String,
        id: String,
        context: AdaptyUICustomElementContext
    ) -> AnyView? {
        switch type {
        case "map" where id == "fitness_centers":
            guard #available(iOS 17.0, *) else {
                return nil // iOS 16: show the fallback
            }
            if locationAccess.isDenied, !locationAccess.isMapOnScreen {
                return nil // access denied before the screen opened: show the fallback
            }
            return AnyView(NearbyFitnessCentersMap(access: locationAccess, places: places))
        // the other cases of your resolver
        default:
            return nil
        }
    }
}
```

<CustomElementMapResolverCalls />

Créez le resolver avec vos emplacements, puis définissez-le comme resolver global de l'application. Appelez `AdaptyUI.setCustomElementsResolver` une seule fois, par exemple au démarrage de l'application :

```swift showLineNumbers title="Swift"

// your app's places, such as partner fitness centers
@MainActor let places = [
    Place(name: "Central Fitness", coordinate: CLLocationCoordinate2D(latitude: 52.5219, longitude: 13.4132)),
    Place(name: "Riverside Gym", coordinate: CLLocationCoordinate2D(latitude: 52.5163, longitude: 13.3777)),
]

// keep this instance: a resolver for one flow can reuse it
@MainActor let customElementsResolver = CustomElementsResolver(places: places)

AdaptyUI.setCustomElementsResolver(customElementsResolver)
```

## 4. Tester sur un appareil \{#4-test-on-a-device\}

Le Flow & Paywall Builder ne peut pas exécuter le code de votre application, donc son canvas n'affiche que le fallback. Pour prévisualiser la carte :

1. [Publiez le flow](builder-save-publish). Pour voir la dernière version publiée plutôt qu'une version en cache, enregistrez l'appareil comme [appareil de test](test-devices).
2. Pour afficher un marqueur sur la carte, ajoutez un lieu situé à moins de 2 km de votre position dans votre liste de lieux.
3. Assurez-vous que l'appareil fonctionne sous iOS 17 ou version ultérieure. Lancez un build de votre application incluant le resolver. Ouvrez l'écran et autorisez l'accès à la localisation. Vérifiez que la carte affiche votre position ainsi qu'un marqueur pour le lieu que vous avez ajouté.

Pour tester le fallback, refusez l'accès à la localisation : dans l'application **Settings**, allez dans **Privacy & Security** > **Location Services** > *votre application*, et sélectionnez **Never**. Ouvrez ensuite l'écran à nouveau.

Pour savoir pourquoi le fallback s'affiche à la place de la carte, suivez les instructions de la section [Tester sur un appareil](ios-flow-custom-elements#test-on-a-device) du guide iOS.
