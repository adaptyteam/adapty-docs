Dans ce guide étape par étape, vous apprendrez à créer et configurer des publicités pour votre application sur TikTok for Business, afin d'optimiser vos campagnes et de suivre facilement leurs performances.

## Étape 1. Ajouter les informations de votre entreprise \{#step-1-add-business-info\}

Si vous débutez sur TikTok for Business, vous devez d'abord renseigner les informations de votre entreprise :

1. Rendez-vous sur [https://ads.tiktok.com](https://ads.tiktok.com/business/) et cliquez sur **Get started**.
2. Inscrivez-vous avec votre adresse e-mail ou votre compte TikTok.
3. Saisissez les informations de votre entreprise et suivez les instructions à l'écran.

Une fois votre compte professionnel approuvé, vous serez redirigé vers la création de votre première campagne.

## Étape 2. Créer un pixel \{#step-2-create-a-pixel\}

Vous aurez besoin d'un pixel TikTok pour connecter les données de votre campagne aux revenus et obtenir de meilleurs résultats :
1. Rendez-vous dans [**Events Manager**](https://ads.tiktok.com/i18n/events_manager/home). Cliquez sur **Connect data source**.
   <ZoomImage id="tiktok-data-source.webp" />
2. Sélectionnez **Web** comme type de source de données.
   <ZoomImage id="tiktok-data-source-type.webp" />
3. Dans la fenêtre **Add your website**, cliquez sur **Skip**.
   <ZoomImage id="add-your-website.webp" />
4. Sélectionnez **Manual setup** et cliquez sur **Next**.
   <ZoomImage id="manual-setup-tiktok.webp" />
5. Sélectionnez **TikTok pixel + Events API** et cliquez sur **Next**.
   <ZoomImage id="pixel-setup-tiktok.webp" />
6. Donnez un nom à votre pixel et cliquez sur **Create**.
   <ZoomImage id="tiktok-pixel.webp" />
7. Pour [Adapty Attribution](adapty-user-acquisition), vous n'avez pas besoin de finaliser l'installation complète du pixel. Vous pouvez donc simplement fermer la fenêtre de configuration, et votre pixel apparaîtra dans la liste.
8. Pour rendre ce pixel disponible dans vos campagnes, vous devez lui envoyer un événement de test depuis [Adapty Attribution](adapty-user-acquisition) :
   1. [Créez une nouvelle campagne TikTok](ua-tiktok).
   2. Développez la section correspondant à votre plateforme – par exemple, iOS.
   3. Sélectionnez un pixel dans le menu déroulant.
   4. Cliquez sur **Send test event**.
      <ZoomImage id="tiktok-test-event.webp" />
   5. Dans le menu déroulant, sélectionnez l'événement que vous utiliserez pour l'optimisation dans l'annonce.
   6. Dans TikTok for Business, ouvrez votre pixel et passez à l'onglet **Test events**. Copiez le `test_event_code`.
      <ZoomImage id="test-event-code.webp" />
   7. Collez-le dans le champ **Test event code** dans Adapty et cliquez sur **Send**.
      <ZoomImage id="adapty-test-event.webp" width="500px" />
9. L'événement de test apparaîtra dans TikTok dans quelques minutes. Dès qu'il s'affiche dans les détails de votre pixel, vous pouvez poursuivre la configuration de la campagne dans TikTok Ads Manager.

## Étape 3. Sélectionner l'objectif de campagne \{#step-3-select-the-campaign-objective\}

:::important
Ce tutoriel utilise la vue Quick setup dans TikTok Ads Manager. Certains paramètres recommandés n'apparaissent que dans la vue Full view, ce que nous signalons dans les étapes correspondantes.
:::

Rendez-vous sur la [page de création d'annonce](https://ads.tiktok.com/i18n/nb_creation/create/objectives) dans Ads Manager.

Sur le premier écran, sélectionnez l'objectif publicitaire et cliquez sur **Continue**.

Sélectionnez **Sales > Website conversion**.

<ZoomImage id="tiktok-objective.webp" />

## Étape 4. Renseignez les informations de la campagne \{#step-4-fill-in-the-campaign-info\}

Ensuite, renseignez les informations de la campagne :

1. Nommez votre campagne dans le champ **Campaign name**.
2. Dans le champ **Optimization goal**, sélectionnez **Conversion**.
   <ZoomImage id="tiktok-campaign-info.webp" />
3. Sélectionnez votre pixel actif dans le menu déroulant et choisissez un **Optimization event**. Notez que seuls les événements actifs sont disponibles. Si l'événement dont vous avez besoin n'est pas disponible, envoyez un événement de test en suivant les instructions de l'[Étape 2](#step-2-create-a-pixel).
4. Votre annonce sera affichée dans le fil et la recherche TikTok. Pour une configuration supplémentaire, cliquez sur **Advanced settings**. Dans **Placements**, configurez les paramètres de placement :
   - **User comment** : sélectionnez cette option si vous souhaitez afficher votre annonce dans la section commentaires. TikTok recommande de laisser les commentaires activés pour aider vos annonces à obtenir plus d'impressions.
   - **Allow video download** : permet aux spectateurs de télécharger votre annonce.
   - **Allow video sharing** : permet aux spectateurs de partager votre annonce.
   <ZoomImage id="tiktok-placement.webp" />
5. Cliquez sur **Continue**.

## Étape 5. Ajouter du contenu publicitaire \{#step-5-add-ad-content\}

Maintenant, il est temps de configurer vos créations et votre URL de destination :

1. Dans le champ **TikTok account**, sélectionnez le compte qui sera utilisé pour la publication.
2. Dans [Adapty Attribution](adapty-user-acquisition), [créez une campagne web](ua-tiktok) et collez le **Click link** dans le champ **Destination URL**.
   <ZoomImage id="tiktok-ad-content.webp" width="700px" />
3. Dans la section **Creatives**, cliquez sur **+ Videos and images**.
4. Si vous souhaitez utiliser vos publications TikTok comme créatifs, sélectionnez-les dans l'onglet **TikTok post**. Sinon, passez à l'onglet **Creative library** et cliquez sur **Upload**. Les fichiers que vous y téléchargez seront accessibles depuis cet onglet ultérieurement, ce qui vous permet de les réutiliser dans d'autres campagnes.
   <ZoomImage id="tiktok-add-creatives.webp" width="700px" />
5. Recadrez les créatifs pour les adapter au format TikTok et choisissez s'ils seront utilisés comme annonces individuelles ou sous forme de carrousel.
6. Développez le créatif téléchargé et cliquez sur **+** à côté de **No music selected**. Vous pouvez y télécharger vos propres fichiers mp3. L'ajout de musique est obligatoire.
7. Dans le champ **Add text**, saisissez le texte qui servira de description.
8. Sélectionnez **Place the ads on this TikTok account as a post** si vous souhaitez publier cette annonce sur votre compte TikTok.
9. Dans le champ **Call to action**, sélectionnez ou supprimez les appels à l'action pertinents pour votre annonce. TikTok les ajoutera automatiquement à votre annonce.
   <ZoomImage id="tiktok-ad-text.webp" width="700px" />
10. Cliquez sur **Continue**.

## Étape 6. Configurer le ciblage et le budget \{#step-6-configure-targeting-and-budget\}

Enfin, définissez à qui votre annonce sera diffusée et combien vous comptez y consacrer :

1. Dans la section **Targeting**, sélectionnez **Automatic** ou **Custom**. L'option **Automatic** est la plus simple si vous ne connaissez pas encore bien votre audience. En revanche, si vous choisissez **Custom**, vous pouvez optimiser vos dépenses en ciblant les groupes d'utilisateurs les plus susceptibles de répondre à votre annonce.
2. Si vous avez sélectionné **Custom**, configurez :
   - **Location** : par défaut, il s'agit de l'emplacement de votre compte publicitaire. Si vous sélectionnez plusieurs pays ou régions, les résultats de l'examen des annonces seront renvoyés séparément pour chaque emplacement. La diffusion effective des annonces peut également varier selon les emplacements pris en charge.
   - **Languages** : par défaut, toutes les langues sont sélectionnées. Choisissez la langue de ciblage en fonction de la langue la plus utilisée dans la zone sélectionnée.
   - **Gender** : par défaut, tous les genres sont sélectionnés.
   :::tip
   Si vous passez en mode Full, vous trouverez une section **Device** supplémentaire sous **Targeting**. Vous pouvez y limiter votre audience par type d'appareil, système d'exploitation et version de l'OS — utile si votre application nécessite une version minimale.
   :::
  <ZoomImage id="tiktok-targeting.webp" width="700px" />
3. Dans la section **Budget**, sélectionnez l'une des options suggérées ou choisissez **Custom**.
4. Si vous avez sélectionné **Custom**, indiquez si vous souhaitez un budget **Daily** ou **Lifetime**, puis saisissez la limite dans votre devise. Le budget **Daily** offre plus de flexibilité pendant votre phase d'apprentissage : vous pouvez commencer avec de petits montants et les ajuster progressivement.
   <ZoomImage id="tiktok-budget.webp" width="700px" />
5. Dans la section **Schedule**, sélectionnez **Continue for at least 7 days** ou **Custom**. Nous vous recommandons de définir un calendrier **Custom** si votre annonce est limitée dans le temps, afin de ne pas manquer le moment où vous devez l'arrêter.
6. Si vous avez sélectionné **Custom**, définissez la date de début, ou les dates de début et de fin de vos annonces. Notez que le fuseau horaire de votre compte sera utilisé.
   <ZoomImage id="tiktok-schedule.webp" width="700px" />
7. Cliquez sur **Publish**.

Lorsque vous aurez terminé, une nouvelle campagne sera créée avec un groupe d'annonces. Ce groupe contiendra une seule annonce si vous avez configuré un carrousel, ou plusieurs annonces si vous avez ajouté des créatifs en tant qu'annonces séparées.

## Étape 7. Saisir les informations de paiement \{#step-7-enter-payment-details\}

Pour lancer l'annonce, une fois le ciblage et le budget publicitaire configurés, saisissez vos informations de paiement. Vous êtes fin prêt·e !
