Pour confirmer que le callback se déclenche, interagissez avec l'entrée dans une version de test de votre application. Pour un sélecteur numérique (Number picker), tournez la roue, puis appuyez sur un bouton qui ouvre un autre écran. Si votre gestionnaire de callback ne reçoit pas d'événement, vérifiez les [prérequis](#before-you-start). Assurez-vous que le flow a été publié après que cette fonctionnalité soit devenue disponible.
