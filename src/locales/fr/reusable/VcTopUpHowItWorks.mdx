1. Un joueur manque d'énergie, et le code de votre application ouvre le flow « énergie épuisée ». Le joueur voit son solde de diamants et deux boutons, un par option : une recharge d'énergie pour 10 diamants, et une heure d'énergie illimitée pour 30.
2. Le joueur appuie sur un bouton, et le code de votre application appelle votre backend pour dépenser les diamants. Pendant la transaction, le joueur voit un spinner dans le bouton.
3. Si la transaction aboutit, le joueur voit une coche. Le code de votre application ferme le flow, et le jeu donne de l'énergie au joueur.
4. Si le solde est insuffisant, le code de votre application ferme le flow « énergie épuisée » et ouvre le flow de recharge. Le joueur voit combien de diamants supplémentaires il lui faut, et achète un pack de diamants ou l'abonnement.
5. Après l'achat, le code de votre application rouvre le flow « énergie épuisée ». Le joueur voit son nouveau solde, et appuie sur un bouton pour dépenser ses diamants.
