Le skill `adapty-integration` automatise l'intégration Adapty de bout en bout : configuration du tableau de bord, installation du SDK, paywall et vérification à chaque étape. Il détecte votre plateforme automatiquement et récupère la documentation Adapty pertinente à chaque étape. Il fonctionne dans n'importe quel agent de code qui prend en charge les skills : Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI, et d'autres.

Le skill fait partie du [plugin `adapty-skills`](https://github.com/adaptyteam/adapty-skills). Pour installer le plugin, exécutez dans votre terminal :

```bash
npx adapty skills install
```

Redémarrez votre agent pour charger les skills. Pour d'autres méthodes d'installation, consultez le [README du plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Claude Code ne met pas le plugin à jour automatiquement. Pour obtenir les nouveaux skills dès leur sortie, dans Claude Code, exécutez `/plugin`, ouvrez **Marketplaces**, sélectionnez `adapty` et choisissez **Enable auto-update**. Pour la commande de mise à jour dans d'autres agents, consultez le [README du plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Pour démarrer l'intégration, demandez à votre agent :

```
Integrate Adapty into my app
```

Le skill pose quelques questions de configuration, puis guide à travers la configuration du tableau de bord, l'installation du SDK, le paywall et la vérification.
