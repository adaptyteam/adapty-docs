La [compétence adapty-integration](https://github.com/adaptyteam/adapty-skills) automatise l'intégration Adapty de bout en bout : configuration du tableau de bord, installation du SDK, paywall et vérification à chaque étape. Elle détecte automatiquement votre plateforme et récupère la documentation Adapty correspondante à chaque étape.

**Outils pris en charge** : Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Pour l'installer, choisissez le format adapté à votre outil. La liste complète se trouve dans le [README de la compétence](https://github.com/adaptyteam/adapty-skills).

Le dépôt contient deux compétences — `adapty-integration` et `ads-manager`, qui pilote Apple Search Ads via le CLI Adapty. Chaque commande ci-dessous installe les deux.

**Claude Code**

```
claude plugin marketplace add adaptyteam/adapty-skills
claude plugin install adapty-skills@adapty
```

**GitHub Copilot CLI**

```
git clone https://github.com/adaptyteam/adapty-skills.git
cp -r adapty-skills/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```
gemini skills install https://github.com/adaptyteam/adapty-skills
```

**OpenAI Codex ou tout autre outil** — utilisez le [skills CLI](https://skills.sh) (notez que les compétences installées de cette façon ne se mettent pas à jour automatiquement) :

```
npx skills add adaptyteam/adapty-skills --all
```

`--all` installe les deux compétences dans chaque agent détecté. Sans cette option, le CLI vous demande laquelle des deux vous souhaitez installer.

Vous pouvez aussi cloner le dépôt et copier les répertoires situés sous `skills/` dans le répertoire des compétences de votre outil.

Une fois l'installation terminée, exécutez la compétence dans votre projet :

```
/adapty-integration
```

La compétence pose quelques questions de configuration, puis vous guide à travers la configuration du tableau de bord, l'installation du SDK, le paywall et la vérification.
