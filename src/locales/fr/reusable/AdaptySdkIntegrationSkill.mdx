Le skill `adapty-integration` automatise l'intégration Adapty de bout en bout : configuration du tableau de bord, installation du SDK, paywall, et vérification à chaque étape. Il détecte automatiquement votre plateforme et récupère la documentation Adapty correspondante à chaque étape. Il fonctionne dans tout agent de programmation compatible avec les skills : Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI, et autres.

Le skill fait partie du [plugin Adapty](manage-adapty-with-ai). Si vous avez déjà installé le plugin, vous disposez de ce skill. Si votre agent ne le répertorie pas, mettez à jour le plugin avec la commande correspondant à votre agent dans le [README du plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Pour installer le plugin dans un agent de programmation, exécutez dans votre terminal :

```bash
npx adapty skills install
```

Redémarrez votre agent pour charger le plugin. Pour d'autres méthodes d'installation, consultez le [README du plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Claude Code ne met pas le plugin à jour automatiquement. Pour obtenir les nouveaux skills dès leur sortie, exécutez `/plugin` dans Claude Code, ouvrez **Marketplaces**, sélectionnez `adapty`, puis choisissez **Enable auto-update**. Pour la commande de mise à jour dans d'autres agents, consultez le [README du plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Pour démarrer l'intégration, demandez à votre agent :

```
Integrate Adapty into my app
```

Le skill pose quelques questions de configuration, puis guide à travers la mise en place du tableau de bord, l'installation du SDK, le paywall et la vérification.
