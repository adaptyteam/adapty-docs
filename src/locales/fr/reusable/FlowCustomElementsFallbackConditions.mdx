Pour afficher le [contenu de secours](flow-custom-elements#set-fallback-content) à la place d'un élément personnalisé vide, ne renvoyez aucune vue dans les situations suivantes :

- Rien à afficher — le fichier d'animation ou de données nécessaire est manquant.
- Rien à traiter — l'utilisateur a passé une question du quiz et les données sont incomplètes.
- Accès refusé — une permission refusée empêche la vue d'accéder à une ressource.

Par exemple, le [resolver](#write-a-resolver-to-match-custom-elements-and-views) ne renvoie aucune vue lorsque le fichier d'animation est manquant.
