Pour indiquer aux joueurs combien de diamants supplémentaires il leur faut, utilisez un [tag personnalisé](flow-custom-tags) : un espace réservé que vous insérez dans un élément texte. Le code de l'étape 4 transmet le nombre au tag une seule fois, à l'ouverture du flow. Les mots autour du nombre restent dans le builder, où vous pouvez les modifier et les traduire.

1. [Créez un tag personnalisé](flow-custom-tags#create-a-custom-tag) nommé `diamonds_needed`, et saisissez un tiret (`—`) dans son champ **Initial value**. Si le code de votre application ne transmet aucun nombre pour le tag, les joueurs voient le tiret.
2. Ajoutez un élément texte avec les mots « Vous avez besoin de plus de diamants ». Après « besoin », [insérez le tag personnalisé `diamonds_needed`](flow-custom-tags#add-a-custom-tag-to-a-text-element).
