Lorsqu'un écran contenant un [élément personnalisé](flow-custom-elements) s'ouvre, le SDK Adapty transmet le Type et l'ID de l'élément à un resolver dans le code de votre application. Le resolver retourne l'un des résultats suivants :

- **La vue correspondant au Type et à l'ID** : les utilisateurs voient la vue native, comme une animation Lottie, un graphique interactif ou un aperçu de caméra.
- **Aucune vue** : les utilisateurs voient le contenu de secours, c'est-à-dire le contenu défini dans l'élément personnalisé dans le Flow & Paywall Builder.

Les utilisateurs de versions de l'application sans resolver voient également le contenu de secours. Vous pouvez donc publier le flow avant de publier la nouvelle version de l'application.
