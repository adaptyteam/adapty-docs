1. Pour trouver l'**Issuer ID** et le **Key ID** de votre clé d'équipe, dans App Store Connect, accédez à [**Users and Access** > **Integrations** > **App Store Connect API**](https://appstoreconnect.apple.com/access/integrations/api), puis ouvrez l'onglet **Team Keys**. Si quelqu'un d'autre a généré la clé et vous a envoyé son Issuer ID, Key ID et le fichier, ignorez cette étape.

   <ZoomImage id="asc-team-keys-ids.webp" width="700px" alt="Issuer ID et Key ID d'une clé d'équipe dans l'onglet Team Keys d'App Store Connect" />

2. Dans Adapty, accédez à [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). Dans la section **App Store Connect API key**, cliquez sur **Connect API Key**.

   <ZoomImage id="app-settings-connect-api-key.webp" width="700px" alt="Section App Store Connect API key dans Adapty, avec le bouton Connect API Key" />

3. Remplissez les champs :
   - **Issuer ID** : copiez-le depuis l'onglet **Team Keys** dans App Store Connect.
   - **Key ID** : copiez-le depuis la liste **Active** de l'onglet **Team Keys**, à côté de la clé que vous avez téléchargée.
   - **Private key (.p8 file)** : importez le fichier téléchargé pour la clé d'équipe.

   <ZoomImage id="app-settings-api-key-dialog.webp" width="700px" alt="Champs Issuer ID, Key ID et Private key (.p8 file) dans la fenêtre de la clé App Store Connect API" />

4. Vous pouvez remplacer une clé connectée ultérieurement, mais vous ne pouvez pas la supprimer. Assurez-vous que la clé provient de l'équipe App Store Connect propriétaire de cette application, puis cliquez sur **Connect**. Dès lors, vous sélectionnez chaque **App Store Product ID** parmi vos produits dans App Store Connect, au lieu de le saisir manuellement.

   Adapty ne vérifie pas la clé auprès d'Apple lors de la connexion. Une clé incorrecte échoue sans message d'erreur relatif à la clé : les produits n'affichent aucun statut App Store et la liste déroulante **App Store Product ID** reste vide. Pour corriger une clé incorrecte, [remplacez-la](app-store-connect-api-key#replace-the-key).
