Adapty calcule les revenus de renouvellement au prix actuel du produit, même pour les utilisateurs qui étaient sur un ancien tarif lors de leur première souscription. Après avoir modifié un prix dans App Store Connect ou Google Play, les chiffres Revenue, MRR et ARR du tableau de bord pour les abonnés existants peuvent diverger des revenus réellement encaissés — Adapty applique le nouveau prix, même si le store a maintenu ces utilisateurs à l'ancien tarif.

Pour vérifier, comparez le champ `price` par transaction dans l'export S3, GCS ou BigQuery avec le tableau de bord pour les mêmes transactions. Le champ de l'export reflète ce que le store a communiqué (le prix effectivement payé par le client) ; le tableau de bord reflète le prix actuel du produit.
