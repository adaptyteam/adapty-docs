À partir du SDK 4.4, les flows nécessitent iOS 16 ou une version ultérieure. Pour créer une app compatible avec iOS 15, marquez les types qui utilisent des flows avec `@available(iOS 16.0, *)`, et ouvrez le flow dans `if #available(iOS 16.0, *)`. Dans la branche `else`, affichez votre propre contenu, par exemple un [paywall personnalisé](ios-implement-paywalls-manually).
