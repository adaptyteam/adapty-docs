1. Dans App Store Connect, accédez à [**Users and Access** > **Integrations** > **In-App Purchase**](https://appstoreconnect.apple.com/access/integrations/api/subs).

   Une seule clé s'applique à toutes les apps de votre équipe App Store Connect. Pour réutiliser une clé active depuis cette page, vous avez besoin de son fichier. Si vous l'avez, passez les étapes 2 à 4. Les clés actives continuent de fonctionner lorsque vous en générez une nouvelle.

2. Pour générer une clé, vous devez avoir le rôle Account Holder ou Admin dans App Store Connect. Sans l'un ou l'autre de ces rôles, demandez à quelqu'un qui en dispose de générer une clé et de vous envoyer le fichier avec son Issuer ID et son Key ID.

   Si la page liste déjà des clés actives, cliquez sur **+**. Sinon, cliquez sur **Generate In-App Purchase Key**.

   <ZoomImage id="asc-in-app-purchase-keys-add.webp" width="700px" alt="Page des clés In-App Purchase dans App Store Connect, avec le bouton permettant d'ajouter une clé" />

3. Saisissez un nom pour la clé, puis cliquez sur **Generate**. La clé apparaît dans la liste **Active**.

   <ZoomImage id="asc-in-app-purchase-key-name.webp" width="700px" alt="Boîte de dialogue Generate In-App Purchase Key avec un nom pour la clé et le bouton Generate" />

4. Vous ne pouvez télécharger chaque clé qu'une seule fois. À côté de la nouvelle clé, cliquez sur **Download In-App Purchase Key**.

   <ZoomImage id="asc-in-app-purchase-key-download-link.webp" width="700px" alt="Liste Active des clés In-App Purchase, avec le lien de téléchargement à côté d'une nouvelle clé" />

   Puis, dans la boîte de dialogue, cliquez sur **Download**. Conservez le fichier en lieu sûr : vous devrez le charger dans chaque app Adapty qui utilise la clé.

   <ZoomImage id="asc-in-app-purchase-key-download-dialog.webp" width="700px" alt="Boîte de dialogue de téléchargement d'une clé In-App Purchase" />
