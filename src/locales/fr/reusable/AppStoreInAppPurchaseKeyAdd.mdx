1. Pour trouver l'**Issuer ID** et le **Key ID** de votre clé, dans App Store Connect, rendez-vous sur [**Users and Access** > **Integrations** > **In-App Purchase**](https://appstoreconnect.apple.com/access/integrations/api/subs). Si quelqu'un d'autre a généré la clé et vous a transmis son Issuer ID, son Key ID et le fichier, passez cette étape.

   <ZoomImage id="asc-in-app-purchase-keys-ids.webp" width="700px" alt="Issuer ID et Key ID d'une clé In-App Purchase dans App Store Connect" />

2. Dans Adapty, rendez-vous sur [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). Dans la section **In-app purchase API (StoreKit 2)**, renseignez les champs suivants :
   - **Issuer ID** : copiez-le depuis la page **In-App Purchase** dans App Store Connect.
   - **Key ID** : copiez-le depuis la liste **Active** sur la page **In-App Purchase**, à côté de la clé que vous avez téléchargée.
   - **Private key (.p8 file)** : importez le fichier que vous avez téléchargé.

   <ZoomImage id="app-settings-in-app-purchase-api.webp" width="700px" alt="Champs Issuer ID, Key ID et Private key (.p8 file) dans la section In-app purchase API (StoreKit 2) dans Adapty" />

3. Adapty signe les [offres promotionnelles](offers) avec la clé In-App Purchase. Dans la section **App Store promotional offers**, saisissez à nouveau la clé :
   - **Subscription key ID** : le Key ID de l'étape 2.
   - **Subscription key (.p8 file)** : le fichier de l'étape 2.

   <ZoomImage id="app-settings-promotional-offers.webp" width="700px" alt="Champs Subscription key ID et Subscription key (.p8 file) dans la section App Store promotional offers" />

   Une clé différente sera enregistrée sans erreur, mais les utilisateurs ne pourront alors pas recevoir d'offres promotionnelles.

4. Cliquez sur **Save**. Adapty vérifie la clé auprès d'Apple dans la section **In-app purchase API (StoreKit 2)** avant d'enregistrer la page. Si Apple rejette la clé, la page affiche « The provided field values are incorrect » : [vérifiez les valeurs saisies](troubleshoot-app-store-integration#the-provided-field-values-are-incorrect-when-saving-credentials).
