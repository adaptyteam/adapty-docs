La [compétence ads-manager](https://github.com/adaptyteam/adapty-sdk-integration-skill) permet à votre outil de codage IA de gérer Apple Ads via les commandes `adapty asa`. Elle connaît l'ordre dans lequel les commandes se combinent, ce qu'il faut lire avant d'écrire quoi que ce soit, et quels appels dépensent de l'argent.

**Outils pris en charge** : Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

La compétence pilote l'Adapty CLI, donc installez et authentifiez le CLI en premier — voir le [guide de démarrage rapide](developer-cli-quickstart).

Dans un espace de travail Cowork d'entreprise, un administrateur doit ajouter `*.adapty.io` à la liste d'autorisation de domaines. Tant que ce n'est pas fait, la compétence ne peut pas accéder à Adapty.

Pour l'installation, choisissez le format correspondant à votre outil. La liste complète se trouve dans le [README de la compétence](https://github.com/adaptyteam/adapty-sdk-integration-skill).

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

Ce plugin contient également la compétence d'intégration SDK. Les deux sont installés ensemble.

**GitHub Copilot CLI**

```bash
gh skill install adaptyteam/adapty-sdk-integration-skill
```

**Gemini CLI**

```bash
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex ou tout autre outil** — utilisez la [skills CLI](https://skills.sh) (notez que les compétences installées de cette façon ne se mettent pas à jour automatiquement) :

```bash
npx skills add adaptyteam/adapty-sdk-integration-skill
```

Vous pouvez aussi cloner le dépôt et copier `skills/ads-manager/` dans le répertoire des compétences de votre outil.

Après l'installation, lancez la compétence dans votre projet :

```bash
/ads-manager
```

La lecture des métriques et les tests à blanc ne coûtent rien. Toute autre commande contacte Apple en quelques secondes, dépense de l'argent réel et ne peut pas être annulée — la compétence vous demande confirmation avant chacune, et vous devriez en faire de même.
