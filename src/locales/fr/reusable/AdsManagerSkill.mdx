La [compétence ads-manager](https://github.com/adaptyteam/adapty-sdk-integration-skill) enseigne à votre outil de codage IA à opérer Apple Ads via les commandes `adapty asa`. Elle connaît l'ordre dans lequel les commandes se composent, ce qu'il faut lire avant d'écrire quoi que ce soit, et quels appels dépensent de l'argent.

**Outils pris en charge** : Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

La compétence pilote le CLI Adapty, donc installez et authentifiez le CLI en premier — consultez le [guide de démarrage rapide](developer-cli-quickstart). Les commandes `adapty asa` sont disponibles à partir d'**Adapty CLI 0.4.0** ; sur une version plus ancienne, elles n'existent tout simplement pas. Vérifiez avec `adapty asa whoami`, qui vous indique également si un compte Apple Ads est connecté et si l'entreprise dispose d'un abonnement Ads Manager actif.

Claude Cowork exécute le CLI dans un sandbox qui bloque tous les domaines hors de sa liste d'autorisation. Autorisez les domaines Adapty avant d'y installer la compétence — voir [Exécuter le CLI dans Cowork](developer-cli-quickstart#run-the-cli-in-cowork).

Pour installer, choisissez la forme correspondant à votre outil. La liste complète se trouve dans le [README de la compétence](https://github.com/adaptyteam/adapty-sdk-integration-skill).

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

Ce plugin contient également la compétence d'intégration SDK. Les deux sont installés ensemble.

**GitHub Copilot CLI**

```bash
git clone https://github.com/adaptyteam/adapty-sdk-integration-skill.git
cp -r adapty-sdk-integration-skill/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```bash
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex ou tout autre outil** — utilisez le [CLI skills](https://skills.sh) (notez que les compétences installées de cette façon ne se mettent pas à jour automatiquement) :

```bash
npx skills add adaptyteam/adapty-sdk-integration-skill --all
```

`--all` installe les deux compétences dans chaque agent détecté. Pour cette compétence seule, utilisez `--skill ads-manager`.

Vous pouvez également cloner le dépôt et copier les répertoires sous `skills/` dans le répertoire de compétences de votre outil — ou simplement `skills/ads-manager/` si vous ne souhaitez que celle-ci.

Après l'installation, exécutez la compétence dans votre projet :

```bash
/ads-manager
```

La lecture des métriques et les simulations à blanc ne coûtent rien. Toute autre commande atteint Apple en quelques secondes, dépense de l'argent réel et ne peut pas être annulée — la compétence demande confirmation avant chacune, et vous devriez faire de même.
