Le [plugin Apple Ads](https://github.com/adaptyteam/apple-ads-cli) enseigne à votre outil de codage IA comment opérer Apple Ads via les commandes `adapty asa`. Il embarque trois compétences :

- **`apple-ads`** : L'opérateur. Il lit les performances, modifie les enchères et les budgets, ajoute des mots-clés et des négatifs, collecte les termes de recherche, et lance et met en pause des campagnes — avec confirmation avant toute dépense.
- **`apple-ads-audit`** : Un auditeur en lecture seule. Il vérifie la santé du compte, le statut de diffusion, la structure, la propriété du trafic et les mots-clés en correspondance exacte en double, et n'écrit jamais.
- **`apple-ads-strategy`** : Un planificateur qui n'a besoin ni de compte, ni de CLI, ni d'abonnement. Il transforme une description de votre application en structure de compte, taxonomie de mots-clés, budgets de départ et liste de mots-clés négatifs.

**Outils pris en charge** : Claude Code, Claude Cowork, GitHub Copilot CLI, OpenAI Codex, Gemini CLI, et tout autre outil compatible avec les compétences.

L'opérateur et l'auditeur pilotent le CLI Adapty, donc installez et authentifiez le CLI en premier — consultez le [guide de démarrage rapide](developer-cli-quickstart). Les commandes `adapty asa` sont disponibles à partir d'**Adapty CLI 0.4.0** ; sur une version plus ancienne, elles n'existent tout simplement pas. Vérifiez avec `adapty asa whoami`, qui indique aussi si un compte Apple Ads est connecté et si l'entreprise dispose d'un abonnement Ads Manager actif. La compétence strategy fonctionne sans rien de tout cela.

Claude Cowork exécute le CLI dans un sandbox qui bloque tous les domaines hors de sa liste d'autorisation. Autorisez les domaines Adapty avant d'installer le plugin — voir [Exécuter le CLI dans Cowork](developer-cli-quickstart#run-the-cli-in-cowork). Une tâche Cowork démarre aussi sur une machine vierge, donc le CLI et sa connexion ne persistent pas entre les sessions — la compétence `adapty-cli-setup` du plugin installe et authentifie à nouveau le CLI au début de chacune.

Pour l'installation, choisissez le format adapté à votre outil. La liste complète est dans le [README du plugin](https://github.com/adaptyteam/apple-ads-cli).

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/apple-ads-cli
claude plugin install apple-ads@adapty
```

En plus des compétences, le plugin Claude Code installe des commandes slash `/asa-*` — des invites prêtes à l'emploi pour les tâches courantes, comme `/asa-review` pour le bilan hebdomadaire et `/asa-harvest` pour transformer les termes de recherche en mots-clés et négatifs.

**Tout autre outil** — utilisez le [skills CLI](https://skills.sh) (notez que les compétences installées de cette façon ne se mettent pas à jour automatiquement) :

```bash
npx skills add adaptyteam/apple-ads-cli --all
```

`--all` installe les trois compétences dans chaque agent détecté. Pour une seule compétence, utilisez `--skill`, par exemple `--skill apple-ads-strategy`.

Après l'installation, lancez une compétence dans votre projet — directement ou via l'une des commandes slash :

```bash
/apple-ads
```

La lecture des métriques et les simulations ne coûtent rien. Toute autre commande atteint Apple en quelques secondes, dépense de l'argent réel et ne peut pas être annulée — les compétences demandent une confirmation avant chacune, et vous devriez faire de même.
