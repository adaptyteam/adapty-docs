Le [plugin Apple Ads](https://github.com/adaptyteam/apple-ads-cli) apprend à votre outil de codage IA à gérer Apple Ads via les commandes `adapty asa`. Il embarque trois skills :

- **`apple-ads`** : L'opérateur. Il lit les performances, modifie les enchères et les budgets, ajoute des mots-clés et des négatifs, récupère les termes de recherche, et lance et met en pause les campagnes — avec confirmation avant toute dépense.
- **`apple-ads-audit`** : Un auditeur en lecture seule. Il vérifie la santé du compte, le statut de diffusion, la structure, la propriété du trafic et les mots-clés en correspondance exacte en double, et n'écrit jamais.
- **`apple-ads-strategy`** : Un planificateur qui ne nécessite ni compte, ni CLI, ni abonnement. Il transforme une description de votre application en structure de compte, en taxonomie de mots-clés, en budgets de départ et en liste de mots-clés négatifs.

**Outils pris en charge** : Claude Code, l'application Claude (anciennement Claude Cowork), GitHub Copilot CLI, OpenAI Codex, Gemini CLI, et tout autre outil compatible avec les skills.

L'opérateur et l'auditeur pilotent le CLI Adapty, donc installez et authentifiez le CLI en premier — consultez le [guide de démarrage rapide](developer-cli-quickstart). Les commandes `adapty asa` sont disponibles à partir d'**Adapty CLI 0.4.0** ; sur une version plus ancienne, elles n'existent pas du tout. Vérifiez avec `adapty asa whoami`, qui vous indique également si un compte Apple Ads est connecté et si l'entreprise dispose d'un abonnement Ads Manager actif. Le skill de stratégie fonctionne sans rien de tout cela.

L'application Claude exécute le CLI dans un sandbox qui bloque tous les domaines hors de sa liste d'autorisation. Autorisez les domaines Adapty avant d'y installer le plugin — voir [Configurer le CLI Adapty dans l'application Claude](developer-cli-cowork). Chaque conversation dans l'application Claude démarre aussi sur une machine vierge, donc le CLI et sa session ne se transmettent pas d'une conversation à l'autre — le skill `adapty-cli-setup` du plugin installe et authentifie à nouveau le CLI au début de chacune.

Pour l'installation, choisissez le format correspondant à votre outil. La liste complète se trouve dans le [README du plugin](https://github.com/adaptyteam/apple-ads-cli).

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/apple-ads-cli
claude plugin install apple-ads@adapty
```

**OpenAI Codex**

```bash
codex plugin marketplace add adaptyteam/apple-ads-cli
codex plugin add apple-ads@adapty
```

Les deux voies d'installation du plugin embarquent les commandes `/asa-*` avec les skills — des prompts prêts à l'emploi pour les tâches courantes, comme `/asa-review` pour le bilan hebdomadaire et `/asa-harvest` pour transformer les termes de recherche en mots-clés et négatifs. Claude Code les expose en tant que commandes slash ; Codex les charge en tant que skills que vous demandez par leur nom.

**Tout autre outil** — utilisez le [skills CLI](https://skills.sh) (notez que les skills installés de cette façon ne se mettent pas à jour automatiquement) :

```bash
npx skills add adaptyteam/apple-ads-cli --all
```

`--all` installe les trois skills dans chaque agent détecté. Pour un seul skill, utilisez `--skill`, par exemple `--skill apple-ads-strategy`.

Après l'installation, lancez un skill dans votre projet — directement ou via l'une des commandes slash :

```bash
/apple-ads
```

La lecture des métriques et les exécutions à blanc ne coûtent rien. Chaque autre commande atteint Apple en quelques secondes, dépense de l'argent réel et ne peut pas être annulée — les skills demandent confirmation avant chacune, et vous devriez faire de même.
