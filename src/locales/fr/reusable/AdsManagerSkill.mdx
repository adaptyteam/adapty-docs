La [compétence ads-manager](https://github.com/adaptyteam/adapty-sdk-integration-skill) apprend à votre outil de codage IA à opérer Apple Ads via les commandes `adapty asa`. Elle connaît l'ordre dans lequel les commandes se composent, ce qu'il faut lire avant d'écrire quoi que ce soit, et quels appels dépensent de l'argent.

**Outils compatibles** : Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

La compétence pilote l'Adapty CLI — installez et authentifiez d'abord le CLI, voir le [guide de démarrage rapide](developer-cli-quickstart). Les commandes `adapty asa` sont disponibles à partir d'**Adapty CLI 0.4.0** ; sur une version antérieure, elles n'existent pas du tout. Vérifiez avec `adapty asa whoami`, qui vous indique aussi si un compte Apple Ads est connecté et si l'entreprise dispose d'un abonnement Ads Manager actif.

Dans un espace de travail Cowork d'entreprise, un administrateur doit ajouter `adapty.io` et `*.adapty.io` à la liste d'autorisation de domaines. Listez les deux : un caractère générique ne couvre pas le domaine apex dans la plupart des implémentations de liste d'autorisation, et c'est là que vit la documentation que la compétence consulte. Tant que les deux ne sont pas autorisés, la compétence ne peut pas accéder à Adapty.

Pour l'installer, choisissez le format correspondant à votre outil. La liste complète se trouve dans le [README de la compétence](https://github.com/adaptyteam/adapty-sdk-integration-skill).

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

Ce plugin contient également la compétence d'intégration SDK. Les deux sont installés ensemble.

**GitHub Copilot CLI**

```bash
git clone https://github.com/adaptyteam/adapty-sdk-integration-skill.git
cp -r adapty-sdk-integration-skill/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```bash
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex ou tout autre outil** — utilisez le [skills CLI](https://skills.sh) (notez que les compétences installées de cette façon ne se mettent pas à jour automatiquement) :

```bash
npx skills add adaptyteam/adapty-sdk-integration-skill --all
```

`--all` installe les deux compétences dans chaque agent détecté. Pour cette compétence seule, utilisez `--skill ads-manager`.

Vous pouvez aussi cloner le dépôt et copier les répertoires sous `skills/` dans le répertoire de compétences de votre outil — ou juste `skills/ads-manager/` si vous ne voulez que celle-ci.

Après l'installation, lancez la compétence dans votre projet :

```bash
/ads-manager
```

La lecture des métriques et les simulations (dry runs) sont gratuites. Toute autre commande atteint Apple en quelques secondes, dépense de l'argent réel, et ne peut pas être annulée — la compétence vous demande confirmation avant chacune, et vous devriez en faire autant.
