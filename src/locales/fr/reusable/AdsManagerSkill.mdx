Le [plugin Apple Ads](https://github.com/adaptyteam/apple-ads-cli) apprend à votre outil de codage IA à opérer Apple Ads via les commandes `adapty asa`. Il embarque trois skills :

- **`apple-ads`** : L'opérateur. Il lit les performances, modifie les enchères et les budgets, ajoute des mots-clés et des exclusions, collecte les termes de recherche, et lance et met en pause des campagnes — avec confirmation avant toute dépense.
- **`apple-ads-audit`** : Un auditeur en lecture seule. Il vérifie la santé du compte, le statut de diffusion, la structure, la propriété du trafic et les mots-clés en correspondance exacte en double, sans jamais écrire.
- **`apple-ads-strategy`** : Un planificateur qui n'a besoin ni de compte, ni de CLI, ni d'abonnement. Il transforme la description de votre application en une structure de compte, une taxonomie de mots-clés, des budgets de départ et une liste de mots-clés à exclure.

**Outils pris en charge** : Claude Code, Claude Cowork, GitHub Copilot CLI, OpenAI Codex, Gemini CLI, et tout autre outil compatible avec les skills.

L'opérateur et l'auditeur pilotent la CLI Adapty — installez et authentifiez donc la CLI en premier : voir le [guide de démarrage rapide](developer-cli-quickstart). Les commandes `adapty asa` sont disponibles à partir d'**Adapty CLI 0.4.0** ; sur une version antérieure, elles n'existent tout simplement pas. Vérifiez avec `adapty asa whoami`, qui vous indique également si un compte Apple Ads est connecté et si l'entreprise dispose d'un abonnement Ads Manager actif. Le skill de stratégie fonctionne sans rien de tout cela.

Claude Cowork exécute la CLI dans un sandbox qui bloque tous les domaines ne figurant pas dans sa liste d'autorisation. Autorisez les domaines Adapty avant d'y installer le plugin — voir [Configurer la CLI Adapty dans Claude Cowork](developer-cli-cowork). Une tâche Cowork démarre aussi sur une machine vierge, donc la CLI et ses identifiants ne persistent pas entre les sessions — le skill `adapty-cli-setup` du plugin installe et authentifie à nouveau la CLI au début de chacune.

Pour l'installation, choisissez le format correspondant à votre outil. La liste complète se trouve dans le [README du plugin](https://github.com/adaptyteam/apple-ads-cli).

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/apple-ads-cli
claude plugin install apple-ads@adapty
```

**OpenAI Codex**

```bash
codex plugin marketplace add adaptyteam/apple-ads-cli
codex plugin add apple-ads@adapty
```

Les deux routes de plugin embarquent les commandes `/asa-*` avec les skills — des prompts prêts à l'emploi pour les tâches courantes, comme `/asa-review` pour le bilan hebdomadaire et `/asa-harvest` pour transformer les termes de recherche en mots-clés et exclusions. Claude Code les expose comme des commandes slash ; Codex les charge comme des skills que vous demandez par leur nom.

**Tout autre outil** — utilisez la [skills CLI](https://skills.sh) (notez que les skills installés de cette façon ne se mettent pas à jour automatiquement) :

```bash
npx skills add adaptyteam/apple-ads-cli --all
```

`--all` installe les trois skills dans chaque agent détecté. Pour un skill individuel, utilisez `--skill`, par exemple `--skill apple-ads-strategy`.

Après l'installation, exécutez un skill dans votre projet — directement ou via l'une des commandes slash :

```bash
/apple-ads
```

La lecture des métriques et les simulations sont gratuites. Toute autre commande atteint Apple en quelques secondes, dépense de l'argent réel et ne peut pas être annulée — les skills demandent une confirmation avant chacune, et vous devriez faire de même.
