
Pour activer les achats intégrés, vous devez comprendre comment Adapty structure les achats :

- **Les produits** sont tout ce qui est disponible à l'achat – abonnements, consommables ou accès à vie.
- **Les paywalls** sont des configurations qui définissent quels produits proposer. Dans Adapty, les paywalls sont le seul moyen de récupérer des produits, mais cette conception vous permet de modifier les offres, les prix et les combinaisons de produits sans toucher au code de votre application.

Ce guide vous aidera à afficher un paywall créé dans le Paywall Builder d'Adapty dans votre application :

1. **Récupérer le paywall** : Obtenez le paywall depuis Adapty.
2. **Afficher le paywall et déléguer la gestion des achats à Adapty** : Affichez le conteneur de paywall obtenu dans votre application.
3. **Gérer les actions des boutons** : Associez les interactions de l'utilisateur avec le paywall aux réponses de votre application. Par exemple, ouvrez des liens ou fermez le paywall lorsque les utilisateurs cliquent sur des boutons.
