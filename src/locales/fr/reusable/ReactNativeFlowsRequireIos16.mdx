À partir du SDK 4.4, les flows nécessitent iOS 16 ou version ultérieure. Sur iOS 15, `createFlowView` et `AdaptyFlowView` renvoient une erreur avec le code `platformNotSupported`. Lorsque votre application reçoit cette erreur, affichez votre propre contenu à la place du flow, comme un [paywall personnalisé](react-native-implement-paywalls-manually).
