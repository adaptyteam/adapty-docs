Pour afficher un spinner puis une coche dans le bouton sur lequel les utilisateurs appuient, ajoutez les deux boutons en tant qu'éléments personnalisés. Avec un [action personnalisée](onboarding-actions#what-custom-actions-cant-do), les utilisateurs ne voient ni spinner ni coche dans un bouton du builder. Une action personnalisée est unidirectionnelle : votre code applicatif ne peut pas renvoyer le résultat de la dépense au flow. Le texte et l'apparence des boutons proviennent de votre code applicatif. Pour les modifier, [publiez une mise à jour de l'application](flow-custom-elements#what-changes-require-an-app-release).

1. [Ajoutez un élément personnalisé](flow-custom-elements#add-and-configure) pour le rechargement d'énergie, et renseignez son **Type** et son **ID** :
   - **Type** : `spend_button`.
   - **ID** : `energy_refill`.
2. Ajoutez un second élément personnalisé pour l'énergie illimitée, avec le même Type et l'ID `unlimited_energy`.

   Le code de l'[étape 2](#connect-the-buttons-to-your-backend) associe une même vue de bouton aux deux éléments personnalisés par leur Type. Le code lit l'option de chaque bouton à partir de son ID.

   <ZoomImage id="vc-top-up-spend-button.webp" width="700px" alt="Paramètres d'élément personnalisé dans le Flow & Paywall Builder, avec spend_button dans le champ Type et unlimited_energy dans le champ ID" />

3. Réduisez la hauteur **Fixed** de chaque élément personnalisé de 200 à la hauteur dont le bouton a besoin.
4. À l'intérieur de chaque élément personnalisé, ajoutez un élément texte et saisissez les mots correspondant à son option :
   - Rechargement d'énergie : « Mettez le jeu à jour pour recharger l'énergie. »
   - Énergie illimitée : « Mettez le jeu à jour pour obtenir l'énergie illimitée. »

   Dans les versions de l'application sans la vue de bouton, les utilisateurs voient ce texte comme [contenu de secours](flow-custom-elements#set-fallback-content), sans bouton sur lequel appuyer.
