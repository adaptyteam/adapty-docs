Vous ne pouvez pas publier ni prévisualiser votre flow si l'un des problèmes suivants est présent.

- Une interaction avec une configuration incomplète. Cas fréquents :
    - Une action **Open URL** sans URL cible.
    - Une action **Navigate to screen** sans destination — survient également lorsque l'écran de destination est supprimé après la configuration de l'action.
    - Une **action conditionnelle** sans opérateur ni valeur.
    - Une action **Set variable** sans attribution de variable ou de valeur.
    - Une action **Purchase** sans produit (store intégré) ou sans URL de Web Paywall (paiement web).
    - Une action **Custom** sans identifiant d'action.
    - Une action **Show alert** avec un titre ou un message vide.
    - Une action **Show** ou **Hide** sans élément sélectionné.
    - Une action **Select product** sans produit cible — survient également lorsque l'élément produit cible est supprimé, déplacé hors de son groupe de produits ou laissé sur un autre écran.
    - Une action **Select product** enregistrée dans un composant réutilisable, ou ciblant un identifiant d'élément utilisé sur plusieurs écrans.
- Un **écran sans éléments**.
- Un élément produit **sans produit associé** — peut survenir si vous supprimez le produit référencé.
- Un JSON de **Remote Config** invalide qui interrompt l'ensemble du processus de livraison — vous ne pouvez même pas enregistrer le brouillon.
