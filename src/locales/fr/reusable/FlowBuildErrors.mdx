Vous ne pouvez pas publier ni prévisualiser votre flow si l'un des problèmes suivants est présent.

- Une interaction avec une configuration incomplète. Cas courants :
    - Une action **Open URL** sans URL cible.
    - Une action **Navigate to screen** sans destination — se produit aussi lorsque l'écran de destination est supprimé après la configuration de l'action.
    - Une **action conditionnelle** sans opérateur ni valeur.
    - Une action **Set variable** sans assignation de variable ou de valeur.
    - Une action **Purchase** sans produit (store intégré) ou sans URL de paywall web (paiement web).
    - Une action **Custom** sans identifiant d'action (Action ID).
    - Une action **Show alert** avec un titre ou un message vide.
    - Une action **Show** ou **Hide** sans élément sélectionné.
    - Une action **Select product** sans produit cible — se produit aussi lorsque l'élément produit cible est supprimé, déplacé hors de son groupe de produits, ou laissé sur un autre écran.
    - Une action **Select product** enregistrée dans un composant réutilisable, ou qui cible un identifiant d'élément utilisé sur plusieurs écrans.
- Une **condition qui utilise un élément, un état ou une variable supprimé(e)** — bloque la publication jusqu'à ce que vous en sélectionniez un(e) existant(e) ou que vous supprimiez la condition.
- Un **écran sans éléments**.
- Un élément produit **sans produit associé** — peut se produire si vous supprimez le produit référencé.
- Un JSON de **Remote Config** invalide bloque l'ensemble du processus de livraison — vous ne pouvez même pas enregistrer le brouillon.
