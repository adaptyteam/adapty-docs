1. Ajoutez un [élément **Products**](paywall-product-block#add-a-product-group) avec les packs de diamants. Pour déclencher l'achat d'un pack lorsqu'un joueur appuie sur sa carte, associez l'[action **Purchase** à chaque carte](paywall-product-block#trigger-purchase-from-a-product-card).
2. Pour proposer l'abonnement sur le même écran que les packs, ajoutez un [bouton d'achat](paywall-product-block#add-a-purchase-button). Dans l'action **Purchase** du bouton, sélectionnez l'abonnement dans le menu déroulant **Product**. Dans le texte du bouton, insérez les variables [`prod_price` et `prod_billing_period`](onboarding-variables#product-variables) de l'abonnement.
3. Dans un élément texte de chaque carte, indiquez le nombre de diamants reçus par le joueur, par exemple « 500 diamants ». Ajoutez un élément texte pour l'abonnement et indiquez le nombre de diamants reçus par période de facturation, par exemple « 300 diamants par mois ». Veillez à ce que chaque chiffre corresponde au **Credit amount** ou au **Credit per cycle** du produit : aucune [variable de produit](onboarding-variables#product-variables) ne contient cette valeur. Si le nom de chaque pack dans le store inclut déjà le chiffre, comme « 500 Diamonds », insérez plutôt la variable `prod_title`.
4. Pour permettre aux joueurs de fermer le flow sans effectuer d'achat, ajoutez un [bouton **Close**](basic-paywall-screen#3-add-the-close-button). Ajoutez les [liens de pied de page](basic-paywall-screen#9-add-footer-links) : les stores exigent les liens vers les Conditions d'utilisation et la Politique de confidentialité partout où les joueurs peuvent souscrire un abonnement.
