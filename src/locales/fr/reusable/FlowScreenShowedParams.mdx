Un flow déclenche `flow_screen_showed` chaque fois qu'un utilisateur ouvre l'un de ses écrans. Adapty comptabilise ces événements dans ses propres analytiques de flow et les transmet également à votre application, afin que vous puissiez reconstituer le même entonnoir dans vos propres outils d'analyse.

| Paramètre        | Description                                                                                                                  |
|:-----------------|:---------------------------------------------------------------------------------------------------------------------------------|
| `instanceId`     | L'identifiant de l'écran que l'utilisateur a ouvert.                                                                        |
| `screen_order`   | La position de l'écran dans le flow.                                                                                           |
| `is_last_screen` | `true` lorsque l'écran n'a nulle part où aller ensuite. Un flow avec branchements peut se terminer sur plusieurs écrans différents, et chacun d'eux retourne `true`. Un écran de paywall retourne `false` si l'une de ses [actions de résultat](respond-to-purchase-outcomes#add-actions-for-a-result) navigue vers un autre écran, quel que soit le résultat de l'achat ou de la restauration. Une action **Navigate back** n'est pas prise en compte. Une navigation vers un écran n'est pas comptabilisée non plus si tous les utilisateurs voient cet écran avant le paywall. |

`isBackendEvent` et `isCustomerEvent` sont tous les deux `true` pour cet événement : Adapty continue de le comptabiliser, et votre application le reçoit également.
