Le Flow & Paywall Builder ne peut pas exécuter le code de votre application, donc son canvas n'affiche que le fallback. Pour prévisualiser l'animation :

1. [Publiez le flow](builder-save-publish). Pour voir la dernière version publiée plutôt qu'une version en cache, enregistrez l'appareil comme [appareil de test](test-devices).
2. Lancez un build de votre application incluant le resolver. Réglez le streak à 0 jour, ouvrez l'écran et vérifiez que l'anneau se remplit jusqu'à cette valeur. Répétez avec d'autres valeurs, comme 4 et 7 jours.

Pour tester le fallback, supprimez le fichier d'animation du build, puis rouvrez l'écran.
