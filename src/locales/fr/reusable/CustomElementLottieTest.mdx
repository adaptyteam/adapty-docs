Le Flow & Paywall Builder ne peut pas exécuter le code de votre application, donc son canvas affiche uniquement le fallback. Pour prévisualiser l'animation :

1. [Publiez le flow](builder-save-publish). Pour voir la dernière version publiée plutôt qu'une version en cache, enregistrez l'appareil comme [appareil de test](test-devices).
2. Lancez un build de votre application incluant le resolver. Définissez le streak à 0 jour, ouvrez l'écran et vérifiez que l'anneau reste vide. Recommencez avec 4 et 7 jours, et vérifiez que l'anneau se remplit jusqu'à chaque valeur.

Pour tester le fallback, supprimez le fichier d'animation du build, puis rouvrez l'écran.
