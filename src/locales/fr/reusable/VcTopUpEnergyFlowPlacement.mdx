Dans le Flow & Paywall Builder, créez le flow « manque d'énergie ». Ajoutez le flow à un [placement](placements) avec l'ID `out_of_energy`. Quand un joueur n'a plus d'énergie, le code de l'étape 2 ouvre le flow depuis ce placement.

Pour permettre aux joueurs de fermer le flow sans effectuer d'achat, ajoutez un [bouton **Fermer**](basic-paywall-screen#3-add-the-close-button).
