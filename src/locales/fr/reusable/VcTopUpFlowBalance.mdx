Pour afficher le solde en diamants, utilisez un [élément personnalisé](flow-custom-elements) : un élément dans lequel les utilisateurs voient une vue native issue du code de votre application. Quand le code de votre application modifie le solde pendant que le flow est ouvert (par exemple après une dépense), les utilisateurs voient le nouveau solde.

1. [Ajoutez un élément personnalisé](flow-custom-elements#add-and-configure) à l'écran, puis renseignez son **Type** et son **ID** :
   - **Type** : `currency_balance`.
   - **ID** : `diamonds`.

   Le code de l'[étape 2](#create-the-balance-view) associe la vue du solde à l'élément personnalisé via ce Type et cet ID.

   <ZoomImage id="vc-top-up-custom-element.webp" width="700px" alt="Custom element settings in the Flow & Paywall Builder, with currency_balance in the Type field, diamonds in the ID field, and an Icon inside the Diamond balance layer" />

2. À l'intérieur de l'élément personnalisé, ajoutez une [**Icône**](custom-media#icon) de diamant. Dans les versions de l'application sans la vue du solde, les utilisateurs voient l'icône comme [contenu de secours](flow-custom-elements#set-fallback-content).
