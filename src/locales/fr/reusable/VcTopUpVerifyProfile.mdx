Dans l'[historique des événements](virtual-currency-balance#review-balance-changes-in-the-event-history) du joueur, vérifiez les entrées suivantes :

- **Virtual currency credited** : Pour chaque achat ou renouvellement qui ajoute des diamonds.
- **Virtual currency debited** : Pour chaque dépense effectuée, avec le label `energy_refill` ou `unlimited_energy`. Adapty nomme cette entrée d'après l'opération `spend`. Sans `operation`, Adapty la nomme **Virtual currency transaction**.
- **Virtual currency adjusted** : Pour chaque débit manuel avec l'opération **Adjustment**, comme celui de l'étape 6.
- **Virtual currency expired** : Pour les diamonds d'abonnement qui expirent sans avoir été dépensés.
