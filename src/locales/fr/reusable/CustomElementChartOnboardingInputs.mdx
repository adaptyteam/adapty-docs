Dans le Flow & Paywall Builder, ajoutez deux saisies [**Number**](builder-inputs-and-forms) à l'onboarding flow :

- Une pour le poids actuel en kilogrammes, avec l'**Element ID** `weight`.
- Une pour le poids cible en kilogrammes, avec l'**Element ID** `goal_weight`.

Pour que votre application lise les poids de la même façon dans toutes les langues, sélectionnez **Integer** dans le menu déroulant **Format** des deux saisies. Une saisie envoie sa valeur à votre application sous forme de texte, exactement tel que l'utilisateur l'a tapé. Le code de cette recette interprète « 70.5 » et « 70,5 » différemment. Les nombres entiers n'ont pas de séparateur décimal.

Pour vous assurer que votre application reçoive les deux valeurs, terminez l'onboarding flow par un écran sans saisies. Sur cet écran, ajoutez un bouton avec l'action [**Close flow**](onboarding-actions#close-flow). Les saisies envoient leurs valeurs lorsqu'elles perdent le focus ou lorsque l'utilisateur passe à un autre écran.
