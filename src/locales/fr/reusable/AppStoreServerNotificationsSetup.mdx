1. Dans Adapty, ouvrez l'application que vous connectez : chaque application Adapty possède sa propre URL de notification. Rendez-vous dans [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). Dans la section **App Store server notifications**, copiez l'URL depuis le champ **URL for App Store server notifications**.

   <ZoomImage id="app-settings-notifications-url.webp" width="700px" alt="URL for App Store server notifications in the App Store server notifications section in Adapty" />

2. Dans [App Store Connect](https://appstoreconnect.apple.com/apps), ouvrez la page **App Information** de votre application.
3. Dans la section **App Store Server Notifications**, repérez **Production Server URL**. Si une URL est déjà présente, cliquez sur **Edit**. Sinon, cliquez sur **Set Up URL**.

   <ZoomImage id="asc-server-notifications-set-up-url.webp" width="700px" alt="App Store Server Notifications section on the App Information page in App Store Connect" />

4. Collez l'URL d'Adapty, puis cliquez sur **Save**.

   <ZoomImage id="asc-server-url-set-up-dialog.webp" width="700px" alt="Production Server URL dialog in App Store Connect with the URL from Adapty" />

5. Pour que les notifications de vos tests sandbox parviennent à Adapty, répétez les étapes 3 et 4 pour **Sandbox Server URL**.
