Sous le champ **URL**, trouvez le lien **generate one with AI**. Cliquez dessus.

Développez le panneau **Generation setup** et complétez ses six étapes dans l'ordre. Chaque bouton ouvre la page correspondante, cliquez donc sur **Refresh** quand vous revenez.

<ZoomImage id="mail-checkout-prerequisites.webp" width="500px" alt="Liste de vérification Generation setup sur la page de création du Web Paywall" />

| Élément de la liste | Quoi faire |
| --- | --- |
| **1. Brand is ready** | Déjà coché si vous avez configuré votre [marque](mail-brand). Sinon, cliquez sur **Set up brand**. |
| **2. Log in to the paywall builder dashboard** | Cliquez sur **Log in** pour vous authentifier dans le builder. |
| **3. Stripe account connected** | Cliquez sur **Connect Stripe** et connectez votre compte. |
| **4. At least one Stripe product with a price** | Cliquez sur **Open Stripe dashboard** et ajoutez un produit avec un prix. |
| **5. Generate the paywall** | 5.1. Cliquez sur **Generate**.<br />5.2. Choisissez jusqu'à trois plans. Cliquez sur **Add plan** pour chacun d'eux après le premier.<br />5.3. Donnez à chaque plan un prix de production, un prix sandbox, ou les deux, dans une même devise. Remplissez la même colonne pour chaque plan — une colonne partiellement remplie bloque la génération. Sans prix sandbox, les [e-mails de test](mail-testing) renvoient vers le paywall de production, où les achats de test ne fonctionnent pas.<br />5.4. Cliquez sur **Generate paywall**. L'opération prend quelques minutes, et le champ **URL** se remplit automatiquement une fois terminé. |
| **6. Review and publish the paywall in the builder** | Cliquez sur **Open editor**, puis vérifiez et publiez. Désactivé tant que le paywall n'a pas été généré. |

<ZoomImage id="mail-checkout-generation-dialog.webp" width="500px" alt="Boîte de dialogue Generate a paywall avec les colonnes de prix de production et sandbox" />

<Callout type="important">
Le paywall doit être publié avant de pouvoir traiter le trafic de checkout. Les paywalls non publiés renvoient une erreur quand les utilisateurs cliquent sur les liens de checkout dans les e-mails.
</Callout>

Une fois le paywall publié, cliquez sur **Save**.
