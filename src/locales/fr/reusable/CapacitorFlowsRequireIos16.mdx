À partir du SDK 4.4, les flows nécessitent iOS 16 ou une version ultérieure. Sur iOS 15, `createFlowView` renvoie une erreur avec le code `platformNotSupported`. Lorsque votre application reçoit cette erreur, affichez votre propre contenu à la place du flow, comme un [paywall personnalisé](capacitor-implement-paywalls-manually).
