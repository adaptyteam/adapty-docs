1. Dans App Store Connect, allez dans [**Users and Access** > **Integrations** > **App Store Connect API**](https://appstoreconnect.apple.com/access/integrations/api), et ouvrez l'onglet **Team Keys**. Adapty a besoin d'une clé d'équipe : les clés individuelles n'ont pas d'Issuer ID.

   Une seule clé d'équipe couvre toutes les applications de votre équipe App Store Connect. Si une clé active dans cet onglet dispose d'un accès **Admin** et que vous avez son fichier, réutilisez-la et passez les étapes 2 à 4.

   Si votre équipe n'a pas encore accès à l'API App Store Connect, le titulaire du compte [en fait la demande](https://developer.apple.com/help/app-store-connect/get-started/app-store-connect-api). Apple examine chaque demande.

2. Pour générer une clé, vous devez avoir le rôle Account Holder ou Admin dans App Store Connect. Si vous n'avez ni l'un ni l'autre, demandez à quelqu'un qui l'a de générer une clé avec l'accès **Admin** et de vous envoyer le fichier avec son Issuer ID et son Key ID.

   Si l'onglet liste déjà des clés actives, cliquez sur **+**. Sinon, cliquez sur **Generate API Key**.

   <ZoomImage id="asc-team-keys-add.webp" width="700px" alt="Onglet Team Keys de la page App Store Connect API dans App Store Connect" />

3. Saisissez un nom pour la clé et définissez **Access** sur **Admin**. **Access** détermine ce qu'Adapty peut faire avec la clé, quel que soit votre propre rôle. Vous ne pouvez pas modifier **Access** après avoir généré la clé. Cliquez sur **Generate**.

   <ZoomImage id="asc-team-key-generate-dialog.webp" width="700px" alt="Boîte de dialogue pour une nouvelle clé d'équipe, avec un nom et le menu déroulant Access" />

4. Vous ne pouvez télécharger chaque clé qu'une seule fois. À côté de la nouvelle clé, cliquez sur **Download**. Conservez le fichier en lieu sûr : vous le téléversez dans chaque application Adapty qui utilise la clé.

   <ZoomImage id="asc-team-key-download.webp" width="700px" alt="Liste active des clés d'équipe, avec le lien Download à côté d'une nouvelle clé" />
