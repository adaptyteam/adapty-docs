import Callout from '../../../components/Callout.astro';

:::important
Les champs, les sélecteurs de date/heure et les groupes à choix multiples n'envoient jamais leur valeur par défaut via ce callback. Si un utilisateur accepte l'option marquée **Set as default** et passe à la suite, aucun événement n'est déclenché. N'interprétez pas l'absence d'événement comme « pas de réponse » — l'utilisateur a simplement conservé la valeur par défaut. Un [sélecteur numérique](builder-number-picker) envoie son nombre par défaut au code de votre application lorsque l'utilisateur appuie sur un bouton qui ouvre un autre écran.
:::

**Les éléments suivants déclenchent cet événement :**

- Champs texte, e-mail, numérique et téléphone
- Sélecteurs de date, d'heure et de date-heure
- Sélecteurs numériques
- Groupes à choix unique et à choix multiple, et bascules

**Les éléments suivants ne le déclenchent pas :**

- Les champs mot de passe, les sélections de produits et les commutateurs d'onglets
- Les saisies dans un élément Header, partagé entre les écrans
- Les groupes à choix multiples dont les options ont des ID d'élément dupliqués ou manquants, ou dont l'ID de groupe est réutilisé sur un autre écran. Un tel groupe n'envoie rien du tout, plutôt qu'une réponse partielle.

**L'événement est déclenché quand :**

- Un champ perd le focus. Un champ vidé renvoie une chaîne vide ; un champ que l'utilisateur n'a jamais modifié ne renvoie rien. Un placeholder n'est pas une valeur. Si l'utilisateur revient sur le champ, le modifie et le quitte à nouveau, un second événement est déclenché.
- L'utilisateur ferme un sélecteur de date ou d'heure après avoir choisi une nouvelle valeur. Le fermer sans modification ne renvoie rien.
- Sur un écran avec un sélecteur numérique, l'utilisateur appuie sur un bouton qui exécute une action **Navigate to Screen**, **Navigate Next** ou **Navigate back** [action](onboarding-actions). Le sélecteur numérique renvoie également sa valeur lorsque l'utilisateur appuie sur une option ou une bascule sur le même écran. Si l'utilisateur n'a jamais fait tourner la molette, la valeur est le nombre par défaut. Un sélecteur numérique renvoie sa valeur même lorsqu'il est masqué, par exemple dans un onglet que l'utilisateur n'a pas ouvert. Aucun second événement ne suit tant que la valeur ne change pas.
- L'utilisateur appuie sur une option ou une bascule. Un événement à choix multiple liste toutes les options sélectionnées ; désélectionner la dernière envoie donc deux tableaux vides.

**L'événement n'est pas déclenché quand :**

- L'utilisateur saisit du texte. Il n'y a pas de flux de frappe, uniquement la valeur que contient le champ au moment où il perd le focus.
- L'utilisateur soumet ou ferme le flow. Une valeur en cours de modification à ce moment-là peut être perdue. Un bouton qui ferme le flow, démarre un achat ou exécute une action personnalisée ne renvoie pas la valeur d'un sélecteur numérique. La section [limitations de livraison](#delivery-and-limitations) explique comment concevoir le dernier écran en tenant compte des deux cas.
- Une valeur est définie sans interaction de l'utilisateur. Une option marquée **Set as default** est présélectionnée à l'ouverture de l'écran, et une action **Set Variable** peut sélectionner une option ou remplir une saisie depuis une autre interaction. Aucune des deux n'envoie d'événement ; une saisie préremplie autre qu'un sélecteur numérique n'est signalée qu'une fois que l'utilisateur la modifie.
