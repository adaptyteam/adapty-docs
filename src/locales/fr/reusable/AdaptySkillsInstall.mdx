Si vous avez déjà installé le plugin Adapty, vous disposez de ce skill. Si votre agent ne le répertorie pas, mettez à jour le plugin avec la commande correspondant à votre agent dans le [README du plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Pour installer le plugin dans un agent de codage, exécutez dans votre terminal :

```bash
npx adapty skills install
```

Redémarrez votre agent pour charger le plugin. Pour installer le plugin dans claude.ai ou Claude desktop, consultez [Installer le plugin](manage-adapty-with-ai#install-the-plugin). Pour les autres méthodes d'installation, consultez le [README du plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Claude Code ne met pas à jour le plugin automatiquement. Pour obtenir les nouveaux skills dès leur publication, dans Claude Code, exécutez `/plugin`, ouvrez **Marketplaces**, sélectionnez `adapty` et choisissez **Enable auto-update**. Pour la commande de mise à jour dans d'autres agents, consultez le [README du plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).
