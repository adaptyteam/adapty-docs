Dans le Flow & Paywall Builder, créez le flow de rechargement. Ajoutez ce flow à un [placement](placements) avec l'ID `out_of_diamonds`. Lorsque le solde est trop faible pour une dépense, le code de l'étape 4 ouvre le flow depuis ce placement.

Pour afficher un flow de rechargement différent selon le solde, ajoutez une [audience](audience) avec un [segment par solde de monnaie virtuelle](segments#virtual-currency-balance) au placement `out_of_diamonds`. Par exemple, affichez un flow distinct aux utilisateurs ayant 0 diamant. Adapty lit le solde à chaque fois que le code de votre application récupère le flow, ce qui fait qu'une dépense ou un achat peut modifier le flow affiché à l'utilisateur par la suite.

Pour afficher également le solde de diamants dans ce flow, [ajoutez un élément personnalisé](flow-custom-elements#add-and-configure) avec le même Type et le même ID que dans le flow « out-of-energy » : `currency_balance` et `diamonds`. À l'intérieur de l'élément personnalisé, ajoutez l'**Icon** du diamant en tant que solution de secours. Les joueurs voient la même vue du solde dans les deux flows, et vous n'avez pas besoin d'ajouter du code pour cela.
