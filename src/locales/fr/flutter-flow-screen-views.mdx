Chaque fois qu'un utilisateur ouvre un écran dans un [flow](adapty-flow-builder), le SDK signale un événement `flow_screen_showed` à votre application. Transmettez-le à Amplitude, Mixpanel ou tout autre outil d'analyse produit que vous utilisez, afin d'analyser les écrans de flow avec le reste des événements de votre application.

:::tip
Pour voir jusqu'où les utilisateurs avancent dans un flow, aucun code n'est nécessaire — les [métriques de flow](flow-metrics) affichent déjà les vues, les complétions et les abandons par écran dans l'Adapty Dashboard. Utilisez ce guide si vous avez besoin des mêmes données dans votre propre outil d'analyse, combinées avec des événements qu'Adapty ne connaît pas.
:::

## Avant de commencer \{#before-you-start\}

Vous avez besoin de :

- **Adapty Flutter SDK v4 ou ultérieur** : le callback d'analyse de flow n'existe pas dans les versions antérieures.
- **Une version de flow publiée après la sortie de cette fonctionnalité** : Adapty génère les événements d'écran lors de la publication d'un flow, donc un flow publié avant cette date ne rapporte rien. Si aucun événement ne parvient à votre application, publiez une nouvelle version du flow et réessayez.

## Ce que vous recevez \{#what-you-receive\}

<FlowScreenShowedParams />

Les vues d'écran arrivent dans le même callback d'analyse que tous les autres événements de flow. Consultez [Gérer les événements de flow et de paywall](flutter-handling-events) pour savoir où l'enregistrer.

## Transmettez chaque vue d'écran à votre analytics \{#forward-every-screen-view-to-your-analytics\}

Vérifiez d'abord le nom de l'événement avant de lire quoi que ce soit d'autre, car un flow signale d'autres événements via le même callback.

```dart showLineNumbers title="Flutter"
void flowViewDidReceiveAnalyticEvent(
  AdaptyUIFlowView view,
  String name,
  Map<String, dynamic> params,
) {
  if (name != 'flow_screen_showed') return;

  final screenId = params['instanceId'];
  final screenOrder = params['screen_order'];

  // Send screenId and screenOrder to your analytics provider here.
}
```

## Exécuter du code quand l'utilisateur atteint la fin \{#run-code-when-a-user-reaches-the-end\}

`is_last_screen` vaut `true` sur un écran que le flow ne peut pas dépasser. Utilisez-le pour débloquer du contenu, marquer l'onboarding comme terminé ou envoyer un événement de complétion personnalisé, sans avoir à ajouter une action de bouton dans le builder.

```dart showLineNumbers title="Flutter"
void flowViewDidReceiveAnalyticEvent(
  AdaptyUIFlowView view,
  String name,
  Map<String, dynamic> params,
) {
  if (name != 'flow_screen_showed') return;
  if (params['is_last_screen'] != true) return;

  // The user reached the end of the flow.
}
```

Atteindre le dernier écran n'est pas la même chose que fermer le flow. Un utilisateur peut voir l'écran final et fermer le flow sans agir dessus, et un flow avec des branches peut se terminer sur plusieurs écrans différents. Pour savoir que le flow lui-même a disparu, utilisez plutôt `flowViewDidDisappear`.
