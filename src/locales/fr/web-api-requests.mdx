L'API côté serveur d'Adapty vous permet d'accéder et de gérer vos données d'abonnement par programmation, facilitant ainsi l'intégration avec vos services et infrastructures existants. Que vous synchronisiez des données entre plateformes, accordiez des niveaux d'accès ou validiez des achats dans Stripe, cette API fournit les outils nécessaires pour maintenir vos systèmes synchronisés et vos utilisateurs engagés.

## Collection Postman et environnement \{#postman-collection-and-environment\}

Pour simplifier l'utilisation de notre API web, nous avons préparé une collection Postman et un fichier d'environnement que vous pouvez télécharger et importer dans Postman.

- **Request Collection** : Inclut toutes les requêtes disponibles dans l'API web Adapty. Elle utilise des variables que vous pouvez définir dans l'environnement.
- **Environment** : Contient une liste de variables où vous pouvez définir des valeurs une seule fois. Nous avons préparé un environnement unifié pour l'API côté serveur, l'API web et l'API d'export analytique pour vous simplifier la tâche. Une fois cet environnement activé, Postman substituera automatiquement les valeurs des variables définies dans vos requêtes.

:::tip

[Téléchargez la collection et l'environnement](https://raw.githubusercontent.com/adaptyteam/adapty-docs/refs/heads/main/Downloads/Adapty_Web_API_postman_collection.zip)

:::

Pour savoir comment importer une collection et un environnement dans Postman, consultez la [documentation Postman](https://learning.postman.com/docs/getting-started/importing-and-exporting/importing-data/).

## Variables utilisées \{#variables-used\}

Nous avons créé un environnement unifié pour l'API côté serveur, l'API web et l'API d'export analytique afin de simplifier votre workflow. Voici les variables spécifiques à l'API web :

| Variable                | Description                                                  | Example Value                                           |
| ----------------------- | ------------------------------------------------------------ | ------------------------------------------------------- |
| public_api_key          | Vous pouvez le trouver dans le champ **Public SDK key** dans les [**App settings**](https://app.adapty.io/settings/general). | `public_live_Pj1P1xzM.2CvSvE1IalQRFjsWy6csBVNpH33atnod` |
| adapty-customer-user-id | L'identifiant utilisateur utilisé dans votre système. Dans l'Adapty Dashboard, vous pouvez le trouver dans le champ **Customer user ID** du profil. | `john.doe@example.com`                                  |
| adapty-profile-id       | L'identifiant utilisateur attribué dans Adapty. Dans l'Adapty Dashboard, vous pouvez le trouver dans le champ **Adapty ID** du profil. | `3286abd3-48b0-4e9c-a5f6-ac0a006333a6`                  |
