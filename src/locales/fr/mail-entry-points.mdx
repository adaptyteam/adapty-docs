Un point d'entrée, c'est la façon dont les données utilisateur arrivent dans Adapty Mail. Quelle que soit l'option choisie, elle transporte toujours les trois mêmes éléments :

- **Leur adresse e-mail** (obligatoire) : la destination de vos e-mails. Sans adresse, Adapty Mail ne crée aucun profil.
- **Leur [identifiant utilisateur client](how-profiles-work)** (facultatif, mais recommandé) : votre propre identifiant stable. Adapty conserve un seul profil par personne entre les réinstallations et les connexions, ce qui permet d'atteindre un utilisateur pour un achat effectué avant qu'il vous ait fourni une adresse e-mail.
- **Leur flux d'événements d'abonnement** (facultatif, mais recommandé) : les essais, les renouvellements, les annulations et les remboursements, au fur et à mesure qu'ils se produisent. Sans ce flux, la seule séquence que quiconque peut recevoir est celle destinée aux personnes n'ayant jamais effectué d'achat.

Pick the entry point that matches your app:

- **Adapty** : À utiliser si votre application exécute déjà le SDK Adapty. Adapty transmet les profils, les adresses e-mail et les événements d'abonnement à votre place, sans que vous ayez besoin d'un serveur propre. Dans votre application, ajoutez l'identification des utilisateurs et la collecte des e-mails. Voir [Connecter Adapty à Adapty Mail](mail-collect-emails).
- **Adapty Mail API** : À utiliser si vous disposez déjà d'un backend contenant ces données, si votre application n'intègre pas le SDK Adapty, ou si vous importez des abonnés depuis une autre source. Vous publiez vous-même les profils et les événements de transaction. La clé secrète dans **Settings** > **Project** authentifie les requêtes. Voir [Envoyer des e-mails et des transactions via l'Adapty Mail API](mail-send-data-via-api).
- **FunnelFox** : À utiliser si vous acquérez et facturez vos utilisateurs via les tunnels web FunnelFox. FunnelFox détient déjà leurs e-mails, achats et événements d'abonnement, et les transmet automatiquement à Adapty Mail — pas de SDK à intégrer, pas de requêtes à écrire. Voir [Connecter FunnelFox à Adapty Mail](mail-funnelfox).
- **Une combinaison** : Vous pouvez utiliser plusieurs points d'entrée simultanément. Adapty Mail regroupe les personnes par adresse e-mail. Deux sources signalant la même adresse aboutissent sur un seul profil ; deux adresses différentes créent des profils distincts, même si le `customer_user_id` est identique.
