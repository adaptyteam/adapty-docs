Un point d'entrée désigne la façon dont les données utilisateur arrivent dans Adapty Mail. Quelle que soit l'option choisie, Adapty Mail a besoin des trois mêmes éléments avant de pouvoir envoyer un e-mail à un utilisateur :

- **Leur adresse e-mail** : la destination de vos e-mails.
- **Leur [identifiant utilisateur client](how-profiles-work)** : l'identifiant unique de l'utilisateur.
- **Leur flux d'événements d'abonnement** : essais, renouvellements, annulations et remboursements, en temps réel.

Choisissez le point d'entrée qui correspond à votre application :

- **Adapty** : utilisez cette option si votre application fait déjà tourner le SDK Adapty. Adapty transfère automatiquement les profils, les e-mails et les événements d'abonnement, sans qu'un serveur côté vous soit nécessaire. Dans votre application, ajoutez l'identification des utilisateurs et la collecte des e-mails. Consultez [Connecter Adapty à Adapty Mail](mail-collect-emails).
- **Adapty Mail API** : utilisez cette option si vous disposez déjà d'un backend qui héberge ces données, si votre application ne contient pas le SDK Adapty, ou si vous importez des abonnés depuis une autre source. Vous publiez vous-même les profils et les événements de transaction. La clé secrète dans **Settings** > **Project** authentifie les requêtes. Consultez [Envoyer des e-mails et des transactions via l'Adapty Mail API](mail-send-data-via-api).
- **FunnelFox** : utilisez cette option si vous acquérez et facturez des utilisateurs via les funnels web FunnelFox. FunnelFox détient déjà leurs e-mails, achats et événements d'abonnement, et les transmet automatiquement à Adapty Mail — pas de travail SDK, pas de requêtes à écrire. Consultez [Connecter FunnelFox à Adapty Mail](mail-funnelfox).
- **Une combinaison** : vous pouvez utiliser plusieurs points d'entrée simultanément. Adapty Mail fait correspondre les données utilisateur entrantes sur `customer_user_id` et l'adresse e-mail, de sorte qu'une personne connue via plusieurs sources n'obtient qu'un seul profil et une seule séquence, sans e-mails en double.
