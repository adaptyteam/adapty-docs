FunnelFox est l'un des points d'entrée d'Adapty Mail — utilisez-le lorsque vous acquérez et facturez des utilisateurs via les funnels web [FunnelFox](https://funnelfox.com). FunnelFox détient déjà leurs adresses e-mail, achats et événements d'abonnement, donc la connexion ne nécessite aucun travail SDK ni aucune requête de votre part.

La connexion est unidirectionnelle. FunnelFox envoie des données à Adapty Mail ; il ne lit jamais vos campagnes en retour et n'envoie jamais d'e-mails lui-même.

## Ce que FunnelFox envoie \{#what-funnelfox-sends\}

- **Profils et adresses e-mail**, dès lors qu'un funnel collecte un e-mail.
- **Identifiants** : l'ID de profil FunnelFox du destinataire, et l'ID utilisateur personnalisé que votre funnel conserve pour lui, s'il en a un. Sur la page du profil, ils apparaissent sous **External Profile IDs**, sous forme d'une ligne **FunnelFox** et d'une ligne **Custom**.
- **Historique des achats** : abonnements, renouvellements et achats uniques. Les remboursements arrivent sous forme de montants négatifs.
- **Événements d'abonnement** : annulations, réactivations, problèmes de facturation et expirations. Ce sont eux qui placent chaque utilisateur dans un [flow](mail-flows).
- **Attributs du profil** : pays, appareil, OS, plateforme et locale — ces cinq éléments sont des filtres de [segment](mail-segments). FunnelFox lit les quatre derniers depuis le user agent du navigateur. Il envoie également le fuseau horaire, qui détermine à quel moment le destinataire reçoit l'e-mail, mais ce n'est pas un filtre. Il n'envoie jamais de version d'application, donc ce filtre reste vide pour les utilisateurs du funnel.
- **Contexte du funnel**, stocké sous forme d'attributs personnalisés sur le profil avec ces clés :
  - `fnlfx_funnel_id` : le funnel qui a collecté l'e-mail.
  - `fnlfx_session_id` : la session du funnel.
  - `fnlfx_experiment_id` : l'expérience du funnel, si l'utilisateur en faisait partie.
  - `email_consent` : si l'utilisateur a accepté de recevoir des e-mails dans le funnel. La valeur est le texte `"true"` ou `"false"`, donc un filtre de segment sur cette clé compare du texte.

Pour transmettre l'une de ces valeurs à une page de paiement, ajoutez son espace réservé au lien — par exemple, `{custom_attribute.fnlfx_session_id}`. Consultez les [espaces réservés](mail-destinations#placeholders).

Les données parviennent à Adapty Mail environ une minute après l'événement du funnel.

## Connecter FunnelFox \{#connect-funnelfox\}

Finalisez d'abord la configuration d'Adapty Mail — consultez [Démarrer avec Adapty Mail](mail-get-started). Sans flow, aucun message envoyé ne produira d'e-mail.

1. Dans Adapty Mail, accédez à **Settings** > **Project** et copiez la **Secret key**.
2. Dans FunnelFox, accédez à **Integrations** > **Adapty Mail**.
3. Collez la clé et enregistrez.

Pour la configuration côté FunnelFox, consultez le [guide d'intégration de FunnelFox](https://funnelfox.com/docs/integrations/email-providers/adapty-mail).

## Une fois la connexion établie \{#after-you-connect\}

Sur la page d'un profil, **External Profile IDs** affiche une ligne **FunnelFox** avec l'identifiant que FunnelFox utilise pour cette personne. Un profil signalé par plusieurs sources comporte une ligne pour chacune, ce qui vous permet de voir toutes les sources qui le connaissent.

Lorsque vous construisez un lien de paiement manuellement, `{funnelfox.external_profile_id}` est remplacé par l'identifiant du profil du destinataire dans FunnelFox. [Destinations e-mail](mail-destinations#placeholders) liste tous les espaces réservés.

## Utiliser en parallèle avec un autre point d'entrée \{#use-it-alongside-another-entry-point\}

Vous pouvez utiliser FunnelFox et un autre [point d'entrée](mail-entry-points) simultanément. Adapty Mail associe les personnes par adresse e-mail. Deux sources signalant la même adresse se regroupent sur un seul profil ; deux adresses différentes créent des profils distincts, même si le `customer_user_id` est identique.
