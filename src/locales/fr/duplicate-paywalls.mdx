Dupliquer un paywall est la méthode à utiliser lorsque vous souhaitez modifier les produits ou offres d'un paywall qu'Adapty ne permet plus d'éditer — consultez [Ajouter une offre à un paywall](create-offer#add-offer-to-paywall) pour savoir dans quels cas cette restriction s'applique. La duplication permet également de conserver les données analytiques du paywall d'origine lorsque vous apportez de petites modifications à un paywall déjà actif dans votre application. Vous pouvez ensuite utiliser les duplicatas pour remplacer les paywalls d'origine dans certains ou tous les placements selon vos besoins.

Cela crée une copie du paywall avec tous ses détails, comme son nom, ses produits et ses éventuelles promotions. Le nouveau paywall aura « Copy » ajouté à son nom pour le distinguer facilement de l'original.

Pour dupliquer un paywall dans l'Adapty Dashboard :

1. Ouvrez la section [**Paywalls**](https://app.adapty.io/paywalls) dans le menu principal d'Adapty. La page de liste des paywalls dans l'Adapty Dashboard donne un aperçu de tous les paywalls présents dans votre compte.
2. Cliquez sur le bouton **3-dot** à côté du paywall et sélectionnez l'option **Duplicate**.

3. Ajustez le nouveau paywall et cliquez sur le bouton **Save**.
4. Adapty vous proposera de remplacer les paywalls originaux par leurs duplicatas dans les placements si le paywall original est actuellement utilisé dans un placement. Si vous choisissez **Create and replace original**, les nouveaux paywalls passeront immédiatement en état **Live**. Vous pouvez aussi les créer en tant que nouveaux paywalls à l'état **Draft** et les ajouter aux placements ultérieurement.
