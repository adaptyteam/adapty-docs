Exporter vos données analytiques en CSV vous donne la flexibilité d'approfondir les métriques de performance de votre application, de personnaliser des rapports et d'analyser les tendances au fil du temps. Avec l'API Adapty, vous pouvez facilement extraire des analyses détaillées au format CSV, ce qui facilite le suivi, le partage et l'affinage de vos données selon vos besoins.

:::tip
Vous utilisez un agent IA ou un LLM pour extraire des analytics ? Consultez [Exporter vos analytics avec un agent IA](export-analytics-with-ai).
:::

## Prise en main de l'API d'export analytique \{#getting-started-with-the-api-for-analytics-export\}

Avec l'API d'export analytique, vous pouvez par exemple :

1. **Analyser le MRR des campagnes marketing** : Mesurez l'impact des campagnes marketing de l'année dernière dans un pays spécifique pour identifier celles qui ont généré le plus de revenus, avec un suivi hebdomadaire. Utilisez la méthode [Récupérer les données analytiques](api-export-analytics/operations/retrieveAnalyticsData) pour cela.

2. **Suivre la rétention des cohortes dans le temps** : Suivez la rétention par cohorte pour identifier les points de décrochage et comparer les cohortes dans le temps, révélant ainsi les tendances et les moments clés où des stratégies d'engagement pourraient améliorer la rétention. Limité à un store spécifique, un pays spécifique et un produit particulier. Utilisez la méthode [Récupérer les données de cohorte](api-export-analytics/operations/retrieveCohortData) pour cela.

3. **Évaluer les taux de conversion par canal** : Analysez les taux de conversion pour les principaux canaux d'acquisition afin d'identifier ceux qui génèrent le plus d'achats initiaux. Cela permet de concentrer les dépenses marketing sur les canaux les plus performants. Utilisez la méthode [Récupérer les données de conversion](api-export-analytics/operations/retrieveConversionData) pour cela.

4. **Analyser le taux de désabonnement** : Surveillez la vitesse à laquelle les utilisateurs se désabonnent pour identifier des tendances de churn ou évaluer l'efficacité de vos efforts de rétention, en vous concentrant sur un pays et un produit spécifiques. Utilisez la méthode [Récupérer les données d'entonnoir](api-export-analytics/operations/retrieveFunnelData) pour cela.

5. **Évaluer la VLV par segment d'utilisateurs** : Identifiez la valeur à vie des différents segments d'utilisateurs pour comprendre quels groupes génèrent le plus de revenus sur la durée. Concentrez-vous sur les segments à forte valeur, comme les abonnés à long terme, et utilisez les résultats pour affiner vos stratégies d'acquisition. Utilisez la méthode [Récupérer les données VLV](api-export-analytics/operations/retrieveLTVData) à cet effet.

6. **Vérifiez la rétention par pays** : Examinez les taux de rétention par région pour identifier les marchés les plus engagés et orienter les stratégies de localisation ou régionales. Utilisez la méthode [Retrieve retention data](api-export-analytics/operations/retrieveRetentionData) pour cela.
