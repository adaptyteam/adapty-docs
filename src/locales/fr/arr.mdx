Le graphique ARR (Annual Recurring Revenue) affiche le chiffre d'affaires généré par tous les abonnements auto-renouvelables actifs, normalisé sur une année. Le graphique considère comme actif tout abonnement payant non expiré. L'ARR est une métrique essentielle pour suivre la croissance de votre activité d'abonnement et prévoir les revenus futurs.

## Calcul \{#calculation\}

:::warning
La calculatrice ci-dessous **ne tient pas compte** de la [commission du store et des taxes](how-adapty-analytics-works#commissions-and-taxes). Comparez le résultat à vos calculs de **chiffre d'affaires brut**.
:::

L'ARR est la version annualisée de vos revenus d'abonnement récurrents. Il est particulièrement utile lorsque les abonnements annuels constituent votre produit principal — pour les entreprises dont les abonnements sont principalement mensuels ou hebdomadaires, le [MRR](mrr) est plus pertinent.

ARR est la somme de (prix × abonnés actifs ÷ période de facturation en années) pour tous vos types d'abonnements. Utilisez 1/12 pour le mensuel, 1/52 pour l'hebdomadaire.

## Gestion des remboursements \{#refund-handling\}

Lorsqu'un abonnement est remboursé, l'ARR supprime sa contribution à chaque date du graphique où il était précédemment comptabilisé. Les valeurs ARR passées peuvent donc diminuer après un remboursement.

Pour une comparaison complète entre les métriques, consultez [Comment les métriques gèrent les remboursements](refund-events#how-metrics-handle-refunds).
