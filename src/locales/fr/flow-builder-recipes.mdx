Cette section explique comment construire les modèles d'écrans les plus courants dans le Flow & Paywall Builder — élément par élément, des choix de mise en page aux interactions. Certains guides se prolongent dans le code de votre application, là où un flow restitue son résultat. Chaque guide est autonome. La plupart n'utilisent que les éléments standard du Flow & Paywall Builder. Pour ajouter une vue native, comme une animation Lottie ou une carte, à un écran de flow, suivez les exemples dans [Éléments personnalisés](flow-custom-elements#examples) (iOS, Android, React Native, Flutter et Capacitor).

Pour dépenser de la monnaie virtuelle dans un flow et en vendre davantage dans un autre, suivez la recette pour [iOS](ios-virtual-currency-top-up).
