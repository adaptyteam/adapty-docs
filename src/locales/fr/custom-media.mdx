Le Flow Builder propose trois types d'éléments média dans la catégorie **Media** : Image, Video et Icon.

:::tip
Pour qu'une image ou une vidéo couvre tout l'écran — y compris les zones derrière l'encoche et l'indicateur de retour à l'accueil — positionnez-la en fixe avec tous les décalages à 0 et sélectionnez **Ignore safe area**. Voir [Disposition et positionnement](manage-paywall-ui-elements#ignore-safe-area).
:::

## Image \{#image\}

Importez un fichier `.JPG`, `.PNG` ou `.GIF` de 20 Mo maximum.

- **Aspect** — détermine comment l'image s'adapte à son conteneur :
  - **Fit** — redimensionne l'image pour qu'elle tienne dans le conteneur sans rognage.
  - **Fill** — étire l'image pour remplir le conteneur.
  - **Cover** — redimensionne l'image pour couvrir le conteneur en la rognant si nécessaire. Par défaut.
- **Use custom media ID** — voir [Identifiant de média personnalisé](#custom-media-id) ci-dessous.

## Video \{#video\}

Importez un fichier `.MP4` ou `.WEBM` de 50 Mo maximum et d'une durée maximale de 30 secondes. La résolution minimale de la vidéo est de 640x640 pixels.

- **Aspect** — Fit, Fill ou Cover. Fill par défaut.
- **Loop** — rejoue la vidéo en continu. Activé par défaut.
- **Use custom media ID** — voir [Identifiant de média personnalisé](#custom-media-id) ci-dessous.

Les vidéos ne sont pas lues dans l'aperçu de l'éditeur — le canvas affiche une image fixe. Sur l'appareil à l'exécution, la vidéo est lue sans son par défaut. Avec Loop activé, elle se répète indéfiniment.

### Déclencher une action à la fin de la vidéo \{#trigger-an-action-when-the-video-ends\}

:::link
Article principal : [Actions](onboarding-actions)
:::

L'élément Video prend en charge un déclencheur **On playback finished** qui se déclenche lorsque la vidéo se termine. Configurez-le dans le panneau **Interactions** pour naviguer vers un autre écran, afficher un CTA ou exécuter toute autre action.

## Icon \{#icon\}

<ZoomImage id="builder-icon-selection.webp" width="300px" float="right" alt="Sélecteur d'icônes avec la bibliothèque Tabler Icons" />

Choisissez parmi la bibliothèque intégrée [Tabler Icons](https://tabler.io/icons), qui propose des milliers d'icônes dans deux styles visuels :

- **Stroke** — contour uniquement.
- **Filled** — remplissage plein.

Recherchez une icône par mot-clé dans le sélecteur. Définissez la couleur de l'icône dans le sélecteur **Color** — choisissez un [style de couleur](builder-styling) enregistré ou définissez une couleur personnalisée.

## Identifiant de média personnalisé \{#custom-media-id\}

:::important
Vous pouvez également définir un identifiant de média personnalisé pour un [arrière-plan](paywall-head-picture) image ou vidéo.
:::

Associez un identifiant de média personnalisé à un élément image ou vidéo pour le remplacer à l'exécution depuis le code de votre application. Utilisez cette option pour des [visuels personnalisés](get-pb-paywalls#customize-assets) — par exemple, afficher l'avatar sélectionné par l'utilisateur.

Le média que vous importez dans le Flow Builder sert de contenu de secours. Si votre code ne fournit pas de média pour cet identifiant à l'exécution, le contenu de secours est affiché à la place.

Pour activer un identifiant de média personnalisé sur un élément Image ou Video :

1. Cochez la case **Use custom media ID** sous la zone d'importation.
2. Saisissez un identifiant de média.
3. Importez une image ou une vidéo de secours.

Dans le code de votre application, récupérez le média par son identifiant — voir [Personnaliser les assets](get-pb-paywalls#customize-assets) pour l'API du SDK.
