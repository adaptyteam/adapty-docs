L'intégration d'Adapty Attribution avec Google Cloud Storage vous permet de stocker les données de campagne d'acquisition utilisateur de façon sécurisée dans un emplacement centralisé. Adapty Attribution enregistre des fichiers .csv dans votre bucket Google Cloud Storage. Chaque ligne correspond à une installation d'application, avec ses identifiants d'appareil et ses données d'attribution, comme le canal et la campagne. Les fichiers ne contiennent aucune donnée de dépenses publicitaires, de revenus ou d'achats.

Pour configurer cette intégration, vous devrez suivre quelques étapes simples dans la Google Cloud Console et dans l'Adapty Attribution Dashboard.

:::note
Adapty Attribution exporte un ensemble de fichiers par jour calendaire vers Google Cloud Storage. Le planificateur d'export s'exécute trois fois par jour — à **02:00**, **04:00** et **06:00 UTC**. Chaque exécution crée le job d'export du jour précédent s'il n'existe pas encore, ou le relance en cas d'échec antérieur. Vos données arrivent donc généralement après l'exécution de 02:00, les exécutions suivantes servant à récupérer les échecs plutôt qu'à ajouter des données.

Chaque export couvre les installations enregistrées par Adapty Attribution au cours de la journée calendaire précédente en UTC. Par exemple, l'export du 8 mars contient les installations enregistrées le 7 mars, de 00:00:00 à 23:59:59 UTC.

Chaque fichier reflète l'attribution au moment de l'export. Pendant jusqu'à 30 jours après une installation, Adapty Attribution peut encore rattacher celle-ci à un autre canal ou campagne. Pour actualiser les fichiers plus anciens avec l'attribution actuelle, [lancez un export manuel](#manual-data-export) pour les dates concernées.
:::

:::warning
L'export planifié ne s'exécute que pour les entreprises disposant d'un abonnement payant ou en période d'essai. Si ce n'est pas votre cas, le planificateur l'ignore et n'écrit aucun fichier, même si l'intégration reste activée dans le tableau de bord. Si votre bucket est vide et que la configuration semble correcte, vérifiez d'abord le statut de votre abonnement.
:::

## Comment configurer l'intégration Google Cloud Storage \{#how-to-set-up-google-cloud-storage-integration\}

### Étape 1. Créer les identifiants Google Cloud Storage \{#step-1-create-google-cloud-storage-credentials\}

Ce guide vous aidera à créer les identifiants nécessaires dans votre Google Cloud Platform Console.

Pour qu'Adapty Attribution puisse charger des rapports de données brutes dans votre bucket désigné, la clé du compte de service est requise, ainsi que les droits d'écriture sur le bucket correspondant. En fournissant la clé du compte de service et en accordant les droits d'écriture sur le bucket, vous autorisez Adapty Attribution à transférer de façon sécurisée et efficace les rapports de données brutes depuis sa plateforme vers votre environnement de stockage.

:::warning
Veuillez noter que nous ne prenons en charge que l'autorisation par clé HMAC de compte de service. Il est donc essentiel de s'assurer que votre clé HMAC de compte de service dispose des rôles « Storage Object Viewer », « Storage Legacy Bucket Writer » et « Storage Object Creator » pour permettre un accès correct à Google Cloud Storage.
:::

### Étape 2. Configurer l'intégration dans Adapty Attribution

1. Accédez à [**Integrations** -> **Google Cloud Storage**](https://app.adapty.io/ua/integrations/google-cloud-storage)
2. Activez le bouton **Export install events to Google Cloud Storage**
3. Remplissez les champs requis pour établir la connexion entre Google Cloud Storage et Adapty Attribution :

| Champ                                     | Description                                                                                                                                                                                                 |
|:------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Google Cloud service account key file** | Le [fichier de clé JSON](ua-google-cloud-storage#step-1-create-google-cloud-storage-credentials) privé téléchargé.                                                                    |
| **Google Cloud bucket name**              | Le nom du bucket dans Google Cloud Storage où vous souhaitez stocker vos données. Il doit être unique dans l'environnement Google Cloud Storage et ne doit contenir aucun espace.                           |
| **Folder inside the bucket**              | Le nom du dossier dans le bucket où vous souhaitez stocker vos données. Il doit être unique dans le bucket et peut servir à organiser vos données. Ce champ est facultatif.                                 |

## Export manuel des données \{#manual-data-export\}

Pour exporter des données sur des dates antérieures, dans la section **Manual file export**, sélectionnez une plage de dates et cliquez sur **Export to Google Cloud Storage**. Si votre bucket contient déjà des fichiers pour ces dates, Adapty Attribution les remplace.

## Structure du tableau \{#table-structure\}

Chaque fichier contient une ligne par installation enregistrée par l'attribution Adapty au cours d'une journée UTC, avec les données d'appareil et d'attribution associées. Les fichiers ne contiennent aucune donnée de dépenses publicitaires, de revenus ni d'achats.

:::warning
Notez que cette structure peut évoluer dans le temps — de nouvelles données pouvant être introduites par nous ou par des tiers avec lesquels nous travaillons. Assurez-vous que le code qui les traite est suffisamment robuste et qu'il repose sur des champs spécifiques, et non sur la structure dans son ensemble.
:::

Les fichiers contiennent les colonnes suivantes :

| Colonne                  | Description                               |
|--------------------------|-------------------------------------------|
| `adapty_profile_id`      | Identifiant unique du profil Adapty       |
| `install_id`             | Identifiant unique d'installation         |
| `created_at`             | Horodatage de création de l'enregistrement (ISO 8601) |
| `installed_at`           | Horodatage d'installation de l'application (ISO 8601) |
| `store`                  | Store d'applications (`ios`, `android`)   |
| `country`                | Code pays de l'utilisateur (ISO 3166-1 alpha-2) |
| `ip_address`             | Adresse IP du client                      |
| `idfa`                   | Identifiant publicitaire iOS (IDFA)       |
| `idfv`                   | Identifiant vendeur iOS (IDFV)            |
| `gaid`                   | Google Advertising ID (Android)           |
| `android_id`             | Identifiant d'appareil Android            |
| `app_set_id`             | Android App Set ID                        |
| `bundle_id`              | Identifiant de bundle de l'application (ex. `com.example.app`) |
| `device_brand`           | Marque de l'appareil (ex. `Apple`, `Samsung`) |
| `device_model`           | Modèle de l'appareil (ex. `iPhone15,2`)   |
| `os_version`             | Version majeure du système d'exploitation |
| `app_version`            | Version de l'application rapportée par le SDK Adapty |
| `sdk_version`            | Version du SDK Adapty                     |
| `channel`                | Canal d'attribution                       |
| `campaign_id`            | Identifiant de campagne                   |
| `campaign_name`          | Nom de la campagne                        |
| `adset_id`               | Identifiant du groupe d'annonces          |
| `adset_name`             | Nom du groupe d'annonces                  |
| `ad_id`                  | Identifiant de l'annonce                  |
| `ad_name`                | Nom de l'annonce                          |
| `keyword_id`             | Identifiant du mot-clé                    |
| `keyword_name`           | Nom du mot-clé                            |
| `asa_org_id`             | Identifiant d'organisation Apple Search Ads |
| `asa_keyword_match_type` | Type de correspondance de mot-clé ASA (`Exact`, `Broad`) |
| `asa_attribution`        | Données d'attribution ASA (chaîne JSON)   |
| `asa_conversion_type`    | Type de conversion ASA                    |
| `asa_country_or_region`  | Pays ou région ASA                        |
| `asa_creative_set_name`  | Nom du jeu de créatifs ASA                |
| `fbclid`                 | Facebook Click ID                         |
| `ttclid`                 | TikTok Click ID                           |
| `utm_source`             | Paramètre UTM source                      |
| `utm_medium`             | Paramètre UTM medium                      |
| `utm_campaign`           | Paramètre UTM campaign                    |
| `utm_term`               | Paramètre UTM term                        |
| `utm_content`            | Paramètre UTM content                     |
| `click_time`             | Horodatage du clic attribué, en secondes Unix. Vide si aucun clic n'est attribué à l'installation. |
| `asa_click_time`         | Horodatage du tap Apple Search Ads avant l'installation, en secondes Unix, arrondi à la minute. Vide si Apple Search Ads ne signale aucun tap pour l'installation. Contrairement à `click_time`, cette valeur est renseignée même si l'attribution Adapty crédite l'installation à un autre canal. |
