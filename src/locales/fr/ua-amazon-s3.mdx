L'intégration d'Adapty Attribution avec Amazon S3 vous permet de stocker en toute sécurité les données de vos campagnes d'acquisition utilisateur en un seul endroit centralisé. Vous pourrez enregistrer vos données de performance de campagne, vos données d'attribution et vos événements d'acquisition utilisateur dans votre bucket Amazon S3 sous forme de fichiers .csv.
Pour configurer cette intégration, vous devrez suivre quelques étapes simples dans la console AWS et le tableau de bord Adapty Attribution.

:::note
Adapty Attribution exporte un ensemble de fichiers par jour calendaire. Le planificateur d'export s'exécute trois fois par jour — à **02h00**, **04h00** et **06h00 UTC**. Chaque exécution crée le job d'export du jour précédent s'il n'existe pas encore, ou le relance si une exécution précédente a échoué. Vos données arrivent donc généralement après l'exécution de 02h00, et les exécutions suivantes servent à récupérer d'éventuels échecs plutôt qu'à ajouter des données.

Chaque fichier contient les données des événements créés pour l'intégralité du jour calendaire précédent en UTC. Par exemple, les données exportées le 8 mars contiendront tous les événements créés le 7 mars de 00:00:00 à 23:59:59 en UTC.
:::

:::warning
L'export planifié ne fonctionne que pour les entreprises disposant d'un plan payant ou en période d'essai. Si votre entreprise n'est dans aucun de ces cas, le planificateur ignore l'export et n'écrit aucun fichier, même si l'intégration reste activée dans le tableau de bord. Si votre bucket est vide et que la configuration semble correcte, vérifiez d'abord le statut de votre plan.
:::

## Comment configurer l'intégration Amazon S3 \{#how-to-set-up-amazon-s3-integration\}

Pour commencer à recevoir des données, vous aurez besoin des identifiants suivants :

1. Access key ID
2. Secret access key
3. S3 bucket name
4. Folder name inside the S3 bucket

:::note
Répertoires imbriqués

Vous pouvez spécifier des répertoires imbriqués dans le champ S3 bucket name, par exemple : adapty-ua-events/com.sample-app
:::

### Étape 2. Configurer l'intégration dans Adapty Attribution

1. Accédez à [**Integrations** -> **Amazon S3**](https://app.adapty.io/ua/integrations/s3)
2. Activez le bouton **Export install events to Amazon S3**.
3. Remplissez les champs suivants pour établir une connexion entre Amazon S3 et les profils Adapty Attribution :

| Champ                        | Description                                                  |
|:-----------------------------| :----------------------------------------------------------- |
| **Access Key ID**            | Un identifiant unique utilisé pour authentifier l'accès d'un utilisateur ou d'une application à un service AWS. Vous trouverez cet identifiant dans le [fichier csv](ua-amazon-s3#step-1-create-amazon-s3-credentials) téléchargé. |
| **Secret Access Key**        | Une clé privée utilisée conjointement avec l'Access Key ID pour authentifier l'accès d'un utilisateur ou d'une application à un service AWS. Vous trouverez cette clé dans le [fichier csv](ua-amazon-s3#step-1-create-amazon-s3-credentials) téléchargé. |
| **S3 Bucket Name**           | Un nom globalement unique qui identifie un bucket S3 spécifique dans le cloud AWS. Les buckets S3 sont un service de stockage simple permettant aux utilisateurs de stocker et de récupérer des objets de données, tels que des fichiers et des images, dans le cloud. |
| **Folder Inside the Bucker** | Le nom du dossier que vous souhaitez créer dans le bucket S3 sélectionné. Notez que S3 simule les dossiers à l'aide de préfixes de clés d'objet, qui sont essentiellement des noms de dossiers. |
| **Region** (Optionnel)        | Obtenez votre région depuis la console de gestion AWS, sous votre compte utilisateur IAM.                                                                                                                                                                                  |

## Export manuel des données \{#manual-data-export\}

En plus de l'export automatique des données d'événements vers Amazon S3, Adapty Attribution propose également une fonctionnalité d'export manuel de fichiers. Cette fonctionnalité vous permet de sélectionner une date précise pour les données d'acquisition utilisateur et de les exporter manuellement vers votre bucket S3. Vous gardez ainsi un contrôle total sur les données exportées et le moment de leur export.

## Structure de la table \{#table-structure\}

Dans l'intégration AWS S3, Adapty Attribution fournit une table pour stocker les données historiques des événements d'installation. Elle contient des informations sur le profil utilisateur, les revenus et les produits, ainsi que le store d'origine, entre autres données.

:::warning
Notez que cette structure peut évoluer au fil du temps — de nouvelles données peuvent être ajoutées par nos soins ou par les tiers avec lesquels nous travaillons. Assurez-vous que votre code qui la traite est suffisamment robuste et s'appuie sur des champs spécifiques, et non sur la structure dans son ensemble.
:::

Voici la structure de la table pour les événements :

| Colonne                  | Description                               |

| `install_id`             | Identifiant d'installation unique         |

| `installed_at`           | Horodatage d'installation de l'application (ISO 8601) |
| `store`                  | Store d'applications (`ios`, `android`)   |
| `country`                | Code pays de l'utilisateur (ISO 3166-1 alpha-2) |
