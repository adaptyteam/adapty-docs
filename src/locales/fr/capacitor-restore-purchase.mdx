La restauration des achats sur iOS et Android permet aux utilisateurs de retrouver l'accès aux contenus achetés précédemment — abonnements ou achats intégrés — sans être facturés à nouveau. Cette fonctionnalité est particulièrement utile pour ceux qui ont désinstallé puis réinstallé l'application, ou qui ont changé d'appareil et souhaitent retrouver leurs achats sans repayer.

:::note
Dans les paywalls créés avec le [Paywall Builder](adapty-paywall-builder), la restauration des achats se fait automatiquement, sans code supplémentaire de votre part. Si c'est votre cas, vous pouvez passer cette étape.
:::

Pour restaurer un achat si vous n'utilisez pas le [Paywall Builder](adapty-paywall-builder) pour personnaliser votre paywall, appelez la méthode `.restorePurchases()` :

```typescript showLineNumbers

try {
  const profile = await adapty.restorePurchases();
  const isSubscribed = profile.accessLevels?.['YOUR_ACCESS_LEVEL']?.isActive;
  
  if (isSubscribed) {
    // Restore access to paid features
    console.log('Access restored successfully!');
  } else {
    console.log('No active subscriptions found');
  }
} catch (error) {
  console.error('Failed to restore purchases:', error);
}
```

Paramètres de réponse :

| Paramètre | Description                                                                                                                                                                                                                                                            |
|---------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **profile** | Un objet [`AdaptyProfile`](https://capacitor.adapty.io/interfaces/adaptyprofile). Ce modèle contient les informations sur les niveaux d'accès, les abonnements et les achats uniques. Vérifiez le **statut du niveau d'accès** pour déterminer si l'utilisateur a accès à l'application. |
