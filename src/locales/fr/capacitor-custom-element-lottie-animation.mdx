## Avant de commencer \{#before-you-start\}

- Mettez à jour votre app vers le SDK Adapty Capacitor 4.4 ou version ultérieure. Les versions antérieures du SDK affichent le [contenu de secours](flow-custom-elements#set-fallback-content) pour chaque élément personnalisé.
- Configurez votre app pour [récupérer](capacitor-get-pb-paywalls) et [afficher](capacitor-present-paywalls) les flows.
- Configurez le code natif de votre app pour les éléments personnalisés, comme dans le [guide Capacitor](capacitor-flow-custom-elements#before-you-start).
- Sur iOS, ajoutez Lottie à la cible de votre app dans Xcode avec Swift Package Manager, depuis `https://github.com/airbnb/lottie-spm.git`.
- Sur Android, [configurez votre projet Android](capacitor-flow-custom-elements#set-up-your-android-project), en incluant Jetpack Compose. La vue d'animation dans cette recette est un composable. Ajoutez Compose Foundation à votre app avec Gradle, depuis `androidx.compose.foundation:foundation`, sans version. Le BOM Compose de `io.adapty:android-ui` définit la version. Ajoutez Lottie pour Jetpack Compose depuis `com.airbnb.android:lottie-compose`.

## 2. Ajoutez le fichier d'animation à votre application \{#2-add-the-animation-file-to-your-app\}

Votre code natif lit le fichier d'animation depuis vos projets iOS et Android, et non depuis les assets de votre application web :

- **iOS** : Ajoutez le fichier à la cible de votre application dans Xcode.
- **Android** : Placez le fichier dans `android/app/src/main/assets`, le dossier `assets` de votre module d'application Android. Gardez-le à la racine de ce dossier, sans le placer dans un sous-dossier.

Le nom du fichier sans `.json` doit correspondre à l'ID de l'élément personnalisé, par exemple `streak_ring.json` pour `streak_ring`.

## 3. Créer la vue d'animation \{#create-the-animation-view\}

Créez un modèle pour le streak, et une vue qui joue l'animation. Votre application met à jour le modèle quand le streak change. La vue lit le modèle, ce qui permet à l'anneau d'afficher le streak actuel à l'ouverture de l'écran :

<Tabs groupId="platform" queryString>
<TabItem value="ios" label="iOS (Swift)" default>

```swift showLineNumbers title="Swift"

// The streak that your app keeps up to date
@MainActor
final class StreakStore: ObservableObject {
    @Published var currentStreak = 0 // days in a row
}

struct StreakRingView: View {
    let animation: LottieAnimation
    @ObservedObject var streakStore: StreakStore

    // 7 days fill the ring: from 0 for an empty ring to 1 for a full one
    private var progress: AnimationProgressTime {
        min(AnimationProgressTime(streakStore.currentStreak) / 7, 1)
    }

    var body: some View {
        LottieView(animation: animation)
            .resizable()
            .playing(.fromProgress(0, toProgress: progress, loopMode: .playOnce))
    }
}
```

`.playing(.fromProgress(0, toProgress: progress, loopMode: .playOnce))` remplit l'anneau une fois, de vide jusqu'à `progress`.

</TabItem>
<TabItem value="android" label="Android (Kotlin)">

```kotlin showLineNumbers title="Kotlin"

// the streak that your app keeps up to date
class StreakStore {
    val currentStreak = MutableStateFlow(0) // days in a row
}

@Composable
fun StreakRing(animationFile: String, streakStore: StreakStore) {
    val composition by rememberLottieComposition(LottieCompositionSpec.Asset(animationFile))
    val streak by streakStore.currentStreak.collectAsState()

    // 7 days fill the ring: from 0 for an empty ring to 1 for a full one
    val progress = minOf(streak / 7f, 1f)

    LottieAnimation(
        composition = composition,
        modifier = Modifier.fillMaxSize(), // scale the animation to fit the custom element
        clipSpec = LottieClipSpec.Progress(0f, progress),
    )
}
```

`clipSpec = LottieClipSpec.Progress(0f, progress)` remplit l'anneau une fois, de vide jusqu'à `progress`.

## 4. Associer l'animation à l'élément personnalisé \{#match-the-animation-to-the-custom-element\}

Dans votre [resolver global](capacitor-flow-custom-elements#pass-the-resolver-to-the-sdk), ajoutez une propriété pour le modèle de série. Renvoyez ensuite la vue d'animation pour le type `lottie_animation` et l'ID `streak_ring`. Les lignes surlignées indiquent ce qu'il faut ajouter ou modifier. Si votre application n'a pas encore de [resolver](capacitor-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views) global, copiez l'intégralité du code :

<Tabs groupId="platform" queryString>
<TabItem value="ios" label="iOS (Swift)" default>

```swift showLineNumbers title="Swift" {6,14-18}

struct CustomElementsResolver: AdaptyUICustomElementsResolver {
    let streakStore: StreakStore

    func view(
        forType type: String,
        id: String,
        context: AdaptyUICustomElementContext
    ) -> AnyView? {
        switch type {
        case "lottie_animation" where id == "streak_ring":
            guard let animation = LottieAnimation.named(id) else {
                return nil // no animation file: show the fallback
            }
            return AnyView(StreakRingView(animation: animation, streakStore: streakStore))
        // the other cases of your resolver
        default:
            return nil
        }
    }
}
```

Placez le cas `streak_ring` avant tout autre cas `lottie_animation`, car Swift n'exécute que le premier cas correspondant. Si le bundle de l'application ne contient aucun fichier pour l'ID, le resolver renvoie `nil` et les utilisateurs voient le fallback.

</TabItem>
<TabItem value="android" label="Android (Kotlin)">

```kotlin showLineNumbers title="Kotlin" {8,22-28}

class CustomElementsResolver(
    context: Context,
    private val streakStore: StreakStore,
) : AdaptyCustomElementsResolver {
    // the animation files in the assets folder, listed once
    private val animationFiles: Set<String> = try {
        context.assets.list("").orEmpty().toSet()
    } catch (e: IOException) {
        emptySet() // no list of files: every Lottie element shows the fallback
    }

    override fun resolve(type: String, id: String): AdaptyCustomElementContent? =
        when (type) {
            "lottie_animation" -> {
                // the ID names the animation file, such as streak_ring.json
                val file = "$id.json"
                when {
                    file !in animationFiles -> null // no file for this ID: show the fallback
                    id == "streak_ring" ->
                        AdaptyCustomElementContent.compose { StreakRing(file, streakStore) }
                    // the other animations of your resolver
                    else -> null
                }
            }
            // the other Types of your resolver
            else -> null
        }
}
```

Si le dossier `assets` ne contient aucun fichier pour l'ID, le résolveur renvoie `null` et les utilisateurs voient le contenu de secours. Si votre résolveur renvoie déjà une [vue pour chaque fichier d'animation](capacitor-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views), renvoyez cette vue à la place de `null` quand l'ID n'est pas `streak_ring`. Ainsi, les utilisateurs voient toujours les animations de vos autres éléments personnalisés `lottie_animation`.

</TabItem>
</Tabs>

        return true

## 5. Envoyez le streak depuis votre code JavaScript \{#5-send-the-streak-from-your-javascript-code\}

Votre code JavaScript gère le streak, et les vues natives le lisent depuis le modèle de streak. Pour mettre à jour le modèle, envoyez le streak à votre code natif via un <InlineTooltip tooltip="plugin Capacitor local">[iOS](https://capacitorjs.com/docs/ios/custom-code), [Android](https://capacitorjs.com/docs/android/custom-code)</InlineTooltip>. Le plugin possède une implémentation pour chaque plateforme ainsi qu'une interface JavaScript.

Implémentez le plugin pour chaque plateforme :

<Tabs groupId="platform" queryString>
<TabItem value="ios" label="iOS (Swift)" default>

Dans la cible `App` dans Xcode, créez le plugin. Il met à jour le modèle de streak dans votre classe `AppDelegate` :

```swift showLineNumbers title="StreakStorePlugin.swift"

@objc(StreakStorePlugin)
public class StreakStorePlugin: CAPPlugin, CAPBridgedPlugin {
    public let identifier = "StreakStorePlugin"
    public let jsName = "StreakStore"
    public let pluginMethods: [CAPPluginMethod] = [
        CAPPluginMethod(name: "setStreak", returnType: CAPPluginReturnPromise)
    ]

    @objc func setStreak(_ call: CAPPluginCall) {
        let days = call.getInt("days") ?? 0
        Task { @MainActor in
            (UIApplication.shared.delegate as? AppDelegate)?.streakStore.currentStreak = days
        }
        call.resolve()
    }
}
```

Créez une sous-classe de `CAPBridgeViewController` qui enregistre le plugin dans sa méthode `capacitorDidLoad`. Si votre application dispose déjà d'une sous-classe de `CAPBridgeViewController`, enregistrez-y le plugin à la place :

```swift showLineNumbers title="MyViewController.swift"

class MyViewController: CAPBridgeViewController {
    override open func capacitorDidLoad() {
        bridge?.registerPluginInstance(StreakStorePlugin())
    }
}
```

Pour que l'application utilise cette sous-classe, dans `SceneDelegate.swift`, remplacez `CAPBridgeViewController()` par `MyViewController()`. Si votre projet n'a pas de `SceneDelegate.swift`, définissez la classe personnalisée du **Bridge View Controller** dans `Main.storyboard` sur `MyViewController`, comme dans [Custom ViewController](https://capacitorjs.com/docs/ios/viewcontroller).

</TabItem>
<TabItem value="android" label="Android (Kotlin)">

Dans le dossier de `MainActivity.java`, créez le plugin. Il met à jour le modèle de streak dans votre classe `MainApplication` :

```kotlin showLineNumbers title="StreakStorePlugin.kt"
package com.example.app


@CapacitorPlugin(name = "StreakStore")
class StreakStorePlugin : Plugin() {
    @PluginMethod
    fun setStreak(call: PluginCall) {
        val app = context.applicationContext as MainApplication
        app.streakStore.currentStreak.value = call.getInt("days") ?: 0
        call.resolve()
    }
}
```

Pour enregistrer le plugin, dans `MainActivity.java`, appelez `registerPlugin` avant `super.onCreate`. Les lignes surlignées indiquent ce qu'il faut ajouter :

```java showLineNumbers title="MainActivity.java" {3,7-11}
package com.example.app;


public class MainActivity extends BridgeActivity {
    @Override
    public void onCreate(Bundle savedInstanceState) {
        registerPlugin(StreakStorePlugin.class);
        super.onCreate(savedInstanceState);
    }
}
```

</TabItem>
</Tabs>

Dans votre code JavaScript, enregistrez le plugin. Envoyez ensuite la streak au lancement de l'application et à chaque fois qu'elle change :

```typescript showLineNumbers title="sendStreak.ts"

interface StreakStorePlugin {
  setStreak(options: { days: number }): Promise<void>;
}

// the name matches the jsName on iOS and the plugin name on Android
const StreakStore = registerPlugin<StreakStorePlugin>('StreakStore');

// call at app launch, and each time the streak changes
export async function sendStreak(days: number) {
  await StreakStore.setStreak({ days });
}
```
