:::important
Les liens de suivi aident Adapty à attribuer les installations d'applications. Si votre publicité dirige les utilisateurs vers un entonnoir web, [taguez son URL avec les paramètres d'Adapty](ua-tag-ad-urls) à la place.
:::

La destination de votre annonce est généralement votre page App Store ou Google Play. Cette page appartient au store, pas à vous, donc elle ne peut pas signaler les clics à Adapty.

Utilisez plutôt un lien de suivi comme destination. Adapty capture la campagne, le groupe d'annonces et l'annonce avant de rediriger l'utilisateur vers le store, puis associe ce clic à l'installation signalée par le SDK. Vos [analyses d'attribution Adapty](ua-analytics) montrent quelles annonces génèrent des revenus.

Adapty génère les liens pour les campagnes [Meta Ads](ua-facebook#step-2-add-campaigns) et [TikTok for Business](ua-tiktok#step-2-add-campaigns). Pour tous les autres réseaux publicitaires, [créez un lien de suivi personnalisé](#custom-tracking-links) avec l'intégration **Custom** dans le Dashboard.

## Types de liens de suivi \{#tracking-link-types\}

Adapty génère deux types de liens de suivi :

- **Liens spécifiques à la plateforme** — un lien distinct pour chaque store. Ils peuvent diriger les utilisateurs vers des fiches store personnalisées, adaptées à votre campagne.
- **One Link** — un lien unique pour les deux stores, associé à la plateforme de l'utilisateur au moment du clic.

Une page de lien de suivi regroupe les liens de tous les stores que vous configurez, ce qui évite d'en créer un nouveau par store. Pour plus de flexibilité, nous recommandons les liens spécifiques à la plateforme.

## Liens de tracking personnalisés \{#custom-tracking-links\}

:::note
Apple Search Ads ne nécessite pas de lien de tracking. Adapty reçoit l'attribution Apple Search Ads sans en avoir besoin, et vous gérez ces campagnes dans [Adapty Ads Manager](adapty-ads-manager).
:::

Pour créer un lien de tracking personnalisé :

1. Dans le tableau de bord Adapty Attribution, ouvrez **Integrations** et sélectionnez la carte **Custom** dans le groupe **Network**.

<ZoomImage id="custom-tracking-link.webp" width="700px" alt="Page Integrations dans Adapty Attribution avec la carte Custom mise en évidence dans le groupe Network" />

2. Cliquez sur **Create link**.

<ZoomImage id="new-tracking-link.webp" width="700px" />

3. Sélectionnez votre application dans la liste et cliquez sur **Next**.

<ZoomImage id="ua-choose-app.webp" width="700px" />

4. Renseignez les paramètres du lien pour l'associer à une campagne et une publicité spécifiques.

| Paramètre         | Description                                                                                             |
|-------------------|---------------------------------------------------------------------------------------------------------|
| **Name**          | Le nom interne du lien de suivi.                                                                        |
| **Channel**       | La source du trafic, comme Meta, Reddit ou TikTok. Utilisé pour regrouper les campagnes dans les analyses. |
| **Campaign ID**   | L'identifiant unique de la campagne dans votre plateforme publicitaire.                                 |
| **Campaign name** | Le nom lisible de la campagne.                                                                          |
| **Ad set ID**     | L'identifiant unique de l'ensemble de publicités (groupe d'annonces) dans votre plateforme publicitaire. |
| **Ad set name**   | Le nom de l'ensemble de publicités.                                                                     |
| **Ad ID**         | L'identifiant unique de la création publicitaire individuelle.                                          |
| **Ad name**       | Le nom de la création publicitaire ou de la variante.                                                   |

5. Par défaut, vous créez un One Link. Pour ajouter des [liens spécifiques à une plateforme](#tracking-link-types) à la place, décochez la case **One Link**.

<ZoomImage id="one-link.webp" width="700px" />

6. Cliquez sur **Create**.
7. Ouvrez la page de votre lien de suivi. Dans la section correspondant à votre [type de lien](#tracking-link-types), copiez la valeur **Click link**.

:::tip
Vous pouvez également définir des paramètres de lien supplémentaires pour [travailler avec des données différées](ua-deferred-data). Par exemple, vous pouvez mettre en place le deep linking différé.
:::

<ZoomImage id="click-link.webp" width="700px" />

8. Accédez à votre plateforme publicitaire et utilisez le lien comme URL de destination de l'annonce.
