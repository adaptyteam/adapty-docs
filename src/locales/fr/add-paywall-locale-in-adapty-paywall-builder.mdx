Localiser vos flows les rend disponibles en plusieurs langues. Dans le Flow Builder, la localisation est organisée par écran, chacun affichant un pourcentage d'avancement pour suivre la progression des traductions.

:::tip
Terminez la configuration de votre flow dans la langue par défaut avant d'ajouter d'autres langues.
:::

## Ajouter et configurer la localisation \{#add-and-set-up-localization\}

1. Dans le panneau gauche, cliquez sur <Inline id="localizations.svg" alt="Localizations" />. Puis cliquez sur **Add locale**. Sélectionnez les langues à ajouter.

<ZoomImage id="new-locale-flow.webp" width="500px" alt="Boîte de dialogue Ajouter une langue" />

2. Chaque langue ajoutée apparaît sous forme de colonne dans le tableau de localisation, pré-remplie avec les valeurs de la langue par défaut.

3. Pour vous concentrer uniquement sur ce qui manque, activez le bouton **Missing only** dans le panneau gauche. Le tableau filtrera alors uniquement les lignes non traduites.

<ZoomImage id="locales-table.webp" width="700px" alt="Tableau de localisation" />

## Exporter et importer pour une traduction externe \{#export-and-import-for-external-translation\}

Vous pouvez exporter le fichier de localisation pour le partager avec des traducteurs et importer les résultats traduits.

Dans la barre d'outils supérieure, cliquez sur **Import / Export**.

<ZoomImage id="import-export.webp" width="700px" />

### Format du fichier exporté \{#export-file-format\}

L'export génère un fichier `.tsv` (valeurs séparées par des tabulations) avec une ligne par élément traduisible. Les colonnes sont :

| Colonne | Description |
|--------|-------------|
| `Screen` | L'écran auquel appartient l'élément (ex. : `Welcome`, `Quiz`) |
| `Element` | Identifiant généré automatiquement pour l'élément dans cet écran. Vous pouvez le modifier dans **Interactions** > **Element ID**. |
| `Property` | Le type de propriété (ex. : `content`) |
| `[default_locale]` | Le code de la langue par défaut (ex. : `en`) |
| `[locale]` | Une colonne par langue ajoutée (ex. : `fr`, `es`) |

Exemple :

```
Screen	Element	Property	en	fr	es
Welcome	title	content	Turn words into art	Transformez les mots en art
Welcome	subtitle	content	Create stunning images in seconds with AI	Créez des images en quelques secondes
Quiz	quiz-title	content	What will you create?
```

:::note
Laissez les colonnes de langue vides pour les lignes non traduites — Adapty les considérera comme manquantes.
:::

### Prérequis pour l'import \{#import-file-requirements\}

- **Format** : `.tsv` (valeurs séparées par des tabulations)
- **En-têtes** : doivent inclure `Screen`, `Element`, `Property` et au moins une colonne de langue
- **Noms des colonnes de langue** : doivent correspondre aux codes des langues déjà ajoutées au flow. L'import d'un fichier contenant des codes de langue absents du flow entraîne une erreur.
- **Import partiel** : vous pouvez n'inclure qu'un sous-ensemble de lignes ; les lignes absentes du fichier conservent leurs valeurs actuelles

## Traduire manuellement \{#translate-manually\}

Vous pouvez également saisir des traductions directement dans n'importe quelle cellule du tableau de localisation.

Pour gérer une ligne spécifique, ouvrez son menu contextuel (**⋮**) :

- **Reset to default** : Rétablit la traduction de la ligne aux valeurs de la langue par défaut.
