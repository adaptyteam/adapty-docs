Vous pouvez localiser votre flow pour proposer aux utilisateurs internationaux un contenu spécifique à leur locale, dans une langue qu'ils comprennent. Vous pouvez traduire ou personnaliser les éléments suivants :

- Toutes les chaînes de caractères du flow.
- [L'URL de chaque action **Open URL**](#action-urls).
- Les images et vidéos, avec un [fichier distinct par locale](#images-and-videos).

Le panneau <Inline id="localizations.svg" alt="Localizations" /> **Localizations** liste toutes les chaînes de caractères et URL d'action dans un seul tableau. Chaque langue correspond à une colonne, et chaque chaîne à une ligne. Vous pouvez y traduire les cellules manuellement, avec l'IA, ou en les exportant pour un traducteur externe. Les images et vidéos ne figurent pas dans le tableau : vous les localisez dans le panneau des propriétés.

<ZoomImage id="locales-table.webp" width="700px" alt="Localizations panel with the locale tabs, the filters, and the localization table" />

Pour afficher une locale aux utilisateurs, votre application [doit transmettre le code de locale](localizations-and-locale-codes) dans la [requête de configuration de la vue du flow](get-pb-paywalls#fetch-the-view-configuration). Les valeurs sans traduction utilisent le contenu de la locale par défaut (l'anglais, sauf si vous [définissez une autre locale par défaut](#set-the-default-locale)).

:::tip
Finalisez la configuration de votre flow dans la locale par défaut avant d'ajouter d'autres langues.
:::

## Ce que vous pouvez localiser \{#what-you-can-localize\}

### Contenu textuel

Le panneau **Localizations** comporte une ligne pour chaque chaîne du flow, notamment :

- Le contenu de chaque élément texte, comme le libellé d'un bouton.
- Le **Placeholder** de chaque champ de saisie.
- Le titre et le message de chaque action **Show alert**.

:::note
Ce qu'une [variable](onboarding-variables) affiche dans les autres langues dépend de l'origine de sa valeur :

- **Variables de produit** : le store renvoie leurs valeurs déjà localisées. Une chaîne qui contient uniquement une variable de produit, comme un prix, n'a pas besoin d'être traduite.
- **Variables personnalisées et de composant** : leurs valeurs ne peuvent pas être localisées. Par exemple, `selectedOptionTitle` affiche le **titre de l'élément** sélectionné exactement tel que vous l'avez saisi. Utilisez plutôt du texte statique ou conditionnel.
:::

### Texte conditionnel \{#conditional-text\}

Les éléments texte peuvent afficher [un contenu différent](onboarding-text#add-conditional-text) selon les conditions que vous définissez. Vous pouvez localiser chaque branche du texte conditionnel.

:::note
Les conditions sont identiques dans toutes les locales. Si une condition compare une variable à une chaîne de caractères, cette chaîne n'est pas localisée.
:::

### URL d'action \{#action-urls\}

Une action **Open URL** peut ouvrir une URL différente selon la langue, par exemple une page d'aide dans la langue de l'utilisateur. Dans une langue sans URL propre, l'action ouvre l'URL de la langue par défaut. Sur l'appareil, le SDK choisit l'URL en fonction de la langue actuelle de l'application, et non du code de langue que votre application lui transmet.

### Images et vidéos \{#images-and-videos\}

Les éléments Image et Vidéo peuvent afficher un [fichier différent dans chaque langue](#localize-images-and-videos). Dans une langue sans fichier propre, l'élément affiche le fichier de la langue par défaut. Le panneau **Localizations** ne liste pas les images et vidéos. Vous ne pouvez pas localiser les icônes ni les [arrière-plans d'écrans et de conteneurs](custom-media#limitations).

## Gérer les localisations et les traductions \{#manage-localizations-and-translations\}

### Ajouter et configurer une locale \{#add-and-set-up-a-locale\}

1. Ouvrez le panneau <Inline id="localizations.svg" alt="Localizations" /> Localizations sur la gauche. Cliquez sur **Add locale**.
2. Dans le champ **Select languages**, sélectionnez une ou plusieurs langues.
3. (Optionnel) Pour traduire votre flow dans les nouvelles locales immédiatement, cochez **Translate content from default locale using AI**.
4. Cliquez sur **Add locales**.

<ZoomImage id="new-locale-flow.webp" width="500px" alt="Boîte de dialogue Ajouter des locales" />

Chaque locale correspond à une colonne dans le tableau de localisation. Les lignes sont les chaînes de caractères et les [URL d'action](#action-urls) du flow, y compris chaque branche du [texte conditionnel](#conditional-text). Le tableau les regroupe en une section par écran.

<ZoomImage id="locales-sidebar.webp" width="250px" float="right" alt="Onglets de locale dans le panneau latéral Localisations, avec une épingle sur la locale par défaut et un pourcentage sur chaque autre locale" />

Le panneau latéral affiche votre progression dans chaque langue sous forme de pourcentage de cellules traduites. L'en-tête de section de chaque écran indique la progression de cet écran dans toutes les langues. Le panneau considère une cellule comme traduite dès qu'elle contient une valeur, même si cette valeur est le texte de la langue par défaut, non traduit.

Une ligne dont la traduction est manquante affiche le badge **Missing**. Chaque cellule vide affiche le texte de la langue par défaut en grisé.

### Traduire les chaînes avec l'IA \{#translate-strings-with-ai\}

L'IA traduit les chaînes depuis la locale par défaut vers les autres locales. Elle ne traduit pas les [URL d'action](#action-urls).

Ouvrez **AI Translate** dans l'en-tête du panneau et sélectionnez l'une des options suivantes :

- **Translate missing only** : Traduit les cellules vides et conserve les traductions existantes.
- **Translate all** : Traduit toutes les cellules et remplace les traductions existantes, y compris celles que vous avez modifiées manuellement.

<ZoomImage id="locales-ai-translate.webp" width="700px" alt="Menu de traduction IA dans l'en-tête du panneau Localisations, avec Traduire les manquants uniquement et Traduire tout" />

Vous ne pouvez traduire que les lignes affichées par les [filtres](#filter-rows). Pour ne traduire que certaines lignes ou certaines locales, cochez d'abord leurs cases.

Si une traduction IA modifie une variable ou la mise en forme du texte, Adapty ignore cette traduction et conserve la valeur précédente de la cellule.

### Définir la langue par défaut \{#set-the-default-locale\}

L'icône d'épingle <Inline id="pin.svg" alt="Pin" /> marque la langue par défaut. Elle contient votre contenu source et sert de langue de secours pour toute traduction manquante. Chaque flow commence avec l'anglais comme langue par défaut et unique.

Avant de changer la langue par défaut, renseignez son remplacement avec des traductions. Si une langue est incomplète au moment où elle devient la langue par défaut, Adapty la complète avec le contenu de la langue par défaut précédente. Les champs ne signalent plus les traductions comme **Missing**.

Pour changer la locale par défaut, dans l'en-tête de colonne de la locale cible, ouvrez **Locale actions** et sélectionnez **Set as default**.

<ZoomImage id="flow-builder-set-default-locale.webp" width="500px" alt="Menu Locale actions d'une colonne de locale, avec Set as default en surbrillance" />

### Supprimer une locale \{#delete-a-locale\}

Pour supprimer une locale, ouvrez **Locale actions** dans l'en-tête de sa colonne et sélectionnez **Delete locale**. Adapty supprime tout le contenu spécifique à cette locale, y compris les images et les vidéos. Pour restaurer la locale, annulez la suppression. Pour supprimer la locale par défaut, commencez par [définir une autre locale comme locale par défaut](#set-the-default-locale).

### Actions sur le tableau \{#table-actions\}

Vous pouvez modifier plusieurs cellules en une seule opération, et un seul Ctrl+Z annule toutes les modifications.

#### Filtrer les lignes \{#filter-rows\}

Définissez les filtres dans la barre latérale du panneau pour limiter les lignes affichées dans le tableau :

- **Screens** — Limite la sélection d'écrans {/*, and hides reusable components*/}.
- **Status** > **Missing only** — Masque les lignes qui ont une traduction dans chaque langue.

Les actions groupées n'affectent que les lignes visibles. En activant un filtre, vous réduisez le périmètre des actions groupées. Pour traduire ou réinitialiser toute une langue ou tout le flow, désactivez d'abord les filtres.

#### Gérer une langue \{#manage-a-locale\}

Ouvrez le menu contextuel de la colonne <Inline id="collapse-layer.svg" alt="Locale actions" /> pour gérer en masse un seul paramètre régional :

- **Set as default** : Définit la locale comme [locale par défaut](#set-the-default-locale).
- **Import** et **Export** : Importez ou exportez le [fichier de traduction](#localize-content-externally) de la locale.
- **AI Translate locale** : Traduit toute la colonne de la locale depuis la locale par défaut [avec l'IA](#translate-strings-with-ai).
- **AI Translate missing only** : Traduit les cellules vides de la locale [avec l'IA](#translate-strings-with-ai).
- **Reset to default (…)** : Supprime toutes les traductions de la locale.
- **Delete locale** : [Supprime la locale et son contenu](#delete-a-locale).

<ZoomImage id="flow-builder-set-default-locale.webp" width="500px" alt="Locale actions menu of a locale column" />

#### Gérer une ligne \{#manage-a-row\}

Ouvrez le menu contextuel de la ligne <Inline id="context.svg" alt="Row context menu" /> pour gérer en bloc une seule chaîne avec toutes ses locales :

- **AI Translate missing only** : Traduit les cellules vides de la ligne [avec l'IA](#translate-strings-with-ai).
- **AI Translate row** : Traduit l'intégralité de la ligne depuis la locale par défaut [avec l'IA](#translate-strings-with-ai).
- **Reset to default** : Supprime toutes les traductions de la ligne.

<ZoomImage id="locales-row-menu.webp" width="600px" alt="Menu contextuel de ligne avec AI Translate manquant uniquement, AI Translate ligne, et Réinitialiser par défaut" />

#### Actions sur les cellules \{#cell-actions\}

Ouvrez le menu contextuel de cellule <Inline id="context.svg" alt="Menu contextuel de cellule" /> pour gérer la valeur d'une cellule individuelle :

- **Add variable** : Insère une [variable](onboarding-variables) dans la cellule.
- **Copy** et **Paste here** : Copie la valeur de la cellule, avec sa mise en forme et ses variables, et la colle dans une autre cellule.
- **AI Translate** : Traduit la cellule [avec l'IA](#translate-strings-with-ai).
- **Push value to all locales** : Copie le texte de la cellule dans toutes les autres locales, sauf la locale par défaut, de sorte que la ligne soit considérée comme traduite. Pour du texte identique dans toutes les langues, comme un nom de marque ou une chaîne contenant uniquement une [variable produit](#text-content), vous pouvez remplir toute la ligne en une seule étape. Pour mettre à jour les copies après avoir modifié la cellule, poussez à nouveau la valeur.
- **Clear translation** : Vide la cellule, de sorte que les utilisateurs dans cette locale voient le texte de la locale par défaut.

<ZoomImage id="locales-cell-menu.webp" width="400px" alt="Barre d'outils de cellule et son menu contextuel, avec Ajouter une variable, Copier, Coller ici, Traduction IA, Pousser la valeur vers tous les paramètres régionaux et Effacer la traduction" />

## Localiser le contenu dans le builder \{#localize-content-in-the-builder\}

Pour traduire les chaînes et définir les URL d'action, ouvrez le panneau **Localizations**. Vous pouvez [les traduire manuellement](#translate-strings-manually), [avec l'IA](#translate-strings-with-ai), ou [exporter le fichier de localisation](#localize-content-externally) pour l'utiliser avec un traducteur tiers.

Pour localiser les images et les vidéos, [modifiez les propriétés de l'élément cible](#localize-images-and-videos).

### Traduire les chaînes manuellement \{#translate-strings-manually\}

Le tableau dans le panneau **Localizations** répertorie toutes les chaînes du flow :

- Texte statique (une ligne par élément)
- Texte conditionnel (une ligne par branche)
- Cibles des actions **Open URL** (une ligne par URL)

Pour traduire une chaîne, cliquez sur une cellule et saisissez la traduction. Pour insérer une [variable](onboarding-variables), cliquez sur **&#123; &#125;** dans la cellule. Pour trouver la ligne d'une chaîne, [sélectionnez son élément](builder-ui#preview-area-center) dans l'aperçu.

Chaque élément de texte conditionnel est un groupe de lignes distinct. Cliquez sur la flèche <Inline id="expand-layer.svg" alt="Expand" /> pour développer le groupe et afficher toutes les branches de condition.

<ZoomImage id="locales-conditional-text.webp" width="700px" alt="Texte conditionnel développé dans le panneau Localisations, avec une ligne pour chaque branche et ses traductions" />

### Définir des URL d'action spécifiques aux paramètres régionaux \{#set-locale-specific-action-urls\}

Chaque action **Open URL** possède sa propre ligne. Pour définir une [URL](#action-urls) différente selon les paramètres régionaux, modifiez la valeur de la cellule dans la colonne correspondante. Pour savoir à quel élément appartient une URL, cliquez sur sa ligne : le builder sélectionne alors cet élément dans l'aperçu.

### Localiser les images et les vidéos \{#localize-images-and-videos\}

Pour afficher une image ou une vidéo différente selon la langue, importez un fichier distinct pour chaque langue :

1. Si le panneau **Localizations** est ouvert, fermez-le.
2. Changez la langue active dans la [barre d'outils inférieure](builder-ui#view-controls-bottom-toolbar).
3. Sélectionnez l'élément image ou vidéo. Importez le fichier localisé.
4. Une fois terminé, rétablissez la valeur par défaut dans **Locale**. Tant qu'une autre langue est active, vos modifications dans le panneau des propriétés ne s'appliquent qu'à cette langue.

<ZoomImage id="image-localization-demo.webp" width="500px" alt="L'image du canvas change au fur et à mesure que la locale active change" />

## Localiser le contenu en externe \{#localize-content-externally\}

Pour traduire tout le texte de votre flow en dehors d'Adapty, par exemple avec un service de traduction ou vos propres traducteurs, [exportez le fichier de localisation](#export-the-localization-file). Une fois la traduction prête, [importez](#import-the-file-with-a-translation) le fichier.

### Exporter le fichier de localisation \{#export-the-localization-file\}

Cliquez sur **Import / Export** dans l'en-tête du tableau pour exporter l'intégralité du flow avec toutes ses locales. Cliquez sur **Export** dans le [menu contextuel de la colonne](#manage-a-locale) pour exporter une locale individuelle avec la locale source.

<ZoomImage id="import-export.webp" width="700px" alt="Menu Import / Export dans l'en-tête du panneau Localisations" />

### Format du fichier d'import / export \{#import--export-file-format\}

Le fichier de localisation est un fichier `.tsv` (valeurs séparées par des tabulations) en UTF-8, avec une ligne par chaîne de caractères ou URL d'action. Un fichier exporté couvre l'intégralité du flow, quels que soient les filtres définis dans le panneau. Pour importer un fichier, conservez son format intact. Les colonnes sont les suivantes :

| Colonne | Description |
|--------|-------------|
| `id` | L'identifiant de la ligne. Adapty fait correspondre les lignes par cet identifiant lors de l'import, donc gardez-le inchangé. Adapty ignore les lignes dont l'`id` n'existe pas dans le flow. |
| `Screen` | L'écran{/* or reusable component*/} auquel appartient la chaîne. Adapty ignore cette colonne lors de l'import. |
| `[locale]` | Une colonne par locale, nommée par son code (ex. : `en`, `fr`). Adapty ignore les colonnes correspondant à des locales absentes du flow. |

Exemple :

```
id	Screen	en	fr	es
lc_1	Welcome	Turn words into art	Transformez les mots en art
lc_2	Welcome	Start your <b>free trial</b>	Commencez votre <b>essai gratuit</b>
lc_3	Quiz	What will you create?
```

Dans le fichier exporté :

- La mise en forme apparaît sous forme de balises HTML, comme `<b>`, et les variables comme `{{name}}`. Conservez-les telles quelles : Adapty les restaure à l'importation.
- Chaque branche du [texte conditionnel](#conditional-text) possède sa propre ligne, sans sa condition.
- Les images et vidéos ne sont pas incluses : vous les [localisez dans le builder](#localize-images-and-videos).

Pour traduire les chaînes ajoutées après l'exportation, exportez à nouveau le fichier.

Adapty ne peut pas importer un fichier dans l'ancien format, avec les colonnes `Screen`, `Element` et `Property`. Pour réutiliser ses traductions, exportez à nouveau le flow et copiez-les dans le nouveau fichier.

### Importer le fichier avec une traduction

:::warning
Si une cellule du fichier est vide, Adapty supprime la traduction de cette cellule à l'importation, sauf dans la colonne de la langue par défaut. Pour conserver les traductions d'une langue, laissez ses cellules telles qu'elles ont été exportées, ou supprimez sa colonne du fichier. Si une importation efface des traductions que vous souhaitiez conserver, annulez l'importation : l'ensemble de l'importation constitue une seule étape d'annulation.
:::

Pour importer l'intégralité du flow, cliquez sur **Import / Export** dans l'en-tête du tableau et sélectionnez **Import**. Pour importer une seule langue, sélectionnez **Import** dans son [menu contextuel de colonne](#manage-a-locale). Ensuite, sélectionnez le fichier traduit.

Les chaînes sans ligne dans le fichier conservent leurs valeurs actuelles. Un import global du flow met à jour le texte de la locale par défaut partout où le fichier le modifie. Un import sur une seule locale ne modifie que la locale importée. Pour importer une nouvelle langue, [ajoutez d'abord sa locale](#add-and-set-up-a-locale).

## Prévisualiser différentes langues \{#preview-different-locales\}

Le texte affiché dans la zone de prévisualisation correspond toujours à la langue active. Si vous modifiez du contenu textuel dans le panneau des propriétés, ces modifications ne s'appliquent qu'à cette langue. Repassez à la langue par défaut pour modifier le contenu source.

- Pour changer la langue active, sélectionnez-la dans le menu déroulant **Locale** de la [barre d'outils inférieure](builder-ui#view-controls-bottom-toolbar), ou cliquez sur son onglet dans le panneau **Localizations**.
- Pour changer d'écran actif depuis le panneau **Localizations**, cliquez sur **View screen** <Inline id="eye.svg" alt="View screen" /> dans l'en-tête de sa section.
- Pour étendre le tableau de localisation sur tout l'écran, cliquez sur **Hide preview**.

<ZoomImage id="preview-locales.webp" width="500px" alt="Aperçu des langues dans Flow & Paywall Builder" />

Pour trouver du texte non traduit sans avoir à prévisualiser chaque écran, exécutez le [skill flow-audit](flow-audit-skill).
