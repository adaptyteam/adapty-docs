Posez des questions à un agent de codage IA sur vos analyses Adapty en langage naturel — revenus, conversions, rétention, LTV — et laissez-le récupérer les chiffres pour vous. L'agent exécute les [commandes d'analyse Adapty CLI](developer-cli-analytics) dans votre terminal et lit les résultats.

## Ce que vous pouvez demander \{#what-you-can-ask-about\}

Le CLI renvoie les mêmes chiffres que ceux affichés dans le tableau de bord Adapty Analytics. Chaque type de question correspond à une commande :

| Question sur | Ce que ça couvre | Commande |
| --- | --- | --- |
| Revenus, MRR, ARR, ARPU et autres graphiques | Une métrique dans le temps, regroupée par une dimension prise en charge par le graphique, comme le pays | `adapty analytics chart` |
| Taux de conversion | Combien d'utilisateurs passent d'une étape à la suivante, par exemple de l'essai au payant | `adapty analytics conversion` |
| Funnel | Où les utilisateurs abandonnent entre l'installation et les renouvellements | `adapty analytics funnel` |
| Rétention | Combien d'abonnés restent après chaque période | `adapty analytics retention` |
| Valeur vie (LTV) | Revenus par utilisateur payant après chaque renouvellement ou jour | `adapty analytics ltv` |
| Cohortes d'installation | Revenus, abonnés et prédictions pour les utilisateurs ayant installé au cours de la même période | `adapty analytics cohort` |

Chaque commande est en lecture seule. L'agent ne peut rien modifier dans votre compte Adapty.

## Avant de commencer \{#before-you-start\}

Vous avez besoin de trois choses :

- **Un compte Adapty avec des données** : le CLI renvoie les mêmes chiffres que votre tableau de bord, donc votre application doit déjà collecter des données analytiques.
- **Le CLI Adapty, version 0.10.0 ou ultérieure, connecté** : pour installer le CLI et vous connecter, exécutez ces commandes. La connexion ouvre un onglet dans le navigateur où vous confirmez le code affiché dans le terminal.

  ```bash
  npm install -g adapty
  ```

  ```bash
  adapty auth login
  ```

  Une seule connexion donne accès à toutes les applications auxquelles votre utilisateur Adapty a accès — aucune clé API n'est nécessaire.

- **Un outil IA capable d'exécuter des commandes terminal** : par exemple Claude Code, Cursor, Codex ou Gemini CLI. Les outils de chat classiques comme claude.ai ou ChatGPT ne peuvent pas exécuter la CLI.

## Donnez les commandes à votre agent \{#give-your-agent-the-commands\}

La [référence CLI analytics](https://adapty.io/docs/fr/developer-cli-analytics.md) décrit chaque commande, ses options et comment interpréter les résultats. Une fois que votre agent l'a lue, il construit les commandes correctes sans que vous ayez à les écrire.

Transmettez la référence à votre agent par URL : si votre agent peut récupérer des URLs, donnez-lui `https://adapty.io/docs/fr/developer-cli-analytics.md` et demandez-lui de lire la page.

L'agent n'a pas besoin de connaître vos noms de graphiques à l'avance. Il les trouve avec `adapty analytics catalog --app <app-id>`, qui liste chaque graphique, conversion, regroupement et filtre pris en charge par votre application.

## Posez des questions sur vos données \{#ask-about-your-data\}

Une fois la référence chargée et le CLI connecté, indiquez le nom de l'app, la métrique, la période et ce que vous souhaitez décider.

Exemples de prompts :

```
For my app "Sleep Tracker", what was MRR at the end of each month this year,
and how does it compare to the same months last year?

Show the trial-to-paid conversion rate for the last 90 days, by product.
Which product converts worst?

Which 10 countries brought the most revenue in Q3? Use revenue after the
store's commission.

How does retention compare between iOS and Android for subscribers who started
in the last 6 months?

Compare LTV after 30 and 90 days for users who installed in July and in August,
and save it as a CSV file.
```

L'agent trouve l'UUID de l'application avec `adapty apps list`, choisit la commande et renvoie les données. Il lit les résultats en JSON (`--json`). Demandez un CSV si vous voulez un fichier prêt pour un tableur — l'agent ajoute `--csv` à la commande.

## Configurer une fois pour une utilisation répétée \{#set-up-once-for-repeated-use\}

Pour éviter de répéter la configuration à chaque session, enregistrez la référence à un endroit où votre agent pourra la réutiliser :

- **Sauvegardez le lien de référence** : Ajoutez `https://adapty.io/docs/fr/developer-cli-analytics.md` dans les règles ou le fichier mémoire de votre agent (par exemple, un fichier `CLAUDE.md` ou un fichier de règles Cursor) pour qu'il se charge à chaque session.
- **Nommez votre app** : Ajoutez le nom ou l'UUID de votre app dans le même fichier, pour ne pas avoir à le préciser à chaque prompt.
- **Sauvegardez vos prompts réutilisables ou créez un skill personnalisé** : Conservez vos questions courantes sous forme de prompts sauvegardés, ou encapsulez-les dans un skill personnalisé ou une commande slash pour que votre agent génère un rapport à la demande.

## Limites \{#limits\}

Gardez ces contraintes à l'esprit :

- **Limite de débit** : Chaque commande d'analyse autorise 2 requêtes par seconde et par application. Le CLI ne réessaie pas automatiquement, donc une commande envoyée trop vite échoue avec le code de sortie 4. Dites à votre agent d'exécuter les commandes l'une après l'autre et d'attendre `retry_after_seconds` avant de relancer une commande échouée.
- **Une application par commande** : Chaque commande lit une seule application. Pour comparer des applications, l'agent exécute une commande par application.
- **Non inclus dans l'Attribution** : Pour les dépenses publicitaires, les installations et le ROAS par campagne, utilisez les [commandes Attribution](developer-cli-attribution). N'ajoutez pas ces chiffres aux chiffres d'analyse, car Adapty les calcule différemment.

Pour extraire des données analytiques depuis un serveur ou une tâche planifiée, sans connexion possible via un navigateur, utilisez l'[API Export Analytics](export-analytics-api) avec une clé API secrète.
