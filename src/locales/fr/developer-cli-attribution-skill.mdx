La skill adapty-attribution permet à un outil de codage IA de répondre à vos questions sur vos campagnes publicitaires à partir de vos données d'[attribution Adapty](adapty-user-acquisition). Posez vos questions en langage naturel — « Quel canal a le mieux rentabilisé le mois dernier ? », « Faut-il couper cette campagne ? » — et la skill exécute les [commandes `adapty attribution`](developer-cli-attribution), lit les résultats et vous répond avec les chiffres à l'appui.

Un skill est un ensemble d'instructions que votre outil IA charge à la demande. Celui-ci contient les parties des rapports d'attribution qui sont faciles à mal interpréter : la base de revenus sur laquelle repose un ROAS, les valeurs qui ne peuvent pas encore être calculées, et d'où proviennent les dépenses Apple Search Ads.

:::note
Le skill se contente de lire. Il ne modifie aucune campagne, aucun lien de suivi, ni aucune intégration, et les ajustements budgétaires qu'il suggère restent à votre discrétion.
:::

## Ce à quoi le skill répond \{#what-it-answers\}

Le skill fonctionne à partir de playbooks — un ensemble de commandes, une façon de les lire et la forme de la réponse — pour les questions que les équipes posent le plus souvent :

- **Retour sur investissement et budget** : Classe les canaux et campagnes par ROAS et indique où allouer un budget supplémentaire, et selon quelles étapes.
- **Campagnes récentes** : Évalue une nouvelle campagne au jour où ses cohortes sont arrivées, plutôt qu'en se basant sur un J30 qui ne contient qu'une semaine de revenus.
- **Qualité des essais** : Classe les campagnes par coût par essai payant plutôt que par coût par installation, ce qui permet de repérer les campagnes dont les essais ne convertissent pas.
- **Résumé hebdomadaire** : Compare la dernière semaine aux précédentes et signale ce qui a évolué.
- **Pays et stores** : Indique où développer la présence et où plafonner les dépenses.
- **Gagnants au sein d'une campagne** : Classe les ensembles de publicités et les publicités au sein d'une même campagne.
- **Trafic de faible qualité** : Signale les campagnes avec plus de remboursements et de rétrofacturations que la moyenne de l'application.
- **Retour sur investissement prédit** : Lit le ROAS prédit sur des horizons plus longs et le convertit en CPI au seuil de rentabilité.
- **Chiffres contradictoires** : Explique pourquoi Meta, TikTok ou Google affichent un ROAS différent de celui d'Adapty.
- **Chute des installations** : Analyse le schéma d'une baisse pour distinguer une cause liée à l'application d'une cause propre à un seul réseau.

Setup questions — connecting Meta, TikTok, or Google Ads, tracking links, the web pixel, Stripe, or Paddle — go to the docs pages that own them.

## Apple Search Ads

L'attribution ne collecte pas les dépenses Apple Search Ads, donc son ROAS est vide à cet endroit. Le skill récupère les dépenses et le ROAS d'Apple Search Ads depuis [Ads Manager](developer-cli-ads-manager) et les affiche sur une ligne distincte, dans la devise de votre groupe de campagnes, sans les fusionner avec les chiffres de l'attribution. Si vous lui indiquez vous-même un montant de dépenses, il vous répond avec un seuil — « Apple Search Ads est plus rentable que Google si ses dépenses étaient inférieures à X$ » — plutôt qu'un ROAS calculé à partir de votre estimation.

## Installer le skill

Le skill est disponible dans le dépôt `adapty-skills`, aux côtés de `adapty-integration`, `ads-manager`, `flow-generator`, et d'autres. Chacune de ces commandes installe tous les skills du dépôt.

<Tabs>
  <TabItem value="claude-code" label="Claude Code">
    ```bash
    claude plugin marketplace add adaptyteam/adapty-skills
    claude plugin install adapty-skills@adapty
    ```

Ensuite, exécutez `/reload-plugins` dans Claude Code pour activer les skills.
  </TabItem>
  <TabItem value="copilot-cli" label="Copilot CLI">
    ```bash
    git clone https://github.com/adaptyteam/adapty-skills.git
    cp -r adapty-skills/skills/* ~/.copilot/skills/
    ```
  </TabItem>
  <TabItem value="gemini-cli" label="Gemini CLI">
    ```bash
    gemini skills install https://github.com/adaptyteam/adapty-skills
    ```
  </TabItem>
  <TabItem value="codex" label="Codex">
    ```bash
    codex plugin marketplace add adaptyteam/adapty-skills
    codex plugin add adapty-skills@adapty
    ```

Ensuite, démarrez un nouveau fil de discussion pour que Codex charge les skills.
  </TabItem>
  <TabItem value="any-tool" label="Any tool">
    ```bash
    npx skills add adaptyteam/adapty-skills --all
    ```

    `--all` installe chaque skill dans chaque agent détecté par la [CLI skills](https://skills.sh). Pour ce skill uniquement, utilisez `--skill adapty-attribution`. Les skills installés de cette façon ne se mettent pas à jour automatiquement — exécutez `npx skills update` pour obtenir une version plus récente.
  </TabItem>
</Tabs>

La skill nécessite l'[Adapty CLI](developer-cli-quickstart), une connexion active, et l'accès Attribution pour votre entreprise. Ensuite, faites-en la demande — `/adapty-attribution` dans les outils qui associent les commandes slash aux skills, ou « Use the adapty-attribution skill » dans ceux qui ne le font pas.

## Exemples de prompts \{#example-prompts\}

Nommez l'application, la période et la décision à prendre. Le skill se charge des commandes.

```
Our app is app_finance. Which paid channels paid back best in August, and where
should next month's extra $20k of budget go? Judge on revenue after the store's
cut.
```

```
Our TikTok "Fall Promo" campaign started on Sep 15. Leadership's rule is to kill
anything under 80% D30 ROAS. How is it doing against "Spring Sleep", and should
we kill it?
```

```
Meta Ads Manager says our "Broad US" campaign had a 2.4 purchase ROAS in August.
Adapty shows something much lower. Which number is right, and what do I tell my
boss?
```
