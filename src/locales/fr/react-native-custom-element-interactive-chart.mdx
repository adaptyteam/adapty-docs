Suivez cette recette pour afficher le poids projeté de chaque utilisateur sous forme de graphique dans un flow de paywall. L'utilisateur saisit son poids actuel et son objectif dans un flow d'onboarding. Votre application collecte ces deux valeurs. Le graphique montre la progression hebdomadaire que l'utilisateur peut espérer avec votre application, d'une valeur à l'autre. Votre application affiche le graphique sous forme de vue native dans un [élément personnalisé](flow-custom-elements). Sur iOS, la vue utilise Swift Charts. Sur Android, la vue dessine le graphique sans bibliothèque de graphiques.

## Avant de commencer \{#before-you-start\}

- Mettez à jour votre application vers Adapty React Native SDK 4.4 ou version ultérieure. Les versions antérieures du SDK affichent le [contenu de secours](flow-custom-elements#set-fallback-content) pour chaque élément personnalisé.
- Configurez votre application pour [récupérer](react-native-get-pb-paywalls) et [afficher](react-native-present-paywalls) les flows.
- Configurez le code natif de votre application pour les éléments personnalisés, comme indiqué dans le [guide React Native](react-native-flow-custom-elements#before-you-start).
- Sur iOS, le glissement le long du graphique nécessite iOS 17 ou une version ultérieure. Sur iOS 16, les utilisateurs voient la ligne, mais ne peuvent pas la faire glisser.
- Sur Android, [configurez Jetpack Compose](react-native-flow-custom-elements#set-up-jetpack-compose) dans votre module d'application. Le graphique de cette recette est un composable. Ajoutez Compose Foundation à votre application avec Gradle, depuis `androidx.compose.foundation:foundation`.

## 3. Enregistrez le poids actuel et l'objectif dans votre application \{#3-save-the-current-and-goal-weight-in-your-app\}

Collectez le poids actuel et l'objectif à partir des événements `flow_user_input` du flow d'onboarding, comme indiqué dans [Traiter les données des flows](react-native-flow-input). Pour savoir que l'utilisateur a atteint le dernier écran, surveillez un événement `flow_screen_showed` avec `is_last_screen` défini sur `true`. Lorsque le flow d'onboarding se ferme après cet écran, transmettez les deux poids à `showWeightPaywall`, la fonction qui [ouvre le flow de paywall avec le graphique](#6-send-the-weights-from-your-javascript-code).

La fonction suivante renvoie les handlers `onAnalytics` et `onDisappeared` du flow d'onboarding :

```typescript showLineNumbers title="weightOnboardingHandlers.ts"

// the event handlers of the onboarding flow view
export function weightOnboardingHandlers(): Partial<FlowEventHandlers> {
  const enteredWeights: Record<string, string> = {};
  let reachedLastScreen = false;

  return {
    onAnalytics(name, params) {
      if (name === 'flow_screen_showed' && params.is_last_screen === true) {
        reachedLastScreen = true;
      } else if (
        name === 'flow_user_input' &&
        typeof params.element_id === 'string' &&
        typeof params.value === 'string'
      ) {
        enteredWeights[params.element_id] = params.value;
      }
      return false; // keep the flow open
    },
    onDisappeared() {
      // number inputs send their values as strings
      const currentWeight = Number.parseFloat(enteredWeights.weight ?? '');
      const goalWeight = Number.parseFloat(enteredWeights.goal_weight ?? '');
      if (reachedLastScreen && !Number.isNaN(currentWeight) && !Number.isNaN(goalWeight)) {
        showWeightPaywall(currentWeight, goalWeight);
      }
      return false;
    },
  };
}
```

Avant de présenter le flow d'onboarding, transmettez les handlers à sa vue :

```typescript showLineNumbers title="React Native"
const view = await createFlowView(flow);
view.setEventHandlers(weightOnboardingHandlers());
await view.present();
```

Si votre application définit déjà `onAnalytics` ou `onDisappeared` pour le flow d'onboarding, ajoutez le code de `weightOnboardingHandlers` à vos handlers. Chaque handler que vous transmettez à `setEventHandlers` remplace tout handler précédent portant le même nom.

## 4. Créer la vue du graphique \{#create-the-chart-view\}

Créez un modèle de plan de poids et une vue avec le graphique. Le plan comporte une entrée par semaine, du poids actuel jusqu'au poids cible. Lorsque l'utilisateur fait glisser son doigt sur le graphique, la vue marque la semaine au point de contact et affiche le poids prévu pour cette semaine :

<Tabs groupId="platform" queryString>
<TabItem value="ios" label="iOS (Swift)" default>

```swift showLineNumbers title="Swift"

struct WeightPlan {
    let entries: [WeightEntry]

    // One entry per week, from the current weight to the goal weight
    init(currentWeight: Double, goalWeight: Double) {
        let weeklyChange = 0.5 // kg per week
        let startDate = Date.now
        let weeks = Int((abs(goalWeight - currentWeight) / weeklyChange).rounded(.up))
        let step = goalWeight < currentWeight ? -weeklyChange : weeklyChange
        entries = (0...weeks).map { week in
            WeightEntry(
                date: startDate.addingTimeInterval(Double(week) * 7 * 24 * 60 * 60),
                kilograms: week == weeks ? goalWeight : currentWeight + step * Double(week)
            )
        }
    }
}

struct WeightEntry: Identifiable {
    let date: Date
    let kilograms: Double
    var id: Date { date }
}

@available(iOS 16.0, *) // Swift Charts needs iOS 16
struct WeightGoalChart: View {
    let entries: [WeightEntry]
    @State private var selectedDate: Date?

    // The entry closest to the date that the user drags to
    private var selectedEntry: WeightEntry? {
        guard let selectedDate else { return nil }
        return entries.min {
            abs($0.date.timeIntervalSince(selectedDate)) < abs($1.date.timeIntervalSince(selectedDate))
        }
    }

    var body: some View {
        if #available(iOS 17.0, *) {
            chart.chartXSelection(value: $selectedDate)
        } else {
            chart // iOS 16: no drag selection
        }
    }

    private var chart: some View {
        Chart {
            ForEach(entries) { entry in
                LineMark(
                    x: .value("Date", entry.date),
                    y: .value("Weight", entry.kilograms)
                )
            }
            if let selectedEntry {
                RuleMark(x: .value("Date", selectedEntry.date))
                    .foregroundStyle(.gray.opacity(0.3))
                PointMark(
                    x: .value("Date", selectedEntry.date),
                    y: .value("Weight", selectedEntry.kilograms)
                )
                .annotation(position: .top) {
                    Text("\(selectedEntry.kilograms, specifier: "%.1f") kg")
                        .font(.caption.bold())
                }
            }
        }
        .chartYScale(domain: .automatic(includesZero: false))
    }
}
```

La navigation par glissement sur le graphique nécessite iOS 17 ou une version ultérieure. Sur iOS 16, les utilisateurs voient la ligne, mais ne peuvent pas glisser dessus.

```kotlin showLineNumbers title="Kotlin"

class WeightPlan(currentWeight: Double, goalWeight: Double) {
    // one entry per week, from the current weight to the goal weight
    val entries: List<WeightEntry> = run {
        val weeklyChange = 0.5 // kg per week
        val start = System.currentTimeMillis()
        val weekMillis = 7L * 24 * 60 * 60 * 1000
        val weeks = ceil(abs(goalWeight - currentWeight) / weeklyChange).toInt()
        val step = if (goalWeight < currentWeight) -weeklyChange else weeklyChange
        (0..weeks).map { week ->
            val kilograms = if (week == weeks) goalWeight else currentWeight + step * week
            WeightEntry(Date(start + week * weekMillis), kilograms)
        }
    }
}

data class WeightEntry(val date: Date, val kilograms: Double)

@Composable
fun WeightGoalChart(entries: List<WeightEntry>) {
    // the week under the finger, or null when the user isn't dragging
    var selectedIndex by remember { mutableStateOf<Int?>(null) }
    val textMeasurer = rememberTextMeasurer()
    val dateFormat = remember { DateFormat.getDateInstance(DateFormat.MEDIUM) }
    val color = Color(0xFFAF52DE)
    val textStyle = TextStyle(color = Color.Gray, fontSize = 12.sp)
    val minKg = entries.minOf { it.kilograms }
    val kgRange = (entries.maxOf { it.kilograms } - minKg).coerceAtLeast(1.0)

    Canvas(
        Modifier
            .fillMaxSize()
            .pointerInput(entries) {
                // horizontal drags select a week; vertical drags scroll the screen
                detectHorizontalDragGestures(
                    onDragEnd = { selectedIndex = null },
                    onDragCancel = { selectedIndex = null },
                ) { change, _ ->
                    val index = (change.position.x / size.width * entries.lastIndex).roundToInt()
                    selectedIndex = index.coerceIn(0, entries.lastIndex)
                }
            }
    ) {
        val startDate = textMeasurer.measure(dateFormat.format(entries.first().date), textStyle)
        val endDate = textMeasurer.measure(dateFormat.format(entries.last().date), textStyle)
        val dateY = size.height - startDate.size.height
        val top = 24.dp.toPx() // room for the projected weight above the line
        val bottom = dateY - 8.dp.toPx()
        fun pointOf(index: Int) = Offset(
            x = size.width * index / entries.lastIndex.coerceAtLeast(1),
            y = bottom - ((entries[index].kilograms - minKg) / kgRange * (bottom - top)).toFloat(),
        )

        // the line from the current weight to the goal weight
        for (index in 1..entries.lastIndex) {
            drawLine(color, pointOf(index - 1), pointOf(index), strokeWidth = 2.dp.toPx())
        }
        // the dates of the first and the last week
        drawText(startDate, topLeft = Offset(0f, dateY))
        drawText(endDate, topLeft = Offset(size.width - endDate.size.width, dateY))

        // the selected week: a point, and the projected weight above it
        selectedIndex?.let { index ->
            val point = pointOf(index)
            drawCircle(color, radius = 5.dp.toPx(), center = point)
            val weight = String.format(Locale.getDefault(), "%.1f kg", entries[index].kilograms)
            val label = textMeasurer.measure(weight, textStyle.copy(color = color))
            val x = (point.x - label.size.width / 2)
                .coerceAtMost(size.width - label.size.width)
                .coerceAtLeast(0f)
            drawText(label, topLeft = Offset(x, point.y - label.size.height - 8.dp.toPx()))
        }
    }
}
```

## 5. Associer le graphique à l'élément personnalisé \{#match-the-chart-to-the-custom-element\}

Dans votre [résolveur global](react-native-flow-custom-elements#pass-the-resolver-to-the-sdk), ajoutez une propriété `WeightPlanStore`. Ensuite, renvoyez la vue du graphique pour le Type `line_chart` et l'ID `weight_goal`. Les lignes surlignées indiquent ce qu'il faut ajouter ou modifier. Si votre application ne possède pas encore de [résolveur](react-native-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views) global, copiez l'intégralité du code :

```swift showLineNumbers title="Swift" {4-8,11,19-23}
// the weight plan that your JavaScript code sends before the paywall flow opens
@MainActor
final class WeightPlanStore {
    var plan: WeightPlan?

struct CustomElementsResolver: AdaptyUICustomElementsResolver {
    let weightPlanStore: WeightPlanStore

    func view(
        forType type: String,
        id: String,
        context: AdaptyUICustomElementContext
    ) -> AnyView? {
        switch type {
        case "line_chart" where id == "weight_goal":
            guard #available(iOS 16.0, *), let plan = weightPlanStore.plan else {
                return nil // no weight plan: show the fallback
            }
            return AnyView(WeightGoalChart(entries: plan.entries))
        // the other cases of your resolver
        default:
            return nil
        }
    }
}
```

## 6. Envoyez les poids depuis votre code JavaScript \{#6-send-the-weights-from-your-javascript-code\}

Définissez le resolver au lancement de l'application et alimentez le store depuis votre code JavaScript via un [Turbo Native Module](https://reactnative.dev/docs/turbo-native-modules-introduction). Le module dispose d'une spec JavaScript et d'une implémentation pour chaque plateforme.

Dans un dossier `specs` à la racine de votre projet, créez la spec du module :

```typescript showLineNumbers title="specs/NativeWeightPlanStore.ts"

export interface Spec extends TurboModule {
  setWeights(currentWeight: number, goalWeight: number): void;
}

export default TurboModuleRegistry.getEnforcing<Spec>('NativeWeightPlanStore');
```

Pour générer le code natif de la spec, ajoutez `codegenConfig` à `package.json`. Remplacez `com.example.app` par le nom du package de votre application Android, dans `package.json` et dans l'implémentation Kotlin du module. Si `package.json` contient déjà `codegenConfig`, ajoutez uniquement `NativeWeightPlanStore` à l'objet `modulesProvider` :

```json showLineNumbers title="package.json"
"codegenConfig": {
  "name": "AppSpecs",
  "type": "modules",
  "jsSrcsDir": "specs",
  "android": {
    "javaPackageName": "com.example.app.specs"
  },
  "ios": {
    "modulesProvider": {
      "NativeWeightPlanStore": "RCTNativeWeightPlanStore"
    }
  }
}
```

Implémentez le module pour chaque plateforme :

Dans `AppDelegate.swift`, ajoutez une propriété pour le plan de poids. Dans la méthode `application(_:didFinishLaunchingWithOptions:)`, définissez le resolver et observez `NotificationCenter` pour mettre à jour le plan de poids à chaque paire de poids. Les lignes surlignées indiquent ce qui est à ajouter. Conservez le reste de la classe `AppDelegate` tel quel :

```swift showLineNumbers title="ios/YourApp/AppDelegate.swift" {1,6-7,13-26}

@main
class AppDelegate: UIResponder, UIApplicationDelegate {
  // the weight plan that your JavaScript code sends
  let weightPlanStore = WeightPlanStore()

  func application(
    _ application: UIApplication,
    didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]? = nil
  ) -> Bool {
    AdaptyUI.setCustomElementsResolver(CustomElementsResolver(weightPlanStore: weightPlanStore))
    // the weights that your JavaScript code sends through the native module
    NotificationCenter.default.addObserver(
      forName: Notification.Name("WeightsDidChange"),
      object: nil,
      queue: .main
    ) { [weightPlanStore] notification in
      guard let currentWeight = notification.userInfo?["current"] as? Double,
            let goalWeight = notification.userInfo?["goal"] as? Double
      else { return }
      MainActor.assumeIsolated {
        weightPlanStore.plan = WeightPlan(currentWeight: currentWeight, goalWeight: goalWeight)
      }
    }
    // the rest of your launch code
    return true
  }
}
```

Pour générer le code natif de la spec, exécutez `pod install` dans le dossier `ios`.

```typescript showLineNumbers title="showWeightPaywall.ts"
export async function showWeightPaywall(currentWeight: number, goalWeight: number) {
```

## 7. Tester sur un appareil \{#7-test-on-a-device\}

Le Flow & Paywall Builder ne peut pas exécuter le code de votre application, donc son canvas affiche uniquement le paywall de secours. Pour prévisualiser le graphique :

1. [Publiez les deux flows](builder-save-publish). Pour voir les dernières versions publiées plutôt que les versions mises en cache, enregistrez l'appareil en tant qu'[appareil de test](test-devices).
2. Lancez un build de votre application qui inclut le resolver. Sur iOS, utilisez un appareil sous iOS 17 ou version ultérieure. Complétez le flow d'onboarding avec un poids actuel et un poids cible. Vérifiez que la ligne du graphique commence au poids actuel et se termine au poids cible.
3. Faites glisser votre doigt sur le graphique et vérifiez que le poids projeté pour la semaine sous votre doigt s'affiche au-dessus de la ligne.

Pour tester le fallback, ne retournez aucune vue pour le type `line_chart`, puis rouvrez le flow de paywall.

Pour comprendre pourquoi le fallback s'affiche à la place du graphique, suivez les instructions de la section [Tester sur un appareil](react-native-flow-custom-elements#test-on-a-device) du guide React Native.
