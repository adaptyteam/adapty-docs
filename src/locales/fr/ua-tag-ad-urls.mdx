Balisez les URL de vos annonces lorsque celles-ci redirigent les utilisateurs vers une page de destination ou un funnel web avant le store. Si votre annonce mène directement à l'App Store ou à Google Play, utilisez plutôt un [lien de suivi](ua-tracking-links) comme destination — le lien transporte lui-même les données de campagne, sans rien à baliser.

Adapty Attribution lit la campagne, le groupe d'annonces et l'annonce depuis l'URL de votre page de destination. Les réseaux publicitaires ajoutent automatiquement leur propre identifiant de clic (`fbclid` ou `ttclid`), qui identifie le réseau mais pas la campagne, le groupe d'annonces ni l'annonce. Pour attribuer les achats jusqu'à l'annonce exacte, ajoutez les paramètres de suivi à vos annonces.

Les étapes sont les mêmes quelle que soit la configuration de votre funnel — avec le [pixel web Adapty](ua-web-pixel) sur votre propre funnel, ou sur [FunnelFox](ua-funnelfox).

## Avant de commencer \{#before-you-start\}

Connectez [Meta Ads](ua-facebook) ou [TikTok for Business](ua-tiktok) à Adapty Attribution et ajoutez une configuration de campagne. Adapty génère les paramètres d'URL publicitaires par configuration de campagne, vous en avez donc besoin pour les copier.

## Taguez vos publicités \{#tag-your-ads\}

1. Dans la section **Web funnel** de la configuration de la campagne, copiez la valeur du champ **Ad URL parameters**.

<ZoomImage id="ua-web-pixel-url-params.webp" width="700px" alt="Champ Ad URL parameters dans la section Web funnel d'une configuration de campagne dans Adapty Attribution" />

2. Dans le réseau publicitaire, collez la valeur au niveau de la **publicité** :
   - **Meta** : Dans le champ **URL parameters** de la publicité.
   - **TikTok** : Sous l'URL de destination de la publicité, dans **Build URL parameters**.

La valeur contient des macros réseau. Le réseau les remplace par les valeurs réelles de campagne, de groupe d'annonces et d'annonce au moment du clic.

Les paramètres n'incluent pas de valeurs `utm_*`, vous pouvez donc conserver votre propre schéma UTM pour vos propres analyses — Adapty ne l'exige pas.
