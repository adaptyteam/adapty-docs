Balisez vos URLs de publicité lorsque votre annonce dirige les utilisateurs vers une page de destination ou un web funnel avant le store. Si votre annonce pointe directement vers l'App Store ou Google Play, utilisez plutôt un [lien de suivi](ua-tracking-links) comme destination — le lien transporte lui-même les données de campagne, sans rien à baliser.

Adapty Attribution lit la campagne, le groupe d'annonces et l'annonce depuis l'URL de votre landing page. Les réseaux publicitaires ajoutent automatiquement leur propre identifiant de clic (`fbclid`, `ttclid` ou `gclid`), qui identifie le réseau mais pas la campagne, le groupe d'annonces ou l'annonce. Pour attribuer les achats jusqu'à l'annonce exacte, ajoutez les paramètres de suivi à vos annonces.

Les étapes sont identiques quelle que soit la configuration de votre funnel — avec le [pixel web Adapty](ua-web-pixel) sur votre propre funnel, ou sur [FunnelFox](ua-funnelfox).

## Avant de commencer \{#before-you-start\}

Connectez [Meta Ads](ua-facebook), [TikTok for Business](ua-tiktok) ou [Google Ads](ua-google-ads) à Adapty Attribution et ajoutez une configuration de campagne. Adapty génère les paramètres d'URL publicitaires par configuration de campagne, vous devez donc en avoir une pour pouvoir les copier.

## Taguez vos annonces \{#tag-your-ads\}

1. Dans la section **Web funnel** de la configuration de campagne, copiez la valeur du champ **Ad URL parameters**.

<ZoomImage id="ua-web-pixel-url-params.webp" width="700px" alt="Champ Ad URL parameters dans la section Web funnel d'une configuration de campagne dans Adapty Attribution" />

2. Dans le réseau publicitaire, collez la valeur :
   - **Meta** : Dans le champ **URL parameters** de l'annonce.
   - **TikTok** : Sous l'URL de destination de l'annonce, dans **Build URL parameters**.
   - **Google Ads** : Dans les paramètres de la campagne, dans **Campaign URL options > Final URL suffix**. L'auto-tagging doit également être activé dans les paramètres de votre compte Google Ads.

La valeur contient des macros réseau. Le réseau les remplace par les vraies valeurs de campagne, d'ensemble d'annonces et d'annonce au moment du clic.

Conservez l'URL de votre landing page ou funnel dans le champ de destination de l'annonce (**Website URL** dans Meta, **Destination URL** dans TikTok, **Final URL** dans Google Ads) sans les paramètres. Le réseau les ajoute à cette URL au moment du clic, ce qui vous permet de modifier l'URL de destination ultérieurement sans avoir à re-tagger l'annonce.

Les paramètres n'incluent pas de valeurs `utm_*`, vous pouvez donc conserver votre propre schéma UTM pour vos propres analyses — Adapty ne l'exige pas.
