Avec Adapty, vous n'avez pas besoin de créer un nouveau paywall de zéro pour chaque application. Si vous gérez plusieurs applications, vous pouvez migrer la configuration du Paywall Builder de n'importe quel paywall créé avec le builder d'une application vers une autre.

La migration vous permet de copier toutes les configurations visuelles :
- Les paramètres de mise en page du paywall et de tous ses éléments
- Les médias
- La localisation

La migration s'applique uniquement à la configuration du builder et ne copie ni les produits ni le Remote Config.

:::note
Si vous migrez une configuration du Paywall Builder avec des polices personnalisées, testez-les sur un appareil car elles peuvent s'afficher incorrectement.
:::

## Migrer un paywall \{#migrate-paywall\}

:::important
Vous pouvez uniquement migrer des paywalls créés dans le Paywall Builder pour le SDK Adapty 3.x. Pour migrer un paywall créé pour le SDK 2.x ou antérieur, commencez par le déplacer vers le Paywall Builder du SDK 3.x.
:::

Pour migrer une configuration Paywall Builder :

1. **Pour un nouveau paywall** : Commencez la [création du paywall](create-paywall) et ajoutez des produits. Ensuite, cliquez sur **Build no-code paywall** pour ouvrir la bibliothèque de modèles.

**Pour un paywall existant** : Rendez-vous dans la section **Layout settings** de l'onglet **Builder & Generator** et cliquez sur **Change template**.
2. Cliquez sur **Choose paywall** dans la boîte **Copy a design from your apps** lors de l'édition du template de paywall.

Après la migration, vous pouvez effectuer toutes les modifications dont vous avez besoin sans affecter le paywall d'origine.
