Le fichier de clé est le justificatif d'identité du compte de service. Adapty l'utilise pour se connecter en tant que ce compte et appeler les API de Google en votre nom.

## Avant de commencer \{#before-you-start\}

[Accordez au compte de service ses autorisations Play Console](grant-permissions-to-service-account). Une clé ne dispose que des accès déjà attribués au compte.

## Générer le fichier de clé \{#generate-the-key-file\}

1. Ouvrez [**IAM & Admin** > **Service accounts**](https://console.cloud.google.com/iam-admin/serviceaccounts) dans Google Cloud Console, et assurez-vous d'être dans le bon projet.

2. Cliquez sur le compte de service que vous avez créé.

3. Ouvrez l'onglet **Keys**, puis cliquez sur **Add key** > **Create new key**.

   <ZoomImage id="gp-keys-add-key.webp" width="700px" alt="Onglet Keys d'un compte de service dans Google Cloud Console, avec le menu Add key ouvert" />

4. Laissez **Key type** sur **JSON** et cliquez sur **Create**. Le fichier sera téléchargé sur votre ordinateur.

<ZoomImage id="gp-create-json-key.webp" width="700px" alt="Boîte de dialogue de création de clé privée avec JSON sélectionné comme type de clé" />

:::warning
Conservez ce fichier en lieu sûr. Google ne vous permettra pas de le télécharger à nouveau, et toute personne qui le possède peut agir en tant que votre compte de service.
:::

## Activer le compte immédiatement \{#activate-the-account-immediately\}

Un nouveau compte de service prend au moins 24 heures à s'activer, et jusque-là, Adapty ne peut pas lire vos produits. Pour éviter cette attente, dans [Google Play Console](https://play.google.com/console/), allez dans **Monetize with Play** > **Products** > **Subscriptions**, puis modifiez et enregistrez la description de n'importe quel produit. Vous pouvez annuler la modification immédiatement après.

<ZoomImage id="gp-edit-product-description.webp" width="700px" alt="Page de détails de l'abonnement dans Google Play Console avec le champ Description" />

:::warning
Si ce fichier de clé est ultérieurement supprimé ou renouvelé, Adapty cesse de lire vos produits et ne peut plus valider les achats. Adapty ne vous en avertit pas — consultez [Si les mises à jour cessent d'arriver](store-sync#if-updates-stop-arriving).
:::
