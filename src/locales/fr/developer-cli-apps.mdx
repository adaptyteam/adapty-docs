Ces commandes Adapty CLI gèrent vos apps et leurs [niveaux d'accès](access-level) : les niveaux d'abonnement que votre app vérifie au moment de l'exécution.

## Applications \{#apps\}

Gérez les applications de votre compte Adapty. Pour la configuration depuis le tableau de bord, consultez [Paramètres de l'application](general).

### adapty apps list

Listez toutes les apps de votre compte Adapty.

```bash
adapty apps list
```

Accepte les [options de pagination](developer-cli-reference#global-flags).

### adapty apps get

Obtenir les détails d'une application spécifique.

```bash
adapty apps get <app-id>
```

| Argument | Description |
|---|---|
| `app-id` | ID de l'application (UUID) |

### adapty apps create

Crée une nouvelle application.

```bash
adapty apps create --title "My App" --platform ios --apple-bundle-id com.example.app
```

| Flag | Required | Description |
|---|---|---|
| `--title` | Yes | Titre de l'application |
| `--platform` | Yes | Plateforme : `ios` ou `android`. Répéter pour les deux : `--platform ios --platform android` |
| `--apple-bundle-id` | Required with `--platform ios` | Bundle ID Apple |
| `--google-bundle-id` | Required with `--platform android` | Bundle ID Google |

### adapty apps update

Mettre à jour une application existante.

```bash
adapty apps update <app-id> --title "New Name"
```

| Argument | Description |
|---|---|
| `app-id` | ID de l'application (UUID) |

| Flag | Description |
|---|---|
| `--title` | Nouveau titre de l'application |
| `--apple-bundle-id` | Nouvel Apple bundle ID |
| `--google-bundle-id` | Nouvel Google bundle ID |

Au moins un flag est requis. `--platform` ne peut pas être modifié après la création.

## Niveaux d'accès \{#access-levels\}

### adapty access-levels list

Listez tous les [niveaux d'accès](access-level) d'une application.

```bash
adapty access-levels list --app <app-id>
```

| Flag | Required | Description |
|---|---|---|
| `--app` | Yes | App ID (UUID) |

Accepte les [flags de pagination](developer-cli-reference#global-flags).

### adapty access-levels get

Obtenez les détails d'un [niveau d'accès](access-level) spécifique.

```bash
adapty access-levels get --app <app-id> <access-level-id>
```

| Argument | Description |
|---|---|
| `access-level-id` | ID du niveau d'accès (UUID) |

| Flag | Requis | Description |
|---|---|---|
| `--app` | Oui | ID de l'app (UUID) |

### adapty access-levels create

Crée un nouveau [niveau d'accès](access-level).

```bash
adapty access-levels create --app <app-id> --sdk-id "pro" --title "Pro"
```

| Flag | Requis | Description |
|---|---|---|
| `--app` | Oui | ID de l'application (UUID) |
| `--sdk-id` | Oui | Identifiant utilisé dans le code de l'application pour vérifier l'accès (par exemple, `"pro"` ou `"premium"`) |
| `--title` | Oui | Libellé affiché dans l'Adapty Dashboard |

### adapty access-levels update

Mettre à jour un [niveau d'accès](access-level) existant.

```bash
adapty access-levels update --app <app-id> <access-level-id> --title "Pro Access"
```

| Argument | Description |
|---|---|
| `access-level-id` | ID du niveau d'accès (UUID) |

| Flag | Requis | Description |
|---|---|---|
| `--app` | Oui | ID de l'application (UUID) |
| `--title` | Oui | Nouveau libellé d'affichage |

`--sdk-id` ne peut pas être modifié après la création.
