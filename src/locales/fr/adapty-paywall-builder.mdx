Le **Paywall Builder** d'Adapty est l'ancien outil no-code pour concevoir des paywalls, qui n'est plus en développement. Il nécessite le SDK Adapty v3.0 ou une version ultérieure. Ne créez pas de nouveaux paywalls ici, surtout avec le SDK v4. Ceux que vous avez déjà créés continuent de fonctionner — le SDK v4 les affiche via les mêmes méthodes que les flows.

Pour recréer un paywall existant en flow en un seul clic, consultez [Convertir un paywall en flow](convert-paywall-to-flow).

Pour afficher un paywall que vous avez déjà créé, récupérez-le ainsi que sa configuration de vue : [iOS](get-pb-paywalls) | [Android](android-get-pb-paywalls) | [React Native](react-native-get-pb-paywalls) | [Flutter](flutter-get-pb-paywalls) | [Unity](unity-get-pb-paywalls) | [Capacitor](capacitor-get-pb-paywalls) | [Kotlin Multiplatform](kmp-get-pb-paywalls)
