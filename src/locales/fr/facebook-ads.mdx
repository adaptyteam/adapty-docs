Grâce à l'intégration Facebook Ads, vous pouvez facilement consulter les statistiques de votre application dans Meta Analytics. Adapty envoie des événements à Meta Ads Manager, vous permettant de créer des audiences similaires basées sur les abonnements pour de meilleurs rendements. Vous pouvez ainsi mesurer précisément les revenus générés par vos abonnements.

L'intégration entre Adapty et Facebook Ads fonctionne de la façon suivante : Adapty envoie à Facebook Ads tous les événements d'abonnement configurés dans votre intégration. Cette intégration est utile pour évaluer l'efficacité de vos campagnes publicitaires.

## Configurer l'intégration \{#set-up-integration\}

### Connecter Adapty à Facebook Ads

Pour intégrer Facebook Ads et analyser les métriques de votre application, vous pouvez configurer l'intégration avec Meta Analytics. En envoyant des événements à Meta Ads Manager, vous pouvez créer des audiences similaires basées sur des événements d'abonnement comme les renouvellements. Pour configurer cette intégration, rendez-vous dans [Integrations > Facebook Ads](https://app.adapty.io/integrations/facebookanalytics) dans l'Adapty Dashboard et renseignez les identifiants requis.

:::note
Veuillez noter que l'intégration Facebook Ads fonctionne sur iOS 14.5+ uniquement pour les utilisateurs ayant donné leur consentement ATT.
:::

### Configurer les événements et les tags \{#configure-events-and-tags\}

Adapty associe ses événements d'achat aux événements standard de Meta, que Meta peut utiliser pour optimiser ses campagnes : `StartTrial`, `Subscribe` et `fb_mobile_purchase`, l'événement d'achat de Meta. **Subscription started**, **Subscription renewed**, **Trial started** et **Trial converted** envoient chacun un événement Meta pour chaque nom sélectionné dans le champ de l'événement, et tous les noms sont sélectionnés par défaut. Un début d'essai, par exemple, génère trois événements Meta. Pour en envoyer moins, retirez des noms du champ.

| Événement Adapty              | Événements Meta par défaut                           |
| :---------------------------- | :--------------------------------------------------- |
| Subscription started          | `Subscribe`, `fb_mobile_purchase`                    |
| Subscription renewed          | `Subscribe`, `fb_mobile_purchase`                    |
| Trial started                 | `StartTrial`, `Subscribe`, `fb_mobile_purchase`      |
| Trial converted               | `Subscribe`, `fb_mobile_purchase`                    |
| Non-subscription purchase     | `fb_mobile_purchase`                                 |

Meta ne dispose pas d'événement standard pour les événements restants, donc Adapty les envoie en tant qu'événements personnalisés sous leurs noms Adapty. Pour utiliser votre propre nommage, modifiez le nom dans le champ de l'événement.

| Événement Adapty                       | Événement Meta par défaut            |
| :--------------------------------- | :----------------------------------- |
| Subscription expired (Churned)     | `subscription_expired`               |
| Subscription renewal cancelled     | `subscription_renewal_cancelled`     |
| Subscription renewal reactivated   | `subscription_renewal_reactivated`   |
| Subscription paused (Android only) | `subscription_paused`                |
| Subscription deferred (Android only) | `subscription_deferred`            |
| Subscription refunded              | `subscription_refunded`              |
| Trial expired                      | `trial_expired`                      |
| Trial renewal cancelled            | `trial_renewal_cancelled`            |
| Trial renewal reactivated          | `trial_renewal_reactivated`          |
| Entered grace period               | `entered_grace_period`               |
| Billing issue detected             | `billing_issue_detected`             |
| Non-subscription purchase refunded | `non_subscription_purchase_refunded` |
| Trial still active                 | `trial_active`                       |
| Subscription still active          | `subscription_active`                |

**Trial still active** et **Subscription still active** sont des [événements synthétiques](events#synthetic-events) : Adapty les envoie à Meta selon un minuteur, et uniquement si l'essai ou l'abonnement est toujours en cours à l'expiration du minuteur. Ils ne portent aucun revenu, donc Meta ne les comptabilise pas dans la valeur des achats. Tous deux sont désactivés par défaut. Pour les envoyer, activez-les et [définissez le délai](configuration#set-the-timer-for-synthetic-events).

### Connectez votre application à Facebook Ads \{#connect-your-app-to-facebook-ads\}

Si vous suivez les étapes ci-dessus, Facebook recevra automatiquement les données d'abonnement en provenance d'Adapty.

Suite aux modifications apportées à l'IDFA dans iOS 14.5, nous vous recommandons de demander le `facebookAnonymousId` de l'utilisateur auprès de Facebook. Ainsi, si l'IDFA de l'utilisateur est indisponible, l'intégration continuera de fonctionner. ## Structure des événements \{#event-structure\}

Adapty envoie des événements à Facebook Ads (Meta) via l'API Graph. Chaque événement est structuré comme suit :

```json
{
  "event": "CUSTOM_APP_EVENTS",
  "app_user_id": "user_12345",
  "advertiser_id": "00000000-0000-0000-0000-000000000000",
  "advertiser_tracking_enabled": 1,
  "application_tracking_enabled": 1,
  "custom_events": "[{\"_eventName\":\"Subscribe\",\"_logTime\":1709294400,\"fb_num_items\":1,\"fb_content_type\":\"in_app\",\"fb_content_id\":\"yearly.premium.6999\",\"fb_currency\":\"USD\",\"fb_order_id\":\"GPA.3383...\",\"fb_transaction_id\":\"GPA.3383...\",\"_valueToSum\":9.99}]",
  "extinfo": "[\"i2\",\"com.example.app\",\"1.0.0\",\"100\",\"17.0.1\",\"iPhone14,3\",\"en_US\",\"GMT+3\",\"\",0,0,0,0,0,0,\"GMT+3\"]",
  "anon_id": "facebook_anon_id_123"
}
```

Where:

| Paramètre | Type | Description |
|:---|:---|:---|
| `event` | String | Toujours "CUSTOM_APP_EVENTS". |
| `app_user_id` | String | Le Customer User ID de l'utilisateur. |
| `advertiser_id` | String | Sur iOS, l'IDFA, ou l'IDFV si l'IDFA est indisponible. Sur Android, l'Advertising ID. Si le profil n'a pas d'identifiant d'appareil, `00000000-0000-0000-0000-000000000000`. |
| `advertiser_tracking_enabled` | Integer | `1` si le tracking est activé (ATT autorisé), `0` sinon. |
| `application_tracking_enabled` | Integer | Toujours `1`. |
| `custom_events` | String | Chaîne encodée en JSON contenant des objets d'événements (voir ci-dessous). |
| `extinfo` | String | Chaîne encodée en JSON contenant les informations sur l'application/l'appareil (par exemple, version, OS, locale). |
| `anon_id` | String | Facebook Anonymous ID (si disponible). |

Le paramètre `custom_events` est un tableau encodé en JSON comportant un objet pour chaque événement Meta auquel l'événement Adapty est associé. Seuls `StartTrial`, `Subscribe` et `fb_mobile_purchase` contiennent `fb_content_id`, `fb_content_type`, `fb_num_items` et `fb_transaction_id`. Chaque objet contient :

| Paramètre | Type | Description |
|:---|:---|:---|
| `_eventName` | String | Le nom de l'événement Meta Ads (ex. : "Subscribe"). |
| `_logTime` | Long | Horodatage de l'événement en secondes. |
| `_valueToSum` | Float | Montant des revenus. |
| `fb_content_id` | String | L'identifiant du produit dans le store. |
| `fb_currency` | String | Code devise (ex. : "USD"). |
| `fb_order_id` | String | Identifiant de transaction original. |
| `fb_transaction_id` | String | Identifiant de transaction original. |
| `fb_content_type` | String | Toujours "in_app". |
| `fb_num_items` | Integer | Toujours 1 pour les événements d'achat. |
