**In-App Purchase Key**, satın almaların gerçekliğini doğrulayarak güvenliğini sağlamak amacıyla App Store Connect içinde oluşturulan özel bir API anahtarıdır.

:::note
App Store Server API için API anahtarları oluşturabilmek için App Store Connect'te Admin veya Account Holder rolüne sahip olmanız gerekir. API anahtarlarının nasıl oluşturulacağı hakkında daha fazla bilgiyi [Apple Developer Dokümantasyonu](https://developer.apple.com/documentation/appstoreserverapi/creating-api-keys-to-authorize-api-requests)'nda bulabilirsiniz.
:::

1. **App Store Connect**'i açın. [**Users and Access** → **Integrations** → **In-App Purchase**](https://appstoreconnect.apple.com/access/integrations/api/subs) bölümüne gidin.

2. Ardından **Active** başlığının yanındaki ekle **(+)** düğmesine tıklayın.

3. Açılan **Generate In-App Purchase Key** penceresinde, ileride başvurmak üzere anahtara bir ad girin. Bu ad Adapty'de kullanılmayacaktır.

4. **Generate** düğmesine tıklayın. **Generate in-App Purchase Key** penceresi kapandıktan sonra oluşturulan anahtarı **Active** listesinde göreceksiniz.

  <img src="/assets/shared/img/fac066b-download_inapp_file.webp"

/>

5. API anahtarınızı oluşturduktan sonra, anahtarı dosya olarak almak için **Download In-App Purchase Key** düğmesine tıklayın.

<Zoom>
  <img src="/assets/shared/img/d59faff-download_in-app_purchase_key.webp"

    border: '1px solid #727272', /* border width and color */
    width: '700px', /* image width */
    display: 'block', /* for alignment */
    margin: '0 auto' /* center alignment */
  }}
/>
</Zoom>

6. **İndirme Uygulama İçi Satın Alma Anahtarı** penceresinde **Download** düğmesine tıklayın. Dosya bilgisayarınıza kaydedilir.
   Bu dosyayı ileride Adapty Kontrol Paneli'ne yüklemek üzere güvende tutmanız çok önemlidir. Oluşturulan dosya yalnızca bir kez indirilebileceğinden, yükleyene kadar güvenli bir şekilde sakladığınızdan emin olun. **Uygulama İçi Satın Alma bölümünden** oluşturulan .p8 anahtarı, [Adapty'nin App Store ile ilk entegrasyonunu yapılandırırken](app-store-connection-configuration#step-3-upload-in-app-purchase-key-file) kullanılacaktır.

:::warning
Bu anahtar daha sonra iptal edilir veya silinirse Adapty promosyon tekliflerini imzalayamaz ve bu indirimler satın alma sırasında uygulanmaz. Adapty bunu bildirmez — bkz. [Güncellemeler gelmeyi durursa](store-sync#if-updates-stop-arriving).
:::
