React Native uygulamanız çocuklara yönelikse, [Apple](https://developer.apple.com/kids/) ve [Google](https://support.google.com/googleplay/android-developer/answer/9893335) politikalarına uymanız gerekir. Adapty SDK kullanıyorsanız, birkaç basit adım onu bu politikalara uyacak ve uygulama mağazası incelemelerini geçecek şekilde yapılandırmanıza yardımcı olur.

:::important
iOS'ta Kids Mode (Çocuk Modu), tüm IDFA, AdSupport ve AppTrackingTransparency kodlarını derleme dışında bırakan `KidsMode` Swift package trait'i aracılığıyla etkinleştirilir. v4 SDK ve **Xcode 26** veya daha yeni bir sürüm gerektirir. Trait'i nasıl uygulayacağınız, iOS projenizin kullandığı paket yöneticisine bağlıdır — bkz. [iOS projenizde yapılacak güncellemeler](#updates-in-your-ios-project).
:::

## Ne gereklidir? \{#whats-required\}

Adapty SDK'yı aşağıdakilerin toplanmasını devre dışı bırakacak şekilde yapılandırmanız gerekir:

- [IDFA (Reklamverenler için Tanımlayıcı)](https://en.wikipedia.org/wiki/Identifier_for_Advertisers) (iOS)
- [Android Reklam Kimliği (AAID/GAID)](https://support.google.com/googleplay/android-developer/answer/6048248) (Android)
- [IP adresi](https://www.ftc.gov/system/files/ftc_gov/pdf/p235402_coppa_application.pdf)

Bunlara ek olarak, müşteri kullanıcı kimliğini dikkatli kullanmanızı öneririz. `<Ad.Soyad>` formatındaki kullanıcı kimliği, e-posta kullanımı gibi kişisel veri toplama olarak değerlendirilebilir. Çocuk Modu için en iyi uygulama, uyumu sağlamak amacıyla rastgele veya anonimleştirilmiş tanımlayıcılar (örneğin karma kimlikler veya cihaz tarafından oluşturulan UUID'ler) kullanmaktır.

## Çocuk Modunu Etkinleştirme \{#enabling-kids-mode\}

### Adapty Kontrol Paneli'nde güncellemeler \{#updates-in-the-adapty-dashboard\}

Adapty Kontrol Paneli'nde IP adresi toplamanı devre dışı bırakmanız gerekir. Bunun için [App settings](https://app.adapty.io/settings/general) sayfasına gidin ve **Collect users' IP address** altındaki **Disable IP address collection** seçeneğine tıklayın.

### Mobil uygulama kodunuzdaki güncellemeler \{#updates-in-your-mobile-app-code\}

Politikalara uymak için Adapty SDK'sını etkinleştirirken kullanıcının IDFA (iOS), GAID/AAID (Android) ve IP adresi toplanmasını devre dışı bırakın:

```typescript showLineNumbers title="App.tsx"

adapty.activate('YOUR_PUBLIC_SDK_KEY', {
  // Disable IP address collection
  ipAddressCollectionDisabled: true,

  // Disable IDFA collection on iOS
  ios: {
    idfaCollectionDisabled: true,
  },

  // Disable Google Advertising ID collection on Android
  android: {
    adIdCollectionDisabled: true,
  },
});
```

### iOS Projenizde Yapılacak Güncellemeler \{#updates-in-your-ios-project\}

App Store Çocuklar Kategorisi (veya COPPA uyumluluğu) için, yerel iOS SDK'sının `KidsMode` Swift package trait'i ile derlenmesi gerekir; bu seçenek IDFA, AdSupport ve AppTrackingTransparency kodlarını derleme dışında bırakır. Bu adım **Xcode 26** veya daha yeni bir sürüm gerektirir.

Swift Package Manager, paket trait'lerini hiçbir entegrasyon yöntemiyle iletemiyor; bu nedenle Adapty React Native SDK, trait'i sizin yerinize uygulayan bir araç sunar. iOS projenizin nasıl kurulduğuna göre uygun olanı seçin; ayrıntılar için [Adapty SDK'yı Yükleyin](sdk-installation-react-native-pure#install-adapty-sdk) bölümüne bakın.

<Tabs groupId="ios-package-manager" queryString>

<TabItem value="cocoapods" label="CocoaPods" default>

SDK, bir Podfile yardımcısıyla birlikte gelir. `ios/Podfile` dosyasında yardımcıyı dahil edin ve `react_native_post_install`'dan **sonra** çağırın:

```ruby showLineNumbers title="ios/Podfile"
require Pod::Executable.execute_command('node', ['-p',
  'require.resolve(
    "react-native-adapty/ios/adapty_kids_mode.rb",
    {paths: [process.argv[1]]},
  )', __dir__]).strip

# ...

post_install do |installer|
  react_native_post_install(
    installer,
    config[:reactNativePath],
    :mac_catalyst_enabled => false
  )

  adapty_enable_kids_mode(installer)
end
```

Ardından `pod install` komutunu çalıştırın:

```sh showLineNumbers title="Shell"
cd ios && pod install
```

`post_install` içindeki yardımcı çağrısını kalıcı olarak bırakın — React Native, her `pod install` çalıştırıldığında Swift paket referanslarını yeniden oluşturur ve yardımcı, özelliği her seferinde yeniden uygular.

</TabItem>

<TabItem value="spm" label="Swift Package Manager (experimental)">

SDK, `adapty-spm-kids-mode` komutunu içerir. Bunu uygulamanızın `package.json` dosyasında bir postinstall hook olarak çalıştırın:

```json showLineNumbers title="package.json"
{
  "scripts": {
    "postinstall": "adapty-spm-kids-mode enable"
  }
}
```

Ardından hook'u ilk kez çalıştırmak için bağımlılıklarınızı yeniden yükleyin:

```sh showLineNumbers title="Shell"
npm install

# or using yarn
yarn install
```

Bu hook kalıcı olarak `package.json` dosyasına ait. React Native'in Swift Package Manager otomatik bağlantısı, paket özelliklerini tanımaz ve her senkronizasyonda toplayıcı paketi yeniden oluşturur; bu yüzden komut, özelliği `node_modules` içindeki SDK'nın kendi manifest'inde etkinleştirir — ve her kurulum bunu değiştirir.

Kids Mode'u etkinleştirdikten veya devre dışı bıraktıktan sonra, bir sonraki iOS derlemesinden önce derleme klasörünü temizleyin (Xcode'da **Product → Clean Build Folder**).

:::note
`adapty-spm-kids-mode enable` komutu, Swift Package Manager entegrasyonunu doğrulayamazsa veya CocoaPods kullanan bir uygulama tespit ederse — React Native'in `Package.swift` okumadığı ve dolayısıyla bu özelliğin etkisiz kaldığı durumlarda — kurulumu başarısız saymadan bir uyarı yazdırır. iOS projeniz kurulumu yaptığınız dizinin dışındaysa `--app-root=path/to/app` seçeneğini kullanın.
:::

Kids Mode'u kapatmak için hook'u `adapty-spm-kids-mode disable` olarak değiştirin.

</TabItem>

</Tabs>

Kids Mode'un etkin olduğunu doğrulamak için `adapty.activate(...)` log satırında `kids_mode_enabled: true` ifadesinin görüntülendiğini kontrol edin.

### Android manifest'inizdeki güncellemeler \{#updates-in-your-android-manifest\}

:::note
Uygulamanız **yalnızca** çocuklara yönelikse ve Android 13 (API 33) veya üzeri sürümleri hedefliyorsa, Google Play `AD_ID` iznini talep etmemenizi gerektirir. Uygulamanızdaki başka bir SDK (analitik, attribution veya reklam), manifest birleştirme yoluyla bu izni ekleyebilir. `adIdCollectionDisabled` ayarı, Adapty'nin kimliği toplamasını durdurur; ancak başka bir SDK'nın tanımladığı bir izni kaldırmaz.
:::

İzni kaldırmak için `android/app/src/main/AndroidManifest.xml` dosyasındaki `<manifest>` öğesinin içine aşağıdakini ekleyin. `<manifest>` öğesi `xmlns:tools="http://schemas.android.com/tools"` bildirimini içermelidir.

```xml showLineNumbers title="AndroidManifest.xml"
<uses-permission
    android:name="com.google.android.gms.permission.AD_ID"
    tools:node="remove" />
```
