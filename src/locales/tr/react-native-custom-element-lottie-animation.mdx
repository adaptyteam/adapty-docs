## Başlamadan önce \{#before-you-start\}

- Adapty React Native SDK 4.4 veya sonraki bir sürüme güncelleyin. Daha eski SDK sürümleri, her özel öğe için [yedek içeriği](flow-custom-elements#set-fallback-content) gösterir.
- Uygulamanızı flow'ları [getirmek](react-native-get-pb-paywalls) ve [görüntülemek](react-native-present-paywalls) için yapılandırın.
- Uygulamanızın yerel kodunu özel öğeler için [React Native kılavuzundaki](react-native-flow-custom-elements#before-you-start) gibi yapılandırın.
- iOS'ta, `https://github.com/airbnb/lottie-spm.git` adresinden Swift Package Manager ile Xcode'da uygulama hedefinize Lottie ekleyin. Uygulamanız `lottie-react-native` kullanıyorsa bu adımı atlayın: o paket Lottie'yi zaten uygulamanıza ekler.
- Android'de, uygulama modülünüzde [Jetpack Compose'u yapılandırın](react-native-flow-custom-elements#set-up-jetpack-compose). Bu tarifte animasyon görünümü bir composable'dır. `androidx.compose.foundation:foundation` adresinden Gradle ile uygulamanıza Compose Foundation ekleyin, sürüm belirtmeden. `io.adapty:android-ui`'nin Compose BOM'u sürümü ayarlar. `com.airbnb.android:lottie-compose` adresinden Jetpack Compose için Lottie ekleyin.

## 2. Animasyon dosyasını uygulamanıza ekleyin \{#2-add-the-animation-file-to-your-app\}

Yerel kodunuz, animasyon dosyasını JavaScript kodunuzun asset'lerinden değil, iOS ve Android projelerinizden okur:

- **iOS**: Dosyayı Xcode'da uygulama hedefinize ekleyin.
- **Android**: Dosyayı `android/app/src/main/assets` dizinine, yani Android uygulama modülünüzün `assets` klasörüne koyun. Dosyayı bir alt klasöre değil, bu klasörün kök dizinine yerleştirin.

`.json` uzantısı olmadan dosya adı, `streak_ring` için `streak_ring.json` gibi özel öğenin kimliğiyle eşleşmelidir.

## 3. Animasyon görünümünü oluşturun \{#create-the-animation-view\}

Streak için bir model ve animasyonu oynatacak bir görünüm oluşturun. Uygulamanız streak değiştiğinde modeli günceller. Görünüm modeli okur, böylece ekran açıldığında halka mevcut streaki gösterir:

<Tabs groupId="platform" queryString>
<TabItem value="ios" label="iOS (Swift)" default>

```swift showLineNumbers title="Swift"

// The streak that your app keeps up to date
@MainActor
final class StreakStore: ObservableObject {
    @Published var currentStreak = 0 // days in a row
}

struct StreakRingView: View {
    let animation: LottieAnimation
    @ObservedObject var streakStore: StreakStore

    // 7 days fill the ring: from 0 for an empty ring to 1 for a full one
    private var progress: AnimationProgressTime {
        min(AnimationProgressTime(streakStore.currentStreak) / 7, 1)
    }

    var body: some View {
        LottieView(animation: animation)
            .resizable()
            .playing(.fromProgress(0, toProgress: progress, loopMode: .playOnce))
    }
}
```

`.playing(.fromProgress(0, toProgress: progress, loopMode: .playOnce))` halkayı bir kez, boştan `progress` değerine kadar doldurur.

</TabItem>
<TabItem value="android" label="Android (Kotlin)">

```kotlin showLineNumbers title="Kotlin"

// the streak that your app keeps up to date
class StreakStore {
    val currentStreak = MutableStateFlow(0) // days in a row
}

@Composable
fun StreakRing(animationFile: String, streakStore: StreakStore) {
    val composition by rememberLottieComposition(LottieCompositionSpec.Asset(animationFile))
    val streak by streakStore.currentStreak.collectAsState()

    // 7 days fill the ring: from 0 for an empty ring to 1 for a full one
    val progress = minOf(streak / 7f, 1f)

    LottieAnimation(
        composition = composition,
        modifier = Modifier.fillMaxSize(), // scale the animation to fit the custom element
        clipSpec = LottieClipSpec.Progress(0f, progress),
    )
}
```

`clipSpec = LottieClipSpec.Progress(0f, progress)` halkayı baştan `progress` değerine kadar doldurur.

## 4. Animasyonu özel elemente bağla \{#match-the-animation-to-the-custom-element\}

[Uygulama genelindeki resolver](react-native-flow-custom-elements#pass-the-resolver-to-the-sdk)'ınıza streak modeli için bir özellik ekleyin. Ardından `lottie_animation` Type ve `streak_ring` ID'si için animasyon görünümünü döndürün. Vurgulanan satırlar, eklenecek veya değiştirilecek kısımları gösterir. Uygulamanızda henüz uygulama genelinde bir [resolver](react-native-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views) yoksa kodun tamamını kopyalayabilirsiniz:

<Tabs groupId="platform" queryString>
<TabItem value="ios" label="iOS (Swift)" default>

```swift showLineNumbers title="Swift" {6,14-18}

struct CustomElementsResolver: AdaptyUICustomElementsResolver {
    let streakStore: StreakStore

    func view(
        forType type: String,
        id: String,
        context: AdaptyUICustomElementContext
    ) -> AnyView? {
        switch type {
        case "lottie_animation" where id == "streak_ring":
            guard let animation = LottieAnimation.named(id) else {
                return nil // no animation file: show the fallback
            }
            return AnyView(StreakRingView(animation: animation, streakStore: streakStore))
        // the other cases of your resolver
        default:
            return nil
        }
    }
}
```

`streak_ring` case'ini diğer `lottie_animation` case'lerinden önce yerleştirin; çünkü Swift yalnızca eşleşen ilk case'i çalıştırır. Uygulama paketinde söz konusu ID için dosya yoksa, çözümleyici `nil` döndürür ve kullanıcılar yedek içeriği görür.

</TabItem>
<TabItem value="android" label="Android (Kotlin)">

```kotlin showLineNumbers title="Kotlin" {8,22-28}

class CustomElementsResolver(
    context: Context,
    private val streakStore: StreakStore,
) : AdaptyCustomElementsResolver {
    // the animation files in the assets folder, listed once
    private val animationFiles: Set<String> = try {
        context.assets.list("").orEmpty().toSet()
    } catch (e: IOException) {
        emptySet() // no list of files: every Lottie element shows the fallback
    }

    override fun resolve(type: String, id: String): AdaptyCustomElementContent? =
        when (type) {
            "lottie_animation" -> {
                // the ID names the animation file, such as streak_ring.json
                val file = "$id.json"
                when {
                    file !in animationFiles -> null // no file for this ID: show the fallback
                    id == "streak_ring" ->
                        AdaptyCustomElementContent.compose { StreakRing(file, streakStore) }
                    // the other animations of your resolver
                    else -> null
                }
            }
            // the other Types of your resolver
            else -> null
        }
}
```

`assets` klasöründe ilgili ID için dosya yoksa, resolver `null` döndürür ve kullanıcılar yedek içeriği görür. Resolver'ınız zaten [her animasyon dosyası için bir view döndürüyorsa](react-native-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views), ID `streak_ring` olmadığında `null` yerine o view'ı döndürün. Bu sayede kullanıcılar diğer `lottie_animation` özel öğelerinizin animasyonlarını görmeye devam eder.

## 5. JavaScript kodunuzdan streak'i gönderin \{#5-send-the-streak-from-your-javascript-code\}

JavaScript kodunuz streak'i tutar ve native görünümler bunu streak modelinden okur. Modeli güncellemek için streak'i [Turbo Native Module](https://reactnative.dev/docs/turbo-native-modules-introduction) aracılığıyla native kodunuza gönderin. Modülün bir JavaScript spec'i ve her platform için bir implementasyonu vardır.

Projenizin kök dizinindeki bir `specs` klasöründe modülün spec'ini oluşturun:

```typescript showLineNumbers title="specs/NativeStreakStore.ts"

export interface Spec extends TurboModule {
  setStreak(days: number): void;
}

export default TurboModuleRegistry.getEnforcing<Spec>('NativeStreakStore');
```

To generate the native code of the spec, add `codegenConfig` to `package.json`. `com.example.app` kısmını `package.json` dosyasında ve modülün Kotlin implementasyonunda Android uygulamanızın paket adıyla değiştirin. `package.json` dosyasında `codegenConfig` zaten varsa, yalnızca `modulesProvider` nesnesine `NativeStreakStore` ekleyin:

```json showLineNumbers title="package.json"
"codegenConfig": {
  "name": "AppSpecs",
  "type": "modules",
  "jsSrcsDir": "specs",
  "android": {
    "javaPackageName": "com.example.app.specs"
  },
  "ios": {
    "modulesProvider": {
      "NativeStreakStore": "RCTNativeStreakStore"
    }
  }
}
```

Her platform için modülü uygulayın:

<Tabs groupId="platform" queryString>
<TabItem value="ios" label="iOS (Swift)" default>

Xcode'da uygulama hedefinizdeki bir Objective-C++ modülü oluşturun. Bu modül, streak verisini `NotificationCenter` aracılığıyla Swift kodunuza gönderir:

```objectivec showLineNumbers title="RCTNativeStreakStore.h"
#import <AppSpecs/AppSpecs.h>

@interface RCTNativeStreakStore : NSObject <NativeStreakStoreSpec>
@end
```

```objectivec showLineNumbers title="RCTNativeStreakStore.mm"
#import "RCTNativeStreakStore.h"

@implementation RCTNativeStreakStore

+ (NSString *)moduleName {
  return @"NativeStreakStore";
}

- (std::shared_ptr<facebook::react::TurboModule>)getTurboModule:
    (const facebook::react::ObjCTurboModule::InitParams &)params {
  return std::make_shared<facebook::react::NativeStreakStoreSpecJSI>(params);
}

- (void)setStreak:(double)days {
  // the AppDelegate updates the streak model when it receives this notification
  [[NSNotificationCenter defaultCenter] postNotificationName:@"StreakDidChange"
                                                      object:nil
                                                    userInfo:@{@"days": @((NSInteger)days)}];
}

@end
```

`AppDelegate` sınıfınızda `NotificationCenter`'ı gözlemleyerek her yeni streak ile streak modelini güncelleyin. `application(_:didFinishLaunchingWithOptions:)` metodunda, `AdaptyUI.setCustomElementsResolver` çağrısından sonra gözlemciyi ekleyin:

```swift showLineNumbers title="ios/YourApp/AppDelegate.swift"
// the streak that your JavaScript code sends through the native module
NotificationCenter.default.addObserver(
  forName: Notification.Name("StreakDidChange"),
  object: nil,
  queue: .main
) { [streakStore] notification in
  guard let days = notification.userInfo?["days"] as? Int else { return }
  MainActor.assumeIsolated { streakStore.currentStreak = days }
}
```

Spesifikasyonun native kodunu üretmek için `ios` klasöründe `pod install` komutunu çalıştırın.

</TabItem>
<TabItem value="android" label="Android (Kotlin)">

Create the module, and a package that registers it with React Native:

```kotlin showLineNumbers title="NativeStreakStoreModule.kt"
package com.example.app


class NativeStreakStoreModule(reactContext: ReactApplicationContext) :
    NativeStreakStoreSpec(reactContext) {

    override fun getName() = NAME

    override fun setStreak(days: Double) {
        val app = reactApplicationContext.applicationContext as MainApplication
        app.streakStore.currentStreak.value = days.toInt()
    }

    companion object {
        const val NAME = "NativeStreakStore"
    }
}
```

```kotlin showLineNumbers title="NativeStreakStorePackage.kt"

class NativeStreakStorePackage : BaseReactPackage() {
    override fun getModule(name: String, reactContext: ReactApplicationContext): NativeModule? =
        if (name == NativeStreakStoreModule.NAME) NativeStreakStoreModule(reactContext) else null

    override fun getReactModuleInfoProvider() = ReactModuleInfoProvider {
        mapOf(
            NativeStreakStoreModule.NAME to ReactModuleInfo(
                name = NativeStreakStoreModule.NAME,
                className = NativeStreakStoreModule.NAME,
                canOverrideExistingModule = false,
                needsEagerInit = false,
                isCxxModule = false,
                isTurboModule = true,
            )
        )
    }
}
```

`MainApplication.kt` dosyasında, `NativeStreakStorePackage`'ı paket listesine ekleyin:

```kotlin showLineNumbers title="MainApplication.kt" {2}
PackageList(this).packages.apply {
  add(NativeStreakStorePackage())
}
```
