[Özel etiket](flow-custom-tags), uygulamanızdan gelen bir değere sahip özel bir değişkendir. Bir değişkenin ayarlarında **Value comes from outside the app** seçeneğini belirledikten sonra uygulamanız bu değeri Adapty SDK aracılığıyla ayarlayabilir. Örneğin, bir metin öğesi "Coins:" ve bir özel etiket içeriyorsa, uygulamanız bu etiket için "120" değerini aktardığında kullanıcılar "Coins: 120" şeklinde görür.

## Özel etiket değerlerini aktarma \{#pass-custom-tag-values\}

`getFlowConfiguration` metodunun `tagResolver` parametresine, uygulamanızın değerlerini `[String: String]` sözlüğü olarak aktarın:

- Her anahtar, `user.streak` gibi özel bir etiketin tam adıdır.
- Her değer, kullanıcıların etiket yerine gördüğü metindir.
- Her değer, "1250.0" değil "1,250" gibi okunabilir bir formatta olmalıdır. Adapty bu değerleri biçimlendirmez veya çevirmez.

```swift showLineNumbers title="Swift"
let customTags = [
    "username": "DragonSlayer42",
    "coins": "1,250",
]

do {
    let flowConfiguration = try await AdaptyUI.getFlowConfiguration(
        forFlow: flow,
        tagResolver: customTags
    )
    // present the flow
} catch {
    // handle the error
}
```

SwiftUI [`.flow` modifier ve `AdaptyFlowView`](ios-present-paywalls#present-flows-and-paywalls-in-swiftui) ile UIKit [flow controller](ios-present-paywalls#present-flows-and-paywalls-in-uikit), özel etiket değerleri için herhangi bir parametre almaz. Bu bileşenler, verdiğiniz flow yapılandırmasındaki değerleri gösterir.

### BMI'yi paywall'a aktarın \{#pass-the-bmi-to-the-paywall\}

Onboarding flow'unun `flow_user_input` etkinliklerinden ağırlık ve boy bilgilerini toplayın; bunun nasıl yapıldığını [Flow'lardan veri işleme](ios-flow-input) bölümünde bulabilirsiniz. Kullanıcının son ekrana ulaştığını anlamak için `is_last_screen` değeri `true` olan bir `flow_screen_showed` etkinliğini izleyin; bkz. [Flow ekran görüntülemelerini takip etme](ios-flow-screen-views). Kullanıcı o ekranın ardından onboarding flow'unu kapattığında BMI'yi hesaplayın. Ardından paywall'ın flow yapılandırmasını çekin ve `bmi` özel etiketi için BMI değerini aktarın.

Aşağıdaki kod UIKit içindir. `AdaptyFlowControllerDelegate` metodlarını tek bir view controller üzerinde uygular; bu view controller, hem onboarding flow'unun controller'ının hem de paywall controller'ının delegate'idir. View controller aynı zamanda delegate'in satın alma ve geri yükleme metodlarını da uygulamalıdır; bu örnek onları dışarıda bırakmıştır. Bunları görmek için [UIKit'te flow ve paywall sunma](ios-present-paywalls#present-flows-and-paywalls-in-uikit) sayfasına gidin.

```swift showLineNumbers title="Swift"
private var bodyAnswers: [String: String] = [:]
private var reachedLastScreen = false

func flowController(
    _ controller: AdaptyFlowController,
    didReceiveAnalyticEvent name: String,
    params: [String: any Sendable]
) {
    if name == "flow_screen_showed", params["is_last_screen"] as? Bool == true {
        reachedLastScreen = true
        return
    }
    guard name == "flow_user_input",
          let elementId = params["element_id"] as? String,
          let value = params["value"] as? String
    else { return }

    bodyAnswers[elementId] = value
}

func flowControllerDidDisappear(_ controller: AdaptyFlowController) {
    // This delegate receives events from both flows. Reset `bodyAnswers` and
    // `reachedLastScreen` whenever a flow disappears, so that the paywall
    // doesn't open again when the user closes it.
    let answers = bodyAnswers
    let finished = reachedLastScreen
    bodyAnswers.removeAll()
    reachedLastScreen = false

    // Number inputs send their values as strings.
    guard finished,
          let weight = answers["weight"].flatMap({ Double($0) }),
          let height = answers["height"].flatMap({ Double($0) }),
          height > 0
    else { return }

    let heightInMeters = height / 100
    let bmi = weight / (heightInMeters * heightInMeters)

    Task {
        await showBMIPaywall(bmi: bmi.formatted(.number.precision(.fractionLength(1))))
    }
}

func showBMIPaywall(bmi: String) async {
    do {
        let flow = try await Adapty.getFlow(placementId: "bmi_paywall")
        let flowConfiguration = try await AdaptyUI.getFlowConfiguration(
            forFlow: flow,
            tagResolver: ["bmi": bmi]
        )
        let flowController = try AdaptyUI.flowController(
            with: flowConfiguration,
            delegate: self
        )
        present(flowController, animated: true)
    } catch {
        // handle the error
    }
}
```

`formatted`, kullanıcının yerel ayarına göre ondalık ayırıcı kullanır: İngilizce'de "22.7", Almanca'da "22,7".

SwiftUI'da, delegate metotları yerine onboarding flow'unun `.flow` modifier'ının closure'larını kullanın:

- `didReceiveAnalyticEvent`: Ağırlığı ve boyu toplayın ve son ekranın `flow_screen_showed` eventini izleyin.
- `didDisappear`: Kullanıcı son ekrana ulaştıysa BMI'yı hesaplayın. Ardından paywall'ın flow yapılandırmasını çekin ve `bmi` custom tag'i için BMI değerini geçirin. Bu yapılandırmayı ikinci bir `.flow` modifier ile gösterin.

### BMI'ı kullanıcı profiline kaydedin \{#save-the-bmi-to-the-users-profile\}

Kullanıcılara BMI'larına göre farklı flow'lar göstermek için bunu profillerinin bir [özel özelliği](setting-user-attributes#custom-user-attributes) olarak kaydedin. Adapty Kontrol Paneli'nde `bmi` anahtarıyla bir **Number** [özel özelliği oluşturun](segments#custom-attributes). Ardından her flow'u bu özellikten oluşturulan bir [kitle](audience) için gösterin.

`updateProfile` metodunu `flowControllerDidDisappear` içinde, `bmi`'ı hesaplayan satırın hemen ardından çağırın. Bir segment'in BMI'ı bir eşik değeriyle karşılaştırabilmesi için biçimlendirilmiş string yerine `Double` değeri iletin:

```swift showLineNumbers title="Swift"
do {
    let params = try AdaptyProfileParameters.Builder()
        .with(customAttribute: bmi, forKey: "bmi")
        .build()
    try await Adapty.updateProfile(params: params)
} catch {
    // handle the error
}
```
