SDK tarafından döndürülen her hata bir `AdaptyError` örneğidir. İşte bir örnek:

:::tip
**Hata ayıklamadan önce ayrıntılı logları etkinleştirin.** Çoğu `AdaptyError`, altta yatan bir StoreKit, Play Billing, ağ veya backend hatasını sarmalayan bir yapıya sahiptir. Ayrıntılı loglar açıkken (`adapty.setLogLevel({ logLevel: 'verbose' })` — bkz. [Loglama](sdk-installation-capacitor#logging)), sarmalanan hata konsola yazdırılır ve bu genellikle gerçek nedeni gösterir. `AdaptyError` üzerindeki `detail` özelliği log düzeyinden bağımsız olarak doldurulur — ayrıntılı loglar onu yalnızca konsolda görünür kılar.
:::

```typescript showLineNumbers

try {
  const result = await adapty.makePurchase({ product });
  
  // Handle purchase result
  if (result.type === 'success') {
    console.log('Purchase successful:', result.profile);
  } else if (result.type === 'user_cancelled') {
    console.log('User cancelled the purchase');
  } else if (result.type === 'pending') {
    console.log('Purchase is pending');
  }
} catch (error) {
  if (error instanceof AdaptyError) {
    console.error('Adapty error:', error.adaptyCode, error.localizedDescription);
    
    // Handle specific error codes
    switch (error.adaptyCode) {
      case ErrorCodeName.cantMakePayments:
        console.log('In-app purchases are not allowed on this device');
        break;
      case ErrorCodeName.notActivated:
        console.log('Adapty SDK is not activated');
        break;
      case ErrorCodeName.productPurchaseFailed:
        console.log('Purchase failed:', error.detail);
        break;
      default:
        console.log('Other error occurred:', error.detail);
    }
  } else {
    console.error('Non-Adapty error:', error);
  }
}
```

## Hata Özellikleri \{#error-properties\}

`AdaptyError` sınıfı aşağıdaki özellikleri sağlar:

| Özellik | Tür | Açıklama |
|----------|------|-------------|
| `adaptyCode` | `number` | Sayısal hata kodu (örn. `cantMakePayments` için `1003`) |
| `codeName` | `ErrorCodeName \| undefined` | Hata kodunun adı (örn. `'cantMakePayments'`) ya da SDK sürümünüzde bilinmeyen bir kod için `undefined`. SDK 4.3.0 sürümünden itibaren kullanılabilir |
| `localizedDescription` | `string` | Kullanıcıya yönelik hata mesajı |
| `detail` | `string \| undefined` | Ek hata ayrıntıları (isteğe bağlı) |
| `message` | `string` | Kod ve açıklamayı içeren tam hata mesajı |

## Hata Kodları \{#error-codes\}

SDK, hata kodlarıyla çalışmak için sabitler ve yardımcı araçlar sunar:

### ErrorCodeName Sabiti \{#errorcodename-constant\}

Dize tanımlayıcılarını sayısal kodlarla eşleştirir:

```typescript

ErrorCodeName.cantMakePayments // 1003
ErrorCodeName.notActivated // 2002
ErrorCodeName.networkFailed // 2005
```

### ErrorCode Sabiti \{#errorcode-constant\}

Sayısal kodları dize tanımlayıcılarıyla eşleştirir:

```typescript

ErrorCode[1003] // 'cantMakePayments'
ErrorCode[2002] // 'notActivated'
ErrorCode[2005] // 'networkFailed'
```

### Yardımcı Fonksiyonlar

```typescript

// Get numeric code from string name:
getErrorCode('cantMakePayments') // 1003

// Get string name from numeric code:
getErrorPrompt(1003) // 'cantMakePayments'
```

Native SDK'lar, kurulu Capacitor SDK'nızdan daha yeni kodlar döndürebilir ve `error.adaptyCode` bunları olduğu gibi iletir. SDK 4.3.0 itibarıyla TypeScript türü bu kodları da kabul eder. Bilinen bir kodu yeni bir koddan ayırt etmek için `isKnownErrorCode` ve `getErrorCodeName` kullanın:

```typescript

isKnownErrorCode(1003) // true
getErrorCodeName(1003) // 'cantMakePayments'
getErrorCodeName(9999) // undefined: a code unknown to this SDK version
getErrorPrompt(9999)   // 'Unknown code: 9999'
```

4.3 özellikleri için yeni kodlar:

| Ad | Kod | Açıklama |
|------|------|-------------|
| `billingPlanUnavailable` | 1060 | Yalnızca iOS. Ürün, bu cihazda veya bu mağazada istenen faturalama planını sunmuyor. [12 aylık taahhüt](app-store-12-month-commitment) planı, iOS 26.4 veya sonrasını ve Xcode 26.5 veya sonrasıyla derlenmiş bir uygulama gerektirir. |
| `operationInProgress` | 3201 | Yalnızca iOS. Önceki bir çağrı hâlâ [mağaza mesajlarını](capacitor-store-messages) gösterirken `showStoreMessages` çağrıldığında döner. Tamamlanmasını bekleyin, ardından tekrar deneyin. |
| `resolverFailure` | 3202 | Yalnızca iOS. Ön planda etkin bir pencere sahnesi yokken `showStoreMessages` çağrıldığında döner. Uygulama ön plandayken metodu tekrar çağırın. |

SDK 4.3.0 ayrıca önceki sürümlerin bilinmeyen olarak raporladığı kodları da adlandırır: 2, 1020, 1030, 1050, 3020 ve 4104–4107. Örneğin, `getErrorPrompt(1050)` artık `'Unknown code: 1050'` yerine `'paymentPendingError'` döndürür.

### Hata Kodlarını Karşılaştırma \{#comparing-error-codes\}

**Önemli:** `error.adaptyCode` bir **sayı** olduğundan, doğrudan sayısal kodlarla karşılaştırın:

```typescript
// Option 1: Use ErrorCodeName constant (recommended) ✅
if (error.adaptyCode === ErrorCodeName.cantMakePayments) {
  console.log('Cannot make payments');
}

// Option 2: Compare with numeric literal ✅
if (error.adaptyCode === 1003) {
  console.log('Cannot make payments');
}

// NOT like this ❌ - compares number to string and will never match
if (error.adaptyCode === ErrorCode[1003]) {
}
```

## Global Hata Yöneticisi \{#global-error-handler\}

Tüm Adapty hatalarını yakalamak için global bir hata yöneticisi kurabilirsiniz:

```typescript showLineNumbers

// Set up global error handler
AdaptyError.onError = (error: AdaptyError) => {
  console.error('Global Adapty error:', {
    code: error.adaptyCode,
    message: error.localizedDescription,
    detail: error.detail
  });
  
  // Handle specific error types globally
  if (error.adaptyCode === ErrorCodeName.notActivated) {
    // SDK not activated - maybe retry activation
    console.log('SDK not activated, attempting to reactivate...');
  }
};
```

### Ağ Hatalarını Yönetme \{#handle-network-errors\}

```typescript showLineNumbers

async function fetchFlow(placementId: string) {
  try {
    const flow = await adapty.getFlow({ placementId });
    return flow;
  } catch (error) {
    if (error instanceof AdaptyError) {
      switch (error.adaptyCode) {
        case ErrorCodeName.networkFailed:
          console.log('Network error, retrying...');
          // Implement retry logic
          break;
        case ErrorCodeName.serverError:
          console.log('Server error:', error.detail);
          break;
        case ErrorCodeName.notActivated:
          console.log('SDK not activated');
          break;
        default:
          console.error('Paywall fetch error:', error.localizedDescription);
      }
    }
    throw error;
  }
}
```
