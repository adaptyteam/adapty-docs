[Özel etiket](flow-custom-tags), uygulamanızdan gelen bir değere sahip özel bir değişkendir. Bir değişkenin ayarlarında **Value comes from outside the app** seçeneğini belirledikten sonra, uygulamanız bu değeri Adapty SDK aracılığıyla ayarlayabilir. Örneğin, bir metin öğesi "Coins:" ifadesini ve bir özel etiket içeriyorsa, uygulamanız etiket için "120" değerini aktardığında kullanıcılar "Coins: 120" görür.

## Özel etiket değerlerini iletme \{#pass-custom-tag-values\}

Uygulamanızın değerlerini, bir `AdaptyUICreateFlowViewParameters` nesnesinin `SetCustomTags` metoduna, `Dictionary<string, string>` gibi string'ten string'e bir sözlük olarak iletin ve o nesneyle birlikte `AdaptyUI.CreateFlowView` metodunu çağırın:

- Her anahtar, `user.streak` gibi özel etiketin tam adıdır.
- Her değer, kullanıcıların etiket yerine gördüğü string'tir.
- Her değer, "1250.0" değil "1,250" gibi okunabilir olmalıdır. Adapty bu değeri biçimlendirmez veya çevirmez.

SDK, değerleri yalnızca view oluşturulduğunda bir kez okur; bu nedenle flow açıkken değişmezler.

```csharp showLineNumbers title="Unity"
var parameters = new AdaptyUICreateFlowViewParameters()
    .SetCustomTags(new Dictionary<string, string> {
        { "username", "DragonSlayer42" },
        { "coins", "1,250" }
    });

AdaptyUI.CreateFlowView(flow, parameters, (view, error) => {
    if (error != null) {
        // handle the error
        return;
    }

    // present the view
});
```

### BMI'yi paywall'a iletme \{#pass-the-bmi-to-the-paywall\}

Onboarding flow'unun `flow_user_input` event'lerinden kullanıcının ağırlık ve boyunu toplayın; bunun nasıl yapıldığını [Flow'lardan veri işleme](unity-flow-input) bölümünde bulabilirsiniz. Kullanıcının son ekrana ulaştığını anlamak için `is_last_screen` değeri `true` olarak ayarlanmış bir `flow_screen_showed` event'ini izleyin; bununla ilgili ayrıntılar [Flow ekran görüntülemelerini takip etme](unity-flow-screen-views) bölümündedir. Kullanıcı bu ekrandan sonra onboarding flow'unu kapattığında BMI'yi hesaplayın. Ardından paywall'ın view'ını oluşturun ve `bmi` özel etiketi için BMI değerini iletin.

`Adapty.SetFlowsEventsListener` ile kaydettiğiniz listener üzerinde aşağıdaki metodları uygulayın. `FlowViewDidDisappear` yalnızca uygulamanız onboarding flow'unu kapattıktan sonra tetiklenir; bu nedenle listener, [Flow ve paywall'ları kapatma](unity-handle-paywall-actions#close-flows-and-paywalls) bölümünde açıklandığı gibi **Close flow** eylemini de işlemelidir:

```csharp showLineNumbers title="Unity"
private readonly Dictionary<string, string> bodyAnswers = new Dictionary<string, string>();
private bool reachedLastScreen;

public void FlowViewDidReceiveAnalyticEvent(
    AdaptyUIFlowView view,
    string name,
    IReadOnlyDictionary<string, object> parameters
) {
    if (name == "flow_screen_showed") {
        if (parameters.TryGetValue("is_last_screen", out var lastScreen)
            && lastScreen is bool isLast && isLast) {
            reachedLastScreen = true;
        }
        return;
    }
    if (name != "flow_user_input") return;
    if (!parameters.TryGetValue("value", out var raw) || !(raw is string value)) return;

    if (!parameters.TryGetValue("element_id", out var idRaw) || !(idRaw is string elementId)) return;

    bodyAnswers[elementId] = value;
}

public void FlowViewDidDisappear(AdaptyUIFlowView view) {
    // The listener receives events from every flow. Reset `bodyAnswers` and
    // `reachedLastScreen` whenever a flow disappears, so that the paywall
    // doesn't open again when the user closes it.
    var answers = new Dictionary<string, string>(bodyAnswers);
    var finished = reachedLastScreen;
    bodyAnswers.Clear();
    reachedLastScreen = false;

    // Number inputs send their values as strings.
    if (!finished) return;
    if (!answers.TryGetValue("weight", out var weightText)
        || !double.TryParse(weightText, out var weight)) return;
    if (!answers.TryGetValue("height", out var heightText)
        || !double.TryParse(heightText, out var height)
        || height <= 0) return;

    var heightInMeters = height / 100;
    var bmi = weight / (heightInMeters * heightInMeters);
    ShowBmiPaywall(bmi.ToString("0.0"));
}

private void ShowBmiPaywall(string bmi) {
    Adapty.GetFlow("bmi_paywall", (flow, flowError) => {
        if (flowError != null) {
            // handle the error
            return;
        }

        var parameters = new AdaptyUICreateFlowViewParameters()
            .SetCustomTags(new Dictionary<string, string> { { "bmi", bmi } });

        AdaptyUI.CreateFlowView(flow, parameters, (view, viewError) => {
            if (viewError != null) {
                // handle the error
                return;
            }

            view.Present((presentError) => {
                if (presentError != null) {
                    // handle the error
                }
            });
        });
    });
}
```

`ToString("0.0")` geçerli kültürün ondalık ayracını kullanır: İngilizce'de "22.7", Almanca'da "22,7".

### BMI'yi kullanıcı profiline kaydetme \{#save-the-bmi-to-the-users-profile\}

Kullanıcılara BMI'lerine göre farklı flow'lar göstermek için bunu profillerinin [özel özelliği](unity-setting-user-attributes#custom-user-attributes) olarak kaydedin. Adapty Kontrol Paneli'nde `bmi` anahtarıyla bir **Number** [özel özelliği oluşturun](segments#custom-attributes). Ardından her flow'u bu özellikten oluşturulan bir [kitleye](audience) göre gösterin.

`FlowViewDidDisappear` içinde, `bmi`'yi hesaplayan satırın hemen ardından `Adapty.UpdateProfile` metodunu çağırın. Bir segmentin BMI'yi bir eşik değeriyle karşılaştırabilmesi için biçimlendirilmiş string'i değil, `double` değerini geçin:

```csharp showLineNumbers title="Unity"
var parameters = new AdaptyProfileParameters.Builder()
    .SetCustomDoubleAttribute("bmi", bmi)
    .Build();

Adapty.UpdateProfile(parameters, (error) => {
    if (error != null) {
        // handle the error
    }
});
```
