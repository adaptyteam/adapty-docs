Uygulama içi satın almaları etkinleştirmek için üç temel kavramı anlamanız gerekir:

- [**Ürünler**](product) – kullanıcıların satın alabileceği her şey (abonelikler, consumable'lar, süresiz erişim)
- [**Flow'lar ve paywalllar**](adapty-flow-builder) – ürünleri kullanıcılara sunan ekranlar; no-code Flow & Paywall Builder ile oluşturulur. SDK bunları `getFlow` aracılığıyla getirir. Kullanıcı arayüzünü kendi kodunuzla oluşturmayı tercih ediyorsanız bkz. [Özel paywall uygulama](android-quickstart-manual).
- [**Placement'lar**](placements) – uygulamanızda flow'ları ve paywallları nerede ve ne zaman göstereceğiniz (`main`, `onboarding`, `settings` gibi). Bunları kontrol panelinde placement'lara bağlarsınız, ardından kodunuzda placement ID'si ile talep edersiniz. Bu sayede A/B testleri yürütmek ve farklı kullanıcılara farklı içerikler göstermek kolaylaşır.

Adapty, uygulamanızda satın almaları etkinleştirmek için size üç yöntem sunar. Uygulama gereksinimlerinize bağlı olarak birini seçin:

| Uygulama | Karmaşıklık | Ne zaman kullanılır |
|---|---|---|
| Adapty Flow & Paywall Builder | ✅ Kolay | No-code builder'da [eksiksiz, satın almaya hazır bir flow veya paywall oluşturursunuz](quickstart-paywalls). Adapty bunu otomatik olarak render eder ve tüm karmaşık satın alma mantığını, makbuz doğrulamasını ve abonelik yönetimini arka planda halleder. |
| Özel paywalllar | 🟡 Orta | Paywall kullanıcı arayüzünü kendi uygulama kodunuzda siz uygularsınız, ancak ürün tekliflerinde esnekliği korumak için flow nesnesini yine de Adapty'den alırsınız. [Kılavuza](android-quickstart-manual) bakın. |
| Observer mode | 🔴 Zor | Kendi satın alma altyapınız zaten vardır ve onu kullanmaya devam etmek istersiniz. Observer mode'un Adapty'de bazı kısıtlamaları olduğunu unutmayın. [Makaleye](observer-vs-full-mode) bakın. |

:::important
**Aşağıdaki adımlar, Adapty Flow & Paywall Builder'da oluşturulan bir flow veya paywall'un nasıl uygulanacağını göstermektedir.**

Paywall arayüzünü kendiniz oluşturmayı tercih ediyorsanız, [Özel paywall'ları uygulama](android-quickstart-manual) bölümüne bakın.
:::

Adapty Flow & Paywall Builder'da oluşturulan bir flow veya paywall'u uygulamanızda görüntülemek için yalnızca şunları yapmanız gerekir:

1. **Flow veya paywallı alın**: Adapty'den alın.
2. **Görüntüleyin, satın almaları Adapty yönetsin**: View'ı uygulamanızda gösterin.
3. **Buton aksiyonlarını yönetin**: Kullanıcı etkileşimlerini uygulamanızın bu etkileşimlere verdiği yanıtlarla ilişkilendirin. Örneğin, kullanıcılar butonlara tıkladığında bağlantılar açın veya paywallı kapatın.

## Başlamadan önce \{#before-you-start\}

Başlamadan önce şu adımları tamamlayın:

1. Adapty Kontrol Paneli'nde [uygulamanızı Google Play'e bağlayın](initial-android).
2. Adapty'de [ürünlerinizi oluşturun](create-product).
3. [Bir flow veya paywall oluşturun](paywall-builder-templates) ve [buna ürünler ekleyin](paywall-product-block).
4. [Bir placement oluşturun ve flow ya da paywall'ınızı buna ekleyin](create-placement).
5. Uygulama kodunuzda [Adapty SDK'yı yükleyin ve etkinleştirin](sdk-installation-android). Bu kılavuzda Adapty Android SDK v4 API'leri kullanılmaktadır.

:::tip
Bu adımları tamamlamanın en hızlı yolu [hızlı başlangıç kılavuzunu](quickstart) takip etmek ya da [Developer CLI](developer-cli-quickstart) kullanarak flow'lar ve placement'lar oluşturmaktır.
:::

## 1. Flow veya paywall'ı alın \{#1-get-the-flow-or-paywall\}

Flow'larınız ve paywall'larınız, kontrol panelinde yapılandırılan placement'larla ilişkilidir. Placement'lar, farklı kitleler için farklı flow'lar veya paywall'lar çalıştırmanıza ya da [A/B testleri](ab-tests) yapmanıza olanak tanır.

Adapty Flow & Paywall Builder'da oluşturulan bir flow veya paywall'ı almak için şunları yapmanız gerekir:

1. `getFlow` metodunu kullanarak [placement](placements) ID'sine göre `flow` nesnesini alın ve bir görünüm yapılandırmasına sahip olup olmadığını kontrol edin.

2. Görünüm yapılandırmasını almak için `getFlowConfiguration` metodunu kullanın. Görünüm yapılandırması, onu görüntülemek için gereken UI öğelerini ve stilini içerir.

:::important
Görünüm yapılandırmasını almak için [flow veya paywall'ı yayınlayın](builder-save-publish). Yayınlanmamış düzenlemeleri olan bir flow veya paywall **Dirty** statüsüne sahip olur ve placement'ı son yayınlanan sürümü sunmaya devam eder.
:::

<Tabs groupId="current-os" queryString>

<TabItem value="kotlin" label="Kotlin" default>

```kotlin showLineNumbers
Adapty.getFlow("YOUR_PLACEMENT_ID") { result ->
    if (result is AdaptyResult.Success) {
        val flow = result.value
        
        if (!flow.hasViewConfiguration) {
            return@getFlow
        }
        
        AdaptyUI.getFlowConfiguration(flow) { configResult ->
            if (configResult is AdaptyResult.Success) {
                val flowConfiguration = configResult.value
            }
        }
    }
}
```
</TabItem>
<TabItem value="java" label="Java" default>

```java showLineNumbers

Adapty.getFlow("YOUR_PLACEMENT_ID", result -> {
    if (result instanceof AdaptyResult.Success) {
        AdaptyFlow flow = ((AdaptyResult.Success<AdaptyFlow>) result).getValue();

            return;

            if (configResult instanceof AdaptyResult.Success) {
                AdaptyUI.FlowConfiguration flowConfiguration =
                    ((AdaptyResult.Success<AdaptyUI.FlowConfiguration>) configResult).getValue();
                // yüklenen konfigürasyonu kullan
            }
        });
    }
});
```

## 2. Flow veya paywallı görüntüleyin \{#2-display-the-flow-or-paywall\}

Artık flow yapılandırmasına sahip olduğunuzda, flow'unuzu veya paywallınızı görüntülemek için yalnızca birkaç satır eklemeniz yeterlidir.

Görsel flow'u cihaz ekranında görüntüleyebilmek için önce yapılandırmanız gerekir. Bunu yapmak için `AdaptyUI.getFlowView()` metodunu çağırın ya da `AdaptyFlowView`'ı doğrudan oluşturun:

## 3. Buton eylemlerini yönetin \{#handle-button-actions\}

Kullanıcılar flow veya paywall'daki butonlara tıkladığında Android SDK; satın alma, geri yükleme, ekranı kapatma ve bağlantı açma işlemlerini otomatik olarak gerçekleştirir.

Ancak diğer butonların özel veya önceden tanımlanmış ID'leri vardır ve bu eylemlerin kodunuzda yönetilmesini gerektirir. Ya da varsayılan davranışlarını geçersiz kılmak isteyebilirsiniz.

Örneğin, aşağıda kapat butonunun varsayılan davranışı gösterilmektedir. Bunu koda eklemenize gerek yoktur, ancak gerektiğinde nasıl yapıldığını buradan görebilirsiniz.

:::tip
Buton [action'ları](android-handle-paywall-actions) ve [event'leri](android-handling-events) nasıl yöneteceğinizi anlatan kılavuzlarımızı okuyun.
:::

<Tabs groupId="current-os" queryString>

<TabItem value="kotlin" label="Kotlin" default>

```kotlin showLineNumbers title="Kotlin"
override fun onActionPerformed(action: AdaptyUI.Action, context: Context) {
    when (action) {
        AdaptyUI.Action.Close -> (context as? Activity)?.onBackPressed() // default behavior
    }
}
```
</TabItem>
<TabItem value="java" label="Java" default>

```java showLineNumbers
@Override
public void onActionPerformed(@NonNull AdaptyUI.Action action, @NonNull Context context) {
    if (action instanceof AdaptyUI.Action.Close) {
        if (context instanceof Activity) {
            ((Activity) context).onBackPressed();
        }
    }
}
```

## Tam örnek \{#full-example\}

Tüm bu adımları uygulamanızda nasıl bir araya getirebileceğiniz aşağıda gösterilmektedir.

<Tabs groupId="current-os" queryString>

<TabItem value="kotlin" label="Kotlin" default>

```kotlin showLineNumbers title="Kotlin"
class MainActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)

        Adapty.getFlow("YOUR_PLACEMENT_ID") { flowResult ->
            if (flowResult is AdaptyResult.Success) {
                val flow = flowResult.value

                if (!flow.hasViewConfiguration) {
                    // Use custom logic
                    return@getFlow
                }

                AdaptyUI.getFlowConfiguration(flow) { configResult ->
                    if (configResult is AdaptyResult.Success) {
                        val flowConfiguration = configResult.value

                        val flowView = AdaptyUI.getFlowView(
                            this,
                            flowConfiguration,
                            null, // products = null means auto-fetch
                            object : AdaptyFlowDefaultEventListener() {
                                override fun onActionPerformed(action: AdaptyUI.Action, context: Context) {
                                    when (action) {
                                        is AdaptyUI.Action.Close -> {
                                            (context as? Activity)?.onBackPressed()
                                        }
                                    }
                                }
                            }
                        )

                        setContentView(flowView)
                    }
                }
            }
        }
    }
}

```
</TabItem>
