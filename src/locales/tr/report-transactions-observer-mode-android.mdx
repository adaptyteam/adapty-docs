Observer mode'da Adapty SDK, mevcut satın alma sisteminiz üzerinden yapılan satın almaları kendi başına takip edemez. Bu nedenle uygulama mağazasındaki işlemleri manuel olarak bildirmeniz gerekir. Analytics hatalarını önlemek için uygulamanızı yayınlamadan **önce** bu adımı tamamlamanız kritik önem taşır.

Her işlemi Adapty'nin tanıyabilmesi için `reportTransaction` kullanarak açıkça bildirin.

:::warning

**İşlem raporlamayı atlama!**
`reportTransaction` çağrısı yapmazsanız, Adapty işlemi tanımaz, analitiklerde görünmez ve integrasyonlara gönderilmez.

:::

Adapty flow'ları ve paywalllerini kullanıyorsanız, işlem raporlarken `variationId` ekleyin. Bu, satın almayı tetikleyen flow veya paywall ile ilişkilendirerek doğru analitik sağlar.

<Tabs groupId="current-os" queryString>
<TabItem value="kotlin" label="Kotlin" default>

```kotlin showLineNumbers
val transactionInfo = TransactionInfo.fromPurchase(purchase)

Adapty.reportTransaction(transactionInfo, variationId) { result ->
    if (result is AdaptyResult.Success) {
        // success
    }
}
```

Parametreler:

| Parametre       | Zorunluluk | Açıklama                                                  |
| --------------- | ---------- | ------------------------------------------------------------ |
| transactionInfo | zorunlu | Satın alma işleminden alınan TransactionInfo; buradaki satın alma, billing library [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) sınıfının bir örneğidir. |
| variationId     | isteğe bağlı | Varyantın string tanımlayıcısı. `AdaptyPaywall` nesnesinin `variationId` özelliği kullanılarak alınabilir. |

</TabItem>
<TabItem value="java" label="Java" default>

```java showLineNumbers
TransactionInfo transactionInfo = TransactionInfo.fromPurchase(purchase);

Adapty.reportTransaction(transactionInfo, variationId, result -> {
    if (result instanceof AdaptyResult.Success) {
        // success
    }
});
```

Parametreler:

| Parametre       | Zorunluluk | Açıklama                                                  |
| --------------- | ---------- | ------------------------------------------------------------ |
| transactionInfo | zorunlu | Satın alma işleminden alınan TransactionInfo; burada satın alma, billing library [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) sınıfının bir örneğidir. |
| variationId     | isteğe bağlı | Varyantın string tanımlayıcısı. `AdaptyPaywall` nesnesinin `variationId` özelliğini kullanarak elde edebilirsiniz. |

</TabItem>

Observer modunda, Adapty SDK kendi başına mevcut satın alma sisteminiz üzerinden yapılan satın almaları takip edemez. Uygulama mağazanızdan işlemleri bildirmeniz veya geri yüklemeniz gerekir. Analytics'te hata oluşmaması için bunu uygulamanızı yayınlamadan **önce** yapılandırmanız çok önemlidir.

İşlemi Adapty'ye bildirmek için `restorePurchases` kullanın.

:::warning

**Satın alma işlemini geri yüklemeyi atlama!**
`restorePurchases` çağırmazsanız, Adapty işlemi tanımaz, bu işlem analitikte görünmez ve integrasyonlara gönderilmez.

:::

Adapty flow'ları ve paywalllarını kullanıyorsanız, doğru analitik için satın almayı gerçekleştiren flow veya paywall'a `setVariationId` metoduyla işleminizi bağlayın.

<Tabs groupId="current-os" queryString>
<TabItem value="kotlin" label="Kotlin" default>

```kotlin showLineNumbers
Adapty.restorePurchases { result ->
    if (result is AdaptyResult.Success) {
        // success
    }
}

Adapty.setVariationId(transactionId, variationId) { error ->
    if (error == null) {
        // success
    }
}
```

Parametreler:

| Parametre     | Zorunluluk | Açıklama                                                  |
| ------------- | ---------- | ---------------------------------------------------------- |
| transactionId | zorunlu    | Satın alma işleminin (`purchase.getOrderId`) dize tanımlayıcısı; burada satın alma, billing library'nin [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) sınıfının bir örneğidir. |
| variationId   | zorunlu    | Varyantın dize tanımlayıcısı. `AdaptyPaywall` nesnesinin `variationId` özelliği kullanılarak alınabilir. |

</TabItem>
<TabItem value="java" label="Java" default>

```java showLineNumbers
Adapty.restorePurchases(result -> {
    if (result instanceof AdaptyResult.Success) {
        // success
    }
});

Adapty.setVariationId(transactionId, variationId, error -> {
    if (error == null) {
        // success
    }
});
```

Parametreler:

| Parametre     | Zorunluluk | Açıklama                                                  |
| ------------- | -------- | ------------------------------------------------------------ |
| transactionId | zorunlu | Satın alma işleminin string tanımlayıcısı (`purchase.getOrderId`); burada satın alma, billing library [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) sınıfının bir örneğidir. |
| variationId   | zorunlu | Varyantın string tanımlayıcısı. Bunu `AdaptyPaywall` nesnesinin `variationId` özelliğini kullanarak alabilirsiniz. |

</TabItem>

**İşlemleri Raporlama**

Observer Mode'da Adapty'ye bir işlemi bildirmek için `restorePurchases` kullanın. Bu konu [Mobil Kodda Satın Almaları Geri Yükleme](android-restore-purchase) sayfasında açıklanmaktadır.

:::warning
**İşlem raporlamayı atlamayın!**
`restorePurchases` çağrısı yapmazsanız, Adapty işlemi tanımaz, işlem analizlerde görünmez ve entegrasyonlara gönderilmez.
::: 

**Flow'ları ve paywall'ları işlemlerle ilişkilendirme**

Adapty SDK, satın almaların kaynağını belirleyemez; çünkü bunları siz işliyorsunuz. Bu nedenle, Observer modunda flow'lar, paywall'lar ve/veya A/B testleri kullanmayı planlıyorsanız, uygulama mağazanızdan gelen işlemi mobil uygulama kodunuzda ilgili flow veya paywall ile ilişkilendirmeniz gerekir. Uygulamanızı yayına almadan önce bunu doğru şekilde yapmanız önemlidir; aksi takdirde analizlerde hatalara yol açar.

<Tabs groupId="current-os" queryString>
<TabItem value="kotlin" label="Kotlin" default>

```kotlin 
Adapty.setVariationId(transactionId, variationId) { error ->
    if (error == null) {
        // success
    }
}
```

İstek parametreleri:

| Parametre     | Zorunluluk | Açıklama                                                  |
| ------------- | ---------- | ------------------------------------------------------------ |
| transactionId | zorunlu | Dize tanımlayıcısı (satın almanın purchase.getOrderId değeri; burada purchase, billing library [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) sınıfının bir örneğidir). |
| variationId   | zorunlu | Varyantın dize tanımlayıcısı. Bunu `AdaptyPaywall` nesnesinin `variationId` özelliğini kullanarak alabilirsiniz. |

</TabItem>

```java 
Adapty.setVariationId(transactionId, variationId, error -> {

        // success
```

| ------------------------------------------------- | -------- | ------------------------------------------------------------ |
| transactionId | zorunlu | Satın alma işleminin string tanımlayıcısı (purchase.getOrderId), burada purchase, billing library [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) sınıfının bir örneğidir. |
| variationId | zorunlu | Varyantın string tanımlayıcısı. Bunu `AdaptyPaywall` nesnesinin `variationId` özelliğini kullanarak alabilirsiniz. |
