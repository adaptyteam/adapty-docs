[Özel etiket](flow-custom-tags), uygulamanızdan gelen bir değere sahip özel bir değişkendir. Bir değişkenin ayarlarında **Value comes from outside the app** seçeneğini işaretledikten sonra uygulamanız, bu değeri Adapty SDK aracılığıyla ayarlayabilir. Örneğin, bir metin öğesi "Coins:" ifadesini ve bir özel etiketi içeriyorsa, uygulamanız etiket için "120" değerini aktardığında kullanıcılar "Coins: 120" ifadesini görür.

## Özel etiket değerlerini aktarın \{#pass-custom-tag-values\}

Uygulamanızın değerlerini `AdaptyUI().createFlowView` veya `AdaptyUIFlowPlatformView` bileşeninin `customTags` parametresine `Map<String, String>` olarak aktarın:

- Her anahtar, `user.streak` gibi özel bir etiketin tam adıdır.
- Her değer, kullanıcıların etiket yerine gördüğü metindir.
- Her değer "1250.0" değil "1,250" gibi insan tarafından okunabilir olmalıdır. Adapty bu değerleri biçimlendirmez veya çevirmez.

SDK değerleri yalnızca bir kez, görünümü oluşturduğunda okur; bu nedenle flow açıkken değişmezler.

### BMI'yi paywall'a iletme \{#pass-the-bmi-to-the-paywall\}

Onboarding flow'unun `flow_user_input` olaylarından kullanıcının ağırlık ve boy bilgilerini toplayın; bunu nasıl yapacağınızı [Flow'lardan gelen verileri işleme](flutter-flow-input) bölümünde bulabilirsiniz. Kullanıcının son ekrana ulaştığını anlamak için `is_last_screen` değeri `true` olan bir `flow_screen_showed` olayını izleyin; bu konuyu [Flow ekran görüntülemelerini takip etme](flutter-flow-screen-views) bölümünde bulabilirsiniz. Kullanıcı o ekrandan sonra onboarding flow'unu kapattığında BMI'yi hesaplayın. Ardından paywall'ın görünümünü oluşturun ve `bmi` özel etiketi için BMI değerini iletin.

Aşağıdaki metodları `AdaptyUI().setFlowsEventsObserver` ile kaydettiğiniz observer'a ekleyin. Observer ayrıca `flowViewDidFinishRestore` ve `flowViewDidReceiveError` metodlarını da uygulamalıdır; bu örnek onları dışarıda bırakmaktadır:

```dart showLineNumbers title="Flutter"
final Map<String, String> bodyAnswers = {};
bool reachedLastScreen = false;

void flowViewDidReceiveAnalyticEvent(
  AdaptyUIFlowView view,
  String name,
  Map<String, dynamic> params,
) {
  if (name == 'flow_screen_showed' && params['is_last_screen'] == true) {
    reachedLastScreen = true;
    return;
  }
  if (name != 'flow_user_input') return;

  final elementId = params['element_id'];
  final value = params['value'];
  if (elementId is! String || value is! String) return;

  bodyAnswers[elementId] = value;
}

void flowViewDidDisappear(AdaptyUIFlowView view) {
  // The observer receives events from every flow. Reset `bodyAnswers` and
  // `reachedLastScreen` whenever a flow disappears, so that the paywall
  // doesn't open again when the user closes it.
  final answers = Map<String, String>.of(bodyAnswers);
  final finished = reachedLastScreen;
  bodyAnswers.clear();
  reachedLastScreen = false;

  // Number inputs send their values as strings.
  final weight = double.tryParse(answers['weight'] ?? '');
  final height = double.tryParse(answers['height'] ?? '');
  if (!finished || weight == null || height == null || height <= 0) return;

  final heightInMeters = height / 100;
  final bmi = weight / (heightInMeters * heightInMeters);
  showBmiPaywall(bmi.toStringAsFixed(1));
}

Future<void> showBmiPaywall(String bmi) async {
  try {
    final flow = await Adapty().getFlow(placementId: 'bmi_paywall');
    final view = await AdaptyUI().createFlowView(
      flow: flow,
      customTags: {'bmi': bmi},
    );
    await view.present();
  } on AdaptyError catch (e) {
    // handle the error
  } catch (e) {
    // handle the error
  }
}
```

`toStringAsFixed` her zaman ondalık ayırıcı olarak nokta kullanır. Kullanıcının yerel ayarına ait ayırıcıyı kullanmak için BMI'yi `intl` paketindeki `NumberFormat` ile biçimlendirin.

### Kullanıcının profiline BMI'yi kaydetme \{#save-the-bmi-to-the-users-profile\}

Kullanıcılara BMI'lerine göre farklı flow'lar göstermek için bunu profillerinin bir [custom attribute](flutter-setting-user-attributes#custom-user-attributes)'u olarak kaydedin. Adapty Kontrol Paneli'nde `bmi` anahtarıyla bir **Number** [custom attribute oluşturun](segments#custom-attributes). Ardından her flow'u bu attribute'tan oluşturulmuş bir [kitle](audience)'ye gösterin.

`updateProfile` metodunu `flowViewDidDisappear` içinde, `bmi`'yi hesaplayan satırın hemen ardından çağırın. Bir segmentin BMI'yi bir eşik değeriyle karşılaştırabilmesi için biçimlendirilmiş string yerine o `double` değerini geçirin:

```dart showLineNumbers title="Flutter"
try {
  final builder = AdaptyProfileParametersBuilder()
    ..setCustomDoubleAttribute(bmi, 'bmi');
  await Adapty().updateProfile(builder.build());
} on AdaptyError catch (e) {
  // handle the error
} catch (e) {
  // handle the error
}
```
