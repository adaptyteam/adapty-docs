Mobil uygulamanızda paywall'ları görüntülemek, kullanıcılara premium içerik veya hizmetlere erişim sunmanın temel adımlarından biridir. Ancak bir paywall, yalnızca Adapty'nin ekranı render ettiği durumlarda — yani bir [flow](adapty-flow-builder) veya [eski Paywall Builder](adapty-paywall-builder) ile oluşturulmuş bir paywall söz konusu olduğunda — satın almaları kendi başına destekler.

Ekranı kendi kodunuzla render ediyorsanız, satın almayı tamamlamak ve istenen içeriğin kilidini açmak için `.makePurchase()` adlı ayrı bir yöntem kullanmanız gerekir. Bu yöntem, kullanıcıların paywall'larla etkileşime geçmesi ve istedikleri işlemleri gerçekleştirmesi için bir geçit işlevi görür.

Kullanıcının satın almaya çalıştığı ürün için paywall'ınızda aktif bir promosyon teklifi varsa, Adapty bunu satın alma sırasında otomatik olarak uygular.

Tek bir adımı bile atlamadan [başlangıç yapılandırmasını](quickstart) tamamladığınızdan emin olun. Bu olmadan satın alımları doğrulayamayız.

## Satın alma yap \{#make-purchase\}

:::note
**Adapty ekranınızı mı oluşturuyor?** Bir [flow](adapty-flow-builder) veya [Paywall Builder](adapty-paywall-builder) paywall için satın almalar otomatik olarak işlenir—bu adımı atlayabilirsiniz.

**Adım adım rehber mi arıyorsunuz?** Tam bağlamla uçtan uca uygulama talimatları için [hızlı başlangıç kılavuzuna](capacitor-implement-paywalls-manually) göz atın.
:::

```typescript showLineNumbers

try {
  const result = await adapty.makePurchase({ product });
  
  if (result.type === 'success') {
    const isSubscribed = result.profile?.accessLevels?.['YOUR_ACCESS_LEVEL']?.isActive;
    
    if (isSubscribed) {
      // Grant access to the paid features
      console.log('User is now subscribed!');
    }
  } else if (result.type === 'user_cancelled') {
    console.log('Purchase cancelled by user');
  } else if (result.type === 'pending') {
    console.log('Purchase is pending');
  }
} catch (error) {
  console.error('Purchase failed:', error);
}
```

İstek parametreleri:

| Parametre   | Zorunluluk | Açıklama                                                                                                                 |
| :---------- | :------- |:----------------------------------------------------------------------------------------------------------------------------|
| **product** | zorunlu | `getPaywallProducts` ile flow üzerinden alınan bir [`AdaptyPaywallProduct`](https://capacitor.adapty.io/interfaces/adaptypaywallproduct) nesnesi. |

Yanıt parametreleri:

| Parametre | Açıklama                                                                                                                                                                                                                                                                                                                                                         |
|---------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **result** | Satın alma sonucunu belirten `type` alanı (`'success'`, `'user_cancelled'` veya `'pending'`) ve başarılı satın almalarda güncellenmiş [`AdaptyProfile`](https://capacitor.adapty.io/interfaces/adaptyprofile) içeren `profile` alanını barındıran bir [`AdaptyPurchaseResult`](https://capacitor.adapty.io/types/adaptypurchaseresult) nesnesi. |

## Satın alma sırasında aboneliği değiştirme \{#change-subscription-when-making-a-purchase\}

Bir kullanıcı mevcut aboneliğini yenilemek yerine yeni bir abonelik seçtiğinde, bu işlemin nasıl gerçekleşeceği uygulama mağazasına göre farklılık gösterir:

- App Store'da abonelik, abonelik grubu içinde otomatik olarak güncellenir. Kullanıcı bir gruptan abonelik satın alırken başka bir grupta da aktif aboneliği varsa, her iki abonelik aynı anda aktif olur.
- Google Play'de abonelik otomatik olarak güncellenmez. Geçişi aşağıda açıklandığı şekilde mobil uygulama kodunuzda yönetmeniz gerekir.

Android'de aboneliği başka biriyle değiştirmek için `.makePurchase()` metodunu ek parametre ile çağırın:

```typescript showLineNumbers

try {
  const result = await adapty.makePurchase({ 
    product,
    params: {
      android: {
        subscriptionUpdateParams: {
          oldSubVendorProductId: 'old_product_id',
          prorationMode: 'charge_prorated_price'
        },
        isOfferPersonalized: true
      }
    }
  });
  
  if (result.type === 'success') {
    const isSubscribed = result.profile?.accessLevels?.['YOUR_ACCESS_LEVEL']?.isActive;
    
    if (isSubscribed) {
      // Grant access to the paid features
      console.log('Subscription updated successfully!');
    }
  } else if (result.type === 'user_cancelled') {
    console.log('Purchase cancelled by user');
  } else if (result.type === 'pending') {
    console.log('Purchase is pending');
  }
} catch (error) {
  console.error('Purchase failed:', error);
}
```

| Parametre | Varlık | Açıklama |
| :--------- | :------- | :----------------------------------------------------------- |
| **params** | isteğe bağlı | [`MakePurchaseParamsInput`](https://capacitor.adapty.io/types/makepurchaseparamsinput) türünde, platforma özgü satın alma parametrelerini içeren bir nesne. |

`MakePurchaseParamsInput` yapısı şunları içerir:

```typescript
{
  android: {
    subscriptionUpdateParams: {
      oldSubVendorProductId: 'old_product_id',
      prorationMode: 'charge_prorated_price'
    },
    isOfferPersonalized: true
  }
}
```

Google Geliştirici belgelerinde abonelikler ve değiştirme modları hakkında daha fazla bilgi edinebilirsiniz:

- [Değişim modları hakkında](https://developer.android.com/google/play/billing/subscriptions#replacement-modes)
- [Google'ın değişim modları için önerileri](https://developer.android.com/google/play/billing/subscriptions#replacement-recommendations)
- Değişim modu [`CHARGE_PRORATED_PRICE`](https://developer.android.com/reference/com/android/billingclient/api/BillingFlowParams.SubscriptionUpdateParams.ReplacementMode#CHARGE_PRORATED_PRICE()). Not: Bu yöntem yalnızca abonelik yükseltmeleri için kullanılabilir. Düşürme işlemleri desteklenmez.
- Değişim modu [`DEFERRED`](https://developer.android.com/reference/com/android/billingclient/api/BillingFlowParams.SubscriptionUpdateParams.ReplacementMode#DEFERRED()). Not: Gerçek abonelik değişikliği yalnızca mevcut abonelik faturalama dönemi sona erdiğinde gerçekleşir.

### Ön ödemeli planları yönetme (Android) \{#manage-prepaid-plans-android\}

Uygulama kullanıcılarınız [ön ödemeli planlar](https://developer.android.com/google/play/billing/subscriptions#prepaid-plans) satın alabiliyorsa (örneğin birkaç aylık yenilenmez abonelik), ön ödemeli planlar için [bekleyen işlemleri](https://developer.android.com/google/play/billing/subscriptions#pending) etkinleştirebilirsiniz.

```typescript showLineNumbers
await adapty.activate({
  apiKey: 'YOUR_PUBLIC_SDK_KEY',
  params: {
    android: {
        pendingPrepaidPlansEnabled: true,
    },
  }
});
```

## iOS'ta teklif kodlarını kullanma \{#redeem-offer-codes-in-ios\}

<OfferCodesInfo />

Uygulamanızda kod kullanma ekranını göstermek için:

```typescript showLineNumbers

try {
  await adapty.presentCodeRedemptionSheet();
} catch (error) {
  console.error('Failed to present code redemption sheet:', error);
}
```

:::danger
Gözlemlerimize göre, bazı uygulamalarda Teklif Kodu Kullanma ekranı güvenilir şekilde çalışmayabilir. Kullanıcıyı doğrudan App Store'a yönlendirmenizi öneririz.

Bunu yapmak için aşağıdaki formattaki URL'yi açmanız gerekir:
`https://apps.apple.com/redeem?ctx=offercodes&id={apple_app_id}&code={code}`
:::

## App Store'dan tanıtılan uygulama içi satın almalar \{#in-app-purchases-from-the-app-store\}

:::info
Uygulamanız, SDK 4.1.1 sürümünden itibaren **iOS 16.4** veya sonrasında tanıtılan uygulama içi satın almaları devralabilir. iOS 16.4 altında bu olay hiçbir zaman tetiklenmez ve tanıtılan satın almalar kendi kendine tamamlanır. Olay, Android'de de hiçbir zaman tetiklenmez.
:::

Bir kullanıcı App Store ürün sayfanızdan satın alma işlemi başlattığında ve işlem uygulamanıza aktarıldığında, SDK bunu otomatik olarak tamamlar — Apple satın alma sistemi ekranı hemen görünür ve Adapty işlemi diğer satın almalar gibi işler. Bunun için tarafınızdan herhangi bir kod yazmanıza gerek yoktur.

Tanıtılan ürün bir abonelik teklifi içeriyorsa, SDK satın alma sırasında bunu otomatik olarak uygular. Teklif, App Store satın alma niyetinden okunur; bu bilgi iOS 18.0 ve sonrasında sunulmaktadır. iOS 16.4–17.x'te ise satın alma temel fiyat üzerinden gerçekleşir.

Tamamlamayı kendiniz devralmak için — örneğin önce kendi ekranınızı göstermek amacıyla — `'onPromotedPurchaseReceived'` olayını dinleyin ve ürünü `makePromotedPurchase`'e geçirin:

```typescript showLineNumbers

const listener = await adapty.addListener('onPromotedPurchaseReceived', async ({ product }) => {
  const result = await adapty.makePromotedPurchase({ product });
  // process the purchase result
});
```

:::warning
Dinleyiciniz kayıtlıyken SDK, promosyonlu satın almaları sizin adınıza tamamlamayı durdurur. Eğer işleyiciniz hiçbir zaman `makePromotedPurchase` çağırmazsa, satın alma gerçekleşmez: App Store ürünü uygulamanıza teslim eder ve bekler.
:::

`makePromotedPurchase` hiçbir satın alma parametresi almaz — promosyonlu bir ürün paywall'dan değil, App Store'dan gelir; dolayısıyla herhangi bir paywall bağlamı taşımaz. `makePurchase` ile aynı [`AdaptyPurchaseResult`](https://capacitor.adapty.io/types/adaptypurchaseresult) değerini döndürür.

`adapty.removeAllListeners()` çağrısı, promosyon satın alma dinleyicinizi diğerleriyle birlikte kaldırır ve SDK'nın otomatik tamamlaması devreye girer. Uygulamanız tamamlamayı hâlâ yönetecekse dinleyiciyi yeniden kaydedin.
