[Observer modu](observer-vs-full-mode) kullanıyorsanız, kendi satın alma mantığınızdan siz sorumlusunuz. Ancak paywall arayüzünü [Flow & Paywall Builder](adapty-flow-builder)'a devredebilirsiniz.

Ekranı builder'da tasarlayın, Adapty SDK onu native olarak render eder. Metin, düzen ve fiyatlandırmayı istediğiniz zaman güncelleyin, uygulama güncellemesine gerek yok.

Bu kılavuz, bir flow'u nasıl sunacağınızı ve satın alma callback'lerini nasıl yöneteceğinizi gösterir. Adapty satın alma işlemlerini sizin için tamamlıyorsa bunun yerine [Flow'ları ve paywall'ları görüntüleme](kmp-present-paywalls) bölümüne bakın.

## Başlamadan önce \{#before-you-start\}

You need:

- **Adapty Kotlin Multiplatform SDK 4.0 (beta) veya üzeri**: Daha eski sürümler flow'ları render edemez. Mevcut bir uygulamayı taşımak için [migration rehberine](migration-to-kmp-sdk-v4) bakın.
- **Yapılandırma builder'ında `withObserverMode(true)` çağrısı**: [Kotlin Multiplatform SDK kurulum rehberine](sdk-installation-kotlin-multiplatform#activate-adapty-sdk) bakın.
- **İlk mağaza entegrasyonu**: Adapty'yi [App Store ile](initial_ios) ve [Google Play ile](initial-android) kurun.
- **Ürünleri olan yayınlanmış bir flow**: [Flow & Paywall Builder](adapty-flow-builder)'da oluşturun ve [ürünleri](create-product) atayın.
- **Bir flow placement'ı**: [Placement oluşturun](create-placement) ve flow'unuzu atayın.
- **Uygulamanızda alınan flow**: Sunmadan önce [flow'u ve yapılandırmasını alın](kmp-get-pb-paywalls).

## Uygulama \{#implementation\}

Observer modunda SDK, sizin adınıza satın alma işlemi gerçekleştirmez. Kullanıcı, Adapty tarafından render edilen bir flow içindeki satın alma veya geri yükleme düğmesine dokunduğunda, SDK `AdaptyUIObserverModeResolver` metodunuzu çağırır — satın alma veya geri yükleme işlemini burada kendi kodunuzla gerçekleştirin.

1. `AdaptyUIObserverModeResolver` arayüzünü uygulayın:

   ```kotlin showLineNumbers
   import com.adapty.kmp.AdaptyUIObserverModeResolver
   import com.adapty.kmp.models.AdaptyPaywallProduct
   import com.adapty.kmp.models.AdaptyUIFlowView

   class MyObserverModeResolver : AdaptyUIObserverModeResolver {
       override fun observerModeDidInitiatePurchase(
           view: AdaptyUIFlowView,
           product: AdaptyPaywallProduct,
           onStartPurchase: () -> Unit,
           onFinishPurchase: () -> Unit
       ) {
           onStartPurchase() // the view shows its loading indicator
           // make the purchase with your own code,
           // then report the transaction to Adapty and call:
           onFinishPurchase() // the view hides the loading indicator
       }

       override fun observerModeDidInitiateRestore(
           view: AdaptyUIFlowView,
           onStartRestore: () -> Unit,
           onFinishRestore: () -> Unit
       ) {
           onStartRestore()
           // restore purchases with your own code, then:
           onFinishRestore()
       }
   }
   ```

`observerModeDidInitiatePurchase` metodu kullanıcının bir satın alma başlattığını, `observerModeDidInitiateRestore` ise kullanıcının geri yükleme başlattığını size bildirir. Buna karşılık olarak kendi özel satın alma veya geri yükleme flow'unuzu tetikleyin.

Ayrıca, satın alma veya geri yükleme sürecini AdaptyUI'ya bildirmek için aşağıdaki callback'leri çağırmayı unutmayın. Bu, yükleyiciyi göstermek gibi düzgün flow davranışı için gereklidir:

| Callback           | Description                                                                      |
   | :----------------- | :------------------------------------------------------------------------------- |
   | onStartPurchase()  | Satın alma başladığında AdaptyUI'ı bilgilendirmek için bu callback çağrılmalıdır.  |
   | onFinishPurchase() | Satın alma tamamlandığında AdaptyUI'ı bilgilendirmek için bu callback çağrılmalıdır. |
   | onStartRestore()   | Geri yükleme başladığında AdaptyUI'ı bilgilendirmek için bu callback çağrılmalıdır.   |
   | onFinishRestore()  | Geri yükleme tamamlandığında AdaptyUI'ı bilgilendirmek için bu callback çağrılmalıdır.  |

Flow, kodunuz çalışırken açık kalır — başarılı bir satın alma veya geri yükleme işleminden sonra onu kendiniz kapatmanız gerekir.

2. Herhangi bir ekran göstermeden önce resolver'ı kaydedin:

   ```kotlin showLineNumbers
   import com.adapty.kmp.AdaptyUI

   AdaptyUI.setObserverModeResolver(MyObserverModeResolver())
   ```

   Kayıtlı bir resolver olmadan, flow görünümünün satın almayı kodunuza iletmenin bir yolu yoktur ve kullanıcı satın alma düğmesine bastığında hiçbir şey olmaz.

3. Flow view'u her zamanki gibi oluşturun ve gösterin: [flow'u çekip view'unu oluşturun](kmp-get-pb-paywalls), ardından [gösterin](kmp-present-paywalls). Ekstra parametre gerekmez — resolver kaydedildikten sonra, Adapty tarafından render edilen her flow, satın alma ve restore işlemlerini onun üzerinden yönlendirir.

:::warning
[İşlemi raporlamayı ve paywall ile ilişkilendirmeyi](report-transactions-observer-mode-kmp) unutmayın. Aksi takdirde Adapty işlemi tanımayacak ve satın almanın kaynak paywall'ını belirleyemeyecektir.
:::
