[Observer modu](observer-vs-full-mode) kullanıyorsanız, kendi satın alma mantığınızdan siz sorumlusunuz. Ancak paywall arayüzünü [Flow & Paywall Builder](adapty-flow-builder)'a devredebilirsiniz.

Ekranı builder'da tasarlayın; Adapty SDK onu yerel olarak render eder. Metin, düzen ve fiyatlandırmayı istediğiniz zaman, uygulama güncellemesi gerektirmeden değiştirin. Kullanıcı bir satın alma düğmesine dokunduğunda SDK, satın almayı tamamlaması için kodunuzu çağırır.

Bu kılavuz, bu ekranın nasıl sunulacağını ve satın alma çağrısının nasıl yönetileceğini gösterir. Satın almaları Adapty sizin için tamamlıyorsa bunun yerine [Flow ve paywall'ları görüntüleme](android-present-paywalls) bölümüne bakın.

<SDKv4>

## Başlamadan önce \{#before-you-start\}

Şunlara ihtiyacınız var:

- **Adapty Android SDK v4 veya üzeri**: Önceki sürümler flow'ları render edemez. Mevcut bir uygulamayı v3'ten taşımak için [migration guide](migration-to-android-sdk-v4) adresine bakın.
- **`observerMode` `true` olarak ayarlanmış**: [Android SDK kurulum kılavuzuna](sdk-installation-android) bakın.
- **İlk mağaza entegrasyonu**: Adapty'yi [Google Play ile](initial-android) yapılandırın.
- **Ürünlerle yayınlanmış bir flow**: [Flow & Paywall Builder](adapty-flow-builder)'da oluşturun ve [ürünleri](create-product) atayın.
- **Bir flow placement'ı**: [Bir placement oluşturun](create-placement) ve flow'unuzu atayın.
- **Uygulamanızda çekilen flow**: Flow'u sunmadan önce [flow'u ve yapılandırmasını alın](android-get-pb-paywalls).

## Uygulama \{#implementation\}

1. `AdaptyUiObserverModeHandler` öğesini uygulayın.

`onPurchaseInitiated` olayı, kullanıcının bir satın alma işlemi başlattığını size bildirir. Bu callback'e yanıt olarak kendi özel satın alma flow'unuzu tetikleyebilirsiniz:

<Tabs groupId="current-os" queryString>
<TabItem value="kotlin" label="Kotlin" default>
   ```kotlin showLineNumbers
   val observerModeHandler =
    AdaptyUiObserverModeHandler { product, onStartPurchase, onFinishPurchase ->
       onStartPurchase()
       yourBillingClient.makePurchase(
           product,
           onSuccess = { purchase ->
               onFinishPurchase()
               //handle success
           },
           onError = {
               onFinishPurchase()
               //handle error
           },
           onCancel = {
               onFinishPurchase()
               //handle cancel
           }
       )
   }
   ```
</TabItem>
<TabItem value="java" label="Java" default>
   ```java showLineNumbers
   AdaptyUiObserverModeHandler observerModeHandler = (product, onStartPurchase, onFinishPurchase) -> {
       onStartPurchase.invoke();
       yourBillingClient.makePurchase(
           product,
           purchase -> {
               onFinishPurchase.invoke();
               //handle success
           },
           error -> {
               onFinishPurchase.invoke();
               //handle error
           },
           () -> { //cancellation
               onFinishPurchase.invoke();
               //handle cancel
           }
       );
   };
   ```
</TabItem>

Observer mode'da geri yüklemeleri işlemek için `getRestoreHandler()` metodunu override edin. Varsayılan olarak `null` döndürür; bu da Adapty'nin yerleşik `Adapty.restorePurchases()` flow'unu kullanır. Kendi geri yükleme implementasyonunuzu sağlamak için:

<Tabs groupId="current-os" queryString>
<TabItem value="kotlin" label="Kotlin" default>
   ```kotlin showLineNumbers
   val observerModeHandler = object : AdaptyUiObserverModeHandler {
       override fun onPurchaseInitiated(
           product: AdaptyPaywallProduct,
           onStartPurchase: AdaptyUiObserverModeHandler.PurchaseStartCallback,
           onFinishPurchase: AdaptyUiObserverModeHandler.PurchaseFinishCallback,
       ) {
           // the same body as the purchase example above
       }

       override fun getRestoreHandler() =
           AdaptyUiObserverModeHandler.RestoreHandler { onStartRestore, onFinishRestore ->
               onStartRestore()
               yourBillingClient.restorePurchases(
                   onSuccess = { restoredPurchases ->
                       onFinishRestore()
                       //handle successful restore
                   },
                   onError = {
                       onFinishRestore()
                       //handle error
                   }
               )
           }
   }
   ```
</TabItem>
<TabItem value="java" label="Java" default>
   ```java showLineNumbers
   AdaptyUiObserverModeHandler observerModeHandler = new AdaptyUiObserverModeHandler() {
       @Override
       public void onPurchaseInitiated(
           AdaptyPaywallProduct product,
           PurchaseStartCallback onStartPurchase,
           PurchaseFinishCallback onFinishPurchase
       ) {
           // the same body as the purchase example above
       }

       @Override
       public RestoreHandler getRestoreHandler() {
           return (onStartRestore, onFinishRestore) -> {
               onStartRestore.invoke();
               yourBillingClient.restorePurchases(
                   restoredPurchases -> {
                       onFinishRestore.invoke();
                       //handle successful restore
                   },
                   error -> {
                       onFinishRestore.invoke();
                       //handle error
                   }
               );
           };
       }
   };
   ```
</TabItem>
</Tabs>

Bu satın alma veya geri yükleme işlemi hakkında AdaptyUI'ı bilgilendirmek için aşağıdaki callback'leri çağırmayı unutmayın. Bu, yükleyiciyi gösterme gibi doğru flow davranışı için gereklidir:

| Callback           | Description                                                                                    |
   | :----------------- |:-----------------------------------------------------------------------------------------------|
   | onStartPurchase()  | Satın alma işleminin başladığını AdaptyUI'ya bildirmek için bu callback çağrılmalıdır.         |
   | onFinishPurchase() | Satın alma işleminin tamamlandığını AdaptyUI'ya bildirmek için bu callback çağrılmalıdır.      |
   | onStartRestore()   | İsteğe bağlı. Geri yükleme işleminin başladığını AdaptyUI'ya bildirmek için çağrılabilir.     |
   | onFinishRestore()  | İsteğe bağlı. Geri yükleme işleminin tamamlandığını AdaptyUI'ya bildirmek için çağrılabilir.  |

| **tagResolver** | isteğe bağlı | Flow metnindeki özel etiketleri çözümlemek için `AdaptyUiTagResolver` kullanın. Bu çözümleyici bir etiket parametresi alır ve bunu karşılık gelen bir dizeye dönüştürür. |
| **observerModeHandler** | Observer modu için zorunlu | Önceki adımda uyguladığınız `AdaptyUiObserverModeHandler`. |

1. `AdaptyUiObserverModeHandler`'ı uygulayın. `AdaptyUiObserverModeHandler`'ın callback'i (`onPurchaseInitiated`), kullanıcı bir satın alma işlemi başlattığında sizi bilgilendirir. Bu callback'e yanıt olarak kendi özel satın alma flow'unuzu şu şekilde tetikleyebilirsiniz:

<Tabs groupId="current-os" queryString>
<TabItem value="kotlin" label="Kotlin" default>
   ```kotlin showLineNumbers
   val observerModeHandler =
   AdaptyUiObserverModeHandler { product, paywall, paywallView, onStartPurchase, onFinishPurchase ->
       onStartPurchase()
       yourBillingClient.makePurchase(
           product,
           onSuccess = { purchase ->
               onFinishPurchase()
               //handle success
           },
           onError = {
               onFinishPurchase()
               //handle error
           },
           onCancel = {
               onFinishPurchase()
               //handle cancel
           }
       )
   }
   ```
</TabItem>
<TabItem value="java" label="Java" default>
   ```java showLineNumbers
   AdaptyUiObserverModeHandler observerModeHandler = (product, paywall, paywallView, onStartPurchase, onFinishPurchase) -> {
       onStartPurchase.invoke();
       yourBillingClient.makePurchase(
           product,
           purchase -> {
               onFinishPurchase.invoke();
               //handle success
           },
           error -> {
               onFinishPurchase.invoke();
               //handle error
           },
           () -> { //cancellation
               onFinishPurchase.invoke();
               //handle cancel
           }
       );
   };
   ```
</TabItem>
</Tabs>

Ayrıca, bu callback'leri AdaptyUI'ya çağırmayı unutmayın. Bu, yükleyiciyi göstermek gibi düzgün paywall davranışı için gereklidir:

| Kotlin'de Callback | Java'da Callback          | Açıklama                                                                                                                                        |
   | :----------------- | :------------------------ | :---------------------------------------------------------------------------------------------------------------------------------------------- |
   | onStartPurchase()  | onStartPurchase.invoke()  | Satın alma işleminin başladığını AdaptyUI'ya bildirmek için bu callback çağrılmalıdır.                                                          |
   | onFinishPurchase() | onFinishPurchase.invoke() | Satın alma işleminin başarıyla tamamlandığını, tamamlanamadığını veya iptal edildiğini AdaptyUI'ya bildirmek için bu callback çağrılmalıdır. |
