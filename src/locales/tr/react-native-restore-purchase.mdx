Satın almaları geri yükleme, hem iOS hem de Android'de kullanıcıların abonelikler veya uygulama içi satın almalar gibi daha önce satın aldıkları içeriklere tekrar ücret ödenmeden erişmesini sağlayan bir özelliktir. Bu özellik özellikle uygulamayı kaldırıp yeniden yükleyen ya da yeni bir cihaza geçen ve daha önce satın aldıkları içeriklere tekrar para ödemeden erişmek isteyen kullanıcılar için oldukça kullanışlıdır.

:::note
Ekranı bir builder ile oluşturduysanız, satın almaları manuel olarak geri yüklemeniz gerekmez. Geri yükleme kontrolünü bağlayın — Flow & Paywall Builder'da **Restore purchases** eylemi ya da eskisinde bir geri yükleme bağlantısı veya düğmesi — ve SDK geri yüklemeyi tamamlar.
:::

Ekranı kendiniz oluşturduysanız `.restorePurchases()` metodunu çağırın:

```typescript showLineNumbers
try {
    const profile = await adapty.restorePurchases();
    const isSubscribed = profile.accessLevels['YOUR_ACCESS_LEVEL']?.isActive;
  
    if (isSubscribed) {
        // restore access
    }
} catch (error) {
    // handle the error
}
```

Yanıt parametreleri:

| Parametre | Açıklama |
|---------|-----------|
| **Profile** | <p>Bir [`AdaptyProfile`](https://react-native.adapty.io/interfaces/adaptyprofile) nesnesi. Bu model, access level'lar, abonelikler ve tek seferlik satın almalar hakkında bilgi içerir.</p><p>Kullanıcının uygulamaya erişimi olup olmadığını belirlemek için **access level** durumunu kontrol edin.</p> |

:::info
Adapty React Native SDK 4.0.3 ve sonraki sürümlerde, `restorePurchases()` yüklenecek bir şey olmasa bile başarıyla tamamlanır: mevcut profili döndürür, bu yüzden içindeki access level durumunu kontrol edin. Daha eski SDK sürümlerinde bu durumda Android'de yöntem `noPurchasesToRestore` hatasıyla reddedilir.
:::
