Adapty'nin veri erişimini otomatikleştirebilmesi için Google Cloud Console'da bir servis hesabı gerekmektedir.

1. Google Cloud Console'un [**IAM & Admin** -> **Service accounts**](https://console.cloud.google.com/iam-admin/serviceaccounts) bölümünü açın. Doğru projeyi kullandığınızdan emin olun.

<Zoom>
  <img src="/assets/shared/img/17bbf45-google_cloud_create_service_account.webp"
  style={{
    border: '1px solid #727272', /* border width and color */
    width: '700px', /* image width */
    display: 'block', /* for alignment */
    margin: '0 auto' /* center alignment */
  }}
/>
</Zoom>

2. **Service accounts** penceresinde, **Create service account** düğmesine tıklayın.

<Zoom>
  <img src="/assets/shared/img/b93eec1-service_account_details.webp"
  style={{
    border: '1px solid #727272', /* border width and color */
    width: '700px', /* image width */
    display: 'block', /* for alignment */
    margin: '0 auto' /* center alignment */
  }}
/>
</Zoom>

3. **Create service account** penceresinin **Service account details** alt bölümünde, istediğiniz **Service Account Name** değerini girin. Bu hesabın amacını belirtmek için adın içinde "Adapty" kullanmanızı öneririz. **Service account ID** otomatik olarak oluşturulacaktır.

4. Servis hesabı e-posta adresini kopyalayın ve ileride kullanmak üzere kaydedin.

5. **Create and continue** düğmesine tıklayın.

<Zoom>
  <img src="/assets/shared/img/e69d713-grant_access_to_project.webp"
  style={{
    border: '1px solid #727272', /* border width and color */
    width: '700px', /* image width */
    display: 'block', /* for alignment */
    margin: '0 auto' /* center alignment */
  }}
/>
</Zoom>

6. **Bu hizmet hesabına projeye erişim izni ver** alt bölümünün **Rol seç** açılır listesinde **Pub/Sub -> Pub/Sub Admin** seçeneğini belirleyin. Bu rol, gerçek zamanlı geliştirici bildirimlerini etkinleştirmek için gereklidir.

<Zoom>
  <img src="/assets/shared/img/976299c-service_account_role.webp"
  style={{
    border: '1px solid #727272', /* border width and color */
    width: '700px', /* image width */
    display: 'block', /* for alignment */
    margin: '0 auto' /* center alignment */
  }}
/>
</Zoom>

7. **Başka bir rol ekle** düğmesine tıklayın.

8. Yeni **Role** açılır listesinde **Monitoring -> Monitoring Viewer** seçeneğini belirleyin. Bu rol, bildirim kuyruğunun izlenmesine izin vermek için gereklidir.

9. **Continue** düğmesine tıklayın.

<Zoom>
  <img src="/assets/shared/img/ffe8d82-grant_user_access.webp"
  style={{
    border: '1px solid #727272', /* border width and color */
    width: '700px', /* image width */
    display: 'block', /* for alignment */
    margin: '0 auto' /* center alignment */
  }}
/>
</Zoom>

10. Herhangi bir değişiklik yapmadan **Done** düğmesine tıklayın. **Service accounts** penceresi açılır.
