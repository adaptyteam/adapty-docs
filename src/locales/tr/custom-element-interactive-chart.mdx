Bu tarifi, bir paywall flow'unda her kullanıcının tahmini kilo değişimini grafik olarak göstermek için kullanın. Kullanıcı, bir onboarding flow'unda mevcut ve hedef kilosunu girer. Uygulamanız her iki değeri de toplar. Grafik, uygulamanızla birlikte kullanıcının bir değerden diğerine haftalık olarak ne kadar ilerleme bekleyebileceğini gösterir. Uygulamanız, grafiği bir [özel element](flow-custom-elements) içinde native bir view olarak render eder. Bu view, Swift Charts kullanır.

## 3. Mevcut ve hedef ağırlığı uygulamanıza kaydedin \{#3-save-the-current-and-goal-weight-in-your-app\}

Onboarding flow'unun `flow_user_input` etkinliklerinden mevcut ve hedef ağırlığı toplayın; bunun için [Flow'lardan veri işleme](ios-flow-input) konusuna bakın. Kullanıcının son ekrana ulaştığını anlamak için `is_last_screen` değeri `true` olan bir `flow_screen_showed` etkinliğini izleyin. Onboarding flow'u o ekranın ardından kapandığında, her iki ağırlığı da [paywall flow'unu grafikle birlikte açan](#5-match-the-chart-to-the-custom-element) `showWeightPaywall` fonksiyonuna iletin.

Aşağıdaki kod UIKit içindir. Bir view controller, her iki flow'un da delegate'idir. Her `AdaptyFlowControllerDelegate`'in implement ettiği satın alma ve geri yükleme metodlarını eklemek için [UIKit'te flow'ları ve paywall'ları sunma](ios-present-paywalls#present-flows-and-paywalls-in-uikit) bölümüne bakın.

```swift showLineNumbers title="Swift"
private var enteredWeights: [String: String] = [:]
private var reachedLastScreen = false

func flowController(
    _ controller: AdaptyFlowController,
    didReceiveAnalyticEvent name: String,
    params: [String: any Sendable]
) {
    if name == "flow_screen_showed", params["is_last_screen"] as? Bool == true {
        reachedLastScreen = true
        return
    }
    guard name == "flow_user_input",
          let elementId = params["element_id"] as? String,
          let value = params["value"] as? String
    else { return }

    enteredWeights[elementId] = value
}

func flowControllerDidDisappear(_ controller: AdaptyFlowController) {
    // This delegate receives events from both flows. Reset the entered
    // weights whenever a flow disappears, so that the paywall doesn't open
    // again when the user closes it.
    let weights = enteredWeights
    let finished = reachedLastScreen
    enteredWeights.removeAll()
    reachedLastScreen = false

    // Number inputs send their values as strings
    guard finished,
          let currentWeight = weights["weight"].flatMap({ Double($0) }),
          let goalWeight = weights["goal_weight"].flatMap({ Double($0) })
    else { return }

    Task {
        await showWeightPaywall(currentWeight: currentWeight, goalWeight: goalWeight)
    }
}
```

SwiftUI'da, delegate metotları yerine `.flow` modifier'ının `didReceiveAnalyticEvent` ve `didDisappear` closure'larını kullanın. Paywall flow'unu ikinci bir `.flow` modifier ile sunun.

## 4. Grafik görünümünü oluşturun \{#create-the-chart-view\}

Bir kilo planı modeli ve grafikli bir görünüm oluşturun. Planda mevcut kilodan hedef kiloya kadar haftada bir girdi bulunur. Kullanıcı grafik üzerinde sürüklediğinde, görünüm dokunulan noktadaki haftayı işaretler ve o haftaya ait tahmini kiloyu gösterir:

```swift showLineNumbers title="Swift"

struct WeightPlan {
    let entries: [WeightEntry]

    // One entry per week, from the current weight to the goal weight
    init(currentWeight: Double, goalWeight: Double) {
        let weeklyChange = 0.5 // kg per week
        let startDate = Date.now
        let weeks = Int((abs(goalWeight - currentWeight) / weeklyChange).rounded(.up))
        let step = goalWeight < currentWeight ? -weeklyChange : weeklyChange
        entries = (0...weeks).map { week in
            WeightEntry(
                date: startDate.addingTimeInterval(Double(week) * 7 * 24 * 60 * 60),
                kilograms: week == weeks ? goalWeight : currentWeight + step * Double(week)
            )
        }
    }
}

struct WeightEntry: Identifiable {
    let date: Date
    let kilograms: Double
    var id: Date { date }
}

@available(iOS 16.0, *) // Swift Charts needs iOS 16
struct WeightGoalChart: View {
    let entries: [WeightEntry]
    @State private var selectedDate: Date?

    // The entry closest to the date that the user drags to
    private var selectedEntry: WeightEntry? {
        guard let selectedDate else { return nil }
        return entries.min {
            abs($0.date.timeIntervalSince(selectedDate)) < abs($1.date.timeIntervalSince(selectedDate))
        }
    }

    var body: some View {
        if #available(iOS 17.0, *) {
            chart.chartXSelection(value: $selectedDate)
        } else {
            chart // iOS 16: no drag selection
        }
    }

    private var chart: some View {
        Chart {
            ForEach(entries) { entry in
                LineMark(
                    x: .value("Date", entry.date),
                    y: .value("Weight", entry.kilograms)
                )
            }
            if let selectedEntry {
                RuleMark(x: .value("Date", selectedEntry.date))
                    .foregroundStyle(.gray.opacity(0.3))
                PointMark(
                    x: .value("Date", selectedEntry.date),
                    y: .value("Weight", selectedEntry.kilograms)
                )
                .annotation(position: .top) {
                    Text("\(selectedEntry.kilograms, specifier: "%.1f") kg")
                        .font(.caption.bold())
                }
            }
        }
        .chartYScale(domain: .automatic(includesZero: false))
    }
}
```

Grafik üzerinde sürükleme özelliği iOS 17 veya üzerini gerektirir. iOS 16'da kullanıcılar çizgiyi görebilir, ancak üzerinde sürükleyemez.

## 5. Grafiği özel öğeyle eşleştirin \{#match-the-chart-to-the-custom-element\}

`line_chart` Türü ve `weight_goal` ID'si için grafik görünümünü döndüren bir [çözümleyici](ios-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views) yazın. Ağırlık planını çözümleyicinin bir özelliğinde saklayın:

```swift showLineNumbers title="Swift"

@available(iOS 16.0, *) // the chart needs iOS 16
struct WeightChartResolver: AdaptyUICustomElementsResolver {
    let plan: WeightPlan

    func view(
        forType type: String,
        id: String,
        context: AdaptyUICustomElementContext
    ) -> AnyView? {
        guard type == "line_chart", id == "weight_goal" else {
            return nil // another custom element: show the fallback
        }
        return AnyView(WeightGoalChart(entries: plan.entries))
    }
}
```

Attach the resolver to the paywall flow when you fetch its configuration. Create the resolver with the weight plan from the current and goal weight:

```swift showLineNumbers title="Swift"
func showWeightPaywall(currentWeight: Double, goalWeight: Double) async {
    let plan = WeightPlan(currentWeight: currentWeight, goalWeight: goalWeight)
    do {
        let flow = try await Adapty.getFlow(placementId: "weight_paywall")
        let flowConfiguration = try await AdaptyUI.getFlowConfiguration(
            forFlow: flow,
            customElementsResolver: WeightChartResolver(plan: plan)
        )
        let flowController = try AdaptyUI.flowController(
            with: flowConfiguration,
            delegate: self
        )
        present(flowController, animated: true)
    } catch {
        // handle the error
    }
}
```

Uygulamanız [uygulama genelinde bir resolver](ios-flow-custom-elements#set-an-app-wide-resolver) ayarlıyorsa, bu resolver paywall flow'undakinin yerini alır. `WeightChartResolver`, başka herhangi bir Type ve ID için görünüm döndürmez; çünkü bu tarifte paywall flow'unun başka özel öğesi yoktur. Paywall flow'unuzda başka özel öğeler varsa, uygulama genelinde kullandığınız resolver'ı buna geçirin. Ardından, [Bir flow'a resolver ekleme](ios-flow-custom-elements#attach-a-resolver-to-one-flow) bölümünde gösterildiği gibi, söz konusu Type ve ID'ler için uygulama genelindeki resolver'ı çağırın.

## 6. Cihazda test edin \{#6-test-on-a-device\}

Flow & Paywall Builder, uygulama kodunuzu çalıştıramaz; bu nedenle tuval yalnızca yedek içeriği gösterir. Grafiği önizlemek için:

1. [Her iki flow'u da yayınlayın](builder-save-publish). Önbelleğe alınmış sürümler yerine en son yayınlanan sürümleri görmek için cihazı bir [test cihazı](test-devices) olarak kaydedin.
2. Resolver'ı içeren uygulamanızın bir build'ini çalıştırın. iOS 17 veya sonraki bir sürüme sahip cihaz kullanın. Onboarding flow'unu mevcut ağırlık ve hedef ağırlıkla tamamlayın. Grafiğin çizgisinin mevcut ağırlıktan başladığını ve hedef ağırlıkta bittiğini doğrulayın.
3. Grafik üzerinde sürükleyin ve parmağınızın altındaki haftanın tahmini ağırlığının çizginin üzerinde göründüğünü doğrulayın.

Yedek paywall'ı test etmek için `showWeightPaywall` içindeki `WeightChartResolver` argümanını kaldırın ve paywall flow'unu tekrar açın.

Yedek yerine grafiğin neden göründüğünü anlamak için iOS kılavuzunun [Cihazda test etme](ios-flow-custom-elements#test-on-a-device) bölümündeki talimatları izleyin.
