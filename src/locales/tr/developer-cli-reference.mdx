Adapty CLI, komutlarını `products` veya `placements` gibi konulara göre gruplar. Her konunun kendi sayfası vardır ve bu sayfalarda komutlar, argümanlar, bayraklar ve kabul edilen değerler yer alır. Bu sayfa konuları, her komutun kabul ettiği bayrakları ve Adapty skill'lerini yükleyen komutu listeler.

| Konu | Komutlar | Ne yaparlar |
|---|---|---|
| [Uygulamalar ve access level'lar](developer-cli-apps) | `apps`, `access-levels` | Uygulamalar oluşturun, yapılandırın ve uygulamanızın kontrol ettiği abonelik katmanlarını ayarlayın |
| [Ürünler ve teklifler](developer-cli-products) | `products`, `product-offers` | Ürünleri ayarlayın, App Store ve Google Play ürün kimliklerine eşleyin ve mağaza tekliflerini onlara bağlayın |
| [Paywall'lar](developer-cli-paywalls) | `paywalls` | Paywall oluşturun, ürünleri onlara atayın ve metriklerini okuyun |
| [Flow'lar](developer-cli-flows) | `flows` | Flow oluşturun, builder yapılandırmalarını yazın ve doğrulayın, yayınlayın, önceki sürümleri geri yükleyin, kopyalayın ve metriklerini ile ekran hunisini okuyun |
| [Placement'lar ve segmentler](developer-cli-placements) | `placements`, `segments` | Placement'ları, kitlelerini ve kitlelerin hedeflediği segmentleri yapılandırın. Flow ve paywall placement'larının metriklerini okuyun |
| [Analitik](developer-cli-analytics) | `analytics` | Grafikleri, dönüşümleri, huniyi, tutmayı, LTV'yi ve kohortları okuyun |
| [A/B testleri](developer-cli-ab-tests) | `ab-tests` | Paywall ve flow A/B testleri oluşturun, başlatın, durdurun, değiştirin ve arşivleyin; sonuçlarını okuyun |
| [Attribution](developer-cli-attribution) | `attribution` | Kanala ve kampanyaya göre harcamayı, yüklemeleri, geliri ve ROAS'ı okuyun |
| [Ads Manager](developer-cli-ads-manager-reference) | `asa` | Apple Ads kampanyalarını, anahtar kelimeleri ve otomasyon kurallarını yönetin |
| [Geçişler](developer-cli-migrations) | `migrations` | Bir RevenueCat projesini Adapty'e taşıyın |
| [Kimlik doğrulama](developer-cli-authentication) | `auth` | CLI oturumunuzu başlatın, kontrol edin ve iptal edin |

## Global flags \{#global-flags\}

Bu flagler tüm komutlarda kullanılabilir.

| Flag | Açıklama |
|---|---|
| `--json` | Biçimlendirilmiş metin yerine JSON olarak çıktı verir |
| `--help` | Komut yardımını gösterir |

`adapty product-offers list` ve `adapty flows versions list` dışındaki tüm `list` komutları ayrıca sayfalama flaglerini de kabul eder:

| Flag | Varsayılan | Açıklama |
|---|---|---|
| `--page` | `1` | Sayfa numarası |
| `--page-size` | `20` | Sayfa başına öğe sayısı (maks: 100) |

## Beceriler \{#skills\}

### adapty skills install

Bu makinedeki kodlama agent'larına Adapty skill'lerini yükler.

```bash
adapty skills install
```

| Bayrak | Zorunlu | Açıklama |
|---|---|---|
| `--agent` | Hayır | Yüklenecek agent: `claude-code`, `codex` veya `gemini-cli`. Birden fazla agent için bayrağı tekrarlayın. |
| `-y`, `--yes` | Hayır | Sormadan bulunan tüm agent'lara yükler. CLI birden fazla agent bulduğunda ve sormak mümkün olmadığında gereklidir; örneğin `--json` ile kullanıldığında. |

CLI, `PATH` üzerinde Claude Code, Codex ve Gemini CLI'ı arar. Hiçbirini bulamazsa, diğer ajanları kapsayan `npx skills@1.7.0 add adaptyteam/adapty-skills --all --global` komutunu çalıştırıp çalıştırmayacağını sorar. Skill'lerin yüklenmesi için ajanı yeniden başlatın.

Claude Code, eklentiyi kendi başına güncellemez. Yeni skill'leri yayınlandıkça almak için Claude Code'da `/plugin` komutunu çalıştırın, **Marketplaces** bölümünü açın, `adapty` seçeneğini seçin ve **Enable auto-update** öğesini seçin. Menüyü kullanmadan etkinleştirmek için `~/.claude/settings.json` dosyasındaki `adapty` girişine `"autoUpdate": true` ekleyin:

```json title="~/.claude/settings.json"
{
  "extraKnownMarketplaces": {
    "adapty": {
      "source": { "source": "github", "repo": "adaptyteam/adapty-skills" },
      "autoUpdate": true
    }
  }
}
```

Skills CLI aracılığıyla yüklenen skill'ler `npx skills update` komutuyla güncellenir. Codex için [plugin README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#codex) dosyasına bakın.
