[Observer modu](observer-vs-full-mode) kullanıyorsanız, satın alma mantığından siz sorumlusunuz. Ancak paywall arayüzünü [Flow & Paywall Builder](adapty-flow-builder)'a devredebilirsiniz.

Ekranı builder'da tasarlayın, Adapty SDK onu yerel olarak render eder. Metin, düzen ve fiyatlandırmayı uygulama güncellemesi yapmadan istediğiniz zaman değiştirin.

Bu kılavuz, bir flow'u nasıl sunacağınızı ve satın alma callback'lerini nasıl yöneteceğinizi gösterir. Adapty satın alma işlemlerini sizin için tamamlıyorsa, bunun yerine [Flow ve paywall'ları görüntüleme](capacitor-present-paywalls) sayfasına bakın.

## Başlamadan önce \{#before-you-start\}

Gereksinimler:

- **Adapty Capacitor SDK 4.1 veya üzeri**: Önceki sürümler flow'ları görüntüleyemez. Mevcut bir uygulamayı taşımak için [migration kılavuzuna](migration-to-capacitor-sdk-v4) bakın.
- **`observerMode` `true` olarak ayarlanmış**: [Capacitor SDK kurulum kılavuzuna](sdk-installation-capacitor#activate-adapty-module-of-adapty-sdk) bakın.
- **İlk mağaza entegrasyonu**: Adapty'yi [App Store ile](initial_ios) ve [Google Play ile](initial-android) kurun.
- **Ürünlere sahip yayımlanmış bir flow**: [Flow & Paywall Builder](adapty-flow-builder)'da oluşturun ve [ürünleri](create-product) buna atayın.
- **Bir flow placement'ı**: [Bir placement oluşturun](create-placement) ve flow'unuzu buna atayın.
- **Uygulamanızda alınan flow**: Göstermeden önce [flow'u ve yapılandırmasını alın](capacitor-get-pb-paywalls).

## Uygulama \{#implementation\}

Observer modunda SDK, satın alma işlemlerini sizin adınıza gerçekleştirmez. Kullanıcı, Adapty tarafından oluşturulan bir flow içindeki satın alma veya geri yükleme düğmesine dokunduğunda, SDK sizin `onObserverPurchaseInitiated` veya `onObserverRestoreInitiated` olay işleyicinizi çağırır. Satın alma veya geri yükleme işlemini orada kendi kodunuzla gerçekleştirin.

1. Observer modu olay işleyicilerini view üzerinde ayarlayın. Diğer platformlardan farklı olarak, ayrı bir resolver nesnesi yoktur — işleyiciler normal [olay işleyicilerinin](capacitor-handling-events) bir parçasıdır, bu nedenle oluşturduğunuz her view'da bunları ayarlayın:

   ```typescript showLineNumbers title="Capacitor"
   import { adapty, createFlowView } from '@adapty/capacitor';

   const view = await createFlowView(flow);

   const unsubscribe = await view.setEventHandlers({
     onObserverPurchaseInitiated(product, onStartPurchase, onFinishPurchase) {
       onStartPurchase(); // the view shows its loading indicator
       myPurchaseApi(product.vendorProductId)
         .then((transactionId) =>
           adapty.reportTransaction({ transactionId, variationId: flow.variationId }),
         )
         .finally(() => onFinishPurchase()); // the view hides the loading indicator
       return false; // keep the flow open; dismiss it yourself after success
     },
     onObserverRestoreInitiated(onStartRestore, onFinishRestore) {
       onStartRestore();
       myRestoreApi().finally(() => onFinishRestore());
       return false;
     },
   });
   ```

`onObserverPurchaseInitiated` handler, kullanıcının bir satın alma işlemi başlattığını size bildirir; `onObserverRestoreInitiated` ise kullanıcının bir geri yükleme işlemi başlattığını. Buna yanıt olarak kendi özel satın alma veya geri yükleme flow'unuzu tetikleyin.

Ayrıca, satın alma veya geri yükleme sürecini AdaptyUI'ya bildirmek için aşağıdaki callback'leri çağırmayı unutmayın. Bu, yükleyiciyi göstermek gibi düzgün flow davranışı için gereklidir:

| Callback           | Description                                                                              |
   | :----------------- | :--------------------------------------------------------------------------------------- |
   | onStartPurchase()  | Satın alma işleminin başladığını AdaptyUI'ya bildirmek için bu callback çağrılmalıdır.   |
   | onFinishPurchase() | Satın alma işleminin bittiğini AdaptyUI'ya bildirmek için bu callback çağrılmalıdır.     |
   | onStartRestore()   | Geri yükleme işleminin başladığını AdaptyUI'ya bildirmek için bu callback çağrılmalıdır. |
   | onFinishRestore()  | Geri yükleme işleminin bittiğini AdaptyUI'ya bildirmek için bu callback çağrılmalıdır.   |

2. Flow görünümünü her zamanki gibi sunun: [flow'u alın ve görünümünü oluşturun](capacitor-get-pb-paywalls), ardından [sunun](capacitor-present-paywalls). Ekstra parametre gerekmez — handler'lar yalnızca SDK `observerMode: true` ile etkinleştirildiğinde tetiklenir.

:::warning
[İşlemi bildirmeyi ve paywall ile ilişkilendirmeyi](report-transactions-observer-mode-capacitor) unutmayın. Aksi takdirde Adapty işlemi tanımaz ve satın almanın kaynak paywall'ını belirleyemez.
:::
