[Özel etiket](flow-custom-tags), uygulamanızdan gelen bir değere sahip özel bir değişkendir. Bir değişkenin ayarlarında **Value comes from outside the app** seçeneğini belirledikten sonra uygulamanız, Adapty SDK aracılığıyla bu değeri ayarlayabilir. Örneğin, bir metin öğesi "Coins:" ve bir özel etiket içeriyorsa ve uygulamanız etiket için "120" değerini aktarırsa kullanıcılar "Coins: 120" görür.

## Özel etiket değerlerini aktarma \{#pass-custom-tag-values\}

Bir `AdaptyUiTagResolver` oluşturun ve bunu `AdaptyUI.getFlowView` metodunun `tagResolver` parametresine geçirin. SDK, her özel etiketin tam adıyla (örneğin `user.streak`) resolver'ı çağırır. Resolver aşağıdakilerden birini döndürür:

- **Bir string**: Kullanıcılar etiketi bu değeri göreceği şekilde görür. "1250.0" gibi değil, "1.250" gibi insan tarafından okunabilir bir format olmalıdır. Adapty bunu biçimlendirmez veya çevirmez.
- **`null`**: Kullanıcılar yedek olarak etiketin Başlangıç değerini görür.
- **Boş bir string**: Kullanıcılar etiket yerine hiçbir şey görmez.

val customTags = mapOf(

### BMI'yi paywalle aktarma \{#pass-the-bmi-to-the-paywall\}

Onboarding flow'unun `flow_user_input` olaylarından kullanıcının ağırlığını ve boyunu toplayın; bunun için [Flow'lardan veri işleme](android-flow-input) bölümüne bakın. Kullanıcının son ekrana ulaştığını anlamak için `is_last_screen` değeri `true` olarak ayarlanmış bir `flow_screen_showed` olayını izleyin; bunun için [Flow ekran görüntülemelerini takip etme](android-flow-screen-views) bölümüne bakın. Kullanıcı o ekrandan sonra onboarding flow'unu kapattığında BMI'yi hesaplayın. Ardından paywallın flow görünümünü oluşturun ve `bmi` özel etiketi için BMI değerini aktarın.

Onboarding flow'unun görünümüne aşağıdaki listener'ı geçirin:

```kotlin showLineNumbers title="Kotlin"
class OnboardingEventListener(
    private val onBmiCalculated: (bmi: String) -> Unit,
) : AdaptyFlowDefaultEventListener() {

    private val bodyAnswers = mutableMapOf<String, String>()
    private var reachedLastScreen = false

    override fun onAnalyticEvent(
        name: String,
        params: Map<String, Any?>,
        context: Context,
    ) {
        if (name == "flow_screen_showed" && params["is_last_screen"] == true) {
            reachedLastScreen = true
            return
        }
        if (name != "flow_user_input") return

        val elementId = params["element_id"] as? String ?: return
        val value = params["value"] as? String ?: return

        bodyAnswers[elementId] = value
    }

    override fun onFlowClosed() {
        // Reset `bodyAnswers` and `reachedLastScreen` on every close,
        // so that the next run starts without old answers.
        val answers = bodyAnswers.toMap()
        val finished = reachedLastScreen
        bodyAnswers.clear()
        reachedLastScreen = false

        // Number inputs send their values as strings.
        if (!finished) return
        val weight = answers["weight"]?.toDoubleOrNull() ?: return
        val height = answers["height"]?.toDoubleOrNull()?.takeIf { it > 0 } ?: return

        val heightInMeters = height / 100
        val bmi = weight / (heightInMeters * heightInMeters)

        onBmiCalculated(String.format(Locale.getDefault(), "%.1f", bmi))
    }
}
```

When the user closes the onboarding flow after its last screen, the listener calls `onBmiCalculated` with the BMI. Pass a lambda for `onBmiCalculated` that calls the following function. The function fetches the paywall flow, creates its view, and passes the BMI for the `bmi` custom tag:

```kotlin showLineNumbers title="Kotlin"
fun showBmiPaywall(activity: Activity, bmi: String) {
    Adapty.getFlow("bmi_paywall") { flowResult ->
        when (flowResult) {
            is AdaptyResult.Success -> {
                AdaptyUI.getFlowConfiguration(flowResult.value) { configResult ->
                    when (configResult) {
                        is AdaptyResult.Success -> {
                            val flowView = AdaptyUI.getFlowView(
                                activity,
                                configResult.value,
                                products = null,
                                eventListener = AdaptyFlowDefaultEventListener(),
                                tagResolver = AdaptyUiTagResolver { tag ->
                                    if (tag == "bmi") bmi else null
                                },
                            )
                            // add flowView to your view hierarchy
                        }
                        is AdaptyResult.Error -> {
                            // handle the error
                        }
                    }
                }
            }
            is AdaptyResult.Error -> {
                // handle the error
            }
        }
    }
}
```

`String.format` ile `Locale.getDefault()` kullanmak, kullanıcının yerel ayarına göre ondalık ayracı uygular: İngilizce'de "22.7", Almanca'da "22,7".

### BMI'yi kullanıcının profiline kaydet \{#save-the-bmi-to-the-users-profile\}

Kullanıcılara BMI'lerine göre farklı flow'lar göstermek için bunu profillerinin bir [custom attribute](android-setting-user-attributes#custom-user-attributes)'ı olarak kaydedin. Adapty Kontrol Paneli'nde `bmi` anahtarıyla [**Number** türünde bir custom attribute oluşturun](segments#custom-attributes). Ardından her flow'u bu attribute'tan oluşturulan bir [kitle](audience) ile gösterin.

`updateProfile` metodunu `onFlowClosed` içinde, `bmi`'yi hesaplayan satırın hemen ardından çağırın. Bir segment'in BMI'yi bir eşik değeriyle karşılaştırabilmesi için biçimlendirilmiş string yerine `Double` değerini geçirin:

```kotlin showLineNumbers title="Kotlin"
val params = AdaptyProfileParameters.Builder()
    .withCustomAttribute("bmi", bmi)
    .build()

Adapty.updateProfile(params) { error ->
    if (error != null) {
        // handle the error
    }
}
```
