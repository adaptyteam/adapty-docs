Facebook Ads entegrasyonu sayesinde uygulama istatistiklerinizi Meta Analytics'te kolayca takip edebilirsiniz. Adapty, Meta Ads Manager'a etkinlikler göndererek aboneliklere dayalı benzer kitleler oluşturmanıza ve daha iyi dönüşümler elde etmenize yardımcı olur. Bu sayede reklamlarınızın aboneliklerden ne kadar gelir sağladığını doğru bir şekilde görebilirsiniz.

Adapty ile Facebook Ads arasındaki entegrasyon şu şekilde çalışır: Adapty, entegrasyonunuzda yapılandırılmış tüm abonelik olaylarını Facebook Ads'e gönderir. Bu entegrasyon, reklam kampanyalarınızın etkinliğini değerlendirmek için faydalıdır.

## Entegrasyonu kurma \{#set-up-integration\}

### Adapty'yi Facebook Ads'e bağlama \{#connect-adapty-to-facebook-ads\}

Facebook Ads entegrasyonunu kurmak ve uygulama metriklerinizi analiz etmek için Meta Analytics entegrasyonunu ayarlayabilirsiniz. Meta Ads Manager'a etkinlik göndererek yenileme gibi abonelik etkinliklerine dayalı benzer kitleler oluşturabilirsiniz. Bu entegrasyonu yapılandırmak için Adapty Kontrol Paneli'nde [Integrations > Facebook Ads](https://app.adapty.io/integrations/facebookanalytics) bölümüne gidin ve gerekli kimlik bilgilerini girin.

:::note
Facebook Ads entegrasyonunun yalnızca ATT onayı vermiş kullanıcılar için iOS 14.5 ve üzeri sürümlerde çalıştığını lütfen unutmayın.
:::

### Olayları ve etiketleri yapılandırın \{#configure-events-and-tags\}

Adapty, satın alma olaylarını Meta'nın standart olaylarıyla eşleştirir; Meta bu olaylar üzerinden kampanyaları optimize edebilir: `StartTrial`, `Subscribe` ve Meta'nın satın alma olayı olan `fb_mobile_purchase`. **Subscription started**, **Subscription renewed**, **Trial started** ve **Trial converted** olaylarının her biri, olay alanında seçili olan her ad için ayrı bir Meta olayı gönderir ve varsayılan olarak tüm adlar seçilidir. Örneğin bir deneme başlangıcı, Meta'ya üç ayrı olay olarak iletilir. Daha az olay göndermek istiyorsanız alandaki adları kaldırabilirsiniz.

| Adapty etkinliği              | Varsayılan Meta etkinlikleri                           |
| :------------------------ | :-------------------------------------------- |
| Subscription started      | `Subscribe`, `fb_mobile_purchase`             |
| Subscription renewed      | `Subscribe`, `fb_mobile_purchase`             |
| Trial started             | `StartTrial`, `Subscribe`, `fb_mobile_purchase` |
| Trial converted           | `Subscribe`, `fb_mobile_purchase`             |
| Non-subscription purchase | `fb_mobile_purchase`                          |

Meta'nın geri kalan olaylar için standart bir etkinliği yoktur; bu nedenle Adapty bunları kendi Adapty adlarıyla özel olaylar olarak gönderir. Kendi adlandırmanızla eşleştirmek için olayın alanındaki adı değiştirin.

| Adapty etkinliği                       | Varsayılan Meta etkinliği                   |
| :--------------------------------- | :----------------------------------- |
| Subscription expired (Churned)     | `subscription_expired`               |
| Subscription renewal cancelled     | `subscription_renewal_cancelled`     |
| Subscription renewal reactivated   | `subscription_renewal_reactivated`   |
| Subscription paused (Yalnızca Android) | `subscription_paused`                |
| Subscription deferred (Yalnızca Android) | `subscription_deferred`            |
| Subscription refunded              | `subscription_refunded`              |
| Trial expired                      | `trial_expired`                      |
| Trial renewal cancelled            | `trial_renewal_cancelled`            |
| Trial renewal reactivated          | `trial_renewal_reactivated`          |
| Entered grace period               | `entered_grace_period`               |
| Billing issue detected             | `billing_issue_detected`             |
| Non-subscription purchase refunded | `non_subscription_purchase_refunded` |
| Trial still active                 | `trial_active`                       |
| Subscription still active          | `subscription_active`                |

**Trial still active** ve **Subscription still active**, [sentetik event](events#synthetic-events)'lardır: Adapty bunları Meta'ya bir zamanlayıcıyla gönderir; yalnızca deneme süresi veya abonelik, zamanlayıcı sona erdiğinde hâlâ devam ediyorsa iletilir. Gelir içermediklerinden Meta bunları satın alma değerine dahil etmez. Her ikisi de varsayılan olarak kapalıdır. Göndermek için açın ve [gecikmeyi ayarlayın](configuration#set-the-timer-for-synthetic-events).

## Etkinlik yapısı \{#event-structure\}

Adapty, Graph API aracılığıyla Facebook Ads'e (Meta) etkinlik gönderir. Her etkinlik şu yapıdadır:

```json
{
  "event": "CUSTOM_APP_EVENTS",
  "app_user_id": "user_12345",
  "advertiser_id": "00000000-0000-0000-0000-000000000000",
  "advertiser_tracking_enabled": 1,
  "application_tracking_enabled": 1,
  "custom_events": "[{\"_eventName\":\"Subscribe\",\"_logTime\":1709294400,\"fb_num_items\":1,\"fb_content_type\":\"in_app\",\"fb_content_id\":\"yearly.premium.6999\",\"fb_currency\":\"USD\",\"fb_order_id\":\"GPA.3383...\",\"fb_transaction_id\":\"GPA.3383...\",\"_valueToSum\":9.99}]",
  "extinfo": "[\"i2\",\"com.example.app\",\"1.0.0\",\"100\",\"17.0.1\",\"iPhone14,3\",\"en_US\",\"GMT+3\",\"\",0,0,0,0,0,0,\"GMT+3\"]",
  "anon_id": "facebook_anon_id_123"
}
```

Parametreler:

| Parametre | Tür | Açıklama |
|:---|:---|:---|
| `event` | String | Her zaman "CUSTOM_APP_EVENTS". |
| `app_user_id` | String | Kullanıcının Customer User ID'si. |
| `advertiser_id` | String | iOS'ta IDFA, IDFA kullanılamadığında IDFV. Android'de Advertising ID. Profilde cihaz kimliği yoksa `00000000-0000-0000-0000-000000000000`. |
| `advertiser_tracking_enabled` | Integer | İzleme etkinse (ATT yetkilendirilmişse) `1`, aksi takdirde `0`. |
| `application_tracking_enabled` | Integer | Her zaman `1`. |
| `custom_events` | String | Olay nesnelerinin JSON kodlu dizesi (aşağıya bakın). |
| `extinfo` | String | Uygulama/cihaz bilgilerini (ör. sürüm, işletim sistemi, yerel ayar) içeren JSON kodlu dize. |
| `anon_id` | String | Facebook Anonymous ID (varsa). |

`custom_events` parametresi, Adapty olayının eşlendiği her Meta olayı için bir nesne içeren JSON kodlu bir dizidir. Yalnızca `StartTrial`, `Subscribe` ve `fb_mobile_purchase` olayları `fb_content_id`, `fb_content_type`, `fb_num_items` ve `fb_transaction_id` alanlarını taşır. Her nesne şunları içerir:

| Parametre | Tür | Açıklama |
|:---|:---|:---|
| `_eventName` | String | Meta Ads etkinlik adı (ör. "Subscribe"). |
| `_logTime` | Long | Etkinliğin saniye cinsinden zaman damgası. |
| `_valueToSum` | Float | Gelir tutarı. |
| `fb_content_id` | String | Mağazadaki Ürün ID'si. |
| `fb_currency` | String | Para birimi kodu (ör. "USD"). |
| `fb_order_id` | String | Orijinal işlem ID'si. |
| `fb_transaction_id` | String | Orijinal işlem ID'si. |
| `fb_content_type` | String | Her zaman "in_app". |
| `fb_num_items` | Integer | Satın alma etkinlikleri için her zaman 1. |
