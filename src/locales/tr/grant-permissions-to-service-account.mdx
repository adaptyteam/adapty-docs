Adapty'nin abonelikleri yönetmek ve satın almaları doğrulamak için kullanacağı hizmet hesabına gerekli izinleri verin.

1. [Google Play Console](https://play.google.com/console/)'ı açın, **Users and permissions** sayfasına gidin ve **Invite new users** butonuna tıklayın.

  <img src="/assets/shared/img/7b0e614-users_and_permissions.webp"

    width: '700px', /* image width */

    margin: '0 auto' /* center alignment */
  }}
/>
</Zoom>

2. **Invite user** sayfasında, oluşturduğunuz servis kullanıcısının e-posta adresini girin.

<Zoom>
  <img src="/assets/shared/img/3afd002-invite_user.webp"
  style={{
    border: '1px solid #727272', /* border width and color */
    width: '700px', /* image width */
    display: 'block', /* for alignment */
    margin: '0 auto' /* center alignment */
  }}
/>
</Zoom>

3. **Account permissions** sekmesine geçin.

<Zoom>
  <img src="/assets/shared/img/4e2717b-account_permissions.webp"
  style={{
    border: '1px solid #727272', /* border width and color */
    width: '700px', /* image width */
    display: 'block', /* for alignment */
    margin: '0 auto' /* center alignment */
  }}
/>
</Zoom>

4. Aşağıdaki izinleri seçin:
   - View app information and download bulk reports (read-only)
   - View financial data, orders, and cancellation survey responses
   - Manage orders and subscriptions
   - Manage store presence
5. **Invite user** butonuna tıklayın.
6. **Send invite?** penceresinde **Send invite** butonuna tıklayın. Servis hesabı kullanıcı listesinde görünecektir.
