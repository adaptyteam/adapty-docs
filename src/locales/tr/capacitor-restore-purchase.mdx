Hem iOS hem de Android'de satın alma işlemlerini geri yükleme, kullanıcıların abonelikler veya uygulama içi satın almalar gibi daha önce satın aldıkları içeriklere yeniden ücretlendirilmeden erişmesini sağlayan bir özelliktir. Bu özellik, uygulamayı kaldırıp yeniden yükleyen ya da yeni bir cihaza geçen ve önceki satın almalarına tekrar ödeme yapmadan erişmek isteyen kullanıcılar için oldukça kullanışlıdır.

:::note
Ekranı bir builder'da oluşturduysanız, satın almaları manuel olarak geri yüklemeniz gerekmez. Flow & Paywall Builder'daki **Restore purchases** eylemini ya da eski builder'daki bir geri yükleme bağlantısı veya düğmesini restore kontrolüne bağlayın; SDK geri yükleme işlemini kendisi tamamlar.
:::

Ekranı kendiniz oluşturduysanız `.restorePurchases()` metodunu çağırın:

```typescript showLineNumbers

try {
  const profile = await adapty.restorePurchases();
  const isSubscribed = profile.accessLevels?.['YOUR_ACCESS_LEVEL']?.isActive;
  
  if (isSubscribed) {
    // Restore access to paid features
    console.log('Access restored successfully!');
  } else {
    console.log('No active subscriptions found');
  }
} catch (error) {
  console.error('Failed to restore purchases:', error);
}
```

Yanıt parametreleri:

| Parametre | Açıklama                                                                                                                                                                                                                                                            |
|---------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **profile** | Bir [`AdaptyProfile`](https://capacitor.adapty.io/interfaces/adaptyprofile) nesnesi. Bu model; access level'lar, abonelikler ve abonelik dışı satın almalar hakkında bilgi içerir. Kullanıcının uygulamaya erişimi olup olmadığını belirlemek için **access level** durumunu kontrol edin. |
