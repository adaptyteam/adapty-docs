Bir kullanıcı [flow](adapty-flow-builder) içinde bir ekranı her açtığında, SDK uygulamanıza `flow_screen_showed` etkinliği bildirir. Bunu Amplitude, Mixpanel veya kullandığınız herhangi bir ürün analitiğine ileterek flow ekranlarını uygulamanızın diğer etkinlikleriyle birlikte analiz edebilirsiniz.

:::tip
Kullanıcıların bir flow'da ne kadar ilerlediğini görmek için herhangi bir koda ihtiyacınız yok — [flow metrikleri](flow-metrics) Adapty Kontrol Paneli'nde görüntülenmeleri, tamamlanmaları ve ekran başına düşüş oranlarını zaten gösteriyor. Bu kılavuzu, aynı verilere kendi analitiğinizde ihtiyaç duyduğunuzda ve bunları Adapty'nin bilmediği olaylarla birleştirmek istediğinizde kullanın.
:::

## Başlamadan önce \{#before-you-start\}

İhtiyacınız olanlar:

- **Adapty Capacitor SDK v4 veya üzeri**: Flow analytics callback'i önceki sürümlerde mevcut değildir.
- **Bu özellik kullanıma sunulduktan sonra yayınlanan bir flow sürümü**: Adapty, ekran olaylarını bir flow'u yayınladığında oluşturur; dolayısıyla bundan önce yayınladığınız bir flow hiçbir şey raporlamaz. Uygulamanıza hiç olay ulaşmıyorsa flow'un yeni bir sürümünü yayınlayıp tekrar deneyin.

## Ne alırsınız \{#what-you-receive\}

<FlowScreenShowedParams />

Ekran görüntülemeleri, diğer tüm flow olaylarıyla aynı analitik callback'e ulaşır. Bunu nereye kaydedeceğinizi öğrenmek için [Flow ve paywall olaylarını yönetme](capacitor-handling-events) bölümüne bakın.

## Her ekran görünümünü analizlerinize iletin \{#forward-every-screen-view-to-your-analytics\}

Callback aynı zamanda diğer olayları da ilettiğinden, herhangi bir şeyi okumadan önce olay adını eşleştirin.

```typescript showLineNumbers title="Capacitor"
view.setEventHandlers({
  onAnalytics(name, params) {
    if (name === 'flow_screen_showed') {
      const screenId = params.instanceId;
      const screenOrder = params.screen_order;

      // Send screenId and screenOrder to your analytics provider here.
    }
    return false; // keep the flow open
  },
});
```

## Kullanıcı sona ulaştığında kod çalıştırma \{#run-code-when-a-user-reaches-the-end\}

`is_last_screen`, flow'un ilerleyemeyeceği bir ekranda `true` olur. İçeriklerin kilidini açmak, onboarding'i tamamlandı olarak işaretlemek veya kendi tamamlanma etkinliğinizi göndermek için builder'a bir buton aksiyonu eklemeden bunu kullanabilirsiniz.

```typescript showLineNumbers title="Capacitor"
view.setEventHandlers({
  onAnalytics(name, params) {
    if (name === 'flow_screen_showed' && params.is_last_screen) {
      // The user reached the end of the flow.
    }
    return false; // keep the flow open
  },
});
```

Son ekrana ulaşmak, flow'u kapatmakla aynı şey değildir. Kullanıcı son ekranı görüp herhangi bir işlem yapmadan flow'u kapatabilir; ayrıca dallanan bir flow birkaç farklı ekranda sona erebilir. Flow'un kendisinin kapandığını anlamak için bunun yerine `onDisappeared` kullanın.
