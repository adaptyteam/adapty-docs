Observer mode'da Adapty SDK, mevcut satın alma sisteminiz üzerinden gerçekleştirilen işlemleri kendi başına takip edemez. Uygulama mağazasındaki işlemleri kendiniz bildirmeniz gerekir. Analitik hatalarını önlemek için bunu uygulamanızı yayınlamadan **önce** ayarlamanız son derece önemlidir.

Her işlemi Adapty'nin tanıyabilmesi için `reportTransaction` kullanarak açıkça bildirin.

:::warning

**İşlem raporlamayı atlamayın!**
`reportTransaction` çağırmazsanız Adapty işlemi tanımaz, işlem analizlerde görünmez ve entegrasyonlara gönderilmez.

:::

Adapty paywall'larını kullanıyorsanız, işlemi raporlarken `variationId` bilgisini ekleyin. Bu, satın almayı tetikleyen paywall ile ilişkilendirir ve paywall analizlerinin doğru olmasını sağlar.

```swift showLineNumbers
do {
    // every time when calling transasction.finish()
    try await Adapty.reportTransaction(transaction, withVariationId: <YOUR_PAYWALL_VARIATION_ID>)
} catch {
    // handle the error
}
```

Parametreler:

| Parametre       | Zorunluluk | Açıklama                                                  |
| --------------- | ---------- | ------------------------------------------------------------ |
| **transaction** | zorunlu | <ul><li> StoreKit 1 için: SKPaymentTransaction.</li><li> StoreKit 2 için: Transaction.</li></ul> |
| **variationId** | isteğe bağlı | Paywall varyantının benzersiz ID'si. `AdaptyPaywall` nesnesinin `variationId` özelliğinden alınabilir. |

</TabItem>

Observer modunda Adapty SDK, mevcut satın alma sisteminiz üzerinden gerçekleştirilen satın almaları kendi başına takip edemez. App Store veya Google Play üzerindeki işlemleri bildirmeniz ya da geri yüklemeniz gerekir. Analytics'te hata oluşmaması için bunu uygulamanızı yayınlamadan **önce** ayarlamanız kritik önem taşır.

İşlem verilerini Adapty'ye göndermek için `reportTransaction` kullanın.

:::warning

**İşlem bildirmeyi atlamayın!**
`reportTransaction` çağırmazsanız Adapty işlemi tanımaz, analytics'te görünmez ve entegrasyonlara iletilmez.

:::

Adapty paywall'larını kullanıyorsanız, bir işlemi bildirirken `withVariationId` parametresini ekleyin. Bu, satın almayı tetikleyen paywall ile ilişkilendirir ve paywall analizlerinin doğru olmasını sağlar.

```swift showLineNumbers
do {
    // every time when calling transasction.finish()
    try await Adapty.reportTransaction(transaction, withVariationId: <YOUR_PAYWALL_VARIATION_ID>)
} catch {
    // handle the error
}
```

Parametreler:

| Parametre       | Zorunluluk | Açıklama                                                  |
| --------------- | -------- | ------------------------------------------------------------ |
| **transaction** | zorunlu | <ul><li> StoreKit 1 için: SKPaymentTransaction.</li><li> StoreKit 2 için: Transaction.</li></ul> |
| **variationId** | isteğe bağlı | Paywall varyantının benzersiz kimliği. `AdaptyPaywall` nesnesinin `variationId` özelliğinden alınabilir. |

</TabItem>

**İşlemleri Raporlama**

- 3.1.x ve önceki sürümler, App Store'daki işlemleri otomatik olarak dinler; dolayısıyla manuel raporlama gerekmez.
- Sürüm 3.2, Observer Mode'u desteklemiyor.

**Paywallları işlemlerle ilişkilendirme**

Adapty SDK, satın almaların kaynağını belirleyemez; çünkü bunları işleyen sizsiniz. Bu nedenle, Observer mode'da paywall ve/veya A/B testi kullanmak istiyorsanız, uygulama mağazanızdan gelen işlemi mobil uygulama kodunuzda ilgili paywall ile ilişkilendirmeniz gerekir. Uygulamanızı yayınlamadan önce bunu doğru şekilde yapmanız önemlidir; aksi takdirde analizlerde hatalara yol açabilir.

```swift 
let variationId = paywall.variationId
// There are two overloads: for StoreKit 1 and StoreKit 2
Adapty.setVariationId(variationId, forPurchasedTransaction: transactionId) { error in
    if error == nil {
        // successful binding
    }    
}
```

İstek parametreleri:

| Parametre     | Zorunluluk | Açıklama                                                  |
| ------------- | ---------- | ------------------------------------------------------------ |
| variationId   | zorunlu | `AdaptyPaywall` nesnesinin `variationId` özelliğini kullanarak elde edebileceğiniz varyasyonun string tanımlayıcısı. |
| transactionId | zorunlu | <p>StoreKit 1 için: bir [SKPaymentTransaction](https://developer.apple.com/documentation/storekit/skpaymenttransaction) nesnesi.</p><p>StoreKit 2 için: [Transaction](https://developer.apple.com/documentation/storekit/transaction) nesnesi.</p> |
