<SDKv4>

Observer mode'da Adapty SDK, mevcut satın alma sisteminiz üzerinden gerçekleştirilen satın almaları kendi başına takip edemez. Uygulama mağazasından gelen işlemleri kendiniz bildirmeniz gerekir. Analytics'te hata oluşmaması için bunu uygulamanızı yayınlamadan **önce** kurmanız kritik önem taşır.

Her işlemi Adapty'nin tanıması için `reportTransaction` kullanarak açıkça bildirin.

:::warning

**İşlem bildirmeyi atlamayın!**
`reportTransaction` çağrısı yapmazsanız Adapty işlemi tanımaz, analytics'te görünmez ve entegrasyonlara gönderilmez.

:::

Adapty flow'ları ve paywall'ları kullanıyorsanız, bir işlemi raporlarken `variationId` değerini ekleyin. Bu, satın almayı tetikleyen flow veya paywall ile ilişkilendirir ve doğru analytics verisi sağlar.

:::warning
Kullanıcının satın aldığı `AdaptyPaywallProduct` nesnesinin `variationId` değerini kullanın; `AdaptyFlow.variationId` değerini değil. Bir flow'un kendi variation ID'si, satın almayı flow ile ilişkilendirmez.
:::

```swift showLineNumbers
do {
    // every time when calling transaction.finish()
    // verificationResult is the VerificationResult<Transaction> StoreKit 2 returns
    try await Adapty.reportTransaction(verificationResult, withVariationId: <YOUR_PAYWALL_VARIATION_ID>)
} catch {
    // handle the error
}
```

Parametreler:

| Parametre       | Zorunluluk | Açıklama                                                  |
| --------------- | -------- | ------------------------------------------------------------ |
| **transaction** | zorunlu | `VerificationResult<Transaction>`, StoreKit 2'nin döndürdüğü haliyle, açmadan önce. Adapty imzalı işlemi sunucuya gönderir. Yalnızca `Transaction` alan aşırı yüklenmiş versiyon, SDK 4.3.2'den itibaren kullanımdan kaldırılmıştır. |
| **variationId** | isteğe bağlı | Paywall varyasyonunun benzersiz kimliği. Kullanıcının satın aldığı `AdaptyPaywallProduct`'ın `variationId` değerini iletin. Bu, söz konusu ürünü içeren `AdaptyFlowPaywall`'ın `variationId` değeriyle aynıdır. |

</SDKv4>

:::warning

**İşlem raporlamayı atlama!**
`reportTransaction` çağırmazsan Adapty işlemi tanımaz, işlem analizlerde görünmez ve entegrasyonlara gönderilmez.

:::

Adapty flow'ları ve paywallları kullanıyorsan, bir işlem raporlarken `variationId`'yi de ekle. Bu, satın almayı tetikleyen flow veya paywall ile ilişkilendirerek analizlerin doğru olmasını sağlar.

```swift showLineNumbers
do {
    // transaction.finish() her çağrıldığında
    // verificationResult, StoreKit 2'nin döndürdüğü VerificationResult<Transaction> değeridir
    try await Adapty.reportTransaction(verificationResult, withVariationId: <YOUR_PAYWALL_VARIATION_ID>)
} catch {
    // hatayı işle
}
```

Parametreler:

| Parametre       | Zorunluluk | Açıklama                                                  |
| --------------- | -------- | ------------------------------------------------------------ |
| **transaction** | zorunlu | <ul><li> StoreKit 1 için: SKPaymentTransaction.</li><li> StoreKit 2 için: `Transaction` veya SDK 3.12.0 ve sonrasında, StoreKit'in döndürdüğü şekliyle, unwrap etmeden önce `VerificationResult<Transaction>`.</li></ul> |
| **variationId** | isteğe bağlı | Paywall varyantının benzersiz ID'si. `AdaptyPaywall` nesnesinin `variationId` özelliğinden alınır. |

Observer modunda, Adapty SDK mevcut satın alma sisteminiz üzerinden yapılan satın almaları kendi başına takip edemez. App store'dan işlemleri bildirmeniz veya geri yüklemeniz gerekir. Analytics'teki hataları önlemek için bunu uygulamanızı yayınlamadan **önce** kurmanız çok önemlidir.

İşlem verilerini Adapty'ye göndermek için `reportTransaction` kullanın.

:::warning

**İşlem raporlamayı atlama!**
`reportTransaction` çağrısı yapmazsanız, Adapty işlemi tanımaz; işlem ne analizlerde görünür ne de entegrasyonlara iletilir.

:::

Adapty flow'ları ve paywallları kullanıyorsanız, bir işlem raporlarken `withVariationId` parametresini ekleyin. Bu, satın almayı tetikleyen flow veya paywall ile ilişkilendirir ve doğru analizler sağlar.

```swift showLineNumbers
do {
    // transasction.finish() her çağrıldığında
    try await Adapty.reportTransaction(transaction, withVariationId: <YOUR_PAYWALL_VARIATION_ID>)
} catch {
    // hatayı işle
}
```

Parametreler:

| Parametre       | Zorunluluk | Açıklama                                                  |
| --------------- | -------- | ------------------------------------------------------------ |
| **transaction** | zorunlu | <ul><li> StoreKit 1 için: SKPaymentTransaction.</li><li> StoreKit 2 için: Transaction.</li></ul> |
| **variationId** | isteğe bağlı | Paywall varyantının benzersiz kimliği. `AdaptyPaywall` nesnesinin `variationId` özelliğinden alınabilir. |

**İşlemleri Raporlama**

- 3.1.x'e kadar olan sürümler App Store'daki işlemleri otomatik olarak dinler, dolayısıyla manuel raporlama gerekmez.
- 3.2 sürümü Observer Mode'u desteklememektedir.

**Flow'ları ve paywall'ları işlemlerle ilişkilendirme**

Adapty SDK, satın almaların kaynağını belirleyemez; bu işlemi siz yapıyorsunuz. Bu nedenle, Observer modunda flow'lar, paywall'lar ve/veya A/B testleri kullanmayı planlıyorsanız, uygulama mağazanızdan gelen işlemi (transaction) mobil uygulama kodunuzda ilgili flow veya paywall ile ilişkilendirmeniz gerekir. Uygulamanızı yayınlamadan önce bunu doğru şekilde yapmanız önemlidir; aksi takdirde analizlerde hatalara yol açar.

```swift 
let variationId = paywall.variationId
// There are two overloads: for StoreKit 1 and StoreKit 2
Adapty.setVariationId(variationId, forPurchasedTransaction: transactionId) { error in
    if error == nil {
        // successful binding
    }    
}
```

İstek parametreleri:

| Parametre     | Zorunluluk | Açıklama                                                  |
| ------------- | ---------- | ------------------------------------------------------------ |
| variationId   | zorunlu | `AdaptyPaywall` nesnesinin `variationId` özelliğini kullanarak elde edebileceğiniz varyasyonun string tanımlayıcısı. |
| transactionId | zorunlu | <p>StoreKit 1 için: bir [SKPaymentTransaction](https://developer.apple.com/documentation/storekit/skpaymenttransaction) nesnesi.</p><p>StoreKit 2 için: [Transaction](https://developer.apple.com/documentation/storekit/transaction) nesnesi.</p> |
