Adapty Mail bir MCP sunucusu çalıştırır; böylece bir yapay zeka asistanı, kontrol panelinde yaptığınız gibi projenizde çalışabilir: kampanyalar oluşturur ve yerelleştirir, flow'lar başlatır, gönderme alan adı ayarlar, profillere bakar ve analizleri okur. Asistan kendi Adapty Mail hesabınızla oturum açar ve siz kontrol panelinde bağlantıyı onayladıktan sonra izinlerinizi alır. API anahtarına gerek yoktur.

| | |
|---|---|
| Sunucu URL'si | `https://api-mail.adapty.io/mcp` |
| Protokol | MCP over Streamable HTTP, OAuth 2.1 girişi |
| Şununla çalışır | Claude (web ve masaüstü), ChatGPT, Claude Code, Codex CLI, GitHub Copilot CLI, Gemini CLI, Cursor, Windsurf ve OAuth destekli uzak MCP sunucularıyla uyumlu her istemci |

:::tip
Bir kodlama ajanında en iyi sonuçları almak için [Adapty Mail skill](mail-skill)'ini de ekleyin. Sunucuyu sizin için bağlar, gerçek kişilere e-posta gönderecek her işlemden önce onay ister ve lansman sonrası süreçleri kapsar: sonuçlar, A/B testleri ve birinin neden e-posta almadığı.
:::

## Asistanın yapabilecekleri \{#what-the-assistant-can-do\}

Sunucunun araçları kontrol paneliyle birebir örtüşür:

| Alan | Örnekler |
|---|---|
| Yönlendirme | Şirketlerinizi ve projelerinizi bulun, eksik kurulum adımlarını görün |
| Marka | Mağaza listelemesinden marka oluşturun, inceleyin ve düzenleyin |
| Gönderme alanları | Alan adı ekleyin, DNS kayıtlarını alın, doğrulamayı kontrol edin, alan adı sağlığını okuyun |
| Hedefler | E-postalarınızın bağlandığı sayfaları oluşturun ve güncelleyin |
| Kampanyalar | Bir özetten kampanya oluşturun, e-postaları düzenleyin, çevirin, test e-postası gönderin |
| Flow'lar ve segmentler | Segmentler oluşturun, flow başlatın veya değiştirin |
| A/B testleri | Testler oluşturun, başlatın ve sonlandırın |
| Profiller | Bir profili ve yolculuğunu arayın, profili abonelikten çıkarın |
| Analitik | Zaman içinde kampanya metrikleri, dökümleri, A/B testi hunileri |
| Ayarlar | Gönderen adı, yanıt adresi, çift opt-in, görsel yüklemeleri |

MCP istemcilerinde prompt olarak üç yönlendirmeli iş akışı mevcuttur. Claude Code'da `/mcp__adaptymail__campaign_to_flow` gibi slash komutları olarak görünürler:

- **campaign_to_flow**: Bir özetten kampanya oluşturun, hedef ve segment seçin, flow'u başlatın.
- **campaign_localization**: Kaydedilmiş bir kampanyayı daha fazla dile çevirin.
- **domain_onboarding**: Gönderici domain ekleyin, DNS kayıtlarını yayınlayın ve doğrulayın.

Bazı kurulum adımları yalnızca kontrol panelinde yapılır: [şirket adresiniz](mail-get-started#5-add-your-company-address), [web checkout](mail-checkout) ve [veri göndermeyi etkinleştirme](mail-entry-points).

## Başlamadan önce \{#before-you-start\}

- **Proje üyeliği**: Adapty Mail hesabınız, üzerinde çalışmak istediğiniz projenin üyesidir. Asistan yalnızca hesabınızın erişebildiği şirketleri ve projeleri görebilir.
- **İstemci desteği**: İstemciniz OAuth ile uzak MCP sunucularını desteklemektedir.

:::warning
Asistan sizinle aynı yetkilere sahiptir ve yaptığı her şey gerçektir: bir flow'u kaydetmek gerçek kişilere e-posta gönderilmeye başlaması anlamına gelir. Sunucu, yıkıcı araçlarını işaretler; test ettiğimiz asistanlar bu araçları çalıştırmadan önce onay ister. Onaylamadan önce asistanın planını okuyun.
:::

## Asistanınızı bağlayın \{#connect-your-assistant\}

### Claude (claude.ai ve Claude desktop)

1. Sunucuyu eklemek için **Settings → Connectors** bölümünü açın ve **Add custom connector** düğmesine tıklayın.
2. Bir ad girin, örneğin `Adapty Mail`, ve URL olarak `https://api-mail.adapty.io/mcp` yazın.
3. **Authentication** ayarını **Sign in now** olarak bırakın ve OAuth istemcisini algılanan varsayılan değerde tutun, ardından **Add** düğmesine tıklayın.
4. Açılan Adapty Mail sekmesinde istenirse giriş yapın ve **Approve** düğmesine tıklayın.

Çalışma alanı yöneticileri bu bağlayıcıyı tüm organizasyon için bir kez ekleyebilir. Her üye, ilk kullanımda kendi Adapty Mail hesabıyla giriş yapar.

### ChatGPT

ChatGPT, **Settings** sayfasındaki bağlayıcılar bölümünden özel MCP sunucuları ekler. Çalışma alanınızda geliştirici modunun etkinleştirilmiş olması gerekir.

1. Sunucuyu eklemek için **Create** düğmesine tıklayın.
2. Bir ad girin, örneğin `Adapty Mail`, ve sunucu URL'sini `https://api-mail.adapty.io/mcp` olarak ayarlayın. **Authentication** ayarını **OAuth** olarak bırakın.
3. Özel MCP sunucusu uyarısını kabul edin ve **Create** düğmesine tıklayın.
4. ChatGPT sorduğunda sunucuyu bağlayın. Açılan Adapty Mail sekmesinde gerekirse oturum açın ve **Approve** düğmesine tıklayın.

### Claude Code

```bash
claude mcp add --transport http --scope user adaptymail https://api-mail.adapty.io/mcp
```

Oturum açmak için Claude Code'da `/mcp` komutunu çalıştırın, `adaptymail` seçeneğini seçin ve **Authenticate** üzerine tıklayın. Ardından tarayıcınızda Adapty Mail kontrol paneline giriş yapın ve **Approve** butonuna tıklayın.

### Codex CLI

```bash
codex mcp add adaptymail --url https://api-mail.adapty.io/mcp
codex mcp login adaptymail
```

Giriş komutu tarayıcınızı açar; burada bağlantıyı onaylarsınız. Sunucuyu manuel olarak yapılandırmak için `~/.codex/config.toml` dosyasına ekleyin, ardından giriş komutunu çalıştırın:

```toml
[mcp_servers.adaptymail]
url = "https://api-mail.adapty.io/mcp"
```

### GitHub Copilot CLI

```bash
copilot mcp add --transport http adaptymail https://api-mail.adapty.io/mcp
```

Sunucu ilk kez bağlandığında, tarayıcınız oturum açma için açılır.

### Gemini CLI

```bash
gemini mcp add --transport http --scope user adaptymail https://api-mail.adapty.io/mcp
```

Yeni bir oturum başlatın, ardından `/mcp auth adaptymail` komutunu çalıştırın ve tarayıcınızda bağlantıyı onaylayın.

### Cursor, Windsurf ve diğer istemciler

Sunucuyu istemcinin MCP yapılandırma dosyasına ekleyin, örneğin `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "adaptymail": {
      "url": "https://api-mail.adapty.io/mcp"
    }
  }
}
```

İstemci ilk bağlandığında tarayıcınızı oturum açmak için açar. Uzak sunucular için OAuth desteklemeyen istemciler Adapty Mail'e bağlanamaz.

## Bağlantıyı onaylayın \{#approve-the-connection\}

Her istemci, Adapty Mail kontrol panelinde aynı ekranda sona erer. Bu ekranda, erişim isteyen uygulama adı ve uygulamanın bu erişimi alacağı adres gösterilir. Masaüstü araçlar için bu adres kendi bilgisayarınızdadır (`localhost`), bu nedenle yalnızca kendiniz başlattığınız bir bağlantıyı onaylayın. Tamamlamak için **Approve** düğmesine tıklayın.

Bağlantı isteği 10 dakika sonra sona erer. Ekranda **This request has expired** yazıyorsa istemciden yeniden başlayın.

## Çalışmaya Başla \{#start-working\}

Asistana projelerinizi listeletmesini isteyin, ardından üzerinde çalışmak istediğiniz projeyi adlandırın. Deneyebileceğiniz bazı istekler:

- "Projemin onboarding durumunu göster ve neyin eksik olduğunu söyle."
- "Denemesi sona eren kullanıcılar için İngilizce bir geri kazanma kampanyası oluştur ve bana ilk e-postayı göster."
- "Deneme süresi sona erdi kampanyasını Almanca ve Fransızcaya çevir."
- "`mail.example.com` adresini gönderme etki alanı olarak ekle ve DNS kayıtlarını ver."
- "Son 30 gün için yayındaki kampanyalarımın açılma ve tıklanma oranlarını karşılaştır."

## Bağlantıyı Kesme \{#disconnect\}

Bağlantıyı kesmek için istemcinin ayarlarından bağlayıcıyı kaldırın. Claude'da bu **Settings → Connectors** bölümünde, ChatGPT'de bağlayıcının sayfasında; Claude Code'da ise `claude mcp remove adaptymail` komutunu çalıştırarak yapılır.

İstemcinin erişim tokenı bir saat içinde sona erer. Yenileme tokenı, istemci bağlantıyı kestiğinde iptal edilir; kullanılmayan bir token ise 90 gün sonra sona erer. Yeniden bağlanmak için sunucuyu tekrar ekleyin ve bağlantıyı bir kez daha onaylayın.

## Sorun Giderme \{#troubleshooting\}

| Sorun | Çözüm |
|---|---|
| Kontrol paneli, bağlantı isteğinin süresi doldu diyor | Bağlantıyı istemciden yeniden başlatın ve 10 dakika içinde onaylayın. |
| Asistan projenin bulunamadığını söylüyor | Hesabınız o projenin üyesi değil. Erişim için şirket sahibinden yardım isteyin. |
| Asistanın oturumu kapandı | Uzun süre boşta kalındığında veya bağlantı kesildiğinde erişim sona erer. İstemciden yeniden bağlanın. |
| İstemci hiç araç listelemiyor | İstemci oturum açılmadan bağlandı. Oturum açma adımını çalıştırın; örneğin Claude Code'da `/mcp` komutunu kullanın. |
