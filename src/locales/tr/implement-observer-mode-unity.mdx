Halihazırda kendi satın alma altyapınız varsa ve Adapty'ye tam olarak geçmeye hazır değilseniz, [Observer mode](observer-vs-full-mode)'u inceleyebilirsiniz. Temel haliyle Observer Mode, gelişmiş analitik ve attribution ile analitik sistemleriyle sorunsuz entegrasyon sunar.

Eğer bu ihtiyaçlarınızı karşılıyorsa, yalnızca şunları yapmanız yeterlidir:
1. Adapty SDK'yı yapılandırırken `observerMode` parametresini `true` olarak ayarlayarak bu özelliği etkinleştirin. Kurulum talimatları için [Unity](sdk-installation-unity#activate-adapty-module-of-adapty-sdk) sayfasına bakın.
2. Mevcut satın alma altyapınızdan Adapty'ye [işlemleri bildirin](report-transactions-observer-mode-unity).

:::tip
SDK v4'te, Adapty tarafından render edilen flow'ları ve paywall'ları Observer modunda da sunabilirsiniz: `IAdaptyUIObserverModeResolver` uygulayın ve bir kullanıcı ilgili düğmeye dokunduğunda kendi kodunuzla satın alma veya geri yükleme işlemi gerçekleştirmek için `SetObserverModeResolver` ile kaydedin. Bkz. [Flow'ları Observer modunda sunma](unity-present-flows-in-observer-mode).
:::

### Observer modu kurulumu

Satın alma işlemlerini ve abonelik durumunu kendiniz yönetiyorsanız ve Adapty'yi yalnızca abonelik olayları ile analitik göndermek için kullanıyorsanız Observer modunu açın.

:::important
Observer modunda çalışırken Adapty SDK hiçbir işlemi kapatmaz; bu nedenle işlemleri kendiniz yönettiğinizden emin olun.
:::

:::note
SDK 4.0'da listener arayüzleri C# I-ön eki kuralını izler: `AdaptyEventListener` yerine `IAdaptyEventListener` uygulayın. Metodlar değişmemiştir. [Geçiş rehberine](migration-to-unity-sdk-v4) bakın.
:::

```csharp showLineNumbers title="C#"
using UnityEngine;
using AdaptySDK;

public class AdaptyListener : MonoBehaviour, AdaptyEventListener {
    void Start() {
        DontDestroyOnLoad(this.gameObject);
        Adapty.SetEventListener(this);

        var builder = new AdaptyConfiguration.Builder("YOUR_PUBLIC_SDK_KEY")
            .SetObserverMode(true); // Enable observer mode

        Adapty.Activate(builder.Build(), (error) => {
            if (error != null) {
                // handle the error
                return;
            }
        });
    }

    public void OnLoadLatestProfile(AdaptyProfile profile) { }
    public void OnInstallationDetailsSuccess(AdaptyInstallationDetails details) { }
    public void OnInstallationDetailsFail(AdaptyError error) { }
}
```

Parametreler:

| Parametre    | Açıklama                                                                                                   |
|--------------|------------------------------------------------------------------------------------------------------------|
| observerMode | [Observer modu](observer-vs-full-mode)'nu kontrol eden boolean değer. Varsayılan değer `false`'tur. |

## Observer Mode'da Adapty flow'larını ve paywalllarını kullanma \{#using-adapty-paywalls-in-observer-mode\}

Adapty'nin flow'larını, paywalllarını ve A/B testi özelliklerini de kullanmak istiyorsanız bunu yapabilirsiniz; ancak Observer Mode'da bunun için birkaç ek adım gereklidir. Yukarıdaki adımlara ek olarak yapmanız gerekenler:

1. [Remote config paywall'larını](present-remote-config-paywalls-unity) her zamanki gibi görüntüleyin. Flow Builder'da oluşturulan flow'lar ve paywall'lar için [Observer modunda flow'ları sunma](unity-present-flows-in-observer-mode) bölümüne bakın.
2. Flow'ları ve paywall'ları satın alma işlemleriyle [ilişkilendirin](report-transactions-observer-mode-unity).
