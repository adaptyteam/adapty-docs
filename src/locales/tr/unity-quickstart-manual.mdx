Bu rehber, Adapty'yi özel paywalllarınıza nasıl entegre edeceğinizi açıklar. Paywall uygulaması üzerinde tam kontrolü elinizde tutarken Adapty SDK ürünleri getirir, yeni satın almaları yönetir ve önceki satın almaları geri yükler. Bu rehber Adapty Unity SDK v4 (beta) API'lerini kullanır — v3 kullanıyorsanız ilgili metod isimlerini öğrenmek için [migration guide](migration-to-unity-sdk-v4) sayfasına bakın.

:::important
**Bu kılavuz, özel paywall'lar uygulayan geliştiriciler içindir.** Satın alımları etkinleştirmenin en kolay yolunu arıyorsanız, [Adapty Flow & Paywall Builder](unity-quickstart-paywalls)'ı kullanın. Flow & Paywall Builder ile flow'larınızı no-code görsel editörde oluşturursunuz, Adapty tüm satın alma mantığını otomatik olarak yönetir ve uygulamanızı yeniden yayımlamadan farklı tasarımları test edebilirsiniz.
:::

## Başlamadan önce \{#before-you-start\}

### Ürünleri ayarlama \{#set-up-products\}

Uygulama içi satın almaları etkinleştirmek için üç temel kavramı anlamanız gerekir:

- [**Ürünler**](product) – kullanıcıların satın alabildiği her şey (abonelikler, consumable'lar, süresiz erişim)
- [**Özel paywalllar**](paywalls) – hangi ürünlerin sunulacağını tanımlayan yapılandırmalar. Adapty'de paywalllar, ürünleri almanın tek yoludur; ancak bu tasarım sayesinde uygulama koduna dokunmadan ürünleri, fiyatları ve teklifleri değiştirebilirsiniz. SDK v4'te bir placement için paywall varyasyonları bir **flow** nesnesi tarafından taşınır — bir flow çeker ve içindeki ürünleri sorgularsınız.
- [**Placement'lar**](placements) – uygulamanızda paywallları nerede ve ne zaman gösterdiğiniz (`main`, `onboarding`, `settings` gibi). Kontrol panelinde placement'lar için paywallları ayarlarsınız, ardından kodunuzda placement ID'si ile bunları talep edersiniz. Bu, A/B testleri çalıştırmayı ve farklı kullanıcılara farklı paywalllar göstermeyi kolaylaştırır.

Bu kavramları, kendi özel paywallınızla çalışsanız bile anladığınızdan emin olun. Bunlar, temelde uygulamanızda sattığınız ürünleri yönetmenin bir yoludur.

Özel paywallınızı uygulamak için bir **custom paywall** oluşturmanız ve bunu bir **placement**'a eklemeniz gerekir. Bu kurulum, ürünlerinizi almanıza olanak tanır. Kontrol panelinde ne yapmanız gerektiğini anlamak için hızlı başlangıç kılavuzunu [buradan](quickstart) takip edin.

### Kullanıcıları yönetme \{#manage-users\}

Kendi tarafınızda backend kimlik doğrulaması ile veya olmadan çalışabilirsiniz.

Ancak Adapty SDK, anonim ve tanımlanmış kullanıcıları farklı şekilde ele alır. Ayrıntıları anlamak ve kullanıcılarla düzgün şekilde çalıştığınızdan emin olmak için [kimlik belirleme hızlı başlangıç kılavuzunu](unity-quickstart-identify) okuyun.

## Adım 1. Ürünleri alın \{#step-1-get-products\}

Özel paywallınız için ürünleri almak üzere şunları yapmanız gerekir:

1. [placement](placements) ID'sini `GetFlow` metoduna geçirerek `flow` nesnesini alın.
2. Bu flow için ürünler dizisini `GetPaywallProducts` metodunu kullanarak alın.

```csharp showLineNumbers
using AdaptySDK;

void LoadPaywall() {
    Adapty.GetFlow("YOUR_PLACEMENT_ID", (flow, error) => {
        if (error != null) {
            // Handle the error
            return;
        }

        Adapty.GetPaywallProducts(flow, (products, productsError) => {
            if (productsError != null) {
                // Handle the error
                return;
            }

            // Use products to build your custom paywall UI
        });
    });
}
```

## Adım 2. Satın almaları kabul etme \{#step-2-accept-purchases\}

Kullanıcı özel paywallınızdaki bir ürüne dokunduğunda, seçilen ürünle birlikte `MakePurchase` metodunu çağırın. Bu işlem satın alma akışını yönetir ve güncellenmiş profili döndürür.

```csharp showLineNumbers
using AdaptySDK;

void PurchaseProduct(AdaptyPaywallProduct product) {
    Adapty.MakePurchase(product, (result, error) => {
        if (error != null) {
            // Handle the error
            return;
        }

        switch (result.Type) {
            case AdaptyPurchaseResultType.Success:
                var profile = result.Profile;
                // Purchase successful, profile updated
                break;
            case AdaptyPurchaseResultType.UserCancelled:
                // User canceled the purchase
                break;
            case AdaptyPurchaseResultType.Pending:
                // Purchase is pending (e.g., user will pay offline with cash)
                break;
        }
    });
}
```

## Adım 3. Satın almaları geri yükle \{#step-3-restore-purchases\}

Uygulama mağazaları, abonelik içeren tüm uygulamaların kullanıcılara satın almalarını geri yükleme imkânı sunmasını zorunlu kılar.

Kullanıcı geri yükleme düğmesine bastığında `RestorePurchases` metodunu çağırın. Bu işlem, satın alma geçmişini Adapty ile senkronize eder ve güncellenmiş profili döndürür.

```csharp showLineNumbers
using AdaptySDK;

void RestorePurchases() {
    Adapty.RestorePurchases((profile, error) => {
        if (error != null) {
            // Handle the error
            return;
        }

        // Restore successful, profile updated
    });
}
```

## Adım 4. Abonelik durumunu kontrol edin \{#step-4-check-the-subscription-status\}

Bir satın alma veya geri yükleme işleminin ardından, paywall'ı gösterip göstermeyeceğinize veya ücretli özelliklerin kilidini açıp açmayacağınıza karar vermek için kullanıcının [access level](access-level) değerini kontrol edin. `MakePurchase` ve `RestorePurchases` metodları zaten güncellenmiş profili döndürür; uygulamanın başka bir yerinde mevcut duruma ihtiyaç duyduğunuzda `GetProfile` metodunu kullanın:

```csharp showLineNumbers
using AdaptySDK;

void CheckPremiumAccess() {
    Adapty.GetProfile((profile, error) => {
        if (error != null) {
            // Handle the error
            return;
        }

        var hasPremiumAccess =
            profile.AccessLevels.TryGetValue("premium", out var premium) && premium.IsActive;
        // Grant access to paid features if hasPremiumAccess is true
    });
}
```

Abonelik durumunu kontrol etmenin ve gerçek zamanlı güncellemeleri dinlemek de dahil olmak üzere izlemenin daha fazla yolu için bkz. [Abonelik durumunu kontrol etme](unity-check-subscription-status).
