Bir kullanıcının belirli ücretli içeriklere erişip erişemeyeceğini belirlerken access level'ını doğrulamanız gerekir. Bu, kullanıcının en az bir access level'a sahip olup olmadığını ve bu seviyenin gerekli olan seviye olup olmadığını kontrol etmek anlamına gelir.

Kullanıcı profilini kontrol ederek bunu yapabilirsiniz; profil, mevcut tüm access level'ları içerir.

Şimdi kullanıcıların ürününüzü satın almasına izin verelim:

1. Ücretli içeriği göstermesi gereken butona çift tıklayın ve sağ panelde **Actions** bölümü açık değilse açın.

2. **Action Flow Editor**'ı açın.

3. **Select Action Trigger** penceresinde **On Tap** seçeneğini seçin.

4. **No Actions Created** penceresinde **Add Conditional Action** düğmesine tıklayın.

5. Eylem argümanlarını ayarlamak için **UNSET** seçeneğine tıklayın ve `currentProfile` değişkenini seçin. Bu, mevcut kullanıcının profil verilerini tutan Adapty değişkenidir.

6. Alanları aşağıdaki gibi doldurun:
- **Available Options**: Data Structure Field
- **Select Field**: accessLevels
- **Available Options**: Filter List Items
- **Filter Conditions**: 
  1. **Conditions -> Single Condition** seçin ve **UNSET** düğmesine tıklayın.
  2. **First value** alanında **Source** olarak **Item in list** seçin ve alanları aşağıdaki gibi doldurun:
     - **Available Options**: Data Structure Field
     - **Select Field**: accessLevelIdentifier
  3. Filtre operatörünü **Equal to** olarak ayarlayın.
  4. **Second value** alanının yanındaki **UNSET** düğmesine tıklayın ve **Value** alanına access level'ınızın ID'sini girin; örneğimizde `premium` kullanıyoruz.
     <Zoom>
     <img src="/assets/shared/img/ff-filter.webp"
     style={{
     border: '1px solid #727272', /* border width and color */
     width: '500px', /* image width */
     display: 'block', /* for alignment */
     margin: '0 auto' /* center alignment */
     }}
     />
     </Zoom>
  5. **Confirm** düğmesine tıklayın ve aşağıdaki diğer alanları doldurmaya devam edin.
- **Available Options**: Item at Index
- **List Index Options**: First
- **Available Options**: Data Structure Field
- **Select Field**: accessLevel
- **Available Options**: Data Structure Field
- **Select Field**: isActive

7. **Onayla**'ya tıklayın.

Şimdi, bundan sonra ne olacağına dair eylemleri ekleyin — kullanıcının doğru aboneliğe sahip olup olmadığına göre. Ya premium abonelere açık sayfaya yönlendirin ya da erişim satın alabilmeleri için paywall sayfasını açın.
