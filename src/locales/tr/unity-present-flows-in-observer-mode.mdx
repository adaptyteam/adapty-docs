[Observer mode](observer-vs-full-mode) kullanıyorsanız kendi satın alma mantığınızdan siz sorumlusunuz. Ancak paywall arayüzünü [Flow & Paywall Builder](adapty-flow-builder)'a devredebilirsiniz.

Builder'da ekranı tasarlayın, Adapty SDK bunu doğal olarak render eder. Metin, düzen ve fiyatlandırmayı istediğiniz zaman güncelleyin; uygulama güncellemesi gerekmez.

Bu rehber, bir flow'un nasıl sunulacağını ve satın alma callback'lerinin nasıl ele alınacağını gösterir. Satın alma işlemlerini Adapty sizin için tamamlıyorsa bunun yerine [Flow ve paywall görüntüleme](unity-present-paywalls) bölümüne bakın.

## Başlamadan önce \{#before-you-start\}

Şunlara ihtiyacınız var:

- **Adapty Unity SDK 4.1 veya üzeri**: Daha eski sürümler flow'ları render edemez. Mevcut bir uygulamayı taşımak için [migration rehberine](migration-to-unity-sdk-v4) bakın.
- **Yapılandırma builder'ında `SetObserverMode(true)` çağrısı**: [Unity SDK kurulum rehberine](sdk-installation-unity#activate-adapty-module-of-adapty-sdk) bakın.
- **İlk mağaza entegrasyonu**: Adapty'yi [App Store ile](initial_ios) ve [Google Play ile](initial-android) kurun.
- **Ürünleri olan yayınlanmış bir flow**: [Flow & Paywall Builder](adapty-flow-builder)'da oluşturun ve [ürünleri](create-product) atayın.
- **Bir flow placement'ı**: [Placement oluşturun](create-placement) ve flow'unuzu ona atayın.
- **Uygulamanızda fetch edilmiş flow**: Sunmadan önce [flow'u ve yapılandırmasını alın](unity-get-pb-paywalls).

## Uygulama \{#implementation\}

Observer modunda SDK, satın alma işlemlerini sizin yerinize gerçekleştirmez. Kullanıcı, Adapty tarafından render edilen bir flow içinde satın alma veya geri yükleme butonuna dokunduğunda SDK, sizin `IAdaptyUIObserverModeResolver` implementasyonunuzu çağırır — satın alma veya geri yükleme işlemini orada kendi kodunuzla gerçekleştirin.

1. `IAdaptyUIObserverModeResolver` arayüzünü implemente edin:

   ```csharp showLineNumbers
   using System;
   using AdaptySDK;

   public class MyObserverModeResolver : IAdaptyUIObserverModeResolver
   {
       public void FlowViewDidInitiatePurchase(
           AdaptyUIFlowView view,
           AdaptyPaywallProduct product,
           Action onStartPurchase,
           Action onFinishPurchase
       )
       {
           onStartPurchase(); // the view shows its loading indicator
           // make the purchase with your own code,
           // then report the transaction to Adapty and call:
           onFinishPurchase(); // the view hides the loading indicator
       }

       public void FlowViewDidInitiateRestore(
           AdaptyUIFlowView view,
           Action onStartRestore,
           Action onFinishRestore
       )
       {
           onStartRestore();
           // restore purchases with your own code, then:
           onFinishRestore();
       }
   }
   ```

`FlowViewDidInitiatePurchase` metodu, kullanıcının bir satın alma işlemi başlattığını; `FlowViewDidInitiateRestore` ise kullanıcının bir geri yükleme işlemi başlattığını bildirir. Buna yanıt olarak özel satın alma veya geri yükleme flow'unuzu tetikleyin.

   Ayrıca AdaptyUI'ı satın alma veya geri yükleme süreci hakkında bilgilendirmek için aşağıdaki callback'leri çağırmayı unutmayın. Bu, yükleyiciyi göstermek gibi doğru flow davranışı için gereklidir:

| Callback           | Açıklama                                                                                          |
   | :----------------- | :------------------------------------------------------------------------------------------------ |
   | onStartPurchase()  | Satın alma işleminin başladığını AdaptyUI'ya bildirmek için bu callback çağrılmalıdır.  |
   | onFinishPurchase() | Satın alma işleminin tamamlandığını AdaptyUI'ya bildirmek için bu callback çağrılmalıdır. |
   | onStartRestore()   | Geri yükleme işleminin başladığını AdaptyUI'ya bildirmek için bu callback çağrılmalıdır.   |
   | onFinishRestore()  | Geri yükleme işleminin tamamlandığını AdaptyUI'ya bildirmek için bu callback çağrılmalıdır.  |

Flow, kodunuz çalışırken açık kalır — başarılı bir satın alma veya restore işleminin ardından onu kendiniz kapatmanız gerekir.

2. Herhangi bir ekran göstermeden önce resolver'ı kaydedin:

   ```csharp showLineNumbers
   Adapty.SetObserverModeResolver(new MyObserverModeResolver());
   ```

   Kayıtlı bir resolver olmadan, flow görünümünün satın alma işlemini kodunuza iletmesinin hiçbir yolu yoktur ve kullanıcı satın alma düğmesine dokunduğunda hiçbir şey olmaz.

3. Flow view'ı her zamanki gibi oluşturun ve sunun: [flow'u alın ve view'ını oluşturun](unity-get-pb-paywalls), ardından [sunun](unity-present-paywalls). Ek parametre gerekmez — resolver kaydedildikten sonra, Adapty'nin render ettiği her flow, satın alma ve geri yükleme işlemlerini bu resolver üzerinden yönlendirir.

:::warning
[İşlemi bildirmeyi ve paywall ile ilişkilendirmeyi](report-transactions-observer-mode-unity) unutmayın. Aksi takdirde Adapty işlemi tanımaz ve satın almanın kaynak paywall'ını belirleyemez.
:::
