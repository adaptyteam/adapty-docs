[ads-manager skill](https://github.com/adaptyteam/adapty-sdk-integration-skill), AI kodlama aracınıza `adapty asa` komutları aracılığıyla Apple Ads'i yönetmeyi öğretir. Komutların hangi sırayla çalıştığını, herhangi bir şey yazmadan önce neyin okunması gerektiğini ve hangi çağrıların para harcadığını bilir.

**Desteklenen araçlar**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Skill, Adapty CLI'yi kullandığı için önce CLI'yi kurun ve kimlik doğrulaması yapın — bkz. [hızlı başlangıç kılavuzu](developer-cli-quickstart). `adapty asa` komutları **Adapty CLI 0.4.0 ve sonrasında** mevcuttur; eski bir sürümde bu komutlar hiç bulunmaz. `adapty asa whoami` ile kontrol edin; bu komut aynı zamanda bir Apple Ads hesabının bağlı olup olmadığını ve şirketin aktif bir Ads Manager aboneliğine sahip olup olmadığını da gösterir.

Kurumsal bir Cowork çalışma alanında, bir yöneticinin domain izin listesine hem `adapty.io` hem de `*.adapty.io` adreslerini eklemesi gerekir. Her ikisini de listeleyin: çoğu izin listesi uygulamasında wildcard, apex domaini kapsamaz ve skill'in okuduğu belgeler apex domaininde bulunur. Her ikisi de izin listesine alınmadan skill Adapty'e ulaşamaz.

Kurulum için aracınıza uygun formu seçin. Tam liste [skill README](https://github.com/adaptyteam/adapty-sdk-integration-skill) dosyasında bulunmaktadır.

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

Bu eklenti aynı zamanda SDK entegrasyon skill'ini de içerir. Her ikisi birlikte yüklenir.

**GitHub Copilot CLI**

```bash
git clone https://github.com/adaptyteam/adapty-sdk-integration-skill.git
cp -r adapty-sdk-integration-skill/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```bash
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex veya başka herhangi bir araç** — [skills CLI](https://skills.sh)'yi kullanın (bu şekilde yüklenen skill'lerin otomatik güncellenmediğini unutmayın):

```bash
npx skills add adaptyteam/adapty-sdk-integration-skill --all
```

`--all`, her iki skill'i de tespit ettiği tüm agent'lara yükler. Yalnızca bu skill için `--skill ads-manager` kullanın.

Alternatif olarak, repoyu klonlayıp `skills/` altındaki dizinleri aracınızın skills dizinine kopyalayabilirsiniz — ya da yalnızca bunu istiyorsanız `skills/ads-manager/` dizinini.

Kurduktan sonra, projenizde skill'i çalıştırın:

```bash
/ads-manager
```

Metrikleri okumak ve kuru çalıştırmalar (dry run) ücretsizdir. Diğer her komut saniyeler içinde Apple'a ulaşır, gerçek para harcar ve geri alınamaz — skill her birinden önce onay ister; siz de öyle yapmalısınız.
