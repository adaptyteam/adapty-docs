[ads-manager skill](https://github.com/adaptyteam/adapty-sdk-integration-skill), AI kodlama aracınıza `adapty asa` komutları aracılığıyla Apple Ads yönetimini öğretir. Komutların hangi sırayla birleştiğini, herhangi bir yazma işleminden önce nelerin okunması gerektiğini ve hangi çağrıların para harcadığını bilir.

**Desteklenen araçlar**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Skill, Adapty CLI'yi kullandığı için önce CLI'yi kurup kimlik doğrulamasını yapmanız gerekir — bkz. [hızlı başlangıç kılavuzu](developer-cli-quickstart). `adapty asa` komutları **Adapty CLI 0.4.0 ve sonraki sürümlerle** birlikte gelir; daha eski bir sürümde bu komutlar hiç mevcut değildir. `adapty asa whoami` ile kontrol edebilirsiniz; bu komut aynı zamanda bir Apple Ads hesabının bağlı olup olmadığını ve şirketin aktif bir Ads Manager aboneliğine sahip olup olmadığını da gösterir.

Claude Cowork, CLI'yi yalnızca izin listesindeki alan adlarına erişime izin veren bir sandbox ortamında çalıştırır. Skill'i buraya kurmadan önce Adapty alan adlarına izin verin — bkz. [CLI'yi Cowork'te Çalıştırma](developer-cli-quickstart#run-the-cli-in-cowork).

Kurulum için kullandığınız araca uygun formu seçin. Tam liste [skill README](https://github.com/adaptyteam/adapty-sdk-integration-skill) dosyasında yer almaktadır.

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

Bu eklenti, SDK entegrasyon skill'ini de içerir. İkisi birlikte kurulur.

**GitHub Copilot CLI**

```bash
git clone https://github.com/adaptyteam/adapty-sdk-integration-skill.git
cp -r adapty-sdk-integration-skill/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```bash
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex veya başka bir araç** — [skills CLI](https://skills.sh)'yi kullanın (bu yolla kurulan skill'lerin otomatik güncellemediğini unutmayın):

```bash
npx skills add adaptyteam/adapty-sdk-integration-skill --all
```

`--all`, her iki skill'i de algıladığı tüm agent'lara kurar. Yalnızca bu skill için `--skill ads-manager` kullanın.

Alternatif olarak, repoyu klonlayıp `skills/` altındaki dizinleri aracınızın skills dizinine kopyalayabilirsiniz — ya da yalnızca bu skill'i istiyorsanız `skills/ads-manager/` dizinini kopyalayın.

Kurulumun ardından skill'i projenizde çalıştırın:

```bash
/ads-manager
```

Metrikleri okumak ve kuru çalıştırmalar ücretsizdir. Diğer tüm komutlar saniyeler içinde Apple'a ulaşır, gerçek para harcar ve geri alınamaz — skill her birinden önce onay ister ve siz de istemelisiniz.
