[ads-manager skill](https://github.com/adaptyteam/adapty-sdk-integration-skill), yapay zeka kodlama aracınıza `adapty asa` komutları aracılığıyla Apple Ads'i yönetmeyi öğretir. Komutların nasıl bir araya geldiğini, herhangi bir şey yazmadan önce nelerin okunması gerektiğini ve hangi çağrıların para harcadığını bilir.

**Desteklenen araçlar**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Skill, Adapty CLI'yi kullandığından önce CLI'yi yükleyip kimlik doğrulamasını yapın — [hızlı başlangıç kılavuzuna](developer-cli-quickstart) bakın.

Kurumsal bir Cowork çalışma alanında, bir yöneticinin `*.adapty.io` adresini alan adı izin listesine eklemesi gerekir. Bu yapılmadan skill, Adapty'e ulaşamaz.

Kurulum için aracınıza uygun formu seçin. Tam liste [skill README](https://github.com/adaptyteam/adapty-sdk-integration-skill) dosyasında bulunmaktadır.

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

Bu eklenti aynı zamanda SDK entegrasyon skill'ini de içerir. Her ikisi birlikte yüklenir.

**GitHub Copilot CLI**

```bash
gh skill install adaptyteam/adapty-sdk-integration-skill
```

**Gemini CLI**

```bash
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex veya başka bir araç** — [skills CLI](https://skills.sh)'yi kullanın (bu şekilde yüklenen skill'ler otomatik güncellenmez):

```bash
npx skills add adaptyteam/adapty-sdk-integration-skill
```

Alternatif olarak, depoyu klonlayın ve `skills/ads-manager/` dizinini aracınızın skills dizinine kopyalayın.

Kurulumdan sonra skill'i projenizde çalıştırın:

```bash
/ads-manager
```

Metrikleri okumak ve kuru çalıştırmalar hiçbir şeye mal olmaz. Diğer tüm komutlar saniyeler içinde Apple'a ulaşır, gerçek para harcar ve geri alınamaz — skill her birinden önce onay ister, siz de öyle yapmalısınız.
