1. **Issuer ID** ve takım anahtarının **Key ID** bilgilerini bulmak için App Store Connect'te [**Users and Access** > **Integrations** > **App Store Connect API**](https://appstoreconnect.apple.com/access/integrations/api) bölümüne gidin ve **Team Keys** sekmesini açın. Anahtarı başkası oluşturmuşsa ve size Issuer ID, Key ID ve dosyayı gönderdiyse bu adımı atlayın.

   <ZoomImage id="asc-team-keys-ids.webp" width="700px" alt="App Store Connect'teki Team Keys sekmesinde takım anahtarının Issuer ID ve Key ID bilgileri" />

2. Adapty'de [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk) bölümüne gidin. **App Store Connect API key** bölümünde **Connect API Key** düğmesine tıklayın.

   <ZoomImage id="app-settings-connect-api-key.webp" width="700px" alt="Adapty'deki App Store Connect API key bölümü ve Connect API Key düğmesi" />

3. Alanları doldurun:
   - **Issuer ID**: App Store Connect'teki **Team Keys** sekmesinden kopyalayın.
   - **Key ID**: **Team Keys** sekmesindeki **Active** listesinde, indirdiğiniz anahtarın yanından kopyalayın.
   - **Private key (.p8 file)**: Takım anahtarı için indirdiğiniz dosyayı yükleyin.

   <ZoomImage id="app-settings-api-key-dialog.webp" width="700px" alt="App Store Connect API anahtarı penceresindeki Issuer ID, Key ID ve Private key (.p8 file) alanları" />

4. Bağlı bir anahtarı daha sonra değiştirebilirsiniz, ancak kaldıramazsınız. Anahtarın bu uygulamanın sahibi olan App Store Connect takımına ait olduğundan emin olun ve **Connect** düğmesine tıklayın. Bundan sonra her **App Store Product ID**'yi yazmak yerine App Store Connect'teki ürünlerinizden seçersiniz.

   Adapty, bağladığınızda anahtarı Apple ile doğrulamaz. Yanlış bir anahtar, anahtar hakkında herhangi bir mesaj vermeden başarısız olur: ürünler App Store durumu göstermez ve **App Store Product ID** açılır menüsü boş kalır. Yanlış bir anahtarı düzeltmek için [anahtarı değiştirin](app-store-connect-api-key#replace-the-key).
