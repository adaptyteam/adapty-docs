[adapty-integration skill](https://github.com/adaptyteam/adapty-skills), Adapty entegrasyonunu uçtan uca otomatikleştirir: kontrol paneli kurulumu, SDK kurulumu, paywall ve aşama başına doğrulama. Platformunuzu otomatik olarak algılar ve her aşamada ilgili Adapty dokümanlarını getirir.

**Desteklenen araçlar**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Kurulum için aracınıza uygun formu seçin. Tam liste [skill README](https://github.com/adaptyteam/adapty-skills) dosyasında yer almaktadır.

Repoda iki skill bulunur — `adapty-integration` ve `ads-manager`; ikincisi Apple Search Ads'i Adapty CLI üzerinden çalıştırır. Aşağıdaki her komut her ikisini de kurar.

**Claude Code**

```
claude plugin marketplace add adaptyteam/adapty-skills
claude plugin install adapty-skills@adapty
```

**GitHub Copilot CLI**

```
git clone https://github.com/adaptyteam/adapty-skills.git
cp -r adapty-sdk-integration-skill/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```
gemini skills install https://github.com/adaptyteam/adapty-skills
```

**OpenAI Codex veya başka bir araç** — [skills CLI](https://skills.sh) kullanın (bu yöntemle kurulan skill'ler otomatik güncellenmez):

```
npx skills add adaptyteam/adapty-skills --all
```

`--all`, her ikisini de algıladığı tüm agent'lara kurar. Bu parametre olmadan CLI, hangisini istediğinizi sorar.

Alternatif olarak, repoyu klonlayıp `skills/` altındaki dizinleri aracınızın skills dizinine kopyalayabilirsiniz.

Kurulumun ardından projenizde skill'i çalıştırın:

```
/adapty-integration
```

Skill birkaç kurulum sorusu sorar, ardından kontrol paneli kurulumu, SDK kurulumu, paywall ve doğrulama adımlarında sizi yönlendirir.
