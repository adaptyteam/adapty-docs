`adapty-integration` skill'i, Adapty entegrasyonunu uçtan uca otomatikleştirir: kontrol paneli kurulumu, SDK kurulumu, paywall ve aşama bazında doğrulama. Platformunuzu otomatik olarak algılar ve her aşamada ilgili Adapty dokümanlarını getirir. Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI ve diğerleri dahil, skill'leri destekleyen her kod ajanında çalışır.

Bu skill, [`adapty-skills` plugin'inin](https://github.com/adaptyteam/adapty-skills) bir parçasıdır. Plugin'i kurmak için terminalinizde şunu çalıştırın:

```bash
npx adapty skills install
```

Skill'leri yüklemek için ajanınızı yeniden başlatın. Diğer kurulum yöntemleri için [plugin README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install) dosyasına bakın.

Entegrasyonu başlatmak için ajanınızda şunu sorun:

```
Integrate Adapty into my app
```

Skill birkaç kurulum sorusu sorar, ardından kontrol paneli kurulumu, SDK kurulumu, paywall ve doğrulama adımlarını sırayla gerçekleştirir.
