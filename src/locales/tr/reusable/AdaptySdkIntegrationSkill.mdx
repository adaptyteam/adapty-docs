[adapty-integration skill](https://github.com/adaptyteam/adapty-skills), Adapty entegrasyonunu uçtan uca otomatikleştirir: kontrol paneli kurulumu, SDK kurulumu, paywall ve aşamaya özel doğrulama. Platformunuzu otomatik olarak algılar ve her aşamada ilgili Adapty belgelerini çeker.

**Desteklenen araçlar**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Kurulum için aracınıza uygun formu seçin. Tam liste [skill README](https://github.com/adaptyteam/adapty-skills) dosyasındadır.

Depoda bu skill'den fazlası bulunur ve aşağıdaki komutların her biri tümünü kurar.

**Claude Code**

```
claude plugin marketplace add adaptyteam/adapty-skills
claude plugin install adapty-skills@adapty
```

**GitHub Copilot CLI**

```
git clone https://github.com/adaptyteam/adapty-skills.git
cp -r adapty-skills/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```
gemini skills install https://github.com/adaptyteam/adapty-skills
```

**OpenAI Codex**

```
codex plugin marketplace add adaptyteam/adapty-skills
codex plugin add adapty-skills@adapty
```

**Diğer araçlar** — [skills CLI](https://skills.sh) kullanın (bu yöntemle kurulan skill'ler otomatik güncellenmez):

```
npx skills add adaptyteam/adapty-skills --all
```

`--all`, algılanan her agent'a tüm skill'leri kurar. Kullanılmazsa CLI hangilerini istediğinizi sorar.

Alternatif olarak depoyu klonlayıp `skills/` altındaki dizinleri aracınızın skill dizinine kopyalayabilirsiniz.

Kurulumun ardından projenizde skill'i çalıştırın:

```
/adapty-integration
```

Skill birkaç kurulum sorusu sorar, ardından kontrol paneli kurulumu, SDK kurulumu, paywall ve doğrulama adımlarında size rehberlik eder.
