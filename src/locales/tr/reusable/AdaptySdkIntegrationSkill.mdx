[adapty-integration skill](https://github.com/adaptyteam/adapty-skills), Adapty entegrasyonunu uçtan uca otomatikleştirir: kontrol paneli kurulumu, SDK kurulumu, paywall ve her aşama için doğrulama. Platformunuzu otomatik olarak algılar ve her aşamada ilgili Adapty dokümanlarını getirir.

**Desteklenen araçlar**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Yüklemek için aracınıza uygun formu seçin. Tam liste [skill README](https://github.com/adaptyteam/adapty-skills) dosyasında yer alıyor.

Depo iki skill barındırır — `adapty-integration` ve `ads-manager`; `ads-manager`, Adapty CLI aracılığıyla Apple Search Ads'i çalıştırır. Aşağıdaki her komut her ikisini de yükler.

**Claude Code**

```
claude plugin marketplace add adaptyteam/adapty-skills
claude plugin install adapty-skills@adapty
```

**GitHub Copilot CLI**

```
git clone https://github.com/adaptyteam/adapty-skills.git
cp -r adapty-skills/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```
gemini skills install https://github.com/adaptyteam/adapty-skills
```

**OpenAI Codex veya başka bir araç** — [skills CLI](https://skills.sh) kullanın (bu yöntemle yüklenen skill'ler otomatik olarak güncellenmez):

```
npx skills add adaptyteam/adapty-skills --all
```

`--all`, algılanan her ajana her iki skill'i de yükler. Bu seçenek olmadan CLI, hangisini istediğinizi sorar.

Alternatif olarak depoyu klonlayın ve `skills/` altındaki dizinleri aracınızın skills dizinine kopyalayın.

Yükledikten sonra skill'i projenizde çalıştırın:

```
/adapty-integration
```

Skill birkaç kurulum sorusu sorar, ardından kontrol paneli kurulumu, SDK kurulumu, paywall ve doğrulama adımlarını tek tek yürütür.
