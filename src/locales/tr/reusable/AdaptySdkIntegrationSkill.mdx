[adapty-sdk-integration skill](https://github.com/adaptyteam/adapty-sdk-integration-skill), Adapty entegrasyonunu uçtan uca otomatikleştirir: kontrol paneli kurulumu, SDK yüklemesi, paywall ve aşamaya göre doğrulama. Platformunuzu otomatik olarak algılar ve her aşamada ilgili Adapty belgelerini getirir.

**Desteklenen araçlar**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Yüklemek için aracınıza uygun formu seçin. Tam liste [skill README](https://github.com/adaptyteam/adapty-sdk-integration-skill) dosyasında yer almaktadır.

Depo iki skill barındırır — `adapty-sdk-integration` ve Adapty CLI aracılığıyla Apple Search Ads'i çalıştıran `ads-manager`. Aşağıdaki komutların her biri her ikisini de yükler.

**Claude Code**

```
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

**GitHub Copilot CLI**

```
git clone https://github.com/adaptyteam/adapty-sdk-integration-skill.git
cp -r adapty-sdk-integration-skill/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex veya başka bir araç** — [skills CLI](https://skills.sh) kullanın (bu şekilde yüklenen skill'lerin otomatik olarak güncellenmediğini unutmayın):

```
npx skills add adaptyteam/adapty-sdk-integration-skill --all
```

`--all` her ikisini de tespit ettiği tüm agent'lara yükler. Bu seçenek olmadan CLI, ikisinden hangisini istediğinizi sorar.

Alternatif olarak, repoyu klonlayıp `skills/` altındaki dizinleri aracınızın skill dizinine kopyalayabilirsiniz.

Yükledikten sonra, skill'i projenizde çalıştırın:

```
/adapty-sdk-integration
```

Skill birkaç kurulum sorusu sorar, ardından kontrol paneli kurulumu, SDK yüklemesi, paywall ve doğrulama adımlarını teker teker ilerletir.
