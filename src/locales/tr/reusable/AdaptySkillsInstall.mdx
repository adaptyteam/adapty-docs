Adapty eklentisini zaten kurduysanız bu skill'e sahipsiniz demektir. Ajanınız bunu listelemiyor ise [eklenti README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install) dosyasındaki komutla eklentiyi güncelleyin.

Eklentiyi bir kodlama ajanına kurmak için terminalinizde şunu çalıştırın:

```bash
npx adapty skills install
```

Eklentiyi yüklemek için ajanınızı yeniden başlatın. Eklentiyi claude.ai veya Claude desktop'a kurmak için [Eklentiyi Kur](manage-adapty-with-ai#install-the-plugin) bölümüne bakın. Diğer kurulum yöntemleri için [eklenti README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install) dosyasına göz atın.

Claude Code eklentiyi otomatik olarak güncellemez. Yeni skill'leri yayımlandıkça almak için Claude Code'da `/plugin` komutunu çalıştırın, **Marketplaces** bölümünü açın, `adapty` seçeneğini seçin ve **Enable auto-update** seçeneğini etkinleştirin. Diğer ajanlardaki güncelleme komutu için [eklenti README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install) dosyasına bakın.
