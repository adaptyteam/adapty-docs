Eklentiyi yüklemek için terminalinizde şunu çalıştırın:

```bash
npx adapty skills install
```

Skill'leri yüklemek için ajanınızı yeniden başlatın. Diğer kurulum yöntemleri için [eklenti README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install) dosyasına bakın.

Claude Code, eklentiyi kendiliğinden güncellemez. Yeni skill'leri yayınlandıkça almak için Claude Code'da `/plugin` komutunu çalıştırın, **Marketplaces** bölümünü açın, `adapty` seçeneğini seçin ve **Enable auto-update** seçeneğini belirleyin. Diğer ajanlardaki güncelleme komutu için [eklenti README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install) dosyasına bakın.
