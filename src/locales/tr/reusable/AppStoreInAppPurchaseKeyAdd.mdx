1. **Issuer ID** ve **Key ID** bilgilerini bulmak için App Store Connect'te [**Users and Access** > **Integrations** > **In-App Purchase**](https://appstoreconnect.apple.com/access/integrations/api/subs) sayfasına gidin. Anahtarı başkası oluşturduysa ve size Issuer ID, Key ID ile dosyayı gönderdiyse bu adımı atlayın.

   <ZoomImage id="asc-in-app-purchase-keys-ids.webp" width="700px" alt="App Store Connect'te In-App Purchase anahtarının Issuer ID ve Key ID bilgileri" />

2. Adapty'de [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk) sayfasına gidin. **In-app purchase API (StoreKit 2)** bölümünde alanları doldurun:
   - **Issuer ID**: App Store Connect'teki **In-App Purchase** sayfasından kopyalayın.
   - **Key ID**: **In-App Purchase** sayfasındaki **Active** listesinden, indirdiğiniz anahtarın yanından kopyalayın.
   - **Private key (.p8 file)**: İndirdiğiniz dosyayı yükleyin.

   <ZoomImage id="app-settings-in-app-purchase-api.webp" width="700px" alt="Adapty'deki In-app purchase API (StoreKit 2) bölümündeki Issuer ID, Key ID ve Private key (.p8 file) alanları" />

3. Adapty, [promosyon tekliflerini](offers) In-App Purchase anahtarıyla imzalar. **App Store promotional offers** bölümünde anahtarı tekrar girin:
   - **Subscription key ID**: 2. adımdaki Key ID.
   - **Subscription key (.p8 file)**: 2. adımdaki dosya.

   <ZoomImage id="app-settings-promotional-offers.webp" width="700px" alt="App Store promotional offers bölümündeki Subscription key ID ve Subscription key (.p8 file) alanları" />

   Farklı bir anahtar hatasız kaydedilir, ancak kullanıcılar bu durumda promosyon tekliflerini alamaz.

4. **Save**'e tıklayın. Adapty, sayfayı kaydetmeden önce **In-app purchase API (StoreKit 2)** bölümündeki anahtarı Apple ile doğrular. Apple anahtarı reddederse sayfada "The provided field values are incorrect" hatası görünür: [değerleri gözden geçirin](troubleshoot-app-store-integration#the-provided-field-values-are-incorrect-when-saving-credentials).
