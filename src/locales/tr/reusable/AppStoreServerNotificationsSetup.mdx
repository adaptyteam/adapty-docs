1. Adapty'de bağladığınız uygulamayı açın: her Adapty uygulamasının kendine ait bir bildirim URL'si vardır. [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk) sayfasına gidin. **App Store server notifications** bölümünde, **URL for App Store server notifications** alanındaki URL'yi kopyalayın.

   <ZoomImage id="app-settings-notifications-url.webp" width="700px" alt="Adapty'deki App Store server notifications bölümünde App Store sunucu bildirimleri için URL" />

2. [App Store Connect](https://appstoreconnect.apple.com/apps)'te uygulamanızın **App Information** sayfasını açın.
3. **App Store Server Notifications** bölümünde **Production Server URL**'yi bulun. Orada zaten bir URL varsa **Edit**'e tıklayın. Yoksa **Set Up URL**'ye tıklayın.

   <ZoomImage id="asc-server-notifications-set-up-url.webp" width="700px" alt="App Store Connect'teki App Information sayfasında App Store Server Notifications bölümü" />

4. Adapty'den kopyaladığınız URL'yi yapıştırın ve **Save**'e tıklayın.

   <ZoomImage id="asc-server-url-set-up-dialog.webp" width="700px" alt="App Store Connect'teki Production Server URL iletişim kutusunda Adapty'den alınan URL" />

5. Sandbox testlerinizdeki bildirimlerin Adapty'ye ulaşması için **Sandbox Server URL** kısmında da 3. ve 4. adımları tekrarlayın.
