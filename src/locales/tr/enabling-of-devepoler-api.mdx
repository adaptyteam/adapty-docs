Adapty, ürünlerinizi okumak, satın alımları doğrulamak ve abonelik olaylarını aşağıdaki Google API'leri aracılığıyla alır:

- Google Play Android Developer API
- Google Play Developer Reporting API
- Cloud Pub/Sub API

## Başlamadan önce \{#before-you-start\}

Google Play entegrasyonunun ihtiyaç duyduğu [erişim ayrıcalıklarına ve Google Cloud projesine](initial-android#before-you-start) sahip olduğunuzdan emin olun. Bunlar olmadan aşağıdaki adımları tamamlayamazsınız.

## API'leri Etkinleştirin \{#enable-the-apis\}

1. [Google Cloud Console](https://console.cloud.google.com/)'u açın.

2. Entegrasyon için kullanacağınız projeyi seçin.

3. [**Google Play Android Developer API**](https://console.cloud.google.com/apis/library/androidpublisher.googleapis.com) sayfasını açın.

4. **Enable**'a tıklayın ve durum **Enabled** olarak görünene kadar bekleyin. Düğme **Manage** yazıyorsa API zaten etkin demektir, yapmanız gereken bir şey yok.

   <ZoomImage id="gp-api-library-enable.webp" width="700px" alt="An API page in the Google Cloud API library, with the Enable button" />

5. [**Google Play Developer Reporting API**](https://console.cloud.google.com/apis/library/playdeveloperreporting.googleapis.com) sayfasını açın.

6. **Enable** butonuna tıklayın ve durumun **Enabled** olarak görünmesini bekleyin.

7. [**Cloud Pub/Sub API**](https://console.cloud.google.com/apis/library/pubsub.googleapis.com) sayfasını açın.

8. **Enable** butonuna tıklayın ve durumun **Enabled** olarak görünmesini bekleyin.

Onaylamak için Google Cloud Console'da [**APIs & Services**](https://console.cloud.google.com/apis/dashboard) sayfasını açın. Alt kısımdaki tabloda projede etkinleştirilen tüm API'ler listelenir ve üçü de görünmelidir:

- Google Play Android Developer API
- Google Play Developer Reporting API
- Cloud Pub/Sub API

<ZoomImage id="gp-apis-enabled-list.webp" width="700px" alt="Gerekli üç API'yi listeleyen etkin API'ler ve hizmetler tablosu" />
