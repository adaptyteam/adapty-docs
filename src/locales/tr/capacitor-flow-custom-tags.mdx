[Özel etiket](flow-custom-tags), uygulamanızdan gelen bir değere sahip özel bir değişkendir. Bir değişkenin ayarlarında **Value comes from outside the app** seçeneğini belirledikten sonra uygulamanız bu değeri Adapty SDK aracılığıyla ayarlayabilir. Örneğin, bir metin öğesi "Coins:" ifadesini ve bir özel etiketi içeriyorsa, uygulamanız etiket için 120 değerini aktardığında kullanıcılar "Coins: 120" görür.

## Özel etiket değerlerini aktarma \{#pass-custom-tag-values\}

Uygulamanızın değerlerini `createFlowView` fonksiyonunun `customTags` parametresine bir nesne olarak aktarın:

- Her anahtar, `user.streak` gibi özel etiketin tam adıdır.
- Her değer, kullanıcıların etiket yerine gördüğü metindir.
- Her değer, "1250.0" gibi değil, "1.250" gibi okunabilir formatta olmalıdır. Adapty bu değerleri biçimlendirmez veya çevirmez.

SDK değerleri yalnızca bir kez, view oluşturulurken okur; dolayısıyla flow açıkken bu değerler değişmez.

```typescript showLineNumbers title="Capacitor"

const customTags = {
  'username': 'DragonSlayer42',
  'coins': '1,250',
};

try {
  const view = await createFlowView(flow, { customTags });
  await view.present();
} catch (error) {
  // handle the error
}
```

### BMI'yi paywall'a aktarma \{#pass-the-bmi-to-the-paywall\}

Kullanıcının ağırlık ve boyunu onboarding flow'unun `flow_user_input` olaylarından toplayın; bunun için [Flow'lardan veri işleme](capacitor-flow-input) bölümüne bakın. Kullanıcının son ekrana ulaştığını anlamak için `is_last_screen` değeri `true` olarak ayarlanmış bir `flow_screen_showed` olayını izleyin; ayrıntılar için [Flow ekran görüntülemelerini izleme](capacitor-flow-screen-views) bölümüne bakın. Kullanıcı o ekrandan sonra onboarding flow'unu kapattığında BMI'yi hesaplayın. Ardından paywall'ın görünümünü oluşturun ve `bmi` özel etiketi için BMI'yi aktarın.

`onboardingView` üzerinde, onboarding flow'u için oluşturduğunuz view'a şu handler'ları kaydedin:

```typescript showLineNumbers title="Capacitor"

const bodyAnswers: Record<string, string> = {};
let reachedLastScreen = false;

await onboardingView.setEventHandlers({
  onAnalytics(name, params) {
    if (name === 'flow_screen_showed' && params.is_last_screen) {
      reachedLastScreen = true;
    }
    if (name === 'flow_user_input' && typeof params.value === 'string') {
      bodyAnswers[params.element_id as string] = params.value;
    }
    return false;
  },
  onDisappeared() {
    // Number inputs send their values as strings.
    const weight = Number(bodyAnswers.weight);
    const height = Number(bodyAnswers.height);
    const finished = reachedLastScreen;
    delete bodyAnswers.weight;
    delete bodyAnswers.height;
    reachedLastScreen = false;

    if (finished && weight > 0 && height > 0) {
      const heightInMeters = height / 100;
      const bmi = weight / (heightInMeters * heightInMeters);
      showBmiPaywall(bmi.toLocaleString(undefined, { maximumFractionDigits: 1 }));
    }
    return false;
  },
});

async function showBmiPaywall(bmi: string) {
  try {
    const flow = await adapty.getFlow({ placementId: 'bmi_paywall' });
    const view = await createFlowView(flow, { customTags: { 'bmi': bmi } });
    await view.present();
  } catch (error) {
    // handle the error
  }
}
```

`toLocaleString` kullanıcının yerel ayarına göre ondalık ayırıcı kullanır: İngilizce'de "22.7", Almanca'da "22,7".

### VKİ'yi kullanıcı profiline kaydetme \{#save-the-bmi-to-the-users-profile\}

Kullanıcılara VKİ'lerine göre farklı flow'lar göstermek için bunu profillerinin [özel niteliği](capacitor-setting-user-attributes#custom-user-attributes) olarak kaydedin. Adapty Kontrol Paneli'nde `bmi` anahtarıyla bir [**Number** özel niteliği oluşturun](segments#custom-attributes). Ardından her flow'u bu nitelikten oluşturulmuş bir [kitle](audience) için gösterin.

VKİ'yi hesapladıktan sonra `updateProfile` metodunu çağırın. Bir segmentin VKİ'yi bir eşik değeriyle karşılaştırabilmesi için biçimlendirilmiş bir dize değil, sayıyı kaydedin:

```typescript showLineNumbers title="Capacitor"
try {
  await adapty.updateProfile({
    codableCustomAttributes: { bmi: bmi },
  });
} catch (error) {
  // handle the error
}
```
