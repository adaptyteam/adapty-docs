## 2. Animasyon dosyasını uygulamanıza ekleyin \{#2-add-the-animation-file-to-your-app\}

Animasyon dosyasını uygulama modülünüzün `assets` klasörü olan `src/main/assets` dizinine koyun. Dosyayı bu klasörün kökünde tutun, bir alt klasöre koymayın.

`.json` uzantısı olmadan dosya adı, özel öğenin ID'siyle eşleşmelidir; örneğin `streak_ring` için `streak_ring.json`.

## 3. Animasyon görünümünü oluşturun \{#create-the-animation-view\}

Streak için bir model ve animasyonu oynatacak bir görünüm oluşturun. Uygulamanız streak değiştiğinde modeli günceller. Görünüm modeli okuduğundan, ekran açıldığında halka mevcut streak'i gösterir:

<Tabs groupId="current-os" queryString>
<TabItem value="kotlin" label="Kotlin" default>

```kotlin showLineNumbers title="Kotlin"

// the streak that your app keeps up to date
class StreakStore {
    val currentStreak = MutableStateFlow(0) // days in a row
}

@Composable
fun StreakRing(animationFile: String, streakStore: StreakStore) {
    val composition by rememberLottieComposition(LottieCompositionSpec.Asset(animationFile))
    val streak by streakStore.currentStreak.collectAsState()

    // 7 days fill the ring: from 0 for an empty ring to 1 for a full one
    val progress = minOf(streak / 7f, 1f)

    LottieAnimation(
        composition = composition,
        modifier = Modifier.fillMaxSize(), // scale the animation to fit the custom element
        clipSpec = LottieClipSpec.Progress(0f, progress),
    )
}
```

`clipSpec = LottieClipSpec.Progress(0f, progress)` halkayı baştan `progress` değerine kadar bir kez doldurur. Uygulamanız streak'i zaten bir `StateFlow` içinde tutuyorsa, `StreakStore` yerine o `StateFlow`'u kullanın.

</TabItem>
<TabItem value="java" label="Java">

```java showLineNumbers title="Java"

// the streak that your app keeps up to date
public class StreakStore {
    public final MutableLiveData<Integer> currentStreak = new MutableLiveData<>(0); // days in a row
}

public class StreakRingView extends LottieAnimationView {
    private final StreakStore streakStore;

    private final Observer<Integer> streakObserver = streak -> {
        // 7 days fill the ring: from 0 for an empty ring to 1 for a full one
        float progress = Math.min(streak / 7f, 1f);
        setMinAndMaxProgress(0f, progress);
        playAnimation();
    };

    public StreakRingView(Context context, String animationFile, StreakStore streakStore) {
        super(context);
        this.streakStore = streakStore;
        setAnimation(animationFile);
    }

    @Override
    protected void onAttachedToWindow() {
        super.onAttachedToWindow();
        streakStore.currentStreak.observeForever(streakObserver);
    }

    @Override
    protected void onDetachedFromWindow() {
        streakStore.currentStreak.removeObserver(streakObserver);
        super.onDetachedFromWindow();
    }
}
```

`setMinAndMaxProgress(0f, progress)` ve `playAnimation()` fonksiyonları halkayı bir kez, boştan `progress` değerine kadar doldurur. Uygulamanız streak'i zaten bir `LiveData` içinde tutuyorsa, `StreakStore` yerine o `LiveData`'yı kullanın.

</TabItem>

## 4. Animasyonu özel elemente bağla \{#match-the-animation-to-the-custom-element\}

[Uygulama genelindeki resolver'ınıza](android-flow-custom-elements#display-views-in-every-flow), streak modeli için bir özellik ekleyin. Ardından `lottie_animation` Type'ı ve `streak_ring` ID'si için animasyon view'ını döndürün. Vurgulanan satırlar eklenecek veya değiştirilecek kısımları göstermektedir. Uygulamanızda henüz uygulama genelinde bir [resolver](android-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views) yoksa tüm kodu kopyalayabilirsiniz:

<Tabs groupId="current-os" queryString>
<TabItem value="kotlin" label="Kotlin" default>

```kotlin showLineNumbers title="Kotlin" {8,22-28}

class CustomElementsResolver(
    context: Context,
    private val streakStore: StreakStore,
) : AdaptyCustomElementsResolver {
    // the animation files in the assets folder, listed once
    private val animationFiles: Set<String> = try {
        context.assets.list("").orEmpty().toSet()
    } catch (e: IOException) {
        emptySet() // no list of files: every Lottie element shows the fallback
    }

    override fun resolve(type: String, id: String): AdaptyCustomElementContent? =
        when (type) {
            "lottie_animation" -> {
                // the ID names the animation file, such as streak_ring.json
                val file = "$id.json"
                when {
                    file !in animationFiles -> null // no file for this ID: show the fallback
                    id == "streak_ring" ->
                        AdaptyCustomElementContent.compose { StreakRing(file, streakStore) }
                    // the other animations of your resolver
                    else -> null
                }
            }
            // the other Types of your resolver
            else -> null
        }
}
```

`assets` klasöründe ID için dosya yoksa, resolver `null` döndürür ve kullanıcılar yedek içeriği görür. Resolver'ınız zaten [her animasyon dosyası için bir view döndürüyorsa](android-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views), ID `streak_ring` olmadığında `null` yerine o view'ı döndürün. Bu sayede kullanıcılar diğer `lottie_animation` özel elementlerinizin animasyonlarını görmeye devam eder.

</TabItem>
<TabItem value="java" label="Java">

```java showLineNumbers title="Java" {10,14-15,34-40}

public class CustomElementsResolver implements AdaptyCustomElementsResolver {
    private final StreakStore streakStore;
    // the animation files in the assets folder, listed once
    private final Set<String> animationFiles = new HashSet<>();

    public CustomElementsResolver(Context context, StreakStore streakStore) {
        this.streakStore = streakStore;
        try {
            String[] files = context.getAssets().list("");
            if (files != null) {
                animationFiles.addAll(Arrays.asList(files));
            }
        } catch (IOException e) {
            // no list of files: every Lottie element shows the fallback
        }
    }

    @Override
    public AdaptyCustomElementContent resolve(String type, String id) {
        if (type.equals("lottie_animation")) {
            // the ID names the animation file, such as streak_ring.json
            String file = id + ".json";
            if (!animationFiles.contains(file)) {
                return null; // no file for this ID: show the fallback
            }
            if (id.equals("streak_ring")) {
                return AdaptyCustomElementContent.view(
                        (context, elementContext) -> new StreakRingView(context, file, streakStore)
                );
            }
            // the other animations of your resolver
            return null;
        }
        // the other Types of your resolver
        return null;
    }
}
```

`assets` klasöründe ilgili ID için dosya yoksa, resolver `null` döndürür ve kullanıcılar yedek içeriği görür. Resolver'ınız zaten [her animasyon dosyası için bir view döndürüyorsa](android-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views), ID `streak_ring` olmadığında `null` yerine o view'ı döndürün. Bu sayede kullanıcılar diğer `lottie_animation` özel elementlerinizin animasyonlarını görmeye devam eder.

</TabItem>

Streak modeliyle resolver'ı oluşturun ve uygulama genelinde geçerli resolver olarak ayarlayın. `AdaptyUI.setCustomElementsResolver` fonksiyonunu, örneğin uygulama başlangıcında, bir kez çağırın:

<Tabs groupId="current-os" queryString>
<TabItem value="kotlin" label="Kotlin" default>

```kotlin showLineNumbers title="Kotlin"

class App : Application() {
    // the streak model that your app updates
    val streakStore = StreakStore()

    // keep this instance: a resolver for one flow can reuse it
    // lazy: the context isn't attached yet while App is constructed
    val customElementsResolver by lazy { CustomElementsResolver(this, streakStore) }

    override fun onCreate() {
        super.onCreate()
        AdaptyUI.setCustomElementsResolver(customElementsResolver)
    }
}
```

</TabItem>
<TabItem value="java" label="Java">

```java showLineNumbers title="Java"

public class App extends Application {
    // the streak model that your app updates
    private final StreakStore streakStore = new StreakStore();
    // keep this instance: a resolver for one flow can reuse it
    private CustomElementsResolver customElementsResolver;

    @Override
    public void onCreate() {
        super.onCreate();
        customElementsResolver = new CustomElementsResolver(this, streakStore);
        AdaptyUI.setCustomElementsResolver(customElementsResolver);
    }

    public StreakStore getStreakStore() {
        return streakStore;
    }

    public CustomElementsResolver getCustomElementsResolver() {
        return customElementsResolver;
    }
}
```
