Bu hızlı başlangıç kılavuzu, bir token para birimini uçtan uca ayarlar: aylık abonelik, her fatura döneminde kullanıcılara 1000 token verir ve uygulamanızdaki ücretli işlemler token harcar. Adapty tüm bakiyeleri takip eder, böylece backend'iniz yalnızca okuma ve harcama işlemleri yapar.

1. `TOKENS` para birimi oluşturmak için [Sanal para birimi oluşturma](create-virtual-currency) kılavuzunu izleyin. Bunu Pro aboneliğinize bağlayın ve **Credit per cycle** değerini 1000 olarak ayarlayın. Adapty, **Credit per cycle** miktarını aboneliğin her fatura döneminde bir kez verir: aylık abonelikler için her ay, haftalık abonelikler için her hafta. Ekstra token satmak için tek seferlik token paketi ürünlerini de bağlayın.

   <ZoomImage id="new-currency-combined.webp" width="700px" alt="Yeni sanal para birimi oluşturma ekranları" />

2. Bir oluşturma işlemi başlatmadan önce kullanıcının bakiyesini okumak için [List virtual currency balances](api-adapty/operations/listVirtualCurrencyBalances) çağrısı yapın:

   ```bash title="Read balances"
   curl https://api.adapty.io/api/v2/server-side-api/vc/balances/ \
     -H "Authorization: Api-Key {your secret key}" \
     -H "adapty-customer-user-id: user-42"
   ```

   Yanıt, uygulamanızdaki tüm para birimlerini listeler; bakiyesi 0 olan para birimleri de dahildir. Örneğin, 1000 `TOKENS`:

   ```json title="Response"
   {
     "response_created_at": 1794477600123,
     "data": [
       {
         "code": "TOKENS",
         "name": "Tokens",
         "balance": 1000,
         "held": 0,
         "available": 1000,
         "expiry": { "non_expiring": 1000, "expiring": [], "expiring_later": 0, "expired": 0 }
       }
     ]
   }
   ```
3. Kullanıcı bir üretim işlemi çalıştırdığında, negatif bir `amount` ile [Sanal para birimi işlemi oluştur](api-adapty/operations/createVirtualCurrencyTransaction) çağrısı yaparak token'ları harcayın. Bu örnekte, bir görsel üretimi 100 token'a mal olmaktadır. Token'ların neye harcandığını göstermek için istek ayrıca `operation`'ı `spend` ve `feature`'ı `image_generation` olarak ayarlar (bkz. [İşlemleri etiketle](virtual-currencies#label-transactions)):

   ```bash title="Spend tokens"
   curl -X POST https://api.adapty.io/api/v2/server-side-api/vc/transactions/ \
     -H "Authorization: Api-Key {your secret key}" \
     -H "adapty-customer-user-id: user-42" \
     -H "Content-Type: application/json" \
     -d '{
           "items": [{"currency_code": "TOKENS", "amount": -100}],
           "operation": "spend",
           "feature": "image_generation"
         }'
   ```

   İşlem atomiktir ve güncellenmiş bakiyeyi döndürür. Tek bir işlem, `items` içinde her biri bir kez listelenmek üzere 20 adede kadar para birimini değiştirebilir. Kullanıcı maliyeti karşılayamazsa, istek `insufficient_balance` döndürür ve hiçbir şey değişmez. İstekleri güvenle yeniden denemek için bir `Idempotency-Key` başlığı ekleyin. Bakiye bir harcamayı karşılayamazsa yükleme flow'u açmak için [iOS](ios-virtual-currency-top-up) tarifini izleyin.
4. Geri kazanma promosyonu çalıştırmak için aynı endpoint aracılığıyla pozitif bir `amount` ile token'lar verin. Bu şekilde verdiğiniz kredilerin son kullanma tarihi yoktur. Kullanıcılara ilk satın alma işlemlerinden önce bakiye vermek için bkz. [Başlangıç bakiyesi verme](grant-initial-balance).
5. Ekonomiyi istediğiniz zaman denetleyebilmek için kullanıcının [profilindeki](virtual-currency-balance) veya [işlem geçmişindeki](api-adapty/operations/listVirtualCurrencyTransactions) her değişikliği inceleyin.
