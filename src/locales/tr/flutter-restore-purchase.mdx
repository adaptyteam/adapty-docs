Hem iOS hem de Android'de Satın Almaları Geri Yükleme özelliği, kullanıcıların abonelikler veya uygulama içi satın almalar gibi daha önce satın aldıkları içeriklere tekrar ücret ödemeden erişmesini sağlar. Bu özellik özellikle uygulamayı kaldırıp yeniden yükleyen ya da yeni bir cihaza geçen ve daha önce satın aldıkları içeriklere tekrar ücret ödemeden erişmek isteyen kullanıcılar için oldukça kullanışlıdır.

:::note
Eğer ekranı bir builder ile oluşturduysanız, satın almaları manuel olarak geri yüklemeniz gerekmez. Geri yükleme kontrolünü bağlamanız yeterlidir — Flow & Paywall Builder'da **Restore purchases** eylemi veya eski builder'da bir geri yükleme bağlantısı ya da düğmesi — SDK geri yükleme işlemini tamamlar.
:::

Eğer ekranı kendiniz oluşturduysanız, `.restorePurchases()` metodunu çağırın:

```dart showLineNumbers
try {
  final profile = await Adapty().restorePurchases();
  if (profile?.accessLevels['YOUR_ACCESS_LEVEL']?.isActive ?? false) {
        // successful access restore      
  }
} on AdaptyError catch (adaptyError) {
  // handle the error
} catch (e) {
}
```

Yanıt parametreleri:

| Parametre | Açıklama |
|---------|-----------|
| **Profile** | <p>Bir [`AdaptyProfile`](https://pub.dev/documentation/adapty_flutter/latest/adapty_flutter/AdaptyProfile-class.html) nesnesi. Bu model, access level'lar, abonelikler ve abonelik dışı satın almalar hakkında bilgi içerir.</p><p>Kullanıcının uygulamaya erişimi olup olmadığını belirlemek için **access level durumunu** kontrol edin.</p> |

:::info
Adapty Flutter SDK 4.0.4 ve sonrasında, `restorePurchases()` geri yüklenecek bir şey olmasa bile başarıyla tamamlanır: mevcut profili döndürür, bu nedenle içindeki access level durumunu kontrol edin. Daha eski SDK sürümlerinde, bu durumda Android'de metot `noPurchasesToRestore` hatasıyla başarısız olur.
:::
