Mobil uygulamanızda paywall'ları görüntülemek, kullanıcılara premium içerik veya hizmetlere erişim sunmanın temel adımlarından biridir. Ancak bir paywall, yalnızca Adapty ekranı render ettiğinde — yani bir [flow](adapty-flow-builder) ya da [eski Paywall Builder](adapty-paywall-builder) ile oluşturulmuş bir paywall söz konusu olduğunda — satın alma işlemlerini tek başına destekler.

Ekranı kendi kodunuzla render ediyorsanız, satın alma işlemini tamamlamak ve istenen içeriğin kilidini açmak için `.makePurchase()` adlı ayrı bir yöntem kullanmanız gerekir. Bu yöntem, kullanıcıların paywall'larla etkileşime geçmesini ve istedikleri işlemleri gerçekleştirmesini sağlayan temel mekanizmadır.

Eğer paywallınızda kullanıcının satın almaya çalıştığı ürün için aktif bir promosyon teklifi varsa, Adapty bunu satın alma sırasında otomatik olarak uygular.

:::warning
Başlangıç teklifinin otomatik olarak uygulanabilmesi için ekranın Adapty tarafından render edilmesi gerektiğini unutmayın.

Diğer durumlarda, [iOS'ta kullanıcının başlangıç teklifi için uygunluğunu doğrulamanız](fetch-paywalls-and-products#check-intro-offer-eligibility-on-ios) gerekecektir. Bu adımı atlamak, uygulamanızın yayın sürecinde reddedilmesine yol açabilir. Bunun yanı sıra, başlangıç teklifine uygun olan kullanıcılardan tam fiyat alınmasına neden olabilir.
:::

[Başlangıç yapılandırmasını](quickstart) tek bir adımı bile atlamadan tamamladığınızdan emin olun. Bu olmadan satın alımları doğrulayamayız.

## Satın alma yap \{#make-purchase\}

:::note
**Adapty ekranınızı mı oluşturuyor?** Bir [flow](adapty-flow-builder) veya [Paywall Builder](adapty-paywall-builder) paywall için satın almalar otomatik olarak işlenir; bu adımı atlayabilirsiniz.

**Adım adım rehber mi arıyorsunuz?** Tüm bağlamıyla uçtan uca uygulama talimatları için [hızlı başlangıç kılavuzuna](unity-implement-paywalls-manually) göz atın.
:::

```csharp showLineNumbers
using AdaptySDK;

void MakePurchase(AdaptyPaywallProduct product) {
  Adapty.MakePurchase(product, (result, error) => {
    switch (result.Type) {
      case AdaptyPurchaseResultType.Pending:
        // handle pending purchase
        break;
      case AdaptyPurchaseResultType.UserCancelled:
        // handle purchase cancellation
        break;
      case AdaptyPurchaseResultType.Success:
        var profile = result.Profile;
        // handle successfull purchase
        break;
      default:
        break;
    }
  });
}
```

İstek parametreleri:

| Parametre   | Varlık   | Açıklama                                                                                           |
| :---------- | :------- |:---------------------------------------------------------------------------------------------------|
| **Product** | gerekli  | Paywall'dan alınan bir [`AdaptyPaywallProduct`](https://unity.adapty.io/class_adapty_s_d_k_1_1_adapty_paywall_product.html) nesnesi. |

Yanıt parametreleri:

| Parametre | Açıklama                                                                                                                                                                                                                                                                                                                                                                                  |
|---------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Profile** | <p>İstek başarılı olursa yanıt bu nesneyi içerir. Bir [AdaptyProfile](https://unity.adapty.io/class_adapty_s_d_k_1_1_adapty_profile.html) nesnesi, kullanıcının uygulama içindeki access level'ları, abonelikleri ve tek seferlik satın almaları hakkında kapsamlı bilgi sağlar.</p><p>Kullanıcının uygulamaya gerekli erişime sahip olup olmadığını belirlemek için access level durumunu kontrol edin.</p> |

:::warning
**Not:** Hâlâ Apple'ın StoreKit v2.0'dan düşük bir sürümünü ve Adapty SDK'nın v2.9.0'dan düşük bir sürümünü kullanıyorsanız, bunun yerine [Apple App Store paylaşılan secret'ı](app-store-connection-configuration#step-5-enter-app-store-shared-secret) sağlamanız gerekir. Bu yöntem Apple tarafından kullanımdan kaldırılmıştır.
:::

## Satın alma sırasında aboneliği değiştirme \{#change-subscription-when-making-a-purchase\}

Bir kullanıcı mevcut aboneliğini yenilemek yerine yeni bir abonelik seçtiğinde, bu süreç uygulama mağazasına göre farklı işler:

- App Store'da abonelik, abonelik grubu içinde otomatik olarak güncellenir. Kullanıcı bir gruptan abonelik satın alırken başka bir gruptan zaten aktif bir aboneliği varsa, her iki abonelik aynı anda aktif olur.
- Google Play'de abonelik otomatik olarak güncellenmez. Geçişi, aşağıda açıklandığı gibi mobil uygulama kodunuzda yönetmeniz gerekir.

Android'de aboneliği başka biriyle değiştirmek için `.makePurchase()` metodunu ek parametre ile çağırın:

```csharp showLineNumbers
// Create subscription update parameters
var subscriptionUpdateParams = new AdaptySubscriptionUpdateParameters(
    "old_product_id", // Product ID of the current subscription
    AdaptySubscriptionUpdateReplacementMode.WithTimeProration
);

Adapty.MakePurchase(product, subscriptionUpdateParams, (profile, error) => {
  if(error != null) {
      // Handle the error
      return;
  }

  // successful cross-grade
});
```

Ek istek parametresi:

| Parametre                    | Varlık   | Açıklama                                                                                               |
| :--------------------------- | :------- |:-------------------------------------------------------------------------------------------------------|
| **subscriptionUpdateParams** | zorunlu  | bir [`AdaptySubscriptionUpdateParameters`](https://unity.adapty.io/class_adapty_s_d_k_1_1_adapty_subscription_update_parameters.html) nesnesi. |

Abonelikler ve değiştirme modları hakkında daha fazla bilgi edinmek için Google Geliştirici belgelerine bakabilirsiniz:

- [Değiştirme modları hakkında](https://developer.android.com/google/play/billing/subscriptions#replacement-modes)
- [Google'ın değiştirme modları için önerileri](https://developer.android.com/google/play/billing/subscriptions#replacement-recommendations)
- Değiştirme modu [`CHARGE_PRORATED_PRICE`](https://developer.android.com/reference/com/android/billingclient/api/BillingFlowParams.SubscriptionUpdateParams.ReplacementMode#CHARGE_PRORATED_PRICE()). Not: Bu yöntem yalnızca abonelik yükseltmeleri için kullanılabilir. Düşürme işlemleri desteklenmez.
- Değiştirme modu [`DEFERRED`](https://developer.android.com/reference/com/android/billingclient/api/BillingFlowParams.SubscriptionUpdateParams.ReplacementMode#DEFERRED()). Not: Gerçek abonelik değişikliği yalnızca mevcut abonelik fatura dönemi sona erdiğinde gerçekleşir.

## iOS'ta teklif kodlarını kullanma \{#redeem-offer-codes-in-ios\}

Uygulamanızda kod kullanma sayfasını göstermek için:

```csharp showLineNumbers
Adapty.PresentCodeRedemptionSheet((error) => {

});
```

:::danger
Gözlemlerimize göre, bazı uygulamalarda Teklif Kodu Kullanma sayfası güvenilir biçimde çalışmayabilir. Kullanıcıyı doğrudan App Store'a yönlendirmenizi öneririz.

`https://apps.apple.com/redeem?ctx=offercodes&id={apple_app_id}&code={code}`
:::

## App Store'dan tanıtılan uygulama içi satın almalar \{#in-app-purchases-from-the-app-store\}

:::info
Uygulamanız, SDK 4.1 sürümünden itibaren ve **iOS 16.4** ya da daha yeni sürümlerde tanıtılan uygulama içi satın almaları alır. iOS 16.4'ün altında bu callback hiçbir zaman tetiklenmez ve tanıtılan satın almalar kendi kendine tamamlanır. Bu yalnızca iOS'a özgü bir özelliktir: Android'de callback hiçbir zaman tetiklenmez.
:::

Bir kullanıcı App Store ürün sayfanızdan satın alma işlemi başlattığında, SDK ürünü `OnReceivePromotedPurchase` aracılığıyla size iletir ve bekler. Satın almayı tamamlamak uygulamanıza bağlıdır: ürünü `Adapty.MakePromotedPurchase` fonksiyonuna geçirin. Bu kontrolü elinizde tuttuğunuz için, satın alma başlamadan önce kendi ekranınızı gösterebilirsiniz.

Tanıtılan ürün bir abonelik teklifi içeriyorsa SDK, teklifi satın alma sırasında otomatik olarak uygular. Teklif, App Store satın alma intent'inden okunur; bu özellik iOS 18.0 ve sonrasında desteklenmektedir. iOS 16.4–17.x sürümlerinde ise satın alma işlemi temel fiyattan gerçekleştirilir.

`IAdaptyEventListener`, aldığınız bir satın almayı tamamlamak için `Adapty.MakePromotedPurchase` ile birlikte kullanılan `OnReceivePromotedPurchase(AdaptyPromotedProduct)` metodunu içerir:

```csharp showLineNumbers
public void OnReceivePromotedPurchase(AdaptyPromotedProduct product) {
    Adapty.MakePromotedPurchase(product, (result, error) => {
        // process the purchase result
    });
}
```

:::warning
`OnReceivePromotedPurchase`, satın alma işleminin kendisidir. Boş bir implementasyon, kullanıcının başlattığı bir satın almayı düşürür: App Store ürünü uygulamanıza teslim eder ve başka hiçbir şey işlemi tamamlamaz.
:::

## Ön ödemeli planları yönetme (Android) \{#manage-prepaid-plans-android\}

Uygulama kullanıcılarınız [ön ödemeli planlar](https://developer.android.com/google/play/billing/subscriptions#prepaid-plans) satın alabiliyorsa (örneğin, birkaç aylık yenilenmeyen bir abonelik), ön ödemeli planlar için [bekleyen işlemleri](https://developer.android.com/google/play/billing/subscriptions#pending) etkinleştirebilirsiniz.

```csharp showLineNumbers title="Unity"
using UnityEngine;
using AdaptySDK;

var builder = new AdaptyConfiguration.Builder("YOUR_API_KEY")
    .SetGoogleEnablePendingPrepaidPlans(true);

Adapty.Activate(builder.Build(), (error) => {
    if (error != null) {
        // handle the error
        return;
    }
}); 
```
