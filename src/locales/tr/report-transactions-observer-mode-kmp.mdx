<SDKv4>

Observer Mode'da Adapty SDK, mevcut satın alma sisteminiz aracılığıyla gerçekleştirilen satın almaları kendi başına takip edemez. App Store'dan gelen işlemleri kendiniz raporlamanız gerekir. Analizlerde hata oluşmaması için bunu uygulamanızı yayınlamadan **önce** yapılandırmanız kritik öneme sahiptir.

Her işlemi Adapty'nin tanıması için `reportTransaction` kullanarak açıkça raporlayın.

:::warning
**İşlem raporlamayı atlama!**
`reportTransaction` çağırmazsanız Adapty işlemi tanımaz, analitiklerde görünmez ve entegrasyonlara iletilmez.
:::

Adapty flow'ları ve paywall'ları kullanıyorsanız, bir işlemi raporlarken `variationId` değerini ekleyin. Bu, satın almayı tetikleyen flow veya paywall'a bağlar ve analitiklerin doğru çalışmasını sağlar.

```kotlin showLineNumbers

Adapty.reportTransaction(
    transactionId = "your_transaction_id",
    variationId = product.paywallVariationId // kullanıcının satın aldığı AdaptyPaywallProduct
).onSuccess {
    // İşlem başarıyla raporlandı
}.onError { error ->
    // hatayı işle
}
```

Parametreler:

| Parametre       | Zorunluluk | Açıklama                                                                                                                                                                                  |
| --------------- | -------- |----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| transactionId   | zorunlu | <ul><li> iOS için: İşlemin tanımlayıcısı.</li><li> Android için: Satın almanın string tanımlayıcısı (`purchase.getOrderId`); burada satın alma, billing library [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) sınıfının bir örneğidir.</li></ul>                                                       |
| variationId     | isteğe bağlı | Varyasyonun string tanımlayıcısı. Kullanıcının satın aldığı `AdaptyPaywallProduct`'ın `paywallVariationId` değerini geçin. Bu, söz konusu ürünü içeren [AdaptyFlowPaywall](https://kmp.adapty.io/adapty/com.adapty.kmp.models/-adapty-flow-paywall/) nesnesinin `variationId` değeriyle aynıdır. |

</SDKv4>

<SDKv3>

Observer modunda Adapty SDK, mevcut satın alma sisteminiz aracılığıyla gerçekleştirilen satın almaları kendi başına takip edemez. App store'dan gelen işlemleri kendiniz bildirmeniz gerekir. Analizlerde hata oluşmaması için bunu uygulamanızı yayınlamadan **önce** ayarlamanız kritik önem taşır.

Her işlemi Adapty'nin tanıyabilmesi için `reportTransaction` kullanarak açıkça bildirin.

:::warning
**İşlem bildirmeyi atlamayın!**
`reportTransaction` çağırmazsanız Adapty işlemi tanımaz, işlem analizlerde görünmez ve entegrasyonlara gönderilmez.
:::

Adapty flow'larını ve paywall'larını kullanıyorsanız, bir işlemi raporlarken `variationId` parametresini ekleyin. Bu, satın almayı tetikleyen flow veya paywall ile ilişkilendirerek doğru analitik verisi sağlar.

```kotlin showLineNumbers

Adapty.reportTransaction(
    transactionId = "your_transaction_id",
    variationId = paywall.variationId
).onSuccess {
    // Transaction reported successfully
}.onError { error ->
    // handle the error
}
```

Parametreler:

| Parametre       | Zorunluluk | Açıklama                                                                                                                                                                                  |
| --------------- | -------- |----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| transactionId   | zorunlu | <ul><li> iOS için: İşlemin tanımlayıcısı.</li><li> Android için: Satın alma işleminin string tanımlayıcısı (`purchase.getOrderId`); burada satın alma, billing library'nin [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) sınıfının bir örneğidir.</li></ul>                                                       |
| variationId     | opsiyonel | Varyantın string tanımlayıcısı. `AdaptyPaywall` nesnesinin `variationId` özelliğini kullanarak elde edebilirsiniz. |

</SDKv3>
