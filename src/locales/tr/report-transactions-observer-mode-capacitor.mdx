<SDKv4>

Observer modunda, Adapty SDK kendi başına mevcut satın alma sisteminiz üzerinden gerçekleştirilen satın alımları takip edemez. App Store'dan gelen işlemleri kendiniz bildirmeniz gerekir. Analitik hatalarından kaçınmak için bunu uygulamanızı yayına almadan **önce** ayarlamanız kritik önem taşır.

Her işlemi Adapty'nin tanıyabilmesi için `reportTransaction` kullanarak açıkça bildirin.

:::warning

**İşlem bildirmeyi atlama!**
`reportTransaction` çağırmazsanız Adapty işlemi tanımaz, işlem analitikte görünmez ve entegrasyonlara gönderilmez.

:::

Adapty flow ve paywall kullanıyorsanız, bir işlemi raporlarken `variationId` değerini de ekleyin. Bu, satın almayı tetikleyen flow veya paywall'a bağlayarak analizlerin doğru çalışmasını sağlar.

```typescript showLineNumbers

const variationId = product.variationId; // the AdaptyPaywallProduct the user bought

try {
  await adapty.reportTransaction({ 
    transactionId: 'your_transaction_id',
    variationId: variationId 
  });
} catch (error) {
  console.error('Failed to report transaction:', error);
}
```

Parametreler:

| Parametre     | Zorunluluk | Açıklama                                                  |
| ------------- | -------- | ------------------------------------------------------------ |
| **transactionId** | zorunlu | <ul><li> iOS için: İşlemin tanımlayıcısı.</li><li> Android için: Satın almanın string tanımlayıcısı (`purchase.getOrderId`); burada satın alma, billing kütüphanesinin [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) sınıfının bir örneğidir.</li></ul> |
| **variationId**   | isteğe bağlı | Varyantın string tanımlayıcısı. Kullanıcının satın aldığı `AdaptyPaywallProduct`'ın `variationId` değerini geçirin. Bu değer, ilgili ürünü içeren `AdaptyFlowPaywall`'ın `variationId` değeriyle aynıdır. |

</SDKv4>

<SDKv3>

Observer modunda, Adapty SDK'sı mevcut satın alma sisteminiz üzerinden gerçekleştirilen satın almaları kendi başına takip edemez. Uygulama mağazasından işlemleri bildirmeniz gerekir. Analytics'te hata oluşmaması için bunu uygulamanızı yayınlamadan **önce** ayarlamanız kritik önem taşır.

Her işlemi Adapty'nin tanıyabilmesi için açıkça bildirmek amacıyla `reportTransaction` kullanın.

:::warning

**İşlem bildirmeyi atlama!**
`reportTransaction` çağrısı yapmazsanız, Adapty işlemi tanımaz, işlem analytics'te görünmez ve entegrasyonlara gönderilmez.

:::

Adapty flow'ları ve paywall'ları kullanıyorsanız, bir işlem bildirirken `variationId` değerini ekleyin. Bu, satın almayı tetikleyen flow veya paywall ile ilişkilendirerek doğru analizler yapılmasını sağlar.

```typescript showLineNumbers

const variationId = paywall.variationId;

try {
  await adapty.reportTransaction({ 
    transactionId: 'your_transaction_id',
    variationId: variationId 
  });
} catch (error) {
  console.error('Failed to report transaction:', error);
}
```

Parametreler:

| Parametre     | Zorunluluk | Açıklama                                                  |
| ------------- | -------- | ------------------------------------------------------------ |
| **transactionId** | zorunlu | <ul><li> iOS için: İşlemin tanımlayıcısı.</li><li> Android için: Satın almanın string tanımlayıcısı (`purchase.getOrderId`); burada satın alma, billing library [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) sınıfının bir örneğidir.</li></ul> |
| **variationId**   | isteğe bağlı | Varyantın string tanımlayıcısı. Bunu `AdaptyPaywall` nesnesinin `variationId` özelliğini kullanarak alabilirsiniz. |

</SDKv3>
