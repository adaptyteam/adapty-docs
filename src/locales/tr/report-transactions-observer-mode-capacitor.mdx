---

Observer modunda, Adapty SDK kendi başına mevcut satın alma sisteminiz üzerinden gerçekleştirilen satın alımları takip edemez. App Store'dan gelen işlemleri kendiniz bildirmeniz gerekir. Analitik hatalarından kaçınmak için bunu uygulamanızı yayına almadan **önce** ayarlamanız kritik önem taşır.

Her işlemi Adapty'nin tanıyabilmesi için `reportTransaction` kullanarak açıkça bildirin.

:::warning

**İşlem bildirmeyi atlama!**
`reportTransaction` çağırmazsanız Adapty işlemi tanımaz, işlem analitikte görünmez ve entegrasyonlara gönderilmez.

:::

Adapty paywall'larını kullanıyorsanız, bir işlemi raporlarken `variationId` değerini ekleyin. Bu, satın alma işlemini tetikleyen paywall'a bağlayarak doğru paywall analitiği sağlar.

```typescript showLineNumbers

const variationId = paywall.variationId;

try {
  await adapty.reportTransaction({ 
    transactionId: 'your_transaction_id',
    variationId: variationId 
  });
} catch (error) {
  console.error('Failed to report transaction:', error);
}
```

Parametreler:

| Parametre     | Zorunluluk | Açıklama                                                  |
| ------------- | -------- | ------------------------------------------------------------ |
| **transactionId** | zorunlu | <ul><li> iOS için: İşlemin tanımlayıcısı.</li><li> Android için: Satın almanın string tanımlayıcısı (`purchase.getOrderId`); burada satın alma, billing library [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) sınıfının bir örneğidir.</li></ul> |
| **variationId**   | isteğe bağlı | Varyantın string tanımlayıcısı. Bunu `AdaptyPaywall` nesnesinin `variationId` özelliğini kullanarak alabilirsiniz. |
