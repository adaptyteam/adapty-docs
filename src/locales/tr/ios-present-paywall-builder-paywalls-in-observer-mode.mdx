[Observer modu](observer-vs-full-mode) kullanıyorsanız, satın alma mantığınızdan siz sorumlusunuz. Ancak paywall arayüzünü [Flow & Paywall Builder](adapty-flow-builder)'a devredebilirsiniz.

Ekranı builder'da tasarlayın; Adapty SDK onu cihazda yerel olarak render eder. İçeriği, düzeni ve fiyatlandırmayı istediğiniz zaman, uygulama güncellemesi gerektirmeden güncelleyebilirsiniz. Kullanıcı bir satın alma butonuna dokunduğunda SDK, satın alma işlemini tamamlaması için kodunuzu çağırır.

Bu rehber, ekranı nasıl göstereceğinizi ve satın alma çağrısını nasıl yöneteceğinizi açıklar. Satın alma işlemlerini Adapty tamamlıyorsa bunun yerine [Flow'ları ve paywallları gösterme](ios-present-paywalls) bölümüne bakın.

<SDKv4>

## Başlamadan önce \{#before-you-start\}

İhtiyacınız olanlar:

- **Adapty iOS SDK v4 veya üzeri**: Önceki sürümler flow'ları render edemez. Mevcut bir uygulamayı v3'ten taşımak için [migration kılavuzuna](migration-to-ios-sdk-v4) bakın.
- **`observerMode` `true` olarak ayarlanmış**: [iOS SDK kurulum kılavuzuna](sdk-installation-ios#activate-adapty-module-of-adapty-sdk) bakın.
- **İlk mağaza entegrasyonu**: Adapty'yi [App Store ile](initial_ios) kurun.
- **Ürünlere sahip yayımlanmış bir flow**: [Flow & Paywall Builder](adapty-flow-builder) ile oluşturun ve [ürünleri](create-product) atayın.
- **Bir flow placement'ı**: [Bir placement oluşturun](create-placement) ve flow'unuzu ona atayın.
- **Uygulamanızda çekilen flow**: Göstermeden önce [flow'u ve yapılandırmasını alın](get-pb-paywalls).

1. `AdaptyObserverModeResolver` nesnesini uygulayın:

   ```swift showLineNumbers title="Swift"
   func observerMode(didInitiatePurchase product: AdaptyPaywallProduct,
                     onStartPurchase: @MainActor @Sendable @escaping () -> Void,
                     onFinishPurchase: @MainActor @Sendable @escaping () -> Void) {
          // use the product object to handle the purchase
          // call onStartPurchase / onFinishPurchase to notify AdaptyUI about the purchase progress
   }

   func observerModeDidInitiateRestorePurchases(onStartRestore: @MainActor @Sendable @escaping () -> Void,
                                                onFinishRestore: @MainActor @Sendable @escaping () -> Void) {
          // call onStartRestore / onFinishRestore to notify AdaptyUI about the restore progress
   }
   ```

2. Resolver'ınızı `observerModeResolver:` parametresi olarak geçirerek bir flow yapılandırma nesnesi oluşturun:

   ```swift showLineNumbers title="Swift"
   do {
       let flowConfiguration = try await AdaptyUI.getFlowConfiguration(
           forFlow: flow,
           observerModeResolver: <AdaptyObserverModeResolver>
       )
   } catch {
       // handle the error
   }
   ```

   İstek parametreleri:

| Parametre | Zorunluluk | Açıklama |
   | :----------------------- | :------- | :----------------------------------------------------------------------------------------------------------------------- |
   | **forFlow**              | zorunlu | `Adapty.getFlow(placementId:)` aracılığıyla elde edilen bir `AdaptyFlow` nesnesi. Bkz. [Flow ve paywall'ları alma](get-pb-paywalls). |
   | **observerModeResolver** | zorunlu | Yukarıda uyguladığınız `AdaptyObserverModeResolver`.                                                                  |

3. `AdaptyUI.flowController(with:delegate:)` kullanarak flow controller'ı başlatın:

   ```swift showLineNumbers title="Swift"
   import AdaptyUI

   let visualFlow = try AdaptyUI.flowController(
       with: flowConfiguration,
       delegate: <AdaptyFlowControllerDelegate>
   )
   ```

   İstek parametreleri:

| Parameter | Presence | Description |
   | :------------------------- | :------- | :----------------------------------------------------------------------------------------------------------------------------------------------- |
   | **flowConfiguration** | required | Flow'un görsel ayrıntılarını içeren bir `AdaptyUI.FlowConfiguration` nesnesi. Bkz. [Flow'ları ve paywallları getir](get-pb-paywalls). |
   | **delegate** | required | Flow olaylarını dinlemek için bir `AdaptyFlowControllerDelegate`. Bkz. [Flow ve paywall olaylarını işle](ios-handling-events). |

Döndürür:

   | Nesne                | Açıklama                                               |
   | :------------------- | :----------------------------------------------------- |
   | AdaptyFlowController | İstenen flow ekranını temsil eden bir nesne.           |

4. Controller'ı gösterin:

   ```swift showLineNumbers title="Swift"
   present(visualFlow, animated: true)
   ```

:::warning
[Satın alma işlemlerini paywall'larla ilişkilendirmeyi](report-transactions-observer-mode) unutmayın. Aksi takdirde Adapty, satın almanın kaynağı olan paywall'ı belirleyemez.
:::

<TabItem value="swiftui" label="SwiftUI" default>

SwiftUI'da, resolver ile flow konfigürasyonunu alın ve `.flow` modifier'ına geçirin:

```swift showLineNumbers title="SwiftUI"
@State var flowPresented = false
@State var flowConfiguration: AdaptyUI.FlowConfiguration?

var body: some View {
    Text("Hello, AdaptyUI!")
        .flow(
            isPresented: $flowPresented,
            flowConfiguration: flowConfiguration,
            didPerformAction: { action in
                switch action {
                    case .close:
                        flowPresented = false
                    default:
                        break
                }
            },
            didFinishPurchase: { product, purchaseResult in /* dismiss, or do nothing to let the flow continue */ },
            didFailPurchase: { product, error in /* handle the error */ },
            didFinishRestore: { profile in /* check access level and dismiss */ },
            didFailRestore: { error in /* handle the error */ },
            didReceiveError: { error in flowPresented = false }
        )
        .task {
            flowConfiguration = try? await AdaptyUI.getFlowConfiguration(
                forFlow: flow,
                observerModeResolver: <AdaptyObserverModeResolver>
            )
        }
}
```

`getFlowConfiguration` üzerindeki `observerModeResolver:` parametresi, render edilen flow'un özel satın alma mantığınıza uymasını sağlar — modifier'ın kendisi tam moddaki geri çağırmaların aynısını kullanır.

:::warning
[Satın alma işlemlerini paywalllarla ilişkilendirmeyi](report-transactions-observer-mode) unutmayın. Aksi takdirde Adapty, satın almanın kaynak paywall'unu belirleyemez.
:::

1. `AdaptyObserverModeResolver` nesnesini uygulayın:

   ```swift showLineNumbers title="Swift"
   func observerMode(didInitiatePurchase product: AdaptyPaywallProduct,
                     onStartPurchase: @MainActor @Sendable @escaping () -> Void,
                     onFinishPurchase: @MainActor @Sendable @escaping () -> Void) {
          // use the product object to handle the purchase
          // use the onStartPurchase and onFinishPurchase callbacks to notify AdaptyUI about the process of the purchase
   }

   func observerModeDidInitiateRestorePurchases(onStartRestore: @MainActor @Sendable @escaping () -> Void,
                                                onFinishRestore: @MainActor @Sendable @escaping () -> Void) {
          // use the onStartRestore and onFinishRestore callbacks to notify AdaptyUI about the process of the restore
   }
   ```

`observerMode(didInitiatePurchase:onStartPurchase:onFinishPurchase:)` olayı, kullanıcının bir satın alma işlemi başlattığını size bildirir. Bu callback'e yanıt olarak özel satın alma flow'unuzu tetikleyebilirsiniz.

   `observerModeDidInitiateRestorePurchases(onStartRestore:onFinishRestore:)` olayı, kullanıcının bir geri yükleme işlemi başlattığını size bildirir. Bu callback'e yanıt olarak özel geri yükleme flow'unuzu tetikleyebilirsiniz.

Ayrıca, satın alma veya geri yükleme sürecini AdaptyUI'ya bildirmek için aşağıdaki callback'leri çağırmayı unutmayın. Bu, loader gösterimi gibi paywall'ın düzgün çalışması için gereklidir:

| Callback           | Description                                                                      |
   | :----------------- | :------------------------------------------------------------------------------- |
   | onStartPurchase()  | Bu callback, satın alma işleminin başladığını AdaptyUI'ya bildirmek için çağrılmalıdır.  |
   | onFinishPurchase() | Bu callback, satın alma işleminin tamamlandığını AdaptyUI'ya bildirmek için çağrılmalıdır. |
   | onStartRestore()   | Bu callback, geri yükleme işleminin başladığını AdaptyUI'ya bildirmek için çağrılmalıdır.   |
   | onFinishRestore()  | Bu callback, geri yükleme işleminin tamamlandığını AdaptyUI'ya bildirmek için çağrılmalıdır.  |

2. Bir paywall yapılandırma nesnesi oluşturun:

   ```swift showLineNumbers title="Swift"
   do {
       let paywallConfiguration = try AdaptyUI.getPaywallConfiguration(
        forPaywall: <paywall object>, 
        observerModeResolver: <AdaptyObserverModeResolver>
        )
   } catch {
       // handle the error
   }
   ```

   İstek parametreleri:

| Parametre                | Zorunluluk | Açıklama                                                                                                                                                                                                                                                                                                           |
   | :----------------------- | :------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
   | **Paywall**              | zorunlu | İstenen paywall için bir kontrolcü elde etmek amacıyla kullanılan `AdaptyPaywall` nesnesi.                                                                                                                                                                                                                                             |
   | **ObserverModeResolver** | zorunlu | Bir önceki adımda uyguladığınız `AdaptyObserverModeResolver` nesnesi.                                                                                                                                                                                                                                                      |

3. Görüntülemek istediğiniz görsel paywallı `.paywallController(for:products:viewConfiguration:delegate:)` metodunu kullanarak başlatın:

   ```swift showLineNumbers title="Swift"
   import AdaptyUI

       with: <paywall configuration object>,
       delegate: <AdaptyPaywallControllerDelegate>
   )
   ```

İstek parametreleri:

| Parametre                | Zorunluluk | Açıklama                                                                                                                                                                                                                                                                                                           |
| :----------------------- | :------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Paywall Configuration**              | zorunlu | Paywallın görsel ayrıntılarını içeren bir `AdaptyUI.PaywallConfiguration` nesnesi. `AdaptyUI.getPaywallConfiguration(forPaywall:locale:)` metodunu kullanın. Daha fazla bilgi için [Paywall Builder paywalllarını ve yapılandırmalarını getirme](get-pb-paywalls) konusuna bakın.                                                                                                                                                                                                                                             |
| **Delegate**             | zorunlu | Paywall olaylarını dinlemek için bir `AdaptyPaywallControllerDelegate`. Daha fazla bilgi için [Paywall olaylarını işleme](ios-handling-events) konusuna bakın.                                                                                                                                                                 |

Döndürür:

| Nesne                   | Açıklama                                             |
| :---------------------- | :--------------------------------------------------- |
| AdaptyPaywallController | İstenen paywall ekranını temsil eden bir nesne       |

Nesne başarıyla oluşturulduktan sonra şu şekilde görüntüleyebilirsiniz:

| **didFailRendering**                | Arayüz oluşturma sırasında bir hata oluşursa bu callback çağrılır.                            |
| **observerModeDidInitiatePurchase** | Bu callback, bir kullanıcı satın alma işlemi başlattığında çağrılır.                          |
