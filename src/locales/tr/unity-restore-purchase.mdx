Satın Almaları Geri Yükleme özelliği, hem iOS hem de Android'de kullanıcıların abonelikler veya uygulama içi satın almalar gibi daha önce satın aldıkları içeriklere yeniden ücret ödemeden erişmesini sağlar. Bu özellik özellikle uygulamayı kaldırıp yeniden yükleyen ya da yeni bir cihaza geçen ve daha önce satın aldıkları içeriklere tekrar ödeme yapmadan erişmek isteyen kullanıcılar için oldukça işe yarar.

:::note
Ekranı bir builder'da oluşturduysanız, satın almaları manuel olarak geri yüklemeniz gerekmez. Geri yükleme kontrolünü bağlayın — Flow & Paywall Builder'daki **Restore purchases** eylemi ya da eskisinde bir geri yükleme bağlantısı veya düğmesi — ve SDK geri yüklemeyi tamamlar.
:::

Ekranı kendiniz oluşturduysanız `.restorePurchases()` metodunu çağırın:

```csharp showLineNumbers
Adapty.RestorePurchases((profile, error) => {
    if (error != null) {
        // handle the error
        return;
    }
  
    var accessLevel = profile.AccessLevels["YOUR_ACCESS_LEVEL"];
    if (accessLevel != null && accessLevel.IsActive) {
        // restore access
    }
});
```

Yanıt parametreleri:

| Parametre | Açıklama                                                                                                                                                                                                                                                   |
|---------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Profile** | <p>Bir [`AdaptyProfile`](https://unity.adapty.io/class_adapty_s_d_k_1_1_adapty_profile.html) nesnesi. Bu model; access level, abonelik ve abonelik dışı satın alımlara ilişkin bilgileri içerir.</p><p>Kullanıcının uygulamaya erişimi olup olmadığını belirlemek için **access level** durumunu kontrol edin.</p> |
