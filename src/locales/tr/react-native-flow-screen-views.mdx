Bir kullanıcı [flow](adapty-flow-builder) içindeki bir ekranı her açtığında, SDK uygulamanıza bir `flow_screen_showed` olayı bildirir. Bunu Amplitude, Mixpanel veya kullandığınız herhangi bir ürün analitiği platformuna ileterek flow ekranlarını uygulamanızın diğer olaylarıyla birlikte analiz edebilirsiniz.

:::tip
Kullanıcıların bir flow'da ne kadar ilerlediğini görmek için herhangi bir koda ihtiyacınız yok — [flow metrikleri](flow-metrics) Adapty Kontrol Paneli'nde görüntülemeleri, tamamlanmaları ve ekran bazında düşüş oranlarını zaten gösteriyor. Bu kılavuzu, aynı verilere kendi analizlerinizde ihtiyaç duyduğunuzda ve bunları Adapty'nin bilmediği olaylarla birleştirmek istediğinizde kullanın.
:::

## Başlamadan önce \{#before-you-start\}

İhtiyacınız olanlar:

- **Adapty React Native SDK v4 veya üzeri**: Flow analytics callback'i daha eski sürümlerde mevcut değildir.
- **Bu özelliğin yayımlanmasından sonra yayımlanan bir flow sürümü**: Adapty, ekran olaylarını bir flow yayımlandığında oluşturur; dolayısıyla bu tarihten önce son kez yayımladığınız bir flow hiçbir şey raporlamaz. Uygulamanıza hiç olay ulaşmıyorsa flow'un yeni bir sürümünü yayımlayıp tekrar deneyin.

## Ne alırsınız \{#what-you-receive\}

<FlowScreenShowedParams />

Ekran görüntülemeleri, diğer tüm flow olaylarıyla aynı analytics callback'ine ulaşır. Kaydettirme konusunda [Flow ve paywall olaylarını yönetme](react-native-handling-events-1) sayfasına bakın.

## Her ekran görüntülemesini analitiğinize iletin \{#forward-every-screen-view-to-your-analytics\}

Önce event adıyla eşleşme yapın; çünkü bir flow, diğer eventleri de aynı callback üzerinden raporlar.

```javascript showLineNumbers title="React Native"
const unsubscribe = view.setEventHandlers({
  onAnalytics(name, params) {
    if (name === 'flow_screen_showed') {
      const screenId = params.instanceId;
      const screenOrder = params.screen_order;

      // screenId ve screenOrder'ı burada analitik sağlayıcınıza gönderin.
    }
    return false; // flow'u açık tut
  },
});
```

## Kullanıcı sona ulaştığında kod çalıştırma \{#run-code-when-a-user-reaches-the-end\}

`is_last_screen`, flow'un ilerleyemeyeceği bir ekranda `true` değerini alır. Builder'da bunun için bir buton aksiyonu eklemeden içerik kilidini açmak, onboarding'i tamamlandı olarak işaretlemek veya kendi tamamlanma event'inizi göndermek için kullanabilirsiniz.

```javascript showLineNumbers title="React Native"
const unsubscribe = view.setEventHandlers({
  onAnalytics(name, params) {
    if (name === 'flow_screen_showed' && params.is_last_screen) {
      // The user reached the end of the flow.
    }
    return false; // keep the flow open
  },
});
```

Son ekrana ulaşmak, flow'u kapatmakla aynı şey değildir. Kullanıcı son ekranı görüp herhangi bir işlem yapmadan flow'u kapatabilir; ayrıca dallanan bir flow birden fazla farklı ekranda sona erebilir. Flow'un kendisinin kapandığını anlamak için bunun yerine `onDisappeared` kullanın.
