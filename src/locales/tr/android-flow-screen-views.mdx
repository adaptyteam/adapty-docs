Bir kullanıcı [flow](adapty-flow-builder) içindeki bir ekranı her açtığında, SDK uygulamanıza bir `flow_screen_showed` eventi bildirir. Bunu Amplitude, Mixpanel veya kullandığınız ürün analitiği aracına ileterek flow ekranlarını uygulamanızın diğer eventlarıyla birlikte analiz edebilirsiniz.

:::tip
Bir flow'a kaç kullanıcının başladığını ve kaçının sonuna ulaştığını görmek için herhangi bir koda ihtiyacınız yok — [flow metrikleri](flow-metrics) bunu zaten Adapty Kontrol Paneli'nde raporluyor. Ekran bazında bir dönüşüm hunisi oluşturmak için bu kılavuzu kullanın; flow metrikleri bunu hesaplamaz ya da flow ekranlarını Adapty'nin bilmediği olaylarla birleştirmek istiyorsanız bu kılavuz işinize yarar.
:::

## Başlamadan Önce \{#before-you-start\}

İhtiyacınız olanlar:

- **Adapty Android SDK v4 veya üzeri**: Flow analitik callback'i daha önceki sürümlerde mevcut değildir.
- **Bu özellik yayınlandıktan sonra yayımlanan bir flow sürümü**: Adapty, bir flow'u yayımladığında ekran olaylarını oluşturur; dolayısıyla bu tarihten önce en son yayımladığınız bir flow hiçbir şey raporlamaz. Uygulamanıza hiç olay gelmiyorsa flow'un yeni bir sürümünü yayımlayıp tekrar deneyin.

Ekran görüntülemeleri, diğer tüm flow olaylarıyla aynı analytics callback'ine ulaşır. Bunu nereye kaydedeceğinizi öğrenmek için [Flow & paywall olaylarını yönetme](android-handling-events) bölümüne bakın.

## Her ekran görüntülemesini analitiğinize iletin \{#forward-every-screen-view-to-your-analytics\}

Başka bir şey okumadan önce event adıyla eşleştirme yapın; çünkü bir flow, aynı callback aracılığıyla başka eventlar da raporlar.

```kotlin showLineNumbers title="Kotlin"
override fun onAnalyticEvent(
    name: String,
    params: Map<String, Any?>,
    context: Context,
) {
    if (name != "flow_screen_showed") return

    val screenId = params["instanceId"]
    val screenOrder = params["screen_order"]

    // Send screenId and screenOrder to your analytics provider here.
}
```

## Kullanıcı sona ulaştığında kod çalıştırın \{#run-code-when-a-user-reaches-the-end\}

`is_last_screen`, flow'un ilerleyemeyeceği bir ekranda `true` değerini alır. İçerik kilidini açmak, onboarding'i tamamlandı olarak işaretlemek veya kendi tamamlanma etkinliğinizi göndermek için builder'da bir buton eylemi eklemeden bu değeri kullanabilirsiniz.

```kotlin showLineNumbers title="Kotlin"
override fun onAnalyticEvent(
    name: String,
    params: Map<String, Any?>,
    context: Context,
) {
    if (name != "flow_screen_showed") return
    if (params["is_last_screen"] != true) return

    // The user reached the end of the flow.
}
```

Son ekrana ulaşmak, flow'u kapatmakla aynı şey değildir. Kullanıcı son ekranı görebilir ve herhangi bir işlem yapmadan flow'u kapatabilir; ayrıca dallanan bir flow birden fazla farklı ekranda sona erebilir. Flow'un kendisinin kapandığını anlamak için bunun yerine `onFlowClosed` kullanın.
