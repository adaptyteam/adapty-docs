<SDKv4>

Observer modunda, Adapty SDK kendi başına mevcut satın alma sisteminiz üzerinden gerçekleştirilen satın almaları takip edemez. Uygulama mağazasından gelen işlemleri kendiniz bildirmeniz gerekir. Analizlerde hata oluşmaması için bunu uygulamanızı yayınlamadan **önce** ayarlamanız kritik önem taşır.

Her işlemi Adapty'nin tanıyabilmesi için `reportTransaction` kullanarak açıkça bildirin.

:::warning

**İşlem bildirmeyi atlamayın!**
`ReportTransaction` çağrısı yapmazsanız Adapty işlemi tanımaz, işlem analizlerde görünmez ve entegrasyonlara gönderilmez.

:::

Adapty flow'ları ve paywall'ları kullanıyorsanız, bir işlem bildirirken `variationId` parametresini ekleyin. Bu, satın almayı onu tetikleyen flow veya paywall'a bağlar ve doğru analizler sağlar.

:::warning
Kullanıcının satın aldığı `AdaptyPaywallProduct` nesnesinin `PaywallVariationId` değerini kullanın, `AdaptyFlow.VariationId` değerini değil. Bir flow'un kendi varyasyon ID'si, satın almayı flow'a bağlamaz.
:::

```csharp showLineNumbers
Adapty.ReportTransaction(
  "YOUR_TRANSACTION_ID", 
  "PAYWALL_VARIATION_ID", // optional
  (error) => {
  // handle the error
});
```

Parametreler:

| Parametre     | Zorunluluk | Açıklama                                                                                                                                                                                                                                                                                          |
| ------------- | -------- |------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| transactionId | zorunlu | <ul><li> iOS için: İşlemin tanımlayıcısı.</li><li> Android için: Satın almanın `purchase.getOrderId` dize tanımlayıcısı; burada satın alma, billing library [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) sınıfının bir örneğidir.</li></ul> |
| variationId   | isteğe bağlı | Varyasyonun dize tanımlayıcısı. Kullanıcının satın aldığı `AdaptyPaywallProduct`'ın `PaywallVariationId` değerini geçin. Bu, söz konusu ürünü içeren `AdaptyFlowPaywall`'ın `VariationId` değeriyle aynıdır. |
| appleJWSTransaction | isteğe bağlı | Yalnızca iOS, SDK 4.3.0 ve sonrası. İmzalı StoreKit 2 işlemi: doğrulama sonucunun `jwsRepresentation` değeri; `transactionId` ile aynı işleme aittir. SDK bunu olduğu gibi Adapty'ye gönderir. Android bu parametreyi yok sayar. |

iOS'ta, satın alma sisteminiz size StoreKit 2 transaction'ını veriyorsa, JWS temsilini `appleJWSTransaction` içinde iletin. Bunu bir varyasyon olmadan iletmek için `variationId` olarak `null` geçin:

```csharp showLineNumbers
Adapty.ReportTransaction(
  "YOUR_TRANSACTION_ID",
  "PAYWALL_VARIATION_ID", // optional, or null
  "YOUR_JWS_REPRESENTATION", // iOS only, optional
  (error) => {
  // handle the error
});
```

Observer modunda, Adapty SDK mevcut satın alma sisteminiz aracılığıyla yapılan satın almaları kendi başına takip edemez. App Store'dan işlemleri raporlamanız veya geri yüklemeniz gerekir. Analitik hatalarından kaçınmak için bunu uygulamanızı yayına almadan **önce** kurmanız kritik önem taşır.

Her işlemi açıkça raporlamak için her iki platformda da `reportTransaction` kullanın; Adapty'nin bunu tanıdığından emin olmak için Android'de ek bir adım olarak `restorePurchases` kullanın.

:::warning

**İşlem raporlamayı ve satın alma geri yüklemesini atlamayın!**
Bu metodları çağırmazsanız, Adapty işlemi tanımaz, analitiklerde görünmez ve entegrasyonlara gönderilmez.

:::

Adapty flow'ları ve paywall'ları kullanıyorsanız, bir işlem raporlarken `PAYWALL_VARIATION_ID` değerini ekleyin. Bu, satın almayı tetikleyen flow veya paywall ile ilişkilendirerek doğru analitiği sağlar.

```csharp showLineNumbers
// every time when calling transasction.finish()

#if UNITY_ANDROID && !UNITY_EDITOR
  Adapty.RestorePurchases((profile, error) => {
    // handle the error
  });
#endif

Adapty.ReportTransaction(
  "YOUR_TRANSACTION_ID", 
  "PAYWALL_VARIATION_ID", // optional
  (error) => {
  // handle the error
});
```

Parametreler:

| Parametre     | Zorunluluk | Açıklama                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------- | -------- |--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| transactionId | zorunlu | <ul><li> iOS, StoreKit 1 için: bir [SKPaymentTransaction](https://developer.apple.com/documentation/storekit/skpaymenttransaction) nesnesi.</li><li> iOS, StoreKit 2 için: [Transaction](https://developer.apple.com/documentation/storekit/transaction) nesnesi.</li><li> Android için: Satın almanın dize tanımlayıcısı (`purchase.getOrderId`); burada satın alma, faturalama kütüphanesinin [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) sınıfının bir örneğidir.</li></ul> |
| variationId   | isteğe bağlı | Varyantın dize tanımlayıcısı. `AdaptyPaywall` nesnesinin `variationId` özelliği kullanılarak elde edilebilir.                                                                                                                                                                                                                                                                                                                                                                                |

**Flow'ları ve paywallları işlemlerle ilişkilendirme**

Adapty SDK, satın alma işlemlerinin kaynağını belirleyemez; çünkü bu işlemleri siz gerçekleştiriyorsunuz. Bu nedenle, Observer modunda flow, paywall ve/veya A/B testi kullanmayı planlıyorsanız, uygulama mağazanızdan gelen işlemi (transaction) mobile uygulama kodunuzda ilgili flow veya paywall ile ilişkilendirmeniz gerekir. Bu adımı uygulamanızı yayınlamadan önce doğru şekilde yapmak kritik önem taşır; aksi takdirde analizlerde hatalara yol açabilir.

```csharp 
Adapty.SetVariationForTransaction("<variationId>", "<transactionId>", (error) => { 
    if(error != null) {
        // handle the error
        return;
    }

    // successful binding
});
```

| Parametre                                              | Zorunluluk | Açıklama                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ------------------------------------------------------ | -------- |-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| transactionId                                          | zorunlu | <p>iOS, StoreKit 1 için: bir [SKPaymentTransaction](https://developer.apple.com/documentation/storekit/skpaymenttransaction) nesnesi.</p><p>iOS, StoreKit 2 için: [Transaction](https://developer.apple.com/documentation/storekit/transaction) nesnesi.</p><p>Android için: String tanımlayıcı (satın alma işleminin purchase.getOrderId değeri; burada purchase, billing library [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) sınıfının bir örneğidir).</p> |
| variationId                                            | zorunlu | Varyantın string tanımlayıcısı. `AdaptyPaywall` nesnesinin `variationId` özelliği kullanılarak elde edilebilir.                                                                                                                                                                                                                                                                                                                                              |
