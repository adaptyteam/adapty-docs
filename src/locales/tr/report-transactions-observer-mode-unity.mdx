Observer mode'da Adapty SDK, mevcut satın alma sisteminiz üzerinden yapılan satın almaları kendi başına takip edemez. App store'dan gelen işlemleri kendiniz bildirmeniz gerekir. Analitik hatalarından kaçınmak için uygulamanızı yayına almadan **önce** bunu ayarlamanız kritik önem taşır.

Her işlemi Adapty'nin tanıyabilmesi için `reportTransaction` kullanarak açıkça bildirin.

:::warning

**İşlem raporlamayı atlamayın!**
`ReportTransaction` çağırmazsanız, Adapty işlemi tanımaz, işlem analizlerde görünmez ve entegrasyonlara gönderilmez.

:::

Adapty flow'ları ve paywall'larını kullanıyorsanız, işlem raporlarken `variationId` ekleyin. Bu, satın almayı tetikleyen flow veya paywall ile ilişkilendirir ve doğru analiz sağlar.

```csharp showLineNumbers
Adapty.ReportTransaction(
  "YOUR_TRANSACTION_ID", 
  "PAYWALL_VARIATION_ID", // optional
  (error) => {
  // handle the error
});
```

Parametreler:

| Parametre     | Zorunluluk | Açıklama                                                                                                                                                                                                                                                                                          |
| ------------- | -------- |------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| transactionId | zorunlu | <ul><li> iOS için: İşlemin tanımlayıcısı.</li><li> Android için: Satın almanın `purchase.getOrderId` dize tanımlayıcısı; burada satın alma, billing kütüphanesinin [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) sınıfının bir örneğidir.</li></ul> |
| variationId   | isteğe bağlı | Varyantın dize tanımlayıcısı. Bunu [AdaptyPaywall](https://unity.adapty.io/class_adapty_s_d_k_1_1_adapty_paywall.html) nesnesinin `variationId` özelliğini kullanarak alabilirsiniz.                                                                                                                                                  |

</TabItem>

Observer modunda, Adapty SDK mevcut satın alma sisteminiz aracılığıyla yapılan satın almaları kendi başına takip edemez. App Store'dan işlemleri raporlamanız veya geri yüklemeniz gerekir. Analitik hatalarından kaçınmak için bunu uygulamanızı yayına almadan **önce** kurmanız kritik önem taşır.

Her işlemi açıkça raporlamak için her iki platformda da `reportTransaction` kullanın; Adapty'nin bunu tanıdığından emin olmak için Android'de ek bir adım olarak `restorePurchases` kullanın.

:::warning

**İşlem raporlamayı ve satın alma geri yüklemesini atlamayın!**
Bu metodları çağırmazsanız, Adapty işlemi tanımaz, analitiklerde görünmez ve entegrasyonlara gönderilmez.

:::

Adapty flow'ları ve paywall'ları kullanıyorsanız, bir işlem raporlarken `PAYWALL_VARIATION_ID` değerini ekleyin. Bu, satın almayı tetikleyen flow veya paywall ile ilişkilendirerek doğru analitiği sağlar.

```csharp showLineNumbers
// every time when calling transasction.finish()

#if UNITY_ANDROID && !UNITY_EDITOR
  Adapty.RestorePurchases((profile, error) => {
    // handle the error
  });
#endif

Adapty.ReportTransaction(
  "YOUR_TRANSACTION_ID", 
  "PAYWALL_VARIATION_ID", // optional
  (error) => {
  // handle the error
});
```

Parametreler:

| Parametre     | Zorunluluk | Açıklama                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------- | -------- |--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| transactionId | zorunlu | <ul><li> iOS, StoreKit 1 için: bir [SKPaymentTransaction](https://developer.apple.com/documentation/storekit/skpaymenttransaction) nesnesi.</li><li> iOS, StoreKit 2 için: [Transaction](https://developer.apple.com/documentation/storekit/transaction) nesnesi.</li><li> Android için: satın almanın String tanımlayıcısı (`purchase.getOrderId`); burada satın alma, billing library [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) sınıfının bir örneğidir.</li></ul> |
| variationId   | isteğe bağlı | Varyantın string tanımlayıcısı. Bunu [AdaptyPaywall](https://unity.adapty.io/class_adapty_s_d_k_1_1_adapty_paywall.html) nesnesinin `variationId` özelliğini kullanarak alabilirsiniz.                                                                                                                                                                                                                                                                                                                                                                |

**İşlemleri raporlama**

- 3.1.x'e kadar olan sürümler App Store'daki işlemleri otomatik olarak dinler, bu nedenle manuel raporlama gerekmez.
- Sürüm 3.2, Observer Mode'u desteklememektedir.

**İşlemleri raporlama**

`restorePurchases` kullanarak Observer Mode'da Adapty'ye bir işlemi bildirin. Bunun nasıl yapılacağı [Mobil Kodda Satın Alma Geri Yükleme](unity-restore-purchase) sayfasında açıklanmaktadır.

:::warning
**İşlem bildirmeyi atlamayın!**
`restorePurchases` çağrısı yapmazsanız Adapty işlemi tanımaz, analitiklerde görünmez ve entegrasyonlara gönderilmez.
:::

**Flow'ları ve paywallları işlemlerle ilişkilendirme**

Adapty SDK, satın alma işlemlerinin kaynağını belirleyemez; çünkü bu işlemleri siz gerçekleştiriyorsunuz. Bu nedenle, Observer modunda flow, paywall ve/veya A/B testi kullanmayı planlıyorsanız, uygulama mağazanızdan gelen işlemi (transaction) mobile uygulama kodunuzda ilgili flow veya paywall ile ilişkilendirmeniz gerekir. Bu adımı uygulamanızı yayınlamadan önce doğru şekilde yapmak kritik önem taşır; aksi takdirde analizlerde hatalara yol açabilir.

```csharp 
Adapty.SetVariationForTransaction("<variationId>", "<transactionId>", (error) => { 
    if(error != null) {
        // handle the error
        return;
    }

    // successful binding
});
```

| Parametre | Zorunluluk | Açıklama |
| ------------------------------------------------------ | -------- |-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| transactionId | zorunlu | <p>iOS, StoreKit 1 için: bir [SKPaymentTransaction](https://developer.apple.com/documentation/storekit/skpaymenttransaction) nesnesi.</p><p>iOS, StoreKit 2 için: [Transaction](https://developer.apple.com/documentation/storekit/transaction) nesnesi.</p><p>Android için: Dize tanımlayıcısı (satın almanın purchase.getOrderId değeri; burada purchase, billing library [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) sınıfının bir örneğidir).</p> |
| variationId | zorunlu | Varyantın dize tanımlayıcısı. Bunu [AdaptyPaywall](https://unity.adapty.io/class_adapty_s_d_k_1_1_adapty_paywall.html) nesnesinin `variationId` özelliğini kullanarak alabilirsiniz. |
