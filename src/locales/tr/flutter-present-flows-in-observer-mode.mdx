[Observer mode](observer-vs-full-mode) kullanıyorsanız, satın alma mantığından siz sorumlusunuz. Ancak paywall arayüzünü [Flow & Paywall Builder](adapty-flow-builder)'a devredebilirsiniz.

Ekranı builder'da tasarlayın, Adapty SDK onu natively render eder. Metin, düzen ve fiyatlandırmayı istediğiniz zaman güncelleyin; uygulama güncellemesi gerekmez.

Bu kılavuz, bir flow'un nasıl sunulacağını ve satın alma callback'lerinin nasıl yönetileceğini gösterir. Adapty satın almaları sizin adınıza tamamlıyorsa, bunun yerine [Flow ve paywall'ları görüntüleme](flutter-present-paywalls) bölümüne bakın.

## Başlamadan önce \{#before-you-start\}

Şunlara ihtiyacınız var:

- **Adapty Flutter SDK 4.0 veya üzeri**: Eski sürümler flow'ları render edemez. Mevcut bir uygulamayı taşımak için [migration kılavuzuna](migration-to-flutter-sdk-v4) bakın.
- **`observerMode` `true` olarak ayarlanmış**: Flutter SDK kurulum kılavuzundaki [Flutter SDK installation guide](sdk-installation-flutter#activate-adapty-module-of-adapty-sdk) bölümüne bakın.
- **İlk mağaza entegrasyonu**: Adapty'yi [App Store ile](initial_ios) ve [Google Play ile](initial-android) kurun.
- **Ürünleri olan yayımlanmış bir flow**: [Flow & Paywall Builder](adapty-flow-builder)'da oluşturun ve [ürünleri](create-product) atayın.
- **Bir flow placement'ı**: [Bir placement oluşturun](create-placement) ve flow'unuzu atayın.
- **Uygulamanızda çekilen flow**: Flow'u sunmadan önce [flow'u ve yapılandırmasını alın](flutter-get-pb-paywalls).

## Uygulama \{#implementation\}

Observer modunda SDK, satın alma işlemlerini sizin adınıza gerçekleştirmez. Bir kullanıcı Adapty tarafından render edilen bir flow'daki satın alma veya geri yükleme düğmesine dokunduğunda, SDK sizin `AdaptyUIObserverModeResolver`'ınızı çağırır — satın alma veya geri yükleme işlemini orada kendi kodunuzla gerçekleştirin.

1. `AdaptyUIObserverModeResolver`'ı uygulayın:

   ```dart showLineNumbers title="Flutter"
   class MyObserverModeResolver extends AdaptyUIObserverModeResolver {
     @override
     void observerModeDidInitiatePurchase(
       AdaptyUIFlowView view,
       AdaptyPaywallProduct product,
       void Function() onStartPurchase,
       void Function() onFinishPurchase,
     ) {
       onStartPurchase(); // the view shows its loading indicator
       // make the purchase with your own code, then:
       onFinishPurchase(); // the view hides the loading indicator
     }

     @override
     void observerModeDidInitiateRestore(
       AdaptyUIFlowView view,
       void Function() onStartRestore,
       void Function() onFinishRestore,
     ) {
       onStartRestore();
       // restore purchases with your own code, then:
       onFinishRestore();
     }
   }
   ```

`observerModeDidInitiatePurchase` metodu, kullanıcının bir satın alma işlemi başlattığını; `observerModeDidInitiateRestore` ise kullanıcının bir geri yükleme işlemi başlattığını size bildirir. Buna yanıt olarak özel satın alma veya geri yükleme flow'unuzu tetikleyin.

   Ayrıca, satın alma veya geri yükleme sürecini AdaptyUI'a bildirmek için aşağıdaki callback'leri çağırmayı unutmayın. Bu, yükleyiciyi göstermek gibi düzgün flow davranışı için gereklidir:

| Callback           | Description                                                                                        |
   | :----------------- | :------------------------------------------------------------------------------------------------- |
   | onStartPurchase()  | Satın alma işleminin başladığını AdaptyUI'ya bildirmek için bu callback çağrılmalıdır.  |
   | onFinishPurchase() | Satın alma işleminin tamamlandığını AdaptyUI'ya bildirmek için bu callback çağrılmalıdır. |
   | onStartRestore()   | Geri yükleme işleminin başladığını AdaptyUI'ya bildirmek için bu callback çağrılmalıdır.   |
   | onFinishRestore()  | Geri yükleme işleminin tamamlandığını AdaptyUI'ya bildirmek için bu callback çağrılmalıdır.  |

2. Herhangi bir ekran göstermeden önce resolver'ı kaydedin:

   ```dart showLineNumbers title="Flutter"
   AdaptyUI().setObserverModeResolver(MyObserverModeResolver());
   ```

3. Flow görünümünü her zamanki gibi oluşturun ve gösterin: [flow'u alın ve görünümünü oluşturun](flutter-get-pb-paywalls), ardından [gösterin](flutter-present-paywalls). Ekstra parametre gerekmez — resolver kaydedildiğinde, Adapty tarafından render edilen her flow satın alma ve geri yükleme işlemlerini onun üzerinden yönlendirir.

:::warning
[İşlemi bildirmeyi ve paywall ile ilişkilendirmeyi](report-transactions-observer-mode-flutter) unutmayın. Aksi takdirde Adapty işlemi tanımayacak ve satın alma işleminin kaynak paywall'ını belirleyemeyecektir.
:::
