Ertelenmiş deeplink'ler, kullanıcılar reklamlarınıza tıkladıktan sonra uygulamanızı yüklediğinde özel veri aktarmanıza olanak tanır. Örneğin, kullanıcıları uygulamayı yükleyip başlatır başlatmaz belirli bir sayfaya yönlendirebilirsiniz.

:::important
Adapty SDK 4.1 sürümünden itibaren Adapty Attribution varsayılan olarak devre dışıdır. `onInstallationDetailsSuccess` geri çağrısı yalnızca [SDK'yı etkinleştirirken Adapty Attribution'ı etkinleştirdiğinizde](user-acquisition#step-1-enable-adapty-attribution-in-the-sdk) tetiklenir.
:::

Nasıl çalıştığı aşağıda açıklanmıştır:

1. Bir kullanıcı reklamınıza tıkladığında, Adapty tıklama verisini kaydeder.
2. Adapty yükleme olayını kaydettiğinde, tıklamaya ait ertelenmiş veriyi alır.
3. Kullanıcı uygulamanızı yükleyip ilk kez başlattıktan sonra, Adapty depolanan veriyi getirir ve uygulamanız özel parametreleri alır; bu sayede uygulama kodunuzda farklı değerlere göre işlem yapabilirsiniz.

Uygulamanız ertelenmiş veriyi yalnızca Adapty, yüklemeyi tıklamayla eşleştirdiğinde alır. Uygulamanız zaten yüklü olan bir kullanıcı reklamınıza tıklarsa, uygulama yeni bir ertelenmiş veri almaz.

iOS'ta Adapty, kurulumu yalnızca aynı IP adresi aralığından gelen tıklamalarla eşleştirir. Örneğin, Wi-Fi üzerinden yapılan bir tıklama ile hücresel ağda gerçekleşen ilk başlatma eşleştirilemez; bu durumda uygulamanız hiçbir ertelenmiş veri almaz.

Adapty aşağıdaki ertelenmiş veri parametrelerini destekler:

- `ios_deferred_data`
- `android_deferred_data`
- `deferred_data_sub[1-10]`

Ertelenmiş veri parametreleri eklemek için bunları kampanya ayarlarınızda bağlantınıza ekleyin:

1. Kampanyanız Meta Ads veya TikTok üzerinde yayınlanıyorsa, izleme bağlantınızı **Integrations** > **Meta Ads** veya **TikTok Ads** bölümünde bulabilirsiniz. Kampanyanız farklı bir platformu hedefliyorsa **Integrations** > **Custom** kısmını açın. Ardından kullanmak istediğiniz bağlantıyı kopyalayın.

<ZoomImage id="ua-lnk.webp" width="900px" />

2. Reklam platformunuzda (Meta, TikTok, Google Ads, vb.), bağlantıyı reklam hedef URL alanına yapıştırın, ardından ertelenmiş veri parametrelerini ekstra sorgu parametreleri olarak ekleyin — her birinin önüne `&` koyun. Örneğin, iOS kullanıcılarını yüklemeden sonra bir 'Welcome' ekranına göndermek için `&ios_deferred_data=welcome` ekleyin. Son hedef URL şu şekilde görünecektir:

```
https://api-ua.adapty.io/api/v1/attribution/c/YOUR_CODE?campaign_id=__CAMPAIGN_ID__&adset_id=__AID__&ad_id=__CID__&campaign_name=__CAMPAIGN_NAME__&adset_name=__AID_NAME__&ad_name=__CID_NAME__&redirect_url=__APP_LINK__&ios_deferred_data=welcome
```

3. Uygulama kodunuzda parametrelere yanıt verin. SDK, bunları kurulum detaylarının `payload` özelliğinde iletir:
   - **iOS**: `payload.dictionary` üzerinden okuyun.
   - **Android**: `payload.dataMap` üzerinden okuyun.
   - **React Native ve Flutter**: `payload` bir JSON dizesidir, bu yüzden önce ayrıştırın.

Örneğin, `ios_deferred_data` değeri `welcome` olan kurulumları şu şekilde ele alabilirsiniz:

<TabItem value="swift" label="Swift" default>

```swift showLineNumbers
Adapty.delegate = self

nonisolated func onInstallationDetailsSuccess(_ details: AdaptyInstallationDetails) {
    guard
        let deeplink = details.payload?.dictionary?["ios_deferred_data"] as? String,
        deeplink == "welcome"
    else { return }

    DispatchQueue.main.async {
        print("Navigate to welcome screen")
        // navigate to your screen here
    }
}
```

```kotlin showLineNumbers
Adapty.setOnInstallationDetailsListener(object : OnInstallationDetailsListener {
    override fun onInstallationDetailsSuccess(details: AdaptyInstallationDetails) {
        if (details.payload?.dataMap?.get("android_deferred_data") == "welcome") {
            println("Navigate to welcome screen")
            // navigate here
        }
    }

    override fun onInstallationDetailsFailure(error: AdaptyError) {
        // handle the error
    }
})
```

```typescript showLineNumbers
adapty.addEventListener('onInstallationDetailsSuccess', details => {

            const payload = JSON.parse(details.payload);
            if (payload.ios_deferred_data === 'welcome') {
                // Navigate to welcome screen
                // Replace with your app's navigation logic
                // For example, using React Navigation:
                // navigation.navigate('Welcome');
```

```dart showLineNumbers
Adapty().onUpdateInstallationDetailsSuccessStream.listen((details) {
  final payloadStr = details.payload;
  if (payloadStr == null) return;

  final payload = json.decode(payloadStr) as Map<String, dynamic>;
  if (payload['ios_deferred_data'] == 'welcome') {
    print('Navigate to welcome screen');
  }
});
```
