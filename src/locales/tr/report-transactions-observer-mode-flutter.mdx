<SDKv4>

Observer mode'da Adapty SDK, mevcut satın alma sisteminiz üzerinden gerçekleştirilen satın almaları kendi başına takip edemez. Uygulama mağazasından gelen işlemleri kendiniz bildirmeniz gerekir. Analytics'te hata oluşmaması için bunu uygulamanızı yayına almadan **önce** yapılandırmanız kritik önem taşır.

Her işlemi Adapty'nin tanıyabilmesi için `reportTransaction` kullanarak açıkça bildirin.

:::warning

**İşlem bildirmeyi atlamayın!**
`reportTransaction` çağrısı yapmazsanız Adapty işlemi tanımaz, işlem analytics'te görünmez ve entegrasyonlara gönderilmez.

:::

Adapty flow'ları ve paywall'ları kullanıyorsanız, bir işlemi bildirirken `variationId` değerini ekleyin. Bu, satın almayı tetikleyen flow veya paywall ile ilişkilendirerek doğru analitik verisi sağlar.

```dart showLineNumbers
try {
    // every time when calling transaction.finish()
    await Adapty().reportTransaction(
        transactionId: "YOUR_TRANSACTION_ID",
        variationId: "PAYWALL_VARIATION_ID", // optional
    );
} on AdaptyError catch (adaptyError) {
    // handle the error
} catch (e) {
    // handle the error
}
```

Parametreler:

| Parametre     | Zorunluluk | Açıklama                                                  |
| ------------- | -------- | ------------------------------------------------------------ |
| transactionId | zorunlu | <ul><li> iOS için: İşlemin tanımlayıcısı.</li><li> Android için: Billing library [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) sınıfının bir örneği olan satın alma nesnesinin `purchase.getOrderId` string tanımlayıcısı.</li></ul> |
| variationId   | isteğe bağlı | Varyasyonun string tanımlayıcısı. Kullanıcının satın aldığı `AdaptyPaywallProduct`'ın `paywallVariationId` değerini iletin. Bu, söz konusu ürünü içeren [AdaptyFlowPaywall](https://pub.dev/documentation/adapty_flutter/latest/adapty_flutter/AdaptyFlowPaywall-class.html) nesnesinin `variationId` değeriyle aynıdır. |
| appleJwsTransaction | isteğe bağlı | Yalnızca iOS, SDK 4.3.0 ve sonrası. İmzalı StoreKit 2 işlemi: `transactionId` ile aynı işlem için doğrulama sonucunun `jwsRepresentation` değeri. SDK bunu Adapty'e olduğu gibi gönderir. Android bu parametreyi yoksayar. |

iOS'ta, satın alma sisteminiz size StoreKit 2 transaction'ını veriyorsa, JWS temsilini `appleJwsTransaction` içinde geçirin:

```dart showLineNumbers
await Adapty().reportTransaction(
    transactionId: "YOUR_TRANSACTION_ID",
    variationId: "PAYWALL_VARIATION_ID", // optional
    appleJwsTransaction: jwsRepresentation, // iOS only, optional
);
```

Observer modunda, Adapty SDK kendi başına mevcut satın alma sisteminiz üzerinden gerçekleştirilen satın almaları takip edemez. Uygulama mağazanızdaki işlemleri bildirmeniz ya da geri yüklemeniz gerekir. Analizlerde hata oluşmaması için bunu uygulamanızı yayına almadan **önce** yapılandırmanız kritik önem taşır.

Her işlemi açıkça bildirmek için her iki platformda da `reportTransaction` kullanın; Adapty'nin bunu tanıması için Android'de ek bir adım olarak `restorePurchases` kullanın.

:::warning

**İşlem raporlama ve satın alma geri yüklemeyi atlamayın!**
Eğer bu yöntemleri çağırmazsanız, Adapty işlemi tanımaz, analitiklerde görünmez ve entegrasyonlara gönderilmez.

:::

Adapty flow'ları ve paywalllarını kullanıyorsanız, bir işlemi raporlarken `variationId` değerini de ekleyin. Bu, satın almayı tetikleyen flow veya paywall ile ilişkilendirerek doğru analitik verisi elde etmenizi sağlar.

```dart showLineNumbers
// every time when calling transaction.finish()
if (Platform.isAndroid) {
    try {
        await Adapty().restorePurchases();
    } on AdaptyError catch (adaptyError) {
        // handle the error
    } catch (e) {
    }
}

try {
    // every time when calling transaction.finish()
    await Adapty().reportTransaction(
        transactionId: "YOUR_TRANSACTION_ID",
        variationId: "PAYWALL_VARIATION_ID", // optional

} on AdaptyError catch (adaptyError) {
    // handle the error
} catch (e) {
    // handle the error
}
```

| Parametre     | Zorunluluk | Açıklama                                                  |
| ------------- | -------- | ------------------------------------------------------------ |

**Flow'ları ve paywallları işlemlerle ilişkilendirme**

Adapty SDK, satın almaların kaynağını belirleyemez; çünkü bunları işleyen sizsiniz. Bu nedenle, Observer modunda flow'lar, paywall'lar ve/veya A/B testleri kullanmayı planlıyorsanız, uygulama mağazanızdan gelen işlemi (transaction) mobil uygulama kodunuzda ilgili flow veya paywall ile ilişkilendirmeniz gerekir. Uygulamanızı yayınlamadan önce bunu doğru şekilde yapmanız önemlidir; aksi takdirde analizlerde hatalara yol açar.

```dart
final transactionId = transaction.transactionIdentifier
final variationId = paywall.variationId

try {
  await Adapty().setVariationId('transactionId', variationId);
} on AdaptyError catch (adaptyError) {
  // handle the error
} catch (e) {
}
```
