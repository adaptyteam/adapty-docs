Observer mode'da, Adapty SDK kendi başına mevcut satın alma sisteminiz üzerinden yapılan satın almaları takip edemez. App Store'daki işlemleri uygulamanızdan manuel olarak bildirmeniz gerekir. Analitik hatalarını önlemek için bunu uygulamanızı yayınlamadan **önce** yapılandırmanız son derece önemlidir.

Her işlemi Adapty'nin tanıyabilmesi için `reportTransaction` kullanarak açıkça bildirin.

:::warning

**İşlem raporlamayı atlama!**
`reportTransaction` çağırmadığın takdirde Adapty işlemi tanımaz, işlem analizlerde görünmez ve entegrasyonlara gönderilmez.

:::

Adapty flow'ları ve paywall'ları kullanıyorsan, bir işlem raporlarken `variationId` değerini ekle. Bu, satın almayı tetikleyen flow veya paywall ile ilişkilendirir ve doğru analizler sağlar.

```dart showLineNumbers
try {
    // transaction.finish() her çağrıldığında
    await Adapty().reportTransaction(
        transactionId: "YOUR_TRANSACTION_ID",
        variationId: "PAYWALL_VARIATION_ID", // isteğe bağlı
    );
} on AdaptyError catch (adaptyError) {
    // hatayı yönet
} catch (e) {
    // hatayı yönet
}
```

Parametreler:

| Parametre     | Zorunluluk | Açıklama                                                  |
| ------------- | -------- | ------------------------------------------------------------ |
| transactionId | zorunlu | <ul><li> iOS için: İşlemin tanımlayıcısı.</li><li> Android için: Satın almanın `purchase.getOrderId` dize tanımlayıcısı; burada satın alma, billing library [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) sınıfının bir örneğidir.</li></ul> |
| variationId   | isteğe bağlı | Varyasyonun dize tanımlayıcısı. Bunu [AdaptyPaywall](https://pub.dev/documentation/adapty_flutter/3.17.2/adapty_flutter/AdaptyPaywall-class.html) nesnesinin `variationId` özelliğini kullanarak alabilirsiniz. |
| appleJwsTransaction | isteğe bağlı | Yalnızca iOS, SDK 4.3.0 veya üzeri. İmzalanmış StoreKit 2 işlemi: `transactionId` ile aynı işlem için doğrulama sonucunun `jwsRepresentation` değeri. SDK bunu Adapty'ye olduğu gibi gönderir. Android bu parametreyi yoksayar. |

iOS'ta, satın alma sisteminiz size StoreKit 2 işlemini veriyorsa, JWS temsilini `appleJwsTransaction` içinde geçirin:

```dart showLineNumbers
await Adapty().reportTransaction(
    transactionId: "YOUR_TRANSACTION_ID",
    variationId: "PAYWALL_VARIATION_ID", // optional
    appleJwsTransaction: jwsRepresentation, // iOS only, optional
);
```

Observer modunda Adapty SDK, mevcut satın alma sisteminiz üzerinden gerçekleştirilen satın almaları kendi başına takip edemez. App Store'dan gelen işlemleri bildirmeniz ya da geri yüklemeniz gerekir. Analitik hatalarını önlemek için uygulamanızı yayınlamadan **önce** bu adımı tamamlamanız kritik önem taşır.

Her işlemi açıkça bildirmek için her iki platformda da `reportTransaction` kullanın; Adapty'nin işlemi tanımasını sağlamak amacıyla Android'de ek bir adım olarak `restorePurchases` kullanın.

:::warning

**İşlem raporlama ve satın alma geri yüklemeyi atlamayın!**
Eğer bu yöntemleri çağırmazsanız, Adapty işlemi tanımaz, analitiklerde görünmez ve entegrasyonlara gönderilmez.

:::

Adapty flow'ları ve paywalllarını kullanıyorsanız, bir işlemi raporlarken `variationId` değerini de ekleyin. Bu, satın almayı tetikleyen flow veya paywall ile ilişkilendirerek doğru analitik verisi elde etmenizi sağlar.

```dart showLineNumbers
// every time when calling transaction.finish()
if (Platform.isAndroid) {
    try {
        await Adapty().restorePurchases();
    } on AdaptyError catch (adaptyError) {
        // handle the error
    } catch (e) {
    }
}

try {
    // every time when calling transaction.finish()
    await Adapty().reportTransaction(
        transactionId: "YOUR_TRANSACTION_ID",
        variationId: "PAYWALL_VARIATION_ID", // optional
    );
} on AdaptyError catch (adaptyError) {
    // handle the error
} catch (e) {
    // handle the error
}
```

Parametreler:

| Parametre     | Zorunluluk | Açıklama                                                  |
| ------------- | -------- | ------------------------------------------------------------ |
| transactionId | zorunlu | <ul><li> iOS, StoreKit 1 için: bir [SKPaymentTransaction](https://developer.apple.com/documentation/storekit/skpaymenttransaction) nesnesi.</li><li> iOS, StoreKit 2 için: [Transaction](https://developer.apple.com/documentation/storekit/transaction) nesnesi.</li><li> Android için: String tanımlayıcı (satın almanın purchase.getOrderId değeri; burada purchase, billing library [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) sınıfının bir örneğidir).</li></ul> |
| variationId   | isteğe bağlı | Varyasyonun string tanımlayıcısı. Bunu [AdaptyPaywall](https://pub.dev/documentation/adapty_flutter/3.17.2/adapty_flutter/AdaptyPaywall-class.html) nesnesinin `variationId` özelliğini kullanarak alabilirsiniz. |

**Flow'ları ve paywallları işlemlerle ilişkilendirme**

Adapty SDK, satın almaların kaynağını belirleyemez; çünkü bunları işleyen sizsiniz. Bu nedenle, Observer modunda flow'lar, paywall'lar ve/veya A/B testleri kullanmayı planlıyorsanız, uygulama mağazanızdan gelen işlemi (transaction) mobil uygulama kodunuzda ilgili flow veya paywall ile ilişkilendirmeniz gerekir. Uygulamanızı yayınlamadan önce bunu doğru şekilde yapmanız önemlidir; aksi takdirde analizlerde hatalara yol açar.

```dart
final transactionId = transaction.transactionIdentifier
final variationId = paywall.variationId

try {
  await Adapty().setVariationId('transactionId', variationId);
} on AdaptyError catch (adaptyError) {
  // handle the error
} catch (e) {
}
```
