Bu Adapty CLI komutları, uygulamalarınızı ve bunların [access level](access-level)'larını (uygulamanızın çalışma zamanında kontrol ettiği abonelik kademelerini) yönetir.

## Uygulamalar \{#apps\}

Adapty hesabınızdaki uygulamaları yönetin. Kontrol paneli tabanlı yapılandırma için bkz. [Uygulama ayarları](general).

### adapty apps list

Adapty hesabınızdaki tüm uygulamaları listeler.

```bash
adapty apps list
```

[Sayfalandırma flag'lerini](developer-cli-reference#global-flags) kabul eder.

### adapty apps get

Belirli bir uygulama için ayrıntıları alır.

```bash
adapty apps get <app-id>
```

| Argüman | Açıklama |
|---|---|
| `app-id` | Uygulama ID'si (UUID) |

### adapty apps create

Yeni bir uygulama oluşturur.

```bash
adapty apps create --title "My App" --platform ios --apple-bundle-id com.example.app
```

| Flag | Zorunlu | Açıklama |
|---|---|---|
| `--title` | Evet | Uygulama başlığı |
| `--platform` | Evet | Platform: `ios` veya `android`. Her ikisi için tekrarlayın: `--platform ios --platform android` |
| `--apple-bundle-id` | `--platform ios` ile zorunlu | Apple bundle ID |
| `--google-bundle-id` | `--platform android` ile zorunlu | Google bundle ID |

### adapty apps update

Mevcut bir uygulamayı günceller.

```bash
adapty apps update <app-id> --title "New Name"
```

| Argüman | Açıklama |
|---|---|
| `app-id` | Uygulama ID'si (UUID) |

| Bayrak | Açıklama |
|---|---|
| `--title` | Yeni uygulama başlığı |
| `--apple-bundle-id` | Yeni Apple bundle ID'si |
| `--google-bundle-id` | Yeni Google bundle ID'si |

En az bir bayrak zorunludur. `--platform` oluşturulduktan sonra değiştirilemez.

## Access level'lar \{#access-levels\}

### adapty access-levels list

Bir uygulamaya ait tüm [access level'ları](access-level) listeler.

```bash
adapty access-levels list --app <app-id>
```

| Flag | Zorunlu | Açıklama |
|---|---|---|
| `--app` | Evet | Uygulama ID'si (UUID) |

[Sayfalama flag'lerini](developer-cli-reference#global-flags) kabul eder.

### adapty access-levels get

Belirli bir [access level](access-level) için ayrıntıları alır.

```bash
adapty access-levels get --app <app-id> <access-level-id>
```

| Argüman | Açıklama |
|---|---|
| `access-level-id` | Access level ID'si (UUID) |

| Bayrak | Zorunlu | Açıklama |
|---|---|---|
| `--app` | Evet | Uygulama ID'si (UUID) |

### adapty access-levels create

Yeni bir [access level](access-level) oluşturun.

```bash
adapty access-levels create --app <app-id> --sdk-id "pro" --title "Pro"
```

| Flag | Zorunlu | Açıklama |
|---|---|---|
| `--app` | Evet | Uygulama ID'si (UUID) |
| `--sdk-id` | Evet | Erişimi kontrol etmek için uygulama kodunda kullanılan tanımlayıcı (örneğin, `"pro"` veya `"premium"`) |
| `--title` | Evet | Adapty kontrol panelinde görünen etiket |

### adapty access-levels update

Mevcut bir [access level](access-level) günceller.

```bash
adapty access-levels update --app <app-id> <access-level-id> --title "Pro Access"
```

| Argüman | Açıklama |
|---|---|
| `access-level-id` | Access level ID (UUID) |

| Flag | Zorunlu | Açıklama |
|---|---|---|
| `--app` | Evet | Uygulama ID (UUID) |
| `--title` | Evet | Yeni görüntüleme etiketi |

`--sdk-id` oluşturulduktan sonra değiştirilemez.
