Bir flow veya paywall oluşturduysanız, bunu kullanıcıya göstermek için mobil uygulama kodunuzda render etme konusunda endişelenmenize gerek yoktur. Böyle bir flow veya paywall, içinde ne gösterileceğini ve nasıl gösterileceğini zaten içerir.

:::warning

Bu rehber, Adapty tarafından render edilen flow'ları ve **yeni Paywall Builder paywall'larını** kapsar. Remote config paywall'ları ve [Observer modu](observer-vs-full-mode) için süreç farklıdır.

- **Remote config paywall**'larını sunmak için [Remote config ile tasarlanan paywallı göster](present-remote-config-paywalls-unity) sayfasına bakın.
- **Observer mode**'da flow'ları sunmak için [Observer mode'da flow'ları sun](unity-present-flows-in-observer-mode) sayfasına bakın.

:::

Aşağıda kullanılan `view` nesnesini edinmek için [Flow'ları ve paywall'ları al](unity-get-pb-paywalls) sayfasına bakın.

Bir flow veya paywall görüntülemek için [`CreateFlowView`](unity-get-pb-paywalls#fetch-the-view-configuration) metoduyla oluşturulan `view` üzerinde `view.Present()` metodunu kullanın. Her `view` yalnızca bir kez kullanılabilir: kapatılan bir `view` yok edilir. Flow'u tekrar görüntülemeniz gerekiyorsa yeni bir `view` örneği oluşturmak için `CreateFlowView`'ı bir kez daha çağırın.

:::warning
Aynı `view`'ı yeniden oluşturmadan tekrar kullanmak hataya yol açabilir.
:::

```csharp showLineNumbers title="Unity"
view.Present((error) => {
    // handle the error
});
```

## Diyalog göster \{#show-dialog\}

Android'de bir flow veya paywall gösterilirken, yerel uyarı diyalogları yerine bu yöntemi kullanın. Android'de normal uyarılar flow görünümünün arkasında kalır ve kullanıcılar tarafından görülemez. Bu yöntem, tüm platformlarda diyaloğun flow'un üzerinde düzgün şekilde gösterilmesini sağlar.

```csharp showLineNumbers title="Unity"
var dialog = new AdaptyUIDialogConfiguration()
    .SetTitle("Close this screen?")
    .SetContent("You will lose access to exclusive offers.")
    .SetDefaultActionTitle("Stay")
    .SetSecondaryActionTitle("Close");

AdaptyUI.ShowDialog(view, dialog, (action, error) => {
    if (error == null) {
        if (action == AdaptyUIDialogActionType.Secondary) {
            // User confirmed - close the flow
            view.Dismiss((error) => {
                // handle the error
            });
        }
        // If primary - do nothing, user stays
    }
});
```

## iOS sunum stilini yapılandırın \{#configure-ios-presentation-style\}

`Present()` metoduna `iosPresentationStyle` parametresini geçirerek flow veya paywallın iOS'ta nasıl sunulacağını yapılandırın. Parametre, `AdaptyUIIOSPresentationStyle.FullScreen` (varsayılan) veya `AdaptyUIIOSPresentationStyle.PageSheet` değerlerini kabul eder.

```csharp showLineNumbers title="Unity"
view.Present(AdaptyUIIOSPresentationStyle.PageSheet, (error) => {
    // handle the error
});
```

<SDKv3>

Paywall Builder ile bir paywall özelleştirdiyseniz, bunu kullanıcıya göstermek için mobil uygulama kodunuzda ayrıca render etmeniz gerekmez. Bu tür bir paywall, hem ne gösterileceğini hem de nasıl gösterileceğini içerir.

:::warning

Bu kılavuz, Adapty SDK 3.3.0 veya sonraki sürümünü gerektiren **yeni Paywall Builder**'ı kapsar.

Remote config paywalllarını sunmak için bkz. [Remote config ile tasarlanan paywallları render etme](present-remote-config-paywalls).

:::

Bir paywall görüntülemek için, [`CreatePaywallView`](unity-get-pb-paywalls#fetch-the-view-configuration-of-paywall-designed-using-paywall-builder) metoduyla oluşturulan `view` üzerinde `view.Present()` metodunu kullanın. Her `view` yalnızca bir kez kullanılabilir. Paywall'ı tekrar göstermeniz gerekiyorsa, yeni bir `view` örneği oluşturmak için `CreatePaywallView`'ı bir kez daha çağırın.

:::warning

Aynı `view`'ı yeniden oluşturmadan kullanmak `AdaptyUIError.viewAlreadyPresented` hatasına neden olabilir.
:::

```csharp showLineNumbers title="Unity"
view.Present((error) => {
  // handle the error
});
```

## Diyalog gösterme \{#show-dialog\}

Android'de bir paywall görünümü sunulduğunda, yerel uyarı iletişim kutuları yerine bu metodu kullanın. Android'de normal uyarılar paywall görünümünün arkasında kalarak kullanıcılara görünmez hale gelir. Bu metod, tüm platformlarda iletişim kutusunun paywall'ın üzerinde düzgün şekilde gösterilmesini sağlar.

```csharp showLineNumbers title="Unity"
var dialog = new AdaptyUIDialogConfiguration()
    .SetTitle("Close paywall?")
    .SetContent("You will lose access to exclusive offers.")
    .SetDefaultActionTitle("Stay")
    .SetSecondaryActionTitle("Close");

AdaptyUI.ShowDialog(view, dialog, (action, error) => {
    if (error == null) {
        if (action == AdaptyUIDialogActionType.Secondary) {
            // User confirmed - close the paywall
            view.Dismiss();
        }
        // If primary - do nothing, user stays
    }
});
```

## iOS sunum stilini yapılandırma \{#configure-ios-presentation-style\}

`Present()` metoduna `iosPresentationStyle` parametresini geçirerek paywallın iOS'ta nasıl sunulacağını yapılandırın. Parametre, `AdaptyUIIOSPresentationStyle.FullScreen` (varsayılan) veya `AdaptyUIIOSPresentationStyle.PageSheet` değerlerini kabul eder.

```csharp showLineNumbers title="Unity"
view.Present(AdaptyUIIOSPresentationStyle.PageSheet, (error) => {
    // handle the error
});
```
