<MethodPromo method="GetFlow" label="Flow ve paywall'ları göster" />

Bir flow veya eski Paywall Builder'da bir paywall oluşturduysanız, bunu kullanıcıya göstermek için mobil uygulama kodunuzda render etme konusunda endişelenmenize gerek yoktur. Bu tür bir flow veya paywall, içinde ne gösterileceğini ve nasıl gösterileceğini zaten içerir.

:::warning

Bu kılavuz, Adapty tarafından render edilen flow'lar ve paywall'lar için geçerlidir. Özel paywall'lar ve [Observer modu](observer-vs-full-mode) için süreç farklıdır.

- Özel paywalls sunmak için [Özel paywalls sunma](present-remote-config-paywalls-unity) sayfasına bakın.
- **Observer mode**'da flow sunmak için [Observer mode'da flow sunma](unity-present-flows-in-observer-mode) sayfasına bakın.

:::

Aşağıda kullanılan `view` nesnesini elde etmek için [Flow ve paywall'ları alma](unity-get-pb-paywalls) sayfasına bakın.

Bir flow veya paywall görüntülemek için [`CreateFlowView`](unity-get-pb-paywalls#fetch-the-view-configuration) metoduyla oluşturulan `view` üzerinde `view.Present()` metodunu kullanın. Varsayılan olarak, kapatılan bir view yok edilir. Flow'u tekrar görüntülemek için `CreateFlowView`'ı bir kez daha çağırarak yeni bir `view` örneği oluşturun ya da kapatırken [view'ı koruyun](#keep-the-view-to-present-it-again).

:::warning
Yok edilmiş bir `view`'ı yeniden kullanmak hataya yol açar.
:::

```csharp showLineNumbers title="Unity"
view.Present((error) => {
    // handle the error
});
```

## Görünümü tekrar sunmak için saklayın \{#keep-the-view-to-present-it-again\}

:::info
Saklanan görünümler SDK 4.3.0 sürümünden itibaren kullanılabilir.
:::

`view.Dismiss()` görünümü bellekten kaldırır. Bunun yerine görünümü saklamak için `destroy` parametresine `false` değerini geçin:

```csharp showLineNumbers title="Unity"
view.Dismiss(false, (error) => {
    // handle the error
});
```

Bu görünümü tekrar sunduğunuzda kullanıcı, flow'un o ana kadar oluşturduğu durumuyla birlikte kaldığı ekrana döner. Görünüm `Id`'sini koruduğundan, olayları aynı `view.Id` ile dinleyicinize ulaşmaya devam eder.

Tuttuğunuz bir view, siz serbest bırakana kadar bellekte kalır. Artık ihtiyacınız olmadığında `view.Destroy()` çağrısını yapın:

```csharp showLineNumbers title="Unity"
view.Destroy((error) => {
    // handle the error
});
```

`Destroy()`, view hâlâ ekrandaysa önce onu kapatır. Oluşturup hiç göstermediğiniz bir view'ı ya da iOS'ta kullanıcının aşağı kaydırarak kapattığı sayfa sayfası (page-sheet) view'ını da serbest bırakır. Normal bir `Dismiss()` çağrısından sonra kullanmayın: o view zaten serbest bırakılmıştır ve çağrı başarısız olur.

Kullanıcı **Close** butonuna dokunduğunda görünümü açık tutmak için [`Close` action handler'ınızda](unity-handle-paywall-actions#close-flows-and-paywalls) `destroy: false` ile kapatın. `FlowViewDidPerformAction` metodu uygulamanızdaki her flow ve paywall için çalıştığından, yalnızca yeniden göstermeyi planladığınız görünümü tutmak için `view.Id` değerini karşılaştırın. Görünümü oluştururken bir alana kaydedin; böylece sonradan karşılaştırabilir ve yeniden gösterebilirsiniz:

```csharp showLineNumbers title="Unity"
private AdaptyUIFlowView keptView;

void CreateKeptView(AdaptyFlow flow) {
    AdaptyUI.CreateFlowView(flow, new AdaptyUICreateFlowViewParameters(), (view, error) => {
        if (error != null) {
            // handle the error
            return;
        }
        keptView = view;
    });
}

public void FlowViewDidPerformAction(
    AdaptyUIFlowView view,
    AdaptyUIUserAction action
) {
    switch (action.Type) {
        case AdaptyUIUserActionType.Close:
            view.Dismiss(view.Id != keptView?.Id, null);
            break;
        default:
            // handle other events
            break;
    }
}
```

Sakladığınız `view`'ı elinizde tutun: flow veya paywall'ı yeniden göstermek ve `Destroy()` ile serbest bırakmak için buna ihtiyacınız olacak. `keptView.Destroy()` çağrısından sonra `keptView`'ı `null` olarak ayarlayın; böylece yukarıdaki karşılaştırma, serbest bırakılmış bir view ile eşleşmez. Diğer tüm `view.Dismiss()` çağrıları da view'ı serbest bırakır; buna [`FlowViewDidReceiveError`](unity-handling-events#rendering-and-runtime-errors) içindeki çağrı da dahildir. Bir view hatası sonrasında `CreateFlowView` ile yeni bir view oluşturun.

## Diyalog göster \{#show-dialog\}

Android'de bir flow veya paywall gösterilirken, yerel uyarı diyalogları yerine bu yöntemi kullanın. Android'de normal uyarılar flow görünümünün arkasında kalır ve kullanıcılar tarafından görülemez. Bu yöntem, tüm platformlarda diyaloğun flow'un üzerinde düzgün şekilde gösterilmesini sağlar.

```csharp showLineNumbers title="Unity"
var dialog = new AdaptyUIDialogConfiguration()
    .SetTitle("Close this screen?")
    .SetContent("You will lose access to exclusive offers.")
    .SetDefaultActionTitle("Stay")
    .SetSecondaryActionTitle("Close");

AdaptyUI.ShowDialog(view, dialog, (action, error) => {
    if (error == null) {
        if (action == AdaptyUIDialogActionType.Secondary) {
            // User confirmed - close the flow
            view.Dismiss((error) => {
                // handle the error
            });
        }
        // If primary - do nothing, user stays
    }
});
```

## iOS sunum stilini yapılandırma \{#configure-ios-presentation-style\}

`Present()` metoduna `iosPresentationStyle` parametresini geçirerek flow veya paywallın iOS'ta nasıl sunulacağını yapılandırın. Parametre, `AdaptyUIIOSPresentationStyle.FullScreen` (varsayılan) veya `AdaptyUIIOSPresentationStyle.PageSheet` değerlerini kabul eder.

```csharp showLineNumbers title="Unity"
view.Present(AdaptyUIIOSPresentationStyle.PageSheet, (error) => {
    // handle the error
});
```

Kullanıcı, sayfa sayfasını kapatmak için aşağı kaydırabilir. Görünüm, `Dismiss()` çağrısı yapılmadan bellekte kalır: tekrar sunun ya da SDK 4.3.0 ve sonrasında [`Destroy()`](#keep-the-view-to-present-it-again) ile serbest bırakın.

<SDKv3>

Paywall Builder kullanarak bir paywall özelleştirdiyseniz, bunu kullanıcıya göstermek için mobil uygulama kodunuzda ayrıca render etmeniz gerekmez. Bu tür bir paywall, hem paywall içinde neyin gösterileceğini hem de nasıl gösterileceğini içerir.

:::warning

Bu kılavuz, Adapty SDK 3.3.0 veya sonrasını gerektiren **eski Paywall Builder**'ı kapsamaktadır.

Özel paywallları sunmak için bkz. [Özel paywallları sunma](present-remote-config-paywalls-unity).

:::

Bir paywall görüntülemek için, [`CreatePaywallView`](unity-get-pb-paywalls#fetch-the-view-configuration-of-paywall-designed-using-paywall-builder) yöntemiyle oluşturulan `view` üzerinde `view.Present()` metodunu kullanın. Her `view` yalnızca bir kez kullanılabilir. Paywall'ı tekrar görüntülemeniz gerekirse, yeni bir `view` örneği oluşturmak için `CreatePaywallView` metodunu bir kez daha çağırın.

:::warning

Aynı `view`'ı yeniden oluşturmadan tekrar kullanmak `AdaptyUIError.viewAlreadyPresented` hatasına yol açabilir.
:::

```csharp showLineNumbers title="Unity"
view.Present((error) => {
  // handle the error
});
```

## Diyalog gösterme \{#show-dialog\}

Android'de bir paywall görünümü sunulduğunda, yerel uyarı iletişim kutuları yerine bu metodu kullanın. Android'de normal uyarılar paywall görünümünün arkasında kalarak kullanıcılara görünmez hale gelir. Bu metod, tüm platformlarda iletişim kutusunun paywall'ın üzerinde düzgün şekilde gösterilmesini sağlar.

```csharp showLineNumbers title="Unity"
var dialog = new AdaptyUIDialogConfiguration()
    .SetTitle("Close paywall?")
    .SetContent("You will lose access to exclusive offers.")
    .SetDefaultActionTitle("Stay")
    .SetSecondaryActionTitle("Close");

AdaptyUI.ShowDialog(view, dialog, (action, error) => {
    if (error == null) {
        if (action == AdaptyUIDialogActionType.Secondary) {
            // User confirmed - close the paywall
            view.Dismiss();
        }
        // If primary - do nothing, user stays
    }
});
```
