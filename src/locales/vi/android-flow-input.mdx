Khi người dùng nhập vào một trường đầu vào, trả lời câu hỏi, hoặc bật/tắt một nút trong [flow](adapty-flow-builder), SDK sẽ truyền giá trị đó đến ứng dụng của bạn thông qua callback analytics.

Các ứng dụng thường sử dụng dữ liệu đó để:

- **Đăng ký người dùng trên backend riêng**: Lấy địa chỉ email và tên người dùng đã nhập trong flow onboarding, rồi tạo tài khoản cho họ khi flow kết thúc.
- **Lưu câu trả lời và tùy chọn**: Theo dõi những gì người dùng đã chọn để ứng dụng có thể xử lý sau — ví dụ, [ghi vào hồ sơ người dùng Adapty](android-setting-user-attributes) dưới dạng thuộc tính tùy chỉnh.
- **Tùy chỉnh các flow sau**: Lưu câu trả lời từ quiz dưới dạng thuộc tính tùy chỉnh, rồi nhắm mục tiêu một placement sau đó để mỗi phân khúc nhận được flow khác nhau, hoặc một paywall khác bên trong đó.
- **Hiển thị các giá trị tính toán từ câu trả lời**: Ví dụ, tính BMI từ cân nặng và chiều cao của người dùng, rồi [truyền vào một custom tag trong flow tiếp theo](android-flow-custom-tags#example-show-a-bmi-from-onboarding-answers).
- **Đẩy dữ liệu sang các nền tảng analytics bên thứ ba**: Chuyển tiếp câu trả lời tới Amplitude, Mixpanel, hoặc bất kỳ công cụ phân tích sản phẩm nào bạn đang dùng.

Các input và selectable group tự động báo cáo giá trị của chúng. Để phân biệt các input trong code, hãy đặt cho mỗi input một **Element ID** có ý nghĩa và mỗi selectable group một **Group ID** trong builder.

## Nhận giá trị đầu vào \{#receive-input-values\}

Giá trị đầu vào được chuyển đến cùng callback với mọi sự kiện analytics khác từ một flow, dưới tên sự kiện `flow_user_input`. Ghi đè `onAnalyticEvent` trên listener sự kiện flow của bạn:

```kotlin showLineNumbers title="Kotlin"
class MyFlowEventListener : AdaptyFlowDefaultEventListener() {

    override fun onAnalyticEvent(
        name: String,
        params: Map<String, Any?>,
        context: Context,
    ) {
        handleFlowInput(name, params)
    }
}
```

Callback `onAnalyticEvent` truyền tất cả các sự kiện analytics từ một flow, bao gồm [lượt xem màn hình](android-flow-screen-views). Để lọc các sự kiện nhập liệu của người dùng, hãy so sánh `name` với `flow_user_input`. Tham số lưu trữ giá trị phụ thuộc vào `element_type`:

| `element_type` | Tham số lưu trữ giá trị | Kiểu Kotlin |
|:---------------|:------------------------|:----------|
| `text_input`, `email_input`, `number_input`, `phone_input` | `value` | `String` |
| `date_picker`, `time_picker`, `date_time_picker` | `value` | `Long` trong SDK 4.3.0 trở lên, `Double` trong các phiên bản cũ hơn. Thời gian Unix tính bằng mili giây. Đọc qua `Number`. |
| `single_choice`, `multi_choice` | `item_ids`, `item_titles` | `List<String>` |
| `toggle` | `value` | `Boolean` |

Phần [Những gì bạn nhận được](#what-you-receive) liệt kê từng tham số và những gì mỗi phần tử builder báo cáo.

Lưu từng giá trị input khi listener nhận được, và gửi toàn bộ khi flow đóng lại. Để bắt được thời điểm đó, hãy override `onFlowClosed` trong `AdaptyFlowEventListener` của bạn. Hàm này chạy khi flow view bị đóng, dù người dùng đã hoàn thành flow hay đóng giữa chừng.

## Các trường hợp sử dụng \{#use-cases\}

### Đăng ký người dùng trên backend của bạn \{#register-users-on-your-backend\}

Thu thập các giá trị khi chúng đến và gửi chúng một lần khi flow đóng lại, để một request mang đầy đủ tất cả câu trả lời.

Flow đóng lại dù người dùng đã hoàn thành hay bỏ dở giữa chừng. Hãy kiểm tra các trường bạn cần trước khi gọi backend.

Flow không thể hiển thị lỗi từ backend của bạn. Callback không có giá trị trả về, và SDK không có phương thức nào gửi dữ liệu vào flow đang chạy. Nếu đăng ký thất bại, chẳng hạn do email đã được sử dụng, hãy hiển thị lỗi trong giao diện của bạn sau khi flow đóng lại.

```kotlin showLineNumbers title="Kotlin"
class MyFlowEventListener : AdaptyFlowDefaultEventListener() {

    private val flowAnswers = mutableMapOf<String, String>()

    override fun onAnalyticEvent(
        name: String,
        params: Map<String, Any?>,
        context: Context,
    ) {
        if (name != "flow_user_input") return

        val elementId = params["element_id"] as? String ?: return
        val value = params["value"] as? String ?: return

        flowAnswers[elementId] = value
    }

    override fun onFlowClosed() {
        if (!flowAnswers.containsKey("email")) return

        // Send flowAnswers to your backend here to create the account.

        flowAnswers.clear()
    }
}
```

### Làm phong phú hồ sơ người dùng với dữ liệu \{#enrich-user-profiles-with-data\}

Để liên kết dữ liệu người dùng nhập với hồ sơ của họ và tránh hỏi lại thông tin đã có, hãy [cập nhật hồ sơ người dùng](android-setting-user-attributes) ngay khi nhận được giá trị.

Ví dụ, nếu flow của bạn có ô nhập văn bản với Element ID là `name` và ô nhập email với Element ID là `email`:

```kotlin showLineNumbers title="Kotlin"
private fun handleFlowInput(name: String, params: Map<String, Any?>) {
    if (name != "flow_user_input") return

    val elementId = params["element_id"] as? String ?: return
    val value = params["value"] as? String ?: return

    val builder = AdaptyProfileParameters.Builder()

    when (elementId) {
        "name" -> builder.withFirstName(value)
        "email" -> builder.withEmail(value)
        else -> return
    }

    Adapty.updateProfile(builder.build()) { error ->
        if (error != null) {
            // handle the error
        }
    }
}
```

### Tùy chỉnh các flow hiển thị sau \{#customize-flows-shown-later\}

Câu trả lời quiz cũng có thể quyết định những gì người dùng thấy tại một [placement](placements) sau đó — một flow khác, hoặc một paywall khác bên trong đó.

Ví dụ: hỏi người dùng về kinh nghiệm thể thao của họ trong onboarding flow, sau đó hiển thị cho mỗi nhóm flow riêng với các sản phẩm và nội dung khác nhau.

1. Thêm một [quiz](onboarding-quizzes) vào flow của bạn. Đặt cho [selectable group](flow-selectable-elements) Group ID là `experience`, và mỗi tùy chọn một Element ID có ý nghĩa.
2. Xử lý các câu trả lời và [thiết lập custom attributes](android-setting-user-attributes) cho người dùng.

```kotlin showLineNumbers title="Kotlin"
private fun handleFlowInput(name: String, params: Map<String, Any?>) {
    if (name != "flow_user_input") return
    if (params["element_id"] != "experience") return

    val optionId = (params["item_ids"] as? List<*>)?.firstOrNull() as? String ?: return

    val builder = AdaptyProfileParameters.Builder()
    // Set the custom attribute 'experience' to the option the user selected
    // (beginner, amateur, or pro).
    builder.withCustomAttribute("experience", optionId)

    Adapty.updateProfile(builder.build()) { error ->
        if (error != null) {
            // handle the error
        }
    }
}
```

3. [Tạo một phân khúc](segments) cho mỗi giá trị thuộc tính tùy chỉnh.
4. Tạo một [placement](placements) và thêm một [đối tượng](audience) cho mỗi phân khúc.
5. [Hiển thị flow](android-present-paywalls) cho placement đó trong ứng dụng của bạn.
