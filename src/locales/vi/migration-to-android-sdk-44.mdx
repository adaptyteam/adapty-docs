Để cập nhật ứng dụng từ Adapty Android SDK 4.1, 4.2 hoặc 4.3 lên 4.4, hãy đặt phiên bản `adapty-bom` thành `4.4.0` và thay thế file fallback trong cùng bản build. Các phiên bản SDK 4.1–4.3 sẽ từ chối file mới. Nếu ứng dụng đang dùng 4.0, bạn cần thực hiện [các thay đổi v4.1](migration-to-android-sdk-41) trước.

:::warning
Định dạng file dự phòng đã thay đổi trong phiên bản 4.4, và trình biên dịch không thể phát hiện file lỗi thời. Nếu không có [file dự phòng mới](#replace-the-fallback-file), mọi placement sẽ mất paywall dự phòng.
:::

## Thay thế file dự phòng \{#replace-the-fallback-file\}

Để tải lại [file dự phòng](fallback-flows), trong **[Placements](https://app.adapty.io/placements)**, nhấp vào **Fallbacks** > **Download Android Fallback**. Trong hàng **Adapty SDK v4.4.0 and higher**, nhấp vào **Download**. Đóng gói file này vào ứng dụng của bạn.

File được tải về có tên `android_4_4_0_fallback.json`. Đặt lại tên file theo tên mà ứng dụng của bạn đang tải, hoặc cập nhật tên trong lệnh gọi để tải nó:

- **`FileLocation.fromAsset`**: Tên tệp, ví dụ `android_fallback.json`.
- **`FileLocation.fromResId`**: Tên tài nguyên, ví dụ `android_fallback` trong `R.raw.android_fallback`.

Với tệp lỗi thời, `Adapty.setFallback` sẽ truyền `AdaptyError` vào callback với thông báo "The fallback file version is not correct. Download a new one from the Adapty Dashboard." Để xác minh tệp mới, hãy chạy ứng dụng và đảm bảo rằng callback này không nhận được lỗi nào. Callback là tùy chọn. Nếu không dùng callback, hãy đặt [log level](sdk-installation-android#logging) thành `AdaptyLogLevel.ERROR` hoặc mức chi tiết hơn, rồi đảm bảo rằng Logcat không hiển thị lỗi này.
