Để cập nhật ứng dụng của bạn từ Adapty Android SDK 4.1, 4.2 hoặc 4.3 lên 4.4, hãy đặt phiên bản `adapty-bom` thành `4.4.0` và thay thế file dự phòng trong cùng bản build đó. Các phiên bản SDK 4.1–4.3 sẽ từ chối file mới. Nếu code Java của bạn gọi `AdaptyFlowView.showFlow`, hãy thêm một đối số vào mỗi lần gọi. Ứng dụng đang dùng 4.0 cần thực hiện [các thay đổi v4.1](migration-to-android-sdk-41) trước.

:::warning
Định dạng file dự phòng đã thay đổi trong phiên bản 4.4 và trình biên dịch không thể phát hiện file cũ. Nếu không có [file dự phòng mới](#replace-the-fallback-file), mọi placement sẽ mất paywall dự phòng của nó.
:::

## Thay thế file dự phòng \{#replace-the-fallback-file\}

Để tải lại [file dự phòng](fallback-flows), trong **[Placements](https://app.adapty.io/placements)**, nhấp vào **Fallbacks** > **Download Android Fallback**. Trong hàng **Adapty SDK v4.4.0 and higher**, nhấp vào **Download**. Đóng gói file này vào ứng dụng của bạn.

File được tải về có tên `android_4_4_0_fallback.json`. Đặt lại tên file theo tên mà ứng dụng của bạn đang tải, hoặc cập nhật tên trong lệnh gọi để tải nó:

- **`FileLocation.fromAsset`**: Tên tệp, ví dụ `android_fallback.json`.
- **`FileLocation.fromResId`**: Tên tài nguyên, ví dụ `android_fallback` trong `R.raw.android_fallback`.

Với tệp cũ, `Adapty.setFallback` sẽ truyền một `AdaptyError` vào callback với thông báo "The fallback file version is not correct. Download a new one from the Adapty Dashboard." Để xác minh tệp mới, hãy chạy ứng dụng và đảm bảo callback này không nhận được lỗi. Callback là tùy chọn. Nếu không có callback, hãy đặt thuộc tính [`Adapty.logLevel`](sdk-installation-android#logging) thành `AdaptyLogLevel.ERROR` hoặc mức chi tiết hơn, rồi đảm bảo rằng Logcat không hiển thị lỗi này.

## Thêm tham số vào lệnh gọi showFlow trong Java \{#add-an-argument-to-showflow-calls-in-java\}

Trong 4.4, `AdaptyFlowView.showFlow` có thêm tham số cuối mới là `customElementsResolver`. Code Java phải truyền đầy đủ tất cả tham số của `showFlow`, do đó lệnh gọi với tám tham số sẽ không biên dịch được. Hãy truyền `null` làm tham số cuối:

```diff showLineNumbers
  flowView.showFlow(flowConfiguration, products, eventListener, insets,
-         customAssets, tagResolver, timerResolver, observerModeHandler);
+         customAssets, tagResolver, timerResolver, observerModeHandler, null);
```

Kotlin calls to `showFlow` and all calls to `AdaptyUI.getFlowView` compile without changes.
