Hỏi AI coding agent về analytics Adapty của bạn bằng ngôn ngữ thông thường — doanh thu, tỷ lệ chuyển đổi, retention, LTV — và để agent tự lấy số liệu cho bạn. Agent chạy các [lệnh analytics Adapty CLI](developer-cli-analytics) trong terminal của bạn và đọc kết quả.

## Những gì bạn có thể hỏi \{#what-you-can-ask-about\}

CLI trả về các con số giống như những gì Adapty Analytics dashboard hiển thị. Mỗi loại câu hỏi tương ứng với một lệnh:

| Câu hỏi về | Nội dung | Lệnh |
| --- | --- | --- |
| Revenue, MRR, ARR, ARPU và các biểu đồ khác | Một chỉ số theo thời gian, được nhóm theo một chiều mà biểu đồ hỗ trợ, chẳng hạn như quốc gia | `adapty analytics chart` |
| Tỷ lệ chuyển đổi | Số lượng người dùng chuyển từ bước này sang bước tiếp theo, chẳng hạn như từ dùng thử sang trả phí | `adapty analytics conversion` |
| Phễu | Nơi người dùng rời bỏ giữa lúc cài đặt và gia hạn | `adapty analytics funnel` |
| Retention | Số lượng người đăng ký còn lại sau mỗi kỳ | `adapty analytics retention` |
| Lifetime value (LTV) | Doanh thu trên mỗi người dùng trả phí sau mỗi lần gia hạn hoặc mỗi ngày | `adapty analytics ltv` |
| Cohort cài đặt | Doanh thu, số người đăng ký và các dự đoán cho người dùng đã cài đặt trong cùng một khoảng thời gian | `adapty analytics cohort` |

Mọi lệnh đều ở chế độ chỉ đọc. Agent không thể thay đổi bất cứ điều gì trong tài khoản Adapty của bạn thông qua chúng.

## Trước khi bắt đầu \{#before-you-start\}

Bạn cần ba thứ sau:

- **Tài khoản Adapty có dữ liệu**: CLI trả về các con số giống hệt dashboard của bạn, vì vậy app của bạn phải đã thu thập analytics.
- **Adapty CLI phiên bản 0.10.0 trở lên, đã đăng nhập**: Để cài CLI và đăng nhập, chạy các lệnh sau. Quá trình đăng nhập sẽ mở một tab trình duyệt để bạn xác nhận mã từ terminal.

  ```bash
  npm install -g adapty
  ```

  ```bash
  adapty auth login
  ```

  Một lần đăng nhập sẽ đọc được tất cả các app mà tài khoản Adapty của bạn có quyền truy cập, nên bạn không cần API key.

- **Một công cụ AI có thể chạy lệnh terminal**: Ví dụ như Claude Code, Cursor, Codex hoặc Gemini CLI. Các công cụ chat thông thường như claude.ai hay ChatGPT không thể chạy CLI.

## Cấp lệnh cho agent của bạn \{#give-your-agent-the-commands\}

[Tài liệu tham khảo CLI analytics](https://adapty.io/docs/vi/developer-cli-analytics.md) mô tả mọi lệnh, các flag của chúng, và cách đọc kết quả. Sau khi agent đọc xong, nó sẽ tự xây dựng các lệnh đúng mà không cần bạn phải viết tay.

Cung cấp tài liệu tham khảo cho agent qua URL: nếu agent của bạn có thể tải URL, hãy cung cấp `https://adapty.io/docs/vi/developer-cli-analytics.md` và yêu cầu nó đọc trang đó.

Tác nhân không cần biết tên biểu đồ của bạn trước. Nó tự tìm bằng lệnh `adapty analytics catalog --app <app-id>`, lệnh này liệt kê mọi biểu đồ, conversion, nhóm và bộ lọc mà ứng dụng của bạn hỗ trợ.

## Hỏi về dữ liệu của bạn \{#ask-about-your-data\}

Với reference đã được tải và CLI đã đăng nhập, hãy chỉ rõ tên app, chỉ số, khoảng thời gian và điều bạn muốn quyết định.

Ví dụ về các câu lệnh:

```
For my app "Sleep Tracker", what was MRR at the end of each month this year,
and how does it compare to the same months last year?

Show the trial-to-paid conversion rate for the last 90 days, by product.
Which product converts worst?

Which 10 countries brought the most revenue in Q3? Use revenue after the
store's commission.

How does retention compare between iOS and Android for subscribers who started
in the last 6 months?

Compare LTV after 30 and 90 days for users who installed in July and in August,
and save it as a CSV file.
```

Tác nhân tìm UUID của ứng dụng bằng `adapty apps list`, chọn lệnh phù hợp và trả về dữ liệu. Kết quả được đọc dưới dạng JSON (`--json`). Yêu cầu CSV khi bạn muốn file sẵn sàng cho bảng tính — tác nhân sẽ thêm `--csv` vào lệnh.

## Thiết lập một lần để dùng nhiều lần \{#set-up-once-for-repeated-use\}

Để không phải lặp lại quá trình thiết lập mỗi phiên làm việc, hãy lưu tài liệu tham chiếu để agent của bạn có thể tái sử dụng:

- **Lưu đường dẫn tham khảo**: Thêm `https://adapty.io/docs/vi/developer-cli-analytics.md` vào file quy tắc hoặc bộ nhớ của agent (ví dụ: file `CLAUDE.md` hoặc file quy tắc Cursor) để nó tải vào mỗi phiên làm việc.
- **Đặt tên ứng dụng**: Thêm tên hoặc UUID của ứng dụng vào cùng file đó, để bạn không cần phải chỉ định tên trong mỗi câu lệnh.
- **Lưu các câu lệnh hay dùng hoặc tạo skill tùy chỉnh**: Lưu các câu hỏi thường gặp dưới dạng câu lệnh đã lưu, hoặc đóng gói chúng vào một skill hoặc lệnh slash tùy chỉnh để agent chạy báo cáo theo yêu cầu.

## Giới hạn \{#limits\}

Hãy lưu ý các ràng buộc sau:

- **Giới hạn tốc độ**: Mỗi lệnh analytics cho phép 2 request mỗi giây trên mỗi app. CLI không tự thử lại, vì vậy lệnh gửi quá nhanh sẽ thất bại với exit code 4. Hãy yêu cầu agent chạy các lệnh tuần tự và chờ `retry_after_seconds` trước khi chạy lại lệnh bị lỗi.
- **Một app mỗi lệnh**: Mỗi lệnh chỉ đọc một app. Để so sánh các app, agent chạy một lệnh cho mỗi app.
- **Không cộng vào Attribution**: Để xem chi tiêu quảng cáo, lượt cài đặt và ROAS theo chiến dịch, hãy dùng [lệnh Attribution](developer-cli-attribution). Đừng cộng các số liệu đó vào số liệu analytics vì Adapty tính toán chúng theo cách khác.

Để lấy dữ liệu analytics từ server hoặc một scheduled job, nơi không ai có thể đăng nhập qua trình duyệt, hãy sử dụng [Export Analytics API](export-analytics-api) với secret API key.
