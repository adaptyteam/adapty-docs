Khôi phục giao dịch mua trên cả iOS và Android là tính năng cho phép người dùng lấy lại quyền truy cập vào nội dung đã mua trước đó — chẳng hạn như gói đăng ký hoặc in-app purchase — mà không bị tính phí thêm. Tính năng này đặc biệt hữu ích cho những người dùng đã gỡ cài đặt rồi cài lại ứng dụng, hoặc chuyển sang thiết bị mới và muốn tiếp tục sử dụng nội dung đã mua mà không cần thanh toán lại.

:::note
Nếu bạn xây dựng màn hình bằng builder, bạn không cần tự khôi phục giao dịch mua theo cách thủ công. Chỉ cần kết nối control khôi phục — hành động **Restore purchases** trong Flow & Paywall Builder, hoặc link/nút khôi phục trong phiên bản cũ — và SDK sẽ tự hoàn thành việc khôi phục.
:::

Nếu bạn tự xây dựng màn hình, hãy gọi phương thức `.restorePurchases()`:

```typescript showLineNumbers

try {
  const profile = await adapty.restorePurchases();
  const isSubscribed = profile.accessLevels?.['YOUR_ACCESS_LEVEL']?.isActive;
  
  if (isSubscribed) {
    // Restore access to paid features
    console.log('Access restored successfully!');
  } else {
    console.log('No active subscriptions found');
  }
} catch (error) {
  console.error('Failed to restore purchases:', error);
}
```

Tham số phản hồi:

| Tham số | Mô tả |
|---------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **profile** | Một đối tượng [`AdaptyProfile`](https://capacitor.adapty.io/interfaces/adaptyprofile). Model này chứa thông tin về các mức độ truy cập, gói đăng ký và các sản phẩm mua một lần. Kiểm tra **trạng thái mức độ truy cập** để xác định xem người dùng có quyền truy cập vào ứng dụng hay không. |
