[Custom tag](flow-custom-tags) là một biến tùy chỉnh với giá trị đến từ ứng dụng của bạn. Sau khi bạn chọn **Value comes from outside the app** trong cài đặt của một biến, ứng dụng của bạn có thể đặt giá trị của nó thông qua Adapty SDK. Ví dụ: một phần tử văn bản chứa "Coins:" và một custom tag. Nếu ứng dụng của bạn truyền 120 cho tag đó, người dùng sẽ thấy "Coins: 120".

## Truyền giá trị custom tag \{#pass-custom-tag-values\}

Truyền các giá trị của ứng dụng vào tham số `customTags` của `AdaptyUI.createFlowView` hoặc `createNativeFlowView`, dưới dạng `Map<String, String>`:

- Mỗi key là tên đầy đủ của một custom tag, ví dụ `user.streak`.
- Mỗi value là chuỗi mà người dùng sẽ thấy thay cho tag đó.
- Mỗi value phải ở dạng người đọc được, ví dụ "1,250" thay vì "1250.0". Adapty không tự định dạng hay dịch giá trị này.

SDK đọc các giá trị một lần duy nhất khi tạo view, nên chúng sẽ không thay đổi trong khi flow đang mở.

<Tabs>
<TabItem value="standalone" label="With Compose Multiplatform" default>

```kotlin showLineNumbers title="Kotlin Multiplatform"

viewModelScope.launch {
    val customTags = mapOf(
        "username" to "DragonSlayer42",
        "coins" to "1,250",
    )

    AdaptyUI.createFlowView(
        flow = flow,
        customTags = customTags,
    ).onSuccess { view ->
        view.present()
    }.onError { error ->
        // handle the error
    }
}
```

Để nhúng flow vào bố cục Compose, hãy truyền cùng tham số `customTags` vào composable `AdaptyUIFlowPlatformView`. Nếu bạn truyền một map `customTags` khác, composable sẽ tạo một view mới và người dùng sẽ quay lại màn hình đầu tiên của flow.

### Truyền chỉ số BMI vào paywall

Thu thập cân nặng và chiều cao từ các sự kiện `flow_user_input` của onboarding flow, như trong [Xử lý dữ liệu từ flow](kmp-flow-input). Để biết người dùng đã đến màn hình cuối cùng, theo dõi sự kiện `flow_screen_showed` với `is_last_screen` được đặt thành `true`, như trong [Theo dõi lượt xem màn hình flow](kmp-flow-screen-views). Khi người dùng đóng onboarding flow sau màn hình đó, hãy tính BMI. Sau đó tạo view cho paywall và truyền BMI vào custom tag `bmi`.

Phương thức `flowViewDidReceiveAnalyticEvent` phân tích các tham số sự kiện bằng thư viện `kotlinx.serialization.json`. Nếu dự án của bạn chưa có thư viện này, hãy thêm `org.jetbrains.kotlinx:kotlinx-serialization-json` vào phần dependencies của ứng dụng. Sau đó triển khai các phương thức sau trên observer mà bạn đăng ký với `AdaptyUI.setFlowsEventsObserver`:

```kotlin showLineNumbers title="Kotlin Multiplatform"

class MyFlowsEventsObserver(
    private val scope: CoroutineScope,
) : AdaptyUIFlowsEventsObserver {

    private val bodyAnswers = mutableMapOf<String, String>()
    private var reachedLastScreen = false

    override fun flowViewDidReceiveAnalyticEvent(
        view: AdaptyUIFlowView,
        name: String,
        paramsJsonString: String,
    ) {
        if (name != "flow_user_input" && name != "flow_screen_showed") return

        val params = Json.parseToJsonElement(paramsJsonString).jsonObject
        if (name == "flow_screen_showed") {
            if (params["is_last_screen"]?.jsonPrimitive?.booleanOrNull == true) {
                reachedLastScreen = true
            }
            return
        }
        val elementId = params["element_id"]?.jsonPrimitive?.content ?: return
        val value = params["value"]?.jsonPrimitive?.contentOrNull ?: return

        bodyAnswers[elementId] = value
    }

    override fun flowViewDidDisappear(view: AdaptyUIFlowView) {
        // The observer receives events from every flow. Reset `bodyAnswers` and
        // `reachedLastScreen` whenever a flow disappears, so that the paywall
        // doesn't open again when the user closes it.
        val answers = bodyAnswers.toMap()
        val finished = reachedLastScreen
        bodyAnswers.clear()
        reachedLastScreen = false

        // Number inputs send their values as strings.
        if (!finished) return
        val weight = answers["weight"]?.toDoubleOrNull() ?: return
        val height = answers["height"]?.toDoubleOrNull()?.takeIf { it > 0 } ?: return

        val heightInMeters = height / 100
        val bmi = weight / (heightInMeters * heightInMeters)
        val bmiText = ((bmi * 10).roundToInt() / 10.0).toString()

        scope.launch { showBmiPaywall(bmiText) }
    }
}

suspend fun showBmiPaywall(bmi: String) {
    Adapty.getFlow(placementId = "bmi_paywall").onSuccess { flow ->
        AdaptyUI.createFlowView(
            flow = flow,
            customTags = mapOf("bmi" to bmi),
        ).onSuccess { view ->
            view.present()
        }.onError { error ->
            // handle the error
        }
    }.onError { error ->
        // handle the error
    }
}
```

`toString` luôn dùng dấu chấm làm dấu thập phân: "22.7". Để dùng dấu thập phân theo ngôn ngữ của người dùng, hãy định dạng BMI bằng formatter phù hợp với từng nền tảng, chẳng hạn như `java.text.NumberFormat` trên Android và `NSNumberFormatter` trên iOS.

### Lưu chỉ số BMI vào hồ sơ người dùng \{#save-the-bmi-to-the-users-profile\}

Để hiển thị cho người dùng các flow khác nhau dựa trên chỉ số BMI, hãy lưu chỉ số này dưới dạng [thuộc tính tùy chỉnh](kmp-setting-user-attributes#custom-user-attributes) trong hồ sơ của họ. Trên Adapty Dashboard, [tạo một thuộc tính tùy chỉnh kiểu **Number**](segments#custom-attributes) với key `bmi`. Sau đó hiển thị mỗi flow cho một [đối tượng](audience) được xây dựng từ thuộc tính này.

Gọi phương thức `updateProfile` sau khi tính xong chỉ số BMI. Lưu dưới dạng số, không phải chuỗi đã định dạng, để một phân khúc có thể so sánh chỉ số BMI với một ngưỡng nhất định:

```kotlin showLineNumbers title="Kotlin Multiplatform"

val params = AdaptyProfileParameters.Builder()
    .withCustomAttribute("bmi", bmi)
    .build()

scope.launch {
    Adapty.updateProfile(params).onError { error ->
        // handle the error
    }
}
```
