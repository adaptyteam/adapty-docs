## Trước khi bắt đầu \{#before-you-start\}

- Cập nhật ứng dụng của bạn lên Adapty Flutter SDK 4.4 trở lên. Các phiên bản SDK cũ hơn sẽ hiển thị [nội dung dự phòng](flow-custom-elements#set-fallback-content) cho mọi phần tử tùy chỉnh.
- Thiết lập ứng dụng để [tải](flutter-get-pb-paywalls) và [hiển thị](flutter-present-paywalls) flow.
- Thiết lập code native cho ứng dụng để dùng các phần tử tùy chỉnh, theo [hướng dẫn Flutter](flutter-flow-custom-elements#before-you-start).
- Trên iOS, thêm Lottie vào target `Runner` trong Xcode bằng Swift Package Manager, từ `https://github.com/airbnb/lottie-spm.git`.
- Trên Android, thiết lập Jetpack Compose trong module ứng dụng của bạn. View animation trong recipe này là một composable. Thêm Lottie cho Jetpack Compose vào ứng dụng bằng Gradle, từ `com.airbnb.android:lottie-compose`.

## 2. Thêm file animation vào ứng dụng \{#2-add-the-animation-file-to-your-app\}

Code native của bạn đọc file animation từ dự án iOS và Android, không phải từ thư mục `assets` của Flutter:

- **iOS**: Thêm file vào target `Runner` trong Xcode.
- **Android**: Đặt file vào `android/app/src/main/assets`, thư mục `assets` của module ứng dụng Android. Giữ file ở thư mục gốc, không đặt trong thư mục con.

Tên file không có `.json` phải khớp với ID của custom element, ví dụ `streak_ring.json` tương ứng với `streak_ring`.

## 3. Tạo animation view \{#create-the-animation-view\}

Tạo một model cho streak và một view phát animation. App của bạn cập nhật model khi streak thay đổi. View đọc từ model, vì vậy vòng tròn hiển thị streak hiện tại khi màn hình mở ra:

<Tabs groupId="platform" queryString>
<TabItem value="ios" label="iOS (Swift)" default>

```swift showLineNumbers title="Swift"

// The streak that your app keeps up to date
@MainActor
final class StreakStore: ObservableObject {
    @Published var currentStreak = 0 // days in a row
}

struct StreakRingView: View {
    let animation: LottieAnimation
    @ObservedObject var streakStore: StreakStore

    // 7 days fill the ring: from 0 for an empty ring to 1 for a full one
    private var progress: AnimationProgressTime {
        min(AnimationProgressTime(streakStore.currentStreak) / 7, 1)
    }

    var body: some View {
        LottieView(animation: animation)
            .resizable()
            .playing(.fromProgress(0, toProgress: progress, loopMode: .playOnce))
    }
}
```

`.playing(.fromProgress(0, toProgress: progress, loopMode: .playOnce))` điền vào vòng tròn một lần, từ trống đến `progress`.

</TabItem>
<TabItem value="android" label="Android (Kotlin)">

```kotlin showLineNumbers title="Kotlin"

// the streak that your app keeps up to date
class StreakStore {
    val currentStreak = MutableStateFlow(0) // days in a row
}

@Composable
fun StreakRing(animationFile: String, streakStore: StreakStore) {
    val composition by rememberLottieComposition(LottieCompositionSpec.Asset(animationFile))
    val streak by streakStore.currentStreak.collectAsState()

    // 7 days fill the ring: from 0 for an empty ring to 1 for a full one
    val progress = minOf(streak / 7f, 1f)

    LottieAnimation(
        composition = composition,
        modifier = Modifier.fillMaxSize(), // scale the animation to fit the custom element
        clipSpec = LottieClipSpec.Progress(0f, progress),
    )
}
```

`clipSpec = LottieClipSpec.Progress(0f, progress)` điền vào vòng tròn một lần, từ trống đến `progress`.

## 4. Khớp animation với custom element \{#match-the-animation-to-the-custom-element\}

Trong [resolver toàn ứng dụng](flutter-flow-custom-elements#pass-the-resolver-to-the-sdk) của bạn, thêm một property cho streak model. Sau đó trả về animation view cho Type `lottie_animation` và ID `streak_ring`. Các dòng được highlight cho thấy những gì cần thêm hoặc thay đổi. Nếu ứng dụng của bạn chưa có [resolver](flutter-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views) toàn ứng dụng, hãy sao chép toàn bộ đoạn code:

<Tabs groupId="platform" queryString>
<TabItem value="ios" label="iOS (Swift)" default>

```swift showLineNumbers title="Swift" {6,14-18}

struct CustomElementsResolver: AdaptyUICustomElementsResolver {
    let streakStore: StreakStore

    func view(
        forType type: String,
        id: String,
        context: AdaptyUICustomElementContext
    ) -> AnyView? {
        switch type {
        case "lottie_animation" where id == "streak_ring":
            guard let animation = LottieAnimation.named(id) else {
                return nil // no animation file: show the fallback
            }
            return AnyView(StreakRingView(animation: animation, streakStore: streakStore))
        // the other cases of your resolver
        default:
            return nil
        }
    }
}
```

Đặt case `streak_ring` trước bất kỳ case `lottie_animation` nào khác, vì Swift chỉ chạy case đầu tiên khớp. Nếu app bundle không có file cho ID đó, resolver sẽ trả về `nil` và người dùng sẽ thấy fallback.

</TabItem>
<TabItem value="android" label="Android (Kotlin)">

```kotlin showLineNumbers title="Kotlin" {8,22-28}

class CustomElementsResolver(
    context: Context,
    private val streakStore: StreakStore,
) : AdaptyCustomElementsResolver {
    // the animation files in the assets folder, listed once
    private val animationFiles: Set<String> = try {
        context.assets.list("").orEmpty().toSet()
    } catch (e: IOException) {
        emptySet() // no list of files: every Lottie element shows the fallback
    }

    override fun resolve(type: String, id: String): AdaptyCustomElementContent? =
        when (type) {
            "lottie_animation" -> {
                // the ID names the animation file, such as streak_ring.json
                val file = "$id.json"
                when {
                    file !in animationFiles -> null // no file for this ID: show the fallback
                    id == "streak_ring" ->
                        AdaptyCustomElementContent.compose { StreakRing(file, streakStore) }
                    // the other animations of your resolver
                    else -> null
                }
            }
            // the other Types of your resolver
            else -> null
        }
}
```

Nếu thư mục `assets` không có file nào khớp với ID, resolver sẽ trả về `null` và người dùng sẽ thấy phần dự phòng. Nếu resolver của bạn đã trả về [view cho mọi file animation](flutter-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views), hãy trả về view đó thay vì `null` khi ID không phải là `streak_ring`. Như vậy, người dùng vẫn thấy được các animation của các custom element `lottie_animation` khác.

</TabItem>
</Tabs>

## 5. Gửi streak từ mã Dart của bạn \{#5-send-the-streak-from-your-dart-code\}

Mã Dart của bạn lưu trữ streak, và các view native đọc nó từ streak model. Để cập nhật model, hãy gửi streak sang mã native thông qua một [platform channel](https://docs.flutter.dev/platform-integration/platform-channels). Trong mã iOS và Android của bạn, hãy lắng nghe channel:

<Tabs groupId="platform" queryString>
<TabItem value="ios" label="iOS (Swift)" default>

Trong phương thức `didInitializeImplicitFlutterEngine` của class `AppDelegate`, thêm các dòng được highlight:

```swift showLineNumbers title="ios/Runner/AppDelegate.swift" {3-14}
func didInitializeImplicitFlutterEngine(_ engineBridge: FlutterImplicitEngineBridge) {
  GeneratedPluginRegistrant.register(with: engineBridge.pluginRegistry)
  let streakChannel = FlutterMethodChannel(
    name: "custom_elements/streak",
    binaryMessenger: engineBridge.applicationRegistrar.messenger()
  )
  streakChannel.setMethodCallHandler { [streakStore] call, result in
    guard call.method == "setStreak", let days = call.arguments as? Int else {
      return result(FlutterMethodNotImplemented)
    }
    // the channel calls this handler on the main thread
    MainActor.assumeIsolated { streakStore.currentStreak = days }
    result(nil)
  }
}
```

:::note
Đoạn code `AppDelegate` trong hướng dẫn này theo mẫu iOS của Flutter 3.41 trở lên, sử dụng `FlutterImplicitEngineDelegate`. Nếu class `AppDelegate` của bạn không sử dụng nó, hãy bỏ qua protocol và phương thức `didInitializeImplicitFlutterEngine`. Thay vào đó, hãy tạo channel trong `application(_:didFinishLaunchingWithOptions:)`, trước `return super.application(...)`, với messenger của root view controller. Giữ nguyên lệnh gọi `GeneratedPluginRegistrant` theo mẫu của bạn:

```swift showLineNumbers title="ios/Runner/AppDelegate.swift"
GeneratedPluginRegistrant.register(with: self)
let controller = window?.rootViewController as! FlutterViewController
let streakChannel = FlutterMethodChannel(
  name: "custom_elements/streak",
  binaryMessenger: controller.binaryMessenger
)
```
:::

</TabItem>
<TabItem value="android" label="Android (Kotlin)">

Trong class `MainActivity`, override phương thức `configureFlutterEngine`:

```kotlin showLineNumbers title="Kotlin"

class MainActivity : FlutterFragmentActivity() {
    override fun configureFlutterEngine(flutterEngine: FlutterEngine) {
        super.configureFlutterEngine(flutterEngine)
        val streakStore = (application as App).streakStore
        MethodChannel(flutterEngine.dartExecutor.binaryMessenger, "custom_elements/streak")
            .setMethodCallHandler { call, result ->
                if (call.method == "setStreak") {
                    streakStore.currentStreak.value = call.arguments as Int
                    result.success(null)
                } else {
                    result.notImplemented()
                }
            }
    }
}
```

</TabItem>
</Tabs>

Trong code Dart của bạn, hãy gửi streak khi khởi động ứng dụng và mỗi khi streak thay đổi:

```dart showLineNumbers title="Flutter"

// your iOS and Android code listens to this channel
const streakChannel = MethodChannel('custom_elements/streak');

// call at app launch, and each time the streak changes
Future<void> sendStreak(int days) async {
  await streakChannel.invokeMethod('setStreak', days);
}
```
