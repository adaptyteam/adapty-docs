Nếu bạn sử dụng [chế độ Observer](observer-vs-full-mode), bạn tự chịu trách nhiệm cho logic mua hàng của mình. Nhưng bạn có thể ủy quyền giao diện paywall cho [Flow & Paywall Builder](adapty-flow-builder).

Thiết kế màn hình trong builder, và Adapty SDK sẽ render nó trực tiếp trên thiết bị. Cập nhật nội dung, bố cục và giá cả bất kỳ lúc nào mà không cần phát hành lại app. Khi người dùng nhấn nút mua hàng, SDK sẽ gọi code của bạn để hoàn tất giao dịch.

Hướng dẫn này trình bày cách hiển thị màn hình đó và xử lý lệnh gọi mua hàng. Nếu Adapty hoàn tất giao dịch thay cho bạn, hãy xem [Hiển thị flow & paywall](android-present-paywalls).

<SDKv4>

## Trước khi bắt đầu \{#before-you-start\}

Bạn cần:

- **Adapty Android SDK v4 trở lên**: Các phiên bản cũ hơn không thể render flow. Để chuyển từ v3, xem [hướng dẫn migration](migration-to-android-sdk-v4).
- **`observerMode` đặt thành `true`**: Xem [hướng dẫn cài đặt Android SDK](sdk-installation-android).
- **Tích hợp cửa hàng ban đầu**: Thiết lập Adapty [với Google Play](initial-android).
- **Một flow đã xuất bản với sản phẩm**: Xây dựng trong [Flow & Paywall Builder](adapty-flow-builder) và gán [sản phẩm](create-product) vào đó.
- **Một placement cho flow**: [Tạo một placement](create-placement) và gán flow của bạn vào đó.
- **Flow đã được tải trong ứng dụng**: [Lấy flow và cấu hình của nó](android-get-pb-paywalls) trước khi hiển thị.

## Triển khai \{#implementation\}

1. Triển khai `AdaptyUiObserverModeHandler`.

Sự kiện `onPurchaseInitiated` sẽ thông báo cho bạn biết người dùng đã khởi tạo một giao dịch mua. Bạn có thể kích hoạt flow mua hàng tùy chỉnh của mình trong callback này:

<TabItem value="kotlin" label="Kotlin" default>
   ```kotlin showLineNumbers
   val observerModeHandler =

       onStartPurchase()
       yourBillingClient.makePurchase(
           product,
           onSuccess = { purchase ->
               onFinishPurchase()
               //handle success
           },
           onError = {
               onFinishPurchase()
               //handle error
           },
           onCancel = {
               onFinishPurchase()
               //handle cancel
           }
       )
   }
   ```

<TabItem value="java" label="Java" default>
   ```java showLineNumbers
   AdaptyUiObserverModeHandler observerModeHandler = (product, onStartPurchase, onFinishPurchase) -> {
       onStartPurchase.invoke();

               onFinishPurchase.invoke();
               //handle success
           },
           error -> {
               onFinishPurchase.invoke();
               //handle error

           () -> { //cancellation
               onFinishPurchase.invoke();
               //handle cancel
           }
       );
   };
   ```

Để xử lý việc khôi phục trong Observer mode, hãy override `getRestoreHandler()`. Mặc định nó trả về `null`, tức là sử dụng flow `Adapty.restorePurchases()` tích hợp sẵn của Adapty. Để cung cấp implementation khôi phục của riêng bạn:

<Tabs groupId="current-os" queryString>
<TabItem value="kotlin" label="Kotlin" default>
   ```kotlin showLineNumbers
   val observerModeHandler = object : AdaptyUiObserverModeHandler {
       override fun onPurchaseInitiated(
           product: AdaptyPaywallProduct,
           onStartPurchase: AdaptyUiObserverModeHandler.PurchaseStartCallback,
           onFinishPurchase: AdaptyUiObserverModeHandler.PurchaseFinishCallback,
       ) {
           // the same body as the purchase example above
       }

       override fun getRestoreHandler() =
           AdaptyUiObserverModeHandler.RestoreHandler { onStartRestore, onFinishRestore ->
               onStartRestore()
               yourBillingClient.restorePurchases(
                   onSuccess = { restoredPurchases ->
                       onFinishRestore()
                       //handle successful restore
                   },
                   onError = {
                       onFinishRestore()
                       //handle error
                   }
               )
           }
   }
   ```
</TabItem>
<TabItem value="java" label="Java" default>
   ```java showLineNumbers
   AdaptyUiObserverModeHandler observerModeHandler = new AdaptyUiObserverModeHandler() {
       @Override
       public void onPurchaseInitiated(
           AdaptyPaywallProduct product,
           PurchaseStartCallback onStartPurchase,
           PurchaseFinishCallback onFinishPurchase
       ) {
           // the same body as the purchase example above
       }

       @Override
       public RestoreHandler getRestoreHandler() {
           return (onStartRestore, onFinishRestore) -> {
               onStartRestore.invoke();
               yourBillingClient.restorePurchases(
                   restoredPurchases -> {
                       onFinishRestore.invoke();
                       //handle successful restore
                   },
                   error -> {
                       onFinishRestore.invoke();
                       //handle error
                   }
               );
           };
       }
   };
   ```
</TabItem>
</Tabs>

Hãy nhớ gọi các callback sau để thông báo cho AdaptyUI biết về quá trình mua hàng hoặc khôi phục. Điều này cần thiết để flow hoạt động đúng, chẳng hạn như hiển thị loader:

| Callback           | Mô tả                                                                                               |
   | :----------------- |:----------------------------------------------------------------------------------------------------|
   | onStartPurchase()  | Callback này cần được gọi để thông báo cho AdaptyUI rằng quá trình mua đã bắt đầu.                 |
   | onFinishPurchase() | Callback này cần được gọi để thông báo cho AdaptyUI rằng quá trình mua đã hoàn tất.                |
   | onStartRestore()   | Tùy chọn. Callback này có thể được gọi để thông báo cho AdaptyUI rằng quá trình khôi phục đã bắt đầu. |
   | onFinishRestore()  | Tùy chọn. Callback này có thể được gọi để thông báo cho AdaptyUI rằng quá trình khôi phục đã hoàn tất. |

| Tham số | Bắt buộc | Mô tả |
|---------|--------|-----------|
| **flowConfiguration** | bắt buộc | Cung cấp một đối tượng `AdaptyUI.FlowConfiguration` chứa thông tin hiển thị của flow. Sử dụng phương thức `AdaptyUI.getFlowConfiguration(flow)` để tải nó. Tham khảo chủ đề [Fetch the view configuration](android-get-pb-paywalls#fetch-the-view-configuration) để biết thêm chi tiết. |
| **products** | tùy chọn | Cung cấp một mảng `AdaptyPaywallProduct` để tối ưu hóa thời điểm hiển thị sản phẩm trên màn hình. Nếu truyền `null`, AdaptyUI sẽ tự động tải các sản phẩm cần thiết. |
| **eventListener** | tùy chọn | Cung cấp một `AdaptyFlowEventListener` để theo dõi các sự kiện của flow. Nên kế thừa `AdaptyFlowDefaultEventListener` để dễ sử dụng hơn. Tham khảo chủ đề [Handle flow & paywall events](android-handling-events) để biết thêm chi tiết. |
| **insets** | tùy chọn | Insets là các khoảng trống xung quanh flow giúp các phần tử có thể nhấn không bị ẩn phía sau thanh hệ thống. Mặc định: `Unspecified`, cho phép Adapty tự động điều chỉnh insets. Xem [Change flow insets](android-present-paywalls#change-flow-insets). |
| **customAssets** | tùy chọn | Truyền một đối tượng `AdaptyCustomAssets` để thay thế hình ảnh và video trong flow của bạn ở runtime. Tham khảo [Customize assets](android-get-pb-paywalls#customize-assets) để biết thêm chi tiết. |
| **tagResolver** | tùy chọn | Sử dụng `AdaptyUiTagResolver` để xử lý các thẻ tùy chỉnh trong văn bản của flow. Resolver này nhận tham số là thẻ và chuyển đổi nó thành chuỗi tương ứng. |
| **observerModeHandler** | bắt buộc với Observer mode | `AdaptyUiObserverModeHandler` mà bạn đã triển khai ở bước trước. |

Đừng quên [liên kết paywall với giao dịch mua hàng](report-transactions-observer-mode-android). Nếu không, Adapty sẽ không xác định được nguồn flow của giao dịch.
:::

1. Triển khai `AdaptyUiObserverModeHandler`. Callback của `AdaptyUiObserverModeHandler` (`onPurchaseInitiated`) thông báo cho bạn khi người dùng bắt đầu thực hiện mua hàng. Bạn có thể kích hoạt flow mua hàng tùy chỉnh của mình khi nhận được callback này như sau:

<Tabs groupId="current-os" queryString>
<TabItem value="kotlin" label="Kotlin" default>
   ```kotlin showLineNumbers
   val observerModeHandler =
   AdaptyUiObserverModeHandler { product, paywall, paywallView, onStartPurchase, onFinishPurchase ->
       onStartPurchase()
       yourBillingClient.makePurchase(
           product,
           onSuccess = { purchase ->
               onFinishPurchase()
               //handle success
           },
           onError = {
               onFinishPurchase()
               //handle error
           },
           onCancel = {
               onFinishPurchase()
               //handle cancel
           }
       )
   }
   ```
</TabItem>
<TabItem value="java" label="Java" default>
   ```java showLineNumbers
   AdaptyUiObserverModeHandler observerModeHandler = (product, paywall, paywallView, onStartPurchase, onFinishPurchase) -> {
       onStartPurchase.invoke();
       yourBillingClient.makePurchase(
           product,
           purchase -> {
               onFinishPurchase.invoke();
               //handle success
           },
           error -> {
               onFinishPurchase.invoke();
               //handle error
           },
           () -> { //cancellation
               onFinishPurchase.invoke();
               //handle cancel
           }
       );
   };
   ```

| Callback trong Kotlin | Callback trong Java       | Mô tả                                                                                                                                                    |
   | :-------------------- | :------------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------- |
   | onStartPurchase()     | onStartPurchase.invoke()  | Callback này cần được gọi để thông báo cho AdaptyUI rằng quá trình mua đã bắt đầu.                                                                      |
   | onFinishPurchase()    | onFinishPurchase.invoke() | Callback này cần được gọi để thông báo cho AdaptyUI rằng quá trình mua đã kết thúc (thành công hay không), hoặc quá trình mua đã bị hủy. |

   ```kotlin showLineNumbers
   import androidx.core.view.ViewCompat
   import androidx.core.view.WindowInsetsCompat

   //create extension function
   fun View.onReceiveSystemBarsInsets(action: (insets: Insets) -> Unit) {
       ViewCompat.setOnApplyWindowInsetsListener(this) { _, insets ->
           val systemBarInsets = insets.getInsets(WindowInsetsCompat.Type.systemBars())
           ViewCompat.setOnApplyWindowInsetsListener(this, null)
           action(systemBarInsets)
           insets
       }
   }
   //and then use it with the view
   paywallView.onReceiveSystemBarsInsets { insets ->
       val paywallInsets = AdaptyPaywallInsets.of(insets.top, insets.bottom)
       paywallView.setEventListener(eventListener)
       paywallView.setObserverModeHandler(observerModeHandler)
       paywallView.showPaywall(viewConfig, products, paywallInsets, personalizedOfferResolver, tagResolver)
   }
   ```
