Nếu bạn đã tạo một flow hoặc paywall bằng Flow Builder hoặc Paywall Builder, bạn không cần lo lắng về việc render nó trong code ứng dụng di động để hiển thị cho người dùng. Flow hoặc paywall như vậy đã bao gồm cả nội dung cần hiển thị lẫn cách hiển thị nó.

:::warning
Phần này chỉ áp dụng cho [Observer mode](observer-vs-full-mode). Nếu bạn không làm việc ở Observer mode, hãy tham khảo chủ đề [Android - Hiển thị flow & paywall](android-present-paywalls) thay thế.
:::

:::tip
Hãy xây dựng flow trong [Flow Builder](adapty-flow-builder).
:::

1. Triển khai `AdaptyUiObserverModeHandler`.

Sự kiện `onPurchaseInitiated` sẽ thông báo cho bạn biết người dùng đã khởi tạo một giao dịch mua. Bạn có thể kích hoạt flow mua hàng tùy chỉnh của mình để phản hồi callback này:

   ```kotlin showLineNumbers
       onStartPurchase()
       yourBillingClient.makePurchase(
           product,
           onSuccess = { purchase ->
               onFinishPurchase()
               //handle success
           },
           onError = {
               onFinishPurchase()
               //handle error
           },
           onCancel = {
               onFinishPurchase()
               //handle cancel
           }
       )
   }
   ```

<TabItem value="java" label="Java" default>

   ```java showLineNumbers
               onFinishPurchase.invoke();
               //handle success

               //handle cancel
   ```

Để xử lý việc khôi phục giao dịch trong Observer mode, hãy override `getRestoreHandler()`. Mặc định nó trả về `null`, tức là sử dụng flow `Adapty.restorePurchases()` có sẵn của Adapty. Để cung cấp cách xử lý khôi phục của riêng bạn:
<Tabs groupId="current-os" queryString>
<TabItem value="kotlin" label="Kotlin" default>
   ```kotlin showLineNumbers
   val observerModeHandler = object : AdaptyUiObserverModeHandler {
       override fun onPurchaseInitiated(
           product: AdaptyPaywallProduct,
           onStartPurchase: AdaptyUiObserverModeHandler.PurchaseStartCallback,
           onFinishPurchase: AdaptyUiObserverModeHandler.PurchaseFinishCallback,
       ) {
           // the same body as the purchase example above
       }

       override fun getRestoreHandler() =
           AdaptyUiObserverModeHandler.RestoreHandler { onStartRestore, onFinishRestore ->
               onStartRestore()
               yourBillingClient.restorePurchases(
                   onSuccess = { restoredPurchases ->
                       onFinishRestore()
                       //handle successful restore
                   },
                   onError = {
                       onFinishRestore()
                       //handle error
                   }
               )
           }
   }
   ```
</TabItem>
<TabItem value="java" label="Java" default>
   ```java showLineNumbers
   AdaptyUiObserverModeHandler observerModeHandler = new AdaptyUiObserverModeHandler() {
       @Override
       public void onPurchaseInitiated(
           AdaptyPaywallProduct product,
           PurchaseStartCallback onStartPurchase,
           PurchaseFinishCallback onFinishPurchase
       ) {
           // the same body as the purchase example above
       }

       @Override
       public RestoreHandler getRestoreHandler() {
           return (onStartRestore, onFinishRestore) -> {
               onStartRestore.invoke();
               yourBillingClient.restorePurchases(
                   restoredPurchases -> {
                       onFinishRestore.invoke();
                       //handle successful restore
                   },
                   error -> {
                       onFinishRestore.invoke();
                       //handle error
                   }
               );
           };
       }
   };
   ```
</TabItem>
</Tabs>

Hãy nhớ gọi các callback sau để thông báo cho AdaptyUI về quá trình mua hàng hoặc khôi phục. Điều này cần thiết để flow hoạt động đúng, chẳng hạn như hiển thị loader:
| Callback           | Mô tả                                                                                         |
   | :----------------- |:----------------------------------------------------------------------------------------------|
   | onStartPurchase()  | Callback cần được gọi để thông báo cho AdaptyUI rằng quá trình mua hàng đã bắt đầu.          |
   | onFinishPurchase() | Callback cần được gọi để thông báo cho AdaptyUI rằng quá trình mua hàng đã hoàn tất.         |
   | onStartRestore()   | Tùy chọn. Callback có thể được gọi để thông báo cho AdaptyUI rằng quá trình khôi phục đã bắt đầu.  |
   | onFinishRestore()  | Tùy chọn. Callback có thể được gọi để thông báo cho AdaptyUI rằng quá trình khôi phục đã hoàn tất. |

| Tham số | Bắt buộc | Mô tả |
|---------|--------|-----------|
| **flowConfiguration** | bắt buộc | Cung cấp đối tượng `AdaptyUI.FlowConfiguration` chứa thông tin hiển thị của flow. Sử dụng phương thức `AdaptyUI.getFlowConfiguration(flow)` để tải nó. | **products** | tùy chọn | Cung cấp một mảng `AdaptyPaywallProduct` để tối ưu thời điểm hiển thị sản phẩm trên màn hình. Nếu truyền vào `null`, AdaptyUI sẽ tự động tải các sản phẩm cần thiết. |
| **eventListener** | tùy chọn | Cung cấp `AdaptyFlowEventListener` để theo dõi các sự kiện của flow. Nên kế thừa `AdaptyFlowDefaultEventListener` để dễ sử dụng hơn. Tham khảo chủ đề [Handle flow & paywall events](android-handling-events) để biết thêm chi tiết. |
| **insets** | tùy chọn | Insets là khoảng cách xung quanh flow giúp các phần tử có thể nhấn không bị ẩn sau thanh hệ thống. Mặc định: `Unspecified`, cho phép Adapty tự động điều chỉnh insets. Xem [Change flow insets](android-present-paywalls#change-flow-insets). |
| **customAssets** | tùy chọn | Truyền đối tượng `AdaptyCustomAssets` để thay thế hình ảnh và video trong flow hoặc paywall của bạn lúc chạy. Tham khảo [Customize assets](android-get-pb-paywalls#customize-assets) để biết thêm chi tiết. |
| **tagResolver** | tùy chọn | Sử dụng `AdaptyUiTagResolver` để phân giải các custom tag trong văn bản của flow. Resolver này nhận tham số là một tag và phân giải nó thành chuỗi tương ứng. Tham khảo chủ đề Custom tags in Paywall Builder để biết thêm chi tiết. |
| **observerModeHandler** | bắt buộc khi dùng Observer mode | `AdaptyUiObserverModeHandler` mà bạn đã triển khai ở bước trước. |

| Tham số | Bắt buộc | Mô tả                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
|---------|--------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Products** | tùy chọn | Truyền một mảng `AdaptyPaywallProduct` để tối ưu hóa thời điểm hiển thị sản phẩm trên màn hình. | **ViewConfiguration** | bắt buộc | Truyền một đối tượng `AdaptyViewConfiguration` chứa thông tin hiển thị của paywall. Dùng phương thức `Adapty.getViewConfiguration(paywall)` để tải nó. | **TagResolver** | tùy chọn | Dùng `AdaptyUiTagResolver` để xử lý các thẻ tùy chỉnh trong văn bản của paywall. Resolver này nhận tham số là một thẻ và chuyển đổi nó thành chuỗi tương ứng.
