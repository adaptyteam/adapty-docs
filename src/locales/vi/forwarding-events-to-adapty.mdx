Nếu backend của bạn cần giữ URL trong App Store Connect, hãy chuyển tiếp thông báo máy chủ App Store từ backend của bạn sang Adapty mà không thay đổi gì. Nếu backend của bạn không cần URL trong App Store Connect, hãy [thiết lập chuyển tiếp đến backend của bạn trong Adapty](enable-app-store-server-notifications#raw-events-forwarding). Cách đó không cần viết code.

Adapty xử lý các thông báo từ backend của bạn như thể Apple gửi trực tiếp. Với [Refund Saver](refund-saver), Adapty vẫn xử lý các yêu cầu hoàn tiền trong số đó.

Nếu backend của bạn nhận thông báo thời gian thực từ nhà phát triển của Google Play thông qua chủ đề Pub/Sub riêng, bạn không cần viết thêm code để chuyển tiếp chúng sang Adapty. [Thêm một push subscription cho Adapty vào chủ đề đó](enable-real-time-developer-notifications-rtdn#send-notifications-to-two-adapty-apps).

Để chuyển tiếp thông báo máy chủ App Store sang Adapty:

1. Trong Adapty, mở ứng dụng bạn đang kết nối: mỗi ứng dụng Adapty có URL thông báo riêng. Truy cập [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). Trong mục **App Store server notifications**, sao chép URL từ trường **URL for App Store server notifications**.
2. Trong backend của bạn, chuyển tiếp mỗi thông báo từ Apple đến URL vừa sao chép. Trong mỗi request:

   - Giữ nguyên body từ Apple: `{"signedPayload": "…"}`.
   - Đặt header `Content-Type: application/json`.
   - Không thêm header `Authorization`.

   Nếu Adapty cũng chuyển tiếp thông báo đến backend của bạn, đừng gửi lại những thông báo đó cho Adapty.

package main

	"fmt"
	"strings"
	"net/http"
)

func main() {
	url := "https://api.adapty.io/api/v1/sdk/apple/webhook/123a258e62fad41bfa734f4b0dbcad45/" // Replace this with the actual URL

	payload := strings.NewReader(`{"signedPayload":"eyJhbGciOiJFUzI1NiIs..."}`) // Apple's request body, unchanged

	method := "POST"

	client := &http.Client{}
	req, err := http.NewRequest(method, url, payload)
	if err != nil {
		fmt.Println("Error creating request:", err)
		return
	}
	req.Header.Add("Content-Type", "application/json")

	res, err := client.Do(req)
	if err != nil {
		fmt.Println("Error sending request:", err)
		return
	}
	defer res.Body.Close()
}

Phản hồi `200` không xác nhận rằng Adapty có thể sử dụng thông báo đó. Adapty phản hồi trước khi giải mã payload đã ký. Để xác nhận rằng thông báo đã đến Adapty, hãy thực hiện [mua hàng trong sandbox](test-purchases-in-sandbox). Sau đó kiểm tra [trạng thái thông báo](enable-app-store-server-notifications#check-that-notifications-reach-adapty) trong phần **App Store server notifications** có hiển thị **Active** hay không.
