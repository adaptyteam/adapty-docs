Để cập nhật ứng dụng từ Adapty iOS SDK 4.3 lên 4.4, hãy áp dụng mọi thay đổi trong hướng dẫn này. Nếu ứng dụng đang dùng 4.1 hoặc 4.2, bạn cần thực hiện [các thay đổi v4.3](migration-to-ios-sdk-43) trước, và nếu đang dùng 4.0 thì cần thực hiện [các thay đổi v4.1](migration-to-ios-sdk-41) trước đó.

:::warning
Định dạng file dự phòng đã thay đổi trong phiên bản 4.4, và compiler không thể phát hiện file lỗi thời. Nếu không có [file dự phòng mới](#fallback-files), mọi placement sẽ mất đi paywall dự phòng của nó.
:::

## Tham khảo nhanh \{#quick-reference\}

| Trước | Sau |
|---|---|
| `case let .custom(id)` | `case let .custom(id, _)` |
| `AdaptyUICustomAsset` | `AdaptyUIAsset`; `AdaptyCustomAsset` không thay đổi |
| `.color(.uiColor(x))` và `.color(.swiftUIColor(c))` | `.color(Color(uiColor: x))` và `.color(c)` |
| `AdaptyUICustomFontAsset(font:defaultColor:defaultLetterSpacing:defaultLineHeight:)` | `AdaptyUIFontAsset(font:color:letterSpacing:lineHeight:)` |
| Không có data asset | `AdaptyUIAsset` bao gồm `.data` cho data asset |
| `AdaptyProduct.localizedBillingPeriod` | `subscriptionPricingTerms?.localizedBillingPeriod` |
| File dự phòng đã tải xuống cho 4.1–4.3 | Định dạng file dự phòng mới; tải lại file |

## AdaptyUI.Action.custom chứa hai giá trị \{#custom-actions\}

Khi người dùng nhấn vào một nút có action tùy chỉnh, ứng dụng của bạn sẽ nhận được `AdaptyUI.Action.custom`. Trong phiên bản 4.4, nó chứa thêm giá trị thứ hai là `arguments` sau action ID. Trong closure `didPerformAction` và phương thức delegate `flowController(_:didPerform:)`, hãy thêm `_` cho giá trị thứ hai này:

```diff showLineNumbers
  switch action {
- case let .custom(id):
+ case let .custom(id, _):
      if id == "openNewPaywall" {
          // Display another flow or paywall
      }
  default:
      break
  }
```

```
Code that compares `id` to a string stops compiling until you add `_`. Other code still builds, with the warning "enum case 'custom' has 2 associated values; matching them as a tuple is deprecated". In that code, `id` contains both values, not the action ID alone. Add `_` wherever Xcode shows this warning.
```

## Tài sản tùy chỉnh \{#custom-assets\}

Trong 4.4, `AdaptyUICustomAsset` được đổi tên thành `AdaptyUIAsset`. Tên cũ sẽ kích hoạt cảnh báo deprecation.

Tài sản màu sắc, phông chữ và dữ liệu thay đổi theo ba cách:

- **Tài sản màu sắc**: `.color` nhận một `Color` của SwiftUI. `AdaptyUICustomColorAsset` đã bị xóa. Hãy bọc `UIColor` trong `Color(uiColor:)` và truyền trực tiếp một `Color` của SwiftUI:

  ```diff showLineNumbers
  - "brand_color": .color(.uiColor(brandColor)),
  + "brand_color": .color(Color(uiColor: brandColor)),
  ```

- **Font assets**: `AdaptyUIFontAsset` nhận `color:`, `letterSpacing:`, và `lineHeight:` thay vì `defaultColor:`, `defaultLetterSpacing:`, và `defaultLineHeight:`. Tham số `color:` nhận một SwiftUI `Color`:

  ```diff showLineNumbers
  - "title_font": .font(AdaptyUICustomFontAsset(font: titleFont, defaultColor: .uiColor(.white), defaultLineHeight: 24)),
  + "title_font": .font(AdaptyUIFontAsset(font: titleFont, color: .white, lineHeight: 24)),
  ```

- **Tài sản dữ liệu**: `AdaptyUIAsset` bổ sung kiểu tài sản mới là `.data`. Câu lệnh `switch` liệt kê mọi kiểu tài sản mà không có nhánh `default` sẽ không còn biên dịch được. Chỉ có [custom elements](ios-flow-custom-elements) mới đọc tài sản dữ liệu, nên nhánh mới có thể để trống: `case .data: break`.

## AdaptyProduct.localizedBillingPeriod không còn được hỗ trợ \{#localizedbillingperiod-is-deprecated\}

`AdaptyProduct` có thuộc tính [`subscriptionPricingTerms`](fetch-paywalls-and-products) mô tả từng lần thanh toán cho sản phẩm: giá tiền và tần suất người dùng thanh toán. Trong phiên bản 4.4, `localizedBillingPeriod` — văn bản hiển thị tần suất thanh toán — được chuyển từ `AdaptyProduct` sang `subscriptionPricingTerms`. `AdaptyProduct.localizedBillingPeriod` vẫn hoạt động nhưng sẽ hiển thị cảnh báo đã lỗi thời: nó trả về `subscriptionPricingTerms?.localizedBillingPeriod`. Để xóa cảnh báo, hãy đọc thuộc tính từ pricing terms:

```diff showLineNumbers
- let period = product.localizedBillingPeriod
+ let period = product.subscriptionPricingTerms?.localizedBillingPeriod
```

## Tệp dự phòng \{#fallback-files\}

Định dạng [tệp dự phòng](fallback-flows) đã thay đổi trong SDK 4.4. Tải lại tệp từ **[Placements](https://app.adapty.io/placements)** > **Fallbacks**, chọn **Adapty SDK v4.4.0 and higher**, rồi đưa vào ứng dụng của bạn.

Tệp tải về có tên `ios_4_4_0_fallback.json`. Đặt tên tệp trùng với tên mà ứng dụng truyền vào `Bundle.main.url(forResource:withExtension:)`, hoặc cập nhật tên trong lệnh gọi đó.

:::warning
Một file dự phòng lỗi thời sẽ không gây ra lỗi biên dịch nào. Mọi placement đều âm thầm mất đi paywall dự phòng của mình. SDK log sau đó sẽ hiển thị "The fallback paywalls version is not correct. Download a new one from the Adapty Dashboard."
:::
