Khôi phục mua hàng trên iOS và Android là tính năng cho phép người dùng lấy lại quyền truy cập vào nội dung đã mua trước đó — chẳng hạn như gói đăng ký hoặc in-app purchase — mà không bị tính phí thêm. Tính năng này đặc biệt hữu ích cho những người dùng đã gỡ và cài lại ứng dụng, hoặc chuyển sang thiết bị mới và muốn truy cập lại nội dung đã mua mà không cần thanh toán lại.

:::note
Nếu bạn xây dựng màn hình bằng builder, bạn không cần khôi phục giao dịch mua thủ công. Chỉ cần kết nối điều khiển khôi phục — hành động **Restore purchases** trong Flow & Paywall Builder, hoặc liên kết/nút khôi phục trong phiên bản cũ — và SDK sẽ tự hoàn tất việc khôi phục.
:::

Nếu bạn tự xây dựng màn hình, hãy gọi phương thức `.restorePurchases()`:

```typescript showLineNumbers
try {
    const profile = await adapty.restorePurchases();
    const isSubscribed = profile.accessLevels['YOUR_ACCESS_LEVEL']?.isActive;
  
    if (isSubscribed) {
        // restore access
    }
} catch (error) {
    // handle the error
}
```

Tham số trả về:

| Tham số | Mô tả |
|---------|-----------|
| **Profile** | <p>Một đối tượng [`AdaptyProfile`](https://react-native.adapty.io/interfaces/adaptyprofile). Model này chứa thông tin về mức độ truy cập, gói đăng ký và các sản phẩm mua một lần.</p><p>Kiểm tra **trạng thái mức độ truy cập** để xác định xem người dùng có quyền truy cập vào ứng dụng hay không.</p> |

:::info
Trong Adapty React Native SDK 4.0.3 trở lên, `restorePurchases()` hoàn thành thành công ngay cả khi không có gì để khôi phục: nó trả về hồ sơ người dùng hiện tại, vì vậy hãy kiểm tra trạng thái mức độ truy cập trong đó. Trong các phiên bản SDK cũ hơn, phương thức này sẽ trả về lỗi `noPurchasesToRestore` trên Android trong trường hợp này.
:::
