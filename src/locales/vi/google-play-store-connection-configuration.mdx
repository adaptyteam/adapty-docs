Đây là bước duy nhất trong quá trình tích hợp Google Play được thực hiện trên Adapty thay vì trên Google Console. Bạn cung cấp cho Adapty tên package và file service account key, sau đó Adapty sẽ dùng chúng để xác thực các giao dịch mua và đọc thông tin sản phẩm của bạn.

:::danger
Đừng thay đổi tên package hoặc file key sau khi ứng dụng của bạn đã ra mắt với Adapty SDK. Điều này sẽ làm hỏng quá trình xác thực mua hàng cho tất cả người dùng đang chạy ứng dụng. Key từ một Cloud project khác cũng sẽ thay đổi tên topic, khiến thông báo thời gian thực ngừng hoạt động.
:::

## Trước khi bắt đầu \{#before-you-start\}

[Tạo tệp khóa tài khoản dịch vụ](create-service-account-key-file). Bạn sẽ tải tệp đó lên tại đây.

## Kết nối ứng dụng \{#connect-the-app\}

1. Mở [Google Play Console](https://play.google.com/console/), chọn ứng dụng của bạn và sao chép tên package. Trang **Dashboard** hiển thị tên này ngay dưới tên ứng dụng.

2. Mở [**App settings** > **Android SDK**](https://app.adapty.io/settings/android-sdk) trong Adapty Dashboard.

3. Dán tên package vào trường **Package name**.

4. Tải file JSON key lên ở mục **Service account key file**.

   <ZoomImage id="gp-adapty-android-sdk.webp" width="700px" alt="Tab Android SDK trong App settings của Adapty, hiển thị trường Package name và khu vực tải lên Service account key file" />

5. Nhấp vào **Save**.

Lưu file key cũng đồng thời tạo chủ đề Pub/Sub trong Cloud project của bạn, cần thiết cho bước tiếp theo.
