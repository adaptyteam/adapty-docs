Mỗi khi người dùng mở một màn hình trong [flow](adapty-flow-builder), SDK sẽ báo cáo sự kiện `flow_screen_showed` tới ứng dụng của bạn. Hãy chuyển tiếp sự kiện này tới Amplitude, Mixpanel, hoặc bất kỳ công cụ phân tích sản phẩm nào bạn đang dùng, để có thể phân tích các màn hình flow cùng với các sự kiện còn lại trong ứng dụng.

:::tip
Để xem người dùng tiến đến đâu trong một flow, bạn không cần viết code — [chỉ số flow](flow-metrics) đã hiển thị lượt xem, lượt hoàn thành và tỷ lệ thoát theo từng màn hình ngay trên Adapty Dashboard. Hãy dùng hướng dẫn này khi bạn cần dữ liệu đó trong hệ thống analytics của riêng mình, kết hợp với các sự kiện mà Adapty không theo dõi.
:::

## Trước khi bắt đầu \{#before-you-start\}

Bạn cần:

- **Adapty iOS SDK v4 trở lên**: Callback phân tích flow không tồn tại trong các phiên bản cũ hơn.
- **Một phiên bản flow được publish sau khi tính năng này ra mắt**: Adapty tạo các sự kiện màn hình khi publish flow, vì vậy flow bạn publish trước thời điểm đó sẽ không báo cáo gì cả. Nếu không có sự kiện nào đến ứng dụng của bạn, hãy publish phiên bản mới của flow và thử lại.

## Những gì bạn nhận được \{#what-you-receive\}

<FlowScreenShowedParams />

Lượt xem màn hình được gửi đến cùng callback analytics với mọi sự kiện flow khác. Xem [Xử lý sự kiện flow & paywall](ios-handling-events) để biết nơi đăng ký callback.

## Chuyển tiếp mọi lượt xem màn hình tới analytics của bạn \{#forward-every-screen-view-to-your-analytics\}

Hãy kiểm tra tên sự kiện trước khi đọc bất cứ thứ gì khác, vì một flow báo cáo các sự kiện khác qua cùng một callback.

```swift showLineNumbers title="Swift"
func flowController(
    _ controller: AdaptyFlowController,
    didReceiveAnalyticEvent name: String,
    params: [String: any Sendable]
) {
    guard name == "flow_screen_showed" else { return }

    let screenId = params["instanceId"] as? String
    let screenOrder = params["screen_order"] as? Int

    // Send screenId and screenOrder to your analytics provider here.
}
```

## Chạy code khi người dùng đến màn hình cuối \{#run-code-when-a-user-reaches-the-end\}

`is_last_screen` là `true` trên màn hình mà flow không thể tiến thêm. Dùng nó để mở khóa nội dung, đánh dấu onboarding đã hoàn tất, hoặc gửi sự kiện hoàn thành theo cách của bạn — mà không cần thêm button action trong builder.

```swift showLineNumbers title="Swift"
func flowController(
    _ controller: AdaptyFlowController,
    didReceiveAnalyticEvent name: String,
    params: [String: any Sendable]
) {
    guard name == "flow_screen_showed",
          params["is_last_screen"] as? Bool == true
    else { return }

    // The user reached the end of the flow.
}
```

Reaching the last screen is not the same as closing the flow. A user can see the final screen and dismiss the flow without acting on it, and a branching flow can end on several different screens. To know that the flow itself went away, use `flowControllerDidDisappear` in UIKit, or the `didDisappear` closure in SwiftUI instead.
