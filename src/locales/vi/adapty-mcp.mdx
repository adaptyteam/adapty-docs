MCP server của Adapty kết nối trợ lý AI với tài khoản Adapty của bạn. Bạn có thể hỏi về doanh thu và chuyển đổi, thiết lập sản phẩm và placement, xuất bản flow, hoặc bắt đầu A/B test ngay từ cửa sổ chat, bằng ngôn ngữ tự nhiên. Trợ lý đăng nhập bằng tài khoản Adapty của bạn trên trình duyệt và nhận quyền của bạn. Không cần API key.

| | |
|---|---|
| Server URL | `https://mcp.adapty.io/mcp` |
| Protocol | MCP over Streamable HTTP, OAuth 2.1 sign-in in the browser |
| Works with | claude.ai, Claude desktop, Claude Code, Codex, and other MCP clients that support OAuth sign-in |

:::important
MCP server cấp quyền truy cập tài khoản Adapty cho trợ lý của bạn. Để trang bị thêm kiến thức — các quy tắc cấu hình flow, phương pháp đã được kiểm chứng cho analytics của bạn, và xác nhận trước mỗi bước ảnh hưởng đến người dùng — hãy cài đặt [Adapty plugin](manage-adapty-with-ai#install-the-plugin) trước. Trong Claude Code và Codex, plugin sẽ tự thêm server này cho bạn, vì vậy bạn chỉ cần [đăng nhập](#connect-your-assistant).
:::

## Trợ lý có thể làm gì \{#what-the-assistant-can-do\}

Các công cụ của server tuân theo Adapty Dashboard và [Adapty Developer CLI](developer-cli). Trợ lý sẽ tự chọn công cụ phù hợp với yêu cầu của bạn; bạn không cần gọi tên chúng.

| Khu vực | Trợ lý có thể làm gì | Thử hỏi |
|---|---|---|
| Ứng dụng và mức độ truy cập | Liệt kê, tạo và cập nhật ứng dụng và mức độ truy cập | "Tạo mức độ truy cập `premium` trong Fitness Pro." |
| Sản phẩm và ưu đãi | Tạo sản phẩm với ID sản phẩm trên cửa hàng, và liên kết ưu đãi của cửa hàng với chúng | "Sản phẩm nào của tôi chưa có ID sản phẩm Google Play?" |
| Paywall | Tạo và cập nhật paywall, và tìm các placement hiển thị từng paywall | "Placement nào hiển thị paywall Annual sale?" |
| Flow | Tạo flow, đọc và ghi cấu hình builder, xác thực, xem trước, xuất bản và đọc chỉ số của flow | "Xuất bản flow Onboarding v2 và cho tôi biết placement nào hiển thị nó." |
| Placement và đối tượng | Tạo placement và thay đổi ai thấy nội dung gì, và đọc chỉ số của các flow placement | "Ai thấy gì trên placement `onboarding`?" |
| Phân khúc | Đọc phân khúc và các bộ lọc của chúng | "Liệt kê các phân khúc của tôi và mỗi phân khúc lọc theo tiêu chí gì." |
| A/B test | Tạo, bắt đầu, dừng, thay thế và lưu trữ các A/B test paywall và flow | "Bắt đầu A/B test nháp Weekly vs annual cho người dùng ở Đức." |
| Analytics | Đọc doanh thu, MRR, tỷ lệ chuyển đổi, funnel, retention, LTV và install cohort | "So sánh tỷ lệ chuyển đổi từ dùng thử sang trả phí theo quốc gia trong tháng trước." |
| Migration từ RevenueCat | Tạo và chạy migration catalog RevenueCat sang ứng dụng Adapty mới | "Chuyển dự án RevenueCat của tôi sang ứng dụng Adapty mới." |

Adapty Mail có MCP server riêng. Để kết nối một assistant với dự án Adapty Mail của bạn, xem [Quản lý Adapty Mail bằng AI assistant](mail-mcp).

## Chọn MCP server hoặc CLI \{#choose-the-mcp-server-or-the-cli\}

MCP server và [Adapty Developer CLI](developer-cli) đều kết nối đến cùng một tài khoản Adapty. Nếu chưa cài cái nào, plugin Adapty sẽ hỏi bạn muốn thiết lập cái nào và hướng dẫn các bước. Nếu đã có cả hai, plugin sẽ tự chọn cái phù hợp cho từng tác vụ:

| | Adapty MCP server | Adapty CLI |
|---|---|---|
| Chạy trong | Bất kỳ MCP client nào, bao gồm claude.ai và Claude desktop | Các agent chạy lệnh terminal, và script của bạn |
| Đăng nhập | Một lần mỗi client, trên trình duyệt | `adapty auth login`, một lần mỗi máy |
| Phù hợp nhất cho | Câu hỏi và thay đổi từ chat | Chỉnh sửa flow config, thay đổi hàng loạt, và script |
| Cài đặt | Không cần cài đặt gì | `npm install -g adapty` |

Trong claude.ai và Claude desktop, MCP server cần ít thiết lập hơn so với CLI: CLI phải được cài đặt và xác thực trong mỗi cuộc hội thoại, như mô tả trong [Thiết lập Adapty CLI trong ứng dụng Claude](developer-cli-cowork).

<Details summary="Skill nào dùng MCP server và skill nào dùng CLI">

Trước bước đầu tiên, mỗi skill sẽ tự phát hiện xem trợ lý của bạn có MCP server, CLI, hay cả hai. Nếu chỉ có một, skill sẽ dùng cái đó. Nếu có cả hai, skill sẽ dùng cái phù hợp hơn với công việc của nó:

- **MCP server**: Chạy A/B test, tích hợp SDK và kiểm tra purchases.
- **Adapty CLI**: Xây dựng và kiểm tra flows, tìm điểm cần test tiếp theo, chuyển placements sang flows, và tạo phân khúc. Các skill này chạy script và file riêng, CLI sẽ truyền file trực tiếp cho chúng.

</Details>

## Trước khi bắt đầu

- **Tài khoản Adapty**: Trợ lý hoạt động trong các công ty và ứng dụng mà tài khoản Adapty của bạn có thể truy cập, với các quyền của bạn.
- **MCP client có OAuth**: Client của bạn hỗ trợ các remote MCP server đăng nhập bằng OAuth.

:::warning
Trợ lý hành động với quyền của bạn, và các thay đổi là thực tế. Một A/B test được khởi chạy hoặc một placement bị thay đổi sẽ ảnh hưởng đến người dùng của bạn. Trước khi trợ lý bắt đầu hoặc dừng một A/B test, hoặc thay đổi đối tượng xem nội dung trên một placement, server sẽ yêu cầu nó mô tả chính xác tác động và chờ xác nhận từ bạn. Hãy đọc kỹ kế hoạch trước khi phê duyệt.
:::

## Kết nối trợ lý của bạn \{#connect-your-assistant\}

<Tabs groupId="mcp-client" queryString>
<TabItem value="claude-app" label="claude.ai" default>

claude.ai và Claude desktop thêm remote MCP server dưới dạng custom connector.

1. Để thêm server, mở **Settings → Connectors** và nhấp vào **Add custom connector**.
2. Nhập tên, ví dụ `Adapty`, và URL `https://mcp.adapty.io/mcp`.
3. Giữ nguyên cài đặt xác thực mặc định và nhấp vào **Add**.
4. Đăng nhập vào Adapty trong tab trình duyệt vừa mở ra. Xem [Đăng nhập](#sign-in).

Quản trị viên workspace có thể thêm connector một lần cho toàn bộ tổ chức. Mỗi thành viên sau đó đăng nhập bằng tài khoản Adapty của mình vào lần đầu tiên họ sử dụng.

</TabItem>
<TabItem value="claude-code" label="Claude Code">

Nếu bạn đã cài plugin Adapty, Claude Code sẽ tự động liệt kê server là `plugin:adapty-skills:adapty` với trạng thái **Needs authentication**. Để đăng nhập, chạy `/mcp` trong Claude Code, chọn `plugin:adapty-skills:adapty`, rồi chọn **Authenticate**.

Nếu chưa cài plugin, hãy thêm server trước:

```bash
claude mcp add --transport http --scope user adapty https://mcp.adapty.io/mcp
```

Sau đó chạy `/mcp` trong Claude Code, chọn `adapty`, và chọn **Authenticate**. Nếu các công cụ Adapty không xuất hiện trong phiên hiện tại, hãy bắt đầu một phiên mới.

</TabItem>
<TabItem value="codex" label="Codex">

Nếu bạn đã cài đặt plugin Adapty, plugin sẽ tự thêm server và Codex sẽ yêu cầu bạn đăng nhập khi kết nối.

Nếu không dùng plugin, hãy thêm server và đăng nhập thủ công:

```bash
codex mcp add adapty --url https://mcp.adapty.io/mcp
codex mcp login adapty
```

Lệnh đăng nhập sẽ mở trình duyệt của bạn. Để tự cấu hình server, hãy thêm vào `~/.codex/config.toml`, sau đó chạy lệnh đăng nhập:

```toml
[mcp_servers.adapty]
url = "https://mcp.adapty.io/mcp"
```

Khởi động một phiên `codex` mới để tải các công cụ Adapty.

</TabItem>
<TabItem value="other" label="Other clients">

Thêm `https://mcp.adapty.io/mcp` làm remote MCP server trong phần cài đặt client hoặc file cấu hình MCP của bạn. Client sẽ mở trình duyệt để đăng nhập lần đầu kết nối.

Máy chủ nhận diện mỗi client thông qua Client ID Metadata Document, phương thức đăng ký client của đặc tả MCP hiện tại. Client nào không hỗ trợ phương thức này sẽ không thể hoàn tất quá trình đăng nhập. Trong trường hợp đó, hãy dùng [Adapty Developer CLI](developer-cli-quickstart) từ một terminal agent thay thế.

</TabItem>
</Tabs>

## Đăng nhập \{#sign-in\}

Mọi client đều kết thúc ở cùng một nơi: trang đăng nhập Adapty trên trình duyệt của bạn.

1. Đăng nhập bằng tài khoản Adapty của bạn, nếu bạn chưa đăng nhập.
2. Cho phép client truy cập vào tài khoản Adapty của bạn.

Sau đó, client sẽ đọc và thay đổi dữ liệu trong các công ty mà tài khoản của bạn có thể mở, và nó sẽ duy trạng thái đăng nhập cho đến khi bạn ngắt kết nối. Chỉ chấp nhận lần đăng nhập do chính bạn khởi tạo.

Để xác minh kết nối, hãy hỏi trợ lý xem nó đang đăng nhập vào tài khoản Adapty nào. Câu trả lời phải nêu tên bạn và các công ty mà tài khoản của bạn có thể mở.

## Bắt đầu làm việc \{#start-working\}

Hỏi trợ lý xem nó có thể thấy những ứng dụng nào, rồi đặt tên ứng dụng bạn muốn làm việc. Một số yêu cầu bạn có thể thử:

```text
List my Adapty apps and their placements.
How did revenue and new subscriptions change last month compared with the month before?
Which products in Fitness Pro have no App Store product ID?
Show who sees what on the onboarding placement, including any A/B test.
Create a draft A/B test on main_paywall: the current paywall against Annual sale, 50/50.
```

The assistant asks for confirmation before the steps that change what users see. A request that only reads data runs without questions.

After a task of several steps, the assistant can send the Adapty team a short note about how the task went. The note contains no personal data of your app's users.

## Ngắt kết nối \{#disconnect\}

Để ngắt kết nối, hãy xóa server trong client:

- **claude.ai**: Trong **Settings → Connectors**, xóa connector Adapty.
- **Claude Code**: Chạy `claude mcp remove adapty`. Nếu server đi kèm với plugin Adapty, hãy tắt nó trong `/mcp`.
- **Codex**: Xóa server `adapty` khỏi `~/.codex/config.toml`.

Để kết nối lại, hãy thêm server và đăng nhập lại một lần nữa.

## Khắc phục sự cố \{#troubleshooting\}

| Vấn đề | Giải pháp |
|---|---|
| Claude Code hiển thị server là **Needs authentication** | Client đã thêm server nhưng chưa đăng nhập. Chạy `/mcp`, chọn server Adapty và chọn **Authenticate**. |
| Client không liệt kê công cụ Adapty nào | Hoàn tất đăng nhập, sau đó bắt đầu phiên mới. Một số client chỉ tải công cụ khi bắt đầu phiên. |
| Trợ lý không tìm thấy ứng dụng | Ứng dụng thuộc về một công ty mà tài khoản Adapty của bạn không có quyền truy cập. Hãy yêu cầu chủ sở hữu công ty cấp quyền. |
| Client không thể hoàn tất đăng nhập | Client không hỗ trợ phương thức đăng nhập mà server sử dụng. Kết nối từ claude.ai, Claude Code hoặc Codex, hoặc sử dụng [Adapty Developer CLI](developer-cli-quickstart). |
