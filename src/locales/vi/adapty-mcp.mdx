MCP server của Adapty kết nối trợ lý AI với tài khoản Adapty của bạn. Hỏi về doanh thu và tỷ lệ chuyển đổi, thiết lập sản phẩm và placement, xuất bản flow, hoặc bắt đầu A/B test từ chat, bằng ngôn ngữ tự nhiên. Trợ lý đăng nhập bằng tài khoản Adapty của bạn trên trình duyệt và nhận quyền của bạn. Không cần API key.

| | |
|---|---|
| Server URL | `https://mcp.adapty.io/mcp` |
| Protocol | MCP over Streamable HTTP, OAuth 2.1 sign-in in the browser |
| Works with | The Claude app (web and desktop), Claude Code, Codex, and other MCP clients that support OAuth sign-in |

:::important
MCP server hoạt động tốt nhất khi kết hợp với [Adapty skills](#add-the-adapty-skills). Server cung cấp cho trợ lý quyền truy cập vào tài khoản của bạn; còn skills cung cấp các quy trình đã được kiểm nghiệm để thực hiện công việc. Việc xây dựng flow, paywall và tìm ra điểm cần kiểm thử trong analytics đều phụ thuộc vào skills.
:::

## Thêm Adapty skills \{#add-the-adapty-skills\}

MCP server cho phép trợ lý của bạn truy cập vào tài khoản Adapty. Các Adapty skill cung cấp kiến thức cần thiết: những workflow đã được kiểm thử, lên kế hoạch thay đổi, xác minh và hỏi trước mỗi bước có ảnh hưởng đến người dùng của bạn. Hãy cài đặt chúng cùng nhau. Plugin `adapty-skills` bao gồm cả các skill lẫn MCP server này.

Có hai loại công việc phụ thuộc vào các skill:

- **Flow và paywall**: [Skill flow-generator](flow-generator-skill) tích hợp sẵn các quy tắc cấu hình của Flow Builder. Skill này xây dựng màn hình từ mô tả hoặc ảnh chụp màn hình, đồng thời xác thực và xem trước mọi thay đổi trước khi lưu flow. Nếu không có skill này, trợ lý vẫn có thể đọc và ghi cấu hình flow, nhưng sẽ không có quy tắc để tạo ra một cấu hình hợp lệ.
- **Analytics và những gì cần test tiếp theo**: [Skill growth-advisor](export-analytics-with-ai) biết cần đọc báo cáo nào và đọc như thế nào, đồng thời chuyển đổi các con số của bạn thành các giả thuyết để A/B test. Nếu không có skill này, trợ lý vẫn có thể lấy các biểu đồ của bạn, nhưng sẽ không có phương pháp để giải thích chúng.

### Thêm plugin trong ứng dụng Claude \{#add-the-plugin-in-the-claude-app\}

Bạn thêm plugin từ cài đặt Claude, không cần dùng dòng lệnh.

1. Trong Claude, mở **Settings** → **Plugins**.
2. Nhấp **Add** → **Add marketplace**.
3. Chọn **Add from a repository**.
4. Trong trường **URL**, nhập `adaptyteam/adapty-skills` và chọn repository. Để nhận các skill và bản vá mới khi có, hãy giữ **Sync automatically** bật.
5. Nhấp **Sync**.

<ZoomImage id="adapty-skills-claude-add-marketplace.png" width="584px" alt="Add marketplace dialog in Claude with adaptyteam/adapty-skills in the URL field and Sync automatically turned on" />

Claude mở tab **Discover** với các plugin từ marketplace của Adapty. Để cài đặt các skill, trong hàng **Adapty**, nhấn **Add**.

<ZoomImage id="adapty-skills-claude-discover.png" width="600px" alt="Discover tab in Claude listing the Adapty, Apple ads, and Apple ads benchmarks plugins, each with an Add button" />

Các skill chạy script của chúng trong sandbox của Claude. Để cho phép điều này, trong **Settings** → **Capabilities**, hãy bật **Code execution and file creation**.

### Thêm plugin vào coding agent \{#add-the-plugin-in-a-coding-agent\}

Trong Claude Code, Codex, Copilot CLI, Gemini CLI, Cursor và các coding agent khác, hãy chạy:

```bash
npx adapty skills install
```

Lệnh này cài plugin thông qua trình cài đặt của agent khi agent có sẵn trình đó. Sau khi cài xong, hãy khởi động lại agent. Trong Claude Code và Codex, plugin còn thêm cả Adapty MCP server, nên bạn chỉ cần đăng nhập như mô tả trong phần [Kết nối assistant của bạn](#connect-your-assistant).

<Details summary="Skill nào dùng MCP server và skill nào dùng CLI">

Trước bước đầu tiên, mỗi skill sẽ phát hiện xem agent của bạn có MCP server, [Adapty Developer CLI](developer-cli), hay cả hai. Nếu chỉ có một, skill sẽ sử dụng cái đó. Nếu có cả hai, skill sẽ dùng cái phù hợp nhất với công việc:

- **MCP server**: Chạy A/B test, đọc Adapty Attribution, tích hợp SDK, chạy Apple Ads, và kiểm tra giao dịch mua.
- **Adapty CLI**: Xây dựng và kiểm tra flow, tìm điểm cần test tiếp theo, chuyển placement sang flow, và tạo phân khúc. Các skill này chạy script và file riêng, CLI sẽ cung cấp file trực tiếp cho chúng.

</Details>

## Trợ lý có thể làm gì \{#what-the-assistant-can-do\}

Các công cụ của server tuân theo Adapty Dashboard và [Adapty Developer CLI](developer-cli). Trợ lý sẽ tự chọn công cụ phù hợp với yêu cầu của bạn; bạn không cần gọi tên chúng.

| Khu vực | Trợ lý có thể làm gì | Thử hỏi |
|---|---|---|
| Ứng dụng và mức độ truy cập | Liệt kê, tạo và cập nhật ứng dụng và mức độ truy cập | "Tạo mức độ truy cập `premium` trong Fitness Pro." |
| Sản phẩm và ưu đãi | Tạo sản phẩm với ID sản phẩm trên cửa hàng, và liên kết ưu đãi trên cửa hàng với chúng | "Những sản phẩm nào của tôi chưa có ID sản phẩm Google Play?" |
| Paywall | Tạo và cập nhật paywall, và tìm các placement đang hiển thị từng paywall | "Những placement nào đang hiển thị paywall Annual sale?" |
| Flow | Tạo flow, đọc và ghi cấu hình builder, xác thực, xem trước, xuất bản và đọc chỉ số flow | "Xuất bản flow Onboarding v2 và cho tôi biết những placement nào đang hiển thị nó." |
| Placement và đối tượng | Tạo placement và thay đổi ai xem gì, và đọc chỉ số của các flow placement | "Ai đang xem gì trên placement `onboarding`?" |
| Phân khúc | Đọc phân khúc và bộ lọc của chúng | "Liệt kê các phân khúc của tôi và từng cái đang lọc theo tiêu chí gì." |
| A/B test | Tạo, bắt đầu, dừng, thay thế và lưu trữ A/B test cho paywall và flow | "Bắt đầu bản thảo test Weekly vs annual cho người dùng ở Đức." |
| Phân tích | Đọc doanh thu, MRR, tỷ lệ chuyển đổi, phễu, tỷ lệ giữ chân, LTV và cohort cài đặt | "So sánh tỷ lệ chuyển đổi từ dùng thử sang trả phí theo quốc gia trong tháng trước." |
| Attribution | Đọc hiệu suất chiến dịch từ [Adapty Attribution](user-acquisition) | "Những chiến dịch nào hoàn vốn trong tháng 9?" |
| Apple Ads | Chạy chiến dịch, nhóm quảng cáo, từ khóa và quy tắc tự động hóa trong [Adapty Ads Manager](developer-cli-ads-manager), và đọc chỉ số của chúng | "Những từ khóa nào tiêu tốn nhiều nhất tuần trước mà không có lượt cài đặt nào?" |
| Migration từ RevenueCat | Tạo và chạy migration danh mục RevenueCat của bạn sang ứng dụng Adapty mới | "Chuyển dự án RevenueCat của tôi sang ứng dụng Adapty mới." |

Adapty Mail có MCP server riêng. Để kết nối một assistant với dự án Adapty Mail của bạn, xem [Quản lý Adapty Mail bằng AI assistant](mail-mcp).

## Chọn MCP server hoặc CLI \{#choose-the-mcp-server-or-the-cli\}

MCP server và [Adapty Developer CLI](developer-cli) đều kết nối đến cùng một tài khoản Adapty. Hãy chọn dựa trên nơi assistant của bạn chạy:

| | Adapty MCP server | Adapty CLI |
|---|---|---|
| Chạy trong | Bất kỳ MCP client nào, bao gồm các ứng dụng chat như Claude app | Các agent chạy lệnh terminal và script của riêng bạn |
| Đăng nhập | Một lần cho mỗi client, trên trình duyệt | `adapty auth login`, một lần cho mỗi máy |
| Phù hợp nhất cho | Đặt câu hỏi và thực hiện thay đổi qua chat | Chỉnh sửa cấu hình flow, thay đổi hàng loạt và script |
| Cài đặt | Không cần cài đặt | `npm install -g adapty` |

Một agent có thể sử dụng cả hai. Trong ứng dụng Claude, MCP server cần ít thiết lập hơn so với CLI: CLI phải được cài đặt và ủy quyền trong mỗi cuộc hội thoại, như mô tả trong [Thiết lập Adapty CLI trong ứng dụng Claude](developer-cli-cowork).

## Trước khi bắt đầu

- **Tài khoản Adapty**: Trợ lý hoạt động trong các công ty và ứng dụng mà tài khoản Adapty của bạn có thể truy cập, với các quyền của bạn.
- **MCP client có OAuth**: Client của bạn hỗ trợ các remote MCP server đăng nhập bằng OAuth.

:::warning
Trợ lý hành động với quyền của bạn, và các thay đổi là thực tế. Một A/B test được khởi chạy hoặc một placement bị thay đổi sẽ ảnh hưởng đến người dùng của bạn. Trước khi trợ lý bắt đầu hoặc dừng một A/B test, hoặc thay đổi đối tượng xem nội dung trên một placement, server sẽ yêu cầu nó mô tả chính xác tác động và chờ xác nhận từ bạn. Hãy đọc kỹ kế hoạch trước khi phê duyệt.
:::

## Kết nối trợ lý của bạn \{#connect-your-assistant\}

<Tabs groupId="mcp-client" queryString>
<TabItem value="claude-app" label="Claude app" default>

Ứng dụng Claude (claude.ai và Claude desktop) thêm các MCP server từ xa dưới dạng custom connector.

1. Để thêm server, mở **Settings → Connectors** và nhấn **Add custom connector**.
2. Nhập tên, ví dụ `Adapty`, và URL `https://mcp.adapty.io/mcp`.
3. Giữ nguyên cài đặt xác thực mặc định và nhấn **Add**.
4. Đăng nhập vào Adapty trong tab trình duyệt mở ra. Xem [Đăng nhập](#sign-in).

Quản trị viên workspace có thể thêm connector một lần cho toàn bộ tổ chức. Mỗi thành viên sau đó đăng nhập bằng tài khoản Adapty của mình khi sử dụng lần đầu.

</TabItem>
<TabItem value="claude-code" label="Claude Code">

Nếu bạn dùng plugin `adapty-skills`, Claude Code đã liệt kê server là `plugin:adapty-skills:adapty` với trạng thái **Needs authentication**. Để đăng nhập, chạy `/mcp` trong Claude Code, chọn `plugin:adapty-skills:adapty`, rồi chọn **Authenticate**.

Nếu không dùng plugin, hãy thêm server trước:

```bash
claude mcp add --transport http --scope user adapty https://mcp.adapty.io/mcp
```

Sau đó chạy `/mcp` trong Claude Code, chọn `adapty`, và chọn **Authenticate**. Nếu các công cụ Adapty không xuất hiện trong phiên hiện tại, hãy bắt đầu một phiên mới.

</TabItem>
<TabItem value="codex" label="Codex">

Nếu bạn sử dụng plugin `adapty-skills`, plugin sẽ tự thêm server và Codex sẽ yêu cầu bạn đăng nhập khi kết nối.

Nếu không dùng plugin, hãy thêm server và đăng nhập thủ công:

```bash
codex mcp add adapty --url https://mcp.adapty.io/mcp
codex mcp login adapty
```

Lệnh đăng nhập sẽ mở trình duyệt của bạn. Để tự cấu hình server, hãy thêm vào `~/.codex/config.toml`, sau đó chạy lệnh đăng nhập:

```toml
[mcp_servers.adapty]
url = "https://mcp.adapty.io/mcp"
```

Khởi động một phiên `codex` mới để tải các công cụ Adapty.

</TabItem>
<TabItem value="other" label="Other clients">

Client nào không hỗ trợ phương thức này sẽ không thể hoàn tất quá trình đăng nhập. Trong trường hợp đó, hãy dùng [Adapty Developer CLI](developer-cli-quickstart) từ một terminal agent thay thế.

## Đăng nhập \{#sign-in\}

Mọi client đều kết thúc ở cùng một nơi: trang đăng nhập Adapty trên trình duyệt của bạn.

1. Đăng nhập bằng tài khoản Adapty của bạn, nếu bạn chưa đăng nhập.
2. Cho phép client truy cập vào tài khoản Adapty của bạn.

Sau đó, client sẽ đọc và thay đổi dữ liệu trong các công ty mà tài khoản của bạn có thể mở, và nó sẽ duy trạng thái đăng nhập cho đến khi bạn ngắt kết nối. Chỉ chấp nhận lần đăng nhập do chính bạn khởi tạo.

Để xác minh kết nối, hãy hỏi trợ lý xem nó đang đăng nhập vào tài khoản Adapty nào. Câu trả lời phải nêu tên bạn và các công ty mà tài khoản của bạn có thể mở.

## Bắt đầu làm việc \{#start-working\}

Hỏi trợ lý xem nó có thể thấy những ứng dụng nào, rồi đặt tên ứng dụng bạn muốn làm việc. Một số yêu cầu bạn có thể thử:

```text
List my Adapty apps and their placements.
How did revenue and new subscriptions change last month compared with the month before?
Which products in Fitness Pro have no App Store product ID?
Show who sees what on the onboarding placement, including any A/B test.
Create a draft A/B test on main_paywall: the current paywall against Annual sale, 50/50.
```

The assistant asks for confirmation before the steps that change what users see. A request that only reads data runs without questions.

After a task of several steps, the assistant can send the Adapty team a short note about how the task went. The note contains no personal data of your app's users.

## Ngắt kết nối \{#disconnect\}

Để ngắt kết nối, xóa server khỏi client:

- **Claude app**: Trong **Settings → Connectors**, xóa connector Adapty.
- **Claude Code**: Chạy `claude mcp remove adapty`. Nếu server đi kèm với plugin `adapty-skills`, hãy tắt nó trong `/mcp`.
- **Codex**: Xóa server `adapty` khỏi `~/.codex/config.toml`.

Để kết nối lại, thêm server và đăng nhập lại một lần nữa.

## Khắc phục sự cố \{#troubleshooting\}

| Vấn đề | Giải pháp |
|---|---|
| Claude Code hiển thị server là **Needs authentication** | Client đã thêm server nhưng chưa đăng nhập. Chạy `/mcp`, chọn server Adapty, và chọn **Authenticate**. |
| Client không liệt kê công cụ Adapty nào | Hoàn tất đăng nhập, sau đó bắt đầu phiên mới. Một số client chỉ tải công cụ khi bắt đầu phiên. |
| Trợ lý không tìm thấy ứng dụng | Ứng dụng thuộc về một công ty mà tài khoản Adapty của bạn không có quyền truy cập. Hãy yêu cầu chủ sở hữu công ty cấp quyền. |
| Client không thể hoàn tất đăng nhập | Client không hỗ trợ phương thức đăng nhập mà server sử dụng. Kết nối từ ứng dụng Claude, Claude Code, hoặc Codex, hoặc sử dụng [Adapty Developer CLI](developer-cli-quickstart). |
