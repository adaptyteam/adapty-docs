Các lệnh Adapty CLI này quản lý ứng dụng của bạn và [mức độ truy cập](access-level) của chúng: các cấp gói đăng ký mà ứng dụng kiểm tra trong thời gian chạy.

## Ứng dụng \{#apps\}

Quản lý các ứng dụng trong tài khoản Adapty của bạn. Để cấu hình trên Dashboard, xem [Cài đặt ứng dụng](general).

### adapty apps list

Liệt kê tất cả các ứng dụng trong tài khoản Adapty của bạn.

```bash
adapty apps list
```

Chấp nhận [các cờ phân trang](developer-cli-reference#global-flags).

### adapty apps get

Lấy thông tin chi tiết của một ứng dụng cụ thể.

```bash
adapty apps get <app-id>
```

| Argument | Description |
|---|---|
| `app-id` | App ID (UUID) |

### adapty apps create

Tạo một ứng dụng mới.

```bash
adapty apps create --title "My App" --platform ios --apple-bundle-id com.example.app
```

| Flag | Required | Description |
|---|---|---|
| `--title` | Yes | Tên ứng dụng |
| `--platform` | Yes | Nền tảng: `ios` hoặc `android`. Lặp lại để dùng cả hai: `--platform ios --platform android` |
| `--apple-bundle-id` | Required with `--platform ios` | Apple bundle ID |
| `--google-bundle-id` | Required with `--platform android` | Google bundle ID |

### adapty apps update

Cập nhật một ứng dụng hiện có.

```bash
adapty apps update <app-id> --title "New Name"
```

| Argument | Description |
|---|---|
| `app-id` | App ID (UUID) |

| Flag | Description |
|---|---|
| `--title` | Tiêu đề mới của ứng dụng |
| `--apple-bundle-id` | Apple bundle ID mới |
| `--google-bundle-id` | Google bundle ID mới |

Phải có ít nhất một flag. `--platform` không thể thay đổi sau khi tạo.

## Mức độ truy cập \{#access-levels\}

### adapty access-levels list

Liệt kê tất cả [mức độ truy cập](access-level) của một ứng dụng.

```bash
adapty access-levels list --app <app-id>
```

| Flag | Bắt buộc | Mô tả |
|---|---|---|
| `--app` | Có | App ID (UUID) |

Chấp nhận [các flag phân trang](developer-cli-reference#global-flags).

### adapty access-levels get

Lấy thông tin chi tiết của một [mức độ truy cập](access-level) cụ thể.

```bash
adapty access-levels get --app <app-id> <access-level-id>
```

| Đối số | Mô tả |
|---|---|
| `access-level-id` | ID mức độ truy cập (UUID) |

| Cờ | Bắt buộc | Mô tả |
|---|---|---|
| `--app` | Có | ID ứng dụng (UUID) |

### adapty access-levels create

Tạo một [mức độ truy cập](access-level) mới.

```bash
adapty access-levels create --app <app-id> --sdk-id "pro" --title "Pro"
```

| Flag | Bắt buộc | Mô tả |
|---|---|---|
| `--app` | Có | App ID (UUID) |
| `--sdk-id` | Có | Định danh dùng trong code ứng dụng để kiểm tra quyền truy cập (ví dụ: `"pro"` hoặc `"premium"`) |
| `--title` | Có | Nhãn hiển thị trên Adapty Dashboard |

### adapty access-levels update

Cập nhật một [mức độ truy cập](access-level) hiện có.

```bash
adapty access-levels update --app <app-id> <access-level-id> --title "Pro Access"
```

| Đối số | Mô tả |
|---|---|
| `access-level-id` | ID mức độ truy cập (UUID) |

| Flag | Bắt buộc | Mô tả |
|---|---|---|
| `--app` | Có | ID ứng dụng (UUID) |
| `--title` | Có | Nhãn hiển thị mới |

`--sdk-id` không thể thay đổi sau khi đã tạo.
