<SDKv4>

Nếu ứng dụng Unity của bạn dành cho trẻ em, bạn phải tuân thủ chính sách của [Apple](https://developer.apple.com/kids/) và [Google](https://support.google.com/googleplay/android-developer/answer/9893335). Nếu đang sử dụng Adapty SDK, chỉ cần vài bước đơn giản là bạn có thể cấu hình SDK để đáp ứng các chính sách này và vượt qua quá trình kiểm duyệt của cửa hàng ứng dụng.

## Yêu cầu cần thực hiện? \{#whats-required\}

Bạn cần cấu hình Adapty SDK để tắt tính năng thu thập:

- [IDFA (Identifier for Advertisers)](https://en.wikipedia.org/wiki/Identifier_for_Advertisers) (iOS)
- [Android Advertising ID (AAID/GAID)](https://support.google.com/googleplay/android-developer/answer/6048248) (Android)
- [Địa chỉ IP](https://www.ftc.gov/system/files/ftc_gov/pdf/p235402_coppa_application.pdf)

Ngoài ra, chúng tôi khuyến nghị bạn cẩn thận khi sử dụng customer user ID. User ID theo định dạng `<FirstName.LastName>` chắc chắn sẽ bị coi là thu thập dữ liệu cá nhân, tương tự như việc sử dụng email. Đối với Kids Mode, cách tốt nhất là sử dụng các định danh ngẫu nhiên hoặc đã được ẩn danh hóa (ví dụ: ID đã hash hoặc UUID do thiết bị tạo ra) để đảm bảo tuân thủ.

## Bật Kids Mode \{#enabling-kids-mode\}

### Cập nhật trong Adapty Dashboard \{#updates-in-the-adapty-dashboard\}

Trong Adapty Dashboard, bạn cần tắt tính năng thu thập địa chỉ IP. Để thực hiện, hãy vào [App settings](https://app.adapty.io/settings/general) và nhấp vào **Disable IP address collection** trong mục **Collect users' IP address**.

### Cập nhật trong mã ứng dụng của bạn \{#updates-in-your-app-code\}

Tắt tính năng thu thập Android Advertising ID và địa chỉ IP khi bạn kích hoạt SDK:

```csharp showLineNumbers title="C#"
var builder = new AdaptyConfiguration.Builder("YOUR_PUBLIC_SDK_KEY")
// highlight-start
    .SetGoogleAdvertisingIdCollectionDisabled(true) // set to `true`
    .SetIPAddressCollectionDisabled(true); // set to `true`
// highlight-end

Adapty.Activate(builder.Build(), (error) => {
    if (error != null) {
        // handle the error
        return;
    }
});
```

Trên iOS, bạn không cần gọi `SetAppleIDFACollectionDisabled` — việc bật Kids Mode cho bản build iOS (xem bên dưới) sẽ tự động tắt tính năng thu thập IDFA trong cấu hình SDK cho bạn.

### Bật Kids Mode cho bản build iOS \{#enable-kids-mode-for-the-ios-build\}

:::important
Trên iOS, Kids Mode là một Swift package trait có tên `KidsMode`. Khi bật, tính năng này sẽ loại bỏ IDFA, AdSupport và AppTrackingTransparency khỏi binary SDK. Yêu cầu SDK 4.0 trở lên — phiên bản này cài đặt iOS SDK native thông qua Swift Package Manager — và **Xcode 26** trở lên, vì các phiên bản Xcode cũ hơn không hỗ trợ Swift package traits.
:::

1. Trong Unity Editor, vào **Player Settings** > **Other Settings** và thêm `ADAPTY_KIDS_MODE` vào **Scripting Define Symbols** cho nền tảng iOS.
2. Build dự án của bạn cho iOS như bình thường. Adapty sẽ bật trait `KidsMode` trên tham chiếu package AdaptySDK-iOS trong dự án Xcode được tạo ra, đồng thời buộc bật `apple_idfa_collection_disabled` trong cấu hình runtime.

:::warning
Thêm define trong **Player Settings**, không phải trong build profile. Các scripting define của build profile chỉ áp dụng cho các assembly của Editor sau khi Unity biên dịch lại chúng, vì vậy một bản build được khởi động trong cùng phiên làm việc có thể tạo ra một binary báo cáo Kids Mode trong khi vẫn liên kết IDFA. Adapty sẽ báo lỗi build iOS khi phát hiện trạng thái đó. `BuildPlayerOptions.extraScriptingDefines` không được hỗ trợ vì nó không bao giờ áp dụng cho các assembly của Editor.
:::

### Cập nhật trong Android manifest của bạn \{#updates-in-your-android-manifest\}

Nếu ứng dụng của bạn chỉ nhắm đến đối tượng **trẻ em** và biên dịch với Android 13 (API 33) trở lên, Google Play yêu cầu bạn không được khai báo quyền `AD_ID`. Việc tắt tính năng thu thập trong cấu hình SDK sẽ ngăn Adapty thu thập ID đó, nhưng không thể xóa một quyền đã được plugin khác khai báo thông qua quá trình hợp nhất manifest.

Để xóa quyền này, hãy bật **Custom Main Manifest** trong **Player Settings** > **Publishing Settings**, sau đó thêm đoạn sau vào bên trong phần tử `<manifest>` của `Assets/Plugins/Android/AndroidManifest.xml`. Phần tử `<manifest>` phải khai báo `xmlns:tools="http://schemas.android.com/tools"`.

```xml showLineNumbers title="AndroidManifest.xml"
<uses-permission
    android:name="com.google.android.gms.permission.AD_ID"
    tools:node="remove" />
```

Đối với Chế độ Trẻ em (Kids Mode), phương pháp tốt nhất là sử dụng các định danh ngẫu nhiên hoặc ẩn danh (ví dụ: ID đã được băm hoặc UUID do thiết bị tạo ra) để đảm bảo tuân thủ quy định.

var builder = new AdaptyConfiguration.Builder("YOUR_PUBLIC_SDK_KEY")

### Bật Kids Mode cho bản build iOS \{#enable-kids-mode-for-the-ios-build\}

Để biên dịch loại bỏ IDFA và AdSupport khỏi binary iOS, bạn cần Adapty Unity SDK 4.0 trở lên. Hãy nâng cấp theo [hướng dẫn migration](migration-to-unity-sdk-v4), sau đó làm theo hướng dẫn SDK 4.0 trên trang này.

Với SDK 3.x, bạn vẫn có thể tắt tính năng thu thập IDFA trong cấu hình SDK bằng `SetAppleIDFACollectionDisabled(true)`, nhưng mã IDFA và AdSupport vẫn còn trong binary. Để xem các tùy chọn cấu hình native, hãy xem [Kids Mode trong iOS SDK](kids-mode) và [Kids Mode trong Android SDK](kids-mode-android).
