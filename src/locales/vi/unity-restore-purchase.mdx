Khôi phục giao dịch mua trên cả iOS và Android là tính năng cho phép người dùng lấy lại quyền truy cập vào các nội dung đã mua trước đó, chẳng hạn như gói đăng ký hoặc in-app purchase, mà không bị tính phí thêm. Tính năng này đặc biệt hữu ích cho những người dùng đã gỡ cài đặt và cài đặt lại ứng dụng, hoặc chuyển sang thiết bị mới và muốn truy cập nội dung đã mua trước đó mà không phải trả tiền lại.

:::note
Nếu bạn đã xây dựng màn hình trong builder, bạn không cần tự khôi phục giao dịch mua thủ công. Chỉ cần kết nối điều khiển khôi phục — hành động **Restore purchases** trong Flow & Paywall Builder, hoặc nút/liên kết khôi phục trong phiên bản cũ — và SDK sẽ tự hoàn tất việc khôi phục.
:::

Nếu bạn tự xây dựng màn hình, hãy gọi phương thức `.restorePurchases()`:

```csharp showLineNumbers
Adapty.RestorePurchases((profile, error) => {
    if (error != null) {
        // handle the error
        return;
    }
  
    var accessLevel = profile.AccessLevels["YOUR_ACCESS_LEVEL"];
    if (accessLevel != null && accessLevel.IsActive) {
        // restore access
    }
});
```
