Mỗi khi người dùng mở một màn hình trong [flow](adapty-flow-builder), SDK sẽ báo cáo sự kiện `flow_screen_showed` đến ứng dụng của bạn. Hãy chuyển tiếp sự kiện này đến Amplitude, Mixpanel, hoặc bất kỳ hệ thống phân tích sản phẩm nào bạn đang sử dụng, để bạn có thể phân tích các màn hình flow cùng với các sự kiện còn lại trong ứng dụng.

:::tip
Để xem người dùng đi được đến đâu trong một flow, bạn không cần viết code — [flow metrics](flow-metrics) đã hiển thị lượt xem, lượt hoàn thành và tỷ lệ thoát theo từng màn hình ngay trong Adapty Dashboard. Hãy dùng hướng dẫn này khi bạn cần dữ liệu đó trong hệ thống analytics của riêng mình, kết hợp với các sự kiện mà Adapty không biết đến.
:::

## Trước khi bắt đầu \{#before-you-start\}

Bạn cần:

- **Adapty React Native SDK v4 trở lên**: Callback analytics của flow không tồn tại trong các phiên bản cũ hơn.
- **Một phiên bản flow được publish sau khi tính năng này ra mắt**: Adapty tạo các sự kiện màn hình khi publish flow, vì vậy một flow bạn đã publish trước đó sẽ không báo cáo gì cả. Nếu không có sự kiện nào đến ứng dụng của bạn, hãy publish phiên bản mới của flow và thử lại.

## Những gì bạn nhận được \{#what-you-receive\}

<FlowScreenShowedParams />

Lượt xem màn hình được gửi đến cùng callback analytics như mọi sự kiện flow khác. Xem [Xử lý sự kiện flow & paywall](react-native-handling-events-1) để biết nơi đăng ký.

## Chuyển tiếp mọi lượt xem màn hình đến analytics của bạn \{#forward-every-screen-view-to-your-analytics\}

Kiểm tra tên sự kiện trước khi đọc bất kỳ thông tin nào khác, vì một flow sẽ báo cáo các sự kiện khác thông qua cùng một callback.

```javascript showLineNumbers title="React Native"
const unsubscribe = view.setEventHandlers({
  onAnalytics(name, params) {
    if (name === 'flow_screen_showed') {
      const screenId = params.instanceId;
      const screenOrder = params.screen_order;

      // Send screenId and screenOrder to your analytics provider here.
    }
    return false; // keep the flow open
  },
});
```

## Chạy code khi người dùng đến màn hình cuối \{#run-code-when-a-user-reaches-the-end\}

`is_last_screen` là `true` trên màn hình mà flow không thể tiến thêm. Dùng nó để mở khóa nội dung, đánh dấu onboarding đã hoàn thành, hoặc gửi sự kiện hoàn thành theo cách của bạn, mà không cần thêm hành động nút trong builder.

```javascript showLineNumbers title="React Native"
const unsubscribe = view.setEventHandlers({
  onAnalytics(name, params) {
    if (name === 'flow_screen_showed' && params.is_last_screen) {
      // The user reached the end of the flow.
    }
    return false; // keep the flow open
  },
});
```

Reaching the last screen is not the same as closing the flow. A user can see the final screen and dismiss the flow without acting on it, and a branching flow can end on several different screens. To know that the flow itself went away, use `onDisappeared` instead.
