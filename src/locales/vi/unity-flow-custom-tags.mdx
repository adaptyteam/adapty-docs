[Custom tag](flow-custom-tags) là một biến tùy chỉnh có giá trị từ ứng dụng của bạn. Sau khi bạn chọn **Value comes from outside the app** trong cài đặt của biến, ứng dụng có thể đặt giá trị đó thông qua Adapty SDK. Ví dụ: một phần tử văn bản chứa "Coins:" và một custom tag. Nếu ứng dụng của bạn truyền "120" cho tag đó, người dùng sẽ thấy "Coins: 120".

## Truyền giá trị custom tag \{#pass-custom-tag-values\}

Truyền giá trị từ ứng dụng của bạn vào phương thức `SetCustomTags` của đối tượng `AdaptyUICreateFlowViewParameters`, dưới dạng dictionary từ string sang string, chẳng hạn như `Dictionary<string, string>`, rồi gọi `AdaptyUI.CreateFlowView` với đối tượng đó:

- Mỗi key là tên đầy đủ của một custom tag, ví dụ như `user.streak`.
- Mỗi value là chuỗi mà người dùng nhìn thấy thay thế cho tag đó.
- Mỗi value phải ở dạng dễ đọc, chẳng hạn "1,250" thay vì "1250.0". Adapty không tự định dạng hay dịch giá trị này.

SDK đọc các giá trị một lần duy nhất khi tạo view, vì vậy chúng sẽ không thay đổi trong khi flow đang mở.

```csharp showLineNumbers title="Unity"
var parameters = new AdaptyUICreateFlowViewParameters()
    .SetCustomTags(new Dictionary<string, string> {
        { "username", "DragonSlayer42" },
        { "coins", "1,250" }
    });

AdaptyUI.CreateFlowView(flow, parameters, (view, error) => {
    if (error != null) {
        // handle the error
        return;
    }

    // present the view
});
```

### Truyền chỉ số BMI vào paywall \{#pass-the-bmi-to-the-paywall\}

Thu thập cân nặng và chiều cao từ các sự kiện `flow_user_input` của flow onboarding, như trong [Xử lý dữ liệu từ flow](unity-flow-input). Để biết người dùng đã đến màn hình cuối cùng, hãy theo dõi sự kiện `flow_screen_showed` với `is_last_screen` được đặt thành `true`, như trong [Theo dõi lượt xem màn hình flow](unity-flow-screen-views). Khi người dùng đóng flow onboarding sau màn hình đó, hãy tính chỉ số BMI. Sau đó tạo view của paywall và truyền BMI vào custom tag `bmi`.

Triển khai các phương thức sau trên listener bạn đăng ký với `Adapty.SetFlowsEventsListener`. `FlowViewDidDisappear` chỉ kích hoạt sau khi ứng dụng của bạn đóng flow onboarding, vì vậy listener cũng phải xử lý hành động **Close flow**, như trong [Đóng flow và paywall](unity-handle-paywall-actions#close-flows-and-paywalls):

```csharp showLineNumbers title="Unity"
private readonly Dictionary<string, string> bodyAnswers = new Dictionary<string, string>();
private bool reachedLastScreen;

public void FlowViewDidReceiveAnalyticEvent(
    AdaptyUIFlowView view,
    string name,
    IReadOnlyDictionary<string, object> parameters
) {
    if (name == "flow_screen_showed") {
        if (parameters.TryGetValue("is_last_screen", out var lastScreen)
            && lastScreen is bool isLast && isLast) {
            reachedLastScreen = true;
        }
        return;
    }
    if (name != "flow_user_input") return;
    if (!parameters.TryGetValue("value", out var raw) || !(raw is string value)) return;

    if (!parameters.TryGetValue("element_id", out var idRaw) || !(idRaw is string elementId)) return;

    bodyAnswers[elementId] = value;
}

public void FlowViewDidDisappear(AdaptyUIFlowView view) {
    // The listener receives events from every flow. Reset `bodyAnswers` and
    // `reachedLastScreen` whenever a flow disappears, so that the paywall
    // doesn't open again when the user closes it.
    var answers = new Dictionary<string, string>(bodyAnswers);
    var finished = reachedLastScreen;
    bodyAnswers.Clear();
    reachedLastScreen = false;

    // Number inputs send their values as strings.
    if (!finished) return;
    if (!answers.TryGetValue("weight", out var weightText)
        || !double.TryParse(weightText, out var weight)) return;
    if (!answers.TryGetValue("height", out var heightText)
        || !double.TryParse(heightText, out var height)
        || height <= 0) return;

    var heightInMeters = height / 100;
    var bmi = weight / (heightInMeters * heightInMeters);
    ShowBmiPaywall(bmi.ToString("0.0"));
}

private void ShowBmiPaywall(string bmi) {
    Adapty.GetFlow("bmi_paywall", (flow, flowError) => {
        if (flowError != null) {
            // handle the error
            return;
        }

        var parameters = new AdaptyUICreateFlowViewParameters()
            .SetCustomTags(new Dictionary<string, string> { { "bmi", bmi } });

        AdaptyUI.CreateFlowView(flow, parameters, (view, viewError) => {
            if (viewError != null) {
                // handle the error
                return;
            }

            view.Present((presentError) => {
                if (presentError != null) {
                    // handle the error
                }
            });
        });
    });
}
```

`ToString("0.0")` sử dụng dấu phân cách thập phân theo ngôn ngữ hiện tại: "22.7" trong tiếng Anh, "22,7" trong tiếng Đức.

### Lưu chỉ số BMI vào hồ sơ người dùng \{#save-the-bmi-to-the-users-profile\}

Để hiển thị các flow khác nhau cho người dùng dựa trên chỉ số BMI, hãy lưu nó dưới dạng [thuộc tính tùy chỉnh](unity-setting-user-attributes#custom-user-attributes) trong hồ sơ của họ. Trong Adapty Dashboard, [tạo một thuộc tính tùy chỉnh kiểu **Number**](segments#custom-attributes) với khóa `bmi`. Sau đó hiển thị mỗi flow cho một [đối tượng](audience) được xây dựng từ thuộc tính đó.

Gọi phương thức `Adapty.UpdateProfile` trong `FlowViewDidDisappear`, ngay sau dòng tính toán `bmi`. Truyền vào giá trị `double` thay vì chuỗi đã được định dạng, để phân khúc có thể so sánh chỉ số BMI với một ngưỡng nhất định:

```csharp showLineNumbers title="Unity"
var parameters = new AdaptyProfileParameters.Builder()
    .SetCustomDoubleAttribute("bmi", bmi)
    .Build();

Adapty.UpdateProfile(parameters, (error) => {
    if (error != null) {
        // handle the error
    }
});
```
