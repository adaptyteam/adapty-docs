Adapty đọc sản phẩm, xác thực giao dịch mua và nhận các sự kiện gói đăng ký thông qua các API Google sau:

- Google Play Android Developer API
- Google Play Developer Reporting API
- Cloud Pub/Sub API

## Trước khi bắt đầu \{#before-you-start\}

Hãy kiểm tra xem bạn đã có [quyền truy cập và dự án Google Cloud mà tích hợp Google Play yêu cầu](initial-android#before-you-start) chưa. Bạn không thể hoàn thành các bước dưới đây nếu thiếu chúng.

## Kích hoạt các API \{#enable-the-apis\}

1. Mở [Google Cloud Console](https://console.cloud.google.com/).

2. Chọn dự án bạn sẽ dùng cho việc tích hợp.

3. Mở trang [**Google Play Android Developer API**](https://console.cloud.google.com/apis/library/androidpublisher.googleapis.com).

4. Nhấp **Enable** và chờ cho đến khi trạng thái hiển thị **Enabled**. Nếu nút hiển thị **Manage** thay vì vậy, API đã được bật và bạn không cần làm gì thêm.

   <ZoomImage id="gp-api-library-enable.webp" width="700px" alt="An API page in the Google Cloud API library, with the Enable button" />

5. Mở trang [**Google Play Developer Reporting API**](https://console.cloud.google.com/apis/library/playdeveloperreporting.googleapis.com).

6. Nhấp **Enable** và chờ đến khi trạng thái hiển thị **Enabled**.

7. Mở trang [**Cloud Pub/Sub API**](https://console.cloud.google.com/apis/library/pubsub.googleapis.com).

8. Nhấp **Enable** và chờ đến khi trạng thái hiển thị **Enabled**.

Để xác nhận, hãy mở trang [**APIs & Services**](https://console.cloud.google.com/apis/dashboard) trong Google Cloud Console. Bảng ở cuối trang liệt kê tất cả các API đang được bật trong dự án, và cả ba API sau đây đều phải xuất hiện:

- Google Play Android Developer API
- Google Play Developer Reporting API
- Cloud Pub/Sub API

<ZoomImage id="gp-apis-enabled-list.webp" width="700px" alt="Bảng APIs and services đã bật hiển thị đủ ba API bắt buộc" />
