Adapty tự động tạo các file cấu hình JSON cho [paywall dự phòng](/fallback-paywalls) của bạn, mỗi nền tảng một file. Các file này cũng chứa dữ liệu dự phòng cho các onboarding của bạn.

Nếu một placement có nhiều hơn một paywall hoặc onboarding, phiên bản dự phòng sẽ bao gồm biến thể có trọng số cao nhất hoặc đối tượng rộng nhất. Adapty cập nhật các file này mỗi khi bạn chỉnh sửa paywall hoặc onboarding.

Làm theo các bước dưới đây để tải xuống cấu hình dự phòng của bạn:

1. Mở trang **[Placements](https://app.adapty.io/placements)**.
2. Nhấn nút **Fallbacks**.
3. Chọn nền tảng mục tiêu (*iOS* hoặc *Android*) từ danh sách thả xuống.
4. Chọn phiên bản SDK của bạn để bắt đầu tải xuống.

:::tip
Để tải file từ terminal, hãy dùng [Developer CLI](developer-cli). Truyền vào phiên bản Adapty SDK mà ứng dụng của bạn đang sử dụng:

```bash
adapty fallbacks get --app <app-id> --platform ios --sdk-version <sdk-version> --output ios_fallback.json
```

Chạy lệnh này một lần cho mỗi cửa hàng, với `--platform ios` hoặc `--platform android`. Xem [`adapty fallbacks get`](developer-cli-fallbacks) để biết các flag.
:::
