Làm theo hướng dẫn này để tích hợp bản đồ tương tác vào một flow. Bản đồ hiển thị các địa điểm của bạn, chẳng hạn như các trung tâm thể hình đối tác, trong phạm vi 2 km tính từ vị trí người dùng. Ứng dụng của bạn render bản đồ dưới dạng native view trong một [phần tử tùy chỉnh](flow-custom-elements), sử dụng MapKit. Ứng dụng sẽ yêu cầu quyền truy cập vị trí ngay trên màn hình flow.

## Trước khi bắt đầu \{#before-you-start\}

- Cập nhật ứng dụng lên Adapty iOS SDK 4.4 trở lên. Các phiên bản SDK cũ hơn sẽ hiển thị [nội dung dự phòng](flow-custom-elements#set-fallback-content) cho mọi phần tử tùy chỉnh.
- Thiết lập ứng dụng để [tải](get-pb-paywalls) và [hiển thị](ios-present-paywalls) flow.
- Để yêu cầu người dùng cấp quyền truy cập vị trí, hãy thêm key `NSLocationWhenInUseUsageDescription` vào file `Info.plist` của ứng dụng. Đặt giá trị của key này là nội dung thông báo, ví dụ: "Find fitness centers near you."

## 2. Tạo map view \{#2-create-the-map-view\}

Tạo một kiểu cho các địa điểm của bạn, và một model cho quyền truy cập vị trí:

```swift showLineNumbers title="Swift"

// A place of your app, such as a partner fitness center
struct Place: Identifiable {
    let id = UUID()
    let name: String
    let coordinate: CLLocationCoordinate2D
}

// One location manager for the resolver and the map view
@MainActor
final class LocationAccess: NSObject, ObservableObject, CLLocationManagerDelegate {
    @Published private(set) var status: CLAuthorizationStatus = .notDetermined
    var isMapOnScreen = false
    private let manager = CLLocationManager()

    var isDenied: Bool { status == .denied || status == .restricted }

    override init() {
        super.init()
        manager.delegate = self
        status = manager.authorizationStatus
    }

    // Shows the prompt only if the user hasn't answered it yet
    func requestAccess() {
        manager.requestWhenInUseAuthorization()
    }

    nonisolated func locationManagerDidChangeAuthorization(_ manager: CLLocationManager) {
        let status = manager.authorizationStatus
        Task { @MainActor in self.status = status }
    }
}
```

```mdx
# Tạo chế độ xem bản đồ

Chế độ xem này yêu cầu quyền truy cập vị trí và hiển thị một marker cho mỗi địa điểm của bạn trong vòng 2 km tính từ người dùng.
```

```swift showLineNumbers title="Swift"

@available(iOS 17.0, *)
struct NearbyFitnessCentersMap: View {
    @ObservedObject var access: LocationAccess
    let places: [Place]
    @State private var position: MapCameraPosition = .userLocation(fallback: .automatic)
    @State private var nearbyPlaces: [Place] = []

    var body: some View {
        ZStack {
            if access.isDenied {
                ContentUnavailableView(
                    "Location access is off",
                    systemImage: "location.slash",
                    description: Text("To see fitness centers near you, allow location access in Settings.")
                )
            } else {
                Map(position: $position) {
                    UserAnnotation()
                    ForEach(nearbyPlaces) { place in
                        Marker(place.name, systemImage: "dumbbell.fill", coordinate: place.coordinate)
                            .tint(.teal)
                    }
                }
                .task {
                    access.requestAccess()
                    do {
                        for try await update in CLLocationUpdate.liveUpdates() {
                            guard let location = update.location else { continue }
                            nearbyPlaces = places.filter { place in
                                let placeLocation = CLLocation(
                                    latitude: place.coordinate.latitude,
                                    longitude: place.coordinate.longitude
                                )
                                return location.distance(from: placeLocation) <= 2_000 // meters
                            }
                            withAnimation {
                                position = .automatic // zoom to fit the user and the places
                            }
                            break
                        }
                    } catch {
                        // the map still shows the location of the user
                    }
                }
            }
        }
        // Tells the resolver that the map is on the screen
        .onAppear { access.isMapOnScreen = true }
        .onDisappear { access.isMapOnScreen = false }
    }
}
```

Chế độ xem bản đồ yêu cầu iOS 17 trở lên. Trên iOS 16, người dùng sẽ thấy paywall dự phòng.

Nếu người dùng từ chối quyền truy cập vị trí trên màn hình, chế độ xem sẽ thay thế bản đồ bằng thông báo hướng dẫn cách cho phép truy cập trong Cài đặt.

## 3. Khớp map với custom element \{#match-the-map-to-the-custom-element\}

Trong [resolver toàn cục](ios-flow-custom-elements#set-an-app-wide-resolver) của bạn, hãy thêm các thuộc tính cho model `LocationAccess` và danh sách địa điểm. Sau đó trả về map view cho Type `map` và ID `fitness_centers`. Các dòng được highlight cho thấy những gì cần thêm hoặc thay đổi. Nếu ứng dụng của bạn chưa có [resolver](ios-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views) toàn cục, hãy sao chép toàn bộ đoạn code:

```swift showLineNumbers title="Swift" {5-6,14-21}

struct CustomElementsResolver: AdaptyUICustomElementsResolver {
    let locationAccess = LocationAccess()
    let places: [Place] // your app's places, such as partner fitness centers

    func view(
        forType type: String,
        id: String,
        context: AdaptyUICustomElementContext
    ) -> AnyView? {
        switch type {
        case "map" where id == "fitness_centers":
            guard #available(iOS 17.0, *) else {
                return nil // iOS 16: show the fallback
            }
            if locationAccess.isDenied, !locationAccess.isMapOnScreen {
                return nil // access denied before the screen opened: show the fallback
            }
            return AnyView(NearbyFitnessCentersMap(access: locationAccess, places: places))
        // the other cases of your resolver
        default:
            return nil
        }
    }
}
```

<CustomElementMapResolverCalls />

Tạo resolver với các phần tử của bạn, và đặt nó làm resolver toàn ứng dụng. Gọi `AdaptyUI.setCustomElementsResolver` một lần, chẳng hạn khi khởi động ứng dụng:

```swift showLineNumbers title="Swift"

// your app's places, such as partner fitness centers
@MainActor let places = [
    Place(name: "Central Fitness", coordinate: CLLocationCoordinate2D(latitude: 52.5219, longitude: 13.4132)),
    Place(name: "Riverside Gym", coordinate: CLLocationCoordinate2D(latitude: 52.5163, longitude: 13.3777)),
]

// keep this instance: a resolver for one flow can reuse it
@MainActor let customElementsResolver = CustomElementsResolver(places: places)

AdaptyUI.setCustomElementsResolver(customElementsResolver)
```

## 4. Kiểm tra trên thiết bị \{#4-test-on-a-device\}

Flow & Paywall Builder không thể chạy code ứng dụng của bạn, vì vậy canvas chỉ hiển thị fallback. Để xem trước bản đồ:

1. [Xuất bản flow](builder-save-publish). Để xem phiên bản đã xuất bản mới nhất thay vì phiên bản được lưu trong bộ nhớ đệm, hãy đăng ký thiết bị làm [thiết bị thử nghiệm](test-devices).
2. Để thấy điểm đánh dấu trên bản đồ, hãy thêm một địa điểm trong phạm vi 2 km tính từ vị trí của bạn vào danh sách địa điểm.
3. Đảm bảo thiết bị chạy iOS 17 trở lên. Chạy bản build ứng dụng có chứa resolver. Mở màn hình và cho phép truy cập vị trí. Kiểm tra xem bản đồ có hiển thị vị trí của bạn và điểm đánh dấu cho địa điểm vừa thêm hay không.

Để kiểm tra paywall dự phòng, hãy từ chối quyền truy cập vị trí: trong ứng dụng **Settings**, vào **Privacy & Security** > **Location Services** > *ứng dụng của bạn*, rồi chọn **Never**. Sau đó mở lại màn hình.

Để tìm hiểu lý do tại sao paywall dự phòng hiển thị thay vì bản đồ, hãy làm theo hướng dẫn trong phần [Kiểm tra trên thiết bị](ios-flow-custom-elements#test-on-a-device) của hướng dẫn iOS.
