Plugin Adapty dạy công cụ AI của bạn cách làm việc với Adapty. Cài đặt nó trong Claude Code, Codex, Cursor, một coding agent khác, hoặc claude.ai, rồi hỏi bằng ngôn ngữ thông thường: tích hợp SDK, xây dựng paywall, tìm hiểu lý do doanh thu giảm, hoặc bắt đầu một A/B test. Plugin là một bộ skill: các quy trình đã được kiểm tra, mỗi skill cho một loại tác vụ. Đây là sản phẩm duy nhất bạn cài đặt. Nó kết nối với tài khoản Adapty của bạn thông qua Adapty MCP server hoặc Adapty CLI, và trong Claude Code và Codex, nó tự động thêm MCP server cho bạn, vì vậy bạn chỉ cần đăng nhập.

## Plugin bổ sung những gì \{#what-the-plugin-adds\}

Một AI tool có thể truy cập tài khoản Adapty của bạn thông qua [Adapty MCP server](adapty-mcp) hoặc [Adapty CLI](developer-cli-quickstart). Quyền truy cập đó cho phép nó đọc và thay đổi dữ liệu của bạn. Plugin cung cấp cho nó kiến thức để thực hiện điều đó một cách chính xác:

- **Quy tắc cấu hình flow**: Một flow là một config JSON lớn với các quy tắc chỉ tồn tại trong plugin. Nhờ đó, tool của bạn có thể xây dựng màn hình từ mô tả hoặc ảnh chụp màn hình, đồng thời validate và xem trước mọi thay đổi trước khi lưu flow. Nếu không có plugin, tool của bạn vẫn có thể đọc và ghi config flow, nhưng không thể tạo ra một config hợp lệ.
- **Các phương thức đã được kiểm thử**: Plugin biết báo cáo nào trả lời câu hỏi nào, cách đọc chúng, và số liệu của bạn so với thị trường ra sao. Nó chuyển số liệu của bạn thành các giả thuyết để A/B test, được xếp hạng theo doanh thu tiềm năng.
- **Adapty APIs hiện tại**: Khi tích hợp SDK, plugin đọc tài liệu Adapty mới nhất ở từng bước, nên tool của bạn viết code cho phiên bản SDK bạn đang cài, chứ không phải phiên bản nó nhớ từ dữ liệu huấn luyện.
- **Xác nhận trước khi thay đổi ảnh hưởng đến người dùng**: Trước khi bắt đầu A/B test, thay đổi placement, hoặc gửi email đến người dùng thật, plugin hiển thị những gì sẽ thay đổi và chờ bạn xác nhận.
- **Kết nối**: Plugin phát hiện tool của bạn đang dùng MCP server, CLI, hay cả hai, và chọn phương thức phù hợp nhất cho từng tác vụ.

## Cài đặt plugin \{#install-the-plugin\}

<Tabs groupId="ai-tool">
<TabItem value="coding-agent" label="Coding agent" default>

Plugin hoạt động với bất kỳ coding agent nào hỗ trợ skill: Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI, và nhiều agent khác.

Để cài đặt plugin, chạy lệnh sau trong terminal:

```bash
npx adapty skills install
```

Khởi động lại agent để tải plugin. Để xem các cách cài đặt khác, hãy tham khảo [README của plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Claude Code không tự cập nhật plugin. Để nhận skill mới khi có phiên bản mới, trong Claude Code, chạy `/plugin`, mở **Marketplaces**, chọn `adapty`, và chọn **Enable auto-update**.

Trong Claude Code và Codex, plugin cũng thêm Adapty MCP server, nên bạn chỉ cần đăng nhập theo hướng dẫn tại [Kết nối trợ lý của bạn](adapty-mcp#connect-your-assistant). Với các agent khác, lần đầu tiên khi một skill cần tài khoản của bạn, plugin sẽ hỏi bạn muốn dùng Adapty CLI hay MCP server và cung cấp các bước thiết lập cho lựa chọn của bạn.

</TabItem>

<TabItem value="claude-ai" label="claude.ai">

Bạn cài đặt plugin trong cài đặt của Claude, không cần dòng lệnh. Các bước thực hiện tương tự trong Claude desktop.

1. Trong Claude, mở **Settings** → **Plugins**.
2. Nhấp **Add** → **Add marketplace**.
3. Chọn **Add from a repository**.
4. Trong trường **URL**, nhập `adaptyteam/adapty-skills` và chọn repository. Để nhận các skill mới và bản sửa lỗi khi chúng ra mắt, hãy giữ **Sync automatically** bật.
5. Nhấp **Sync**.

<ZoomImage id="adapty-skills-claude-add-marketplace.png" width="584px" alt="Add marketplace dialog in Claude with adaptyteam/adapty-skills in the URL field and Sync automatically turned on" />

Claude mở tab **Discover** với các plugin từ marketplace Adapty. Để cài plugin, trong hàng **Adapty**, nhấn **Add**.

<ZoomImage id="adapty-skills-claude-discover.png" width="600px" alt="Discover tab in Claude listing the Adapty, Apple ads, and Apple ads benchmarks plugins, each with an Add button" />

Plugin chạy các script trong sandbox của Claude. Để cho phép điều này, trong **Settings** → **Capabilities**, hãy bật **Code execution and file creation**.

Để cấp cho Claude quyền truy cập vào tài khoản Adapty của bạn, hãy thêm Adapty MCP server làm connector và đăng nhập, theo hướng dẫn tại [Kết nối trợ lý của bạn](adapty-mcp#connect-your-assistant).

</TabItem>

## Những gì bạn có thể làm \{#what-you-can-do\}

Bạn không cần đặt tên skill. Hãy đặt câu hỏi như khi bạn trao đổi với đồng nghiệp — plugin sẽ tự chọn workflow phù hợp.

### Tích hợp SDK \{#integrate-the-sdk\}

```
Integrate Adapty into my app
```

Plugin cấu hình ứng dụng của bạn trong Adapty Dashboard, cài đặt SDK, thêm paywall và xác minh từng giai đoạn trước khi tiến tiếp. Plugin tự động nhận diện nền tảng của bạn. Xem hướng dẫn cho [iOS](adapty-sdk-integration-skill), [Android](adapty-sdk-integration-skill-android), [React Native](adapty-sdk-integration-skill-react-native), [Flutter](adapty-sdk-integration-skill-flutter), [Unity](adapty-sdk-integration-skill-unity), [Kotlin Multiplatform](adapty-sdk-integration-skill-kmp), hoặc [Capacitor](adapty-sdk-integration-skill-capacitor).

### Xây dựng và chỉnh sửa flow

```
Add a German locale to my onboarding flow
```

Plugin này [xây dựng và chỉnh sửa flow](flow-generator-skill): thêm ngôn ngữ, viết lại nội dung, thêm hoặc xóa màn hình, thiết lập nhánh quiz, và xây dựng paywall từ mô tả. Trước khi xuất bản, plugin sẽ [kiểm tra flow](flow-audit-skill) về trigger, tuân thủ cửa hàng, sản phẩm và bản địa hóa. Nếu placement của bạn đang hiển thị paywall, plugin sẽ [chuyển chúng sang flow](migrate-placements-skill).

### Tìm điều cần test tiếp theo \{#find-what-to-test-next\}

```
Audit my app. What should I test next to grow revenue?
```

Plugin [đọc analytics, giá cả và các A/B test trước đây của bạn](export-analytics-with-ai), đánh giá từng phần trong mô hình kinh doanh của bạn so với thị trường, và trả về các giả thuyết được xếp hạng theo doanh thu có thể đạt được. Plugin cũng trả lời các câu hỏi thông thường về số liệu của bạn, chẳng hạn như lý do tỷ lệ gia hạn giảm vào tháng trước.

### Chạy A/B test \{#run-ab-tests\}

```
Start a 50/50 test of my two onboarding paywalls
```

Plugin này [tạo, khởi động, dừng và thay thế A/B test](ab-tests-skill) cho paywall và flow.

### Phân tích chiến dịch quảng cáo của bạn \{#analyze-your-ad-campaigns\}

```
Which campaigns should I scale, and which should I cut?
```

Plugin [đọc dữ liệu Attribution của Adapty](developer-cli-attribution-skill): ROAS, thời gian hoàn vốn, chi phí mỗi lượt dùng thử, và số tiền hoàn trả theo kênh, chiến dịch, và quốc gia.

:::tip
Chiến dịch Apple Ads có plugin riêng. Xem [Quản lý Apple Ads với công cụ AI](developer-cli-ads-manager-skill).
:::

### Chạy Adapty Mail

```
Why didn't this user get the welcome email?
```

Plugin [kết nối Adapty Mail MCP server](mail-skill), khởi chạy email flow, và truy tìm lý do tại sao email không được gửi. Plugin sẽ hỏi trước khi thực hiện bất kỳ hành động nào gửi email đến người thật.

### Migrate từ RevenueCat \{#migrate-from-revenuecat\}

```
Move my RevenueCat project to Adapty
```

Agent lập trình sẽ sao chép catalog RevenueCat và thiết kế paywall của bạn sang ứng dụng Adapty mới, sau đó thay thế SDK RevenueCat trong code bằng các lệnh gọi sử dụng ID Adapty tương ứng. Xem [Migration từ RevenueCat](migration-from-revenuecat).

## Plugin kết nối với tài khoản của bạn như thế nào \{#how-the-plugin-reaches-your-account\}

Plugin hoạt động thông qua hai kết nối. Khi công cụ của bạn chưa có cả hai, plugin sẽ hỏi bạn muốn thiết lập cái nào và hướng dẫn từng bước. Khi cả hai đã có, plugin sẽ chọn một trong hai cho mỗi tác vụ:

- **[Adapty MCP server](adapty-mcp)**: Kết nối dành cho claude.ai và Claude desktop, cũng như các coding agent hỗ trợ MCP. Bạn đăng nhập bằng tài khoản Adapty trên trình duyệt. Không cần API key.
- **[Adapty CLI](developer-cli-quickstart)**: Kết nối dành cho các coding agent chạy lệnh terminal. Các workflow về flow và analytics ưu tiên dùng CLI vì chúng làm việc với file cục bộ. Bạn cũng có thể tự chạy CLI hoặc gọi từ script của mình.

## Xây dựng backend của bạn với AI \{#build-your-backend-with-ai\}

Hai hướng dẫn dưới đây dành cho phần code bạn tự viết trên server của mình. Hãy sao chép hướng dẫn vào công cụ AI của bạn — nó đã bao gồm code chạy được, các lưu ý về trường dữ liệu, và các giới hạn trong một lần dán:

- [Xử lý sự kiện gói đăng ký](handle-webhooks-with-ai): nhận webhook Adapty tại endpoint của bạn.
- [Kiểm tra và cấp quyền truy cập gói đăng ký](server-side-api-with-ai): gọi server-side API của Adapty từ backend của bạn.

## Cung cấp tài liệu Adapty cho công cụ AI của bạn \{#give-your-ai-tool-the-adapty-docs\}

### Tài liệu dạng văn bản thuần

Mỗi tài liệu Adapty đều có phiên bản Markdown — thêm `.md` vào URL trang, hoặc nhấp vào **Copy for LLM** bên dưới tiêu đề. Để có ngữ cảnh rộng hơn, hãy cung cấp cho công cụ của bạn chỉ mục [`llms.txt`](https://adapty.io/docs/vi/llms.txt) hoặc một tập con theo nền tảng như [`ios-llms.txt`](https://adapty.io/docs/vi/ios-llms.txt).

### Context7

[Context7](https://context7.com/adaptyteam/adapty-docs) is an MCP server that serves Adapty docs to your AI tool, but it indexes only code snippets — not the full prose. Use it for quick code examples; for complete guidance, give your tool the [plain-text docs](#plain-text-docs). Context7 serves docs only; to work with your account, [install the Adapty plugin](#install-the-plugin).
