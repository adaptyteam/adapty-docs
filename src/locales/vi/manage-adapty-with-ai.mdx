Adapty hoạt động với các công cụ AI và agent lập trình. Dùng chúng để tích hợp SDK, hỏi về analytics, hoặc tra cứu tài liệu Adapty ngay trong editor của bạn. Trang này liệt kê các công cụ hiện có và đối tượng phù hợp với từng công cụ.

## Tích hợp Adapty SDK với AI \{#integrate-the-adapty-sdk-with-ai\}

Hai cách để thêm Adapty SDK vào ứng dụng của bạn bằng công cụ lập trình AI. Cả hai đều hoạt động với Cursor, Claude và các trợ lý AI khác.

### Tích hợp dựa trên skill \{#skill-based-integration\}

Skill tích hợp Adapty SDK sẽ chạy toàn bộ quá trình tích hợp từ công cụ AI coding của bạn chỉ với một lệnh. Dùng skill này khi bạn muốn thiết lập tự động, có hướng dẫn.

Chọn nền tảng của bạn: [iOS](adapty-sdk-integration-skill) · [Android](adapty-sdk-integration-skill-android) · [React Native](adapty-sdk-integration-skill-react-native) · [Flutter](adapty-sdk-integration-skill-flutter) · [Unity](adapty-sdk-integration-skill-unity) · [Kotlin Multiplatform](adapty-sdk-integration-skill-kmp) · [Capacitor](adapty-sdk-integration-skill-capacitor)

### Tích hợp từng bước

Hướng dẫn công cụ AI của bạn qua từng giai đoạn tích hợp theo thứ tự, cung cấp đúng tài liệu vào đúng lúc. Sử dụng khi bạn muốn xem xét từng bước trong quá trình thực hiện.

Chọn nền tảng của bạn: [iOS](adapty-cursor) · [Android](adapty-cursor-android) · [React Native](adapty-cursor-react-native) · [Flutter](adapty-cursor-flutter) · [Unity](adapty-cursor-unity) · [Kotlin Multiplatform](adapty-cursor-kmp) · [Capacitor](adapty-cursor-capacitor)

## Xây dựng và chỉnh sửa flow bằng công cụ lập trình AI \{#build-and-edit-flows-with-an-ai-coding-tool\}

[Flow-generator skill](flow-generator-skill) chỉnh sửa các flow Adapty của bạn ngay từ terminal — thêm ngôn ngữ, viết lại nội dung, thêm hoặc xóa màn hình, thiết lập phân nhánh, hoặc tạo paywall từ mô tả. Công cụ này xem trước và kiểm tra mọi thay đổi cục bộ, sau đó lưu bản nháp để bạn xuất bản.

## Quản lý Adapty từ dòng lệnh \{#manage-adapty-from-the-command-line\}

[Adapty Developer CLI](developer-cli-quickstart) cho phép bạn quản lý các thực thể trong Adapty — apps, mức độ truy cập, sản phẩm, paywall và placement — ngay từ terminal, mà không cần mở dashboard. Vì đây là công cụ dòng lệnh, AI coding agent của bạn có thể chạy trực tiếp.

## Hỏi về dữ liệu của bạn \{#ask-about-your-data\}

Trỏ một AI coding agent vào Export Analytics API để truy vấn các chỉ số của bạn bằng ngôn ngữ thông thường — doanh thu, retention, LTV, và nhiều hơn nữa. Không cần MCP server.

## Cung cấp tài liệu Adapty cho công cụ AI của bạn \{#give-your-ai-tool-the-adapty-docs\}

### Tài liệu dạng văn bản thuần

Mỗi tài liệu Adapty đều có phiên bản Markdown — thêm `.md` vào URL trang, hoặc nhấp vào **Copy for LLM** bên dưới tiêu đề. Để có ngữ cảnh rộng hơn, hãy cung cấp cho công cụ của bạn chỉ mục [`llms.txt`](https://adapty.io/docs/vi/llms.txt) hoặc một tập con theo nền tảng như [`ios-llms.txt`](https://adapty.io/docs/vi/ios-llms.txt).

### Context7

[Context7](https://context7.com/adaptyteam/adapty-docs) is an MCP server that serves Adapty docs to your AI tool, but it indexes only code snippets — not the full prose. Use it for quick code examples; for complete guidance, give your tool the plain-text docs above. Context7 works with Cursor, Claude Code, Windsurf, and other MCP-compatible tools.
