Khôi phục giao dịch mua là tính năng cho phép người dùng lấy lại quyền truy cập vào nội dung đã mua trước đó — chẳng hạn như các gói đăng ký hoặc in-app purchase — mà không bị tính tiền thêm lần nữa. Tính năng này đặc biệt hữu ích cho những người đã gỡ cài đặt rồi cài lại ứng dụng, hoặc chuyển sang thiết bị mới và muốn truy cập lại nội dung đã mua mà không cần thanh toán lại.

:::note
Trong các paywall được xây dựng bằng [Paywall Builder](adapty-paywall-builder), giao dịch mua sẽ được khôi phục tự động mà không cần thêm code từ phía bạn. Nếu đó là trường hợp của bạn — bạn có thể bỏ qua bước này.
:::

Để khôi phục giao dịch mua khi bạn không sử dụng [Paywall Builder](adapty-paywall-builder) để tùy chỉnh paywall, hãy gọi phương thức `.restorePurchases()`:

<Tabs groupId="current-os" queryString>

<TabItem value="kotlin" label="Kotlin" default>

```kotlin showLineNumbers
Adapty.restorePurchases { result ->
    when (result) {
        is AdaptyResult.Success -> {
            val profile = result.value
                      
            if (profile.accessLevels["YOUR_ACCESS_LEVEL"]?.isActive == true) {
            // successful access restore
            }
        }
        is AdaptyResult.Error -> {
            val error = result.error
            // handle the error
        }
    }
}
```
</TabItem>
<TabItem value="java" label="Java" default>

```java showLineNumbers
Adapty.restorePurchases(result -> {
    if (result instanceof AdaptyResult.Success) {
        AdaptyProfile profile = ((AdaptyResult.Success<AdaptyProfile>) result).getValue();
        
        if (profile != null) {
            AdaptyProfile.AccessLevel premium = profile.getAccessLevels().get("YOUR_ACCESS_LEVEL");
            
            if (premium != null && premium.isActive()) {
                // successful access restore
            }
        }
    } else if (result instanceof AdaptyResult.Error) {
        AdaptyError error = ((AdaptyResult.Error) result).getError();
        // handle the error
    }
});
```
</TabItem>

</Tabs>

Response parameters:

| Parameter | Description |
|---------|-----------|
| **Profile** | <p>Một đối tượng [`AdaptyProfile`](https://android.adapty.io/adapty/com.adapty.models/-adapty-profile/). Model này chứa thông tin về các mức độ truy cập, gói đăng ký, và các sản phẩm mua một lần.</p><p>Kiểm tra **trạng thái mức độ truy cập** để xác định xem người dùng có quyền truy cập vào ứng dụng hay không.</p> |

:::info
Trong Adapty Android SDK 4.0.2 trở lên, `restorePurchases()` hoàn thành thành công ngay cả khi không có gì để khôi phục: nó trả về hồ sơ người dùng hiện tại, vì vậy hãy kiểm tra trạng thái mức độ truy cập trong đó. Trong các phiên bản SDK trước đó, phương thức này thất bại với lỗi `NO_PURCHASES_TO_RESTORE` trong trường hợp này.
:::

## Những gì có thể được khôi phục \{#what-can-be-restored\}

`restorePurchases` khôi phục các gói đăng ký đang hoạt động và các sản phẩm mua một lần chưa được tiêu thụ từ Google Play.

Trong Adapty Android SDK 4.0.2 trở lên, sử dụng Google Play Billing Library 8, Play Store không còn trả về các gói đăng ký đã hết hạn hoặc các sản phẩm mua một lần đã được tiêu thụ. Để người dùng có thể khôi phục những giao dịch đó trên nhiều thiết bị và sau khi cài đặt lại, hãy [xác định họ](android-identifying-users) bằng `Adapty.identify`. Adapty sau đó sẽ khôi phục lịch sử mua hàng từ backend của mình thay vì từ cửa hàng.

:::note
Google Play chỉ báo cáo những giao dịch mua hiện đang sở hữu, vì vậy `restorePurchases()` không thể tìm thấy các gói đăng ký đã hết hạn trước khi bạn tích hợp Adapty. Để thêm chúng vào Adapty, hãy [import dữ liệu lịch sử của bạn](importing-historical-data-to-adapty).
:::
