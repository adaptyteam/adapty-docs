title: "Thông tin xác thực Apple App Store"
description: "Đối với ứng dụng iOS, tìm hiểu nội dung từng phần trong tab iOS SDK của App settings và cách thiết lập từng mục."
metadataTitle: "Cấu hình cài đặt iOS trong Adapty | Tài liệu Adapty"
---

Tab [**iOS SDK**](https://app.adapty.io/settings/ios-sdk) trong **App settings** lưu trữ thông tin xác thực App Store của ứng dụng. Để nhập tất cả thông tin, hãy làm theo hướng dẫn [Configure App Store integration](app-store-connection-configuration).

<ZoomImage id="app-settings-ios-sdk.webp" width="700px" alt="Tab iOS SDK trong App settings" />

| Phần | Nội dung và lý do Adapty cần | Nơi thiết lập |
|---|---|---|
| **SDK status** | SDK Adapty đã được cài đặt trong ứng dụng của bạn chưa | [Cài đặt Adapty SDK](installation-of-adapty-sdks) |
| **Bundle ID** | Bundle ID của ứng dụng, dùng để xử lý thanh toán | [Nhập Bundle ID và Apple App ID](app-store-connection-configuration#enter-the-bundle-id-and-apple-app-id) |
| **In-app purchase API (StoreKit 2)** | Khóa In-App Purchase, dùng để xác thực thanh toán | [Thêm khóa In-App Purchase vào Adapty](generate-in-app-purchase-key) |
| **App Store Connect shared secret** | Shared secret riêng của ứng dụng, dùng để xác thực biên lai thanh toán và tạo sản phẩm trong App Store Connect | [Nhập app-specific shared secret](app-store-connection-configuration#enter-the-app-specific-shared-secret) |
| **App Store server notifications** | URL nhận sự kiện gói đăng ký từ Apple, và URL tùy chọn của máy chủ bạn để Adapty chuyển tiếp các sự kiện đó | [Bật App Store server notifications](enable-app-store-server-notifications) |
| **Apple Retention Messaging API** | URL bạn gửi cho Apple khi yêu cầu quyền truy cập vào Retention Messaging API | [Thiết lập Retention Messaging](retention-messaging-setup) |
| **App Store promotional offers** | ID và file của khóa In-App Purchase, dùng để ký các ưu đãi | [Thêm khóa In-App Purchase vào Adapty](generate-in-app-purchase-key) |
| **App Store Connect API key** | Khóa từ tab **Team Keys** trong App Store Connect, dùng để tạo sản phẩm và đồng bộ trạng thái cũng như giá của chúng | [Thêm App Store Connect API key vào Adapty](app-store-connect-api-key) |
| **Apple App ID** | Apple ID của ứng dụng, dùng để tìm kiếm và tạo sản phẩm trong App Store Connect cùng các mục đích khác | [Nhập Bundle ID và Apple App ID](app-store-connection-configuration#enter-the-bundle-id-and-apple-app-id) |
