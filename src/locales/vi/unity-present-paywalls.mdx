Nếu bạn đã tạo một flow hoặc paywall, bạn không cần lo lắng về việc render nó trong code ứng dụng di động để hiển thị cho người dùng. Flow hoặc paywall đó đã chứa cả nội dung cần hiển thị lẫn cách thức hiển thị.

:::warning

Hướng dẫn này dành cho các flow và **paywall được xây dựng bằng Paywall Builder mới** do Adapty render. Quy trình sẽ khác đối với paywall dùng Remote Config và [Observer mode](observer-vs-full-mode).

- Để hiển thị **paywall Remote Config**, xem [Hiển thị paywall được thiết kế bằng Remote Config](present-remote-config-paywalls-unity).
- Để hiển thị flow trong **Observer mode**, xem [Hiển thị flow trong Observer mode](unity-present-flows-in-observer-mode).

:::

Để lấy đối tượng `view` được sử dụng bên dưới, xem [Lấy flow & paywall](unity-get-pb-paywalls).

Để hiển thị một flow hoặc paywall, hãy sử dụng phương thức `view.Present()` trên `view` được tạo bởi phương thức [`CreateFlowView`](unity-get-pb-paywalls#fetch-the-view-configuration). Mỗi `view` chỉ có thể được sử dụng một lần: một view đã bị đóng sẽ bị hủy. Nếu bạn cần hiển thị lại flow, hãy gọi `CreateFlowView` thêm một lần nữa để tạo một `view` mới.

:::warning
Việc tái sử dụng cùng một `view` mà không tạo lại có thể dẫn đến lỗi.
:::

```csharp showLineNumbers title="Unity"
view.Present((error) => {
    // handle the error
});
```

## Hiển thị hộp thoại \{#show-dialog\}

Sử dụng phương thức này thay cho các hộp thoại cảnh báo mặc định khi một flow hoặc paywall đang được hiển thị trên Android. Trên Android, các alert thông thường sẽ xuất hiện phía sau view của flow, khiến người dùng không thể nhìn thấy chúng. Phương thức này đảm bảo hộp thoại được hiển thị đúng cách phía trên flow trên tất cả các nền tảng.

```csharp showLineNumbers title="Unity"
var dialog = new AdaptyUIDialogConfiguration()
    .SetTitle("Close this screen?")
    .SetContent("You will lose access to exclusive offers.")
    .SetDefaultActionTitle("Stay")
    .SetSecondaryActionTitle("Close");

AdaptyUI.ShowDialog(view, dialog, (action, error) => {
    if (error == null) {
        if (action == AdaptyUIDialogActionType.Secondary) {
            // User confirmed - close the flow
            view.Dismiss((error) => {
                // handle the error
            });
        }
        // If primary - do nothing, user stays
    }
});
```

## Cấu hình kiểu hiển thị trên iOS \{#configure-ios-presentation-style\}

Cấu hình cách flow hoặc paywall hiển thị trên iOS bằng cách truyền tham số `iosPresentationStyle` vào phương thức `Present()`. Tham số này chấp nhận các giá trị `AdaptyUIIOSPresentationStyle.FullScreen` (mặc định) hoặc `AdaptyUIIOSPresentationStyle.PageSheet`.

```csharp showLineNumbers title="Unity"
view.Present(AdaptyUIIOSPresentationStyle.PageSheet, (error) => {
    // handle the error
});
```

Nếu bạn đã tùy chỉnh một paywall bằng Paywall Builder, bạn không cần lo lắng về việc render nó trong code ứng dụng để hiển thị cho người dùng. Paywall như vậy chứa cả nội dung cần hiển thị lẫn cách hiển thị nó.

Để hiển thị paywall, sử dụng phương thức `view.Present()` trên `view` được tạo bởi phương thức [`CreatePaywallView`](unity-get-pb-paywalls#fetch-the-view-configuration-of-paywall-designed-using-paywall-builder). :::warning

Việc tái sử dụng cùng một `view` mà không tạo lại có thể dẫn đến lỗi `AdaptyUIError.viewAlreadyPresented`.
:::

```csharp showLineNumbers title="Unity"
view.Present((error) => {
  // handle the error
});
```
