Deeplink hoãn (deferred deeplinks) cho phép bạn truyền dữ liệu tùy chỉnh vào ứng dụng khi người dùng cài đặt nó sau khi nhấp vào quảng cáo của bạn. Ví dụ: bạn có thể điều hướng họ đến một vị trí cụ thể trong ứng dụng ngay sau khi họ cài đặt và khởi chạy.

:::important
Kể từ Adapty SDK phiên bản 4.1, Adapty Attribution bị tắt theo mặc định. Callback `onInstallationDetailsSuccess` chỉ kích hoạt sau khi bạn [bật Adapty Attribution khi khởi tạo SDK](user-acquisition#step-1-enable-adapty-attribution-in-the-sdk).
:::

Cách thức hoạt động:

1. Khi người dùng nhấp vào quảng cáo của bạn, Adapty lưu dữ liệu nhấp chuột.
2. Khi Adapty ghi nhận sự kiện cài đặt, nó lấy dữ liệu deferred từ lần nhấp đó.
3. Sau khi người dùng cài đặt ứng dụng và khởi chạy lần đầu tiên, Adapty truy xuất dữ liệu đã lưu và ứng dụng của bạn nhận được các tham số tùy chỉnh, cho phép bạn xử lý các giá trị khác nhau trong code ứng dụng.

Adapty hỗ trợ các tham số deferred data sau:

- `ios_deferred_data`
- `android_deferred_data`
- `deferred_data_sub[1-10]`

Để thêm tham số deferred data, hãy nối chúng vào link trong cài đặt chiến dịch của bạn:

1. Mở chiến dịch của bạn từ trang **Integrations -> Meta/TikTok Ads**. Hoặc mở tracking link từ trang **Tracking links**. Sao chép click link mà bạn sẽ dùng trong chiến dịch.

<ZoomImage id="ua-lnk.webp" width="900px" />

2. Trong nền tảng quảng cáo của bạn (Meta, TikTok, Google Ads, v.v.), dán link vào trường URL đích của quảng cáo, sau đó thêm các tham số deferred data vào link đó dưới dạng query parameter bổ sung — mỗi tham số được bắt đầu bằng `&`. Ví dụ: để đưa người dùng iOS đến màn hình 'Welcome' sau khi cài đặt, thêm `&ios_deferred_data=welcome`. URL đích cuối cùng sẽ có dạng như sau:

```
https://api-ua.adapty.io/api/v1/attribution/click?adpt_cid=__ADAPTY__ID__&ios_deferred_data=welcome&campaign_id=__CAMPAIGN_ID__&adset_id=__AID__&ad_id=__CID__&campaign_name=__CAMPAIGN_NAME__&adset_name=__AID_NAME__&ad_name=__CID_NAME__&redirect_url=__APP_LINK__
```

3. Xử lý các tham số trong code của ứng dụng. Lưu ý rằng các tham số deferred data nằm trong tham số `payload`, và `payload` là một JSON đã được escape, vì vậy bạn cần parse nó trong code ứng dụng.

Ví dụ, đây là cách bạn có thể xử lý các lượt cài đặt có `ios_deferred_data` là `welcome`:

<TabItem value="swift" label="Swift" default>
```swift showLineNumbers
Adapty.delegate = self

nonisolated func onInstallationDetailsSuccess(_ details: AdaptyInstallationDetails) {
    guard
        let payloadStr = details.payload,
        let data = payloadStr.data(using: .utf8),
        let payload = try? JSONSerialization.jsonObject(with: data) as? [String: Any],
        let deeplink = payload["ios_deferred_data"] as? String,
        deeplink == "welcome"
    else { return }

    DispatchQueue.main.async {
        print("Navigate to welcome screen")
        // navigate to your screen here
    }
}
```

<TabItem value="android" label="Kotlin">

```kotlin showLineNumbers
Adapty.setOnInstallationDetailsListener(object : OnInstallationDetailsListener {
    override fun onInstallationDetailsSuccess(details: AdaptyInstallationDetails) {
        details.payload?.let {
            runCatching {
                val json = JSONObject(it)
                if (json.optString("android_deferred_data") == "welcome") {
                    println("Navigate to welcome screen")
                    // navigate here
                }
            }.onFailure(Throwable::printStackTrace)
        }
    }
})

```

            if (payload.ios_deferred_data === 'welcome') {
