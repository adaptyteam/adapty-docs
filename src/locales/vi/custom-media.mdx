Flow & Paywall Builder bao gồm ba loại phần tử media thuộc danh mục **Media**: Image, Video và Icon.

:::tip
Để hình ảnh hoặc video bao phủ toàn bộ màn hình — kể cả các vùng phía sau notch và home indicator — hãy đặt nó ở chế độ fixed với tất cả offset bằng 0 và chọn **Ignore safe area**. Xem [Bố cục và vị trí](manage-paywall-ui-elements#ignore-safe-area).
:::

## Hình ảnh \{#image\}

Tải lên tệp `.JPG`, `.PNG`, hoặc `.WEBP` dung lượng tối đa 20 MB.

Ảnh GIF và WEBP động không được hỗ trợ. Để thêm chuyển động, hãy dùng phần tử [Video](#video) thay thế.

:::tip
Để đặt nội dung lên trên một hình ảnh toàn màn hình, hãy [tạo hero image](paywall-head-picture#use-a-background-as-a-hero-image) từ nền màn hình và một sliding sheet.
:::

- **Aspect** — kiểm soát cách hình ảnh khớp với container:
  - **Fit** — thu phóng hình ảnh để vừa khít trong container mà không cắt xén.
  - **Fill** — kéo giãn hình ảnh để lấp đầy container.
  - **Cover** — thu phóng hình ảnh để phủ kín container, cắt xén nếu cần. Mặc định.
- **Use custom media ID** — xem [Custom media ID](#custom-media-id) bên dưới.

## Video \{#video\}

Tải lên tệp `.MP4` hoặc `.WEBM` tối đa 50 MB và không dài hơn 30 giây. Độ phân giải video tối thiểu là 640x640 pixel.

- **Aspect** — Fit, Fill hoặc Cover. Mặc định là Fill.
- **Loop** — phát lại video liên tục. Bật theo mặc định.
- **Use custom media ID** — xem [Custom media ID](#custom-media-id) bên dưới.

Video không phát trong bản xem trước trên editor — canvas chỉ hiển thị một khung hình tĩnh. Trên thiết bị khi chạy thực tế, video phát ở chế độ tắt tiếng theo mặc định. Khi bật Loop, video lặp lại vô hạn.

### Kích hoạt hành động khi video kết thúc \{#trigger-an-action-when-the-video-ends\}

:::link
Bài viết chính: [Hành động](onboarding-actions)
:::

Phần tử Video hỗ trợ trigger **On playback finished** kích hoạt khi video phát đến cuối. Thiết lập nó trong bảng **Interactions** để điều hướng đến màn hình khác, hiển thị CTA, hoặc thực hiện bất kỳ hành động nào khác.

## Biểu tượng \{#icon\}

<ZoomImage id="builder-icon-selection.webp" width="300px" float="right" alt="Icon picker with the Tabler Icons library" />

Chọn từ thư viện [Tabler Icons](https://tabler.io/icons) được tích hợp sẵn, với hàng nghìn biểu tượng theo hai phong cách hiển thị:

- **Stroke** — chỉ viền ngoài.
- **Filled** — tô đặc.

Tìm kiếm trong bộ chọn bằng từ khóa để tìm biểu tượng. Đặt màu cho biểu tượng trong bộ chọn **Color** — chọn [kiểu màu](builder-styling) đã lưu hoặc đặt màu tùy chỉnh.

## Bản địa hóa media \{#localize-media\}

:::link
Bài viết chính: [Thêm ngôn ngữ](add-paywall-locale-in-adapty-paywall-builder)
:::

Các phần tử Hình ảnh và Video có thể chứa một file riêng cho từng ngôn ngữ. Kích hoạt ngôn ngữ mục tiêu, chọn phần tử, rồi tải lên file đã được bản địa hóa trong bảng thuộc tính. Các ngôn ngữ chưa có file riêng sẽ hiển thị file của ngôn ngữ mặc định.

### Hạn chế \{#limitations\}

Bạn không thể bản địa hóa những phần sau:

- Icons
- **Fill** của màn hình hoặc container — bao gồm nền màn hình và hình ảnh hoặc video nền của container, được thiết lập trong mục [Fill](builder-styling#fill). Để thay đổi hình ảnh hoặc video theo ngôn ngữ, hãy thêm nó dưới dạng phần tử [Image](#image) hoặc [Video](#video) độc lập — những phần tử này hỗ trợ file theo từng ngôn ngữ, như mô tả trong [Bản địa hóa media](#localize-media).
- ID media tùy chỉnh

## ID media tùy chỉnh \{#custom-media-id\}

:::important
Bạn cũng có thể đặt ID media tùy chỉnh cho [background](paywall-head-picture) dạng ảnh hoặc video.
:::

Gắn thẻ một phần tử ảnh hoặc video với ID media tùy chỉnh để hoán đổi nó lúc runtime từ code của ứng dụng. Dùng tính năng này cho [hình ảnh được cá nhân hóa](get-pb-paywalls#customize-assets) — ví dụ như hiển thị avatar mà người dùng đã chọn.

Media bạn tải lên trong Flow & Paywall Builder sẽ đóng vai trò là fallback. Nếu code của bạn không cung cấp media cho ID đó lúc runtime, fallback sẽ được hiển thị thay thế.

Một custom media ID chỉ có thể hoán đổi file cùng loại — ảnh với ảnh, video với video. Nếu loại không khớp, fallback sẽ được hiển thị.

Để bật custom media ID cho phần tử Image hoặc Video:

1. Chọn checkbox **Use custom media ID** bên dưới khu vực tải lên.
2. Nhập một media ID.
3. Tải lên ảnh hoặc video dự phòng.

Trong code ứng dụng, tải media theo ID của nó — xem [Tùy chỉnh assets](get-pb-paywalls#customize-assets) để biết API SDK.
