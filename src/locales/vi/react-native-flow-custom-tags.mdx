[Custom tag](flow-custom-tags) là một biến tùy chỉnh với giá trị lấy từ ứng dụng của bạn. Sau khi bạn chọn **Value comes from outside the app** trong cài đặt của biến, ứng dụng có thể gán giá trị cho biến đó thông qua Adapty SDK. Ví dụ: một phần tử văn bản có nội dung "Coins:" và một custom tag. Nếu ứng dụng của bạn truyền "120" cho tag đó, người dùng sẽ thấy "Coins: 120".

## Truyền giá trị custom tag \{#pass-custom-tag-values\}

Truyền các giá trị từ ứng dụng của bạn vào trường `customTags` của tham số view, dưới dạng một object. Với component `AdaptyFlowView`, tham số này là prop `params` của nó. Với `createFlowView`, đây là đối số thứ hai của nó.

- Mỗi key là tên đầy đủ của một custom tag, ví dụ `user.streak`.
- Mỗi value là chuỗi mà người dùng thấy thay cho tag đó.
- Mỗi value phải ở dạng con người đọc được, ví dụ "1,250" thay vì "1250.0". Adapty không tự định dạng hay dịch giá trị này.

`createFlowView` đọc các giá trị một lần khi tạo view, do đó chúng không thay đổi trong khi flow đang mở. Nếu `params` của một `AdaptyFlowView` đã được gắn kết thay đổi, component sẽ tạo lại flow view và flow bắt đầu lại từ màn hình đầu tiên. Hãy giữ nguyên `params` trong khi flow đang mở.

### Truyền chỉ số BMI vào paywall \{#pass-the-bmi-to-the-paywall\}

Thu thập cân nặng và chiều cao từ các sự kiện `flow_user_input` của onboarding flow, như trong [Xử lý dữ liệu từ flow](react-native-flow-input). Để biết người dùng đã đến màn hình cuối, hãy theo dõi sự kiện `flow_screen_showed` với `is_last_screen` được đặt là `true`, như trong [Theo dõi lượt xem màn hình flow](react-native-flow-screen-views). Khi người dùng đóng onboarding flow sau màn hình đó, hãy tính BMI. Sau đó tạo view cho paywall và truyền BMI vào custom tag `bmi`.

Đăng ký các handler sau trên `onboardingView`, là view mà `createFlowView` trả về cho onboarding flow. Component `AdaptyFlowView` không có handler `onDisappeared`, vì vậy ví dụ này không hoạt động với nó.

```javascript showLineNumbers title="React Native"

const bodyAnswers = {};
let reachedLastScreen = false;

const unsubscribe = onboardingView.setEventHandlers({
  onAnalytics(name, params) {
    if (name === 'flow_screen_showed' && params.is_last_screen) {
      reachedLastScreen = true;
    }
    if (name === 'flow_user_input' && typeof params.value === 'string') {
      bodyAnswers[params.element_id] = params.value;
    }
    return false; // keep the flow open
  },
  onDisappeared() {
    // Number inputs send their values as strings.
    const weight = Number(bodyAnswers.weight);
    const height = Number(bodyAnswers.height);
    const finished = reachedLastScreen;
    delete bodyAnswers.weight;
    delete bodyAnswers.height;
    reachedLastScreen = false;

    if (finished && weight > 0 && height > 0) {
      const heightInMeters = height / 100;
      const bmi = weight / (heightInMeters * heightInMeters);
      showBmiPaywall(bmi.toLocaleString(undefined, { maximumFractionDigits: 1 }));
    }
    return false;
  },
});

async function showBmiPaywall(bmi) {
  try {
    const flow = await adapty.getFlow('bmi_paywall');
    const view = await createFlowView(flow, { customTags: { 'bmi': bmi } });
    await view.present();
  } catch (error) {
    // handle the error
  }
}
```

`toLocaleString` sử dụng dấu phân cách thập phân theo ngôn ngữ của người dùng: "22.7" trong tiếng Anh, "22,7" trong tiếng Đức.

### Lưu chỉ số BMI vào hồ sơ người dùng \{#save-the-bmi-to-the-users-profile\}

Để hiển thị các flow khác nhau cho người dùng dựa trên chỉ số BMI, hãy lưu nó dưới dạng [thuộc tính tùy chỉnh](react-native-setting-user-attributes#custom-user-attributes) trong hồ sơ người dùng của họ. Trong Adapty Dashboard, [tạo một thuộc tính tùy chỉnh kiểu **Number**](segments#custom-attributes) với key là `bmi`. Sau đó hiển thị mỗi flow cho một [đối tượng](audience) được xây dựng từ thuộc tính này.

Gọi phương thức `updateProfile` trong `onDisappeared`, ngay sau dòng tính `bmi`. Truyền số đó, không phải chuỗi đã định dạng, để một phân khúc có thể so sánh BMI với ngưỡng. `onDisappeared` không thể là `async`, vì vậy hãy xử lý kết quả bằng `.catch` thay vì `await`:

```javascript showLineNumbers title="React Native"
adapty
  .updateProfile({ codableCustomAttributes: { bmi } })
  .catch((error) => {
    // handle the error
  });
```
