1. Trong Adapty, mở ứng dụng bạn đang kết nối: mỗi ứng dụng Adapty có URL thông báo riêng. Đi đến [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). Trong mục **App Store server notifications**, sao chép URL từ trường **URL for App Store server notifications**.

   <ZoomImage id="app-settings-notifications-url.webp" width="700px" alt="URL for App Store server notifications in the App Store server notifications section in Adapty" />

2. Trong [App Store Connect](https://appstoreconnect.apple.com/apps), mở trang **App Information** của ứng dụng.
3. Trong mục **App Store Server Notifications**, tìm **Production Server URL**. Nếu đã có URL ở đó, nhấn **Edit**. Nếu chưa có, nhấn **Set Up URL**.

   <ZoomImage id="asc-server-notifications-set-up-url.webp" width="700px" alt="App Store Server Notifications section on the App Information page in App Store Connect" />

4. Dán URL từ Adapty vào và nhấn **Save**.

   <ZoomImage id="asc-server-url-set-up-dialog.webp" width="700px" alt="Production Server URL dialog in App Store Connect with the URL from Adapty" />

5. Để nhận thông báo từ các bài kiểm thử sandbox của bạn trong Adapty, lặp lại bước 3 và 4 cho **Sandbox Server URL**.
