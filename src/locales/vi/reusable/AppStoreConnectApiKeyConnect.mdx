1. Để tìm **Issuer ID** và **Key ID** của team key, trong App Store Connect, hãy vào [**Users and Access** > **Integrations** > **App Store Connect API**](https://appstoreconnect.apple.com/access/integrations/api) và mở tab **Team Keys**. Nếu người khác đã tạo key và gửi cho bạn Issuer ID, Key ID và file, hãy bỏ qua bước này.

   <ZoomImage id="asc-team-keys-ids.webp" width="700px" alt="Issuer ID và Key ID của một team key trên tab Team Keys trong App Store Connect" />

2. Trong Adapty, vào [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). Trong phần **App Store Connect API key**, nhấp vào **Connect API Key**.

   <ZoomImage id="app-settings-connect-api-key.webp" width="700px" alt="Phần App Store Connect API key trong Adapty, với nút Connect API Key" />

3. Điền vào các trường:
   - **Issuer ID**: Sao chép từ tab **Team Keys** trong App Store Connect.
   - **Key ID**: Sao chép từ danh sách **Active** trên tab **Team Keys**, bên cạnh key bạn đã tải xuống.
   - **Private key (.p8 file)**: Tải lên file bạn đã tải xuống cho team key.

   <ZoomImage id="app-settings-api-key-dialog.webp" width="700px" alt="Các trường Issuer ID, Key ID và Private key (.p8 file) trong cửa sổ App Store Connect API key" />

4. Bạn có thể thay thế key đã kết nối sau này, nhưng không thể xóa nó. Hãy đảm bảo key thuộc về team App Store Connect sở hữu ứng dụng này, rồi nhấp vào **Connect**. Từ đó trở đi, bạn sẽ chọn từng **App Store Product ID** từ các sản phẩm của mình trong App Store Connect thay vì nhập thủ công.

   Adapty không xác minh key với Apple khi bạn kết nối. Một key sai sẽ thất bại mà không có thông báo gì về key đó: các sản phẩm sẽ không hiển thị trạng thái App Store và dropdown **App Store Product ID** sẽ trống. Để sửa key sai, hãy [thay thế nó](app-store-connect-api-key#replace-the-key).
