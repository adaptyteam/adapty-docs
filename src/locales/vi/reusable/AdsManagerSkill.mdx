[Ads-manager skill](https://github.com/adaptyteam/adapty-sdk-integration-skill) dạy công cụ AI coding của bạn điều khiển Apple Ads thông qua các lệnh `adapty asa`. Skill này biết thứ tự kết hợp các lệnh, biết cần đọc gì trước khi thực hiện bất kỳ thay đổi nào, và biết lệnh nào sẽ tốn tiền thật.

**Công cụ được hỗ trợ**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Skill này điều khiển Adapty CLI, vì vậy hãy cài đặt và xác thực CLI trước — xem [hướng dẫn quickstart](developer-cli-quickstart).

Trong workspace Cowork của doanh nghiệp, quản trị viên phải thêm `*.adapty.io` vào danh sách cho phép domain. Cho đến khi được thêm, skill sẽ không thể kết nối với Adapty.

Để cài đặt, chọn cách phù hợp với công cụ của bạn. Danh sách đầy đủ có trong [README của skill](https://github.com/adaptyteam/adapty-sdk-integration-skill).

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

Plugin này cũng bao gồm SDK integration skill. Cả hai được cài đặt cùng nhau.

**GitHub Copilot CLI**

```bash
gh skill install adaptyteam/adapty-sdk-integration-skill
```

**Gemini CLI**

```bash
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex hoặc công cụ khác** — sử dụng [skills CLI](https://skills.sh) (lưu ý rằng các skill được cài theo cách này sẽ không tự động cập nhật):

```bash
npx skills add adaptyteam/adapty-sdk-integration-skill
```

Ngoài ra, bạn có thể clone repo và sao chép thư mục `skills/ads-manager/` vào thư mục skills của công cụ bạn đang dùng.

Sau khi cài đặt, chạy skill trong project của bạn:

```bash
/ads-manager
```

Đọc chỉ số và chạy thử (dry run) không tốn phí. Mọi lệnh khác đều gửi yêu cầu đến Apple trong vòng vài giây, tốn tiền thật và không thể hoàn tác — skill sẽ hỏi xác nhận trước mỗi lệnh như vậy, và bạn cũng nên làm vậy.
