[Kỹ năng ads-manager](https://github.com/adaptyteam/adapty-sdk-integration-skill) hướng dẫn công cụ AI lập trình của bạn vận hành Apple Ads thông qua các lệnh `adapty asa`. Nó biết thứ tự kết hợp các lệnh, nội dung cần đọc trước khi thực hiện bất kỳ thao tác nào, và những lệnh nào sẽ tiêu tiền.

**Công cụ hỗ trợ**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Kỹ năng này điều khiển Adapty CLI, vì vậy hãy cài đặt và xác thực CLI trước — xem [hướng dẫn bắt đầu nhanh](developer-cli-quickstart). Các lệnh `adapty asa` có trong **Adapty CLI 0.4.0 trở lên**; trên phiên bản cũ hơn, các lệnh này không tồn tại. Kiểm tra bằng `adapty asa whoami`, lệnh này cũng cho biết tài khoản Apple Ads đã được kết nối chưa và công ty có đăng ký Ads Manager đang hoạt động hay không.

Claude Cowork chạy CLI trong một sandbox chặn mọi domain nằm ngoài danh sách cho phép. Hãy cho phép các domain của Adapty trước khi cài đặt kỹ năng ở đó — xem [Chạy CLI trong Cowork](developer-cli-quickstart#run-the-cli-in-cowork).

Để cài đặt, chọn dạng phù hợp với công cụ của bạn. Danh sách đầy đủ có trong [README của kỹ năng](https://github.com/adaptyteam/adapty-sdk-integration-skill).

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

Plugin này cũng chứa kỹ năng tích hợp SDK. Cả hai được cài đặt cùng nhau.

**GitHub Copilot CLI**

```bash
git clone https://github.com/adaptyteam/adapty-sdk-integration-skill.git
cp -r adapty-sdk-integration-skill/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```bash
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex hoặc bất kỳ công cụ nào khác** — sử dụng [skills CLI](https://skills.sh) (lưu ý rằng các kỹ năng được cài đặt theo cách này sẽ không tự động cập nhật):

```bash
npx skills add adaptyteam/adapty-sdk-integration-skill --all
```

`--all` cài đặt cả hai kỹ năng vào mọi agent mà nó phát hiện được. Chỉ cài kỹ năng này, dùng `--skill ads-manager`.

Ngoài ra, bạn có thể clone repo và sao chép các thư mục trong `skills/` vào thư mục kỹ năng của công cụ — hoặc chỉ `skills/ads-manager/` nếu bạn chỉ muốn kỹ năng này.

Sau khi cài đặt, chạy kỹ năng trong dự án của bạn:

```bash
/ads-manager
```

Đọc chỉ số và dry run không tốn phí. Mọi lệnh khác đều kết nối với Apple trong vài giây, tiêu tiền thật, và không thể hoàn tác — kỹ năng sẽ hỏi trước mỗi lệnh như vậy, và bạn cũng nên làm vậy.
