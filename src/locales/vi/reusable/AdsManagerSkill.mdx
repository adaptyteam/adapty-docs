[Kỹ năng ads-manager](https://github.com/adaptyteam/adapty-sdk-integration-skill) giúp công cụ AI của bạn vận hành Apple Ads thông qua các lệnh `adapty asa`. Nó biết thứ tự kết hợp các lệnh, những gì cần đọc trước khi thực hiện bất kỳ thay đổi nào, và những lệnh nào tiêu tốn tiền thật.

**Công cụ được hỗ trợ**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Kỹ năng này điều khiển Adapty CLI, vì vậy hãy cài đặt và xác thực CLI trước — xem [hướng dẫn quickstart](developer-cli-quickstart). Các lệnh `adapty asa` có trong **Adapty CLI 0.4.0 trở lên**; trên phiên bản cũ hơn, chúng không tồn tại. Kiểm tra bằng `adapty asa whoami`, lệnh này cũng cho biết tài khoản Apple Ads đã được kết nối chưa và công ty có đang đăng ký Ads Manager không.

Trong workspace Cowork của doanh nghiệp, quản trị viên phải thêm cả `adapty.io` và `*.adapty.io` vào danh sách cho phép tên miền. Hãy liệt kê cả hai: wildcard không bao gồm apex domain trong hầu hết các triển khai danh sách cho phép, và apex chính là nơi lưu trữ tài liệu mà kỹ năng cần đọc. Cho đến khi cả hai được cho phép, kỹ năng sẽ không thể kết nối đến Adapty.

Để cài đặt, chọn dạng phù hợp với công cụ của bạn. Danh sách đầy đủ có trong [README của kỹ năng](https://github.com/adaptyteam/adapty-sdk-integration-skill).

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

Plugin này cũng bao gồm kỹ năng tích hợp SDK. Cả hai được cài đặt cùng nhau.

**GitHub Copilot CLI**

```bash
git clone https://github.com/adaptyteam/adapty-sdk-integration-skill.git
cp -r adapty-sdk-integration-skill/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```bash
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex hoặc công cụ khác** — sử dụng [skills CLI](https://skills.sh) (lưu ý rằng các kỹ năng cài theo cách này không tự cập nhật):

```bash
npx skills add adaptyteam/adapty-sdk-integration-skill --all
```

`--all` cài đặt cả hai kỹ năng vào mọi agent được phát hiện. Để chỉ cài kỹ năng này, dùng `--skill ads-manager`.

Ngoài ra, bạn có thể clone repo và sao chép các thư mục trong `skills/` vào thư mục kỹ năng của công cụ — hoặc chỉ `skills/ads-manager/` nếu bạn chỉ muốn kỹ năng này.

Sau khi cài đặt, chạy kỹ năng trong dự án của bạn:

```bash
/ads-manager
```

Đọc số liệu và chạy thử (dry run) không tốn chi phí. Mọi lệnh khác đều tiếp cận Apple trong vài giây, tiêu tốn tiền thật và không thể hoàn tác — kỹ năng sẽ hỏi xác nhận trước mỗi lệnh, và bạn cũng nên làm vậy.
