[Skill adapty-sdk-integration](https://github.com/adaptyteam/adapty-sdk-integration-skill) tự động hóa toàn bộ quá trình tích hợp Adapty: cấu hình dashboard, cài đặt SDK, paywall và xác minh từng bước. Skill tự động nhận diện nền tảng của bạn và tải tài liệu Adapty phù hợp ở mỗi giai đoạn.

**Công cụ được hỗ trợ**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Để cài đặt, chọn lệnh phù hợp với công cụ của bạn. Danh sách đầy đủ có trong [README của skill](https://github.com/adaptyteam/adapty-sdk-integration-skill).

Repository chứa hai skill — `adapty-sdk-integration` và `ads-manager`, skill thứ hai chạy Apple Search Ads thông qua Adapty CLI. Mỗi lệnh dưới đây cài đặt cả hai.

**Claude Code**

```
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

**GitHub Copilot CLI**

```
git clone https://github.com/adaptyteam/adapty-sdk-integration-skill.git
cp -r adapty-sdk-integration-skill/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex hoặc công cụ khác** — dùng [skills CLI](https://skills.sh) (lưu ý rằng các skill cài theo cách này sẽ không tự động cập nhật):

```
npx skills add adaptyteam/adapty-sdk-integration-skill --all
```

`--all` cài cả hai skill vào mọi agent được phát hiện. Nếu không dùng flag này, CLI sẽ hỏi bạn muốn cài skill nào.

Ngoài ra, bạn có thể clone repo và sao chép các thư mục trong `skills/` vào thư mục skills của công cụ bạn đang dùng.

Sau khi cài đặt, chạy skill trong dự án của bạn:

```
/adapty-sdk-integration
```

Skill sẽ hỏi một vài câu hỏi cấu hình, sau đó hướng dẫn bạn qua các bước cấu hình dashboard, cài đặt SDK, paywall và xác minh.
