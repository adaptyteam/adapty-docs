[Skill adapty-integration](https://github.com/adaptyteam/adapty-skills) tự động hóa toàn bộ quá trình tích hợp Adapty: thiết lập dashboard, cài đặt SDK, paywall, và xác minh từng bước. Skill tự phát hiện nền tảng của bạn và tải tài liệu Adapty phù hợp ở mỗi bước.

**Các công cụ được hỗ trợ**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Để cài đặt, chọn cú pháp phù hợp với công cụ của bạn. Danh sách đầy đủ có trong [README của skill](https://github.com/adaptyteam/adapty-skills).

Repository chứa hai skill — `adapty-integration` và `ads-manager`, cái sau chạy Apple Search Ads thông qua Adapty CLI. Mỗi lệnh bên dưới đều cài đặt cả hai.

**Claude Code**

```
claude plugin marketplace add adaptyteam/adapty-skills
claude plugin install adapty-skills@adapty
```

**GitHub Copilot CLI**

```
git clone https://github.com/adaptyteam/adapty-skills.git
cp -r adapty-skills/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```
gemini skills install https://github.com/adaptyteam/adapty-skills
```

**OpenAI Codex hoặc bất kỳ công cụ nào khác** — sử dụng [skills CLI](https://skills.sh) (lưu ý rằng các skill được cài đặt theo cách này sẽ không tự động cập nhật):

```
npx skills add adaptyteam/adapty-skills --all
```

`--all` cài đặt cả hai skill vào mọi agent mà nó phát hiện được. Nếu không dùng cờ này, CLI sẽ hỏi bạn muốn cài skill nào trong hai skill đó.

Ngoài ra, bạn có thể clone repo và sao chép các thư mục trong `skills/` vào thư mục skills của công cụ bạn đang dùng.

Sau khi cài đặt, chạy skill trong dự án của bạn:

```
/adapty-integration
```

Skill sẽ hỏi một vài câu hỏi thiết lập, sau đó hướng dẫn bạn qua các bước thiết lập dashboard, cài đặt SDK, paywall và xác minh.
