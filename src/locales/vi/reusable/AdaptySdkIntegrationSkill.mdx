Skill `adapty-integration` tự động hóa toàn bộ quá trình tích hợp Adapty: thiết lập dashboard, cài đặt SDK, paywall và xác minh từng bước. Skill tự động nhận diện nền tảng của bạn và lấy tài liệu Adapty phù hợp ở từng bước. Nó hoạt động trong bất kỳ coding agent nào hỗ trợ skill: Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI và các agent khác.

Skill này là một phần của [plugin `adapty-skills`](https://github.com/adaptyteam/adapty-skills). Để cài đặt plugin, chạy lệnh sau trong terminal:

```bash
npx adapty skills install
```

Khởi động lại agent để tải các skill. Để xem các phương pháp cài đặt khác, xem [README của plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Claude Code không tự cập nhật plugin. Để nhận các skill mới khi chúng được phát hành, trong Claude Code, chạy `/plugin`, mở **Marketplaces**, chọn `adapty` và chọn **Enable auto-update**. Để xem lệnh cập nhật trong các agent khác, xem [README của plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Để bắt đầu tích hợp, trong agent của bạn, nhập:

```
Integrate Adapty into my app
```

Skill sẽ hỏi một vài câu hỏi thiết lập, sau đó hướng dẫn bạn qua các bước thiết lập dashboard, cài đặt SDK, paywall và xác minh.
