[Adapty-integration skill](https://github.com/adaptyteam/adapty-skills) tự động hóa toàn bộ quá trình tích hợp Adapty: cấu hình dashboard, cài đặt SDK, paywall và xác minh từng bước. Skill này tự động nhận diện nền tảng của bạn và tải tài liệu Adapty tương ứng ở mỗi bước.

**Công cụ hỗ trợ**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Để cài đặt, chọn lệnh phù hợp với công cụ bạn đang dùng. Danh sách đầy đủ có trong [README của skill](https://github.com/adaptyteam/adapty-skills).

Repository chứa hai skill — `adapty-integration` và `ads-manager`, skill thứ hai chạy Apple Search Ads thông qua Adapty CLI. Mỗi lệnh dưới đây sẽ cài cả hai.

**Claude Code**

```
claude plugin marketplace add adaptyteam/adapty-skills
claude plugin install adapty-skills@adapty
```

**GitHub Copilot CLI**

```
git clone https://github.com/adaptyteam/adapty-skills.git
cp -r adapty-sdk-integration-skill/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```
gemini skills install https://github.com/adaptyteam/adapty-skills
```

**OpenAI Codex hoặc công cụ khác** — dùng [skills CLI](https://skills.sh) (lưu ý rằng các skill cài theo cách này sẽ không tự động cập nhật):

```
npx skills add adaptyteam/adapty-skills --all
```

`--all` cài cả hai skill vào mọi agent được phát hiện. Nếu không có tùy chọn này, CLI sẽ hỏi bạn muốn cài skill nào.

Ngoài ra, bạn có thể clone repo và sao chép các thư mục trong `skills/` vào thư mục skills của công cụ bạn đang dùng.

Sau khi cài đặt, chạy skill trong project của bạn:

```
/adapty-integration
```

Skill sẽ hỏi một vài câu hỏi cấu hình, sau đó hướng dẫn bạn qua các bước: cấu hình dashboard, cài đặt SDK, paywall và xác minh.
