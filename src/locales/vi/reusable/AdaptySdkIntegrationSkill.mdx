Skill `adapty-integration` tự động hóa toàn bộ quá trình tích hợp Adapty: thiết lập dashboard, cài đặt SDK, paywall và xác minh từng giai đoạn. Skill tự phát hiện nền tảng của bạn và tải tài liệu Adapty liên quan ở từng bước. Skill hoạt động trên mọi coding agent hỗ trợ skill: Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI và nhiều agent khác.

Skill này là một phần của [Adapty plugin](manage-adapty-with-ai). Nếu bạn đã cài plugin, bạn đã có skill này rồi. Nếu agent của bạn không hiển thị skill, hãy cập nhật plugin bằng lệnh dành cho agent của bạn trong [plugin README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Để cài plugin trong một coding agent, chạy lệnh sau trong terminal:

```bash
npx adapty skills install
```

Khởi động lại agent để tải plugin. Để xem các phương thức cài đặt khác, hãy xem [plugin README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Claude Code không tự cập nhật plugin. Để nhận các skill mới khi chúng ra mắt, trong Claude Code, chạy `/plugin`, mở **Marketplaces**, chọn `adapty` và chọn **Enable auto-update**. Để xem lệnh cập nhật trên các agent khác, hãy xem [plugin README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Để bắt đầu tích hợp, hãy yêu cầu agent của bạn:

```
Integrate Adapty into my app
```

Skill sẽ hỏi một vài câu hỏi thiết lập, sau đó hướng dẫn bạn qua các bước thiết lập dashboard, cài đặt SDK, paywall và xác minh.
