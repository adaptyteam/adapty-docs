[Skill adapty-integration](https://github.com/adaptyteam/adapty-skills) tự động hóa toàn bộ quá trình tích hợp Adapty: thiết lập dashboard, cài đặt SDK, paywall, và kiểm tra từng giai đoạn. Skill tự nhận diện nền tảng của bạn và tải tài liệu Adapty liên quan ở từng bước.

**Công cụ hỗ trợ**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Để cài đặt, chọn cú pháp phù hợp với công cụ bạn đang dùng. Danh sách đầy đủ có trong [README của skill](https://github.com/adaptyteam/adapty-skills).

Repository chứa nhiều skill hơn skill này, và mỗi lệnh dưới đây sẽ cài đặt tất cả chúng.

**Claude Code**

```
claude plugin marketplace add adaptyteam/adapty-skills
claude plugin install adapty-skills@adapty
```

**GitHub Copilot CLI**

```
git clone https://github.com/adaptyteam/adapty-skills.git
cp -r adapty-skills/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```
gemini skills install https://github.com/adaptyteam/adapty-skills
```

**OpenAI Codex**

```
codex plugin marketplace add adaptyteam/adapty-skills
codex plugin add adapty-skills@adapty
```

**Bất kỳ công cụ nào khác** — dùng [skills CLI](https://skills.sh) (lưu ý rằng các skill cài theo cách này sẽ không tự cập nhật):

```
npx skills add adaptyteam/adapty-skills --all
```

`--all` cài tất cả skill vào mọi agent mà CLI phát hiện được. Nếu không có tùy chọn này, CLI sẽ hỏi bạn muốn cài cái nào.

Ngoài ra, bạn có thể clone repo và sao chép các thư mục trong `skills/` vào thư mục skills của công cụ bạn đang dùng.

Sau khi cài đặt, chạy skill trong dự án của bạn:

```
/adapty-integration
```

Skill sẽ hỏi một vài câu hỏi thiết lập, sau đó hướng dẫn bạn qua các bước: thiết lập dashboard, cài đặt SDK, paywall, và kiểm tra.
