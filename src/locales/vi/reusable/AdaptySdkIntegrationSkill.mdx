Skill `adapty-integration` tự động hóa toàn bộ quá trình tích hợp Adapty: thiết lập dashboard, cài đặt SDK, paywall, và xác minh từng giai đoạn. Skill tự nhận diện nền tảng của bạn và tải tài liệu Adapty tương ứng ở từng bước. Skill hoạt động với mọi coding agent hỗ trợ skill: Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI và các agent khác.

Skill này là một phần của [`adapty-skills` plugin](https://github.com/adaptyteam/adapty-skills). Để cài đặt plugin, chạy lệnh sau trong terminal:

```bash
npx adapty skills install
```

Khởi động lại agent để tải các skill. Các phương thức cài đặt khác, xem [plugin README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Để bắt đầu tích hợp, hãy nhập vào agent của bạn:

```
Integrate Adapty into my app
```

Skill sẽ hỏi một vài câu hỏi thiết lập, sau đó hướng dẫn bạn qua từng bước: thiết lập dashboard, cài đặt SDK, paywall và xác minh.
