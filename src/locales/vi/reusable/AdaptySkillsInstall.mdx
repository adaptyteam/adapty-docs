Nếu bạn đã cài đặt plugin Adapty, bạn đã có skill này. Nếu agent của bạn không liệt kê nó, hãy cập nhật plugin bằng lệnh dành cho agent của bạn trong [plugin README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Để cài đặt plugin trong một coding agent, chạy lệnh sau trong terminal:

```bash
npx adapty skills install
```

Khởi động lại agent để tải plugin. Để cài đặt plugin trong claude.ai hoặc Claude desktop, xem [Cài đặt plugin](manage-adapty-with-ai#install-the-plugin). Để biết các phương thức cài đặt khác, xem [plugin README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Claude Code không tự cập nhật plugin. Để nhận các skill mới khi chúng ra mắt, trong Claude Code, chạy `/plugin`, mở **Marketplaces**, chọn `adapty`, và chọn **Enable auto-update**. Để biết lệnh cập nhật trong các agent khác, xem [plugin README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).
