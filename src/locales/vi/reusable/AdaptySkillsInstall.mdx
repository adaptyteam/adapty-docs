Để cài đặt plugin, chạy lệnh sau trong terminal:

```bash
npx adapty skills install
```

Khởi động lại agent để tải các skill. Để xem các phương thức cài đặt khác, hãy xem [README của plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Claude Code không tự động cập nhật plugin. Để nhận các skill mới khi chúng được phát hành, trong Claude Code, chạy `/plugin`, mở **Marketplaces**, chọn `adapty`, rồi chọn **Enable auto-update**. Để xem lệnh cập nhật cho các agent khác, hãy xem [README của plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).
