1. Để tìm **Issuer ID** và **Key ID** của khóa, trong App Store Connect, truy cập [**Users and Access** > **Integrations** > **In-App Purchase**](https://appstoreconnect.apple.com/access/integrations/api/subs). Nếu người khác đã tạo khóa và gửi cho bạn Issuer ID, Key ID và file, hãy bỏ qua bước này.

   <ZoomImage id="asc-in-app-purchase-keys-ids.webp" width="700px" alt="Issuer ID và Key ID của khóa In-App Purchase trong App Store Connect" />

2. Trong Adapty, truy cập [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). Trong phần **In-app purchase API (StoreKit 2)**, điền vào các trường:
   - **Issuer ID**: Sao chép từ trang **In-App Purchase** trong App Store Connect.
   - **Key ID**: Sao chép từ danh sách **Active** trên trang **In-App Purchase**, bên cạnh khóa bạn đã tải xuống.
   - **Private key (.p8 file)**: Tải lên file bạn đã tải xuống.

   <ZoomImage id="app-settings-in-app-purchase-api.webp" width="700px" alt="Các trường Issuer ID, Key ID và Private key (.p8 file) trong phần In-app purchase API (StoreKit 2) trong Adapty" />

3. Adapty ký [ưu đãi](offers) bằng khóa In-App Purchase. Trong phần **App Store promotional offers**, nhập lại khóa:
   - **Subscription key ID**: Key ID từ bước 2.
   - **Subscription key (.p8 file)**: File từ bước 2.

   <ZoomImage id="app-settings-promotional-offers.webp" width="700px" alt="Các trường Subscription key ID và Subscription key (.p8 file) trong phần App Store promotional offers" />

   Nếu dùng khóa khác, hệ thống sẽ lưu mà không báo lỗi, nhưng người dùng sẽ không nhận được ưu đãi.

4. Nhấp **Save**. Adapty xác minh khóa trong phần **In-app purchase API (StoreKit 2)** với Apple trước khi lưu trang. Nếu Apple từ chối khóa, trang sẽ hiển thị "The provided field values are incorrect": [xem lại các giá trị](troubleshoot-app-store-integration#the-provided-field-values-are-incorrect-when-saving-credentials).
