## Trước khi bắt đầu \{#before-you-start\}

- Cập nhật ứng dụng lên Adapty React Native SDK 4.4 trở lên. Các phiên bản SDK cũ hơn sẽ hiển thị [nội dung dự phòng](flow-custom-elements#set-fallback-content) cho mọi phần tử tùy chỉnh.
- Thiết lập ứng dụng để [tải](react-native-get-pb-paywalls) và [hiển thị](react-native-present-paywalls) flow.
- Thiết lập native code trong ứng dụng cho các phần tử tùy chỉnh, theo [hướng dẫn React Native](react-native-flow-custom-elements#before-you-start).
- Trên iOS, thêm Lottie vào app target trong Xcode bằng Swift Package Manager, từ `https://github.com/airbnb/lottie-spm.git`. Nếu ứng dụng đã dùng `lottie-react-native`, bỏ qua bước này: package đó đã tích hợp sẵn Lottie.
- Trên Android, [thiết lập Jetpack Compose](react-native-flow-custom-elements#set-up-jetpack-compose) trong app module. Animation view trong recipe này là một composable. Thêm Compose Foundation và Lottie cho Jetpack Compose vào ứng dụng bằng Gradle, từ `androidx.compose.foundation:foundation` và `com.airbnb.android:lottie-compose`.

## 2. Thêm file animation vào ứng dụng \{#add-the-animation-file-to-your-app\}

Code native của bạn đọc file animation từ dự án iOS và Android, không phải từ assets của code JavaScript:

- **iOS**: Thêm file vào app target của bạn trong Xcode.
- **Android**: Đặt file vào `android/app/src/main/assets`, thư mục `assets` của Android app module. Giữ file ở thư mục gốc, không đặt trong thư mục con.

Tên file không có `.json` phải khớp với ID của custom element, ví dụ `streak_ring.json` cho `streak_ring`.

## 3. Tạo animation view \{#create-the-animation-view\}

Tạo một model cho streak và một view phát animation. Ứng dụng của bạn cập nhật model khi streak thay đổi. View đọc từ model, vì vậy vòng tròn sẽ hiển thị streak hiện tại khi màn hình mở ra:

<Tabs groupId="platform" queryString>
<TabItem value="ios" label="iOS (Swift)" default>

```swift showLineNumbers title="Swift"

// The streak that your app keeps up to date
@MainActor
final class StreakStore: ObservableObject {
    @Published var currentStreak = 0 // days in a row
}

struct StreakRingView: View {
    let animation: LottieAnimation
    @ObservedObject var streakStore: StreakStore

    // 7 days fill the ring: from 0 for an empty ring to 1 for a full one
    private var progress: AnimationProgressTime {
        min(AnimationProgressTime(streakStore.currentStreak) / 7, 1)
    }

    var body: some View {
        LottieView(animation: animation)
            .resizable()
            .playing(.fromProgress(0, toProgress: progress, loopMode: .playOnce))
    }
}
```

`.playing(.fromProgress(0, toProgress: progress, loopMode: .playOnce))` lấp đầy vòng một lần, từ trống đến `progress`.

</TabItem>
<TabItem value="android" label="Android (Kotlin)">

```kotlin showLineNumbers title="Kotlin"

// the streak that your app keeps up to date
class StreakStore {
    val currentStreak = MutableStateFlow(0) // days in a row
}

@Composable
fun StreakRing(animationFile: String, streakStore: StreakStore) {
    val composition by rememberLottieComposition(LottieCompositionSpec.Asset(animationFile))
    val streak by streakStore.currentStreak.collectAsState()

    // 7 days fill the ring: from 0 for an empty ring to 1 for a full one
    val progress = minOf(streak / 7f, 1f)

    LottieAnimation(
        composition = composition,
        modifier = Modifier.fillMaxSize(), // scale the animation to fit the custom element
        clipSpec = LottieClipSpec.Progress(0f, progress),
    )
}
```

`clipSpec = LottieClipSpec.Progress(0f, progress)` điền vào vòng tròn một lần, từ trống đến `progress`.

## 4. Khớp animation với phần tử tùy chỉnh \{#match-the-animation-to-the-custom-element\}

Trong [resolver toàn ứng dụng](react-native-flow-custom-elements#pass-the-resolver-to-the-sdk) của bạn, thêm một thuộc tính cho streak model. Sau đó trả về animation view cho Type `lottie_animation` và ID `streak_ring`. Các dòng được highlight cho thấy những gì cần thêm hoặc thay đổi. Nếu ứng dụng của bạn chưa có [resolver](react-native-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views) toàn ứng dụng, hãy sao chép toàn bộ đoạn code:

<Tabs groupId="platform" queryString>
<TabItem value="ios" label="iOS (Swift)" default>

```swift showLineNumbers title="Swift" {6,14-18}

struct CustomElementsResolver: AdaptyUICustomElementsResolver {
    let streakStore: StreakStore

    func view(
        forType type: String,
        id: String,
        context: AdaptyUICustomElementContext
    ) -> AnyView? {
        switch type {
        case "lottie_animation" where id == "streak_ring":
            guard let animation = LottieAnimation.named(id) else {
                return nil // no animation file: show the fallback
            }
            return AnyView(StreakRingView(animation: animation, streakStore: streakStore))
        // the other cases of your resolver
        default:
            return nil
        }
    }
}
```

Đặt case `streak_ring` trước bất kỳ case `lottie_animation` nào khác, vì Swift chỉ chạy case đầu tiên khớp. Nếu bundle ứng dụng không có file nào cho ID đó, resolver sẽ trả về `nil` và người dùng sẽ thấy fallback.

</TabItem>
<TabItem value="android" label="Android (Kotlin)">

```kotlin showLineNumbers title="Kotlin" {8,22-28}

class CustomElementsResolver(
    context: Context,
    private val streakStore: StreakStore,
) : AdaptyCustomElementsResolver {
    // the animation files in the assets folder, listed once
    private val animationFiles: Set<String> = try {
        context.assets.list("").orEmpty().toSet()
    } catch (e: IOException) {
        emptySet() // no list of files: every Lottie element shows the fallback
    }

    override fun resolve(type: String, id: String): AdaptyCustomElementContent? =
        when (type) {
            "lottie_animation" -> {
                // the ID names the animation file, such as streak_ring.json
                val file = "$id.json"
                when {
                    file !in animationFiles -> null // no file for this ID: show the fallback
                    id == "streak_ring" ->
                        AdaptyCustomElementContent.compose { StreakRing(file, streakStore) }
                    // the other animations of your resolver
                    else -> null
                }
            }
            // the other Types of your resolver
            else -> null
        }
}
```

Nếu thư mục `assets` không có file nào khớp với ID, resolver sẽ trả về `null` và người dùng sẽ thấy fallback. Nếu resolver của bạn đã [trả về view cho mọi file animation](react-native-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views), hãy trả về view đó thay vì `null` khi ID không phải là `streak_ring`. Như vậy, người dùng vẫn thấy được các animation từ những custom element `lottie_animation` khác.

</TabItem>
</Tabs>

## 5. Gửi streak từ mã JavaScript của bạn \{#5-send-the-streak-from-your-javascript-code\}

Mã JavaScript của bạn lưu trữ streak, và các native view đọc dữ liệu đó từ streak model. Để cập nhật model, hãy gửi streak sang native code thông qua một [Turbo Native Module](https://reactnative.dev/docs/turbo-native-modules-introduction). Module này có một JavaScript spec và một phần triển khai cho mỗi nền tảng.

Trong thư mục `specs` ở thư mục gốc của dự án, hãy tạo spec cho module:

```typescript showLineNumbers title="specs/NativeStreakStore.ts"

export interface Spec extends TurboModule {
  setStreak(days: number): void;
}

export default TurboModuleRegistry.getEnforcing<Spec>('NativeStreakStore');
```

Để tạo mã native cho spec, thêm `codegenConfig` vào `package.json`. Thay `com.example.app` bằng tên package của ứng dụng Android của bạn, trong `package.json` và trong phần triển khai Kotlin của module. Nếu `package.json` đã có `codegenConfig`, chỉ cần thêm `NativeStreakStore` vào object `modulesProvider`:

```json showLineNumbers title="package.json"
"codegenConfig": {
  "name": "AppSpecs",
  "type": "modules",
  "jsSrcsDir": "specs",
  "android": {
    "javaPackageName": "com.example.app.specs"
  },
  "ios": {
    "modulesProvider": {
      "NativeStreakStore": "RCTNativeStreakStore"
    }
  }
}
```

Triển khai module cho từng nền tảng:

<Tabs groupId="platform" queryString>
<TabItem value="ios" label="iOS (Swift)" default>

Trong app target của bạn trong Xcode, tạo một module Objective-C++. Module này sẽ gửi streak đến code Swift của bạn thông qua `NotificationCenter`:

```objectivec showLineNumbers title="RCTNativeStreakStore.h"
#import <AppSpecs/AppSpecs.h>

@interface RCTNativeStreakStore : NSObject <NativeStreakStoreSpec>
@end
```

```objectivec showLineNumbers title="RCTNativeStreakStore.mm"
#import "RCTNativeStreakStore.h"

@implementation RCTNativeStreakStore

+ (NSString *)moduleName {
  return @"NativeStreakStore";
}

- (std::shared_ptr<facebook::react::TurboModule>)getTurboModule:
    (const facebook::react::ObjCTurboModule::InitParams &)params {
  return std::make_shared<facebook::react::NativeStreakStoreSpecJSI>(params);
}

- (void)setStreak:(double)days {
  // the AppDelegate updates the streak model when it receives this notification
  [[NSNotificationCenter defaultCenter] postNotificationName:@"StreakDidChange"
                                                      object:nil
                                                    userInfo:@{@"days": @((NSInteger)days)}];
}

@end
```

Để cập nhật mô hình streak với mỗi streak mới, hãy quan sát `NotificationCenter` trong class `AppDelegate` của bạn. Trong phương thức `application(_:didFinishLaunchingWithOptions:)`, thêm observer sau lệnh gọi `AdaptyUI.setCustomElementsResolver`:

```swift showLineNumbers title="ios/YourApp/AppDelegate.swift"
// the streak that your JavaScript code sends through the native module
NotificationCenter.default.addObserver(
  forName: Notification.Name("StreakDidChange"),
  object: nil,
  queue: .main
) { [streakStore] notification in
  guard let days = notification.userInfo?["days"] as? Int else { return }
  MainActor.assumeIsolated { streakStore.currentStreak = days }
}
```

Để tạo mã native từ spec, chạy `pod install` trong thư mục `ios`.

</TabItem>
<TabItem value="android" label="Android (Kotlin)">

Create the module, and a package that registers it with React Native:

```kotlin showLineNumbers title="NativeStreakStoreModule.kt"
package com.example.app


class NativeStreakStoreModule(reactContext: ReactApplicationContext) :
    NativeStreakStoreSpec(reactContext) {

    override fun getName() = NAME

    override fun setStreak(days: Double) {
        val app = reactApplicationContext.applicationContext as MainApplication
        app.streakStore.currentStreak.value = days.toInt()
    }

    companion object {
        const val NAME = "NativeStreakStore"
    }
}
```

```kotlin showLineNumbers title="NativeStreakStorePackage.kt"

class NativeStreakStorePackage : BaseReactPackage() {
    override fun getModule(name: String, reactContext: ReactApplicationContext): NativeModule? =
        if (name == NativeStreakStoreModule.NAME) NativeStreakStoreModule(reactContext) else null

    override fun getReactModuleInfoProvider() = ReactModuleInfoProvider {
        mapOf(
            NativeStreakStoreModule.NAME to ReactModuleInfo(
                name = NativeStreakStoreModule.NAME,
                className = NativeStreakStoreModule.NAME,
                canOverrideExistingModule = false,
                needsEagerInit = false,
                isCxxModule = false,
                isTurboModule = true,
            )
        )
    }
}
```

Trong `MainApplication.kt`, thêm `NativeStreakStorePackage` vào danh sách packages:

```kotlin showLineNumbers title="MainApplication.kt" {2}
PackageList(this).packages.apply {
  add(NativeStreakStorePackage())
}
```
