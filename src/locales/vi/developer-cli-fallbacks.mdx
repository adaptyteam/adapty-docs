Tải xuống [file dự phòng](fallback-flows) mà ứng dụng của bạn đóng gói cho trường hợp không thể kết nối tới Adapty. Đây là file tương tự như tính năng tải xuống **Fallbacks** trên trang **Placements**.

## adapty fallbacks get

```bash
adapty fallbacks get --app <app-id> --platform ios --sdk-version 4.4.0 --output ios_fallback.json
```

| Flag | Bắt buộc | Mô tả |
|---|---|---|
| `--app` | Có | App ID (UUID) |
| `--platform` | Có | `ios` cho App Store hoặc `android` cho Google Play. Các ứng dụng macOS và visionOS dùng file `ios`. |
| `--sdk-version` | Có | Phiên bản Adapty SDK mà ứng dụng của bạn sử dụng, theo định dạng `X.Y.Z`. Với Flutter, React Native, Unity, Kotlin Multiplatform và Capacitor, truyền vào phiên bản plugin Adapty. |
| `--output` | Không | File để ghi kết quả. Các thư mục cha sẽ được tạo tự động. Nếu không chỉ định, file sẽ được xuất ra standard output. |

Mỗi file cho một cửa hàng sẽ bao gồm tất cả các placement trong app. Để triển khai cho cả hai cửa hàng, hãy chạy lệnh một lần với `--platform ios` và một lần với `--platform android`.

File chỉ bao gồm các placement đang hoạt động, vì vậy hãy publish các flow của bạn và kích hoạt placement của chúng trước khi tải file về. Tải lại file sau khi bạn thay đổi một placement hoặc nâng cấp SDK, vì file này chỉ là một snapshot.

Adapty chọn định dạng file dựa trên `--sdk-version`. SDK chỉ chấp nhận định dạng mà nó được xây dựng cho và từ chối bất kỳ file nào khác khi khởi động, không có lỗi build:

| `--sdk-version` | Định dạng file |
|---|---|
| 4.4.0 trở lên | 12 |
| 4.1.x – 4.3.x | 11 |
| 4.0.x | 10 |
| 3.12.x trở lên và các phiên bản 3.x sau | 9 |
| 3.8.x – 3.11.x | 8 |
| 3.4.x – 3.7.x | 7 |
| 3.0.x – 3.3.x | 6 |
| Dưới 3.0 | 5 |

Paywall placement có trong mọi định dạng. Flow placement chỉ có trong các file dành cho SDK 4.0 trở lên.

Với `--output`, CLI chỉ ghi file sau khi toàn bộ quá trình tải xuống thành công, vì vậy nếu chạy thất bại thì file cũ vẫn được giữ nguyên. Nếu không dùng `--output`, đầu ra chuẩn chỉ chứa nội dung file còn mọi lỗi đều được gửi tới đầu ra lỗi chuẩn. Lệnh chuyển hướng `> file` đơn thuần sẽ làm rỗng file trước khi yêu cầu bắt đầu, vì vậy hãy dùng `--output`.

Adapty xây dựng toàn bộ file trước khi phản hồi, quá trình này có thể mất vài phút đối với ứng dụng lớn. Lệnh chỉ gửi một yêu cầu duy nhất và không thử lại. Mỗi ứng dụng có thể tải file tối đa 30 lần mỗi giờ trên tất cả các token; sau đó, lệnh sẽ thất bại với lỗi giới hạn tốc độ cho biết thời gian cần chờ. Chỉ tải file cho các bản build release, không tải ở mỗi lần commit.

| Mã thoát | Ý nghĩa |
|---|---|
| `0` | File đã được ghi |
| `1` | Không thể ghi file. File trước đó không thay đổi. |
| `2` | Giá trị flag không hợp lệ |
| `3` | Không có token hoặc bị từ chối truy cập |
| `4` | Lỗi API, bao gồm giới hạn tốc độ, hoặc phản hồi không phải là file paywall dự phòng |
| `5` | Không thể kết nối đến Adapty, không có phản hồi trong vòng 300 giây, hoặc quá trình tải xuống bị gián đoạn |
