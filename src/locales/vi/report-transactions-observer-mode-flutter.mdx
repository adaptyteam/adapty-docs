Trong Observer mode, Adapty SDK không thể tự theo dõi các giao dịch mua được thực hiện qua hệ thống mua hàng hiện có của bạn. Bạn cần báo cáo các giao dịch từ cửa hàng ứng dụng. Điều quan trọng là phải thiết lập điều này **trước khi** phát hành ứng dụng để tránh sai sót trong phân tích.

Sử dụng `reportTransaction` để báo cáo từng giao dịch một cách rõ ràng để Adapty nhận biết.

:::warning
**Đừng bỏ qua bước báo cáo giao dịch!**
Nếu bạn không gọi `reportTransaction`, Adapty sẽ không nhận ra giao dịch đó, nó sẽ không xuất hiện trong analytics và sẽ không được gửi đến các integration.

:::

Nếu bạn sử dụng flow & paywall của Adapty, hãy bao gồm `variationId` khi báo cáo giao dịch. Điều này liên kết giao dịch mua hàng với flow hoặc paywall đã kích hoạt nó, đảm bảo analytics chính xác.

```dart showLineNumbers
try {
    // every time when calling transaction.finish()
    await Adapty().reportTransaction(
        transactionId: "YOUR_TRANSACTION_ID",
        variationId: "PAYWALL_VARIATION_ID", // optional
    );
} on AdaptyError catch (adaptyError) {
    // handle the error
} catch (e) {
    // handle the error
}
```

Tham số:

| Parameter     | Presence | Description                                                  |
| ------------- | -------- | ------------------------------------------------------------ |
| transactionId | required | <ul><li> Với iOS: Mã định danh của giao dịch.</li><li> Với Android: Mã định danh chuỗi `purchase.getOrderId` của giao dịch mua, trong đó purchase là một instance của lớp [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) trong thư viện billing.</li></ul> |
| variationId   | optional | Mã định danh chuỗi của biến thể. Bạn có thể lấy nó thông qua thuộc tính `variationId` của đối tượng [AdaptyPaywall](https://pub.dev/documentation/adapty_flutter/3.17.2/adapty_flutter/AdaptyPaywall-class.html). |

Trong Observer mode, Adapty SDK không thể tự theo dõi các giao dịch mua được thực hiện qua hệ thống mua hàng hiện có của bạn. Bạn cần báo cáo các giao dịch từ cửa hàng ứng dụng hoặc khôi phục chúng. Sử dụng `reportTransaction` trên cả hai nền tảng để báo cáo từng giao dịch một cách rõ ràng, và sử dụng `restorePurchases` trên Android như một bước bổ sung để đảm bảo Adapty nhận ra giao dịch đó.

:::warning
**Đừng bỏ qua việc báo cáo giao dịch và khôi phục giao dịch mua!**
Nếu bạn không gọi các phương thức này, Adapty sẽ không nhận ra giao dịch, nó sẽ không xuất hiện trong analytics và sẽ không được gửi đến các tích hợp.

:::

Nếu bạn sử dụng flow & paywall của Adapty, hãy bao gồm `variationId` khi báo cáo giao dịch. Điều này liên kết giao dịch mua với flow hoặc paywall đã kích hoạt nó, đảm bảo analytics chính xác.

```dart showLineNumbers
// every time when calling transaction.finish()
if (Platform.isAndroid) {
    try {
        await Adapty().restorePurchases();
    } on AdaptyError catch (adaptyError) {
        // handle the error
    } catch (e) {
    }
}

try {
    // every time when calling transaction.finish()
    await Adapty().reportTransaction(
        transactionId: "YOUR_TRANSACTION_ID",
        variationId: "PAYWALL_VARIATION_ID", // optional
    );
} on AdaptyError catch (adaptyError) {
    // handle the error
} catch (e) {
    // handle the error
}
```

Tham số:

| Parameter     | Presence | Description                                                  |
| ------------- | -------- | ------------------------------------------------------------ |
| transactionId | required | <ul><li> Với iOS, StoreKit 1: một đối tượng [SKPaymentTransaction](https://developer.apple.com/documentation/storekit/skpaymenttransaction).</li><li> Với iOS, StoreKit 2: đối tượng [Transaction](https://developer.apple.com/documentation/storekit/transaction).</li><li> Với Android: Chuỗi định danh (purchase.getOrderId của giao dịch mua, trong đó purchase là một instance của class [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) trong billing library.</li></ul> |
| variationId   | optional | Chuỗi định danh của biến thể. Bạn có thể lấy nó thông qua thuộc tính `variationId` của đối tượng [AdaptyPaywall](https://pub.dev/documentation/adapty_flutter/3.17.2/adapty_flutter/AdaptyPaywall-class.html). |

**Liên kết flow & paywall với giao dịch**

SDK Adapty không thể xác định nguồn gốc của các giao dịch mua, vì bạn là người xử lý chúng. Do đó, nếu bạn có ý định sử dụng flow, paywall và/hoặc A/B test trong chế độ Observer, bạn cần liên kết giao dịch đến từ cửa hàng ứng dụng của mình với flow hoặc paywall tương ứng trong code ứng dụng di động. Điều này rất quan trọng và cần thực hiện đúng trước khi phát hành ứng dụng, nếu không sẽ dẫn đến lỗi trong phân tích.

```dart
final transactionId = transaction.transactionIdentifier
final variationId = paywall.variationId

try {
  await Adapty().setVariationId('transactionId', variationId);
} on AdaptyError catch (adaptyError) {
  // handle the error
} catch (e) {
}
```
