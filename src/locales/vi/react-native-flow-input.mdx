Khi người dùng nhập vào một trường nhập liệu, trả lời một câu hỏi, hoặc bật/tắt một nút trong [flow](adapty-flow-builder), SDK sẽ chuyển giá trị đó đến ứng dụng của bạn thông qua callback analytics.

Các ứng dụng thường sử dụng dữ liệu đó để:

- **Đăng ký người dùng trên backend của riêng bạn**: Lấy địa chỉ email và tên mà người dùng đã nhập trong flow onboarding, rồi tạo tài khoản cho họ khi flow đóng lại.
- **Lưu câu trả lời và sở thích**: Theo dõi những gì người dùng đã chọn để ứng dụng có thể sử dụng sau này — ví dụ: [ghi vào hồ sơ người dùng Adapty của họ](react-native-setting-user-attributes) dưới dạng thuộc tính tùy chỉnh.
- **Tùy chỉnh các flow sau này**: Lưu câu trả lời quiz dưới dạng thuộc tính tùy chỉnh, sau đó nhắm mục tiêu vào một placement sau để mỗi phân khúc nhận được một flow khác nhau, hoặc một paywall khác nhau bên trong đó.
- **Cung cấp dữ liệu cho các nền tảng phân tích bên thứ ba**: Chuyển tiếp câu trả lời đến Amplitude, Mixpanel, hoặc bất kỳ công cụ phân tích sản phẩm nào bạn đang sử dụng.

Các input và nhóm có thể chọn sẽ tự động báo cáo giá trị của chúng. Để phân biệt các input trong code của bạn, hãy đặt cho mỗi input một **Element ID** có ý nghĩa và mỗi nhóm có thể chọn một **Group ID** trong builder.

## Nhận giá trị đầu vào \{#receive-input-values\}

Giá trị đầu vào được gửi đến cùng một handler với tất cả các sự kiện analytics khác từ một flow, với tên sự kiện là `flow_user_input`. Đăng ký `onAnalytics` cùng với các handler sự kiện flow khác của bạn:

```javascript showLineNumbers title="React Native"
const unsubscribe = view.setEventHandlers({
  onAnalytics(name, params) {
    handleFlowInput(name, params);
    return false; // keep the flow open
  },
});
```

Callback `onAnalytics` truyền tất cả các sự kiện analytics từ một flow, bao gồm cả [lượt xem màn hình](react-native-flow-screen-views).
- Tham số `name` chứa tên sự kiện. Để lọc các sự kiện nhập liệu của người dùng, hãy so sánh `name` với `flow_user_input`.
- Tham số `element_type` xác định danh mục phần tử.
- Giá trị đầu vào được lưu ở các tham số khác nhau tùy theo loại phần tử:
     - Text field, picker và toggle lưu dữ liệu nhập của người dùng trong `value`
     - Nhóm có thể chọn (selectable group) báo cáo các tùy chọn đang được chọn trong `item_ids` và `item_titles`

```javascript showLineNumbers title="React Native"
function handleFlowInput(name, params) {
  if (name !== 'flow_user_input') return;

  // The screen the input sits on. Pair it with element_id to tell apart
  // two fields that share an Element ID on different screens.
  const screenId = params.instanceId;

  switch (params.element_type) {
    case 'text_input':
    case 'email_input':
    case 'number_input':
    case 'phone_input': {
      const text = params.value;
      break;
    }
    case 'date_picker':
    case 'time_picker':
    case 'date_time_picker': {
      // Unix time in milliseconds.
      const date = new Date(params.value);
      break;
    }
    case 'single_choice': {
      const optionId = params.item_ids[0];
      break;
    }
    case 'multi_choice': {
      const optionIds = params.item_ids;
      break;
    }
    case 'toggle': {
      const isOn = params.value;
      break;
    }
  }
}
```

## Phân phối và giới hạn \{#delivery-and-limitations\}

<FlowInputLimitations />

Lưu lại từng giá trị đầu vào ngay khi handler nhận được, rồi gửi toàn bộ khi flow đóng lại. Để bắt được thời điểm đó, hãy đăng ký handler `onDisappeared` cùng với `onAnalytics`. Handler này chạy khi màn hình flow bị đóng, dù người dùng đã hoàn thành flow hay thoát ra giữa chừng.

## Các trường hợp sử dụng \{#use-cases\}

### Đăng ký người dùng trên backend của bạn \{#register-users-on-your-backend\}

Thu thập các giá trị khi chúng xuất hiện và gửi tất cả một lần khi flow đóng lại, để một request mang đầy đủ thông tin trả lời.

Flow sẽ biến mất dù người dùng hoàn thành hay bỏ dở giữa chừng. Hãy kiểm tra các trường bắt buộc trước khi gọi backend của bạn.

Flow không thể hiển thị lỗi từ backend. Giá trị trả về của handler chỉ đóng view flow, và SDK không có phương thức nào gửi dữ liệu vào một flow đang chạy. Nếu việc đăng ký thất bại, chẳng hạn vì email đã được sử dụng, hãy hiển thị lỗi đó trong giao diện của bạn sau khi flow đóng lại.

```javascript showLineNumbers title="React Native"
const flowAnswers = {};

const unsubscribe = view.setEventHandlers({
  onAnalytics(name, params) {
    if (name === 'flow_user_input' && typeof params.value === 'string') {
      flowAnswers[params.element_id] = params.value;
    }
    return false;
  },
  onDisappeared() {
    if (flowAnswers.email) {
      // Send flowAnswers to your backend here to create the account.
    }
    return false;
  },
});
```

### Làm phong phú hồ sơ người dùng với dữ liệu \{#enrich-user-profiles-with-data\}

Để liên kết những gì người dùng đã nhập với hồ sơ của họ và tránh hỏi lại cùng một thông tin hai lần, hãy [cập nhật hồ sơ người dùng](react-native-setting-user-attributes) khi các giá trị được nhập vào.

Ví dụ: nếu flow của bạn có một ô nhập văn bản với Element ID là `name` và một ô nhập email với Element ID là `email`:

```javascript showLineNumbers title="React Native"
function handleFlowInput(name, params) {
  if (name !== 'flow_user_input') return;
  if (typeof params.value !== 'string') return;

  const profileParams = {};

  switch (params.element_id) {
    case 'name':
      profileParams.firstName = params.value;
      break;
    case 'email':
      profileParams.email = params.value;
      break;
    default:
      return;
  }

  adapty.updateProfile(profileParams).catch(error => {
    // handle the error
  });
}
```

### Tùy chỉnh flow được hiển thị sau \{#customize-flows-shown-later\}

Câu trả lời trong quiz cũng có thể quyết định nội dung người dùng thấy ở một [placement](placements) khác — một flow khác, hoặc một paywall khác trong đó.

Ví dụ: hỏi người dùng về kinh nghiệm tập thể thao trong onboarding flow, rồi hiển thị cho mỗi nhóm flow riêng với sản phẩm và nội dung khác nhau.

1. Thêm [quiz](onboarding-quizzes) vào flow của bạn. Đặt Group ID của [selectable group](flow-selectable-elements) là `experience`, và đặt Element ID có ý nghĩa cho mỗi lựa chọn.
2. Xử lý các câu trả lời và [đặt custom attribute](react-native-setting-user-attributes) cho người dùng.

```javascript showLineNumbers title="React Native"
function handleFlowInput(name, params) {
  if (name !== 'flow_user_input') return;
  if (params.element_id !== 'experience') return;

  adapty
    .updateProfile({
      // Set the custom attribute 'experience' to the option the user selected
      // (beginner, amateur, or pro).
      codableCustomAttributes: { experience: params.item_ids[0] },
    })
    .catch(error => {
      // handle the error
    });
}
```

3. [Tạo một phân khúc](segments) cho mỗi giá trị thuộc tính tùy chỉnh.
4. Tạo một [placement](placements) và thêm một [đối tượng](audience) cho mỗi phân khúc.
5. [Hiển thị flow](react-native-present-paywalls) cho placement đó trong ứng dụng của bạn.
