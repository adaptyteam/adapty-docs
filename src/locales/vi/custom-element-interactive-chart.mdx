Theo công thức này để hiển thị biểu đồ cân nặng dự kiến của từng người dùng trong một paywall flow. Người dùng nhập cân nặng hiện tại và mục tiêu trong một onboarding flow. Ứng dụng của bạn thu thập cả hai giá trị. Biểu đồ hiển thị tiến trình hàng tuần mà người dùng có thể kỳ vọng với ứng dụng của bạn, từ giá trị này đến giá trị kia. Ứng dụng của bạn render biểu đồ dưới dạng native view trong một [custom element](flow-custom-elements). View này sử dụng Swift Charts.

## 3. Lưu cân nặng hiện tại và mục tiêu trong ứng dụng \{#3-save-the-current-and-goal-weight-in-your-app\}

Thu thập cân nặng hiện tại và mục tiêu từ các sự kiện `flow_user_input` của onboarding flow, như trong [Xử lý dữ liệu từ flow](ios-flow-input). Để biết người dùng đã đến màn hình cuối, hãy theo dõi sự kiện `flow_screen_showed` có `is_last_screen` được đặt thành `true`. Khi onboarding flow đóng lại sau màn hình đó, truyền cả hai giá trị cân nặng vào `showWeightPaywall` — hàm dùng để [mở paywall flow kèm biểu đồ](#5-match-the-chart-to-the-custom-element).

Đoạn code sau đây dành cho UIKit. Một view controller đóng vai trò là delegate của cả hai flow. Để thêm các phương thức mua hàng và khôi phục mà mọi `AdaptyFlowControllerDelegate` đều implement, hãy xem [Hiển thị flow và paywall trong UIKit](ios-present-paywalls#present-flows-and-paywalls-in-uikit).

```swift showLineNumbers title="Swift"
private var enteredWeights: [String: String] = [:]
private var reachedLastScreen = false

func flowController(
    _ controller: AdaptyFlowController,
    didReceiveAnalyticEvent name: String,
    params: [String: any Sendable]
) {
    if name == "flow_screen_showed", params["is_last_screen"] as? Bool == true {
        reachedLastScreen = true
        return
    }
    guard name == "flow_user_input",
          let elementId = params["element_id"] as? String,
          let value = params["value"] as? String
    else { return }

    enteredWeights[elementId] = value
}

func flowControllerDidDisappear(_ controller: AdaptyFlowController) {
    // This delegate receives events from both flows. Reset the entered
    // weights whenever a flow disappears, so that the paywall doesn't open
    // again when the user closes it.
    let weights = enteredWeights
    let finished = reachedLastScreen
    enteredWeights.removeAll()
    reachedLastScreen = false

    // Number inputs send their values as strings
    guard finished,
          let currentWeight = weights["weight"].flatMap({ Double($0) }),
          let goalWeight = weights["goal_weight"].flatMap({ Double($0) })
    else { return }

    Task {
        await showWeightPaywall(currentWeight: currentWeight, goalWeight: goalWeight)
    }
}
```

Trong SwiftUI, hãy sử dụng các closure `didReceiveAnalyticEvent` và `didDisappear` của modifier `.flow` thay vì các phương thức delegate. Hiển thị paywall flow bằng modifier `.flow` thứ hai.

## 4. Tạo chart view \{#4-create-the-chart-view\}

Tạo một model cho kế hoạch cân nặng, và một view chứa biểu đồ. Kế hoạch có một mục mỗi tuần, từ cân nặng hiện tại đến cân nặng mục tiêu. Khi người dùng kéo dọc theo biểu đồ, view sẽ đánh dấu tuần tại điểm chạm và hiển thị cân nặng dự kiến cho tuần đó:

```swift showLineNumbers title="Swift"

struct WeightPlan {
    let entries: [WeightEntry]

    // One entry per week, from the current weight to the goal weight
    init(currentWeight: Double, goalWeight: Double) {
        let weeklyChange = 0.5 // kg per week
        let startDate = Date.now
        let weeks = Int((abs(goalWeight - currentWeight) / weeklyChange).rounded(.up))
        let step = goalWeight < currentWeight ? -weeklyChange : weeklyChange
        entries = (0...weeks).map { week in
            WeightEntry(
                date: startDate.addingTimeInterval(Double(week) * 7 * 24 * 60 * 60),
                kilograms: week == weeks ? goalWeight : currentWeight + step * Double(week)
            )
        }
    }
}

struct WeightEntry: Identifiable {
    let date: Date
    let kilograms: Double
    var id: Date { date }
}

@available(iOS 16.0, *) // Swift Charts needs iOS 16
struct WeightGoalChart: View {
    let entries: [WeightEntry]
    @State private var selectedDate: Date?

    // The entry closest to the date that the user drags to
    private var selectedEntry: WeightEntry? {
        guard let selectedDate else { return nil }
        return entries.min {
            abs($0.date.timeIntervalSince(selectedDate)) < abs($1.date.timeIntervalSince(selectedDate))
        }
    }

    var body: some View {
        if #available(iOS 17.0, *) {
            chart.chartXSelection(value: $selectedDate)
        } else {
            chart // iOS 16: no drag selection
        }
    }

    private var chart: some View {
        Chart {
            ForEach(entries) { entry in
                LineMark(
                    x: .value("Date", entry.date),
                    y: .value("Weight", entry.kilograms)
                )
            }
            if let selectedEntry {
                RuleMark(x: .value("Date", selectedEntry.date))
                    .foregroundStyle(.gray.opacity(0.3))
                PointMark(
                    x: .value("Date", selectedEntry.date),
                    y: .value("Weight", selectedEntry.kilograms)
                )
                .annotation(position: .top) {
                    Text("\(selectedEntry.kilograms, specifier: "%.1f") kg")
                        .font(.caption.bold())
                }
            }
        }
        .chartYScale(domain: .automatic(includesZero: false))
    }
}
```

Tính năng kéo theo biểu đồ yêu cầu iOS 17 trở lên. Trên iOS 16, người dùng vẫn thấy đường kẻ nhưng không thể kéo dọc theo nó.

## 5. Ghép biểu đồ với custom element \{#match-the-chart-to-the-custom-element\}

Viết một [resolver](ios-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views) trả về view biểu đồ cho Type `line_chart` và ID `weight_goal`. Lưu kế hoạch cân nặng trong một thuộc tính của resolver:

```swift showLineNumbers title="Swift"

@available(iOS 16.0, *) // the chart needs iOS 16
struct WeightChartResolver: AdaptyUICustomElementsResolver {
    let plan: WeightPlan

    func view(
        forType type: String,
        id: String,
        context: AdaptyUICustomElementContext
    ) -> AnyView? {
        guard type == "line_chart", id == "weight_goal" else {
            return nil // another custom element: show the fallback
        }
        return AnyView(WeightGoalChart(entries: plan.entries))
    }
}
```

Attach the resolver to the paywall flow when you fetch its configuration. Create the resolver with the weight plan from the current and goal weight:

```swift showLineNumbers title="Swift"
func showWeightPaywall(currentWeight: Double, goalWeight: Double) async {
    let plan = WeightPlan(currentWeight: currentWeight, goalWeight: goalWeight)
    do {
        let flow = try await Adapty.getFlow(placementId: "weight_paywall")
        let flowConfiguration = try await AdaptyUI.getFlowConfiguration(
            forFlow: flow,
            customElementsResolver: WeightChartResolver(plan: plan)
        )
        let flowController = try AdaptyUI.flowController(
            with: flowConfiguration,
            delegate: self
        )
        present(flowController, animated: true)
    } catch {
        // handle the error
    }
}
```

Nếu ứng dụng của bạn đã thiết lập một [resolver toàn ứng dụng](ios-flow-custom-elements#set-an-app-wide-resolver), resolver này sẽ thay thế nó trong paywall flow. `WeightChartResolver` không trả về view nào cho bất kỳ Type và ID nào khác, vì paywall flow trong ví dụ này không có custom element nào khác. Nếu paywall flow của bạn có các custom element khác, hãy truyền resolver toàn ứng dụng vào resolver này. Sau đó gọi resolver toàn ứng dụng cho các Type và ID của chúng, như trong phần [Gắn resolver vào một flow](ios-flow-custom-elements#attach-a-resolver-to-one-flow).

## 6. Kiểm tra trên thiết bị \{#6-test-on-a-device\}

Flow & Paywall Builder không thể chạy code của ứng dụng, vì vậy canvas chỉ hiển thị fallback. Để xem trước biểu đồ:

1. [Xuất bản cả hai flow](builder-save-publish). Để xem các phiên bản đã xuất bản mới nhất thay vì phiên bản được lưu trong bộ nhớ đệm, hãy đăng ký thiết bị làm [thiết bị thử nghiệm](test-devices).
2. Chạy bản build ứng dụng có chứa resolver. Sử dụng thiết bị chạy iOS 17 trở lên. Hoàn thành flow onboarding với cân nặng hiện tại và mục tiêu. Xác minh rằng đường kẻ trên biểu đồ bắt đầu từ cân nặng hiện tại và kết thúc ở cân nặng mục tiêu.
3. Kéo dọc theo biểu đồ và xác minh rằng cân nặng dự kiến cho tuần dưới ngón tay bạn xuất hiện phía trên đường kẻ.

Để kiểm tra fallback, hãy xóa đối số `WeightChartResolver` trong `showWeightPaywall`, sau đó mở lại paywall flow.

Để tìm hiểu lý do tại sao fallback xuất hiện thay vì biểu đồ, hãy làm theo hướng dẫn trong phần [Kiểm tra trên thiết bị](ios-flow-custom-elements#test-on-a-device) của hướng dẫn iOS.
