Hãy làm theo hướng dẫn này để hiển thị tiến trình của người dùng dưới dạng hoạt ảnh Lottie — ví dụ: một vòng tròn tô dần để biểu thị streak hàng ngày của họ. Ứng dụng của bạn sẽ render hoạt ảnh này dưới dạng Lottie view gốc trong một [custom element](flow-custom-elements).

:::tip
Recipe này chỉ áp dụng cho ứng dụng iOS. Các ứng dụng được xây dựng bằng framework khác chỉ hiển thị [nội dung dự phòng](flow-custom-elements#set-fallback-content) của các phần tử tùy chỉnh. Hỗ trợ cho Android và các framework đa nền tảng sẽ sớm ra mắt.
:::

## Trước khi bắt đầu \{#before-you-start\}

- Cập nhật ứng dụng lên Adapty iOS SDK 4.4 trở lên. Các phiên bản SDK cũ hơn sẽ hiển thị [nội dung dự phòng](flow-custom-elements#set-fallback-content) cho mọi phần tử tùy chỉnh.
- Thiết lập ứng dụng để [tải](get-pb-paywalls) và [hiển thị](ios-present-paywalls) flow.
- Thêm Lottie vào ứng dụng bằng Swift Package Manager, từ `https://github.com/airbnb/lottie-spm.git`.
- Chuẩn bị một hoạt ảnh Lottie định dạng `.json`, hoặc tải file mẫu [`streak_ring.json`](https://raw.githubusercontent.com/adaptyteam/adapty-docs/refs/heads/main/Downloads/streak_ring.json). Ứng dụng sẽ phát hoạt ảnh từ đầu và dừng lại theo tỷ lệ tiến trình, ví dụ dừng giữa chừng nếu tiến trình đạt 50%. Để hiển thị đúng tiến trình, hoạt ảnh cần đáp ứng:
  - Không có tiến trình ở khung hình đầu tiên, và tiến trình đầy đủ ở khung hình cuối cùng.
  - Tốc độ đều, không có easing. Nếu hoạt ảnh bắt đầu chậm rồi tăng tốc, nó sẽ hiển thị ít hơn một nửa tiến trình ở điểm giữa.

## 1. Thêm custom element vào màn hình \{#1-add-the-custom-element-to-the-screen\}

Trong Flow & Paywall Builder, [thêm một custom element](flow-custom-elements#add-and-configure) vào màn hình flow và cấu hình cho animation:

- **Type**: `lottie_animation`.
- **ID**: `streak_ring`. Trong hướng dẫn này, ID cũng là tên của file animation.
- **Height**: Giữ nguyên chiều cao **Fixed** mặc định. Animation sẽ tự co giãn để vừa với custom element.

Bên trong custom element, thêm một [**Image**](custom-media#image) với ảnh tĩnh của chiếc nhẫn. Người dùng sẽ thấy ảnh này như là [nội dung dự phòng](flow-custom-elements#set-fallback-content) khi phiên bản ứng dụng của họ không phát được animation.

## 2. Thêm file animation vào ứng dụng \{#2-add-the-animation-file-to-your-app\}

Trong Xcode, thêm file animation vào target ứng dụng của bạn. Tên file (không có phần mở rộng `.json`) phải khớp với ID của phần tử tùy chỉnh, ví dụ `streak_ring.json` tương ứng với `streak_ring`.

## 3. Tạo animation view \{#3-create-the-animation-view\}

Tạo một model cho streak, và một SwiftUI view phát animation. App của bạn cập nhật model khi streak thay đổi. View đọc model, nên ring hiển thị streak hiện tại khi màn hình mở:

<Tabs groupId="current-os" queryString>
<TabItem value="ios" label="iOS" default>

```swift showLineNumbers title="Swift"

// The streak that your app keeps up to date
@MainActor
final class StreakStore: ObservableObject {
    @Published var currentStreak = 0 // days in a row
}

struct StreakRingView: View {
    let animation: LottieAnimation
    @ObservedObject var streakStore: StreakStore

    // 7 days fill the ring: from 0 for an empty ring to 1 for a full one
    private var progress: AnimationProgressTime {
        min(AnimationProgressTime(streakStore.currentStreak) / 7, 1)
    }

    var body: some View {
        LottieView(animation: animation)
            .resizable()
            .playing(.fromProgress(0, toProgress: progress, loopMode: .playOnce))
    }
}
```

</TabItem>
</Tabs>

`.playing(.fromProgress(0, toProgress: progress, loopMode: .playOnce))` điền vào vòng tròn một lần, từ trống đến `progress`. Nếu ứng dụng của bạn đã lưu streak trong một `ObservableObject`, hãy dùng object đó thay cho `StreakStore`.

## 4. Liên kết animation với phần tử tùy chỉnh \{#match-the-animation-to-the-custom-element\}

Trong [resolver toàn ứng dụng](ios-flow-custom-elements#set-an-app-wide-resolver) của bạn, thêm một thuộc tính cho streak model. Sau đó thêm một case trả về `StreakRingView` cho Type `lottie_animation` và ID `streak_ring`. Các dòng được tô sáng cho thấy những gì cần thêm. Nếu ứng dụng của bạn chưa có [resolver](ios-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views) toàn ứng dụng, hãy sao chép toàn bộ đoạn code:

<Tabs groupId="current-os" queryString>
<TabItem value="ios" label="iOS" default>

```swift showLineNumbers title="Swift" {2,6,14-18}

struct CustomElementsResolver: AdaptyUICustomElementsResolver {
    let streakStore: StreakStore

    func view(
        forType type: String,
        id: String,
        context: AdaptyUICustomElementContext
    ) -> AnyView? {
        switch type {
        case "lottie_animation" where id == "streak_ring":
            guard let animation = LottieAnimation.named(id) else {
                return nil // no animation file: show the fallback
            }
            return AnyView(StreakRingView(animation: animation, streakStore: streakStore))
        // the other cases of your resolver
        default:
            return nil
        }
    }
}
```

</TabItem>
</Tabs>

Đặt case `streak_ring` trước bất kỳ case `lottie_animation` nào khác, vì Swift chỉ chạy case đầu tiên khớp. Nếu bundle ứng dụng không có file nào cho ID đó, resolver trả về `nil` và người dùng sẽ thấy phần dự phòng.

Tạo resolver với streak model và đặt nó làm resolver toàn ứng dụng. Gọi `AdaptyUI.setCustomElementsResolver(_:)` một lần, chẳng hạn khi khởi động ứng dụng:

<Tabs groupId="current-os" queryString>
<TabItem value="ios" label="iOS" default>

```swift showLineNumbers title="Swift"

// the streak model that your app updates
@MainActor let streakStore = StreakStore()

// keep this instance: a resolver for one flow can reuse it
@MainActor let customElementsResolver = CustomElementsResolver(streakStore: streakStore)

AdaptyUI.setCustomElementsResolver(customElementsResolver)
```

</TabItem>
</Tabs>

## 5. Kiểm tra trên thiết bị \{#5-test-on-a-device\}

Flow & Paywall Builder không thể chạy code của ứng dụng, vì vậy canvas chỉ hiển thị fallback. Để xem trước animation:

1. [Xuất bản flow](builder-save-publish). Để xem phiên bản đã xuất bản mới nhất thay vì phiên bản được lưu trong bộ nhớ đệm, hãy đăng ký thiết bị làm [thiết bị test](test-devices).
2. Chạy một bản build của ứng dụng có bao gồm resolver. Đặt streak thành một vài giá trị, chẳng hạn như 0, 4 và 7 ngày. Mở màn hình cho từng giá trị và xác minh rằng vòng tròn được tô đầy đến mức đó.

Để test fallback, hãy xóa file animation khỏi bản build và mở lại màn hình.

Để tìm hiểu nguyên nhân tại sao paywall dự phòng hiển thị thay vì hiệu ứng animation, hãy làm theo hướng dẫn trong phần [Kiểm tra trên thiết bị](ios-flow-custom-elements#test-on-a-device) của hướng dẫn iOS.
