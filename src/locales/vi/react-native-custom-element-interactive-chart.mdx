Hãy làm theo hướng dẫn này để hiển thị biểu đồ cân nặng dự kiến của từng người dùng trong một paywall flow. Người dùng nhập cân nặng hiện tại và mục tiêu trong onboarding flow. App của bạn thu thập cả hai giá trị. Biểu đồ hiển thị tiến trình hàng tuần mà người dùng có thể kỳ vọng khi dùng app của bạn, từ giá trị này đến giá trị kia. App của bạn render biểu đồ dưới dạng native view trong một [custom element](flow-custom-elements). Trên iOS, view sử dụng Swift Charts. Trên Android, view vẽ biểu đồ mà không cần thư viện chart.

## Trước khi bắt đầu \{#before-you-start\}

- Cập nhật ứng dụng lên Adapty React Native SDK 4.4 trở lên. Các phiên bản SDK cũ hơn sẽ hiển thị [nội dung dự phòng](flow-custom-elements#set-fallback-content) cho mọi custom element.
- Thiết lập ứng dụng để [tải](react-native-get-pb-paywalls) và [hiển thị](react-native-present-paywalls) flow.
- Thiết lập code native của ứng dụng cho các custom element, như trong [hướng dẫn React Native](react-native-flow-custom-elements#before-you-start).
- Trên iOS, tính năng kéo dọc theo biểu đồ yêu cầu iOS 17 trở lên. Trên iOS 16, người dùng vẫn thấy đường kẻ nhưng không thể kéo dọc theo nó.
- Trên Android, [thiết lập Jetpack Compose](react-native-flow-custom-elements#set-up-jetpack-compose) trong module ứng dụng của bạn. Biểu đồ trong recipe này là một composable. Thêm Compose Foundation vào ứng dụng bằng Gradle, từ `androidx.compose.foundation:foundation`.

## 3. Lưu cân nặng hiện tại và mục tiêu trong ứng dụng \{#3-save-the-current-and-goal-weight-in-your-app\}

Thu thập cân nặng hiện tại và mục tiêu từ các sự kiện `flow_user_input` của onboarding flow, như hướng dẫn trong [Xử lý dữ liệu từ flow](react-native-flow-input). Để biết người dùng đã đến màn hình cuối cùng, hãy theo dõi sự kiện `flow_screen_showed` có `is_last_screen` được đặt thành `true`. Khi onboarding flow đóng lại sau màn hình đó, truyền cả hai giá trị cân nặng vào `showWeightPaywall` — hàm [mở paywall flow kèm biểu đồ](#6-send-the-weights-from-your-javascript-code).

Hàm sau đây trả về các handler `onAnalytics` và `onDisappeared` của flow onboarding:

```typescript showLineNumbers title="weightOnboardingHandlers.ts"

// the event handlers of the onboarding flow view
export function weightOnboardingHandlers(): Partial<FlowEventHandlers> {
  const enteredWeights: Record<string, string> = {};
  let reachedLastScreen = false;

  return {
    onAnalytics(name, params) {
      if (name === 'flow_screen_showed' && params.is_last_screen === true) {
        reachedLastScreen = true;
      } else if (
        name === 'flow_user_input' &&
        typeof params.element_id === 'string' &&
        typeof params.value === 'string'
      ) {
        enteredWeights[params.element_id] = params.value;
      }
      return false; // keep the flow open
    },
    onDisappeared() {
      // number inputs send their values as strings
      const currentWeight = Number.parseFloat(enteredWeights.weight ?? '');
      const goalWeight = Number.parseFloat(enteredWeights.goal_weight ?? '');
      if (reachedLastScreen && !Number.isNaN(currentWeight) && !Number.isNaN(goalWeight)) {
        showWeightPaywall(currentWeight, goalWeight);
      }
      return false;
    },
  };
}
```

Trước khi hiển thị onboarding flow, hãy truyền các handler vào view của nó:

```typescript showLineNumbers title="React Native"
const view = await createFlowView(flow);
view.setEventHandlers(weightOnboardingHandlers());
await view.present();
```

Nếu ứng dụng của bạn đã đặt `onAnalytics` hoặc `onDisappeared` cho onboarding flow, hãy thêm code của `weightOnboardingHandlers` vào các handler của bạn. Mỗi handler bạn truyền vào `setEventHandlers` sẽ thay thế bất kỳ handler cùng tên nào đã được đặt trước đó.

## 4. Tạo chart view \{#create-the-chart-view\}

Tạo model cho kế hoạch cân nặng và một view với biểu đồ. Kế hoạch có một mục nhập mỗi tuần, từ cân nặng hiện tại đến cân nặng mục tiêu. Khi người dùng kéo dọc theo biểu đồ, view sẽ đánh dấu tuần tại điểm chạm và hiển thị cân nặng dự kiến cho tuần đó:

```swift showLineNumbers title="Swift"

struct WeightPlan {
    let entries: [WeightEntry]

    // One entry per week, from the current weight to the goal weight
    init(currentWeight: Double, goalWeight: Double) {
        let weeklyChange = 0.5 // kg per week
        let startDate = Date.now
        let weeks = Int((abs(goalWeight - currentWeight) / weeklyChange).rounded(.up))
        let step = goalWeight < currentWeight ? -weeklyChange : weeklyChange
        entries = (0...weeks).map { week in
            WeightEntry(
                date: startDate.addingTimeInterval(Double(week) * 7 * 24 * 60 * 60),
                kilograms: week == weeks ? goalWeight : currentWeight + step * Double(week)
            )
        }
    }
}

struct WeightEntry: Identifiable {
    let date: Date
    let kilograms: Double
    var id: Date { date }
}

@available(iOS 16.0, *) // Swift Charts needs iOS 16
struct WeightGoalChart: View {
    let entries: [WeightEntry]
    @State private var selectedDate: Date?

    // The entry closest to the date that the user drags to
    private var selectedEntry: WeightEntry? {
        guard let selectedDate else { return nil }
        return entries.min {
            abs($0.date.timeIntervalSince(selectedDate)) < abs($1.date.timeIntervalSince(selectedDate))
        }
    }

    var body: some View {
        if #available(iOS 17.0, *) {
            chart.chartXSelection(value: $selectedDate)
        } else {
            chart // iOS 16: no drag selection
        }
    }

    private var chart: some View {
        Chart {
            ForEach(entries) { entry in
                LineMark(
                    x: .value("Date", entry.date),
                    y: .value("Weight", entry.kilograms)
                )
            }
            if let selectedEntry {
                RuleMark(x: .value("Date", selectedEntry.date))
                    .foregroundStyle(.gray.opacity(0.3))
                PointMark(
                    x: .value("Date", selectedEntry.date),
                    y: .value("Weight", selectedEntry.kilograms)
                )
                .annotation(position: .top) {
                    Text("\(selectedEntry.kilograms, specifier: "%.1f") kg")
                        .font(.caption.bold())
                }
            }
        }
        .chartYScale(domain: .automatic(includesZero: false))
    }
}
```

```kotlin showLineNumbers title="Kotlin"

class WeightPlan(currentWeight: Double, goalWeight: Double) {
    // one entry per week, from the current weight to the goal weight
    val entries: List<WeightEntry> = run {
        val weeklyChange = 0.5 // kg per week
        val start = System.currentTimeMillis()
        val weekMillis = 7L * 24 * 60 * 60 * 1000
        val weeks = ceil(abs(goalWeight - currentWeight) / weeklyChange).toInt()
        val step = if (goalWeight < currentWeight) -weeklyChange else weeklyChange
        (0..weeks).map { week ->
            val kilograms = if (week == weeks) goalWeight else currentWeight + step * week
            WeightEntry(Date(start + week * weekMillis), kilograms)
        }
    }
}

data class WeightEntry(val date: Date, val kilograms: Double)

@Composable
fun WeightGoalChart(entries: List<WeightEntry>) {
    // the week under the finger, or null when the user isn't dragging
    var selectedIndex by remember { mutableStateOf<Int?>(null) }
    val textMeasurer = rememberTextMeasurer()
    val dateFormat = remember { DateFormat.getDateInstance(DateFormat.MEDIUM) }
    val color = Color(0xFFAF52DE)
    val textStyle = TextStyle(color = Color.Gray, fontSize = 12.sp)
    val minKg = entries.minOf { it.kilograms }
    val kgRange = (entries.maxOf { it.kilograms } - minKg).coerceAtLeast(1.0)

    Canvas(
        Modifier
            .fillMaxSize()
            .pointerInput(entries) {
                // horizontal drags select a week; vertical drags scroll the screen
                detectHorizontalDragGestures(
                    onDragEnd = { selectedIndex = null },
                    onDragCancel = { selectedIndex = null },
                ) { change, _ ->
                    val index = (change.position.x / size.width * entries.lastIndex).roundToInt()
                    selectedIndex = index.coerceIn(0, entries.lastIndex)
                }
            }
    ) {
        val startDate = textMeasurer.measure(dateFormat.format(entries.first().date), textStyle)
        val endDate = textMeasurer.measure(dateFormat.format(entries.last().date), textStyle)
        val dateY = size.height - startDate.size.height
        val top = 24.dp.toPx() // room for the projected weight above the line
        val bottom = dateY - 8.dp.toPx()
        fun pointOf(index: Int) = Offset(
            x = size.width * index / entries.lastIndex.coerceAtLeast(1),
            y = bottom - ((entries[index].kilograms - minKg) / kgRange * (bottom - top)).toFloat(),
        )

        // the line from the current weight to the goal weight
        for (index in 1..entries.lastIndex) {
            drawLine(color, pointOf(index - 1), pointOf(index), strokeWidth = 2.dp.toPx())
        }
        // the dates of the first and the last week
        drawText(startDate, topLeft = Offset(0f, dateY))
        drawText(endDate, topLeft = Offset(size.width - endDate.size.width, dateY))

        // the selected week: a point, and the projected weight above it
        selectedIndex?.let { index ->
            val point = pointOf(index)
            drawCircle(color, radius = 5.dp.toPx(), center = point)
            val weight = String.format(Locale.getDefault(), "%.1f kg", entries[index].kilograms)
            val label = textMeasurer.measure(weight, textStyle.copy(color = color))
            val x = (point.x - label.size.width / 2)
                .coerceAtMost(size.width - label.size.width)
                .coerceAtLeast(0f)
            drawText(label, topLeft = Offset(x, point.y - label.size.height - 8.dp.toPx()))
        }
    }
}
```

## 6. Gửi trọng số từ mã JavaScript của bạn \{#6-send-the-weights-from-your-javascript-code\}

Đặt resolver khi khởi động ứng dụng và cập nhật store từ mã JavaScript thông qua [Turbo Native Module](https://reactnative.dev/docs/turbo-native-modules-introduction). Module này có một JavaScript spec và một phần triển khai cho mỗi nền tảng.

Trong thư mục `specs` ở thư mục gốc của dự án, tạo spec cho module:

```typescript showLineNumbers title="specs/NativeWeightPlanStore.ts"

export interface Spec extends TurboModule {
  setWeights(currentWeight: number, goalWeight: number): void;
}

export default TurboModuleRegistry.getEnforcing<Spec>('NativeWeightPlanStore');
```

Để tạo native code từ spec, hãy thêm `codegenConfig` vào `package.json`. Thay `com.example.app` bằng tên package của ứng dụng Android của bạn, trong `package.json` và trong phần triển khai Kotlin của module. Nếu `package.json` đã có `codegenConfig`, chỉ cần thêm `NativeWeightPlanStore` vào object `modulesProvider`:

```json showLineNumbers title="package.json"
"codegenConfig": {
  "name": "AppSpecs",
  "type": "modules",
  "jsSrcsDir": "specs",
  "android": {
    "javaPackageName": "com.example.app.specs"
  },
  "ios": {
    "modulesProvider": {
      "NativeWeightPlanStore": "RCTNativeWeightPlanStore"
    }
  }
}
```

Trong `AppDelegate.swift`, thêm một thuộc tính cho kế hoạch cân nặng. Trong phương thức `application(_:didFinishLaunchingWithOptions:)`, đặt resolver và theo dõi `NotificationCenter` để cập nhật kế hoạch cân nặng với mỗi cặp trọng số. Các dòng được tô sáng cho thấy những gì cần thêm. Giữ nguyên phần còn lại của lớp `AppDelegate`:

```swift showLineNumbers title="ios/YourApp/AppDelegate.swift" {1,6-7,13-26}

@main
class AppDelegate: UIResponder, UIApplicationDelegate {
  // the weight plan that your JavaScript code sends
  let weightPlanStore = WeightPlanStore()

  func application(
    _ application: UIApplication,
    didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]? = nil
  ) -> Bool {
    AdaptyUI.setCustomElementsResolver(CustomElementsResolver(weightPlanStore: weightPlanStore))
    // the weights that your JavaScript code sends through the native module
    NotificationCenter.default.addObserver(
      forName: Notification.Name("WeightsDidChange"),
      object: nil,
      queue: .main
    ) { [weightPlanStore] notification in
      guard let currentWeight = notification.userInfo?["current"] as? Double,
            let goalWeight = notification.userInfo?["goal"] as? Double
      else { return }
      MainActor.assumeIsolated {
        weightPlanStore.plan = WeightPlan(currentWeight: currentWeight, goalWeight: goalWeight)
      }
    }
    // the rest of your launch code
    return true
  }
}
```

## 7. Kiểm tra trên thiết bị \{#7-test-on-a-device\}

Flow & Paywall Builder không thể chạy code ứng dụng của bạn, nên canvas chỉ hiển thị fallback. Để xem trước biểu đồ:

1. [Xuất bản cả hai flow](builder-save-publish). Để xem các phiên bản đã xuất bản mới nhất thay vì phiên bản được lưu trong bộ nhớ đệm, hãy đăng ký thiết bị làm [thiết bị kiểm thử](test-devices).
2. Chạy bản build ứng dụng có chứa resolver. Trên iOS, hãy dùng thiết bị chạy iOS 17 trở lên. Hoàn thành flow onboarding với cân nặng hiện tại và cân nặng mục tiêu. Xác nhận rằng đường trên biểu đồ bắt đầu từ cân nặng hiện tại và kết thúc tại cân nặng mục tiêu.
3. Kéo dọc theo biểu đồ và xác nhận rằng cân nặng dự kiến cho tuần mà bạn đang chỉ vào hiển thị phía trên đường kẻ.

Để kiểm tra fallback, hãy không trả về view nào cho Type `line_chart`, rồi mở lại paywall flow.

Để tìm hiểu lý do tại sao fallback xuất hiện thay vì biểu đồ, hãy làm theo hướng dẫn trong phần [Kiểm tra trên thiết bị](react-native-flow-custom-elements#test-on-a-device) của hướng dẫn React Native.
