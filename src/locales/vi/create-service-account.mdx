Để Adapty có thể tự động hóa việc truy cập dữ liệu, bạn cần tạo một tài khoản dịch vụ trong Google Cloud Console.

1. Mở mục [**IAM & Admin** -> **Service accounts**](https://console.cloud.google.com/iam-admin/serviceaccounts) trong Google Cloud Console. Đảm bảo bạn đang sử dụng đúng project.

<Zoom>
  <img src="/assets/shared/img/17bbf45-google_cloud_create_service_account.webp"
  style={{
    border: '1px solid #727272', /* border width and color */
    width: '700px', /* image width */
    display: 'block', /* for alignment */
    margin: '0 auto' /* center alignment */
  }}
/>
</Zoom>

2. Trong cửa sổ **Service accounts**, nhấp vào nút **Create service account**.

<Zoom>
  <img src="/assets/shared/img/b93eec1-service_account_details.webp"
  style={{
    border: '1px solid #727272', /* border width and color */
    width: '700px', /* image width */
    display: 'block', /* for alignment */
    margin: '0 auto' /* center alignment */
  }}
/>
</Zoom>

3. Trong phần **Service account details** của cửa sổ **Create service account**, nhập **Service Account Name** mà bạn muốn. Chúng tôi khuyên bạn nên đặt tên có chứa "Adapty" để thể hiện mục đích của tài khoản này. **Service account ID** sẽ được tạo tự động.

4. Sao chép địa chỉ email tài khoản dịch vụ và lưu lại để dùng sau.

5. Nhấp vào nút **Create and continue**.

<Zoom>
  <img src="/assets/shared/img/e69d713-grant_access_to_project.webp"
  style={{
    border: '1px solid #727272', /* border width and color */
    width: '700px', /* image width */
    display: 'block', /* for alignment */
    margin: '0 auto' /* center alignment */
  }}
/>
</Zoom>

6. Trong danh sách thả xuống **Select a role** của mục con **Grant this service account access to project**, chọn **Pub/Sub -> Pub/Sub Admin**. Vai trò này bắt buộc để bật thông báo thời gian thực cho nhà phát triển.

<Zoom>
  <img src="/assets/shared/img/976299c-service_account_role.webp"
  style={{
    border: '1px solid #727272', /* border width and color */
    width: '700px', /* image width */
    display: 'block', /* for alignment */
    margin: '0 auto' /* center alignment */
  }}
/>
</Zoom>

7. Nhấp vào nút **Add another role**.

8. Trong danh sách thả xuống **Role** mới, chọn **Monitoring -> Monitoring Viewer**. Vai trò này cần thiết để cho phép giám sát hàng đợi thông báo.

9. Nhấp vào nút **Continue**.

<Zoom>
  <img src="/assets/shared/img/ffe8d82-grant_user_access.webp"
  style={{
    border: '1px solid #727272', /* border width and color */
    width: '700px', /* image width */
    display: 'block', /* for alignment */
    margin: '0 auto' /* center alignment */
  }}
/>
</Zoom>

10. Nhấp vào nút **Done** mà không thay đổi gì. Cửa sổ **Service accounts** sẽ mở ra.
