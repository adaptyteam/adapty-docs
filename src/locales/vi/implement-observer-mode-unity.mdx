Nếu bạn đã có cơ sở hạ tầng mua hàng riêng và chưa sẵn sàng chuyển hoàn toàn sang Adapty, bạn có thể khám phá [Observer mode](observer-vs-full-mode). Ở dạng cơ bản, Observer Mode cung cấp phân tích nâng cao và tích hợp liền mạch với các hệ thống attribution và analytics.

Nếu điều này đáp ứng nhu cầu của bạn, bạn chỉ cần:
1. Bật tính năng này khi cấu hình Adapty SDK bằng cách đặt tham số `observerMode` thành `true`. Làm theo hướng dẫn thiết lập cho [Unity](sdk-installation-unity#activate-adapty-module-of-adapty-sdk).
2. [Báo cáo giao dịch](report-transactions-observer-mode-unity) từ hệ thống thanh toán hiện có của bạn đến Adapty.

:::tip
Trong SDK v4, bạn cũng có thể hiển thị các flow và paywall do Adapty render trong Observer mode: triển khai `IAdaptyUIObserverModeResolver` và đăng ký nó với `SetObserverModeResolver` để thực hiện việc mua hoặc khôi phục bằng code của riêng bạn khi người dùng nhấn vào nút tương ứng. Xem [Hiển thị flow trong Observer mode](unity-present-flows-in-observer-mode).
:::

### Thiết lập chế độ Observer \{#observer-mode-setup\}

Bật chế độ Observer nếu bạn tự xử lý giao dịch mua và trạng thái gói đăng ký, đồng thời sử dụng Adapty để gửi sự kiện gói đăng ký và phân tích.

:::important
Khi chạy ở chế độ Observer, Adapty SDK sẽ không đóng bất kỳ giao dịch nào, vì vậy hãy đảm bảo bạn tự xử lý điều đó.
:::

:::note
Trong SDK 4.0, các interface listener tuân theo quy ước tiền tố C# I-: hãy implement `IAdaptyEventListener` thay vì `AdaptyEventListener`. Các phương thức không thay đổi. Xem [hướng dẫn migration](migration-to-unity-sdk-v4).
:::

```csharp showLineNumbers title="C#"
using UnityEngine;
using AdaptySDK;

public class AdaptyListener : MonoBehaviour, AdaptyEventListener {
    void Start() {
        DontDestroyOnLoad(this.gameObject);
        Adapty.SetEventListener(this);

        var builder = new AdaptyConfiguration.Builder("YOUR_PUBLIC_SDK_KEY")
            .SetObserverMode(true); // Enable observer mode

        Adapty.Activate(builder.Build(), (error) => {
            if (error != null) {
                // handle the error
                return;
            }
        });
    }

    public void OnLoadLatestProfile(AdaptyProfile profile) { }
    public void OnInstallationDetailsSuccess(AdaptyInstallationDetails details) { }
    public void OnInstallationDetailsFail(AdaptyError error) { }
}
```

Tham số:

| Tham số      | Mô tả                                                                                                       |
|--------------|-------------------------------------------------------------------------------------------------------------|
| observerMode | Giá trị boolean kiểm soát [Observer mode](observer-vs-full-mode). Giá trị mặc định là `false`. |

## Sử dụng flow & paywall của Adapty trong Observer Mode \{#using-adapty-paywalls-in-observer-mode\}

Nếu bạn muốn sử dụng các tính năng flow, paywall và A/B test của Adapty, bạn hoàn toàn có thể — nhưng cần thêm một số cấu hình khi ở Observer Mode. Dưới đây là những bước bạn cần thực hiện ngoài các bước đã nêu ở trên:

1. Hiển thị [paywall Remote Config](present-remote-config-paywalls-unity) như bình thường. Đối với flow & paywall được xây dựng trong Flow Builder, xem [Hiển thị flow ở chế độ Observer](unity-present-flows-in-observer-mode).
2. [Liên kết flow & paywall](report-transactions-observer-mode-unity) với các giao dịch mua hàng.
