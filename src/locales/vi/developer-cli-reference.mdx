Adapty CLI nhóm các lệnh theo chủ đề, chẳng hạn như `products` hoặc `placements`. Mỗi chủ đề có trang riêng với các lệnh, đối số, cờ và giá trị được chấp nhận. Trang này liệt kê các chủ đề, các cờ mà mỗi lệnh đều chấp nhận, và lệnh dùng để cài đặt các Adapty skill.

| Chủ đề | Lệnh | Chức năng |
|---|---|---|
| [Apps và mức độ truy cập](developer-cli-apps) | `apps`, `access-levels` | Tạo và cấu hình ứng dụng cùng các cấp gói đăng ký mà ứng dụng kiểm tra |
| [Sản phẩm và ưu đãi](developer-cli-products) | `products`, `product-offers` | Thiết lập sản phẩm, ánh xạ chúng với ID sản phẩm trên App Store và Google Play, và liên kết ưu đãi của cửa hàng với chúng |
| [Paywalls](developer-cli-paywalls) | `paywalls` | Tạo paywall và gán sản phẩm vào chúng |
| [Flows](developer-cli-flows) | `flows` | Tạo flow, viết và xác thực cấu hình builder, xuất bản chúng, và đọc các chỉ số của chúng |
| [Placements và phân khúc](developer-cli-placements) | `placements`, `segments` | Cấu hình placement, đối tượng của chúng, và các phân khúc mà đối tượng nhắm tới. Đọc chỉ số của các placement dạng flow |
| [Analytics](developer-cli-analytics) | `analytics` | Đọc biểu đồ, chuyển đổi, funnel, retention, LTV và cohort |
| [A/B test](developer-cli-ab-tests) | `ab-tests` | Tạo, bắt đầu, dừng, thay thế và lưu trữ các A/B test cho paywall và flow |
| [Attribution](developer-cli-attribution) | `attribution` | Đọc chi tiêu, lượt cài đặt, doanh thu và ROAS theo kênh và chiến dịch |
| [Ads Manager](developer-cli-ads-manager-reference) | `asa` | Chạy các chiến dịch Apple Ads, từ khóa và quy tắc tự động hóa |
| [Migrations](developer-cli-migrations) | `migrations` | Chuyển một dự án RevenueCat sang Adapty |
| [Xác thực](developer-cli-authentication) | `auth` | Đăng nhập, kiểm tra và thu hồi phiên CLI của bạn |

## Cờ toàn cục \{#global-flags\}

Các cờ này có thể dùng cho tất cả các lệnh.

| Cờ | Mô tả |
|---|---|
| `--json` | Xuất ra JSON thay vì văn bản có định dạng |
| `--help` | Hiển thị trợ giúp lệnh |

Tất cả các lệnh `list` ngoại trừ `adapty product-offers list` đều chấp nhận thêm cờ phân trang:

| Cờ | Mặc định | Mô tả |
|---|---|---|
| `--page` | `1` | Số trang |
| `--page-size` | `20` | Số mục mỗi trang (tối đa: 100) |

## Skills \{#skills\}

### adapty skills install

Cài đặt các Adapty skill vào các coding agent trên máy này.

```bash
adapty skills install
```

| Flag | Required | Description |
|---|---|---|
| `--agent` | No | Agent to install into: `claude-code`, `codex`, or `gemini-cli`. Repeat the flag for several agents. |
| `-y`, `--yes` | No | Install into every agent found without asking. Required when the CLI finds several agents and can't ask, for example with `--json`. |

CLI tìm kiếm Claude Code, Codex và Gemini CLI trên `PATH`. Nếu không tìm thấy, nó sẽ hỏi có muốn chạy `npx skills@1.7.0 add adaptyteam/adapty-skills --all --global` không — lệnh này hỗ trợ các agent khác. Khởi động lại agent để tải các skill.

Claude Code không tự cập nhật plugin. Để nhận các skill mới khi chúng được phát hành, trong Claude Code, chạy `/plugin`, mở **Marketplaces**, chọn `adapty`, rồi chọn **Enable auto-update**. Để bật tính năng này mà không cần dùng menu, thêm `"autoUpdate": true` vào mục `adapty` trong `~/.claude/settings.json`:

```json title="~/.claude/settings.json"
{
  "extraKnownMarketplaces": {
    "adapty": {
      "source": { "source": "github", "repo": "adaptyteam/adapty-skills" },
      "autoUpdate": true
    }
  }
}
```

Các skill được cài đặt qua skills CLI có thể cập nhật bằng `npx skills update`. Với Codex, xem [README của plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#codex).
