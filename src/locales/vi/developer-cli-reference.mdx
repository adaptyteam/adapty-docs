Adapty CLI nhóm các lệnh theo chủ đề, chẳng hạn như `products` hoặc `placements`. Mỗi chủ đề có trang riêng với các lệnh, tham số, cờ và giá trị được chấp nhận. Trang này liệt kê các chủ đề, các cờ mà mọi lệnh đều chấp nhận, lệnh in phiên bản CLI của bạn, và lệnh cài đặt các Adapty skill.

| Chủ đề | Lệnh | Chức năng |
|---|---|---|
| [Apps và mức độ truy cập](developer-cli-apps) | `apps`, `access-levels` | Tạo và cấu hình ứng dụng cùng các bậc gói đăng ký mà app kiểm tra |
| [Sản phẩm và ưu đãi](developer-cli-products) | `products`, `product-offers` | Thiết lập sản phẩm, ánh xạ chúng với ID sản phẩm trên App Store và Google Play, và liên kết ưu đãi từ cửa hàng vào sản phẩm |
| [Paywalls](developer-cli-paywalls) | `paywalls` | Tạo paywall, gán sản phẩm vào đó, và đọc các chỉ số của chúng |
| [Flows](developer-cli-flows) | `flows`, `fonts` | Tạo flow, viết và xác thực cấu hình builder, tải lên font tùy chỉnh, publish, khôi phục phiên bản trước, nhân bản, và đọc các chỉ số cùng phễu màn hình |
| [Placements và phân khúc](developer-cli-placements) | `placements`, `segments` | Cấu hình placement, đối tượng của chúng, và các phân khúc mà đối tượng nhắm tới. Đọc chỉ số của placement flow và paywall |
| [Analytics](developer-cli-analytics) | `analytics` | Đọc biểu đồ, tỷ lệ chuyển đổi, phễu, retention, LTV và cohort |
| [A/B test](developer-cli-ab-tests) | `ab-tests` | Tạo, bắt đầu, dừng, thay thế và lưu trữ A/B test cho paywall và flow, đọc kết quả |

| [Ads Manager](developer-cli-ads-manager-reference) | `asa` | Chạy chiến dịch Apple Ads, từ khóa và quy tắc tự động hóa |
| [Retention Messaging](developer-cli-retention-messaging) | `retention-messaging` | Kết nối Apple Retention Messaging, chạy performance test, tạo, thay đổi, kích hoạt và vô hiệu hóa retention message, đọc các chỉ số |
| [Refund Saver](developer-cli-refund-saver) | `refund-saver` | Bật/tắt Refund Saver, đặt tùy chọn hoàn tiền cho từng cửa hàng và một hồ sơ người dùng, xác minh key của từng cửa hàng, đọc yêu cầu hoàn tiền và khoản tiết kiệm |
| [Tiền tệ ảo](developer-cli-virtual-currencies) | `virtual-currencies` | Tạo tiền tệ ảo, thay đổi số tín dụng mỗi sản phẩm cấp, đọc lịch sử giao dịch tín dụng và số dư của app hoặc người dùng |

## Cờ toàn cục \{#global-flags\}

Các cờ này có thể dùng với tất cả các lệnh.

| Cờ | Mô tả |
|---|---|
| `--json` | Xuất dưới dạng JSON thay vì văn bản định dạng |
| `--help` | Hiển thị trợ giúp lệnh |

Tất cả các lệnh `list`, ngoại trừ `adapty product-offers list`, `adapty flows versions list`, và hai danh sách giao dịch của `adapty virtual-currencies`, đều hỗ trợ các cờ phân trang:

| Cờ | Mặc định | Mô tả |
|---|---|---|
| `--page` | `1` | Số trang |
| `--page-size` | `20` | Số mục mỗi trang (tối đa: 100) |

`adapty virtual-currencies transactions list` và `adapty virtual-currencies profiles transactions list` đọc một trang cho mỗi lệnh với một con trỏ: chúng nhận `--page-size` và `--cursor`, không phải `--page`. Xem [Đọc giao dịch tín dụng](developer-cli-virtual-currencies#read-credit-transactions).

## Phiên bản CLI \{#cli-version\}

### adapty version

In phiên bản hiện tại của CLI và kiểm tra xem có phiên bản mới hơn không.

```bash
adapty version
```

Lệnh này in ra cùng một dòng như `adapty --version`, sau đó truy vấn registry npm công khai để lấy phiên bản mới nhất, với giới hạn thời gian 3 giây. Khi có phiên bản mới hơn, lệnh sẽ in ra phiên bản đó kèm lệnh cập nhật, `npm i -g adapty@latest`. Khi registry không phản hồi kịp thời, lệnh sẽ in `Could not check for a newer version.` và vẫn thoát với mã 0.

Với `--json`, output có các trường sau:

| Trường | Mô tả |
|---|---|
| `installed` | Phiên bản CLI đã cài đặt |
| `latest` | Phiên bản mới nhất trên npm, hoặc `null` nếu registry không phản hồi kịp thời |
| `update_available` | `true` khi `latest` mới hơn `installed`, ngược lại là `false` |

Lệnh này yêu cầu CLI phiên bản 0.26.1 trở lên. Nếu đang dùng phiên bản cũ hơn 0.26.1, hãy chạy `adapty --version`.

## Skills \{#skills\}

### adapty skills install

Cài đặt các Adapty skill vào các coding agent trên máy này.

```bash
adapty skills install
```

| Flag | Required | Description |
|---|---|---|
| `--agent` | No | Agent to install into: `claude-code`, `codex`, or `gemini-cli`. Repeat the flag for several agents. |
| `-y`, `--yes` | No | Install into every agent found without asking. Required when the CLI finds several agents and can't ask, for example with `--json`. |

CLI tìm kiếm Claude Code, Codex và Gemini CLI trên `PATH`. Nếu không tìm thấy, nó sẽ hỏi có muốn chạy `npx skills@1.7.0 add adaptyteam/adapty-skills --all --global` không — lệnh này hỗ trợ các agent khác. Khởi động lại agent để tải các skill.

Claude Code không tự cập nhật plugin. Để nhận các skill mới khi chúng được phát hành, trong Claude Code, chạy `/plugin`, mở **Marketplaces**, chọn `adapty`, rồi chọn **Enable auto-update**. Để bật tính năng này mà không cần dùng menu, thêm `"autoUpdate": true` vào mục `adapty` trong `~/.claude/settings.json`:

```json title="~/.claude/settings.json"
{
  "extraKnownMarketplaces": {
    "adapty": {
      "source": { "source": "github", "repo": "adaptyteam/adapty-skills" },
      "autoUpdate": true
    }
  }
}
```

Các skill được cài đặt qua skills CLI có thể cập nhật bằng `npx skills update`. Với Codex, xem [README của plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#codex).
