**In-App Purchase Key** là một API key chuyên dụng được tạo trong App Store Connect để xác thực các in-app purchase bằng cách xác nhận tính hợp lệ của chúng.

:::note
Để tạo API keys cho App Store Server API, bạn phải có vai trò Admin hoặc Account Holder trong App Store Connect. Bạn cũng có thể đọc thêm về cách tạo API Keys trong [Tài liệu Apple Developer](https://developer.apple.com/documentation/appstoreserverapi/creating-api-keys-to-authorize-api-requests).
:::

1. Mở **App Store Connect**. Truy cập mục [**Users and Access** → **Integrations** → **In-App Purchase**](https://appstoreconnect.apple.com/access/integrations/api/subs).

2. Sau đó nhấn nút thêm **(+)** bên cạnh tiêu đề **Active**.

3. Trong cửa sổ **Generate In-App Purchase Key** vừa mở, nhập tên cho khóa để bạn dễ nhận biết sau này. Tên này sẽ không được sử dụng trong Adapty.

4. Nhấp vào nút **Generate**. Sau khi cửa sổ **Generate in-App Purchase Key** đóng lại, bạn sẽ thấy khóa vừa tạo xuất hiện trong danh sách **Active**.

5. Sau khi tạo API key, nhấn nút **Download In-App Purchase Key** để tải key về dưới dạng file.

6. Trong cửa sổ **Download in-App Purchase Key**, nhấn nút **Download**. File sẽ được lưu về máy tính của bạn.
   Hãy giữ file này an toàn để tải lên Adapty Dashboard sau này. Lưu ý rằng file được tạo ra chỉ có thể tải xuống một lần, vì vậy hãy đảm bảo lưu trữ an toàn cho đến khi bạn tải nó lên. File .p8 key được tạo từ **In-App Purchase section** sẽ được dùng khi [cấu hình tích hợp ban đầu của Adapty với App Store](app-store-connection-configuration#step-3-upload-in-app-purchase-key-file).

:::warning
Nếu key này bị thu hồi hoặc xóa sau đó, Adapty sẽ không thể ký ưu đãi và các ưu đãi đó sẽ ngừng áp dụng khi mua hàng. Adapty không thông báo điều này — xem [Nếu cập nhật ngừng hoạt động](store-sync#if-updates-stop-arriving).
:::
