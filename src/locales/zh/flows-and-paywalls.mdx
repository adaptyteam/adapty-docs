付费墙页面用于展示你的产品并允许用户购买。Adapty 提供两种构建方式：

- **流程与付费墙**：在 [Flow & Paywall Builder](adapty-flow-builder) 中设计界面，Adapty SDK 会在应用内原生渲染。你可以单独创建一个付费墙，也可以创建一个以付费墙结尾的完整用户引导流程。
- **自定义付费墙**：在应用代码中自行搭建界面，并将其销售的产品以[自定义付费墙](paywalls)的形式保存到 Adapty 中，由 Adapty 处理购买逻辑。

## 将流程与付费墙同自定义付费墙进行比较 \{#compare-flows--paywalls-with-custom-paywalls\}

| | 流程与付费墙 | 自定义付费墙 |
|---|---|---|
| **由谁构建 UI** | 由您在可视化无代码编辑器中完成。SDK 以原生方式渲染，无需 Web 视图。 | 由您的开发者在应用代码中完成。 |
| **如何开始** | 使用[模板](paywall-builder-templates)、空白画布或[Figma 导入](import-from-figma)。 | 使用您现有的页面和设计系统。 |
| **在看板中使用 AI 构建** | [AI 编辑器](flow-ai-editor)可根据自然语言描述或参考截图对页面进行重新排版、改写或重新布局。 | 不支持。 |
| **使用您的 AI 编码工具构建** | [flow-generator 技能](flow-generator-skill)可根据描述或截图构建流程或付费墙，并编辑文案、语言版本和页面。[flow-audit 技能](flow-audit-skill)可在发布前检查问题。 | [SDK 集成技能](adapty-sdk-integration-skill)通过 [Developer CLI](developer-cli-paywalls#adapty-paywalls-create) 创建自定义付费墙，并在应用中编写购买代码。 |
| **无需发版即可修改** | 设计、文案、页面、逻辑和产品。 | 您的代码读取的[远程配置](customize-paywall-with-remote-config)值。布局变更需要发版。 |
| **按目标受众展示不同设计** | 您构建的任何流程，均可分配至版位上的目标受众。 | 仅限用户所运行的应用版本中内置的设计。 |
| **多页面旅程** | 付费墙前的用户引导页面、[测验](onboarding-quizzes)和[分支跳转](onboarding-navigation-branching)，用户作答结果可[传递至您的应用](ios-flow-input)。 | 取决于您的代码实现。 |
| **本地化** | 在编辑器中按页面设置[语言版本](add-paywall-locale-in-adapty-paywall-builder)。 | 按语言版本配置[远程配置](add-remote-config-locale)，并支持在看板中进行 AI 翻译。 |
| **A/B 测试** | 在流程版位上对流程或付费墙进行测试。 | 在付费墙版位上对自定义付费墙进行测试。 |
| **数据分析** | [流程数据图表](flow-metrics)，收入归因至每个页面。浏览量自动追踪。 | [自定义付费墙数据图表](paywall-metrics)。您的代码负责向 Adapty 上报每次浏览。 |
| **Web 购买** | 支持，通过[网页付费墙](web-paywall)实现。 | 支持，通过[网页付费墙](web-paywall)实现。 |
| **应用体积** | 页面和图片在应用获取流程时从 Adapty 加载，新付费墙不会增加应用包体积。 | 每个页面、图片和文本字符串都打包在应用中。 |
| **版位类型** | [流程版位](create-placement)。 | [付费墙版位](create-placement)。 |
| **Adapty SDK** | v4.0 及以上版本。 | 任意版本。 |

付费墙编辑工具创建的付费墙与自定义付费墙无法共用同一个 A/B 测试，因为每种类型都需要独立的版位。如需对比，请在独立版位中[逐步推出编辑工具付费墙](flow-gradual-rollout)。

## 如何选择 \{#which-one-to-choose\}

- **选择流程和付费墙**：如果你希望在无需编写 UI 代码或发布应用版本的情况下设计、测试和修改购买页面，或者付费墙是用户引导流程的一部分。
- **选择自定义付费墙**：如果你希望用自己的代码构建页面，例如复用应用中已有的组件。

当您的应用渲染屏幕时，Adapty 中的自定义付费墙是该屏幕所销售的固定产品组合，例如按周和按月订阅方案。Adapty 会为每个付费墙统计转化率和收入，便于您比较哪种产品组合的销售效果更好。您可以在同一版位向不同目标受众展示不同的付费墙，并进行 A/B 测试相互比较。如需销售不同的产品，只需在看板中替换该版位上的付费墙，无需发布新版本应用。

两者都位于 Adapty 主菜单的 **Flows & Paywalls** 中：流程与付费墙在 **Flow & Paywall builder** 标签页，自定义付费墙在 **Custom Paywalls** 标签页。

在[旧版付费墙编辑工具](adapty-paywall-builder)中构建的付费墙仍可在 **Custom Paywalls & Legacy** 标签页中编辑，但无法在此新建付费墙。如需将为 Adapty SDK 3.x 构建的付费墙以草稿流程的形式迁移，同时保持原版本继续上线，请使用 **Move to new builder** 操作——详见[将付费墙转换为流程](convert-paywall-to-flow)。如需完整迁移（包括版位迁移和 SDK 升级），请参阅[迁移至流程](migrate-to-flows)。
