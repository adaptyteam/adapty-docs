付费墙页面用于展示你的产品并允许用户购买。Adapty 提供两种构建方式：

- **流程与付费墙**：在 [Flow & Paywall Builder](adapty-flow-builder) 中设计界面，Adapty SDK 会在应用内原生渲染。你可以单独创建一个付费墙，也可以创建一个以付费墙结尾的完整用户引导流程。
- **自定义付费墙**：在应用代码中自行搭建界面，并将其销售的产品以[自定义付费墙](paywalls)的形式保存到 Adapty 中，由 Adapty 处理购买逻辑。

## 将流程与付费墙同自定义付费墙进行比较 \{#compare-flows--paywalls-with-custom-paywalls\}

| | 流程与付费墙 | 自定义付费墙 |
|---|---|---|
| **谁来构建 UI** | 由你在可视化无代码编辑器中完成。SDK 以原生方式渲染，无需 Web 视图。 | 由你的开发者在应用代码中实现。 |
| **如何开始** | 使用[模板](paywall-builder-templates)、空白画布，或[从 Figma 导入](import-from-figma)。 | 使用你现有的页面和设计系统。 |
| **在看板中使用 AI 构建** | [AI 编辑器](flow-ai-editor)可根据自然语言描述或参考截图，对页面进行重新设计、改写文案或重新排版。 | 不支持。 |
| **使用 AI 编程工具构建** | [flow-generator 技能](flow-generator-skill)可根据描述或截图构建流程或付费墙，并编辑文案、多语言内容和页面。[flow-audit 技能](flow-audit-skill)可在发布前检查潜在问题。 | [SDK 集成技能](adapty-sdk-integration-skill)通过 [Developer CLI](developer-cli-reference#adapty-paywalls-create) 创建自定义付费墙，并在应用中编写购买代码。 |
| **无需发版即可修改** | 设计、文案、页面、逻辑和产品均可修改。 | 仅限你的代码所读取的[远程配置](customize-paywall-with-remote-config)值。布局变更需要发版。 |
| **按目标受众展示不同设计** | 你构建的任意流程，均可在版位上指定目标受众。 | 仅限用户所运行的应用版本中内置的设计。 |
| **多页面旅程** | 支持在付费墙前展示用户引导页面、[问卷](onboarding-quizzes)和[分支跳转](onboarding-navigation-branching)，并可将用户答案[传递给应用](ios-flow-input)。 | 由你的代码自行实现。 |
| **本地化** | 在编辑工具中按页面配置[多语言内容](add-paywall-locale-in-adapty-paywall-builder)。 | 使用按语言区分的[远程配置](add-remote-config-locale)，并可在看板中使用 AI 翻译。 |
| **A/B 测试** | 在流程版位上，对流程或付费墙进行 A/B 测试。 | 在付费墙版位上，对自定义付费墙进行 A/B 测试。 |
| **数据分析** | [流程数据图表](flow-metrics)，收入归因到每个页面，浏览量自动追踪。 | [自定义付费墙数据图表](paywall-metrics)，需由你的代码向 Adapty 上报每次浏览。 |
| **网页购买** | 支持，使用[网页付费墙](web-paywall)。 | 支持，使用[网页付费墙](web-paywall)。 |
| **应用体积** | 页面和图片在应用获取流程时从 Adapty 加载，新付费墙不会增加应用包体积。 | 所有页面、图片和文案均随应用包一同发布。 |
| **版位类型** | [流程版位](create-placement)。 | [付费墙版位](create-placement)。 |
| **Adapty SDK** | v4.0 或更高版本。 | 任意版本。 |

付费墙编辑工具创建的付费墙与自定义付费墙无法共用同一个 A/B 测试，因为每种类型都需要独立的版位。如需对比，请在独立版位中[逐步推出编辑工具付费墙](flow-gradual-rollout)。

## 如何选择 \{#which-one-to-choose\}

- **选择流程和付费墙**：如果你希望在无需编写 UI 代码或发布应用版本的情况下设计、测试和修改购买页面，或者付费墙是用户引导流程的一部分。
- **选择自定义付费墙**：如果你希望用自己的代码构建页面，例如复用应用中已有的组件。

当您的应用渲染屏幕时，Adapty 中的自定义付费墙是该屏幕所销售的固定产品组合，例如按周和按月订阅方案。Adapty 会为每个付费墙统计转化率和收入，便于您比较哪种产品组合的销售效果更好。您可以在同一版位向不同目标受众展示不同的付费墙，并进行 A/B 测试相互比较。如需销售不同的产品，只需在看板中替换该版位上的付费墙，无需发布新版本应用。

两者都位于 Adapty 主菜单的 **Flows & Paywalls** 中：流程与付费墙在 **Flow & Paywall builder** 标签页，自定义付费墙在 **Custom Paywalls** 标签页。

在[旧版付费墙编辑工具](adapty-paywall-builder)中构建的付费墙仍可在 **Custom Paywalls & Legacy** 标签页中编辑，但无法在此新建付费墙。如需将为 Adapty SDK 3.x 构建的付费墙以草稿流程的形式迁移，同时保持原版本继续上线，请使用 **Move to new builder** 操作——详见[将付费墙转换为流程](convert-paywall-to-flow)。如需完整迁移（包括版位迁移和 SDK 升级），请参阅[迁移至流程](migrate-to-flows)。
