<SDKv4>

在 Observer 模式下，Adapty SDK 无法自动追踪通过您现有购买系统完成的交易，您需要手动上报来自应用商店的交易记录。请务必在发布应用**之前**完成此配置，以避免分析数据出现错误。

使用 `reportTransaction` 明确上报每笔交易，以便 Adapty 识别。

:::warning

**不要跳过交易上报！**
如果您不调用 `ReportTransaction`，Adapty 将无法识别该交易，它不会出现在分析数据中，也不会同步到各集成渠道。

:::

如果您使用 Adapty 流程与付费墙，请在上报交易时包含 `variationId`。这会将购买行为关联到触发它的流程或付费墙，从而确保分析数据准确。

:::warning
请传入用户所购买 `AdaptyPaywallProduct` 的 `PaywallVariationId`，而非 `AdaptyFlow.VariationId`。流程自身的 variation ID 无法将购买行为关联到该流程。
:::

```csharp showLineNumbers
Adapty.ReportTransaction(
  "YOUR_TRANSACTION_ID", 
  "PAYWALL_VARIATION_ID", // optional
  (error) => {
  // handle the error
});
```

参数：

| 参数 | 是否必填 | 描述 |
| ------------- | -------- |------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| transactionId | 必填 | <ul><li> iOS：交易的标识符。</li><li> Android：购买的字符串标识符 `purchase.getOrderId`，其中 purchase 是计费库 [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) 类的实例。</li></ul> |
| variationId   | 选填 | 实验变体的字符串标识符。请传入用户购买的 `AdaptyPaywallProduct` 的 `PaywallVariationId`。该值与包含此产品的 `AdaptyFlowPaywall` 的 `VariationId` 相同。 |
| appleJWSTransaction | 选填 | 仅限 iOS，SDK 4.3.0 及以上版本。已签名的 StoreKit 2 交易：其验证结果的 `jwsRepresentation`，对应与 `transactionId` 相同的交易。SDK 会原样将其发送给 Adapty。Android 会忽略此参数。 |

在 iOS 上，如果您的购买系统提供了 StoreKit 2 transaction，请在 `appleJWSTransaction` 中传入其 JWS 表示。若要在不传入 variation 的情况下传递，请将 `variationId` 设为 `null`：

```csharp showLineNumbers
Adapty.ReportTransaction(
  "YOUR_TRANSACTION_ID",
  "PAYWALL_VARIATION_ID", // optional, or null
  "YOUR_JWS_REPRESENTATION", // iOS only, optional
  (error) => {
  // handle the error
});
```

在观察者模式下，Adapty SDK 无法自行追踪通过您现有购买系统完成的购买。您需要从应用商店上报或恢复交易。务必在发布应用**之前**完成此设置，以避免分析数据出现错误。

在两个平台上使用 `reportTransaction` 显式上报每笔交易，并在 Android 上额外使用 `restorePurchases`，以确保 Adapty 识别该交易。

:::warning

**不要跳过交易上报和购买恢复！**
如果不调用这些方法，Adapty 将无法识别交易，该交易不会出现在分析数据中，也不会被发送到集成中。

:::

如果你使用 Adapty 流程和付费墙，请在上报交易时附带 `PAYWALL_VARIATION_ID`。这会将购买行为关联到触发它的流程或付费墙，从而确保分析数据的准确性。

```csharp showLineNumbers
// every time when calling transasction.finish()

#if UNITY_ANDROID && !UNITY_EDITOR
  Adapty.RestorePurchases((profile, error) => {
    // handle the error
  });
#endif

Adapty.ReportTransaction(
  "YOUR_TRANSACTION_ID", 
  "PAYWALL_VARIATION_ID", // optional
  (error) => {
  // handle the error
});
```

参数：

| 参数 | 是否必填 | 描述 |
| ------------- | -------- |--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| transactionId | 必填 | <ul><li> iOS，StoreKit 1：[SKPaymentTransaction](https://developer.apple.com/documentation/storekit/skpaymenttransaction) 对象。</li><li> iOS，StoreKit 2：[Transaction](https://developer.apple.com/documentation/storekit/transaction) 对象。</li><li> Android：购买对象的字符串标识符（`purchase.getOrderId`），其中购买对象是计费库 [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) 类的实例。</li></ul> |
| variationId   | 可选 | 实验变体的字符串标识符。可通过 `AdaptyPaywall` 对象的 `variationId` 属性获取。 |

**将流程与付费墙关联到交易**

Adapty SDK 无法确定购买的来源，因为购买是由您自行处理的。因此，如果您打算在观察者模式下使用流程、付费墙和/或 A/B 测试，则需要在移动应用代码中将来自应用商店的交易与对应的流程或付费墙关联起来。在发布应用之前务必正确完成此设置，否则会导致分析数据出现错误。

```csharp 
Adapty.SetVariationForTransaction("<variationId>", "<transactionId>", (error) => { 
    if(error != null) {
        // handle the error
        return;
    }

    // successful binding
});
```

| 参数 | 是否必填 | 描述 |
| ------------------------------------------------------ | -------- |-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| transactionId                                          | 必填 | <p>iOS，StoreKit 1：[SKPaymentTransaction](https://developer.apple.com/documentation/storekit/skpaymenttransaction) 对象。</p><p>iOS，StoreKit 2：[Transaction](https://developer.apple.com/documentation/storekit/transaction) 对象。</p><p>Android：字符串标识符（purchase.getOrderId，其中 purchase 是 billing library [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) 类的实例）。</p> |
| variationId                                            | 必填 | 实验变体的字符串标识符。可通过 `AdaptyPaywall` 对象的 `variationId` 属性获取。 |
