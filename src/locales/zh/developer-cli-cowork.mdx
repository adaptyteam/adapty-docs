[Adapty 开发者 CLI](developer-cli) 可以在 Claude 应用中使用，让你直接通过对话窗口管理 Adapty 账户，而无需打开终端。Claude 在沙盒环境中运行命令，该环境只能访问白名单域名，因此在首次登录账户之前，需要在 Claude 中完成一次性配置。

:::note
Claude Cowork 和聊天现已[合并为一个 Claude](https://claude.com/resources/articles/cowork-is-now-claude)：你在 Cowork 中能做的事，现在在任何对话中都可以完成。此次合并正在按计划逐步推出。如果你的计划中仍有独立的 Cowork，请按照相同步骤操作，并在 Cowork 中开始每项任务。
:::

**所需条件：**

- Claude 应用
- Adapty 账户
- 对于企业版 Claude 工作区，需要工作区管理员的协助——请参阅[允许 Adapty 域名](#allow-the-adapty-domains)

## 添加 Adapty 插件 \{#add-the-adapty-plugin\}

Adapty 插件包含 Claude 用于安装、鉴权和驱动 CLI 的技能，其中包括用于广告管理工作的 [Apple Ads 技能](developer-cli-ads-manager-skill)。

添加插件的步骤：

1. 在 Claude 中，打开 **Settings** → **Plugins**。
2. 点击 **Add** → **Add marketplace**。
3. 选择 **Add from a repository**。
4. 在 **URL** 字段中，粘贴 `https://github.com/adaptyteam/apple-ads-cli`。
5. 点击 **Sync**。

<ZoomImage id="cowork-marketplace-url.png" width="700px" alt="Add marketplace dialog in Claude with the Adapty repository URL and the Sync button" />

Adapty 插件会显示在插件目录的 **Personal** 下。

## 将 Adapty 域名加入允许列表 \{#allow-the-adapty-domains\}

在沙盒的域名允许列表中添加 Adapty 之前，CLI 无法登录或读取你的账户信息。

请同时允许 `adapty.io` 和 `*.adapty.io`。在大多数允许列表实现中，通配符不涵盖顶级域名。CLI 本身会访问 `api.adapty.io`，而在工作过程中读取 Adapty 文档的 Agent 则会访问顶级域名。

Claude 在对话开始时应用这些设置。如果你在对话过程中更改了访问模式或添加了域名，该对话仍会保留其启动时的设置——请开启新对话。

### 个人账户 \{#personal-accounts\}

您可以自行设置白名单：

1. 在 Claude 中，打开 **Settings** → **Capabilities**。
2. 开启 **Code execution and file creation**。**Allow network egress** 区块在此之前会保持隐藏。
3. 开启 **Allow network egress**。
4. 在 **Domain allowlist** 中，选择 **Package managers only**。
5. 在 **Additional allowed domains** 下，添加 `adapty.io`，然后添加 `*.adapty.io`。

<ZoomImage id="cowork-domain-allowlist.png" width="700px" alt="Claude 中的 Allow network egress 设置，附加允许域名列表中包含 adapty.io 和 *.adapty.io" />

另一种访问模式 **All domains**，允许沙盒访问任何站点。选择该模式后，无需添加 Adapty 域名。

### 企业工作区 \{#corporate-workspaces\}

由管理员控制许可名单。请让他们为工作区添加这两个域名。

## 安装并授权 CLI \{#install-and-authorize-the-cli\}

每次对话都在一台全新的机器上开始：没有 CLI、没有令牌，也没有配置会从上一次对话中延续下来，因此安装和登录步骤需要在每次对话开始时重复执行。

安装并授权 CLI 的步骤如下：

1. 在 Claude 中开启一个新对话。
2. 让 Claude 安装 Adapty CLI——例如，输入"Install the Adapty CLI"。Claude 可能会请求权限以打开安装链接——允许即可。

   <ZoomImage id="cowork-cli-installed.png" width="700px" alt="A Claude chat where Claude confirms the Adapty CLI is installed" />

3. 安装完成后，Claude 会提示你登录 Adapty——同意后，它会发布一个包含设备码的授权链接。该设备码有效期约为 15 分钟。

   <ZoomImage id="cowork-auth-link.png" width="700px" alt="A Claude chat where Claude posts the Adapty authorization link and device code" />

4. 打开该链接，浏览器会跳转到 Adapty CLI 授权页面。
5. 确认页面上显示的验证码与 Claude 给出的一致，然后点击 **Authorize**。如果两者不匹配，请点击 **Deny** 并让 Claude 重新生成链接。

   <ZoomImage id="cowork-authorize-page.png" width="700px" alt="浏览器中显示设备码和授权按钮的 Adapty CLI 授权页面" />

6. 返回聊天，告知 Claude 你已完成授权——例如，输入"done"。Claude 会验证登录信息并显示你的账号详情。

CLI 已准备就绪。如需通过聊天设置应用、产品和付费墙，请参阅[快速入门指南](developer-cli-quickstart)。

## 故障排查 \{#troubleshooting\}

| 问题 | 解决方法 |
|---------|---------------|
| 点击 **Sync** 后技能未出现 | 确认仓库 URL 为 `https://github.com/adaptyteam/apple-ads-cli`，然后再次点击 **Sync**。 |
| 安装或授权时出现网络错误 | 将 `adapty.io` 和 `*.adapty.io` 添加到[域名白名单](#allow-the-adapty-domains)。设置在新对话开始时生效，添加后请重新开启一个对话。 |
| 授权链接无法打开或被拒绝 | 验证码约 15 分钟后过期，请让 Claude 重新生成链接。 |
| 浏览器中的代码与聊天中的代码不匹配 | 不要点击 **Authorize**，请让 Claude 重新生成链接并重新开始。 |
