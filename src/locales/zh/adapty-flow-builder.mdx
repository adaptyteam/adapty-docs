:::important
流程在触达用户之前，需要更新的 SDK 版本以及专属版位：

- **Adapty SDK v4.0 或更高版本**：低版本 SDK 无法渲染流程。
- **独立的流程版位**：流程和付费墙属于不同的内容类型，因此各自使用独立的版位类型。流程无法放在付费墙版位上，新的流程版位也不能复用付费墙版位的 ID——版位 ID 在整个应用中是唯一的。参阅[创建版位](create-placement)。
:::

在 Adapty 中，你可以在可视化无代码编辑器中创建流程。

- **创建付费墙、用户引导等内容**：创建动态的单屏或多屏流程。
- **完整的流程模板**：从[专业设计的模板](paywall-builder-templates)开始构建流程。
- **导入 Figma 设计**：[从 Figma 导入框架](import-from-figma)，将其转化为可编辑的流程。
- **灵活设计**：可视化还原复杂页面，无需编写代码。
- <Inline id="sparkle.svg" alt="AI Editor" /> **[AI 编辑器](flow-ai-editor)**：用日常语言描述你想做的改动，效果立即呈现在屏幕上——重新调整样式、修改文案或重新排版，无需手动调整任何属性。
- **原生渲染**：Adapty SDK 以原生方式渲染流程，不使用 WebView，确保流畅的用户体验。
- **无需重新发布即可更新**：随时修改文案、设计或逻辑，更新无需发布新版本即可触达用户。

## 你可以构建什么 \{#what-you-can-build\}

你可以在应用的任何位置放置流程——首次启动时、高级功能入口前，或某个关键操作完成后。每个页面都可以完全自定义，让每个流程都契合当下的使用场景。以下是一些最常见的用例：

- **应用用户引导**：展示应用功能，通过问答收集用户偏好，并根据答案个性化推荐内容和行动号召。参见[搭建个性化用户引导流程](onboarding-flow-tutorial)。
- **付费墙页面**：在高级内容前设置功能门槛，展示产品的功能列表、定价及购买按钮。参见[创建基础付费墙页面](basic-paywall-screen)。
- **标签页分级方案**：以标签页形式并排展示订阅层级，用户切换时同步更新功能列表和行动号召。参见[创建带标签页的付费墙](paywall-with-tabs)和[按产品展示不同功能](paywall-features-per-product)。
- **可展开的方案列表**：突出显示一个推荐方案，用户想要对比时再通过底部弹窗展示完整产品列表。参见[在底部弹窗中展示所有方案](show-plans-bottom-sheet)。
- **调查与测验**：收集用户目标、偏好或使用经验，然后根据答案分支跳转流程、定制后续页面，或[在应用中处理这些数据](ios-flow-input)。参见[输入框与表单](builder-inputs-and-forms)。
- **社会认同**：在用户做出购买决策前，通过评论卡片、评分和用户推荐建立信任感。参见[评价与推荐](builder-reviews-and-testimonials)。
- **促销与赢回页面**：运营限时折扣、免费试用活动，或通过赢回页面重新激活流失用户。

以上只是最常见的几种模式。流程由灵活、可复用的元素构成，你可以将它们组合成产品所需的几乎任何页面——并在产品迭代时随时调整。

## 创建流程 \{#create-a-flow\}

[创建新流程](paywall-builder-templates)，可从自定义设计的图库模板、空白画布或[你的 Figma 设计](import-from-figma)开始。然后利用以下功能进行自定义：

- **[元素库](builder-elements)** — 文本、媒体、按钮、表单及其他内容的预置模块。
- **[操作](onboarding-actions)** — 在屏幕间导航、打开 URL、执行购买等。
- **[变量](onboarding-variables)** — 在文本中使用变量值，或用于触发基于条件的流程逻辑。
- **[条件导航](onboarding-navigation-branching)** — 根据用户输入分支流程。
- **[测验与输入](builder-inputs-and-forms)** — 收集用户输入，在流程中使用，或传递给您的应用。
- <Inline id="sparkle.svg" alt="AI Editor" /> **[AI 编辑器](flow-ai-editor)** — 用自然语言描述修改内容，AI 会将其应用到当前屏幕。
- **[深色模式](paywall-dark-mode)** — 为元素设置样式以匹配设备主题。
- **[本地化](add-flow-remote-config-locale)** — 支持手动或 AI 辅助。

[保存并发布](builder-save-publish)草稿，然后将其关联到一个[流程版位](create-placement)——使用一个新版位，且版位 ID 不得与应用中其他版位重复。流程版位可以向不同的[目标受众](add-audience-paywall-ab-test)提供不同的流程。

流程上线后，可在其[数据图表](flow-metrics)页面追踪浏览量、完成率和营收情况。Analytics 页面上的大多数数据图表（从 MRR 到流失率）也支持[按单个流程筛选](filter-flows#filter-analytics-by-flow)，甚至可细化到流程中的某个具体页面。
