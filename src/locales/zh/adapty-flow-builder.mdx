:::important
流程在触达用户之前，需要更新版本的 SDK 以及专属的版位：

- **Adapty SDK v4.0 或更高版本**：低版本 SDK 无法渲染流程。
- **独立的流程版位**：流程和付费墙属于不同的内容类型，因此各自使用独立的版位类型。流程无法放在付费墙版位上，新的流程版位也不能复用付费墙版位的 ID——版位 ID 在整个应用中是唯一的。参阅[创建版位](create-placement)。
:::

在 Adapty 中，你可以在可视化无代码编辑器中创建流程。

- **创建付费墙、用户引导等内容**：创建动态的单屏或多屏流程。
- **功能完善的流程模板**：从[专业设计的模板](paywall-builder-templates)开始构建流程。
- **灵活的设计方式**：以可视化方式还原复杂页面，无需编写代码。
- <Inline id="sparkle.svg" alt="AI Editor" /> **[AI 编辑器](flow-ai-editor)**：用日常语言描述修改需求，改动即刻呈现在屏幕上——无需调整任何属性，即可重新排版、改写文案或重新布局。
- **原生渲染**：Adapty SDK 以原生方式渲染流程，不依赖 Web 视图，确保流畅的用户体验。
- **无需重新发版即可更新**：随时修改文案、设计或逻辑，更新无需发布新版本即可触达用户。

## 你可以构建什么 \{#what-you-can-build\}

你可以在应用的任何位置放置流程——首次启动时、高级功能入口前，或某个关键操作完成后。每个页面都可以完全自定义，让每个流程都契合当下的使用场景。以下是一些最常见的用例：
- **应用用户引导**：展示应用功能，提问互动，并根据测验答案个性化突出功能和 CTA。请参阅[构建个性化用户引导流程](onboarding-flow-tutorial)。
- **付费墙页面**：在高级内容前设置功能门槛，展示含功能列表、定价和购买按钮的产品。请参阅[创建基础付费墙页面](basic-paywall-screen)。
- **分标签的分级方案**：在标签中并排展示订阅套餐，当用户切换时同步更新功能列表和 CTA。请参阅[创建带标签的付费墙](paywall-with-tabs)和[为不同产品展示不同功能](paywall-features-per-product)。
- **可展开的方案列表**：先突出展示一个重点优惠，当用户想要比较时，在底部弹出完整产品列表。请参阅[在底部弹窗中展示全部方案](show-plans-bottom-sheet)。
- **调查和测验**：收集用户目标、偏好或经验水平，然后根据答案分支流程或定制后续页面。请参阅[流程编辑工具中的输入与表单](builder-inputs-and-forms)。
- **社会认同**：在购买决策前展示评论卡片、评分和用户推荐，建立信任感。请参阅[评论与推荐](builder-reviews-and-testimonials)。
- **促销和赢回页面**：开展限时折扣、免费试用促销，或通过赢回页面重新激活流失用户。
以上只是最常见的几种模式。流程由灵活、可复用的元素构成，你可以将它们组合成产品所需的几乎任何页面——并在产品迭代时随时调整。

## 创建流程 \{#create-a-flow\}

[创建新流程](paywall-builder-templates)，可从自定义设计的模板库中选择，也可从空白画布开始。然后通过以下功能对其进行定制：
- **[元素库](builder-elements)** — 预置的文本、媒体、按钮、表单及其他内容模块。
- **[交互动作](onboarding-actions)** — 在页面之间跳转、打开 URL、发起购买等。
- **[变量](onboarding-variables)** — 在文本中使用变量值，或实现基于触发条件的流程逻辑。
- **[条件导航](onboarding-navigation-branching)** — 根据用户输入进行分支跳转。
- **[问卷与输入](builder-inputs-and-forms)** — 收集并处理用户输入。
- <Inline id="sparkle.svg" alt="AI Editor" /> **[AI 编辑器](flow-ai-editor)** — 用自然语言描述修改需求，AI 会将其应用到当前页面。
- **[深色模式](paywall-dark-mode)** — 设置元素样式以匹配设备主题。
- **[本地化](add-flow-remote-config-locale)** — 支持手动或 AI 辅助。

[保存并发布](builder-save-publish)草稿，然后将其附加到[流程版位](create-placement) — 创建一个新版位，并使用应用中其他版位均未使用的版位 ID。一个流程版位可以为不同的[目标受众](add-audience-paywall-ab-test)展示不同的流程。
