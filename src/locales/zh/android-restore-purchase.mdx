恢复购买是一项允许用户重新获取此前已购内容（如订阅或应用内购买）的功能，且无需再次付费。此功能尤其适用于以下场景：用户卸载并重新安装了应用，或更换了新设备，希望在不重复付费的情况下访问此前购买的内容。

:::note
如果你在编辑工具中构建了付费墙界面，则无需手动恢复购买。只需关联对应的恢复控件——在 Flow & 付费墙编辑工具中使用 **Restore purchases** 操作，或在旧版编辑工具中使用恢复链接或按钮——SDK 会自动完成恢复流程。
:::

如果你自行构建了界面，请调用 `.restorePurchases()` 方法：

<Tabs groupId="current-os" queryString>

<TabItem value="kotlin" label="Kotlin" default>

```kotlin showLineNumbers
Adapty.restorePurchases { result ->
    when (result) {
        is AdaptyResult.Success -> {
            val profile = result.value
                      
            if (profile.accessLevels["YOUR_ACCESS_LEVEL"]?.isActive == true) {
            // successful access restore
            }
        }
        is AdaptyResult.Error -> {
            val error = result.error
            // handle the error
        }
    }
}
```
</TabItem>
<TabItem value="java" label="Java" default>

```java showLineNumbers
Adapty.restorePurchases(result -> {
    if (result instanceof AdaptyResult.Success) {
        AdaptyProfile profile = ((AdaptyResult.Success<AdaptyProfile>) result).getValue();
        
        if (profile != null) {
            AdaptyProfile.AccessLevel premium = profile.getAccessLevels().get("YOUR_ACCESS_LEVEL");
            
            if (premium != null && premium.isActive()) {
                // successful access restore
            }
        }
    } else if (result instanceof AdaptyResult.Error) {
        AdaptyError error = ((AdaptyResult.Error) result).getError();
        // handle the error
    }
});
```
</TabItem>

</Tabs>

响应参数：

| 参数 | 描述 |
|---------|-----------|
| **Profile** | <p>一个 [`AdaptyProfile`](https://android.adapty.io/adapty/com.adapty.models/-adapty-profile/) 对象。该模型包含访问等级、订阅和一次性购买的相关信息。</p><p>检查**访问等级状态**以确定用户是否有权访问应用。</p> |

:::info
从 Adapty Android SDK 3.17.3 和 4.0.2 版本开始，即使没有任何可恢复的内容，`restorePurchases()` 也会成功完成：它会返回当前用户画像，请检查其中的访问等级状态。在更早的 SDK 版本中，这种情况下该方法会以 `NO_PURCHASES_TO_RESTORE` 错误失败。
:::

## 可以恢复哪些内容 \{#what-can-be-restored\}

`restorePurchases` 可恢复 Google Play 中的有效订阅和未消耗的一次性购买。

从 Adapty Android SDK 3.17.3 和 4.0.2 开始（使用 Google Play Billing Library 8），Play Store 不再返回已过期的订阅或已消耗的一次性购买。若需让用户在更换设备或重新安装后恢复这些内容，请通过 `Adapty.identify` [识别用户](android-identifying-users)。Adapty 将从其后端（而非商店）恢复购买历史记录。

:::note
Google Play 仅报告当前拥有的购买记录，因此 `restorePurchases()` 无法找到在你集成 Adapty 之前已过期的订阅。如需将其添加到 Adapty，请[导入历史数据](importing-historical-data-to-adapty)。
:::
