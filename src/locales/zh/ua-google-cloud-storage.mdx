Adapty Attribution 与 Google Cloud Storage 的集成，可让您将用户获取活动数据安全地存储在同一位置。Adapty Attribution 会将 .csv 文件保存到您的 Google Cloud Storage 存储桶中。每一行代表一次应用安装，包含设备标识符和归因数据（如渠道和活动信息）。这些文件不包含广告支出、收入或购买数据。

要设置此集成，您需要在 Google Cloud Console 和 Adapty Attribution 看板中按照以下几个简单步骤进行操作。

:::note
Adapty 归因数据每个日历日向 Google Cloud Storage 导出一组文件。导出调度程序每天运行三次——分别在 **02:00**、**04:00** 和 **06:00 UTC**。每次运行要么创建前一天的导出任务（如果尚不存在），要么在之前的运行失败时进行重试。因此，您的数据通常在 02:00 运行后即可到达，后续运行的目的是从失败中恢复，而不是添加新数据。

每次导出涵盖 Adapty 归因在前一个 UTC 自然日内记录的安装数据。例如，3 月 8 日的导出包含 3 月 7 日 00:00:00 至 23:59:59 UTC 期间记录的安装数据。

每个文件展示的是导出时刻的归因状态。安装发生后的 30 天内，Adapty 归因仍可能将该安装归属到其他渠道或广告活动。若需用最新归因刷新历史文件，请针对相应日期[手动执行导出](#manual-data-export)。
:::

:::warning
计划导出功能仅适用于付费套餐或试用期内的公司。如果两者均不符合，调度程序将跳过导出并不写入任何文件，即使该集成在看板中显示为已启用。如果您的存储桶为空且配置看起来正确，请先检查您的套餐状态。
:::

## 如何设置 Google Cloud Storage 集成 \{#how-to-set-up-google-cloud-storage-integration\}

### 第一步：创建 Google Cloud Storage 凭证 \{#step-1-create-google-cloud-storage-credentials\}

本指南将帮助你在 Google Cloud Platform Console 中创建所需的凭证。

为了让 Adapty Attribution 将原始数据报告上传到你指定的存储桶，需要提供服务账号的密钥，并授予对应存储桶的写入权限。通过提供服务账号密钥并授予存储桶写入权限，你可以让 Adapty Attribution 安全高效地将原始数据报告从其平台传输到你的存储环境。

:::warning
请注意，我们仅支持服务账号 HMAC 密钥授权，因此请务必确保您的服务账号 HMAC 密钥已添加"Storage Object Viewer"、"Storage Legacy Bucket Writer"和"Storage Object Creator"角色，以便正常访问 Google Cloud Storage。
:::

### 第二步：在 Adapty Attribution 中配置集成 \{#step-2-configure-integration-in-adapty-attribution\}

1. 前往 [**Integrations** -> **Google Cloud Storage**](https://app.adapty.io/ua/integrations/google-cloud-storage)
2. 打开 **Export install events to Google Cloud Storage** 开关
3. 填写必填字段，以建立 Google Cloud Storage 与 Adapty Attribution 之间的连接：

| 字段 | 描述 |
|:------------------------------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Google Cloud service account key file** | 下载的私有 [JSON 密钥文件](ua-google-cloud-storage#step-1-create-google-cloud-storage-credentials)。 |
| **Google Cloud bucket name** | 您希望在 Google Cloud Storage 中存储数据的存储桶名称。该名称在 Google Cloud Storage 环境中必须唯一，且不能包含空格。 |
| **Folder inside the bucket** | 存储桶内用于存储数据的文件夹名称。该名称在存储桶内必须唯一，可用于整理数据。此字段为选填项。 |

## 手动数据导出 \{#manual-data-export\}

如需导出更早日期的数据，请在 **Manual file export** 部分选择日期范围，然后点击 **Export to Google Cloud Storage**。如果您的存储桶中已存在相应日期的文件，Adapty Attribution 会将其替换。

## 表格结构 \{#table-structure\}

每个文件中，每行对应 Adapty 归因在某一 UTC 日期内记录的一次安装，包含其设备数据和归因信息。文件中不含广告支出、收入或购买数据。

:::warning
请注意，随着我们或第三方合作伙伴引入新数据，该结构可能会随时间扩展。请确保处理这些文件的代码具有足够的健壮性，仅依赖特定字段，而非依赖整体结构。
:::

文件包含以下列：

| 列名                       | 描述                                       |
|--------------------------|-------------------------------------------|
| `adapty_profile_id`      | Adapty 用户画像唯一标识符                   |
| `install_id`             | 安装唯一标识符                              |
| `created_at`             | 记录创建时间戳（ISO 8601）                  |
| `installed_at`           | 应用安装时间戳（ISO 8601）                  |
| `store`                  | 应用商店（`ios`、`android`）                |
| `country`                | 用户国家代码（ISO 3166-1 alpha-2）          |
| `ip_address`             | 客户端 IP 地址                              |
| `idfa`                   | iOS 广告主标识符                            |
| `idfv`                   | iOS 供应商标识符                            |
| `gaid`                   | Google 广告 ID（Android）                   |
| `android_id`             | Android 设备 ID                             |
| `app_set_id`             | Android App Set ID                          |
| `bundle_id`              | 应用 Bundle 标识符（如 `com.example.app`）  |
| `device_brand`           | 设备品牌（如 `Apple`、`Samsung`）           |
| `device_model`           | 设备型号（如 `iPhone15,2`）                 |
| `os_version`             | 主要 OS 版本                                |
| `app_version`            | Adapty SDK 上报的应用版本                   |
| `sdk_version`            | Adapty SDK 版本                             |
| `channel`                | 归因渠道                                    |
| `campaign_id`            | 推广活动标识符                              |
| `campaign_name`          | 推广活动名称                                |
| `adset_id`               | 广告组标识符                                |
| `adset_name`             | 广告组名称                                  |
| `ad_id`                  | 广告标识符                                  |
| `ad_name`                | 广告名称                                    |
| `keyword_id`             | 关键词标识符                                |

| `asa_org_id`             | Apple Search Ads 组织 ID                    |

| `fbclid`                 | Facebook Click ID                           |
| `ttclid`                 | TikTok Click ID                             |
| `utm_source`             | UTM source 参数                             |
| `utm_medium`             | UTM medium 参数                             |
| `utm_campaign`           | UTM campaign 参数                           |
| `utm_term`               | UTM term 参数                               |
| `utm_content`            | UTM content 参数                            |

| `asa_click_time`         | 安装前 Apple Search Ads 点击的时间戳，单位为 Unix 秒，精确到分钟。若 Apple Search Ads 未上报该安装的点击，则为空。与 `click_time` 不同，即使 Adapty Attribution 将该安装归因到其他渠道，此字段也可能有值。 |
