公式是一种[自定义变量](onboarding-variables#custom-variables)，其值通过计算得出，可以是数字或日期。公式可以读取用户在流程中给出的答案、其他自定义变量、Adapty 产品目录中的产品价格以及当前日期。借助流程与付费墙编辑工具中的公式，流程无需修改应用代码即可展示计算结果：

- **答案结果**：测验得分之和、由体重和身高计算出的 BMI，或以英尺和英寸表示的身高。
- **价格**：所选产品打八折后的价格，或用户选择年度方案相比周方案能节省多少钱。
- **日期**：免费试用的结束日期。
- **时长**：免费试用的天数，或根据出生日期计算的用户年龄。

该流程在设备上计算公式的结果。当公式读取的某个值发生变化时，流程会自动更新结果。您可以在文本元素中显示该结果，也可以将其用于条件判断。

## 创建公式 \{#create-a-formula\}

1. 在流程编辑工具中打开 <Inline id="variables.svg" alt="Variables" /> Variables 面板。
2. 添加新变量——点击 <Inline id="plus.svg" alt="Plus" />。
3. 输入变量的 **Name**，例如 `bmi`。其他公式通过这个名称读取计算结果。
4. 在 **Value Type** 下拉菜单中，选择 **Formula**。
5. 在 **Expression** 字段中输入公式，例如 `round({{weight}} * 10000 / ({{height}} * {{height}}), 1)`，其中 `weight` 和 `height` 是 Number 类型变量。规则说明请参阅[编写公式](#write-a-formula)。
6. 点击 **Create variable**。

<ZoomImage id="flow-formula-create.webp" width="300px" alt="创建变量对话框，显示公式类型、表达式字段中的 BMI 公式、数字输出类型以及 22.9 的预览值" />

当你离开 **Expression** 字段时，编辑工具会对公式进行校验。如果公式存在错误，字段下方会显示错误提示。在错误显示期间，**Create variable** 按钮（对于已有变量则为 **Save**）将被禁用。编辑表达式后，错误提示消失，按钮恢复可用。

字段下方，编辑工具会显示：

- **Output type**：**Number** 或 **Date**，即结果的类型。编辑工具根据公式自动设置：当公式是返回日期的[日期函数](#date-functions)（如 `addDays`）或单独的 Date 值（如 `{{trial_start}}`）时，结果为 Date；其他公式的结果均为 Number，包括计算两个日期之间时长的公式（如 `daysBetween`）。
- **Date format**：仅适用于 Date 类型的公式。控制文本元素如何显示结果。请参阅[在文本元素中显示日期](#show-a-date-in-a-text-element)。
- **Preview**：根据初始值和产品价格计算出的结果预览。请参阅[在编辑工具中预览公式](#preview-a-formula-in-the-builder)。

公式始终依赖其他值，因此没有**Initial value**。同样，您的应用程序也无法设置公式。

### 插入引用和函数 \{#insert-references-and-functions\}

如果你不确定变量的确切名称，可以在 **Expression** 字段中输入 `{{`，系统会弹出变量列表。输入名称的一部分即可筛选列表，然后选择所需变量插入其引用。输入函数名称时，列表同样会自动弹出。在数字值（如 `{{weight}}` 或 `5`）后输入空格时，列表会显示 `+`、`-`、`*` 和 `/` 等运算符供选择。按 Escape 可关闭列表。

该列表仅显示可以出现在光标位置的变量和函数。例如，在 `addDays` 的第一个参数中，列表会提供 Date 值、`today()` 以及返回日期的函数。在 `round` 的第二个参数中，列表不提供任何内容，因为小数位数是一个需要手动输入的数字。

**Expression** 字段以芯片的形式显示每个引用，芯片上显示变量名称，例如自定义变量显示为 **weight**，产品价格显示为 **Weekly · prod_price**。芯片是一个整体单元：按 Backspace 或 Delete 键会删除整个引用，方向键则会将光标移过芯片。

要浏览公式可以读取的所有变量，或查看某个函数的说明，请使用 **Output type** 行上的两个按钮。每个按钮都会在 **Expression** 字段的光标处插入文本：

- <Inline id="variables.svg" alt="Insert variable" /> **Insert variable**：打开一个包含四个标签页的列表。选择一个值以插入其引用，或选择一个函数以插入其名称和左括号：
  - **Functions**：公式的函数。
  - **Elements**：输入框和选择器中的答案，例如 `weight.value`。
  - **Products**：所选产品在各产品组中的价格，以及您 Adapty 目录中的产品。请参阅[读取任意产品的价格](#read-the-price-of-any-product)。
  - **Custom**：数字、日期和公式类型的自定义变量。
- <Inline id="function.svg" alt="Insert function" /> **Insert function**：列出所有函数，每个函数均附有描述和示例。如需查找某个函数，请在搜索框中输入其名称。选择一个函数即可插入其名称和左括号，例如 `addDays(`，然后输入参数和右括号。

**插入变量**列表不显示 String、Boolean 或 Array 类型的变量，也不显示您正在编辑的公式。

## 编写公式 \{#write-a-formula\}

公式由数字、值引用、运算符和函数组成。函数名和变量名区分大小写：`Round(2.5)` 会报错。

### 参考文献 \{#references\}

将每个参考文献放在双大括号中：

| 引用 | 公式含义 | 示例 |
| :--- | :--- | :--- |
| `{{<variable name>}}` | Number、Date 或 Formula 类型的自定义变量 | `{{discount}}` |
| `{{<Element ID>.value}}` | [文本或数字输入框](builder-inputs-and-forms)、[数字选择器](builder-number-picker)或日期/日期时间输入框中的答案 | `{{weight.value}}` |
| `{{<Group ID>.selectedProduct.prod_price}}` | 用户在产品组中选择的产品价格（数字形式） | `{{products.selectedProduct.prod_price}}` |
| `{{<Group ID>.selectedProduct.prod_price_per_week}}` | 所选产品每周的价格。同理还有 `prod_price_per_day`、`prod_price_per_month` 和 `prod_price_per_year`。非订阅产品不返回任何值。详见[按周期计算的价格](#per-period-prices)。 | `{{products.selectedProduct.prod_price_per_month}}` |
| `{{<Group ID>.selectedProduct.offer_price}}` | 所选产品的优惠价格（数字形式） | `{{products.selectedProduct.offer_price}}` |
| `{{<Group ID>.selectedProduct}}` | 所选产品，仅作为 `addOfferDuration` 的第二个参数使用 | `{{products.selectedProduct}}` |
| `{{<Adapty product ID>.prod_price}}` | Adapty 产品目录中某个产品的价格（数字形式），也支持该产品的按周期价格，例如 `prod_price_per_week`。详见[读取任意产品的价格](#read-the-price-of-any-product)。 | `{{<annual product ID>.prod_price}}`，显示为 **Annual · prod_price** |

当答案为数字时，公式会将其识别为数值——支持前置负号和一位小数（小数点或小数逗号均可）。公式会自动忽略首尾空格。例如，`12`、`-5`、`1.5` 和 `1,5` 均为有效数字。其他格式（如 `abc`、`1,5,0` 或 `1e3`）会使公式返回[无值](#formulas-without-a-value)。在公式读取的数字输入框中，用户只能输入数字。选择 **Decimal (Point)** 或 **Decimal (Comma)** 格式后，用户可以输入对应的小数分隔符，因此各类键盘上的小数键均可正常使用。

日期或日期与时间输入会返回用户选择的具体日历日期。

公式可以读取另一个公式，但引用关系不能形成循环。如果公式 A 读取公式 B，那么公式 B 就不能反过来读取公式 A。更长的循环同样会报错，例如 A 读取 B、B 读取 C、C 读取 A。公式也不能引用自身。当你重命名变量、**Element ID** 或 **Group ID** 时，公式会显示新名称，读取的值保持不变。当你删除某个公式正在读取的变量时，**Expression** 字段会在相应位置显示一个 **deleted variable** 标记，字段下方也会出现错误提示。

一个名称同时匹配两个值会导致错误。例如，如果自定义变量命名为 `age.value`，而某个输入框的 Element ID 为 `age`，则 `{{age.value}}` 会同时匹配两者。请重命名该自定义变量。

### 数字与运算符 \{#numbers-and-operators\}

- **数字**：始终使用小数点，例如 `0.8`。在函数内部，逗号用于分隔参数：`round(2,5)` 即 `round(2, 5)`，结果为 2，而非 2.5。在函数外部，数字中出现逗号会导致报错。数字或引用前的负号表示负值，例如 `-3`。
- **运算符**：`+`、`-`、`*` 和 `/`。流程会先计算 `*` 和 `/`，再计算 `+` 和 `-`；同级运算符从左到右依次计算。使用括号可改变计算顺序，例如 `({{a}} + {{b}}) / 2`。

## 数值公式 \{#number-formulas\}

数值公式返回一个数字。

### 数字函数 \{#number-functions\}

| 函数 | 结果 | 示例 |
| :--- | :--- | :--- |
| `round(n)` | `n` 四舍五入到整数。正好在中间的值远离零方向舍入。 | `round(2.5)` = 3, `round(-2.5)` = -3 |
| `round(n, digits)` | `n` 四舍五入到 `digits` 位小数。`digits` 是 0 到 6 之间的整数，须直接写在公式中，不能使用引用或计算式。 | `round(23.12, 1)` = 23.1, `round(1.005, 2)` = 1.01 |
| `floor(n)` | 不大于 `n` 的最大整数 | `floor(2.7)` = 2, `floor(-2.5)` = -3 |
| `mod(a, b)` | `a` 除以 `b` 的余数，符号与 `b` 相同，与电子表格中的 MOD 函数一致 | `mod(7, 3)` = 1, `mod(-7, 3)` = 2, `mod(5.5, 2)` = 1.5 |

`round`、`floor` 和 `mod` 的零结果始终为 0，而非 -0。

### 在文本元素中显示数字 \{#show-a-number-in-a-text-element\}

要显示公式或 Date 变量，请从变量选择器的 **Custom** 选项卡中将变量[插入到文本元素](onboarding-variables#use-variables-in-text)里。顶层带有 `round` 的 Date 和数字会以设备语言显示，而非流程语言。

Number 公式的显示方式取决于公式顶层的函数：

- **`round` 在顶层**：数字的小数位数与 `round` 设置的完全一致。使用设备语言的小数分隔符，无千位分隔符和货币符号。例如，`round(23.12, 1)` 在英语中显示 "23.1"，在俄语中显示 "23,1"；`round(15.04, 1)` 在英语中显示 "15.0"。
- **其他任何公式**：数字以原始形式显示，所有语言均使用小数点，最多保留 15 位有效数字。例如，`9.99 * 0.8` 显示 "7.992"，`1 - 1 / 3` 显示 "0.666666666666667"。如需设置小数位数，请将 `round` 放在公式的顶层，例如 `round(1 - 1 / 3, 2)`。

Number 类型变量以及顶层使用 `floor` 或 `mod` 的公式，在纯文本形式中同样会正常显示。

### 在条件中比较数字 \{#compare-numbers-in-conditions\}

你可以在条件中选择公式或日期变量，例如在[条件可见性](onboarding-element-visibility)规则或条件动作中：

- **Number formulas**：使用与 Number 变量相同的运算符：**Equals**、**Does not equal**、**Greater than**、**Less than**、**Is empty** 和 **Is not empty**。可将公式与某个数字或另一个 Number 值进行比较，例如 `bmi` **Greater than** `25`。这些运算符不包含"大于等于"或"小于等于"。如需匹配 10 及以上的整数（例如测验分数），可使用 `score` **Greater than** `9`。

## 产品价格 \{#product-prices\}

公式可以从以下两个来源读取产品价格：

- **所选产品组中的产品**：当用户在产品组中选择其他产品时，价格会随之变化，例如 `{{products.selectedProduct.prod_price}}`。
- **Adapty 目录中的某个产品**：即使该屏幕未显示该产品，也可以获取其价格。适用于方案对比场景，例如计算年度方案相对于周付方案的节省金额。

在设备上，流程会根据用户所在地区使用对应货币的商店价格。产品价格加载完成后，流程会重新计算公式。

### 读取任意产品的价格 \{#read-the-price-of-any-product\}

1. 在 **Expression** 字段中，将光标放置在价格所在的位置。
2. 点击 <Inline id="variables.svg" alt="Insert variable" /> **Insert variable**，并打开 **Products** 标签。
3. 指向该产品，然后选择价格：`prod_price`，或[按周期价格](#per-period-prices)，例如 `prod_price_per_week`。

**Products** 标签将产品分为两组：

- **This flow**：该流程中各页面上的产品。
- **Other**：你 Adapty 目录中的其余产品。

要区分不同产品，可对比列表中各产品的访问等级和美元价格。列表不显示产品的订阅时长。当两个产品名称相同时，列表和芯片的提示框还会显示商店产品 ID。

只有当产品已加入[该页面的产品列表](paywall-product-block)时，公式才能在页面上显示价格。将公式插入文本元素或在条件中使用时，编辑工具会自动将该产品添加到列表中，不附带任何优惠或计费方案。当公式通过另一个公式读取价格时，编辑工具同样如此处理。对于可复用组件，编辑工具会将该产品添加到每个显示该组件的页面中。如果页面中该产品已附带优惠或计费方案，编辑工具会额外添加一条不带优惠和计费方案的条目。

添加的条目会显示在 **Products** 面板中、分析数据里，以及你的应用代码接收到的产品列表中，与该页面的其他产品一样。页面不会自动选中它，点击文本也不会触发购买。

编辑工具添加该条目后，你可以在 **Products** 面板中管理它，与该页面的其他产品一样：

- **你从公式中删除了价格，或者从屏幕中删除了公式**：该条目会保留。如果屏幕上没有其他地方使用该产品，请删除该条目。保留的条目会在你从 Adapty 目录中删除该产品后阻止发布。
- **你在屏幕仍使用该公式的情况下删除了条目**：编辑工具不会重新添加该条目，屏幕会显示 **This product is off this screen** 问题。要修复该问题，请在 **Products** 面板中重新添加该产品。

当您从 Adapty 目录中删除某个产品后，**Expression** 字段会将其价格显示为 **Missing product** 标签，并在字段下方显示错误提示。请用其他产品的价格替换该价格。删除操作不会影响已发布的流程版本。

如果您通过 [Adapty CLI](developer-cli-flows) 或 API 创建流程，请按照编辑工具的做法，将不带优惠或计费计划的产品添加到每个使用该公式的屏幕中。在表达式中，使用 [`adapty products list`](developer-cli-products) 返回的 Adapty 产品 ID。只有当文本元素或条件使用了该公式，且流程中没有任何屏幕包含不带优惠或计费计划的产品时，发布才会因 `formula_undeclared_product` 错误而失败。

### 按周期计算的价格 \{#per-period-prices\}

按周期计算的价格是指订阅产品每天、每周、每月或每年的价格。公式可以读取目录产品以及产品组中所选产品的这些价格：

| 价格 | 示例：月度产品，价格为 9.99 |
| :--- | :--- |
| `prod_price_per_day` | 9.99 / 30 = 0.333 |
| `prod_price_per_week` | 9.99 × 7 / 30 = 2.331 |
| `prod_price_per_month` | 9.99 |
| `prod_price_per_year` | 9.99 × 12 = 119.88 |

流程会将价格除以产品订阅时长所包含的天数、周数、月数或年数。一个月等于 30 天，即 30/7 周；一年等于 365 天、52 周或 12 个月。[文本元素的价格变量](onboarding-variables#product-variables)使用相同的换算规则。例如，年付产品售价 120，则 `prod_price_per_month` 的值为 10，`prod_price_per_week` 的值为 120 / 52。

计算公式会保留每计费周期价格的所有小数位。如需保留两位小数，请在公式最外层添加 `round`。例如，当用户选择年费产品且价格为 120 时，`round({{products.selectedProduct.prod_price_per_week}}, 2)` 将显示"2.31"。

非订阅产品（如永久授权产品或消耗型商品）的每计费周期价格将返回[无值](#formulas-without-a-value)。

## 日期公式 \{#date-formulas\}

日期公式返回一个日期值。如需在公式中使用固定日期（例如试用开始日期），请将其存储在日期变量中。

### 创建日期变量 \{#create-a-date-variable\}

1. 打开 <Inline id="variables.svg" alt="Variables" /> Variables 面板，点击 <Inline id="plus.svg" alt="Plus" />。
2. 输入变量的 **Name**，例如 `trial_start`。
3. 在 **Value Type** 下拉菜单中，选择 **Date**。
4. （可选）在 **Initial value** 字段中，以 `DD.MM.YYYY` 格式输入日期，例如 `17.11.2026`，或点击该字段后在日历中选择日期，然后点击 **Apply**。编辑工具不接受不存在的日期，例如 `31.02.2027`。若不设置初始值，则变量在 [**Set variable** 操作](onboarding-actions) 赋值之前将没有任何值。
5. （可选）在 **Date format** 下拉菜单中，选择文本元素显示日期的格式。详见[在文本元素中显示日期](#show-a-date-in-a-text-element)。
6. 点击 **Create variable**。

<ZoomImage id="flow-date-variable-create.webp" width="300px" alt="The Create variable dialog with the Date type and the Initial value 17.11.2026" />

Date 变量存储一个不含时间或时区的日期。

如需在用户点击某个元素时更改 Date 变量，请添加 [**Set variable**](onboarding-actions) 动作，选择该 Date 变量，然后以 `DD.MM.YYYY` 格式输入新日期，或在日历中选择。**Set variable** 动作无法修改公式，因为公式始终依赖其他值。

### 日期函数 \{#date-functions\}

| 函数 | 结果 | 示例 |
| :--- | :--- | :--- |
| `today()` | 设备上的当前日期 | `today()` |
| `addDays(date, n)` | `date` 加 `n` 天 | `addDays(today(), 7)` |
| `addWeeks(date, n)` | `date` 加 `n` 周 | `addWeeks({{trial_start}}, 2)` |
| `addMonths(date, n)` | `date` 加 `n` 个月 | `addMonths({{trial_start}}, 1)` |
| `addYears(date, n)` | `date` 加 `n` 年 | `addYears({{birth_date.value}}, 18)` |
| `addOfferDuration(date, product)` | `date` 加上产品优惠的时长 | `addOfferDuration(today(), {{products.selectedProduct}})` |
| `daysBetween(start, end)` | 从 `start` 到 `end` 的日历天数，返回数字类型 | `daysBetween(today(), {{trial_end}})` |
| `weeksBetween(start, end)` | 从 `start` 到 `end` 的完整周数，返回数字类型 | `weeksBetween({{trial_start}}, today())` |
| `monthsBetween(start, end)` | 从 `start` 到 `end` 的完整月数，返回数字类型 | `monthsBetween({{trial_start}}, today())` |
| `yearsBetween(start, end)` | 从 `start` 到 `end` 的完整年数，返回数字类型 | `yearsBetween({{birth_date.value}}, today())` |

日期函数遵循以下规则：

- **`today()`**：返回设备时区当天的起始时刻。流程在打开时读取当天日期，因此即使流程保持打开状态跨越午夜，该值也不会改变。
- **负数和小数 `n`**：`n` 为负数时日期向前推。流程会舍去 `n` 的小数部分：`addWeeks(date, 1.5)` 加 1 周，`addDays(date, -1.9)` 将日期推前 1 天。
- **月份天数不足**：当目标月份没有对应的日期时，结果取该月最后一天。例如，2027 年 1 月 31 日加 1 个月为 2027 年 2 月 28 日，2028 年 2 月 29 日加 1 年为 2029 年 2 月 28 日。
- **`addOfferDuration`**：按顺序将 Adapty SDK 传入流程的产品优惠各阶段依次叠加。每个阶段的计算方式为：该阶段的周期乘以期数，一次性加总。例如，从 2026 年 11 月 10 日开始的 7 天免费试用期，将于 2026 年 11 月 17 日结束。如果产品没有优惠，或某阶段的周期未知，则结果无值。
- **日期间隔**：`daysBetween`、`weeksBetween`、`monthsBetween` 和 `yearsBetween` 只计整数单位，小数部分舍去：
  - `weeksBetween` 将天数除以 7：13 天为 1 周。
  - `monthsBetween` 和 `yearsBetween` 按完整的日历月和年计算。例如，从 2027 年 1 月 15 日到 2027 年 3 月 14 日为 1 个月，到 2027 年 3 月 15 日为 2 个月。若 `end` 所在月份天数不足以容纳 `start` 的日期，则以该月最后一天作为满月的节点：从 2027 年 1 月 31 日到 2027 年 2 月 28 日为 1 个月。
  - 当 `end` 早于 `start` 时，结果为负数：等于将两个日期顺序互换后的结果取相反数。例如，`daysBetween` 从 2026 年 12 月 1 日到 2026 年 11 月 24 日的结果为 -7；若 `end` 比 `start` 早 10 天，`weeksBetween` 的结果为 -1。

在公式中，Date 只能作为时间加法函数的第一个参数，或作为计算两个日期之间时长的函数的参数。在计算中直接使用 Date，例如 `{{trial_start}} + 1`，会报错。Number 不能作为需要日期类型的函数参数。String、Boolean 或 Array 变量不能参与公式计算。

### 在文本元素中显示日期 \{#show-a-date-in-a-text-element\}

若要显示公式或 Date 变量，请从变量选择器的 **Custom** 标签页将该变量[插入文本元素](onboarding-variables#use-variables-in-text)。顶层带有 `round` 的日期和数字会以设备语言显示，而非流程语言。

Date 变量和 Date 公式在变量设置中均包含 **Date format** 选项。所有引用该变量的文本元素都会使用此格式，修改格式后，这些文本元素也会随之更新。新建变量默认使用 **Medium** 格式。

要在同一文本元素中使用其他格式，请在 **Content** 字段中点击变量并选择一种格式。若要恢复变量的默认格式，请选择 **Variable default**。可用格式如下：

| 日期格式 | 英语示例 |
| :--- | :--- |
| **Short** | 11/17/26 |
| **Medium** | Nov 17, 2026 |
| **Long** | November 17, 2026 |
| **Month D** | November 17 |
| **Mon D** | Nov 17 |

**Short**、**Medium** 和 **Long** 会根据设备语言的日期顺序进行显示。**Month D** 和 **Mon D** 在所有语言中均将月份置于日期之前，例如俄语中显示为"ноября 17"。

### 在条件中比较日期 \{#compare-dates-in-conditions\}

你可以在条件中选择公式或日期变量，例如[条件可见性](onboarding-element-visibility)规则或条件动作：

- **日期变量和日期公式**：使用 **Equals**、**Does not equal**、**Earlier than**、**Later than**、**Is empty** 或 **Is not empty**。可以将日期与另一个日期进行比较，也可以与你以 `DD.MM.YYYY` 格式输入或在日历中选取的日期进行比较。**Is empty** 在日期尚无值时为真，例如在 **Set variable** 动作赋值之前，未设置初始值的日期变量。

日期比较针对的是日历天，而非时间。例如，用户在 2026 年 11 月 17 日 21:00 选择的日期等于 `17.11.2026`。日期不能与数字进行比较。

## 没有值的公式 \{#formulas-without-a-value\}

当公式中某个值在设备上不可用时，该公式将没有值：

- 答案为空，或不是一个数字。
- 产品价格未能加载，或商店未返回公式所读取的产品。要在 iOS 和 Android 上都为公式提供值，请在 App Store Connect 和 Google Play Console 中设置该产品。
- 该产品不是订阅，但公式读取了[按周期价格](#per-period-prices)。
- 所选产品没有优惠，但公式读取了 `offer_price` 或调用了 `addOfferDuration`。
- 公式除以零，例如 `{{a}} / 0` 或 `mod({{a}}, 0)`。
- 公式所读取的日期变量没有值。

读取无值公式的公式本身也没有值。当公式没有值时，其行为如下：

- **文本元素**：公式不显示任何内容。
- **条件**：**为空** 为真。**等于**、**不等于** 以及所有基于该公式的比较均为假。

当公式所读取的值发生变化时，流程会更新公式的计算结果：用户输入答案、**Set variable** 操作更改某个变量，或产品价格加载完成时，均会触发更新。如果用户返回并清除了某个答案，该公式在下一个屏幕上将没有可用的值。在流程更改自定义变量之前，公式读取的是该变量的初始值（Initial value）。

## 在编辑工具中预览公式 \{#preview-a-formula-in-the-builder\}

编辑工具会根据自定义变量的初始值以及 Adapty 目录中产品的美元价格来计算公式结果。当公式包含以下任一情况时，**Expression** 字段下方的 **Preview** 将显示 **No value**：

- 用户输入或选择的答案
- `offer_price`
- `addOfferDuration` 的优惠
- 没有值的变量，例如没有初始值的日期变量
- Adapty 产品目录中没有 USD 价格或 USD 价格为 0 的产品价格
- 非订阅类产品（如永久授权产品）的按周期计算价格

在这些情况下，画布上的文本元素会显示大括号中的变量名，例如 `{{trial_end}}`。要查看答案的值，请[在 Adapty 移动应用中预览流程](paywall-device-compatibility-preview)。优惠的值需要包含真实产品的应用构建版本。

在画布上，顶层带有 `round` 的日期和数字会以你在预览中选择的语言显示。

## 示例 \{#examples\}

### 显示答案总和 \{#show-a-sum-of-answers\}

在某个屏幕上，添加三个 Number 输入控件，元素 ID 分别设为 `a1`、`a2` 和 `a3`。创建一个名为 `sum` 的公式：

```
{{a1.value}} + {{a2.value}} + {{a3.value}}
```

在下一个屏幕中，将 `sum` 插入到文本元素里。如果用户分别输入 2、3、4，文本显示"9"；如果用户返回并将 4 改为 5，文本则显示"10"。

### 显示 BMI 及"High"标签 \{#show-a-bmi-and-a-high-label\}

添加一个元素 ID 为 `weight` 的数字输入框（用于输入体重，单位：千克），以及一个元素 ID 为 `height` 的数字输入框（用于输入身高，单位：厘米）。创建公式 `bmi`：

```
round({{weight.value}} * 10000 / ({{height.value}} * {{height.value}}), 1)
```

将 `bmi` 插入文本元素。当 BMI 为 23.12 时，英语设备语言下用户看到的是"23.1"，俄语设备语言下看到的是"23,1"。如需仅在 BMI 超过 25 时显示"High"标签，可添加一个包含"High"文字的文本元素，并为其设置[条件可见性](onboarding-element-visibility)规则：`bmi` **大于** `25`。

### 显示折扣价格 \{#show-a-discounted-price\}

创建一个公式 `discounted`，对所选产品的价格打八折：

```
{{products.selectedProduct.prod_price}} * 0.8
```

然后创建公式 `shown`，将其四舍五入到小数点后两位：

```
round({{discounted}}, 2)
```

将 `shown` 插入文本元素。对于价格为 9.99 的产品，文本显示"7.99"；当用户选择价格为 100 的产品时，文本显示"80.00"。数字不带货币符号。如果所选产品的价格未能加载，文本为空。

### 显示年度计划的节省金额 \{#show-the-savings-of-the-annual-plan\}

要显示用户选择年度计划相比购买 52 周的周计划能节省多少，可以创建一个 `saving` 公式，读取两个产品的价格。周计划产品不需要出现在流程的任何页面上。在本例中，年度产品售价为 120，周计划产品售价为 5：

1. 在 **Expression** 字段中，点击 <Inline id="variables.svg" alt="Insert variable" /> **Insert variable**。在 **Products** 标签页中，指向每周产品，然后选择 `prod_price`。
2. 输入 `* 52 -`。
3. 以同样的方式插入年度产品的 `prod_price`。

**Expression** 字段显示 **Weekly · prod_price** `* 52 -` **Annual · prod_price**，**Preview** 显示 140。编辑工具会将表达式与 Adapty 产品 ID 一起保存：

```
{{<weekly product ID>.prod_price}} * 52 - {{<annual product ID>.prod_price}}
```

要以百分比形式显示节省金额，请创建公式 `saving_percent`。从 **Products** 标签页插入两个价格，操作方式与 `saving` 相同。编辑工具会将表达式保存为：

```
round((1 - {{<annual product ID>.prod_price}} / ({{<weekly product ID>.prod_price}} * 52)) * 100)
```

对于这些价格，`saving_percent` 为 54。将 `saving` 或 `saving_percent` 插入付费墙屏幕上的文本元素中。编辑工具会将按周计费的产品添加到屏幕产品列表的末尾。在设备端，该公式使用用户所在货币的商店价格进行计算。屏幕上的购买按钮将触发年付产品的购买。

### 显示试用期结束日期和提醒日期 \{#show-the-end-of-a-trial-and-a-reminder-date\}

创建公式 `trial_end`：

```
addOfferDuration(today(), {{products.selectedProduct}})
```

然后创建公式 `reminder`，表示试用期结束前三天：

```
addDays({{trial_end}}, -3)
```

对于提供 7 天免费试用的产品，在 2026 年 11 月 10 日时，`trial_end` 为 2026 年 11 月 17 日，`reminder` 为 2026 年 11 月 14 日。使用 **Medium** 日期格式时，文本显示为"Nov 17, 2026"；使用 **Month D** 格式时，显示为"November 17"。

### 显示试用时长 \{#show-the-length-of-a-trial\}

使用[显示试用结束日期与提醒日期](#show-the-end-of-a-trial-and-a-reminder-date)中的 `trial_end` 公式，并创建一个 `trial_days` 公式：

```
daysBetween(today(), {{trial_end}})
```

在文本元素中输入"Free for"，插入 `trial_days`，再输入"days"。对于提供 7 天免费试用的产品，文本将显示"Free for 7 days"。当所选产品没有优惠时，`trial_end` 没有值。如果只想在产品有优惠时显示该文本，请为文本元素添加[条件可见性](onboarding-element-visibility)规则：`trial_end` **Is not empty**。

### 显示用户年龄 \{#show-the-age-of-a-user\}

添加一个元素 ID 为 `birth_date` 的日期输入框，并创建公式 `age`：

```
yearsBetween({{birth_date.value}}, today())
```

对于 2000 年 11 月 25 日出生的用户，`age` 在 2026 年 11 月 24 日时为 25，在 2026 年 11 月 25 日时为 26。当答案为空时，`age` 没有值。

### 以英尺和英寸显示身高 \{#show-a-height-in-feet-and-inches\}

添加一个元素 ID 为 `height` 的数字输入框，用于输入以厘米为单位的身高。创建三个公式：

- `total`：`round({{height.value}} / 2.54)`，以整英寸表示的身高。
- `feet`：`floor({{total}} / 12)`。
- `inches`：`mod({{total}}, 12)`。

在文本元素中，插入 `feet`，输入"ft"，再插入 `inches`，然后输入"in"。输入 180 cm 时，文本显示"5 ft 11 in"；输入 140 cm 时，显示"4 ft 7 in"。

## 故障排查 \{#troubleshooting\}

当你离开 **Expression** 字段时，编辑工具会在该字段下方显示公式的第一个错误。以下是一些示例：

| 错误文本 | 原因及修复方法 |
| :--- | :--- |
| `addDays() needs a date and a number` | 函数的参数数量有误，或参数类型不正确。请参考[数值函数](#number-functions)或[日期函数](#date-functions)表格中的参数说明。 |
| `Unknown function "flor". Use one of: …` | 函数名拼写有误，或大小写不匹配。请使用错误提示中列出的函数。如需读取变量，请将变量名放入 `{{ }}` 中。 |
| `Use a dot in a decimal number, like 1.5` | 函数外的数字使用了逗号。请将逗号替换为小数点。在函数内部，编辑工具会将逗号识别为参数分隔符，因此同样需要使用小数点。 |
| `{{…}} is not a variable, an answer or a product field of this flow` | 不存在该名称的变量、元素 ID 或产品组。请修正名称，或创建相应变量。 |
| `{{…}}: the product … is not in the product catalog of the app` | 您已从 Adapty 目录中删除该产品。对应组件显示为 **Missing product**。请将价格替换为其他产品的价格。 |
| `Offers, billing plans and fields other than prod_price, … of a catalog product are not supported yet` | 公式读取了您 Adapty 目录中某个产品的优惠、计费计划或其他字段。请通过 **Insert variable** 的 **Products** 标签插入价格。 |
| `This variable no longer exists. Pick another one.` | 公式所读取的变量已被删除。**Expression** 字段会将其显示为 **deleted variable** 组件。请替换为其他引用。 |
| `{{…}} is the name of a variable and of an element answer: rename the variable` | 该名称与两个值重复。请重命名自定义变量。 |
| `{{…}} uses this formula: formulas cannot use each other in a loop` | 公式之间的引用形成了循环：例如，公式 A 读取公式 B，公式 B 又读取公式 A。请移除其中一个引用。 |

<ZoomImage id="flow-formula-error.webp" width="300px" alt="Expression 字段下方的未知函数错误，以及可用函数列表" />

包含错误的公式会阻止发布。**Can't publish yet** 对话框会在 **Variables** 下列出每个存在错误的公式。关于发布时可能出现的错误，请参阅[常见问题](flow-common-issues#a-flow-wont-preview-or-publish)。

## 限制 \{#limitations\}

- **仅限数字和日期**：公式只能返回数字或日期。如需根据结果显示文字，请在文本元素中添加[条件文本](onboarding-text#add-conditional-text)。例如，若要在 BMI 超过 25 时显示"High"，将 **if** 条件设为 `bmi` **Greater than** `25`，并在 **then** 下输入"High"。
- **产品目录中的产品**：公式只读取 Adapty 产品目录中某个产品的价格及按周期计算的价格，不含优惠或计费方案。若要使用优惠价格，请在产品组中读取所选产品的 `offer_price`。
- **已选产品**：读取已选产品的公式在用户选择产品之前没有返回值。若要在屏幕打开时就显示结果，请在某张产品卡片上选择 **Set as default**。
- **iOS 和 Android 上的优惠**：在 iOS 上，Adapty SDK 向流程传递一个优惠。在用户可用的优惠中，优先顺序依次为：赢回优惠、促销活动、新用户优惠。在 Android 上，Adapty SDK 只传递新用户优惠的第一阶段。对于"免费试用 + 折扣价"的组合，Android 上的 `addOfferDuration` 只会计入试用期。
