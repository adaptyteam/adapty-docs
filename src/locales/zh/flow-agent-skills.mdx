Agent 技能让你的 AI 编程工具能够通过 [Adapty CLI](developer-cli-quickstart) 在终端中操作流程，而无需使用可视化编辑器。你用自然语言描述需求，工具会读取流程的编辑器配置，完成相应操作，并在保存前向你展示结果。

两项技能相辅相成：一项用于构建和修改流程，另一项用于检查流程是否可以安全发布。两者集成在同一个插件中，安装一次即可同时获得这两项功能。

<CustomDocCardList />

当你明确知道需要修改什么时，请使用 **flow-generator**——添加新语言、重写文案、增减页面、调整分支逻辑均可。它会编辑配置并保存草稿等待你审核，不会直接发布。

当你想确认某个流程是否完善时，请使用 **flow-audit**。它会读取流程和你的产品目录，报告真实用户使用时可能遇到的问题，并将修复任务交给 flow-generator 处理。

这两个技能都不能替代 [AI 编辑器](flow-ai-editor)——后者直接在付费墙编辑工具中运行。而这些 Agent 技能运行在你的终端中，与你的应用代码处于同一会话。
