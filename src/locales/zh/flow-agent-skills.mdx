Agent 技能让你自己的 AI 编程工具能够通过 [Adapty CLI](developer-cli-quickstart) 在终端中操作流程，而无需使用可视化编辑器。你用自然语言描述需求，工具读取你的账户、完成工作，并在保存之前向你展示结果。

三项技能，各司其职：一项用于构建和修改流程，一项用于检查流程是否可以安全发布，还有一项用于将仍在使用付费墙的应用迁移到流程版位。三项技能集成在同一个插件中，安装一次即可全部使用。

当你明确知道需要做什么改动时，使用 **flow-generator**——添加新语言、改写文案、增删页面、调整跳转逻辑。它会编辑配置并保存草稿等待你审批，不会直接发布。

当你想确认一个流程是否完善时，使用 **flow-audit**。它会读取该流程及你的产品目录，报告真实用户会遇到的问题，并将修复方案交给 flow-generator 处理。

当您的应用仍在使用付费墙时，请使用 **migrate-placements**。它不会影响流程内容——它会读取您的付费墙版位，为每个版位创建一个流程版位，然后返回版位 ID 和需要修改的 SDK 调用。

以上工具均不能替代 [AI 编辑器](flow-ai-editor)，后者直接在流程与付费墙编辑工具内运行。Agent 技能在您的终端中运行，与您的应用代码处于同一会话。
