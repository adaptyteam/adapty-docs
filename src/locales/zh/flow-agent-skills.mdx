Agent 技能让你的 AI 工具能够通过 [Adapty CLI](developer-cli-quickstart) 或 [Adapty MCP 服务器](adapty-mcp) 操作流程，而无需使用可视化编辑器。你用自然语言描述需求，工具读取你的账户、完成操作，并在保存之前向你展示结果。

四种技能各司其职：一种用于创建和修改流程，一种用于检查流程是否可以安全发布，一种用于检查商店是否会接受该流程，还有一种用于将仍在使用付费墙的应用迁移到流程版位。这四种技能均包含在 [Adapty 插件](manage-adapty-with-ai)中，安装一次即可全部使用。

当你明确知道需要做什么改动时，请使用 **flow-generator**——比如添加新的语言区域、重写文案、增删页面或调整分支逻辑。它会编辑配置并保存草稿供你审核，不会自动发布。

当你想了解某个流程是否已完善时，请使用 **flow-audit**。它会读取该流程及你的产品目录，报告真实用户可能遇到的问题，并将修复任务交给 flow-generator 处理。

在提交 App Store 或 Google Play 审核之前，请使用 **[paywall-compliance](paywall-compliance-skill)**。它会根据应用商店规则和订阅消费者法律，检查流程、截图或应用代码，并附上近期开发者反馈的拒审原因。

当您的应用仍在运行付费墙时，请使用 **migrate-placements**。它不会触碰流程内容——它会读取您的付费墙版位，为每个版位创建一个流程版位，然后将版位 ID 和需要修改的 SDK 调用交给您。

以上这些都不能替代 [AI 编辑器](flow-ai-editor)，它在流程与付费墙编辑工具内部运行。而技能则在您自己的 AI 工具中运行：一个 AI 编程助手，与您的应用代码处于同一会话中，或在 claude.ai 中运行。
