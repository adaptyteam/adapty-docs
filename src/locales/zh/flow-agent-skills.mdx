Agent 技能让你的 AI 工具能够通过 [Adapty CLI](developer-cli-quickstart) 或 [Adapty MCP 服务器](adapty-mcp) 操作流程，而无需使用可视化编辑器。你用自然语言描述需求，工具读取你的账户、完成操作，并在保存之前向你展示结果。

三个技能各司其职：一个负责构建和修改流程，一个负责检查流程是否可以安全发布，一个负责将仍在使用付费墙的应用迁移到流程版位。三者都包含在 [Adapty 插件](manage-adapty-with-ai)中，安装一次即可全部获得。

<CustomDocCardList />

当你清楚自己需要哪些改动时，请使用 **flow-generator**——添加新语言、改写文案、增删页面、重新连接分支。它会编辑配置并保存草稿等待你审阅，不会自动发布。

当你想检查某个流程是否已完成时，请使用 **flow-audit**。它会读取流程和你的产品目录，报告真实用户会遇到的问题，并将修复任务交给 flow-generator。

当你的应用仍在使用付费墙时，请使用 **migrate-placements**。它不会修改流程内容——它会读取你的付费墙版位，为每个版位创建对应的流程版位，然后将版位 ID 和需要更改的 SDK 调用交给你。

以上这些都不能替代 [AI 编辑器](flow-ai-editor)——后者直接在流程与付费墙编辑工具内部运行。而 agent 技能则在你自己的 AI 工具中运行：一个代码智能体，与你的应用代码处于同一会话中，或在 claude.ai 中使用。
