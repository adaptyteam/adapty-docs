欢迎！我们致力于让应用内购买变得轻松简单 🚀

我们打造了 [Adapty Capacitor SDK](https://github.com/adaptyteam/AdaptySDK-Capacitor/)，帮你省去应用内购买的繁琐工作，让你专注于最擅长的事——开发出色的应用。以下是我们为你处理的一切：

- 开箱即用地处理购买、票据验证和订阅管理
- 无需更新应用即可创建和测试付费墙
- 零配置即可获得详细的购买分析——同期群、LTV、流失率和漏斗分析一应俱全
- 跨会话和设备始终保持用户订阅状态最新
- 只需一行代码即可将应用与营销归因和分析服务集成

:::note
在深入代码之前，你需要先将 Adapty 与 App Store Connect 和 Google Play Console 集成，然后在看板中配置产品。请先查看我们的[快速入门指南](quickstart)完成所有配置。
:::

## 主要概念 \{#main-concepts\}

在深入代码之前，让我们先了解 Adapty 的核心概念。

Adapty 方案的精妙之处在于：只有版位是硬编码在应用中的。其他一切——产品、付费墙设计、定价和优惠——都可以在不更新应用的情况下，通过 Adapty 看板灵活管理：

1. **产品** - 应用内可供购买的任何内容——订阅、消耗型商品或永久授权。

2. **流程与付费墙** - 将产品与配置绑定，并挂载到版位上。有两种构建方式，详见[流程与付费墙](flows-and-paywalls)：
   - **[流程与付费墙编辑工具](adapty-flow-builder)** - 可视化无代码界面。Adapty 负责渲染界面并处理购买流程。
   - **[自定义付费墙](paywalls)** - 无可视化配置；你需要在自己的代码中构建界面，并手动调用 `makePurchase`。详见[实现自定义付费墙](capacitor-quickstart-manual)。

   在 SDK 代码中，两种方式都通过同一个 `getFlow` 方法获取。

3. **版位** - 用户旅程中你希望展示流程或付费墙的关键位置。版位代表了你的变现策略中"在哪里"和"什么时候"的问题。常见版位包括：
   - `main` - 主付费墙位置
   - `onboarding` - 在用户引导流程中展示
   - `settings` - 可从应用设置中访问

   初次集成时，先从 `main` 或 `onboarding` 等基础版位入手，然后再考虑应用中还有哪些地方的用户可能准备好进行购买。

4. **Profile（用户画像）** - 当用户购买产品后，其用户画像将被分配一个**访问等级**，你可以通过它来控制付费功能的访问权限。
