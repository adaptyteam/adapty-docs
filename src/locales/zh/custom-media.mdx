付费墙编辑工具的 **Media** 分类下包含三种媒体元素类型：Image（图片）、Video（视频）和 Icon（图标）。

:::tip
如需让图片或视频铺满整个屏幕（包括刘海和 Home 指示器后面的区域），请将其定位方式设置为固定，将所有偏移量设为 0，并勾选 **Ignore safe area**。详见[布局与定位](manage-paywall-ui-elements#ignore-safe-area)。
:::

## 图片 \{#image\}

上传 `.JPG`、`.PNG` 或 `.WEBP` 格式的文件，大小不超过 20 MB。

不支持动态 GIF 和 WEBP。如需添加动画效果，请改用 [视频](#video) 元素。

图片元素可以为每种语言设置不同的图片，但不支持深色主题切换。如需根据深色模式显示不同图片，请[创建包含图片图层的颜色样式](builder-reusable-styles#create-a-color-style)，分别对应两种主题，然后[添加容器并将该样式设为其背景](paywall-dark-mode#recipe-add-an-image-that-changes-with-the-theme)。

:::tip
要将内容叠加在全屏图片上，可以用屏幕背景和滑动面板[构建一个主视觉图片](paywall-head-picture#use-a-background-as-a-hero-image)。
:::

- **Content mode** — 控制图片填充容器的方式（在设置图片高度时生效）。详见[图片尺寸](#image-sizing)。
- **Use custom media ID** — 详见下方的[自定义媒体 ID](#custom-media-id)。

### 图片尺寸 \{#image-sizing\}

图片有其固有比例，而你设置的容器尺寸可能与之不符。先设置宽度，再决定高度：

- **自动高度**。图片保持原有比例：高度由所设宽度自动推算。**内容模式**会随之关闭，因为无需裁剪。
- **固定或填充高度**。容器拥有独立的比例，此时**内容模式**用于处理尺寸不匹配的情况：
  - **适应**。将整张图片缩放至容器内，留有空白区域。
  - **填充**。裁剪超出部分。默认选项。

要让图片在任意屏幕宽度下都不被裁剪，请将宽度设置为 **Fill**，高度设置为 **Auto**。如果固定高度，顶部和底部的裁剪效果会随屏幕尺寸变化而改变。

## 视频 \{#video\}

上传 `.MP4` 或 `.WEBM` 文件，大小不超过 50 MB，时长不超过 30 秒。视频最低分辨率为 640x640 像素。

- **Aspect** — 控制视频在设置高度后填充容器的方式。请参阅[视频尺寸](#video-sizing)。
- **Loop** — 循环播放视频，默认开启。
- **Use custom media ID** — 请参阅下方[自定义媒体 ID](#custom-media-id)。

视频在编辑器预览中不会播放——画布仅显示静帧。在设备上运行时，视频默认静音播放。开启 Loop 后，视频将无限循环。

Video 元素可以为每种语言区域设置不同的视频，但不支持深色主题。如需在深色模式下切换视频，请[创建一个包含视频图层的颜色样式](builder-reusable-styles#create-a-color-style)，分别对应每种主题。然后[添加一个容器并将该样式设为其背景](paywall-dark-mode#recipe-add-an-image-that-changes-with-the-theme)。

### 视频大小调整 \{#video-sizing\}

视频有其自身的比例，而你为其设置的容器尺寸可能与之不符。高度属性决定了处理方式：

- **Hug height**。高度跟随视频自身比例自动调整。
- **Fixed 或 Fill height**。通过 **Aspect** 属性解决尺寸不匹配的问题：
  - **Fit**。将整个视频缩放至容器内，多余空间留白。
  - **Fill**。裁剪超出部分。默认设置。

当 Adapty 无法读取上传视频的尺寸时，会弹出警告："Could not determine video dimensions. Set a fixed height to ensure the video displays correctly."请为视频设置固定高度，或确保其容器具有固定高度，否则视频高度可能会折叠为 0。

### 视频播放结束时触发动作 \{#trigger-an-action-when-the-video-ends\}

:::link
主要文章：[动作](onboarding-actions)
:::

视频元素支持 **On playback finished** 触发器，当视频播放到结尾时触发。在 **Interactions** 面板中进行设置，可跳转到其他页面、显示 CTA，或执行任何其他动作。

## 图标 \{#icon\}

<ZoomImage id="builder-icon-selection.webp" width="300px" float="right" alt="Icon picker with the Tabler Icons library" />

从内置的 [Tabler Icons](https://tabler.io/icons) 图标库中选择，提供两种视觉风格的数千个图标：

- **Stroke** — 仅描边轮廓。
- **Filled** — 实心填充。

在选择器中通过关键词搜索图标。在 **Color** 选择器中设置图标颜色——可选择已保存的[颜色样式](builder-reusable-styles#color-styles)或自定义颜色。每个图层样式只能应用单一纯色。

## 本地化媒体资源 \{#localize-media\}

:::link
主要文章：[添加语言](add-paywall-locale-in-adapty-paywall-builder)
:::

以下元素和图层支持为每种语言单独上传不同的文件：

- 图片和视频元素。
- [填充](builder-styling#fill)中的图片和视频图层，例如屏幕背景。
- [颜色样式](builder-reusable-styles#color-styles)的图片和视频图层，可分别为浅色或深色版本单独设置。

上传本地化文件的步骤：

1. 如果 **Localizations** 面板已打开，请先关闭它以显示属性面板。
2. 在[底部工具栏](builder-ui#view-controls-bottom-toolbar)中，将 **Locale** 设置为目标语言。
3. 选中元素，或点击预览区域的空白处以选择屏幕背景。
4. 在属性面板中上传本地化文件。
5. 将 **Locale** 重新设置回默认语言，以便后续编辑应用于默认语言。

对于颜色样式，在激活目标语言时[替换样式中的图片或视频](builder-reusable-styles#images-and-videos)。

在没有独立文件的语言区域中，用户将看到默认语言区域的文件。对于颜色样式，每个版本会单独回退到默认语言区域。你也可以在 [**Localizations** 面板](add-paywall-locale-in-adapty-paywall-builder#localize-images-and-videos)中为每个语言区域上传文件。

### 限制 \{#limitations\}

图标和自定义媒体 ID 无法本地化。如需本地化具有自定义媒体 ID 的图片或视频，请使用该 ID 在运行时[替换为本地化文件](#custom-media-id)。

## 自定义媒体 ID \{#custom-media-id\}

:::important
你可以为[填充](builder-styling#fill)中的图片或视频（例如[屏幕背景](paywall-head-picture)）设置自定义媒体 ID。
:::

为图片或视频元素添加自定义媒体 ID，即可在运行时通过应用代码动态替换它。适用于[个性化视觉内容](get-pb-paywalls#customize-assets)——例如，显示用户选择的头像。

在 Flow & Paywall Builder 中上传的媒体文件作为备用内容。如果你的代码在运行时未提供该 ID 对应的媒体，则会显示备用内容。

自定义媒体 ID 只能将文件替换为同类型的文件——图片换图片，视频换视频。若类型不匹配，则显示备用内容。

要在图片或视频元素上启用自定义媒体 ID：

1. 勾选上传区域下方的 **Use custom media ID** 复选框。
2. 输入媒体 ID。
3. 上传备用图片或视频。

在应用代码中，通过 ID 获取媒体资源——请参阅 [自定义资源](get-pb-paywalls#customize-assets) 了解 SDK API。

:::tip
要让流程首屏即时渲染，请为首屏中较大的图片和视频添加自定义媒体 ID，并让开发者将这些文件打包到应用中。详见[从应用包中显示首屏媒体资源](ios-optimize-paywall-fetching#show-first-screen-media-from-the-app-bundle)。
:::
