恢复购买是一项功能，允许用户重新获取此前购买的内容（如订阅或应用内购买），且无需再次付费。这项功能尤其适用于以下场景：用户卸载后重新安装了应用，或换了新设备，希望在无需重复付费的情况下访问之前购买的内容。

:::note
如果你在编辑工具中构建了页面，则无需手动恢复购买。只需将还原控件连接好——在 Flow & 付费墙编辑工具中使用 **Restore purchases** 操作，或在旧版编辑工具中使用还原链接或按钮——SDK 会自动完成恢复。
:::

如果你自行构建了页面，请调用 `.restorePurchases()` 方法：

```kotlin showLineNumbers

Adapty.restorePurchases().onSuccess { profile ->
    if (profile.accessLevels["YOUR_ACCESS_LEVEL"]?.isActive == true) {
        // successful access restore
    }
}.onError { error ->
    // handle the error
}
```

响应参数：

| 参数 | 描述 |
|---------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Profile** | <p>一个 [`AdaptyProfile`](https://kmp.adapty.io//////adapty/com.adapty.kmp.models/-adapty-profile/) 对象。该模型包含有关访问等级、订阅和非订阅购买的信息。</p><p>检查**访问等级状态**以确定用户是否有权访问该应用。</p> |
