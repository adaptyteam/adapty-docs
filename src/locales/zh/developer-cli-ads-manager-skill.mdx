`ads-manager` 技能让 AI 编程工具能够通过 [Adapty CLI](developer-cli-ads-manager) 操作你的 Apple Ads 账户。用自然语言提问，它会自行判断需要执行哪些命令，先读取账户数据，再将写入操作提交给你确认，然后才实际发送到 Apple。

技能是 AI 工具按需加载的一组指令。这个技能涵盖了 Ads Manager 中最容易出错的部分：每个标识符对应哪个参数，每个列表支持哪些过滤条件，一次批量操作最多可以提交多少关键词，以及哪些调用会产生费用。

## 它处理的内容 \{#what-it-handles\}

- **读取性能**：针对每个问题选择最合适的单次调用，而非逐页翻查结果。它知道"前 N 名"类问题只需一次有序调用，统计实体数量也根本不需要调用指标接口。
- **结构变更**：按正确顺序创建和更新广告系列、广告组、广告及关键词，写入子实体前先读取父实体。
- **关键词管理**：批量添加关键词并调整出价，同时将搜索词转化为关键词和否定关键词。
- **自动化规则**：设置基于规则的自动化，并在影响实际出价前先进行模拟运行。
- **竞品调研**：获取竞品应用所竞价的关键词。

## 它不会做什么 \{#what-it-will-not-do\}

该技能将每次写入都视为不可逆操作，因为确实如此——CLI 没有删除功能，且更改会在几秒内同步到 Apple。

- 在写入之前先读取，而不是猜测 ID 或预算。
- 在任何涉及花费的命令执行前都会先询问确认，并且当您亲自运行命令时，保留 CLI 自身的确认提示。
- 在链式写入的每次操作上固定一个幂等键，这样在结果不明确后重新运行时不会创建第二个广告系列。
- 优先采用小批量方式，以便 Apple 返回部分拒绝时仍易于查看。

:::note
该功能仅提供建议并准备待执行命令。读取数据指标和模拟运行不产生任何费用，但对线上广告账户的任何变更操作，均由您自行审核批准后方可执行。
:::

## 与 AI Agent 的区别 \{#how-it-differs-from-the-ai-agent\}

Adapty Ads Manager 在看板中还内置了一个 [AI Agent](ads-manager-ai-agent)。两者面向不同的使用需求：

| | AI Agent | ads-manager skill |
|---|---|---|
| 运行位置 | Adapty 看板 | 你的终端，在 AI 编码工具中 |
| 功能 | 分析并给出建议 | 分析、给出建议，并执行命令 |
| 配置 | 无需配置 | 需要 Adapty CLI 和该 skill |

如果你想了解账户中正在发生什么，使用 AI Agent；如果你还希望直接执行变更，则使用 skill。
