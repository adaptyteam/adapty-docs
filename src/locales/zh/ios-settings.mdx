**App settings** 中的 [**iOS SDK**](https://app.adapty.io/settings/ios-sdk) 标签页保存了您应用的 App Store 凭证。如需逐一填写，请参阅[配置 App Store 集成](app-store-connection-configuration)。

<ZoomImage id="app-settings-ios-sdk.webp" width="700px" alt="App settings 中的 iOS SDK 标签页" />

| 板块 | 内容及 Adapty 所需原因 | 配置位置 |
|---|---|---|
| **SDK status** | 应用中是否已安装 Adapty SDK | [安装 Adapty SDK](installation-of-adapty-sdks) |
| **Bundle ID** | 应用的 Bundle ID，用于处理购买 | [填写 Bundle ID 和 Apple App ID](app-store-connection-configuration#enter-the-bundle-id-and-apple-app-id) |
| **In-app purchase API (StoreKit 2)** | 用于验证购买的 In-App Purchase 密钥 | [将 In-App Purchase 密钥添加到 Adapty](generate-in-app-purchase-key) |
| **App Store Connect shared secret** | 应用专属共享密钥，用于验证购买凭据并在 App Store Connect 中创建产品 | [填写应用专属共享密钥](app-store-connection-configuration#enter-the-app-specific-shared-secret) |
| **App Store server notifications** | 接收 Apple 订阅事件的 URL，以及可选的服务器 URL（Adapty 会将事件转发至此） | [启用 App Store 服务器通知](enable-app-store-server-notifications) |
| **Apple Retention Messaging API** | 申请访问 Retention Messaging API 时提交给 Apple 的 URL | [设置 Retention Messaging](retention-messaging-setup) |
| **App Store promotional offers** | 用于签署促销活动的 In-App Purchase 密钥 ID 和文件 | [将 In-App Purchase 密钥添加到 Adapty](generate-in-app-purchase-key) |
| **App Store Connect API key** | 来自 App Store Connect **Team Keys** 标签页的密钥，用于在其中创建产品并同步产品状态和价格 | [将 App Store Connect API 密钥添加到 Adapty](app-store-connect-api-key) |
| **Apple App ID** | 应用的 Apple ID，用于在 App Store Connect 中查找和创建产品等操作 | [填写 Bundle ID 和 Apple App ID](app-store-connection-configuration#enter-the-bundle-id-and-apple-app-id) |
