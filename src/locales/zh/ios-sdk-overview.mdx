欢迎！我们致力于让应用内购买变得轻松简单 🚀

我们构建了 Adapty iOS SDK，让应用内购买不再繁琐，让您专注于最擅长的事——打造出色的应用。以下是我们为您处理的一切：

- 开箱即用地处理购买、收据验证和订阅管理
- 无需更新应用，即可创建和测试流程与付费墙
- 零配置获取详细的购买数据分析——包含同期群、LTV、流失率和漏斗分析
- 跨应用会话和设备始终保持用户订阅状态最新
- 仅需一行代码，即可将应用与营销归因和数据分析服务集成

:::note
在深入代码之前，你需要先将 Adapty 与 App Store Connect 集成，并在看板中配置产品。请先查看我们的[快速入门指南](quickstart)完成所有配置。
:::

## 核心概念 \{#main-concepts\}

在开始编写代码之前，让我们先了解 Adapty 的核心概念。

Adapty 方案的妙处在于：只有版位是硬编码在应用中的。其余所有内容——产品、付费墙设计、定价和优惠——都可以在 Adapty 看板中灵活管理，无需更新应用：

1. [**产品**](product) - 应用中可供购买的任何内容，包括订阅、消耗型商品或永久授权。

2. **流程与付费墙** - 将产品与配置捆绑，并附加到版位。有两种构建方式，详见[流程与付费墙](flows-and-paywalls)：
   - **[流程与付费墙编辑工具](adapty-flow-builder)** - 可视化的无代码界面。Adapty 负责渲染界面并为您处理购买流程。
   - **[自定义付费墙](paywalls)** - 无可视化配置；您需要在自己的代码中构建界面，并自行调用 `makePurchase`。参见[实现自定义付费墙](ios-quickstart-manual)。

   在 SDK 代码中，两种方式均通过同一个 `getFlow` 方法获取。

3. [**版位**](placements) - 用户旅程中你希望展示流程或付费墙的关键节点。可以把版位理解为变现策略的"在哪里"和"什么时候"。常见版位包括：
   - `main` - 主付费墙位置
   - `onboarding` - 在用户引导流程中展示
   - `settings` - 从应用设置中访问

   第一次集成时，先从 `main` 或 `onboarding` 等基础版位入手，之后再[思考应用中还有哪些地方的用户可能准备好付费](choose-meaningful-placements)。

4. [**用户画像**](profiles-crm) - 当用户购买产品时，其用户画像会被分配一个**访问等级**，你可以通过它来控制用户对付费功能的访问权限。
