Adapty Attribution 可帮助您将广告支出与订阅收入关联起来，适用于 web 转 app 的推广活动，让您在同一个地方全面了解应用的整体收益情况。

要在 Adapty Attribution 中查看收入数据，您需要先在 Adapty 看板中启用该集成。无需传入任何 API 密钥、令牌或标识符，只需更新并配置 Adapty SDK 即可。

:::important
Adapty Attribution 适用于：
- iOS、Android 和 Flutter SDK 3.9.1 及更高版本。
- React Native 和 Capacitor SDK 3.10.0 及更高版本。
- Unity SDK 3.12.0 及更高版本。
- Kotlin Multiplatform SDK 3.15.0 及更高版本。

从 SDK 4.1 版本开始，Adapty Attribution 在 SDK 中默认关闭。[在你的应用代码中启用它](#step-1-enable-adapty-attribution-in-the-sdk)。
:::

## 开始之前 \{#before-you-start\}

要将您的收入数据与广告系列效果关联起来，请让 Adapty 追踪您的购买记录：

- 如果您**已经使用 Adapty 实现了应用内购买**，则无需在此阶段进行任何其他操作。
- 如果您**尚未实现应用内购买并希望使用 Adapty**，请按照[快速入门指南](quickstart)中的步骤，将购买处理委托给 Adapty。
- 如果您**已经在不使用 Adapty 的情况下实现了应用内购买**，且不打算使用 Adapty 的核心功能，请[以观察者模式为您的平台安装 Adapty SDK](implement-observer-mode)。在此阶段，您只需将 SDK 添加到项目中，以启用观察者模式的方式激活它，并上报交易记录。

此设置可实现网页到应用的归因：
- 当用户安装您的应用时，Adapty SDK 会上报安装事件，Adapty Attribution 即可将其与广告活动进行匹配。
- Adapty SDK 能够感知应用内所有与收入相关的事件，并将其归因到网页广告活动。

## 第一步：在 SDK 中启用 Adapty 归因 \{#step-1-enable-adapty-attribution-in-the-sdk\}

从 Adapty SDK 4.1 版本开始，Adapty 归因功能默认禁用。如需让 SDK 注册安装事件并向应用传递安装详情，请在激活 SDK 时启用该功能：

<Tabs groupId="current-os" queryString>
<TabItem value="swift" label="Swift" default>

```swift showLineNumbers
let configurationBuilder = AdaptyConfiguration
    .builder(withAPIKey: "YOUR_PUBLIC_SDK_KEY")
    .with(adaptyAttributionEnabled: true)
```

</TabItem>
<TabItem value="kotlin" label="Kotlin">

```kotlin showLineNumbers
val config = AdaptyConfig.Builder("YOUR_PUBLIC_SDK_KEY")
    .withAdaptyAttributionEnabled(true)
    .build()

Adapty.activate(applicationContext, config)
```

</TabItem>
<TabItem value="java" label="Java">

```java showLineNumbers
AdaptyConfig config = new AdaptyConfig.Builder("YOUR_PUBLIC_SDK_KEY")
    .withAdaptyAttributionEnabled(true)
    .build();

Adapty.activate(getApplicationContext(), config);
```

</TabItem>
<TabItem value="rn" label="React Native (TS)">

```typescript showLineNumbers
adapty.activate('YOUR_PUBLIC_SDK_KEY', {
  adaptyAttributionEnabled: true,
});
```

</TabItem>
<TabItem value="kmp" label="Kotlin Multiplatform">

```kotlin showLineNumbers
val config = AdaptyConfig
    .Builder("YOUR_PUBLIC_SDK_KEY")
    .withAdaptyAttributionEnabled(true)
    .build()

Adapty.activate(configuration = config)
```

</TabItem>
<TabItem value="capacitor" label="Capacitor (TS)">

```typescript showLineNumbers
await adapty.activate({
  apiKey: 'YOUR_PUBLIC_SDK_KEY',
  params: {
    adaptyAttributionEnabled: true,
  }
});
```

</TabItem>
<TabItem value="flutter" label="Flutter (Dart)">

```dart showLineNumbers
await Adapty().activate(
  configuration: AdaptyConfiguration(apiKey: 'YOUR_PUBLIC_SDK_KEY')
    ..withAdaptyAttributionEnabled(true)
);
```

</TabItem>
</Tabs>

在低于 4.1 的 SDK 版本中，Adapty 归因会自动启用——无需修改代码。

为了让 Adapty 将安装与广告点击相匹配，请在应用启动时（从第一次启动开始）激活 SDK。SDK 在激活后才会上报安装信息，因此延迟激活会导致上报延迟。

## 第二步：打开 Adapty Attribution \{#step-2-open-adapty-attribution\}

:::important
如果点击 Adapty 图标后没有出现 **Attribution**，请在浏览器设置中清除 adapty.io 的 Cookie 和站点数据，然后重新加载页面。
:::

点击页面顶部的 Adapty 图标，选择 **Attribution**。

<ZoomImage id="product-switcher.webp" width="500px" alt="Adapty product switcher" />

订阅事件会自动流入 Adapty Attribution。完成第三步连接数据源后，推广活动数据便会显示出来。

要暂停事件推送，请在 Adapty 看板中打开 **Integrations > Adapty**，然后关闭该开关。

## 第三步：连接广告平台并添加跟踪链接 \{#step-3-connect-your-ad-platform-and-add-tracking-links\}

Adapty 通过跟踪链接将应用安装与广告活动数据关联起来。如需在 Adapty Attribution 中衡量广告效果：

- **跳转至 App Store 或 Google Play 的广告**：将跟踪链接设为目标 URL。
- **跳转至网页漏斗的广告**：[为其 URL 添加 Adapty 参数标记](ua-tag-ad-urls)。

如果使用的是 Google Ads 广告活动，请改为参阅[将 Google Ads 与 Adapty Attribution 集成](ua-google-ads)。

如果您在多个平台投放广告，请分别为每个平台设置跟踪链接。

Adapty 与广告平台的对接方式有两种：

- **原生集成（Meta Ads、TikTok Ads、Google Ads）。** Adapty 直接与广告平台连接。追踪链接自动生成，广告系列参数根据链接所在的投放位置动态填充。同一条链接可跨不同广告系列、广告组或创意复用，Adapty 会自动获取正确的广告系列数据和广告支出。

- **仅跟踪链接（其他所有广告平台）。** Adapty 不与广告平台直接连接。跟踪链接需手动创建，所有推广活动参数必须在创建链接时明确定义。这些平台不提供广告支出数据。对于 Meta Ads、TikTok Ads 和 Google Ads 推广活动，请改用原生集成。

<Tabs>
<TabItem value="meta" label="Meta Ads" default>
要为 Meta Ads 创建跟踪链接：
1. 在 Adapty Attribution 看板中前往 [Integrations > Meta](https://app.adapty.io/ua/integrations/facebook/accounts)，然后点击 **Continue with Facebook**。

<ZoomImage id="ua-connect-meta.webp" width="700px" />
2. 使用你的 Facebook 账号登录，然后点击 **Continue**。

<ZoomImage id="ua-fb-sign.webp" width="500px" />

3. 查看所申请的权限，然后点击 **Save**。
4. 在顶部导航栏中选择要推广的应用，切换到 **Web Campaigns** 标签页，然后点击 **Create configuration**。

<ZoomImage id="ua-new-campaign.webp" width="500px" />

5. 在 **General** 标签页中，展开 **iOS** 和/或 **Android** 部分，粘贴 App Store 和/或 Google Play 的应用链接，然后点击 **Save**。

<ZoomImage id="ua-url.webp" width="900px" />

6. 复制**一个链接**或特定平台链接的 **Click link** 字段值。然后在 Meta Ads Manager 中打开您的广告，将此链接粘贴为目标 URL。

:::important
为了帮助您的 Meta 广告顺利通过审核，请在 `?` 处将链接拆分。在 **Website URL** 字段中，粘贴 `?` 之前的部分，例如 `https://api-ua.adapty.io/api/v1/attribution/c/YOUR_CODE`。每个网页广告系列都有自己的代码，因此请从您正在设置的广告系列中复制该值，而非其他广告。将 `?` 之后的所有内容粘贴到 **Tracking** 部分的 **URL parameters** 字段中。请参阅 Meta 广告指南中的[创建广告](meta-create-campaign#step-5-create-ads)。
:::

7. 现在，当您在 Meta Ads 中投放广告后，其数据将可在 Adapty Attribution 看板中进行分析。
</TabItem>
<TabItem value="tiktok" label="TikTok for Business">
要为 TikTok for Business 创建追踪链接：
1. 在 Adapty Attribution 看板中前往 [Integrations > TikTok Ads](https://app.adapty.io/ua/integrations/tiktok/accounts)，然后点击 **Continue with TikTok**。
   <ZoomImage id="ua-connect-tiktok.webp" width="700px" />
2. 使用您的 TikTok 账号登录，然后点击 **Continue**。

3. 查看所请求的权限，然后点击 **Save**。

    <ZoomImage id="ua-tiktok-sign.webp" width="500px" />
4. 在标题栏中，选择要推广的应用。然后切换到 **Web Campaigns** 标签页，点击 **Create configuration**。

    <ZoomImage id="ua-new-campaign-tiktok.webp" width="500px" />

5. 在 **General** 标签页中，展开 **iOS** 和/或 **Android** 部分，粘贴 App Store 和/或 Google Play 应用链接。然后点击 **Save**。

    <ZoomImage id="ua-url.webp" width="900px" />

6. 复制**一个链接**或特定平台链接的 **Click link** 字段值。然后在 TikTok Ads Manager 中创建广告时，将此值粘贴到 **Destination URL** 字段中。这样 Adapty 就能将安装和购买行为与 TikTok 广告关联起来。请参阅 TikTok 广告指南中的[添加广告内容](tiktok-create-campaign#step-5-add-ad-content)。

    <ZoomImage id="ua-lnk.webp" width="900px" />

</TabItem>
<TabItem value="others" label="其他广告平台">
为其他广告平台创建追踪链接：

1. 在 Adapty Attribution 看板中，打开 **Integrations**，在 **Network** 分组下选择 **Custom** 卡片，然后点击 **Create link**。

    <ZoomImage id="new-tracking-link.webp" width="700px" />

2. 从列表中选择您的应用，然后点击 **Next**。

    <ZoomImage id="ua-choose-app.webp" width="700px" />

3. 填写链接参数，以便与您想要追踪的广告活动和广告相匹配。
4. 默认情况下，您创建的是 One Link。它会自动检测用户的平台，并在追踪点击后将其重定向到 App Store 或 Google Play。

    如果您希望为每个平台使用单独的重定向 URL，请取消选中 **One Link** 复选框，并手动提供各平台对应的应用商店链接。

    <ZoomImage id="one-link.webp" width="700px" />

5. 点击 **Create**。
6. 打开您的追踪链接页面，从以下某个部分复制 **Click link**：
    - **One link** – 使用此链接追踪点击并自动将用户重定向到对应的应用商店。
    - **iOS link** 或 **Android link** — 如果您希望为每个应用商店使用独立链接，可选择对应的平台专属版本。
7. 前往您的广告平台，将该链接粘贴为广告目标 URL。

</TabItem>
</Tabs>

## 第四步：启动网页转应用活动并查看结果 \{#step-4-launch-your-web-to-app-campaign-and-view-results\}

活动上线后，用户开始安装应用，Adapty 便会将安装量和收入归因到对应的活动。

在 [Adapty 归因分析看板](ua-analytics)中，您可以查看以下活动级别的数据图表：
- 安装量与转化率
- 订阅与购买收入
- 按广告平台、活动、广告组和素材细分的效果数据

安装数据大约 10 分钟后会出现在看板中，购买数据则大约需要 30 分钟。广告花费数据适用于具有原生集成的平台，Adapty 每 4 小时刷新一次。
