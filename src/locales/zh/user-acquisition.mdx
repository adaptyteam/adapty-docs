Adapty Attribution 可帮助您将广告支出与订阅收入关联起来，适用于 web 转 app 的推广活动，让您在同一个地方全面了解应用的整体收益情况。

要在 Adapty Attribution 中查看收入数据，您需要先在 Adapty 看板中启用该集成。无需传入任何 API 密钥、令牌或标识符，只需更新并配置 Adapty SDK 即可。
:::important
Adapty Attribution 适用于：
- iOS、Android 和 Flutter SDK 3.9.1 及更高版本。
- React Native 和 Capacitor SDK 3.10.0 及更高版本。
- Unity SDK 3.12.0 及更高版本。
- Kotlin Multiplatform SDK 3.15.0 及更高版本。

从 SDK 4.1 版本开始，Adapty Attribution 在 SDK 中默认关闭。[在你的应用代码中启用它](#step-1-enable-adapty-attribution-in-the-sdk)。
:::

## 开始之前 \{#before-you-start\}

要将您的收入数据与广告系列效果关联起来，请让 Adapty 追踪您的购买记录：
- 如果您**已经通过 Adapty 实现了应用内购买**，此阶段无需进行任何其他操作。
- 如果您**尚未实现应用内购买且希望使用 Adapty**，请按照[快速入门指南](quickstart)完成相关步骤，将购买处理委托给 Adapty。
- 如果您**已经在不使用 Adapty 的情况下实现了应用内购买**，且不打算迁移至 Adapty，请[以观察者模式为您的平台安装 Adapty SDK](implement-observer-mode)。在此阶段，您只需将 SDK 添加到项目中，以启用观察者模式的方式激活它，并上报交易记录：
此设置可实现网页到应用的归因：
- 用户安装应用后，Adapty SDK 会从链接参数中获取安装详情，从而让 Adapty 归因功能获取推广活动信息。
- Adapty SDK 能够感知应用内所有与收入相关的事件，并将其归因到网页推广活动。
## 第一步：在 SDK 中启用 Adapty 归因 \{#step-1-enable-adapty-attribution-in-the-sdk\}

从 Adapty SDK 4.1 版本开始，Adapty 归因功能默认禁用。如需让 SDK 注册安装事件并向应用传递安装详情，请在激活 SDK 时启用该功能：

<Tabs groupId="current-os" queryString>
<TabItem value="swift" label="Swift" default>

```swift showLineNumbers
let configurationBuilder = AdaptyConfiguration
    .builder(withAPIKey: "YOUR_PUBLIC_SDK_KEY")
    .with(adaptyAttributionEnabled: true)
```

</TabItem>
<TabItem value="kotlin" label="Kotlin">

```kotlin showLineNumbers
val config = AdaptyConfig.Builder("YOUR_PUBLIC_SDK_KEY")
    .withAdaptyAttributionEnabled(true)
    .build()

Adapty.activate(applicationContext, config)
```

</TabItem>
<TabItem value="java" label="Java">

```java showLineNumbers
AdaptyConfig config = new AdaptyConfig.Builder("YOUR_PUBLIC_SDK_KEY")
    .withAdaptyAttributionEnabled(true)
    .build();

Adapty.activate(getApplicationContext(), config);
```

</TabItem>
</Tabs>

在 SDK 4.1 以下版本中，Adapty Attribution 会自动启用，无需修改代码。

## 第 2 步：打开 Adapty Attribution \{#step-2-open-adapty-attribution\}

:::important
如果点击 Adapty 图标后未看到 **Attribution**，请在浏览器设置中清除 adapty.io 的 Cookie 和网站数据，然后重新加载页面。
:::

点击页头中的 Adapty 图标，选择 **Attribution**。

<ZoomImage id="product-switcher.webp" width="500px" alt="Adapty product switcher" />

订阅事件会自动开始流入 Adapty Attribution。完成第 3 步并连接数据源后，广告活动数据将随之显示。

要暂停事件推送，请在 Adapty 看板中打开 **Integrations > Adapty**，然后关闭该开关。

## 第三步：连接广告平台并添加追踪链接 \{#step-3-connect-your-ad-platform-and-add-tracking-links\}

Adapty 通过追踪链接将应用安装与广告系列数据关联起来。
在您希望通过 Adapty Attribution 衡量效果的每个广告系列中，都必须将追踪链接设为目标 URL。

如果您在多个平台上投放广告，请分别为每个平台配置追踪链接。

Adapty 与广告平台的对接方式有以下两种：

- **原生集成（Meta Ads、TikTok Ads）。** Adapty 直接与广告平台对接。追踪链接自动生成，广告系列参数根据链接的使用场景动态填充。你可以在不同广告系列、广告组或素材中复用同一条链接，Adapty 会自动获取正确的广告系列数据和广告消耗。

- **仅限跟踪链接（所有其他广告平台）。** Adapty 不会直接连接广告平台。跟踪链接需手动创建，所有推广活动参数都必须在创建链接时明确定义。这些平台不支持广告支出数据。

<Tabs>
<TabItem value="meta" label="Meta Ads" default>
要为 Meta Ads 创建跟踪链接：
1. 前往 Adapty Attribution 看板中的 [Integrations > Meta](https://app.adapty.io/ua/integrations/facebook/accounts)，点击 **Continue with Facebook**。

<ZoomImage id="ua-connect-meta.webp" width="700px" />
2. 使用您的 Facebook 账号登录，然后点击 **Continue**。

<ZoomImage id="ua-fb-sign.webp" width="500px" />

3. 查看请求的权限，然后点击 **Save**。
4. 切换到 **Web campaigns** 标签页，点击 **Create campaign**。选择应用后点击 **Save**。

<ZoomImage id="ua-new-campaign.webp" width="500px" />

5. 在 **General** 标签页中，展开 **iOS** 和/或 **Android** 部分，粘贴 App Store 和/或 Google Play 应用链接。然后点击 **Save**。

<ZoomImage id="ua-url.webp" width="900px" />

6. 复制**一个链接**或特定平台链接的 **Click link** 字段值。然后在 Meta Ads Manager 中打开您的广告，将此链接粘贴为目标 URL。

:::important
在 **Website URL** 字段中，粘贴 `https://api-ua.adapty.io/api/v1/attribution/click`。将链接的其余部分粘贴到 **Tracking** 部分的 **URL parameters** 字段中。这样有助于您的 Meta 广告通过审核。请参阅[在 Meta Ads Manager 中设置广告的更多建议](meta-create-campaign)。
:::

7. 现在，当您在 Meta Ads 中投放广告后，其数据将可在 Adapty Attribution 看板中进行分析。
</TabItem>
<TabItem value="tiktok" label="TikTok for Business">
要为 TikTok for Business 创建追踪链接：
1. 在 Adapty Attribution 看板中前往 [Integrations > TikTok Ads](https://app.adapty.io/ua/integrations/tiktok/accounts)，然后点击 **Continue with TikTok**。
   <ZoomImage id="ua-connect-tiktok.webp" width="700px" />
2. 使用您的 TikTok 账号登录，然后点击 **Continue**。

3. 查看所请求的权限，然后点击 **Save**。

   <ZoomImage id="ua-tiktok-sign.webp" width="500px" />
4. 切换到 **Web campaigns** 标签页，点击 **Create campaign**。选择应用并点击 **Save**。

    <ZoomImage id="ua-new-campaign-tiktok.webp" width="500px" />

5. 在 **General** 标签页中，展开 **iOS** 和/或 **Android** 部分，粘贴 App Store 和/或 Google Play 应用 URL。然后点击 **Save**。

    <ZoomImage id="ua-url.webp" width="900px" />

6. 复制**一个链接**或特定平台链接的 **Click link** 字段值。然后，在 TikTok Ads Manager 中创建广告时，将该值粘贴到 **Advanced Settings** 部分下的 **Tracking URL** 字段中。这将使 Adapty 能够将安装和购买与 TikTok 中的广告关联起来。请参阅[在 TikTok Ads 中设置广告系列的指南](tiktok-create-campaign)。

    <ZoomImage id="ua-lnk.webp" width="900px" />
7. 现在，当您在 TikTok for Business 中投放广告后，其数据将可在 Adapty Attribution 看板中进行分析。

</TabItem>
<TabItem value="others" label="其他广告平台">
要为其他广告平台创建追踪链接：

1. 在 Adapty Attribution 看板中，从侧边栏菜单进入 **Tracking links**，然后点击 **Create link**。

    <ZoomImage id="new-tracking-link.webp" width="700px" />

2. 从列表中选择你的应用，然后点击 **Next**。

    <ZoomImage id="ua-choose-app.webp" width="700px" />

3. 填写链接参数，以便与您想要追踪的广告活动和广告相匹配。
4. 默认情况下，您创建的是 One Link。它会自动检测用户的平台，并在追踪点击后将其重定向到 App Store 或 Google Play。

    如果您希望为每个平台使用单独的重定向 URL，请取消选中 **One Link** 复选框，并手动提供各平台对应的应用商店链接。

    <ZoomImage id="one-link.webp" width="700px" />

5. 点击 **Create**。
6. 打开您的追踪链接页面，从以下某个部分复制 **Click link**：
    - **One link** – 使用此链接追踪点击并自动将用户重定向到对应的应用商店。
    - **iOS link** 或 **Android link** — 如果您希望为每个应用商店使用独立链接，可选择对应的平台专属版本。
7. 前往您的广告平台，将该链接粘贴为广告目标 URL。

</TabItem>
</Tabs>

## 第四步：启动网页转应用营销活动并查看结果 \{#step-4-launch-your-web-to-app-campaign-and-view-results\}

营销活动上线后，一旦用户开始安装你的应用，Adapty 便会将安装量和收入归因到对应的活动中。

在 [Adapty 归因分析看板](ua-analytics) 中，你可以查看以下活动层级的数据图表：
- 安装量与转化率
- 订阅及购买收入
- 按广告平台、营销活动、广告组和广告创意细分的表现数据

安装和收入事件一经从应用中收到，相关数据图表即会显示。广告支出数据适用于已完成原生集成的平台。
