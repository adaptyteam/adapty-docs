**Progress** 分类提供两种元素类型——一种用于在多屏流程中显示基于步骤的进度，另一种用于显示原地繁忙状态。

## 进度指示器 \{#progress-indicators\}

<ZoomImage id="builder-progress-indicator.webp" width="700px" alt="屏幕顶部的进度指示器，设置面板已打开" />

### 进度条样式 \{#indicator-styles\}

<ZoomImage id="flow-indicators.webp" width="300px" alt="Progress indicator variants" float="right" />

**Progress** 元素用于显示用户在多屏流程中的当前位置。该类别提供三种视觉样式：

- **Linear** — 单条进度条，随用户前进而填充。
- **Segmented** — 每步对应一段独立的进度条，逐步填充。
- **Connectors** — 带标签的圆圈通过连线串联（例如，依次显示 Step 1、Step 2、Step 3）。

### 将步骤与屏幕对应 \{#match-steps-to-screens\}

<ZoomImage id="builder-progress-indicator-settings.webp" width="280px" float="right" alt="进度指示器设置面板，包含变体选择器、每屏一段开关和屏幕下拉菜单" />

默认情况下，进度指示器会追踪流程中的每个屏幕。若只想追踪其中几个屏幕，可在 **Screens** 下拉菜单中选择。也可以打开想要排除的屏幕，取消勾选 **Include screen in progress indicator** 复选框。

如果需要更精细地控制步骤数量，可以关闭 **One segment per screen** 开关。

:::warning
步骤位置取决于屏幕列表中的顺序，而非用户实际浏览的顺序。在非线性流程中，指示器显示的步骤编号可能会跳跃或倒退。
:::

### 步骤状态 \{#step-states\}

<ZoomImage id="builder-progress-indicator-step-settings.webp" width="280px" float="right" alt="Step-level settings panel with ID, Screens, and Completed/Current/Upcoming state tabs" />

每个步骤都有三种状态——**Completed**、**Current** 和 **Upcoming**。在进度指示器中选择某个步骤，即可在右侧面板中编辑该状态的样式。使用 **Apply changes to all states** 可将当前编辑同步到另外两种状态。

修改某个步骤会影响同一指示器内的所有步骤。

### 布局与定位 \{#layout-and-positioning\}

进度指示器是一个全局元素，因此无法将其放置在[容器](builder-containers)内，也无法设置其位置——它默认使用绝对定位。当用户滚动屏幕时，指示器保持固定不动，内容在其下方滚动。

要控制指示器周围的间距，请使用 **Spacing** 区域中的 **Margin** 和 **Padding** 控件，而不是直接移动元素。如果布局显示不正确，可以同时调整指示器及其相邻元素的外边距或内边距。

## 加载器 \{#loaders\}

<ZoomImage id="flow-loaders.webp" width="220px" alt="The Loaders templates in the Add element panel: Spinner, Spinner with label, Progress bar, and Progress bar with label" float="right" />

**加载器**是一种动画元素，用于提示系统正在处理中：例如，正在处理用户的测验答案以生成个性化计划。

该类别提供四种模板：

- **Spinner** — 圆形加载动画。
- **Spinner with label** — 带文字说明的圆形加载动画（例如"Loading..."）。
- **Progress bar** — 从 0 填充至 100% 的水平进度条。
- **Progress bar with label** — 带文字说明和百分比的水平进度条（例如"Analyzing... 47%"）。

### 旋转加载图标 \{#spinners\}

旋转加载图标会在所在页面保持旋转状态。在 **Spinner** 部分可选择六种样式之一。在 **Animation** 部分，**Duration** 用于设置完成一次完整旋转所需的时间。

旋转动画的**Duration**（持续时间）并不决定屏幕保持打开的时长。**On screen appear** 触发器配合 **Navigate to Screen** 动作会立即跳转页面。如果需要加载屏幕最多保持 5 秒，请在该动作的[屏幕过渡](flow-screen-transitions#move-users-to-another-screen-automatically)中添加 **Delay**（延迟）。如需更长的等待时间，可添加一个带有 **On timer end** 触发器的 [Timer](flow-timer)（计时器）来跳转到下一屏，或改用[进度条](#run-actions-when-a-progress-bar-is-full)。

### 进度条 \{#progress-bars\}

<ZoomImage id="builder-loader-settings.webp" width="280px" float="right" alt="Loader settings with Type set to Radial, Show percentage on, and the Typography, Progress color, and Animation sections" />

进度条每次打开所在页面时，会从 0 填充至 100%。在 **Loader** 部分，将 **Type** 设置为 **Linear** 可显示条形进度条，设置为 **Radial** 可显示环形进度条。对于环形进度条，**Thickness** 用于设置线条的粗细。

在 **Animation** 部分：

- **Duration** 设置进度条填满所需的时间。
- **Easing** 设置填充速度的加减速方式。

要设置填充颜色，请使用 **Progress color** 部分；要设置未填充轨道的颜色，请使用 **Fill** 部分。

在画布中，进度条默认显示为满格状态。如需查看填充动画效果，请播放画布动画。

### 显示百分比 \{#show-the-percentage\}

要在进度条或环形中显示百分比，请在 **Loader** 部分开启 **Show percentage**。要更改其字体和颜色，请使用 **Typography** 部分。

要在单独的文本中显示百分比（例如紧靠说明文字旁边）：

1. 在进度条的 **Loader** 部分，输入一个 **Element ID**，例如 `analysis`。
2. 在文本中插入 `analysis.progress` 变量，并在其后输入 `%`。

文本会随进度条一起递增计数。**Progress bar with label** 模板就是按照这种方式设置的。显示该变量的文本无法同时显示其他变量或产品值。

### 进度条满时执行操作 \{#run-actions-when-a-progress-bar-is-full\}

**On Load Complete** 触发器会在进度条达到 100% 时执行一次操作。例如：

- 若要在进度条满时跳转到下一个屏幕，请添加 **Navigate to Screen** 操作。
- 若要让 **Next** 按钮在进度条满之前保持不可用状态，请创建一个初始值为 `false` 的布尔变量，并添加一个 **Set Variable** 操作将其设为 `true`。然后，[为按钮添加 **Disabled** 状态](builder-element-states#condition-driven-disabled-state)，使其在变量为 `false` 时生效。

### 依次播放进度条 \{#play-progress-bars-one-after-another\}

<ZoomImage id="builder-loader-start-loader.webp" width="500px" alt="带有“开始加载动画”操作的“加载完成时”触发器，用于启动第二个加载动画" />

若要按顺序填充多个进度条（例如分析的每个步骤对应一个进度条），请按以下步骤操作：

1. 选择除第一个以外的所有进度条。在 **Loader** 部分，关闭 **Autostart**。这些进度条在页面打开时保持在 0。
2. 选择第一个进度条。在 **On Load Complete** 下，添加 **Start loader** 操作，并选择第二个进度条。
3. 对第二个进度条重复步骤 2，以启动第三个进度条，以此类推。

**Start loader** 仅列出同一页面上已关闭 **Autostart** 的进度条。你可以在一个操作中选择多个进度条，让它们同时填充。

### 延迟显示或隐藏加载器 \{#delay-or-hide-a-loader\}

若要在页面打开一段时间后才显示进度条或旋转加载图标，请在 **Animation** 部分将 **Show after delay** 设置为相应的毫秒数。进度条将在延迟结束后开始填充。

若要仅在用户点击某元素时才显示加载器，请将加载器的 **Visibility** 设置为 **Hide**。然后选中需要触发加载器显示的元素，并[添加一个在 **On Tap** 时执行的 **Show element** 动作](flow-show-hide-animations#show-or-hide-an-element)。隐藏状态的进度条会在显示出来时开始填充，而非在其所在页面打开时就开始填充。

### 用户离开页面时 \{#when-users-leave-the-screen\}

- 如果用户在进度条已满后返回页面，进度条保持在 100%，**On Load Complete** 动作不会再次触发。
- 如果用户在进度条未满时离开页面，进度条会停止。当他们返回时，进度条从 0 重新开始填充。

属于[可复用组件](reuse-flow-elements)的进度条，不能在某个动作打开的底部弹窗内包含 **On Load Complete** 动作。包含此类进度条的流程无法发布。
