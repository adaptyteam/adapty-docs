<SDKv4>

在 Observer 模式下，Adapty SDK 无法自动追踪通过现有购买系统完成的购买行为。你需要手动上报来自应用商店的交易记录。在发布应用**之前**完成此配置至关重要，否则会导致分析数据出现错误。

使用 `reportTransaction` 明确上报每笔交易，以便 Adapty 识别。

:::warning

**请勿跳过交易上报！**
如果不调用 `reportTransaction`，Adapty 将无法识别该交易，它不会出现在分析数据中，也不会被发送到集成服务。

:::

如果您使用 Adapty 流程和付费墙，请在上报交易时附上 `variationId`。这样可以将购买行为与触发它的流程或付费墙关联起来，从而确保分析数据的准确性。

:::warning
- 在 Android 上，请使用 Adapty React Native SDK 4.4.0 或更高版本。旧版本可能不会将 `variationId` 发送至 Adapty，导致购买无法与流程关联。
- 请传入用户所购买的 `AdaptyPaywallProduct` 的 `variationId`，而非 `AdaptyFlow.variationId`。流程自身的 variation ID 无法将购买行为与流程关联起来。
:::

```typescript showLineNumbers
const variationId = product.variationId; // 用户购买的 AdaptyPaywallProduct

try {
    await adapty.reportTransaction(transactionId, variationId);
} catch (error) {
    // 处理 `AdaptyError`
}
```

Parameters:

| Parameter     | Presence | Description                                                  |
| ------------- | -------- | ------------------------------------------------------------ |
| transactionId | required | <ul><li> iOS：交易的标识符。</li><li> Android：购买的字符串标识符（`purchase.getOrderId`），其中 purchase 是计费库 [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) 类的实例。</li></ul> |
| variationId   | optional | 实验变体的字符串标识符。传入用户购买的 `AdaptyPaywallProduct` 的 `variationId`，其值与包含该产品的 `AdaptyFlowPaywall` 的 `variationId` 相同。 |
| ios.jwsTransaction | optional | 仅限 iOS，SDK 4.3.0 及更高版本。已签名的 StoreKit 2 交易：即其验证结果的 `jwsRepresentation`。SDK 会原样将其发送至 Adapty。Android 忽略此参数。 |

在 iOS 上，如果你的购买系统提供了 StoreKit 2 transaction，请在第三个参数中传入其 JWS 表示：

```typescript showLineNumbers
await adapty.reportTransaction(transactionId, variationId, {
  ios: { jwsTransaction },
});
```

在观察者模式下，Adapty SDK 无法自动追踪通过现有购买系统完成的交易。您需要从应用商店上报交易记录，或手动恢复购买。为避免分析数据出现错误，请务必在发布应用**之前**完成此配置。

在两个平台上均使用 `reportTransaction` 明确上报每笔交易，并在 Android 上额外使用 `restorePurchases`，以确保 Adapty 能够识别这些交易。

:::warning

**不要跳过交易上报！**
如果不调用这些方法，Adapty 将无法识别该交易，它不会出现在分析数据中，也不会被发送到集成服务。

:::

如果你使用 Adapty 的流程和付费墙，请在上报交易时包含 `variationId`。这样可以将购买行为关联到触发它的流程或付费墙，确保分析数据的准确性。

```typescript showLineNumbers
if (Platform.OS === 'android') {
    try {
        await adapty.restorePurchases();
    } catch (error) {
        // handle the error
    }
}

...

const variationId = paywall.variationId;

try {
    await adapty.reportTransaction(transactionId, variationId);
} catch (error) {
    // handle the `AdaptyError`
}
```

| 参数          | 是否必填 | 描述                                                         |

**将流程和付费墙关联到交易**

Adapty SDK 无法确定购买来源，因为购买由您自行处理。因此，如果您打算在 Observer 模式下使用流程、付费墙和/或 A/B 测试，您需要在移动应用代码中将来自应用商店的交易与对应的流程或付费墙关联起来。在发布应用之前务必正确完成此操作，否则将导致分析数据出现错误。

```typescript 
const variationId = paywall.variationId;

try {
    await adapty.setVariationId('transactionId', variationId);
} catch (error) {
    // handle the `AdaptyError`
}
```

Request parameters:

| 参数          | 是否必填 | 描述                                                         |
| ------------- | -------- | ------------------------------------------------------------ |
| transactionId | 必填     | <p>iOS，StoreKit 1：[SKPaymentTransaction](https://developer.apple.com/documentation/storekit/skpaymenttransaction) 对象。</p><p>iOS，StoreKit 2：[Transaction](https://developer.apple.com/documentation/storekit/transaction) 对象。</p><p>Android：字符串标识符（purchase.getOrderId，其中 purchase 是计费库 [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) 类的实例）。</p> |
| variationId   | 必填     | 实验变体的字符串标识符。可通过 `AdaptyPaywall` 对象的 `variationId` 属性获取。 |
