每当用户打开[流程](adapty-flow-builder)中的某个页面时，SDK 都会向您的应用报告一个 `flow_screen_showed` 事件。将其转发到 Amplitude、Mixpanel 或您使用的任何产品分析工具，以便将流程页面与应用中的其他事件一起进行分析。

:::tip
要查看用户在流程中进行到哪一步，无需任何代码——[流程数据图表](flow-metrics)已在 Adapty 看板中展示了浏览量、完成率和每屏流失情况。如果你需要将这些数据导入自己的分析系统，并与 Adapty 未知的事件进行关联，请参阅本指南。
:::

## 开始之前 \{#before-you-start\}

你需要：

- **Adapty Capacitor SDK v4 或更高版本**：更早的版本不存在流程分析回调。
- **在此功能发布后发布的流程版本**：Adapty 在发布流程时生成屏幕事件，因此在此之前最后发布的流程不会上报任何数据。如果应用没有收到任何事件，请重新发布一个新版本的流程并再试一次。

## 接收的数据 \{#what-you-receive\}

<FlowScreenShowedParams />

屏幕浏览事件与其他所有流程事件通过同一个分析回调上报。注册方式请参阅[处理流程与付费墙事件](capacitor-handling-events)。

## 将每个屏幕浏览事件转发到您的分析系统 \{#forward-every-screen-view-to-your-analytics\}

在读取任何其他内容之前，先匹配事件名称，因为流程会通过同一个回调上报其他事件。

```typescript showLineNumbers title="Capacitor"
view.setEventHandlers({
  onAnalytics(name, params) {
    if (name === 'flow_screen_showed') {
      const screenId = params.instanceId;
      const screenOrder = params.screen_order;

      // Send screenId and screenOrder to your analytics provider here.
    }
    return false; // keep the flow open
  },
});
```

## 当用户到达末尾时执行代码 \{#run-code-when-a-user-reaches-the-end\}

`is_last_screen` 在流程无法继续前进的页面上为 `true`。可利用它解锁内容、标记用户引导已完成，或发送自定义完成事件，无需在编辑工具中为此添加按钮动作。

```typescript showLineNumbers title="Capacitor"
view.setEventHandlers({
  onAnalytics(name, params) {
    if (name === 'flow_screen_showed' && params.is_last_screen) {
      // The user reached the end of the flow.
    }
    return false; // keep the flow open
  },
});
```

到达最后一屏并不等同于关闭流程。用户可能看到最终屏幕后直接关闭流程，而不进行任何操作；分支流程也可能在多个不同的屏幕上结束。如需了解流程本身何时消失，请改用 `onDisappeared`。
