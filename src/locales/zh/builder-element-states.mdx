交互式流程元素会根据用户操作改变外观：点击测验选项后变为 **Selected**，聚焦输入框后变为 **Active**。某些状态由条件驱动：你可以**禁用**按钮，或添加带有自定义名称和条件的[自定义状态](#custom-states)。为每个状态单独设置样式，无需编写应用代码即可为用户提供视觉反馈。

## 按元素类型划分的可用状态 \{#available-states-by-element-kind\}

| 元素类型 | 内置状态 | 可添加状态 |
|---|---|---|
| [可选元素](#selectable-element-states) | **Default**、**Selected** | **Disabled**、[自定义状态](#custom-states) |
| [输入框](#input-states) | **Default**、**Active**、**Invalid** | **Disabled**；文本、电子邮件、密码、数字和电话输入框支持[自定义状态](#custom-states) |
| [任何带有点击交互的元素](#condition-driven-disabled-state)——按钮、图片、图标、容器等 | **Default** | **Disabled**、[支持的元素](#elements-that-support-custom-states)上的[自定义状态](#custom-states) |
| [进度指示器步骤](#step-states-for-progress-indicators) | **Completed**、**Current**、**Upcoming** | — |

**可添加**状态默认不显示——打开 **States settings** <Inline id="settings.svg" alt="Settings" /> 来添加它们。这些状态由条件驱动：你可以定义它们何时激活。详见[条件驱动的禁用状态](#condition-driven-disabled-state)和[自定义状态](#custom-states)。

其他元素的条件也可以对元素状态进行求值。例如，你可以[说明按钮为何被禁用](element-states-in-conditions#explain-why-a-button-is-disabled)。

## 当多个状态同时应用于同一元素时 \{#when-several-states-apply-to-one-element\}

多个状态可以同时应用于同一元素。例如：

- 用户在邮箱字段中输入了无效地址，然后再次点击该字段进行修改。字段获得焦点，因此 **Active** 生效；地址仍然无效，因此 **Invalid** 也同时生效。
- 用户开启了试用开关，因此 **Selected** 生效。随后他们选择了一个不含试用的套餐。该开关对应套餐设置了 **Disabled** 条件，因此 **Disabled** 也同时生效。
- 一个 **Continue** 按钮同时拥有 **Disabled** 状态和一个名为 **Locked** 的自定义状态，两个条件均为真，因此两个状态同时生效。

一个元素在同一时刻只能处于一种状态。当多个状态同时适用时，该元素处于此列表中排在最后的状态：

1. **Selected**
2. **Invalid**
3. **Active**
4. **Disabled**
5. [自定义状态](#custom-states)

当多个自定义状态同时适用时，该元素处于 **States** 设置列表中排在最后的自定义状态。

在示例中，email 字段为 **Active** 状态，trial 开关为 **Disabled** 状态，**Continue** 按钮为 **Locked** 状态。元素的外观取决于你为该状态设置的样式。条件只会匹配与当前状态一致的状态。当上述状态均不适用时，元素为 **Default** 状态。

自定义状态仅影响元素的外观。**Disabled** 状态的元素即便被自定义状态改变了外观，仍然不响应点击操作。

## 如何设置状态样式 \{#how-to-style-a-state\}

<ZoomImage id="element-states-panel.webp" width="300px" alt="所选元素右侧面板中的状态部分" float="right" />


1. 选择一个元素。右侧面板中的 **States** 部分会列出该元素支持的所有状态。
2. 在 **States** 部分，激活目标状态。如有需要，可添加[条件驱动的 Disabled 状态](#condition-driven-disabled-state)或[自定义状态](#custom-states)。
3. 修改任意属性——填充色、边框、字体等。所做更改仅作用于该状态。

    嵌套元素会与父元素一起变为有状态。对子元素的任何更改都限定在父元素的活动状态范围内。

4. 编辑工具在运行时应用匹配的样式。

## 可选元素的状态 \{#selectable-element-states\}

<ZoomImage id="selectable-state-demo.webp" width="600px" alt="Selectable element with Selected state activated and a style override applied" />

可选元素——测验选项、产品、选项卡、开关和复选框，以及任何[自定义可选元素](flow-selectable-elements#make-an-element-selectable)——开箱即用支持两种状态：

- **Default**：元素的默认外观。
- **Selected**：用户点击元素时激活。当用户取消选中该元素时，编辑工具会恢复为 Default 状态。

在单选组中，选择一个元素会取消其他元素的选中状态。多选组允许同时选中多个元素。切换按钮相互独立——选中其中一个不会影响其他兄弟元素。详见[组类型](flow-selectable-elements#group-types)。

:::tip
如需复用特定状态的样式，可先在一个元素（如产品卡片）上设置好，然后让 [AI 编辑器](flow-ai-editor)将其应用到其他元素上。特定状态的样式不会在兄弟元素之间自动同步。
:::

## 输入状态 \{#input-states\}

- **Default**：输入框的默认外观。
- **Active**：输入框获得焦点时应用。
- **Invalid**：当输入内容验证失败时应用。例如，邮件字段中不包含 `@`。请参阅[输入验证](builder-inputs-and-forms#input-validation)。
- **Disabled**：输入框不可交互。需手动添加此状态，请参阅[条件驱动的禁用状态](#condition-driven-disabled-state)。
- **Custom states**：仅适用于文本、电子邮件、密码、数字和电话输入框。在自定义状态下，只有输入框的填充颜色、边框和圆角半径会发生变化。请参阅[自定义状态](#custom-states)。

以同样的方式为每个状态设置样式（就像设置可选择元素的样式一样）：激活目标状态，然后更改属性。

## 条件驱动的禁用状态 \{#condition-driven-disabled-state\}

禁用状态会阻止用户与元素进行交互。与默认、已选中、活跃或无效状态不同，禁用状态不会自动激活——它需要用户自定义的触发条件。

禁用状态适用于：

- **输入框**：任何[输入字段](builder-inputs-and-forms)——文本、邮箱、密码、数字、电话、日期和/或时间。
- **可选元素**：测验选项、产品、标签页、切换开关和复选框，以及任何[自定义可选元素](flow-selectable-elements#make-an-element-selectable)。
- **带点击交互的任意元素**：例如触发导航操作的按钮、图片或图标。

### 添加禁用状态 \{#add-the-disabled-state\}

<ZoomImage id="add-disabled-state.webp" width="300px" float="right" alt="States section with the Add state menu open and the Disabled option" />

要添加并配置禁用状态：

1. 选择目标元素。
2. 在 **States** 部分，点击 **Add state**，然后选择 **Disabled**。如果该元素已有状态，请先点击 **Settings** <Inline id="settings.svg" alt="Settings" />：**Add state** 位于状态列表下方。对于不支持自定义状态的元素，控件显示为 **Disabled state** 按钮。
3. Disabled 状态将出现在 **States** 部分。
4. 在新建的 Disabled 状态旁边，点击 **Edit conditional state** <Inline id="visibility-conditional.svg" alt="Edit conditional state" />。
5. 添加条件。如果希望在输入内容未通过验证时禁用 **submit** 按钮，可将输入框的 `isValid` 变量与 `false` 进行比较。
6. 为 Disabled 状态设置样式，以直观地传达禁用限制（例如，降低不透明度）。

{ <ZoomImage id="set-disabled-condition.webp" width="700px" alt="Set condition for disabled state " />}

Adapty SDK 会在运行时评估该条件，并在适当时应用 Disabled 状态——无需修改应用代码。

**Disabled** 条件还可以评估另一个元素的状态。例如，你可以[同时禁用两个元素](element-states-in-conditions#synchronize-element-states)。

## 自定义状态 \{#custom-states\}

自定义状态是一种由你命名、并附带自定义条件的状态。例如，**Locked** 状态可以在用户处于免费计划时将按钮显示为灰色。只要条件为真，元素就会保持在该自定义状态中。

每个元素最多可以添加 5 个自定义状态。

### 支持自定义状态的元素 \{#elements-that-support-custom-states\}

- **带有点击动作的元素**：按钮、容器、图片、视频、计时器和轮播图。首先，在 **Interactions** 选项卡中为其添加至少包含一个动作的 [**On Tap** 触发器](onboarding-actions#set-up-interactions)。
- **可选择的元素**：可选择组中的元素，以及带有点击动作的可选择元素。
- **输入框**：文本、电子邮件、密码、数字和电话输入框。

其他元素（如图标、底部弹出层、选项卡项、选项卡内容、选择器和进度指示步骤）不支持自定义状态。

<ZoomImage id="custom-state-needs-tap.webp" width="300px" float="right" alt="Add state menu with the Custom state option turned off and the caption Add a tap action to use custom states" />

要为按钮、容器、图片、视频、计时器或轮播图添加自定义状态，请先添加带有至少一个操作的 **On Tap** 触发器。在此之前，**States** 部分不会显示 **Add state** 控件。如果元素已有状态，**Custom state** 选项处于关闭状态，并显示说明文字"Add a tap action to use custom states"。添加点击操作后，该选项将变为可用。

### 添加自定义状态 \{#add-a-custom-state\}

<ZoomImage id="custom-state-add-menu.webp" width="300px" float="right" alt="States section with the Add state menu open, listing Disabled and Custom state" />

1. 选中元素。
2. 在 **States** 区域，点击 **Add state**。如果该元素已有状态，请先点击 **Settings** <Inline id="settings.svg" alt="Settings" />：**Add state** 位于状态列表下方。
3. 选择 **Custom state**，**Edit state** 面板随即打开。

    <ZoomImage id="custom-state-edit-panel.webp" width="400px" alt="编辑状态面板，名称为 Locked，条件为 plan 等于 free" />

4. 在 **Name** 中，输入状态名称，例如 **Locked**。名称须遵循[命名规则](#name-rules)。
5. 添加条件。例如，将 `plan` 变量与 `free` 进行比较。如需添加更多条件，点击 **Add Condition**，并选择需要满足其中 **all**（全部）还是 **any**（任意）条件。
6. 点击 **Save**。新状态将作为标签页显示在 **States** 部分。
7. 激活新状态的标签页，并[为其设置样式](#how-to-style-a-state)。嵌套元素的样式（例如按钮内的文字）同样会在设备上生效。

要关闭 **Edit state** 面板且不保存更改，点击 **Cancel** 或关闭按钮、按 **Escape**，或在面板外部点击。

当一个元素已有 5 个自定义状态时，**Custom state** 选项将变为不可用，并显示提示文字"Up to 5 custom states"。如需添加新的自定义状态，请先删除一个现有状态。如果从 JSON 或 AI 工具导入的流程配置中，某个元素包含超过 5 个自定义状态，这些状态将保留，并且可以正常编辑。

### 命名规则 \{#name-rules\}

编辑工具不区分大小写：**Locked** 和 **locked** 视为同一个名称。保存时，系统还会自动去除名称首尾的空格。如果名称违反规则，**Save** 按钮将变为不可用状态，并在输入框下方显示错误提示：

| 规则 | 错误 |
|---|---|
| 名称不能为空。 | **Name is required** |
| 名称不超过 30 个字符。 | **Max 30 characters** |
| 名称不能是 **Default**，也不能与内置状态名称相同：**Selected**、**Active**、**Invalid**、**Disabled**、**Completed**、**Current**、**Upcoming** 或 `focused`。 | **This name is reserved** |
| 名称与该元素的其他自定义状态名称不重复。 | **A state with this name already exists** |

### 编辑自定义状态 \{#edit-a-custom-state\}

<ZoomImage id="custom-state-tab-tooltip.webp" width="300px" float="right" alt="带有编辑状态按钮的锁定状态标签页提示" />

要修改自定义状态的名称或条件，可通过以下方式打开 **Edit state** 面板：

- 在 **States** 设置列表中，点击该状态所在的行，或点击该行中的条件图标 <Inline id="visibility-conditional.svg" alt="Condition" />。
- 将鼠标悬停在该状态的标签页上，然后在提示框中点击 **Edit state**。

保存后，该状态将保留其样式。评估此状态的其他元素的条件会显示新名称。

### 删除自定义状态 \{#delete-a-custom-state\}

在 **States** 设置列表中，点击该状态所在行的垃圾桶图标。如果其他元素的条件引用了该状态，系统会先弹出对话框列出这些元素。点击 **Delete** 后，这些条件将失效，在修复之前无法发布流程。请参阅[故障排查](element-states-in-conditions#troubleshooting)。

编辑工具会删除该状态及其样式。如果被删除状态的标签页当前处于激活状态，则 **Default** 标签页将自动变为激活状态。

如需恢复该状态，请撤销删除操作。状态将在列表中恢复到原来的位置，并保留其样式。

### 条件不完整 \{#incomplete-conditions\}

当条件行的某一侧为空时，该条件行就是不完整的。例如，你添加了一行但未填写，或者选择了变量但未输入值。包含不完整行的条件永远不会变为真，即使其他行为真也不例外。元素不会进入该状态，设备将显示其 **Default** 样式。此规则同样适用于 **Disabled** 条件：元素将保持可交互状态。

编辑工具不会对不完整的行显示警告，因此请在发布前填写或删除每一行。如果某行有值或选择了 **is empty**，但未设置变量，发布时会触发 [**Invalid State Condition** 错误](flow-common-issues#a-flow-wont-preview-or-publish)。

### 限制 \{#limitations\}

<ZoomImage id="custom-state-device-warning.webp" width="300px" float="right" alt="States settings list with the warning Not shown on the device. Add a tap action to the element. under two custom states" />

- **不在设备上显示该状态的元素**：画布会在任何元素上展示自定义状态，但设备只会在[支持的元素](#elements-that-support-custom-states)上显示。不支持的元素也可以拥有自定义状态，例如来自 JSON 或 AI 工具，或在删除其点击操作后。

    在这种情况下，**States** 设置列表和标签页工具提示会显示警告："Not shown on the device. Add a tap action to the element." 或 "Not shown on the device for this element type."。你仍然可以编辑、删除和发布该状态。
- **输入框**：在自定义状态下，输入框只有填充色、边框和圆角半径会发生变化。其他属性（如文字颜色）保持 **Default** 值不变。输入框的 **Edit state** 面板会显示说明文字："Only fill, border and corner radius change in a custom state"。
- **视频和轮播图**：当视频或轮播图在设备上切换状态时，视频会从头开始播放，轮播图也会返回第一张幻灯片。如果视频或轮播图需要保持当前播放位置或当前幻灯片，请不要为其添加自定义状态。

## 进度指示器的步骤状态 \{#step-states-for-progress-indicators\}

:::link
主要文章：[进度指示器](builder-loaders-and-progress-bars#step-states)
:::

进度指示器向用户展示他们在用户引导流程中的进展情况。每个步骤有三种状态：

- **已完成**：用户已经经过的步骤。
- **当前**：用户当前所在的步骤。
- **即将到来**：用户尚未到达的步骤。
