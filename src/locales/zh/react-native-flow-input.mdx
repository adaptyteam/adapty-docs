当用户在[流程](adapty-flow-builder)中的输入框中输入内容、回答测验或拨动开关时，SDK 会通过其分析回调将对应的值传递给你的应用。

应用最常将这些数据用于：

- **在自有后端注册用户**：获取用户在引导流程中填写的邮箱和姓名，在流程关闭时为其创建账户。
- **保存答案与偏好设置**：记录用户的选择，供应用后续使用——例如，[将其作为自定义属性写入用户的 Adapty 用户画像](react-native-setting-user-attributes)。
- **自定义后续流程**：将问卷答案保存为自定义属性，再针对后续版位进行定向，让不同市场细分的用户看到不同的流程，或流程中不同的付费墙。
- **接入第三方分析平台**：将答案转发至 Amplitude、Mixpanel 或你所使用的其他产品分析工具。

输入框和可选组会自动上报其值。为了在代码中区分各个输入框，请在编辑工具中为每个输入框指定一个有意义的 **Element ID**，为每个可选组指定一个 **Group ID**。

## 接收输入值 \{#receive-input-values\}

输入值与流程中其他所有分析事件一样，通过同一个处理器传递，事件名称为 `flow_user_input`。在注册其他流程事件处理器的同时，注册 `onAnalytics`：

```javascript showLineNumbers title="React Native"
const unsubscribe = view.setEventHandlers({
  onAnalytics(name, params) {
    handleFlowInput(name, params);
    return false; // keep the flow open
  },
});
```

`onAnalytics` 回调会传递流程中的所有分析事件，包括[屏幕浏览事件](react-native-flow-screen-views)。
- `name` 参数包含事件名称。如需筛选用户输入事件，请将 `name` 与 `flow_user_input` 进行比较。
- `element_type` 参数表示元素类别。
- 根据元素类型的不同，输入值存储在不同的参数中：
     - 文本框、选择器和开关的用户输入存储在 `value` 中
     - 可选组在 `item_ids` 和 `item_titles` 中报告当前选中的选项

```javascript showLineNumbers title="React Native"
function handleFlowInput(name, params) {
  if (name !== 'flow_user_input') return;

  // The screen the input sits on. Pair it with element_id to tell apart
  // two fields that share an Element ID on different screens.
  const screenId = params.instanceId;

  switch (params.element_type) {
    case 'text_input':
    case 'email_input':
    case 'number_input':
    case 'phone_input': {
      const text = params.value;
      break;
    }
    case 'date_picker':
    case 'time_picker':
    case 'date_time_picker': {
      // Unix time in milliseconds.
      const date = new Date(params.value);
      break;
    }
    case 'single_choice': {
      const optionId = params.item_ids[0];
      break;
    }
    case 'multi_choice': {
      const optionIds = params.item_ids;
      break;
    }
    case 'toggle': {
      const isOn = params.value;
      break;
    }
  }
}
```

## 发送与限制条件 \{#delivery-and-limitations\}

<FlowInputLimitations />

将每个输入值在收到时即时存储，待流程关闭时一并发送完整数据。要捕获这一时刻，请在注册 `onAnalytics` 的同时注册 `onDisappeared` 处理器。无论用户是完成了整个流程还是中途关闭，该处理器都会在流程视图消失时触发。

## 使用场景 \{#use-cases\}

### 在后端注册用户 \{#register-users-on-your-backend\}

等所有答案收集完毕后再统一发送，确保一次请求携带完整数据。

无论用户是正常完成流程还是中途退出，流程都会关闭。在调用后端接口前，请先校验所需字段是否已填写。

流程无法展示来自后端的错误信息。处理函数的返回值仅用于关闭流程视图，SDK 也没有向运行中的流程传入数据的方法。如果注册失败（例如邮箱已被占用），请在流程关闭后通过你自己的 UI 展示错误提示。

```javascript showLineNumbers title="React Native"
const flowAnswers = {};

const unsubscribe = view.setEventHandlers({
  onAnalytics(name, params) {
    if (name === 'flow_user_input' && typeof params.value === 'string') {
      flowAnswers[params.element_id] = params.value;
    }
    return false;
  },
  onDisappeared() {
    if (flowAnswers.email) {
      // Send flowAnswers to your backend here to create the account.
    }
    return false;
  },
});
```

### 使用数据丰富用户画像 \{#enrich-user-profiles-with-data\}

为了将用户输入的信息关联到其用户画像，并避免重复询问相同的内容，请在数据输入时[更新用户画像](react-native-setting-user-attributes)。

例如，如果你的流程中有一个 Element ID 为 `name` 的文本输入框和一个 Element ID 为 `email` 的邮箱输入框：

```javascript showLineNumbers title="React Native"
function handleFlowInput(name, params) {
  if (name !== 'flow_user_input') return;
  if (typeof params.value !== 'string') return;

  const profileParams = {};

  switch (params.element_id) {
    case 'name':
      profileParams.firstName = params.value;
      break;
    case 'email':
      profileParams.email = params.value;
      break;
    default:
      return;
  }

  adapty.updateProfile(profileParams).catch(error => {
    // handle the error
  });
}
```

### 自定义后续显示的流程 \{#customize-flows-shown-later\}

测验答案也可以决定用户在后续[版位](placements)中看到的内容——可以是不同的流程，也可以是其中不同的付费墙。

例如，在用户引导流程中询问用户的运动经验，然后为每组用户展示包含不同产品和文案的专属流程。

1. 在流程中添加[测验](onboarding-quizzes)。将[可选组](flow-selectable-elements)的 Group ID 设为 `experience`，并为每个选项设置有意义的 Element ID。
2. 处理答案并为用户[设置自定义属性](react-native-setting-user-attributes)。

```javascript showLineNumbers title="React Native"
function handleFlowInput(name, params) {
  if (name !== 'flow_user_input') return;
  if (params.element_id !== 'experience') return;

  adapty
    .updateProfile({
      // Set the custom attribute 'experience' to the option the user selected
      // (beginner, amateur, or pro).
      codableCustomAttributes: { experience: params.item_ids[0] },
    })
    .catch(error => {
      // handle the error
    });
}
```

3. 为每个自定义属性值[创建一个市场细分](segments)。
4. 创建一个[版位](placements)，并为每个市场细分添加一个[目标受众](audience)。
5. 在你的应用中[展示该版位的流程](react-native-present-paywalls)。
