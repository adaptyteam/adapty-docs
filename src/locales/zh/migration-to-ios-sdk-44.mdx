要将应用从 Adapty iOS SDK 4.3 升级至 4.4，请按照本指南完成每一项变更。如果应用当前使用 4.1 或 4.2 版本，需先完成 [v4.3 变更](migration-to-ios-sdk-43)；如果使用 4.0 版本，则需先完成 [v4.1 变更](migration-to-ios-sdk-41)。

:::warning
备用文件格式在 4.4 版本中有所变更，编译器无法检测到过期的文件。如果不更新[备用文件](#fallback-files)，每个版位都将失去其备用付费墙。
:::

## 快速参考 \{#quick-reference\}

| 变更前 | 变更后 |
|---|---|
| `case let .custom(id)` | `case let .custom(id, _)` |
| `AdaptyUICustomAsset` | `AdaptyUIAsset`；`AdaptyCustomAsset` 保持不变 |
| `.color(.uiColor(x))` 和 `.color(.swiftUIColor(c))` | `.color(Color(uiColor: x))` 和 `.color(c)` |
| `AdaptyUICustomFontAsset(font:defaultColor:defaultLetterSpacing:defaultLineHeight:)` | `AdaptyUIFontAsset(font:color:letterSpacing:lineHeight:)` |
| 不支持 data 资产 | `AdaptyUIAsset` 新增 `.data` 以支持 data 资产 |
| `AdaptyProduct.localizedBillingPeriod` | `subscriptionPricingTerms?.localizedBillingPeriod` |
| 适用于 4.1–4.3 的备用付费墙文件 | 备用付费墙文件格式已更新，请重新下载 |

## AdaptyUI.Action.custom 包含两个值 \{#custom-actions\}

当用户点击带有自定义操作的按钮时，你的应用会收到 `AdaptyUI.Action.custom`。在 4.4 版本中，该值在 action ID 之后新增了第二个值 `arguments`。在 `didPerformAction` 闭包和 `flowController(_:didPerform:)` 代理方法中，为第二个值添加 `_`：

```diff showLineNumbers
  switch action {
- case let .custom(id):
+ case let .custom(id, _):
      if id == "openNewPaywall" {
          // Display another flow or paywall
      }
  default:
      break
  }
```

Code that compares `id` to a string stops compiling until you add `_`. Other code still builds, with the warning "enum case 'custom' has 2 associated values; matching them as a tuple is deprecated". In that code, `id` contains both values, not the action ID alone. Add `_` wherever Xcode shows this warning.

## 自定义资源 \{#custom-assets\}

在 4.4 版本中，`AdaptyUICustomAsset` 已重命名为 `AdaptyUIAsset`，旧名称会触发废弃警告。

颜色、字体和数据资源有以下三处变化：

- **颜色资源**：`.color` 接受 SwiftUI 的 `Color`，`AdaptyUICustomColorAsset` 已被移除。请将 `UIColor` 包装为 `Color(uiColor:)`，然后直接传入 SwiftUI 的 `Color`：

  ```diff showLineNumbers
  - "brand_color": .color(.uiColor(brandColor)),
  + "brand_color": .color(Color(uiColor: brandColor)),
  ```

- **字体资源**：`AdaptyUIFontAsset` 使用 `color:`、`letterSpacing:` 和 `lineHeight:` 替代 `defaultColor:`、`defaultLetterSpacing:` 和 `defaultLineHeight:`。`color:` 参数接受 SwiftUI 的 `Color`：

  ```diff showLineNumbers
  - "title_font": .font(AdaptyUICustomFontAsset(font: titleFont, defaultColor: .uiColor(.white), defaultLineHeight: 24)),
  + "title_font": .font(AdaptyUIFontAsset(font: titleFont, color: .white, lineHeight: 24)),
  ```

- **数据资产**：`AdaptyUIAsset` 新增了一种资产类型 `.data`。如果 `switch` 语句列举了所有资产类型且没有 `default` 分支，代码将无法编译。由于只有[自定义元素](ios-flow-custom-elements)会读取数据资产，新增的分支可以留空：`case .data: break`。

## AdaptyProduct.localizedBillingPeriod 已弃用 \{#localizedbillingperiod-is-deprecated\}

`AdaptyProduct` 有一个 [`subscriptionPricingTerms`](fetch-paywalls-and-products) 属性，用于描述该产品的每次付款信息：付款金额以及用户的付款频率。在 4.4 版本中，`localizedBillingPeriod`（显示用户付款频率的文本）从 `AdaptyProduct` 移至 `subscriptionPricingTerms`。`AdaptyProduct.localizedBillingPeriod` 仍然可用，但会显示弃用警告：它返回 `subscriptionPricingTerms?.localizedBillingPeriod`。若要消除该警告，请从定价条款中读取此属性：

```diff showLineNumbers
- let period = product.localizedBillingPeriod
+ let period = product.subscriptionPricingTerms?.localizedBillingPeriod
```

## 备用文件 \{#fallback-files\}

[备用文件](fallback-flows)格式在 SDK 4.4 中发生了变更。请从 **[Placements](https://app.adapty.io/placements)** > **Fallbacks** 重新下载该文件，选择 **Adapty SDK v4.4.0 and higher**，并将其打包到应用中。

下载的文件名为 `ios_4_4_0_fallback.json`。请将其命名为应用传入 `Bundle.main.url(forResource:withExtension:)` 的名称，或在该调用中更新文件名。

:::warning
使用过时的备用付费墙文件不会产生任何编译错误，但所有版位都会悄无声息地失去备用付费墙。SDK 日志将显示："The fallback paywalls version is not correct. Download a new one from the Adapty Dashboard."
:::
