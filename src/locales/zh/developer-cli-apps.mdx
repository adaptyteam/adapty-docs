这些 Adapty CLI 命令用于管理您的应用及其[访问等级](access-level)：即应用在运行时检查的订阅层级。

## 应用 \{#apps\}

管理 Adapty 账户中的应用。如需通过看板进行配置，请参阅[应用设置](general)。

### adapty apps list

列出您 Adapty 账户中的所有应用。

```bash
adapty apps list
```

接受[分页标志](developer-cli-reference#global-flags)。

### adapty apps get

获取特定应用的详细信息。

```bash
adapty apps get <app-id>
```

| 参数 | 描述 |
|---|---|
| `app-id` | 应用 ID（UUID） |

### adapty apps create

创建新应用。

```bash
adapty apps create --title "My App" --platform ios --apple-bundle-id com.example.app
```

| 标志 | 是否必填 | 描述 |
|---|---|---|
| `--title` | 是 | 应用名称 |
| `--platform` | 是 | 平台：`ios` 或 `android`。如需同时指定两个平台，可重复使用：`--platform ios --platform android` |
| `--apple-bundle-id` | 使用 `--platform ios` 时必填 | Apple bundle ID |
| `--google-bundle-id` | 使用 `--platform android` 时必填 | Google bundle ID |

### adapty apps update

更新已有应用。

```bash
adapty apps update <app-id> --title "New Name"
```

| 参数 | 描述 |
|---|---|
| `app-id` | 应用 ID（UUID） |

| 标志 | 描述 |
|---|---|
| `--title` | 新应用名称 |
| `--apple-bundle-id` | 新 Apple Bundle ID |
| `--google-bundle-id` | 新 Google Bundle ID |

至少需要指定一个标志。`--platform` 创建后不可更改。

## 访问等级 \{#access-levels\}

### adapty access-levels list

列出应用的所有[访问等级](access-level)。

```bash
adapty access-levels list --app <app-id>
```

| 参数 | 是否必填 | 描述 |
|---|---|---|
| `--app` | 是 | 应用 ID（UUID） |

支持[分页参数](developer-cli-reference#global-flags)。

### adapty access-levels get

获取指定[访问等级](access-level)的详细信息。

```bash
adapty access-levels get --app <app-id> <access-level-id>
```

| 参数 | 描述 |
|---|---|
| `access-level-id` | 访问等级 ID（UUID） |

| 标志 | 必填 | 描述 |
|---|---|---|
| `--app` | 是 | 应用 ID（UUID） |

### adapty access-levels create

创建一个新的[访问等级](access-level)。

```bash
adapty access-levels create --app <app-id> --sdk-id "pro" --title "Pro"
```

| 参数 | 必填 | 描述 |
|---|---|---|
| `--app` | 是 | 应用 ID（UUID） |
| `--sdk-id` | 是 | 在应用代码中用于检查访问权限的标识符（例如 `"pro"` 或 `"premium"`） |
| `--title` | 是 | 在 Adapty 看板中显示的标签名称 |

### adapty access-levels update

更新现有[访问等级](access-level)。

```bash
adapty access-levels update --app <app-id> <access-level-id> --title "Pro Access"
```

| 参数 | 描述 |
|---|---|
| `access-level-id` | 访问等级 ID（UUID） |

| 标志 | 是否必填 | 描述 |
|---|---|---|
| `--app` | 是 | 应用 ID（UUID） |
| `--title` | 是 | 新的显示标签 |

`--sdk-id` 创建后不可更改。
