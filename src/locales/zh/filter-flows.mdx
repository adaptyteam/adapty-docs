[**Flows**](https://app.adapty.io/flows) 页面列出了您应用中的所有流程，并显示每个流程的[状态](#filter-by-status)和主要[数据图表](flow-metrics)。点击某个流程可查看其完整[数据图表](flow-metrics)，如果您拥有 **Developer** 角色，则可进入 [Flow Builder](adapty-flow-builder)。

<ZoomImage id="flow-list.webp" width="700px" alt="流程页面，包含搜索框、全部状态筛选器、可排序的流程名称和状态列，以及展开的上下文菜单" />

## 按名称搜索 \{#search-by-name\}

**按流程名称搜索**可匹配流程名称的任意部分。不会搜索版位、产品或屏幕内容。

## 按状态筛选 \{#filter-by-status\}

打开列表上方的 **All states** 筛选器，选择一个或多个状态，然后点击 **Apply**。[保存与发布流程](builder-save-publish#flow-status)中详细说明了每种状态的含义以及流程如何在各状态之间流转。

<ZoomImage id="flows-filter-by-state.webp" width="300px" alt="All states filter open, with a checkbox for each flow status and an Apply button" />

## 按版位筛选 \{#filter-by-placement\}

打开列表上方的 **All placements** 筛选器，选择一个或多个[版位](placements)，然后点击 **Apply**。当至少有一个流程已分配至版位时，该筛选器才会显示。

<ZoomImage id="flows-filter-by-placement.webp" width="300px" alt="All placements filter open, listing two placements with checkboxes and an Apply button" />

## 排序 \{#sort\}

您可以按 **Flow name** 或 **Status** 排序。数据图表列不支持排序。默认情况下，已发布的流程排在最前，已归档的流程排在最后。

## 流程操作 \{#flow-actions\}

在流程所在行中打开上下文菜单 <Inline id="context.svg" alt="Context menu" />。

| 操作 | 说明 |
| :----- | :----------- |
| **Metrics** | 打开该流程的[数据图表](flow-metrics)。 |
| **Edit** | 在[流程编辑工具](adapty-flow-builder)中打开该流程。 |
| **Copy** | 将该流程[复制](copy-flows)为新的草稿。 |
| **Archive** | [归档该流程](archive-flows)。 |

已归档流程的菜单中显示 **Metrics** 和 **Back to active**，后者用于[恢复该流程](archive-flows#restore-a-flow)。
