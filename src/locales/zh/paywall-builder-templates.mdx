你可以从模板创建流程，也可以从零开始，或基于现有付费墙创建。

<FlowVideoTutorials />

## 创建流程 \{#create-flow\}

<ZoomImage id="create-flow-menu.webp" width="300px" alt="Create flow menu with Start from scratch and Browse templates options" float="right" />

1. 打开 [**Flows**](filter-flows) 页面。
2. 点击 **Create flow**。
3. 选择一个选项：
   - **Browse templates**（打开模板库）
   - **Start from scratch**（创建空白流程）
4. 在编辑器中重命名流程。点击顶部标题栏中的流程名称，输入新名称。

<ZoomImage id="rename-flow.webp" width="500px" alt="Rename the flow name in the top toolbar" />

:::warning
Adapty 允许流程重名。请为每个新建的流程重命名，否则会创建多个难以区分的 **Untitled** 流程。
:::
### 使用模板 \{#use-a-template\}

<ZoomImage id="template-library.webp" width="700px" alt="Template library modal with template cards" />

模板库包含多个模板，可作为你构建流程的起点。每个模板都是一个完整的流程，包含多个页面、交互元素和可用的导航功能。你可以编辑任意元素来进行自定义。

使用模板的步骤：

1. 在模板库中浏览模板卡片。每张卡片会展示该流程的预览截图。
2. 点击你想要的卡片上的 **Use as template**。
模板加载完成后，您可以在编辑工具中修改任何元素、页面或属性。
### 从零开始 \{#start-from-scratch\}

<ZoomImage id="empty-screen.webp" width="300px" alt="编辑工具中带有单个空白屏幕的空流程" float="right" />

从零开始会创建一个包含单个空白屏幕的流程。你可以使用[元素库](builder-elements)中的元素来设计该屏幕。
## 从旧版付费墙编辑工具迁移付费墙 \{#migrate-a-paywall-from-the-legacy-paywall-builder\}

:::link
主要文章：[将付费墙转换为流程](convert-paywall-to-flow)
:::

除了从模板创建流程，你也可以将现有的旧版付费墙直接转换。

打开付费墙的看板页面，点击 **Move to new builder**。Adapty 会将该付费墙重新创建为新的草稿流程——保留原有的布局、文本、产品和本地化内容。旧版付费墙仍会正常运行，以确保平稳过渡。

<ZoomImage id="move-to-new-builder.webp" width="700px" alt="Move to new builder button in the paywall action row" />

## 更换模板 \{#change-the-template\}

您可以在编辑工具内切换模板。打开 Screens 面板，点击 **Templates** <Inline id="template-library.svg" alt="Templates" /> 按钮重新打开模板库，然后选择一个新模板。

:::warning
应用新模板会替换当前的流程草稿。Adapty 会提示您确认——点击 **Use template** 继续操作，或点击 **Cancel** 保留草稿。确认后，之前的草稿将无法恢复。已发布的流程不受影响，仍正常运行。
:::
## 模板中的自定义字体 \{#custom-fonts-in-templates\}

:::link
主要文章：[Flow Builder 中的自定义字体](using-custom-fonts-in-flow-builder)
:::

<ZoomImage id="custom-font-warning.webp" width="300px" alt="Custom font chip on a template card with the warning tooltip" float="right" />

带有 **Custom font** 标签的模板使用了自定义字体。这些字体不随移动端 SDK 一起提供。将鼠标悬停在标签上可查看该模板所使用的字体。

若要在设备上呈现预期的排版效果，请将字体文件添加到您的应用包中。未内置该字体的旧版应用将回退使用系统字体。
要在不影响旧版本的情况下更换字体，请[复制该流程](copy-flows)，在副本中更改字体，并将副本限制为[包含该字体的应用版本](segments)。
