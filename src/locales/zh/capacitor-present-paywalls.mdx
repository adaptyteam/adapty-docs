<SDKv4>

如果您已创建了流程，或在旧版付费墙编辑工具中创建了付费墙，则无需在移动应用代码中手动渲染，即可将其展示给用户。此类流程本身已包含展示内容与展示方式的完整定义。

开始之前，请确认：

1. 你已创建了一个[流程](paywall-builder-templates)或[付费墙](create-paywall)。
2. 你已将其添加到[版位](placements)。
3. 你已[获取流程并准备好视图](capacitor-get-pb-paywalls)。

:::warning

本指南仅适用于**由 Adapty 渲染的流程和付费墙**，需要 SDK v4.0 或更高版本。自定义付费墙的展示流程有所不同。

- 如需展示自定义付费墙，请参阅[展示自定义付费墙](present-remote-config-paywalls-capacitor)。

:::

要将流程或付费墙显示为独立屏幕，请对由 [`createFlowView`](capacitor-get-pb-paywalls#fetch-the-view-configuration) 方法创建的 `view` 调用 `view.present()` 方法。默认情况下，关闭的 `view` 会被销毁。如需再次显示该流程，请再次调用 `createFlowView` 创建新的 `view` 实例，或在关闭时[保留已关闭的流程](#keep-a-closed-flow-for-later)。

:::warning
重复使用已销毁的 `view` 会导致错误。
:::

```typescript showLineNumbers

const view = await createFlowView(flow);

// Optional: handle flow events (close, purchase, restore, etc)
// await view.setEventHandlers({ ... });

try {
  await view.present();
} catch (error) {
  // handle the error
}
```

:::important
多次调用 `setEventHandlers` 会覆盖你设置的处理器，替换掉对应事件之前设置的默认处理器和自定义处理器。
:::

## 配置 iOS 展示样式 \{#configure-ios-presentation-style\}

通过向 `present()` 方法传入 `iosPresentationStyle` 参数，可以配置流程在 iOS 上的展示方式。该参数接受 `'full_screen'`（默认值）或 `'page_sheet'` 两种值。在 Android 上，流程始终在应用的 Activity 中以全屏模式展示。

```typescript showLineNumbers
try {
  await view.present({ iosPresentationStyle: 'page_sheet' });
} catch (error) {
  // handle the error
}
```

## 保留已关闭的流程以供后续使用 \{#keep-a-closed-flow-for-later\}

:::info
`destroy` 选项和 `destroy()` 方法从 SDK 4.3.0 版本开始支持。
:::

当用户可能很快重新打开某个流程时（例如设置页面中按钮触发的付费墙），保留该流程而不销毁它，这样再次打开时无需重新加载，且可以从上次离开的位置继续。

默认情况下，`view.dismiss()` 会关闭流程并销毁其原生视图，因此 `view` 无法再次呈现。如果希望稍后再次呈现同一流程，请传入 `destroy: false`。下次调用 `present()` 时，流程会从用户关闭时所在的页面重新打开，保留用户离开时的状态，且事件处理程序依然有效：

```typescript showLineNumbers
// Close the flow and keep its native view in memory
await view.dismiss({ destroy: false });

// Later: open the flow again on the same screen
await view.present();
```

原生视图会一直保留在内存中，直到你主动释放它。当你不再需要该流程时，请调用 `destroy()`：

```typescript showLineNumbers
await view.dismiss({ destroy: false });
// ...
await view.destroy();
```

`destroy()` 会先关闭仍在屏幕上显示的视图，再清除其事件处理器。请仅对使用 `destroy: false` 关闭的视图调用此方法：普通的 `dismiss()` 会自动释放视图，之后再调用 `destroy()` 将会失败。

当拥有视图的组件销毁时（Angular 的 `ngOnDestroy`、React 的 `useEffect` 清理函数、或 Vue 的 `onUnmounted`），请释放所持有的视图。否则原生视图将在整个会话期间持续占用内存。注意捕获错误：视图可能已被提前释放，例如事件处理函数返回 `true` 之后。

```typescript showLineNumbers
// For example, in a React useEffect cleanup
return () => {
  view.destroy().catch(() => {
    // the view was already released
  });
};
```

返回 `true` 的事件处理器会通过常规的 `dismiss()` 关闭流程，即使你之前保留过原生视图，也会将其销毁。默认的 `onCloseButtonPress` 和 `onError` 处理器均返回 `true`。任何你让其返回 `true` 的处理器也是如此，例如 `onAndroidSystemBack`。若要在用户关闭时保留流程，请自行关闭并返回 `false`：

```typescript showLineNumbers
await view.setEventHandlers({
  onCloseButtonPress() {
    view.dismiss({ destroy: false }).catch(error => {
      // handle the error
    });
    return false;
  },
});
```

## 使用开发者自定义计时器 \{#use-developer-defined-timer\}

本节适用于在流程与付费墙编辑工具中行为设置为 **Developer defined** 的计时器。在编辑工具中，每个此类计时器都有一个 **Timer ID**（参见 [让应用设置结束日期](flow-timer#let-your-app-set-the-end-date)），由应用为其设置结束时间。代码中使用的 Timer ID 必须与编辑工具中的完全一致，包括字母大小写和空格。如果 ID 不匹配，计时器将无法从应用获取结束时间。

要设置结束日期，请将 `customTimers` 参数传入 `createFlowView`：这是一个将每个 Timer ID 映射到 `Date`（即计时器结束日期）的对象。

```typescript showLineNumbers

const customTimers = {
  CUSTOM_TIMER_NY: new Date(new Date().getFullYear() + 1, 0, 1), // next New Year's Day
};

try {
  const view = await createFlowView(flow, { customTimers });
  await view.present();
} catch (error) {
  // handle the error
}
```

在此示例中，`CUSTOM_TIMER_NY` 是编辑工具中**开发者自定义**计时器的 Timer ID。该计时器显示距下一个元旦还剩多少时间，例如 `13d 09h 03m 34s`。

SDK 在创建视图时会读取一次 `customTimers`，因此你计算出的日期（例如从现在起 6 小时后）从该时刻开始倒计时。如果日期已过，计时器立即显示为零，并触发其 **On timer end** 事件。如果 `customTimers` 中没有某个 Timer ID 对应的键，计时器将从打开页面时起倒计时一小时。

## 显示对话框 \{#show-dialog\}

当 Android 上展示 flow 视图时，请使用此方法代替原生的 alert 对话框。在 Android 上，普通 alert 会出现在 flow 视图的后面，导致用户无法看到。此方法可确保在所有平台上，对话框都能正确显示在 flow 的上层。

```typescript showLineNumbers
try {
  const action = await view.showDialog({
    title: 'Close paywall?',
    content: 'You will lose access to exclusive offers.',
    primaryActionTitle: 'Stay',
    secondaryActionTitle: 'Close',
  });

  if (action === 'secondary') {
    // User confirmed - close the flow
    await view.dismiss();
  }
  // If primary - do nothing, user stays
} catch (error) {
  // handle error
}
```

## 用新订阅替换旧订阅 \{#replace-one-subscription-with-another\}

当 Android 用户在已有活跃订阅的情况下尝试购买新订阅时，你可以在创建流程视图时传入订阅更新参数，来控制新购买的处理方式。如需用新订阅替换当前订阅，请在 `createFlowView` 中使用 `productPurchaseParams`，并传入 `oldSubVendorProductId` 和 `prorationMode` 参数。

```typescript showLineNumbers

const productPurchaseParams = flow.paywalls
  .flatMap((paywall) => paywall.productIdentifiers)
  .map((productId) => {
    const params: MakePurchaseParamsInput = {};
    if (Capacitor.getPlatform() === 'android') {
      params.android = {
        subscriptionUpdateParams: {
          oldSubVendorProductId: 'PRODUCT_ID_OF_THE_CURRENT_ACTIVE_SUBSCRIPTION',
          prorationMode: 'with_time_proration',
        },
      };
    }
    return { productId, params };
  });

const view = await createFlowView(flow, { productPurchaseParams });
```

<SDKv3>

如果你使用付费墙编辑工具自定义了付费墙，则无需在移动端代码中手动处理其渲染逻辑来向用户展示它。此类付费墙已包含展示内容与展示方式的完整配置。

:::warning
本指南仅适用于旧版付费墙编辑工具构建的付费墙。如需展示自定义付费墙，请参阅[展示自定义付费墙](present-remote-config-paywalls-capacitor)。
:::

要显示付费墙，请在由 [`createPaywallView`](capacitor-get-pb-paywalls#fetch-the-view-configuration-of-paywall-designed-using-paywall-builder) 方法创建的 `view` 上调用 `view.present()` 方法。每个 `view` 只能使用一次。如果需要再次显示付费墙，请重新调用 `createPaywallView` 创建新的 `view` 实例。

:::warning

重复使用同一个 `view` 而不重新创建，可能会导致错误。
:::

```typescript showLineNumbers

const view = await createPaywallView(paywall);

view.setEventHandlers({
  onUrlPress(url) {
    window.open(url, '_blank');
    return false;
  },
});

try {
  await view.present();
} catch (error) {
  // handle the error
}
```

## 使用开发者自定义计时器 \{#use-developer-defined-timer\}

要在移动应用中使用开发者自定义计时器，请使用 `timerId`，在本例中为 `CUSTOM_TIMER_NY`，即你在 Adapty 看板中设置的开发者自定义计时器的 **Timer ID**。这可确保你的应用动态更新计时器，显示正确的值——例如 `13d 09h 03m 34s`（计算方式为计时器的结束时间（如元旦）减去当前时间）。

```typescript showLineNumbers
const customTimers = { 'CUSTOM_TIMER_NY': new Date(2025, 0, 1) };

const view = await createPaywallView(paywall, { customTimers });
```

在此示例中，`CUSTOM_TIMER_NY` 是你在 Adapty 看板中设置的开发者自定义计时器的**计时器 ID**。计时器会确保你的应用动态更新并显示正确的倒计时值——例如 `13d 09h 03m 34s`（由计时器的结束时间（如元旦）减去当前时间计算得出）。
