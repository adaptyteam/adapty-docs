**Adapty Developer CLI** 是一个命令行工具，让你无需打开看板即可管理 Adapty 账户。它提供了主要的配置功能，可从终端或自动化环境中访问。

**使用 CLI 可以做到：**

- 在您的 Adapty 账户中创建并配置 iOS 和 Android 应用
- 定义访问等级——即应用在运行时检查的订阅层级
- 设置产品并将其映射到 App Store 和 Google Play 的商店 ID
- 创建付费墙并为其分配产品
- 创建流程、编写其构建配置并发布——请参阅命令参考中的[流程](developer-cli-reference#flows)
- 配置版位以通过 SDK 获取付费墙或流程
- 通过 [Ads Manager](developer-cli-ads-manager) 管理 Apple Ads 推广活动、关键词及自动化规则
- 通过 [Attribution](developer-cli-attribution) 读取 Adapty 归因报告——包括各渠道和推广活动的广告花费、安装量、营收及 ROAS
