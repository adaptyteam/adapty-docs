**Adapty Developer CLI** 是一款命令行工具，让你无需打开看板即可管理 Adapty 账户。它提供主要配置功能，可在终端或自动化环境中使用。

<AIPromo id="adapty-mcp" title="Work from a chat instead of a terminal." cta="Connect the Adapty MCP server">
Adapty MCP 服务器让 Claude 应用、Claude Code、Codex 及其他 MCP 客户端共享同一个账号。你只需在浏览器中登录一次，无需安装任何内容。
</AIPromo>

**使用 CLI 可以做到：**

- 在 Adapty 账户中创建并配置 iOS 和 Android 应用
- 定义访问等级——即应用在运行时检查的订阅层级
- 配置产品并将其映射到 App Store 和 Google Play 的商店 ID
- 将商店优惠（包括 Google Play 免费试用）关联到产品——详见命令参考中的[产品优惠](developer-cli-products#product-offers)
- 创建付费墙并为其分配产品
- 创建流程、编写其编辑器配置并发布——详见命令参考中的[流程](developer-cli-flows)
- 配置版位，通过 SDK 获取付费墙或流程
- 通过[Analytics](developer-cli-analytics)查看应用的分析数据——收入、MRR、转化率、漏斗、留存率、LTV 和同期群
- 通过[A/B 测试](developer-cli-ab-tests)创建、启动、停止和替换付费墙及流程的 A/B 测试
- 通过[Ads Manager](developer-cli-ads-manager)管理 Apple Ads 广告系列、关键词和自动化规则
- 通过[Attribution](developer-cli-attribution)查看 Adapty 归因报告——按渠道和广告系列划分的花费、安装量、收入和 ROAS
- 通过[Retention Messaging](developer-cli-retention-messaging)设置 Apple 留存消息，并创建、修改和激活订阅者取消订阅时看到的留存消息
- 通过[Refund Saver](developer-cli-refund-saver)开启 Refund Saver、设置退款偏好，并查看已节省的金额
- 通过[Virtual currencies](developer-cli-virtual-currencies)创建虚拟货币、设置每个产品授予的积分数量，并查看用户的积分交易记录和余额
- 迁移 RevenueCat 项目——包括产品目录、付费墙设计、应用代码和交易历史——详见[从 RevenueCat 迁移](migration-from-revenuecat)
- 使用 `adapty skills install` 将 Adapty 技能安装到你的编程智能体中——详见命令参考中的[Skills](developer-cli-reference#skills)
