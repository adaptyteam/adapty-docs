**Adapty Developer CLI** 是一款命令行工具，无需打开看板即可管理您的 Adapty 账户。它提供了主要的配置功能，可在终端或自动化环境中使用。

<AIPromo id="adapty-mcp" title="通过对话界面替代终端操作。" cta="连接 Adapty MCP 服务器">
Adapty MCP 服务器可让 Claude 应用、Claude Code、Codex 及其他 MCP 客户端访问同一账户。您只需在浏览器中登录一次，无需安装任何内容。
</AIPromo>

**使用 CLI 可以完成以下操作：**

- 在 Adapty 账户中创建并配置 iOS 和 Android 应用
- 定义访问等级——应用在运行时检查的订阅层级
- 设置产品并将其映射到 App Store 和 Google Play 商店 ID
- 将商店优惠（包括 Google Play 免费试用）关联到产品——详见命令参考中的[产品优惠](developer-cli-products#product-offers)
- 创建付费墙并为其分配产品
- 创建流程、编写构建配置并发布——详见命令参考中的[流程](developer-cli-flows)
- 配置版位，通过 SDK 获取付费墙或流程
- 通过 [Analytics](developer-cli-analytics) 查看应用分析数据——包括收入、MRR、转化率、漏斗、留存率、LTV 和同期群
- 通过 [A/B tests](developer-cli-ab-tests) 创建、启动、停止及替换付费墙和流程的 A/B 测试
- 通过 [Ads Manager](developer-cli-ads-manager) 管理 Apple Ads 广告系列、关键词和自动化规则
- 通过 [Attribution](developer-cli-attribution) 查看 Adapty 归因报告——按渠道和广告系列细分的支出、安装量、收入及 ROAS
- 通过 [Retention Messaging](developer-cli-retention-messaging) 设置 Apple 留存消息，并创建、修改和激活订阅者取消时看到的留存消息
- 迁移 RevenueCat 项目——包括目录、付费墙设计、应用代码和交易历史——详见[从 RevenueCat 迁移](migration-from-revenuecat)
- 使用 `adapty skills install` 将 Adapty 技能安装到编程助手中——详见命令参考中的[技能](developer-cli-reference#skills)
