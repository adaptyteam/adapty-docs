**Adapty Developer CLI** 是一个命令行工具，让你无需打开看板即可管理 Adapty 账户。它提供了主要的配置功能，可从终端或自动化环境中访问。

**使用 CLI 可以做到：**

- 在您的 Adapty 账户中创建并配置 iOS 和 Android 应用
- 定义访问等级——应用在运行时检查的订阅层级
- 设置产品并将其映射到 App Store 和 Google Play 的商店 ID
- 创建付费墙并为其分配产品
- 配置版位以便通过 SDK 获取付费墙
- 通过 [Ads Manager](developer-cli-ads-manager) 运行 Apple Ads 广告系列、关键词及自动化规则
