恢复购买功能在 iOS 和 Android 上均可使用，它允许用户重新获取此前已购内容（如订阅或应用内购买）的访问权限，而无需再次付费。对于那些卸载后重新安装应用、或更换了新设备却希望继续访问已购内容的用户来说，这一功能尤为实用。

:::note
如果你在编辑工具中构建了界面，则无需手动恢复购买。只需绑定其恢复控件——在 Flow & 付费墙编辑工具中使用 **Restore purchases** 操作，或在旧版中使用恢复链接或按钮——SDK 会自动完成恢复。
:::

如果你是自己构建的界面，请调用 `.restorePurchases()` 方法：

```csharp showLineNumbers
Adapty.RestorePurchases((profile, error) => {
    if (error != null) {
        // handle the error
        return;
    }
  
    var accessLevel = profile.AccessLevels["YOUR_ACCESS_LEVEL"];
    if (accessLevel != null && accessLevel.IsActive) {
        // restore access
    }
});
```

响应参数：

| 参数 | 描述 |
|---------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Profile** | <p>一个 [`AdaptyProfile`](https://unity.adapty.io/class_adapty_s_d_k_1_1_adapty_profile.html) 对象。该模型包含有关访问等级、订阅和非订阅购买的信息。</p><p>请检查**访问等级状态**以确定用户是否有权访问该应用。</p> |
