Adapty CLI 按主题（如 `products` 或 `placements`）对命令进行分组。每个主题都有独立页面，详细介绍其命令、参数、标志及可接受的值。本页列出所有主题、每条命令通用的标志，以及安装 Adapty 技能的命令。

| 主题 | 命令 | 功能说明 |
|---|---|---|
| [应用与访问等级](developer-cli-apps) | `apps`、`access-levels` | 创建和配置应用，以及应用所检查的订阅层级 |
| [产品与优惠](developer-cli-products) | `products`、`product-offers` | 配置产品，将其映射到 App Store 和 Google Play 的产品 ID，并关联商店优惠 |
| [付费墙](developer-cli-paywalls) | `paywalls` | 创建付费墙并为其分配产品 |
| [流程](developer-cli-flows) | `flows` | 创建流程，编写和验证其编辑器配置，发布流程，并查看相关数据图表 |
| [版位与市场细分](developer-cli-placements) | `placements`、`segments` | 配置版位、其目标受众，以及受众所针对的市场细分。查看流程版位的数据图表 |
| [分析](developer-cli-analytics) | `analytics` | 查看数据图表、转化率、漏斗、留存率、LTV 和同期群 |
| [A/B 测试](developer-cli-ab-tests) | `ab-tests` | 创建、启动、停止、替换和归档付费墙及流程 A/B 测试 |
| [归因](developer-cli-attribution) | `attribution` | 按渠道和广告系列查看花费、安装量、收入和 ROAS |
| [Ads Manager](developer-cli-ads-manager-reference) | `asa` | 管理 Apple Ads 广告系列、关键词和自动化规则 |
| [迁移](developer-cli-migrations) | `migrations` | 将 RevenueCat 项目迁移至 Adapty |
| [身份验证](developer-cli-authentication) | `auth` | 登录、检查和撤销 CLI 会话 |

## 全局标志 \{#global-flags\}

这些标志适用于所有命令。

| 标志 | 描述 |
|---|---|
| `--json` | 以 JSON 格式输出，而非格式化文本 |
| `--help` | 显示命令帮助 |

除 `adapty product-offers list` 之外，所有 `list` 命令还支持分页标志：

| 标志 | 默认值 | 描述 |
|---|---|---|
| `--page` | `1` | 页码 |
| `--page-size` | `20` | 每页条数（最大：100） |

## 技能 \{#skills\}

### adapty skills install

将 Adapty 技能安装到本机的编程智能体中。

```bash
adapty skills install
```

| Flag | Required | Description |
|---|---|---|
| `--agent` | No | Agent to install into: `claude-code`, `codex`, or `gemini-cli`. Repeat the flag for several agents. |
| `-y`, `--yes` | No | Install into every agent found without asking. Required when the CLI finds several agents and can't ask, for example with `--json`. |

CLI 会在 `PATH` 中查找 Claude Code、Codex 和 Gemini CLI。如果都未找到，它会询问是否运行 `npx skills@1.7.0 add adaptyteam/adapty-skills --all --global`，此命令适用于其他智能体。重启智能体以加载技能。

Claude Code 不会自动更新插件。要在发布新技能时及时获取，请在 Claude Code 中运行 `/plugin`，打开 **Marketplaces**，选择 `adapty`，然后点击 **Enable auto-update**。如需不通过菜单开启此功能，可在 `~/.claude/settings.json` 的 `adapty` 条目中添加 `"autoUpdate": true`：

```json title="~/.claude/settings.json"
{
  "extraKnownMarketplaces": {
    "adapty": {
      "source": { "source": "github", "repo": "adaptyteam/adapty-skills" },
      "autoUpdate": true
    }
  }
}
```

通过 skills CLI 安装的技能可以使用 `npx skills update` 进行更新。关于 Codex，请参阅 [plugin README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#codex)。
