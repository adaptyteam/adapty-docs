Adapty CLI 按主题（如 `products` 或 `placements`）对命令进行分组。每个主题都有独立的页面，列出其命令、参数、标志及可接受的值。本页面列出了所有主题、每条命令均支持的标志、打印 CLI 版本的命令，以及安装 Adapty 技能的命令。

| 主题 | 命令 | 功能说明 |
|---|---|---|
| [应用与访问等级](developer-cli-apps) | `apps`、`access-levels` | 创建和配置应用，以及应用所检查的订阅层级 |
| [产品与优惠](developer-cli-products) | `products`、`product-offers` | 设置产品，将其映射到 App Store 和 Google Play 的产品 ID，并关联应用商店优惠 |
| [付费墙](developer-cli-paywalls) | `paywalls` | 创建付费墙，为其分配产品，并查看其数据图表 |
| [流程](developer-cli-flows) | `flows`、`fonts` | 创建流程，编写并验证其编辑器配置，上传所用的自定义字体，发布流程，恢复历史版本，复制流程，以及查看其数据图表和页面漏斗 |
| [版位与市场细分](developer-cli-placements) | `placements`、`segments` | 配置版位、目标受众及受众所针对的市场细分。查看流程和付费墙版位的数据图表 |
| [分析](developer-cli-analytics) | `analytics` | 查看数据图表、转化率、漏斗、留存、LTV 和同期群 |
| [A/B 测试](developer-cli-ab-tests) | `ab-tests` | 创建、启动、停止、替换和归档付费墙及流程 A/B 测试，并查看其结果 |
| [归因](developer-cli-attribution) | `attribution` | 按渠道和广告系列查看支出、安装量、收入和 ROAS |
| [广告管理](developer-cli-ads-manager-reference) | `asa` | 管理 Apple Ads 广告系列、关键词和自动化规则 |
| [留存消息](developer-cli-retention-messaging) | `retention-messaging` | 接入 Apple 留存消息，运行性能测试，创建、修改、启用和停用留存消息，并查看其数据图表 |
| [退款保护](developer-cli-refund-saver) | `refund-saver` | 开启或关闭退款保护，设置每个应用商店及单个用户画像的退款偏好，验证各商店的密钥，以及查看退款请求和节省金额 |
| [虚拟货币](developer-cli-virtual-currencies) | `virtual-currencies` | 创建虚拟货币，修改每个产品所授予的积分数量，以及查看应用或用户的积分交易记录和余额 |
| [备用付费墙](developer-cli-fallbacks) | `fallbacks` | 下载应用在无法连接 Adapty 时所使用的备用文件 |
| [迁移](developer-cli-migrations) | `migrations` | 将 RevenueCat 项目迁移至 Adapty |
| [身份验证](developer-cli-authentication) | `auth` | 登录、检查并撤销 CLI 会话 |

## 全局标志 \{#global-flags\}

这些标志适用于所有命令。

| 标志 | 描述 |
|---|---|
| `--json` | 以 JSON 格式输出，而非格式化文本 |
| `--help` | 显示命令帮助 |

除 `adapty product-offers list`、`adapty flows versions list` 以及 `adapty virtual-currencies` 的两个交易列表命令外，所有 `list` 命令也支持分页标志：

| 标志 | 默认值 | 描述 |
|---|---|---|
| `--page` | `1` | 页码 |
| `--page-size` | `20` | 每页条目数（最大：100） |

`adapty virtual-currencies transactions list` 和 `adapty virtual-currencies profiles transactions list` 每个命令读取一页数据，使用游标分页：接受 `--page-size` 和 `--cursor` 参数，而非 `--page`。详见[读取积分交易记录](developer-cli-virtual-currencies#read-credit-transactions)。

## CLI 版本 \{#cli-version\}

### adapty version

打印已安装的 CLI 版本，并检查是否有更新版本可用。

```bash
adapty version
```

该命令输出与 `adapty --version` 相同的内容，然后向公共 npm 注册表查询最新版本，超时限制为 3 秒。如果有更新版本，命令会打印版本号及更新命令 `npm i -g adapty@latest`。如果注册表未在规定时间内响应，命令会打印 `Could not check for a newer version.`，退出码仍为 0。

使用 `--json` 时，输出包含以下字段：

| 字段 | 描述 |
|---|---|
| `installed` | 已安装的 CLI 版本 |
| `latest` | npm 上的最新版本，若注册表未及时响应则为 `null` |
| `update_available` | 当 `latest` 比 `installed` 更新时为 `true`，否则为 `false` |

此命令需要 CLI 0.26.1 或更高版本。若版本低于 0.26.1，请运行 `adapty --version`。

## 技能 \{#skills\}

### adapty skills install

将 Adapty 技能安装到本机的编程智能体中。

```bash
adapty skills install
```

| Flag | Required | Description |
|---|---|---|
| `--agent` | No | Agent to install into: `claude-code`, `codex`, or `gemini-cli`. Repeat the flag for several agents. |
| `-y`, `--yes` | No | Install into every agent found without asking. Required when the CLI finds several agents and can't ask, for example with `--json`. |

CLI 会在 `PATH` 中查找 Claude Code、Codex 和 Gemini CLI。如果都未找到，它会询问是否运行 `npx skills@1.7.0 add adaptyteam/adapty-skills --all --global`，此命令适用于其他智能体。重启智能体以加载技能。

Claude Code 不会自动更新插件。要在发布新技能时及时获取，请在 Claude Code 中运行 `/plugin`，打开 **Marketplaces**，选择 `adapty`，然后点击 **Enable auto-update**。如需不通过菜单开启此功能，可在 `~/.claude/settings.json` 的 `adapty` 条目中添加 `"autoUpdate": true`：

```json title="~/.claude/settings.json"
{
  "extraKnownMarketplaces": {
    "adapty": {
      "source": { "source": "github", "repo": "adaptyteam/adapty-skills" },
      "autoUpdate": true
    }
  }
}
```

通过 skills CLI 安装的技能可以使用 `npx skills update` 进行更新。关于 Codex，请参阅 [plugin README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#codex)。
