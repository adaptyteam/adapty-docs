[流程编辑工具](adapty-flow-builder)将保存与发布分开处理。草稿会将您的工作保存在 Adapty 看板中，而发布则会通过 SDK 将当前版本提供给用户。本文介绍这两种操作及其适用场景。

## 将流程保存为草稿 \{#save-a-flow-as-a-draft\}

:::warning
无效的[远程配置](customize-flow-with-remote-config)会导致草稿无法保存。
:::

付费墙编辑工具每分钟自动保存一次进度。

如需手动保存草稿，请点击付费墙编辑工具右上角的 **Save draft**，或按 **Cmd/Ctrl + S**。

草稿仅在看板内可见，不会影响用户在应用中看到的内容，即使该流程已分配至某个[版位](placements)也是如此。

<ZoomImage id="flow-builder-save-draft.webp" width="700px" alt="Save draft button in the Flow Builder top toolbar" />
## 发布流程 \{#publish-a-flow\}

发布操作会通过 SDK 将当前版本的流程提供给用户。发布后，新版本将替换同一流程之前已发布的任何版本。

:::note
如需将流程添加到[版位](placements)，请先发布它。草稿状态的流程无法添加。
:::

要发布流程，请点击付费墙编辑工具右上角的 **Publish to Live**。

接下来发生的情况取决于该流程是否已分配到某个版位：
- **流程已关联版位**：用户下次请求该版位时即可看到新版本。
- **流程未关联版位**：将流程添加到[版位](create-placement)，以开始向用户展示。

:::tip
当每个操作、页面和产品元素均配置完成后，流程即可发布。常见问题请参阅[问题排查](#troubleshooting)。
:::

<ZoomImage id="flow-builder-publish-to-live.webp" width="500px" alt="Publish to Live button in the Flow Builder top toolbar" />
:::warning
[自定义字体](using-custom-fonts-in-flow-builder)不会随流程一起打包——你必须将每个字体文件单独添加到应用包中。若缺少字体文件，用户将看到系统默认字体。

如需在已发布的流程中更换字体且不影响旧版本：请[复制该流程](copy-flows)，在副本中修改字体，然后将副本通过[目标受众](add-audience-paywall-ab-test)定向到已包含该字体的应用版本。
:::

## 流程状态 \{#flow-status\}

每个流程在[流程列表](filter-flows)中都会显示一个状态，反映该流程在保存和发布生命周期中所处的阶段。

| 状态 | 含义 |
| :----- | :------ |
| **Draft** | 该流程从未发布过。目前只存在草稿，用户尚未看到它。需要先发布草稿，才能将其添加到[版位](placements)。 |
| **Dirty** | 该流程已发布，但存在已保存但尚未发布的编辑内容。用户看到的仍是上次发布的版本，直到再次发布为止。 |
| **Publishing** | 正在发布中。 |
| **Failed** | 上次发布尝试失败。如果存在上次发布的版本，用户将继续看到该版本。 |
| **Published** | 最新保存的版本已上线，没有未发布的编辑内容。 |
| **Archived** | 该流程已被[归档](archive-flows#archive-a-flow)，在[恢复](archive-flows#restore-a-flow)之前无法编辑。 |

## 故障排除 \{#troubleshooting\}

操作未完成、屏幕为空、产品元素未绑定产品，或无效的远程配置 JSON，都会导致预览和发布被阻止。如需查看完整问题列表及解决方法，请参阅[常见问题](flow-common-issues#a-flow-wont-preview-or-publish)。

在 [Adapty 应用](paywall-device-compatibility-preview)中预览你的流程，以便在发布前发现问题。如果流程在预览时加载失败，请查看错误信息了解详情。
