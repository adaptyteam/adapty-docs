Adapty 使用应用内购买密钥来验证应用内的购买，并为[促销活动](offers)签名。在 App Store Connect 中生成密钥，然后在 Adapty 的 **App settings** 的两个部分中输入该密钥。如果密钥失效或需要更换，请[替换密钥](#replace-the-key)。

App 内购买密钥与 [App Store Connect API 密钥](app-store-connect-api-key)不同，尽管 App Store Connect 对这两种密钥的 ID 均标注为 **Issuer ID** 和 **Key ID**。

如需在 **App settings** > **iOS SDK** 中一次性填写所有凭据，请参阅[配置 App Store 集成](app-store-connection-configuration)。

## 替换密钥 \{#replace-the-key\}

如果密钥失效或需要更换，请在吊销旧密钥之前先将新密钥保存到 Adapty。

密钥失效时会出现以下情况：

- 应用内购买无法解锁任何访问等级，且应用不会收到任何报错。
- 用户无法兑换促销活动。
- [Refund Saver](refund-saver) 无法响应消耗请求。
- Adapty 不会显示任何警告，**App Store server notifications** 部分中的状态仍显示为 **Active**。

当您的应用迁移至另一个 Apple 开发者账号时，请[将密钥替换为新所有者团队的密钥](transfer-apps#app-store-ios-transfer)。

To replace the key:

1. 在 Adapty 中，进入 [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk)。要确认 Adapty 当前使用的密钥，在 **In-app purchase API (StoreKit 2)** 部分，记录 **Key ID** 字段中的值。
2. [生成一个新密钥](#generate-the-key-in-app-store-connect)。
3. 在 **In-app purchase API (StoreKit 2)** 和 **App Store promotional offers** 部分，[将新密钥添加到 Adapty](#add-the-key-to-adapty)，然后点击 **Save**。
4. 一个密钥可供你 App Store Connect 团队的所有应用使用。如果其他 Adapty 应用也使用了第 1 步中的 Key ID，请将新密钥一并添加到这些应用中。同时，将你服务器上使用旧密钥的地方也替换为新密钥。
5. 已吊销的密钥将在所有使用它的应用中立即失效，且无法恢复。请在 App Store Connect 中吊销旧密钥：即第 1 步中 Key ID 对应的有效密钥。

当 Adapty 没有可用密钥时完成购买的用户，可以通过[恢复购买](troubleshoot-app-store-integration#a-purchase-succeeds-but-the-customer-loses-access)找回访问权限。
