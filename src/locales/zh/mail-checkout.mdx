Adapty Mail 发送的每封邮件都包含一个专属于该收件人的唯一结账链接。用户点击后，会进入一个网页结账漏斗，该漏斗会通过用户画像识别用户身份、展示你的优惠内容并完成支付处理。结账漏斗保存在 Adapty Mail 的 **Web Paywalls** 中，通过内置的 **web paywall builder** 进行编辑。
## 前提条件 \{#requirements\}

- 需要一个已配置好订阅产品的网页支付服务商。**Generate with AI** 仅支持 Stripe，并在编辑工具中直接连接。**Use your own hosted paywall** 可接受任意服务商——Stripe、Paddle、PayPal 或其他——因为支付流程由你自行处理。
您无需为网页付费墙编辑器单独注册账户。它已内置于 Adapty Mail 中：首次登录时系统会自动为您创建工作区，并使用您的 Adapty 凭据登录编辑器。这与您在主 Adapty 看板付费墙页面上配置的任何网页付费墙无关——Adapty Mail 的网页付费墙是独立的实体，完全由 Adapty Mail 管理。
## 设置结账流程 \{#set-up-your-checkout-funnel\}

在 Adapty Mail 中，前往 **Web Paywalls → Create**。你有两种方式：

- **Generate with AI**：Adapty Mail 内置的网页付费墙编辑工具会自动为你生成漏斗。仅支持 Stripe——如需使用 Paddle 或 PayPal，请选择第二种方式。
- **Use your own hosted paywall**：接入你自己托管的付费墙，支持任意支付服务商。
### 使用 AI 生成 \{#generate-with-ai\}

创建页面顶部会显示一个**前提条件**面板，其中包含内联操作按钮，引导你完成每个前提条件——品牌准备就绪、编辑工具登录、Stripe 连接、产品配置，以及最终的审核与发布步骤。逐一完成后，面板会随每个步骤的完成自动刷新。

<ZoomImage id="mail-checkout-prerequisites.webp" width="500px" alt="Prerequisites panel on the Web Paywall Create page with checklist items and inline action buttons" />

所有前提条件变为绿色后，点击 **Generate** 打开生成对话框。需要做两个选择：
- **Environment**：选择 **Production** 或 **Sandbox**。Sandbox 使用你的 Stripe 测试模式产品，适合开发和本地环境，其账户与生产环境完全隔离，测试交易不会影响线上数据。
- **Plans**：最多选择 **3 个 Stripe 方案**。每个方案是产品与价格的组合，付费墙会将这些方案作为结账时的可选项呈现给用户。如果选择的方案少于 3 个，付费墙只会展示你已选的方案。
<ZoomImage id="mail-checkout-generation-dialog.webp" width="500px" alt="Web paywall generation dialog with Environment toggle and Stripe plan selector" />

点击 **Generate** 开始构建。构建完成后，在编辑工具中打开预览结果并发布，然后点击 **Save**。

:::important
付费墙必须先发布，才能处理结账流量。未发布的付费墙在用户点击邮件结账链接时会返回错误。
:::
有关付费墙编辑工具中支付提供商的详细配置（Stripe 账号、测试与正式模式、产品设置），请参阅[网页付费墙配置](web-paywall-configuration)。
### 使用自托管付费墙 \{#use-your-own-hosted-paywall\}

在此方式下，Adapty Mail 会将收件人引导至你自己托管的页面，并将每位收件人的对应值替换到 URL 中。点击之后的全部流程——优惠展示、支付、个性化——均在你这一侧完成，可搭配任意支付服务商。

1. 在 **Web Paywalls → Create** 中，选择 **Enter URL manually**。
2. 粘贴你的付费墙 URL，并将占位符作为查询参数附在其中。Adapty Mail 会针对每位收件人进行替换，以便页面识别访客身份。示例：

```
   https://example.com/paywall?email={email}&adapty_profile_id={adapty.external_profile_id}
   ```
3. 为付费墙填写 **Name** 并保存，之后即可将其绑定到推广活动中。

创建页面列出了所有可用的占位符，并会自动勾选在您粘贴的 URL 中找到的占位符：

| 占位符 | 值 |
| --- | --- |
| `{email}` | 收件人的电子邮件地址。 |
| `{adapty.external_profile_id}` | 收件人在 Adapty 中的用户画像 ID。 |
| `{funnelfox.external_profile_id}` | 收件人在 FunnelFox 中的用户画像 ID。 |
| `{custom.external_profile_id}` | 您通过 [Adapty Mail API](mail-send-data-via-api) 发送的用户 ID。 |
| `{scheduled_email_id}` | 携带该链接的电子邮件 ID。 |

这三个用户画像 ID 占位符分别对应用户画像的不同来源，无论你的项目是否用到所有来源，页面都会一并列出。请根据数据发送方式选择对应的占位符：`{adapty.external_profile_id}` 用于 [Adapty 集成](mail-collect-emails)，`{custom.external_profile_id}` 用于 [API](mail-send-data-via-api)。若收件人没有某个占位符对应的值，该占位符会被解析为空字符串，不会以字面文本形式出现在页面上；而 Adapty Mail 无法识别的占位符则会原样保留，按你输入的内容直接传递。

#### 你的页面需要做什么 \{#what-your-page-has-to-do\}

Adapty Mail 的工作到重定向为止。接下来有两件事需要你来完成：

- **在结账开始前识别访客**：从查询字符串中读取用户画像 ID 或邮箱，并将其附加到购买记录上，确保付款归属于该邮件发送对象。
- **回传购买结果**：Adapty Mail 无法感知在您自有支付渠道发生的付款，而它不知晓的购买既不会计入 [Analytics](mail-analytics) 的转化，也不会计入归因收入——更糟的是，后续邮件序列仍会继续发送给已购买的用户。请通过已有的数据通路回传购买信息：[Adapty 集成](mail-collect-emails) 或 Adapty Mail API 上的[交易事件](mail-send-data-via-api#send-transaction-events)。

#### 上线前先测试 \{#test-it-before-launching\}

**Send test email** 可验证邮件是否正常渲染且付款页面可用，但通过 URL 添加的付费墙无法选择 **Sandbox** 模式——弹窗会提示 *"This paywall has no sandbox products, so only production is available."* 因此，测试流量会直接流向您的正式页面并使用真实产品：您可以用真实银行卡付款后申请退款，或将 URL 指向自己的测试环境以验证整体流程。详见[测试您的设置](mail-testing#test-the-email-and-checkout-on-their-own)。

## 结账页面的外观 \{#what-the-checkout-looks-like\}

当用户点击结账链接时，会进入**主转化页面**。完成支付操作后，将看到**支付成功**或**支付失败**页面——每次尝试只显示其中一个。

**主转化页面**
一个完整的销售展示页面。AI 会为每个板块自动生成文案和图片：
| 版块 | AI 生成内容 |
|---|---|
| 标题 | 醒目、突出利益点的加粗标题 |
| 副标题 | 辅助说明价值主张 |
| 优惠徽章 | 紧迫感徽章（不生造价格——使用模糊的促销文案） |
| CTA 按钮 | 行动导向文案，2–5 个词 |
| 核心优势 | 3–6 张带表情符号的优势卡片 |
| 功能特性 | 3–8 条功能说明，含标题和副标题 |
| 订阅方案 | 方案选择标题及优惠倒计时文案 |
| 社会证明 | 社区口碑文案及 3–5 条真实感用户评价 |
| 常见问题 | 3–6 个常见问题及解答 |
| 保障承诺 | 退款或满意度保障文案 |
**付款成功**
附带后续步骤说明的祝贺消息，以及一张 AI 生成的图片。

**付款失败**
友好提示用户重试的消息。结账状态保持不变。
## 个性化的工作原理 \{#how-personalization-works\}

每封邮件的 CTA 链接均指向为收件人专门构建的结账 URL。发送前，Adapty Mail 会将付费墙 URL 中的每个占位符替换为该收件人对应的值：

```
https://example.com/paywall?email=jane@example.com&adapty_profile_id=6f2a...c91
```

生成的付费墙会自动获取这些参数，无需在网页版付费墙编辑工具中进行任何配置。对于通过 URL 添加的付费墙，你可以自行选择要包含哪些占位符。用户点击后，结账页面会读取这些参数来识别用户身份。购买完成后，Adapty 会将收入归因到具体促成转化的电子邮件地址。相关数据会显示在[营销活动分析](mail-analytics)中。

## 故障排查 \{#troubleshooting\}

| 问题 | 解决方案 |
|---|---|
| 结账链接无法打开 | 请确认付费墙已在网页付费墙编辑工具中发布 |
| 结账时用户未被识别 | 请确认在发送邮件之前已使用正确的用户 ID 调用了 `Adapty.identify()` |
| 购买未归因到邮件 | 归因依赖于用户点击邮件中的 CTA 链接，因此收件人必须通过该链接进入结账页面，且购买记录需在同一用户画像下到达 Adapty Mail。若某次购买已归因到更早的邮件，则保持原归因不变 |
