每封邮件都会链接到浏览器中的结账页面，购买在该页面上完成。要创建结账页面，请在 Adapty Mail 中进入 **Email Destinations**，选择 **Web Paywall**，然后点击 **Create**。共有两种选项：

| | AI 生成 | 自行托管 |
| --- | --- | --- |
| 页面构建方 | Adapty Mail（内置 Web 付费墙编辑工具） | 您 |
| 支付服务商 | 仅限 Stripe | 任意 |
| 项目 | 必须关联 Adapty 应用 | 任意 |
| 您的工作 | 选择方案，然后审核并发布 | 构建页面、从 URL 中读取收件人信息、回传购买数据 |

:::note
Adapty 核心产品有其自己的 Web 付费墙，这是一个独立功能——本文内容与其无关。
:::

## 使用 AI 生成 \{#generate-with-ai\}

:::warning
AI 生成需要将项目**关联到 Adapty 应用**——即你第一次从 Adapty 看板打开 Mail 时，Adapty 为你创建的那个应用。如果你是在 Adapty Mail 中自行创建的项目，或使用独立账户或你自己的 Adapty 账户，请自行托管付费墙。
:::

### 生成的付费墙长什么样 \{#what-a-generated-paywall-looks-like\}

生成后会产生四个页面，收件人从邮件中点击链接后将依次看到：

1. **邮箱** — 包含一个标题、一个副标题和一个邮箱输入框。Adapty Mail 会从链接中自动填入邮箱，这样营销活动带来的流量可以直接进入下一步；通过其他方式访问的用户则需要手动输入。
2. **付费墙** — 销售页面，见下文。
3. **支付成功**或**支付失败** — 二者只会显示其中一个。

AI 会根据你的品牌信息自动生成付费墙页面的所有内容：

| 版块 | 内容 |
| --- | --- |
| 标题与副标题 | 开篇宣传语 |
| 优惠徽章 | 紧迫感文案，不含虚构价格 |
| 主视觉图片 | 根据您的品牌生成 |
| 方案 | 标题、限时计时器以及您选择的方案 |
| 亮点 | 3–6 张卡片 |
| 功能特性 | 3–8 项，每项含标题和副标题 |
| 社会认同 | 一行证明文案，以及 3–5 条用户评价 |
| 常见问题 | 3–6 组问答 |
| 品质保障 | 退款或满意度承诺文案 |

CTA 和倒计时始终固定在顶部。**Payment success** 显示生成的图片和后续步骤；**Payment failed** 提示用户再次尝试，并保留结账状态。

## 使用您自己托管的付费墙 \{#use-your-own-hosted-paywall\}

采用这种方式时，Adapty Mail 会将收件人引导至您自己托管的页面。URL 中包含[占位符](#personalize-your-url-with-placeholders-and-hooks)，用于传递用户信息。用户点击后的所有环节——优惠内容、支付流程、个性化体验——都由您来处理，可使用任意支付服务商。

1. 为目标地址设置一个**名称**——在将其关联到推广活动时，你将通过该名称来选择它。
2. 将托管付费墙的 URL 粘贴到 **URL** 字段中。URL 必须使用 HTTPS，并且可以包含[占位符](#personalize-your-url-with-placeholders-and-hooks)，用于替换每位收件人不同的值。
3. 点击 **Save**。目标地址即可在推广活动中使用。

### 使用占位符和钩子个性化您的 URL \{#personalize-your-url-with-placeholders-and-hooks\}

使用占位符和钩子，用每位收件人的唯一值来个性化您的付费墙 URL。[占位符](mail-destinations#placeholders) 列出了完整的占位符集合及使用规则。

### 重定向后您的页面需要完成的操作 \{#what-your-page-has-to-do\}

Adapty Mail 在重定向后不执行任何操作。以下操作由您负责：

- **在结账开始前识别访客**：从查询字符串中读取用户画像 ID 或邮箱，并将其与购买关联，确保付款记录到收到邮件的客户名下。
- **将购买结果回传**：Adapty Mail 无法感知在您自有支付服务商处完成的付款。如果 Adapty Mail 不知道某笔购买的存在，该购买既不会被计为转化，也不会作为归因收入出现在[数据分析](mail-analytics)中——更糟糕的是，系列邮件会继续发送给已经购买的用户。请通过您现有的数据传输路径回传购买信息：[Adapty 集成](mail-collect-emails)，或 Adapty Mail API 的[交易事件](mail-send-data-via-api#send-transaction-events)接口。

### 上线前测试付费墙 \{#test-the-paywall-before-launching\}

**Send test email** 可验证邮件是否正常渲染以及页面能否完成支付，但对于通过 URL 添加的付费墙，**Sandbox** 选项不可用——弹窗会提示 *"This paywall has no sandbox products, so only production is available."* 因此测试会直接访问你的线上页面并使用真实产品：你可以用真实银行卡支付后申请退款，或在验证流程时将 URL 指向自己的测试环境。详情请参阅[测试你的配置](mail-testing#test-the-email-and-checkout-on-their-own)。

## 故障排除 \{#troubleshooting\}

| 问题 | 解决方案 |
|---|---|
| 结账链接无法打开 | 请确认付费墙已在 Web 付费墙编辑工具中发布 |
| 结账时用户未被识别 | 检查 URL 中是否包含与数据来源匹配的占位符。若占位符与数据来源不符，将解析为空字符串，导致该参数为空 |
| 购买未归因到对应邮箱 | 归因依赖于用户点击邮件中的 CTA 链接，因此收件人必须通过该链接进入结账页面，且购买记录需在同一用户画像下到达 Adapty Mail。若该购买已归因于早前的邮件，则保留原有归因 |
