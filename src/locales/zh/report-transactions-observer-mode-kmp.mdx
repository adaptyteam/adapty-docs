<SDKv4>

在 Observer 模式下，Adapty SDK 无法自动追踪通过您现有购买系统完成的购买。您需要手动上报来自应用商店的交易。在发布应用**之前**完成此设置至关重要，以避免分析数据出现错误。

使用 `reportTransaction` 显式上报每笔交易，以便 Adapty 识别。

:::warning
**请勿跳过交易上报！**
如果您不调用 `reportTransaction`，Adapty 将无法识别该交易，它不会出现在分析数据中，也不会被发送到集成系统。
:::

如果您使用 Adapty 流程和付费墙，请在上报交易时包含 `variationId`。这样可以将购买行为与触发它的流程或付费墙关联起来，从而确保分析数据的准确性。

:::warning
请传入用户购买的 `AdaptyPaywallProduct` 的 `paywallVariationId`，而非 `AdaptyFlow.variationId`。流程自身的 variation ID 无法将购买行为与该流程关联。
:::

```kotlin showLineNumbers

Adapty.reportTransaction(
    transactionId = "your_transaction_id",
    variationId = product.paywallVariationId // the AdaptyPaywallProduct the user bought
).onSuccess {
    // Transaction reported successfully
}.onError { error ->
    // handle the error
}
```

参数：

| 参数            | 是否必填 | 描述                                                                                                                                                                                         |
| --------------- | -------- |----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| transactionId   | 必填 | <ul><li> iOS：交易的标识符。</li><li> Android：购买的字符串标识符（`purchase.getOrderId`），其中 purchase 是计费库 [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) 类的实例。</li></ul>                                                       |
| variationId     | 可选 | 实验变体的字符串标识符。请传入用户购买的 `AdaptyPaywallProduct` 的 `paywallVariationId`。该值与包含此产品的 [AdaptyFlowPaywall](https://kmp.adapty.io/adapty/com.adapty.kmp.models/-adapty-flow-paywall/) 的 `variationId` 相同。 |

</SDKv4>

<SDKv3>

在 Observer 模式下，Adapty SDK 无法自动追踪通过现有购买系统完成的购买。你需要手动上报应用商店的交易记录。请务必在发布应用**之前**完成此配置，以免影响分析数据的准确性。

使用 `reportTransaction` 方法，向 Adapty 显式上报每一笔交易，使其得以识别。

:::warning
**切勿跳过交易上报！**
如果未调用 `reportTransaction`，Adapty 将无法识别该交易，该交易不会出现在分析数据中，也不会同步到各集成渠道。
:::

如果您使用 Adapty 流程和付费墙，请在上报交易时附带 `variationId`。这样可以将购买行为与触发它的流程或付费墙关联起来，确保分析数据的准确性。

```kotlin showLineNumbers

Adapty.reportTransaction(
    transactionId = "your_transaction_id",
    variationId = paywall.variationId
).onSuccess {
    // Transaction reported successfully
}.onError { error ->
    // handle the error
}
```

参数：

| 参数            | 是否必填 | 描述                                                                                                                                                                                  |
| --------------- | -------- |----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| transactionId   | 必填 | <ul><li> iOS：交易的标识符。</li><li> Android：购买的字符串标识符（`purchase.getOrderId`），其中 purchase 是计费库 [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) 类的实例。</li></ul>                                                       |
| variationId     | 可选 | 实验变体的字符串标识符。可通过 `AdaptyPaywall` 对象的 `variationId` 属性获取。 |

</SDKv3>
