在任意屏幕的 [**Screen settings**](paywall-layout-and-products#screen-settings) 下方的 **Fill** 面板中设置背景。面板中的每个图层可以是纯色、渐变、图片或视频，一个屏幕可以叠加多个图层——这也是实现[为图片或视频添加色调](#tint-a-background)的方式。

## 图片 \{#image\}

<ZoomImage id="flow-builder-bg-img.webp" width="300px" alt="Flow builder background image" float="right"/>

上传 `.JPG`、`.PNG` 或 `.WEBP` 格式的文件，大小不超过 20 MB。图片会自动缩放以覆盖整个背景区域。

:::note
背景图片和视频会填满整个视口，包括刘海和系统栏后面的区域——即使启用了 **Safe area** 也是如此。请将重要内容远离边缘，以免被裁切。
:::

如需在运行时通过应用代码动态替换背景图片，请启用[自定义媒体 ID](custom-media#custom-media-id)。

## 视频 \{#video\}

<ZoomImage id="flow-builder-bg-vid.webp" width="300px" alt="Flow builder background video" float="right"/>

上传 `.MP4` 或 `.WEBM` 文件，大小不超过 50 MB。预览区显示的是静态帧，但在设备上运行时会播放视频。

开启 **Loop** 可让视频循环播放。

如需在运行时动态切换背景视频，请启用[自定义媒体 ID](custom-media#custom-media-id)。
## 纯色 \{#solid-color\}

<ZoomImage id="flow-builder-bg-solid.webp" width="300px" alt="Flow builder solid background" float="right"/>

输入十六进制色值，并将不透明度设置为 0 到 100%。从色板中选取已保存的[颜色样式](builder-styling)来应用品牌色——背景会自动跟随浅色和深色主题切换。
## 渐变 \{#gradient\}

<ZoomImage id="flow-builder-bg-gradient.webp" width="300px" alt="Flow builder gradient background" float="right"/>

构建多色阶线性渐变：

- **Direction** — 将渐变旋转 0 到 360°。
- **Stops** — 沿色条拖动以调整位置。点击某个色阶可编辑其十六进制颜色值和不透明度。
- **Opacity** — 图层行上的滑块会同时缩放所有色阶，从而保持它们之间的渐变效果不变。

<ZoomImage id="builder-gradient-demo.webp" width="500px" alt="Configuring a gradient fill with multiple color stops" />

## 为背景添加色调 \{#tint-a-background\}

文字叠放在图片或视频上时，只有当背景足够深时才能清晰可读。为了使背景更均匀，可以在媒体上方叠加一个半透明图层：

1. 在 **Screen settings** 中，将 **Fill** 图层设置为您的图片或视频。
2. 要添加第二个图层，点击 **Fill** 旁边的 <Inline id="plus.svg" alt="Plus" />。新图层会出现在列表顶部，覆盖在媒体内容之上。
3. 点击图层的色块，选择 **Gradient** <Inline id="fill-gradient.svg" alt="Gradient" />。若只想加深文字所在边缘的区域，可将渐变设置为从该边缘的不透明色标渐变至另一侧的透明色标。
4. 拖动图层行上的滑块，调整着色的强度。

拖动图层可调整其在堆叠中的位置，点击 <Inline id="close.svg" alt="Close" /> 可将其移除。
