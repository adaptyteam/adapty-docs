使用输入框收集用户信息，例如姓名、电子邮件地址或出生日期。保存用户的回答，并在流程的其他地方引用这些数据，比如在后续页面中直接用名字称呼用户。

## 添加输入项 \{#add-an-input\}

<ZoomImage id="add-input.webp" width="400px" float="right" alt="Add input" />

1. 打开 **Add element** 面板。
2. 在 **Forms & Quiz** 类别中，点击 **Input**。
3. 选择输入类型：
   - **Text：** 任意短文本输入。
   - **E-mail：** 电子邮件地址，可选格式验证。
   - **Password：** 安全文本输入，可配置密码要求。
   - **Number：** 数值输入，可配置格式。
   - **Phone number：** 电话号码。
   - **Date：** 打开日期选择器。
   - **Time：** 打开时间选择器。
   - **Date & Time：** 打开组合选择器。
   - **[Number picker](builder-number-picker)：** 您可设置滚轮的最小值和最大值，用户在此范围内选择一个数字。

## 配置输入项 \{#configure-an-input\}

:::link
有关视觉设置（布局、样式和可见性）的更多详情，请参阅[样式与外观](builder-styling)。
:::

对于所有输入类型，您可以在 **Design** 标签页中配置以下内容：

- **Type：** 将文本字段切换为 Text、E-mail、Password、Number 和 Phone number 类型，或将日期/时间选择器切换为 Date、Time 和 Date & Time 类型。
- **Element ID：** 用于在流程中其他位置引用该输入值的标识符。详见下方[使用输入值](#use-input-values)。
- **Placeholder：** 字段为空时显示的提示文字。
- **State：** 定义输入框在不同场景下的外观。可在 **Default**、**Active**、**Invalid** 和 **Disabled** 之间切换，并为每种状态设置不同的视觉样式。
- **Typography：** 字段中显示值的文字样式。
- **Leading and trailing icons：** 在输入框内添加图标。对于 Password 类型的输入框，只能添加前置图标。

[数字选择器](builder-number-picker)仅提供本列表中的**元素 ID** 和**排版**设置。

## 使用输入值 \{#use-input-values\}

:::tip
您的应用也可以接收输入值。要收集这些值，请[处理 SDK 的分析回调](ios-flow-input)。每当用户离开某个输入框时，回调会传递该输入框的值，您的应用可以在内部进行处理。

对于数字选择器，当用户点击打开另一个屏幕的按钮时，回调会传递对应的值。点击测验选项或切换同一屏幕上的开关时也会触发回调。
:::

每个输入都会自动作为变量使用，无需任何设置或 **On Submit** 操作。该值通过输入的 **Element ID** 引用，你可以在 **Input Settings** 或 **Picker Settings** 中设置该 ID。

如需在流程的其他地方使用输入值（例如个性化文案、填充其他字段或实现条件跳转），请插入一个变量并选择：

**Element > Screen > `<elementId>.value`**

:::link
请参阅以下相关指南，了解如何使用已保存的输入值：
- [条件导航](onboarding-navigation-branching)
- [变量](onboarding-variables)
:::

## 输入验证 \{#input-validation\}

验证行为取决于输入类型。除数字选择器外，每种输入都会暴露一个只读布尔变量 `<elementId>.isValid`，用于反映输入值是否符合该输入的验证规则。可以在条件操作或条件可见性中使用该变量——例如，在邮箱格式有效之前隐藏"下一步"按钮。

:::note
- `isValid` 变量是只读的——无法对其赋值。
- 空输入始终被视为有效。
- 文本输入没有验证规则，`textInput.isValid` 始终返回 `True`。
:::

| 输入类型 | 验证行为 |
|---|---|
| 文本 | 无内置验证规则。 |
| 电子邮件 | 可选。在 **Design** 面板中启用 **Validate email format**，对输入值进行电子邮件格式校验。 |
| 电话号码 | 内置电话号码格式校验。无法在编辑工具中配置——该规则在运行时评估。 |
| 密码 | 可配置。详见下方[密码要求](#password-requirements)。 |
| 数字 | 基于格式。输入值必须符合所选数字格式。详见下方[数字格式](#number-format)。 |
| 日期、时间、日期和时间 | 内置。选择器仅接受有效的日期或时间值。 |

**Invalid** [视觉状态](builder-styling#input-states)会在用户提交表单时触发——例如按下键盘上的 Enter 或 Done 键。在此之前，输入框显示 **Active** 或 **Default** 状态。

### 密码要求 \{#password-requirements\}

密码输入框支持可配置的验证规则。在 **Design** 面板中点击 **Edit password requirements** 即可打开规则编辑器。已启用的规则会以实时清单的形式显示在输入框下方——每条规则满足条件时，对应项目前会出现勾选标记。

可用规则：

- **Min length** — 最少字符数。默认值：8。
- **Max length** — 最多字符数。默认值：32。
- **Uppercase letter** — 至少包含一个 A–Z 大写字母。
- **Lowercase letter** — 至少包含一个 a–z 小写字母。
- **Number** — 至少包含一个数字。
- **Special character** — 至少包含一个非字母数字字符（例如 `!@#$%`）。

只有满足所有已启用的规则，密码才视为有效。

### 数字格式 \{#number-format\}

**Number** 输入设置中的 **Format** 下拉菜单控制输入值的解析方式：

- **Integer** — 仅限整数（例如 `4`）。
- **Decimal (Point)** — 以小数点作为分隔符的小数（例如 `4.89`）。
- **Decimal (Comma)** — 以逗号作为分隔符的小数（例如 `4,89`）。

不符合所选格式的值将被视为无效。

## 在输入事件上触发操作 \{#trigger-actions-on-input-events\}

:::link
主文章：[操作](onboarding-actions)
:::

你可以通过 **Interactions** 面板，在响应用户输入时运行操作：

- **On changed** — 当用户更改输入值时触发。适用于所有输入类型。
- **On submit** — 当用户通过按下键盘上的 Enter 或 Done 提交文本输入时触发。日期和时间选择器以及数字选择器不支持此触发器。
