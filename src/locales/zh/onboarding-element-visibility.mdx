你可以通过为元素添加条件来控制其显示与否。带有条件的元素仅对满足指定条件的用户可见。

:::important
如果你通过 **Show element** 或 **Hide element** [操作](onboarding-actions)来显示或隐藏某个元素，该操作会覆盖该元素上设置的 **Visibility** 条件。此覆盖效果将持续到条件中的变量或元素状态发生更新为止。

对于设置了 **Visibility** 条件的元素，这些操作会立即改变元素状态，[不带任何动画或延迟效果](flow-show-hide-animations#when-animation-and-delay-dont-apply)。

对于需要根据某个条件（例如测验答案）来显示或隐藏的元素，请使用 **Visibility** 条件。对于需要在特定时刻改变可见性的情况（例如[屏幕打开或用户点击某个元素时](flow-show-hide-animations#show-or-hide-an-element)），请使用动作。
:::

为元素添加条件：

1. 在画布或图层面板中选择该元素。
2. 在右侧面板的 **Visibility** 部分，选择 **Conditional**。

<ZoomImage id="flow-conditional-visibility.webp" width="500px" alt="Conditional visibility settings" />

3. 通过从三个标签页中选择属性类型来设置条件：
   - **Custom**：由你创建和管理的变量，其值可通过用户交互更新。详情请参阅[变量](onboarding-variables)。
   - **Products**：流程中产品的属性，例如价格或名称。
   - **Elements**：流程中其他元素的状态，例如试用开关是否已激活。
4. 输入要匹配的 **Value**。
5. 点击运算符可根据需要进行更改。
6. （可选）点击 **Add condition** 添加更多条件。使用选择器来要求所有条件都匹配，或只需满足其中任意一个。
