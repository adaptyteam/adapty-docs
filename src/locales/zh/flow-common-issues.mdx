本文整理了在[流程编辑器](adapty-flow-builder)中构建流程时最常见的问题，并逐一说明原因与解决方法。

## 流程无法预览或发布 \{#a-flow-wont-preview-or-publish\}

<ZoomImage id="flow-publish-error.webp" width="300px" alt="Publish error message in the Flow Builder web UI when a flow has incomplete actions" float="right" />

如果存在以下任何问题，您将无法发布或预览流程。

- 与配置不完整的交互。常见情况：
    - **打开 URL** 操作没有目标 URL。
    - **跳转至屏幕** 操作没有目标页面——当目标页面在操作设置完成后被删除时也会出现此问题。
    - **条件操作** 没有运算符或值。
    - **设置变量** 操作没有变量/值分配。
    - **购买** 操作没有产品（应用内商店）或没有 Web 付费墙 URL（网页支付）。
    - **自定义** 操作没有操作 ID。
    - **显示提示** 操作的标题或消息为空。
    - **显示**或**隐藏**操作没有选中任何元素。
    - **选择产品** 操作没有目标产品——当目标产品元素被删除、移出其产品组或留在其他屏幕上时也会出现此问题。
    - **选择产品** 操作保存在可复用组件内，或其目标元素 ID 在多个屏幕上重复使用。
- **没有任何元素的屏幕**。
- **未关联产品的产品元素**——移除引用的产品后可能出现此情况。
- 无效的**远程配置** JSON 会中断整个交付流程——您甚至无法保存草稿。

在发布之前，建议[在 Adapty 应用中预览流程](paywall-device-compatibility-preview)。如果流程无法加载，错误信息会提供更多详情。

以上列出的是阻止流程保存的问题。即使流程通过了所有这些检查，对真实用户而言仍可能存在隐患——例如缺少恢复购买操作、购买按钮失效、缺少翻译等。[流程审查技能](flow-audit-skill)专门用于检测此类问题，并以通过/失败的结论作为最终输出，而非错误信息。

## 发布失败，提示"Something went wrong" \{#publishing-fails-with-something-went-wrong\}

此错误表示发布请求在 Adapty 侧失败，并非你的流程配置有误——这也是错误提示较为通用的原因。你的线上版本不受影响。请复制错误信息中的 **Request ID**，并发送至 [support@adapty.io](mailto:support@adapty.io)，以便团队定位该失败请求。

## 购买时优惠未生效 \{#an-offer-doesnt-apply-at-purchase\}

编辑工具会验证每个产品元素是否已关联产品，但不会验证产品的优惠。如果优惠在商店或 Adapty 中被修改或删除，流程仍会正常发布，购买也会在没有优惠的情况下继续进行。修改优惠后，请重新打开流程，为每个受影响的产品元素重新选择优惠，然后重新发布。

## 预览中优惠价格为空 \{#an-offer-price-is-empty-in-the-preview\}

编辑工具预览无法连接应用商店，因此 `offer_price`、`offer_billing_period` 和 `offer_full_duration` 会显示带花括号的变量名，而非实际值。在应用中通过 SDK 渲染流程时，这些变量会正常解析。如需预览依赖优惠类型的条件，请参阅[预览产品和优惠](paywall-device-compatibility-preview#preview-products-and-offers)。

## 设置透明度后颜色显示异常 \{#a-color-renders-wrong-when-opacity-is-set\}

颜色请使用 6 位十六进制代码，例如 `#FFFFFF`。若使用简写代码（如 `#FFF`）并将透明度设置为低于 100%，会生成无效颜色。

## 排版编辑未能应用到元素状态 \{#typography-edits-dont-reach-an-element-state\}

一旦某个状态（例如 **Selected**）拥有自己的排版设置，对 **Default** 状态排版所做的修改——包括应用不同的文本样式——都不会影响该状态。请直接编辑该状态的排版设置。

## 删除文字样式后元素失去样式 \{#elements-lose-their-styling-after-a-text-style-is-deleted\}

删除[文字样式](builder-styling#text-styles)时，其设置不会复制到使用该样式的元素中——这些元素会回退到默认排版。删除样式前，请先将受影响的元素改用其他样式，或手动为它们设置排版。

## 条件与变量在元素 ID 更改后失效 \{#conditions-and-variables-break-after-an-element-id-change\}

条件和文本变量通过 **Element ID** 引用元素，修改 ID 后引用不会自动更新——它们会静默失效。请在引用元素之前先设置好 Element ID。如果必须修改，需手动更新所有相关条件和变量引用。唯一的例外是进度条分段：重命名分段时，其引用会自动同步更新。

## 条件或变量解析为空值 \{#a-condition-or-variable-resolves-to-an-empty-value\}

变量选择器会列出所有页面的字段，因此条件或文本变量可能会引用用户尚未填写的输入项。在运行时，此类引用会解析为空值。请只引用流程中已在前面收集到的字段。

## Set variable 操作无法更改已选产品 \{#a-set-variable-action-doesnt-change-the-selected-product\}

已选产品不是可赋值的变量，因此 **Set variable** 无法切换选择。请改用 [**Select product**](onboarding-actions#select-product) 操作。

## 图片或视频无法上传 \{#an-image-or-video-wont-upload\}

超出流程编辑器媒体限制的文件将无法上传。请对照[图片](custom-media#image)和[视频](custom-media#video)要求检查文件：

| 元素 | 格式 | 最大文件大小 | 其他限制 |
| :--- | :--- | :--- | :--- |
| 图片 | `.JPG`、`.PNG`、`.WEBP` | 20 MB | — |
| 视频 | `.MP4`、`.WEBM` | 50 MB | 最长 30 秒；最小分辨率 640×640 像素 |

以下格式不受支持：

- **动态 GIF 和动态 WEBP**：如需添加动画效果，请改用 Video 元素。
- **SVG**：将文件导出为 PNG 或 WEBP 格式。对于图标，无需上传任何文件——Icon 元素会从内置的 [Tabler Icons](custom-media#icon) 图标库中调取。

## 底部栏未显示 \{#a-footer-doesnt-render\}

底部栏只在启用了**垂直滚动**的页面上才会显示。请在 [**Screen settings** > **Scroll**](paywall-layout-and-products#scroll) 中启用**垂直滚动**。
