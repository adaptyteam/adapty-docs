本文汇总了在[流程与付费墙编辑工具](adapty-flow-builder)中构建流程时最常遇到的问题，并逐一说明原因与解决方法。

## 流程无法预览或发布 \{#a-flow-wont-preview-or-publish\}

<ZoomImage id="flow-cant-publish-yet.webp" width="500px" alt="尚无法发布的对话框，提示屏幕上有三张卡片仍需关联产品" />

尝试预览或发布流程时，您可能会遇到以下错误：

| 消息 | 原因与解决方法 |
|---|---|
| **No product selected** | 产品卡片未关联任何产品。请选择一个产品，或删除该卡片。 |
| **This product no longer exists**、**This offer no longer exists** | 该产品或优惠已从看板中删除。请在使用处选择其他产品，或在 **Products** 面板中找到 **Missing** 条目，使用 **Replace in N places** 一次性修复屏幕上所有引用。 |
| **This product is off this screen**、**This offer is off this screen** | 文本变量、条件或操作引用了不在当前屏幕列表中的产品，例如在 **Products** 面板中将其移除之后。请在面板中重新添加该产品，或编辑相关引用。 |
| **Offer required** | `offer_price`、`offer_billing_period` 或 `offer_full_duration` 被用于没有优惠的产品。请为该产品选择一个优惠，或改用 `prod_*` 变量。 |
| **Product reference is invalid** | 产品引用格式不正确。请重新选择该产品。 |
| **Purchase action has no product to buy** | **Purchase** 操作没有关联产品，可能是留空或指向了已删除的卡片。请在元素的 **Interactions** 标签页中，将 **Product** 设置为某个产品或 `products.selectedProduct`。 |
| **Select product action has no product to select** | **Select product** 操作所指向的卡片已不存在：已被删除、移出了产品组，或位于另一屏幕。请在元素的 **Interactions** 标签页中，将操作指向当前屏幕上的某张卡片。 |
| **Flow has no screens**、**Screen "…" has no elements** | 请为空屏幕添加内容，或将其删除。仅包含远程配置内容的流程不受此限制。 |
| **Invalid interaction action** | 某个操作未填写完整：**Open URL** 缺少 URL、**Navigate to screen** 未设置目标、**Set variable** 未指定赋值、**Custom** 缺少 Action ID、**Show alert** 既无标题也无消息、**Show** 或 **Hide** 未指定元素、网页支付 **Purchase** 缺少 Web Paywall URL。请打开该元素的交互设置，补全或删除相关操作。 |
| **Missing navigation target** | **Navigate to screen** 操作指向了已删除的屏幕。请选择一个现有屏幕，或移除该操作。 |
| **Missing product target**、**Invalid product target**、**Product target on another screen**、**Ambiguous product target**、**Select Product inside a component** | **Select product** 操作所指向的卡片已被删除、不在产品组中、位于另一屏幕、与其他屏幕上的元素共享相同元素 ID，或位于跨屏幕共享的页眉/页脚中。请将操作指向同一屏幕产品组中具有唯一 ID 的卡片。 |
| **Missing selectable group** | 某元素指向的可选组已不存在。请重新关联，或重新创建该组。 |
| **Invalid visibility condition** | 条件显示规则未填写完整。请在条件构建器中补全设置。 |
| **Circular state conditions** | 多个元素的 **Disabled** 条件相互依赖，形成循环。请在其中一个元素的 **States** 部分，修改或删除造成循环的 **Disabled** 条件。 |
| **Missing Default Locale Content** | **Open URL** 操作在其他语言区域设置了 URL，但默认语言区域没有。请在[**Localizations** 面板](add-paywall-locale-in-adapty-paywall-builder)中添加默认 URL。 |
| **Missing product reference** | 旧版流程使用了未在当前屏幕注册的产品。请打开该屏幕，在 **Products** 面板中添加该产品。 |

在构建过程中，请定期[在 Adapty 应用中预览流程](paywall-device-compatibility-preview)。无法发布的流程在那里也无法加载，错误信息会指出具体问题所在。

:::tip
若要检查流程是否已准备好上线，请运行 [flow-audit skill](flow-audit-skill)。它能检测发布错误之外的问题：失效按钮、应用商店合规性、未完成的文案以及翻译覆盖情况。报告会逐一列出问题元素及其所在屏幕。
:::

## 发布失败并显示"出现错误"且无详细信息 \{#publishing-fails-with-something-went-wrong-and-no-details\}

<ZoomImage id="flow-publish-error.webp" width="300px" alt="发布失败后显示“出现错误”的通知，包含支持邮箱地址和可复制的请求 ID" float="right" />

发布请求在 Adapty 端失败，与您的流程无关。您的线上版本未受影响。请等待几分钟后重新发布。如果仍然失败，请从通知中复制 **Request ID**，并发送至 [support@adapty.io](mailto:support@adapty.io)，以便团队定位失败的请求。

## 优惠在购买时未生效 \{#an-offer-doesnt-apply-at-purchase\}

编辑工具只会检查该优惠在 Adapty 中是否仍然存在。折扣是否实际生效，由商店在购买时决定：新用户优惠取决于用户的资格条件，App Store 促销活动则需要有效的 In-App Purchase Key。这两种情况均在[产品与价格差异](store-sync#product-and-price-discrepancies)中有详细说明。

## 预览中优惠价格为空 \{#an-offer-price-is-empty-in-the-preview\}

编辑工具预览无法连接应用商店，因此 `offer_price`、`offer_billing_period` 和 `offer_full_duration` 会显示带花括号的变量名，而非实际值。在应用中通过 SDK 渲染流程时，这些变量会正常解析。如需预览依赖优惠类型的条件，请参阅[预览产品和优惠](paywall-device-compatibility-preview#preview-products-and-offers)。

## 输入简写十六进制颜色后发布失败 \{#publishing-fails-after-entering-a-shorthand-hex-color\}

请始终使用完整的六位十六进制颜色值，例如 `#FFFFFF`。颜色输入框接受较短的值，但不会自动补全，因此像 `#FFF` 这样的简写会以格式错误的形式传入 SDK 配置，导致发布被拒。透明度与此无关——即使在 100% 不透明的情况下，同样的简写值也会失败。四位值是其中最麻烦的例外：它能成功发布，但渲染出来的颜色并非你所选的颜色。

## 排版编辑未能应用到元素状态 \{#typography-edits-dont-reach-an-element-state\}

一旦某个状态（例如 **Selected**）拥有自己的排版设置，对 **Default** 状态排版所做的修改——包括应用不同的文本样式——都不会影响该状态。请直接编辑该状态的排版设置。

## 元素缺少位置、大小和间距控件 \{#position-size-and-spacing-controls-are-missing-for-an-element\}

元素及其容器均使用 **Free** 方向。此时只有一种可用的位置和大小设置：**Absolute**，且宽高均为固定值。Adapty 会隐藏其他所有控件——包括 **Position** 切换开关、**Spacing** 区域以及 **Fill** 和 **Hug** 选项。若要恢复这些控件，请将元素的 [**Direction**](manage-paywall-ui-elements#direction) 改为 **Vertical** 或 **Horizontal**。

## 更改测验选项的 Element ID 后，条件停止匹配 \{#a-condition-stops-matching-after-you-change-the-element-id-of-a-quiz-option\}

将用户所选选项与某个值进行比较的条件（例如 `quiz.selectedOptionId` `=` `option_1`）会将选项的 **Element ID** 以纯文本形式写入条件中。当你更改 **Element ID** 时，编辑工具不会自动更新该文本，导致条件停止匹配。请在将某个选项用于条件之前，先设置好其 **Element ID**。如果之后需要更改，请同步更新所有引用了旧 ID 的条件。

编辑工具会自动更新其他相关引用：输入字段的变量、组 ID、元素状态以及进度条分段。

## 条件或变量解析为空值 \{#a-condition-or-variable-resolves-to-an-empty-value\}

变量选择器会列出每个屏幕的字段，因此条件或文本变量可能引用用户尚未填写的输入项。在运行时，此类引用会解析为空值。请仅引用流程中更早收集的字段。

[数字选择器](builder-number-picker)的变量永远不会为空：在用户拨动滚轮之前，它等于默认数值。如果某个条件在用户到达该选择器之前就对变量进行求值，可能会匹配到用户实际上从未选择过的答案。

## 用户看到的是自定义标签的初始值，而不是应用中的实际值 \{#users-see-a-custom-tags-initial-value-instead-of-your-apps-value\}

在以下情况下，用户会看到[自定义标签](flow-custom-tags)的初始值：

- **您的应用未传入任何值**：打开流程的代码未为该标签传入值，或者用户尚未将应用更新到传入值的版本。
- **名称不匹配**：应用代码中的名称与编辑工具中标签的名称不一致。名称区分大小写，且包含所属分组。例如，若 `user` 分组下有一个 `streak` 标签，则该标签的完整名称为 `user.streak`。
- **同一文本元素中的另一个标签没有值**：如果一个文本元素中的某个自定义标签没有值，该元素中的所有标签都会显示其初始值。请为文本元素中的每个自定义标签都传入值。

Adapty 移动应用不传递自定义标签的值，因此其预览仅显示初始值。要查看您的应用传递的值，请在应用的构建版本中打开该流程。

## 用户在自定义标签处看不到任何内容 \{#users-see-nothing-in-place-of-a-custom-tag\}

在以下情况下，用户在[自定义标签](flow-custom-tags)处看不到任何内容：

- **您的应用传入了空字符串**：Adapty 将空字符串视为一个值，因此初始值不会作为备用内容显示。如需显示初始值，请不要为该标签传入任何值。
- **该标签没有初始值**：如果您希望在应用未传入任何值时显示备用内容，请为该标签设置一个初始值。

## Set variable 操作无法更改已选产品 \{#a-set-variable-action-doesnt-change-the-selected-product\}

已选产品不是可赋值的变量，因此 **Set variable** 无法切换选择。请改用 [**Select product**](onboarding-actions#select-product) 操作。

## 流程未执行为购买结果设置的操作 \{#the-flow-doesnt-run-the-actions-set-for-a-purchase-result\}

流程会在商店返回结果时执行购买或购买恢复的[结果操作](respond-to-purchase-outcomes#add-actions-for-a-result)。此时，用户必须停留在发起购买的屏幕上。在以下情况下，流程会跳过这些操作：

- **您的应用关闭了流程**：当购买或恢复完成时，您的应用在回调中关闭了流程。若要让流程继续运行，请[在这些回调中保持流程开启](respond-to-purchase-outcomes#before-you-start)。
- **导航动作在结果返回前触发**：在同一触发器中，**Purchase** 或 **Restore purchases** 之后紧跟着 **Navigate to Screen**、**Navigate Next**、**Navigate back** 或 **Close Flow** 动作。该动作会在点击时立即执行，因此在商店返回结果之前，用户就已离开了该页面。请将此动作移入结果处理分支中，例如 **When succeeded**。
- **用户离开了页面**：在商店返回结果之前，用户通过返回按钮等方式导航到了其他页面。
- **购买属于 Web Payment 类型**：流程无法接收 **Web Payment** 购买的结果，因此设置为 **Web Payment** 的 **Purchase** 动作没有结果处理分支。当您将动作切换为 **Web Payment** 时，Flow & Paywall Builder 会自动移除其结果动作。

您无法在 Adapty 移动应用的预览中进行真实购买。如需测试结果操作，请在您应用的构建版本中[进行沙盒购买](test-purchases-in-sandbox)。

## 购买按钮在 Android 上点击无响应 \{#a-purchase-button-does-nothing-on-android\}

在 Android 上，如果用户在 Google Play 返回产品信息之前点击**购买**按钮，按钮不会有任何响应。产品加载完成后，按钮才能正常使用。在 iOS 上，同样的提前点击操作会导致购买失败，并触发**购买失败时**的后续动作。

以下情况下，该按钮始终无法正常使用：

- **Google Play 未返回该产品**：请确认产品在 Google Play Console 中处于激活状态，且 Adapty 中该产品使用的 Google Play 产品 ID 一致。如需查看 Adapty 中的产品，请参阅[创建产品](create-product)。
- **产品加载失败**：在原生 Android 应用中，SDK 默认不会重新加载产品。如需重试，请在 [`onLoadingProductsFailure`](android-handling-events#product-loading-errors) 中返回 `true`。
- **你的应用向流程传入产品时未包含该产品**：当你的应用向流程传入 [`products`](android-present-paywalls) 时，SDK 不会从 Google Play 加载任何产品。请将流程中的每个产品都添加到该列表中。
- **之前的购买未完成**：SDK 会忽略新购买，直到上一次购买完成。在 Observer 模式下，每次购买后请调用 `onFinishPurchase()`。在 [`onAwaitingPurchaseParams`](android-handling-events#upgrade-subscription) 中，务必调用 `onPurchaseParamsReceived`。

在 iOS 上，如果 App Store 未返回该产品，每次点击都会导致购买失败，流程将执行 **When failed** 操作。如需排查原因，请参阅[产品未显示](troubleshoot-app-store-integration#products-dont-appear)。

## 图片或视频无法上传 \{#an-image-or-video-wont-upload\}

超出 Flow & Paywall Builder 媒体限制的文件无法上传。请对照[图片](custom-media#image)和[视频](custom-media#video)要求检查文件：

| 元素 | 格式 | 最大文件大小 | 其他限制 |
| :--- | :--- | :--- | :--- |
| 图片 | `.JPG`、`.PNG`、`.WEBP` | 20 MB | — |
| 视频 | `.MP4`、`.WEBM` | 50 MB | 最长 30 秒；最小分辨率 640×640 像素 |

以下格式不受支持：

- **动态 GIF 和动态 WEBP**：如需添加动画效果，请改用 Video 元素。
- **SVG**：将文件导出为 PNG 或 WEBP 格式。对于图标，无需上传任何文件——Icon 元素会从内置的 [Tabler Icons](custom-media#icon) 图标库中调取。

## 底部栏未显示 \{#a-footer-doesnt-render\}

底部栏只在启用了**垂直滚动**的页面上才会显示。请在 [**Screen settings** > **Scroll**](paywall-layout-and-products#scroll) 中启用**垂直滚动**。
