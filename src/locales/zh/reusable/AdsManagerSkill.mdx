[ads-manager skill](https://github.com/adaptyteam/adapty-sdk-integration-skill) 可以让你的 AI 编程工具通过 `adapty asa` 命令操作 Apple Ads。它了解命令的组合顺序、写入前需要读取哪些内容，以及哪些调用会花费真实资金。

**支持的工具**：Claude Code、GitHub Copilot CLI、OpenAI Codex、Gemini CLI。

该 skill 基于 Adapty CLI 运行，因此请先安装并完成 CLI 的身份验证——参见[快速入门指南](developer-cli-quickstart)。`adapty asa` 命令在 **Adapty CLI 0.4.0 及以上版本**中提供；旧版本中该命令不存在。可通过 `adapty asa whoami` 进行检查，它还会告诉你是否已关联 Apple Ads 账号，以及公司是否拥有有效的 Ads Manager 订阅。

Claude Cowork 在沙盒中运行 CLI，该沙盒会屏蔽白名单以外的所有域名。在此处安装 skill 之前，请先放行 Adapty 相关域名——参见 [Run the CLI in Cowork](developer-cli-quickstart#run-the-cli-in-cowork)。

安装时，请选择适合你工具的方式。完整列表见 [skill README](https://github.com/adaptyteam/adapty-sdk-integration-skill)。

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

此插件同时包含 SDK 集成 skill，两者会一并安装。

**GitHub Copilot CLI**

```bash
git clone https://github.com/adaptyteam/adapty-sdk-integration-skill.git
cp -r adapty-sdk-integration-skill/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```bash
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex 或其他工具** — 使用 [skills CLI](https://skills.sh)（注意：通过此方式安装的 skill 不会自动更新）：

```bash
npx skills add adaptyteam/adapty-sdk-integration-skill --all
```

`--all` 会将两个 skill 都安装到它检测到的每个 agent 中。如果只需安装本 skill，请使用 `--skill ads-manager`。

你也可以克隆该仓库，然后将 `skills/` 下的目录复制到你工具的 skills 目录中——如果只需要这一个，复制 `skills/ads-manager/` 即可。

安装完成后，在你的项目中运行该 skill：

```bash
/ads-manager
```

读取数据指标和模拟运行不产生任何费用。其他所有命令都会在几秒内触达 Apple，花费真实资金，且无法撤销——每次执行前 skill 都会询问确认，你也应当如此。
