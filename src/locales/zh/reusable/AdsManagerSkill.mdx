[ads-manager skill](https://github.com/adaptyteam/adapty-sdk-integration-skill) 可以教你的 AI 编码工具通过 `adapty asa` 命令操作 Apple Ads。它了解命令的组合顺序、在执行写入操作前应读取哪些内容，以及哪些调用会产生费用。

**支持的工具**：Claude Code、GitHub Copilot CLI、OpenAI Codex、Gemini CLI。

该 skill 驱动 Adapty CLI，因此请先安装并完成 CLI 的身份验证——参阅[快速入门指南](developer-cli-quickstart)。`adapty asa` 命令在 **Adapty CLI 0.4.0 及更高版本**中提供；旧版本中该命令根本不存在。运行 `adapty asa whoami` 进行检查，该命令同时会告知你是否已连接 Apple Ads 账户，以及公司是否拥有有效的 Ads Manager 订阅。

在企业 Cowork 工作区中，管理员必须将 `adapty.io` 和 `*.adapty.io` 都添加到域名白名单。两者须同时添加：在大多数白名单实现中，通配符不覆盖根域名，而根域名正是该 skill 读取文档的地址。在两者都被允许之前，该 skill 无法访问 Adapty。

安装时，请根据你使用的工具选择对应的方式。完整列表请参阅 [skill README](https://github.com/adaptyteam/adapty-sdk-integration-skill)。

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

此插件同时包含 SDK 集成 skill，两者会一并安装。

**GitHub Copilot CLI**

```bash
git clone https://github.com/adaptyteam/adapty-sdk-integration-skill.git
cp -r adapty-sdk-integration-skill/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```bash
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex 或其他工具** —— 使用 [skills CLI](https://skills.sh)（注意以此方式安装的 skill 不会自动更新）：

```bash
npx skills add adaptyteam/adapty-sdk-integration-skill --all
```

`--all` 会将两个 skill 安装到检测到的所有 agent 中。如果只需安装本 skill，请使用 `--skill ads-manager`。

你也可以克隆仓库，将 `skills/` 下的目录复制到你的工具的 skills 目录中——如果只需要这一个 skill，复制 `skills/ads-manager/` 即可。

安装完成后，在你的项目中运行该 skill：

```bash
/ads-manager
```

读取数据指标和演练运行不产生任何费用。其他所有命令都会在数秒内触达 Apple，花费真实资金，且操作无法撤销——该 skill 在每次执行前都会向你确认，你自己也应该做到同样的谨慎。
