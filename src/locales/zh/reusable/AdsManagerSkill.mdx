[Apple Ads 插件](https://github.com/adaptyteam/apple-ads-cli)可以让你的 AI 编程工具通过 `adapty asa` 命令操作 Apple Ads。它包含三个技能：

- **`apple-ads`**：操作员。它读取效果数据、调整出价和预算、添加关键词和否定词、挖掘搜索词，并启动和暂停广告活动——在任何花钱的操作前都会请求确认。
- **`apple-ads-audit`**：只读审计员。它检查账户健康状况、投放状态、账户结构、流量归属和重复精确匹配关键词，不会进行任何写入操作。
- **`apple-ads-strategy`**：规划师，无需账户、CLI 或订阅即可使用。它根据你的应用描述生成账户结构、关键词分类体系、初始预算和否定关键词列表。

**支持的工具**：Claude Code、Claude 应用（前身为 Claude Cowork）、GitHub Copilot CLI、OpenAI Codex、Gemini CLI 以及任何支持技能的工具。

操作员和审计员依赖 Adapty CLI 运行，请先安装并完成身份验证——参见[快速入门指南](developer-cli-quickstart)。`adapty asa` 命令在 **Adapty CLI 0.4.0 及更高版本**中提供；旧版本中这些命令不存在。可通过 `adapty asa whoami` 检查，该命令还会告诉你是否已连接 Apple Ads 账户以及公司是否有有效的 Ads Manager 订阅。策略技能无需上述任何配置即可使用。

Claude 应用在沙盒环境中运行 CLI，该沙盒会屏蔽白名单以外的所有域名。在该环境中安装插件前，请先允许 Adapty 相关域名——参见[在 Claude 应用中设置 Adapty CLI](developer-cli-cowork)。Claude 应用中的每次对话都在全新的机器上运行，因此 CLI 及其登录状态不会在对话间保留——插件的 `adapty-cli-setup` 技能会在每次对话开始时重新安装并完成身份验证。

安装时，请根据你使用的工具选择对应方式。完整列表请参见[插件 README](https://github.com/adaptyteam/apple-ads-cli)。

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/apple-ads-cli
claude plugin install apple-ads@adapty
```

**OpenAI Codex**

```bash
codex plugin marketplace add adaptyteam/apple-ads-cli
codex plugin add apple-ads@adapty
```

两种插件方式都会附带 `/asa-*` 命令和技能——这些是针对常见任务的现成提示词，例如用于每周回顾的 `/asa-review` 和用于将搜索词转化为关键词与否定词的 `/asa-harvest`。Claude Code 将它们作为斜杠命令提供；Codex 则将其作为可按名称调用的技能加载。

**其他工具** — 使用 [skills CLI](https://skills.sh)（注意：以此方式安装的技能不会自动更新）：

```bash
npx skills add adaptyteam/apple-ads-cli --all
```

`--all` 会将全部三个技能安装到它检测到的每个智能体中。若只安装某一个技能，请使用 `--skill`，例如 `--skill apple-ads-strategy`。

安装完成后，在你的项目中运行技能——可直接调用，也可通过斜杠命令：

```bash
/apple-ads
```

读取数据指标和演练运行不会产生任何费用。其他所有命令都会在几秒内到达 Apple，花费真实金钱，且无法撤销——技能在每次操作前都会请求确认，你也应如此。
