[Apple Ads 插件](https://github.com/adaptyteam/apple-ads-cli) 可以让你的 AI 编程工具通过 `adapty asa` 命令操作 Apple Ads。它包含三个技能：

- **`apple-ads`**：操作员。负责读取效果数据、调整出价和预算、添加关键词和否定关键词、收集搜索词，以及启动和暂停广告系列——每次涉及花费的操作都会在执行前要求确认。
- **`apple-ads-audit`**：只读审计工具。检查账户健康状况、投放状态、账户结构、流量归属以及重复的精确匹配关键词，不执行任何写入操作。
- **`apple-ads-strategy`**：规划工具，无需账户、CLI 或订阅即可使用。根据你的应用描述，生成账户结构、关键词分类体系、初始预算以及否定关键词列表。

**支持的工具**：Claude Code、Claude Cowork、GitHub Copilot CLI、OpenAI Codex、Gemini CLI，以及其他支持技能的工具。

操作员和审计工具依赖 Adapty CLI 驱动，因此请先安装并完成 CLI 身份验证——参见[快速入门指南](developer-cli-quickstart)。`adapty asa` 命令从 **Adapty CLI 0.4.0** 起提供；旧版本中不存在这些命令。可通过 `adapty asa whoami` 检查版本，该命令同时会告知你是否已连接 Apple Ads 账户，以及公司是否有有效的 Ads Manager 订阅。策略技能无需以上任何条件即可使用。

Claude Cowork 在沙盒中运行 CLI，该沙盒会屏蔽白名单以外的所有域名。在该环境中安装插件前，请先放行 Adapty 相关域名——参见[在 Claude Cowork 中配置 Adapty CLI](developer-cli-cowork)。Cowork 任务每次都在全新机器上启动，因此 CLI 及登录状态不会在会话之间保留——插件的 `adapty-cli-setup` 技能会在每次会话开始时重新安装并完成身份验证。

安装时，请根据你使用的工具选择对应方式。完整列表请查看[插件 README](https://github.com/adaptyteam/apple-ads-cli)。

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/apple-ads-cli
claude plugin install apple-ads@adapty
```

**OpenAI Codex**

```bash
codex plugin marketplace add adaptyteam/apple-ads-cli
codex plugin add apple-ads@adapty
```

两种插件安装方式都会同时带来 `/asa-*` 命令和技能——这些是针对常见任务的现成提示词，例如用于每周复盘的 `/asa-review`，以及将搜索词转化为关键词和否定关键词的 `/asa-harvest`。Claude Code 以斜杠命令的形式呈现它们；Codex 则将其作为技能加载，可通过名称调用。

**其他工具** — 使用 [skills CLI](https://skills.sh)（注意：通过此方式安装的技能不会自动更新）：

```bash
npx skills add adaptyteam/apple-ads-cli --all
```

`--all` 会将全部三个技能安装到它检测到的每个 Agent 中。如需单独安装某个技能，请使用 `--skill`，例如 `--skill apple-ads-strategy`。

安装完成后，在你的项目中运行技能——可直接运行，也可通过斜杠命令触发：

```bash
/apple-ads
```

读取数据指标和演练运行不会产生任何费用。其他所有命令都会在几秒内实际触达 Apple、花费真实资金，且无法撤销——技能在每次执行前都会请求确认，你也应养成同样的习惯。
