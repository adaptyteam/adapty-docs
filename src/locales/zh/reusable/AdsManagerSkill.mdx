[Apple Ads 插件](https://github.com/adaptyteam/apple-ads-cli)能让你的 AI 编程工具通过 `adapty asa` 命令操作 Apple Ads。它提供三项技能：

- **`apple-ads`**：操作员。可读取效果数据、调整出价和预算、添加关键词及否定关键词、挖掘搜索词，以及启动和暂停广告系列——在任何花钱的操作前都会请求确认。
- **`apple-ads-audit`**：只读审计员。检查账户健康状况、投放状态、账户结构、流量归属及重复精确匹配关键词，不执行任何写入操作。
- **`apple-ads-strategy`**：无需账户、CLI 或订阅的规划工具。只需输入应用描述，即可生成账户结构、关键词分类体系、初始预算和否定关键词列表。

**支持的工具**：Claude Code、Claude Cowork、GitHub Copilot CLI、OpenAI Codex、Gemini CLI，以及其他所有支持技能的工具。

操作员和审计员依赖 Adapty CLI 运行，请先安装并完成 CLI 认证——参见[快速入门指南](developer-cli-quickstart)。`adapty asa` 命令在 **Adapty CLI 0.4.0 及以上版本**中提供；旧版本中这些命令不存在。可通过 `adapty asa whoami` 检查版本，该命令同时会告知是否已连接 Apple Ads 账户，以及公司是否拥有有效的 Ads Manager 订阅。策略技能无需以上任何条件即可使用。

Claude Cowork 在沙盒中运行 CLI，该沙盒会屏蔽白名单以外的所有域名。在该环境中安装插件前，请先放行 Adapty 域名——参见[在 Cowork 中运行 CLI](developer-cli-quickstart#run-the-cli-in-cowork)。Cowork 任务每次都在全新机器上启动，因此 CLI 及其登录状态不会在会话间保留——插件的 `adapty-cli-setup` 技能会在每次会话开始时重新安装并认证 CLI。

根据你使用的工具选择对应的安装方式。完整列表请参见[插件 README](https://github.com/adaptyteam/apple-ads-cli)。

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/apple-ads-cli
claude plugin install apple-ads@adapty
```

除技能外，Claude Code 插件还会安装 `/asa-*` 斜杠命令——这些是常用任务的预设提示词，例如用于每周复盘的 `/asa-review`，以及将搜索词转化为关键词和否定关键词的 `/asa-harvest`。

**其他工具** — 使用 [skills CLI](https://skills.sh)（注意通过此方式安装的技能不会自动更新）：

```bash
npx skills add adaptyteam/apple-ads-cli --all
```

`--all` 会将全部三项技能安装到它检测到的每个 Agent 中。如需单独安装某项技能，使用 `--skill`，例如 `--skill apple-ads-strategy`。

安装完成后，在项目中运行技能——可直接运行，也可通过斜杠命令：

```bash
/apple-ads
```

读取数据指标和演习运行不产生任何费用。其他所有命令都会在数秒内触达 Apple，花费真实资金，且无法撤销——技能在每次操作前都会询问确认，你也应该如此。
