[ads-manager skill](https://github.com/adaptyteam/adapty-sdk-integration-skill) 可以让你的 AI 编程工具通过 `adapty asa` 命令操作 Apple Ads。它了解命令的组合顺序、执行写入操作前需要读取的内容，以及哪些调用会产生费用。

**支持的工具**：Claude Code、GitHub Copilot CLI、OpenAI Codex、Gemini CLI。

该 skill 依赖 Adapty CLI 运行，请先安装并完成 CLI 的身份验证——参阅[快速入门指南](developer-cli-quickstart)。

在企业 Cowork 工作区中，管理员必须将 `*.adapty.io` 添加到域名白名单，否则 skill 将无法连接到 Adapty。

安装时，请根据你使用的工具选择对应的命令。完整列表请参见 [skill README](https://github.com/adaptyteam/adapty-sdk-integration-skill)。

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

此插件同时包含 SDK 集成 skill，两者会一并安装。

**GitHub Copilot CLI**

```bash
gh skill install adaptyteam/adapty-sdk-integration-skill
```

**Gemini CLI**

```bash
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex 或其他工具** — 使用 [skills CLI](https://skills.sh)（注意：通过此方式安装的 skill 不会自动更新）：

```bash
npx skills add adaptyteam/adapty-sdk-integration-skill
```

或者，克隆该仓库并将 `skills/ads-manager/` 复制到你的工具的 skills 目录中。

安装完成后，在你的项目中运行该 skill：

```bash
/ads-manager
```

读取数据指标和试运行不产生任何费用。其他所有命令都会在数秒内直接调用 Apple 接口，消耗真实资金且无法撤销——skill 在每次执行前都会向你确认，你自己也应当谨慎操作。
