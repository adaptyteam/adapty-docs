
| 事件名称                               | 描述                                                                                                                                                                                                                                                                                                                                                         |
|:-----------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| subscription_started               | 当用户激活不含试用期的付费订阅时触发，即立即扣款。                                                                                                                                                                                                                                                                                      |
| subscription_active                | 在 `subscription_started` 事件触发后，确认订阅仍处于有效状态。你需要设置从订阅开始到本次检查之间的天数。若订阅仍有效（包括用户已进入宽限期的情况），则会收到该事件。若订阅在检查时已结束，或用户已关闭自动续订，则不会收到任何通知，Adapty 也不会再次检查。此事件仅跟随未含试用期的订阅触发。试用转化会发送 `trial_converted`，不会启动本次检查。 |
| subscription_renewed               | 当订阅续期并向用户扣款时触发。无论是试用订阅还是非试用订阅，均从第二次计费起触发。                                                                                                                                                                                                                                                           |
| subscription_renewal_cancelled     | 用户已关闭订阅自动续订。用户在已付费订阅期结束前仍可享受高级功能。                                                                                                                                                                                                                                                                          |
| subscription_renewal_reactivated   | 当用户重新激活订阅自动续订时触发。                                                                                                                                                                                                                                                                                                           |
| subscription_expired               | 当订阅在取消后完全结束时触发。例如，用户于 12 月 12 日取消订阅，但订阅至 12 月 31 日仍有效，则该事件在 12 月 31 日订阅到期时记录。                                                                                                                                                                                                              |
| subscription_paused                | 当用户激活[订阅暂停](https://developer.android.com/google/play/billing/lifecycle/subscriptions#pause)时触发（仅限 Android）。                                                                                                                                                                                                                                     |
| subscription_deferred              | 当订阅购买被[延期](https://adapty.io/glossary/subscription-purchase-deferral/)时触发，允许用户在保留高级功能访问权限的同时延迟付款。此功能通过 Google Play Developer API 提供，可用于免费试用或为面临财务困难的用户提供便利。 |
| non_subscription_purchase          | 任何非订阅购买，例如永久授权或消耗型商品（如游戏内货币）。                                                                                                                                                                                                                                                                                   |
| trial_started                      | 当用户激活试用订阅时触发。                                                                                                                                                                                                                                                                                                                   |
| trial_active                       | 在 `trial_started` 事件触发后，确认试用仍处于有效状态。你需要设置从试用开始到本次检查之间的天数。若试用仍在进行中，则会收到该事件。若试用在检查时已结束或已转化，或用户已关闭自动续订，则不会收到任何通知，Adapty 也不会再次检查。 |
| trial_converted                    | 当试用结束并向用户扣款（首次购买）时触发。例如，用户的试用期至 1 月 14 日，但在 1 月 7 日被扣款，则该事件在 1 月 7 日记录。                                                                                                                                                                                                                    |
| trial_renewal_cancelled            | 用户在试用期内关闭了订阅自动续订。用户在试用结束前仍可享受高级功能，但不会被扣款或开始订阅。                                                                                                                                                                                                                                                 |
| trial_renewal_reactivated          | 当用户在试用期内重新激活订阅自动续订时触发。                                                                                                                                                                                                                                                                                                 |
| trial_expired                      | 当试用结束且未转化为订阅时触发。                                                                                                                                                                                                                                                                                                             |
| entered_grace_period               | 当付款尝试失败且用户进入宽限期（如已启用）时触发。用户在此期间仍可享受高级功能。                                                                                                                                                                                                                                                            |
| billing_issue_detected             | 当扣款尝试出现账单问题时触发（例如，银行卡余额不足）。                                                                                                                                                                                                                                                                                      |
| subscription_refunded              | 当订阅被退款时触发（例如，由 Apple 客服处理）。                                                                                                                                                                                                                                                                                              |
| non_subscription_purchase_refunded | 当非订阅购买被退款时触发。                                                                                                                                                                                                                                                                                                                   |
| access_level_updated               | 当用户的访问等级更新时触发。                                                                                                                                                                                                                                                                                                                 |
