1. 要查找团队密钥的 **Issuer ID** 和 **Key ID**，请在 App Store Connect 中前往 [**Users and Access** > **Integrations** > **App Store Connect API**](https://appstoreconnect.apple.com/access/integrations/api)，然后打开 **Team Keys** 标签页。如果其他人已生成密钥并将 Issuer ID、Key ID 和文件发送给您，请跳过此步骤。

   <ZoomImage id="asc-team-keys-ids.webp" width="700px" alt="Issuer ID and the Key ID of a team key on the Team Keys tab in App Store Connect" />

2. 在 Adapty 中，前往 [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk)。在 **App Store Connect API key** 部分，点击 **Connect API Key**。

   <ZoomImage id="app-settings-connect-api-key.webp" width="700px" alt="App Store Connect API key section in Adapty, with the Connect API Key button" />

3. 填写以下字段：
   - **Issuer ID**：从 App Store Connect 的 **Team Keys** 标签页复制。
   - **Key ID**：从 **Team Keys** 标签页的 **Active** 列表中复制，位于您下载的密钥旁边。
   - **Private key (.p8 file)**：上传您为团队密钥下载的文件。

   <ZoomImage id="app-settings-api-key-dialog.webp" width="700px" alt="Issuer ID, Key ID, and Private key (.p8 file) fields in the window for the App Store Connect API key" />

4. 您可以稍后替换已连接的密钥，但无法将其移除。请确保该密钥来自拥有此应用的 App Store Connect 团队，然后点击 **Connect**。之后，您可以直接从 App Store Connect 的产品中选择每个 **App Store Product ID**，而无需手动输入。

   Adapty 在您连接密钥时不会向 Apple 验证该密钥。错误的密钥不会给出任何关于密钥的提示信息：产品将不显示 App Store 状态，且 **App Store Product ID** 下拉列表保持为空。如需修复错误密钥，请[替换它](app-store-connect-api-key#replace-the-key)。
