回调会传递两种事件。通过过滤 `name` 字段，只显示 `flow_user_input` 事件。响应的 JSON 数据结构如下：

```json
{
  "name": "flow_user_input",
  "instanceId": "scr_registration",
  "isBackendEvent": false,
  "isCustomerEvent": true,
  "element_id": "email",
  "element_type": "email_input",
  "value": "jane@example.com"
}
```

| 参数 | 描述 |
|:------------------|:------------|
| `name`            | 输入事件为 `flow_user_input`，页面浏览事件为 `flow_screen_showed`。 |
| `instanceId`      | 该输入框所在页面的 ID。元素 ID 在同一页面内唯一，并非在整个流程中唯一。如果你的流程中多个页面都有输入框，过滤事件时请将 `instanceId` 与 `element_id` 配合使用。 |
| `element_id`      | [输入框](builder-inputs-and-forms)的 **Element ID**，或[可选择组](flow-selectable-elements)的 **Group ID**。 |
| `element_type`    | 触发事件的元素类型，决定了下列哪个参数携带输入值。 |
| `value`           | **仅适用于文本框、选择器和开关。** 输入值：文本框为字符串，日期和时间选择器为整数，数字选择器可包含小数，开关为布尔值。 |
| `item_ids`        | **仅适用于单选和多选可选择组。** 已选选项的 **Element ID**，按选项在编辑工具中出现的顺序排列。单选组为一个条目，多选组可以有任意数量。 |
| `item_titles`     | **仅适用于单选和多选可选择组。** `item_ids` 中各选项对应的标题，顺序相同。该字段不会为空：没有标题的选项会以其 ID 代替。 |
| `isCustomerEvent` | 工具标志，该事件始终为 `true`。用于标记 SDK 传递到你的回调的事件。如果一个处理程序需要将所有流程事件转发到你的分析系统，可以通过该标志而非 `name` 来判断。 |
| `isBackendEvent`  | 工具标志，该事件始终为 `false`。用于标记 Adapty 同时记录到自身分析的事件。`false` 表明用户输入的内容只到达你的应用，不会发送到其他地方——Adapty 不会接收或存储这些数据。 |

各元素上报的内容：

| 编辑工具中的元素 | `element_type` | 存储值的参数 | 内容说明 |
|:---------------|:---------------|:----------------------------|:--------------|
| **Text**、**Number**、**Phone number** 输入框 | `text_input`、`number_input`、`phone_input` | `value` | 用户输入的原始字符串。数字以字符串形式传入，而非数值类型。 |
| **E-mail** 输入框 | `email_input` | `value` | 用户输入的原始字符串，即使未通过编辑工具的格式校验也会原样传入。请在使用前在你的端进行校验。 |
| **Password** 输入框 | 无 | 无 | 不发送任何事件。 |
| **Date** 输入框 | `date_picker` | `value` | 所选日期当地时间午夜时刻的 Unix 毫秒时间戳，为整数。 |
| **Time** 输入框 | `time_picker` | `value` | Unix 毫秒时间戳，为整数，向下取整到分钟。 |
| **Date & Time** 输入框 | `date_picker` 和 `time_picker` | `value` | 由两个元素组成：日期选择器和时间选择器，各自单独发送事件。 |
| 在 **Type** 下拉菜单中切换为 **Date & Time** 的输入框 | `date_time_picker` | `value` | Unix 毫秒时间戳，为整数，向下取整到分钟。 |
| **Number picker** | `wheel_range_picker` | `value` | 用户拨动选择的数值，若从未拨动则为默认值。可包含小数，例如 `70.5`。与 **Number** 输入框的值不同，该值以数值类型传入，而非字符串。 |
| **Single choice** 组 | `single_choice` | `item_ids`、`item_titles` | 两个数组。`item_ids`：包含已选选项 Element ID 的数组。`item_titles`：包含该选项标题的数组。 |
| **Multi-choice** 组 | `multi_choice` | `item_ids`、`item_titles` | 两个数组。`item_ids`：所有已选选项的 Element ID，按选项在编辑工具中出现的顺序排列。`item_titles`：对应的标题，顺序相同。未选择任何内容时两个数组均为空。 |
| **Toggle** 组 | `toggle` | `value` | 布尔值。 |

如需根据答案进行分支判断，请比较 `item_ids`，而非 `item_titles`。标题是派生值：优先使用选项的 **Element Title**（如已设置），其次是默认语言中的文本，最后才是 Element ID。使用其他语言浏览流程的用户看到的文本可能不同。
