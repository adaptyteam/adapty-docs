要在用户点击的按钮中显示加载动画，然后显示对勾标记，需要将两个按钮都作为自定义元素添加。在带有[自定义动作](onboarding-actions#what-custom-actions-cant-do)的编辑工具按钮中，用户既看不到加载动画也看不到对勾标记。自定义动作是单向的：您的应用代码无法将消耗结果返回给流程。按钮的文本和样式来自您的应用代码。如需更改文本或样式，请[发布应用更新](flow-custom-elements#what-changes-require-an-app-release)。

1. 为能量补充[添加一个自定义元素](flow-custom-elements#add-and-configure)，并填写其 **Type** 和 **ID**：
   - **Type**：`spend_button`。
   - **ID**：`energy_refill`。
2. 为无限能量添加第二个自定义元素，Type 相同，ID 填写 `unlimited_energy`。

   [步骤 2](#connect-the-buttons-to-your-backend) 中的代码通过 Type 将同一个按钮视图匹配到两个自定义元素，并通过各自的 ID 读取每个按钮的选项。

   <ZoomImage id="vc-top-up-spend-button.webp" width="700px" alt="Custom element settings in the Flow & Paywall Builder, with spend_button in the Type field and unlimited_energy in the ID field" />

3. 将每个自定义元素的 **Fixed** 高度从 200 调整为按钮所需的实际高度。
4. 在每个自定义元素内部添加一个文本元素，并为其选项输入说明文字：
   - 能量补充："Update the game to refill energy."
   - 无限能量："Update the game to get unlimited energy."

   在不支持按钮视图的应用版本中，用户将看到此文本作为[备用内容](flow-custom-elements#set-fallback-content)显示，没有可点击的按钮。
