要显示钻石余额，请使用[自定义元素](flow-custom-elements)：用户可以在其中看到来自您应用代码的原生视图的元素。当您的应用代码在流程打开时更改余额（例如消费后），用户会看到最新余额。

1. 在屏幕上[添加自定义元素](flow-custom-elements#add-and-configure)，并输入其 **Type** 和 **ID**：
   - **Type**：`currency_balance`。
   - **ID**：`diamonds`。

   [第 2 步](#create-the-balance-view)中的代码通过此 Type 和 ID 将余额视图与自定义元素匹配。

   <ZoomImage id="vc-top-up-custom-element.webp" width="700px" alt="Custom element settings in the Flow & Paywall Builder, with currency_balance in the Type field, diamonds in the ID field, and an Icon inside the Diamond balance layer" />

2. 在自定义元素内部，添加一个钻石[**Icon**](custom-media#icon)。在没有余额视图的应用版本中，用户会看到该图标作为[备用内容](flow-custom-elements#set-fallback-content)。
