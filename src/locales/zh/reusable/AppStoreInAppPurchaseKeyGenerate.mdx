1. 在 App Store Connect 中，前往 [**Users and Access** > **Integrations** > **In-App Purchase**](https://appstoreconnect.apple.com/access/integrations/api/subs)。

   同一个密钥可供你的 App Store Connect 团队下所有应用使用。如需复用此页面中已有的活跃密钥，你需要有对应的文件。如果你已有该文件，可跳过第 2-4 步。生成新密钥后，原有的活跃密钥仍然有效。

2. 生成密钥需要在 App Store Connect 中拥有 Account Holder 或 Admin 角色。如果你没有这两个角色，请联系拥有相应角色的人员来生成密钥，并让其将文件连同 Issuer ID 和 Key ID 一并发给你。

   如果页面上已列出活跃密钥，点击 **+**；否则，点击 **Generate In-App Purchase Key**。

   <ZoomImage id="asc-in-app-purchase-keys-add.webp" width="700px" alt="In-App Purchase keys page in App Store Connect, with the button that adds a key" />

3. 输入密钥名称，然后点击 **Generate**。密钥将出现在 **Active** 列表中。

   <ZoomImage id="asc-in-app-purchase-key-name.webp" width="700px" alt="Generate In-App Purchase Key dialog with a name for the key and the Generate button" />

4. 每个密钥只能下载一次。在新密钥旁边，点击 **Download In-App Purchase Key**。

   <ZoomImage id="asc-in-app-purchase-key-download-link.webp" width="700px" alt="Active list of In-App Purchase keys, with the download link next to a new key" />

   然后在弹出的对话框中点击 **Download**。请妥善保管该文件：你需要将它上传到每个使用此密钥的 Adapty 应用中。

   <ZoomImage id="asc-in-app-purchase-key-download-dialog.webp" width="700px" alt="Download dialog for an In-App Purchase key" />
