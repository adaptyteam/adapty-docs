如果存在以下任何问题，您将无法发布或预览流程。

- 存在配置不完整的交互操作，常见情况包括：
    - **打开 URL** 操作未设置目标 URL。
    - **导航到屏幕**操作未设置目标页面——当目标屏幕在操作设置完成后被删除时，也会出现此问题。
    - **条件操作**未设置运算符或值。
    - **设置变量**操作未分配变量或值。
    - **购买**操作未关联任何产品（应用内商店）或未填写 Web 付费墙 URL（网页支付）。
    - **自定义**操作未填写 Action ID。
    - **显示提示**操作的标题或消息为空。
    - **显示**或**隐藏**操作未选择任何元素。
    - **选择产品**操作未设置目标产品——当目标产品元素被删除、移出所在产品组或留在其他屏幕时，也会出现此问题。
    - **选择产品**操作保存在可复用组件内，或其目标元素 ID 在多个屏幕上均有使用。
- **屏幕中没有任何元素**。
- 产品元素**未关联产品**——在移除已引用的产品后可能出现此问题。
- **远程配置** JSON 无效会导致整个交付流程失败——此时甚至无法保存草稿。
