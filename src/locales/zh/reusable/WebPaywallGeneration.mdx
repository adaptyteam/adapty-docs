在 **URL** 字段下，找到 **generate one with AI** 链接并点击。

展开 **Generation setup** 面板，按顺序完成其中的六个步骤。每个按钮会打开对应操作的页面，返回后点击 **Refresh** 刷新状态。

<ZoomImage id="mail-checkout-prerequisites.webp" width="500px" alt="Web Paywall 创建页面上的 Generation setup 清单" />

| 清单项目 | 操作说明 |
| --- | --- |
| **1. Brand is ready** | 如果你已设置好[品牌](mail-brand)，该项会自动勾选。否则点击 **Set up brand**。 |
| **2. Log in to the paywall builder dashboard** | 点击 **Log in** 以完成编辑器认证。 |
| **3. Stripe account connected** | 点击 **Connect Stripe** 并连接你的账户。 |
| **4. At least one Stripe product with a price** | 点击 **Open Stripe dashboard**，添加一个带价格的产品。 |
| **5. Generate the paywall** | 5.1. 点击 **Generate**。<br />5.2. 最多选择三个方案，第一个之后每个方案点击 **Add plan**。<br />5.3. 为每个方案设置生产环境价格、沙盒价格，或同时设置，且所有价格须使用同一货币。每个方案须填写同一列——某列数据填写不完整将无法生成。若未设置沙盒价格，[测试邮件](mail-testing)将使用生产环境付费墙，测试购买在该环境下无法正常进行。<br />5.4. 点击 **Generate paywall**，生成需要几分钟，完成后 **URL** 字段将自动填入。 |
| **6. Review and publish the paywall in the builder** | 点击 **Open editor**，检查并发布。在付费墙生成之前该按钮处于禁用状态。 |

<ZoomImage id="mail-checkout-generation-dialog.webp" width="500px" alt="包含生产环境和沙盒价格列的付费墙生成对话框" />

<Callout type="important">
付费墙必须在发布后才能处理结账流量。未发布的付费墙在用户点击邮件结账链接时会返回错误。
</Callout>

付费墙发布后，点击 **Save**。
