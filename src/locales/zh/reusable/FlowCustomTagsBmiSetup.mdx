1. [创建两个流程](paywall-builder-templates)：一个用于引导用户输入体重和身高的用户引导流程，以及一个显示 BMI 的付费墙流程。
2. 在用户引导流程中添加两个 [**Number** 输入框](builder-inputs-and-forms)：
   - 一个用于输入以公斤为单位的体重，**Element ID** 设为 `weight`。
   - 一个用于输入以厘米为单位的身高，**Element ID** 设为 `height`。

   两个输入框的 **Format** 均设为 **Integer**。[示例代码](#pass-the-bmi-to-the-paywall)需要整数。输入框会原样发送用户输入的内容，代码无法将 "70.5" 和 "70,5" 识别为相同的值。
3. 为确保应用能收到两个值，请在用户引导流程末尾添加一个没有输入框的屏幕。在该屏幕上添加一个带有 [**Close flow**](onboarding-actions#close-flow) 操作的按钮。输入框会在失去焦点或用户切换到另一个屏幕时发送其值，而 Close flow 操作不会触发发送。示例代码仅在用户到达最后一个屏幕时才会打开付费墙。
4. 在付费墙流程中，[创建一个名为 `bmi` 的自定义标签](flow-custom-tags#create-a-custom-tag)。在 **Initial value** 字段中输入一个破折号（`—`）。若应用未传入 BMI，用户将看到该破折号。
5. 在付费墙流程中添加一个文本元素，内容为 "Your BMI:"。在这些文字之后，[插入 `bmi` 自定义标签](flow-custom-tags#add-a-custom-tag-to-a-text-element)。
6. 将用户引导流程添加到某个[版位](placements)，例如 `onboarding`。将付费墙流程添加到 ID 为 `bmi_paywall` 的版位。[将 BMI 传递给付费墙](#pass-the-bmi-to-the-paywall)中的代码将通过此 ID 获取付费墙。
