[adapty-integration skill](https://github.com/adaptyteam/adapty-skills) 可自动完成 Adapty 的全流程集成：看板配置、SDK 安装、付费墙设置以及各阶段验证。它能自动检测你的平台，并在每个阶段获取相关 Adapty 文档。

**支持的工具**：Claude Code、GitHub Copilot CLI、OpenAI Codex、Gemini CLI。

安装时，根据你使用的工具选择对应的方式。完整列表请参见 [skill README](https://github.com/adaptyteam/adapty-skills)。

该仓库包含两个 skill——`adapty-integration` 和 `ads-manager`（通过 Adapty CLI 运行 Apple Search Ads）。下方每条命令均会同时安装两者。

**Claude Code**

```
claude plugin marketplace add adaptyteam/adapty-skills
claude plugin install adapty-skills@adapty
```

**GitHub Copilot CLI**

```
git clone https://github.com/adaptyteam/adapty-skills.git
cp -r adapty-sdk-integration-skill/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```
gemini skills install https://github.com/adaptyteam/adapty-skills
```

**OpenAI Codex 或其他工具** — 使用 [skills CLI](https://skills.sh)（注意：通过此方式安装的 skill 不会自动更新）：

```
npx skills add adaptyteam/adapty-skills --all
```

`--all` 会将两个 skill 安装到所有检测到的 agent 中。不加该参数时，CLI 会询问你要安装哪一个。

也可以克隆仓库，将 `skills/` 下的目录复制到你的工具对应的 skills 目录中。

安装完成后，在你的项目中运行该 skill：

```
/adapty-integration
```

该 skill 会询问几个配置问题，然后逐步引导完成看板配置、SDK 安装、付费墙设置和验证。
