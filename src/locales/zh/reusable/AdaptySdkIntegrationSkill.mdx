`adapty-integration` 技能可端到端自动完成 Adapty 集成：看板配置、SDK 安装、付费墙设置以及每个阶段的验证。它会自动检测你的平台，并在每个阶段拉取相关 Adapty 文档。它适用于任何支持技能的编码智能体：Claude Code、Codex、Cursor、GitHub Copilot、Gemini CLI 等。

该技能是 [Adapty 插件](manage-adapty-with-ai) 的一部分。如果你已安装插件，则已拥有此技能。如果你的智能体未列出该技能，请使用 [插件 README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install) 中适用于你的智能体的命令更新插件。

如需在编码智能体中安装插件，请在终端中运行：

```bash
npx adapty skills install
```

重启智能体以加载插件。其他安装方式请参阅 [插件 README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install)。

Claude Code 不会自动更新插件。如需在新技能发布后及时获取，请在 Claude Code 中运行 `/plugin`，打开 **Marketplaces**，选择 `adapty`，然后选择 **Enable auto-update**。其他智能体的更新命令请参阅 [插件 README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install)。

如需开始集成，在你的智能体中输入：

```
Integrate Adapty into my app
```

技能会提出几个配置问题，然后逐步完成看板配置、SDK 安装、付费墙设置和验证。
