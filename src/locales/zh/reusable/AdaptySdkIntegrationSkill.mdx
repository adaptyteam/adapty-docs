`adapty-integration` 技能可端到端自动完成 Adapty 集成：看板配置、SDK 安装、付费墙设置以及每个阶段的验证。它能自动检测你的平台，并在每个阶段获取相关的 Adapty 文档。该技能支持所有兼容技能的 AI 编程助手：Claude Code、Codex、Cursor、GitHub Copilot、Gemini CLI 等。

该技能是 [`adapty-skills` 插件](https://github.com/adaptyteam/adapty-skills)的一部分。要安装插件，请在终端中运行：

```bash
npx adapty skills install
```

重启你的助手以加载技能。其他安装方式请参阅[插件 README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install)。

Claude Code 不会自动更新插件。若要在新技能发布时及时获取，请在 Claude Code 中运行 `/plugin`，打开 **Marketplaces**，选择 `adapty`，然后选择 **Enable auto-update**。其他助手的更新命令请参阅[插件 README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install)。

要开始集成，在你的助手中输入：

```
Integrate Adapty into my app
```

该技能会询问几个配置问题，然后依次引导你完成看板配置、SDK 安装、付费墙设置和验证。
