[adapty-sdk-integration skill](https://github.com/adaptyteam/adapty-sdk-integration-skill) 可以端到端自动化 Adapty 集成：看板配置、SDK 安装、付费墙，以及各阶段验证。它会自动检测你的平台，并在每个阶段获取相关的 Adapty 文档。

**支持的工具**：Claude Code、GitHub Copilot CLI、OpenAI Codex、Gemini CLI。

安装时，根据你使用的工具选择对应的方式。完整列表见 [skill README](https://github.com/adaptyteam/adapty-sdk-integration-skill)。

该仓库包含两个 skill——`adapty-sdk-integration` 和 `ads-manager`，后者通过 Adapty CLI 运行 Apple Search Ads。以下每条命令均会同时安装这两个 skill。

**Claude Code**

```
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

**GitHub Copilot CLI**

```
git clone https://github.com/adaptyteam/adapty-sdk-integration-skill.git
cp -r adapty-sdk-integration-skill/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex 或其他工具** — 使用 [skills CLI](https://skills.sh)（注意通过此方式安装的 skill 不会自动更新）：

```
npx skills add adaptyteam/adapty-sdk-integration-skill --all
```

`--all` 会将两个 skill 安装到所有检测到的 agent 中。不加该参数时，CLI 会询问你要安装哪一个。

你也可以克隆仓库，将 `skills/` 目录下的各子目录复制到你的工具对应的 skills 目录中。

安装完成后，在你的项目中运行该 skill：

```
/adapty-sdk-integration
```

该 skill 会询问几个配置问题，然后逐步完成看板配置、SDK 安装、付费墙和验证。
