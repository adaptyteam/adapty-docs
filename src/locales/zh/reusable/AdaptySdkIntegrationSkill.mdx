`adapty-integration` 技能可端到端自动化 Adapty 集成流程：看板配置、SDK 安装、付费墙搭建以及各阶段验证。它能自动检测你的平台，并在每个阶段获取相关的 Adapty 文档。该技能适用于任何支持技能的编程助手：Claude Code、Codex、Cursor、GitHub Copilot、Gemini CLI 等。

该技能是 [`adapty-skills` 插件](https://github.com/adaptyteam/adapty-skills) 的一部分。请在终端运行以下命令安装插件：

```bash
npx adapty skills install
```

重启你的助手以加载技能。其他安装方式请参见[插件 README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install)。

要开始集成，请在你的助手中输入：

```
Integrate Adapty into my app
```

技能会询问几个配置问题，然后引导你完成看板配置、SDK 安装、付费墙搭建和验证流程。
