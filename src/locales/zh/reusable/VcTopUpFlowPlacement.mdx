在 Flow & Paywall Builder 中创建充值流程。将该流程添加到 ID 为 `out_of_diamonds` 的[版位](placements)。当余额不足以完成消耗时，第 4 步中的代码会从该版位打开流程。

要根据余额显示不同的充值流程，请在 `out_of_diamonds` 版位中添加一个包含[虚拟货币余额细分](segments#virtual-currency-balance)的[目标受众](audience)。例如，向钻石数量为 0 的用户展示单独的流程。每次应用代码获取流程时，Adapty 都会读取余额，因此一次消耗或购买可能会改变用户下次看到的流程。

如需在该流程中也显示钻石余额，请[添加一个自定义元素](flow-custom-elements#add-and-configure)，其 Type 和 ID 与能量不足流程中的完全相同：`currency_balance` 和 `diamonds`。在自定义元素内，添加钻石 **Icon** 作为备用内容。这样玩家在两个流程中看到的余额视图完全一致，无需为此添加任何代码。
