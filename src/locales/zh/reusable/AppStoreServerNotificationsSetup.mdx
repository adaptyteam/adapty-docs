1. 在 Adapty 中，打开你要连接的应用：每个 Adapty 应用都有自己独立的通知 URL。前往 [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk)。在 **App Store server notifications** 部分，从 **URL for App Store server notifications** 字段中复制 URL。

   <ZoomImage id="app-settings-notifications-url.webp" width="700px" alt="URL for App Store server notifications in the App Store server notifications section in Adapty" />

2. 在 [App Store Connect](https://appstoreconnect.apple.com/apps) 中，打开你的应用的 **App Information** 页面。
3. 在 **App Store Server Notifications** 部分，找到 **Production Server URL**。如果已有 URL，点击 **Edit**；否则点击 **Set Up URL**。

   <ZoomImage id="asc-server-notifications-set-up-url.webp" width="700px" alt="App Store Server Notifications section on the App Information page in App Store Connect" />

4. 粘贴来自 Adapty 的 URL，然后点击 **Save**。

   <ZoomImage id="asc-server-url-set-up-dialog.webp" width="700px" alt="Production Server URL dialog in App Store Connect with the URL from Adapty" />

5. 若要让沙盒测试中的通知也能到达 Adapty，请对 **Sandbox Server URL** 重复步骤 3 和 4。
