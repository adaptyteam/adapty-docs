**已启用（默认）**

已识别用户（拥有 [Customer User ID](identifying-users#set-customer-user-id-on-configuration) 的用户）在设备登录相同 Apple/Google 账号的情况下，可以共享 Adapty 提供的同一[访问等级](access-level)。当用户重新安装应用并使用不同邮箱登录时，仍可访问之前购买的内容。启用此选项后，多个已识别用户可以共享同一访问等级。

虽然访问等级是共享的，但所有过去和未来的交易仍会作为事件记录在原始 Customer User ID 下，以保持分析数据的一致性并完整保留交易历史——包括试用期、订阅购买、续订等，均关联到同一用户画像。

**将访问权限转移给新用户**

已识别用户可以继续访问 Adapty 提供的[访问等级](access-level)，即使他们使用不同的 [Customer User ID](identifying-users#set-customer-user-id-on-configuration) 登录或重新安装应用，只要设备登录的是同一 Apple/Google 账号即可。

与前一选项不同，Adapty 会在已识别用户之间转移购买记录。这样可以确保已购内容始终可用，但每次只有一个用户可以拥有访问权限。例如，如果 UserA 购买了订阅，UserB 在同一设备上登录并恢复交易，则 UserB 将获得该订阅的访问权限，而 UserA 的访问权限将被撤销。

如果其中一个用户（新用户或旧用户）未被识别，Adapty 中的这两个用户画像仍会共享访问等级。

虽然访问等级会被转移，但所有过去和未来的交易仍会作为事件记录在原始 Customer User ID 下，以保持分析数据的一致性并完整保留交易历史——包括试用期、订阅购买、续订等，均关联到同一用户画像。

切换到**将访问权限转移给新用户**后，用户画像之间的访问等级不会立即转移。每个特定访问等级的转移流程仅在 Adapty 收到来自商店的事件时触发，例如订阅续订、恢复购买或验证交易时。

**已禁用**

第一个获得访问等级的已识别用户画像将永久保留该等级。如果您的业务逻辑要求购买记录绑定到单一 Customer User ID，这是最佳选择。

请注意，访问等级在匿名用户之间仍会共享。

您可以通过[删除所有者的用户画像](https://adapty.io/docs/zh/api-adapty/operations/deleteProfile)来"解绑"购买记录。删除后，该访问等级将归属于第一个申领它的用户画像，无论是匿名用户还是已识别用户。

禁用共享仅影响新用户。已在用户之间共享的订阅在禁用此选项后仍将继续共享。

<Callout type="warning">
Apple 和 Google 要求在用户之间共享或转移应用内购买，因为他们依赖 Apple/Google 账号来关联购买记录。若不启用共享，用户在重新安装后可能无法恢复购买。

禁用共享可能导致用户登录后无法重新获得访问权限。

我们建议仅在用户**必须先登录**才能购买的情况下禁用共享。否则，已识别用户可能在购买订阅后登录到另一个账号，从而永久失去访问权限。
</Callout>

### 我应该选择哪个设置？\{#which-setting-should-i-choose\}

| 我的应用……                                                    | 推荐选项                                                             |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| 没有登录系统，仅使用 Adapty 的匿名用户画像 ID。 | 使用默认选项，因为在三种选项中，访问等级始终在匿名用户画像 ID 之间共享。 |
| 拥有可选登录系统，允许用户在创建账号前进行购买。 | 选择**将访问权限转移给新用户**，确保未登录时购买的用户之后仍可恢复交易。 |
| 要求用户在购买前创建账号，但允许购买记录关联到多个 Customer User ID。 | 选择**将访问权限转移给新用户**，确保每次只有一个 Customer User ID 拥有访问权限，同时允许用户使用不同 Customer User ID 登录而不丢失已付费的访问权限。 |
| 要求用户在购买前创建账号，并严格规定购买记录绑定到单一 Customer User ID。 | 选择**已禁用**，确保交易记录永远不会在账号之间转移。 |
