1. 在 App Store Connect 中，前往 [**Users and Access** > **Integrations** > **App Store Connect API**](https://appstoreconnect.apple.com/access/integrations/api)，并打开 **Team Keys** 标签页。Adapty 需要团队密钥：个人密钥没有 Issuer ID。

   一个团队密钥可供你的 App Store Connect 团队下的所有 App 使用。如果该标签页上已有一个具有 **Admin** 访问权限的有效密钥，且你持有对应文件，可直接复用并跳过第 2-4 步。

   如果你的团队尚未获得 App Store Connect API 访问权限，需由账户持有人（Account Holder）[申请开通](https://developer.apple.com/help/app-store-connect/get-started/app-store-connect-api)。Apple 会逐一审核每项申请。

2. 生成密钥需要在 App Store Connect 中拥有 Account Holder 或 Admin 角色。如果两者都没有，请联系具有相应角色的人员，让其生成一个具有 **Admin** 访问权限的密钥，并将文件连同 Issuer ID 和 Key ID 一并发给你。

   如果标签页中已列有有效密钥，点击 **+**；否则，点击 **Generate API Key**。

   <ZoomImage id="asc-team-keys-add.webp" width="700px" alt="Team Keys tab of the App Store Connect API page in App Store Connect" />

3. 输入密钥名称，并将 **Access** 设置为 **Admin**。**Access** 决定了 Adapty 使用该密钥的权限范围，与你自身的角色无关。密钥生成后无法更改 **Access**。点击 **Generate**。

   <ZoomImage id="asc-team-key-generate-dialog.webp" width="700px" alt="Dialog for a new team key, with a name and the Access dropdown" />

4. 每个密钥只能下载一次。在新密钥旁边点击 **Download**。请妥善保管该文件：你需要将其上传到每个使用该密钥的 Adapty 应用中。

   <ZoomImage id="asc-team-key-download.webp" width="700px" alt="Active list of team keys, with the Download link next to a new key" />
