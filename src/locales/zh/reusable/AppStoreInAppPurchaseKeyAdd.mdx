1. 要查找密钥的 **Issuer ID** 和 **Key ID**，请在 App Store Connect 中前往 [**Users and Access** > **Integrations** > **In-App Purchase**](https://appstoreconnect.apple.com/access/integrations/api/subs)。如果是其他人生成了密钥并将 Issuer ID、Key ID 和文件发送给您，请跳过此步骤。

   <ZoomImage id="asc-in-app-purchase-keys-ids.webp" width="700px" alt="Issuer ID and the Key ID of an In-App Purchase key in App Store Connect" />

2. 在 Adapty 中，前往 [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk)。在 **In-app purchase API (StoreKit 2)** 部分，填写以下字段：
   - **Issuer ID**：从 App Store Connect 的 **In-App Purchase** 页面复制。
   - **Key ID**：从 **In-App Purchase** 页面的 **Active** 列表中复制，位于您下载的密钥旁边。
   - **Private key (.p8 file)**：上传您下载的文件。

   <ZoomImage id="app-settings-in-app-purchase-api.webp" width="700px" alt="Issuer ID, Key ID, and Private key (.p8 file) fields in the In-app purchase API (StoreKit 2) section in Adapty" />

3. Adapty 使用 In-App Purchase 密钥为[促销活动](offers)签名。在 **App Store promotional offers** 部分，再次输入密钥：
   - **Subscription key ID**：步骤 2 中的 Key ID。
   - **Subscription key (.p8 file)**：步骤 2 中的文件。

   <ZoomImage id="app-settings-promotional-offers.webp" width="700px" alt="Subscription key ID and Subscription key (.p8 file) fields in the App Store promotional offers section" />

   若使用了不同的密钥，保存时不会报错，但用户将无法收到促销活动。

4. 点击 **Save**。Adapty 在保存页面之前，会通过 Apple 验证 **In-app purchase API (StoreKit 2)** 部分中的密钥。如果 Apple 拒绝该密钥，页面将显示"The provided field values are incorrect"：请[检查相关值](troubleshoot-app-store-integration#the-provided-field-values-are-incorrect-when-saving-credentials)。
