如果你已经安装了 Adapty 插件，就已经拥有了这个技能。如果你的 agent 没有列出它，请使用 [plugin README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install) 中适用于你的 agent 的命令更新插件。

要在编程 agent 中安装插件，请在终端运行：

```bash
npx adapty skills install
```

重启你的 agent 以加载插件。要在 claude.ai 或 Claude 桌面端安装插件，请参阅[安装插件](manage-adapty-with-ai#install-the-plugin)。其他安装方式请参阅 [plugin README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install)。

Claude Code 不会自动更新插件。要在新技能发布时获取它们，请在 Claude Code 中运行 `/plugin`，打开 **Marketplaces**，选择 `adapty`，然后选择 **Enable auto-update**。其他 agent 的更新命令请参阅 [plugin README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install)。
