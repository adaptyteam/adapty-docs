要安装插件，请在终端中运行：

```bash
npx adapty skills install
```

重启你的智能体以加载技能。其他安装方式请参阅 [插件 README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install)。

Claude Code 不会自动更新插件。要在发布时获取新技能，请在 Claude Code 中运行 `/plugin`，打开 **Marketplaces**，选择 `adapty`，然后选择 **Enable auto-update**。其他智能体的更新命令请参阅 [插件 README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install)。
