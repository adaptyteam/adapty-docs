留存消息让您可以在取消流程中触达即将流失的订阅用户。当用户进入 iOS 的"取消订阅"界面时，Apple 会根据其产品和语言区域向其展示对应的消息。

留存消息分为两种类型：

- **默认**：简单的赢回消息，包含标题、正文和可选图片。当促销消息不可用时作为备用方案。
- **促销**：向订阅用户提供特别优惠或其他方案的赢回消息。只有已分配默认消息的产品才能创建促销消息。

## 开始前准备 \{#before-you-begin\}

- 至少创建一个[产品](create-product)，以便留存消息关联。
- 在沙盒模式下[测试留存消息](retention-messaging-setup)。

## 创建消息 \{#create-a-message\}

在 Adapty 看板中打开 Retention Messaging 页面。点击 **Create Default** 创建默认消息，或点击 **Create Message** 创建促销消息。

<ZoomImage id="retention-select-default-or-promo.webp" width="700px" alt="The Create Default and Create Message buttons in the Retention Messaging page header" />

选择环境——沙盒消息用于测试，生产消息面向真实用户。在你[配置生产 URL](retention-messaging-setup#switch-to-production) 并通过沙盒性能测试之前，生产选项将保持禁用状态。

<ZoomImage id="retention-new-message.webp" width="700px" alt="新消息起始页面，包含“创建沙盒消息”和“创建生产消息”选项" />

### 常规 \{#general\}

为消息命名，并添加取消订阅时将触发此消息的产品。

产品列表中无法添加的产品会显示为灰色，并在旁边标注原因：**used** 表示已有同类型的其他消息覆盖该产品；**no default message** 表示该产品需要先配置默认消息，才能设置促销消息。

<ZoomImage id="retention-message-step-1-general.webp" width="700px" alt="Default message General step with the Name field and Products section" />

对于**促销**消息，需要为添加的每个产品关联一个优惠。每个产品对应一个优惠，在所有产品都关联了优惠之前，**Next** 按钮保持禁用状态：

- **Link Promo Offer**：您[之前为该产品设置的](app-store-offers)促销活动。

    <ZoomImage id="retention-messaging-promo.webp" width="500px" alt="Promo message General step with the Associated offers list open for a product" />

- **Link Plan Switch**：您目录中的其他产品。如果产品列表为空，请检查您是否已添加 [App Store Connect API 密钥](app-store-connection-configuration)：Adapty 需要此密钥来查找产品。

    <ZoomImage id="retention-messaging-switch-plan.webp" width="500px" alt="Promo message General step with the Associated plan list open for a product" />

### 内容 \{#content\}

用英文编写消息内容。右侧预览区会在您输入时实时显示取消订阅屏幕上的效果。

**默认**消息可以包含图片。在 **Alt text** 字段中添加替代文本，以便屏幕阅读器描述该图片。替代文本不会被本地化：Apple 在所有语言环境中都使用英文替代文本。

默认情况下，标题和正文显示在图片下方。如需将标题显示在图片上方，请在 **Title position** 下选择 **Above the image**。正文始终保持在图片下方。

<ZoomImage id="retention-message-step-2-content.webp" width="700px" alt="内容步骤中已上传图片，标题位置设置为图片上方，手机预览显示标题位于图片上方" />

:::important
请在创建消息时选择标题位置。之后无法更改——如需使用其他位置，请创建新消息。如果创建消息时未添加图片，之后再添加，标题将保持在图片下方。
:::

### 本地化 \{#localization\}

英语是源语言。添加订阅者使用的其他语言，然后翻译内容。

1. 点击 **Add Locale**，选择要支持的语言区域。
2. 点击 **AI Translate All Cells**，自动翻译[内容](#content)。翻译会替换所有已添加语言区域的标题和正文，包括手动编辑的内容，因此请先完成翻译再进行编辑。
3. 点击任意单元格可编辑翻译内容。

每种语言的翻译必须符合与英文原文相同的字数限制：标题不超过 66 个字符，正文不超过 144 个字符。超出限制将阻止 **Submit To Review**，直到你缩短文字为止。

将鼠标悬停在某个语言区域上，可在"取消订阅"页面预览效果。

如果 Apple 尚未批准目标语言的翻译，Adapty 将回退至 `en-US` 版本。

<ZoomImage id="retention-message-step-3-localization.webp" width="700px" alt="包含语言区域表格和 AI Translate All Cells 按钮的本地化步骤" />

## 提交审核 \{#submit-for-review\}

消息准备好后，点击 **Submit To Review**。Adapty 会将所有已填写标题或正文的语言版本上传至 Apple，Apple 随即开始审核。标题和正文均为空的语言版本将被自动忽略。你可以在 Retention Messaging 页面上查看提交的[状态](#message-states)。

Adapty 仅在你提交时才会保存消息。

## 消息状态 \{#message-states\}

提交消息后，Apple 会对每个语言区域分别进行审核。只要 Apple 批准了至少一个语言区域，该消息就会上线。对于尚未通过审核的语言区域，Adapty 会[回退到 `en-US`](#localization)。**Retention Messaging** 页面上的 **State** 列可用于跟踪消息的审核进度：

| 状态 | 含义 |
| --- | --- |
| **In review** | Apple 尚未收到该消息，或尚未审核通过任何语言版本。 |
| **Live** | Apple 已批准该消息，Adapty 会将其展示给正在取消订阅的用户。 |
| **Rejected** | Apple 在至少一个语言版本中拒绝了提交——请尝试提交替代版本。 |
| **Inactive** | 您已[停用](#deactivate-and-reactivate)该消息。现在可以为相同产品创建新消息。 |

要查看 Apple 尚未批准的语言区域，请打开消息并转到 **Localization** 步骤。每个已添加的语言区域都会显示其各自的 **Live**、**In review** 或 **Rejected** 状态。

您可以随时编辑任何消息——包括正在向客户提供服务的消息。如果您编辑 **Live** 状态的消息，或向其添加新的语言区域，该消息将立即失去 Live 状态，并重新变为 **In review** 状态。

如果您修改了现有消息的英文标题或正文，**Content** 步骤按钮将变为 **Update Locales**。点击该按钮以打开 **Localization** 步骤，更新翻译内容，然后点击 **Submit To Review**。

## 停用与重新激活 \{#deactivate-and-reactivate\}

若要将消息从 Apple 下架但不从 Adapty 中删除，请打开该消息所在行的菜单，然后点击 **Deactivate**。

若要重新上架，请点击 **Activate**。重新激活无需 Apple 审核，消息可能需要几分钟才能送达所有订阅者。

每个产品最多只能有一条默认消息和一条促销消息。如果该消息处于停用期间，另一条同类型的消息已占用该产品，则激活将失败。
