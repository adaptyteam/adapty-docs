留存消息让您可以在取消流程中触达即将流失的订阅用户。当用户进入 iOS 的"取消订阅"界面时，Apple 会根据其产品和语言区域向其展示对应的消息。

留存消息分为两种类型：

- **默认（Default）**：基础留存消息，包含标题、正文、可选图片以及最多五个要点。当促销消息不可用时，将以此作为备用。
- **促销（Promo）**：向订阅用户提供特别优惠或其他方案的留存消息。仅当某个产品已分配了默认消息时，才能为其创建促销消息。

## 开始前准备 \{#before-you-begin\}

- 至少创建一个[产品](create-product)，以便留存消息关联。
- 在沙盒模式下[测试留存消息](retention-messaging-setup)。

## 创建消息 \{#create-a-message\}

在 Adapty 看板中打开 Retention Messaging 页面。点击 **Create Default** 创建默认消息，或点击 **Create Message** 创建促销消息。

<ZoomImage id="retention-select-default-or-promo.webp" width="700px" alt="The Create Default and Create Message buttons in the Retention Messaging page header" />

选择环境——沙盒消息用于测试，生产消息面向真实用户。在你[配置生产 URL](retention-messaging-setup#switch-to-production) 并通过沙盒性能测试之前，生产选项将保持禁用状态。

<ZoomImage id="retention-new-message.webp" width="700px" alt="新消息起始页面，包含“创建沙盒消息”和“创建生产消息”选项" />

### 常规设置 \{#general\}

为消息命名，并添加取消时将触发该消息的产品。

产品列表会将无法添加的产品显示为灰色，并在每个产品旁注明原因：**used** 表示同类型的另一条消息已涵盖该产品，**no default message** 表示该产品需要先设置默认消息，才能使用促销消息。

沙盒环境和生产环境的消息相互独立，因此沙盒环境中的默认消息无法覆盖生产环境中的产品。在创建生产环境的促销消息之前，请先为同一产品创建一条生产环境的默认消息。无需等待 Apple 审核：提交默认消息后，即可立即将其产品添加到促销消息中。

<ZoomImage id="retention-message-step-1-general.webp" width="700px" alt="Default message General step with the Name field and Products section" />

对于**促销**消息，需要为你添加的每个产品关联一个激励项。每个产品对应一个激励项，在所有产品都关联激励项之前，**Next** 按钮保持禁用状态：

- **Link Promo Offer**：你[之前为产品设置的](app-store-offers)促销活动。列表中仅显示促销活动，因此赢回优惠和新用户优惠不会出现在列表中。如果列表为空，请[在 App Store Connect 中创建促销活动](app-store-offers#promotional-offers)，并[在 Adapty 中将其添加到产品中](create-offer)。

    <ZoomImage id="retention-messaging-promo.webp" width="500px" alt="Promo message General step with the Associated offers list open for a product" />

- **Link Plan Switch**：从您的产品目录中选择另一个产品。如果套餐列表为空，请检查您是否已添加 [App Store Connect API 密钥](app-store-connection-configuration)：Adapty 需要该密钥来查找套餐。

    <ZoomImage id="retention-messaging-switch-plan.webp" width="500px" alt="Promo message General step with the Associated plan list open for a product" />

### 内容 \{#content\}

用英文编写消息内容。右侧预览区会在您输入时实时显示取消订阅屏幕上的效果。

**默认**消息可以包含图片。在 **Alt text** 字段中添加替代文本，以便屏幕阅读器描述该图片。替代文本不会被本地化：Apple 在所有语言环境中都使用英文替代文本。

默认情况下，标题和正文显示在图片下方。如需将标题显示在图片上方，请在 **Title position** 下选择 **Above the image**。正文始终保持在图片下方。

<ZoomImage id="retention-message-step-2-content.webp" width="700px" alt="内容步骤中已上传图片，标题位置设置为图片上方，手机预览显示标题位于图片上方" />

:::important
请在创建消息时选择标题位置。之后无法更改——如需使用其他位置，请创建新消息。如果创建消息时未添加图片，之后再添加，标题将保持在图片下方。
:::

**Default** 消息还可以在正文下方列出最多五个要点，无论是否带有图片。要添加要点，请在 **Bullet points** 下点击 **+ Add Bullet Point**，然后填写相关字段：

- **Icon**：每个要点均为必填项。上传一张 PNG 图片，尺寸必须为 1024 × 1024 像素，且不含透明度。Apple 会单独审核每个图标。
- **Text**：最多 66 个字符。
- **Alt text**：供屏幕阅读器使用的图标描述。若留空，Adapty 会向 Apple 发送默认描述。与图片的 alt 文本一样，该字段不会进行本地化。

<ZoomImage id="retention-message-bullet-points.webp" width="600px" alt="已填写子弹点 1 卡片的内容步骤，以及手机预览中消息正文下方列出三个带图标的子弹点" />

促销消息不支持子弹点。

### 本地化 \{#localization\}

英语为源语言。添加订阅者使用的其他语言，然后翻译内容。

1. 点击 **Add Locale**，选择需要支持的语言区域。
2. 点击 **AI Translate All Cells**，自动翻译[内容](#content)。翻译结果会替换所有已添加语言区域中的标题、正文和要点文本，包括你手动编辑的内容，因此请先翻译，再进行编辑。
3. 点击任意单元格即可编辑译文。

每个语言版本的字符限制与英文原文相同：标题最多 66 个字符，正文最多 144 个字符，每条要点最多 66 个字符。超出限制将阻止 **Submit To Review** 操作，直到你缩短文字。任何语言版本中有文字的要点若为空，也会阻止提交。每条要点的图标在所有语言版本中保持一致，只翻译要点文字。

将鼠标悬停在某个语言版本上，可在取消订阅页面预览其效果。

如果 Apple 尚未审核通过某语言的翻译，Adapty 将回退使用 `en-US` 版本。

<ZoomImage id="retention-message-step-3-localization.webp" width="700px" alt="本地化步骤，包含语言环境表格和 AI 全量翻译按钮" />

## 提交审核 \{#submit-for-review\}

消息准备好后，点击 **Submit To Review**。Adapty 会将消息及其要点图标上传至 Apple，涵盖所有填写了任意文本的语言区域，Apple 随即开始审核。若某个语言区域的所有单元格均为空，Adapty 会自动跳过该区域。请在 Retention Messaging 页面监控提交内容的[状态](#message-states)。

消息仅在提交时才会被 Adapty 保存。

## 消息状态 \{#message-states\}

提交消息后，Apple 会分别审核每个语言版本。只有当 Apple 批准所有语言版本（包括英语）后，消息才会正式上线。Default 消息还需要 Apple 将其确认为你添加的每个产品的默认消息。在此之前，消息会保持 **In review** 状态，即使部分语言版本已显示 **Live**。对于 Apple 尚未批准的语言版本，Adapty 会[回退至 `en-US`](#localization)。Retention Messaging 页面上的 **State** 列可帮助你跟踪消息的审核进度：

| 状态 | 含义 |
| --- | --- |
| **In review** | Apple 尚未收到该消息，或尚未批准其所有语言版本，或尚未为其所有产品接受默认消息。 |
| **Live** | Apple 已批准该消息，Adapty 将其推送给正在取消订阅的用户。 |
| **Rejected** | Apple 拒绝了至少一种语言版本的提交——请尝试提交替代版本。 |
| **Inactive** | 您已[停用](#deactivate-and-reactivate)该消息。现在可以为相同产品创建新的消息。 |

要查看 Apple 尚未批准哪些语言区域，请打开该消息并转到 **Localization** 步骤。每个已添加的语言区域都会显示其各自的 **Live**、**In review** 或 **Rejected** 状态。英语行没有状态显示，但 Apple 也必须批准它。如果所有已添加的语言区域均显示 **Live**，而该消息仍处于 **In review** 状态，请联系支持团队并提供消息名称。

您可以随时编辑任意消息——包括正在向用户提供服务的消息。如果您编辑一条 **Live** 消息，或为其添加新语言版本，该消息将立即失去上线状态，重新变为 **In review** 状态。

如果您修改了现有消息的英文标题或正文，**Content** 步骤按钮将变为 **Update Locales**。点击该按钮进入 **Localization** 步骤，更新翻译内容，然后点击 **Submit To Review**。

## 停用与重新激活 \{#deactivate-and-reactivate\}

若要将消息从 Apple 下架但不从 Adapty 中删除，请打开该消息所在行的菜单，然后点击 **Deactivate**。

若要重新上架，请点击 **Activate**。重新激活无需 Apple 审核，消息可能需要几分钟才能送达所有订阅者。

每个产品最多只能有一条默认消息和一条促销消息。如果该消息处于停用期间，另一条同类型的消息已占用该产品，则激活将失败。
