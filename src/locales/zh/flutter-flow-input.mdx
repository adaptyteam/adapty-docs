当用户在[流程](adapty-flow-builder)中填写输入框、回答问题或切换开关时，SDK 会通过分析回调将该值传递给你的应用。

应用通常会将这些数据用于：

- **在自己的后端注册用户**：获取用户在用户引导流程中输入的邮箱地址和姓名，在流程关闭时为其创建账户。
- **保存答案和偏好设置**：记录用户的选择，以便应用后续使用——例如，[将其作为自定义属性写入用户的 Adapty 用户画像](flutter-setting-user-attributes)。
- **自定义后续流程**：将问卷答案保存为自定义属性，再针对后续版位进行定向，让每个市场细分看到不同的流程，或其中不同的付费墙。
- **展示根据答案计算的数值**：例如，根据用户的体重和身高计算 BMI，并[将其传递给下一个流程中的自定义标签](flutter-flow-custom-tags#example-show-a-bmi-from-onboarding-answers)。
- **向第三方分析平台传送数据**：将答案转发至 Amplitude、Mixpanel 或你所使用的产品分析工具。

输入框和可选组会自动上报其值。为了在代码中区分不同的输入框，请在编辑工具中为每个输入框指定一个有意义的 **Element ID**，为每个可选组指定一个 **Group ID**。

## 接收输入值 \{#receive-input-values\}

输入值会随其他所有来自流程的分析事件一起，通过事件名称 `flow_user_input` 到达同一个回调。在通过 `AdaptyUI().setFlowsEventsObserver` 注册的观察者上实现 `flowViewDidReceiveAnalyticEvent`：

```dart showLineNumbers title="Flutter"
void flowViewDidReceiveAnalyticEvent(
  AdaptyUIFlowView view,
  String name,
  Map<String, dynamic> params,
) {
  handleFlowInput(name, params);
}
```

`flowViewDidReceiveAnalyticEvent` 回调会传递来自流程的所有分析事件，包括[屏幕浏览事件](flutter-flow-screen-views)。如需筛选用户输入事件，请将 `name` 与 `flow_user_input` 进行比较。存储值的参数取决于 `element_type`：

| `element_type` | 存储值的参数 | Dart 类型 |
|:---------------|:----------------------------|:--------|
| `text_input`, `email_input`, `number_input`, `phone_input` | `value` | `String` |
| `date_picker`, `time_picker`, `date_time_picker` | `value` | `num`，Unix 时间（毫秒）：从 SDK 4.3.0 起两端均为 `int`。更早版本的 SDK 中，Android 上为 `double`，请以 `num` 读取。 |
| `wheel_range_picker` | `value` | `num`：整数为 `int`，含小数为 `double`。Android SDK 4.3.0 之前始终为 `double`，请以 `num` 读取。 |
| `single_choice`, `multi_choice` | `item_ids`, `item_titles` | `List` |
| `toggle` | `value` | `bool` |

## 传输与限制 \{#delivery-and-limitations\}

<FlowInputLimitations />

将每个输入值存储在观察者接收时，并在流程关闭时发送完整的数据集。要捕捉该时机，请在同一个观察者上实现 `flowViewDidDisappear`。无论用户完成了流程还是中途关闭，该方法都会在流程视图消失时执行。

## 使用场景 \{#use-cases\}

### 在后端注册用户 \{#register-users-on-your-backend\}

在答案逐步收集完毕后，等流程关闭时再统一发送，这样一次请求就能携带完整的答案集。

无论用户是完成了流程还是中途退出，页面都会消失。在调用后端之前，请先检查所需字段是否已填写。

流程无法展示来自后端的错误信息。回调没有返回值，正在运行的流程也无法接收来自应用的数据。如果注册失败（例如邮箱已被占用），请在流程关闭后通过你自己的 UI 展示错误提示。

```dart showLineNumbers title="Flutter"
final Map<String, String> flowAnswers = {};

void flowViewDidReceiveAnalyticEvent(
  AdaptyUIFlowView view,
  String name,
  Map<String, dynamic> params,
) {
  if (name != 'flow_user_input') return;

  final elementId = params['element_id'];
  final value = params['value'];
  if (elementId is! String || value is! String) return;

  flowAnswers[elementId] = value;
}

void flowViewDidDisappear(AdaptyUIFlowView view) {
  if (!flowAnswers.containsKey('email')) return;

  // Send flowAnswers to your backend here to create the account.

  flowAnswers.clear();
}
```

### 用户画像数据填充 \{#enrich-user-profiles-with-data\}

为了将用户输入的内容与其用户画像关联，并避免重复询问相同信息，请在数据输入时[更新用户画像](flutter-setting-user-attributes)。

例如，如果您的流程中有一个 Element ID 为 `name` 的文本输入框和一个 Element ID 为 `email` 的邮件输入框：

```dart showLineNumbers title="Flutter"
void handleFlowInput(String name, Map<String, dynamic> params) async {
  if (name != 'flow_user_input') return;

  final value = params['value'];
  if (value is! String) return;

  final builder = AdaptyProfileParametersBuilder();

  switch (params['element_id'] as String) {
    case 'name':
      builder.setFirstName(value);
      break;
    case 'email':
      builder.setEmail(value);
      break;
    default:
      return;
  }

  try {
    await Adapty().updateProfile(builder.build());
  } on AdaptyError catch (adaptyError) {
    // handle the error
  }
}
```

### 自定义后续显示的流程 \{#customize-flows-shown-later\}

测验答案也可以决定用户在后续[版位](placements)中看到什么——不同的流程，或其中不同的付费墙。

例如，在用户引导流程中询问用户的运动经历，然后根据分组为每类用户展示包含不同产品和文案的专属流程。

1. 在流程中添加[测验](onboarding-quizzes)。将[可选组](flow-selectable-elements)的 Group ID 设为 `experience`，并为每个选项设置有意义的 Element ID。
2. 处理答案并为用户[设置自定义属性](flutter-setting-user-attributes)。

```dart showLineNumbers title="Flutter"
void handleFlowInput(String name, Map<String, dynamic> params) async {
  if (name != 'flow_user_input') return;
  if (params['element_id'] != 'experience') return;

  final optionId = (params['item_ids'] as List).cast<String>().first;

  final builder = AdaptyProfileParametersBuilder();
  // Set the custom attribute 'experience' to the option the user selected
  // (beginner, amateur, or pro).
  builder.setCustomStringAttribute(optionId, 'experience');

  try {
    await Adapty().updateProfile(builder.build());
  } on AdaptyError catch (adaptyError) {
    // handle the error
  }
}
```

3. 为每个自定义属性值[创建一个市场细分](segments)。
4. 创建一个[版位](placements)，并为每个市场细分添加一个[目标受众](audience)。
5. 在你的应用中[展示该版位的流程](flutter-present-paywalls)。
