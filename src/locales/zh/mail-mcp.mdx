Adapty Mail 运行一个 MCP 服务器，AI 助手可以像你在看板中操作一样在你的项目里工作：生成并本地化营销活动、启动流程、设置发送域名、查找用户画像以及查看数据图表。助手使用你自己的 Adapty Mail 账号登录，经你在看板中批准连接后即可获得相应权限。无需 API 密钥。

| | |
|---|---|
| 服务器 URL | `https://api-mail.adapty.io/mcp` |
| 协议 | MCP over Streamable HTTP，OAuth 2.1 登录 |
| 适用于 | Claude（网页版和桌面版）、ChatGPT、Claude Code、Codex CLI、GitHub Copilot CLI、Gemini CLI、Cursor、Windsurf，以及任何支持带 OAuth 的远程 MCP 服务器的客户端 |

:::tip
若要在编码助手中获得最佳效果，请同时添加 [Adapty Mail 技能](mail-skill)。它会自动帮你连接服务器，在向真实用户发送邮件前会主动询问确认，并负责上线后的后续工作：查看结果、A/B 测试以及分析邮件未送达的原因。
:::

## 助手能做什么 \{#what-the-assistant-can-do\}

服务器的工具与看板功能一一对应：

| 功能领域 | 示例 |
|---|---|
| 产品导航 | 查找您的公司和项目，查看缺少哪些设置步骤 |
| 品牌 | 从商店列表构建品牌，审核并编辑 |
| 发件域名 | 添加域名，获取 DNS 记录，检查验证状态，查看域名健康状况 |
| 目标地址 | 创建和更新邮件链接的落地页 |
| 营销活动 | 根据简报生成营销活动，编辑邮件，翻译内容，发送测试邮件 |
| 流程与市场细分 | 创建市场细分，启动或修改流程 |
| A/B 测试 | 创建、启动并结束测试 |
| 用户画像 | 查找用户画像及其历程，取消订阅某用户画像 |
| 数据分析 | 营销活动的数据图表趋势、细分维度拆解、A/B 测试漏斗 |
| 设置 | 发件人名称、回复地址、双重确认订阅、图片上传 |

以下三个引导式工作流可在支持提示词的客户端中作为提示使用。在 Claude Code 中，它们以斜杠命令的形式出现，例如 `/mcp__adaptymail__campaign_to_flow`：

- **campaign_to_flow**：根据简报生成一个推广活动，选择目标版位和市场细分，然后启动流程。
- **campaign_localization**：将已保存的推广活动翻译成更多语言。
- **domain_onboarding**：添加发送域名，发布其 DNS 记录，并完成验证。

某些设置步骤仅在看板中完成：填写[公司地址](mail-get-started#5-add-your-company-address)、配置 [Web 结账](mail-checkout)，以及[开启数据发送](mail-entry-points)。

## 开始之前 \{#before-you-start\}

- **项目成员资格**：您的 Adapty Mail 账号已加入您想操作的项目。助手只能访问您的账号有权限打开的公司和项目。
- **客户端支持**：您的客户端支持通过 OAuth 连接远程 MCP 服务器。

:::warning
助手拥有与您相同的权限，它执行的所有操作都是真实生效的：保存一个流程就会立即开始向真实用户发送邮件。服务器会标记具有破坏性的工具，我们测试过的助手在执行这类操作前都会请求确认。请在批准前仔细阅读助手的操作计划。
:::

## 连接你的助手 \{#connect-your-assistant\}

### Claude（claude.ai 和 Claude 桌面端）

1. 要添加服务器，请打开 **Settings → Connectors**，然后点击 **Add custom connector**。
2. 输入名称（例如 `Adapty Mail`）和 URL `https://api-mail.adapty.io/mcp`。
3. 将 **Authentication** 保持为 **Sign in now**，OAuth 客户端保留默认检测值，然后点击 **Add**。
4. 在打开的 Adapty Mail 标签页中，如有提示请登录，然后点击 **Approve**。

工作区管理员可以为整个组织添加一次连接器。之后每位成员在首次使用时，用自己的 Adapty Mail 账号登录即可。

### ChatGPT

ChatGPT 通过 **Settings** 中的连接器页面添加自定义 MCP 服务器。必须为您的工作区启用开发者模式。

1. 点击 **Create** 添加服务器。
2. 输入名称（例如 `Adapty Mail`）和服务器 URL `https://api-mail.adapty.io/mcp`，**Authentication** 保持选择 **OAuth**。
3. 展开 **Advanced OAuth settings**，在 **Client registration** 下将 **Registration method** 设置为 **Dynamic Client Registration (DCR)**。
4. 接受自定义 MCP 服务器警告，然后点击 **Create**。
5. 当 ChatGPT 提示时，连接服务器。在打开的 Adapty Mail 标签页中，如有需要请先登录，然后点击 **Approve**。

:::important
第 3 步是必须完成的。使用 ChatGPT 的默认注册方式时，连接会因 `invalid_request` 错误而失败，提示找不到 client ID。
:::

### Claude Code

```bash
claude mcp add --transport http --scope user adaptymail https://api-mail.adapty.io/mcp
```

要登录，请在 Claude Code 中运行 `/mcp`，选择 `adaptymail`，然后点击 **Authenticate**。接着在浏览器中登录 Adapty Mail 看板，点击 **Approve**。

### Codex CLI

```bash
codex mcp add adaptymail --url https://api-mail.adapty.io/mcp
codex mcp login adaptymail
```

登录命令会打开浏览器，在那里确认连接。如果想手动配置服务器，请将以下内容添加到 `~/.codex/config.toml`，然后运行登录命令：

```toml
[mcp_servers.adaptymail]
url = "https://api-mail.adapty.io/mcp"
```

### GitHub Copilot CLI

```bash
copilot mcp add --transport http adaptymail https://api-mail.adapty.io/mcp
```

服务器首次连接时，浏览器会自动打开登录页面。

### Gemini CLI

```bash
gemini mcp add --transport http --scope user adaptymail https://api-mail.adapty.io/mcp
```

开启新会话，然后运行 `/mcp auth adaptymail`，并在浏览器中批准连接。

### Cursor、Windsurf 及其他客户端 \{#cursor-windsurf-and-other-clients\}

将服务器添加到客户端的 MCP 配置文件中，例如 `~/.cursor/mcp.json`：

```json
{
  "mcpServers": {
    "adaptymail": {
      "url": "https://api-mail.adapty.io/mcp"
    }
  }
}
```

客户端首次连接时会打开浏览器供你登录。不支持远程服务器 OAuth 的客户端无法连接到 Adapty Mail。

## 批准连接 \{#approve-the-connection\}

每个客户端最终都会停在 Adapty Mail 看板的同一个页面。页面上会显示请求访问权限的应用名称，以及该应用接收访问权限的地址。对于桌面工具，该地址位于你自己的电脑上（`localhost`），因此只批准你自己发起的连接请求。完成后，点击 **Approve**。

连接请求将在 10 分钟后过期。如果页面显示 **This request has expired**，请从客户端重新开始。

## 开始使用 \{#start-working\}

请助手列出您的项目，然后告知您想处理的那个项目。以下是一些可以尝试的请求：

- "查看我的项目的用户引导状态，并告诉我缺少什么。"
- "为试用期已过期的用户生成一个赢回优惠活动，使用英文，并展示第一封邮件。"
- "将活动 Trial expired 翻译成德语和法语。"
- "添加 `mail.example.com` 作为发送域，并给我 DNS 记录。"
- "对比最近 30 天内我的所有上线活动的打开率和点击率。"

## 断开连接 \{#disconnect\}

要断开连接，请在客户端设置中移除连接器。在 Claude 中，位于 **Settings → Connectors**；在 ChatGPT 中，位于连接器页面；在 Claude Code 中，运行 `claude mcp remove adaptymail`。

客户端的访问令牌将在一小时内过期。刷新令牌在客户端断开连接时会被撤销；未使用的刷新令牌将在 90 天后过期。如需重新连接，请再次添加服务器并批准连接。

## 故障排除 \{#troubleshooting\}

| 问题 | 解决方案 |
|---|---|
| ChatGPT 报 `invalid_request` 错误，提示"Client ID ... not found" | 在连接器设置中，将 **Registration method** 设置为 **Dynamic Client Registration (DCR)**。详见 [ChatGPT](#chatgpt)。 |
| 看板提示连接请求已过期 | 请从客户端重新发起连接，并在 10 分钟内完成授权。 |
| 助手提示找不到该项目 | 您的账号不是该项目的成员，请联系公司所有者申请访问权限。 |
| 助手已退出登录 | 长时间空闲或主动断开连接后访问权限会过期，请从客户端重新连接。 |
| 客户端未显示任何工具 | 客户端在未登录的情况下建立了连接，请执行登录步骤，例如在 Claude Code 中运行 `/mcp`。 |
