## 为什么使用示例应用？ \{#why-use-sample-apps\}

- **快速集成：** 在真实应用中了解 Adapty SDK 的工作方式。
- **最佳实践：** 遵循推荐的实现模式。
- **调试与测试：** 在将 Adapty 集成到自己的项目之前，使用示例应用进行排查和实验。

## 可用示例应用 \{#available-sample-apps\}

- [iOS (Swift)](https://github.com/adaptyteam/AdaptySDK-iOS/tree/master/Examples)
- [Android (Kotlin)](https://github.com/adaptyteam/AdaptySDK-Android/tree/master/app)
- [React Native（基础示例）](https://github.com/adaptyteam/AdaptySDK-React-Native/tree/master/examples/BasicExample) — 展示 SDK 核心功能的最简配置。
- [React Native（Expo Go 和 Expo Web）](https://github.com/adaptyteam/AdaptySDK-React-Native/tree/master/examples/ExpoGoWebMock) — 上手最快的示例：直接在浏览器中以模拟数据运行，无需 Adapty API key，涵盖自定义付费墙以及 Flow & 付费墙编辑工具。
- [React Native（Focus Journal，一个 Expo 应用）](https://github.com/adaptyteam/AdaptySDK-React-Native/tree/master/examples/FocusJournalExpo) — 一款通过 Flow & 付费墙编辑工具付费墙锁定高级功能的应用，附带[视频教程](https://www.youtube.com/watch?v=TtCJswpt2ms)。
- [React Native（Adapty DevTools）](https://github.com/adaptyteam/AdaptySDK-React-Native/tree/master/examples/AdaptyDevtools) — 用于处理复杂场景的开发与问题排查工具。同一应用也提供[使用 Swift Package Manager 而非 CocoaPods 的版本](https://github.com/adaptyteam/AdaptySDK-React-Native/tree/master/examples/AdaptyDevtoolsSpm)。
- [Flutter (Dart)](https://github.com/adaptyteam/AdaptySDK-Flutter/tree/master/example)
- [Unity (C#)](https://github.com/adaptyteam/AdaptySDK-Unity/tree/main/Assets)
- [Kotlin Multiplatform](https://github.com/adaptyteam/AdaptySDK-KMP/tree/main/example)
- [Capacitor (React)](https://github.com/adaptyteam/AdaptySDK-Capacitor/tree/master/examples/basic-react-example)
- [Capacitor (Vue.js)](https://github.com/adaptyteam/AdaptySDK-Capacitor/tree/master/examples/basic-vue-example)
- [Capacitor (Angular)](https://github.com/adaptyteam/AdaptySDK-Capacitor/tree/master/examples/basic-angular-example)
- [Capacitor（高级开发工具）](https://github.com/adaptyteam/AdaptySDK-Capacitor/tree/master/examples/adapty-devtools)
