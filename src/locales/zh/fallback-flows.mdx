为了保持流畅的用户体验，为你的[流程](adapty-flow-builder)设置**备用版本**非常重要。

当您的应用请求流程时，Adapty SDK 会联系我们的服务器获取其配置。如果 SDK 无法从主 Adapty API 获取流程（网络问题、服务器故障），它会回退到其他来源：

- 如果用户已经查看过该流程，SDK 将使用缓存副本。
- 如果主 Adapty API 无响应，SDK 将从备用 Adapty 服务器请求流程。
- 如果两者均不可用，SDK 将加载打包在应用内的备用配置文件。

:::important
备用服务器和备用文件仅服务于 **All Users** 目标受众，忽略所有市场细分。如果你按平台拆分目标受众，请在 All Users 流程中使用同时包含 App Store 和 Google Play ID 的产品。否则，备用流程将没有适用于其他商店用户的产品。
:::

Adapty 会自动生成这些备用文件。流程备用包与付费墙共享——每个平台一个 JSON 文件，同时包含两者的备用变体。SDK 会按需读取对应的部分。

:::important
流程备用方案包含在 **Adapty SDK 4.0+** 版本中。如果在下载对话框中选择了更早的 SDK 版本，文件将只包含付费墙和用户引导的变体，不包含流程内容。在依赖流程备用方案之前，请确保你的应用使用的是支持流程的 SDK 版本。
:::

## 开始之前 \{#before-you-start\}

1. 在 Flow & Paywall Builder 中创建一个 [流程](adapty-flow-builder)。
2. 为该流程[创建一个版位](create-placement)。

## 下载备用付费墙文件 \{#download-the-fallback-file\}

1. 打开 **[Placements](https://app.adapty.io/placements)** 页面。
2. 点击右上角的 **Fallbacks** 按钮。
3. 从下拉菜单中选择目标平台。
4. 选择与应用中 Adapty SDK 版本匹配的选项，例如 **Adapty SDK v4.4.0 and higher**。

浏览器将按平台下载对应的 JSON 文件，例如 `ios_4_0_0_fallback.json`。

:::tip
如需通过终端下载文件，请使用 [Developer CLI](developer-cli)。传入应用所使用的 Adapty SDK 版本：

```bash
adapty fallbacks get --app <app-id> --platform ios --sdk-version <sdk-version> --output ios_fallback.json
```

每个应用商店运行一次，使用 `--platform ios` 或 `--platform android`。详见 [`adapty fallbacks get`](developer-cli-fallbacks) 的参数说明。
:::

## 下载后的操作 \{#after-the-download\}

将文件添加到你的应用代码中，然后参照对应平台的配置指南。加载付费墙备用资源的 API 同样适用于流程备用资源，前提是你的应用已升级到支持流程功能的 SDK 版本：

- [iOS](ios-use-fallback-paywalls)
- [Android](android-use-fallback-paywalls)
- [React Native](react-native-use-fallback-paywalls)
- [Flutter](flutter-use-fallback-paywalls)
- [Unity](unity-use-fallback-paywalls)
- [Kotlin Multiplatform](kmp-use-fallback-paywalls)
- [Capacitor](capacitor-use-fallback-paywalls)

## 限制 \{#limitations\}

备用流程是硬编码并本地存储的，因此不具备实时流程的完整动态能力：

- **每个版位仅限一个目标受众。** 如果一个版位有多个[目标受众](audience)，备用文件只使用 **All users** 目标受众。
- **不含实时 A/B 测试。** 如果 **All users** 目标受众正在运行 A/B 测试，文件会包含该测试的每个实验变体及其流量权重。SDK 会按权重将用户分配到各实验变体。如需在停止测试后更新备用文件，请重新下载该文件并将其加入新的应用版本发布。
- **不含跨版位 A/B 测试。** 备用文件不包含任何[跨版位 A/B 测试](ab-test-types)，即便该测试运行在 **All users** 目标受众上也不例外。对于参与此类测试的版位，文件仅包含该版位的常规 **All users** 内容：即其流程或常规 A/B 测试。
- **不支持远程更新。** 更新备用文件需要发布新的应用版本。如需在运行时通过远程配置进行更新，请改为通过实时流程推送。
