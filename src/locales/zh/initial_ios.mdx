将您在 App Store 上的应用连接到 Adapty，以便 Adapty 能够验证购买、接收订阅事件并从商店读取您的产品信息。

每个应用商店需单独接入，Adapty 仅对已接入的商店进行购买验证。如果你的应用也在 Google Play 上架，请[同样接入 Google Play](initial-android)——两者相互独立，完成其中一个不会简化另一个的流程。

整个配置涉及 App Store Connect 和 Adapty 看板，大约需要 30 分钟。

## 初始集成指南 \{#guide-for-the-initial-integration\}

- [ ] 在 Adapty 注册账号并填写移动应用名称和类别后，我们会在 Adapty 平台上为你完成应用配置。
- [ ] 在 Adapty 看板和 App Store Connect 中[配置 App Store 集成](app-store-connection-configuration)。
- [ ] 为你使用的框架安装 Adapty SDK：
  - [ ] [为原生 iOS 安装 Adapty SDK](sdk-installation-ios)
  - [ ] [为 React Native 安装 Adapty SDK](sdk-installation-reactnative)
  - [ ] [为 Flutter 安装 Adapty SDK](sdk-installation-flutter)
  - [ ] [为 Unity 安装 Adapty SDK](sdk-installation-unity)
  - [ ] [为 Kotlin Multiplatform 安装 Adapty SDK](sdk-installation-kotlin-multiplatform)
- [ ] 构建应用并在沙盒模式下运行。

初始集成完成后，您[可以开始使用 Adapty 的功能](product)。

请注意，要在移动应用中展示付费墙和产品，并使数据分析正常运行，您需要修改应用代码。具体来说，您至少需要[展示付费墙](ios-quickstart-paywalls)，如果使用的付费墙不是通过付费墙编辑工具创建的，还需要在应用内[处理购买流程](making-purchases)。

:::danger
发布应用前，请先检查发布清单

在发布应用之前，请务必仔细查阅[发布清单](release-checklist)。这将确保您在集成 Adapty SDK 的应用上线前已完成所有必要步骤。
:::
