Adapty Mail 将您的 Adapty 用户数据转化为 AI 生成的邮件序列，帮助将试用用户转化为付费订阅者。它直接使用您 Adapty 项目中已有的用户画像数据来构建、发送和归因营销活动——无需额外的电子邮件平台。

## 为什么选择 Adapty Mail？ \{#why-adapty-mail\}

发送精准邮件营销活动需要文案、设计、发送基础设施和收入归因，每一项都是独立的难题。

Adapty Mail 一站式解决所有问题。系统会根据你的应用商店 URL 及其他补充来源自动构建品牌档案，并在 2 分钟内生成完整的邮件序列——从你自己的域名发出，附带个性化结账链接和购买归因。

## 工作原理 \{#how-it-works\}

1. **收集邮件地址**：您的应用通过 SDK 将用户邮件地址和 `customer_user_id` 传递给 Adapty。Adapty Mail 使用这些数据识别收件人，并将收入归因到促成每次购买的具体邮件。您也可以通过服务端使用 [Adapty Mail API](mail-send-data-via-api) 发送这些数据。
2. **搭建 Web 付费墙**：每封邮件都会链接到该结账页面。
3. **生成邮件序列**：AI 根据您的品牌档案生成 1–15 封邮件，包含文案、设计、主视觉图片以及与您应用类别和品牌风格匹配的个性化结账链接。
4. **启动流程**：选择触发条件（从未购买、续订已取消、账单问题、订阅已到期或已退款）和市场细分，然后关联您的活动。邮件将自动开始发送，邮件驱动的购买收入将归因到促成转化的具体邮件。

## 要求 \{#requirements\}

使用 Adapty Mail，您需要满足以下条件：

- 一个 Adapty 账户
- 在您的应用中配置好邮件收集功能——请参阅[收集用户邮件](mail-collect-emails)
- 在 Adapty SDK 中配置好 `customer_user_id`
- 一个您拥有控制权的域名，并可访问其 DNS 设置
- 一个网页支付提供商（Stripe、Paddle 或 PayPal）
