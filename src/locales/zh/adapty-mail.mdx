Adapty Mail 将您的 Adapty 用户数据转化为 AI 生成的邮件序列，帮助将试用用户转化为付费订阅者。它直接使用您 Adapty 项目中已有的用户画像数据来构建、发送和归因营销活动——无需额外的电子邮件平台。

## 为什么选择 Adapty Mail？ \{#why-adapty-mail\}

发送精准邮件营销活动需要文案、设计、发送基础设施和收入归因，每一项都是独立的难题。

Adapty Mail 一站式解决所有问题。系统会根据你的应用商店 URL 及其他补充来源自动构建品牌档案，并在 2 分钟内生成完整的邮件序列——从你自己的域名发出，附带个性化结账链接和购买归因。

## 工作原理 \{#how-it-works\}

1. **收集邮箱**：您的应用通过 SDK 将用户邮箱和 `customer_user_id` 值传递给 Adapty。Adapty Mail 使用这些数据来识别收件人，并将收入归因到促成购买的具体邮件。您也可以通过 [Adapty Mail API](mail-send-data-via-api) 从服务器发送此数据。当同一用户从多个来源进入 Adapty Mail 时，Adapty Mail 会将其合并为单一用户画像。合并优先级依次为：发送系统自身 ID、`customer_user_id`，最后是邮箱地址，确保该用户只收到一套序列，而非每个来源各一套。
2. **构建网页付费墙**：即每封邮件所链接的结账页面。
3. **生成序列**：AI 根据您的品牌资料生成 1–15 封邮件，包含文案、设计、主图，以及根据您的应用类别和品牌风格量身定制的个性化结账链接。
4. **启动流程**：选择一个触发条件（从未购买、已取消续订、账单问题、订阅到期或已退款）和一个市场细分，然后关联您的营销活动。邮件将自动开始发送，由邮件驱动的购买收入会归因到促成转化的具体邮件。

## 要求 \{#requirements\}

使用 Adapty Mail，您需要满足以下条件：

- 一个 Adapty 账户
- 在您的应用中配置好邮件收集功能——请参阅[收集用户邮件](mail-collect-emails)
- 在 Adapty SDK 中配置好 `customer_user_id`
- 一个您拥有控制权的域名，并可访问其 DNS 设置
- 一个网页支付提供商（Stripe、Paddle 或 PayPal）

## 入门指南 \{#get-started\}

按照 [Adapty Mail 入门指南](mail-get-started) 完成设置并启动第一个营销活动。设置完成后，在正式面向真实用户上线前，请先[测试你的流程](mail-testing)。
