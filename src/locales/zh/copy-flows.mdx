复制流程并修改部分元素，以针对特定[目标受众](add-audience-paywall-ab-test)、[A/B 测试](ab-tests)或应用版本进行调整。复制单个屏幕以便在其他流程中复用。

<ZoomImage id="flow-copy-archive.webp" width="700px" alt="Flows list with the context menu open, showing Metrics, Edit, Copy, and Archive" />

## 复制流程 \{#copy-a-flow\}

1. 打开 [**Flows**](filter-flows) 页面。
2. 在流程所在行，打开右键菜单 <Inline id="context.svg" alt="Context menu" /> 并选择 **Copy**。已归档的流程无法复制。
3. 流程编辑工具会将副本作为新的 **Draft** 打开，名称为原流程名称加上 `_copy` 后缀。

   副本包含流程本身存储的所有内容：

- **屏幕与元素**：每个屏幕的布局、元素和交互。
   - **已分配产品**：产品卡片与商店产品之间的关联关系。
   - **设计**：已保存的颜色和文字样式、背景及深色模式值。
   - **自定义字体**：同一应用内的所有流程共享相同的[自定义字体](using-custom-fonts-in-flow-builder)，因此副本会保留这些字体。
   - **变量**：[自定义变量、元素变量和产品变量](onboarding-variables)。
   - **本地化**：每个语言区域及其已翻译的文本和媒体资源。
   - **远程配置**：每个语言区域的 [JSON 数据](customize-flow-with-remote-config)。

流程外存储的任何内容都不会随之复制：

    - **版位**：副本不属于任何[版位](placements)。
    - **A/B 测试**：副本不加入任何 [A/B 测试](ab-tests)。
    - **数据图表**：副本从空白的[分析历史](flow-metrics)开始。

4. 可选：[重命名流程](paywall-builder-templates#create-flow)。Adapty 允许重复的流程名称——使用唯一名称有助于避免混淆。
5. 保存[或发布](builder-save-publish)副本。副本在发布前始终处于 **Draft** 状态。
6. 将副本添加到[版位](placements)以向用户展示。

## 在流程间复制屏幕 \{#copy-screens-between-flows\}

要将屏幕移动到另一个流程，请先[**复制**](paywall-layout-and-products#screen-actions)到剪贴板，然后打开目标流程，再粘贴到 **Screens** 面板中。剪贴板支持在不同流程甚至不同浏览器之间传输屏幕。

Adapty 不会复制屏幕在流程层级所引用的内容。粘贴后的屏幕可能不完整，并可能包含失效引用。含有失效引用的流程可能[无法发布](builder-save-publish#troubleshooting)。

粘贴后，请逐一检查以下内容：

- **变量**：文本绑定、条件和操作将无法解析。请用目标流程中的变量替换相关引用。
- **已保存的样式**：元素会丢失颜色和文字样式。请从目标流程中应用一个样式。
- **导航操作**：**导航到屏幕**操作会丢失目标。请将每个操作指向目标流程中的某个屏幕。
- **本地化**：只有两个流程共有的语言区域才会保留翻译。其他语言区域的用户将看到目标流程的默认语言。
- **产品和自定义字体**：同一应用中的所有流程可以共享相同的产品和字体。从同一应用的不同流程粘贴的屏幕会保留其产品和字体。但若从其他应用粘贴屏幕，则会导致产品和字体引用失效。

Replace each broken reference with a working equivalent in the destination flow.
