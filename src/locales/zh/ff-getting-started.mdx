借助 Adapty，你可以在移动应用用户旅程的不同节点（如用户引导、设置页等）创建并运行付费墙和 A/B 测试。这些节点称为[版位](placements)。应用中的一个版位可以同时管理多个付费墙或 [A/B 测试](ab-tests)，每个付费墙或 A/B 测试面向特定的用户群体，即[目标受众](audience)。此外，你还可以对付费墙进行灵活实验，随时将一个付费墙替换为另一个，无需发布新版本。唯一需要硬编码到移动应用中的，只有版位 ID。

Adapty 库会使用 Adapty 看板中的最新产品数据持续更新你的付费墙。它负责[获取产品数据](ff-action-flow)、[将数据展示在付费墙上](ff-add-variables-to-paywalls)、[处理购买流程](ff-make-purchase)，以及[检查用户的访问等级](ff-check-subscription-status)以判断是否应向其开放付费内容。

要开始使用，只需将 [Adapty 库添加](ff-getting-started#add-the-adapty-library-as-a-dependency)到你的 FlutterFlow 项目中，并按以下方式[初始化](ff-getting-started#initiate-adapty-plugin)。

:::warning

在开始之前，请注意以下限制：

- 适用于 FlutterFlow 的 Adapty 库不支持 Web 应用。请避免使用它编译 Web 应用。
- 适用于 FlutterFlow 的 Adapty 库不支持使用 Adapty 付费墙编辑工具创建的付费墙。在使用 Adapty 启用购买功能之前，你需要在 FlutterFlow 中自行设计付费墙。

:::

## 初始化 Adapty 插件 \{#initiate-adapty-plugin\}

要让 Adapty 看板识别你的应用，你需要在 FlutterFlow 中提供一个专用密钥。

1. 在你的 FlutterFlow 项目中，从左侧菜单进入 **Settings and Integrations > Permissions**。
2. 在打开的 **Permissions** 窗口中，点击 **Add Permission** 按钮。
3. 在 **iOS Permission Key** 和 **Android Permission Key** 字段中，粘贴 `AdaptyPublicSdkKey`。
4. 在 **Permission Message** 中，从 Adapty 看板的 [**App Settings** -> **General** tab](https://app.adapty.io/settings/general) 复制 **Public SDK key**。每个应用都有自己的 SDK key，如果你有多个应用，请确保复制的是正确的那个。
