下载应用在无法连接 Adapty 时所打包的[备用文件](fallback-flows)。该文件与 **Placements** 页面上 **Fallbacks** 下载的文件相同。

## adapty fallbacks get

```bash
adapty fallbacks get --app <app-id> --platform ios --sdk-version 4.4.0 --output ios_fallback.json
```

| 参数 | 是否必填 | 描述 |
|---|---|---|
| `--app` | 是 | App ID（UUID） |
| `--platform` | 是 | App Store 使用 `ios`，Google Play 使用 `android`。macOS 和 visionOS 应用使用 `ios` 文件。 |
| `--sdk-version` | 是 | 应用所使用的 Adapty SDK 版本，格式为 `X.Y.Z`。Flutter、React Native、Unity、Kotlin Multiplatform 和 Capacitor 请传入 Adapty 插件版本号。 |
| `--output` | 否 | 指定写入的文件路径，父目录会自动创建。不指定时，内容输出到标准输出。 |

每个应用的所有版位只需一个文件即可覆盖。要同时支持两个应用商店，请分别使用 `--platform ios` 和 `--platform android` 各运行一次该命令。

该文件仅包含已上线的版位，因此请先发布你的流程并激活对应版位，再下载文件。每次修改版位或升级 SDK 后，都需要重新下载，因为该文件只是一个快照。

Adapty 会根据 `--sdk-version` 自动选择文件格式。SDK 只接受与其构建版本匹配的格式，启动时会拒绝任何其他格式的文件，且不会产生构建错误：

| `--sdk-version` | 文件格式 |
|---|---|
| 4.4.0 及更高版本 | 12 |
| 4.1.x – 4.3.x | 11 |
| 4.0.x | 10 |
| 3.12.x 及更高 3.x 版本 | 9 |
| 3.8.x – 3.11.x | 8 |
| 3.4.x – 3.7.x | 7 |
| 3.0.x – 3.3.x | 6 |
| 3.0 以下 | 5 |

付费墙版位在所有格式中均可用。流程版位仅在 SDK 4.0 及更高版本的文件中支持。

使用 `--output` 时，CLI 只在整个下载成功后才写入文件，因此即使运行失败，之前的文件也会保留。不使用该选项时，标准输出只传输文件内容，所有错误信息则输出到标准错误流。直接使用 `> file` 重定向会在请求开始前清空文件，所以请使用 `--output`。

Adapty 在响应前会构建整个文件，大型应用可能需要几分钟。该命令只发送一次请求，不会重试。每个应用的所有令牌每小时最多可下载该文件 30 次；超出后命令会失败，并显示限速错误，提示需要等待多长时间。请仅在发布构建时下载该文件，而非每次提交都执行。

| 退出代码 | 含义 |
|---|---|
| `0` | 文件已写入 |
| `1` | 文件无法写入，原有文件保持不变 |
| `2` | 无效的标志值 |
| `3` | 无令牌，或访问被拒绝 |
| `4` | API 错误，包括速率限制，或返回内容不是备用付费墙文件 |
| `5` | 无法连接到 Adapty，300 秒内未响应，或下载中断 |
