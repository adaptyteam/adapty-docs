作为顶尖的用户互动解决方案之一，[Braze](https://www.braze.com/) 提供了丰富的推送通知、电子邮件、短信及应用内消息工具。通过将 Adapty 与 Braze 集成，您可以在一处轻松查看所有订阅事件，并基于这些事件触发自动化通信流程。

Adapty 提供了一套完整的数据，让你可以在一个地方追踪来自所有应用商店的[订阅事件](events)，并用于更新 Braze 中的用户画像。借助 Adapty，你可以轻松了解订阅用户的行为偏好，并据此以精准有效的方式与他们沟通。因此，通过此集成，你可以在 Braze 看板中追踪订阅事件，并将其与你的[获客活动](https://www.braze.com/product/journey-orchestration)进行关联。

Adapty 会将订阅事件、用户属性和购买记录发送至 Braze，让你在完成以下简单集成后，即可使用 Braze 推送通知与客户建立精准沟通。

## 如何设置 Braze 集成 \{#how-to-set-up-braze-integration\}

要集成 Braze，请前往 [Integrations -> Braze](https://app.adapty.io/integrations/braze)，打开开关并填写相关字段。

## 事件、用户属性与购买记录 \{#events-user-attributes-and-purchases\}

在凭据设置下方，有三组事件可供你从 Adapty 发送到 Braze。直接开启你需要的事件即可。你也可以根据需要修改事件名称，以便发送到 Braze。查看 Adapty 提供的完整事件列表，请点击[这里](events)：

Adapty 将通过服务端对服务端集成，把订阅事件和用户属性发送到 Braze，让你可以在 Braze 看板中查看这些数据，并据此配置营销活动。

对于包含收入的事件（例如试用转化和续订），Adapty 会将这些信息作为购买事件发送给 Braze。

[在此](messaging#event-properties)可查看发送到 Braze 的事件属性完整规格说明。

:::note
实用的用户属性

Adapty 默认会为 Braze 集成发送一些用户属性。您可以参考下方提供的属性列表，根据需求选择最适合的属性。
:::

| 用户属性 | 类型 | 值 |
|--------------|----|-----|
| `adapty_customer_user_id` | String | 包含客户定义的用户唯一标识符的值。可在 Adapty [看板](profiles-crm)和 Braze 中找到。 |
| `adapty_profile_id` | String | 包含 Adapty 用户画像 ID 的唯一标识符值，可在 Adapty [看板](profiles-crm)中找到。 |
| `environment` | String | <p>表示用户当前处于沙盒还是生产环境。</p><p></p><p>值为 `Sandbox` 或 `Production`</p> |
| `store` | String | <p>包含用于完成购买的商店名称。</p><p></p><p>可能的值：</p><p>`app_store` 或 `play_store`。</p> |
| `vendor_product_id` | String | <p>包含 Apple/Google 商店中产品 ID 的值。</p><p></p><p>例如：org.locals.12345</p> |
| `subscription_expires_at` | String | <p>包含最新订阅的到期日期。</p><p></p><p>值格式为：</p><p>YYYY-MM-DDTHH:mm:ss.SSS+TZ</p><p>例如：2023-02-15T17:22:03.000+0000</p> |
| `active_subscription` | String | 在任何购买/续订事件时值将设为 `true`，若订阅已到期则设为 `false`。 |
| `period_type` | String | <p>表示最近一次购买或续订的周期类型。</p><p></p><p>可能的值为：</p><p>`trial` 表示试用期，`normal` 表示其他情况。</p> |

所有浮点值将被四舍五入为整数，字符串保持不变。

除了预定义的标签列表外，还可以使用标签发送[自定义属性](segments#custom-attributes)。这为标签中包含的数据类型提供了更大的灵活性，有助于追踪与产品或服务相关的特定信息。如果用户在[集成页面](https://app.adapty.io/integrations/braze)勾选了 **Send user attributes** 复选框，所有自定义用户属性将自动发送到 Braze。

## SDK 配置 \{#sdk-configuration\}

要在 Adapty 和 Braze 中关联用户画像，需要使用与 Adapty 相同的 customer user ID 配置 Braze SDK，或调用其 `.changeUser()` 方法：

<Tabs groupId="current-os" queryString>
<TabItem value="swift" label="iOS (Swift)" default>
```swift showLineNumbers
let braze = Braze(configuration: configuration)
braze.changeUser(userId: "adapty_customer_user_id")
```
</TabItem>
<TabItem value="kotlin" label="Android (Kotlin)" default>
```kotlin showLineNumbers
Braze.getInstance(context).changeUser("adapty_customer_user_id")
```
</TabItem>
</Tabs>
