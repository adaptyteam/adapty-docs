[虚拟货币](virtual-currencies)在用户购买产品或续订订阅时向其授予积分。virtual-currencies 技能可让你在 AI 工具中管理这些货币。你的智能体可以列出所有货币、查看每个关联产品授予的积分数量、创建货币，以及添加、修改或删除关联产品。它还能读取用户的积分交易记录和余额，从而帮你分析该用户余额的来源。该技能通过 [`adapty virtual-currencies` CLI 命令](developer-cli-virtual-currencies)或 [Adapty MCP 服务器](adapty-mcp)运行。

:::note
该技能在每次变更前会先向你确认。它会展示具体变更内容：每个关联产品变更前后的积分数量，或新货币及其对应产品。只有在你确认后才会执行变更。新金额从下次购买或续订时生效：当前订阅用户将在下次续订时获得新金额。
:::

## 开始之前 \{#before-you-start\}

- **Adapty 中的产品**：货币通过其在 Adapty 中关联的[产品](create-product)来发放积分。
- **已连接到 Adapty 账户的 AI 工具**：该技能通过 [Adapty MCP server](adapty-mcp) 或 [Adapty CLI](developer-cli) 运行。在 Claude Code 和 Codex 中，插件会自动添加 MCP server，你只需登录即可。该技能会检测你的 AI 工具配置了哪一种并加以使用。若两者都有，则优先使用 MCP server；若都没有，该技能会询问你要设置哪一种。

## 技能在每次更改前会询问什么 \{#what-the-skill-asks-before-each-change\}

技能会在每次更改前读取当前内容，并向你展示将要进行的改动。只有你在技能提出问题后的回答才算数。之前泛泛的"继续吧"不算。如果你回答否，技能不会做任何修改。

| 变更 | 技能会告知您的内容 |
|---|---|
| 创建货币 | 代码、名称及其关联产品。货币创建后不可删除，代码也不可修改，且每个应用最多可创建 20 种货币。余额归属于单个用户画像，因此若用户未登录，重新安装应用或更换设备后将丢失其积分。 |
| 添加或修改关联产品 | 每个发生变更的产品：新增产品，或每次购买/每个订阅周期中变更前后的积分数量。当前订阅者将在下次续费时获得新的积分数量。其他关联产品保持不变。 |
| 移除关联产品 | 该产品及其当前积分数量。该产品的购买行为将不再授予此货币的积分，且不会有任何交易记录记录此类不授予积分的购买。已授予的积分保持不变。 |
| 修改名称或描述 | 修改前后的名称或描述。其余内容保持不变。 |

如果在技能读取与写入之间，看板或其他工具修改了货币，技能不会覆盖该变更。Adapty 会拒绝写入；或者对于通过 CLI 修改名称的情况，技能在写入前的最后一次读取会发现变更。什么都不会改变。技能会再次展示该变更，并等待你重新确认。

如果 Adapty 未响应某次变更，技能不会立即重新发送。它会先读取当前货币状态，并告知你已保存的内容。对于仍未生效的部分变更，技能会展示新的确认问题，并等待你重新确认。

## 技能如何解释余额 \{#how-the-skill-explains-a-balance\}

询问某个用户为何拥有某笔余额，技能会通过用户画像 ID 或你自己的用户 ID 读取该用户的积分交易记录和余额。它会告诉你哪些购买、消费和赠送操作产生了这笔余额，以及哪些积分将在何时过期。看板中该[用户的用户画像](virtual-currency-balance)显示的是相同的数据。

如果用户在重新安装、更换设备或重新登录后积分消失，该技能会要求你提供用户之前的用户画像并读取其余额。余额归属于某一用户画像，不会迁移到其他画像，因此积分会保留在之前的用户画像中。要让每位用户在所有设备上都能访问自己的余额，请[识别你的用户](virtual-currency-balance#balances-profiles-and-devices)。

## 限制 \{#limits\}

- **不可删除货币**：无论是在技能中还是在看板中，均无法删除货币或修改其代码。
- **不可修改余额**：技能不会增减余额。请通过服务端 API 在服务器上消耗或发放积分：参见[虚拟货币快速入门](virtual-currency-quickstart)和[发放初始余额](grant-initial-balance)。如需调整单个用户的余额，请使用[看板](virtual-currency-balance#adjust-a-balance-manually)。
- **不可无人值守地执行变更**：在定时任务或脚本中，若无人应答，技能仅执行读取操作。如需变更，它会说明该变更的具体影响，并给出供你手动执行的命令。

要自行运行命令（不使用技能），请参阅[通过 CLI 管理虚拟货币](developer-cli-virtual-currencies)。
