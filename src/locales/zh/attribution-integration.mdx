Adapty 可以与第三方服务交换信息，将订阅事件归因到具体的营销活动。通过这种交换，您可以：

* 了解哪些营销策略带来了最多的收益
* 按归因筛选 Adapty [订阅数据图表](charts)
* 借助第三方服务的能力分析 Adapty 订阅数据

您可以通过以下两种方式进行配置：

* [集成归因](#integrated-attribution) 只需少量配置，即可让 Adapty 与 9 个主流平台交换数据。
* [手动归因](#manual-attribution) 需要你自行从第三方服务 API 获取归因数据，再发送给 Adapty。

:::tip
开启 [Adapty Attribution](user-acquisition)，全面了解你应用的经济状况。

Adapty Attribution 是一个配置简单的 Web 看板，可以整合来自不同来源的数据，帮助你发现高效的用户获取策略。
:::

:::warning
保持数据整洁：避免事件重复和归因冲突。请参阅 **[避免数据问题](#prevent-data-issues)** 部分中的建议，确保新数据源不会污染您的分析数据。
:::

## 集成归因 \{#integrated-attribution\}

Adapty 提供与 9 个主流服务的开箱即用归因集成。这些平台可以自动从 Adapty 接收[订阅数据](events)，处理每笔购买，并返回相应的归因信息。

每个平台的工作流程各有不同，但操作步骤同样简单：

1. **设置自动数据共享。** 授权 Adapty 与您选择的平台进行通信。
2. **集成 Adapty SDK。** 某些平台需要额外的代码来设置归因数据。
3. **禁用其他事件共享服务和归因来源**，以避免[事件重复](#avoid-event-duplication)和[数据冲突](#select-a-single-attribution-source)。

请阅读对应平台的指南，了解详细的集成说明：

- [Adjust](adjust)
- [Airbridge](airbridge)
- [Apple Search Ads](apple-search-ads)
- [AppsFlyer](appsflyer)
- [Asapty](asapty)
- [Branch](branch)
- [Facebook Ads](facebook-ads)
- [Singular](singular)
- [Tenjin](tenjin)

Adjust、AppsFlyer、Branch 和 Singular 还可以接收[合成事件](events#synthetic-events)——这是一个信号，表明试用或订阅在最初几天内持续有效。对于 Meta 和 TikTok 广告系列，Adapty Attribution 提供[合格试用](ua-facebook#qualified-trial)功能。

:::note
如果您希望 Adapty 扩展此列表，请[提交功能请求](https://adapty.featurebase.app/en?b=6979f233ebd3cffd4f425ba0)并说明您对特定服务的需求。
:::

## 手动归因 \{#manual-attribution\}

如果 Adapty 尚未与你所使用的服务提供[集成归因](#integrated-attribution)，则需要自行编写代码与归因来源交换数据。

1. **从归因服务获取数据**。使用该服务的 API 请求归因数据。
2. **根据获取到的归因数据创建一个字典。**

    该字典可包含以下键：

    - `status`（`organic`、`non-organic` 或 `unknown`）
    - `channel`
    - `campaign`
    - `ad_group`
    - `ad_set`
    - `creative`

:::important
    * 所有键均为可选。
    * Adapty 会忽略不在列表中的键。
    * 每个键的值最多可包含 50 个字符。
    :::

    **示例**：

**参数：**

- `attribution`（必填）：包含归因数据的字典。
   - `provider`（必填；在 SDK 4.1 版本之前名为 `source`）：归因提供商。如果您的归因提供商不支持[集成归因](#integrated-attribution)，请使用自定义值——iOS 上为 `.custom`，Android 和 Kotlin Multiplatform 上为 `AdaptyExternalAttributionProvider.CUSTOM`，Unity 上为 `AdaptyExternalAttributionProvider.Custom`，Flutter 上为 `AdaptyExternalAttributionProvider.custom`，Capacitor 和 React Native 上为字符串 `'custom'`。在 SDK 4.1 版本之前，请传入字符串 `"custom"`。

## 防止数据问题 \{#prevent-data-issues\}

### 选择单一归因来源 \{#select-a-single-attribution-source\}

不要同时启用多个平台的归因集成。Adapty 每次只能接受一个归因来源，且一旦保存了归因值，便无法覆盖。

如果你启用了多个归因来源，Adapty 会选择数据量最多的来源——但这不一定是最准确的数据。

例如，非自然流量的 [Apple Search Ads 归因](apple-search-ads) 在 iOS 上始终具有最高优先级。如需关闭 Apple Search Ads 归因，请前往 [**App Settings** -> **Apple Search Ads** 选项卡](https://app.adapty.io/settings/apple-search-ads)，并关闭 **Receive Apple Search Ads attribution** 开关。

### 避免事件重复 \{#avoid-event-duplication\}

如果您使用 Adapty 将实时订阅数据共享给归因服务，**您需要禁用**其他具有相同用途的服务。如果您将 Facebook 账号连接到了 AppsFlyer、Adjust 或 Branch，除非您主动退出，否则这些事件将自动转发到这些服务。

重复事件会干扰您的分析，使数据难以解读。配置好 Adapty 事件共享后，请将第三方事件转发功能**关闭**。
