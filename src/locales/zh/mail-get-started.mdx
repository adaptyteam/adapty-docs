本指南将帮助你设置 Adapty Mail 并启动第一个电子邮件流程。

设置分为九个步骤：

1. [选择账户类型](#1-choose-your-account-type)
2. [连接数据](#2-connect-your-data)
3. [设置品牌](#3-set-up-your-brand)
4. [设置发送域名](#4-set-up-your-sending-domain)
5. [添加公司地址](#5-add-your-company-address)
6. [创建网页付费墙](#6-create-a-web-paywall)
7. [用 AI 生成营销活动](#7-generate-a-campaign-with-ai)
8. [启动流程](#8-launch-a-flow)
9. [开始发送](#9-start-sending)

Adapty Mail 会跟踪你在引导清单中的进度，一旦所有步骤完成，清单将自动隐藏。

## 开始之前 \{#before-you-start\}

在开始之前，请确认以下条件已满足：

- **DNS 访问权限**：你可以在根域名下添加记录。
- **支付方式**：你已拥有 Stripe 账户并配置好订阅产品。如需使用其他支付提供商，请自行托管结账流程——详见[配置结账](mail-checkout)。

## 1. 选择账户类型 \{#1-choose-your-account-type\}

:::warning
请谨慎选择——你在 Adapty Mail 中自行创建的项目，之后无法关联到 Adapty。
:::

账户类型决定了你的 Adapty Mail 项目能够执行哪些操作：

| | Adapty 关联版（推荐） | 独立版 |
| --- | --- | --- |
| **注册** | 使用您的 [Adapty 账户](https://app.adapty.io/) 登录并打开 **Mail**。Adapty 会创建一个与您的应用关联的项目。在设置的最后一步完成前，Adapty Mail 与 SDK 之间的数据交换处于禁用状态。您无需将购买记录迁移至 Adapty：只需使用易于配置的[观察者模式](observer-vs-full-mode)上报交易即可。 | 使用电子邮件地址和密码[仅注册 Adapty Mail](https://mail.adapty.io/signup)。无需 Adapty 账户，也无需在应用中进行任何安装——您可通过 FunnelFox 或 API 自行导入数据。 |
| **结账页面**（第 6 步） | **AI 自动生成**——一个基于您品牌风格、集成 Stripe 支付的托管结账页面——或使用您自己的托管付费墙 | 您自己的托管付费墙 |
| **市场细分** | 从 Adapty 导入，或在 Mail 中创建 | 在 Mail 中创建 |
| **品牌信息**——用于生成邮件的内容：名称、Logo、配色及语气风格（第 3 步） | 如果您的应用在应用商店有上架信息，系统会在您进入前自动提取；否则需手动填写 | 粘贴您的应用商店链接后自动提取 |
| **购买数据**（第 2 步） | 在 **Settings** > **Project** 中一键配置；也支持 FunnelFox 和 API | 将密钥粘贴至 Adapty 看板或 FunnelFox，或通过 API 导入 |
| **团队** | 团队成员从您的 Adapty 公司账户打开 Mail 即可加入；也支持邮件邀请 | 邮件邀请 |

## 2. 连接你的数据 \{#2-connect-your-data\}

在 Adapty Mail 向用户发送邮件之前，它需要：

- **他们的电子邮件地址**：您发送邮件的目标地址。
- **他们的[客户用户 ID](how-profiles-work)**：用户的唯一标识符。Adapty 将其存储在用户画像中，以便跨设备识别同一用户。如果没有此 ID，每当用户重新安装应用或退出登录时，Adapty 都会为其创建一个新的用户画像。
- **他们的订阅事件流**：试用、续订、取消和退款等事件，实时推送。这些事件让您能够根据用户行为进行精准触达，并将收入与促成购买的邮件关联起来。如果没有事件流，用户只能收到针对从未购买过的用户所设定的消息序列。

按照说明，使用以下数据创建一个**[入口点](mail-entry-points)**：

- **Adapty**：如果您的应用已集成 Adapty SDK，请选择此方式。Adapty 会自动将用户画像、邮箱和订阅事件转发给您，无需自建服务器。在应用中，添加用户身份识别和邮箱收集功能即可。详见 [将 Adapty 连接到 Adapty Mail](mail-collect-emails)。
- **Adapty Mail API**：如果您已有自建后端并持有相关数据、应用未集成 Adapty SDK，或需要从其他来源导入订阅者，请选择此方式。您需要自行提交用户画像和交易事件。请求通过 **Settings** > **Project** 中的密钥进行鉴权。详见 [通过 Adapty Mail API 发送邮件和交易数据](mail-send-data-via-api)。
- **FunnelFox**：如果您通过 FunnelFox Web 漏斗获取用户并完成收费，请选择此方式。FunnelFox 已持有用户的邮箱、购买记录和订阅事件，并会自动将其转发至 Adapty Mail，无需集成 SDK，也无需编写任何请求。详见 [FunnelFox 集成指南](https://funnelfox.com/docs/integrations/email-providers/adapty-mail)。
- **组合使用**：您可以同时使用多个数据入口。Adapty Mail 通过 `customer_user_id` 和邮箱地址对传入的用户数据进行匹配。

Adapty Mail 会在其余设置完成后开始发送邮件。

## 3. 设置您的品牌 \{#3-set-up-your-brand\}

Adapty Mail 在没有**品牌**的情况下无法生成邮件或网页付费墙。品牌存储了 Adapty Mail 匹配您应用外观和风格所需的信息——名称、Logo、颜色、字体、语调、功能特性和用户评价。您提供应用商店的介绍页面，Adapty Mail 将据此构建品牌。

1. 在 Adapty Mail 中，打开 **Brand**。
2. 如果页面显示已填写的品牌信息，请查看后继续操作。如果显示 **Set up your brand** 界面，请继续以下步骤。
3. 在 **Store** 下，选择 **App Store** 或 **Google Play**，然后粘贴您的应用商店链接。
   :::note
   设置界面仅接受 App Store 或 Google Play 的应用页面链接。如果您的应用没有商店页面（例如 web-to-app 转化漏斗），请在继续操作前联系 Adapty 支持团队。
   :::
4. 点击 **Build my brand**。Adapty Mail 会抓取该页面、解析用户评价并推断您的品牌风格，通常在一分钟内完成。
5. 如需查看各板块内容、手动编辑，或添加落地页和社交媒体来源，请参阅[品牌](mail-brand)。

## 4. 设置发送域名 \{#4-set-up-your-sending-domain\}

Adapty Mail 通过您的私有域名发送邮件。您只需添加一次 DNS 记录，所有营销活动均可使用同一已验证的域名。

要注册您的第一个域名，请在 Adapty Mail 中前往 **Settings** > **DNS** > **Email domains** 部分。

1. 在 **Domain** 字段中，输入您的根域名（例如 `yourapp.com`）。仅接受顶级域名——不接受 `app.yourapp.com` 之类的子域名。
2. 在 **Sending subdomain** 字段中，输入邮件发送前缀，或留空以使用 `mail`。邮件将从 `hello@mail.yourapp.com` 发出。
3. 点击 **Add domain**。

   <ZoomImage id="mail-email-domains.webp" width="500px" />

4. 在您的域名注册商处，添加新域名卡片中列出的所有 DNS 记录。这些记录分为三组：发送子域名的 DKIM 和 MAIL FROM 记录、用于预热域名的邮箱记录，以及服务于 `go.yourapp.com`（用于提供图片和追踪链接）的记录。若要了解每组记录的认证用途，请参阅[您需要添加哪些记录](mail-sending-domain#which-records-you-add)。如需一次性导出全部记录，请点击 **Export**。
5. 可选步骤：在根域名上添加建议的 DMARC TXT 记录（推荐）。
6. 点击 **Check** 立即验证，或关闭卡片，让 Adapty Mail 自动轮询 DNS。

<ZoomImage id="mail-email-domains.webp" width="700px" />

验证时间一览：

- **自动轮询**：添加域名 1 分钟后进行首次检查，之后检查间隔逐步加倍，最长每小时一次，直到找到记录为止。
- **手动检查**：随时点击 **Check** 立即触发检查。
- **DNS 传播**：通常需要几分钟，极少数情况下最长可达 48 小时。
- **验证窗口期**：7 天。若窗口期过期，DNS 记录仍会保留——在 **Settings** > **DNS** 中重新添加域名，即可开启新的窗口期。

验证一个域名即可开始使用 Adapty Mail。每个项目最多可添加五个域名，其余域名可在之后再行添加。

有关各记录类型及域名预热的详细信息，请参阅[配置发送域名](mail-sending-domain)。

## 5. 添加公司地址 \{#add-your-company-address\}

反垃圾邮件法规要求每封营销邮件都必须包含实际的邮政地址。Adapty Mail 会将您的地址显示在每封营销邮件的页脚，并在填写之前阻止营销活动的生成。

1. 在 Adapty Mail 中，前往 **Settings** > **Company**。
2. 在 **Company address** 部分，填写 **Legal company name**、**Address line 1**、**City**、**Postal code** 和 **Country**。**Address line 2** 和 **State / Region** 为可选项。
3. 点击 **Save**。

## 6. 创建网页付费墙 \{#6-create-a-web-paywall\}

当收件人点击邮件中的 CTA 时，他们会进入一个**网页付费墙**——一个在浏览器中打开的结账页面。每个营销活动都需要关联一个网页付费墙，未关联的营销活动将被 Adapty Mail 拒绝。这与您的应用内付费墙不同：在此完成的购买属于网页支付，而非 App Store 或 Google Play 的交易。

您有两种选择：

- **用 AI 生成**：使用内置编辑工具生成付费墙，由 [FunnelFox](https://funnelfox.com) 提供支持。生成的付费墙通过 Stripe 处理付款。
- **使用自托管付费墙**：将 Adapty Mail 指向您已自行托管的页面，使用任意支付提供商。Adapty Mail 会将用户重定向到您的付费墙，并在 URL 中预填用户信息。自托管付费墙可使用任何支付提供商。

:::note
**使用 AI 生成功能需要 Stripe 和已关联的 Adapty 账户**。AI 生成的结账流程仅支持 Stripe。如果你使用其他支付服务商，或使用独立的 Adapty Mail 账户，请使用自己托管的付费墙。
:::

首先，在 Adapty Mail 中前往 **Web Paywalls** > **Create**。

<ZoomImage id="new-web-paywall.webp" width="500px" />

### 选项 A：使用 AI 生成 \{#option-a-generate-with-ai\}

页面会显示一个前置条件清单，每项旁边都有内联按钮——按顺序逐一完成，然后回来生成。清单涵盖登录付费墙编辑工具、连接 Stripe、添加产品以及查看结果。完整操作步骤请参阅[设置结账](mail-checkout)。如果你在其他标签页中完成了某项前置条件，点击清单上的 **Refresh** 即可同步状态。

所有前置条件都变为绿色后，点击 **Proceed to generation**。在 **Choose plans** 对话框中：

1. 选择 1–3 个方案，所有方案使用同一货币。每个方案是生成的付费墙在结账时展示的一个选项。点击 **Add plan** 可添加第二个和第三个方案。
2. 对于每个方案，选择正式环境价格、沙盒对应价格，或两者都选。同一行中的正式环境价格和沙盒价格算作一个方案。
3. 点击 **Generate paywall**。

每个方案要么填写完整的列，要么全部留空——列只填写一部分会导致无法生成。若没有沙盒价格，[测试邮件](mail-testing)将链接到正式环境付费墙，且测试购买无法正常进行。

:::important
付费墙必须先发布才能处理结账流量。未发布的付费墙在用户点击邮件结账链接时会返回错误。
:::

### 方案 B：使用您自己托管的付费墙 \{#option-b-use-your-own-hosted-paywall\}

1. 选择 **Enter URL manually**。
2. 粘贴您托管的付费墙 URL，并将占位符作为查询参数添加。Adapty Mail 会为每位收件人替换相应的占位符，以便结账页面识别访客。示例：

   ```
   https://example.com/paywall?email={email}&adapty_profile_id={adapty.external_profile_id}
   ```

   创建页面列出了可用的占位符。请参阅[设置结账](mail-checkout#use-your-own-hosted-paywall)，了解每个占位符对应的具体内容。
3. 保存并发布。

有关结账漏斗结构及个性化工作原理，请参阅[设置结账](mail-checkout)。

<ZoomImage id="generate-web-paywall.webp" width="500px" />

## 7. 使用 AI 生成营销活动 \{#7-generate-a-campaign-with-ai\}

**营销活动**是一组最多 15 封邮件的序列，会在一段时间内依次发送给同一收件人。AI 会根据你在[第 3 步](#3-set-up-your-brand)配置的品牌信息自动生成完整序列，包括文案、设计、主图以及个性化结账链接。

1. 在 Adapty Mail 中，前往 **Campaigns** 并点击 **Create**。
2. 设置营销活动名称。
3. 在 **Web paywall** 下拉菜单中，选择你在上一步添加的 Web 付费墙。

   <ZoomImage id="mail-new-campaign.webp" width="500px" />

4. 点击 **Generate emails**。
5. 填写生成对话框——语气、语言、可选的自定义提示（最多 2,000 个字符）以及邮件数量（1–15，默认 4）。各字段的含义请参阅[创建活动](mail-create-campaign)。

   <ZoomImage id="generate-emails.webp" width="500px" />

6. 点击 **Generate**。生成通常需要几分钟。如果系统在 5 分钟内无法完成，会自动超时——遇到这种情况请重试。
7. 预览每封邮件。预览头部有一个 **Theme toggle**（Auto、Light、Dark），用于控制预览的渲染方式——生成的内容在各模式下完全相同。你可以重新生成单封邮件、编辑文案，或打开 HTML 编辑器进行精细调整。

<ZoomImage id="generated-emails.webp" width="700px" />

8. 点击 **Create** 保存活动。

营销活动将保存为**草稿**状态，暂不发送——只有将营销活动关联到流程后才会正式上线（下一步操作）。在营销活动编辑器中没有单独的"发布"操作。

## 8. 启动流程 \{#launch-a-flow\}

Adapty Mail 内置了**流程**功能。流程将**触发器**（订阅事件）与**营销活动**（邮件序列）关联起来。五种触发器——订阅即将到期、付款失败等——各自对应一个独立的流程。流程可以向所有触发该事件的用户发送同一个营销活动，也可以利用**市场细分**向不同用户群发送不同的营销活动。

1. 在 Adapty Mail 中，进入 **Flows**，然后打开你想配置的触发器：
   - **Never purchased** — 已注册但尚未完成购买的用户。
   - **Renewal cancelled** — 已关闭自动续费但订阅仍在有效期内的用户。
   - **Billing issue** — 付款失败、银行卡被拒或已过期，或处于宽限期。
   - **Expired** — 订阅已到期，访问权限已失效。
   - **Refunded** — 购买后申请退款的用户。

   各触发器的目标和文案风格指引，请参阅[流程](mail-flows)。

2. 点击 **Create** 打开对话框。

<ZoomImage id="create-flow-mail.webp" width="500px" />

3. 在对话框中：
   - 选择一个**细分市场（Segment）**。**All Users** 会覆盖所有触发该事件的用户，足以用于启动。如需后续缩小目标受众范围，可以创建[不同的市场细分](mail-segments)——根据用户的国家、年龄或订阅状态进行过滤。
   - 将内容类型设置为 **Campaign**（A/B 测试选项详见 [A/B 测试](mail-ab-testing)）。
   - 选择在第 7 步中保存的 **Campaign**。
4. 点击 **Save**。

流程一旦保存即刻上线，无需单独的发布步骤。从此刻起，符合条件的用户在触发事件发生后便会开始收到该活动推送。

:::note
您可以在同一触发器下添加多行，每行对应各自的目标受众和活动。Adapty Mail 会从上到下依次检查，使用首个匹配的目标受众。请将 **All Users** 置于最后一行——若将其置于其他位置，Adapty Mail 将无法保存流程。
:::

<ZoomImage id="mail-flow-details.webp" width="500px" />

:::tip
如果新收件人在接收营销邮件之前需要确认地址，请在此步骤之前开启[双重确认订阅](mail-double-opt-in)。只有在开启后创建的用户画像才会被要求确认。
:::

## 9. 开始发送 \{#9-start-sending\}

您的营销活动已配置完毕，但尚未激活——还没有用户数据流入 Adapty Mail。请通过[您选择的入口点](#2-connect-your-data)开始数据传输。您的项目是否已关联 Adapty（第 1 步）只影响*如何*开启 Adapty 数据源，而不影响实际传入的内容：

| 您的数据来源 | 您的 Mail 项目是否已关联 Adapty 应用 | 操作说明 |
| --- | --- | --- |
| [Adapty SDK](mail-collect-emails#5-enable-sending) | 是 | 在 Adapty Mail 中，进入 **Settings** > **Project**，点击 **Enable Adapty integration**。在完成流程（第 8 步）之前，该按钮将保持禁用状态。 |
| [Adapty SDK](mail-collect-emails#5-enable-sending) | 否 | Adapty 可以向未关联的项目推送数据——只需要密钥即可。从 **Settings** > **Project** 复制 secret key，然后在 Adapty 看板的 **Integrations** > **Adapty Mail** 中粘贴。 |
| 您的后端，通过 [Adapty Mail API](mail-send-data-via-api) | 均可 | 开始推送用户画像和交易事件。在完成此设置之前发送的用户画像不会收到任何邮件，这也是此步骤放在最后的原因。 |
| [FunnelFox](mail-funnelfox) | 均可 | 从 **Settings** > **Project** 复制 secret key，然后在 FunnelFox 的 **Integrations** > **Adapty Mail** 中粘贴。数据约一分钟内开始同步。 |

从此刻起，符合你市场细分条件的用户一旦触发触发器，就会立即收到该活动。在向真实用户开放之前，请先[使用一个测试用户测试整个流程](mail-testing)。

## 故障排除 \{#troubleshooting\}

| 问题 | 解决方案 |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Generate emails** 按钮显示为灰色 | 品牌或公司地址缺失。按钮的提示文字会指明是哪一项。请参阅 [步骤 3](#3-set-up-your-brand) 和 [步骤 5](#5-add-your-company-address) |
| 付费墙生成被阻止 | 面板会说明原因：未设置品牌、未关联 Stripe 账户，或 Stripe 产品中没有价格。修复后点击 **Refresh** 刷新检查列表 |
| 营销活动无法保存 | 每个营销活动都需要一个网页付费墙。请在 [步骤 6](#6-create-a-web-paywall) 中创建 |
| **Enable Adapty integration** 按钮显示为灰色 | Adapty Mail 至少需要先创建一个流程。请参阅 [步骤 8](#8-launch-a-flow) |
| DNS 记录无法验证 | 检查记录是否完全匹配——末尾不能有多余的点、CNAME 目标正确、每条记录只填一个值。DNS 传播最长可能需要 48 小时 |
| 验证窗口已过期 | 在 **Settings** > **DNS** 中重新添加域名以开始新的验证窗口。注册商处的记录仍然有效，无需重新添加 |
| 邮件生成超时 | 生成操作将在 5 分钟后停止。请重试，如果问题持续出现，请联系 Adapty 支持团队 |

有关初始设置之外的错误，请参阅[设置发送域](mail-sending-domain#troubleshooting)和[设置结账](mail-checkout#troubleshooting)中的故障排除部分。
