Adapty 会自动为您的[备用付费墙](/fallback-paywalls)生成 JSON 配置文件，每个平台各一份。这些文件同时包含您的用户引导的备用数据。

如果某个版位设置了多个[目标受众](audience)，备用文件仅使用 **All users** 目标受众。如果该目标受众正在运行 A/B 测试，文件会包含测试的所有实验变体，SDK 会按权重将用户分配到各实验变体中。[跨版位 A/B 测试](ab-test-types)不会写入该文件。每当您修改付费墙或用户引导时，Adapty 会自动更新这些文件。

按照以下步骤下载备用配置：

1. 打开 **[Placements](https://app.adapty.io/placements)** 页面。
2. 点击 **Fallbacks** 按钮。
3. 从下拉菜单中选择目标平台（*iOS* 或 *Android*）。
4. 选择您的 SDK 版本以开始下载。

:::tip
如需通过终端下载文件，请使用 [Developer CLI](developer-cli)。传入您应用所使用的 Adapty SDK 版本：

```bash
adapty fallbacks get --app <app-id> --platform ios --sdk-version <sdk-version> --output ios_fallback.json
```

每次运行时针对一个应用商店，使用 `--platform ios` 或 `--platform android`。详见 [`adapty fallbacks get`](developer-cli-fallbacks) 的参数说明。
:::
