[Retention Messaging](https://developer.apple.com/documentation/retentionmessaging) 是 Apple 的一项功能，可在 iOS **取消订阅**界面上向订阅者展示自定义消息，就在他们确认取消之前。通过给用户一个留下来的理由——或者一个优惠——来降低订阅流失率。

Adapty 与 Apple 的 Retention Messaging API 对接，每当订阅用户点击 **Cancel Subscription** 时，Apple 会实时请求对应的消息内容。Adapty 为你运行该端点：你在 Adapty 看板中编写、本地化并测试消息，Adapty 自动响应 Apple 的请求。无需自建后端，无需发布新版本。

消息分为两种类型。*默认*消息是纯文字内容，当促销消息无法显示时作为兜底展示。*促销*消息则在此基础上增加具体激励：折扣、免费试用，或切换到更合适的方案。Apple 会根据每位订阅者的产品和语言，为其展示匹配的消息。

## 快速入门 \{#quickstart\}

开始之前，你需要准备：

- 在 Adapty 中配置 [App Store Connect API 密钥](app-store-connection-configuration)。
- [获得 Apple 对你的应用的审批](retention-messaging-setup#request-access-from-apple)。Apple 的审核最长需要一个月，请尽早提交申请。
- 至少一个用于消息推送的[产品](create-product)。

然后：

1. [在沙盒模式下将 Adapty 连接到 Retention Messaging API](retention-messaging-setup)。
2. 使用沙盒账号或通过 TestFlight 购买时长最长的产品，并保持订阅激活状态。
3. [通过 Apple 的性能测试](retention-messaging-setup#pass-the-performance-test)。此过程最多需要一小时。
4. 切换到生产模式。
5. [创建您的生产环境消息](retention-messaging-create)——先创建默认消息，再创建促销消息——并将每条消息提交给 Apple 审核。
6. Apple 审核通过后，[追踪每条消息的表现](retention-messaging-analytics)。
