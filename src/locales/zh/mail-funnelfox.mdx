FunnelFox 是 Adapty Mail 的接入入口之一——当你通过 [FunnelFox](https://funnelfox.com) 网页漏斗获取用户并向其收费时，可以使用此方式。FunnelFox 已保存了用户的电子邮件地址、购买记录和订阅事件，因此完成连接无需任何 SDK 工作，也无需自行发起请求。

该连接为单向传输。FunnelFox 将数据推送至 Adapty Mail，不会反向读取您的营销活动数据，也不会自行发送电子邮件。

## FunnelFox 发送的内容 \{#what-funnelfox-sends\}

- **用户画像与电子邮件地址**：在漏斗收集了电子邮件的情况下。
- **标识符**：收件人的 FunnelFox 用户画像 ID，以及漏斗为其保存的自定义用户 ID（如有）。在用户画像页面中，它们显示在 **External Profile IDs** 下，分别为 **FunnelFox** 行和 **Custom** 行。
- **购买历史**：订阅、续订和一次性购买。退款以负金额显示。
- **订阅事件**：取消、重新激活、账单问题和到期。正是这些事件将每位用户纳入对应的[流程](mail-flows)。
- **用户画像属性**：国家、设备、操作系统、平台和语言区域——这五项均为[市场细分](mail-segments)筛选条件。FunnelFox 从浏览器的 User Agent 中读取后四项，同时发送时区信息（用于设置收件人接收邮件的时间，但不作为筛选条件）。它不发送应用版本，因此漏斗用户的该筛选条件始终为空。
- **漏斗上下文**：以自定义属性的形式存储在用户画像中，使用以下键名：
  - `fnlfx_funnel_id`：收集该电子邮件的漏斗。
  - `fnlfx_session_id`：漏斗会话。
  - `fnlfx_experiment_id`：漏斗实验（如果用户参与了实验）。
  - `email_consent`：用户是否在漏斗中同意接收电子邮件。值为文本 `"true"` 或 `"false"`，因此对其进行市场细分筛选时比较的是文本值。

要将这些值传递到结账页面，请在链接中添加对应的占位符，例如 `{custom_attribute.fnlfx_session_id}`。请参阅[占位符](mail-destinations#placeholders)。

数据会在漏斗事件发生后约一分钟内到达 Adapty Mail。

## 连接 FunnelFox \{#connect-funnelfox\}

请先完成 Adapty Mail 的其余设置——请参阅[Adapty Mail 入门](mail-get-started)。在流程创建完成之前，您发送的任何内容都不会产生邮件。

1. 在 Adapty Mail 中，前往 **Settings** > **Project**，复制 **Secret key**。
2. 在 FunnelFox 中，前往 **Integrations** > **Adapty Mail**。
3. 粘贴密钥并保存。

关于 FunnelFox 一侧的设置，请参阅 [FunnelFox 集成指南](https://funnelfox.com/docs/integrations/email-providers/adapty-mail)。

## 连接后 \{#after-you-connect\}

在用户画像页面，**External Profile IDs** 会显示一行 **FunnelFox** 记录，其中包含 FunnelFox 为该用户分配的 ID。如果一个用户画像来自多个数据源，每个数据源都会单独显示一行，方便你查看所有了解该用户的来源。

手动构建结账链接时，`{funnelfox.external_profile_id}` 会解析为收件人在 FunnelFox 中的用户画像 ID。[邮件目标地址](mail-destinations#placeholders) 列出了所有可用的占位符。

## 与其他入口点配合使用 \{#use-it-alongside-another-entry-point\}

您可以同时运行 FunnelFox 和其他[入口点](mail-entry-points)。Adapty Mail 通过电子邮件地址匹配用户。两个来源上报相同地址时，会合并到同一个用户画像；两个不同地址则会创建独立的用户画像，即使 `customer_user_id` 相同也不例外。
