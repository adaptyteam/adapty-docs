[FunnelFox](https://funnelfox.com) 是一个 web2app 漏斗平台，让你可以在 App Store 之外获客并向用户收费，从而绕过其费用和其他限制。

配置此集成后，FunnelFox 的购买数据将发送至 Adapty。Adapty 随即将你的网页收入与广告支出进行匹配，让你清晰看到每个广告系列、广告组和广告的实际收益。

## 工作原理 \{#how-it-works\}

当用户在 FunnelFox 漏斗中完成购买时，FunnelFox 会将交易事件发送至 Adapty Attribution。Adapty 使用 **Project ID** 来识别该交易归属于哪个应用。事件随后被存储并显示在 Adapty Attribution 分析中。

集成运行后，Adapty 中的每笔交易均包含：

- **订阅生命周期事件**：开始、续订、取消、试用转化、退款等
- **归因渠道**：Facebook、TikTok、Google 或自然流量。Adapty 通过广告网络自动添加的点击 ID 来识别来源——无需手动配置。
- **归因数据**：广告系列、广告组和广告标识符；UTM 参数；平台点击 ID（fbclid、ttclid、gclid）。广告系列、广告组和广告信息仅在您的广告带有 Adapty [追踪参数](#step-3-tag-your-ad-urls) 时才会传入。
- **漏斗与实验数据**：FunnelFox 漏斗名称和实验名称，便于对比 A/B 测试的各实验变体。
- **同期群日期**：首次试用开始或购买的日期。由于 Web 端购买没有应用安装事件，Adapty 会以该日期作为同期群划分依据。

## 配置集成 \{#configure-integration\}

:::note
在 FunnelFox 漏斗中，你无需使用 [Adapty 网页像素](ua-web-pixel)——FunnelFox 会直接向 Adapty 上报购买数据。
:::

### 步骤 1. 在 FunnelFox 中获取您的项目 ID \{#step-1-get-your-project-id-in-funnelfox\}

1. 在您的 FunnelFox 看板中，点击左侧边栏中的 **Settings**。
2. 在 **Project info** 部分，复制 **ID** 值。

<ZoomImage id="ff-project-id.webp" width="500px" />

### 步骤 2. 在 Adapty Attribution 中添加项目

1. 在 Adapty Attribution 中，前往 [**Integrations > FunnelFox**](https://app.adapty.io/ua/integrations/funnelfox)。
2. 粘贴从 FunnelFox 复制的 Project ID。
3. 点击 **Save**。

如需连接更多 FunnelFox 项目，点击 **Add project** 并对每个项目重复此步骤。

<ZoomImage id="ua-funnelfox.webp" width="500px" />

### 第三步：为广告链接添加标签 \{#step-3-tag-your-ad-urls\}

FunnelFox 只能传递到达您落地页 URL 的广告系列数据，且在访客首次进入页面时读取该 URL，而非在结账时读取。请按照[为网页漏斗的广告链接添加标签](ua-tag-ad-urls)中的说明，将 Adapty 的追踪参数添加到您的广告中。

### 第四步：在 FunnelFox 中开启广告系列归因 \{#step-4-turn-on-campaign-attribution-in-funnelfox\}

:::note
该设置默认关闭，且 FunnelFox 不会回填历史数据：开启前已完成的交易不会同步到 Adapty。
:::

1. 在 FunnelFox 中，前往 [**Integrations > Adapty**](https://app.funnelfox.com/integrations/adapty)。
2. 开启 **Campaign attribution**。

请为每个已连接的 FunnelFox 项目执行此操作。

您的 FunnelFox 项目必须归属于某个组织，且广告账户必须已在 Adapty 中完成连接。

有关 FunnelFox 通过此渠道发送的事件，请参阅 FunnelFox 文档中的 [Adapty 集成](https://funnelfox.com/docs/integrations/subscription-management/adapty#campaign-attribution)。
