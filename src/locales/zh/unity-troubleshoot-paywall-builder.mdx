本指南帮助你解决在 Unity SDK 中使用 Adapty 付费墙编辑工具设计的付费墙时遇到的常见问题。如需了解流程相关问题，请参阅[常见问题](flow-common-issues)。

## 获取付费墙配置失败 \{#getting-a-paywall-configuration-fails\}

**问题**：`CreateView` 方法无法获取付费墙配置。

**原因**：付费墙未在付费墙编辑工具中启用设备显示。

**解决方案**：在付费墙编辑工具中启用 **Show on device** 开关。

## 付费墙展示次数过多 \{#the-paywall-view-number-is-too-big\}

**问题**：付费墙的展示次数显示为预期值的两倍。

**原因**：您可能在代码中调用了 `LogShowFlow`（SDK v4+）/ `LogShowPaywall`，导致通过旧版付费墙编辑工具构建的付费墙展示次数被重复计算。Adapty 会自动追踪这些展示，无需手动调用此方法。

**解决方案**：请确认您的代码中没有针对通过旧版付费墙编辑工具构建的付费墙调用 `LogShowFlow`（SDK v4+）/ `LogShowPaywall`。

## 其他问题 \{#other-issues\}

**问题**：您遇到了上述未涵盖的其他付费墙编辑工具相关问题。

**解决方案**：如有需要，请参照[迁移指南](unity-sdk-migration-guides)将 SDK 升级至最新版本。许多问题已在较新版本的 SDK 中得到解决。
