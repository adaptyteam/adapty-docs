数据入口是指用户数据进入 Adapty Mail 的方式。无论使用哪种方式，Adapty Mail 在向用户发送邮件之前，都需要具备以下三项信息：

- **用户的电子邮件地址**：邮件的发送目标。
- **用户的 [customer user ID](how-profiles-work)**：用户的唯一标识符。
- **用户的订阅事件动态**：试用、续订、取消和退款等事件的实时推送。

选择适合你应用的接入方式：

- **Adapty**：如果您的应用已集成 Adapty SDK，请选择此方式。Adapty 会自动为您转发用户画像、邮件地址和订阅事件，无需自建服务器。在应用中添加用户身份识别和邮件收集逻辑即可。详见[将 Adapty 连接到 Adapty Mail](mail-collect-emails)。
- **Adapty Mail API**：如果您已有自己的后端服务并持有相关数据，或应用未集成 Adapty SDK，或需要从其他来源导入订阅者，请选择此方式。您需要自行发送用户画像和交易事件。请求通过 **Settings** > **Project** 中的密钥进行鉴权。详见[通过 Adapty Mail API 发送邮件和交易数据](mail-send-data-via-api)。
- **FunnelFox**：如果您通过 FunnelFox 网页漏斗获取用户并完成收费，请选择此方式。FunnelFox 已持有用户的邮件地址、购买记录和订阅事件，并会自动将这些数据转发至 Adapty Mail，无需集成 SDK，也无需编写任何请求。详见[将 FunnelFox 连接到 Adapty Mail](mail-funnelfox)。
- **组合使用**：您可以同时启用多个数据来源。Adapty Mail 通过 `customer_user_id` 和邮件地址匹配用户数据，因此来自多个来源的同一用户只会生成一个用户画像和一个邮件序列，不会产生重复发送。
