数据入口是用户数据进入 Adapty Mail 的方式。无论使用哪种方式，它都携带相同的三类信息：

- **他们的电子邮件地址**（必填）：邮件的发送目标。没有邮箱地址，Adapty Mail 就无法创建用户画像。
- **他们的 [customer user ID](how-profiles-work)**（可选，但推荐）：您自己设置的稳定标识符。Adapty 会在重新安装和重新登录时保持同一个人的用户画像，这样用户在提供邮箱前完成的购买记录也能关联到他们。
- **他们的订阅事件订阅源**（可选，但推荐）：试用、续费、取消和退款等事件，实时触发。没有它，所有人都只能收到"从未购买"这一类用户对应的邮件序列。

请选择与您的应用匹配的入口点：

- **Adapty**：如果您的应用已集成 Adapty SDK，请选择此方式。Adapty 会自动转发用户画像、邮箱地址和订阅事件，无需自建服务器。只需在应用中添加用户识别和邮箱采集功能即可。详见[将 Adapty 连接到 Adapty Mail](mail-collect-emails)。
- **Adapty Mail API**：如果您已有自建后端并保存了相关数据、应用未集成 Adapty SDK，或需要从其他渠道导入订阅者，请选择此方式。您需要自行上传用户画像和交易事件。请求认证使用 **Settings** > **Project** 中的密钥。详见[通过 Adapty Mail API 发送邮件和交易数据](mail-send-data-via-api)。
- **FunnelFox**：如果您通过 FunnelFox 网页漏斗获客并收费，请选择此方式。FunnelFox 已持有用户的邮箱、购买记录和订阅事件，并会自动转发至 Adapty Mail，无需集成 SDK，也无需编写任何请求。详见[将 FunnelFox 连接到 Adapty Mail](mail-funnelfox)。
- **组合使用**：您可以同时使用多种接入方式。Adapty Mail 通过邮箱地址匹配用户。两个来源上报同一邮箱地址时，会合并到同一用户画像；上报不同地址时，即使 `customer_user_id` 相同，也会创建独立的用户画像。
