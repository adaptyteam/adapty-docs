要将您的 iOS 应用连接到 Adapty，请在 **App settings** > **iOS SDK** 中填写 App Store 凭据。Adapty 随后将：

- 验证购买。
- 接收订阅事件。
- 保持您的产品与 App Store Connect 同步。

如果购买或订阅事件停止到达 Adapty，请[逐项检查凭据](#check-each-credential)。

<YouTube id="VJQbzoTCkqs" />

开始之前：

- 您需要在 App Store Connect 中访问目标应用。如果应用尚未创建，请先[配置 App Store Connect](set-up-app-store-connect)。如果您没有平台访问权限，请向相关人员申请。
- 您的团队需要访问 App Store Connect API——这是生成所需访问密钥的必要条件。如果团队尚未获得访问权限，请联系 Account Holder [申请开通](https://developer.apple.com/help/app-store-connect/get-started/app-store-connect-api)。Apple 会对每个申请进行审核。
- 请打开两个浏览器标签页：一个打开 [App Store Connect](https://appstoreconnect.apple.com/apps) 中的应用页面，另一个打开 Adapty 中的 [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk)。在本指南的操作过程中，您需要在两个标签页之间复制相关信息。

## 概述 \{#overview\}

本指南中的每项凭据都是必需的。Adapty 将每项凭据用于[与 App Store 数据交换的不同环节](store-sync#if-updates-stop-arriving)。要完成配置，请按以下七个步骤操作：

1. 输入 [Bundle ID 和 Apple App ID](#enter-the-bundle-id-and-apple-app-id)
2. 输入 [App 专属共享密钥](#enter-the-app-specific-shared-secret)
3. 使用 Adapty 提供的 URL [启用 App Store 服务器通知](#enable-app-store-server-notifications)
4. 添加 [App 内购买密钥](#add-the-in-app-purchase-key)
5. 添加 [App Store Connect API 密钥](#add-the-app-store-connect-api-key)
6. 安装 [Adapty SDK 并进行沙盒购买](#check-each-credential)
7. [验证所有凭据](#check-each-credential)

## 输入 Bundle ID 和 Apple App ID \{#enter-the-bundle-id-and-apple-app-id\}

两个值用于在 App Store Connect 中标识你的应用：Bundle ID 和 Apple ID（在 Adapty 中标记为 **Apple App ID**）。Adapty 需要 Bundle ID 来处理购买。有了 Apple ID，Adapty 能够：

- 在 App Store Connect 中查找您的产品，并[在那里创建新产品](create-product#create-product-and-push-to-store)。
- 显示您产品的 App Store 状态和价格。
- 为[留存消息推送](retention-messaging-setup)提供实时消息服务。
- 运行 [AI 增长顾问](autopilot)分析。
- 向归因集成（如 AppsFlyer）标识您的应用。

Apple 会在您将应用添加到 App Store Connect 时分配 Apple ID，因此即使您的应用尚未上架 App Store，也请填写该 ID。

## 输入应用专用共享密钥 \{#enter-the-app-specific-shared-secret\}

Adapty 需要应用专用共享密钥来验证购买凭证，并在 App Store Connect 中创建产品。

1. 在 [App Store Connect](https://appstoreconnect.apple.com/apps) 中，打开应用的 **App Information** 页面。在 **App-Specific Shared Secret** 部分，点击 **Manage**。

   <ZoomImage id="asc-app-information-shared-secret.webp" width="700px" alt="App Store Connect 中 App Information 页面上的 App-Specific Shared Secret 部分" />

2. 复制密钥。如果该应用尚未生成密钥，请先点击 **Generate**。生成密钥需要在 App Store Connect 中拥有 Account Holder 或 Admin 角色。如果您没有上述角色，请联系拥有该角色的人员生成密钥并发送给您。

   除非您是通过[应用转让](transfer-apps#app-store-ios-transfer)接收该应用，否则请勿点击 **Regenerate**：点击后，当前密钥将在所有使用该密钥的地方立即失效。

   <ZoomImage id="asc-shared-secret-dialog.webp" width="700px" alt="App-Specific Shared Secret window with the secret" />

3. 在 Adapty 中，将密钥粘贴到 **App Store Connect shared secret** 字段。

   <ZoomImage id="app-settings-shared-secret.webp" width="700px" alt="App Store Connect shared secret field in Adapty" />

4. 点击 **Save**。

## 使用 Adapty 提供的 URL 启用 App Store 服务器通知 \{#enable-app-store-server-notifications\}

:::link
主要文章：[启用 App Store 服务器通知](enable-app-store-server-notifications)
:::

Apple 会在续订、退款及其他订阅事件发生时，将服务器通知实时推送给 Adapty。即使您的应用未上报任何交易，Adapty 也会记录这些事件。

如果 Apple 已在向某台服务器发送这些通知，请在 App Store Connect 中替换其 URL 之前，先设置好转发。在 Adapty 中，将该服务器的 URL 填入 **URL for forwarding raw Apple events** 字段，然后点击 **Save**。Adapty 随后会将[从 Apple 收到的通知转发](enable-app-store-server-notifications#raw-events-forwarding)到该服务器。

如果您的后端必须在 App Store Connect 中保留其 URL，请改为[从后端将通知传递给 Adapty](forwarding-events-to-adapty)。

## 检查每个凭据是否有效 \{#check-each-credential\}

要确认 Adapty 能验证购买，请先在应用中[安装 Adapty SDK](installation-of-adapty-sdks)，再[进行沙盒购买](test-purchases-in-sandbox)。

沙盒购买只会用到部分凭据。请在购买后逐一验证，每当购买或订阅事件无法送达 Adapty 时，也请重新核查：

- **Bundle ID**、**Apple App ID** 和 **App Store Connect shared secret**：将这三个值与 App Store Connect **App Information** 页面上的 **Bundle ID**、**Apple ID** 以及 **App-Specific Shared Secret** 下的密钥进行比对。
- **App Store server notifications**：一旦有购买或续订通知到达 Adapty，该部分的状态会显示为 **Active**。如果显示其他状态，请[检查服务器 URL](enable-app-store-server-notifications#check-that-notifications-reach-adapty)。
- **In-app purchase API (StoreKit 2)**：Adapty 在您保存时会向 Apple 验证密钥。如果之后应用内购买未能解锁任何访问等级，说明密钥可能已失效，请[更换密钥](generate-in-app-purchase-key#replace-the-key)。
- **App Store promotional offers**：确认 **Subscription key ID** 与 **In-app purchase API (StoreKit 2)** 部分中的 **Key ID** 一致。如果不一致，请[在两个部分中输入相同的密钥](generate-in-app-purchase-key#add-the-key-to-adapty)。
- **App Store Connect API key**：**Products** 页面的 **App Store status** 列会显示每个 App Store 产品的状态。如果某个产品显示横线或 **Not Connected**，请[检查密钥和 Apple App ID](troubleshoot-app-store-integration#products-dont-appear-or-show-no-app-store-status)。

刚完成设置后，Analytics 中统计到的试用和购买数量可能多于安装量，也可能多于 Event Feed 中显示的数量。这是因为存在[没有用户画像的交易](how-profiles-work#transactions-without-profiles)：这些购买来自尚未打开过集成了 Adapty SDK 版本应用的用户。

Adapty 与应用商店报告之间的其他差异，源于[各自统计购买的方式](discrepancies-and-troubleshooting)，而非凭据配置问题。
