## 保存凭据时出现"提供的字段值不正确"错误 \{#the-provided-field-values-are-incorrect-when-saving-credentials\}

当你保存应用内购买密钥时，Adapty 会根据 **Issuer ID**、**Key ID** 和 **Private key (.p8 file)** 字段构建一个认证令牌，并通过 Apple 验证。此错误表示 Apple 拒绝了该令牌。请按以下顺序检查各字段的值：

1. **密钥类型。** 此密钥必须是 App Store Connect 中 **Users and Access** > **Integrations** > **In-App Purchase** 页面下的 **In-App Purchase** 密钥。**Team Keys** 选项卡下的密钥（即 App Store Connect API 密钥）有其独立的 **Issuer ID** 和 **Key ID**，Apple 不接受将其用于此处。请改在 **App Store Connect API key** 部分[连接该密钥](app-store-connect-api-key#connect-the-key-in-adapty)。
2. **同一账户和团队。** Issuer ID、Key ID 和 .p8 文件必须来自与该应用相同的 App Store Connect 团队。使用其他团队账户（例如代理商账户）生成的密钥将无法通过验证。
3. **.p8 文件本身。** 请直接上传从 App Store Connect 下载的原始文件。通过粘贴密钥内容重新生成的文件往往会验证失败。每个密钥只能下载一次，如果原始文件丢失，请重新生成一个新密钥。
4. **Bundle ID。** Bundle ID 必须与 App Store Connect 中应用的 Bundle ID 完全一致，使用反向 DNS 格式，不含空格，例如 `com.company.app`。
5. **隐藏字符。** 请直接从 App Store Connect 复制每个 ID。多余的空白字符或形似字符——例如用小写字母 `l` 替代数字 `1`——都会导致验证失败。

此验证仅使用三个应用内购买密钥字段和 Bundle ID。App-Specific Shared Secret 和 [App Store Connect API 密钥](app-store-connect-api-key) 不参与此验证，因此重新填写任何一个都不会影响结果。

如果所有值均与 App Store Connect 匹配，但仍看到此错误，请通过 [support@adapty.io](mailto:support@adapty.io) 联系 Adapty 支持团队。

## 产品未显示或 App Store 状态缺失 \{#products-dont-appear-or-show-no-app-store-status\}

当 Adapty 无法从 App Store Connect 读取您的产品时，您会看到以下一种或多种现象：

- **App Store Product ID** 下拉列表中未显示您的产品。
- 产品列表的 **App Store status** 列显示破折号或"Not Connected"，或产品页面持续停留在"Status pending"状态。
- 留存消息的 **Associated plan** 列表显示"No options"。
- 您为产品下载的价格 CSV 文件仅包含列标题，无任何数据。

请按顺序逐一排查以下原因：

- **应用未配置 App Store Connect API 密钥**：[关联团队密钥](app-store-connect-api-key)。
- **Apple 拒绝 App Store Connect API 密钥**：该密钥属于其他团队、已被撤销，或者 Key ID 与其 .p8 文件不匹配。请[替换密钥](app-store-connect-api-key#replace-the-key)，使用拥有该应用的团队的密钥。
- **Apple App ID 为空或填写有误**：请从 App Store Connect 中[复制应用的 Apple ID](app-store-connection-configuration#enter-the-bundle-id-and-apple-app-id)，并填入 **Apple App ID** 字段。
- **产品属于其他应用**：Adapty 仅在与您 Apple App ID 对应的 App Store Connect 应用中查找产品。请确认该产品确实属于该应用。
- **产品创建时间不足 10 分钟**：在 App Store Connect 中创建产品后，请等待 10 分钟，然后再在 **App Store Product ID** 下拉列表中查找。

## 推送产品时出现"403 Client Error: Forbidden"错误 \{#403-client-error-forbidden-when-you-push-a-product\}

推送产品时，如果账户持有人尚未接受最新的付费应用协议，App Store Connect 会返回此错误。账户持有人可在 App Store Connect 中打开 **Business** > **Agreements**，然后点击付费应用对应的 **View and Agree to Terms** 以接受协议。

App Store Connect API 密钥被撤销同样会导致 403 错误：[替换密钥](app-store-connect-api-key#replace-the-key)。

## 通知状态显示"Delayed"或"Stalled" \{#the-notifications-status-reads-delayed-or-stalled\}

**App settings** > **iOS SDK** 页面上的通知状态显示"Delayed"，表示最近一条通知到达时间已超过 24 小时。超过 72 小时后，状态将变为"Stalled"。[请验证 App Store Connect 中的 **Production Server URL** 和 **Sandbox Server URL** 是否与 Adapty 中的 **URL for App Store server notifications** 保持一致](enable-app-store-server-notifications#check-that-notifications-reach-adapty)。

## 购买成功，但用户失去访问权限 \{#a-purchase-succeeds-but-the-customer-loses-access\}

用户完成付款后可能短暂拥有访问权限，但在应用从 Adapty 刷新用户画像后，该权限消失了。

通常原因如下：

- **应用内购买密钥已失效**：Adapty 无法向 Apple 验证交易。[替换密钥](generate-in-app-purchase-key#replace-the-key)。
- **产品未在 Adapty 中关联**：客户购买的商店产品 ID 未关联至 Adapty 产品，因此没有可授予的访问等级。请确认该产品以正确的 **App Store Product ID** 存在，并已分配[访问等级](access-level)。

替换应用内购买密钥后，请让在密钥失效期间完成购买的用户恢复购买记录。恢复操作可立即找回他们的访问权限。

## Adapty 中的价格与 App Store 不匹配 \{#prices-in-adapty-dont-match-app-store\}

如果 Adapty 与 App Store 显示的产品价格不一致，请检查你添加产品的方式。Adapty 产品页面上的 **price** 字段在不同情况下有不同的用途。

如果你在 Adapty 中创建产品并从看板推送到商店，该价格将作为商店的初始定价。

如果你添加的产品在商店中已存在，此价格仅作为占位符使用。Adapty 的分析、集成和 SDK 均以从 App Store 实际获取的价格为准，而非该占位符。App Store 价格发生变更后不会同步更新占位符，且目前无法在看板中手动编辑占位符。
