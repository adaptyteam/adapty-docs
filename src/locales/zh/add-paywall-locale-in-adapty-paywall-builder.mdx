为流程添加本地化支持后，它就能以多种语言呈现给用户。在流程编辑工具中，本地化按屏幕组织，每个屏幕都会显示翻译完成百分比，方便追踪进度。

:::tip
在添加其他语言之前，请先用默认语言区域完成流程的所有设置。
:::
## 添加并配置本地化 \{#add-and-set-up-localization\}

1. 在左侧面板中，点击 <Inline id="localizations.svg" alt="Localizations" />，然后点击 **Add locale**，选择要添加的语言。

<ZoomImage id="new-locale-flow.webp" width="500px" alt="Add locale dialog" />

2. 每个已添加的语言区域将作为一列显示在本地化表格中，并预先填入默认语言的内容。

3. 如果只想查看尚未翻译的内容，可以在左侧面板中开启 **Missing only** 开关，表格将只显示未翻译的行。

<ZoomImage id="locales-table.webp" width="700px" alt="Localization table" />
## 设置默认语言 \{#set-the-default-locale\}

默认语言保存着源内容，并作为任何缺失翻译的备用语言。每个流程初始时以英语作为默认语言，也是唯一的语言。

固定图标 <Inline id="pin.svg" alt="Pin" /> 标记默认语言。除非先将其他语言设为默认，否则无法删除默认语言。

如需更改默认语言，请打开目标语言列标题中的上下文菜单 <Inline id="context.svg" alt="Context menu" />，然后选择 **Set as default**。

<ZoomImage id="flow-builder-set-default-locale.webp" width="700px" alt="Locale column menu with Set as default selected" />

## 导出与导入以供外部翻译 \{#export-and-import-for-external-translation\}

您可以将本地化文件导出，发送给翻译人员，然后再导入翻译结果。

在顶部工具栏中，点击 **Import / Export**。

<ZoomImage id="import-export.webp" width="700px" />

### 导出文件格式 \{#export-file-format\}

导出会生成一个 `.tsv`（制表符分隔）文件，每行对应一个可翻译元素。各列说明如下：

| 列名 | 说明 |
|--------|-------------|
| `Screen` | 该元素所属的屏幕（例如 `Welcome`、`Quiz`） |
| `Element` | 该屏幕内自动生成的元素标识符。可在 **Interactions** > **Element ID** 中修改。 |
| `Property` | 属性类型（例如 `content`） |
| `[default_locale]` | 默认语言代码（例如 `en`） |
| `[locale]` | 每个已添加的语言对应一列（例如 `fr`、`es`） |

示例：
:::note
对于未翻译的行，将对应语言列留空——Adapty 会将其视为缺失内容。
:::
### 导入文件要求 \{#import-file-requirements\}

- **格式**：`.tsv`（制表符分隔值）
- **标题行**：必须包含 `Screen`、`Element`、`Property` 列，以及至少一个语言区域列
- **语言区域列名**：必须与流程中已添加的语言区域代码一致。若文件中包含流程里不存在的语言区域代码，将会报错。
- **部分导入**：可以只包含部分行；文件中未包含的行将保留其当前值
### 限制 \{#limitations\}

- 导出过程会从字符串中去除变量。如果将此数据重新导入，则需要手动将变量添加回去。
- 导出的文件仅包含字符串——如需本地化媒体文件，请参阅[本地化图片和视频](#localize-images-and-videos)。

## 手动翻译 \{#translate-manually\}

您也可以直接在本地化表格的任意单元格中输入翻译内容。

要管理某一行，请打开其上下文菜单 <Inline id="context.svg" alt="Context menu" />：

- **Reset to default**：将该行的翻译恢复为默认语言的值。

## 本地化图片和视频 \{#localize-images-and-videos\}

通过为每种语言环境上传不同的文件，可以实现图片和视频的本地化。

1. 在画布下方或本地化面板中激活目标语言环境。
2. 选择图片/视频元素。
3. 在属性面板中上传本地化文件。

未上传本地化文件的媒体元素将显示默认语言环境的文件。

<ZoomImage id="image-localization-demo.webp" width="500px" alt="随活动语言环境切换而变化的画布图片" />
