在 iOS 和 Android 上恢复购买是一项功能，允许用户重新获得对之前购买内容（如订阅或应用内购买）的访问权限，而无需再次付费。该功能对于那些可能卸载并重新安装了应用，或者换了新设备并希望无需重新付费即可访问之前购买内容的用户尤为实用。

:::note
如果你在编辑工具中构建了界面，则无需手动恢复购买。只需将恢复控件连接好——在 Flow & 付费墙编辑工具中使用 **Restore purchases** 动作，或在旧版编辑工具中使用恢复链接或按钮——SDK 会自动完成恢复操作。
:::

如果你自行构建了界面，请调用 `.restorePurchases()` 方法：

```typescript showLineNumbers

try {
  const profile = await adapty.restorePurchases();
  const isSubscribed = profile.accessLevels?.['YOUR_ACCESS_LEVEL']?.isActive;
  
  if (isSubscribed) {
    // Restore access to paid features
    console.log('Access restored successfully!');
  } else {
    console.log('No active subscriptions found');
  }
} catch (error) {
  console.error('Failed to restore purchases:', error);
}
```

响应参数：

| 参数 | 描述 |
|---------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **profile** | 一个 [`AdaptyProfile`](https://capacitor.adapty.io/interfaces/adaptyprofile) 对象。该模型包含有关访问等级、订阅和非订阅购买的信息。请检查**访问等级状态**以确定用户是否有权访问应用。 |
