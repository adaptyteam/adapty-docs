这是 Google Play 集成中唯一需要在 Adapty 而非 Google 控制台中完成的步骤。您向 Adapty 提供包名和服务账户密钥文件，Adapty 将使用它们来验证购买并读取您的产品信息。

:::danger
应用上线并集成 Adapty SDK 后，请勿更改包名或密钥文件。这会导致所有已安装该应用的用户购买验证失败。来自不同 Cloud 项目的密钥还会更改主题名称，从而中断实时通知。

另一种情况是密钥已失效。如果服务账号密钥在 Google Cloud 中被删除或轮换，请尽快上传替换密钥：在此之前，产品读取和购买验证将持续失败。请参阅[更新停止接收时的处理方式](store-sync#if-updates-stop-arriving)。
:::

## 开始之前 \{#before-you-start\}

[生成服务账号密钥文件](create-service-account-key-file)。您需要在这里上传该文件。

## 连接应用 \{#connect-the-app\}

1. 打开 [Google Play Console](https://play.google.com/console/)，选择你的应用，并复制其包名。**Dashboard** 页面会在应用名称下方显示包名。

2. 在 Adapty 看板中打开 [**App settings** > **Android SDK**](https://app.adapty.io/settings/android-sdk)。

3. 将包名粘贴到 **Package name** 字段中。

4. 将 JSON 密钥文件上传到 **Service account key file**。

   <ZoomImage id="gp-adapty-android-sdk.webp" width="700px" alt="Android SDK tab of App settings in Adapty, showing the Package name field and the Service account key file upload area" />

5. 点击 **Save**。

保存密钥文件的同时，也会在你的 Cloud 项目中创建 Pub/Sub 主题，下一步需要用到它。

## 后续步骤 \{#next-steps\}

[启用实时开发者通知（RTDN）](enable-real-time-developer-notifications-rtdn)，让 Google Play 将续订、取消和退款事件实时上报给 Adapty。
