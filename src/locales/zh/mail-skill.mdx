adapty-mail 技能让你可以在 AI 编码工具中运行 Adapty Mail 项目。它通过 [Adapty Mail MCP 服务器](mail-mcp) 以你的身份登录并运行。它可以启动流程、翻译营销活动内容、引导你完成发送域名的 DNS 配置与验证、查看营销活动和 A/B 测试结果，以及排查某用户未收到邮件的原因。

The MCP server alone gives your agent the tools. The skill adds what an agent gets wrong without it:

- **连接服务器**：验证服务器是否已连接并登录。如果未连接，会为你提供客户端的配置步骤。
- **邮件还是 Adapty 其他功能**：流程、市场细分和用户画像在 Adapty Mail 与 Adapty 应用内付费墙中含义不同。该技能会在做任何修改前先确认你指的是哪一个。
- **只能在看板中完成的操作**：当请求需要填写公司地址、开启网页结账或数据发送时，它会告知你，并提供相关说明页面的链接。
- **上线后的工作**：效果分析、A/B 测试、送达率以及追踪丢失的邮件。

:::note
没有您的确认，任何内容都不会发送给真实用户。保存流程即开始发送，保存时的市场细分列表将替换整个流程，因此该技能会首先展示流程的完整面貌：每个市场细分、每个活动，以及所有已移除的内容。删除、取消订阅，以及 A/B 测试的启动和结束，同样需要您的确认。
:::

adapty-mail 技能是 [`adapty-skills` 插件](https://github.com/adaptyteam/adapty-skills)的一部分。

## 工作原理 \{#how-it-works\}

1. **连接。** 技能会验证 MCP 服务器是否正常响应，并确认您已登录。
2. **了解现状。** 技能会找到您的项目，并读取已有的配置信息：品牌、公司地址、发送域、活动、流程，以及数据最后到达的时间。它会复用现有内容。
3. **制定计划。** 在开始执行前，技能会列出只能由您在看板中完成的操作。
4. **执行。** 技能通过服务器工具逐步操作，并向您展示每一步的结果。凡是会向真实用户发送邮件或无法撤销的操作，都会等待您的确认。

## 为什么邮件未发送 \{#why-an-email-didnt-send\}

当你询问某个用户时，该技能会读取其用户画像及行为旅程，然后按顺序逐一排查以下原因，找到第一个能解释问题的原因后即停止：

1. 该用户画像已被屏蔽：已退订、邮件退回、投诉举报或地址验证失败。详见[退订与屏蔽](mail-suppression)。
2. 该用户已在另一个营销流程中。
3. 该用户已完成购买，因此序列按预期结束。
4. 在域名预热期间，发送限制导致邮件被延迟。
5. 触发器从未触发。原因可能是没有购买事件到达 Adapty Mail，或者用户画像在设置完成前就已进入。
6. 流程中没有任何市场细分匹配该用户。
7. 双重确认订阅已开启，但该用户尚未确认地址。
8. 该邮件仍在按用户所在时区安排的发送窗口中等待发送。
