当公司被收购、出售应用或调整业务主体时，可将应用转让给新所有者。转让完成后，新所有者需[验证购买是否正常解锁访问权限](#verify-transfer-completed-successfully)。

## 转让应用所有权 \{#transfer-app-ownership\}

:::note
在转让过程中，请勿删除或重新创建产品。在确认转让成功完成之前，请勿更改产品 ID。
:::

针对每个发生变更的账户，请按照相应步骤操作：

- Apple 开发者账户：[App Store (iOS) 转让](#app-store-ios-transfer)
- Google Play 开发者账户：[Google Play (Android) 转让](#google-play-android-transfer)
- 仅 Adapty 账户：[仅限 Adapty 转让](#adapty-only-transfer)

### App Store（iOS）转移 \{#app-store-ios-transfer\}

如果应用迁移到另一个 Apple 开发者账号，新所有者需要在 Adapty 中用自己的凭据替换以下三项：

- 应用内购买密钥
- App Store Connect API 密钥（团队密钥）
- 应用专属共享密钥

应用的 Bundle ID 和在 Adapty 中的通知 URL 保持不变。

转移分为两个阶段：[Apple 完成转移之前](#before-apple-completes-the-transfer)和 [Apple 完成转移之后](#after-apple-completes-the-transfer)。

#### Apple 完成转移之前 \{#before-apple-completes-the-transfer\}

1. **新所有者：** 如果你没有 Adapty 账户，请在 [app.adapty.io](https://app.adapty.io) 创建一个。
2. **旧所有者：** 按照 Apple 的[转让指南](https://developer.apple.com/help/app-store-connect/transfer-an-app/overview-of-app-transfer)在 App Store Connect 中发起应用转让。
3. **旧所有者：** 发送邮件至 [support@adapty.io](mailto:support@adapty.io)，申请在 Adapty 中转让应用。邮件中请注明应用名称以及第 1 步中 Adapty 账户的邮箱地址。之后新所有者可在 Adapty 中填写自己的应用凭据。
4. **新所有者：** 你需要一个应用内购买密钥，以及一个具有 **Admin** 权限的团队密钥（来自你的 App Store Connect 团队）。如果你已有现成的有效密钥文件，直接使用该密钥即可；否则，请在 App Store Connect 中生成[应用内购买密钥](generate-in-app-purchase-key#generate-the-key-in-app-store-connect)或[团队密钥](app-store-connect-api-key#generate-a-team-key-in-app-store-connect)。
5. **新所有者：** 在 App Store Connect 中确认接受转让。Apple 通常在两个工作日内完成转让，届时会通知双方的账户持有人。

#### Apple 完成转让后 \{#after-apple-completes-the-transfer\}

:::warning
Apple 完成转让后，请立即在 Adapty 中保存新的应用内购买密钥。转让完成后，原所有者的密钥将对该应用失效。在 Adapty 没有可用密钥期间，新的购买不会解锁任何访问等级，且应用不会收到任何错误提示。在此期间完成购买的用户，可在[恢复购买](troubleshoot-app-store-integration#a-purchase-succeeds-but-the-customer-loses-access)后获得相应的访问权限。
:::

1. **新所有者：** 在 Adapty 中前往 [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk)。在 **In-app purchase API (StoreKit 2)** 和 **App Store promotional offers** 部分输入新的应用内购买密钥，然后点击 **Save**。
2. **新所有者：** 连接团队密钥，以便 Adapty 保持您的产品与 App Store Connect 同步。如果 **App Store Connect API key** 部分已有密钥，请点击 **Edit**；否则点击 **Connect API Key**，然后输入团队密钥。
3. **新所有者：** 在 App Store Connect 中，打开应用的 **App Information** 页面。确认页面上的 [**Production Server URL** 和 **Sandbox Server URL**](enable-app-store-server-notifications#enter-the-notification-url-in-app-store-connect) 与 Adapty 中的 **URL for App Store server notifications** 一致。
4. **新所有者：** 确认[新密钥正常工作](app-store-connection-configuration#check-each-credential)后，[重新生成应用专属共享密钥](app-store-connection-configuration#enter-the-app-specific-shared-secret)，使旧所有者的副本失效。立即将新密钥粘贴到 Adapty 中，然后点击 **Save**。

### Google Play（Android）转移 \{#google-play-android-transfer\}

如果应用迁移到另一个 Google Play 开发者账号，新所有者需要在 Adapty 中将所有 Google Play 凭据替换为自己的凭据。

1. **新所有者：** 如果还没有 Adapty 账户，请在 [app.adapty.io](https://app.adapty.io) 注册一个。
2. **双方：** 确保两个 Google Play 开发者账户均已完成注册。
3. **原所有者：** 通过 Google Play 控制台或 Google Play 开发者支持提交转让申请。Google 可能会要求提供额外文件，例如 DUNS 编号、合同或销售证明。
4. **新所有者：** 审核并批准转让申请。
5. **Google：** Google 支持团队处理转让事宜，通常需要几个工作日，但具体时长可能因账户验证、订阅复杂程度和支付设置而有所不同。
6. **原所有者：** Google 完成转让后，发送邮件至 [support@adapty.io](mailto:support@adapty.io)，申请在 Adapty 中转移应用。请提供应用名称和新所有者的电子邮件地址。
7. **新所有者：** 在 Adapty 中接收应用后，参照 [Google Play 集成指南](initial-android) 在您的账户下生成并配置所有凭据。

转让内容包括用户、订阅、统计数据、评分和商店列表。现有订阅者的账单连续性将得到保障，但付款将在转让完成后才切换到新所有者的商户账户。转让前的付款报告和订单仍保留在原账户中。详细要求请参阅 Google 的[转让指南](https://support.google.com/googleplay/android-developer/answer/6230247)。

### 仅迁移 Adapty 账号 \{#adapty-only-transfer\}

如果应用只是迁移到另一个 Adapty 账号，所有凭证和通知 URL 均保持不变，无需修改应用商店配置或应用代码。

1. **新所有者：** 如果还没有 Adapty 账号，请在 [app.adapty.io](https://app.adapty.io) 注册一个。
2. **原所有者：** 发送邮件至 [support@adapty.io](mailto:support@adapty.io)，申请在 Adapty 中转移应用。请提供应用名称和新所有者的邮箱地址。

## 验证转移是否成功完成 \{#verify-transfer-completed-successfully\}

转移完成后，新所有者检查应用：

1. **检查看板访问权限**：新所有者应能在其 Adapty 看板中看到该应用。
2. **测试 SDK 连接**：运行应用，确认 Adapty SDK 初始化时无报错。
3. **测试购买**：完成一次[测试购买](validate-test-purchases)，并验证是否成功解锁访问权限。
4. **检查凭证**：对于 App Store，请[验证每个凭证是否正常工作](app-store-connection-configuration#check-each-credential)。对于 Google Play，请在 Adapty 中确认新服务账号连接成功。
5. **检查续订**：转移完成后的几天内，现有订阅者的续订记录应出现在 [**Event feed**](event-feed) 中。
