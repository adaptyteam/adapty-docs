您可以直接在 Adapty 看板中手动调整特定用户的访问等级。这在客户支持场景中尤为实用。例如，您可以为某位用户额外延长一周的高级功能使用时间，以感谢其留下精彩评价。

## 在 Adapty 看板中为特定用户授予访问等级 \{#give-access-level-to-a-specific-customer-in-the-adapty-dashboard\}

1. 从 Adapty 主菜单前往 **[Profiles and Segments](https://app.adapty.io/placements)**。

2. 点击您想要授予访问权限的用户。

3. 点击 **Add access level**。

4. 选择要授予的访问等级，以及该客户的访问等级到期时间。

5. 点击 **Apply**。

## 通过 API 为特定用户授予访问等级 \{#give-access-level-to-a-specific-customer-via-api\}

您也可以使用 Adapty API 从服务器端为用户授予访问等级。当您有推荐奖励或其他与产品相关的活动时，这一功能非常实用。详情请参阅[通过服务端 API 授予访问等级](api-adapty/operations/grantAccessLevel)页面。

## 在后端追踪手动授权 \{#track-manual-grants-on-your-backend\}

如果你的 [webhook 集成](set-up-webhook-integration) 已启用 [Access level updated](webhook-event-types-and-fields#for-access-level-updated-event) 事件，Adapty 会在你手动授予、更新或撤销某个访问等级时发送该事件。

当已授予的访问等级到期时，不会发送任何事件：Adapty 每次请求时都会重新计算访问权限，而非记录状态变更，因此到期不会触发任何事件。如果你的后端需要在访问结束时撤销相应功能，请根据你在授予访问等级时设置的到期日期，提前安排撤销操作。
