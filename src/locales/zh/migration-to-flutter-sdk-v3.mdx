Adapty SDK v3.0 引入了全新的 [Adapty 付费墙编辑工具](adapty-paywall-builder)——这款免代码、用户友好的付费墙创建工具焕然一新。凭借极高的灵活性和丰富的设计能力，您的付费墙将更加高效、更具盈利潜力。

:::info

请注意，AdaptyUI 库已弃用，现已作为 AdaptySDK 的一部分包含在内。

:::

## 移除 AdaptyUI SDK \{#remove-adaptui-sdk\}

1. AdaptyUI 现已成为 Adapty SDK 中的一个模块，请从 `pubspec.yaml` 文件中移除 `adapty_ui_flutter`：

   ```diff showLineNumbers
   dependencies:
   + adapty_flutter: ^3.2.1
   - adapty_flutter: ^2.10.3
   - adapty_ui_flutter: ^2.1.3
   ```

2. 运行：

   ```bash showLineNumbers title="Bash"
   flutter pub get
   ```

## 配置 Adapty SDK \{#configure-adapty-sdks\}

此前，你需要使用 `Adapty-Info.plist` 和 `AndroidManifest.xml` 文件来配置 Adapty SDK。

现在，无需再使用额外的配置文件。你可以在激活时直接传入所有必要参数。

Adapty SDK 只需配置一次，通常在应用生命周期的起始阶段进行。

### 激活 Adapty SDK 的 Adapty 模块 \{#activate-adapty-module-of-adapty-sdk\}

1. 从您的应用中移除 AdaptyUI SDK 导入，如下所示：

   ```diff showLineNumbers
   import 'package:adapty_flutter/adapty_flutter.dart';
   - import 'package:adapty_ui_flutter/adapty_ui_flutter.dart';
   ```

2. 按如下方式更新 Adapty SDK 的激活代码：

   ```diff showLineNumbers
   try {
   -	Adapty().activate();  
   +    await Adapty().activate(
   +        configuration: AdaptyConfiguration(apiKey: 'YOUR_API_KEY')
   +         ..withLogLevel(AdaptyLogLevel.debug)
   +         ..withObserverMode(false)
   +         ..withCustomerUserId(null)
   +         ..withIpAddressCollectionDisabled(false)
   +         ..withIdfaCollectionDisabled(false),
   +   );
   } catch (e) {
       // handle the error
   }
   ```

参数：

| 参数                                | 是否必填 | 描述                                                  |
| ----------------------------------- | -------- | ------------------------------------------------------------ |
| **PUBLIC_SDK_KEY**                  | 必填 | 可在 Adapty 应用设置的 **Public SDK key** 字段中找到：[**App settings**-> **General** tab -> **API keys** subsection](https://app.adapty.io/settings/general) |
| **withLogLevel**                    | 可选 | Adapty 会记录错误及其他关键信息，以便深入了解应用的运行状况。可用的日志级别如下：<ul><li> error：仅记录错误。</li><li> warn：记录错误以及 SDK 发出的不会导致严重问题但值得关注的消息。</li><li> info：记录错误、警告及重要信息（例如各模块生命周期相关的日志）。</li><li> verbose：记录调试时可能有用的所有附加信息，例如函数调用、API 请求等。</li></ul> |
| **withObserverMode**                | 可选 | <p>控制[观察者模式](observer-vs-full-mode)的布尔值。如果您自行处理购买和订阅状态，并使用 Adapty 发送订阅事件和分析数据，请将其开启。</p><p>默认值为 `false`。</p><p></p><p>🚧 在观察者模式下运行时，Adapty SDK 不会关闭任何交易，请确保您自行处理。</p> |
| **withCustomerUserId**              | 可选 | 用户在您系统中的标识符。我们会在订阅和分析事件中发送该标识符，以便将事件归因到正确的用户画像。您也可以在 [**Profiles and Segments**](https://app.adapty.io/profiles/users) 菜单中通过 `customerUserId` 查找用户。 |
| **withIdfaCollectionDisabled**      | 可选 | <p>设置为 `true` 可禁用 IDFA 的收集与共享。</p><p>用户 IP 地址的共享。</p><p>默认值为 `false`。</p><p>有关 IDFA 收集的更多详情，请参阅[分析集成](analytics-integration#disable-collection-of-advertising-identifiers)章节。</p> |
| **withIpAddressCollectionDisabled** | 可选 | <p>设置为 `true` 可禁用用户 IP 地址的收集与共享。</p><p>默认值为 `false`。</p> |

### 激活 Adapty SDK 的 AdaptyUI 模块 \{#activate-adaptyui-module-of-adapty-sdk\}

只有在计划使用[付费墙编辑工具](adapty-paywall-builder)时，才需要配置 AdaptyUI 模块：

```dart showLineNumbers title="Dart"
try {
    final mediaCache = AdaptyUIMediaCacheConfiguration(
        memoryStorageTotalCostLimit: 100 * 1024 * 1024, // 100MB
        memoryStorageCountLimit: 2147483647, // 2^31 - 1, max int value in Dart
        diskStorageSizeLimit: 100 * 1024 * 1024, // 100MB
    );

    await AdaptyUI().activate(
        configuration: AdaptyUIConfiguration(mediaCache: mediaCache),
        observer: <AdaptyUIObserver Implementation>,
    );
} catch (e) {
    // handle the error
}
```

请注意，AdaptyUI 配置是可选的，你可以在不使用配置的情况下激活 AdaptyUI 模块。但如果你使用了配置，则其中所有参数均为必填项。

参数说明：

| 参数                              | 是否必填 | 描述                                              |
| :------------------------------ | :------- | :------------------------------------------------ |
| **memoryStorageTotalCostLimit** | 必填     | 存储的总容量限制，单位为字节。                    |
| **memoryStorageCountLimit**     | 必填     | 内存存储的最大条目数量。                          |
| **diskStorageSizeLimit**        | 必填     | 磁盘存储的文件大小限制，单位为字节。0 表示不限制。 |
