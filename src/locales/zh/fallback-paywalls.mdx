:::important
本文介绍 Adapty SDK v3 及更早版本的备用方案。在 SDK v4 中，单个备用文件同时包含 flow 和付费墙数据——请参阅[备用 flow](fallback-flows)。旧版备用文件格式与 SDK v4 不兼容，因此升级后请下载正确的版本。
:::

为了保持流畅的用户体验，请务必为你的[付费墙](paywalls)和[用户引导](onboardings)设置**备用版本**。

当应用加载付费墙时，Adapty SDK 会向服务器请求付费墙配置数据。但如果设备因网络故障或服务器宕机而无法连接到 Adapty，该怎么办？

* 如果用户之前访问过该付费墙，且设备已缓存其数据，应用将**从缓存**加载付费墙数据。
* 如果设备未缓存该付费墙，应用将查找本地存储的配置文件，使应用能够正常显示付费墙而不会报错。

Adapty 会自动为您生成备用配置文件以供下载和使用。每个文件包含*所有*版位的平台专属配置。

## 开始使用 \{#get-started\}

1. 从 Adapty [下载备用配置文件](/local-fallback-paywalls)。
2. 使用 Adapty SDK 配置你的备用付费墙：
    * [iOS](ios-use-fallback-paywalls)
    * [Android](android-use-fallback-paywalls)
    * [React Native](react-native-use-fallback-paywalls)
    * [Flutter](flutter-use-fallback-paywalls)
    * [Unity](unity-use-fallback-paywalls)
    * [Kotlin Multiplatform](kmp-use-fallback-paywalls)
    * [Capacitor](capacitor-use-fallback-paywalls)

## 限制 \{#limitations\}

备用付费墙是硬编码并存储在本地的，因此不具备常规 Adapty 付费墙的动态能力。

* 备用付费墙不支持[国际化](paywall-localization)。该文件始终使用 `en` 语言环境，因此离线用户只能看到英文内容。[升级到 SDK v4](migration-to-ios-sdk-v4) 可解除此限制——其备用文件包含所有语言环境。
* 每个版位只能有一个备用付费墙。如果你的设置中针对不同[目标受众](audience)配置了不同的付费墙，Adapty 将使用针对"All users"的配置。
* 备用付费墙不支持 [A/B 测试](ab-tests)。如果某个付费墙参与了 A/B 测试，其备用配置文件将包含权重最高的实验变体。
* 备用付费墙无法进行[远程管理](customize-paywall-with-remote-config)。如需更新配置文件，你必须在 App Store / Google Play 上发布新版本的应用。
