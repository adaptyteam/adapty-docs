Flow & Paywall Builder 每次只显示一个页面，因此在包含测验分支的长用户引导中，很难看清每个答案通往何处。[flow-generator 技能](flow-generator-skill) 可以将整个流程绘制成一张地图：按顺序列出每个页面、每条路径，以及每个分叉或终止的位置。

这张地图是一个单独的 HTML 文件，可以直接在浏览器中打开。文件中包含页面预览，因此可以直接发给团队成员，他们无需任何配置即可查看。

:::important
地图是 flow-generator 技能的一部分，无需额外安装——请按照 [flow-generator 安装步骤](flow-generator-skill#install-the-skill)操作。绘制地图仅读取流程数据，不会向看板保存任何内容。
:::

## 功能说明 \{#what-its-for\}

- **发布前检查分支逻辑**：查看每个测验答案跳转到哪个页面，以及各分支在哪里汇合。
- **发现连接错误**：地图会标记出没有任何路径指向的页面，以及没有出路的页面。这两种情况都能通过发布检查，却会让用户在设备上陷入死路。
- **快速了解他人构建的流程**：无需逐屏点击，一眼就能读懂一个包含 20 个页面的用户引导结构。
- **分享结构图**：将文件发送给不使用 Adapty 看板的设计师或产品经理。

## 使用方法 \{#how-to-use-it\}

技能在构建或重新连接包含十个或更多屏幕的流程后，或在添加或更改分支后，会自动打开地图。若要为任意流程打开地图，用日常语言提问即可：

```
How are the screens in my "Sleep onboarding" flow connected?
```

```
Where does the "Not really" button on the Busy mind screen lead?
```

技能会获取流程，渲染每个屏幕，并打开地图。拖动背景或滚动可平移视图，使用 **+** 和 **−** 可缩放，点击 **Fit** 可查看整个流程，点击某个屏幕可将其放大。

## 地图显示的内容 \{#what-the-map-shows\}

屏幕从左到右依次排列，从第一个开始。同一分支并排放置的屏幕位于同一列中。

| 地图上的内容 | 含义 |
| :--- | :--- |
| 灰色箭头 | 不依赖答案的路径。 |
| 带标签的紫色箭头 | 分支的一个情形。标签表示触发该分支的答案，例如 `goal = Falling asleep faster`。**otherwise** 标签表示默认情形。 |
| 虚线箭头 | 返回编号更小的屏幕。 |
| **after timer** 标签 | 该屏幕的[计时器](flow-timer)结束后自动跳转。 |
| **branches** 标签 | 路径在此屏幕处分叉。 |
| **buys**、**restores**、**closes flow**、**back** 标签 | 离开当前屏幕但不打开其他屏幕的操作。 |
| **nothing leads here** 标签 | 没有屏幕会跳转到此屏幕，用户无法到达。 |
| **no way out** 标签 | 没有按钮可以打开其他屏幕、完成购买或关闭流程。仅有 **Back** 按钮不算出口。 |

要高亮显示某个屏幕的路径，将鼠标悬停在该屏幕上即可。其他屏幕和箭头将会淡化。

## 无浏览器模式 \{#without-a-browser\}

如果您的 AI 工具运行在远程机器上，技能会在对话中以文本形式打印相同的地图：

```
◆ Bedtime
    bedtime = After midnight  →  Name
    otherwise  →  Wind-down
    back
▢ Name
    back
    (no way out)
▢ Wind-down
    "Continue"  →  Reaction: wind-down
```

◆ 表示路径分叉的屏幕。`back` 等标签列出了离开当前屏幕但不打开其他屏幕的操作。

## 限制 \{#limitations\}

- **它展示的是配置，而非设备行为**：地图绘制的是流程中定义的路径。若要确认计时器触发或分支在手机上打开的是正确的界面，请使用[设备预览](paywall-device-compatibility-preview)。
- **界面预览与技能预览有相同的限制**：价格显示为变量名，开关显示为关闭状态。详见 [The preview renders one screen, in one state](flow-generator-skill#the-preview-renders-one-screen-in-one-state)。
- **自定义操作止于流程边界**：当按钮触发[**自定义操作**](onboarding-actions#custom-actions)时，地图会在该界面上标注操作 ID。您的应用在响应时打开的界面不属于流程的一部分，因此地图不会显示。
- **地图为只读**：若要修改路径，请向技能发起请求，或在 Flow & Paywall Builder 中编辑流程，然后重新打开地图。
