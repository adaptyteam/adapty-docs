Apple 要求所有新应用及应用更新在 App Store Connect 的 **App Privacy** 部分以及应用清单文件中进行隐私披露。Adapty 是您应用的第三方依赖项，因此您需要披露如何在用户数据方面使用 Adapty。

## Apple 应用隐私清单 \{#apple-app-privacy-manifest\}

[隐私清单文件](https://developer.apple.com/documentation/bundleresources/describing-data-use-in-privacy-manifests)（名为 `PrivacyInfo.xcprivacy`）描述了您的应用使用哪些私人数据以及使用原因。作为应用所有者，您必须为自己的应用创建此清单文件。此外，如果您集成了其他 SDK，请确保那些列在 [需要隐私清单和签名的 SDK](https://developer.apple.com/support/third-party-SDK-requirements/) 列表中的 SDK 的清单文件已包含在内。构建应用时，Xcode 会将所有这些清单文件合并为一个。

尽管 Adapty 并未出现在[需要隐私清单和签名的 SDK 列表](https://developer.apple.com/support/third-party-SDK-requirements/)中，但 2.10.2 及以上版本的 Adapty SDK 已为您内置了隐私清单，方便使用。请确保将 SDK 更新到最新版本以获取该清单。

隐私清单仅用于生成 Xcode 的隐私报告。App Review 会审核您在 [App Store Connect](#apple-app-privacy-disclosure-in-app-store-connect) 中填写的内容，请务必完整填写该部分。

如果您通过 Adapty 的 `customerUserId` 识别用户，请在清单文件中声明该用户 ID：

1. 在隐私信息文件的 `NSPrivacyCollectedDataTypes` 数组中添加一个字典。
2. 向该字典添加 `NSPrivacyCollectedDataType`、`NSPrivacyCollectedDataTypeLinked` 和 `NSPrivacyCollectedDataTypeTracking` 键。
3. 为 `NSPrivacyCollectedDataTypes` 字典中的 `NSPrivacyCollectedDataType` 键添加字符串 `NSPrivacyCollectedDataTypeUserID`（该字符串是 [隐私清单文件中需申报的数据类别与类型列表](https://developer.apple.com/documentation/bundleresources/describing-data-use-in-privacy-manifests#Describe-the-data-your-app-or-third-party-SDK-collects) 中 `UserID` 数据类型的标识符）。
4. 为 `NSPrivacyCollectedDataTypeLinked` 键添加 `true`。为 `NSPrivacyCollectedDataTypeTracking` 键添加 `false`，除非您将用户 ID 用于 [Apple 所定义的跟踪](https://developer.apple.com/app-store/user-privacy-and-data-use/) 目的。
5. 将 `NSPrivacyCollectedDataTypePurposeAppFunctionality` 和 `NSPrivacyCollectedDataTypePurposeAnalytics` 字符串用作 `NSPrivacyCollectedDataTypes` 字典中 `NSPrivacyCollectedDataTypePurposes` 键的值。

如果您将付费墙定向到带有自定义属性的目标受众，请仔细考虑所使用的自定义属性，以及它们是否与[需要在清单文件中上报的数据类别和类型](https://developer.apple.com/documentation/bundleresources/describing-data-use-in-privacy-manifests)相匹配。如果匹配，请对每种数据类型重复上述步骤。

报告完所有数据类型和类别后，按照 [Apple 文档](https://developer.apple.com/documentation/bundleresources/describing-data-use-in-privacy-manifests#Create-your-apps-privacy-report)中的说明创建应用的隐私报告。

### 数据类型 \{#data-types\}

下表列出了 Apple 要求您披露的数据类型，并注明了哪些是 Adapty 所需的。**此处仅涉及 Adapty。** 如果您的应用通过其他 SDK 或自定义代码收集了额外数据，请同时勾选相应的数据类型。

✅ = Adapty 必需

👀 = 可能需要（详见下方说明）

❌ = Adapty 不需要——如果您的应用通过其他方式收集此数据，请自行勾选

| 数据类型 | 必填 | 备注 |
|--------------------------------------------------------------|----------|----------------------------------------------------------------------------------------------------------------------------------------------------|
| 标识符 | ✅ | <p>Adapty 为每次安装生成一个设备 ID 并收集 IDFV，因此您需要选择"Device ID"。</p><p></p><p>如果您使用 customerUserId 识别用户，请选择"User ID"。</p> |
| 购买记录 | ✅ | Adapty 收集用户的购买历史。 |
| 使用数据 | ✅ | Adapty 在用户画像中记录应用打开次数以及付费墙和流程事件，因此您需要选择"Product Interaction"。 |
| 联系信息，包括姓名、电话号码或电子邮件地址 | 👀 | 如果您通过 **`updateProfile`** 方法传递姓名、电话号码或电子邮件地址等个人数据，则为必填项。 |
| 位置 | ❌ | Adapty 不收集精确位置数据。如果您的应用收集此数据，请勾选。 |
| 健康与健身 | ❌ | Adapty 不收集健康或健身数据。如果您的应用收集此数据，请勾选。 |
| 敏感信息 | ❌ | Adapty 不收集敏感信息。如果您的应用收集此数据，请勾选。 |
| 用户内容 | ❌ | Adapty 不收集用户内容。如果您的应用收集此数据，请勾选。 |
| 诊断数据 | ❌ | Adapty 不收集诊断数据。如果您的应用收集此数据，请勾选。 |
| 浏览历史 | ❌ | Adapty 不收集浏览历史。如果您的应用收集此数据，请勾选。 |
| 搜索历史 | ❌ | Adapty 不收集搜索历史。如果您的应用收集此数据，请勾选。 |
| 通讯录 | ❌ | Adapty 不收集联系人列表。如果您的应用收集此数据，请勾选。 |
| 财务信息 | ❌ | Adapty 不收集财务信息。如果您的应用收集此数据，请勾选。 |

Adapty 还会收集设备型号、操作系统版本、语言区域、时区、App Store 店面和用户代理。这些信息不对应任何 Apple 数据类型，因此无需声明。

#### 标识符 \{#identifiers\}

使用 Adapty 时，您必须披露以下标识符：
- **Device ID** — Adapty 会为每次安装生成设备 ID 并收集 IDFV。同时也会收集 IDFA，除非您[禁用 IDFA 收集](analytics-integration#disable-collection-of-advertising-identifiers)。由于每次安装的设备 ID 无法关闭，因此所有情况下都需要声明 **Device ID**。
- **User ID** — 如果您使用 **`customerUserId`** 标识用户，则需要声明此项。

使用 Adapty 时，您必须声明您的应用会收集**产品互动**数据。Adapty 会在用户画像中记录应用打开记录以及付费墙和流程事件。

### 关联与追踪 \{#linking-and-tracking\}

对于每种数据类型，Apple 还会询问该数据是否与用户身份关联，以及是否用于追踪。关于 Adapty，请按以下方式回答：

- **与用户关联**：如果未设置 `customerUserId`，则为**否**。设备 ID 是每次安装时随机生成的标识符，其中不包含任何个人身份信息。如果设置了 `customerUserId`，则所有 Adapty 数据类型均应回答**是**，因为用户 ID 会将所有数据关联到该用户。
- **用于追踪**：**否**。Adapty 不会将此数据用于 [Apple 定义的追踪](https://developer.apple.com/app-store/user-privacy-and-data-use/)。只有当你的应用将该数据用于追踪时，才回答**是**。
