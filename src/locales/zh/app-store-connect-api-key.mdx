Adapty 使用 App Store Connect API 密钥来管理你在 App Store Connect 中的产品：

- [创建产品](create-product#create-product-and-push-to-store)和订阅组。
- 在 Adapty 中添加产品时，通过 ID 查找您的现有产品。
- 在 Adapty 中显示每个产品的 App Store 状态。
- 每日导入价格，并导出您在 Adapty 中所做的价格更改。
- 在[留存消息](retention-messaging-setup)的 Switch Plan 中推荐产品。

Adapty 仅在您在 Adapty 中执行操作时（例如创建产品或更改价格时）才会修改 App Store Connect。显示状态和导入价格时，Adapty 仅从 App Store Connect 读取数据。

在 App Store Connect 的 **Team Keys** 标签页中生成密钥，然后在 Adapty 的 **App settings** 中连接该密钥。如果密钥失效或需要更换，请[替换密钥](#replace-the-key)。

App Store Connect API 密钥与[应用内购买密钥](generate-in-app-purchase-key)不同，但 App Store Connect 对这两种密钥的 ID 标签均显示为 **Issuer ID** 和 **Key ID**。

如需在 **App settings** > **iOS SDK** 中一次性填写所有凭证，请参阅[配置 App Store 集成](app-store-connection-configuration)。

## 替换密钥 \{#replace-the-key\}

如果密钥失效或需要更改 **Access** 设置，请在撤销旧密钥之前先在 Adapty 中连接新密钥。

没有可用的密钥，Adapty 将无法：

- 创建产品。
- 通过 ID 查找已有产品。
- 同步产品状态和价格。

失效的密钥在 Adapty 中仍会显示为已连接。表现为[产品没有 App Store 状态，且 **App Store Product ID** 下拉列表为空](troubleshoot-app-store-integration#products-dont-appear-or-show-no-app-store-status)。

Adapty 不显示已连接密钥的 Key ID。如果不确定 Adapty 当前使用的是哪个密钥，请用新密钥替换它。

当你的应用迁移到其他 Apple 开发者账户时，请[连接新账户的团队密钥](transfer-apps#app-store-ios-transfer)。

替换密钥的步骤：

1. [生成一个新的团队密钥](#generate-a-team-key-in-app-store-connect)。
2. 在 Adapty 中，前往 [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk)。在 **App Store Connect API key** 部分，点击 **Edit**。[填入新密钥的相关信息](#connect-the-key-in-adapty)，然后点击 **Save changes**。
3. 一个团队密钥可供你 App Store Connect 团队下的所有应用使用。如果团队中的其他应用也在使用 Adapty，请为它们同样配置新密钥。同时替换任何服务器上正在使用旧密钥的地方。
4. 被撤销的密钥将立即在所有使用它的应用中失效，且无法恢复。如果你知道新密钥所替换的旧密钥，请前往 App Store Connect 将旧密钥撤销。
