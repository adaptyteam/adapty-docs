Adapty 中的**目标受众**是基于[市场细分](segments)划分的用户群组，帮助你为特定用户群组定制流程、付费墙、用户引导或 A/B 测试。你可以通过筛选条件来定义这些市场细分，确保合适的用户看到合适的流程、付费墙或用户引导。

在 Adapty 中，**版位**是展示流程、付费墙、用户引导或 A/B 测试的位置。当你向版位添加目标受众时，即可针对特定用户群体展示个性化内容。例如，你可以根据用户的年龄、设备、订阅状态或[虚拟货币余额](segments#virtual-currency-balance)来展示不同的流程或付费墙。如果某个用户同时符合多个用户群的条件，你可以设置优先级，决定最终向其展示哪个内容。

在下面的示例中，我们有一个用户引导流程，用于展示标识符为 `Onboarding` 的版位。在你的应用代码中，你将使用此标识符访问该版位。如果用户属于"Yoga beginners"目标受众，他们将看到第一个付费墙。不属于"Yoga beginners"目标受众的用户将看到第二个付费墙。

要向特定目标受众展示流程、付费墙、用户引导或 A/B 测试，请按以下步骤操作：

1. [创建用户市场细分](segments#creation)。如果你希望向所有用户展示该流程、付费墙或 A/B 测试，可以跳过此步骤，直接使用默认创建的"All users"目标受众。
2. [将该市场细分作为目标受众添加到版位，并指定应向其展示哪个流程、付费墙或 A/B 测试](add-audience-paywall-ab-test)。每个版位会自动添加"All users"目标受众，你只需指定应显示哪个流程、付费墙或 A/B 测试。
3. 如果版位中有多个目标受众，请[设置正确的优先级](change-audience-priority)。这可以确保同时属于多个目标受众的用户看到最相关的内容。当用户属于多个目标受众时，将显示优先级最高的目标受众对应的内容。
4. <InlineTooltip tooltip="在移动端应用代码中展示与此版位关联的流程或付费墙">[iOS](ios-quickstart-paywalls)、[Android](android-quickstart-paywalls)、[React Native](react-native-quickstart-paywalls)、[Flutter](flutter-quickstart-paywalls) 和 [Unity](unity-quickstart-paywalls)</InlineTooltip>。

:::note
当 SDK 无法从主 Adapty API 获取流程，转而使用备用服务器或本地备用文件时，用户将看到**All Users**目标受众的内容，无论他们属于哪个市场细分。请确保 All Users 的内容适用于所有用户，例如同时包含两个商店的产品。详见[备用流程](fallback-flows)。
:::
