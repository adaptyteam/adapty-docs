在订阅用户能够看到你的留存消息之前，Apple 需要一种在用户取消订阅时联系 Adapty 的方式。本文介绍如何建立该连接——先在沙盒模式下配置，再切换到生产环境。

## 开始之前 \{#before-you-begin\}

- 在 Adapty 中添加 [App Store Connect API 密钥](app-store-connection-configuration)。Adapty 使用该密钥注册实时 URL 并与 Apple 进行通信。
- 申请加入 [Apple 的留存消息计划](https://developer.apple.com/documentation/retentionmessaging) 并等待 Apple 审批。未获批准时，Apple 会拒绝连接请求。

## 沙盒设置 \{#sandbox-setup\}

Apple 要求你先在沙盒环境中测试连接，以便在发送生产消息之前验证其可靠性。

### 配置沙盒 URL \{#configure-sandbox-url\}

点击 **Configure Sandbox URL** 开始设置。

<ZoomImage id="retention-messaging-configure-sandbox-url.webp" width="700px" alt="Sandbox setup card with the Point your Sandbox URL to Adapty step and the Configure URL button" />

Adapty 会将您的 App Store Connect 账号连接到其自有的实时端点。如果 App Store Connect 中已设置了其他 URL，按钮将显示为 **Replace URL**。

连接成功后，Adapty 会显示"Sandbox URL has been configured."来确认配置完成。

### 测试连接 \{#test-the-connection\}

在发送正式消息之前，Apple 会进行测试，确认 Adapty 能够快速响应其请求。

1. 使用[沙盒账号](test-purchases-in-sandbox)购买其中一个产品。测试需要一笔可以取消的交易。
2. 点击 **Start Test**。测试需要几分钟时间，如果失败可以重试。

<ZoomImage id="retention-messaging-test-sandbox-url.webp" width="700px" alt="Sandbox URL performance test running in the dashboard" />

## 切换到生产环境 \{#switch-to-production\}

完成沙盒环境配置后，Adapty 允许你关闭 **Sandbox mode** 开关，进入生产模式。

<ZoomImage id="retention-messaging-sandbox-mode-toggle.webp" width="700px" alt="The Sandbox mode toggle above the messages table" />

点击 **Configure URL**。Adapty 会将其端点注册到 Apple 的生产环境，并显示"Production URL has been configured."确认消息。如果 App Store Connect 中已设置了不同的生产环境 URL，请改为点击 **Replace URL**。
