当广告将用户引导至落地页或网页漏斗（而非直接跳转至应用商店）时，请为广告 URL 添加标签。如果广告直接跳转到 App Store 或 Google Play，请改用[追踪链接](ua-tracking-links)作为目标地址——链接本身已携带广告活动数据，无需额外添加标签。

Adapty Attribution 从您的落地页 URL 中读取广告系列、广告组和广告信息。广告网络会自动附加其专属点击 ID（`fbclid` 或 `ttclid`），用于识别网络来源，但无法精确识别具体的广告系列、广告组或广告。若要将购买行为归因至具体广告，请在广告中添加追踪参数。

无论您的转化漏斗采用哪种方式——在自有漏斗中使用 [Adapty 网页像素](ua-web-pixel)，还是使用 [FunnelFox](ua-funnelfox)——操作步骤均相同。

## 开始之前 \{#before-you-start\}

将 [Meta Ads](ua-facebook) 或 [TikTok for Business](ua-tiktok) 接入 Adapty 归因，并添加广告系列配置。Adapty 会根据广告系列配置生成广告 URL 参数，因此你需要先创建一个配置，才能从中复制这些参数。

## 为您的广告添加标签 \{#tag-your-ads\}

1. 在广告活动配置的 **Web funnel** 部分，复制 **Ad URL parameters** 字段的值。

<ZoomImage id="ua-web-pixel-url-params.webp" width="700px" alt="Ad URL parameters field in the Web funnel section of a campaign configuration in Adapty Attribution" />

2. 在广告网络中，在**广告**层级粘贴该值：
   - **Meta**：粘贴至广告的 **URL parameters** 字段。
   - **TikTok**：在广告目标 URL 下方，粘贴至 **Build URL parameters**。

该值包含网络宏，网络会在点击时将其替换为实际的广告系列、广告组和广告值。

这些参数不包含 `utm_*` 值，因此你可以继续保留自己的 UTM 方案用于自有分析——Adapty 不要求使用特定格式。
