如果你的广告会将用户引导至落地页或 Web 漏斗，再跳转到应用商店，请为广告 URL 添加标签。如果广告直接跳转至 App Store 或 Google Play，请改用[追踪链接](ua-tracking-links)作为目标地址——链接本身已携带广告系列数据，无需额外打标签。

Adapty Attribution 从您的落地页 URL 中读取广告系列、广告组和广告信息。广告网络会自动附加其专属的点击 ID（`fbclid`、`ttclid` 或 `gclid`），用于识别网络来源，但不包含广告系列、广告组或广告信息。若要将购买归因精确到具体广告，请在广告中添加跟踪参数。

无论您的转化漏斗如何运作——使用自有漏斗上的 [Adapty 网络像素](ua-web-pixel)，还是使用 [FunnelFox](ua-funnelfox)——操作步骤都是一样的。

## 开始之前 \{#before-you-start\}

将 [Meta Ads](ua-facebook)、[TikTok for Business](ua-tiktok) 或 [Google Ads](ua-google-ads) 连接到 Adapty 归因，并添加广告活动配置。Adapty 会根据每个广告活动配置生成广告 URL 参数，因此你需要先创建一个配置才能从中复制参数。

## 标记您的广告 \{#tag-your-ads\}

1. 在广告活动配置的 **Web funnel** 部分，复制 **Ad URL parameters** 字段的值。

<ZoomImage id="ua-web-pixel-url-params.webp" width="700px" alt="Ad URL parameters field in the Web funnel section of a campaign configuration in Adapty Attribution" />

2. 在广告网络中，粘贴以下值：
   - **Meta**：粘贴到广告的 **URL parameters** 字段。
   - **TikTok**：在广告目标 URL 下，粘贴到 **Build URL parameters**。
   - **Google Ads**：在广告系列设置中，粘贴到 **Campaign URL options > Final URL suffix**。此外，还需在 Google Ads 账户设置中开启自动标记功能。

该值包含网络宏，广告网络会在用户点击时将其替换为实际的广告系列、广告组和广告数据。

在广告的目标字段（Meta 中的 **Website URL**、TikTok 中的 **Destination URL**、Google Ads 中的 **Final URL**）中保留落地页或漏斗 URL，无需附加参数。广告网络会在用户点击时自动将参数追加到该 URL，因此你可以随时更换目标 URL，而无需重新标记广告。

这些参数不包含 `utm_*` 值，所以你可以继续使用自己的 UTM 方案用于自有数据分析——Adapty 并不要求使用 UTM。
