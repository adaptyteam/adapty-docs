这是 Adapty 归因分析中可用数据图表的概览。通过本文，你可以了解每项数据图表的含义以及 Adapty 的计算方式。如需查看 Adapty Core 生成的订阅分析数据，请参阅[数据图表对照表](metric-comparison-table)。

:::note
Web 购买没有应用安装事件。Adapty 会按首次试用开始或购买的日期对其进行同期群分析。
:::

| **Spend**                         | 用户每次点击您广告的费用总和。                                                                                                                                                                                                                                                                                                                                                                                                                            | No     |
| **Impressions**                   | 在所选日期范围内，您的广告被展示的次数。                                                                                                                                                                                                                                                                                                                                                                                                                           | No     |
| **Clicks**                        | 在所选日期范围内，用户点击您广告的次数。不含对[自定义追踪链接](ua-tracking-links)的点击。                                                                                                                                                                                                                                                                                                                                                                       | No     |
| **Clicks (attributed)** | Adapty 通过其追踪链接统计的广告点击次数。含对[自定义追踪链接](ua-tracking-links)的点击。 | No |
| **CPI**                           | **CPI（每次安装费用）** 是每次安装所需支付的金额。<br/>**公式**：`Spend / Installs`                                                                                                                                                                                                                                                                                                                                         | No     |
| **CPC**                           | **CPC（每次点击费用）** 是每次点击广告所需支付的金额。<br/>**公式**：`Spend / Clicks`                                                                                                                                                                                                                                                                                                                                                    | No     |
| **CPM**                           | **CPM（千次展示费用）** 是每一千次广告展示所需支付的金额。<br/>**公式**：`Spend / (Impressions / 1000)`                                                                                                                                                                                                                                                                                                                                | No     |
| **ICR**                           | **ICR（安装转化率）** 是广告点击中转化为安装的百分比。<br/>**公式**：`(Installs / Clicks) × 100%`                                                                                                                                                                                                                                                                                                                                      | No     |
| **ICR (attributed)** | **Clicks (attributed)** 中转化为安装的百分比。<br/>**公式**：`(Installs / Clicks (attributed)) × 100%` | No |
| **IPM**                           | **IPM（千次展示安装数）** 表示每一千次广告展示带来的安装数量。<br/>**公式**：`(Installs / Impressions) × 1000`                                                                                                                                                                                                                                                                                                                                             | No     |
| **CTR**                           | **CTR（点击率）** 是展示次数中产生点击的百分比。<br/>**公式**：`(Clicks / Impressions) × 100%`                                                                                                                                                                                                                                                                                                                                        | No     |
| **Inline link clicks**            | 用户点击广告素材或应用页面内嵌链接的次数。                                                                                                                                                                                                                                                                                                                                                                | No     |
| **Avg cost per inline link click** | 每次内嵌链接点击的平均费用。<br/>**公式**：`Spend / Inline link clicks`                                                                                                                                                                                                                                                                                                                                                | No     |
| **Inline link click through rate**         | 展示次数中产生内嵌链接点击的百分比。<br/>**公式**：`(Inline link clicks / Impressions) × 100%`                                                                                                                                                                                                                                                                                                                                | No     |
| **Installs**                      | 在所选日期范围内，用户安装您应用的总次数。每次重新安装均计为一次新安装，并拥有独立的归因。                                                                                                                                                                                                                                                                                                                                                           | No     |
| **Payers** | 用户直接开启或通过试用期转化后开启的付费订阅数量。<br/>**公式**：`Subscriptions started + Trial converted` | Yes |
| **Total revenue**                 | 在所选日期范围内安装应用的用户迄今为止产生的总收入。如需在毛收入与净收入之间切换，请使用 [Adapty Attribution 分析](ua-analytics#gross-revenue-or-proceeds)中的收入下拉菜单。                                                                                                                                                                                                                                                                  | No     |
| **Revenue** | 在所选日期范围内安装应用的用户，在安装后同期群周期内产生的收入，例如 **D7 Revenue** 对应安装后 7 天。如无需同期群周期，请使用 **Total revenue**。 | Cohorts only |
| **ROAS**                          | **ROAS（广告支出回报率）** 是广告收入除以广告支出所得的百分比。<br/>**公式**：`(Total revenue / Spend) × 100%（Spend > 0 时），否则为 0%`                                                                                                                                                                                                                                                            | Yes    |
| **AdProfit** | 收入减去广告支出的差值。<br/>**公式**：`Total revenue − Spend` | Yes |
| **ARPU** | **ARPU（每用户平均收入）** 是每次安装的平均收入。<br/>**公式**：`Total revenue / Installs` | Yes |
| **ARPPU** | **ARPPU（每付费用户平均收入）** 是每位付费用户的平均收入。<br/>**公式**：`Total revenue / Paying users`。`Paying users` 是实际付费用户数，而 **Payers** 是付费订阅数量。 | No |
| **ARPAS** | **ARPAS（每活跃订阅者平均收入）** 是每个已开启订阅或试用的平均收入。<br/>**公式**：`Total revenue / (Subscriptions started + Trial started)` | Yes |
| **ARPT** | **ARPT（每试用平均收入）** 是每次试用开启的平均收入。<br/>**公式**：`Total revenue / Trial started` | Yes |
| **Cost per trial**                | 每次试用开启的平均费用。<br/>**公式**：`Spend / Trial started`                                                                                                                                                                                                                                                                                                                                                   | No     |
| **Cost per subscription**         | 每次订阅开启的平均费用。<br/>**公式**：`Spend / Subscriptions started`                                                                                                                                                                                                                                                                                                                           | No     |

## 事件数据图表 \{#event-metrics\}

事件数据图表统计在所选日期范围内安装的用户的订阅和购买事件。每个事件包含两个数据图表：

- **Count**：事件发生的次数。
- **Rate**：次数占安装量的百分比。**公式**：`(Count / Installs) × 100%`

你可以添加带或不带同期群周期的所有事件数据图表。

| 事件 | 数量数据图表 | 比率数据图表 |
|---|---|---|
| 用户开始付费订阅（无试用期）。 | **Subscriptions started** | **Rate subscription started** |
| 订阅已续期。 | **Subscription renewed** | **Rate subscription renewed** |
| 用户关闭了订阅的自动续期。 | **Subscription renewal cancelled** | **Rate subscription renewal cancelle** |
| 用户重新开启了订阅的自动续期。 | **Subscription renewal reactivated** | **Rate subscription renewal reactivated** |
| 订阅到期且未续期。 | **Subscription expired** | **Rate subscription expired** |
| 用户在 Android 上暂停了订阅。 | **Subscription paused** | **Rate subscription paused** |
| 应用后端[延期支付](https://adapty.io/glossary/subscription-purchase-deferral/) Google Play 订阅。 | **Subscription deferred count** | **Rate subscription deferred** |
| 商店退款了一笔订阅购买。 | **Subscription refunded** | **Rate subscription refunded** |
| 用户就订阅付款向银行发起了争议。 | **Subscription chargeback** | **Rate subscription chargeback** |
| 银行将有争议的订阅付款退还给了您。 | **Subscription chargeback reversed** | **Rate subscription chargeback reversed** |
| 用户开始了免费试用。 | **Trial started** | **Rate trial started** |
| 试用转化为付费订阅。 | **Trial converted** | **Rate trial converted** |
| 用户在试用期间关闭了自动续期。 | **Trial renewal cancelled** | **Rate trial renewal cancelled** |
| 用户在试用期间重新开启了自动续期。 | **Trial renewal reactivated** | **Rate trial renewal reactivated** |
| 试用结束且未转化为付费订阅。 | **Trial expired** | **Rate trial expired** |
| 商店无法向用户收费，例如余额不足。 | **Billing issue detected** | **Rate billing issue detected** |
| 由于账单问题，订阅进入宽限期。 | **Entered grace period** | **Rate entered grace period** |
| 用户进行了一次性购买。 | **Non-subscription purchase** | **Rate non-subscription purchase** |

| 银行将有争议的一次性购买付款退还给了您。 | **Non-subscription purchase chargeback reversed** | **Rate non-subscription purchase chargeback reversed** |

## Google Ads 数据图表 \{#google-ads-metrics\}

Google Ads 会自行上报这些数据图表，因此仅在 Google Ads 行中可见。其他广告网络的行显示"—"。如需一次性将大多数此类列添加到表格中，请选择 [Google Ads 预设](ua-analytics#google-ads-preset)。

| **数据图表** | 描述 | 同期群 |
|---|---|---|
| **Conversions (Network)** | Google Ads 按点击日期统计的转化数，对应您 Google Ads 账户中的转化操作。这是 Google 的数据，并非 Adapty 的试用或购买数据，两者不一致。 | 否 |
| **All Conv. (Network)** | Google Ads 按点击日期统计的所有转化数。Google Ads 在其 **All conv.** 列中显示该数值。 | 否 |
| **Cost per Conversion (Network)** | Google Ads 报告的每次转化平均花费。仅统计有转化记录的行的花费。<br/>**公式**: `Spend / Conversions (Network)` | 否 |
| **First Page Bid Est.** | Google 对在搜索结果首页展示广告所需出价的估算值。 | 否 |
| **First Position Bid Est.** | Google 对在搜索结果首页首位展示广告所需出价的估算值。 | 否 |
| **Status** | 该行的广告系列、广告组、广告或关键词在 Google Ads 中的状态：**Enabled**、**Paused** 或 **Removed**。 | 否 |

### 转化率 \{#conversions\}

Adapty 会对每天的转化数据刷新 3 天，之后保持不变。Google Ads 会持续将延迟转化追加到过去的点击日期，因此在 Adapty 中，较早的日期显示的转化数可能少于 Google Ads 中的数据。Adapty 不会导入开始收集数据之前的转化记录，因此这些日期显示为"—"。

### 出价估算 \{#bid-estimates\}

出价估算列仅在按关键词分组时才会出现在表格中。对于每个关键词，Adapty 会显示 Google 针对所选日期范围内该关键词最近一个有流量的日期的估算值。

Google 不为展示广告和应用广告关键词提供出价估算。对于采用自动出价策略（如 **Maximize clicks**、**Maximize conversions** 或 **Target CPA**）的广告系列中的搜索关键词，也不会提供出价估算。这些关键词会显示"—"。

### 状态 \{#status\}

Adapty 每天更新一次状态。当以下两个条件同时满足时，行中才会显示状态：

- 表格按广告活动、广告组、广告或关键词分组。
- 该行在所选日期范围内有 Google Ads 支出。

如果多个 Google Ads 广告活动同名，只要其中有任意一个处于启用状态，该行就显示 **Enabled**。否则，若有任意一个处于暂停状态则显示 **Paused**，若全部已被移除则显示 **Removed**。

## 预测数据图表 \{#predicted-metrics\}

预测数据图表基于应用自身的历史数据，对同期群的未来表现进行预测，因此也涵盖自然流量安装。预测数据图表支持多个同期群周期，包括 D30、D60、D90、D180 和 D360，以及你自定义添加的天数周期。有关这些数值的计算方式，请参阅 [Adapty 归因中的预测数据图表](ua-predicted-metrics)。

| **数据图表**    | 描述                                                                                                                                                                                | <InlineTooltip tooltip="同期群支持">同期群周期将数据图表限定在安装后的特定天数内，例如 D7 ROAS 对应 7 天。</InlineTooltip> |
|---------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---:|
| **pRevenue**  | 预测同期群在目标时间范围内的总收入。根据应用的历史同期群留存率建模。                                                        | 仅限同期群 |
| **pROAS**     | 预测在相同时间范围内的广告支出回报率。**计算公式**：`(pRevenue / Spend) × 100%`。对于没有支出数据的行（如 **Organic**），Adapty 不计算该值。                     | 仅限同期群 |
| **pAdProfit** | 预测在该时间范围内扣除广告支出后的净收入。**计算公式**：`pRevenue − Spend`                                                                                                        | 仅限同期群 |
| **pARPU**     | 预测在该时间范围内每次安装的平均收入（即预测 LTV）。**计算公式**：`pRevenue / Installs`                                                                                                 | 仅限同期群 |
| **pARPPU**    | 预测在该时间范围内每位付费用户的平均收入。**计算公式**：`pRevenue / paying users at d{N}`，其中 `d{N}` 与所选时间范围对应。                                     | 仅限同期群 |
