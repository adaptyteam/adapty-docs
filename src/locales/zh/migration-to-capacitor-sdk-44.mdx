Adapty Capacitor SDK 4.4 更改了备用付费墙文件格式，iOS 流程需要 iOS 16，并在 Android 上将流程脚本错误上报给您的应用。在 4.4 版本中，`AdaptyPrice.currencyCode`、`AdaptyPrice.localizedString` 和 `AdaptySubscription.billingPlan` 在 TypeScript 中不再是可选类型。要将应用升级到 4.4，请安装最新的 `@adapty/capacitor` 包，并在同一构建中替换两个备用付费墙文件。旧版本的 SDK 不支持新文件。请参阅本指南中的其他更改内容。

如果您仍在使用 4.2 或更早版本，请先参阅[迁移至 v4.3](migration-to-capacitor-sdk-43)，再按本指南操作。

:::warning
备用付费墙文件格式在 4.4 版本中已更改，编译器无法检测适用于 SDK 4.1–4.3 的备用文件。如果不[更新备用文件](#replace-the-fallback-files)，每个版位都将失去其备用付费墙。
:::

## 快速参考 \{#quick-reference\}

| v4.3 | v4.4 |
|---|---|
| 备用文件适用于 4.1–4.3 版本下载 | 备用文件格式已更新；请重新下载两个文件 |
| 流程支持在 iOS 15 上打开 | 流程需要 iOS 16 |
| 在 Android 上，SDK 仅记录流程脚本错误 | 错误会以 `jsException` 的形式传递至 `onError` |
| `AdaptyPrice.currencyCode`、`AdaptyPrice.localizedString` 和 `AdaptySubscription.billingPlan` 为可选项 | 它们现在为必填项 |

## 安装 \{#installation\}

更新 `@adapty/capacitor` 包，并同步原生项目：

```bash showLineNumbers
npm install @adapty/capacitor@latest
npx cap sync
```

环境要求不变：**iOS 15.0** 和 **Capacitor 8**。流程功能例外：请参阅 [流程需要 iOS 16](#flows-require-ios-16)。完整配置说明请参阅[安装 Adapty SDK](sdk-installation-capacitor)。

## 替换备用文件 \{#replace-the-fallback-files\}

要重新下载[备用文件](capacitor-use-fallback-paywalls)，请在 **[Placements](https://app.adapty.io/placements)** 中点击 **Fallbacks** > **Download iOS Fallback**。在 **Adapty SDK v4.4.0 and higher** 行，点击 **Download**。再以同样方式操作 **Download Android Fallback**。

下载的文件名为 `ios_4_4_0_fallback.json` 和 `android_4_4_0_fallback.json`。请用它们替换 SDK 4.1–4.3 的备用文件，使用方式与[使用备用付费墙](capacitor-use-fallback-paywalls)中描述的相同：

- **iOS**：将文件添加到您的 Xcode 项目中。
- **Android**：将文件放入 Android 备用付费墙文件（适用于 4.1–4.3 版本）所在的文件夹中。

为每个文件命名时，请使用您的应用传递给 `adapty.setFallback` 的名称，或在该调用中更新文件名。

如果使用的是 SDK 4.1–4.3 的备用付费墙文件，`adapty.setFallback` 会抛出 `AdaptyError`。要验证新文件是否正确，请分别在 iOS 和 Android 上运行应用，并确认该调用不再抛出错误。

## 流程需要 iOS 16 \{#flows-require-ios-16\}

从 4.4 版本开始，流程需要 iOS 16 或更高版本。其他 SDK 功能（如购买和自定义付费墙）仍可在 iOS 15 上正常使用。

在 iOS 15 上，`createFlowView` 会抛出带有 `platformNotSupported` 错误码的 `AdaptyError`。当您的应用收到此错误时，请改为展示您自己的内容，例如[自定义付费墙](capacitor-implement-paywalls-manually)。

## Android 上的流程脚本错误会触发 `onError` \{#flow-script-errors-reach-onerror-on-android\}

在 Android 上，流程脚本在处理 SDK 事件时可能抛出异常。从 4.4 版本开始，该异常会以 `jsException` 错误码封装为 `AdaptyError` 传递给 `onError` 处理器，行为与 iOS 保持一致。此前，SDK 仅会记录日志而不会向上传递该异常。

如果未设置 `onError`，流程将在此错误发生时关闭。若希望保持流程继续运行，请设置 `onError`，并在该错误时返回 `false`。

## 价格和订阅属性现为必填项 \{#price-and-subscription-properties-are-required\}

在 TypeScript 中，`AdaptyPrice.currencyCode`、`AdaptyPrice.localizedString` 和 `AdaptySubscription.billingPlan` 不再是可选属性。如果你的代码中创建了这些对象（例如测试中的 mock），请为其设置这些属性。

在 4.4 版本中，每个订阅的 `billingPlan` 均为 `up_front`，除非用户购买了[承诺计划](set-up-12-month-commitment)。在 4.4 之前，只有 App Store 订阅才有 `billingPlan`。
