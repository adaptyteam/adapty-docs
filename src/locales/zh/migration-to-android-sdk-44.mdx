要将您的应用从 Adapty Android SDK 4.1、4.2 或 4.3 升级到 4.4，请将 `adapty-bom` 版本设置为 `4.4.0`，并在同一次构建中替换备用文件。SDK 4.1–4.3 版本不兼容新文件格式。如果您的 Java 代码调用了 `AdaptyFlowView.showFlow`，需要为每处调用添加一个参数。如果应用当前使用的是 4.0，请先完成 [v4.1 变更](migration-to-android-sdk-41)。

:::warning
4.4 版本的备用文件格式已发生变更，编译器无法检测到过时的文件。如果不[替换备用文件](#replace-the-fallback-file)，所有版位都将失去备用付费墙。
:::

## 替换备用文件 \{#replace-the-fallback-file\}

要重新下载[备用文件](fallback-flows)，请在 **[Placements](https://app.adapty.io/placements)** 中点击 **Fallbacks** > **Download Android Fallback**。在 **Adapty SDK v4.4.0 and higher** 一行，点击 **Download**，然后将文件打包到应用中。

下载的文件名为 `android_4_4_0_fallback.json`。请将其重命名为应用加载时所使用的文件名，或在加载该文件的调用中更新文件名：

- **`FileLocation.fromAsset`**：文件名，例如 `android_fallback.json`。
- **`FileLocation.fromResId`**：资源名称，例如 `R.raw.android_fallback` 中的 `android_fallback`。

如果文件版本过时，`Adapty.setFallback` 会在回调中返回一个 `AdaptyError`，错误信息为"The fallback file version is not correct. Download a new one from the Adapty Dashboard."。要验证新文件是否有效，请运行应用并确认该回调没有返回错误。回调是可选的。如果不使用回调，请将 [`Adapty.logLevel`](sdk-installation-android#logging) 属性设置为 `AdaptyLogLevel.ERROR` 或更详细的级别，然后确认 Logcat 中没有出现该错误。

## 在 Java 中为 showFlow 调用添加参数 \{#add-an-argument-to-showflow-calls-in-java\}

在 4.4 版本中，`AdaptyFlowView.showFlow` 新增了一个末尾参数 `customElementsResolver`。Java 代码必须传入 `showFlow` 的所有参数，因此传入八个参数的调用将无法编译。请将 `null` 作为最后一个参数传入：

```diff showLineNumbers
  flowView.showFlow(flowConfiguration, products, eventListener, insets,
-         customAssets, tagResolver, timerResolver, observerModeHandler);
+         customAssets, tagResolver, timerResolver, observerModeHandler, null);
```

Kotlin 中对 `showFlow` 的调用以及所有对 `AdaptyUI.getFlowView` 的调用均无需修改即可编译通过。
