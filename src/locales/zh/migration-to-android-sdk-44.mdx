如需将应用从 Adapty Android SDK 4.1、4.2 或 4.3 升级至 4.4，请将 `adapty-bom` 版本设置为 `4.4.2`，并在同一构建版本中替换备用文件。SDK 版本 4.1–4.3 不支持新文件。如果应用当前使用 4.0 版本，请先参照 [v4.1 变更说明](migration-to-android-sdk-41) 完成升级。若需继续升级至 4.5，请参阅[迁移至 v4.5](migration-to-android-sdk-45)。

:::warning
备用文件格式在 4.4 版本中发生了变化，编译器无法检测过时的文件。如果不[更新备用文件](#replace-the-fallback-file)，所有版位都将失去其备用付费墙。
:::

## 替换备用文件 \{#replace-the-fallback-file\}

要重新下载[备用文件](fallback-flows)，请在 **[Placements](https://app.adapty.io/placements)** 中点击 **Fallbacks** > **Download Android Fallback**。在 **Adapty SDK v4.4.0 and higher** 一行，点击 **Download**，然后将文件打包到应用中。

下载的文件名为 `android_4_4_0_fallback.json`。请将其重命名为应用加载时所使用的文件名，或在加载该文件的调用中更新文件名：

- **`FileLocation.fromAsset`**：文件名，例如 `android_fallback.json`。
- **`FileLocation.fromResId`**：资源名称，例如 `R.raw.android_fallback` 中的 `android_fallback`。

如果文件版本过旧，`Adapty.setFallback` 会在回调中返回一个 `AdaptyError`，提示信息为："The fallback file version is not correct. Download a new one from the Adapty Dashboard."。要验证新文件是否有效，请运行应用并确认回调未收到任何错误。回调是可选的。若不使用回调，请将[日志级别](sdk-installation-android#logging)设置为 `AdaptyLogLevel.ERROR` 或更详细的级别，然后确认 Logcat 中没有出现此错误。
