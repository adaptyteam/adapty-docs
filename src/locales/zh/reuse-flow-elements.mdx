应用中的大多数付费墙都共用相同的模块：套餐选择、试用时间线、对比区块。在每个流程中手动重建这些模块既费时，复制出来的版本也容易出现差异。[flow-generator 技能](flow-generator-skill)可以将流程中的任意片段保存为文件，并将其添加到另一个流程中——无论是同一应用还是不同应用——同时自动解析该片段所依赖的颜色、字体、图标和产品绑定。

保存的文件是纯 JSON 格式。你可以将它放在应用代码旁边、提交到版本库，或者分享给团队成员。

:::important
这是流程生成技能的一部分，无需额外安装——按照[流程生成技能的安装步骤](flow-generator-skill#install-the-skill)操作即可。它会将更改保存到你看板中的流程，因此请先在草稿上运行，并在付费墙编辑工具中检查结果后再发布。
:::

## 它的用途 \{#what-its-for\}

- **团队真正共享的组件库。** 只需保存一次方案选择，之后每个新流程都能直接使用真实内容，而不是近似替代。
- **改一处，处处生效。** 在某个流程中修正试用期时间线，保存后添加到其他流程即可。
- **将已验证的模块迁移到新应用。** 在一个应用中转化效果好的模块，可以作为下一个应用的合理起点，该功能会自动将产品重新绑定到目标应用的产品目录。
- **保持统一的设计规范。** 仅保存颜色和文字样式（不含任何元素），然后应用到其他流程。

## 使用方法 \{#how-to-use-it\}

用自然语言提问，技能会处理剩下的一切。

### 保存流程的某个部分 \{#save-a-piece-of-a-flow\}

```
Save the plan selection from my Premium paywall so I can reuse it.
```

该技能会写入一个文件并打印其完整路径，让你始终知道要提交或发送哪个文件。它还会汇总写入内容——包括元素数量，以及其中包含的颜色、文字样式、分组和产品数量。

它只会问一个问题：你是否打算在同一个应用内复用，还是在任何地方都能用。无论如何选择，文件都是完整的，答错了也没有任何损失。

你可以保存一个元素及其内部所有内容、整个页面、可复用的组件，或者单独的主题。

### 将其添加到另一个流程 \{#add-it-to-another-flow\}

```
Add the two-plan selection to my onboarding paywall, above the CTA.
```

在执行任何操作之前，该功能会先展示一个方案：精确显示模块的落点位置、新增内容、从目标位置继承的颜色和文字样式，以及为避免冲突需要重命名的 ID。同时还会打印出导入的文案内容，方便你检查是否有属于旧流程的文字被一并带入。

Anything it can't resolve by itself — a product missing from this app's catalog, a
variable with no source here — is listed separately, as something for you to finish
rather than something it guessed at.

Read the plan, then say go. The skill writes the draft and renders the screen so you can
see the result.

## 工作原理 \{#how-it-works\}

保存的元素很少单独存在。它会指向流程中其他地方定义的颜色、文字样式、字体、图标、产品和变量。这项功能将这些依赖项分为两类。

**可随文件携带的内容。** 颜色、文字样式、字体和图标会连同其定义一起打包到文件中。在目标位置：

| 目标位置 | 处理方式 |
| :--- | :--- |
| 已有同名且含义相同的定义 | 直接复用 |
| 同名但含义不同 | **采用目标位置的值**，并告知你 |
| 从未有过该定义 | 从文件中添加该定义 |

采用目标位置的值通常正是你想要的效果：将卡片移入另一个应用时，它应该呈现出该应用的风格。方案中会同时显示两个值，因此你可以根据需要覆盖该选择。

**它无法处理的内容。** 产品 ID、变量来源、**Navigate to screen** 的目标——这些都指向某个流程或应用中的具体元素。该技能会尽力重新绑定它们，对于无法处理的部分，会在 `NEEDS YOU` 下列出，而不是随意猜测。

在草稿保存之前，该技能会重新检查整个流程：每个引用都能正确解析，每个语言版本都已填充，没有 ID 冲突，且结果仍能通过发布检查。所有遗留问题都会明确披露，不会悄悄修正。

## 需要检查的内容 \{#what-to-check\}

- **文案应与产品匹配。** 在原流程中读起来顺畅的内容块，放到目标流程后可能就不对了。执行计划会在 `WILL SAY` 下打印导入的文本，方便你在写入前进行核对。
- **价格是变量，而非固定文本。** 如果目标流程中没有某个价格所对应的产品，该价格将显示为空。执行计划会对此进行提示。
- **元素尺寸可能依赖于上下文。** 一个填满原容器的元素，放到新容器中可能会被拉伸变形。渲染预览能帮你发现这类问题。

## 限制 \{#limitations\}

- **产品不会自动跨应用迁移。** 该技能会将你的商店产品 ID 与目标应用进行匹配重新绑定，如果某个产品在目标应用中不存在，它会解除绑定并提示你手动关联。
- **视频和自定义字体需手动处理。** 两者均无法通过终端上传。
- **预览仅渲染单个屏幕的单一状态。** 语言切换或选中状态不会在预览中显示——请查阅方案说明了解详情。
