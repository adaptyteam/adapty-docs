在观察者模式下，Adapty SDK 无法自动跟踪通过您现有购买系统完成的购买。您需要从应用商店上报交易。在发布应用之前，务必完成此设置，否则会导致分析数据出错。

使用 `reportTransaction` 显式上报每笔交易，以便 Adapty 识别。

:::warning

**不要跳过交易上报！**
如果不调用 `reportTransaction`，Adapty 将无法识别该交易，它既不会出现在分析数据中，也不会发送到集成渠道。

:::

如果你使用 Adapty 流程和付费墙，请在上报交易时传入 `variationId`。这样可以将购买行为与触发它的流程或付费墙关联起来，确保分析数据的准确性。

```dart showLineNumbers
try {
    // every time when calling transaction.finish()
    await Adapty().reportTransaction(
        transactionId: "YOUR_TRANSACTION_ID",
        variationId: "PAYWALL_VARIATION_ID", // optional
    );
} on AdaptyError catch (adaptyError) {
    // handle the error
} catch (e) {
    // handle the error
}
```

参数：

| 参数          | 是否必填 | 描述                                                         |
| ------------- | -------- | ------------------------------------------------------------ |
| transactionId | 必填     | <ul><li>iOS：交易的标识符。</li><li>Android：购买的字符串标识符 `purchase.getOrderId`，其中 purchase 是计费库 [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) 类的实例。</li></ul> |
| variationId   | 选填     | 实验变体的字符串标识符。可通过 [AdaptyPaywall](https://pub.dev/documentation/adapty_flutter/3.17.2/adapty_flutter/AdaptyPaywall-class.html) 对象的 `variationId` 属性获取。 |

</TabItem>

在观察者模式下，Adapty SDK 无法自动跟踪通过您现有购买系统完成的购买。您需要从应用商店上报或恢复交易。在发布应用之前，务必完成此设置，否则会导致分析数据出错。

在两个平台上均使用 `reportTransaction` 显式上报每笔交易，并在 Android 上额外调用 `restorePurchases`，以确保 Adapty 能够识别该交易。

:::warning

**不要跳过交易上报和购买恢复！**
如果不调用这些方法，Adapty 将无法识别该交易，它不会出现在分析报告中，也不会发送到各集成渠道。

:::

如果你使用 Adapty 流程和付费墙，请在上报交易时包含 `variationId`。这会将购买行为与触发它的流程或付费墙关联起来，从而确保分析数据的准确性。

```dart showLineNumbers
// every time when calling transaction.finish()
if (Platform.isAndroid) {
    try {
        await Adapty().restorePurchases();
    } on AdaptyError catch (adaptyError) {
        // handle the error
    } catch (e) {
    }
}

try {
    // every time when calling transaction.finish()
    await Adapty().reportTransaction(
        transactionId: "YOUR_TRANSACTION_ID",
        variationId: "PAYWALL_VARIATION_ID", // optional
    );
} on AdaptyError catch (adaptyError) {
    // handle the error
} catch (e) {
    // handle the error
}
```

参数：

| 参数          | 是否必需 | 描述                                                         |
| ------------- | -------- | ------------------------------------------------------------ |
| transactionId | 必需     | <ul><li>iOS，StoreKit 1：[SKPaymentTransaction](https://developer.apple.com/documentation/storekit/skpaymenttransaction) 对象。</li><li>iOS，StoreKit 2：[Transaction](https://developer.apple.com/documentation/storekit/transaction) 对象。</li><li>Android：字符串标识符（purchase.getOrderId，其中 purchase 是账单库 [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) 类的实例）。</li></ul> |
| variationId   | 可选     | 实验变体的字符串标识符。可通过 [AdaptyPaywall](https://pub.dev/documentation/adapty_flutter/3.17.2/adapty_flutter/AdaptyPaywall-class.html) 对象的 `variationId` 属性获取。 |

**将流程和付费墙关联到交易**

Adapty SDK 无法确定购买来源，因为购买由您自行处理。因此，如果您打算在观察者模式下使用流程、付费墙和/或 A/B 测试，您需要在移动应用代码中将来自应用商店的交易与对应的流程或付费墙关联起来。在发布应用之前务必正确完成这一步，否则会导致分析数据出现错误。

```dart
final transactionId = transaction.transactionIdentifier
final variationId = paywall.variationId

try {
  await Adapty().setVariationId('transactionId', variationId);
} on AdaptyError catch (adaptyError) {
  // handle the error
} catch (e) {
}
```
