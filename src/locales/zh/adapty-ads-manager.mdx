**Adapty Ads Manager** 是一款一体化平台，专为帮助您更高效地管理、优化和扩展 Apple Ads 广告系列而设计。它将您的 Apple Search Ads 效果数据与关键收入指标（如安装量、试用、订阅和用户生命周期价值）连接起来，无需借助 MMP。

借助实时分析、AI 驱动的预测和智能自动化，Adapty Ads Manager 消除了繁琐的人工出价调整、电子表格操作和凭感觉猜测，取而代之的是清晰的洞察和帮助您快速采取行动的工具。

使用 Adapty Ads Manager，您将获得：

- **[概览](ads-manager-overview)**：一览所有核心数据——花费、收入、ROAS、CPA 等——每项均配有每日趋势数据图表
- **[AI 智能体](ads-manager-ai-agent)**：用自然语言提问，获取完整漏斗分析和优化建议
- **实时效果数据**：覆盖广告系列、广告组和关键词
- **端到端收入追踪**：从搜索 → 安装 → 试用 → 订阅 → LTV
- **AI 趋势预测与建议**：助力盈利性规模扩张
- **批量管理**：出价、预算、状态和结构
- **[基于规则的自动化](ads-manager-automations)**：管理关键词全生命周期
- **[市场洞察](ads-manager-market-intelligence)**：覆盖 50+ 个国家的竞争对手关键词策略
- **[关键词建议工具](ads-manager-keyword-suggester)**：针对任意种子词提供相关搜索词及 Apple 类目上下文
- **[搜索热度](ads-manager-search-popularity)**：在选定市场、类目和时段内排名最高的 App Store 搜索词
- **[CPP A/B 测试](ads-manager-cpp-ab-tests)**：并排对比自定义产品页面，找出最佳方案
- **[CLI](developer-cli-ads-manager)**：从终端管理广告系列、关键词和自动化规则，并通过 [Apple Ads 插件](developer-cli-ads-manager-skill)让 AI 编程工具读取你的数据并执行操作

## 为什么选择 Adapty Ads Manager？\{#why-choose-adapty-ads-manager\}

因为我们为您提供**市场上最精准的数据**。

与原生 Apple Ads 控制台或 MMP 不同，我们的数据是**实时、无损且完整关联**的——涵盖试用、订阅和 LTV，没有延迟，也不存在归因缺口。

凭借简便的接入方式和流畅的使用体验，您可以在一个地方管理所有内容，无需在多个工具之间来回切换。

## 入门指南 \{#get-started\}

要开始使用 Adapty 广告管理器，请参阅[入门指南](adapty-ads-manager-get-started)。该指南涵盖了所需的两个步骤：安装 Adapty SDK 并连接您的 Apple Ads 账户。

您也可以通过终端管理同一账户，详见[通过 CLI 管理广告管理器](developer-cli-ads-manager)。
