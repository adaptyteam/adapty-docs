本指南帮助你解决在 React Native SDK 中使用 Adapty 付费墙编辑工具设计的付费墙时遇到的常见问题。有关流程问题，请参阅[常见问题](flow-common-issues)。

## 获取付费墙配置失败 \{#getting-a-paywall-configuration-fails\}

**问题**：获取流程或付费墙的视图配置失败。

**原因**：付费墙未在付费墙编辑工具中启用设备显示。

**解决方案**：在付费墙编辑工具中启用 **Show on device** 开关。

## 付费墙浏览量数字过大 \{#the-paywall-view-number-is-too-big\}

**问题**：付费墙的浏览次数显示为预期值的两倍。

**原因**：你可能在代码中调用了 `logShowFlow`（React Native SDK v4+）/`logShowPaywall`，导致通过旧版付费墙编辑工具构建的付费墙浏览次数被重复统计。Adapty 会自动追踪这些浏览记录，因此无需手动调用该方法。

**解决方案**：请确认在使用旧版付费墙编辑工具构建的付费墙时，代码中没有调用 `logShowFlow`（React Native SDK v4+）/`logShowPaywall`。
