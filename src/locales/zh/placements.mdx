**版位**是应用中插入 Adapty 内容的位置。你可以在应用启动时、进入付费功能前、设置页面或任何其他地方触发版位。

版位有三种类型，其中两种用于新工作：

- **流程版位**用于承载一个[流程](adapty-flow-builder)：即在[流程与付费墙编辑工具](adapty-flow-builder)中搭建的单个页面或页面序列。流程可以是用户引导、付费墙，或以付费墙结尾的用户引导。如果您想自行构建页面，请改用付费墙版位。
- **付费墙版位**会将一个[付费墙](paywalls)——您在看板中创建的产品配置——传递给您自行构建的页面。

第三种类型，**用户引导版位**，用于从旧版用户引导编辑器中提供[用户引导](onboardings)。Adapty 将于 2026 年 10 月 1 日停用该编辑器，请将新的用户引导构建为流程。

## 规则与注意事项 \{#rules-and-pitfalls\}

- **版位的类型在创建时就已固定**，因为每种类型都有其对应的数据指标体系。
- **版位 ID 在整个应用中必须唯一**，同一个 ID 不能在一处用于流程，在另一处又用于付费墙。
- **手动实现的付费墙和流程无法共用同一个 [A/B 测试](ab-tests)**，因为两者需要各自独立的版位类型。如需对比两者效果，可以在独立版位上[逐步推出流程](flow-gradual-rollout)，再进行对比分析。
- **若要将付费墙版位迁移至流程，请使用新 ID 创建一个新的流程版位**，然后发布一个调用该版位的应用新版本。详见[迁移至流程](migrate-to-flows)。
- **应用中唯一需要硬编码的是版位 ID。** 其他所有内容均可在看板中控制，无需发布应用：包括该版位展示哪个流程或付费墙、[目标受众](audience)分组以及 [A/B 测试](ab-tests)。
- **版位 ID 必须与看板中的 ID 完全一致。** 请直接复制，避免引入多余的空格。若 ID 不匹配，SDK 请求将失败，SDK 会使用你设置的本地备用文件（如有）。
- **仅限旧版付费墙编辑工具** — 关闭 **Show on device** 并不会将付费墙从其版位中移除。该版位仍会解析到该付费墙，但没有编辑工具配置，应用将无内容可渲染。如需停止展示某个付费墙，请将其从版位的目标受众中移除。

:::tip
您也可以使用 [Developer CLI](developer-cli-reference#placements) 以编程方式管理版位。
:::

## 版位列表 \{#placements-list\}

要查看所有版位，请从 Adapty 主菜单进入 **Placements**。版位按类型分类显示：**Paywalls**、**Onboardings** 和 **Flows**。

每个标签页都提供了用户旅程中各个位置的完整视图，展示流程、付费墙、用户引导或 A/B 测试的展示情况。列表中的每一项对应一个具体版位，方便进行管理和修改。

您可以编辑版位详情、将其与所需的流程、付费墙、用户引导或 A/B 测试关联到指定目标受众，或删除不需要的版位。表格中的数字反映了各版位自激活以来的数据图表。
