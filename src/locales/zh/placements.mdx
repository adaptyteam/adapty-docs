通过 Adapty 的版位系统，你可以在用户旅程的不同节点（例如用户引导流程、应用设置等）创建并运行[流程](adapty-flow-builder)、[付费墙](paywalls)、[用户引导](onboardings)和 [A/B 测试](ab-tests)。这些节点就叫做**版位**。

应用中的一个版位可以同时管理多个流程、付费墙、用户引导或 A/B 测试，每个都针对特定用户群体，我们称之为[目标受众](audience)。此外，你可以对流程、付费墙和用户引导进行实验，随时将其替换为另一个，无需发布新版本。

在移动应用中，你唯一需要硬编码的就是版位 ID。

:::warning
- 版位 ID 必须与看板中的 ID 完全一致——复制时请勿带入多余空格。如果 ID 不匹配，SDK 请求将失败，若你已配置本地备用文件，SDK 会使用该备用文件。
- 关闭 **Show on device** 并不会将付费墙从版位中移除：版位仍会解析到该付费墙，只是没有付费墙编辑工具的配置，导致应用无内容可渲染。如需停止展示某个付费墙，请改为将其从版位的目标受众中移除。
:::

## 版位列表 \{#placements-list\}

版位分为三种类型：
- **流程版位**
- **付费墙版位**
- **用户引导版位**

版位类型在创建时确定，之后无法更改，因为每种类型都有其独立的数据指标集。版位 ID 在应用内所有版位中唯一，无论类型如何，因此同一个 ID 不能既用于流程又用于付费墙。

要查看所有版位，请从 Adapty 主菜单进入 **Placements**。页面会按 **Paywalls**、**Onboardings** 和 **Flows** 标签页分类展示所有版位。

每个标签页都提供了全面的视图，展示用户旅程中流程、付费墙、用户引导或 A/B 测试可能出现的各个版位。列表中的每一项对应一个具体的版位，便于管理和修改。

您可以编辑版位详情、将其与特定目标受众的流程、付费墙、用户引导或 A/B 测试关联，或删除不需要的版位。表格中的数字反映了各版位自激活以来的分析数据。

在此页面，你可以：

- [创建新版位](create-placement)
- [编辑现有版位](edit-placement)
- [删除现有版位](delete-placement)
- 下载本地备用[流程](fallback-flows)、[付费墙](fallback-paywalls)或用户引导文件。当用户打开应用时，若无法连接 Adapty 后端（无网络连接，或极少数情况下后端不可用），且设备上也没有缓存，则会使用这些文件。同一个 **Fallbacks** 下载包同时涵盖流程和付费墙——在下载弹窗中选择的 SDK 版本决定了该包是否包含流程（SDK 4.0 及以上版本）或仅包含付费墙。
