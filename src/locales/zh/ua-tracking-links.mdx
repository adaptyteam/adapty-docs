:::important
追踪链接帮助 Adapty 对应用安装进行归因。如果你的广告将用户引导至网页漏斗，请改为[使用 Adapty 的参数标记其 URL](ua-tag-ad-urls)。
:::

广告的目标地址通常是 App Store 或 Google Play 页面。该页面属于应用商店，而非你，因此无法向 Adapty 上报点击数据。

请改用追踪链接作为目标地址。Adapty 会在将用户重定向到应用商店之前，捕获广告系列、广告组和广告信息，再将该点击与 SDK 上报的安装行为进行匹配。你的 [Adapty 归因分析](ua-analytics) 将展示哪些广告带来了收益。

Adapty 会自动生成 [Meta Ads](ua-facebook#step-2-add-campaigns) 和 [TikTok for Business](ua-tiktok#step-2-add-campaigns) 广告系列的链接。对于其他所有广告网络，请在看板中使用 **Custom** 集成来[创建自定义追踪链接](#custom-tracking-links)。

## 追踪链接类型 \{#tracking-link-types\}

Adapty 生成两种追踪链接：

- **平台专属链接** — 每个应用商店对应一条独立链接，可将用户引导至针对特定营销活动定制的商店页面。
- **One Link** — 一条同时适用于两个应用商店的链接，在用户点击时自动匹配其所在平台。

一个追踪链接页面包含您配置的所有商店的链接，因此无需为每个商店单独创建。为获得更大灵活性，我们推荐使用平台专属链接。

## 自定义追踪链接 \{#custom-tracking-links\}

:::note
Apple Search Ads 无需追踪链接。Adapty 可直接接收 Apple Search Ads 的归因数据，相关广告系列在 [Adapty Ads Manager](adapty-ads-manager) 中管理。
:::

创建自定义追踪链接：

1. 在 Adapty Attribution 看板中，打开 **Integrations**，然后在 **Network** 分组下选择 **Custom** 卡片。

<ZoomImage id="custom-tracking-link.webp" width="700px" alt="Integrations page in Adapty Attribution with the Custom card highlighted in the Network group" />

2. 点击 **Create link**。

<ZoomImage id="new-tracking-link.webp" width="700px" />

3. 从列表中选择您的应用，然后点击 **Next**。

<ZoomImage id="ua-choose-app.webp" width="700px" />

4. 填写链接参数，将该链接与特定广告系列和广告关联。

| Parameter         | Description                                                                                   |
|-------------------|-----------------------------------------------------------------------------------------------|
| **Name**          | 内部追踪链接名称。                                                              |
| **Channel**       | 流量来源，例如 Meta、Reddit 或 TikTok，用于在数据分析中对广告系列进行分组。 |
| **Campaign ID**   | 广告平台中广告系列的唯一标识符。                                                    |
| **Campaign name** | 广告系列的可读名称。                                                            |
| **Ad set ID**     | 广告平台中广告组（广告集）的唯一标识符。                                           |
| **Ad set name**   | 广告组的名称。                                                                       |
| **Ad ID**         | 单个广告素材的唯一标识符。                                                          |
| **Ad name**       | 广告素材或变体的名称。                                                     |

5. 默认情况下，您创建的是 One Link。如需添加[平台专属链接](#tracking-link-types)，请取消选中 **One Link** 复选框。

<ZoomImage id="one-link.webp" width="700px" />

6. 点击 **Create**。
7. 打开您的追踪链接页面。在对应[链接类型](#tracking-link-types)的部分，复制 **Click link** 的值。

:::tip
您还可以设置额外的链接参数，以[使用延迟数据](ua-deferred-data)。例如，可以实现延迟深度链接。
:::

<ZoomImage id="click-link.webp" width="700px" />

8. 前往您的广告平台，将该链接用作广告的目标 URL。
