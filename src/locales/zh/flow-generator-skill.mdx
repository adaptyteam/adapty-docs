[flow-generator 技能](https://github.com/adaptyteam/adapty-skills)让你的 AI 工具能够构建和编辑你的流程。用自然语言告诉它要构建或修改什么，工具会通过 [Adapty CLI](developer-cli-quickstart) 或 [Adapty MCP 服务器](adapty-mcp) 读取流程的编辑器配置，重写后渲染预览，待你确认后保存草稿。

技能是 AI 工具按需加载的一组指令。本技能涵盖流程配置中容易出错的部分：哪些编辑会阻止发布、删除某个屏幕后哪些引用会失效，以及渲染预览能证明什么、不能证明什么。

:::important
流程生成器技能目前处于实验阶段，所做的更改会直接保存到看板中的流程。请先在草稿或副本上运行，并在流程与付费墙编辑工具中仔细审查每一处变更，再进行发布。
:::

## 开始之前 \{#before-you-start\}

- **集成了 Adapty 插件的 AI 工具**：支持 Claude Code、Codex、Copilot CLI 或 Gemini CLI 等代码智能体，以及 claude.ai。该技能优先使用 Adapty CLI。如果仅配置了 MCP 服务器，它会提议安装 CLI；如果你拒绝，它将通过 MCP 继续运行，并列出每个未执行的本地验证步骤。
- **Adapty 目录中的产品**：在设计销售页面之前，该技能会列出你的产品，并询问哪些应放置其中。如果没有合适的产品，它可以根据你提供的商店产品 ID 创建一个，并会事先确认。

## 您可以用它做什么 \{#what-you-can-do-with-it\}

### 从零开始创建流程 \{#author-a-flow-from-scratch\}

- **从描述生成**："我的健身 App 付费墙，两个套餐，默认选中年付。"该技能自动选择排版结构，从经过渲染验证的模式库（标签页、套餐卡片、切换开关、倒计时、进度条、底部弹窗）中构建出来，并使用你从产品目录中选定的产品。
- **从截图或设计稿生成**：提供参考图，它会匹配布局、颜色、字体和图标风格，并逐一列出所有无法完全还原的差异。参考图可以是竞品的付费墙、你自己的截图，或设计工具中的某一帧。如果你的 AI 工具通过 MCP 连接到该设计工具，它可以直接读取帧内容——无需导出截图，也不用手动描述设计细节。
- **对照转化数据评分**：如果你没有提供设计稿，该技能会在构建完成后自动运行 Adapty 的 `paywall-teardown` 库，对生成的页面进行评估，并优先修复评分最低的问题——在你看到结果之前就已完成。你得到的是一个按你所在品类高转化模式打造的页面，而不是千篇一律的通用布局。

### 修改已有的流程 \{#change-a-flow-you-already-have\}

- **本地化新市场**：添加语言区域，并填写所有可本地化字段——标题、按钮标签、套餐说明、图片插槽和输入占位符。这是将一个已投入使用的付费墙快速扩展到十种语言的最高效方式。
- **一次性改写所有语言版本的文案**：在不调整结构的前提下修改措辞，并在价格变量周围进行编辑而非直接修改变量本身，从而确保价格正常解析。
- **重构流程结构**：添加、删除、重新排序屏幕，修复因此产生的导航断点，并报告所有无法到达的屏幕。
- **添加测验和分支逻辑**：构建可选择的分组、选项 ID 以及将每个答案路由到对应屏幕的条件动作——这一个性化步骤能将用户引导转化为有针对性的付费墙访问。
- **为测试创建实验变体**：将已生效的流程复制到新流程，然后应用你想测试的更改。屏幕、主题、字体、语言区域、产品和远程配置均会一并迁移，实验变体只在你指定的地方有所不同。
- **为季节或营销活动重新换肤**：从参考图片中采样颜色，并将新主题应用到整个流程，无需逐屏手动调整样式。
- **回退到早期版本**：在流程的[版本历史记录](flow-version-history)中找到早期版本，将其恢复为草稿或复制到新流程。技能随后会从该版本继续进行编辑。

## 安装技能 \{#install-the-skill\}

该技能是 [Adapty 插件](manage-adapty-with-ai) 的一部分。

<AdaptySkillsInstall />

然后用简单的语言描述你想做的事。大多数请求属于以下几类：

- **描述流程**：应用的功能、当前页面要销售的内容、默认选中哪个套餐。
- **指定设计参考**：提供截图、你自己的页面或设计工具中的某个画框。
- **提出具体修改**：说明流程名称和要改的内容——新增语言版本、修改文案、增加页面、根据测验答案添加分支。
- **回答它的问题**：它会询问某个页面应放哪些产品，对于任何真实数据，它不会自行编造。

## 工作原理 \{#how-it-works\}

该技能构建的所有内容都汇集到一个本地文件中。在最后一步之前，任何内容都不会同步到你的看板。

1. **设置并验证身份**。该技能会在需要时安装或更新 [Adapty CLI](developer-cli-quickstart)，然后验证你的 Adapty 登录状态并读取你的应用 ID。如果你尚未登录，它会打开浏览器登录页面并等待你完成登录。

2. **选择或创建流程**。编辑时，技能会先获取该流程的配置，并汇报所发现的内容——屏幕、语言区域、产品以及导航图——以便在改动任何内容之前发现选错流程的情况。在开始编辑前，技能会将已获取的配置保存一份副本作为备份。[版本历史](flow-version-history)保存了每一个已发布的版本，但不包含草稿的早期状态，因此对于从未发布过的草稿，这份副本是唯一的回退途径。如果是新建工作，技能会创建一个全新的流程，而不是在已有内容的流程上直接生成。

3. **验证配置**。该工具会对本地文件执行两次验证，并对 Adapty 执行一次验证。本地验证确认内部引用仍然一致，且各属性格式正确。`adapty flows config validate` 随后会调用与发布时相同的服务进行校验，结果为绿色即表示配置可以发布。这三次验证均不保存任何内容。

4. **预览与迭代**。该技能会将每个更改过的屏幕渲染为截图并进行检查。如果你提供了参考图片，它会逐项对比渲染结果与文件——颜色、字体、图标样式、比例——并尽力缩小差距。如果发现问题，技能会返回第 3 步，这会消耗一次截图配额，而非一次保存配额。

5. **批准并保存**。覆盖已有配置前需要你明确确认。该功能会为每个被修改的页面展示渲染前后的对比效果，列出无可视化内容的变更，在浏览器中打开一个实时预览页面，并显示备份文件名。确认无误后才会执行写入。

## 运行完成后 \{#after-the-run\}

技能会为你保存一个草稿。要让用户看到它：

1. **在 Flow & Paywall Builder 中打开该流程。** 如果你已在浏览器标签中打开了该流程，请刷新页面——Flow & Paywall Builder 不会自动获取通过 CLI 所做的写入操作。
2. **查看变更内容。** 对于保存前状态为 **Published** 的流程，Adapty 会将其标记为 **Dirty**，团队中所有成员都能看到该状态。你的用户仍会看到上一次发布的版本。
3. **在真实设备上预览。** [预览流程](paywall-device-compatibility-preview) 介绍了通过 Adapty 移动应用扫描二维码的预览流程。测试技能报告为未验证的所有内容——分支逻辑、切换开关，以及渲染语言以外的任何本地化语言。
4. **发布。** 点击 Flow & Paywall Builder 右上角的 **Publish to Live**，或在终端运行 [`adapty flows publish`](developer-cli-flows#adapty-flows-publish)。未添加到[版位](create-placement)的流程仍然不会触达任何用户，且草稿状态的流程无法添加到版位——因此请先发布。详见[保存与发布流程](builder-save-publish)。

如果结果有误，可以让技能回滚。技能会列出该流程的所有版本，将你选定的版本恢复为草稿，并展示结果。恢复操作会替换当前草稿，因此在替换之前，技能会先询问你，并提供将当前草稿复制为新流程的选项。对于从未发布过的草稿，历史记录中没有更早的状态，此时可以让技能将其备份副本写回。你也可以在 Flow & Paywall Builder 中手动修改流程。无论采用哪种方式，已保存的草稿对用户不会产生任何影响。

The version history also undoes a bad publish. Ask the skill to go back to the version that was live before: it restores that version as the draft, and you publish the draft when you're ready.

## 提供图片和视频 \{#give-it-your-images-and-videos\}

该技能会从你的电脑上传图片或视频，并将返回的 URL 绑定到流程中，因此你无需在 Flow & Paywall Builder 中手动添加媒体资源。它需要的是**文件路径**，而非图片本身：当你在聊天中粘贴或附加图片时，AI 工具接收的是像素数据，而没有文件，所以无法进行上传。

将资源放在电脑上的某个文件夹中，然后告诉工具路径：

```
The hero images are in ./design/paywall/. Use hero-calm.png on the first
screen and the three icons in ./design/paywall/icons/ for the benefit rows.
```

格式和大小限制与在流程及付费墙编辑工具中手动上传的要求一致——详见[图片、视频与图标](custom-media)。SVG 是唯一的例外：它无法上传，因此技能会以内联方式绘制单色字形代替。

该技能通过 [`adapty flows media upload-video`](developer-cli-flows#adapty-flows-media-upload-video) 上传视频。视频必须是 MP4 或 WebM 格式，时长不超过 30 秒，大小不超过 50 MB，宽度和高度均不低于 640 像素。不支持 GIF 格式，该技能也不会将动图转换为视频。当技能仅通过 MCP 服务器运行时，暂不支持上传视频：它会放置一个带有空占位符的视频元素，你需要在 Flow & Paywall Builder 中上传视频片段。

每次上传都会向媒体库单独添加一个资源，且没有任何 CLI 命令可以删除它，因此重复构建会留下多余的副本。

如果你指定了一个工具找不到的文件名，它会直接报错询问，而不会用看起来相似的文件替代。错误的文件会让页面在渲染时看起来一切正常，只是图片用的是错误的那张，而整个工作流中没有任何环节能捕捉到这个问题。

## 使用你自己的 AI 代理 \{#bring-your-own-agent\}

Adapty 在 Flow 与付费墙编辑工具中内置了一个 [AI 编辑器](flow-ai-editor)。两者的区别不在于功能多少，而在于工作发生在谁的环境里。

AI 编辑器是 Adapty 的代理，作用于你当前打开的页面。而 skill 则恰好相反：你的代理、你的模型、你的工具链，Adapty 只是它会操作的众多工具之一。你的 AI 工具已经能访问的一切，都可以随之而来——你的代码仓库、设计文件、MCP 服务器，以及你自己的提示词和上下文。

| | AI 编辑工具 | flow-generator 技能 |
|---|---|---|
| 使用的 agent | Adapty 的，运行在浏览器中 | 您自己的：编码 agent 或 claude.ai |
| 可访问的内容 | 当前打开的页面，以及您附加的图片 | 您的 AI 工具可访问的任何内容 |
| 单次提示的范围 | 单个页面 | 整个流程——页面、导航、语言环境 |
| 本地化 | 不支持 | 添加语言环境并填写所有可本地化的字段 |
| 撤销 | 每次提示单击一次 | 流程的备份副本、版本历史记录，以及每次保存前需要您确认 |
| 设置 | 无需设置 | 需要 Adapty 插件，以及 Adapty CLI 或 MCP 服务器 |

当您已进入编辑工具并想对当前屏幕进行重新样式调整时，请使用 AI Editor。如果您不想离开自己的环境来完成流程相关工作，请使用 skill。

## 技能不会做什么 \{#what-the-skill-wont-do\}

该技能将您的流程视为实时内容，因为已发布的流程正在为真实用户提供服务。

- **发布由您决定**：技能只会保存草稿，不会发布。请在 Flow & Paywall Builder 中自行发布，或使用 [`adapty flows publish`](developer-cli-flows#adapty-flows-publish)。
- **覆盖需要您确认**：保存操作会替换整个配置，不支持部分写入，草稿也无法撤销。确认时会显示流程名称、ID、状态以及技能在编辑前备份的文件。
- **恢复版本仍为草稿**：技能会将早期版本恢复为草稿，不会发布。替换草稿前会向您确认。
- **未保存的更改由您处理**：技能在打开或恢复其他版本前，会询问您是否保存未保存的更改、放弃更改，还是留在当前版本。
- **并发编辑会导致写入失败**：首次写入之后，每次写入都会将配置的 `updated_at` 时间戳回传给 Adapty。如果期间有队友保存了该流程，Adapty 会拒绝本次写入，而不会覆盖对方的工作。
- **删除流程须在看板中操作**：CLI 没有删除命令，因此技能为您创建的流程需要您在看板中手动删除。
- **真实数据和资源由您提供**：评分、评论数、折扣百分比和商店价格不会凭空生成。如果某个模式需要您未提供的数据，技能会向您询问或直接省略该元素，并说明具体处理方式。

:::note
读取、验证和预览均不计费，也不会产生任何更改。保存配置是唯一会影响看板的操作，且需要您的确认。
:::

## 限制 \{#limitations\}

#### 运行需要时间 \{#runs-take-time\}

每次修改后，技能都会进行验证并重新渲染，这样可以防止错误配置出现在你的看板上——但也会让运行速度比普通对话回复慢。小幅修改只需几分钟即可完成。而制作一个包含多屏幕和分支逻辑的流程则需要 **10 到 40 分钟**。启动后去做别的事，不用一直盯着它。

#### 自定义字体需要手动处理 \{#custom-fonts-stay-manual\}

该技能不会上传[自定义字体](using-custom-fonts-in-flow-builder)文件。它会按照设计要求创建文字样式，并将其指向一个占位字体。请在 Flow & Paywall Builder 中上传字体，并将其应用到相应样式。

#### 预览仅渲染单个屏幕的单一状态 \{#the-preview-renders-one-screen-in-one-state\}

该技能的预览页面只展示单个屏幕，不会演示完整流程。以下内容均无法在预览中呈现，请在真实设备上逐一测试——[预览流程](paywall-device-compatibility-preview)中有具体说明：

- **导航和分支跳转**：携带导航操作的按钮在预览中保持原位，因此条件路由无法触发。每个页面都是独立渲染的。
- **切换和多选**：切换行和多选行始终以其默认的关闭状态显示。单选行和产品卡片则会正常渲染其选中状态。
- **非当前语言环境**：预览会忽略流程的默认语言环境和语言列表顺序，因此无法直观地验证翻译效果。请在流程与付费墙编辑工具中切换语言环境，检查是否有文字溢出容器的情况。
- **运行时才能解析的内容**：实际价格、商店货币和用户输入均无法预览。价格变量会以字面量 token 形式显示，其长度通常超过实际价格，可能导致文字被固定按钮遮挡——这种重叠在价格真正解析后便会消失。
- **页面无法感知的屏幕尺寸**：依赖视口高度的布局需要在小屏手机上实际验证。
