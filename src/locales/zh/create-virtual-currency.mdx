要出售虚拟货币积分，需先定义一种虚拟货币，再将其关联到你的产品。

整个流程分为两步——本文均有详细说明。关联产品后，每次购买或续订都会自动授予积分。

## 创建虚拟货币 \{#create-a-virtual-currency\}

在 Adapty 看板中，打开 **Products** > [**Virtual currency**](https://app.adapty.io/virtual-currency)。

<ZoomImage id="virtual-currency-tab.webp" width="700px" alt="The Virtual currency tab under Products, showing the empty state and the New virtual currency button" />

创建虚拟货币的步骤如下：

1. 点击 **New virtual currency**，侧边栏将在 **General** 步骤处打开。
2. 填写货币详情：
    - **Code**：货币在应用内的唯一**永久**标识符，例如 `COINS`。用于在服务端 API 中标识该货币，并追踪每位用户的余额。
    
        使用拉丁字母、数字和下划线，最多 32 个字符。小写字母会自动转换为大写。
    - **Name**：显示名称，例如 `Gold`。可以在之后更改。
    - **Description**：关于该货币的可选备注。
3. 点击 **Continue** 进入 **Link Products** 步骤。

:::important
货币的 **Code** 一旦创建后就无法更改。但 **Name** 之后仍可编辑。
:::

当您引入新货币时，每个用户画像的初始余额为 0。如需在用户购买任何内容之前为其设置余额，请参阅[授予初始余额](grant-initial-balance)。

<ZoomImage id="new-currency-step-1.webp" width="500px" alt="The General step of the New virtual currency drawer, with Code, Name, and Description fields" />

## 关联产品 \{#link-products\}

将产品与虚拟货币关联，这样购买或续订即可获得该货币的积分。您可以将一个产品关联到多种货币，也可以将一种货币关联到多个产品。您可以在 **Link Products** 步骤中立即关联产品，也可以在后续编辑货币时再添加。

在 **Link Products** 步骤中，**Associated products** 部分列出了可授予此货币的产品。如需添加，请点击 **Add associated products**，然后选择一个产品。

每次授予都会累加到用户的余额中，而不是替换原有余额，因此来自不同产品的点数会不断累积。点数设置取决于产品类型：

- **订阅产品**有三个积分设置：
    - **每个周期的积分**（必填）：首次付费购买及每次续订（包括将试用转为付费的续订）时授予的积分。
    - **试用开始时的积分**（可选）：免费试用开始时一次性授予的独立积分。
    - **积分在每个计费周期结束时过期**（复选框）：选中后，订阅每次仅授予一个计费周期的积分。周期结束时，未使用的积分将过期。其他订阅、一次性购买商品和 Server-side API 的积分余额不受影响。未选中时，积分跨周期累积且永不过期。
- **一次性购买商品**：设置**积分数量**，即每次购买授予的积分数。一次性购买商品的积分永不过期。

点击 **Save** 以创建货币及其产品链接。

产品链接仅对之后的交易生效。新链接的产品将从下次购买或续订时开始发放积分。Adapty 不会自动向当前订阅者授予货币——他们需要先完成续订。移除链接后，未来的发放将停止，但已发放的积分不受影响。

勾选 **Credits expire at the end of each billing cycle** 复选框后，到期积分将遵循订阅的生命周期：

- 当续费付款失败时，未使用的积分仍会在已付费周期结束时过期，即使用户在宽限期内仍保有访问权限。Adapty 会在付款成功后授予新积分。
- 取消订阅后，积分将保留至已付费周期结束。
- 当订阅到期时，Adapty 会将该订阅授予的剩余积分重置为 0。
- 商店在已付费周期结束后才上报的延迟续费，不会授予任何积分：这些积分会立即过期。

当商店退款时，Adapty 会从余额中扣除该次购买对应的积分：

- **一次性购买商品**：该购买所授予的全部积分。
- **订阅**：与退款比例相对应的积分份额。

Adapty 仅扣回用户尚未消费的积分，因此余额不会低于 0。在用户画像的[事件历史记录](virtual-currency-balance#review-balance-changes-in-the-event-history)中，该变动显示为 **Virtual currency revoked**。

当用户在 App Store 上进行升级时：

- 用户可获得高级别产品的完整**每周期积分**，不按比例扣减。
- 用户保留低级别产品的积分，即使 App Store 已退还其未使用部分的费用。
- 如果为低级别产品勾选了**每个计费周期结束时积分过期**复选框，则在升级时，其未使用的积分将立即过期。

## 混合余额的消费顺序 \{#how-a-mixed-balance-is-spent\}

一种货币的余额可以同时包含来自多个来源的积分——例如，有到期时间的订阅授予积分和无到期时间的一次性购买授予积分。当消费操作从余额中扣减时，Adapty 会优先消耗有到期时间的积分，且按照授予时间由早到晚的顺序扣减，只有当所有有到期时间的积分耗尽后，才会开始消耗无到期时间的积分。这就是为什么订阅到期时只会重置该订阅尚未消费的那部分积分——由一次性购买产品授予的积分仍会保留在余额中。

## 后续步骤 \{#next-steps\}

创建货币并关联产品后，购买会自动授予积分。接下来你可以：

- 在[虚拟货币余额](virtual-currency-balance)页面跟踪每位用户的余额。
- 通过服务端 API 在运行时授予、消耗和读取余额：[创建虚拟货币交易](api-adapty/operations/createVirtualCurrencyTransaction)和[查询虚拟货币余额列表](api-adapty/operations/listVirtualCurrencyBalances)。如需完整示例，请参阅[虚拟货币快速入门](virtual-currency-quickstart)。
- 当余额不足以支付消耗时，如需触发充值流程，请参阅适用于 [iOS](ios-virtual-currency-top-up) 的操作指南。
