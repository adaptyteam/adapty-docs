Adapty MCP 服务器将 AI 助手连接到你的 Adapty 账户。用自然语言询问收入与转化情况、配置产品和版位、发布流程、启动 A/B 测试，或管理 Apple Ads 广告系列——一切都在对话中完成。助手通过浏览器使用你的 Adapty 账户登录并获取权限，无需 API 密钥。

| | |
|---|---|
| 服务器 URL | `https://mcp.adapty.io/mcp` |
| 协议 | MCP over Streamable HTTP，浏览器内 OAuth 2.1 登录 |
| 适用客户端 | claude.ai、Claude desktop、Claude Code、Codex 以及其他支持 OAuth 登录的 MCP 客户端 |

:::important
MCP 服务器让你的助手能够访问你的 Adapty 账户。要为其提供专业知识——流程配置规则、经过验证的分析方法，以及在每个影响用户的步骤前进行确认——请先安装 [Adapty 插件](manage-adapty-with-ai#install-the-plugin)。在 Claude Code 和 Codex 中，插件会自动为你添加此服务器，因此你只需[登录](#connect-your-assistant)即可。
:::

## 助手能做什么 \{#what-the-assistant-can-do\}

服务器工具遵循 Adapty 看板和 [Adapty 开发者 CLI](developer-cli) 的规范。助手会根据你的请求自动选用合适的工具，无需你指定。

| 功能区域 | 助手可以做什么 | 示例提问 |
|---|---|---|
| 应用与访问等级 | 列出、创建和更新应用及访问等级 | "在 Fitness Pro 中创建一个 `premium` 访问等级。" |
| 产品与优惠 | 创建产品并关联应用商店产品 ID，以及将应用商店优惠与产品绑定 | "哪些产品没有 Google Play 产品 ID？" |
| 付费墙 | 创建和更新付费墙，并查找展示各付费墙的版位 | "哪些版位展示了 Annual sale 付费墙？" |
| 流程 | 创建流程，读写流程编辑器配置，验证、预览、发布，以及查看流程数据图表。列出、查看、重命名和恢复历史版本，或将某个流程/版本复制为新流程 | "发布流程 Onboarding v2，并告诉我哪些版位展示了它。" |
| 版位与目标受众 | 创建版位、更改用户看到的内容，以及查看流程版位的数据图表 | "`onboarding` 版位向哪些用户展示了什么内容？" |
| 市场细分 | 读取市场细分及其筛选条件 | "列出我的所有市场细分及各自的筛选条件。" |
| A/B 测试 | 创建、启动、停止、替换和归档付费墙及流程 A/B 测试 | "针对德国用户启动草稿测试 Weekly vs annual。" |
| 分析 | 读取收入、MRR、转化率、漏斗、留存率、LTV 和安装同期群数据 | "对比上个月各国家的试用转付费转化率。" |
| Apple Ads | 在 [Adapty Ads Manager](adapty-ads-manager) 中管理广告活动、广告组、关键词和自动化规则，并查看相关数据图表 | "上周哪些关键词花费最多但没有带来任何安装？" |
| 从 RevenueCat 迁移 | 创建并执行将 RevenueCat 目录迁移至新 Adapty 应用的任务 | "将我的 RevenueCat 项目迁移到一个新的 Adapty 应用。" |

要使用版本历史，助手会调用[版本历史](flow-version-history#work-with-versions-from-the-cli-or-an-ai-assistant)的以下工具：`flows_versions_list`、`flows_versions_get`、`flows_versions_preview`、`flows_versions_rename`、`flows_versions_restore` 和 `flows_duplicate`。恢复操作会替换当前草稿。如需保留草稿，请先将其复制到新流程中。当流程存在草稿时，助手会在替换前询问你，并提供先复制草稿的选项。恢复后的版本在你发布之前不会对用户生效。

Adapty Mail 拥有自己的 MCP 服务器。要将 AI 助手连接到您的 Adapty Mail 项目，请参阅[使用 AI 助手管理 Adapty Mail](mail-mcp)。

## 选择 MCP 服务器还是 CLI \{#choose-the-mcp-server-or-the-cli\}

MCP 服务器与 [Adapty Developer CLI](developer-cli) 连接的是同一个 Adapty 账户。如果两者都未配置，Adapty 插件会询问你想设置哪一个，并给出具体步骤。如果两者都已配置，插件会根据任务自动选择其中一个：

| | Adapty MCP server | Adapty CLI |
|---|---|---|
| 运行环境 | 任意 MCP 客户端，包括 claude.ai 和 Claude desktop | 支持执行终端命令的 Agent 及自定义脚本 |
| 登录方式 | 每个客户端登录一次，在浏览器中完成 | `adapty auth login`，每台机器登录一次 |
| 适用场景 | 通过聊天进行问答和修改操作 | 编辑流程配置、批量修改及脚本操作 |
| 安装方式 | 无需安装 | `npm install -g adapty` |

在 claude.ai 和 Claude 桌面版中，MCP 服务器所需的配置比 CLI 少：CLI 需要在每次对话中安装并授权，详情请参阅[在 Claude 应用中配置 Adapty CLI](developer-cli-cowork)。

<Details summary="哪些技能使用 MCP 服务器，哪些使用 CLI">

每个技能在执行第一步之前，会自动检测你的助手是否配置了 MCP 服务器、CLI，或两者都有。若只有一个，技能就使用该工具。若两者都有，技能会根据任务性质选择更合适的一个：

- **MCP server**：运行 A/B 测试、运行 Apple Ads、集成 SDK 以及测试购买。
- **Adapty CLI**：构建和审计流程、确定下一步测试内容、将版位迁移到流程，以及创建市场细分。这些技能会运行自己的脚本和文件，CLI 会直接将文件传递给它们。

</Details>

## 开始之前 \{#before-you-start\}

- **Adapty 账户**：助手在你的 Adapty 账户有权限访问的公司和应用中运行。
- **支持 OAuth 的 MCP 客户端**：你的客户端需要支持通过 OAuth 登录的远程 MCP 服务器。

:::warning
助手以您的权限执行操作，其所做的更改均为真实生效。已启动的 A/B 测试或已更改的版位会直接影响您的用户，而修改 Apple Ads 出价或预算则会花费真实费用。在助手启动或停止 A/B 测试，或更改版位受众之前，服务器会要求其描述确切影响并等待您的确认。请在批准前仔细阅读操作计划。
:::

## 连接您的助手 \{#connect-your-assistant\}

<Tabs groupId="mcp-client" queryString>
<TabItem value="claude-app" label="claude.ai" default>

claude.ai 和 Claude 桌面端通过自定义连接器的方式添加远程 MCP 服务器。

1. 要添加服务器，请打开 **Settings → Connectors**，然后点击 **Add custom connector**。
2. 输入名称，例如 `Adapty`，以及 URL `https://mcp.adapty.io/mcp`。
3. 保持默认的身份验证设置，然后点击 **Add**。
4. 在随后打开的浏览器标签页中登录 Adapty。请参阅[登录](#sign-in)。

工作区管理员只需为整个组织添加一次连接器，之后每位成员在首次使用时用自己的 Adapty 账号登录即可。

</TabItem>
<TabItem value="claude-code" label="Claude Code">

如果你已安装 Adapty 插件，Claude Code 会将服务器自动列为 `plugin:adapty-skills:adapty`，状态显示为 **Needs authentication**。要登录，请在 Claude Code 中运行 `/mcp`，选择 `plugin:adapty-skills:adapty`，然后选择 **Authenticate**。

如果未安装插件，请先添加服务器：

```bash
claude mcp add --transport http --scope user adapty https://mcp.adapty.io/mcp
```

然后在 Claude Code 中运行 `/mcp`，选择 `adapty`，并点击 **Authenticate**。如果当前会话中没有出现 Adapty 工具，请重新开启一个新会话。

</TabItem>
<TabItem value="codex" label="Codex">

如果你已安装 Adapty 插件，插件会自动添加服务器，Codex 连接时会提示你登录。

如果没有安装插件，请手动添加服务器并登录：

```bash
codex mcp add adapty --url https://mcp.adapty.io/mcp
codex mcp login adapty
```

登录命令会打开您的浏览器。如果想手动配置服务器，请将其添加到 `~/.codex/config.toml`，然后运行登录命令：

```toml
[mcp_servers.adapty]
url = "https://mcp.adapty.io/mcp"
```

开启新的 `codex` 会话以加载 Adapty 工具。

</TabItem>
<TabItem value="other" label="其他客户端">

在您的客户端设置或 MCP 配置文件中，将 `https://mcp.adapty.io/mcp` 添加为远程 MCP 服务器。客户端首次连接时会打开浏览器供您登录。

服务器通过客户端 ID 元数据文档来识别每个客户端，这是当前 MCP 规范的客户端注册方式。不支持此方式的客户端将无法完成登录。遇到这种情况，请改用终端代理中的 [Adapty 开发者 CLI](developer-cli-quickstart)。

</TabItem>
</Tabs>

## 登录 \{#sign-in\}

每个客户端最终都会跳转到同一个地方：浏览器中的 Adapty 登录页面。

1. 用你的 Adapty 账号登录（如果尚未登录）。
2. 授权客户端访问你的 Adapty 账号。

登录后，客户端将读取并修改你账号有权访问的公司数据，并保持登录状态，直到你主动断开连接。请只批准由你本人发起的登录请求。

如需验证连接是否成功，可以询问助手当前登录的是哪个 Adapty 账号。回答中应包含你的名字以及你账号可以访问的公司。

## 开始使用 \{#start-working\}

向助手询问它能看到哪些应用，然后告诉它要处理哪个应用。可以尝试以下请求：

```text
List my Adapty apps and their placements.
How did revenue and new subscriptions change last month compared with the month before?
Which products in Fitness Pro have no App Store product ID?
Show who sees what on the onboarding placement, including any A/B test.
Create a draft A/B test on main_paywall: the current paywall against Annual sale, 50/50.
```

助手在执行会改变用户所见内容的步骤前会先请求确认。仅读取数据的请求无需确认，直接执行。

完成多步骤任务后，助手可向 Adapty 团队发送一条关于任务执行情况的简短说明。该说明不包含您应用用户的任何个人数据。

## 断开连接 \{#disconnect\}

如需断开连接，请在客户端中移除服务器：

- **claude.ai**：在 **Settings → Connectors** 中移除 Adapty 连接器。
- **Claude Code**：运行 `claude mcp remove adapty`。如果服务器来自 Adapty 插件，请改在 `/mcp` 中禁用它。
- **Codex**：从 `~/.codex/config.toml` 中移除 `adapty` 服务器。

如需重新连接，请再次添加服务器并登录。

## 故障排查 \{#troubleshooting\}

| 问题 | 解决方案 |
|---|---|
| Claude Code 将服务器显示为 **Needs authentication** | 客户端已添加服务器但未登录。运行 `/mcp`，选择 Adapty 服务器，然后选择 **Authenticate**。 |
| 客户端未列出任何 Adapty 工具 | 完成登录后，开始新的会话。部分客户端仅在会话开始时加载工具。 |
| 助手找不到某个应用 | 该应用属于你的 Adapty 账户无权访问的公司。请联系公司所有者获取权限。 |
| 客户端无法完成登录 | 该客户端不支持服务器所使用的登录方式。请从 claude.ai、Claude Code 或 Codex 连接，或使用 [Adapty Developer CLI](developer-cli-quickstart)。 |
