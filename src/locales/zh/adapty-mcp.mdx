Adapty MCP 服务器将 AI 助手与你的 Adapty 账户连接起来。你可以用自然语言查询收入和转化数据、配置产品和版位、发布流程，或在对话中发起 A/B 测试。助手会在浏览器中通过你的 Adapty 账户完成登录并获取相应权限，无需 API 密钥。

| | |
|---|---|
| 服务器地址 | `https://mcp.adapty.io/mcp` |
| 协议 | MCP over Streamable HTTP，在浏览器中通过 OAuth 2.1 登录 |
| 适用范围 | Claude 应用（网页版和桌面版）、Claude Code、Codex 以及其他支持 OAuth 登录的 MCP 客户端 |

:::important
MCP 服务器与 [Adapty 技能](#add-the-adapty-skills)配合使用效果最佳。服务器为助手提供访问您账户的权限，技能为其提供经过验证的工作流。构建流程和付费墙，以及在数据分析中找到下一个测试方向，都依赖于技能。
:::

## 添加 Adapty 技能 \{#add-the-adapty-skills\}

MCP 服务器让你的助手能够访问你的 Adapty 账户。Adapty 技能则赋予它实际的操作能力：经过验证的工作流，能够规划变更、进行校验，并在每个影响用户的步骤前主动确认。两者需要配合使用。`adapty-skills` 插件已将技能和 MCP 服务器打包在一起。

以下两类工作依赖于这些技能：

- **流程与付费墙**：[flow-generator 技能](flow-generator-skill)内置了付费墙编辑工具的配置规则，能够根据描述或截图构建页面，并在保存流程前对每次变更进行验证和预览。没有该技能，助手虽然可以读写流程配置，但不具备有效配置的规则。
- **数据分析与下一步测试方向**：[growth-advisor 技能](export-analytics-with-ai)了解应读取哪些报告以及如何解读，能将你的数据转化为 A/B 测试假设。没有该技能，助手虽然可以获取数据图表，但没有方法对其加以解释。

### 在 Claude 应用中添加插件

你可以直接在 Claude 设置中添加插件，无需使用命令行。

1. 在 Claude 中，打开 **Settings** → **Plugins**。
2. 点击 **Add** → **Add marketplace**。
3. 选择 **Add from a repository**。
4. 在 **URL** 字段中输入 `adaptyteam/adapty-skills`，然后选择该仓库。如需自动获取新技能和修复更新，请保持 **Sync automatically** 开启。
5. 点击 **Sync**。

<ZoomImage id="adapty-skills-claude-add-marketplace.png" width="584px" alt="Add marketplace dialog in Claude with adaptyteam/adapty-skills in the URL field and Sync automatically turned on" />

Claude 会打开 **Discover** 标签页，显示来自 Adapty 市场的插件。要安装技能，请在 **Adapty** 行中点击 **Add**。

<ZoomImage id="adapty-skills-claude-discover.png" width="600px" alt="Discover tab in Claude listing the Adapty, Apple ads, and Apple ads benchmarks plugins, each with an Add button" />

技能在 Claude 的沙盒中运行其脚本。要允许此操作，请在 **Settings** → **Capabilities** 中开启 **Code execution and file creation**。

### 在编程智能体中添加插件 \{#add-the-plugin-in-a-coding-agent\}

在 Claude Code、Codex、Copilot CLI、Gemini CLI、Cursor 及其他编程智能体中运行：

```bash
npx adapty skills install
```

该命令会在支持自有安装器的智能体中通过其安装器完成插件安装。安装完成后请重启你的智能体。在 Claude Code 和 Codex 中，插件还会添加 Adapty MCP 服务器，因此你只需登录，如[连接你的助手](#connect-your-assistant)所述。

<Details summary="哪些技能使用 MCP 服务器，哪些使用 CLI">

每个技能在执行第一步之前，会先检测你的 agent 是否配置了 MCP 服务器、[Adapty Developer CLI](developer-cli)，或两者都有。如果只有其中一个，技能就使用那个；如果两者都有，技能会根据任务选择最合适的：

- **MCP server**：运行 A/B 测试、集成 SDK、测试购买。
- **Adapty CLI**：构建和审核流程、寻找下一个测试点、将版位迁移到流程、创建市场细分。这些技能会运行自己的脚本和文件，CLI 直接将文件传递给它们。

</Details>

## 助手能做什么 \{#what-the-assistant-can-do\}

服务器工具遵循 Adapty 看板和 [Adapty 开发者 CLI](developer-cli) 的规范。助手会根据你的请求自动选用合适的工具，无需你指定。

| 功能区域 | 助手可以执行的操作 | 示例提问 |
|---|---|---|
| 应用与访问等级 | 列出、创建和更新应用及访问等级 | "在 Fitness Pro 中创建一个 `premium` 访问等级。" |
| 产品与优惠 | 创建产品并关联商店产品 ID，以及将商店优惠与产品关联 | "我有哪些产品没有 Google Play 产品 ID？" |
| 付费墙 | 创建和更新付费墙，以及查找展示各付费墙的版位 | "哪些版位展示了 Annual sale 付费墙？" |
| 流程 | 创建流程，读写编辑器配置，验证、预览、发布，以及查看流程数据图表 | "发布流程 Onboarding v2，并告诉我哪些版位正在展示它。" |
| 版位与目标受众 | 创建版位并调整展示策略，以及查看流程版位的数据图表 | "`onboarding` 版位向哪些用户展示了什么内容？" |
| 市场细分 | 查看市场细分及其筛选条件 | "列出我的所有市场细分及各自的筛选条件。" |
| A/B 测试 | 创建、启动、停止、替换及归档付费墙和流程的 A/B 测试 | "针对德国用户启动草稿测试 Weekly vs annual。" |
| 数据分析 | 查看收入、MRR、转化率、漏斗、留存率、LTV 及安装同期群 | "比较上个月各国家/地区的试用转付费转化率。" |
| 从 RevenueCat 迁移 | 创建并执行将 RevenueCat 商品目录迁移至新 Adapty 应用的流程 | "将我的 RevenueCat 项目迁移到一个新的 Adapty 应用。" |

Adapty Mail 拥有自己的 MCP 服务器。要将 AI 助手连接到您的 Adapty Mail 项目，请参阅[使用 AI 助手管理 Adapty Mail](mail-mcp)。

## 选择 MCP 服务器或 CLI \{#choose-the-mcp-server-or-the-cli\}

MCP 服务器和 [Adapty Developer CLI](developer-cli) 连接的是同一个 Adapty 账户。根据你的助手运行环境来选择：

| | Adapty MCP 服务器 | Adapty CLI |
|---|---|---|
| 运行于 | 任何 MCP 客户端，包括 Claude 应用等聊天工具 | 能执行终端命令的智能体，以及你自己的脚本 |
| 登录方式 | 每个客户端登录一次，通过浏览器完成 | `adapty auth login`，每台设备登录一次 |
| 适用场景 | 通过聊天提问或进行更改 | 编辑流程配置、批量变更及脚本操作 |
| 安装方式 | 无需安装 | `npm install -g adapty` |

智能体可以同时使用两者。在 Claude 应用中，MCP 服务器比 CLI 的配置步骤更少：CLI 需要在每次对话中都进行安装和授权，详情请参阅[在 Claude 应用中配置 Adapty CLI](developer-cli-cowork)。

## 开始之前 \{#before-you-start\}

- **Adapty 账户**：该助手可在你的 Adapty 账户有权限访问的公司和应用中运行。
- **支持 OAuth 的 MCP 客户端**：你的客户端需支持通过 OAuth 登录的远程 MCP 服务器。

:::warning
助手以你的权限执行操作，所有变更均为实际生效。启动 A/B 测试或修改版位配置后，结果会直接影响你的用户。每当助手准备启动或停止 A/B 测试，或变更版位的受众展示规则时，服务器会要求它描述本次操作的确切影响，并等待你确认。请在批准前仔细阅读操作计划。
:::

## 连接你的助手 \{#connect-your-assistant\}

<Tabs groupId="mcp-client" queryString>
<TabItem value="claude-app" label="Claude app" default>

Claude 应用（claude.ai 和 Claude 桌面版）通过自定义连接器的方式添加远程 MCP 服务器。

1. 要添加服务器，打开 **Settings → Connectors**，点击 **Add custom connector**。
2. 输入一个名称，例如 `Adapty`，以及 URL `https://mcp.adapty.io/mcp`。
3. 保持默认认证设置，点击 **Add**。
4. 在打开的浏览器标签页中登录 Adapty。请参阅[登录](#sign-in)。

工作区管理员只需为整个组织添加一次连接器。之后每个成员在首次使用时，用自己的 Adapty 账户登录即可。

</TabItem>
<TabItem value="claude-code" label="Claude Code">

如果你使用了 `adapty-skills` 插件，Claude Code 中已列出服务器 `plugin:adapty-skills:adapty`，状态显示为 **Needs authentication**。要登录，请在 Claude Code 中运行 `/mcp`，选择 `plugin:adapty-skills:adapty`，然后选择 **Authenticate**。

如果没有使用插件，请先添加服务器：

```bash
claude mcp add --transport http --scope user adapty https://mcp.adapty.io/mcp
```

然后在 Claude Code 中运行 `/mcp`，选择 `adapty`，并点击 **Authenticate**。如果当前会话中没有出现 Adapty 工具，请新开一个会话。

</TabItem>
<TabItem value="codex" label="Codex">

如果你使用了 `adapty-skills` 插件，插件会自动添加服务器，Codex 连接时会提示你登录。

如果没有使用插件，请手动添加服务器并登录：

```bash
codex mcp add adapty --url https://mcp.adapty.io/mcp
codex mcp login adapty
```

登录命令会打开您的浏览器。如果想手动配置服务器，请将其添加到 `~/.codex/config.toml`，然后运行登录命令：

```toml
[mcp_servers.adapty]
url = "https://mcp.adapty.io/mcp"
```

开启新的 `codex` 会话以加载 Adapty 工具。

</TabItem>
<TabItem value="other" label="其他客户端">

在您的客户端设置或 MCP 配置文件中，将 `https://mcp.adapty.io/mcp` 添加为远程 MCP 服务器。客户端首次连接时会打开浏览器供您登录。

服务器通过客户端 ID 元数据文档来识别每个客户端，这是当前 MCP 规范的客户端注册方式。不支持此方式的客户端将无法完成登录。遇到这种情况，请改用终端代理中的 [Adapty 开发者 CLI](developer-cli-quickstart)。

</TabItem>

## 登录 \{#sign-in\}

每个客户端最终都会跳转到同一个地方：浏览器中的 Adapty 登录页面。

1. 用你的 Adapty 账号登录（如果尚未登录）。
2. 授权客户端访问你的 Adapty 账号。

登录后，客户端将读取并修改你账号有权访问的公司数据，并保持登录状态，直到你主动断开连接。请只批准由你本人发起的登录请求。

如需验证连接是否成功，可以询问助手当前登录的是哪个 Adapty 账号。回答中应包含你的名字以及你账号可以访问的公司。

## 开始使用 \{#start-working\}

向助手询问它能看到哪些应用，然后告诉它要处理哪个应用。可以尝试以下请求：

```text
List my Adapty apps and their placements.
How did revenue and new subscriptions change last month compared with the month before?
Which products in Fitness Pro have no App Store product ID?
Show who sees what on the onboarding placement, including any A/B test.
Create a draft A/B test on main_paywall: the current paywall against Annual sale, 50/50.
```

助手在执行会改变用户所见内容的步骤前会先请求确认。仅读取数据的请求无需确认，直接执行。

完成多步骤任务后，助手可向 Adapty 团队发送一条关于任务执行情况的简短说明。该说明不包含您应用用户的任何个人数据。

## 断开连接 \{#disconnect\}

如需断开连接，请在客户端中移除对应服务器：

- **Claude app**：在 **Settings → Connectors** 中移除 Adapty 连接器。
- **Claude Code**：运行 `claude mcp remove adapty`。如果服务器是通过 `adapty-skills` 插件安装的，请改在 `/mcp` 中禁用它。
- **Codex**：从 `~/.codex/config.toml` 中移除 `adapty` 服务器。

如需重新连接，重新添加服务器并登录即可。

## 故障排查 \{#troubleshooting\}

| 问题 | 解决方案 |
|---|---|
| Claude Code 将服务器显示为 **Needs authentication** | 客户端已添加服务器，但未登录。运行 `/mcp`，选择 Adapty 服务器，然后选择 **Authenticate**。 |
| 客户端未列出任何 Adapty 工具 | 完成登录后，开始一个新会话。部分客户端仅在会话开始时加载工具。 |
| 助手找不到某个应用 | 该应用属于您的 Adapty 账户无权访问的公司。请联系公司所有者申请访问权限。 |
| 客户端无法完成登录 | 客户端不支持服务器所使用的登录方式。请通过 Claude 应用、Claude Code 或 Codex 进行连接，或使用 [Adapty Developer CLI](developer-cli-quickstart)。 |
