Adapty 插件能让你的 AI 工具与 Adapty 协同工作。将它安装到 Claude Code、Codex、Cursor 或其他 AI 编码助手，乃至 claude.ai，然后用自然语言描述需求：集成 SDK、搭建付费墙、排查营收下滑原因，或启动 A/B 测试。该插件是一套技能的集合：经过验证的工作流，每种任务对应一个。它是你唯一需要安装的产品。它通过 Adapty MCP 服务器或 Adapty CLI 连接到你的 Adapty 账户；在 Claude Code 和 Codex 中，它会自动帮你添加 MCP 服务器，你只需完成登录即可。

## 插件的作用 \{#what-the-plugin-adds\}

AI 工具可以通过 [Adapty MCP 服务器](adapty-mcp) 或 [Adapty CLI](developer-cli-quickstart) 访问你的 Adapty 账户，从而读取和修改你的数据。插件为 AI 工具提供了正确完成这些操作所需的知识：

- **流程配置规则**：流程是一个大型 JSON 配置，其规则只存在于插件中。有了这些规则，你的工具可以根据描述或截图构建页面，并在保存流程之前验证和预览每处更改。没有这些规则，你的工具虽然可以读写流程配置，但无法构建出有效的配置。
- **经过验证的方法**：插件知道哪些报告能回答特定问题、如何解读这些报告，以及你的数据与市场相比处于什么水平。它会将你的数据转化为 A/B 测试假设，并按潜在收益大小排序。
- **最新的 Adapty API**：在集成 SDK 时，插件会在每个阶段读取最新的 Adapty 文档，因此你的工具会根据你实际安装的 SDK 版本编写代码，而不是依赖训练数据中记忆的旧版本。
- **变更上线前需确认**：在启动 A/B 测试、修改版位或向真实用户发送邮件之前，插件会向你展示即将发生的变更，并等待你的确认。
- **连接方式**：插件会自动检测你的工具是否接入了 MCP 服务器、CLI 或两者，并为每项任务选择最合适的方式。

## 安装插件 \{#install-the-plugin\}

<Tabs groupId="ai-tool">
<TabItem value="coding-agent" label="Coding agent" default>

该插件适用于所有支持技能的编程 Agent：Claude Code、Codex、Cursor、GitHub Copilot、Gemini CLI 等。

如需安装插件，请在终端中运行：

```bash
npx adapty skills install
```

重启 Agent 以加载插件。其他安装方式请参阅 [插件 README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install)。

Claude Code 不会自动更新插件。要获取新技能，请在 Claude Code 中运行 `/plugin`，打开 **Marketplaces**，选择 `adapty`，然后选择 **Enable auto-update**。

在 Claude Code 和 Codex 中，插件还会添加 Adapty MCP 服务器，因此你只需登录，具体步骤请参见[连接你的助手](adapty-mcp#connect-your-assistant)。在其他智能体中，当某个技能首次需要访问你的账户时，插件会询问你是使用 Adapty CLI 还是 MCP 服务器，并提供你所选方式的配置步骤。

</TabItem>

<TabItem value="claude-ai" label="claude.ai">

插件安装在 Claude 的设置界面中完成，无需命令行。在 Claude 桌面版中步骤相同。

1. 在 Claude 中，打开 **Settings** → **Plugins**。
2. 点击 **Add** → **Add marketplace**。
3. 选择 **Add from a repository**。
4. 在 **URL** 字段中输入 `adaptyteam/adapty-skills`，然后选择该仓库。若希望自动获取新技能和修复更新，请保持 **Sync automatically** 开启。
5. 点击 **Sync**。

<ZoomImage id="adapty-skills-claude-add-marketplace.png" width="584px" alt="Add marketplace dialog in Claude with adaptyteam/adapty-skills in the URL field and Sync automatically turned on" />

Claude 打开 **Discover** 标签页，显示来自 Adapty 市场的插件。如需安装插件，在 **Adapty** 行中点击 **Add**。

<ZoomImage id="adapty-skills-claude-discover.png" width="600px" alt="Discover tab in Claude listing the Adapty, Apple ads, and Apple ads benchmarks plugins, each with an Add button" />

该插件在 Claude 的沙盒中运行脚本。要启用此功能，请在 **Settings** → **Capabilities** 中开启 **Code execution and file creation**。

要让 Claude 访问您的 Adapty 账户，请按照[连接您的助手](adapty-mcp#connect-your-assistant)中的说明，将 Adapty MCP 服务器添加为连接器并登录。

## 你可以做什么 \{#what-you-can-do\}

你不需要指定技能名称。像给同事布置任务一样描述需求，插件会自动选择对应的工作流。

### 集成 SDK \{#integrate-the-sdk\}

```
Integrate Adapty into my app
```

该插件会在 Adapty 看板中配置你的应用、安装 SDK、添加付费墙，并在进入下一步前验证每个阶段。它能自动检测你的平台。请参阅以下指南：[iOS](adapty-sdk-integration-skill)、[Android](adapty-sdk-integration-skill-android)、[React Native](adapty-sdk-integration-skill-react-native)、[Flutter](adapty-sdk-integration-skill-flutter)、[Unity](adapty-sdk-integration-skill-unity)、[Kotlin Multiplatform](adapty-sdk-integration-skill-kmp) 或 [Capacitor](adapty-sdk-integration-skill-capacitor)。

### 构建与编辑流程 \{#build-and-edit-flows\}

```
Add a German locale to my onboarding flow
```

该插件[构建并编辑流程](flow-generator-skill)：添加语言区域、改写文案、增删页面、配置问答分支逻辑，以及根据描述构建付费墙。在发布之前，它还会[审查流程](flow-audit-skill)，检查触发器、商店合规性、产品和本地化配置。如果你的版位展示的是付费墙，该插件可以[将其迁移至流程](migrate-placements-skill)。

### 寻找下一个测试方向 \{#find-what-to-test-next\}

```
Audit my app. What should I test next to grow revenue?
```

该插件[读取您的分析数据、定价信息和历史 A/B 测试](export-analytics-with-ai)，对照市场标准对您业务的各个环节进行评分，并返回按潜在收入影响排序的测试假设。它还能回答关于您数据的直接问题，例如上个月续订量下降的原因。

### 运行 A/B 测试 \{#run-ab-tests\}

```
Start a 50/50 test of my two onboarding paywalls
```

该插件可为付费墙和流程[创建、启动、停止和替换 A/B 测试](ab-tests-skill)。

### 分析你的广告活动 \{#analyze-your-ad-campaigns\}

```
Which campaigns should I scale, and which should I cut?
```

该插件[读取你的 Adapty 归因数据](developer-cli-attribution-skill)：广告支出回报率（ROAS）、回本周期、单次试用成本以及各渠道、广告系列和国家的退款数据。

:::tip
Apple Ads 广告活动有专属插件。请参阅[使用 AI 编程工具管理 Apple Ads](developer-cli-ads-manager-skill)。
:::

### 运行 Adapty Mail

```
Why didn't this user get the welcome email?
```

该插件[连接 Adapty Mail MCP 服务器](mail-skill)，启动邮件流程，并追踪邮件未发送的原因。在实际发送邮件给真实用户之前，它会先请求确认。

### 从 RevenueCat 迁移 \{#migrate-from-revenuecat\}

```
Move my RevenueCat project to Adapty
```

您的编程智能体会将您的 RevenueCat 商品目录和付费墙设计复制到新的 Adapty 应用中，然后将代码中的 RevenueCat SDK 调用替换为使用匹配 Adapty ID 的调用。请参阅[从 RevenueCat 迁移](migration-from-revenuecat)。

## 插件如何连接到您的账户 \{#how-the-plugin-reaches-your-account\}

该插件通过两种连接方式工作。如果您的工具两种都未配置，插件会询问您要设置哪一种，并提供相应步骤。两种都配置好后，插件会根据不同任务选择对应的连接方式：

- **[Adapty MCP 服务器](adapty-mcp)**：适用于 claude.ai、Claude 桌面端以及支持 MCP 的编程代理的连接方式。在浏览器中登录 Adapty 账号即可使用，无需 API 密钥。
- **[Adapty CLI](developer-cli-quickstart)**：适用于执行终端命令的编程代理的连接方式。流程和分析工作流优先使用此方式，因为它们需要操作本地文件。你也可以自己运行 CLI 或在脚本中调用它。

## 借助 AI 构建后端 \{#build-your-backend-with-ai\}

以下两份指南适用于您自己服务器端的代码。将指南复制到 AI 编程工具中，即可在一次粘贴中获得可运行的代码、字段注意事项和限制说明：

- [处理订阅事件](handle-webhooks-with-ai)：在您的端点接收 Adapty webhook。
- [检查并授予订阅访问权限](server-side-api-with-ai)：从您的后端调用 Adapty 服务端 API。

## 为您的 AI 工具提供 Adapty 文档 \{#give-your-ai-tool-the-adapty-docs\}

### 纯文本文档 \{#plain-text-docs\}

每篇 Adapty 文档都提供 Markdown 格式——在页面 URL 末尾加上 `.md`，或点击标题下方的 **Copy for LLM**。如需更广泛的上下文，可将 [`llms.txt`](https://adapty.io/docs/zh/llms.txt) 索引或特定平台的子集（如 [`ios-llms.txt`](https://adapty.io/docs/zh/ios-llms.txt)）提供给你的工具。

### Context7

[Context7](https://context7.com/adaptyteam/adapty-docs) 是一个 MCP 服务器，可将 Adapty 文档提供给你的 AI 工具，但它只索引代码片段，而非完整的文档内容。如需快速查找代码示例，可以使用它；如需完整指引，请将[纯文本文档](#plain-text-docs)提供给你的工具。Context7 仅提供文档服务；若要操作你的账户，请[安装 Adapty 插件](#install-the-plugin)。
