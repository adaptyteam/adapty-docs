<SDKv4>

在观察者模式下，Adapty SDK 无法自动跟踪通过您现有购买系统完成的购买行为。您需要手动从应用商店上报交易。在发布应用**之前**完成此设置至关重要，否则可能导致分析数据出错。

使用 `reportTransaction` 显式上报每笔交易，以便 Adapty 识别它。

:::warning

**请勿跳过交易上报！**
如果您不调用 `reportTransaction`，Adapty 将无法识别该交易，它不会出现在分析数据中，也不会被发送至集成渠道。

:::

如果您使用 Adapty 流程和付费墙，请在上报交易时附上 `variationId`。这能将购买行为与触发它的流程或付费墙关联起来，从而确保分析数据准确。

:::warning
请传入用户购买的 `AdaptyPaywallProduct` 的 `variationId`，而不是 `AdaptyFlow.variationId`。流程自身的 variation ID 无法将购买行为与该流程关联。
:::

```typescript showLineNumbers

const variationId = product.variationId; // the AdaptyPaywallProduct the user bought

try {
  await adapty.reportTransaction({ 
    transactionId: 'your_transaction_id',
    variationId: variationId 
  });
} catch (error) {
  console.error('Failed to report transaction:', error);
}
```

参数：

| 参数 | 是否必填 | 描述 |
| ------------- | -------- | ------------------------------------------------------------ |
| **transactionId** | 必填 | <ul><li> iOS：交易的标识符。</li><li> Android：购买的字符串标识符（`purchase.getOrderId`），其中 purchase 是计费库 [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) 类的实例。</li></ul> |
| **variationId**   | 选填 | 实验变体的字符串标识符。请传入用户购买的 `AdaptyPaywallProduct` 的 `variationId`，与包含该产品的 `AdaptyFlowPaywall` 的 `variationId` 值相同。 |
| **ios.jwsTransaction** | 选填 | 仅限 iOS，SDK 4.3.0 及以上版本。已签名的 StoreKit 2 交易：即与 `transactionId` 对应的同一交易，其验证结果的 `jwsRepresentation`。SDK 会将其原样发送给 Adapty。Android 会忽略此参数。 |

在 iOS 上，如果你的购买系统提供了 StoreKit 2 交易对象，请通过 `ios.jwsTransaction` 传入其 JWS 表示：

```typescript showLineNumbers
await adapty.reportTransaction({
  transactionId: 'your_transaction_id',
  variationId: variationId, // optional
  ios: { jwsTransaction: 'YOUR_JWS_REPRESENTATION' }, // iOS only, optional
});
```

</SDKv4>

<SDKv3>

在 Observer 模式下，Adapty SDK 无法自动追踪通过现有购买系统完成的购买行为。你需要手动上报来自应用商店的交易。请务必在发布应用**之前**完成此配置，以避免数据分析出现错误。

使用 `reportTransaction` 明确上报每笔交易，以便 Adapty 识别。

:::warning

**不要跳过交易上报！**
如果未调用 `reportTransaction`，Adapty 将无法识别该交易，它不会出现在数据分析中，也不会被发送到各集成渠道。

:::

如果您使用 Adapty 的流程和付费墙，请在上报交易时包含 `variationId`。这会将购买行为关联到触发它的流程或付费墙，从而确保分析数据的准确性。

```typescript showLineNumbers

const variationId = paywall.variationId;

try {
  await adapty.reportTransaction({ 
    transactionId: 'your_transaction_id',
    variationId: variationId 
  });
} catch (error) {
  console.error('Failed to report transaction:', error);
}
```

参数：

| 参数     | 是否必填 | 描述                                                  |
| ------------- | -------- | ------------------------------------------------------------ |
| **transactionId** | 必填 | <ul><li> iOS：交易的标识符。</li><li> Android：购买的字符串标识符（`purchase.getOrderId`），其中 purchase 是 billing library [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) 类的实例。</li></ul> |
| **variationId**   | 选填 | 实验变体的字符串标识符。可通过 `AdaptyPaywall` 对象的 `variationId` 属性获取。 |

</SDKv3>
