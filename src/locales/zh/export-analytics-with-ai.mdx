用自然语言向 AI 编程助手查询 Adapty 数据分析——营收、转化率、留存率、LTV——让它帮你获取数据。该助手会在你的终端中运行 [Adapty CLI 分析命令](developer-cli-analytics)并读取结果。

## 你可以询问哪些内容 \{#what-you-can-ask-about\}

CLI 返回的数字与 Adapty Analytics 看板上显示的数据完全一致。每种问题对应一条命令：

| 问题类型 | 涵盖内容 | 命令 |
| --- | --- | --- |
| 收入、MRR、ARR、ARPU 及其他数据图表 | 某项数据图表随时间的变化，按该图表支持的维度（如国家）分组 | `adapty analytics chart` |
| 转化率 | 用户从一个步骤推进到下一步骤的比例，例如从试用转为付费 | `adapty analytics conversion` |
| 漏斗 | 用户在安装到续费之间的流失节点 | `adapty analytics funnel` |
| 留存率 | 每个周期后仍活跃的订阅用户数量 | `adapty analytics retention` |
| 生命周期价值（LTV） | 每位付费用户在每次续费或每天后产生的收入 | `adapty analytics ltv` |
| 安装同期群 | 同一时期安装的用户的收入、订阅者数量及趋势预测 | `adapty analytics cohort` |

所有命令均为只读操作。代理无法通过这些命令对您的 Adapty 账户进行任何更改。

## 开始之前 \{#before-you-start\}

你需要准备以下三样东西：

- **已有数据的 Adapty 账号**：CLI 返回的数据与看板中的数字一致，因此你的应用必须已经开始收集分析数据。
- **Adapty CLI 0.10.0 或更高版本，并已登录**：运行以下命令安装 CLI 并登录。登录时会打开一个浏览器标签页，在其中确认终端显示的验证码。

  ```bash
  npm install -g adapty
  ```

  ```bash
  adapty auth login
  ```

  一次登录即可访问你的 Adapty 用户有权限查看的所有应用，无需 API 密钥。

- **能够运行终端命令的 AI 工具**：例如 Claude Code、Cursor、Codex 或 Gemini CLI。claude.ai 或 ChatGPT 等纯聊天工具无法运行 CLI。

## 为你的 Agent 提供命令参考 \{#give-your-agent-the-commands\}

[CLI 分析参考文档](https://adapty.io/docs/zh/developer-cli-analytics.md)详细描述了每个命令、其参数标志以及如何解读结果。Agent 读取后，无需你手动编写即可构建正确的命令。

通过 URL 将参考文档提供给 Agent：如果你的 Agent 支持抓取 URL，请将 `https://adapty.io/docs/zh/developer-cli-analytics.md` 提供给它，并让它读取该页面。

代理无需提前了解您的数据图表名称。只需运行 `adapty analytics catalog --app <app-id>`，即可列出您的应用支持的所有数据图表、转化指标、分组维度和筛选条件。

## 询问你的数据 \{#ask-about-your-data\}

加载好参考文档并登录 CLI 后，说明应用名称、数据图表、时间段以及你想做的决策。

示例提示语：

```
For my app "Sleep Tracker", what was MRR at the end of each month this year,
and how does it compare to the same months last year?

Show the trial-to-paid conversion rate for the last 90 days, by product.
Which product converts worst?

Which 10 countries brought the most revenue in Q3? Use revenue after the
store's commission.

How does retention compare between iOS and Android for subscribers who started
in the last 6 months?

Compare LTV after 30 and 90 days for users who installed in July and in August,
and save it as a CSV file.
```

智能体通过 `adapty apps list` 查找应用的 UUID，选择对应命令并返回数据。结果以 JSON 格式读取（`--json`）。如需电子表格格式的文件，可要求 CSV 输出——智能体会在命令中添加 `--csv`。

## 一次配置，反复使用 \{#set-up-once-for-repeated-use\}

为避免每次会话都重复配置，请将参考内容保存到 agent 可复用的位置：

- **保存参考链接**：将 `https://adapty.io/docs/zh/developer-cli-analytics.md` 添加到你的 agent 规则或记忆文件（例如 `CLAUDE.md` 或 Cursor 规则文件）中，以便每次会话时自动加载。
- **命名你的应用**：将应用名称或 UUID 也添加到同一文件，这样就不必在每个提示中重复指定了。
- **保存常用提示或创建自定义技能**：将你的常见问题保存为固定提示，或者将其封装成自定义技能或斜杠命令，让 agent 随时按需生成报告。

## 限制 \{#limits\}

请注意以下限制：

- **速率限制**：每个分析命令每个应用每秒允许 2 次请求。CLI 不会自动重试，因此发送过快的命令会以退出码 4 失败。请告知你的 agent 逐条运行命令，并在失败后等待 `retry_after_seconds` 再重试。
- **每条命令对应一个应用**：每条命令只读取一个应用的数据。如需比较多个应用，agent 需为每个应用分别运行命令。
- **不纳入归因数据**：广告花费、安装量和按广告系列统计的 ROAS，请使用 [归因命令](developer-cli-attribution)。不要将其数据与分析数据相加，因为 Adapty 的计算方式不同。

要从服务器或定时任务中提取分析数据（这类场景无法通过浏览器登录），请改用[导出分析 API](export-analytics-api) 并配合密钥使用。
