SDK 返回的所有错误均为 `AdaptyError` 类型。
:::tip
**在调试前开启详细日志。** 大多数 `AdaptyError` 都封装了底层的 Play Billing、网络或后端错误。开启详细日志（`Adapty.logLevel = AdaptyLogLevel.VERBOSE` — 参见[日志记录](sdk-installation-android#logging)）后，封装的错误会打印到控制台，通常能直接告诉你真正的原因。
:::

:::important
如果以上方案未能解决你的问题，请查看[其他问题](#other-issues)，了解联系支持前需要做哪些准备，以便我们更高效地为你提供帮助。
:::

## 流程渲染错误 \{#flow-rendering-errors\}

Adapty SDK 4.0 及更高版本通过 `AdaptyFlowEventListener` 中的 `onError` 回调报告这些错误，而不是从方法调用中直接返回。详情请参阅[在 Android SDK 中处理事件](android-handling-events)。

| 错误 | 解决方案 |
|-------|----------|
| WRONG_ASSET_TYPE | 流程中某个图片元素指向的资产是颜色或渐变填充，SDK 因此在该位置渲染了占位符。请在[流程编辑工具](adapty-flow-builder)中为该元素指定图片资产。 |
| JS_EXCEPTION | 流程的 JavaScript 抛出了异常。请查看错误信息中的异常详情。 |
| NAVIGATOR_NOT_FOUND | 打开页面的操作指定了一个不存在于流程视图配置中的导航器，且该流程没有可回退的 `default` 导航器。请在[流程编辑工具](adapty-flow-builder)中检查该操作的目标设置。 |
| INVALID_ACTION_URL | 打开 URL 的操作引用了一个无法解析为 URL 的字符串 ID。请在[流程编辑工具](adapty-flow-builder)中为该操作设置有效的 URL。 |

## 其他问题 \{#other-issues\}

如果您尚未找到解决方案，可以采取以下后续步骤：

- **将 SDK 升级到最新版本**：我们始终建议升级到最新的 SDK 版本，因为它们更稳定并包含已知问题的修复。
- **联系支持团队或在[支持论坛](https://adapty.featurebase.app/)中获得其他开发者的帮助**。
- **通过 [support@adapty.io](mailto:support@adapty.io) 或在线聊天联系支持团队**：如果您还不打算升级 SDK 或升级后问题仍未解决，请联系我们的支持团队。请注意，如果您[启用详细日志记录](sdk-installation-android#logging)并与团队共享日志，您的问题将得到更快解决。您也可以附上相关代码片段。
