:::warning
**用户引导功能已在 SDK v4 中弃用，并将在未来版本中移除。** 该功能不再接受修复或改进。请改用[流程](unity-get-pb-paywalls)：与在 WebView 中运行的用户引导不同，流程直接在设备上原生渲染，带来更流畅的动画效果、一致的原生外观、更快的加载速度，且无需依赖 WebView 运行时。请参阅[获取流程与付费墙](unity-get-pb-paywalls)和[展示流程与付费墙](unity-present-paywalls)快速上手。
:::

当您的用户回答测验问题或在输入字段中填写数据时，`OnboardingViewOnStateUpdatedAction` 方法将被调用。您可以在代码中保存或处理字段类型。

在您的类中实现 `OnboardingViewOnStateUpdatedAction` 方法：

:::note
在 SDK 4.0 中，监听器接口遵循 C# 的 I 前缀命名规范：请实现 `IAdaptyOnboardingsEventsListener` 而非 `AdaptyOnboardingsEventsListener`。方法本身保持不变。详见[迁移指南](migration-to-unity-sdk-v4)。
:::

```csharp showLineNumbers title="Unity"
public class OnboardingManager : MonoBehaviour, AdaptyOnboardingsEventsListener
{
    public void OnboardingViewOnStateUpdatedAction(
        AdaptyUIOnboardingView view,
        AdaptyUIOnboardingMeta meta,
        string elementId,
        AdaptyOnboardingsStateUpdatedParams @params
    )
    {
        switch (@params) {
            case AdaptyOnboardingsSelectParams selectParams:
                // handle single selection
                break;
            case AdaptyOnboardingsMultiSelectParams multiSelectParams:
                // handle multiple selections
                break;
            case AdaptyOnboardingsInputParams inputParams:
                // handle text input
                break;
            case AdaptyOnboardingsDatePickerParams datePickerParams:
                // handle date selection
                break;
        }
    }
    
    // ... other interface methods
}
```

参数说明如下：

| 参数      | 描述                                                                                                                                                                                                                                                                                     |
|----------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `elementId`    | 输入元素的唯一标识符。保存答案时可用它将问题与答案关联起来。                                                                                                                                                                                                 |
| `@params`       | 用户输入数据对象，可以是以下类型之一。                                                                                                                                                                                                              |
| `AdaptyOnboardingsSelectParams`  | 从选项中单选。包含 `Id`、`Value`、`Label`                                                                           |
| `AdaptyOnboardingsMultiSelectParams` | 从选项中多选。包含一个 `Params` 列表（每项包含 `Id`、`Value`、`Label`）<br/>• `input`：包含 `type`、`value` 的对象<br/>• `datePicker`：包含 `day`、`month`、`year` 的对象 |
| `AdaptyOnboardingsInputParams` | 文本输入字段。包含 `Input`，可以是 `AdaptyOnboardingsTextInput`、`AdaptyOnboardingsEmailInput` 或 `AdaptyOnboardingsNumberInput` |
| `AdaptyOnboardingsDatePickerParams` | 日期选择。包含可为空的 `Day`、`Month`、`Year` |

## 使用场景 \{#use-cases\}

### 用户画像数据补充 \{#enrich-user-profiles-with-data\}

如果希望立即将用户输入的数据与其用户画像关联，避免重复询问相同信息，则需要在处理操作时通过 [更新用户画像](unity-setting-user-attributes) 的方式将输入数据写入。

例如，您让用户在 ID 为 `name` 的文本字段中输入姓名，并希望将该字段的值设置为用户的名字；同时让用户在 `email` 字段中输入邮箱地址。在您的应用代码中，示例如下：

```csharp showLineNumbers title="Unity"
public class OnboardingManager : MonoBehaviour, AdaptyOnboardingsEventsListener
{
    public void OnboardingViewOnStateUpdatedAction(
        AdaptyUIOnboardingView view,
        AdaptyUIOnboardingMeta meta,
        string elementId,
        AdaptyOnboardingsStateUpdatedParams @params
    )
    {
        if (@params is AdaptyOnboardingsInputParams inputParams) {
            var builder = new AdaptyProfileParameters.Builder();
            
            switch (elementId) {
                case "name":
                    if (inputParams.Input is AdaptyOnboardingsTextInput textInput) {
                        builder.SetFirstName(textInput.Value);
                    }
                    break;
                case "email":
                    if (inputParams.Input is AdaptyOnboardingsEmailInput emailInput) {
                        builder.SetEmail(emailInput.Value);
                    }
                    break;
            }
            
            Adapty.UpdateProfile(builder.Build(), (error) => {
                if (error != null) {
                    // handle the error
                }
            });
        }
    }
    
    // ... other interface methods
}
```

### 根据答案自定义付费墙 \{#customize-paywalls-based-on-answers\}

通过在用户引导中加入问卷，你可以根据用户完成引导后的答案来自定义向他们展示的付费墙。

例如，你可以询问用户的运动经验，然后向不同用户群展示不同的 CTA 和产品。

1. 在用户引导编辑器中[添加问卷](onboarding-quizzes)，并为每个选项设置有意义的 ID。

<ZoomImage id="experience.webp" />

2. 根据 ID 处理问卷响应，并为用户[设置自定义属性](unity-setting-user-attributes)。

```csharp showLineNumbers title="Unity"
public class OnboardingManager : MonoBehaviour, AdaptyOnboardingsEventsListener
{
    public void OnboardingViewOnStateUpdatedAction(
        AdaptyUIOnboardingView view,
        AdaptyUIOnboardingMeta meta,
        string elementId,
        AdaptyOnboardingsStateUpdatedParams @params
    )
    {
        if (@params is AdaptyOnboardingsSelectParams selectParams) {
            var builder = new AdaptyProfileParameters.Builder();
            
            switch (elementId) {
                case "experience":
                    // set custom attribute 'experience' with the selected value (beginner, amateur, pro)
                    builder.SetCustomStringAttribute("experience", selectParams.Value);
                    break;
            }
            
            Adapty.UpdateProfile(builder.Build(), (error) => {
                if (error != null) {
                    // handle the error
                }
            });
        }
    }
    
    // ... other interface methods
}
```

3. 为每个自定义属性值[创建市场细分](segments)。
4. 创建一个[版位](placements)，并为每个市场细分添加[目标受众](audience)。
5. 在你的应用代码中为该版位[展示付费墙](unity-paywalls)。如果你的用户引导中有打开付费墙的按钮，请将付费墙代码作为[该按钮操作的响应](unity-handling-onboarding-events#opening-a-paywall)来实现。
