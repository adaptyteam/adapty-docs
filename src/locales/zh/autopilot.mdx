AI Growth Advisor 告诉你如何改进应用来提升收入，并帮助你通过 A/B 测试加以验证。你的 AI 智能体使用 [growth-advisor skill](export-analytics-with-ai) 完成分析和配置工作。Adapty 看板中的 **AI Growth Advisor** 页面保存了所有结果：你的团队决定推进的每一个增长假设，从想法到 A/B 测试结果，全程可追溯。

<ZoomImage id="ai-growth-advisor-hypotheses.webp" width="700px" alt="The AI Growth Advisor page with two hypotheses on the Hypotheses tab, each with its placement, flow or segment, rationale, and expected impact" />

## 工作原理 \{#how-it-works\}

1. **智能体读取您的数据。** 包括收入、从安装到付费每个步骤的转化率、续订、退款、主要国家/地区，以及您的版位、流程、产品、价格和历史 A/B 测试。它读取账户中的所有内容，未经您确认不会进行任何更改。
2. **与市场基准对标。** 根据 Adapty 发布的《付费墙现状》和《应用内订阅现状》报告，对您所在地区和类别的市场中位数，将业务的每个环节评定为强、一般或弱。薄弱环节按每月损失金额排序。
3. **提出优化假设。** 每个假设包含一项具体变更建议、您的应用为何需要它的原因、来自真实订阅 A/B 测试的预期结果，以及在您当前流量下完成 A/B 测试所需的时间。
4. **筛选值得测试的假设。** 您采纳的假设会显示在此页面上，供整个团队查看。您跳过的假设会连同您的理由一起归档，智能体不会再次重复建议。
5. **智能体搭建 A/B 测试。** 它会构建测试所需的流程文案、产品或市场细分，创建测试并将其与对应假设关联。每项更改都需等待您的确认。
6. **由您判定结果。** 当测试积累了足够多的购买数据后，智能体会展示各实验变体的数据并询问您哪个获胜。结果将保存在假设中，后续假设可以在此基础上继续推进。

智能体每次对话都从这份列表开始，因此不会重复建议你已经测试过的内容，新团队成员也能看到所有已测试内容及其原因的完整历史记录。

## 开始之前 \{#before-you-start\}

- **带有 Adapty 插件的 AI 智能体**：growth-advisor 技能是 [Adapty 插件](manage-adapty-with-ai)的一部分，可在 Claude Code、Codex 等代码智能体以及 claude.ai 中使用。
- **Adapty 中的数据**：该技能会根据你自己的收入、转化率和续订数据，将你的应用与市场进行对标评分。若暂无数据，它会根据市场中位数提供一份初始方案。

## 获取你的第一批假设 \{#get-your-first-hypotheses\}

1. 安装 Adapty 插件，请参考[安装技能](export-analytics-with-ai#install-the-skill)。

2. 要获取适合你应用的提示词，请在 **AI Growth Advisor** 页面点击 **Copy to agent**。如果列表中已有假设，点击 **How it works** 并在那里复制提示词。该提示词会要求 Agent 审查你的应用并制定测试计划，并包含你的应用 ID，以便 Agent 读取正确的应用数据。

3. 将提示词粘贴到你的 Agent 中。Agent 会审查你的应用并返回一份假设列表，然后询问哪些需要加入列表、哪些可以跳过。

4. 告诉 Agent 要添加哪些假设。Agent 会将其保存，并显示在 **AI Growth Advisor** 页面上。

<ZoomImage id="ai-growth-advisor-empty.webp" width="500px" alt="The empty AI Growth Advisor page with two steps: install the Adapty Skills plugin, then copy the prompt to your agent" />

你不必从看板开始操作。每当 growth-advisor 技能提出假设时（例如在你询问"接下来应该测试什么？"之后），它都会询问你要添加哪些假设。

:::tip
你跳过的假设会连同你填写的原因一起保存到 **Archived** 中，这样 agent 就不会再次建议它。如果你想暂时保留某个假设，告诉 agent "not now"即可。
:::

## 按阶段划分的假设 \{#hypotheses-by-stage\}

以下标签页展示了假设从创意到结果的完整流程：

| 标签页 | 显示内容 |
|---|---|
| **Hypotheses** | 等待 A/B 测试的假设，包括已起草并准备启动 A/B 测试的假设 |
| **Testing** | 正在运行 A/B 测试的假设 |
| **Completed** | 已完成 A/B 测试的假设，以及未经测试直接上线的变更 |
| **Archived** | 你归档的假设，以及代理建议时被跳过的假设 |

当一个标签页显示多种类型的假设时，您可以按类型筛选：**Visual**、**Pricing**、**Geo-pricing**、**Audience** 或 **Other**。标签页和筛选条件会记录在页面 URL 中，方便您与团队共享当前视图。

每张假设卡片显示以下信息：

- **更改内容与原因**：标题、具体更改内容，以及在 **Rationale** 下说明应用需要此次更改的原因。
- **运行位置**：**版位**，以及所更改的 **Flow** 或 **市场细分**。在 Adapty 中已删除的版位、Flow 或市场细分会被标记为 **Deleted**。
- **预期影响**：用于评判 A/B 测试的数据图表，例如 ARPU 或试用转化率（CR to trial），以及预期范围。该范围是根据市场数据和真实 A/B 测试估算所得，实际结果可能有所不同。
- **基于**：此次测试所依托的假设，例如在某次已完成的 A/B 测试后的下一步行动。

## 使用 Agent 继续推进假设 \{#continue-a-hypothesis-with-your-agent\}

每张卡片都有一个按钮，可以复制发给 Agent 的提示词。提示词中包含假设名称，Agent 会读取其在 Adapty 中的当前状态并从中继续推进，无需你再解释进度。

卡片提供的内容取决于其状态：

| 状态 | 按钮 | Agent 对提示词的处理 |
|---|---|---|
| 无状态 | **Copy to agent** | 构建 A/B 测试所需内容，例如复制流程或创建新产品，并配置测试 |
| **Ready to launch** | **Launch test**、**Copy to agent** | 与你一起审查 A/B 测试草稿并协助你启动测试。**Launch test** 会打开草稿，你在其中启动测试 |
| **Test running** | **View test**、**Copy to agent** | 报告测试进度及是否可以停止 |
| **Needs review** | **View results**、**Discuss with agent** | 与你一起审查结果，并询问测试是胜出、落败还是无定论。卡片可能会显示 Adapty 建议的结果 |
| **Won**、**Lost**、**Inconclusive** | **View results**、**Discuss with agent** | 审查结果并建议下一步操作 |
| **Applied without test** | **Discuss with agent** | 回顾变更上线后的表现并建议下一步操作 |

<ZoomImage id="ai-growth-advisor-completed.webp" width="700px" alt="已完成标签页显示三个假设：一个标记为已获胜，一个标记为需要审核，一个标记为已应用但未经测试" />

测试停止后，若有获胜者，其假设会自动移至 **Completed** 标签页。若测试结束时没有获胜者，则会显示 **Needs review** 状态，直到你告知代理结果为止。

:::tip
如需在测试可决策时主动获得通知，而无需手动查询，可让代理按计划自动检查。请参阅[设置定期检查](growth-advisor-recurring-checks)。
:::

## 归档假设 \{#archive-a-hypothesis\}

要从列表中移除某个假设，请在其卡片上点击 **Archive**。归档操作只影响列表显示：该假设对应的产品、A/B 测试、流程和版位在 Adapty 中仍会正常运行。如需恢复，请在弹出的提示信息中点击 **Undo**，或稍后在 **Archived** 标签页中点击 **Restore**。

恢复后的假设将作为新假设重新出现，不包含之前关联的 A/B 测试。

## 来自 Autopilot v1 的假设 \{#hypotheses-from-autopilot-v1\}

AI Growth Advisor 曾经根据看板中的付费墙和市场分析来制定增长计划。该分析功能现已不再提供。这些增长计划中的假设仍会保留在你的列表中，并标有 **Autopilot v1** 徽章。在此类卡片上点击 **Copy to agent**，会同时复制其标题、变更内容和依据，以便 agent 直接使用。
