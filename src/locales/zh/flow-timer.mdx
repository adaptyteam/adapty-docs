**倒计时**从固定时长或指定日期时间开始倒数至零。归零后，计时器显示将定格。

## 模板 \{#templates\}

<ZoomImage id="countdown-templates.webp" width="200px" alt="Countdown timer templates" float="left" />

该分类提供四种视觉样式：

- **Blocks** — 将天、时、分、秒分别显示在带标签的独立格子中。
- **Inline Units** — 带单位后缀的单行文本。
- **Inline** — 纯数字显示。
- **Badge** — 胶囊形数字展示。

## 设置 \{#settings\}

<ZoomImage id="builder-countdown-settings.webp" width="300px" float="right" alt="右侧面板中的倒计时设置" />

### 设置时长 \{#set-the-duration\}

在右侧面板的 **Countdown** 区域，输入倒计时的初始时长（天、小时、分钟、秒）。小时字段最多可输入 999，因此 72 小时的倒计时可以直接输入 `72h`，而无需换算成 `3d`。两种写法效果完全相同：超过 23 的小时数在 `timer_days` 中仍会按整天计算。

设置了 **Until date** 行为的计时器没有时长。如需设置结束时间，请参阅[倒计时至指定日期](#count-down-to-a-date)。

### 更改时间格式 \{#change-the-time-format\}

计时器中的文本通过计时器变量显示剩余时间。如需更改计时器显示的时间单位，请选择计时器内的文本元素，然后在 **Content** 部分点击 <Inline id="variables.svg" alt="Variables" /> **Add variable** 并选择一个计时器变量。

| 变量 | 显示内容 | 53 小时倒计时开始时的值 |
|---|---|---|
| `timer_days` | 剩余完整天数 | `02` |
| `timer_hours` | 当天剩余小时数，范围 0 到 23 | `05` |
| `timer_total_hours` | 剩余总小时数，包含完整天数 | `53` |
| `timer_minutes` | 当前小时内剩余分钟数 | `00` |
| `timer_seconds` | 当前分钟内剩余秒数 | `00` |

若要将超过一天的倒计时仅以小时形式显示，例如 `48:00:00` 或 `72:00:00`，请使用 `timer_total_hours:timer_minutes:timer_seconds`。不要在同一文本中添加 `timer_days`：`timer_total_hours` 已包含天数，同时添加会导致重复计算。

### 配置行为 \{#configure-the-behavior\}

**Behavior** 下拉菜单控制计时器的启动时机，或让其倒计时至指定日期：

- **Every appear** — 每次用户打开该页面时重新开始计时。默认选项。
- **First appear** — 在当前应用会话中用户首次查看该页面时开始计时。若用户在同一会话内返回该页面，计时继续；应用重新启动后计时重置。
- **First appear (persisted)** — 在用户首次打开该页面时开始计时，并在应用重启后保持持续计时。
- **Until date** — 倒计时至指定日期和时间，例如某次促销活动的结束时间。请参阅[倒计时至指定日期](#count-down-to-a-date)。

### 倒计时至指定日期 \{#count-down-to-a-date\}

<ZoomImage id="flow-timer-until-date.webp" width="300px" float="right" alt="倒计时部分，行为设置为“Until date”：截止日期 28.11.2026，时间 23:59，时区 Europe/Berlin，且“User's local time”复选框未勾选" />

若要在限时活动（例如黑色星期五促销）中显示真实剩余时间，请设置倒计时至活动结束日期，而非从某个时长开始倒计时：

1. 在 **Behavior** 下拉菜单中，选择 **Until date**。持续时间字段将变为结束日期字段。
2. 在 **End date** 字段中，选择活动的最后一天。
3. 在 **Time** 字段中，输入结束的小时和分钟。默认值为 23:59。
4. 在 **Time zone** 下拉菜单中，选择结束时使用的时区。默认值为浏览器所在时区。

选择时区后，活动结束对所有用户而言是同一时刻。两个在不同日期打开页面的用户，在同一时刻看到的倒计时是相同的，重新打开页面或重启应用也不会重置计时器。

如果希望活动在每位用户所在时区的相同时刻结束（例如各地的午夜），请选择 **User's local time**。每台设备将根据自身时钟倒计时至设定的日期和时间，因此不同时区的用户会在不同时刻归零。

在结束日期和时间到达时，计时器显示为零，并触发其 **On timer end** 事件。在结束后打开该页面的用户会立即看到零，且该触发器在每次打开页面时运行一次。计时器会保留在页面上：若要在促销结束后移除计时器或折扣角标，请添加一个带有 **Hide element** 动作的 **On timer end** 触发器（参见[显示或隐藏元素](flow-show-hide-animations#show-or-hide-an-element)）。

:::note
在每个 **Until date** 计时器都设置了结束日期之前，编辑工具不会发布流程。流程仍可在没有结束日期的情况下保存。过去的结束日期也有效：计时器从一开始就显示为零。
:::

计时器根据设备时钟计算剩余时间，因此用户修改设备时钟后，剩余时间也会随之改变。

### 计时器结束时触发操作 \{#trigger-an-action-when-the-timer-ends\}

:::link
主文章：[操作](onboarding-actions)
:::

添加 **On timer end** 触发器，在倒计时归零时执行操作——例如跳转到另一个屏幕或隐藏折扣标签。

## 延迟关闭按钮的出现时机 \{#delay-when-a-close-button-appears\}

如需延迟关闭按钮的出现，请[使用 **Show element** 动作](flow-show-hide-animations#show-an-element-a-few-seconds-after-the-screen-opens)：

1. 将 **Close** 按钮添加到屏幕，并在 **Design** 面板中将其 **Visibility** 设置为 **Hide**。
2. 添加一个 **On Screen Appear** 触发器，并配置一个目标为关闭按钮的 **Show element** 动作。
3. 在 **Delay** 字段中设置按钮出现前的等待时间，最长可设置为 5000 毫秒。

以上步骤替代了旧版付费墙编辑工具中的 **Show after delay** 选项。

For a delay longer than 5 seconds, replace steps 2 and 3 with a Countdown timer that users don't see:

1. 在同一屏幕上添加一个倒计时计时器元素。将其 **Visibility** 保持为 **Show**，并保留文本中的数字，以便其 **On timer end** 触发器能够触发。
2. 为了让倒计时不可见，将其文本颜色设置为完全透明，或与背景色相同。
3. 将计时器的时长设置为关闭按钮出现前的延迟时间（参见 [设置时长](#set-the-duration)）。
4. 在计时器上添加一个 **On timer end** 触发器，配置 **Show element** 动作，目标指向关闭按钮（参见 [显示或隐藏元素](flow-show-hide-animations#show-or-hide-an-element)）。

当计时器归零时，**Show element** 操作会显示关闭按钮。
