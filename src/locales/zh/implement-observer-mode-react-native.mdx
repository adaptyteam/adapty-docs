如果你已经有自己的购买基础设施，暂时还不打算完全切换到 Adapty，可以了解一下 [Observer 模式](observer-vs-full-mode)。在其基本形式下，Observer 模式提供高级分析功能，并能与归因和分析系统无缝集成。

如果这满足您的需求，您只需：
1. 在配置 Adapty SDK 时，将 `observerMode` 参数设置为 `true` 即可启用。请按照 [React Native](sdk-installation-reactnative) 的安装说明进行操作。
2. 从您现有的购买基础设施向 Adapty [上报交易](report-transactions-observer-mode-react-native)。

:::tip
在 SDK v4 中，你也可以在 Observer 模式下展示 Adapty 渲染的流程和付费墙：设置 `onObserverPurchaseInitiated` 和 `onObserverRestoreInitiated` 事件处理器，当用户点击对应按钮时，使用你自己的代码执行购买或恢复操作。详见 [在 Observer 模式下展示流程](react-native-present-flows-in-observer-mode)。
:::

### 观察者模式配置 \{#observer-mode-setup\}

如果你自行处理购买和订阅状态，仅使用 Adapty 发送订阅事件和分析数据，请开启观察者模式。

:::important
在观察者模式下，Adapty SDK 不会关闭任何交易，请确保你自行处理。
:::

```typescript showLineNumbers title="App.tsx"

adapty.activate('YOUR_PUBLIC_SDK_KEY', {
  observerMode: true, // Enable observer mode
});
```

参数：

| 参数 | 描述 |
| --------------------------- | ------------------------------------------------------------ |
| observerMode                | 一个布尔值，用于控制[观察者模式](observer-vs-full-mode)。默认值为 `false`。 |

## 在观察者模式下使用 Adapty 流程与付费墙 \{#using-adapty-paywalls-in-observer-mode\}

如果你还想使用 Adapty 的流程、付费墙和 A/B 测试功能，也完全可以——但在观察者模式下需要一些额外配置。除了上述步骤之外，你还需要完成以下操作：

1. 像平常一样展示[远程配置付费墙](present-remote-config-paywalls-react-native)。对于在流程编辑器中构建的流程和付费墙，请参阅[在观察者模式下展示流程](react-native-present-flows-in-observer-mode)。
2. 将流程和付费墙与购买交易进行[关联](report-transactions-observer-mode-react-native)。
