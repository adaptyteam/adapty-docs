[Slack](https://slack.com/) 是一款职场即时通讯和效率协作平台，想必大家已经耳熟能详。

通过此集成，每当 Adapty 追踪到一笔收入事件时，你都会在 Slack 中收到通知。如果你希望第一时间感受到每一次 MRR 增长的喜悦，或者想要及时掌握试用取消、付款问题、退款等动态，这项功能会非常实用。

## 如何设置 Slack 集成 \{#how-to-set-up-slack-integration\}

您需要：

- 在您的 Slack 工作区中创建一个应用
- 授予其发送消息的权限
- 然后在 [Integrations → Slack](https://app.adapty.io/integrations/slack) 中向 Adapty 提供必要信息。

### 3\. 在 Adapty 中配置集成 \{#configure-the-integration-in-adapty\}

1. 前往 [**Integrations** → **Slack**](https://app.adapty.io/integrations/slack)：

<Zoom>
  <img src="/assets/shared/img/b4ffd71-CleanShot_2024-01-04_at_19.05.222x.webp"
  style={{
    border: 'none', /* border width and color */
    width: '700px', /* image width */
    display: 'block', /* for alignment */
    margin: '0 auto' /* center alignment */
  }}
/>
</Zoom>

2. 粘贴上一步中的 `xoxb-...` 令牌，并选择应用将发布到的频道。您可以将集成设置为仅接收生产环境事件、沙盒事件或两者兼收。您也可以选择发布的货币（原始货币或换算为 USD）。

  :::note
  请注意，如果您希望 Adapty 在私有频道中发布消息，您需要手动将在 Slack 中创建的 `Adapty` 应用添加到该频道，否则将无法正常使用。
  :::

3. 最后，您可以在 **Events** 下选择要接收的事件：
