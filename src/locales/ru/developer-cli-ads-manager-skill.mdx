[Apple Ads plugin](https://github.com/adaptyteam/apple-ads-cli) позволяет AI-инструменту для написания кода управлять вашим аккаунтом Apple Ads через [Adapty CLI](developer-cli-ads-manager). Задайте вопрос на обычном языке — плагин сам определит, какие команды нужны, сначала прочитает данные аккаунта и предложит изменения до того, как они попадут в Apple.

Навык — это набор инструкций, которые ваш AI-инструмент загружает по запросу. Плагин поставляется с тремя из них: оператор, управляющий аккаунтом, аудитор только для чтения и стратегический планировщик, — плюс плейбуки для регулярных задач (еженедельные проверки, анализ ROAS по когортам, перераспределение бюджета), вертикальные гайды с категорийными таксономиями ключевых слов и базовой экономикой, а также [слэш-команды](#slash-commands), превращающие самые распространённые задачи в однострочники. Вместе они покрывают те части интерфейса Ads Manager, где легче всего ошибиться: какой идентификатор принимает каждый флаг, какой фильтр использует каждый список, сколько ключевых слов помещается в батч и какие вызовы стоят денег.

## Что он обрабатывает \{#what-it-handles\}

- **Производительность чтения**: выбирает единственный вызов, который отвечает на вопрос, вместо постраничного перебора результатов. Понимает, что вопрос «топ-N» — это один упорядоченный вызов, а для подсчёта сущностей вызов метрик вообще не нужен.
- **Структурные изменения**: создаёт и обновляет кампании, группы объявлений, объявления и ключевые слова в правильном порядке, читая родительскую сущность перед записью дочерней.
- **Работа с ключевыми словами**: добавляет и пересматривает ставки по ключевым словам пакетами, а также переносит поисковые запросы в ключевые слова и минус-слова.
- **Автоматизации**: настраивает автоматизации на основе правил и запускает их в тестовом режиме перед применением к реальным ставкам.
- **Исследование конкурентов**: получает ключевые слова, по которым делают ставки конкурирующие приложения.
- **Аудит аккаунта**: скилл `apple-ads-audit` проверяет состояние аккаунта, статус показа, структуру и дублирующиеся ключевые слова, не внося никаких изменений.
- **Планирование с нуля**: скилл `apple-ads-strategy` разрабатывает структуру аккаунта, таксономию ключевых слов и начальные бюджеты на основе описания вашего приложения — без необходимости в аккаунте Apple Ads или CLI.

## Чего плагин не делает \{#what-it-will-not-do\}

Плагин считает каждую запись необратимой — потому что так и есть: CLI не умеет удалять, а изменения достигают Apple за секунды.

- Перед записью он читает текущее состояние, а не угадывает ID или бюджет.
- Перед любой командой, которая тратит деньги, он запрашивает подтверждение, и оставляет собственный запрос подтверждения CLI, если команду запускаете вы.
- На каждую запись в цепочке он проставляет ключ идемпотентности, чтобы повторный запуск после неясного результата не создавал вторую кампанию.
- Он предпочитает небольшие пакеты, чтобы частичный отказ от Apple было легко прочитать.

:::note
Навыки рекомендуют и подготавливают команды. Чтение метрик и пробные запуски ничего не стоят, но вы несёте ответственность за подтверждение любых изменений в действующем рекламном аккаунте.
:::

## Плагин Benchmarks \{#benchmarks-plugin\}

На том же маркетплейсе есть опциональный companion-плагин [`apple-ads-benchmarks`](https://github.com/adaptyteam/apple-ads-benchmarks) — опубликованные Adapty базовые показатели Apple Ads для приложений с подписками, упакованные в виде локальных данных, которые ваш AI-инструмент может запрашивать: показатель кликабельности, конверсия, CPT и CPA по 90 странам, 22 жанрам App Store и 59 нишам, а также экономика подписчиков: LTV за первый год. Работает полностью офлайн — не требует ни аккаунта Apple Ads, ни CLI, ни подписки на Adapty.

Используйте это, чтобы оценить, является ли показатель проблемным, прежде чем углубляться в аккаунт: «Высокий ли CPT в $4 для фитнес-приложения в Германии?» — это прежде всего вопрос к бенчмаркам.

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/apple-ads-cli
claude plugin install apple-ads-benchmarks@adapty
```

**Any other tool**

```bash
npx skills add adaptyteam/apple-ads-benchmarks --all
```

:::note
Бенчмарк CPA — это стоимость загрузки, а не установки, а CR — это переходы к загрузкам, а не конверсия из триала в платную подписку. При сравнении убедитесь, что используете одинаковые определения метрик.
:::

## Команды со слешем \{#slash-commands\}

В Claude Code плагин также добавляет девять команд `/asa-*`. Каждая из них — готовый промпт, который выбирает нужный навык и сценарий для типичной задачи, так что вы просто вводите команду вместо того, чтобы писать промпт вручную:

| Команда | Что делает |
|---|---|
| `/asa-review` | Еженедельная сверка — направление, сравнение установок, выбросы и одно действие |
| `/asa-audit` | Аудит состояния аккаунта или живой структуры в режиме только для чтения |
| `/asa-bids` | Просмотр и корректировка ставок по ROAS когорты |
| `/asa-budget` | Перераспределение бюджета между кампаниями |
| `/asa-harvest` | Сбор поисковых запросов в точные ключевые слова и минус-слова |
| `/asa-negatives` | Поиск поисковых запросов для добавления в минус-слова с максимальной точностью |
| `/asa-opportunities` | Поиск ключевых слов конкурентов через Market Intelligence |
| `/asa-cpp` | Привязка намерения по ключевому слову к существующей Custom Product Page и объявлению |
| `/asa-launch` | Планирование и запуск новой кампании Apple Search Ads |

Slash commands install with the Claude Code plugin. In other tools, ask for the same jobs in plain language — the skills carry the same playbooks.

## Примеры промптов \{#example-prompts\}

Навыки уже содержат команды, порядок их выполнения и информацию о том, какие из них тратят деньги, — поэтому в промпте не нужно это расписывать. Пишите промпт о том, что навык не может определить самостоятельно: метрика и период, по которым вы оцениваете кампании, эталон для сравнения и формат желаемого ответа.

### Проверка уже запущенного аккаунта \{#audit-an-account-you-already-run\}

Используйте это, когда кампании уже запущены и вы хотите понять, куда уходят деньги. Все необходимые команды — на чтение, так что ничего в вашем аккаунте не изменится.

```
Audit my Apple Search Ads account and tell me what needs my attention. This is
read-only — don't change anything.

Judge campaigns on cohort net ROAS over the last 30 days against a 3:1
benchmark, since Adapty attributes real subscription revenue back to the
campaign that drove it. Cover campaigns, keywords, the search terms I'm
matching on, and what my active automations do.

Serving status and the reasons a campaign isn't serving come back on the
metrics rows, not from campaigns list.

Then report back in plain language:
- what's blocked and how to unblock it
- net ROAS per campaign against the benchmark
- the top 3 places I'm wasting money
- the top 3 growth opportunities
- the changes you'd make, each as the exact command with its current and new
  value, for me to approve one at a time

I'm not an Apple Ads expert. Assume I'm smart but busy.
```

### Запустите первые кампании \{#launch-your-first-campaigns\}

Используйте это, когда аккаунт Apple Ads пуст. Навык оператора создаёт кампании в приостановленном состоянии по умолчанию, и этот запрос удерживает это до тех пор, пока вы не ознакомитесь с планом.

```
I want to launch Apple Search Ads for my app from scratch. I'm not an Apple
Ads expert — guide me and build it for me. Create everything paused.

Interview me first, briefly: what my app does and who it's for, which
countries to start in, my monthly test budget, and my target cost per
subscriber. If I don't know that last one, work it back from my price and
expected trial conversion.

Then propose a starter structure as a table before you create anything: a
brand campaign, a generic campaign, a competitor campaign if I name
competitors, and a small discovery campaign to mine search terms. For each
one give me a one-line reason it exists, its share of the budget, its ad
groups, a starter keyword list with match types and bids, and the negative
keywords to share across all of them.

Build it once I approve, then show me what was created.

Finish with a launch checklist: what I still have to fix in the Apple Search
Ads console before anything can serve, such as a payment method or a pending
tax verification; how to switch the campaigns on when I'm ready; and one
automation rule worth adding after a week of data. Then tell me to come back
in 7 days for a performance review.
```

## Чем это отличается от AI Agent \{#how-it-differs-from-the-ai-agent\}

В дашборде Adapty Ads Manager также есть встроенный [AI Agent](ads-manager-ai-agent). Эти два инструмента решают разные задачи:

| | AI Agent | Apple Ads plugin |
|---|---|---|
| Где работает | В дашборде Adapty | В вашем терминале, в AI-инструменте для кода |
| Что делает | Анализирует и даёт рекомендации | Анализирует, даёт рекомендации и выполняет команды |
| Настройка | Не требуется | Adapty CLI и плагин |

Используйте AI Agent, чтобы узнать, что происходит в вашем аккаунте. Используйте плагин, когда хотите, чтобы изменение было выполнено автоматически.
