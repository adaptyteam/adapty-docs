[Плагин Apple Ads](https://github.com/adaptyteam/apple-ads-cli) позволяет AI-инструменту управлять вашим аккаунтом Apple Ads через [Adapty CLI](developer-cli-ads-manager). Задайте вопрос на обычном языке — инструмент сам разберётся, какие команды на него отвечают, сначала считает данные аккаунта и предложит изменение на ваше согласование, прежде чем что-либо дойдёт до Apple.

Скилл — это набор инструкций, которые AI-инструмент загружает по запросу. Плагин включает три скилла: оператор для управления аккаунтом, аудитор только для чтения и стратегический планировщик, а также плейбуки для регулярных задач — еженедельные проверки, анализ ROAS по когортам, перераспределение бюджета, вертикальные гайды с таксономиями ключевых слов и стартовой экономикой по категориям, а также [слэш-команды](#slash-commands), превращающие самые частые задачи в однострочники. Вместе они берут на себя те части Ads Manager, где легко ошибиться: какой идентификатор принимает каждый флаг, какой фильтр используется в каждом списке, сколько ключевых слов умещается в пакете и какие вызовы стоят денег.

## Что умеет плагин \{#what-it-handles\}

- **Чтение показателей**: выбирает единственный вызов, который отвечает на вопрос, вместо того чтобы листать результаты постранично. Плагин знает, что вопрос «топ-N» — это один отсортированный вызов, а подсчёт сущностей вообще не требует вызова метрик.
- **Структурные изменения**: создаёт и обновляет кампании, группы объявлений, объявления и ключевые слова в правильном порядке, считывая родительскую сущность перед записью дочерней.
- **Работа с ключевыми словами**: добавляет ключевые слова и переставляет ставки пакетами, переносит поисковые запросы в ключевые слова и минус-слова.
- **Автоматизации**: настраивает автоматизации на основе правил и запускает их в тестовом режиме перед применением к реальным ставкам.
- **Исследование конкурентов**: получает ключевые слова, по которым ставятся конкурирующие приложения.
- **Аудит аккаунта**: скилл `apple-ads-audit` проверяет состояние аккаунта, статус показа, структуру и дублирующиеся ключевые слова, ничего не изменяя.
- **Планирование с нуля**: скилл `apple-ads-strategy` разрабатывает структуру аккаунта, таксономию ключевых слов и стартовые бюджеты по описанию вашего приложения — аккаунт Apple Ads и CLI не нужны.

## Чего плагин не делает \{#what-it-will-not-do\}

Плагин считает каждую запись необратимой — потому что так и есть: CLI не поддерживает удаление, а изменения доходят до Apple за секунды.

- Сначала читает, потом пишет — не угадывает идентификатор или бюджет.
- Спрашивает подтверждение перед любой командой, требующей затрат, и оставляет встроенный запрос подтверждения CLI, когда команду выполняете вы сами.
- Фиксирует ключ идемпотентности на каждой записи в цепочке, чтобы повторный запуск после неясного результата не создал вторую кампанию.
- Предпочитает небольшие пакеты, чтобы частичный отказ от Apple было легко прочитать.

:::note
Скиллы рекомендуют и подготавливают команды. Чтение метрик и тестовые запуски ничего не стоят, но ответственность за одобрение любых изменений в живом рекламном аккаунте остаётся на вас.
:::

## Плагин с бенчмарками \{#benchmarks-plugin\}

На том же маркетплейсе есть опциональный компаньон — [`apple-ads-benchmarks`](https://github.com/adaptyteam/apple-ads-benchmarks): опубликованные Adapty базовые показатели Apple Ads для приложений с подписками, упакованные в локальные данные, которые может запрашивать ваш AI-инструмент: CTR, конверсия, CPT и CPA по 90 странам, 22 жанрам App Store и 59 нишам, а также экономика подписчиков — например, LTV за первый год. Работает полностью офлайн: аккаунт Apple Ads, CLI и подписка Adapty не нужны.

Используйте его, чтобы понять, является ли показатель проблемой, прежде чем углубляться в аккаунт: «Высокий ли $4 CPT для фитнес-приложения в Германии?» — сначала вопрос для бенчмарков.

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/apple-ads-cli
claude plugin install apple-ads-benchmarks@adapty
```

**Любой другой инструмент**

```bash
npx skills add adaptyteam/apple-ads-benchmarks --all
```

:::note
Бенчмарковый CPA — это стоимость загрузки, а не установки; CR — это отношение нажатий к загрузкам, а не конверсия из триала в платящего. Сравнивайте каждый показатель с вашей метрикой по одному и тому же определению.
:::

## Слэш-команды \{#slash-commands\}

В Claude Code плагин добавляет девять команд `/asa-*`. Каждая — готовый промпт, который выбирает нужный скилл и плейбук для типовой задачи, так что вместо написания промпта вы просто вводите команду:

| Команда | Что делает |
|---|---|
| `/asa-review` | Еженедельная проверка — направление, сравнение установок, выбросы и одно действие |
| `/asa-audit` | Аудит состояния аккаунта или живой структуры только для чтения |
| `/asa-bids` | Просмотр и корректировка ставок по когортному ROAS |
| `/asa-budget` | Перераспределение бюджета между кампаниями |
| `/asa-harvest` | Перенос поисковых запросов в точные ключевые слова и минус-слова |
| `/asa-negatives` | Поиск в поисковых запросах наиболее узких безопасных минус-слов |
| `/asa-opportunities` | Поиск возможностей по ключевым словам конкурентов через Market Intelligence |
| `/asa-cpp` | Привязка намерения ключевого слова к существующей Custom Product Page и объявлению |
| `/asa-launch` | Планирование и запуск новой кампании Apple Search Ads |

Слэш-команды устанавливаются вместе с плагином Claude Code. В других инструментах задавайте те же задачи на обычном языке — скиллы содержат те же плейбуки.

## Примеры промптов \{#example-prompts\}

Скиллы уже содержат команды, порядок их компоновки и информацию о том, какие из них тратят деньги, поэтому промпт не должен всё это расписывать. Пишите промпт для того, что скилл не может определить самостоятельно: метрику и период, по которым вы оцениваете кампании, бенчмарк для сравнения и формат нужного ответа.

### Аудит работающего аккаунта \{#audit-an-account-you-already-run\}

Используйте, когда кампании уже запущены и вы хотите понять, куда уходят деньги. Все нужные команды — только чтение, аккаунт не изменится.

```
Audit my Apple Search Ads account and tell me what needs my attention. This is
read-only — don't change anything.

Judge campaigns on cohort net ROAS over the last 30 days against a 3:1
benchmark, since Adapty attributes real subscription revenue back to the
campaign that drove it. Cover campaigns, keywords, the search terms I'm
matching on, and what my active automations do.

Serving status and the reasons a campaign isn't serving come back on the
metrics rows, not from campaigns list.

Then report back in plain language:
- what's blocked and how to unblock it
- net ROAS per campaign against the benchmark
- the top 3 places I'm wasting money
- the top 3 growth opportunities
- the changes you'd make, each as the exact command with its current and new
  value, for me to approve one at a time

I'm not an Apple Ads expert. Assume I'm smart but busy.
```

### Запуск первых кампаний \{#launch-your-first-campaigns\}

Используйте, когда аккаунт Apple Ads пуст. Скилл оператора создаёт кампании приостановленными по умолчанию, и этот промпт удерживает его в этом состоянии, пока вы не прочитаете план.

```
I want to launch Apple Search Ads for my app from scratch. I'm not an Apple
Ads expert — guide me and build it for me. Create everything paused.

Interview me first, briefly: what my app does and who it's for, which
countries to start in, my monthly test budget, and my target cost per
subscriber. If I don't know that last one, work it back from my price and
expected trial conversion.

Then propose a starter structure as a table before you create anything: a
brand campaign, a generic campaign, a competitor campaign if I name
competitors, and a small discovery campaign to mine search terms. For each
one give me a one-line reason it exists, its share of the budget, its ad
groups, a starter keyword list with match types and bids, and the negative
keywords to share across all of them.

Build it once I approve, then show me what was created.

Finish with a launch checklist: what I still have to fix in the Apple Search
Ads console before anything can serve, such as a payment method or a pending
tax verification; how to switch the campaigns on when I'm ready; and one
automation rule worth adding after a week of data. Then tell me to come back
in 7 days for a performance review.
```

## Отличие от AI Agent \{#how-it-differs-from-the-ai-agent\}

В Adapty Ads Manager также есть встроенный [AI Agent](ads-manager-ai-agent) в дашборде. Они решают разные задачи:

| | AI Agent | Плагин Apple Ads |
|---|---|---|
| Где работает | Дашборд Adapty | Ваш терминал, в вашем AI-инструменте |
| Что делает | Анализирует и рекомендует | Анализирует, рекомендует и выполняет команды |
| Настройка | Не нужна | Adapty CLI и плагин |

Используйте AI Agent, чтобы узнать, что происходит в аккаунте. Используйте плагин, когда хотите, чтобы изменение было выполнено тоже.
