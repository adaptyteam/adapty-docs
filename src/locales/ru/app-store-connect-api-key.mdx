Adapty использует ключ App Store Connect API для работы с вашими продуктами в App Store Connect:

- [Создавать продукты](create-product#create-product-and-push-to-store) и группы подписок.
- Находить существующие продукты по ID при добавлении продукта в Adapty.
- Отображать статус каждого продукта в App Store Connect.
- Импортировать цены ежедневно и экспортировать изменения цен, сделанные в Adapty.
- Предлагать продукты для Switch Plan в [Retention Messaging](retention-messaging-setup).

Adapty вносит изменения в App Store Connect только когда вы выполняете действия в Adapty, например создаёте продукт или меняете цены. Для отображения статусов и импорта цен Adapty только читает данные из App Store Connect.

Создайте ключ на вкладке **Team Keys** в App Store Connect, а затем подключите его в **App settings** в Adapty. Если ключ перестанет работать или потребует замены, [замените его](#replace-the-key).

Ключ App Store Connect API отличается от [ключа In-App Purchase](generate-in-app-purchase-key), хотя App Store Connect присваивает обоим ключам идентификаторы с одинаковыми названиями: **Issuer ID** и **Key ID**.

Чтобы ввести все учётные данные в **App settings** > **iOS SDK** за один раз, следуйте инструкции [Configure App Store integration](app-store-connection-configuration).

## Замена ключа \{#replace-the-key\}

Если ключ перестал работать или нужно изменить настройку **Access**, подключите новый ключ в Adapty до того, как отзовёте старый.

Без рабочего ключа Adapty не сможет:

- Создавать продукты.
- Находить существующие продукты по ID.
- Синхронизировать статус и цены продуктов.

Нерабочий ключ по-прежнему отображается в Adapty как подключённый. Признаки проблемы — [продукты без статуса App Store и пустой выпадающий список **App Store Product ID**](troubleshoot-app-store-integration#products-dont-appear-or-show-no-app-store-status).

Adapty не отображает Key ID подключённого ключа. Если вы не знаете, какой ключ использует Adapty, замените его новым.

Когда ваше приложение переходит на другой аккаунт разработчика Apple, [подключите командный ключ от нового владельца](transfer-apps#app-store-ios-transfer).

Чтобы заменить ключ:

1. [Создайте новый командный ключ](#generate-a-team-key-in-app-store-connect).
2. В Adapty перейдите в [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). В разделе **App Store Connect API key** нажмите **Edit**. [Введите значения нового ключа](#connect-the-key-in-adapty) и нажмите **Save changes**.
3. Один командный ключ обслуживает все приложения вашей команды в App Store Connect. Если другие приложения вашей команды используют Adapty, подключите новый ключ и для них. Замените старый ключ на всех серверах, которые его используют.
4. Отозванный ключ перестаёт работать во всех приложениях, которые его используют, и восстановить его невозможно. Если вы знаете, какой ключ заменяет новый, перейдите в App Store Connect и отзовите старый.
