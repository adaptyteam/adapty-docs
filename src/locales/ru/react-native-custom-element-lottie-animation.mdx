## Прежде чем начать \{#before-you-start\}

- Обновите приложение до Adapty React Native SDK 4.4 или новее. Более ранние версии SDK показывают [резервный контент](flow-custom-elements#set-fallback-content) для каждого кастомного элемента.
- Настройте приложение для [получения](react-native-get-pb-paywalls) и [отображения](react-native-present-paywalls) флоу.
- Настройте нативный код приложения для кастомных элементов, как описано в [гайде для React Native](react-native-flow-custom-elements#before-you-start).
- На iOS добавьте Lottie в таргет приложения в Xcode с помощью Swift Package Manager из `https://github.com/airbnb/lottie-spm.git`. Если приложение использует `lottie-react-native`, пропустите этот шаг: этот пакет уже добавляет Lottie в приложение.
- На Android [настройте Jetpack Compose](react-native-flow-custom-elements#set-up-jetpack-compose) в модуле приложения. Вью анимации в этом рецепте является composable. Добавьте Compose Foundation в приложение через Gradle из `androidx.compose.foundation:foundation` без указания версии. Версию устанавливает Compose BOM из `io.adapty:android-ui`. Добавьте Lottie для Jetpack Compose из `com.airbnb.android:lottie-compose`.

## 2. Добавьте файл анимации в приложение \{#2-add-the-animation-file-to-your-app\}

Нативный код читает файл анимации из проектов iOS и Android, а не из ассетов JavaScript-кода:

- **iOS**: Добавьте файл в целевой таргет приложения в Xcode.
- **Android**: Поместите файл в `android/app/src/main/assets` — папку `assets` модуля Android-приложения. Храните его в корне этой папки, без вложенных подпапок.

Имя файла без `.json` должно совпадать с ID пользовательского элемента, например `streak_ring.json` для `streak_ring`.

## 3. Создайте анимированное представление \{#create-the-animation-view\}

Создайте модель для стрика и представление, которое воспроизводит анимацию. Когда стрик меняется, приложение обновляет модель. Представление читает модель, поэтому кольцо отображает текущий стрик при открытии экрана:

<Tabs groupId="platform" queryString>
<TabItem value="ios" label="iOS (Swift)" default>

```swift showLineNumbers title="Swift"

// The streak that your app keeps up to date
@MainActor
final class StreakStore: ObservableObject {
    @Published var currentStreak = 0 // days in a row
}

struct StreakRingView: View {
    let animation: LottieAnimation
    @ObservedObject var streakStore: StreakStore

    // 7 days fill the ring: from 0 for an empty ring to 1 for a full one
    private var progress: AnimationProgressTime {
        min(AnimationProgressTime(streakStore.currentStreak) / 7, 1)
    }

    var body: some View {
        LottieView(animation: animation)
            .resizable()
            .playing(.fromProgress(0, toProgress: progress, loopMode: .playOnce))
    }
}
```

`.playing(.fromProgress(0, toProgress: progress, loopMode: .playOnce))` заполняет кольцо один раз, от пустого состояния до значения `progress`.

</TabItem>
<TabItem value="android" label="Android (Kotlin)">

```kotlin showLineNumbers title="Kotlin"

// the streak that your app keeps up to date
class StreakStore {
    val currentStreak = MutableStateFlow(0) // days in a row
}

@Composable
fun StreakRing(animationFile: String, streakStore: StreakStore) {
    val composition by rememberLottieComposition(LottieCompositionSpec.Asset(animationFile))
    val streak by streakStore.currentStreak.collectAsState()

    // 7 days fill the ring: from 0 for an empty ring to 1 for a full one
    val progress = minOf(streak / 7f, 1f)

    LottieAnimation(
        composition = composition,
        modifier = Modifier.fillMaxSize(), // scale the animation to fit the custom element
        clipSpec = LottieClipSpec.Progress(0f, progress),
    )
}
```

`clipSpec = LottieClipSpec.Progress(0f, progress)` заполняет кольцо один раз, от пустого до `progress`.

## 4. Привяжите анимацию к кастомному элементу \{#match-the-animation-to-the-custom-element\}

В вашем [глобальном резолвере](react-native-flow-custom-elements#pass-the-resolver-to-the-sdk) добавьте свойство для модели streak. Затем верните анимационный вью для типа `lottie_animation` и ID `streak_ring`. В выделенных строках показано, что нужно добавить или изменить. Если у вашего приложения ещё нет глобального [резолвера](react-native-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views), скопируйте весь код целиком:

<Tabs groupId="platform" queryString>
<TabItem value="ios" label="iOS (Swift)" default>

```swift showLineNumbers title="Swift" {6,14-18}

struct CustomElementsResolver: AdaptyUICustomElementsResolver {
    let streakStore: StreakStore

    func view(
        forType type: String,
        id: String,
        context: AdaptyUICustomElementContext
    ) -> AnyView? {
        switch type {
        case "lottie_animation" where id == "streak_ring":
            guard let animation = LottieAnimation.named(id) else {
                return nil // no animation file: show the fallback
            }
            return AnyView(StreakRingView(animation: animation, streakStore: streakStore))
        // the other cases of your resolver
        default:
            return nil
        }
    }
}
```

Поставьте case `streak_ring` перед любым другим case `lottie_animation`, потому что Swift выполняет только первый подходящий case. Если в бандле приложения нет файла с таким ID, резолвер возвращает `nil`, и пользователь видит фолбэк.

</TabItem>
<TabItem value="android" label="Android (Kotlin)">

```kotlin showLineNumbers title="Kotlin" {8,22-28}

class CustomElementsResolver(
    context: Context,
    private val streakStore: StreakStore,
) : AdaptyCustomElementsResolver {
    // the animation files in the assets folder, listed once
    private val animationFiles: Set<String> = try {
        context.assets.list("").orEmpty().toSet()
    } catch (e: IOException) {
        emptySet() // no list of files: every Lottie element shows the fallback
    }

    override fun resolve(type: String, id: String): AdaptyCustomElementContent? =
        when (type) {
            "lottie_animation" -> {
                // the ID names the animation file, such as streak_ring.json
                val file = "$id.json"
                when {
                    file !in animationFiles -> null // no file for this ID: show the fallback
                    id == "streak_ring" ->
                        AdaptyCustomElementContent.compose { StreakRing(file, streakStore) }
                    // the other animations of your resolver
                    else -> null
                }
            }
            // the other Types of your resolver
            else -> null
        }
}
```

Если в папке `assets` нет файла с таким ID, резолвер возвращает `null`, и пользователи видят резервный вариант. Если ваш резолвер уже возвращает [представление для каждого файла анимации](react-native-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views), возвращайте это представление вместо `null`, когда ID не равен `streak_ring`. Так пользователи по-прежнему будут видеть анимации остальных кастомных элементов `lottie_animation`.

## 5. Отправьте счётчик серии из JavaScript-кода \{#5-send-the-streak-from-your-javascript-code\}

Ваш JavaScript-код управляет счётчиком серии, а нативные представления читают его из модели. Чтобы обновить модель, отправьте счётчик в нативный код через [Turbo Native Module](https://reactnative.dev/docs/turbo-native-modules-introduction). Модуль включает JavaScript-спецификацию и реализацию для каждой платформы.

В папке `specs` в корне проекта создайте спецификацию модуля:

```typescript showLineNumbers title="specs/NativeStreakStore.ts"

export interface Spec extends TurboModule {
  setStreak(days: number): void;
}

export default TurboModuleRegistry.getEnforcing<Spec>('NativeStreakStore');
```

Чтобы сгенерировать нативный код спецификации, добавьте `codegenConfig` в `package.json`. Замените `com.example.app` на имя пакета вашего Android-приложения — в `package.json` и в Kotlin-реализации модуля. Если `codegenConfig` в `package.json` уже есть, добавьте только `NativeStreakStore` в объект `modulesProvider`:

```json showLineNumbers title="package.json"
"codegenConfig": {
  "name": "AppSpecs",
  "type": "modules",
  "jsSrcsDir": "specs",
  "android": {
    "javaPackageName": "com.example.app.specs"
  },
  "ios": {
    "modulesProvider": {
      "NativeStreakStore": "RCTNativeStreakStore"
    }
  }
}
```

Реализуйте модуль для каждой платформы:

<Tabs groupId="platform" queryString>
<TabItem value="ios" label="iOS (Swift)" default>

В target вашего приложения в Xcode создайте модуль на Objective-C++. Он передаёт серию в ваш Swift-код через `NotificationCenter`:

```objectivec showLineNumbers title="RCTNativeStreakStore.h"
#import <AppSpecs/AppSpecs.h>

@interface RCTNativeStreakStore : NSObject <NativeStreakStoreSpec>
@end
```

```objectivec showLineNumbers title="RCTNativeStreakStore.mm"
#import "RCTNativeStreakStore.h"

@implementation RCTNativeStreakStore

+ (NSString *)moduleName {
  return @"NativeStreakStore";
}

- (std::shared_ptr<facebook::react::TurboModule>)getTurboModule:
    (const facebook::react::ObjCTurboModule::InitParams &)params {
  return std::make_shared<facebook::react::NativeStreakStoreSpecJSI>(params);
}

- (void)setStreak:(double)days {
  // the AppDelegate updates the streak model when it receives this notification
  [[NSNotificationCenter defaultCenter] postNotificationName:@"StreakDidChange"
                                                      object:nil
                                                    userInfo:@{@"days": @((NSInteger)days)}];
}

@end
```

Чтобы обновлять модель стрика при каждом новом стрике, наблюдайте за `NotificationCenter` в классе `AppDelegate`. В методе `application(_:didFinishLaunchingWithOptions:)` добавьте наблюдателя после вызова `AdaptyUI.setCustomElementsResolver`:

```swift showLineNumbers title="ios/YourApp/AppDelegate.swift"
// the streak that your JavaScript code sends through the native module
NotificationCenter.default.addObserver(
  forName: Notification.Name("StreakDidChange"),
  object: nil,
  queue: .main
) { [streakStore] notification in
  guard let days = notification.userInfo?["days"] as? Int else { return }
  MainActor.assumeIsolated { streakStore.currentStreak = days }
}
```

Чтобы сгенерировать нативный код спецификации, выполните `pod install` в папке `ios`.

</TabItem>
<TabItem value="android" label="Android (Kotlin)">

Create the module, and a package that registers it with React Native:

```kotlin showLineNumbers title="NativeStreakStoreModule.kt"
package com.example.app


class NativeStreakStoreModule(reactContext: ReactApplicationContext) :
    NativeStreakStoreSpec(reactContext) {

    override fun getName() = NAME

    override fun setStreak(days: Double) {
        val app = reactApplicationContext.applicationContext as MainApplication
        app.streakStore.currentStreak.value = days.toInt()
    }

    companion object {
        const val NAME = "NativeStreakStore"
    }
}
```

```kotlin showLineNumbers title="NativeStreakStorePackage.kt"

class NativeStreakStorePackage : BaseReactPackage() {
    override fun getModule(name: String, reactContext: ReactApplicationContext): NativeModule? =
        if (name == NativeStreakStoreModule.NAME) NativeStreakStoreModule(reactContext) else null

    override fun getReactModuleInfoProvider() = ReactModuleInfoProvider {
        mapOf(
            NativeStreakStoreModule.NAME to ReactModuleInfo(
                name = NativeStreakStoreModule.NAME,
                className = NativeStreakStoreModule.NAME,
                canOverrideExistingModule = false,
                needsEagerInit = false,
                isCxxModule = false,
                isTurboModule = true,
            )
        )
    }
}
```

В файле `MainApplication.kt` добавьте `NativeStreakStorePackage` в список пакетов:

```kotlin showLineNumbers title="MainApplication.kt" {2}
PackageList(this).packages.apply {
  add(NativeStreakStorePackage())
}
```
