[Кастомный тег](flow-custom-tags) — это переменная, значение которой задаётся вашим приложением. Когда в настройках переменной выбрано **Value comes from outside the app**, приложение может передать её значение через Adapty SDK. Например, текстовый элемент содержит «Coins:» и кастомный тег. Если приложение передаёт для этого тега значение «120», пользователь видит «Coins: 120».

## Передача пользовательских значений тегов \{#pass-custom-tag-values\}

Создайте `AdaptyUiTagResolver` и передайте его в параметр `tagResolver` метода `AdaptyUI.getFlowView`. SDK вызывает резолвер с полным именем каждого кастомного тега, например `user.streak`. Резолвер возвращает одно из следующих значений:

- **Строка**: пользователи видят её вместо тега. Она должна быть удобочитаемой, например «1 250», а не «1250.0». Adapty не форматирует и не переводит её.
- **`null`**: пользователи видят начальное значение тега как запасной вариант.
- **Пустая строка**: пользователи не видят ничего вместо тега.

```kotlin showLineNumbers title="Kotlin"
val customTags = mapOf(
    "username" to "DragonSlayer42",
    "coins" to "1,250",
)
val tagResolver = AdaptyUiTagResolver { tag -> customTags[tag] }

val flowView = AdaptyUI.getFlowView(
    activity,
    flowConfiguration,
    products = null,
    eventListener = eventListener,
    tagResolver = tagResolver,
)
```

### Передача BMI на пейвол \{#pass-the-bmi-to-the-paywall\}

Собирайте данные о весе и росте из событий `flow_user_input` флоу онбординга, как описано в разделе [Обработка данных из флоу](android-flow-input). Чтобы определить, что пользователь достиг последнего экрана, отслеживайте событие `flow_screen_showed` с параметром `is_last_screen`, равным `true`, — подробнее в разделе [Отслеживание просмотров экранов флоу](android-flow-screen-views). Когда пользователь закрывает флоу онбординга после этого экрана, вычислите BMI. Затем создайте представление флоу пейвола и передайте BMI в качестве значения кастомного тега `bmi`.

Передайте следующий листенер в представление флоу онбординга:

```kotlin showLineNumbers title="Kotlin"
class OnboardingEventListener(
    private val onBmiCalculated: (bmi: String) -> Unit,
) : AdaptyFlowDefaultEventListener() {

    private val bodyAnswers = mutableMapOf<String, String>()
    private var reachedLastScreen = false

    override fun onAnalyticEvent(
        name: String,
        params: Map<String, Any?>,
        context: Context,
    ) {
        if (name == "flow_screen_showed" && params["is_last_screen"] == true) {
            reachedLastScreen = true
            return
        }
        if (name != "flow_user_input") return

        val elementId = params["element_id"] as? String ?: return
        val value = params["value"] as? String ?: return

        bodyAnswers[elementId] = value
    }

    override fun onFlowClosed() {
        // Reset `bodyAnswers` and `reachedLastScreen` on every close,
        // so that the next run starts without old answers.
        val answers = bodyAnswers.toMap()
        val finished = reachedLastScreen
        bodyAnswers.clear()
        reachedLastScreen = false

        // Number inputs send their values as strings.
        if (!finished) return
        val weight = answers["weight"]?.toDoubleOrNull() ?: return
        val height = answers["height"]?.toDoubleOrNull()?.takeIf { it > 0 } ?: return

        val heightInMeters = height / 100
        val bmi = weight / (heightInMeters * heightInMeters)

        onBmiCalculated(String.format(Locale.getDefault(), "%.1f", bmi))
    }
}
```

Когда пользователь закрывает флоу онбординга после последнего экрана, слушатель вызывает `onBmiCalculated` с BMI. Передайте лямбду для `onBmiCalculated`, которая вызывает следующую функцию. Функция получает флоу пейвола, создаёт его представление и передаёт BMI для кастомного тега `bmi`:

```kotlin showLineNumbers title="Kotlin"
fun showBmiPaywall(activity: Activity, bmi: String) {
    Adapty.getFlow("bmi_paywall") { flowResult ->
        when (flowResult) {
            is AdaptyResult.Success -> {
                AdaptyUI.getFlowConfiguration(flowResult.value) { configResult ->
                    when (configResult) {
                        is AdaptyResult.Success -> {
                            val flowView = AdaptyUI.getFlowView(
                                activity,
                                configResult.value,
                                products = null,
                                eventListener = AdaptyFlowDefaultEventListener(),
                                tagResolver = AdaptyUiTagResolver { tag ->
                                    if (tag == "bmi") bmi else null
                                },
                            )
                            // add flowView to your view hierarchy
                        }
                        is AdaptyResult.Error -> {
                            // handle the error
                        }
                    }
                }
            }
            is AdaptyResult.Error -> {
                // handle the error
            }
        }
    }
}
```

`String.format` с `Locale.getDefault()` использует десятичный разделитель локали пользователя: "22.7" для английского, "22,7" для немецкого.

### Сохраните ИМТ в профиль пользователя \{#save-the-bmi-to-the-users-profile\}

Чтобы показывать пользователям разные флоу в зависимости от их ИМТ, сохраните его как [пользовательский атрибут](android-setting-user-attributes#custom-user-attributes) профиля. В дашборде Adapty [создайте пользовательский атрибут типа **Number**](segments#custom-attributes) с ключом `bmi`. Затем показывайте каждый флоу аудитории, сформированной на основе этого атрибута.

Вызовите метод `updateProfile` внутри `onFlowClosed`, сразу после строки, вычисляющей `bmi`. Передайте значение типа `Double`, а не отформатированную строку — это позволит сегменту сравнивать ИМТ с пороговым значением:

```kotlin showLineNumbers title="Kotlin"
val params = AdaptyProfileParameters.Builder()
    .withCustomAttribute("bmi", bmi)
    .build()

Adapty.updateProfile(params) { error ->
    if (error != null) {
        // handle the error
    }
}
```
