Вкладка [**iOS SDK**](https://app.adapty.io/settings/ios-sdk) в разделе **App settings** содержит данные App Store вашего приложения. Чтобы заполнить их все, следуйте инструкции [Настройка интеграции с App Store](app-store-connection-configuration).

<ZoomImage id="app-settings-ios-sdk.webp" width="700px" alt="Вкладка iOS SDK в настройках приложения" />

| Раздел | Что здесь хранится и зачем это нужно Adapty | Где настроить |
|---|---|---|
| **SDK status** | Установлен ли SDK Adapty в вашем приложении | [Установка SDK Adapty](installation-of-adapty-sdks) |
| **Bundle ID** | Bundle ID вашего приложения для обработки покупок | [Введите Bundle ID и Apple App ID](app-store-connection-configuration#enter-the-bundle-id-and-apple-app-id) |
| **In-app purchase API (StoreKit 2)** | Ключ In-App Purchase для валидации покупок | [Добавьте ключ In-App Purchase в Adapty](generate-in-app-purchase-key) |
| **App Store Connect shared secret** | Секрет приложения для валидации чеков о покупке и создания продуктов в App Store Connect | [Введите секрет приложения](app-store-connection-configuration#enter-the-app-specific-shared-secret) |
| **App Store server notifications** | URL для получения событий подписки от Apple и необязательный URL вашего сервера, куда Adapty их пересылает | [Включите уведомления сервера App Store](enable-app-store-server-notifications) |
| **Apple Retention Messaging API** | URL, который вы передаёте Apple при запросе доступа к Retention Messaging API | [Настройте Retention Messaging](retention-messaging-setup) |
| **App Store promotional offers** | ID и файл ключа In-App Purchase для подписи promotional offer | [Добавьте ключ In-App Purchase в Adapty](generate-in-app-purchase-key) |
| **App Store Connect API key** | Ключ из вкладки **Team Keys** в App Store Connect для создания продуктов и синхронизации их статуса и цен | [Добавьте ключ App Store Connect API в Adapty](app-store-connect-api-key) |
| **Apple App ID** | Apple ID вашего приложения для поиска и создания продуктов в App Store Connect и других целей | [Введите Bundle ID и Apple App ID](app-store-connection-configuration#enter-the-bundle-id-and-apple-app-id) |
