Push-уведомления в мобильном приложении Adapty для [iOS](https://apps.apple.com/us/app/adapty/id6739359219) и [Android](https://play.google.com/store/apps/details?id=io.adapty.dashboard) помогают следить за тем, что происходит с вашими приложениями в реальном времени. Отслеживайте новые триалы, продления подписок и установки — мгновенные обновления без необходимости заходить в дашборд.

Вы можете задать настройки уведомлений по умолчанию для всех приложений, а затем скорректировать их для отдельных приложений, если нужен более тонкий контроль. Это особенно удобно при запуске нового приложения, когда хочется пристально следить за первой активностью.

Общее количество уведомлений по всем вашим приложениям ограничено 1000 в день.

## Настройка push-уведомлений \{#configure-push-notifications\}

Чтобы настроить push-уведомления в мобильном приложении Adapty:

1. Откройте приложение Adapty.
2. Перейдите в **Settings → Notifications**.
3. Нажмите **Enable notifications**, чтобы разрешить приложению отправлять вам уведомления.
4. Выберите, использовать ли настройки по умолчанию или настроить уведомления отдельно для каждого приложения. Обратите внимание, что индивидуальные настройки приложения имеют приоритет над настройками по умолчанию.
5. Выберите события, о которых хотите получать уведомления.

## Поддерживаемые события \{#supported-events\}

Вы можете получать push-уведомления для следующих типов событий:

* Access level updated
* Auto-renew turned off
* Auto-renew turned on
* Billing issue detected
* Entered grace period
* Non-subscription purchase
* Non-subscription purchase refunded
* Subscription cancelled
* Subscription deferred
* Subscription initial purchase
* Subscription paused
* Subscription refunded
* Subscription renewed
* Trial canceled
* Trial converted
* Trial started
