Восстановление покупок в iOS и Android — это функция, которая позволяет пользователям восстановить доступ к ранее приобретённому контенту, например подпискам или встроенным покупкам, без повторной оплаты. Она особенно полезна, когда пользователь переустановил приложение, сменил устройство и хочет получить доступ к уже оплаченному контенту.

:::note
Если вы создали экран в билдере, вам не нужно восстанавливать покупки вручную. Подключите элемент восстановления — действие **Restore purchases** во Flow & Paywall Builder или ссылку/кнопку восстановления в старом — и SDK выполнит восстановление.
:::

Если вы создали экран самостоятельно, вызовите метод `.restorePurchases()`:

```csharp showLineNumbers
Adapty.RestorePurchases((profile, error) => {
    if (error != null) {
        // handle the error
        return;
    }
  
    var accessLevel = profile.AccessLevels["YOUR_ACCESS_LEVEL"];
    if (accessLevel != null && accessLevel.IsActive) {
        // restore access
    }
});
```

Параметры ответа:

| Параметр | Описание                                                                                                                                                                                                                                                   |
|---------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Profile** | <p>Объект [`AdaptyProfile`](https://unity.adapty.io/class_adapty_s_d_k_1_1_adapty_profile.html). Модель содержит информацию об уровнях доступа, подписках и разовых покупках.</p><p>Проверьте **статус уровня доступа**, чтобы определить, есть ли у пользователя доступ к приложению.</p> |
