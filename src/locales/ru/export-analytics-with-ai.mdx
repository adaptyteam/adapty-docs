Задайте вопрос AI-агенту о вашей аналитике Adapty на обычном языке — выручка, конверсии, удержание, LTV — и он сам получит нужные данные. Агент запускает [команды аналитики Adapty CLI](developer-cli-analytics) в вашем терминале и читает результаты.

## Что можно спрашивать \{#what-you-can-ask-about\}

CLI возвращает те же данные, что и дашборд Adapty Analytics. Каждый тип вопроса соответствует одной команде:

| Вопрос о | Что охватывает | Команда |
| --- | --- | --- |
| Revenue, MRR, ARR, ARPU и других графиках | Метрика во времени, сгруппированная по измерению, которое поддерживает график, например по стране | `adapty analytics chart` |
| Конверсиях | Сколько пользователей переходит с одного шага на следующий, например с триала на платную подписку | `adapty analytics conversion` |
| Воронке | Где пользователи отваливаются между установкой и продлениями | `adapty analytics funnel` |
| Удержании | Сколько подписчиков остаётся после каждого периода | `adapty analytics retention` |
| Lifetime value (LTV) | Выручка на платящего пользователя после каждого продления или дня | `adapty analytics ltv` |
| Когортах по установкам | Выручка, подписчики и прогнозы для пользователей, установивших приложение в одном периоде | `adapty analytics cohort` |

Все команды доступны только для чтения. Агент не может вносить никаких изменений в ваш аккаунт Adapty с их помощью.

## Перед началом работы \{#before-you-start\}

Вам понадобится три вещи:

- **Аккаунт Adapty с данными**: CLI возвращает те же цифры, что и ваш дашборд, поэтому приложение уже должно собирать аналитику.
- **Adapty CLI версии 0.10.0 или выше с выполненным входом**: Чтобы установить CLI и войти в систему, выполните следующие команды. При входе откроется вкладка браузера, где нужно подтвердить код из терминала.

  ```bash
  npm install -g adapty
  ```

  ```bash
  adapty auth login
  ```

  Один вход в систему открывает доступ ко всем приложениям, к которым у вашего пользователя Adapty есть доступ — API-ключ не нужен.

- **AI-инструмент с возможностью выполнять команды в терминале**: Например, Claude Code, Cursor, Codex или Gemini CLI. Обычные чат-инструменты вроде claude.ai или ChatGPT не умеют запускать CLI.

## Дайте агенту описание команд \{#give-your-agent-the-commands\}

В [справочнике по CLI-аналитике](https://adapty.io/docs/ru/developer-cli-analytics.md) описана каждая команда, её флаги и то, как читать результаты. Прочитав его, агент будет составлять корректные команды без вашего участия.

Передайте агенту справочник по URL: если ваш агент умеет загружать страницы, дайте ему `https://adapty.io/docs/ru/developer-cli-analytics.md` и попросите прочитать её.

Агенту не нужно заранее знать названия ваших графиков. Он находит их с помощью `adapty analytics catalog --app <app-id>` — команда выводит список всех графиков, конверсий, группировок и фильтров, доступных для вашего приложения.

## Задайте вопрос о своих данных \{#ask-about-your-data\}

Когда справочник загружен и CLI авторизован, укажите приложение, метрику, период и что именно вы хотите решить.

Примеры запросов:

```
For my app "Sleep Tracker", what was MRR at the end of each month this year,
and how does it compare to the same months last year?

Show the trial-to-paid conversion rate for the last 90 days, by product.
Which product converts worst?

Which 10 countries brought the most revenue in Q3? Use revenue after the
store's commission.

How does retention compare between iOS and Android for subscribers who started
in the last 6 months?

Compare LTV after 30 and 90 days for users who installed in July and in August,
and save it as a CSV file.
```

Агент находит UUID приложения с помощью `adapty apps list`, выбирает нужную команду и возвращает данные. Результаты читаются в формате JSON (`--json`). Запросите CSV, если нужен файл для таблицы — агент добавит `--csv` к команде.

## Настройте один раз для многократного использования \{#set-up-once-for-repeated-use\}

Чтобы не повторять настройку каждый раз, сохраните ссылку там, где агент сможет её переиспользовать:

- **Сохраните ссылку**: Добавьте `https://adapty.io/docs/ru/developer-cli-analytics.md` в файл правил или памяти агента (например, `CLAUDE.md` или файл правил Cursor), чтобы он загружался при каждой сессии.
- **Укажите название приложения**: Добавьте название или UUID вашего приложения в тот же файл, чтобы не указывать его в каждом запросе.
- **Сохраните повторно используемые промпты или создайте скилл**: Храните типовые вопросы как сохранённые промпты или оберните их в скилл или slash-команду, чтобы агент запускал отчёт по запросу.

## Ограничения \{#limits\}

Учитывайте следующие ограничения:

- **Ограничение частоты запросов**: каждая аналитическая команда допускает 2 запроса в секунду на приложение. CLI не повторяет запросы автоматически, поэтому команда, отправленная слишком быстро, завершается с кодом выхода 4. Скажите агенту выполнять команды последовательно и ждать `retry_after_seconds` перед повторным запуском упавшей команды.
- **Одно приложение на команду**: каждая команда работает с одним приложением. Чтобы сравнить приложения, агент запускает по одной команде на каждое.
- **Не добавляйте к атрибуции**: для рекламных расходов, установок и ROAS по кампаниям используйте [команды Attribution](developer-cli-attribution). Не суммируйте эти данные с аналитическими — Adapty рассчитывает их по-разному.

Чтобы получить аналитику с сервера или через задание по расписанию, где нет возможности войти через браузер, используйте [Export Analytics API](export-analytics-api) с секретным API-ключом.
