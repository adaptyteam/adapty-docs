Воспользуйтесь этим рецептом, чтобы отображать прогресс пользователя в виде анимации Lottie — например, кольца, заполняющегося по мере накопления ежедневной серии. Ваше приложение рендерит анимацию как нативный Lottie-вид в [кастомном элементе](flow-custom-elements).

:::tip
Этот рецепт распространяется только на iOS-приложения. Приложения, созданные на других фреймворках, отображают только [резервный контент](flow-custom-elements#set-fallback-content) кастомных элементов. Поддержка Android и кросс-платформенных фреймворков появится позже.
:::

## Перед тем как начать \{#before-you-start\}

- Обновите приложение до Adapty iOS SDK 4.4 или новее. Более ранние версии SDK показывают [резервный контент](flow-custom-elements#set-fallback-content) для каждого кастомного элемента.
- Настройте приложение для [получения](get-pb-paywalls) и [отображения](ios-present-paywalls) флоу.
- Добавьте Lottie в приложение через Swift Package Manager по адресу `https://github.com/airbnb/lottie-spm.git`.
- Подготовьте анимацию Lottie в формате `.json` или скачайте пример [`streak_ring.json`](https://raw.githubusercontent.com/adaptyteam/adapty-docs/refs/heads/main/Downloads/streak_ring.json). Приложение воспроизводит анимацию с начала и останавливает её пропорционально прогрессу — например, на середине при 50%. Чтобы прогресс отображался точно, анимация должна соответствовать следующим требованиям:
  - На первом кадре прогресс равен нулю, на последнем — полный прогресс.
  - Постоянная скорость без ускорений и замедлений. Если анимация начинается медленно и затем ускоряется, то на середине воспроизведения будет показано меньше половины прогресса.

## 1. Добавьте пользовательский элемент на экран \{#add-the-custom-element-to-the-screen\}

В Flow & Paywall Builder [добавьте пользовательский элемент](flow-custom-elements#add-and-configure) на экран флоу и настройте его для анимации:

- **Type**: `lottie_animation`.
- **ID**: `streak_ring`. В этом рецепте ID также является именем файла анимации.
- **Height**: Оставьте значение по умолчанию **Fixed**. Анимация масштабируется по размеру пользовательского элемента.

Внутри пользовательского элемента добавьте [**Image**](custom-media#image) со статичным изображением кольца. Пользователи увидят его как [резервный контент](flow-custom-elements#set-fallback-content), если версия их приложения не поддерживает воспроизведение анимации.

## 2. Добавьте файл анимации в приложение \{#add-the-animation-file-to-your-app\}

В Xcode добавьте файл анимации в таргет приложения. Имя файла без `.json` должно совпадать с ID пользовательского элемента — например, `streak_ring.json` для `streak_ring`.

## 3. Создайте анимированное представление \{#3-create-the-animation-view\}

Создайте модель для серии и SwiftUI-представление, которое воспроизводит анимацию. Ваше приложение обновляет модель при изменении серии. Представление читает модель, поэтому кольцо отображает текущую серию при открытии экрана:

<Tabs groupId="current-os" queryString>
<TabItem value="ios" label="iOS" default>

```swift showLineNumbers title="Swift"

// The streak that your app keeps up to date
@MainActor
final class StreakStore: ObservableObject {
    @Published var currentStreak = 0 // days in a row
}

struct StreakRingView: View {
    let animation: LottieAnimation
    @ObservedObject var streakStore: StreakStore

    // 7 days fill the ring: from 0 for an empty ring to 1 for a full one
    private var progress: AnimationProgressTime {
        min(AnimationProgressTime(streakStore.currentStreak) / 7, 1)
    }

    var body: some View {
        LottieView(animation: animation)
            .resizable()
            .playing(.fromProgress(0, toProgress: progress, loopMode: .playOnce))
    }
}
```

</TabItem>
</Tabs>

`.playing(.fromProgress(0, toProgress: progress, loopMode: .playOnce))` заполняет кольцо один раз — от пустого состояния до значения `progress`. Если в вашем приложении стрик уже хранится в `ObservableObject`, используйте этот объект вместо `StreakStore`.

## 4. Привяжите анимацию к кастомному элементу \{#match-the-animation-to-the-custom-element\}

В вашем [общем резолвере](ios-flow-custom-elements#set-an-app-wide-resolver) добавьте свойство для модели серии. Затем добавьте кейс, который возвращает `StreakRingView` для Type `lottie_animation` и ID `streak_ring`. Выделенные строки показывают, что нужно добавить. Если в вашем приложении ещё нет общего [резолвера](ios-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views), скопируйте весь код:

<Tabs groupId="current-os" queryString>
<TabItem value="ios" label="iOS" default>

```swift showLineNumbers title="Swift" {2,6,14-18}

struct CustomElementsResolver: AdaptyUICustomElementsResolver {
    let streakStore: StreakStore

    func view(
        forType type: String,
        id: String,
        context: AdaptyUICustomElementContext
    ) -> AnyView? {
        switch type {
        case "lottie_animation" where id == "streak_ring":
            guard let animation = LottieAnimation.named(id) else {
                return nil // no animation file: show the fallback
            }
            return AnyView(StreakRingView(animation: animation, streakStore: streakStore))
        // the other cases of your resolver
        default:
            return nil
        }
    }
}
```

</TabItem>
</Tabs>

Поместите case `streak_ring` перед другими case `lottie_animation`, потому что Swift выполняет только первый подходящий case. Если в бандле приложения нет файла с таким ID, резолвер возвращает `nil`, и пользователи видят фолбэк.

Создайте резолвер с моделью стрика и установите его как общесистемный. Вызовите `AdaptyUI.setCustomElementsResolver(_:)` один раз — например, при запуске приложения:

<Tabs groupId="current-os" queryString>
<TabItem value="ios" label="iOS" default>

```swift showLineNumbers title="Swift"

// the streak model that your app updates
@MainActor let streakStore = StreakStore()

// keep this instance: a resolver for one flow can reuse it
@MainActor let customElementsResolver = CustomElementsResolver(streakStore: streakStore)

AdaptyUI.setCustomElementsResolver(customElementsResolver)
```

</TabItem>
</Tabs>

## 5. Протестируйте на устройстве \{#test-on-a-device\}

Flow & Paywall Builder не может выполнять код вашего приложения, поэтому на холсте отображается только резервный вариант. Чтобы предварительно просмотреть анимацию:

1. [Опубликуйте флоу](builder-save-publish). Чтобы увидеть последнюю опубликованную версию вместо кешированной, зарегистрируйте устройство как [тестовое](test-devices).
2. Запустите сборку приложения с резолвером. Установите для стрика несколько значений, например 0, 4 и 7 дней. Откройте экран для каждого значения и убедитесь, что кольцо заполняется до нужного значения.

Чтобы протестировать резервный вариант, удалите файл анимации из сборки и снова откройте экран.

Чтобы выяснить, почему вместо анимации отображается резервный вариант, следуйте инструкциям в разделе [Тест на устройстве](ios-flow-custom-elements#test-on-a-device) руководства для iOS.
