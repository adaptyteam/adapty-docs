Флоу можно создать несколькими способами:

- **[Из шаблона](#use-a-template)**: Начните с готового многоэкранного флоу и отредактируйте любой элемент.
- **[Из дизайна Figma](#import-a-design-from-figma)**: Выберите фреймы в Figma, отправьте их в Adapty и отредактируйте результат как флоу.
- **[С помощью AI-инструмента для кода](flow-generator-skill)**: Загрузите скилл flow-generator, опишите флоу на обычном языке, и инструмент создаст его через Adapty CLI.
- **[С нуля](#start-from-scratch)**: Начните с одного пустого экрана.
- **[Из существующего пейвола](#migrate-a-paywall-from-the-legacy-paywall-builder)**: Пересоздайте пейвол из Paywall Builder как флоу — с его макетом, текстом, продуктами и локализациями.

## Создание флоу \{#create-flow\}

<ZoomImage id="create-flow-menu.webp" width="300px" alt="Create flow menu with Start from scratch and Browse templates options" float="right" />

1. Откройте страницу [**Flows**](filter-flows).
2. Нажмите **Create flow**.
3. Выберите вариант:
   - **Browse templates** (открывает библиотеку шаблонов)
   - **Start from scratch** (создаёт пустой флоу)
4. Переименуйте флоу в редакторе. Нажмите на название флоу в шапке и введите новое имя.

<ZoomImage id="rename-flow.webp" width="500px" alt="Rename the flow name in the top toolbar" />

:::warning
Adapty допускает одинаковые названия флоу. Переименовывайте каждый новый флоу, иначе получите несколько флоу с названием **Untitled**, которые сложно различить.
:::

### Использование шаблона \{#use-a-template\}

<ZoomImage id="template-library.webp" width="700px" alt="Template library modal with template cards" />

Библиотека шаблонов содержит несколько готовых шаблонов, которые служат отправной точкой для вашего флоу. Каждый из них — полноценный флоу с несколькими экранами, интерактивными элементами и настроенной навигацией. Любой элемент можно отредактировать под свои нужды.

Чтобы применить шаблон:

1. В библиотеке шаблонов просмотрите карточки. На каждой карточке показаны скриншоты из флоу.
2. Нажмите **Use as template** на нужной карточке.

Шаблон загружается в конструктор. Отсюда вы можете изменить любой элемент, экран или свойство.

### Начать с нуля \{#start-from-scratch\}

<ZoomImage id="empty-screen.webp" width="300px" alt="Пустой флоу с одним пустым экраном в конструкторе" float="right" />

Начать с нуля — создать флоу с одним пустым экраном. Оформите экран с помощью элементов из [библиотеки элементов](builder-elements).

## Импортировать дизайн из Figma \{#import-a-design-from-figma\}

:::link
Основная статья: [Импортировать дизайн из Figma](import-from-figma)
:::

Если макет пейвола уже есть в Figma, его можно отправить в Adapty, не воссоздавая экраны вручную:

1. Установите плагин Adapty для Figma.
2. Выберите фреймы и запустите плагин.
3. Adapty получит ваш флоу с его структурой, текстом и изображениями. Интерактивные элементы нужно настроить вручную.

## Миграция пейвола из устаревшего Paywall Builder \{#migrate-a-paywall-from-the-legacy-paywall-builder\}

:::link
Основная статья: [Конвертация пейвола во флоу](convert-paywall-to-flow)
:::

Вместо того чтобы создавать флоу из шаблона, можно конвертировать уже существующий устаревший пейвол.

Откройте страницу пейвола на дашборде и нажмите **Move to new builder**. Adapty пересоздаст пейвол как новый черновик флоу — сохранив макет, текст, продукты и локализации. Старый пейвол продолжит работу, чтобы переход был плавным.

<ZoomImage id="move-to-new-builder.webp" width="700px" alt="Move to new builder button in the paywall action row" />

## Смена шаблона \{#change-the-template\}

Шаблон можно сменить прямо в конструкторе. Откройте панель **Screens** и нажмите кнопку **Templates** <Inline id="template-library.svg" alt="Templates" />, чтобы снова открыть библиотеку шаблонов, затем выберите новый шаблон.

:::warning
Применение нового шаблона заменяет текущий черновик флоу. Adapty запросит подтверждение — нажмите **Use template**, чтобы продолжить, или **Cancel**, чтобы оставить черновик. После подтверждения восстановить предыдущий черновик невозможно. Опубликованный флоу остаётся активным и не затрагивается.
:::

## Пользовательские шрифты в шаблонах \{#custom-fonts-in-templates\}

:::link
Основная статья: [Пользовательские шрифты в Flow & Paywall Builder](using-custom-fonts-in-flow-builder)
:::

<ZoomImage id="custom-font-warning.webp" width="300px" alt="Custom font chip on a template card with the warning tooltip" float="right" />

Шаблоны с отметкой **Custom font** используют пользовательские шрифты. Эти шрифты не входят в состав SDK. Наведите курсор на отметку, чтобы увидеть, какие шрифты использует шаблон.

Чтобы типографика отображалась корректно на устройстве, добавьте файлы шрифтов в бандл приложения. В старых версиях приложения, где шрифт отсутствует, будет использоваться системный шрифт.

Чтобы сменить шрифт, не затрагивая старые версии, [скопируйте флоу](copy-flows), измените шрифт в копии и ограничьте её [версиями приложения, в которых есть этот шрифт](segments).
