:::important
Прежде чем флоу дойдёт до пользователей, потребуется более новая версия SDK и отдельный плейсмент:

- **Adapty SDK версии 4.0 или выше**: более ранние версии SDK не умеют отображать флоу.
- **Собственный плейсмент для флоу**: флоу и пейволы — это разные типы контента, поэтому каждый из них живёт в своём типе плейсмента. Флоу нельзя поместить в плейсмент для пейвола, а новый плейсмент для флоу не может переиспользовать ID плейсмента пейвола — ID плейсментов уникальны в рамках всего приложения. См. [Создание плейсмента](create-placement).
:::

В Adapty флоу создаются в визуальном редакторе без кода.

- **Создавайте пейволы, онбординги и не только**: Создавайте динамические одно- или многоэкранные флоу.
- **Готовые шаблоны флоу**: Начните флоу с [профессионально оформленного шаблона](paywall-builder-templates).
- **Гибкий дизайн**: Воссоздавайте сложные экраны визуально — без единой строки кода.
- <Inline id="sparkle.svg" alt="AI Editor" /> **[AI Editor](flow-ai-editor)**: Опишите изменение простым языком и наблюдайте, как оно применяется на экране — меняйте стиль, текст или расположение элементов, не трогая настройки.
- **Нативный рендеринг**: SDK Adapty рендерит флоу нативно, без веб-вьюшек, обеспечивая бесшовный пользовательский опыт.
- **Обновления без релиза**: Меняйте тексты, дизайн или логику в любое время. Обновления доходят до пользователей без выпуска нового приложения.

## Что можно создать \{#what-you-can-build\}

Флоу можно разместить в любом месте приложения — при первом запуске, перед премиум-функцией или после ключевого действия. Каждый экран полностью настраивается, поэтому флоу всегда соответствует контексту. Вот несколько самых популярных сценариев:

- **Онбординг приложения**: покажите возможности приложения, задайте вопросы и персонализируйте выделенные функции и CTA на основе ответов на квиз. См. [Создание персонализированного онбординг-флоу](onboarding-flow-tutorial).
- **Экраны пейвола**: разместите ограничение доступа перед премиум-контентом и представьте продукты со списком функций, ценами и кнопкой покупки. См. [Создание базового экрана пейвола](basic-paywall-screen).
- **Тарифные планы во вкладках**: покажите уровни подписки рядом во вкладках, меняя список функций и CTA при переключении между ними. См. [Создание пейвола с вкладками](paywall-with-tabs) и [Разные функции для каждого продукта](paywall-features-per-product).
- **Раскрывающиеся списки планов**: начните с одного выделенного предложения и откройте полный список продуктов в нижнем листе, когда пользователь захочет сравнить. См. [Показ всех планов в нижнем листе](show-plans-bottom-sheet).
- **Опросы и квизы**: собирайте цели, предпочтения или уровень опыта, затем используйте ответы для ветвления флоу, адаптации последующих экранов или [обработки в приложении](ios-flow-input). См. [Поля ввода и формы в Flow Builder](builder-inputs-and-forms).
- **Социальное доказательство**: укрепляйте доверие с помощью карточек с отзывами, рейтингов и рекомендаций непосредственно перед принятием решения о покупке. См. [Отзывы и рекомендации](builder-reviews-and-testimonials).
- **Промо- и win-back экраны**: запускайте скидки с ограниченным сроком действия, предложения с бесплатным пробным периодом или win-back-экраны для повторного вовлечения ушедших пользователей.

Это лишь самые распространённые паттерны. Флоу строятся из гибких, переиспользуемых элементов, поэтому вы можете собирать из них практически любые экраны, которые нужны вашему продукту, — и перестраивать их по мере его развития.

## Создайте флоу \{#create-a-flow\}

[Создайте новый флоу](paywall-builder-templates) из галереи шаблонов или с чистого холста, а затем настройте его с помощью следующих возможностей:

- **[Библиотека элементов](builder-elements)** — готовые блоки для текста, медиа, кнопок, форм и другого контента.
- **[Действия](onboarding-actions)** — навигация между экранами, открытие URL, запуск покупок и многое другое.
- **[Переменные](onboarding-variables)** — использование значений переменных в тексте или для логики флоу на основе триггеров.
- **[Условная навигация](onboarding-navigation-branching)** — ветвление флоу в зависимости от действий пользователя.
- **[Квизы и поля ввода](builder-inputs-and-forms)** — сбор пользовательского ввода, его использование во флоу или передача в приложение.
- <Inline id="sparkle.svg" alt="AI Editor" /> **[AI Editor](flow-ai-editor)** — опишите изменение на обычном языке, и ИИ применит его к текущему экрану.
- **[Тёмный режим](paywall-dark-mode)** — стилизация элементов под тему устройства.
- **[Локализация](add-flow-remote-config-locale)** — вручную или с помощью ИИ.

[Сохраните и опубликуйте](builder-save-publish) черновик, затем прикрепите его к [плейсменту флоу](create-placement) — новому, с идентификатором плейсмента, который не используется ни в одном другом плейсменте приложения. Плейсмент флоу может содержать разные флоу для разных [аудиторий](add-audience-paywall-ab-test).
