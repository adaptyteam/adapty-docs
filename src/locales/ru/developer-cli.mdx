**Adapty Developer CLI** — это инструмент командной строки для управления аккаунтом Adapty без открытия дашборда. Он предоставляет основные возможности настройки прямо из терминала или автоматизированных сред.

<AIPromo id="adapty-mcp" title="Работайте в чате вместо терминала." cta="Подключите Adapty MCP server">
Adapty MCP server открывает доступ к тому же аккаунту из приложения Claude, Claude Code, Codex и других MCP-клиентов. Достаточно один раз войти через браузер — ничего устанавливать не нужно.
</AIPromo>

**Что можно делать с помощью CLI:**

- Создайте и настройте приложения для iOS и Android в своём аккаунте Adapty
- Определите уровни доступа — уровни подписки, которые приложение проверяет во время выполнения
- Настройте продукты и привяжите их к идентификаторам в App Store и Google Play
- Привяжите предложения стора, включая бесплатные пробные периоды Google Play, к продуктам — см. [Предложения продуктов](developer-cli-products#product-offers) в справочнике команд
- Создайте пейволы и назначьте им продукты
- Создайте флоу, напишите конфиги их билдера и опубликуйте их — см. [Флоу](developer-cli-flows) в справочнике команд
- Настройте плейсменты для загрузки пейволов или флоу через SDK
- Читайте аналитику своего приложения — выручку, MRR, конверсии, воронку, удержание, LTV и когорты — через [Analytics](developer-cli-analytics)
- Создавайте, запускайте, останавливайте и заменяйте A/B-тесты пейволов и флоу через [A/B tests](developer-cli-ab-tests)
- Управляйте кампаниями Apple Ads, ключевыми словами и правилами автоматизации через [Ads Manager](developer-cli-ads-manager)
- Читайте отчёты Adapty Attribution — расходы, установки, выручку и ROAS по каналам и кампаниям — через [Attribution](developer-cli-attribution)
- Настройте Apple Retention Messaging, создавайте, изменяйте и активируйте сообщения удержания, которые видят подписчики при отмене, через [Retention Messaging](developer-cli-retention-messaging)
- Включите Refund Saver, настройте его параметры возврата и просматривайте сохранённые данные через [Refund Saver](developer-cli-refund-saver)
- Мигрируйте проект RevenueCat — каталог, дизайны пейволов, код приложения и историю транзакций — см. [Миграция с RevenueCat](migration-from-revenuecat)
- Установите скиллы Adapty в своих агентах программирования с помощью `adapty skills install` — см. [Скиллы](developer-cli-reference#skills) в справочнике команд
