**Adapty Developer CLI** — это инструмент командной строки для управления аккаунтом Adapty без открытия дашборда. Он предоставляет основные возможности настройки, доступные из терминала или автоматизированных сред.

**Что можно делать с CLI:**

- Создавать и настраивать iOS- и Android-приложения в аккаунте Adapty
- Определять уровни доступа — уровни подписки, которые приложение проверяет во время выполнения
- Настраивать продукты и привязывать их к идентификаторам в App Store и Google Play
- Создавать пейволы и назначать на них продукты
- Создавать флоу, писать конфигурации для их билдера и публиковать их — см. [Флоу](developer-cli-reference#flows) в справочнике команд
- Настраивать плейсменты для получения пейволов или флоу через SDK
- Запускать кампании Apple Ads, ключевые слова и правила автоматизации через [Ads Manager](developer-cli-ads-manager)
- Читать отчёты Adapty Attribution — расходы, установки, выручку и ROAS по каналам и кампаниям — через [Attribution](developer-cli-attribution)
- Мигрировать проект RevenueCat — каталог, дизайны пейволов, код приложения и историю транзакций — см. [Миграция с RevenueCat](migration-from-revenuecat)
- Устанавливать скиллы Adapty в своих агентах с помощью `adapty skills install` — см. [Skills](developer-cli-reference#skills) в справочнике команд
