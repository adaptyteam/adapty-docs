В этой статье собраны проблемы, которые чаще всего возникают при построении флоу в [Flow Builder](adapty-flow-builder), с указанием причин и способов их устранения.

## Флоу не открывается для предпросмотра или публикации \{#a-flow-wont-preview-or-publish\}

<ZoomImage id="flow-publish-error.webp" width="300px" alt="Publish error message in the Flow Builder web UI when a flow has incomplete actions" float="right" />

Предпросмотр и публикация флоу недоступны, если присутствует хотя бы одна из следующих проблем.

- Взаимодействие с неполной конфигурацией. Распространённые случаи:
    - Действие **Open URL** без целевого URL.
    - Действие **Navigate to screen** без указания экрана назначения — также возникает, если экран назначения был удалён после настройки действия.
    - **Условное действие** без указания оператора или значения.
    - Действие **Set variable** без назначения переменной/значения.
    - Действие **Purchase** без продукта (встроенная покупка) или без URL Web Paywall (веб-оплата).
    - Действие **Custom** без идентификатора действия (Action ID).
    - Действие **Show alert** с пустым заголовком (Title) или сообщением (Message).
    - Действие **Show** или **Hide** без выбранного элемента.
    - Действие **Select product** без целевого продукта — также возникает, если целевой элемент продукта удалён, перемещён из своей группы продуктов или находится на другом экране.
    - Действие **Select product**, сохранённое внутри переиспользуемого компонента, или нацеленное на идентификатор элемента, который используется более чем на одном экране.
- **Экран без элементов**.
- Элемент продукта **без привязанного продукта** — может возникнуть при удалении привязанного продукта.
- Невалидный JSON в **Remote Config** нарушает весь процесс доставки — сохранить черновик в этом случае невозможно.

Чтобы поймать проблемы до публикации, [просмотрите флоу в приложении Adapty](paywall-device-compatibility-preview). Если флоу не загружается, сообщение об ошибке даст более подробную информацию.

Этот список — о том, что мешает сохранить флоу. Флоу может пройти все эти проверки и при этом оказаться небезопасным для реального пользователя — без кнопки восстановления покупок, с нерабочей кнопкой покупки или без нужных переводов. Навык [аудита флоу](flow-audit-skill) проверяет именно это и заканчивается вынесением вердикта «пройдено/не пройдено», а не сообщением об ошибке.

## Публикация завершается ошибкой «Something went wrong» \{#publishing-fails-with-something-went-wrong\}

Эта ошибка означает, что запрос на публикацию не прошёл на стороне Adapty, — проблема не в настройках вашего флоу. Именно поэтому сообщение такое общее. Ваша текущая версия не изменилась. Скопируйте **Request ID** из сообщения об ошибке и отправьте его на [support@adapty.io](mailto:support@adapty.io), чтобы команда смогла найти упавший запрос.

## Офер не применяется при покупке \{#an-offer-doesnt-apply-at-purchase\}

Paywall Builder проверяет, что у каждого элемента продукта есть продукт, но не проверяет офер продукта. Если офер впоследствии будет изменён или удалён в сторе или в Adapty, флоу всё равно публикуется, а покупка проходит без офера. После изменения оферов откройте флоу заново, переназначьте офер для каждого затронутого элемента продукта и опубликуйте флоу повторно.

## Цена предложения не отображается в превью \{#an-offer-price-is-empty-in-the-preview\}

Превью в билдере не имеет доступа к сторам, поэтому `offer_price`, `offer_billing_period` и `offer_full_duration` отображают имя переменной в фигурных скобках вместо значения. Они подставляются корректно, когда SDK рендерит флоу в вашем приложении. Чтобы просмотреть условия, зависящие от типа предложения, см. [Предпросмотр продуктов и предложений](paywall-device-compatibility-preview#preview-products-and-offers).

## Цвет отображается неправильно при заданной прозрачности \{#a-color-renders-wrong-when-opacity-is-set\}

Вводите цвета в формате 6-значного hex-кода, например `#FFFFFF`. Сокращённый код вроде `#FFF` в сочетании с прозрачностью ниже 100% даёт некорректный цвет.

## Изменения типографики не применяются к состоянию элемента \{#typography-edits-dont-reach-an-element-state\}

Если у состояния, например **Selected**, есть собственные настройки типографики, изменения типографики в состоянии **Default** — включая применение другого текстового стиля — на него не влияют. Редактируйте типографику состояния напрямую.

## Элементы теряют оформление после удаления текстового стиля \{#elements-lose-their-styling-after-a-text-style-is-deleted\}

Удаление [текстового стиля](builder-styling#text-styles) не копирует его настройки в элементы, которые его используют: эти элементы возвращаются к типографике по умолчанию. Перед удалением стиля переназначьте затронутые элементы на другой стиль или задайте их типографику вручную.

## Условия и переменные перестают работать после изменения ID элемента \{#conditions-and-variables-break-after-an-element-id-change\}

Условия и текстовые переменные ссылаются на элементы по **Element ID**, и при изменении ID эти ссылки не обновляются автоматически — они просто перестают работать. Задавайте Element ID до того, как на него ссылаетесь. Если всё же пришлось изменить ID, вручную обновите все условия и переменные, которые на него ссылаются. Исключение — сегменты прогресс-бара: при их переименовании ссылки обновляются автоматически.

## Условие или переменная возвращает пустое значение \{#a-condition-or-variable-resolves-to-an-empty-value\}

Список переменных содержит поля со всех экранов, поэтому условие или текстовая переменная может ссылаться на поле, которое пользователь ещё не заполнил. Во время выполнения такая ссылка возвращает пустое значение. Ссылайтесь только на поля, собранные на предыдущих экранах флоу.

## Действие Set variable не меняет выбранный продукт \{#a-set-variable-action-doesnt-change-the-selected-product\}

Выбранный продукт не является переменной, которой можно присвоить значение, поэтому **Set variable** не может изменить выбор. Используйте действие [**Select product**](onboarding-actions#select-product).

## Изображение или видео не загружается \{#an-image-or-video-wont-upload\}

Файл, не соответствующий ограничениям медиа Flow Builder, не загрузится. Проверьте файл на соответствие требованиям для [изображений](custom-media#image) и [видео](custom-media#video):

| Элемент | Форматы | Максимальный размер файла | Другие ограничения |
| :--- | :--- | :--- | :--- |
| Изображение | `.JPG`, `.PNG`, `.WEBP` | 20 МБ | — |
| Видео | `.MP4`, `.WEBM` | 50 МБ | Максимум 30 секунд; минимум 640×640 пикселей |

Следующие форматы не поддерживаются:

- **Анимированные GIF и анимированные WEBP**: Для добавления анимации используйте элемент Video.
- **SVG**: Экспортируйте файл в PNG или WEBP. Для иконок ничего загружать не нужно — элемент Icon использует встроенную библиотеку [Tabler Icons](custom-media#icon).

## Подвал не отображается \{#a-footer-doesnt-render\}

Подвал отображается только на экране, где включена **Vertical scroll**. Включите **Vertical scroll** в [**Screen settings** > **Scroll**](paywall-layout-and-products#scroll).
