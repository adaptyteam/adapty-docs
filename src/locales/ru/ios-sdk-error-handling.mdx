В Adapty SDK есть собственная обёртка для всех типов ошибок — `AdaptyError`. По сути, каждая ошибка, возвращаемая SDK, является `AdaptyError`. У неё есть два полезных свойства: `originalError` и `adaptyErrorCode`, описанные ниже.

**originalError** содержит исходную ошибку на случай, если вам нужно работать с ней напрямую. Покупки проходят через StoreKit 2, поэтому при неудачной покупке это обычно ошибка StoreKit 2: [StoreKitError](https://developer.apple.com/documentation/storekit/storekiterror) или [Product.PurchaseError](https://developer.apple.com/documentation/storekit/product/purchaseerror). Другие ошибки могут содержать [SKError](https://developer.apple.com/documentation/storekit/skerror), [NSError](https://developer.apple.com/documentation/foundation/nserror) или общую Swift-ошибку [Error](https://developer.apple.com/documentation/swift/error). Это свойство опционально, поскольку часть ошибок генерируется непосредственно SDK — например, при несогласованных или отсутствующих данных — и не имеет исходной ошибки, вокруг которой изначально строился обёртка.

**adaptyErrorCode** можно использовать для обработки распространённых проблем, например:

- неверные учётные данные
- сетевые ошибки
- проблемы с оплатой
- неверный чек
- и многое другое

Отменённая или ожидающая покупка не является ошибкой. `makePurchase` возвращает её как результат `.userCancelled` или `.pending`, поэтому обрабатывайте это в результате. В блоке `catch` сравните код ошибки с кодами, которые вы хотите обработать:

```swift showLineNumbers title="Swift"
do {
    let purchaseResult = try await Adapty.makePurchase(product: product)
    if case .userCancelled = purchaseResult {
        // purchase was cancelled
        // you can offer discount to your user or remind them later
    }
} catch let error as AdaptyError {
    if error.adaptyErrorCode == .productPurchaseFailed {
        // read error.originalError for the StoreKit reason
    }
} catch {
    // handle other errors
}
```

:::tip
**Включите подробные логи перед отладкой.** Большинство `AdaptyError` оборачивают ошибку StoreKit, сети или бэкенда. Если включить подробные логи (`Adapty.logLevel = .verbose` — см. [Логирование](sdk-installation-ios#logging)), эта вложенная ошибка выводится в консоль, и обычно сразу становится ясна реальная причина. Свойство `originalError` заполняется в любом случае — подробные логи просто делают её видимой в консоли.
:::

:::important
Если эти решения не помогли, перейдите в раздел [Другие проблемы](#other-issues) — там описаны шаги, которые стоит выполнить перед обращением в поддержку, чтобы мы могли помочь вам быстрее.
:::

## Медленная загрузка сразу после `updateProfile` \{#slow-fetches-right-after-updateprofile\}

Если вы задаёте пользовательские атрибуты через `updateProfile` и запрашиваете плейсмент в той же сессии, SDK может вычислить хеш сегмента для плейсмента на основе атрибутов, которые ещё не успели примениться. SDK повторяет запрос после обновления хеша сегмента, поэтому симптом проявляется как замедленная загрузка, а не ошибка. Загрузка завершается неудачей только в том случае, если после повторной попытки расхождение сохраняется — это означает, что запись атрибута не прошла.

Чтобы избежать повторного запроса, дождитесь завершения `updateProfile` перед загрузкой плейсмента. Подробнее — в разделе [Порядок вызовов в iOS SDK](ios-sdk-call-order).

## Другие проблемы \{#other-issues\}

Если вы ещё не нашли решение, попробуйте следующее:

- **Обновите SDK до последней версии**: мы всегда рекомендуем использовать актуальные версии SDK — они более стабильны и содержат исправления известных проблем.
- **Обратитесь в службу поддержки или получите помощь от других разработчиков** на [форуме поддержки](https://adapty.featurebase.app/).
- **Напишите в поддержку на [support@adapty.io](mailto:support@adapty.io) или в чат**: если вы не готовы обновлять SDK или обновление не помогло, свяжитесь с нашей командой поддержки. Обратите внимание: проблема решится быстрее, если вы [включите подробное логирование](sdk-installation-ios#logging) и поделитесь логами с командой. Также можно прикрепить соответствующие фрагменты кода.
