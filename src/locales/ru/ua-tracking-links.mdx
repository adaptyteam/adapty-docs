:::important
Трекинговые ссылки помогают Adapty атрибутировать установки приложения. Если ваша реклама ведёт пользователей в веб-воронку, [добавьте к её URL параметры Adapty](ua-tag-ad-urls).
:::

Обычно целевая страница объявления — это страница в App Store или Google Play. Эта страница принадлежит стору, а не вам, поэтому она не может передавать клики в Adapty.

Используйте вместо этого трекинговую ссылку в качестве целевой страницы. Adapty фиксирует кампанию, группу объявлений и само объявление, а затем перенаправляет пользователя в стор — после чего сопоставляет этот клик с установкой, о которой сообщает SDK. В [аналитике атрибуции Adapty](ua-analytics) вы увидите, какие объявления приносят доход.

Adapty автоматически формирует ссылки для кампаний [Meta Ads](ua-facebook#step-2-add-campaigns) и [TikTok for Business](ua-tiktok#step-2-add-campaigns). Для всех остальных рекламных сетей [создайте кастомную ссылку отслеживания](#custom-tracking-links) с помощью интеграции **Custom** в дашборде.

## Типы трекинговых ссылок \{#tracking-link-types\}

Adapty генерирует два вида трекинговых ссылок:

- **Платформенные ссылки** — отдельная ссылка для каждого стора. Они могут вести пользователей на кастомизированные страницы в сторе, которые соответствуют вашей кампании.
- **One Link** — единая ссылка для обоих сторов, определяющая платформу пользователя в момент клика.

На одной странице трекинговой ссылки хранятся ссылки для всех сторов, которые вы настраиваете, поэтому создавать отдельную страницу для каждого стора не нужно. Для большей гибкости мы рекомендуем использовать платформенные ссылки.

## Пользовательские ссылки для отслеживания \{#custom-tracking-links\}

:::note
Apple Search Ads не требует ссылки для отслеживания. Adapty получает атрибуцию Apple Search Ads без неё, а управление кампаниями ведётся в [Adapty Ads Manager](adapty-ads-manager).
:::

Чтобы создать пользовательскую ссылку для отслеживания:

1. В дашборде Adapty Attribution откройте **Integrations** и выберите карточку **Custom** в группе **Network**.

<ZoomImage id="custom-tracking-link.webp" width="700px" alt="Integrations page in Adapty Attribution with the Custom card highlighted in the Network group" />

2. Нажмите **Create link**.

<ZoomImage id="new-tracking-link.webp" width="700px" />

3. Выберите приложение из списка и нажмите **Next**.

<ZoomImage id="ua-choose-app.webp" width="700px" />

4. Заполните параметры ссылки, чтобы привязать её к конкретной кампании и объявлению.

| Параметр          | Описание                                                                                                          |
|-------------------|-------------------------------------------------------------------------------------------------------------------|
| **Name**          | Внутреннее название трекинговой ссылки.                                                                           |
| **Channel**       | Источник трафика, например Meta, Reddit или TikTok. Используется для группировки кампаний в аналитике.            |
| **Campaign ID**   | Уникальный идентификатор кампании в вашей рекламной платформе.                                                    |
| **Campaign name** | Читаемое название кампании.                                                                                       |
| **Ad set ID**     | Уникальный идентификатор группы объявлений в вашей рекламной платформе.                                           |
| **Ad set name**   | Название группы объявлений.                                                                                       |
| **Ad ID**         | Уникальный идентификатор отдельного рекламного креатива.                                                          |
| **Ad name**       | Название рекламного креатива или варианта.                                                                        |

5. По умолчанию создаётся One Link. Чтобы добавить [ссылки для конкретных платформ](#tracking-link-types), снимите флажок **One Link**.

<ZoomImage id="one-link.webp" width="700px" />

6. Нажмите **Create**.
7. Откройте страницу трекинговой ссылки. В разделе для вашего [типа ссылки](#tracking-link-types) скопируйте значение **Click link**.

:::tip
Вы также можете задать дополнительные параметры ссылки для [работы с отложенными данными](ua-deferred-data). Например, реализовать отложенный диплинкинг.
:::

<ZoomImage id="click-link.webp" width="700px" />

8. Перейдите в рекламную платформу и используйте эту ссылку в качестве целевого URL объявления.
