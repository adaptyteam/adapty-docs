В этом гайде вы настроите Adapty Mail и запустите свой первый email-флоу.

Настройка состоит из девяти частей:

1. [Выберите тип аккаунта](#1-choose-your-account-type)
2. [Подключите данные](#2-connect-your-data)
3. [Настройте бренд](#3-set-up-your-brand)
4. [Настройте домен отправки](#4-set-up-your-sending-domain)
5. [Добавьте адрес компании](#5-add-your-company-address)
6. [Создайте веб-пейвол](#6-create-a-web-paywall)
7. [Сгенерируйте кампанию с помощью ИИ](#7-generate-a-campaign-with-ai)
8. [Запустите флоу](#8-launch-a-flow)
9. [Начните отправку](#9-start-sending)

Adapty Mail отслеживает ваш прогресс в чеклисте онбординга и скрывает его, когда все шаги выполнены.

## Перед началом работы \{#before-you-start\}

Убедитесь, что у вас есть всё необходимое:

- **Доступ к DNS**: вы можете добавлять записи в корневой домен.
- **Платежи**: у вас есть аккаунт Stripe с настроенными продуктами подписки. Чтобы использовать другого провайдера, разместите чекаут самостоятельно — см. [Настройка чекаута](mail-checkout).

## 1. Выберите тип аккаунта \{#1-choose-your-account-type\}

:::warning
Выбирайте внимательно — проект, созданный вами самостоятельно в Adapty Mail, нельзя будет привязать к Adapty позже.
:::

Тип аккаунта определяет, что ваш проект в Adapty Mail сможет делать:

| | Связано с Adapty (рекомендуется) | Автономно |
| --- | --- | --- |
| **Регистрация** | Войдите в свой [аккаунт Adapty](https://app.adapty.io/) и откройте **Mail**. Adapty создаёт проект, связанный с вашим приложением. Обмен данными между Adapty Mail и SDK отключён до последнего шага настройки. Переносить покупки в Adapty не нужно: достаточно простого в настройке [режима наблюдения](observer-vs-full-mode), который только передаёт данные о транзакциях. | [Зарегистрируйтесь только в Adapty Mail](https://mail.adapty.io/signup) с помощью адреса электронной почты и пароля. Аккаунт Adapty не нужен, ничего устанавливать в приложении не требуется — данные вы приносите сами через FunnelFox или API. |
| **Страница оформления** (Шаг 6) | **Сгенерировать с помощью AI** — размещённая страница оформления, построенная под ваш бренд, с подключёнными платежами Stripe — или ваш собственный пейвол | Ваш собственный пейвол |
| **Сегменты** | Импортируйте из Adapty или создайте в Mail | Создайте в Mail |
| **Бренд** — основа для генерации писем: название, логотип, цвета и тон (Шаг 3) | Формируется из страницы вашего приложения в сторе до вашего прихода, если она есть | Формируется из URL стора, который вы вставляете |
| **Данные о покупках** (Шаг 2) | Один клик в **Settings** > **Project**; FunnelFox и API тоже работают | Секретный ключ, вставленный в дашборд Adapty или FunnelFox, либо API |
| **Команда** | Участники команды присоединяются, когда открывают Mail из вашей компании в Adapty; также доступны приглашения по email | Приглашения по email |

## 2. Подключите свои данные \{#2-connect-your-data\}

Прежде чем Adapty Mail сможет отправить пользователю письмо, ему нужно:

- **Адрес электронной почты**: куда будут отправляться письма.
- **[Customer user ID](how-profiles-work)**: уникальный идентификатор пользователя. Adapty хранит его в профиле пользователя, чтобы распознавать одного и того же человека на разных устройствах. Без него Adapty создаёт новый профиль каждый раз, когда пользователь переустанавливает приложение или выходит из системы.
- **Лента событий подписки**: пробные периоды, продления, отмены и возвраты в режиме реального времени. Они позволяют таргетировать пользователей на основе их поведения и связывать доход с письмом, которое привело к покупке. Без ленты событий пользователь может получить только цепочку писем для тех, кто ещё ничего не купил.

Следуйте инструкциям, чтобы создать **[точку входа](mail-entry-points)** для этих данных:

- **Adapty**: Используйте этот вариант, если ваше приложение уже работает с Adapty SDK. Adapty сам передаёт профили, адреса электронной почты и события подписок, поэтому собственный сервер не нужен. В приложении добавьте идентификацию пользователей и сбор email-адресов. См. [Подключение Adapty к Adapty Mail](mail-collect-emails).
- **Adapty Mail API**: Используйте этот вариант, если у вас уже есть бэкенд с этими данными, если в приложении нет Adapty SDK или если вы импортируете подписчиков из другого источника. Профили и транзакционные события вы отправляете самостоятельно. Секретный ключ в разделе **Settings** > **Project** используется для аутентификации запросов. См. [Отправка писем и транзакций через Adapty Mail API](mail-send-data-via-api).
- **FunnelFox**: Используйте этот вариант, если пользователи привлекаются и оплачивают через воронки FunnelFox. FunnelFox уже хранит их адреса электронной почты, покупки и события подписок и сам передаёт всё это в Adapty Mail — никакой работы с SDK и никаких запросов писать не нужно. См. [руководство по интеграции FunnelFox](https://funnelfox.com/docs/integrations/email-providers/adapty-mail).
- **Комбинация**: Можно использовать несколько точек входа одновременно. Adapty Mail сопоставляет входящие данные пользователей по `customer_user_id` и адресу электронной почты.

Adapty Mail начинает рассылать письма после завершения остальной части настройки.

## 3. Настройте свой бренд \{#3-set-up-your-brand\}

Adapty Mail не может создавать письма или веб-пейволы без **бренда**. Бренд хранит всю информацию, необходимую Adapty Mail для соответствия стилю и тональности вашего приложения: название, логотип, цвета, шрифты, тон общения, возможности и отзывы. Вы предоставляете описание из стора, а Adapty Mail создаёт бренд на его основе.

1. В Adapty Mail откройте **Brand**.
2. Если на странице уже отображается заполненный бренд — просмотрите его и продолжайте. Если показывается экран **Set up your brand** — следуйте инструкциям ниже.
3. В разделе **Store** выберите **App Store** или **Google Play**, затем вставьте URL вашего листинга.
   :::note
   Экран настройки принимает только ссылку на листинг в App Store или Google Play. Если у вашего приложения нет листинга в сторе — например, если вы используете воронку web-to-app — свяжитесь с поддержкой Adapty, прежде чем продолжить.
   :::
4. Нажмите **Build my brand**. Adapty Mail загрузит страницу, разберёт отзывы и определит голос бренда. Обычно это занимает меньше минуты.
5. Чтобы просмотреть разделы, отредактировать их вручную или добавить лендинги и социальные сети в качестве источников, см. [Brand](mail-brand).

## 4. Настройте домен для отправки писем \{#set-up-your-sending-domain\}

Adapty Mail отправляет письма с вашего личного домена. Вы один раз добавляете DNS-записи, и все кампании используют один и тот же верифицированный домен.

Чтобы зарегистрировать первый домен, перейдите в Adapty Mail в **Settings** > **DNS** > раздел **Email domains**.

1. В поле **Domain** введите корневой домен (например, `yourapp.com`). Принимаются только apex-домены — поддомены вроде `app.yourapp.com` не пройдут валидацию.
2. В поле **Sending subdomain** введите префикс, с которого будут уходить письма, или оставьте поле пустым, чтобы использовать `mail`. Тогда письма будут приходить с адреса `hello@mail.yourapp.com`.
3. Нажмите **Add domain**.

   <ZoomImage id="mail-email-domains.webp" width="500px" />

4. В панели управления вашего регистратора домена добавьте все DNS-записи, которые перечислены в карточке нового домена. Они разбиты на три группы: записи DKIM и MAIL FROM для вашего отправляющего поддомена, записи для почтового ящика, который прогревает домен, а также записи для `go.yourapp.com`, который обслуживает изображения и отслеживаемые ссылки. О том, что именно аутентифицирует каждая группа, читайте в разделе [Какие записи нужно добавить](mail-sending-domain#which-records-you-add). Чтобы скопировать все сразу, нажмите **Export**.
5. При желании добавьте предложенную TXT-запись DMARC для корневого домена (рекомендуется).
6. Нажмите **Check**, чтобы проверить записи немедленно, или закройте карточку и дайте Adapty Mail самостоятельно опросить DNS.

<ZoomImage id="mail-email-domains.webp" width="700px" />

Краткое описание проверки:

- **Автоматический опрос**: первая проверка запускается через 1 минуту после добавления домена, затем интервалы удваиваются — вплоть до одного раза в час, пока записи не будут найдены.
- **Ручная проверка**: нажмите **Check** в любой момент, чтобы запустить немедленную проверку.
- **Распространение DNS**: обычно занимает несколько минут, в редких случаях — до 48 часов.
- **Окно верификации**: 7 дней. Если оно истекает, ваши DNS-записи остаются на месте — добавьте домен повторно в **Settings** > **DNS**, чтобы начать новое окно.

Одного подтверждённого домена достаточно, чтобы начать работу с Adapty Mail. В проекте можно добавить до пяти доменов — остальные можно подключить позже.

Подробнее о типах записей и прогреве домена см. в разделе [Настройка домена для отправки](mail-sending-domain).

## 5. Добавьте адрес компании \{#add-your-company-address\}

Антиспамовые законы требуют указывать физический почтовый адрес в каждом маркетинговом письме. Adapty Mail автоматически добавляет его в подвал каждого кампейн-письма и блокирует создание кампаний, пока адрес не заполнен.

1. В Adapty Mail перейдите в **Settings** > **Company**.
2. В разделе **Company address** заполните поля **Legal company name**, **Address line 1**, **City**, **Postal code** и **Country**. Поля **Address line 2** и **State / Region** необязательны.
3. Нажмите **Save**.

## 6. Создайте веб-пейвол \{#create-a-web-paywall\}

Когда получатель кликает на CTA в письме, он попадает на **веб-пейвол** — страницу оформления заказа в браузере. Каждая кампания ссылается на него, и Adapty Mail отклонит кампанию без него. Это не ваш встроенный пейвол: покупка, совершённая там, является веб-платежом, а не транзакцией App Store или Google Play.

У вас есть два варианта:

- **Генерировать с помощью AI**: Создайте пейвол с помощью встроенного конструктора на базе [FunnelFox](https://funnelfox.com). Сгенерированный пейвол использует Stripe для обработки платежей.
- **Использовать собственный пейвол**: Укажите Adapty Mail страницу, которую вы уже хостите, с любым провайдером. Adapty Mail перенаправляет пользователя на ваш пейвол, подставляя данные пользователя прямо в URL. Пейвол на собственном хостинге может использовать любой платёжный провайдер.

:::note
**Для функции «Создать с помощью AI» необходимы Stripe и аккаунт, привязанный к Adapty**. Stripe — единственный провайдер, который поддерживается в сгенерированных чекаутах. Если вы используете другой провайдер или отдельный аккаунт Adapty Mail, используйте собственный размещённый пейвол.
:::

Для начала в Adapty Mail перейдите в **Web Paywalls** > **Create**.

<ZoomImage id="new-web-paywall.webp" width="500px" />

### Вариант A: Сгенерировать с помощью ИИ

На странице отображается чеклист с необходимыми условиями и встроенными кнопками — выполните их по порядку, а затем вернитесь и нажмите «Сгенерировать». Чеклист включает вход в Paywall Builder, подключение Stripe, добавление продуктов и проверку результата. Подробное описание см. в разделе [Настройка оплаты](mail-checkout). Если вы выполнили какое-либо условие в другой вкладке, нажмите **Refresh** в чеклисте, чтобы обновить статус.

Когда все условия будут отмечены зелёным, нажмите **Proceed to generation**. В диалоге **Choose plans**:

1. Выберите от 1 до 3 планов в одной валюте. Каждый план — это одно предложение, которое сгенерированный пейвол покажет при оформлении покупки. Нажмите **Add plan**, чтобы добавить второй и третий план.
2. Для каждого плана укажите продакшн-цену, её аналог в песочнице или оба значения. Продакшн-цена и цена в песочнице в одной строке считаются одним планом.
3. Нажмите **Generate paywall**.

Заполняйте колонку для каждого плана полностью или оставляйте полностью пустой — частично заполненная колонка заблокирует генерацию. Без цен в песочнице [тестовые письма](mail-testing) будут вести на продакшн-пейвол, а тестовые покупки работать не будут.

:::important
Пейвол должен быть опубликован до того, как он начнёт обрабатывать трафик оформления заказов. Неопубликованные пейволы возвращают ошибку, когда пользователи переходят по ссылкам оформления заказа из email.
:::

### Вариант Б: использование собственного пейвола \{#option-b-use-your-own-hosted-paywall\}

1. Выберите **Enter URL manually**.
2. Вставьте URL вашего пейвола с плейсхолдерами в качестве query-параметров. Adapty Mail подставляет их для каждого получателя, чтобы страница оформления покупки могла идентифицировать посетителя. Пример:

   ```
   https://example.com/paywall?email={email}&adapty_profile_id={adapty.external_profile_id}
   ```

   На странице создания перечислены доступные плейсхолдеры. Подробнее о том, что каждый из них подставляет, см. в разделе [Настройка чекаута](mail-checkout#use-your-own-hosted-paywall).
3. Сохраните и опубликуйте.

Подробнее об анатомии воронки оформления и о том, как работает персонализация, читайте в разделе [Настройка оформления](mail-checkout).

## 7. Создайте кампанию с помощью ИИ \{#7-generate-a-campaign-with-ai\}

**Кампания** — это последовательность из до 15 писем, которые один получатель получает в течение времени. ИИ генерирует всю последовательность на основе бренда, который вы настроили на [шаге 3](#3-set-up-your-brand): текст, дизайн, главные изображения и персонализированные ссылки на оформление покупки.

1. В Adapty Mail перейдите в **Campaigns** и нажмите **Create**.
2. Укажите название кампании.
3. В выпадающем списке **Web paywall** выберите веб-пейвол, добавленный на предыдущем шаге.

   <ZoomImage id="mail-new-campaign.webp" width="500px" />

4. Нажмите **Generate emails**.
5. Заполните диалог генерации — тон, язык, необязательный пользовательский промпт (до 2 000 символов) и количество писем (1–15, по умолчанию 4). Подробнее о каждом поле — в разделе [Создание кампании](mail-create-campaign).

   <ZoomImage id="generate-emails.webp" width="500px" />

6. Нажмите **Generate**. Генерация обычно занимает несколько минут. Если процесс не завершится за 5 минут, система прервёт его — в таком случае попробуйте ещё раз.
7. Просмотрите каждое письмо. В заголовке предпросмотра есть **Theme toggle** (Auto, Light, Dark), который управляет отображением — сам контент одинаков во всех режимах. Вы можете перегенерировать отдельные письма, отредактировать текст или открыть HTML-редактор для точной настройки.

<ZoomImage id="generated-emails.webp" width="700px" />

8. Нажмите **Create**, чтобы сохранить кампанию.

Кампания сохраняется как **черновик** и пока не отправляется — кампании запускаются только после привязки к флоу (следующий шаг). Отдельной кнопки «Опубликовать» в редакторе кампании нет.

## 8. Запустите флоу \{#8-launch-a-flow\}

В Adapty Mail есть собственные **флоу**. Флоу связывает **триггеры** (события подписки) с **кампаниями** (email-последовательностями). Для каждого из пяти триггеров — истечение подписки, неудачный платёж и т. д. — есть отдельный флоу. Флоу может отправлять одну кампанию всем, кто попал под триггер, или использовать **сегменты**, чтобы отправлять разным группам разные кампании.

1. В Adapty Mail перейдите в раздел **Flows** и откройте нужный триггер:
   - **Never purchased** — пользователи, которые зарегистрировались, но ещё не совершили покупку.
   - **Renewal cancelled** — пользователи, отключившие автопродление, но у которых ещё активна подписка.
   - **Billing issue** — платёж не прошёл, карта отклонена или истёк срок её действия, либо активен льготный период.
   - **Expired** — подписка истекла и доступ закрыт.
   - **Refunded** — пользователи, запросившие возврат средств после покупки.

   Подробнее о целях и тональности каждого триггера — в разделе [Флоу](mail-flows).

2. Нажмите **Create**, чтобы открыть диалоговое окно.

<ZoomImage id="create-flow-mail.webp" width="500px" />

3. В диалоговом окне:
   - Выберите **Segment**. **All Users** охватывает всех, кто попадает под этот триггер, — этого достаточно для запуска. Чтобы сузить аудиторию позже, создайте [другой сегмент](mail-segments) — отфильтрованную подгруппу пользователей по стране, возрасту или состоянию подписки.
   - Установите тип контента **Campaign** (вариант A/B-теста рассматривается в разделе [A/B-тестирование](mail-ab-testing)).
   - Выберите **Campaign**, сохранённую на шаге 7.
4. Нажмите **Save**.

Флоу запускается немедленно — отдельного шага для запуска нет. С этого момента пользователи, соответствующие сегменту, начнут получать кампанию, как только произойдёт триггерное событие.

:::note
В один триггер можно добавить несколько строк — каждая со своим сегментом и кампанией. Adapty Mail проверяет их сверху вниз и использует первый подходящий сегмент. Держите **All Users** последним — Adapty Mail не сохранит флоу, если он стоит в другом месте.
:::

:::tip

## 9. Начните отправку \{#9-start-sending\}

Кампания настроена, но пока не запущена — данные пользователей ещё не поступают в Adapty Mail. Запустите поток данных через [точку входа, которую вы выбрали](#2-connect-your-data). Наличие связи вашего проекта с Adapty (шаг 1) меняет лишь *то, как* вы включаете фид Adapty, но не то, что в него поступает:

| Откуда берутся данные | Ваш Mail-проект связан с приложением Adapty | Что делать |
| --- | --- | --- |
| [SDK Adapty](mail-collect-emails#5-enable-sending) | Да | В Adapty Mail перейдите в **Settings** > **Project** и нажмите **Enable Adapty integration**. Кнопка остаётся неактивной, пока у вас нет флоу (шаг 8). |
| [SDK Adapty](mail-collect-emails#5-enable-sending) | Нет | Adapty может передавать данные в проект, с которым не связан, — для этого нужен только ключ. Скопируйте секретный ключ из **Settings** > **Project** и вставьте его в дашборде Adapty в разделе **Integrations** > **Adapty Mail**. |
| Ваш бэкенд через [Adapty Mail API](mail-send-data-via-api) | Любой | Начните отправлять профили и события транзакций. Профили, отправленные до завершения этой настройки, не получат ни одного письма — именно поэтому данный шаг идёт последним. |
| [FunnelFox](mail-funnelfox) | Любой | Скопируйте секретный ключ из **Settings** > **Project** и вставьте его в FunnelFox в разделе **Integrations** > **Adapty Mail**. Данные начнут поступать примерно через минуту. |

Как только пользователь попадает в сегмент, он получает кампанию в момент срабатывания триггера. Прежде чем запустить кампанию для реальных пользователей, [протестируйте всю цепочку](mail-testing) на одном тестовом пользователе.

## Устранение неполадок \{#troubleshooting\}

| Проблема                                               | Решение                                                                                                                                                                     |
| ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Generate emails** недоступна (серая)                 | Не указан адрес бренда или компании. Подсказка кнопки покажет, какой именно. См. [Шаг 3](#3-set-up-your-brand) и [Шаг 5](#5-add-your-company-address)                       |
| Генерация пейвола заблокирована                        | Панель укажет причину: нет бренда, не подключён аккаунт Stripe или нет продуктов Stripe с ценами. Устраните проблему, затем нажмите **Refresh** для обновления чеклиста      |
| Кампания не сохраняется                                | Каждой кампании нужен веб-пейвол. Создайте его на [Шаге 6](#6-create-a-web-paywall)                                                                                           |
| **Enable Adapty integration** недоступна (серая)       | Для Adapty Mail нужен хотя бы один флоу. См. [Шаг 8](#8-launch-a-flow)                                                                                                      |
| DNS-записи не проходят проверку                        | Убедитесь, что они введены точно — без завершающих точек, правильные CNAME-цели, одно значение на запись. Распространение DNS может занять до 48 часов                       |
| Истёк срок окна верификации                            | Добавьте домен повторно в **Settings** > **DNS**, чтобы открыть новое окно. Записи у вашего регистратора остаются прежними — повторно добавлять их не нужно                  |
| Превышено время ожидания при генерации писем           | Генерация останавливается через 5 минут. Повторите попытку; если ошибка повторяется, обратитесь в поддержку Adapty                                                           |

По ошибкам вне начальной настройки смотрите разделы по устранению неполадок в [Настройка домена отправки](mail-sending-domain#troubleshooting) и [Настройка оформления заказа](mail-checkout#troubleshooting).
