Если ваш бэкенд должен сохранить свой URL в App Store Connect, передавайте серверные уведомления App Store из вашего бэкенда в Adapty без изменений. Если бэкенду не нужен собственный URL в App Store Connect, [настройте пересылку на ваш бэкенд в Adapty](enable-app-store-server-notifications#raw-events-forwarding) — этот вариант не требует кода.

Adapty обрабатывает уведомления, поступающие с вашего бэкенда, так же, как если бы их отправила Apple напрямую. С [Refund Saver](refund-saver) Adapty по-прежнему отвечает на запросы возврата средств среди этих уведомлений.

Если ваш бэкенд получает уведомления о реальном времени от Google Play через собственный топик Pub/Sub, никаких доработок для передачи их в Adapty не требуется. [Добавьте push-подписку для Adapty к этому топику](enable-real-time-developer-notifications-rtdn#send-notifications-to-two-adapty-apps).

Чтобы передавать серверные уведомления App Store в Adapty:

1. В Adapty откройте приложение, которое подключаете: у каждого приложения Adapty есть собственный URL для уведомлений. Перейдите в [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). В разделе **App Store server notifications** скопируйте URL из поля **URL for App Store server notifications**.
2. В вашем бэкенде отправляйте каждое уведомление от Apple на скопированный URL. В каждом запросе:

   - Оставьте тело запроса от Apple без изменений: `{"signedPayload": "…"}`.
   - Укажите заголовок `Content-Type: application/json`.
   - Не добавляйте заголовок `Authorization`.

   Если Adapty также пересылает уведомления на ваш бэкенд, не отправляйте их обратно в Adapty.

func main() {

	req, err := http.NewRequest(method, url, payload)

		fmt.Println("Error creating request:", err)
		return
	}
	req.Header.Add("Content-Type", "application/json")

	res, err := client.Do(req)
	if err != nil {
		fmt.Println("Error sending request:", err)
		return
	}
	defer res.Body.Close()
}

Ответ `200` не подтверждает, что Adapty смог использовать уведомление. Adapty отвечает до того, как декодирует подписанный payload. Чтобы убедиться, что уведомления доходят до Adapty, совершите [покупку в песочнице](test-purchases-in-sandbox). Затем проверьте, что [статус уведомлений](enable-app-store-server-notifications#check-that-notifications-reach-adapty) в разделе **App Store server notifications** отображается как **Active**.
