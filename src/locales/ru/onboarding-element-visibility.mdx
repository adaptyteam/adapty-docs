Вы можете управлять отображением элемента, добавив к нему условие. Условный элемент виден только тем пользователям, которые соответствуют заданным критериям.

Условие также может оценивать [состояние другого элемента](element-states-in-conditions). Например, можно показывать подсказку только тогда, когда кнопка находится в состоянии **Disabled**.

:::important
Если вы показываете или скрываете элемент с помощью действий **Show element** или **Hide element** ([действие](onboarding-actions)), это действие переопределяет условие **Visibility**, установленное для данного элемента. Переопределение действует до тех пор, пока переменная или состояние элемента в условии не будут обновлены.

Для элемента с условием **Visibility** эти действия изменяют элемент мгновенно, [без анимации и задержки](flow-show-hide-animations#when-animation-and-delay-dont-apply).

Используйте условия **Visibility** для элементов, которые должны отображаться или скрываться в зависимости от критерия, например ответа в квизе. Используйте действия, когда видимость должна меняться в конкретный момент, например [когда открывается экран или пользователь нажимает на элемент](flow-show-hide-animations#show-or-hide-an-element).
:::

Чтобы добавить условие к элементу:

1. Выберите элемент на холсте или в панели слоёв.
2. В разделе **Visibility** правой панели выберите **Conditional**.

<ZoomImage id="flow-conditional-visibility.webp" width="500px" alt="Настройки условной видимости" />

3. Чтобы задать условие, выберите тип свойства на одной из следующих вкладок:
   - **Custom**: Переменные, которые вы создаёте и которыми управляете; их значения можно обновлять через действия пользователя. Подробнее — в разделе [Variables](onboarding-variables).
   - **Product**: Свойства продуктов в вашем флоу, например цена или название.
   - **Elements**: Переменные других элементов, например ответ на вопрос квиза или состояние переключателя.
   - **States**: [Состояние другого элемента](element-states-in-conditions) на экране, например кнопка в состоянии **Disabled**.
   - **System**: Платформа устройства пользователя, `system.platform`. См. [Показывать элемент только на одной платформе](#show-an-element-on-one-platform-only).
4. Введите **Value** для сопоставления.
5. Нажмите на оператор, чтобы изменить его при необходимости.
6. (Опционально) Нажмите **Add condition**, чтобы добавить дополнительные условия. С помощью селектора укажите, должны ли выполняться все условия одновременно или достаточно любого одного.

## Показ элемента только на одной платформе \{#show-an-element-on-one-platform-only\}

Чтобы использовать один флоу для iOS и Android, показывайте платформозависимые элементы только на нужной платформе. Например, «Управляйте подпиской в настройках App Store» — на iOS, а «Управляйте подпиской в Google Play» — на Android.

1. Выберите элемент и в разделе **Visibility** выберите **Conditional**.
2. Нажмите на поле **Variable**, откройте вкладку **System** и выберите `system.platform`.
3. В выпадающем списке значений выберите **iOS** или **Android**. При условии `=` элемент будет показан только на этой платформе. При условии `!=` — только на другой платформе.

<ZoomImage id="flow-condition-system-platform.webp" width="500px" alt="Show element if editor with the System tab open and system.platform selected" />

SDK Adapty передаёт информацию о платформе автоматически — приложению не нужно её передавать. Android-устройства, включая устройства Huawei, соответствуют **Android**.

На холсте элемент отображается, если условие соответствует платформе [устройства предпросмотра](paywall-device-compatibility-preview#preview-in-the-adapty-dashboard). Чтобы посмотреть другую платформу, выберите устройство этой платформы в настройках предпросмотра.

Чтобы показать целый экран только на одной платформе, используйте [условное действие](onboarding-actions#show-a-screen-on-one-platform-only).
