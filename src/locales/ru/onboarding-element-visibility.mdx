Вы можете управлять отображением элемента, добавив к нему условие. Элемент с условием виден только тем пользователям, которые соответствуют заданным критериям.

:::important
Если вы показываете или скрываете элемент с помощью действий **Show element** или **Hide element** ([действие](onboarding-actions)), это действие переопределяет условие **Visibility**, установленное для данного элемента. Переопределение действует до тех пор, пока переменная или состояние элемента в условии не будут обновлены.

Для элемента с условием **Visibility** эти действия изменяют элемент мгновенно, [без анимации и задержки](flow-show-hide-animations#when-animation-and-delay-dont-apply).

Используйте условия **Visibility** для элементов, которые должны отображаться или скрываться в зависимости от критерия, например ответа в квизе. Используйте действия, когда видимость должна меняться в конкретный момент, например [когда открывается экран или пользователь нажимает на элемент](flow-show-hide-animations#show-or-hide-an-element).
:::

Чтобы добавить условие к элементу:

1. Выберите элемент на холсте или в панели слоёв.
2. В разделе **Visibility** правой панели выберите **Conditional**.

<ZoomImage id="flow-conditional-visibility.webp" width="500px" alt="Настройки условной видимости" />

3. Настройте условие, выбрав тип свойства на одной из трёх вкладок:
   - **Custom**: переменные, которые вы создаёте и которыми управляете; их значения можно обновлять через действия пользователя. Подробнее — в разделе [Variables](onboarding-variables).
   - **Products**: свойства продуктов в вашем флоу, например цена или название.
   - **Elements**: состояния других элементов флоу, например активен ли переключатель триала.
4. Введите **Value** для сравнения.
5. При необходимости нажмите на оператор, чтобы изменить его.
6. (Опционально) Нажмите **Add condition**, чтобы добавить ещё условия. С помощью селектора укажите, должны ли выполняться все условия сразу или достаточно любого одного.
