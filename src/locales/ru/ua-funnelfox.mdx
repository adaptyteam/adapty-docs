[FunnelFox](https://funnelfox.com) — это веб2app платформа для воронок, которая позволяет привлекать пользователей и принимать от них оплату за пределами App Store, минуя его комиссию и другие ограничения.

Настройте эту интеграцию, чтобы передавать данные о покупках FunnelFox в Adapty. Adapty сопоставит ваш веб-доход с расходами на рекламу, и вы сможете видеть, сколько принесла каждая кампания, группа объявлений и отдельное объявление.

## Как это работает \{#how-it-works\}

Когда пользователь совершает покупку в вашем фаннеле FunnelFox, FunnelFox отправляет событие транзакции в Adapty Attribution. Adapty использует **Project ID** для определения приложения, которому принадлежит транзакция. Событие сохраняется и отображается в аналитике Adapty Attribution.

После запуска интеграции каждая транзакция в Adapty включает:

- **События жизненного цикла подписки**: начало, продление, отмена, конвертация триала, возврат средств и другие
- **Канал атрибуции**: Facebook, TikTok, Google или органика. Adapty определяет его по идентификатору клика, который рекламные сети добавляют автоматически — никаких настроек с вашей стороны не требуется.
- **Данные атрибуции**: идентификаторы кампании, группы объявлений и объявления; UTM-параметры; идентификаторы кликов платформ (fbclid, ttclid, gclid). Данные о кампании, группе объявлений и объявлении поступают только при наличии в ваших рекламных материалах [параметров отслеживания Adapty](#step-3-tag-your-ad-urls).
- **Данные воронок и экспериментов**: название воронки и название эксперимента в FunnelFox, что позволяет сравнивать варианты A/B-тестов
- **Дата когорты**: дата первого старта триала или покупки. У веб-покупок нет события установки приложения, поэтому Adapty распределяет их по когортам именно по этой дате.

## Настройка интеграции \{#configure-integration\}

:::note
Веб-пиксель Adapty на воронке FunnelFox не нужен — FunnelFox сам передаёт данные о покупках в Adapty.
:::

### Шаг 1. Получите Project ID в FunnelFox \{#step-1-get-your-project-id-in-funnelfox\}

1. В дашборде FunnelFox нажмите **Settings** в левой боковой панели.
2. В разделе **Project info** скопируйте значение **ID**.

<ZoomImage id="ff-project-id.webp" width="500px" />

### Шаг 2. Добавьте проект в Adapty Attribution

1. В Adapty Attribution перейдите в [**Integrations > FunnelFox**](https://app.adapty.io/ua/integrations/funnelfox).
2. Вставьте Project ID, скопированный из FunnelFox.
3. Нажмите **Save**.

Чтобы подключить дополнительные проекты FunnelFox, нажмите **Add project** и повторите этот шаг для каждого из них.

<ZoomImage id="ua-funnelfox.webp" width="500px" />

### Шаг 3. Добавьте теги к URL ваших объявлений \{#step-3-tag-your-ad-urls\}

FunnelFox передаёт только те данные кампании, которые содержатся в URL целевой страницы — и считывает этот URL в момент первого посещения, а не при оформлении заказа. Добавьте параметры отслеживания Adapty к вашим объявлениям, как описано в разделе [Добавление тегов к URL объявлений для веб-воронок](ua-tag-ad-urls).

### Шаг 4. Включите атрибуцию кампаний в FunnelFox

:::note
По умолчанию эта настройка отключена, и FunnelFox не восстанавливает данные задним числом: транзакции, совершённые до её включения, в Adapty не попадут.
:::

1. В FunnelFox перейдите в [**Integrations > Adapty**](https://app.funnelfox.com/integrations/adapty).
2. Включите **Campaign attribution**.

Включите это для каждого проекта FunnelFox, который вы подключили.

Ваш проект FunnelFox должен принадлежать организации, а рекламные аккаунты — быть подключены в Adapty.

Описание событий, которые FunnelFox передаёт через этот канал, см. в разделе [Интеграция с Adapty](https://funnelfox.com/docs/integrations/subscription-management/adapty#campaign-attribution) документации FunnelFox.
