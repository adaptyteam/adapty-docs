В режиме Observer mode SDK не может самостоятельно отслеживать покупки, сделанные через вашу существующую систему покупок. Вам нужно передавать транзакции из стора вручную. Важно настроить это **до** выпуска приложения, чтобы избежать ошибок в аналитике.

Используйте `reportTransaction`, чтобы явно сообщать Adapty о каждой транзакции.

:::warning

**Не пропускайте отчёт о транзакции!**
Если вы не вызовете `reportTransaction`, Adapty не распознает транзакцию, она не появится в аналитике и не будет передана в интеграции.

:::

Если вы используете флоу и пейволы Adapty, передавайте `variationId` при отчёте о транзакции. Это связывает покупку с флоу или пейволом, который её инициировал, и обеспечивает точность аналитики.

```swift showLineNumbers
do {
    // every time when calling transasction.finish()
    try await Adapty.reportTransaction(transaction, withVariationId: <YOUR_PAYWALL_VARIATION_ID>)
} catch {
    // handle the error
}
```

Параметры:

| Параметр        | Наличие  | Описание                                                     |
| --------------- | -------- | ------------------------------------------------------------ |
| **transaction** | обязательный | <ul><li> Для StoreKit 1: SKPaymentTransaction.</li><li> Для StoreKit 2: Transaction.</li></ul> |
| **variationId** | необязательный | Уникальный ID варианта пейвола. Получите его из свойства `variationId` объекта `AdaptyPaywall`. |

**Reporting transactions**

- Версии до 3.1.x автоматически отслеживают транзакции в App Store, поэтому вручную сообщать о них не нужно.
- Версия 3.2 не поддерживает Observer Mode.

**Привязка флоу и пейволов к транзакциям**

Adapty SDK не может определить источник покупок, поскольку вы самостоятельно их обрабатываете. Поэтому, если вы планируете использовать флоу, пейволы и/или A/B-тесты в режиме Observer, вам необходимо связать транзакцию из стора с соответствующим флоу или пейволом в коде мобильного приложения. Важно сделать это правильно до выпуска приложения, иначе это приведёт к ошибкам в аналитике.

```swift 
let variationId = paywall.variationId
// There are two overloads: for StoreKit 1 and StoreKit 2
Adapty.setVariationId(variationId, forPurchasedTransaction: transactionId) { error in
    if error == nil {
        // successful binding
    }    
}
```

Параметры запроса:

| Параметр      | Наличие  | Описание                                                     |
| ------------- | -------- | ------------------------------------------------------------ |
| variationId   | required | Строковый идентификатор варианта. Его можно получить через свойство `variationId` объекта `AdaptyPaywall`. |
| transactionId | required | <p>Для StoreKit 1: объект [SKPaymentTransaction](https://developer.apple.com/documentation/storekit/skpaymenttransaction).</p><p>Для StoreKit 2: объект [Transaction](https://developer.apple.com/documentation/storekit/transaction).</p> |
