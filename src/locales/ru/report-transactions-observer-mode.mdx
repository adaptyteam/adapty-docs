<SDKv4>

В режиме Observer Adapty SDK не может самостоятельно отслеживать покупки, совершённые через вашу существующую систему покупок. Вам нужно передавать транзакции из стора. Важно настроить это **до** релиза приложения, чтобы избежать ошибок в аналитике.

Используйте `reportTransaction`, чтобы явно сообщать Adapty о каждой транзакции.

:::warning

**Не пропускайте передачу транзакций!**
Если вы не вызовете `reportTransaction`, Adapty не распознает транзакцию, она не появится в аналитике и не будет отправлена в интеграции.

:::

Если вы используете флоу и пейволы Adapty, передавайте `variationId` при отчёте о транзакции. Это связывает покупку с флоу или пейволом, который её инициировал, и обеспечивает точную аналитику.

:::warning
Передавайте `variationId` продукта `AdaptyPaywallProduct`, который купил пользователь, а не `AdaptyFlow.variationId`. Собственный variation ID флоу не связывает покупку с флоу.
:::

```swift showLineNumbers
do {
    // every time when calling transaction.finish()
    // verificationResult is the VerificationResult<Transaction> StoreKit 2 returns
    try await Adapty.reportTransaction(verificationResult, withVariationId: <YOUR_PAYWALL_VARIATION_ID>)
} catch {
    // handle the error
}
```

Параметры:

| Параметр        | Наличие  | Описание                                                     |
| --------------- | -------- | ------------------------------------------------------------ |
| **transaction** | required | `VerificationResult<Transaction>` — результат StoreKit 2 до его распаковки. Adapty отправляет подписанную транзакцию на сервер. Перегрузка, принимающая голый `Transaction`, устарела начиная с SDK 4.3.2. |
| **variationId** | optional | Уникальный ID варианта пейвола. Передайте `variationId` продукта `AdaptyPaywallProduct`, который купил пользователь. Это то же значение, что и `variationId` объекта `AdaptyFlowPaywall`, содержащего данный продукт. |

</SDKv4>

**Reporting transactions**

- Версии до 3.1.x автоматически отслеживают транзакции в App Store, поэтому вручную сообщать о них не нужно.
- Версия 3.2 не поддерживает Observer Mode.

**Привязка флоу и пейволов к транзакциям**

Adapty SDK не может определить источник покупок, поскольку вы самостоятельно их обрабатываете. Поэтому, если вы планируете использовать флоу, пейволы и/или A/B-тесты в режиме Observer, вам необходимо связать транзакцию из стора с соответствующим флоу или пейволом в коде мобильного приложения. Важно сделать это правильно до выпуска приложения, иначе это приведёт к ошибкам в аналитике.

```swift 
let variationId = paywall.variationId
// There are two overloads: for StoreKit 1 and StoreKit 2
Adapty.setVariationId(variationId, forPurchasedTransaction: transactionId) { error in
    if error == nil {
        // successful binding
    }    
}
```

Параметры запроса:

| Параметр      | Наличие  | Описание                                                     |
| ------------- | -------- | ------------------------------------------------------------ |
| variationId   | required | Строковый идентификатор варианта. Его можно получить через свойство `variationId` объекта `AdaptyPaywall`. |
| transactionId | required | <p>Для StoreKit 1: объект [SKPaymentTransaction](https://developer.apple.com/documentation/storekit/skpaymenttransaction).</p><p>Для StoreKit 2: объект [Transaction](https://developer.apple.com/documentation/storekit/transaction).</p> |
