Это обзор метрик, доступных в аналитике Adapty Attribution. Используйте его, чтобы понять, что измеряет каждая метрика и как Adapty её рассчитывает. Для аналитики подписок, генерируемой Adapty Core, используйте [таблицу сравнения метрик](metric-comparison-table).

:::note
Веб-покупки не имеют события установки приложения. Adapty включает их в когорты по дате первого пробного периода или покупки.
:::

## Метрики событий \{#event-metrics\}

Метрики событий считают события подписки и покупки пользователей, установивших приложение в выбранном диапазоне дат. Для каждого события доступны две метрики:

- **Count**: Количество раз, когда произошло событие.
- **Rate**: Количество в виде процента от установок. **Формула**: `(Count / Installs) × 100%`

Все метрики событий можно добавить с периодом когорты или без него.

| Событие | Метрика количества | Метрика доли |
|---|---|---|
| Пользователи оформили платную подписку без пробного периода. | **Subscriptions started** | **Rate subscription started** |
| Подписки продлились. | **Subscription renewed** | **Rate subscription renewed** |
| Пользователи отключили автопродление подписки. | **Subscription renewal cancelled** | **Rate subscription renewal cancelle** |
| Пользователи снова включили автопродление подписки. | **Subscription renewal reactivated** | **Rate subscription renewal reactivated** |
| Подписки завершились без продления. | **Subscription expired** | **Rate subscription expired** |
| Пользователи приостановили подписку на Android. | **Subscription paused** | **Rate subscription paused** |
| Бэкенд приложения [отложил платёж](https://adapty.io/glossary/subscription-purchase-deferral/) по подписке Google Play. | **Subscription deferred count** | **Rate subscription deferred** |
| Стор вернул оплату за подписку. | **Subscription refunded** | **Rate subscription refunded** |
| Пользователи оспорили платёж за подписку через банк. | **Subscription chargeback** | **Rate subscription chargeback** |
| Банк вернул вам оспоренный платёж за подписку. | **Subscription chargeback reversed** | **Rate subscription chargeback reversed** |
| Пользователи активировали бесплатный пробный период. | **Trial started** | **Rate trial started** |
| Пробные периоды конвертировались в платные подписки. | **Trial converted** | **Rate trial converted** |
| Пользователи отключили автопродление во время пробного периода. | **Trial renewal cancelled** | **Rate trial renewal cancelled** |
| Пользователи снова включили автопродление во время пробного периода. | **Trial renewal reactivated** | **Rate trial renewal reactivated** |
| Пробные периоды завершились без конвертации в платные подписки. | **Trial expired** | **Rate trial expired** |
| Стор не смог списать средства с пользователя, например из-за недостатка средств. | **Billing issue detected** | **Rate billing issue detected** |
| Подписки вошли в льготный период из-за проблем с оплатой. | **Entered grace period** | **Rate entered grace period** |
| Пользователи совершили разовую покупку. | **Non-subscription purchase** | **Rate non-subscription purchase** |
| Стор вернул оплату за разовую покупку. | **Non-subscription purchase refunded** | **Rate non-subscription purchase refunded** |
| Пользователи оспорили платёж за разовую покупку через банк. | **Non-subscription purchase chargeback** | **Rate non-subscription purchase chargeback** |
| Банк вернул вам оспоренный платёж за разовую покупку. | **Non-subscription purchase chargeback reversed** | **Rate non-subscription purchase chargeback reversed** |

## Метрики Google Ads \{#google-ads-metrics\}

Google Ads сам предоставляет эти метрики, поэтому они доступны только в строках Google Ads. В строках других сетей отображается «—». Чтобы добавить большинство этих столбцов в таблицу за один шаг, выберите [пресет Google Ads](ua-analytics#google-ads-preset).

| **Метрика** | Описание | Когорта |
|---|---|---|
| **Conversions (Network)** | Конверсии, которые Google Ads засчитывает для действий-конверсий в вашем аккаунте Google Ads, по дате клика. Это цифры Google, а не триалы или покупки Adapty, поэтому они не совпадают. | Нет |
| **All Conv. (Network)** | Все конверсии, которые засчитывает Google Ads, по дате клика. Google Ads отображает это число в столбце **All conv.** | Нет |
| **Cost per Conversion (Network)** | Средние расходы на одну конверсию по данным Google Ads. Учитываются только расходы по строкам, в которых зафиксированы конверсии. <br/>**Формула**: `Spend / Conversions (Network)` | Нет |
| **First Page Bid Est.** | Оценка Google минимальной ставки, необходимой для показа объявления на первой странице результатов поиска. | Нет |
| **First Position Bid Est.** | Оценка Google минимальной ставки, необходимой для показа объявления на первой позиции на первой странице результатов поиска. | Нет |
| **Status** | Статус кампании, группы объявлений, объявления или ключевого слова в Google Ads: **Enabled**, **Paused** или **Removed**. | Нет |

### Конверсии \{#conversions\}

Adapty обновляет конверсии за каждый день в течение 3 дней, после чего данные фиксируются. Google Ads продолжает добавлять запоздалые конверсии к прошлым датам кликов, поэтому для более старых дней количество конверсий в Adapty может быть меньше, чем в Google Ads. Adapty не импортирует конверсии за дни, предшествующие началу сбора данных, — для таких дней отображается «—».

### Оценки ставок \{#bid-estimates\}

Два столбца с оценками ставок появляются в таблице только при группировке по ключевым словам. Для каждого ключевого слова Adapty показывает оценку Google за последний день с трафиком в выбранном диапазоне дат.

Google не предоставляет оценки ставок для ключевых слов Display и App. Также оценки недоступны для ключевых слов Search в кампаниях с автоматическим управлением ставками, например **Maximize clicks**, **Maximize conversions** или **Target CPA**. Для таких ключевых слов отображается «—».

### Статус \{#status\}

Adapty обновляет статусы раз в день. Строка отображает статус при одновременном выполнении двух условий:

- Таблица сгруппирована по кампании, группе объявлений, объявлению или ключевому слову.
- У строки есть расходы в Google Ads за выбранный период.

Если несколько кампаний Google Ads имеют одинаковое название, в строке отображается **Enabled**, если хотя бы одна из них активна. В противном случае отображается **Paused**, если хотя бы одна из них приостановлена, и **Removed**, если все они удалены.

## Прогнозируемые метрики \{#predicted-metrics\}

Прогнозируемые метрики проецируют будущую эффективность когорты на основе исторических данных самого приложения, поэтому они охватывают в том числе органические установки. Они доступны для нескольких периодов когорты: D30, D60, D90, D180 и D360, а также для пользовательских периодов, которые можно добавить в днях. О том, как рассчитываются эти значения, читайте в разделе [Прогнозируемые метрики в Adapty Attribution](ua-predicted-metrics).

| **Метрика**   | Описание                                                                                                                                                                                   | <InlineTooltip tooltip="Поддержка когорт">Период когорты ограничивает метрику определённым количеством дней после установки, например 7 дней для D7 ROAS.</InlineTooltip> |
|---------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---:|
| **pRevenue**  | Прогнозируемая общая выручка, которую когорта ожидаемо принесёт к целевому горизонту. Рассчитывается на основе исторического удержания когорт приложения.                                  | Только когорты |
| **pROAS**     | Прогнозируемый возврат рекламных расходов за тот же горизонт. **Формула**: `(pRevenue / Spend) × 100%`. Adapty не рассчитывает значение для строк без расходов, например **Organic**.      | Только когорты |
| **pAdProfit** | Прогнозируемая выручка за вычетом рекламных расходов за горизонт. **Формула**: `pRevenue − Spend`                                                                                          | Только когорты |
| **pARPU**     | Прогнозируемая средняя выручка на установку за горизонт (прогнозируемый LTV). **Формула**: `pRevenue / Installs`                                                                           | Только когорты |
| **pARPPU**    | Прогнозируемая средняя выручка на платящего пользователя за горизонт. **Формула**: `pRevenue / paying users at d{N}`, где `d{N}` соответствует выбранному горизонту.                       | Только когорты |
