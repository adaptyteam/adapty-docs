Кастомный тег — это [кастомная переменная](onboarding-variables#custom-variables), значение которой берётся из вашего приложения. После того как вы выберете **Value comes from outside the app** в настройках переменной, приложение может задать её значение через Adapty SDK. Например, текстовый элемент содержит «Coins:» и кастомный тег. Если приложение передаёт «120» для этого тега, пользователи видят «Coins: 120».

Используйте кастомные теги, чтобы показывать:

- **Кто это за пользователь**: имя пользователя в приветствии, например «С возвращением, DragonSlayer42!»
- **Что есть у пользователя**: количество дней в серии или уровень игрока.
- **Что вычисляет ваше приложение**: скидка на большой пакет или [ИМТ](ios-flow-custom-tags#example-show-a-bmi-from-onboarding-answers), рассчитанный на основе ответов пользователя в предыдущем флоу.

## Значения и резервные данные \{#values-and-fallbacks\}

Ваше приложение определяет каждое значение по имени кастомного тега. Значение всегда является строкой. Adapty не форматирует и не переводит строку, поэтому приложение должно самостоятельно сделать каждое значение читаемым для пользователя перед отображением во флоу. Например, передавайте "1,250", а не "1250.0".

## 1. Создайте пользовательский тег \{#create-a-custom-tag\}

1. Откройте панель <Inline id="variables.svg" alt="Variables" /> Variables во флоу-билдере.
2. Добавьте новую переменную — нажмите <Inline id="plus.svg" alt="Plus" />.
3. Задайте **Name** переменной. Код приложения должен ссылаться на неё именно так, включая регистр букв.
   - **Символы**: используйте латинские буквы (A–Z и a–z), цифры, `_` и `-`. Чтобы поместить тег в группу, начните имя с названия группы и точки, например `user.streak`.
   - **Зарезервированные имена**: не используйте зарезервированные имена в любом регистре — например, `PRICE`, `TITLE`, `VALUE` или имена, начинающиеся с `TIMER_`.
   - **Уникальность**: имя должно быть уникальным в пределах флоу.
4. (Опционально) Чтобы различать переменные между собой, заполните поле **Description**. При наведении курсора на имя переменной в билдере вы увидите это описание.
5. В поле **Initial value** введите значение по умолчанию, которое пользователи увидят, если приложение не передаст никакого значения:
   - **Слово, подходящее любому пользователю**: для тега `username` в приветствии введите `friend`. Неаутентифицированные пользователи увидят «Welcome back, friend!». Обратите внимание, что начальное значение нельзя локализовать.
   - **Тире для баланса или счётчика**: чтобы не показывать некорректный баланс неаутентифицированным пользователям, введите тире (`—`).

6. (Только для переменных типа **String**) Установите флажок **Value comes from outside the app**. Это действие необратимо и фиксирует **Value Type**.
7. Нажмите **Create variable**.

<ZoomImage id="flow-custom-tag-create.webp" width="500px" alt="Create variable form with a name, a description, the String value type, and an initial value" />

Переменные привязаны к конкретному флоу. Чтобы использовать пользовательский тег в другом флоу, создайте его там с тем же именем.

### Замените переменную пользовательским тегом \{#replace-a-variable-with-a-custom-tag\}

Установить флажок **Value comes from outside the app** можно только при создании переменной. Чтобы отображать значение из приложения вместо обычной пользовательской переменной — например, из [конвертированного пейвола](convert-paywall-to-flow) — замените переменную пользовательским тегом:

1. Удалите переменную и все её упоминания во флоу.
2. [Создайте пользовательский тег](#create-a-custom-tag) с тем же именем.
3. [Вставьте пользовательский тег](#add-a-custom-tag-to-a-text-element) в каждый текстовый элемент, в котором использовалась переменная.

## 2. Добавьте пользовательский тег в текстовый элемент \{#add-a-custom-tag-to-a-text-element\}

Выберите текстовый элемент. В разделе **Content** нажмите <Inline id="variables.svg" alt="Variables" /> **Add variable** и выберите тег на вкладке **Custom**.

<ZoomImage id="flow-custom-tag-full-name.webp" width="500px" alt="Custom tab of the Add variable dropdown with the streak tag in the user group" />

## 3. Передайте значения из вашего приложения \{#pass-the-values-from-your-app\}

В коде приложения нужно использовать точное имя каждого кастомного тега, включая его группу. Например, если в группе `user` есть тег `streak`, полное имя тега — `user.streak`.

## Ограничения \{#limitations\}

- **Только текстовые элементы**: Пользовательские теги можно вставлять только в текстовые элементы. Следующие элементы не поддерживаются:
  - Действия **Set variable**
  - Действия **Show alert**
  - Действия **Open URL**
  - Плейсхолдеры полей ввода
- **Условия на пользовательские теги недоступны**: Нельзя использовать пользовательский тег в условии или условной видимости. Чтобы показывать нужные фразы, элементы и экраны в зависимости от значения из приложения:
  - **Фраза**: Сформируйте её в коде приложения и передайте как значение тега. Например, для тега `coins_message` передайте «У вас 120 монет» игрокам с монетами и «Получите первые монеты» остальным.
  - **Элементы и экраны**: [Сохраните значение как пользовательский атрибут](setting-user-attributes). Затем покажите отдельный флоу [аудитории](audience), построенной на основе этого атрибута.
- **Метода SDK для обновления значений в открытом флоу нет**: Чтобы показать результат на основе того, что пользователь ввёл во флоу, передайте результат в следующий флоу — как в [примере с BMI](ios-flow-custom-tags#example-show-a-bmi-from-onboarding-answers).
