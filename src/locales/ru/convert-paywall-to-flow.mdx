Если ваш текущий пейвол создан в устаревшем Paywall Builder, его можно конвертировать во флоу. Действие **Move to new builder** в один клик воссоздаёт пейвол как редактируемый черновик флоу.

При конвертации копируется:

- **Макет и дизайн**: экраны, элементы и стили оригинального пейвола.
- **Текст**: весь контент на каждой добавленной вами локали.
- **Продукты**: каждый продукт с ценами и скидками в виде переменных, а не жёстко заданных значений.

Оригинальный пейвол остаётся активным и неизменным, так что вы можете настраивать и тестировать флоу до переключения. Что не переносится при конвертации — это привязка пейвола к плейсменту: флоу является отдельным типом контента, поэтому ему нужен [собственный плейсмент для флоу](#serve-your-flow).

:::warning
Некоторые функции устаревшего Paywall Builder не имеют аналогов во флоу, поэтому конвертированный пейвол может не совпадать с оригиналом в точности. Панель [Import review](#import-review) проведёт вас через каждое отличие и объяснит, как его исправить.
:::

## Конвертируйте пейвол \{#convert-your-paywall\}

Чтобы конвертировать пейвол во флоу, откройте страницу обзора пейвола и нажмите **Move to new builder**. Эта кнопка отображается только для пейволов, созданных с помощью устаревшего Paywall Builder.

<ZoomImage id="move-to-new-builder.webp" width="700px" alt="Кнопка Move to new builder в строке действий пейвола" />

Adapty откроет черновик флоу в редакторе, где вы сможете отредактировать его перед публикацией. Если что-то перенеслось не точно, билдер запустит [проверку импорта](#import-review).

<ZoomImage id="paywall-imported-toast.webp" width="500px" alt="Уведомление об импорте пейвола в редакторе флоу после конвертации" />

## Проверка импорта \{#import-review\}

Панель **Import review** содержит список всего, что конвертация не смогла воспроизвести точно, и предлагает решение для каждого несоответствия.

<ZoomImage id="import-review.webp" width="500px" alt="Import review panel listing what the conversion couldn't reproduce exactly, with a checkbox for each item" />

Разберите каждый пункт в панели, затем [проверьте флоу на реальном устройстве](migrate-to-flows#preview-on-device) перед публикацией.

## Запустите свой флоу \{#serve-your-flow\}

:::link
Основная статья: [Миграция на флоу](migrate-to-flows)
:::

Конвертированный флоу начинает как черновик и не заменяет плейсмент, на котором работает исходный пейвол. Чтобы показать его пользователям:

1. [Опубликуйте флоу](builder-save-publish).
2. Создайте новый плейсмент для флоу и добавьте в него флоу.
3. Запросите этот плейсмент флоу в приложении с помощью Adapty SDK v4.

:::warning
Флоу нельзя разместить на плейсменте пейвола, и он не может использовать ID плейсмента пейвола. Флоу и пейволы — это разные типы контента, каждый из которых привязан к своему типу плейсмента, а тип плейсмента фиксируется при создании. ID плейсментов уникальны в рамках всего приложения, поэтому новому плейсменту для флоу нужен ID, который не используется ни в одном другом плейсменте — включая тот пейвол, который этот флоу заменяет. См. [Создание нового плейсмента для флоу](migrate-to-flows#create-a-new-placement-for-your-flow).
:::

Сохраняйте плейсмент пейвола активным, пока старые версии приложения всё ещё к нему обращаются — у таких пользователей его ID вшит в приложение, и они не смогут попасть во флоу, пока не обновятся.
