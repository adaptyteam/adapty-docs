Если ваш текущий пейвол создан в устаревшем Paywall Builder, его можно конвертировать во флоу. Действие **Move to new builder** воссоздаёт пейвол как редактируемый черновик флоу — в один клик.

Конвертация копирует:

- **Макет и дизайн**: экраны, элементы и стили из исходного пейвола.
- **Текст**: весь контент на каждой добавленной локали.
- **Продукты**: каждый продукт с ценами и скидками в виде переменных, а не захардкоженных значений.
- **Кастомные теги**: конвертация создаёт обычную кастомную переменную для каждого кастомного тега пейвола. У каждой переменной есть имя тега и нет начального значения. Чтобы показывать значения из вашего приложения, [замените каждую переменную на кастомный тег](flow-custom-tags#replace-a-variable-with-a-custom-tag).

Оригинальный пейвол остаётся активным и неизменным, поэтому вы можете настраивать и тестировать флоу, не затрагивая его. Единственное, что не переносится при конвертации, — это плейсмент пейвола: флоу является отдельным типом контента, поэтому ему нужен [собственный плейсмент флоу](#serve-your-flow).

:::warning
Некоторые функции Legacy Paywall Builder не имеют аналогов во флоу, поэтому сконвертированный пейвол может не полностью совпадать с оригиналом. Панель [Import review](#import-review) подробно описывает каждое отличие и способы его устранения.
:::

## Конвертируйте ваш пейвол \{#convert-your-paywall\}

Чтобы конвертировать пейвол во флоу, откройте страницу обзора пейвола и нажмите **Move to new builder**. Эта кнопка появляется только для пейволов, созданных в Paywall Builder для Adapty SDK 3.x — конвертер использует конфигурацию именно этого билдера. Чтобы конвертировать более старый пейвол, сначала перенесите его в Paywall Builder для SDK 3.x.

<ZoomImage id="move-to-new-builder.webp" width="700px" alt="Move to new builder button in the paywall action row" />

Adapty открывает черновик флоу в редакторе, где вы можете отредактировать его перед публикацией. Если что-то перенеслось не совсем точно, билдер запустит [проверку импорта](#import-review).

<ZoomImage id="paywall-imported-toast.webp" width="500px" alt="Paywall imported toast in the flow editor after conversion" />

## Проверка импорта \{#import-review\}

Панель **Import review** содержит список всего, что не удалось воспроизвести при конвертации, и предлагает исправление для каждого несоответствия.

<ZoomImage id="import-review.webp" width="500px" alt="Import review panel listing what the conversion couldn't reproduce exactly, with a checkbox for each item" />

Просмотрите панель, затем [проверьте флоу на реальном устройстве](migrate-to-flows#preview-on-device) перед публикацией.

## Запуск флоу \{#serve-your-flow\}

:::link
Основная статья: [Миграция на флоу](migrate-to-flows)
:::

Сконвертированный флоу создаётся как черновик и не подключается автоматически к плейсменту, на котором работает исходный пейвол. Чтобы показать его пользователям:

1. [Опубликуйте флоу](builder-save-publish).
2. Создайте новый плейсмент для флоу и добавьте в него флоу.
3. Получите этот плейсмент в приложении с помощью Adapty SDK v4.

:::warning
Флоу нельзя разместить на плейсменте пейвола, и он не может использовать ID плейсмента пейвола. Флоу и пейволы — это разные типы контента, поэтому каждый живёт на своём типе плейсмента, а тип плейсмента фиксируется при его создании. ID плейсментов уникальны в рамках всего приложения, поэтому новому плейсменту для флоу нужен ID, который не используется ни одним другим плейсментом — включая пейвол, который этот флоу заменяет. См. [Создание нового плейсмента для флоу](migrate-to-flows#create-a-new-placement-for-your-flow).
:::

Оставьте плейсмент пейвола активным, пока старые версии приложения к нему обращаются — у таких пользователей его ID зашит в приложении, и они не смогут перейти к флоу без обновления.

## Конвертация нескольких пейволов за раз \{#convert-many-paywalls-at-once\}

**Move to new builder** конвертирует один пейвол, и каждый созданный флоу всё равно требует отдельного плейсмента. Когда вы переносите целое приложение, а не один пейвол, [скилл агента migrate-placements](migrate-placements-skill) перечисляет все плейсменты пейволов в вашем приложении, группирует их по пейволу, которому они соответствуют — чтобы вы понимали, сколько конвертаций вас ждёт, — сообщает, у каких пейволов уже есть флоу, и создаёт новые плейсменты для флоу после их публикации.

Конверсия клика остаётся за вами. Команды CLI для **Move to new builder** не существует, и панель [Import review](#import-review) вам нужно пройти самостоятельно — скилл ждёт, затем перечитывает ваш аккаунт и находит флоу, созданные в результате конверсии.
