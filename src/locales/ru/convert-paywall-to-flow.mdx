Если ваш текущий пейвол создан в устаревшем Paywall Builder, его можно конвертировать во флоу. Действие **Move to new builder** пересоздаёт пейвол как редактируемый черновик флоу — одним кликом.

При конвертации копируются:

- **Макет и дизайн**: экраны, элементы и стили из оригинального пейвола.
- **Текст**: все тексты на каждом добавленном вами языке.
- **Продукты**: каждый продукт с ценами и скидками в виде переменных, а не жёстко заданных значений.

Оригинальный пейвол остаётся активным и неизменным, так что вы можете настроить и протестировать флоу до переключения. Единственное, что не переносится при конвертации, — это плейсмент пейвола: флоу является другим типом контента, поэтому ему нужен [собственный плейсмент флоу](#serve-your-flow).

:::warning
Некоторые функции устаревшего Paywall Builder не имеют аналогов во флоу, поэтому конвертированный пейвол может не совпадать с оригиналом один в один. Панель [Import review](#import-review) покажет каждое расхождение и подскажет, как его устранить.
:::

## Конвертация пейвола \{#convert-your-paywall\}

Чтобы конвертировать пейвол во флоу, откройте страницу обзора пейвола и нажмите **Move to new builder**. Эта кнопка отображается только для пейволов, созданных в Paywall Builder для Adapty SDK 3.x — конвертеру нужна именно его конфигурация. Чтобы конвертировать более старый пейвол, сначала перенесите его в Paywall Builder для SDK 3.x.

<ZoomImage id="move-to-new-builder.webp" width="700px" alt="Кнопка Move to new builder в строке действий пейвола" />

Adapty открывает черновик флоу в редакторе, где его можно отредактировать перед публикацией. Если что-то не перенеслось точно, билдер запускает [Import review](#import-review).

<ZoomImage id="paywall-imported-toast.webp" width="500px" alt="Уведомление об импорте пейвола в редакторе флоу после конвертации" />

## Import review \{#import-review\}

Панель **Import review** перечисляет всё, что конвертация не смогла воспроизвести, и предлагает способ устранения каждого расхождения.

<ZoomImage id="import-review.webp" width="500px" alt="Панель Import review со списком того, что конвертация не смогла воспроизвести точно, с чекбоксом для каждого пункта" />

Пройдите по всем пунктам панели, затем [просмотрите флоу на реальном устройстве](migrate-to-flows#preview-on-device) перед публикацией.

## Подключение флоу к плейсменту \{#serve-your-flow\}

:::link
Основная статья: [Миграция на флоу](migrate-to-flows)
:::

Конвертированный флоу начинает как черновик и не замещает плейсмент, на котором работает оригинальный пейвол. Чтобы показать его пользователям:

1. [Опубликуйте флоу](builder-save-publish).
2. Создайте новый плейсмент флоу и добавьте в него флоу.
3. Запросите этот плейсмент флоу в приложении с помощью Adapty SDK v4.

:::warning
Флоу нельзя разместить на плейсменте пейвола и нельзя использовать ID плейсмента пейвола. Флоу и пейволы — разные типы контента, поэтому каждый из них существует на своём типе плейсмента, а тип плейсмента фиксируется при его создании. ID плейсментов уникальны в рамках всего приложения, поэтому новый плейсмент флоу должен иметь ID, который не используется ни одним другим плейсментом — включая пейвол, который этот флоу заменяет. См. [Создание нового плейсмента для флоу](migrate-to-flows#create-a-new-placement-for-your-flow).
:::

Не отключайте плейсмент пейвола, пока старые версии приложения всё ещё обращаются к нему — у этих пользователей его ID встроен в приложение, и они не смогут получить флоу до обновления.

## Конвертация нескольких пейволов сразу \{#convert-many-paywalls-at-once\}

**Move to new builder** конвертирует один пейвол, и каждый созданный таким образом флоу всё равно нуждается в собственном плейсменте. Когда вы переносите всё приложение, а не один пейвол, [скилл агента migrate-placements](migrate-placements-skill) перечисляет все плейсменты пейволов в вашем приложении, группирует их по обслуживаемому пейволу, чтобы вы понимали, сколько конвертаций вас ждёт, сообщает, у каких пейволов уже есть флоу, и создаёт новые плейсменты флоу после публикации флоу.

Сам клик для конвертации остаётся за вами. Для **Move to new builder** нет команды CLI, а панель [Import review](#import-review) тоже нужно пройти самостоятельно — скилл ждёт, затем повторно считывает ваш аккаунт и находит флоу, созданные при конвертации.
