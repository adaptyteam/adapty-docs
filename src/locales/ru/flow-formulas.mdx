Формула — это [пользовательская переменная](onboarding-variables#custom-variables) с вычисляемым значением: числом или датой. Формула может считывать ответы пользователей во флоу, другие пользовательские переменные, цены продуктов из каталога Adapty и текущую дату. С помощью формул в Flow & Paywall Builder флоу может отображать вычисленные значения без единой строки кода в приложении:

- **Результат на основе ответов**: сумма очков в тесте, ИМТ из веса и роста или рост в футах и дюймах.
- **Цена**: цена выбранного продукта со скидкой 20% или экономия при переходе с еженедельного плана на годовой.
- **Дата**: дата окончания бесплатного пробного периода.
- **Длительность**: продолжительность бесплатного пробного периода в днях или возраст пользователя по дате рождения.

Флоу вычисляет результат формулы на устройстве. Когда значение, которое читает формула, изменяется, флоу обновляет результат. Вы можете отображать результат в текстовом элементе и использовать его в условиях.

## Создание формулы \{#create-a-formula\}

1. Откройте панель <Inline id="variables.svg" alt="Variables" /> Variables в конструкторе флоу.
2. Добавьте новую переменную — нажмите <Inline id="plus.svg" alt="Plus" />.
3. Введите **Name** переменной, например `bmi`. Другие формулы используют это имя для чтения результата.
4. В выпадающем списке **Value Type** выберите **Formula**.
5. В поле **Expression** введите формулу, например `round({{weight}} * 10000 / ({{height}} * {{height}}), 1)`, где `weight` и `height` — числовые переменные. О правилах записи см. раздел [Написание формулы](#write-a-formula).
6. Нажмите **Create variable**.

<ZoomImage id="flow-formula-create.webp" width="300px" alt="Диалог создания переменной с типом Formula, формулой BMI в поле Expression, числовым типом выходных данных и предпросмотром значения 22.9" />

Когда вы покидаете поле **Expression**, конструктор проверяет формулу. Если в формуле есть ошибка, её текст отображается под полем. Пока ошибка отображается, кнопка **Create variable**, или **Save** для существующей переменной, недоступна. Когда вы редактируете выражение, ошибка исчезает и кнопка снова становится доступной.

Под полем конструктор показывает:

- **Output type**: **Number** или **Date** — тип результата. Билдер определяет его по формуле: результат имеет тип Date, если формула является [функцией даты](#date-functions), возвращающей дату, например `addDays`, или отдельным значением типа Date, например `{{trial_start}}`. Любая другая формула даёт Number, включая формулу, вычисляющую разницу между двумя датами, например `daysBetween`.
- **Date format**: Только для формулы типа Date. Определяет, как текстовые элементы отображают результат. См. [Показать дату в текстовом элементе](#show-a-date-in-a-text-element).
- **Preview**: Результат, вычисленный на основе начальных значений и цен продуктов. См. [Предварительный просмотр формулы в билдере](#preview-a-formula-in-the-builder).

Формула всегда зависит от других значений, поэтому у неё нет **Initial value**. По той же причине приложение не может задать формулу.

### Вставка ссылок и функций \{#insert-references-and-functions\}

Если вы не знаете точное имя переменной, введите `{{` в поле **Expression**. Откроется список переменных. Введите часть имени, чтобы отфильтровать список, и выберите переменную для вставки её ссылки. Список также открывается при вводе имени функции. Когда вы вводите пробел после числового значения, например `{{weight}}` или `5`, список предлагает операторы `+`, `-`, `*` и `/`. Чтобы закрыть список, нажмите Escape.

Список показывает только переменные и функции, которые подходят для позиции курсора. Например, в первом аргументе `addDays` список предложит значения типа Date, `today()` и функции, возвращающие дату. Во втором аргументе `round` список ничего не предложит, потому что количество знаков после запятой — это число, которое вы вводите вручную.

Поле **Expression** отображает каждую ссылку в виде чипа с именем переменной — например, **weight** для пользовательской переменной или **Weekly · prod_price** для цены продукта. Чип — единый объект: Backspace или Delete удаляет всю ссылку целиком, а клавиши со стрелками перемещают курсор мимо чипа.

Чтобы просмотреть все переменные, доступные формуле, или прочитать описание функции, воспользуйтесь двумя кнопками на строке **Output type**. Каждая кнопка вставляет текст в поле **Expression** в позиции курсора:

- <Inline id="variables.svg" alt="Insert variable" /> **Insert variable**: Открывает список с четырьмя вкладками. Выберите значение, чтобы вставить ссылку на него, или функцию, чтобы вставить её название и открывающую скобку:
  - **Functions**: Функции формул.
  - **Elements**: Ответы в полях ввода и выборках, например `weight.value`.
  - **Products**: Цены выбранного продукта в каждой группе продуктов, а затем продукты вашего каталога Adapty. См. [Считать цену любого продукта](#read-the-price-of-any-product).
  - **Custom**: Пользовательские переменные типов Number, Date и Formula.
- <Inline id="function.svg" alt="Insert function" /> **Insert function**: Список функций с описанием и примером для каждой. Чтобы найти функцию, введите её название в поле поиска. Выберите функцию, чтобы вставить её название и открывающую скобку, например `addDays(`. Затем введите аргументы и закрывающую скобку.

Список **Insert variable** не показывает переменные типа String, Boolean или Array, а также формулу, которую вы редактируете.

## Напишите формулу \{#write-a-formula\}

Формула сочетает числа, ссылки на значения, операторы и функции. Имена функций и переменных чувствительны к регистру: `Round(2.5)` — это ошибка.

### Ссылки \{#references\}

Заключайте каждую ссылку в двойные фигурные скобки:

| Справочник | Что читает формула | Пример |
| :--- | :--- | :--- |
| `{{<variable name>}}` | Пользовательская переменная типа Number, Date или Formula | `{{discount}}` |
| `{{<Element ID>.value}}` | Ответ в поле [ввода текста или числа](builder-inputs-and-forms), [числовом пикере](builder-number-picker) или поле ввода даты или даты и времени | `{{weight.value}}` |
| `{{<Group ID>.selectedProduct.prod_price}}` | Цена продукта, выбранного пользователем в группе продуктов, в виде числа | `{{products.selectedProduct.prod_price}}` |
| `{{<Group ID>.selectedProduct.prod_price_per_week}}` | Цена выбранного продукта за одну неделю. Также доступны `prod_price_per_day`, `prod_price_per_month` и `prod_price_per_year`. Для продукта, не являющегося подпиской, значение не возвращается. См. [Цены за период](#per-period-prices). | `{{products.selectedProduct.prod_price_per_month}}` |
| `{{<Group ID>.selectedProduct.offer_price}}` | Цена предложения выбранного продукта в виде числа | `{{products.selectedProduct.offer_price}}` |
| `{{<Group ID>.selectedProduct}}` | Выбранный продукт, только в качестве второго аргумента функции `addOfferDuration` | `{{products.selectedProduct}}` |
| `{{<Adapty product ID>.prod_price}}` | Цена продукта из каталога Adapty в виде числа. Также доступны цены за период, например `prod_price_per_week`. См. [Получение цены любого продукта](#read-the-price-of-any-product). | `{{<annual product ID>.prod_price}}`, отображается как **Annual · prod_price** |

Формула считывает введённый ответ как число, если он состоит из цифр с необязательным знаком минус в начале и необязательной дробной частью после одной десятичной точки или одной десятичной запятой. Формула игнорирует пробелы в начале и конце строки. Например, `12`, `-5`, `1.5` и `1,5` — это числа. Любой другой ответ, например `abc`, `1,5,0` или `1e3`, даёт формуле [нет значения](#formulas-without-a-value). В поле ввода Number, которое читает формула, пользователи могут вводить только число. С форматами **Decimal (Point)** и **Decimal (Comma)** пользователи могут вводить десятичную точку или десятичную запятую, поэтому десятичная клавиша любой клавиатуры работает корректно.

Поле «Date» или «Date & Time» возвращает календарный день, выбранный пользователем.

Формула может читать другую формулу, но ссылки не могут образовывать циклы. Если формула A читает формулу B, формула B не может читать формулу A в ответ. Более длинный цикл — тоже ошибка: например, A читает B, B читает C, а C читает A. Формула не может ссылаться на саму себя. При переименовании переменной, **Element ID** или **Group ID** формула показывает новое имя и читает то же значение. При удалении переменной, которую читает формула, в поле **Expression** появляется чип **deleted variable**, а под полем отображается ошибка.

Имя, совпадающее с двумя значениями, является ошибкой. Например, если пользовательская переменная называется `age.value`, а у элемента ввода задан Element ID `age`, то `{{age.value}}` соответствует сразу двум значениям. Переименуйте пользовательскую переменную.

### Числа и операторы \{#numbers-and-operators\}

- **Числа**: Всегда используйте десятичную точку, например `0.8`. Внутри функции аргументы разделяются запятой: `round(2,5)` — это `round(2, 5)`, что даёт 2, а не 2.5. За пределами функции запятая в числе является ошибкой. Минус перед числом или ссылкой делает значение отрицательным, например `-3`.
- **Операторы**: `+`, `-`, `*` и `/`. Флоу вычисляет `*` и `/` раньше `+` и `-`, а операторы одного уровня — слева направо. Используйте скобки, чтобы изменить порядок: `({{a}} + {{b}}) / 2`.

## Числовые формулы \{#number-formulas\}

Числовая формула возвращает число.

### Числовые функции \{#number-functions\}

| Function | Result | Example |
| :--- | :--- | :--- |
| `round(n)` | `n`, округлённое до целого числа. Значение ровно посередине округляется от нуля. | `round(2.5)` = 3, `round(-2.5)` = -3 |
| `round(n, digits)` | `n`, округлённое до `digits` знаков после запятой. `digits` — целое число от 0 до 6, которое вводится в формулу напрямую, а не как ссылка или вычисление. | `round(23.12, 1)` = 23.1, `round(1.005, 2)` = 1.01 |
| `floor(n)` | Наибольшее целое число, не превышающее `n` | `floor(2.7)` = 2, `floor(-2.5)` = -3 |
| `mod(a, b)` | Остаток от деления `a` на `b` со знаком `b`, как в функции MOD в таблицах | `mod(7, 3)` = 1, `mod(-7, 3)` = 2, `mod(5.5, 2)` = 1.5 |

Нулевой результат операций `round`, `floor` и `mod` всегда равен 0, но не -0.

### Отображение числа в текстовом элементе \{#show-a-number-in-a-text-element\}

Чтобы показать формулу или переменную типа Date, [вставьте переменную](onboarding-variables#use-variables-in-text) в текстовый элемент с вкладки **Custom** в окне выбора переменных. Даты и числа с функцией `round` на верхнем уровне отображаются на языке устройства, а не на языке флоу.

То, как отображается числовая формула, зависит от функции на верхнем уровне формулы:

- **`round` на верхнем уровне**: Число отображается ровно с таким количеством знаков после запятой, которое задаёт `round`. В качестве разделителя используется символ, принятый в языке устройства, без разделителей тысяч и знака валюты. Например, `round(23.12, 1)` показывает «23.1» на английском и «23,1» на русском, а `round(15.04, 1)` показывает «15.0» на английском.
- **Любая другая формула**: Число отображается в чистом виде, с точкой в качестве десятичного разделителя во всех языках и не более чем 15 значащими цифрами. Например, `9.99 * 0.8` показывает «7.992», а `1 - 1 / 3` — «0.666666666666667». Чтобы задать количество знаков после запятой, поместите `round` на верхний уровень формулы, например: `round(1 - 1 / 3, 2)`.

Переменная типа Number и формула с `floor` или `mod` на верхнем уровне также отображаются в простой форме.

### Сравнение чисел в условиях \{#compare-numbers-in-conditions\}

Вы можете выбрать формулу или переменную типа Date в условии, например в правиле [условной видимости](onboarding-element-visibility) или в условном действии:

- **Числовые формулы**: Используют те же операторы, что и для числовой переменной: **Equals**, **Does not equal**, **Greater than**, **Less than**, **Is empty** и **Is not empty**. Сравнивайте формулу с числом или с другим числовым значением, например `bmi` **Greater than** `25`. Операторы не включают «больше или равно» и «меньше или равно». Чтобы проверить, что целое число не меньше 10 (например, счёт за тест), используйте `score` **Greater than** `9`.

## Цены на продукты \{#product-prices\}

Формула может получать цены продуктов из двух источников:

- **Выбранный продукт из группы продуктов**: Цена меняется, когда пользователь выбирает другой продукт в группе, например `{{products.selectedProduct.prod_price}}`.
- **Продукт из каталога Adapty**: Цена одного конкретного продукта, даже если он не отображается на экране. Используйте это для сравнения планов — например, чтобы показать экономию при выборе годового плана по сравнению с недельным.

На устройстве флоу использует цену из стора в валюте пользователя. Когда цены продуктов загружаются, флоу пересчитывает формулу заново.

### Считать цену любого продукта \{#read-the-price-of-any-product\}

1. В поле **Expression** установите курсор там, где должна стоять цена.
2. Нажмите <Inline id="variables.svg" alt="Insert variable" /> **Insert variable** и откройте вкладку **Products**.
3. Наведите на продукт и выберите цену: `prod_price` или [цену за период](#per-period-prices), например `prod_price_per_week`.

Вкладка **Products** отображает продукты в двух группах:

- **This flow**: продукты на экранах флоу.
- **Other**: остальные продукты вашего каталога Adapty.

Чтобы различать продукты, сравнивайте уровень доступа и цену в USD для каждого продукта в списке. Длительность подписки в списке не отображается. Если два продукта имеют одинаковое название, список и всплывающая подсказка чипа также показывают ID продукта в сторе.

Формула может отображать цену на экране только в том случае, если продукт есть в [списке продуктов экрана](paywall-product-block). Когда вы вставляете формулу в текстовый элемент или используете её в условии, Builder добавляет продукт в этот список — без оффера и тарифного плана. То же самое происходит, когда формула считывает цену через другую формулу. Для переиспользуемого компонента Builder добавляет продукт в каждый экран, отображающий этот компонент. Если продукт уже присутствует на экране только с оффером или тарифным планом, Builder добавляет вторую запись — без них.

Добавленная запись отображается на панели **Products**, в аналитике и в списке продуктов, которые получает код вашего приложения — как и любой другой продукт экрана. Экран не выбирает её автоматически, а нажатие на текст не инициирует покупку.

После того как Paywall Builder добавит запись, вы управляете ею на панели **Products**, как и любым другим продуктом экрана:

- **Вы удаляете цену из формулы или формулу с экрана**: запись остаётся. Если продукт больше нигде на экране не используется, удалите запись. Запись, которую вы оставите, заблокирует публикацию после удаления продукта из каталога Adapty.
- **Вы удаляете запись, пока экран всё ещё использует формулу**: билдер не добавляет запись обратно, и на экране появляется проблема **This product is off this screen**. Чтобы её исправить, добавьте продукт снова в панели **Products**.

Когда вы удаляете продукт из каталога Adapty, в поле **Expression** его цена отображается как чип **Missing product**, а под полем появляется сообщение об ошибке. Замените эту цену ценой другого продукта. Удаление не затрагивает опубликованные версии флоу.

Если вы создаёте флоу с помощью [Adapty CLI](developer-cli-flows) или API, добавьте продукт без оффера или тарифного плана на каждый экран, использующий формулу, — так же, как это делает конструктор. В выражении используйте Adapty product ID, который возвращает команда [`adapty products list`](developer-cli-products). Публикация завершается ошибкой `formula_undeclared_product` только в том случае, если текстовый элемент или условие использует формулу, а ни один экран флоу не содержит продукт без оффера или тарифного плана.

### Цены за период \{#per-period-prices\}

Цена за период — это стоимость продукта-подписки за один день, неделю, месяц или год. Формула может считывать эти цены для продукта из каталога и для выбранного продукта из группы продуктов:

| Цена | Пример для месячного продукта по цене 9.99 |
| :--- | :--- |
| `prod_price_per_day` | 9.99 / 30 = 0.333 |
| `prod_price_per_week` | 9.99 × 7 / 30 = 2.331 |
| `prod_price_per_month` | 9.99 |
| `prod_price_per_year` | 9.99 × 12 = 119.88 |

Флоу делит цену на количество дней, недель, месяцев или лет в длительности подписки продукта. Месяц равен 30 дням, то есть 30/7 недели. Год равен 365 дням, 52 неделям или 12 месяцам. [Переменные цен для текстовых элементов](onboarding-variables#product-variables) используют те же правила пересчёта. Например, для годового продукта с ценой 120 переменная `prod_price_per_month` вернёт 10, а `prod_price_per_week` — 120 / 52.

Формула сохраняет все знаки после запятой при расчёте цены за период. Чтобы отобразить цену с двумя знаками после запятой, добавьте `round` на верхний уровень формулы. Если пользователь выбирает годовой продукт с ценой 120, `round({{products.selectedProduct.prod_price_per_week}}, 2)` покажет «2.31».

Продукт, не являющийся подпиской, — например, продукт с пожизненным доступом или расходуемая покупка, — возвращает цены за период как [пустое значение](#formulas-without-a-value).

## Формулы дат \{#date-formulas\}

Формула даты возвращает дату. Чтобы использовать фиксированный день в формуле, например дату начала пробного периода, сохраните его в переменной типа Date.

### Создание переменной Date \{#create-a-date-variable\}

1. Откройте панель <Inline id="variables.svg" alt="Variables" /> Variables и нажмите <Inline id="plus.svg" alt="Plus" />.
2. Введите **Name** переменной, например `trial_start`.
3. В выпадающем списке **Value Type** выберите **Date**.
4. (Опционально) В поле **Initial value** введите дату в формате `DD.MM.YYYY`, например `17.11.2026`, или нажмите на поле и выберите день в календаре, затем нажмите **Apply**. Builder не принимает несуществующие даты, например `31.02.2027`. Без Initial value переменная не имеет значения до тех пор, пока его не установит [действие **Set variable**](onboarding-actions).
5. (Опционально) В выпадающем списке **Date format** выберите, как текстовые элементы будут отображать дату. См. [Показ даты в текстовом элементе](#show-a-date-in-a-text-element).
6. Нажмите **Create variable**.

<ZoomImage id="flow-date-variable-create.webp" width="300px" alt="The Create variable dialog with the Date type and the Initial value 17.11.2026" />

Переменная типа Date хранит дату без времени и часового пояса.

Чтобы изменить переменную Date по нажатию на элемент, добавьте действие [**Set variable**](onboarding-actions), выберите переменную Date и введите новую дату в формате `DD.MM.YYYY` или выберите её в календаре. Действие **Set variable** не может изменить формулу, поскольку формула всегда зависит от других значений.

### Функции для работы с датами \{#date-functions\}

| Функция | Результат | Пример |
| :--- | :--- | :--- |
| `today()` | Текущий день на устройстве | `today()` |
| `addDays(date, n)` | `date` плюс `n` дней | `addDays(today(), 7)` |
| `addWeeks(date, n)` | `date` плюс `n` недель | `addWeeks({{trial_start}}, 2)` |
| `addMonths(date, n)` | `date` плюс `n` месяцев | `addMonths({{trial_start}}, 1)` |
| `addYears(date, n)` | `date` плюс `n` лет | `addYears({{birth_date.value}}, 18)` |
| `addOfferDuration(date, product)` | `date` плюс длительность оффера продукта | `addOfferDuration(today(), {{products.selectedProduct}})` |
| `daysBetween(start, end)` | Количество календарных дней от `start` до `end` в виде числа | `daysBetween(today(), {{trial_end}})` |
| `weeksBetween(start, end)` | Количество целых недель от `start` до `end` в виде числа | `weeksBetween({{trial_start}}, today())` |
| `monthsBetween(start, end)` | Количество целых месяцев от `start` до `end` в виде числа | `monthsBetween({{trial_start}}, today())` |
| `yearsBetween(start, end)` | Количество целых лет от `start` до `end` в виде числа | `yearsBetween({{birth_date.value}}, today())` |

The date functions follow these rules:

- **`today()`**: Возвращает начало текущего дня в часовом поясе устройства. Флоу считывает день в момент открытия, поэтому значение не меняется в полночь, пока флоу открыт.
- **Отрицательные и дробные значения `n`**: Отрицательное `n` сдвигает дату назад. Флоу отбрасывает дробную часть `n`: `addWeeks(date, 1.5)` добавляет 1 неделю, а `addDays(date, -1.9)` сдвигает дату на 1 день назад.
- **Короткие месяцы**: Если в целевом месяце нет нужного числа, результатом будет последний день этого месяца. Например, 31 января 2027 плюс 1 месяц — это 28 февраля 2027, а 29 февраля 2028 плюс 1 год — это 28 февраля 2029.
- **`addOfferDuration`**: Добавляет каждую фазу оффера продукта, которую Adapty SDK передаёт во флоу, по порядку. Для каждой фазы функция добавляет период фазы, умноженный на количество периодов за один шаг: бесплатный пробный период на 7 дней, начавшийся 10 ноября 2026, заканчивается 17 ноября 2026. Если у продукта нет оффера или период одной из фаз неизвестен, результат не содержит значения.
- **Разница между датами**: `daysBetween`, `weeksBetween`, `monthsBetween` и `yearsBetween` считают только целые единицы, отбрасывая остаток:
  - `weeksBetween` делит количество дней на 7: 13 дней — это 1 неделя.
  - `monthsBetween` и `yearsBetween` считают полные календарные месяцы и годы. Например, от 15 января 2027 до 14 марта 2027 — это 1 месяц, а до 15 марта 2027 — 2 месяца. Если месяц даты `end` слишком короткий для числа даты `start`, последний день этого месяца завершает месяц: от 31 января 2027 до 28 февраля 2027 — это 1 месяц.
  - Если `end` раньше `start`, результат отрицательный — то есть результат для этих двух дат в обратном порядке со знаком минус. Например, `daysBetween` от 1 декабря 2026 до 24 ноября 2026 даёт -7, а `weeksBetween` даёт -1, если `end` на 10 дней раньше `start`.

Внутри формулы дата может быть только первым аргументом функции, добавляющей время к дате, или аргументом функции, считающей время между двумя датами. Дата в вычислении, например `{{trial_start}} + 1`, является ошибкой. Число не может быть аргументом там, где функция ожидает дату. Строка, булево значение или переменная-массив не могут участвовать в формуле.

### Отображение даты в текстовом элементе \{#show-a-date-in-a-text-element\}

Чтобы отобразить формулу или переменную типа Date, [вставьте переменную](onboarding-variables#use-variables-in-text) в текстовый элемент с вкладки **Custom** в выборщике переменных. Даты и числа с `round` на верхнем уровне отображаются на языке устройства, а не на языке флоу.

У переменной и формулы типа Date в настройках переменной есть параметр **Date format**. Все текстовые элементы, отображающие эту переменную, используют данный формат, и при его изменении все они обновятся. Для новой переменной по умолчанию задан формат **Medium**.

Чтобы использовать другой формат в одном текстовом элементе, в поле **Content** нажмите на переменную и выберите формат. Чтобы вернуться к формату переменной, выберите **Variable default**. Доступные форматы:

| Формат даты | Пример на английском |
| :--- | :--- |
| **Short** | 11/17/26 |
| **Medium** | Nov 17, 2026 |
| **Long** | November 17, 2026 |
| **Month D** | November 17 |
| **Mon D** | Nov 17 |

**Short**, **Medium** и **Long** следуют порядку даты языка устройства. **Month D** и **Mon D** всегда отображают месяц перед днём на всех языках, например «ноября 17» в русском.

### Сравнение дат в условиях \{#compare-dates-in-conditions\}

Вы можете выбрать формулу или переменную типа Date в условии — например, в правиле [условной видимости](onboarding-element-visibility) или в условном действии:

- **Переменные Date и формулы Date**: используйте **Equals**, **Does not equal**, **Earlier than**, **Later than**, **Is empty** или **Is not empty**. Сравнивайте дату с другой датой или с датой, введённой вручную в формате `DD.MM.YYYY` либо выбранной в календаре. **Is empty** возвращает true, пока переменная не имеет значения, — например, переменная типа Date без начального значения до того, как действие **Set variable** его установит.

Сравнение дат работает по календарным дням, а не по времени. Например, дата, которую пользователь выбрал в 21:00 17 ноября 2026 года, равна `17.11.2026`. Сравнивать дату с числом нельзя.

## Формулы без значения \{#formulas-without-a-value\}

Формула не имеет значения, если одно из входящих в неё значений недоступно на устройстве:

- Ответ пустой или не является числом.
- Цены продуктов не загрузились, либо стор не вернул продукт, который читает формула. Чтобы формула получала значение и на iOS, и на Android, настройте продукт в App Store Connect и в Google Play Console.
- Продукт не является подпиской, а формула читает [цену за период](#per-period-prices).
- У выбранного продукта нет офера, а формула читает `offer_price` или вызывает `addOfferDuration`.
- Формула делит на ноль, например `{{a}} / 0` или `mod({{a}}, 0)`.
- Переменная типа Date, которую читает формула, не имеет значения.

Формула, считывающая другую формулу без значения, тоже не имеет значения. Когда у формулы нет значения, она ведёт себя следующим образом:

- **Текстовые элементы**: формула ничего не показывает.
- **Условия**: **Is empty** истинно. **Equals**, **Does not equal** и все остальные сравнения с этой формулой — ложны.

Флоу обновляет результат формулы при изменении считываемых ею значений: когда пользователь вводит ответ, действие **Set variable** изменяет переменную или загружаются цены продукта. Если пользователь вернулся назад и очистил ответ, на следующем экране формула не будет иметь значения. Пока флоу не изменит кастомную переменную, формула считывает её начальное значение (Initial value).

## Предпросмотр формулы в конструкторе \{#preview-a-formula-in-the-builder\}

Конструктор вычисляет результат формулы на основе начальных значений пользовательских переменных и цен продуктов в каталоге Adapty в USD. В разделе **Preview** под полем **Expression** отображается **No value**, если формула содержит любое из следующего:

- Ответ, который пользователь вводит или выбирает
- `offer_price`
- Оферта `addOfferDuration`
- Переменная без значения, например переменная типа Date без начального значения
- Цена продукта из вашего каталога Adapty без цены в USD или с ценой USD равной 0
- Цена за период для продукта, не являющегося подпиской, например продукта с пожизненным доступом

В таких случаях текстовый элемент на холсте показывает имя переменной в фигурных скобках, например `{{trial_end}}`. Чтобы увидеть значения ответов, [просмотрите флоу в мобильном приложении Adapty](paywall-device-compatibility-preview). Значения offer требуют сборки вашего приложения с реальными продуктами.

На холсте даты и числа с `round` на верхнем уровне отображаются на языке, выбранном для предпросмотра.

## Примеры \{#examples\}

### Показать сумму ответов \{#show-a-sum-of-answers\}

На экране добавьте три числовых поля (Number inputs) с Element ID `a1`, `a2` и `a3`. Создайте формулу `sum`:

```
{{a1.value}} + {{a2.value}} + {{a3.value}}
```

На следующем экране вставьте `sum` в текстовый элемент. Если пользователь введёт 2, 3 и 4 — в тексте отобразится «9». Если вернуться назад и изменить 4 на 5 — отобразится «10».

### Показать BMI и метку «High» \{#show-a-bmi-and-a-high-label\}

Добавьте поле Number input с Element ID `weight` для веса в килограммах и ещё одно с Element ID `height` для роста в сантиметрах. Создайте формулу `bmi`:

```
round({{weight.value}} * 10000 / ({{height.value}} * {{height.value}}), 1)
```

Вставьте `bmi` в текстовый элемент. При BMI 23.12 пользователи с английским языком устройства увидят «23.1», а с русским — «23,1». Чтобы показывать метку «High» только при BMI выше 25, добавьте текстовый элемент со словом «High» и задайте ему правило [условной видимости](onboarding-element-visibility): `bmi` **Greater than** `25`.

### Показать цену со скидкой \{#show-a-discounted-price\}

Создайте формулу `discounted`, которая уменьшает цену выбранного продукта на 20%:

```
{{products.selectedProduct.prod_price}} * 0.8
```

Затем создайте формулу `shown`, которая округляет результат до двух знаков после запятой:

```
round({{discounted}}, 2)
```

Вставьте `shown` в текстовый элемент. Для продукта с ценой 9.99 текст отобразит «7.99». Когда пользователь выбирает продукт с ценой 100, текст отобразит «80.00». Знак валюты не отображается. Если цена выбранного продукта не загрузилась, текст будет пустым.

### Показывайте экономию на годовом плане \{#show-the-savings-of-the-annual-plan\}

Чтобы показать пользователям, сколько они экономят на годовом плане по сравнению с 52 неделями еженедельного плана, создайте формулу `saving`, которая считывает цены обоих продуктов. Еженедельный продукт необязательно должен присутствовать на каком-либо экране флоу. В этом примере годовой продукт стоит 120, а еженедельный — 5:

1. В поле **Expression** нажмите <Inline id="variables.svg" alt="Insert variable" /> **Insert variable**. Во вкладке **Products** наведите на недельный продукт и выберите `prod_price`.
2. Введите `* 52 -`.
3. Таким же образом добавьте `prod_price` годового продукта.

В поле **Expression** отобразится **Weekly · prod_price** `* 52 -` **Annual · prod_price**, а в **Preview** появится значение 140. Билдер сохраняет выражение с ID продуктов Adapty:

```
{{<weekly product ID>.prod_price}} * 52 - {{<annual product ID>.prod_price}}
```

Чтобы показать скидку в процентах, создайте формулу `saving_percent`. Вставьте две цены с вкладки **Products** так же, как для `saving`. Билдер сохранит выражение в виде:

```
round((1 - {{<annual product ID>.prod_price}} / ({{<weekly product ID>.prod_price}} * 52)) * 100)
```

Для этих цен значение `saving_percent` равно 54. Вставьте `saving` или `saving_percent` в текстовый элемент на экране пейвола. Builder добавляет недельный продукт в конец списка продуктов экрана. На устройстве формула использует цены стора в валюте пользователя. Кнопка покупки на экране инициирует покупку годового продукта.

### Отображение даты окончания пробного периода и напоминания \{#show-the-end-of-a-trial-and-a-reminder-date\}

Создайте формулу `trial_end`:

```
addOfferDuration(today(), {{products.selectedProduct}})
```

Затем создайте формулу `reminder` за три дня до окончания пробного периода:

```
addDays({{trial_end}}, -3)
```

Для продукта с 7-дневным пробным периодом 10 ноября 2026 года `trial_end` будет 17 ноября 2026 года, а `reminder` — 14 ноября 2026 года. С форматом даты **Medium** в тексте отобразится «Nov 17, 2026». С форматом **Month D** — «November 17».

### Показать длительность пробного периода \{#show-the-length-of-a-trial\}

Используйте формулу `trial_end` из раздела [Показать окончание пробного периода и дату напоминания](#show-the-end-of-a-trial-and-a-reminder-date) и создайте формулу `trial_days`:

```
daysBetween(today(), {{trial_end}})
```

В текстовом элементе введите «Free for», вставьте `trial_days` и введите «days». Для продукта с 7-дневным пробным периодом текст будет отображаться как «Free for 7 days». Если у выбранного продукта нет оффера, `trial_end` не имеет значения. Чтобы текст отображался только для продукта с оффером, задайте текстовому элементу правило [условной видимости](onboarding-element-visibility): `trial_end` **Is not empty**.

### Показать возраст пользователя \{#show-the-age-of-a-user\}

Добавьте поле ввода Date с Element ID `birth_date` и создайте формулу `age`:

```
yearsBetween({{birth_date.value}}, today())
```

Для пользователей, рождённых 25 ноября 2000 года, `age` равен 25 на 24 ноября 2026 года и 26 на 25 ноября 2026 года. Пока поле пустое, `age` не имеет значения.

### Показать рост в футах и дюймах \{#show-a-height-in-feet-and-inches\}

Добавьте поле ввода Number с идентификатором элемента `height` для роста в сантиметрах. Создайте три формулы:

- `total`: `round({{height.value}} / 2.54)` — рост в целых дюймах.
- `feet`: `floor({{total}} / 12)`.
- `inches`: `mod({{total}}, 12)`.

В текстовом элементе вставьте `feet`, введите «ft», вставьте `inches` и введите «in». Для 180 см текст покажет «5 ft 11 in». Для 140 см — «4 ft 7 in».

## Устранение неполадок \{#troubleshooting\}

Когда вы покидаете поле **Expression**, конструктор отображает первую ошибку формулы под полем. Несколько примеров:

| Текст ошибки | Причина и способ исправления |
| :--- | :--- |
| `addDays() needs a date and a number` | У функции неверное количество аргументов или аргумент неправильного типа. Используйте аргументы из таблицы [числовых функций](#number-functions) или [функций дат](#date-functions). |
| `Unknown function "flor". Use one of: …` | Имя функции написано с опечаткой или в неправильном регистре. Используйте функцию из списка в тексте ошибки. Чтобы обратиться к переменной, заключите её имя в `{{ }}`. |
| `Use a dot in a decimal number, like 1.5` | Число вне функции содержит запятую. Замените запятую точкой. Внутри функции билдер воспринимает запятую как разделитель аргументов, поэтому там тоже используйте точку. |
| `{{…}} is not a variable, an answer or a product field of this flow` | Переменной, ID элемента или группы продуктов с таким именем не существует. Исправьте имя или создайте переменную. |
| `{{…}}: the product … is not in the product catalog of the app` | Вы удалили продукт из каталога Adapty. Чип отображается как **Missing product**. Замените цену на цену другого продукта. |
| `Offers, billing plans and fields other than prod_price, … of a catalog product are not supported yet` | Формула обращается к офферу, тарифному плану или другому полю продукта из каталога Adapty. Вставьте цену с вкладки **Products** в **Insert variable**. |
| `This variable no longer exists. Pick another one.` | Вы удалили переменную, к которой обращается формула. В поле **Expression** она отображается как чип **deleted variable**. Замените её другой ссылкой. |
| `{{…}} is the name of a variable and of an element answer: rename the variable` | Имя совпадает сразу с двумя значениями. Переименуйте пользовательскую переменную. |
| `{{…}} uses this formula: formulas cannot use each other in a loop` | Ссылки между формулами образуют цикл: например, формула A обращается к формуле B, а формула B — к формуле A. Уберите одну из ссылок. |

## Ограничения \{#limitations\}

- **Только числа и даты**: формула возвращает только число или дату. Чтобы отобразить текст в зависимости от результата, добавьте [условный текст](onboarding-text#add-conditional-text) к текстовому элементу. Например, чтобы показать «High» при ИМТ выше 25, задайте условие **if** как `bmi` **Greater than** `25` и введите «High» в поле **then**.
- **Продукты каталога**: формула считывает только цену и цены за период для продукта из вашего каталога Adapty без учёта offer или тарифного плана. Чтобы использовать цену offer, считайте `offer_price` выбранного продукта в группе продуктов.
- **Выбранный продукт**: формула, которая считывает выбранный продукт, не имеет значения, пока пользователь не выберет продукт. Чтобы результат отображался при открытии экрана, выберите **Set as default** на одной из карточек продукта.
- **Офферы на iOS и Android**: на iOS SDK Adapty передаёт во флоу один оффер. Среди доступных пользователю офферов приоритет такой: сначала win-back offer, затем promotional offer, затем introductory offer. На Android SDK Adapty передаёт только первую фазу introductory offer. Если после бесплатного пробного периода следует сниженная цена, `addOfferDuration` на Android добавляет только пробный период.
