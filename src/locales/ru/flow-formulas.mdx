Формула — это [пользовательская переменная](onboarding-variables#custom-variables) с вычисленным значением: числом или датой. Формула может считывать ответы пользователей в флоу, другие пользовательские переменные, выбранный продукт и текущий день. С помощью формул в Flow & Paywall Builder флоу может отображать вычисленные значения без кода в вашем приложении:

- **Результат вычислений**: Сумма баллов теста, ИМТ из веса и роста или рост в футах и дюймах.
- **Цена**: Цена выбранного продукта со скидкой 20%.
- **Дата**: Дата окончания бесплатного пробного периода.

Флоу вычисляет результат формулы на устройстве. При изменении любого значения, которое используется в формуле, флоу автоматически обновляет результат. Результат можно отобразить в текстовом элементе и использовать в условиях.

## Создание формулы \{#create-a-formula\}

1. Откройте панель <Inline id="variables.svg" alt="Variables" /> Variables в конструкторе флоу.
2. Добавьте новую переменную — нажмите <Inline id="plus.svg" alt="Plus" />.
3. Введите **Name** переменной, например `bmi`. Другие формулы используют это имя для чтения результата.
4. В выпадающем списке **Value Type** выберите **Formula**.
5. В поле **Expression** введите формулу, например `round({{weight}} * 10000 / ({{height}} * {{height}}), 1)`, где `weight` и `height` — числовые переменные. О правилах записи см. раздел [Написание формулы](#write-a-formula).
6. Нажмите **Create variable**.

<ZoomImage id="flow-formula-create.webp" width="300px" alt="Диалог создания переменной с типом Formula, формулой BMI в поле Expression, типом вывода Number и предпросмотром значения 22.9" />

Когда вы покидаете поле **Expression**, конструктор проверяет формулу. Если в формуле есть ошибка, её текст появляется под полем. Пока ошибка отображается, кнопка **Create variable**, или **Save** для существующей переменной, недоступна. Когда вы редактируете выражение, ошибка исчезает и кнопка снова становится активной.

Без ошибки под полем отображается подсказка. Для формулы типа Date подсказка гласит: «Use a formula to set a date that updates automatically. Use negative n to go back in time». Для остальных формул подсказка гласит: «Use round(x, 2) to set the decimals».

Под полем билдер также отображает:

- **Output type**: **Number** или **Date** — тип результата. Билдер определяет его из формулы: результат является Date, если формула представляет собой [функцию даты](#date-functions) или отдельное значение типа Date, например `{{trial_start}}`. Любая другая формула даёт Number.
- **Date format**: Только для формулы типа Date. Определяет, как текстовые элементы отображают результат. См. [Показать дату в текстовом элементе](#show-a-date-in-a-text-element).
- **Preview**: Результат, вычисленный на основе начальных значений и цен продукта. См. [Предпросмотр формулы в билдере](#preview-a-formula-in-the-builder).

Формула всегда зависит от других значений, поэтому у неё нет **Initial value**. По той же причине приложение не может задать формулу.

### Вставка ссылок и функций \{#insert-references-and-functions\}

Чтобы добавить ссылку или функцию, не набирая её вручную, используйте две кнопки на строке **Output type**. Каждая кнопка добавляет текст в позицию курсора в поле **Expression**:

- <Inline id="variables.svg" alt="Insert variable" /> **Insert variable**: Список значений, которые формула может считывать, разделённых на три группы: **Variables**, **Answers** и **Selected product**. Выберите значение, чтобы вставить ссылку на него, например `{{weight.value}}`.
- <Inline id="function.svg" alt="Insert function" /> **Insert function**: Список функций с описанием и примером для каждой. Чтобы найти функцию, введите её название в поле поиска. Выберите функцию, чтобы вставить её имя и открывающую скобку, например `addDays(`. Затем введите аргументы и закрывающую скобку.

В списке **Insert variable** отображаются только значения, которые формула может считать. Строковые, булевые переменные и массивы, а также формула, которую вы редактируете, в этом списке не отображаются.

## Напишите формулу \{#write-a-formula\}

Формула сочетает числа, ссылки на значения, операторы и функции. Имена функций и переменных чувствительны к регистру: `Round(2.5)` — это ошибка.

### Ссылки \{#references\}

Заключайте каждую ссылку в двойные фигурные скобки:

| Ссылка | Что считывает формула | Пример |
| :--- | :--- | :--- |
| `{{<variable name>}}` | Пользовательская переменная типа Number, Date или Formula | `{{discount}}` |
| `{{<Element ID>.value}}` | Ответ в поле [Text or Number input](builder-inputs-and-forms), [Number picker](builder-number-picker) или ввода Date или Date & Time | `{{weight.value}}` |
| `{{<Group ID>.selectedProduct.prod_price}}` | Цена продукта, выбранного пользователем в группе продуктов, в виде числа | `{{products.selectedProduct.prod_price}}` |
| `{{<Group ID>.selectedProduct.offer_price}}` | Цена предложения выбранного продукта в виде числа | `{{products.selectedProduct.offer_price}}` |
| `{{<Group ID>.selectedProduct}}` | Выбранный продукт, только в качестве второго аргумента `addOfferDuration` | `{{products.selectedProduct}}` |

Формула считывает введённый ответ как число, если он состоит из цифр с необязательным знаком минус в начале и необязательной дробной частью после одной десятичной точки или одной десятичной запятой. Формула игнорирует пробелы в начале и конце строки. Например, `12`, `-5`, `1.5` и `1,5` — это числа. Любой другой ответ, например `abc`, `1,5,0` или `1e3`, даёт формуле [нет значения](#formulas-without-a-value). В поле ввода Number, которое читает формула, пользователи могут вводить только число. С форматами **Decimal (Point)** и **Decimal (Comma)** пользователи могут вводить десятичную точку или десятичную запятую, поэтому десятичная клавиша любой клавиатуры работает корректно.

Поле ввода даты или даты и времени передаёт календарный день, выбранный пользователем.

Формула может читать другую формулу, но не саму себя, и две формулы не могут читать друг друга. При переименовании переменной, **Element ID** или **Group ID** формула отображает новое имя и читает то же значение. Если удалить переменную, которую читает формула, на её месте появится `{{deleted variable}}` и формула будет содержать ошибку.

Имя, совпадающее с двумя значениями, является ошибкой. Например, если пользовательская переменная называется `age.value`, а у элемента ввода задан Element ID `age`, то `{{age.value}}` соответствует сразу двум значениям. Переименуйте пользовательскую переменную.

### Числа и операторы \{#numbers-and-operators\}

- **Числа**: Всегда используйте десятичную точку, например `0.8`. Внутри функции аргументы разделяются запятой: `round(2,5)` — это `round(2, 5)`, что даёт 2, а не 2.5. За пределами функции запятая в числе является ошибкой. Минус перед числом или ссылкой делает значение отрицательным, например `-3`.
- **Операторы**: `+`, `-`, `*` и `/`. Флоу вычисляет `*` и `/` раньше `+` и `-`, а операторы одного уровня — слева направо. Используйте скобки, чтобы изменить порядок: `({{a}} + {{b}}) / 2`.

## Числовые формулы \{#number-formulas\}

Числовая формула возвращает число.

### Числовые функции \{#number-functions\}

| Function | Result | Example |
| :--- | :--- | :--- |
| `round(n)` | `n`, округлённое до целого числа. Значение ровно посередине округляется от нуля. | `round(2.5)` = 3, `round(-2.5)` = -3 |
| `round(n, digits)` | `n`, округлённое до `digits` знаков после запятой. `digits` — целое число от 0 до 6, которое вводится в формулу напрямую, а не как ссылка или вычисление. | `round(23.12, 1)` = 23.1, `round(1.005, 2)` = 1.01 |
| `floor(n)` | Наибольшее целое число, не превышающее `n` | `floor(2.7)` = 2, `floor(-2.5)` = -3 |
| `mod(a, b)` | Остаток от деления `a` на `b` со знаком `b`, как в функции MOD в таблицах | `mod(7, 3)` = 1, `mod(-7, 3)` = 2, `mod(5.5, 2)` = 1.5 |

Нулевой результат операций `round`, `floor` и `mod` всегда равен 0, но не -0.

### Отображение числа в текстовом элементе \{#show-a-number-in-a-text-element\}

Чтобы показать формулу или переменную типа Date, [вставьте переменную](onboarding-variables#use-variables-in-text) в текстовый элемент с вкладки **Custom** в окне выбора переменных. Даты и числа с функцией `round` на верхнем уровне отображаются на языке устройства, а не на языке флоу.

То, как отображается числовая формула, зависит от функции на верхнем уровне формулы:

- **`round` на верхнем уровне**: Число содержит ровно столько десятичных знаков, сколько задаёт `round`. В качестве разделителя используется символ, принятый для языка устройства, без разделителей тысяч и знака валюты. Например, `round(23.12, 1)` покажет "23.1" на английском и "23,1" на русском, а `round(15.04, 1)` покажет "15.0" на английском.
- **Любая другая формула**: Число отображается в обычном виде с точкой в качестве десятичного разделителя во всех языках. У некоторых дробных чисел появляется длинный «хвост» из цифр: `9.99 * 0.8` покажет "7.992000000000001". Чтобы задать количество знаков после запятой, поместите `round` на верхний уровень формулы, например `round(9.99 * 0.8, 2)`.

Переменная типа Number и формула с `floor` или `mod` на верхнем уровне также отображаются в простой форме.

### Сравнение чисел в условиях \{#compare-numbers-in-conditions\}

Вы можете выбрать формулу или переменную типа Date в условии, например в правиле [условной видимости](onboarding-element-visibility) или в условном действии:

- **Числовые формулы**: Используют те же операторы, что и для числовой переменной: **Equals**, **Does not equal**, **Greater than**, **Less than**, **Is empty** и **Is not empty**. Сравнивайте формулу с числом или с другим числовым значением, например `bmi` **Greater than** `25`. Операторы не включают «больше или равно» и «меньше или равно». Чтобы проверить, что целое число не меньше 10 (например, счёт за тест), используйте `score` **Greater than** `9`.

## Формулы дат \{#date-formulas\}

Формула даты возвращает дату. Чтобы использовать фиксированный день в формуле, например дату начала пробного периода, сохраните его в переменной типа Date.

### Создание переменной Date \{#create-a-date-variable\}

1. Откройте панель <Inline id="variables.svg" alt="Variables" /> Variables и нажмите <Inline id="plus.svg" alt="Plus" />.
2. Введите **Name** переменной, например `trial_start`.
3. В выпадающем списке **Value Type** выберите **Date**.
4. (Опционально) В поле **Initial value** введите дату в формате `DD.MM.YYYY`, например `17.11.2026`, или нажмите на поле и выберите день в календаре, затем нажмите **Apply**. Builder не принимает несуществующие даты, например `31.02.2027`. Без Initial value переменная не имеет значения до тех пор, пока его не установит [действие **Set variable**](onboarding-actions).
5. (Опционально) В выпадающем списке **Date format** выберите, как текстовые элементы будут отображать дату. См. [Показ даты в текстовом элементе](#show-a-date-in-a-text-element).
6. Нажмите **Create variable**.

<ZoomImage id="flow-date-variable-create.webp" width="300px" alt="The Create variable dialog with the Date type and the Initial value 17.11.2026" />

Переменная типа Date хранит дату без времени и часового пояса.

Чтобы изменить переменную Date по нажатию на элемент, добавьте действие [**Set variable**](onboarding-actions), выберите переменную Date и введите новую дату в формате `DD.MM.YYYY` или выберите её в календаре. Действие **Set variable** не может изменить формулу, поскольку формула всегда зависит от других значений.

### Функции для работы с датами \{#date-functions\}

| Функция | Результат | Пример |
| :--- | :--- | :--- |
| `today()` | Текущий день на устройстве | `today()` |
| `addDays(date, n)` | `date` плюс `n` дней | `addDays(today(), 7)` |
| `addWeeks(date, n)` | `date` плюс `n` недель | `addWeeks({{trial_start}}, 2)` |
| `addMonths(date, n)` | `date` плюс `n` месяцев | `addMonths({{trial_start}}, 1)` |
| `addYears(date, n)` | `date` плюс `n` лет | `addYears({{birth_date.value}}, 18)` |
| `addOfferDuration(date, product)` | `date` плюс длительность оффера продукта | `addOfferDuration(today(), {{products.selectedProduct}})` |

The date functions follow these rules:

- **`today()`**: Возвращает начало текущего дня в часовом поясе устройства. Флоу считывает день при открытии, поэтому значение не меняется в полночь, пока флоу открыт.
- **Отрицательное и дробное `n`**: Отрицательное `n` сдвигает дату назад. Флоу отбрасывает дробную часть `n`: `addWeeks(date, 1.5)` добавляет 1 неделю, а `addDays(date, -1.9)` сдвигает дату на 1 день назад.
- **Короткие месяцы**: Если в целевом месяце нет нужного числа, результатом будет последний день этого месяца. Например, 31 января 2027 года плюс 1 месяц — это 28 февраля 2027 года, а 29 февраля 2028 года плюс 1 год — это 28 февраля 2029 года.
- **`addOfferDuration`**: Добавляет каждую фазу оффера продукта, которую SDK Adapty передаёт во флоу, по порядку. Для каждой фазы функция добавляет период фазы, умноженный на количество периодов за один шаг: пробный период на 7 дней, начавшийся 10 ноября 2026 года, заканчивается 17 ноября 2026 года. Если у продукта нет оффера или период одной из фаз оффера неизвестен, результат не будет иметь значения.

Внутри формулы дата может быть только первым аргументом функции дат. Дата в вычислении, например `{{trial_start}} + 1`, является ошибкой. Число не может быть первым аргументом функции дат. Переменная типа String, Boolean или Array не может быть частью формулы.

### Отображение даты в текстовом элементе \{#show-a-date-in-a-text-element\}

Чтобы отобразить формулу или переменную типа Date, [вставьте переменную](onboarding-variables#use-variables-in-text) в текстовый элемент с вкладки **Custom** в выборщике переменных. Даты и числа с `round` на верхнем уровне отображаются на языке устройства, а не на языке флоу.

У переменной и формулы типа Date в настройках переменной есть параметр **Date format**. Все текстовые элементы, отображающие эту переменную, используют данный формат, и при его изменении все они обновятся. Для новой переменной по умолчанию задан формат **Medium**.

Чтобы использовать другой формат в одном текстовом элементе, в поле **Content** нажмите на переменную и выберите формат. Чтобы вернуться к формату переменной, выберите **Variable default**. Доступные форматы:

| Формат даты | Пример на английском |
| :--- | :--- |
| **Short** | 11/17/26 |
| **Medium** | Nov 17, 2026 |
| **Long** | November 17, 2026 |
| **Month D** | November 17 |
| **Mon D** | Nov 17 |

**Short**, **Medium** и **Long** следуют порядку даты языка устройства. **Month D** и **Mon D** всегда отображают месяц перед днём на всех языках, например «ноября 17» в русском.

### Сравнение дат в условиях \{#compare-dates-in-conditions\}

Вы можете выбрать формулу или переменную типа Date в условии, например в правиле [условной видимости](onboarding-element-visibility) или в условном действии:

- **Переменные Date и формулы Date**: используйте **Equals**, **Does not equal**, **Earlier than** или **Later than**. Сравните дату с другой датой или с датой, которую вы вводите в формате `DD.MM.YYYY` либо выбираете в календаре.

Сравнение дат работает по календарным дням, а не по времени. Например, дата, которую пользователь выбрал в 21:00 17 ноября 2026 года, равна `17.11.2026`. Сравнивать дату с числом нельзя.

## Формулы без значения \{#formulas-without-a-value\}

Формула не имеет значения, если одно из её значений недоступно на устройстве:

- Ответ пустой или не является числом.
- Цены продуктов не загрузились.
- У выбранного продукта нет офера, а формула обращается к `offer_price` или вызывает `addOfferDuration`.
- Формула делит на ноль, например `{{a}} / 0` или `mod({{a}}, 0)`.
- Переменная типа Date, к которой обращается формула, не имеет значения.

Формула, которая обращается к формуле без значения, тоже не имеет значения. Без значения формула работает следующим образом:

- **Текстовые элементы**: формула ничего не показывает.
- **Условия**: **Is empty** возвращает true. **Equals**, **Does not equal** и все сравнения с формулой возвращают false.

Флоу обновляет результат формулы, когда изменяется значение, которое она считывает: когда пользователь вводит ответ, действие **Set variable** меняет переменную или загружаются цены продуктов. Если пользователь вернётся назад и очистит ответ, на следующем экране у формулы не будет значения. Пока флоу не изменит пользовательскую переменную, формула считывает её начальное значение (Initial value).

## Предпросмотр формулы в билдере \{#preview-a-formula-in-the-builder\}

Билдер вычисляет результат формулы на основе начальных значений пользовательских переменных и `prod_price` выбранного продукта. В поле **Preview** под полем **Expression** отображается **No value**, если формула содержит любое из следующего:

- Ответ, который пользователь вводит или выбирает
- `offer_price`
- Оффер из `addOfferDuration`
- Переменную без значения, например переменную типа Date без начального значения

В таких случаях текстовый элемент на холсте показывает имя переменной в фигурных скобках, например `{{trial_end}}`. Чтобы увидеть значения ответов, [просмотрите флоу в мобильном приложении Adapty](paywall-device-compatibility-preview). Значения offer требуют сборки вашего приложения с реальными продуктами.

На холсте даты и числа с `round` на верхнем уровне отображаются на языке, выбранном для предпросмотра.

## Примеры \{#examples\}

### Показать сумму ответов \{#show-a-sum-of-answers\}

На экране добавьте три числовых поля (Number inputs) с Element ID `a1`, `a2` и `a3`. Создайте формулу `sum`:

```
{{a1.value}} + {{a2.value}} + {{a3.value}}
```

На следующем экране вставьте `sum` в текстовый элемент. Если пользователь введёт 2, 3 и 4 — в тексте отобразится «9». Если вернуться назад и изменить 4 на 5 — отобразится «10».

### Показать BMI и метку «High» \{#show-a-bmi-and-a-high-label\}

Добавьте поле Number input с Element ID `weight` для веса в килограммах и ещё одно с Element ID `height` для роста в сантиметрах. Создайте формулу `bmi`:

```
round({{weight.value}} * 10000 / ({{height.value}} * {{height.value}}), 1)
```

Вставьте `bmi` в текстовый элемент. При BMI 23.12 пользователи с английским языком устройства увидят «23.1», а с русским — «23,1». Чтобы показывать метку «High» только при BMI выше 25, добавьте текстовый элемент со словом «High» и задайте ему правило [условной видимости](onboarding-element-visibility): `bmi` **Greater than** `25`.

### Показать цену со скидкой \{#show-a-discounted-price\}

Создайте формулу `discounted`, которая уменьшает цену выбранного продукта на 20%:

```
{{products.selectedProduct.prod_price}} * 0.8
```

Затем создайте формулу `shown`, которая округляет результат до двух знаков после запятой:

```
round({{discounted}}, 2)
```

Вставьте `shown` в текстовый элемент. Для продукта с ценой 9.99 текст отобразит «7.99». Когда пользователь выбирает продукт с ценой 100, текст отобразит «80.00». Знак валюты не отображается. Если цена выбранного продукта не загрузилась, текст будет пустым.

### Отображение даты окончания пробного периода и напоминания \{#show-the-end-of-a-trial-and-a-reminder-date\}

Создайте формулу `trial_end`:

```
addOfferDuration(today(), {{products.selectedProduct}})
```

Затем создайте формулу `reminder` за три дня до окончания пробного периода:

```
addDays({{trial_end}}, -3)
```

Для продукта с 7-дневным пробным периодом 10 ноября 2026 года `trial_end` будет 17 ноября 2026 года, а `reminder` — 14 ноября 2026 года. С форматом даты **Medium** в тексте отобразится «Nov 17, 2026». С форматом **Month D** — «November 17».

### Показать рост в футах и дюймах \{#show-a-height-in-feet-and-inches\}

Добавьте поле ввода Number с идентификатором элемента `height` для роста в сантиметрах. Создайте три формулы:

- `total`: `round({{height.value}} / 2.54)` — рост в целых дюймах.
- `feet`: `floor({{total}} / 12)`.
- `inches`: `mod({{total}}, 12)`.

В текстовом элементе вставьте `feet`, введите «ft», вставьте `inches` и введите «in». Для 180 см текст покажет «5 ft 11 in». Для 140 см — «4 ft 7 in».

## Устранение неполадок \{#troubleshooting\}

Когда вы покидаете поле **Expression**, конструктор отображает первую ошибку формулы под полем. Несколько примеров:

| Текст ошибки | Причина и решение |
| :--- | :--- |
| `addDays() needs a date and a number` | Функция получила неверное количество аргументов или аргумент неправильного типа. Используйте аргументы из таблицы [Числовые функции](#number-functions) или [Функции дат](#date-functions). |
| `Unknown function "flor". Use one of: …` | Имя функции написано с ошибкой или не совпадает по регистру. Используйте функцию из списка в тексте ошибки. Чтобы обратиться к переменной, заключите её имя в `{{ }}`. |
| `Use a dot in a decimal number, like 1.5` | Число вне функции содержит запятую. Замените запятую на точку. Внутри функции запятая воспринимается как разделитель аргументов, поэтому там тоже используйте точку. |
| `{{…}} is not a variable, an answer or a product field of this flow` | Переменной, ID элемента или группы продуктов с таким именем не существует. Исправьте имя или создайте переменную. |
| `This variable no longer exists. Pick another one.` | Вы удалили переменную, которую использует формула. В выражении она отображается как `{{deleted variable}}`. Замените её другой ссылкой. |
| `{{…}} is the name of a variable and of an element answer: rename the variable` | Имя совпадает с двумя значениями. Переименуйте пользовательскую переменную. |
| `{{…}} uses this formula: formulas cannot use each other in a loop` | Две или более формул ссылаются друг на друга. Удалите одну из ссылок. |

<ZoomImage id="flow-formula-error.webp" width="300px" alt="Ошибка неизвестной функции под полем Expression со списком доступных функций" />

Формула с ошибкой блокирует публикацию. В диалоге **Can't publish yet** перечислены все формулы с ошибками в разделе **Variables**. Подробнее об ошибках, которые могут возникнуть при публикации, см. в разделе [Частые проблемы](flow-common-issues#a-flow-wont-preview-or-publish).

## Ограничения \{#limitations\}

- **Только числа и даты**: формула возвращает только число или дату. Чтобы отображать текст в зависимости от результата, добавьте [условный текст](onboarding-text#add-conditional-text) к текстовому элементу. Например, чтобы показывать «High» при ИМТ выше 25, задайте условие **if** как `bmi` **Greater than** `25`, а под **then** введите «High».
- **Цены продуктов**: формула считывает только цену выбранного продукта в каждой группе продуктов. Она не может считать цену продукта, который пользователь не выбрал, — например, месячный план, когда выбран годовой. Чтобы результат отображался при открытии экрана, выберите **Set as default** на одной из карточек продукта.
- **Офферы на iOS и Android**: на iOS SDK Adapty передаёт во флоу один оффер. Среди доступных пользователю офферов приоритет такой: сначала win-back offer, затем promotional offer, затем introductory offer. На Android SDK Adapty передаёт только первую фазу introductory offer. Если после бесплатного пробного периода следует сниженная цена, `addOfferDuration` на Android добавляет только пробный период.
