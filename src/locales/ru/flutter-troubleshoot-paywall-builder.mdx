Этот гайд поможет устранить распространённые проблемы при использовании пейволов, созданных в Adapty Paywall Builder, во Flutter SDK. По вопросам, связанным с флоу, обратитесь к разделу [Типичные проблемы](flow-common-issues).

## Получение конфигурации пейвола завершается ошибкой \{#getting-a-paywall-configuration-fails\}

**Проблема**: Метод `createPaywallView` не может получить конфигурацию пейвола.

**Причина**: Пейвол не включён для отображения на устройстве в Paywall Builder.

**Решение**: Включите переключатель **Show on device** в Paywall Builder.

## Количество просмотров пейвола слишком велико \{#the-paywall-view-number-is-too-big\}

**Проблема**: Счётчик просмотров пейвола показывает значение, вдвое превышающее ожидаемое.

**Причина**: Возможно, в вашем коде вызывается `logShowFlow` (Flutter SDK v4+) / `logShowPaywall`, что дублирует количество просмотров для пейвола, созданного в старом Paywall Builder. Adapty отслеживает эти просмотры автоматически, поэтому данный метод вызывать не нужно.

**Решение**: Убедитесь, что в вашем коде не вызывается `logShowFlow` (Flutter SDK v4+) / `logShowPaywall` для пейвола, созданного в старом Paywall Builder.

## Другие проблемы \{#other-issues\}

**Проблема**: У вас возникают другие проблемы, связанные с Paywall Builder, которые не описаны выше.

**Решение**: При необходимости обновите SDK до последней версии, следуя [гайдам по миграции](flutter-sdk-migration-guides). Многие проблемы уже исправлены в новых версиях SDK.
