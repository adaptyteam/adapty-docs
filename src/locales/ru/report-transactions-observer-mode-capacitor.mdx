<SDKv4>

В режиме Observer Adapty SDK не может самостоятельно отслеживать покупки, совершённые через вашу существующую систему. Вам нужно передавать транзакции из стора вручную. Важно настроить это **до** релиза приложения, чтобы избежать ошибок в аналитике.

Используйте `reportTransaction`, чтобы явно сообщать Adapty о каждой транзакции.

:::warning

**Не пропускайте передачу транзакций!**
Если вы не вызовете `reportTransaction`, Adapty не распознает транзакцию: она не появится в аналитике и не будет отправлена в интеграции.

:::

Если вы используете флоу и пейволы Adapty, передавайте `variationId` при регистрации транзакции. Это свяжет покупку с флоу или пейволом, который её инициировал, и обеспечит корректную аналитику.

```typescript showLineNumbers

const variationId = product.variationId; // the AdaptyPaywallProduct the user bought

try {
  await adapty.reportTransaction({ 
    transactionId: 'your_transaction_id',
    variationId: variationId 
  });
} catch (error) {
  console.error('Failed to report transaction:', error);
}
```

Параметры:

| Параметр     | Наличие | Описание                                                  |
| ------------- | -------- | ------------------------------------------------------------ |
| **transactionId** | обязательный | <ul><li> Для iOS: идентификатор транзакции.</li><li> Для Android: строковый идентификатор (`purchase.getOrderId`) покупки, где покупка — это экземпляр класса [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) из библиотеки биллинга.</li></ul> |
| **variationId**   | необязательный | Строковый идентификатор варианта. Передайте `variationId` продукта `AdaptyPaywallProduct`, который купил пользователь. Это то же значение, что и `variationId` объекта `AdaptyFlowPaywall`, содержащего данный продукт. | 
| **ios.jwsTransaction** | необязательный | Только для iOS, SDK 4.3.0 и выше. Подписанная транзакция StoreKit 2: `jwsRepresentation` результата её верификации для той же транзакции, что и `transactionId`. SDK отправляет его в Adapty без изменений. Android игнорирует этот параметр. |

На iOS, если ваша платёжная система возвращает транзакцию StoreKit 2, передайте её JWS-представление в `ios.jwsTransaction`:

```typescript showLineNumbers
await adapty.reportTransaction({
  transactionId: 'your_transaction_id',
  variationId: variationId, // optional
  ios: { jwsTransaction: 'YOUR_JWS_REPRESENTATION' }, // iOS only, optional
});
```

</SDKv4>

<SDKv3>

В режиме Observer Adapty SDK не может самостоятельно отслеживать покупки, совершённые через вашу существующую систему. Вам необходимо самостоятельно передавать транзакции из стора. Это важно настроить **до** публикации приложения, чтобы избежать ошибок в аналитике.

Используйте `reportTransaction`, чтобы явно сообщать Adapty о каждой транзакции.

:::warning

**Не пропускайте передачу транзакций!**
Если вы не вызываете `reportTransaction`, Adapty не распознает транзакцию, она не появится в аналитике и не будет отправлена в интеграции.

:::

Если вы используете флоу и пейволы Adapty, передавайте `variationId` при отправке транзакции. Это свяжет покупку с флоу или пейволом, который её инициировал, и обеспечит точную аналитику.

```typescript showLineNumbers

const variationId = paywall.variationId;

try {
  await adapty.reportTransaction({ 
    transactionId: 'your_transaction_id',
    variationId: variationId 
  });
} catch (error) {
  console.error('Failed to report transaction:', error);
}
```

Параметры:

| Параметр     | Наличие | Описание                                                  |
| ------------- | -------- | ------------------------------------------------------------ |
| **transactionId** | обязательный | <ul><li> Для iOS: идентификатор транзакции.</li><li> Для Android: строковый идентификатор (`purchase.getOrderId`) покупки, где покупка — это экземпляр класса [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) библиотеки биллинга.</li></ul> |
| **variationId**   | необязательный | Строковый идентификатор варианта. Его можно получить через свойство `variationId` объекта `AdaptyPaywall`. |

</SDKv3>
