:::warning
Apple может отклонить приложения, в которых переключатель пробного периода включён по умолчанию. Переключатель в положении «включено» может быть расценён как манипулятивный тёмный паттерн согласно Руководству по проверке App Store — он подразумевает согласие пользователя на бесплатный пробный период без явного выбора.

Чтобы избежать отклонения, установите переключатель в положение **выключено** по умолчанию и позвольте пользователям самостоятельно подключать пробный период.
:::

Переключатель триала — это бинарный переключатель, позволяющий пользователям выбирать между обычными продуктами и продуктами с пробным периодом на пейволе. При изменении состояния он может запускать действие — например, менять группы продуктов, обновлять переменные или показывать и скрывать элементы — мгновенно.

Чтобы добавить переключатель триала, нажмите **+** на нужном экране и выберите **Trial toggle**.

Каждый переключатель триала является выбираемым элементом, а его группа определяет переменную, отражающую его состояние:

- **Toggle** group: `<group>.isActive` — **True** или **False**.
- **Single choice** group: `<group>.selectedOptionId` — ID выбранного элемента, пустое пока ничего не выбрано.

Выберите переключатель и откройте вкладку **Interactions**, чтобы увидеть, к какой группе он относится.

Чтобы другие элементы реагировали на состояние переключателя, настройте условное [действие](onboarding-actions) или [условную видимость](onboarding-element-visibility) на основе этой переменной.

Ваше приложение также может [получать состояние переключателя через SDK](ios-flow-input). Каждый раз, когда пользователь переключает тогл, SDK передаёт его новое состояние в виде булевого значения, которое приложение может обработать внутри или на бэкенде.
