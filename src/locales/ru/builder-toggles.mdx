Категория **Toggle** включает три элемента, которые пользователь нажимает, чтобы включить или выключить что-либо:

- **Trial toggle**: переключатель, который переводит пейвол между стандартными продуктами и продуктами с пробным периодом.
- **Checkbox**: чекбокс с текстовой меткой — для согласий и подтверждений.
- **Toggle**: переключатель с текстовой меткой — для любого другого выбора вкл/выкл.

Чтобы добавить элемент, нажмите **+** на нужном экране, откройте **Paywall & Commerce** > **Toggle** и выберите элемент. Он появится в корне дерева слоёв — перетащите его в нужный контейнер на панели **Layers**.

:::note
В разделе **Basics** > **Checkmarks** тоже есть графика для чекбоксов, радиокнопок и переключателей. Это статические иконки для оформления строк внутри другого выбираемого элемента, например карточки продукта. Элементы из этой статьи используйте тогда, когда пользователь сам что-то выбирает.
:::

## Переключатель пробного периода \{#trial-toggle\}

:::warning
Apple может отклонить приложения, использующие заранее активированный переключатель пробного периода. Переключатель, включённый по умолчанию, может быть расценён как манипулятивный тёмный паттерн согласно правилам App Store Review Guidelines — он подразумевает согласие пользователя на пробный период без явного выбора.

Чтобы избежать отклонения, установите переключатель в положение **off** по умолчанию и дайте пользователям возможность самостоятельно активировать пробный период.
:::

Переключатель пробного периода позволяет пользователям выбирать между стандартными продуктами и продуктами с пробным периодом на пейволе. При изменении его состояния может срабатывать действие — например, замена группы продуктов, обновление переменных или скрытие/отображение элементов — мгновенно.

## Флажок \{#checkbox\}

Флажок с текстовой подписью, предзаполненной значением `I agree to the Terms and Privacy Policy`. Используйте его там, где пользователь должен подтвердить что-то, прежде чем флоу продолжится.

## Toggle \{#toggle\}

Переключатель с текстовой меткой. Используйте его для выбора «вкл/выкл», который не изменяет продукт, — например, для подписки на напоминания перед пейволом или для отображения дополнительного блока контента.

## Чтение состояния в условиях \{#read-the-state-in-conditions\}

Каждый из этих элементов является [выбираемым элементом](flow-selectable-elements), а его группа определяет переменную, отражающую его состояние:

- Группа **Toggle**: `<group>.isActive` — **True** или **False**.
- Группа **Single choice**: `<group>.selectedOptionId` — ID выбранного элемента, пустое значение, пока ничего не выбрано.

Выберите элемент и откройте вкладку **Interactions**, чтобы увидеть, к какой группе он относится.

Чтобы другие элементы зависели от состояния, задайте условное [действие](onboarding-actions) или [условную видимость](onboarding-element-visibility) на основе этой переменной.

Ваше приложение также может [получать состояние через SDK](ios-flow-input). Каждый раз, когда пользователь его изменяет, SDK передаёт новое значение, которое приложение может обработать внутри или на бэкенде.
