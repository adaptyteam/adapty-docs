Это руководство использует API Adapty Kotlin Multiplatform SDK v4 (beta). Если вы используете v3, ознакомьтесь с [руководством по миграции](migration-to-kmp-sdk-v4) для получения соответствующих имён методов.

Чтобы подключить встроенные покупки, вам нужно разобраться с тремя ключевыми концепциями:

- [**Продукты**](product) – всё, что пользователи могут купить (подписки, расходуемые покупки, пожизненный доступ)
- [**Флоу и пейволы**](adapty-flow-builder) – экраны для представления продуктов пользователям, созданные в конструкторе флоу и пейволов без кода. SDK получает их через `getFlow`. Если вы предпочитаете создавать UI в собственном коде, см. [Реализация кастомных пейволов](kmp-quickstart-manual).
- [**Плейсменты**](placements) – где и когда в приложении показываются флоу и пейволы (например, `main`, `onboarding`, `settings`). Вы привязываете их к плейсментам в дашборде, а затем запрашиваете по ID плейсмента в коде. Это упрощает запуск A/B-тестов и показ разного контента разным пользователям.

Adapty предлагает три способа подключить покупки в приложении. Выберите один из них в зависимости от требований вашего приложения:

| Реализация | Сложность | Когда использовать |
|---|---|---|
| Adapty Flow & Paywall Builder | ✅ Просто | Вы [создаёте готовый к покупкам флоу или пейвол в no-code конструкторе](quickstart-paywalls). Adapty автоматически отображает его и берёт на себя всю сложную логику покупок, валидацию чеков и управление подписками. |
| Кастомные пейволы | 🟡 Средне | Вы реализуете UI пейвола в коде своего приложения, но при этом получаете объект флоу из Adapty, сохраняя гибкость в управлении продуктами. См. [гайд](kmp-quickstart-manual). |
| Observer mode | 🔴 Сложно | У вас уже есть собственная инфраструктура обработки покупок, и вы хотите продолжать её использовать. Учтите, что observer mode имеет ряд ограничений в Adapty. См. [статью](observer-vs-full-mode). |

:::important
**Ниже описано, как реализовать флоу или пейвол, созданный в Adapty Flow & Paywall Builder.**

Если вы хотите создать UI пейвола самостоятельно, см. [Реализация кастомных пейволов](kmp-quickstart-manual).
:::

Чтобы отобразить флоу или пейвол, созданный в Adapty Flow & Paywall Builder, в коде приложения нужно:

1. **Получите флоу или пейвол**: Получите его из Adapty.
2. **Отобразите его — Adapty сам обработает покупки**: Покажите вью в вашем приложении.
3. **Обработайте действия кнопок**: Свяжите действия пользователя с реакцией вашего приложения. Например, открывайте ссылки или закрывайте пейвол при нажатии кнопок.

## Перед началом работы \{#before-you-start\}

Прежде чем начать, выполните следующие шаги:

1. Подключите приложение к [App Store](initial_ios) и/или [Google Play](initial-android) в дашборде Adapty.
2. [Создайте продукты](create-product) в Adapty.
3. [Создайте флоу или пейвол](paywall-builder-templates) и [добавьте в него продукты](paywall-product-block).
4. [Создайте плейсмент и добавьте в него флоу или пейвол](create-placement).
5. [Установите и активируйте SDK](sdk-installation-kotlin-multiplatform) в коде вашего приложения.

:::tip
Самый быстрый способ выполнить эти шаги — следовать [руководству по быстрому старту](quickstart) или создавать флоу и плейсменты с помощью [Developer CLI](developer-cli-quickstart).
:::

## 1. Получите флоу или пейвол \{#1-get-the-flow-or-paywall\}

Ваши флоу и пейволы связаны с плейсментами, настроенными в дашборде. Плейсменты позволяют показывать разные флоу или пейволы разным аудиториям или запускать [A/B-тесты](ab-tests).

Чтобы получить флоу или пейвол, созданный в Adapty Flow & Paywall Builder, необходимо:

1. Получить объект `flow` по ID [плейсмента](placements) с помощью метода `getFlow`.

2. Создайте представление флоу с помощью метода `createFlowView`. Представление содержит UI-элементы и стили, необходимые для отображения флоу. Если для флоу не настроено представление, `createFlowView` возвращает ошибку — обработайте её в `onError`.

:::important
Чтобы получить представление, [опубликуйте флоу или пейвол](builder-save-publish). Флоу или пейвол с неопубликованными изменениями имеет статус **Dirty**, и его плейсмент продолжает показывать последнюю опубликованную версию.
:::

```kotlin showLineNumbers
Adapty.getFlow("YOUR_PLACEMENT_ID")
    .onSuccess { flow ->
        AdaptyUI.createFlowView(flow)
            .onSuccess { view ->
                view.present()
            }
            .onError { error ->
                // the flow has no view configured, or view creation failed
            }
    }
    .onError { error ->
        // handle the error
    }
```

## 2. Отобразите флоу или пейвол \{#2-display-the-flow-or-paywall\}

Когда у вас есть флоу, достаточно добавить несколько строк, чтобы его отобразить.

Чтобы показать визуальный флоу на экране устройства, нужно сначала создать вью. Для этого вызовите метод `AdaptyUI.createFlowView()`:

```kotlin showLineNumbers
AdaptyUI.createFlowView(flow)
    .onSuccess { view ->
        view.present()
    }
    .onError { error ->
        // handle the error
    }
```

После успешного создания представления его можно отобразить на экране устройства. Каждое представление можно использовать только один раз: после вызова `dismiss()` вызовите `createFlowView` снова, чтобы показать флоу ещё раз.

:::tip
Подробнее о том, как отображать флоу или пейвол, см. в нашем [гайде](kmp-present-paywalls).
:::

## 3. Обработка действий кнопок \{#handle-button-actions\}

Когда пользователи нажимают кнопки во флоу или пейволе, Kotlin Multiplatform SDK автоматически обрабатывает покупки, восстановление, закрытие экрана и открытие ссылок.

Однако другие кнопки имеют пользовательские или заранее заданные идентификаторы и требуют обработки действий в вашем коде. Также вы можете переопределить их поведение по умолчанию.

Например, ниже показано поведение кнопки закрытия по умолчанию. Добавлять его в код не нужно, но здесь вы можете увидеть, как это делается при необходимости.

Обратите внимание, что по умолчанию флоу остаётся открытым после успешной покупки. Если вы хотите закрыть его после завершения покупки, скройте вью в колбэке `flowViewDidFinishPurchase`.

:::tip
Читайте наши гайды о том, как обрабатывать [действия](kmp-handle-paywall-actions) и [события](kmp-handling-events) кнопок.
:::

```kotlin showLineNumbers
AdaptyUI.setFlowsEventsObserver(object : AdaptyUIFlowsEventsObserver {
    override fun flowViewDidPerformAction(view: AdaptyUIFlowView, action: AdaptyUIAction) {
        when (action) {
            is AdaptyUIAction.CloseAction -> mainUiScope.launch { view.dismiss() }
            else -> Unit
        }
    }

    override fun flowViewDidFinishPurchase(
        view: AdaptyUIFlowView,
        product: AdaptyPaywallProduct,
        purchaseResult: AdaptyPurchaseResult
    ) {
        if (purchaseResult !is AdaptyPurchaseResult.UserCanceled) {
            mainUiScope.launch { view.dismiss() }
        }
    }
})
```

## Следующие шаги \{#next-steps\}

Ваш флоу или пейвол готов к отображению в приложении. Протестируйте покупки в [песочнице App Store](test-purchases-in-sandbox) или в [Google Play Store](testing-on-android), чтобы убедиться, что тестовая покупка проходит успешно.

Теперь нужно [проверить уровень доступа пользователей](kmp-check-subscription-status), чтобы корректно показывать пейвол или открывать доступ к платным функциям нужным пользователям.

## Полный пример \{#full-example\}

Вот как все эти шаги можно объединить в вашем приложении.

```kotlin showLineNumbers
// Set up the observer for handling flow events
AdaptyUI.setFlowsEventsObserver(object : AdaptyUIFlowsEventsObserver {
    override fun flowViewDidPerformAction(view: AdaptyUIFlowView, action: AdaptyUIAction) {
        when (action) {
            is AdaptyUIAction.CloseAction -> mainUiScope.launch { view.dismiss() }
            else -> Unit
        }
    }

    override fun flowViewDidFinishPurchase(
        view: AdaptyUIFlowView,
        product: AdaptyPaywallProduct,
        purchaseResult: AdaptyPurchaseResult
    ) {
        if (purchaseResult !is AdaptyPurchaseResult.UserCanceled) {
            mainUiScope.launch { view.dismiss() }
        }
    }
})

// Get and display the flow
Adapty.getFlow("YOUR_PLACEMENT_ID")
    .onSuccess { flow ->
        AdaptyUI.createFlowView(flow)
            .onSuccess { view ->
                view.present()
            }
            .onError { error ->
                // the flow has no view configured — use custom logic
            }
    }
    .onError { error ->
        // handle the error
    }
```
