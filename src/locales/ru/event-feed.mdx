Лента событий позволяет визуально отслеживать [события](events), генерируемые Adapty, и проверять статус их экспорта в сторонние интеграции, включая вебхук.

<ZoomImage id="event-status.webp" width="700px" alt="Лента событий со статусом доставки каждого события" />

:::note
Статус отправки для AppsFlyer, Facebook Ads и Branch может быть неточным, поскольку эти сервисы не всегда возвращают ошибки при их возникновении.
:::

Чтобы просмотреть профиль пользователя, инициировавшего транзакцию, нажмите кнопку **View Profile** в деталях события.

## Событие отсутствует в ленте \{#an-event-is-missing-from-the-feed\}

Есть три причины, по которым событие может не попасть в ленту.

- **Adapty не создал его.** Для большинства событий отключение типа в одной интеграции всё равно создаёт событие — просто со [статусом «серое»](event-statuses). Но есть два исключения:

1. Adapty не создаёт `access_level_updated`, если [интеграция с вебхуком](webhook) не настроена и не включена.
   2. Adapty не создаёт [синтетические события](events#synthetic-events), если пробная или обычная подписка уже не активна на момент проверки. См. [Синтетическое событие не пришло](handle-integration-errors#a-synthetic-event-never-arrived).

- **Событие существует, но не отображается в ленте.** Транзакции из серверного API v1 никогда не отображаются — используйте [серверный API (версия 2)](api-adapty/operations/setTransaction). Также не отображаются события без профиля: транзакции, которые поступили до того, как SDK идентифицировал пользователя, например уведомления от сервера стора. Чтобы включить их в экспорт, активируйте **Include events without profile** в настройках интеграции [S3](s3-exports) или [Google Cloud Storage](google-cloud-storage). Кроме того, не отображаются продления, которые Apple фиксирует заранее, — они [появятся, когда наступит соответствующий момент времени](how-profiles-work), хотя Adapty немедленно передаёт их в ваши интеграции.

- **Событие старше двух недель.** Лента хранит события только за последние две недели. Поэтому [синтетическое событие](events#synthetic-events) с большой задержкой может появиться без события `trial_started` или `subscription_started`, которое запустило его таймер.
