Adapty работает с AI-инструментами для написания кода и агентами. Используйте их, чтобы интегрировать SDK, задавать вопросы об аналитике или искать документацию Adapty — не выходя из редактора. На этой странице перечислено всё доступное и для кого каждый инструмент предназначен.

## Интеграция SDK Adapty с помощью ИИ \{#integrate-the-adapty-sdk-with-ai\}

Два способа добавить SDK Adapty в ваше приложение с помощью ИИ-инструментов для написания кода. Оба работают с Cursor, Claude и другими ИИ-ассистентами.

### Интеграция на основе скилла \{#skill-based-integration\}

Скилл интеграции Adapty SDK выполняет полную интеграцию из вашего AI-инструмента разработки одной командой. Используйте его, если хотите пройти настройку в автоматическом режиме с подсказками.

Выберите платформу: [iOS](adapty-sdk-integration-skill) · [Android](adapty-sdk-integration-skill-android) · [React Native](adapty-sdk-integration-skill-react-native) · [Flutter](adapty-sdk-integration-skill-flutter) · [Unity](adapty-sdk-integration-skill-unity) · [Kotlin Multiplatform](adapty-sdk-integration-skill-kmp) · [Capacitor](adapty-sdk-integration-skill-capacitor)

### Пошаговая интеграция \{#step-by-step-integration\}

Проведите AI-инструмент через этапы интеграции последовательно, предоставляя нужную документацию в правильном порядке. Используйте этот подход, если хотите проверять каждый шаг по мере выполнения.

Выберите платформу: [iOS](adapty-cursor) · [Android](adapty-cursor-android) · [React Native](adapty-cursor-react-native) · [Flutter](adapty-cursor-flutter) · [Unity](adapty-cursor-unity) · [Kotlin Multiplatform](adapty-cursor-kmp) · [Capacitor](adapty-cursor-capacitor)

## Миграция с RevenueCat с помощью ИИ \{#migrate-from-revenuecat-with-ai\}

Adapty CLI переносит каталог RevenueCat в новое приложение Adapty. Затем скилл `adapty-integration` поручает вашему агенту заменить SDK RevenueCat на идентификаторы, которые каталог получил в Adapty. См. [Миграция с RevenueCat](migration-from-revenuecat).

## Создание и редактирование флоу с помощью AI-инструмента для разработки \{#build-and-edit-flows-with-an-ai-coding-tool\}

Скилл [flow-generator](flow-generator-skill) редактирует флоу Adapty прямо из терминала — добавляет локаль, переписывает тексты, добавляет или убирает экраны, настраивает ветвление или создаёт пейвол по описанию. Каждое изменение проверяется и валидируется локально, после чего сохраняется как черновик для публикации.

Перед публикацией скилл [flow-audit](flow-audit-skill) анализирует тот же флоу и проверяет его готовность к продакшену — триггеры, соответствие требованиям стора, продукты и локализацию — и выдаёт итоговый результат: пройдено или нет.

Если ваше приложение уже работает с пейволами, [скилл migrate-placements](migrate-placements-skill) возьмёт миграцию на себя: он проинвентаризирует плейсменты ваших пейволов, сгруппирует их по пейволу, который каждый из них обслуживает, и создаст рядом с оригинальным плейсмент флоу для каждого из них.

## Управление Adapty из командной строки \{#manage-adapty-from-the-command-line\}

[Adapty Developer CLI](developer-cli-quickstart) позволяет управлять сущностями Adapty — приложениями, уровнями доступа, продуктами, пейволами, флоу и плейсментами — прямо из терминала, не открывая дашборд. Поскольку это инструмент командной строки, ваш AI-агент может запускать его напрямую.

## Дайте вашему AI-инструменту документацию Adapty \{#give-your-ai-tool-the-adapty-docs\}

### Документация в формате обычного текста

Каждая страница документации Adapty доступна в формате Markdown — добавьте `.md` к URL страницы или нажмите **Copy for LLM** под заголовком. Для более широкого контекста передайте вашему инструменту индекс [`llms.txt`](https://adapty.io/docs/ru/llms.txt) или подмножество для конкретной платформы, например [`ios-llms.txt`](https://adapty.io/docs/ru/ios-llms.txt).

### Context7

[Context7](https://context7.com/adaptyteam/adapty-docs) — это MCP-сервер, который передаёт документацию Adapty вашему AI-инструменту, однако индексирует только фрагменты кода, а не полный текст. Используйте его для быстрого поиска примеров кода; для полного руководства передайте инструменту обычный текст документации выше. Context7 работает с Cursor, Claude Code, Windsurf и другими MCP-совместимыми инструментами.
