Плагин Adapty обучает ваш ИИ-инструмент работе с Adapty. Установите его в Claude Code, Codex, Cursor, другой coding agent или claude.ai, а затем спросите на обычном языке: интегрировать SDK, создать пейвол, разобраться, почему упала выручка, или запустить A/B-тест. Плагин — это набор скиллов: проверенные рабочие процессы, по одному на каждый тип задачи. Это единственный продукт, который нужно установить. Он обращается к вашему аккаунту Adapty через Adapty MCP server или Adapty CLI, а в Claude Code и Codex автоматически добавляет MCP server — вам остаётся только войти в систему.

## Что даёт плагин \{#what-the-plugin-adds\}

AI-инструмент может получить доступ к вашему аккаунту Adapty через [сервер Adapty MCP](adapty-mcp) или [Adapty CLI](developer-cli-quickstart). Это позволяет ему читать и изменять ваши данные. Плагин снабжает его знаниями, необходимыми для правильной работы:

- **Правила конфигурации флоу**: флоу — это большой JSON-конфиг с правилами, которые существуют только в плагине. С ними ваш инструмент строит экраны из описания или скриншота, а также проверяет и предпросматривает каждое изменение перед сохранением флоу. Без них инструмент может читать и записывать конфиг флоу, но не может построить валидный.
- **Проверенные методы**: плагин знает, какие отчёты отвечают на тот или иной вопрос, как их читать и как ваши цифры соотносятся с рынком. Он превращает ваши метрики в гипотезы для A/B-тестов, отсортированные по потенциальному доходу.
- **Актуальные API Adapty**: при интеграции SDK плагин читает актуальную документацию Adapty на каждом этапе, поэтому ваш инструмент пишет код для той версии SDK, которую вы устанавливаете, а не для той, что хранится в его обучающих данных.
- **Подтверждение перед изменениями, которые затронут ваших пользователей**: перед запуском A/B-теста, изменением плейсмента или отправкой писем реальным людям плагин показывает, что именно изменится, и ждёт вашего подтверждения.
- **Подключение**: плагин определяет, есть ли у вашего инструмента MCP-сервер, CLI или оба, и выбирает наиболее подходящий для каждой задачи.

## Установка плагина \{#install-the-plugin\}

<Tabs groupId="ai-tool">
<TabItem value="coding-agent" label="Coding agent" default>

Плагин работает в любом coding agent с поддержкой скиллов: Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI и других.

Чтобы установить плагин, выполните в терминале:

```bash
npx adapty skills install
```

Перезапустите агента, чтобы загрузить плагин. О других способах установки читайте в [README плагина](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Claude Code не обновляет плагин автоматически. Чтобы получать новые скиллы по мере их выхода, в Claude Code выполните `/plugin`, откройте **Marketplaces**, выберите `adapty` и нажмите **Enable auto-update**.

В Claude Code и Codex плагин также добавляет MCP-сервер Adapty, поэтому вам достаточно войти в систему, как описано в разделе [Подключение ассистента](adapty-mcp#connect-your-assistant). В других агентах при первом обращении скилла к вашему аккаунту плагин предложит выбрать: использовать Adapty CLI или MCP-сервер — и покажет шаги по настройке выбранного варианта.

</TabItem>

<TabItem value="claude-ai" label="claude.ai">

Плагин устанавливается через настройки Claude — командная строка не нужна. Шаги одинаковы для Claude desktop.

1. В Claude откройте **Settings** → **Plugins**.
2. Нажмите **Add** → **Add marketplace**.
3. Выберите **Add from a repository**.
4. В поле **URL** введите `adaptyteam/adapty-skills` и выберите репозиторий. Чтобы получать новые скиллы и исправления по мере их выхода, оставьте включённым **Sync automatically**.
5. Нажмите **Sync**.

<ZoomImage id="adapty-skills-claude-add-marketplace.png" width="584px" alt="Add marketplace dialog in Claude with adaptyteam/adapty-skills in the URL field and Sync automatically turned on" />

Claude открывает вкладку **Discover** с плагинами из маркетплейса Adapty. Чтобы установить плагин, в строке **Adapty** нажмите **Add**.

<ZoomImage id="adapty-skills-claude-discover.png" width="600px" alt="Discover tab in Claude listing the Adapty, Apple ads, and Apple ads benchmarks plugins, each with an Add button" />

Плагин запускает свои скрипты в песочнице Claude. Чтобы разрешить это, в **Settings** → **Capabilities** включите **Code execution and file creation**.

Чтобы предоставить Claude доступ к вашему аккаунту Adapty, добавьте MCP-сервер Adapty в качестве коннектора и войдите в систему, как описано в разделе [Подключите ассистента](adapty-mcp#connect-your-assistant).

## Что можно делать \{#what-you-can-do\}

Называть скилл необязательно. Опишите задачу так, как объяснили бы коллеге, — плагин сам выберет нужный флоу.

### Интеграция SDK

```
Integrate Adapty into my app
```

Плагин настраивает ваше приложение в дашборде Adapty, устанавливает SDK, добавляет пейвол и проверяет каждый этап перед переходом к следующему. Он автоматически определяет вашу платформу. Смотрите гайд для [iOS](adapty-sdk-integration-skill), [Android](adapty-sdk-integration-skill-android), [React Native](adapty-sdk-integration-skill-react-native), [Flutter](adapty-sdk-integration-skill-flutter), [Unity](adapty-sdk-integration-skill-unity), [Kotlin Multiplatform](adapty-sdk-integration-skill-kmp) или [Capacitor](adapty-sdk-integration-skill-capacitor).

### Создание и редактирование флоу

```
Add a German locale to my onboarding flow
```

Плагин [создаёт и редактирует флоу](flow-generator-skill): добавляет локали, переписывает тексты, добавляет или удаляет экраны, настраивает ветвление квизов и собирает пейвол из описания. Перед публикацией он [проверяет флоу](flow-audit-skill) на наличие триггеров, соответствие требованиям сторов, продукты и локализацию. Если в ваших плейсментах показываются пейволы, плагин [переносит их во флоу](migrate-placements-skill).

### Найдите, что тестировать дальше \{#find-what-to-test-next\}

```
Audit my app. What should I test next to grow revenue?
```

Плагин [читает вашу аналитику, цены и прошлые A/B-тесты](export-analytics-with-ai), оценивает каждую часть вашего бизнеса относительно рынка и возвращает гипотезы, отсортированные по потенциальному влиянию на выручку. Он также отвечает на простые вопросы о ваших данных — например, почему в прошлом месяце упали обновления подписок.

### Запуск A/B-тестов \{#run-ab-tests\}

```
Start a 50/50 test of my two onboarding paywalls
```

Плагин [создаёт, запускает, останавливает и заменяет A/B-тесты](ab-tests-skill) для пейволов и флоу.

### Анализируйте свои рекламные кампании \{#analyze-your-ad-campaigns\}

```
Which campaigns should I scale, and which should I cut?
```

Плагин [считывает данные атрибуции Adapty](developer-cli-attribution-skill): ROAS, окупаемость, стоимость триала и возвраты по каналам, кампаниям и странам.

:::tip
Для кампаний Apple Ads есть отдельный плагин. См. [Управление Apple Ads с помощью AI-инструмента](developer-cli-ads-manager-skill).
:::

### Запустить Adapty Mail

```
Why didn't this user get the welcome email?
```

Плагин [подключает MCP-сервер Adapty Mail](mail-skill), запускает email-флоу и выясняет, почему письмо не было отправлено. Перед любым действием, затрагивающим реальных пользователей, он запрашивает подтверждение.

### Переход с RevenueCat

```
Move my RevenueCat project to Adapty
```

Ваш coding agent копирует каталог RevenueCat и дизайны пейволов в новое приложение Adapty, а затем заменяет SDK RevenueCat в вашем коде на вызовы с соответствующими ID Adapty. См. [Миграция с RevenueCat](migration-from-revenuecat).

## Как плагин подключается к вашему аккаунту \{#how-the-plugin-reaches-your-account\}

Плагин работает через два подключения. Если ни одного из них нет, плагин спрашивает, какое из них настроить, и объясняет шаги. Когда оба доступны, он выбирает нужное для каждой задачи:

- **[Adapty MCP server](adapty-mcp)**: Подключение для claude.ai, Claude Desktop и coding-агентов с поддержкой MCP. Вы входите через браузер под своим аккаунтом Adapty. API-ключ не нужен.
- **[Adapty CLI](developer-cli-quickstart)**: Подключение для coding-агентов, которые выполняют команды в терминале. Флоу и аналитические воркфлоу предпочитают его, так как работают с локальными файлами. Вы также можете запускать CLI вручную или из собственных скриптов.

## Создайте бэкенд с помощью ИИ \{#build-your-backend-with-ai\}

Эти два гайда предназначены для кода, который вы пишете для своего собственного сервера. Скопируйте гайд в ваш ИИ-инструмент для написания кода, и он получит готовый к запуску код, нюансы полей и ограничения в одной вставке:

- [Обработка событий подписки](handle-webhooks-with-ai): получение вебхуков Adapty на вашем эндпоинте.
- [Проверка и предоставление доступа к подписке](server-side-api-with-ai): вызов серверного API Adapty из вашего бэкенда.

## Дайте вашему AI-инструменту документацию Adapty \{#give-your-ai-tool-the-adapty-docs\}

### Документация в формате обычного текста

Каждая страница документации Adapty доступна в формате Markdown — добавьте `.md` к URL страницы или нажмите **Copy for LLM** под заголовком. Для более широкого контекста передайте вашему инструменту индекс [`llms.txt`](https://adapty.io/docs/ru/llms.txt) или подмножество для конкретной платформы, например [`ios-llms.txt`](https://adapty.io/docs/ru/ios-llms.txt).

### Context7

[Context7](https://context7.com/adaptyteam/adapty-docs) — это MCP-сервер, который предоставляет документацию Adapty вашему AI-инструменту, но индексирует только фрагменты кода, а не полный текст. Используйте его для быстрого поиска примеров кода; для полного руководства передайте инструменту [документацию в текстовом формате](#plain-text-docs). Context7 работает только с документацией; для работы с вашим аккаунтом [установите плагин Adapty](#install-the-plugin).
