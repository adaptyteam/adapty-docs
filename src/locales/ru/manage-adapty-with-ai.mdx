Adapty совместим с ИИ-инструментами для разработки и агентами. Используйте их для интеграции SDK, получения ответов по аналитике или поиска в документации Adapty, не выходя из редактора. На этой странице перечислено всё доступное и описано, для кого предназначен каждый инструмент.

## Интеграция SDK Adapty с помощью ИИ \{#integrate-the-adapty-sdk-with-ai\}

Есть два способа подключить SDK Adapty к приложению с помощью ИИ-инструмента. Оба работают с Cursor, Claude и другими ИИ-ассистентами.

### Интеграция на основе скиллов \{#skill-based-integration\}

Скилл интеграции SDK Adapty выполняет всю интеграцию из вашего ИИ-инструмента одной командой. Используйте его, если хотите автоматизированную настройку с подсказками.

Выберите платформу: [iOS](adapty-sdk-integration-skill) · [Android](adapty-sdk-integration-skill-android) · [React Native](adapty-sdk-integration-skill-react-native) · [Flutter](adapty-sdk-integration-skill-flutter) · [Unity](adapty-sdk-integration-skill-unity) · [Kotlin Multiplatform](adapty-sdk-integration-skill-kmp) · [Capacitor](adapty-sdk-integration-skill-capacitor)

### Пошаговая интеграция \{#step-by-step-integration\}

Проведите свой ИИ-инструмент через интеграцию поэтапно, передавая нужную документацию в правильном порядке. Используйте этот способ, если хотите проверять каждый шаг по мере выполнения.

Выберите платформу: [iOS](adapty-cursor) · [Android](adapty-cursor-android) · [React Native](adapty-cursor-react-native) · [Flutter](adapty-cursor-flutter) · [Unity](adapty-cursor-unity) · [Kotlin Multiplatform](adapty-cursor-kmp) · [Capacitor](adapty-cursor-capacitor)

## Создание и редактирование флоу с помощью ИИ-инструмента \{#build-and-edit-flows-with-an-ai-coding-tool\}

[Скилл flow-generator](flow-generator-skill) редактирует ваши флоу Adapty прямо из терминала — добавляет локаль, переписывает тексты, добавляет или удаляет экраны, настраивает ветвление или создаёт пейвол по описанию. Он предварительно просматривает и проверяет каждое изменение локально, затем сохраняет черновик для публикации.

Перед публикацией [скилл flow-audit](flow-audit-skill) анализирует тот же флоу и проверяет его готовность к production — триггеры, соответствие требованиям стора, продукты и локализацию — и выносит итоговый вердикт: пройдено или нет.

Если ваше приложение уже работает на пейволах, [скилл migrate-placements](migrate-placements-skill) поможет с переходом: он инвентаризирует ваши плейсменты пейволов, группирует их по пейволу, который каждый из них обслуживает, и создаёт флоу-плейсмент для каждого рядом с оригинальным.

## Управление Adapty из командной строки \{#manage-adapty-from-the-command-line\}

[Adapty Developer CLI](developer-cli-quickstart) позволяет управлять сущностями Adapty — приложениями, уровнями доступа, продуктами, пейволами, флоу и плейсментами — из терминала, без открытия дашборда. Поскольку это инструмент командной строки, ваш ИИ-агент может запускать его напрямую.

## Подключение документации Adapty к вашему ИИ-инструменту \{#give-your-ai-tool-the-adapty-docs\}

### Документация в формате обычного текста \{#plain-text-docs\}

Каждая страница документации Adapty доступна в формате Markdown — добавьте `.md` к URL страницы или нажмите **Copy for LLM** под заголовком. Для более широкого контекста передайте инструменту индекс [`llms.txt`](https://adapty.io/docs/ru/llms.txt) или подмножество для конкретной платформы, например [`ios-llms.txt`](https://adapty.io/docs/ru/ios-llms.txt).

### Context7 \{#context7\}

[Context7](https://context7.com/adaptyteam/adapty-docs) — это MCP-сервер, который передаёт документацию Adapty вашему ИИ-инструменту, однако он индексирует только фрагменты кода, а не полный текст. Используйте его для быстрых примеров кода; для полноценного руководства передавайте инструменту документацию в формате обычного текста, описанную выше. Context7 работает с Cursor, Claude Code, Windsurf и другими совместимыми с MCP инструментами.
