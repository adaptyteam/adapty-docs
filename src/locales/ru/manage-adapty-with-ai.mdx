Adapty работает с ИИ-инструментами для написания кода и агентами. С их помощью можно интегрировать SDK, задавать вопросы по аналитике или искать документацию Adapty, не выходя из редактора. На этой странице перечислены доступные инструменты и то, для кого каждый из них предназначен.

## Интеграция Adapty SDK с помощью ИИ \{#integrate-the-adapty-sdk-with-ai\}

Два способа добавить Adapty SDK в ваше приложение с помощью ИИ-инструмента для кодирования. Оба работают с Cursor, Claude и другими ИИ-ассистентами.

### Интеграция с помощью скилла \{#skill-based-integration\}

Скилл интеграции Adapty SDK проведёт вас через весь процесс настройки прямо из вашего AI-инструмента для написания кода — одной командой. Используйте его, когда хотите получить пошаговую автоматизированную настройку.

Выберите платформу: [iOS](adapty-sdk-integration-skill) · [Android](adapty-sdk-integration-skill-android) · [React Native](adapty-sdk-integration-skill-react-native) · [Flutter](adapty-sdk-integration-skill-flutter) · [Unity](adapty-sdk-integration-skill-unity) · [Kotlin Multiplatform](adapty-sdk-integration-skill-kmp) · [Capacitor](adapty-sdk-integration-skill-capacitor)

### Пошаговая интеграция \{#step-by-step-integration\}

Пройдите интеграцию с вашим AI-инструментом поэтапно — подавайте нужные документы в правильном порядке. Используйте этот подход, если хотите проверять каждый шаг по мере выполнения.

Выберите платформу: [iOS](adapty-cursor) · [Android](adapty-cursor-android) · [React Native](adapty-cursor-react-native) · [Flutter](adapty-cursor-flutter) · [Unity](adapty-cursor-unity) · [Kotlin Multiplatform](adapty-cursor-kmp) · [Capacitor](adapty-cursor-capacitor)

## Создавайте и редактируйте флоу с помощью AI-инструмента для кода \{#build-and-edit-flows-with-an-ai-coding-tool\}

Навык [flow-generator](flow-generator-skill) редактирует ваши флоу Adapty прямо из терминала — добавляет локаль, переписывает текст, добавляет или удаляет экраны, настраивает ветвление или создаёт пейвол по описанию. Он локально просматривает и проверяет каждое изменение, а затем сохраняет черновик для публикации.

Перед публикацией навык [flow-audit](flow-audit-skill) читает тот же флоу и проверяет его готовность к продакшену — триггеры, соответствие требованиям стора, продукты и локализацию — и выносит итоговый вердикт: пройдено или нет.

## Управление Adapty из командной строки \{#manage-adapty-from-the-command-line\}

[Adapty Developer CLI](developer-cli-quickstart) позволяет управлять сущностями Adapty — приложениями, уровнями доступа, продуктами, пейволами и плейсментами — прямо из терминала, не открывая дашборд. Поскольку это инструмент командной строки, ваш AI-агент может запускать его напрямую.

## Спросите об аналитике своих данных \{#ask-about-your-data\}

Подключите AI-агент к Export Analytics API, чтобы запрашивать метрики на простом языке — выручку, удержание, LTV и многое другое. MCP-сервер не нужен.

## Дайте своему AI-инструменту доступ к документации Adapty

### Документация в формате обычного текста

Каждая страница документации Adapty доступна в формате Markdown — добавьте `.md` к URL страницы или нажмите **Copy for LLM** под заголовком. Для более широкого контекста передайте своему инструменту индексный файл [`llms.txt`](https://adapty.io/docs/ru/llms.txt) или подмножество для конкретной платформы, например [`ios-llms.txt`](https://adapty.io/docs/ru/ios-llms.txt).

### Context7

[Context7](https://context7.com/adaptyteam/adapty-docs) is an MCP server that serves Adapty docs to your AI tool, but it indexes only code snippets — not the full prose. Use it for quick code examples; for complete guidance, give your tool the plain-text docs above. Context7 works with Cursor, Claude Code, Windsurf, and other MCP-compatible tools.
