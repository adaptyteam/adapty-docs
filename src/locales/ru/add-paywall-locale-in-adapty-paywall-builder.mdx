Вы можете локализовать свой флоу, чтобы предоставлять международным пользователям контент на их языке. Можно перевести или настроить следующее:

- Любую строку во флоу.
- [URL каждого действия **Open URL**](#action-urls).
- Изображения и видео — с [отдельным файлом для каждой локали](#images-and-videos).

В панели <Inline id="localizations.svg" alt="Localizations" /> **Localizations** весь контент собран в одну таблицу, где каждому языку соответствует отдельный столбец. Там можно переводить ячейки вручную, с помощью AI или экспортировать их для стороннего переводчика.

<ZoomImage id="locales-table.webp" width="700px" alt="Localizations panel with the locale tabs, the filters, and the localization table" />

Чтобы показать пользователям локаль, ваше приложение [должно передать код локали](localizations-and-locale-codes) в [запросе конфигурации флоу](get-pb-paywalls#fetch-the-view-configuration). Значения без перевода используют контент из локали по умолчанию (английской, если вы не [задали другую локаль как основную](#set-the-default-locale)).

:::tip
Сначала настройте флоу в локали по умолчанию, и только потом добавляйте другие языки.
:::

## Что можно локализовать \{#what-you-can-localize\}

### Текстовый контент \{#text-content\}

Панель **Localizations** содержит строку для каждого текстового элемента флоу, в том числе:

- Содержимое каждого текстового элемента, например подпись кнопки.
- **Placeholder** каждого поля ввода.
- Заголовок и сообщение каждого действия **Show alert**.

:::note
То, что [переменная](onboarding-variables) показывает в других локалях, зависит от источника её значения:

- **Переменные продукта**: стор возвращает их значения уже локализованными. Строка, содержащая только переменную продукта — например, цену, — не требует перевода.
- **Переменные элементов и пользовательские переменные**: их значения нельзя локализовать. Например, `selectedOptionTitle` отображает **Element Title** выбранного варианта именно в том виде, в котором вы его ввели. Вместо этого используйте статический или условный текст.
:::

### Условный текст \{#conditional-text\}

Текстовые элементы могут отображать [разный контент](onboarding-text#add-conditional-text) в зависимости от заданных условий. Каждую ветку условного текста можно локализовать.

:::note
Условия одинаковы во всех локалях. Если условие сравнивает переменную со строкой, эта строка не локализуется.
:::

### URL действий \{#action-urls\}

Действие **Open URL** может открывать разные URL в каждой локали флоу — например, страницу справки на языке пользователя. Если для локали пользователя альтернативный URL не задан, отображается URL по умолчанию.

### Изображения и видео \{#images-and-videos\}

Элементы изображений и видео могут отображать [разный файл для каждой локали](#localize-images-and-videos). Если вы не загрузите файл для локали пользователя, он увидит файл по умолчанию. В панели **Localizations** строка по-прежнему будет иметь значок **Missing**. Если файл по умолчанию подходит для всех локалей, [отметьте строку как выполненную](#manage-a-row), чтобы убрать значок. Иконки и [фоны экранов и контейнеров](custom-media#limitations) локализовать нельзя.

## Управление локализациями и переводами \{#manage-localizations-and-translations\}

### Добавление и настройка локали \{#add-and-set-up-a-locale\}

1. Откройте панель <Inline id="localizations.svg" alt="Localizations" /> Localizations слева. Нажмите **Add locale**.
2. В поле **Select languages** выберите один или несколько языков.
3. (Необязательно) Чтобы сразу перевести флоу на новые локали, выберите **Translate content from default locale using AI**.
4. Нажмите **Add locales**.

<ZoomImage id="new-locale-flow.webp" width="500px" alt="Add locales dialog" />

В таблице локализации каждая локаль — это столбец, а каждый элемент [локализуемого контента](#what-you-can-localize) — строка. Строки в таблице сгруппированы по экранам.

<ZoomImage id="locales-sidebar.webp" width="250px" float="right" alt="Вкладки локалей на боковой панели Localizations с булавкой на дефолтной локали и процентом на каждой другой локали" />

Боковая панель показывает прогресс по каждой локали в виде процента переведённых ячеек. Заголовок раздела каждого экрана показывает прогресс этого экрана по всем локалям. Панель считает ячейку переведённой, как только в ней появляется значение — даже если это текст из локали по умолчанию, без перевода. Если вы [отметите строку](#manage-a-row) как Done или Missing, именно эта отметка определяет статус строки, независимо от содержимого ячеек.

Строка с отсутствующим переводом отображается с бейджем **Missing**. Ячейка без значения для конкретной локали показывает содержимое локали по умолчанию.

### Перевод строк с помощью ИИ \{#translate-strings-with-ai\}

ИИ переводит строки с основной локали на другие локали. [URL действий](#action-urls), изображения и видео он не переводит.

Откройте **AI Translate** в шапке панели и выберите один из следующих вариантов:

- **Translate missing only**: Переводит только ячейки без перевода и сохраняет существующие переводы. Если вы [пометили строку как Missing](#manage-a-row), она будет переведена заново полностью. Если строка помечена как Done, она пропускается.
- **Translate all**: Переводит все ячейки и заменяет существующие переводы, включая те, что вы редактировали вручную.

<ZoomImage id="locales-ai-translate.webp" width="700px" alt="AI Translate menu in the Localizations panel header, with Translate missing only and Translate all" />

Вы можете переводить только те строки, которые отображаются после применения [фильтров](#filter-rows). Чтобы перевести только часть строк или локалей, сначала отметьте их флажками.

Если AI-перевод изменяет переменную или форматирование текста, Adapty отклоняет такой перевод и оставляет в ячейке предыдущее значение.

### Установите язык по умолчанию \{#set-the-default-locale\}

Значок булавки <Inline id="pin.svg" alt="Pin" /> отмечает язык по умолчанию. В нём хранится исходный контент, и он используется как резервный при отсутствии переводов. Каждый флоу начинается с английского языка в качестве единственного и языка по умолчанию.

Прежде чем менять язык по умолчанию, заполните замену переводами. Если новый язык окажется неполным в момент назначения его языком по умолчанию, Adapty заполнит его содержимым из предыдущего языка по умолчанию. Поля больше не будут отображаться как **Missing**.

Чтобы изменить язык по умолчанию, в заголовке столбца нужного языка откройте **Locale actions** и выберите **Set as default**.

<ZoomImage id="flow-builder-set-default-locale.webp" width="500px" alt="Locale actions menu of a locale column, with Set as default highlighted" />

Если очистить содержимое элемента в языке по умолчанию, пользователи других языков по-прежнему будут видеть контент на своём языке, если он задан. Чтобы удалить его тоже, [сбросьте строку](#manage-a-row) в панели **Localizations**.

### Удаление локали \{#delete-a-locale\}

Чтобы удалить локаль, откройте **Locale actions** в заголовке её столбца и выберите **Delete locale**. Adapty удалит весь контент, связанный с этой локалью, включая изображения и видео. Чтобы восстановить локаль, отмените удаление. Чтобы удалить локаль по умолчанию, сначала [сделайте другую локаль основной](#set-the-default-locale).

### Действия с таблицей

Вы можете изменить множество ячеек за одну операцию — одна отмена вернёт все изменения.

#### Фильтрация строк

Задайте фильтры на боковой панели, чтобы ограничить отображаемые строки:

- **Screens** — Ограничивает выборку экранов {/*, and hides reusable components*/}.
- **Status** > **Missing only** — Показывает только строки со значком **Missing**.

Чтобы найти строки по ключевому слову, нажмите **Search** в заголовке панели. Таблица покажет только те строки, в которых ключевое слово встречается в тексте или имени файла любой локали.

Массовые действия применяются только к видимым строкам. Когда фильтр включён, область применения массовых действий ограничена. Чтобы перевести или сбросить весь локаль или весь флоу, сначала отключите фильтры и очистите поиск.

#### Управление локалью \{#manage-a-locale\}

Чтобы массово управлять содержимым одного локаля, наведите курсор на заголовок его столбца и откройте контекстное меню столбца <Inline id="context.svg" alt="Locale actions" />:

- **Set as default**: Делает локаль [локалью по умолчанию](#set-the-default-locale).
- **Import** и **Export**: Импорт или экспорт [файла переводов](#localize-content-externally) локали.
- **AI Translate locale**: Переводит весь столбец локали из локали по умолчанию [с помощью ИИ](#translate-strings-with-ai).
- **AI Translate missing only**: Переводит пустые ячейки локали [с помощью ИИ](#translate-strings-with-ai).
- **Reset to default (…)**: Удаляет весь специфичный для локали контент из столбца локали.
- **Delete locale**: [Удаляет локаль и её контент](#delete-a-locale).

<ZoomImage id="flow-builder-set-default-locale.webp" width="500px" alt="Locale actions menu of a locale column" />

#### Управление строкой \{#manage-a-row\}

Чтобы массово управлять содержимым отдельной строки, откройте контекстное меню строки <Inline id="context.svg" alt="Row context menu" />:

- **Mark as Done** или **Mark as Missing**: Вручную устанавливает статус строки, независимо от содержимого ячеек. Например, пометьте название бренда как **Done**, если оно не требует перевода.
- **AI Translate missing only**: Переводит пустые ячейки строки [с помощью ИИ](#translate-strings-with-ai).
- **AI Translate row**: Переводит всю строку из локали по умолчанию [с помощью ИИ](#translate-strings-with-ai).
- **Reset to default**: Удаляет весь контент, специфичный для локали, из строки.

Когда вы редактируете текст локали по умолчанию, Adapty снимает отметку **Done** со строки.

<ZoomImage id="locales-row-menu.webp" width="600px" alt="Контекстное меню строки с пунктами Mark as Done, AI Translate missing only, AI Translate row и Reset to default" />

#### Действия с ячейками \{#cell-actions\}

Откройте контекстное меню ячейки <Inline id="context.svg" alt="Контекстное меню ячейки" />, чтобы управлять отдельным значением:

- **Add variable**: Вставляет [переменную](onboarding-variables) в ячейку.
- **Copy** и **Paste here**: Копирует значение ячейки вместе с форматированием и переменными и вставляет его в другую ячейку.
- **AI Translate**: Переводит ячейку [с помощью ИИ](#translate-strings-with-ai).
- **Push value to all locales**: Копирует значение ячейки во все остальные локали, кроме локали по умолчанию. Если после этого вы отредактируете ячейку, значение нужно будет распространить повторно.
- **Clear translation**: Очищает ячейку, и пользователи с соответствующей локалью видят текст локали по умолчанию.

<ZoomImage id="locales-cell-menu.webp" width="400px" alt="Панель инструментов ячейки и её контекстное меню с пунктами Add variable, Copy, Paste here, AI Translate, Push value to all locales и Clear translation" />

## Локализация контента в конструкторе \{#localize-content-in-the-builder\}

Чтобы перевести строки и задать URL-адреса для действий, откройте панель **Localizations**. Вы можете [перевести их вручную](#translate-strings-manually), [с помощью ИИ](#translate-strings-with-ai) или [экспортировать файл локализации](#localize-content-externally) для работы со сторонним переводчиком.

Для локализации изображений и видео [загрузите файл для каждой локали](#localize-images-and-videos).

### Переводите строки вручную \{#translate-strings-manually\}

Таблица на панели **Localizations** содержит все строки флоу:

- Статичный текст (по одной строке на элемент)
- Условный текст (по одной строке на ветку)
- Целевые URL действия **Open URL** (по одной строке на URL)

Чтобы перевести строку, кликните по ячейке и введите перевод. Чтобы вставить [переменную](onboarding-variables), нажмите **{ }** в ячейке. Чтобы найти строку нужного элемента, [выберите его](builder-ui#preview-area-center) в превью.

Каждый элемент условного текста — это отдельная группа строк. Нажмите стрелку <Inline id="expand-layer.svg" alt="Expand" />, чтобы развернуть группу и просмотреть все ветки условий.

<ZoomImage id="locales-conditional-text.webp" width="700px" alt="Условный текст, развёрнутый на панели локализаций: отдельная строка для каждой ветки и её переводов" />

### Установите URL действия для конкретного языка \{#set-locale-specific-action-urls\}

Каждое действие **Open URL** имеет отдельную строку. Чтобы задать другой [URL](#action-urls) для определённого языка, кликните на пустое место в ячейке этого языка и введите URL. Не кликайте по самому URL — иначе он откроется в новой вкладке. Чтобы узнать, какому элементу принадлежит URL, кликните по его строке: builder выделит этот элемент в предпросмотре.

### Локализация изображений и видео \{#localize-images-and-videos\}

Чтобы показывать другое изображение или видео в определённой локали, загрузите отдельный файл для этой локали. На панели **Localizations** наведите курсор на ячейку нужной локали в строке с изображением или видео и нажмите **Replace**. Чтобы вернуться к файлу локали по умолчанию, нажмите **Reset**.

<ZoomImage id="locales-media-cell.webp" width="500px" alt="Image cell in the Localizations panel with the Open image, Replace, Download, and Reset buttons, and its context menu" />

Также можно [загрузить файл в панели свойств](custom-media#localize-media), выбрав нужную локаль на нижней панели инструментов.

<ZoomImage id="image-localization-demo.webp" width="500px" alt="Canvas image changing as the active locale changes" />

## Локализация контента с помощью внешних инструментов \{#localize-content-externally\}

Чтобы перевести весь текст флоу за пределами Adapty — например, с помощью переводческого сервиса или собственных переводчиков — [экспортируйте файл локализации](#export-the-localization-file). Когда перевод будет готов, [импортируйте](#import-the-file-with-a-translation) файл обратно.

### Экспорт файла локализации \{#export-the-localization-file\}

Чтобы экспортировать весь флоу со всеми локалями, нажмите **Import / Export** в заголовке панели и выберите **Export**. Чтобы экспортировать отдельную локаль вместе с исходной, выберите **Export** в [контекстном меню столбца](#manage-a-locale).

<ZoomImage id="import-export.webp" width="700px" alt="Меню Import / Export в заголовке панели Localizations" />

### Формат файла импорта / экспорта \{#import--export-file-format\}

Файл локализации — это файл `.tsv` (с разделением табуляцией) в кодировке UTF-8, в котором каждая строка соответствует одному тексту или URL действия. Экспортируемый файл охватывает весь флоу, независимо от фильтров, выбранных на панели. Чтобы импортировать файл, сохраните его формат без изменений. Столбцы:

| Столбец | Описание |
|--------|-------------|
| `id` | Идентификатор строки. Adapty сопоставляет строки по нему при импорте, поэтому не изменяйте его. Adapty игнорирует строки с `id`, которого нет во флоу. |
| `Screen` | Экран{/* or reusable component*/}, которому принадлежит строка. Adapty игнорирует этот столбец при импорте. |
| `[locale]` | По одному столбцу на каждую локаль, названному по её коду (например, `en`, `fr`). Adapty игнорирует столбцы для локалей, которых нет во флоу. |

Пример:

```
id	Screen	en	fr	es
lc_1	Welcome	Turn words into art	Transformez les mots en art
lc_2	Welcome	Start your <b>free trial</b>	Commencez votre <b>essai gratuit</b>
lc_3	Quiz	What will you create?
```

В экспортированном файле:

- Форматирование передаётся HTML-тегами, например `<b>`, а переменные — как `{{name}}`. Оставляйте их нетронутыми: Adapty восстанавливает их при импорте.
- Каждая ветка [условного текста](#conditional-text) выводится отдельной строкой, без указания условия.
- Изображения и видео не включаются: их [локализуют в конструкторе](#localize-images-and-videos).

Чтобы перевести строки, добавленные после экспорта, экспортируйте файл повторно.

Adapty не может импортировать файл в старом формате со столбцами `Screen`, `Element` и `Property`. Чтобы повторно использовать уже добавленные переводы, экспортируйте флоу снова и скопируйте их в новый файл.

### Импортируйте файл с переводом \{#import-the-file-with-a-translation\}

:::warning
Если ячейка в файле пустая, Adapty удаляет перевод этой ячейки при импорте — за исключением столбца с локалью по умолчанию. Чтобы сохранить переводы локали, оставьте её ячейки такими, как при экспорте, или удалите её столбец из файла. Если после импорта были удалены нужные переводы, отмените его: весь импорт отменяется за один шаг.
:::

Чтобы импортировать флоу целиком, нажмите **Import / Export** в заголовке панели и выберите **Import**. Чтобы импортировать одну локаль, выберите **Import** в [контекстном меню её столбца](#manage-a-locale). Затем выберите переведённый файл.

Строки без соответствующей строки в файле сохраняют текущие значения. Импорт целого флоу обновляет текст локали по умолчанию там, где файл вносит изменения. Импорт одной локали изменяет только ту локаль, которую вы импортируете. Чтобы импортировать новый язык, сначала [добавьте его локаль](#add-and-set-up-a-locale).

## Предпросмотр разных локалей \{#preview-different-locales\}

Текст в области предпросмотра всегда отображается на активной локали. Если вы редактируете текстовый контент в панели свойств, эти изменения применяются только к этой локали. Переключитесь обратно на локаль по умолчанию, чтобы редактировать исходный контент.

- Чтобы переключить активную локаль, выберите её в выпадающем списке **Locale** на [нижней панели инструментов](builder-ui#view-controls-bottom-toolbar) или кликните по её вкладке в панели **Localizations**.
- Чтобы переключить активный экран из панели **Localizations**, нажмите **View screen** <Inline id="eye.svg" alt="View screen" /> в заголовке соответствующего раздела.
- Чтобы развернуть таблицу локализации на весь экран, нажмите **Hide preview**.

<ZoomImage id="preview-locales.webp" width="500px" alt="Locale preview in Flow & Paywall Builder" />

Чтобы найти непереведённый текст, не просматривая каждый экран вручную, запустите [скилл flow-audit](flow-audit-skill).
