Локализация флоу делает их доступными на нескольких языках. В Flow Builder локализация организована по экранам — каждый из них показывает процент выполнения для отслеживания прогресса перевода.

:::tip
Завершите настройку флоу в локали по умолчанию, прежде чем добавлять другие языки.
:::
## Добавление и настройка локализации \{#add-and-set-up-localization\}

1. На левой панели нажмите <Inline id="localizations.svg" alt="Localizations" />. Затем нажмите **Add locale**. Выберите языки для добавления.

<ZoomImage id="new-locale-flow.webp" width="500px" alt="Add locale dialog" />

2. Каждый добавленный язык отображается в виде столбца в таблице локализации, предзаполненного значениями языка по умолчанию.

3. Чтобы сосредоточиться только на незаполненных полях, включите переключатель **Missing only** на левой панели. Таблица отфильтруется и покажет только непереведённые строки.

<ZoomImage id="locales-table.webp" width="700px" alt="Localization table" />
## Установите язык по умолчанию \{#set-the-default-locale\}

Язык по умолчанию содержит исходный контент и используется как запасной вариант для отсутствующих переводов. Каждый флоу начинается с английского языка в качестве единственного языка по умолчанию.

Значок булавки <Inline id="pin.svg" alt="Pin" /> обозначает язык по умолчанию. Удалить язык по умолчанию нельзя, пока другой язык не будет назначен языком по умолчанию.

Чтобы изменить язык по умолчанию, откройте контекстное меню <Inline id="context.svg" alt="Context menu" /> в заголовке столбца нужного языка и выберите **Set as default**.

<ZoomImage id="flow-builder-set-default-locale.webp" width="700px" alt="Меню колонки языка с выбранным пунктом «Установить по умолчанию»" />

## Экспорт и импорт для внешнего перевода \{#export-and-import-for-external-translation\}

Вы можете экспортировать файл локализации, чтобы передать его переводчикам, и затем импортировать переведённый результат.

На верхней панели инструментов нажмите **Import / Export**.

<ZoomImage id="import-export.webp" width="700px" />

### Формат экспортируемого файла \{#export-file-format\}

При экспорте создаётся файл `.tsv` (значения, разделённые табуляцией), где каждая строка соответствует одному переводимому элементу. Столбцы:

| Столбец | Описание |
|--------|-------------|
| `Screen` | Экран, которому принадлежит элемент (например, `Welcome`, `Quiz`) |
| `Element` | Автоматически сгенерированный идентификатор элемента на этом экране. Его можно изменить в **Interactions** > **Element ID**. |
| `Property` | Тип свойства (например, `content`) |
| `[default_locale]` | Код языка по умолчанию (например, `en`) |
| `[locale]` | По одному столбцу на каждую добавленную локаль (например, `fr`, `es`) |

Пример:
:::note
Оставляйте столбцы локалей пустыми для непереведённых строк — Adapty будет считать их отсутствующими.
:::
### Требования к файлу импорта

- **Формат**: `.tsv` (значения, разделённые табуляцией)
- **Заголовки**: должны содержать столбцы `Screen`, `Element`, `Property` и хотя бы один столбец с локалью
- **Названия столбцов с локалями**: должны совпадать с кодами локалей, уже добавленных во флоу. Если файл содержит коды локалей, отсутствующие во флоу, импорт завершится ошибкой.
- **Частичный импорт**: можно включить только часть строк — строки, не вошедшие в файл, сохранят текущие значения
### Ограничения \{#limitations\}

- При экспорте переменные удаляются из строк. Если вы повторно импортируете эти данные, переменные придётся добавить вручную.
- Экспортируемый файл содержит только строки — для локализации медиафайлов см. [Локализация изображений и видео](#localize-images-and-videos).

## Переводите вручную \{#translate-manually\}

Вы также можете вводить переводы прямо в любую ячейку таблицы локализации.

Чтобы управлять конкретной строкой, откройте её контекстное меню <Inline id="context.svg" alt="Context menu" />:

- **Reset to default**: Сбрасывает перевод строки до значений языка по умолчанию.

## Локализация изображений и видео \{#localize-images-and-videos\}

Изображения и видео можно локализовать, загружая разные файлы для каждой локали.

1. Активируйте нужную локаль — под канвасом или в панели локализации.
2. Выберите элемент с изображением или видео.
3. Загрузите локализованный файл в панели свойств.

Медиаэлементы без локализованных файлов будут отображать файл локали по умолчанию.
