Локализация флоу позволяет отображать их на нескольких языках. В Flow & Paywall Builder локализация организована по экранам — для каждого из них отображается процент завершения перевода.

:::tip
Перед добавлением других языков сначала завершите настройку флоу в локали по умолчанию.
:::

## Добавление и настройка локализации \{#add-and-set-up-localization\}

1. На левой панели нажмите <Inline id="localizations.svg" alt="Localizations" />. Затем нажмите **Add locale** и выберите нужные языки.

<ZoomImage id="new-locale-flow.webp" width="500px" alt="Add locale dialog" />

2. Каждая добавленная локаль появляется в таблице локализации в виде отдельного столбца, предзаполненного значениями из языка по умолчанию.

3. Чтобы сосредоточиться только на незаполненных строках, включите переключатель **Missing only** на левой панели. Таблица отфильтрует и покажет только непереведённые строки.

<ZoomImage id="locales-table.webp" width="700px" alt="Localization table" />

## Установка локали по умолчанию \{#set-the-default-locale\}

Локаль по умолчанию содержит исходный контент и используется как запасной вариант при отсутствии переводов. Каждый флоу начинается с английского языка в качестве единственной локали по умолчанию.

Значок булавки <Inline id="pin.svg" alt="Pin" /> обозначает локаль по умолчанию. Удалить её нельзя, пока другая локаль не будет назначена локалью по умолчанию.

Чтобы изменить локаль по умолчанию, откройте контекстное меню <Inline id="context.svg" alt="Context menu" /> в заголовке столбца нужной локали и выберите **Set as default**.

<ZoomImage id="flow-builder-set-default-locale.webp" width="700px" alt="Locale column menu with Set as default selected" />

## Экспорт и импорт для внешнего перевода \{#export-and-import-for-external-translation\}

Вы можете экспортировать файл локализации для передачи переводчикам и импортировать готовые переводы.

На верхней панели инструментов нажмите **Import / Export**.

<ZoomImage id="import-export.webp" width="700px" />

### Формат экспортируемого файла \{#export-file-format\}

При экспорте создаётся файл `.tsv` (с разделителями-табуляциями), содержащий по одной строке на каждый переводимый элемент. Столбцы:

| Столбец | Описание |
|--------|-------------|
| `Screen` | Экран, которому принадлежит элемент (например, `Welcome`, `Quiz`) |
| `Element` | Автоматически сгенерированный идентификатор элемента на этом экране. Его можно изменить в **Interactions** > **Element ID**. |
| `Property` | Тип свойства (например, `content`) |
| `[default_locale]` | Языковой код локали по умолчанию (например, `en`) |
| `[locale]` | По одному столбцу на каждую добавленную локаль (например, `fr`, `es`) |

Пример:

```
Screen	Element	Property	en	fr	es
Welcome	title	content	Turn words into art	Transformez les mots en art
Welcome	subtitle	content	Create stunning images in seconds with AI	Créez des images en quelques secondes
Quiz	quiz-title	content	What will you create?
```

:::note
Оставляйте столбцы локалей пустыми для непереведённых строк — Adapty будет расценивать их как отсутствующие.
:::

### Требования к импортируемому файлу \{#import-file-requirements\}

- **Формат**: `.tsv` (значения, разделённые табуляцией)
- **Заголовки**: должны включать `Screen`, `Element`, `Property` и хотя бы один столбец локали
- **Названия столбцов локалей**: должны совпадать с кодами локалей, уже добавленных во флоу. Импорт файла с кодами локалей, отсутствующими во флоу, приведёт к ошибке.
- **Частичный импорт**: можно включить только подмножество строк; строки, отсутствующие в файле, сохранят текущие значения

### Ограничения \{#limitations\}

- При экспорте переменные удаляются из строк. Если вы импортируете эти данные обратно, переменные нужно будет добавить вручную.
- Экспортируемый файл содержит только текстовые строки — для локализации медиафайлов см. раздел [Локализация изображений и видео](#localize-images-and-videos).

## Ручной перевод \{#translate-manually\}

Вы также можете вводить переводы напрямую в любую ячейку таблицы локализации.

Для управления конкретной строкой откройте её контекстное меню <Inline id="context.svg" alt="Context menu" />:

- **Reset to default**: откатывает перевод строки к значениям из языка по умолчанию.

## Локализация изображений и видео \{#localize-images-and-videos\}

Изображения и видео можно локализовать, загрузив разные файлы для каждой локали.

1. Активируйте нужную локаль — под холстом или на панели локализации.
2. Выберите элемент изображения или видео.
3. Загрузите локализованный файл на панели свойств.

Медиаэлементы без локализованных файлов будут отображать файл локали по умолчанию.

<ZoomImage id="image-localization-demo.webp" width="500px" alt="Canvas image changing as the active locale changes" />


## Предпросмотр локализации \{#preview-the-localization\}

Чтобы проверить переводы, переключите активную локаль в Flow & Paywall Builder и просмотрите каждый экран.

<ZoomImage id="preview-locales.webp" width="500px" alt="Locale preview in Flow & Paywall Builder" />

Чтобы проверить охват всех локалей сразу, а не экран за экраном, воспользуйтесь [скиллом flow-audit](flow-audit-skill) — он покажет пустые переводы и непереведённые значения по всему флоу.
