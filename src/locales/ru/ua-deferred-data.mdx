Отложенные диплинки позволяют передавать пользовательские данные в приложение, когда пользователи устанавливают его после перехода по вашей рекламе. Например, можно сразу после установки и запуска направить их в нужный раздел приложения.

:::important
Начиная с версии Adapty SDK 4.1, Adapty Attribution отключена по умолчанию. Коллбэк `onInstallationDetailsSuccess` срабатывает только после того, как вы [включите Adapty Attribution при активации SDK](user-acquisition#step-1-enable-adapty-attribution-in-the-sdk).
:::

Вот как это работает:

1. Когда пользователь нажимает на вашу рекламу, Adapty сохраняет данные о клике.
2. Когда Adapty регистрирует событие установки, он получает отложенные данные о клике.
3. После того как пользователь устанавливает приложение и запускает его впервые, Adapty извлекает сохранённые данные, и ваше приложение получает пользовательские параметры, что позволяет реагировать на различные значения в коде приложения.

Приложение получает отложенные данные только в том случае, если Adapty связывает установку с кликом. Если пользователь, у которого уже установлено ваше приложение, нажимает на рекламу, приложение не получает новых отложенных данных.

На iOS Adapty сопоставляет установку с кликом только в том случае, если оба события пришли с одного диапазона IP-адресов. Например, клик по Wi-Fi и первый запуск по мобильной сети не будут сопоставлены, и ваше приложение не получит отложенные данные.

Adapty поддерживает следующие параметры отложенных данных:

- `ios_deferred_data`
- `android_deferred_data`
- `deferred_data_sub[1-10]`

Чтобы добавить параметры отложенных данных, добавьте их к вашей ссылке в настройках кампании:

1. Если ваша кампания запущена в Meta Ads или TikTok, найдите ссылку для отслеживания в **Integrations** > **Meta Ads** или **TikTok Ads**. Если кампания настроена на другую платформу, откройте **Integrations** > **Custom**. Затем скопируйте нужную ссылку.

<ZoomImage id="ua-lnk.webp" width="900px" />

2. В рекламной платформе (Meta, TikTok, Google Ads и т. д.) вставьте ссылку в поле URL назначения объявления, затем добавьте к ней параметры отложенных данных в виде дополнительных query-параметров — каждый с префиксом `&`. Например, чтобы показать iOS-пользователям экран «Welcome» после установки, добавьте `&ios_deferred_data=welcome`. Итоговый URL назначения будет выглядеть так:

```
https://api-ua.adapty.io/api/v1/attribution/c/YOUR_CODE?campaign_id=__CAMPAIGN_ID__&adset_id=__AID__&ad_id=__CID__&campaign_name=__CAMPAIGN_NAME__&adset_name=__AID_NAME__&ad_name=__CID_NAME__&redirect_url=__APP_LINK__&ios_deferred_data=welcome
```

3. Обработайте параметры в коде приложения. SDK передаёт их в свойстве `payload` сведений об установке:
   - **iOS**: считайте их из `payload.dictionary`.
   - **Android**: считайте их из `payload.dataMap`.
   - **React Native и Flutter**: `payload` — это JSON-строка, поэтому сначала распарсите её.

Вот как, например, можно обработать установки, у которых `ios_deferred_data` равно `welcome`:

<TabItem value="swift" label="Swift" default>

```swift showLineNumbers
Adapty.delegate = self

nonisolated func onInstallationDetailsSuccess(_ details: AdaptyInstallationDetails) {
    guard
        let deeplink = details.payload?.dictionary?["ios_deferred_data"] as? String,
        deeplink == "welcome"
    else { return }

    DispatchQueue.main.async {
        print("Navigate to welcome screen")
        // navigate to your screen here
    }
}
```

<TabItem value="android" label="Kotlin">

```kotlin showLineNumbers
Adapty.setOnInstallationDetailsListener(object : OnInstallationDetailsListener {
    override fun onInstallationDetailsSuccess(details: AdaptyInstallationDetails) {
        if (details.payload?.dataMap?.get("android_deferred_data") == "welcome") {
            println("Navigate to welcome screen")
            // navigate here
        }
    }

    override fun onInstallationDetailsFailure(error: AdaptyError) {
        // handle the error
    }
})

```

```typescript showLineNumbers
adapty.addEventListener('onInstallationDetailsSuccess', details => {
    // Parse the payload JSON and navigate to welcome screen if needed
    try {
        if (details.payload) {
            const payload = JSON.parse(details.payload);
            if (payload.ios_deferred_data === 'welcome') {
                // Navigate to welcome screen
                // Replace with your app's navigation logic
                // For example, using React Navigation:
                // navigation.navigate('Welcome');
                console.log('Navigate to welcome screen');
            }
        }
    } catch (error) {
        console.error('Error parsing installation details payload:', error);
    }
});
```

<TabItem value="flutter" label="Flutter">

```dart showLineNumbers
Adapty().onUpdateInstallationDetailsSuccessStream.listen((details) {
  final payloadStr = details.payload;
  if (payloadStr == null) return;

  final payload = json.decode(payloadStr) as Map<String, dynamic>;
  if (payload['ios_deferred_data'] == 'welcome') {
    print('Navigate to welcome screen');
  }
});

```
