## Прежде чем начать \{#before-you-start\}

- Обновите приложение до Adapty Flutter SDK 4.4 или новее. В более ранних версиях SDK для каждого кастомного элемента отображается [резервный контент](flow-custom-elements#set-fallback-content).
- Настройте приложение для [получения](flutter-get-pb-paywalls) и [отображения](flutter-present-paywalls) флоу.
- Настройте нативный код приложения для кастомных элементов, как описано в [гайде для Flutter](flutter-flow-custom-elements#before-you-start).
- На iOS добавьте Lottie в таргет `Runner` в Xcode через Swift Package Manager из `https://github.com/airbnb/lottie-spm.git`.
- На Android настройте Jetpack Compose в модуле приложения. Вью анимации в этом рецепте является composable. Добавьте Lottie для Jetpack Compose в приложение через Gradle из `com.airbnb.android:lottie-compose`.

## 2. Добавьте файл анимации в приложение \{#add-the-animation-file-to-your-app\}

Нативный код считывает файл анимации из проектов iOS и Android, а не из папки `assets` Flutter:

- **iOS**: Добавьте файл в таргет `Runner` в Xcode.
- **Android**: Поместите файл в `android/app/src/main/assets` — папку `assets` модуля Android-приложения. Храните файл в корне этой папки, а не во вложенных директориях.

Имя файла без `.json` должно совпадать с ID пользовательского элемента, например `streak_ring.json` для `streak_ring`.

## 3. Создайте анимированный экран \{#create-the-animation-view\}

Создайте модель для серии и экран, который воспроизводит анимацию. Ваше приложение обновляет модель при изменении серии. Экран читает модель, поэтому кольцо отображает текущую серию при открытии экрана:

<Tabs groupId="platform" queryString>
<TabItem value="ios" label="iOS (Swift)" default>

```swift showLineNumbers title="Swift"

// The streak that your app keeps up to date
@MainActor
final class StreakStore: ObservableObject {
    @Published var currentStreak = 0 // days in a row
}

struct StreakRingView: View {
    let animation: LottieAnimation
    @ObservedObject var streakStore: StreakStore

    // 7 days fill the ring: from 0 for an empty ring to 1 for a full one
    private var progress: AnimationProgressTime {
        min(AnimationProgressTime(streakStore.currentStreak) / 7, 1)
    }

    var body: some View {
        LottieView(animation: animation)
            .resizable()
            .playing(.fromProgress(0, toProgress: progress, loopMode: .playOnce))
    }
}
```

`.playing(.fromProgress(0, toProgress: progress, loopMode: .playOnce))` заполняет кольцо один раз — от пустого состояния до значения `progress`.

</TabItem>
<TabItem value="android" label="Android (Kotlin)">

```kotlin showLineNumbers title="Kotlin"

// the streak that your app keeps up to date
class StreakStore {
    val currentStreak = MutableStateFlow(0) // days in a row
}

@Composable
fun StreakRing(animationFile: String, streakStore: StreakStore) {
    val composition by rememberLottieComposition(LottieCompositionSpec.Asset(animationFile))
    val streak by streakStore.currentStreak.collectAsState()

    // 7 days fill the ring: from 0 for an empty ring to 1 for a full one
    val progress = minOf(streak / 7f, 1f)

    LottieAnimation(
        composition = composition,
        modifier = Modifier.fillMaxSize(), // scale the animation to fit the custom element
        clipSpec = LottieClipSpec.Progress(0f, progress),
    )
}
```

`clipSpec = LottieClipSpec.Progress(0f, progress)` заполняет кольцо один раз — от пустого до значения `progress`.

## 4. Привяжите анимацию к кастомному элементу \{#match-the-animation-to-the-custom-element\}

В вашем [глобальном резолвере](flutter-flow-custom-elements#pass-the-resolver-to-the-sdk) добавьте свойство для модели серии. Затем верните анимацию для типа `lottie_animation` и идентификатора `streak_ring`. Выделенные строки показывают, что нужно добавить или изменить. Если в вашем приложении ещё нет глобального [резолвера](flutter-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views), скопируйте весь код целиком:

<Tabs groupId="platform" queryString>
<TabItem value="ios" label="iOS (Swift)" default>

```swift showLineNumbers title="Swift" {6,14-18}

struct CustomElementsResolver: AdaptyUICustomElementsResolver {
    let streakStore: StreakStore

    func view(
        forType type: String,
        id: String,
        context: AdaptyUICustomElementContext
    ) -> AnyView? {
        switch type {
        case "lottie_animation" where id == "streak_ring":
            guard let animation = LottieAnimation.named(id) else {
                return nil // no animation file: show the fallback
            }
            return AnyView(StreakRingView(animation: animation, streakStore: streakStore))
        // the other cases of your resolver
        default:
            return nil
        }
    }
}
```

Поставьте кейс `streak_ring` перед всеми остальными кейсами `lottie_animation`, потому что Swift выполняет только первый подходящий кейс. Если в бандле приложения нет файла для данного ID, резолвер возвращает `nil`, и пользователи видят фолбэк.

</TabItem>
<TabItem value="android" label="Android (Kotlin)">

```kotlin showLineNumbers title="Kotlin" {8,22-28}

class CustomElementsResolver(
    context: Context,
    private val streakStore: StreakStore,
) : AdaptyCustomElementsResolver {
    // the animation files in the assets folder, listed once
    private val animationFiles: Set<String> = try {
        context.assets.list("").orEmpty().toSet()
    } catch (e: IOException) {
        emptySet() // no list of files: every Lottie element shows the fallback
    }

    override fun resolve(type: String, id: String): AdaptyCustomElementContent? =
        when (type) {
            "lottie_animation" -> {
                // the ID names the animation file, such as streak_ring.json
                val file = "$id.json"
                when {
                    file !in animationFiles -> null // no file for this ID: show the fallback
                    id == "streak_ring" ->
                        AdaptyCustomElementContent.compose { StreakRing(file, streakStore) }
                    // the other animations of your resolver
                    else -> null
                }
            }
            // the other Types of your resolver
            else -> null
        }
}
```

Если в папке `assets` нет файла с нужным ID, резолвер возвращает `null`, и пользователи видят фолбэк. Если ваш резолвер уже возвращает [представление для каждого файла анимации](flutter-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views), возвращайте это представление вместо `null`, когда ID не равен `streak_ring`. Так пользователи по-прежнему будут видеть анимации остальных кастомных элементов `lottie_animation`.

## 5. Отправьте счётчик серий из вашего Dart-кода \{#5-send-the-streak-from-your-dart-code\}

Ваш Dart-код хранит счётчик серий, а нативные представления читают его из модели серий. Чтобы обновить модель, отправьте значение счётчика в нативный код через [platform channel](https://docs.flutter.dev/platform-integration/platform-channels). В коде iOS и Android подпишитесь на этот канал:

<Tabs groupId="platform" queryString>
<TabItem value="ios" label="iOS (Swift)" default>

В методе `didInitializeImplicitFlutterEngine` класса `AppDelegate` добавьте выделенные строки:

```swift showLineNumbers title="ios/Runner/AppDelegate.swift" {3-14}
func didInitializeImplicitFlutterEngine(_ engineBridge: FlutterImplicitEngineBridge) {
  GeneratedPluginRegistrant.register(with: engineBridge.pluginRegistry)
  let streakChannel = FlutterMethodChannel(
    name: "custom_elements/streak",
    binaryMessenger: engineBridge.applicationRegistrar.messenger()
  )
  streakChannel.setMethodCallHandler { [streakStore] call, result in
    guard call.method == "setStreak", let days = call.arguments as? Int else {
      return result(FlutterMethodNotImplemented)
    }
    // the channel calls this handler on the main thread
    MainActor.assumeIsolated { streakStore.currentStreak = days }
    result(nil)
  }
}
```

:::note
Код `AppDelegate` в этом рецепте соответствует iOS-шаблону Flutter 3.41 и более поздних версий, в котором используется `FlutterImplicitEngineDelegate`. Если ваш класс `AppDelegate` не использует этот протокол, уберите его и метод `didInitializeImplicitFlutterEngine`. Вместо этого создайте канал в `application(_:didFinishLaunchingWithOptions:)` до вызова `return super.application(...)`, используя мессенджер корневого контроллера представления. Сохраните вызов `GeneratedPluginRegistrant` из вашего шаблона:

```swift showLineNumbers title="ios/Runner/AppDelegate.swift"
GeneratedPluginRegistrant.register(with: self)
let controller = window?.rootViewController as! FlutterViewController
let streakChannel = FlutterMethodChannel(
  name: "custom_elements/streak",
  binaryMessenger: controller.binaryMessenger
)
```
:::

</TabItem>
<TabItem value="android" label="Android (Kotlin)">

В классе `MainActivity` переопределите метод `configureFlutterEngine`:

```kotlin showLineNumbers title="Kotlin"

class MainActivity : FlutterFragmentActivity() {
    override fun configureFlutterEngine(flutterEngine: FlutterEngine) {
        super.configureFlutterEngine(flutterEngine)
        val streakStore = (application as App).streakStore
        MethodChannel(flutterEngine.dartExecutor.binaryMessenger, "custom_elements/streak")
            .setMethodCallHandler { call, result ->
                if (call.method == "setStreak") {
                    streakStore.currentStreak.value = call.arguments as Int
                    result.success(null)
                } else {
                    result.notImplemented()
                }
            }
    }
}
```

</TabItem>
</Tabs>

В вашем коде на Dart отправляйте стрик при запуске приложения и каждый раз, когда он изменяется:

```dart showLineNumbers title="Flutter"

// your iOS and Android code listens to this channel
const streakChannel = MethodChannel('custom_elements/streak');

// call at app launch, and each time the streak changes
Future<void> sendStreak(int days) async {
  await streakChannel.invokeMethod('setStreak', days);
}
```
