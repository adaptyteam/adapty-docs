Интеграция Adapty Attribution с Amazon S3 позволяет надёжно хранить данные о кампаниях по привлечению пользователей в одном месте. Adapty Attribution сохраняет файлы .csv в ваш бакет Amazon S3. Каждая строка соответствует одной установке приложения и содержит идентификаторы устройства и данные атрибуции: канал, кампанию и т. д. Финансовые данные — рекламные расходы, доходы или информация о покупках — в файлы не включаются.

Чтобы настроить интеграцию, выполните несколько простых шагов в AWS Console и дашборде Adapty Attribution.

:::note
Adapty Attribution экспортирует один набор файлов за каждый календарный день. Планировщик экспорта запускается три раза в день — в **02:00**, **04:00** и **06:00 UTC**. Каждый запуск либо создаёт задание экспорта за предыдущий день (если оно ещё не существует), либо повторяет его, если более ранний запуск завершился ошибкой. Таким образом, ваши данные, как правило, появляются после запуска в 02:00, а последующие запуски предназначены для восстановления после сбоев, а не для добавления новых данных.

Каждый экспорт охватывает установки, зафиксированные Adapty Attribution за предыдущий календарный день по UTC. Например, экспорт за 8 марта содержит установки, записанные 7 марта с 00:00:00 до 23:59:59 UTC.

Каждый файл отражает атрибуцию на момент экспорта. В течение до 30 дней после установки Adapty Attribution может переатрибутировать установку на другой канал или кампанию. Чтобы обновить более старые файлы с текущей атрибуцией, [запустите экспорт вручную](#manual-data-export) для нужных дат.
:::

:::warning
Запланированный экспорт выполняется только для компаний на платном плане или в пробном периоде. Если ваша компания не относится ни к одной из этих категорий, планировщик пропустит задачу и не запишет ни одного файла, даже если интеграция включена в дашборде. Если ваш бакет пуст и конфигурация выглядит правильно, сначала проверьте статус вашего плана.
:::

## Как настроить интеграцию с Amazon S3 \{#how-to-set-up-amazon-s3-integration\}

Для получения данных вам потребуются следующие учётные данные:

1. Access key ID
2. Secret access key
3. Название бакета S3
4. Название папки внутри бакета S3

:::note
Вложенные директории

В поле названия бакета Amazon S3 можно указывать вложенные директории, например: adapty-ua-events/com.sample-app
:::

### Шаг 2. Настройка интеграции в Adapty Attribution

1. Перейдите в [**Integrations** -> **Amazon S3**](https://app.adapty.io/ua/integrations/s3)
2. Включите переключатель **Export install events to Amazon S3**.
3. Заполните следующие поля, чтобы установить связь между Amazon S3 и профилями Adapty Attribution:

| Поле                         | Описание                                                     |
|:-----------------------------| :----------------------------------------------------------- |
| **Access Key ID**            | Уникальный идентификатор для аутентификации пользователя или приложения при доступе к сервису AWS. Найдите этот идентификатор в скачанном [csv-файле](ua-amazon-s3#step-1-create-amazon-s3-credentials). |
| **Secret Access Key**        | Приватный ключ, используемый вместе с Access Key ID для аутентификации при доступе к сервису AWS. Найдите этот ключ в скачанном [csv-файле](ua-amazon-s3#step-1-create-amazon-s3-credentials). |
| **S3 Bucket Name**           | Глобально уникальное имя, идентифицирующее конкретный бакет S3 в облаке AWS. Бакеты S3 — это простое хранилище, позволяющее загружать и получать объекты данных (файлы, изображения и т. д.) в облаке. |
| **Folder Inside the Bucker** | Имя папки, которую вы хотите создать внутри выбранного бакета S3. Обратите внимание, что S3 эмулирует папки с помощью префиксов ключей объектов, которые по сути и являются именами папок. |
| **Region** (опционально)      | Узнайте ваш регион в консоли управления AWS в разделе вашего IAM-аккаунта.                                                                                                                                                                                  |

## Экспорт данных вручную \{#manual-data-export\}

Чтобы экспортировать данные за более ранние даты, в разделе **Manual file export** выберите диапазон дат и нажмите **Export to S3**. Если в вашем бакете уже есть файлы за эти даты, Adapty Attribution заменит их.

## Структура таблицы \{#table-structure\}

В каждом файле содержится по одной строке на каждую установку, зафиксированную атрибуцией Adapty за один день по UTC, с данными об устройстве и атрибуцией. Файлы не содержат данных о расходах на рекламу, доходах или покупках.

:::warning
Обратите внимание, что эта структура может расширяться со временем — по мере добавления новых данных нами или третьими сторонами, с которыми мы работаем. Убедитесь, что ваш код обработки достаточно устойчив и опирается на конкретные поля, а не на структуру в целом.
:::
