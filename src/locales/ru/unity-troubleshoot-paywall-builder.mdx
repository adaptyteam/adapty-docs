Этот гайд поможет вам решить распространённые проблемы при использовании пейволов, созданных в Paywall Builder Adapty, в Unity SDK. Если у вас возникли проблемы с флоу, см. [Распространённые проблемы](flow-common-issues).

## Ошибка при получении конфигурации пейвола \{#getting-a-paywall-configuration-fails\}

**Проблема**: Метод `CreateView` не может получить конфигурацию пейвола.

**Причина**: Пейвол не включён для отображения на устройстве в Paywall Builder.

**Решение**: Включите переключатель **Show on device** в Paywall Builder.

## Число просмотров пейвола слишком велико \{#the-paywall-view-number-is-too-big\}

**Проблема**: Счётчик просмотров пейвола показывает значение вдвое больше ожидаемого.

**Причина**: Возможно, в коде вызывается `LogShowFlow` (SDK v4+) / `LogShowPaywall`, что дублирует количество просмотров пейвола, созданного в старом Paywall Builder. Adapty отслеживает эти просмотры автоматически, поэтому данный метод вызывать не нужно.

**Решение**: Убедитесь, что в коде не вызывается `LogShowFlow` (SDK v4+) / `LogShowPaywall` для пейвола, созданного в старом Paywall Builder.

## Другие проблемы \{#other-issues\}

**Проблема**: Вы столкнулись с другими проблемами, связанными с Paywall Builder, которые не описаны выше.

**Решение**: При необходимости обновите SDK до последней версии с помощью [гайдов по миграции](unity-sdk-migration-guides). Многие проблемы устраняются в новых версиях SDK.
