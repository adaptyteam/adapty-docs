Paywall Builder и Flow Builder показывают по одному экрану за раз, поэтому в длинном онбординге с ветками квиза сложно понять, куда ведёт каждый ответ. [Скилл flow-generator](flow-generator-skill) умеет нарисовать весь флоу в виде карты: каждый экран по порядку, все переходы между ними и все точки разветвления или завершения.

Карта — это один HTML-файл, который открывается в браузере. В него вложены превью экранов, так что его можно отправить коллеге — он откроет файл без какой-либо настройки.

:::important
Карта является частью скилла flow-generator, поэтому устанавливать ничего дополнительно не нужно — следуйте [инструкциям по установке flow-generator](flow-generator-skill#install-the-skill). Построение карты только считывает флоу: ничего в дашборд не сохраняется.
:::

## Для чего это нужно \{#what-its-for\}

- **Проверяйте ветвление перед публикацией**: смотрите, какой экран открывается по каждому ответу квиза и где ветки сходятся снова.
- **Находите ошибки в связях**: карта отмечает экран, к которому ничто не ведёт, и экран, с которого некуда идти дальше. Оба проходят проверку при публикации, и оба оставляют пользователей в тупике на устройстве.
- **Изучайте флоу, созданный кем-то другим**: просматривайте онбординг из 20 экранов с первого взгляда, а не кликая по экранам по одному.
- **Делитесь структурой**: отправьте файл дизайнеру или продакт-менеджеру, который не работает с дашбордом Adapty.

## Как использовать \{#how-to-use-it\}

Скилл открывает карту самостоятельно после того, как создаст или перестроит флоу из десяти и более экранов, а также после добавления или изменения ветки. Чтобы открыть карту для любого флоу, спросите в свободной форме:

```
How are the screens in my "Sleep onboarding" flow connected?
```

```
Where does the "Not really" button on the Busy mind screen lead?
```

Скилл загружает флоу, рендерит каждый экран и открывает карту. Для перемещения перетащите фон или прокрутите колесо мыши. Для масштабирования используйте **+** и **−** или нажмите **Fit**, чтобы увидеть весь флоу целиком. Чтобы увеличить экран, кликните по нему.

## Что показывает карта \{#what-the-map-shows\}

Экраны идут слева направо, начиная с первого. Экраны, которые ветка размещает рядом, находятся в одной колонке.

| На карте | Значение |
| :--- | :--- |
| Серая стрелка | Путь, который не зависит от ответа. |
| Фиолетовая стрелка с подписью | Один из вариантов ветки. Подпись указывает ответ, открывающий этот путь, например `goal = Falling asleep faster`. Подпись **otherwise** обозначает случай по умолчанию. |
| Пунктирная стрелка | Ведёт назад к экрану с меньшим номером. |
| Подпись **after timer** | Экран переключается автоматически по истечении [таймера](flow-timer). |
| Тег **branches** | На этом экране путь разветвляется. |
| Теги **buys**, **restores**, **closes flow**, **back** | Действия, которые покидают экран, не открывая другой. |
| Тег **nothing leads here** | Ни один экран не ведёт к этому, поэтому пользователи до него не доходят. |
| Тег **no way out** | Ни одна кнопка не открывает другой экран, не совершает покупку и не закрывает флоу. Кнопка **Back** в одиночку не считается. |

Чтобы выделить пути одного экрана, наведите на него курсор. Остальные экраны и стрелки потускнеют.

## Без браузера \{#without-a-browser\}

Если ваш AI-инструмент работает на удалённой машине, скилл выводит такую же карту текстом прямо в чате:

```
◆ Bedtime
    bedtime = After midnight  →  Name
    otherwise  →  Wind-down
    back
▢ Name
    back
    (no way out)
▢ Wind-down
    "Continue"  →  Reaction: wind-down
```

◆ обозначает экран, где путь разветвляется. Такие теги, как `back`, перечисляют действия, которые уводят с экрана, не открывая другого.

## Ограничения \{#limitations\}

- **Карта отображает конфиг, а не устройство**: карта показывает пути, определённые во флоу. Чтобы убедиться, что таймер срабатывает или ветка открывает нужный экран на телефоне, используйте [предпросмотр на устройстве](paywall-device-compatibility-preview).
- **Предпросмотр экранов имеет те же ограничения, что и предпросмотр скилла**: цены отображаются как имена переменных, переключатели показывают выключенное состояние. См. [Предпросмотр показывает один экран в одном состоянии](flow-generator-skill#the-preview-renders-one-screen-in-one-state).
- **Кастомные действия заканчиваются на границе флоу**: когда кнопка запускает [**Custom Action**](onboarding-actions#custom-actions), карта помечает экран идентификатором действия. Экран, который ваше приложение открывает в ответ, не является частью флоу, поэтому карта его не показывает.
- **Карта доступна только для чтения**: чтобы изменить путь, попросите скилл или отредактируйте флоу в Flow & Paywall Builder, а затем откройте карту снова.
