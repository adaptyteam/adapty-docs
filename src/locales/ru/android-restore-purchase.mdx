Восстановление покупок — это функция, которая позволяет пользователям снова получить доступ к ранее приобретённому контенту (подпискам или встроенным покупкам) без повторного списания средств. Особенно она полезна тем, кто удалил и переустановил приложение или перешёл на новое устройство и хочет получить доступ к уже оплаченному контенту.

:::note
В пейволах, созданных с помощью [Paywall Builder](adapty-paywall-builder), покупки восстанавливаются автоматически — никакого дополнительного кода не требуется. Если вы используете именно его, этот шаг можно пропустить.
:::

Чтобы восстановить покупку без использования [Paywall Builder](adapty-paywall-builder) для кастомизации пейвола, вызовите метод `.restorePurchases()`:

<TabItem value="kotlin" label="Kotlin" default>

```kotlin showLineNumbers
Adapty.restorePurchases { result ->
    when (result) {
        is AdaptyResult.Success -> {
            val profile = result.value
                      
            if (profile.accessLevels["YOUR_ACCESS_LEVEL"]?.isActive == true) {
            // successful access restore
            }
        }
        is AdaptyResult.Error -> {
            val error = result.error
            // handle the error
        }
    }
}
```
</TabItem>
<TabItem value="java" label="Java" default>

```java showLineNumbers
Adapty.restorePurchases(result -> {
    if (result instanceof AdaptyResult.Success) {
        AdaptyProfile profile = ((AdaptyResult.Success<AdaptyProfile>) result).getValue();
        
        if (profile != null) {
            AdaptyProfile.AccessLevel premium = profile.getAccessLevels().get("YOUR_ACCESS_LEVEL");
            
            if (premium != null && premium.isActive()) {
                // successful access restore
            }
        }
    } else if (result instanceof AdaptyResult.Error) {
        AdaptyError error = ((AdaptyResult.Error) result).getError();
        // handle the error
    }
});
```
</TabItem>

</Tabs>

Параметры ответа:

| Параметр | Описание |
|---------|-----------|
| **Profile** | <p>Объект [`AdaptyProfile`](https://android.adapty.io/adapty/com.adapty.models/-adapty-profile/). Эта модель содержит информацию об уровнях доступа, подписках и разовых покупках.</p><p>Проверьте **статус уровня доступа**, чтобы определить, есть ли у пользователя доступ к приложению.</p> |

:::info
В Adapty Android SDK версии 4.0.2 и выше `restorePurchases()` завершается успешно даже если нечего восстанавливать: метод возвращает текущий профиль, поэтому проверяйте в нём статус уровня доступа. В более ранних версиях SDK метод в этом случае завершается с ошибкой `NO_PURCHASES_TO_RESTORE`.
:::

## Что можно восстановить \{#what-can-be-restored\}

`restorePurchases` восстанавливает активные подписки и неиспользованные разовые покупки из Google Play.

В Adapty Android SDK 4.0.2 и выше, использующем Google Play Billing Library 8, Play Store больше не возвращает истёкшие подписки и использованные разовые покупки. Чтобы пользователи могли восстановить их на другом устройстве или после переустановки, [идентифицируйте их](android-identifying-users) с помощью `Adapty.identify`. В этом случае Adapty восстановит историю покупок из своего бэкенда, а не из стора.

:::note
Google Play сообщает только об активных покупках, поэтому `restorePurchases()` не может найти подписки, которые истекли до интеграции Adapty. Чтобы добавить их в Adapty, [импортируйте исторические данные](importing-historical-data-to-adapty).
:::
