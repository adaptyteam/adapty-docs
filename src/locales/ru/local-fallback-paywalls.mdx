Adapty автоматически генерирует JSON-файлы конфигурации для ваших [резервных пейволов](/fallback-paywalls), по одному на каждую платформу. Эти файлы также содержат резервные данные для ваших онбордингов.

Если в одном плейсменте несколько пейволов или онбордингов, в резервной версии будет вариант с наибольшим весом или самой широкой аудиторией. Adapty обновляет эти файлы при каждом изменении пейволов или онбордингов.

Чтобы скачать резервные конфигурации, выполните следующие шаги:

1. Откройте страницу **[Placements](https://app.adapty.io/placements)**.
2. Нажмите кнопку **Fallbacks**.
3. Выберите нужную платформу (*iOS* или *Android*) из выпадающего списка.
4. Выберите версию SDK, чтобы начать загрузку.

:::tip
Чтобы скачать файл через терминал, воспользуйтесь [Developer CLI](developer-cli). Укажите версию Adapty SDK, с которой собрано ваше приложение:

```bash
adapty fallbacks get --app <app-id> --platform ios --sdk-version <sdk-version> --output ios_fallback.json
```

Запускайте команду отдельно для каждого стора, указывая `--platform ios` или `--platform android`. Подробнее о флагах — в [`adapty fallbacks get`](developer-cli-fallbacks).
:::
