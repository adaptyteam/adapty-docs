Скачайте [резервный файл](fallback-flows), который приложение использует при отсутствии связи с Adapty. Это тот же файл, что и загрузка **Fallbacks** на странице **Placements**.

## adapty fallbacks get

```bash
adapty fallbacks get --app <app-id> --platform ios --sdk-version 4.4.0 --output ios_fallback.json
```

| Флаг | Обязательный | Описание |
|---|---|---|
| `--app` | Да | ID приложения (UUID) |
| `--platform` | Да | `ios` для App Store или `android` для Google Play. Приложения macOS и visionOS используют файл `ios`. |
| `--sdk-version` | Да | Версия Adapty SDK, с которой собрано приложение, в формате `X.Y.Z`. Для Flutter, React Native, Unity, Kotlin Multiplatform и Capacitor укажите версию плагина Adapty. |
| `--output` | Нет | Файл для записи. Родительские директории создаются автоматически. Если не указан, файл выводится в стандартный вывод. |

Один файл на стор охватывает все плейсменты приложения. Чтобы выгрузить файлы для обоих сторов, запустите команду дважды — с `--platform ios` и с `--platform android`.

Файл содержит только активные плейсменты, поэтому перед скачиванием опубликуйте флоу и активируйте их плейсменты. После изменения плейсмента или обновления SDK скачайте файл заново — это снимок на текущий момент.

Adapty определяет формат файла по значению `--sdk-version`. SDK принимает только тот формат, под который собран, и при запуске отклоняет любой другой — без ошибки сборки:

| `--sdk-version` | Формат файла |
|---|---|
| 4.4.0 и выше | 12 |
| 4.1.x – 4.3.x | 11 |
| 4.0.x | 10 |
| 3.12.x и выше 3.x | 9 |
| 3.8.x – 3.11.x | 8 |
| 3.4.x – 3.7.x | 7 |
| 3.0.x – 3.3.x | 6 |
| Ниже 3.0 | 5 |

Плейсменты пейволов присутствуют в каждом формате. Плейсменты флоу — только в файлах для SDK 4.0 и выше.

С флагом `--output` CLI записывает файл только после успешного завершения загрузки, поэтому при сбое предыдущий файл остаётся нетронутым. Без него стандартный вывод содержит только файл, а все ошибки направляются в стандартный поток ошибок. Обычный редирект `> file` очищает файл до начала запроса, поэтому используйте `--output`.

Adapty собирает весь файл перед отправкой ответа — для большого приложения это может занять несколько минут. Команда отправляет один запрос и никогда не повторяет его. Каждое приложение может скачать файл 30 раз в час суммарно по всем токенам; после этого команда завершается с ошибкой rate-limit, которая сообщает, сколько нужно подождать. Скачивайте файл для релизных сборок, а не при каждом коммите.

| Код выхода | Значение |
|---|---|
| `0` | Файл записан |
| `1` | Файл не удалось записать. Предыдущий файл остался без изменений. |
| `2` | Недопустимое значение флага |
| `3` | Нет токена или доступ запрещён |
| `4` | Ошибка API, включая превышение лимита запросов, или ответ, не являющийся резервным файлом |
| `5` | Adapty недоступен, не ответил в течение 300 секунд или загрузка прервалась |
