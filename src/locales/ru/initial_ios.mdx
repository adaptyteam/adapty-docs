Подключите своё приложение из App Store к Adapty, чтобы Adapty мог валидировать покупки, получать события подписок и считывать ваши продукты из стора.

Каждый стор подключается отдельно, и Adapty валидирует покупки только для подключённых сторов. Если ваше приложение также доступно в Google Play, [подключите и его](initial-android) — эти два процесса независимы друг от друга и не сокращают друг друга.

Настройка охватывает App Store Connect и дашборд Adapty и занимает около 30 минут.

## Гайд по начальной интеграции \{#guide-for-the-initial-integration\}

- [ ] Как только вы создадите аккаунт в Adapty и укажете название и категорию мобильного приложения, мы настроим его в рамках нашей платформы Adapty.
- [ ] [Настройте интеграцию с App Store](app-store-connection-configuration) в дашборде Adapty и App Store Connect.
- [ ] Установите SDK Adapty для используемых фреймворков:
  - [ ] [Установите Adapty SDK для нативного iOS](sdk-installation-ios)
  - [ ] [Установите Adapty SDK для React Native](sdk-installation-reactnative)
  - [ ] [Установите Adapty SDK для Flutter](sdk-installation-flutter)
  - [ ] [Установите Adapty SDK для Unity](sdk-installation-unity)
  - [ ] [Установите Adapty SDK для Kotlin Multiplatform](sdk-installation-kotlin-multiplatform)
- [ ] Соберите приложение и запустите его в режиме песочницы.

После завершения начальной интеграции вы [можете начать использовать возможности Adapty](product).

Имейте в виду, что для отображения пейволов и продуктов в вашем мобильном приложении, а также для работы аналитики необходимо внести изменения в код приложения. В частности, нужно как минимум [отображать пейволы](ios-quickstart-paywalls) и, если вы используете пейволы, созданные без Paywall Builder, [обрабатывать процесс покупки](making-purchases) внутри приложения.

:::danger
Перед релизом приложения пройдите чеклист релиза

Перед выпуском приложения обязательно ознакомьтесь с [чеклистом для релиза](release-checklist). Это поможет убедиться, что все необходимые шаги выполнены перед публикацией приложения с Adapty SDK.
:::
