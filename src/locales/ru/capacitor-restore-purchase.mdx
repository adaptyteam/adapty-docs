Восстановление покупок в iOS и Android позволяет пользователям снова получить доступ к ранее приобретённому контенту — например, подпискам или встроенным покупкам — без повторной оплаты. Это особенно удобно, если пользователь удалил и переустановил приложение или сменил устройство и хочет вернуть доступ к купленному контенту.

:::note
Если вы создали экран в билдере, восстанавливать покупки вручную не нужно. Привяжите соответствующий элемент управления — действие **Restore purchases** во Flow & Paywall Builder или ссылку/кнопку восстановления в старом — и SDK выполнит восстановление.
:::

Если вы создали экран самостоятельно, вызовите метод `.restorePurchases()`:

```typescript showLineNumbers

try {
  const profile = await adapty.restorePurchases();
  const isSubscribed = profile.accessLevels?.['YOUR_ACCESS_LEVEL']?.isActive;
  
  if (isSubscribed) {
    // Restore access to paid features
    console.log('Access restored successfully!');
  } else {
    console.log('No active subscriptions found');
  }
} catch (error) {
  console.error('Failed to restore purchases:', error);
}
```

Параметры ответа:

| Параметр | Описание                                                                                                                                                                                                                                                            |
|---------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **profile** | Объект [`AdaptyProfile`](https://capacitor.adapty.io/interfaces/adaptyprofile). Эта модель содержит информацию об уровнях доступа, подписках и разовых покупках. Проверьте **статус уровня доступа**, чтобы определить, есть ли у пользователя доступ к приложению. |
