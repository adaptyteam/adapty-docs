Adapty Mail запускает MCP-сервер, поэтому ИИ-ассистент может работать с вашим проектом так же, как вы работаете в дашборде: генерировать и локализовывать кампании, запускать флоу, настраивать домен для отправки, искать профили и читать аналитику. Ассистент входит под вашей учётной записью Adapty Mail и получает ваши права доступа после того, как вы подтверждаете подключение в дашборде. API-ключ не нужен.

| | |
|---|---|
| Server URL | `https://api-mail.adapty.io/mcp` |
| Protocol | MCP over Streamable HTTP, OAuth 2.1 sign-in |
| Works with | Claude (web and desktop), ChatGPT, Claude Code, Codex CLI, GitHub Copilot CLI, Gemini CLI, Cursor, Windsurf, and any client that supports remote MCP servers with OAuth |

:::tip
Для лучших результатов в coding agent добавьте также [скилл Adapty Mail](mail-skill). Он подключает сервер автоматически, запрашивает подтверждение перед отправкой писем реальным людям и берёт на себя работу после запуска: результаты, A/B-тесты и разбор причин, по которым письмо не дошло.
:::

## Что умеет ассистент \{#what-the-assistant-can-do\}

Инструменты сервера повторяют возможности дашборда:

| Область | Примеры |
|---|---|
| Ориентация | Найти компании и проекты, узнать, какие шаги настройки не завершены |
| Бренд | Создать бренд из описания в сторе, просмотреть и отредактировать его |
| Отправляющие домены | Добавить домен, получить DNS-записи, проверить верификацию, узнать состояние домена |
| Назначения | Создать и обновить страницы, на которые ведут ссылки в письмах |
| Кампании | Сгенерировать кампанию из брифа, редактировать письма, переводить их, отправлять тестовые письма |
| Флоу и сегменты | Создавать сегменты, запускать и изменять флоу |
| A/B-тесты | Создавать, запускать и завершать тесты |
| Профили | Найти профиль и его историю, отписать профиль |
| Аналитика | Метрики кампаний в динамике, разбивки, воронки A/B-тестов |
| Настройки | Имя отправителя, адрес для ответа, double opt-in, загрузка изображений |

Три управляемых флоу доступны в виде промптов в клиентах, которые их поддерживают. В Claude Code они отображаются как слэш-команды, например `/mcp__adaptymail__campaign_to_flow`:

- **campaign_to_flow**: Создать кампанию на основе брифа, выбрать назначение и сегмент, запустить флоу.
- **campaign_localization**: Перевести сохранённую кампанию на другие языки.
- **domain_onboarding**: Добавить домен для отправки, опубликовать DNS-записи и верифицировать его.

Некоторые шаги настройки выполняются только в дашборде: [адрес компании](mail-get-started#5-add-your-company-address), [веб-чекаут](mail-checkout) и [включение отправки данных](mail-entry-points).

## Перед началом работы \{#before-you-start\}

- **Членство в проекте**: ваш аккаунт Adapty Mail является участником проекта, с которым вы хотите работать. Ассистент видит только те компании и проекты, которые доступны вашему аккаунту.
- **Поддержка клиента**: ваш клиент поддерживает удалённые MCP-серверы с OAuth.

:::warning
Ассистент обладает теми же правами, что и вы, и все его действия происходят по-настоящему: сохранение флоу запускает отправку писем реальным людям. Сервер помечает деструктивные инструменты, а протестированные нами ассистенты запрашивают подтверждение перед их выполнением. Внимательно читайте план ассистента, прежде чем его одобрять.
:::

## Подключите вашего ассистента \{#connect-your-assistant\}

### Claude (claude.ai и Claude desktop)

1. Чтобы добавить сервер, откройте **Settings → Connectors** и нажмите **Add custom connector**.
2. Введите название, например `Adapty Mail`, и URL `https://api-mail.adapty.io/mcp`.
3. Оставьте **Authentication** на **Sign in now**, OAuth-клиент — на определённом по умолчанию, и нажмите **Add**.
4. На открывшейся вкладке Adapty Mail войдите в аккаунт, если потребуется, и нажмите **Approve**.

Администраторы рабочего пространства могут добавить коннектор один раз для всей организации. После этого каждый участник входит со своим аккаунтом Adapty Mail при первом использовании.

### ChatGPT

ChatGPT добавляет пользовательские MCP-серверы со страницы коннекторов в **Settings**. Для вашего воркспейса должен быть включён режим разработчика.

1. Чтобы добавить сервер, нажмите **Create**.
2. Введите имя, например `Adapty Mail`, и URL сервера `https://api-mail.adapty.io/mcp`. Оставьте **Authentication** в значении **OAuth**.
3. Примите предупреждение о пользовательском MCP-сервере и нажмите **Create**.
4. Когда ChatGPT запросит подтверждение, подключите сервер. На открывшейся вкладке Adapty Mail войдите в аккаунт при необходимости и нажмите **Approve**.

### Claude Code

```bash
claude mcp add --transport http --scope user adaptymail https://api-mail.adapty.io/mcp
```

Чтобы войти, запустите `/mcp` в Claude Code, выберите `adaptymail` и нажмите **Authenticate**. Затем войдите в дашборд Adapty Mail в браузере и нажмите **Approve**.

### Codex CLI

```bash
codex mcp add adaptymail --url https://api-mail.adapty.io/mcp
codex mcp login adaptymail
```

Команда login открывает браузер, где вы подтверждаете подключение. Чтобы настроить сервер вручную, добавьте его в `~/.codex/config.toml` и затем выполните команду login:

```toml
[mcp_servers.adaptymail]
url = "https://api-mail.adapty.io/mcp"
```

### GitHub Copilot CLI

```bash
copilot mcp add --transport http adaptymail https://api-mail.adapty.io/mcp
```

При первом подключении к серверу откроется браузер для входа в аккаунт.

### Gemini CLI

```bash
gemini mcp add --transport http --scope user adaptymail https://api-mail.adapty.io/mcp
```

Начните новую сессию, затем выполните `/mcp auth adaptymail` и подтвердите подключение в браузере.

### Cursor, Windsurf и другие клиенты

Добавьте сервер в файл конфигурации MCP клиента, например `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "adaptymail": {
      "url": "https://api-mail.adapty.io/mcp"
    }
  }
}
```

При первом подключении клиент откроет браузер для входа. Клиенты без поддержки OAuth для удалённых серверов не смогут подключиться к Adapty Mail.

## Подтвердите подключение \{#approve-the-connection\}

Каждый клиент завершает работу на одном и том же экране в дашборде Adapty Mail. На нём указано название приложения, запрашивающего доступ, и адрес, по которому это приложение получает доступ. Для десктопных инструментов этот адрес находится на вашем собственном компьютере (`localhost`), поэтому подтверждайте только то подключение, которое вы сами инициировали. Чтобы завершить процесс, нажмите **Approve**.

Запрос на подключение истекает через 10 минут. Если на экране отображается **This request has expired**, начните заново со стороны клиента.

## Начало работы \{#start-working\}

Попросите ассистента показать ваши проекты, затем укажите, с каким из них хотите работать. Примеры запросов:

- «Покажи статус онбординга моего проекта и скажи, чего не хватает.»
- «Создай win-back кампанию для пользователей, у которых истёк триал, на английском, и покажи первое письмо.»
- «Переведи кампанию Trial expired на немецкий и французский.»
- «Добавь `mail.example.com` как домен отправки и дай мне DNS-записи.»
- «Сравни показатели открытий и кликов по активным кампаниям за последние 30 дней.»

## Отключение \{#disconnect\}

Чтобы отключиться, удалите коннектор в настройках клиента. В Claude это **Settings → Connectors**; в ChatGPT — на странице коннектора; в Claude Code выполните `claude mcp remove adaptymail`.

Токен доступа клиента истекает в течение часа. Refresh-токен отзывается при отключении клиента; неиспользованный истекает через 90 дней. Чтобы подключиться снова, добавьте сервер и подтвердите соединение ещё раз.

## Устранение неполадок \{#troubleshooting\}

| Проблема | Решение |
|---|---|
| Дашборд сообщает, что запрос на подключение истёк | Начните подключение заново со стороны клиента и подтвердите его в течение 10 минут. |
| Ассистент сообщает, что проект не найден | Ваш аккаунт не является участником этого проекта. Попросите владельца компании предоставить доступ. |
| Ассистент был разлогинен | Доступ истекает после длительного простоя или после отключения. Переподключитесь со стороны клиента. |
| Клиент не отображает инструменты | Клиент подключился без авторизации. Выполните шаг входа, например `/mcp` в Claude Code. |
