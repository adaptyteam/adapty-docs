Чтобы подключить встроенные покупки, нужно разобраться в трёх ключевых понятиях:

- [**Продукты**](product) – всё, что пользователи могут купить (подписки, расходуемые покупки, пожизненный доступ)
- [**Флоу и пейволы**](adapty-flow-builder) – экраны, которые предлагают продукты пользователям, созданные в конструкторе флоу и пейволов без кода. SDK получает их через `getFlow`. Если вы предпочитаете строить UI самостоятельно, смотрите [Реализация пользовательских пейволов](android-quickstart-manual).
- [**Плейсменты**](placements) – где и когда в приложении показываются флоу и пейволы (например, `main`, `onboarding`, `settings`). Вы привязываете их к плейсментам в дашборде, а затем запрашиваете по ID плейсмента в коде. Это упрощает запуск A/B-тестов и показ разных вариантов разным пользователям.

Adapty предлагает три способа подключить покупки в вашем приложении. Выберите подходящий в зависимости от требований:

| Реализация | Сложность | Когда использовать |
|---|---|---|
| Adapty Flow & Paywall Builder | ✅ Легко | Вы [создаёте готовый к покупке флоу или пейвол в no-code конструкторе](quickstart-paywalls). Adapty автоматически отображает его и берёт на себя всю логику покупок, валидацию чеков и управление подписками. |
| Кастомные пейволы | 🟡 Средне | Вы реализуете UI пейвола в коде своего приложения, но всё равно получаете объект флоу от Adapty, сохраняя гибкость в настройке продуктов. См. [гайд](android-quickstart-manual). |
| Режим наблюдателя | 🔴 Сложно | У вас уже есть собственная инфраструктура для обработки покупок, и вы хотите продолжать её использовать. Учтите, что режим наблюдателя имеет ограничения в Adapty. См. [статью](observer-vs-full-mode). |

:::important
**Шаги ниже показывают, как реализовать флоу или пейвол, созданный в Adapty Flow & Paywall Builder.**

Если вы хотите создать UI пейвола самостоятельно, см. [Реализация пользовательских пейволов](android-quickstart-manual).
:::

Чтобы отобразить флоу или пейвол, созданный в Adapty Flow & Paywall Builder, в коде приложения вам нужно только:

1. **Получите флоу или пейвол**: Получите его из Adapty.
2. **Отобразите его — Adapty возьмёт на себя покупки**: Покажите экран в вашем приложении.
3. **Обрабатывайте действия кнопок**: Свяжите взаимодействия пользователей с реакцией вашего приложения на них. Например, открывайте ссылки или закрывайте пейвол при нажатии кнопок.

## Прежде чем начать

Прежде чем начать, выполните следующие шаги:

1. [Подключите приложение к Google Play](initial-android) в дашборде Adapty.
2. [Создайте продукты](create-product) в Adapty.
3. [Создайте флоу или пейвол](paywall-builder-templates) и [добавьте в него продукты](paywall-product-block).
4. [Создайте плейсмент и добавьте в него флоу или пейвол](create-placement).
5. [Установите и активируйте SDK](sdk-installation-android) в коде приложения. В этом гайде используются API Adapty Android SDK v4.

:::tip
Самый быстрый способ выполнить эти шаги — следовать [руководству по быстрому старту](quickstart) или создать флоу и плейсменты с помощью [Developer CLI](developer-cli-quickstart).
:::

## 1. Получите флоу или пейвол \{#1-get-the-flow-or-paywall\}

Ваши флоу и пейволы связаны с плейсментами, настроенными в дашборде. Плейсменты позволяют показывать разные флоу или пейволы разным аудиториям или запускать [A/B-тесты](ab-tests).

Чтобы получить флоу или пейвол, созданный в Adapty Flow & Paywall Builder, необходимо:

1. Получить объект `flow` по ID [плейсмента](placements) с помощью метода `getFlow` и проверить, есть ли в нём конфигурация представления.

2. Получите конфигурацию представления с помощью метода `getFlowConfiguration`. Конфигурация представления содержит элементы UI и стили, необходимые для его отображения.

:::important
Чтобы получить конфигурацию представления, [опубликуйте флоу или пейвол](builder-save-publish). Флоу или пейвол с неопубликованными изменениями имеет статус **Dirty**, и его плейсмент продолжает отдавать последнюю опубликованную версию.
:::

<Tabs groupId="current-os" queryString>

<TabItem value="kotlin" label="Kotlin" default>

```kotlin showLineNumbers
Adapty.getFlow("YOUR_PLACEMENT_ID") { result ->
    if (result is AdaptyResult.Success) {
        val flow = result.value
        
        if (!flow.hasViewConfiguration) {
            return@getFlow
        }
        
        AdaptyUI.getFlowConfiguration(flow) { configResult ->
            if (configResult is AdaptyResult.Success) {
                val flowConfiguration = configResult.value
            }
        }
    }
}
```
</TabItem>

            return;

            if (configResult instanceof AdaptyResult.Success) {
                AdaptyUI.FlowConfiguration flowConfiguration =
                    ((AdaptyResult.Success<AdaptyUI.FlowConfiguration>) configResult).getValue();
                // use loaded configuration
            }
        });
    }
});

## 2. Отобразите флоу или пейвол \{#2-display-the-flow-or-paywall\}

Теперь, когда у вас есть конфигурация флоу, достаточно добавить несколько строк, чтобы отобразить флоу или пейвол.

Чтобы отобразить визуальный флоу на экране устройства, его нужно предварительно настроить. Для этого вызовите метод `AdaptyUI.getFlowView()` или создайте `AdaptyFlowView` напрямую:

## 3. Обработка действий кнопок \{#handle-button-actions\}

Когда пользователи нажимают кнопки во флоу или пейволе, Android SDK автоматически обрабатывает покупки, восстановление, закрытие экрана и открытие ссылок.

Однако другие кнопки имеют пользовательские или предустановленные идентификаторы и требуют обработки действий в вашем коде. Кроме того, вы можете переопределить их поведение по умолчанию.

Например, вот поведение кнопки закрытия по умолчанию. Добавлять его в код не нужно, но здесь можно увидеть, как это делается при необходимости.

:::tip
Ознакомьтесь с нашими гайдами по обработке [действий](android-handle-paywall-actions) и [событий](android-handling-events) кнопок.
:::

<Tabs groupId="current-os" queryString>

<TabItem value="kotlin" label="Kotlin" default>

```kotlin showLineNumbers title="Kotlin"
override fun onActionPerformed(action: AdaptyUI.Action, context: Context) {
    when (action) {
        AdaptyUI.Action.Close -> (context as? Activity)?.onBackPressed() // default behavior
    }
}
```
</TabItem>
<TabItem value="java" label="Java" default>

```java showLineNumbers
@Override
public void onActionPerformed(@NonNull AdaptyUI.Action action, @NonNull Context context) {
    if (action instanceof AdaptyUI.Action.Close) {
        if (context instanceof Activity) {
            ((Activity) context).onBackPressed();
        }
    }
}
```

## Полный пример \{#full-example\}

Вот как все эти шаги можно объединить в вашем приложении.

<Tabs groupId="current-os" queryString>

<TabItem value="kotlin" label="Kotlin" default>

```kotlin showLineNumbers title="Kotlin"
class MainActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)

        Adapty.getFlow("YOUR_PLACEMENT_ID") { flowResult ->
            if (flowResult is AdaptyResult.Success) {
                val flow = flowResult.value

                if (!flow.hasViewConfiguration) {
                    // Use custom logic
                    return@getFlow
                }

                AdaptyUI.getFlowConfiguration(flow) { configResult ->
                    if (configResult is AdaptyResult.Success) {
                        val flowConfiguration = configResult.value

                        val flowView = AdaptyUI.getFlowView(
                            this,
                            flowConfiguration,
                            null, // products = null means auto-fetch
                            object : AdaptyFlowDefaultEventListener() {
                                override fun onActionPerformed(action: AdaptyUI.Action, context: Context) {
                                    when (action) {
                                        is AdaptyUI.Action.Close -> {
                                            (context as? Activity)?.onBackPressed()
                                        }
                                    }
                                }
                            }
                        )

                        setContentView(flowView)
                    }
                }
            }
        }
    }
}

```
