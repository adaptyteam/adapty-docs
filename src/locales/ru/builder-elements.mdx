Чтобы открыть библиотеку элементов и добавить новый элемент на экран, нажмите кнопку со знаком плюса <Inline id="plus.svg" alt="Plus" /> на левой панели или над предпросмотром устройства.

Элементы делятся на следующие категории:
- [Основные](#basics) (контейнеры макета, текст, медиа, списки, значки, галочки)
- [Формы и квизы](#forms--quiz) (кнопки, поля ввода, квизы, вкладки)
- [Пейвол и коммерция](#paywall--commerce) (продукты, переключатели, вовлечение пользователей, обратный отсчёт)
- [Индикаторы прогресса](#progress) и загрузчики

Для каждого элемента Adapty предлагает несколько пресетов — шаблонов с заполнителями контента или заранее настроенными взаимодействиями.

Чтобы отобразить нативный вид из вашего приложения, например анимацию Lottie, интерактивный график или карту, добавьте [пользовательский элемент](flow-custom-elements).

## Основы \{#basics\}

### Макет \{#layout\}

:::link
Основная статья: [Элементы макета](builder-containers)
:::

<ZoomImage id="layout-element-templates.webp" width="350px" alt="Шаблоны элементов макета" float="left" />

Элементы макета — это контейнеры, которые организуют расположение вложенных элементов.

- **Vertical Container**: располагает дочерние элементы сверху вниз
- **Horizontal Container**: располагает дочерние элементы слева направо
- **Dividers (horizontal and vertical)**: линии, визуально разделяющие разделы контента
- **Carousel**: контейнер с прокруткой свайпом
- **Footer**: панель, закреплённая внизу экрана, за пределами области прокрутки
- **Sliding sheet**: панель, которая накладывает основной контент поверх фонового изображения
- **Bottom Sheet**: панель, выезжающая снизу экрана

:::link
Основная статья: [Текстовый контент](onboarding-text)
:::

Текстовый элемент может содержать статичный текст, [переменные](onboarding-variables) или [условный текст](onboarding-text#add-conditional-text), а также поддерживает [локализацию](paywall-localization).

Текстовый элемент также может отображать данные из вашего приложения — например, баланс монет игрока или количество дней в серии. Вставьте [кастомный тег](flow-custom-tags) туда, где должны отображаться данные. Ваше приложение задаёт значение тега через SDK Adapty, поэтому каждый пользователь видит свой баланс или серию.


<ZoomImage id="text-templates.webp" width="400px" alt="Text element templates" float="right" />

Следующие текстовые пресеты доступны по умолчанию. Чтобы изменить этот список, добавьте или удалите [сохранённые текстовые стили](builder-reusable-styles):

- H1
- H2
- H3
- Button Label
- Body
- Caption
- Small Label

Меню **Text** также содержит элемент **Old Price** — перечёркнутая цена продукта, которая рассчитывается автоматически на основе множителя. См. [Добавить старую цену](onboarding-text#add-an-old-price).

### Медиа \{#media\}

:::link
Основная статья: [Изображения, видео и иконки](custom-media)
:::

:::note
В этом разделе описываются элементы медиа на переднем плане. Чтобы заполнить весь экран изображением или видео, измените [фон экрана](paywall-layout-and-products#screen-background).
:::

<ZoomImage id="media-templates.webp" width="200px" alt="Media element templates" float="right"/>

- **Icon**: векторная иконка из встроенной библиотеки, с настраиваемыми размером и цветом
- **Image**: изображение — загрузите своё или укажите URL
- **Video**: встроенный видеоплеер для файлов размером до 50 МБ. Поддерживает повторное воспроизведение.
- **Custom element**: [нативный элемент из вашего приложения](flow-custom-elements), например анимация Lottie, интерактивный график или карта.

### Список \{#list\}

Элементы списка организуют контент в строки и столбцы для отображения единообразно отформатированных данных. По сути, список — это [контейнер](manage-paywall-ui-elements#layout).

- **Icon List**: строки с ведущей иконкой и текстовой подписью
- **Timeline**: вертикальная последовательность со связанными индикаторами шагов
- **Image List**: строки с ведущим изображением и текстом
- **Icon Cards**: сетка карточек с центрированными иконками
- **Image Cards**: сетка карточек с изображениями
- **Comparison Table**: многостолбцовая таблица для сравнения функций по тарифам (например, Free vs Pro)

<ZoomImage id="list-templates.webp" width="700px" alt="Шаблоны элементов списка"/>

### Значок \{#badge\}

<ZoomImage id="badge-template.webp" width="200px" alt="Badge templates" float="right"/>

Небольшой оверлейный ярлык для выделения элемента — как правило, используется для продвижения скидок или конкретных планов (например, «Скидка 5%»). Используйте [абсолютное позиционирование](manage-paywall-ui-elements#absolute), чтобы разместить значок поверх другого элемента.

### Индикаторы выбора \{#checkmarks\}

Иконки-индикаторы для использования внутри [выбираемых элементов](flow-selectable-elements), таких как карточки продуктов. Каждая форма доступна в двух пресетах: включённом и выключенном.

<ZoomImage id="checkmark-templates.webp" width="700px" alt="Checkmark templates" float="right"/>


- Checkbox
- Circle
- Radiobutton
- Toggle

Если вам нужен переключатель или флажок, который пользователь нажимает напрямую, используйте элементы [Toggle](#toggle).

## Формы и викторины \{#forms--quiz\}

### Кнопки \{#buttons\}

:::link
Основная статья: [Кнопки](paywall-buttons)
:::

Кнопки запускают действия по нажатию — переход на другой экран, открытие URL или закрытие флоу.

<ZoomImage id="button-templates.webp" width="400px" alt="Layout element templates" float="right" />

Каждый пресет — это отправная точка: переоформите его и назначьте любое действие. Настройте поведение кнопки на вкладке [Interactions](builder-ui#interactions-properties).

- **Base**: обычная кнопка с текстом по центру
- **Right Icon**: кнопка со значком справа
- **With Subtitle**: включает две строки текста
- **Pulse Animation**: включает анимированный пульсирующий эффект
- **Purchase**: запускает покупку
- **Secondary Outline**: кнопка с обводкой для второстепенных действий
- **Back**: переход к предыдущему экрану
- **Close flow**: выход из флоу
- **View more plans**: показывает дополнительные варианты продуктов
- **Links**: набор кнопок в подвале (Restore, Terms of Service, Privacy Policy)

### Поля ввода \{#inputs\}

:::link
Основная статья: [Поля ввода и формы](builder-inputs-and-forms)
:::

Поля ввода позволяют пользователям вводить данные. Каждое поле использует подходящий метод ввода и правила валидации.

<ZoomImage id="input-templates.webp" width="400px" alt="Input templates" float="right" />

- Текст
- E-mail
- Пароль
- Число
- Номер телефона
- Дата
- Время
- Дата и время
- Числовой выбор

Поля Дата, Время и Дата и время открывают нативный системный пикер устройства (колесо или календарь) при нажатии.

У [числового пикера](builder-number-picker) вместо поля ввода есть колесо прокрутки. Вы задаёте минимальное и максимальное значение для колеса, а пользователь выбирает число в этом диапазоне.

Используйте [переменные](onboarding-variables) для обработки пользовательского ввода и управления условной логикой.

### Викторины \{#quizzes\}

:::link
Основная статья: [Опросы и викторины](onboarding-quizzes)
:::

Элементы викторины представляют собой экраны с множественным выбором для опросов, сбора предпочтений и сегментации пользователей. Настройте [взаимодействия](onboarding-navigation-branching), чтобы управлять флоу в зависимости от ответа пользователя.

<ZoomImage id="quiz-templates.webp" width="400px" alt="Шаблоны викторин" float="right" />

- **Icon Options**: одноколоночный список с иконками
- **Emoji Options**: одноколоночный список с эмодзи
- **Image Options**: одноколоночный список с изображениями
- **Icon Grid**: многоколоночная сетка с иконками
- **Emoji Grid**: многоколоночная сетка с эмодзи
- **Image Grid**: многоколоночная сетка с фотографиями
- **Rating**: числовая шкала (например, 1–5)

### Вкладки \{#tabs\}

:::link
Основная статья: [Вкладки](builder-tabs)
:::

Вкладки разбивают раздел экрана на переключаемые панели с контентом. Пользователь выбирает вкладку, и содержимое ниже обновляется соответственно. Обычно используются для группировки планов продуктов или переключения между ежемесячными и годовыми ценами.

<ZoomImage id="tab-templates.webp" width="500px" alt="Tab templates" float="right" />

- **Segment control**: переключатель в виде таблетки с закруглёнными углами вокруг выбранной вкладки
- **Button Tabs**: отдельные вкладки в стиле кнопок
- **Underline**: текстовые метки с подчёркиванием, обозначающим выбранную вкладку


## Пейвол и монетизация \{#paywall--commerce\}

### Продукты \{#products\}

:::link
Основная статья: [Продукты](paywall-product-block)
:::

Элементы продуктов отображают детали встроенных покупок и управляют выбором продукта. Каждый пресет организует данные о продукте в определённом формате. Привяжите свои продукты, чтобы заполнить элементы реальными данными из Adapty.

<ZoomImage id="product-templates.webp" width="400px" alt="Product templates" float="right" />

- **Vertical List**: карточки продуктов, расположенные в столбик
- **Horizontal List**: карточки продуктов, расположенные в ряд
- **Feature Carousel**: прокручиваемые карточки со списком возможностей
- **Feature Cards**: статичные карточки со списком возможностей
- **Banner List**: компактные строки со встроенными бейджами

### Переключатель \{#toggle\}

:::link
Основная статья: [Переключатели и чекбоксы](builder-toggles)
:::

<ZoomImage id="toggle-template.webp" width="200px" alt="Toggle templates" float="right" />

Переключатели и чекбоксы, которые пользователь нажимает, чтобы включить или выключить что-либо. Каждый из них является [выбираемым элементом](flow-selectable-elements), поэтому другие элементы могут реагировать на его состояние.

- **Trial toggle**: переключает отображаемый продукт между стандартной ценой и предложением с бесплатным пробным периодом
- **Checkbox**: чекбокс с текстовой меткой, предзаполненный строкой согласия с условиями использования и политикой конфиденциальности
- **Toggle**: переключатель с текстовой меткой

### Вовлечение пользователей \{#user-engagement\}

:::link
Основная статья: [Отзывы и рекомендации](builder-reviews-and-testimonials)
:::

Готовые блоки с пользовательскими оценками, которые формируют доверие и повышают конверсию. Шаблоны представляют собой базовые контейнеры с заполнителями.

<ZoomImage id="user-engagement-templates.webp" width="400px" alt="Шаблоны вовлечения пользователей" float="right" />

- **Review**: звёздный рейтинг с отзывом и именем автора
- **Review Carousel**: прокручиваемые карточки с отзывами и точками пагинации
- **Rating**: числовая оценка со звёздами
- **App Rating**: крупная оценка со шкалой звёзд и количеством отзывов
- **Social Proof**: стопка аватаров с числом пользователей

### Обратный отсчёт \{#countdown\}

:::link
Основная статья: [Таймер обратного отсчёта](flow-timer)
:::

<ZoomImage id="countdown-templates.webp" width="300px" alt="Шаблоны таймера обратного отсчёта" float="right" />

Отображает часы, минуты и секунды, отсчитывающие время до нуля. Используйте его, чтобы создать ощущение срочности для ограниченных по времени предложений. По достижении нуля таймер может запускать действия — например, переход на другой экран или скрытие бейджа со скидкой.

- **Inline**: компактное числовое отображение
- **Inline with units**: числовое отображение с подписями единиц
- **Badge**: небольшой выделенный оверлей таймера
- **Blocks**: отдельные карточки для дней, часов, минут и секунд

## Прогресс \{#progress\}

:::link
Основная статья: [Загрузчики и индикаторы прогресса](builder-loaders-and-progress-bars)
:::

### Индикаторы прогресса \{#progress-indicators\}

<ZoomImage id="flow-indicators.webp" width="300px" alt="Progress indicator variants" float="right" />

Пошаговые индикаторы прогресса, показывающие, на каком экране флоу находится пользователь. Удобны для онбординга, когда нужно показать, сколько шагов осталось.

- **Linear**: сплошная полоса, которая заполняется по мере прохождения
- **Segmented**: полоса, разделённая на отдельные сегменты — по одному на каждый шаг
- **Connectors**: пронумерованные маркеры шагов, соединённые короткими линиями

### Загрузчики \{#loaders\}

<ZoomImage id="flow-loaders.webp" width="300px" alt="Loader variants" float="right" />

Анимированные индикаторы загрузки для переходов между экранами. Используйте загрузчики, когда приложение обрабатывает данные пользователя — например, после отправки квиза.

- **Spinner**: вращающийся круговой индикатор
- **Spinner with label**: спиннер с текстовой подписью (например, «Загрузка...»)
- **Loader**: горизонтальный индикатор прогресса
