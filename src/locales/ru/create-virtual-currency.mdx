Чтобы продавать кредиты виртуальной валюты, сначала определите валюту, а затем привяжите её к продуктам.

Это делается в два шага — оба описаны в этой статье. После привязки продукта каждая покупка или продление будет автоматически начислять кредиты.

## Создание виртуальной валюты \{#create-a-virtual-currency\}

В дашборде Adapty откройте **Products** > [**Virtual currency**](https://app.adapty.io/virtual-currency).

<ZoomImage id="virtual-currency-tab.webp" width="700px" alt="The Virtual currency tab under Products, showing the empty state and the New virtual currency button" />

Чтобы создать виртуальную валюту:

1. Нажмите **New virtual currency**. Откроется панель на шаге **General**.
2. Заполните данные о валюте:
    - **Code**: Уникальный **постоянный** идентификатор валюты в вашем приложении, например `COINS`. Идентифицирует валюту в серверном API и отслеживает баланс каждого пользователя.
    
        Используйте латинские буквы, цифры и символы подчёркивания, не более 32 символов. Строчные буквы автоматически преобразуются в прописные.
    - **Name**: Отображаемое название, например `Gold`. Его можно изменить позже.
    - **Description**: Необязательное примечание о валюте.
3. Нажмите **Continue**, чтобы перейти к шагу **Link Products**.

:::important
После создания валюты изменить её **Code** невозможно. **Name** можно отредактировать в любое время.
:::

При создании новой валюты начальный баланс каждого профиля равен 0. Чтобы выдать пользователям баланс до первой покупки, см. [Выдать начальный баланс](grant-initial-balance).

<ZoomImage id="new-currency-step-1.webp" width="500px" alt="The General step of the New virtual currency drawer, with Code, Name, and Description fields" />

## Привязка продуктов \{#link-products\}

Привяжите продукт к виртуальной валюте, чтобы покупка или продление подписки начисляло кредиты в этой валюте. Один продукт можно привязать к нескольким валютам, а одну валюту — к нескольким продуктам. Привязать продукты можно сейчас, на шаге **Link Products**, или позже при редактировании валюты.

На шаге **Link Products** в разделе **Associated products** отображаются продукты, которые начисляют данную валюту. Чтобы добавить продукт, нажмите **Add associated products** и выберите нужный продукт.

Каждое начисление добавляется к балансу пользователя, а не заменяет его, поэтому кредиты от разных продуктов накапливаются. Настройки кредитов зависят от типа продукта:

- **Продукты с подпиской** имеют три настройки кредитов:
    - **Credit per cycle** (обязательно): кредиты, начисляемые при первой платной покупке и при каждом продлении, включая продление, которое переводит пробный период в платный.
    - **Credit on trial start** (опционально): отдельная разовая сумма, начисляемая при начале бесплатного пробного периода.
    - **Credits expire at the end of each billing cycle** (чекбокс): если выбрано, подписка начисляет кредиты на один расчётный период за раз. По окончании периода неиспользованные кредиты сгорают. Кредиты из других подписок, разовых продуктов и Server-side API остаются на балансе. Если не выбрано, кредиты накапливаются между периодами и не имеют срока действия.
- **Разовые продукты**: задайте **Credit amount** — количество кредитов, начисляемых за каждую покупку. Кредиты из разовых продуктов не имеют срока действия.

Нажмите **Save**, чтобы создать валюту с привязанными продуктами.

Привязка продуктов действует только для будущих событий. Вновь привязанный продукт начисляет кредиты начиная со следующей покупки или продления. Adapty не начисляет валюту текущим подписчикам автоматически — им нужно сначала продлить подписку. Если убрать привязку, новые начисления прекращаются, а уже выданные кредиты остаются.

Если установлен флажок **Credits expire at the end of each billing cycle**, срок действия кредитов соответствует жизненному циклу подписки:

- Если платёж при продлении не прошёл, неиспользованные кредиты всё равно сгорают в конце оплаченного периода, даже если пользователь сохраняет доступ в течение льготного периода. Adapty начисляет новые кредиты после успешного платежа.
- После отмены подписки кредиты остаются до конца оплаченного периода.
- Когда подписка истекает, Adapty обнуляет оставшиеся кредиты, выданные этой подпиской.
- Позднее продление, о котором стор сообщает уже после окончания оплаченного периода, не даёт кредитов: они сразу же сгорели бы.

Когда стор возвращает деньги за покупку, Adapty убирает кредиты этой покупки из баланса:

- **Разовая покупка**: все кредиты, начисленные за эту покупку.
- **Подписка**: часть кредитов, пропорциональная возвращённой сумме.

Adapty списывает только те кредиты, которые пользователь ещё не потратил, поэтому баланс никогда не уходит ниже 0. В [истории событий](virtual-currency-balance#review-balance-changes-in-the-event-history) профиля это изменение отображается как **Virtual currency revoked**.

Когда пользователь выполняет апгрейд в App Store:

- Пользователь получает полный **Кредит за цикл** продукта более высокого уровня без пропорционального распределения.
- Пользователь сохраняет кредиты продукта более низкого уровня, даже если App Store возвращает неиспользованную часть его стоимости.
- Если для продукта более низкого уровня установлен флажок **Credits expire at the end of each billing cycle**, неиспользованные кредиты истекают в момент перехода на более высокий уровень.

## Как тратится смешанный баланс \{#how-a-mixed-balance-is-spent\}

Баланс валюты может одновременно содержать кредиты из нескольких источников — например, истекающий грант от подписки и неистекающий от разовой покупки. Когда списание дебетует баланс, Adapty сначала расходует истекающие кредиты, начиная с самого старого гранта, и переходит к неистекающим только после того, как истекающие закончатся. Именно поэтому окончание подписки сбрасывает лишь неизрасходованную часть, полученную от этой подписки, — кредиты, выданные разовой покупкой, остаются на балансе.

## Дальнейшие шаги \{#next-steps\}

После того как вы создадите валюту и привяжете продукты, покупки будут автоматически зачислять кредиты. Что дальше:

- Отслеживайте баланс каждого пользователя на странице [Virtual currency balance](virtual-currency-balance).
- Начисляйте, списывайте и считывайте балансы в рантайме через server-side API: [Create virtual currency transaction](api-adapty/operations/createVirtualCurrencyTransaction) и [List virtual currency balances](api-adapty/operations/listVirtualCurrencyBalances). Готовый пример — в гайде [Virtual currency quickstart](virtual-currency-quickstart).
- Чтобы открыть флоу пополнения баланса, когда средств недостаточно, воспользуйтесь рецептом для [iOS](ios-virtual-currency-top-up).
