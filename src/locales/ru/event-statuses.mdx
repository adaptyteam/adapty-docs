Adapty определяет доставку на основе HTTP-кода ответа: любой ответ за пределами диапазона `200-399` считается ошибкой.

Вы можете отслеживать статусы событий интеграций в разделе **Event List** дашборда Adapty. Система отображает статусы для всех включённых интеграций вне зависимости от того, активирован ли конкретный тип события для данной интеграции.

- Чёрный: событие успешно отправлено.
- <span style={{ color: 'grey' }}>Серый:</span> этот тип события отключён для данной интеграции.
- <span style={{ color: 'red' }}>Красный:</span> в интеграции есть проблема, требующая внимания.

Чтобы узнать подробности о неудачных событиях, наведите курсор на название интеграции — появится всплывающая подсказка с описанием ошибки.
