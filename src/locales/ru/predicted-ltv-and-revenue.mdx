Прогнозы Adapty помогают ответить на следующие вопросы:

1. Каков прогнозируемый LTV ваших когорт пользователей?
2. Какие когорты, скорее всего, принесут наибольшую выручку в будущем?
3. Сколько можно вложить с учётом ожидаемой отдачи?
С помощью Adapty Predictions вы можете принимать решения о доходах и росте на основе данных.

Модель прогнозирования Adapty оценивает долгосрочный потенциал дохода когорт пользователей вашего приложения. Для каждой когорты она прогнозирует, как будут меняться доход, количество платящих пользователей и средний LTV. Это помогает принимать взвешенные решения в области привлечения пользователей, маркетинговых стратегий и развития продукта.

Adapty предлагает прогноз пожизненной ценности (LTV) и прогноз выручки для когорт платящих пользователей. Прогнозы отображаются на странице когортного анализа через 3, 6, 9, 12, 18 и 24 месяца после создания когорты.

Для приложений с очень короткой историей модель переключается на средние значения по всем приложениям, поэтому прогнозы для новых приложений могут не полностью отражать поведение их конкретных пользователей.

## Как работает модель \{#how-the-model-works\}

Модель прогнозирования Adapty использует паттерны роста из исторических данных когорт для проецирования будущей выручки и LTV.

Для каждой комбинации приложения и типа продукта модель измеряет, как накопленная выручка когорты и накопленное количество платящих пользователей растут между фиксированными точками в жизни когорты, которые отсчитываются в днях с момента её старта. Интервалы между точками короткие, пока когорта молодая, и удлиняются по мере её «взросления»: сначала дни, затем месяцы, потом кварталы. Adapty измеряет пару коэффициентов роста для каждого интервала: один для выручки, другой для платящих пользователей.

Чтобы построить прогноз когорты, Adapty берёт последнюю достигнутую точку и последовательно применяет коэффициенты вперёд — до дня, соответствующего выбранному горизонту: день 90 для прогноза на 3 месяца, день 365 для 12-месячного, день 730 для 24-месячного. Все используемые данные полностью анонимизированы.

Коэффициенты рассчитываются отдельно для каждого типа продукта: еженедельные, ежемесячные, 2-месячные, 3-месячные, 6-месячные и годовые подписки, а также пожизненный доступ и разовые покупки. Прогноз когорты — это сумма прогнозов по каждому типу продукта, который приобретали её пользователи.

Модель выдаёт два значения для каждой когорты:

- **Predicted revenue**: общий доход, который когорта, по прогнозу, принесёт в рамках выбранного горизонта.
- **Predicted LTV**: predicted revenue, делённый на прогнозируемое количество платящих пользователей в когорте.

### Коэффициенты для конкретного приложения и общие коэффициенты \{#app-specific-and-cross-app-coefficients\}

По умолчанию прогноз для когорты использует коэффициенты, рассчитанные на основе прошлых когорт того же типа продукта в этом приложении — с учётом особенностей поведения его пользователей. Приложение получает собственные коэффициенты для типа продукта, как только накапливает не менее двух когорт достаточного размера для измерения.

Два источника смешиваются внутри одного прогноза: там, где собственная история приложения не охватывает какой-либо интервал, Adapty заполняет этот шаг коэффициентами, усреднёнными по всем приложениям, продающим продукт того же типа. Таким образом, молодое приложение может строить прогноз первых недель на основе собственных данных, а остальную часть года — на основе кросс-апп средних значений.

### Доступность и обновление прогнозов \{#availability-and-updates\}

Прогнозы строятся только для недельных и месячных когорт. Если в поле **Cohort length** выбрано «день», «квартал» или «год», колонки с прогнозами остаются пустыми.

Для недельных и месячных когорт доступность прогнозов зависит от того, сколько времени существует когорта, а не от того, какие продукты покупали её пользователи. Первый прогноз для когорты появляется, когда период установки полностью завершился, а пробный период, который мог начаться в этот период, успел конвертироваться.

Период установки длится одну неделю после начала когорты для еженедельной длины когорты и один месяц — для ежемесячной. До его окончания когорта продолжает собирать установки. Пользователь, установивший приложение в последний день, всё ещё может начать самый длинный триал, а выручка когорты учитывается только после того, как триалы конвертируются, — поэтому ожидание равно периоду установки плюс длина самого длинного триала. Чем длиннее триалы, тем позже появляются прогнозы.

После этого прогнозы пересчитываются ежедневно на основе актуальных данных о транзакциях, поэтому они остаются в соответствии с поведением когорты.

### Ограничения \{#limitations\}

- **Качество данных**: нестандартное поведение когорты или небольшое количество платящих пользователей снижает точность. Когорты с менее чем 30 платящими пользователями не получают прогноз и исключаются из обучающих данных модели.
- **Новые приложения**: приложения без достаточной истории используют межприложенческие коэффициенты, которые могут не отражать специфику поведения пользователей конкретного приложения.
- **Возраст когорты**: прогнозы для заданного горизонта скрываются, как только когорта превышает этот горизонт. Например, трёхмесячные прогнозы перестают отображаться по истечении трёх месяцев, а для когорт старше 24 месяцев прогнозы не показываются вовсе.

### Выберите горизонт прогноза \{#select-the-horizon\}

Чтобы изменить горизонт прогноза, выберите нужное значение в выпадающем списке **Predictions**. Доступные варианты: 3, 6, 9, 12, 18 и 24 месяца с момента создания когорты.
### Фильтрация по продукту \{#filter-by-product\}

Вы можете фильтровать прогнозируемый доход и LTV по продукту. По умолчанию прогнозы строятся на основе всех данных о покупках — фильтрация по продукту показывает вклад каждого продукта.

## Когда прогнозы недоступны \{#when-predictions-are-unavailable\}

Если для когорты невозможно построить прогноз, в столбцах Predicted Revenue и Predicted LTV отображаются длинные тире (—) вместо значений. Это может происходить по нескольким причинам:
- **Неподдерживаемая длина когорты**: в параметре **Cohort length** выбрано значение «день», «квартал» или «год». Прогнозы строятся только для недельных и месячных когорт.
- **Неподдерживаемый фильтр или сравнение**: таблица отфильтрована по плейсменту, аудитории, пейволу или A/B-тесту, либо включён период сравнения. Фильтры по продукту, длительности продукта, стране, стору и данным атрибуции прогнозы не скрывают.
- **Недостаточно времени с момента создания когорты**: период установки когорты ещё не завершился, либо у самого длинного триала, который мог начаться за этот период, не было времени конвертироваться. См. [Доступность и обновления](#availability-and-updates).
- **Малый размер когорты**: менее 30 платящих пользователей — слишком мало для надёжного прогноза.
- **Нетипичное поведение когорты**: когорта значительно отклоняется от паттернов, ожидаемых моделью. Через несколько недель, когда накопится больше данных, это может разрешиться само.
- **Горизонт превышен**: когорта старше выбранного горизонта прогноза. Например, 3-месячный прогноз скрывается после трёх месяцев, 12-месячный — после двенадцати, а для когорт старше 24 месяцев прогнозы не отображаются вовсе.

:::warning
При включении прогнозов учтите, что данные прогнозов по Revenue и LTV могут появиться на дашборде Adapty с задержкой до 24 часов.
:::
