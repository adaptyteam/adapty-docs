Сообщения для удержания позволяют взаимодействовать с отписывающимися пользователями в процессе отмены подписки. Когда пользователь открывает экран iOS «Отмена подписки», Apple показывает ему сообщение, соответствующее его продукту и языку.

Существует два вида сообщений для удержания:

- **Default**: Простое win-back сообщение с заголовком, телом и необязательным изображением. Используется как резервный вариант, когда promo-сообщение недоступно.
- **Promo**: Win-back сообщение, предлагающее подписчикам специальную сделку или другой план. Promo-сообщения можно создавать только для продуктов, у которых уже назначено Default-сообщение.

## Прежде чем начать \{#before-you-begin\}

- Создайте хотя бы один [продукт](create-product), который будет охватывать сообщение.
- [Протестируйте Retention Messaging](retention-messaging-setup) в режиме песочницы.

## Создание сообщения \{#create-a-message\}

Откройте страницу Retention Messaging в дашборде Adapty. Нажмите **Create Default** для дефолтного сообщения или **Create Message** для промо-сообщения.

<ZoomImage id="retention-select-default-or-promo.webp" width="700px" alt="Кнопки Create Default и Create Message в заголовке страницы Retention Messaging" />

Выберите окружение — sandbox-сообщение для тестирования или production-сообщение для реальных пользователей.

<ZoomImage id="retention-new-message.webp" width="700px" alt="Стартовый экран нового сообщения с вариантами Create a sandbox message и Create a production message" />

### Общее \{#general\}

Задайте название сообщения и добавьте продукты, отмена которых будет его запускать.

<ZoomImage id="retention-message-step-1-general.webp" width="700px" alt="Default message General step with the Name field and Products section" />

Для **промо**-сообщения настройте стимул, который убедит подписчика остаться:

- **Promo offer**: promotional offer, который вы [заранее настроили для продукта](app-store-offers).

    <ZoomImage id="retention-messaging-promo.webp" width="500px" alt="Promo message General step with an associated offer selected for a product" />

- **Смена тарифа**: другой продукт из вашего каталога.

    <ZoomImage id="retention-messaging-switch-plan.webp" width="500px" alt="Promo message General step with an associated plan selected for a product" />

### Контент \{#content\}

Напишите сообщение на английском языке. Предварительный просмотр справа показывает, как оно будет выглядеть на экране отмены подписки.

Сообщение **Default** может содержать изображение.

<ZoomImage id="retention-message-step-2-content.webp" width="700px" alt="Content step with title, body, and image fields, and a phone preview of the Cancel Subscription screen" />

### Локализация \{#localization\}

Английский язык является исходным. Добавьте остальные языки, которыми пользуются ваши подписчики, и переведите контент.

1. Нажмите **Add Locale** и выберите нужные локали.
2. Нажмите **AI Translate All Cells**, чтобы автоматически перевести [контент](#content).
3. Нажмите на любую ячейку, чтобы отредактировать перевод.

Наведите курсор на локаль, чтобы увидеть предпросмотр экрана отмены подписки.

<ZoomImage id="retention-message-step-3-localization.webp" width="700px" alt="Localization step with the locale table and the AI Translate All Cells button" />

## Отправка на проверку \{#submit-for-review\}

Когда сообщение готово, нажмите **Submit To Review**. Apple проверит его, и статус изменится на **In review**, затем на **Live** или **Rejected**.

Сообщение станет доступно для продакшн-пользователей после того, как Apple одобрит хотя бы одну локаль.

:::note
Apple проверяет каждую локаль отдельно. Подписчики видят ваше сообщение только в одобренных локалях — автоматического резерва на английский нет.
:::
