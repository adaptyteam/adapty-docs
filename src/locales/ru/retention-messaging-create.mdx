Сообщения для удержания позволяют обращаться к отписывающимся пользователям в процессе отмены подписки. Когда пользователь переходит на экран отмены подписки в iOS, Apple показывает ему сообщение, соответствующее его продукту и локали.

Существует два вида сообщений для удержания:

- **Default**: Простое win-back сообщение с заголовком, текстом и необязательным изображением. Используется как резервное, когда promo-сообщение недоступно.
- **Promo**: Win-back сообщение со специальным предложением или альтернативным тарифом для подписчиков. Promo-сообщения можно создавать только для продуктов, которым уже назначено Default-сообщение.

## Прежде чем начать \{#before-you-begin\}

- Создайте хотя бы один [продукт](create-product), который будет охватывать сообщение.
- [Протестируйте Retention Messaging](retention-messaging-setup) в режиме песочницы.

## Создание сообщения \{#create-a-message\}

Откройте страницу Retention Messaging в дашборде Adapty. Нажмите **Create Default** для сообщения по умолчанию или **Create Message** для промо-сообщения.

<ZoomImage id="retention-select-default-or-promo.webp" width="700px" alt="The Create Default and Create Message buttons in the Retention Messaging page header" />

Выберите окружение — sandbox для тестирования или production для реальных пользователей. Опция production остаётся недоступной, пока вы не [настроите production URL](retention-messaging-setup#switch-to-production) и не пройдёте тест производительности в песочнице.

<ZoomImage id="retention-new-message.webp" width="700px" alt="Начальный экран создания нового сообщения с опциями Create a sandbox message и Create a production message" />

### Общее \{#general\}

Назовите сообщение и добавьте продукты, которые будут его запускать при отмене.

В списке продуктов недоступные продукты отображаются серым — с указанием причины рядом: **used** означает, что другое сообщение того же типа уже покрывает этот продукт, а **no default message** означает, что продукту нужно сообщение Default, прежде чем он сможет получить promo-сообщение.

<ZoomImage id="retention-message-step-1-general.webp" width="700px" alt="Default message General step with the Name field and Products section" />

Для **промо**-сообщения привяжите поощрение к каждому добавленному продукту. Один продукт — одно поощрение, и кнопка **Next** остаётся недоступной, пока у каждого продукта не будет поощрения:

- **Link Promo Offer**: promotional offer, который вы [заранее настроили для продукта](app-store-offers).

    <ZoomImage id="retention-messaging-promo.webp" width="500px" alt="Promo message General step with the Associated offers list open for a product" />

- **Link Plan Switch**: другой продукт из вашего каталога. Если список планов пуст, убедитесь, что вы добавили [ключ API App Store Connect](app-store-connection-configuration): Adapty нужен он для поиска планов.

    <ZoomImage id="retention-messaging-switch-plan.webp" width="500px" alt="Promo message General step with the Associated plan list open for a product" />

### Содержимое \{#content\}

Вводите текст сообщения на английском языке. Предварительный просмотр справа показывает, как сообщение будет выглядеть на экране отмены подписки.

Сообщение **Default** может содержать изображение. Добавьте **Alt text**, чтобы описать изображение для программ экранного доступа. Alt text не локализуется: Apple получает английский alt text для всех локалей.

По умолчанию заголовок и текст отображаются под изображением. Чтобы показать заголовок над изображением, выберите **Above the image** в разделе **Title position**. Текст всегда остаётся под изображением.

<ZoomImage id="retention-message-step-2-content.webp" width="700px" alt="Шаг «Content» с загруженным изображением, положение заголовка установлено «Над изображением», и предварительный просмотр на телефоне показывает заголовок над изображением" />

:::important
Выберите положение заголовка при создании сообщения. Изменить его впоследствии нельзя — чтобы использовать другое положение, создайте новое сообщение. Если вы создаёте сообщение без изображения и добавляете его позже, заголовок останется под изображением.
:::

### Локализация \{#localization\}

Английский — исходный язык. Добавьте другие языки, которыми пользуются ваши подписчики, а затем переведите контент.

1. Нажмите **Add Locale** и выберите нужные локали.
2. Нажмите **AI Translate All Cells**, чтобы автоматически перевести [контент](#content). Перевод заменяет заголовок и текст во всех добавленных локалях, включая ваши правки вручную, — поэтому сначала переводите, а потом редактируйте.
3. Нажмите на любую ячейку, чтобы отредактировать перевод.

Каждая локаль должна укладываться в те же ограничения, что и английский оригинал: 66 символов для заголовка и 144 для текста. Перевод, превышающий эти лимиты, заблокирует **Submit To Review** до тех пор, пока вы его не сократите.

Наведите курсор на локаль, чтобы просмотреть превью на экране отмены подписки.

Если Apple ещё не одобрила перевод для нужной локали, Adapty использует версию `en-US`.

<ZoomImage id="retention-message-step-3-localization.webp" width="700px" alt="Шаг локализации с таблицей локалей и кнопкой AI Translate All Cells" />

## Отправка на проверку \{#submit-for-review\}

Когда сообщение готово, нажмите **Submit To Review**. Adapty загружает сообщение в Apple для каждой локали, в которой заполнен заголовок или текст, и Apple начинает проверку. Локали с пустыми полями Adapty игнорирует. Следите за [статусом](#message-states) своей отправки на странице Retention Messaging.

Adapty сохраняет сообщение только в момент отправки.

## Статусы сообщения \{#message-states\}

После отправки сообщения Apple проверяет каждую локаль отдельно. Сообщение публикуется, как только Apple одобряет хотя бы одну локаль. Для локалей, которые ещё не прошли проверку, Adapty [возвращается к `en-US`](#localization). Столбец **State** на странице Retention Messaging позволяет отслеживать статус сообщения:

| Состояние | Что означает |
| --- | --- |
| **In review** | Apple ещё не получила сообщение или не одобрила ни одну из его локализаций. |
| **Live** | Apple одобрила сообщение, и Adapty показывает его отменяющим подписку пользователям. |
| **Rejected** | Apple отклонила заявку хотя бы в одной локализации — попробуйте отправить другую версию. |
| **Inactive** | Вы [деактивировали](#deactivate-and-reactivate) сообщение. Теперь можно создать новое для тех же продуктов. |

Чтобы узнать, какие локали ещё не одобрены Apple, откройте сообщение и перейдите на шаг **Localization**. Для каждой добавленной локали отображается собственный статус: **Live**, **In review** или **Rejected**.

Вы можете редактировать любое сообщение в любое время — в том числе то, которое в данный момент отображается пользователям. Если вы отредактируете сообщение со статусом **Live** или добавите к нему новую локаль, оно немедленно потеряет статус **Live** и снова станет **In review**.

Если вы изменили заголовок или текст существующего сообщения на английском, кнопка шага **Content** меняется на **Update Locales**. Нажмите её, чтобы открыть шаг **Localization**, обновите переводы и нажмите **Submit To Review**.

## Деактивация и повторная активация \{#deactivate-and-reactivate\}

Чтобы убрать сообщение из Apple, не удаляя его из Adapty, откройте меню в строке сообщения и нажмите **Deactivate**.

Чтобы вернуть его, нажмите **Activate**. Повторная активация не требует проверки Apple, и сообщение может занять несколько минут, чтобы достичь всех подписчиков.

У продукта может быть не более одного сообщения по умолчанию и одного промо-сообщения. Если пока это сообщение было неактивно другое сообщение того же типа заняло продукт, активация завершится с ошибкой.
