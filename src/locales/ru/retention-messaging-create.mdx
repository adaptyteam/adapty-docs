Сообщения для удержания позволяют обращаться к отписывающимся пользователям в процессе отмены подписки. Когда пользователь переходит на экран отмены подписки в iOS, Apple показывает ему сообщение, соответствующее его продукту и локали.

Существует два вида сообщений для удержания:

- **Default**: Простое win-back сообщение с заголовком, текстом и необязательным изображением. Используется как резервное, когда promo-сообщение недоступно.
- **Promo**: Win-back сообщение со специальным предложением или альтернативным тарифом для подписчиков. Promo-сообщения можно создавать только для продуктов, которым уже назначено Default-сообщение.

## Прежде чем начать \{#before-you-begin\}

- Создайте хотя бы один [продукт](create-product), который будет охватывать сообщение.
- [Протестируйте Retention Messaging](retention-messaging-setup) в режиме песочницы.

## Создание сообщения \{#create-a-message\}

Откройте страницу Retention Messaging в дашборде Adapty. Нажмите **Create Default** для дефолтного сообщения или **Create Message** для промо-сообщения.

<ZoomImage id="retention-select-default-or-promo.webp" width="700px" alt="Кнопки Create Default и Create Message в заголовке страницы Retention Messaging" />

Выберите окружение — sandbox-сообщение для тестирования или production-сообщение для реальных пользователей.

<ZoomImage id="retention-new-message.webp" width="700px" alt="Стартовый экран нового сообщения с вариантами Create a sandbox message и Create a production message" />

### Общее \{#general\}

Задайте название сообщения и добавьте продукты, отмена которых будет его запускать.

<ZoomImage id="retention-message-step-1-general.webp" width="700px" alt="Default message General step with the Name field and Products section" />

Для **промо**-сообщения настройте стимул, который убедит подписчика остаться:

- **Promo offer**: promotional offer, который вы [заранее настроили для продукта](app-store-offers).

    <ZoomImage id="retention-messaging-promo.webp" width="500px" alt="Promo message General step with an associated offer selected for a product" />

- **Смена тарифа**: другой продукт из вашего каталога.

    <ZoomImage id="retention-messaging-switch-plan.webp" width="500px" alt="Promo message General step with an associated plan selected for a product" />

### Контент \{#content\}

Напишите сообщение на английском языке. Предварительный просмотр справа показывает, как оно будет выглядеть на экране отмены подписки.

Сообщение **Default** может содержать изображение.

<ZoomImage id="retention-message-step-2-content.webp" width="700px" alt="Content step with title, body, and image fields, and a phone preview of the Cancel Subscription screen" />

### Локализация \{#localization\}

Английский — исходный язык. Добавьте остальные языки, которые используют ваши подписчики, а затем переведите контент.

1. Нажмите **Add Locale** и выберите нужные локали.
2. Нажмите **AI Translate All Cells**, чтобы автоматически перевести [контент](#content).
3. Нажмите на любую ячейку, чтобы отредактировать перевод.

Наведите указатель на локаль, чтобы просмотреть её на экране отмены подписки.

Если Apple ещё не одобрила перевод для целевой локали, Adapty использует версию на `en-US`.

<ZoomImage id="retention-message-step-3-localization.webp" width="700px" alt="Шаг локализации с таблицей локалей и кнопкой AI Translate All Cells" />

## Отправка на проверку \{#submit-for-review\}

Когда сообщение готово, нажмите **Submit To Review**. Adapty загружает сообщение в Apple для всех добавленных вами локалей, и Apple начинает проверку. Следите за [статусом](#message-states) вашей заявки на странице Retention Messaging.

## Статусы сообщений \{#message-states\}

После отправки сообщения Apple проверяет каждую его локаль. Каждая локаль проверяется отдельно, но сообщение публикуется только тогда, когда *все локали* одобрены. Колонка **State** на странице Retention Messaging позволяет отслеживать статус сообщения:

| Статус | Что означает |
| --- | --- |
| **Draft** | Вы ещё не отправили сообщение. Adapty не сохраняет его до отправки. |
| **In review** | Apple ещё не получила сообщение или не завершила проверку для всех локалей. |
| **Live** | Apple одобрила сообщение, и Adapty показывает его отменяющим подписку пользователям. |
| **Rejected** | Apple отклонила отправку хотя бы для одной локали — попробуйте отправить альтернативную версию. |
| **Inactive** | Вы [деактивировали](#deactivate-and-reactivate) сообщение. Теперь можно создать новое для тех же продуктов. |

Вы можете редактировать любое сообщение в любое время — в том числе то, которое прямо сейчас показывается вашим пользователям. Если вы отредактируете сообщение со статусом **Live** или добавите к нему новую локаль, оно сразу потеряет этот статус и снова станет сообщением **In Review**.

## Деактивация и реактивация \{#deactivate-and-reactivate\}

Чтобы удалить сообщение из Apple, не удаляя его из Adapty, откройте меню в строке сообщения и нажмите **Deactivate**.

Чтобы вернуть его, нажмите **Activate**. Сообщение снова перейдёт в статус **In review**, пока Adapty загружает его в Apple.

У продукта может быть не более одного дефолтного сообщения и одного промосообщения. Если пока сообщение было неактивно другое сообщение того же типа заняло продукт, активация завершится ошибкой.
