Если вы используете [режим Observer](observer-vs-full-mode), вы сами отвечаете за логику покупок. При этом UI пейвола можно делегировать [Flow & Paywall Builder](adapty-flow-builder).

Создайте экран в билдере, и SDK Adapty отрисует его нативно. Обновляйте тексты, макет и цены в любой момент — без выпуска нового релиза приложения.

В этом гайде показано, как отобразить флоу и обработать колбэки покупок. Если Adapty выполняет покупки за вас, см. [Отображение флоу и пейволов](flutter-present-paywalls).

## Прежде чем начать \{#before-you-start\}

Вам потребуется:

- **Adapty Flutter SDK 4.0 или выше**: Более ранние версии не поддерживают рендеринг флоу. Для миграции существующего приложения см. [руководство по миграции](migration-to-flutter-sdk-v4).
- **`observerMode` установлен в `true`**: См. [руководство по установке Flutter SDK](sdk-installation-flutter#activate-adapty-module-of-adapty-sdk).
- **Базовая интеграция со стором**: Настройте Adapty [с App Store](initial_ios) и [с Google Play](initial-android).
- **Опубликованный флоу с продуктами**: Создайте его в [Flow & Paywall Builder](adapty-flow-builder) и назначьте ему [продукты](create-product).
- **Плейсмент для флоу**: [Создайте плейсмент](create-placement) и назначьте ему ваш флоу.
- **Флоу, загруженный в приложении**: [Получите флоу и его конфигурацию](flutter-get-pb-paywalls) перед отображением.

## Реализация \{#implementation\}

В режиме Observer SDK не совершает покупки за вас. Когда пользователь нажимает кнопку покупки или восстановления во флоу, отрендеренном Adapty, SDK вызывает ваш `AdaptyUIObserverModeResolver` — выполните покупку или восстановление с помощью вашего собственного кода там.

1. Реализуйте `AdaptyUIObserverModeResolver`:

   ```dart showLineNumbers title="Flutter"
   class MyObserverModeResolver extends AdaptyUIObserverModeResolver {
     @override
     void observerModeDidInitiatePurchase(
       AdaptyUIFlowView view,
       AdaptyPaywallProduct product,
       void Function() onStartPurchase,
       void Function() onFinishPurchase,
     ) {
       onStartPurchase(); // the view shows its loading indicator
       // make the purchase with your own code, then:
       onFinishPurchase(); // the view hides the loading indicator
     }

     @override
     void observerModeDidInitiateRestore(
       AdaptyUIFlowView view,
       void Function() onStartRestore,
       void Function() onFinishRestore,
     ) {
       onStartRestore();
       // restore purchases with your own code, then:
       onFinishRestore();
     }
   }
   ```

Метод `observerModeDidInitiatePurchase` сообщает, что пользователь инициировал покупку, а `observerModeDidInitiateRestore` — что пользователь инициировал восстановление покупок. В ответ на эти события запускайте свой кастомный флоу покупки или восстановления.

   Также не забудьте вызвать следующие коллбэки, чтобы уведомить AdaptyUI о процессе покупки или восстановления. Это необходимо для корректного поведения флоу — например, для отображения загрузчика:

| Callback           | Описание                                                                                            |
   | :----------------- | :-------------------------------------------------------------------------------------------------- |
   | onStartPurchase()  | Callback должен вызываться, чтобы уведомить AdaptyUI о начале покупки.    |
   | onFinishPurchase() | Callback должен вызываться, чтобы уведомить AdaptyUI о завершении покупки. |
   | onStartRestore()   | Callback должен вызываться, чтобы уведомить AdaptyUI о начале восстановления покупок.    |
   | onFinishRestore()  | Callback должен вызываться, чтобы уведомить AdaptyUI о завершении восстановления покупок.  |

2. Зарегистрируйте резолвер до отображения любого экрана:

   ```dart showLineNumbers title="Flutter"
   AdaptyUI().setObserverModeResolver(MyObserverModeResolver());
   ```

3. Создайте и отобразите флоу как обычно: [получите флоу и создайте его вид](flutter-get-pb-paywalls), затем [отобразите его](flutter-present-paywalls). Дополнительные параметры не нужны — после регистрации резолвера все покупки и восстановления в любом флоу, отрисованном Adapty, будут проходить через него.

:::warning
Не забудьте [сообщить о транзакции и связать её с пейволом](report-transactions-observer-mode-flutter). В противном случае Adapty не распознает транзакцию и не определит исходный пейвол покупки.
:::
