Каждый раз, когда пользователь открывает экран [флоу](adapty-flow-builder), SDK отправляет в ваше приложение событие `flow_screen_showed`. Передавайте его в Amplitude, Mixpanel или любую другую продуктовую аналитику, которую вы используете, чтобы анализировать экраны флоу вместе с остальными событиями приложения.

:::tip
Чтобы узнать, как далеко пользователи проходят флоу, код не нужен — [метрики флоу](flow-metrics) уже показывают просмотры, завершения и отток по каждому экрану в дашборде Adapty. Используйте этот гайд, когда вам нужны те же данные в вашей аналитике, объединённые с событиями, о которых Adapty не знает.
:::

## Прежде чем начать \{#before-you-start\}

Вам понадобится:

- **Adapty Unity SDK v4 или выше**: коллбэк аналитики флоу отсутствует в более ранних версиях.
- **Версия флоу, опубликованная после выхода этой функции**: Adapty генерирует события экранов при публикации флоу, поэтому флоу, опубликованный до этого момента, не передаёт никаких событий. Если события не поступают в ваше приложение, опубликуйте новую версию флоу и попробуйте снова.

## Что вы получаете \{#what-you-receive\}

<FlowScreenShowedParams />

Просмотры экранов поступают в тот же аналитический коллбэк, что и все остальные события флоу. Подробнее о том, где его зарегистрировать, читайте в разделе [Обработка событий флоу и пейвола](unity-handling-events).

## Пересылайте каждый показ экрана в аналитику \{#forward-every-screen-view-to-your-analytics\}

Сначала проверьте имя события, прежде чем читать что-либо ещё, потому что флоу передаёт другие события через тот же колбэк.

```csharp showLineNumbers title="Unity"
public void FlowViewDidReceiveAnalyticEvent(
    AdaptyUIFlowView view,
    string name,
    IDictionary<string, object> @params
) {
    if (name != "flow_screen_showed") return;

    var screenId = @params["instanceId"];
    var screenOrder = @params["screen_order"];

    // Send screenId and screenOrder to your analytics provider here.
}
```

## Запуск кода, когда пользователь достигает конца флоу \{#run-code-when-a-user-reaches-the-end\}

`is_last_screen` равно `true` на экране, дальше которого флоу не продвигается. Используйте это, чтобы разблокировать контент, отметить онбординг как завершённый или отправить собственное событие завершения — без добавления действия кнопки в конструкторе.

```csharp showLineNumbers title="Unity"
public void FlowViewDidReceiveAnalyticEvent(
    AdaptyUIFlowView view,
    string name,
    IDictionary<string, object> @params
) {
    if (name != "flow_screen_showed") return;
    if (!(@params["is_last_screen"] is bool isLast) || !isLast) return;

    // The user reached the end of the flow.
}
```

Достижение последнего экрана — это не то же самое, что закрытие флоу. Пользователь может увидеть финальный экран и закрыть флоу, не предприняв никаких действий, а ветвящийся флоу может завершаться на нескольких разных экранах. Чтобы узнать, что флоу закрылся, используйте вместо этого `FlowViewDidDisappear`.
