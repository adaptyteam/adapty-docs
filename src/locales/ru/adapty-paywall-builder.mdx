Adapty **Paywall Builder** — это более ранний no-code инструмент для создания пейволов, который больше не развивается. Для его работы требуется Adapty SDK v3.0 или выше. Не создавайте здесь новые пейволы, особенно на SDK v4. Те, что вы уже создали, продолжают работать — SDK v4 рендерит их через те же методы, что и флоу.

Чтобы пересоздать существующий пейвол как флоу в один клик, см. [Конвертация пейвола во флоу](convert-paywall-to-flow).
