Следуйте этому рецепту, чтобы отобразить прогнозируемый вес пользователя в виде графика в пейволе флоу. Пользователь вводит текущий и целевой вес в процессе онбординга. Ваше приложение собирает оба значения. График показывает недельный прогресс, которого пользователь может ожидать с вашим приложением, — от одного значения к другому. Приложение отображает график как нативный вид в [кастомном элементе](flow-custom-elements). На iOS вид использует Swift Charts. На Android график отрисовывается без сторонней библиотеки для графиков.

## Прежде чем начать \{#before-you-start\}

- Обновите приложение до Adapty React Native SDK 4.4 или новее. В более ранних версиях SDK вместо каждого кастомного элемента отображается [резервный контент](flow-custom-elements#set-fallback-content).
- Настройте приложение для [получения](react-native-get-pb-paywalls) и [отображения](react-native-present-paywalls) флоу.
- Настройте нативный код приложения для кастомных элементов, как описано в [гайде для React Native](react-native-flow-custom-elements#before-you-start).
- На iOS перетаскивание по графику требует iOS 17 или новее. На iOS 16 пользователи видят линию, но не могут перемещаться по ней.
- На Android [настройте Jetpack Compose](react-native-flow-custom-elements#set-up-jetpack-compose) в модуле приложения. График в этом рецепте является composable. Добавьте Compose Foundation в приложение через Gradle из `androidx.compose.foundation:foundation` без указания версии. Версию задаёт Compose BOM из `io.adapty:android-ui`.

## 3. Сохраните текущий и целевой вес в вашем приложении \{#3-save-the-current-and-goal-weight-in-your-app\}

Собирайте текущий и целевой вес из событий `flow_user_input` онбординг-флоу, как описано в разделе [Обработка данных из флоу](react-native-flow-input). Чтобы определить, что пользователь дошёл до последнего экрана, отслеживайте событие `flow_screen_showed` со значением `is_last_screen` равным `true`. Когда онбординг-флоу закроется после этого экрана, передайте оба значения веса в `showWeightPaywall` — функцию, которая [открывает пейвол-флоу с графиком](#6-send-the-weights-from-your-javascript-code).

Следующая функция возвращает обработчики `onAnalytics` и `onDisappeared` флоу онбординга:

```typescript showLineNumbers title="weightOnboardingHandlers.ts"

// the event handlers of the onboarding flow view
export function weightOnboardingHandlers(): Partial<FlowEventHandlers> {
  const enteredWeights: Record<string, string> = {};
  let reachedLastScreen = false;

  return {
    onAnalytics(name, params) {
      if (name === 'flow_screen_showed' && params.is_last_screen === true) {
        reachedLastScreen = true;
      } else if (
        name === 'flow_user_input' &&
        typeof params.element_id === 'string' &&
        typeof params.value === 'string'
      ) {
        enteredWeights[params.element_id] = params.value;
      }
      return false; // keep the flow open
    },
    onDisappeared() {
      // number inputs send their values as strings
      const currentWeight = Number.parseFloat(enteredWeights.weight ?? '');
      const goalWeight = Number.parseFloat(enteredWeights.goal_weight ?? '');
      if (reachedLastScreen && !Number.isNaN(currentWeight) && !Number.isNaN(goalWeight)) {
        showWeightPaywall(currentWeight, goalWeight);
      }
      return false;
    },
  };
}
```

Перед показом флоу онбординга передайте обработчики в его представление:

```typescript showLineNumbers title="React Native"
const view = await createFlowView(flow);
view.setEventHandlers(weightOnboardingHandlers());
await view.present();
```

Если в вашем приложении уже заданы `onAnalytics` или `onDisappeared` для флоу онбординга, добавьте код `weightOnboardingHandlers` к своим обработчикам. Каждый обработчик, переданный в `setEventHandlers`, заменяет ранее установленный обработчик с тем же именем.

## 4. Создайте представление графика \{#create-the-chart-view\}

Создайте модель плана снижения веса и представление с графиком. В плане есть одна запись на каждую неделю — от текущего веса до целевого. Когда пользователь проводит пальцем по графику, представление отмечает неделю в точке касания и показывает прогнозируемый вес для этой недели:

```swift showLineNumbers title="Swift"

struct WeightPlan {
    let entries: [WeightEntry]

    // One entry per week, from the current weight to the goal weight
    init(currentWeight: Double, goalWeight: Double) {
        let weeklyChange = 0.5 // kg per week
        let startDate = Date.now
        let weeks = Int((abs(goalWeight - currentWeight) / weeklyChange).rounded(.up))
        let step = goalWeight < currentWeight ? -weeklyChange : weeklyChange
        entries = (0...weeks).map { week in
            WeightEntry(
                date: startDate.addingTimeInterval(Double(week) * 7 * 24 * 60 * 60),
                kilograms: week == weeks ? goalWeight : currentWeight + step * Double(week)
            )
        }
    }
}

struct WeightEntry: Identifiable {
    let date: Date
    let kilograms: Double
    var id: Date { date }
}

@available(iOS 16.0, *) // Swift Charts needs iOS 16
struct WeightGoalChart: View {
    let entries: [WeightEntry]
    @State private var selectedDate: Date?

    // The entry closest to the date that the user drags to
    private var selectedEntry: WeightEntry? {
        guard let selectedDate else { return nil }
        return entries.min {
            abs($0.date.timeIntervalSince(selectedDate)) < abs($1.date.timeIntervalSince(selectedDate))
        }
    }

    var body: some View {
        if #available(iOS 17.0, *) {
            chart.chartXSelection(value: $selectedDate)
        } else {
            chart // iOS 16: no drag selection
        }
    }

    private var chart: some View {
        Chart {
            ForEach(entries) { entry in
                LineMark(
                    x: .value("Date", entry.date),
                    y: .value("Weight", entry.kilograms)
                )
            }
            if let selectedEntry {
                RuleMark(x: .value("Date", selectedEntry.date))
                    .foregroundStyle(.gray.opacity(0.3))
                PointMark(
                    x: .value("Date", selectedEntry.date),
                    y: .value("Weight", selectedEntry.kilograms)
                )
                .annotation(position: .top) {
                    Text("\(selectedEntry.kilograms, specifier: "%.1f") kg")
                        .font(.caption.bold())
                }
            }
        }
        .chartYScale(domain: .automatic(includesZero: false))
    }
}
```

```kotlin showLineNumbers title="Kotlin"

class WeightPlan(currentWeight: Double, goalWeight: Double) {
    // one entry per week, from the current weight to the goal weight
    val entries: List<WeightEntry> = run {
        val weeklyChange = 0.5 // kg per week
        val start = System.currentTimeMillis()
        val weekMillis = 7L * 24 * 60 * 60 * 1000
        val weeks = ceil(abs(goalWeight - currentWeight) / weeklyChange).toInt()
        val step = if (goalWeight < currentWeight) -weeklyChange else weeklyChange
        (0..weeks).map { week ->
            val kilograms = if (week == weeks) goalWeight else currentWeight + step * week
            WeightEntry(Date(start + week * weekMillis), kilograms)
        }
    }
}

data class WeightEntry(val date: Date, val kilograms: Double)

@Composable
fun WeightGoalChart(entries: List<WeightEntry>) {
    // the week under the finger, or null when the user isn't dragging
    var selectedIndex by remember { mutableStateOf<Int?>(null) }
    val textMeasurer = rememberTextMeasurer()
    val dateFormat = remember { DateFormat.getDateInstance(DateFormat.MEDIUM) }
    val color = Color(0xFFAF52DE)
    val textStyle = TextStyle(color = Color.Gray, fontSize = 12.sp)
    val minKg = entries.minOf { it.kilograms }
    val kgRange = (entries.maxOf { it.kilograms } - minKg).coerceAtLeast(1.0)

    Canvas(
        Modifier
            .fillMaxSize()
            .pointerInput(entries) {
                // horizontal drags select a week; vertical drags scroll the screen
                detectHorizontalDragGestures(
                    onDragEnd = { selectedIndex = null },
                    onDragCancel = { selectedIndex = null },
                ) { change, _ ->
                    val index = (change.position.x / size.width * entries.lastIndex).roundToInt()
                    selectedIndex = index.coerceIn(0, entries.lastIndex)
                }
            }
    ) {
        val startDate = textMeasurer.measure(dateFormat.format(entries.first().date), textStyle)
        val endDate = textMeasurer.measure(dateFormat.format(entries.last().date), textStyle)
        val dateY = size.height - startDate.size.height
        val top = 24.dp.toPx() // room for the projected weight above the line
        val bottom = dateY - 8.dp.toPx()
        fun pointOf(index: Int) = Offset(
            x = size.width * index / entries.lastIndex.coerceAtLeast(1),
            y = bottom - ((entries[index].kilograms - minKg) / kgRange * (bottom - top)).toFloat(),
        )

        // the line from the current weight to the goal weight
        for (index in 1..entries.lastIndex) {
            drawLine(color, pointOf(index - 1), pointOf(index), strokeWidth = 2.dp.toPx())
        }
        // the dates of the first and the last week
        drawText(startDate, topLeft = Offset(0f, dateY))
        drawText(endDate, topLeft = Offset(size.width - endDate.size.width, dateY))

        // the selected week: a point, and the projected weight above it
        selectedIndex?.let { index ->
            val point = pointOf(index)
            drawCircle(color, radius = 5.dp.toPx(), center = point)
            val weight = String.format(Locale.getDefault(), "%.1f kg", entries[index].kilograms)
            val label = textMeasurer.measure(weight, textStyle.copy(color = color))
            val x = (point.x - label.size.width / 2)
                .coerceAtMost(size.width - label.size.width)
                .coerceAtLeast(0f)
            drawText(label, topLeft = Offset(x, point.y - label.size.height - 8.dp.toPx()))
        }
    }
}
```

## 5. Сопоставьте график с кастомным элементом \{#match-the-chart-to-the-custom-element\}

Если у вашего приложения ещё нет общего [резолвера](react-native-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views), скопируйте весь код:

```swift showLineNumbers title="Swift" {4-8,11,19-23}
// the weight plan that your JavaScript code sends before the paywall flow opens
@MainActor
final class WeightPlanStore {
    var plan: WeightPlan?

struct CustomElementsResolver: AdaptyUICustomElementsResolver {
    let weightPlanStore: WeightPlanStore

    func view(
        forType type: String,
        id: String,
        context: AdaptyUICustomElementContext
    ) -> AnyView? {
        switch type {
        case "line_chart" where id == "weight_goal":
            guard #available(iOS 16.0, *), let plan = weightPlanStore.plan else {
                return nil // no weight plan: show the fallback
            }
            return AnyView(WeightGoalChart(entries: plan.entries))
        // the other cases of your resolver
        default:
            return nil
        }
    }
}
```

```kotlin showLineNumbers title="Kotlin" {4-7,10,15-22}
}
```

## 6. Отправьте веса из вашего JavaScript-кода \{#6-send-the-weights-from-your-javascript-code\}

Установите резолвер при запуске приложения и заполняйте стор из JavaScript-кода через [Turbo Native Module](https://reactnative.dev/docs/turbo-native-modules-introduction). Модуль содержит JavaScript-спецификацию и реализацию для каждой платформы.

В папке `specs` в корне вашего проекта создайте спецификацию модуля:

```typescript showLineNumbers title="specs/NativeWeightPlanStore.ts"

export interface Spec extends TurboModule {
  setWeights(currentWeight: number, goalWeight: number): void;
}

export default TurboModuleRegistry.getEnforcing<Spec>('NativeWeightPlanStore');
```

Чтобы сгенерировать нативный код спецификации, добавьте `codegenConfig` в `package.json`. Замените `com.example.app` на имя пакета вашего Android-приложения — в `package.json` и в Kotlin-реализации модуля. Если `codegenConfig` в `package.json` уже есть, добавьте только `NativeWeightPlanStore` в объект `modulesProvider`:

```json showLineNumbers title="package.json"
"codegenConfig": {
  "name": "AppSpecs",
  "type": "modules",
  "jsSrcsDir": "specs",
  "android": {
    "javaPackageName": "com.example.app.specs"
  },
  "ios": {
    "modulesProvider": {
      "NativeWeightPlanStore": "RCTNativeWeightPlanStore"
    }
  }
}
```

Реализуйте модуль для каждой платформы:

В `AppDelegate.swift` добавьте свойство для плана веса. В методе `application(_:didFinishLaunchingWithOptions:)` установите resolver и подпишитесь на `NotificationCenter`, чтобы обновлять план веса при каждой паре весов. Выделенные строки показывают, что нужно добавить. Остальную часть класса `AppDelegate` оставьте без изменений:

```swift showLineNumbers title="ios/YourApp/AppDelegate.swift" {1,6-7,13-26}

@main
class AppDelegate: UIResponder, UIApplicationDelegate {
  // the weight plan that your JavaScript code sends
  let weightPlanStore = WeightPlanStore()

  func application(
    _ application: UIApplication,
    didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]? = nil
  ) -> Bool {
    AdaptyUI.setCustomElementsResolver(CustomElementsResolver(weightPlanStore: weightPlanStore))
    // the weights that your JavaScript code sends through the native module
    NotificationCenter.default.addObserver(
      forName: Notification.Name("WeightsDidChange"),
      object: nil,
      queue: .main
    ) { [weightPlanStore] notification in
      guard let currentWeight = notification.userInfo?["current"] as? Double,
            let goalWeight = notification.userInfo?["goal"] as? Double
      else { return }
      MainActor.assumeIsolated {
        weightPlanStore.plan = WeightPlan(currentWeight: currentWeight, goalWeight: goalWeight)
      }
    }
    // the rest of your launch code
    return true
  }
}
```

Чтобы сгенерировать нативный код спецификации, выполните команду `pod install` в папке `ios`.

## 7. Протестируйте на устройстве \{#7-test-on-a-device\}

Paywall Builder не может запустить код вашего приложения, поэтому на холсте отображается только резервный вариант. Чтобы предварительно посмотреть график:

1. [Опубликуйте оба флоу](builder-save-publish). Чтобы увидеть последние опубликованные версии вместо кэшированных, зарегистрируйте устройство как [тестовое](test-devices).
2. Запустите сборку приложения, включающую резолвер. На iOS используйте устройство с iOS 17 или выше. Пройдите онбординг, указав текущий и целевой вес. Убедитесь, что линия графика начинается с текущего веса и заканчивается целевым.
3. Проведите пальцем по графику и убедитесь, что прогнозируемый вес для недели под пальцем отображается над линией.

Чтобы протестировать резервный вариант, не возвращайте никакого представления для типа `line_chart` и снова откройте флоу с пейволом.

Чтобы разобраться, почему вместо графика отображается резервный вариант, следуйте инструкциям в разделе [Тестирование на устройстве](react-native-flow-custom-elements#test-on-a-device) руководства по React Native.
