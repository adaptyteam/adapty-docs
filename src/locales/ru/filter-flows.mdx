На странице [**Flows**](https://app.adapty.io/flows) отображаются все флоу вашего приложения с их [статусом](#filter-by-status) и основными [метриками](flow-metrics). Нажмите на флоу, чтобы открыть полные [метрики](flow-metrics) или, если у вас роль **Developer**, — [Flow Builder](adapty-flow-builder).

<ZoomImage id="flow-list.webp" width="700px" alt="Страница флоу с полем поиска, фильтром All states, сортируемыми колонками Flow name и Status, и открытым контекстным меню" />

## Поиск по имени \{#search-by-name\}

**Поиск по имени флоу** находит совпадения с любой частью названия флоу. Он не ищет по плейсментам, продуктам или содержимому экранов.

## Фильтрация по статусу \{#filter-by-status\}

Откройте фильтр **All states** над списком, выберите один или несколько статусов и нажмите **Apply**. В разделе [Сохранение и публикация флоу](builder-save-publish#flow-status) объясняется, что означает каждый статус и как флоу переходит между ними.

<ZoomImage id="flows-filter-by-state.webp" width="300px" alt="Открытый фильтр All states с чекбоксами для каждого статуса флоу и кнопкой Apply" />

## Фильтрация по плейсменту \{#filter-by-placement\}

Откройте фильтр **All placements** над списком, выберите один или несколько [плейсментов](placements) и нажмите **Apply**. Этот фильтр появляется, когда хотя бы один флоу назначен на плейсмент.

<ZoomImage id="flows-filter-by-placement.webp" width="300px" alt="Открытый фильтр All placements с двумя плейсментами, флажками и кнопкой Apply" />

## Сортировка \{#sort\}

Можно сортировать по **Flow name** или **Status**. Столбцы с метриками сортировке не поддаются. По умолчанию сначала идут опубликованные флоу, в конце — архивные.

## Действия с флоу \{#flow-actions\}

Откройте контекстное меню <Inline id="context.svg" alt="Context menu" /> в строке флоу.

| Действие | Что делает |
| :----- | :----------- |
| **Metrics** | Открывает [метрики](flow-metrics) флоу. |
| **Edit** | Открывает флоу в [Flow Builder](adapty-flow-builder). |
| **Copy** | [Копирует флоу](copy-flows) как новый черновик. |
| **Archive** | [Архивирует флоу](archive-flows). |

Меню архивированного флоу показывает **Metrics** и **Back to active** — последнее [восстанавливает флоу](archive-flows#restore-a-flow).
