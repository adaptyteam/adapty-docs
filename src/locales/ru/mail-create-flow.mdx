В Adapty Mail **флоу** направляет пользователей в кампании при срабатывании триггера. Флоу начинает работать сразу после добавления строки — отдельного шага запуска нет. Вы настраиваете его как приоритетный список строк внутри фиксированного представления триггера, где каждая строка задаёт сегмент и кампанию, которую он получает. В этом гайде описано, как добавлять, переупорядочивать, редактировать и удалять эти строки. Концепции триггеров, приоритетов и типов контента рассмотрены в разделе [Флоу](mail-flows).

## Добавление строки \{#add-a-row\}

1. В Adapty Mail перейдите в **Flows** и откройте нужный триггер.
2. Нажмите **Create**, чтобы открыть диалоговое окно.

   <ZoomImage id="create-flow-mail.webp" width="500px" alt="Диалог создания потока с полями Segment, Content type и Campaign" />

3. В диалоговом окне:
   - **Segment**: Выберите сегмент или **All Users**, чтобы охватить всех пользователей.
   - **Content type**: **Campaign** — для одной кампании, или **A/B Test** — чтобы сравнить несколько вариантов (см. [A/B-тестирование](mail-ab-testing)).
   - **Campaign**: Выберите кампанию для отправки. В списке отображаются только кампании, написанные для данного триггера — см. [назначение](mail-create-campaign).
   <ZoomImage id="mail-flow-details.webp" width="500px" alt="Flow details view with a prioritized list of segment-to-campaign rows" />

4. Нажмите **Save**.

Строка активируется немедленно. Пользователи, которые попадают под условие триггера и соответствуют сегменту, начинают получать кампанию с этого момента.

## Переупорядочивание строк \{#reorder-rows\}

Перетащите маркер слева от строки, чтобы изменить её приоритет. Adapty Mail автоматически присваивает `priority: 1, 2, 3…` в соответствии с сохранённым порядком.

Строка **All Users** должна оставаться последней — перемещение её выше другой строки заблокировано при сохранении.

## Редактирование строки \{#edit-a-row\}

Нажмите **Change content** на нужной строке, чтобы открыть диалоговое окно с предзаполненными текущими значениями. Можно изменить сегмент, тип контента и кампанию, затем нажать **Save** для применения изменений.

Строку с A/B-тестом можно редактировать только пока тест находится в состоянии **draft**. После запуска теста его контент заблокирован до завершения теста.

## Удаление строки \{#delete-a-row\}

Откройте меню действий строки и нажмите **Delete**. Подтверждение не запрашивается — строка удаляется немедленно.

- **Строки с кампанией**: можно удалить в любое время.
- **Строки с активным A/B-тестом**: удалить нельзя. Сначала завершите тест с помощью **Finish A/B test**, затем удалите строку.

:::note
Удаление строки останавливает попадание новых пользователей в последовательность. Пользователи, уже находящиеся в середине последовательности, могут продолжать получать запланированные письма — автоматической отмены нет.
:::
