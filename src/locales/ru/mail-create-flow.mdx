В Adapty Mail **флоу** связывает **триггер** с **кампанией**, а **пользовательский сегмент** определяет, кто её получит.

Триггер — это событие, которое запускает флоу. У каждого триггера есть своя вкладка, где вы сопоставляете сегменты с кампаниями, которые они получат, в порядке приоритета.

Этот гайд описывает, как добавлять, упорядочивать, редактировать и удалять сегменты. Полный обзор концепций см. в разделе [Флоу](mail-flows).

## Добавьте сегмент во флоу \{#add-a-segment-to-a-flow\}

1. В Adapty Mail перейдите в **Flows** и откройте нужный триггер.
2. Нажмите **Create**, чтобы открыть диалоговое окно.

   <ZoomImage id="create-flow-mail.webp" width="500px" alt="Диалоговое окно создания флоу с полями Segment, Content type и Campaign" />

3. В диалоге:
   - **Segment**: выберите сегмент или **All Users** как универсальный вариант.
   - **Content type**: **Campaign** для одной кампании или **A/B Test** для сравнения нескольких — см. [A/B-тестирование](mail-ab-testing).
   - **Campaign**: выберите кампанию для отправки. В списке отображаются только кампании, написанные для данного триггера — см. [назначение](mail-create-campaign).
   <ZoomImage id="mail-flow-details.webp" width="500px" alt="Flow details view with a prioritized list of segment-to-campaign rows" />

4. Нажмите **Save**.

Флоу запускается сразу после сохранения. Пользователи, которые попадают под триггер и соответствуют сегменту, начинают получать кампанию с этого момента, причём первое письмо придёт через заданную [**задержку**](mail-flows#email-delivery-timing).

## Изменение приоритета \{#change-priority\}

Чтобы изменить порядок, перетащите строку за маркер слева.

**All Users**, если присутствует, должна иметь наименьший приоритет — то есть быть последней записью для триггера. Иначе флоу не сохранится.

## Изменение контента для сегмента \{#change-what-a-segment-receives\}

Нажмите **Change content** в строке, чтобы открыть диалог с уже заполненными текущими значениями. Вы можете изменить сегмент, тип контента и кампанию, а затем нажать **Save** для применения изменений.

Сегмент, связанный с A/B-тестом, можно редактировать только пока тест находится в состоянии **draft**. После запуска теста его контент блокируется до завершения теста.

## Удаление сегмента из флоу \{#remove-a-segment-from-a-flow\}

Откройте меню действий строки и нажмите **Delete**. Диалога подтверждения нет — строка удаляется сразу.

- **Сегменты, привязанные к кампании**: можно удалить в любой момент.
- **Сегменты, привязанные к активному A/B-тесту**: удалить нельзя. Сначала завершите тест с помощью **Finish A/B test**.

:::note
Удаление сегмента останавливает попадание новых пользователей в последовательность. Пользователи, уже находящиеся в середине последовательности, могут продолжать получать запланированные письма — автоматической отмены не происходит.
:::
