Этот гайд поможет вам устранить распространённые проблемы при использовании пейволов, созданных в Adapty Paywall Builder, в iOS SDK. По вопросам, связанным с флоу, смотрите раздел [Типичные проблемы](flow-common-issues).

## Ошибка при получении конфигурации пейвола \{#getting-a-paywall-configuration-fails\}

**Проблема**: Метод `getPaywallConfiguration` не может получить конфигурацию пейвола.

**Причина**: Пейвол не включён для отображения на устройстве в Paywall Builder.

**Решение**: Включите переключатель **Show on device** в Paywall Builder.

## Число просмотров пейвола слишком большое \{#the-paywall-view-number-is-too-big\}

**Проблема**: Счётчик просмотров пейвола показывает значение в два раза больше ожидаемого.

**Причина**: Возможно, вы вызываете `logShowFlow` (iOS SDK v4+) / `logShowPaywall` в коде, что дублирует количество просмотров пейвола, созданного в старом Paywall Builder. Adapty отслеживает эти просмотры автоматически, поэтому вызывать этот метод не нужно.

**Решение**: Убедитесь, что вы не вызываете `logShowFlow` (iOS SDK v4+) / `logShowPaywall` в коде для пейвола, созданного в старом Paywall Builder.

## Другие проблемы \{#other-issues\}

**Проблема**: Вы столкнулись с другими проблемами, связанными с Paywall Builder, которые не описаны выше.

**Решение**: При необходимости обновите SDK до последней версии, воспользовавшись [гайдами по миграции](ios-sdk-migration-guides). Многие проблемы уже исправлены в новых версиях SDK.
