Это единственный шаг интеграции с Google Play, который выполняется в Adapty, а не в консоли Google. Вы предоставляете Adapty название пакета и файл ключа сервисного аккаунта, после чего Adapty использует их для валидации покупок и чтения ваших продуктов.

:::danger
Не меняйте имя пакета или файл ключа после того, как ваше приложение вышло в продакшн с Adapty SDK. Это сломает валидацию покупок для всех, кто уже использует ваше приложение. Ключ из другого Cloud-проекта также изменит имя топика, что остановит получение уведомлений в реальном времени.

Противоположный случай — ключ, который уже перестал работать. Если ключ сервисного аккаунта удалён или ротирован в Google Cloud, загрузите замену как можно скорее: чтение продуктов и валидация покупок будут нарушены до тех пор, пока вы этого не сделаете. См. [Если обновления перестали поступать](store-sync#if-updates-stop-arriving).
:::

## Прежде чем начать \{#before-you-start\}

[Создайте файл ключа сервисного аккаунта](create-service-account-key-file). Именно его вы загрузите здесь.

## Подключите приложение \{#connect-the-app\}

1. Откройте [Google Play Console](https://play.google.com/console/), выберите приложение и скопируйте его package name. На странице **Dashboard** он отображается под названием приложения.

2. Откройте [**App settings** > **Android SDK**](https://app.adapty.io/settings/android-sdk) в дашборде Adapty.

3. Вставьте package name в поле **Package name**.

4. Загрузите JSON-файл ключа в поле **Service account key file**.

   <ZoomImage id="gp-adapty-android-sdk.webp" width="700px" alt="Android SDK tab of App settings in Adapty, showing the Package name field and the Service account key file upload area" />

5. Нажмите **Save**.

Сохранение файла ключа также создаёт тему Pub/Sub в вашем Cloud-проекте — она понадобится на следующем шаге.
