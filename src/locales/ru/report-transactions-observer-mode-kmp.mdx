В режиме Observer Adapty SDK не может самостоятельно отслеживать покупки, совершённые через вашу существующую систему покупок. Вам нужно передавать транзакции из стора вручную. Важно настроить это **до** публикации приложения, чтобы избежать ошибок в аналитике.

Используйте `reportTransaction`, чтобы явно сообщить Adapty о каждой транзакции.

:::warning
**Не пропускайте передачу транзакций!**
Если вы не вызовете `reportTransaction`, Adapty не распознает транзакцию, она не появится в аналитике и не будет отправлена в интеграции.
:::

Если вы используете пейволы Adapty, передавайте `variationId` при регистрации транзакции. Это свяжет покупку с пейволом, который её инициировал, и обеспечит точную аналитику пейволов.

```kotlin showLineNumbers

Adapty.reportTransaction(
    transactionId = "your_transaction_id",
    variationId = paywall.variationId
).onSuccess {
    // Transaction reported successfully
}.onError { error ->
    // handle the error
}
```

Параметры:

| Параметр        | Наличие  | Описание                                                                                                                                                                                                     |
| --------------- | -------- |--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| transactionId   | обязательный | Идентификатор транзакции из стора. Как правило, это токен покупки или идентификатор транзакции, который возвращает стор.                                                                                     |
| variationId     | необязательный | Строковый идентификатор варианта. Его можно получить через свойство `variationId` объекта [AdaptyPaywall](https://kmp.adapty.io//////adapty/com.adapty.kmp.models/-adapty-paywall/). |
