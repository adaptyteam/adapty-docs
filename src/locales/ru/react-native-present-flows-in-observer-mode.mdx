Если вы используете [режим Observer](observer-vs-full-mode), вы самостоятельно отвечаете за логику покупок. Однако UI пейвола можно делегировать [Flow & Paywall Builder](adapty-flow-builder).

Разработайте экран в конструкторе — Adapty SDK отрендерит его нативно. Обновляйте текст, макет и цены когда угодно, без выпуска новой версии приложения.

В этом гайде показано, как отобразить флоу и обработать коллбэки покупок. Если Adapty управляет покупками за вас, см. [Отображение флоу и пейволов](react-native-present-paywalls).

## Прежде чем начать \{#before-you-start\}

Вам понадобится:

- **Adapty React Native SDK 4.0 или выше**: Более ранние версии не могут рендерить флоу. На Android используйте версию 4.4.0 или выше: более ранние версии могут не связывать зафиксированные покупки с флоу. Чтобы перейти с существующего приложения, см. [гайд по миграции](migration-to-react-native-sdk-v4).
- **`observerMode` установлен в `true`**: См. [гайд по установке React Native SDK](sdk-installation-reactnative).
- **Начальная интеграция со стором**: Настройте Adapty [с App Store](initial_ios) и [с Google Play](initial-android).
- **Опубликованный флоу с продуктами**: Создайте его в [Flow & Paywall Builder](adapty-flow-builder) и назначьте ему [продукты](create-product).
- **Плейсмент для флоу**: [Создайте плейсмент](create-placement) и назначьте ему ваш флоу.
- **Флоу, загруженный в приложение**: [Получите флоу и его конфигурацию](react-native-get-pb-paywalls) перед отображением.

В режиме Observer SDK не выполняет покупки самостоятельно. Когда пользователь нажимает кнопку покупки или восстановления во флоу, отображаемом Adapty, SDK вызывает ваш обработчик событий `onObserverPurchaseInitiated` или `onObserverRestoreInitiated` — выполните покупку или восстановление с помощью собственного кода в этом обработчике.

## Установите обработчики событий в режиме наблюдателя \{#set-the-observer-mode-event-handlers\}

В отличие от других платформ, здесь нет отдельного объекта-резолвера — обработчики являются частью обычных [обработчиков событий](react-native-handling-events-1), поэтому устанавливайте их для каждого флоу, который вы показываете.

<TabItem value="platform" label="React component" default>

Для React-компонента передайте обработчики как пропсы в `AdaptyFlowView`:

```typescript showLineNumbers title="React Native (TSX)"

function MyFlow({ flow }) {
  const onObserverPurchaseInitiated = useCallback<
    FlowEventHandlers['onObserverPurchaseInitiated']
  >((product, onStartPurchase, onFinishPurchase) => {
    onStartPurchase(); // the flow shows its loading indicator
    myPurchaseApi(product.vendorProductId)
      .then((transactionId) => adapty.reportTransaction(transactionId, product.variationId))
      .finally(() => onFinishPurchase()); // the flow hides the loading indicator
  }, []);

  const onObserverRestoreInitiated = useCallback<
    FlowEventHandlers['onObserverRestoreInitiated']
  >((onStartRestore, onFinishRestore) => {
    onStartRestore();
    myRestoreApi().finally(() => onFinishRestore());
  }, []);

  return (
    <AdaptyFlowView
      flow={flow}
      onObserverPurchaseInitiated={onObserverPurchaseInitiated}
      onObserverRestoreInitiated={onObserverRestoreInitiated}
      // ... your other event handlers
    />
  );
}
```

:::note
Во встроенном компоненте значение, которое возвращает обработчик, не закрывает флоу. Размонтируйте компонент самостоятельно после успешной покупки или восстановления покупок.
:::

Для модального представления задайте обработчики на созданном вами представлении:

```typescript showLineNumbers title="React Native (TSX)"

const view = await createFlowView(flow);

const unsubscribe = view.setEventHandlers({
  onObserverPurchaseInitiated(product, onStartPurchase, onFinishPurchase) {
    onStartPurchase(); // the flow shows its loading indicator
    myPurchaseApi(product.vendorProductId)
      .then((transactionId) => adapty.reportTransaction(transactionId, product.variationId))
      .finally(() => onFinishPurchase()); // the flow hides the loading indicator
    return false; // keep the flow open; dismiss it yourself after success, or let the flow continue
  },
  onObserverRestoreInitiated(onStartRestore, onFinishRestore) {
    onStartRestore();
    myRestoreApi().finally(() => onFinishRestore());
    return false;
  },
});
```

Обработчик `onObserverPurchaseInitiated` уведомляет вас о том, что пользователь инициировал покупку, а `onObserverRestoreInitiated` — что пользователь инициировал восстановление покупок. В ответ запустите свой кастомный флоу покупки или восстановления.

Также не забудьте вызвать следующие колбэки, чтобы уведомить AdaptyUI о ходе покупки или восстановления. Это необходимо для корректного поведения флоу — например, для отображения загрузчика:

| Callback           | Description                                                                                         |
| :----------------- | :-------------------------------------------------------------------------------------------------- |
| onStartPurchase()  | Коллбэк следует вызывать, чтобы уведомить AdaptyUI о начале покупки.    |
| onFinishPurchase() | Коллбэк следует вызывать, чтобы уведомить AdaptyUI о завершении покупки. |
| onStartRestore()   | Коллбэк следует вызывать, чтобы уведомить AdaptyUI о начале восстановления покупок.   |
| onFinishRestore()  | Коллбэк следует вызывать, чтобы уведомить AdaptyUI о завершении восстановления покупок.  |

После `onFinishPurchase()` флоу выполняет одни и те же [действия для результата](respond-to-purchase-outcomes#add-actions-for-a-result) независимо от того, что произошло, включая отменённую покупку: действия **When pending** на iOS и действия **When succeeded** на Android. Любой экран, зависящий от результата покупки (например, экран благодарности), показывайте из своего кода — только ваш код знает результат. После `onFinishRestore()` флоу выполняет действия **When restore completed** независимо от того, что произошло.

## Отображение флоу \{#present-the-flow\}

Отображайте флоу как обычно: [получите флоу и создайте его представление](react-native-get-pb-paywalls), затем [отобразите его](react-native-present-paywalls). Никаких дополнительных параметров не требуется — обработчики срабатывают только в том случае, если SDK был активирован с `observerMode: true`.

:::warning
Не забудьте [сообщить о транзакции и связать её с пейволом](report-transactions-observer-mode-react-native). В противном случае Adapty не распознает транзакцию и не определит исходный пейвол покупки. Передавайте `variationId` продукта `AdaptyPaywallProduct`, который купил пользователь, а не `AdaptyFlow.variationId`: собственный variation ID флоу не связывает покупку с флоу.
:::
