:::important
Эта статья описывает резервные пейволы для Adapty SDK v3 и более ранних версий. В SDK v4 один файл резервных данных содержит информацию о флоу и пейволах — см. [Резервные флоу](fallback-flows). Формат старого файла резервных данных несовместим с SDK v4, поэтому после обновления обязательно скачайте актуальную версию.
:::

Чтобы обеспечить бесперебойный пользовательский опыт, важно настроить **резервные версии** для ваших [пейволов](paywalls) и [онбордингов](onboardings).

Когда приложение загружает пейвол, SDK запрашивает данные его конфигурации с серверов Adapty. Но что делать, если устройство не может подключиться к Adapty из-за проблем с сетью или перебоев в работе серверов?

* Если пользователь уже открывал пейвол ранее и устройство кешировало его данные, приложение загружает данные пейвола **из кеша**.
* Если устройство не кешировало пейвол, приложение ищет локально сохранённый файл конфигурации. Это позволяет отобразить пейвол без ошибки.

Adapty автоматически генерирует резервные файлы конфигурации, которые вы можете скачать и использовать. Каждый файл содержит платформозависимые конфигурации для *всех* ваших плейсментов.

## С чего начать \{#get-started\}

1. [Скачайте резервный файл конфигурации](/local-fallback-paywalls) из Adapty.
2. Настройте резервные пейволы с помощью SDK Adapty:
    * [iOS](ios-use-fallback-paywalls)
    * [Android](android-use-fallback-paywalls)
    * [React Native](react-native-use-fallback-paywalls)
    * [Flutter](flutter-use-fallback-paywalls)
    * [Unity](unity-use-fallback-paywalls)
    * [Kotlin Multiplatform](kmp-use-fallback-paywalls)
    * [Capacitor](capacitor-use-fallback-paywalls)

## Ограничения \{#limitations\}

Резервные пейволы хранятся локально и имеют фиксированную конфигурацию, поэтому им недоступны динамические возможности обычных пейволов Adapty.

* Резервные пейволы не поддерживают [интернационализацию](paywall-localization). Файл всегда использует локаль `en`, поэтому офлайн-пользователи видят только английский язык. [Обновитесь до SDK v4](migrate-to-flows#update-the-sdk), чтобы снять это ограничение — его резервный файл содержит все локали.
* У каждого плейсмента может быть только один резервный пейвол. Если ваша конфигурация включает разные настройки пейвола для разных [аудиторий](audience), Adapty использует конфигурацию, предназначенную для «All users».
* Резервные пейволы не поддерживают [A/B-тесты](ab-tests). Если пейвол участвует в A/B-тесте, его резервный конфигурационный файл будет включать вариант с наибольшим весом.
* Резервными пейволами нельзя [управлять удалённо](customize-paywall-with-remote-config). Чтобы обновить конфигурационный файл, нужно выпустить новую версию приложения в App Store / Google Play.
