Apple требует раскрытия информации о конфиденциальности для всех новых приложений и обновлений — как в разделе **App Privacy** в App Store Connect, так и в виде файла манифеста приложения. Adapty является сторонней зависимостью вашего приложения, поэтому вам необходимо указать, как вы используете Adapty в отношении данных пользователей.

## Манифест конфиденциальности Apple \{#apple-app-privacy-manifest\}

[Файл манифеста конфиденциальности](https://developer.apple.com/documentation/bundleresources/describing-data-use-in-privacy-manifests), называемый `PrivacyInfo.xcprivacy`, описывает, какие персональные данные использует ваше приложение и с какой целью. Каждый владелец приложения обязан создать такой файл. Кроме того, если вы подключаете сторонние SDK, убедитесь, что файлы манифеста для тех из них, которые входят в список [SDK, требующих манифеста конфиденциальности и подписи](https://developer.apple.com/support/third-party-SDK-requirements/), включены в сборку. При компиляции Xcode объединит все эти файлы в один.

Несмотря на то что Adapty не входит в список [SDK, для которых требуются манифест конфиденциальности и подпись](https://developer.apple.com/support/third-party-SDK-requirements/), версии 2.10.2 и выше Adapty SDK включают его для вашего удобства. Обязательно обновите SDK, чтобы получить манифест.

Манифест используется только для формирования отчёта о конфиденциальности в Xcode. App Review проверяет ваши ответы в [App Store Connect](#apple-app-privacy-disclosure-in-app-store-connect), поэтому заполните этот раздел полностью.

Если вы идентифицируете пользователей с помощью `customerUserId` Adapty, укажите идентификатор пользователя в файле манифеста:

1. Добавьте словарь в массив `NSPrivacyCollectedDataTypes` в файле конфиденциальности.
2. Добавьте ключи `NSPrivacyCollectedDataType`, `NSPrivacyCollectedDataTypeLinked` и `NSPrivacyCollectedDataTypeTracking` в словарь.
3. Добавьте строку `NSPrivacyCollectedDataTypeUserID` (идентификатор типа данных `UserID` в [списке категорий и типов данных для указания в файле манифеста](https://developer.apple.com/documentation/bundleresources/describing-data-use-in-privacy-manifests#Describe-the-data-your-app-or-third-party-SDK-collects)) для ключа `NSPrivacyCollectedDataType` в вашем словаре `NSPrivacyCollectedDataTypes`.
4. Укажите `true` для ключа `NSPrivacyCollectedDataTypeLinked`. Укажите `false` для ключа `NSPrivacyCollectedDataTypeTracking`, если вы не используете идентификатор пользователя для [отслеживания в соответствии с определением Apple](https://developer.apple.com/app-store/user-privacy-and-data-use/).
5. Используйте строки `NSPrivacyCollectedDataTypePurposeAppFunctionality` и `NSPrivacyCollectedDataTypePurposeAnalytics` в качестве значений для ключа `NSPrivacyCollectedDataTypePurposes` в вашем словаре `NSPrivacyCollectedDataTypes`.

Если вы таргетируете пейволы на аудитории с пользовательскими атрибутами, тщательно проверьте, соответствуют ли используемые атрибуты [категориям и типам данных, подлежащим указанию в файле манифеста](https://developer.apple.com/documentation/bundleresources/describing-data-use-in-privacy-manifests). Если да — повторите шаги выше для каждого типа данных.

После того как вы укажете все собираемые типы и категории данных, создайте отчёт о конфиденциальности вашего приложения, как описано в [документации Apple](https://developer.apple.com/documentation/bundleresources/describing-data-use-in-privacy-manifests#Create-your-apps-privacy-report).

#### Идентификаторы \{#identifiers\}

При использовании Adapty необходимо раскрыть следующие идентификаторы:
- **Device ID** — Adapty генерирует идентификатор устройства для каждой установки и собирает IDFV. Также собирается IDFA, если только вы не [отключите сбор рекламных идентификаторов](analytics-integration#disable-collection-of-advertising-identifiers). Отключить идентификатор для каждой установки нельзя, поэтому **Device ID** нужно декларировать в любом случае.
- **User ID** — обязателен, если вы идентифицируете пользователей с помощью **`customerUserId`**.

#### Данные об использовании \{#usage-data\}

При использовании Adapty необходимо указать, что ваше приложение собирает данные **Product Interaction**. Adapty записывает открытия приложения, а также события пейвола и флоу в профиле пользователя.

    - **Product Personalization** — Adapty использует данные о покупках для сегментации аудитории и таргетинга пейволов. Это актуально только если вы таргетируете плейсменты по аудитории, но выбрать этот пункт — безопасный выбор по умолчанию.

### Привязка и отслеживание \{#linking-and-tracking\}

Для каждого типа данных Apple также спрашивает, привязаны ли данные к личности пользователя и используются ли они для отслеживания. Для Adapty ответьте следующим образом:

- **Связано с пользователем**: **Нет**, если вы не задаёте `customerUserId`. Идентификатор устройства — это случайный идентификатор, генерируемый при каждой установке, и он никак не идентифицирует человека. Если вы задаёте `customerUserId`, укажите **Да** для каждого типа данных Adapty, поскольку пользовательский ID связывает их все с пользователем.
- **Используется для отслеживания**: **Нет**. Adapty не использует эти данные для [отслеживания в том смысле, который определяет Apple](https://developer.apple.com/app-store/user-privacy-and-data-use/). Укажите **Да** только в том случае, если ваше приложение использует эти данные для отслеживания.
