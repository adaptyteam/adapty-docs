Используйте этот гайд для следующей настройки Google Ads:

- **Что вы рекламируете**: Android-приложение в Google Play.
- **Тип кампании**: App campaigns for installs (UAC). Они показывают ваши объявления в Google Search, Google Play, YouTube и других приложениях и на сайтах. Каждое объявление ведёт на страницу вашего приложения в Google Play.

В Adapty Attribution кампании App campaigns for installs (UAC) работают только для Android-приложений. Чтобы рекламировать iOS-приложение или веб-воронку, используйте [Search и Performance Max кампании](google-ads-search-pmax-campaigns).

## Как это работает \{#how-it-works\}

Когда вы подключаете кампании App к Adapty Attribution:

- Google получает события о пробных периодах и покупках от Adapty.
- На основе этих данных Google делает ставки на пользователей, которые склонны начать пробный период или оформить подписку, а не просто установить приложение.
- Adapty Attribution показывает доход и ROAS по каждой кампании, группе объявлений и объявлению, используя расходы, которые Adapty получает из Google Ads.

В этом гайде вы создадите App Link ID в Google Ads и добавите его в Adapty Attribution. Через эту ссылку Adapty отправляет данные о каждой новой установке в Google. Если пользователь пришёл из рекламы App campaign, Google возвращает [кампанию, группу объявлений и объявление](ua-google-ads#app-campaigns-android) в Adapty.

## Прежде чем начать \{#before-you-begin\}

Убедитесь, что:

- Ваше приложение опубликовано в Google Play в рабочей среде или в открытом тесте без ограничения по количеству тестировщиков.
- В SDK вашего приложения включена [атрибуция Adapty](user-acquisition#step-1-enable-adapty-attribution-in-the-sdk).
- У вас есть аккаунт Google Ads в [Expert Mode](ua-google-ads#before-you-begin), чтобы вы могли создавать App-кампании.
- В аккаунте Google Ads настроен способ оплаты.
- Ваш аккаунт Google, например you@appname.com, имеет [уровень доступа **Admin**](ua-google-ads-settings#set-account-permissions) в аккаунте Google Ads. Этот уровень доступа необходим для создания App Link ID.
- Ваш аккаунт Google [подключён к атрибуции Adapty](ua-google-ads-settings#connect-your-google-account).

## Настройте App Link ID и кампанию \{#set-up-the-app-link-id-and-the-campaign\}

Через подключённый аккаунт Google Adapty обновляет расходы по кампаниям каждые 4 часа. Для App-кампаний также нужна ссылка на само приложение — App Link ID. Через неё Adapty передаёт в Google данные об установках, пробных периодах и покупках. Новая ссылка для каждой кампании не нужна.

Если вы уже запускаете App-кампании для своего приложения, выберите, какую из них использовать с Adapty Attribution. В противном случае создайте новую кампанию — иначе вы не сможете в полной мере воспользоваться возможностями Adapty Attribution.

| Кампания | Установки и выручка в Adapty Attribution | Google оптимизирует по пробным периодам или покупкам | Шаги |
|---|---|---|---|
| Существующая кампания | ✅ без исторических установок | ❌ | [Шаги 1–3](#create-the-configuration-in-adapty-attribution) |
| Новая кампания (рекомендуется) | ✅ | ✅ | Все шаги этого гайда |

### 1. Создайте конфигурацию в Adapty Attribution \{#create-the-configuration-in-adapty-attribution\}

1. Переключитесь на приложение, которое хотите рекламировать.
2. Перейдите в **Integrations** > **Google Ads**. На вкладке **App Campaigns** нажмите **Create configuration**.

    <ZoomImage id="google-ads-create-ad-campaign.webp" width="700px" alt="App Campaigns tab of the Google Ads integration in Adapty Attribution with the Create configuration button" />

3. Скопируйте значение **Provider ID** — оно понадобится для создания App Link ID в Google Ads.

### 2. Создайте ID ссылки приложения в Google Ads \{#create-the-app-link-id-in-google-ads\}

1. Нажмите иконку **Tools** и выберите **Data manager**.
2. Нажмите **+ Connect Product**, выберите **Third-party app analytics** и нажмите **Continue**.
3. Нажмите **Create link ID**.
4. В списке провайдеров выберите **Other provider** и вставьте **Provider ID**, скопированный из Adapty Attribution.
5. Выберите **Android** в качестве платформы и найдите своё приложение в поле **Look up your app**.
6. Нажмите **Create link ID** и скопируйте сгенерированный ID ссылки.

:::note
Google Ads отображает идентификатор ссылки как **Unverified** до тех пор, пока не получит первое событие от Adapty.
:::

### 3. Добавьте ID ссылки в Adapty Attribution \{#add-the-link-id-to-adapty-attribution\}

1. Вернитесь к конфигурации, созданной на [шаге 1](#create-the-configuration-in-adapty-attribution). Вставьте ID ссылки в поле **Android App Link ID**. Каждый ID ссылки можно использовать только в одной конфигурации.

    <ZoomImage id="app-link-id.webp" width="700px" alt="Android App Link ID field in an App campaigns configuration, with the Provider ID above it" />

2. [Выберите, какие события Adapty отправляет в Google](ua-google-ads-settings#map-events). Чтобы передавать в Google доход по начатым триалам, настройте [переопределение дохода](ua-google-ads-settings#revenue-override). Чтобы отправлять в Google только те триалы, которые пользователи сохранили, настройте [Qualified trial](ua-google-ads-settings#qualified-trial).
3. Нажмите **Save**.

### 4. Отправьте тестовые события \{#send-test-events\}

Когда Google Ads получает событие впервые, Google создаёт действие-конверсию, которое его учитывает. Чтобы действия-конверсии были готовы до создания кампании, отправьте тестовое событие для каждого события, которое вы хотите оптимизировать:

1. В настройках нажмите **Send test event**.
2. В поле события для оптимизации выберите или введите название события Google, например `in_app_purchase`. Затем нажмите **Send**. Adapty отобразит результат в уведомлении.
3. Если конверсионное действие для события не появляется в Google Ads после успешной отправки тестового события, импортируйте это событие как конверсионное действие. Инструкция Google описана в статье [Measure app conversions with third-party app analytics](https://support.google.com/google-ads/answer/7382633).

<ZoomImage id="google-ads-test-event.webp" width="700px" alt="Диалог отправки тестового события в настройках App campaigns, с in_app_purchase в качестве имени события" />

Чтобы Google Ads принял первые установки из кампании, опубликуйте её после успешного тестового события. Новый идентификатор ссылки активируется в Google Ads примерно через 24 часа, поэтому до этого момента тестовые события могут завершаться с ошибкой. Если тестовое событие не прошло, следуйте инструкции [Тестовое событие не проходит для нового идентификатора ссылки](#test-event-fails-for-a-new-link-id).

### 5. Оптимизируйте кампанию по триалам или покупкам \{#optimize-your-campaign-for-trials-or-purchases\}

По умолчанию Google учитывает события из Adapty в отчётах, но не использует их для оптимизации ставок. Чтобы изменить это для нужного события, отредактируйте действие-конверсию:

1. В Google Ads перейдите в **Goals** > **Conversions** > **All conversions**.
2. Нажмите на действие-конверсию, по которому хотите оптимизироваться.
3. Выберите вкладку **Settings**.
4. Нажмите на параметр **Action optimization**. Выберите **Primary action used for bidding optimization** и нажмите **Save**.

### 6. Создайте и опубликуйте новую App-кампанию \{#create-the-app-campaign\}

Создайте новую App-кампанию, даже если уже запускаете App-кампании для своего приложения. Google не рекомендует менять целевое событие оптимизации в уже работающей App-кампании.

1. В Google Ads откройте меню **Campaigns** и выберите **Campaigns**. Нажмите кнопку со знаком плюс и выберите **New campaign**.
2. В качестве цели выберите **App promotion**, в качестве подтипа кампании — **App installs**.
3. Выберите платформу **Android**, затем найдите своё приложение по названию, имени пакета или издателю.
4. Введите название кампании и нажмите **Continue**. Затем выберите целевые местоположения.
5. Выберите языки объявлений. Google не переводит их автоматически.
6. На странице **Budget and bidding** в выпадающем списке **What do you want to focus on?** выберите **In-app actions**.
7. В разделе **Which actions are most important to you?** выберите конверсионное действие, которое вы изменили на [шаге 5](#optimize-your-campaign-for-trials-or-purchases). Google рекомендует использовать одно действие на кампанию.
8. Введите целевую стоимость за действие. Если у вас уже есть активные кампании, ориентируйтесь на показатели **Cost per trial** или **Cost per subscription** в [аналитике атрибуции Adapty](ua-analytics).
9. Установите дневной бюджет не менее чем в 10 раз больше целевой стоимости за действие — такова рекомендация Google.
10. Добавьте материалы для объявлений: несколько заголовков, описаний, изображений и видео. Google сам составит объявления из них.
11. Нажмите **Publish campaign**.

## После публикации \{#after-you-publish\}

- **Дождитесь проверки объявления**: Google проверяет каждое объявление перед запуском. Во время проверки статус объявления — **Under review**. Большинство проверок завершается в течение одного рабочего дня. После прохождения проверки статус меняется на **Eligible**, и объявление начинает показываться.
- **Не вносите крупных изменений, пока Google обучается**: Как правило, алгоритму Google требуется 1–2 недели, чтобы понять, какие клики приводят к конверсиям, которые Adapty передаёт в Google. Изменения в кампании в этот период могут нарушить процесс обучения. Не меняйте событие для оптимизации. Корректируйте бюджет или целевую стоимость действия не более чем на 20% за раз.
- **Смотрите установки, выручку и ROAS в Adapty Attribution**: Откройте [аналитику Adapty Attribution](ua-analytics). Adapty обновляет данные о расходах, показах и кликах из Google Ads каждые 4 часа.

## Устранение неполадок \{#troubleshooting\}

### Тест события завершается ошибкой для нового link ID \{#test-event-fails-for-a-new-link-id\}

Новый link ID активируется в Google Ads примерно в течение 24 часов. До этого Google Ads отклоняет события от Adapty, поэтому тест события завершается ошибкой, даже если настройка выполнена правильно.

Подождите 24 часа и отправьте тестовое событие снова. Не заменяйте link ID в это время: новый link ID потребует ещё 24 часов для активации.

Если тест события всё равно завершается ошибкой после 24 часов, проверьте поле **Android App Link ID** в настройках. Оно должно содержать link ID из **Data manager**, а не другой идентификатор Google Ads.

Как только тестовое событие успешно сработает для каждого события оптимизации, перейдите к разделу [Оптимизируйте кампанию по пробным периодам или покупкам](#optimize-your-campaign-for-trials-or-purchases).

### Google Ads не показывает конверсии от Adapty \{#google-ads-shows-no-conversions-from-adapty\}

Чтобы увидеть конверсии, которые Adapty отправляет в Google, в Google Ads перейдите в **Goals** > **Conversions** > **All conversions**. Если для нужного события конверсии не отображаются, проверьте следующее:

- [Тестовое событие прошло успешно](#send-test-events) для данного события.
- Google [оптимизирует ставки для этого события](#optimize-your-campaign-for-trials-or-purchases).
- Вы выбрали действие-конверсию в своей App-кампании в разделе **Which actions are most important to you?**.

### Кампании приложений показывают меньше установок из ЕЭЗ и Великобритании \{#app-campaigns-show-fewer-installs-from-the-eea-and-the-uk\}

Для защиты конфиденциальности пользователей из Европейской экономической зоны и Великобритании Adapty помечает события, отправляемые в Google, как не согласованные для рекламы. В результате Google может засчитывать меньше установок из этих регионов в ваших кампаниях приложений. Это ожидаемое поведение — ваша настройка работает корректно.
