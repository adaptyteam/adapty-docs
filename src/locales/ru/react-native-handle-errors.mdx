Каждая ошибка, возвращаемая SDK, имеет тип `AdaptyErrorCode`. Пример:
:::tip
**Включите подробные логи перед отладкой.** Большинство `AdaptyError` оборачивают ошибку StoreKit, Play Billing, сети или бэкенда. При включённых verbose-логах (`adapty.setLogLevel('verbose')` — см. Логирование для [pure RN](sdk-installation-react-native-pure#logging) или [Expo](sdk-installation-react-native-expo#logging)) эта ошибка выводится в консоль, что обычно сразу указывает на причину.
:::

:::important
Если эти решения не помогли, перейдите к разделу [Другие проблемы](#other-issues) — там описаны шаги, которые нужно предпринять перед обращением в поддержку, чтобы мы могли помочь вам эффективнее.
:::
```typescript showLineNumbers
try {
  const params: MakePurchaseParamsInput = {};
  await adapty.makePurchase(product, params);
} catch (error) {
  if (
    error instanceof AdaptyError &&
    error.adaptyCode === getErrorCode('cantMakePayments')
  ) {
    // Встроенные покупки не разрешены на этом устройстве
  }
}
```

`error.adaptyCode` — это число, поэтому сравнивайте его с числом: либо с литералом (`1003`), либо с результатом `getErrorCode('<name>')`. `ErrorCode` работает в обратную сторону — преобразует число в имя — поэтому используйте его для логирования, а не для сравнения.

:::note
Отмена покупки пользователем — **не** ошибка. `makePurchase` возвращает [`AdaptyPurchaseResult`](react-native-sdk-models) с `type` равным `'user_cancelled'` — см. [Совершение покупок](react-native-making-purchases).
:::

## Другие проблемы \{#other-issues\}

Если вы ещё не нашли решение, попробуйте следующее:
- **Обновите SDK до последней версии**: мы всегда рекомендуем обновляться до последних версий SDK, так как они более стабильны и содержат исправления известных проблем.
- **Обратитесь в поддержку или получите помощь от других разработчиков** на [форуме поддержки](https://adapty.featurebase.app/).
- **Напишите в поддержку на [support@adapty.io](mailto:support@adapty.io) или в чат**: если вы не готовы обновить SDK или обновление не помогло, обратитесь в нашу службу поддержки. Обратите внимание: проблема решится быстрее, если вы [включите подробное логирование](sdk-installation-reactnative) и поделитесь логами с командой. Также можно приложить соответствующие фрагменты кода.
