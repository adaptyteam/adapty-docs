## Зачем использовать примеры приложений? \{#why-use-sample-apps\}

- **Быстрая интеграция:** посмотрите, как Adapty SDK работает в реальном приложении.
- **Лучшие практики:** следуйте рекомендованным паттернам реализации.
- **Отладка и тестирование:** используйте примеры приложений для устранения проблем и экспериментов перед интеграцией Adapty в собственный проект.

## Доступные примеры приложений \{#available-sample-apps\}

- [iOS (Swift)](https://github.com/adaptyteam/AdaptySDK-iOS/tree/master/Examples)
- [Android (Kotlin)](https://github.com/adaptyteam/AdaptySDK-Android/tree/master/app)
- [React Native (базовый пример)](https://github.com/adaptyteam/AdaptySDK-React-Native/tree/master/examples/BasicExample) — минимальная настройка, демонстрирующая основные возможности SDK.
- [React Native (Expo Go и Expo Web)](https://github.com/adaptyteam/AdaptySDK-React-Native/tree/master/examples/ExpoGoWebMock) — самый быстрый способ попробовать: работает в браузере на тестовых данных, без API-ключа Adapty. Включает как кастомный пейвол, так и Flow & Paywall Builder.
- [React Native (Focus Journal, приложение на Expo)](https://github.com/adaptyteam/AdaptySDK-React-Native/tree/master/examples/FocusJournalExpo) — приложение с платными функциями за пейволом, построенным через Flow & Paywall Builder. Есть [видеогайд](https://www.youtube.com/watch?v=TtCJswpt2ms).
- [React Native (Adapty DevTools)](https://github.com/adaptyteam/AdaptySDK-React-Native/tree/master/examples/AdaptyDevtools) — инструмент разработки и отладки для сложных случаев. То же приложение доступно [с Swift Package Manager вместо CocoaPods](https://github.com/adaptyteam/AdaptySDK-React-Native/tree/master/examples/AdaptyDevtoolsSpm).
- [Flutter (Dart)](https://github.com/adaptyteam/AdaptySDK-Flutter/tree/master/example)
- [Unity (C#)](https://github.com/adaptyteam/AdaptySDK-Unity/tree/main/Assets)
- [Kotlin Multiplatform](https://github.com/adaptyteam/AdaptySDK-KMP/tree/main/example)
- [Capacitor (React)](https://github.com/adaptyteam/AdaptySDK-Capacitor/tree/master/examples/basic-react-example)
- [Capacitor (Vue.js)](https://github.com/adaptyteam/AdaptySDK-Capacitor/tree/master/examples/basic-vue-example)
- [Capacitor (Angular)](https://github.com/adaptyteam/AdaptySDK-Capacitor/tree/master/examples/basic-angular-example)
- [Capacitor (расширенные инструменты разработки)](https://github.com/adaptyteam/AdaptySDK-Capacitor/tree/master/examples/adapty-devtools)
