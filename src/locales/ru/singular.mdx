[Singular](https://www.singular.net/) — это платформа Mobile Measurement Partner (MMP), которая собирает и отображает данные маркетинговых кампаний.

Adapty отправляет в Singular [события подписок](events), которые вы выбираете. В дашборде Singular вы можете видеть, какую выручку приносит каждая кампания, и оценивать эффективность рекламы.

## Настройка интеграции \{#set-up-integration\}

### Подключение Adapty к Singular

Чтобы настроить интеграцию с Singular, перейдите в раздел [Integrations > Singular](https://app.adapty.io/integrations/singular) дашборда Adapty, включите переключатель и заполните поля.

<ZoomImage id="singular-creds.webp" />

Доступны следующие учётные данные:

- **Singular SDK Key**: Обязательное поле. Продакшн SDK-ключ вашего приложения в Singular.
- **Singular SDK Key (Sandbox)**: Необязательное поле. SDK-ключ для песочницы вашего приложения в Singular. Если не указан, события из песочницы не будут отправляться в Singular.

Оба ключа можно найти в дашборде Singular в разделе **Developer tools -> SDK Keys -> SDK Key (**не** SDK Secret)**:

Adapty отправляет события подписок на сервер Singular по схеме server-to-server, поэтому вы можете просматривать все события подписок в дашборде Singular и связывать их с вашими рекламными кампаниями.

### Подключите приложение к Singular

По умолчанию Singular включает Singular Device ID (SDID) для аккаунтов, созданных 15 июля 2026 года или позже. Такие аккаунты принимают события только через Event API v2, а Adapty отправляет событие в v2 только при наличии SDID в профиле пользователя. Чтобы события доставлялись в подобный аккаунт, передавайте SDID в Adapty из своего приложения.

Если ваш аккаунт Singular создан до 15 июля 2026 года и SDID на нём не включён, пропустите этот шаг. Adapty отправляет события через Event API v1, и изменения в коде приложения не требуются.

1. Активируйте Adapty, затем запустите Singular SDK с SDID-коллбэком: `sdidReceivedHandler` на iOS, `SDIDAccessorHandler` на Android, `sdidReceivedCallback` на React Native и Flutter, и `SingularSdidAccessorHandler` на Unity.
2. Дождитесь, пока Singular вызовет коллбэк. SDID приходит в ваше приложение асинхронно, после запуска Singular SDK. Singular вызывает коллбэк при каждом запуске, в том числе когда SDID уже сохранён на устройстве.
3. Внутри коллбэка передайте SDID в Adapty через `setIntegrationIdentifier()` с ключом `singular_sdid`. Ни один SDK Adapty не имеет предопределённой константы для этого ключа, поэтому используйте строковый литерал.
4. Вызывайте `Adapty.identify()` только после завершения `setIntegrationIdentifier()`. При активации Adapty создаёт анонимный профиль, а затем переключается на идентифицированный после того, как `identify()` завершится. SDID, установленный в момент этого переключения, может быть потерян.

## Структура события \{#event-structure\}

Adapty выбирает версию Singular Event API для каждого события в зависимости от того, есть ли в профиле пользователя SDID:

- **С SDID**: Adapty отправляет `POST`-запрос на `https://s2s.singular.net/api/v2/evt` с телом в формате form-urlencoded. Параметр `sdid` заменяет идентификаторы устройства `idfa`, `idfv`, `aifa`, `andi` и `asid`. Булевы значения передаются как `true` или `false`.
- **Без SDID**: Adapty отправляет `GET`-запрос на `https://s2s.singular.net/api/v1/evt` с параметрами запроса.

В остальном оба варианта содержат одинаковые параметры. Событие v1 имеет следующую структуру:

```json
{
  "n": "subscription_renewed",
  "a": "singular_sdk_key_123",
  "p": "iOS",
  "i": "com.example.app",
  "ip": "192.168.100.1",
  "idfa": "00000000-0000-0000-0000-000000000000",
  "idfv": "00000000-0000-0000-0000-000000000000",
  "ve": "17.0.1",
  "att_authorization_status": 3,
  "custom_user_id": "user_12345",
  "utime": 1709294400,
  "partner": "adapty",
  "use_ip": false,
  "is_revenue_event": true,
  "amt": 9.99,
  "cur": "USD",
  "purchase_product_id": "yearly.premium.6999",
  "purchase_transaction_id": "GPA.3383...",
  "e": "{\"is_revenue_event\":true,\"amt\":9.99,\"cur\":\"USD\",\"purchase_product_id\":\"yearly.premium.6999\",\"purchase_transaction_id\":\"GPA.3383...\"}"
}
```

Где:

| Параметр                   | Тип     | Описание                                                                      |
|:---------------------------|:--------|:------------------------------------------------------------------------------|
| `n`                        | String  | Название события (маппится из события Adapty).                                |
| `a`                        | String  | Ваш Singular SDK Key.                                                         |
| `p`                        | String  | Платформа ("iOS" или "Android").                                              |
| `i`                        | String  | Store App ID (Bundle ID).                                                     |
| `ip`                       | String  | IP-адрес пользователя.                                                        |
| `sdid`                     | String  | **Только v2**. Singular Device ID, из идентификатора интеграции `singular_sdid`. |
| `idfa`                     | String  | **iOS, только v1**. ID for Advertisers (в верхнем регистре).                 |
| `idfv`                     | String  | **iOS, только v1**. ID for Vendors (в верхнем регистре).                     |
| `aifa`                     | String  | **Android, только v1**. Google Advertising ID (в нижнем регистре).           |
| `andi`                     | String  | **Android, только v1**. Android ID (в нижнем регистре).                      |
| `asid`                     | String  | **Android, только v1**. App Set ID (в нижнем регистре).                      |
| `ve`                       | String  | Версия ОС.                                                                    |
| `att_authorization_status` | Integer | **Только iOS**. Статус ATT (например, `3` — авторизован).                    |
| `custom_user_id`           | String  | Customer User ID пользователя.                                                |
| `utime`                    | Long    | UNIX-временная метка события в секундах.                                      |
| `partner`                  | String  | Всегда `adapty`. Указывает, что событие отправлено Adapty.                    |
| `use_ip`                   | Boolean | `true`, если у Adapty нет IP-адреса пользователя.                            |
| `is_revenue_event`         | Boolean | `true`, если событие содержит доход. Отправляется только с событиями дохода. |
| `amt`                      | Float   | Сумма дохода.                                                                 |
| `cur`                      | String  | Код валюты (например, "USD").                                                 |
| `purchase_product_id`      | String  | ID продукта из стора.                                                         |
| `purchase_transaction_id`  | String  | Оригинальный ID транзакции.                                                   |
| `e`                        | String  | JSON-строка с деталями события (см. ниже).                                    |

Параметр `e` (данные пользовательского события) — это JSON-строка, содержащая:

| Параметр                  | Тип     | Описание                                      |
|:--------------------------|:--------|:----------------------------------------------|
| `is_revenue_event`        | Boolean | `true`, если событие содержит выручку.        |
| `amt`                     | Float   | Сумма выручки.                                |
| `cur`                     | String  | Код валюты.                                   |
| `purchase_product_id`     | String  | ID продукта в сторе.                          |
| `purchase_transaction_id` | String  | Оригинальный ID транзакции.                   |

## Устранение неполадок \{#troubleshooting\}

### События не проходят с ошибкой `invalid api version: v1` \{#events-fail-with-invalid-api-version-v1\}

Ваш аккаунт Singular был создан 15 июля 2026 года или позднее и принимает события только через Event API v2. Adapty отправил событие на v1, потому что в профиле пользователя нет SDID. Чтобы исправить это, передайте SDID в Adapty из своего приложения, как описано в разделе [Подключите приложение к Singular](#connect-your-app-to-singular). События от пользователей, использующих версию приложения без вызова `setIntegrationIdentifier()`, будут продолжать завершаться с ошибкой, пока те не обновят приложение.
