Adapty CLI группирует команды по темам, например `products` или `placements`. Каждой теме посвящена отдельная страница с описанием команд, аргументов, флагов и допустимых значений. На этой странице перечислены темы, флаги, которые принимает каждая команда, и команда для установки скиллов Adapty.

| Тема | Команды | Что они делают |
|---|---|---|
| [Приложения и уровни доступа](developer-cli-apps) | `apps`, `access-levels` | Создание и настройка приложений и уровней подписки, которые проверяет ваше приложение |
| [Продукты и офферы](developer-cli-products) | `products`, `product-offers` | Настройка продуктов, их сопоставление с идентификаторами продуктов App Store и Google Play, а также привязка офферов стора |
| [Пейволы](developer-cli-paywalls) | `paywalls` | Создание пейволов и назначение продуктов на них |
| [Флоу](developer-cli-flows) | `flows` | Создание флоу, написание и валидация их конфигураций в билдере, публикация |
| [Плейсменты и сегменты](developer-cli-placements) | `placements`, `segments` | Настройка плейсментов, их аудиторий и сегментов, на которые эти аудитории нацелены |
| [Аналитика](developer-cli-analytics) | `analytics` | Чтение графиков, конверсий, воронки, удержания, LTV и когорт |
| [Атрибуция](developer-cli-attribution) | `attribution` | Чтение расходов, установок, выручки и ROAS по каналам и кампаниям |
| [Ads Manager](developer-cli-ads-manager-reference) | `asa` | Управление кампаниями Apple Ads, ключевыми словами и правилами автоматизации |
| [Миграции](developer-cli-migrations) | `migrations` | Перенос проекта RevenueCat в Adapty |
| [Аутентификация](developer-cli-authentication) | `auth` | Вход, проверка и отзыв сессии CLI |

## Глобальные флаги \{#global-flags\}

Эти флаги доступны для всех команд.

| Флаг | Описание |
|---|---|
| `--json` | Вывод в формате JSON вместо форматированного текста |
| `--help` | Показать справку по команде |

Все команды `list`, кроме `adapty product-offers list`, также принимают флаги пагинации:

| Флаг | По умолчанию | Описание |
|---|---|---|
| `--page` | `1` | Номер страницы |
| `--page-size` | `20` | Элементов на странице (макс.: 100) |

## Скиллы \{#skills\}

### adapty skills install

Устанавливает скиллы Adapty в агенты кодирования на этом компьютере.

```bash
adapty skills install
```

| Флаг | Обязателен | Описание |
|---|---|---|
| `--agent` | Нет | Агент для установки: `claude-code`, `codex` или `gemini-cli`. Повторите флаг для нескольких агентов. |
| `-y`, `--yes` | Нет | Установить во все найденные агенты без подтверждения. Обязателен, если CLI находит несколько агентов и не может задать вопрос, например при использовании `--json`. |

CLI ищет Claude Code, Codex и Gemini CLI в `PATH`. Если ни один не найден, он спрашивает, запустить ли `npx skills@1.7.0 add adaptyteam/adapty-skills --all --global` — это покрывает другие агенты. Перезапустите агент, чтобы скиллы загрузились.

Claude Code не обновляет плагин самостоятельно. Чтобы получать новые скиллы по мере выхода, в Claude Code выполните `/plugin`, откройте **Marketplaces**, выберите `adapty` и нажмите **Enable auto-update**. Чтобы включить это без меню, добавьте `"autoUpdate": true` в запись `adapty` в файле `~/.claude/settings.json`:

```json title="~/.claude/settings.json"
{
  "extraKnownMarketplaces": {
    "adapty": {
      "source": { "source": "github", "repo": "adaptyteam/adapty-skills" },
      "autoUpdate": true
    }
  }
}
```

Скиллы, установленные через skills CLI, обновляются командой `npx skills update`. Для Codex смотрите [README плагина](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#codex).
