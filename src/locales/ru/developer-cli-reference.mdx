Adapty CLI группирует команды по темам, например `products` или `placements`. Для каждой темы есть отдельная страница с командами, аргументами, флагами и допустимыми значениями. На этой странице перечислены темы, флаги, принимаемые каждой командой, команда для вывода версии CLI и команда для установки скиллов Adapty.

| Тема | Команды | Что делают |
|---|---|---|
| [Приложения и уровни доступа](developer-cli-apps) | `apps`, `access-levels` | Создание и настройка приложений и уровней подписки, которые проверяет ваше приложение |
| [Продукты и офферы](developer-cli-products) | `products`, `product-offers` | Настройка продуктов, привязка их к ID продуктов App Store и Google Play, и связывание офферов стора с ними |
| [Пейволы](developer-cli-paywalls) | `paywalls` | Создание пейволов, назначение продуктов и просмотр метрик |
| [Флоу](developer-cli-flows) | `flows` | Создание флоу, написание и валидация конфигов билдера, публикация, восстановление более ранних версий, дублирование, просмотр метрик и воронки экранов |
| [Плейсменты и сегменты](developer-cli-placements) | `placements`, `segments` | Настройка плейсментов, их аудиторий и сегментов, на которые нацелены аудитории. Просмотр метрик плейсментов флоу и пейволов |
| [Аналитика](developer-cli-analytics) | `analytics` | Просмотр графиков, конверсий, воронки, удержания, LTV и когорт |
| [A/B-тесты](developer-cli-ab-tests) | `ab-tests` | Создание, запуск, остановка, замена и архивирование A/B-тестов пейволов и флоу, просмотр их результатов |
| [Атрибуция](developer-cli-attribution) | `attribution` | Просмотр расходов, установок, дохода и ROAS по каналам и кампаниям |
| [Ads Manager](developer-cli-ads-manager-reference) | `asa` | Управление кампаниями Apple Ads, ключевыми словами и правилами автоматизации |
| [Retention Messaging](developer-cli-retention-messaging) | `retention-messaging` | Подключение Apple Retention Messaging, запуск теста производительности, создание, изменение, активация и деактивация retention-сообщений, просмотр их метрик |
| [Резервные пейволы](developer-cli-fallbacks) | `fallbacks` | Загрузка резервного файла, который приложение использует, когда не может подключиться к Adapty |
| [Миграции](developer-cli-migrations) | `migrations` | Перенос проекта RevenueCat в Adapty |
| [Аутентификация](developer-cli-authentication) | `auth` | Вход, проверка и отзыв сессии CLI |

## Глобальные флаги \{#global-flags\}

Эти флаги доступны для всех команд.

| Флаг | Описание |
|---|---|
| `--json` | Вывод в формате JSON вместо форматированного текста |
| `--help` | Показать справку по команде |

Все команды `list`, кроме `adapty product-offers list` и `adapty flows versions list`, также принимают флаги пагинации:

| Флаг | По умолчанию | Описание |
|---|---|---|
| `--page` | `1` | Номер страницы |
| `--page-size` | `20` | Элементов на странице (макс.: 100) |

## Версия CLI \{#cli-version\}

### adapty version

Выводит установленную версию CLI и проверяет, доступна ли более новая версия.

```bash
adapty version
```

Команда выводит ту же строку, что и `adapty --version`, затем обращается к публичному реестру npm за последней версией, ожидая не более 3 секунд. Если доступна более новая версия, команда выводит её вместе с командой обновления: `npm i -g adapty@latest`. Если реестр не отвечает в течение отведённого времени, команда выводит `Could not check for a newer version.` и завершается с кодом 0.

При использовании `--json` вывод содержит следующие поля:

| Поле | Описание |
|---|---|
| `installed` | Установленная версия CLI |
| `latest` | Последняя версия на npm, или `null` если реестр не отвечает вовремя |
| `update_available` | `true` если `latest` новее, чем `installed`, иначе `false` |

Для этой команды требуется CLI версии 0.26.1 или выше. Если у вас более ранняя версия, выполните `adapty --version`.

## Скиллы \{#skills\}

### adapty skills install

Устанавливает скиллы Adapty в агенты кодирования на этом компьютере.

```bash
adapty skills install
```

| Флаг | Обязателен | Описание |
|---|---|---|
| `--agent` | Нет | Агент для установки: `claude-code`, `codex` или `gemini-cli`. Повторите флаг для нескольких агентов. |
| `-y`, `--yes` | Нет | Установить во все найденные агенты без подтверждения. Обязателен, если CLI находит несколько агентов и не может задать вопрос, например при использовании `--json`. |

CLI ищет Claude Code, Codex и Gemini CLI в `PATH`. Если ни один не найден, он спрашивает, запустить ли `npx skills@1.7.0 add adaptyteam/adapty-skills --all --global` — это покрывает другие агенты. Перезапустите агент, чтобы скиллы загрузились.

Claude Code не обновляет плагин самостоятельно. Чтобы получать новые скиллы по мере выхода, в Claude Code выполните `/plugin`, откройте **Marketplaces**, выберите `adapty` и нажмите **Enable auto-update**. Чтобы включить это без меню, добавьте `"autoUpdate": true` в запись `adapty` в файле `~/.claude/settings.json`:

```json title="~/.claude/settings.json"
{
  "extraKnownMarketplaces": {
    "adapty": {
      "source": { "source": "github", "repo": "adaptyteam/adapty-skills" },
      "autoUpdate": true
    }
  }
}
```

Скиллы, установленные через skills CLI, обновляются командой `npx skills update`. Для Codex смотрите [README плагина](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#codex).
