Чтобы обновить приложение с Adapty Android SDK 4.1, 4.2 или 4.3 до 4.4, установите версию `adapty-bom` на `4.4.2` и замените резервный файл в той же сборке. SDK версий 4.1–4.3 не принимают новый файл. Приложение на версии 4.0 сначала требует [изменений для v4.1](migration-to-android-sdk-41).

:::warning
Формат резервного файла изменился в версии 4.4, и компилятор не может обнаружить устаревший файл. Без [нового резервного файла](#replace-the-fallback-file) каждый плейсмент лишится своего резерва.
:::

## Замените резервный файл \{#replace-the-fallback-file\}

Чтобы скачать [резервный файл](fallback-flows) повторно, в разделе **[Placements](https://app.adapty.io/placements)** нажмите **Fallbacks** > **Download Android Fallback**. В строке **Adapty SDK v4.4.0 and higher** нажмите **Download**. Добавьте файл в своё приложение.

Скачанный файл называется `android_4_4_0_fallback.json`. Переименуйте его в соответствии с именем файла, который загружает ваше приложение, или обновите имя в вызове, который его загружает:

- **`FileLocation.fromAsset`**: Имя файла, например `android_fallback.json`.
- **`FileLocation.fromResId`**: Имя ресурса, например `android_fallback` в `R.raw.android_fallback`.

Если файл устарел, `Adapty.setFallback` передаёт в коллбэк `AdaptyError` с сообщением «The fallback file version is not correct. Download a new one from the Adapty Dashboard.». Чтобы проверить новый файл, запустите приложение и убедитесь, что коллбэк не получает ошибку. Коллбэк необязателен. Если он не задан, установите [уровень логирования](sdk-installation-android#logging) `AdaptyLogLevel.ERROR` или более подробный, а затем проверьте, что Logcat не показывает эту ошибку.
