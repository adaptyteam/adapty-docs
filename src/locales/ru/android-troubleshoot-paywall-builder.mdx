Этот гайд поможет вам устранить распространённые проблемы при использовании пейволов, созданных в Adapty Paywall Builder в Android SDK. Если у вас возникли проблемы с флоу, смотрите [Распространённые проблемы](flow-common-issues).

## Получение конфигурации пейвола завершается ошибкой \{#getting-a-paywall-configuration-fails\}

**Проблема**: Метод `getViewConfiguration` не может получить конфигурацию пейвола.

**Причина**: Пейвол не включён для отображения на устройстве в Paywall Builder.

**Решение**: Включите переключатель **Show on device** в Paywall Builder.

## Число просмотров пейвола слишком велико \{#the-paywall-view-number-is-too-big\}

**Проблема**: Счётчик просмотров пейвола показывает значение, вдвое превышающее ожидаемое.

**Причина**: Возможно, вы вызываете `logShowFlow` (Android SDK v4+) / `logShowPaywall` в своём коде, что дублирует счётчик просмотров для пейвола, созданного в старом Paywall Builder. Adapty отслеживает такие просмотры автоматически, поэтому вызывать этот метод вручную не нужно.

**Решение**: Убедитесь, что вы не вызываете `logShowFlow` (Android SDK v4+) / `logShowPaywall` в своём коде для пейвола, созданного в старом Paywall Builder.

## Другие проблемы \{#other-issues\}

**Проблема**: У вас возникают другие проблемы, связанные с Paywall Builder, не описанные выше.

**Решение**: При необходимости обновите SDK до последней версии, следуя [гайдам по миграции](android-sdk-migration-guides). Многие проблемы уже исправлены в новых версиях SDK.
