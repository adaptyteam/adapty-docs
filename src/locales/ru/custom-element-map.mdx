Следуйте этому рецепту, чтобы добавить интерактивную карту во флоу. Карта показывает ваши места — например, партнёрские фитнес-центры — в радиусе 2 км от пользователя. Приложение отображает карту как нативное представление в [пользовательском элементе](flow-custom-elements) с помощью MapKit. Приложение запрашивает доступ к геолокации прямо на экране флоу.

## Прежде чем начать \{#before-you-start\}

- Обновите приложение до Adapty iOS SDK 4.4 или выше. В более ранних версиях SDK для каждого кастомного элемента отображается [резервный контент](flow-custom-elements#set-fallback-content).
- Настройте приложение для [получения](get-pb-paywalls) и [отображения](ios-present-paywalls) флоу.
- Чтобы запросить у пользователей доступ к геолокации, добавьте ключ `NSLocationWhenInUseUsageDescription` в файл `Info.plist` вашего приложения. Укажите в качестве значения текст запроса, например: «Найдите фитнес-центры рядом с вами».

## 2. Создайте представление карты \{#2-create-the-map-view\}

Создайте тип для ваших мест и модель для доступа к местоположению:

```swift showLineNumbers title="Swift"

// A place of your app, such as a partner fitness center
struct Place: Identifiable {
    let id = UUID()
    let name: String
    let coordinate: CLLocationCoordinate2D
}

// One location manager for the resolver and the map view
@MainActor
final class LocationAccess: NSObject, ObservableObject, CLLocationManagerDelegate {
    @Published private(set) var status: CLAuthorizationStatus = .notDetermined
    var isMapOnScreen = false
    private let manager = CLLocationManager()

    var isDenied: Bool { status == .denied || status == .restricted }

    override init() {
        super.init()
        manager.delegate = self
        status = manager.authorizationStatus
    }

    // Shows the prompt only if the user hasn't answered it yet
    func requestAccess() {
        manager.requestWhenInUseAuthorization()
    }

    nonisolated func locationManagerDidChangeAuthorization(_ manager: CLLocationManager) {
        let status = manager.authorizationStatus
        Task { @MainActor in self.status = status }
    }
}
```

Create a view with a map. The view requests location access and displays a marker for each of your places within 2 km of the user:

```swift showLineNumbers title="Swift"

@available(iOS 17.0, *)
struct NearbyFitnessCentersMap: View {
    @ObservedObject var access: LocationAccess
    let places: [Place]
    @State private var position: MapCameraPosition = .userLocation(fallback: .automatic)
    @State private var nearbyPlaces: [Place] = []

    var body: some View {
        ZStack {
            if access.isDenied {
                ContentUnavailableView(
                    "Location access is off",
                    systemImage: "location.slash",
                    description: Text("To see fitness centers near you, allow location access in Settings.")
                )
            } else {
                Map(position: $position) {
                    UserAnnotation()
                    ForEach(nearbyPlaces) { place in
                        Marker(place.name, systemImage: "dumbbell.fill", coordinate: place.coordinate)
                            .tint(.teal)
                    }
                }
                .task {
                    access.requestAccess()
                    do {
                        for try await update in CLLocationUpdate.liveUpdates() {
                            guard let location = update.location else { continue }
                            nearbyPlaces = places.filter { place in
                                let placeLocation = CLLocation(
                                    latitude: place.coordinate.latitude,
                                    longitude: place.coordinate.longitude
                                )
                                return location.distance(from: placeLocation) <= 2_000 // meters
                            }
                            withAnimation {
                                position = .automatic // zoom to fit the user and the places
                            }
                            break
                        }
                    } catch {
                        // the map still shows the location of the user
                    }
                }
            }
        }
        // Tells the resolver that the map is on the screen
        .onAppear { access.isMapOnScreen = true }
        .onDisappear { access.isMapOnScreen = false }
    }
}
```

Представление карты требует iOS 17 или новее. На iOS 16 пользователи видят резервный пейвол.

Если пользователь отказывает в доступе к геолокации на экране, представление заменяет карту сообщением о том, как разрешить доступ в настройках.

## 3. Привяжите карту к кастомному элементу \{#match-the-map-to-the-custom-element\}

В своём [глобальном резолвере](ios-flow-custom-elements#set-an-app-wide-resolver) добавьте свойства для модели `LocationAccess` и мест. Затем верните представление карты для типа `map` и ID `fitness_centers`. Выделенные строки показывают, что нужно добавить или изменить. Если в вашем приложении ещё нет глобального [резолвера](ios-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views), скопируйте весь код:

```swift showLineNumbers title="Swift" {5-6,14-21}

struct CustomElementsResolver: AdaptyUICustomElementsResolver {
    let locationAccess = LocationAccess()
    let places: [Place] // your app's places, such as partner fitness centers

    func view(
        forType type: String,
        id: String,
        context: AdaptyUICustomElementContext
    ) -> AnyView? {
        switch type {
        case "map" where id == "fitness_centers":
            guard #available(iOS 17.0, *) else {
                return nil // iOS 16: show the fallback
            }
            if locationAccess.isDenied, !locationAccess.isMapOnScreen {
                return nil // access denied before the screen opened: show the fallback
            }
            return AnyView(NearbyFitnessCentersMap(access: locationAccess, places: places))
        // the other cases of your resolver
        default:
            return nil
        }
    }
}
```

<CustomElementMapResolverCalls />

Создайте резолвер с вашими плейсментами и установите его как глобальный для всего приложения. Вызовите `AdaptyUI.setCustomElementsResolver` один раз — например, при запуске приложения:

```swift showLineNumbers title="Swift"

// your app's places, such as partner fitness centers
@MainActor let places = [
    Place(name: "Central Fitness", coordinate: CLLocationCoordinate2D(latitude: 52.5219, longitude: 13.4132)),
    Place(name: "Riverside Gym", coordinate: CLLocationCoordinate2D(latitude: 52.5163, longitude: 13.3777)),
]

// keep this instance: a resolver for one flow can reuse it
@MainActor let customElementsResolver = CustomElementsResolver(places: places)

AdaptyUI.setCustomElementsResolver(customElementsResolver)
```

## 4. Протестируйте на устройстве \{#4-test-on-a-device\}

Paywall Builder и Flow Builder не могут запустить код вашего приложения, поэтому на канвасе отображается только резервный вариант. Чтобы просмотреть карту:

1. [Опубликуйте флоу](builder-save-publish). Чтобы увидеть последнюю опубликованную версию вместо кэшированной, зарегистрируйте устройство как [тестовое](test-devices).
2. Чтобы на карте появился маркер, добавьте место в радиусе 2 км от вашего местоположения в список мест.
3. Убедитесь, что на устройстве установлена iOS 17 или новее. Запустите сборку приложения с подключённым резолвером. Откройте экран и разрешите доступ к геолокации. Убедитесь, что на карте отображается ваше местоположение и маркер добавленного места.

Чтобы протестировать резервный вариант, запретите доступ к геолокации: в приложении **Settings** перейдите в **Privacy & Security** > **Location Services** > *ваше приложение* и выберите **Never**. Затем снова откройте экран.

Чтобы разобраться, почему вместо карты отображается резервный вариант, следуйте инструкциям в разделе [Тест на устройстве](ios-flow-custom-elements#test-on-a-device) руководства по iOS.
