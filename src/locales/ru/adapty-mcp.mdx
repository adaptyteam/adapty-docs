MCP-сервер Adapty подключает ИИ-ассистента к вашему аккаунту Adapty. Спрашивайте о доходах и конверсиях, настраивайте продукты и плейсменты, публикуйте флоу или запускайте A/B-тесты прямо из чата, на обычном языке. Ассистент входит в аккаунт Adapty через браузер и получает ваши права. API-ключ не нужен.

| | |
|---|---|
| URL сервера | `https://mcp.adapty.io/mcp` |
| Протокол | MCP over Streamable HTTP, OAuth 2.1 вход через браузер |
| Работает с | Приложением Claude (веб и десктоп), Claude Code, Codex и другими MCP-клиентами с поддержкой OAuth |

:::important
MCP-сервер лучше всего работает совместно со [скиллами Adapty](#add-the-adapty-skills). Сервер даёт ассистенту доступ к вашему аккаунту, а скиллы — проверенные сценарии работы. Создание флоу, пейволов и поиск точек роста в аналитике требуют скиллов.
:::

## Добавьте скиллы Adapty \{#add-the-adapty-skills\}

MCP-сервер даёт ассистенту доступ к вашему аккаунту Adapty. Скиллы Adapty — это готовые проверенные сценарии: они планируют изменение, проверяют его и запрашивают подтверждение перед каждым шагом, который затрагивает пользователей. Устанавливайте их вместе. Плагин `adapty-skills` включает и скиллы, и этот MCP-сервер.

Скиллы нужны для двух видов задач:

- **Флоу и пейволы**: [Скилл flow-generator](flow-generator-skill) включает правила конфигурации Flow Builder. Он строит экраны по описанию или скриншоту, а также проверяет и предварительно просматривает каждое изменение перед сохранением флоу. Без скилла ассистент может читать и записывать конфиг флоу, но не знает правил валидного конфига.
- **Аналитика и что тестировать дальше**: [Скилл growth-advisor](export-analytics-with-ai) знает, какие отчёты читать и как их интерпретировать, и превращает ваши цифры в гипотезы для A/B-тестов. Без скилла ассистент может получить ваши графики, но не умеет их объяснять.

### Добавление плагина в приложении Claude \{#add-the-plugin-in-the-claude-app\}

Плагин добавляется через настройки Claude, без командной строки.

1. В Claude откройте **Settings** → **Plugins**.
2. Нажмите **Add** → **Add marketplace**.
3. Выберите **Add from a repository**.
4. В поле **URL** введите `adaptyteam/adapty-skills` и выберите репозиторий. Чтобы получать новые скиллы и исправления по мере их выхода, оставьте **Sync automatically** включённым.
5. Нажмите **Sync**.

<ZoomImage id="adapty-skills-claude-add-marketplace.png" width="584px" alt="Add marketplace dialog in Claude with adaptyteam/adapty-skills in the URL field and Sync automatically turned on" />

Claude открывает вкладку **Discover** с плагинами из маркетплейса Adapty. Чтобы установить скиллы, в строке **Adapty** нажмите **Add**.

<ZoomImage id="adapty-skills-claude-discover.png" width="600px" alt="Discover tab in Claude listing the Adapty, Apple ads, and Apple ads benchmarks plugins, each with an Add button" />

Скиллы запускают свои скрипты в песочнице Claude. Чтобы разрешить это, в **Settings** → **Capabilities** включите **Code execution and file creation**.

### Добавьте плагин в кодинг-агент \{#add-the-plugin-in-a-coding-agent\}

В Claude Code, Codex, Copilot CLI, Gemini CLI, Cursor и других кодинг-агентах выполните:

```bash
npx adapty skills install
```

Команда устанавливает плагин через собственный инсталлятор агента, если он есть. После этого перезапустите агента. В Claude Code и Codex плагин также добавляет MCP-сервер Adapty, поэтому достаточно только войти в систему, как описано в разделе [Подключите ассистента](#connect-your-assistant).

<Details summary="Какие скиллы используют MCP-сервер, а какие — CLI">

Перед первым шагом каждый скилл определяет, есть ли у вашего агента MCP-сервер, [Adapty Developer CLI](developer-cli) или оба инструмента. Если доступен один из них, скилл использует его. Если оба — скилл выбирает наиболее подходящий:

- **MCP-сервер**: запуск A/B-тестов, чтение атрибуции Adapty, интеграция SDK, запуск Apple Ads и тестирование покупок.
- **Adapty CLI**: построение и аудит флоу, поиск идей для тестирования, перенос плейсментов во флоу и создание сегментов. Эти скиллы запускают собственные скрипты и файлы, а CLI передаёт им файлы напрямую.

</Details>

## Что умеет ассистент \{#what-the-assistant-can-do\}

Инструменты сервера соответствуют дашборду Adapty и [Adapty Developer CLI](developer-cli). Ассистент сам выбирает нужные инструменты для вашего запроса — вам не нужно их называть.

| Область | Что может делать ассистент | Примеры запросов |
|---|---|---|
| Приложения и уровни доступа | Просматривать, создавать и обновлять приложения и уровни доступа | «Создай уровень доступа `premium` в Fitness Pro.» |
| Продукты и офферы | Создавать продукты с идентификаторами из стора и привязывать к ним офферы | «Какие из моих продуктов не имеют идентификатора Google Play?» |
| Пейволы | Создавать и обновлять пейволы, а также находить плейсменты, в которых они показываются | «В каких плейсментах показывается пейвол Annual sale?» |
| Флоу | Создавать флоу, читать и изменять конфиги билдера, валидировать, просматривать, публиковать и читать метрики флоу | «Опубликуй флоу Onboarding v2 и скажи, в каких плейсментах он показывается.» |
| Плейсменты и аудитории | Создавать плейсменты и управлять тем, кто что видит, а также читать метрики плейсментов с флоу | «Кто и что видит на плейсменте `onboarding`?» |
| Сегменты | Читать сегменты и их фильтры | «Покажи мои сегменты и фильтры каждого из них.» |
| A/B-тесты | Создавать, запускать, останавливать, заменять и архивировать A/B-тесты пейволов и флоу | «Запусти черновик теста Weekly vs annual для пользователей из Германии.» |
| Аналитика | Читать выручку, MRR, конверсии, воронку, удержание, LTV и когорты по установкам | «Сравни конверсию из триала в платную подписку по странам за прошлый месяц.» |
| Атрибуция | Читать эффективность кампаний из [Adapty Attribution](user-acquisition) | «Какие кампании окупились в сентябре?» |
| Apple Ads | Управлять кампаниями, группами объявлений, ключевыми словами и правилами автоматизации в [Adapty Ads Manager](developer-cli-ads-manager), а также читать их метрики | «Какие ключевые слова потратили больше всего за прошлую неделю без единой установки?» |
| Миграция с RevenueCat | Создавать и выполнять миграцию каталога RevenueCat в новое приложение Adapty | «Перенеси мой проект RevenueCat в новое приложение Adapty.» |

У Adapty Mail есть собственный MCP-сервер. Чтобы подключить ассистента к вашему проекту Adapty Mail, см. [Управление Adapty Mail с помощью AI-ассистентов](mail-mcp).

## Выберите MCP-сервер или CLI \{#choose-the-mcp-server-or-the-cli\}

MCP-сервер и [Adapty Developer CLI](developer-cli) работают с одним и тем же аккаунтом Adapty. Выбирайте по тому, где запускается ваш ассистент:

| | MCP-сервер Adapty | Adapty CLI |
|---|---|---|
| Запускается в | Любом MCP-клиенте, включая чат-приложения, например Claude | Агентах, выполняющих команды в терминале, и ваших собственных скриптах |
| Вход | Один раз на клиент, через браузер | `adapty auth login`, один раз на машину |
| Лучше подходит для | Вопросов и изменений из чата | Редактирования конфигов флоу, массовых изменений и скриптов |
| Установка | Ничего не нужно устанавливать | `npm install -g adapty` |

Агент может использовать и то, и другое. В приложении Claude MCP-сервер требует меньше настройки, чем CLI: CLI нужно устанавливать и авторизовывать в каждом разговоре, как описано в [Настройка Adapty CLI в приложении Claude](developer-cli-cowork).

## Прежде чем начать \{#before-you-start\}

- **Аккаунт Adapty**: Ассистент работает в компаниях и приложениях, к которым у вашего аккаунта Adapty есть доступ, с вашими правами.
- **MCP-клиент с OAuth**: Ваш клиент поддерживает удалённые MCP-серверы, которые входят через OAuth.

:::warning
Ассистент действует с вашими правами, и его изменения реальны. Запущенный A/B-тест или изменённый плейсмент сразу достигает ваших пользователей. Прежде чем запустить или остановить A/B-тест, или изменить, кто что видит в плейсменте, сервер просит ассистента описать точный эффект и дождаться вашего подтверждения. Внимательно прочитайте план перед тем, как его одобрить.
:::

## Подключите своего ассистента \{#connect-your-assistant\}

<TabItem value="claude-app" label="Claude app" default>

Приложение Claude (claude.ai и Claude desktop) добавляет удалённые MCP-серверы как пользовательские коннекторы.

1. Чтобы добавить сервер, откройте **Settings → Connectors** и нажмите **Add custom connector**.
2. Введите название, например `Adapty`, и URL `https://mcp.adapty.io/mcp`.
3. Оставьте настройки аутентификации по умолчанию и нажмите **Add**.
4. Войдите в Adapty в открывшейся вкладке браузера. См. [Войти](#sign-in).

Администраторы рабочего пространства могут добавить коннектор один раз для всей организации. Каждый участник затем входит со своим аккаунтом Adapty при первом использовании.

</TabItem>
<TabItem value="claude-code" label="Claude Code">

Если вы используете плагин `adapty-skills`, Claude Code уже отображает сервер как `plugin:adapty-skills:adapty` со статусом **Needs authentication**. Чтобы войти, выполните `/mcp` в Claude Code, выберите `plugin:adapty-skills:adapty` и нажмите **Authenticate**.

Без плагина сначала добавьте сервер:

```bash
claude mcp add --transport http --scope user adapty https://mcp.adapty.io/mcp
```

Затем выполните `/mcp` в Claude Code, выберите `adapty` и нажмите **Authenticate**. Если инструменты Adapty не появились в текущей сессии, начните новую.

</TabItem>
<TabItem value="codex" label="Codex">

Если вы используете плагин `adapty-skills`, он добавляет сервер автоматически, а Codex попросит войти в систему при подключении.

Без плагина добавьте сервер и войдите вручную:

```bash
codex mcp add adapty --url https://mcp.adapty.io/mcp
codex mcp login adapty
```

Команда login открывает браузер. Чтобы вместо этого настроить сервер вручную, добавьте его в `~/.codex/config.toml`, затем выполните команду login:

```toml
[mcp_servers.adapty]
url = "https://mcp.adapty.io/mcp"
```

Начните новую сессию `codex`, чтобы загрузить инструменты Adapty.

</TabItem>
<TabItem value="other" label="Другие клиенты">

Добавьте `https://mcp.adapty.io/mcp` как удалённый MCP-сервер в настройках вашего клиента или в файле конфигурации MCP. При первом подключении клиент откроет браузер для авторизации.

Сервер идентифицирует каждый клиент по его Client ID Metadata Document — методу регистрации клиента, описанному в текущей спецификации MCP. Клиент, не поддерживающий этот метод, не сможет завершить вход. В таком случае используйте [Adapty Developer CLI](developer-cli-quickstart) через терминальный агент.

## Войти в систему \{#sign-in\}

Каждый клиент завершает настройку на одном и том же шаге: открывается страница входа в Adapty в браузере.

1. Войдите в свой аккаунт Adapty, если ещё не вошли.
2. Разрешите клиенту доступ к вашему аккаунту Adapty.

После этого клиент читает и изменяет данные в компаниях, доступных вашему аккаунту, и остаётся авторизованным до тех пор, пока вы его не отключите. Подтверждайте только тот вход, который вы инициировали сами.

Чтобы проверить подключение, спросите ассистента, в какой аккаунт Adapty он вошёл. В ответе должны быть указаны ваше имя и компании, доступные вашему аккаунту.

## Начало работы \{#start-working\}

Спросите ассистента, какие приложения ему доступны, а затем укажите приложение, с которым хотите работать. Примеры запросов:

```text
List my Adapty apps and their placements.
How did revenue and new subscriptions change last month compared with the month before?
Which products in Fitness Pro have no App Store product ID?
Show who sees what on the onboarding placement, including any A/B test.
Create a draft A/B test on main_paywall: the current paywall against Annual sale, 50/50.
```

Помощник запрашивает подтверждение перед шагами, которые меняют то, что видят пользователи. Запрос, который только читает данные, выполняется без дополнительных вопросов.

После многошагового задания помощник может отправить команде Adapty короткую заметку о том, как прошло выполнение задачи. Заметка не содержит персональных данных пользователей вашего приложения.

## Отключение \{#disconnect\}

Чтобы отключиться, удалите сервер в клиенте:

- **Claude app**: В **Settings → Connectors** удалите коннектор Adapty.
- **Claude Code**: Выполните `claude mcp remove adapty`. Если сервер был установлен с плагином `adapty-skills`, отключите его через `/mcp`.
- **Codex**: Удалите сервер `adapty` из `~/.codex/config.toml`.

Чтобы подключиться снова, добавьте сервер и войдите повторно.

## Устранение неполадок \{#troubleshooting\}

| Проблема | Решение |
|---|---|
| Claude Code показывает сервер как **Needs authentication** | Клиент добавил сервер, но не выполнил вход. Запустите `/mcp`, выберите сервер Adapty и нажмите **Authenticate**. |
| Клиент не отображает инструменты Adapty | Завершите вход, затем начните новую сессию. Некоторые клиенты загружают инструменты только в начале сессии. |
| Ассистент не может найти приложение | Приложение принадлежит компании, к которой у вашего аккаунта Adapty нет доступа. Обратитесь к владельцу компании за доступом. |
| Клиент не может завершить вход | Клиент не поддерживает метод входа, используемый сервером. Подключитесь через приложение Claude, Claude Code или Codex, либо воспользуйтесь [Adapty Developer CLI](developer-cli-quickstart). |
