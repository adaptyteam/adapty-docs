MCP-сервер Adapty подключает AI-ассистента к вашему аккаунту Adapty. Задавайте вопросы о доходах и конверсиях, настраивайте продукты и плейсменты, публикуйте флоу или запускайте A/B-тесты прямо из чата, на обычном языке. Ассистент авторизуется через браузер с вашим аккаунтом Adapty и получает ваши права доступа. API-ключ не нужен.

| | |
|---|---|
| URL сервера | `https://mcp.adapty.io/mcp` |
| Протокол | MCP over Streamable HTTP, авторизация OAuth 2.1 в браузере |
| Работает с | claude.ai, Claude desktop, Claude Code, Codex и другими MCP-клиентами с поддержкой OAuth |

:::important
MCP-сервер предоставляет вашему ассистенту доступ к аккаунту Adapty. Чтобы добавить ему экспертизу — правила конфигурации флоу, проверенные методы для вашей аналитики и подтверждение перед каждым шагом, затрагивающим пользователей, — сначала установите [плагин Adapty](manage-adapty-with-ai#install-the-plugin). В Claude Code и Codex плагин добавляет этот сервер автоматически, так что вам достаточно просто [войти в систему](#connect-your-assistant).
:::

## Что умеет ассистент \{#what-the-assistant-can-do\}

Инструменты сервера соответствуют дашборду Adapty и [Adapty Developer CLI](developer-cli). Ассистент сам выбирает нужные инструменты для вашего запроса — вам не нужно их называть.

| Область | Что умеет ассистент | Попробуйте спросить |
|---|---|---|
| Приложения и уровни доступа | Просматривать, создавать и обновлять приложения и уровни доступа | «Создай уровень доступа `premium` в Fitness Pro.» |
| Продукты и офферы | Создавать продукты с их ID в сторе и привязывать к ним офферы стора | «У каких моих продуктов нет Google Play product ID?» |
| Пейволы | Создавать и обновлять пейволы, а также находить плейсменты, в которых они показываются | «В каких плейсментах показывается пейвол Annual sale?» |
| Флоу | Создавать флоу, читать и писать конфиги builder, валидировать, превьювировать, публиковать и читать метрики флоу | «Опубликуй флоу Onboarding v2 и скажи, в каких плейсментах он показывается.» |
| Плейсменты и аудитории | Создавать плейсменты и управлять тем, кому что показывается, а также читать метрики плейсментов флоу | «Кто и что видит на плейсменте `onboarding`?» |
| Сегменты | Читать сегменты и их фильтры | «Покажи мои сегменты и фильтры каждого из них.» |
| A/B-тесты | Создавать, запускать, останавливать, заменять и архивировать A/B-тесты пейволов и флоу | «Запусти черновик теста Weekly vs annual для пользователей из Германии.» |
| Аналитика | Читать данные по выручке, MRR, конверсиям, воронке, удержанию, LTV и когортам установок | «Сравни конверсию trial-to-paid по странам за прошлый месяц.» |
| Миграция из RevenueCat | Создавать и запускать миграцию каталога RevenueCat в новое приложение Adapty | «Перенеси мой проект RevenueCat в новое приложение Adapty.» |

У Adapty Mail есть собственный MCP-сервер. Чтобы подключить ассистента к вашему проекту Adapty Mail, см. [Управление Adapty Mail с помощью AI-ассистентов](mail-mcp).

## Выберите MCP-сервер или CLI \{#choose-the-mcp-server-or-the-cli\}

MCP-сервер и [Adapty Developer CLI](developer-cli) работают с одним и тем же аккаунтом Adapty. Если не настроен ни один из них, плагин Adapty предложит выбрать и даст инструкции по настройке. Если настроены оба, плагин выбирает подходящий для каждой задачи:

| | Сервер Adapty MCP | Adapty CLI |
|---|---|---|
| Работает в | Любом MCP-клиенте, включая claude.ai и Claude desktop | Агентах, выполняющих команды терминала, и ваших собственных скриптах |
| Вход | Один раз на клиент, в браузере | `adapty auth login`, один раз на машину |
| Лучше всего подходит для | Вопросов и изменений из чата | Редактирования конфигов флоу, массовых изменений и скриптов |
| Установка | Ничего устанавливать не нужно | `npm install -g adapty` |

В claude.ai и Claude desktop настройка MCP-сервера проще, чем CLI: CLI нужно устанавливать и авторизовывать в каждом новом разговоре, как описано в разделе [Настройка Adapty CLI в приложении Claude](developer-cli-cowork).

<Details summary="Какие скиллы используют MCP-сервер, а какие — CLI">

Перед первым шагом каждый скилл определяет, есть ли у вашего ассистента MCP-сервер, CLI или оба инструмента. При наличии одного скилл использует его. При наличии обоих скилл выбирает тот, который лучше подходит для конкретной задачи:

- **MCP-сервер**: Запуск A/B-тестов, интеграция SDK и тестирование покупок.
- **Adapty CLI**: Сборка и аудит флоу, поиск того, что тестировать дальше, перенос плейсментов во флоу и создание сегментов. Эти скиллы запускают собственные скрипты и файлы, а CLI передаёт им файлы напрямую.

</Details>

## Прежде чем начать \{#before-you-start\}

- **Аккаунт Adapty**: Ассистент работает в компаниях и приложениях, к которым у вашего аккаунта Adapty есть доступ, с вашими правами.
- **MCP-клиент с OAuth**: Ваш клиент поддерживает удалённые MCP-серверы, которые входят через OAuth.

:::warning
Ассистент действует с вашими правами, и его изменения реальны. Запущенный A/B-тест или изменённый плейсмент сразу достигает ваших пользователей. Прежде чем запустить или остановить A/B-тест, или изменить, кто что видит в плейсменте, сервер просит ассистента описать точный эффект и дождаться вашего подтверждения. Внимательно прочитайте план перед тем, как его одобрить.
:::

## Подключите ассистента \{#connect-your-assistant\}

<Tabs groupId="mcp-client" queryString>
<TabItem value="claude-app" label="claude.ai" default>

claude.ai и Claude desktop добавляют удалённые MCP-серверы как пользовательские коннекторы.

1. Чтобы добавить сервер, откройте **Settings → Connectors** и нажмите **Add custom connector**.
2. Введите имя, например `Adapty`, и URL `https://mcp.adapty.io/mcp`.
3. Оставьте настройки аутентификации по умолчанию и нажмите **Add**.
4. Войдите в Adapty во вкладке браузера, которая откроется. См. [Вход в систему](#sign-in).

Администраторы рабочего пространства могут добавить коннектор один раз для всей организации. При первом использовании каждый участник входит со своей учётной записью Adapty.

</TabItem>
<TabItem value="claude-code" label="Claude Code">

Если вы установили плагин Adapty, Claude Code уже отображает сервер как `plugin:adapty-skills:adapty` со статусом **Needs authentication**. Чтобы войти, выполните `/mcp` в Claude Code, выберите `plugin:adapty-skills:adapty` и нажмите **Authenticate**.

Если плагин не установлен, сначала добавьте сервер:

```bash
claude mcp add --transport http --scope user adapty https://mcp.adapty.io/mcp
```

Затем выполните `/mcp` в Claude Code, выберите `adapty` и нажмите **Authenticate**. Если инструменты Adapty не появились в текущей сессии, начните новую.

</TabItem>
<TabItem value="codex" label="Codex">

Если вы установили плагин Adapty, он добавляет сервер автоматически, и Codex предложит войти в систему при подключении.

Без плагина добавьте сервер и войдите вручную:

```bash
codex mcp add adapty --url https://mcp.adapty.io/mcp
codex mcp login adapty
```

Команда login открывает браузер. Чтобы вместо этого настроить сервер вручную, добавьте его в `~/.codex/config.toml`, затем выполните команду login:

```toml
[mcp_servers.adapty]
url = "https://mcp.adapty.io/mcp"
```

Начните новую сессию `codex`, чтобы загрузить инструменты Adapty.

</TabItem>
<TabItem value="other" label="Другие клиенты">

Добавьте `https://mcp.adapty.io/mcp` как удалённый MCP-сервер в настройках вашего клиента или в файле конфигурации MCP. При первом подключении клиент откроет браузер для авторизации.

Сервер идентифицирует каждый клиент по его Client ID Metadata Document — методу регистрации клиента, описанному в текущей спецификации MCP. Клиент, не поддерживающий этот метод, не сможет завершить вход. В таком случае используйте [Adapty Developer CLI](developer-cli-quickstart) через терминальный агент.

</TabItem>
</Tabs>

## Войти в систему \{#sign-in\}

Каждый клиент завершает настройку на одном и том же шаге: открывается страница входа в Adapty в браузере.

1. Войдите в свой аккаунт Adapty, если ещё не вошли.
2. Разрешите клиенту доступ к вашему аккаунту Adapty.

После этого клиент читает и изменяет данные в компаниях, доступных вашему аккаунту, и остаётся авторизованным до тех пор, пока вы его не отключите. Подтверждайте только тот вход, который вы инициировали сами.

Чтобы проверить подключение, спросите ассистента, в какой аккаунт Adapty он вошёл. В ответе должны быть указаны ваше имя и компании, доступные вашему аккаунту.

## Начало работы \{#start-working\}

Спросите ассистента, какие приложения ему доступны, а затем укажите приложение, с которым хотите работать. Примеры запросов:

```text
List my Adapty apps and their placements.
How did revenue and new subscriptions change last month compared with the month before?
Which products in Fitness Pro have no App Store product ID?
Show who sees what on the onboarding placement, including any A/B test.
Create a draft A/B test on main_paywall: the current paywall against Annual sale, 50/50.
```

Помощник запрашивает подтверждение перед шагами, которые меняют то, что видят пользователи. Запрос, который только читает данные, выполняется без дополнительных вопросов.

После многошагового задания помощник может отправить команде Adapty короткую заметку о том, как прошло выполнение задачи. Заметка не содержит персональных данных пользователей вашего приложения.

## Отключение \{#disconnect\}

Чтобы отключиться, удалите сервер в клиенте:

- **claude.ai**: В разделе **Settings → Connectors** удалите коннектор Adapty.
- **Claude Code**: Выполните команду `claude mcp remove adapty`. Если сервер был добавлен через плагин Adapty, отключите его через `/mcp`.
- **Codex**: Удалите сервер `adapty` из файла `~/.codex/config.toml`.

Чтобы подключиться снова, добавьте сервер и войдите ещё раз.

## Устранение неполадок \{#troubleshooting\}

| Проблема | Решение |
|---|---|
| Claude Code показывает сервер со статусом **Needs authentication** | Клиент добавил сервер, но не выполнил вход. Запустите `/mcp`, выберите сервер Adapty и нажмите **Authenticate**. |
| Клиент не отображает инструменты Adapty | Завершите вход, затем начните новую сессию. Некоторые клиенты загружают инструменты только при старте сессии. |
| Ассистент не может найти приложение | Приложение принадлежит компании, к которой у вашего аккаунта Adapty нет доступа. Попросите владельца компании предоставить доступ. |
| Клиент не может завершить вход | Клиент не поддерживает метод входа, используемый сервером. Подключитесь через claude.ai, Claude Code или Codex либо воспользуйтесь [Adapty Developer CLI](developer-cli-quickstart). |
