MCP-сервер Adapty подключает ИИ-ассистента к вашему аккаунту Adapty. Спрашивайте о доходах и конверсиях, настраивайте продукты и плейсменты, публикуйте флоу, запускайте A/B-тесты или управляйте кампаниями Apple Ads — прямо в чате, на обычном языке. Ассистент авторизуется через браузер под вашим аккаунтом Adapty и получает ваши права. API-ключ не нужен.

| | |
|---|---|
| URL сервера | `https://mcp.adapty.io/mcp` |
| Протокол | MCP over Streamable HTTP, OAuth 2.1 — авторизация в браузере |
| Работает с | claude.ai, Claude desktop, Claude Code, Codex и другими MCP-клиентами с поддержкой OAuth |

:::important
MCP-сервер предоставляет вашему ассистенту доступ к аккаунту Adapty. Чтобы добавить ему экспертизу — правила конфигурации флоу, проверенные методы для вашей аналитики и подтверждение перед каждым шагом, затрагивающим пользователей, — сначала установите [плагин Adapty](manage-adapty-with-ai#install-the-plugin). В Claude Code и Codex плагин добавляет этот сервер автоматически, так что вам достаточно просто [войти в систему](#connect-your-assistant).
:::

## Что умеет ассистент \{#what-the-assistant-can-do\}

Инструменты сервера соответствуют дашборду Adapty и [Adapty Developer CLI](developer-cli). Ассистент сам выбирает нужные инструменты для вашего запроса — вам не нужно их называть.

| Раздел | Что умеет ассистент | Примеры запросов |
|---|---|---|
| Приложения и уровни доступа | Просматривать, создавать и обновлять приложения и уровни доступа | «Создай уровень доступа `premium` в Fitness Pro.» |
| Продукты и офферы | Создавать продукты с их ID в сторе и привязывать офферы стора к ним | «У каких моих продуктов нет ID продукта в Google Play?» |
| Пейволы | Создавать и обновлять пейволы, находить плейсменты, в которых они показываются | «В каких плейсментах показывается пейвол Annual sale?» |
| Флоу | Создавать флоу, читать и редактировать их конфиги в билдере, валидировать, предпросматривать, публиковать и просматривать метрики флоу. Просматривать, переименовывать и восстанавливать предыдущие версии, а также дублировать флоу или версию в новый флоу | «Опубликуй флоу Onboarding v2 и скажи, в каких плейсментах он показывается.» |
| Плейсменты и аудитории | Создавать плейсменты и управлять тем, кто что видит, а также читать метрики плейсментов с флоу | «Кто и что видит на плейсменте `onboarding`?» |
| Сегменты | Читать сегменты и их фильтры | «Покажи мои сегменты и фильтры каждого.» |
| A/B-тесты | Создавать, запускать, останавливать, заменять и архивировать A/B-тесты пейволов и флоу | «Запусти черновой тест Weekly vs annual для пользователей из Германии.» |
| Аналитика | Читать данные по выручке, MRR, конверсиям, воронке, удержанию, LTV и когортам по установкам | «Сравни конверсию из триала в платную подписку по странам за прошлый месяц.» |
| Apple Ads | Управлять кампаниями, группами объявлений, ключевыми словами и правилами автоматизации в [Adapty Ads Manager](adapty-ads-manager), а также читать их метрики | «Какие ключевые слова потратили больше всего на прошлой неделе без единой установки?» |
| Retention Messaging | Читать статус настройки, подключать realtime URL, запускать тест производительности, создавать, изменять, активировать и деактивировать [retention-сообщения](retention-messaging), а также читать их метрики. Для работы с изображениями и новыми пунктами нужен [CLI](developer-cli-retention-messaging) или дашборд | «Какие retention-сообщения сейчас активны на проде и какой у них save rate?» |
| Refund Saver | Включать и выключать [Refund Saver](refund-saver), проверять наличие нужных ключей в каждом сторе, задавать настройки возвратов для каждого стора и отдельного профиля, а также читать данные об обработанных запросах на возврат и сэкономленных средствах | «Сколько сэкономил Refund Saver за прошлый месяц?» |
| Миграция с RevenueCat | Создавать и запускать миграцию каталога RevenueCat в новое приложение Adapty | «Перенеси мой проект RevenueCat в новое приложение Adapty.» |

Для работы с историей версий ассистент использует инструменты [истории версий](flow-version-history#work-with-versions-from-the-cli-or-an-ai-assistant): `flows_versions_list`, `flows_versions_get`, `flows_versions_preview`, `flows_versions_rename`, `flows_versions_restore` и `flows_duplicate`. Восстановление заменяет черновик. Чтобы сохранить черновик, сначала продублируйте его в новый флоу. Если у флоу есть черновик, ассистент спросит вас перед заменой и предложит сначала продублировать черновик. Восстановленная версия не попадёт к пользователям, пока вы её не опубликуете.

У Adapty Mail есть собственный MCP-сервер. Чтобы подключить ассистента к вашему проекту Adapty Mail, см. [Управление Adapty Mail с помощью AI-ассистентов](mail-mcp).

## Выберите MCP-сервер или CLI \{#choose-the-mcp-server-or-the-cli\}

MCP-сервер и [Adapty Developer CLI](developer-cli) работают с одним и тем же аккаунтом Adapty. Если не настроен ни один из них, плагин Adapty предложит выбрать и даст инструкции по настройке. Если настроены оба, плагин выбирает подходящий для каждой задачи:

| | Сервер Adapty MCP | Adapty CLI |
|---|---|---|
| Работает в | Любом MCP-клиенте, включая claude.ai и Claude desktop | Агентах, выполняющих команды терминала, и ваших собственных скриптах |
| Вход | Один раз на клиент, в браузере | `adapty auth login`, один раз на машину |
| Лучше всего подходит для | Вопросов и изменений из чата | Редактирования конфигов флоу, массовых изменений и скриптов |
| Установка | Ничего устанавливать не нужно | `npm install -g adapty` |

В claude.ai и Claude desktop настройка MCP-сервера проще, чем CLI: CLI нужно устанавливать и авторизовывать в каждом новом разговоре, как описано в разделе [Настройка Adapty CLI в приложении Claude](developer-cli-cowork).

<Details summary="Какие скиллы используют MCP-сервер, а какие — CLI">

Перед первым шагом каждый скилл определяет, есть ли у вашего ассистента MCP-сервер, CLI или оба инструмента. При наличии одного скилл использует его. При наличии обоих скилл выбирает тот, который лучше подходит для конкретной задачи:

- **MCP server**: Запуск A/B-тестов, Apple Ads, интеграция SDK и тестирование покупок.
- **Adapty CLI**: Создание и аудит флоу, поиск того, что тестировать дальше, перенос плейсментов во флоу и создание сегментов. Эти скиллы запускают собственные скрипты и файлы, а CLI передаёт им файлы напрямую.

</Details>

## Прежде чем начать \{#before-you-start\}

- **Аккаунт Adapty**: Ассистент работает в компаниях и приложениях, доступных вашему аккаунту Adapty, с вашими правами.
- **MCP-клиент с OAuth**: Ваш клиент поддерживает удалённые MCP-серверы с авторизацией через OAuth.

:::warning
Ассистент действует с вашими правами, и его изменения реальны. Запущенный A/B-тест или изменённый плейсмент сразу достигает ваших пользователей, а изменённая ставка или бюджет в Apple Ads тратит реальные деньги. Прежде чем ассистент запустит или остановит A/B-тест либо изменит, кому и какой плейсмент показывается, сервер попросит его описать точный эффект и дождаться вашего подтверждения. Внимательно прочитайте план перед тем, как его одобрить.
:::

## Подключите ассистента \{#connect-your-assistant\}

<Tabs groupId="mcp-client" queryString>
<TabItem value="claude-app" label="claude.ai" default>

claude.ai и Claude desktop добавляют удалённые MCP-серверы в качестве пользовательских коннекторов.

1. Чтобы добавить сервер, откройте **Settings → Connectors** и нажмите **Add custom connector**.
2. Введите название, например `Adapty`, и URL `https://mcp.adapty.io/mcp`.
3. Оставьте настройки аутентификации по умолчанию и нажмите **Add**.
4. Войдите в Adapty в открывшейся вкладке браузера. См. [Вход в систему](#sign-in).
5. Чтобы ассистент мог отправлять в Adapty прикреплённое изображение или скриншот отзыва из App Store, добавьте `*.adapty.io` в список разрешённых доменов. Claude хранит прикреплённый файл в своей песочнице, и у неё есть доступ только к разрешённым доменам. Внесите это изменение в claude.ai в браузере или в Claude Desktop: в мобильном приложении Claude такой настройки нет, но изменение распространяется и на ваши разговоры там.
   - На индивидуальном плане откройте **Settings → Capabilities**. Включите **Code execution and file creation** и **Allow network egress**: поле **Additional allowed domains** появляется только при включении обоих параметров. Затем добавьте `*.adapty.io` в поле **Additional allowed domains**.
   - На плане Team или Enterprise владелец организации добавляет `*.adapty.io` в **Organization settings → Capabilities**.

   Применение нового домена может занять несколько минут. Если ассистент по-прежнему не может отправить файл, начните новый разговор. Если в списке разрешённых доменов выбрано **All domains**, пропустите этот шаг.

Администраторы рабочего пространства могут добавить коннектор один раз для всей организации. Каждый участник затем входит со своим аккаунтом Adapty при первом использовании.

</TabItem>
<TabItem value="claude-code" label="Claude Code">

Если вы установили плагин Adapty, Claude Code уже отображает сервер как `plugin:adapty-skills:adapty` со статусом **Needs authentication**. Чтобы войти, запустите `/mcp` в Claude Code, выберите `plugin:adapty-skills:adapty` и нажмите **Authenticate**.

Без плагина сначала добавьте сервер:

```bash
claude mcp add --transport http --scope user adapty https://mcp.adapty.io/mcp
```

Затем запустите `/mcp` в Claude Code, выберите `adapty` и нажмите **Authenticate**. Если инструменты Adapty не появятся в текущей сессии, начните новую.

</TabItem>
<TabItem value="codex" label="Codex">

Если вы установили плагин Adapty, плагин добавляет сервер сам, и Codex предложит войти при подключении.

Без плагина добавьте сервер и войдите вручную:

```bash
codex mcp add adapty --url https://mcp.adapty.io/mcp
codex mcp login adapty
```

Команда входа откроет браузер. Чтобы настроить сервер вручную, добавьте его в `~/.codex/config.toml`, затем выполните команду входа:

```toml
[mcp_servers.adapty]
url = "https://mcp.adapty.io/mcp"
```

Запустите новую сессию `codex`, чтобы загрузить инструменты Adapty.

</TabItem>
<TabItem value="other" label="Other clients">

Добавьте `https://mcp.adapty.io/mcp` как удалённый MCP-сервер в настройках клиента или в файле конфигурации MCP. При первом подключении клиент откроет браузер для входа.

Сервер идентифицирует каждый клиент через Client ID Metadata Document — метод регистрации клиентов, предусмотренный актуальной спецификацией MCP. Если клиент не поддерживает этот метод, пройти авторизацию не получится. В таком случае используйте [Adapty Developer CLI](developer-cli-quickstart) из терминального агента.

</TabItem>

## Войти в систему \{#sign-in\}

Каждый клиент завершает настройку на одном и том же шаге: открывается страница входа в Adapty в браузере.

1. Войдите в свой аккаунт Adapty, если ещё не вошли.
2. Разрешите клиенту доступ к вашему аккаунту Adapty.

После этого клиент читает и изменяет данные в компаниях, доступных вашему аккаунту, и остаётся авторизованным до тех пор, пока вы его не отключите. Подтверждайте только тот вход, который вы инициировали сами.

Чтобы проверить подключение, спросите ассистента, в какой аккаунт Adapty он вошёл. В ответе должны быть указаны ваше имя и компании, доступные вашему аккаунту.

## Начало работы \{#start-working\}

Спросите ассистента, какие приложения ему доступны, а затем укажите приложение, с которым хотите работать. Примеры запросов:

```text
List my Adapty apps and their placements.
How did revenue and new subscriptions change last month compared with the month before?
Which products in Fitness Pro have no App Store product ID?
Show who sees what on the onboarding placement, including any A/B test.
Create a draft A/B test on main_paywall: the current paywall against Annual sale, 50/50.
```

Помощник запрашивает подтверждение перед шагами, которые меняют то, что видят пользователи. Запрос, который только читает данные, выполняется без дополнительных вопросов.

После многошагового задания помощник может отправить команде Adapty короткую заметку о том, как прошло выполнение задачи. Заметка не содержит персональных данных пользователей вашего приложения.

## Отключение \{#disconnect\}

Чтобы отключиться, удалите сервер в клиенте:

- **claude.ai**: В разделе **Settings → Connectors** удалите коннектор Adapty.
- **Claude Code**: Выполните команду `claude mcp remove adapty`. Если сервер был добавлен через плагин Adapty, отключите его через `/mcp`.
- **Codex**: Удалите сервер `adapty` из файла `~/.codex/config.toml`.

Чтобы подключиться снова, добавьте сервер и войдите ещё раз.

## Устранение неполадок \{#troubleshooting\}

| Проблема | Решение |
|---|---|
| Claude Code показывает сервер как **Needs authentication** | Клиент добавил сервер, но не выполнил вход. Запустите `/mcp`, выберите сервер Adapty и нажмите **Authenticate**. |
| Клиент не показывает инструменты Adapty | Завершите вход, затем начните новую сессию. Некоторые клиенты загружают инструменты только при старте сессии. |
| Ассистент не может найти приложение | Приложение принадлежит компании, к которой у вашего аккаунта Adapty нет доступа. Попросите владельца компании предоставить доступ. |
| В claude.ai ассистент не может отправить изображение или скриншот в Adapty, загрузка завершается ошибкой 403 | Песочница Claude блокирует домен Adapty. Добавьте `*.adapty.io` в список разрешённых доменов в Claude, как описано в разделе [Подключите ассистента](#connect-your-assistant). Настройка может применяться несколько минут. Если ошибка не исчезает, начните новый диалог. |
| Клиент не может завершить вход | Клиент не поддерживает метод входа, который использует сервер. Подключитесь через claude.ai, Claude Code или Codex, либо воспользуйтесь [Adapty Developer CLI](developer-cli-quickstart). |
