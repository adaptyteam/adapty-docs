Уровни доступа позволяют управлять тем, что пользователи могут делать в вашем приложении, без хардкода конкретных ID продуктов. Каждый продукт определяет, на какой срок пользователь получает определённый уровень доступа. Таким образом, при каждой покупке Adapty предоставляет доступ к приложению на определённый период (для подписок) или навсегда (для покупок с пожизненным доступом).

При создании приложения в дашборде Adapty автоматически создаётся уровень доступа `premium`. Он является уровнем доступа по умолчанию и не может быть удалён.

:::tip
Вы также можете создавать уровни доступа программно с помощью [Developer CLI](developer-cli-apps#adapty-access-levels-create).
:::

Чтобы создать новый уровень доступа:

1. Перейдите в **[Products](https://app.adapty.io/access-levels)** в главном меню Adapty, затем выберите вкладку **Access levels**.

3. В окне **Create access level** присвойте ему идентификатор. Этот идентификатор будет использоваться в вашем мобильном приложении для предоставления доступа к дополнительным функциям после покупки пользователем. Кроме того, он помогает различать уровни доступа в приложении. Убедитесь, что он понятен и легко читается — для вашего удобства.

4. Нажмите **Create access level**, чтобы подтвердить создание уровня доступа.
