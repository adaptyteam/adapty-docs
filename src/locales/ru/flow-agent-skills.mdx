Навыки агента позволяют вашему AI-ассистенту по написанию кода работать с флоу прямо из терминала через [Adapty CLI](developer-cli-quickstart), а не через визуальный редактор. Вы описываете задачу на обычном языке, инструмент читает данные вашего аккаунта, выполняет работу и показывает результат до того, как что-либо будет сохранено.

Три навыка, и у каждого своя зона ответственности: один создаёт флоу и вносит в них изменения, второй проверяет, готов ли флоу к публикации, третий переводит приложение, использующее пейволы, на флоу-плейсменты. Все три поставляются в одном плагине, так что одна установка даёт вам каждый из них.

Используйте **flow-generator**, когда знаете, что именно нужно изменить — добавить новую локаль, переписать текст, добавить или убрать экран, перестроить ветку. Он редактирует конфиг и сохраняет черновик для вашего согласования; публикация при этом не происходит.

Используйте **flow-audit**, когда хотите проверить, готов ли флоу к запуску. Он читает флоу и ваш каталог продуктов, сообщает о том, что сломается для реального пользователя, и передаёт найденные проблемы в flow-generator для исправления.

Используйте **migrate-placements**, если ваше приложение ещё работает на пейволах. Этот инструмент не затрагивает содержимое флоу — он считывает ваши плейсменты с пейволами, создаёт для каждого из них плейсмент флоу, а затем передаёт вам идентификаторы плейсментов и вызов SDK для замены.

Ни один из них не заменяет [AI Editor](flow-ai-editor), который работает непосредственно внутри Flow & Paywall Builder. Навыки агента запускаются в вашем терминале, в той же сессии, что и код вашего приложения.
