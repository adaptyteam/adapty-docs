[FunnelFox](https://funnelfox.com) создаёт веб-воронки: лендинги и квизы, которые продают ваши подписки за пределами App Store и Google Play. Подключите FunnelFox к Adapty, чтобы пользователи, совершившие покупку в интернете, получали доступ к платным функциям в вашем мобильном приложении, а их покупки отображались в том же дашборде, что и покупки из сторов.

Подключение требует один ключ и один идентификатор уровня доступа. После этого ваше приложение должно идентифицировать покупателя, чтобы предоставить ему этот уровень доступа. См. [Предоставление доступа в приложении](#provide-access-in-your-app).

## Как работает интеграция \{#how-the-integration-works\}

FunnelFox собирает оплату на сайте. Затем FunnelFox вызывает [Server-side API Adapty](getting-started-with-server-side-api), чтобы создать [профиль](profiles-crm), записать транзакцию и предоставить [уровень доступа](access-level), ID которого вы указываете в настройках интеграции FunnelFox. Продления, отмены и неудачные платежи обновляют тот же профиль. Веб-покупки отображаются в [аналитике Adapty](analytics) рядом с доходами из App Store и Google Play.

Создайте соответствующий [продукт](product) в Adapty для каждого продукта, который продаёт ваша воронка. Покупка в любом случае попадёт в Adapty, но без продукта Adapty не знает длительность подписки, поэтому аналитика может показать неверную длительность или оставить покупку без категории.

Adapty связывает веб-покупку с пользователем приложения по customer user ID. По умолчанию FunnelFox использует в качестве этого ID email-адрес, введённый при оформлении заказа.

Если ваша воронка выставляет счета через Stripe или Paddle, подключать этого провайдера к Adapty отдельно не нужно. Подключайте его только в том случае, если вы также продаёте через него за пределами своих воронок — Adapty дедуплицирует транзакции, поступающие из обоих источников.

Чтобы реализовать тот же флоу с собственным веб-чекаутом вместо воронки FunnelFox, см. [Синхронизация покупок между вебом и мобильным приложением](sync-subscribers-from-web).

## Подключение FunnelFox \{#connect-funnelfox\}

Подключение настраивается на стороне FunnelFox — следуйте [инструкции по интеграции FunnelFox с Adapty](https://funnelfox.com/docs/integrations/subscription-management/adapty#setup). Вам понадобятся два значения из Adapty:

- **Secret API key**: Откройте [**App Settings**](https://app.adapty.io/settings/general) в Adapty и скопируйте секретный ключ.
- **Access level ID**: [Уровень доступа](access-level), который предоставляется после покупки. В каждом приложении Adapty по умолчанию создаётся уровень `premium`; если нужен другой — сначала [создайте его](create-access-level).

## Предоставление разных уровней доступа в одном флоу \{#grant-different-access-levels-within-one-funnel\}

Если флоу продаёт один тариф, настраивать ничего не нужно: каждая покупка будет предоставлять уровень доступа из настроек интеграции.

Чтобы продавать несколько тарифов из одного флоу, используйте поле **Custom entitlement** в элементе оформления заказа. Оно переопределяет ID уровня доступа из настроек интеграции для покупок через этот элемент. Флоу может содержать несколько элементов оформления заказа — например, кнопку Wallet и аккордеон-чекаут. У каждого из них есть своё поле **Custom entitlement**, поэтому заполните его на каждом элементе, который должен предоставлять переопределённый уровень доступа.

:::important
Переопубликуйте флоу после изменения настроек интеграции или любого значения **Custom entitlement**. Опубликованный флоу продолжает использовать предыдущую конфигурацию вплоть до переопубликации.
:::

## Предоставьте доступ в своём приложении \{#provide-access-in-your-app\}

Чтобы открыть платные функции для пользователя, совершившего покупку через веб, вызовите `Adapty.activate()` или `Adapty.identify()` с тем же customer user ID, который использовал FunnelFox. По умолчанию это адрес электронной почты, введённый покупателем при оформлении заказа. Подробнее о вызове смотрите в разделах <InlineTooltip tooltip="Идентификация пользователей">[iOS](identifying-users), [Android](android-identifying-users), [React Native](react-native-identifying-users), [Flutter](flutter-identifying-users), [Unity](unity-identifying-users), [Kotlin Multiplatform](kmp-identifying-users) и [Capacitor](capacitor-identifying-users)</InlineTooltip>.

Установка приложения по ссылке из воронки не идентифицирует покупателя. Пока ваше приложение не вызовет `Adapty.identify()` с совпадающим ID, профиль с уровнем доступа и профиль, созданный приложением, остаются разделёнными, и приложение не показывает платный доступ. Вход через email, указанный при оплате, совмещает эти два профиля.

Чтобы открыть доступ без шага авторизации, передайте customer user ID из воронки в приложение через отложенный диплинк, затем вызовите `Adapty.identify()` с этим ID при первом запуске.

Затем считайте уровень доступа из профиля, чтобы открыть нужные функции. Подробнее — <InlineTooltip tooltip="Проверка статуса подписки">[iOS](ios-check-subscription-status), [Android](android-check-subscription-status), [React Native](react-native-check-subscription-status), [Flutter](flutter-check-subscription-status), [Unity](unity-check-subscription-status), [Kotlin Multiplatform](kmp-check-subscription-status) и [Capacitor](capacitor-check-subscription-status)</InlineTooltip>.

## Проверьте интеграцию \{#test-the-integration\}

1. Совершите покупку в вашей воронке.
2. В Adapty откройте [**Profiles**](https://app.adapty.io/profiles/users) и найдите профиль по customer user ID, который использует FunnelFox.
3. Убедитесь, что уровень доступа, ID которого вы указали в настройках интеграции FunnelFox, активен на этом профиле.
4. Откройте приложение, авторизуйтесь под тем же пользователем и убедитесь, что платные функции разблокированы.

## Устранение неполадок \{#troubleshooting\}

### Пользователь, купивший подписку через веб, открывает приложение без доступа \{#a-web-buyer-opens-the-app-without-paid-access\}

Ваше приложение не идентифицировало покупателя. FunnelFox предоставил уровень доступа профилю, привязанному к ID, который он использовал — по умолчанию это email, указанный при оформлении заказа, — а ваше приложение читает другой профиль. Вызовите `Adapty.identify()` с этим ID, как описано в разделе [Предоставление доступа в приложении](#provide-access-in-your-app).

## Другие интеграции FunnelFox \{#other-funnelfox-integrations\}

FunnelFox подключается к трём продуктам Adapty, каждый из которых настраивается отдельно.

| Продукт | Что FunnelFox отправляет в Adapty | Гайд по настройке |
|---|---|---|
| Core | Профили, транзакции и уровни доступа, чтобы покупки через веб открывали доступ в приложении | Эта статья |
| Adapty Attribution | События транзакций с данными о кампании, воронке и эксперименте | [Интеграция FunnelFox с Adapty Attribution](ua-funnelfox) |
| Adapty Mail | Email-адреса, история покупок и события подписок | [Подключение FunnelFox к Adapty Mail](mail-funnelfox) |
