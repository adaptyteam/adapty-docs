1. В Adapty откройте приложение, которое вы подключаете: у каждого приложения Adapty есть собственный URL для уведомлений. Перейдите в [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). В разделе **App Store server notifications** скопируйте URL из поля **URL for App Store server notifications**.

   <ZoomImage id="app-settings-notifications-url.webp" width="700px" alt="URL for App Store server notifications in the App Store server notifications section in Adapty" />

2. В [App Store Connect](https://appstoreconnect.apple.com/apps) откройте страницу **App Information** вашего приложения.
3. В разделе **App Store Server Notifications** найдите **Production Server URL**. Если URL уже указан, нажмите **Edit**. В противном случае нажмите **Set Up URL**.

   <ZoomImage id="asc-server-notifications-set-up-url.webp" width="700px" alt="App Store Server Notifications section on the App Information page in App Store Connect" />

4. Вставьте URL из Adapty и нажмите **Save**.

   <ZoomImage id="asc-server-url-set-up-dialog.webp" width="700px" alt="Production Server URL dialog in App Store Connect with the URL from Adapty" />

5. Чтобы уведомления из тестовой среды (песочницы) тоже доходили до Adapty, повторите шаги 3 и 4 для **Sandbox Server URL**.
