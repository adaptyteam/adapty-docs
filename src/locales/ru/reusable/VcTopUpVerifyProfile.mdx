В [истории событий](virtual-currency-balance#review-balance-changes-in-the-event-history) игрока проверьте наличие следующих записей:

- **Virtual currency credited**: для каждой покупки или продления подписки, которая начисляет кристаллы.
- **Virtual currency debited**: для каждого списания с меткой `energy_refill` или `unlimited_energy`. Adapty называет эту запись по имени операции `spend`. Если `operation` не указана, Adapty называет её **Virtual currency transaction**.
- **Virtual currency adjusted**: для каждого ручного списания с операцией **Adjustment**, как в шаге 6.
- **Virtual currency expired**: для кристаллов из подписки, которые истекли без использования.
