Чтобы сообщить игрокам, сколько ещё алмазов им не хватает, используйте [кастомный тег](flow-custom-tags): плейсхолдер, который вставляется в текстовый элемент. Код на шаге 4 передаёт число в тег один раз — при открытии флоу. Слова вокруг числа остаются в билдере, где их можно редактировать и переводить.

1. [Создайте кастомный тег](flow-custom-tags#create-a-custom-tag) с именем `diamonds_needed` и введите тире (`—`) в поле **Initial value**. Если код приложения не передаёт число для тега, игроки увидят тире.
2. Добавьте текстовый элемент со словами «You need more diamonds». После «need» [вставьте кастомный тег `diamonds_needed`](flow-custom-tags#add-a-custom-tag-to-a-text-element).
