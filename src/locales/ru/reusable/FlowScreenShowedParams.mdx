Флоу отправляет событие `flow_screen_showed` каждый раз, когда пользователь открывает один из его экранов. Adapty учитывает эти события в собственной аналитике флоу и также передаёт их в ваше приложение, чтобы вы могли построить такую же воронку в своей аналитике.

| Параметр         | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|:-----------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `instanceId`     | ID экрана, который открыл пользователь.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `screen_order`   | Порядковый номер экрана во флоу.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `is_last_screen` | `true`, если экран не ведёт никуда дальше. Во флоу с ветвлением может быть несколько конечных экранов — каждый из них передаёт `true`. Экран пейвола передаёт `false`, если хотя бы одно из его [действий на исходе](respond-to-purchase-outcomes#add-actions-for-a-result) ведёт на другой экран, независимо от результата покупки или восстановления. Действие **Navigate back** не учитывается. Переход на экран тоже не учитывается, если все пользователи проходят этот экран до пейвола. |

Оба параметра `isBackendEvent` и `isCustomerEvent` равны `true` для этого события: Adapty продолжает считать его, а ваше приложение также получает его.
