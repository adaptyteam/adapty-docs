1. Добавьте элемент [**Products**](paywall-product-block#add-a-product-group) с наборами алмазов. Чтобы запускать покупку набора при нажатии на карточку, привяжите [действие **Purchase** к каждой карточке](paywall-product-block#trigger-purchase-from-a-product-card).
2. Чтобы предложить подписку на том же экране, что и наборы, добавьте [кнопку покупки](paywall-product-block#add-a-purchase-button). В действии **Purchase** кнопки выберите подписку из выпадающего списка **Product**. В тексте кнопки вставьте переменные [`prod_price` и `prod_billing_period`](onboarding-variables#product-variables) подписки.
3. В текстовом элементе каждой карточки укажите, сколько алмазов получает игрок, например «500 алмазов». Добавьте текстовый элемент для подписки и укажите, сколько алмазов игрок получает за каждый расчётный период, например «300 алмазов в месяц». Следите, чтобы каждое число совпадало с **Credit amount** или **Credit per cycle** продукта: ни одна [переменная продукта](onboarding-variables#product-variables) не хранит это значение. Если название набора в сторе уже содержит число, например «500 Diamonds», вставьте вместо него переменную `prod_title`.
4. Чтобы игроки могли закрыть флоу без покупки, добавьте [кнопку **Close**](basic-paywall-screen#3-add-the-close-button). Добавьте [ссылки в футере](basic-paywall-screen#9-add-footer-links): сторы требуют указывать ссылки на Условия использования и Политику конфиденциальности везде, где игроки могут оформить подписку.
