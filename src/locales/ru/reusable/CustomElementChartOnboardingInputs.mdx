В Flow & Paywall Builder добавьте два поля ввода [**Number**](builder-inputs-and-forms) в флоу онбординга:

- Одно для текущего веса в килограммах с **Element ID** `weight`.
- Одно для целевого веса в килограммах с **Element ID** `goal_weight`.

Чтобы приложение считывало вес одинаково во всех локалях, выберите **Integer** в выпадающем списке **Format** для обоих полей. Поле отправляет значение в приложение как текст ровно в том виде, в каком пользователь его ввёл. Код в этом рецепте по-разному обработает «70.5» и «70,5». Целые числа не содержат разделителя дробной части.

Чтобы приложение гарантированно получило оба значения, завершите флоу онбординга экраном без полей ввода. На этом экране добавьте кнопку с действием [**Close flow**](onboarding-actions#close-flow). Поля ввода отправляют свои значения при потере фокуса или при переходе пользователя на другой экран.
