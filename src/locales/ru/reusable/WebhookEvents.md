
| Event name                         | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|:-----------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| subscription_started               | Срабатывает, когда пользователь активирует платную подписку без пробного периода, то есть оплата списывается сразу.                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| subscription_active                | Подтверждает, что подписка всё ещё активна после события `subscription_started`. Вы задаёте количество дней между началом подписки и этой проверкой. Событие приходит, если подписка по-прежнему активна, в том числе когда пользователь вошёл в льготный период. Если подписка к тому моменту завершилась или пользователь отключил автопродление — событие не придёт, и Adapty больше не проверяет. Это событие относится только к подпискам, оформленным без пробного периода. Конвертированный триал отправляет `trial_converted`, который проверку не запускает. |
| subscription_renewed               | Срабатывает при продлении подписки и списании оплаты. Начиная со второго расчётного периода — как для триальных, так и для обычных подписок.                                                                                                                                                                                                                                                                                                                                                                                                             |
| subscription_renewal_cancelled     | Пользователь отключил автопродление подписки. Доступ к премиум-функциям сохраняется до конца оплаченного периода.                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| subscription_renewal_reactivated   | Срабатывает, когда пользователь повторно включает автопродление подписки.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| subscription_expired               | Срабатывает, когда подписка полностью заканчивается после отмены. Например, если пользователь отменил подписку 12 декабря, но она оставалась активной до 31 декабря — событие фиксируется 31 декабря.                                                                                                                                                                                                                                                                                                                                                    |
| subscription_paused                | Срабатывает, когда пользователь активирует [паузу подписки](https://developer.android.com/google/play/billing/lifecycle/subscriptions#pause) (только Android).                                                                                                                                                                                                                                                                                                                                                                                           |
| subscription_deferred              | Срабатывает, когда покупка подписки [откладывается](https://adapty.io/glossary/subscription-purchase-deferral/): пользователь сохраняет доступ к премиум-функциям, но оплата переносится на более поздний срок. Функция доступна через Google Play Developer API и может использоваться для бесплатных пробных периодов или в поддержку пользователей в сложной финансовой ситуации.                                                                                                                                                                     |
| non_subscription_purchase          | Любая разовая покупка: пожизненный доступ или расходуемая покупка, например внутриигровая валюта.                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| trial_started                      | Срабатывает, когда пользователь активирует пробную подписку.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| trial_active                       | Подтверждает, что пробный период всё ещё активен после события `trial_started`. Вы задаёте количество дней между началом триала и этой проверкой. Событие приходит, если триал ещё идёт. Если триал завершился или конвертировался, либо пользователь отключил автопродление — событие не придёт, и Adapty больше не проверяет.                                                                                                                                                                                                                          |
| trial_converted                    | Срабатывает, когда пробный период заканчивается и с пользователя списывается первая оплата. Например, если триал действует до 14 января, но оплата проходит 7 января — событие фиксируется 7 января.                                                                                                                                                                                                                                                                                                                                                     |
| trial_renewal_cancelled            | Пользователь отключил автопродление во время пробного периода. Доступ к премиум-функциям сохраняется до конца триала, но оплата не спишется и подписка не оформится.                                                                                                                                                                                                                                                                                                                                                                                     |
| trial_renewal_reactivated          | Срабатывает, когда пользователь повторно включает автопродление во время пробного периода.                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| trial_expired                      | Срабатывает, когда пробный период заканчивается без конвертации в подписку.                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| entered_grace_period               | Срабатывает, когда попытка списания оплаты не удаётся и пользователь входит в льготный период (если он включён). В течение этого времени доступ к премиум-функциям сохраняется.                                                                                                                                                                                                                                                                                                                                                                          |
| billing_issue_detected             | Срабатывает при ошибке оплаты во время попытки списания (например, недостаточно средств на карте).                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| subscription_refunded              | Срабатывает при возврате средств за подписку (например, по решению службы поддержки Apple).                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| non_subscription_purchase_refunded | Срабатывает при возврате средств за разовую покупку.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| access_level_updated               | Срабатывает при обновлении уровня доступа пользователя.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
