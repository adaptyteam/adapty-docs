
| Название события                   | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
|:-----------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| subscription_started               | Срабатывает, когда пользователь активирует платную подписку без пробного периода — то есть с немедленным списанием.                                                                                                                                                                                                                                                                                                                                                                                            |
| subscription_active                | Подтверждает, что подписка всё ещё активна после события `subscription_started`. Вы задаёте количество дней между началом подписки и этой проверкой. Событие приходит, если подписка активна, в том числе когда пользователь вошёл в льготный период. Если к моменту проверки подписка завершилась или пользователь отключил автопродление, событие не поступает и Adapty больше не проверяет. Событие относится только к подпискам, оформленным без пробного периода. Конвертация триала отправляет `trial_converted`, которое проверку не запускает. |
| subscription_renewed               | Происходит при продлении подписки и списании средств. Фиксируется начиная со второго платёжного периода — как для подписок с пробным периодом, так и без него.                                                                                                                                                                                                                                                                                                                                                |
| subscription_renewal_cancelled     | Пользователь отключил автопродление подписки. Доступ к премиум-функциям сохраняется до конца оплаченного периода.                                                                                                                                                                                                                                                                                                                                                                                             |
| subscription_renewal_reactivated   | Срабатывает, когда пользователь снова включает автопродление подписки.                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| subscription_expired               | Срабатывает, когда подписка полностью завершается после отмены. Например, если пользователь отменил подписку 12 декабря, но она оставалась активной до 31 декабря, событие фиксируется 31 декабря, когда подписка истекает.                                                                                                                                                                                                                                                                                    |
| subscription_paused                | Происходит, когда пользователь активирует [паузу подписки](https://developer.android.com/google/play/billing/lifecycle/subscriptions#pause) (только Android).                                                                                                                                                                                                                                                                                                                                                 |
| subscription_deferred              | Срабатывает, когда вы бесплатно продлеваете подписку пользователя: через [отсрочку](https://adapty.io/glossary/subscription-purchase-deferral/) по Google Play Developer API или через [продление даты продления](https://developer.apple.com/documentation/appstoreserverapi/extend-a-subscription-renewal-date) по App Store Server API. Доступ к премиум-функциям сохраняется до новой даты продления.                                                                                                      |
| non_subscription_purchase          | Любая разовая покупка: пожизненный доступ или расходуемая покупка, например внутриигровая валюта.                                                                                                                                                                                                                                                                                                                                                                                                             |
| trial_started                      | Срабатывает, когда пользователь активирует пробную подписку.                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| trial_active                       | Подтверждает, что триал всё ещё активен после события `trial_started`. Вы задаёте количество дней между началом триала и этой проверкой. Событие приходит, если триал ещё идёт. Если к моменту проверки триал завершился или конвертировался, либо пользователь отключил автопродление, событие не поступает и Adapty больше не проверяет.                                                                                                                                                                     |
| trial_converted                    | Происходит, когда триал завершается и с пользователя списываются средства (первая оплата). Например, если у пользователя триал до 14 января, но списание происходит 7 января, событие фиксируется 7 января.                                                                                                                                                                                                                                                                                                   |
| trial_renewal_cancelled            | Пользователь отключил автопродление подписки во время пробного периода. Доступ к премиум-функциям сохраняется до конца триала, но списания не будет и подписка не оформится.                                                                                                                                                                                                                                                                                                                                  |
| trial_renewal_reactivated          | Происходит, когда пользователь снова включает автопродление подписки во время пробного периода.                                                                                                                                                                                                                                                                                                                                                                                                               |
| trial_expired                      | Срабатывает, когда триал завершается без конвертации в подписку.                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| entered_grace_period               | Происходит, когда попытка списания не удаётся и пользователь входит в льготный период (если он включён). На это время доступ к премиум-функциям сохраняется.                                                                                                                                                                                                                                                                                                                                                  |
| billing_issue_detected             | Срабатывает при ошибке оплаты во время попытки списания (например, недостаточно средств на карте).                                                                                                                                                                                                                                                                                                                                                                                                            |
| subscription_refunded              | Срабатывает при возврате средств за подписку (например, по запросу в Apple Support).                                                                                                                                                                                                                                                                                                                                                                                                                          |
| non_subscription_purchase_refunded | Срабатывает при возврате средств за разовую покупку.                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| access_level_updated               | Происходит при изменении уровня доступа пользователя.                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
