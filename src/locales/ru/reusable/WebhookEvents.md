
| Название события                   | Описание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
|:-----------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| subscription_started               | Срабатывает, когда пользователь активирует платную подписку без пробного периода — то есть с немедленным списанием.                                                                                                                                                                                                                                                                                                                                                                                                                                |
| subscription_active                | Подтверждает, что подписка всё ещё активна после события `subscription_started`. Вы задаёте количество дней между началом подписки и этой проверкой. Событие приходит, если подписка по-прежнему активна, даже если автопродление уже отменено или пользователь находится в льготном периоде. Если к тому моменту подписка завершилась, событие не приходит и Adapty больше не проверяет. Это событие следует только за подписками, купленными без пробного периода. Конвертация триала отправляет `trial_converted`, который проверку не запускает. |
| subscription_renewed               | Происходит при продлении подписки и списании средств с пользователя. Событие фиксируется начиная со второго платёжного цикла — как для подписок с триалом, так и без.                                                                                                                                                                                                                                                                                                                                                                             |
| subscription_renewal_cancelled     | Пользователь отключил автопродление подписки. Пользователь сохраняет доступ к Premium-функциям до конца оплаченного периода.                                                                                                                                                                                                                                                                                                                                                                                                                       |
| subscription_renewal_reactivated   | Срабатывает, когда пользователь повторно включает автопродление подписки.                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| subscription_expired               | Срабатывает, когда подписка окончательно завершается после отмены. Например, если пользователь отменил подписку 12 декабря, но она оставалась активной до 31 декабря, событие фиксируется 31 декабря, когда подписка истекает.                                                                                                                                                                                                                                                                                                                     |
| subscription_paused                | Происходит, когда пользователь активирует [паузу подписки](https://developer.android.com/google/play/billing/lifecycle/subscriptions#pause) (только Android).                                                                                                                                                                                                                                                                                                                                                                                     |
| subscription_deferred              | Срабатывает, когда покупка подписки [откладывается](https://adapty.io/glossary/subscription-purchase-deferral/), позволяя пользователям перенести оплату, сохранив доступ к Premium-функциям. Функция доступна через Google Play Developer API и может использоваться для бесплатных пробных периодов или для поддержки пользователей, испытывающих финансовые трудности.                                                                                                                                                                          |
| non_subscription_purchase          | Любая покупка без подписки: пожизненный доступ или расходуемые покупки, например внутриигровая валюта.                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| trial_started                      | Срабатывает, когда пользователь активирует пробную подписку.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| trial_active                       | Подтверждает, что триал всё ещё активен после события `trial_started`. Вы задаёте количество дней между началом триала и этой проверкой. Событие приходит, если триал по-прежнему активен, даже если автопродление уже отменено. Если к тому моменту триал завершился или конвертировался, событие не приходит и Adapty больше не проверяет.                                                                                                                                                                                                        |
| trial_converted                    | Происходит, когда пробный период заканчивается и с пользователя списываются средства (первая оплата). Например, если у пользователя триал до 14 января, но списание происходит 7 января, событие фиксируется 7 января.                                                                                                                                                                                                                                                                                                                             |
| trial_renewal_cancelled            | Пользователь отключил автопродление подписки во время пробного периода. Пользователь сохраняет доступ к Premium-функциям до конца триала, но списания не произойдёт и подписка не начнётся.                                                                                                                                                                                                                                                                                                                                                        |
| trial_renewal_reactivated          | Происходит, когда пользователь повторно включает автопродление подписки во время пробного периода.                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| trial_expired                      | Срабатывает, когда пробный период заканчивается без конвертации в подписку.                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| entered_grace_period               | Происходит, когда попытка платежа завершается неудачей и пользователь входит в льготный период (если он включён). В это время пользователь сохраняет Premium-доступ.                                                                                                                                                                                                                                                                                                                                                                              |
| billing_issue_detected             | Срабатывает при возникновении проблемы с оплатой во время попытки списания (например, недостаточно средств на карте).                                                                                                                                                                                                                                                                                                                                                                                                                             |
| subscription_refunded              | Срабатывает при возврате средств за подписку (например, через поддержку Apple).                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| non_subscription_purchase_refunded | Срабатывает при возврате средств за покупку без подписки.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| access_level_updated               | Происходит при обновлении уровня доступа пользователя.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
