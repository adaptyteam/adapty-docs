1. Чтобы найти **Issuer ID** и **Key ID** вашего ключа, в App Store Connect перейдите в [**Users and Access** > **Integrations** > **In-App Purchase**](https://appstoreconnect.apple.com/access/integrations/api/subs). Если кто-то другой сгенерировал ключ и передал вам его Issuer ID, Key ID и файл, пропустите этот шаг.

   <ZoomImage id="asc-in-app-purchase-keys-ids.webp" width="700px" alt="Issuer ID и Key ID ключа In-App Purchase в App Store Connect" />

2. В Adapty перейдите в [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). В разделе **In-app purchase API (StoreKit 2)** заполните поля:
   - **Issuer ID**: скопируйте со страницы **In-App Purchase** в App Store Connect.
   - **Key ID**: скопируйте из списка **Active** на странице **In-App Purchase**, рядом с загруженным ключом.
   - **Private key (.p8 file)**: загрузите скачанный файл.

   <ZoomImage id="app-settings-in-app-purchase-api.webp" width="700px" alt="Поля Issuer ID, Key ID и Private key (.p8 file) в разделе In-app purchase API (StoreKit 2) в Adapty" />

3. Adapty подписывает [promotional offers](offers) с помощью ключа In-App Purchase. В разделе **App Store promotional offers** укажите ключ ещё раз:
   - **Subscription key ID**: Key ID из шага 2.
   - **Subscription key (.p8 file)**: файл из шага 2.

   <ZoomImage id="app-settings-promotional-offers.webp" width="700px" alt="Поля Subscription key ID и Subscription key (.p8 file) в разделе App Store promotional offers" />

   Если указать другой ключ, ошибки не будет, но пользователи не смогут получать promotional offers.

4. Нажмите **Save**. Перед сохранением страницы Adapty проверяет ключ в разделе **In-app purchase API (StoreKit 2)** через Apple. Если Apple отклоняет ключ, страница показывает сообщение «The provided field values are incorrect»: [проверьте введённые значения](troubleshoot-app-store-integration#the-provided-field-values-are-incorrect-when-saving-credentials).
