В флоу пейвола [добавьте кастомный элемент](flow-custom-elements#add-and-configure) на экран и настройте его для графика:

- **Type**: `line_chart`.
- **ID**: `weight_goal`.
- **Height**: Оставьте высоту по умолчанию **Fixed**. График заполнит кастомный элемент.

Не помещайте кастомный элемент в контейнеры, реагирующие на касание, например в карусель, — чтобы только график реагировал на перетаскивание по нему.

Внутри кастомного элемента добавьте [**Image**](custom-media#image) с примером графика веса. Пользователи увидят его как [резервный контент](flow-custom-elements#set-fallback-content), если версия вашего приложения не отображает график.
