Чтобы показывать спиннер, а затем галочку на кнопке, которую нажимают пользователи, добавьте обе кнопки как пользовательские элементы. В кнопке билдера с [пользовательским действием](onboarding-actions#what-custom-actions-cant-do) пользователи не увидят ни спиннера, ни галочки. Пользовательское действие работает в одну сторону: код вашего приложения не может вернуть результат трат во флоу. Текст и внешний вид кнопок задаются кодом вашего приложения. Чтобы изменить текст или внешний вид, [выпустите обновление приложения](flow-custom-elements#what-changes-require-an-app-release).

1. [Добавьте пользовательский элемент](flow-custom-elements#add-and-configure) для пополнения энергии и укажите его **Type** и **ID**:
   - **Type**: `spend_button`.
   - **ID**: `energy_refill`.
2. Добавьте второй пользовательский элемент для безлимитной энергии с тем же Type и ID `unlimited_energy`.

   Код из [шага 2](#connect-the-buttons-to-your-backend) сопоставляет один вид кнопки с обоими пользовательскими элементами по их Type. Код считывает параметр каждой кнопки из её ID.

   <ZoomImage id="vc-top-up-spend-button.webp" width="700px" alt="Настройки пользовательского элемента в Flow & Paywall Builder: в поле Type указано spend_button, в поле ID — unlimited_energy" />

3. Уменьшите **Fixed** высоту каждого пользовательского элемента с 200 до той, которая нужна кнопке.
4. Внутри каждого пользовательского элемента добавьте текстовый элемент и введите описание варианта:
   - Пополнение энергии: «Обновите игру, чтобы пополнить энергию.»
   - Безлимитная энергия: «Обновите игру, чтобы получить безлимитную энергию.»

   В версиях приложения без вида кнопки пользователи увидят этот текст в качестве [резервного контента](flow-custom-elements#set-fallback-content) — без кнопки для нажатия.
