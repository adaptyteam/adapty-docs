Во Flow & Paywall Builder создайте флоу пополнения. Добавьте флоу в [плейсмент](placements) с ID `out_of_diamonds`. Когда баланс оказывается слишком низким для траты, код из шага 4 открывает флоу из этого плейсмента.

Чтобы показывать разные флоу пополнения в зависимости от баланса, добавьте [аудиторию](audience) с [сегментом по балансу виртуальной валюты](segments#virtual-currency-balance) в плейсмент `out_of_diamonds`. Например, покажите отдельный флоу пользователям с 0 алмазами. Adapty считывает баланс каждый раз, когда ваш код приложения запрашивает флоу, — таким образом, трата или покупка может изменить флоу, который пользователь увидит в следующий раз.

Чтобы отобразить баланс алмазов и в этом флоу, [добавьте пользовательский элемент](flow-custom-elements#add-and-configure) с теми же Type и ID, что и во флоу нехватки энергии: `currency_balance` и `diamonds`. Внутри пользовательского элемента добавьте **Icon** алмаза в качестве запасного варианта. Игроки увидят одинаковое отображение баланса в обоих флоу, и добавлять для этого дополнительный код не нужно.
