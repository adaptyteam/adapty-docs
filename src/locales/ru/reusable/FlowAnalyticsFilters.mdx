Страница метрик флоу охватывает просмотры, завершения, конверсию и доход. Такие метрики, как MRR, активные подписки, отток, льготный период и проблемы с оплатой, доступны только на странице [Графики](charts). Чтобы просматривать их для конкретного флоу, отфильтруйте метрики по **Flow** или **Flow screen**:

- **Flow**: Один флоу со всеми его экранами в совокупности.
- **Flow screen**: Один экран флоу. Экраны вложены в свой флоу и используют следующее соглашение об именовании: `<position>. <screen name>`, например `9. Paywall A`.

Чтобы сравнивать флоу или экраны рядом на одном графике, группируйте по тем же атрибутам вместо фильтрации.

В списке фильтров отображаются только флоу и экраны, по которым есть хотя бы одна транзакция.
:::
