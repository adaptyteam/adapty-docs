Страница метрик флоу охватывает просмотры, завершения, конверсию и выручку. Такие метрики, как MRR, активные подписки, отток, льготный период и проблемы с оплатой, доступны только на странице [Графики](charts). Чтобы просмотреть их для конкретного флоу, отфильтруйте эти метрики по **Flow** или **Flow screen**:

- **Flow**: Один флоу со всеми его экранами, учтёнными вместе.
- **Flow screen**: Один экран флоу. Экраны вложены в свой флоу и используют следующее соглашение об именовании: `<position>. <screen name>`, например `9. Paywall A`.

Чтобы сравнить флоу или экраны рядом на одном графике, используйте группировку по тем же атрибутам вместо фильтрации.

В списке фильтров отображаются только флоу и экраны, по которым есть хотя бы одна транзакция.
:::
