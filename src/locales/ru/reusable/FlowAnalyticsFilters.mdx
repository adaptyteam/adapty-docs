На странице метрик флоу отображаются просмотры, завершения, конверсия и выручка. Такие метрики, как MRR, активные подписки, отток, льготный период и проблемы с оплатой, доступны только на странице [Графики](charts). Чтобы увидеть их для конкретного флоу, отфильтруйте эти метрики по **Flow** или **Flow screen**:

- **Flow**: Один флоу со всеми его экранами, учитываемыми вместе.
- **Flow screen**: Один экран флоу. Экраны вложены в свой флоу и именуются по следующему соглашению: `<position>. <screen name>`, например `9. Paywall A`.

Чтобы сравнить флоу или экраны рядом на одном графике, используйте группировку по тем же атрибутам вместо фильтрации.

:::important
В списке фильтра отображаются только флоу и экраны, по которым есть хотя бы одна транзакция.
:::
