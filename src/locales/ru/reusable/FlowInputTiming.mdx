:::important
Поля, выборщики даты и времени, а также группы выбора никогда не отправляют своё значение по умолчанию через этот коллбэк. Если пользователь принимает вариант, помеченный **Set as default**, и переходит дальше, событие не срабатывает. Не интерпретируйте отсутствие события как «нет ответа» — пользователь просто оставил значение по умолчанию. [Number picker](builder-number-picker) отправляет своё значение по умолчанию в код приложения, когда пользователь нажимает кнопку, открывающую другой экран.
:::

**Это событие вызывают следующие элементы:**

- Текстовые, email-, числовые и телефонные поля
- Выборщики даты, времени и даты-времени
- Number picker'ы
- Группы единственного и множественного выбора, а также переключатели

**Следующие элементы его не вызывают:**

- Поля для ввода пароля, выбора продукта и переключатели вкладок
- Поля внутри элемента Header, который используется на всех экранах
- Группы выбора с дублирующимися или отсутствующими идентификаторами элементов, а также с Group ID, повторно использованным на другом экране. Такая группа не отправляет ничего, а не часть ответа.

**Событие срабатывает когда:**

- Поле теряет фокус. Очищенное поле передаёт пустую строку; поле, которое пользователь не редактировал, не передаёт ничего. Плейсхолдер значением не является. Если пользователь вернулся к полю, отредактировал его и снова покинул, происходит второе событие.
- Пользователь закрывает выборщик даты или времени после выбора нового значения. Закрытие без изменений ничего не передаёт.
- На экране с Number picker'ом пользователь нажимает кнопку, выполняющую действие **Navigate to Screen**, **Navigate Next** или **Navigate back** [action](onboarding-actions). Number picker также передаёт своё значение, когда пользователь выбирает вариант или переключает тумблер на том же экране. Если пользователь не крутил колесо, значением является число по умолчанию. Number picker передаёт значение даже когда он скрыт — например, во вкладке, которую пользователь не открывал. Второго события не будет, пока значение не изменится.
- Пользователь выбирает вариант или переключает тумблер. Событие множественного выбора перечисляет все выбранные варианты, поэтому снятие отметки с последнего отправляет два пустых массива.

**Событие не срабатывает когда:**

- Пользователь печатает. Потока нажатий клавиш нет — передаётся только значение, которое поле содержит в момент потери фокуса.
- Пользователь отправляет данные или закрывает флоу. Значение, которое редактируется в этот момент, может быть утеряно. Кнопка, закрывающая флоу, запускающая покупку или выполняющая пользовательское действие, не передаёт значение Number picker'а. Раздел [ограничения доставки](#delivery-and-limitations) объясняет, как правильно оформить последний экран с учётом обоих случаев.
- Значение устанавливается без участия пользователя. Вариант, помеченный **Set as default**, выбирается заранее при открытии экрана, а действие **Set Variable** может выбрать вариант или заполнить поле из другого взаимодействия. Ни то ни другое не отправляет событие; заранее заполненное поле (кроме Number picker'а) передаётся только после того, как пользователь его отредактирует.
