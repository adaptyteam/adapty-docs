1. [Создайте два флоу](paywall-builder-templates): онбординг-флоу, который собирает вес и рост пользователя, и флоу пейвола, который показывает его ИМТ.
2. Добавьте два поля [**Number**](builder-inputs-and-forms) в онбординг-флоу:
   - Одно для веса в килограммах с **Element ID** `weight`.
   - Одно для роста в сантиметрах с **Element ID** `height`.

   Для обоих полей установите **Format** в значение **Integer**. Поле передаёт значение как текст, точно так, как его ввёл пользователь, а [пример кода](#pass-the-bmi-to-the-paywall) по-разному читает «70.5» и «70,5». Целые числа не имеют десятичного разделителя, поэтому код читает их одинаково в любой локали.

   Если вместо поля **Number** вы добавите [Number picker](builder-number-picker), код приложения получит `value` как числовой тип, а не строку. В примере кода читайте `value` как числовой тип, допускающий десятичные значения.
3. Чтобы убедиться, что приложение получает оба значения, завершите онбординг-флоу экраном без полей ввода. На этом экране добавьте кнопку с действием [**Close flow**](onboarding-actions#close-flow). Поля ввода отправляют значения при потере фокуса или при переходе пользователя на другой экран. Действие Close flow не отправляет их. Пример кода открывает пейвол только в том случае, если пользователь дошёл до последнего экрана.
4. В флоу пейвола [создайте кастомный тег](flow-custom-tags#create-a-custom-tag) с именем `bmi`. В поле **Initial value** введите тире (`—`). Пользователи увидят тире, если приложение не передаст ИМТ.
5. Добавьте текстовый элемент со словами «Your BMI:» во флоу пейвола. После этих слов [вставьте кастомный тег `bmi`](flow-custom-tags#add-a-custom-tag-to-a-text-element).
6. Добавьте онбординг-флоу в [плейсмент](placements), например `onboarding`. Добавьте флоу пейвола в плейсмент с ID `bmi_paywall`. Код из раздела [Pass the BMI to the paywall](#pass-the-bmi-to-the-paywall) загружает пейвол по этому ID.
