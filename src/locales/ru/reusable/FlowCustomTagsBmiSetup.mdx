1. [Создайте два флоу](paywall-builder-templates): флоу онбординга, который собирает вес и рост пользователя, и флоу пейвола, который показывает его ИМТ.
2. Добавьте два поля [**Number**](builder-inputs-and-forms) во флоу онбординга:
   - Одно для веса в килограммах с **Element ID** `weight`.
   - Одно для роста в сантиметрах с **Element ID** `height`.

   Для обоих полей установите **Format** в значение **Integer**. [Пример кода](#pass-the-bmi-to-the-paywall) работает с целыми числами. Поле передаёт ровно то, что ввёл пользователь, а код не воспринимает «70.5» и «70,5» одинаково.
3. Чтобы убедиться, что приложение получает оба значения, завершите флоу онбординга экраном без полей ввода. На этом экране добавьте кнопку с действием [**Close flow**](onboarding-actions#close-flow). Поля ввода отправляют значения при потере фокуса или при переходе на другой экран. Действие Close flow не отправляет их. Пример кода открывает пейвол только если пользователь дошёл до последнего экрана.
4. Во флоу пейвола [создайте кастомный тег](flow-custom-tags#create-a-custom-tag) с именем `bmi`. В поле **Initial value** введите тире (`—`). Пользователи увидят тире, если приложение не передаст ИМТ.
5. Добавьте текстовый элемент со словами «Your BMI:» во флоу пейвола. После этих слов [вставьте кастомный тег `bmi`](flow-custom-tags#add-a-custom-tag-to-a-text-element).
6. Добавьте флоу онбординга в [плейсмент](placements), например `onboarding`. Добавьте флоу пейвола в плейсмент с ID `bmi_paywall`. Код из раздела [Pass the BMI to the paywall](#pass-the-bmi-to-the-paywall) получает пейвол по этому ID.
