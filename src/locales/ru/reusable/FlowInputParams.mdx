Коллбэк доставляет два типа событий. Фильтруйте по `name`, чтобы отображать только события `flow_user_input`. JSON-полезная нагрузка ответа выглядит так:

```json
{
  "name": "flow_user_input",
  "instanceId": "scr_registration",
  "isBackendEvent": false,
  "isCustomerEvent": true,
  "element_id": "email",
  "element_type": "email_input",
  "value": "jane@example.com"
}
```

| Параметр          | Описание |
|:------------------|:------------|
| `name`            | `flow_user_input` для событий ввода, `flow_screen_showed` для просмотров экранов. |
| `instanceId`      | ID экрана элемента ввода. Element ID уникальны в пределах одного экрана, но не всего флоу. Если во флоу есть поля ввода на нескольких экранах, комбинируйте `instanceId` с `element_id` при фильтрации событий. |
| `element_id`      | **Element ID** [поля ввода](builder-inputs-and-forms) или **Group ID** [группы выбора](flow-selectable-elements). |
| `element_type`    | Тип элемента, отправившего событие. Определяет, какой из параметров ниже содержит значение ввода. |
| `value`           | **Только для текстовых полей, пикеров и переключателей.** Введённое значение: строка для текстовых полей, целое число для пикеров даты и времени, число с возможными десятичными знаками для числовых пикеров, булево значение для переключателей. |
| `item_ids`        | **Только для групп одиночного и множественного выбора.** **Element ID** выбранных опций в порядке их отображения в билдере. Один элемент для группы одиночного выбора; любое количество для множественного выбора. |
| `item_titles`     | **Только для групп одиночного и множественного выбора.** Заголовки опций, перечисленных в `item_ids`, в том же порядке. Никогда не бывает пустым: если у опции нет заголовка, вместо него подставляется её ID. |
| `isCustomerEvent` | Вспомогательный флаг, всегда `true` для этого события. Помечает события, которые SDK доставляет в ваш коллбэк. Удобен, если один обработчик пересылает все события флоу в вашу аналитику и вы фильтруете по флагу, а не по `name`. |
| `isBackendEvent`  | Вспомогательный флаг, всегда `false` для этого события. Помечает события, которые Adapty также записывает для собственной аналитики. Значение `false` подтверждает, что данные, введённые пользователями, поступают только в ваше приложение — Adapty их не получает и не хранит. |

Что сообщает каждый элемент:

| В билдере | `element_type` | Параметр, хранящий значение | Что содержит |
|:---------------|:---------------|:----------------------------|:--------------|
| Поле ввода **Text**, **Number**, **Phone number** | `text_input`, `number_input`, `phone_input` | `value` | Необработанная строка, введённая пользователем. Числа передаются как строки, а не как числовые типы. |
| Поле ввода **E-mail** | `email_input` | `value` | Необработанная строка, введённая пользователем, даже если она не прошла валидацию формата в билдере. Проверяйте её на своей стороне перед использованием. |
| Поле ввода **Password** | нет | нет | Событие не отправляет. |
| Поле ввода **Date** | `date_picker` | `value` | Unix-время в миллисекундах, целое число, соответствующее полуночи по местному времени выбранной даты. |
| Поле ввода **Time** | `time_picker` | `value` | Unix-время в миллисекундах, целое число, округлённое вниз до минуты. |
| Поле ввода **Date & Time** | `date_picker` и `time_picker` | `value` | Два элемента: пикер даты и пикер времени. Каждый отправляет собственное событие. |
| Поле ввода, переключённое в режим **Date & Time** в выпадающем списке **Type** | `date_time_picker` | `value` | Unix-время в миллисекундах, целое число, округлённое вниз до минуты. |
| **Number picker** | `wheel_range_picker` | `value` | Число, выбранное пользователем, или значение по умолчанию, если колесо не прокручивалось. Может иметь десятичные знаки, например `70.5`. В отличие от значения поля **Number**, передаётся как числовой тип, а не строка. |
| Группа **Single choice** | `single_choice` | `item_ids`, `item_titles` | Два массива. `item_ids`: массив с Element ID выбранной опции. `item_titles`: массив с заголовком этой опции. |
| Группа **Multi-choice** | `multi_choice` | `item_ids`, `item_titles` | Два массива. `item_ids`: Element ID всех выбранных опций в порядке их отображения в билдере. `item_titles`: их заголовки в том же порядке. Оба массива пустые, если ничего не выбрано. |
| Группа **Toggle** | `toggle` | `value` | Булево значение. |

Для ветвления по ответу сравнивайте `item_ids`, а не `item_titles`. Заголовок является производным: это **Element Title** опции (если задан), затем её текст в основной локали, затем её Element ID. Пользователь, просматривавший флоу на другом языке, видел другой текст.
