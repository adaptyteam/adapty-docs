Чтобы отображать значения из вашего приложения во флоу, настройте кастомные теги в билдере:

1. [Создайте кастомный тег](flow-custom-tags#create-a-custom-tag) для каждого значения, которое передаёт ваше приложение.

   <ZoomImage id="flow-custom-tag-create.webp" width="500px" alt="Форма создания переменной с именем, описанием, типом значения String и начальным значением" />

2. [Вставьте каждый тег в текстовый элемент](flow-custom-tags#add-a-custom-tag-to-a-text-element).
3. Запишите полное имя каждого тега, включая его группу. Именно под этим именем код вашего приложения передаёт каждое значение. Например, если группа `user` содержит тег `streak`, полное имя тега — `user.streak`.

   <ZoomImage id="flow-custom-tag-full-name.webp" width="500px" alt="Вкладка Custom в выпадающем списке Add variable с тегом streak в группе user" />
