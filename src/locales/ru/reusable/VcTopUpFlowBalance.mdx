Чтобы отобразить баланс алмазов, используйте [пользовательский элемент](flow-custom-elements) — элемент, в котором пользователи видят нативный вид из кода вашего приложения. Когда код приложения изменяет баланс во время открытого флоу (например, после траты), пользователи сразу видят новый баланс.

1. [Добавьте пользовательский элемент](flow-custom-elements#add-and-configure) на экран и задайте его **Type** и **ID**:
   - **Type**: `currency_balance`.
   - **ID**: `diamonds`.

   Код из [шага 2](#create-the-balance-view) связывает представление баланса с пользовательским элементом по этим Type и ID.

   <ZoomImage id="vc-top-up-custom-element.webp" width="700px" alt="Custom element settings in the Flow & Paywall Builder, with currency_balance in the Type field, diamonds in the ID field, and an Icon inside the Diamond balance layer" />

2. Внутри пользовательского элемента добавьте [**Icon**](custom-media#icon) алмаза. В версиях приложения без представления баланса пользователи увидят иконку в качестве [резервного содержимого](flow-custom-elements#set-fallback-content).
