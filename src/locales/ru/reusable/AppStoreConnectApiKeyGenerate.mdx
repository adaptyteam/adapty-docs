1. В App Store Connect перейдите в [**Users and Access** > **Integrations** > **App Store Connect API**](https://appstoreconnect.apple.com/access/integrations/api) и откройте вкладку **Team Keys**. Adapty требует командный ключ: у индивидуальных ключей нет Issuer ID.

   Один командный ключ подходит для всех приложений вашей команды App Store Connect. Если на этой вкладке уже есть активный ключ с доступом **Admin** и у вас есть его файл, используйте его повторно и пропустите шаги 2–4.

   Если у вашей команды ещё нет доступа к App Store Connect API, Account Holder должен [запросить его](https://developer.apple.com/help/app-store-connect/get-started/app-store-connect-api). Apple рассматривает каждый запрос отдельно.

2. Для создания ключа вам нужна роль Account Holder или Admin в App Store Connect. Если у вас нет ни той ни другой, попросите человека с нужной ролью сгенерировать ключ с доступом **Admin** и передать вам файл вместе с Issuer ID и Key ID.

   Если на вкладке уже есть активные ключи, нажмите **+**. В противном случае нажмите **Generate API Key**.

   <ZoomImage id="asc-team-keys-add.webp" width="700px" alt="Team Keys tab of the App Store Connect API page in App Store Connect" />

3. Введите название ключа и установите **Access** на **Admin**. Параметр **Access** определяет, что Adapty сможет делать с этим ключом, независимо от вашей собственной роли. Изменить **Access** после создания ключа невозможно. Нажмите **Generate**.

   <ZoomImage id="asc-team-key-generate-dialog.webp" width="700px" alt="Dialog for a new team key, with a name and the Access dropdown" />

4. Каждый ключ можно скачать только один раз. Рядом с новым ключом нажмите **Download**. Храните файл в безопасном месте: вы будете загружать его в каждое приложение Adapty, которое использует этот ключ.

   <ZoomImage id="asc-team-key-download.webp" width="700px" alt="Active list of team keys, with the Download link next to a new key" />
