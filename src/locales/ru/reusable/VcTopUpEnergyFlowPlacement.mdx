В Flow & Paywall Builder создайте флоу выхода из энергии. Добавьте флоу в [плейсмент](placements) с ID `out_of_energy`. Когда у игрока заканчивается энергия, код из шага 2 открывает флоу из этого плейсмента.

Чтобы игрок мог закрыть флоу без траты, добавьте [кнопку **Close**](basic-paywall-screen#3-add-the-close-button).
