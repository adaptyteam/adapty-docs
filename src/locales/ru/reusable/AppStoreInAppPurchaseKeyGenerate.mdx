1. В App Store Connect перейдите в [**Users and Access** > **Integrations** > **In-App Purchase**](https://appstoreconnect.apple.com/access/integrations/api/subs).

   Один ключ работает для всех приложений вашей команды в App Store Connect. Чтобы повторно использовать активный ключ с этой страницы, вам понадобится его файл. Если он у вас есть, пропустите шаги 2–4. Активные ключи продолжают работать при создании нового.

2. Для генерации ключа вам нужна роль Account Holder или Admin в App Store Connect. Если у вас нет ни одной из этих ролей, попросите того, у кого она есть, сгенерировать ключ и прислать вам файл с Issuer ID и Key ID.

   Если на странице уже есть активные ключи, нажмите **+**. В противном случае нажмите **Generate In-App Purchase Key**.

   <ZoomImage id="asc-in-app-purchase-keys-add.webp" width="700px" alt="In-App Purchase keys page in App Store Connect, with the button that adds a key" />

3. Введите название ключа и нажмите **Generate**. Ключ появится в списке **Active**.

   <ZoomImage id="asc-in-app-purchase-key-name.webp" width="700px" alt="Generate In-App Purchase Key dialog with a name for the key and the Generate button" />

4. Каждый ключ можно скачать только один раз. Рядом с новым ключом нажмите **Download In-App Purchase Key**.

   <ZoomImage id="asc-in-app-purchase-key-download-link.webp" width="700px" alt="Active list of In-App Purchase keys, with the download link next to a new key" />

   Затем в диалоговом окне нажмите **Download**. Храните файл в надёжном месте: вы будете загружать его в каждое приложение Adapty, которое использует этот ключ.

   <ZoomImage id="asc-in-app-purchase-key-download-dialog.webp" width="700px" alt="Download dialog for an In-App Purchase key" />
