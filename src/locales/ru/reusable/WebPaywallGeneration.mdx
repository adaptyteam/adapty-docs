В поле **URL** найдите ссылку **generate one with AI** и нажмите на неё.

Разверните панель **Generation setup** и выполните шесть шагов по порядку. Каждая кнопка открывает страницу, где выполняется этот шаг, — после возврата нажмите **Refresh**.

<ZoomImage id="mail-checkout-prerequisites.webp" width="500px" alt="Чеклист Generation setup на странице создания Web Paywall" />

| Пункт чеклиста | Что нужно сделать |
| --- | --- |
| **1. Brand is ready** | Уже отмечен, если вы настроили [бренд](mail-brand). Если нет — нажмите **Set up brand**. |
| **2. Log in to the paywall builder dashboard** | Нажмите **Log in**, чтобы авторизоваться в билдере. |
| **3. Stripe account connected** | Нажмите **Connect Stripe** и подключите аккаунт. |
| **4. At least one Stripe product with a price** | Нажмите **Open Stripe dashboard** и добавьте продукт с ценой. |
| **5. Generate the paywall** | 5.1. Нажмите **Generate**.<br />5.2. Выберите до трёх планов. Для каждого последующего нажмите **Add plan**.<br />5.3. Укажите для каждого плана производственную цену, цену для песочницы или обе — в одной валюте. Заполняйте один и тот же столбец для всех планов: незаполненный столбец заблокирует генерацию. Без цен для песочницы [тестовые письма](mail-testing) будут вести на производственный пейвол, где тестовые покупки не работают.<br />5.4. Нажмите **Generate paywall**. Это займёт несколько минут; поле **URL** заполнится автоматически по завершении. |
| **6. Review and publish the paywall in the builder** | Нажмите **Open editor**, проверьте и опубликуйте пейвол. Кнопка недоступна до тех пор, пока пейвол не сгенерирован. |

<ZoomImage id="mail-checkout-generation-dialog.webp" width="500px" alt="Диалог генерации пейвола со столбцами производственных цен и цен для песочницы" />

<Callout type="important">
Пейвол должен быть опубликован, прежде чем он сможет обрабатывать трафик оформления заказов. Неопубликованные пейволы возвращают ошибку, когда пользователи переходят по ссылкам оформления заказа из писем.
</Callout>

После публикации пейвола нажмите **Save**.
