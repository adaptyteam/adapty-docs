Для установки плагина выполните в терминале команду:

```bash
npx adapty skills install
```

Перезапустите агент, чтобы загрузить скиллы. Другие способы установки описаны в [README плагина](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Claude Code не обновляет плагин автоматически. Чтобы получать новые скиллы по мере их выхода, запустите в Claude Code команду `/plugin`, откройте **Marketplaces**, выберите `adapty` и нажмите **Enable auto-update**. Команду обновления для других агентов см. в [README плагина](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).
