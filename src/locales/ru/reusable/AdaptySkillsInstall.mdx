Если вы уже установили плагин Adapty, этот скилл у вас есть. Если агент его не отображает, обновите плагин командой для вашего агента из [README плагина](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Чтобы установить плагин в агент для разработки, выполните в терминале:

```bash
npx adapty skills install
```

Перезапустите агента, чтобы плагин загрузился. Чтобы установить плагин в claude.ai или Claude desktop, см. [Установка плагина](manage-adapty-with-ai#install-the-plugin). Другие способы установки описаны в [README плагина](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Claude Code не обновляет плагин автоматически. Чтобы получать новые скиллы по мере их выхода, в Claude Code выполните `/plugin`, откройте **Marketplaces**, выберите `adapty` и нажмите **Enable auto-update**. Команду обновления для других агентов можно найти в [README плагина](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).
