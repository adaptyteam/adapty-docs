[Плагин Apple Ads](https://github.com/adaptyteam/apple-ads-cli) обучает ваш AI-инструмент для разработки управлять Apple Ads через команды `adapty asa`. В нём три скилла:

- **`apple-ads`**: Оператор. Читает показатели эффективности, изменяет ставки и бюджеты, добавляет ключевые слова и минус-слова, собирает поисковые запросы, запускает и приостанавливает кампании — с подтверждением перед любым действием, требующим трат.
- **`apple-ads-audit`**: Аудитор только для чтения. Проверяет состояние аккаунта, статус показов, структуру, охват трафика и дублирующиеся ключевые слова с точным совпадением — без записи.
- **`apple-ads-strategy`**: Планировщик, которому не нужны аккаунт, CLI или подписка. Превращает описание вашего приложения в структуру аккаунта, таксономию ключевых слов, стартовые бюджеты и список минус-слов.

**Поддерживаемые инструменты**: Claude Code, Claude Cowork, GitHub Copilot CLI, OpenAI Codex, Gemini CLI и любой другой инструмент с поддержкой скиллов.

Оператор и аудитор работают через Adapty CLI — сначала установите и авторизуйте его, см. [руководство по быстрому старту](developer-cli-quickstart). Команды `adapty asa` появились в **Adapty CLI 0.4.0 и новее**; в более старых версиях их нет. Проверьте командой `adapty asa whoami` — она также покажет, подключён ли аккаунт Apple Ads и есть ли у компании активная подписка Ads Manager. Скилл стратегии работает без всего этого.

Claude Cowork запускает CLI в песочнице, которая блокирует все домены за пределами списка разрешённых. Перед установкой плагина разрешите домены Adapty — см. [Настройка Adapty CLI в Claude Cowork](developer-cli-cowork). Задача в Cowork также запускается на чистой машине, поэтому CLI и данные авторизации не сохраняются между сессиями — скилл `adapty-cli-setup` устанавливает и авторизует CLI заново в начале каждой сессии.

Для установки выберите вариант для вашего инструмента. Полный список — в [README плагина](https://github.com/adaptyteam/apple-ads-cli).

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/apple-ads-cli
claude plugin install apple-ads@adapty
```

**OpenAI Codex**

```bash
codex plugin marketplace add adaptyteam/apple-ads-cli
codex plugin add apple-ads@adapty
```

Оба варианта установки добавляют команды `/asa-*` вместе со скиллами — готовые промпты для типовых задач, например `/asa-review` для еженедельной проверки и `/asa-harvest` для превращения поисковых запросов в ключевые и минус-слова. Claude Code показывает их как слэш-команды; Codex загружает как скиллы, которые вызываются по имени.

**Любой другой инструмент** — используйте [skills CLI](https://skills.sh) (обратите внимание: скиллы, установленные таким образом, не обновляются автоматически):

```bash
npx skills add adaptyteam/apple-ads-cli --all
```

`--all` устанавливает все три скилла во все обнаруженные агенты. Для установки одного скилла используйте `--skill`, например `--skill apple-ads-strategy`.

После установки запустите скилл в своём проекте — напрямую или через одну из слэш-команд:

```bash
/apple-ads
```

Чтение метрик и пробные запуски ничего не стоят. Любая другая команда обращается к Apple в течение секунд, тратит реальные деньги и не может быть отменена — скиллы запрашивают подтверждение перед каждой такой командой, и вам стоит делать то же самое.
