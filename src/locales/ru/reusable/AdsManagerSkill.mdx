[Плагин Apple Ads](https://github.com/adaptyteam/apple-ads-cli) обучает ваш AI-инструмент работе с Apple Ads через команды `adapty asa`. В него входят три скилла:

- **`apple-ads`**: Оператор. Читает показатели эффективности, изменяет ставки и бюджеты, добавляет ключевые слова и минус-слова, собирает поисковые запросы, запускает и останавливает кампании — с подтверждением перед любым действием, которое тратит деньги.
- **`apple-ads-audit`**: Аудитор только для чтения. Проверяет состояние аккаунта, статус показа, структуру, охват трафика и дублирующиеся ключевые слова с точным соответствием — и ничего не записывает.
- **`apple-ads-strategy`**: Планировщик, которому не нужен ни аккаунт, ни CLI, ни подписка. Превращает описание вашего приложения в структуру аккаунта, таксономию ключевых слов, стартовые бюджеты и список минус-слов.

**Поддерживаемые инструменты**: Claude Code, приложение Claude (ранее Claude Cowork), GitHub Copilot CLI, OpenAI Codex, Gemini CLI и любой другой инструмент с поддержкой скиллов.

Оператор и аудитор работают через Adapty CLI, поэтому сначала установите и аутентифицируйте CLI — см. [гайд по быстрому старту](developer-cli-quickstart). Команды `adapty asa` появились в **Adapty CLI версии 0.4.0 и новее**; в более ранних версиях их нет вообще. Проверьте с помощью `adapty asa whoami` — эта команда также покажет, подключён ли аккаунт Apple Ads и есть ли у компании активная подписка на Ads Manager. Скилл strategy работает без всего этого.

Приложение Claude запускает CLI в песочнице, которая блокирует все домены, кроме внесённых в белый список. Добавьте домены Adapty в список разрешённых, прежде чем устанавливать плагин — см. [Настройка Adapty CLI в приложении Claude](developer-cli-cowork). Каждый разговор в приложении Claude также начинается на чистой машине, поэтому CLI и данные авторизации не сохраняются между разговорами — скилл `adapty-cli-setup` плагина устанавливает и аутентифицирует CLI заново в начале каждого из них.

Для установки выберите способ для вашего инструмента. Полный список — в [README плагина](https://github.com/adaptyteam/apple-ads-cli).

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/apple-ads-cli
claude plugin install apple-ads@adapty
```

**OpenAI Codex**

```bash
codex plugin marketplace add adaptyteam/apple-ads-cli
codex plugin add apple-ads@adapty
```

Оба способа установки плагина включают команды `/asa-*` вместе со скиллами — готовые промпты для типичных задач, например `/asa-review` для еженедельной проверки и `/asa-harvest` для превращения поисковых запросов в ключевые слова и минус-слова. В Claude Code они доступны как слэш-команды; в Codex загружаются как скиллы, которые вызываются по имени.

**Любой другой инструмент** — используйте [skills CLI](https://skills.sh) (обратите внимание, что скиллы, установленные таким способом, не обновляются автоматически):

```bash
npx skills add adaptyteam/apple-ads-cli --all
```

`--all` устанавливает все три скилла во все обнаруженные агенты. Для установки одного скилла используйте `--skill`, например `--skill apple-ads-strategy`.

После установки запустите скилл в своём проекте — напрямую или через одну из слэш-команд:

```bash
/apple-ads
```

Просмотр метрик и пробные запуски ничего не стоят. Все остальные команды за секунды достигают Apple, тратят реальные деньги и не могут быть отменены — скиллы запрашивают подтверждение перед каждой такой командой, и вам стоит делать то же самое.
