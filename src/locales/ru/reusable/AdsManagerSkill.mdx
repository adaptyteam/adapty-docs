[Навык ads-manager](https://github.com/adaptyteam/adapty-sdk-integration-skill) учит ваш AI-инструмент для разработки управлять Apple Ads через команды `adapty asa`. Он знает порядок составления команд, что нужно прочитать перед записью и какие вызовы тратят деньги.

**Поддерживаемые инструменты**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Навык управляет Adapty CLI, поэтому сначала установите и аутентифицируйте CLI — см. [руководство по быстрому старту](developer-cli-quickstart). Команды `adapty asa` входят в **Adapty CLI 0.4.0 и новее**; в более старых версиях они отсутствуют. Проверьте с помощью `adapty asa whoami` — эта команда также покажет, подключён ли аккаунт Apple Ads и есть ли у компании активная подписка Ads Manager.

Claude Cowork запускает CLI в песочнице, блокирующей все домены за пределами белого списка. Разрешите домены Adapty до установки навыска — см. [Запуск CLI в Cowork](developer-cli-quickstart#run-the-cli-in-cowork).

Для установки выберите вариант для своего инструмента. Полный список — в [README навыка](https://github.com/adaptyteam/adapty-sdk-integration-skill).

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

Этот плагин также содержит навык интеграции SDK. Оба устанавливаются вместе.

**GitHub Copilot CLI**

```bash
git clone https://github.com/adaptyteam/adapty-sdk-integration-skill.git
cp -r adapty-sdk-integration-skill/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```bash
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex или любой другой инструмент** — используйте [skills CLI](https://skills.sh) (обратите внимание, что навыки, установленные таким способом, не обновляются автоматически):

```bash
npx skills add adaptyteam/adapty-sdk-integration-skill --all
```

`--all` устанавливает оба навыка во все обнаруженные агенты. Для установки только этого навыка используйте `--skill ads-manager`.

Как вариант, клонируйте репозиторий и скопируйте директории из `skills/` в директорию навыков вашего инструмента — или только `skills/ads-manager/`, если нужен только этот навык.

После установки запустите навык в своём проекте:

```bash
/ads-manager
```

Чтение метрик и пробные запуски ничего не стоят. Каждая другая команда обращается к Apple в течение нескольких секунд, тратит реальные деньги и не может быть отменена — навык спрашивает подтверждение перед каждой такой командой, и вам стоит делать то же самое.
