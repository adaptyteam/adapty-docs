[Плагин Apple Ads](https://github.com/adaptyteam/apple-ads-cli) обучает ваш AI-инструмент для работы с кодом управлять Apple Ads через команды `adapty asa`. В него входят три скилла:

- **`apple-ads`**: Оператор. Читает данные о производительности, изменяет ставки и бюджеты, добавляет ключевые слова и минус-слова, собирает поисковые запросы, запускает и приостанавливает кампании — с подтверждением перед любым действием, требующим бюджета.
- **`apple-ads-audit`**: Аудитор только для чтения. Проверяет состояние аккаунта, статус показа, структуру, охват трафика и дублирующиеся ключевые слова с точным соответствием — без каких-либо записей.
- **`apple-ads-strategy`**: Планировщик, которому не нужны аккаунт, CLI или подписка. Превращает описание вашего приложения в структуру аккаунта, таксономию ключевых слов, начальные бюджеты и список минус-слов.

**Поддерживаемые инструменты**: Claude Code, Claude Cowork, GitHub Copilot CLI, OpenAI Codex, Gemini CLI и любые другие инструменты с поддержкой скиллов.

Оператор и аудитор работают через Adapty CLI, поэтому сначала установите и авторизуйте CLI — см. [гайд по быстрому старту](developer-cli-quickstart). Команды `adapty asa` появились в **Adapty CLI 0.4.0 и новее**; в более старых версиях они отсутствуют. Проверьте командой `adapty asa whoami` — она также покажет, подключён ли аккаунт Apple Ads и есть ли у компании активная подписка Ads Manager. Скилл стратегии работает без всего этого.

Claude Cowork запускает CLI в песочнице, которая блокирует все домены вне белого списка. Добавьте домены Adapty в разрешённые перед установкой плагина — см. [Настройка Adapty CLI в Claude Cowork](developer-cli-cowork). Задача в Cowork также запускается на чистой машине, поэтому CLI и авторизация не сохраняются между сессиями — скилл `adapty-cli-setup` плагина устанавливает и авторизует CLI заново в начале каждой сессии.

Для установки выберите вариант для вашего инструмента. Полный список — в [README плагина](https://github.com/adaptyteam/apple-ads-cli).

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/apple-ads-cli
claude plugin install apple-ads@adapty
```

Помимо скиллов, плагин Claude Code устанавливает slash-команды `/asa-*` — готовые промпты для распространённых задач, например `/asa-review` для еженедельной проверки и `/asa-harvest` для преобразования поисковых запросов в ключевые слова и минус-слова.

**Любой другой инструмент** — используйте [skills CLI](https://skills.sh) (обратите внимание, что скиллы, установленные таким способом, не обновляются автоматически):

```bash
npx skills add adaptyteam/apple-ads-cli --all
```

`--all` устанавливает все три скилла во все обнаруженные агенты. Для установки одного скилла используйте `--skill`, например `--skill apple-ads-strategy`.

После установки запустите скилл в своём проекте — напрямую или через одну из slash-команд:

```bash
/apple-ads
```

Чтение метрик и пробные запуски ничего не стоят. Каждая другая команда обращается к Apple в течение нескольких секунд, тратит реальные деньги и не может быть отменена — скиллы запрашивают подтверждение перед каждой такой командой, и вам тоже следует это делать.
