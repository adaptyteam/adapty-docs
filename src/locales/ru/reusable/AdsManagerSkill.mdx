[Плагин Apple Ads](https://github.com/adaptyteam/apple-ads-cli) обучает ваш AI-инструмент для разработки работать с Apple Ads через команды `adapty asa`. Он включает три навыка:

- **`apple-ads`**: Оператор. Читает данные о производительности, изменяет ставки и бюджеты, добавляет ключевые слова и минус-слова, собирает поисковые запросы, запускает и приостанавливает кампании — с подтверждением перед любым расходованием средств.
- **`apple-ads-audit`**: Аудитор только для чтения. Проверяет состояние аккаунта, статус показа, структуру, охват трафика и дублирующиеся ключевые слова с точным соответствием, ничего не записывает.
- **`apple-ads-strategy`**: Планировщик, которому не нужен аккаунт, CLI или подписка. Превращает описание вашего приложения в структуру аккаунта, таксономию ключевых слов, стартовые бюджеты и список минус-слов.

**Поддерживаемые инструменты**: Claude Code, Claude Cowork, GitHub Copilot CLI, OpenAI Codex, Gemini CLI и любой другой инструмент с поддержкой навыков.

Оператор и аудитор работают через Adapty CLI, поэтому сначала установите и авторизуйтесь в CLI — см. [руководство по быстрому старту](developer-cli-quickstart). Команды `adapty asa` появились в **Adapty CLI 0.4.0 и новее**; в более старых версиях их нет вообще. Проверьте с помощью `adapty asa whoami` — это также покажет, подключён ли аккаунт Apple Ads и есть ли у компании активная подписка Ads Manager. Навык стратегии работает без всего этого.

Claude Cowork запускает CLI в песочнице, которая блокирует все домены вне своего списка разрешённых. Разрешите домены Adapty перед установкой плагина там — см. [Запуск CLI в Cowork](developer-cli-quickstart#run-the-cli-in-cowork). Задача в Cowork также запускается на чистой машине, поэтому CLI и его авторизация не сохраняются между сессиями — навык `adapty-cli-setup` плагина устанавливает и авторизует CLI заново в начале каждой сессии.

Для установки выберите форму для вашего инструмента. Полный список — в [README плагина](https://github.com/adaptyteam/apple-ads-cli).

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/apple-ads-cli
claude plugin install apple-ads@adapty
```

Помимо навыков, плагин Claude Code устанавливает slash-команды `/asa-*` — готовые промпты для типовых задач, например `/asa-review` для еженедельной проверки и `/asa-harvest` для превращения поисковых запросов в ключевые слова и минус-слова.

**Любой другой инструмент** — используйте [skills CLI](https://skills.sh) (обратите внимание, что навыки, установленные таким способом, не обновляются автоматически):

```bash
npx skills add adaptyteam/apple-ads-cli --all
```

`--all` устанавливает все три навыка в каждый обнаруженный агент. Для установки одного навыка используйте `--skill`, например `--skill apple-ads-strategy`.

После установки запустите навык в своём проекте — напрямую или через одну из slash-команд:

```bash
/apple-ads
```

Чтение метрик и пробные запуски ничего не стоят. Любая другая команда достигает Apple за секунды, тратит реальные деньги и не может быть отменена — навыки спрашивают подтверждение перед каждой такой командой, и вам тоже следует это делать.
