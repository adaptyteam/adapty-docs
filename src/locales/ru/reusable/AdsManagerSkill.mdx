[Скилл ads-manager](https://github.com/adaptyteam/adapty-sdk-integration-skill) обучает ваш AI-инструмент для написания кода управлять Apple Ads через команды `adapty asa`. Он знает порядок составления команд, что нужно прочитать перед тем, как что-то записать, и какие вызовы тратят деньги.

**Поддерживаемые инструменты**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Скилл управляет Adapty CLI, поэтому сначала установите и аутентифицируйте CLI — см. [руководство по быстрому старту](developer-cli-quickstart).

В корпоративном рабочем пространстве Cowork администратор должен добавить `*.adapty.io` в список разрешённых доменов. До этого скилл не сможет подключиться к Adapty.

Для установки выберите подходящий вариант для вашего инструмента. Полный список — в [README скилла](https://github.com/adaptyteam/adapty-sdk-integration-skill).

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

Этот плагин также содержит скилл интеграции SDK. Оба устанавливаются вместе.

**GitHub Copilot CLI**

```bash
gh skill install adaptyteam/adapty-sdk-integration-skill
```

**Gemini CLI**

```bash
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex или любой другой инструмент** — используйте [skills CLI](https://skills.sh) (обратите внимание, что скиллы, установленные таким образом, не обновляются автоматически):

```bash
npx skills add adaptyteam/adapty-sdk-integration-skill
```

Также можно клонировать репозиторий и скопировать `skills/ads-manager/` в директорию скиллов вашего инструмента.

После установки запустите скилл в вашем проекте:

```bash
/ads-manager
```

Чтение метрик и пробные запуски ничего не стоят. Каждая другая команда обращается к Apple в течение нескольких секунд, тратит реальные деньги и не может быть отменена — скилл запрашивает подтверждение перед каждой такой командой, и вы должны делать то же самое.
