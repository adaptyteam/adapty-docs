1. Чтобы найти **Issuer ID** и **Key ID** вашего командного ключа, в App Store Connect перейдите в [**Users and Access** > **Integrations** > **App Store Connect API**](https://appstoreconnect.apple.com/access/integrations/api) и откройте вкладку **Team Keys**. Если кто-то другой сгенерировал ключ и прислал вам его Issuer ID, Key ID и файл — пропустите этот шаг.

   <ZoomImage id="asc-team-keys-ids.webp" width="700px" alt="Issuer ID и Key ID командного ключа на вкладке Team Keys в App Store Connect" />

2. В Adapty перейдите в [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). В разделе **App Store Connect API key** нажмите **Connect API Key**.

   <ZoomImage id="app-settings-connect-api-key.webp" width="700px" alt="Раздел App Store Connect API key в Adapty с кнопкой Connect API Key" />

3. Заполните поля:
   - **Issuer ID**: скопируйте со вкладки **Team Keys** в App Store Connect.
   - **Key ID**: скопируйте из списка **Active** на вкладке **Team Keys**, рядом с загруженным ключом.
   - **Private key (.p8 file)**: загрузите файл, скачанный для командного ключа.

   <ZoomImage id="app-settings-api-key-dialog.webp" width="700px" alt="Поля Issuer ID, Key ID и Private key (.p8 file) в окне подключения App Store Connect API key" />

4. Подключённый ключ можно заменить позже, но удалить нельзя. Убедитесь, что ключ принадлежит той команде App Store Connect, которой принадлежит это приложение, и нажмите **Connect**. После этого **App Store Product ID** для каждого продукта можно выбирать из списка App Store Connect, а не вводить вручную.

   Adapty не проверяет ключ через Apple в момент подключения. Неверный ключ не даёт ошибки, связанной с ключом: продукты не показывают статус в App Store, а выпадающий список **App Store Product ID** остаётся пустым. Чтобы исправить неверный ключ, [замените его](app-store-connect-api-key#replace-the-key).
