Скилл [adapty-integration](https://github.com/adaptyteam/adapty-skills) полностью автоматизирует интеграцию Adapty: настройку дашборда, установку SDK, пейвол и проверку на каждом этапе. Он автоматически определяет вашу платформу и загружает соответствующую документацию Adapty на каждом шаге.

**Поддерживаемые инструменты**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Для установки выберите команду для вашего инструмента. Полный список — в [README скилла](https://github.com/adaptyteam/adapty-skills).

В репозитории два скилла — `adapty-integration` и `ads-manager`, который запускает Apple Search Ads через Adapty CLI. Каждая команда ниже устанавливает оба.

**Claude Code**

```
claude plugin marketplace add adaptyteam/adapty-skills
claude plugin install adapty-skills@adapty
```

**GitHub Copilot CLI**

```
git clone https://github.com/adaptyteam/adapty-skills.git
cp -r adapty-skills/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```
gemini skills install https://github.com/adaptyteam/adapty-skills
```

**OpenAI Codex или любой другой инструмент** — используйте [skills CLI](https://skills.sh) (обратите внимание, что скиллы, установленные таким способом, не обновляются автоматически):

```
npx skills add adaptyteam/adapty-skills --all
```

`--all` устанавливает оба скилла во все обнаруженные агенты. Без него CLI спросит, какой из двух вы хотите установить.

Также можно клонировать репозиторий и скопировать директории из `skills/` в папку скиллов вашего инструмента.

После установки запустите скилл в своём проекте:

```
/adapty-integration
```

Скилл задаст несколько вопросов по настройке, а затем проведёт вас через настройку дашборда, установку SDK, пейвол и проверку.
