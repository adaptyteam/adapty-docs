Скилл `adapty-integration` автоматизирует интеграцию Adapty от начала до конца: настройку дашборда, установку SDK, пейвол и проверку на каждом этапе. Он автоматически определяет вашу платформу и загружает соответствующую документацию Adapty на каждом шаге. Работает в любом агенте, поддерживающем скиллы: Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI и других.

Скилл является частью [плагина `adapty-skills`](https://github.com/adaptyteam/adapty-skills). Чтобы установить плагин, выполните в терминале:

```bash
npx adapty skills install
```

Перезапустите агент, чтобы загрузить скиллы. Другие способы установки описаны в [README плагина](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Claude Code не обновляет плагин автоматически. Чтобы получать новые скиллы по мере их выхода, в Claude Code выполните `/plugin`, откройте **Marketplaces**, выберите `adapty` и нажмите **Enable auto-update**. Команду обновления для других агентов смотрите в [README плагина](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Чтобы начать интеграцию, напишите в агенте:

```
Integrate Adapty into my app
```

Скилл задаст несколько вопросов по настройке, а затем проведёт через настройку дашборда, установку SDK, пейвол и проверку.
