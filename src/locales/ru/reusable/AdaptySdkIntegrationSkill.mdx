[Навык adapty-integration](https://github.com/adaptyteam/adapty-skills) автоматизирует интеграцию Adapty от начала до конца: настройка дашборда, установка SDK, пейвол и проверка на каждом этапе. Он автоматически определяет вашу платформу и загружает нужную документацию Adapty на каждом шаге.

**Поддерживаемые инструменты**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Чтобы установить навык, выберите нужный вариант для вашего инструмента. Полный список — в [README репозитория](https://github.com/adaptyteam/adapty-skills).

В репозитории два навыка — `adapty-integration` и `ads-manager`, который управляет Apple Search Ads через Adapty CLI. Каждая из команд ниже устанавливает оба.

**Claude Code**

```
claude plugin marketplace add adaptyteam/adapty-skills
claude plugin install adapty-skills@adapty
```

**GitHub Copilot CLI**

```
git clone https://github.com/adaptyteam/adapty-skills.git
cp -r adapty-sdk-integration-skill/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```
gemini skills install https://github.com/adaptyteam/adapty-skills
```

**OpenAI Codex или любой другой инструмент** — используйте [skills CLI](https://skills.sh) (обратите внимание: навыки, установленные таким способом, не обновляются автоматически):

```
npx skills add adaptyteam/adapty-skills --all
```

`--all` устанавливает оба навыка во все обнаруженные агенты. Без этого флага CLI спрашивает, какой из двух вы хотите установить.

Также можно склонировать репозиторий и скопировать директории из `skills/` в папку навыков вашего инструмента.

После установки запустите навык в своём проекте:

```
/adapty-integration
```

Навык задаст несколько вопросов для настройки, затем последовательно проведёт через настройку дашборда, установку SDK, создание пейвола и проверку.
