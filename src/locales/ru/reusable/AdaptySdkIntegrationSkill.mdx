[Скилл adapty-sdk-integration](https://github.com/adaptyteam/adapty-sdk-integration-skill) автоматизирует интеграцию Adapty от начала до конца: настройку дашборда, установку SDK, пейвол и проверку на каждом этапе. Он автоматически определяет вашу платформу и загружает соответствующую документацию Adapty на каждом шаге.

**Поддерживаемые инструменты**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Для установки выберите подходящий вариант для вашего инструмента. Полный список — в [README скилла](https://github.com/adaptyteam/adapty-sdk-integration-skill).

В репозитории хранятся два скилла — `adapty-sdk-integration` и `ads-manager`, который запускает Apple Search Ads через Adapty CLI. Каждая из приведённых команд устанавливает оба скилла.

**Claude Code**

```
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

**GitHub Copilot CLI**

```
git clone https://github.com/adaptyteam/adapty-sdk-integration-skill.git
cp -r adapty-sdk-integration-skill/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex или любой другой инструмент** — используйте [skills CLI](https://skills.sh) (обратите внимание: скиллы, установленные таким способом, не обновляются автоматически):

```
npx skills add adaptyteam/adapty-sdk-integration-skill --all
```

`--all` устанавливает оба скилла во все обнаруженные агенты. Без этого флага CLI спросит, какой из двух вы хотите установить.

Как вариант, можно склонировать репозиторий и скопировать директории из `skills/` в директорию скиллов вашего инструмента.

После установки запустите скилл в вашем проекте:

```
/adapty-sdk-integration
```

Скилл задаст несколько вопросов о настройке, а затем проведёт вас через настройку дашборда, установку SDK, создание пейвола и верификацию.
