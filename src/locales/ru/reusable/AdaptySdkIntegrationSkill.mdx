Скилл `adapty-integration` автоматизирует интеграцию Adapty от начала до конца: настройка дашборда, установка SDK, пейвол и проверка на каждом этапе. Он автоматически определяет вашу платформу и загружает соответствующую документацию Adapty на каждом шаге. Работает в любом агенте, поддерживающем скиллы: Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI и других.

Скилл входит в состав плагина [`adapty-skills`](https://github.com/adaptyteam/adapty-skills). Чтобы установить плагин, выполните в терминале:

```bash
npx adapty skills install
```

Перезапустите агент, чтобы загрузить скиллы. Другие способы установки описаны в [README плагина](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Чтобы начать интеграцию, напишите агенту:

```
Integrate Adapty into my app
```

Скилл задаст несколько вопросов по настройке, затем проведёт через настройку дашборда, установку SDK, настройку пейвола и проверку.
