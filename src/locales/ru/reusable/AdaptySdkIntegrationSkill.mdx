Скилл [adapty-integration](https://github.com/adaptyteam/adapty-skills) автоматизирует интеграцию Adapty от начала до конца: настройка дашборда, установка SDK, пейвол и проверка на каждом этапе. Он автоматически определяет вашу платформу и загружает нужную документацию Adapty на каждом шаге.

**Поддерживаемые инструменты**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Для установки выберите вариант для вашего инструмента. Полный список — в [README скилла](https://github.com/adaptyteam/adapty-skills).

В репозитории хранится больше скиллов, чем один, и каждая команда ниже устанавливает их все.

**Claude Code**

```
claude plugin marketplace add adaptyteam/adapty-skills
claude plugin install adapty-skills@adapty
```

**GitHub Copilot CLI**

```
git clone https://github.com/adaptyteam/adapty-skills.git
cp -r adapty-skills/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```
gemini skills install https://github.com/adaptyteam/adapty-skills
```

**OpenAI Codex**

```
codex plugin marketplace add adaptyteam/adapty-skills
codex plugin add adapty-skills@adapty
```

**Любой другой инструмент** — воспользуйтесь [skills CLI](https://skills.sh) (обратите внимание, что скиллы, установленные таким способом, не обновляются автоматически):

```
npx skills add adaptyteam/adapty-skills --all
```

`--all` устанавливает все скиллы в каждый обнаруженный агент. Без него CLI спросит, какие именно вы хотите установить.

Также можно клонировать репозиторий и скопировать директории из `skills/` в папку скиллов вашего инструмента.

После установки запустите скилл в своём проекте:

```
/adapty-integration
```

Скилл задаст несколько вопросов по настройке, а затем проведёт вас через настройку дашборда, установку SDK, создание пейвола и проверку.
