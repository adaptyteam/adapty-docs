Скилл `adapty-integration` автоматизирует интеграцию Adapty от начала до конца: настройку дашборда, установку SDK, пейвол и проверку на каждом этапе. Он автоматически определяет вашу платформу и загружает нужную документацию Adapty на каждом шаге. Работает в любом агенте с поддержкой скиллов: Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI и других.

Скилл входит в состав [плагина Adapty](manage-adapty-with-ai). Если вы уже установили плагин, этот скилл у вас есть. Если агент не показывает его в списке, обновите плагин командой для вашего агента из [README плагина](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Чтобы установить плагин в агент, выполните в терминале:

```bash
npx adapty skills install
```

Перезапустите агент, чтобы плагин загрузился. Другие способы установки описаны в [README плагина](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Claude Code не обновляет плагин автоматически. Чтобы получать новые скиллы по мере их выхода, в Claude Code выполните `/plugin`, откройте **Marketplaces**, выберите `adapty` и нажмите **Enable auto-update**. Команда обновления для других агентов приведена в [README плагина](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Чтобы запустить интеграцию, напишите агенту:

```
Integrate Adapty into my app
```

Скилл задаст несколько вопросов по настройке, после чего проведёт вас через настройку дашборда, установку SDK, создание пейвола и проверку.
