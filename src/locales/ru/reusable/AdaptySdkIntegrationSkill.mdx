[Навык adapty-integration](https://github.com/adaptyteam/adapty-skills) автоматизирует интеграцию Adapty от начала до конца: настройку дашборда, установку SDK, пейвол и проверку на каждом этапе. Он автоматически определяет вашу платформу и на каждом шаге подтягивает нужную документацию Adapty.

**Поддерживаемые инструменты**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Для установки выберите команду под ваш инструмент. Полный список — в [README репозитория](https://github.com/adaptyteam/adapty-skills).

В репозитории два навыка — `adapty-integration` и `ads-manager`, который управляет Apple Search Ads через Adapty CLI. Каждая команда ниже устанавливает оба.

**Claude Code**

```
claude plugin marketplace add adaptyteam/adapty-skills
claude plugin install adapty-skills@adapty
```

**GitHub Copilot CLI**

```
git clone https://github.com/adaptyteam/adapty-skills.git
cp -r adapty-skills/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```
gemini skills install https://github.com/adaptyteam/adapty-skills
```

**OpenAI Codex или любой другой инструмент** — используйте [skills CLI](https://skills.sh) (обратите внимание: навыки, установленные таким способом, не обновляются автоматически):

```
npx skills add adaptyteam/adapty-skills --all
```

`--all` устанавливает оба навыка во все обнаруженные агенты. Без этого флага CLI спросит, какой из двух вы хотите установить.

Кроме того, можно клонировать репозиторий и скопировать директории из `skills/` в директорию навыков вашего инструмента.

После установки запустите навык в своём проекте:

```
/adapty-integration
```

Навык задаст несколько вопросов по настройке, а затем проведёт через настройку дашборда, установку SDK, пейвол и проверку.
