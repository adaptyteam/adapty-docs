Каждый раз, когда пользователь открывает экран в [флоу](adapty-flow-builder), SDK отправляет в ваше приложение событие `flow_screen_showed`. Передавайте его в Amplitude, Mixpanel или любую другую продуктовую аналитику, чтобы анализировать экраны флоу вместе с остальными событиями приложения.

:::tip
Чтобы отследить, как далеко пользователи проходят флоу, никакой код не нужен — [метрики флоу](flow-metrics) уже отображают просмотры, завершения и отток на каждом экране в дашборде Adapty. Используйте этот гайд, когда нужны те же данные в вашей собственной аналитике, объединённые с событиями, о которых Adapty не знает.
:::

## Прежде чем начать \{#before-you-start\}

Вам понадобится:

- **Adapty Android SDK v4 или выше**: колбэк аналитики флоу отсутствует в более ранних версиях.
- **Версия флоу, опубликованная после выхода этой функции**: Adapty генерирует события экранов при публикации флоу, поэтому флоу, опубликованный до этого момента, не передаёт никаких событий. Если события не поступают в ваше приложение, опубликуйте новую версию флоу и попробуйте снова.

## Что вы получаете \{#what-you-receive\}

<FlowScreenShowedParams />

Просмотры экранов поступают в тот же аналитический колбэк, что и все остальные события флоу. Смотрите [Обработка событий флоу и пейвола](android-handling-events), где указано, как его зарегистрировать.

## Пересылайте каждый просмотр экрана в вашу аналитику \{#forward-every-screen-view-to-your-analytics\}

Сначала проверяйте имя события, поскольку флоу отправляет и другие события через тот же колбэк.

```kotlin showLineNumbers title="Kotlin"
override fun onAnalyticEvent(
    name: String,
    params: Map<String, Any?>,
    context: Context,
) {
    if (name != "flow_screen_showed") return

    val screenId = params["instanceId"]
    val screenOrder = params["screen_order"]

    // Send screenId and screenOrder to your analytics provider here.
}
```

## Запускайте код, когда пользователь доходит до конца \{#run-code-when-a-user-reaches-the-end\}

`is_last_screen` равно `true` на экране, дальше которого флоу не может продвинуться. Используйте это, чтобы открыть контент, отметить онбординг как завершённый или отправить собственное событие о завершении — без добавления действия кнопки в билдере.

```kotlin showLineNumbers title="Kotlin"
override fun onAnalyticEvent(
    name: String,
    params: Map<String, Any?>,
    context: Context,
) {
    if (name != "flow_screen_showed") return
    if (params["is_last_screen"] != true) return

    // The user reached the end of the flow.
}
```

Достижение последнего экрана — это не то же самое, что закрытие флоу. Пользователь может увидеть финальный экран и закрыть флоу, не предприняв никаких действий, а флоу с ветвлением может завершиться на нескольких разных экранах. Чтобы отследить, что флоу закрылось, используйте `onFlowClosed`.
