Вкладка **Design** на правой панели управляет визуальным оформлением каждого элемента. Доступные свойства зависят от типа элемента, однако большинство из них имеют общие параметры стилизации.

:::link
Сведения о размерах, отступах и позиционировании см. в разделе [Макет и позиционирование](manage-paywall-ui-elements).
:::

<AIPromo title="Пропустите вкладку Design совсем.">
  Попросите AI Editor «придать пейволу тёмный, премиальный вид» — и он изменит стиль всех элементов сразу: заливки, углы, типографику и отступы.
</AIPromo>

## Видимость \{#visibility\}

<ZoomImage id="flow-builder/visibility.webp" width="300px" float="right" alt="Visibility toggle" />

Переключатель **Visibility** определяет, отображается ли элемент на экране.

* <Inline id="eye.svg" alt="Show" /> **Show** (по умолчанию): элемент всегда виден.
* <Inline id="visibility-conditional.svg" alt="Conditional" /> **Conditional**: элемент виден только при выполнении определённых условий. Подробнее см. в разделе [Условная видимость](onboarding-element-visibility).
* <Inline id="visibility-hide.svg" alt="Hide" /> **Hide**: элемент всегда скрыт. Используйте это, чтобы временно убрать элемент из флоу без его удаления.

## Заливка \{#fill\}

<ZoomImage id="single-layer-color-fill.webp" width="300px" float="right" alt="Screen settings with one solid color layer in the Fill section, and the color picker on the Custom tab" />

Раздел **Fill** задаёт фон элемента. Чтобы заполнить весь экран, используйте [фон экрана](paywall-head-picture).

Заливка состоит из одного или нескольких слоёв. Каждый слой имеет один из следующих типов:

- **Сплошной цвет** <Inline id="fill-solid.svg" alt="Solid color" />: Используйте палитру или введите HEX-значение. Настройте **прозрачность**, чтобы сделать фон полупрозрачным.
- **Градиент** <Inline id="fill-gradient.svg" alt="Gradient" />: Два и более цветовых стопа. Перетаскивайте стопы, чтобы настроить переход, и задайте угол с помощью ползунка **Direction**. Чтобы изменить стоп, отредактируйте его строку в разделе **Stops**. Чтобы добавить стоп, кликните на полосу градиента или на <Inline id="plus.svg" alt="Add gradient stop" /> рядом с **Stops**. Ползунок в строке слоя меняет прозрачность всех стопов одновременно.
- **Изображение** <Inline id="fill-image.svg" alt="Image" /> или **Видео** <Inline id="fill-video.svg" alt="Video" />: [Изображение или видео](custom-media) в качестве фона.

<ZoomImage id="gradient-picker.webp" width="300px" alt="The gradient picker with three stops, the Direction slider, and the Stops list" />

Чтобы управлять слоями:

- Чтобы добавить слой, нажмите <Inline id="plus.svg" alt="Plus" /> рядом с **Fill**.
- Чтобы изменить тип слоя, нажмите на его образец и выберите тип.
- Чтобы изменить порядок слоёв, перетащите их строки.
- Чтобы удалить слой, нажмите <Inline id="close.svg" alt="Close" /> в его строке.

Верхний слой перекрывает нижние, поэтому полупрозрачный слой поверх изображения [окрашивает его](paywall-head-picture#tint-a-background). Поля ввода и выбора даты/времени отображают только нижний слой.

Чтобы повторно использовать слой в других элементах или создать его тёмную версию, [сохраните его как цветовой стиль](builder-reusable-styles#create-a-color-style). Чтобы повторно использовать изображение вместе с его окраской, [создайте единый многослойный стиль](builder-reusable-styles#multi-layer-styles).

## Граница \{#border\}

<ZoomImage id="flow-builder/border.webp" width="300px" float="right" alt="Border settings" />

Границы по умолчанию отключены. Нажмите <Inline id="plus.svg" alt="Plus" /> рядом с **Border** на правой панели, чтобы добавить границу. Чтобы убрать её, нажмите <Inline id="close.svg" alt="Close" /> рядом с заголовком **Border**.

При наличии границы настройте:

- **Color**: Используйте палитру цветов или введите hex-значение. Чтобы применить [цветовой стиль](builder-reusable-styles#color-styles), выберите его на вкладке **Styles**. Граница игнорирует [слои изображений и видео](builder-reusable-styles#multi-layer-styles) стиля.
- **Width**: Толщина границы в пикселях.

:::tip
Чтобы сделать границу градиентной, примените [цветовой стиль](builder-reusable-styles#color-styles) со слоем градиента в поле **Color**.
:::

## Углы \{#corners\}

<ZoomImage id="flow-builder/corners.webp" width="300px" float="right" alt="Настройки углов" />

Раздел **Corners** управляет радиусом скругления углов.

* **Radius slider**: задаёт одинаковый радиус для всех четырёх углов
* **Per-corner toggle** <Inline id="per-corner.svg" alt="Per Corner" />: включите, чтобы задать отдельный радиус для каждого угла

## Эффекты \{#effects\}

<ZoomImage id="flow-builder/effects.webp" width="300px" float="right" alt="Effects settings" />

Нажмите кнопку плюса <Inline id="plus.svg" alt="Plus" /> рядом с **Effects**, чтобы добавить один или несколько визуальных эффектов:

* **Drop shadow**: Тень за элементом
* **Inner shadow**: Тень внутри границ элемента
* **Layer blur**: Размывает элемент и его дочерние элементы

На один элемент можно накладывать несколько эффектов. Используйте переключатель видимости <Inline id="eye.svg" alt="Show" />, чтобы временно отключить эффект.

## Анимация \{#animation\}

<ZoomImage id="flow-builder/animation.webp" width="300px" float="right" alt="Animation settings" />

Нажмите кнопку <Inline id="plus.svg" alt="Plus" /> рядом с **Animation**, чтобы добавить анимационный эффект. На данный момент доступна только анимация **Pulse** — элемент ритмично увеличивается и уменьшается, привлекая к себе внимание.

Настройте анимацию Pulse с помощью следующих параметров:

| Параметр | Описание |
|-----------|-------------|
| Scale amount (%) | Насколько элемент увеличивается относительно исходного размера |
| Duration (ms) | Продолжительность одного цикла анимации |
| Delay between loops (ms) | Пауза между повторениями |
| Shadow color | Цвет пульсирующей тени |
| Shadow size (px) | Размер пульсирующей тени |

<ZoomImage id="flow-builder/animation-demo.webp" width="600px" alt="Pulse animation in action" />

### Предпросмотр анимации \{#preview-the-animation\}

По умолчанию в билдере отображаются статичные экраны — анимации не воспроизводятся, пока вы не включите их. Есть два способа:

- Нажмите кнопку **Toggle animations** <Inline id="fill-video.svg" alt="Toggle animations" /> над превью устройства. Она включает или отключает анимации на экране — после включения они воспроизводятся непрерывно, пока вы не нажмёте снова. Кнопка появляется только тогда, когда на активном экране есть хотя бы одна анимация.
- Откройте [контекстное меню](paywall-layout-and-products#screen-actions) экрана (значок с тремя точками рядом со слоем экрана) и выберите **Play Animation**.

## Свойства типографики (текстовые элементы) \{#typography-properties-text-elements\}

<ZoomImage id="flow-builder/typography.webp" width="300px" float="right" alt="Настройки типографики" />

Для текстовых элементов отображается раздел **Typography** со следующими настройками:

### Шрифт

:::link
Смотрите также: [Пользовательские шрифты](using-custom-fonts-in-flow-builder)
:::

Нажмите на выпадающий список шрифтов <Inline id="font-select.svg" alt="Font select" />, чтобы открыть выбор шрифта. В нём есть две вкладки:

* **Styles**: Список сохранённых [текстовых стилей](builder-reusable-styles#text-styles) вашего проекта. Выберите стиль, чтобы сразу применить все его настройки типографики.
* **Fonts**: Список всех доступных семейств шрифтов. Найдите нужный через поиск или прокрутку. Встроенные шрифты могут **отображаться по-разному на разных устройствах** — для единообразного отображения загрузите [пользовательский шрифт](using-custom-fonts-in-flow-builder).

Чтобы сохранить текущие настройки типографики как новый [текстовый стиль](builder-reusable-styles#text-styles), нажмите <Inline id="plus.svg" alt="Create text style" /> рядом с вкладками. После этого элемент будет использовать новый стиль.

### Размер и насыщенность \{#size-and-weight\}

:::warning
**Жирный** и **курсив** не влияют на [пользовательский шрифт](using-custom-fonts-in-flow-builder), если его семейство не включает соответствующее начертание. [Загрузите нужное начертание](using-custom-fonts-in-flow-builder#manage-a-custom-font) самостоятельно.
:::

* **Weight**: Выберите насыщенность шрифта из выпадающего списка
* **Size**: Выберите размер из выпадающего списка или введите произвольное значение

:::note
Размер текста отображается по-разному в зависимости от платформы: Android масштабирует текст во флоу в соответствии с системными настройками размера шрифта, тогда как iOS отображает ровно тот размер, который вы задали. Проверяйте вёрстку на Android с увеличенным системным размером шрифта — текст, который умещается на iOS, может переноситься или выходить за границы там.
:::

### Цвет \{#color\}

Нажмите на образец цвета и введите значение в формате HEX или воспользуйтесь палитрой. Чтобы применить [стиль цвета](builder-reusable-styles#color-styles), выберите его на вкладке **Styles**. Для текста отображаются только [слои с заливкой](builder-reusable-styles#multi-layer-styles) стиля.

### Выравнивание \{#alignment\}

Две группы элементов управления выравниванием:

* **По горизонтали**: По левому краю <Inline id="align-left.svg" alt="Align left" />, По центру <Inline id="align-center.svg" alt="Align center" />, или По правому краю <Inline id="align-right.svg" alt="Align right" />
* **По вертикали**: По верхнему краю <Inline id="align-top.svg" alt="Align top" />, По середине <Inline id="align-middle.svg" alt="Align middle" />, или По нижнему краю <Inline id="align-bottom.svg" alt="Align bottom" />

### Оформление \{#decoration\}

* **None** <Inline id="border-none.svg" alt="None" />: Без оформления (по умолчанию)
* **Underline** <Inline id="underline.svg" alt="Underline" />: Добавляет подчёркивание текста
* **Strikethrough** <Inline id="strikethrough.svg" alt="Strikethrough" />: Добавляет зачёркивание текста

### Усечение \{#truncation\}

Включите усечение, чтобы обрезать текст, превышающий значение **Max Lines**.
Это удобно при поддержке нескольких языков: если переведённая строка
длиннее оригинала, усечение не даст ей сломать вёрстку.

:::note
Когда вы выбираете текстовый элемент, над ним на холсте появляется **встроенная панель инструментов**. Она даёт быстрый доступ к шрифту, начертанию, размеру и выравниванию — без прокрутки правой панели.
:::

## Настройки состояний (интерактивные элементы) \{#state-specific-settings-interactive-elements\}

<ZoomImage id="flow-builder/states.webp" width="300px" alt="State selection" float="right" />

Интерактивные элементы поддерживают несколько визуальных состояний. При выборе такого элемента в правой панели появляется раздел **States**. Переключайтесь между состояниями, чтобы настроить отдельные визуальные свойства для каждого из них.

Каждое состояние может переопределять любое визуальное свойство — заливку, границу, цвет типографики, прозрачность и другие.

### Выбираемые состояния \{#selectable-states\}

:::link
Основная статья: [Выбираемые элементы](flow-selectable-elements)
:::

Элементы, входящие в выбираемую группу (варианты квиза, продукты, вкладки, переключатели и чекбоксы), по умолчанию имеют два состояния:

* **Default**: Обычный вид элемента
* **Selected**: Вид, когда пользователь выбрал этот вариант. Переопределите такие свойства, как заливка, цвет рамки и цвет текста, чтобы выделить активный выбор

Чтобы задать стиль для неактивного состояния выбираемого элемента, добавьте третье состояние вручную. Откройте **States settings** <Inline id="settings.svg" alt="Settings" /> и добавьте **Disabled state**.

Состояние **Disabled** зависит от условий. Выберите его и нажмите **Set conditions** <Inline id="visibility-conditional.svg" alt="set conditions" />, чтобы указать, при каких условиях элемент становится неактивным во время выполнения, — например, когда обязательное поле пустое.

### Состояния полей ввода \{#input-states\}

Поля ввода поддерживают несколько состояний:

* **Default**: обычный вид без фокуса
* **Active**: поле в фокусе, готово к вводу
* **Invalid**: введённое значение не прошло валидацию
* **Disabled**: поле неактивно и недоступно для взаимодействия

<ZoomImage id="flow-builder/state-demo.webp" width="600px" alt="Переключение состояний и применение визуальных переопределений" />

### Другие элементы с управлением состоянием \{#other-state-bearing-elements\}

Некоторые элементы поддерживают стилизацию по состояниям, выходящую за рамки стандартной схемы **Default / Selected / Disabled**:

- **[Шаги индикатора прогресса](builder-loaders-and-progress-bars#step-states)** — три состояния для каждого шага: **Completed**, **Current** и **Upcoming**.
- **[Точки карусели](builder-containers#dots)** — два варианта цвета: **Color** для неактивных точек и **Active Color** для точки текущего слайда.

## Переиспользуемые стили \{#reusable-styles\}

:::link
Основная статья: [Переиспользуемые стили](builder-reusable-styles)
:::

Чтобы текстовые и цветовые свойства оставались единообразными во всём флоу, сохраните их как переиспользуемые стили. При изменении стиля он обновится во всех элементах и экранах, которые его используют.
