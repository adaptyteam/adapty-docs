Предоставьте необходимые разрешения сервисному аккаунту, который Adapty будет использовать для управления подписками и проверки покупок.

1. Откройте [Google Play Console](https://play.google.com/console/), перейдите на страницу **Users and permissions** и нажмите кнопку **Invite new users**.

2. На странице **Invite user** введите адрес электронной почты созданного вами сервисного пользователя.

<Zoom>
  <img src="/assets/shared/img/3afd002-invite_user.webp"

    width: '700px', /* image width */
    display: 'block', /* for alignment */
    margin: '0 auto' /* center alignment */
  }}
/>
</Zoom>

3. Перейдите на вкладку **Account permissions**.

<Zoom>
  <img src="/assets/shared/img/4e2717b-account_permissions.webp"
  style={{
    border: '1px solid #727272', /* border width and color */
    width: '700px', /* image width */
    display: 'block', /* for alignment */
    margin: '0 auto' /* center alignment */
  }}
/>
</Zoom>

4. Выберите следующие разрешения:
   - View app information and download bulk reports (read-only)
   - View financial data, orders, and cancellation survey responses
   - Manage orders and subscriptions
   - Manage store presence
5. Нажмите кнопку **Invite user**.
6. В окне **Send invite?** нажмите кнопку **Send invite**. Сервисный аккаунт появится в списке пользователей.
