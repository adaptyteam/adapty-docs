[Плейсмент](placements) — это конкретное место в вашем мобильном приложении, где можно показывать флоу, пейвол, онбординг или A/B-тест. Например, выбор подписки может появляться во флоу при запуске приложения, а расходуемый продукт (например, золотые монеты) — когда у пользователя заканчиваются монеты в игре.

Вы можете показывать одни и те же или разные флоу, пейволы, онбординги или A/B-тесты в разных плейсментах или разным сегментам пользователей — в Adapty они называются «аудиториями».

Прочитайте раздел [Как выбрать подходящие плейсменты](choose-meaningful-placements) — там есть полезные советы.

:::tip
Плейсменты также можно создавать программно с помощью [Developer CLI](developer-cli-reference#adapty-placements-create).
:::

:::info
Хотя процесс создания плейсмента схож для флоу, пейволов и онбордингов, один плейсмент не может обслуживать более одного типа — каждый тип плейсмента обрабатывает разные метрики. Тип фиксируется при создании плейсмента, поэтому если вы хотите показывать флоу там, где раньше показывался пейвол, потребуется создать новый плейсмент для флоу с новым идентификатором плейсмента.
:::

## Создание и настройка плейсмента \{#create-and-configure-a-placement\}

1. Перейдите в раздел **[Placements](https://app.adapty.io/placements)** главного меню Adapty. Выберите вкладку **Flows**, **Paywalls** или **Onboardings** в зависимости от типа плейсмента, который хотите создать.

2. Нажмите **Create placement**.

    width: '700px', /* image width */

</Zoom>
3. Введите **Placement name** — внутренний идентификатор в дашборде Adapty. Его можно изменить позже.

4. Введите **Placement ID** — этот идентификатор используется в Adapty SDK для вызова [флоу](adapty-flow-builder), [пейволов](paywalls), [онбордингов](onboardings) и [A/B-тестов](ab-tests) плейсмента. Placement ID уникален среди всех плейсментов в приложении вне зависимости от их типа, и изменить его после создания нельзя.

Затем назначьте плейсменту флоу, пейвол, онбординг или A/B-тест. Adapty поддерживает [аудитории](audience) — сегменты пользователей на основе [сегментов](segments) — так что вы можете показывать разный контент разным группам пользователей. Если таргетинг не нужен, аудитория *All users* по умолчанию охватывает всех.

<AddAudience />

Как только плейсмент сохранён и опубликован, всё готово — используйте **Placement ID** в коде приложения, чтобы получить и отобразить его.
