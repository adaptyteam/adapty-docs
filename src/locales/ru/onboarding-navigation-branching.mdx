Навигация и ветвление позволяют провести пользователей через каждый шаг вашего флоу: используйте статические маршруты для перехода всех пользователей к основным экранам и динамическую навигацию для адаптации флоу на основе выбора пользователя.

При переходе между экранами флоу может отображать [анимации переходов](flow-screen-transitions).

:::link
Навигация — это тип действия. Подробнее о действиях см. в разделе [Действия](onboarding-actions).
:::

## Навигация между экранами \{#navigate-between-screens\}

Вы можете настроить статическую и динамическую навигацию с помощью различных элементов флоу.

### Статическая навигация \{#static-navigation\}

Статическая навигация направляет всех пользователей на один и тот же экран. Чтобы настроить её:
1. Выберите любой элемент, по которому пользователь может нажать, — кнопку, вариант ответа в квизе или переключатель.

   <ZoomImage id="add-trigger.webp" width="500px" alt="Add trigger button" />

2. Откройте панель **Interactions** справа и нажмите **Add trigger**.

   Чтобы переходить на следующий экран сразу при выборе варианта в квизе — без отдельного нажатия кнопки — выберите здесь элемент варианта ответа, а не кнопку.

   <ZoomImage id="navigate-to-screen-settings.webp" width="300px" alt="Окно редактирования действия Navigate to Screen с Paywall в качестве назначения, анимацией Slide in upward with Ease out bounce, длительностью 400 мс и без задержки" />

3. Настройте триггер **On tap**:
   - **Action**: Выберите **Navigate to screen**.
   - **Destination**: Выберите экран назначения.
   - **Animation**: Оставьте анимацию push по умолчанию или выберите другую [анимацию](flow-screen-transitions#animation-types).

  <DocVideo id="flow-transition-slide-in.mp4" width="300px" alt="Slide in: пейвол выезжает снизу и появляется поверх текущего экрана с лёгким пружинящим эффектом, а нажатие стрелки «назад» убирает пейвол обратно вниз" />

### Динамическая навигация \{#dynamic-navigation\}

Динамическая навигация направляет пользователей в зависимости от их ответов в квизе, состояния переключателей и кастомных атрибутов.
Любой [выбираемый элемент](flow-selectable-elements) может быть условием для динамической навигации.

Чтобы её настроить:
1. Выберите элемент, который будет осуществлять навигацию.
2. Откройте панель **Interactions** справа. Нажмите **Add trigger**.

   Чтобы перенаправить пользователей сразу при нажатии на вариант квиза — без дополнительного нажатия кнопки — выберите здесь элемент варианта квиза вместо кнопки.

   <ZoomImage id="add-trigger.webp" width="500px" alt="Add trigger button" />

3. Настройте триггер **On tap**:
   - **Action**: выберите **Conditional**.
   - **Conditions**: задайте условия навигации. Подробнее [здесь](onboarding-actions#conditional-actions).

<ZoomImage id="conditional-action.webp" width="500px" alt="Conditional actions" />

## Закрытие флоу \{#close-flow\}

Если пользовательский сценарий предполагает закрытие флоу, вы можете настроить это с помощью кнопок или квизов с одиночным ответом:

1. Добавьте и выберите элемент, который должен закрывать флоу при нажатии.
2. Откройте панель **Interactions** справа. Нажмите **Add trigger**.
   <ZoomImage id="add-trigger.webp" width="500px" alt="Add trigger button" />

3. Настройте триггер **On tap**:
   - **Action**: выберите **Close flow**.

<ZoomImage id="close-flow.webp" width="500px" alt="Close flow action" />
