Восстановление покупок на iOS и Android позволяет пользователям снова получить доступ к ранее приобретённому контенту — подпискам или встроенным покупкам — без повторного списания средств. Это особенно удобно, когда пользователь удалил и переустановил приложение или перешёл на новое устройство и хочет получить доступ к ранее купленному контенту, не платя снова.

:::note
Если вы создали экран в билдере, восстанавливать покупки вручную не нужно. Привяжите соответствующий элемент управления — действие **Restore purchases** во Flow & Paywall Builder или кнопку/ссылку восстановления в старом — и SDK выполнит восстановление самостоятельно.
:::

Если вы создали экран самостоятельно, вызовите метод `.restorePurchases()`:

```typescript showLineNumbers
try {
    const profile = await adapty.restorePurchases();
    const isSubscribed = profile.accessLevels['YOUR_ACCESS_LEVEL']?.isActive;
  
    if (isSubscribed) {
        // restore access
    }
} catch (error) {
    // handle the error
}
```

Параметры ответа:

| Параметр | Описание |
|---------|-----------|
| **Profile** | <p>Объект [`AdaptyProfile`](https://react-native.adapty.io/interfaces/adaptyprofile). Эта модель содержит информацию об уровнях доступа, подписках и разовых покупках.</p><p>Проверьте **статус уровня доступа**, чтобы определить, есть ли у пользователя доступ к приложению.</p> |

:::info
В Adapty React Native SDK 4.0.3 и выше `restorePurchases()` успешно завершается, даже если нечего восстанавливать: метод возвращает текущий профиль, поэтому проверяйте в нём статус уровня доступа. В более ранних версиях SDK метод на Android возвращает ошибку `noPurchasesToRestore` в таком случае.
:::
