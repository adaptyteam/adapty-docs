[Adapty Developer CLI](developer-cli) работает в Claude Cowork, так что вы можете управлять аккаунтом Adapty прямо из чата, а не из терминала. Cowork выполняет команды в песочнице, которая обращается только к разрешённым доменам, поэтому перед первым входом в аккаунт CLI нужно один раз настроить в Claude.

**Что вам понадобится:**

- Приложение Claude desktop с Cowork
- Аккаунт Adapty
- Для корпоративных рабочих пространств Claude — помощь администратора рабочего пространства: см. [Разрешить домены Adapty](#allow-the-adapty-domains)

## Добавление плагина Adapty \{#add-the-adapty-plugin\}

Плагин Adapty содержит инструкции, которым следует Claude при установке, аутентификации и работе с CLI, включая [навык Apple Ads](developer-cli-ads-manager-skill) для работы с Ads Manager.

Чтобы добавить плагин:

1. В Claude откройте **Settings** → **Plugins**.
2. Нажмите **Add** → **Add marketplace**.
3. Выберите **Add from a repository**.
4. В поле **URL** вставьте `https://github.com/adaptyteam/apple-ads-cli`.
5. Нажмите **Sync**.

<ZoomImage id="cowork-marketplace-url.png" width="700px" alt="Add marketplace dialog in Claude with the Adapty repository URL and the Sync button" />

Плагины Adapty появятся в разделе **Personal** в каталоге плагинов.

## Разрешите домены Adapty \{#allow-the-adapty-domains\}

Пока вы не добавите Adapty в список разрешённых доменов песочницы, CLI не сможет войти в аккаунт или считать его данные.

Разрешите оба домена: `adapty.io` и `*.adapty.io`. Символ подстановки не распространяется на корневой домен в большинстве реализаций списков разрешений. CLI обращается к `api.adapty.io`, а агент, который читает документацию Adapty в процессе работы, — к корневому домену.

Cowork применяет эти настройки при запуске задачи. Если вы измените режим доступа или добавите домен в ходе разговора, текущий разговор сохранит исходные настройки — начните новую задачу.

### Личные аккаунты

Вы настраиваете список разрешённых доменов самостоятельно:

1. В Claude откройте **Settings** → **Capabilities**.
2. Включите **Code execution and file creation**. Блок **Allow network egress** скрыт, пока вы этого не сделаете.
3. Включите **Allow network egress**.
4. В **Domain allowlist** выберите **Package managers only**.
5. В разделе **Additional allowed domains** добавьте `adapty.io`, затем `*.adapty.io`.

<ZoomImage id="cowork-domain-allowlist.png" width="700px" alt="Allow network egress settings in Claude, with adapty.io and *.adapty.io in the additional allowed domains list" />

Другой режим доступа, **All domains**, позволяет песочнице обращаться к любому сайту. При его выборе домены Adapty добавлять не нужно.

### Корпоративные рабочие пространства \{#corporate-workspaces\}

Доступом управляет администратор. Попросите его добавить оба домена для рабочего пространства.

## Установка и авторизация CLI \{#install-and-authorize-the-cli\}

Каждая задача в Cowork запускается на чистой машине: без CLI, токена и конфигурации из предыдущей сессии, поэтому шаги установки и входа повторяются в начале каждой задачи.

Чтобы установить и авторизовать CLI:

1. Начните новую задачу в Cowork.
2. Попросите Claude установить Adapty CLI — например, «Install the Adapty CLI». Cowork может запросить разрешение на открытие ссылок установки — разрешите это.

   <ZoomImage id="cowork-cli-installed.png" width="700px" alt="Чат в Cowork, где Claude подтверждает установку Adapty CLI" />

3. После установки Cowork предложит войти в Adapty — согласитесь, и он отправит ссылку для авторизации с кодом устройства. Код действует около 15 минут.

   <ZoomImage id="cowork-auth-link.png" width="700px" alt="A Cowork chat where Claude posts the Adapty authorization link and device code" />

4. Откройте ссылку. В браузере откроется страница авторизации Adapty CLI.
5. Убедитесь, что код на странице совпадает с кодом от Cowork, затем нажмите **Authorize**. Если коды не совпадают, нажмите **Deny** и попросите Cowork выдать новую ссылку.

<ZoomImage id="cowork-authorize-page.png" width="700px" alt="The Adapty CLI authorization page in a browser showing the device code and the Authorize button" />

6. Вернитесь в чат и сообщите Cowork, что авторизация выполнена — например, напишите «done». Cowork проверит вход и выведет данные вашего аккаунта.

CLI готов к работе. Чтобы настроить приложение, продукты и пейволы через чат, следуйте [руководству по быстрому старту](developer-cli-quickstart).

## Устранение неполадок \{#troubleshooting\}

| Проблема | Как исправить |
|---------|---------------|
| Навыки не появляются после нажатия **Sync** | Убедитесь, что URL репозитория — `https://github.com/adaptyteam/apple-ads-cli`, затем нажмите **Sync** ещё раз. |
| Сетевые ошибки при установке или авторизации | Добавьте `adapty.io` и `*.adapty.io` в [список разрешённых доменов](#allow-the-adapty-domains). Настройки применяются при запуске задачи, поэтому после добавления начните новую задачу. |
| Ссылка для авторизации не открывается или отклоняется | Код действителен около 15 минут. Попросите Cowork сгенерировать новую ссылку. |
| Код в браузере не совпадает с кодом в чате | Не нажимайте **Authorize**. Попросите Cowork прислать новую ссылку и начните заново. |
