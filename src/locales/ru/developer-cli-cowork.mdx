[Adapty Developer CLI](developer-cli) работает в приложении Claude, так что вы можете управлять своим аккаунтом Adapty прямо из чата, а не через терминал. Claude выполняет команды в песочнице, которая имеет доступ только к разрешённым доменам, поэтому перед первым входом в аккаунт CLI нужно один раз настроить в Claude.

:::note
Claude Cowork и чат теперь [объединены в один Claude](https://claude.com/resources/articles/cowork-is-now-claude): всё, что вы делали в Cowork, теперь доступно в любом разговоре. Объединение постепенно распространяется по планам. Если в вашем плане по-прежнему есть отдельный Cowork, следуйте тем же шагам и начинайте каждую задачу в Cowork.
:::

**Что вам понадобится:**

- Приложение Claude
- Аккаунт Adapty
- Для корпоративных рабочих пространств Claude — помощь администратора рабочего пространства: см. [Разрешите домены Adapty](#allow-the-adapty-domains)

## Добавление плагина Adapty \{#add-the-adapty-plugin\}

Плагин Adapty содержит скиллы, которым следует Claude при установке, аутентификации и управлении CLI, включая [скилл Apple Ads](developer-cli-ads-manager-skill) для работы с Ads Manager.

Чтобы добавить плагин:

1. В Claude откройте **Settings** → **Plugins**.
2. Нажмите **Add** → **Add marketplace**.
3. Выберите **Add from a repository**.
4. В поле **URL** вставьте `https://github.com/adaptyteam/apple-ads-cli`.
5. Нажмите **Sync**.

<ZoomImage id="cowork-marketplace-url.png" width="700px" alt="Add marketplace dialog in Claude with the Adapty repository URL and the Sync button" />

Плагины Adapty появятся в разделе **Personal** в каталоге плагинов.

## Разрешите домены Adapty \{#allow-the-adapty-domains\}

Пока вы не добавите Adapty в список разрешённых доменов песочницы, CLI не сможет войти в аккаунт или читать его данные.

Добавьте в список оба домена: `adapty.io` и `*.adapty.io`. В большинстве реализаций вайлдкард не распространяется на корневой домен. Сам CLI обращается к `api.adapty.io`, а агент, читающий документацию Adapty в процессе работы, обращается к корневому домену.

Claude применяет эти настройки в момент начала разговора. Если вы измените режим доступа или добавите домен в ходе разговора, текущий разговор сохранит те настройки, с которыми он начался — начните новый разговор.

### Личные аккаунты \{#personal-accounts\}

Список разрешённых доменов настраивается самостоятельно:

1. В Claude откройте **Settings** → **Capabilities**.
2. Включите **Code execution and file creation**. Блок **Allow network egress** появится только после этого.
3. Включите **Allow network egress**.
4. В **Domain allowlist** выберите **Package managers only**.
5. В разделе **Additional allowed domains** добавьте `adapty.io`, затем `*.adapty.io`.

<ZoomImage id="cowork-domain-allowlist.png" width="700px" alt="Настройки Allow network egress в Claude с adapty.io и *.adapty.io в списке дополнительных разрешённых доменов" />

Другой режим доступа, **All domains**, позволяет песочнице обращаться к любому сайту. При его выборе домены Adapty добавлять не нужно.

### Корпоративные рабочие пространства \{#corporate-workspaces\}

Список разрешённых доменов контролирует администратор. Попросите его добавить оба домена для рабочего пространства.

## Установка и авторизация CLI \{#install-and-authorize-the-cli\}

Каждый новый разговор начинается на чистой машине: ни CLI, ни токен, ни конфигурация не сохраняются между сессиями, поэтому шаги установки и входа повторяются в начале каждого разговора.

Чтобы установить и авторизовать CLI:

1. Начните новый разговор в Claude.
2. Попросите Claude установить Adapty CLI — например, «Install the Adapty CLI». Claude может запросить разрешение на открытие ссылок установки — разрешите это.

   <ZoomImage id="cowork-cli-installed.png" width="700px" alt="Чат с Claude, в котором Claude подтверждает установку Adapty CLI" />

3. После установки Claude предложит войти в Adapty — согласитесь, и он опубликует ссылку для авторизации с кодом устройства. Код действует около 15 минут.

   <ZoomImage id="cowork-auth-link.png" width="700px" alt="A Claude chat where Claude posts the Adapty authorization link and device code" />

4. Откройте ссылку. В браузере откроется страница авторизации Adapty CLI.
5. Убедитесь, что код на странице совпадает с кодом, который прислал Claude, затем нажмите **Authorize**. Если коды не совпадают, нажмите **Deny** и попросите Claude прислать новую ссылку.

   <ZoomImage id="cowork-authorize-page.png" width="700px" alt="The Adapty CLI authorization page in a browser showing the device code and the Authorize button" />

6. Вернитесь в чат и сообщите Claude, что авторизация прошла — например, «готово». Claude проверит вход и выведет данные вашего аккаунта.

CLI готов к работе. Чтобы настроить приложение, продукты и пейволы прямо из чата, следуйте [гайду по быстрому старту](developer-cli-quickstart).

## Устранение неполадок \{#troubleshooting\}

| Проблема | Как исправить |
|---------|---------------|
| Скиллы не появляются после нажатия **Sync** | Проверьте, что URL репозитория — `https://github.com/adaptyteam/apple-ads-cli`, затем нажмите **Sync** ещё раз. |
| Сетевые ошибки при установке или авторизации | Добавьте `adapty.io` и `*.adapty.io` в [список разрешённых доменов](#allow-the-adapty-domains). Настройки применяются при начале нового разговора, поэтому запустите новый чат после их добавления. |
| Ссылка для авторизации не открывается или отклоняется | Код действителен около 15 минут. Попросите Claude сгенерировать новую ссылку. |
| Код в браузере не совпадает с кодом в чате | Не нажимайте **Authorize**. Попросите Claude предоставить новую ссылку и начните заново. |
