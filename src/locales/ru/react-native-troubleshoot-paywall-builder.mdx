Этот гайд поможет вам решить распространённые проблемы при использовании пейволов, созданных в Adapty Paywall Builder, в React Native SDK. Если у вас возникают проблемы с флоу, см. [Распространённые проблемы](flow-common-issues).

## Получение конфигурации пейвола завершается ошибкой \{#getting-a-paywall-configuration-fails\}

**Проблема**: Запрос конфигурации отображения для флоу или пейвола завершается ошибкой.

**Причина**: Пейвол не включён для отображения на устройстве в Paywall Builder.

**Решение**: Включите переключатель **Show on device** в Paywall Builder.

## Число просмотров пейвола слишком большое \{#the-paywall-view-number-is-too-big\}

**Проблема**: Счётчик просмотров пейвола показывает вдвое больше ожидаемого.

**Причина**: Возможно, в вашем коде вызывается `logShowFlow` (React Native SDK v4+) / `logShowPaywall`, что дублирует счётчик просмотров для пейвола, созданного в старом Paywall Builder. Adapty отслеживает эти просмотры автоматически, поэтому данный метод вызывать не нужно.

**Решение**: Убедитесь, что в вашем коде не вызывается `logShowFlow` (React Native SDK v4+) / `logShowPaywall` для пейвола, созданного в старом Paywall Builder.

## Другие проблемы \{#other-issues\}

**Проблема**: Вы столкнулись с другими проблемами, связанными с Paywall Builder, которые не описаны выше.

**Решение**: При необходимости обновите SDK до последней версии, воспользовавшись [гайдами по миграции](react-native-sdk-migration-guides). Многие проблемы уже исправлены в новых версиях SDK.
