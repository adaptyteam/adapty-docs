Переключатель пробного периода позволяет переключать пейвол между продуктами с бесплатным пробным периодом и без него. Но сам переключатель — это просто выключатель: включён или выключён. Вы сами задаёте правила, которые показывают нужные карточки и определяют, какой продукт выбран.

В этом гайде показано, как задать эти правила и собрать полноценный пейвол с переключателем.

<DocVideo id="paywall-trial-toggle-demo.mp4" width="300px" alt="Готовый пейвол: переключение тогла меняет оба продуктовых карточки на версии с триалом и изменяет текст кнопки с Purchase на Start your free trial" />

## Перед началом работы \{#before-you-start\}

- Создайте экран пейвола — например, следуйте рецепту [Создание базового экрана пейвола](basic-paywall-screen).
- [Создайте продукты](create-product) и [добавьте к ним триальное предложение](create-offer).

:::important
Если вы хотите сделать триал опциональным (что необходимо для использования переключателя триала), не создавайте introductory offer. На iOS introductory offers применяются **автоматически** для каждого подходящего пользователя. Отключить их невозможно. Используйте вместо этого promotional offer. См. [Как Adapty работает с офферами](create-offer#how-adapty-works-with-offers).
:::

## 1. Добавьте карточки продуктов \{#1-add-the-product-cards\}

1. Нажмите на меню **+** > **Paywall & Commerce** > **Products** и выберите пресет.
2. Выберите карточку — на холсте или в панели **Layers**. Назначьте продукт карточке, а в выпадающем списке офферов оставьте **No offer**.
3. Повторите для каждого плана — по одной карточке на план, без триала.
4. Продублируйте каждую карточку. В каждой копии выберите триальный оффер в выпадающем списке.

Теперь у каждого плана есть две карточки, указывающие на один и тот же продукт — одна с оффером, другая без.

<ZoomImage id="paywall-trial-toggle-cards.webp" width="700px" alt="Четыре карточки продуктов на холсте — годовой и месячный, каждый с пробным периодом и без — все отображаются до того, как заданы какие-либо правила видимости" />

## 2. Добавьте переключатель пробного периода \{#2-add-the-trial-toggle\}

1. Нажмите **+** > **Paywall & Commerce** > **Trial Toggle**.

    <ZoomImage id="paywall-trial-toggle-add.webp" width="700px" alt="The trial toggle added to the paywall screen and selected on the canvas" />

2. Убедитесь, что переключатель входит в группу выбора правильного типа. Нажмите на пустую область холста, чтобы открыть **Screen settings**. В разделе **Selectable groups** откройте `trial_toggle`, установите **Group Type** в значение **Toggle** и нажмите **Save**. В диалоге отобразится переменная, которую мы будем использовать для определения состояния переключателя: `trial_toggle.isActive`.

   <ZoomImage id="paywall-trial-toggle-group-type.webp" width="500px" alt="The Edit group dialog with Group Type set to Toggle and the condition variable trial_toggle.isActive below it" />

3. Отредактируйте метку переключателя.

Оставьте переключатель выключенным по умолчанию. Предварительно включённый переключатель триала может привести к отклонению в App Store как тёмный паттерн — см. [Переключатели](builder-toggles).

## 3. Показ нужных карточек для каждого состояния переключателя \{#3-show-the-right-cards-for-each-toggle-state\}

На вкладке **Design** каждой карточки в разделе **Visibility** выберите **Conditional** и настройте условие:

| Карточка | Условие |
|---|---|
| С пробным периодом | `trial_toggle.isActive` **Equals** **True** |
| Без пробного периода | `trial_toggle.isActive` **Equals** **False** |

<ZoomImage id="paywall-trial-toggle-visibility.webp" width="700px" alt="The Yearly_notrial card selected with Visibility set to Conditional and the Show element if popover showing trial_toggle.isActive Equals False" />

## 4. Выбирайте видимую карточку при переключении тогла \{#4-select-a-visible-card-when-the-toggle-changes\}

Карточки теперь меняются вместе с тоглом, но выбранный продукт — нет. Карточка, которая становится невидимой, остаётся выбранной, и действие **Purchase** по-прежнему направлено на неё — то есть пользователь, включивший пробный период, всё равно может быть списан.

Добавьте **Conditional Action** к тоглу, чтобы при каждом нажатии выбор сбрасывался на видимую карточку.

1. На панели **Layers** выберите контейнер **Trial toggle**.
2. Откройте вкладку **Interactions**, добавьте триггер **On tap** и **Conditional Action**:

| Блок | Что настроить |
    |---|---|
    | **if** | `trial_toggle.isActive` **Equals** **True** |
    | **then** | **Select Product**, указывающий на карточку с триалом |
    | **else** | **Select Product**, указывающий на тот же продукт без триала |

<ZoomImage id="paywall-trial-toggle-conditional-action.webp" width="700px" alt="Триггер On Tap переключателя с условным действием: trial_toggle.isActive Equals True выбирает одну карточку, ветка else — другую" />

## 5. Обновите надпись на кнопке \{#update-the-button-label\}

Призыв к действию должен меняться, когда пробный период включён.

1. Выберите текстовый элемент кнопки.
2. На вкладке **Design** в разделе **Content** выберите **Conditional** и нажмите **Edit conditions**.
3. Заполните блоки:

    | Блок | Что настроить |
    |---|---|
    | **if** | `trial_toggle.isActive` **Equals** **True** |
    | **then** | Текст для пробного периода, например `Start your free trial` |
    | **else** | Стандартный текст, например `Purchase` |

<ZoomImage id="paywall-trial-toggle-button-label.webp" width="500px" alt="The Edit conditional text dialog with trial_toggle.isActive Equals True showing Start your free trial, and Purchase in the else branch" />

Подробнее об условном тексте читайте в разделе [Добавить условный текст](onboarding-text#add-conditional-text).
