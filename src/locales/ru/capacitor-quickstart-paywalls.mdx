Чтобы включить встроенные покупки, нужно понять три ключевых понятия:

- [**Продукты**](product) – всё, что пользователи могут купить (подписки, расходуемые покупки, пожизненный доступ)
- [**Флоу и пейволы**](adapty-flow-builder) – экраны, которые показывают продукты пользователям; создаются в визуальном конструкторе Flow & Paywall Builder без написания кода. SDK получает их через `getFlow`. Если вы предпочитаете строить интерфейс в собственном коде, см. [Реализация кастомных пейволов](capacitor-quickstart-manual).
- [**Плейсменты**](placements) – где и когда показывать флоу и пейволы в приложении (например, `main`, `onboarding`, `settings`). Вы привязываете их к плейсментам в дашборде, а затем запрашиваете по ID плейсмента в коде. Это упрощает запуск A/B-тестов и показ разных вариантов разным пользователям.

Adapty предлагает три способа подключить покупки в вашем приложении. Выберите подходящий в зависимости от требований вашего приложения:

| Реализация | Сложность | Когда использовать |
|---|---|---|
| Adapty Flow & Paywall Builder | ✅ Легко | Вы [создаёте готовый к покупке флоу или пейвол в no-code конструкторе](quickstart-paywalls). Adapty автоматически отображает его и берёт на себя всю сложную логику покупок, валидацию чеков и управление подписками. |
| Кастомные пейволы | 🟡 Средне | Вы реализуете UI пейвола в коде приложения, но всё равно получаете объект флоу от Adapty, сохраняя гибкость в управлении продуктами. См. [гайд](capacitor-quickstart-manual). |
| Observer mode | 🔴 Сложно | У вас уже есть собственная инфраструктура обработки покупок, и вы хотите продолжать её использовать. Обратите внимание, что observer mode имеет свои ограничения в Adapty. См. [статью](observer-vs-full-mode). |

:::important
**Шаги ниже показывают, как реализовать флоу или пейвол, созданный в Adapty Flow & Paywall Builder.**

Если вы предпочитаете создавать UI пейвола самостоятельно, см. [Реализация кастомных пейволов](capacitor-quickstart-manual).
:::

Чтобы отобразить флоу или пейвол, созданный в Adapty Flow & Paywall Builder, в коде приложения вам нужно только:

1. **Получите флоу или пейвол**: Получите его из Adapty.
2. **Отобразите его — Adapty сам обработает покупки**: Покажите экран в своём приложении.
3. **Обработайте действия кнопок**: Свяжите действия пользователя с реакцией вашего приложения. Например, открывайте ссылки или закрывайте пейвол при нажатии кнопок.

## Перед началом работы \{#before-you-start\}

Прежде чем начать, выполните следующие шаги:

1. Подключите приложение к [App Store](initial_ios) и/или [Google Play](initial-android) в дашборде Adapty.
2. [Создайте продукты](create-product) в Adapty.
3. [Создайте флоу или пейвол](paywall-builder-templates) и [добавьте в него продукты](paywall-product-block).
4. [Создайте плейсмент и добавьте в него флоу или пейвол](create-placement).
5. [Установите и активируйте SDK](sdk-installation-capacitor) в коде приложения. В этом гайде используются API Adapty Capacitor SDK v4.

## 1. Получите флоу или пейвол \{#1-get-the-flow-or-paywall\}

Ваши флоу и пейволы привязаны к плейсментам, настроенным в дашборде. Плейсменты позволяют показывать разные флоу или пейволы разным аудиториям, а также запускать [A/B-тесты](ab-tests).

Чтобы получить флоу или пейвол, созданный в Adapty Flow & Paywall Builder, получите объект `flow` по ID [плейсмента](placements) с помощью метода `getFlow`. Флоу содержит элементы UI и стили, необходимые для его отображения.

```typescript showLineNumbers title="Capacitor"

try {
  const flow = await adapty.getFlow({
    placementId: 'YOUR_PLACEMENT_ID',
  });
  // the requested flow
} catch (error) {
  // handle the error
}
```

## 2. Отобразите флоу или пейвол \{#2-display-the-flow-or-paywall\}

Теперь, когда у вас есть флоу, достаточно добавить несколько строк для его отображения.

Создайте `view` с помощью метода `createFlowView`, задайте обработчики событий, затем вызовите `view.present()`. Каждый `view` можно использовать только один раз. Если нужно отобразить флоу снова, вызовите `createFlowView` ещё раз, чтобы создать новый экземпляр `view`.

```typescript showLineNumbers title="Capacitor"

try {
  const view = await createFlowView(flow);

  await view.setEventHandlers({
    onPurchaseCompleted(purchaseResult, product) {
      return purchaseResult.type === 'success'; // close the flow on a successful purchase, keep it open for cancelled or pending purchases
    },
  });

  await view.present();
} catch (error) {
  // handle the error
}
```

:::tip
Подробнее о том, как отображать флоу или пейвол, см. в нашем [гайде](capacitor-present-paywalls).
:::

## 3. Обработка нажатий кнопок \{#handle-button-actions\}

Когда пользователи нажимают кнопки во флоу или пейволе, Capacitor SDK автоматически обрабатывает покупки, восстановление, закрытие экрана и открытие URL.

Однако другие кнопки имеют пользовательские или предустановленные ID и требуют обработки действий в вашем коде. Либо вы можете захотеть переопределить их поведение по умолчанию.

Например, вот поведение по умолчанию для кнопки закрытия. Добавлять его в код не нужно, но здесь вы можете увидеть, как это делается при необходимости.

```typescript showLineNumbers title="Capacitor"
const unsubscribe = await view.setEventHandlers({
  onCloseButtonPress() {
    return true; // allow the flow to close
  },
});
```

:::tip
Читайте наши гайды о том, как обрабатывать [действия кнопок](capacitor-handle-paywall-actions) и [события](capacitor-handling-events).
:::

## Полный пример \{#full-example\}

Вот как все шаги из этого гайда можно объединить в вашем приложении.

```typescript showLineNumbers title="Capacitor"

export async function showFlow() {
  try {
    const flow = await adapty.getFlow({
      placementId: 'YOUR_PLACEMENT_ID',
    });

    const view = await createFlowView(flow);

    await view.setEventHandlers({
      onCloseButtonPress() {
        return true;
      },
      onPurchaseCompleted(purchaseResult, product) {
        return purchaseResult.type === 'success'; // close the flow on a successful purchase, keep it open for cancelled or pending purchases
      },
    });

    await view.present();
  } catch (error) {
    // handle any error that may occur during the process
    console.warn('Error showing flow:', error);
  }
}
```
