## Прежде чем начать \{#before-you-start\}

- Обновите приложение до Adapty Capacitor SDK 4.4 или более поздней версии. В более ранних версиях SDK для каждого кастомного элемента отображается [резервный контент](flow-custom-elements#set-fallback-content).
- Настройте приложение для [получения](capacitor-get-pb-paywalls) и [отображения](capacitor-present-paywalls) флоу.
- Настройте нативный код приложения для кастомных элементов, как описано в [гайде для Capacitor](capacitor-flow-custom-elements#before-you-start).
- На iOS добавьте Lottie в таргет приложения в Xcode с помощью Swift Package Manager, из `https://github.com/airbnb/lottie-spm.git`.
- На Android [настройте Android-проект](capacitor-flow-custom-elements#set-up-your-android-project), включая Jetpack Compose. View для анимации в этом рецепте является composable-компонентом. Добавьте Compose Foundation в приложение через Gradle, из `androidx.compose.foundation:foundation`, без указания версии. Версию задаёт Compose BOM из `io.adapty:android-ui`. Добавьте Lottie для Jetpack Compose из `com.airbnb.android:lottie-compose`.

## 2. Добавьте файл анимации в приложение \{#add-the-animation-file-to-your-app\}

Нативный код читает файл анимации из iOS и Android проектов, а не из ассетов веб-приложения:

- **iOS**: Добавьте файл в таргет приложения в Xcode.
- **Android**: Поместите файл в `android/app/src/main/assets` — папку `assets` модуля Android-приложения. Держите его в корне этой папки, не в подпапке.

Имя файла без `.json` должно совпадать с ID пользовательского элемента, например `streak_ring.json` для `streak_ring`.

## 3. Создайте анимированное представление \{#create-the-animation-view\}

Создайте модель для серии и представление, которое воспроизводит анимацию. Приложение обновляет модель при изменении серии. Представление считывает модель, поэтому кольцо показывает текущую серию при открытии экрана:

<Tabs groupId="platform" queryString>
<TabItem value="ios" label="iOS (Swift)" default>

```swift showLineNumbers title="Swift"

// The streak that your app keeps up to date
@MainActor
final class StreakStore: ObservableObject {
    @Published var currentStreak = 0 // days in a row
}

struct StreakRingView: View {
    let animation: LottieAnimation
    @ObservedObject var streakStore: StreakStore

    // 7 days fill the ring: from 0 for an empty ring to 1 for a full one
    private var progress: AnimationProgressTime {
        min(AnimationProgressTime(streakStore.currentStreak) / 7, 1)
    }

    var body: some View {
        LottieView(animation: animation)
            .resizable()
            .playing(.fromProgress(0, toProgress: progress, loopMode: .playOnce))
    }
}
```

`.playing(.fromProgress(0, toProgress: progress, loopMode: .playOnce))` заполняет кольцо один раз — от пустого до значения `progress`.

</TabItem>
<TabItem value="android" label="Android (Kotlin)">

```kotlin showLineNumbers title="Kotlin"

// the streak that your app keeps up to date
class StreakStore {
    val currentStreak = MutableStateFlow(0) // days in a row
}

@Composable
fun StreakRing(animationFile: String, streakStore: StreakStore) {
    val composition by rememberLottieComposition(LottieCompositionSpec.Asset(animationFile))
    val streak by streakStore.currentStreak.collectAsState()

    // 7 days fill the ring: from 0 for an empty ring to 1 for a full one
    val progress = minOf(streak / 7f, 1f)

    LottieAnimation(
        composition = composition,
        modifier = Modifier.fillMaxSize(), // scale the animation to fit the custom element
        clipSpec = LottieClipSpec.Progress(0f, progress),
    )
}
```

`clipSpec = LottieClipSpec.Progress(0f, progress)` заполняет кольцо один раз, от пустого до `progress`.

## 4. Сопоставьте анимацию с кастомным элементом \{#match-the-animation-to-the-custom-element\}

В вашем [общем резолвере](capacitor-flow-custom-elements#pass-the-resolver-to-the-sdk) добавьте свойство для модели streak. Затем верните представление анимации для типа `lottie_animation` и идентификатора `streak_ring`. Выделенные строки показывают, что нужно добавить или изменить. Если в вашем приложении ещё нет [резолвера](capacitor-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views), скопируйте весь код целиком:

<Tabs groupId="platform" queryString>
<TabItem value="ios" label="iOS (Swift)" default>

```swift showLineNumbers title="Swift" {6,14-18}

struct CustomElementsResolver: AdaptyUICustomElementsResolver {
    let streakStore: StreakStore

    func view(
        forType type: String,
        id: String,
        context: AdaptyUICustomElementContext
    ) -> AnyView? {
        switch type {
        case "lottie_animation" where id == "streak_ring":
            guard let animation = LottieAnimation.named(id) else {
                return nil // no animation file: show the fallback
            }
            return AnyView(StreakRingView(animation: animation, streakStore: streakStore))
        // the other cases of your resolver
        default:
            return nil
        }
    }
}
```

Поставьте case `streak_ring` перед любым другим case `lottie_animation`, потому что Swift выполняет только первый подходящий case. Если в бандле приложения нет файла для данного ID, резолвер возвращает `nil`, и пользователи видят фолбэк.

</TabItem>
<TabItem value="android" label="Android (Kotlin)">

```kotlin showLineNumbers title="Kotlin" {8,22-28}

class CustomElementsResolver(
    context: Context,
    private val streakStore: StreakStore,
) : AdaptyCustomElementsResolver {
    // the animation files in the assets folder, listed once
    private val animationFiles: Set<String> = try {
        context.assets.list("").orEmpty().toSet()
    } catch (e: IOException) {
        emptySet() // no list of files: every Lottie element shows the fallback
    }

    override fun resolve(type: String, id: String): AdaptyCustomElementContent? =
        when (type) {
            "lottie_animation" -> {
                // the ID names the animation file, such as streak_ring.json
                val file = "$id.json"
                when {
                    file !in animationFiles -> null // no file for this ID: show the fallback
                    id == "streak_ring" ->
                        AdaptyCustomElementContent.compose { StreakRing(file, streakStore) }
                    // the other animations of your resolver
                    else -> null
                }
            }
            // the other Types of your resolver
            else -> null
        }
}
```

Если в папке `assets` нет файла для данного ID, резолвер возвращает `null`, и пользователи видят резервный вариант. Если ваш резолвер уже возвращает [представление для каждого файла анимации](capacitor-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views), возвращайте это представление вместо `null`, когда ID не равен `streak_ring`. Так пользователи по-прежнему будут видеть анимации остальных кастомных элементов `lottie_animation`.

</TabItem>
</Tabs>

## 5. Отправьте streak из JavaScript-кода \{#send-the-streak-from-your-javascript-code\}

Ваш JavaScript-код хранит streak, а нативные представления считывают его из модели streak. Чтобы обновить модель, отправьте streak в нативный код через <InlineTooltip tooltip="локальный плагин Capacitor">[iOS](https://capacitorjs.com/docs/ios/custom-code), [Android](https://capacitorjs.com/docs/android/custom-code)</InlineTooltip>. Плагин имеет реализацию для каждой платформы и JavaScript-интерфейс.

Реализуйте плагин для каждой платформы:

<Tabs groupId="platform" queryString>
<TabItem value="ios" label="iOS (Swift)" default>

В целевом объекте `App` в Xcode создайте плагин. Он обновляет модель стрика в вашем классе `AppDelegate`:

```swift showLineNumbers title="StreakStorePlugin.swift"

@objc(StreakStorePlugin)
public class StreakStorePlugin: CAPPlugin, CAPBridgedPlugin {
    public let identifier = "StreakStorePlugin"
    public let jsName = "StreakStore"
    public let pluginMethods: [CAPPluginMethod] = [
        CAPPluginMethod(name: "setStreak", returnType: CAPPluginReturnPromise)
    ]

    @objc func setStreak(_ call: CAPPluginCall) {
        let days = call.getInt("days") ?? 0
        Task { @MainActor in
            (UIApplication.shared.delegate as? AppDelegate)?.streakStore.currentStreak = days
        }
        call.resolve()
    }
}
```

Создайте подкласс `CAPBridgeViewController`, который регистрирует плагин в методе `capacitorDidLoad`. Если в вашем приложении уже есть подкласс `CAPBridgeViewController`, зарегистрируйте плагин там:

```swift showLineNumbers title="MyViewController.swift"

class MyViewController: CAPBridgeViewController {
    override open func capacitorDidLoad() {
        bridge?.registerPluginInstance(StreakStorePlugin())
    }
}
```

Чтобы приложение использовало этот подкласс, в `SceneDelegate.swift` замените `CAPBridgeViewController()` на `MyViewController()`. Если в вашем проекте нет `SceneDelegate.swift`, установите custom class **Bridge View Controller** в `Main.storyboard` как `MyViewController`, как описано в [Custom ViewController](https://capacitorjs.com/docs/ios/viewcontroller).

</TabItem>
<TabItem value="android" label="Android (Kotlin)">

В папке `MainActivity.java` создайте плагин. Он обновляет модель streak в вашем классе `MainApplication`:

```kotlin showLineNumbers title="StreakStorePlugin.kt"
package com.example.app


@CapacitorPlugin(name = "StreakStore")
class StreakStorePlugin : Plugin() {
    @PluginMethod
    fun setStreak(call: PluginCall) {
        val app = context.applicationContext as MainApplication
        app.streakStore.currentStreak.value = call.getInt("days") ?: 0
        call.resolve()
    }
}
```

Чтобы зарегистрировать плагин, в `MainActivity.java` вызовите `registerPlugin` до `super.onCreate`. Выделенные строки показывают, что нужно добавить:

```java showLineNumbers title="MainActivity.java" {3,7-11}
package com.example.app;


public class MainActivity extends BridgeActivity {
    @Override
    public void onCreate(Bundle savedInstanceState) {
        registerPlugin(StreakStorePlugin.class);
        super.onCreate(savedInstanceState);
    }
}
```

</TabItem>
</Tabs>

В своём JavaScript-коде зарегистрируйте плагин. Затем отправляйте стрик при запуске приложения и каждый раз, когда он изменяется:

```typescript showLineNumbers title="sendStreak.ts"

interface StreakStorePlugin {
  setStreak(options: { days: number }): Promise<void>;
}

// the name matches the jsName on iOS and the plugin name on Android
const StreakStore = registerPlugin<StreakStorePlugin>('StreakStore');

// call at app launch, and each time the streak changes
export async function sendStreak(days: number) {
  await StreakStore.setStreak({ days });
}
```
