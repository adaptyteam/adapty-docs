Если вы привлекаете пользователей через веб-воронку или лендинг, веб-пиксель Adapty связывает каждый визит с рекламным объявлением, которое его привело. Пиксель присваивает каждому посетителю идентификатор клика. Когда посетитель совершает оплату, вы передаёте этот идентификатор вместе с транзакцией, и Adapty Attribution сопоставляет покупку с конкретной кампанией, группой объявлений и объявлением.

Пиксель доступен для кампаний Meta Ads и TikTok for Business.

:::note
Если ваша воронка работает на FunnelFox, пиксель не нужен. См. [Интеграция FunnelFox с атрибуцией Adapty](ua-funnelfox).
:::

## Как это работает \{#how-it-works\}

При загрузке страницы пиксель:

- Присваивает посетителю `click_id` и сохраняет его в браузере на 7 дней.
- Считывает рекламные сигналы из URL страницы: идентификаторы кликов Meta (`fbclid`) и TikTok (`ttclid`), идентификаторы и названия кампаний, групп объявлений и объявлений, а также параметры `utm_*`.
- Отправляет `click_id` и собранные сигналы в Adapty в фоновом режиме.

При оформлении заказа вы передаёте транзакции только `click_id`. Adapty сопоставляет его с сигналами, которые уже отправил пиксель, и автоматически определяет рекламный канал.

:::tip
Пиксель отслеживает только посещения из рекламы. Чтобы передавать сами покупки в атрибуцию Adapty, подключите [Stripe](ua-stripe) или [Paddle](ua-paddle).
:::

## Прежде чем начать \{#before-you-start\}

Подключите [Meta Ads](ua-facebook) или [TikTok for Business](ua-tiktok) к атрибуции Adapty и добавьте конфигурацию кампании. Adapty генерирует фрагмент пикселя для каждой конфигурации кампании, поэтому она вам нужна, чтобы скопировать этот фрагмент.

Пиксель считывает данные рекламы из URL вашей посадочной страницы, поэтому ваши объявления должны содержать параметры отслеживания Adapty. Без них Adapty атрибутирует покупку сети, но не кампании, группе объявлений или отдельному объявлению. См. [Разметка URL объявлений для веб-воронок](ua-tag-ad-urls).

## Установка пикселя \{#install-the-pixel\}

1. В Adapty Attribution откройте конфигурацию вашей кампании Meta Ads или TikTok.
2. На вкладке **General** разверните раздел **Web funnel** и скопируйте значение поля **Pixel snippet**.

<ZoomImage id="ua-web-pixel-snippet.webp" width="700px" alt="Pixel snippet field in the Web funnel section of a campaign configuration in Adapty Attribution" />

3. Вставьте сниппет в `<head>` каждой страницы вашей воронки:

```html
<script async src="https://api-ua.adapty.io/pixel/loader.js" data-code="YOUR_CODE"></script>
```

Значение `data-code` идентифицирует ваше приложение и кампанию. Это публичный идентификатор, а не секретный ключ.

## Управление согласием \{#manage-consent\}

Пиксель записывает куки первой стороны и запись в localStorage, а также считывает идентификаторы кликов по рекламе при загрузке страницы. Вы являетесь контролёром данных для вашей воронки и несёте юридическую ответственность за это.

По умолчанию пиксель запускается при загрузке страницы. Чтобы включить его только после получения согласия, добавьте `data-consent="denied"` в сниппет — пиксель не будет ничего сохранять и отправлять, пока вы не предоставите согласие из вашего баннера с куки:

```js
window.adaptyPixel.grantConsent();  // start capture
window.adaptyPixel.revokeConsent(); // clear stored state and stop
window.adaptyPixel.getConsent();    // 'granted' | 'denied'
```

:::warning
Ограничивайте пиксель по согласию для трафика из ЕС/ЕЭЗ. Правила ePrivacy требуют предварительного согласия для хранения данных в браузере, и пиксель атрибуции первой стороны не является исключением.
:::

Сниппет загружается асинхронно, поэтому `window.adaptyPixel` не существует на строке сразу после тега `<script>`. Вызывайте API согласия из колбэка баннера согласия или защитите ранний вызов проверкой `if (window.adaptyPixel) { ... }`.

## Примечания по использованию \{#usage-notes\}

- **Одностраничные воронки**: Клиентская навигация сохраняет тот же `click_id`, поэтому воронка, построенная как одностраничное приложение, работает без дополнительной настройки.
- **Стабильность Click ID**: Чтение `click_id` при загрузке страницы или на этапе оформления заказа возвращает одно и то же значение. Если посетитель заходит в воронку повторно по новому объявлению, побеждает последний клик по рекламе.
- **Продления**: Прикрепляйте `click_id` только к первой транзакции. Атрибуцию конверсий из триала и продлений подписки Adapty отслеживает через саму подписку.
