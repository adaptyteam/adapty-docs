Adapty использует ключ In-App Purchase для проверки покупок в вашем приложении и подписи [promotional offers](offers). Создайте ключ в App Store Connect, а затем введите его в двух разделах **App settings** в Adapty. Если ключ перестал работать или требует замены, [замените его](#replace-the-key).

Ключ для встроенных покупок отличается от [ключа App Store Connect API](app-store-connect-api-key), хотя App Store Connect использует одинаковые названия для идентификаторов обоих ключей: **Issuer ID** и **Key ID**.

Чтобы ввести все учётные данные в **App settings** > **iOS SDK** за один раз, следуйте инструкции [Настройка интеграции с App Store](app-store-connection-configuration).

## Замена ключа \{#replace-the-key\}

Если ключ перестал работать или нужно его обновить, сначала сохраните новый ключ в Adapty, и только потом отзовите старый.

Когда ключ перестаёт работать:

- Покупки в приложении не открывают доступ, при этом приложение не получает никакой ошибки.
- Пользователи не могут активировать promotional offers.
- [Refund Saver](refund-saver) не может отвечать на запросы о потреблении.
- Adapty не показывает предупреждений, а статус в разделе **App Store server notifications** остаётся **Active**.

Когда ваше приложение переходит на другой аккаунт разработчика Apple, [замените ключ на ключ от команды нового владельца](transfer-apps#app-store-ios-transfer).

The input fragment "To replace the key:" contains no code blocks and is a single line of prose. Here is the translation:

Чтобы заменить ключ:

1. В Adapty перейдите в [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). Чтобы определить ключ, который Adapty использует сейчас, в разделе **In-app purchase API (StoreKit 2)** посмотрите значение в поле **Key ID**.
2. [Создайте новый ключ](#generate-the-key-in-app-store-connect).
3. [Добавьте новый ключ в Adapty](#add-the-key-to-adapty) в разделах **In-app purchase API (StoreKit 2)** и **App Store promotional offers**, затем нажмите **Save**.
4. Один ключ обслуживает все приложения вашей команды в App Store Connect. Если другие приложения Adapty используют Key ID из шага 1, добавьте новый ключ и в них. Замените старый ключ на всех своих серверах, где он используется.
5. Отозванный ключ перестаёт работать во всех приложениях, которые его используют, и восстановить его невозможно. В App Store Connect отзовите старый ключ — активный ключ с Key ID из шага 1.

Пользователи, которые совершили покупку в тот момент, когда у Adapty не было рабочего ключа, получат доступ, когда [восстановят покупки](troubleshoot-app-store-integration#a-purchase-succeeds-but-the-customer-loses-access).
