Категория элементов **User Engagement** предоставляет пять шаблонов для размещения отзывов, рейтингов и социального подтверждения на пейволе. Каждый шаблон — это полностью редактируемая композиция: замените текст-заполнитель и примените ваши [стили цветов](builder-styling) и [типографику](onboarding-text) в соответствии с остальной частью флоу.

<ZoomImage id="user-engagement-templates.webp" width="500px" alt="Шаблоны вовлечения пользователей: Review, Review Carousel, Rating, App Rating, Social Proof" />

## Обзор \{#review\}

Карточка с оценкой, цитатой и подписью автора. Используется для демонстрации запоминающейся пользовательской цитаты.

## Карусель с отзывами \{#review-carousel\}

Ряд карточек с отзывами, по которым пользователь листает свайпом, с точками пагинации внизу. Используйте её, чтобы показать несколько цитат, не растягивая экран.

Каждая карточка — это копия элемента «Карточка с отзывом», поэтому редактируйте их по одной на панели **Layers**: раскройте карусель, выберите карточку и замените оценку, цитату и подпись.

## Рейтинг \{#rating\}

Счётчик и строка со звёздами, например «17000+ рейтингов». Используйте, чтобы подчеркнуть количество оценок.

## Рейтинг приложения \{#app-rating\}

Отображает итоговую оценку с указанием количества отзывов, например «4.9 / На основе 1000+ отзывов». Используйте, чтобы подчеркнуть высокий общий рейтинг.

## Социальное доказательство \{#social-proof\}

Группа аватаров с указанием количества участников — например, «Присоединяйтесь к 50 000+ пользователей». Используйте, чтобы подчеркнуть масштаб сообщества.
