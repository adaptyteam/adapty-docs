Adapty Attribution помогает связать расходы на рекламу с доходами от подписок в кампаниях web-to-app, давая полное представление об экономике приложения в одном месте.

Чтобы видеть данные о доходах в Adapty Attribution, сначала нужно включить интеграцию в дашборде Adapty. Передавать API-ключи, токены или идентификаторы не требуется. Просто обновите и настройте SDK.
:::important
Adapty Attribution доступна в:
- iOS, Android и Flutter SDK версии 3.9.1 и выше.
- React Native и Capacitor SDK версии 3.10.0 и выше.
- Unity SDK версии 3.12.0 и выше.
- Kotlin Multiplatform SDK версии 3.15.0 и выше.

Начиная с SDK версии 4.1, Adapty Attribution по умолчанию отключена в SDK. [Включите её в коде вашего приложения](#step-1-enable-adapty-attribution-in-the-sdk).
:::

## Прежде чем начать \{#before-you-start\}

Чтобы связать данные о доходах с эффективностью кампаний, позвольте Adapty отслеживать ваши покупки:
- Если вы **уже реализовали встроенные покупки с помощью Adapty**, на этом этапе ничего дополнительно делать не нужно.
- Если вы **ещё не реализовали встроенные покупки и хотите использовать Adapty**, выполните шаги из [руководства по быстрому старту](quickstart), чтобы делегировать обработку покупок Adapty.
- Если вы **уже реализовали встроенные покупки без Adapty** и не планируете переходить на Adapty, [установите SDK для вашей платформы в режиме наблюдателя](implement-observer-mode). На этом этапе нужно только добавить SDK в проект, активировать его с включённым режимом наблюдателя и передавать транзакции:
Эта настройка обеспечивает атрибуцию из веба в приложение:
- Когда пользователи устанавливают ваше приложение, SDK получает детали установки из параметров ссылки, чтобы Adapty Attribution мог получить данные о кампании
- SDK знает обо всех событиях, связанных с доходом внутри приложения, и может атрибутировать их к веб-кампаниям.
## Шаг 1. Включите Adapty Attribution в SDK \{#step-1-enable-adapty-attribution-in-the-sdk\}

Начиная с версии SDK 4.1, Adapty Attribution отключена по умолчанию. Чтобы SDK мог регистрировать установки и передавать данные об установке в ваше приложение, включите её при активации SDK:

```swift showLineNumbers title="Swift"
let configurationBuilder = AdaptyConfiguration
    .builder(withAPIKey: "YOUR_PUBLIC_SDK_KEY")
    .with(adaptyAttributionEnabled: true)
```

В версиях SDK ниже 4.1 Adapty Attribution включается автоматически — никаких изменений в коде не требуется.

## Шаг 2. Откройте Adapty Attribution \{#step-2-open-adapty-attribution\}

:::important
Если **Attribution** не появляется при нажатии на логотип Adapty, очистите куки и данные сайта для adapty.io в настройках браузера, затем перезагрузите страницу.
:::

Нажмите на логотип Adapty в шапке и выберите **Attribution**.

<ZoomImage id="product-switcher.webp" width="500px" alt="Adapty product switcher" />

События подписок начнут поступать в Adapty Attribution автоматически. Данные о кампаниях появятся после подключения источника данных на шаге 3.

Чтобы приостановить доставку событий, откройте **Integrations > Adapty** в дашборде Adapty и выключите переключатель.

- Пробные периоды (Trials)
- Подписки
- Проблемы (Issues)

## Шаг 3. Подключите рекламную платформу и добавьте ссылки для отслеживания \{#step-3-connect-your-ad-platform-and-add-tracking-links\}

Adapty использует ссылки для отслеживания, чтобы связать установки приложения с данными кампаний.
Такую ссылку нужно указывать в качестве целевого URL в каждой рекламной кампании, которую вы хотите отслеживать в Adapty Attribution.

Если вы запускаете рекламу на нескольких платформах, настройте ссылки для отслеживания для каждой из них отдельно.

Adapty взаимодействует с рекламными платформами двумя способами:

- **Нативные интеграции (Meta Ads, TikTok Ads).** Adapty подключается напрямую к рекламной платформе. Трекинговые ссылки генерируются автоматически, а параметры кампании заполняются динамически в зависимости от того, где используется ссылка. Одну и ту же ссылку можно применять в разных кампаниях, группах объявлений или креативах — Adapty автоматически получит корректные данные о кампании и расходах на рекламу.

- **Только трекинговые ссылки (все остальные рекламные платформы).** Adapty не подключается к рекламной платформе. Трекинговые ссылки создаются вручную, и все параметры кампании должны быть заданы явно при создании ссылки. Данные о расходах на рекламу для этих платформ недоступны.

Чтобы создать трекинговую ссылку для Meta Ads:
1. Перейдите в [Integrations > Meta](https://app.adapty.io/ua/integrations/facebook/accounts) в дашборде Adapty Attribution и нажмите **Continue with Facebook**.

<ZoomImage id="ua-connect-meta.webp" width="700px" />

<ZoomImage id="ua-fb-sign.webp" width="500px" />

3. Ознакомьтесь с запрашиваемыми разрешениями и нажмите **Save**.
4. Перейдите на вкладку **Web campaigns** и нажмите **Create campaign**. Выберите приложение и нажмите **Save**.

<ZoomImage id="ua-new-campaign.webp" width="500px" />

5. На вкладке **General** раскройте раздел **iOS** и/или **Android** и вставьте URL приложения из App Store и/или Google Play. Затем нажмите **Save**.

<ZoomImage id="ua-url.webp" width="900px" />

6. Скопируйте значение поля **Click link** для **одной ссылки** или для ссылки под конкретную платформу. Затем откройте ваше объявление в Meta Ads Manager и вставьте эту ссылку в качестве URL назначения.

:::important
В поле **Website URL** вставьте `https://api-ua.adapty.io/api/v1/attribution/click`. Остальную часть ссылки вставьте в поле **URL parameters** в разделе **Tracking**. Это поможет вашему объявлению в Meta пройти модерацию. Подробнее см. [рекомендации по настройке объявлений в Meta Ads Manager](meta-create-campaign).

    Если вы предпочитаете использовать отдельные URL перенаправления для каждой платформы, снимите флажок **One Link** и укажите ссылки на сторы для каждой платформы вручную.

## Шаг 4. Запустите кампанию web-to-app и посмотрите результаты \{#step-4-launch-your-web-to-app-campaign-and-view-results\}

Как только кампания запущена и пользователи начинают устанавливать приложение, Adapty начинает атрибутировать установки и доходы вашим кампаниям.

В [дашборде аналитики атрибуции Adapty](ua-analytics) вы увидите метрики на уровне кампании:
- Установки и конверсии
- Доходы от подписок и покупок
- Разбивка по рекламным платформам, кампаниям, группам объявлений и креативам

Метрики появляются сразу после получения событий установки и дохода из вашего приложения. Данные о рекламных расходах доступны для платформ с нативными интеграциями.
