Adapty читает ваши продукты, валидирует покупки и получает события подписки через следующие API Google:

- Google Play Android Developer API
- Google Play Developer Reporting API
- Cloud Pub/Sub API

## Перед началом \{#before-you-start\}

Убедитесь, что у вас есть [необходимые права доступа и проект Google Cloud для интеграции с Google Play](initial-android#before-you-start). Без них выполнить описанные ниже шаги не получится.

## Включение API \{#enable-the-apis\}

1. Откройте [Google Cloud Console](https://console.cloud.google.com/).

2. Выберите проект, который будете использовать для интеграции.

3. Откройте страницу [**Google Play Android Developer API**](https://console.cloud.google.com/apis/library/androidpublisher.googleapis.com).

4. Нажмите **Enable** и дождитесь, пока статус не изменится на **Enabled**. Если вместо этого отображается кнопка **Manage**, API уже включён и никаких действий не требуется.

   <ZoomImage id="gp-api-library-enable.webp" width="700px" alt="An API page in the Google Cloud API library, with the Enable button" />

5. Откройте страницу [**Google Play Developer Reporting API**](https://console.cloud.google.com/apis/library/playdeveloperreporting.googleapis.com).

6. Нажмите **Enable** и дождитесь, пока статус не изменится на **Enabled**.

7. Откройте страницу [**Cloud Pub/Sub API**](https://console.cloud.google.com/apis/library/pubsub.googleapis.com).

8. Нажмите **Enable** и дождитесь, пока статус не изменится на **Enabled**.

Для подтверждения откройте страницу [**APIs & Services**](https://console.cloud.google.com/apis/dashboard) в Google Cloud Console. В таблице внизу перечислены все активированные в проекте API — все три должны присутствовать:

- Google Play Android Developer API
- Google Play Developer Reporting API
- Cloud Pub/Sub API

<ZoomImage id="gp-apis-enabled-list.webp" width="700px" alt="Таблица включённых API и сервисов со всеми тремя необходимыми API" />
