Este inicio rápido configura una moneda de tokens de principio a fin: una suscripción mensual otorga a los usuarios 1000 tokens en cada período de facturación, y las acciones de pago en tu app cuestan tokens. Adapty gestiona todos los saldos, así que tu backend solo necesita leerlos y gastarlos.

1. Sigue la guía [Crear moneda virtual](create-virtual-currency) para crear una moneda `TOKENS`. Vincúlala a tu suscripción Pro y establece **Credit per cycle** en 1000. Adapty concede el **Credit per cycle** una vez por cada período de facturación de la suscripción: cada mes para una suscripción mensual, cada semana para una semanal. Para vender tokens adicionales, vincula también productos de paquetes de tokens de compra única.

   <ZoomImage id="new-currency-combined.webp" width="700px" alt="Pantallas de creación de nueva moneda virtual" />

2. Llama a [List virtual currency balances](api-adapty/operations/listVirtualCurrencyBalances) para leer el saldo del usuario, por ejemplo, antes de iniciar una generación:

   ```bash title="Read balances"
   curl https://api.adapty.io/api/v2/server-side-api/vc/balances/ \
     -H "Authorization: Api-Key {your secret key}" \
     -H "adapty-customer-user-id: user-42"
   ```

   La respuesta lista todas las monedas de tu app, incluidas las que tienen saldo 0. Por ejemplo, 1000 `TOKENS`:

   ```json title="Response"
   {
     "response_created_at": 1794477600123,
     "data": [
       {
         "code": "TOKENS",
         "name": "Tokens",
         "balance": 1000,
         "held": 0,
         "available": 1000,
         "expiry": { "non_expiring": 1000, "expiring": [], "expiring_later": 0, "expired": 0 }
       }
     ]
   }
   ```
3. Cuando el usuario ejecute una generación, gasta los tokens llamando a [Crear transacción de moneda virtual](api-adapty/operations/createVirtualCurrencyTransaction) con un `amount` negativo. En este ejemplo, generar una imagen cuesta 100 tokens. Para indicar en qué se gastaron los tokens, la solicitud también define `operation` como `spend` y `feature` como `image_generation` (consulta [Etiquetar transacciones](virtual-currencies#label-transactions)):

   ```bash title="Spend tokens"
   curl -X POST https://api.adapty.io/api/v2/server-side-api/vc/transactions/ \
     -H "Authorization: Api-Key {your secret key}" \
     -H "adapty-customer-user-id: user-42" \
     -H "Content-Type: application/json" \
     -d '{
           "items": [{"currency_code": "TOKENS", "amount": -100}],
           "operation": "spend",
           "feature": "image_generation"
         }'
   ```

   La transacción es atómica y devuelve el saldo actualizado. Una transacción puede cambiar hasta 20 divisas, cada una indicada una sola vez en `items`. Si el usuario no puede cubrir el coste, la solicitud devuelve `insufficient_balance` y no se modifica nada. Incluye una cabecera `Idempotency-Key` para reintentar solicitudes de forma segura. Para abrir un flow de recarga cuando el saldo no puede cubrir un gasto, consulta la guía para [iOS](ios-virtual-currency-top-up).
4. Para ejecutar una oferta de recuperación, concede tokens a través del mismo endpoint con un `amount` positivo. Los créditos que concedas de esta forma no caducan nunca. Para dar saldo a los usuarios antes de su primera compra, consulta [Conceder un saldo inicial](grant-initial-balance).
5. Revisa cada cambio en el [perfil](virtual-currency-balance) del usuario o en el [historial de transacciones](api-adapty/operations/listVirtualCurrencyTransactions) para poder auditar la economía en cualquier momento.
