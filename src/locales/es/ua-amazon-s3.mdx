La integración de Adapty Attribution con Amazon S3 te permite almacenar los datos de campañas de adquisición de usuarios de forma segura en un único lugar centralizado. Adapty Attribution guarda archivos .csv en tu bucket de Amazon S3. Cada fila corresponde a una instalación de la app, con sus identificadores de dispositivo y datos de atribución, como el canal y la campaña. Los archivos no contienen datos de gasto publicitario, ingresos ni compras.

Para configurar esta integración, deberás seguir unos sencillos pasos en la consola de AWS y en el dashboard de Adapty Attribution.

:::note
Adapty Attribution exporta un conjunto de archivos por día natural. El programador de exportaciones se ejecuta tres veces al día: a las **02:00**, **04:00** y **06:00 UTC**. Cada ejecución crea el trabajo de exportación del día anterior si aún no existe, o lo reintenta si una ejecución anterior falló. Por lo tanto, tus datos suelen estar disponibles tras la ejecución de las 02:00, y las ejecuciones posteriores sirven para recuperarse de fallos, no para añadir datos.

Cada exportación abarca las instalaciones que Adapty Attribution registró durante el día natural anterior en UTC. Por ejemplo, la exportación del 8 de marzo contiene las instalaciones registradas el 7 de marzo, de 00:00:00 a 23:59:59 UTC.

Cada archivo muestra la atribución en el momento de la exportación. Durante los 30 días siguientes a una instalación, Adapty Attribution puede reasignarla a otro canal o campaña. Para actualizar archivos anteriores con la atribución actual, [ejecuta una exportación manual](#manual-data-export) para esas fechas.
:::

:::warning
La exportación programada solo se ejecuta para empresas con un plan de pago o en período de prueba. Si tu empresa no cumple ninguna de estas condiciones, el programador la omite y no escribe ningún archivo, aunque la integración siga habilitada en el dashboard. Si tu bucket está vacío y la configuración parece correcta, comprueba primero el estado de tu plan.
:::

## Cómo configurar la integración con Amazon S3 \{#how-to-set-up-amazon-s3-integration\}

Para empezar a recibir datos, necesitarás las siguientes credenciales:

1. Access key ID
2. Secret access key
3. Nombre del bucket de S3
4. Nombre de la carpeta dentro del bucket de S3

:::note
Directorios anidados

Puedes especificar directorios anidados en el campo del nombre del bucket de Amazon S3, p. ej. adapty-ua-events/com.sample-app
:::

### Paso 1. Crear credenciales de Amazon S3 \{#step-1-create-amazon-s3-credentials\}

Esta guía te ayudará a crear las credenciales necesarias en tu AWS Console.

#### 1.1. Crear política de acceso \{#11-create-access-policy\}

1. Ve al [IAM Policy Dashboard](https://us-east-1.console.aws.amazon.com/iamv2/home?region=us-east-1#/policies) en tu AWS Console
2. Selecciona la opción **Create Policy**

```json showLineNumbers title="Json"
        }
    ]
}
```

### Paso 2. Configurar la integración en Adapty Attribution \{#step-2-configure-integration-in-adapty-attribution\}

1. Ve a [**Integrations** -> **Amazon S3**](https://app.adapty.io/ua/integrations/s3)
2. Activa el toggle **Export install events to Amazon S3**.
3. Rellena los siguientes campos para establecer la conexión entre Amazon S3 y los perfiles de Adapty Attribution:

| Campo                        | Descripción                                                  |
|:-----------------------------| :----------------------------------------------------------- |
| **Access Key ID**            | Un identificador único que se usa para autenticar el acceso de un usuario o aplicación a un servicio de AWS. Encuéntralo en el [archivo csv](ua-amazon-s3#step-1-create-amazon-s3-credentials) descargado. |
| **Secret Access Key**        | Una clave privada que se usa junto con el Access Key ID para autenticar el acceso de un usuario o aplicación a un servicio de AWS. Encuéntrala en el [archivo csv](ua-amazon-s3#step-1-create-amazon-s3-credentials) descargado. |
| **S3 Bucket Name**           | Un nombre único global que identifica un bucket S3 específico dentro de la nube de AWS. Los buckets S3 son un servicio de almacenamiento simple que permite a los usuarios guardar y recuperar objetos de datos, como archivos e imágenes, en la nube. |
| **Folder Inside the Bucker** | El nombre de la carpeta que quieres tener dentro del bucket S3 seleccionado. Ten en cuenta que S3 simula carpetas mediante prefijos de clave de objeto, que son esencialmente nombres de carpeta. |
| **Region** (Opcional)         | Obtén tu región desde la consola de administración de AWS en tu cuenta de usuario IAM.                                                                                                                                                                                  |

## Exportación manual de datos \{#manual-data-export\}

Para exportar datos de fechas anteriores, en la sección **Manual file export**, selecciona un rango de fechas y haz clic en **Export to S3**. Si tu bucket ya tiene archivos para esas fechas, Adapty Attribution los reemplaza.

## Estructura de la tabla \{#table-structure\}

Cada archivo tiene una fila por instalación que Adapty Attribution registró durante un día UTC, junto con los datos del dispositivo y la atribución. Los archivos no contienen datos de gasto publicitario, ingresos ni compras.

:::warning
Ten en cuenta que esta estructura puede crecer con el tiempo, ya que podemos añadir nuevos datos nosotros mismos o a través de los terceros con los que trabajamos. Asegúrate de que el código que lo procesa sea lo suficientemente robusto y se base en campos específicos, no en la estructura en su conjunto.
:::

Los archivos tienen las siguientes columnas:

| Columna                  | Descripción                               |
|--------------------------|-------------------------------------------|
| `adapty_profile_id`      | Identificador único del perfil de Adapty  |
| `install_id`             | Identificador único de instalación        |
| `created_at`             | Marca de tiempo de creación del registro (ISO 8601) |
| `installed_at`           | Marca de tiempo de instalación de la app (ISO 8601) |
| `store`                  | Store de la app (`ios`, `android`)        |
| `country`                | Código de país del usuario (ISO 3166-1 alpha-2) |
| `ip_address`             | Dirección IP del cliente                  |
| `idfa`                   | Identificador de Publicidad de iOS (IDFA) |
| `idfv`                   | Identificador para Vendedores de iOS (IDFV) |
| `gaid`                   | ID de Publicidad de Google (Android)      |
| `android_id`             | ID de dispositivo Android                 |
| `app_set_id`             | Android App Set ID                        |
| `bundle_id`              | Identificador del bundle de la app (p. ej., `com.example.app`) |
| `device_brand`           | Marca del dispositivo (p. ej., `Apple`, `Samsung`) |
| `device_model`           | Modelo del dispositivo (p. ej., `iPhone15,2`) |
| `os_version`             | Versión principal del sistema operativo   |
| `app_version`            | Versión de la app reportada por el SDK de Adapty |
| `sdk_version`            | Versión del SDK de Adapty                 |
| `channel`                | Canal de atribución                       |
| `campaign_id`            | Identificador de campaña                  |
| `campaign_name`          | Nombre de la campaña                      |
| `adset_id`               | Identificador del conjunto de anuncios    |
| `adset_name`             | Nombre del conjunto de anuncios           |
| `ad_id`                  | Identificador del anuncio                 |
| `ad_name`                | Nombre del anuncio                        |
| `keyword_id`             | Identificador de palabra clave            |
| `keyword_name`           | Nombre de la palabra clave                |
| `asa_org_id`             | ID de organización de Apple Search Ads    |
| `asa_keyword_match_type` | Tipo de concordancia de palabra clave de ASA (`Exact`, `Broad`) |
| `asa_attribution`        | Datos de atribución de ASA (cadena JSON)  |
| `asa_conversion_type`    | Tipo de conversión de ASA                 |
| `asa_country_or_region`  | País o región de ASA                      |
| `asa_creative_set_name`  | Nombre del conjunto creativo de ASA       |
| `fbclid`                 | ID de clic de Facebook                    |
| `ttclid`                 | ID de clic de TikTok                      |
| `utm_source`             | Parámetro de fuente UTM                   |
| `utm_medium`             | Parámetro de medio UTM                    |
| `utm_campaign`           | Parámetro de campaña UTM                  |
| `utm_term`               | Parámetro de término UTM                  |
| `utm_content`            | Parámetro de contenido UTM                |
| `click_time`             | Marca de tiempo del clic atribuido, en segundos Unix. Vacío cuando no hay ningún clic atribuido a la instalación. |
| `asa_click_time`         | Marca de tiempo del tap de Apple Search Ads previo a la instalación, en segundos Unix, redondeado al minuto. Vacío cuando Apple Search Ads no reporta ningún tap para la instalación. A diferencia de `click_time`, tiene valor incluso si la atribución de Adapty le asigna la instalación a otro canal. |
