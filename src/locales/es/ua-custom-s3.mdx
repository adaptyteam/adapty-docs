La integración de Adapty Attribution con almacenamiento compatible con S3 personalizado te permite guardar de forma segura los datos de campañas de adquisición de usuarios en tu propia solución de almacenamiento compatible con S3. Adapty Attribution guarda archivos .csv en tu bucket de S3 personalizado. Cada fila corresponde a una instalación de la app, con sus identificadores de dispositivo y datos de atribución, como el canal y la campaña. Los archivos no contienen datos de gasto publicitario, ingresos ni compras.

Para configurar esta integración, deberás seguir unos sencillos pasos en la consola de tu almacenamiento compatible con S3 y en el dashboard de Adapty Attribution.

:::note
Adapty Attribution exporta un conjunto de archivos por día natural. El programador de exportaciones se ejecuta tres veces al día: a las **02:00**, **04:00** y **06:00 UTC**. Cada ejecución crea el trabajo de exportación del día anterior si aún no existe, o lo reintenta si una ejecución anterior falló. Por lo general, tus datos estarán disponibles tras la ejecución de las 02:00; las ejecuciones posteriores están pensadas para recuperarse de fallos, no para agregar datos nuevos.

Cada exportación cubre las instalaciones que Adapty Attribution registró durante el día calendario anterior en UTC. Por ejemplo, la exportación del 8 de marzo contiene las instalaciones registradas el 7 de marzo, de 00:00:00 a 23:59:59 UTC.

Cada archivo muestra la atribución en el momento de la exportación. Durante hasta 30 días después de una instalación, Adapty Attribution puede reasignar la instalación a otro canal o campaña. Para actualizar archivos antiguos con la atribución actual, [ejecuta una exportación manual](#manual-data-export) para esas fechas.
:::

:::warning
La exportación programada solo se ejecuta para empresas con un plan de pago o en período de prueba. Si tu empresa no cumple ninguna de las dos condiciones, el programador la omite y no escribe ningún archivo, aunque la integración siga habilitada en el dashboard. Si tu bucket está vacío y la configuración parece correcta, comprueba primero el estado de tu plan.
:::

## Configurar la integración de Custom S3 \{#set-up-custom-s3-integration\}

Para empezar a recibir datos, configura la integración en Adapty Attribution:

1. Ve a [**Integrations** -> **Custom S3**](https://app.adapty.io/ua/integrations/custom-s3)
2. Activa el toggle **Export install events to custom S3**.
3. Rellena los campos obligatorios para establecer la conexión entre tu almacenamiento Custom S3 y los perfiles de Adapty Attribution.

| Campo | Descripción |
|:----------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Access Key ID** | Identificador único que se utiliza para autenticar el acceso de un usuario o aplicación a tu servicio de almacenamiento compatible con S3. Encuéntralo en la consola de tu proveedor de almacenamiento. |
| **Secret Access Key** | Clave privada que se usa junto con el Access Key ID para autenticar el acceso de un usuario o aplicación a tu servicio de almacenamiento compatible con S3. Encuéntrala en la consola de tu proveedor de almacenamiento. |
| **S3 Bucket Name** | Nombre único a nivel global que identifica un bucket S3 específico dentro de tu entorno de almacenamiento. Los buckets S3 son un servicio de almacenamiento simple que permite guardar y recuperar objetos de datos, como archivos e imágenes, en la nube. |
| **Region** (Opcional) | Obtén tu región desde la consola de administración. |
| **Folder Inside the Bucket** (Opcional) | Nombre de la carpeta que deseas crear dentro del bucket S3 seleccionado. Ten en cuenta que S3 simula carpetas mediante prefijos de clave de objeto, que son esencialmente nombres de carpeta. |
| **Custom Endpoint URL** | URL del endpoint para tu servicio de almacenamiento compatible con S3. Tu proveedor de almacenamiento debe facilitártela (por ejemplo, MinIO, DigitalOcean Spaces, Wasabi, etc.). |

:::note
También puedes especificar directorios anidados en el campo del nombre del bucket de S3, por ejemplo, `adapty-ua-events/com.sample-app`
:::

## Exportación manual de datos \{#manual-data-export\}

Para exportar datos de fechas anteriores, en la sección **Manual file export**, selecciona un rango de fechas y haz clic en **Export to S3**. Si tu bucket ya tiene archivos para esas fechas, Adapty Attribution los reemplaza.

## Estructura de la tabla \{#table-structure\}

Cada archivo tiene una fila por cada instalación que registró la atribución de Adapty durante un día UTC, junto con los datos de dispositivo y de atribución. Los archivos no contienen datos de gasto publicitario, ingresos ni compras.

:::warning
Ten en cuenta que esta estructura puede crecer con el tiempo, con nuevos datos introducidos por nosotros o por terceros con los que trabajamos. Asegúrate de que el código que la procesa sea lo suficientemente robusto y se base en campos específicos, no en la estructura en su conjunto.
:::

Los archivos tienen las siguientes columnas:

| Columna                  | Descripción                               |
|--------------------------|-------------------------------------------|
| `adapty_profile_id`      | Identificador único de perfil de Adapty   |
| `install_id`             | Identificador único de instalación        |
| `created_at`             | Marca de tiempo de creación del registro (ISO 8601) |
| `installed_at`           | Marca de tiempo de instalación de la app (ISO 8601) |
| `store`                  | Store de la app (`ios`, `android`)        |
| `country`                | Código de país del usuario (ISO 3166-1 alpha-2) |
| `ip_address`             | Dirección IP del cliente                  |
| `idfa`                   | Identificador para anunciantes de iOS     |
| `idfv`                   | Identificador para proveedores de iOS     |
| `gaid`                   | Google Advertising ID (Android)           |
| `android_id`             | ID de dispositivo Android                 |
| `app_set_id`             | Android App Set ID                        |
| `bundle_id`              | Identificador de bundle de la app (p. ej., `com.example.app`) |
| `device_brand`           | Marca del dispositivo (p. ej., `Apple`, `Samsung`) |
| `device_model`           | Modelo del dispositivo (p. ej., `iPhone15,2`) |
| `os_version`             | Versión principal del sistema operativo   |
| `app_version`            | Versión de la app reportada por el SDK de Adapty |
| `sdk_version`            | Versión del SDK de Adapty                 |
| `channel`                | Canal de atribución                       |
| `campaign_id`            | Identificador de campaña                  |
| `campaign_name`          | Nombre de campaña                         |
| `adset_id`               | Identificador de conjunto de anuncios     |
| `adset_name`             | Nombre del conjunto de anuncios           |
| `ad_id`                  | Identificador de anuncio                  |
| `ad_name`                | Nombre del anuncio                        |
| `keyword_id`             | Identificador de palabra clave            |
| `keyword_name`           | Nombre de palabra clave                   |
| `asa_org_id`             | ID de organización de Apple Search Ads    |
| `asa_keyword_match_type` | Tipo de coincidencia de palabra clave de ASA (`Exact`, `Broad`) |
| `asa_attribution`        | Datos de atribución de ASA (cadena JSON)  |
| `asa_conversion_type`    | Tipo de conversión de ASA                 |
| `asa_country_or_region`  | País o región de ASA                      |
| `asa_creative_set_name`  | Nombre del conjunto creativo de ASA       |
| `fbclid`                 | Facebook Click ID                         |
| `ttclid`                 | TikTok Click ID                           |
| `utm_source`             | Parámetro de fuente UTM                   |
| `utm_medium`             | Parámetro de medio UTM                    |
| `utm_campaign`           | Parámetro de campaña UTM                  |
| `utm_term`               | Parámetro de término UTM                  |
| `utm_content`            | Parámetro de contenido UTM                |
| `click_time`             | Marca de tiempo del clic atribuido, en segundos Unix. Vacío cuando no hay ningún clic atribuido a la instalación. |
| `asa_click_time`         | Marca de tiempo del tap en Apple Search Ads antes de la instalación, en segundos Unix, redondeada al minuto. Vacío cuando Apple Search Ads no reporta ningún tap para la instalación. A diferencia de `click_time`, tiene valor incluso si la atribución de Adapty asigna la instalación a otro canal. |
