Cada vez que un usuario abre una pantalla de un [flow](adapty-flow-builder), el SDK reporta un evento `flow_screen_showed` a tu app. Reenvíalo a Amplitude, Mixpanel o a cualquier herramienta de analíticas de producto que uses, para poder analizar las pantallas del flow junto con el resto de los eventos de tu app.

:::tip
Para ver hasta dónde llegan los usuarios en un flow, no necesitas ningún código — las [métricas de flow](flow-metrics) ya muestran vistas, finalizaciones y abandono por pantalla en el Adapty Dashboard. Usa esta guía cuando necesites esos mismos datos en tu propio sistema de analítica, combinados con eventos que Adapty no conoce.
:::

## Antes de empezar \{#before-you-start\}

Necesitas:

- **Adapty Flutter SDK v4 o posterior**: El callback de análisis de flow no existe en versiones anteriores.
- **Una versión del flow publicada después de que se lanzara esta función**: Adapty genera los eventos de pantalla al publicar un flow, por lo que un flow publicado antes de entonces no reportará nada. Si no llegan eventos a tu app, publica una nueva versión del flow e inténtalo de nuevo.

## Qué recibes \{#what-you-receive\}

<FlowScreenShowedParams />

Las vistas de pantalla llegan al mismo callback de analíticas que el resto de eventos del flow. Consulta [Gestionar eventos de flow y paywall](flutter-handling-events) para saber dónde registrarlo.

## Reenvía cada vista de pantalla a tu sistema de analíticas \{#forward-every-screen-view-to-your-analytics\}

Comprueba primero el nombre del evento antes de leer cualquier otro dato, ya que un flow reporta otros eventos a través del mismo callback.

```dart showLineNumbers title="Flutter"
void flowViewDidReceiveAnalyticEvent(
  AdaptyUIFlowView view,
  String name,
  Map<String, dynamic> params,
) {
  if (name != 'flow_screen_showed') return;

  final screenId = params['instanceId'];
  final screenOrder = params['screen_order'];

  // Send screenId and screenOrder to your analytics provider here.
}
```

## Ejecutar código cuando el usuario llega al final \{#run-code-when-a-user-reaches-the-end\}

`is_last_screen` es `true` en una pantalla a partir de la cual el flow no puede avanzar. Úsalo para desbloquear contenido, marcar el onboarding como completado o enviar un evento de finalización propio, sin necesidad de añadir una acción de botón en el builder.

```dart showLineNumbers title="Flutter"
void flowViewDidReceiveAnalyticEvent(
  AdaptyUIFlowView view,
  String name,
  Map<String, dynamic> params,
) {
  if (name != 'flow_screen_showed') return;
  if (params['is_last_screen'] != true) return;

  // The user reached the end of the flow.
}
```

Llegar a la última pantalla no es lo mismo que cerrar el flow. Un usuario puede ver la pantalla final y cerrar el flow sin interactuar con él, y un flow con ramificaciones puede terminar en varias pantallas distintas. Para saber cuándo el flow en sí desaparece, usa `flowViewDidDisappear` en su lugar.
