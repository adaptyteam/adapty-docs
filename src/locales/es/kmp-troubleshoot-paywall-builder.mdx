Esta guía te ayuda a resolver problemas comunes al usar paywalls diseñados en el Adapty Paywall Builder con el SDK de Kotlin Multiplatform. Para problemas con flows, consulta [Problemas comunes](flow-common-issues).

## La obtención de la configuración del paywall falla \{#getting-a-paywall-configuration-fails\}

**Problema**: El método `createFlowView` no consigue crear una vista, o el flow no tiene una configuración de vista.

**Motivo**: El paywall no está habilitado para mostrarse en el dispositivo en el Paywall Builder.

**Solución**: Activa el interruptor **Show on device** en el Paywall Builder. También puedes leer la propiedad `hasViewConfiguration` del objeto `AdaptyFlow` para comprobar si hay una configuración de vista disponible.

## El número de visualizaciones del paywall es demasiado alto \{#the-paywall-view-number-is-too-big\}

**Problema**: El recuento de visualizaciones del paywall muestra el doble del número esperado.

**Motivo**: Es posible que estés llamando a `logShowFlow` (SDK v4+) / `logShowPaywall` en tu código, lo que duplica el recuento de visualizaciones de un paywall creado en el antiguo Paywall Builder. Adapty realiza ese seguimiento automáticamente, por lo que no necesitas este método.

**Solución**: Asegúrate de no estar llamando a `logShowFlow` (SDK v4+) / `logShowPaywall` en tu código para un paywall creado en el antiguo Paywall Builder.
