El plugin de Adapty enseña a tu herramienta de IA a trabajar con Adapty. Instálalo en Claude Code, Codex, Cursor, otro agente de codificación o claude.ai, y luego pídele en lenguaje natural: integrar el SDK, construir un paywall, averiguar por qué cayeron los ingresos o iniciar una prueba A/B. El plugin es un conjunto de skills: flujos de trabajo probados, uno para cada tipo de tarea. Es el único producto que instalas. Se conecta a tu cuenta de Adapty a través del servidor MCP de Adapty o la CLI de Adapty, y en Claude Code y Codex añade el servidor MCP automáticamente, así que solo tienes que iniciar sesión.

## Qué añade el plugin \{#what-the-plugin-adds\}

Una herramienta de IA puede acceder a tu cuenta de Adapty a través del [servidor MCP de Adapty](adapty-mcp) o la [CLI de Adapty](developer-cli-quickstart). Ese acceso le permite leer y modificar tus datos. El plugin le proporciona el conocimiento necesario para hacerlo correctamente:

- **Reglas de configuración de flows**: Un flow es un JSON de configuración extenso con reglas que solo existen en el plugin. Con ellas, tu herramienta construye pantallas a partir de una descripción o una captura de pantalla, y valida y previsualiza cada cambio antes de guardar el flow. Sin ellas, tu herramienta puede leer y escribir la configuración de un flow, pero no puede construir uno válido.
- **Métodos probados**: El plugin sabe qué informes responden a cada pregunta, cómo leerlos y cómo se comparan tus números con el mercado. Convierte tus números en hipótesis para pruebas A/B, ordenadas por el impacto en ingresos.
- **APIs actuales de Adapty**: Al integrar el SDK, el plugin lee la documentación actualizada de Adapty en cada etapa, así que tu herramienta escribe código para la versión del SDK que instalas, no para la que recuerda de sus datos de entrenamiento.
- **Confirmación antes de cambios que lleguen a tus usuarios**: Antes de iniciar una prueba A/B, cambiar un placement o enviar correos a personas reales, el plugin te muestra qué va a cambiar y espera tu confirmación.
- **Conexión**: El plugin detecta si tu herramienta tiene el servidor MCP, la CLI o ambos, y elige el que mejor se adapta a cada tarea.

## Instalar el plugin \{#install-the-plugin\}

<Tabs groupId="ai-tool">
<TabItem value="coding-agent" label="Coding agent" default>

El plugin funciona en cualquier agente de codificación que soporte skills: Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI y otros.

Para instalar el plugin, ejecuta en tu terminal:

```bash
npx adapty skills install
```

Reinicia tu agente para cargar el plugin. Para otros métodos de instalación, consulta el [README del plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Claude Code no actualiza el plugin por sí solo. Para recibir nuevos skills a medida que se publican, en Claude Code ejecuta `/plugin`, abre **Marketplaces**, selecciona `adapty` y elige **Enable auto-update**.

En Claude Code y Codex, el plugin también añade el servidor MCP de Adapty, así que solo tienes que iniciar sesión, como se describe en [Conecta tu asistente](adapty-mcp#connect-your-assistant). En otros agentes, la primera vez que un skill necesita tu cuenta, el plugin pregunta si prefieres usar el CLI de Adapty o el servidor MCP y te indica los pasos para configurar el que elijas.

</TabItem>

<TabItem value="claude-ai" label="claude.ai">

Instala el plugin desde los ajustes de Claude, sin línea de comandos. Los pasos son los mismos en Claude desktop.

1. En Claude, abre **Settings** → **Plugins**.
2. Haz clic en **Add** → **Add marketplace**.
3. Selecciona **Add from a repository**.
4. En el campo **URL**, escribe `adaptyteam/adapty-skills` y selecciona el repositorio. Para recibir nuevos skills y correcciones a medida que se publiquen, mantén activada la opción **Sync automatically**.
5. Haz clic en **Sync**.

<ZoomImage id="adapty-skills-claude-add-marketplace.png" width="584px" alt="Add marketplace dialog in Claude with adaptyteam/adapty-skills in the URL field and Sync automatically turned on" />

Claude abre la pestaña **Discover** con los plugins del marketplace de Adapty. Para instalar el plugin, en la fila **Adapty**, haz clic en **Add**.

<ZoomImage id="adapty-skills-claude-discover.png" width="600px" alt="Discover tab in Claude listing the Adapty, Apple ads, and Apple ads benchmarks plugins, each with an Add button" />

El plugin ejecuta sus scripts en el sandbox de Claude. Para permitirlo, en **Settings** → **Capabilities**, activa **Code execution and file creation**.

Para que Claude pueda acceder a tu cuenta de Adapty, añade el servidor Adapty MCP como conector e inicia sesión, tal como se describe en [Conecta tu asistente](adapty-mcp#connect-your-assistant).

## Qué puedes hacer \{#what-you-can-do\}

No necesitas indicar ningún skill. Pregunta como le explicarías algo a un compañero, y el plugin elige el flujo de trabajo.

### Integrar el SDK \{#integrate-the-sdk\}

```
Integrate Adapty into my app
```

El plugin configura tu app en el Adapty Dashboard, instala el SDK, añade un paywall y verifica cada etapa antes de continuar. Detecta tu plataforma automáticamente. Consulta la guía para [iOS](adapty-sdk-integration-skill), [Android](adapty-sdk-integration-skill-android), [React Native](adapty-sdk-integration-skill-react-native), [Flutter](adapty-sdk-integration-skill-flutter), [Unity](adapty-sdk-integration-skill-unity), [Kotlin Multiplatform](adapty-sdk-integration-skill-kmp) o [Capacitor](adapty-sdk-integration-skill-capacitor).

### Crear y editar flows

```
Add a German locale to my onboarding flow
```

El plugin [crea y edita flows](flow-generator-skill): añade idiomas, reescribe textos, agrega o elimina pantallas, configura bifurcaciones en cuestionarios y construye un paywall a partir de una descripción. Antes de publicar, [audita el flow](flow-audit-skill) para verificar triggers, cumplimiento con las stores, productos y localización. Si tus placements muestran paywalls, el plugin [los migra a flows](migrate-placements-skill).

### Encuentra qué probar a continuación \{#find-what-to-test-next\}

```
Audit my app. What should I test next to grow revenue?
```

El plugin [lee tu analítica, precios y pruebas A/B anteriores](export-analytics-with-ai), puntúa cada parte de tu negocio frente al mercado y devuelve hipótesis ordenadas por el impacto potencial en los ingresos. También responde preguntas concretas sobre tus datos, como por qué bajaron las renovaciones el mes pasado.

### Ejecutar pruebas A/B \{#run-ab-tests\}

```
Start a 50/50 test of my two onboarding paywalls
```

El plugin [crea, inicia, detiene y reemplaza pruebas A/B](ab-tests-skill) para paywalls y flows.

### Analiza tus campañas publicitarias \{#analyze-your-ad-campaigns\}

```
Which campaigns should I scale, and which should I cut?
```

El plugin [lee tus datos de atribución de Adapty](developer-cli-attribution-skill): ROAS, retorno de inversión, coste por prueba y reembolsos por canal, campaña y país.

:::tip
Las campañas de Apple Ads tienen su propio plugin. Consulta [Gestiona Apple Ads con una herramienta de IA](developer-cli-ads-manager-skill).
:::

### Ejecutar Adapty Mail

```
Why didn't this user get the welcome email?
```

El plugin [conecta el servidor MCP de Adapty Mail](mail-skill), lanza flows de email y rastrea por qué no se envió un email. Pregunta antes de hacer cualquier cosa que envíe emails reales a personas.

### Migrar desde RevenueCat

```
Move my RevenueCat project to Adapty
```

Tu agente de código copia el catálogo y los diseños de paywall de RevenueCat a una nueva app de Adapty, y luego reemplaza el SDK de RevenueCat en tu código con llamadas que usan los IDs de Adapty equivalentes. Consulta [Migración desde RevenueCat](migration-from-revenuecat).

## Cómo conecta el plugin con tu cuenta \{#how-the-plugin-reaches-your-account\}

El plugin funciona mediante dos conexiones. Si tu herramienta no tiene ninguna, el plugin te pregunta cuál quieres configurar y te explica los pasos. Si tienes ambas, elige la más adecuada para cada tarea:

- **[Servidor MCP de Adapty](adapty-mcp)**: La conexión para claude.ai y Claude Desktop, y para los agentes de código que admiten MCP. Inicia sesión con tu cuenta de Adapty en el navegador. No necesitas ninguna clave de API.
- **[CLI de Adapty](developer-cli-quickstart)**: La conexión para agentes de código que ejecutan comandos de terminal. Los flujos de trabajo de flow y analíticas lo prefieren, ya que trabajan con archivos locales. También puedes ejecutar el CLI tú mismo o desde tus propios scripts.

## Dale a tu herramienta de IA la documentación de Adapty \{#give-your-ai-tool-the-adapty-docs\}

### Documentación en texto plano \{#plain-text-docs\}

Toda la documentación de Adapty está disponible en Markdown: añade `.md` a la URL de la página o haz clic en **Copy for LLM** debajo del título. Para un contexto más amplio, dale a tu herramienta el índice [`llms.txt`](https://adapty.io/docs/es/llms.txt) o un subconjunto específico de plataforma como [`ios-llms.txt`](https://adapty.io/docs/es/ios-llms.txt).

### Context7

[Context7](https://context7.com/adaptyteam/adapty-docs) es un servidor MCP que sirve la documentación de Adapty a tu herramienta de IA, pero solo indexa fragmentos de código, no el texto completo. Úsalo para obtener ejemplos de código rápidos; para una guía completa, proporciona a tu herramienta los [documentos en texto plano](#plain-text-docs). Context7 sirve solo documentación; para trabajar con tu cuenta, [instala el plugin de Adapty](#install-the-plugin).
