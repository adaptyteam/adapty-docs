En el Flow & Paywall Builder, crea el flow de recarga. Añade el flow a un [placement](placements) con el ID `out_of_diamonds`. Cuando el saldo sea demasiado bajo para un gasto, el código del paso 4 abre el flow desde este placement.

Para mostrar un flow de recarga diferente según el saldo, añade una [audiencia](audience) con un [segmento por saldo de moneda virtual](segments#virtual-currency-balance) al placement `out_of_diamonds`. Por ejemplo, muestra un flow independiente a los usuarios con 0 diamantes. Adapty lee el saldo cada vez que el código de tu app obtiene el flow, así que un gasto o una compra puede cambiar el flow que el usuario ve a continuación.

Para mostrar el saldo de diamantes también en este flow, [añade un elemento personalizado](flow-custom-elements#add-and-configure) con el mismo Type e ID que en el flow de sin energía: `currency_balance` y `diamonds`. Dentro del elemento personalizado, añade el **Icon** de diamante como respaldo. Los jugadores ven la misma vista de saldo en ambos flows y no necesitas añadir código para ello.
