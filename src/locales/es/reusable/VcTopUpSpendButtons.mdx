Para mostrar un spinner y luego una marca de verificación en el botón que los usuarios pulsan, añade ambos botones como elementos personalizados. Los usuarios no ven ni el spinner ni la marca de verificación en un botón del builder con una [acción personalizada](onboarding-actions#what-custom-actions-cant-do). Una acción personalizada es unidireccional: el código de tu app no puede devolver el resultado del gasto al flow. El texto y el aspecto de los botones provienen del código de tu app. Para cambiar el texto o el aspecto, [publica una actualización de la app](flow-custom-elements#what-changes-require-an-app-release).

1. [Añade un elemento personalizado](flow-custom-elements#add-and-configure) para la recarga de energía e introduce su **Type** e **ID**:
   - **Type**: `spend_button`.
   - **ID**: `energy_refill`.
2. Añade un segundo elemento personalizado para energía ilimitada, con el mismo Type y el ID `unlimited_energy`.

   El código del [paso 2](#connect-the-buttons-to-your-backend) asocia una vista de botón a ambos elementos personalizados por su Type. El código lee la opción de cada botón a partir de su ID.

   <ZoomImage id="vc-top-up-spend-button.webp" width="700px" alt="Configuración del elemento personalizado en el Flow & Paywall Builder, con spend_button en el campo Type y unlimited_energy en el campo ID" />

3. Reduce la altura **Fixed** de cada elemento personalizado de 200 al alto que necesita el botón.
4. Dentro de cada elemento personalizado, añade un elemento de texto e introduce las palabras para su opción:
   - Recarga de energía: "Update the game to refill energy."
   - Energía ilimitada: "Update the game to get unlimited energy."

   En versiones de la app sin la vista de botón, los usuarios ven este texto como [contenido de respaldo](flow-custom-elements#set-fallback-content), sin ningún botón que pulsar.
