Si ya instalaste el plugin de Adapty, tienes este skill. Si tu agente no lo muestra en la lista, actualiza el plugin con el comando correspondiente a tu agente en el [README del plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Para instalar el plugin en un agente de código, ejecuta en tu terminal:

```bash
npx adapty skills install
```

Reinicia tu agente para cargar el plugin. Para instalar el plugin en claude.ai o Claude desktop, consulta [Instalar el plugin](manage-adapty-with-ai#install-the-plugin). Para otros métodos de instalación, consulta el [README del plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Claude Code no actualiza el plugin por sí solo. Para obtener nuevos skills a medida que se publiquen, en Claude Code ejecuta `/plugin`, abre **Marketplaces**, selecciona `adapty` y elige **Enable auto-update**. Para el comando de actualización en otros agentes, consulta el [README del plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).
