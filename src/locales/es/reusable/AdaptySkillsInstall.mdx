Para instalar el plugin, ejecuta en tu terminal:

```bash
npx adapty skills install
```

Reinicia tu agente para cargar los skills. Para otros métodos de instalación, consulta el [README del plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Claude Code no actualiza el plugin por sí solo. Para obtener nuevos skills a medida que se publican, en Claude Code ejecuta `/plugin`, abre **Marketplaces**, selecciona `adapty` y elige **Enable auto-update**. Para el comando de actualización en otros agentes, consulta el [README del plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).
