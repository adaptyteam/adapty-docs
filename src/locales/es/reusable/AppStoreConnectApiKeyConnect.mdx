1. Para encontrar el **Issuer ID** y el **Key ID** de tu clave de equipo, en App Store Connect, ve a [**Users and Access** > **Integrations** > **App Store Connect API**](https://appstoreconnect.apple.com/access/integrations/api) y abre la pestaña **Team Keys**. Si otra persona generó la clave y te envió su Issuer ID, Key ID y archivo, omite este paso.

   <ZoomImage id="asc-team-keys-ids.webp" width="700px" alt="Issuer ID y el Key ID de una clave de equipo en la pestaña Team Keys en App Store Connect" />

2. En Adapty, ve a [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). En la sección **App Store Connect API key**, haz clic en **Connect API Key**.

   <ZoomImage id="app-settings-connect-api-key.webp" width="700px" alt="Sección App Store Connect API key en Adapty, con el botón Connect API Key" />

3. Rellena los campos:
   - **Issuer ID**: Cópialo desde la pestaña **Team Keys** en App Store Connect.
   - **Key ID**: Cópialo de la lista **Active** en la pestaña **Team Keys**, junto a la clave que descargaste.
   - **Private key (.p8 file)**: Sube el archivo que descargaste para la clave de equipo.

   <ZoomImage id="app-settings-api-key-dialog.webp" width="700px" alt="Campos Issuer ID, Key ID y Private key (.p8 file) en la ventana de la App Store Connect API key" />

4. Puedes reemplazar una clave conectada más adelante, pero no puedes eliminarla. Asegúrate de que la clave pertenece al equipo de App Store Connect propietario de esta app y haz clic en **Connect**. A partir de entonces, seleccionarás cada **App Store Product ID** de tus productos en App Store Connect en lugar de escribirlo manualmente.

   Adapty no verifica la clave con Apple en el momento de conectarla. Una clave incorrecta falla sin ningún mensaje relacionado con la clave: los productos no muestran ningún estado de App Store y el desplegable **App Store Product ID** permanece vacío. Para corregir una clave incorrecta, [reemplázala](app-store-connect-api-key#replace-the-key).
