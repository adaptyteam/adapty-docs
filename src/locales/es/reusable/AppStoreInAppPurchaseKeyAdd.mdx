1. Para encontrar el **Issuer ID** y el **Key ID** de tu clave, en App Store Connect, ve a [**Users and Access** > **Integrations** > **In-App Purchase**](https://appstoreconnect.apple.com/access/integrations/api/subs). Si otra persona generó la clave y te envió su Issuer ID, Key ID y el archivo, omite este paso.

   <ZoomImage id="asc-in-app-purchase-keys-ids.webp" width="700px" alt="Issuer ID y Key ID de una clave de compra in-app en App Store Connect" />

2. En Adapty, ve a [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). En la sección **In-app purchase API (StoreKit 2)**, rellena los campos:
   - **Issuer ID**: Cópialo desde la página **In-App Purchase** en App Store Connect.
   - **Key ID**: Cópialo desde la lista **Active** en la página **In-App Purchase**, junto a la clave que descargaste.
   - **Private key (.p8 file)**: Sube el archivo que descargaste.

   <ZoomImage id="app-settings-in-app-purchase-api.webp" width="700px" alt="Campos Issuer ID, Key ID y Private key (.p8 file) en la sección In-app purchase API (StoreKit 2) en Adapty" />

3. Adapty firma las [ofertas promocionales](offers) con la clave de compra in-app. En la sección **App Store promotional offers**, introduce la clave de nuevo:
   - **Subscription key ID**: El Key ID del paso 2.
   - **Subscription key (.p8 file)**: El archivo del paso 2.

   <ZoomImage id="app-settings-promotional-offers.webp" width="700px" alt="Campos Subscription key ID y Subscription key (.p8 file) en la sección App Store promotional offers" />

   Si usas una clave distinta, se guardará sin error, pero los usuarios no podrán recibir ofertas promocionales.

4. Haz clic en **Save**. Adapty verifica la clave de la sección **In-app purchase API (StoreKit 2)** con Apple antes de guardar la página. Si Apple rechaza la clave, la página mostrará "The provided field values are incorrect": [revisa los valores](troubleshoot-app-store-integration#the-provided-field-values-are-incorrect-when-saving-credentials).
