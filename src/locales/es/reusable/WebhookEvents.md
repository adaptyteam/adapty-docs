
| Nombre del evento                  | Descripción                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
|:-----------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| subscription_started               | Se activa cuando un usuario activa una suscripción de pago sin período de prueba, es decir, se le cobra de inmediato.                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| subscription_active                | Confirma que la suscripción sigue activa después del evento `subscription_started`. Debes definir cuántos días transcurren entre el inicio de la suscripción y esta comprobación. El evento llega si la suscripción sigue activa, incluido el caso en que el usuario haya entrado en un período de gracia. Si la suscripción terminó o el usuario desactivó la renovación automática, no llega nada y Adapty no vuelve a comprobar. Este evento solo sigue a suscripciones compradas sin prueba. Una prueba que se convierte envía `trial_converted`, que no inicia la comprobación. |
| subscription_renewed               | Ocurre cuando se renueva una suscripción y se cobra al usuario. Este evento comienza a partir de la segunda facturación, ya sea una suscripción con o sin período de prueba.                                                                                                                                                                                                                                                                                                                                                                              |
| subscription_renewal_cancelled     | Un usuario ha desactivado la renovación automática de la suscripción. El usuario conserva el acceso a las funciones premium hasta el final del período de suscripción de pago.                                                                                                                                                                                                                                                                                                                                                                            |
| subscription_renewal_reactivated   | Se activa cuando un usuario reactiva la renovación automática de la suscripción.                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| subscription_expired               | Se activa cuando una suscripción termina definitivamente tras ser cancelada. Por ejemplo, si un usuario cancela una suscripción el 12 de diciembre pero esta permanece activa hasta el 31 de diciembre, el evento se registra el 31 de diciembre cuando expira.                                                                                                                                                                                                                                                                                           |
| subscription_paused                | Ocurre cuando un usuario activa la [pausa de suscripción](https://developer.android.com/google/play/billing/lifecycle/subscriptions#pause) (solo Android).                                                                                                                                                                                                                                                                                                                                                                                               |
| subscription_deferred              | Se activa cuando extiendes la suscripción de un usuario sin coste: mediante un [aplazamiento](https://adapty.io/glossary/subscription-purchase-deferral/) a través de la API de Google Play Developer, o una [extensión de fecha de renovación](https://developer.apple.com/documentation/appstoreserverapi/extend-a-subscription-renewal-date) a través de la App Store Server API. El usuario conserva el acceso a las funciones premium hasta la fecha de renovación extendida.                                                                        |
| non_subscription_purchase          | Cualquier compra que no sea una suscripción, como acceso de por vida o productos consumibles como monedas del juego.                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| trial_started                      | Se activa cuando un usuario activa una suscripción de prueba.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| trial_active                       | Confirma que la prueba sigue activa después del evento `trial_started`. Debes definir cuántos días transcurren entre el inicio de la prueba y esta comprobación. El evento llega si la prueba sigue en curso. Si la prueba terminó, se convirtió o el usuario desactivó la renovación automática, no llega nada y Adapty no vuelve a comprobar.                                                                                                                                                                                                           |
| trial_converted                    | Ocurre cuando finaliza una prueba y se cobra al usuario (primera compra). Por ejemplo, si un usuario tiene una prueba hasta el 14 de enero pero se le cobra el 7 de enero, este evento se registra el 7 de enero.                                                                                                                                                                                                                                                                                                                                         |
| trial_renewal_cancelled            | Un usuario desactivó la renovación automática de la suscripción durante el período de prueba. El usuario conserva el acceso a las funciones premium hasta que finalice la prueba, pero no se le cobrará ni iniciará una suscripción.                                                                                                                                                                                                                                                                                                                      |
| trial_renewal_reactivated          | Ocurre cuando un usuario reactiva la renovación automática de la suscripción durante el período de prueba.                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| trial_expired                      | Se activa cuando una prueba termina sin convertirse en suscripción.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| entered_grace_period               | Ocurre cuando falla un intento de pago y el usuario entra en un período de gracia (si está habilitado). El usuario conserva el acceso premium durante este tiempo.                                                                                                                                                                                                                                                                                                                                                                                        |
| billing_issue_detected             | Se activa cuando ocurre un problema de facturación durante un intento de cobro (por ejemplo, saldo insuficiente en la tarjeta).                                                                                                                                                                                                                                                                                                                                                                                                                           |
| subscription_refunded              | Se activa cuando se reembolsa una suscripción (por ejemplo, por parte del soporte de Apple).                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| non_subscription_purchase_refunded | Se activa cuando se reembolsa una compra que no es una suscripción.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| access_level_updated               | Ocurre cuando se actualiza el nivel de acceso de un usuario.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
