No puedes publicar ni previsualizar tu flow si se da alguno de los siguientes problemas.

- Una interacción con una configuración incompleta. Casos habituales:
    - Una acción **Open URL** sin URL de destino.
    - Una acción **Navigate to screen** sin destino — también ocurre cuando la pantalla de destino se elimina después de configurar la acción.
    - Una **acción condicional** sin operador o valor.
    - Una acción **Set variable** sin asignación de variable/valor.
    - Una acción **Purchase** sin producto (store in-app) ni URL de Web Paywall (pago web).
    - Una acción **Custom** sin ID de acción.
    - Una acción **Show alert** con el Título o el Mensaje vacíos.
    - Una acción **Show** o **Hide** sin ningún elemento seleccionado.
    - Una acción **Select product** sin producto de destino — también ocurre cuando el elemento de producto de destino se elimina, se saca de su grupo de productos o se deja en otra pantalla.
    - Una acción **Select product** guardada dentro de un componente reutilizable, o que apunta a un ID de elemento usado en más de una pantalla.
- Una **condición que usa un elemento, estado o variable eliminados** — bloquea la publicación hasta que selecciones uno existente o elimines la condición.
- Una **pantalla sin elementos**.
- Un elemento de producto **sin producto asignado** — puede ocurrir si eliminas el producto referenciado.
- Un JSON de **Remote Config** no válido interrumpe todo el proceso de entrega — ni siquiera puedes guardar el borrador.
