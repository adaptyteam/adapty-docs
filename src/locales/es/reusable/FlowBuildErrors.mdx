No puedes publicar ni previsualizar tu flow si alguno de los siguientes problemas está presente.

- Una interacción con una configuración incompleta. Casos habituales:
    - Una acción **Open URL** sin URL de destino.
    - Una acción **Navigate to screen** sin destino — también ocurre cuando la pantalla de destino se elimina después de configurar la acción.
    - Una **acción condicional** sin operador ni valor.
    - Una acción **Set variable** sin asignación de variable o valor.
    - Una acción **Purchase** sin producto (store in-app) ni URL de Web Paywall (pago web).
    - Una acción **Custom** sin Action ID.
    - Una acción **Show alert** con el Title o el Message vacíos.
    - Una acción **Show** o **Hide** sin ningún elemento seleccionado.
    - Una acción **Select product** sin producto de destino — también ocurre cuando el elemento de producto de destino se elimina, se saca de su grupo de productos o se deja en otra pantalla.
    - Una acción **Select product** guardada dentro de un componente reutilizable, o que apunta a un ID de elemento utilizado en más de una pantalla.
- Una **pantalla sin elementos**.
- Un elemento de producto **sin producto asignado** — puede ocurrir si eliminas el producto referenciado.
- Un JSON de **remote config** inválido interrumpe todo el proceso de entrega — ni siquiera puedes guardar el borrador.
