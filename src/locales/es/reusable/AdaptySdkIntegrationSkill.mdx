El skill `adapty-integration` automatiza la integración de Adapty de principio a fin: configuración del dashboard, instalación del SDK, paywall y verificación en cada etapa. Detecta tu plataforma automáticamente y obtiene la documentación relevante de Adapty en cada paso. Funciona en cualquier agente de código que admita skills: Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI y otros.

El skill forma parte del [plugin de Adapty](manage-adapty-with-ai). Si ya instalaste el plugin, tienes este skill. Si tu agente no lo muestra, actualiza el plugin con el comando correspondiente a tu agente en el [README del plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Para instalar el plugin en un agente de código, ejecuta en tu terminal:

```bash
npx adapty skills install
```

Reinicia tu agente para cargar el plugin. Para otros métodos de instalación, consulta el [README del plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Claude Code no actualiza el plugin por su cuenta. Para obtener los nuevos skills a medida que se publican, en Claude Code ejecuta `/plugin`, abre **Marketplaces**, selecciona `adapty` y elige **Enable auto-update**. Para el comando de actualización en otros agentes, consulta el [README del plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Para iniciar la integración, pide en tu agente:

```
Integrate Adapty into my app
```

El skill hace algunas preguntas de configuración y luego guía paso a paso por la configuración del dashboard, la instalación del SDK, el paywall y la verificación.
