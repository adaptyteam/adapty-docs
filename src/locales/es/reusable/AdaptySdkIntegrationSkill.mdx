El [skill adapty-integration](https://github.com/adaptyteam/adapty-skills) automatiza la integración de Adapty de principio a fin: configuración del dashboard, instalación del SDK, paywall y verificación por etapas. Detecta tu plataforma automáticamente y obtiene la documentación relevante de Adapty en cada etapa.

**Herramientas compatibles**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Para instalarlo, elige el formulario correspondiente a tu herramienta. La lista completa está en el [README del skill](https://github.com/adaptyteam/adapty-skills).

El repositorio contiene dos skills: `adapty-integration` y `ads-manager`, que ejecuta Apple Search Ads a través del CLI de Adapty. Cada comando de abajo instala ambos.

**Claude Code**

```
claude plugin marketplace add adaptyteam/adapty-skills
claude plugin install adapty-skills@adapty
```

**GitHub Copilot CLI**

```
git clone https://github.com/adaptyteam/adapty-skills.git
cp -r adapty-skills/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```
gemini skills install https://github.com/adaptyteam/adapty-skills
```

**OpenAI Codex u otra herramienta** — usa el [skills CLI](https://skills.sh) (ten en cuenta que los skills instalados de esta forma no se actualizan automáticamente):

```
npx skills add adaptyteam/adapty-skills --all
```

`--all` instala ambos skills en todos los agentes que detecte. Sin este flag, el CLI pregunta cuál de los dos quieres instalar.

También puedes clonar el repositorio y copiar los directorios que hay en `skills/` en el directorio de skills de tu herramienta.

Una vez instalado, ejecuta el skill en tu proyecto:

```
/adapty-integration
```

El skill hace algunas preguntas de configuración y luego guía el proceso de configuración del dashboard, instalación del SDK, paywall y verificación.
