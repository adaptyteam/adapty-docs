El [skill adapty-integration](https://github.com/adaptyteam/adapty-skills) automatiza la integración de Adapty de principio a fin: configuración del dashboard, instalación del SDK, paywall y verificación por etapas. Detecta tu plataforma automáticamente y obtiene la documentación relevante de Adapty en cada etapa.

**Herramientas compatibles**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Para instalarlo, elige el formulario para tu herramienta. La lista completa está en el [README del skill](https://github.com/adaptyteam/adapty-skills).

El repositorio contiene más skills que este, y cada comando de abajo instala todos ellos.

**Claude Code**

```
claude plugin marketplace add adaptyteam/adapty-skills
claude plugin install adapty-skills@adapty
```

**GitHub Copilot CLI**

```
git clone https://github.com/adaptyteam/adapty-skills.git
cp -r adapty-skills/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```
gemini skills install https://github.com/adaptyteam/adapty-skills
```

**OpenAI Codex**

```
codex plugin marketplace add adaptyteam/adapty-skills
codex plugin add adapty-skills@adapty
```

**Cualquier otra herramienta** — usa la [skills CLI](https://skills.sh) (ten en cuenta que los skills instalados de esta forma no se actualizan automáticamente):

```
npx skills add adaptyteam/adapty-skills --all
```

`--all` instala todos los skills en cada agente que detecte. Sin él, la CLI pregunta cuáles quieres instalar.

Como alternativa, clona el repositorio y copia los directorios que hay en `skills/` en el directorio de skills de tu herramienta.

Tras la instalación, ejecuta el skill en tu proyecto:

```
/adapty-integration
```

El skill hace unas preguntas de configuración y luego guía a través de la configuración del dashboard, la instalación del SDK, el paywall y la verificación.
