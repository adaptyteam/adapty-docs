El skill `adapty-integration` automatiza la integración de Adapty de principio a fin: configuración del dashboard, instalación del SDK, paywall y verificación por etapas. Detecta tu plataforma automáticamente y obtiene la documentación relevante de Adapty en cada etapa. Funciona en cualquier agente de programación que soporte skills: Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI y otros.

El skill forma parte del [plugin `adapty-skills`](https://github.com/adaptyteam/adapty-skills). Para instalar el plugin, ejecuta en tu terminal:

```bash
npx adapty skills install
```

Reinicia tu agente para cargar los skills. Para otros métodos de instalación, consulta el [README del plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Claude Code no actualiza el plugin por sí solo. Para obtener los nuevos skills a medida que se publiquen, en Claude Code ejecuta `/plugin`, abre **Marketplaces**, selecciona `adapty` y elige **Enable auto-update**. Para el comando de actualización en otros agentes, consulta el [README del plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install).

Para iniciar la integración, pide a tu agente:

```
Integrate Adapty into my app
```

El skill hace algunas preguntas de configuración y luego te guía a través de la configuración del dashboard, la instalación del SDK, el paywall y la verificación.
