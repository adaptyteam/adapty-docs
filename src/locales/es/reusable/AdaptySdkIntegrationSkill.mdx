La [skill adapty-sdk-integration](https://github.com/adaptyteam/adapty-sdk-integration-skill) automatiza la integración de Adapty de principio a fin: configuración del dashboard, instalación del SDK, paywall y verificación por etapas. Detecta tu plataforma automáticamente y obtiene la documentación de Adapty relevante en cada etapa.

**Herramientas compatibles**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

Para instalarla, elige el formulario correspondiente a tu herramienta. La lista completa está en el [README de la skill](https://github.com/adaptyteam/adapty-sdk-integration-skill).

El repositorio contiene dos skills: `adapty-sdk-integration` y `ads-manager`, que ejecuta Apple Search Ads a través de la CLI de Adapty. Cada uno de los comandos siguientes instala ambas.

**Claude Code**

```
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

**GitHub Copilot CLI**

```
git clone https://github.com/adaptyteam/adapty-sdk-integration-skill.git
cp -r adapty-sdk-integration-skill/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex u otra herramienta** — usa la [CLI de skills](https://skills.sh) (ten en cuenta que las skills instaladas de esta forma no se actualizan automáticamente):

```
npx skills add adaptyteam/adapty-sdk-integration-skill --all
```

`--all` instala ambas skills en todos los agentes que detecta. Sin esta opción, la CLI pregunta cuál de las dos quieres instalar.

También puedes clonar el repositorio y copiar los directorios que hay dentro de `skills/` en el directorio de skills de tu herramienta.

Tras la instalación, ejecuta la skill en tu proyecto:

```
/adapty-sdk-integration
```

La skill hace algunas preguntas de configuración y luego guía paso a paso por la configuración del dashboard, la instalación del SDK, el paywall y la verificación.
