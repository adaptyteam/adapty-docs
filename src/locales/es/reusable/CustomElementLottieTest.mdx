El Flow & Paywall Builder no puede ejecutar el código de tu app, por lo que el canvas solo muestra el fallback. Para previsualizar la animación:

1. [Publica el flow](builder-save-publish). Para ver la última versión publicada en lugar de una en caché, registra el dispositivo como [dispositivo de prueba](test-devices).
2. Ejecuta una compilación de tu app que incluya el resolver. Establece la racha en 0 días, abre la pantalla y verifica que el anillo se llene hasta ese valor. Repite con otros valores, como 4 y 7 días.

Para probar el fallback, elimina el archivo de animación de la compilación y abre la pantalla de nuevo.
