Cuando se abre una pantalla con un [elemento personalizado](flow-custom-elements), el SDK de Adapty pasa el Type y el ID del elemento a un resolver en el código de tu app. El resolver devuelve una de las siguientes opciones:

- **La vista que coincide con el Type y el ID**: Los usuarios ven la vista nativa, como una animación Lottie, un gráfico interactivo o una vista previa de la cámara.
- **Sin vista**: Los usuarios ven el fallback, que es el contenido dentro del elemento personalizado en el Flow & Paywall Builder.

Los usuarios de versiones de la app sin el resolver también verán el fallback. Por eso, puedes publicar el flow antes de lanzar la app.
