La [skill ads-manager](https://github.com/adaptyteam/adapty-sdk-integration-skill) enseña a tu herramienta de codificación con IA a operar Apple Ads mediante los comandos `adapty asa`. Conoce el orden en que se componen los comandos, qué leer antes de escribir cualquier cosa y qué llamadas gastan dinero.

**Herramientas compatibles**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

La skill controla la CLI de Adapty, así que primero instala y autentica la CLI — consulta la [guía de inicio rápido](developer-cli-quickstart).

En un espacio de trabajo corporativo de Cowork, un administrador debe añadir `*.adapty.io` a la lista de dominios permitidos. Hasta que lo haga, la skill no podrá conectarse a Adapty.

Para instalar, elige el formulario correspondiente a tu herramienta. La lista completa está en el [README de la skill](https://github.com/adaptyteam/adapty-sdk-integration-skill).

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

Este plugin también incluye la skill de integración con el SDK. Ambas se instalan juntas.

**GitHub Copilot CLI**

```bash
gh skill install adaptyteam/adapty-sdk-integration-skill
```

**Gemini CLI**

```bash
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex u otra herramienta** — usa la [skills CLI](https://skills.sh) (ten en cuenta que las skills instaladas de esta forma no se actualizan automáticamente):

```bash
npx skills add adaptyteam/adapty-sdk-integration-skill
```

También puedes clonar el repositorio y copiar `skills/ads-manager/` en el directorio de skills de tu herramienta.

Tras instalar, ejecuta la skill en tu proyecto:

```bash
/ads-manager
```

Leer métricas y hacer simulaciones no tiene ningún coste. Cualquier otro comando llega a Apple en segundos, gasta dinero real y no puede deshacerse — la skill te pedirá confirmación antes de cada uno, y tú también deberías hacerlo.
