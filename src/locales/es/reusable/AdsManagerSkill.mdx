La [habilidad ads-manager](https://github.com/adaptyteam/adapty-sdk-integration-skill) enseña a tu herramienta de codificación con IA a operar Apple Ads mediante los comandos `adapty asa`. Conoce el orden en que se componen los comandos, qué leer antes de escribir cualquier cosa y qué llamadas gastan dinero.

**Herramientas compatibles**: Claude Code, GitHub Copilot CLI, OpenAI Codex, Gemini CLI.

La habilidad utiliza el CLI de Adapty, así que instala y autentica el CLI primero; consulta la [guía de inicio rápido](developer-cli-quickstart). Los comandos `adapty asa` están disponibles a partir de **Adapty CLI 0.4.0**; en versiones anteriores no existen. Compruébalo con `adapty asa whoami`, que también te indica si hay una cuenta de Apple Ads conectada y si la empresa tiene una suscripción activa a Ads Manager.

En un espacio de trabajo corporativo Cowork, un administrador debe añadir tanto `adapty.io` como `*.adapty.io` a la lista de dominios permitidos. Añade ambos: un comodín no cubre el dominio raíz en la mayoría de las implementaciones de listas de permitidos, y el dominio raíz es donde vive la documentación que lee la habilidad. Hasta que ambos estén permitidos, la habilidad no puede acceder a Adapty.

Para instalar, elige la forma correspondiente a tu herramienta. La lista completa está en el [README de la habilidad](https://github.com/adaptyteam/adapty-sdk-integration-skill).

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

Este plugin también contiene la habilidad de integración del SDK. Ambas se instalan juntas.

**GitHub Copilot CLI**

```bash
git clone https://github.com/adaptyteam/adapty-sdk-integration-skill.git
cp -r adapty-sdk-integration-skill/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```bash
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex u otra herramienta** — usa el [CLI de habilidades](https://skills.sh) (ten en cuenta que las habilidades instaladas de esta forma no se actualizan automáticamente):

```bash
npx skills add adaptyteam/adapty-sdk-integration-skill --all
```

`--all` instala ambas habilidades en todos los agentes que detecta. Para instalar solo esta habilidad, usa `--skill ads-manager`.

También puedes clonar el repositorio y copiar los directorios de `skills/` en el directorio de habilidades de tu herramienta, o solo `skills/ads-manager/` si únicamente quieres esta.

Tras instalar, ejecuta la habilidad en tu proyecto:

```bash
/ads-manager
```

Leer métricas y hacer pruebas en seco no tiene ningún coste. Cualquier otro comando llega a Apple en segundos, gasta dinero real y no se puede deshacer — la habilidad pide confirmación antes de cada uno, y tú también deberías hacerlo.
