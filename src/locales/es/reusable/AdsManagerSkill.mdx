El [plugin de Apple Ads](https://github.com/adaptyteam/apple-ads-cli) enseña a tu herramienta de codificación con IA a operar Apple Ads mediante los comandos `adapty asa`. Incluye tres skills:

- **`apple-ads`**: El operador. Lee el rendimiento, cambia pujas y presupuestos, añade palabras clave y negativas, recopila términos de búsqueda, y lanza y pausa campañas — con confirmación antes de gastar dinero.
- **`apple-ads-audit`**: Un auditor de solo lectura. Comprueba la salud de la cuenta, el estado de publicación, la estructura, la propiedad del tráfico y las palabras clave de concordancia exacta duplicadas, y nunca escribe.
- **`apple-ads-strategy`**: Un planificador que no necesita cuenta, CLI ni suscripción. Convierte la descripción de tu app en una estructura de cuenta, una taxonomía de palabras clave, presupuestos iniciales y una lista de palabras clave negativas.

**Herramientas compatibles**: Claude Code, Claude Cowork, GitHub Copilot CLI, OpenAI Codex, Gemini CLI y cualquier otra herramienta que admita skills.

El operador y el auditor utilizan el CLI de Adapty, así que instala y autentícalo primero — consulta la [guía de inicio rápido](developer-cli-quickstart). Los comandos `adapty asa` se incluyen en **Adapty CLI 0.4.0 y versiones posteriores**; en versiones anteriores no existen en absoluto. Compruébalo con `adapty asa whoami`, que también indica si hay una cuenta de Apple Ads conectada y si la empresa tiene una suscripción activa a Ads Manager. El skill de estrategia funciona sin nada de esto.

Claude Cowork ejecuta el CLI en un sandbox que bloquea todos los dominios fuera de su lista de permitidos. Permite los dominios de Adapty antes de instalar el plugin — consulta [Configurar el CLI de Adapty en Claude Cowork](developer-cli-cowork). Una tarea de Cowork también comienza en una máquina limpia, por lo que el CLI y su sesión no persisten entre sesiones — el skill `adapty-cli-setup` del plugin instala y autentica el CLI al inicio de cada una.

Para instalar, elige el formato para tu herramienta. La lista completa está en el [README del plugin](https://github.com/adaptyteam/apple-ads-cli).

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/apple-ads-cli
claude plugin install apple-ads@adapty
```

**OpenAI Codex**

```bash
codex plugin marketplace add adaptyteam/apple-ads-cli
codex plugin add apple-ads@adapty
```

Ambas rutas de plugin incluyen los comandos `/asa-*` junto con los skills — prompts predefinidos para tareas comunes, como `/asa-review` para la revisión semanal y `/asa-harvest` para convertir términos de búsqueda en palabras clave y negativas. Claude Code los expone como comandos de barra; Codex los carga como skills que se solicitan por nombre.

**Cualquier otra herramienta** — usa el [skills CLI](https://skills.sh) (ten en cuenta que los skills instalados de esta forma no se actualizan automáticamente):

```bash
npx skills add adaptyteam/apple-ads-cli --all
```

`--all` instala los tres skills en todos los agentes que detecta. Para instalar un solo skill, usa `--skill`, por ejemplo `--skill apple-ads-strategy`.

Tras instalar, ejecuta un skill en tu proyecto — directamente o a través de uno de los comandos de barra:

```bash
/apple-ads
```

Leer métricas y hacer ejecuciones de prueba no tiene coste alguno. Cualquier otro comando llega a Apple en segundos, gasta dinero real y no se puede deshacer — los skills preguntan antes de cada uno, y tú también deberías hacerlo.
