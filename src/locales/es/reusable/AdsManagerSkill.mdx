El [plugin de Apple Ads](https://github.com/adaptyteam/apple-ads-cli) enseña a tu herramienta de codificación con IA a operar Apple Ads mediante los comandos `adapty asa`. Incluye tres habilidades:

- **`apple-ads`**: El operador. Lee el rendimiento, cambia pujas y presupuestos, añade palabras clave y negativas, recoge términos de búsqueda, y lanza y pausa campañas — con confirmación antes de cualquier gasto.
- **`apple-ads-audit`**: Un auditor de solo lectura. Comprueba la salud de la cuenta, el estado de servicio, la estructura, la propiedad del tráfico y las palabras clave de concordancia exacta duplicadas, y nunca escribe.
- **`apple-ads-strategy`**: Un planificador que no necesita cuenta, CLI ni suscripción. Convierte la descripción de tu app en una estructura de cuenta, una taxonomía de palabras clave, presupuestos iniciales y una lista de palabras clave negativas.

**Herramientas compatibles**: Claude Code, Claude Cowork, GitHub Copilot CLI, OpenAI Codex, Gemini CLI, y cualquier otra herramienta que admita habilidades.

El operador y el auditor utilizan la CLI de Adapty, así que instala y autentica la CLI primero — consulta la [guía de inicio rápido](developer-cli-quickstart). Los comandos `adapty asa` se incluyen en **Adapty CLI 0.4.0 y versiones posteriores**; en una versión más antigua no existen en absoluto. Compruébalo con `adapty asa whoami`, que también te indica si hay una cuenta de Apple Ads conectada y si la empresa tiene una suscripción activa a Ads Manager. La habilidad de estrategia funciona sin nada de esto.

Claude Cowork ejecuta la CLI en un sandbox que bloquea todos los dominios fuera de su lista de permitidos. Permite los dominios de Adapty antes de instalar el plugin allí — consulta [Ejecutar la CLI en Cowork](developer-cli-quickstart#run-the-cli-in-cowork). Una tarea de Cowork también empieza en una máquina limpia, por lo que la CLI y su sesión no se mantienen entre sesiones — la habilidad `adapty-cli-setup` del plugin instala y autentica la CLI de nuevo al inicio de cada una.

Para instalar, elige el formato para tu herramienta. La lista completa está en el [README del plugin](https://github.com/adaptyteam/apple-ads-cli).

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/apple-ads-cli
claude plugin install apple-ads@adapty
```

Además de las habilidades, el plugin de Claude Code instala los comandos de barra `/asa-*` — prompts predefinidos para tareas habituales, como `/asa-review` para la revisión semanal y `/asa-harvest` para convertir términos de búsqueda en palabras clave y negativas.

**Cualquier otra herramienta** — usa la [CLI de habilidades](https://skills.sh) (ten en cuenta que las habilidades instaladas de esta forma no se actualizan automáticamente):

```bash
npx skills add adaptyteam/apple-ads-cli --all
```

`--all` instala las tres habilidades en todos los agentes que detecta. Para instalar solo una habilidad, usa `--skill`, por ejemplo `--skill apple-ads-strategy`.

Tras la instalación, ejecuta una habilidad en tu proyecto — ya sea directamente o mediante uno de los comandos de barra:

```bash
/apple-ads
```

Leer métricas y hacer simulaciones no cuesta nada. Cualquier otro comando llega a Apple en segundos, gasta dinero real y no se puede deshacer — las habilidades piden confirmación antes de cada uno, y tú también deberías hacerlo.
