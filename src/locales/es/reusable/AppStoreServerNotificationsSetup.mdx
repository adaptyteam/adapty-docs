1. En Adapty, abre la app que estás conectando: cada app de Adapty tiene su propia URL de notificaciones. Ve a [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). En la sección **App Store server notifications**, copia la URL del campo **URL for App Store server notifications**.

   <ZoomImage id="app-settings-notifications-url.webp" width="700px" alt="URL for App Store server notifications en la sección App Store server notifications en Adapty" />

2. En [App Store Connect](https://appstoreconnect.apple.com/apps), abre la página **App Information** de tu app.
3. En la sección **App Store Server Notifications**, busca **Production Server URL**. Si ya hay una URL, haz clic en **Edit**. Si no, haz clic en **Set Up URL**.

   <ZoomImage id="asc-server-notifications-set-up-url.webp" width="700px" alt="Sección App Store Server Notifications en la página App Information en App Store Connect" />

4. Pega la URL de Adapty y haz clic en **Save**.

   <ZoomImage id="asc-server-url-set-up-dialog.webp" width="700px" alt="Diálogo Production Server URL en App Store Connect con la URL de Adapty" />

5. Para que las notificaciones de tus pruebas sandbox lleguen a Adapty, repite los pasos 3 y 4 para **Sandbox Server URL**.
