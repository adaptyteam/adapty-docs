## ¿Por qué usar las apps de ejemplo? \{#why-use-sample-apps\}

- **Integración rápida:** Descubre cómo funciona el SDK de Adapty en una app real.
- **Buenas prácticas:** Sigue los patrones de implementación recomendados.
- **Depuración y pruebas:** Usa las apps de ejemplo para resolver problemas y experimentar antes de integrar Adapty en tu propio proyecto.

## Apps de ejemplo disponibles \{#available-sample-apps\}

- [iOS (Swift)](https://github.com/adaptyteam/AdaptySDK-iOS/tree/master/Examples)
- [Android (Kotlin)](https://github.com/adaptyteam/AdaptySDK-Android/tree/master/app)
- [React Native (ejemplo básico)](https://github.com/adaptyteam/AdaptySDK-React-Native/tree/master/examples/BasicExample) — una configuración mínima que muestra las funciones principales del SDK.
- [React Native (Expo Go y Expo Web)](https://github.com/adaptyteam/AdaptySDK-React-Native/tree/master/examples/ExpoGoWebMock) — la más rápida de probar: se ejecuta en un navegador con datos simulados, por lo que no necesita una clave API de Adapty. Incluye tanto un paywall personalizado como el Flow & Paywall Builder.
- [React Native (Focus Journal, una app con Expo)](https://github.com/adaptyteam/AdaptySDK-React-Native/tree/master/examples/FocusJournalExpo) — una app con funciones premium detrás de un paywall del Flow & Paywall Builder. Incluye una [guía en vídeo](https://www.youtube.com/watch?v=TtCJswpt2ms).
- [React Native (Adapty DevTools)](https://github.com/adaptyteam/AdaptySDK-React-Native/tree/master/examples/AdaptyDevtools) — una herramienta de desarrollo e informes de errores para trabajar con casos más complejos. La misma app también está disponible [con Swift Package Manager en lugar de CocoaPods](https://github.com/adaptyteam/AdaptySDK-React-Native/tree/master/examples/AdaptyDevtoolsSpm).
- [Flutter (Dart)](https://github.com/adaptyteam/AdaptySDK-Flutter/tree/master/example)
- [Unity (C#)](https://github.com/adaptyteam/AdaptySDK-Unity/tree/main/Assets)
- [Kotlin Multiplatform](https://github.com/adaptyteam/AdaptySDK-KMP/tree/main/example)
- [Capacitor (React)](https://github.com/adaptyteam/AdaptySDK-Capacitor/tree/master/examples/basic-react-example)
- [Capacitor (Vue.js)](https://github.com/adaptyteam/AdaptySDK-Capacitor/tree/master/examples/basic-vue-example)
- [Capacitor (Angular)](https://github.com/adaptyteam/AdaptySDK-Capacitor/tree/master/examples/basic-angular-example)
- [Capacitor (Herramientas avanzadas de desarrollo)](https://github.com/adaptyteam/AdaptySDK-Capacitor/tree/master/examples/adapty-devtools)
