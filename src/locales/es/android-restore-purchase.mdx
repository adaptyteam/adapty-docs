Restaurar compras es una función que permite a los usuarios recuperar el acceso a contenido adquirido previamente, como suscripciones o compras in-app, sin que se les vuelva a cobrar. Esta función es especialmente útil para usuarios que han desinstalado y reinstalado la app o que han cambiado de dispositivo y quieren acceder a su contenido sin pagar de nuevo.

:::note
En los paywalls creados con [Paywall Builder](adapty-paywall-builder), las compras se restauran automáticamente sin que tengas que añadir código adicional. Si es tu caso, puedes saltarte este paso.
:::

Para restaurar una compra cuando no usas [Paywall Builder](adapty-paywall-builder) para personalizar el paywall, llama al método `.restorePurchases()`:

<TabItem value="kotlin" label="Kotlin" default>

```kotlin showLineNumbers
Adapty.restorePurchases { result ->
    when (result) {
        is AdaptyResult.Success -> {
            val profile = result.value
                      
            if (profile.accessLevels["YOUR_ACCESS_LEVEL"]?.isActive == true) {
            // successful access restore
            }
        }
        is AdaptyResult.Error -> {
            val error = result.error
            // handle the error
        }
    }
}
```
</TabItem>
<TabItem value="java" label="Java" default>

```java showLineNumbers
Adapty.restorePurchases(result -> {
    if (result instanceof AdaptyResult.Success) {
        AdaptyProfile profile = ((AdaptyResult.Success<AdaptyProfile>) result).getValue();
        
        if (profile != null) {
            AdaptyProfile.AccessLevel premium = profile.getAccessLevels().get("YOUR_ACCESS_LEVEL");
            
            if (premium != null && premium.isActive()) {
                // successful access restore
            }
        }
    } else if (result instanceof AdaptyResult.Error) {
        AdaptyError error = ((AdaptyResult.Error) result).getError();
        // handle the error
    }
});
```
</TabItem>

</Tabs>

Parámetros de respuesta:

| Parámetro | Descripción |
|---------|-----------|
| **Profile** | <p>Un objeto [`AdaptyProfile`](https://android.adapty.io/adapty/com.adapty.models/-adapty-profile/). Este modelo contiene información sobre niveles de acceso, suscripciones y compras únicas.</p><p>Comprueba el **estado del nivel de acceso** para determinar si el usuario tiene acceso a la app.</p> |

:::info
A partir del SDK de Adapty para Android 3.17.3 y 4.0.2, `restorePurchases()` se completa correctamente incluso cuando no hay nada que restaurar: devuelve el perfil actual, así que comprueba el estado del nivel de acceso en él. En versiones anteriores del SDK, el método falla con el error `NO_PURCHASES_TO_RESTORE` en este caso.
:::

## Qué se puede restaurar \{#what-can-be-restored\}

`restorePurchases` recupera suscripciones activas y compras únicas no consumidas de Google Play.

A partir del SDK de Adapty para Android 3.17.3 y 4.0.2, que utilizan Google Play Billing Library 8, el Play Store ya no devuelve suscripciones caducadas ni compras únicas consumidas. Para permitir que los usuarios recuperen esas compras en otros dispositivos y reinstalaciones, [identifícalos](android-identifying-users) con `Adapty.identify`. Adapty entonces restaura el historial de compras desde su backend en lugar de desde el store.

:::note
Google Play solo reporta las compras actualmente vigentes, por lo que `restorePurchases()` no puede encontrar suscripciones que expiraron antes de que integraras Adapty. Para añadirlas a Adapty, [importa tus datos históricos](importing-historical-data-to-adapty).
:::
