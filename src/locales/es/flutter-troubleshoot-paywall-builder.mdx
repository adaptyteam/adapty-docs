Esta guía te ayuda a resolver problemas comunes al usar paywalls diseñados en el Adapty Paywall Builder en el SDK de Flutter. Para problemas con flows, consulta [Problemas comunes](flow-common-issues).

## Error al obtener la configuración de un paywall \{#getting-a-paywall-configuration-fails\}

**Problema**: El método `createPaywallView` no puede recuperar la configuración del paywall.

**Motivo**: El paywall no está habilitado para mostrarse en el dispositivo en el Paywall Builder.

**Solución**: Activa el toggle **Show on device** en el Paywall Builder.

## El número de visualizaciones del paywall es demasiado alto \{#the-paywall-view-number-is-too-big\}

**Problema**: El contador de visualizaciones del paywall muestra el doble de lo esperado.

**Motivo**: Es posible que estés llamando a `logShowFlow` (Flutter SDK v4+) / `logShowPaywall` en tu código, lo que duplica el recuento de visualizaciones de un paywall creado en el Paywall Builder antiguo. Adapty registra esas visualizaciones automáticamente, por lo que no necesitas este método.

**Solución**: Asegúrate de no estar llamando a `logShowFlow` (Flutter SDK v4+) / `logShowPaywall` en tu código para un paywall creado en el Paywall Builder antiguo.

## Otros problemas \{#other-issues\}

**Problema**: Experimentas otros problemas relacionados con el Paywall Builder que no se tratan más arriba.

**Solución**: Migra el SDK a la versión más reciente siguiendo las [guías de migración](flutter-sdk-migration-guides) si es necesario. Muchos problemas se resuelven en versiones más recientes del SDK.
