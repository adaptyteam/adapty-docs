El servidor MCP de Adapty conecta un asistente de IA con tu cuenta de Adapty. Pregunta sobre ingresos y conversiones, configura productos y placements, publica flows o inicia una prueba A/B desde un chat, en lenguaje natural. El asistente inicia sesión con tu cuenta de Adapty en el navegador y obtiene tus permisos. No necesitas ninguna clave de API.

| | |
|---|---|
| URL del servidor | `https://mcp.adapty.io/mcp` |
| Protocolo | MCP sobre Streamable HTTP, inicio de sesión OAuth 2.1 en el navegador |
| Compatible con | claude.ai, Claude desktop, Claude Code, Codex y otros clientes MCP que admitan inicio de sesión OAuth |

:::important
El servidor MCP da a tu asistente acceso a tu cuenta de Adapty. Para proporcionarle el conocimiento necesario —las reglas de configuración de flows, los métodos probados para tus analíticas y una confirmación antes de cada paso que llegue a tus usuarios—, instala primero el [plugin de Adapty](manage-adapty-with-ai#install-the-plugin). En Claude Code y Codex, el plugin añade este servidor automáticamente, así que solo tienes que [iniciar sesión](#connect-your-assistant).
:::

## Qué puede hacer el asistente \{#what-the-assistant-can-do\}

Las herramientas del servidor siguen el Adapty Dashboard y el [Adapty Developer CLI](developer-cli). El asistente elige las herramientas según tu solicitud; no necesitas nombrarlas tú.

| Área | Lo que el asistente puede hacer | Prueba preguntando |
|---|---|---|
| Apps y niveles de acceso | Listar, crear y actualizar apps y niveles de acceso | "Crea un nivel de acceso `premium` en Fitness Pro." |
| Productos y ofertas | Crear productos con sus IDs de producto en el store y vincular ofertas del store a ellos | "¿Cuáles de mis productos no tienen un ID de producto de Google Play?" |
| Paywalls | Crear y actualizar paywalls, y encontrar los placements que muestran cada uno | "¿Qué placements muestran el paywall Annual sale?" |
| Flows | Crear flows, leer y escribir sus configuraciones del builder, validar, previsualizar, publicar y leer métricas de flows | "Publica el flow Onboarding v2 y dime qué placements lo muestran." |
| Placements y audiencias | Crear placements y cambiar quién ve qué, y leer las métricas de los placements de flows | "¿Quién ve qué en el placement `onboarding`?" |
| Segmentos | Leer segmentos y sus filtros | "Lista mis segmentos y por qué filtra cada uno." |
| Pruebas A/B | Crear, iniciar, detener, reemplazar y archivar pruebas A/B de paywalls y flows | "Inicia el borrador de la prueba Weekly vs annual para usuarios en Alemania." |
| Analytics | Leer ingresos, MRR, conversiones, el funnel, retención, LTV y cohortes de instalación | "Compara la conversión de prueba a pago por país del mes pasado." |
| Migración desde RevenueCat | Crear y ejecutar una migración de tu catálogo de RevenueCat a una nueva app de Adapty | "Mueve mi proyecto de RevenueCat a una nueva app de Adapty." |

Adapty Mail tiene su propio servidor MCP. Para conectar un asistente a tu proyecto de Adapty Mail, consulta [Gestiona Adapty Mail con asistentes de IA](mail-mcp).

## Elige el servidor MCP o el CLI \{#choose-the-mcp-server-or-the-cli\}

El servidor MCP y la [CLI de Adapty para desarrolladores](developer-cli) acceden a la misma cuenta de Adapty. Si no tienes ninguno configurado, el plugin de Adapty te preguntará cuál quieres usar y te guiará con los pasos. Si tienes ambos, el plugin elige uno según la tarea:

| | Servidor MCP de Adapty | Adapty CLI |
|---|---|---|
| Se ejecuta en | Cualquier cliente MCP, incluidos claude.ai y Claude desktop | Agentes que ejecutan comandos de terminal y tus propios scripts |
| Inicio de sesión | Una vez por cliente, en el navegador | `adapty auth login`, una vez por máquina |
| Ideal para | Preguntas y cambios desde un chat | Editar configuraciones de flow, cambios en bloque y scripts |
| Instalación | No requiere instalación | `npm install -g adapty` |

En claude.ai y Claude desktop, el servidor MCP requiere menos configuración que el CLI: el CLI debe instalarse y autorizarse en cada conversación, como se describe en [Configura el CLI de Adapty en la app de Claude](developer-cli-cowork).

<Details summary="Qué skills usan el servidor MCP y cuáles usan el CLI">

Antes de su primer paso, cada skill detecta si tu asistente tiene el servidor MCP, el CLI, o ambos. Con uno solo, el skill lo utiliza. Con ambos, el skill usa el que mejor se adapta a su tarea:

- **Servidor MCP**: Ejecutar pruebas A/B, integrar el SDK y probar compras.
- **Adapty CLI**: Crear y auditar flows, encontrar qué probar a continuación, mover placements a flows y crear segmentos. Estos skills ejecutan sus propios scripts y archivos, y el CLI les pasa los archivos directamente.

</Details>

## Antes de empezar \{#before-you-start\}

- **Cuenta de Adapty**: El asistente opera en las empresas y apps a las que tu cuenta de Adapty tiene acceso, con tus permisos.
- **Cliente MCP con OAuth**: Tu cliente es compatible con servidores MCP remotos que inician sesión con OAuth.

:::warning
El asistente actúa con tus derechos y sus cambios son reales. Una prueba A/B iniciada o un placement modificado llega a tus usuarios. Antes de que el asistente inicie o detenga una prueba A/B, o cambie quién ve qué en un placement, el servidor le pide que describa el efecto exacto y espere tu confirmación. Lee el plan antes de aprobarlo.
:::

## Conecta tu asistente \{#connect-your-assistant\}

<Tabs groupId="mcp-client" queryString>
<TabItem value="claude-app" label="claude.ai" default>

claude.ai y Claude desktop añaden servidores MCP remotos como conectores personalizados.

1. Para añadir el servidor, abre **Settings → Connectors** y haz clic en **Add custom connector**.
2. Escribe un nombre, por ejemplo `Adapty`, y la URL `https://mcp.adapty.io/mcp`.
3. Deja la configuración de autenticación por defecto y haz clic en **Add**.
4. Inicia sesión en Adapty en la pestaña del navegador que se abre. Consulta [Iniciar sesión](#sign-in).

Los administradores del espacio de trabajo pueden añadir el conector una vez para toda la organización. Cada miembro inicia sesión con su propia cuenta de Adapty la primera vez que lo usa.

</TabItem>
<TabItem value="claude-code" label="Claude Code">

Si instalaste el plugin de Adapty, Claude Code ya muestra el servidor como `plugin:adapty-skills:adapty`, con el estado **Needs authentication**. Para iniciar sesión, ejecuta `/mcp` en Claude Code, selecciona `plugin:adapty-skills:adapty` y elige **Authenticate**.

Sin el plugin, añade primero el servidor:

```bash
claude mcp add --transport http --scope user adapty https://mcp.adapty.io/mcp
```

Luego ejecuta `/mcp` en Claude Code, selecciona `adapty` y elige **Authenticate**. Si las herramientas de Adapty no aparecen en la sesión actual, inicia una sesión nueva.

</TabItem>
<TabItem value="codex" label="Codex">

Si instalaste el plugin de Adapty, el plugin añade el servidor y Codex te pedirá que inicies sesión cuando se conecte.

Sin el plugin, añade el servidor e inicia sesión:

```bash
codex mcp add adapty --url https://mcp.adapty.io/mcp
codex mcp login adapty
```

El comando de inicio de sesión abre tu navegador. Para configurar el servidor manualmente, agrégalo a `~/.codex/config.toml` y luego ejecuta el comando de inicio de sesión:

```toml
[mcp_servers.adapty]
url = "https://mcp.adapty.io/mcp"
```

Inicia una nueva sesión de `codex` para cargar las herramientas de Adapty.

</TabItem>
<TabItem value="other" label="Other clients">

Añade `https://mcp.adapty.io/mcp` como servidor MCP remoto en la configuración de tu cliente o en el archivo de configuración MCP. La primera vez que se conecte, el cliente abrirá tu navegador para iniciar sesión.

El servidor identifica a cada cliente mediante el Client ID Metadata Document, el método de registro de clientes de la especificación MCP actual. Un cliente que no admite este método no puede completar el inicio de sesión. En ese caso, usa el [Adapty Developer CLI](developer-cli-quickstart) desde un agente de terminal.

</TabItem>
</Tabs>

## Iniciar sesión \{#sign-in\}

Todos los clientes terminan en el mismo sitio: la página de inicio de sesión de Adapty en tu navegador.

1. Inicia sesión con tu cuenta de Adapty, si aún no lo has hecho.
2. Permite que el cliente acceda a tu cuenta de Adapty.

El cliente leerá y modificará los datos de las empresas a las que tiene acceso tu cuenta, y permanecerá conectado hasta que lo desconectes. Aprueba solo un inicio de sesión que hayas iniciado tú mismo.

Para verificar la conexión, pregúntale al asistente con qué cuenta de Adapty ha iniciado sesión. La respuesta debería indicar tu nombre y las empresas a las que tiene acceso tu cuenta.

## Empieza a trabajar \{#start-working\}

Pregúntale al asistente qué apps puede ver y luego indícale en cuál quieres trabajar. Algunas peticiones que puedes probar:

```text
List my Adapty apps and their placements.
How did revenue and new subscriptions change last month compared with the month before?
Which products in Fitness Pro have no App Store product ID?
Show who sees what on the onboarding placement, including any A/B test.
Create a draft A/B test on main_paywall: the current paywall against Annual sale, 50/50.
```

El asistente pide confirmación antes de los pasos que cambian lo que ven los usuarios. Una solicitud que solo lee datos se ejecuta sin preguntas.

Después de una tarea de varios pasos, el asistente puede enviar al equipo de Adapty una nota breve sobre cómo fue la tarea. La nota no contiene datos personales de los usuarios de tu app.

## Desconexión \{#disconnect\}

Para desconectarte, elimina el servidor en el cliente:

- **claude.ai**: En **Settings → Connectors**, elimina el conector de Adapty.
- **Claude Code**: Ejecuta `claude mcp remove adapty`. Si el servidor se instaló con el plugin de Adapty, desactívalo en `/mcp`.
- **Codex**: Elimina el servidor `adapty` de `~/.codex/config.toml`.

Para volver a conectarte, añade el servidor e inicia sesión de nuevo.

## Solución de problemas \{#troubleshooting\}

| Problema | Solución |
|---|---|
| Claude Code muestra el servidor como **Needs authentication** | El cliente añadió el servidor pero no inició sesión. Ejecuta `/mcp`, selecciona el servidor de Adapty y elige **Authenticate**. |
| El cliente no muestra herramientas de Adapty | Completa el inicio de sesión y empieza una nueva sesión. Algunos clientes solo cargan las herramientas al comienzo de una sesión. |
| El asistente no encuentra una app | La app pertenece a una empresa a la que tu cuenta de Adapty no tiene acceso. Pide acceso al propietario de la empresa. |
| El cliente no puede completar el inicio de sesión | El cliente no admite el método de inicio de sesión que usa el servidor. Conéctate desde claude.ai, Claude Code o Codex, o usa la [CLI para desarrolladores de Adapty](developer-cli-quickstart). |
