Adapty genera automáticamente archivos de configuración JSON para tus [paywalls de respaldo](/fallback-paywalls), uno por plataforma. Estos archivos también contienen datos de respaldo para tus onboardings.

Si un placement tiene varias [audiencias](audience), el archivo de respaldo solo usa la audiencia **All users**. Si esa audiencia ejecuta una prueba A/B, el archivo contiene cada variante de la prueba y el SDK distribuye a los usuarios entre ellas según el peso asignado. Las [pruebas A/B entre placements](ab-test-types) nunca se incluyen en el archivo. Adapty actualiza estos archivos cada vez que modificas tus paywalls u onboardings.

Sigue los pasos a continuación para descargar tus configuraciones de respaldo:

1. Abre la página **[Placements](https://app.adapty.io/placements)**.
2. Haz clic en el botón **Fallbacks**.
3. Selecciona tu plataforma de destino (*iOS* o *Android*) en el desplegable.
4. Selecciona tu versión del SDK para iniciar la descarga.

:::tip
Para descargar el archivo desde la terminal, usa el [Developer CLI](developer-cli). Indica la versión del SDK de Adapty con la que está compilada tu app:

```bash
adapty fallbacks get --app <app-id> --platform ios --sdk-version <sdk-version> --output ios_fallback.json
```

Ejecútalo una vez por store, con `--platform ios` o `--platform android`. Consulta [`adapty fallbacks get`](developer-cli-fallbacks) para ver los flags.
:::
