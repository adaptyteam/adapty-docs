Adapty lee tus productos, valida compras y recibe eventos de suscripción a través de las siguientes APIs de Google:

- Google Play Android Developer API
- Google Play Developer Reporting API
- Cloud Pub/Sub API

## Antes de empezar \{#before-you-start\}

Comprueba que tienes los [privilegios de acceso y el proyecto de Google Cloud que necesita la integración con Google Play](initial-android#before-you-start). Sin ellos, no podrás completar los pasos siguientes.

## Habilitar las APIs \{#enable-the-apis\}

1. Abre la [Google Cloud Console](https://console.cloud.google.com/).

2. Selecciona el proyecto que usarás para la integración.

3. Abre la página de la [**Google Play Android Developer API**](https://console.cloud.google.com/apis/library/androidpublisher.googleapis.com).

4. Haz clic en **Enable** y espera a que el estado muestre **Enabled**. Si el botón indica **Manage** en lugar de eso, la API ya está activa y no hay nada que hacer.

   <ZoomImage id="gp-api-library-enable.webp" width="700px" alt="Una página de API en la biblioteca de API de Google Cloud, con el botón Enable" />

5. Abre la página de la [**Google Play Developer Reporting API**](https://console.cloud.google.com/apis/library/playdeveloperreporting.googleapis.com).

6. Haz clic en **Enable** y espera a que el estado muestre **Enabled**.

7. Abre la página de la [**Cloud Pub/Sub API**](https://console.cloud.google.com/apis/library/pubsub.googleapis.com).

8. Haz clic en **Enable** y espera a que el estado muestre **Enabled**.

Para confirmarlo, abre la página [**APIs & Services**](https://console.cloud.google.com/apis/dashboard) en Google Cloud Console. La tabla que aparece en la parte inferior lista todas las APIs habilitadas en el proyecto, y las tres deberían aparecer:

- Google Play Android Developer API
- Google Play Developer Reporting API
- Cloud Pub/Sub API

<ZoomImage id="gp-apis-enabled-list.webp" width="700px" alt="Tabla de APIs y servicios habilitados con las tres APIs requeridas" />
