[FunnelFox](https://funnelfox.com) crea funnels web: páginas de aterrizaje y cuestionarios que venden tus suscripciones fuera de la App Store y Google Play. Conecta FunnelFox a Adapty para dar a los compradores web acceso a las funciones de pago en tu app móvil, y para ver sus compras en el mismo dashboard que las compras de la store.

Conectar requiere una clave y un ID de nivel de acceso. Tu aplicación debe identificar al comprador para alcanzar ese nivel de acceso. Consulta [Proporciona acceso en tu aplicación](#provide-access-in-your-app).

## Cómo funciona la integración \{#how-the-integration-works\}

FunnelFox gestiona el cobro en la web. A continuación, llama a la [API server-side de Adapty](getting-started-with-server-side-api) para crear el [perfil](profiles-crm), registrar la transacción y otorgar el [nivel de acceso](access-level) cuyo ID introduces en la configuración de la integración de FunnelFox. Las renovaciones, cancelaciones y pagos fallidos actualizan el mismo perfil. Las compras web aparecen en [Adapty analytics](analytics) junto con los ingresos de App Store y Google Play.

Crea un [producto](product) correspondiente en Adapty por cada producto que vende tu embudo. La compra llega a Adapty de cualquier manera, pero sin un producto Adapty no tiene la duración de la suscripción, por lo que los análisis pueden reportar una duración incorrecta o dejar la compra sin categorizar.

Adapty vincula una compra web con un usuario de la app mediante el customer user ID. FunnelFox utiliza por defecto la dirección de correo electrónico introducida en el checkout como ese ID.

Si tu funnel factura a través de Stripe o Paddle, no tienes que conectar ese proveedor a Adapty también. Conéctalo solo si además vendes a través de él fuera de tus funnels, y Adapty deduplicará las transacciones que lleguen desde ambas fuentes.

Para construir el mismo flow con tu propio checkout web en lugar de un funnel de FunnelFox, consulta [Sincronizar compras entre web y móvil](sync-subscribers-from-web).

## Conectar FunnelFox \{#connect-funnelfox\}

La configuración se realiza desde el lado de FunnelFox, siguiendo la [guía de integración de Adapty de FunnelFox](https://funnelfox.com/docs/integrations/subscription-management/adapty#setup). Se necesitan dos valores de Adapty:

- **Secret API key**: Abre [**App Settings**](https://app.adapty.io/settings/general) en Adapty y copia la clave secreta.
- **Access level ID**: El [nivel de acceso](access-level) que otorga una compra. Todas las apps de Adapty comienzan con uno llamado `premium`; si necesitas otro, [créalo](create-access-level) primero.

## Otorga diferentes niveles de acceso dentro de un mismo funnel \{#grant-different-access-levels-within-one-funnel\}

Un funnel que vende un único nivel no necesita nada aquí: cada compra otorga el nivel de acceso definido en la configuración de la integración.

Para vender más de un nivel desde un mismo funnel, usa el campo **Custom entitlement** en un elemento de checkout. Este campo sobreescribe el ID del nivel de acceso de la configuración de la integración para las compras realizadas a través de ese elemento. Un funnel puede contener más de un elemento de checkout, como un botón Wallet y un checkout en acordeón. Cada uno tiene su propio campo **Custom entitlement**, así que rellénalo en cada elemento que deba otorgar el nivel de acceso personalizado.

:::important
Republica el funnel después de cambiar la configuración de la integración o cualquier valor de **Custom entitlement**. Un funnel publicado sigue sirviendo su configuración anterior hasta que lo republiques.
:::

## Proporcionar acceso en tu app \{#provide-access-in-your-app\}

Para desbloquear funciones de pago a un comprador web, llama a `Adapty.activate()` o `Adapty.identify()` con el mismo customer user ID que usó FunnelFox. Por defecto, ese ID es la dirección de correo electrónico que el comprador introdujo en el proceso de pago. Consulta <InlineTooltip tooltip="Identificación de usuarios">[iOS](identifying-users), [Android](android-identifying-users), [React Native](react-native-identifying-users), [Flutter](flutter-identifying-users), [Unity](unity-identifying-users), [Kotlin Multiplatform](kmp-identifying-users) y [Capacitor](capacitor-identifying-users)</InlineTooltip> para ver la llamada correspondiente.

Instalar la app desde un enlace del funnel no identifica al comprador. Hasta que tu app llame a `Adapty.identify()` con el ID correspondiente, el perfil que tiene el nivel de acceso y el perfil que la app creó permanecen separados, y la app no muestra ningún acceso de pago. Iniciar sesión con el correo del checkout los vincula.

Para desbloquear el acceso sin un paso de inicio de sesión, pasa el customer user ID del funnel a la app mediante un deferred deep link y llama a `Adapty.identify()` con ese ID en el primer lanzamiento.

Luego lee el nivel de acceso del perfil para desbloquear las funciones. Consulta <InlineTooltip tooltip="Comprobación del estado de la suscripción">[iOS](ios-check-subscription-status), [Android](android-check-subscription-status), [React Native](react-native-check-subscription-status), [Flutter](flutter-check-subscription-status), [Unity](unity-check-subscription-status), [Kotlin Multiplatform](kmp-check-subscription-status), y [Capacitor](capacitor-check-subscription-status)</InlineTooltip>.

## Prueba la integración \{#test-the-integration\}

1. Completa una compra en tu funnel.
2. En Adapty, abre [**Profiles**](https://app.adapty.io/profiles/users) y busca el perfil por el ID de usuario cliente que usa FunnelFox.
3. Confirma que el nivel de acceso cuyo ID introdujiste en la configuración de la integración de FunnelFox está activo en ese perfil.
4. Abre tu app, identifica al mismo usuario y confirma que las funciones de pago se desbloquean.

## Solución de problemas \{#troubleshooting\}

### Un comprador web abre la app sin acceso de pago \{#a-web-buyer-opens-the-app-without-paid-access\}

Tu app no ha identificado al comprador. FunnelFox otorgó el nivel de acceso a un perfil vinculado al ID que utilizó, que por defecto es el correo electrónico del checkout, y tu app está leyendo un perfil diferente. Llama a `Adapty.identify()` con ese ID, tal como se describe en [Proporcionar acceso en tu app](#provide-access-in-your-app).

## Otras integraciones de FunnelFox \{#other-funnelfox-integrations\}

FunnelFox se conecta a tres productos de Adapty, cada uno configurado por separado.

| Producto | Qué envía FunnelFox a Adapty | Guía de configuración |
|---|---|---|
| Core | Perfiles, transacciones y niveles de acceso, para que las compras web desbloqueen la app | Este artículo |
| Adapty Attribution | Eventos de transacción con datos de campaña, funnel y experimento | [Integrar FunnelFox con Adapty Attribution](ua-funnelfox) |
| Adapty Mail | Direcciones de correo electrónico, historial de compras y eventos de suscripción | [Conectar FunnelFox a Adapty Mail](mail-funnelfox) |
