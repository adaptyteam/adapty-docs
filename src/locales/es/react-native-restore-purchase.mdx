Restaurar compras en iOS y Android es una funcionalidad que permite a los usuarios recuperar el acceso a contenido adquirido previamente, como suscripciones o compras in-app, sin que se les vuelva a cobrar. Esta funcionalidad resulta especialmente útil para quienes han desinstalado y vuelto a instalar la app, o han cambiado de dispositivo, y quieren acceder a su contenido anterior sin pagar de nuevo.

:::note
Si construiste la pantalla con un builder, no necesitas restaurar las compras manualmente. Conecta su control de restauración — la acción **Restore purchases** en el Flow & Paywall Builder, o un enlace o botón de restauración en el antiguo — y el SDK completa la restauración.
:::

Si construiste la pantalla tú mismo, llama al método `.restorePurchases()`:

```typescript showLineNumbers
try {
    const profile = await adapty.restorePurchases();
    const isSubscribed = profile.accessLevels['YOUR_ACCESS_LEVEL']?.isActive;
  
    if (isSubscribed) {
        // restore access
    }
} catch (error) {
    // handle the error
}
```

Parámetros de respuesta:

| Parámetro | Descripción |
|---------|-----------|
| **Profile** | <p>Un objeto [`AdaptyProfile`](https://react-native.adapty.io/interfaces/adaptyprofile). Este modelo contiene información sobre los niveles de acceso, suscripciones y compras únicas.</p><p>Comprueba el **estado del nivel de acceso** para determinar si el usuario tiene acceso a la aplicación.</p> |

:::info
En Adapty React Native SDK 4.0.3 y versiones posteriores, `restorePurchases()` se completa correctamente incluso cuando no hay nada que restaurar: devuelve el perfil actual, así que comprueba en él el estado del nivel de acceso. En versiones anteriores del SDK, el método devuelve el error `noPurchasesToRestore` en Android en este caso.
:::
