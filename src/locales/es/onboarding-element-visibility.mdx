Puedes controlar si un elemento aparece añadiéndole una condición. Un elemento condicional solo es visible para los usuarios que cumplan los criterios especificados.

:::important
Si muestras u ocultas un elemento usando las acciones **Show element** o **Hide element** [action](onboarding-actions), la acción anula la condición de **Visibility** establecida en ese elemento. La anulación dura hasta que se actualice una variable o el estado de un elemento en la condición.

En un elemento con una condición de **Visibility**, estas acciones cambian el elemento de inmediato, [sin animación ni retraso](flow-show-hide-animations#when-animation-and-delay-dont-apply).

Usa las condiciones de **Visibility** para los elementos que deben aparecer u ocultarse en función de un criterio, como una respuesta de un cuestionario. Usa acciones cuando la visibilidad deba cambiar en un momento concreto, como [cuando se abre la pantalla o el usuario pulsa un elemento](flow-show-hide-animations#show-or-hide-an-element).
:::

Para añadir una condición a un elemento:

1. Selecciona el elemento en el canvas o en el panel de capas.
2. En la sección **Visibility** del panel derecho, selecciona **Conditional**.

<ZoomImage id="flow-conditional-visibility.webp" width="500px" alt="Configuración de visibilidad condicional" />

3. Configura la condición eligiendo un tipo de propiedad en una de las tres pestañas:
   - **Custom**: Variables que creas y gestionas tú; sus valores se pueden actualizar mediante interacciones del usuario. Consulta [Variables](onboarding-variables) para más detalles.
   - **Products**: Propiedades de los productos de tu flow, como el precio o el nombre.
   - **Elements**: Estados de otros elementos del flow, como si un interruptor de prueba está activo.
4. Introduce el **Value** que quieres comparar.
5. Haz clic en el operador para cambiarlo si es necesario.
6. (Opcional) Haz clic en **Add condition** para añadir más condiciones. Usa el selector para exigir que se cumplan todas las condiciones o al menos una de ellas.
