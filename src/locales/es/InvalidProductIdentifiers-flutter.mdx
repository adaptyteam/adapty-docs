El error 1000, `noProductIDsFound`, indica que ninguno de los productos que solicitaste en el paywall están disponibles para compra en el App Store, aunque estén listados allí. Este error puede ir acompañado de un aviso `InvalidProductIdentifiers`. Si el aviso aparece sin error, puedes ignorarlo sin problema.

Si estás encontrando el error `noProductIDsFound`, sigue estos pasos para resolverlo:

## Paso 6. Vuelve a crear el producto si está bloqueado \{#step-6-recreate-the-product-if-its-stuck\}

Los pasos 1–5 pueden superarse sin problemas —estado `Approved`, Bundle ID coincidente, clave API válida— y aun así el SDK devuelve `1000 noProductIDsFound`. En ese caso, el producto puede estar bloqueado en el registro de Apple. El registro de productos de Apple entra ocasionalmente en un estado en el que el producto existe en la interfaz de App Store Connect pero no está disponible en la ruta de búsqueda de StoreKit.

Elimina el producto en App Store Connect y vuelve a crearlo con el mismo ID de producto. Espera hasta 24 horas tras la recreación para que se propague.
