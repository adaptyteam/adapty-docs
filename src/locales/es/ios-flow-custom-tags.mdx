Un [custom tag](flow-custom-tags) es una variable personalizada con un valor proveniente de tu app. Después de seleccionar **Value comes from outside the app** en la configuración de una variable, tu app puede establecer su valor a través del SDK de Adapty. Por ejemplo, un elemento de texto contiene "Coins:" y un custom tag. Si tu app pasa "120" para el tag, los usuarios ven "Coins: 120".

## Pasar valores de etiquetas personalizadas \{#pass-custom-tag-values\}

Pasa los valores de tu app al parámetro `tagResolver` de `getFlowConfiguration`, como un diccionario `[String: String]`:

- Cada clave es el nombre completo de una etiqueta personalizada, como `user.streak`.
- Cada valor es el texto que verán los usuarios en lugar de la etiqueta.
- Cada valor debe ser legible para personas, como "1.250", no "1250.0". Adapty no lo formatea ni traduce.

```swift showLineNumbers title="Swift"
let customTags = [
    "username": "DragonSlayer42",
    "coins": "1,250",
]

do {
    let flowConfiguration = try await AdaptyUI.getFlowConfiguration(
        forFlow: flow,
        tagResolver: customTags
    )
    // present the flow
} catch {
    // handle the error
}
```

El [modificador `.flow` y `AdaptyFlowView`](ios-present-paywalls#present-flows-and-paywalls-in-swiftui) de SwiftUI y el [controlador de flow](ios-present-paywalls#present-flows-and-paywalls-in-uikit) de UIKit no tienen ningún parámetro para valores de etiquetas personalizadas. Muestran los valores de la configuración del flow que les proporcionas.

### Pasar el IMC al paywall

Recoge el peso y la altura de los eventos `flow_user_input` del flow de onboarding, como se explica en [Procesar datos de flows](ios-flow-input). Para saber que el usuario llegó a la última pantalla, observa el evento `flow_screen_showed` con `is_last_screen` en `true`, como se explica en [Rastrear vistas de pantalla del flow](ios-flow-screen-views). Cuando el usuario cierre el flow de onboarding después de esa pantalla, calcula el IMC. Luego obtén la configuración del flow del paywall y pasa el IMC para la etiqueta personalizada `bmi`.

El siguiente código es para UIKit. Implementa los métodos de `AdaptyFlowControllerDelegate` en un único view controller, que actúa como delegado tanto del controlador del flow de onboarding como del controlador del paywall. El view controller también debe implementar los métodos de compra y restauración del delegado, que este ejemplo omite. Para verlos, consulta [Presentar flows y paywalls en UIKit](ios-present-paywalls#present-flows-and-paywalls-in-uikit).

```swift showLineNumbers title="Swift"
private var bodyAnswers: [String: String] = [:]
private var reachedLastScreen = false

func flowController(
    _ controller: AdaptyFlowController,
    didReceiveAnalyticEvent name: String,
    params: [String: any Sendable]
) {
    if name == "flow_screen_showed", params["is_last_screen"] as? Bool == true {
        reachedLastScreen = true
        return
    }
    guard name == "flow_user_input",
          let elementId = params["element_id"] as? String,
          let value = params["value"] as? String
    else { return }

    bodyAnswers[elementId] = value
}

func flowControllerDidDisappear(_ controller: AdaptyFlowController) {
    // This delegate receives events from both flows. Reset `bodyAnswers` and
    // `reachedLastScreen` whenever a flow disappears, so that the paywall
    // doesn't open again when the user closes it.
    let answers = bodyAnswers
    let finished = reachedLastScreen
    bodyAnswers.removeAll()
    reachedLastScreen = false

    // Number inputs send their values as strings.
    guard finished,
          let weight = answers["weight"].flatMap({ Double($0) }),
          let height = answers["height"].flatMap({ Double($0) }),
          height > 0
    else { return }

    let heightInMeters = height / 100
    let bmi = weight / (heightInMeters * heightInMeters)

    Task {
        await showBMIPaywall(bmi: bmi.formatted(.number.precision(.fractionLength(1))))
    }
}

func showBMIPaywall(bmi: String) async {
    do {
        let flow = try await Adapty.getFlow(placementId: "bmi_paywall")
        let flowConfiguration = try await AdaptyUI.getFlowConfiguration(
            forFlow: flow,
            tagResolver: ["bmi": bmi]
        )
        let flowController = try AdaptyUI.flowController(
            with: flowConfiguration,
            delegate: self
        )
        present(flowController, animated: true)
    } catch {
        // handle the error
    }
}
```

`formatted` usa el separador decimal de la configuración regional del usuario: "22.7" en inglés, "22,7" en alemán.

En SwiftUI, usa los closures del modificador `.flow` del onboarding en lugar de los métodos del delegado:

- `didReceiveAnalyticEvent`: Recoge el peso y la altura, y espera el evento `flow_screen_showed` de la última pantalla.
- `didDisappear`: Si el usuario llegó a la última pantalla, calcula el IMC. Luego obtén la configuración del flow del paywall y pasa el IMC para el tag personalizado `bmi`. Presenta esa configuración con un segundo modificador `.flow`.

### Guardar el IMC en el perfil del usuario \{#save-the-bmi-to-the-users-profile\}

Para mostrar distintos flows a los usuarios según su IMC, guárdalo como un [atributo personalizado](setting-user-attributes#custom-user-attributes) de su perfil. En el Adapty Dashboard, [crea un atributo personalizado de tipo **Number**](segments#custom-attributes) con la clave `bmi`. Luego muestra cada flow a una [audiencia](audience) definida a partir de ese atributo.

Llama al método `updateProfile` en `flowControllerDidDisappear`, justo después de la línea que calcula `bmi`. Pasa el `Double`, no el string formateado, para que un segmento pueda comparar el IMC con un umbral:

```swift showLineNumbers title="Swift"
do {
    let params = try AdaptyProfileParameters.Builder()
        .with(customAttribute: bmi, forKey: "bmi")
        .build()
    try await Adapty.updateProfile(params: params)
} catch {
    // handle the error
}
```
