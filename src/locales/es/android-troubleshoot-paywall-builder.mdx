Esta guía te ayuda a resolver problemas frecuentes al usar paywalls diseñados en el Paywall Builder de Adapty en el SDK de Android. Para problemas con flows, consulta [Problemas comunes](flow-common-issues).

## Fallo al obtener la configuración de un paywall \{#getting-a-paywall-configuration-fails\}

**Problema**: El método `getViewConfiguration` no consigue recuperar la configuración del paywall.

**Causa**: El paywall no está habilitado para mostrarse en el dispositivo en el Paywall Builder.

**Solución**: Activa el botón **Show on device** en el Paywall Builder.

## El número de visualizaciones del paywall es demasiado alto \{#the-paywall-view-number-is-too-big\}

**Problema**: El contador de visualizaciones del paywall muestra el doble de lo esperado.

**Motivo**: Es posible que estés llamando a `logShowFlow` (Android SDK v4+) / `logShowPaywall` en tu código, lo que duplica el contador de visualizaciones de un paywall creado en el antiguo Paywall Builder. Adapty registra esas visualizaciones automáticamente, por lo que no necesitas usar este método.

**Solución**: Asegúrate de no estar llamando a `logShowFlow` (Android SDK v4+) / `logShowPaywall` en tu código para un paywall creado en el antiguo Paywall Builder.

## Otros problemas \{#other-issues\}

**Problema**: Experimentas otros problemas relacionados con el Paywall Builder que no se cubren aquí.

**Solución**: Si es necesario, migra el SDK a la versión más reciente siguiendo las [guías de migración](android-sdk-migration-guides). Muchos problemas se resuelven en versiones más recientes del SDK.
