Cada vez que un usuario abre una pantalla en un [flow](adapty-flow-builder), el SDK notifica un evento `flow_screen_showed` a tu app. Reenvíalo a Amplitude, Mixpanel o cualquier herramienta de analítica de producto que uses, para poder analizar las pantallas del flow junto con el resto de los eventos de tu app.

:::tip
Para ver hasta dónde llegan los usuarios en un flow, no necesitas código: las [métricas de flow](flow-metrics) ya muestran vistas, finalizaciones y abandono por pantalla en el Adapty Dashboard. Usa esta guía cuando necesites esos mismos datos en tu propia analítica, combinados con eventos que Adapty no conoce.
:::

## Antes de empezar \{#before-you-start\}

Necesitas:

- **Adapty iOS SDK v4 o posterior**: El callback de análisis de flow no existe en versiones anteriores.
- **Una versión del flow publicada después del lanzamiento de esta función**: Adapty genera los eventos de pantalla al publicar un flow, así que un flow que publicaste antes de esa fecha no reportará nada. Si no llega ningún evento a tu app, publica una nueva versión del flow e inténtalo de nuevo.

## Qué recibes \{#what-you-receive\}

<FlowScreenShowedParams />

Las vistas de pantalla llegan al mismo callback de analíticas que el resto de eventos del flow. Consulta [Gestionar eventos de flow y paywall](ios-handling-events) para saber dónde registrarlo.

## Reenvía cada vista de pantalla a tu sistema de analítica \{#forward-every-screen-view-to-your-analytics\}

Comprueba el nombre del evento antes de leer cualquier otra cosa, ya que un flow puede reportar otros eventos a través del mismo callback.

```swift showLineNumbers title="Swift"
func flowController(
    _ controller: AdaptyFlowController,
    didReceiveAnalyticEvent name: String,
    params: [String: any Sendable]
) {
    guard name == "flow_screen_showed" else { return }

    let screenId = params["instanceId"] as? String
    let screenOrder = params["screen_order"] as? Int

    // Send screenId and screenOrder to your analytics provider here.
}
```

## Ejecuta código cuando el usuario llega al final \{#run-code-when-a-user-reaches-the-end\}

`is_last_screen` es `true` en una pantalla a partir de la cual el flow no puede avanzar. Úsalo para desbloquear contenido, marcar el onboarding como completado o enviar tu propio evento de finalización, sin necesidad de añadir una acción de botón en el builder.

```swift showLineNumbers title="Swift"
func flowController(
    _ controller: AdaptyFlowController,
    didReceiveAnalyticEvent name: String,
    params: [String: any Sendable]
) {
    guard name == "flow_screen_showed",
          params["is_last_screen"] as? Bool == true
    else { return }

    // The user reached the end of the flow.
}
```

Llegar a la última pantalla no es lo mismo que cerrar el flow. Un usuario puede ver la pantalla final y cerrar el flow sin realizar ninguna acción, y un flow con ramas puede terminar en varias pantallas diferentes. Para saber que el flow en sí desapareció, usa `flowControllerDidDisappear` en UIKit, o el closure `didDisappear` en SwiftUI en su lugar.
