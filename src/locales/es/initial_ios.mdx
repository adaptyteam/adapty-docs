Conecta tu app del App Store con Adapty para que pueda validar compras, recibir eventos de suscripción y leer tus productos del store.

Cada store se conecta por separado, y Adapty valida las compras solo para los stores que hayas conectado. Si tu app también está en Google Play, [conéctalo también](initial-android) — los dos son independientes, y hacer uno no acorta el otro.

La configuración abarca App Store Connect y el Adapty Dashboard, y tarda unos 30 minutos.

## Guía para la integración inicial \{#guide-for-the-initial-integration\}

- [ ] Una vez que creas una cuenta en Adapty e indicas el nombre y la categoría de tu app, configuramos la app por ti dentro de nuestra plataforma Adapty.
- [ ] [Configura la integración con App Store](app-store-connection-configuration) en el Adapty Dashboard y App Store Connect.
- [ ] Instala los SDK de Adapty para los frameworks que uses:
  - [ ] [Instala el SDK de Adapty para iOS nativo](sdk-installation-ios)
  - [ ] [Instala el SDK de Adapty para React Native](sdk-installation-reactnative)
  - [ ] [Instala el SDK de Adapty para Flutter](sdk-installation-flutter)
  - [ ] [Instala el SDK de Adapty para Unity](sdk-installation-unity)
  - [ ] [Instala el SDK de Adapty para Kotlin Multiplatform](sdk-installation-kotlin-multiplatform)
- [ ] Compila tu aplicación y ejecútala en modo sandbox.

Tras completar la integración inicial, puedes [empezar a usar las funciones de Adapty](product).

Ten en cuenta que para que los paywalls y productos se muestren en tu aplicación móvil y para que los análisis funcionen, necesitas hacer cambios en el código de tu app. En concreto, debes [mostrar los paywalls](ios-quickstart-paywalls) como mínimo y, si usas paywalls que no han sido creados con el Paywall Builder, [gestionar el proceso de compra](making-purchases) dentro de tu app.
