Sigue esta receta para mostrar el peso proyectado de cada usuario como un gráfico en un flow de paywall. El usuario introduce su peso actual y su peso objetivo en un flow de onboarding. Tu app recoge ambos valores. El gráfico muestra el progreso semanal que el usuario puede esperar con tu app, del primer valor al segundo. Tu app renderiza el gráfico como una vista nativa en un [elemento personalizado](flow-custom-elements). La vista utiliza Swift Charts.

## 3. Guarda el peso actual y el objetivo en tu app \{#3-save-the-current-and-goal-weight-in-your-app\}

Recoge el peso actual y el objetivo a partir de los eventos `flow_user_input` del flow de onboarding, tal como se describe en [Procesar datos de flows](ios-flow-input). Para saber que el usuario llegó a la última pantalla, escucha el evento `flow_screen_showed` con `is_last_screen` establecido en `true`. Cuando el flow de onboarding se cierre tras esa pantalla, pasa ambos pesos a `showWeightPaywall`, la función que [abre el flow de paywall con el gráfico](#5-match-the-chart-to-the-custom-element).

El siguiente código es para UIKit. Un view controller actúa como delegado de ambos flows. Para añadir los métodos de compra y restauración que implementa cada `AdaptyFlowControllerDelegate`, consulta [Presentar flows y paywalls en UIKit](ios-present-paywalls#present-flows-and-paywalls-in-uikit).

```swift showLineNumbers title="Swift"
private var enteredWeights: [String: String] = [:]
private var reachedLastScreen = false

func flowController(
    _ controller: AdaptyFlowController,
    didReceiveAnalyticEvent name: String,
    params: [String: any Sendable]
) {
    if name == "flow_screen_showed", params["is_last_screen"] as? Bool == true {
        reachedLastScreen = true
        return
    }
    guard name == "flow_user_input",
          let elementId = params["element_id"] as? String,
          let value = params["value"] as? String
    else { return }

    enteredWeights[elementId] = value
}

func flowControllerDidDisappear(_ controller: AdaptyFlowController) {
    // This delegate receives events from both flows. Reset the entered
    // weights whenever a flow disappears, so that the paywall doesn't open
    // again when the user closes it.
    let weights = enteredWeights
    let finished = reachedLastScreen
    enteredWeights.removeAll()
    reachedLastScreen = false

    // Number inputs send their values as strings
    guard finished,
          let currentWeight = weights["weight"].flatMap({ Double($0) }),
          let goalWeight = weights["goal_weight"].flatMap({ Double($0) })
    else { return }

    Task {
        await showWeightPaywall(currentWeight: currentWeight, goalWeight: goalWeight)
    }
}
```

En SwiftUI, utiliza los closures `didReceiveAnalyticEvent` y `didDisappear` del modificador `.flow` en lugar de los métodos del delegado. Presenta el flow del paywall con un segundo modificador `.flow`.

## 4. Crea la vista del gráfico \{#4-create-the-chart-view\}

Crea un modelo de plan de peso y una vista con el gráfico. El plan tiene una entrada por semana, desde el peso actual hasta el peso objetivo. Cuando el usuario arrastra por el gráfico, la vista marca la semana en el punto táctil y muestra el peso proyectado para esa semana:

```swift showLineNumbers title="Swift"

struct WeightPlan {
    let entries: [WeightEntry]

    // One entry per week, from the current weight to the goal weight
    init(currentWeight: Double, goalWeight: Double) {
        let weeklyChange = 0.5 // kg per week
        let startDate = Date.now
        let weeks = Int((abs(goalWeight - currentWeight) / weeklyChange).rounded(.up))
        let step = goalWeight < currentWeight ? -weeklyChange : weeklyChange
        entries = (0...weeks).map { week in
            WeightEntry(
                date: startDate.addingTimeInterval(Double(week) * 7 * 24 * 60 * 60),
                kilograms: week == weeks ? goalWeight : currentWeight + step * Double(week)
            )
        }
    }
}

struct WeightEntry: Identifiable {
    let date: Date
    let kilograms: Double
    var id: Date { date }
}

@available(iOS 16.0, *) // Swift Charts needs iOS 16
struct WeightGoalChart: View {
    let entries: [WeightEntry]
    @State private var selectedDate: Date?

    // The entry closest to the date that the user drags to
    private var selectedEntry: WeightEntry? {
        guard let selectedDate else { return nil }
        return entries.min {
            abs($0.date.timeIntervalSince(selectedDate)) < abs($1.date.timeIntervalSince(selectedDate))
        }
    }

    var body: some View {
        if #available(iOS 17.0, *) {
            chart.chartXSelection(value: $selectedDate)
        } else {
            chart // iOS 16: no drag selection
        }
    }

    private var chart: some View {
        Chart {
            ForEach(entries) { entry in
                LineMark(
                    x: .value("Date", entry.date),
                    y: .value("Weight", entry.kilograms)
                )
            }
            if let selectedEntry {
                RuleMark(x: .value("Date", selectedEntry.date))
                    .foregroundStyle(.gray.opacity(0.3))
                PointMark(
                    x: .value("Date", selectedEntry.date),
                    y: .value("Weight", selectedEntry.kilograms)
                )
                .annotation(position: .top) {
                    Text("\(selectedEntry.kilograms, specifier: "%.1f") kg")
                        .font(.caption.bold())
                }
            }
        }
        .chartYScale(domain: .automatic(includesZero: false))
    }
}
```

La función de arrastre sobre el gráfico requiere iOS 17 o posterior. En iOS 16, los usuarios ven la línea, pero no pueden arrastrar a lo largo de ella.

## 5. Relaciona el gráfico con el elemento personalizado \{#5-match-the-chart-to-the-custom-element\}

Escribe un [resolver](ios-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views) que devuelva la vista del gráfico para el tipo `line_chart` y el ID `weight_goal`. Guarda el plan de peso en una propiedad del resolver:

```swift showLineNumbers title="Swift"

@available(iOS 16.0, *) // the chart needs iOS 16
struct WeightChartResolver: AdaptyUICustomElementsResolver {
    let plan: WeightPlan

    func view(
        forType type: String,
        id: String,
        context: AdaptyUICustomElementContext
    ) -> AnyView? {
        guard type == "line_chart", id == "weight_goal" else {
            return nil // another custom element: show the fallback
        }
        return AnyView(WeightGoalChart(entries: plan.entries))
    }
}
```

Attach the resolver to the paywall flow when you fetch its configuration. Create the resolver with the weight plan from the current and goal weight:

```swift showLineNumbers title="Swift"
func showWeightPaywall(currentWeight: Double, goalWeight: Double) async {
    let plan = WeightPlan(currentWeight: currentWeight, goalWeight: goalWeight)
    do {
        let flow = try await Adapty.getFlow(placementId: "weight_paywall")
        let flowConfiguration = try await AdaptyUI.getFlowConfiguration(
            forFlow: flow,
            customElementsResolver: WeightChartResolver(plan: plan)
        )
        let flowController = try AdaptyUI.flowController(
            with: flowConfiguration,
            delegate: self
        )
        present(flowController, animated: true)
    } catch {
        // handle the error
    }
}
```

Si tu app establece un [resolver de toda la aplicación](ios-flow-custom-elements#set-an-app-wide-resolver), este resolver lo reemplaza en el flow del paywall. `WeightChartResolver` no devuelve ninguna vista para ningún otro Type ni ID, porque el flow del paywall de esta receta no tiene otros elementos personalizados. Si tu flow del paywall tiene otros elementos personalizados, pasa el resolver de toda la aplicación a este. Luego llama al resolver de toda la aplicación para sus Types e IDs, como se indica en [Adjuntar un resolver a un solo flow](ios-flow-custom-elements#attach-a-resolver-to-one-flow).

## 6. Prueba en un dispositivo \{#6-test-on-a-device\}

El Flow & Paywall Builder no puede ejecutar el código de tu app, por lo que el lienzo solo muestra el respaldo. Para previsualizar el gráfico:

1. [Publica ambos flows](builder-save-publish). Para ver las últimas versiones publicadas en lugar de las versiones en caché, registra el dispositivo como [dispositivo de prueba](test-devices).
2. Ejecuta una compilación de tu app que incluya el resolver. Usa un dispositivo con iOS 17 o posterior. Completa el flow de onboarding con un peso actual y un peso objetivo. Verifica que la línea del gráfico empiece en el peso actual y termine en el peso objetivo.
3. Arrastra a lo largo del gráfico y verifica que el peso proyectado para la semana bajo tu dedo aparezca encima de la línea.

Para probar el respaldo, haz que `WeightChartResolver` devuelva `nil` y vuelve a abrir el flow del paywall.

Para saber por qué aparece el respaldo en lugar del gráfico, sigue las instrucciones de la sección [Probar en un dispositivo](ios-flow-custom-elements#test-on-a-device) de la guía de iOS.
