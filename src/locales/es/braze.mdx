Como una de las principales soluciones de captación de clientes, [Braze](https://www.braze.com/) ofrece una amplia gama de herramientas para notificaciones push, correo electrónico, SMS y mensajería in-app. Al integrar Adapty con Braze, puedes acceder fácilmente a todos tus eventos de suscripción en un solo lugar, lo que te permite activar comunicaciones automatizadas basadas en esos eventos.

Adapty proporciona un conjunto completo de datos que te permite rastrear [eventos de suscripción](events) de todas las stores en un solo lugar y puede usarse para actualizar los perfiles de tus usuarios en Braze. Con Adapty, puedes ver fácilmente cómo se comportan tus suscriptores, conocer sus preferencias y usar esa información para comunicarte con ellos de forma dirigida y efectiva. Por lo tanto, esta integración te permite rastrear eventos de suscripción en tu dashboard de Braze y vincularlos con tus [campañas de adquisición.](https://www.braze.com/product/journey-orchestration)

Adapty envía eventos de suscripción, propiedades de usuario y compras a Braze, para que puedas crear comunicaciones dirigidas a los clientes mediante notificaciones push de Braze tras una integración breve y sencilla como se describe a continuación.

## Cómo configurar la integración con Braze \{#how-to-set-up-braze-integration\}

Para conectar Adapty con Braze, abre [**Integrations** → **Braze**](https://app.adapty.io/integrations/braze) en el Adapty Dashboard, activa el interruptor y completa las credenciales:

- **REST API key** y **Braze Instance ID** son obligatorios.
- **iOS App ID** y **Android App ID** son opcionales.

1. Para crear la **REST API key**, en el dashboard de Braze, ve a **Settings** → **APIs and Identifiers** y haz clic en **Create API Key**. En los permisos de datos de usuario, selecciona `users.track`. Braze no permite modificar los permisos de una clave una vez creada, por lo que si una clave no tiene `users.track`, deberás reemplazarla por una nueva. Para más información, consulta [Creating REST API keys](https://www.braze.com/docs/api/basics#creating-rest-api-keys) en la documentación de Braze.
2. Para encontrar el **Braze Instance ID**, compara la URL de tu dashboard de Braze con la [tabla de instancias](https://www.braze.com/docs/api/basics/#endpoints) en la documentación de Braze. El ID de instancia tiene un formato regional, como `US-03` o `EU-01`. Por ejemplo, `dashboard-03.braze.com` corresponde a `US-03`.
3. Para encontrar el **iOS App ID** y el **Android App ID**, en el dashboard de Braze, ve a **Settings** → **APIs and Identifiers** → **App Identifiers**. Copia el valor de la columna **Identifier** para cada app. Para más información, consulta [App identifier](https://www.braze.com/docs/api/identifier_types#app-identifier) en la documentación de Braze.

## Eventos, atributos de usuario y compras \{#events-user-attributes-and-purchases\}

Justo debajo de las credenciales hay tres grupos de eventos que puedes enviar a Braze desde Adapty. Activa simplemente los que necesites. También puedes cambiar los nombres de los eventos según lo que necesites enviar a Braze. Consulta la lista completa de eventos que ofrece Adapty [aquí](events):

Adapty enviará eventos de suscripción y atributos de usuario a Braze mediante una integración servidor a servidor, lo que te permitirá verlos en tu Braze Dashboard y configurar campañas basándote en ellos.

Para los eventos que tienen ingresos, como las conversiones de prueba y las renovaciones, Adapty enviará esta información a Braze como compras.

:::warning
Adapty envía ingresos a Braze únicamente como eventos de compra legacy. Braze ha puesto los eventos de compra legacy en modo de mantenimiento y no los habilita para nuevos clientes. Si tu workspace de Braze no los acepta, Braze rechaza cada evento que tenga ingresos con HTTP 400 y el mensaje `Legacy purchase ingestion is disabled`. Esos eventos, como primeras compras, renovaciones, conversiones de prueba y reembolsos, no llegan a Braze en absoluto, no solo sus ingresos.

Antes de activar la integración, asegúrate de que tu workspace de Braze acepta eventos de compra heredados. Para más información, consulta [Purchase events](https://www.braze.com/docs/user_guide/data/activation/events/purchase_events) en la documentación de Braze.
:::

[Aquí](messaging#event-properties) encontrarás las especificaciones completas de las propiedades de los eventos enviados a Braze.

:::note
Atributos de usuario útiles

Adapty envía por defecto algunos atributos de usuario para la integración con Braze. Consulta la lista que se incluye a continuación para determinar cuáles se adaptan mejor a tus necesidades.
:::

| Atributo de usuario | Tipo | Valor |
|--------------|----|-----|
| `adapty_customer_user_id` | String | Contiene el valor del identificador único del usuario definido por el cliente. Se puede encontrar tanto en el [Dashboard](profiles-crm) de Adapty como en Braze. |
| `adapty_profile_id` | String | Contiene el valor del identificador único del Perfil de Usuario de Adapty, que se puede encontrar en el [Dashboard](profiles-crm) de Adapty. |
| `environment` | String | <p>Indica si el usuario opera en un entorno sandbox o de producción.</p><p></p><p>Los valores son `Sandbox` o `Production`</p> |
| `store` | String | <p>Contiene el nombre de la Store utilizada para realizar la compra.</p><p></p><p>Valores posibles:</p><p>`app_store` o `play_store`.</p> |
| `vendor_product_id` | String | <p>Contiene el valor del ID de producto en la store de Apple/Google.</p><p></p><p>p. ej., org.locals.12345</p> |
| `subscription_expires_at` | String | <p>Contiene la fecha de vencimiento de la suscripción más reciente.</p><p></p><p>El formato del valor es:</p><p>YYYY-MM-DDTHH:mm:ss.SSS+TZ</p><p>p. ej., 2023-02-15T17:22:03.000+0000</p> |
| `active_subscription` | String | El valor se establecerá en `true` en cualquier evento de compra o renovación, o en `false` si la suscripción ha expirado. |
| `period_type` | String | <p>Indica el tipo de período más reciente para la compra o renovación.</p><p></p><p>Los valores posibles son</p><p>`trial` para un período de prueba o `normal` para el resto.</p> |

Todos los valores float se redondearán a int. Los strings permanecen igual.

Además de la lista predefinida de etiquetas disponibles, es posible enviar [atributos personalizados](segments#custom-attributes) mediante etiquetas. Esto permite mayor flexibilidad en el tipo de datos que se pueden incluir con la etiqueta y puede resultar útil para rastrear información específica relacionada con un producto o servicio. Todos los atributos de usuario personalizados se envían automáticamente a Braze si el usuario marca la casilla **Send user attributes** en [la página de integración](https://app.adapty.io/integrations/braze).

## Configuración del SDK \{#sdk-configuration\}

Para vincular perfiles de usuario en Adapty y Braze, debes configurar el SDK de Braze con el mismo ID de usuario que Adapty o usar su método `.changeUser()`:

<Tabs groupId="current-os" queryString>
<TabItem value="swift" label="iOS (Swift)" default>
```swift showLineNumbers
let braze = Braze(configuration: configuration)
braze.changeUser(userId: "adapty_customer_user_id")
```
</TabItem>
<TabItem value="kotlin" label="Android (Kotlin)" default>
```kotlin showLineNumbers
Braze.getInstance(context).changeUser("adapty_customer_user_id")
```
</TabItem>
</Tabs>
