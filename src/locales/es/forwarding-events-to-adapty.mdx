Si tu backend necesita mantener su URL en App Store Connect, reenvía las notificaciones del servidor de App Store desde tu backend a Adapty sin modificarlas. Si tu backend no necesita su URL en App Store Connect, [configura el reenvío a tu backend en Adapty](enable-app-store-server-notifications#raw-events-forwarding) en su lugar. Esa opción no requiere código.

Adapty procesa las notificaciones de tu backend como si Apple las hubiera enviado directamente. Con [Refund Saver](refund-saver), Adapty sigue respondiendo a las solicitudes de reembolso que lleguen entre ellas.

Si tu backend recibe notificaciones de desarrollador en tiempo real de Google Play a través de su propio tema de Pub/Sub, no necesita ningún código para pasarlas a Adapty. [Añade una suscripción push para Adapty a ese tema](enable-real-time-developer-notifications-rtdn#send-notifications-to-two-adapty-apps).

Para pasar las notificaciones del servidor de App Store a Adapty:

1. En Adapty, abre la app que estás conectando: cada app de Adapty tiene su propia URL de notificaciones. Ve a [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk). En la sección **App Store server notifications**, copia la URL del campo **URL for App Store server notifications**.
2. En tu backend, reenvía cada notificación de Apple a la URL que copiaste. En cada solicitud:

   - Mantén el cuerpo de Apple sin cambios: `{"signedPayload": "…"}`.
   - Establece el encabezado `Content-Type: application/json`.
   - No añadas un encabezado `Authorization`.

   Si Adapty también reenvía notificaciones a tu backend, no las reenvíes de vuelta a Adapty.

Aquí tienes ejemplos para diferentes lenguajes de programación:

  ```go showLineNumbers
package main

	"fmt"
	"strings"
	"net/http"
)

func main() {
	url := "https://api.adapty.io/api/v1/sdk/apple/webhook/123a258e62fad41bfa734f4b0dbcad45/" // Replace this with the actual URL

	payload := strings.NewReader(`{"signedPayload":"eyJhbGciOiJFUzI1NiIs..."}`) // Apple's request body, unchanged

	method := "POST"

	client := &http.Client{}
	req, err := http.NewRequest(method, url, payload)
	if err != nil {
		fmt.Println("Error creating request:", err)
		return
	}
	req.Header.Add("Content-Type", "application/json")

	res, err := client.Do(req)
	if err != nil {
		fmt.Println("Error sending request:", err)
		return
	}
	defer res.Body.Close()
}
  ```

Una respuesta `200` no confirma que Adapty haya podido usar la notificación. Adapty responde antes de decodificar el payload firmado. Para confirmar que las notificaciones llegan a Adapty, realiza una [compra en sandbox](test-purchases-in-sandbox). Luego comprueba que [el estado de las notificaciones](enable-app-store-server-notifications#check-that-notifications-reach-adapty) en la sección **App Store server notifications** aparezca como **Active**.
