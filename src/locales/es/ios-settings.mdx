---

La pestaña [**iOS SDK**](https://app.adapty.io/settings/ios-sdk) en **App settings** contiene las credenciales de App Store de tu app. Para introducirlas todas, sigue [Configurar la integración con App Store](app-store-connection-configuration).

<ZoomImage id="app-settings-ios-sdk.webp" width="700px" alt="Pestaña iOS SDK en App settings" />

| Sección | Qué contiene y por qué Adapty la necesita | Dónde configurarla |
|---|---|---|
| **SDK status** | Si el SDK de Adapty está instalado en tu app | [Instalación del SDK de Adapty](installation-of-adapty-sdks) |
| **Bundle ID** | El Bundle ID de tu app para procesar compras | [Introducir el Bundle ID y el Apple App ID](app-store-connection-configuration#enter-the-bundle-id-and-apple-app-id) |
| **In-app purchase API (StoreKit 2)** | La clave de compra in-app para validar compras | [Añadir la clave de compra in-app a Adapty](generate-in-app-purchase-key) |
| **App Store Connect shared secret** | El shared secret específico de la app para validar recibos de compra y crear productos en App Store Connect | [Introducir el app-specific shared secret](app-store-connection-configuration#enter-the-app-specific-shared-secret) |
| **App Store server notifications** | La URL que recibe los eventos de suscripción de Apple y una URL opcional de tu servidor a la que Adapty los reenvía | [Habilitar las notificaciones del servidor de App Store](enable-app-store-server-notifications) |
| **Apple Retention Messaging API** | La URL que envías a Apple cuando solicitas acceso a la Retention Messaging API | [Configurar Retention Messaging](retention-messaging-setup) |
| **App Store promotional offers** | El ID y el archivo de la clave de compra in-app para firmar ofertas promocionales | [Añadir la clave de compra in-app a Adapty](generate-in-app-purchase-key) |
| **App Store Connect API key** | Una clave de la pestaña **Team Keys** en App Store Connect para crear productos allí y sincronizar su estado y precios | [Añadir la clave de API de App Store Connect a Adapty](app-store-connect-api-key) |
| **Apple App ID** | El Apple ID de tu app para buscar y crear productos en App Store Connect, entre otros usos | [Introducir el Bundle ID y el Apple App ID](app-store-connection-configuration#enter-the-bundle-id-and-apple-app-id) |
