Adapty admite la integración con sistemas de pago web para ayudarte a gestionar suscripciones y compras tanto desde tu app móvil como desde tu sitio web en un único lugar. Esto te permite:

- Recopilar datos de suscripción tanto de compras in-app como de compras en sitio web en un único sistema
- Conceder acceso a funciones de pago en tu app móvil a usuarios que compraron en tu sitio web
- Ver analíticas y datos de suscripción de todos los canales de venta en un solo dashboard

Integraciones disponibles:

- [Stripe](stripe)
- [Paddle](paddle)
- [FunnelFox](funnelfox)
