Adapty Mail ejecuta un servidor MCP, de modo que un asistente de IA puede trabajar en tu proyecto igual que tú lo harías en el dashboard: generar y localizar campañas, lanzar flows, configurar un dominio de envío, consultar perfiles y leer analíticas. El asistente inicia sesión con tu propia cuenta de Adapty Mail y obtiene tus permisos en cuanto apruebas la conexión en el dashboard. No se necesita ninguna clave de API.

| | |
|---|---|
| URL del servidor | `https://api-mail.adapty.io/mcp` |
| Protocolo | MCP sobre Streamable HTTP, inicio de sesión OAuth 2.1 |
| Compatible con | Claude (web y escritorio), ChatGPT, Claude Code, Codex CLI, GitHub Copilot CLI, Gemini CLI, Cursor, Windsurf, y cualquier cliente que admita servidores MCP remotos con OAuth |

:::tip
Para obtener los mejores resultados en un agente de código, añade también el [skill de Adapty Mail](mail-skill). Se conecta al servidor por ti, pregunta antes de hacer cualquier cosa que envíe correos a personas reales, y cubre el trabajo posterior al lanzamiento: resultados, pruebas A/B y por qué alguien no recibió un correo.
:::

## Qué puede hacer el asistente \{#what-the-assistant-can-do\}

Las herramientas del servidor reflejan el dashboard:

| Área | Ejemplos |
|---|---|
| Orientación | Localiza tus empresas y proyectos, ve qué pasos de configuración faltan |
| Marca | Crea la marca a partir de un listado en la store, revísala y edítala |
| Dominios de envío | Añade un dominio, obtén sus registros DNS, comprueba la verificación, consulta el estado del dominio |
| Destinos | Crea y actualiza las páginas a las que enlazan tus correos |
| Campañas | Genera una campaña a partir de un brief, edita correos, tradúcelos, envía un correo de prueba |
| Flows y segmentos | Crea segmentos y lanza o modifica flows |
| Pruebas A/B | Crea, lanza y finaliza pruebas |
| Perfiles | Busca un perfil y su historial, da de baja a un perfil |
| Analítica | Métricas de campaña a lo largo del tiempo, desgloses, embudos de pruebas A/B |
| Ajustes | Nombre del remitente, dirección de respuesta, doble opt-in, subida de imágenes |

Hay tres flujos de trabajo guiados disponibles como prompts en los clientes que los admiten. En Claude Code aparecen como comandos slash, por ejemplo `/mcp__adaptymail__campaign_to_flow`:

- **campaign_to_flow**: Genera una campaña a partir de un brief, elige un destino y un segmento, y lanza el flow.
- **campaign_localization**: Traduce una campaña guardada a más idiomas.
- **domain_onboarding**: Añade un dominio de envío, publica sus registros DNS y verifícalo.

Algunos pasos de configuración solo se realizan en el dashboard: tu [dirección de empresa](mail-get-started#5-add-your-company-address), el [web checkout](mail-checkout) y la [activación del envío de datos](mail-entry-points).

## Antes de empezar

- **Membresía del proyecto**: Tu cuenta de Adapty Mail es miembro del proyecto en el que quieres trabajar. El asistente solo ve las empresas y proyectos que tu cuenta puede abrir.
- **Compatibilidad del cliente**: Tu cliente admite servidores MCP remotos con OAuth.

:::warning
El asistente tiene los mismos permisos que tú, y todo lo que hace es real: guardar un flow empieza a enviar correos a personas reales. El servidor marca sus herramientas destructivas, y los asistentes que hemos probado piden confirmación antes de ejecutarlas. Lee el plan del asistente antes de aprobarlo.
:::

## Conecta tu asistente \{#connect-your-assistant\}

### Claude (claude.ai y Claude desktop)

1. Para añadir el servidor, abre **Settings → Connectors** y haz clic en **Add custom connector**.
2. Introduce un nombre, por ejemplo `Adapty Mail`, y la URL `https://api-mail.adapty.io/mcp`.
3. Deja **Authentication** en **Sign in now** y el cliente OAuth en el valor predeterminado detectado, luego haz clic en **Add**.
4. En la pestaña Adapty Mail que se abre, inicia sesión si se te pide y haz clic en **Approve**.

Los administradores del espacio de trabajo pueden añadir el conector una sola vez para toda la organización. Cada miembro inicia sesión con su propia cuenta de Adapty Mail la primera vez que lo usa.

### ChatGPT

ChatGPT añade servidores MCP personalizados desde la página de conectores en **Settings**. El modo desarrollador debe estar habilitado en tu workspace.

1. Para añadir el servidor, haz clic en **Create**.
2. Introduce un nombre, por ejemplo `Adapty Mail`, y la URL del servidor `https://api-mail.adapty.io/mcp`. Mantén **Authentication** en **OAuth**.
3. Acepta la advertencia del servidor MCP personalizado y haz clic en **Create**.
4. Cuando ChatGPT lo solicite, conecta el servidor. En la pestaña de Adapty Mail que se abre, inicia sesión si es necesario y haz clic en **Approve**.

### Claude Code

```bash
claude mcp add --transport http --scope user adaptymail https://api-mail.adapty.io/mcp
```

Para iniciar sesión, ejecuta `/mcp` en Claude Code, selecciona `adaptymail` y elige **Authenticate**. Luego inicia sesión en el Adapty Mail dashboard en tu navegador y haz clic en **Approve**.

### Codex CLI

```bash
codex mcp add adaptymail --url https://api-mail.adapty.io/mcp
codex mcp login adaptymail
```

El comando de login abre tu navegador, donde apruebas la conexión. Para configurar el servidor manualmente, agrégalo a `~/.codex/config.toml` y luego ejecuta el comando de login:

```toml
[mcp_servers.adaptymail]
url = "https://api-mail.adapty.io/mcp"
```

### GitHub Copilot CLI

```bash
copilot mcp add --transport http adaptymail https://api-mail.adapty.io/mcp
```

La primera vez que el servidor se conecta, el navegador se abre para iniciar sesión.

### Gemini CLI

```bash
gemini mcp add --transport http --scope user adaptymail https://api-mail.adapty.io/mcp
```

Inicia una nueva sesión y ejecuta `/mcp auth adaptymail` para aprobar la conexión en tu navegador.

### Cursor, Windsurf y otros clientes

Añade el servidor al archivo de configuración MCP del cliente, por ejemplo `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "adaptymail": {
      "url": "https://api-mail.adapty.io/mcp"
    }
  }
}
```

La primera vez que se conecta, el cliente abre el navegador para iniciar sesión. Los clientes que no admiten OAuth para servidores remotos no pueden conectarse a Adapty Mail.

## Aprobar la conexión \{#approve-the-connection\}

Todos los clientes terminan en la misma pantalla del dashboard de Adapty Mail. En ella aparece el nombre de la aplicación que solicita acceso y la dirección donde la aplicación recibe ese acceso. En el caso de herramientas de escritorio, esa dirección está en tu propio equipo (`localhost`), así que aprueba únicamente una conexión que hayas iniciado tú. Para finalizar, haz clic en **Approve**.

La solicitud de conexión caduca pasados 10 minutos. Si la pantalla muestra **This request has expired**, vuelve a empezar desde el cliente.

## Empieza a trabajar \{#start-working\}

Pide al asistente que liste tus proyectos y luego nombra el que quieres trabajar. Algunas solicitudes que puedes probar:

- "Muéstrame el estado de onboarding de mi proyecto e indícame qué falta."
- "Genera una campaña de recuperación para usuarios cuyo trial haya expirado, en inglés, y muéstrame el primer email."
- "Traduce la campaña Trial expired al alemán y al francés."
- "Añade `mail.example.com` como dominio de envío y dame los registros DNS."
- "Compara las tasas de apertura y clics de mis campañas activas en los últimos 30 días."

## Desconexión \{#disconnect\}

Para desconectarte, elimina el conector en los ajustes del cliente. En Claude, está en **Settings → Connectors**; en ChatGPT, en la página del conector; en Claude Code, ejecuta `claude mcp remove adaptymail`.

El token de acceso del cliente expira en una hora. El token de actualización se revoca cuando el cliente se desconecta; uno sin usar expira tras 90 días. Para volver a conectarte, añade el servidor y aprueba la conexión de nuevo.

## Solución de problemas \{#troubleshooting\}

| Problema | Solución |
|---|---|
| El dashboard indica que la solicitud de conexión ha expirado | Inicia la conexión de nuevo desde el cliente y apruébala en un plazo de 10 minutos. |
| El asistente indica que no se encontró el proyecto | Tu cuenta no es miembro de ese proyecto. Solicita acceso al propietario de la empresa. |
| El asistente cerró sesión | El acceso expira tras un largo período de inactividad o al desconectarte. Vuelve a conectarte desde el cliente. |
| El cliente no muestra ninguna herramienta | El cliente se conectó sin iniciar sesión. Ejecuta el paso de inicio de sesión correspondiente, por ejemplo `/mcp` en Claude Code. |
