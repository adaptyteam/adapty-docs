:::important
Este artículo trata sobre los paywalls de respaldo para Adapty SDK v3 y versiones anteriores. En SDK v4, un único archivo de respaldo incluye datos de flows y paywalls — consulta [Fallback flows](fallback-flows). El formato antiguo del archivo de respaldo no es compatible con SDK v4, así que descarga la versión correcta después de actualizar.
:::

Para mantener una experiencia de usuario fluida, es importante que configures **versiones de respaldo** para tus [paywalls](paywalls) y [onboardings](onboardings).

Cuando tu aplicación carga un paywall, el SDK de Adapty solicita los datos de configuración del paywall a nuestros servidores. ¿Pero qué ocurre si el dispositivo no puede conectarse a Adapty por problemas de red o caídas del servidor?

* Si el usuario accedió al paywall anteriormente y el dispositivo guardó sus datos en caché, la aplicación carga los datos del paywall **desde la caché**.
* Si el dispositivo no tiene el paywall en caché, la aplicación busca un archivo de configuración almacenado localmente. Esto le permite mostrar el paywall sin errores.

Adapty genera automáticamente archivos de configuración de respaldo para que los descargues y uses. Cada archivo contiene configuraciones específicas de plataforma para *todos* tus placements.

## Primeros pasos \{#get-started\}

1. [Descarga el archivo de configuración de respaldo](/local-fallback-paywalls) desde Adapty.
2. Usa el SDK de Adapty para configurar tus paywalls de respaldo:
    * [iOS](ios-use-fallback-paywalls)
    * [Android](android-use-fallback-paywalls)
    * [React Native](react-native-use-fallback-paywalls)
    * [Flutter](flutter-use-fallback-paywalls)
    * [Unity](unity-use-fallback-paywalls)
    * [Kotlin Multiplatform](kmp-use-fallback-paywalls)
    * [Capacitor](capacitor-use-fallback-paywalls)

## Limitaciones \{#limitations\}

Los paywalls de respaldo están codificados de forma fija y se almacenan localmente, por lo que carecen de las capacidades dinámicas de los paywalls regulares de Adapty.

* Los paywall de respaldo no admiten [internacionalización](paywall-localization). El archivo siempre usa el locale `en`, por lo que los usuarios sin conexión solo ven inglés. [Actualiza al SDK v4](migration-to-ios-sdk-v4) para eliminar esa limitación: su archivo de respaldo incluye todos los locales.
* Cada placement solo puede tener un paywall de respaldo. Si tu configuración incluye diferentes configuraciones de paywall para distintas [audiencias](audience), Adapty usa la configuración destinada a "All users".
* Los paywall de respaldo no admiten [pruebas A/B](ab-tests). Si un paywall participa en una prueba A/B, su archivo de configuración de respaldo incluirá la variante con mayor peso.
* Los paywall de respaldo no se pueden [gestionar de forma remota](customize-paywall-with-remote-config). Si quieres actualizar el archivo de configuración, debes publicar una nueva versión de la app en App Store / Google Play.
