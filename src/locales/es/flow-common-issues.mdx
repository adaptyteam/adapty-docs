Este artículo recoge los problemas que surgen con más frecuencia al crear un flow en el [Flow Builder](adapty-flow-builder), cada uno con su causa y su solución.

## Un flow no se puede previsualizar ni publicar \{#a-flow-wont-preview-or-publish\}

<ZoomImage id="flow-publish-error.webp" width="300px" alt="Mensaje de error al publicar en la interfaz web del Flow Builder cuando un flow tiene acciones incompletas" float="right" />

No es posible publicar ni previsualizar tu flow si se da alguno de los siguientes problemas.

- Una interacción con una configuración incompleta. Casos habituales:
    - Una acción **Open URL** sin URL de destino.
    - Una acción **Navigate to screen** sin destino — también ocurre cuando se elimina la pantalla de destino después de configurar la acción.
    - Una **acción condicional** sin operador ni valor.
    - Una acción **Set variable** sin asignación de variable/valor.
    - Una acción **Purchase** sin producto (compra in-app) o sin URL de Web Paywall (pago web).
    - Una acción **Custom** sin ID de acción.
    - Una acción **Show alert** con el Título o el Mensaje vacíos.
    - Una acción **Show** o **Hide** sin ningún elemento seleccionado.
    - Una acción **Select product** sin producto de destino — también ocurre cuando el elemento de producto de destino se elimina, se mueve fuera de su grupo de productos o se deja en otra pantalla.
    - Una acción **Select product** guardada dentro de un componente reutilizable, o que apunta a un ID de elemento usado en más de una pantalla.
- Una **pantalla sin elementos**.
- Un elemento de producto **sin producto asociado** — puede ocurrir si eliminas el producto referenciado.
- Un JSON de **Remote Config** inválido interrumpe todo el proceso de entrega — ni siquiera es posible guardar el borrador.

Para detectarlos antes de publicar, [previsualiza el flow en la app de Adapty](paywall-device-compatibility-preview). Si el flow no carga, el mensaje de error te dará más información.

## La acción Set variable no cambia el producto seleccionado \{#a-set-variable-action-doesnt-change-the-selected-product\}

El producto seleccionado no es una variable que puedas asignar, por lo que **Set variable** no puede cambiar la selección. Usa la acción [**Select product**](onboarding-actions#select-product) en su lugar.

## Una imagen o vídeo no se sube \{#an-image-or-video-wont-upload\}

Los archivos que estén fuera de los límites de medios del Flow Builder no se subirán. Verifica el archivo según los requisitos de [imagen](custom-media#image) y [vídeo](custom-media#video):

| Elemento | Formatos | Tamaño máximo de archivo | Otros límites |
| :--- | :--- | :--- | :--- |
| Imagen | `.JPG`, `.PNG`, `.WEBP` | 20 MB | — |
| Vídeo | `.MP4`, `.WEBM` | 50 MB | Máximo 30 segundos; mínimo 640×640 píxeles |

Estos formatos no son compatibles:

- **GIFs animados y WEBPs animados**: Para añadir movimiento, usa un elemento de vídeo en su lugar.
- **SVG**: Exporta el archivo como PNG o WEBP. Para los iconos, no necesitas subir nada — el elemento de icono usa la biblioteca [Tabler Icons](custom-media#icon) incluida.
