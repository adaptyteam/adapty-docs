El Flow & Paywall Builder incluye tres tipos de elementos multimedia en la categoría **Media**: Image, Video e Icon.

:::tip
Para que una imagen o vídeo cubra toda la pantalla, incluyendo las áreas detrás del notch y el indicador de inicio, colócalo como fijo con todos los desplazamientos en 0 y selecciona **Ignore safe area**. Consulta [Diseño y posicionamiento](manage-paywall-ui-elements#ignore-safe-area).
:::

## Imagen \{#image\}

Sube un archivo `.JPG`, `.PNG` o `.WEBP` de hasta 20 MB.

Los GIF y WEBP animados no son compatibles. Para añadir movimiento, usa un elemento [Video](#video).

:::tip
Para colocar tu contenido sobre una imagen a pantalla completa, [crea una imagen hero](paywall-head-picture#use-a-background-as-a-hero-image) a partir de un fondo de pantalla y una hoja deslizante.
:::

- **Content mode** — controla cómo la imagen rellena su contenedor cuando defines su altura. Consulta [Tamaño de imagen](#image-sizing).
- **Use custom media ID** — consulta [ID de medio personalizado](#custom-media-id) más abajo.

### Tamaño de la imagen \{#image-sizing\}

Una imagen tiene sus propias proporciones, y el contenedor que le asignas puede no coincidir con ellas. Establece primero el ancho y luego decide el alto:

- **Alto automático**. La imagen mantiene su forma: el alto se calcula a partir del ancho que establezcas. El **Content mode** se desactiva porque no hay nada que recortar.
- **Alto fijo o de relleno**. El contenedor adquiere sus propias proporciones y el **Content mode** resuelve el desajuste:
  - **Fit**. Escala la imagen completa dentro del contenedor y deja espacio vacío.
  - **Fill**. Recorta lo que sobresale. Valor predeterminado.

Para mantener una imagen sin recortar en cualquier ancho de pantalla, usa el ancho **Fill** con la altura **Auto**. Con una altura fija, el recorte en la parte superior e inferior varía de un tamaño de pantalla a otro.

## Vídeo \{#video\}

Sube un archivo `.MP4` o `.WEBM` de hasta 50 MB y no más de 30 segundos. La resolución mínima del vídeo es de 640x640 píxeles.

- **Aspect** — controla cómo el vídeo rellena su contenedor cuando estableces su altura. Consulta [Tamaño del vídeo](#video-sizing).
- **Loop** — reproduce el vídeo en bucle continuo. Activado por defecto.
- **Use custom media ID** — consulta [ID de medio personalizado](#custom-media-id) más abajo.

Los vídeos no se reproducen en la vista previa del editor: el lienzo muestra un fotograma estático. En el dispositivo durante la ejecución, el vídeo se reproduce sin sonido por defecto. Con **Loop** activado, se repite indefinidamente.

### Tamaño del vídeo \{#video-sizing\}

Un vídeo tiene sus propias proporciones, y el contenedor que le asignes puede no coincidir con ellas. La altura determina lo que ocurre:

- **Hug height**. La altura sigue las proporciones propias del vídeo.
- **Fixed o Fill height**. La propiedad **Aspect** resuelve el desajuste:
  - **Fit**. Escala el vídeo completo dentro del contenedor y deja espacio vacío.
  - **Fill**. Recorta lo que se desborde. Valor por defecto.

Cuando Adapty no puede leer las proporciones de un vídeo al subirlo, muestra una advertencia: "Could not determine video dimensions. Set a fixed height to ensure the video displays correctly." Dale al vídeo una altura fija, o asegúrate de que el contenedor que lo aloja tenga una. De lo contrario, su altura puede colapsar a 0.

### Desencadenar una acción cuando el vídeo termina \{#trigger-an-action-when-the-video-ends\}

:::link
Artículo principal: [Acciones](onboarding-actions)
:::

El elemento Video admite un trigger **On playback finished** que se activa cuando el vídeo llega al final. Configúralo en el panel **Interactions** para navegar a otra pantalla, mostrar un CTA o ejecutar cualquier otra acción.

## Icono \{#icon\}

<ZoomImage id="builder-icon-selection.webp" width="300px" float="right" alt="Selector de iconos con la biblioteca Tabler Icons" />

Elige entre la biblioteca integrada [Tabler Icons](https://tabler.io/icons), con miles de iconos en dos estilos visuales:

- **Stroke** — solo contorno.
- **Filled** — relleno sólido.

Busca en el selector por palabra clave para encontrar un icono. Configura el color del icono en el selector **Color** — elige un [estilo de color](builder-styling) guardado o establece un color personalizado.

## Localizar contenido multimedia \{#localize-media\}

:::link
Artículo principal: [Añadir un idioma](add-paywall-locale-in-adapty-paywall-builder)
:::

Los elementos de imagen y vídeo pueden contener un archivo diferente por idioma. Activa el idioma de destino, selecciona el elemento y sube el archivo localizado en el panel de propiedades. Los idiomas que no tienen su propio archivo muestran el archivo del idioma predeterminado.

### Limitaciones \{#limitations\}

No es posible localizar los siguientes elementos:

- Iconos
- El **Fill** de una pantalla o un contenedor — esto incluye los fondos de pantalla y la imagen o vídeo de fondo propio de un contenedor, configurados desde la sección [Fill](builder-styling#fill). Para variar una imagen o vídeo según el idioma, agrégala como elemento independiente de tipo [Image](#image) o [Video](#video); estos sí admiten un archivo específico por idioma, tal como se describe en [Localizar contenido multimedia](#localize-media).
- IDs de contenido multimedia personalizados

## ID de medio personalizado \{#custom-media-id\}

:::important
También puedes establecer un ID de medio personalizado para un [fondo](paywall-head-picture) de imagen o vídeo.
:::

Etiqueta un elemento de imagen o vídeo con un ID de medio personalizado para intercambiarlo en tiempo de ejecución desde el código de tu app. Úsalo para [elementos visuales personalizados](get-pb-paywalls#customize-assets) — por ejemplo, para mostrar el avatar elegido por el usuario.

El medio que subas en el Flow & Paywall Builder actúa como respaldo. Si tu código no proporciona ningún medio para ese ID en tiempo de ejecución, se muestra el respaldo.

Un ID de medio personalizado solo puede sustituir un archivo por otro del mismo tipo: una imagen por una imagen, un vídeo por un vídeo. Si los tipos no coinciden, se muestra el respaldo.

Para habilitar un ID de medio personalizado en un elemento de imagen o vídeo:

1. Selecciona la casilla **Use custom media ID** bajo el área de carga.
2. Introduce un ID de medio.
3. Sube una imagen o vídeo de respaldo.

En el código de tu app, obtén el medio por su ID. Consulta [Personalizar assets](get-pb-paywalls#customize-assets) para ver la API del SDK.
