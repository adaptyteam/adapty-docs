La navegación y ramificación te permite guiar a los usuarios por cada paso de tu flow: usa rutas estáticas para llevar a todos a las pantallas principales, y navegación dinámica para adaptar el flow según las elecciones del usuario.

Cuando los usuarios se mueven entre pantallas, el flow puede mostrar [animaciones de transición](flow-screen-transitions).

:::link
La navegación es un tipo de acción. Para obtener más información sobre las acciones, consulta [Acciones](onboarding-actions).
:::

## Navegar entre pantallas \{#navigate-between-screens\}

Puedes configurar la navegación estática y dinámica usando distintos elementos del flow.

Para mover a los usuarios a otra pantalla unos segundos después de que se abra la pantalla actual, [retrasa una acción **Navigate to Screen** bajo el disparador **On Screen Appear**](flow-screen-transitions#move-users-to-another-screen-automatically).

### Navegación estática \{#static-navigation\}

La navegación estática dirige a todos los usuarios a la misma pantalla de destino. Para configurarla:
1. Selecciona cualquier elemento que los usuarios puedan pulsar: botón, respuesta de quiz o interruptor.

   <ZoomImage id="add-trigger.webp" width="500px" alt="Add trigger button" />

2. Abre el panel **Interactions** a la derecha. Allí, haz clic en **Add trigger**.

   Para navegar a los usuarios inmediatamente al pulsar una opción del quiz —sin necesidad de pulsar un botón adicional— selecciona aquí el elemento de opción del quiz en lugar de un botón.

   <ZoomImage id="navigate-to-screen-settings.webp" width="300px" alt="Ventana de edición de acción para Navegar a pantalla con Paywall como destino, Deslizar hacia arriba con Ease out bounce, una duración de 400 ms y sin retraso" />

3. Configura el disparador **On tap**:
   - **Action**: Selecciona **Navigate to screen**.
   - **Destination**: Elige la pantalla de destino.
   - **Animation**: Mantén el push predeterminado o selecciona otra [animación](flow-screen-transitions#animation-types).

  <DocVideo id="flow-transition-slide-in.mp4" width="300px" alt="Deslizar hacia dentro: un paywall se desliza hacia arriba y aparece gradualmente sobre la pantalla actual con un ligero rebote; la flecha de retroceso desliza el paywall hacia abajo" />

### Navegación dinámica \{#dynamic-navigation\}

La navegación dinámica enruta a los usuarios según sus respuestas en el quiz, el estado de los elementos toggle y los atributos personalizados.
Cualquier [elemento seleccionable](flow-selectable-elements) puede ser una condición para la navegación dinámica.

Para configurarla:
1. Selecciona el elemento que navegará a los usuarios.
2. Abre el panel **Interactions** a la derecha y haz clic en **Add trigger**.

   Para navegar a los usuarios de inmediato cuando pulsan una opción del quiz —sin necesidad de un toque adicional en un botón— selecciona aquí el elemento de opción del quiz en lugar de un botón.

   <ZoomImage id="add-trigger.webp" width="500px" alt="Botón Add trigger" />

3. Configura el trigger **On tap**:
   - **Action**: Selecciona **Conditional**.
   - **Conditions**: Define las acciones de navegación condicional. Más información [aquí](onboarding-actions#conditional-actions).

<ZoomImage id="conditional-action.webp" width="500px" alt="Acciones condicionales" />

## Cerrar el flow \{#close-flow\}

Si el recorrido del usuario requiere cerrar el flow, puedes configurarlo usando botones o quizzes de respuesta única:

1. Añade y selecciona el elemento que debe cerrar el flow al pulsarlo.
2. Abre el panel **Interactions** a la derecha y haz clic en **Add trigger**.
   <ZoomImage id="add-trigger.webp" width="500px" alt="Botón Add trigger" />

3. Configura el trigger **On tap**:
   - **Action**: Selecciona **Close flow**.

<ZoomImage id="close-flow.webp" width="500px" alt="Acción Close flow" />
