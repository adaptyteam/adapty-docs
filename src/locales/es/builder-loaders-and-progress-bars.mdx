La categoría **Progress** proporciona dos tipos de elementos: uno para el progreso por pasos a través de un flow de varias pantallas, y otro para indicadores de actividad en línea.

## Indicadores de progreso \{#progress-indicators\}

<ZoomImage id="builder-progress-indicator.webp" width="700px" alt="Un indicador de progreso en la parte superior de una pantalla con el panel de ajustes abierto" />

### Estilos de indicador \{#indicator-styles\}

<ZoomImage id="flow-indicators.webp" width="300px" alt="Variantes de indicador de progreso" float="right" />

Un elemento **Progress** muestra la posición del usuario en un flow de varias pantallas. La categoría ofrece tres variantes visuales:

- **Linear** — Una barra única que se rellena conforme el usuario avanza.
- **Segmented** — Barras separadas por cada paso que se van rellenando una a una.
- **Connectors** — Círculos con etiquetas conectados por líneas (p. ej., Step 1, Step 2, Step 3 en secuencia).

### Asociar pasos a pantallas

<ZoomImage id="builder-progress-indicator-settings.webp" width="280px" float="right" alt="Panel de configuración del indicador de progreso con selector de variante, botón de alternancia One segment per screen y desplegable Screens" />

Por defecto, el indicador de progreso hace un seguimiento de todas las pantallas del flow. Para limitarlo a un subconjunto, elige las opciones en el desplegable **Screens**. También puedes abrir la pantalla que quieras excluir y desmarcar la casilla **Include screen in progress indicator**.

Desactiva **One segment per screen** si necesitas un control más preciso sobre el número de pasos.

:::warning
La posición del paso sigue el orden de la lista de pantallas, no el orden en que el usuario las ve realmente. En flows no lineales, el paso mostrado en el indicador puede avanzar o retroceder.
:::

### Estados de los pasos \{#step-states\}

<ZoomImage id="builder-progress-indicator-step-settings.webp" width="280px" float="right" alt="Panel de configuración a nivel de paso con ID, Pantallas y pestañas de estado Completado/Actual/Próximo" />

Cada paso tiene tres estados: **Completed**, **Current** y **Upcoming**. Selecciona un paso dentro del Progress Indicator para editar el estilo de un estado en el panel derecho. Usa **Apply changes to all states** para copiar tus cambios a los otros dos.

Editar un paso afecta a todos los pasos dentro del mismo indicador.

### Diseño y posicionamiento \{#layout-and-positioning\}

El indicador de progreso es un elemento global, por lo que no puedes colocarlo dentro de un [contenedor](builder-containers). Tampoco puedes establecer su posición: utiliza posicionamiento absoluto por defecto. Cuando el usuario desplaza la pantalla, el indicador permanece fijo y el contenido se desplaza por debajo.

Para controlar el espacio alrededor del indicador, usa los controles **Margin** y **Padding** de la sección **Spacing** en lugar de mover el elemento. Si el diseño no se ve bien, ajusta el margen o el relleno tanto en el indicador como en el elemento adyacente.

## Loaders \{#loaders\}

<ZoomImage id="flow-loaders.webp" width="220px" alt="The Loaders templates in the Add element panel: Spinner, Spinner with label, Progress bar, and Progress bar with label" float="right" />

Un **Loader** es un elemento animado que indica que se está procesando algo: por ejemplo, las respuestas de un usuario a un cuestionario para preparar un plan personalizado.

La categoría incluye cuatro plantillas:

- **Spinner** — Un spinner circular.
- **Spinner with label** — Un spinner circular con un texto (por ejemplo, "Loading...").
- **Progress bar** — Una barra horizontal que se llena del 0 al 100%.
- **Progress bar with label** — Una barra horizontal con un texto y un porcentaje (por ejemplo, "Analyzing... 47%").

### Spinners \{#spinners\}

Un spinner gira mientras su pantalla esté abierta. Para cambiar su aspecto, elige uno de los seis estilos en la sección **Spinner**. En la sección **Animation**, **Duration** establece el tiempo de una rotación completa.

La **Duración** de un spinner no determina cuánto tiempo permanece abierta la pantalla. Un disparador **On screen appear** con una acción **Navigate to Screen** lleva a los usuarios a la siguiente pantalla de inmediato. Para mantener una pantalla de carga abierta hasta 5 segundos, añade un **Delay** a la [transición de pantalla](flow-screen-transitions#move-users-to-another-screen-automatically) de esa acción. Para esperas más largas, añade un [Timer](flow-timer) con un disparador **On timer end** que navegue a la siguiente pantalla, o usa una [barra de progreso](#run-actions-when-a-progress-bar-is-full) en su lugar.

### Barras de progreso \{#progress-bars\}

<ZoomImage id="builder-loader-settings.webp" width="280px" float="right" alt="Loader settings with Type set to Radial, Show percentage on, and the Typography, Progress color, and Animation sections" />

Una barra de progreso se llena de 0 a 100% cada vez que se abre su pantalla. En la sección **Loader**, establece **Type** en **Linear** para una barra o en **Radial** para un anillo. Para un anillo, **Thickness** define el grosor de su línea.

En la sección **Animation**:

- **Duration** define cuánto tarda la barra en llenarse.
- **Easing** define cómo acelera y desacelera el relleno.

Para configurar el color del relleno, usa la sección **Progress color**. Para configurar el color de la pista sin rellenar, usa la sección **Fill**.

En el canvas, la barra de progreso aparece llena. Para ver cómo se rellena, reproduce las animaciones del canvas.

### Mostrar el porcentaje \{#show-the-percentage\}

Para mostrar el porcentaje dentro de la barra o del anillo, en la sección **Loader**, activa **Show percentage**. Para cambiar la fuente y el color, usa la sección **Typography**.

Para mostrar el porcentaje en un texto independiente, por ejemplo junto a un título:

1. En la sección **Loader** de la barra de progreso, escribe un **Element ID**, por ejemplo `analysis`.
2. En el texto, inserta la variable `analysis.progress` y escribe `%` después.

El texto cuenta junto con la barra. La plantilla **Progress bar with label** está configurada de esta manera. Un texto que muestra esta variable no puede mostrar otras variables ni valores de producto.

### Ejecutar acciones cuando la barra de progreso esté completa \{#run-actions-when-a-progress-bar-is-full\}

El disparador **On Load Complete** ejecuta sus acciones una sola vez, cuando la barra de progreso llega al 100%. Por ejemplo:

- Para pasar a los usuarios a la siguiente pantalla cuando la barra esté completa, añade una acción **Navigate to Screen**.
- Para mantener el botón **Next** deshabilitado hasta que la barra esté completa, crea una variable booleana con el valor inicial `false` y añade una acción **Set Variable** que la establezca en `true`. Luego, [añade un estado **Disabled**](builder-element-states#condition-driven-disabled-state) al botón que se aplique mientras la variable sea `false`.

### Reproducir barras de progreso una tras otra \{#play-progress-bars-one-after-another\}

<ZoomImage id="builder-loader-start-loader.webp" width="500px" alt="Un disparador On Load Complete con una acción Start loader que inicia un segundo loader" />

Para rellenar varias barras de progreso en secuencia, por ejemplo una barra por cada paso de un análisis:

1. Selecciona todas las barras de progreso excepto la primera. En la sección **Loader**, desactiva **Autostart**. Estas barras se quedan en 0 al abrir la pantalla.
2. Selecciona la primera barra de progreso. En **On Load Complete**, añade una acción **Start loader** y selecciona la segunda barra.
3. Repite el paso 2 para que la segunda barra inicie la tercera, y así sucesivamente.

**Start loader** solo muestra las barras de progreso de la misma pantalla que tienen **Autostart** desactivado. Puedes seleccionar varias barras en una sola acción para que se rellenen al mismo tiempo.

### Retrasar u ocultar un cargador \{#delay-or-hide-a-loader\}

Para mostrar un spinner o una barra de progreso un tiempo después de que se abra la pantalla, en la sección **Animation**, establece **Show after delay** en milisegundos. Una barra de progreso empieza a llenarse cuando finaliza el retraso.

Para mostrar un cargador solo cuando los usuarios pulsen un elemento, establece la **Visibility** del cargador en **Hide**. Después, selecciona el elemento que debe mostrar el cargador y [añade una acción **Show element** que se ejecute **On Tap**](flow-show-hide-animations#show-or-hide-an-element). Una barra de progreso oculta empieza a llenarse cuando aparece, no cuando se abre su pantalla.

### Cuando los usuarios abandonan la pantalla

- Si los usuarios vuelven a una pantalla después de que una barra de progreso haya llegado al 100%, la barra permanece al 100%. Sus acciones **On Load Complete** no se vuelven a ejecutar.
- Si los usuarios abandonan una pantalla antes de que la barra de progreso llegue al 100%, la barra se detiene. Cuando vuelvan, se llenará de nuevo desde 0.

Una barra de progreso que forma parte de un [componente reutilizable](reuse-flow-elements) no puede tener acciones **On Load Complete** dentro de un bottom sheet que abra una acción. Un flow con dicha barra no se publica.
