La categoría **Toggle** ofrece tres elementos que los usuarios pulsan para activar o desactivar algo:

- **Trial toggle**: un interruptor que alterna el paywall entre productos estándar y productos de prueba.
- **Checkbox**: una casilla de verificación con una etiqueta de texto, para consentimiento y confirmación.
- **Toggle**: un interruptor con una etiqueta de texto, para cualquier otra opción de activar/desactivar.

Para añadir uno, haz clic en **+** en la pantalla de destino, abre **Paywall & Commerce** > **Toggle** y selecciona el elemento. Aparecerá en la raíz del árbol de capas — arrástralo al contenedor de destino en el panel **Layers**.

:::note
**Basics** > **Checkmarks** también ofrece gráficos de checkbox, radio y toggle. Son iconos estáticos para decorar filas dentro de otro elemento seleccionable, como una tarjeta de producto. Usa los elementos de este artículo cuando sea el usuario quien seleccione algo por sí mismo.
:::

## Alternancia de prueba \{#trial-toggle\}

:::warning
Apple puede rechazar aplicaciones que usen un interruptor de prueba preseleccionado. Un interruptor configurado en "activado" por defecto puede considerarse un patrón oscuro manipulador según las Directrices de Revisión de la App Store, ya que implica el consentimiento del usuario a una prueba gratuita sin una elección explícita.

Para evitar el rechazo, configura el interruptor en **desactivado** por defecto y permite que los usuarios activen la prueba por sí mismos.
:::

Un interruptor de prueba permite a los usuarios elegir entre productos estándar y productos con periodo de prueba en un paywall. Cuando el usuario cambia su estado, puede desencadenar una acción —como intercambiar grupos de productos, actualizar variables o mostrar y ocultar elementos— de forma instantánea.

## Casilla de verificación \{#checkbox\}

Una casilla de verificación emparejada con una etiqueta de texto, prellenada con `I agree to the Terms and Privacy Policy`. Úsala cuando el usuario necesite confirmar algo antes de que el flow continúe.

## Toggle \{#toggle\}

Un interruptor emparejado con una etiqueta de texto. Úsalo para opciones de activar/desactivar que no cambian el producto — por ejemplo, activar recordatorios antes del paywall o revelar un bloque de contenido adicional.

## Leer el estado en condiciones \{#read-the-state-in-conditions\}

Cada uno de estos elementos es un [elemento seleccionable](flow-selectable-elements), y su grupo determina la variable que refleja su estado:

- Grupo **Toggle**: `<group>.isActive` — **True** o **False**.
- Grupo **Single choice**: `<group>.selectedOptionId` — el ID del elemento seleccionado, vacío mientras no se haya seleccionado nada.

Selecciona el elemento y abre la pestaña **Interactions** para ver a qué grupo pertenece.

Para que otros elementos dependan del estado, establece una [acción](onboarding-actions) condicional o una [visibilidad condicional](onboarding-element-visibility) basada en esta variable.

Tu app también puede [recibir el estado a través del SDK](ios-flow-input). Cada vez que el usuario lo cambie, el SDK informará del nuevo valor, que tu app podrá procesar internamente o en tu back-end.
