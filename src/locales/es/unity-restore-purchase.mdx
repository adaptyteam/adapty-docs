Restaurar compras en iOS y Android es una función que permite a los usuarios recuperar el acceso a contenido adquirido previamente, como suscripciones o compras in-app, sin que se les vuelva a cobrar. Esta función es especialmente útil para usuarios que hayan desinstalado y reinstalado la app o que hayan cambiado de dispositivo y quieran acceder a su contenido comprado anteriormente sin pagar de nuevo.

:::note
Si creaste la pantalla en un builder, no necesitas restaurar las compras manualmente. Conecta su control de restauración — la acción **Restore purchases** en el Flow & Paywall Builder, o un enlace o botón de restauración en el antiguo — y el SDK completa la restauración.
:::

Si creaste la pantalla tú mismo, llama al método `.restorePurchases()`:

```csharp showLineNumbers
Adapty.RestorePurchases((profile, error) => {
    if (error != null) {
        // handle the error
        return;
    }
  
    var accessLevel = profile.AccessLevels["YOUR_ACCESS_LEVEL"];
    if (accessLevel != null && accessLevel.IsActive) {
        // restore access
    }
});
```

Parámetros de respuesta:

| Parámetro | Descripción                                                                                                                                                                                                                                                   |
|---------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Profile** | <p>Un objeto [`AdaptyProfile`](https://unity.adapty.io/class_adapty_s_d_k_1_1_adapty_profile.html). Este modelo contiene información sobre los niveles de acceso, suscripciones y compras únicas.</p><p>Comprueba el **estado del nivel de acceso** para determinar si el usuario tiene acceso a la app.</p> |
