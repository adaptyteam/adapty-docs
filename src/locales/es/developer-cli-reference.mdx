La CLI de Adapty agrupa sus comandos por tema, como `products` o `placements`. Cada tema tiene su propia página con sus comandos, argumentos, flags y valores aceptados. Esta página enumera los temas, los flags que acepta cada comando, el comando que muestra tu versión de la CLI y el comando que instala los skills de Adapty.

| Tema | Comandos | Qué hacen |
|---|---|---|
| [Apps y niveles de acceso](developer-cli-apps) | `apps`, `access-levels` | Crear y configurar apps y los niveles de suscripción que tu app comprueba |
| [Productos y ofertas](developer-cli-products) | `products`, `product-offers` | Configurar productos, asociarlos con los IDs de producto de App Store y Google Play, y vincular las ofertas de la store |
| [Paywalls](developer-cli-paywalls) | `paywalls` | Crear paywalls, asignarles productos y consultar sus métricas |
| [Flows](developer-cli-flows) | `flows`, `fonts` | Crear flows, escribir y validar sus configuraciones del builder, subir las fuentes personalizadas que usan, publicarlos, restaurar versiones anteriores, duplicarlos y consultar sus métricas y el embudo de pantallas |
| [Placements y segmentos](developer-cli-placements) | `placements`, `segments` | Configurar placements, sus audiencias y los segmentos a los que se dirigen. Consultar las métricas de los placements de flows y paywalls |
| [Analytics](developer-cli-analytics) | `analytics` | Consultar gráficos, conversiones, el embudo, retención, LTV y cohortes |
| [Pruebas A/B](developer-cli-ab-tests) | `ab-tests` | Crear, iniciar, detener, reemplazar y archivar pruebas A/B de paywalls y flows, y consultar sus resultados |
| [Atribución](developer-cli-attribution) | `attribution` | Consultar gasto, instalaciones, ingresos y ROAS por canal y campaña |
| [Ads Manager](developer-cli-ads-manager-reference) | `asa` | Gestionar campañas de Apple Ads, palabras clave y reglas de automatización |
| [Retention Messaging](developer-cli-retention-messaging) | `retention-messaging` | Conectar Apple Retention Messaging, ejecutar el test de rendimiento, crear, modificar, activar y desactivar mensajes de retención, y consultar sus métricas |
| [Refund Saver](developer-cli-refund-saver) | `refund-saver` | Activar y desactivar Refund Saver, establecer la preferencia de reembolso de cada store y de un perfil, verificar las claves de cada store, y consultar las solicitudes de reembolso y el ahorro |
| [Monedas virtuales](developer-cli-virtual-currencies) | `virtual-currencies` | Crear monedas virtuales, cambiar cuántos créditos otorga cada producto, y consultar las transacciones de créditos y los saldos de una app o un usuario |
| [Fallbacks](developer-cli-fallbacks) | `fallbacks` | Descargar el archivo de respaldo que tu app incluye para cuando no puede conectar con Adapty |
| [Migraciones](developer-cli-migrations) | `migrations` | Mover un proyecto de RevenueCat a Adapty |
| [Autenticación](developer-cli-authentication) | `auth` | Iniciar sesión, comprobar y revocar tu sesión de CLI |

## Indicadores globales \{#global-flags\}

Estos indicadores están disponibles en todos los comandos.

| Indicador | Descripción |
|---|---|
| `--json` | Muestra la salida como JSON en lugar de texto formateado |
| `--help` | Muestra la ayuda del comando |

Todos los comandos `list`, excepto `adapty product-offers list`, `adapty flows versions list` y las dos listas de transacciones de `adapty virtual-currencies`, también aceptan indicadores de paginación:

| Indicador | Valor por defecto | Descripción |
|---|---|---|
| `--page` | `1` | Número de página |
| `--page-size` | `20` | Elementos por página (máx.: 100) |

`adapty virtual-currencies transactions list` y `adapty virtual-currencies profiles transactions list` leen una página por cada comando con un cursor: aceptan `--page-size` y `--cursor`, no `--page`. Consulta [Leer transacciones de créditos](developer-cli-virtual-currencies#read-credit-transactions).

## Versión de CLI \{#cli-version\}

### adapty version

Muestra la versión instalada del CLI e indica si hay una versión más reciente disponible.

```bash
adapty version
```

El comando imprime la misma línea que `adapty --version`, luego consulta el registro público de npm para obtener la versión más reciente, con un límite de tiempo de 3 segundos. Si hay una versión más reciente disponible, el comando la muestra junto con el comando de actualización, `npm i -g adapty@latest`. Si el registro no responde a tiempo, el comando imprime `Could not check for a newer version.` y aun así termina con el código 0.

Con `--json`, la salida incluye estos campos:

| Campo | Descripción |
|---|---|
| `installed` | Versión instalada de la CLI |
| `latest` | Última versión en npm, o `null` si el registro no responde a tiempo |
| `update_available` | `true` si `latest` es más reciente que `installed`, de lo contrario `false` |

El comando requiere la versión 0.26.1 o posterior de la CLI. Si tienes una versión anterior a la 0.26.1, ejecuta `adapty --version`.

## Skills \{#skills\}

### adapty skills install

Instala los skills de Adapty en los agentes de codificación de esta máquina.

```bash
adapty skills install
```

| Flag | Requerido | Descripción |
|---|---|---|
| `--agent` | No | Agente en el que instalar: `claude-code`, `codex` o `gemini-cli`. Repite la flag para varios agentes. |
| `-y`, `--yes` | No | Instala en todos los agentes encontrados sin preguntar. Obligatorio cuando el CLI encuentra varios agentes y no puede preguntar, por ejemplo con `--json`. |

La CLI busca Claude Code, Codex y Gemini CLI en el `PATH`. Si no encuentra ninguno, pregunta si ejecutar `npx skills@1.7.0 add adaptyteam/adapty-skills --all --global`, que cubre otros agentes. Reinicia el agente para cargar los skills.

Claude Code no actualiza el plugin por su cuenta. Para obtener nuevos skills a medida que se publican, en Claude Code ejecuta `/plugin`, abre **Marketplaces**, selecciona `adapty` y elige **Enable auto-update**. Para activarlo sin usar el menú, añade `"autoUpdate": true` a la entrada `adapty` en `~/.claude/settings.json`:

```json title="~/.claude/settings.json"
{
  "extraKnownMarketplaces": {
    "adapty": {
      "source": { "source": "github", "repo": "adaptyteam/adapty-skills" },
      "autoUpdate": true
    }
  }
}
```

Los skills instalados a través del CLI de skills se actualizan con `npx skills update`. Para Codex, consulta el [README del plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#codex).
