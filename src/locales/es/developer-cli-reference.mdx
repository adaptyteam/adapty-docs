La CLI de Adapty agrupa sus comandos por tema, como `products` o `placements`. Cada tema tiene su propia página con sus comandos, argumentos, flags y valores aceptados. Esta página enumera los temas, los flags que acepta cada comando, el comando que muestra tu versión de la CLI y el comando que instala los skills de Adapty.

| Tema | Comandos | Qué hacen |
|---|---|---|
| [Apps y niveles de acceso](developer-cli-apps) | `apps`, `access-levels` | Crea y configura apps y los niveles de suscripción que tu app verifica |
| [Productos y ofertas](developer-cli-products) | `products`, `product-offers` | Configura productos, asígnalos a IDs de producto de App Store y Google Play, y vincula ofertas del store |
| [Paywalls](developer-cli-paywalls) | `paywalls` | Crea paywalls, asígnales productos y consulta sus métricas |
| [Flows](developer-cli-flows) | `flows` | Crea flows, escribe y valida sus configuraciones del builder, publícalos, restaura versiones anteriores, duplícalos y consulta sus métricas y el embudo de pantallas |
| [Placements y segmentos](developer-cli-placements) | `placements`, `segments` | Configura placements, sus audiencias y los segmentos a los que se dirigen. Consulta las métricas de placements de flows y paywalls |
| [Analytics](developer-cli-analytics) | `analytics` | Consulta gráficos, conversiones, el embudo, retención, LTV y cohortes |
| [Pruebas A/B](developer-cli-ab-tests) | `ab-tests` | Crea, inicia, detiene, reemplaza y archiva pruebas A/B de paywalls y flows, y consulta sus resultados |
| [Atribución](developer-cli-attribution) | `attribution` | Consulta gasto, instalaciones, ingresos y ROAS por canal y campaña |
| [Ads Manager](developer-cli-ads-manager-reference) | `asa` | Gestiona campañas de Apple Ads, palabras clave y reglas de automatización |
| [Retention Messaging](developer-cli-retention-messaging) | `retention-messaging` | Conecta Apple Retention Messaging, ejecuta la prueba de rendimiento, crea, modifica, activa y desactiva mensajes de retención, y consulta sus métricas |
| [Fallbacks](developer-cli-fallbacks) | `fallbacks` | Descarga el archivo de paywall de respaldo que tu app incluye para cuando no puede conectarse a Adapty |
| [Migraciones](developer-cli-migrations) | `migrations` | Mueve un proyecto de RevenueCat a Adapty |
| [Autenticación](developer-cli-authentication) | `auth` | Inicia sesión, verifica y revoca tu sesión de CLI |

## Indicadores globales \{#global-flags\}

Estos indicadores están disponibles en todos los comandos.

| Indicador | Descripción |
|---|---|
| `--json` | Muestra la salida como JSON en lugar de texto con formato |
| `--help` | Muestra la ayuda del comando |

Todos los comandos `list`, excepto `adapty product-offers list` y `adapty flows versions list`, también aceptan indicadores de paginación:

| Indicador | Valor por defecto | Descripción |
|---|---|---|
| `--page` | `1` | Número de página |
| `--page-size` | `20` | Elementos por página (máx.: 100) |

## Versión de CLI \{#cli-version\}

### adapty version

Muestra la versión instalada del CLI e indica si hay una versión más reciente disponible.

```bash
adapty version
```

El comando imprime la misma línea que `adapty --version`, luego consulta el registro público de npm para obtener la versión más reciente, con un límite de tiempo de 3 segundos. Si hay una versión más reciente disponible, el comando la muestra junto con el comando de actualización, `npm i -g adapty@latest`. Si el registro no responde a tiempo, el comando imprime `Could not check for a newer version.` y aun así termina con el código 0.

Con `--json`, la salida incluye estos campos:

| Campo | Descripción |
|---|---|
| `installed` | Versión instalada de la CLI |
| `latest` | Última versión en npm, o `null` si el registro no responde a tiempo |
| `update_available` | `true` si `latest` es más reciente que `installed`, de lo contrario `false` |

El comando requiere la versión 0.26.1 o posterior de la CLI. Si tienes una versión anterior a la 0.26.1, ejecuta `adapty --version`.

## Skills \{#skills\}

### adapty skills install

Instala los skills de Adapty en los agentes de codificación de esta máquina.

```bash
adapty skills install
```

| Flag | Requerido | Descripción |
|---|---|---|
| `--agent` | No | Agente en el que instalar: `claude-code`, `codex` o `gemini-cli`. Repite la flag para varios agentes. |
| `-y`, `--yes` | No | Instala en todos los agentes encontrados sin preguntar. Obligatorio cuando el CLI encuentra varios agentes y no puede preguntar, por ejemplo con `--json`. |

La CLI busca Claude Code, Codex y Gemini CLI en el `PATH`. Si no encuentra ninguno, pregunta si ejecutar `npx skills@1.7.0 add adaptyteam/adapty-skills --all --global`, que cubre otros agentes. Reinicia el agente para cargar los skills.

Claude Code no actualiza el plugin por su cuenta. Para obtener nuevos skills a medida que se publican, en Claude Code ejecuta `/plugin`, abre **Marketplaces**, selecciona `adapty` y elige **Enable auto-update**. Para activarlo sin usar el menú, añade `"autoUpdate": true` a la entrada `adapty` en `~/.claude/settings.json`:

```json title="~/.claude/settings.json"
{
  "extraKnownMarketplaces": {
    "adapty": {
      "source": { "source": "github", "repo": "adaptyteam/adapty-skills" },
      "autoUpdate": true
    }
  }
}
```

Los skills instalados a través del CLI de skills se actualizan con `npx skills update`. Para Codex, consulta el [README del plugin](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#codex).
