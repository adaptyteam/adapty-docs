Configurar las notificaciones de servidor de App Store es fundamental para garantizar la precisión de los datos, ya que te permite recibir actualizaciones al instante desde App Store, incluida información sobre reembolsos y otros eventos.

:::important
Se requiere Adapty iOS SDK 2.10.0 o posterior para la compatibilidad completa con App Store Server Notifications V2.
:::

1. Copia la **URL for App Store server notification** en el Adapty Dashboard.

2. Abre [App Store Connect](https://appstoreconnect.apple.com/apps). Selecciona tu app y ve a la sección **General** → **App Information**, subsección **App Store Server Notifications**.
3. Pega la **URL for App Store server notification** copiada en los campos **Production Server URL** y **Sandbox Server URL**.

:::warning
Completa ambos campos de URL. Sin la **Production Server URL**, Adapty no se entera de las renovaciones, vencimientos y reembolsos que ocurren fuera de la app. Si las notificaciones de producción estuvieron ausentes durante un período, contacta con [support@adapty.io](mailto:support@adapty.io): Adapty puede restaurar el historial perdido desde Apple usando una lista de valores `apple_original_transaction_id`, sin crear duplicados.
:::

Después de guardar las URLs, el estado de las notificaciones en el Adapty Dashboard solo cambia cuando Apple envía la primera notificación real, es decir, cuando ocurre el primer evento de suscripción, como una compra o una renovación. La notificación de prueba de Apple no lo cambia. Un estado de espera justo después de la configuración no significa que la conexión esté rota.

## Reenvío de eventos sin procesar \{#raw-events-forwarding\}

En algunos casos, puede que quieras seguir recibiendo eventos S2S sin procesar desde Apple. Para continuar recibiéndolos mientras usas Adapty, simplemente añade tu endpoint al campo **URL for forwarding raw Apple events** y te enviaremos los eventos tal como los recibimos de Apple.
