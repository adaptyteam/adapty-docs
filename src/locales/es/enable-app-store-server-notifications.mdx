Configurar las notificaciones de servidor de App Store es fundamental para garantizar la precisión de los datos, ya que te permite recibir actualizaciones al instante desde App Store, incluida información sobre reembolsos y otros eventos.

:::important
Se requiere Adapty iOS SDK 2.10.0 o posterior para la compatibilidad completa con App Store Server Notifications V2.
:::

1. Copia la **URL for App Store server notification** en el Adapty Dashboard.

2. Abre [App Store Connect](https://appstoreconnect.apple.com/apps). Selecciona tu app y ve a la sección **General** → **App Information**, subsección **App Store Server Notifications**.
3. Pega la **URL for App Store server notification** copiada en los campos **Production Server URL** y **Sandbox Server URL**.

Después de guardar las URLs, el estado de las notificaciones en el Adapty Dashboard solo cambia cuando Apple envía la primera notificación real, es decir, cuando ocurre el primer evento de suscripción, como una compra o una renovación. La notificación de prueba de Apple no lo cambia. Un estado de espera justo después de la configuración no significa que la conexión esté rota.

## Reenvío de eventos raw \{#raw-events-forwarding\}

A veces puede que quieras seguir recibiendo eventos S2S raw directamente desde Apple. Para continuar recibiéndolos mientras usas Adapty, simplemente añade tu endpoint en el campo **URL for forwarding raw Apple events** y nosotros reenviaremos los eventos tal cual los recibimos de Apple.

:::warning
Si las notificaciones dejan de llegar a Adapty, las nuevas transacciones, renovaciones y reembolsos dejan de registrarse. Adapty no lo señala — consulta [Si las actualizaciones dejan de llegar](store-sync#if-updates-stop-arriving).
:::

## Autenticidad de las notificaciones \{#notification-authenticity\}

Adapty no verifica el origen de las notificaciones entrantes del servidor de App Store más allá de la propia URL de notificación: no comprueba la dirección IP del remitente ni valida la firma JWS de Apple. Trata la URL de notificación como una credencial: cualquier persona que la tenga puede enviar un payload a ella.

El tipo de notificación **TEST** del Sandbox de Apple nunca se almacena, independientemente de quién la envíe, por lo que enviarla manualmente nunca crea un evento en el [Event Feed](event-feed).
