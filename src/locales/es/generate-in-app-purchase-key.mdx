La **clave de compra in-app** es una clave API especializada que se crea en App Store Connect para validar las compras confirmando su autenticidad.

:::note
Para generar claves API para la App Store Server API, debes tener el rol de Admin o Account Holder en App Store Connect. También puedes leer sobre cómo generar claves API en la [Documentación para desarrolladores de Apple](https://developer.apple.com/documentation/appstoreserverapi/creating-api-keys-to-authorize-api-requests).
:::

1. Abre **App Store Connect**. Ve a la sección [**Users and Access** → **Integrations** → **In-App Purchase**](https://appstoreconnect.apple.com/access/integrations/api/subs).

2. Luego haz clic en el botón de añadir **(+)** junto al título **Active**.

3. En la ventana **Generate In-App Purchase Key** que se abre, introduce el nombre de la clave para tu referencia futura. No se utilizará en Adapty.

4. Haz clic en el botón **Generate**. Una vez que la ventana **Generate in-App Purchase Key** se cierre, verás la clave creada en la lista **Active**.

5. Una vez que hayas generado tu clave API, haz clic en el botón **Download In-App Purchase Key** para obtener la clave como archivo.

<Zoom>
  <img src="/assets/shared/img/d59faff-download_in-app_purchase_key.webp"
  style={{
    border: '1px solid #727272', /* border width and color */
    width: '700px', /* image width */
    display: 'block', /* for alignment */
    margin: '0 auto' /* center alignment */
  }}
/>
</Zoom>

6. En la ventana **Download in-App Purchase Key**, haz clic en el botón **Download**. El archivo se guardará en tu ordenador.
   Es fundamental mantener este archivo en un lugar seguro para poder subirlo al Adapty Dashboard más adelante. Ten en cuenta que el archivo generado solo se puede descargar una vez, así que guárdalo en un lugar seguro hasta que lo subas. La clave .p8 generada desde la sección **In-App Purchase section** se utilizará al [configurar la integración inicial de Adapty con App Store](app-store-connection-configuration#step-3-upload-in-app-purchase-key-file).

:::warning
Si esta clave se revoca o elimina más adelante, Adapty no podrá firmar ofertas promocionales y esos descuentos dejarán de aplicarse en la compra. Adapty no lo notifica — consulta [Si las actualizaciones dejan de llegar](store-sync#if-updates-stop-arriving).
:::
