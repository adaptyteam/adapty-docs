Estos comandos de la CLI de Adapty gestionan [productos](product), los asignan a sus IDs de producto en App Store y Google Play, y vinculan ofertas de la store a ellos.

## Productos \{#products\}

### Lista de productos de Adapty \{#adapty-products-list\}

Lista todos los [productos](product) de una app.

```bash
adapty products list --app <app-id>
```

| Flag | Requerido | Descripción |
|---|---|---|
| `--app` | Sí | ID de la app (UUID) |

Acepta [flags de paginación](developer-cli-reference#global-flags).

### adapty products get

Obtén los detalles de un [producto](product) específico.

```bash
adapty products get --app <app-id> <product-id>
```

| Argumento | Descripción |
|---|---|
| `product-id` | ID del producto (UUID) |

| Flag | Requerido | Descripción |
|---|---|---|
| `--app` | Sí | ID de la app (UUID) |

### adapty products create

Crea un nuevo [producto](product).

:::important
Los IDs de producto de la store y los IDs de precio no se pueden cambiar después de la creación. Para usar IDs de store diferentes, crea un nuevo producto.
:::

```bash
adapty products create --app <app-id> --title "Monthly" --access-level-id <access-level-id> --period monthly --ios-product-id com.example.monthly
```

| Flag | Requerido | Descripción |
|---|---|---|
| `--app` | Sí | ID de la app (UUID) |
| `--title` | Sí | Título del producto |
| `--access-level-id` | Sí | ID (UUID) del [nivel de acceso](access-level) que desbloquea este producto |
| `--period` | Sí | Período de suscripción: `weekly`, `monthly`, `two_months`, `trimonthly`, `semiannual`, `annual`, `lifetime` |
| `--ios-product-id` | Al menos un store requerido | ID del producto en App Store Connect |
| `--android-product-id` | Al menos un store requerido | ID del producto en Google Play Console |
| `--android-base-plan-id` | Requerido con `--android-product-id` salvo que se use `--period lifetime` | ID del plan base en Google Play Console |
| `--stripe-product-id` | Al menos un store requerido | ID del producto en Stripe |
| `--stripe-price-id` | Requerido con `--stripe-product-id` | ID del precio en Stripe |
| `--paddle-product-id` | Al menos un store requerido | ID del producto en Paddle |
| `--paddle-price-id` | Requerido con `--paddle-product-id` | ID del precio en Paddle |

Cada producto necesita al menos un store: `--ios-product-id`, `--android-product-id`, `--stripe-product-id`, o `--paddle-product-id`. Un mismo producto puede llevar IDs de varios stores a la vez.

Para vender un producto en la web a través de Stripe o Paddle, primero conecta el proveedor de pago con Adapty: consulta [Stripe](stripe) y [Paddle](paddle). Para cada uno de estos stores, pasa el ID del producto y el ID del precio juntos. El comando falla si solo pasas uno de los dos.

```bash
adapty products create --app <app-id> --title "Monthly" --access-level-id <access-level-id> --period monthly --stripe-product-id prod_xxx --stripe-price-id price_xxx
```

Un producto solo para web es válido: puedes crear un producto con IDs de Stripe o Paddle sin IDs de App Store o Google Play.

### adapty products update

Actualiza un [producto](product) existente.

Los IDs de producto y precio del store no se pueden cambiar después de la creación y no están disponibles en este comando. Para usar IDs de store diferentes, crea un nuevo producto.

```bash
adapty products update --app <app-id> <product-id> --title "Monthly" --access-level-id <access-level-id>
```

| Argumento | Descripción |
|---|---|
| `product-id` | ID del producto (UUID) |

| Indicador | Obligatorio | Descripción |
|---|---|---|
| `--app` | Sí | ID de la app (UUID) |
| `--title` | No | Título del producto |
| `--access-level-id` | No | ID (UUID) del [nivel de acceso](access-level) que desbloquea este producto |

## Ofertas de producto \{#product-offers\}

Vincula las ofertas que creaste en App Store Connect o Google Play Console con un producto de Adapty para que Adapty pueda aplicarlas. Para saber qué hace cada tipo de oferta y cómo crearla en el store, consulta [Añadir ofertas a Adapty](create-offer).

Añade estas ofertas:

- Ofertas promocionales y de recuperación de App Store.
- Todas las ofertas de Google Play, incluidas las pruebas gratuitas. Google Play no tiene un tipo de oferta introductoria, por lo que una prueba es una oferta sobre un plan base y solo se aplica después de vincularla en Adapty.

No añadas ofertas introductorias de App Store: se aplican automáticamente a los usuarios que cumplan los requisitos.

Una oferta vinculada aún tiene que seleccionarse para el producto en un flow o un paywall antes de que los usuarios la vean. Para seleccionarla en un paywall, usa el Adapty Dashboard: consulta [Mostrar oferta](create-offer#2-display-offer).

`adapty products list` y `adapty products get` muestran cuántas ofertas están vinculadas a cada producto en `offers_count`. El recuento incluye solo las ofertas vinculadas en Adapty, no las que existen en los stores.

### adapty product-offers list

Lista todas las ofertas vinculadas a un [producto](product).

```bash
adapty product-offers list --app <app-id> --product <product-id>
```

| Flag | Obligatorio | Descripción |
|---|---|---|
| `--app` | Sí | ID de la app (UUID) |
| `--product` | Sí | ID del producto (UUID) |

Devuelve todas las ofertas en una sola página y no acepta [flags de paginación](developer-cli-reference#global-flags).

### adapty product-offers get

Obtén los detalles de una oferta específica.

```bash
adapty product-offers get --app <app-id> <offer-id>
```

| Argumento | Descripción |
|---|---|
| `offer-id` | ID de la oferta (UUID) |

| Flag | Obligatorio | Descripción |
|---|---|---|
| `--app` | Sí | ID de la app (UUID) |

### adapty product-offers create

Vincula una oferta de store a un [producto](product).

```bash
adapty product-offers create --app <app-id> --product <product-id> --title "Spring" --type promotional --ios-offer-id spring_ios --android-offer-id spring-android
```

| Flag | Obligatorio | Descripción |
|---|---|---|
| `--app` | Sí | ID de la app (UUID) |
| `--product` | Sí | ID del producto (UUID) |
| `--title` | Sí | Nombre de la oferta, visible solo en el Adapty Dashboard |
| `--type` | Sí | Tipo de oferta: `promotional` o `win_back` |
| `--ios-offer-id` | Al menos un store obligatorio | ID de oferta de App Store Connect |
| `--android-offer-id` | Al menos un store obligatorio | ID de oferta de Google Play Console |

Las ofertas de recuperación son exclusivas de App Store, por lo que `--type win_back` solo acepta `--ios-offer-id`. Para cualquier oferta de Google Play, incluida la prueba gratuita, usa `--type promotional`.

```bash
adapty product-offers create --app <app-id> --product <product-id> --title "Come back" --type win_back --ios-offer-id winback_ios
```

### adapty product-offers update

Actualiza una oferta existente.

```bash
adapty product-offers update --app <app-id> <offer-id> --title "Spring 2"
```

| Argument | Description |
|---|---|
| `offer-id` | ID de la oferta (UUID) |

| Indicador | Obligatorio | Descripción |
|---|---|---|
| `--app` | Sí | ID de la app (UUID) |
| `--title` | No | Nombre de la oferta |
| `--type` | No | Tipo de oferta: `promotional` o `win_back`. Para cambiar una oferta a `win_back`, elimina también su parte de Google Play con `--clear-android-offer-id` |
| `--ios-offer-id` | No | Nuevo ID de oferta de App Store |
| `--android-offer-id` | No | Nuevo ID de oferta de Google Play |
| `--clear-ios-offer-id` | No | Elimina la parte de App Store de la oferta |
| `--clear-android-offer-id` | No | Elimina la parte de Google Play de la oferta |

Se requiere al menos una opción además de `--app`. Los campos que omitas conservan sus valores actuales. Cada oferta mantiene al menos un ID de oferta de store, por lo que el comando falla si intenta eliminar el último.

:::warning
El comando lee la oferta y la guarda completa. Si alguien edita la misma oferta en el Adapty Dashboard entre esa lectura y el guardado, su cambio se sobreescribe.
:::

Las ofertas introductorias no se pueden actualizar. Una oferta que tenga un store distinto de App Store o Google Play tampoco se puede actualizar desde la CLI: edítala en el Adapty Dashboard.

Para eliminar una oferta, utiliza el Adapty Dashboard. La CLI no tiene comando de eliminación.
