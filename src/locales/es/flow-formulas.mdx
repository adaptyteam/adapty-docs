Una fórmula es una [variable personalizada](onboarding-variables#custom-variables) con un valor calculado: un número o una fecha. Una fórmula puede leer las respuestas que los usuarios dan en el flow, otras variables personalizadas, los precios de los productos de tu catálogo de Adapty y el día actual. Con fórmulas en el Flow & Paywall Builder, un flow puede mostrar valores calculados sin necesidad de código en tu app:

- **Un resultado de respuestas**: La suma de puntuaciones de un cuestionario, un IMC calculado a partir del peso y la altura, o la altura en pies y pulgadas.
- **Un precio**: El precio del producto seleccionado con un 20% de descuento, o cuánto ahorra el usuario con el plan anual frente al semanal.
- **Una fecha**: La fecha de fin de una prueba gratuita.
- **Una duración**: La duración de una prueba gratuita en días, o la edad de un usuario a partir de su fecha de nacimiento.

El flow calcula el resultado de una fórmula en el dispositivo. Cuando cambia un valor que la fórmula lee, el flow actualiza el resultado. Puedes mostrar el resultado en un elemento de texto y usarlo en condiciones.

## Crear una fórmula \{#create-a-formula\}

1. Abre el panel <Inline id="variables.svg" alt="Variables" /> Variables en el flow builder.
2. Añade una nueva variable: haz clic en <Inline id="plus.svg" alt="Plus" />.
3. Escribe el **Name** de la variable, por ejemplo `bmi`. Las demás fórmulas usan este nombre para leer el resultado.
4. En el desplegable **Value Type**, selecciona **Formula**.
5. En el campo **Expression**, escribe la fórmula, por ejemplo `round({{weight}} * 10000 / ({{height}} * {{height}}), 1)`, donde `weight` y `height` son variables de tipo Number. Consulta las reglas en [Escribir una fórmula](#write-a-formula).
6. Haz clic en **Create variable**.

<ZoomImage id="flow-formula-create.webp" width="300px" alt="El diálogo Crear variable con el tipo Fórmula, una fórmula de IMC en el campo Expresión, el tipo de salida Número y una vista previa de 22,9" />

Cuando sales del campo **Expression**, el builder valida la fórmula. Si la fórmula tiene un error, el texto del error aparece debajo del campo. Mientras se muestra el error, el botón **Create variable**, o **Save** para una variable existente, queda desactivado. Al editar la expresión, el error desaparece y el botón vuelve a estar disponible.

Debajo del campo, el builder muestra:

- **Tipo de resultado**: **Number** (número) o **Date** (fecha), el tipo del resultado. El builder lo determina a partir de la fórmula: el resultado es una fecha cuando la fórmula es una [función de fecha](#date-functions) que devuelve una fecha, como `addDays`, o un valor de fecha solo, como `{{trial_start}}`. Cualquier otra fórmula devuelve un número, incluida una que calcula el tiempo entre dos fechas, como `daysBetween`.
- **Formato de fecha**: Solo para fórmulas de fecha. Cómo los elementos de texto muestran el resultado. Consulta [Mostrar una fecha en un elemento de texto](#show-a-date-in-a-text-element).
- **Vista previa**: El resultado calculado a partir de los valores iniciales y los precios de los productos. Consulta [Previsualizar una fórmula en el builder](#preview-a-formula-in-the-builder).

Una fórmula siempre depende de otros valores, por lo que no tiene **Initial value**. Por la misma razón, tu aplicación no puede establecer una fórmula.

### Insertar referencias y funciones

Si no conoces el nombre exacto de una variable, escribe `{{` en el campo **Expression**. Se abre una lista de variables. Escribe parte del nombre para filtrar la lista y selecciona una variable para insertar su referencia. La lista también se abre al escribir el nombre de una función. Cuando escribes un espacio después de un valor numérico, como `{{weight}}` o `5`, la lista ofrece los operadores `+`, `-`, `*` y `/`. Para cerrar la lista, pulsa Escape.

La lista muestra solo las variables y funciones que pueden ir en la posición del cursor. Por ejemplo, en el primer argumento de `addDays`, la lista ofrece valores Date, `today()` y las funciones que devuelven una fecha. En el segundo argumento de `round`, la lista no ofrece nada, porque el número de decimales es un número que escribes tú.

El campo **Expression** muestra cada referencia como una etiqueta con el nombre de la variable, como **weight** para una variable personalizada o **Weekly · prod_price** para el precio de un producto. Una etiqueta es una unidad: Retroceso o Suprimir elimina toda la referencia, y las teclas de flecha mueven el cursor más allá de la etiqueta.

Para explorar todas las variables que puede leer la fórmula, o para ver la descripción de una función, utiliza los dos botones de la línea **Output type**. Cada botón añade texto en la posición del cursor en el campo **Expression**:

- <Inline id="variables.svg" alt="Insert variable" /> **Insert variable**: Abre una lista con cuatro pestañas. Selecciona un valor para insertar su referencia, o una función para insertar su nombre y un paréntesis de apertura:
  - **Functions**: Las funciones de las fórmulas.
  - **Elements**: Las respuestas en inputs y pickers, como `weight.value`.
  - **Products**: Los precios del producto seleccionado en cada grupo de productos, seguidos de los productos de tu catálogo de Adapty. Consulta [Lee el precio de cualquier producto](#read-the-price-of-any-product).
  - **Custom**: Las variables personalizadas de tipo Number, Date y Formula.
- <Inline id="function.svg" alt="Insert function" /> **Insert function**: Muestra las funciones, cada una con una descripción y un ejemplo. Para encontrar una función, escribe su nombre en el campo de búsqueda. Selecciona una función para insertar su nombre y un paréntesis de apertura, como `addDays(`. Luego escribe los argumentos y el paréntesis de cierre.

La lista **Insert variable** no muestra variables de tipo String, Boolean ni Array, ni la fórmula que estás editando.

## Escribir una fórmula \{#write-a-formula\}

Una fórmula combina números, referencias a valores, operadores y funciones. Los nombres de funciones y variables distinguen entre mayúsculas y minúsculas: `Round(2.5)` es un error.

### Referencias \{#references\}

Pon cada referencia entre dobles llaves:

| Referencia | Lo que lee la fórmula | Ejemplo |
| :--- | :--- | :--- |
| `{{<variable name>}}` | Una variable personalizada de tipo Number, Date o Formula | `{{discount}}` |
| `{{<Element ID>.value}}` | La respuesta en un [campo de texto o número](builder-inputs-and-forms), un [selector numérico](builder-number-picker), o un campo de fecha o fecha y hora | `{{weight.value}}` |
| `{{<Group ID>.selectedProduct.prod_price}}` | El precio del producto que el usuario seleccionó en un grupo de productos, como número | `{{products.selectedProduct.prod_price}}` |
| `{{<Group ID>.selectedProduct.prod_price_per_week}}` | El precio del producto seleccionado por semana. También `prod_price_per_day`, `prod_price_per_month` y `prod_price_per_year`. Un producto que no es una suscripción no devuelve ningún valor. Ver [Precios por período](#per-period-prices). | `{{products.selectedProduct.prod_price_per_month}}` |
| `{{<Group ID>.selectedProduct.offer_price}}` | El precio de la oferta del producto seleccionado, como número | `{{products.selectedProduct.offer_price}}` |
| `{{<Group ID>.selectedProduct}}` | El producto seleccionado, solo como segundo argumento de `addOfferDuration` | `{{products.selectedProduct}}` |
| `{{<Adapty product ID>.prod_price}}` | El precio de un producto de tu catálogo de Adapty, como número. También los precios por período del producto, como `prod_price_per_week`. Ver [Leer el precio de cualquier producto](#read-the-price-of-any-product). | `{{<annual product ID>.prod_price}}`, mostrado como **Annual · prod_price** |

Una fórmula lee la respuesta escrita como un número cuando la respuesta son dígitos, con un signo menos opcional al inicio y una fracción opcional tras un punto decimal o una coma decimal. La fórmula ignora los espacios al principio y al final. Por ejemplo, `12`, `-5`, `1.5` y `1,5` son números. Cualquier otra respuesta, como `abc`, `1,5,0` o `1e3`, da a la fórmula [sin valor](#formulas-without-a-value). En un campo de entrada de tipo Número que lee una fórmula, los usuarios solo pueden escribir un número. Con los formatos **Decimal (Point)** y **Decimal (Comma)**, los usuarios pueden escribir un punto decimal o una coma decimal, de modo que la tecla decimal de cualquier teclado funciona.

Una entrada de tipo Date o Date & Time proporciona el día del calendario que el usuario seleccionó.

Una fórmula puede leer otra fórmula, pero las referencias no pueden formar un círculo. Si la fórmula A lee la fórmula B, la fórmula B no puede leer la fórmula A. Un círculo más largo también es un error, como cuando A lee B, B lee C y C lee A. Una fórmula no puede hacer referencia a sí misma. Cuando cambias el nombre de una variable, un **Element ID** o un **Group ID**, la fórmula muestra el nuevo nombre y lee el mismo valor. Cuando eliminas una variable que una fórmula lee, el campo **Expression** muestra un chip de **deleted variable** en su lugar y aparece un error debajo del campo.

Un nombre que coincide con dos valores es un error. Por ejemplo, si una variable personalizada tiene el nombre `age.value` y una entrada tiene el Element ID `age`, `{{age.value}}` coincide con ambos. Cambia el nombre de la variable personalizada.

### Números y operadores

- **Números**: Usa siempre un punto decimal, como `0.8`. Dentro de una función, la coma separa los argumentos: `round(2,5)` equivale a `round(2, 5)`, que da 2, no 2.5. Fuera de una función, una coma en un número es un error. Un menos delante de un número o una referencia lo hace negativo, como `-3`.
- **Operadores**: `+`, `-`, `*` y `/`. El flow calcula `*` y `/` antes que `+` y `-`, y los operadores del mismo nivel de izquierda a derecha. Usa paréntesis para cambiar el orden: `({{a}} + {{b}}) / 2`.

## Fórmulas numéricas \{#number-formulas\}

Una fórmula numérica devuelve un número.

### Funciones numéricas

| Función | Resultado | Ejemplo |
| :--- | :--- | :--- |
| `round(n)` | `n` redondeado al número entero más cercano. Un valor exactamente en el medio se redondea alejándose del cero. | `round(2.5)` = 3, `round(-2.5)` = -3 |
| `round(n, digits)` | `n` redondeado a `digits` decimales. `digits` es un número entero del 0 al 6 que se escribe directamente en la fórmula, no es una referencia ni un cálculo. | `round(23.12, 1)` = 23.1, `round(1.005, 2)` = 1.01 |
| `floor(n)` | El número entero más grande que no supera a `n` | `floor(2.7)` = 2, `floor(-2.5)` = -3 |
| `mod(a, b)` | El resto de dividir `a` entre `b`, con el signo de `b`, como la función MOD de las hojas de cálculo | `mod(7, 3)` = 1, `mod(-7, 3)` = 2, `mod(5.5, 2)` = 1.5 |

Un resultado cero de `round`, `floor` y `mod` es siempre 0, nunca -0.

### Mostrar un número en un elemento de texto \{#show-a-number-in-a-text-element\}

Para mostrar una fórmula o una variable de tipo Date, [inserta la variable](onboarding-variables#use-variables-in-text) en un elemento de texto desde la pestaña **Custom** del selector de variables. Las fechas y los números con `round` en el nivel superior aparecen en el idioma del dispositivo, no en el idioma del flow.

La forma en que aparece una fórmula de tipo Number depende de la función en el nivel superior de la fórmula:

- **`round` en el nivel superior**: El número tiene exactamente los decimales que especifica `round`. Utiliza el separador decimal del idioma del dispositivo, sin separadores de miles ni símbolo de moneda. Por ejemplo, `round(23.12, 1)` muestra "23.1" en inglés y "23,1" en ruso, y `round(15.04, 1)` muestra "15.0" en inglés.
- **Cualquier otra fórmula**: El número aparece en su forma simple, con un punto decimal en todos los idiomas y hasta 15 dígitos significativos. Por ejemplo, `9.99 * 0.8` muestra "7.992", y `1 - 1 / 3` muestra "0.666666666666667". Para establecer el número de decimales, coloca `round` en el nivel superior de la fórmula, como `round(1 - 1 / 3, 2)`.

Una variable de tipo Number y una fórmula con `floor` o `mod` en el nivel superior también aparecen en la forma simple.

### Comparar números en condiciones \{#compare-numbers-in-conditions\}

Puedes seleccionar una fórmula o una variable de fecha en una condición, como una regla de [visibilidad condicional](onboarding-element-visibility) o una acción condicional:

- **Fórmulas de número**: Usa los mismos operadores que para una variable de número: **Equals**, **Does not equal**, **Greater than**, **Less than**, **Is empty** e **Is not empty**. Compara la fórmula con un número o con otro valor numérico, como `bmi` **Greater than** `25`. Los operadores no incluyen "mayor o igual que" ni "menor o igual que". Para comparar con un número entero de 10 o más, como la puntuación de un cuestionario, usa `score` **Greater than** `9`.

## Precios de productos \{#product-prices\}

Una fórmula puede leer los precios de productos de dos fuentes:

- **El producto seleccionado de un grupo de productos**: El precio cambia cuando los usuarios seleccionan otro producto del grupo, como `{{products.selectedProduct.prod_price}}`.
- **Un producto de tu catálogo de Adapty**: El precio de un producto concreto, incluso si la pantalla no lo muestra. Úsalo para comparar planes, como el ahorro del plan anual frente al semanal.

En el dispositivo, el flow utiliza el precio del store en la moneda del usuario. Cuando se cargan los precios de los productos, el flow recalcula la fórmula.

### Leer el precio de cualquier producto \{#read-the-price-of-any-product\}

1. En el campo **Expression**, coloca el cursor donde debe ir el precio.
2. Haz clic en <Inline id="variables.svg" alt="Insert variable" /> **Insert variable** y abre la pestaña **Products**.
3. Señala el producto y selecciona el precio: `prod_price`, o un [precio por período](#per-period-prices), como `prod_price_per_week`.

La pestaña **Products** muestra los productos en dos grupos:

- **This flow**: Los productos en las pantallas del flow.
- **Other**: El resto de tu catálogo de Adapty.

Para distinguir los productos, compara el nivel de acceso y el precio en USD de cada producto de la lista. La lista no muestra la duración de la suscripción de un producto. Cuando dos productos tienen el mismo título, la lista y el tooltip del chip también muestran el ID de producto del store.

Una fórmula solo puede mostrar el precio de un producto en una pantalla cuando ese producto está en la [lista de productos de la pantalla](paywall-product-block). Cuando insertas la fórmula en un elemento de texto o la usas en una condición, el builder añade el producto a esa lista sin oferta ni plan de facturación. Lo mismo ocurre cuando la fórmula lee el precio a través de otra fórmula. En el caso de un componente reutilizable, el builder añade el producto a cada pantalla que muestre ese componente. Si la pantalla ya tiene el producto solo con una oferta o un plan de facturación, el builder añade una segunda entrada sin ellos.

La entrada añadida aparece en el panel de **Products**, en el análisis y en los productos que recibe el código de tu aplicación, como cualquier otro producto de la pantalla. La pantalla no lo selecciona y pulsar sobre el texto no inicia su compra.

Una vez que el constructor añade la entrada, la gestionas en el panel de **Products**, como cualquier otro producto de la pantalla:

- **Eliminas el precio de la fórmula, o la fórmula de la pantalla**: La entrada permanece. Si ningún otro elemento de la pantalla usa el producto, elimina la entrada. Una entrada que conserves bloquea la publicación si luego eliminas el producto de tu catálogo de Adapty.
- **Eliminas la entrada mientras la pantalla sigue usando la fórmula**: El builder no vuelve a añadir la entrada, y la pantalla muestra el problema **This product is off this screen**. Para solucionarlo, vuelve a añadir el producto en el panel **Products**.

Cuando eliminas un producto de tu catálogo de Adapty, el campo **Expression** muestra su precio como un chip **Missing product** y aparece un error debajo del campo. Sustituye el precio por el de otro producto. La eliminación no afecta a las versiones publicadas del flow.

Si creas un flow con la [CLI de Adapty](developer-cli-flows) o la API, añade el producto, sin oferta ni plan de facturación, a cada pantalla que use la fórmula, tal como hace el builder. En la expresión, usa el ID de producto de Adapty que devuelve [`adapty products list`](developer-cli-products). La publicación falla con el error `formula_undeclared_product` solo cuando un elemento de texto o una condición usa la fórmula y ninguna pantalla del flow tiene el producto sin oferta ni plan de facturación.

### Precios por período \{#per-period-prices\}

El precio por período es el precio de un producto de suscripción por día, semana, mes o año. Una fórmula puede leer estos precios para un producto del catálogo y para el producto seleccionado de un grupo de productos:

| Precio | Ejemplo para un producto mensual con precio 9,99 |
| :--- | :--- |
| `prod_price_per_day` | 9,99 / 30 = 0,333 |
| `prod_price_per_week` | 9,99 × 7 / 30 = 2,331 |
| `prod_price_per_month` | 9,99 |
| `prod_price_per_year` | 9,99 × 12 = 119,88 |

El flow divide el precio entre el número de días, semanas, meses o años que dura la suscripción del producto. Un mes equivale a 30 días, por lo que un mes equivale a 30/7 semanas. Un año equivale a 365 días, 52 semanas o 12 meses. Las [variables de precio de los elementos de texto](onboarding-variables#product-variables) aplican la misma conversión. Por ejemplo, un producto anual con un precio de 120 da como resultado 10 para `prod_price_per_month` y 120 / 52 para `prod_price_per_week`.

La fórmula conserva todos los decimales del precio por período. Para mostrar el precio con dos decimales, usa `round` en el nivel superior de la fórmula. Cuando los usuarios seleccionan un producto anual con precio 120, `round({{products.selectedProduct.prod_price_per_week}}, 2)` muestra "2.31".

Un producto que no es una suscripción, como un producto de por vida o un consumible, devuelve los precios por período [sin valor](#formulas-without-a-value).

## Fórmulas de fecha \{#date-formulas\}

Una fórmula de fecha devuelve una fecha. Para usar un día fijo en una fórmula, como la fecha de inicio de una prueba, guárdalo en una variable de tipo Date.

### Crear una variable de fecha \{#create-a-date-variable\}

1. Abre el panel <Inline id="variables.svg" alt="Variables" /> Variables y haz clic en <Inline id="plus.svg" alt="Plus" />.
2. Escribe el **Name** de la variable, por ejemplo `trial_start`.
3. En el desplegable **Value Type**, selecciona **Date**.
4. (Opcional) En el campo **Initial value**, escribe una fecha con el formato `DD.MM.YYYY`, por ejemplo `17.11.2026`, o haz clic en el campo y elige el día en el calendario y luego haz clic en **Apply**. El builder no acepta fechas inexistentes, como `31.02.2027`. Sin un valor inicial, la variable no tiene valor hasta que una acción [**Set variable**](onboarding-actions) lo establezca.
5. (Opcional) En el desplegable **Date format**, selecciona cómo mostrarán la fecha los elementos de texto. Consulta [Mostrar una fecha en un elemento de texto](#show-a-date-in-a-text-element).
6. Haz clic en **Create variable**.

<ZoomImage id="flow-date-variable-create.webp" width="300px" alt="The Create variable dialog with the Date type and the Initial value 17.11.2026" />

Una variable de tipo Date almacena una fecha sin hora ni zona horaria.

Para cambiar una variable Date cuando el usuario toca un elemento, añade una acción [**Set variable**](onboarding-actions), selecciona la variable Date e introduce la nueva fecha en formato `DD.MM.YYYY` o elígela en el calendario. Una acción **Set variable** no puede cambiar una fórmula, ya que una fórmula siempre depende de otros valores.

### Funciones de fecha \{#date-functions\}

| Función | Resultado | Ejemplo |
| :--- | :--- | :--- |
| `today()` | El día actual en el dispositivo | `today()` |
| `addDays(date, n)` | `date` más `n` días | `addDays(today(), 7)` |
| `addWeeks(date, n)` | `date` más `n` semanas | `addWeeks({{trial_start}}, 2)` |
| `addMonths(date, n)` | `date` más `n` meses | `addMonths({{trial_start}}, 1)` |
| `addYears(date, n)` | `date` más `n` años | `addYears({{birth_date.value}}, 18)` |
| `addOfferDuration(date, product)` | `date` más la duración de la oferta del producto | `addOfferDuration(today(), {{products.selectedProduct}})` |
| `daysBetween(start, end)` | El número de días naturales desde `start` hasta `end`, como número | `daysBetween(today(), {{trial_end}})` |
| `weeksBetween(start, end)` | El número de semanas completas desde `start` hasta `end`, como número | `weeksBetween({{trial_start}}, today())` |
| `monthsBetween(start, end)` | El número de meses completos desde `start` hasta `end`, como número | `monthsBetween({{trial_start}}, today())` |
| `yearsBetween(start, end)` | El número de años completos desde `start` hasta `end`, como número | `yearsBetween({{birth_date.value}}, today())` |

The date functions follow these rules:

- **`today()`**: Indica el inicio del día actual en la zona horaria del dispositivo. El flow lee el día cuando se abre, así que el valor no cambia a medianoche mientras el flow está abierto.
- **`n` negativo y fraccionario**: Un `n` negativo retrocede la fecha. El flow descarta la parte fraccionaria de `n`: `addWeeks(date, 1.5)` añade 1 semana, y `addDays(date, -1.9)` retrocede la fecha 1 día.
- **Meses cortos**: Cuando el mes de destino no tiene ese día, el resultado es el último día de ese mes. Por ejemplo, el 31 de enero de 2027 más 1 mes es el 28 de febrero de 2027, y el 29 de febrero de 2028 más 1 año es el 28 de febrero de 2029.
- **`addOfferDuration`**: Añade cada fase de la oferta del producto que el SDK de Adapty pasa al flow, en orden. Para cada fase, la función suma el período de esa fase multiplicado por su número de períodos en un solo paso: una prueba gratuita de 7 días que comienza el 10 de noviembre de 2026 termina el 17 de noviembre de 2026. Si el producto no tiene oferta, o una fase de la oferta tiene un período desconocido, el resultado no tiene valor.
- **Tiempo entre fechas**: `daysBetween`, `weeksBetween`, `monthsBetween` y `yearsBetween` cuentan solo unidades completas y descartan el resto:
  - `weeksBetween` divide el número de días entre 7: 13 días es 1 semana.
  - `monthsBetween` y `yearsBetween` cuentan meses y años calendario completos. Por ejemplo, del 15 de enero de 2027 al 14 de marzo de 2027 es 1 mes, y al 15 de marzo de 2027 son 2 meses. Cuando el mes de `end` es demasiado corto para el día de `start`, el último día de ese mes completa el mes: del 31 de enero de 2027 al 28 de febrero de 2027 es 1 mes.
  - Cuando `end` es anterior a `start`, el resultado es negativo: el resultado para las dos fechas en orden inverso, con un signo menos. Por ejemplo, `daysBetween` del 1 de diciembre de 2026 al 24 de noviembre de 2026 da -7, y `weeksBetween` da -1 para un `end` 10 días anterior a `start`.

Dentro de una fórmula, una fecha solo puede ser el primer argumento de una función que añade tiempo a una fecha, o un argumento de una función que cuenta el tiempo entre dos fechas. Una fecha en un cálculo, como `{{trial_start}} + 1`, es un error. Un número no puede ser un argumento donde una función necesita una fecha. Una variable de tipo cadena, booleano o array no puede formar parte de una fórmula.

### Mostrar una fecha en un elemento de texto \{#show-a-date-in-a-text-element\}

Para mostrar una fórmula o una variable de tipo Date, [inserta la variable](onboarding-variables#use-variables-in-text) en un elemento de texto desde la pestaña **Custom** del selector de variables. Las fechas y los números con `round` en el nivel superior aparecen en el idioma del dispositivo, no en el idioma del flow.

Una variable de tipo Date y una fórmula de tipo Date tienen un **Date format** en la configuración de la variable. Cada elemento de texto que muestra la variable usa este formato, y cuando lo cambias, todos esos elementos de texto cambian también. Las variables nuevas tienen el formato **Medium**.

Para usar otro formato en un elemento de texto, en el campo **Content**, haz clic en la variable y selecciona un formato. Para volver al formato de la variable, selecciona **Variable default**. Los formatos son:

| Formato de fecha | Ejemplo en inglés |
| :--- | :--- |
| **Short** | 11/17/26 |
| **Medium** | Nov 17, 2026 |
| **Long** | November 17, 2026 |
| **Month D** | November 17 |
| **Mon D** | Nov 17 |

**Short**, **Medium** y **Long** siguen el orden de fecha del idioma del dispositivo. **Month D** y **Mon D** muestran el mes antes que el día en todos los idiomas, como "ноября 17" en ruso.

### Comparar fechas en condiciones \{#compare-dates-in-conditions\}

Puedes seleccionar una fórmula o una variable de fecha en una condición, como una regla de [visibilidad condicional](onboarding-element-visibility) o una acción condicional:

- **Variables de fecha y fórmulas de fecha**: Usa **Equals**, **Does not equal**, **Earlier than**, **Later than**, **Is empty** o **Is not empty**. Compara la fecha con otra fecha, o con una fecha que introduzcas como `DD.MM.YYYY` o selecciones en el calendario. **Is empty** es verdadero mientras la fecha no tenga valor, como una variable de fecha sin valor inicial antes de que una acción **Set variable** la establezca.

Una comparación de fechas compara días del calendario, no horas. Por ejemplo, una fecha que los usuarios seleccionaron a las 21:00 del 17 de noviembre de 2026 equivale a `17.11.2026`. No se puede comparar una fecha con un número.

## Fórmulas sin valor \{#formulas-without-a-value\}

Una fórmula no tiene valor cuando alguno de sus valores no está disponible en el dispositivo:

- Una respuesta está vacía o no es un número.
- Los precios del producto no se cargaron, o el store no devolvió un producto que la fórmula lee. Para darle un valor a la fórmula tanto en iOS como en Android, configura el producto en App Store Connect y en Google Play Console.
- El producto no es una suscripción y la fórmula lee un [precio por período](#per-period-prices).
- El producto seleccionado no tiene oferta y la fórmula lee `offer_price` o llama a `addOfferDuration`.
- La fórmula divide entre cero, como en `{{a}} / 0` o `mod({{a}}, 0)`.
- Una variable de fecha que lee la fórmula no tiene valor.

Una fórmula que lee otra fórmula sin valor tampoco tiene valor. Sin valor, una fórmula funciona así:

- **Elementos de texto**: La fórmula no muestra nada.
- **Condiciones**: **Is empty** es verdadero. **Equals**, **Does not equal** y todas las comparaciones de la fórmula son falsas.

El flow actualiza el resultado de una fórmula cuando cambia un valor que la fórmula lee: cuando los usuarios escriben una respuesta, una acción **Set variable** cambia una variable, o cuando se cargan los precios de los productos. Si los usuarios retroceden y borran una respuesta, la fórmula no tendrá valor en la siguiente pantalla. Hasta que el flow cambie una variable personalizada, la fórmula lee el valor inicial de la variable.

## Vista previa de una fórmula en el builder \{#preview-a-formula-in-the-builder\}

El builder calcula el resultado de una fórmula a partir de los valores iniciales de las variables personalizadas y los precios en USD de los productos de tu catálogo de Adapty. La **Preview** que aparece bajo el campo **Expression** muestra **No value** cuando la fórmula contiene alguno de los siguientes elementos:

- Una respuesta que los usuarios escriben o seleccionan
- `offer_price`
- La oferta de `addOfferDuration`
- Una variable sin valor, como una variable de tipo Date sin valor inicial
- El precio de un producto de tu catálogo de Adapty sin precio en USD, o con un precio en USD de 0
- El precio por período de un producto que no es una suscripción, como un producto de acceso de por vida

En estos casos, un elemento de texto en el canvas muestra el nombre de la variable entre llaves, como `{{trial_end}}`. Para ver los valores de las respuestas, [previsualiza el flow en la app móvil de Adapty](paywall-device-compatibility-preview). Los valores de las ofertas requieren una compilación de tu app con productos reales.

En el canvas, las fechas y los números con `round` en el nivel superior aparecen en el idioma que selecciones para la previsualización.

## Ejemplos \{#examples\}

### Mostrar la suma de respuestas \{#show-a-sum-of-answers\}

En una pantalla, añade tres entradas numéricas con los IDs de elemento `a1`, `a2` y `a3`. Crea una fórmula `sum`:

```
{{a1.value}} + {{a2.value}} + {{a3.value}}
```

En la siguiente pantalla, inserta `sum` en un elemento de texto. Si el usuario introduce 2, 3 y 4, el texto muestra "9". Si vuelve atrás y cambia 4 por 5, el texto muestra "10".

### Mostrar un IMC y una etiqueta "High" \{#show-a-bmi-and-a-high-label\}

Añade un campo Number input con el ID de elemento `weight` para el peso en kilogramos, y otro con el ID de elemento `height` para la altura en centímetros. Crea una fórmula `bmi`:

```
round({{weight.value}} * 10000 / ({{height.value}} * {{height.value}}), 1)
```

Inserta `bmi` en un elemento de texto. Para un IMC de 23,12, los usuarios verán "23.1" con el idioma del dispositivo en inglés y "23,1" con el ruso. Para mostrar la etiqueta "High" solo cuando el IMC supere 25, añade un elemento de texto con la palabra "High" y asígnale una regla de [visibilidad condicional](onboarding-element-visibility): `bmi` **Greater than** `25`.

### Mostrar un precio con descuento \{#show-a-discounted-price\}

Crea una fórmula `discounted` que aplique un 20% de descuento al precio del producto seleccionado:

```
{{products.selectedProduct.prod_price}} * 0.8
```

Luego crea una fórmula `shown` que lo redondee a dos decimales:

```
round({{discounted}}, 2)
```

Inserta `shown` en un elemento de texto. Para un producto con precio 9.99, el texto muestra "7.99". Cuando el usuario selecciona un producto con precio 100, el texto muestra "80.00". El número no incluye el símbolo de moneda. Si el precio del producto seleccionado no se cargó, el texto aparece vacío.

### Mostrar el ahorro del plan anual \{#show-the-savings-of-the-annual-plan\}

Para mostrar cuánto ahorran los usuarios con un plan anual en comparación con 52 semanas de un plan semanal, crea una fórmula `saving` que lea los precios de ambos productos. El producto semanal no necesita aparecer en ninguna pantalla del flow. En este ejemplo, el producto anual cuesta 120 y el producto semanal cuesta 5:

1. En el campo **Expression**, haz clic en <Inline id="variables.svg" alt="Insert variable" /> **Insert variable**. En la pestaña **Products**, apunta al producto semanal y selecciona `prod_price`.
2. Escribe `* 52 -`.
3. Inserta el `prod_price` del producto anual de la misma manera.

El campo **Expression** muestra **Weekly · prod_price** `* 52 -` **Annual · prod_price**, y el **Preview** muestra 140. El builder guarda la expresión con los IDs de producto de Adapty:

```
{{<weekly product ID>.prod_price}} * 52 - {{<annual product ID>.prod_price}}
```

Para mostrar el ahorro como porcentaje, crea una fórmula `saving_percent`. Inserta los dos precios desde la pestaña **Products**, de la misma forma que para `saving`. El builder guarda la expresión como:

```
round((1 - {{<annual product ID>.prod_price}} / ({{<weekly product ID>.prod_price}} * 52)) * 100)
```

Para estos precios, `saving_percent` es 54. Inserta `saving` o `saving_percent` en un elemento de texto de la pantalla del paywall. El builder añade el producto semanal al final de la lista de productos de la pantalla. En el dispositivo, la fórmula usa los precios del store en la moneda del usuario. El botón de compra de la pantalla inicia la compra del producto anual.

### Mostrar la fecha de fin de prueba y un recordatorio \{#show-the-end-of-a-trial-and-a-reminder-date\}

Crea una fórmula `trial_end`:

```
addOfferDuration(today(), {{products.selectedProduct}})
```

Luego crea una fórmula `reminder` para tres días antes de que termine la prueba:

```
addDays({{trial_end}}, -3)
```

Para un producto con una prueba gratuita de 7 días, el 10 de noviembre de 2026, `trial_end` es el 17 de noviembre de 2026 y `reminder` es el 14 de noviembre de 2026. Con el formato de fecha **Medium**, el texto muestra "Nov 17, 2026". Con **Month D**, muestra "November 17".

### Mostrar la duración de una prueba \{#show-the-length-of-a-trial\}

Usa la fórmula `trial_end` de [Mostrar el fin de una prueba y una fecha de recordatorio](#show-the-end-of-a-trial-and-a-reminder-date), y crea una fórmula `trial_days`:

```
daysBetween(today(), {{trial_end}})
```

En un elemento de texto, escribe "Free for", inserta `trial_days` y escribe "days". Para un producto con una prueba gratuita de 7 días, el texto muestra "Free for 7 days". Cuando el producto seleccionado no tiene oferta, `trial_end` no tiene valor. Para mostrar el texto solo para un producto con oferta, asigna al elemento de texto una regla de [visibilidad condicional](onboarding-element-visibility): `trial_end` **Is not empty**.

### Mostrar la edad de un usuario \{#show-the-age-of-a-user\}

Añade un campo de fecha con el ID de elemento `birth_date` y crea una fórmula `age`:

```
yearsBetween({{birth_date.value}}, today())
```

Para usuarios nacidos el 25 de noviembre de 2000, `age` es 25 el 24 de noviembre de 2026 y 26 el 25 de noviembre de 2026. Mientras el campo esté vacío, `age` no tiene ningún valor.

### Mostrar una altura en pies y pulgadas \{#show-a-height-in-feet-and-inches\}

Añade un campo de entrada numérica con el ID de elemento `height` para la altura en centímetros. Crea tres fórmulas:

- `total`: `round({{height.value}} / 2.54)`, la altura en pulgadas enteras.
- `feet`: `floor({{total}} / 12)`.
- `inches`: `mod({{total}}, 12)`.

En un elemento de texto, inserta `feet`, escribe "ft", inserta `inches` y escribe "in". Para 180 cm, el texto muestra "5 ft 11 in". Para 140 cm, muestra "4 ft 7 in".

## Resolución de problemas \{#troubleshooting\}

Cuando sales del campo **Expression**, el editor muestra el primer error de la fórmula debajo del campo. Algunos ejemplos:

| Texto de error | Causa y solución |
| :--- | :--- |
| `addDays() needs a date and a number` | Una función tiene un número incorrecto de argumentos o un argumento del tipo equivocado. Usa los argumentos de la tabla de [Funciones numéricas](#number-functions) o [Funciones de fecha](#date-functions). |
| `Unknown function "flor". Use one of: …` | El nombre de la función está mal escrito o tiene mayúsculas/minúsculas incorrectas. Usa una función de la lista que aparece en el error. Para leer una variable, escribe su nombre entre `{{ }}`. |
| `Use a dot in a decimal number, like 1.5` | Un número fuera de una función tiene una coma. Sustitúyela por un punto decimal. Dentro de una función, el builder interpreta la coma como separador entre argumentos, así que usa también el punto decimal. |
| `{{…}} is not a variable, an answer or a product field of this flow` | Ninguna variable, ID de elemento ni grupo de productos tiene ese nombre. Corrige el nombre o crea la variable. |
| `{{…}}: the product … is not in the product catalog of the app` | Has eliminado el producto de tu catálogo de Adapty. El chip muestra **Missing product**. Sustituye el precio por el de otro producto. |
| `Offers, billing plans and fields other than prod_price, … of a catalog product are not supported yet` | La fórmula lee una oferta, un plan de facturación u otro campo de un producto de tu catálogo de Adapty. Inserta el precio desde la pestaña **Products** de **Insert variable**. |
| `This variable no longer exists. Pick another one.` | Has eliminado una variable que la fórmula lee. El campo **Expression** la muestra como chip de **deleted variable**. Sustitúyela por otra referencia. |
| `{{…}} is the name of a variable and of an element answer: rename the variable` | El nombre coincide con dos valores. Cambia el nombre de la variable personalizada. |
| `{{…}} uses this formula: formulas cannot use each other in a loop` | Las referencias entre fórmulas forman un ciclo: por ejemplo, la fórmula A lee la fórmula B y la fórmula B lee la fórmula A. Elimina una de las referencias. |

<ZoomImage id="flow-formula-error.webp" width="300px" alt="Un error de función desconocida debajo del campo Expresión, con la lista de funciones disponibles" />

Una fórmula con error bloquea la publicación. El diálogo **Can't publish yet** muestra cada fórmula con error en **Variables**. Para ver los errores que pueden aparecer al publicar, consulta [Problemas comunes](flow-common-issues#a-flow-wont-preview-or-publish).

## Limitaciones \{#limitations\}

- **Solo números y fechas**: Una fórmula solo devuelve un número o una fecha. Para mostrar texto que dependa del resultado, añade [texto condicional](onboarding-text#add-conditional-text) a un elemento de texto. Por ejemplo, para mostrar "Alto" cuando el IMC supera 25, establece la condición **if** como `bmi` **Greater than** `25` e introduce "Alto" en **then**.
- **Productos del catálogo**: Una fórmula lee únicamente el precio y los precios por período de un producto de tu catálogo de Adapty, sin oferta ni plan de facturación. Para usar el precio de una oferta, lee `offer_price` del producto seleccionado en un grupo de productos.
- **Producto seleccionado**: Una fórmula que lee el producto seleccionado no tiene valor hasta que el usuario elige un producto. Para mostrar el resultado cuando se abre la pantalla, selecciona **Set as default** en una de las tarjetas de producto.
- **Ofertas en iOS y Android**: En iOS, el SDK de Adapty pasa una oferta al flow. Entre las ofertas disponibles para el usuario, primero se aplica una oferta de recuperación, luego una oferta promocional y después una oferta introductoria. En Android, el SDK de Adapty pasa solo la primera fase de la oferta introductoria. Para una prueba gratuita seguida de un precio con descuento, `addOfferDuration` en Android añade únicamente la prueba.
