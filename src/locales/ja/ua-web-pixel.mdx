ウェブファネルやランディングページからユーザーを獲得している場合、Adapty ウェブピクセルを使うと各訪問をその訪問のきっかけとなった広告に結びつけることができます。ピクセルはすべての訪問者にクリック ID を割り当てます。訪問者が支払いを行う際に、そのクリック ID をトランザクションと一緒に渡すと、Adapty アトリビューションがその購入を正確なキャンペーン、広告セット、広告に照合します。

Meta Ads、TikTok for Business、Google Ads キャンペーンでピクセルを利用できます。Google Ads では、アプリキャンペーンではなく、その他のキャンペーンで利用可能です。

:::note
FunnelFox でファネルを運用している場合、ピクセルは不要です。[FunnelFox と Adapty アトリビューションの連携](ua-funnelfox)をご覧ください。
:::

## 仕組み \{#how-it-works\}

ページ読み込み時、ピクセルは以下を行います：

- 訪問者に `click_id` を割り当て、7日間ブラウザに保存します。
- ページURLから広告シグナルを取得します：Meta（`fbclid`）、TikTok（`ttclid`）、Google（`gclid`、`gbraid`、`wbraid`）のクリックID、キャンペーン、広告セット、広告の識別子と名前、および `utm_*` パラメーター。
- `click_id` と取得したシグナルをバックグラウンドでAdaptyに送信します。

チェックアウト時には、`click_id` だけをトランザクションに付加します。Adaptyはそれをピクセルが送信済みのシグナルと照合し、広告チャネルを自動的に判定します。

:::tip
ピクセルは広告への訪問のみを追跡します。購入自体をAdaptyのアトリビューションに取り込むには、[Stripe](ua-stripe)または[Paddle](ua-paddle)を連携してください。
:::

## 始める前に \{#before-you-start\}

[Meta Ads](ua-facebook)、[TikTok for Business](ua-tiktok)、または [Google Ads](ua-google-ads) を Adapty アトリビューションに連携し、キャンペーン設定を追加してください。Adapty はキャンペーン設定ごとにピクセルスニペットを生成するため、スニペットをコピーするには設定が必要です。

ピクセルはランディングページ URL から広告データを読み取るため、広告には Adapty のトラッキングパラメーターを含める必要があります。これがないと、Adapty は購入をネットワークに帰属させることはできても、キャンペーン・広告セット・広告には帰属させられません。詳しくは [ウェブファネル用の広告 URL のタグ付け](ua-tag-ad-urls) をご覧ください。

## ピクセルをインストールする \{#install-the-pixel\}

1. Adapty Attribution で、Meta Ads、TikTok、または Google Ads のキャンペーン設定を開きます。
2. **Web funnel** セクションを展開し、**Pixel snippet** フィールドの値をコピーします。Meta Ads および TikTok の設定では、このセクションは **General** タブにあります。

<ZoomImage id="ua-web-pixel-snippet.webp" width="700px" alt="Pixel snippet field in the Web funnel section of a campaign configuration in Adapty Attribution" />

3. スニペットをファネルの全ページの `<head>` に貼り付けます。

```html
<script async src="https://api-ua.adapty.io/pixel/loader.js" data-code="YOUR_CODE"></script>
```

`data-code` の値はアプリとキャンペーンを識別するものです。これは公開識別子であり、秘密情報ではありません。

## 同意の管理 \{#manage-consent\}

ピクセルはファーストパーティクッキーと localStorage のエントリを書き込み、ページ読み込み時に広告クリック ID を読み取ります。ファネルのデータ管理者はあなた自身であり、その法的根拠もあなたが保有します。

デフォルトでは、ピクセルはページ読み込み時に動作します。同意に基づいて制御したい場合は、スニペットに `data-consent="denied"` を追加してください。これにより、クッキーバナーから同意を付与するまで、ピクセルはデータの保存も送信も行いません。

```js
window.adaptyPixel.grantConsent();  // start capture
window.adaptyPixel.revokeConsent(); // clear stored state and stop
window.adaptyPixel.getConsent();    // 'granted' | 'denied'
```

:::warning
EU/EEA のトラフィックに対しては、同意を取得した上でピクセルをゲートしてください。ePrivacy 規則ではブラウザストレージへの事前同意が必要であり、ファーストパーティアトリビューションピクセルも例外ではありません。
:::

スニペットは非同期で読み込まれるため、`<script>` タグの直後の行では `window.adaptyPixel` は存在しません。同意 API は同意バナーのコールバックから呼び出すか、早期呼び出しの場合は `if (window.adaptyPixel) { ... }` でガードしてください。

## 使用上の注意 \{#usage-notes\}

- **シングルページファネル**: クライアントサイドのナビゲーションでは同じ `click_id` が保持されるため、シングルページアプリとして構築されたファネルは追加設定なしで動作します。
- **Click ID の安定性**: ページ読み込み時またはチェックアウト時に `click_id` を読み取ると、同じ値が返されます。訪問者が新しい広告から再度ファネルに入った場合は、最新の広告クリックが優先されます。
- **更新（リニューアル）**: `click_id` は初回トランザクションにのみ付与してください。Adapty はトライアルのコンバージョンやサブスクリプションの更新を、サブスクリプション自体を通じてアトリビュートします。
