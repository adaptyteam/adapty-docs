adapty-mail スキルを使うと、AI コーディングツールから Adapty Mail プロジェクトを操作できます。あなたのアカウントでサインインした [Adapty Mail MCP サーバー](mail-mcp) を経由して動作します。フローの起動、キャンペーンの翻訳、送信ドメインの DNS 設定と認証、キャンペーンや A/B テストの結果確認、特定のユーザーにメールが届かなかった理由の調査などが行えます。

The MCP server alone gives your agent the tools. The skill adds what an agent gets wrong without it:

- **サーバーへの接続**: サーバーが接続済みでサインイン状態かどうかを確認します。未接続の場合は、クライアント向けのセットアップ手順を案内します。
- **Adapty Mail か、それ以外の Adapty 機能か**: フロー、セグメント、プロファイルは、Adapty Mail とアプリ内ペイウォールの Adapty とでは意味が異なります。スキルは変更を加える前に、どちらを指しているかを確認します。
- **ダッシュボードでのみ行える操作**: 会社の住所、ウェブチェックアウト、データ送信の有効化が必要なリクエストの場合、その旨を通知し、該当ページへのリンクを提供します。
- **ローンチ後の作業**: 結果の確認、A/B テスト、配信到達性、メールが届かない場合のトレースなど。

:::note
あなたの承認なしに実際のユーザーへ何かが送信されることはありません。フローを保存すると送信が開始され、保存されたセグメントリストがフロー全体を置き換えるため、スキルはまずフローの現在の状態を表示します（すべてのセグメント、すべてのキャンペーン、および削除されたものを含む）。削除、配信停止、A/B テストの開始と終了も、あなたの承認を待ちます。
:::

## スキルをインストールする \{#install-the-skill\}

adapty-mail スキルは [`adapty-skills` プラグイン](https://github.com/adaptyteam/adapty-skills)の一部です。プラグインをインストールするには、ターミナルで以下を実行してください：

```bash
npx adapty skills install
```

エージェントを再起動してスキルを読み込みます。他のインストール方法については、[プラグインの README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install) を参照してください。

このスキルを使用するには、Adapty Mail MCPサーバーが必要です。エージェントにまだ接続されていない場合は、Adapty Mail に接続するよう依頼してください。スキルがクライアント向けのコマンドを提供し、Adapty Mail ダッシュボードで接続を承認します。各クライアントの手順は [AI アシスタントで Adapty Mail を管理する](mail-mcp#connect-your-assistant) をご参照ください。

## 仕組み \{#how-it-works\}

1. **接続。** スキルは MCP サーバーが応答しているか、またサインインしているかを確認します。
2. **把握。** プロジェクトを見つけ、すでに設定されている内容（ブランド、会社の住所、送信ドメイン、キャンペーン、フロー、最終データ到着日時）を読み込みます。既存のものを再利用します。
3. **計画。** 開始前にダッシュボードで自分だけが行える操作を明示します。
4. **実行。** サーバーのツールを順に使い、各結果を表示します。実際の人にメールを送信する操作や元に戻せない操作は、確認を求めてから実行します。

## メールが送信されなかった理由 \{#why-an-email-didnt-send\}

特定のユーザーについて確認すると、スキルはそのプロファイルとプロファイルのジャーニーを読み取り、以下の理由を順番に確認して、最初に該当する理由で停止します：

1. プロファイルが抑制されています：配信停止、バウンス、苦情報告、またはアドレス認証失敗。[配信停止と抑制](mail-suppression)を参照してください。
2. その人はすでに別のマーケティングフローに入っています。
3. 購入が完了したため、設計通りにシーケンスが終了しました。
4. ドメインウォームアップ中に送信制限によってメールが保留されました。
5. トリガーが一度も発火しませんでした。購入イベントが Adapty Mail に届いていないか、セットアップ完了前にプロファイルが到着しています。
6. フロー内のどのセグメントもその人に一致しませんでした。
7. ダブルオプトインが有効になっており、その人がアドレスを確認していません。
8. その人のタイムゾーンの送信ウィンドウに合わせてメールがまだスケジュールされています。
