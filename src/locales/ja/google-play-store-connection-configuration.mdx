これは、GoogleコンソールではなくAdaptyで行うGoogle Playインテグレーションの唯一のステップです。パッケージ名とサービスアカウントキーファイルをAdaptに渡すと、Adaptはそれらを使って購入の検証とプロダクトの読み取りを行います。

:::danger
アプリが Adapty SDK で公開された後は、パッケージ名やキーファイルを変更しないでください。変更すると、すでにアプリを利用しているユーザー全員の購入検証が機能しなくなります。また、別の Cloud プロジェクトのキーを使用するとトピック名も変わり、リアルタイム通知が停止します。
:::

## 始める前に \{#before-you-start\}

[サービスアカウントキーファイルを生成してください](create-service-account-key-file)。そのファイルをここでアップロードします。

## アプリを接続する \{#connect-the-app\}

1. [Google Play Console](https://play.google.com/console/) を開き、アプリを選択して、パッケージ名をコピーします。**Dashboard** ページのアプリ名の下に表示されています。

2. Adapty ダッシュボードで [**App settings** > **Android SDK**](https://app.adapty.io/settings/android-sdk) を開きます。

3. **Package name** にパッケージ名を貼り付けます。

4. **Service account key file** に JSON キーファイルをアップロードします。

   <ZoomImage id="gp-adapty-android-sdk.webp" width="700px" alt="Android SDK tab of App settings in Adapty, showing the Package name field and the Service account key file upload area" />

5. **Save** をクリックします。

キーファイルを保存すると、Cloud プロジェクトに Pub/Sub トピックも作成されます。これは次のステップで必要になります。

## 次のステップ \{#next-steps\}

[リアルタイムデベロッパー通知（RTDN）を有効化する](enable-real-time-developer-notifications-rtdn)ことで、Google Play がサブスクリプションの更新、キャンセル、返金を Adapty に通知するようになります。
