要素に条件を追加することで、その表示を制御できます。条件付き要素は、指定された条件を満たしたユーザーにのみ表示されます。

条件では、[別の要素の状態](element-states-in-conditions)を評価することもできます。たとえば、ボタンが **Disabled** のときだけヒントを表示する、といった設定が可能です。

:::important
**Show element** または **Hide element** [アクション](onboarding-actions)を使って要素を表示・非表示にした場合、そのアクションはその要素に設定された **Visibility** 条件を上書きします。上書きは、条件内の変数または要素の状態が更新されるまで続きます。

**Visibility** 条件が設定された要素では、これらのアクションはアニメーションや遅延なしに[即座に要素を変更します](flow-show-hide-animations#when-animation-and-delay-dont-apply)。

**Visibility** 条件は、クイズの回答など特定の基準に基づいて要素を表示または非表示にする場合に使用します。アクションは、[画面が開いたときやユーザーが要素をタップしたとき](flow-show-hide-animations#show-or-hide-an-element)など、特定のタイミングで表示状態を変更する場合に使用します。
:::

要素に条件を追加するには:

1. キャンバスまたはレイヤーパネルで要素を選択します。
2. 右パネルの **Visibility** セクションで **Conditional** を選択します。

<ZoomImage id="flow-conditional-visibility.webp" width="500px" alt="条件付き表示設定" />

3. 条件を設定するには、以下のいずれかのタブからプロパティの種類を選択します：
   - **Custom**：自分で作成・管理する変数で、ユーザーの操作によって値を更新できます。詳細は[変数](onboarding-variables)をご覧ください。
   - **Product**：価格や名前など、フロー内のプロダクトのプロパティ。
   - **Elements**：クイズの回答やトグルのオン/オフなど、他のエレメントの変数。
   - **States**：**Disabled** ボタンなど、画面上の[別のエレメントの状態](element-states-in-conditions)。
   - **System**：ユーザーのデバイスのプラットフォーム（`system.platform`）。[特定のプラットフォームにのみエレメントを表示する](#show-an-element-on-one-platform-only)をご覧ください。
4. 一致させる **Value** を入力します。
5. 必要に応じてオペレーターをクリックして変更します。
6. （任意）**Add condition** をクリックして条件を追加します。セレクターを使って、すべての条件を満たす場合またはいずれか一つを満たす場合を指定できます。

<ZoomImage id="visibility.gif" width="500px" alt="要素の表示条件を設定する" />

## 要素を特定のプラットフォームのみに表示する \{#show-an-element-on-one-platform-only\}

iOS と Android で1つのフローを共有しながら、プラットフォーム固有の要素をそれぞれのプラットフォームのみに表示できます。たとえば、iOS では「App Store の設定でサブスクリプションを管理する」、Android では「Google Play でサブスクリプションを管理する」と表示できます。

1. 要素を選択し、**Visibility** セクションで **Conditional** を選択します。
2. **Variable** フィールドをクリックし、**System** タブを開いて `system.platform` を選択します。
3. 値のドロップダウンで **iOS** または **Android** を選択します。`=` を使うとその プラットフォームのみに表示され、`!=` を使うともう一方のプラットフォームのみに表示されます。

<ZoomImage id="flow-condition-system-platform.webp" width="500px" alt="Show element if editor with the System tab open and system.platform selected" />

プラットフォームは Adapty SDK が自動的に報告するため、アプリ側で渡す必要はありません。Huawei デバイスを含む Android デバイスは **Android** に一致します。

キャンバスには、条件が[プレビューデバイス](paywall-device-compatibility-preview#preview-in-the-adapty-dashboard)のプラットフォームと一致する場合に要素が表示されます。別のプラットフォームでプレビューするには、プレビューコントロールでそのプラットフォームのデバイスを選択してください。

特定のプラットフォームのみで画面全体を表示するには、[条件付きアクション](onboarding-actions#show-a-screen-on-one-platform-only)を使用してください。
