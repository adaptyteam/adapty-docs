1. App Store Connectで、[**Users and Access** > **Integrations** > **In-App Purchase**](https://appstoreconnect.apple.com/access/integrations/api/subs)に移動します。

   1つのキーでApp Store Connectチームのすべてのアプリに使用できます。このページのアクティブなキーを再利用するには、そのファイルが必要です。ファイルがあれば、ステップ2〜4はスキップしてください。新しいキーを生成しても、既存のアクティブなキーは引き続き使用できます。

2. キーを生成するには、App Store ConnectでAccount HolderまたはAdmin権限が必要です。どちらの権限もない場合は、権限を持つ方にキーの生成を依頼し、Issuer IDとKey IDとともにファイルを送ってもらってください。

   ページにすでにアクティブなキーが表示されている場合は **+** をクリックします。表示されていない場合は **Generate In-App Purchase Key** をクリックします。

   <ZoomImage id="asc-in-app-purchase-keys-add.webp" width="700px" alt="In-App Purchase keys page in App Store Connect, with the button that adds a key" />

3. キーの名前を入力し、**Generate** をクリックします。キーが **Active** リストに表示されます。

   <ZoomImage id="asc-in-app-purchase-key-name.webp" width="700px" alt="Generate In-App Purchase Key dialog with a name for the key and the Generate button" />

4. 各キーのダウンロードは1回のみ可能です。新しいキーの横にある **Download In-App Purchase Key** をクリックします。

   <ZoomImage id="asc-in-app-purchase-key-download-link.webp" width="700px" alt="Active list of In-App Purchase keys, with the download link next to a new key" />

   次に、ダイアログで **Download** をクリックします。ファイルは安全に保管してください。このキーを使用する各Adaptyアプリにアップロードします。

   <ZoomImage id="asc-in-app-purchase-key-download-dialog.webp" width="700px" alt="Download dialog for an In-App Purchase key" />
