1. **Issuer ID** と **Key ID** を確認するには、App Store Connect で [**Users and Access** > **Integrations** > **App Store Connect API**](https://appstoreconnect.apple.com/access/integrations/api) に移動し、**Team Keys** タブを開きます。他の担当者がキーを生成し、Issuer ID、Key ID、ファイルを送ってくれた場合は、この手順をスキップしてください。

   <ZoomImage id="asc-team-keys-ids.webp" width="700px" alt="Issuer ID and the Key ID of a team key on the Team Keys tab in App Store Connect" />

2. Adapty で [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk) に移動します。**App Store Connect API key** セクションで **Connect API Key** をクリックします。

   <ZoomImage id="app-settings-connect-api-key.webp" width="700px" alt="App Store Connect API key section in Adapty, with the Connect API Key button" />

3. 各フィールドを入力します：
   - **Issuer ID**：App Store Connect の **Team Keys** タブからコピーします。
   - **Key ID**：**Team Keys** タブの **Active** リストから、ダウンロードしたキーの横にある値をコピーします。
   - **Private key (.p8 file)**：チームキー用にダウンロードしたファイルをアップロードします。

   <ZoomImage id="app-settings-api-key-dialog.webp" width="700px" alt="Issuer ID, Key ID, and Private key (.p8 file) fields in the window for the App Store Connect API key" />

4. 接続済みのキーは後から置き換えることができますが、削除はできません。キーがこのアプリを所有する App Store Connect チームのものであることを確認し、**Connect** をクリックします。以降は、**App Store Product ID** をキーボードで入力するのではなく、App Store Connect 内のプロダクトから選択できるようになります。

   Adapty は接続時に Apple でキーを検証しません。誤ったキーを設定した場合、キーに関するエラーメッセージは表示されず、プロダクトに App Store のステータスが表示されなくなり、**App Store Product ID** のドロップダウンが空のままになります。誤ったキーを修正するには、[キーを置き換えて](app-store-connect-api-key#replace-the-key)ください。
