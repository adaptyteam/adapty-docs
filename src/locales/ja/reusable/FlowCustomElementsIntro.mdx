[カスタム要素](flow-custom-elements)を含む画面が開くと、Adapty SDK はその要素の Type と ID をアプリのコード内のリゾルバに渡します。リゾルバは次のいずれかを返します。

- **Type と ID に対応するビュー**: ユーザーには、Lottie アニメーション、インタラクティブなチャート、カメラプレビューなどのネイティブビューが表示されます。
- **ビューなし**: ユーザーには、フォールバック（Flow & Paywall Builder 内のカスタム要素のコンテンツ）が表示されます。

リゾルバが実装されていない旧バージョンのアプリのユーザーにも、フォールバックが表示されます。そのため、アプリのリリース前にフローを公開することができます。
