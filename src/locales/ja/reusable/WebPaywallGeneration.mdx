**URL** フィールドの下にある **generate one with AI** リンクを見つけてクリックします。

**Generation setup** パネルを展開し、6つのステップを順番に完了します。各ボタンをクリックすると該当ページが開くので、戻ってきたら **Refresh** をクリックしてください。

<ZoomImage id="mail-checkout-prerequisites.webp" width="500px" alt="Web ペイウォール作成ページの Generation setup チェックリスト" />

| チェックリスト項目 | 操作内容 |
| --- | --- |
| **1. Brand is ready** | [ブランド](mail-brand)を設定済みであれば、すでにチェックが入っています。設定していない場合は **Set up brand** をクリックします。 |
| **2. Log in to the paywall builder dashboard** | **Log in** をクリックしてビルダーを認証します。 |
| **3. Stripe account connected** | **Connect Stripe** をクリックしてアカウントを接続します。 |
| **4. At least one Stripe product with a price** | **Open Stripe dashboard** をクリックして、価格付きのプロダクトを追加します。 |
| **5. Generate the paywall** | 5.1. **Generate** をクリックします。<br />5.2. 最大3つのプランを選択します。2つ目以降は **Add plan** をクリックします。<br />5.3. 各プランに本番価格、サンドボックス価格、またはその両方を同一通貨で設定します。すべてのプランで同じ列を埋めてください。列が一部しか埋まっていないと生成がブロックされます。サンドボックス価格がない場合、[テストメール](mail-testing)は本番ペイウォールを使用するため、テスト購入が機能しません。<br />5.4. **Generate paywall** をクリックします。数分かかりますが、完了すると **URL** フィールドに自動入力されます。 |
| **6. Review and publish the paywall in the builder** | **Open editor** をクリックして内容を確認し、公開します。ペイウォールを生成するまで無効です。 |

<ZoomImage id="mail-checkout-generation-dialog.webp" width="500px" alt="本番価格とサンドボックス価格の列があるペイウォール生成ダイアログ" />

<Callout type="important">
ペイウォールはチェックアウトトラフィックを処理する前に公開されている必要があります。未公開のペイウォールは、ユーザーがメールのチェックアウトリンクをクリックするとエラーを返します。
</Callout>

ペイウォールを公開したら、**Save** をクリックします。
