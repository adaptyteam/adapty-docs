ダイヤモンドの残高を表示するには、[カスタム要素](flow-custom-elements)を使用します。カスタム要素とは、アプリのコードからネイティブビューを表示できる要素です。フローが開いている間にアプリのコードが残高を変更した場合（消費後など）、ユーザーには新しい残高が表示されます。

1. [カスタム要素を追加](flow-custom-elements#add-and-configure)して、**Type** と **ID** を入力します：
   - **Type**：`currency_balance`
   - **ID**：`diamonds`

   [ステップ 2](#create-the-balance-view) のコードは、この Type と ID によって残高ビューをカスタム要素に対応付けます。

   <ZoomImage id="vc-top-up-custom-element.webp" width="700px" alt="Custom element settings in the Flow & Paywall Builder, with currency_balance in the Type field, diamonds in the ID field, and an Icon inside the Diamond balance layer" />

2. カスタム要素の内部に、ダイヤモンドの[**Icon**](custom-media#icon)を追加します。残高ビューを持たないアプリバージョンでは、ユーザーにはこのアイコンが[フォールバック](flow-custom-elements#set-fallback-content)として表示されます。
