1. App Store Connect で [**Users and Access** > **Integrations** > **App Store Connect API**](https://appstoreconnect.apple.com/access/integrations/api) に移動し、**Team Keys** タブを開きます。Adapty にはチームキーが必要です。個人キーには Issuer ID がありません。

   1 つのチームキーで、App Store Connect チームのすべてのアプリに使用できます。このタブに **Admin** アクセス権を持つ有効なキーがあり、そのファイルを持っている場合は、そのキーを再利用し、手順 2〜4 をスキップしてください。

   チームがまだ App Store Connect API アクセスを持っていない場合は、Account Holder が[アクセスをリクエスト](https://developer.apple.com/help/app-store-connect/get-started/app-store-connect-api)します。Apple が各リクエストを審査します。

2. キーを生成するには、App Store Connect で Account Holder または Admin のロールが必要です。どちらのロールも持っていない場合は、いずれかのロールを持つ人に **Admin** アクセス権のキーを生成してもらい、Issuer ID と Key ID とともにファイルを送ってもらってください。

   タブにすでに有効なキーが表示されている場合は **+** をクリックします。表示されていない場合は **Generate API Key** をクリックします。

   <ZoomImage id="asc-team-keys-add.webp" width="700px" alt="Team Keys tab of the App Store Connect API page in App Store Connect" />

3. キーの名前を入力し、**Access** を **Admin** に設定します。**Access** は、ご自身のロールに関わらず Adapty がキーで実行できる操作を決定します。キーを生成した後に **Access** を変更することはできません。**Generate** をクリックします。

   <ZoomImage id="asc-team-key-generate-dialog.webp" width="700px" alt="Dialog for a new team key, with a name and the Access dropdown" />

4. 各キーのダウンロードは 1 回のみ可能です。新しいキーの横にある **Download** をクリックします。ファイルは安全に保管してください。このキーを使用する各 Adapty アプリにアップロードします。

   <ZoomImage id="asc-team-key-download.webp" width="700px" alt="Active list of team keys, with the Download link next to a new key" />
