`adapty-integration` スキルは、Adapty インテグレーションをエンドツーエンドで自動化します。ダッシュボードのセットアップ、SDK のインストール、ペイウォール、各ステージの確認が含まれます。プラットフォームを自動検出し、各ステージで関連する Adapty ドキュメントを取得します。Claude Code、Codex、Cursor、GitHub Copilot、Gemini CLI など、スキルをサポートする任意のコーディングエージェントで動作します。

このスキルは [`adapty-skills` プラグイン](https://github.com/adaptyteam/adapty-skills) の一部です。プラグインをインストールするには、ターミナルで次を実行してください：

```bash
npx adapty skills install
```

エージェントを再起動してスキルを読み込んでください。その他のインストール方法については、[プラグインの README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install) を参照してください。

インテグレーションを開始するには、エージェントで次のように入力してください：

```
Integrate Adapty into my app
```

スキルがいくつかのセットアップに関する質問をした後、ダッシュボードのセットアップ、SDK のインストール、ペイウォール、確認の手順を案内します。
