`adapty-integration` スキルは、ダッシュボードのセットアップ、SDK のインストール、ペイウォール、各ステージの検証まで、Adapty のインテグレーションをエンドツーエンドで自動化します。プラットフォームを自動検出し、各ステージで関連する Adapty ドキュメントを取得します。Claude Code、Codex、Cursor、GitHub Copilot、Gemini CLI など、スキルをサポートするあらゆるコーディングエージェントで動作します。

このスキルは [Adapty プラグイン](manage-adapty-with-ai) の一部です。すでにプラグインをインストール済みであれば、このスキルも利用できます。エージェントにスキルが表示されない場合は、[プラグインの README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install) に記載されているコマンドでプラグインを更新してください。

コーディングエージェントにプラグインをインストールするには、ターミナルで次のコマンドを実行します：

```bash
npx adapty skills install
```

エージェントを再起動してプラグインを読み込みます。他のインストール方法については、[プラグインの README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install) をご覧ください。

Claude Code はプラグインを自動更新しません。新しいスキルが追加されたタイミングで取得するには、Claude Code で `/plugin` を実行し、**Marketplaces** を開いて `adapty` を選択し、**Enable auto-update** を選んでください。他のエージェントでの更新コマンドは、[プラグインの README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install) をご確認ください。

インテグレーションを開始するには、エージェントに次のように入力してください：

```
Integrate Adapty into my app
```

スキルがいくつかのセットアップに関する質問をした後、ダッシュボードのセットアップ、SDK のインストール、ペイウォール、検証の手順を案内します。
