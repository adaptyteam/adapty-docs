[adapty-integration スキル](https://github.com/adaptyteam/adapty-skills)は、Adapty のインテグレーションをエンドツーエンドで自動化します。ダッシュボードの設定、SDK のインストール、ペイウォール、各ステージの確認まで対応しており、プラットフォームを自動検出して各ステージで関連する Adapty ドキュメントを取得します。

**対応ツール**: Claude Code、GitHub Copilot CLI、OpenAI Codex、Gemini CLI。

インストールするには、使用するツールに合ったフォームを選んでください。全リストは[スキルの README](https://github.com/adaptyteam/adapty-skills)に記載されています。

このリポジトリには複数のスキルが含まれており、以下の各コマンドはそれらをすべてインストールします。

**Claude Code**

```
claude plugin marketplace add adaptyteam/adapty-skills
claude plugin install adapty-skills@adapty
```

**GitHub Copilot CLI**

```
git clone https://github.com/adaptyteam/adapty-skills.git
cp -r adapty-skills/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```
gemini skills install https://github.com/adaptyteam/adapty-skills
```

**OpenAI Codex**

```
codex plugin marketplace add adaptyteam/adapty-skills
codex plugin add adapty-skills@adapty
```

**その他のツール** — [skills CLI](https://skills.sh) を使用してください（この方法でインストールしたスキルは自動更新されません）:

```
npx skills add adaptyteam/adapty-skills --all
```

`--all` を指定すると、検出されたすべてのエージェントにすべてのスキルがインストールされます。指定しない場合、CLI がどれをインストールするか確認します。

または、リポジトリをクローンして `skills/` 以下のディレクトリをツールのスキルディレクトリにコピーしてください。

インストール後、プロジェクト内でスキルを実行します:

```
/adapty-integration
```

スキルはいくつかのセットアップに関する質問をした後、ダッシュボードの設定、SDK のインストール、ペイウォール、確認の手順を順番に案内します。
