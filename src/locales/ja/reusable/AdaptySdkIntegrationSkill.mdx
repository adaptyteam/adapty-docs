[adapty-integration スキル](https://github.com/adaptyteam/adapty-skills)は、Adapty のインテグレーションをエンドツーエンドで自動化します。ダッシュボードのセットアップ、SDK のインストール、ペイウォール、各ステージの検証が含まれます。プラットフォームを自動検出し、各ステージで関連する Adapty ドキュメントを取得します。

**対応ツール**: Claude Code、GitHub Copilot CLI、OpenAI Codex、Gemini CLI。

インストールするには、お使いのツールに合ったフォームを選択してください。完全なリストは [スキルの README](https://github.com/adaptyteam/adapty-skills) にあります。

このリポジトリには `adapty-integration` と `ads-manager` の 2 つのスキルが含まれています。`ads-manager` は Adapty CLI を通じて Apple Search Ads を実行します。以下の各コマンドで両方をインストールします。

**Claude Code**

```
claude plugin marketplace add adaptyteam/adapty-skills
claude plugin install adapty-skills@adapty
```

**GitHub Copilot CLI**

```
git clone https://github.com/adaptyteam/adapty-skills.git
cp -r adapty-skills/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```
gemini skills install https://github.com/adaptyteam/adapty-skills
```

**OpenAI Codex またはその他のツール** — [skills CLI](https://skills.sh) を使用してください（この方法でインストールしたスキルは自動更新されません）:

```
npx skills add adaptyteam/adapty-skills --all
```

`--all` を指定すると、検出されたすべてのエージェントに両方のスキルがインストールされます。指定しない場合、CLI がどちらをインストールするか確認します。

または、リポジトリをクローンして `skills/` 以下のディレクトリをお使いのツールのスキルディレクトリにコピーしてください。

インストール後、プロジェクト内でスキルを実行します:

```
/adapty-integration
```

スキルがいくつかのセットアップの質問をし、その後ダッシュボードのセットアップ、SDK のインストール、ペイウォール、検証をステップごとに案内します。
