`adapty-integration` スキルは、Adapty のインテグレーションをエンドツーエンドで自動化します：ダッシュボードのセットアップ、SDK のインストール、ペイウォール、および各ステージの検証。プラットフォームを自動検出し、各ステージで関連する Adapty ドキュメントを取得します。Claude Code、Codex、Cursor、GitHub Copilot、Gemini CLI など、スキルをサポートするあらゆるコーディングエージェントで動作します。

このスキルは [`adapty-skills` プラグイン](https://github.com/adaptyteam/adapty-skills)の一部です。プラグインをインストールするには、ターミナルで次のコマンドを実行してください：

```bash
npx adapty skills install
```

エージェントを再起動してスキルを読み込んでください。その他のインストール方法については、[プラグインの README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install) を参照してください。

Claude Code はプラグインを自動更新しません。新しいスキルが公開されたタイミングで入手するには、Claude Code で `/plugin` を実行し、**Marketplaces** を開いて `adapty` を選択し、**Enable auto-update** を選択してください。他のエージェントでの更新コマンドについては、[プラグインの README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install) を参照してください。

インテグレーションを開始するには、エージェントで次のように入力してください：

```
Integrate Adapty into my app
```

スキルはいくつかのセットアップに関する質問をした後、ダッシュボードのセットアップ、SDK のインストール、ペイウォール、および検証の各ステップを案内します。
