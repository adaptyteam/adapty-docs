1. [2つのフローを作成します](paywall-builder-templates)：ユーザーの体重と身長を収集するオンボーディングフローと、BMIを表示するペイウォールフローです。
2. オンボーディングフローに2つの [**Number** 入力欄](builder-inputs-and-forms) を追加します：
   - 体重（キログラム）用。**Element ID** を `weight` に設定します。
   - 身長（センチメートル）用。**Element ID** を `height` に設定します。

   両方の入力欄で、**Format** を **Integer** に設定してください。入力欄はユーザーが入力したテキストをそのまま送信するため、[サンプルコード](#pass-the-bmi-to-the-paywall) では「70.5」と「70,5」を同じように読み取れません。整数には小数点区切り文字がないため、どのロケールでも同じように読み取れます。

   各 **Number** 入力欄の代わりに [Number ピッカー](builder-number-picker) を使用する場合、アプリのコードは `value` を文字列ではなく数値型として受け取ります。サンプルコードでは、`value` を小数を受け付ける数値型として読み取ってください。
3. アプリが両方の値を受け取れるよう、オンボーディングフローの最後に入力欄のないスクリーンを追加します。そのスクリーンに [**Close flow**](onboarding-actions#close-flow) アクションを持つボタンを追加してください。入力欄はフォーカスが外れたとき、またはユーザーが別のスクリーンに移動したときに値を送信します。Close flow アクションは値を送信しません。サンプルコードは、ユーザーが最後のスクリーンに到達した場合にのみペイウォールを開きます。
4. ペイウォールフローで、`bmi` という名前の [カスタムタグを作成します](flow-custom-tags#create-a-custom-tag)。**Initial value** フィールドにダッシュ（`—`）を入力します。アプリが BMI を渡さない場合、ユーザーにはダッシュが表示されます。
5. ペイウォールフローに「Your BMI:」というテキスト要素を追加します。この文字の後に [`bmi` カスタムタグを挿入します](flow-custom-tags#add-a-custom-tag-to-a-text-element)。
6. オンボーディングフローを `onboarding` などの [プレースメント](placements) に追加します。ペイウォールフローを ID `bmi_paywall` のプレースメントに追加します。[BMI をペイウォールに渡す](#pass-the-bmi-to-the-paywall) のコードはこの ID でペイウォールを取得します。
