[Apple Ads プラグイン](https://github.com/adaptyteam/apple-ads-cli)は、AI コーディングツールが `adapty asa` コマンドを通じて Apple Ads を操作できるようにします。3つのスキルが含まれています：

- **`apple-ads`**: オペレーター。パフォーマンスの読み取り、入札額・予算の変更、キーワードやネガティブキーワードの追加、検索語句の収集、キャンペーンの起動・一時停止を行います。費用が発生する操作の前には必ず確認を求めます。
- **`apple-ads-audit`**: 読み取り専用の監査ツール。アカウントの健全性、配信ステータス、構造、トラフィックの所有状況、重複する完全一致キーワードを確認します。書き込み操作は一切行いません。
- **`apple-ads-strategy`**: アカウント、CLI、サブスクリプションなしで動作するプランナー。アプリの説明をもとに、アカウント構造、キーワード分類、開始予算、ネガティブキーワードリストを生成します。

**対応ツール**: Claude Code、Claude Cowork、GitHub Copilot CLI、OpenAI Codex、Gemini CLI、およびスキルをサポートするその他のツール。

オペレーターと監査ツールは Adapty CLI を使用するため、先に CLI のインストールと認証を完了してください。[クイックスタートガイド](developer-cli-quickstart)を参照してください。`adapty asa` コマンドは **Adapty CLI 0.4.0 以降**に含まれており、古いバージョンには存在しません。`adapty asa whoami` で確認できます。このコマンドは、Apple Ads アカウントが接続されているか、会社がアクティブな Ads Manager サブスクリプションを持っているかどうかも表示します。strategy スキルはこれらなしで動作します。

Claude Cowork は、許可リスト外のドメインをすべてブロックするサンドボックス内で CLI を実行します。プラグインをインストールする前に、Adapty のドメインを許可してください。[Claude Cowork で Adapty CLI をセットアップする](developer-cli-cowork)を参照してください。Cowork のタスクはクリーンな環境で開始されるため、CLI とそのログイン情報はセッション間で引き継がれません。プラグインの `adapty-cli-setup` スキルは、各セッションの開始時に CLI のインストールと認証を再実行します。

インストールするには、ご使用のツールに合った方法を選択してください。全リストは[プラグインの README](https://github.com/adaptyteam/apple-ads-cli)を参照してください。

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/apple-ads-cli
claude plugin install apple-ads@adapty
```

**OpenAI Codex**

```bash
codex plugin marketplace add adaptyteam/apple-ads-cli
codex plugin add apple-ads@adapty
```

どちらのプラグイン方法でも、スキルとともに `/asa-*` コマンドが提供されます。これらは週次チェックインの `/asa-review`、検索語句をキーワードやネガティブキーワードに変換する `/asa-harvest` など、一般的な作業向けに用意されたプロンプトです。Claude Code ではスラッシュコマンドとして使用でき、Codex では名前で呼び出すスキルとして読み込まれます。

**その他のツール** — [skills CLI](https://skills.sh) を使用してください（この方法でインストールされたスキルは自動更新されません）：

```bash
npx skills add adaptyteam/apple-ads-cli --all
```

`--all` は検出されたすべてのエージェントに3つのスキルをすべてインストールします。1つのスキルだけをインストールする場合は `--skill` を使用します。例: `--skill apple-ads-strategy`。

インストール後、プロジェクトでスキルを実行します。直接実行するか、スラッシュコマンドを使用してください：

```bash
/apple-ads
```

指標の読み取りとドライランは無料です。その他のコマンドは数秒以内に Apple に到達し、実際の費用が発生し、取り消すことができません。スキルは各操作の前に確認を求めます。あなた自身も同様に確認するようにしてください。
