[ads-manager スキル](https://github.com/adaptyteam/adapty-sdk-integration-skill)は、AIコーディングツールに `adapty asa` コマンドを通じて Apple Ads を操作する方法を教えます。コマンドの組み合わせ順序、書き込み前に読むべき内容、そして実際に費用が発生するコマンドを把握しています。

**対応ツール**: Claude Code、GitHub Copilot CLI、OpenAI Codex、Gemini CLI

このスキルは Adapty CLI を動かすので、先に CLI をインストールして認証を済ませてください。詳しくは[クイックスタートガイド](developer-cli-quickstart)を参照してください。`adapty asa` コマンドは **Adapty CLI 0.4.0 以降**に含まれており、古いバージョンにはそもそも存在しません。`adapty asa whoami` で確認できます。このコマンドは Apple Ads アカウントが連携済みかどうか、および会社が有効な Ads Manager サブスクリプションを持っているかも教えてくれます。

企業の Cowork ワークスペースでは、管理者がドメイン許可リストに `adapty.io` と `*.adapty.io` の両方を追加する必要があります。両方を記載してください。ほとんどの許可リスト実装ではワイルドカードはapex ドメインをカバーしないため、スキルが参照するドキュメントはapex ドメインに置かれています。両方が許可されるまで、スキルは Adapty にアクセスできません。

インストールするには、お使いのツールに合った方法を選んでください。全リストは[スキルの README](https://github.com/adaptyteam/adapty-sdk-integration-skill) を参照してください。

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

このプラグインには SDK インテグレーションスキルも含まれています。両方がまとめてインストールされます。

**GitHub Copilot CLI**

```bash
git clone https://github.com/adaptyteam/adapty-sdk-integration-skill.git
cp -r adapty-sdk-integration-skill/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```bash
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex またはその他のツール** — [skills CLI](https://skills.sh) を使用してください（この方法でインストールされたスキルは自動更新されません）:

```bash
npx skills add adaptyteam/adapty-sdk-integration-skill --all
```

`--all` は検出されたすべてのエージェントに両方のスキルをインストールします。このスキル単体の場合は `--skill ads-manager` を使用してください。

または、リポジトリをクローンして `skills/` 以下のディレクトリをツールのスキルディレクトリにコピーしてください。このスキルだけが必要な場合は `skills/ads-manager/` のみをコピーしてください。

インストール後、プロジェクトでスキルを実行します:

```bash
/ads-manager
```

指標の読み取りとドライランは無料です。それ以外のコマンドは数秒以内に Apple に到達し、実際の費用が発生し、取り消すことができません。スキルは実行前に確認を求めますが、あなた自身も同様に確認してください。
