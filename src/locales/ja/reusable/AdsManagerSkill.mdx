[ads-manager スキル](https://github.com/adaptyteam/adapty-sdk-integration-skill) は、AI コーディングツールが `adapty asa` コマンドを使って Apple Ads を操作できるよう訓練します。コマンドの実行順序、書き込み前に何を確認すべきか、どの呼び出しが課金されるかを把握しています。

**対応ツール**: Claude Code、GitHub Copilot CLI、OpenAI Codex、Gemini CLI。

このスキルは Adapty CLI を使って動作するため、まず CLI をインストールして認証を済ませてください — [クイックスタートガイド](developer-cli-quickstart) を参照してください。`adapty asa` コマンドは **Adapty CLI 0.4.0 以降** に含まれており、それより古いバージョンには存在しません。`adapty asa whoami` で確認できます。このコマンドは、Apple Ads アカウントが接続されているか、Ads Manager サブスクリプションがアクティブかどうかも表示します。

Claude Cowork は、許可リスト以外のドメインをすべてブロックするサンドボックス内で CLI を実行します。スキルをインストールする前に Adapty のドメインを許可してください — [Run the CLI in Cowork](developer-cli-quickstart#run-the-cli-in-cowork) を参照してください。

インストールするには、お使いのツールに合った方法を選んでください。全リストは [スキルの README](https://github.com/adaptyteam/adapty-sdk-integration-skill) をご覧ください。

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

このプラグインには SDK インテグレーションスキルも含まれています。両方が一緒にインストールされます。

**GitHub Copilot CLI**

```bash
git clone https://github.com/adaptyteam/adapty-sdk-integration-skill.git
cp -r adapty-sdk-integration-skill/skills/* ~/.copilot/skills/
```

**Gemini CLI**

```bash
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex またはその他のツール** — [skills CLI](https://skills.sh) を使用してください（この方法でインストールしたスキルは自動更新されません）：

```bash
npx skills add adaptyteam/adapty-sdk-integration-skill --all
```

`--all` を指定すると、検出されたすべてのエージェントに両方のスキルがインストールされます。このスキルだけをインストールするには `--skill ads-manager` を使用してください。

または、リポジトリをクローンして `skills/` 以下のディレクトリをツールのスキルディレクトリにコピーしてください。このスキルだけが必要な場合は `skills/ads-manager/` のみをコピーします。

インストール後、プロジェクト内でスキルを実行します：

```bash
/ads-manager
```

指標の読み取りとドライランは無料です。それ以外のコマンドはすべて数秒以内に Apple に到達し、実際の課金が発生し、取り消しができません — スキルは実行前に確認を求めます。あなたも同様に確認してください。
