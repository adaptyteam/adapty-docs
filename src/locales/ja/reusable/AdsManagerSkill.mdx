[Apple Ads プラグイン](https://github.com/adaptyteam/apple-ads-cli)は、AI コーディングツールに `adapty asa` コマンドを通じて Apple Ads を操作する方法を教えます。3つのスキルが含まれています：

- **`apple-ads`**: オペレーター。パフォーマンスの確認、入札額・予算の変更、キーワードと除外キーワードの追加、検索語句の収集、キャンペーンの開始・一時停止を行います。費用が発生する操作は実行前に確認を求めます。
- **`apple-ads-audit`**: 読み取り専用の監査ツール。アカウントの健全性、配信ステータス、構造、トラフィックの所有権、重複する完全一致キーワードをチェックします。書き込みは一切行いません。
- **`apple-ads-strategy`**: アカウント、CLI、サブスクリプション不要のプランニングツール。アプリの説明をもとに、アカウント構造、キーワードの分類体系、初期予算、除外キーワードリストを作成します。

**対応ツール**: Claude Code、Claude アプリ（旧称 Claude Cowork）、GitHub Copilot CLI、OpenAI Codex、Gemini CLI、その他スキルに対応したあらゆるツール。

オペレーターと監査ツールは Adapty CLI を使用するため、まず CLI のインストールと認証を行ってください。詳しくは[クイックスタートガイド](developer-cli-quickstart)をご覧ください。`adapty asa` コマンドは **Adapty CLI 0.4.0 以降**に含まれており、古いバージョンでは利用できません。`adapty asa whoami` で確認できます。このコマンドは Apple Ads アカウントの接続状況や、会社がアクティブな Ads Manager サブスクリプションを持っているかどうかも確認できます。strategy スキルはこれらが不要です。

Claude アプリは CLI をサンドボックス内で実行するため、許可リスト外のドメインはすべてブロックされます。プラグインをインストールする前に、Adapty のドメインを許可してください。詳しくは[Claude アプリでの Adapty CLI のセットアップ](developer-cli-cowork)をご覧ください。また、Claude アプリの各会話はクリーンな環境で開始されるため、CLI とそのログイン情報は会話をまたいで引き継がれません。プラグインの `adapty-cli-setup` スキルは、各会話の開始時に CLI のインストールと認証を再度行います。

インストールするには、お使いのツールに対応した手順を選択してください。すべての対応ツールの一覧は[プラグインの README](https://github.com/adaptyteam/apple-ads-cli)に記載されています。

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/apple-ads-cli
claude plugin install apple-ads@adapty
```

**OpenAI Codex**

```bash
codex plugin marketplace add adaptyteam/apple-ads-cli
codex plugin add apple-ads@adapty
```

どちらのプラグイン経由でも、スキルと一緒に `/asa-*` コマンドが追加されます。週次チェックイン用の `/asa-review` や、検索語句をキーワードと除外キーワードに変換する `/asa-harvest` など、よく使う操作のための既成プロンプトです。Claude Code ではスラッシュコマンドとして使用でき、Codex では名前で呼び出すスキルとして読み込まれます。

**その他のツール** — [skills CLI](https://skills.sh) を使用してください（この方法でインストールしたスキルは自動更新されません）：

```bash
npx skills add adaptyteam/apple-ads-cli --all
```

`--all` は検出されたすべてのエージェントに3つのスキルをすべてインストールします。1つのスキルだけインストールする場合は `--skill` を使用します。例：`--skill apple-ads-strategy`。

インストール後、プロジェクトでスキルを実行します。直接実行するか、スラッシュコマンドを使用してください：

```bash
/apple-ads
```

指標の確認やドライランは無料です。それ以外のコマンドは数秒以内に Apple に接続し、実際の費用が発生し、取り消しができません。スキルは実行前に確認を求めますが、ご自身でも必ず確認してください。
