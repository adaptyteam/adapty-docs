[ads-manager スキル](https://github.com/adaptyteam/adapty-sdk-integration-skill)は、AIコーディングツールが `adapty asa` コマンドを通じてApple Adsを操作できるようにします。コマンドの組み合わせ順序、何かを書く前に読むべき内容、そして費用が発生するコールについての知識を持っています。

**対応ツール**: Claude Code、GitHub Copilot CLI、OpenAI Codex、Gemini CLI。

このスキルはAdapty CLIを使用するため、まずCLIをインストールして認証を済ませてください — [クイックスタートガイド](developer-cli-quickstart)を参照してください。

企業のCoworkワークスペースでは、管理者が `*.adapty.io` をドメインの許可リストに追加する必要があります。追加されるまで、スキルはAdaptyに接続できません。

インストールするには、使用するツールに合ったフォームを選択してください。完全なリストは[スキルのREADME](https://github.com/adaptyteam/adapty-sdk-integration-skill)に記載されています。

**Claude Code**

```bash
claude plugin marketplace add adaptyteam/adapty-sdk-integration-skill
claude plugin install adapty-sdk-integration@adapty
```

このプラグインにはSDKインテグレーションスキルも含まれています。両方が一緒にインストールされます。

**GitHub Copilot CLI**

```bash
gh skill install adaptyteam/adapty-sdk-integration-skill
```

**Gemini CLI**

```bash
gemini skills install https://github.com/adaptyteam/adapty-sdk-integration-skill
```

**OpenAI Codex またはその他のツール** — [skills CLI](https://skills.sh)を使用してください（この方法でインストールしたスキルは自動更新されません）：

```bash
npx skills add adaptyteam/adapty-sdk-integration-skill
```

または、リポジトリをクローンして `skills/ads-manager/` をツールのスキルディレクトリにコピーしてください。

インストール後、プロジェクトでスキルを実行します：

```bash
/ads-manager
```

指標の読み取りとドライランは無料です。それ以外のコマンドはすべて数秒以内にAppleに到達し、実際のお金が使われ、取り消しはできません — スキルは各コマンドの前に確認を求めます。あなたも同様に確認すべきです。
