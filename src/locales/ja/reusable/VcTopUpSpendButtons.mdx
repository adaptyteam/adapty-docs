ユーザーがタップするボタンにスピナーとチェックマークを順番に表示するには、両方のボタンをカスタム要素として追加します。ビルダーボタンに[カスタムアクション](onboarding-actions#what-custom-actions-cant-do)が設定されている場合、スピナーもチェックマークも表示されません。カスタムアクションは一方向です。アプリコードはspendの結果をフローに返すことができません。ボタンのテキストと外観はアプリコードから指定します。テキストや外観を変更するには、[アプリのアップデートをリリース](flow-custom-elements#what-changes-require-an-app-release)してください。

1. エネルギー補充用の[カスタム要素を追加](flow-custom-elements#add-and-configure)し、**Type** と **ID** を入力します:
   - **Type**: `spend_button`.
   - **ID**: `energy_refill`.
2. 無制限エネルギー用に2つ目のカスタム要素を追加します。Typeは同じで、IDは `unlimited_energy` にします。

   [ステップ2](#connect-the-buttons-to-your-backend)のコードは、Typeを使って1つのボタンビューを両方のカスタム要素にマッチさせます。各ボタンのオプションはIDから読み取られます。

   <ZoomImage id="vc-top-up-spend-button.webp" width="700px" alt="Custom element settings in the Flow & Paywall Builder, with spend_button in the Type field and unlimited_energy in the ID field" />

3. 各カスタム要素の **Fixed** の高さを200から、ボタンに必要な高さに変更します。
4. 各カスタム要素の内側にテキスト要素を追加し、オプションの文言を入力します:
   - エネルギー補充: "Update the game to refill energy."
   - 無制限エネルギー: "Update the game to get unlimited energy."

   ボタンビューを持たないアプリバージョンでは、ユーザーにはこのテキストが[フォールバック](flow-custom-elements#set-fallback-content)として表示され、タップできるボタンはありません。
