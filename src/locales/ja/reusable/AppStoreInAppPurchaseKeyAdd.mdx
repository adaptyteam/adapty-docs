1. **Issuer ID** と **Key ID** を確認するには、App Store Connect で [**Users and Access** > **Integrations** > **In-App Purchase**](https://appstoreconnect.apple.com/access/integrations/api/subs) に移動します。他の人がキーを生成し、Issuer ID、Key ID、ファイルを送ってもらった場合は、このステップをスキップしてください。

   <ZoomImage id="asc-in-app-purchase-keys-ids.webp" width="700px" alt="Issuer ID and the Key ID of an In-App Purchase key in App Store Connect" />

2. Adapty で [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk) に移動します。**In-app purchase API (StoreKit 2)** セクションで、各フィールドを入力してください：
   - **Issuer ID**：App Store Connect の **In-App Purchase** ページからコピーします。
   - **Key ID**：**In-App Purchase** ページの **Active** リストで、ダウンロードしたキーの横に表示されている値をコピーします。
   - **Private key (.p8 file)**：ダウンロードしたファイルをアップロードします。

   <ZoomImage id="app-settings-in-app-purchase-api.webp" width="700px" alt="Issuer ID, Key ID, and Private key (.p8 file) fields in the In-app purchase API (StoreKit 2) section in Adapty" />

3. Adapty は In-App Purchase キーを使って[プロモーションオファー](offers)に署名します。**App Store promotional offers** セクションで、同じキーを再度入力してください：
   - **Subscription key ID**：手順 2 の Key ID を入力します。
   - **Subscription key (.p8 file)**：手順 2 のファイルをアップロードします。

   <ZoomImage id="app-settings-promotional-offers.webp" width="700px" alt="Subscription key ID and Subscription key (.p8 file) fields in the App Store promotional offers section" />

   別のキーを入力してもエラーなく保存されますが、ユーザーはプロモーションオファーを受け取れなくなります。

4. **Save** をクリックします。Adapty はページを保存する前に、**In-app purchase API (StoreKit 2)** セクションのキーを Apple に対して検証します。Apple がキーを拒否した場合、ページに「The provided field values are incorrect」と表示されます。[値を確認してください](troubleshoot-app-store-integration#the-provided-field-values-are-incorrect-when-saving-credentials)。
