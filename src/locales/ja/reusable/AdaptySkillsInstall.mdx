プラグインをインストールするには、ターミナルで次のコマンドを実行してください：

```bash
npx adapty skills install
```

エージェントを再起動してスキルを読み込んでください。その他のインストール方法については、[プラグインの README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install) を参照してください。

Claude Code はプラグインを自動更新しません。新しいスキルが追加されたら、Claude Code で `/plugin` を実行して **Marketplaces** を開き、`adapty` を選択して **Enable auto-update** を選んでください。他のエージェントでの更新コマンドについては、[プラグインの README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install) を参照してください。
