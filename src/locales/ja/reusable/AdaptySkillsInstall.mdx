Adapty プラグインをすでにインストール済みであれば、このスキルは利用可能です。エージェントの一覧に表示されていない場合は、[プラグイン README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install) に記載されているコマンドでプラグインを更新してください。

コーディングエージェントにプラグインをインストールするには、ターミナルで次のコマンドを実行してください：

```bash
npx adapty skills install
```

エージェントを再起動してプラグインを読み込んでください。claude.ai または Claude デスクトップへのインストール方法は、[プラグインのインストール](manage-adapty-with-ai#install-the-plugin) を参照してください。その他のインストール方法については、[プラグイン README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install) を参照してください。

Claude Code はプラグインを自動更新しません。新しいスキルが追加されたタイミングで取得するには、Claude Code で `/plugin` を実行し、**Marketplaces** を開いて `adapty` を選択し、**Enable auto-update** を選んでください。その他のエージェントでの更新コマンドは、[プラグイン README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install) を参照してください。
