**有効（デフォルト）**

識別済みユーザー（[Customer User ID](identifying-users#set-customer-user-id-on-configuration) を持つユーザー）は、デバイスが同じ Apple/Google ID でサインインしている場合、Adapty が提供する同じ[アクセスレベル](access-level)を共有できます。これは、ユーザーがアプリを再インストールして別のメールアドレスでログインしても、以前の購入へのアクセスを維持できるため便利です。このオプションでは、複数の識別済みユーザーが同じアクセスレベルを共有できます。

アクセスレベルは共有されますが、過去および将来のすべてのトランザクションは、一貫したアナリティクスを維持し完全なトランザクション履歴（トライアル期間、サブスクリプション購入、更新など）を同じプロファイルに紐付けるために、元の Customer User ID のイベントとして記録されます。

**新しいユーザーへのアクセス移転**

識別済みユーザーは、別の [Customer User ID](identifying-users#set-customer-user-id-on-configuration) でログインしたり、アプリを再インストールしたりしても、デバイスが同じ Apple/Google ID でサインインしている限り、Adapty が提供する[アクセスレベル](access-level)へのアクセスを維持できます。

前のオプションと異なり、Adapty は識別済みユーザー間で購入を移転します。これにより購入済みコンテンツへのアクセスは保証されますが、一度にアクセスできるのは 1 人のユーザーのみです。たとえば、UserA がサブスクリプションを購入し、UserB が同じデバイスでログインしてトランザクションを復元した場合、UserB がサブスクリプションへのアクセスを取得し、UserA からは取り消されます。

どちらかのユーザー（新しいユーザーまたは古いユーザー）が識別されていない場合でも、Adapty ではそれらのプロファイル間でアクセスレベルが共有されます。

アクセスレベルは移転されますが、過去および将来のすべてのトランザクションは、一貫したアナリティクスを維持し完全なトランザクション履歴（トライアル期間、サブスクリプション購入、更新など）を同じプロファイルに紐付けるために、元の Customer User ID のイベントとして記録されます。

**新しいユーザーへのアクセス移転**に切り替えた後、アクセスレベルはすぐにはプロファイル間で移転されません。特定のアクセスレベルの移転プロセスは、サブスクリプションの更新、復元、またはトランザクションの検証など、ストアからイベントを受信したときにのみトリガーされます。

**無効**

アクセスレベルを最初に取得した識別済みユーザープロファイルが、そのアクセスを永続的に保持します。ビジネスロジック上、購入を単一の Customer User ID に紐付ける必要がある場合に最適なオプションです。

なお、アクセスレベルは匿名ユーザー間では引き続き共有されます。

購入の「紐付け解除」は、[オーナーのユーザープロファイルを削除する](https://adapty.io/docs/ja/api-adapty/operations/deleteProfile)ことで行えます。削除後、アクセスレベルは匿名・識別済みを問わず最初にそれを要求したユーザープロファイルが利用できるようになります。

共有の無効化は新しいユーザーにのみ影響します。すでにユーザー間で共有されているサブスクリプションは、このオプションを無効にした後も引き続き共有されます。

<Callout type="warning">
Apple と Google は、Apple/Google ID を使って購入と関連付けるため、アプリ内課金をユーザー間で共有または移転することを要求しています。共有しない場合、その後の再インストール時に購入の復元ができない可能性があります。

共有を無効にすると、ログイン後にユーザーがアクセスを取り戻せなくなる場合があります。

共有の無効化は、購入前にユーザーが**必ずログインする必要がある**場合にのみ推奨します。そうでない場合、識別済みユーザーがサブスクリプションを購入後、別のアカウントにログインしてアクセスを永久に失う可能性があります。
</Callout>

### どの設定を選べばよいですか？ \{#which-setting-should-i-choose\}

| アプリの状況                                                    | 推奨オプション                                             |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| ログインシステムがなく、Adapty の匿名プロファイル ID のみを使用している。 | デフォルトのオプションを使用してください。3 つのオプションすべてで、匿名プロファイル ID 間ではアクセスレベルが常に共有されます。 |
| オプションのログインシステムがあり、アカウント作成前に購入できる。 | アカウントなしで購入したユーザーが後からトランザクションを復元できるよう、**新しいユーザーへのアクセス移転**を選択してください。 |
| 購入前にアカウント作成が必須だが、複数の Customer User ID への購入の紐付けを許可している。 | 一度にアクセスできる Customer User ID を 1 つに制限しながら、別の Customer User ID でログインしても有料アクセスを失わないよう、**新しいユーザーへのアクセス移転**を選択してください。 |
| 購入前にアカウント作成が必須で、購入を単一の Customer User ID に厳密に紐付けるルールがある。 | トランザクションがアカウント間で移転されないよう、**無効**を選択してください。 |
