1. Adaptyで、接続するアプリを開きます。各AdaptyアプリにはそれぞれのNotification URLがあります。[**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk)に移動します。**App Store server notifications**セクションで、**URL for App Store server notifications**フィールドからURLをコピーします。

   <ZoomImage id="app-settings-notifications-url.webp" width="700px" alt="AdaptyのApp Store server notificationsセクションにあるURL for App Store server notifications" />

2. [App Store Connect](https://appstoreconnect.apple.com/apps)で、アプリの**App Information**ページを開きます。
3. **App Store Server Notifications**セクションで、**Production Server URL**を探します。すでにURLが設定されている場合は**Edit**をクリックし、設定されていない場合は**Set Up URL**をクリックします。

   <ZoomImage id="asc-server-notifications-set-up-url.webp" width="700px" alt="App Store ConnectのApp InformationページにあるApp Store Server Notificationsセクション" />

4. AdaptyのURLを貼り付け、**Save**をクリックします。

   <ZoomImage id="asc-server-url-set-up-dialog.webp" width="700px" alt="App Store ConnectのProduction Server URLダイアログ（AdaptyのURLを入力した状態）" />

5. サンドボックステストからの通知もAdaptyに届くようにするには、**Sandbox Server URL**について手順3と4を繰り返します。
