
| イベント名 | 説明 |
|:-----------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| subscription_started | トライアル期間なしで有料サブスクリプションを開始したとき（即時課金）にトリガーされます。 |
| subscription_active | `subscription_started` イベントの後、サブスクリプションがまだアクティブであることを確認します。サブスクリプション開始からこのチェックまでの日数を設定する必要があります。自動更新がすでにキャンセルされていたり、ユーザーがグレース期間に入っていても、サブスクリプションがアクティブであればイベントが届きます。その時点でサブスクリプションが終了していた場合は、何も届かず Adapty は再チェックしません。このイベントはトライアルなしで購入されたサブスクリプションにのみ続きます。トライアルからの切り替えは `trial_converted` を送信し、このチェックは開始されません。 |
| subscription_renewed | サブスクリプションが更新されてユーザーに課金されたときに発生します。このイベントはトライアルあり・なし問わず2回目の請求から始まります。 |
| subscription_renewal_cancelled | ユーザーがサブスクリプションの自動更新をオフにしました。ユーザーは有料サブスクリプション期間の終了までプレミアム機能へのアクセスを維持します。 |
| subscription_renewal_reactivated | ユーザーがサブスクリプションの自動更新を再有効化したときにトリガーされます。 |
| subscription_expired | キャンセル後にサブスクリプションが完全に終了したときにトリガーされます。たとえば、ユーザーが12月12日にサブスクリプションをキャンセルしても12月31日まで有効な場合、イベントは12月31日に記録されます。 |
| subscription_paused | ユーザーが[サブスクリプションの一時停止](https://developer.android.com/google/play/billing/lifecycle/subscriptions#pause)を有効にしたときに発生します（Android のみ）。 |
| subscription_deferred | サブスクリプション購入が[延期](https://adapty.io/glossary/subscription-purchase-deferral/)され、ユーザーがプレミアム機能へのアクセスを維持しながら支払いを遅らせられるようになったときにトリガーされます。この機能は Google Play Developer API を通じて利用でき、無料トライアルや経済的な困難を抱えるユーザーへの対応に使用できます。 |
| non_subscription_purchase | 永続アクセスやゲーム内コインなどの消耗型アイテムといった、サブスクリプション以外のすべての購入。 |
| trial_started | ユーザーがトライアルサブスクリプションを開始したときにトリガーされます。 |
| trial_active | `trial_started` イベントの後、トライアルがまだアクティブであることを確認します。トライアル開始からこのチェックまでの日数を設定する必要があります。自動更新がすでにキャンセルされていても、トライアルがアクティブであればイベントが届きます。その時点でトライアルが終了または切り替えが済んでいた場合は、何も届かず Adapty は再チェックしません。 |
| trial_converted | トライアルが終了してユーザーに課金（初回購入）されたときに発生します。たとえば、ユーザーのトライアルが1月14日までだが1月7日に課金された場合、このイベントは1月7日に記録されます。 |
| trial_renewal_cancelled | トライアル期間中にユーザーがサブスクリプションの自動更新をオフにしました。ユーザーはトライアル終了までプレミアム機能へのアクセスを維持しますが、課金もサブスクリプション開始もされません。 |
| trial_renewal_reactivated | トライアル期間中にユーザーがサブスクリプションの自動更新を再有効化したときに発生します。 |
| trial_expired | トライアルがサブスクリプションに切り替わらずに終了したときにトリガーされます。 |
| entered_grace_period | 支払いの試行が失敗し、ユーザーがグレース期間（有効な場合）に入ったときに発生します。この期間中、ユーザーはプレミアムアクセスを維持します。 |
| billing_issue_detected | 課金試行中に請求の問題（カード残高不足など）が発生したときにトリガーされます。 |
| subscription_refunded | サブスクリプションが（Apple サポートなどにより）返金されたときにトリガーされます。 |
| non_subscription_purchase_refunded | サブスクリプション以外の購入が返金されたときにトリガーされます。 |
| access_level_updated | ユーザーのアクセスレベルが更新されたときに発生します。 |
