
| イベント名 | 説明 |
|:-----------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| subscription_started               | トライアル期間なしで有料サブスクリプションを有効にしたとき（つまり即時請求が発生したとき）にトリガーされます。                                                                                                                                                                                                                                      |
| subscription_active                | `subscription_started` イベントの後、サブスクリプションがまだアクティブであることを確認します。サブスクリプション開始からこの確認までの日数を設定する必要があります。ユーザーがグレース期間に入っている場合も含め、サブスクリプションがアクティブであればイベントが届きます。その時点でサブスクリプションが終了していた場合、または自動更新をオフにしていた場合は何も届かず、Adapty は再確認を行いません。このイベントはトライアルなしで購入されたサブスクリプションにのみ続きます。トライアルからの移行時は `trial_converted` が送信されますが、その場合はこの確認はトリガーされません。 |
| subscription_renewed               | サブスクリプションが更新され、ユーザーに請求が発生したときに発生します。このイベントはトライアルあり・なしに関わらず、2回目以降の請求から記録されます。                                                                                                                                                                                           |
| subscription_renewal_cancelled     | ユーザーがサブスクリプションの自動更新をオフにしました。有料期間が終了するまでプレミアム機能へのアクセスは維持されます。                                                                                                                                                                                                         |
| subscription_renewal_reactivated   | ユーザーがサブスクリプションの自動更新を再有効化したときにトリガーされます。                                                                                                                                                                                                                                                                        |
| subscription_expired               | キャンセルされたサブスクリプションが完全に終了したときにトリガーされます。たとえば、ユーザーが12月12日にサブスクリプションをキャンセルしても12月31日までアクティブな場合、サブスクリプションが期限切れになる12月31日にイベントが記録されます。                                                                                                     |
| subscription_paused                | ユーザーが[サブスクリプションの一時停止](https://developer.android.com/google/play/billing/lifecycle/subscriptions#pause)を有効にしたときに発生します（Android のみ）。                                                                                                                                                                                                                     |
| subscription_deferred              | サブスクリプションの購入が[延期](https://adapty.io/glossary/subscription-purchase-deferral/)されたときにトリガーされます。プレミアム機能へのアクセスを維持しながら支払いを先送りできる機能で、Google Play Developer API を通じて利用可能です。無料トライアルや、経済的な事情を抱えるユーザーへの対応に活用できます。 |
| non_subscription_purchase          | 永続アクセスやゲーム内コインなどの消耗型アイテムといった、サブスクリプション以外の買い切り購入。                                                                                                                                                                                                                                                   |
| trial_started                      | ユーザーがトライアルサブスクリプションを有効にしたときにトリガーされます。                                                                                                                                                                                                                                                                               |
| trial_active                       | `trial_started` イベントの後、トライアルがまだアクティブであることを確認します。トライアル開始からこの確認までの日数を設定する必要があります。トライアルがまだ続いていればイベントが届きます。その時点でトライアルが終了・移行していた場合、または自動更新をオフにしていた場合は何も届かず、Adapty は再確認を行いません。 |
| trial_converted                    | トライアルが終了してユーザーへの請求が発生したとき（初回購入）に発生します。たとえば、1月14日までトライアルがあるユーザーが1月7日に請求された場合、このイベントは1月7日に記録されます。                                                                                                                                                        |
| trial_renewal_cancelled            | トライアル期間中にユーザーがサブスクリプションの自動更新をオフにしました。トライアルが終了するまでプレミアム機能へのアクセスは維持されますが、請求が発生したりサブスクリプションが開始されることはありません。                                                                                                                                               |
| trial_renewal_reactivated          | トライアル期間中にユーザーがサブスクリプションの自動更新を再有効化したときに発生します。                                                                                                                                                                                                                                                                   |
| trial_expired                      | サブスクリプションへ移行せずにトライアルが終了したときにトリガーされます。                                                                                                                                                                                                                                                                                   |
| entered_grace_period               | 支払いの試みが失敗し、ユーザーがグレース期間に入ったとき（有効な場合）に発生します。この間、ユーザーはプレミアムアクセスを維持できます。                                                                                                                                                                                                             |
| billing_issue_detected             | 請求処理中に問題が発生したとき（例：カード残高不足）にトリガーされます。                                                                                                                                                                                                                                                                    |
| subscription_refunded              | サブスクリプションが払い戻されたとき（例：Apple サポートによる対応）にトリガーされます。                                                                                                                                                                                                                                                                 |
| non_subscription_purchase_refunded | サブスクリプション以外の購入が払い戻されたときにトリガーされます。                                                                                                                                                                                                                                                                             |
| access_level_updated               | ユーザーのアクセスレベルが更新されたときに発生します。                                                                                                                                                                                                                                                                                       |
