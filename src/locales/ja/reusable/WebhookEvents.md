
| イベント名 | 説明 |
|:-----------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| subscription_started               | トライアル期間なしで有料サブスクリプションを開始したとき（即時課金）にトリガーされます。 |
| subscription_active                | `subscription_started` イベントの後、サブスクリプションがまだアクティブであることを確認します。サブスクリプション開始からこのチェックまでの日数を設定する必要があります。サブスクリプションがまだアクティブな場合（グレース期間中を含む）にイベントが届きます。その時点でサブスクリプションが終了していた場合や、ユーザーが自動更新をオフにしていた場合は、イベントは届かず、Adapty は再チェックしません。このイベントはトライアルなしで購入したサブスクリプションにのみ続きます。トライアルからの切り替えは `trial_converted` を送信するため、このチェックは開始されません。 |
| subscription_renewed               | サブスクリプションが更新されてユーザーに課金されたときに発生します。トライアルあり・なしを問わず、2 回目以降の請求から発生します。 |
| subscription_renewal_cancelled     | ユーザーがサブスクリプションの自動更新をオフにしました。ユーザーは有料サブスクリプション期間が終了するまでプレミアム機能にアクセスできます。 |
| subscription_renewal_reactivated   | ユーザーがサブスクリプションの自動更新を再有効化したときにトリガーされます。 |
| subscription_expired               | キャンセル後、サブスクリプションが完全に終了したときにトリガーされます。たとえば、ユーザーが 12 月 12 日にサブスクリプションをキャンセルしても 12 月 31 日まで有効な場合、イベントは 12 月 31 日に記録されます。 |
| subscription_paused                | ユーザーが[サブスクリプションの一時停止](https://developer.android.com/google/play/billing/lifecycle/subscriptions#pause)を有効にしたときに発生します（Android のみ）。 |
| subscription_deferred              | 無償でユーザーのサブスクリプションを延長したときにトリガーされます。Google Play Developer API による[延期](https://adapty.io/glossary/subscription-purchase-deferral/)、または App Store Server API による[更新日の延長](https://developer.apple.com/documentation/appstoreserverapi/extend-a-subscription-renewal-date)が対象です。ユーザーは延長された更新日までプレミアム機能にアクセスできます。 |
| non_subscription_purchase          | 永続アクセスやゲーム内コインなどの消耗型アイテムといった、サブスクリプション以外のすべての購入。 |
| trial_started                      | ユーザーがトライアルサブスクリプションを開始したときにトリガーされます。 |
| trial_active                       | `trial_started` イベントの後、トライアルがまだアクティブであることを確認します。トライアル開始からこのチェックまでの日数を設定する必要があります。トライアルがまだ実行中の場合にイベントが届きます。その時点でトライアルが終了または切り替わっていた場合や、ユーザーが自動更新をオフにしていた場合は、イベントは届かず、Adapty は再チェックしません。 |
| trial_converted                    | トライアルが終了してユーザーに課金された（初回購入）ときに発生します。たとえば、ユーザーのトライアルが 1 月 14 日までだが 1 月 7 日に課金された場合、このイベントは 1 月 7 日に記録されます。 |
| trial_renewal_cancelled            | ユーザーがトライアル期間中にサブスクリプションの自動更新をオフにしました。ユーザーはトライアルが終了するまでプレミアム機能にアクセスできますが、課金やサブスクリプションへの移行は行われません。 |
| trial_renewal_reactivated          | ユーザーがトライアル期間中にサブスクリプションの自動更新を再有効化したときに発生します。 |
| trial_expired                      | サブスクリプションに切り替わらずにトライアルが終了したときにトリガーされます。 |
| entered_grace_period               | 支払いの試行が失敗し、ユーザーがグレース期間に入ったとき（有効な場合）に発生します。この間、ユーザーはプレミアムアクセスを維持します。 |
| billing_issue_detected             | 課金試行時に請求の問題が発生したとき（例：カード残高不足）にトリガーされます。 |
| subscription_refunded              | サブスクリプションが返金されたとき（例：Apple サポートによる対応）にトリガーされます。 |
| non_subscription_purchase_refunded | サブスクリプション以外の購入が返金されたときにトリガーされます。 |
| access_level_updated               | ユーザーのアクセスレベルが更新されたときに発生します。 |
