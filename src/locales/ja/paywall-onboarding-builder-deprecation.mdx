2026年10月1日をもって、Adaptyはレガシーのペイウォールビルダーとオンボーディングビルダーを廃止し、[フローBuilder](adapty-flow-builder)へ移行します。これまでに公開したコンテンツは引き続き機能し、ユーザーはペイウォールやオンボーディングを通常通り利用でき、データもそのまま保持されます。既存のペイウォールやオンボーディングの編集も引き続き可能です。廃止後は新規作成ができなくなり、レガシービルダーのサポートも終了します。

## 引き続き機能すること \{#what-keeps-working\}

非推奨化によってユーザーへの影響は一切なく、既存のペイウォールとオンボーディングは引き続き編集可能です。

- **公開済みのペイウォールとオンボーディング**: SDK は、現在割り当てられているプレースメントで引き続きアプリ内にレンダリングします。
- **編集**: 既存のペイウォールとオンボーディングはレガシービルダーで引き続き編集できます。
- **データ**: ペイウォール、オンボーディング、およびその指標はダッシュボードに残ります。削除されるものはありません。

## 2026年10月1日に終了すること \{#what-stops-on-october-1-2026\}

その日以降、レガシービルダーでは以下の機能が利用できなくなります：

- **新規ペイウォールおよびオンボーディングの作成不可**：レガシービルダーでの新規作成はできなくなります。新規作成は[フローBuilder](adapty-flow-builder)をご利用ください。
- **サポートの終了**：Adaptyはレガシービルダーの修正対応を終了します。

## フロービルダーへの移行 \{#move-to-flow-builder\}

[フロー](adapty-flow-builder)は、オンボーディング画面とペイウォールを1つの体験にまとめたものです。1つのエディターで構築し、1つのプレースメントから配信できます。フローの構築、デバイスでのプレビュー、フロープレースメントの作成、アプリの Adapty SDK v4 へのアップデートまでの全工程については、[フローへの移行](migrate-to-flows)を参照してください。

:::note
既存のペイウォールをフローにワンクリックで変換する移行機能は近日公開予定です。
:::

フローは Adapty SDK v4 以降でレンダリングされるため、ユーザーがフローを見るのは、v4 を組み込んだバージョンに更新してからになります。最初のフローが完成したときにすでに v4 リリースが公開されているよう、今すぐ SDK のアップグレードを始めましょう。

ペイウォールが収益の大部分を占めていて、一度にすべてのトラフィックを切り替えたくない場合は、[フローを段階的にロールアウト](flow-gradual-rollout)しましょう。既存のペイウォールと並行して少数のユーザーに提供し、コンバージョンを比較しながら、結果が安定したら割合を引き上げていきます。
