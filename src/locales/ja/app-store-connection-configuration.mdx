iOS アプリを Adapty に接続するには、**App settings** > **iOS SDK** にアプリの App Store 認証情報を入力します。設定後、Adapty は次の処理を行います：

- 購入を検証する。
- サブスクリプションイベントを受信する。
- プロダクトを App Store Connect と同期し続ける。

購入やサブスクリプションのイベントが Adapty に届かなくなった場合は、[各認証情報を確認する](#check-each-credential)を参照してください。

<YouTube id="VJQbzoTCkqs" />

始める前に：

- App Store Connect のターゲットアプリへのアクセス権が必要です。まだアプリがない場合は、[App Store Connect のセットアップ](set-up-app-store-connect)を行ってください。プラットフォームへのアクセス権がない場合は、担当者にリクエストしてください。
- チームが App Store Connect API にアクセスできる必要があります。これは必要なアクセスキーを生成するために必要です。まだアクセスできない場合は、Account Holder に[リクエスト](https://developer.apple.com/help/app-store-connect/get-started/app-store-connect-api)するよう依頼してください。Apple は各リクエストを審査します。
- ブラウザのタブを2つ開いてください：一方に [App Store Connect](https://appstoreconnect.apple.com/apps) のアプリ画面、もう一方に Adapty の [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk) を開きます。このガイドを通じて、2つのタブ間で値をコピーします。

## 概要 \{#overview\}

このガイドで紹介するすべての認証情報は必須です。Adapty はそれぞれを [App Store とのデータ交換の異なる部分](store-sync#if-updates-stop-arriving)に使用します。設定を完了するには、以下の7つのステップに従ってください。

1. [バンドルIDとApple App ID](#enter-the-bundle-id-and-apple-app-id)を入力する
2. [アプリ固有の共有シークレット](#enter-the-app-specific-shared-secret)を入力する
3. AdaptyのURLを使用して[App Serverサーバー通知](#enable-app-store-server-notifications)を有効にする
4. [アプリ内購入キー](#add-the-in-app-purchase-key)を追加する
5. [App Store Connect APIキー](#add-the-app-store-connect-api-key)を追加する
6. [Adapty SDKをインストールしてサンドボックス購入を行う](#check-each-credential)
7. [すべての認証情報を確認する](#check-each-credential)

## Bundle ID と Apple App ID の入力 \{#enter-the-bundle-id-and-apple-app-id\}

App Store Connect でアプリを識別する値は、Bundle ID と Apple ID（Adapty では **Apple App ID** と表示）の2つです。Adapty は購入を処理するために Bundle ID を必要とします。Apple ID を使用することで、Adapty は以下のことが可能になります：

- App Store Connect でプロダクトを検索し、[そこで新規プロダクトを作成します](create-product#create-product-and-push-to-store)。
- プロダクトの App Store ステータスと価格を表示します。
- [リテンションメッセージング](retention-messaging-setup) のリアルタイムメッセージを配信します。
- [AI 成長アドバイザー](autopilot) の分析を実行します。
- AppsFlyer などのアトリビューション連携にアプリを識別させます。

Apple ID は App Store Connect にアプリを追加したときに Apple が割り当てるため、アプリが App Store に公開される前でも入力してください。

## アプリ固有の共有シークレットを入力する \{#enter-the-app-specific-shared-secret\}

Adaptyが購入レシートを検証し、App Store Connectでプロダクトを作成するには、アプリ固有の共有シークレットが必要です。

1. [App Store Connect](https://appstoreconnect.apple.com/apps)で、アプリの **App Information** ページを開きます。**App-Specific Shared Secret** セクションで、**Manage** をクリックします。

   <ZoomImage id="asc-app-information-shared-secret.webp" width="700px" alt="App Store ConnectのApp InformationページにあるApp-Specific Shared Secretセクション" />

2. シークレットをコピーします。アプリにまだシークレットがない場合は、先に **Generate** をクリックしてください。シークレットを生成するには、App Store Connect の Account Holder または Admin ロールが必要です。どちらのロールも持っていない場合は、該当するロールを持つ人にシークレットの生成と共有を依頼してください。

   [アプリ転送](transfer-apps#app-store-ios-transfer)でアプリを受け取った場合を除き、**Regenerate** はクリックしないでください。クリックすると、現在のシークレットが使用されているすべての場所で機能しなくなります。

   <ZoomImage id="asc-shared-secret-dialog.webp" width="700px" alt="App-Specific Shared Secret window with the secret" />

3. Adapty で、シークレットを **App Store Connect shared secret** フィールドに貼り付けます。

   <ZoomImage id="app-settings-shared-secret.webp" width="700px" alt="App Store Connect shared secret field in Adapty" />

4. **Save** をクリックします。

## AdaptyのURLを使ってApp Storeサーバー通知を有効にする \{#enable-app-store-server-notifications\}

:::link
メイン記事：[App Storeサーバー通知を有効にする](enable-app-store-server-notifications)
:::

Appleはサブスクリプションの更新、返金、その他のイベントが発生すると、サーバー通知をAdaptyに送信します。アプリがトランザクションを報告しない場合でも、Adaptyはこれらのイベントを記録します。

もし Apple がすでにこれらの通知を別のサーバーに送信している場合は、App Store Connect でその URL を置き換える前に、そのサーバーへの転送を設定してください。Adapty の **URL for forwarding raw Apple events** フィールドに転送先サーバーの URL を入力し、**Save** をクリックしてください。その後、Adapty は [Apple から受け取った通知をそのサーバーに転送します](enable-app-store-server-notifications#raw-events-forwarding)。

バックエンドが App Store Connect に自身の URL を維持する必要がある場合は、代わりに[バックエンドから Adapty に通知を渡してください](forwarding-events-to-adapty)。

## App Store Connect APIキーを追加する \{#add-the-app-store-connect-api-key\}

:::link
メイン記事：[App Store Connect APIキーをAdaptyに追加する](app-store-connect-api-key)
:::

AdaptyはApp Store Connect APIキーを使って、[App Store Connectでプロダクトを作成](create-product#create-product-and-push-to-store)したり、ステータスや価格を同期したりします。これはIn-App Purchase keyとは別のキーですが、**Issuer ID**と**Key ID**というフィールド名は共通です。

Adapty には **Admin** アクセス権限を持つチームキーが必要です。まだお持ちでない場合は、先に [App Store Connect でチームキーを生成してください](app-store-connect-api-key#generate-a-team-key-in-app-store-connect)。Adapty でキーを連携するには：

## 各認証情報が機能しているかを確認する \{#check-each-credential\}

Adapty が購入を検証していることを確認するには、アプリに [Adapty SDK をインストール](installation-of-adapty-sdks)し、[サンドボックス購入を実行](test-purchases-in-sandbox)してください。

サンドボックス購入では、一部の認証情報のみが使用されます。購入後に各認証情報を確認し、購入やサブスクリプションイベントが Adapty に届かなくなった際にも再度確認してください：

- **Bundle ID**、**Apple App ID**、**App Store Connect shared secret**: この3つの値を、App Store Connectの **App Information** ページにある **Bundle ID**、**Apple ID**、および **App-Specific Shared Secret** のシークレットと照合してください。
- **App Store server notifications**: このセクションのステータスは、購入または更新に関する通知がAdaptyに届くと **Active** と表示されます。それ以外の表示になっている場合は、[サーバーURLを確認](enable-app-store-server-notifications#check-that-notifications-reach-adapty)してください。
- **In-app purchase API (StoreKit 2)**: 保存時にAdaptyがAppleでキーを検証します。その後、アプリ内での購入でアクセスが解除されない場合、キーが機能しなくなっている可能性があります。[キーを置き換えて](generate-in-app-purchase-key#replace-the-key)ください。
- **App Store promotional offers**: **Subscription key ID** が **In-app purchase API (StoreKit 2)** セクションの **Key ID** と一致していることを確認してください。異なる場合は、[両方のセクションに同じキーを入力](generate-in-app-purchase-key#add-the-key-to-adapty)してください。
- **App Store Connect API key**: 各App StoreプロダクトのステータスはAdaptyの **Products** ページの **App Store status** 列に表示されます。プロダクトにダッシュまたは **Not Connected** が表示されている場合は、[キーとApple App IDを確認](troubleshoot-app-store-integration#products-dont-appear-or-show-no-app-store-status)してください。

セットアップ直後は、Analytics でトライアルや購入がインストール数より多くカウントされたり、イベントフィードに表示される数より多くなることがあります。この差は[プロファイルのないトランザクション](how-profiles-work#transactions-without-profiles)によるものです。これは、Adapty SDK を含むバージョンのアプリをまだ開いていないユーザーの購入です。

Adapty とストアのレポートにおけるその他の差異は、認証情報の問題ではなく、[それぞれの購入カウント方法](discrepancies-and-troubleshooting)の違いによるものです。
