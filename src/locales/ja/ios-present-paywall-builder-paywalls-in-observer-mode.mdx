title: "iOS SDKのオブザーバーモードでフローを表示する"
description: "オブザーバーモードで、独自のコードで購入を処理しながら、iOSアプリにフローを表示します。"
metadataTitle: "オブザーバーモードでのフローの表示 | Adapty ドキュメント"
---

[オブザーバーモード](observer-vs-full-mode)を使用する場合、購入ロジックはご自身で実装する必要があります。ただし、ペイウォールのUIは[フロー＆ペイウォールビルダー](adapty-flow-builder)に委任できます。

ビルダーで画面をデザインすれば、Adapty SDK がそれをネイティブにレンダリングします。コピー、レイアウト、価格はアプリをリリースせずにいつでも更新できます。ユーザーが購入ボタンをタップすると、SDK があなたのコードを呼び出して購入を完了します。

このガイドでは、その画面を表示して購入コールを処理する方法を説明します。Adapty が購入を代わりに完了する場合は、[フローとペイウォールの表示](ios-present-paywalls)を参照してください。

<SDKv4>

## 始める前に \{#before-you-start\}

以下が必要です：

- **Adapty iOS SDK v4以降**: 旧バージョンではフローをレンダリングできません。既存アプリをv3から移行する場合は、[移行ガイド](migration-to-ios-sdk-v4)を参照してください。
- **`observerMode` を `true` に設定**: [iOS SDKインストールガイド](sdk-installation-ios#activate-adapty-module-of-adapty-sdk)を参照してください。
- **ストアの初期設定**: [App Storeとの連携](initial_ios)でAdaptyをセットアップしてください。
- **プロダクトが設定された公開済みフロー**: [フロー＆ペイウォールビルダー](adapty-flow-builder)で作成し、[プロダクト](create-product)を割り当ててください。
- **フローのプレースメント**: [プレースメントを作成](create-placement)し、フローを割り当ててください。
- **アプリ内でフローを取得済み**: 表示する前に[フローとその設定を取得](get-pb-paywalls)してください。

1. `AdaptyObserverModeResolver` オブジェクトを実装します。

   ```swift showLineNumbers title="Swift"
   func observerMode(didInitiatePurchase product: AdaptyPaywallProduct,
                     onStartPurchase: @MainActor @Sendable @escaping () -> Void,
                     onFinishPurchase: @MainActor @Sendable @escaping () -> Void) {
          // use the product object to handle the purchase
          // call onStartPurchase / onFinishPurchase to notify AdaptyUI about the purchase progress
   }

   func observerModeDidInitiateRestorePurchases(onStartRestore: @MainActor @Sendable @escaping () -> Void,
                                                onFinishRestore: @MainActor @Sendable @escaping () -> Void) {
          // call onStartRestore / onFinishRestore to notify AdaptyUI about the restore progress
   }
   ```

2. リゾルバーを `observerModeResolver:` パラメーターとして渡し、フロー設定オブジェクトを作成します：

   ```swift showLineNumbers title="Swift"
   do {
       let flowConfiguration = try await AdaptyUI.getFlowConfiguration(
           forFlow: flow,
           observerModeResolver: <AdaptyObserverModeResolver>
       )
   } catch {
       // handle the error
   }
   ```

   リクエストパラメーター：

| パラメータ                | 必須 | 説明                                                                                                              |
   | :----------------------- | :------- | :----------------------------------------------------------------------------------------------------------------------- |
   | **forFlow**              | 必須 | `Adapty.getFlow(placementId:)` で取得した `AdaptyFlow` オブジェクト。[フローとペイウォールの取得](get-pb-paywalls)を参照。 |
   | **observerModeResolver** | 必須 | 上記で実装した `AdaptyObserverModeResolver`。                                                                  |

3. `AdaptyUI.flowController(with:delegate:)` を使用してフローコントローラーを初期化します：

   ```swift showLineNumbers title="Swift"
   import AdaptyUI

   let visualFlow = try AdaptyUI.flowController(
       with: flowConfiguration,
       delegate: <AdaptyFlowControllerDelegate>
   )
   ```

   リクエストパラメーター：

| パラメーター | 必須/任意 | 説明 |
   | :------------------------- | :------- | :----------------------------------------------------------------------------------------------------------------------------------------------- |
   | **flowConfiguration**      | 必須 | フローの視覚的な詳細を含む `AdaptyUI.FlowConfiguration` オブジェクト。[フローとペイウォールの取得](get-pb-paywalls)を参照してください。 |
   | **delegate**               | 必須 | フローイベントを受け取るための `AdaptyFlowControllerDelegate`。[フロー & ペイウォールイベントの処理](ios-handling-events)を参照してください。 |

Returns:

   | Object               | Description                                            |
   | :------------------- | :----------------------------------------------------- |
   | AdaptyFlowController | リクエストされたフローの画面を表すオブジェクト。      |

4. コントローラーを表示する:

   ```swift showLineNumbers title="Swift"
   present(visualFlow, animated: true)
   ```

:::warning
[購入トランザクションへのペイウォールの関連付け](report-transactions-observer-mode)を忘れずに行ってください。これを行わないと、Adapty は購入元のペイウォールを特定できません。
:::

SwiftUI では、リゾルバーを使ってフロー設定を取得し、`.flow` モディファイアに渡します：

```swift showLineNumbers title="SwiftUI"
@State var flowPresented = false
@State var flowConfiguration: AdaptyUI.FlowConfiguration?

var body: some View {
    Text("Hello, AdaptyUI!")
        .flow(
            isPresented: $flowPresented,
            flowConfiguration: flowConfiguration,
            didPerformAction: { action in
                switch action {
                    case .close:
                        flowPresented = false
                    default:
                        break
                }
            },
            didFinishPurchase: { product, purchaseResult in /* dismiss, or do nothing to let the flow continue */ },
            didFailPurchase: { product, error in /* handle the error */ },
            didFinishRestore: { profile in /* check access level and dismiss */ },
            didFailRestore: { error in /* handle the error */ },
            didReceiveError: { error in flowPresented = false }
        )
        .task {
            flowConfiguration = try? await AdaptyUI.getFlowConfiguration(
                forFlow: flow,
                observerModeResolver: <AdaptyObserverModeResolver>
            )
        }
}
```

`getFlowConfiguration` の `observerModeResolver:` パラメーターは、レンダリングされたフローにカスタム購入ロジックを適用するためのものです。このモディファイアは、フルモードと同じコールバックを使用します。

:::warning
[購入トランザクションとペイウォールを紐付ける](report-transactions-observer-mode)ことを忘れないでください。紐付けを行わないと、Adapty は購入元のペイウォールを特定できません。
:::

1. `AdaptyObserverModeResolver` オブジェクトを実装します:

   ```swift showLineNumbers title="Swift"
   func observerMode(didInitiatePurchase product: AdaptyPaywallProduct,
                     onStartPurchase: @MainActor @Sendable @escaping () -> Void,
                     onFinishPurchase: @MainActor @Sendable @escaping () -> Void) {
          // use the product object to handle the purchase
          // use the onStartPurchase and onFinishPurchase callbacks to notify AdaptyUI about the process of the purchase
   }

   func observerModeDidInitiateRestorePurchases(onStartRestore: @MainActor @Sendable @escaping () -> Void,
                                                onFinishRestore: @MainActor @Sendable @escaping () -> Void) {
          // use the onStartRestore and onFinishRestore callbacks to notify AdaptyUI about the process of the restore
   }
   ```

`observerMode(didInitiatePurchase:onStartPurchase:onFinishPurchase:)` イベントは、ユーザーが購入を開始したことを通知します。このコールバックに応答して、カスタム購入フローをトリガーできます。

`observerModeDidInitiateRestorePurchases(onStartRestore:onFinishRestore:)` イベントは、ユーザーが復元を開始したことを通知します。このコールバックに応答して、カスタム復元フローをトリガーできます。

また、購入またはリストアのプロセスについて AdaptyUI に通知するために、以下のコールバックを呼び出すことを忘れないでください。これは、ローダーの表示など、ペイウォールの適切な動作に必要です。

| コールバック | 説明 |
   | :----------------- | :------------------------------------------------------------------------------- |
   | onStartPurchase()  | 購入が開始されたことを AdaptyUI に通知するために呼び出すコールバックです。  |
   | onFinishPurchase() | 購入が完了したことを AdaptyUI に通知するために呼び出すコールバックです。 |
   | onStartRestore()   | リストアが開始されたことを AdaptyUI に通知するために呼び出すコールバックです。   |
   | onFinishRestore()  | リストアが完了したことを AdaptyUI に通知するために呼び出すコールバックです。  |

2. ペイウォール設定オブジェクトを作成します：

   ```swift showLineNumbers title="Swift"
   do {
       let paywallConfiguration = try AdaptyUI.getPaywallConfiguration(
        forPaywall: <paywall object>, 
        observerModeResolver: <AdaptyObserverModeResolver>
        )
   } catch {
       // handle the error
   }
   ```

   リクエストパラメータ：

| パラメータ | 必須/任意 | 説明 |
   | :----------------------- | :------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
   | **Paywall**              | 必須 | 目的のペイウォールのコントローラーを取得するための `AdaptyPaywall` オブジェクト。                                                                                                                                                                                                                                             |
   | **ObserverModeResolver** | 必須 | 前のステップで実装した `AdaptyObserverModeResolver` オブジェクト。                                                                                                                                                                                                                                                      |

3. `.paywallController(for:products:viewConfiguration:delegate:)` メソッドを使用して、表示したいビジュアルペイウォールを初期化します：

   ```swift showLineNumbers title="Swift"
   import AdaptyUI
   
   let visualPaywall = AdaptyUI.paywallController(
       with: <paywall configuration object>,
       delegate: <AdaptyPaywallControllerDelegate>
   )
   ```

リクエストパラメーター：

| パラメータ                | 必須/任意 | 説明                                                                                                                                                                                                                                                                                                           |
| :----------------------- | :------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Paywall Configuration**              | 必須 | ペイウォールの視覚的な詳細を含む `AdaptyUI.PaywallConfiguration` オブジェクト。`AdaptyUI.getPaywallConfiguration(forPaywall:locale:)` メソッドを使用してください。詳細は [ペイウォールビルダーのペイウォールとその設定を取得する](get-pb-paywalls) をご参照ください。                                                                                                                                                                                                                                                             |
| **Delegate**             | 必須 | ペイウォールイベントを受け取るための `AdaptyPaywallControllerDelegate`。詳細は [ペイウォールイベントの処理](ios-handling-events) をご参照ください。                                                                                                                                                                 |

戻り値:

| オブジェクト            | 説明                                   |
| :---------------------- | :------------------------------------- |
| AdaptyPaywallController | リクエストされたペイウォール画面を表すオブジェクト |

オブジェクトが正常に作成されたら、次のように表示できます:

```swift showLineNumbers title="Swift"
present(visualPaywall, animated: true)
```

:::warning
[ペイウォールを購入トランザクションに関連付ける](report-transactions-observer-mode)ことを忘れないでください。関連付けを行わないと、Adaptyは購入元のペイウォールを特定できません。
:::

| **Configuration** | 必須 | ペイウォールの視覚的な詳細を含む `AdaptyUI.LocalizedViewConfiguration` オブジェクト。`AdaptyUI.getViewConfiguration(paywall:locale:)` メソッドを使用してください。詳細は [ペイウォールビルダーのペイウォールとその設定の取得](get-pb-paywalls) を参照してください。                                             |
| **TagResolver**   | 任意 | カスタムタグとその解決済みの値の辞書を定義します。カスタムタグはペイウォールコンテンツのプレースホルダーとして機能し、ペイウォール内のパーソナライズされたコンテンツとして特定の文字列に動的に置き換えられます。詳細はペイウォールビルダーのカスタムタグのトピックを参照してください。 |

Closure parameters:

| クロージャパラメータ                   | 説明                                                                       |
| :---------------------------------- | :-------------------------------------------------------------------------------- |
| **didFinishRestore**                | Adapty.restorePurchases() が成功した場合、このコールバックが呼び出されます。             |
| **didFailRestore**                  | Adapty.restorePurchases() が失敗した場合、このコールバックが呼び出されます。                |
| **didFailRendering**                | インターフェースのレンダリング中にエラーが発生した場合、このコールバックが呼び出されます。 |
| **observerModeDidInitiatePurchase** | ユーザーが購入を開始したときにこのコールバックが呼び出されます。                        |

その他のクロージャパラメータについては、[iOS - イベントのハンドリング](ios-handling-events) のトピックを参照してください。
