リテンションメッセージングは、iOSのサブスクリプションキャンセル画面で、キャンセルを確定する前にサブスクライバーへカスタムメッセージを表示します。解約しようとしているサブスクライバーを引き留めるために活用できます。

*デフォルト*メッセージはすべてのサブスクライバーに継続する理由を伝えます。*プロモ*メッセージはさらに具体的なインセンティブを加えます：割引、無料トライアル、またはより適したプランへの乗り換え機会です。Apple は各サブスクライバーに、そのプロダクトと言語に合ったメッセージを表示します。

メッセージの作成、ローカライズ、テストは Adapty ダッシュボードで行います。Adapty はアプリのリリースなしに自動的に Apple へ配信します。

## クイックスタート \{#quickstart\}

開始する前に、以下が必要です：

- [Apple の Retention Messaging プログラム](https://developer.apple.com/documentation/retentionmessaging)へのアクセス。
- Adapty に設定済みの [App Store Connect API キー](app-store-connection-configuration)。

次に：

1. [サンドボックスモードで Adapty をリテンションメッセージング API に接続する](retention-messaging-setup)。
2. サンドボックスモードでいずれかのプロダクトを購入して、接続テストに使用するトランザクションを用意する。
3. Apple の接続テストに合格する。
4. プロダクションモードに切り替える。
5. [プロダクション用のメッセージを作成する](retention-messaging-create) — まずデフォルトメッセージ、次にプロモメッセージの順に作成し、それぞれ Apple のレビューに提出する。
