[Retention Messaging](https://developer.apple.com/documentation/retentionmessaging) は、iOS の **Cancel Subscription** 画面でサブスクリプションをキャンセルする直前に、カスタムメッセージを表示する Apple の機能です。理由やオファーを提示することでサブスクリプションの解約を抑止できます。

Adapty は Apple の Retention Messaging API に接続しているため、サブスクライバーが **Cancel Subscription** をタップするたびに、Apple がリアルタイムで適切なメッセージをリクエストします。Adapty がそのエンドポイントを代わりに処理します。Adapty ダッシュボードでメッセージの作成、ローカライズ、テストを行うだけで、Adapty が Apple に自動で応答します。バックエンドの構築もアプリのリリースも不要です。

メッセージには2種類あります。*デフォルト*メッセージはプレーンなテキストで、プロモメッセージを表示できない場合のフォールバックとして機能します。*プロモ*メッセージはその上に具体的なインセンティブを追加します。割引、無料トライアル、またはより適切なプランへの切り替えなどです。Appleは各サブスクライバーに、プロダクトと言語に合ったメッセージを表示します。

## クイックスタート \{#quickstart\}

始める前に、以下が必要です：

- Adapty に設定済みの [App Store Connect API キー](app-store-connection-configuration)
- [Apple によるアプリの承認](retention-messaging-setup#request-access-from-apple)。Apple の審査には最大1か月かかるため、早めにリクエストを送ってください。
- メッセージの対象となる[プロダクト](create-product)が少なくとも1つ。

準備ができたら：

1. [サンドボックスモードで Adapty を Retention Messaging API に接続する](retention-messaging-setup)。
2. サンドボックスアカウントまたは TestFlight を使って、最長期間のプロダクトを購入し、サブスクリプションをアクティブな状態に保つ。
3. [Apple のパフォーマンステストをパスする](retention-messaging-setup#pass-the-performance-test)。最大1時間かかる場合がある。
4. 本番モードに切り替える。
5. [本番メッセージを作成する](retention-messaging-create) — まずデフォルトメッセージ、次にプロモメッセージの順で作成し、それぞれ Apple のレビューに提出する。
6. Apple の承認後、[各メッセージのパフォーマンスをトラッキングする](retention-messaging-analytics)。
