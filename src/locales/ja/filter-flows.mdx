[**Flows**](https://app.adapty.io/flows) ページには、アプリ内のすべてのフローとその[ステータス](#filter-by-status)および主要な[指標](flow-metrics)が一覧表示されます。フローをクリックすると詳細な[指標](flow-metrics)が開きます。**Developer** ロールを持っている場合は、[フロービルダー](adapty-flow-builder)が開きます。

<ZoomImage id="flow-list.webp" width="700px" alt="検索ボックス、All states フィルター、並べ替え可能な Flow name 列と Status 列、およびオープン状態のコンテキストメニューを備えた Flows ページ" />

## 名前で検索 \{#search-by-name\}

**フロー名で検索**は、フロー名の一部に一致します。プレースメント、プロダクト、スクリーンのコンテンツは検索されません。

## ステータスでフィルタリングする \{#filter-by-status\}

リスト上部の **All states** フィルターを開き、1つまたは複数のステータスを選択して **Apply** をクリックします。各ステータスの意味とフローの遷移については、[フローの保存と公開](builder-save-publish#flow-status)を参照してください。

<ZoomImage id="flows-filter-by-state.webp" width="300px" alt="All states filter open, with a checkbox for each flow status and an Apply button" />

## プレースメントで絞り込む \{#filter-by-placement\}

リスト上部の **All placements** フィルターを開き、1つ以上の[プレースメント](placements)を選択して **Apply** をクリックします。このフィルターは、少なくとも1つのフローがプレースメントに割り当てられている場合に表示されます。

<ZoomImage id="flows-filter-by-placement.webp" width="300px" alt="All placements filter open, listing two placements with checkboxes and an Apply button" />

## 並べ替え \{#sort\}

**Flow name** または **Status** で並べ替えることができます。指標の列は並べ替えできません。デフォルトでは、公開済みのフローが先頭に、アーカイブ済みのフローが末尾に表示されます。

## フローアクション \{#flow-actions\}

フローの行にあるコンテキストメニュー <Inline id="context.svg" alt="Context menu" /> を開きます。

| アクション | 内容 |
| :----- | :----------- |
| **Metrics** | フローの[指標](flow-metrics)を開きます。 |
| **Edit** | [フロービルダー](adapty-flow-builder)でフローを開きます。 |
| **Copy** | フローを新しいドラフトとして[コピー](copy-flows)します。 |
| **Archive** | フローを[アーカイブ](archive-flows)します。 |

アーカイブ済みフローのメニューには **Metrics** のみ表示されます。
