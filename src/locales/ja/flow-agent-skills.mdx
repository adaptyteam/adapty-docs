エージェントスキルを使うと、ビジュアルエディターではなく [Adapty CLI](developer-cli-quickstart) や [Adapty MCPサーバー](adapty-mcp) を通じて、自分のAIツールでフローを操作できます。やりたいことを普通の言葉で伝えるだけで、ツールがアカウントを読み取り、作業を実行し、保存前に結果を確認させてくれます。

4つのスキルが役割を分担しています。フローの作成と変更を担当するもの、フローを公開しても安全かを確認するもの、ストアが承認するかをチェックするもの、そしてペイウォールを使用しているアプリをフローのプレースメントへ移行するものです。4つすべてが [Adapty プラグイン](manage-adapty-with-ai) に同梱されているため、1回インストールするだけですべてを利用できます。

変更内容が明確な場合は **flow-generator** を使用してください。新しいロケールの追加、テキストの書き直し、画面の追加・削除、分岐の変更などに対応しています。設定を編集してドラフトとして保存し、あなたの承認を待ちます。公開は行いません。

フローが完成しているか確認したいときは **flow-audit** を使ってください。フローとプロダクトカタログを読み取り、実際のユーザーに何が問題となるかをレポートし、修正内容を flow-generator に渡します。

App Store や Google Play のレビューに提出する前には **[paywall-compliance](paywall-compliance-skill)** を使ってください。フロー、スクリーンショット、またはアプリのコードをストアのルールやサブスクリプションに関する消費者法と照合し、開発者から最近報告されたリジェクト事例も追加します。

アプリがまだペイウォールで動作している場合は **migrate-placements** を使用してください。フローのコンテンツには触れず、ペイウォールのプレースメントを読み取って各プレースメントに対応するフロープレースメントを作成し、プレースメント ID と変更用の SDK 呼び出しを返します。

これらのスキルはいずれも [AI エディター](flow-ai-editor) の代わりにはなりません。AI エディターはフロー＆ペイウォールビルダー内で動作します。エージェントスキルはあなた自身の AI ツール（コーディングエージェント、アプリコードと同じセッション、または claude.ai）で実行されます。
