エージェントスキルを使うと、ビジュアルエディターではなく [Adapty CLI](developer-cli-quickstart) や [Adapty MCPサーバー](adapty-mcp) を通じて、自分のAIツールでフローを操作できます。やりたいことを普通の言葉で伝えるだけで、ツールがアカウントを読み取り、作業を実行し、保存前に結果を確認させてくれます。

Adaptyプラグインには3つのスキルが含まれており、それぞれ役割が分担されています。ひとつはフローの作成・変更、ひとつはフローが公開可能な状態かをチェック、もうひとつはペイウォールで動いているアプリをフローのプレースメントに移行する作業を担います。3つともすべて[Adaptyプラグイン](manage-adapty-with-ai)に同梱されているため、一度インストールするだけで利用できます。

<CustomDocCardList />

ロケールの追加、テキストの書き換え、画面の追加・削除、分岐の変更など、変更内容が明確な場合は **flow-generator** を使ってください。コンフィグを編集してドラフトとして保存するため、承認前に内容を確認できます。公開は行いません。

**flow-audit** は、フローが完成しているかどうかを確認したいときに使用します。フローとプロダクトカタログを読み込み、実際のユーザーに問題が発生する箇所を報告して、修正内容を flow-generator に引き渡します。

**migrate-placements** は、アプリがまだペイウォールで動作している場合に使用します。フローのコンテンツには手を加えず、ペイウォールのプレースメントを読み込んで各プレースメントに対応するフロープレースメントを作成し、プレースメント ID と変更に必要な SDK 呼び出しを渡します。

これらのいずれも、Flow & ペイウォールビルダー内で動作する[AI エディター](flow-ai-editor)の代わりにはなりません。エージェントスキルは、あなた自身の AI ツール（コーディングエージェント、アプリコードと同じセッション、または claude.ai）で動作します。
