[Observerモード](observer-vs-full-mode)を使用する場合、購入ロジックはご自身で管理する必要があります。ただし、ペイウォールのUIは[フロー＆ペイウォールビルダー](adapty-flow-builder)に委任できます。

フローはビルダーでデザインし、Adapty SDK がネイティブにレンダリングします。コピー、レイアウト、価格はいつでも更新でき、アプリのリリースは不要です。

このガイドでは、フローを表示して购入コールバックを処理する方法を説明します。Adapty が購入を代わりに処理する場合は、[フローとペイウォールの表示](capacitor-present-paywalls)を参照してください。

## 始める前に \{#before-you-start\}

準備するもの：

- **Adapty Capacitor SDK 4.1以降**: それより古いバージョンではフローをレンダリングできません。既存のアプリを移行する場合は、[移行ガイド](migration-to-capacitor-sdk-v4)をご覧ください。
- **`observerMode`を`true`に設定**: [Capacitor SDKインストールガイド](sdk-installation-capacitor#activate-adapty-module-of-adapty-sdk)をご覧ください。
- **ストアの初期連携**: [App Store](initial_ios)および[Google Play](initial-android)でAdaptyをセットアップしてください。
- **プロダクトを含む公開済みフロー**: [フロー＆ペイウォールビルダー](adapty-flow-builder)で作成し、[プロダクト](create-product)を割り当ててください。
- **フローのプレースメント**: [プレースメントを作成](create-placement)し、フローを割り当ててください。
- **アプリでのフローの取得**: フローを表示する前に、[フローとその設定を取得](capacitor-get-pb-paywalls)してください。

## 実装 \{#implementation\}

Observer モードでは、SDK は購入処理を代行しません。Adapty がレンダリングするフロー内で購入ボタンまたは復元ボタンをユーザーがタップすると、SDK は購入処理や復元処理を行う代わりに、`onObserverPurchaseInitiated` または `onObserverRestoreInitiated` のイベントハンドラーを呼び出します。そのハンドラー内で、独自のコードを使って購入または復元を実行してください。

1. ビューにオブザーバーモードのイベントハンドラーを設定します。他のプラットフォームとは異なり、独立したリゾルバーオブジェクトはなく、ハンドラーは通常の[イベントハンドラー](capacitor-handling-events)の一部です。そのため、作成するすべてのビューに設定してください。

   ```typescript showLineNumbers title="Capacitor"
   import { adapty, createFlowView } from '@adapty/capacitor';

   const view = await createFlowView(flow);

   const unsubscribe = await view.setEventHandlers({
     onObserverPurchaseInitiated(product, onStartPurchase, onFinishPurchase) {
       onStartPurchase(); // the view shows its loading indicator
       myPurchaseApi(product.vendorProductId)
         .then((transactionId) =>
           adapty.reportTransaction({ transactionId, variationId: flow.variationId }),
         )
         .finally(() => onFinishPurchase()); // the view hides the loading indicator
       return false; // keep the flow open; dismiss it yourself after success
     },
     onObserverRestoreInitiated(onStartRestore, onFinishRestore) {
       onStartRestore();
       myRestoreApi().finally(() => onFinishRestore());
       return false;
     },
   });
   ```

`onObserverPurchaseInitiated` ハンドラーはユーザーが購入を開始したことを、`onObserverRestoreInitiated` はユーザーがリストアを開始したことを通知します。これらに応じて、カスタムの購入またはリストアフローをトリガーしてください。

また、購入またはリストアの処理について AdaptyUI に通知するために、以下のコールバックを必ず呼び出してください。これは、ローダーの表示など、適切なフロー動作に必要です。

| コールバック | 説明 |
   | :----------------- | :------------------------------------------------------------------------------- |
   | onStartPurchase()  | 購入が開始されたことを AdaptyUI に通知するために呼び出すコールバックです。  |
   | onFinishPurchase() | 購入が完了したことを AdaptyUI に通知するために呼び出すコールバックです。 |
   | onStartRestore()   | 復元が開始されたことを AdaptyUI に通知するために呼び出すコールバックです。   |
   | onFinishRestore()  | 復元が完了したことを AdaptyUI に通知するために呼び出すコールバックです。  |

2. フローのビューを通常通り表示します：[フローを取得してビューを作成し](capacitor-get-pb-paywalls)、[表示します](capacitor-present-paywalls)。追加のパラメータは不要です — ハンドラーは SDK が `observerMode: true` で有効化された場合にのみ起動します。

:::warning
[トランザクションを報告してペイウォールに紐づける](report-transactions-observer-mode-capacitor)ことを忘れないでください。これを行わないと、Adapty はトランザクションを認識できず、購入元のペイウォールを特定できません。
:::
