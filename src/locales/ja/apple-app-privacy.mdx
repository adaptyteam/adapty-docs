Appleは、App Store Connectの **App Privacy** セクションおよびアプリのマニフェストファイルとして、すべての新しいアプリおよびアップデートに対してプライバシーの開示を義務付けています。AdaptyはアプリのサードパーティSDKであるため、ユーザーデータに関してAdaptyをどのように使用しているかを開示する必要があります。

## Apple アプリプライバシーマニフェスト \{#apple-app-privacy-manifest\}

`PrivacyInfo.xcprivacy` という名前の[プライバシーマニフェストファイル](https://developer.apple.com/documentation/bundleresources/describing-data-use-in-privacy-manifests)は、アプリが使用するプライベートデータとその理由を記述します。アプリオーナーはすべて、自分のアプリ用のマニフェストファイルを作成する必要があります。さらに、追加のSDKを統合している場合は、[プライバシーマニフェストと署名が必要なSDK](https://developer.apple.com/support/third-party-SDK-requirements/)リストに含まれるSDKのマニフェストファイルが含まれていることを確認してください。アプリをビルドする際、Xcodeはこれらすべてのマニフェストファイルを1つにまとめます。

AdaptyはAppleの[プライバシーマニフェストと署名が必要なSDKのリスト](https://developer.apple.com/support/third-party-SDK-requirements/)に含まれていませんが、バージョン2.10.2以降のAdapty SDKにはご利用の便宜のためにプライバシーマニフェストが含まれています。マニフェストを取得するには、SDKを最新バージョンに更新してください。

マニフェストはXcodeが生成するプライバシーレポートにのみ使用されます。App Reviewでは[App Store Connect](#apple-app-privacy-disclosure-in-app-store-connect)での回答内容が確認されるため、そちらのセクションを漏れなく記入してください。

AdaptyのcustomerUserIdでユーザーを識別している場合は、マニフェストファイルにユーザーIDを宣言してください：

1. プライバシー情報ファイルの `NSPrivacyCollectedDataTypes` 配列に辞書を追加します。
2. `NSPrivacyCollectedDataType`、`NSPrivacyCollectedDataTypeLinked`、`NSPrivacyCollectedDataTypeTracking` キーをその辞書に追加します。
3. `NSPrivacyCollectedDataTypes` 辞書内の `NSPrivacyCollectedDataType` キーの値として、文字列 `NSPrivacyCollectedDataTypeUserID`（[マニフェストファイルで報告すべきデータカテゴリとタイプの一覧](https://developer.apple.com/documentation/bundleresources/describing-data-use-in-privacy-manifests#Describe-the-data-your-app-or-third-party-SDK-collects)における `UserID` データタイプの識別子）を追加します。
4. `NSPrivacyCollectedDataTypeLinked` キーに `true` を追加します。[Apple が定義するトラッキング](https://developer.apple.com/app-store/user-privacy-and-data-use/)にユーザー ID を使用している場合を除き、`NSPrivacyCollectedDataTypeTracking` キーには `false` を追加します。
5. `NSPrivacyCollectedDataTypes` 辞書内の `NSPrivacyCollectedDataTypePurposes` キーの値として、`NSPrivacyCollectedDataTypePurposeAppFunctionality` および `NSPrivacyCollectedDataTypePurposeAnalytics` 文字列を使用します。

カスタム属性を使用してオーディエンスにペイウォールをターゲティングしている場合は、使用しているカスタム属性が[マニフェストファイルで報告するデータカテゴリとタイプ](https://developer.apple.com/documentation/bundleresources/describing-data-use-in-privacy-manifests)に該当するかどうかを慎重に確認してください。該当する場合は、データタイプごとに上記の手順を繰り返してください。

収集するすべてのデータタイプとカテゴリを報告したら、[Appleのドキュメント](https://developer.apple.com/documentation/bundleresources/describing-data-use-in-privacy-manifests#Create-your-apps-privacy-report)に従ってアプリのプライバシーレポートを作成してください。

#### 識別子 \{#identifiers\}

Adaptyを使用する場合、以下の識別子を開示する必要があります：
- **Device ID** — AdaptyはインストールごとにデバイスIDを生成し、IDFVを収集します。また、[広告識別子の収集を無効化](analytics-integration#disable-collection-of-advertising-identifiers)しない限り、IDFAも収集します。インストールごとのデバイスIDはオフにできないため、すべての場合に**Device ID**を申告してください。
- **User ID** — **`customerUserId`**でユーザーを識別する場合に必要です。

#### 使用状況データ \{#usage-data\}

Adapty を使用する場合、アプリが **Product Interaction** を収集していることを開示する必要があります。Adapty はアプリの起動、ペイウォールおよびフローのイベントをユーザーのプロファイルに記録します。

**データタイプ**を保存した後、データの使用目的を示す必要があります：

1. **Purchases** ブロック内の **Set up purchase history** をクリックします。

        <img src="/assets/shared/img/purchase-privacy.webp"
        style={{
        border: 'none', /* border width and color */
        width: '700px', /* image width */
        display: 'block', /* for alignment */
        margin: '0 auto' /* center alignment */
    }}
        />
    </Zoom>

2. Appleが購入履歴データの使用目的を尋ねてきたら、Adapty向けに以下を選択してください：
    - **Analytics** — Adaptyは収益アナリティクス、コホート、指標のために購入履歴を使用します。
    - **Product Personalization** — Adaptyはオーディエンスのセグメンテーションとペイウォールのターゲティングのために購入データを使用します。これはオーディエンスによってプレースメントをターゲティングする場合にのみ適用されますが、選択しておくのが安全なデフォルトです。
    - **App Functionality** — Adaptyは購入を検証し、アクセスレベルを管理し、サブスクリプションのステータスを追跡します。

    アプリが購入データを他の方法でも使用している場合（たとえば、Adapty インテグレーション経由で広告プラットフォームに購入イベントを送信している場合など）は、追加の目的を選択してください。

        margin: '0 auto' /* center alignment */

3. **次へ**をクリックします。
4. **Device ID** と **User ID**（使用している場合）の両方について：
    1. **User/Device ID** ブロック内の **Set up user/device ID** をクリックします。
    2. Apple から識別子データの使用目的を尋ねられたら、Adapty 向けに以下を選択します：
        - **App Functionality** — Adapty は識別子を使用してユーザープロファイルを管理し、購入を紐付け、アクセスレベルを追跡します。
        - **Analytics** — Adapty は識別子を使用してユーザー数をカウントし、アナリティクスでイベントをユーザーに紐付けます。

       サードパーティプラットフォームへのアトリビューションデータの送信に Adapty インテグレーション（AppsFlyer や Adjust など）を使用している場合は、**Third-Party Advertising** も選択してください。アプリが他の方法で識別子を使用している場合は、追加の目的も選択してください。

### リンクとトラッキング \{#linking-and-tracking\}

Apple はデータの種類ごとに、そのデータがユーザーの個人情報と紐付けられているか、またトラッキングに使用されているかを確認します。Adapty については、以下のように回答してください。

- **ユーザーへのリンク**: `customerUserId` を設定しない場合は **No**。デバイス ID はインストールごとにランダムに生成される識別子であり、個人を特定する情報は含まれません。`customerUserId` を設定した場合は、すべての Adapty データタイプに対して **Yes** と答えてください。ユーザー ID によってすべてのデータがユーザーに紐付けられます。
- **トラッキングへの使用**: **No**。Adapty は[Apple が定義するトラッキング](https://developer.apple.com/app-store/user-privacy-and-data-use/)にこのデータを使用しません。アプリがデータをトラッキングに使用する場合のみ **Yes** と答えてください。
