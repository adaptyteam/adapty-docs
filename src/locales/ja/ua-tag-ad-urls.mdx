広告がApp StoreやGoogle Playへ直接誘導するのではなく、ランディングページやウェブファネルを経由する場合は、広告URLにタグを付けてください。広告がApp StoreやGoogle Playへ直接誘導する場合は、代わりに[トラッキングリンク](ua-tracking-links)を遷移先として使用してください。リンク自体にキャンペーンデータが含まれるため、別途タグ付けは不要です。

Adapty Attribution は、ランディングページの URL からキャンペーン、広告セット、広告を読み取ります。広告ネットワークは自社のクリック ID（`fbclid` や `ttclid`）を自動的に付加しますが、これはネットワークを識別するだけで、キャンペーン、広告セット、広告は特定できません。購入を特定の広告まで正確にアトリビュートするには、トラッキングパラメーターを広告に追加してください。

手順は、自社ファネルで [Adapty ウェブピクセル](ua-web-pixel) を使う場合でも、[FunnelFox](ua-funnelfox) を使う場合でも同じです。

## はじめる前に \{#before-you-start\}

[Meta Ads](ua-facebook) または [TikTok for Business](ua-tiktok) を Adapty アトリビューションに接続し、キャンペーン設定を追加してください。Adapty はキャンペーン設定ごとに広告 URL パラメーターを生成するため、コピーするにはキャンペーン設定が必要です。

## 広告にタグを付ける \{#tag-your-ads\}

1. キャンペーン設定の **Web funnel** セクションで、**Ad URL parameters** フィールドの値をコピーします。

<ZoomImage id="ua-web-pixel-url-params.webp" width="700px" alt="Ad URL parameters field in the Web funnel section of a campaign configuration in Adapty Attribution" />

2. 広告ネットワークで、**広告**レベルにその値を貼り付けます：
   - **Meta**：広告の **URL parameters** フィールドに貼り付けます。
   - **TikTok**：広告の遷移先 URL の下にある **Build URL parameters** に貼り付けます。

このバリューにはネットワークマクロが含まれています。ネットワークはクリック時に、実際のキャンペーン、広告セット、広告の値に置き換えます。

ランディングページやファネルのURLは、広告の送信先フィールド（Metaでは **Website URL**、TikTokでは **Destination URL**）にパラメーターなしで入力してください。クリック時にネットワークがそのURLにパラメーターを付加するため、広告を再タグ付けすることなく後から送信先URLを変更できます。

パラメーターには `utm_*` の値が含まれていないため、独自の分析のために既存のUTMスキームをそのまま使用できます。Adaptyはそれを必要としません。
