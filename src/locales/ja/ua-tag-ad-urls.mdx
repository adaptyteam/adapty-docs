広告がストアの前にランディングページやウェブファネルへ誘導する場合は、広告URLにタグを付けてください。広告が直接App StoreまたはGoogle Playへ誘導する場合は、代わりに[トラッキングリンク](ua-tracking-links)を遷移先として使用してください。リンク自体にキャンペーンデータが含まれているため、タグ付けは不要です。

Adapty Attributionは、ランディングページのURLからキャンペーン、広告セット、広告を読み取ります。広告ネットワークは独自のクリックID（`fbclid`、`ttclid`、または`gclid`）を自動的に付加しますが、これはネットワークを識別するものの、キャンペーン、広告セット、広告は識別できません。購入を特定の広告まで正確にアトリビューションするには、広告にトラッキングパラメーターを追加してください。

手順は、自社ファネルで[Adaptyウェブピクセル](ua-web-pixel)を使う場合でも、[FunnelFox](ua-funnelfox)を使う場合でも同じです。

## 始める前に \{#before-you-start\}

[Meta Ads](ua-facebook)、[TikTok for Business](ua-tiktok)、または [Google Ads](ua-google-ads) を Adapty アトリビューションに接続し、キャンペーン設定を追加してください。Adapty はキャンペーン設定ごとに広告 URL パラメーターを生成するため、それらをコピーするには設定が必要です。

## 広告にタグを付ける \{#tag-your-ads\}

1. キャンペーン設定の **Web funnel** セクションで、**Ad URL parameters** フィールドの値をコピーします。

<ZoomImage id="ua-web-pixel-url-params.webp" width="700px" alt="Ad URL parameters field in the Web funnel section of a campaign configuration in Adapty Attribution" />

2. 広告ネットワークに値を貼り付けます:
   - **Meta**: 広告の **URL parameters** フィールドに貼り付けます。
   - **TikTok**: 広告のリンク先 URL の下にある **Build URL parameters** に貼り付けます。
   - **Google Ads**: キャンペーン設定の **Campaign URL options > Final URL suffix** に貼り付けます。また、Google Ads アカウント設定で自動タグ設定をオンにする必要があります。

この値にはネットワークマクロが含まれており、クリック時にネットワークが実際のキャンペーン、広告セット、広告の値に置き換えます。

ランディングページまたはファネルのURLは、広告の遷移先フィールド（Metaでは **Website URL**、TikTokでは **Destination URL**、Google Adsでは **Final URL**）にパラメータなしで設定してください。ネットワークがクリック時にそのURLへパラメータを付加するため、広告を再タグ付けしなくても遷移先URLを後から変更できます。

パラメータには `utm_*` の値は含まれないため、独自の分析ツール向けに自分のUTMスキームをそのまま使い続けられます。Adapty はそれを必要としません。
