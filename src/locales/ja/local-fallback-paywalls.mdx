Adapty は、[フォールバックペイウォール](/fallback-paywalls)用の JSON 設定ファイルをプラットフォームごとに自動生成します。これらのファイルには、オンボーディングのフォールバックデータも含まれています。

1 つのプレースメントに複数のペイウォールまたはオンボーディングがある場合、フォールバックバージョンには最も重みが高い、またはオーディエンスが最も広いバリアントが含まれます。ペイウォールまたはオンボーディングを変更するたびに、Adapty はこれらのファイルを更新します。

以下の手順に従って、フォールバック設定をダウンロードしてください：

1. **[Placements](https://app.adapty.io/placements)** ページを開きます。
2. **Fallbacks** ボタンをクリックします。
3. ドロップダウンからターゲットプラットフォーム（*iOS* または *Android*）を選択します。
4. SDKバージョンを選択してダウンロードを開始します。

:::tip
ターミナルからファイルをダウンロードするには、[Developer CLI](developer-cli) を使用します。アプリのSDKバージョンを指定してください：

```bash
adapty fallbacks get --app <app-id> --platform ios --sdk-version <sdk-version> --output ios_fallback.json
```

`--platform ios` または `--platform android` を付けて、ストアごとに1回実行してください。フラグの詳細は [`adapty fallbacks get`](developer-cli-fallbacks) を参照してください。
:::
