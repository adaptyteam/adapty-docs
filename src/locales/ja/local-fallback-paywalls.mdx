Adaptyは、[フォールバックペイウォール](/fallback-paywalls)用のJSON設定ファイルをプラットフォームごとに自動生成します。これらのファイルには、オンボーディングのフォールバックデータも含まれています。

プレースメントに複数の[オーディエンス](audience)がある場合、フォールバックファイルは **All users** オーディエンスのみを使用します。そのオーディエンスでA/B テストが実行されている場合、ファイルにはテストのすべてのバリアントが含まれ、SDKは重みに基づいてユーザーを振り分けます。[クロスプレースメントA/B テスト](ab-test-types)はファイルに含まれません。Adaptyは、ペイウォールやオンボーディングを変更するたびにこれらのファイルを更新します。

フォールバック設定をダウンロードするには、以下の手順に従ってください：

1. **[Placements](https://app.adapty.io/placements)** ページを開きます。
2. **Fallbacks** ボタンをクリックします。
3. ドロップダウンからターゲットプラットフォーム（*iOS* または *Android*）を選択します。
4. SDKバージョンを選択してダウンロードを開始します。

:::tip
ターミナルからファイルをダウンロードする場合は、[Developer CLI](developer-cli) を使用してください。アプリに組み込まれている Adapty SDK のバージョンを指定します：

```bash
adapty fallbacks get --app <app-id> --platform ios --sdk-version <sdk-version> --output ios_fallback.json
```

`--platform ios` または `--platform android` を付けて、ストアごとに1回実行してください。フラグの詳細は [`adapty fallbacks get`](developer-cli-fallbacks) を参照してください。
:::
