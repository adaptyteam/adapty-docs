モバイルアプリ内でペイウォールを表示することは、ユーザーにプレミアムコンテンツやサービスへのアクセスを提供するための重要なステップです。ただし、ペイウォールの表示だけで購入が完結するのは、Adapty が画面をレンダリングする場合、つまり[フロー](adapty-flow-builder)や[旧ペイウォールビルダー](adapty-paywall-builder)で作成したペイウォールを表示する場合に限られます。

独自のコードで画面をレンダリングする場合は、購入を完了してコンテンツのロックを解除するために、`.makePurchase()` という別のメソッドを使用する必要があります。このメソッドは、ユーザーがペイウォールを通じて希望するトランザクションを進めるための入口となります。

ペイウォールに、ユーザーが購入しようとしているプロダクトに対してアクティブなプロモーションオファーがある場合、Adapty は購入時に自動的にそれを適用します。

:::warning
初回オファーが自動的に適用されるのは、Adapty が画面をレンダリングする場合のみであることに注意してください。

それ以外の場合は、[iOS での初回オファーの利用資格を確認](fetch-paywalls-and-products#check-intro-offer-eligibility-on-ios)する必要があります。この手順を省略すると、リリース時にアプリが審査で却下される可能性があります。また、初回オファーの対象ユーザーに通常価格が請求される可能性もあります。
:::

一つのステップも省略せずに[初期設定](quickstart)を完了していることを確認してください。設定が完了していないと、購入の検証ができません。

## 購入を実行する \{#make-purchase\}

:::note
**Adapty が画面をレンダリングしていますか？** [フロー](adapty-flow-builder)または[ペイウォールビルダー](adapty-paywall-builder)のペイウォールの場合、購入は自動的に処理されます。このステップはスキップできます。

**ステップごとの手順をお探しですか？** 完全なコンテキストを含むエンドツーエンドの実装手順については、[クイックスタートガイド](ios-implement-paywalls-manually)をご覧ください。
:::

## App Storeからのプロモーションアプリ内課金 \{#in-app-purchases-from-the-app-store\}

ユーザーがApp Storeで購入を開始し、そのトランザクションがアプリに引き継がれると、SDKは`AdaptyPromotedProduct`オブジェクトとともに`didReceivePromotedPurchase`デリゲートメソッドを呼び出します。この場合、2つの選択肢があります：

- **トランザクションを即時処理する:** `didReceivePromotedPurchase` を実装しない。デフォルト実装はすぐに購入を開始し、Apple の購入システム画面が自動的に表示されます。
- **プロダクトオブジェクトを後で処理するために保存する:** `didReceivePromotedPurchase` を実装し、プロダクトを保存してから、後で保存したプロダクトを使って `makePurchase` を呼び出す。ユーザーに購入をトリガーする前に独自の画面を表示したい場合に便利です。

プロモーション対象のプロダクトにサブスクリプションオファーが含まれている場合、SDK は購入時に自動的にそれを適用します。オファーは App Store の購入インテントから読み取られ、iOS 18.0 以降で公開されます。iOS 16.4〜17.x では、`subscriptionOffer` は常に `nil` となり、購入は通常価格で進みます。

完全なスニペットはこちらです：

```swift showLineNumbers title="Swift"
final class YourAdaptyDelegateImplementation: AdaptyDelegate {
    // 1. Store the product object to defer the transaction.
    // To process the transaction immediately instead, don't implement this method —
    // the default implementation starts the purchase right away.
    nonisolated func didReceivePromotedPurchase(_ product: AdaptyPromotedProduct) {
        // store the product object
    }

    // 2. Continue the deferred purchase later on by passing the product to `makePurchase` when the timing is appropriate
    func continueDeferredPurchase() async {
        let storedProduct: AdaptyPromotedProduct = // get the product object from 1.
        do {
            let purchaseResult = try await Adapty.makePurchase(product: storedProduct)
            // process the purchase result
        } catch {
            // handle the error
        }
    }
}
```

:::warning
`didReceivePromotedPurchase` APIはSDKバージョン4.1以降で利用可能で、**iOS 16.4**以降が必要です。SDKバージョン4.0はプロモートされたアプリ内課金を一切サポートしておらず、iOS 16.4未満のデバイスではこのメソッドは呼び出されません。古いiOSバージョンでプロモートされた購入が必要な場合は、SDK 3.xを使用し、以下に示す`shouldAddStorePayment`をお使いください。
:::

<Details summary="Adapty SDK 3.xをお使いですか？">

SDK 3.xでは、SDKは代わりに`shouldAddStorePayment`デリゲートメソッドを呼び出します：

- **トランザクションをすぐに処理する：** `shouldAddStorePayment` で `true` を返します。これにより、Apple の購入システム画面がすぐに表示されます。
- **プロダクトオブジェクトを後で処理するために保存する：** `shouldAddStorePayment` で `false` を返し、後で保存したプロダクトを使って `makePurchase` を呼び出します。

```swift showLineNumbers title="Swift"
final class YourAdaptyDelegateImplementation: AdaptyDelegate {
    nonisolated func shouldAddStorePayment(for product: AdaptyDeferredProduct) -> Bool {
        // 1a.
        // Return `true` to continue the transaction in your app. The Apple purchase system screen will show automatically.

        // 1b.
        // Store the product object and return `false` to defer or cancel the transaction.
        false
    }
    
    // 2. Continue the deferred purchase later on by passing the product to `makePurchase` when the timing is appropriate
    func continueDeferredPurchase() async {
        let storedProduct: AdaptyDeferredProduct = // get the product object from 1b.
        do {
            try await Adapty.makePurchase(product: storedProduct)
        } catch {
            // handle the error
        }
    }
}
```

</Details>

## iOS でオファーコードを利用する \{#redeem-offer-codes-in-ios\}

<OfferCodesInfo />

アプリ内でコード引き換えシートを表示するには：

```swift showLineNumbers
Adapty.presentCodeRedemptionSheet()
```

:::danger
確認された問題として、一部のアプリでオファーコード引き換えシートが正常に動作しない場合があります。ユーザーを直接 App Store にリダイレクトすることをお勧めします。

そのためには、以下の形式の URL を開く必要があります：
`https://apps.apple.com/redeem?ctx=offercodes&id={apple_app_id}&code={code}`
:::
