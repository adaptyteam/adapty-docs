AIコーディングエージェントに平易な言葉でAdaptyのアナリティクスについて質問しましょう。収益、コンバージョン、リテンション、LTVなど、エージェントがターミナルで[Adapty CLIのアナリティクスコマンド](developer-cli-analytics)を実行して結果を取得します。

## 何を質問できるか \{#what-you-can-ask-about\}

CLI は Adapty Analytics ダッシュボードに表示されるものと同じ数値を返します。質問の種類ごとに対応するコマンドが決まっています：

| 質問の内容 | カバー範囲 | コマンド |
| --- | --- | --- |
| 収益、MRR、ARR、ARPU、その他のチャート | 国など、チャートがサポートするディメンションでグループ化された、時系列の指標 | `adapty analytics chart` |
| コンバージョン率 | トライアルから有料への移行など、ユーザーが各ステップをどれだけ進むか | `adapty analytics conversion` |
| ファネル | インストールから更新までの間のどの段階でユーザーが離脱するか | `adapty analytics funnel` |
| リテンション | 各期間後にサブスクライバーがどれだけ残るか | `adapty analytics retention` |
| ライフタイムバリュー（LTV） | 各更新または日数経過後の有料ユーザーあたりの収益 | `adapty analytics ltv` |
| インストールコホート | 同じ期間にインストールしたユーザーの収益、サブスクライバー数、および予測 | `adapty analytics cohort` |

すべてのコマンドは読み取り専用です。エージェントはこれらを通じてAdaptyアカウントを変更することはできません。

## 始める前に \{#before-you-start\}

必要なものは3つです：

- **データがある Adapty アカウント**: CLI はダッシュボードと同じ数値を返すため、アプリがすでにアナリティクスを収集している必要があります。
- **Adapty CLI バージョン 0.10.0 以降がインストール済みでログイン済みであること**: CLI のインストールとログインは、以下のコマンドを実行してください。ログインするとブラウザのタブが開き、ターミナルに表示されたコードを確認します。

  ```bash
  npm install -g adapty
  ```

  ```bash
  adapty auth login
  ```

  一度ログインすれば、その Adapty ユーザーがアクセスできるすべてのアプリを読み取れるため、API キーは不要です。

- **ターミナルコマンドを実行できるAIツール**: Claude Code、Cursor、Codex、Gemini CLIなど。claude.aiやChatGPTのような通常のチャットツールはCLIを実行できません。

## エージェントにコマンドを覚えさせる \{#give-your-agent-the-commands\}

[CLI アナリティクスリファレンス](https://adapty.io/docs/ja/developer-cli-analytics.md) には、すべてのコマンド・フラグ・結果の読み方が記載されています。エージェントがこれを読めば、あなたがコマンドを書かなくても正しいコマンドを組み立てられます。

リファレンスを URL で渡してください。エージェントが URL を取得できる場合は `https://adapty.io/docs/ja/developer-cli-analytics.md` を渡し、そのページを読むよう指示してください。

エージェントは事前にチャート名を知っておく必要はありません。`adapty analytics catalog --app <app-id>` を使えば、アプリが対応しているすべてのチャート、コンバージョン、グルーピング、フィルターを一覧表示できます。

## データについて質問する \{#ask-about-your-data\}

リファレンスを読み込み、CLIでログインしたら、アプリ名・指標・期間・意思決定の内容を指定してください。

プロンプト例：

```
For my app "Sleep Tracker", what was MRR at the end of each month this year,
and how does it compare to the same months last year?

Show the trial-to-paid conversion rate for the last 90 days, by product.
Which product converts worst?

Which 10 countries brought the most revenue in Q3? Use revenue after the
store's commission.

How does retention compare between iOS and Android for subscribers who started
in the last 6 months?

Compare LTV after 30 and 90 days for users who installed in July and in August,
and save it as a CSV file.
```

エージェントは `adapty apps list` を使ってアプリのUUIDを検索し、コマンドを選択してデータを返します。結果はJSON形式（`--json`）で読み取ります。スプレッドシートで使いたい場合はCSVをリクエストすると、エージェントがコマンドに `--csv` を追加します。

## 繰り返し使うための初期設定 \{#set-up-once-for-repeated-use\}

毎回セッションのたびに設定をやり直さなくて済むよう、エージェントが再利用できる場所にリファレンスを保存しておきましょう。

- **参照リンクを保存する**: `https://adapty.io/docs/ja/developer-cli-analytics.md` をエージェントのルールまたはメモリファイル（例：`CLAUDE.md` や Cursor のルールファイル）に追加して、セッションごとに読み込まれるようにしてください。
- **アプリ名を登録する**: アプリ名または UUID を同じファイルに追加しておくと、毎回のプロンプトで指定する手間が省けます。
- **再利用可能なプロンプトを保存するか、カスタムスキルを作成する**: よく使う質問を保存済みプロンプトとして管理するか、カスタムスキルやスラッシュコマンドとしてラップしておくと、エージェントがオンデマンドでレポートを実行できます。

## 制限事項 \{#limits\}

以下の制約を念頭に置いてください：

- **レート制限**: 各アナリティクスコマンドはアプリごとに1秒あたり2リクエストまで許可されます。CLIはリトライしないため、コマンドを速く送りすぎるとexitコード4で失敗します。エージェントにはコマンドを1つずつ順番に実行させ、失敗した場合は`retry_after_seconds`待ってから再実行するよう指示してください。
- **1コマンドにつき1アプリ**: 各コマンドは1つのアプリのみを読み取ります。アプリを比較する場合は、エージェントがアプリごとに1コマンドずつ実行します。
- **アトリビューションへの追加禁止**: 広告費、インストール数、キャンペーン別ROASについては[アトリビューションコマンド](developer-cli-attribution)を使用してください。Adaptyはアナリティクスの数値とは異なる計算方法を用いているため、アトリビューションの数値をアナリティクスの数値に加算しないでください。

サーバーやスケジュールされたジョブからアナリティクスを取得する場合（ブラウザからログインできない環境）は、代わりにシークレットAPIキーを使って[エクスポートアナリティクスAPI](export-analytics-api)を利用してください。
