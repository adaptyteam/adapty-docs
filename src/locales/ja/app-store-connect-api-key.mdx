AdaptyはApp Store Connect APIキーを使用して、App Store Connect内のプロダクトを管理します：

- [プロダクトを作成](create-product#create-product-and-push-to-store)し、サブスクリプショングループを設定する。
- Adaptyにプロダクトを追加する際、IDで既存のプロダクトを検索する。
- Adapty内で各プロダクトのApp Storeステータスを表示する。
- 価格を毎日インポートし、Adaptyで行った価格変更をエクスポートする。
- [リテンションメッセージング](retention-messaging-setup)のSwitchプランにプロダクトを提案する。

Adaptyは、プロダクトの作成や価格変更など、Adapty上で操作を行った場合にのみApp Store Connectを更新します。ステータスの表示や価格のインポートは、App Store Connectの読み取りのみを行います。

**App Store Connect** の **Team Keys** タブでキーを生成し、Adapty の **App settings** で接続してください。キーが使えなくなったり変更が必要になった場合は、[キーを置き換えて](#replace-the-key)ください。

App Store Connect API キーは [アプリ内課金キー](generate-in-app-purchase-key) とは別のものですが、App Store Connect ではどちらのキーの ID も **Issuer ID** および **Key ID** として表示されます。

**App settings** > **iOS SDK** ですべての認証情報を一度に入力するには、[App Store インテグレーションの設定](app-store-connection-configuration) に従ってください。

## キーを置き換える \{#replace-the-key\}

キーが機能しなくなった場合や **Access** の設定を変更する必要がある場合は、古いキーを無効化する前に新しいキーを Adapty に接続してください。

有効なキーがないと、Adapty は以下の操作を実行できません：

- プロダクトを作成する。
- ID で既存のプロダクトを検索する。
- プロダクトのステータスや価格を同期する。

機能しなくなったキーも、Adapty 上では接続済みとして表示されます。その兆候として、[App Store のステータスが表示されず、**App Store Product ID** のドロップダウンが空のプロダクト](troubleshoot-app-store-integration#products-dont-appear-or-show-no-app-store-status)が挙げられます。

Adapty は、接続済みキーの Key ID を表示しません。Adapty が使用しているキーが不明な場合は、新しいキーに置き換えてください。

アプリを別の Apple デベロッパーアカウントに移行する場合は、[新しいオーナーのチームキーを接続してください](transfer-apps#app-store-ios-transfer)。

キーを置き換えるには:

1. [新しいチームキーを生成する](#generate-a-team-key-in-app-store-connect)。
2. Adapty で [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk) に移動します。**App Store Connect API key** セクションで **Edit** をクリックします。[新しいキーの値を入力し](#connect-the-key-in-adapty)、**Save changes** をクリックします。
3. 1つのチームキーで App Store Connect チームのすべてのアプリに対応できます。チームの他のアプリで Adapty を使用している場合は、それらにも新しいキーを接続してください。また、古いキーを使用しているサーバーがあれば、そちらも新しいキーに置き換えてください。
4. 失効したキーは、それを使用しているすべてのアプリで機能しなくなり、復元することはできません。新しいキーが置き換えるキーがわかっている場合は、App Store Connect にアクセスしてそのキーを失効させてください。
