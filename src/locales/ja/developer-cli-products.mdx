これらの Adapty CLI コマンドは、[プロダクト](product) の管理、App Store および Google Play のプロダクト ID へのマッピング、ストアオファーとの紐付けを行います。

## プロダクト \{#products\}

### adapty products list

アプリの全[プロダクト](product)を一覧表示します。

```bash
adapty products list --app <app-id>
```

| フラグ | 必須 | 説明 |
|---|---|---|
| `--app` | はい | アプリID（UUID） |

[ページネーションフラグ](developer-cli-reference#global-flags)を使用できます。

### adapty products get

特定の[プロダクト](product)の詳細を取得します。

```bash
adapty products get --app <app-id> <product-id>
```

| 引数 | 説明 |
|---|---|
| `product-id` | プロダクト ID（UUID） |

| フラグ | 必須 | 説明 |
|---|---|---|
| `--app` | はい | アプリ ID（UUID） |

### adapty products create

新しい[プロダクト](product)を作成します。

:::important
ストアプロダクトと価格 ID は作成後に変更できません。別のストア ID を使用するには、新しいプロダクトを作成してください。
:::

```bash
adapty products create --app <app-id> --title "Monthly" --access-level-id <access-level-id> --period monthly --ios-product-id com.example.monthly
```

| フラグ | 必須 | 説明 |
|---|---|---|
| `--app` | はい | アプリ ID（UUID） |
| `--title` | はい | プロダクトのタイトル |
| `--access-level-id` | はい | このプロダクトが解除する[アクセスレベル](access-level) ID（UUID） |
| `--period` | はい | サブスクリプション期間：`weekly`、`monthly`、`two_months`、`trimonthly`、`semiannual`、`annual`、`lifetime` |
| `--ios-product-id` | いずれか1つのストアが必須 | App Store Connect のプロダクト ID |
| `--android-product-id` | いずれか1つのストアが必須 | Google Play Console のプロダクト ID |
| `--android-base-plan-id` | `--period lifetime` でない場合、`--android-product-id` と共に必須 | Google Play Console のベースプラン ID |
| `--stripe-product-id` | いずれか1つのストアが必須 | Stripe のプロダクト ID |
| `--stripe-price-id` | `--stripe-product-id` と共に必須 | Stripe の価格 ID |
| `--paddle-product-id` | いずれか1つのストアが必須 | Paddle のプロダクト ID |
| `--paddle-price-id` | `--paddle-product-id` と共に必須 | Paddle の価格 ID |

すべてのプロダクトには少なくとも1つのストアが必要です: `--ios-product-id`、`--android-product-id`、`--stripe-product-id`、または `--paddle-product-id`。1つのプロダクトに複数のストアのIDをまとめて設定することもできます。

Stripe や Paddle を通じてウェブでプロダクトを販売するには、まず決済プロバイダーを Adapty に接続してください: [Stripe](stripe) および [Paddle](paddle) を参照。これらのストアでは、プロダクト ID と価格 ID をセットで渡す必要があります。どちらか一方のみを渡した場合、コマンドはエラーになります。

```bash
adapty products create --app <app-id> --title "Monthly" --access-level-id <access-level-id> --period monthly --stripe-product-id prod_xxx --stripe-price-id price_xxx
```

ウェブ専用のプロダクトも有効です。App Store や Google Play の ID がなくても、Stripe または Paddle の ID のみを使用してプロダクトを作成できます。

### adapty products update

既存の[プロダクト](product)を更新します。

ストアのプロダクトIDと価格IDは作成後に変更できないため、このコマンドでは利用できません。異なるストアIDを使用するには、新しいプロダクトを作成してください。

```bash
adapty products update --app <app-id> <product-id> --title "Monthly" --access-level-id <access-level-id>
```

| 引数 | 説明 |
|---|---|
| `product-id` | プロダクトID（UUID） |

| フラグ | 必須 | 説明 |
|---|---|---|
| `--app` | はい | アプリ ID（UUID） |
| `--title` | いいえ | プロダクトのタイトル |
| `--access-level-id` | いいえ | このプロダクトがアンロックする[アクセスレベル](access-level) ID（UUID） |

## プロダクトオファー \{#product-offers\}

App Store Connect または Google Play Console で作成したオファーを Adapty のプロダクトに紐付けることで、Adapty がオファーを適用できるようになります。各オファータイプの詳細や、ストアでのオファー作成方法については、[Adapty にオファーを追加する](create-offer)を参照してください。

以下のオファーを追加してください：

- App Store のプロモーションオファーおよびウィンバックオファー。
- 無料トライアルを含む、すべての Google Play オファー。Google Play には初回オファーという概念がないため、トライアルはベースプランへのオファーとして扱われ、Adapty で紐付けを行って初めて適用されます。

App Store の初回オファーは追加不要です。対象ユーザーに自動的に適用されます。

リンクされたオファーは、ユーザーに表示される前に、フローまたはペイウォール内のプロダクトで選択される必要があります。ペイウォールで選択するには、Adapty ダッシュボードを使用してください。詳しくは [オファーを表示する](create-offer#2-display-offer) をご覧ください。

`adapty products list` と `adapty products get` では、各プロダクトにリンクされているオファーの数を `offers_count` で確認できます。この数にはAdapty でリンクされたオファーのみが含まれ、ストアに存在するオファーは含まれません。

### adapty product-offers list

[プロダクト](product)に紐づくすべてのオファーを一覧表示します。

```bash
adapty product-offers list --app <app-id> --product <product-id>
```

| フラグ | 必須 | 説明 |
|---|---|---|
| `--app` | はい | アプリID（UUID） |
| `--product` | はい | プロダクトID（UUID） |

すべてのオファーを1ページで返し、[ページネーションフラグ](developer-cli-reference#global-flags)は使用できません。

### adapty product-offers get

特定のオファーの詳細を取得します。

```bash
adapty product-offers get --app <app-id> <offer-id>
```

| 引数 | 説明 |
|---|---|
| `offer-id` | オファー ID（UUID） |

| フラグ | 必須 | 説明 |
|---|---|---|
| `--app` | はい | アプリ ID（UUID） |

### adapty product-offers create

[プロダクト](product)にストアオファーをリンクします。

```bash
adapty product-offers create --app <app-id> --product <product-id> --title "Spring" --type promotional --ios-offer-id spring_ios --android-offer-id spring-android
```

| フラグ | 必須 | 説明 |
|---|---|---|
| `--app` | 必須 | アプリID（UUID） |
| `--product` | 必須 | プロダクトID（UUID） |
| `--title` | 必須 | オファー名（Adapty ダッシュボードにのみ表示） |
| `--type` | 必須 | オファータイプ：`promotional` または `win_back` |
| `--ios-offer-id` | 少なくとも1つのストアが必須 | App Store ConnectのオファーID |
| `--android-offer-id` | 少なくとも1つのストアが必須 | Google Play ConsoleのオファーID |

ウィンバックオファーはApp Store専用のため、`--type win_back` は `--ios-offer-id` のみを使用します。Google Playのオファー（無料トライアルを含む）はすべて `--type promotional` を使用してください。

```bash
adapty product-offers create --app <app-id> --product <product-id> --title "Come back" --type win_back --ios-offer-id winback_ios
```

### adapty product-offers update

既存のオファーを更新します。

```bash
adapty product-offers update --app <app-id> <offer-id> --title "Spring 2"
```

| 引数 | 説明 |
|---|---|
| `offer-id` | オファーID（UUID） |

| フラグ | 必須 | 説明 |
|---|---|---|
| `--app` | はい | アプリID（UUID） |
| `--title` | いいえ | オファー名 |
| `--type` | いいえ | オファータイプ：`promotional`（プロモーションオファー）または `win_back`（ウィンバックオファー）。オファーを `win_back` に変更するには、`--clear-android-offer-id` を使用してGoogle Play側も削除してください |
| `--ios-offer-id` | いいえ | 新しいApp StoreのオファーID |
| `--android-offer-id` | いいえ | 新しいGoogle PlayのオファーID |
| `--clear-ios-offer-id` | いいえ | オファーのApp Store側を削除する |
| `--clear-android-offer-id` | いいえ | オファーのGoogle Play側を削除する |

`--app` 以外のフラグを少なくとも1つ指定する必要があります。省略したフィールドは現在の値が維持されます。オファーには必ず1つ以上のストアオファーIDが必要なため、最後の1つを削除しようとするとコマンドは失敗します。

:::warning
このコマンドはオファーを読み取り、まるごと保存します。読み取りから保存までの間に誰かが Adapty ダッシュボードで同じオファーを編集した場合、その変更は上書きされます。
:::

初回オファーは更新できません。App Store または Google Play 以外のストアのオファーも、CLI からは更新できません。その場合は Adapty ダッシュボードで編集してください。

オファーを削除するには、Adapty ダッシュボードを使用してください。CLIには削除コマンドがありません。
