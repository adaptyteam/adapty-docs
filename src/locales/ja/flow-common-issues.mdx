この記事では、[Flow & Paywall Builder](adapty-flow-builder) でフローを構築する際に最もよく発生する問題を、原因と対処法とともにまとめています。

## フローのプレビューまたは公開ができない \{#a-flow-wont-preview-or-publish\}

プロダクトに関する問題は [**Issues** パネル](builder-save-publish#fix-issues-before-publishing) に表示されます。パネル内の問題をクリックすると、修正が必要な設定が開きます。

フローのプレビューまたは公開を試みると、次のエラーが表示される場合があります：

| メッセージ | 原因と対処 |
|---|---|
| **No product selected** | プロダクトカードにプロダクトが設定されていません。プロダクトを選択するか、カードを削除してください。 |
| **This product no longer exists**、**This offer no longer exists** | プロダクトまたはオファーがダッシュボードから削除されています。使用箇所で別のものを選択するか、**Products** パネルの **Missing** エントリにある **Replace in N places** を使って、画面上の全使用箇所をまとめて修正してください。 |
| **This product is off this screen**、**This offer is off this screen** | テキスト変数、条件、またはアクションが画面のリストに存在しないプロダクトを参照しています（例：**Products** パネルで削除した場合）。パネルでプロダクトを再追加するか、参照を編集してください。 |
| **Product reference is invalid** | プロダクト参照の形式が正しくありません。プロダクトを再選択してください。 |
| **Purchase action has no product to buy** | **Purchase** アクションにプロダクトが設定されていません（空のままか、削除済みのカードを指しています）。要素の **Interactions** タブで **Product** にプロダクトまたは `products.selectedProduct` を設定してください。 |
| **Select product action has no product to select** | **Select product** アクションが参照していたカードが存在しません（削除された、プロダクトグループ外に移動された、または別の画面にある）。要素の **Interactions** タブで、同じ画面上のカードをアクションの対象に設定してください。 |
| **Flow has no screens**、**Screen "…" has no elements** | 空の画面にコンテンツを追加するか、削除してください。リモートコンフィグのコンテンツのみを持つフローはこの対象外です。 |
| **Invalid interaction action** | アクションが未完了です（URLのない **Open URL**、遷移先のない **Navigate to screen**、割り当てのない **Set variable**、Action IDのない **Custom**、タイトルもメッセージもない **Show alert**、要素のない **Show** または **Hide**、Web Paywall URLのないウェブ決済 **Purchase**）。要素のインタラクションを開いて、アクションを完成させるか削除してください。 |
| **"…" has no link to open**、**"…" runs a custom action without an ID**、**"…" shows an alert with no text**、**"…" has an unfinished condition**、**Complete the selected action before publishing.** | アクションが設定されていません（リンクのない **Open URL** アクション、IDのない **Custom Action**、タイトルもメッセージもない **Show alert** アクション、条件が未入力の **Conditional** アクション）。**Issues** パネルに各項目が表示されます。**Publish to Live** をクリックすると、ビルダーが最初の問題要素の **Interactions** タブを開きます。アクションを完成させるか削除してください。**Conditional** アクションの場合は、すべての条件を入力するか、該当するブランチを削除してください。 |
| **Missing navigation target** | **Navigate to screen** アクションが削除済みの画面を指しています。既存の画面を選択するか、アクションを削除してください。 |
| **Missing product target**、**Invalid product target**、**Product target on another screen**、**Ambiguous product target**、**Select Product inside a component** | **Select product** アクションのターゲットカードが削除されている、プロダクトグループに属していない、別の画面にある、別の画面の要素と同じ要素IDを持っている、または画面をまたいで共有されるフッター・ヘッダー内にあります。同じ画面のプロダクトグループ内にある一意のIDを持つカードをアクションの対象に設定してください。 |
| **Missing selectable group** | 要素が存在しないセレクタブルグループを参照しています。再接続するか、グループを再作成してください。 |
| **Invalid visibility condition** | 条件付き表示ルールが未完了です。コンディションビルダーで完成させてください。 |
| **Broken references**、**Fix the broken reference before publishing.**、**Fix N broken references before publishing.** | **Publish to Live** をクリックすると、**Can't publish yet** ダイアログに、存在しない要素・ステート・変数を使用している条件が一覧表示されます（削除後や別のフローから画面をペーストした場合など）。値はあるが変数がない条件行も同じリストに表示されます。**Go to screen** をクリックして最初の問題箇所を開き、条件で既存の要素・ステート・変数を選択するか、条件を削除してください。 |
| **Condition uses a deleted element or state**、**Condition uses a deleted variable** | 存在しない要素・ステート・変数を条件が参照しているため公開に失敗しました。条件を開いて既存の要素・ステート・変数を選択するか、条件を削除してから再公開してください。 |
| **Invalid State Condition**、`invalid_state_condition` | Adapty CLI または API がフローを公開できませんでした。**Disabled** または **custom** ステートの条件の行に値または **Is empty** はあるが変数がありません。その行に変数を選択するか、行を削除してから再公開してください。 |
| **Circular state conditions** | 複数の要素の **Disabled** または **custom** ステート条件が互いのステートをループ状に参照しています。いずれかの要素の **States** セクションで、ループを生じさせている条件を変更または削除してください。 |
| **Variables** 以下のフォーミュラ名に **This variable no longer exists. Pick another one.** などのエラーテキストが表示される | [フォーミュラ](flow-formulas)にエラーがあります。Variables パネルのフォーミュラの行にエラーアイコンが表示されます。変数を開き、[トラブルシューティング](flow-formulas#troubleshooting)に従ってフォーミュラを修正してください。 |
| **Formula "…" has a syntax error** | フォーミュラが構文規則に従っていません（例：括弧の欠落、数値にカンマが含まれる、関数名が不明）。変数を開いてフォーミュラを修正してください。 |
| **Formula "…" has a wrong number of arguments** | フォーミュラの関数の引数が多すぎるか少なすぎます。[数値関数](flow-formulas#number-functions)および[日付関数](flow-formulas#date-functions)の引数リストを参照してください。 |
| **Formula "…" uses a value of the wrong type** | フォーミュラが数値の代わりにテキスト・真偽値・日付を使用しているか、日付の代わりに数値を使用しています。変数を開いてフォーミュラを修正してください。 |
| **Formula "…" uses a deleted value** | フォーミュラがフロー内に存在しない変数・回答・プロダクトグループを参照しています。フォーミュラ内の参照を置き換えてください。 |
| **Formula "…": the product "…" has no Products row with no offer and no plan on any screen of the flow**、`formula_undeclared_product` | Adapty CLI または API がフローを公開できませんでした。テキスト要素または条件が、Adapty カタログ内のプロダクトの価格を読み取る[フォーミュラ](flow-formulas#read-the-price-of-any-product)を使用していますが、フローのどの画面にもオファーや請求プランなしのそのプロダクトがありません。Flow & Paywall Builder は自動的に追加しますが、このエラーはビルダー外で作成したフローでのみ発生します。フォーミュラを使用する各画面のプロダクトに、オファーや請求プランなしでそのプロダクトを追加してから再公開してください。 |
| **Formula "…" uses a name with two meanings** | フォーミュラの変数が要素の回答またはプロダクトフィールドと同じ名前を持っています。変数の名前を変更してください。 |
| **Formula "…" uses itself in a loop** | フロー内のフォーミュラが互いをループ状に参照しているため、計算できません。いずれかの参照を削除してください。 |
| **Set Variable writes the formula "…"** | **Set variable** アクションがフォーミュラを変更しようとしています。フォーミュラは常に他の値に依存するため、アクションで設定することはできません。アクションで別の変数を選択してください。 |
| **Variable "…" cannot show in an action** | Date 変数または[フォーミュラ](flow-formulas)が、**Show alert** アクションのタイトル・メッセージ、**Open URL** アクションのアドレス、または **Set variable** アクションのテキスト値に含まれています。これらのテキストでは日付や計算値をデバイス上に表示できません。アクションから変数を削除してください。値を表示するには、テキスト要素に挿入してください。 |
| **Missing Default Locale Content** | **Open URL** アクションに別のロケールのURLはありますが、デフォルトロケールのURLがありません。[**Localizations** パネル](add-paywall-locale-in-adapty-paywall-builder)でデフォルトのURLを追加してください。 |
| **Missing product reference** | 古いフローが画面に登録されていないプロダクトを使用しています。画面を開き、**Products** パネルでプロダクトを追加してください。 |

ビルド中は定期的に [Adapty アプリでフローをプレビュー](paywall-device-compatibility-preview)してください。公開できないフローはプレビューでも表示されず、エラーメッセージで問題が確認できます。

:::tip
フローが本番環境に対応しているか確認するには、[flow-audit スキル](flow-audit-skill)を実行してください。公開エラーのチェックでは検出されない問題（機能しないボタン、ストアコンプライアンス、未完成のテキスト、翻訳の網羅性）を確認します。各問題について、レポートには該当要素とそのスクリーンが記載されます。
:::

## 「Something went wrong」というエラーで詳細なしに公開が失敗する \{#publishing-fails-with-something-went-wrong-and-no-details\}

<ZoomImage id="flow-publish-error.webp" width="300px" alt="公開失敗後の「Something went wrong」通知。サポートアドレスとコピー用のリクエストIDが表示されている" float="right" />

公開リクエストはAdapty側で失敗しており、フローの問題ではありません。ライブバージョンは変更されていません。数分待ってから再度公開してください。それでも失敗する場合は、通知に表示されている **Request ID** をコピーして [support@adapty.io](mailto:support@adapty.io) に送信してください。チームが失敗したリクエストを特定します。

## 購入時にオファーが適用されない \{#an-offer-doesnt-apply-at-purchase\}

ビルダーが確認するのは、オファーが Adapty に存在しているかどうかだけです。割引が実際に適用されるかどうかは、購入時にストアが判断します。初回オファーはユーザーの適格性に依存し、App Store のプロモーションオファーには有効な In-App Purchase Key が必要です。どちらのケースも [プロダクトと価格の不一致](store-sync#product-and-price-discrepancies) で解説しています。

## プレビューでオファー価格が空になっている \{#an-offer-price-is-empty-in-the-preview\}

ビルダーのプレビューはストアにアクセスできないため、`offer_price`、`offer_billing_period`、`offer_full_duration`、および `intro_*` 変数は値の代わりに波括弧付きの変数名が表示されます。これらはSDKがアプリ内でフローをレンダリングする際に解決されます。オファータイプに応じた条件のプレビュー方法については、[プロダクトとオファーのプレビュー](paywall-device-compatibility-preview#preview-products-and-offers)を参照してください。

## 16進数カラーの省略形入力後に公開が失敗する \{#publishing-fails-after-entering-a-shorthand-hex-color\}

カラーは必ず `#FFFFFF` のように6桁の16進数で入力してください。カラーフィールドは短い値も受け付けますが、自動的に展開されないため、`#FFF` のような省略形はSDKの設定に不正な形式で渡され、公開が拒否されます。不透明度は関係ありません——同じ値は不透明度100%でも失敗します。最もコストのかかる例外は4桁の値です。これは公開は成功しますが、意図していない色がレンダリングされます。

## タイポグラフィの変更がエレメントの状態に反映されない \{#typography-edits-dont-reach-an-element-state\}

**Selected** などの状態に独自のタイポグラフィ設定がある場合、**Default** 状態のタイポグラフィを変更しても（別のテキストスタイルを適用する場合も含む）、その状態には影響しません。各状態のタイポグラフィは直接編集してください。

## 要素の位置・サイズ・スペーシングのコントロールが表示されない \{#position-size-and-spacing-controls-are-missing-for-an-element\}

要素とそのコンテナの両方で **Free** 方向が設定されています。この場合、使用できる位置とサイズは **Absolute** のみで、幅と高さは固定されます。Adapty はそれ以外のコントロール（**Position** トグル、**Spacing** セクション、**Fill** および **Hug** オプション）をすべて非表示にします。コントロールを再表示するには、要素の [**Direction**](manage-paywall-ui-elements#direction) を **Vertical** または **Horizontal** に変更してください。

## クイズオプションの要素IDを変更すると条件が一致しなくなる \{#a-condition-stops-matching-after-you-change-the-element-id-of-a-quiz-option\}

`quiz.selectedOptionId` `=` `option_1` のように、ユーザーが選択したオプションを値と比較する条件には、オプションの**要素ID**がテキストとして含まれています。**要素ID**を変更しても、ビルダーはそのテキストを自動更新しないため、条件が一致しなくなります。条件で使用する前に、各オプションの**要素ID**を設定してください。後から変更した場合は、古いIDと比較しているすべての条件を更新してください。

ビルダーは、入力フィールドの変数、グループID、要素の状態、プログレスバーのセグメントなど、その他の参照を自動的に更新します。

## 条件または変数が空の値に解決される \{#a-condition-or-variable-resolves-to-an-empty-value\}

変数ピッカーはすべての画面のフィールドをリストアップするため、条件やテキスト変数は、ユーザーがまだ入力していない項目を参照できてしまいます。実行時、そのような参照は空の値に解決されます。フロー内でより前に収集されたフィールドのみを参照してください。

[数値ピッカー](builder-number-picker)の変数が空になることはありません。ユーザーがホイールを操作するまで、デフォルトの数値と等しい状態が続きます。ユーザーがピッカーに到達する前に変数を評価する条件は、ユーザーが実際には選択していない回答にマッチする可能性があります。

## ユーザーがアプリの値ではなくカスタムタグの初期値を見ている \{#users-see-a-custom-tags-initial-value-instead-of-your-apps-value\}

ユーザーが[カスタムタグ](flow-custom-tags)の初期値を見てしまうのは、以下のケースです。

- **アプリが値を渡していない**: フローを開くコードでそのタグの値を渡していないか、ユーザーがその処理を含むバージョンにアプリを更新していない。
- **名前が一致していない**: アプリのコード内の名前がビルダーのタグ名と異なっている。名前は大文字・小文字を区別し、グループ名も含む。たとえば、`user` グループに `streak` タグがある場合、タグの正確な名前は `user.streak` になる。
- **同じテキスト要素内の別のタグに値がない**: テキスト要素内のカスタムタグのいずれかに値がないと、その要素内のすべてのタグが Initial value を表示する。テキスト要素内のすべてのカスタムタグに値を渡すこと。

Adapty モバイルアプリはカスタムタグの値を渡さないため、プレビューには Initial values のみが表示されます。アプリが渡す値を確認するには、実際のアプリのビルドでフローを開いてください。

## カスタムタグの場所に何も表示されない \{#users-see-nothing-in-place-of-a-custom-tag\}

以下の場合、[カスタムタグ](flow-custom-tags)の場所に何も表示されません：

- **アプリが空の文字列を渡している場合**：Adapty は空の文字列を値として扱うため、初期値がフォールバックとして表示されません。初期値を表示するには、タグに値を渡さないようにしてください。
- **タグに初期値が設定されていない場合**：アプリが値を渡さなかったときにフォールバックを表示するには、タグに初期値を入力してください。

## Set variable アクションで選択中のプロダクトが変わらない \{#a-set-variable-action-doesnt-change-the-selected-product\}

どのプロダクトが選択されているかは変数として割り当てられるものではないため、**Set variable** で選択を変更することはできません。代わりに [**Select product**](onboarding-actions#select-product) アクションを使用してください。

## 購入結果に設定されたアクションがフローで実行されない \{#the-flow-doesnt-run-the-actions-set-for-a-purchase-result\}

フローは、ストアが結果を返したときに、購入または購入の復元に対する[結果アクション](respond-to-purchase-outcomes#add-actions-for-a-result)を実行します。その時点で、ユーザーは購入を開始した画面にいる必要があります。以下の場合、フローはこれらのアクションをスキップします。

- **アプリがフローを閉じる**: 購入または復元が完了したとき、アプリはコールバック内でフローを閉じます。フローを継続させるには、[これらのコールバックでフローを開いたままにしてください](respond-to-purchase-outcomes#before-you-start)。
- **ナビゲーションが結果より先に実行される**: **Navigate to Screen**、**Navigate Next**、**Navigate back**、または **Close Flow** アクションが、同じトリガー内の **Purchase** または **Restore purchases** の後に続いている場合、そのアクションはタップ時に実行されるため、ストアが結果を返す前にユーザーが画面を離れてしまいます。このアクションを **When succeeded** などのアウトカムに移動させてください。
- **ユーザーが画面を離れる**: 戻るボタンなどを使って、ストアが結果を返す前にユーザーが別の画面に移動してしまいます。
- **購入がウェブ決済による購入である**: フローは **Web Payment** 購入の結果を受け取らないため、**Web Payment** に設定された **Purchase** アクションにはアウトカムがありません。アクションを **Web Payment** に切り替えると、Flow & Paywall Builder はそのアウトカムアクションを削除します。

Adapty モバイルアプリのプレビューでは、実際の購入を行うことはできません。アクションの結果をテストするには、アプリのビルドで[サンドボックス購入](test-purchases-in-sandbox)を行ってください。

## AndroidでPurchaseボタンをタップしても何も起きない \{#a-purchase-button-does-nothing-on-android\}

Android では、Google Play がプロダクトを返す前にユーザーが **Purchase** ボタンをタップすると、何も起きません。プロダクトが読み込まれた後はボタンが正常に機能します。iOS では、同じタイミングで早期にタップすると購入が失敗し、フローは **When failed** アクションを実行します。

以下の場合、ボタンは一切機能しません：

- **Google Playがプロダクトを返さない**: プロダクトがGoogle Play Consoleでアクティブになっていること、およびAdapty内のプロダクトが同じGoogle PlayプロダクトIDを使用していることを確認してください。Adaptyでプロダクトを確認するには、[プロダクトの作成](create-product)を参照してください。
- **プロダクトの読み込みに失敗した**: ネイティブAndroidアプリでは、SDKはデフォルトでプロダクトを再読み込みしません。再試行するには、[`onLoadingProductsFailure`](android-handling-events#product-loading-errors)から`true`を返してください。
- **アプリがこのプロダクトを含めずにフローへプロダクトを渡している**: アプリが[`products`](android-present-paywalls)をフローに渡す場合、SDKはGoogle Playからプロダクトを読み込みません。フローのすべてのプロダクトをそのリストに追加してください。
- **以前の購入が完了していない**: SDKは前の購入が完了するまで新しい購入を無視します。Observerモードでは、すべての購入後に`onFinishPurchase()`を呼び出してください。[`onAwaitingPurchaseParams`](android-handling-events#upgrade-subscription)では、必ず`onPurchaseParamsReceived`を呼び出してください。

iOSでは、App Storeがプロダクトを返さない場合、すべてのタップで購入が失敗し、フローは **When failed** アクションを実行します。原因を調べるには、[プロダクトが表示されない](troubleshoot-app-store-integration#products-dont-appear)を参照してください。

## 画像や動画がアップロードできない \{#an-image-or-video-wont-upload\}

フローとペイウォールビルダーのメディア制限外のファイルはアップロードできません。[画像](custom-media#image)と[動画](custom-media#video)の要件に照らしてファイルを確認してください。

| 要素 | フォーマット | 最大ファイルサイズ | その他の制限 |
| :--- | :--- | :--- | :--- |
| 画像 | `.JPG`, `.PNG`, `.WEBP` | 20 MB | — |
| 動画 | `.MP4`, `.WEBM` | 50 MB | 最大30秒、最小640×640ピクセル |

以下のフォーマットはサポートされていません。

- **アニメーションGIFおよびアニメーションWEBP**: モーションを追加するには、代わりにVideoエレメントを使用してください。
- **SVG**: ファイルをPNGまたはWEBPとしてエクスポートしてください。アイコンの場合はアップロード不要です。Iconエレメントがバンドルされた[Tabler Icons](custom-media#icon)ライブラリから描画します。

## フッターが表示されない \{#a-footer-doesnt-render\}

2026年11月27日より前に公開されたフローでは、**Vertical scroll** がオフになっている画面でフッターが表示されません。フッターを表示するには、フローを再公開してください。Flow & Paywall Builder で開き、軽微な変更を加えて [**Publish to Live**](builder-save-publish#publish-a-flow) を有効にし、クリックしてください。
