この記事では、[Flow & Paywall Builder](adapty-flow-builder) でフローを構築する際に最もよく発生する問題を、原因と対処法とともにまとめています。

## フローがプレビューまたは公開できない \{#a-flow-wont-preview-or-publish\}

<ZoomImage id="flow-cant-publish-yet.webp" width="500px" alt="3つのカードにまだプロダクトが設定されていないことを報告する「まだ公開できません」ダイアログ" />

フローをプレビューまたは公開しようとすると、次のエラーが発生することがあります：

| メッセージ | 原因と修正方法 |
|---|---|
| **No product selected** | プロダクトカードにプロダクトが設定されていません。プロダクトを選択するか、カードを削除してください。 |
| **This product no longer exists**、**This offer no longer exists** | プロダクトまたはオファーがダッシュボードから削除されています。使用箇所で別のものを選択するか、**Products** パネルの **Missing** エントリにある **Replace in N places** を使用して、画面上のすべての使用箇所を一括修正してください。 |
| **This product is off this screen**、**This offer is off this screen** | テキスト変数、条件、またはアクションが、画面のリストに存在しないプロダクトを参照しています。たとえば、**Products** パネルでプロダクトを削除した後に発生します。パネルでプロダクトを追加し直すか、参照を編集してください。 |
| **Offer required** | `offer_price`、`offer_billing_period`、または `offer_full_duration` が、オファーのないプロダクトで使用されています。プロダクトにオファーを設定するか、代わりに `prod_*` 変数を使用してください。 |
| **Product reference is invalid** | プロダクト参照が不正な形式です。プロダクトを再選択してください。 |
| **Purchase action has no product to buy** | **Purchase** アクションにプロダクトが設定されていません。空のままか、削除済みのカードを指しています。要素の **Interactions** タブで、**Product** をプロダクトまたは `products.selectedProduct` に設定してください。 |
| **Select product action has no product to select** | **Select product** アクションが指していたカードが存在しません。削除されたか、プロダクトグループの外に移動されたか、別の画面にあります。要素の **Interactions** タブで、この画面上のカードをアクションの対象に設定してください。 |
| **Flow has no screens**、**Screen "…" has no elements** | 空の画面にコンテンツを追加するか、画面を削除してください。リモートコンフィグのコンテンツのみを持つフローは対象外です。 |
| **Invalid interaction action** | アクションが不完全です。URLのない **Open URL**、移動先のない **Navigate to screen**、割り当てのない **Set variable**、Action IDのない **Custom**、タイトルもメッセージもない **Show alert**、対象要素のない **Show** または **Hide**、Web Paywall URLのないウェブ決済 **Purchase** が該当します。要素のインタラクションを開いて、アクションを完成させるか削除してください。 |
| **Missing navigation target** | **Navigate to screen** アクションが、削除された画面を指しています。既存の画面を選択するか、アクションを削除してください。 |
| **Missing product target**、**Invalid product target**、**Product target on another screen**、**Ambiguous product target**、**Select Product inside a component** | **Select product** アクションの対象カードが削除されている、プロダクトグループに含まれていない、別の画面にある、別の画面の要素と同じ要素IDを持つ、またはフッターやヘッダー内に配置されています。同じ画面のプロダクトグループ内にある、一意のIDを持つカードをアクションの対象に設定してください。 |
| **Missing selectable group** | 要素が、存在しないセレクタブルグループを参照しています。再接続するか、グループを再作成してください。 |
| **Invalid visibility condition** | 条件付き表示ルールが不完全です。条件ビルダーで設定を完成させてください。 |
| **Localized conditional text mismatch** | 条件付きテキストのブランチがロケールによって異なっています。すべてのロケールで同じ条件を設定してください。 |
| **Missing product reference** | 古いフローが、画面に登録されていないプロダクトを使用しています。画面を開き、**Products** パネルでプロダクトを追加してください。 |

ビルド中は定期的に [Adapty アプリでフローをプレビュー](paywall-device-compatibility-preview)してください。公開できないフローはプレビューでも表示されず、エラーメッセージで問題が確認できます。

:::tip
フローが本番環境に対応しているか確認するには、[flow-audit スキル](flow-audit-skill)を実行してください。公開エラーのチェックでは検出されない問題（機能しないボタン、ストアコンプライアンス、未完成のテキスト、翻訳の網羅性）を確認します。各問題について、レポートには該当要素とそのスクリーンが記載されます。
:::

## 「Something went wrong」というエラーで詳細なしに公開が失敗する \{#publishing-fails-with-something-went-wrong-and-no-details\}

<ZoomImage id="flow-publish-error.webp" width="300px" alt="公開失敗後の「Something went wrong」通知。サポートアドレスとコピー用のリクエストIDが表示されている" float="right" />

公開リクエストはAdapty側で失敗しており、フローの問題ではありません。ライブバージョンは変更されていません。数分待ってから再度公開してください。それでも失敗する場合は、通知に表示されている **Request ID** をコピーして [support@adapty.io](mailto:support@adapty.io) に送信してください。チームが失敗したリクエストを特定します。

## 購入時にオファーが適用されない \{#an-offer-doesnt-apply-at-purchase\}

ビルダーが確認するのは、オファーが Adapty に存在しているかどうかだけです。割引が実際に適用されるかどうかは、購入時にストアが判断します。初回オファーはユーザーの適格性に依存し、App Store のプロモーションオファーには有効な In-App Purchase Key が必要です。どちらのケースも [プロダクトと価格の不一致](store-sync#product-and-price-discrepancies) で解説しています。

## プレビューでオファー価格が空になる \{#an-offer-price-is-empty-in-the-preview\}

ビルダーのプレビューはストアに接続できないため、`offer_price`、`offer_billing_period`、`offer_full_duration` は値の代わりに変数名が波括弧付きで表示されます。これらはSDKがアプリ内でフローをレンダリングする際に解決されます。オファータイプに依存する条件をプレビューするには、[プロダクトとオファーのプレビュー](paywall-device-compatibility-preview#preview-products-and-offers)を参照してください。

## 16進数カラーの省略形入力後に公開が失敗する \{#publishing-fails-after-entering-a-shorthand-hex-color\}

カラーは必ず `#FFFFFF` のように6桁の16進数で入力してください。カラーフィールドは短い値も受け付けますが、自動的に展開されないため、`#FFF` のような省略形はSDKの設定に不正な形式で渡され、公開が拒否されます。不透明度は関係ありません——同じ値は不透明度100%でも失敗します。最もコストのかかる例外は4桁の値です。これは公開は成功しますが、意図していない色がレンダリングされます。

## タイポグラフィの変更がエレメントの状態に反映されない \{#typography-edits-dont-reach-an-element-state\}

**Selected** などの状態に独自のタイポグラフィ設定がある場合、**Default** 状態のタイポグラフィを変更しても（別のテキストスタイルを適用する場合も含む）、その状態には影響しません。各状態のタイポグラフィは直接編集してください。

## テキストスタイルを削除すると要素のスタイルが失われる \{#elements-lose-their-styling-after-a-text-style-is-deleted\}

[テキストスタイル](builder-styling#text-styles)を削除しても、そのスタイルを使用していた要素にその設定はコピーされません。削除後、それらの要素はデフォルトのタイポグラフィにフォールバックします。スタイルを削除する前に、影響を受ける要素を別のスタイルに変更するか、タイポグラフィを手動で設定してください。

## 要素の位置・サイズ・スペーシングのコントロールが表示されない \{#position-size-and-spacing-controls-are-missing-for-an-element\}

要素とそのコンテナの両方で **Free** 方向が設定されています。この場合、使用できる位置とサイズは **Absolute** のみで、幅と高さは固定されます。Adapty はそれ以外のコントロール（**Position** トグル、**Spacing** セクション、**Fill** および **Hug** オプション）をすべて非表示にします。コントロールを再表示するには、要素の [**Direction**](manage-paywall-ui-elements#direction) を **Vertical** または **Horizontal** に変更してください。

## 条件と変数が要素IDの変更後に機能しなくなる \{#conditions-and-variables-break-after-an-element-id-change\}

条件やテキスト変数は**要素ID**で要素を参照しており、IDを変更しても参照は自動的に更新されません。参照が暗黙的に解決されなくなります。要素IDは参照する前に設定してください。変更が必要な場合は、すべての条件と変数の参照を新しいIDに合わせて更新してください。例外はプログレスバーのセグメントで、セグメント名を変更すると参照が自動的に更新されます。

## 条件または変数が空の値に解決される \{#a-condition-or-variable-resolves-to-an-empty-value\}

変数ピッカーにはすべての画面のフィールドが表示されるため、条件やテキスト変数が、ユーザーがまだ入力していないフィールドを参照してしまうことがあります。実行時、そのような参照は空の値に解決されます。フロー内で前の画面で収集されたフィールドのみを参照するようにしてください。

## Set variable アクションで選択中のプロダクトが変わらない \{#a-set-variable-action-doesnt-change-the-selected-product\}

どのプロダクトが選択されているかは変数として割り当てられるものではないため、**Set variable** で選択を変更することはできません。代わりに [**Select product**](onboarding-actions#select-product) アクションを使用してください。

## 画像や動画がアップロードできない \{#an-image-or-video-wont-upload\}

フローとペイウォールビルダーのメディア制限外のファイルはアップロードできません。[画像](custom-media#image)と[動画](custom-media#video)の要件に照らしてファイルを確認してください。

| 要素 | フォーマット | 最大ファイルサイズ | その他の制限 |
| :--- | :--- | :--- | :--- |
| 画像 | `.JPG`, `.PNG`, `.WEBP` | 20 MB | — |
| 動画 | `.MP4`, `.WEBM` | 50 MB | 最大30秒、最小640×640ピクセル |

以下のフォーマットはサポートされていません。

- **アニメーションGIFおよびアニメーションWEBP**: モーションを追加するには、代わりにVideoエレメントを使用してください。
- **SVG**: ファイルをPNGまたはWEBPとしてエクスポートしてください。アイコンの場合はアップロード不要です。Iconエレメントがバンドルされた[Tabler Icons](custom-media#icon)ライブラリから描画します。

## フッターが表示されない \{#a-footer-doesnt-render\}

フッターは**縦スクロール**が有効になっている画面にのみ表示されます。[**Screen settings** > **Scroll**](paywall-layout-and-products#scroll) で**縦スクロール**を有効にしてください。
