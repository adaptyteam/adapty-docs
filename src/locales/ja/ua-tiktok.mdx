Adapty アトリビューションの TikTok for Business 連携を使うと、TikTok でのキャンペーンパフォーマンスをトラッキング・最適化できます。

:::tip
[TikTok for Business での広告設定ガイド](tiktok-create-campaign)もご覧ください。
:::

## ステップ1. TikTokアカウントを接続する \{#step-1-connect-your-tiktok-account\}

1. 左サイドバーから **Integrations > TikTok Ads** に移動し、**Continue with TikTok** をクリックします。

<ZoomImage id="ua-connect-tiktok.webp" width="700px" />

2. TikTokアカウントでサインインし、**Continue** をクリックします。

3. 要求される権限を確認し、**Save** をクリックします。

<ZoomImage id="ua-tiktok-sign.webp" width="500px" />

完了すると、すべての広告アカウントがAdapty UAに追加されます。続けてキャンペーンを追加できます。

## ステップ 2. キャンペーンを追加する \{#step-2-add-campaigns\}

1つのキャンペーンで、App Store・Google Play・Webファネルをまとめてカバーできます。連携を機能させるには、2つの要素が必要です。

- **トラッキングリンク**: 広告に挿入します。ユーザーが広告をタップすると、Adapty はクリックを記録し、ユーザーを目的地に誘導し、後でそのインストールと購入をその広告に紐付けます。各目的地には専用のリンクが割り当てられます。
- **ピクセル**: TikTok アカウントのピクセルの中からキャンペーンで選択します。コンバージョンを TikTok に送り返すことで、TikTok が実際の購入データを基にキャンペーンを最適化できます。1 つのピクセルで 3 つの目的地すべてに対応することも、目的地ごとに個別のピクセルを用意することもできます。

TikTok for Business キャンペーンを Adapty アトリビューションに追加し、TikTok 広告のパフォーマンスを Adapty で計測するには:

1. **Web Campaigns** タブに切り替えて、**Create configuration** をクリックします。

   <ZoomImage id="ua-new-campaign-tiktok.webp" width="500px" />

2. **General** タブで **iOS** および/または **Android** セクションを展開し、App Store および/または Google Play のアプリケーション URL を貼り付けます。

   <ZoomImage id="ua-url.webp" width="900px" />

3. **Click link** フィールドの値をコピーします。次に、TikTok Ads Manager で広告を作成する際、**Advanced Settings** セクション内の **Tracking URL** フィールドにこの値を貼り付けます。これにより、Adapty はインストールや購入を TikTok の広告に紐付けられるようになります。

<ZoomImage id="ua-lnk.webp" width="900px" />

4. (オプション) TikTok にコンバージョンイベントを送り返すには、TikTok のピクセルを Adapty アトリビューションのキャンペーンと紐付けることもできます。その場合は、**Pixel** ドロップダウンから既存のピクセルを選択してください。ピクセルを選択したら、**Send test event** をクリックして接続を確認できます。

**Web funnel**セクションも同じように機能します。ウェブファネルでの購入はアプリの外で行われるため、TikTokはここで選択したピクセルを通じてのみその情報を取得できます。同じセクションに、[ファネルにピクセルをインストール](ua-web-pixel)するためのスニペットと、[広告URLにタグを付ける](ua-tag-ad-urls)ためのパラメーターも記載されています。

送信先ごとに異なるピクセルを使用すると、iOS・Android・Webの購入をそれぞれ最適化とレポートで分けて管理できます。一方、すべての送信先で同じピクセルを使用すると、それらがまとめて集計されます。**Web Campaigns**リストでは、各設定ごとにこの選択内容が**Pixel (iOS)**・**Pixel (Android)**・**Pixel (Web)**の列にピクセル名とIDで表示されます。ピクセルが設定されていないセクションはダッシュ（—）で表示され、3つのセクションすべてで同じピクセルを選択した場合は、そのピクセルが3回表示されます。

## ステップ3. イベントをマッピングする \{#step-3-map-events\}

キャンペーン最適化のためにコンバージョンイベントを TikTok に送り返すには、**Events names** セクションでイベントマッピングを設定する必要があります。これにより、ユーザーがアプリ内でアクションを実行したときに、Adapty がサブスクリプションイベントを自動的に送信します。

**Events names** セクションで、TikTok Ads Manager で追跡したいイベントをオンに切り替えます。有効にした各イベントに対して、ドロップダウンから対応する TikTok イベントを選択するか、カスタムイベントを設定してください。デフォルトでは、Adapty は Adapty イベントを TikTok の標準イベントにマッピングします。

**Save** をクリックして、イベントマッピングの設定を適用します。

## 追加設定 \{#additional-configuration\}

### 追加パラメーター \{#additional-parameters\}

**Additional parameter** フィールドでは、Adapty 外での分析に使うカスタムデータを追加できます。特定のキャンペーンやユーザーデータを外部の分析ツールやアトリビューションパートナーに渡したい場合に便利です。

**Additional parameter** フィールドに、アトリビューショントラッキングに含めたいカスタムデータを入力してください。追加パラメーターは TikTok に送信されるすべてのアトリビューションデータに含まれ、高度なキャンペーン分析や最適化に活用できます。

例えば、同じキャンペーンで複数のバリエーションを実施している場合、`variant=A` や `variant=B` を追加して、異なるクリエイティブアプローチを区別することができます。

:::important
追加パラメーターを設定すると、TikTok Ads Manager に貼り付ける **Click link** が変わります。すでにこのリンクをコピーして貼り付けた後にカスタムパラメーターを追加した場合は、カスタムパラメーターを含む更新済みのクリックリンクをコピーして貼り直してください。
:::

### 設定 \{#settings\}

**Settings** タブでは、Adapty がユーザーのアクションを TikTok Ads キャンペーンに紐付ける方法を設定します。決定論的および確率論的アトリビューションマッチングの時間枠をここで指定します。

設定するには、キャンペーン設定の **Settings** タブを開きます。調整できる主な設定は次の 2 つです。

- **決定論的マッチングウィンドウ**: これはデバイスの正確な識別子（iOS の IDFA や Android の Advertising ID など）を使用して、ユーザーをキャンペーンに高精度でマッチングします。最大限のアトリビューション精度を得るために 168 時間（7 日間）に設定してください。これはデフォルトかつ推奨値です。ユーザーが TikTok 広告をクリックしてこのウィンドウ内にアプリをインストールした場合、Adapty はデバイス識別子を使ってそのインストールを特定の広告クリックに確実に紐付けることができます。

- **Probabilistic matching window**: これは統計モデリングとデバイスフィンガープリンティングを使用して、決定論的マッチングが不可能な場合にユーザーをマッチングします。ほとんどのキャンペーンではこれを6時間に設定してください。これがデフォルトであり、多くのユースケースで適切に機能します。クリック数の多いキャンペーンでは、1〜2時間に短縮することもできます。プライバシー設定などの要因で決定論的にマッチングできないユーザーについては、Adapty はこの短いウィンドウ内で確率論的マッチングを使用します。

**Save** をクリックして設定を適用します。

<ZoomImage id="ua-meta-attribution-settings.webp" width="900px" />

### 収益オーバーライド \{#revenue-override\}

トライアルイベントを追跡し、そのイベントにTikTokで収益をアトリビュートしたい場合は、**Revenue override** セクションを使用してください。このセクションは **Trial started** イベントが有効になっているときに表示されます。オーバーライドは **Trial started** にのみ適用されます — **Trial converted** と **Subscription started** は常に実際の収益を送信します。

トライアルイベントのターゲットごとに、収益として報告するサブスクリプション価格の割合を設定します。たとえば、30% に設定した場合、Adapty はトライアルイベントのコンバージョン値としてサブスクリプション価格の30%を送信します。

オーバーライドを追加するには：

1. **Events names** セクションで **Trial started** を有効にします。
2. **Revenue override** の **Add override** をクリックします。
3. 対象のイベントを選択し、収益の割合（0〜100）を入力します。
4. **Save** をクリックします。

<ZoomImage id="revenue-override.webp" width="500px" />

### 適格なトライアル \{#qualified-trial\}

トライアルは、キャンセルされずに一定時間が経過した場合に適格とみなされます。**Qualified trial** セクションを使用して、トライアルイベントが適格と判断されるまで保留することで、TikTok にはユーザーが継続したトライアルのみが送信されます。

各トライアルイベントのターゲットに対して、待機する時間数を設定してください。Adapty はトライアル開始からの時間をカウントし、期限が過ぎた時点でイベントを送信します。ユーザーが期限前に自動更新をオフにした場合、Adapty はイベントを送信しません。ユーザーが期限前に自動更新を再度オンにした場合、Adapty は予定どおりイベントを送信します。

トライアルが適格になるまでイベントを保留するには：

1. **Events names** セクションで **Trial started** を有効にします。
2. **Qualified trial** で **Add event** をクリックします。
3. 対象のイベントを選択し、1〜24 の範囲で待機時間（時間単位）を入力します。
4. **Save** をクリックします。

<ZoomImage id="qualified-trial.webp" width="700px" alt="Qualified trial section with a target event held for two hours in a campaign configuration" />

Adapty は適格イベントをトライアル開始時刻とともに送信するため、TikTok ではトライアルが開始された日として報告されます。

:::important
Adaptiyは、App StoreまたはGoogle Playのトランザクションによって対象のトライアルを照合するため、この保留はアプリ内トライアルにのみ適用されます。[FunnelFox](ua-funnelfox)などのウェブ購入からのトライアルイベントは即時に送信されます。
:::

**Revenue override** と **Qualified trial** は独立して動作するため、同じトライアルイベントに両方を適用できます。Revenue override は TikTok が受け取る値を変更し、Qualified trial は TikTok がそれを受け取るタイミングを変更します。両方を使用した場合、Adapty はトライアルが条件を満たすまでイベントを保留し、その後オーバーライドされた収益とともに送信します。どちらを推奨するかは一概には言えません。実際のキャンペーンでテストして効果を確かめてください。

### すべてのイベントを送信する \{#send-all-events\}

デフォルトでは、AdaptyはTikTokキャンペーン経由で獲得したユーザーのイベントのみを報告します。**Send all events** オプションを有効にすると、オーガニックや未アトリビューションのユーザーを含む、すべてのインストールとトランザクションが報告されます。

キャンペーンからTikTokに送られるコンバージョン数が少なく、最適化に十分でない場合を除き、この設定は推奨しません。オーガニックや未アトリビューションのイベントをキャンペーンイベントと混在させると、TikTokの最適化精度が低下するためです。

**Send all events (forward organic/non-attributed events to this pixel)** をオンにする場合は、キャンペーン設定でこのオプションを選択し、**Save** をクリックしてください。
