アプリがAdaptyに接続できない場合にバンドルする[フォールバックファイル](fallback-flows)をダウンロードします。これは**Placements**ページの**Fallbacks**ダウンロードと同じファイルです。

## adapty fallbacks get

```bash
adapty fallbacks get --app <app-id> --platform ios --sdk-version 4.4.0 --output ios_fallback.json
```

| フラグ | 必須 | 説明 |
|---|---|---|
| `--app` | Yes | アプリ ID（UUID） |
| `--platform` | Yes | App Store の場合は `ios`、Google Play の場合は `android`。macOS および visionOS アプリは `ios` ファイルを使用します。 |
| `--sdk-version` | Yes | アプリに組み込まれている Adapty SDK のバージョンを `X.Y.Z` 形式で指定します。Flutter、React Native、Unity、Kotlin Multiplatform、Capacitor の場合は Adapty プラグインのバージョンを渡してください。 |
| `--output` | No | 書き込み先のファイル。親ディレクトリは自動的に作成されます。指定しない場合、ファイルは標準出力に出力されます。 |

1つのファイルでアプリの全プレースメントをカバーします。両方のストアに対応するには、`--platform ios` と `--platform android` を指定してコマンドをそれぞれ1回ずつ実行してください。

ファイルにはライブのプレースメントのみが含まれるため、フローを公開してプレースメントをアクティブにしてからダウンロードしてください。プレースメントを変更したり SDK をアップグレードした後は、再度ダウンロードしてください。ファイルはスナップショットです。

Adapty は `--sdk-version` からファイル形式を決定します。SDK は自身がビルドされた形式のみを受け付け、それ以外のファイルは起動時にビルドエラーなしで拒否します。

| `--sdk-version` | ファイル形式 |
|---|---|
| 4.4.0 以降 | 12 |
| 4.1.x – 4.3.x | 11 |
| 4.0.x | 10 |
| 3.12.x 以降の 3.x | 9 |
| 3.8.x – 3.11.x | 8 |
| 3.4.x – 3.7.x | 7 |
| 3.0.x – 3.3.x | 6 |
| 3.0 未満 | 5 |

ペイウォールのプレースメントはすべての形式に含まれています。フローのプレースメントは SDK 4.0 以降向けのファイルにのみ含まれています。

`--output` を使うと、ダウンロードが完全に成功した後にのみファイルへ書き込まれるため、実行が失敗しても以前のファイルが保持されます。`--output` なしの場合、標準出力にはファイルの内容のみが流れ、エラーはすべて標準エラー出力へ送られます。`> file` のようなリダイレクトはリクエスト開始前にファイルを空にしてしまうため、`--output` を使用してください。

Adapty はファイル全体をビルドしてから応答するため、大規模なアプリでは数分かかる場合があります。このコマンドはリクエストを1回送信するだけで、リトライは行いません。各アプリはすべてのトークンを合わせて1時間あたり30回ファイルをダウンロードできます。上限を超えると、待機時間を示すレート制限エラーが返されます。ファイルのダウンロードはリリースビルド時に行い、コミットのたびに実行しないようにしてください。

| 終了コード | 意味 |
|---|---|
| `0` | ファイルが書き込まれた |
| `1` | ファイルを書き込めなかった。以前のファイルは変更されていない。 |
| `2` | 無効なフラグ値 |
| `3` | トークンがないか、アクセスが拒否された |
| `4` | レート制限を含むAPIエラー、またはフォールバックファイル以外のレスポンス |
| `5` | Adaptyに到達できなかった、300秒以内に応答がなかった、またはダウンロードが中断された |
