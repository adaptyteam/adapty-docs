Adaptyは、HTTPステータスコードに基づいて配信可否を判断し、`200-399`の範囲外のレスポンスをすべて失敗とみなします。

インテグレーションイベントのステータスは、Adapty ダッシュボードの **Event List** で確認できます。特定のイベントタイプが該当インテグレーションで有効になっているかどうかに関わらず、有効なすべてのインテグレーションのステータスが表示されます。

- 黒：イベントが正常に送信された。
- <span style={{ color: 'grey' }}>グレー：</span> このインテグレーションではイベントタイプが無効になっている。
- <span style={{ color: 'red' }}>赤：</span> インテグレーションに注意が必要な問題がある。

失敗したイベントの詳細を確認するには、インテグレーション名にカーソルを合わせると、具体的なエラー情報を示すツールチップが表示されます。

イベントが完全に見当たらない場合は、[イベントフィードにイベントが表示されない](event-feed#an-event-is-missing-from-the-feed)でその理由を確認できます。
