フローをローカライズして、国際ユーザーにそれぞれのロケールに合ったコンテンツをその言語で提供できます。以下の要素を翻訳またはカスタマイズできます：

- フロー内のすべての文字列。
- [各 **Open URL** アクションのURL](#action-urls)。
- 画像と動画（[ロケールごとに個別ファイル](#images-and-videos)を使用）。

<Inline id="localizations.svg" alt="Localizations" /> **Localizations** パネルには、すべての文字列とアクションURLが一つのテーブルにまとめられています。各ロケールは列、各文字列は行として表示されます。セルの翻訳は手動で行うことも、AIを使うことも、サードパーティの翻訳者向けにエクスポートすることもできます。画像と動画はテーブルには含まれておらず、プロパティパネルでローカライズします。

<ZoomImage id="locales-table.webp" width="700px" alt="ロケールタブ、フィルター、ローカライズテーブルが表示されたLocalizationsパネル" />

ユーザーにロケールを表示するには、アプリが[フロービュー設定リクエスト](get-pb-paywalls#fetch-the-view-configuration)で[ロケールコードを渡す](localizations-and-locale-codes)必要があります。翻訳が存在しない値は、デフォルトロケール（[別のロケールをデフォルトに設定](#set-the-default-locale)しない限り英語）で指定されたコンテンツにフォールバックします。

:::tip
他の言語を追加する前に、デフォルトロケールでフローの設定を完了してください。
:::

## ローカライズできる内容 \{#what-you-can-localize\}

### テキストコンテンツ \{#text-content\}

**Localizations** パネルには、フロー内のすべての文字列の行が含まれます。例えば以下のようなものです：

- ボタンラベルなど、各テキスト要素のコンテンツ。
- 各入力フィールドの **Placeholder**。
- 各 **Show alert** アクションのタイトルとメッセージ。

:::note
[変数](onboarding-variables)が他のロケールでどのように表示されるかは、その値がどこから来るかによって異なります：

- **Product variables**: The store returns their values already localized. A string that only contains a product variable, such as a price, needs no translation.
- **Custom and element variables**: Their values cannot be localized. For example, `selectedOptionTitle` shows the selected option's **Element Title** exactly as you entered it. Use static or conditional text instead.
:::

### 条件付きテキスト \{#conditional-text\}

テキスト要素は、設定した条件に応じて[異なるコンテンツ](onboarding-text#add-conditional-text)を表示できます。条件付きテキストの各分岐をローカライズすることができます。

:::note
条件はすべてのロケールで同一です。条件が変数と文字列を比較する場合、その文字列はローカライズされません。
:::

### アクションURL \{#action-urls\}

**Open URL** アクションは、ロケールごとに異なるURLを開くことができます。たとえば、ユーザーの言語に対応したヘルプページを開く場合などに使用します。独自のURLが設定されていないロケールでは、デフォルトロケールのURLが開かれます。デバイス上では、SDKはアプリに渡すロケールコードではなく、アプリの現在の言語に基づいてURLを選択します。

### 画像と動画 \{#images-and-videos\}

画像と動画の要素は、[ロケールごとに異なるファイルを表示](#localize-images-and-videos)できます。独自のファイルが設定されていないロケールでは、デフォルトロケールのファイルが表示されます。**Localizations** パネルには、画像と動画は表示されません。アイコンや[画面・コンテナの背景](custom-media#limitations)はローカライズできません。

## ローカライゼーションと翻訳の管理 \{#manage-localizations-and-translations\}

### ロケールを追加して設定する \{#add-and-set-up-a-locale\}

1. 左側の <Inline id="localizations.svg" alt="Localizations" /> Localizations パネルを開き、**Add locale** をクリックします。
2. **Select languages** フィールドで、1 つまたは複数の言語を選択します。
3. （省略可）新しいロケールへの翻訳をすぐに行う場合は、**Translate content from default locale using AI** を選択します。
4. **Add locales** をクリックします。

<ZoomImage id="new-locale-flow.webp" width="500px" alt="Add locales dialog" />

各ロケールはローカリゼーションテーブルの列に対応しています。行はフロー内の文字列と[アクションURL](#action-urls)で、[条件付きテキスト](#conditional-text)の各分岐も含まれます。テーブルはスクリーンごとにセクションにまとめられています。

<ZoomImage id="locales-sidebar.webp" width="250px" float="right" alt="Locale tabs in the Localizations panel sidebar, with a pin on the default locale and a percentage on each other locale" />

パネルのサイドバーには、各ロケールの進捗状況が翻訳済みセルの割合として表示されます。各画面のセクションヘッダーには、すべてのロケールにわたるその画面の進捗状況が表示されます。パネルはデフォルトロケールのテキストが未翻訳のままでも、値が入力されていれば翻訳済みとしてカウントします。

翻訳が欠落している行には **Missing** バッジが表示されます。空のセルにはデフォルトロケールのテキストがグレーアウトして表示されます。

### AIによる文字列の翻訳 \{#translate-strings-with-ai\}

AIはデフォルトロケールの文字列を他のロケールに翻訳します。[アクションURL](#action-urls)は翻訳されません。

パネルヘッダーの **AI Translate** を開き、以下のいずれかを選択します。

- **Translate missing only**：空のセルを翻訳し、既存の翻訳はそのまま保持します。
- **Translate all**：すべてのセルを翻訳し、手動で編集したものも含めて既存の翻訳を上書きします。

<ZoomImage id="locales-ai-translate.webp" width="700px" alt="AI Translate menu in the Localizations panel header, with Translate missing only and Translate all" />

You can only translate the rows that the [filters](#filter-rows) show. To translate only some rows or locales, select their checkboxes first.

If an AI translation changes a variable or the text formatting, Adapty discards that translation and keeps the cell's previous value.

### デフォルトロケールの設定 \{#set-the-default-locale\}

ピンアイコン <Inline id="pin.svg" alt="Pin" /> はデフォルトロケールを示します。デフォルトロケールはソースコンテンツを保持し、翻訳が欠けている場合のフォールバックとして機能します。すべてのフローは、英語をデフォルトかつ唯一のロケールとして開始します。

デフォルトロケールを変更する前に、置き換え先のロケールに翻訳を入力してください。ロケールが不完全な状態でデフォルトになった場合、Adapty は以前のデフォルトロケールのコンテンツで補完します。その場合、フィールドに翻訳が **Missing** として表示されなくなります。

デフォルトのロケールを変更するには、対象ロケールの列ヘッダーで **Locale actions** を開き、**Set as default** を選択します。

<ZoomImage id="flow-builder-set-default-locale.webp" width="500px" alt="ロケール列の Locale actions メニュー（Set as default がハイライト表示されている）" />

### ロケールを削除する \{#delete-a-locale\}

ロケールを削除するには、その列ヘッダーにある **Locale actions** を開き、**Delete locale** を選択します。Adapty はロケール固有のコンテンツ（画像や動画を含む）をすべて削除します。ロケールを復元するには、削除を元に戻してください。デフォルトのロケールを削除するには、まず[別のロケールをデフォルトに設定](#set-the-default-locale)してください。

### テーブルの操作 \{#table-actions\}

1つの操作で多くのセルをまとめて変更でき、1回のアンドゥですべての変更を元に戻せます。

#### 行のフィルタリング \{#filter-rows\}

パネルのサイドバーでフィルターを設定すると、テーブルに表示される行を絞り込めます：

- **Screens** — 画面の選択を絞り込みます {/*, and hides reusable components*/}。
- **Status** > **Missing only** — すべてのロケールに翻訳が存在する行を非表示にします。

一括操作は表示中の行にのみ適用されます。フィルターをオンにすると、一括操作の対象範囲が限定されます。ロケール全体またはフロー全体を翻訳・リセットするには、先にフィルターをオフにしてください。

#### ロケールの管理 \{#manage-a-locale\}

列のコンテキストメニュー <Inline id="collapse-layer.svg" alt="Locale actions" /> を開くと、単一ロケールをまとめて管理できます：

- **Set as default**: ロケールを[デフォルトロケール](#set-the-default-locale)に設定します。
- **Import** と **Export**: ロケールの[翻訳ファイルをインポートまたはエクスポート](#localize-content-externally)します。
- **AI Translate locale**: ロケールの列全体をデフォルトロケールから[AIを使って翻訳](#translate-strings-with-ai)します。
- **AI Translate missing only**: ロケールの空のセルを[AIを使って翻訳](#translate-strings-with-ai)します。
- **Reset to default (…)**: ロケールのすべての翻訳を削除します。
- **Delete locale**: [ロケールとそのコンテンツを削除](#delete-a-locale)します。

<ZoomImage id="flow-builder-set-default-locale.webp" width="500px" alt="Locale actions menu of a locale column" />

#### 行を管理する \{#manage-a-row\}

行のコンテキストメニュー <Inline id="context.svg" alt="Row context menu" /> を開くと、1つの文字列をすべてのロケールごとまとめて管理できます：

- **AI Translate missing only**: 空のセルを [AIで](#translate-strings-with-ai)翻訳します。
- **AI Translate row**: デフォルトロケールから行全体を [AIで](#translate-strings-with-ai)翻訳します。
- **Reset to default**: 行内のすべての翻訳を削除します。

<ZoomImage id="locales-row-menu.webp" width="600px" alt="Row context menu with AI Translate missing only, AI Translate row, and Reset to default" />

#### セル操作 \{#cell-actions\}

セルのコンテキストメニュー <Inline id="context.svg" alt="Cell context menu" /> を開くと、セルの値を個別に管理できます。

- **Add variable**: セルに[変数](onboarding-variables)を挿入します。
- **Copy** と **Paste here**: セルの値を、書式設定や変数ごとコピーして別のセルに貼り付けます。
- **AI Translate**: セルを[AIで翻訳](#translate-strings-with-ai)します。
- **Push value to all locales**: セルのテキストをデフォルト以外のすべてのロケールにコピーし、その行を翻訳済みとしてカウントします。ブランド名や[プロダクト変数](#text-content)のみを含む文字列など、どの言語でも同じテキストの場合、行全体を一度に埋めることができます。セルを編集した後にコピーを更新するには、再度プッシュしてください。
- **Clear translation**: セルを空にして、そのロケールのユーザーにデフォルトロケールのテキストが表示されるようにします。

<ZoomImage id="locales-cell-menu.webp" width="400px" alt="セルのツールバーとコンテキストメニュー。変数を追加、コピー、ここに貼り付け、AI翻訳、すべてのロケールに値をプッシュ、翻訳をクリアが表示されています" />

## ビルダーでコンテンツをローカライズする \{#localize-content-in-the-builder\}

文字列を翻訳してアクションURLを設定するには、**Localizations** パネルを開きます。[手動で翻訳する](#translate-strings-manually)、[AIを使って翻訳する](#translate-strings-with-ai)、または[ローカライズファイルをエクスポート](#localize-content-externally)してサードパーティの翻訳者に渡すことができます。

画像や動画をローカライズするには、[対象要素のプロパティを編集](#localize-images-and-videos)します。

### 文字列を手動で翻訳する \{#translate-strings-manually\}

**Localizations** パネルの表には、フロー内のすべての文字列が含まれています。

- 静的テキスト（要素ごとに1行）
- 条件付きテキスト（分岐ごとに1行）
- **Open URL** アクションのターゲット（URLごとに1行）

文字列を翻訳するには、セルをクリックして翻訳を入力します。[変数](onboarding-variables)を挿入するには、セル内の **&#123; &#125;** をクリックします。文字列の行を見つけるには、プレビューでその[要素を選択](builder-ui#preview-area-center)してください。

各条件付きテキスト要素は、それぞれ独立した行グループです。矢印 <Inline id="expand-layer.svg" alt="Expand" /> をクリックしてグループを展開し、すべての条件ブランチを確認できます。

<ZoomImage id="locales-conditional-text.webp" width="700px" alt="Conditional text expanded in the Localizations panel, with a row for each branch and its translations" />

### ロケール別アクションURLの設定 \{#set-locale-specific-action-urls\}

**Open URL** アクションにはそれぞれ専用の行があります。特定のロケールに別の[URL](#action-urls)を設定するには、そのロケールの列のセル値を変更します。URLがどの要素に属しているかを確認するには、その行をクリックしてください。ビルダーがプレビュー内で該当する要素を選択します。

### 画像と動画のローカライズ \{#localize-images-and-videos\}

ロケールごとに異なる画像や動画を表示するには、そのロケール用のファイルを個別にアップロードします。

1. **Localizations** パネルが開いている場合は閉じます。
2. [ボトムツールバー](builder-ui#view-controls-bottom-toolbar)で現在のロケールを切り替えます。
3. 画像または動画要素を選択し、ローカライズしたファイルをアップロードします。
4. 作業が完了したら、**Locale** をデフォルトに戻します。別のロケールがアクティブな間は、プロパティパネルでの編集はそのロケールにのみ適用されます。

<ZoomImage id="image-localization-demo.webp" width="500px" alt="アクティブなロケールが変わるとキャンバス画像も変わる" />

## コンテンツを外部でローカライズする \{#localize-content-externally\}

フロー内のテキスト全体を、翻訳サービスや自社の翻訳者を使って Adapty の外部で翻訳するには、[ローカライゼーションファイルをエクスポート](#export-the-localization-file)してください。翻訳が完成したら、ファイルを[インポート](#import-the-file-with-a-translation)して戻します。

### ローカライズファイルのエクスポート \{#export-the-localization-file\}

テーブルヘッダーの **Import / Export** をクリックすると、すべてのロケールを含むフロー全体をエクスポートできます。[列のコンテキストメニュー](#manage-a-locale)の **Export** をクリックすると、個別のロケールをソースロケールと一緒にエクスポートできます。

<ZoomImage id="import-export.webp" width="700px" alt="ローカライズパネルのヘッダーにある Import / Export メニュー" />

### インポート / エクスポートファイルの形式 \{#import--export-file-format\}

ローカライズファイルは UTF-8 エンコードの `.tsv`（タブ区切り）形式で、1 行につき 1 つの文字列またはアクション URL が含まれます。エクスポートファイルはフロー全体を対象とし、パネルで設定したフィルターには関係なく全件が出力されます。インポートする際は、ファイルの形式を変更しないでください。列の構成は次のとおりです：

| カラム | 説明 |
|--------|-------------|
| `id` | 行の識別子です。Adapty はインポート時にこれで行を照合するため、変更しないでください。フローに存在しない `id` を持つ行は無視されます。 |
| `Screen` | 文字列が属する画面{/* or reusable component*/}です。Adapty はインポート時にこのカラムを無視します。 |
| `[locale]` | ロケールごとに1カラム用意し、ロケールコード（例：`en`、`fr`）で名前を付けます。フローに存在しないロケールのカラムは無視されます。 |

例：

```
id	Screen	en	fr	es
lc_1	Welcome	Turn words into art	Transformez les mots en art
lc_2	Welcome	Start your <b>free trial</b>	Commencez votre <b>essai gratuit</b>
lc_3	Quiz	What will you create?
```

エクスポートされたファイルについて：

- フォーマットは `<b>` などのHTMLタグとして、変数は `{{name}}` の形式で表示されます。インポート時にAdaptyが復元するため、そのまま残してください。
- [条件付きテキスト](#conditional-text)の各分岐はそれぞれ独自の行を持ち、条件は含まれません。
- 画像や動画は含まれません。[ビルダーでローカライズ](#localize-images-and-videos)してください。

エクスポート後に追加した文字列を翻訳するには、ファイルを再度エクスポートしてください。

Adaptyは、`Screen`、`Element`、`Property`列を含む古い形式のファイルをインポートできません。翻訳を再利用するには、フローを再度エクスポートし、新しいファイルにコピーしてください。

### ファイルを使って翻訳をインポートする \{#import-the-file-with-a-translation\}

:::warning
ファイル内のセルが空の場合、デフォルトロケールの列を除き、Adapty はインポート時にそのセルの翻訳を削除します。ロケールの翻訳を保持するには、エクスポート時の状態のままセルを残すか、そのロケールの列をファイルから削除してください。インポートによって保持したかった翻訳が消えた場合は、インポートを元に戻してください。インポート全体が1つの元に戻す操作として処理されます。
:::

フロー全体をインポートするには、テーブルヘッダーの **Import / Export** をクリックして **Import** を選択します。1つのロケールをインポートするには、[列のコンテキストメニュー](#manage-a-locale)で **Import** を選択します。その後、翻訳済みのファイルを選択します。

ファイルに行がない文字列は現在の値を保持します。フロー全体のインポートは、ファイルが変更した箇所のデフォルトロケールのテキストを更新します。1つのロケールのインポートは、インポートするロケールのみを変更します。新しい言語をインポートするには、まず[ロケールを追加](#add-and-set-up-a-locale)してください。

## 異なるロケールをプレビューする \{#preview-different-locales\}

プレビューエリアには、常にアクティブなロケールのテキストが表示されます。プロパティパネルでテキスト内容を編集すると、その変更は該当のロケールにのみ適用されます。ソースコンテンツを編集するには、デフォルトのロケールに切り替えてください。

- アクティブなロケールを切り替えるには、[下部ツールバー](builder-ui#view-controls-bottom-toolbar)の **Locale** ドロップダウンから選択するか、**Localizations** パネルのタブをクリックします。
- **Localizations** パネルからアクティブな画面を切り替えるには、セクションヘッダーの **View screen** <Inline id="eye.svg" alt="View screen" /> をクリックします。
- ローカライゼーションテーブルを画面全体に広げるには、**Hide preview** をクリックします。

<ZoomImage id="preview-locales.webp" width="500px" alt="Locale preview in Flow & Paywall Builder" />

未翻訳のテキストをすべての画面でプレビューせずに見つけるには、[flow-audit スキル](flow-audit-skill)を実行してください。
