**カウントダウンタイマー**は、固定の時間からゼロに向かってカウントダウンするか、指定した日時までカウントダウンします。ゼロに達すると、表示が止まります。

## テンプレート \{#templates\}

<ZoomImage id="countdown-templates.webp" width="200px" alt="カウントダウンタイマーのテンプレート" float="left" />

このカテゴリーには4つのビジュアルバリアントがあります：

- **Blocks** — 日・時・分・秒をそれぞれラベル付きのセルに分けて表示します。
- **Inline Units** — 単位のサフィックスを付けた1行テキスト表示です。
- **Inline** — 数字のみの表示です。
- **Badge** — ピル形状の数字表示です。

## 設定 \{#settings\}

<ZoomImage id="builder-countdown-settings.webp" width="300px" float="right" alt="右パネルのカウントダウンタイマー設定" />

### 期間を設定する \{#set-the-duration\}

右パネルの **Countdown** セクションで、日・時・分・秒の開始期間を入力します。時間フィールドには最大999まで入力できるため、72時間のカウントダウンを `3d` ではなく `72h` として入力することもできます。どちらも同じカウントダウンになりますが、23を超える時間は `timer_days` では丸1日としてカウントされます。

**Until date** の動作が設定されたタイマーには期間がありません。終了日時を設定するには、[特定の日付までカウントダウンする](#count-down-to-a-date)を参照してください。

### タイマーの時間形式を変更する \{#change-the-time-format\}

タイマー内のテキストは、タイマー変数を使って残り時間を表示します。タイマーに表示する単位を変更するには、タイマー内のテキスト要素を選択し、**Content** セクションで <Inline id="variables.svg" alt="Variables" /> **Add variable** をクリックして、タイマー変数を選択してください。

| 変数 | 表示内容 | 53時間のカウントダウン開始時の値 |
|---|---|---|
| `timer_days` | 残り日数（端数切り捨て） | `02` |
| `timer_hours` | 現在の日の中の残り時間（0〜23） | `05` |
| `timer_total_hours` | 残り総時間（日数分を含む） | `53` |
| `timer_minutes` | 現在の時間内の残り分 | `00` |
| `timer_seconds` | 現在の分内の残り秒 | `00` |

1日以上のカウントダウンを `48:00:00` や `72:00:00` のように時間のみで表示するには、`timer_total_hours:timer_minutes:timer_seconds` を使用してください。同じテキストに `timer_days` を追加しないでください。`timer_total_hours` にはすでに日数が含まれているため、二重カウントになってしまいます。

### 動作の設定 \{#configure-the-behavior\}

**Behavior** ドロップダウンでは、タイマーの開始タイミングを制御したり、指定した日付までのカウントダウンに設定したりできます。

- **Every appear** — ユーザーが画面を開くたびに再スタートします。デフォルト。
- **First appear** — 現在のアプリセッション中にユーザーが初めて画面を表示したときに開始されます。同じセッション内で画面に戻った場合もカウントを継続し、アプリを新たに起動するとリセットされます。
- **First appear (persisted)** — ユーザーが初めて画面を開いたときに開始され、アプリを再起動してもカウントを継続します。
- **Until date** — セールの終了日時など、指定した日時までカウントダウンします。[日付までカウントダウン](#count-down-to-a-date)を参照してください。

### 日付までカウントダウン \{#count-down-to-a-date\}

<ZoomImage id="flow-timer-until-date.webp" width="300px" float="right" alt="「Until date」に設定されたBehaviorのカウントダウンセクション：End date 28.11.2026、Time 23:59、Time zone Europe/Berlin、User's local timeチェックボックスはオフ" />

ブラックフライデーセールのような期間限定キャンペーンの残り時間を正確に表示するには、期間からカウントダウンするのではなく、キャンペーン終了日時に向けてカウントダウンします：

1. **Behavior** ドロップダウンで **Until date** を選択します。期間フィールドが終了日フィールドに切り替わります。
2. **End date** フィールドで、キャンペーンの最終日を選択します。
3. **Time** フィールドに、終了の時刻（時と分）を入力します。デフォルトは 23:59 です。
4. **Time zone** ドロップダウンで、終了のタイムゾーンを選択します。デフォルトはブラウザのタイムゾーンです。

タイムゾーンを選択した場合、終了時刻はすべてのユーザーで同一です。異なる日にスクリーンを開いた2人のユーザーも、同じ瞬間に同じ残り時間を確認でき、スクリーンを再度開いてもアプリを再起動しても、タイマーはリセットされません。

各ユーザーのタイムゾーンで同じ時刻（例：各地域の深夜0時）にキャンペーンを終了するには、**User's local time** を選択します。各デバイスはそれぞれの時計で設定した日時までカウントダウンするため、異なるタイムゾーンのユーザーはそれぞれ異なるタイミングでゼロに達します。

終了日時になると、タイマーはゼロを表示し、**On timer end** トリガーが実行されます。終了後に画面を開いたユーザーはすぐにゼロを確認でき、トリガーは画面を開くたびに1回実行されます。タイマーは画面上に残り続けます。セール終了後にタイマーや割引バッジを非表示にするには、**On timer end** トリガーに **Hide element** アクションを追加してください（[要素の表示・非表示](flow-show-hide-animations#show-or-hide-an-element)を参照）。

:::note
**Until date** タイマーに終了日が設定されていない場合、ビルダーはフローを公開しません。終了日がなくても保存は可能です。過去の終了日も有効で、その場合タイマーは最初からゼロを表示します。
:::

タイマーはデバイスの時計をもとにカウントダウンするため、ユーザーがデバイスの時計を変更すると、残り時間も変わります。

### タイマーが終了したときにアクションを実行する \{#trigger-an-action-when-the-timer-ends\}

:::link
メイン記事: [アクション](onboarding-actions)
:::

カウントダウンがゼロになったときにアクションを実行するには、**On timer end** トリガーを追加します。たとえば、別のスクリーンに移動したり、割引バッジを非表示にしたりできます。

## 閉じるボタンが表示されるまでの遅延 \{#delay-when-a-close-button-appears\}

閉じるボタンの表示を遅らせるには、[**Show element** アクションを使用します](flow-show-hide-animations#show-an-element-a-few-seconds-after-the-screen-opens):

1. **Close** ボタンをスクリーンに追加し、**Design** パネルの **Visibility** を **Hide** に設定します。
2. **On Screen Appear** トリガーに **Show element** アクションを追加し、閉じるボタンをターゲットに指定します。
3. **Delay** フィールドで、ボタンが表示されるまでの時間を最大 5000 ms で設定します。

これらの手順は、旧ペイウォールビルダーの **Show after delay** オプションを置き換えるものです。

For a delay longer than 5 seconds, replace steps 2 and 3 with a Countdown timer that users don't see:

1. カウントダウンタイマー要素を同じスクリーンに追加します。**Visibility** は **Show** のまま残し、テキスト内の数字も残して、**On timer end** トリガーが発火するようにします。
2. カウントダウンが見えないようにするため、テキストを完全に透明にするか、背景と同じ色に設定します。
3. タイマーの時間を、閉じるボタンが表示されるまでの遅延時間に設定します（[時間を設定する](#set-the-duration) を参照）。
4. タイマーに **On timer end** トリガーを追加し、閉じるボタンを対象とした **Show element** アクションを設定します（[要素を表示または非表示にする](flow-show-hide-animations#show-or-hide-an-element) を参照）。

タイマーがゼロになると、**Show element** アクションによってクローズボタンが表示されます。
