**カウントダウンタイマー**は、設定した時間からゼロに向かってカウントダウンし、ゼロに達すると表示が止まります。

## テンプレート \{#templates\}

<ZoomImage id="countdown-templates.webp" width="200px" alt="カウントダウンタイマーのテンプレート" float="left" />

このカテゴリーには4つのビジュアルバリアントがあります：

- **Blocks** — 日・時・分・秒をそれぞれラベル付きのセルに分けて表示します。
- **Inline Units** — 単位のサフィックスを付けた1行テキスト表示です。
- **Inline** — 数字のみの表示です。
- **Badge** — ピル形状の数字表示です。

## 設定 \{#settings\}

<ZoomImage id="builder-countdown-settings.webp" width="300px" float="right" alt="右パネルのカウントダウンタイマー設定" />

### 継続時間を設定する \{#set-the-duration\}

右パネルの **Countdown** セクションで、開始時間を日・時・分・秒で入力します。時間フィールドには最大999まで入力できるため、72時間のカウントダウンを`3d`ではなく`72h`として入力できます。どちらも同じカウントダウンになります。23を超えた時間は`timer_days`で引き続き丸1日としてカウントされます。

### タイマーの時間形式を変更する \{#change-the-time-format\}

タイマー内のテキストは、タイマー変数を使って残り時間を表示します。タイマーに表示する単位を変更するには、タイマー内のテキスト要素を選択し、**Content** セクションで <Inline id="variables.svg" alt="Variables" /> **Add variable** をクリックして、タイマー変数を選択してください。

| 変数 | 表示内容 | 53時間のカウントダウン開始時の値 |
|---|---|---|
| `timer_days` | 残り日数（端数切り捨て） | `02` |
| `timer_hours` | 現在の日の中の残り時間（0〜23） | `05` |
| `timer_total_hours` | 残り総時間（日数分を含む） | `53` |
| `timer_minutes` | 現在の時間内の残り分 | `00` |
| `timer_seconds` | 現在の分内の残り秒 | `00` |

1日以上のカウントダウンを `48:00:00` や `72:00:00` のように時間のみで表示するには、`timer_total_hours:timer_minutes:timer_seconds` を使用してください。同じテキストに `timer_days` を追加しないでください。`timer_total_hours` にはすでに日数が含まれているため、二重カウントになってしまいます。

### 動作を設定する \{#configure-the-behavior\}

**Behavior** ドロップダウンでタイマーの開始タイミングを設定します：

- **Every appear** — ユーザーが画面を開くたびに再スタートします。デフォルト設定です。
- **First appear** — 現在のアプリセッション中にユーザーが初めて画面を表示したときにスタートします。同じセッション中に戻ってきた場合はカウントを継続し、アプリを新たに起動するとリセットされます。
- **First appear (persisted)** — ユーザーが初めて画面を開いたときにスタートし、アプリを再起動してもカウントを継続します。

### タイマーが終了したときにアクションを実行する \{#trigger-an-action-when-the-timer-ends\}

:::link
メイン記事: [アクション](onboarding-actions)
:::

カウントダウンがゼロになったときにアクションを実行するには、**On timer end** トリガーを追加します。たとえば、別のスクリーンに移動したり、割引バッジを非表示にしたりできます。

## 閉じるボタンが表示されるまでの遅延 \{#delay-when-a-close-button-appears\}

閉じるボタンの表示を遅らせるには、[**Show element** アクションを使用します](flow-show-hide-animations#show-an-element-a-few-seconds-after-the-screen-opens):

1. **Close** ボタンをスクリーンに追加し、**Design** パネルの **Visibility** を **Hide** に設定します。
2. **On Screen Appear** トリガーに **Show element** アクションを追加し、閉じるボタンをターゲットに指定します。
3. **Delay** フィールドで、ボタンが表示されるまでの時間を最大 5000 ms で設定します。

これらの手順は、旧ペイウォールビルダーの **Show after delay** オプションを置き換えるものです。

For a delay longer than 5 seconds, replace steps 2 and 3 with a Countdown timer that users don't see:

1. カウントダウンタイマー要素を同じスクリーンに追加します。**Visibility** は **Show** のまま残し、テキスト内の数字も残して、**On timer end** トリガーが発火するようにします。
2. カウントダウンが見えないようにするため、テキストを完全に透明にするか、背景と同じ色に設定します。
3. タイマーの時間を、閉じるボタンが表示されるまでの遅延時間に設定します（[時間を設定する](#set-the-duration) を参照）。
4. タイマーに **On timer end** トリガーを追加し、閉じるボタンを対象とした **Show element** アクションを設定します（[要素を表示または非表示にする](flow-show-hide-animations#show-or-hide-an-element) を参照）。

タイマーがゼロになると、**Show element** アクションによってクローズボタンが表示されます。
