**プロファイル**とは、プロジェクト内の一人の顧客を指します。**Profiles** ページには Adapty Mail が把握しているすべての顧客が一覧表示され、各顧客の購入結果、メールエンゲージメント、アクティビティの全履歴を確認できます。

プロファイルは、設定した[エントリーポイント](mail-entry-points)を通じて自動的に届きます。メールアドレスが登録の必須条件です。メールアドレスを提供していない顧客のプロファイルは、Adapty Mail では作成されません。

:::tip
フローや A/B テスト用に再利用可能なオーディエンスにプロファイルをグループ化するには、[セグメント](mail-segments)をご覧ください。
:::

## プロファイルが Adapty Mail に取り込まれる仕組み \{#how-profiles-get-into-adapty-mail\}

Adapty Mail は、次の3つのソースからプロファイルを自動的に作成します。

- **Adapty**: Adapty SDK がアプリからメールアドレスと購入情報を収集します。詳しくは [Adapty を Adapty Mail に接続する](mail-collect-emails) をご覧ください。
- **Adapty Mail API**: バックエンドからサーバー間でプロファイルとトランザクションを送信します。詳しくは [API 経由でデータを送信する](mail-send-data-via-api) をご覧ください。
- **FunnelFox**: ウェブファネルからメールアドレス、購入情報、サブスクリプションイベントを転送します。詳しくは [FunnelFox を Adapty Mail に接続する](mail-funnelfox) をご覧ください。

Adapty Mail はメールアドレスでユーザーを照合します。同じアドレスを報告する2つのソースは1つのプロファイルにまとめられ、`customer_user_id` が同一であっても異なるアドレスは別々のプロファイルとして作成されます。各ソースはそれぞれ独自の識別子を保持し、プロファイルページにはそれらすべてが **External Profile IDs** の下に一覧表示されます。

Adapty も併用している場合、ここでのプロファイルはAdapty のプロファイルとは異なります。Adapty Mail は独自のレコードを管理しており、Adapty のプロファイル ID は外部 ID のひとつとして保存されます。メールアドレスのない Adapty プロファイルはここに届かないため、Adapty よりもプロファイル数が少なくなることを想定してください。

プロファイルの作成や編集はここではできません（データはそれを送信したソースが所有しています）が、登録解除や削除は可能です。

## プロファイル一覧 \{#the-profiles-list\}

一覧には1行につき1プロファイルが表示され、新しい順に並んでいます。検索ボックスを使って、メールアドレス、プロファイルID、または外部プロファイルIDでプロファイルを検索できます。

| 列 | 内容 |
| --- | --- |
| Profile | 顧客のメールアドレスと、最後のメールイベントに紐づくキャンペーン。 |
| Status | プロファイルの購入ステータス。[プロファイルステータス](#profile-status)を参照。 |
| Country | 顧客の国。 |
| Open rate | 送信数に対する開封数の割合。まだメールが送信されていない場合はダッシュ表示。 |
| LTV | ライフタイムバリュー — 全ソースを合算したこのプロファイルの累計収益。 |
| Joined | プロファイルが Adapty Mail に初めて登録された日時。 |
| Last activity | プロファイルの最後のメールイベントが発生した日時。開封やクリックだけでなく、送信もカウントされます。 |

:::important
**Joined** は、プロファイルが初めて Adapty Mail に登録された日付であり、「顧客開始日」として使用されます。これはデータ取り込み時刻であり、アプリの元のサインアップ日付ではありません。
:::

### プロファイルのステータス \{#profile-status\}

**Status** 列には、プロファイルの購入状態（顧客が購入したものとそれが現在も有効かどうか）が表示されます。メールの受信状況とは無関係です。

| ステータス | 意味 |
| --- | --- |
| Never purchased | 顧客がまだ何も購入していない。 |
| Purchased | 顧客が買い切り購入を行った。 |
| Active subscriber | 顧客が更新予定の有料サブスクリプションを持っている。 |
| Renewal cancelled | 自動更新がオフになっており、現在の期間が終了するまでアクセスが続く。 |
| Billing issue | 更新の支払いが失敗した。 |
| Grace period | 支払いは失敗したが、ストアのグレース期間中はアクセスが継続される。 |
| Churned | サブスクリプションが期限切れになり、アクセスが終了した。 |
| Refunded | 購入が返金された。 |

:::note
プロファイルは**アクティブなサブスクライバー**であってもメールを**配信停止**している場合があり、また**解約済み**であっても**購読中**の場合があります。メールのステータスはプロファイルページに表示され、Adapty Mail がそのプロファイルにメールを送信できるかどうかを制御します。
:::

## プロファイルの詳細 \{#profile-details\}

プロファイルをクリックすると、詳細ページが開きます。

### プロファイルのヘッダー \{#the-profile-header\}

ヘッダーにはお客様の識別情報が表示されます：メールアドレス、国、性別、年齢、プラットフォーム、「顧客開始日」。また、3つのバッジも表示されます：

- **Purchase status**: プロファイルの購入状態。使用される値は[プロファイルステータス](#profile-status)を参照してください。
- **Open rate**: このプロファイルに送信されたメールのうち、開封された割合。[Analytics](mail-analytics)は開封メール数ではなく、1回以上開封した受信者数を集計するため、2つの数値は異なります。
- **Email status**: **Subscribed**（購読中）、または送信が停止された理由（**Unsubscribed**、**Bounced**、**Reported spam** など）。このバッジは **Status** に表示される有料サブスクリプションとは無関係です。

**Subscribed**（購読中）は送信をブロックするものがないことを意味します。何かがスケジュールされているわけではありません。プロファイルは引き続きフロー内のセグメントと一致する必要があり、[ダブルオプトイン](mail-double-opt-in)はアドレスを確認するまでマーケティングメールを保留します。[メールが停止する理由](mail-suppression)では、**Subscribed** の代わりに適用されるすべての理由を説明しています。

### エンゲージメント指標 \{#engagement-metrics\}

ページ上部に5つの指標が表示されます。

- **Sent**：プロファイルに送信されたメール数。
- **Delivered**：メールボックスプロバイダーが受信を承認したメール数。
- **Opened**：受信者がメールを開封した回数（重複カウントあり）。
- **Clicked**：受信者がリンクをクリックした回数。
- **Revenue**：2つの数値 — アトリビューション収益とライフタイムバリュー。

:::note
**アトリビューション済み収益**とは、メールによって促進された収益（メール内のリンクをクリックした後に顧客が行った購入）です。**ライフタイムバリュー（LTV）**とは、メールが関与したかどうかに関わらず、すべてのソースにわたるプロファイルの総収益です。ヘッダーにはまずアトリビューション済み収益が表示され、次にLTVが表示されます。
:::

### プロファイルカード \{#the-profile-card\}

**Profile** カードには、顧客の属性が表示されます：

- **Platform**: 顧客の最新デバイスのプラットフォーム（iOS や Android など）。
- **Email provider**: MX レコードのドメインから特定された、メールボックスを管理するプロバイダー（**Google**、**iCloud**、**Proton** など）。**Disposable** は使い捨てアドレスサービスを示し、[認証に失敗](mail-suppression#address-verification-failed)して最初から抑制済みの状態になります。
- **Country**: 顧客の国。
- **Store country**: 顧客の App Store または Google Play アカウントの国。
- **Gender**: 顧客の性別（判明している場合）。
- **Age**: 顧客の年齢と、送信元から受け取った誕生日。
- **Profile ID**: Adapty Mail がプロファイルに付与する内部識別子。

**External Profile IDs** には、ソースごとに1つのエントリが表示されます。ソースは **Adapty**、**FunnelFox**、または **Custom** のいずれかで、各エントリにはそのソースがこのユーザーに使用している識別子と、最初に受信した日時が含まれます。**Custom attributes** には、ソースから送信されたキーと値のペアが一覧表示されます。

<ZoomImage id="mail-profile-detail.webp" width="700px" alt="エンゲージメント指標、プロファイルカード、購入状態カードを表示するプロファイル詳細ページ" />

### 購入状態 \{#purchase-state\}

**Purchase state** カードには、プロファイルの収益と購入履歴が表示されます。上部にはライフタイムバリュー、その下に定期収益が表示され、続いて最大2つのセクションが表示されます。

- **Subscription**: 価格、ストア、開始日、プロダクトID、およびアクセスが有効な間は **Renews**、終了後は **Expired** と表示される日付。
- **One-time purchase**: 最新の買い切り購入の価格、ストア、購入日、プロダクトID。

両方の購入がある場合、各セクションにはそれぞれのステータスバッジが表示されます。何も購入していない場合、カードには **No purchase yet** と表示されます。

### セグメント \{#segments\}

**Segments** カードには、プロファイルが現在一致しているセグメントの数が表示され、一覧が示されます。セグメントをクリックすると、その詳細を開けます。一致するセグメントがない場合、カードには **Not in any segment** と表示されます。Adapty Mail はリクエストのたびにフィルターを再実行するため、一覧は常に最新のプロファイルデータを反映しています。セグメントの作成方法については、[セグメント](mail-segments)をご覧ください。

## アクティビティジャーニー \{#the-activity-journey\}

**Journey** セクションは、**Profile created** から始まるプロファイルに関するすべての出来事のタイムラインです。メールイベントとトランザクションイベントが1つのリストに混在しています。

### メールイベント \{#email-events\}

各エントリは、Adapty Mail が送信した1件のメールを表します。展開すると、受信者がクリックしたリンクや、そのメールによって発生した購入を確認できます。チップにより、メールがどこまで到達したかが表示されます。

| チップ | 意味 |
| --- | --- |
| **Scheduled** | 送信時刻が設定されており、Adapty Mail がまだ送信していない。 |
| **Sent** | Adapty Mail がメールを送信したが、配信確認をまだ受け取っていない。 |
| **Delivered** | 受信側のメールサーバーがメールを受け付けた。このチップは **Sent** に代わって表示される。 |
| **Opened** | トラッキングピクセルが読み込まれた。 |
| **Clicked** | 受信者がリンクをクリックした。メールを展開すると、クリックされたリンクとそれによって発生した購入を確認できる。 |
| **Confirmed** | 受信者が[ダブルオプトイン](mail-double-opt-in)メールからアドレスを確認した。 |
| **Bounced** | 受信側のメールサーバーがメールを拒否して返送した。 |
| **Spam report** | 受信者がメールをスパムとして報告した。 |
| **Unsubscribed** | 受信者が配信停止した。 |
| **Delayed** | 受信側のメールサーバーが Adapty Mail に後で再試行するよう要求した。 |
| **Throttled** | すべての送信ドメインが[1日の上限](mail-suppression#throttle-temporary-delays-and-cancellations)を超えているため、メールが待機中。 |
| **Cancelled** | メールは送信されない。購入、配信停止、バウンス、スパム報告、削除、または2回目のスロットルはいずれもシーケンスの残りをキャンセルする。詳しくは[メールが停止する理由](mail-suppression)を参照。 |

### トランザクションイベント \{#transaction-events\}

各エントリは、サブスクリプションまたは買い切り購入のマイルストーンです。「ジャーニー」では、生の `event_type` の代わりにわかりやすいラベルを表示します。

| `event_type` | Journey ラベル |
| --- | --- |
| `subscription_started` | Subscription started |
| `subscription_renewed` | Subscription renewed |
| `subscription_renewal_cancelled` | Renewal cancelled |
| `subscription_renewal_reactivated` | Renewal resumed |
| `billing_issue_detected` | Billing issue |
| `entered_grace_period` | Entered grace period |
| `subscription_expired` | Subscription expired |
| `subscription_refunded` | Subscription refunded |
| `non_subscription_purchase` | One-time purchase |
| `non_subscription_purchase_refunded` | Purchase refunded |

これらのイベントは Adapty SDK を通じて自動的に Adapty Mail に届きます。または、[API](mail-send-data-via-api#send-transaction-events) を使って自分で送信することもできます。

## プロファイルの配信停止 \{#unsubscribe-a-profile\}

プロファイルへのメール送信を停止するには、そのプロファイルページを開き、**...** をクリックして **Unsubscribe** を選択します。Adapty Mail はそのプロファイルを配信停止済みとしてマークし、抑制リストに追加します。これにより、キャンペーンやフローからスキップされるようになります。

何らかの理由でプロファイルが抑制リストに登録されると、**Unsubscribe** は無効な状態のままになります。受信者が自分で配信停止する2つの方法については、[メールが停止される理由](mail-suppression) を参照してください。

## プロファイルを削除する \{#delete-a-profile\}

プロファイルを削除すると、Adapty Mail がその人物について保存しているデータをすべて消去できます。たとえば、データ削除リクエストへの対応に使用できます。

プロファイルを削除するには、該当プロファイルのページを開き、**...** をクリックして **Delete** を選択し、確認します。Adapty Mail はその後、次の処理を行います。

- メールアドレスと、名前・性別・誕生日・国・ストアの国・デバイス情報・カスタム属性などのすべての個人属性を消去する。
- そのプロファイルに対してスケジュール済みのメールをキャンセルする。
- プロファイルを Profiles ページから削除する。

この操作は取り消せません。購入記録は個人を特定する情報なしで残るため、収益の合計は変わりません。

削除したアドレスはブロックされません。ソースが再度送信すると、Adapty Mail は削除済みのプロファイルとは無関係な新しいプロファイルを作成します。特定のユーザーを永続的に除外したい場合は、ソース側からそのデータが送信されないようにしてください。

バックエンドからも [プロファイルの削除](api-mail/operations/deleteProfile) エンドポイントを使ってプロファイルを削除できます。
