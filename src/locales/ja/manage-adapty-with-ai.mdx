Adapty プラグインは、AI ツールが Adapty を操作できるようにします。Claude Code、Codex、Cursor、その他のコーディングエージェント、または claude.ai にインストールして、平易な言葉で指示するだけです。SDK の統合、ペイウォールの作成、収益が低下した原因の調査、A/B テストの開始など、さまざまなタスクに対応します。プラグインはスキルの集合体であり、タスクの種類ごとに検証済みのワークフローが用意されています。インストールするプロダクトはこれ一つです。Adapty MCP サーバーまたは Adapty CLI を通じて Adapty アカウントに接続し、Claude Code と Codex では MCP サーバーの追加も自動で行われるため、サインインするだけで使えます。

## プラグインが追加するもの \{#what-the-plugin-adds\}

AIツールは [Adapty MCPサーバー](adapty-mcp) または [Adapty CLI](developer-cli-quickstart) を通じて Adapty アカウントにアクセスできます。これにより、データの読み取りや変更が可能になります。プラグインは、AIツールが正しく操作するために必要な知識を提供します：

- **フローコンフィグのルール**: フローとは、プラグインにのみ存在するルールを持つ大きな JSON コンフィグです。これらのルールを使って、ツールはスクリーンショットや説明文からスクリーンを構築し、フローを保存する前にすべての変更を検証してプレビューします。ルールがない場合、ツールはフローコンフィグの読み書きはできますが、有効なコンフィグを構築することはできません。
- **テスト済みの手法**: プラグインはどのレポートがどの質問に答えるかを把握しており、レポートの読み方や自分の数値が市場と比べてどう位置づけられるかも理解しています。あなたの数値を A/B テストの仮説に変換し、収益への影響が大きい順にランク付けします。
- **最新の Adapty API**: SDK を統合する際、プラグインは各ステージで最新の Adapty ドキュメントを参照します。そのため、ツールはトレーニングデータに記憶されたバージョンではなく、あなたがインストールした SDK バージョンに合ったコードを生成します。
- **ユーザーに影響する変更前の確認**: A/B テストの開始、プレースメントの変更、実際のユーザーへのメール送信を行う前に、プラグインは変更内容を表示してあなたの承認を待ちます。
- **接続**: プラグインはツールが MCP サーバー、CLI、またはその両方を持っているかどうかを検出し、各タスクに適した方を選択します。

## プラグインのインストール \{#install-the-plugin\}

<Tabs groupId="ai-tool">
<TabItem value="coding-agent" label="Coding agent" default>

このプラグインは、スキルをサポートする任意のコーディングエージェント（Claude Code、Codex、Cursor、GitHub Copilot、Gemini CLI など）で動作します。

プラグインをインストールするには、ターミナルで次のコマンドを実行します：

```bash
npx adapty skills install
```

エージェントを再起動してプラグインを読み込んでください。他のインストール方法については、[プラグインの README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#install) を参照してください。

Claude Code はプラグインを自動更新しません。新しいスキルが追加されたら、Claude Code で `/plugin` を実行し、**Marketplaces** を開き、`adapty` を選択して、**Enable auto-update** を選んでください。

Claude Code と Codex では、プラグインが Adapty MCP サーバーも追加するので、[アシスタントを接続する](adapty-mcp#connect-your-assistant)に記載の通り、サインインするだけで使えます。その他のエージェントでは、スキルが初めてアカウントを必要とするとき、プラグインが Adapty CLI と MCP サーバーのどちらを使うか確認し、選択したもののセットアップ手順を案内します。

</TabItem>

<TabItem value="claude-ai" label="claude.ai">

Claudeの設定でプラグインをインストールします。コマンドラインは不要で、Claude desktopでも手順は同じです。

1. Claudeで **Settings** → **Plugins** を開きます。
2. **Add** → **Add marketplace** をクリックします。
3. **Add from a repository** を選択します。
4. **URL** フィールドに `adaptyteam/adapty-skills` と入力し、リポジトリを選択します。新しいスキルや修正が公開されたときに自動で取得するには、**Sync automatically** をオンにしておきます。
5. **Sync** をクリックします。

<ZoomImage id="adapty-skills-claude-add-marketplace.png" width="584px" alt="Add marketplace dialog in Claude with adaptyteam/adapty-skills in the URL field and Sync automatically turned on" />

Claudeは **Discover** タブを開き、Adapty マーケットプレイスのプラグインを表示します。プラグインをインストールするには、**Adapty** の行にある **Add** をクリックします。

<ZoomImage id="adapty-skills-claude-discover.png" width="600px" alt="Discover tab in Claude listing the Adapty, Apple ads, and Apple ads benchmarks plugins, each with an Add button" />

プラグインはClaude のサンドボックス内でスクリプトを実行します。これを許可するには、**Settings** → **Capabilities** で **Code execution and file creation** をオンにしてください。

Claude が Adapty アカウントにアクセスできるようにするには、Adapty MCP サーバーをコネクターとして追加してサインインしてください。詳細は[アシスタントを接続する](adapty-mcp#connect-your-assistant)をご覧ください。

</TabItem>

</Tabs>

## できること \{#what-you-can-do\}

スキルに名前を付ける必要はありません。同僚に説明するように話しかけるだけで、プラグインが適切なワークフローを選択します。

### SDKを統合する \{#integrate-the-sdk\}

```
Integrate Adapty into my app
```

このプラグインはAdapty ダッシュボードでアプリを設定し、SDKをインストールして、ペイウォールを追加し、次のステップに進む前に各段階を検証します。プラットフォームを自動で検出します。各ガイドを参照してください: [iOS](adapty-sdk-integration-skill)、[Android](adapty-sdk-integration-skill-android)、[React Native](adapty-sdk-integration-skill-react-native)、[Flutter](adapty-sdk-integration-skill-flutter)、[Unity](adapty-sdk-integration-skill-unity)、[Kotlin Multiplatform](adapty-sdk-integration-skill-kmp)、[Capacitor](adapty-sdk-integration-skill-capacitor)。

### フローのビルドと編集 \{#build-and-edit-flows\}

```
Add a German locale to my onboarding flow
```

このプラグインは[フローのビルドと編集](flow-generator-skill)を行います。ロケールの追加、コピーの書き換え、画面の追加・削除、クイズの分岐設定、説明からのペイウォール作成などが可能です。公開前には、トリガー、ストアのコンプライアンス、プロダクト、ローカライズについて[フローを監査](flow-audit-skill)します。プレースメントにペイウォールが表示されている場合、プラグインは[それらをフローに移行](migrate-placements-skill)します。

### 次にテストすべきことを見つける \{#find-what-to-test-next\}

```
Audit my app. What should I test next to grow revenue?
```

プラグインは[アナリティクス、価格、過去のA/B テストを読み込み](export-analytics-with-ai)、ビジネスの各側面を市場と比較してスコアリングし、収益に与える影響の大きさでランク付けされた仮説を返します。また、先月の更新率が下がった理由など、数字に関する素朴な質問にも答えます。

### A/B テストを実行する \{#run-ab-tests\}

```
Start a 50/50 test of my two onboarding paywalls
```

プラグインは、ペイウォールとフローの [A/B テストの作成・開始・停止・置き換え](ab-tests-skill) を行います。

### 広告キャンペーンを分析する \{#analyze-your-ad-campaigns\}

```
Which campaigns should I scale, and which should I cut?
```

プラグインは[Adapty のアトリビューションデータを読み取ります](developer-cli-attribution-skill)：チャンネル、キャンペーン、国別の ROAS、回収期間、トライアルあたりのコスト、返金情報。

:::tip
Apple Ads キャンペーン専用のプラグインもあります。[AI コーディングツールで Apple Ads を管理する](developer-cli-ads-manager-skill)をご覧ください。
:::

### Adapty Mail の実行

```
Why didn't this user get the welcome email?
```

このプラグインは [Adapty Mail MCP サーバーに接続](mail-skill)し、メールフローを起動して、メールが送信されなかった理由を追跡します。実際のユーザーにメールを送る操作の前には必ず確認を求めます。

### RevenueCat からの移行 \{#migrate-from-revenuecat\}

```
Move my RevenueCat project to Adapty
```

コーディングエージェントが RevenueCat のカタログとペイウォールデザインを新しい Adapty アプリにコピーし、コード内の RevenueCat SDK の呼び出しを対応する Adapty ID を使った呼び出しに置き換えます。詳細は [RevenueCat からの移行](migration-from-revenuecat) をご覧ください。

## プラグインがアカウントにアクセスする仕組み \{#how-the-plugin-reaches-your-account\}

プラグインは2つの接続方式で動作します。どちらも設定されていない場合、プラグインはどちらを設定するか確認し、手順を案内します。両方が設定されている場合、タスクごとに適切な方を選択します。

- **[Adapty MCPサーバー](adapty-mcp)**: claude.aiやClaude desktop、またはMCPをサポートするコーディングエージェントとの接続方法です。ブラウザでAdaptyアカウントにサインインします。APIキーは不要です。
- **[Adapty CLI](developer-cli-quickstart)**: ターミナルコマンドを実行するコーディングエージェントとの接続方法です。フローと分析のワークフローはローカルファイルを扱うためCLIを推奨します。CLIは自分で実行したり、独自のスクリプトから呼び出すこともできます。

## AIを活用してバックエンドを構築する \{#build-your-backend-with-ai\}

この2つのガイドは、ご自身のサーバー向けに書くコードを対象としています。AIコーディングツールにガイドをコピーすれば、実行可能なコード、フィールドの注意点、制限事項をまとめて貼り付けられます。

- [サブスクリプションイベントの処理](handle-webhooks-with-ai)：エンドポイントでAdaptyのWebhookを受信する。
- [サブスクリプションアクセスの確認と付与](server-side-api-with-ai)：バックエンドからAdaptyのサーバーサイドAPIを呼び出す。

## Adapty ドキュメントを AI ツールに提供する \{#give-your-ai-tool-the-adapty-docs\}

### プレーンテキストドキュメント

すべての Adapty ドキュメントは Markdown 形式でも参照できます。ページの URL に `.md` を追加するか、タイトル下の **Copy for LLM** をクリックしてください。より広いコンテキストが必要な場合は、[`llms.txt`](https://adapty.io/docs/ja/llms.txt) インデックス、または [`ios-llms.txt`](https://adapty.io/docs/ja/ios-llms.txt) などプラットフォーム別のサブセットをツールに渡してください。

### Context7

[Context7](https://context7.com/adaptyteam/adapty-docs) is an MCP server that serves Adapty docs to your AI tool, but it indexes only code snippets — not the full prose. Use it for quick code examples; for complete guidance, give your tool the [plain-text docs](#plain-text-docs). Context7 serves docs only; to work with your account, [install the Adapty plugin](#install-the-plugin).
