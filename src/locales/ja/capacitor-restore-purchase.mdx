購入の復元は iOS と Android の両方で利用できる機能で、ユーザーがサブスクリプションやアプリ内課金など、以前に購入したコンテンツへのアクセスを再取得できるようにします。この機能は、アプリをアンインストール・再インストールしたユーザーや新しいデバイスに切り替えたユーザーが、再度支払いなしに以前購入したコンテンツにアクセスしたい場合に特に役立ちます。

:::note
ビルダーで画面を作成した場合、購入の復元を手動で行う必要はありません。復元コントロールを紐付けてください — Flow & ペイウォールビルダーの **Restore purchases** アクション、または旧バージョンの復元リンクやボタン — SDK が復元を完了します。
:::

画面を自分で作成した場合は、`.restorePurchases()` メソッドを呼び出してください：

```typescript showLineNumbers

try {
  const profile = await adapty.restorePurchases();
  const isSubscribed = profile.accessLevels?.['YOUR_ACCESS_LEVEL']?.isActive;
  
  if (isSubscribed) {
    // Restore access to paid features
    console.log('Access restored successfully!');
  } else {
    console.log('No active subscriptions found');
  }
} catch (error) {
  console.error('Failed to restore purchases:', error);
}
```

レスポンスパラメーター:

| パラメーター | 説明                                                                                                                                                                                                                                                            |
|---------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **profile** | [`AdaptyProfile`](https://capacitor.adapty.io/interfaces/adaptyprofile) オブジェクトです。このモデルにはアクセスレベル、サブスクリプション、買い切り購入に関する情報が含まれています。ユーザーがアプリにアクセスできるかどうかを判断するには、**アクセスレベルのステータス**を確認してください。 |
