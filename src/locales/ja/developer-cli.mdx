**Adapty Developer CLI** は、ダッシュボードを開かずに Adapty アカウントを管理するためのコマンドラインツールです。ターミナルや自動化環境からアクセスできる主要な設定機能を提供します。

**CLI でできること：**

- AdaptyアカウントでiOSおよびAndroidアプリを作成・設定する
- アクセスレベルを定義する — アプリが実行時にチェックするサブスクリプション階層
- プロダクトを設定し、App StoreおよびGoogle PlayのストアIDにマッピングする
- ペイウォールを作成し、プロダクトを割り当てる
- フローを作成し、ビルダーの設定を記述して公開する — コマンドリファレンスの[フロー](developer-cli-reference#flows)を参照
- SDKを通じてペイウォールまたはフローを取得するプレースメントを設定する
- [Ads Manager](developer-cli-ads-manager)を通じてApple Adsのキャンペーン、キーワード、自動化ルールを管理する
- [Attribution](developer-cli-attribution)を通じてAdaptyのアトリビューションレポート（チャネルおよびキャンペーン別の支出、インストール数、収益、ROAS）を読む
- RevenueCatプロジェクト（カタログ、ペイウォールデザイン、アプリコード、トランザクション履歴）を移行する — [RevenueCatからの移行](migration-from-revenuecat)を参照
- `adapty skills install`でコーディングエージェントにAdaptyのスキルをインストールする — コマンドリファレンスの[スキル](developer-cli-reference#skills)を参照
