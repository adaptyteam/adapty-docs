**Adapty Developer CLI** は、ダッシュボードを開かずに Adapty アカウントを管理するためのコマンドラインツールです。ターミナルや自動化環境からアクセスできる主要な設定機能を提供します。

**CLI でできること：**

- Adapty アカウントに iOS と Android アプリを作成・設定する
- アクセスレベルを定義する — アプリが実行時にチェックするサブスクリプション階層
- プロダクトを設定し、App Store および Google Play のストア ID にマッピングする
- ペイウォールを作成し、プロダクトを割り当てる
- SDK 経由でペイウォールを取得するためのプレースメントを設定する
- [Ads Manager](developer-cli-ads-manager) を通じて Apple Ads のキャンペーン、キーワード、自動化ルールを管理する
