**Adapty Developer CLI** は、ダッシュボードを開かずに Adapty アカウントを管理するためのコマンドラインツールです。ターミナルや自動化環境からアクセスできる主要な設定機能を提供します。

**CLI でできること：**

- Adapty アカウントで iOS および Android アプリを作成・設定する
- アクセスレベルを定義する — アプリが実行時に確認するサブスクリプションの階層
- プロダクトを設定し、App Store および Google Play のストア ID に紐付ける
- ペイウォールを作成し、プロダクトを割り当てる
- フローを作成し、ビルダーの設定を記述してパブリッシュする — コマンドリファレンスの [Flows](developer-cli-reference#flows) を参照
- SDK 経由でペイウォールやフローを取得できるようプレースメントを設定する
- [Ads Manager](developer-cli-ads-manager) を通じて Apple Ads のキャンペーン、キーワード、オートメーションルールを管理する
- [Attribution](developer-cli-attribution) を通じて Adapty のアトリビューションレポート（チャネル・キャンペーン別の支出、インストール数、収益、ROAS）を参照する
- RevenueCat プロジェクト（カタログ、ストアイベント、トランザクション履歴）を移行する — [Migration from RevenueCat](migration-from-revenuecat) を参照
