**Adapty Developer CLI** は、ダッシュボードを開かずに Adapty アカウントを管理するためのコマンドラインツールです。ターミナルや自動化環境からアクセスできる主要な設定機能を提供します。

**CLI でできること：**

- AdaptyアカウントでiOSおよびAndroidアプリを作成・設定する
- アクセスレベルを定義する（アプリが実行時にチェックするサブスクリプション階層）
- プロダクトを設定し、App StoreおよびGoogle PlayのストアIDにマッピングする
- ストアオファーをプロダクトにリンクする（Google Playの無料トライアルを含む）— コマンドリファレンスの[プロダクトオファー](developer-cli-products#product-offers)を参照
- ペイウォールを作成し、プロダクトを割り当てる
- フローを作成し、ビルダーの設定を記述して公開する — コマンドリファレンスの[フロー](developer-cli-flows)を参照
- SDKを通じてペイウォールまたはフローを取得するようにプレースメントを設定する
- [Analytics](developer-cli-analytics)を通じてアプリのアナリティクス（収益、MRR、コンバージョン、ファネル、リテンション、LTV、コホート）を確認する
- [A/B tests](developer-cli-ab-tests)を通じてペイウォールおよびフローのA/Bテストの作成・開始・停止・置き換えを行う
- [Ads Manager](developer-cli-ads-manager)を通じてApple Adsのキャンペーン、キーワード、自動化ルールを管理する
- [Attribution](developer-cli-attribution)を通じてAdaptyのアトリビューションレポート（チャネル・キャンペーン別の消費額、インストール数、収益、ROAS）を確認する
- RevenueCatプロジェクト（カタログ、ペイウォールデザイン、アプリコード、トランザクション履歴）を移行する — [RevenueCatからの移行](migration-from-revenuecat)を参照
- `adapty skills install` でスキルをコーディングエージェントにインストールする — コマンドリファレンスの[スキル](developer-cli-reference#skills)を参照
