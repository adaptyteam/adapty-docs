**Adapty Developer CLI** は、ダッシュボードを開かずに Adapty アカウントを管理するためのコマンドラインツールです。ターミナルや自動化環境からアクセスできる主要な設定機能を提供します。

**CLI でできること：**

- AdaptyアカウントでiOSおよびAndroidアプリを作成・設定する
- アクセスレベルを定義する — アプリが実行時にチェックするサブスクリプション階層
- プロダクトを設定し、App StoreおよびGoogle PlayストアのIDにマッピングする
- ペイウォールを作成し、プロダクトを割り当てる
- フローを作成し、ビルダー設定を記述してPublishする — コマンドリファレンスの[フロー](developer-cli-reference#flows)を参照
- SDKを通じてペイウォールまたはフローを取得するプレースメントを設定する
- アプリのアナリティクス（収益、MRR、コンバージョン、ファネル、リテンション、LTV、コホート）を[Analytics](developer-cli-analytics)から確認する
- Apple Adsのキャンペーン、キーワード、自動化ルールを[Ads Manager](developer-cli-ads-manager)から管理する
- チャネルおよびキャンペーン別のAdaptyアトリビューションレポート（広告費、インストール数、収益、ROAS）を[Attribution](developer-cli-attribution)から確認する
- RevenueCatプロジェクト（カタログ、ペイウォールデザイン、アプリコード、取引履歴）を移行する — [RevenueCatからの移行](migration-from-revenuecat)を参照
- `adapty skills install`でコーディングエージェントにAdaptyのスキルをインストールする — コマンドリファレンスの[スキル](developer-cli-reference#skills)を参照
