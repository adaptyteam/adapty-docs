**Adapty Developer CLI** は、ダッシュボードを開かずに Adapty アカウントを管理するためのコマンドラインツールです。ターミナルや自動化環境から主要な設定操作を実行できます。

<AIPromo id="adapty-mcp" title="ターミナルではなくチャットから操作する。" cta="Adapty MCP サーバーに接続する">
Adapty MCP サーバーを使えば、Claude アプリ、Claude Code、Codex、その他の MCP クライアントから同じアカウントにアクセスできます。ブラウザで一度サインインするだけで、インストール不要です。
</AIPromo>

**CLI でできること：**

- AdaptyアカウントでiOSおよびAndroidアプリを作成・設定する
- アクセスレベル（アプリが実行時にチェックするサブスクリプション階層）を定義する
- プロダクトを設定し、App StoreおよびGoogle PlayのストアIDにマッピングする
- ストアオファーをプロダクトにリンクする（Google Playの無料トライアルも含む）— コマンドリファレンスの[プロダクトオファー](developer-cli-products#product-offers)を参照
- ペイウォールを作成し、プロダクトを割り当てる
- フローを作成し、ビルダーの設定を記述して公開する — コマンドリファレンスの[フロー](developer-cli-flows)を参照
- SDKを通じてペイウォールまたはフローを取得するようプレースメントを設定する
- [Analytics](developer-cli-analytics)を通じて、収益・MRR・コンバージョン・ファネル・リテンション・LTV・コホートなど、アプリのアナリティクスを確認する
- [A/B tests](developer-cli-ab-tests)を通じて、ペイウォールおよびフローのA/Bテストを作成・開始・停止・置き換えする
- [Ads Manager](developer-cli-ads-manager)を通じて、Apple Adsのキャンペーン・キーワード・自動化ルールを管理する
- [Attribution](developer-cli-attribution)を通じて、チャネルおよびキャンペーン別の支出・インストール・収益・ROASなど、Adaptyのアトリビューションレポートを確認する
- Apple Retention Messagingを設定し、サブスクライバーがキャンセル時に表示するリテンションメッセージを[Retention Messaging](developer-cli-retention-messaging)を通じて作成・変更・有効化する
- RevenueCatプロジェクト（カタログ・ペイウォールデザイン・アプリコード・取引履歴）をAdaptyに移行する — [Migration from RevenueCat](migration-from-revenuecat)を参照
- `adapty skills install`でコーディングエージェントにAdaptyのスキルをインストールする — コマンドリファレンスの[スキル](developer-cli-reference#skills)を参照
