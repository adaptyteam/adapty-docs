**Adapty Developer CLI** は、ダッシュボードを開かずに Adapty アカウントを管理するためのコマンドラインツールです。ターミナルや自動化環境から主要な設定操作を実行できます。

<AIPromo id="adapty-mcp" title="ターミナルではなくチャットから操作する。" cta="Adapty MCP サーバーに接続する">
Adapty MCP サーバーを使えば、Claude アプリ、Claude Code、Codex、その他の MCP クライアントから同じアカウントにアクセスできます。ブラウザで一度サインインするだけで、インストール不要です。
</AIPromo>

**CLI でできること：**

- AdaptyアカウントでiOSおよびAndroidアプリを作成・設定する
- アクセスレベルを定義する（アプリが実行時にチェックするサブスクリプション階層）
- プロダクトを設定し、App StoreおよびGoogle PlayのストアIDにマッピングする
- ストアオファーをプロダクトにリンクする（Google Playの無料トライアルを含む）— コマンドリファレンスの[プロダクトオファー](developer-cli-products#product-offers)を参照
- ペイウォールを作成し、プロダクトを割り当てる
- フローを作成し、ビルダー設定を記述して公開する — コマンドリファレンスの[フロー](developer-cli-flows)を参照
- プレースメントを設定して、SDKからペイウォールまたはフローを取得する
- アプリのアナリティクス（収益、MRR、コンバージョン、ファネル、リテンション、LTV、コホート）を[アナリティクス](developer-cli-analytics)から確認する
- [A/B テスト](developer-cli-ab-tests)を通じて、ペイウォールとフローのA/B テストを作成・開始・停止・置換する
- [Ads Manager](developer-cli-ads-manager)を通じて、Apple Adsキャンペーン、キーワード、自動化ルールを管理する
- [アトリビューション](developer-cli-attribution)を通じて、チャネルおよびキャンペーン別の広告費、インストール数、収益、ROASをAdaptyアトリビューションレポートで確認する
- Apple Retention Messagingを設定し、サブスクライバーがキャンセル時に表示されるリテンションメッセージを[Retention Messaging](developer-cli-retention-messaging)を通じて作成・変更・有効化する
- Refund Saverを有効にし、返金設定を行い、節約した金額を[Refund Saver](developer-cli-refund-saver)で確認する
- RevenueCatプロジェクト（カタログ、ペイウォールデザイン、アプリコード、トランザクション履歴）を移行する — [RevenueCatからの移行](migration-from-revenuecat)を参照
- `adapty skills install`でコーディングエージェントにAdaptyスキルをインストールする — コマンドリファレンスの[スキル](developer-cli-reference#skills)を参照
