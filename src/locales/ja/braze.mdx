トップクラスのカスタマーエンゲージメントソリューションの一つである [Braze](https://www.braze.com/) は、プッシュ通知、メール、SMS、アプリ内メッセージングなど幅広いツールを提供しています。Adapty と Braze を連携することで、すべてのサブスクリプションイベントを一か所で簡単に確認でき、それらのイベントをトリガーにした自動コミュニケーションを実現できます。

Adapty は、すべてのストアからの[サブスクリプションイベント](events)を一か所で追跡し、Braze のユーザープロファイルを更新するための完全なデータセットを提供します。Adapty を使えば、サブスクライバーの行動を簡単に把握し、好みを理解した上で、ターゲットを絞った効果的なコミュニケーションに活かすことができます。このインテグレーションにより、Braze ダッシュボードでサブスクリプションイベントを追跡し、[獲得キャンペーン](https://www.braze.com/product/journey-orchestration)と紐付けることが可能になります。

Adaptyは、サブスクリプションイベント、ユーザープロパティ、購入情報をBrazeに送信します。以下の簡単な手順でインテグレーションを設定すると、Brazeのプッシュ通知を活用してターゲットを絞ったユーザーコミュニケーションを構築できます。

## Braze インテグレーションの設定方法 \{#how-to-set-up-braze-integration\}

Adapty と Braze を連携するには、Adapty ダッシュボードで [**Integrations** → **Braze**](https://app.adapty.io/integrations/braze) を開き、トグルをオンにして認証情報を入力します。

- **REST API key** と **Braze Instance ID** は必須です。
- **iOS App ID** と **Android App ID** は任意です。

1. **REST API キー**を作成するには、Braze ダッシュボードで **Settings** → **APIs and Identifiers** に移動し、**Create API Key** をクリックします。ユーザーデータのパーミッションで `users.track` を選択してください。Braze では、作成後にキーのパーミッションを変更できないため、`users.track` のないキーは新しいキーに置き換える必要があります。詳細については、Braze ドキュメントの [Creating REST API keys](https://www.braze.com/docs/api/basics#creating-rest-api-keys) を参照してください。
2. **Braze インスタンス ID** を確認するには、Braze ダッシュボードの URL を Braze ドキュメントの [instance table](https://www.braze.com/docs/api/basics/#endpoints) と照合してください。インスタンス ID は `US-03` や `EU-01` のような地域形式です。たとえば、`dashboard-03.braze.com` は `US-03` です。
3. **iOS App ID** と **Android App ID** を確認するには、Braze ダッシュボードで **Settings** → **APIs and Identifiers** → **App Identifiers** に移動します。各アプリの **Identifier** 列の値をコピーしてください。詳細については、Braze ドキュメントの [App identifier](https://www.braze.com/docs/api/identifier_types#app-identifier) を参照してください。

Adaptyはサブスクリプションイベントとユーザー属性をサーバー間統合でBrazeに送信するため、Brazeダッシュボードで確認してキャンペーンを設定できます。

トライアルコンバージョンや更新など、収益が発生するイベントについては、Adapty はこの情報を購入としてBrazeに送信します。

:::warning
Adapty は収益をBrazeにレガシー購入イベントとしてのみ送信します。Brazeはレガシー購入イベントをメンテナンスモードに移行しており、新規顧客に対しては有効化していません。ご利用のBrazeワークスペースがレガシー購入イベントを受け付けない場合、Brazeは収益を含むすべてのイベントをHTTP 400および`Legacy purchase ingestion is disabled`というメッセージで拒否します。初回購入、更新、トライアルコンバージョン、返金などのイベントは、収益だけでなくイベント自体がBrazeに届きません。

インテグレーションを有効にする前に、Braze ワークスペースがレガシー購入イベントを受け入れるように設定されていることを確認してください。詳細については、Braze ドキュメントの [購入イベント](https://www.braze.com/docs/user_guide/data/activation/events/purchase_events) を参照してください。
:::

[こちら](messaging#event-properties) で、Braze に送信されるイベントプロパティの完全な仕様を確認できます。

:::note
便利なユーザー属性

Adapty は、Braze インテグレーションのデフォルトとしていくつかのユーザー属性を送信します。以下に提供されているリストを参照して、ニーズに最適なものをご確認ください。
:::

| ユーザー属性 | 型 | 値 |
|--------------|----|-----|
| `adapty_customer_user_id` | String | お客様が定義したユーザーの一意識別子の値を含みます。Adaptyの[ダッシュボード](profiles-crm)とBrazeの両方で確認できます。 |
| `adapty_profile_id` | String | Adaptyのユーザープロファイルの一意識別子（Adapty User Profile ID）の値を含みます。Adaptyの[ダッシュボード](profiles-crm)で確認できます。 |
| `environment` | String | <p>ユーザーがサンドボックス環境または本番環境のどちらで操作しているかを示します。</p><p></p><p>値は `Sandbox` または `Production` のいずれかです。</p> |
| `store` | String | <p>購入に使用したストアの名前を含みます。</p><p></p><p>設定可能な値：</p><p>`app_store` または `play_store`</p> |
| `vendor_product_id` | String | <p>Apple/GoogleストアのプロダクトIDの値を含みます。</p><p></p><p>例：org.locals.12345</p> |
| `subscription_expires_at` | String | <p>最新のサブスクリプションの有効期限を含みます。</p><p></p><p>値のフォーマット：</p><p>YYYY-MM-DDTHH:mm:ss.SSS+TZ</p><p>例：2023-02-15T17:22:03.000+0000</p> |
| `active_subscription` | String | 購入・更新イベント時に `true`、サブスクリプションが期限切れの場合は `false` に設定されます。 |
| `period_type` | String | <p>購入または更新の最新の期間タイプを示します。</p><p></p><p>設定可能な値：</p><p>トライアル期間の場合は `trial`、それ以外は `normal`</p> |

すべてのfloat値はintに丸められます。文字列はそのまま維持されます。

定義済みのタグリストに加えて、タグを使って[カスタム属性](segments#custom-attributes)を送信することも可能です。これにより、タグに含めるデータの種類の柔軟性が高まり、プロダクトやサービスに関連する特定の情報の追跡に役立ちます。すべてのカスタムユーザー属性は、ユーザーが[統合ページ](https://app.adapty.io/integrations/braze)の **Send user attributes** チェックボックスをオンにすることで、自動的にBrazeに送信されます。

## SDK の設定 \{#sdk-configuration\}

Adapty と Braze のユーザープロファイルを連携するには、Braze SDK を Adapty と同じカスタマーユーザー ID で設定するか、`.changeUser()` メソッドを使用します。

<Tabs groupId="current-os" queryString>
<TabItem value="swift" label="iOS (Swift)" default>
```swift showLineNumbers
let braze = Braze(configuration: configuration)
braze.changeUser(userId: "adapty_customer_user_id")
```
</TabItem>
<TabItem value="kotlin" label="Android (Kotlin)" default>
```kotlin showLineNumbers
Braze.getInstance(context).changeUser("adapty_customer_user_id")
```
</TabItem>
</Tabs>
