## グローバルフラグ \{#global-flags\}

これらのフラグはすべてのコマンドで使用できます。

| フラグ | 説明 |
|---|---|
| `--json` | テキスト形式の代わりにJSONで出力する |
| `--help` | コマンドのヘルプを表示する |

`adapty product-offers list` を除くすべての `list` コマンドは、ページネーションフラグも使用できます：

| フラグ | デフォルト | 説明 |
|---|---|---|
| `--page` | `1` | ページ番号 |
| `--page-size` | `20` | 1ページあたりの件数（最大: 100） |

## スキル \{#skills\}

### adapty skills install

このマシン上のコーディングエージェントに Adapty スキルをインストールします。

```bash
adapty skills install
```

| フラグ | 必須 | 説明 |
|---|---|---|
| `--agent` | いいえ | インストール先のエージェント: `claude-code`、`codex`、`gemini-cli`。複数のエージェントを指定するにはフラグを繰り返します。 |
| `-y`, `--yes` | いいえ | 見つかったすべてのエージェントに確認なしでインストールします。CLI が複数のエージェントを検出し、確認できない場合（例: `--json` 使用時）に必須です。 |

CLIはPATHにあるClaude Code、Codex、Gemini CLIを検出します。いずれも見つからない場合は、`npx skills@1.7.0 add adaptyteam/adapty-skills --all --global`を実行するかどうかを確認するメッセージが表示されます。これは他のエージェントに対応するコマンドです。スキルを読み込むには、エージェントを再起動してください。

Claude Codeはプラグインを自動更新しません。新しいスキルを入手するには、Claude Codeで`/plugin`を実行し、**Marketplaces**を開いて`adapty`を選択し、**Enable auto-update**を選択してください。メニューを使わずに有効にするには、`~/.claude/settings.json`の`adapty`エントリに`"autoUpdate": true`を追加してください：

```json title="~/.claude/settings.json"
{
  "extraKnownMarketplaces": {
    "adapty": {
      "source": { "source": "github", "repo": "adaptyteam/adapty-skills" },
      "autoUpdate": true
    }
  }
}
```

スキル CLI でインストールしたスキルは `npx skills update` で更新できます。Codex については [プラグインの README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#codex) をご覧ください。
