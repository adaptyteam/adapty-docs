## グローバルフラグ \{#global-flags\}

これらのフラグはすべてのコマンドで使用できます。

| フラグ | 説明 |
|---|---|
| `--json` | フォーマットされたテキストの代わりにJSONで出力する |
| `--help` | コマンドのヘルプを表示する |

`adapty product-offers list`、`adapty flows versions list`、および `adapty virtual-currencies` の2つのトランザクションリストを除く、すべての `list` コマンドはページネーションフラグも受け付けます：

| フラグ | デフォルト | 説明 |
|---|---|---|
| `--page` | `1` | ページ番号 |
| `--page-size` | `20` | 1ページあたりのアイテム数（最大：100） |

`adapty virtual-currencies transactions list` と `adapty virtual-currencies profiles transactions list` は、カーソルを使用して各コマンドで1ページずつ読み取ります。これらは `--page` ではなく `--page-size` と `--cursor` を使用します。[クレジットトランザクションの読み取り](developer-cli-virtual-currencies#read-credit-transactions)を参照してください。

## CLI バージョン \{#cli-version\}

### adapty version

CLIのインストール済みバージョンを表示し、新しいバージョンが利用可能かどうかを確認します。

```bash
adapty version
```

このコマンドは `adapty --version` と同じ行を出力した後、公開npmレジストリに最新バージョンを問い合わせます（タイムアウトは3秒）。新しいバージョンが利用可能な場合は、そのバージョンとアップデートコマンド `npm i -g adapty@latest` が表示されます。レジストリが時間内に応答しない場合は `Could not check for a newer version.` と表示され、終了コードは0のままです。

`--json` を使用した場合、出力には以下のフィールドが含まれます：

| フィールド | 説明 |
|---|---|
| `installed` | インストール済みの CLIバージョン |
| `latest` | npm 上の最新バージョン。レジストリが時間内に応答しない場合は `null` |
| `update_available` | `latest` が `installed` より新しい場合は `true`、それ以外は `false` |

このコマンドを使用するには、CLIバージョン 0.26.1 以降が必要です。0.26.1 より前のバージョンを使用している場合は、`adapty --version` を実行してください。

## スキル \{#skills\}

### adapty skills install

このマシン上のコーディングエージェントに Adapty スキルをインストールします。

```bash
adapty skills install
```

| フラグ | 必須 | 説明 |
|---|---|---|
| `--agent` | いいえ | インストール先のエージェント: `claude-code`、`codex`、`gemini-cli`。複数のエージェントを指定するにはフラグを繰り返します。 |
| `-y`, `--yes` | いいえ | 見つかったすべてのエージェントに確認なしでインストールします。CLI が複数のエージェントを検出し、確認できない場合（例: `--json` 使用時）に必須です。 |

CLIはPATHにあるClaude Code、Codex、Gemini CLIを検出します。いずれも見つからない場合は、`npx skills@1.7.0 add adaptyteam/adapty-skills --all --global`を実行するかどうかを確認するメッセージが表示されます。これは他のエージェントに対応するコマンドです。スキルを読み込むには、エージェントを再起動してください。

Claude Codeはプラグインを自動更新しません。新しいスキルを入手するには、Claude Codeで`/plugin`を実行し、**Marketplaces**を開いて`adapty`を選択し、**Enable auto-update**を選択してください。メニューを使わずに有効にするには、`~/.claude/settings.json`の`adapty`エントリに`"autoUpdate": true`を追加してください：

```json title="~/.claude/settings.json"
{
  "extraKnownMarketplaces": {
    "adapty": {
      "source": { "source": "github", "repo": "adaptyteam/adapty-skills" },
      "autoUpdate": true
    }
  }
}
```

スキル CLI でインストールしたスキルは `npx skills update` で更新できます。Codex については [プラグインの README](https://github.com/adaptyteam/adapty-skills/blob/main/plugin/README.md#codex) をご覧ください。
