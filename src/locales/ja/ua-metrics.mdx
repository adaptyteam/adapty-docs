これは、Adapty アトリビューション分析で利用可能な指標の概要です。各指標が何を測定し、Adapty がどのように計算するかを理解するためにご活用ください。Adapty Core が生成するサブスクリプション分析については、[指標比較表](metric-comparison-table)をご覧ください。

:::note
Webでの購入にはアプリインストールイベントがありません。Adaptyはトライアル開始日または購入日を基準にコホートを作成します。
:::

| **指標**                        | 説明                                                                                                                                                                                                                                                                                                                                                                                                                                     | <InlineTooltip tooltip="コホートサポート">コホート期間は、インストール後の日数（例：D7 ROASの場合は7日間）に指標を絞り込みます。</InlineTooltip> |
|-----------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---:|
| **Spend**                         | 広告へのユーザータップのコストの合計です。                                                                                                                                                                                                                                                                                                                                                                                                                            | No     |
| **Impressions**                   | 選択した期間内に広告が表示された回数です。                                                                                                                                                                                                                                                                                                                                                                                                                           | No     |
| **Clicks**                        | 選択した期間内にユーザーが広告をクリックした回数です。[カスタムトラッキングリンク](ua-tracking-links)のクリックは含まれません。                                                                                                                                                                                                                                                                                                                                                                       | No     |
| **Clicks (attributed)** | Adaptyがトラッキングリンクを通じてカウントした広告クリック数です。[カスタムトラッキングリンク](ua-tracking-links)のクリックを含みます。 | No |
| **CPI**                           | **CPI（Cost per Install）**はインストール1件あたりに支払う金額です。<br/>**計算式**: `Spend / Installs`                                                                                                                                                                                                                                                                                                                                         | No     |
| **CPC**                           | **CPC（Cost per Click）**は広告クリック1件あたりに支払う金額です。<br/>**計算式**: `Spend / Clicks`                                                                                                                                                                                                                                                                                                                                    | No     |
| **CPM**                           | **CPM（Cost per Mille）**は広告1,000インプレッションあたりに支払う金額です。<br/>**計算式**: `Spend / (Impressions / 1000)`                                                                                                                                                                                                                                                                                                                | No     |
| **ICR**                           | **ICR（Install Conversion Rate）**は広告クリックのうちインストールに至った割合です。<br/>**計算式**: `(Installs / Clicks) × 100%`                                                                                                                                                                                                                                                                                                                      | No     |
| **ICR (attributed)** | インストールに至った**Clicks (attributed)**の割合です。<br/>**計算式**: `(Installs / Clicks (attributed)) × 100%` | No |
| **IPM**                           | **IPM（Installs per Mille）**は広告1,000インプレッションあたりのインストール数です。<br/>**計算式**: `(Installs / Impressions) × 1000`                                                                                                                                                                                                                                                                                                             | No     |
| **CTR**                           | **CTR（Click-Through Rate）**はインプレッションのうちクリックに至った割合です。<br/>**計算式**: `(Clicks / Impressions) × 100%`                                                                                                                                                                                                                                                                                                                        | No     |
| **Inline link clicks**            | 広告クリエイティブまたはアプリページ内のインラインリンクをユーザーがクリックした回数です。                                                                                                                                                                                                                                                                                                                                                                | No     |
| **Avg cost per inline link click** | インラインリンククリック1件あたりの平均支払額です。<br/>**計算式**: `Spend / Inline link clicks`                                                                                                                                                                                                                                                                                                                                                | No     |
| **Inline link click through rate**         | インプレッションのうちインラインリンクのクリックに至った割合です。<br/>**計算式**: `(Inline link clicks / Impressions) × 100%`                                                                                                                                                                                                                                                                                                                | No     |
| **Installs**                      | 選択した期間内にユーザーがアプリをインストールした総回数です。再インストールも新規インストールとしてカウントされ、それぞれに独自のアトリビューションが付与されます。                                                                                                                                                                                                                                                                                                                                                           | No     |
| **Payers** | 有料サブスクリプションを開始したユーザー数（トライアルからの転換を含む）です。<br/>**計算式**: `Subscriptions started + Trial converted` | Yes |
| **Total revenue**                 | 選択した期間内にインストールしたユーザーの購入によって現時点までに生じた総収益です。グロス収益と手取り収益を切り替えるには、[Adaptyアトリビューションアナリティクス](ua-analytics#gross-revenue-or-proceeds)の収益ドロップダウンをご利用ください。                                                                                                                                                                                                                                                                  | No     |
| **Revenue** | 選択した期間内にインストールしたユーザーの収益のうち、インストール後のコホート期間（例：**D7 Revenue**の場合は7日間）内のものです。コホート期間を設定しない場合は**Total revenue**をご利用ください。 | コホートのみ |
| **ROAS**                          | **ROAS（Return on Ad Spend）**は広告費用対収益率で、収益を広告費で割ってパーセントで表したものです。<br/>**計算式**: `(Total revenue / Spend) × 100%（Spend > 0 の場合、それ以外は 0%）`                                                                                                                                                                                                                                                            | Yes    |
| **AdProfit** | 収益から広告費を差し引いた値です。<br/>**計算式**: `Total revenue − Spend` | Yes |
| **ARPU** | **ARPU（Average Revenue per User）**はインストール1件あたりの平均収益です。<br/>**計算式**: `Total revenue / Installs` | Yes |
| **ARPPU** | **ARPPU（Average Revenue per Paying User）**は支払いを行ったユーザー1人あたりの平均収益です。<br/>**計算式**: `Total revenue / Paying users`。`Paying users`は支払いを行ったユーザー数で、**Payers**は有料サブスクリプションの件数です。 | No |
| **ARPAS** | **ARPAS（Average Revenue per Active Subscriber）**はサブスクリプションまたはトライアル開始1件あたりの平均収益です。<br/>**計算式**: `Total revenue / (Subscriptions started + Trial started)` | Yes |
| **ARPT** | **ARPT（Average Revenue per Trial）**はトライアル開始1件あたりの平均収益です。<br/>**計算式**: `Total revenue / Trial started` | Yes |
| **Cost per trial**                | トライアル開始1件あたりの平均支払額です。<br/>**計算式**: `Spend / Trial started`                                                                                                                                                                                                                                                                                                                                                   | No     |
| **Cost per subscription**         | サブスクリプション開始1件あたりの平均支払額です。<br/>**計算式**: `Spend / Subscriptions started`                                                                                                                                                                                                                                                                                                                           | No     |

## イベント指標 \{#event-metrics\}

イベント指標は、選択した期間内にインストールしたユーザーのサブスクリプションおよび購入イベントをカウントします。各イベントには2つの指標があります：

- **Count**: イベントが発生した回数。
- **Rate**: インストール数に対するカウントの割合。**計算式**: `(Count / Installs) × 100%`

すべてのイベント指標は、コホート期間あり・なしの両方で追加できます。

| イベント | カウント指標 | レート指標 |
|---|---|---|
| ユーザーがトライアルなしで有料サブスクリプションを開始した。 | **Subscriptions started** | **Rate subscription started** |
| サブスクリプションが更新された。 | **Subscription renewed** | **Rate subscription renewed** |
| ユーザーがサブスクリプションの自動更新をオフにした。 | **Subscription renewal cancelled** | **Rate subscription renewal cancelle** |
| ユーザーがサブスクリプションの自動更新を再度オンにした。 | **Subscription renewal reactivated** | **Rate subscription renewal reactivated** |
| サブスクリプションが更新されずに終了した。 | **Subscription expired** | **Rate subscription expired** |
| ユーザーが Android でサブスクリプションを一時停止した。 | **Subscription paused** | **Rate subscription paused** |
| アプリのバックエンドが Google Play サブスクリプションの[支払いを延期した](https://adapty.io/glossary/subscription-purchase-deferral/)。 | **Subscription deferred count** | **Rate subscription deferred** |
| ストアがサブスクリプション購入を返金した。 | **Subscription refunded** | **Rate subscription refunded** |
| ユーザーがサブスクリプションの支払いについて銀行に異議を申し立てた。 | **Subscription chargeback** | **Rate subscription chargeback** |
| 銀行が異議申し立て済みのサブスクリプション支払いを返還した。 | **Subscription chargeback reversed** | **Rate subscription chargeback reversed** |
| ユーザーが無料トライアルを開始した。 | **Trial started** | **Rate trial started** |
| トライアルが有料サブスクリプションに転換された。 | **Trial converted** | **Rate trial converted** |
| ユーザーがトライアル中に自動更新をオフにした。 | **Trial renewal cancelled** | **Rate trial renewal cancelled** |
| ユーザーがトライアル中に自動更新を再度オンにした。 | **Trial renewal reactivated** | **Rate trial renewal reactivated** |
| トライアルが終了し、有料サブスクリプションに転換されなかった。 | **Trial expired** | **Rate trial expired** |
| ストアが残高不足などの理由でユーザーへの請求に失敗した。 | **Billing issue detected** | **Rate billing issue detected** |
| 請求の問題によりサブスクリプションがグレース期間に入った。 | **Entered grace period** | **Rate entered grace period** |
| ユーザーが買い切り購入を行った。 | **Non-subscription purchase** | **Rate non-subscription purchase** |
| ストアが買い切り購入を返金した。 | **Non-subscription purchase refunded** | **Rate non-subscription purchase refunded** |
| ユーザーが買い切り購入の支払いについて銀行に異議を申し立てた。 | **Non-subscription purchase chargeback** | **Rate non-subscription purchase chargeback** |
| 銀行が異議申し立て済みの買い切り購入支払いを返還した。 | **Non-subscription purchase chargeback reversed** | **Rate non-subscription purchase chargeback reversed** |

## Google Ads の指標 \{#google-ads-metrics\}

Google Ads はこれらの指標を独自にレポートするため、Google Ads の行でのみ表示されます。他のネットワークの行には「—」が表示されます。これらの列をまとめてテーブルに追加するには、[Google Ads プリセット](ua-analytics#google-ads-preset)を選択してください。

| **指標** | 説明 | コホート |
|---|---|---|
| **Conversions (Network)** | Google 広告がアカウント内のコンバージョンアクションに対してカウントしたコンバージョン数で、クリック日基準です。これは Google の数値であり、Adapty のトライアルや購入数とは異なるため、両者は一致しません。 | No |
| **All Conv. (Network)** | Google 広告がカウントしたすべてのコンバージョン数で、クリック日基準です。Google 広告では **All conv.** 列にこの数値が表示されます。 | No |
| **Cost per Conversion (Network)** | Google 広告が報告した1コンバージョンあたりの平均費用です。コンバージョンが報告された行の費用のみが対象となります。<br/>**計算式**: `Spend / Conversions (Network)` | No |
| **First Page Bid Est.** | 検索結果の1ページ目に広告を表示するために必要な入札額の Google による推定値です。 | No |
| **First Position Bid Est.** | 検索結果の1ページ目の最上位に広告を表示するために必要な入札額の Google による推定値です。 | No |
| **Status** | その行のキャンペーン、広告グループ、広告、またはキーワードの Google 広告ステータスです: **Enabled**、**Paused**、または **Removed**。 | No |

### コンバージョン \{#conversions\}

Adapty は各日のコンバージョンを 3 日間更新し続け、その後は固定されます。Google Ads は過去のクリック日に遅れてコンバージョンを追加し続けるため、古い日付では Adapty の方が Google Ads より少ないコンバージョン数が表示されることがあります。Adapty はデータ収集を開始する前の日付のコンバージョンをインポートしないため、それらの日付は「—」と表示されます。

### 入札額の見積もり \{#bid-estimates\}

入札額の見積もり列は、キーワードでグループ化した場合にのみテーブルに表示されます。各キーワードについて、Adapty は選択した日付範囲内でトラフィックがあった最新の日のGoogle の見積もりを表示します。

Google は、ディスプレイ広告およびアプリキーワードに対して入札額の見積もりを提供しません。また、**Maximize clicks**、**Maximize conversions**、**Target CPA** などの自動入札を使用するキャンペーンの検索キーワードに対しても提供しません。該当するキーワードには「—」が表示されます。

### ステータス \{#status\}

Adapty はステータスを1日1回更新します。以下の2つの条件が両方満たされた場合に、行にステータスが表示されます：

- テーブルがキャンペーン、広告セット、広告、またはキーワードでグループ化されている。
- 選択した期間内に、その行に Google Ads の支出がある。

複数の Google Ads キャンペーンが同じ名前を持つ場合、そのうちいずれかが有効であれば行には **Enabled** と表示されます。そうでない場合、いずれかが一時停止中であれば **Paused**、すべてが削除済みであれば **Removed** と表示されます。

## 予測指標 \{#predicted-metrics\}

予測指標は、アプリ自身の過去データをもとにコホートの将来パフォーマンスを予測するもので、オーガニックインストールも対象に含まれます。D30、D60、D90、D180、D360 など複数のコホート期間に対応しており、日数を指定してカスタム期間を追加することもできます。これらの値の計算方法については、[Adapty アトリビューションの予測指標](ua-predicted-metrics)を参照してください。

| **指標**      | 説明                                                                                                                                                                                       | <InlineTooltip tooltip="コホートのサポート">コホート期間は、インストールから指定した日数（例：D7 ROAS であれば7日間）に指標を絞り込みます。</InlineTooltip> |
|---------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---:|
| **pRevenue**  | 対象期間までにコホートが生み出すと予測される総収益。アプリの過去のコホートリテンションをもとにモデル化されています。                                                                        | コホートのみ |
| **pROAS**     | 同じ期間における広告費用対効果の予測値。**計算式**: `(pRevenue / Spend) × 100%`。**Organic** など支出のない行については計算されません。                                                     | コホートのみ |
| **pAdProfit** | 期間内の広告費を差し引いた予測収益。**計算式**: `pRevenue − Spend`                                                                                                                        | コホートのみ |
| **pARPU**     | 期間内のインストール1件あたりの予測平均収益（予測LTV）。**計算式**: `pRevenue / Installs`                                                                                                  | コホートのみ |
| **pARPPU**    | 期間内の課金ユーザー1人あたりの予測平均収益。**計算式**: `pRevenue / paying users at d{N}`（`d{N}` は選択した期間に対応）                                                                  | コホートのみ |
