Observerモードでは、Adapty SDKは既存の購入システムを通じて行われたアプリ内課金を自動的に追跡できません。アプリストアからのトランザクションを手動で報告する必要があります。分析のエラーを防ぐために、アプリをリリースする**前**にこの設定を行うことが重要です。

`reportTransaction` を使用して、各トランザクションをAdaptyに明示的に報告します。

:::warning

**トランザクションのレポートをスキップしないでください！**
`reportTransaction` を呼び出さない場合、Adapty はトランザクションを認識できず、アナリティクスに表示されず、インテグレーションにも送信されません。

:::

Adapty のフローやペイウォールを使用している場合は、トランザクションをレポートする際に `variationId` を含めてください。これにより、購入がそれをトリガーしたフローまたはペイウォールに紐付けられ、正確なアナリティクスが保証されます。

<Tabs groupId="current-os" queryString>
<TabItem value="kotlin" label="Kotlin" default>

```kotlin showLineNumbers
val transactionInfo = TransactionInfo.fromPurchase(purchase)

Adapty.reportTransaction(transactionInfo, variationId) { result ->
    if (result is AdaptyResult.Success) {
        // success
    }
}
```

パラメーター:

| パラメータ      | 必須/任意 | 説明                                                         |
| --------------- | --------- | ------------------------------------------------------------ |
| transactionInfo | 必須      | 購入から取得した TransactionInfo。購入はビリングライブラリの [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) クラスのインスタンスです。 |
| variationId     | 任意      | バリアントの文字列識別子。`AdaptyPaywall` オブジェクトの `variationId` プロパティから取得できます。 |

</TabItem>
<TabItem value="java" label="Java" default>

```java showLineNumbers
TransactionInfo transactionInfo = TransactionInfo.fromPurchase(purchase);

Adapty.reportTransaction(transactionInfo, variationId, result -> {
    if (result instanceof AdaptyResult.Success) {
        // success
    }
});
```

パラメーター:

| パラメーター    | 必須/任意 | 説明                                                         |
| --------------- | --------- | ------------------------------------------------------------ |
| transactionInfo | 必須      | 購入から取得したTransactionInfo。ここでの購入は、billing libraryの[Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase)クラスのインスタンスです。 |
| variationId     | 任意      | バリアントの文字列識別子。`AdaptyPaywall`オブジェクトの`variationId`プロパティから取得できます。 |

</TabItem>

オブザーバーモードでは、Adapty SDK は既存の購入システムを通じて行われた購入を単独で追跡することができません。アプリストアからトランザクションを報告するか、復元する必要があります。アナリティクスのエラーを避けるために、アプリをリリースする**前に**これを設定することが重要です。

`restorePurchases` を使用して、トランザクションを Adapty に報告します。

:::warning

**購入の復元をスキップしないでください！**
`restorePurchases` を呼び出さないと、Adapty はトランザクションを認識できず、アナリティクスにも表示されず、インテグレーションにも送信されません。

:::

Adapty のフローやペイウォールを使用している場合は、`setVariationId` メソッドを使って購入につながったフローまたはペイウォールにトランザクションをリンクしてください。これにより、正確なアナリティクスのために購入が正しくアトリビュートされます。

<Tabs groupId="current-os" queryString>
<TabItem value="kotlin" label="Kotlin" default>

```kotlin showLineNumbers
Adapty.restorePurchases { result ->
    if (result is AdaptyResult.Success) {
        // success
    }
}

Adapty.setVariationId(transactionId, variationId) { error ->
    if (error == null) {
        // success
    }
}
```

パラメーター:

| パラメーター | 必須/任意 | 説明 |
| ------------- | -------- | ------------------------------------------------------------ |
| transactionId | required | 購入の文字列識別子（`purchase.getOrderId`）。ここでの purchase は、請求ライブラリの [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) クラスのインスタンスです。 |
| variationId   | required | バリアントの文字列識別子。`AdaptyPaywall` オブジェクトの `variationId` プロパティから取得できます。 |

</TabItem>
<TabItem value="java" label="Java" default>

```java showLineNumbers
Adapty.restorePurchases(result -> {
    if (result instanceof AdaptyResult.Success) {
        // success
    }
});

Adapty.setVariationId(transactionId, variationId, error -> {
    if (error == null) {
        // success
    }
});
```

パラメータ:

| パラメータ     | 必須/任意 | 説明                                                  |
| ------------- | -------- | ------------------------------------------------------------ |
| transactionId | 必須 | 購入のString識別子（`purchase.getOrderId`）。ここでいう購入は、billing libraryの[Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase)クラスのインスタンスです。 |
| variationId   | 必須 | バリアントのString識別子。`AdaptyPaywall`オブジェクトの`variationId`プロパティから取得できます。 |

</TabItem>

**トランザクションの報告**

オブザーバーモードでトランザクションを Adapty に報告するには、[モバイルコードでの購入を復元する](android-restore-purchase)ページで説明されている `restorePurchases` を使用してください。

:::warning
**トランザクションの報告を省略しないでください！**
`restorePurchases` を呼び出さないと、Adapty はトランザクションを認識できず、アナリティクスに表示されず、インテグレーションにも送信されません。
::: 

**フローとペイウォールをトランザクションに関連付ける**

Adapty SDK は購入のソースを特定できません。これはお客様自身が処理しているためです。したがって、Observerモードでフロー、ペイウォール、またはA/Bテストを使用する場合は、アプリストアからのトランザクションを、モバイルアプリのコード内で対応するフローまたはペイウォールに関連付ける必要があります。これはアプリをリリースする前に正しく設定することが重要です。そうしないと、アナリティクスにエラーが発生します。

<Tabs groupId="current-os" queryString>
<TabItem value="kotlin" label="Kotlin" default>

```kotlin 
Adapty.setVariationId(transactionId, variationId) { error ->
    if (error == null) {
        // success
    }
}
```

リクエストパラメータ：

| パラメータ | 必須/任意 | 説明 |
| ------------- | -------- | ------------------------------------------------------------ |
| transactionId | 必須 | 文字列識別子（purchase.getOrderId）。ここでの purchase は、課金ライブラリの [Purchase](https://developer.android.com/reference/com/android/billingclient/api/Purchase) クラスのインスタンスです。 |
| variationId   | 必須 | バリアントの文字列識別子。`AdaptyPaywall` オブジェクトの `variationId` プロパティから取得できます。 |

</TabItem>
