既存の購入インフラがあり、Adapty への完全移行をすぐには行いたくない場合は、[オブザーバーモード](observer-vs-full-mode)をご検討ください。基本的な形では、オブザーバーモードは高度な分析機能と、アトリビューション・分析システムとのシームレスな統合を提供します。

これで要件を満たせる場合は、以下の2つの手順だけで利用できます。
1. Adapty SDK を設定する際に、`observerMode` パラメータを `true` に設定してオンにします。設定手順については [React Native](sdk-installation-reactnative) をご覧ください。
2. 既存の購入インフラから Adapty へ[トランザクションを報告](report-transactions-observer-mode-react-native)します。

:::tip
SDK v4では、ObserverモードでAdapty描画のフローやペイウォールを表示することもできます。ユーザーが対応するボタンをタップした際に、独自のコードで購入やリストアを実行するには、`onObserverPurchaseInitiated`と`onObserverRestoreInitiated`のイベントハンドラーを設定してください。詳しくは[Observerモードでフローを表示する](react-native-present-flows-in-observer-mode)をご覧ください。
:::

### オブザーバーモードのセットアップ \{#observer-mode-setup\}

購入とサブスクリプションのステータスを自分で管理し、サブスクリプションイベントの送信と分析にのみAdaptyを使用する場合は、オブザーバーモードを有効にしてください。

:::important
オブザーバーモードで動作している場合、Adapty SDKはトランザクションをクローズしないため、必ず自分でトランザクションを処理してください。
:::

```typescript showLineNumbers title="App.tsx"

adapty.activate('YOUR_PUBLIC_SDK_KEY', {
  observerMode: true, // Enable observer mode
});
```

パラメータ：

| パラメータ                   | 説明                                                  |
| --------------------------- | ------------------------------------------------------------ |
| observerMode                | [オブザーバーモード](observer-vs-full-mode)を制御するboolean値。デフォルト値は `false` です。 |

## Observer Modeでのフローとペイウォールの使用 \{#using-adapty-paywalls-in-observer-mode\}

フロー、ペイウォール、A/B テスト機能も使用したい場合、Observer Modeでは追加の設定が必要です。上記の手順に加えて、以下の対応が必要となります。

1. [リモートコンフィグペイウォール](present-remote-config-paywalls-react-native)は通常どおり表示してください。フローおよびペイウォールビルダーで作成したペイウォールについては、[Observerモードでフローを表示する](react-native-present-flows-in-observer-mode)を参照してください。
2. フローとペイウォールを購入トランザクションに[関連付けます](report-transactions-observer-mode-react-native)。
