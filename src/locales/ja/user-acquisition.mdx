Adapty Attributionは、ウェブからアプリへのキャンペーンにおける広告費用とサブスクリプション収益を紐付け、アプリの経済全体を一か所で把握できるようにします。

Adapty Attributionで収益データを確認するには、まずAdaptyダッシュボードでインテグレーションを有効にする必要があります。APIキー、トークン、識別子などを渡す必要はありません。Adapty SDKを更新・設定するだけです。

:::important
Adapty Attributionは以下のバージョンで利用可能です：
- iOS、Android、Flutter SDK バージョン 3.9.1 以上
- React Native および Capacitor SDK バージョン 3.10.0 以上
- Unity SDK バージョン 3.12.0 以上
- Kotlin Multiplatform SDK バージョン 3.15.0 以上

SDK バージョン 4.1 以降、Adapty Attribution はデフォルトで無効になっています。[アプリのコードで有効化してください](#step-1-enable-adapty-attribution-in-the-sdk)。
:::

## 始める前に \{#before-you-start\}

収益データとキャンペーンのパフォーマンスを連携させるために、Adapty で購入を追跡できるよう設定してください：

- **すでに Adapty でアプリ内課金を実装している場合**、この段階で追加の作業は必要ありません。
- **まだアプリ内課金を実装しておらず、Adapty を使用したい場合**、[クイックスタートガイド](quickstart)の手順を完了して、購入処理を Adapty に委任してください。
- **Adapty を使用せずにすでにアプリ内課金を実装しており**、Adapty のコア機能を使用する予定がない場合は、[オブザーバーモードでお使いのプラットフォームに Adapty SDK をインストール](implement-observer-mode)してください。この段階では、SDK をプロジェクトに追加し、オブザーバーモードを有効にして起動し、トランザクションをレポートするだけで構いません。

このセットアップにより、ウェブからアプリへのアトリビューションが有効になります：
- ユーザーがアプリをインストールすると、Adapty SDK がインストールを報告し、Adapty Attribution はそれをキャンペーンと照合できます。
- Adapty SDK はアプリ内の収益関連イベントをすべて把握しており、それらをウェブキャンペーンにアトリビュートできます。

## ステップ1. SDKでAdaptyアトリビューションを有効にする \{#step-1-enable-adapty-attribution-in-the-sdk\}

Adapty SDK バージョン4.1以降、Adaptyアトリビューションはデフォルトで無効になっています。SDKがインストールを登録し、インストールの詳細をアプリに配信できるようにするには、SDKを有効化する際に以下の設定を行ってください：

<Tabs groupId="current-os" queryString>
<TabItem value="swift" label="Swift" default>

```swift showLineNumbers
let configurationBuilder = AdaptyConfiguration
    .builder(withAPIKey: "YOUR_PUBLIC_SDK_KEY")
    .with(adaptyAttributionEnabled: true)
```

</TabItem>
<TabItem value="kotlin" label="Kotlin">

```kotlin showLineNumbers
val config = AdaptyConfig.Builder("YOUR_PUBLIC_SDK_KEY")
    .withAdaptyAttributionEnabled(true)
    .build()

Adapty.activate(applicationContext, config)
```

</TabItem>
<TabItem value="java" label="Java">

```java showLineNumbers
AdaptyConfig config = new AdaptyConfig.Builder("YOUR_PUBLIC_SDK_KEY")
    .withAdaptyAttributionEnabled(true)
    .build();

Adapty.activate(getApplicationContext(), config);
```

</TabItem>
<TabItem value="rn" label="React Native (TS)">

```typescript showLineNumbers
adapty.activate('YOUR_PUBLIC_SDK_KEY', {
  adaptyAttributionEnabled: true,
});
```

</TabItem>
<TabItem value="kmp" label="Kotlin Multiplatform">

```kotlin showLineNumbers
val config = AdaptyConfig
    .Builder("YOUR_PUBLIC_SDK_KEY")
    .withAdaptyAttributionEnabled(true)
    .build()

Adapty.activate(configuration = config)
```

</TabItem>
<TabItem value="capacitor" label="Capacitor (TS)">

```typescript showLineNumbers
await adapty.activate({
  apiKey: 'YOUR_PUBLIC_SDK_KEY',
  params: {
    adaptyAttributionEnabled: true,
  }
});
```

</TabItem>
<TabItem value="flutter" label="Flutter (Dart)">

```dart showLineNumbers
await Adapty().activate(
  configuration: AdaptyConfiguration(apiKey: 'YOUR_PUBLIC_SDK_KEY')
    ..withAdaptyAttributionEnabled(true)
);
```

</TabItem>
</Tabs>

SDKバージョン4.1未満では、Adapty アトリビューションは自動的に有効になるため、コードの変更は不要です。

AdaptyがインストールをADクリックに紐付けるには、初回起動時からアプリ起動時にSDKを有効化してください。SDKは有効化後にインストールを報告するため、有効化が遅れると報告も遅れます。

## ステップ2. Adapty Attributionを開く \{#step-2-open-adapty-attribution\}

:::important
Adaptyロゴをクリックしても **Attribution** が表示されない場合は、ブラウザの設定でadapty.ioのCookieとサイトデータをクリアしてから、ページを再読み込みしてください。
:::

ヘッダーのAdaptyロゴをクリックして、**Attribution** を選択します。

<ZoomImage id="product-switcher.webp" width="500px" alt="Adapty product switcher" />

サブスクリプションイベントは自動的にAdapty Attributionに流れ込みます。キャンペーンデータはステップ3でデータソースを接続した後に表示されます。

イベント配信を一時停止するには、Adapty ダッシュボードの **Integrations > Adapty** を開き、トグルをオフにしてください。

- トライアル

## ステップ3. 広告プラットフォームを接続してトラッキングリンクを追加する \{#step-3-connect-your-ad-platform-and-add-tracking-links\}

Adapty はトラッキングリンクを使って、アプリのインストールとキャンペーンデータを紐付けます。Adapty Attribution で広告を計測するには:

- **App Store または Google Play に誘導する広告**: トラッキングリンクをリンク先 URL として使用してください。
- **ウェブファネルに誘導する広告**: [Adapty のパラメータで URL にタグを付ける](ua-tag-ad-urls)。

Google Ads キャンペーンの場合は、代わりに [Adapty Attribution と Google Ads を連携する](ua-google-ads) を参照してください。

複数のプラットフォームで広告を運用している場合は、プラットフォームごとにトラッキングリンクを設定してください。

広告プラットフォームとの連携方法は2つあります。

- **ネイティブ連携（Meta Ads、TikTok Ads、Google Ads）。** Adaptyが広告プラットフォームに直接接続します。トラッキングリンクは自動生成され、キャンペーンのパラメーターはリンクの使用場所に応じて動的に設定されます。異なるキャンペーン、広告セット、クリエイティブで同じリンクを使用でき、Adaptyは正しいキャンペーンデータと広告費用を自動的に受け取ります。

- **トラッキングリンクのみ（その他すべての広告プラットフォーム）。** Adapty は広告プラットフォームに接続しません。トラッキングリンクは手動で作成し、すべてのキャンペーンパラメータはリンク作成時に明示的に定義する必要があります。これらのプラットフォームでは広告費用データは取得できません。Meta Ads、TikTok Ads、Google Ads のキャンペーンにはネイティブ連携をご利用ください。

<Tabs>
<TabItem value="meta" label="Meta Ads" default>
Meta Ads のトラッキングリンクを作成するには：
1. Adapty Attribution ダッシュボードの [Integrations > Meta](https://app.adapty.io/ua/integrations/facebook/accounts) に移動し、**Continue with Facebook** をクリックします。

<ZoomImage id="ua-connect-meta.webp" width="700px" />
2. Facebook アカウントでサインインし、**Continue** をクリックします。

<ZoomImage id="ua-fb-sign.webp" width="500px" />

3. 要求された権限を確認し、**Save** をクリックします。
4. ヘッダーで宣伝するアプリを選択します。次に **Web Campaigns** タブに切り替え、**Create configuration** をクリックします。

<ZoomImage id="ua-new-campaign.webp" width="500px" />

5. **General** タブで **iOS** および/または **Android** セクションを展開し、App Store および/または Google Play のアプリケーション URL を貼り付けます。次に、**Save** をクリックします。

<ZoomImage id="ua-url.webp" width="900px" />

6. **Click link** フィールドの値を、**1つのリンク**またはプラットフォーム固有のリンクからコピーします。次に、Meta Ads Manager で広告を開き、このリンクをデスティネーション URL として貼り付けます。

:::important
Metaの広告審査を通過させるために、リンクを`?`の位置で分割してください。**Website URL**フィールドには`?`より前の部分（例：`https://api-ua.adapty.io/api/v1/attribution/c/YOUR_CODE`）を貼り付けます。各ウェブキャンペーンには固有のコードがあるため、他の広告ではなく設定中のキャンペーンからこの値をコピーしてください。`?`以降の部分は、**Tracking**セクションの**URL parameters**フィールドに貼り付けます。詳細はMetaアカウントガイドの[広告を作成する](meta-create-campaign#step-5-create-ads)をご覧ください。
:::

7. これで Meta Ads で広告を配信すると、そのデータが Adapty Attribution ダッシュボードで分析できるようになります。

3. 要求されたパーミッションを確認し、**Save** をクリックします。

    <ZoomImage id="ua-tiktok-sign.webp" width="500px" />
4. ヘッダーで宣伝するアプリを選択します。次に **Web Campaigns** タブに切り替えて、**Create configuration** をクリックします。

    <ZoomImage id="ua-new-campaign-tiktok.webp" width="500px" />

5. **General** タブで **iOS** および/または **Android** セクションを展開し、App Store および/または Google Play のアプリケーション URL を貼り付けます。次に **Save** をクリックします。

</TabItem>
<TabItem value="others" label="その他の広告プラットフォーム">
その他の広告プラットフォーム向けにトラッキングリンクを作成するには：

1. Adapty Attribution ダッシュボードで **Integrations** を開き、**Network** グループの **Custom** カードを選択します。そこで **Create link** をクリックします。

    <ZoomImage id="new-tracking-link.webp" width="700px" />

2. リストからアプリを選択し、**Next** をクリックします。

    <ZoomImage id="ua-choose-app.webp" width="700px" />

3. リンクのパラメータを入力して、トラッキングしたいキャンペーンや広告と紐づけます。
4. デフォルトでは、One Link が作成されます。これはユーザーのプラットフォームを自動検出し、クリックをトラッキングした後に App Store または Google Play へリダイレクトします。

    プラットフォームごとに異なるリダイレクト URL を使用したい場合は、**One Link** チェックボックスの選択を解除し、各プラットフォームのストアリンクを手動で入力してください。

    <ZoomImage id="one-link.webp" width="700px" />

5. **Create** をクリックします。
6. トラッキングリンクのページを開き、いずれかのセクションから **Click link** をコピーします：
    - **One link** – クリックを計測し、ユーザーを自動的に適切なストアにリダイレクトするリンクです。
    - **iOS link** または **Android link** — ストアごとに別々のリンクを使用したい場合のプラットフォーム別リンクです（任意）。
7. 広告プラットフォームに移動し、広告の遷移先 URL としてリンクを貼り付けます。

</TabItem>

## ステップ 4. ウェブからアプリへのキャンペーンを開始して結果を確認する \{#step-4-launch-your-web-to-app-campaign-and-view-results\}

キャンペーンが公開されてユーザーがアプリをインストールし始めると、Adapty はインストールと収益をキャンペーンにアトリビュートします。

[Adapty アトリビューション分析ダッシュボード](ua-analytics) では、以下のようなキャンペーンレベルの指標を確認できます：
- インストール数とコンバージョン
- サブスクリプションおよび購入による収益
- 広告プラットフォーム、キャンペーン、広告セット、クリエイティブ別のパフォーマンス内訳

インストールはダッシュボードに約10分以内、購入は約30分以内に表示されます。広告費データはネイティブ統合に対応しているプラットフォームで利用可能で、Adaptyは4時間ごとに更新します。
