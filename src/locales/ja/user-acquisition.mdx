Adapty Attributionは、ウェブからアプリへのキャンペーンにおける広告費用とサブスクリプション収益を紐付け、アプリの経済全体を一か所で把握できるようにします。

Adapty Attributionで収益データを確認するには、まずAdaptyダッシュボードでインテグレーションを有効にする必要があります。APIキー、トークン、識別子などを渡す必要はありません。Adapty SDKを更新・設定するだけです。
:::important
Adapty Attributionは以下のバージョンで利用可能です：
- iOS、Android、Flutter SDK バージョン 3.9.1 以上
- React Native および Capacitor SDK バージョン 3.10.0 以上
- Unity SDK バージョン 3.12.0 以上
- Kotlin Multiplatform SDK バージョン 3.15.0 以上

SDK バージョン 4.1 以降、Adapty Attribution はデフォルトで無効になっています。[アプリのコードで有効化してください](#step-1-enable-adapty-attribution-in-the-sdk)。
:::

## 始める前に \{#before-you-start\}

収益データとキャンペーンのパフォーマンスを連携させるために、Adapty で購入を追跡できるよう設定してください：
- すでに **Adapty を使ってアプリ内課金を実装済みの場合**、この段階では他に何もする必要はありません。
- **アプリ内課金をまだ実装していなく、Adapty を使いたい場合**は、[クイックスタートガイド](quickstart) の手順を完了して、購入処理を Adapty に委任してください。
- **Adapty を使わずにアプリ内課金をすでに実装済みで、Adapty への移行を予定していない場合**は、[オブザーバーモードでお使いのプラットフォーム向けに Adapty SDK をインストール](implement-observer-mode)してください。この段階では、プロジェクトに SDK を追加し、オブザーバーモードを有効にして起動し、トランザクションを報告するだけで構いません。
このセットアップにより、ウェブからアプリへのアトリビューションが有効になります：
- ユーザーがアプリをインストールすると、Adapty SDKがリンクパラメータからインストールの詳細を取得し、Adapty アトリビューションがキャンペーンの詳細を取得できるようになります
- Adapty SDKはアプリ内のすべての収益関連イベントを把握し、それらをウェブキャンペーンにアトリビュートできます。
## ステップ1. SDKでAdaptyアトリビューションを有効にする \{#step-1-enable-adapty-attribution-in-the-sdk\}

Adapty SDK バージョン4.1以降、Adaptyアトリビューションはデフォルトで無効になっています。SDKがインストールを登録し、インストールの詳細をアプリに配信できるようにするには、SDKを有効化する際に以下の設定を行ってください：

<Tabs groupId="current-os" queryString>
<TabItem value="swift" label="Swift" default>

```swift showLineNumbers
let configurationBuilder = AdaptyConfiguration
    .builder(withAPIKey: "YOUR_PUBLIC_SDK_KEY")
    .with(adaptyAttributionEnabled: true)
```

</TabItem>
<TabItem value="kotlin" label="Kotlin">

```kotlin showLineNumbers
val config = AdaptyConfig.Builder("YOUR_PUBLIC_SDK_KEY")
    .withAdaptyAttributionEnabled(true)
    .build()

Adapty.activate(applicationContext, config)
```

</TabItem>
<TabItem value="java" label="Java">

```java showLineNumbers
AdaptyConfig config = new AdaptyConfig.Builder("YOUR_PUBLIC_SDK_KEY")
    .withAdaptyAttributionEnabled(true)
    .build();

Adapty.activate(getApplicationContext(), config);
```

</TabItem>
</Tabs>

SDK バージョン 4.1 未満では、Adapty アトリビューションは自動的に有効になるため、コードの変更は不要です。

## ステップ 2. Adapty Attribution を開く \{#step-2-open-adapty-attribution\}

:::important
Adapty ロゴをクリックしても **Attribution** が表示されない場合は、ブラウザの設定で adapty.io の Cookie とサイトデータを削除してから、ページを再読み込みしてください。
:::

ヘッダーの Adapty ロゴをクリックして、**Attribution** を選択してください。

<ZoomImage id="product-switcher.webp" width="500px" alt="Adapty product switcher" />

サブスクリプションイベントは自動的に Adapty Attribution に流れ込み始めます。キャンペーンデータは、ステップ 3 でデータソースを接続した後に表示されます。

イベント配信を一時停止するには、Adapty ダッシュボードの **Integrations > Adapty** を開き、トグルをオフにしてください。

- トライアル

## ステップ3. 広告プラットフォームを連携してトラッキングリンクを追加する \{#step-3-connect-your-ad-platform-and-add-tracking-links\}

Adaptyはトラッキングリンクを使って、アプリのインストールとキャンペーンデータを紐づけます。
Adapty アトリビューションで計測したいすべての広告キャンペーンにおいて、トラッキングリンクを必ず遷移先URLとして使用してください。

複数の広告プラットフォームで広告を運用している場合は、プラットフォームごとに個別にトラッキングリンクを設定してください。

AdaptyがAdプラットフォームと連携する方法は2つあります。

- **ネイティブ連携（Meta Ads、TikTok Ads）。** Adaptyが広告プラットフォームに直接接続します。トラッキングリンクは自動生成され、キャンペーンパラメータはリンクの使用場所に応じて動的に設定されます。同じリンクを異なるキャンペーン、広告セット、クリエイティブで使い回せ、Adaptyは正しいキャンペーンデータと広告費用を自動的に受け取ります。

- **トラッキングリンクのみ（その他すべての広告プラットフォーム）。** Adapty は広告プラットフォームに接続しません。トラッキングリンクは手動で作成され、リンク作成時にすべてのキャンペーンパラメーターを明示的に定義する必要があります。これらのプラットフォームでは広告費用データは利用できません。

<Tabs>
<TabItem value="meta" label="Meta Ads" default>
Meta Ads のトラッキングリンクを作成するには:
1. Adapty Attribution ダッシュボードで [Integrations > Meta](https://app.adapty.io/ua/integrations/facebook/accounts) に移動し、**Continue with Facebook** をクリックします。

<ZoomImage id="ua-connect-meta.webp" width="700px" />
2. Facebookアカウントでサインインし、**Continue** をクリックします。

<ZoomImage id="ua-fb-sign.webp" width="500px" />

3. 要求されるパーミッションを確認し、**Save** をクリックします。
4. **Web campaigns** タブに切り替えて **Create campaign** をクリックします。アプリを選択し、**Save** をクリックします。

<ZoomImage id="ua-new-campaign.webp" width="500px" />

5. **General** タブで **iOS** および/または **Android** セクションを展開し、App Store および/または Google Play のアプリケーション URLを貼り付けます。次に、**Save** をクリックします。

<ZoomImage id="ua-url.webp" width="900px" />

6. **Click link** フィールドの値を **1つのリンク**またはプラットフォーム固有のリンクのいずれかからコピーします。次に、Meta Ads Manager で広告を開き、このリンクをデスティネーション URL として貼り付けます。

:::important
**Website URL** フィールドには `https://api-ua.adapty.io/api/v1/attribution/click` を貼り付けてください。リンクの残りの部分は、**Tracking** セクションの **URL parameters** フィールドに貼り付けます。これにより、Meta 広告の審査が通りやすくなります。詳しくは [Meta Ads Manager での広告設定に関する推奨事項](meta-create-campaign) をご覧ください。
:::

7. これで Meta Ads で広告を配信すると、そのデータが Adapty Attribution ダッシュボードで分析できるようになります。
</TabItem>
<TabItem value="tiktok" label="TikTok for Business">
TikTok for Business のトラッキングリンクを作成するには：
1. Adapty Attribution ダッシュボードの [Integrations > TikTok Ads](https://app.adapty.io/ua/integrations/tiktok/accounts) に移動し、**Continue with TikTok** をクリックします。
   <ZoomImage id="ua-connect-tiktok.webp" width="700px" />
2. TikTok アカウントでサインインし、**Continue** をクリックします。

3. 要求されたパーミッションを確認し、**Save** をクリックします。

<ZoomImage id="ua-tiktok-sign.webp" width="500px" />
4. **Web campaigns** タブに切り替え、**Create campaign** をクリックします。アプリを選択して **Save** をクリックします。

    <ZoomImage id="ua-new-campaign-tiktok.webp" width="500px" />

5. **General** タブで **iOS** および/または **Android** セクションを展開し、App Store および/または Google Play のアプリケーション URL を貼り付けます。その後、**Save** をクリックします。

    <ZoomImage id="ua-url.webp" width="900px" />

6. **Click link** フィールドの値を、**one link** または プラットフォーム別リンクからコピーします。次に、TikTok Ads Manager で広告を作成する際に、**Advanced Settings** セクションの **Tracking URL** フィールドにこの値を貼り付けます。これにより、Adapty はインストールと購入を TikTok の広告に紐付けられるようになります。詳しくは [TikTok Ads でキャンペーンを設定するガイド](tiktok-create-campaign) をご覧ください。

    <ZoomImage id="ua-lnk.webp" width="900px" />
7. TikTok for Business で広告を開始すると、そのデータが Adapty のアトリビューション ダッシュボードで分析できるようになります。

</TabItem>
<TabItem value="others" label="Other ad platforms">
その他の広告プラットフォームのトラッキングリンクを作成するには：

1. Adapty Attribution ダッシュボードで、サイドバーメニューから **Tracking links** に移動し、**Create link** をクリックします。

    <ZoomImage id="new-tracking-link.webp" width="700px" />

2. リストからアプリを選択し、**Next** をクリックします。

    <ZoomImage id="ua-choose-app.webp" width="700px" />

3. リンクのパラメータを入力して、トラッキングしたいキャンペーンや広告と紐づけます。
4. デフォルトでは、One Link が作成されます。これはユーザーのプラットフォームを自動検出し、クリックをトラッキングした後に App Store または Google Play へリダイレクトします。

    プラットフォームごとに異なるリダイレクト URL を使用したい場合は、**One Link** チェックボックスの選択を解除し、各プラットフォームのストアリンクを手動で入力してください。

    <ZoomImage id="one-link.webp" width="700px" />

5. **Create** をクリックします。
6. トラッキングリンクのページを開き、いずれかのセクションから **Click link** をコピーします：
    - **One link** – クリックを計測し、ユーザーを自動的に適切なストアにリダイレクトするリンクです。
    - **iOS link** または **Android link** — ストアごとに別々のリンクを使用したい場合のプラットフォーム別リンクです（任意）。
7. 広告プラットフォームに移動し、広告の遷移先 URL としてリンクを貼り付けます。

</TabItem>
</Tabs>

## ステップ 4. ウェブからアプリへのキャンペーンを開始して結果を確認する \{#step-4-launch-your-web-to-app-campaign-and-view-results\}

キャンペーンが開始され、ユーザーがアプリをインストールし始めると、Adapty はインストールと収益をキャンペーンに紐づけ始めます。

[Adapty アトリビューション アナリティクス ダッシュボード](ua-analytics) では、以下のようなキャンペーンレベルの指標を確認できます：
- インストール数とコンバージョン
- サブスクリプションおよび購入による収益
- 広告プラットフォーム、キャンペーン、広告セット、クリエイティブ別のパフォーマンス内訳

指標は、アプリからインストールおよび収益イベントが受信され次第、表示されます。広告費用データは、ネイティブ連携に対応しているプラットフォームで利用できます。
