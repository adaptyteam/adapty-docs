入力フォームを使用して、名前・メールアドレス・生年月日などのデータをユーザーから収集できます。回答を保存し、フロー内の別の場所で参照できます。たとえば、後続の画面でユーザーを名前で呼びかけることが可能です。

## 入力を追加する \{#add-an-input\}

<ZoomImage id="add-input.webp" width="400px" float="right" alt="Add input" />

1. **Add element** パネルを開きます。
2. **Forms & Quiz** カテゴリで **Input** をクリックします。
3. 入力タイプを選択します：
   - **Text：** 短いテキストの入力。
   - **E-mail：** メールアドレス。任意のフォーマット検証付き。
   - **Password：** セキュアなテキスト入力。設定可能な要件付き。
   - **Number：** 数値。設定可能なフォーマット付き。
   - **Phone number：** 電話番号。
   - **Date：** 日付ピッカーを開きます。
   - **Time：** 時刻ピッカーを開きます。
   - **Date & Time：** 組み合わせピッカーを開きます。
   - **[Number picker](builder-number-picker)：** ホイールの最小値と最大値を設定します。ユーザーはその範囲内で数値を選択します。

## 入力フィールドの設定 \{#configure-an-input\}

:::link
レイアウト、スタイル、表示に関する詳細は、[スタイルと外観](builder-styling)をご覧ください。
:::

すべての入力タイプについて、**Design** タブで次の設定が可能です。

- **Type:** テキストフィールドの種類を「テキスト」「メール」「パスワード」「数値」「電話番号」から切り替えます。日時ピッカーは「日付」「時刻」「日付と時刻」から切り替えられます。
- **Element ID:** フロー内の他の場所で入力値を参照するための識別子です。後述の「[入力値を使用する](#use-input-values)」をご覧ください。
- **Placeholder:** フィールドが空のときに表示されるヒントテキストです。
- **State:** 状況に応じた入力欄の見た目を定義します。**Default**、**Active**、**Invalid**、**Disabled** を切り替えて、それぞれ異なる見た目を適用できます。これらのいずれの状態にも当てはまらない見た目が必要な場合は、[カスタム状態を追加](builder-element-states#add-a-custom-state)してください。カスタム状態は、回答、タップ、または別の要素の状態に応じて切り替えることができます。
- **Typography:** フィールドに表示される値のテキストスタイルです。
- **Leading and trailing icons:** 入力フィールド内にアイコンを追加します。パスワード入力の場合、追加できるのは先頭アイコン（leading icon）のみです。

[Number picker](builder-number-picker) は、このリストから **Element ID** と **Typography** の設定のみを持ちます。

<ZoomImage id="input-settings.webp" width="700px" alt="Add input" />

一部の設定は、特定の入力タイプに固有のものです：

| 設定                         | 入力タイプ                     |
|------------------------------|-------------------------------|
| クリアボタン                 | テキスト、メール               |
| メール形式の検証             | メール                         |
| パスワードアイコンの表示     | パスワード                     |
| パスワード要件の編集         | パスワード                     |
| 数値フォーマット             | 数値                           |
| 日付/時刻フォーマット        | 日付、時刻、日付と時刻         |
| 最小・最大日付               | 日付、日付と時刻               |

## 入力値を使用する \{#use-input-values\}

:::tip
アプリ側でも入力値を受け取ることができます。受け取るには、[SDKのアナリティクスコールバックを処理](ios-flow-input)してください。ユーザーが入力を離れるたびに、コールバックが入力値を返し、アプリ内で処理できます。

Number pickerの場合、ユーザーが別の画面を開くボタンをタップしたときにコールバックが値を返します。同じ画面上でクイズの選択肢をタップしたり、トグルを操作したりした場合も同様に返されます。
:::

すべての入力は自動的に変数として利用できます。セットアップや **On Submit** アクションは不要です。値は入力の **Element ID** を通じて参照され、**Input Settings** または **Picker Settings** で設定します。

フロー内の別の場所でこの入力値を使用するには（例：コピーのパーソナライズ、別フィールドへの値の反映、条件付きナビゲーションの制御など）、変数を挿入して次を選択します：

**Element > Screen > `<elementId>.value`**

:::link
保存された入力値の使い方については、以下のガイドをご覧ください：
- [条件付きナビゲーション](onboarding-navigation-branching)
- [変数](onboarding-variables)
:::

## 入力値のバリデーション \{#input-validation\}

バリデーションの動作は入力タイプによって異なります。Number picker を除くすべての入力は、読み取り専用の Boolean 変数 `<elementId>.isValid` を公開します。これは入力された値がそのバリデーションルールを満たしているかどうかを反映します。条件付きアクションや条件付き表示で使用できます。たとえば、メールアドレスのフォーマットが有効になるまで「次へ」ボタンを非表示にするといった使い方が可能です。

:::note
- `isValid` 変数は読み取り専用です。値を設定することはできません。
- 空の入力は常に有効とみなされます。
- テキスト入力にはバリデーションルールがありません。`textInput.isValid` は常に `True` を返します。
:::

| 入力タイプ | バリデーションの動作 |
|---|---|
| テキスト | 組み込みのバリデーションルールはありません。 |
| メールアドレス | オプションです。**Design** パネルの **Validate email format** を有効にすると、入力値のメール形式チェックが行われます。 |
| 電話番号 | 組み込みの電話番号形式チェックがあります。ビルダーでは設定できません。ルールは実行時に評価されます。 |
| パスワード | 設定可能です。下記の [パスワード要件](#password-requirements) を参照してください。 |
| 数値 | 形式ベースです。入力値は選択した数値フォーマットに一致する必要があります。下記の [数値フォーマット](#number-format) を参照してください。 |
| 日付、時刻、日付と時刻 | 組み込みです。ピッカーは有効な日付または時刻の値のみ受け付けます。 |

**Invalid** [ビジュアルステート](builder-styling#input-states)は、ユーザーがフォームを送信したとき（たとえば、キーボードのEnterキーやDoneキーを押したとき）に有効になります。それまでは、**Active** や **Default** など別のステートが適用されます。

### パスワード要件 \{#password-requirements\}

パスワード入力フィールドでは、バリデーションルールを設定できます。**Design** パネルの **Edit password requirements** をクリックするとルールエディターが開きます。有効なルールは入力フィールドの下にリアルタイムのチェックリストとして表示され、条件が満たされるとその項目にチェックマークが付きます。

利用可能なルール：

- **Min length** — 最小文字数。デフォルト: 8。
- **Max length** — 最大文字数。デフォルト: 32。
- **Uppercase letter** — 大文字（A〜Z）を1文字以上含む。
- **Lowercase letter** — 小文字（a〜z）を1文字以上含む。
- **Number** — 数字を1文字以上含む。
- **Special character** — 英数字以外の文字（例: `!@#$%`）を1文字以上含む。

パスワードは、有効なすべてのルールを満たした場合にのみ有効となります。

### 数値形式 \{#number-format\}

**Number** インプット設定の **Format** ドロップダウンで、入力値の解析方法を制御します：

- **Integer** — 整数のみ（例：`4`）。
- **Decimal (Point)** — ピリオドを小数点区切り文字とする小数（例：`4.89`）。
- **Decimal (Comma)** — カンマを小数点区切り文字とする小数（例：`4,89`）。

選択した形式と一致しない値は無効と見なされます。

## 入力イベントへのアクションのトリガー \{#trigger-actions-on-input-events\}

:::link
メイン記事: [アクション](onboarding-actions)
:::

**Interactions** パネルから、ユーザーの入力に応じてアクションを実行できます：

- **On changed** — ユーザーが入力値を変更したときに発火します。すべての入力タイプで使用できます。
- **On submit** — ユーザーがキーボードの Enter または Done を押してテキスト入力を送信したときに発火します。日付・時刻ピッカーおよび数値ピッカーにはこのトリガーはありません。
