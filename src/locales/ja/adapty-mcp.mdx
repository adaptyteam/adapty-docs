Adapty MCPサーバーは、AIアシスタントをあなたのAdaptyアカウントに接続します。チャットで平易な言葉を使って、収益やコンバージョンについて質問したり、プロダクトやプレースメントのセットアップ、フローの公開、A/Bテストの開始などができます。アシスタントはブラウザでAdaptyアカウントにサインインし、あなたの権限を取得します。APIキーは不要です。

| | |
|---|---|
| サーバーURL | `https://mcp.adapty.io/mcp` |
| プロトコル | Streamable HTTP上のMCP、ブラウザでのOAuth 2.1サインイン |
| 対応クライアント | Claudeアプリ（WebおよびDesktop）、Claude Code、Codex、およびOAuthサインインをサポートするその他のMCPクライアント |

:::important
MCP サーバーは [Adapty スキル](#add-the-adapty-skills)と組み合わせることで最大限の効果を発揮します。サーバーはアシスタントにアカウントへのアクセスを提供し、スキルは実績あるワークフローを提供します。フローやペイウォールの構築、アナリティクスでのテスト対象の特定はスキルに依存しています。
:::

## Adapty スキルを追加する \{#add-the-adapty-skills\}

MCP サーバーはアシスタントに Adapty アカウントへのアクセスを提供します。Adapty スキルはその実行方法を提供します。変更を計画し、検証し、ユーザーに影響を与えるステップごとに確認を求める、テスト済みのワークフローです。この MCP サーバーには、スキルと合わせてインストールしてください。`adapty-skills` プラグインにはスキルとこの MCP サーバーが含まれています。

スキルが必要な作業は 2 種類あります。

- **フローとペイウォール**: [flow-generator スキル](flow-generator-skill)には、フロービルダーの設定ルールが含まれています。説明またはスクリーンショットからスクリーンを構築し、フローを保存する前にすべての変更を検証してプレビューします。スキルがない場合、アシスタントはフローの設定を読み書きできますが、有効な設定のルールを持っていません。
- **アナリティクスと次にテストすべきこと**: [growth-advisor スキル](export-analytics-with-ai)は、どのレポートをどのように読むかを把握し、あなたの数値をA/B テストの仮説に変換します。スキルがない場合、アシスタントはチャートを取得できますが、それを説明する方法を持っていません。

### Claudeアプリでプラグインを追加する \{#add-the-plugin-in-the-claude-app\}

プラグインはClaudeの設定から追加できます。コマンドラインは不要です。

1. Claudeで **Settings** → **Plugins** を開きます。
2. **Add** → **Add marketplace** をクリックします。
3. **Add from a repository** を選択します。
4. **URL** フィールドに `adaptyteam/adapty-skills` と入力し、リポジトリを選択します。新しいスキルや修正を随時受け取るには、**Sync automatically** をオンのままにしておきます。
5. **Sync** をクリックします。

<ZoomImage id="adapty-skills-claude-add-marketplace.png" width="584px" alt="Add marketplace dialog in Claude with adaptyteam/adapty-skills in the URL field and Sync automatically turned on" />

Claude は **Discover** タブを開き、Adapty マーケットプレイスのプラグインを表示します。スキルをインストールするには、**Adapty** の行にある **Add** をクリックします。

<ZoomImage id="adapty-skills-claude-discover.png" width="600px" alt="Discover tab in Claude listing the Adapty, Apple ads, and Apple ads benchmarks plugins, each with an Add button" />

スキルはClaude のサンドボックス内でスクリプトを実行します。これを許可するには、**Settings** → **Capabilities** で **Code execution and file creation** をオンにしてください。

### コーディングエージェントにプラグインをインストールする \{#add-the-plugin-in-a-coding-agent\}

Claude Code、Codex、Copilot CLI、Gemini CLI、Cursor、その他のコーディングエージェントで次のコマンドを実行します。

```bash
npx adapty skills install
```

このコマンドは、エージェントが専用のインストーラーを持っている場合はそれを通じてプラグインをインストールします。実行後はエージェントを再起動してください。Claude Code と Codex では、プラグインによって Adapty MCP サーバーも追加されるため、[アシスタントを接続する](#connect-your-assistant) で説明しているようにサインインするだけで使えます。

<Details summary="MCPサーバーを使うスキルとCLIを使うスキル">

各スキルは最初のステップの前に、エージェントが MCPサーバー、[Adapty Developer CLI](developer-cli)、またはその両方を持っているかどうかを検出します。どちらか一方があれば、スキルはそれを使用します。両方ある場合は、作業に適した方を使用します：

- **MCP サーバー**: A/B テストの実行、Adapty アトリビューションの読み取り、SDK の統合、Apple Ads の実行、購入のテスト。
- **Adapty CLI**: フローの構築と監査、次にテストすべき内容の特定、プレースメントのフローへの移行、セグメントの作成。これらのスキルは独自のスクリプトやファイルを実行し、CLI がファイルを直接渡します。

</Details>

## アシスタントにできること \{#what-the-assistant-can-do\}

サーバーのツールは、Adapty ダッシュボードおよび [Adapty Developer CLI](developer-cli) に準拠しています。アシスタントはリクエストに応じて適切なツールを選択します。ツール名を指定する必要はありません。

| 機能エリア | アシスタントでできること | 質問例 |
|---|---|---|
| アプリとアクセスレベル | アプリとアクセスレベルの一覧表示・作成・更新 | "Fitness Pro に `premium` というアクセスレベルを作成して。" |
| プロダクトとオファー | プロダクトの作成（ストアのプロダクトIDを含む）、ストアオファーとの紐付け | "Google PlayのプロダクトIDが設定されていないプロダクトはどれ？" |
| ペイウォール | ペイウォールの作成・更新、各ペイウォールを表示しているプレースメントの確認 | "Annual sale ペイウォールを表示しているプレースメントはどれ？" |
| フロー | フローの作成、ビルダーコンフィグの読み書き、バリデーション、プレビュー、公開、フロー指標の確認 | "Onboarding v2 フローを公開して、それを表示しているプレースメントを教えて。" |
| プレースメントとオーディエンス | プレースメントの作成、表示内容の変更、フロープレースメントの指標確認 | "`onboarding` プレースメントでは、誰に何が表示されている？" |
| セグメント | セグメントとそのフィルター条件の確認 | "セグメントの一覧と、それぞれのフィルター条件を教えて。" |
| A/B テスト | ペイウォールおよびフローのA/B テストの作成・開始・停止・差し替え・アーカイブ | "ドイツのユーザー向けのドラフトテスト Weekly vs annual を開始して。" |
| アナリティクス | 収益・MRR・コンバージョン・ファネル・リテンション・LTV・インストールコホートの確認 | "先月の国別トライアル→有料コンバージョン率を比較して。" |
| アトリビューション | [Adapty アトリビューション](user-acquisition)からキャンペーンのパフォーマンスを確認 | "9月に費用対効果が出たキャンペーンはどれ？" |
| Apple Ads | [Adapty Ads Manager](developer-cli-ads-manager)でキャンペーン・広告グループ・キーワード・自動化ルールの運用と指標確認 | "先週、インストールがゼロなのに最も費用がかかったキーワードはどれ？" |
| RevenueCatからの移行 | RevenueCatのカタログを新しいAdaptyアプリに移行する作業の作成・実行 | "RevenueCatのプロジェクトを新しいAdaptyアプリに移動して。" |

Adapty Mail には専用の MCP サーバーがあります。アシスタントを Adapty Mail プロジェクトに接続するには、[AI アシスタントで Adapty Mail を管理する](mail-mcp)をご覧ください。

## MCPサーバーまたはCLIを選ぶ \{#choose-the-mcp-server-or-the-cli\}

MCPサーバーと[Adapty Developer CLI](developer-cli)は、どちらも同じAdaptyアカウントにアクセスします。アシスタントがどこで動作するかに応じて選択してください：

| | Adapty MCPサーバー | Adapty CLI |
|---|---|---|
| 動作環境 | Claudeアプリなどのチャットアプリを含む、あらゆるMCPクライアント | ターミナルコマンドを実行するエージェント、および独自のスクリプト |
| サインイン | クライアントごとに1回、ブラウザで実施 | `adapty auth login`、マシンごとに1回 |
| 最適な用途 | チャットからの質問や変更 | フローコンフィグの編集、一括変更、スクリプト |
| インストール | インストール不要 | `npm install -g adapty` |

エージェントはどちらも使用できます。Claude アプリでは、MCP サーバーの方が CLI よりもセットアップが少なくて済みます。CLI は会話のたびにインストールと認証が必要ですが、その手順は [Claude アプリで Adapty CLI をセットアップする](developer-cli-cowork) に記載されています。

## 始める前に \{#before-you-start\}

- **Adapty アカウント**: アシスタントは、あなたの Adapty アカウントでアクセスできる企業やアプリの範囲内で、あなたの権限に基づいて動作します。
- **OAuth 対応の MCP クライアント**: OAuth でサインインできるリモート MCP サーバーをクライアントがサポートしている必要があります。

:::warning
アシスタントはあなたの権限で操作を行い、その変更は実際に反映されます。A/B テストの開始やプレースメントの変更は、ユーザーに即座に影響します。A/B テストの開始・停止、またはプレースメントの表示対象の変更を行う前に、サーバーはアシスタントに対して変更内容の詳細を説明させ、あなたの承認を待つよう求めます。承認する前に必ず内容を確認してください。
:::

## アシスタントを接続する \{#connect-your-assistant\}

<Tabs groupId="mcp-client" queryString>
<TabItem value="claude-app" label="Claude app" default>

Claude app（claude.ai およびClaude デスクトップ）では、リモートMCPサーバーをカスタムコネクターとして追加できます。

1. サーバーを追加するには、**Settings → Connectors** を開き、**Add custom connector** をクリックします。
2. 名前（例：`Adapty`）とURL `https://mcp.adapty.io/mcp` を入力します。
3. デフォルトの認証設定のままにして、**Add** をクリックします。
4. 開いたブラウザタブでAdaptyにサインインします。[サインイン](#sign-in)を参照してください。

ワークスペース管理者は組織全体に対して一度だけコネクターを追加できます。各メンバーは初回利用時に自分のAdaptyアカウントでサインインします。

</TabItem>
<TabItem value="claude-code" label="Claude Code">

`adapty-skills` プラグインを使用している場合、Claude Code ではすでにサーバーが `plugin:adapty-skills:adapty` として一覧表示され、ステータスは **Needs authentication** になっています。サインインするには、Claude Code で `/mcp` を実行し、`plugin:adapty-skills:adapty` を選択して **Authenticate** を選択してください。

プラグインを使用していない場合は、先にサーバーを追加してください：

```bash
claude mcp add --transport http --scope user adapty https://mcp.adapty.io/mcp
```

次に、Claude Code で `/mcp` を実行し、`adapty` を選択して **Authenticate** を選んでください。現在のセッションで Adapty のツールが表示されない場合は、新しいセッションを開始してください。

</TabItem>
<TabItem value="codex" label="Codex">

`adapty-skills` プラグインを使用している場合、プラグインがサーバーを追加し、接続時に Codex がサインインを求めます。

プラグインを使用しない場合は、サーバーを追加してサインインしてください：

```bash
codex mcp add adapty --url https://mcp.adapty.io/mcp
codex mcp login adapty
```

loginコマンドはブラウザを開きます。代わりにサーバーを手動で設定するには、`~/.codex/config.toml` に追加してから、loginコマンドを実行します：

```toml
[mcp_servers.adapty]
url = "https://mcp.adapty.io/mcp"
```

Adaptyツールを読み込むには、新しい `codex` セッションを開始してください。

</TabItem>
<TabItem value="other" label="その他のクライアント">

クライアントの設定またはMCP設定ファイルに `https://mcp.adapty.io/mcp` をリモートMCPサーバーとして追加してください。初回接続時に、クライアントがサインイン用のブラウザを開きます。

サーバーは、現在の MCP 仕様のクライアント登録方式である Client ID Metadata Document によって各クライアントを識別します。この方式をサポートしていないクライアントはサインインを完了できません。その場合は、ターミナルエージェントから [Adapty Developer CLI](developer-cli-quickstart) を代わりに使用してください。

</TabItem>
</Tabs>

## サインイン \{#sign-in\}

どのクライアントも最終的に同じ場所、つまりブラウザに表示される Adapty のサインインページへ誘導されます。

1. まだログインしていない場合は、Adapty アカウントでログインしてください。
2. クライアントが Adapty アカウントにアクセスすることを許可してください。

クライアントはその後、あなたのアカウントでアクセスできる企業のデータを読み取ったり変更したりします。接続を切断するまでサインイン状態が維持されます。自分で開始したサインインのみを承認してください。

接続を確認するには、アシスタントにどの Adapty アカウントにサインインしているかを聞いてみてください。あなたの名前とアカウントでアクセスできる企業名が返ってくるはずです。

## 作業を開始する \{#start-working\}

アシスタントに参照可能なアプリを尋ね、作業対象のアプリ名を伝えましょう。試せるリクエスト例:

```text
List my Adapty apps and their placements.
How did revenue and new subscriptions change last month compared with the month before?
Which products in Fitness Pro have no App Store product ID?
Show who sees what on the onboarding placement, including any A/B test.
Create a draft A/B test on main_paywall: the current paywall against Annual sale, 50/50.
```

ユーザーが目にするものを変更するステップの前に、アシスタントは確認を求めます。データの読み取りのみのリクエストは、確認なしに実行されます。

複数のステップにわたるタスクが完了した後、アシスタントはAdaptyチームにタスクの進行状況に関する短いメモを送ることができます。このメモには、アプリのユーザーの個人データは含まれません。

## 接続を解除する \{#disconnect\}

接続を解除するには、クライアント側でサーバーを削除します。

- **Claude app**: **Settings → Connectors** で Adapty コネクターを削除します。
- **Claude Code**: `claude mcp remove adapty` を実行します。サーバーが `adapty-skills` プラグインとともに追加された場合は、代わりに `/mcp` で無効化します。
- **Codex**: `~/.codex/config.toml` から `adapty` サーバーを削除します。

再度接続するには、サーバーを追加してもう一度サインインしてください。

## トラブルシューティング \{#troubleshooting\}

| 問題 | 解決策 |
|---|---|
| Claude Code でサーバーが **Needs authentication** と表示される | クライアントがサーバーを追加したがサインインしていない。`/mcp` を実行し、Adapty サーバーを選択して **Authenticate** を選ぶ。 |
| クライアントに Adapty のツールが表示されない | サインインを完了してから新しいセッションを開始する。クライアントによってはセッション開始時にのみツールを読み込む場合がある。 |
| アシスタントがアプリを見つけられない | そのアプリは、あなたの Adapty アカウントがアクセスできない会社に属している。会社のオーナーにアクセス権を依頼する。 |
| クライアントがサインインを完了できない | クライアントがサーバーの使用するサインイン方式に対応していない。Claude アプリ、Claude Code、または Codex から接続するか、[Adapty Developer CLI](developer-cli-quickstart) を使用する。 |
