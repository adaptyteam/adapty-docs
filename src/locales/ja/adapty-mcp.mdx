Adapty MCPサーバーは、AIアシスタントをあなたのAdaptyアカウントに接続します。チャットで自然な言葉を使って、収益やコンバージョンについて質問したり、プロダクトやプレースメントの設定、フローの公開、A/Bテストの開始、Apple Ads キャンペーンの運用などができます。アシスタントはブラウザ上でAdaptyアカウントにサインインし、あなたの権限で動作します。APIキーは不要です。

| | |
|---|---|
| サーバーURL | `https://mcp.adapty.io/mcp` |
| プロトコル | Streamable HTTP経由のMCP、ブラウザでのOAuth 2.1サインイン |
| 対応クライアント | claude.ai、Claude desktop、Claude Code、Codex、およびOAuthサインインをサポートするその他のMCPクライアント |

:::important
MCPサーバーを使うと、アシスタントはあなたのAdaptyアカウントにアクセスできるようになります。フローの設定ルール、アナリティクスのテスト済み手法、そしてユーザーに影響する各ステップの前に確認を行うノウハウを持たせるには、まず[Adapty プラグイン](manage-adapty-with-ai#install-the-plugin)をインストールしてください。Claude CodeとCodexでは、プラグインがこのサーバーを自動的に追加するため、[サインイン](#connect-your-assistant)するだけで使えます。
:::

## アシスタントにできること \{#what-the-assistant-can-do\}

サーバーのツールは、Adapty ダッシュボードおよび [Adapty Developer CLI](developer-cli) に準拠しています。アシスタントはリクエストに応じて適切なツールを選択します。ツール名を指定する必要はありません。

| エリア | アシスタントにできること | 質問の例 |
|---|---|---|
| アプリとアクセスレベル | アプリとアクセスレベルの一覧表示・作成・更新 | 「Fitness Pro に `premium` アクセスレベルを作成して。」 |
| プロダクトとオファー | プロダクトの作成（ストアプロダクト ID の設定）、ストアオファーとの紐付け | 「Google Play プロダクト ID が設定されていないプロダクトはどれ？」 |
| ペイウォール | ペイウォールの作成・更新、各ペイウォールを表示しているプレースメントの確認 | 「Annual sale ペイウォールを表示しているプレースメントはどれ？」 |
| フロー | フローの作成、ビルダー設定の読み書き、バリデーション・プレビュー・公開、フロー指標の確認 | 「Onboarding v2 フローを公開して、どのプレースメントに表示されているか教えて。」 |
| プレースメントとオーディエンス | プレースメントの作成・表示対象の変更、フロープレースメントの指標確認 | 「`onboarding` プレースメントで誰が何を見ているか教えて。」 |
| セグメント | セグメントとそのフィルター条件の確認 | 「セグメントの一覧と、それぞれのフィルター条件を教えて。」 |
| A/B テスト | ペイウォールおよびフローの A/B テストの作成・開始・停止・差し替え・アーカイブ | 「ドイツのユーザー向けに Weekly vs annual のドラフトテストを開始して。」 |
| アナリティクス | 収益・MRR・コンバージョン・ファネル・リテンション・LTV・インストールコホートの確認 | 「先月の国別トライアルから有料転換率を比較して。」 |
| Apple Ads | [Adapty Ads Manager](adapty-ads-manager) でキャンペーン・広告グループ・キーワード・自動化ルールの管理と指標確認 | 「先週インストールがなかったのに最も費用がかかったキーワードはどれ？」 |
| RevenueCat からの移行 | RevenueCat カタログを新しい Adapty アプリへ移行する作業の作成と実行 | 「RevenueCat プロジェクトを新しい Adapty アプリに移行して。」 |

Adapty Mail には専用の MCP サーバーがあります。アシスタントを Adapty Mail プロジェクトに接続するには、[AI アシスタントで Adapty Mail を管理する](mail-mcp)をご覧ください。

## MCP サーバーまたは CLI を選択する \{#choose-the-mcp-server-or-the-cli\}

MCP サーバーと [Adapty Developer CLI](developer-cli) は同じ Adapty アカウントにアクセスします。どちらも設定されていない場合、Adapty プラグインがセットアップ方法を案内します。両方が設定されている場合は、タスクごとに適切な方が選択されます。

| | Adapty MCP サーバー | Adapty CLI |
|---|---|---|
| 実行環境 | claude.ai や Claude デスクトップを含む任意の MCP クライアント | ターミナルコマンドを実行するエージェント、および独自スクリプト |
| サインイン | ブラウザでクライアントごとに1回 | `adapty auth login`（マシンごとに1回） |
| 最適な用途 | チャットからの質問や変更 | フローコンフィグの編集、一括変更、スクリプト |
| インストール | インストール不要 | `npm install -g adapty` |

claude.ai やClaude デスクトップでは、MCPサーバーはCLIよりもセットアップの手間がかかりません。CLIは[Claude アプリでAdapty CLIをセットアップする](developer-cli-cowork)で説明されているように、会話のたびにインストールと認証が必要です。

<Details summary="どのスキルがMCPサーバーを使用し、どのスキルがCLIを使用するか">

各スキルは最初のステップの前に、アシスタントがMCPサーバー、CLI、またはその両方を持っているかどうかを検出します。どちらか一方だけであれば、スキルはそれを使用します。両方ある場合は、作業内容に適した方を使用します：

- **MCP サーバー**: A/B テストの実行、Apple Ads の運用、SDK の統合、購入のテスト。
- **Adapty CLI**: フローの構築と監査、次にテストすべき点の発見、プレースメントからフローへの移行、セグメントの作成。これらのスキルは独自のスクリプトやファイルを実行し、CLI がファイルを直接渡します。

</Details>

## 始める前に \{#before-you-start\}

- **Adaptyアカウント**: アシスタントは、あなたのAdaptyアカウントでアクセスできる企業およびアプリ内で、あなたの権限に基づいて動作します。
- **OAuthに対応したMCPクライアント**: OAuthでサインインするリモートMCPサーバーをサポートするクライアントが必要です。

:::warning
アシスタントはあなたの権限で動作し、その変更は実際に反映されます。開始されたA/B テストや変更されたプレースメントはユーザーに届き、変更されたApple Ads の入札額や予算は実際のお金を使います。アシスタントがA/B テストを開始・停止したり、プレースメントで誰に何を表示するかを変更したりする前に、サーバーはアシスタントに正確な影響を説明させ、あなたの承認を待ちます。承認する前に、必ずプランを確認してください。
:::

## アシスタントの接続 \{#connect-your-assistant\}

<Tabs groupId="mcp-client" queryString>
<TabItem value="claude-app" label="claude.ai" default>

claude.ai と Claude デスクトップでは、リモート MCP サーバーをカスタムコネクタとして追加します。

1. サーバーを追加するには、**Settings → Connectors** を開き、**Add custom connector** をクリックします。
2. 名前（例：`Adapty`）と URL `https://mcp.adapty.io/mcp` を入力します。
3. 認証設定はデフォルトのままにして、**Add** をクリックします。
4. 開いたブラウザタブで Adapty にサインインします。[サインイン](#sign-in) を参照してください。

ワークスペースの管理者は、組織全体に対して一度だけコネクターを追加できます。各メンバーは初回使用時に自分の Adapty アカウントでサインインします。

</TabItem>
<TabItem value="claude-code" label="Claude Code">

Adapty プラグインをインストールした場合、Claude Code にはすでに `plugin:adapty-skills:adapty` というサーバーが **Needs authentication** というステータスで表示されています。サインインするには、Claude Code で `/mcp` を実行し、`plugin:adapty-skills:adapty` を選択して **Authenticate** を選択してください。

プラグインなしの場合は、まずサーバーを追加してください：

```bash
claude mcp add --transport http --scope user adapty https://mcp.adapty.io/mcp
```

その後、Claude Code で `/mcp` を実行し、`adapty` を選択して **Authenticate** をクリックします。現在のセッションで Adapty のツールが表示されない場合は、新しいセッションを開始してください。

</TabItem>
<TabItem value="codex" label="Codex">

Adapty プラグインをインストールしている場合、プラグインがサーバーを追加し、接続時に Codex がサインインを求めます。

プラグインを使用しない場合は、サーバーを追加してサインインします：

```bash
codex mcp add adapty --url https://mcp.adapty.io/mcp
codex mcp login adapty
```

loginコマンドはブラウザを開きます。代わりにサーバーを手動で設定するには、`~/.codex/config.toml` に追加してから、loginコマンドを実行します：

```toml
[mcp_servers.adapty]
url = "https://mcp.adapty.io/mcp"
```

Adaptyツールを読み込むには、新しい `codex` セッションを開始してください。

</TabItem>
<TabItem value="other" label="その他のクライアント">

クライアントの設定またはMCP設定ファイルに `https://mcp.adapty.io/mcp` をリモートMCPサーバーとして追加してください。初回接続時に、クライアントがサインイン用のブラウザを開きます。

サーバーは、現在の MCP 仕様のクライアント登録方式である Client ID Metadata Document によって各クライアントを識別します。この方式をサポートしていないクライアントはサインインを完了できません。その場合は、ターミナルエージェントから [Adapty Developer CLI](developer-cli-quickstart) を代わりに使用してください。

</TabItem>
</Tabs>

## サインイン \{#sign-in\}

どのクライアントも最終的に同じ場所、つまりブラウザに表示される Adapty のサインインページへ誘導されます。

1. まだログインしていない場合は、Adapty アカウントでログインしてください。
2. クライアントが Adapty アカウントにアクセスすることを許可してください。

クライアントはその後、あなたのアカウントでアクセスできる企業のデータを読み取ったり変更したりします。接続を切断するまでサインイン状態が維持されます。自分で開始したサインインのみを承認してください。

接続を確認するには、アシスタントにどの Adapty アカウントにサインインしているかを聞いてみてください。あなたの名前とアカウントでアクセスできる企業名が返ってくるはずです。

## 作業を開始する \{#start-working\}

アシスタントに参照可能なアプリを尋ね、作業対象のアプリ名を伝えましょう。試せるリクエスト例:

```text
List my Adapty apps and their placements.
How did revenue and new subscriptions change last month compared with the month before?
Which products in Fitness Pro have no App Store product ID?
Show who sees what on the onboarding placement, including any A/B test.
Create a draft A/B test on main_paywall: the current paywall against Annual sale, 50/50.
```

ユーザーが目にするものを変更するステップの前に、アシスタントは確認を求めます。データの読み取りのみのリクエストは、確認なしに実行されます。

複数のステップにわたるタスクが完了した後、アシスタントはAdaptyチームにタスクの進行状況に関する短いメモを送ることができます。このメモには、アプリのユーザーの個人データは含まれません。

## 切断 \{#disconnect\}

切断するには、クライアントからサーバーを削除します：

- **claude.ai**：**Settings → Connectors** で Adapty コネクターを削除します。
- **Claude Code**：`claude mcp remove adapty` を実行します。サーバーが Adapty プラグインと一緒にインストールされた場合は、代わりに `/mcp` で無効化してください。
- **Codex**：`~/.codex/config.toml` から `adapty` サーバーを削除します。

再度接続するには、サーバーを追加してもう一度サインインしてください。

## トラブルシューティング \{#troubleshooting\}

| 問題 | 解決策 |
|---|---|
| Claude Code でサーバーが **Needs authentication** と表示される | クライアントがサーバーを追加したが、サインインしていない。`/mcp` を実行し、Adapty サーバーを選択して **Authenticate** を選択する。 |
| クライアントに Adapty ツールが表示されない | サインインを完了してから新しいセッションを開始する。クライアントによっては、セッション開始時にのみツールを読み込む場合がある。 |
| アシスタントがアプリを見つけられない | そのアプリは、Adapty アカウントからアクセスできない会社に属している。会社のオーナーにアクセス権を依頼する。 |
| クライアントがサインインを完了できない | クライアントがサーバーの使用するサインイン方法に対応していない。claude.ai、Claude Code、または Codex から接続するか、[Adapty Developer CLI](developer-cli-quickstart) を使用する。 |
