App Store上のアプリをAdaptyに接続することで、購入の検証、サブスクリプションイベントの受信、ストアからのプロダクト情報の取得が可能になります。

各ストアは個別に接続する必要があります。Adapty は接続済みのストアのみ購入を検証します。Google Play でもアプリを配信している場合は、[そちらも接続してください](initial-android)。両者は独立しており、一方を設定しても他方の作業は変わりません。

設定は App Store Connect と Adapty ダッシュボードにまたがり、所要時間は約 30 分です。

## 初期連携ガイド \{#guide-for-the-initial-integration\}

- [ ] Adapty でアカウントを作成し、モバイルアプリ名とカテゴリを入力すると、Adapty プラットフォーム内でアプリが設定されます。
- [ ] Adapty ダッシュボードと App Store Connect で [App Store インテグレーションを設定する](app-store-connection-configuration)。
- [ ] 使用しているフレームワーク向けに Adapty SDK をインストールする:
  - [ ] [iOS ネイティブ向け Adapty SDK をインストールする](sdk-installation-ios)
  - [ ] [React Native 向け Adapty SDK をインストールする](sdk-installation-reactnative)
  - [ ] [Flutter 向け Adapty SDK をインストールする](sdk-installation-flutter)
  - [ ] [Unity 向け Adapty SDK をインストールする](sdk-installation-unity)
  - [ ] [Kotlin Multiplatform 向け Adapty SDK をインストールする](sdk-installation-kotlin-multiplatform)
- [ ] アプリをビルドし、サンドボックスモードで実行する。

初期インテグレーションが完了したら、[Adaptyの機能を使い始める](product)ことができます。

モバイルアプリケーションでペイウォールやプロダクトを表示し、アナリティクスを機能させるには、アプリのコードに変更を加える必要があります。具体的には、少なくとも[ペイウォールの表示](ios-quickstart-paywalls)を実装し、ペイウォールビルダーで作成されていないペイウォールを使用している場合は、アプリ内で[購入処理](making-purchases)も実装する必要があります。

:::danger
アプリをリリースする前にリリースチェックリストを確認してください

アプリケーションをリリースする前に、[リリースチェックリスト](release-checklist)を必ず確認してください。Adapty SDKを組み込んだアプリを公開する前に、すべての必要な手順が完了していることを確認できます。
:::
