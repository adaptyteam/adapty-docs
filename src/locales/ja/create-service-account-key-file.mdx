Play StoreのモバイルアプリをAdaptyと連携するには、Google Cloud Consoleで専用のサービスアカウントキーファイルを生成し、Adaptyにアップロードする必要があります。これらのファイルはアプリを保護し、不正アクセスを防ぐために役立ちます。

:::warning
新しいサービスアカウントが有効になるまで、通常は少なくとも24時間かかります。ただし、[回避策](https://stackoverflow.com/a/60691844)があります。[Google Play Console](https://play.google.com/apps/publish/)でサービスアカウントを作成したら、任意のアプリを開いて **Monetize** -> **Products** -> **Subscriptions/In-app products** に移動します。いずれかのプロダクトの説明を編集して変更を保存してください。これによりサービスアカウントが即座に有効化されるので、その後で変更を元に戻すことができます。
:::

1. Google Cloud Consoleの[**サービスアカウント**](https://console.cloud.google.com/iam-admin/serviceaccounts)セクションを開きます。正しいプロジェクトが選択されていることを確認してください。

2. 表示されたウィンドウで **Add key** をクリックし、ドロップダウンメニューから **Create new key** を選択します。

3. **Create private key for [Your_project_name]** ウィンドウで、**Create** をクリックします。秘密鍵がJSONファイルとしてコンピューターに保存されます。**Private key saved to your computer** ウィンドウに表示されたファイル名を使って確認できます。

4. **Create private key for Your_project_name** ウィンドウで、**Create** ボタンをクリックします。この操作により、秘密鍵がJSONファイルとしてコンピューターに保存されます。必要に応じて、開いた **Private key saved to your computer** ウィンドウに表示されるファイル名を使って、ファイルの場所を確認できます。

このファイルは、[Google Play ストアの連携を設定する](google-play-store-connection-configuration)際に必要になります。

:::warning
新しいサービスアカウントが有効になるまで、通常少なくとも24時間かかります。ただし、[裏技](https://stackoverflow.com/a/60691844)があります。[Google Play Console](https://play.google.com/apps/publish/)でサービスアカウントを作成したら、任意のアプリを開き、**Monetize** -> **Products** -> **Subscriptions/In-app products** に移動します。任意のプロダクトの説明を編集して保存してください。これによりサービスアカウントがすぐに有効化されます。その後、変更を元に戻してもかまいません。
:::
