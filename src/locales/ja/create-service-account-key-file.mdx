キーファイルはサービスアカウントの認証情報です。Adaptyはこれをサービスアカウントとしてサインインするためのキーとして使用し、GoogleのAPIをあなたの代わりに呼び出します。

## 始める前に \{#before-you-start\}

[サービスアカウントに Play Console の権限を付与してください](grant-permissions-to-service-account)。キーが持つアクセス権は、アカウントがすでに持っているものだけです。

## キーファイルを生成する \{#generate-the-key-file\}

1. Google Cloud Console の [**IAM & Admin** > **Service accounts**](https://console.cloud.google.com/iam-admin/serviceaccounts) を開き、正しいプロジェクトにいることを確認します。

2. 作成したサービスアカウントをクリックします。

3. **Keys** タブを開き、**Add key** > **Create new key** をクリックします。

   <ZoomImage id="gp-keys-add-key.webp" width="700px" alt="Keys tab of a service account in Google Cloud Console, with the Add key menu open" />

4. **Key type** は **JSON** のままにして、**Create** をクリックします。ファイルがコンピューターにダウンロードされます。

<ZoomImage id="gp-create-json-key.webp" width="700px" alt="JSONをキータイプとして選択した秘密鍵の作成ダイアログ" />

:::warning
このファイルは安全な場所に保管してください。Googleは再ダウンロードを許可しておらず、このファイルを持っている人は誰でもサービスアカウントとして操作できてしまいます。
:::

## アカウントをすぐにアクティベートする \{#activate-the-account-immediately\}

新しいサービスアカウントのアクティベートには最低24時間かかります。それまでの間、AdaptyはプロダクトをG読み取ることができません。この待ち時間をスキップするには、[Google Play Console](https://play.google.com/console/) で **Monetize with Play** > **Products** > **Subscriptions** に移動し、任意のプロダクトの説明を編集して保存してください。すぐに元に戻しても構いません。

<ZoomImage id="gp-edit-product-description.webp" width="700px" alt="Subscription details page in Google Play Console with the Description field" />

:::warning
このキーファイルが後で削除またはローテーションされると、Adapty はプロダクトの読み取りと購入の検証ができなくなります。Adapty はそれを通知しません — 詳細は[更新が届かなくなった場合](store-sync#if-updates-stop-arriving)を参照してください。
:::
