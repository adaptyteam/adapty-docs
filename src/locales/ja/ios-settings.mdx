**App settings** の [**iOS SDK**](https://app.adapty.io/settings/ios-sdk) タブには、アプリの App Store 認証情報が格納されています。すべての情報を入力するには、[App Store インテグレーションの設定](app-store-connection-configuration)に従ってください。

<ZoomImage id="app-settings-ios-sdk.webp" width="700px" alt="App settings の iOS SDK タブ" />

| セクション | 内容とAdaptyが必要とする理由 | 設定場所 |
|---|---|---|
| **SDK status** | AdaptyのSDKがアプリにインストールされているかどうか | [Adapty SDKのインストール](installation-of-adapty-sdks) |
| **Bundle ID** | 購入を処理するためのアプリのBundle ID | [Bundle IDとApple App IDを入力する](app-store-connection-configuration#enter-the-bundle-id-and-apple-app-id) |
| **In-app purchase API (StoreKit 2)** | 購入を検証するためのアプリ内課金キー | [アプリ内課金キーをAdaptyに追加する](generate-in-app-purchase-key) |
| **App Store Connect shared secret** | 購入レシートの検証およびApp Store Connectでのプロダクト作成に使用するアプリ固有の共有シークレット | [アプリ固有の共有シークレットを入力する](app-store-connection-configuration#enter-the-app-specific-shared-secret) |
| **App Store server notifications** | Appleからサブスクリプションイベントを受信するURLと、Adaptyがイベントを転送する任意のサーバーURL | [App Storeサーバー通知を有効にする](enable-app-store-server-notifications) |
| **Apple Retention Messaging API** | Retention Messaging APIのアクセスをリクエストする際にAppleに提出するURL | [Retention Messagingを設定する](retention-messaging-setup) |
| **App Store promotional offers** | プロモーションオファーに署名するためのアプリ内課金キーのIDとファイル | [アプリ内課金キーをAdaptyに追加する](generate-in-app-purchase-key) |
| **App Store Connect API key** | プロダクトの作成およびステータスと価格の同期のためにApp Store Connectの**Team Keys**タブから取得するキー | [App Store Connect APIキーをAdaptyに追加する](app-store-connect-api-key) |
| **Apple App ID** | App Store Connectでプロダクトを検索・作成するために使用するアプリのApple ID（他の用途にも使用） | [Bundle IDとApple App IDを入力する](app-store-connection-configuration#enter-the-bundle-id-and-apple-app-id) |
