フロー & ペイウォールビルダーはレスポンシブなレイアウトを作成します。要素を正確な座標にドラッグするのではなく、**コンテナ**の中に入れ子にすることで、子要素が自動的に配置されます。

コンテナは要素の方向（縦または横）、揃え方、間隔を決定します。各要素はさらにサイズやマージンを細かく調整できます。また必要に応じて、絶対配置や固定配置でフローから切り離すこともできます。

:::

## レイアウト \{#layout\}

<ZoomImage id="flow-builder/layout.webp" width="300px" float="right" alt="Layout settings" />

レイアウトは、画面上の要素を配置するための主要なツールです。各コンテナは、方向・配置・間隔といったルールに従って子要素を自動的に配置します。ビルダーで利用できるレイアウト要素は次のとおりです。

* **[縦方向コンテナ](builder-containers#containers)**：子要素を上から下へ並べる
* **[横方向コンテナ](builder-containers#containers)**：子要素を左から右へ並べる
* **[区切り線](builder-containers#dividers)**：要素間を視覚的に区切るセパレーター
* **[カルーセル](builder-containers#carousel)**：横方向にスクロールできるスライドのセット
* **[ボトムシート](builder-containers#bottom-sheet)**：ユーザーがボタンをタップしたときに追加コンテンツを表示するスライド式のオーバーレイパネル

コンテナは画面の主要な構成要素です。コンテナを入れ子にすることで、複雑なレイアウトを構築できます。各コンテナには右パネルに **Layout** セクションがあり、子要素の配置方法を制御します。

要素を新しいコンテナにグループ化するには、**Wrap** [レイヤーアクション](paywall-layout-and-products#layer-actions)を使用してください。コンテナを削除して子要素を昇格させるには、**Unwrap** を使用してください。

<ZoomImage id="flow-builder/alignment-distribution-demo.webp" width="600px" alt="配置と分布のオプション" />

:::link
スクリーンとレイヤーの階層について詳しくは、[スクリーンとレイヤー](paywall-layout-and-products)をご覧ください。
:::

### Direction

* <Inline id="free-layout.svg" alt="Free" /> **Free**：自動レイアウトなし。子要素は整列せず、重なり合います。**Free** を選択すると、すべての子要素が[**Absolute** ポジション](#position-in-a-free-container)に変換され、[スタッキング順序](#stacking-order)で重なりの優先度が決まります
* <Inline id="vertical-layout.svg" alt="Vertical" /> **Vertical**：子要素が上から下へ積み重なります（列の行のようなイメージ）
* <Inline id="horizontal-layout.svg" alt="Horizontal" /> **Horizontal**：子要素が左から右へ並びます（行のアイテムのようなイメージ）

### 要素の順序 \{#element-order\}

子要素は**Layers**パネルに表示されている順序でレンダリングされます。垂直コンテナでは、リストの先頭にある要素が画面の上部に表示されます。水平コンテナでは、先頭の要素が左側に表示されます。要素を並び替えるには、Layersパネルでドラッグするか、**Move up**・**Move down**の[レイヤーアクション](paywall-layout-and-products#layer-actions)を使用してください。

### アライメント \{#alignment\}

<ZoomImage id="flow-builder/alignment.webp" width="100px" float="right" alt="Layout settings" />

アライメントグリッドは、子要素がコンテナのクロス軸に沿ってどこに配置されるかを制御します。縦方向のコンテナでは、アライメントは子要素の水平方向の配置（左、中央、右）を制御します。横方向のコンテナでは、垂直方向の配置（上、中央、下）を制御します。

### 配置 \{#distribution\}

配置（Distribution）は、メイン軸に沿って子要素間のスペースをどのように分割するかを決定します：

* **Gap** <Inline id="gap.svg" alt="Gap" />（デフォルト）: 隣接する子要素間の固定ピクセル値
* **Space Between**: 子要素が両端に広がり、間に等間隔のギャップが表示される
* **Space Around**: 各子要素の周囲に等しいスペースが配置され、端のギャップは半分のサイズになる
* **Space Evenly**: すべての子要素の前後および間に等しいスペースが配置される


### コンテンツのクリッピング \{#clip-content\}

コンテナの境界を超えたコンテンツを視覚的にクリップします。これを無効にすると、オーバーフローが許可されます（例：カードの端を意図的にはみ出すバッジなど）。

## 位置 \{#position\}

<ZoomImage id="flow-builder/position-relative.webp" width="300px" float="right" alt="位置切り替えトグル" />

デフォルトでは、各要素の位置はコンテナのレイアウトによって自動的に決まります。**Position** トグルを使うと、通常のフローから切り離して手動で位置を指定できます。

<ZoomImage id="flow-builder/positioning-demo.webp" width="700px" alt="絶対配置と固定配置の動作例" />

### 相対位置（デフォルト）\{#relative-default\}

要素は通常のレイアウトフロー内に配置されます。位置は親コンテナのレイアウトルールによって自動的に決まるため、自由にドラッグすることはできません。相対要素の周囲のスペースを調整するには**Margin**を使用してください。

テキストブロック、画像、カード、ボタン、リストアイテムなど、ほとんどのコンテンツには相対位置を使用してください。

### 絶対位置 \{#absolute\}

<ZoomImage id="flow-builder/position-absolute.webp" width="300px" float="right" alt="Absolute position controls" />

要素は通常のフローから切り離され、他のコンテンツに重なって表示されます。隣接する要素のレイアウトには影響しません。

**Absolute** を選択すると、追加のコントロールが表示されます。

* **オフセットフィールド**（T、L、R、B）：親コンテナの各辺から要素までの距離をピクセル単位で設定します
* **アンカーグリッド**：3×3のグリッド上の点をクリックして、要素が親のどのコーナー、辺、または中央に固定されるかを選択します
* **水平アンカー** <Inline id="horizontal-positioning.svg" alt="Horizontal positioning" />（Left / Center / Right）と **垂直アンカー** <Inline id="vertical-positioning.svg" alt="Vertical positioning" />（Top / Center / Bottom）：グリッドと同じアンカーポイントを操作するドロップダウン
* **Z-index**：他の配置済み要素の中でその要素の[重なり順](#stacking-order)を設定する数値フィールド

画像の上に配置する装飾的なオーバーレイ、バッジ、閉じるボタン、アイコンなどには絶対位置指定を使用してください。

:::tip
絶対配置要素を親要素の全幅に広げるには、水平アンカーを **Left** に設定し、**Right** オフセットを 0 にします。要素が両端に固定され、幅が [**Auto**](#sizing) に切り替わります。
:::

### 固定 \{#fixed\}

<ZoomImage id="flow-builder/position-fixed.webp" width="300px" float="right" alt="固定位置のコントロール" />

このエレメントは親コンテナを完全に無視し、画面上に固定されます。ユーザーがスクロールしても常に表示され続け、ページのコンテンツがその下で動きます。

固定位置指定は絶対位置指定と同じコントロール（オフセット、アンカーグリッド、Z-index）を使用します。すべてのオフセットは、親要素ではなく画面のセーフエリアを基準に計算されます。たとえば、下からのオフセットを0にすると、ホームインジケーターの上に要素が配置されます。物理的な画面端からオフセットを計算したい場合は、[セーフエリアを無視する](#ignore-safe-area)を有効にしてください。

スクロールコンテンツの上に浮かせたい要素（フロートする閉じるボタンや復元ボタン、常時表示されるトップバナー、トップへ戻るコントロール、ナビゲーションバーなど）には、固定配置を使用してください。専用のボトムアクションエリアには、代わりに [Footer](builder-containers#footer) を使用してください。ヒーロー画像の上にコンテンツを重ねるには、[Sliding sheet](builder-containers#sliding-sheet) を使用してください。

### Freeコンテナ内での位置指定 \{#position-in-a-free-container\}

Freeコンテナは子要素を順序付けしません。そのため、子要素の位置は手動で設定する必要があります。**Relative**（相対）位置はサポートされていません。子要素は以下のルールに従います：

- 子要素が**Free**コンテナの場合、[absolute（絶対）](#absolute)位置のみ設定できます。Adaptyは**Position**トグルを非表示にします。トグルを再表示するには、その子要素の[**Direction**](#direction)を**Vertical**または**Horizontal**に設定してください。
- その他の子要素はすべて、[absolute（絶対）](#absolute)または[fixed（固定）](#fixed)位置を設定できます。

### セーフエリアを無視する \{#ignore-safe-area\}

セーフエリアとは、ノッチ・ステータスバー・ホームインジケーターにかからないよう確保された画面領域のことです。デフォルトでは、配置された要素はこの領域内に収まるように制御されます。

位置タイプセレクターの下にある **Ignore safe area** チェックボックスをオンにすると、要素のオフセットが物理的な画面端から計測されるようになります。これにより、要素がノッチやホームインジケーターの裏側まで広がることができます。

<ZoomImage id="position-ignore-safe-area.webp" width="300px" alt="Fixedな要素が選択された状態のポジションパネルと「Ignore safe area」チェックボックス" />

フルブリードのメディアを表示するには、画像または動画のポジションを **Fixed** に設定し、四辺すべてのオフセットを 0 にして、**Ignore safe area** を選択します。これでメディアが画面全体をエッジからエッジまでカバーします。

このチェックボックスは、absolute および fixed ポジションのみで使用できます。relative 要素では無効化されており、要素を **Relative** に戻すとこの設定はクリアされます。

## サイズ設定 \{#sizing\}

<ZoomImage id="flow-builder/sizing.webp" width="300px" alt="Sizing controls" />

各要素には**Width**と**Height**のコントロールがあります。どちらかのドロップダウンをクリックして、サイズ設定モードを選択します。

| モード | 要素のサイズ | 使用可能な場所 |
| --- | --- | --- |
| **Fill** | 親の利用可能なスペースを埋めるように伸縮します。表示される値は自動計算されます | 相対要素のみ |
| **Hug** | コンテンツに合わせて縮小します。表示される値は自動計算されます | [フリーコンテナ内のフリー子要素](#position-in-a-free-container)を除くすべての場所 |
| **Fixed** | 親やコンテンツのサイズに関係なく、入力したピクセル値に合わせます | すべての場所 |
| **Auto** | 2つのオフセット間でコンテンツを伸縮します | [絶対配置または固定配置](#position)要素のみ。**Left** と **Right**、または **Top** と **Bottom** の両方が設定された場合に Adapty が自動的に適用します（手動では選択できません） |

要素の親に **Free** [方向](#direction) を適用すると、その要素の **Fill** サイズが **Fixed** に変わります。その要素自体も **Free** 方向を使用している場合は、**Hug** サイズも **Fixed** になります。

画像には独自の縦横比があるため、高さの設定によってクロップされるかどうかが決まります。詳しくは [画像のサイズ調整](custom-media#image-sizing) を参照してください。

<ZoomImage id="flow-builder/sizing-spacing-demo.webp" width="600px" alt="Fill、Hug、Fixedのサイズ指定モード" />

## スペーシング \{#spacing\}

<ZoomImage id="flow-builder/spacing.webp" width="300px" alt="Spacing box model" />

要素の各辺のスペーシング値を個別に設定します。

| コントロール | 機能 | 利用可能な要素 |
| --- | --- | --- |
| **Margin** | 要素と隣接要素の間にスペースを追加します。大きな値を設定しても、要素が親要素の外にはみ出すことはありません | 相対配置の要素すべて。スクリーン自体にはマージンはありません |
| **Padding** | 要素の境界線とコンテンツの間にスペースを追加します。**Hug** に設定された幅または高さは、パディングを含むように拡張されます | コンテナ、スクリーン、および子コンテンツを持つ要素。例外: **Free** コンテナの直接の子要素、および **Free** スクリーン自体 |

**Free** [方向](#direction)を選択すると、コンテナに設定されていたパディングがクリアされます。

## 重ね順 \{#stacking-order\}

<ZoomImage id="builder-z-index.webp" width="280px" float="right" alt="Position panel for an absolute element with the Z-index field set to 99" />

Relative要素は互いに重なりません。各コンテナは子要素を順番に配置します。**Absolute**または**Fixed**配置によって通常のフローから外れた場合にのみ、重なりが発生します。

**Absolute**または**Fixed**要素は、レイヤーの順序に関係なく、Relative兄弟要素の上に描画されます。Relative要素は互いに重ならないため、**Z-index**フィールドがありません。

**Absolute** または **Fixed** 要素が複数同じ空間を占める場合、その重なり順は次の2つの要素によって決まります（優先順位の高い順）：

- **Z-index**。デフォルト値：0。値が大きい要素が、レイヤーの順序に関係なく上に表示されます。
- **レイヤーの順序**。2つの要素が同じ z-index を持つ場合、レイヤーリストの下にある要素が上に表示されます。
