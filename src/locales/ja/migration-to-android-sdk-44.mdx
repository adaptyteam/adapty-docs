Adapty Android SDK 4.1、4.2、または 4.3 からバージョン 4.4 へアップデートするには、`adapty-bom` のバージョンを `4.4.0` に設定し、同じビルドでフォールバックファイルを差し替えてください。SDK バージョン 4.1〜4.3 は新しいファイルを拒否します。Java コードで `AdaptyFlowView.showFlow` を呼び出している場合は、各呼び出しに引数を追加してください。バージョン 4.0 のアプリは先に [v4.1 の変更](migration-to-android-sdk-41) を適用する必要があります。

:::warning
フォールバックファイルのフォーマットが 4.4 で変更されましたが、コンパイラは古いファイルを検出できません。[新しいフォールバックファイル](#replace-the-fallback-file) を用意しないと、すべてのプレースメントでフォールバックが機能しなくなります。
:::

## フォールバックファイルの差し替え \{#replace-the-fallback-file\}

[フォールバックファイル](fallback-flows)を再ダウンロードするには、**[Placements](https://app.adapty.io/placements)** で **Fallbacks** > **Download Android Fallback** をクリックします。**Adapty SDK v4.4.0 and higher** の行で **Download** をクリックし、ファイルをアプリにバンドルしてください。

ダウンロードされるファイル名は `android_4_4_0_fallback.json` です。アプリが読み込むファイルの名前に合わせてリネームするか、読み込み時の呼び出しでファイル名を更新してください。

- **`FileLocation.fromAsset`**: `android_fallback.json` のようなファイル名。
- **`FileLocation.fromResId`**: `R.raw.android_fallback` における `android_fallback` のようなリソース名。

古いファイルを使用した場合、`Adapty.setFallback` はコールバックに `AdaptyError` を渡し、メッセージは「The fallback file version is not correct. Download a new one from the Adapty Dashboard.」となります。新しいファイルを確認するには、アプリを実行し、このコールバックにエラーが返ってこないことを確認してください。コールバックは省略可能です。コールバックを使用しない場合は、[`Adapty.logLevel`](sdk-installation-android#logging) プロパティを `AdaptyLogLevel.ERROR` またはより詳細なレベルに設定し、Logcat にこのエラーが表示されないことを確認してください。

## JavaでshowFlow呼び出しに引数を追加する \{#add-an-argument-to-showflow-calls-in-java\}

4.4では、`AdaptyFlowView.showFlow`に新しい最後のパラメーター`customElementsResolver`が追加されました。JavaコードではすべてのパラメーターをShownFlow`showFlow`に渡す必要があるため、8つの引数の呼び出しはコンパイルエラーになります。最後の引数として`null`を渡してください：

```diff showLineNumbers
  flowView.showFlow(flowConfiguration, products, eventListener, insets,
-         customAssets, tagResolver, timerResolver, observerModeHandler);
+         customAssets, tagResolver, timerResolver, observerModeHandler, null);
```

Kotlin calls to `showFlow` and all calls to `AdaptyUI.getFlowView` compile without changes.
