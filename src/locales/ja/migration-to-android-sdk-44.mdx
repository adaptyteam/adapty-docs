Adapty Android SDK 4.1、4.2、または 4.3 からアプリを 4.4 に更新するには、`adapty-bom` のバージョンを `4.4.2` に設定し、同じビルドでフォールバックファイルを差し替えてください。SDK バージョン 4.1〜4.3 は新しいファイルを拒否します。4.0 のアプリには先に [v4.1 の変更](migration-to-android-sdk-41) が必要です。

:::warning
フォールバックファイルのフォーマットは4.4で変更されており、コンパイラは古いファイルを検出できません。[新しいフォールバックファイル](#replace-the-fallback-file)がないと、すべてのプレースメントでフォールバックが機能しなくなります。
:::

## フォールバックファイルの差し替え \{#replace-the-fallback-file\}

[フォールバックファイル](fallback-flows)を再ダウンロードするには、**[Placements](https://app.adapty.io/placements)** で **Fallbacks** > **Download Android Fallback** をクリックします。**Adapty SDK v4.4.0 and higher** の行で **Download** をクリックし、ファイルをアプリにバンドルしてください。

ダウンロードされるファイル名は `android_4_4_0_fallback.json` です。アプリが読み込むファイルの名前に合わせてリネームするか、読み込み時の呼び出しでファイル名を更新してください。

- **`FileLocation.fromAsset`**: `android_fallback.json` のようなファイル名。
- **`FileLocation.fromResId`**: `R.raw.android_fallback` における `android_fallback` のようなリソース名。

古いファイルを使用している場合、`Adapty.setFallback` はコールバックに `AdaptyError` を渡し、「The fallback file version is not correct. Download a new one from the Adapty Dashboard.」というメッセージが表示されます。新しいファイルを確認するには、アプリを実行して、このコールバックにエラーが返っていないことを確認してください。コールバックは省略可能です。コールバックを使用しない場合は、[ログレベル](sdk-installation-android#logging)を `AdaptyLogLevel.ERROR` またはより詳細なレベルに設定してください。その後、Logcat にこのエラーが表示されていないことを確認してください。
