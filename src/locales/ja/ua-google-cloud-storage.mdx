Adapty AttributionのGoogle Cloud Storageとの連携により、ユーザー獲得キャンペーンデータを一か所に安全に保存できます。Adapty Attributionは.csvファイルをGoogle Cloud Storageバケットに保存します。各行は1件のアプリインストールを表し、デバイス識別子やチャンネル・キャンペーンなどのアトリビューションデータが含まれます。ファイルには広告費、収益、購入データは含まれません。

この連携を設定するには、Google Cloud ConsoleとAdapty Attribution ダッシュボードでいくつかの手順を行う必要があります。

:::note
Adapty のアトリビューションエクスポートは、1 カレンダー日あたり 1 セットのファイルを Google Cloud Storage に出力します。エクスポートスケジューラーは 1 日 3 回（**02:00**、**04:00**、**06:00 UTC**）実行されます。各実行では、前日分のエクスポートジョブがまだ存在しない場合は新規作成し、以前の実行が失敗していた場合は再試行します。そのため、データは通常 02:00 の実行後に届き、それ以降の実行は追加データを投入するためではなく、失敗からの復旧を目的としています。

各エクスポートには、UTC の前日（1 暦日分）に Adapty アトリビューションが記録したインストールが含まれます。たとえば、3月8日のエクスポートには、3月7日の 00:00:00〜23:59:59 UTC に記録されたインストールが含まれます。

各ファイルには、エクスポート時点のアトリビューションが反映されます。インストールから最大 30 日間、Adapty アトリビューションはそのインストールを別のチャネルやキャンペーンに再帰属させる場合があります。古いファイルを最新のアトリビューションで更新するには、対象日付の[手動エクスポートを実行](#manual-data-export)してください。
:::

:::warning
スケジュールエクスポートは、有料プランまたはトライアル中のプランでのみ実行されます。いずれにも該当しない場合、スケジューラーはスキップされ、ダッシュボードでインテグレーションが有効になっていてもファイルは書き込まれません。バケットが空でかつ設定が正しく見える場合は、まずプランのステータスを確認してください。
:::

## Google Cloud Storage 連携の設定方法 \{#how-to-set-up-google-cloud-storage-integration\}

### ステップ 1. Google Cloud Storage の認証情報を作成する \{#step-1-create-google-cloud-storage-credentials\}

このガイドでは、Google Cloud Platform コンソールで必要な認証情報を作成する手順を説明します。

Adapty Attribution が指定したバケットにローデータレポートをアップロードするには、サービスアカウントのキーと、対応するバケットへの書き込みアクセス権が必要です。サービスアカウントのキーを提供し、バケットへの書き込みアクセスを許可することで、Adapty Attribution がプラットフォームからストレージ環境へローデータレポートを安全かつ効率的に転送できるようになります。

:::warning
サービスアカウントのHMACキー認証のみをサポートしています。Google Cloud Storageへの適切なアクセスを有効にするため、サービスアカウントのHMACキーに「Storage Object Viewer」、「Storage Legacy Bucket Writer」、「Storage Object Creator」のロールが追加されていることを確認してください。
:::

### ステップ 2. Adapty Attribution でインテグレーションを設定する \{#step-2-configure-integration-in-adapty-attribution\}

1. [**Integrations** -> **Google Cloud Storage**](https://app.adapty.io/ua/integrations/google-cloud-storage) に移動します
2. **Export install events to Google Cloud Storage** トグルをオンにします
3. Google Cloud Storage と Adapty Attribution 間の接続を構築するために、必要なフィールドを入力します:

| フィールド                                    | 説明                                                                                                                                                                                          |
|:------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Google Cloud service account key file** | ダウンロードしたプライベート [JSON キーファイル](ua-google-cloud-storage#step-1-create-google-cloud-storage-credentials)。                                                                    |
| **Google Cloud bucket name**              | データを保存する Google Cloud Storage 上のバケット名。Google Cloud Storage 環境内で一意である必要があり、スペースを含めることはできません。                                                   |
| **Folder inside the bucket**              | バケット内でデータを保存するフォルダ名。バケット内で一意である必要があり、データの整理に利用できます。このフィールドへの入力は任意です。                                                      |

## 手動データエクスポート \{#manual-data-export\}

以前の日付のデータをエクスポートするには、**Manual file export** セクションで日付範囲を選択し、**Export to Google Cloud Storage** をクリックします。指定した日付のファイルがすでにバケットに存在する場合、Adapty アトリビューションはそれらを上書きします。

## テーブル構造 \{#table-structure\}

各ファイルには、ある UTC 日にわたって Adapty Attribution が記録したインストール1件につき1行が含まれており、デバイスデータとアトリビューション情報が格納されています。ファイルには広告費、収益、購入データは含まれません。

:::warning
この構造は、当社または連携する第三者によって新しいデータが追加されることで、今後変更される場合があります。処理するコードが特定のフィールドに依存するようにし、構造全体に依存しないよう十分に注意してください。
:::

ファイルには以下の列が含まれます：

| カラム                   | 説明                                      |
|--------------------------|-------------------------------------------|
| `adapty_profile_id`      | Adapty プロファイルの一意識別子           |
| `install_id`             | インストールの一意識別子                  |
| `created_at`             | レコード作成タイムスタンプ（ISO 8601）    |
| `installed_at`           | アプリインストールタイムスタンプ（ISO 8601）|
| `store`                  | アプリストア（`ios`、`android`）          |
| `country`                | ユーザーの国コード（ISO 3166-1 alpha-2）  |
| `ip_address`             | クライアント IP アドレス                  |
| `idfa`                   | iOS 広告識別子（IDFA）                    |
| `idfv`                   | iOS ベンダー識別子（IDFV）                |
| `gaid`                   | Google 広告 ID（Android）                 |
| `android_id`             | Android デバイス ID                       |
| `app_set_id`             | Android App Set ID                        |
| `bundle_id`              | アプリバンドル識別子（例：`com.example.app`）|
| `device_brand`           | デバイスブランド（例：`Apple`、`Samsung`）|
| `device_model`           | デバイスモデル（例：`iPhone15,2`）        |
| `os_version`             | OS のメジャーバージョン                   |
| `app_version`            | Adapty SDK が報告するアプリバージョン     |
| `sdk_version`            | Adapty SDK バージョン                     |
| `channel`                | アトリビューションチャネル                |
| `campaign_id`            | キャンペーン識別子                        |
| `campaign_name`          | キャンペーン名                            |
| `adset_id`               | 広告セット識別子                          |
| `adset_name`             | 広告セット名                              |
| `ad_id`                  | 広告識別子                                |
| `ad_name`                | 広告名                                    |
| `keyword_id`             | キーワード識別子                          |
| `keyword_name`           | キーワード名                              |
| `asa_org_id`             | Apple Search Ads 組織 ID                  |
| `asa_keyword_match_type` | ASA キーワードマッチタイプ（`Exact`、`Broad`）|
| `asa_attribution`        | ASA アトリビューションデータ（JSON 文字列）|
| `asa_conversion_type`    | ASA コンバージョンタイプ                  |
| `asa_country_or_region`  | ASA の国または地域                        |
| `asa_creative_set_name`  | ASA クリエイティブセット名                |
| `fbclid`                 | Facebook クリック ID                      |
| `ttclid`                 | TikTok クリック ID                        |
| `utm_source`             | UTM source パラメータ                     |
| `utm_medium`             | UTM medium パラメータ                     |
| `utm_campaign`           | UTM campaign パラメータ                   |
| `utm_term`               | UTM term パラメータ                       |
| `utm_content`            | UTM content パラメータ                    |
| `click_time`             | アトリビューションされたクリックのタイムスタンプ（Unix 秒）。インストールにクリックがアトリビューションされていない場合は空。 |
| `asa_click_time`         | インストール前の Apple Search Ads タップのタイムスタンプ（Unix 秒、分単位に丸め）。Apple Search Ads がインストールのタップを報告しない場合は空。`click_time` と異なり、Adapty Attribution が別チャネルにインストールをアトリビュートした場合でも値が入ります。 |
