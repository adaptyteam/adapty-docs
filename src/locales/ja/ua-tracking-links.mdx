:::important
トラッキングリンクは、Adapty がアプリのインストールをアトリビューションするのに役立ちます。広告がウェブファネルにユーザーを誘導する場合は、代わりに [Adapty のパラメータでその URL にタグを付けてください](ua-tag-ad-urls)。
:::

広告のリンク先は通常、App StoreまたはGoogle Playのページです。そのページはストアが管理しているため、Adaptyにクリックを報告することができません。

代わりに、トラッキングリンクをリンク先として使用してください。Adaptyはキャンペーン、広告セット、広告の情報を取得してからユーザーをストアにリダイレクトし、そのクリックをSDKが報告するインストールと照合します。[Adapty アトリビューション アナリティクス](ua-analytics)では、どの広告が収益を生み出しているかを確認できます。

Adapty は [Meta Ads](ua-facebook#step-2-add-campaigns) および [TikTok for Business](ua-tiktok#step-2-add-campaigns) キャンペーン用のリンクを自動生成します。その他の広告ネットワークについては、ダッシュボードの **Custom** インテグレーションを使って[カスタムトラッキングリンクを作成](#custom-tracking-links)してください。

## トラッキングリンクの種類 \{#tracking-link-types\}

Adapty では、2 種類のトラッキングリンクを生成できます。

- **プラットフォーム別リンク** — ストアごとに個別のリンクです。キャンペーンに合わせたカスタムストアリスティングにユーザーを誘導できます。
- **One Link** — 両方のストア向けの単一リンクで、クリック時にユーザーのプラットフォームに合わせて振り分けられます。

1 つのトラッキングリンクページに、設定したすべてのストアのリンクが含まれるため、ストアごとに別途設定する必要はありません。柔軟性を高めたい場合は、プラットフォーム別リンクをおすすめします。

## カスタムトラッキングリンク \{#custom-tracking-links\}

:::note
Apple Search Ads にはトラッキングリンクは不要です。Adapty は Apple Search Ads のアトリビューションをリンクなしで受け取ります。キャンペーンの管理は [Adapty Ads Manager](adapty-ads-manager) で行います。
:::

カスタムトラッキングリンクを作成するには：

1. Adapty Attribution ダッシュボードで、**Integrations** を開き、**Network** グループの **Custom** カードを選択します。

<ZoomImage id="custom-tracking-link.webp" width="700px" alt="Integrations page in Adapty Attribution with the Custom card highlighted in the Network group" />

2. **Create link** をクリックします。

<ZoomImage id="new-tracking-link.webp" width="700px" />

3. リストからアプリを選択し、**Next** をクリックします。

<ZoomImage id="ua-choose-app.webp" width="700px" />

4. リンクのパラメータを入力して、特定のキャンペーンや広告にリンクを紐付けます。

| パラメーター       | 説明                                                                                   |
|-------------------|-----------------------------------------------------------------------------------------------|
| **Name**          | トラッキングリンクの内部名称。                                                              |
| **Channel**       | Meta、Reddit、TikTok などのトラフィックソース。アナリティクスでキャンペーンをグループ化するために使用されます。 |
| **Campaign ID**   | 広告プラットフォームにおけるキャンペーンの一意識別子。                                    |
| **Campaign name** | キャンペーンの表示名。                                                                    |
| **Ad set ID**     | 広告プラットフォームにおける広告セット（広告グループ）の一意識別子。                           |
| **Ad set name**   | 広告セットの名前。                                                                       |
| **Ad ID**         | 個々の広告クリエイティブの一意識別子。                                                          |
| **Ad name**       | 広告クリエイティブまたはバリエーションの名前。                                                     |

5. デフォルトでは、One Link が作成されます。代わりに[プラットフォーム別リンク](#tracking-link-types)を追加するには、**One Link** チェックボックスをオフにします。

<ZoomImage id="one-link.webp" width="700px" />

6. **Create** をクリックします。
7. トラッキングリンクのページを開きます。[リンクタイプ](#tracking-link-types)のセクションで、**Click link** の値をコピーします。

:::tip
[遅延データを扱う](ua-deferred-data)ために、追加のリンクパラメーターを設定することもできます。たとえば、ディファードディープリンクを実装できます。
:::

<ZoomImage id="click-link.webp" width="700px" />

8. 広告プラットフォームにアクセスし、そのリンクを広告のリンク先URLとして使用します。
