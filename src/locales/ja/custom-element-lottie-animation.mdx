このレシピに従って、ユーザーの進捗をLottieアニメーションとして表示しましょう。たとえば、デイリーストリークを示すリングが徐々に塗りつぶされるような表現が可能です。アプリは[カスタム要素](flow-custom-elements)内でネイティブのLottieビューとしてアニメーションをレンダリングします。

:::tip
このレシピは iOS アプリのみを対象としています。他のフレームワークで構築されたアプリでは、カスタム要素の[フォールバックコンテンツ](flow-custom-elements#set-fallback-content)のみが表示されます。Android およびクロスプラットフォームフレームワークのサポートは近日公開予定です。
:::

## 始める前に \{#before-you-start\}

- Adapty iOS SDK 4.4 以降にアップデートしてください。それより前のバージョンでは、すべてのカスタム要素に[フォールバックコンテンツ](flow-custom-elements#set-fallback-content)が表示されます。
- アプリにフローを[取得](get-pb-paywalls)して[表示](ios-present-paywalls)するための設定を行ってください。
- Swift Package Manager を使用して、`https://github.com/airbnb/lottie-spm.git` から Lottie をアプリに追加してください。
- Lottie アニメーションを `.json` 形式で用意するか、サンプルの [`streak_ring.json`](https://raw.githubusercontent.com/adaptyteam/adapty-docs/refs/heads/main/Downloads/streak_ring.json) をダウンロードしてください。アプリはアニメーションを最初から再生し、進捗に応じた位置で停止します（50% であれば中間で停止）。進捗を正確に表示するには、アニメーションに以下の条件が必要です：
  - 最初のフレームでは進捗がゼロで、最後のフレームで進捗が 100% になること。
  - イージングなしの一定速度であること。アニメーションがゆっくり始まって加速する場合、50% の時点で実際よりも少ない進捗しか表示されません。

## 1. カスタム要素をスクリーンに追加する \{#1-add-the-custom-element-to-the-screen\}

Flow & Paywall Builder で、フロースクリーンに[カスタム要素を追加](flow-custom-elements#add-and-configure)し、アニメーション用に設定します：

- **Type**: `lottie_animation`。
- **ID**: `streak_ring`。このレシピでは、ID はアニメーションファイル名にもなります。
- **Height**: デフォルトの **Fixed** の高さを維持します。アニメーションはカスタム要素に合わせてスケーリングされます。

カスタム要素内に、リングの静止画像として [**Image**](custom-media#image) を追加します。アニメーションを再生できないバージョンのアプリを使用しているユーザーは、この画像を[フォールバック](flow-custom-elements#set-fallback-content)として表示します。

## 2. アニメーションファイルをアプリに追加する \{#2-add-the-animation-file-to-your-app\}

Xcode で、アニメーションファイルをアプリのターゲットに追加します。`.json` を除いたファイル名は、カスタム要素の ID と一致している必要があります。例えば `streak_ring` に対しては `streak_ring.json` のようにします。

## 3. アニメーションビューを作成する \{#create-the-animation-view\}

ストリークのモデルと、アニメーションを再生する SwiftUI ビューを作成します。アプリはストリークが変化したときにモデルを更新します。ビューはモデルを読み取るため、画面を開いたときにリングが現在のストリークを表示します：

<Tabs groupId="current-os" queryString>
<TabItem value="ios" label="iOS" default>

```swift showLineNumbers title="Swift"

// The streak that your app keeps up to date
@MainActor
final class StreakStore: ObservableObject {
    @Published var currentStreak = 0 // days in a row
}

struct StreakRingView: View {
    let animation: LottieAnimation
    @ObservedObject var streakStore: StreakStore

    // 7 days fill the ring: from 0 for an empty ring to 1 for a full one
    private var progress: AnimationProgressTime {
        min(AnimationProgressTime(streakStore.currentStreak) / 7, 1)
    }

    var body: some View {
        LottieView(animation: animation)
            .resizable()
            .playing(.fromProgress(0, toProgress: progress, loopMode: .playOnce))
    }
}
```

</TabItem>
</Tabs>

`.playing(.fromProgress(0, toProgress: progress, loopMode: .playOnce))` はリングを空の状態から `progress` まで一度だけ塗りつぶします。アプリがすでに `ObservableObject` でストリークを管理している場合は、`StreakStore` の代わりにそのオブジェクトを使用してください。

## 4. アニメーションをカスタム要素に紐付ける \{#match-the-animation-to-the-custom-element\}

[アプリ全体のリゾルバー](ios-flow-custom-elements#set-an-app-wide-resolver)に、ストリークモデル用のプロパティを追加します。次に、`lottie_animation` タイプと `streak_ring` ID に対して `StreakRingView` を返すケースを追加します。ハイライトされている行が追加箇所です。アプリにまだアプリ全体の[リゾルバー](ios-flow-custom-elements#write-a-resolver-to-match-custom-elements-and-views)がない場合は、コード全体をコピーしてください。

<Tabs groupId="current-os" queryString>
<TabItem value="ios" label="iOS" default>

```swift showLineNumbers title="Swift" {2,6,14-18}

struct CustomElementsResolver: AdaptyUICustomElementsResolver {
    let streakStore: StreakStore

    func view(
        forType type: String,
        id: String,
        context: AdaptyUICustomElementContext
    ) -> AnyView? {
        switch type {
        case "lottie_animation" where id == "streak_ring":
            guard let animation = LottieAnimation.named(id) else {
                return nil // no animation file: show the fallback
            }
            return AnyView(StreakRingView(animation: animation, streakStore: streakStore))
        // the other cases of your resolver
        default:
            return nil
        }
    }
}
```

</TabItem>
</Tabs>

`streak_ring` のケースを他の `lottie_animation` ケースよりも前に置いてください。Swift は最初にマッチしたケースしか実行しないためです。アプリバンドルにそのIDのファイルが存在しない場合、リゾルバーは `nil` を返し、ユーザーにはフォールバックが表示されます。

ストリークモデルでリゾルバーを作成し、アプリ全体のリゾルバーとして設定します。`AdaptyUI.setCustomElementsResolver(_:)` はアプリ起動時など、一度だけ呼び出してください：

<Tabs groupId="current-os" queryString>
<TabItem value="ios" label="iOS" default>

```swift showLineNumbers title="Swift"

// the streak model that your app updates
@MainActor let streakStore = StreakStore()

// keep this instance: a resolver for one flow can reuse it
@MainActor let customElementsResolver = CustomElementsResolver(streakStore: streakStore)

AdaptyUI.setCustomElementsResolver(customElementsResolver)
```

</TabItem>
</Tabs>

## 5. デバイスでテストする \{#test-on-a-device\}

フロー & ペイウォールビルダーはアプリのコードを実行できないため、キャンバスにはフォールバックのみが表示されます。アニメーションをプレビューするには、次の手順を実行します。

1. [フローを公開する](builder-save-publish)。キャッシュ済みのバージョンではなく最新の公開バージョンを確認するには、デバイスを[テストデバイス](test-devices)として登録してください。
2. リゾルバーを含むアプリのビルドを実行します。ストリークを 0 日、4 日、7 日など、いくつかの値に設定します。各値でスクリーンを開き、リングがその値まで埋まることを確認してください。

フォールバックをテストするには、アニメーションファイルをビルドから削除し、再度スクリーンを開いてください。

デバイスでのテスト方法については、iOSガイドの[デバイスでテストする](ios-flow-custom-elements#test-on-a-device)セクションをご覧ください。
