Adapty はプロダクトデータを App Store および Google Play と交換しますが、この交換は常時行われるわけでも、完全なものでもありません。ほとんどの値は、ストアにプロダクトを送信したり、新しい価格をアップロードしたりするなど、何らかのアクションを実行したときにのみ更新されます。まったく更新されない値も存在するため、[同じプロダクトに対して Adapty とストアで異なる価格が表示される場合があります](#product-and-price-discrepancies)。

## Adapty がストアから読み取る情報 \{#what-adapty-reads-from-the-stores\}

Adapty はプロダクトリスト、ベースプラン、価格、トランザクションをストアから読み取ります。プロダクトや価格を変更する場合は、ストアのコンソールで行ってください。国別の価格を確認するには、[プロダクトを編集](edit-product#set-country-specific-prices)から価格CSVをダウンロードしてください。

| Adaptyが読み取る情報 | 受信方法（App Store） | 受信方法（Google Play） |
|---|---|---|
| プロダクトリストとレビューステータス | [App Store Connect APIキー](app-store-connect-api-key)を通じて | [サービスアカウント](google-play-store-connection-configuration)を通じて |
| ベースプラン | 該当なし | サブスクリプションプロダクトの一部 |
| 国別価格 | 1日1回、およびストアプロダクトをリンクまたは編集してから約5分後に、[App Store Connect APIキー](app-store-connect-api-key)を通じて | ストアプロダクトをリンクまたは編集したとき |
| トランザクション、更新、払い戻し | Adapty SDKから、および[App Storeサーバー通知](enable-app-store-server-notifications)を通じて | [リアルタイムデベロッパー通知](enable-real-time-developer-notifications-rtdn)を通じて |
| 顧客が支払った金額 | 各トランザクションと共に | 各トランザクションと共に |

## Adaptyがストアに書き込む内容 \{#what-adapty-writes-to-the-stores\}

プロダクト、価格、初回トライアルはAdaptyで設定してから、スケジュールではなくアクションをとったタイミングでストアに反映されます。

| Adaptyが書き込む内容 | App Storeへの反映タイミング | Google Playへの反映タイミング |
|---|---|---|
| 新規プロダクト | [プロダクトをストアにプッシュ](create-product#create-product-and-push-to-store)したとき | プロダクトをストアにプッシュしたとき |
| 国別価格 | [価格CSVをアップロード](edit-product#set-country-specific-prices)したとき | 価格CSVをアップロードしたとき |
| 初回オファー（無料トライアル） | 新規プロダクトをプッシュしたとき | 反映されません — 代わりに[Google Play Console](google-play-offers)で作成してください |

Adapty はアップロードされた CSV とストアの現在の価格を比較し、差異のある価格のみを更新するため、ファイル全体を安全にアップロードできます。既存のサブスクライバーは、**Apply to existing subscribers** を選択しない限り、加入時の価格が維持されます。

## Adaptyのみで設定する内容 \{#what-you-set-in-adapty-only\}

ストアはこれらの設定を変更しません。

| 項目 | Adaptyに留まる理由 |
|---|---|
| 接続したストアプロダクトの価格 | 作成時に固定されるプレースホルダーです。プロダクトを区別するために役立ちますが、ストアには反映されません。アナリティクス、インテグレーション、SDKはすべてストアの実際の価格を使用します。 |
| [アクセスレベル](access-level) | Adaptyが有料コンテンツへのアクセスを付与します。ストアには同等の機能がありません。 |
| プロモーションオファーおよびウィンバックオファーのID | Adaptyは購入に署名するためにIDが必要です。オファー自体はストアのコンソールで作成します。 |

## デバイス上での動作 \{#what-happens-on-the-device\}

ペイウォールを開いたときに表示される価格は、Adapty ではなく StoreKit または Google Play Billing から取得されます。ストアのコンソールで価格を変更すると、ストアが公開した時点でユーザーに反映されます。アプリをリリースし直す必要はなく、Adapty 側での変更も不要です。

逆方向では、Adapty SDK が各購入を価格・通貨・国情報とともに Adapty に送信します。Adapty はこれらの値を使用して、ユーザー自身の通貨で収益を記録します。

## Stripe、Paddle、カスタムストア \{#stripe-paddle-and-custom-stores\}

StripeとPaddleの連携はトランザクションを処理するものであり、プロダクトカタログを同期するものではありません。購入はプロバイダーのWebhook経由でAdaptyに届きます。[カスタムストア](custom-store)の場合は、独自のバックエンドから送信します。プロダクトとPrice IDはすべて手動で追加する必要があります。AdaptyにないIDは何にも紐付かないため、そのトランザクションと収益はいっさい表示されません。StripeとPaddleでは、プロダクトが存在していても**Subscription duration**が設定されていない場合も同様です。どちらのケースも警告は表示されないため、販売するすべてのプロダクトにIDとdurationを必ず設定してください。

## プロダクトと価格の不一致 \{#product-and-price-discrepancies\}

Adapty とストアコンソールの間にある差異の中には、仕様どおりのもので顧客の支払い金額に影響しないものもあります。一方で、収益が記録されない原因となるものもあります。

| 表示内容 | 考えられる原因 | 対処方法 |
|---|---|---|
| Adapty の価格がストアと異なる | **Products** 画面には、プロダクト作成時に入力した価格が表示されます。プロダクトをストアにプッシュした場合、Adapty はその価格を初期価格として使用します。その後は変更できないため、ストアが価格を管理するようになると、両者の価格はずれていきます。現在お客様が支払う価格は[国別価格](edit-product#set-country-specific-prices)です。 | 対応不要です。お客様にはストアの価格が請求され、売上レポートには実際の支払額が使用されます。支払額を変更するには、各ストアのコンソールで価格を編集するか、[価格CSVをアップロード](edit-product#set-country-specific-prices)して両方のストアを一度に変更してください。 |
| プロダクトがドロップダウンに表示されない | 考えられる原因は3つあります。ストアの認証情報が機能しなくなり、空のリストが返される。作成から10分以内のプロダクトが、App Store リストの Adapty キャッシュにまだ反映されていない。選択した **Subscription duration** によってリストが絞り込まれる：**Lifetime**、**Non-Subscriptions**、**Consumables** は買い切り型プロダクトを表示し、それ以外の値はサブスクリプションを表示します。 | ストアでのプロダクトの種類に合わせて **Subscription duration** を設定してください。作成したばかりの場合は、少し待ってから再試行してください。それでも解決しない場合は、[ストアの認証情報](#if-updates-stop-arriving)を確認してください。 |
| 初回オファーが Adapty に表示されない | Adapty は、新しいプロダクトをストアにプッシュするときにのみ初回オファーを作成し、自分が作成したオファーのみを一覧表示します。ストアコンソールで直接設定したオファーは **Edit product** ウィンドウに表示されません。 | 対応不要です。初回オファーは、お客様が対象条件を満たした場合に自動的に適用されるため、Adapty に追加する必要はありません。 |
| 購入時に割引が適用されなかった | お客様が条件を満たしていない可能性があります。判断はストアが行うもので、Adapty ではありません。または、App Store のプロモーションオファーが、Adapty が[アプリ内購入キー](generate-in-app-purchase-key#add-the-key-to-adapty)で署名できなかったために適用されなかった可能性があります。 | キーがアップロードされており有効であることを確認し、ストアでオファーの条件を確認してください。 |
| 価格変更後に Stripe のトランザクションが表示されなくなった | Stripe で価格を変更すると新しい `price_id` が作成されますが、Adapty は `product_id` と `price_id` の完全一致でイベントを照合します。新しい価格のイベントは何にも一致しませんが、Stripe 側ではウェブフックが配信済みとして報告されます。 | 新しい `price_id` を Adapty のプロダクトに追加してください。追加するまで、売上が記録されません。詳しくは [Stripe](stripe) を参照してください。 |
| お客様が購入したのにアクセスレベルが付与されない | 購入したストアのプロダクト ID が Adapty のプロダクトに紐付けられていません。Adapty は自動的に作成したプロダクト行に対して購入を記録しますが、その行にはアクセスレベルが設定されていません。 | Adapty に正確なストアのプロダクト ID でプロダクトを作成し、[アクセスレベル](access-level)を割り当ててください。 |
| 更新が届かなくなった | ストアの認証情報のいずれかが機能しなくなっています。それぞれが連携の異なる部分を担っています。 | 停止している部分を特定し、その認証情報だけを更新してください。詳しくは[更新が届かなくなった場合](#if-updates-stop-arriving)を参照してください。 |

## アップデートが届かなくなった場合 \{#if-updates-stop-arriving\}

Adapty は機能しなくなったクレデンシャルにフラグを立てません。各クレデンシャルはやり取りの一部を担うため、症状を見ればどれを更新すべきかがわかります。

| 停止した内容 | 置き換えるクレデンシャル |
|---|---|
| プロダクト一覧、レビューステータス、またはストアへのプロダクトと価格のプッシュ | App Store: [App Store Connect API キー](app-store-connect-api-key#replace-the-key) または [Apple App ID](app-store-connection-configuration#enter-the-bundle-id-and-apple-app-id)。Google Play: [サービスアカウントキーファイル](create-service-account-key-file)。 |
| 更新と返金 | App Store: [サーバー通知](enable-app-store-server-notifications#check-that-notifications-reach-adapty)。Google Play: [リアルタイムデベロッパー通知](enable-real-time-developer-notifications-rtdn)。 |
| 購入時のプロモーションオファー | App Store: [アプリ内購入キー](generate-in-app-purchase-key#replace-the-key)。 |
| すべてのユーザーの購入検証 | App Store: [アプリ内購入キー](generate-in-app-purchase-key#replace-the-key) と [アプリ固有の共有シークレット](app-store-connection-configuration#enter-the-app-specific-shared-secret)。Google Play: [サービスアカウントキーファイル](google-play-store-connection-configuration)。 |

ストアコンソールで認証情報を置き換えても、Adaptyには反映されません。**App settings**で新しい認証情報をアップロードしてください。
