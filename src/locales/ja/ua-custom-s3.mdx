Adapty AttributionとカスタムのカスタムのカスタムのカスタムのカスタムのカスタムS3互換ストレージとの連携により、ユーザー獲得キャンペーンのデータを独自のS3互換ストレージソリューションに安全に保存できます。Adapty Attributionは、カスタムS3バケットに.csvファイルを保存します。各行は1件のアプリインストールを表し、デバイス識別子やチャネル・キャンペーンなどのアトリビューションデータが含まれます。ファイルには広告費、収益、購入データは含まれません。
この連携を設定するには、S3互換ストレージのコンソールとAdapty Attributionダッシュボードでいくつかの簡単な手順を行う必要があります。

:::note
Adapty アトリビューションのエクスポートは、カレンダーの1日につき1セットのファイルを出力します。エクスポートスケジューラーは1日3回（**02:00**、**04:00**、**06:00 UTC**）実行されます。各実行では、前日のエクスポートジョブがまだ存在しない場合はそれを作成し、以前の実行が失敗していた場合は再試行します。そのため、データは通常 02:00 の実行後に届き、それ以降の実行は追加データのためではなく、失敗時のリカバリーとして機能します。

各エクスポートには、UTC の前日（1 暦日分）に Adapty アトリビューションが記録したインストールが含まれます。たとえば、3 月 8 日のエクスポートには、3 月 7 日の 00:00:00〜23:59:59 UTC に記録されたインストールが含まれます。

各ファイルには、エクスポート時点のアトリビューションが反映されます。インストールから最大 30 日間は、Adapty アトリビューションが別のチャネルやキャンペーンにインストールを再帰属させる場合があります。過去のファイルを最新のアトリビューションに更新するには、対象日付の[手動エクスポートを実行](#manual-data-export)してください。
:::

:::warning
スケジュールエクスポートは、有料プランまたはトライアル中のアカウントのみ実行されます。いずれにも該当しない場合、スケジューラーはエクスポートをスキップしてファイルを書き込みません。ダッシュボードでインテグレーションが有効になっていても同様です。バケットが空でかつ設定が正しい場合は、まずプランの状態をご確認ください。
:::

## Custom S3 インテグレーションのセットアップ \{#set-up-custom-s3-integration\}

データの受信を開始するには、Adapty Attribution でインテグレーションを設定します。

1. [**Integrations** -> **Custom S3**](https://app.adapty.io/ua/integrations/custom-s3) に移動します。
2. **Export install events to custom S3** トグルをオンにします。
3. 必須フィールドに入力して、カスタム S3 ストレージと Adapty Attribution プロファイルの接続を構築します。

| フィールド | 説明 |
|:----------------------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Access Key ID** | S3互換ストレージサービスへのアクセスを認証するための一意の識別子です。ストレージプロバイダーのコンソールで確認できます。 |
| **Secret Access Key** | Access Key IDと組み合わせて、S3互換ストレージサービスへのアクセスを認証するための秘密鍵です。ストレージプロバイダーのコンソールで確認できます。 |
| **S3 Bucket Name** | ストレージ環境内の特定のS3バケットを識別するグローバルに一意の名前です。S3バケットはシンプルなストレージサービスで、ファイルや画像などのデータオブジェクトをクラウドに保存・取得できます。 |
| **Region**（任意） | Management ConsoleでRegionを確認してください。 |
| **Folder Inside the Bucket**（任意） | 選択したS3バケット内に作成するフォルダの名前です。S3ではオブジェクトキーのプレフィックスを使用してフォルダを疑似的に表現しており、これが実質的なフォルダ名となります。 |
| **Custom Endpoint URL** | S3互換ストレージサービスのエンドポイントURLです。ストレージプロバイダー（MinIO、DigitalOcean Spaces、Wasabiなど）から提供されます。 |

:::note
S3バケット名フィールドでは、`adapty-ua-events/com.sample-app` のようにネストされたディレクトリも指定できます。
:::

## 手動データエクスポート \{#manual-data-export\}

以前の日付のデータをエクスポートするには、**Manual file export** セクションで日付範囲を選択し、**Export to S3** をクリックします。指定した日付のファイルがすでにバケットに存在する場合、Adapty アトリビューションはそれらを上書きします。

## テーブル構造 \{#table-structure\}

各ファイルには、ある UTC の1日間に Adapty Attribution が記録したインストールごとに1行のデータが含まれており、デバイスデータとアトリビューション情報が格納されています。ファイルには広告費用、収益、購入データは含まれません。

:::warning
この構造は、私たちまたは連携している第三者によって新しいデータが追加されるなど、今後変更される可能性があります。処理するコードが特定のフィールドに依存するよう実装し、構造全体に依存しないようにしてください。
:::

ファイルには以下の列が含まれています：

| カラム                   | 説明                                       |
|--------------------------|-------------------------------------------|
| `adapty_profile_id`      | Adapty プロファイルの一意な識別子           |
| `install_id`             | インストールの一意な識別子                  |
| `created_at`             | レコード作成のタイムスタンプ（ISO 8601）    |
| `installed_at`           | アプリインストールのタイムスタンプ（ISO 8601）|
| `store`                  | アプリストア（`ios`、`android`）            |
| `country`                | ユーザーの国コード（ISO 3166-1 alpha-2）    |
| `ip_address`             | クライアントの IP アドレス                  |
| `idfa`                   | iOS の広告識別子（IDFA）                    |
| `idfv`                   | iOS のベンダー識別子（IDFV）                |
| `gaid`                   | Google 広告 ID（Android）                  |
| `android_id`             | Android デバイス ID                        |
| `app_set_id`             | Android App Set ID                        |
| `bundle_id`              | アプリのバンドル識別子（例：`com.example.app`）|
| `device_brand`           | デバイスブランド（例：`Apple`、`Samsung`）  |
| `device_model`           | デバイスモデル（例：`iPhone15,2`）          |
| `os_version`             | OS のメジャーバージョン                     |
| `app_version`            | Adapty SDK が報告するアプリバージョン        |
| `sdk_version`            | Adapty SDK のバージョン                     |
| `channel`                | アトリビューションチャネル                   |
| `campaign_id`            | キャンペーンの識別子                        |
| `campaign_name`          | キャンペーン名                              |
| `adset_id`               | 広告セットの識別子                          |
| `adset_name`             | 広告セット名                               |
| `ad_id`                  | 広告の識別子                               |
| `ad_name`                | 広告名                                    |
| `keyword_id`             | キーワードの識別子                          |
| `keyword_name`           | キーワード名                               |
| `asa_org_id`             | Apple Search Ads の組織 ID                 |
| `asa_keyword_match_type` | ASA キーワードマッチタイプ（`Exact`、`Broad`）|
| `asa_attribution`        | ASA アトリビューションデータ（JSON 文字列）  |
| `asa_conversion_type`    | ASA コンバージョンタイプ                    |
| `asa_country_or_region`  | ASA の国または地域                          |
| `asa_creative_set_name`  | ASA クリエイティブセット名                  |
| `fbclid`                 | Facebook クリック ID                       |
| `ttclid`                 | TikTok クリック ID                         |
| `utm_source`             | UTM source パラメータ                      |
| `utm_medium`             | UTM medium パラメータ                      |
| `utm_campaign`           | UTM campaign パラメータ                    |
| `utm_term`               | UTM term パラメータ                        |
| `utm_content`            | UTM content パラメータ                     |
| `click_time`             | アトリビューションされたクリックのタイムスタンプ（Unix 秒）。インストールにクリックがアトリビューションされていない場合は空。 |
| `asa_click_time`         | インストール前の Apple Search Ads タップのタイムスタンプ（Unix 秒、分単位に丸められる）。Apple Search Ads がインストールに対するタップを報告しない場合は空。`click_time` とは異なり、Adapty アトリビューションが別チャネルにインストールをアトリビューションした場合でも値が入ることがある。 |
