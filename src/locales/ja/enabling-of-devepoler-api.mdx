アプリが Play Store で公開されている場合、Adapty との連携に Developer API の有効化は欠かせません。この手順により、アプリとプラットフォーム間のシームレスな通信が確保され、自動化されたプロセスとリアルタイムのデータ分析でサブスクリプションモデルを最適化できます。以下の API を有効にしてください。

- [Google Play Android Developer API](https://console.cloud.google.com/apis/library/androidpublisher.googleapis.com)
- [Google Play Developer Reporting API](https://console.cloud.google.com/apis/library/playdeveloperreporting.googleapis.com)
- [Cloud Pub/Sub API](https://console.cloud.google.com/marketplace/product/google/pubsub.googleapis.com)

アプリがPlay Storeで配信されていない場合、この手順はスキップできます。Play Storeで販売する場合は、今すぐ設定しなくても構いませんが、Adaptyの基本機能に欠かせない設定です。オンボーディング完了後は、**App settings** セクションでアプリストアの設定を行えます。

Google Cloud ConsoleでDeveloper APIを有効にする手順は次のとおりです。

1. [Google Cloud Console](https://console.cloud.google.com/) を開きます。

2. Google Cloud ウィンドウの左上隅で、使用するプロジェクトを選択するか、新しいプロジェクトを作成します。サービスアカウントキーファイルを Adapty にアップロードするまで、同じ Google Cloud プロジェクトを使用し続けてください。

[**APIs & Services**](https://console.cloud.google.com/apis/dashboard) ページ（Google Cloud Console）で再確認できます。ページを下にスクロールし、ページ下部の表に3つのAPIがすべて含まれていることを確認してください：

- Google Play Android Developer API
- Google Play Developer Reporting API
- Cloud Pub/Sub API
