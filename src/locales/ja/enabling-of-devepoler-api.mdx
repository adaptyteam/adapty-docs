Adaptyは以下のGoogle APIを通じて、プロダクトの読み取り、購入の検証、サブスクリプションイベントの受信を行います：

- Google Play Android Developer API
- Google Play Developer Reporting API
- Cloud Pub/Sub API

## 始める前に \{#before-you-start\}

以下の手順を完了するには、[Google Play連携に必要なアクセス権限とGoogle Cloudプロジェクト](initial-android#before-you-start)が必要です。これらが揃っていないと、次の手順を進められません。

## APIを有効にする \{#enable-the-apis\}

1. [Google Cloud Console](https://console.cloud.google.com/)を開きます。

2. 連携に使用するプロジェクトを選択します。

3. [**Google Play Android Developer API**](https://console.cloud.google.com/apis/library/androidpublisher.googleapis.com)のページを開きます。

4. **Enable**をクリックし、ステータスが**Enabled**になるまで待ちます。ボタンに**Manage**と表示されている場合、APIはすでに有効になっているため、操作は不要です。

   <ZoomImage id="gp-api-library-enable.webp" width="700px" alt="An API page in the Google Cloud API library, with the Enable button" />

5. [**Google Play Developer Reporting API**](https://console.cloud.google.com/apis/library/playdeveloperreporting.googleapis.com) ページを開きます。

6. **Enable** をクリックし、ステータスが **Enabled** と表示されるまで待ちます。

7. [**Cloud Pub/Sub API**](https://console.cloud.google.com/apis/library/pubsub.googleapis.com) ページを開きます。

8. **Enable** をクリックし、ステータスが **Enabled** と表示されるまで待ちます。

確認するには、Google Cloud Console の [**APIs & Services**](https://console.cloud.google.com/apis/dashboard) ページを開いてください。下部のテーブルにはプロジェクトで有効になっているすべての API が一覧表示されており、以下の3つがすべて表示されているはずです。

- Google Play Android Developer API
- Google Play Developer Reporting API
- Cloud Pub/Sub API

<ZoomImage id="gp-apis-enabled-list.webp" width="700px" alt="必要な3つの API がすべて表示された、有効な API とサービスの一覧テーブル" />
