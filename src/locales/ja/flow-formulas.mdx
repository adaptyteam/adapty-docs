数式とは、計算された値（数値または日付）を持つ[カスタム変数](onboarding-variables#custom-variables)です。数式はフロー内でユーザーが入力した回答、他のカスタム変数、選択されたプロダクト、および現在の日付を読み取ることができます。フロー & ペイウォールビルダーの数式を使えば、アプリのコードなしにフロー内で計算結果を表示できます：

- **回答からの結果**: クイズのスコアの合計、身長と体重から計算したBMI、フィートとインチで表した身長など。
- **価格**: 20%割引後の選択中プロダクトの価格。
- **日付**: 無料トライアルの終了日。

フローはデバイス上でフォーミュラの結果を計算します。フォーミュラが参照する値が変わると、フローは結果を更新します。結果はテキスト要素に表示したり、条件内で使用したりできます。

## フォーミュラを作成する \{#create-a-formula\}

1. フローバルダーで <Inline id="variables.svg" alt="Variables" /> Variables パネルを開きます。
2. 新しい変数を追加します — <Inline id="plus.svg" alt="Plus" /> をクリックします。
3. 変数の **Name** を入力します（例: `bmi`）。他のフォーミュラはこの名前を使って結果を読み取ります。
4. **Value Type** ドロップダウンで **Formula** を選択します。
5. **Expression** フィールドにフォーミュラを入力します（例: `round({{weight}} * 10000 / ({{height}} * {{height}}), 1)`）。ここで `weight` と `height` は Number 変数です。ルールについては[フォーミュラを書く](#write-a-formula)を参照してください。
6. **Create variable** をクリックします。

<ZoomImage id="flow-formula-create.webp" width="300px" alt="数式タイプ、式フィールドにBMI計算式、数値出力タイプ、22.9のプレビューが表示された「変数を作成」ダイアログ" />

**Expression** フィールドからフォーカスが外れると、ビルダーが数式を検証します。数式にエラーがある場合、フィールドの下にエラーテキストが表示されます。エラーが表示されている間は、**Create variable** ボタン（既存の変数の場合は **Save**）が無効になります。式を編集するとエラーが消え、ボタンが再び使用可能になります。

フィールドの下に、エラーがない場合はヒントが表示されます。日付フォーミュラの場合は「Use a formula to set a date that updates automatically. Use negative n to go back in time」、その他のフォーミュラの場合は「Use round(x, 2) to set the decimals」というヒントが表示されます。

フィールドの下には、ビルダーに次の内容も表示されます：

- **Output type**: **Number** または **Date**（結果の型）。ビルダーがフォーミュラから自動で設定します。フォーミュラが[日付関数](#date-functions)または `{{trial_start}}` のような Date 値単体の場合は Date になり、それ以外は Number になります。
- **Date format**: Date フォーミュラの場合のみ。テキスト要素で結果をどのように表示するかを指定します。[テキスト要素に日付を表示する](#show-a-date-in-a-text-element)を参照してください。
- **Preview**: 初期値とプロダクト価格から計算された結果。[ビルダーでフォーミュラをプレビューする](#preview-a-formula-in-the-builder)を参照してください。

フォーミュラは常に他の値に依存するため、**Initial value**（初期値）はありません。同様の理由で、アプリからフォーミュラを設定することもできません。

### 参照と関数の挿入 \{#insert-references-and-functions\}

参照や関数を手入力せずに追加するには、**Output type** 行にある2つのボタンを使用します。各ボタンは **Expression** フィールドのカーソル位置にテキストを挿入します。

- <Inline id="variables.svg" alt="Insert variable" /> **Insert variable**: フォーミュラが読み取れる値を、**Variables**、**Answers**、**Selected product** の3グループに分けて表示します。値を選択すると、`{{weight.value}}` のような参照が挿入されます。
- <Inline id="function.svg" alt="Insert function" /> **Insert function**: 各関数を説明とサンプル付きで一覧表示します。検索フィールドに関数名を入力して絞り込むこともできます。関数を選択すると、`addDays(` のように関数名と開き括弧が挿入されます。その後、引数と閉じ括弧を入力してください。

**Insert variable** リストには、その数式が読み取れる値のみが表示されます。String、Boolean、Array の変数や、編集中の数式自体は表示されません。

## 数式の書き方 \{#write-a-formula\}

数式は、数値、値への参照、演算子、関数を組み合わせて作成します。関数名と変数名は大文字・小文字を区別します。たとえば `Round(2.5)` はエラーになります。

### 参照 \{#references\}

各参照を二重波括弧で囲みます：

| 参照 | 数式の意味 | 例 |
| :--- | :--- | :--- |
| `{{<variable name>}}` | Number、Date、またはFormula型のカスタム変数 | `{{discount}}` |
| `{{<Element ID>.value}}` | [テキストまたは数値入力](builder-inputs-and-forms)、[数値ピッカー](builder-number-picker)、または日付・日時入力への回答 | `{{weight.value}}` |
| `{{<Group ID>.selectedProduct.prod_price}}` | プロダクトグループでユーザーが選択したプロダクトの価格（数値） | `{{products.selectedProduct.prod_price}}` |
| `{{<Group ID>.selectedProduct.offer_price}}` | 選択したプロダクトのオファー価格（数値） | `{{products.selectedProduct.offer_price}}` |
| `{{<Group ID>.selectedProduct}}` | 選択したプロダクト（`addOfferDuration` の第2引数としてのみ使用可能） | `{{products.selectedProduct}}` |

数式は、入力された回答が数字のみで構成されており、先頭にオプションのマイナス符号、小数点または小数カンマの後にオプションの小数部分がある場合に、その回答を数値として読み取ります。数式は先頭と末尾のスペースを無視します。たとえば、`12`、`-5`、`1.5`、`1,5` は数値として扱われます。`abc`、`1,5,0`、`1e3` のように、これ以外の回答は数式に[値なし](#formulas-without-a-value)を返します。数式が読み取る数値入力フィールドでは、ユーザーは数値のみを入力できます。**Decimal (Point)** および **Decimal (Comma)** フォーマットでは、ユーザーは小数点または小数カンマを入力できるため、あらゆるキーボードの小数キーが使えます。

日付または日時の入力では、ユーザーが選択したカレンダーの日付を取得できます。

フォーミュラは別のフォーミュラを参照できますが、自分自身は参照できません。また、2つのフォーミュラがお互いを参照し合うことはできません。変数、**Element ID**、または **Group ID** の名前を変更すると、フォーミュラには新しい名前が表示され、同じ値が参照されます。フォーミュラが参照している変数を削除すると、その箇所に `{{deleted variable}}` と表示され、エラーが発生します。

`age.value` という名前の付いたカスタム変数と、Element ID が `age` の入力要素が両方存在する場合、`{{age.value}}` は両方に一致してしまいます。これはエラーです。カスタム変数の名前を変更してください。

### 数値と演算子 \{#numbers-and-operators\}

- **数値**: 小数点には必ずピリオドを使用します（例: `0.8`）。関数内ではカンマが引数の区切りとして使われます: `round(2,5)` は `round(2, 5)` と同じで、結果は 2.5 ではなく 2 になります。関数の外でカンマを数値に使うとエラーになります。数値や参照の前にマイナスを付けると負の値になります（例: `-3`）。
- **演算子**: `+`、`-`、`*`、`/` が使えます。フローでは `*` と `/` が `+` と `-` より先に計算され、同じ優先度の演算子は左から右の順で処理されます。計算順序を変えるには括弧を使います: `({{a}} + {{b}}) / 2`。

## 数値フォーミュラ \{#number-formulas\}

数値フォーミュラは数値を返します。

### 数値関数 \{#number-functions\}

| 関数 | 結果 | 例 |
| :--- | :--- | :--- |
| `round(n)` | `n` を整数に丸めた値。ちょうど中間の値はゼロから遠い方向に丸められます。 | `round(2.5)` = 3, `round(-2.5)` = -3 |
| `round(n, digits)` | `n` を小数点以下 `digits` 桁に丸めた値。`digits` は 0〜6 の整数で、数式に直接入力します（参照や計算式は使用不可）。 | `round(23.12, 1)` = 23.1, `round(1.005, 2)` = 1.01 |
| `floor(n)` | `n` 以下の最大の整数 | `floor(2.7)` = 2, `floor(-2.5)` = -3 |
| `mod(a, b)` | `a` を `b` で割った余りで、スプレッドシートの MOD 関数と同様に `b` の符号が使われます。 | `mod(7, 3)` = 1, `mod(-7, 3)` = 2, `mod(5.5, 2)` = 1.5 |

`round`、`floor`、`mod` の計算結果がゼロの場合、常に `0` となり、`-0` にはなりません。

### テキスト要素に数値を表示する \{#show-a-number-in-a-text-element\}

数式または日付変数を表示するには、変数ピッカーの **Custom** タブからテキスト要素に[変数を挿入](onboarding-variables#use-variables-in-text)します。最上位に `round` を持つ日付や数値は、フローの言語ではなくデバイスの言語で表示されます。

Number 数式の表示方法は、数式の最上位にある関数によって異なります：

- **トップレベルの `round`**: `round` で設定した小数点以下の桁数が正確に表示されます。デバイスの言語設定に応じた小数点区切り文字が使用され、千の位の区切り文字や通貨記号は付きません。たとえば、`round(23.12, 1)` は英語では「23.1」、ロシア語では「23,1」と表示され、`round(15.04, 1)` は英語では「15.0」と表示されます。
- **その他の数式**: 数値はすべての言語で小数点付きのそのままの形式で表示されます。小数の数値によっては桁数が長くなる場合があります。例えば `9.99 * 0.8` は「7.992000000000001」と表示されます。小数点以下の桁数を指定するには、`round(9.99 * 0.8, 2)` のように数式のトップレベルに `round` を置いてください。

数値型変数や、トップレベルで `floor` または `mod` を使ったフォーミュラも、通常形式で表示されます。

### 条件内での数値の比較 \{#compare-numbers-in-conditions\}

条件（[条件付き表示](onboarding-element-visibility)ルールや条件アクションなど）では、数式や日付変数を選択できます。

- **数値フォーミュラ**: 数値変数と同じ演算子を使用します: **Equals**、**Does not equal**、**Greater than**、**Less than**、**Is empty**、**Is not empty**。フォーミュラを数値または他の数値変数（例: `bmi` **Greater than** `25`）と比較します。「以上」「以下」の演算子はありません。10以上の整数（例: クイズのスコア）に一致させるには、`score` **Greater than** `9` を使用してください。

## 日付の数式 \{#date-formulas\}

日付の数式は日付を返します。試用開始日など、数式内で固定の日付を使用するには、その日付を日付型変数に保存してください。

### 日付変数を作成する \{#create-a-date-variable\}

1. <Inline id="variables.svg" alt="Variables" /> **Variables** パネルを開き、<Inline id="plus.svg" alt="Plus" /> をクリックします。
2. `trial_start` のような変数の **Name** を入力します。
3. **Value Type** ドロップダウンで **Date** を選択します。
4. （任意）**Initial value** フィールドに `DD.MM.YYYY` 形式の日付（例：`17.11.2026`）を入力するか、フィールドをクリックしてカレンダーから日付を選び、**Apply** をクリックします。`31.02.2027` のような存在しない日付は受け付けられません。Initial value を設定しない場合、[**Set variable** アクション](onboarding-actions)が値をセットするまで、変数には値がありません。
5. （任意）**Date format** ドロップダウンで、テキスト要素での日付の表示形式を選択します。[テキスト要素に日付を表示する](#show-a-date-in-a-text-element)を参照してください。
6. **Create variable** をクリックします。

<ZoomImage id="flow-date-variable-create.webp" width="300px" alt="The Create variable dialog with the Date type and the Initial value 17.11.2026" />

Date変数は、タイムゾーンや時刻を含まない日付のみを保持します。

ユーザーが要素をタップしたときにDate変数を変更するには、[**Set variable**](onboarding-actions)アクションを追加し、Date変数を選択して、新しい日付を`DD.MM.YYYY`形式で入力するか、カレンダーから選択します。**Set variable**アクションはフォーミュラを変更できません。フォーミュラは常に他の値に依存しているためです。

### 日付関数 \{#date-functions\}

| Function | Result | Example |
| :--- | :--- | :--- |
| `today()` | デバイス上の現在の日付 | `today()` |
| `addDays(date, n)` | `date` に `n` 日を加算した日付 | `addDays(today(), 7)` |
| `addWeeks(date, n)` | `date` に `n` 週を加算した日付 | `addWeeks({{trial_start}}, 2)` |
| `addMonths(date, n)` | `date` に `n` ヶ月を加算した日付 | `addMonths({{trial_start}}, 1)` |
| `addYears(date, n)` | `date` に `n` 年を加算した日付 | `addYears({{birth_date.value}}, 18)` |
| `addOfferDuration(date, product)` | `date` にプロダクトのオファー期間を加算した日付 | `addOfferDuration(today(), {{products.selectedProduct}})` |

The date functions follow these rules:

- **`today()`**: デバイスのタイムゾーンで現在の日の開始時刻を返します。フローは開いたときに日付を読み取るため、フローが開いている間に日付が変わっても値は変わりません。
- **負の値・小数の `n`**: `n` が負の値の場合は日付が過去に移動します。フローは `n` の小数部分を切り捨てます。`addWeeks(date, 1.5)` は1週間を加算し、`addDays(date, -1.9)` は1日分過去に移動します。
- **月末処理**: 対象の月にその日付が存在しない場合、結果はその月の最終日になります。たとえば、2027年1月31日の1か月後は2027年2月28日、2028年2月29日の1年後は2029年2月28日となります。
- **`addOfferDuration`**: Adapty SDK がフローに渡すプロダクトのオファーの各フェーズを順番に加算します。各フェーズでは、そのフェーズの期間にフェーズ内の期間数を掛けた値が一度に加算されます。たとえば、2026年11月10日に開始する7日間の無料トライアルは2026年11月17日に終了します。プロダクトにオファーがない場合、またはオファーのいずれかのフェーズに不明な期間がある場合、結果は値なしになります。

数式内では、日付（Date）は日付関数の最初の引数としてのみ使用できます。`{{trial_start}} + 1` のような計算式で日付を使用するとエラーになります。数値（Number）は日付関数の最初の引数には使用できません。文字列（String）、ブール値（Boolean）、または配列（Array）の変数は数式に含めることができません。

### テキスト要素に日付を表示する \{#show-a-date-in-a-text-element\}

数式やDate変数を表示するには、変数ピッカーの **Custom** タブからテキスト要素に[変数を挿入](onboarding-variables#use-variables-in-text)してください。トップレベルで `round` を使用した日付や数値は、フローの言語ではなくデバイスの言語で表示されます。

Date変数とDate数式には、変数設定に **Date format** があります。その変数を表示するすべてのテキスト要素がこのフォーマットを使用し、フォーマットを変更するとそれらのテキスト要素すべてに反映されます。新しい変数のデフォルトフォーマットは **Medium** です。

1つのテキスト要素で別のフォーマットを使用するには、**Content** フィールドで変数をクリックし、フォーマットを選択します。変数のデフォルトフォーマットに戻すには、**Variable default** を選択します。フォーマットの種類は以下のとおりです。

| 日付フォーマット | 英語の例 |
| :--- | :--- |
| **Short** | 11/17/26 |
| **Medium** | Nov 17, 2026 |
| **Long** | November 17, 2026 |
| **Month D** | November 17 |
| **Mon D** | Nov 17 |

**Short**、**Medium**、**Long** はデバイスの言語設定に従った日付の順序で表示されます。**Month D** と **Mon D** はすべての言語で月が日の前に表示されます（例：ロシア語では「ноября 17」）。

### 条件における日付の比較 \{#compare-dates-in-conditions\}

条件（[条件付き表示](onboarding-element-visibility)ルールや条件付きアクションなど）で、フォーミュラまたは日付変数を選択できます。

- **日付変数と日付フォーミュラ**: **Equals**、**Does not equal**、**Earlier than**、または **Later than** を使用します。日付を別の日付と比較するか、`DD.MM.YYYY` 形式で入力するかカレンダーで選択した日付と比較します。

日付の比較は、時刻ではなく暦日を対象に行われます。たとえば、2026年11月17日の21:00にユーザーが選択した日付は `17.11.2026` と等しくなります。日付と数値を比較することはできません。

## 値がないフォーミュラ \{#formulas-without-a-value\}

フォーミュラは、次のいずれかの値がデバイス上で利用できない場合に値を持ちません。

- 回答が空、または数値ではない。
- プロダクトの価格が読み込まれていない。
- 選択されたプロダクトにオファーがなく、フォーミュラが `offer_price` を読み取るか `addOfferDuration` を呼び出す。
- フォーミュラがゼロ除算を行う（`{{a}} / 0` や `mod({{a}}, 0)` など）。
- フォーミュラが読み取る Date 変数に値がない。

値のないフォーミュラを読み取るフォーミュラも、同様に値を持ちません。値がない場合、フォーミュラは次のように動作します。

- **テキスト要素**: 数式には何も表示されません。
- **条件**: **Is empty** が true になります。**Equals**、**Does not equal**、およびその他すべての数式の比較は false になります。

フローは、数式が参照する値が変化したタイミングで数式の結果を更新します。ユーザーが回答を入力したとき、**Set variable** アクションで変数が変更されたとき、またはプロダクトの価格が読み込まれたときです。ユーザーが戻って回答を削除した場合、次の画面では数式に値がありません。カスタム変数がフローによって変更されるまで、数式はその変数の初期値を参照します。

## ビルダーで数式をプレビューする \{#preview-a-formula-in-the-builder\}

ビルダーは、カスタム変数の初期値と選択したプロダクトの `prod_price` を使って数式の結果を計算します。次のいずれかを数式が参照している場合、**Expression** フィールドの下にある **Preview** には **No value** と表示されます。

- ユーザーが入力または選択した回答
- `offer_price`
- `addOfferDuration` のオファー
- 初期値のない Date 変数など、値のない変数

このような場合、キャンバス上のテキスト要素には `{{trial_end}}` のように変数名が中括弧で表示されます。回答の値を確認するには、[Adapty モバイルアプリでフローをプレビュー](paywall-device-compatibility-preview)してください。オファーの値には、実際のプロダクトを使用したアプリのビルドが必要です。

キャンバス上では、最上位レベルに `round` が設定された日付や数値は、プレビュー用に選択した言語で表示されます。

## 例 \{#examples\}

### 回答の合計を表示する \{#show-a-sum-of-answers\}

画面に3つの数値入力を追加し、エレメントIDをそれぞれ `a1`、`a2`、`a3` に設定します。次のような数式 `sum` を作成します。

```
{{a1.value}} + {{a2.value}} + {{a3.value}}
```

次の画面のテキスト要素に `sum` を挿入します。ユーザーが2、3、4を入力すると「9」と表示されます。4を5に変更して戻ると「10」と表示されます。

### BMI と「High」ラベルを表示する \{#show-a-bmi-and-a-high-label\}

体重（キログラム）用の Element ID `weight` と、身長（センチメートル）用の Element ID `height` を持つ Number 入力を追加します。次のフォーミュラ `bmi` を作成します：

```
round({{weight.value}} * 10000 / ({{height.value}} * {{height.value}}), 1)
```

`bmi` をテキスト要素に挿入します。BMI が 23.12 の場合、デバイスの言語が英語なら「23.1」、ロシア語なら「23,1」と表示されます。BMI が 25 を超えた場合のみ「High」というラベルを表示するには、「High」というテキスト要素を追加し、[条件付き表示](onboarding-element-visibility)ルールを設定します：`bmi` **Greater than** `25`。

### 割引価格を表示する \{#show-a-discounted-price\}

選択されたプロダクトの価格から20%割引するフォーミュラ `discounted` を作成します：

```
{{products.selectedProduct.prod_price}} * 0.8
```

次に、小数点以下2桁に丸めるフォーミュラ `shown` を作成します：

```
round({{discounted}}, 2)
```

`shown` をテキスト要素に挿入します。価格が9.99のプロダクトを選択すると「7.99」と表示され、価格が100のプロダクトを選択すると「80.00」と表示されます。数値に通貨記号はつきません。選択されたプロダクトの価格が読み込まれなかった場合、テキストは空になります。

### トライアル終了日とリマインダー日付の表示 \{#show-the-end-of-a-trial-and-a-reminder-date\}

`trial_end` という数式を作成します：

```
addOfferDuration(today(), {{products.selectedProduct}})
```

次に、トライアル終了の3日前を示す `reminder` という数式を作成します：

```
addDays({{trial_end}}, -3)
```

7日間の無料トライアルが付いたプロダクトの場合、2026年11月10日時点では、`trial_end` は2026年11月17日、`reminder` は2026年11月14日になります。日付フォーマットに **Medium** を選択すると "Nov 17, 2026" と表示され、**Month D** を選択すると "November 17" と表示されます。

### 身長をフィートとインチで表示する \{#show-a-height-in-feet-and-inches\}

エレメント ID `height` を持つ数値入力フィールドを追加し、身長をセンチメートルで入力できるようにします。次の3つの数式を作成します：

- `total`: `round({{height.value}} / 2.54)`（インチ単位の身長を整数に丸めたもの）
- `feet`: `floor({{total}} / 12)`
- `inches`: `mod({{total}}, 12)`

テキスト要素に `feet` を挿入し、「ft」と入力してから `inches` を挿入し、「in」と入力します。180 cm の場合は「5 ft 11 in」と表示されます。140 cm の場合は「4 ft 7 in」と表示されます。

## トラブルシューティング \{#troubleshooting\}

**Expression** フィールドからフォーカスを外すと、フィールドの下にその計算式の最初のエラーが表示されます。以下はその例です。

| エラーテキスト | 原因と修正方法 |
| :--- | :--- |
| `addDays() needs a date and a number` | 関数の引数の数が間違っているか、型が正しくありません。[数値関数](#number-functions)または[日付関数](#date-functions)の表に記載された引数を使用してください。 |
| `Unknown function "flor". Use one of: …` | 関数名のスペルが間違っているか、大文字・小文字が異なります。エラーに表示されているリストから関数を選択してください。変数を参照する場合は、名前を `{{ }}` で囲んでください。 |
| `Use a dot in a decimal number, like 1.5` | 関数の外にある数値にカンマが使われています。カンマを小数点（ドット）に置き換えてください。関数内では、ビルダーがカンマを引数の区切り文字として認識するため、小数点にはドットを使用してください。 |
| `{{…}} is not a variable, an answer or a product field of this flow` | この名前に一致する変数、要素ID、またはプロダクトグループが存在しません。名前を修正するか、変数を作成してください。 |
| `This variable no longer exists. Pick another one.` | 数式が参照している変数が削除されています。数式内では `{{deleted variable}}` と表示されます。別の参照に置き換えてください。 |
| `{{…}} is the name of a variable and of an element answer: rename the variable` | 名前が2つの値に一致しています。カスタム変数の名前を変更してください。 |
| `{{…}} uses this formula: formulas cannot use each other in a loop` | 2つ以上の数式が互いを参照しています。いずれかの参照を削除してください。 |

## 制限事項 \{#limitations\}

- **数値と日付のみ**: 数式が返せるのは数値または日付だけです。結果に応じたテキストを表示するには、テキスト要素に[条件付きテキスト](onboarding-text#add-conditional-text)を追加してください。たとえば、BMIが25を超えた場合に「High」と表示するには、**if** 条件を `bmi` **Greater than** `25` に設定し、**then** に「High」と入力します。
- **プロダクト価格**: 数式が読み取れるのは、各プロダクトグループで選択されているプロダクトの価格のみです。ユーザーが年間プランを選択している場合の月額プランなど、選択されていないプロダクトの価格は読み取れません。画面が開いたときに結果を表示するには、いずれかのプロダクトカードで **Set as default** を選択してください。
- **iOS と Android のオファー**: iOS では、Adapty SDK はフローに1つのオファーを渡します。ユーザーが利用できるオファーの中では、ウィンバックオファーが最優先となり、次にプロモーションオファー、そして初回オファーの順になります。Android では、Adapty SDK は初回オファーの最初のフェーズのみを渡します。無料トライアルの後に割引価格が続く場合、Android の `addOfferDuration` はトライアル分のみを加算します。
