数式は[カスタム変数](onboarding-variables#custom-variables)の一種で、計算された値（数値または日付）を持ちます。数式は、フロー内でユーザーが回答した内容、その他のカスタム変数、Adaptyカタログ内のプロダクト価格、および現在の日付を参照できます。フロー＆ペイウォールビルダーの数式を使うと、アプリのコードを書かずに計算された値をフローで表示できます。

- **回答からの結果**: クイズのスコアの合計、身長と体重から算出したBMI、フィートとインチで表した身長など。
- **価格**: 20%割引後のプロダクト価格、週間プランと比較した年間プランの節約額など。
- **日付**: 無料トライアルの終了日など。
- **期間**: 無料トライアルの日数、生年月日から計算したユーザーの年齢など。

フローはデバイス上で数式の結果を計算します。数式が読み取る値が変化すると、フローは結果を更新します。結果はテキスト要素に表示したり、条件の中で使用したりできます。

## フォーミュラを作成する \{#create-a-formula\}

1. フローバルダーで <Inline id="variables.svg" alt="Variables" /> Variables パネルを開きます。
2. 新しい変数を追加します — <Inline id="plus.svg" alt="Plus" /> をクリックします。
3. 変数の **Name** を入力します（例: `bmi`）。他のフォーミュラはこの名前を使って結果を読み取ります。
4. **Value Type** ドロップダウンで **Formula** を選択します。
5. **Expression** フィールドにフォーミュラを入力します（例: `round({{weight}} * 10000 / ({{height}} * {{height}}), 1)`）。ここで `weight` と `height` は Number 変数です。ルールについては[フォーミュラを書く](#write-a-formula)を参照してください。
6. **Create variable** をクリックします。

<ZoomImage id="flow-formula-create.webp" width="300px" alt="「式」フィールドにBMIの数式が入力され、出力タイプが数値、プレビューが22.9と表示されている「変数を作成」ダイアログ（タイプ: 数式）" />

**Expression**フィールドからフォーカスを外すと、ビルダーが数式を検証します。数式にエラーがある場合、フィールドの下にエラーテキストが表示されます。エラーが表示されている間は、**Create variable**ボタン（既存の変数の場合は**Save**）が無効になります。式を編集するとエラーが消え、ボタンが再び有効になります。

フィールドの下には以下が表示されます:

- **出力タイプ**: **Number**（数値）または **Date**（日付）。数式の内容に応じてビルダーが自動で設定します。`addDays` のように日付を返す[日付関数](#date-functions)や、`{{trial_start}}` のような Date 値単体の場合は Date になります。2つの日付の差を日数で返す `daysBetween` など、その他の数式はすべて Number になります。
- **日付フォーマット**: Date 型の数式のみ。テキスト要素での結果の表示形式を指定します。[テキスト要素に日付を表示する](#show-a-date-in-a-text-element)を参照してください。
- **プレビュー**: 初期値とプロダクト価格をもとに計算した結果です。[ビルダーで数式をプレビューする](#preview-a-formula-in-the-builder)を参照してください。

フォーミュラは常に他の値に依存するため、**Initial value**（初期値）はありません。同様の理由で、アプリからフォーミュラを設定することもできません。

### 参照と関数を挿入する \{#insert-references-and-functions\}

変数の正確な名前がわからない場合は、**Expression** フィールドに `{{` と入力します。変数のリストが表示されます。名前の一部を入力してリストを絞り込み、変数を選択して参照を挿入します。関数名を入力したときにもリストが表示されます。`{{weight}}` や `5` のような数値の後にスペースを入力すると、`+`、`-`、`*`、`/` の演算子が候補として表示されます。リストを閉じるには Escape キーを押します。

このリストには、カーソル位置に使用できる変数と関数のみが表示されます。たとえば、`addDays` の最初の引数では、Date 型の値、`today()`、および日付を返す関数が候補として表示されます。`round` の2番目の引数では、小数点以下の桁数は直接入力する数値であるため、候補は何も表示されません。

**Expression** フィールドには、各参照がチップとして表示されます。カスタム変数の場合は **weight**、プロダクトの価格の場合は **Weekly · prod_price** のように、変数名がチップに表示されます。チップは1つの単位です。Backspace または Delete でその参照全体が削除され、矢印キーでカーソルがチップを飛び越えて移動します。

フォーミュラが読み取れるすべての変数を参照したり、関数の説明を読んだりするには、**Output type** 行にある2つのボタンを使用します。各ボタンは **Expression** フィールドのカーソル位置にテキストを挿入します。

- <Inline id="variables.svg" alt="Insert variable" /> **Insert variable**: 4つのタブを含むリストを開きます。値を選択するとその参照が挿入され、関数を選択するとその名前と開き括弧が挿入されます:
  - **Functions**: 数式で使用できる関数の一覧。
  - **Elements**: `weight.value` など、入力フィールドやピッカーで選択された値。
  - **Products**: 各プロダクトグループで選択されたプロダクトの価格、次いで Adapty カタログのプロダクト。[任意のプロダクトの価格を取得する](#read-the-price-of-any-product)を参照してください。
  - **Custom**: 数値・日付・数式のカスタム変数。
- <Inline id="function.svg" alt="Insert function" /> **Insert function**: 各関数の説明と使用例を一覧表示します。検索フィールドに関数名を入力して絞り込むことができます。関数を選択すると `addDays(` のように名前と開き括弧が挿入されます。その後、引数と閉じ括弧を入力してください。

**Insert variable** リストには、String・Boolean・Array変数や、編集中のフォーミュラは表示されません。

## 数式の書き方 \{#write-a-formula\}

数式は、数値、値への参照、演算子、関数を組み合わせて作成します。関数名と変数名は大文字・小文字を区別します。たとえば `Round(2.5)` はエラーになります。

### 参照 \{#references\}

各参照を二重波括弧で囲みます：

| 参照 | 式の意味 | 例 |
| :--- | :--- | :--- |
| `{{<variable name>}}` | Number、Date、またはFormula型のカスタム変数 | `{{discount}}` |
| `{{<Element ID>.value}}` | [テキストまたは数値入力](builder-inputs-and-forms)、[数値ピッカー](builder-number-picker)、あるいは日付・日時入力への回答 | `{{weight.value}}` |
| `{{<Group ID>.selectedProduct.prod_price}}` | プロダクトグループでユーザーが選択したプロダクトの価格（数値） | `{{products.selectedProduct.prod_price}}` |
| `{{<Group ID>.selectedProduct.prod_price_per_week}}` | 選択したプロダクトの1週間あたりの価格。`prod_price_per_day`、`prod_price_per_month`、`prod_price_per_year`も利用可能。サブスクリプション以外のプロダクトには値が返りません。[期間別価格](#per-period-prices)を参照。 | `{{products.selectedProduct.prod_price_per_month}}` |
| `{{<Group ID>.selectedProduct.offer_price}}` | 選択したプロダクトのオファー価格（数値） | `{{products.selectedProduct.offer_price}}` |
| `{{<Group ID>.selectedProduct}}` | 選択したプロダクト。`addOfferDuration`の第2引数としてのみ使用可能 | `{{products.selectedProduct}}` |
| `{{<Adapty product ID>.prod_price}}` | Adaptyカタログ内のプロダクトの価格（数値）。`prod_price_per_week`などの期間別価格も利用可能。[任意のプロダクトの価格を読み取る](#read-the-price-of-any-product)を参照。 | `{{<annual product ID>.prod_price}}`（**Annual · prod_price** と表示） |

数式は、入力された回答が数字のみで構成されており、先頭にオプションのマイナス符号、小数点または小数カンマの後にオプションの小数部分がある場合に、その回答を数値として読み取ります。数式は先頭と末尾のスペースを無視します。たとえば、`12`、`-5`、`1.5`、`1,5` は数値として扱われます。`abc`、`1,5,0`、`1e3` のように、これ以外の回答は数式に[値なし](#formulas-without-a-value)を返します。数式が読み取る数値入力フィールドでは、ユーザーは数値のみを入力できます。**Decimal (Point)** および **Decimal (Comma)** フォーマットでは、ユーザーは小数点または小数カンマを入力できるため、あらゆるキーボードの小数キーが使えます。

日付または日時の入力は、ユーザーが選択したカレンダーの日付を返します。

数式は別の数式を参照できますが、循環参照は許可されていません。数式Aが数式Bを参照している場合、数式BはAを参照できません。A→B→C→Aのような長い循環も同様にエラーになります。数式は自分自身を参照できません。変数、**Element ID**、または **Group ID** の名前を変更すると、数式には新しい名前が表示され、同じ値が読み込まれます。数式が参照している変数を削除すると、**Expression** フィールドにはその箇所に **deleted variable** チップが表示され、フィールドの下にエラーが表示されます。

`age.value` という名前の付いたカスタム変数と、Element ID が `age` の入力要素が両方存在する場合、`{{age.value}}` は両方に一致してしまいます。これはエラーです。カスタム変数の名前を変更してください。

### 数値と演算子 \{#numbers-and-operators\}

- **数値**: 小数点には必ずピリオドを使用します（例: `0.8`）。関数内ではカンマが引数の区切りとして使われます: `round(2,5)` は `round(2, 5)` と同じで、結果は 2.5 ではなく 2 になります。関数の外でカンマを数値に使うとエラーになります。数値や参照の前にマイナスを付けると負の値になります（例: `-3`）。
- **演算子**: `+`、`-`、`*`、`/` が使えます。フローでは `*` と `/` が `+` と `-` より先に計算され、同じ優先度の演算子は左から右の順で処理されます。計算順序を変えるには括弧を使います: `({{a}} + {{b}}) / 2`。

## 数値フォーミュラ \{#number-formulas\}

数値フォーミュラは数値を返します。

### 数値関数 \{#number-functions\}

| 関数 | 結果 | 例 |
| :--- | :--- | :--- |
| `round(n)` | `n` を整数に丸めた値。ちょうど中間の値はゼロから遠い方向に丸められます。 | `round(2.5)` = 3, `round(-2.5)` = -3 |
| `round(n, digits)` | `n` を小数点以下 `digits` 桁に丸めた値。`digits` は 0〜6 の整数で、数式に直接入力します（参照や計算式は使用不可）。 | `round(23.12, 1)` = 23.1, `round(1.005, 2)` = 1.01 |
| `floor(n)` | `n` 以下の最大の整数 | `floor(2.7)` = 2, `floor(-2.5)` = -3 |
| `mod(a, b)` | `a` を `b` で割った余りで、スプレッドシートの MOD 関数と同様に `b` の符号が使われます。 | `mod(7, 3)` = 1, `mod(-7, 3)` = 2, `mod(5.5, 2)` = 1.5 |

`round`、`floor`、`mod` の計算結果がゼロの場合、常に `0` となり、`-0` にはなりません。

### テキスト要素に数値を表示する \{#show-a-number-in-a-text-element\}

数式または日付変数を表示するには、変数ピッカーの **Custom** タブからテキスト要素に[変数を挿入](onboarding-variables#use-variables-in-text)します。最上位に `round` を持つ日付や数値は、フローの言語ではなくデバイスの言語で表示されます。

Number 数式の表示方法は、数式の最上位にある関数によって異なります：

- **`round` がトップレベルにある場合**: `round` で指定した小数点以下の桁数がそのまま表示されます。端末の言語設定に応じた小数点区切り文字が使われ、桁区切り文字や通貨記号は付きません。たとえば、`round(23.12, 1)` は英語では "23.1"、ロシア語では "23,1" と表示され、`round(15.04, 1)` は英語では "15.0" と表示されます。
- **その他の数式**: 数値はそのままの形で表示され、すべての言語で小数点にはピリオドが使われ、有効数字は最大 15 桁です。たとえば、`9.99 * 0.8` は "7.992"、`1 - 1 / 3` は "0.666666666666667" と表示されます。小数点以下の桁数を指定するには、`round(1 - 1 / 3, 2)` のように数式のトップレベルに `round` を置いてください。

数値型変数や、トップレベルで `floor` または `mod` を使ったフォーミュラも、通常形式で表示されます。

### 条件内での数値の比較 \{#compare-numbers-in-conditions\}

条件（[条件付き表示](onboarding-element-visibility)ルールや条件アクションなど）では、数式や日付変数を選択できます。

- **数値フォーミュラ**: 数値変数と同じ演算子を使用します: **Equals**、**Does not equal**、**Greater than**、**Less than**、**Is empty**、**Is not empty**。フォーミュラを数値または他の数値変数（例: `bmi` **Greater than** `25`）と比較します。「以上」「以下」の演算子はありません。10以上の整数（例: クイズのスコア）に一致させるには、`score` **Greater than** `9` を使用してください。

## プロダクトの価格 \{#product-prices\}

フォーミュラは、2つのソースからプロダクトの価格を読み取ることができます。

- **プロダクトグループで選択されたプロダクト**: ユーザーがグループ内の別のプロダクトを選択すると価格が変わります。例: `{{products.selectedProduct.prod_price}}`
- **Adapty カタログ内のプロダクト**: 画面に表示されていないプロダクトも含め、特定の1つのプロダクトの価格を参照できます。たとえば、週次プランと比較した年次プランの節約額を表示するといった用途に使えます。

デバイス上では、フローはユーザーの通貨でストア価格を使用します。プロダクトの価格が読み込まれると、フローはフォーミュラを再計算します。

### 任意のプロダクトの価格を読み取る \{#read-the-price-of-any-product\}

1. **Expression** フィールドで、価格を挿入したい場所にカーソルを置きます。
2. <Inline id="variables.svg" alt="Insert variable" /> **Insert variable** をクリックし、**Products** タブを開きます。
3. プロダクトを選択し、価格を選びます: `prod_price`、または `prod_price_per_week` のような[期間別価格](#per-period-prices)。

**Products** タブには、プロダクトが2つのグループに分かれて表示されます:

- **This flow**: フローの画面に含まれるプロダクト。
- **Other**: Adapty カタログ内のその他のプロダクト。

プロダクトを区別するには、リスト内の各プロダクトのアクセスレベルとUSD価格を比較してください。リストにはプロダクトのサブスクリプション期間は表示されません。2つのプロダクトが同じタイトルを持つ場合、リストとチップのツールチップにストアのプロダクトIDも表示されます。

数式は、プロダクトが[スクリーンのプロダクトリスト](paywall-product-block)に含まれている場合のみ、画面上に価格を表示できます。テキスト要素に数式を挿入したり、条件内で使用したりすると、ビルダーはオファーや請求プランなしでそのプロダクトをリストに追加します。別の数式を通じて価格を読み取る場合も同様です。再利用可能なコンポーネントの場合、ビルダーはそのコンポーネントを表示する各スクリーンにプロダクトを追加します。スクリーンにすでにオファーまたは請求プランありのプロダクトが存在する場合、ビルダーはそれらなしの2つ目のエントリを追加します。

追加されたエントリは、**Products** パネル、アナリティクス、およびアプリのコードが受け取るプロダクト一覧に、画面の他のプロダクトと同様に表示されます。画面がそれを選択することはなく、テキストをタップしても購入は開始されません。

ビルダーがエントリを追加した後は、**Products** パネルで他のプロダクトと同様に管理できます。

- **価格を数式から削除するか、数式をスクリーンから削除した場合**：エントリはそのまま残ります。そのプロダクトをスクリーン上の他の要素が使用していなければ、エントリを削除してください。残したエントリは、Adapty カタログからプロダクトを削除した後でもパブリッシュをブロックします。
- **スクリーンがまだ数式を使用している状態でエントリを削除した場合**：ビルダーはエントリを自動的に追加し直しません。スクリーンには **This product is off this screen** という問題が表示されます。修正するには、**Products** パネルからプロダクトを追加し直してください。

Adaptyカタログからプロダクトを削除すると、**Expression**フィールドにその価格が**Missing product**チップとして表示され、フィールドの下にエラーが表示されます。その価格を別のプロダクトの価格に置き換えてください。削除しても、フローの公開済みバージョンは変更されません。

[Adapty CLI](developer-cli-flows) または API でフローを作成する場合、ビルダーと同様に、数式を使用する各スクリーンに、オファーや課金プランなしでプロダクトを追加してください。数式内では、[`adapty products list`](developer-cli-products) が返す Adapty プロダクト ID を使用します。テキスト要素または条件が数式を使用しているのに、フローのどのスクリーンにもオファーや課金プランなしのプロダクトが存在しない場合のみ、`formula_undeclared_product` エラーで公開に失敗します。

### 期間ごとの価格 \{#per-period-prices\}

期間ごとの価格とは、サブスクリプションプロダクトの1日、1週間、1ヶ月、または1年あたりの価格です。フォーミュラは、カタログプロダクトおよびプロダクトグループで選択されたプロダクトについて、これらの価格を読み取ることができます。

| 価格 | 月額9.99のプロダクトの例 |
| :--- | :--- |
| `prod_price_per_day` | 9.99 / 30 = 0.333 |
| `prod_price_per_week` | 9.99 × 7 / 30 = 2.331 |
| `prod_price_per_month` | 9.99 |
| `prod_price_per_year` | 9.99 × 12 = 119.88 |

フローは、プロダクトのサブスクリプション期間（日数、週数、月数、年数）で価格を割ります。1ヶ月は30日なので、1ヶ月は30/7週です。1年は365日、52週、または12ヶ月です。[テキスト要素の価格変数](onboarding-variables#product-variables)も同じ換算方法を使用します。たとえば、価格が120の年間プロダクトの場合、`prod_price_per_month`は10、`prod_price_per_week`は120 / 52になります。

この計算式は、1期間あたりの価格のすべての小数点以下の桁数を保持します。価格を小数点以下2桁で表示するには、計算式のトップレベルに `round` を配置してください。ユーザーが120という価格の年間プロダクトを選択した場合、`round({{products.selectedProduct.prod_price_per_week}}, 2)` は "2.31" と表示されます。

サブスクリプション以外のプロダクト（永続アクセスプロダクトや消耗型アイテムなど）の場合、1期間あたりの価格は[値なし](#formulas-without-a-value)となります。

## 日付の数式 \{#date-formulas\}

日付の数式は日付を返します。試用開始日など、数式内で固定の日付を使用するには、その日付を日付型変数に保存してください。

### 日付変数を作成する \{#create-a-date-variable\}

1. <Inline id="variables.svg" alt="Variables" /> **Variables** パネルを開き、<Inline id="plus.svg" alt="Plus" /> をクリックします。
2. `trial_start` のような変数の **Name** を入力します。
3. **Value Type** ドロップダウンで **Date** を選択します。
4. （任意）**Initial value** フィールドに `DD.MM.YYYY` 形式の日付（例：`17.11.2026`）を入力するか、フィールドをクリックしてカレンダーから日付を選び、**Apply** をクリックします。`31.02.2027` のような存在しない日付は受け付けられません。Initial value を設定しない場合、[**Set variable** アクション](onboarding-actions)が値をセットするまで、変数には値がありません。
5. （任意）**Date format** ドロップダウンで、テキスト要素での日付の表示形式を選択します。[テキスト要素に日付を表示する](#show-a-date-in-a-text-element)を参照してください。
6. **Create variable** をクリックします。

<ZoomImage id="flow-date-variable-create.webp" width="300px" alt="The Create variable dialog with the Date type and the Initial value 17.11.2026" />

Date変数は、タイムゾーンや時刻を含まない日付のみを保持します。

ユーザーが要素をタップしたときにDate変数を変更するには、[**Set variable**](onboarding-actions)アクションを追加し、Date変数を選択して、新しい日付を`DD.MM.YYYY`形式で入力するか、カレンダーから選択します。**Set variable**アクションはフォーミュラを変更できません。フォーミュラは常に他の値に依存しているためです。

### 日付関数 \{#date-functions\}

| 関数 | 結果 | 例 |
| :--- | :--- | :--- |
| `today()` | デバイス上の現在の日付 | `today()` |
| `addDays(date, n)` | `date` に `n` 日を加算した日付 | `addDays(today(), 7)` |
| `addWeeks(date, n)` | `date` に `n` 週を加算した日付 | `addWeeks({{trial_start}}, 2)` |
| `addMonths(date, n)` | `date` に `n` ヶ月を加算した日付 | `addMonths({{trial_start}}, 1)` |
| `addYears(date, n)` | `date` に `n` 年を加算した日付 | `addYears({{birth_date.value}}, 18)` |
| `addOfferDuration(date, product)` | `date` にプロダクトのオファー期間を加算した日付 | `addOfferDuration(today(), {{products.selectedProduct}})` |
| `daysBetween(start, end)` | `start` から `end` までのカレンダー日数（数値） | `daysBetween(today(), {{trial_end}})` |
| `weeksBetween(start, end)` | `start` から `end` までの週数（整数、数値） | `weeksBetween({{trial_start}}, today())` |
| `monthsBetween(start, end)` | `start` から `end` までの月数（整数、数値） | `monthsBetween({{trial_start}}, today())` |
| `yearsBetween(start, end)` | `start` から `end` までの年数（整数、数値） | `yearsBetween({{birth_date.value}}, today())` |

The date functions follow these rules:

- **`today()`**: デバイスのタイムゾーンで現在の日の開始時刻を返します。フローは開いた時点で日付を読み取るため、フローが開いている間に日付が変わっても値は変わりません。
- **負の値・小数の `n`**: `n` が負の場合は日付が過去方向に移動します。フローは `n` の小数部分を切り捨てます。`addWeeks(date, 1.5)` は1週間を加算し、`addDays(date, -1.9)` は日付を1日前に移動します。
- **月末の短縮**: 対象の月に該当する日が存在しない場合、結果はその月の最終日になります。たとえば、2027年1月31日の1ヶ月後は2027年2月28日、2028年2月29日の1年後は2029年2月28日になります。
- **`addOfferDuration`**: Adapty SDKがフローに渡すプロダクトのオファーの各フェーズを順番に加算します。各フェーズについて、フェーズの期間にその期間数を掛けた値を一度に加算します。たとえば、2026年11月10日に開始する7日間の無料トライアルは2026年11月17日に終了します。プロダクトにオファーがない場合、またはオファーのいずれかのフェーズの期間が不明な場合、結果は値なしになります。
- **日付間の時間**: `daysBetween`、`weeksBetween`、`monthsBetween`、`yearsBetween` は完全な単位のみをカウントし、端数は切り捨てます。
  - `weeksBetween` は日数を7で割ります。13日は1週間です。
  - `monthsBetween` と `yearsBetween` は完全なカレンダー月・年をカウントします。たとえば、2027年1月15日から2027年3月14日までは1ヶ月、2027年3月15日までは2ヶ月です。`end` の月が `start` の日に対して短すぎる場合、その月の最終日でひと月が完成します。2027年1月31日から2027年2月28日までは1ヶ月です。
  - `end` が `start` より前の場合、結果は負の値になります。逆順の2つの日付に対する結果にマイナスを付けたものです。たとえば、`daysBetween` で2026年12月1日から2026年11月24日は -7 になり、`weeksBetween` では `start` より10日前の `end` に対して -1 になります。

数式の中で、Date（日付）は、日付に時間を加算する関数の最初の引数、または2つの日付の間の時間を計算する関数の引数としてのみ使用できます。`{{trial_start}} + 1` のように計算式の中で Date を使用するとエラーになります。Number（数値）は、関数が日付を必要とする引数には使用できません。String（文字列）、Boolean（真偽値）、Array（配列）の変数は、数式の一部として使用できません。

### テキスト要素に日付を表示する \{#show-a-date-in-a-text-element\}

数式やDate変数を表示するには、変数ピッカーの **Custom** タブからテキスト要素に[変数を挿入](onboarding-variables#use-variables-in-text)してください。トップレベルで `round` を使用した日付や数値は、フローの言語ではなくデバイスの言語で表示されます。

Date変数とDate数式には、変数設定に **Date format** があります。その変数を表示するすべてのテキスト要素がこのフォーマットを使用し、フォーマットを変更するとそれらのテキスト要素すべてに反映されます。新しい変数のデフォルトフォーマットは **Medium** です。

1つのテキスト要素で別のフォーマットを使用するには、**Content** フィールドで変数をクリックし、フォーマットを選択します。変数のデフォルトフォーマットに戻すには、**Variable default** を選択します。フォーマットの種類は以下のとおりです。

| 日付フォーマット | 英語の例 |
| :--- | :--- |
| **Short** | 11/17/26 |
| **Medium** | Nov 17, 2026 |
| **Long** | November 17, 2026 |
| **Month D** | November 17 |
| **Mon D** | Nov 17 |

**Short**、**Medium**、**Long** はデバイスの言語設定に従った日付の順序で表示されます。**Month D** と **Mon D** はすべての言語で月が日の前に表示されます（例：ロシア語では「ноября 17」）。

### 条件における日付の比較 \{#compare-dates-in-conditions\}

フォーミュラまたは日付変数を条件（[条件付き表示](onboarding-element-visibility)ルールや条件付きアクションなど）で選択できます。

- **日付変数と日付フォーミュラ**: **Equals**、**Does not equal**、**Earlier than**、**Later than**、**Is empty**、または **Is not empty** を使用できます。日付を別の日付や、`DD.MM.YYYY` 形式で直接入力した日付、またはカレンダーで選択した日付と比較できます。**Is empty** は、日付に値がない状態（たとえば **Set variable** アクションで値が設定される前の初期値のない日付変数）のときに true になります。

日付の比較はカレンダーの日付で行われ、時刻は考慮されません。たとえば、2026年11月17日の21:00にユーザーが選択した日付は `17.11.2026` と等しくなります。日付と数値を比較することはできません。

## 値のない数式 \{#formulas-without-a-value\}

数式は、デバイス上でいずれかの値が利用できない場合に値を持ちません：

- 回答が空、または数値でない。
- プロダクトの価格が読み込まれていない、またはストアが数式で読み取るプロダクトを返さなかった。iOS と Android の両方で数式に値を設定するには、App Store Connect と Google Play Console でプロダクトを設定してください。
- プロダクトがサブスクリプションではないのに、数式が[期間ごとの価格](#per-period-prices)を読み取ろうとしている。
- 選択されたプロダクトにオファーがないのに、数式が `offer_price` を読み取るか、`addOfferDuration` を呼び出している。
- 数式がゼロ除算を行っている（`{{a}} / 0` や `mod({{a}}, 0)` など）。
- 数式が読み取る日付変数に値がない。

値のない数式を読み取る数式も、値を持ちません。値がない場合、数式は次のように動作します：

- **テキスト要素**：数式には何も表示されません。
- **条件**：**Is empty** は true になります。**Equals**、**Does not equal**、およびその数式のすべての比較は false になります。

フォーミュラは、読み取る値が変化したタイミングで結果を更新します。ユーザーが回答を入力したとき、**Set variable** アクションで変数が変更されたとき、またはプロダクト価格が読み込まれたときです。ユーザーが戻って回答を消去した場合、次の画面ではフォーミュラに値がなくなります。フローがカスタム変数を変更するまで、フォーミュラはその変数の初期値（Initial value）を読み取ります。

## ビルダーで数式をプレビューする \{#preview-a-formula-in-the-builder\}

ビルダーは、カスタム変数の初期値と Adapty カタログのプロダクトの USD 価格をもとに、数式の結果を計算します。**Expression** フィールドの下にある **Preview** は、数式が次のいずれかを参照している場合に **No value** と表示されます。

- ユーザーが入力または選択した回答
- `offer_price`
- `addOfferDuration` のオファー
- 値のない変数（初期値が設定されていない日付変数など）
- Adapty カタログ内のプロダクトのうち、USD 価格が設定されていないか USD 価格が 0 のもの
- サブスクリプション以外のプロダクト（永続アクセスプロダクトなど）の期間あたり価格

このような場合、キャンバス上のテキスト要素には `{{trial_end}}` のように変数名が中括弧で表示されます。回答の値を確認するには、[Adapty モバイルアプリでフローをプレビュー](paywall-device-compatibility-preview)してください。オファーの値には、実際のプロダクトを使用したアプリのビルドが必要です。

キャンバス上では、最上位レベルに `round` が設定された日付や数値は、プレビュー用に選択した言語で表示されます。

## 例 \{#examples\}

### 回答の合計を表示する \{#show-a-sum-of-answers\}

画面に3つの数値入力を追加し、エレメントIDをそれぞれ `a1`、`a2`、`a3` に設定します。次のような数式 `sum` を作成します。

```
{{a1.value}} + {{a2.value}} + {{a3.value}}
```

次の画面のテキスト要素に `sum` を挿入します。ユーザーが2、3、4を入力すると「9」と表示されます。4を5に変更して戻ると「10」と表示されます。

### BMI と「High」ラベルを表示する \{#show-a-bmi-and-a-high-label\}

体重（キログラム）用の Element ID `weight` と、身長（センチメートル）用の Element ID `height` を持つ Number 入力を追加します。次のフォーミュラ `bmi` を作成します：

```
round({{weight.value}} * 10000 / ({{height.value}} * {{height.value}}), 1)
```

`bmi` をテキスト要素に挿入します。BMI が 23.12 の場合、デバイスの言語が英語なら「23.1」、ロシア語なら「23,1」と表示されます。BMI が 25 を超えた場合のみ「High」というラベルを表示するには、「High」というテキスト要素を追加し、[条件付き表示](onboarding-element-visibility)ルールを設定します：`bmi` **Greater than** `25`。

### 割引価格を表示する \{#show-a-discounted-price\}

選択されたプロダクトの価格から20%割引するフォーミュラ `discounted` を作成します：

```
{{products.selectedProduct.prod_price}} * 0.8
```

次に、小数点以下2桁に丸めるフォーミュラ `shown` を作成します：

```
round({{discounted}}, 2)
```

`shown` をテキスト要素に挿入します。価格が9.99のプロダクトを選択すると「7.99」と表示され、価格が100のプロダクトを選択すると「80.00」と表示されます。数値に通貨記号はつきません。選択されたプロダクトの価格が読み込まれなかった場合、テキストは空になります。

### 年間プランの割引額を表示する \{#show-the-savings-of-the-annual-plan\}

年間プランが週次プランの52週分と比べてどれだけお得かを表示するには、両プロダクトの価格を読み取る数式 `saving` を作成します。週次プロダクトはフローのどの画面にも表示する必要はありません。この例では、年間プロダクトの価格が120、週次プロダクトの価格が5です。

1. **Expression** フィールドで、<Inline id="variables.svg" alt="Insert variable" /> **Insert variable** をクリックします。**Products** タブで週次プロダクトをポイントし、`prod_price` を選択します。
2. `* 52 -` と入力します。
3. 同じ手順で年次プロダクトの `prod_price` を挿入します。

**Expression** フィールドには **Weekly · prod_price** `* 52 -` **Annual · prod_price** と表示され、**Preview** には 140 と表示されます。ビルダーは Adapty プロダクト ID を使用して式を保存します。

```
{{<weekly product ID>.prod_price}} * 52 - {{<annual product ID>.prod_price}}
```

節約額をパーセンテージで表示するには、フォーミュラ `saving_percent` を作成します。**Products** タブから2つの価格を、`saving` と同じ方法で挿入します。ビルダーは次の式として保存します：

```
round((1 - {{<annual product ID>.prod_price}} / ({{<weekly product ID>.prod_price}} * 52)) * 100)
```

これらの価格では、`saving_percent` は 54 になります。ペイウォール画面のテキスト要素に `saving` または `saving_percent` を挿入します。ビルダーは週次プロダクトを画面のプロダクトリストの末尾に追加します。デバイス上では、計算式がユーザーの通貨でストアの価格を使用します。画面の購入ボタンは年間プロダクトの購入を開始します。

### トライアル終了日とリマインダー日付の表示 \{#show-the-end-of-a-trial-and-a-reminder-date\}

`trial_end` という数式を作成します：

```
addOfferDuration(today(), {{products.selectedProduct}})
```

次に、トライアル終了の3日前を示す `reminder` という数式を作成します：

```
addDays({{trial_end}}, -3)
```

7日間の無料トライアルが付いたプロダクトの場合、2026年11月10日時点では、`trial_end` は2026年11月17日、`reminder` は2026年11月14日になります。日付フォーマットに **Medium** を選択すると "Nov 17, 2026" と表示され、**Month D** を選択すると "November 17" と表示されます。

### トライアルの長さを表示する \{#show-the-length-of-a-trial\}

[トライアルの終了日とリマインダー日の表示](#show-the-end-of-a-trial-and-a-reminder-date)の `trial_end` の数式を使用し、`trial_days` という数式を作成します：

```
daysBetween(today(), {{trial_end}})
```

テキスト要素に「Free for」と入力し、`trial_days` を挿入して、「days」と入力します。7日間の無料トライアルがあるプロダクトでは、「Free for 7 days」と表示されます。選択中のプロダクトにオファーがない場合、`trial_end` には値がありません。オファーのあるプロダクトにのみテキストを表示するには、テキスト要素に[条件付き表示](onboarding-element-visibility)ルールを設定してください：`trial_end` **Is not empty**。

### ユーザーの年齢を表示する \{#show-the-age-of-a-user\}

Element ID を `birth_date` とした Date 入力を追加し、以下の式で `age` というフォーミュラを作成します：

```
yearsBetween({{birth_date.value}}, today())
```

2000年11月25日生まれのユーザーの場合、`age` は2026年11月24日時点で25、2026年11月25日以降は26になります。入力が空の間、`age` は値を持ちません。

### 身長をフィートとインチで表示する \{#show-a-height-in-feet-and-inches\}

エレメント ID `height` を持つ数値入力フィールドを追加し、身長をセンチメートルで入力できるようにします。次の3つの数式を作成します：

- `total`: `round({{height.value}} / 2.54)`（インチ単位の身長を整数に丸めたもの）
- `feet`: `floor({{total}} / 12)`
- `inches`: `mod({{total}}, 12)`

テキスト要素に `feet` を挿入し、「ft」と入力してから `inches` を挿入し、「in」と入力します。180 cm の場合は「5 ft 11 in」と表示されます。140 cm の場合は「4 ft 7 in」と表示されます。

## トラブルシューティング \{#troubleshooting\}

**Expression** フィールドからフォーカスを外すと、フィールドの下にその計算式の最初のエラーが表示されます。以下はその例です。

| エラーテキスト | 原因と修正方法 |
| :--- | :--- |
| `addDays() needs a date and a number` | 関数の引数の数が間違っているか、引数の型が正しくありません。[数値関数](#number-functions)または[日付関数](#date-functions)の表に記載されている引数を使用してください。 |
| `Unknown function "flor". Use one of: …` | 関数名のスペルが間違っているか、大文字・小文字が異なります。エラーに表示されたリストの関数を使用してください。変数を読み取るには、その名前を `{{ }}` で囲んでください。 |
| `Use a dot in a decimal number, like 1.5` | 関数の外にある数値にカンマが使われています。カンマを小数点に置き換えてください。関数の内部では、カンマは引数の区切り文字として認識されるため、そこでも小数点を使用してください。 |
| `{{…}} is not a variable, an answer or a product field of this flow` | この名前に一致する変数、要素ID、またはプロダクトグループが存在しません。名前を修正するか、変数を作成してください。 |
| `{{…}}: the product … is not in the product catalog of the app` | Adapty カタログからプロダクトが削除されています。チップに **Missing product** と表示されます。別のプロダクトの価格に置き換えてください。 |
| `Offers, billing plans and fields other than prod_price, … of a catalog product are not supported yet` | 数式が Adapty カタログのプロダクトのオファー、請求プラン、またはその他のフィールドを参照しています。**Insert variable** の **Products** タブから価格を挿入してください。 |
| `This variable no longer exists. Pick another one.` | 数式が参照している変数が削除されています。**Expression** フィールドに **deleted variable** チップとして表示されます。別の参照に置き換えてください。 |
| `{{…}} is the name of a variable and of an element answer: rename the variable` | 名前が2つの値に一致しています。カスタム変数の名前を変更してください。 |
| `{{…}} uses this formula: formulas cannot use each other in a loop` | 数式間の参照が循環しています。たとえば、数式Aが数式Bを参照し、数式Bが数式Aを参照している状態です。どちらか一方の参照を削除してください。 |

<ZoomImage id="flow-formula-error.webp" width="300px" alt="Expressionフィールドの下に表示されるUnknown functionエラーと、利用可能な関数の一覧" />

エラーのある数式があると、公開がブロックされます。**Can't publish yet** ダイアログの **Variables** の下に、エラーのある数式が一覧表示されます。公開時に表示されるエラーの詳細については、[よくある問題](flow-common-issues#a-flow-wont-preview-or-publish)を参照してください。

## 制限事項 \{#limitations\}

- **数値と日付のみ**: 数式は数値または日付のみを返します。結果に応じたテキストを表示するには、テキスト要素に[条件付きテキスト](onboarding-text#add-conditional-text)を追加してください。たとえば、BMIが25を超える場合に「High」と表示するには、**if** 条件を `bmi` **より大きい** `25` に設定し、**then** に「High」と入力します。
- **カタログのプロダクト**: 数式は、オファーや料金プランなしで、Adaptyカタログ内のプロダクトの価格と期間ごとの価格のみを読み取ります。オファー価格を使用するには、プロダクトグループ内の選択したプロダクトの `offer_price` を読み取ってください。
- **選択中のプロダクト**: 選択中のプロダクトを読み取る数式は、ユーザーがプロダクトを選択するまで値を持ちません。画面が開いたときに結果を表示するには、いずれかのプロダクトカードで **Set as default** を選択してください。
- **iOS と Android のオファー**: iOS では、Adapty SDK はフローに1つのオファーを渡します。ユーザーが利用可能なオファーのうち、ウィンバックオファーが最優先され、次にプロモーションオファー、そして初回オファーの順になります。Android では、Adapty SDK は初回オファーの最初のフェーズのみを渡します。無料トライアルの後に割引価格が続く場合、Android の `addOfferDuration` はトライアル分のみを加算します。
