ようこそ！アプリ内課金をもっと簡単に 🚀

Adapty Flutter SDK を使えば、アプリ内課金の面倒な実装から解放され、素晴らしいアプリ作りに集中できます。Adapty が代わりに行うことは次のとおりです：

- 購入処理、レシート検証、サブスクリプション管理をすぐに利用可能
- アプリのアップデートなしでフローとペイウォールを作成・テスト可能
- コホート、LTV、チャーン、ファネル分析を含む詳細な購入分析をゼロ設定で提供
- アプリセッションやデバイスをまたいで常に最新のユーザーサブスクリプション状態を維持
- 1行のコードでマーケティングアトリビューションおよび分析サービスとの連携が可能

:::note
コードに入る前に、AdaptyをApp Store ConnectおよびGoogle Play Consoleと連携し、ダッシュボードでプロダクトを設定する必要があります。まずは[クイックスタートガイド](quickstart)を参照して、すべての設定を完了させてください。
:::

## はじめに \{#get-started\}

<SkillPromo />

このインテグレーションガイドで説明する内容は以下のとおりです。

1. [SDKのインストールと設定](sdk-installation-flutter): SDKをプロジェクトの依存関係に追加し、コード内で有効化します。
2. [フローとペイウォールで購入を有効化](flutter-quickstart-paywalls): ユーザーがプロダクトを購入できるよう購入フローを設定します。独自のUIを構築する場合は、[カスタムペイウォールの実装](flutter-quickstart-manual)を参照してください。
3. [サブスクリプションの状態を確認](flutter-check-subscription-status): ユーザーのサブスクリプション状態を自動的に確認し、有料コンテンツへのアクセスを制御します。
4. [ユーザーを識別する（任意）](flutter-quickstart-identify): ユーザーをAdaptyのプロファイルに紐付け、デバイス間でデータを一貫して保存できるようにします。

## 主要コンセプト \{#main-concepts\}

コードを書く前に、Adapty の仕組みを支える主要なコンセプトを確認しておきましょう。

Adapty のアプローチの優れた点は、アプリにハードコードするのはプレースメントだけという点です。それ以外のすべて（プロダクト、ペイウォールのデザイン、価格、オファー）は、アプリのアップデートなしに Adapty ダッシュボードから柔軟に管理できます。

1. [**プロダクト**](product) - アプリ内で購入できるもの全般。サブスクリプション、消耗型アイテム、永続アクセスなどが含まれます。

2. **フローとペイウォール** - プロダクトに設定を組み合わせ、プレースメントに紐付けます。構築方法は2種類あります。詳しくは[フローとペイウォール](flows-and-paywalls)で比較しています：
   - **[フロー＆ペイウォールビルダー](adapty-flow-builder)** - ビジュアルなノーコードインターフェース。Adapty が UI をレンダリングし、購入処理も自動で行います。
   - **[カスタムペイウォール](paywalls)** - ビジュアル設定なし。自分のコードで UI を構築し、`makePurchase` を直接呼び出します。[カスタムペイウォールの実装](flutter-quickstart-manual)を参照してください。

   SDK コードでは、どちらも同じ `getFlow` メソッドで取得できます。

3. [**プレースメント**](placements) - フローまたはペイウォールを表示するユーザージャーニー上の戦略的なポイントです。プレースメントはマネタイズ戦略の「どこで」「いつ」を決めるものです。代表的なプレースメントには次のものがあります：
   - `main` - 主要なペイウォールの表示場所
   - `onboarding` - ユーザーのオンボーディングフロー中に表示
   - `settings` - アプリの設定画面からアクセス可能

   最初の連携では `main` や `onboarding` などの基本的なプレースメントから始め、その後は[アプリ内でユーザーが購入意欲を持ちやすい場所を考えてみましょう](choose-meaningful-placements)。

4. [**プロファイル**](profiles-crm) - ユーザーがプロダクトを購入すると、そのプロファイルに**アクセスレベル**が付与され、有料機能へのアクセスを管理するために使用します。
