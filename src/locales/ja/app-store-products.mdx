このページでは、App Store Connect でプロダクトを作成する方法を説明します。Adapty の機能に直接関係しない情報も含まれますが、App Store Connect アカウントでプロダクトを作成する際に問題が発生した場合の参考資料として役立ちます。

Adapty に連携するプロダクトを作成するには：

1. **App Store Connect** を開きます。左側のメニューから [**Monetization** → **Subscriptions**](https://appstoreconnect.apple.com/apps/6477523342/distribution/subscriptions) セクションに進みます。

2. サブスクリプショングループをまだ作成していない場合は、**Subscription Groups** タイトルの下にある **Create** ボタンをクリックしてプロセスを開始します。App Store Connect の [Subscription Groups](https://developer.apple.com/help/app-store-connect/manage-subscriptions/offer-auto-renewable-subscriptions) は、プロダクトを分類・管理し、ユーザーが異なるオファー間をスムーズに切り替えられるようにします。グループの外にサブスクリプションを作成することはできません。

3. 表示された **Create Subscription Group** ウィンドウで、**Reference Name** フィールドに新しいサブスクリプショングループ名を入力します。リファレンス名は、アプリ内のさまざまなサブスクリプショングループを区別・管理するために使用する、ユーザー定義のラベルまたは識別子です。

   リファレンス名はユーザーには表示されません。主に内部での管理や整理を目的としています。App Store Connect のインターフェース上でサブスクリプショングループを識別・参照する際に役立ちます。複数のサブスクリプションを提供している場合や、アプリの構造に合わせてカテゴリ分けしたい場合に特に便利です。

    width: '700px', /* image width */

4. **Create** ボタンをクリックして、サブスクリプショングループの作成を確定します。

5. サブスクリプショングループが作成されて開きます。これでグループ内にサブスクリプションを作成できます。**Subscriptions** タイトルの下にある **Create** ボタンをクリックしてください。既存のグループに新しいサブスクリプションを追加する場合は、**Subscriptions** タイトルの横にある **Plus** ボタンをクリックします。

  <img src="/assets/shared/img/22fc643-add_subscription.webp"
  style={{

    width: '700px', /* image width */
    display: 'block', /* for alignment */
    margin: '0 auto' /* center alignment */
  }}
/>

6. 表示された **Create Subscription** ウィンドウで、**Reference Name** フィールドに名前を、**Product ID** フィールドにサブスクリプションの固有コードを入力します。

   Reference Name は、App Store Connect 内でアプリ内サブスクリプションを識別するための固有の識別子です。App Store 上でユーザーに表示されることはありません。作成するサブスクリプションの内容が一目でわかる、わかりやすい名前を使用することをお勧めします。なお、この名前は64文字以内にする必要があります。

   プロダクト ID は、開発フェーズ中にプロダクトにアクセスし、アプリ内サブスクリプションを管理するサービスである Adapty と同期するために不可欠な、一意の英数字識別子です。プロダクト ID に使用できる文字は、英数字、ピリオド、アンダースコアのみです。

7. **Create** ボタンをクリックして、サブスクリプションの作成を確定します。

8. サブスクリプションが作成され、開きます。次に、**Subscription Duration** リストでサブスクリプションの期間を選択します。サブスクリプション名にすでに期間が記載されている場合でも、**Subscription Duration** フィールドへの入力を忘れずに行ってください。[12か月コミットメントプラン](set-up-12-month-commitment#1-app-store-connect-configuration)を追加するには、**1 Year** を選択して分割払いを設定します。

9. 次に、サブスクリプションの価格を設定します。Subscription Prices の下にある **Add Subscription Price** ボタンをクリックしてください。スクロールダウンして見つける必要がある場合があります。

10. 表示された **Subscription Price** ウィンドウで、**Country or Region** リストから基本国を選択し、**Price** リストから基本通貨を選択します。その後、Apple がこの基本価格と最新の為替レートをもとに、175 の国または地域すべての価格を自動的に計算します。

    margin: '0 auto' /* center alignment */

/>

11. **Next** ボタンをクリックします。開いた **Price by Country or Region** ウィンドウには、すべての国の価格が自動再計算された状態で表示されます。必要に応じて変更できます。

<Zoom>

12. 地域別の価格を更新したら、ウィンドウ下部の **Next** ボタンをクリックして次へ進みます。

13. 表示された **Confirm Subscription Price?** ウィンドウで、最終的な価格を注意深く確認してください。価格を修正したい場合は、**Back** ボタンをクリックして **Price by Country or Region** ウィンドウに戻り、更新できます。価格に問題がなければ、**Confirm** ボタンをクリックしてください。

<Zoom>
  <img src="/assets/shared/img/d2b2031-confirm_prices.webp"
  style={{
    border: '1px solid #727272', /* border width and color */
    width: '700px', /* image width */
    display: 'block', /* for alignment */
    margin: '0 auto' /* center alignment */
  }}
/>
</Zoom>

14. **Confirm Subscription Price?** ウィンドウを閉じた後、サブスクリプションウィンドウの **Save** ボタンをクリックすることを忘れないでください。これを行わないと、サブスクリプションは作成されず、入力したデータはすべて失われます。

なお、ここまでの手順は自動更新サブスクリプションの設定に関するものです。他の種類のアプリ内課金を設定する場合は、「Subscriptions」ではなくサイドバーの **In-App Purchases** タブをクリックしてください。そこから、さまざまな種類のアプリ内課金を管理・作成するセクションに移動できます。
