リテンションメッセージを使うと、解約プロセス中に離脱しようとしているサブスクライバーにアプローチできます。ユーザーがiOSのサブスクリプションキャンセル画面に到達すると、Appleがそのユーザーのプロダクトとロケールに合ったメッセージを表示します。

リテンションメッセージには2種類あります：

- **Default**：ヘッドライン、本文、任意の画像、最大5つの箇条書きを含むシンプルなリテンションメッセージです。プロモメッセージが利用できない場合のフォールバックとして使用されます。
- **Promo**：サブスクライバーに特別なディールや別のプランを提供するリテンションメッセージです。Promoメッセージは、すでにDefaultメッセージが割り当てられているプロダクトに対してのみ作成できます。

## 始める前に \{#before-you-begin\}

- メッセージに含める[プロダクト](create-product)を少なくとも1つ作成してください。
- サンドボックスモードで[リテンションメッセージング](retention-messaging-setup)をテストしてください。

## メッセージを作成する \{#create-a-message\}

Adapty ダッシュボードのRetention Messagingページを開きます。デフォルトメッセージの場合は **Create Default** を、プロモーションメッセージの場合は **Create Message** をクリックします。

<ZoomImage id="retention-select-default-or-promo.webp" width="700px" alt="The Create Default and Create Message buttons in the Retention Messaging page header" />

環境を選択します — テスト用のサンドボックスメッセージか、実際のユーザー向けの本番メッセージかを選びます。本番オプションは、[本番URLの設定](retention-messaging-setup#switch-to-production)が完了し、サンドボックスのパフォーマンステストに合格するまでは無効のままです。

<ZoomImage id="retention-new-message.webp" width="700px" alt="「サンドボックスメッセージを作成」と「プロダクションメッセージを作成」オプションが表示された新規メッセージの開始画面" />

### 全般 \{#general\}

メッセージに名前を付け、キャンセル時にメッセージをトリガーするプロダクトを追加します。

プロダクトリストでは、追加できないプロダクトがグレーアウト表示され、その理由が横に表示されます。**used** は同じタイプの別のメッセージがすでにそのプロダクトをカバーしていることを意味し、**no default message** はそのプロダクトにプロモーションメッセージを設定する前にデフォルトメッセージが必要なことを意味します。

サンドボックスと本番環境はメッセージを別々に管理するため、サンドボックスのデフォルトメッセージは本番環境のプロダクトには適用されません。本番環境のプロモーションメッセージを作成する前に、同じプロダクトに対して本番環境のデフォルトメッセージを作成してください。Apple の審査を待つ必要はありません。デフォルトメッセージを送信すれば、すぐにそのプロダクトをプロモーションメッセージに追加できます。

<ZoomImage id="retention-message-step-1-general.webp" width="700px" alt="Default message General step with the Name field and Products section" />

**promo** メッセージの場合、追加した各プロダクトにインセンティブを紐付ける必要があります。1つのプロダクトに対して1つのインセンティブを設定し、すべてのプロダクトにインセンティブが設定されるまで **Next** は無効のままです：

- **Link Promo Offer**：[事前に設定したプロモーションオファー](app-store-offers)です。リストにはプロモーションオファーのみが表示されるため、ウィンバックオファーや初回オファーは表示されません。リストが空の場合は、[App Store Connect でプロモーションオファーを作成](app-store-offers#promotional-offers)し、[Adapty でプロダクトに追加](create-offer)してください。

    <ZoomImage id="retention-messaging-promo.webp" width="500px" alt="Promo message General step with the Associated offers list open for a product" />

- **Link Plan Switch**: 追加するプロダクトのサブスクリプショングループに属する別のプロダクトです。プランリストが空の場合は、グループの他のプロダクトをAdaptyに追加し、グループのすべてのプロダクトが[App Storeのステータスを表示している](troubleshoot-app-store-integration#products-dont-appear-or-show-no-app-store-status)ことを確認してください。

    <ZoomImage id="retention-messaging-switch-plan.webp" width="500px" alt="プロダクトの関連プランリストが開いた状態のプロモメッセージ全般ステップ" />

### コンテンツ \{#content\}

メッセージは英語で記述してください。右側のプレビューで、入力しながらキャンセルサブスクリプション画面でのメッセージの見え方を確認できます。

**Default** メッセージには画像を含めることができます。スクリーンリーダー向けに画像を説明する **Alt text** を追加してください。Alt text はローカライズされません。Apple はすべてのロケールで英語の Alt text を受け取ります。

デフォルトでは、タイトルと本文は画像の下に表示されます。タイトルを画像の上に表示するには、**Title position** で **Above the image** を選択してください。本文は常に画像の下に表示されます。

<ZoomImage id="retention-message-step-2-content.webp" width="700px" alt="アップロードされた画像、タイトル位置が「画像の上」に設定されたコンテンツステップ、および画像の上にタイトルが表示されているスマートフォンのプレビュー" />

:::important
タイトルの位置はメッセージ作成時に選択してください。後から変更することはできません。別の位置を使用するには、新しいメッセージを作成してください。画像なしでメッセージを作成し、後から画像を追加した場合、タイトルは画像の下に配置されます。
:::

**Default** メッセージでは、ボディの下に最大5つの箇条書きを、画像あり・なしを問わず追加できます。追加するには、**Bullet points** の下にある **+ Add Bullet Point** をクリックして、各フィールドを入力してください。

- **Icon**: すべての箇条書きに必須です。正確に 1024 × 1024 px の PNG をアップロードしてください。透過なし。Apple は各アイコンを個別に審査します。
- **Text**: 最大66文字。
- **Alt text**: スクリーンリーダー向けのアイコンの説明文です。空のままにすると、Adapty がデフォルトの説明文を Apple に送信します。画像の代替テキストと同様に、ローカライズされません。

<ZoomImage id="retention-message-bullet-points.webp" width="600px" alt="メッセージ本文の下にアイコン付きの3つの箇条書きが表示された、入力済みの「Bullet point 1」カードと電話プレビューが表示されたコンテンツステップ" />

プロモーションメッセージには箇条書きを追加できません。

### ローカライズ \{#localization\}

英語がソース言語です。サブスクライバーが使用する他の言語を追加し、コンテンツを翻訳します。

1. **Add Locale** をクリックして、サポートするロケールを選択します。
2. **AI Translate All Cells** をクリックして、[コンテンツ](#content)を自動翻訳します。翻訳は、追加したすべてのロケールのタイトル、本文、箇条書きテキストを置き換えます（手動での編集内容も含む）。そのため、まず翻訳してから編集してください。
3. 任意のセルをクリックして翻訳を編集します。

ロケールごとに、英語ソースと同じ文字数制限を守る必要があります：タイトルは66文字、本文は144文字、各箇条書きは66文字です。制限を超えると**Submit To Review**がブロックされます。テキストがある他のロケールで箇条書きが空欄のままになっていても送信がブロックされます。アイコンはすべてのロケールで共通です：翻訳が必要なのは箇条書きのテキストのみです。

ロケールにカーソルを合わせると、キャンセルサブスクリプション画面のプレビューを確認できます。

対象ロケールの翻訳がAppleにまだ承認されていない場合、Adaptyは`en-US`バージョンにフォールバックします。

<ZoomImage id="retention-message-step-3-localization.webp" width="700px" alt="ロケールテーブルと「AI Translate All Cells」ボタンが表示されたローカライゼーションステップ" />

## レビュー申請 \{#submit-for-review\}

メッセージの準備ができたら、**Submit To Review** をクリックします。Adapty は、テキストが入力されているすべてのロケールについて、メッセージとその箇条書きアイコンを Apple にアップロードし、Apple によるレビューが開始されます。セルがすべて空のロケールは Adapty が除外します。申請の[ステータス](#message-states)は Retention Messaging ページで確認できます。

メッセージは申請時にのみ保存されます。

## メッセージの状態 \{#message-states\}

メッセージを送信すると、Apple は各ロケールを個別に審査します。メッセージが公開されるのは、英語を含むすべてのロケールが Apple に承認された後です。Default メッセージの場合は、追加したすべてのプロダクトに対してデフォルトメッセージとして承認される必要もあります。それまでの間、一部のロケールがすでに **Live** になっていても、メッセージは **In review** のままです。Apple がまだ承認していないロケールについては、Adapty は [`en-US` にフォールバック](#localization)します。Retention Messaging ページの **State** 列で、メッセージの進捗状況を確認できます。

| 状態 | 意味 |
| --- | --- |
| **In review** | Appleがメッセージをまだ受信していないか、すべてのロケールが承認されていないか、すべてのプロダクトに対してデフォルトメッセージが受理されていません。 |
| **Live** | Appleがメッセージを承認し、Adaptyがキャンセルしようとしているサブスクライバーに表示しています。 |
| **Rejected** | 少なくとも1つのロケールでAppleに却下されました。代替バージョンを提出してみてください。 |
| **Inactive** | メッセージを[無効化](#deactivate-and-reactivate)しました。同じプロダクトに対して新しいメッセージを作成できます。 |

Appleがまだ承認していないロケールを確認するには、メッセージを開いて **Localization** ステップに移動してください。追加した各ロケールには、**Live**、**In review**、または **Rejected** の独自のステータスが表示されます。英語の行にはステータスが表示されませんが、Appleによる承認が必要です。追加したすべてのロケールが **Live** になっているにもかかわらずメッセージが **In review** のままの場合は、メッセージ名を添えてサポートにお問い合わせください。

**ライブ**中のメッセージも含め、任意のメッセージをいつでも編集できます。**Live**のメッセージを編集したり、新しいロケールを追加したりすると、そのメッセージは即座にライブステータスを失い、**In review**の状態に戻ります。

既存のメッセージの英語のタイトルまたは本文を変更すると、**Content**ステップのボタンが**Update Locales**に変わります。これをクリックして**Localization**ステップを開き、翻訳を更新してから**Submit To Review**をクリックしてください。

## 無効化と再有効化 \{#deactivate-and-reactivate\}

Adapty から削除せずに Apple からメッセージを削除するには、メッセージの行にあるメニューを開き、**Deactivate** をクリックします。

元に戻すには、**Activate** をクリックします。再有効化では Apple のレビューはスキップされ、メッセージがすべてのサブスクライバーに届くまで数分かかる場合があります。

1つのプロダクトに設定できるデフォルトメッセージとプロモーションメッセージはそれぞれ1件までです。このメッセージが無効化されている間に同じタイプの別のメッセージがそのプロダクトを使用した場合、有効化は失敗します。
