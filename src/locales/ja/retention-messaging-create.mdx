リテンションメッセージを使うと、解約プロセス中に離脱しようとしているサブスクライバーにアプローチできます。ユーザーがiOSのサブスクリプションキャンセル画面に到達すると、Appleがそのユーザーのプロダクトとロケールに合ったメッセージを表示します。

リテンションメッセージには2種類あります：

- **Default**：ヘッドライン、本文、オプションの画像で構成されるシンプルなウィンバックメッセージです。プロモメッセージが利用できない場合のフォールバックとして使用されます。
- **Promo**：特別な特典や別のプランをサブスクライバーに提示するウィンバックメッセージです。Promoメッセージは、すでにDefaultメッセージが割り当てられているプロダクトに対してのみ作成できます。

## 始める前に \{#before-you-begin\}

- メッセージに含める[プロダクト](create-product)を少なくとも1つ作成してください。
- サンドボックスモードで[リテンションメッセージング](retention-messaging-setup)をテストしてください。

## メッセージを作成する \{#create-a-message\}

Adapty ダッシュボードのRetention Messagingページを開きます。デフォルトメッセージの場合は **Create Default** を、プロモーションメッセージの場合は **Create Message** をクリックします。

<ZoomImage id="retention-select-default-or-promo.webp" width="700px" alt="The Create Default and Create Message buttons in the Retention Messaging page header" />

環境を選択します — テスト用のサンドボックスメッセージか、実際のユーザー向けの本番メッセージかを選びます。本番オプションは、[本番URLの設定](retention-messaging-setup#switch-to-production)が完了し、サンドボックスのパフォーマンステストに合格するまでは無効のままです。

<ZoomImage id="retention-new-message.webp" width="700px" alt="「サンドボックスメッセージを作成」と「プロダクションメッセージを作成」オプションが表示された新規メッセージの開始画面" />

### 全般 \{#general\}

メッセージに名前を付け、キャンセル時にメッセージをトリガーするプロダクトを追加します。

プロダクトリストでは、追加できないプロダクトがグレーアウトされ、その理由が横に表示されます。**used** は同じタイプの別のメッセージがそのプロダクトをすでにカバーしていることを意味し、**no default message** はそのプロダクトにプロモーションメッセージを設定する前にデフォルトメッセージが必要なことを意味します。

<ZoomImage id="retention-message-step-1-general.webp" width="700px" alt="Default message General step with the Name field and Products section" />

**プロモ**メッセージの場合、追加するすべてのプロダクトにインセンティブを紐付けてください。1つのプロダクトに1つのインセンティブが対応し、すべてのプロダクトにインセンティブが設定されるまで**Next**は無効のままです。

- **Link Promo Offer**：[プロダクトに対して事前に設定した](app-store-offers)プロモーションオファーです。

    <ZoomImage id="retention-messaging-promo.webp" width="500px" alt="Promo message General step with the Associated offers list open for a product" />

- **Link Plan Switch**: カタログ内の別のプロダクト。プランのリストが空の場合は、[App Store Connect APIキー](app-store-connection-configuration)を追加済みかどうか確認してください。Adaptyがプランを検索するために必要です。

    <ZoomImage id="retention-messaging-switch-plan.webp" width="500px" alt="プロダクトの関連プランリストが開いた状態のPromoメッセージの全般ステップ" />

### コンテンツ \{#content\}

メッセージは英語で記述してください。右側のプレビューで、入力しながらキャンセルサブスクリプション画面でのメッセージの見え方を確認できます。

**Default** メッセージには画像を含めることができます。スクリーンリーダー向けに画像を説明する **Alt text** を追加してください。Alt text はローカライズされません。Apple はすべてのロケールで英語の Alt text を受け取ります。

デフォルトでは、タイトルと本文は画像の下に表示されます。タイトルを画像の上に表示するには、**Title position** で **Above the image** を選択してください。本文は常に画像の下に表示されます。

<ZoomImage id="retention-message-step-2-content.webp" width="700px" alt="アップロードされた画像、タイトル位置が「画像の上」に設定されたコンテンツステップ、および画像の上にタイトルが表示されているスマートフォンのプレビュー" />

:::important
タイトルの位置はメッセージ作成時に選択してください。後から変更することはできません。別の位置を使用するには、新しいメッセージを作成してください。画像なしでメッセージを作成し、後から画像を追加した場合、タイトルは画像の下に配置されます。
:::

### ローカライゼーション \{#localization\}

英語がソース言語です。サブスクライバーが使用するその他の言語を追加し、コンテンツを翻訳してください。

1. **Add Locale** をクリックして、サポートするロケールを選択します。
2. **AI Translate All Cells** をクリックして、[コンテンツ](#content)を自動翻訳します。翻訳はすべての追加済みロケールのタイトルと本文を上書きします（手動編集も含む）。そのため、まず翻訳してから編集してください。
3. 任意のセルをクリックして翻訳を編集します。

すべてのロケールは、英語ソースと同じ文字数制限に収める必要があります。タイトルは66文字、本文は144文字までです。制限を超えると、**Submit To Review** がブロックされます。

ロケールにカーソルを合わせると、「サブスクリプションのキャンセル」画面でプレビューを確認できます。

対象ロケールの翻訳がまだ Apple に承認されていない場合、Adapty は `en-US` バージョンにフォールバックします。

<ZoomImage id="retention-message-step-3-localization.webp" width="700px" alt="ロケールテーブルと「AI Translate All Cells」ボタンが表示されたローカライズ手順" />

## レビューへの提出 \{#submit-for-review\}

メッセージの準備ができたら、**Submit To Review** をクリックします。Adapty はタイトルまたは本文が入力されているすべてのロケールで Apple にメッセージをアップロードし、Apple がレビューを開始します。両方のセルが空のロケールは Adapty が自動的に除外します。提出の[ステータス](#message-states)は Retention Messaging ページで確認できます。

メッセージは提出時にのみ保存されます。

## メッセージの状態 \{#message-states\}

メッセージを送信すると、Apple は各ロケールを個別に審査します。Apple が少なくとも1つのロケールを承認した時点でメッセージが公開されます。まだ承認されていないロケールについては、Adapty が [`en-US` にフォールバックします](#localization)。**Retention Messaging** ページの **State** 列でメッセージの進捗状況を確認できます。

| 状態 | 説明 |
| --- | --- |
| **In review** | Appleがメッセージをまだ受け取っていないか、いずれのロケールも承認されていない状態です。 |
| **Live** | Appleがメッセージを承認し、Adaptyはキャンセルしようとしているサブスクライバーにこれを表示します。 |
| **Rejected** | 少なくとも1つのロケールでAppleが申請を却下しました。代替バージョンを提出してみてください。 |
| **Inactive** | メッセージを[無効化](#deactivate-and-reactivate)した状態です。同じプロダクトに対して新しいメッセージを作成できます。 |

Appleがまだ承認していないロケールを確認するには、メッセージを開いて **Localization** ステップに進みます。追加された各ロケールには、**Live**、**In review**、または **Rejected** のステータスが個別に表示されます。

メッセージはいつでも編集できます。顧客に実際に配信中のメッセージも含まれます。**Live** 状態のメッセージを編集したり、新しいロケールを追加したりすると、そのメッセージはすぐに Live ステータスを失い、**In review** 状態に戻ります。

既存のメッセージの英語のタイトルまたは本文を変更すると、**Content** ステップのボタンが **Update Locales** に変わります。それをクリックして **Localization** ステップを開き、翻訳を更新してから **Submit To Review** をクリックしてください。

## 無効化と再有効化 \{#deactivate-and-reactivate\}

Adapty から削除せずに Apple からメッセージを削除するには、メッセージの行にあるメニューを開き、**Deactivate** をクリックします。

元に戻すには、**Activate** をクリックします。再有効化では Apple のレビューはスキップされ、メッセージがすべてのサブスクライバーに届くまで数分かかる場合があります。

1つのプロダクトに設定できるデフォルトメッセージとプロモーションメッセージはそれぞれ1件までです。このメッセージが無効化されている間に同じタイプの別のメッセージがそのプロダクトを使用した場合、有効化は失敗します。
