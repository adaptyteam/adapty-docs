リテンションメッセージを使うと、解約プロセス中に離脱しようとしているサブスクライバーにアプローチできます。ユーザーがiOSのサブスクリプションキャンセル画面に到達すると、Appleがそのユーザーのプロダクトとロケールに合ったメッセージを表示します。

リテンションメッセージには2種類あります：

- **Default**：ヘッドライン、本文、オプションの画像で構成されるシンプルなウィンバックメッセージです。プロモメッセージが利用できない場合のフォールバックとして使用されます。
- **Promo**：特別な特典や別のプランをサブスクライバーに提示するウィンバックメッセージです。Promoメッセージは、すでにDefaultメッセージが割り当てられているプロダクトに対してのみ作成できます。

## 始める前に \{#before-you-begin\}

- メッセージに含める[プロダクト](create-product)を少なくとも1つ作成してください。
- サンドボックスモードで[リテンションメッセージング](retention-messaging-setup)をテストしてください。

## メッセージを作成する \{#create-a-message\}

Adapty ダッシュボードの Retention Messaging ページを開きます。デフォルトメッセージを作成する場合は **Create Default** を、プロモーションメッセージを作成する場合は **Create Message** をクリックします。

<ZoomImage id="retention-select-default-or-promo.webp" width="700px" alt="The Create Default and Create Message buttons in the Retention Messaging page header" />

環境を選択します。テスト用にはサンドボックスメッセージ、実際のユーザー向けにはプロダクションメッセージを選びます。

<ZoomImage id="retention-new-message.webp" width="700px" alt="New message start screen with Create a sandbox message and Create a production message options" />

### 全般設定 \{#general\}

メッセージに名前を付け、キャンセル時にメッセージをトリガーするプロダクトを追加します。

<ZoomImage id="retention-message-step-1-general.webp" width="700px" alt="Default message General step with the Name field and Products section" />

**プロモ**メッセージの場合は、サブスクライバーに継続を促すインセンティブを設定します。

- **Promo offer**: プロダクトに対して[事前に設定したプロモーションオファー](app-store-offers)。

    <ZoomImage id="retention-messaging-promo.webp" width="500px" alt="Promo message General step with an associated offer selected for a product" />

- **プランの切り替え**: カタログ内の別のプロダクト。

    <ZoomImage id="retention-messaging-switch-plan.webp" width="500px" alt="プロダクトに関連するプランが選択されたプロモメッセージの一般ステップ" />

### コンテンツ \{#content\}

メッセージは英語で入力してください。入力内容は右側のプレビューにキャンセルサブスクリプション画面としてリアルタイムで表示されます。

**Default** メッセージには画像を含めることができます。

<ZoomImage id="retention-message-step-2-content.webp" width="700px" alt="タイトル、本文、画像フィールドと、キャンセルサブスクリプション画面の電話プレビューが表示されたコンテンツステップ" />

### ローカライゼーション \{#localization\}

英語がソース言語です。サブスクライバーが使用する他の言語を追加して、コンテンツを翻訳してください。

1. **Add Locale** をクリックして、サポートするロケールを選択します。
2. **AI Translate All Cells** をクリックして、[コンテンツ](#content)を自動翻訳します。
3. 任意のセルをクリックして翻訳を編集します。

ロケールにカーソルを合わせると、サブスクリプションキャンセル画面でのプレビューを確認できます。

対象ロケールの翻訳がAppleにまだ承認されていない場合、Adaptyは `en-US` バージョンにフォールバックします。

<ZoomImage id="retention-message-step-3-localization.webp" width="700px" alt="ロケールテーブルとAI「Translate All Cells」ボタンを表示したローカリゼーションステップ" />

## レビューに提出する \{#submit-for-review\}

メッセージの準備ができたら、**Submit To Review** をクリックします。Adapty は追加したすべてのロケールのメッセージを Apple にアップロードし、Apple によるレビューが開始されます。提出の[ステータス](#message-states)は「Retention Messaging」ページで確認できます。

## メッセージの状態 \{#message-states\}

メッセージを送信すると、Appleがすべてのロケールを個別に審査します。各ロケールは別々に審査されますが、*すべてのロケール*が承認されて初めてメッセージが公開されます。Retention Messagingページの**State**列でメッセージの進捗を確認できます。

| ステータス | 意味 |
| --- | --- |
| **Draft** | まだメッセージを送信していません。送信するまでAdaptyは保存しません。 |
| **In review** | Appleがまだメッセージを受信していないか、すべてのロケールのレビューが完了していません。 |
| **Live** | Appleがメッセージを承認し、Adaptyがキャンセルしようとしているサブスクライバーに表示しています。 |
| **Rejected** | 少なくとも1つのロケールでAppleが申請を却下しました。別のバージョンを送信してみてください。 |
| **Inactive** | メッセージを[無効化](#deactivate-and-reactivate)しました。同じプロダクトに対して新しいメッセージを作成できます。 |

**ライブ**中のメッセージは、顧客に配信されている最中であっても、いつでも編集できます。**ライブ**メッセージを編集したり、新しいロケールを追加したりすると、そのメッセージはライブ状態を即座に失い、**レビュー中**のステータスに戻ります。

## 無効化と再有効化 \{#deactivate-and-reactivate\}

メッセージをAdaptyから削除せずにAppleから取り下げるには、メッセージ行のメニューを開き、**Deactivate** をクリックします。

元に戻すには、**Activate** をクリックします。AdaptyがAppleに再アップロードする間、メッセージは **In review** の状態に戻ります。

1つのプロダクトに設定できるデフォルトメッセージとプロモメッセージはそれぞれ1件までです。このメッセージが無効化されている間に同じタイプの別のメッセージがそのプロダクトを取得していた場合、有効化に失敗します。
