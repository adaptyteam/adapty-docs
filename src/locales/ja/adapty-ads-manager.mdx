**Adapty Ads Manager**は、Apple Ads キャンペーンをより効率的に管理・最適化・スケールするために設計されたオールインワンプラットフォームです。MMPなしで、インストール数、トライアル、サブスクリプション、ライフタイムバリューなどの主要な収益指標とApple Search Adsのパフォーマンスを連携させます。

リアルタイム分析、AIによる予測、スマートな自動化機能により、煩雑な手動での入札調整やスプレッドシート管理、手探りの試行錯誤を排除し、明確なインサイトと迅速なアクションを可能にするツールへと置き換えます。

Adapty Ads Manager で得られるもの：

- **[概要](ads-manager-overview)**: 支出、収益、ROAS、CPA などの主要指標を一目で確認できます。各指標には日次トレンドチャートも付いています
- **[AIエージェント](ads-manager-ai-agent)**: 自然言語で質問するだけで、ファネル全体の回答とおすすめ施策が得られます
- **リアルタイムパフォーマンスデータ**: キャンペーン、広告グループ、キーワードごとに確認できます
- **エンドツーエンドの収益トラッキング**: 検索 → インストール → トライアル → サブスクリプション → LTV まで追跡します
- **AI予測と推奨**: 収益性の高いスケーリングに活用できます
- **一括管理**: 入札額、予算、ステータス、構造をまとめて操作できます
- **[ルールベースの自動化](ads-manager-automations)**: キーワードのライフサイクル全体を管理します
- **[マーケットインテリジェンス](ads-manager-market-intelligence)**: 50カ国以上の競合キーワード戦略を把握できます
- **[キーワードサジェスター](ads-manager-keyword-suggester)**: 任意のシードフレーズに関連する検索フレーズと、Appleカテゴリのコンテキストを提案します
- **[検索人気度](ads-manager-search-popularity)**: 選択した市場・カテゴリ・期間において、App Storeで上位にランクされる検索キーワードを表示します
- **[CPP A/Bテスト](ads-manager-cpp-ab-tests)**: カスタムプロダクトページを直接比較して、最もパフォーマンスの高いページを見つけます
- **[CLI](developer-cli-ads-manager)**: ターミナルからキャンペーン、キーワード、自動化ルールを管理し、[ads-manager スキル](developer-cli-ads-manager-skill)を通じてAIコーディングツールが指標を読み取り操作できるようにします

## Adapty Ads Managerを選ぶ理由は？ \{#why-choose-adapty-ads-manager\}

**市場で最も正確なデータ**を提供しているからです。

ネイティブのApple Adsコンソールやモバイル計測パートナー（MMP）とは異なり、当社のデータは**リアルタイムで欠損なく、トライアル・サブスクリプション・LTVと完全に連携**しています。遅延やアトリビューションのギャップは一切ありません。

簡単に導入でき、スムーズな操作感で、複数のツールを行き来することなく、すべてを1か所で管理できます。

## 始めるには \{#get-started\}

Adapty Ads Manager を使い始めるには、[ガイド](adapty-ads-manager-get-started)をご覧ください。必要な手順は2つ：Adapty SDK のインストールと Apple Ads アカウントの接続です。

同じアカウントはターミナルからも管理できます — [CLI から Ads Manager を管理する](developer-cli-ads-manager)をご参照ください。
