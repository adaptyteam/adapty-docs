`ads-manager` スキルを使うと、AIコーディングツールが[Adapty CLI](developer-cli-ads-manager)を通じてApple Adsアカウントを操作できるようになります。平易な言葉で質問するだけで、どのコマンドで答えが得られるかを判断し、まずアカウントを読み取り、Appleに届く前に書き込み操作を提案します。

スキルとは、AIツールが必要に応じて読み込む一連の指示のことです。このスキルには、間違えやすいAds Managerの操作に関する情報が含まれています。各フラグが受け付ける識別子の種類、各リストで使えるフィルター、バッチに含められるキーワードの上限数、そして費用が発生する呼び出しなどです。

## 何を処理するか \{#what-it-handles\}

- **読み取りパフォーマンス**: 質問に答える最適な1回の呼び出しを選択し、結果をページングしません。上位N件の質問は順序付きの1回の呼び出しで対応でき、エンティティの件数を数えるだけならメトリクスの呼び出しは不要だということを理解しています。
- **構造の変更**: キャンペーン、広告グループ、広告、キーワードを正しい順序で作成・更新し、子エンティティを書き込む前に親エンティティを読み取ります。
- **キーワード作業**: キーワードの追加や入札額の変更をバッチ処理で行い、検索ワードをキーワードおよび除外キーワードとして登録します。
- **自動化**: ルールベースの自動化を設定し、実際の入札に適用する前にドライランで検証します。
- **競合調査**: 競合アプリが入札しているキーワードを取得します。

## 実行しないこと \{#what-it-will-not-do\}

このスキルはすべての書き込みを不可逆なものとして扱います。実際そうだからです — CLI には削除機能がなく、変更は数秒以内に Apple に反映されます。

- 書き込みの前に必ず読み取りを行い、ID や予算を推測することはありません。
- お金が発生するコマンドの前には必ず確認を求め、あなた自身がコマンドを実行する際は CLI 本来の確認プロンプトもそのまま残します。
- 連続した書き込みにはそれぞれべき等キーを付与するため、結果が不明な状態で再実行しても2つ目のキャンペーンが作成されません。
- 小さなバッチを優先するため、Apple からの一部拒否が発生しても内容を把握しやすくなります。

:::note
このスキルはコマンドの推奨と準備を行います。指標の読み取りとドライランは無料ですが、ライブ広告アカウントを変更するものを承認する責任はユーザーにあります。
:::

## AI エージェントとの違い \{#how-it-differs-from-the-ai-agent\}

Adapty Ads Manager には、ダッシュボード上に組み込みの [AI エージェント](ads-manager-ai-agent)も搭載されています。両者は異なるニーズに応えます：

| | AI エージェント | ads-manager スキル |
|---|---|---|
| 動作場所 | Adapty ダッシュボード | ターミナル（AI コーディングツール内） |
| できること | 分析と推奨 | 分析、推奨、およびコマンドの実行 |
| セットアップ | 不要 | Adapty CLI とスキルの設定が必要 |

アカウントの状況を確認したい場合は AI エージェントを使用してください。変更まで実行したい場合はスキルを使用してください。
