App Storeインテグレーションの問題を解決するには、該当する症状が記載されているセクションを見つけてください。

## 認証情報の保存時に「The provided field values are incorrect」と表示される \{#the-provided-field-values-are-incorrect-when-saving-credentials\}

アプリ内購入キーを保存すると、Adapty は **Issuer ID**、**Key ID**、**Private key (.p8 file)** の各フィールドから認証トークンを生成し、Apple に対して検証を行います。このエラーは、Apple がトークンを拒否したことを意味します。以下の順番で各値を確認してください。

1. **キーの種類。** キーは App Store Connect の **Users and Access** > **Integrations** > **In-App Purchase** で発行した **In-App Purchase** キーである必要があります。**Team Keys** タブの App Store Connect API キーには独自の **Issuer ID** と **Key ID** がありますが、Apple はここでそのキーを拒否します。そのキーは代わりに **App Store Connect API key** セクションで[連携してください](app-store-connect-api-key#connect-the-key-in-adapty)。
2. **同一アカウント・チーム。** Issuer ID、Key ID、.p8 ファイルは、アプリと同じ App Store Connect チームのものでなければなりません。代理店アカウントなど別チームで生成したキーは認証に失敗します。
3. **.p8 ファイル本体。** App Store Connect からダウンロードしたファイルをそのままアップロードしてください。キーの内容を貼り付けて再作成したファイルは失敗することが多いです。各キーはダウンロードできる回数が1回のみのため、元のファイルを紛失した場合は新しいキーを生成してください。
4. **Bundle ID。** Bundle ID は App Store Connect のアプリの Bundle ID と完全に一致している必要があります。スペースなしのリバース DNS 形式（例: `com.company.app`）で指定してください。
5. **不正な文字。** 各 ID は App Store Connect から直接コピーしてください。余分なスペースや似た文字（例: 数字の `1` の代わりに小文字の `l`）が含まれると検証に失敗します。

この検証では、アプリ内課金キーの3つのフィールドとバンドルIDのみが使用されます。App-Specific Shared SecretおよびApp Store Connect APIキー（[App Store Connect API key](app-store-connect-api-key)）は検証に関与しないため、どちらかを再入力しても結果は変わりません。

すべての値がApp Store Connectと一致しているにもかかわらずエラーが表示される場合は、[support@adapty.io](mailto:support@adapty.io)までAdaptyサポートにお問い合わせください。

## プロダクトが表示されない、またはApp Storeのステータスが表示されない \{#products-dont-appear-or-show-no-app-store-status\}

AdaptyがApp Store Connectからプロダクトを読み取れない場合、以下のような症状が1つ以上表示されます。

- **App Store Product ID** ドロップダウンにプロダクトが表示されない。
- プロダクト一覧の **App Store status** 列にダッシュまたは「Not Connected」と表示される、またはプロダクトページが「Status pending」のままになっている。
- リテンションメッセージの **Associated plan** リストに「No options」と表示される。
- プロダクトのCSVをダウンロードすると列のヘッダーしか含まれていない。

以下の原因を順番に確認してください。

- **アプリに App Store Connect API キーがない**: [チームキーを接続してください](app-store-connect-api-key)。
- **Apple が App Store Connect API キーを拒否する**: キーが別チームのものである、失効している、またはキー ID が .p8 ファイルと一致していません。アプリを所有するチームのキーに[キーを置き換えてください](app-store-connect-api-key#replace-the-key)。
- **Apple App ID が空または誤っている**: App Store Connect からアプリの Apple ID を **Apple App ID** フィールドに[コピーしてください](app-store-connection-configuration#enter-the-bundle-id-and-apple-app-id)。
- **プロダクトが別のアプリにある**: Adapty は Apple App ID に紐づく App Store Connect アプリ内のプロダクトのみを検索します。プロダクトがそのアプリに属していることを確認してください。
- **プロダクトを作成してから 10 分経っていない**: App Store Connect で作成してから 10 分待ち、**App Store Product ID** ドロップダウンで再度検索してください。

## プロダクトをプッシュすると「403 Client Error: Forbidden」が発生する \{#403-client-error-forbidden-when-you-push-a-product\}

プロダクトをプッシュすると、アカウントホルダーが最新の Paid Apps Agreement に同意していない場合に App Store Connect からこのエラーが返されます。同意するには、アカウントホルダーが App Store Connect で **Business** > **Agreements** を開き、Paid Apps の **View and Agree to Terms** をクリックします。

失効した App Store Connect API キーも 403 エラーの原因になります。[キーを交換してください](app-store-connect-api-key#replace-the-key)。

## 通知ステータスが「Delayed」または「Stalled」と表示される \{#the-notifications-status-reads-delayed-or-stalled\}

**App settings** > **iOS SDK** に表示される通知ステータスは、最後の通知が24時間以上前に届いた場合に「Delayed」と表示されます。72時間が経過すると「Stalled」と表示されます。[App Store Connect の **Production Server URL** と **Sandbox Server URL** が、Adapty の **URL for App Store server notifications** と一致していることを確認してください](enable-app-store-server-notifications#check-that-notifications-reach-adapty)。

## 購入は成功したがユーザーがアクセスを失う \{#a-purchase-succeeds-but-the-customer-loses-access\}

ユーザーが購入を完了し、一時的にアクセスできる場合はあるものの、アプリがAdaptyからプロファイルを更新した後にアクセスが失われてしまうケースです。

原因として多いのは次のいずれかです：

- **アプリ内課金キーが機能しなくなった**：AdaptyがAppleとのトランザクション検証を行えませんでした。[キーを交換してください](generate-in-app-purchase-key#replace-the-key)。
- **プロダクトがAdaptyでリンクされていない**：お客様が購入したストアのプロダクトIDがAdaptyのプロダクトにリンクされていないため、付与するアクセスレベルが存在しません。正確な **App Store Product ID** でプロダクトが存在し、[アクセスレベル](access-level)が割り当てられていることを確認してください。

アプリ内課金キーを交換した後、キーが壊れていた間に購入したお客様に購入を復元するよう依頼してください。復元を行うと、すぐにアクセスが回復します。

## AdaptyとApp Storeの価格が一致しない \{#prices-in-adapty-dont-match-app-store\}

AdaptyとApp Storeでプロダクトの価格が異なる場合は、追加方法を確認してください。Adaptyのプロダクトページにある **price** フィールドは、ケースによって目的が異なります。

Adaptyでプロダクトを作成し、ダッシュボードからストアにプッシュする場合、この価格が初期ストア価格として使用されます。

すでにストアに存在するプロダクトを追加する場合、この価格はプレースホルダーです。Adapty のアナリティクス・インテグレーション・SDK は、App Store から取得した実際の価格を使用します。App Store の価格変更はプレースホルダーに同期されません。また、現時点ではダッシュボードからプレースホルダーを編集することもできません。
