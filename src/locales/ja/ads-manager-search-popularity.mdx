Search Popularityは、選択した市場・App Storeカテゴリ・完了済みの週または月において、最も検索ランクの高いApp Storeの検索ワードを、Appleが提供する人気度シグナルとともに表示します。キーワードリストの作成、キャンペーンの更新、または新規市場への参入前に、特定市場でユーザーが使用している検索ワードを把握するのに活用できます。

Popularityは検索ボリュームやパフォーマンス予測ではなく、相対的なリサーチシグナルです。

主な用途：

- **市場参入前に調査する**: 予算を投入する前に、対象国やカテゴリで上位に来る検索キーワードを確認しましょう。
- **Apple のデータでキーワードリサーチを優先する**: 直感ではなく、ランクと人気度で候補キーワードを比較しましょう。
- **季節変動や期間ごとの変化を追う**: 完了した週や月を切り替えて、どのキーワードが上昇・下降しているかを比較しましょう。

:::tip
Search Popularity は特定の市場での注目キーワードを示します。ここで見つけたキーワードを関連フレーズやカテゴリのコンテキストに展開するには、[Keyword Suggester](ads-manager-keyword-suggester) でシードキーワードとして使用してください。
:::

## 人気検索ワードを表示する \{#view-popular-search-terms\}

結果セットを読み込むには、左サイドバーの **Search Popularity** に移動します。

1. **Market** を選択します。データの利用可能状況はマーケットによって異なります。
2. **App Store category** を選択します。
3. **Period type** — **Week** または **Month** — を選択し、矢印で期間を移動します。週次データは日曜日〜土曜日の完了済み週を対象とし、月次データは完全なカレンダー月を対象とします。
4. **Show results** をクリックします。

選択したマーケット、カテゴリ、期間に対して、最大500件のワードを含む完全な結果セットがページに読み込まれます。

<ZoomImage id="search-popularity-results.webp" width="700px" alt="Search Popularity results table with market, category, and period filters and export buttons" />

Appleはまだ最新の完了した週のデータを処理中の場合があります。その週がまだ利用できないとページに表示された場合は、前の期間を代わりに読み込んでください。

フィルターを変更しても、**Update results** をクリックするまで表には前の選択内容が表示され続けます。表の上部には、現在表示されている結果が対象とする市場・カテゴリ・期間が示されます。

## 結果の確認とエクスポート \{#explore-and-export-the-results\}

- **Search**: 読み込み済みのキーワードをテキストでフィルタリングします。カウンターには一致したキーワード数が表示されます。
- **Sort**: テーブルをランク順に並べ替えます — **Highest rank first**（ランクの高い順）または **Lowest rank first**（ランクの低い順）。
- **Rows**: 1ページに表示するキーワード数を設定します。
- **Export page**: 表示中のページをCSVファイルとしてダウンロードします。
- **Export all**: 結果セット全体を、マーケット・カテゴリ・期間のコンテキストとともにCSVファイルとしてダウンロードします。検索が有効な場合は、一致したキーワードのみをダウンロードします。

リサーチした語句に入札する準備ができたら、[キーワードを管理する](ads-manager-manage-keywords)の説明に従って広告グループに追加してください。

## 指標の読み方 \{#how-to-read-the-metrics\}

| カラム | 意味 |
|---|---|
| **Rank** | 選択したマーケット・カテゴリ・期間におけるキーワードの順位。数値が小さいほど上位を意味します。 |
| **Genre score** | 選択した App Store カテゴリに対して Apple が返す相対的な人気値。 |
| **Popularity** | 1〜100 に正規化された人気スコア。相対的なシグナルであり、パーセンテージや検索ボリュームではありません。 |
| **Level** | 1〜5 の大まかな人気レベル。大きな差をひと目で把握しやすくするためのもので、アプリの評価ではありません。 |

## データの制限 \{#data-limitations\}

- 人気スコアは Apple の相対的なシグナルです。検索ボリューム、パーセンテージ、インストール数、コンバージョン率、またはパフォーマンス予測ではありません。
- 結果セットには、選択したマーケット、カテゴリ、期間に対して最大 500 件のキーワードが含まれます。
- 完了した期間のみ利用可能です：日曜日〜土曜日の週単位、および完全な暦月単位。
- 結果は最大 6 時間キャッシュされるため、リアルタイムではありません。
