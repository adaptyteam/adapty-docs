:::important
フローをユーザーに届けるには、新しいバージョンの SDK と専用のプレースメントが必要です：

- **Adapty SDK v4.0以降**: 旧バージョンのSDKはフローをレンダリングできません。
- **専用のフロープレースメント**: フローとペイウォールはコンテンツタイプが異なるため、それぞれ専用のプレースメントタイプに配置されます。フローはペイウォールのプレースメントには配置できません。また、新しいフロープレースメントはペイウォールプレースメントのIDを再利用できません — プレースメントIDはアプリ全体で一意です。[プレースメントの作成](create-placement)を参照してください。
:::

Adaptyでは、ビジュアルなノーコードエディターでフローを作成できます。

- **ペイウォール、オンボーディングなどの作成**: 動的なシングルまたはマルチスクリーンのフローを作成できます。
- **充実したフローテンプレート**: [プロがデザインしたテンプレート](paywall-builder-templates)からフローを始められます。
- **柔軟なデザイン**: 複雑な画面もコード不要でビジュアルに再現できます。
- <Inline id="sparkle.svg" alt="AI Editor" /> **[AI エディター](flow-ai-editor)**: 変更内容を自然な言葉で説明するだけで画面に反映されます。プロパティを触らずにスタイル変更、文章の書き換え、要素の並び替えが可能です。
- **ネイティブレンダリング**: Adapty SDK はフローをウェブビューを使わずネイティブにレンダリングするため、シームレスなユーザー体験を実現します。
- **再デプロイ不要で更新**: コピー、デザイン、ロジックはいつでも変更可能。アプリのリリースなしにユーザーへ届きます。

## 作れるもの \{#what-you-can-build\}

フローはアプリのどこにでも配置できます。初回起動時、プレミアム機能の前、重要なアクション後など、あらゆる場面に対応します。すべての画面は自由にカスタマイズできるので、それぞれのフローをその場面に合わせた内容にできます。主な活用例を紹介します。

- **アプリのオンボーディング**: アプリの機能を紹介し、質問を行い、クイズの回答に基づいてハイライトされる機能やCTAをパーソナライズします。[パーソナライズされたオンボーディングフローを作成する](onboarding-flow-tutorial)を参照してください。
- **ペイウォール画面**: プレミアムコンテンツの前に機能制限を設け、機能一覧・価格・購入ボタンとともにプロダクトを提示します。[基本的なペイウォール画面を作成する](basic-paywall-screen)を参照してください。
- **タブ形式の段階プラン**: サブスクリプションのティアをタブで並べて表示し、ユーザーが切り替えると機能一覧とCTAが切り替わります。[タブ付きペイウォールを作成する](paywall-with-tabs)と[プロダクトごとに異なる機能を表示する](paywall-features-per-product)を参照してください。
- **展開可能なプランリスト**: 1つのハイライトオファーを先頭に表示し、比較したいユーザー向けにボトムシートでプロダクト一覧を展開表示します。[ボトムシートにすべてのプランを表示する](show-plans-bottom-sheet)を参照してください。
- **アンケートとクイズ**: 目標・好み・経験レベルを収集し、その回答を使ってフローを分岐させたり、後続の画面をカスタマイズしたり、[アプリ内で処理](ios-flow-input)したりできます。[フロービルダーの入力フォーム](builder-inputs-and-forms)を参照してください。
- **ソーシャルプルーフ**: レビューカード・評価・体験談を購入判断の直前に表示して信頼を構築します。[レビューと体験談](builder-reviews-and-testimonials)を参照してください。
- **プロモーション・ウィンバック画面**: 期間限定の割引、無料トライアルオファー、またはウィンバック画面を使って離脱ユーザーを再エンゲージします。

これらは最もよく使われるパターンに過ぎません。フローは柔軟で再利用可能な要素から構成されているため、プロダクトに必要なほぼあらゆるスクリーンを組み合わせて作ることができ、プロダクトが進化するたびに自由に作り変えることができます。

## フローを作成する \{#create-a-flow\}

[新しいフローを作成する](paywall-builder-templates)には、カスタムデザインのギャラリーテンプレートまたは白紙のキャンバスを使用します。作成後は、以下の機能でカスタマイズできます。

- **[エレメントライブラリ](builder-elements)** — テキスト、メディア、ボタン、フォームなどのコンテンツに使える事前構築済みブロック。
- **[アクション](onboarding-actions)** — 画面間のナビゲーション、URLを開く、購入の実行など。
- **[変数](onboarding-variables)** — テキストや、トリガーベースのフローロジックを有効にするために変数の値を使用。
- **[条件付きナビゲーション](onboarding-navigation-branching)** — ユーザーの入力に基づいてフローを分岐。
- **[クイズと入力](builder-inputs-and-forms)** — ユーザーの入力を収集し、フローで使用したり、アプリに渡す。
- <Inline id="sparkle.svg" alt="AI Editor" /> **[AI エディター](flow-ai-editor)** — 変更を自然言語で説明すると、AI が現在の画面に適用します。
- **[ダークモード](paywall-dark-mode)** — デバイスのテーマに合わせてエレメントをスタイリング。
- **[ローカライズ](add-flow-remote-config-locale)** — 手動またはAI対応。

ドラフトを[保存して公開](builder-save-publish)したら、[フロープレースメント](create-placement)に紐付けましょう。他のプレースメントと重複しない新しいプレースメント ID を使って新規作成してください。フロープレースメントは、[オーディエンス](add-audience-paywall-ab-test)ごとに異なるフローを設定できます。

フローが公開されたら、[指標](flow-metrics)ページでビュー数・完了数・収益を追跡できます。Analytics ページのほとんどのチャート（MRR やチャーンなど）は、[特定のフローに絞り込む](filter-flows#filter-analytics-by-flow)こともできます（フローの画面単位での絞り込みも可能です）。
