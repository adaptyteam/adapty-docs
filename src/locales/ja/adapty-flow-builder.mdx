:::important
フローをユーザーに届けるには、新しいバージョンの SDK と専用のプレースメントが必要です:

- **Adapty SDK v4.0以降**: 旧バージョンのSDKはフローをレンダリングできません。
- **専用のフロープレースメント**: フローとペイウォールはコンテンツタイプが異なるため、それぞれ専用のプレースメントタイプに配置されます。フローはペイウォールのプレースメントには配置できません。また、新しいフロープレースメントはペイウォールプレースメントのIDを再利用できません — プレースメントIDはアプリ全体で一意です。[プレースメントの作成](create-placement)を参照してください。
:::

Adaptyでは、ビジュアルなノーコードエディターでフローを作成できます。

- **ペイウォール、オンボーディングなどを作成**: 動的なシングルまたはマルチスクリーンのフローを作成できます。
- **フル機能のフローテンプレート**: [プロがデザインしたテンプレート](paywall-builder-templates)からフローを開始できます。
- **Figmaデザインのインポート**: [Figmaからフレームをインポート](import-from-figma)して、編集可能なフローに変換できます。
- **柔軟なデザイン**: コード不要で複雑な画面をビジュアルで再現できます。
- <Inline id="sparkle.svg" alt="AI Editor" /> **[AI エディター](flow-ai-editor)**: 変更内容を自然言語で説明するだけで画面に反映されます。スタイルの変更、テキストの書き換え、要素の並び替えをプロパティを触ることなく実行できます。
- **ネイティブレンダリング**: Adapty SDKはWebビューを使わずにフローをネイティブでレンダリングするため、シームレスなユーザー体験を実現します。
- **再デプロイ不要で更新**: コピー、デザイン、ロジックをいつでも変更できます。アプリのリリースなしでユーザーに更新が届きます。

## 作れるもの \{#what-you-can-build\}

フローはアプリのどこにでも配置できます。初回起動時、プレミアム機能の前、重要なアクション後など、あらゆる場面に対応します。すべての画面は自由にカスタマイズできるので、それぞれのフローをその場面に合わせた内容にできます。主な活用例を紹介します。

- **アプリのオンボーディング**: アプリの機能を紹介し、質問でユーザーの好みを把握して、クイズの回答に基づいて表示する機能やCTAをパーソナライズします。詳しくは[パーソナライズされたオンボーディングフローの作成](onboarding-flow-tutorial)を参照してください。
- **ペイウォール画面**: プレミアムコンテンツの前に機能ゲートを設け、機能リスト・価格・購入ボタンとともにプロダクトを提示します。詳しくは[基本的なペイウォール画面の作成](basic-paywall-screen)を参照してください。
- **タブ形式のプラン**: サブスクリプションの各プランをタブで並べて表示し、ユーザーがタブを切り替えると機能リストとCTAも切り替わります。詳しくは[タブ付きペイウォールの作成](paywall-with-tabs)と[プロダクトごとに異なる機能を表示する](paywall-features-per-product)を参照してください。
- **展開可能なプランリスト**: まず注目のオファーを1つ表示し、比較したいユーザーにはボトムシートでプロダクト一覧を展開して見せます。詳しくは[ボトムシートで全プランを表示する](show-plans-bottom-sheet)を参照してください。
- **アンケートとクイズ**: 目標・好み・経験レベルなどを収集し、回答に基づいてフローを分岐させたり、後続の画面をカスタマイズしたり、[アプリ内で処理](ios-flow-input)したりできます。詳しくは[入力とフォーム](builder-inputs-and-forms)を参照してください。
- **ソーシャルプルーフ**: 購入判断の直前に、レビューカード・評価・体験談を表示して信頼感を高めます。詳しくは[レビューと体験談](builder-reviews-and-testimonials)を参照してください。
- **プロモーション・ウィンバック画面**: 期間限定の割引・無料トライアル・ウィンバック画面で、離脱したユーザーの再エンゲージメントを促します。

これらは最もよく使われるパターンに過ぎません。フローは柔軟で再利用可能な要素から構成されているため、プロダクトに必要なほぼあらゆるスクリーンを組み合わせて作ることができ、プロダクトが進化するたびに自由に作り変えることができます。

## フローを作成する \{#create-a-flow\}

[新しいフローを作成](paywall-builder-templates)するには、カスタムデザインのギャラリーテンプレート、空のキャンバス、または[Figmaデザイン](import-from-figma)から始めます。その後、以下の機能でカスタマイズできます。

- **[エレメントライブラリ](builder-elements)** — テキスト、メディア、ボタン、フォームなどのコンテンツに使える事前構築済みブロック。
- **[アクション](onboarding-actions)** — 画面間のナビゲーション、URLを開く、購入の実行など。
- **[変数](onboarding-variables)** — テキストや、トリガーベースのフローロジックを有効にするために変数の値を使用。
- **[条件付きナビゲーション](onboarding-navigation-branching)** — ユーザーの入力に基づいてフローを分岐。
- **[クイズと入力](builder-inputs-and-forms)** — ユーザーの入力を収集し、フローで使用したり、アプリに渡す。
- <Inline id="sparkle.svg" alt="AI Editor" /> **[AI エディター](flow-ai-editor)** — 変更を自然言語で説明すると、AI が現在の画面に適用します。
- **[ダークモード](paywall-dark-mode)** — デバイスのテーマに合わせてエレメントをスタイリング。
- **[ローカライズ](add-flow-remote-config-locale)** — 手動またはAI対応。

下書きを[保存して公開](builder-save-publish)したら、[フロープレースメント](create-placement)に紐付けます。アプリ内の他のプレースメントと重複しない、新しいプレースメント ID を持つプレースメントを作成してください。フロープレースメントでは、[オーディエンス](add-audience-paywall-ab-test)ごとに異なるフローを配信できます。

フローが公開されたら、[指標](flow-metrics)ページでビュー数・完了数・収益を確認できます。Analytics ページの MRR やチャーンなど多くのチャートも、[特定のフローに絞り込んで](filter-flows#filter-analytics-by-flow)表示できます。フローの画面単位での絞り込みも可能です。
