[Observerモード](observer-vs-full-mode)を使用している場合、購入ロジックはご自身で管理する必要があります。ただし、ペイウォールのUIは[Flow & Paywall Builder](adapty-flow-builder)に委任することができます。

ビルダーでスクリーンをデザインすると、Adapty SDK がネイティブにレンダリングします。アプリのリリースなしに、コピー、レイアウト、価格をいつでも更新できます。

このガイドでは、フローの表示と購入コールバックの処理方法を説明します。Adapty が購入を代行する場合は、[フローとペイウォールの表示](react-native-present-paywalls)を参照してください。

## 始める前に \{#before-you-start\}

You need:

- **Adapty React Native SDK 4.0以降**: それ以前のバージョンではフローをレンダリングできません。Androidの場合は4.4.0以降を使用してください。それ以前のバージョンでは、報告された購入をフローに紐付けられない場合があります。既存のアプリを移行する場合は、[マイグレーションガイド](migration-to-react-native-sdk-v4)をご覧ください。
- **`observerMode`を`true`に設定**: [React Native SDKインストールガイド](sdk-installation-reactnative)をご覧ください。
- **ストアの初期連携**: Adaptyを[App Store](initial_ios)および[Google Play](initial-android)と連携してください。
- **プロダクトが設定済みの公開フロー**: [フロー＆ペイウォールビルダー](adapty-flow-builder)で作成し、[プロダクト](create-product)を割り当ててください。
- **フローのプレースメント**: [プレースメントを作成](create-placement)し、フローを割り当ててください。
- **アプリ内でのフローの取得**: 表示する前に[フローとその設定を取得](react-native-get-pb-paywalls)してください。

オブザーバーモードでは、SDKは購入処理を行いません。ユーザーがAdaptyでレンダリングされたフロー内の購入ボタンまたは復元ボタンをタップすると、SDKはあなたの `onObserverPurchaseInitiated` または `onObserverRestoreInitiated` イベントハンドラーを呼び出します。そこで独自のコードを使って購入または復元を実行してください。

## オブザーバーモードのイベントハンドラーを設定する \{#set-the-observer-mode-event-handlers\}

他のプラットフォームとは異なり、専用のリゾルバーオブジェクトはありません。ハンドラーは通常の[イベントハンドラー](react-native-handling-events-1)の一部です。そのため、表示するすべてのフローに設定してください。

<Tabs groupId="presentation-method" queryString>
<TabItem value="platform" label="React component" default>

React コンポーネントの場合は、`AdaptyFlowView` の props としてハンドラーを渡します。

```typescript showLineNumbers title="React Native (TSX)"

function MyFlow({ flow }) {
  const onObserverPurchaseInitiated = useCallback<
    FlowEventHandlers['onObserverPurchaseInitiated']
  >((product, onStartPurchase, onFinishPurchase) => {
    onStartPurchase(); // the flow shows its loading indicator
    myPurchaseApi(product.vendorProductId)
      .then((transactionId) => adapty.reportTransaction(transactionId, product.variationId))
      .finally(() => onFinishPurchase()); // the flow hides the loading indicator
  }, []);

  const onObserverRestoreInitiated = useCallback<
    FlowEventHandlers['onObserverRestoreInitiated']
  >((onStartRestore, onFinishRestore) => {
    onStartRestore();
    myRestoreApi().finally(() => onFinishRestore());
  }, []);

  return (
    <AdaptyFlowView
      flow={flow}
      onObserverPurchaseInitiated={onObserverPurchaseInitiated}
      onObserverRestoreInitiated={onObserverRestoreInitiated}
      // ... your other event handlers
    />
  );
}
```

:::note
埋め込みコンポーネントでは、ハンドラーが返す値はフローを閉じません。購入または購入の復元が成功したら、コンポーネントを自分でアンマウントしてください。
:::

</TabItem>

モーダル表示の場合は、作成したビューにハンドラーを設定します。

```typescript showLineNumbers title="React Native (TSX)"

const view = await createFlowView(flow);

const unsubscribe = view.setEventHandlers({
  onObserverPurchaseInitiated(product, onStartPurchase, onFinishPurchase) {
    onStartPurchase(); // the flow shows its loading indicator
    myPurchaseApi(product.vendorProductId)
      .then((transactionId) => adapty.reportTransaction(transactionId, product.variationId))
      .finally(() => onFinishPurchase()); // the flow hides the loading indicator
    return false; // keep the flow open; dismiss it yourself after success, or let the flow continue
  },
  onObserverRestoreInitiated(onStartRestore, onFinishRestore) {
    onStartRestore();
    myRestoreApi().finally(() => onFinishRestore());
    return false;
  },
});
```

</TabItem>
</Tabs>

`onObserverPurchaseInitiated` ハンドラーはユーザーが購入を開始したことを通知し、`onObserverRestoreInitiated` はユーザーが復元を開始したことを通知します。これに応じて、独自の購入または復元フローを起動してください。

また、購入または復元の進行状況を AdaptyUI に通知するために、以下のコールバックを呼び出すことを忘れないでください。これは、ローダーの表示など、フローを適切に動作させるために必要です：

| コールバック        | 説明                                                                      |
| :----------------- | :------------------------------------------------------------------------------- |
| onStartPurchase()  | 購入が開始されたことを AdaptyUI に通知するために呼び出すコールバックです。  |
| onFinishPurchase() | 購入が完了したことを AdaptyUI に通知するために呼び出すコールバックです。 |
| onStartRestore()   | リストアが開始されたことを AdaptyUI に通知するために呼び出すコールバックです。   |
| onFinishRestore()  | リストアが完了したことを AdaptyUI に通知するために呼び出すコールバックです。  |

`onFinishPurchase()` の後、フローはキャンセルされた購入を含め、何が起きても同じ[アウトカムアクション](respond-to-purchase-outcomes#add-actions-for-a-result)を実行します。iOS では **When pending** アクション、Android では **When succeeded** アクションです。購入結果に応じたスクリーン（サンクスページなど）は自分のコードから表示してください。結果を知っているのはあなたのコードだけです。`onFinishRestore()` の後、フローは何が起きても **When restore completed** アクションを実行します。

## フローを表示する \{#present-the-flow\}

フローは通常どおり表示します。[フローを取得してビューを作成し](react-native-get-pb-paywalls)、[表示する](react-native-present-paywalls)だけです。追加のパラメーターは不要です。ハンドラーは、SDK が `observerMode: true` で有効化された場合にのみ動作します。

:::warning
[トランザクションを報告し、ペイウォールに関連付ける](report-transactions-observer-mode-react-native)ことを忘れないでください。これを行わないと、Adapty はトランザクションを認識できず、購入のソースペイウォールを特定できません。ユーザーが購入した `AdaptyPaywallProduct` の `variationId` を渡してください。`AdaptyFlow.variationId` ではありません。フロー自体のバリエーション ID は、購入をフローに紐付けません。
:::
