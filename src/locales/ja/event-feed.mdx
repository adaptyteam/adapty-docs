イベントフィードでは、Adaptyが生成した[イベント](events)を視覚的に追跡し、Webhookを含むサードパーティのインテグレーションへのエクスポート状況を確認できます。

<ZoomImage id="event-status.webp" width="700px" alt="各イベントの配信ステータスを表示するイベントフィード" />

:::note
AppsFlyer、Facebook Ads、Branchの送信ステータスは、エラーが発生しても常に返すわけではないため、不正確な場合があります。
:::

トランザクションを開始したユーザーのプロファイルを表示するには、イベント詳細の **View Profile** ボタンをクリックします。

## イベントがフィードに表示されない \{#an-event-is-missing-from-the-feed\}

イベントがフィードに表示されない原因は、主に3つあります。

- **Adapty がイベントを作成しなかった。** ほとんどのイベントは、特定のインテグレーションでそのタイプをオフにしていても、イベント自体は作成されます（ただし[グレーのステータス](event-statuses)になります）。ただし、2つの例外があります。

1. Adapty は、[Webhook インテグレーション](webhook)が設定・有効化されていない限り、`access_level_updated` を作成しません。
   2. Adapty は、確認時点でトライアルまたはサブスクリプションがまだ有効でない限り、[合成イベント](events#synthetic-events)を作成しません。詳しくは[合成イベントが届かない場合](handle-integration-errors#a-synthetic-event-never-arrived)をご覧ください。

- **イベントは存在するが、フィードに表示されない。** サーバーサイド API v1 のトランザクションは表示されません。代わりに[サーバーサイド API（バージョン 2）](api-adapty/operations/setTransaction)を使用してください。プロファイルのないイベント（SDK がユーザーを識別する前に届いたトランザクション、例えばストアのサーバー通知など）も表示されません。これらをエクスポートに含めるには、[S3](s3-exports) または [Google Cloud Storage](google-cloud-storage) インテグレーションで **Include events without profile** を有効にしてください。また、Apple が事前にタイムスタンプを設定した更新も表示されません。これらは[タイムスタンプが過ぎてから表示されます](how-profiles-work)が、Adapty はすぐにインテグレーションへ転送します。

- **イベントが2週間以上前のものである。** フィードは2週間分のイベントしか保持しません。そのため、遅延が長い[合成イベント](events#synthetic-events)は、タイマーを開始した`trial_started`や`subscription_started`イベントなしに表示されることがあります。
