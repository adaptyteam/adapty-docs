**In-App Purchase Key**は、App Store Connect内で作成される専用のAPIキーで、購入の正当性を確認して検証するために使用されます。

:::note
App Store Server API の API キーを生成するには、App Store Connect で Admin または Account Holder のロールが必要です。API キーの生成方法については、[Apple Developer Documentation](https://developer.apple.com/documentation/appstoreserverapi/creating-api-keys-to-authorize-api-requests) もご参照ください。
:::

1. **App Store Connect** を開き、[**Users and Access** → **Integrations** → **In-App Purchase**](https://appstoreconnect.apple.com/access/integrations/api/subs) セクションに移動します。

2. **Active** タイトルの横にある追加ボタン **(+)** をクリックします。

3. 表示された **Generate In-App Purchase Key** ウィンドウで、後で参照するためのキー名を入力してください。この名前はAdaptyでは使用されません。

4. **Generate** ボタンをクリックしてください。**Generate in-App Purchase Key** ウィンドウが閉じると、作成されたキーが **Active** リストに表示されます。

<Zoom>
  <img src="/assets/shared/img/fac066b-download_inapp_file.webp"

    display: 'block', /* for alignment */
    margin: '0 auto' /* center alignment */
  }}
/>
</Zoom>

5. APIキーを生成したら、**Download In-App Purchase Key** ボタンをクリックしてキーをファイルとして取得します。

<Zoom>
  <img src="/assets/shared/img/d59faff-download_in-app_purchase_key.webp"
  style={{
    border: '1px solid #727272', /* border width and color */
    width: '700px', /* image width */
    display: 'block', /* for alignment */
    margin: '0 auto' /* center alignment */
  }}
/>
</Zoom>

6. **Download in-App Purchase Key** ウィンドウで、**Download** ボタンをクリックします。ファイルがコンピューターに保存されます。
   このファイルは後で Adapty ダッシュボードにアップロードするため、安全に保管することが重要です。生成されたファイルは一度しかダウンロードできないため、アップロードするまで安全に保管してください。**In-App Purchase section** で生成された .p8 キーは、[Adapty と App Store の初期連携を設定する](app-store-connection-configuration#step-3-upload-in-app-purchase-key-file)際に使用します。

:::warning
このキーが後で失効または削除された場合、Adapty はプロモーションオファーに署名できなくなり、購入時にそれらの割引が適用されなくなります。Adapty はこれを通知しません — [更新が届かなくなった場合](store-sync#if-updates-stop-arriving)を参照してください。
:::
