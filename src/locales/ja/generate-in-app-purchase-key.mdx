Adaptyはアプリ内課金キーを使用して、アプリ内の購入を検証し、[プロモーションオファー](offers)に署名します。App Store Connectでキーを生成し、Adaptyの **App settings** の2つのセクションに入力してください。キーが機能しなくなったり変更が必要になった場合は、[キーを交換してください](#replace-the-key)。

アプリ内購入キーは [App Store Connect APIキー](app-store-connect-api-key) とは異なりますが、App Store Connect では両方のキーのIDに **Issuer ID** と **Key ID** というラベルが付いています。

**App settings** > **iOS SDK** にすべての認証情報をまとめて入力するには、[App Store連携の設定](app-store-connection-configuration) を参照してください。

## キーの更新 \{#replace-the-key\}

キーが機能しなくなった場合や変更が必要な場合は、古いキーを失効させる前に新しいキーをAdaptyに保存してください。

キーが機能しなくなると以下の問題が発生します：

- アプリ内の購入がアクセスを付与せず、アプリにエラーも返されない。
- ユーザーがプロモーションオファーを利用できない。
- [Refund Saver](refund-saver) が消費リクエストに応答できない。
- Adaptyは警告を表示せず、**App Store server notifications** セクションのステータスは **Active** のままとなる。

アプリが別のAppleデベロッパーアカウントに移行する場合は、[新しいオーナーのチームのキーに差し替えてください](transfer-apps#app-store-ios-transfer)。

To replace the key:

1. Adaptyで [**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk) に移動します。現在Adaptyが使用しているキーを確認するには、**In-app purchase API (StoreKit 2)** セクションの **Key ID** フィールドの値をメモしておきます。
2. [新しいキーを生成します](#generate-the-key-in-app-store-connect)。
3. **In-app purchase API (StoreKit 2)** セクションと **App Store promotional offers** セクションで [新しいキーをAdaptyに追加し](#add-the-key-to-adapty)、**Save** をクリックします。
4. 1つのキーがApp Store Connectチームのすべてのアプリで使用されます。他のAdaptyアプリがステップ1のKey IDを使用している場合は、それらのアプリにも新しいキーを追加してください。また、そのキーを使用しているサーバーがあれば、古いキーを新しいキーに置き換えます。
5. 失効したキーはそれを使用しているすべてのアプリで機能しなくなり、復元することはできません。App Store Connectで古いキー（ステップ1のKey IDに対応するアクティブなキー）を失効させます。

Adaptyに有効なキーがない状態で購入したユーザーは、[購入を復元する](troubleshoot-app-store-integration#a-purchase-succeeds-but-the-customer-loses-access)とアクセスが付与されます。
