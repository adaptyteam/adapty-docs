Adapty のアトリビューション機能における Google Ads 連携は、双方向で機能します。AdaptyはGoogle Adsアカウントから広告費用・インプレッション・クリックを取得し、インストール・トライアル・購入データをGoogleへ送り返すことで、Googleが実際の収益をもとにキャンペーンを最適化できるようにします。

Adaptyは2種類のGoogle Adsキャンペーンに対応しており、それぞれ専用のタブと設定手順があります。

- **アプリキャンペーン**: App Store または Google Play でアプリを宣伝する Google のアプリキャンペーンです。Adapty は各アプリの **App Link ID** を通じて Google にイベントを送信し、Google がインストールをキャンペーン、広告グループ、広告、キーワードに紐付けます。これらのキャンペーンにトラッキングリンクは不要です。
- **その他のキャンペーン**: 広告クリックを通じてストアやウェブファネルにユーザーを誘導する、検索・ディスプレイ・ショッピングなどのキャンペーンタイプです。Adapty はキャンペーン用のトラッキングテンプレートを提供し、Google のクリック ID による照合で、選択した Google Ads アカウントにコンバージョンを送信します。

## ステップ 1. Google アカウントを連携する \{#step-1-connect-your-google-account\}

1. Adapty Attribution で、左サイドバーの **Integrations** に移動し、**Google Ads** を選択します。
2. **Sign in with Google** をクリックします。

<ZoomImage id="ua-sign-in-google-ads.webp" width="700px" />

3. Google Ads アカウントへのアクセス権を持つ Google アカウントを選択し、**Continue** をクリックします。
4. 要求されたすべての権限を選択し、**Continue** をクリックします。

その後、Adaptylはお使いのGoogleアカウントがアクセスできるすべてのGoogle Adsアカウント（マネージャーアカウント配下のクライアントアカウントを含む）を同期します。別のGoogleアカウントがアクセスできる広告アカウントを追加するには、**Sign in with Google** を再度クリックしてください。

## ステップ 2. App キャンペーンを追加する \{#step-2-add-app-campaigns\}

アプリ内イベントを Google App キャンペーンに送信するには、Adapty Attribution で設定を作成し、各プラットフォームの App Link ID を使って Google Ads のアプリと紐付けます。

**Adapty Attribution で設定を作成する：**

1. **Integrations > Google Ads** で **App Campaigns** タブに切り替え、**Create configuration** をクリックします。Adapty が現在のアプリの設定を作成して開きます。

<ZoomImage id="google-ads-create-ad-campaign.webp" width="700px" />

2. **Provider ID** の値をコピーします。Google Ads で App Link ID を作成する際に必要です。

**Google Ads で各プラットフォームのアプリリンク ID を作成します：**

1. **Tools** アイコンをクリックし、**Data manager** を選択します。
2. **+ Connect Product** をクリックし、**Third-party app analytics** を選択して、**Continue** をクリックします。
3. **Create link ID** をクリックします。
4. プロバイダーリストから **Other provider** を選択し、Adapty Attribution からコピーした **Provider ID** を貼り付けます。
5. プラットフォームとして **iOS** を選択し、**Look up your app** フィールドでアプリを検索します。
6. **Create link ID** をクリックし、生成されたリンク ID をコピーします。
7. Android のリンク ID を作成するには、プラットフォームを **Android** にして手順 3〜6 を繰り返します。

:::note
Google Ads では、Adapty から最初のイベントを受信するまで、リンク ID が **Unverified** と表示されます。
:::

**Adapty Attribution で、リンク ID を追加します：**

1. 設定画面で、リンク ID を **iOS App Link ID** と **Android App Link ID** のフィールドに貼り付けます。各リンク ID は 1 つの設定にのみ属することができます。

<ZoomImage id="app-link-id.webp" width="700px" />

2. [イベントをマッピングし](#step-4-map-events)、**Save** をクリックします。
3. 接続を確認するには、**Send test event** をクリックし、イベントを選択して送信します。Google は受信した各イベントをアプリのコンバージョンアクションに Google Ads へ追加するため、キャンペーンの最適化目標として選択できます。

<ZoomImage id="google-ads-test-event.webp" width="700px" />

:::note
欧州経済領域および英国のユーザーに対して、Adapty は同意シグナルを「拒否」に設定してイベントを送信します。Adapty Attribution で同意を設定する必要はありません。
:::

## ステップ 3. その他のキャンペーンを追加する \{#step-3-add-other-campaigns\}

検索、ディスプレイ、ショッピング、その他のクリックベースのキャンペーンをトラッキングするには、Adapty アトリビューションでそれらの設定を作成し、そのトラッキングテンプレートを Google Ads のキャンペーンに追加してください。広告を配信する Google Ads アカウントごとに、1 つの設定が必要です。

:::important
Google Ads アカウントの設定で自動タグ設定をオンにしてください。Adapty は自動タグ設定が付与するクリック ID をもとにコンバージョンと広告を照合しており、クリック ID がない場合はコンバージョンを送信しません。
:::

1. **Integrations > Google Ads** で、**Other Campaigns** タブに切り替えて **Create configuration** をクリックします。

   <ZoomImage id="ua-google-ads-other-campaigns.webp" width="700px" alt="Other Campaigns tab of the Google Ads integration in Adapty Attribution with the Create configuration button" />

2. **Google Ads account** ドロップダウンで、広告を配信しているクライアントアカウントを選択します。Google はその広告を配信したアカウントにのみコンバージョンを受け付けます。マネージャーアカウントはコンバージョンを保持できないため、リストに表示されません。

<ZoomImage id="ua-google-ads-account-select.webp" width="700px" alt="Other campaignsの設定でのGoogle Adsアカウントドロップダウンと、その下のトラッキングテンプレート" />

3. **Tracking template** の値をコピーします。次に Google Ads でキャンペーン設定を開き、**Campaign URL options > Tracking template** に貼り付けます。1つのテンプレートで iOS と Android の両方に対応します。
4. 広告がウェブファネルに誘導する場合は、**Web funnel** セクションを展開します：
   - **Pixel snippet** をコピーし、[ファネルにインストールします](ua-web-pixel)。
   - **Ad URL parameters** をコピーし、Google Ads のキャンペーン設定で **Campaign URL options > Final URL suffix** に貼り付けます。これがないと、Adapty は購入を Google Ads に帰属させますが、キャンペーン・広告グループ・広告単位には帰属しません。

<ZoomImage id="ua-google-ads-tracking-links.webp" width="700px" alt="Tracking links section of an Other campaigns configuration with the tracking template, pixel snippet, and ad URL parameters" />

5. [イベントをマッピングする](#step-4-map-events)をクリックし、**Save** をクリックします。

設定を保存すると、Adapty は有効にした各イベントに対して、選択した Google Ads アカウントにコンバージョンアクションを作成します。Google が拒否した場合、Adapty はエラーを表示し、設定を保存しません。編集可能なクライアントアカウントを選択するか、Google アカウントのアクセスが期限切れになっている場合は再接続してください。

:::note
2026年9月11日より前にGoogleアカウントを連携した場合は、Other campaignsを追加する前に再連携してください。それ以前に行った連携では、Adaptyがこれらのキャンペーンのコンバージョンを送信するために必要な権限が不足しています。**Sign in with Google**をクリックして、要求されたすべての権限を選択してください。
:::

## ステップ4. イベントのマッピング \{#step-4-map-events\}

Google が受信するイベントを選択するには、**Events mapping** セクションで送信したいイベントをオンにして、Google Ads 上のイベント名を選択または入力します。イベント名にカンマは使用できません。

<ZoomImage id="ua-google-ads-events.webp" width="700px" />

2つのキャンペーンタイプによって、名前の扱い方が異なります。

- **アプリキャンペーン**: **インストール**は常にオンで、デフォルトでは `first_open` にマッピングされます。各イベントに対して、Googleの標準アプリイベントの中から選択できます: `first_open`、`session_start`、`in_app_purchase`、`ecommerce_purchase`、`view_item`、`view_item_list`、`add_to_cart`、または `view_search_results`。入力したその他の名前は、Adaptyがカスタムアプリイベントとして送信します。
- **その他のキャンペーン**: 各イベントのデフォルト名は `trial_started` のようなAdaptyのイベント名です。選択または入力した名前が、AdaptyがGoogle Adsで作成するコンバージョンアクションの名前になります（入力した通りの名前になります）。

**Save** をクリックします。

## 追加設定 \{#additional-configuration\}

### 収益オーバーライド \{#revenue-override\}

トライアルイベントをトラッキングし、Google にその収益を関連付けたい場合は、**Revenue override** セクションを使用します。このセクションは **Trial started** イベントが有効になっているときに表示されます。オーバーライドは **Trial started** にのみ適用されます。**Trial converted** と **Subscription started** は常に実際の収益を送信します。

各トライアルイベントターゲットに対して、収益としてレポートするサブスクリプション価格の割合を設定します。たとえば、30% に設定すると、Adapty はトライアルイベントのコンバージョン値としてサブスクリプション価格の 30% を送信します。

オーバーライドを追加するには：

1. **Events mapping** セクションで **Trial started** を有効にします。
2. **Revenue override** で **Add event** をクリックします。
3. 対象イベントを選択し、収益の割合（0〜100）を入力します。
4. **Save** をクリックします。

<ZoomImage id="revenue-override.webp" width="500px" />

### Qualified trial \{#qualified-trial\}

:::warning
Adapty Attributionは、トライアルイベントを最大24時間遅延させ、ユーザーがキャンセルしていない場合にのみ送信します。MMPが`trial_started`または[`trial_active`](events#synthetic-events)も転送している場合、Googleは同じトライアルを複数回受け取ることになります。
:::

トライアルは、指定された時間数をキャンセルされずに経過した場合に「有効」と見なされます。**Qualified trial** セクションを使用して、トライアルイベントが有効と見なされるまで保留することで、Googleはユーザーが継続したトライアルのみを受け取るようになります。このセクションは、App campaignsとOther campaignsの両方で利用できます。

各トライアルイベントターゲットに対して、待機する時間数を設定します。Adapty はトライアル開始時から時間をカウントし、期限が過ぎるとイベントを送信します。期限前にユーザーが自動更新をオフにした場合、Adapty はイベントを送信しません。期限前にユーザーが自動更新を再度オンにした場合、Adapty は予定どおりイベントを送信します。

トライアルイベントを条件を満たすまで保留するには：

1. **Events mapping** セクションで **Trial started** を有効にします。
2. **Qualified trial** で **Add event** をクリックします。
3. ターゲットイベントを選択し、待機する時間数（1〜24）を入力します。
4. **Save** をクリックします。

<ZoomImage id="qualified-trial-google-ads.webp" width="700px" alt="Qualified trial section with the in_app_purchase target event held for one hour in a Google Ads campaign configuration" />

**Revenue override** と **Qualified trial** は独立して動作するため、同じトライアルイベントに両方を適用することができます。Revenue override はGoogle が受け取る値を変更し、Qualified trial はGoogle がそれを受け取るタイミングを変更します。両方を使用した場合、Adapty はトライアルが条件を満たすまでイベントを保留し、その後オーバーライドされた収益値と共に送信します。

## AdaptyアトリビューションにおけるGoogle Adsデータ \{#google-ads-data-in-adapty-attribution\}

Adaptyは4時間ごとにGoogle Adsの広告費、インプレッション数、クリック数を更新します。Googleが最近のデータを継続的に調整するため、更新のたびに直近3日分のデータも再取得されます。

[Adaptyアトリビューション分析](ua-analytics)では、Google Adsのデータはキャンペーン、広告グループ、広告、キーワードの4つのレベルで確認できます。国別の内訳はレベルによって異なります。

- **キャンペーンと広告グループ**: Google がレポートした通りの正確な値。
- **広告**: 推定値。Google は広告を国別にレポートしないため、Adapty は各広告の数値を、その広告グループの数値が国別に分割される割合と同じ方法で各国に割り当てます。
- **キーワード**: 利用不可。

接続済みの Google Ads アカウントのいずれのキャンペーンにも一致しない Google Ads クリック ID を持つインストールは、**Google Play** チャネルの下に表示されます。同じインストールを主張する Google Ads と他のソースの間で Adapty がどのように選択するかについては、[チャネル](adapty-user-acquisition#channels)を参照してください。
