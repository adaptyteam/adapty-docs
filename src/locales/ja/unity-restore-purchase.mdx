購入の復元は、iOSとAndroidの両方で提供されている機能で、ユーザーが以前に購入したサブスクリプションやアプリ内課金などのコンテンツへのアクセスを、再度料金を支払うことなく取り戻せるようにするものです。この機能は、アプリをアンインストールして再インストールしたユーザーや、新しいデバイスに切り替えたユーザーが、以前に購入したコンテンツに改めて支払いをせずにアクセスしたい場合に特に役立ちます。

:::note
ビルダーでスクリーンを作成した場合、購入の復元を手動で行う必要はありません。復元コントロールを接続するだけで済みます。Flow & ペイウォールビルダーでは **Restore purchases** アクション、旧ビルダーでは復元リンクまたはボタンを使用すると、SDK が復元を完了します。
:::

スクリーンを自分で作成した場合は、`.restorePurchases()` メソッドを呼び出してください:

```csharp showLineNumbers
Adapty.RestorePurchases((profile, error) => {
    if (error != null) {
        // handle the error
        return;
    }
  
    var accessLevel = profile.AccessLevels["YOUR_ACCESS_LEVEL"];
    if (accessLevel != null && accessLevel.IsActive) {
        // restore access
    }
});
```

レスポンスパラメーター:

| パラメーター | 説明                                                                                                                                                                                                                                                   |
|---------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Profile** | <p>[`AdaptyProfile`](https://unity.adapty.io/class_adapty_s_d_k_1_1_adapty_profile.html) オブジェクト。このモデルには、アクセスレベル、サブスクリプション、非サブスクリプション購入に関する情報が含まれています。</p><p>**アクセスレベルのステータス**を確認して、ユーザーがアプリにアクセスできるかどうかを判断してください。</p> |
