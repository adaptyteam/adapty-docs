アプリ内課金を有効にするには、3つの重要な概念を理解する必要があります。

- [**プロダクト**](product) – ユーザーが購入できるもの（サブスクリプション、消耗型アイテム、永続アクセス）
- [**フロー & ペイウォール**](adapty-flow-builder) – ノーコードのフロー & ペイウォールビルダーで作成した、プロダクトをユーザーに提示する画面。SDKは`getFlow`を通じて取得します。独自のコードでUIを構築したい場合は、[カスタムペイウォールの実装](android-quickstart-manual)を参照してください。
- [**プレースメント**](placements) – アプリ内でフロー & ペイウォールを表示する場所とタイミング（`main`、`onboarding`、`settings`など）。ダッシュボードでプレースメントに紐付けてから、コード内でプレースメントIDを指定してリクエストします。これにより、A/B テストの実施や、ユーザーごとに異なる表示が簡単に行えます。

Adapty では、アプリで購入機能を有効にする方法を3つ提供しています。アプリの要件に応じていずれかを選択してください。

| 実装方法 | 複雑さ | 使用場面 |
|---|---|---|
| Adapty フロー & ペイウォールビルダー | ✅ 簡単 | [ノーコードビルダーで購入可能な完全なフローまたはペイウォールを作成](quickstart-paywalls)します。Adapty が自動的にレンダリングし、購入ロジック、レシート検証、サブスクリプション管理をすべて裏側で処理します。 |
| カスタムペイウォール | 🟡 普通 | アプリのコードでペイウォールの UI を実装しますが、プロダクト提供の柔軟性を保つために Adapty からフローオブジェクトを取得します。[ガイド](android-quickstart-manual)を参照してください。 |
| オブザーバーモード | 🔴 難しい | 独自の購入処理インフラがすでにあり、そのまま使い続けたい場合に使用します。なお、オブザーバーモードには Adapty での制限があります。[記事](observer-vs-full-mode)を参照してください。 |

:::important
**以下の手順では、Adapty フロー & ペイウォールビルダーで作成したフローまたはペイウォールを実装する方法を説明します。**

ペイウォール UI を自分でビルドしたい場合は、[カスタムペイウォールの実装](android-quickstart-manual)をご覧ください。
:::

Adapty フロー & ペイウォールビルダーで作成したフローまたはペイウォールをアプリに表示するには、アプリのコードで次の操作を行うだけです。

1. **フローまたはペイウォールを取得する**: Adaptyから取得します。
2. **表示するだけで購入処理はAdaptyが担当**: ビューをアプリに表示します。
3. **ボタンのアクションを処理する**: ユーザー操作とアプリの応答を紐付けます。たとえば、ユーザーがボタンをタップしたときにリンクを開いたり、ペイウォールを閉じたりします。

## 始める前に \{#before-you-start\}

始める前に、以下の手順を完了してください：

1. Adapty ダッシュボードで[アプリを Google Play に接続する](initial-android)。
2. Adapty で[プロダクトを作成する](create-product)。
3. [フローまたはペイウォールを作成し](paywall-builder-templates)、[プロダクトを追加する](paywall-product-block)。
4. [プレースメントを作成し、フローまたはペイウォールを追加する](create-placement)。
5. アプリのコードに[Adapty SDK をインストールして有効化する](sdk-installation-android)。このガイドでは Adapty Android SDK v4 の API を使用します。

:::tip
これらの手順を最も素早く完了する方法は、[クイックスタートガイド](quickstart)に従うか、[Developer CLI](developer-cli-quickstart)を使ってフローとプレースメントを作成することです。
:::

## 1. フローまたはペイウォールを取得する \{#1-get-the-flow-or-paywall\}

フローとペイウォールは、ダッシュボードで設定されたプレースメントに関連付けられています。プレースメントを使用することで、異なるオーディエンスに対して異なるフローやペイウォールを表示したり、[A/B テスト](ab-tests)を実施したりすることができます。

Adapty Flow & Paywall Builder で作成したフローまたはペイウォールを取得するには、以下の手順が必要です。

1. `getFlow` メソッドを使用して[プレースメント](placements) ID から `flow` オブジェクトを取得し、ビュー設定が含まれているか確認します。

2. `getFlowConfiguration` メソッドを使用してビューの設定を取得します。ビューの設定には、表示に必要なUI要素とスタイリングが含まれています。

:::important
ビューの設定を取得するには、[フローまたはペイウォールを公開](builder-save-publish)してください。未公開の編集がある場合、フローまたはペイウォールのステータスは **Dirty** となり、そのプレースメントは最後に公開されたバージョンを引き続き提供します。
:::

<Tabs groupId="current-os" queryString>

<TabItem value="kotlin" label="Kotlin" default>

```kotlin showLineNumbers
Adapty.getFlow("YOUR_PLACEMENT_ID") { result ->
    if (result is AdaptyResult.Success) {
        val flow = result.value
        
        if (!flow.hasViewConfiguration) {
            return@getFlow
        }
        
        AdaptyUI.getFlowConfiguration(flow) { configResult ->
            if (configResult is AdaptyResult.Success) {
                val flowConfiguration = configResult.value
            }
        }
    }
}
```
</TabItem>
<TabItem value="java" label="Java" default>

```java showLineNumbers

Adapty.getFlow("YOUR_PLACEMENT_ID", result -> {
    if (result instanceof AdaptyResult.Success) {
        AdaptyFlow flow = ((AdaptyResult.Success<AdaptyFlow>) result).getValue();
        
        if (!flow.hasViewConfiguration()) {
            return;
        }
        
        AdaptyUI.getFlowConfiguration(flow, configResult -> {
            if (configResult instanceof AdaptyResult.Success) {
                AdaptyUI.FlowConfiguration flowConfiguration =
                    ((AdaptyResult.Success<AdaptyUI.FlowConfiguration>) configResult).getValue();
                // use loaded configuration
            }
        });
    }
});
```

## 2. フローまたはペイウォールを表示する \{#2-display-the-flow-or-paywall\}

フローの設定を取得したら、あとは数行追加するだけでフローやペイウォールを表示できます。

デバイス画面にビジュアルフローを表示するには、まず設定が必要です。`AdaptyUI.getFlowView()` メソッドを呼び出すか、`AdaptyFlowView` を直接作成してください：

## 3. ボタンアクションの処理 \{#handle-button-actions\}

フローまたはペイウォールでユーザーがボタンをタップすると、Android SDK は購入・復元・画面閉じ・リンク開くといった処理を自動的に行います。

ただし、カスタムまたは事前定義の ID を持つボタンについては、コード側でアクションを処理する必要があります。また、デフォルトの動作をオーバーライドしたい場合もあります。

たとえば、以下は閉じるボタンのデフォルト動作の例です。コードに追加する必要はありませんが、必要な場合にどのように実装するかを確認できます。

:::tip
ボタンの[アクション](android-handle-paywall-actions)と[イベント](android-handling-events)の処理方法については、ガイドをご覧ください。
:::

<Tabs groupId="current-os" queryString>

<TabItem value="kotlin" label="Kotlin" default>

```kotlin showLineNumbers title="Kotlin"
override fun onActionPerformed(action: AdaptyUI.Action, context: Context) {
    when (action) {
        AdaptyUI.Action.Close -> (context as? Activity)?.onBackPressed() // default behavior
    }
}
```
</TabItem>
<TabItem value="java" label="Java" default>

```java showLineNumbers
@Override
public void onActionPerformed(@NonNull AdaptyUI.Action action, @NonNull Context context) {
    if (action instanceof AdaptyUI.Action.Close) {
        if (context instanceof Activity) {
            ((Activity) context).onBackPressed();
        }
    }
}
```

## 次のステップ \{#next-steps\}

<SupportForum />

フローまたはペイウォールをアプリに表示する準備が整いました。[Google Play ストアで購入をテストして](testing-on-android)、フローからテスト購入を完了できることを確認してください。

## 完全な例 \{#full-example\}

これらのすべてのステップをアプリに統合する方法を示します。

<Tabs groupId="current-os" queryString>

<TabItem value="kotlin" label="Kotlin" default>

```kotlin showLineNumbers title="Kotlin"
class MainActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)

        Adapty.getFlow("YOUR_PLACEMENT_ID") { flowResult ->
            if (flowResult is AdaptyResult.Success) {
                val flow = flowResult.value

                if (!flow.hasViewConfiguration) {
                    // Use custom logic
                    return@getFlow
                }

                AdaptyUI.getFlowConfiguration(flow) { configResult ->
                    if (configResult is AdaptyResult.Success) {
                        val flowConfiguration = configResult.value

                        val flowView = AdaptyUI.getFlowView(
                            this,
                            flowConfiguration,
                            null, // products = null means auto-fetch
                            object : AdaptyFlowDefaultEventListener() {
                                override fun onActionPerformed(action: AdaptyUI.Action, context: Context) {
                                    when (action) {
                                        is AdaptyUI.Action.Close -> {
                                            (context as? Activity)?.onBackPressed()
                                        }
                                    }
                                }
                            }
                        )

                        setContentView(flowView)
                    }
                }
            }
        }
    }
}

```
