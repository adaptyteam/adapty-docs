[FunnelFox](https://funnelfox.com)は、App Store外でユーザーを獲得・課金できるweb2appファネルプラットフォームです。App Storeの手数料やその他の制限を回避できます。

このインテグレーションを設定することで、FunnelFoxの購入データをAdaptyに送信できます。AdaptyはウェブのRevenuを広告費と照合し、キャンペーン、広告セット、広告ごとの収益を確認できるようにします。

## 仕組み \{#how-it-works\}

ユーザーがFunnelFoxファネル内で購入を完了すると、FunnelFoxはそのトランザクションイベントをAdapty Attributionに送信します。Adaptyは**Project ID**を使用して、そのトランザクションがどのアプリに属するかを識別します。イベントはその後保存され、[Adapty Attributionアナリティクス](ua-analytics)に表示されます。

インテグレーションが稼働すると、Adaptyの各トランザクションには以下が含まれます：

- **サブスクリプションライフサイクルイベント**: 開始、更新、キャンセル、トライアルからの転換、返金、その他
- **アトリビューションチャネル**: Facebook、TikTok、Google、またはオーガニック。Adapty は広告ネットワークが自動付与するクリック ID から判定するため、設定は不要です。
- **アトリビューションデータ**: キャンペーン、広告セット、広告の識別子、UTM パラメーター、プラットフォームのクリック ID（fbclid、ttclid、gclid）。キャンペーン、広告セット、広告は、広告 URL に Adapty の[トラッキングパラメーター](#step-3-tag-your-ad-urls)を設定している場合のみ取得されます。
- **ファネル・実験データ**: FunnelFox のファネル名と実験名。A/B テストのバリアントを比較する際に活用できます。
- **コホート日**: 最初のトライアル開始日または購入日。Web 購入にはアプリのインストールイベントがないため、Adapty はその日付を基準にコホートを作成します。

## インテグレーションの設定 \{#configure-integration\}

:::note
FunnelFox のファネルでは [Adapty ウェブピクセル](ua-web-pixel) は不要です。FunnelFox が購入情報を直接 Adapty に報告します。
:::

### ステップ 1. FunnelFox で Project ID を取得する \{#step-1-get-your-project-id-in-funnelfox\}

1. FunnelFox ダッシュボードの左サイドバーで **Settings** をクリックします。
2. **Project info** セクションで **ID** の値をコピーします。

<ZoomImage id="ff-project-id.webp" width="500px" />

### ステップ 2. Adapty Attribution にプロジェクトを追加する \{#step-2-add-the-project-in-adapty-attribution\}

1. Adapty Attribution で [**Integrations > FunnelFox**](https://app.adapty.io/ua/integrations/funnelfox) に移動します。
2. FunnelFox からコピーしたプロジェクト ID を貼り付けます。
3. **Save** をクリックします。

FunnelFox のプロジェクトをさらに接続するには、**Add project** をクリックして、各プロジェクトに対してこの手順を繰り返してください。

<ZoomImage id="ua-funnelfox.webp" width="500px" />

### ステップ 3. 広告URLにタグを付ける \{#step-3-tag-your-ad-urls\}

FunnelFox がキャンペーンデータを渡せるのは、そのデータがランディングページの URL に含まれている場合のみです。FunnelFox はビジターが最初にランディングしたタイミングで URL を読み取るため、チェックアウト時ではありません。[ウェブファネル用の広告 URL タグ付け](ua-tag-ad-urls) の説明に従って、広告に Adapty のトラッキングパラメータを追加してください。

### ステップ4. FunnelFoxでキャンペーンアトリビューションを有効にする \{#step-4-turn-on-campaign-attribution-in-funnelfox\}

:::note
この設定はデフォルトでオフになっており、FunnelFoxはバックフィルを行いません。有効にする前に完了したトランザクションはAdaptyに送信されません。
:::

1. FunnelFoxで [**Integrations > Adapty**](https://app.funnelfox.com/integrations/adapty) に移動します。
2. **Campaign attribution** をオンにします。

接続したすべてのFunnelFoxプロジェクトで有効にしてください。

FunnelFoxプロジェクトは組織に属している必要があり、広告アカウントはAdaptyで接続されている必要があります。

FunnelFox がこのチャンネルを通じて送信するイベントについては、FunnelFox ドキュメントの [Adapty インテグレーション](https://funnelfox.com/docs/integrations/subscription-management/adapty#campaign-attribution) を参照してください。
