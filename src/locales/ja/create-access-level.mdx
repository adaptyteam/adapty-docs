アクセスレベルを使うと、特定のプロダクトIDをハードコードすることなく、モバイルアプリのユーザーに対してできることを制御できます。各プロダクトは、ユーザーが特定のアクセスレベルを利用できる期間を定義します。つまり、ユーザーが購入を行うたびに、Adaptyはアプリへのアクセスを一定期間（サブスクリプションの場合）または永続的（永続アクセス購入の場合）に付与します。

Adapty ダッシュボードでアプリを作成すると、`premium` アクセスレベルが自動的に生成されます。これはデフォルトのアクセスレベルとして機能し、削除することはできません。

:::tip
[Developer CLI](developer-cli-apps#adapty-access-levels-create)を使ってアクセスレベルをプログラムで作成することもできます。
:::

新しいアクセスレベルを作成するには：

1. Adapty メインメニューから **[Products](https://app.adapty.io/access-levels)** に移動し、**Access levels** タブを選択します。

2. **Create access level** をクリックします。

   
<Zoom>

3. **Create access level** ウィンドウで、IDを割り当てます。このIDはモバイルアプリ内の識別子として機能し、ユーザーが購入した際に追加機能へのアクセスを可能にします。また、この識別子はアプリ内で他のアクセスレベルと区別する際にも役立ちます。わかりやすく、理解しやすいものにしてください。

4. **Create access level** をクリックして、アクセスレベルの作成を確定します。
