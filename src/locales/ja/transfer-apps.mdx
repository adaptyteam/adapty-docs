会社の買収、アプリの売却、事業体の再編成などの際に、アプリを別のオーナーに移管します。移管後、新しいオーナーは[購入によってアクセスがアンロックされることを確認します](#verify-transfer-completed-successfully)。

## アプリのオーナーシップの移行 \{#transfer-app-ownership\}

:::note
移行プロセス中は、プロダクトを削除または再作成しないでください。移行が正常に完了したことを確認するまで、プロダクト ID を変更しないでください。
:::

変更されるアカウントごとに、以下の手順に従ってください。

- Apple デベロッパーアカウント: [App Store (iOS) の移行](#app-store-ios-transfer)
- Google Play デベロッパーアカウント: [Google Play (Android) の移行](#google-play-android-transfer)
- Adapty アカウントのみ: [Adapty のみの移行](#adapty-only-transfer)

### App Store（iOS）の移管 \{#app-store-ios-transfer\}

アプリが別の Apple デベロッパーアカウントに移管される場合、新しいオーナーは Adapty 内の以下の3つの認証情報を自分のものに置き換えます：

- アプリ内購入キー
- App Store Connect API キー（チームキー）
- アプリ固有の共有シークレット

アプリは Bundle ID と Adapty 内の通知 URL をそのまま引き継ぎます。

移管には2つのフェーズがあります：[Apple が移管を完了する前](#before-apple-completes-the-transfer)と[Apple が移管を完了した後](#after-apple-completes-the-transfer)です。

#### Apple が移管を完了する前 \{#before-apple-completes-the-transfer\}

1. **新オーナー：** Adapty アカウントをお持ちでない場合は、[app.adapty.io](https://app.adapty.io) でアカウントを作成してください。
2. **旧オーナー：** App Store Connect で、Apple の[移行ガイド](https://developer.apple.com/help/app-store-connect/transfer-an-app/overview-of-app-transfer)に従ってアプリの移転を開始してください。
3. **旧オーナー：** Adapty でのアプリ移転については、[support@adapty.io](mailto:support@adapty.io) にメールでご連絡ください。その際、アプリ名と手順 1 で作成した Adapty アカウントのメールアドレスを記載してください。その後、新オーナーが Adapty でアプリの認証情報を入力できるようになります。
4. **新オーナー：** App Store Connect チームの **Admin** アクセス権を持つアプリ内課金キーとチームキーが必要です。既存のアクティブなキーのファイルがある場合は、そのキーをご利用ください。ない場合は、App Store Connect で[アプリ内課金キー](generate-in-app-purchase-key#generate-the-key-in-app-store-connect)または[チームキー](app-store-connect-api-key#generate-a-team-key-in-app-store-connect)を生成してください。
5. **新オーナー：** App Store Connect で移転を承認してください。Apple は 2 営業日以内に処理を完了し、両方のアカウントホルダーに通知します。

#### Appleが転送を完了した後 \{#after-apple-completes-the-transfer\}

:::warning
Appleが転送を完了したら、すぐに新しいアプリ内購入キーをAdaptyに保存してください。転送後は、旧オーナーのキーはそのアプリで機能しなくなります。Adaptyに有効なキーがない間は、新しい購入をしてもアクセスレベルが付与されず、アプリにはエラーも返されません。その間に購入したユーザーは、[購入を復元](troubleshoot-app-store-integration#a-purchase-succeeds-but-the-customer-loses-access)したときにアクセスが付与されます。
:::

1. **新しいオーナー:** Adaptyの[**App settings** > **iOS SDK**](https://app.adapty.io/settings/ios-sdk)を開きます。**In-app purchase API (StoreKit 2)** と **App Store promotional offers** セクションに新しいアプリ内課金キーを入力し、**Save** をクリックします。
2. **新しいオーナー:** チームキーを連携して、AdaptyがプロダクトをApp Store Connectと同期し続けられるようにします。**App Store Connect API key** セクションにすでにキーがある場合は **Edit** をクリックし、ない場合は **Connect API Key** をクリックして、チームキーを入力します。
3. **新しいオーナー:** App Store Connectでアプリの **App Information** ページを開きます。そこに表示されている [**Production Server URL** と **Sandbox Server URL**](enable-app-store-server-notifications#enter-the-notification-url-in-app-store-connect) が、Adaptyの **URL for App Store server notifications** と一致していることを確認します。
4. **新しいオーナー:** [新しいキーが正常に機能したら](app-store-connection-configuration#check-each-credential)、[アプリ固有の共有シークレットを再生成](app-store-connection-configuration#enter-the-app-specific-shared-secret)して、旧オーナーのコピーが使えなくなるようにします。新しいシークレットをすぐにAdaptyに貼り付け、**Save** をクリックします。

### Google Play（Android）の移行 \{#google-play-android-transfer\}

アプリが別の Google Play デベロッパーアカウントに移行する場合、新しいオーナーは Adapty 内のすべての Google Play 認証情報を自分のものに置き換えます。

1. **新オーナー：** Adapty アカウントをお持ちでない場合は、[app.adapty.io](https://app.adapty.io) で作成してください。
2. **両オーナー：** 両方の Google Play デベロッパーアカウントが完全に登録済みであることを確認してください。
3. **旧オーナー：** Google Play Console または Google Play デベロッパーサポートを通じて移管リクエストを送信してください。Google から DUNS 番号、契約書、売買証明書などの追加書類を求められる場合があります。
4. **新オーナー：** 移管リクエストを確認して承認してください。
5. **Google：** Google サポートチームが移管を処理します。通常は数営業日以内に完了しますが、アカウント確認、サブスクリプションの複雑さ、支払い設定によってはそれ以上かかる場合があります。
6. **旧オーナー：** Google が移管を完了したら、[support@adapty.io](mailto:support@adapty.io) にメールを送り、Adapty 上でのアプリの移管を依頼してください。アプリ名と新オーナーのメールアドレスをお伝えください。
7. **新オーナー：** Adapty でアプリを受け取ったら、[Google Play 統合ガイド](initial-android) に従って、ご自身のアカウントで必要な認証情報をすべて生成・設定してください。

移管にはユーザー、サブスクリプション、統計情報、評価、ストアのリスティングが含まれます。既存のサブスクライバーへの課金は継続されますが、収益の振り込みは移管完了後に新しいオーナーのマーチャントアカウントに切り替わります。移管前の支払いレポートと注文は元のアカウントに残ります。詳細な要件については、Google の[移管ガイド](https://support.google.com/googleplay/android-developer/answer/6230247)を参照してください。

### Adaptyのみの移行 \{#adapty-only-transfer\}

アプリが別のAdaptyアカウントに移行するだけであれば、すべてのクレデンシャルと通知URLはそのまま維持されます。ストアやアプリのコードに変更は不要です。

1. **新しいオーナー:** Adaptyアカウントをお持ちでない場合は、[app.adapty.io](https://app.adapty.io)でアカウントを作成してください。
2. **元のオーナー:** [support@adapty.io](mailto:support@adapty.io)にメールを送り、AdaptyでのアプリのApp transfer（移管）を依頼してください。アプリ名と新しいオーナーのメールアドレスを記載してください。

## 移行が正常に完了したことを確認する \{#verify-transfer-completed-successfully\}

移行後、新しいオーナーがアプリを確認します。

1. **ダッシュボードへのアクセスを確認する**: 新しいオーナーが自分の Adapty ダッシュボードでアプリを確認できるか確かめます。
2. **SDK 接続をテストする**: アプリを起動し、Adapty SDK がエラーなく初期化されることを確認します。
3. **購入をテストする**: [テスト購入](validate-test-purchases)を行い、アクセスが解除されることを確認します。
4. **認証情報を確認する**: App Store の場合は[各認証情報が正しく機能するか確認](app-store-connection-configuration#check-each-credential)します。Google Play の場合は、新しいサービスアカウントが Adapty に正常に接続できるか確認します。
5. **更新を確認する**: 移行後数日間、既存のサブスクライバーからの更新が [**Event feed**](event-feed) に表示されるか確認します。
