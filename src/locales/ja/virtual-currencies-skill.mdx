[バーチャル通貨](virtual-currencies)は、ユーザーがプロダクトを購入したりサブスクリプションを更新したりしたときに、クレジットを付与します。virtual-currencies スキルは、AI ツールからバーチャル通貨を管理します。エージェントは通貨の一覧表示、各連携プロダクトが付与するクレジット数の確認、通貨の作成、連携プロダクトの追加・変更・削除を行います。また、ユーザーのクレジット取引履歴と残高を読み取り、そのユーザーの残高の理由を説明することもできます。[`adapty virtual-currencies` CLI コマンド](developer-cli-virtual-currencies)または [Adapty MCP サーバー](adapty-mcp)を通じて動作します。

:::note
スキルは各変更の前に確認を求めます。変更内容（リンクされた各プロダクトの変更前後のクレジット数、または新しい通貨とそのプロダクト）を表示し、あなたが同意した場合のみ変更を実行します。新しい金額は次回の購入または更新から適用されます。現在のサブスクライバーには、次回の更新時に新しい金額が適用されます。
:::

## 始める前に \{#before-you-start\}

- **Adapty のプロダクト**: 通貨は、Adapty に紐付けられた[プロダクト](create-product)を通じてクレジットを付与します。
- **Adapty アカウントに接続された AI ツール**: このスキルは [Adapty MCP サーバー](adapty-mcp)または [Adapty CLI](developer-cli) を通じて機能します。Claude Code と Codex では、プラグインが MCP サーバーを追加するため、サインインするだけで使えます。スキルはどちらの AI ツールを使っているかを確認し、それに応じて使用します。両方がある場合は MCP サーバーを使用します。どちらもない場合は、スキルがどちらをセットアップするか確認します。

## スキルが各変更前に確認すること \{#what-the-skill-asks-before-each-change\}

スキルは各変更の直前に通貨を読み取り、変更内容を表示します。スキルの質問に対するあなたの回答だけが有効です。スキルが変更内容を表示する前の「進めてください」という一般的な返答は無効です。「いいえ」と答えた場合、スキルは何も変更しません。

| 変更 | スキルが伝える内容 |
|---|---|
| 通貨を作成する | コード、名前、および紐づくプロダクト。通貨の削除やコードの変更はできず、1 つのアプリに設定できる通貨は最大 20 件です。残高は 1 つのユーザープロファイルに紐づくため、ユーザーがサインインしていない場合、アプリの再インストールや機種変更時にクレジットが失われます。 |
| 紐づくプロダクトを追加・変更する | 変更対象の各プロダクト：新規追加か、購入ごと・サブスクリプション期間ごとの変更前後のクレジット数。現在のサブスクライバーは次回更新時に新しい金額が適用されます。他の紐づくプロダクトはそのまま維持されます。 |
| 紐づくプロダクトを削除する | 現在のクレジット数とともに対象プロダクトを表示。そのプロダクトの購入ではこの通貨のクレジットが付与されなくなり、クレジットが付与されない購入はトランザクション記録に残りません。すでに付与済みのクレジットはそのまま維持されます。 |
| 名前または説明を変更する | 変更前後の名前または説明。他の設定はそのまま維持されます。 |

スキルの読み取りと書き込みの間に、ダッシュボードや別のツールから通貨が変更された場合、スキルはその変更を上書きしません。Adapty が書き込みを拒否するか、CLI 経由の名前変更の場合は、書き込み直前のスキルの読み取りで変更が検出されます。何も変更されません。スキルは変更内容を再度表示し、新しい確認を待ちます。

Adapty が変更に応答しない場合、スキルはすぐに再送信しません。まず通貨を読み取り、保存された内容を表示します。まだ反映されていない変更部分については、新しい確認画面を表示し、新しい確認を待ちます。

## スキルが残高を説明する仕組み \{#how-the-skill-explains-a-balance\}

ユーザーの残高について質問すると、スキルはプロファイル ID またはユーザー ID を使って、そのユーザーのクレジット取引と残高を読み取ります。どの購入・消費・付与が残高に影響したか、またどのクレジットがいつ期限切れになるかを教えてくれます。ダッシュボードの[ユーザープロファイル](virtual-currency-balance)でも同じデータを確認できます。

ユーザーがアプリを再インストールした後、新しいデバイスで、またはログイン後にクレジットが消えた場合、スキルはユーザーの以前のプロファイルを確認し、その残高を読み取ります。残高は1つのプロファイルに紐づいており、別のプロファイルには移動しないため、クレジットは以前のプロファイルに残ったままになります。すべてのデバイスで各ユーザーの残高を維持するには、[ユーザーを識別](virtual-currency-balance#balances-profiles-and-devices)してください。

## 制限 \{#limits\}

- **通貨の削除不可**: スキルやダッシュボードで、通貨の削除やコードの変更はできません。
- **残高の変更不可**: スキルは残高の増減を行いません。サーバーサイド API を通じてサーバーがクレジットの消費・付与を行います。詳しくは [仮想通貨クイックスタート](virtual-currency-quickstart) および [初期残高の付与](grant-initial-balance) を参照してください。特定ユーザーの残高を修正するには、[ダッシュボード](virtual-currency-balance#adjust-a-balance-manually) を使用してください。
- **無人での変更不可**: スケジュール実行やスクリプトなど、応答できる人がいない場合、スキルは読み取りのみ行います。変更が必要な場合は、その変更内容と実行すべきコマンドを報告します。

スキルを使わずにコマンドを自分で実行する場合は、[CLIから仮想通貨を管理する](developer-cli-virtual-currencies)を参照してください。
