[Adapty Developer CLI](developer-cli) は Claude アプリでも動作するため、ターミナルではなくチャットから Adapty アカウントを管理できます。Claude はコマンドをサンドボックス内で実行し、許可済みドメインにのみアクセスできるため、アカウントにサインインする前に Claude 側で一度だけセットアップが必要です。

:::note
Claude CoworkとチャットはAIが[一つのClaude](https://claude.com/resources/articles/cowork-is-now-claude)に統合されました：Coworkでできたことは、どの会話でも実行できるようになりました。統合はプランごとに順次展開中です。お使いのプランにCoworkが別途ある場合は、同じ手順に従って各タスクをCoworkで開始してください。
:::

**必要なもの：**

- Claudeアプリ
- Adaptyアカウント
- 企業向けClaude ワークスペースの場合は、ワークスペース管理者のサポート — [Adaptyドメインを許可する](#allow-the-adapty-domains) を参照

## Adapty プラグインを追加する \{#add-the-adapty-plugin\}

Adapty プラグインには、CLI のインストール、認証、操作を行うためのスキルが含まれており、Ads Manager の作業用の [Apple Ads スキル](developer-cli-ads-manager-skill)も含まれています。

プラグインを追加するには：

1. Claude で **Settings** → **Plugins** を開きます。
2. **Add** → **Add marketplace** をクリックします。
3. **Add from a repository** を選択します。
4. **URL** フィールドに `https://github.com/adaptyteam/apple-ads-cli` を貼り付けます。
5. **Sync** をクリックします。

<ZoomImage id="cowork-marketplace-url.png" width="700px" alt="AdaptyリポジトリURLとSyncボタンが表示されたClaudeのマーケットプレイス追加ダイアログ" />

Adapty プラグインはプラグインディレクトリの **Personal** の下に表示されます。

## Adapty ドメインを許可する \{#allow-the-adapty-domains\}

サンドボックスのドメイン許可リストに Adapty を追加するまで、CLI はサインインやアカウントの読み取りができません。

`adapty.io` と `*.adapty.io` の両方を許可してください。ほとんどの許可リスト実装では、ワイルドカードは apex ドメインをカバーしません。CLI 自体は `api.adapty.io` に接続し、作業中に Adapty ドキュメントを参照するエージェントは apex ドメインに接続します。

Claude はこれらの設定を会話開始時に適用します。会話中にアクセスモードを変更したりドメインを追加したりしても、その会話は開始時の設定を引き継ぎます — 新しい会話を開始してください。

### 個人アカウント \{#personal-accounts\}

許可リストはご自身で設定します。

1. Claude で **Settings** → **Capabilities** を開きます。
2. **Code execution and file creation** をオンにします。オンにするまで **Allow network egress** ブロックは表示されません。
3. **Allow network egress** をオンにします。
4. **Domain allowlist** で **Package managers only** を選択します。
5. **Additional allowed domains** の下に `adapty.io` を追加し、次に `*.adapty.io` を追加します。

<ZoomImage id="cowork-domain-allowlist.png" width="700px" alt="Claude の Allow network egress 設定画面。追加許可ドメインリストに adapty.io と *.adapty.io が入力されている" />

その他のアクセスモード **All domains** を選択すると、サンドボックスがあらゆるサイトにアクセスできるようになります。この設定を選択した場合、Adapty のドメインを追加する必要はありません。

### 企業ワークスペース \{#corporate-workspaces\}

管理者がホワイトリストを管理しています。ワークスペースに両方のドメインを追加するよう管理者に依頼してください。

## CLI のインストールと認証 \{#install-and-authorize-the-cli\}

会話は毎回クリーンな状態から始まります。CLI もトークンも設定も前の会話から引き継がれないため、インストールとログインの手順は会話のたびに繰り返す必要があります。

CLI をインストールして認証するには：

1. Claude で新しい会話を開始します。
2. Claude に Adapty CLI のインストールを依頼します。例：「Install the Adapty CLI」。Claude がインストールリンクを開く許可を求める場合があります — 許可してください。

   <ZoomImage id="cowork-cli-installed.png" width="700px" alt="A Claude chat where Claude confirms the Adapty CLI is installed" />

3. インストールが完了すると、Claude が Adapty へのサインインを提案します。同意すると、デバイスコード付きの認証リンクが投稿されます。コードは約15分で期限切れになります。

   <ZoomImage id="cowork-auth-link.png" width="700px" alt="A Claude chat where Claude posts the Adapty authorization link and device code" />

4. リンクを開くと、ブラウザに Adapty CLI の認証ページが表示されます。
5. ページに表示されているコードが Claude から提示されたコードと一致していることを確認し、**Authorize** をクリックします。コードが一致しない場合は **Deny** をクリックし、Claude に新しいリンクを要求してください。

   <ZoomImage id="cowork-authorize-page.png" width="700px" alt="ブラウザに表示されたAdapty CLI認証ページ。デバイスコードと「Authorize」ボタンが表示されています" />

6. チャットに戻り、認証が完了したことをClaudeに伝えます — 例えば「done」と入力します。Claudeがログインを確認し、アカウントの詳細を表示します。

CLIの準備が整いました。チャットからアプリ、プロダクト、ペイウォールを設定するには、[クイックスタートガイド](developer-cli-quickstart)に従ってください。

## トラブルシューティング \{#troubleshooting\}

| 問題 | 対処方法 |
|---------|---------------|
| **Sync** をクリックしてもスキルが表示されない | リポジトリURLが `https://github.com/adaptyteam/apple-ads-cli` であることを確認し、**Sync** を再度クリックしてください。 |
| インストールまたは認証中にネットワークエラーが発生する | `adapty.io` と `*.adapty.io` の両方を[ドメイン許可リスト](#allow-the-adapty-domains)に追加してください。設定は会話の開始時に適用されるため、追加後は新しい会話を開始してください。 |
| 認証リンクが開かない、または拒否される | コードは約15分で期限切れになります。Claudeに新しいリンクの生成を依頼してください。 |
| ブラウザのコードとチャットのコードが一致しない | **Authorize** をクリックしないでください。Claudeに新しいリンクを依頼し、最初からやり直してください。 |
