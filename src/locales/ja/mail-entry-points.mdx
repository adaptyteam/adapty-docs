エントリーポイントとは、ユーザーデータがAdapty Mailに届く方法のことです。どの方法を使っても、同じ3つの情報が含まれます。

- **メールアドレス**（必須）：メールの送信先です。これがなければ、Adapty Mail はプロファイルを作成しません。
- **[カスタマーユーザーID](how-profiles-work)**（任意、推奨）：あなた自身が管理する安定した識別子です。Adapty は再インストールやログインをまたいで1人につき1つのプロファイルを維持するため、メールアドレスを提供する前に行った購入もメールで届けられます。
- **サブスクリプションイベントのフィード**（任意、推奨）：トライアル、更新、キャンセル、返金などのイベントをリアルタイムで受け取ります。これがない場合、送信できるシーケンスは「一度も購入していないユーザー向け」のものだけになります。

Pick the entry point that matches your app:

- **Adapty**: アプリがすでに Adapty SDK を使用している場合に選択します。Adapty がプロファイル、メールアドレス、サブスクリプションイベントを転送するため、独自のサーバーは不要です。アプリ側でユーザー識別とメールアドレスの収集を追加してください。詳細は [Adapty と Adapty Mail の連携](mail-collect-emails)を参照してください。
- **Adapty Mail API**: すでにこのデータを保持しているバックエンドがある場合、アプリに Adapty SDK がない場合、または他の場所からサブスクライバーをインポートする場合に選択します。プロファイルとトランザクションイベントは自分でポストします。**Settings** > **Project** のシークレットキーでリクエストを認証します。詳細は [Adapty Mail API でメールとトランザクションを送信する](mail-send-data-via-api)を参照してください。
- **FunnelFox**: FunnelFox のウェブファネルでユーザーを獲得・課金している場合に選択します。FunnelFox はすでにメールアドレス、購入情報、サブスクリプションイベントを保持しており、Adapty Mail に自動転送します。SDK 対応もリクエストの記述も不要です。詳細は [FunnelFox と Adapty Mail の連携](mail-funnelfox)を参照してください。
- **組み合わせ**: 複数のエントリーポイントを同時に使用できます。Adapty Mail はメールアドレスでユーザーを照合します。同じメールアドレスを報告した 2 つのソースは 1 つのプロファイルにまとめられ、異なるメールアドレスは `customer_user_id` が同一であっても別々のプロファイルとして作成されます。
