エントリーポイントとは、ユーザーデータが Adapty Mail に届く方法のことです。どの方法を使う場合も、Adapty Mail がユーザーにメールを送信するには、次の3つの情報が必要です：

- **メールアドレス**: メールの送信先。
- **[カスタマーユーザーID](how-profiles-work)**: ユーザーの一意の識別子。
- **サブスクリプションイベントのフィード**: トライアル、更新、キャンセル、返金など、リアルタイムで発生するイベント。

アプリに合ったエントリーポイントを選択してください：

- **Adapty**: アプリがすでに Adapty SDK を使用している場合に選択します。Adapty がプロファイル、メールアドレス、サブスクリプションイベントを自動で転送するため、独自のサーバーは不要です。アプリ側でユーザー識別とメールアドレスの収集を追加してください。詳しくは [Adapty を Adapty Mail に接続する](mail-collect-emails) を参照してください。
- **Adapty Mail API**: バックエンドですでにこのデータを管理している場合、アプリに Adapty SDK が入っていない場合、または別の場所からサブスクライバーをインポートする場合に選択します。プロファイルとトランザクションイベントは自分で送信します。**Settings** > **Project** のシークレットキーでリクエストを認証します。詳しくは [Adapty Mail API でメールとトランザクションを送信する](mail-send-data-via-api) を参照してください。
- **FunnelFox**: FunnelFox のウェブファネルを通じてユーザーを獲得・課金している場合に選択します。FunnelFox がすでにメールアドレス、購入情報、サブスクリプションイベントを保持しており、自動的に Adapty Mail に転送するため、SDK の作業もリクエストの記述も不要です。詳しくは [FunnelFox を Adapty Mail に接続する](mail-funnelfox) を参照してください。
- **組み合わせ**: 複数のエントリーポイントを同時に使用することもできます。Adapty Mail は `customer_user_id` とメールアドレスで受信したユーザーデータを照合するため、複数のソースから情報が届いたユーザーでも、重複したメールが届くことなく、1 つのプロファイルと 1 つのシーケンスが維持されます。
